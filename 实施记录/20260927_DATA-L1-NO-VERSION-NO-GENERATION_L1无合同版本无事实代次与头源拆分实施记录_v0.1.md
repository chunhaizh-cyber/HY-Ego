## 2. 实际实施

### 2.1 L1 current-only核心

- 删除L1服务合同版本常量、请求/结果字段、入口校验和持久编码。
- 删除仓库及公开面的`G/G0/G1/Gread/H`、事实代次计数器、创建/退出/首次发布代次、代次漂移和历史读取分支。
- 单owner、三分区和有限N分区写入改为同一独占锁下构造私有候选，完整校验后一次交换；失败时正式状态零变化。
- 读取改为锁内current-only值式读回；没有共同快照合同的多次独立读取不再用代次互证。
- 新持久载荷格式为格式5；保留格式版本、快照序号、活动槽、长度和SHA-256，不保存服务合同版本或事实代次；旧格式4只拒绝且保留原材料。
- 技术幂等仍按同实例、同owner或同组合域、同幂等身份和完整规范请求处理精确重复与异义冲突。

### 2.2 无版本公开身份与头源拆分

- 将55个仅表示历史服务合同身份的L1 `_v1/_v2/_v3`类型或函数收敛为无版本名称；没有建立兼容别名或双入口。
- `L1事实基座持久快照格式版本_v1`继续保留，因为它表示持久格式而非服务合同。
- `仓库.L1事实基座.h`和`服务.L1事实基座.h`只保留声明、必要类型和PIMPL/运行包成员；全部非模板实现移入对应`.cpp`。
- 新增的生产`.cpp`均已登记到`海中鱼巣.vcxproj`和`.filters`；生产`.cpp`、工程登记和filters登记均为50项且一一对应。
- 补齐`.filters`中的`领域\合同`筛选器定义。

### 2.3 直接消费者

- DATA-L2、DATA-L3、应用服务、线程和装配消费者改用无合同版本、无事实代次的请求、结果和current-only入口。
- 删除消费者侧代次拼接、漂移重试、首次历史互证和旧读取预算回退。
- 无法在一次锁内取得完整共同材料或缺少现行精确provider的路径具名返回既有`未实现`、`依赖未实现`或`内部不一致`，不使用连续读取、时间、计数器或哈希伪造快照/幂等身份。
- 自我线程仍保留常驻消息循环、停门、邮箱、防重、退出唤醒、join和诊断；下层未实现时不假开门、不假承接。
- 普通应用当前只校验具名运行配置并建立/唯一持有current-only L1持久运行包，随后返回`普通应用装配状态::未实现`；不创建治理线程、不开放治理门。启动入口已删除对装配结果旧`根事实代次`字段的读取。

## 3. 代码知识变更清单

### 3.1 L1核心公开函数

- `L1事实基座仓库::{初始化持久恢复,建立所有者范围,验证所有者范围重入,退出所有者范围}`：删除合同版本和事实代次语义；恢复只读写current-only格式5材料。
- `L1事实基座仓库::{提交中性写集,提交所有者范围中性写集,提交跨所有者原子事务,提交三分区原子事务,提交有限N分区原子事务}`：改为独占锁内私有候选一次交换；后三者历史版本后缀退出。
- `L1事实基座仓库::{读取当前节点,读取当前关系,读取当前值,读取当前属性,读取中性当前源关系组,读取中性当前目标关系组}`：删除代次输入/回显，返回当前事实副本。
- `L1事实基座仓库::{读取所有者范围当前节点,读取所有者范围当前关系,读取所有者范围当前值,读取所有者范围当前事实,读取所有者范围所属节点当前完整值组,读取所有者范围来源当前完整值组,读取所有者范围属性类型当前完整值组,读取所有者范围完整空域,读取节点全部当前引用,读取当前结构所有者,读取所有者范围当前源关系组,读取所有者范围当前目标关系组}`：统一为预算自由current-only读取；旧版本化名称退出。

- `L1事实基座服务`对应转发入口：签名和返回DTO同步迁移；服务层不恢复旧校验或兼容入口。
