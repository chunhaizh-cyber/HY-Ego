### 2.3 self 与最小 manager

- self 消息迁移为 `自我线程根需求复核消息_v2`，创建时一次绑定 fresh、G4-A、task owner 和 manager sink 四个非拥有端口。
- self 工作线程在门关闭时冻结邮箱批次，锁外完成 fresh、双根复核、按意图恢复或签包及异步投递；调用线程只提交控制请求并等待结果。
- self 对固定意图命中不可复用任务返回 `根初始化代际已结束`，不签第二包；可恢复失败以 10ms 可中断等待重试；冻结批、当前项和邮箱的消息指纹访问受同一互斥保护。
- 新建 `任务管理线程`：单一可 join 线程、有界 deque、精确重复/异义冲突、停止排空和诊断快照；只恢复任务初始化并独立读回核心和目标投影。
- manager 对事实代次漂移/已可能发布只在同轮用原包立即恢复一次；资源失败不在同轮立即重试，而是保留原项进入下一轮可中断等待；活动精确重复会唤醒重试等待。

### 2.4 普通应用与工程

- 普通应用上下文唯一持有 task owner、manager、fresh provider、G4-A provider 和 self，并按依赖顺序停止、join。
- 无窗口路径在阶段20后启动 manager、提交固定首次安全/服务双根消息并等待 self 真正开门；失败走阶段13安全回收。
- 普通控制面板路径仍返回阶段12，不启动 manager、不开放治理门。
- 根工程登记 `线程_任务管理.h/.cpp`；新增首批消费专项工程，并同步迁移三个既有专项到新 ABI。
