## 3. 实际变更

### 3.1 协议与身份

- 新增 `海中鱼巣.线程.协议.任务重筹办意图`，承载不可变意图、逐字段完整性、逐字段同义比较、结构化提交状态和抽象提交端口。
- 任务工作结果、任务结果回执和任务结果治理消息协议升级到版本 4。
- 两笔新增任务治理写入身份与既有任务实际结果写入身份一起执行非零、两两不同守卫。
- 两笔新增身份沿工作结果、回执、治理消息、治理后继、目标裁决处理槽和重筹办意图逐字段原样传递。
- 消息发生时间只在 `1..INT64_MAX` 内转换为两笔 DATA 请求共用的生命周期发生时间；不读取当前时钟、不哈希、不截断、不默认补值。

### 3.2 DATA-L2 原子迁移

- `L2提交目标未达成待重筹办迁移请求` 新增旧当前路径和旧当前实例身份。
- `L2提交目标未达成待重筹办迁移结果` 新增旧路径和旧实例正式读回。
- 写前在同一事实截止读取并互证任务、首态、目标裁决证据、当前路径关系和当前实例关系。
- 同一个 owner 写集创建目标未达成待重筹办状态，并退出旧当前治理状态关系、旧当前选择关系和旧当前实例关系。
- 旧路径节点、旧实例节点、任务实际结果和历史治理状态不退出。
- 精确重复重放首次规范化写集，并重新读回首次迁移结果；同键异义返回幂等冲突。

### 3.3 业务提供者

- 新增业务数据头 `任务重筹办.数据.h` 和唯一业务入口 `任务目标未达成重筹办触发提供者::形成待重筹办与下一筹办工作包`。
- 提供者只借入 `L2任务结构服务`，先独立读取并互证任务、路径、实例和正式实际结果，再提交裁决首态与迁移。
- 提交成功或精确重复后，提供者在迁移后事实代次独立读取当前治理状态、当前路径、当前实例、正式实际结果及历史材料。
- 只有当前路径和当前实例均已退出、正式结果仍可读且全部历史互证成立时形成工作包。
- 新筹办轮次严格为旧筹办轮次加一；溢出或任何材料不完整均结构化内部终止。

### 3.4 线程与生产装配

- 自我线程新增独立端口锁、幂等绑定、停止生产并幂等解除、状态 12/13、不可变意图缓存和同槽显式重试。
- 外部端口调用不持有自我线程状态锁；独立端口锁保证提交与解除互斥，不发生悬空调用。
- 目标已达成仍停在“待验证后完成”；只有目标未达成才提交重筹办意图。
- 队列满时保留原意图和原写入身份；显式重试复用同一治理处理槽，不重新取得邮箱消息或重新裁决。
- 任务管理线程新增重筹办有界槽、轮转、公平消费、显式合法等待重试和资源等待自动重排；业务提供者调用发生在任务管理锁外。
- 任务结果生产运行包持有上行桥、重筹办提供者、任务管理线程和任务工作线程，负责端口绑定、启动门禁和停止解除。
- 普通应用只在运行包成功启动后开放自我线程治理运行门。

### 3.5 工程与专项

- 三个新文件已登记到 `海中鱼巣.vcxproj` 与 `海中鱼巣.vcxproj.filters`。
- 治理专项扩展了三笔写入身份守卫、目标未达成真实生产链、队列满同槽重试、端口解绑幂等、DATA 原子迁移和正式读回断言。
- 最终实现删除了业务提供者未使用的 `<new>` 头；未恢复默认整对象比较或大型内联完整性布尔链，避免再次触发已观察到的 MSVC 模块编译器内部错误。
