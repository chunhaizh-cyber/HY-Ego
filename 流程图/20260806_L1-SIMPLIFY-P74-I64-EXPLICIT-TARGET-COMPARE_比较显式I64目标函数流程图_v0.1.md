# L1-SIMPLIFY-P74 比较显式 I64 目标函数流程图 v0.1

更新时间：2026-08-06

本图只描述 `特征比较服务::比较显式I64目标`。登记、满足模板命中、需求维护和装配不进入本函数。

```mermaid
flowchart TD
    A["接收显式目标判断比较请求"] --> B{"版本 身份 截止 见证 上下文和结果位合法吗"}
    B -- "否" --> R1["入口拒绝 零L1调用"]
    B -- "是" --> C["按特征定义和目标判断用途复制当前显式合同"]
    C --> D{"当前合同数量和状态合法吗"}
    D -- "零项" --> R2["未注册"]
    D -- "多项" --> R3["内部不一致 注册不唯一"]
    D -- "失效" --> R4["未注册 注册失效"]
    D -- "唯一有效" --> E{"算法门禁 单位 维度 分量匹配吗"}
    E -- "否" --> R5["结构化拒绝或版本漂移"]
    E -- "是" --> F["读取一次L1完整快照"]
    F --> G{"读取成功且截止等于请求吗"}
    G -- "否" --> R6["资源失败 内部不一致或输入版本失效"]
    G -- "是" --> H{"注册节点 配置 九关系和定义值域与合同一致吗"}
    H -- "否" --> R7["内部不一致或输入版本失效"]
    H -- "是" --> I{"左实例槽 定义关系 当前槽和值见证一致吗"}
    I -- "否" --> R8["输入版本失效"]
    I -- "是" --> J{"右目标状态 当前槽 目标值 属性 来源和见证一致吗"}
    J -- "否" --> R9["输入版本失效"]
    J -- "是" --> K{"左右值都在定义闭区间吗"}
    K -- "否" --> R10["入口拒绝 值域不允许"]
    K -- "是" --> L["计算compare左值右值得到负一零一"]
    L --> M{"请求差异材料吗"}
    M -- "否" --> O["按请求位形成三态或具名关系"]
    M -- "是" --> N{"右减左可表示吗"}
    N -- "否" --> R11["入口拒绝 差异不可表示 零比较载荷"]
    N -- "是" --> P["形成右减左安全差异"]
    P --> O
    O --> Q["返回同截止 注册身份 算法版本 上下文和双输入回执"]
    Q --> Z["结束 零写入 零满足解释"]
    R1 --> Z
    R2 --> Z
    R3 --> Z
    R4 --> Z
    R5 --> Z
    R6 --> Z
    R7 --> Z
    R8 --> Z
    R9 --> Z
    R10 --> Z
    R11 --> Z
```

最大边界：成功只证明显式目标值与当前值在一个已登记比较合同和同一 L1 截止内形成正式比较结果；它不证明 P73 当前需求目标模板已命中，不形成满足、维护、路径、任务或装配事实。
