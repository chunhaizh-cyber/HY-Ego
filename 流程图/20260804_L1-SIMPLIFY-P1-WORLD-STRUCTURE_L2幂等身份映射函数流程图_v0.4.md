# L1-SIMPLIFY-P1-WORLD-STRUCTURE L2 幂等身份映射函数流程图 v0.4

依据：[L2 业务合同隔离详细设计](../规范/详细设计/20260804_L1-SIMPLIFY-P1-WORLD-STRUCTURE_L2业务合同隔离详细设计_v0.4.md)。

```mermaid
flowchart TD
    A["L2 调用方提交世界操作请求"] --> B{"合同/规则/业务身份有效?"}
    B -- "否" --> R1["返回入口拒绝 + 空事实"]
    B -- "是" --> C{"服务所有者"}
    C -- "世界登记" --> D["私有映射: 0x01 << 56 | 身份值"]
    C -- "初始场景" --> E["私有映射: 0x02 << 56 | 身份值"]
    D --> F["形成 L1 中性写集"]
    E --> F
    F --> G["单次提交写集"]
    G --> H{"L1 返回成功或精确重复?"}
    H -- "否" --> R2["映射结构化非成功 + 空事实"]
    H -- "是" --> I["生成预计动作动态: 仅作待校准材料"]
    I --> J["从独立 L1 读取入口再次取得当前事实"]
    J --> K{"同代次、身份、类型、方向、来源全部一致?"}
    K -- "否" --> R3["返回版本漂移或内部不一致"]
    K -- "是" --> L["用读取事实校准动作动态"]
    L --> R4["返回已提交/幂等读回 + L2 业务事实"]
```

约束：业务身份是 L2 合同；映射键、写集和预计动作动态均不得进入 L2 公开结果。成功事实只来自独立读取校准。
