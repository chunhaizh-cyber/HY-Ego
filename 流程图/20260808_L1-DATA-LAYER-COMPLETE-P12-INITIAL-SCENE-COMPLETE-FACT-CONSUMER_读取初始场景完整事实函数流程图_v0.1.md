# L1-DATA-LAYER-COMPLETE-P12-INITIAL-SCENE-COMPLETE-FACT-CONSUMER 读取初始场景完整事实函数流程图 v0.1

日期：2026-08-08

根函数：`L1实际存在场景组合服务::读取初始场景完整事实`

```mermaid
flowchart TD
    A["入口：初始场景读取请求"] --> B["调用场景服务读取初始场景完整结构恰一次"]
    B --> C{"结构结果是否已读取且事实完整"}
    C -- "非成功" --> E1["原状态返回；坏成功返回内部不一致；不带部分事实"]
    C -- "是" --> D{"直接成员组是否为空"}
    D -- "是" --> Z["形成已读取结果：完整场景结构 + 空成员完整事实组"]
    D -- "否" --> F["按场景结构稳定顺序取下一成员结构项"]
    F --> G["调用实际存在服务按成员定位当前资格恰一次"]
    G --> H{"资格是否已读取、完整且截止等于场景截止"}
    H -- "否" --> E2["未找到或坏成功归内部不一致；漂移等保留对应非成功；销毁整组"]
    H -- "是" --> I["由场景请求、成员、资格值和归属关系机械形成实际存在读取请求"]
    I --> J["调用初始场景实际存在原子发布服务读取恰一次"]
    J --> K{"是否已读取且完整"}
    K -- "否" --> E3["未找到或坏成功归内部不一致；其它非成功映射；销毁整组"]
    K -- "是" --> L{"世界根、场景、成员、资格、归属关系、共同截止是否逐字段全等"}
    L -- "否" --> E4["截止不同返回版本漂移；同截止字段矛盾返回内部不一致；销毁整组"]
    L -- "是" --> M["加入成员完整事实临时组"]
    M --> N{"是否还有成员"}
    N -- "有" --> F
    N -- "无" --> O["按存在稳定编码严格升序并检查数量、一一对应、无重复"]
    O --> P{"最终完整性是否成立"}
    P -- "否" --> E5["返回内部不一致；不带部分事实"]
    P -- "是" --> Z
    Z --> Q["返回已读取及调用方拥有的完整值式结果"]
```

## 边界说明

- 场景服务内部才允许调用第一层 P11 源关系查询和 P10 目标关系查询；本根函数对第一层直调为零。
- 零成员是合法成功，实际存在资格与组合事实提供者调用数均为零。
- 任一成员失败都销毁整组，不返回部分成功，不重试、不等待、不读取完整快照、SQL、材料、缓存或日志。
- 图只冻结初始场景、直接子场景和直接成员的完整事实读取，不代表完整世界树快照。
