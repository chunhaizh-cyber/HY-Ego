# DATA-L1-THREE-PARTITION-ATOMIC-V2 三分区中性原子事务业务流程图 v0.1

日期：2026-08-28

图类型：DATA-L1 中性结构能力流程

完成边界：只描述三个内部结构分区共同形成一个 L1 事实代次；不表达特征、状态、动态或任何业务成功。

```mermaid
flowchart TD
    A["调用方已持有同一 L1 实例的三个合法内部写端口"] --> B["提交三分区原子事务 v2\n完整请求 + 共同 G0 + 组合幂等身份"]
    B --> C{"纯值合同、三端口绑定、三 owner、三写集是否有效"}
    C -- "否" --> R1["入口拒绝 / 引用冲突 / 内部不一致\n零候选、零发布"]
    C -- "是" --> D["按参与者 1..3 和写项键规范化完整请求"]
    D --> E["取得仓库唯一写锁并检查隔离 / 完整性"]
    E --> F{"v2 组合幂等账是否命中"}
    F -- "同键同义" --> R2["精确重复\n首次 G1 + 首次三份映射\n零新应用"]
    F -- "同键异义" --> R3["幂等冲突\n零候选、零发布"]
    F -- "未命中" --> G{"共同 G0 是否仍为当前"}
    G -- "否" --> R4["事实代次漂移\n不绑定首次结果"]
    G -- "是" --> H["复制私有候选仓库"]
    H --> I["应用参与者 1\n形成映射 1"]
    I --> J["解析 2 → 1 引用\n应用参与者 2\n形成映射 2"]
    J --> K["解析 3 → 1/2 引用\n应用参与者 3\n形成映射 3"]
    K --> L["把三个候选临时代次和首次写入账归一为 G1=G0+1"]
    L --> M{"全局引用、端点、值、槽、索引和分区闭包是否完整"}
    M -- "否" --> R5["引用冲突 / 内部不一致\n丢弃整个候选"]
    M -- "是" --> N["写候选 v2 组合幂等账并准备持久快照 v2"]
    N --> O{"交换前持久准备是否成功"}
    O -- "否" --> R6["资源失败 / 内部不一致\n正式状态零变化"]
    O -- "是" --> P["一次交换候选为正式仓库状态"]
    P --> Q{"结果形成是否可判定"}
    Q -- "是" --> R7["已提交\n共同 G1 + 三份完整映射"]
    Q -- "否" --> R8["已可能发布\n仅允许原身份原请求重放"]
```
