# L2 旧链清理与六类结构 CRUD 分步路线图 v0.1

日期：2026-08-10

设计身份：`L2-STRUCTURE-CRUD-REBUILD`

```mermaid
flowchart TD
    A[新版 L1 中性节点 关系 值 CRUD] --> D1[D1 删除完整自我准入与发布闭包]
    D1 --> D2[D2 删除旧因果与动态算法材料链]
    D2 --> D3[D3 删除旧状态 动态 特征比较服务]
    D3 --> D4[D4 删除旧特征定义与实例特征服务]
    D4 --> D5[D5 删除旧世界 场景 存在服务]
    D5 --> G1[G1 冻结 L2 六类纯结构合同]
    G1 --> S1[S1 场景节点新增与查询]
    S1 --> E1[E1 存在节点新增与查询]
    E1 --> S2[S2 场景成员关系 CRUD 与完整结构查询]
    S2 --> S3[S3 场景属性换代与退出历史]
    E1 --> E2[E2 存在属性换代与退出历史]
    E2 --> F1[F1 特征定义 CRUD]
    F1 --> F2[F2 特征实例新增 查询与按存在枚举]
    F2 --> F3[F3 特征值换代 退出与历史]
    F3 --> T1[T1 状态新增与查询]
    T1 --> T2[T2 状态替换 退出与历史]
    T2 --> Y1[DYN1 动态新增与查询]
    Y1 --> Y2[DYN2 动态替换 退出与历史]
    Y2 --> C1[C1 因果新增与查询]
    C1 --> C2[C2 因果替换 退出与历史]
    C2 --> Z[A1 唯一 L2 结构服务聚合公开面]
    S3 --> Z
    F3 --> Z
    E2 --> Z
    Z --> V[生产外自定义参数调用 结构化结果 当前历史读回]
```

路线说明：

- 删除按反向依赖从最高层向底层推进，任何集合外生产消费者都会阻断对应删除叶。
- 新建按真实结构依赖推进；层号不形成逐层转发。
- 每个 CRUD 叶只验证本叶公开入口，不使用日志、生产内自检或业务真实性剧本。
- 轮廓只是特征类型化参数之一，统一走特征结构服务，不建立轮廓专用 CRUD。
