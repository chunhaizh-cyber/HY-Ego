## 1. 调用边界

```mermaid

    P29 --> P21["P21 实际存在资格集合"]
```

## 2. 单轮函数流程

```mermaid
flowchart TD
    A["进入一轮读取"] --> G0["P19读取当前世界结构，取得G0"]
    G0 -->|"非成功"| X["固定状态映射并立即结束"]
    G0 --> E["P21读取当前实际存在资格集合"]
    E -->|"非成功"| X
    E --> S["P17尝试读取本轮唯一完整快照"]
    S -->|"非成功"| X
    S --> F1["P24从同一快照读取实例槽集合"]
    F1 -->|"非成功"| X
    F1 --> Z{"槽总数为0?"}
    Z -->|"是"| F2E["P22调用0；P25登记定位=nullopt"]
    Z -->|"否"| R["P22尝试读取当前登记恰一次"]
    R -->|"非成功"| X
    R --> F2["P25从同一快照读取定义详情"]
    F2E --> F2
    F2 -->|"非成功"| X
    F2 --> F3["P26从同一快照读取当前值"]
    F3 -->|"非成功"| X
    F3 --> SD["P27从同一快照读取状态动态"]
    SD -->|"非成功"| X
    SD --> G1["P19读取当前事实代次，取得G1"]
    G1 -->|"非成功"| X
    G1 --> C["P28组合同轮全部纯值材料"]
    C --> O["返回P28结果"]
```

任一非成功后，图中后继 provider、P28 和第二轮调用数均为0；许可拒绝不等待、不 sleep。

## 3. 最多两轮总流程

```mermaid
flowchart TD
    A["校验公开请求与三份不可变定位"] -->|"失败"| RI["入口拒绝或内部不一致\n全部provider调用0"]
    A --> R1["执行第一轮完整流程"]
    R1 -->|"provider非成功"| X1["映射该状态\n不重试"]
    R1 -->|"P28成功或非版本漂移"| O1["原样返回"]
    R1 -->|"仅P28版本漂移"| D["销毁第一轮全部材料"]
    D --> R2["从P19 G0开始执行第二轮"]
    R2 -->|"provider非成功"| X2["映射第二轮状态"]
    R2 -->|"P28任意结果"| O2["原样返回\n仍漂移即最终漂移"]

    D -. "禁止" .-> N1["只重读G1或漂移子集"]
    D -. "禁止" .-> N2["复用第一轮快照/登记/vector"]
    D -. "禁止" .-> N3["sleep/yield/第三轮"]
```

provider 自身返回版本漂移不满足第二轮资格；只有第一轮全部 provider 成功且 P28 因共同截止不等返回版本漂移，才完整执行第二轮。

## 4. 状态与调用数

| 条件 | 对外结果 | 后继调用 | 第二轮 |
| --- | --- | --- | --- |
| 请求错误 | 入口拒绝 | 全部0 | 0 |
| 保存定位损坏 | 内部不一致 | 全部0 | 0 |
| 任一许可拒绝 | 许可拒绝 | 该点后0，P28=0 | 0 |
| 任一其它provider非成功 | 固定同类映射 | 该点后0，P28=0 | 0 |
| 第一轮P28内部不一致/资源失败/未实现 | 原样返回 | 已完成第一轮 | 0 |
| 第一轮P28版本漂移，第二轮成功 | 已读取 | 每轮完整独立 | 1 |
| 两轮P28版本漂移 | 版本漂移 | 每轮完整独立 | 1 |
| 合法空世界 | 已读取完整快照 | P22=0，其余各1 | 0，除非P28漂移 |

成功结果的字段、稳定排序、完整性和缺项组完全由 P28 形成；P29 不二次加工。
