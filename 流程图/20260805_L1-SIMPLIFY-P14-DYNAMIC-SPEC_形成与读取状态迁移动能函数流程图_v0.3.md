## 身份裁决

P14 是关系20状态迁移动能领域，使用 G7 状态/状态动态意图组的入口变体3，固定标签
`0x15000F01`、幂等域 `0x0F`。G7 T01/T02 标签不复用；G9 留给 P78 动态因果领域。

## 1. 登记函数合同与流程

```text
根函数：L1动态服务::建立登记
签名：L1动态登记结果 建立登记(const L1动态登记请求& 请求)
公开 DTO：合同版本1、规则版本1、动态操作幂等身份、期望事实代次
L1写集：合同版本2；十节点；零关系/值/槽/退出
凭证：请求意图组7、格式1、标签0x15000F01、变体3、结果计划摘要全零
```

```mermaid
flowchart TD
    A[读取请求合同/规则/幂等身份/期望事实代次] --> B{锁前字段与G7变体3是否合法?}
    B -- 否 --> X0[返回入口拒绝；provider/提交0/0]
    B -- 是 --> C[按0x0F域映射L1幂等键并形成HZY-L1G7摘要]
    C --> D[调用L1事实基座服务::探测幂等恰一次]
    D -- 同键同摘要 --> Y[返回首次登记幂等读回；provider/提交0/0]
    D -- 同键异摘要 --> X1[返回幂等冲突；不形成候选；0/0]
    D -- 已隔离或内部不一致 --> X2[返回对应拒绝；不形成候选]
    D -- 未找到 --> E[读取非空完整L1快照并校验期望事实代次]
    E --> F{快照/首项见证可形成事实互证材料?}
    F -- 否 --> X3[返回版本漂移/内部不一致/资源失败；不交换]
    F -- 是 --> G[构造L1 v2十节点写集与发布后读回计划]
    G --> H[模式事实互证；L1核心版本见证1次；外部provider0]
    H --> I[调用L1事实基座服务::提交写集恰一次]
    I --> J{成功或精确重复?}
    J -- 否 --> X4[映射状态；零领域结果]
    J -- 是 --> K[同一代次逐项读回十项稳定编码/类型]
    K --> L{十项、类型、代次、互异性均一致?}
    L -- 否 --> X5[返回内部不一致并隔离；保留已发布代次；禁止补写]
    L -- 是 --> S[返回已登记/幂等读回与完整登记DTO]
```

## 2. 纯值规格函数合同与流程

```text
根函数：L1动态服务::形成状态迁移动能规格
输入：P13 v0.2 实际存在I64后继状态规格结果（值式只读）
L1写入/provider/幂等/领域意图：全部0
```

```mermaid
flowchart TD
    P[读取P13值式结果] --> Q{已形成且动态准入允许?}
    Q -- 无前态/等价/禁止 --> QX[返回无需形成或禁止形成；零规格]
    Q -- 其它非成功 --> QY[映射P13非成功；零规格]
    Q -- 是 --> R[校验共同截止、主体/场景/槽、P12选择和P11迁移证据]
    R --> T{非等价增加/减少、差异非零且证据完整?}
    T -- 否且矛盾 --> TX[返回内部不一致；零规格]
    T -- 是 --> U[形成0x44动态节点、八值、角色1—5/9六关系、八槽]
    U --> V{角色6—8为空且形状完整?}
    V -- 否 --> TX
    V -- 是 --> VS[返回状态迁移动能纯值规格；不调用L1]
```

## 3. 读取函数合同与流程

```text
根函数：L1动态服务::读取状态迁移动能
输入：十五个已发布稳定编码
L1写入/provider/幂等/领域意图：全部0；只调用L1当前/历史读取入口
```

```mermaid
flowchart TD
    R1[读取G0并校验十五个稳定编码] --> R2[按已知编码读当前；已退出则读历史]
    R2 --> R3{关系20角色1—5/9、八槽、来源、生命周期完整?}
    R3 -- 否 --> RX[返回对应非成功；空事实]
    R3 -- 是 --> R4[读取G1并校验共同事实截止]
    R4 --> R5{G0与G1同代次?}
    R5 -- 否且未重试 --> R1
    R5 -- 否且已重试 --> RY[返回版本漂移；空事实]
    R5 -- 是 --> RS[返回完整状态迁移动能事实]
```
