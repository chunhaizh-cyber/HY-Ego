## 1. 业务 / 结构流程

```mermaid
flowchart TD
    A[读取概念空间根视图请求] --> B{版本、类别、历史截止、预算有效?}
    B -- 否 --> X1[入口拒绝或数量预算不足\n零投影载荷]
    B -- 是 --> C[正式读取四本体根组\n取得或校验共同 G0]
    P[四本体根 provider\n正式初始化入口\n普通应用唯一装配] --> C
    C --> D{根组恰为四角色且同截止?}
    D -- 否 --> X2[事实代次漂移或内部不一致\n零投影载荷]
    D -- 是 --> E[普通应用唯一装配\n调用 L2 公开概念图读取合同\n不得调用 private helper]
    E --> F{概念、归属、直接边闭包通过?}
    F -- 否 --> X3[内部不一致/资源/许可失败\n零投影载荷]
    F -- 是 --> G{请求叶级支持关系?}
    G -- 否 --> I[概念去重、稳定排序\n保留全部直接多父边]
    G -- 是 --> H[按概念读取同 G0 支持关系\n只保留身份与关系引用]
    H --> J{支持端点、生命周期、G0互证?}
    J -- 否 --> X4[事实代次漂移或内部不一致\n零投影载荷]
    J -- 是 --> I
    I --> K{根、概念、边、支持关系和负载预算通过?}
    K -- 否 --> X5[数量预算不足或内部不一致\n零投影载荷]
    K -- 是 --> L[构造值式 L3 根视图结果\n已读取、实际 G0]
    L --> M[独立正式读回结果确认\n不写入任何事实]
```

## 2. 规则注记

- 根组、概念图和支持关系必须来自同一 `G0`；上游截止不一致不允许拼接或自动重试到另一代次。
- L3 只组合公开 L2 结构，不创建概念、不复制世界事实、不解释业务真实性。
- 四本体根初始化中的进程缓存不是根权威；缓存与正式根组读回冲突时返回内部不一致 / 发布未知。
- 四本体根 provider、初始化入口、普通应用装配和工程登记必须以正式根组 / 概念图读回确认成功；“已发布材料”不得成为读入口或第二权威。
- 任一非成功分支都返回空投影；L3 不产生写集、幂等账或持久快照。
