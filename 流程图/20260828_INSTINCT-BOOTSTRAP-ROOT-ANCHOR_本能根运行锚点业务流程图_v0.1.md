## 1. 启动主流程

```mermaid
flowchart TD
    A["真实自我、四本体根、方法登记根成功"] --> B["形成请求：唯一自我 + 本次启动UTC纳秒"]
    B --> C{"请求有效？"}
    C -- "否" --> X["入口拒绝；锚点空；不创建自我线程"]
    C -- "是" --> D["建立或恢复安全值、服务值一阶定义"]
    D --> E["建立或恢复两份 M-X 二次特征概念"]
    E --> F["建立或恢复唯一自我下两份根实例"]
    F --> G{"每个根的当前值和当前状态情况"}
    G -- "都不存在" --> H["单事务发布首值 M/2 + 初始状态 + 当前选择"]
    H --> H0["首次动态新增量必须为0"]
    G -- "都存在" --> I["fresh互证当前值、状态、主体、实例和UTC时间"]
    G -- "仅一边存在" --> Y["材料未闭合；停门"]
    H0 --> J["建立或恢复两份目标判断比较注册"]
    I --> J
    J --> K["建立或恢复两份 I64_MAX 目标合同"]
    K --> L["建立或恢复两份根需求、列表项和成员关系"]
    L --> M["根需求组读回证明父为空"]
    M --> N["冻结 Gfinal"]
    N --> O["全部材料按 Gfinal 正式重读"]
    O --> P{"身份、角色、值域、合同、关系、唯一性和截止闭合？"}
    P -- "否" --> Z["结构化非成功；锚点空；不创建线程"]
    P -- "是" --> Q["形成值式本能根运行锚点"]
    Q --> R["锚点进入自我线程合同v2锁定请求"]
    R --> S["创建自我线程并停在治理运行门"]
    S --> T["全部启动阶段成功后开放治理循环"]
```

## 2. 首值与初始状态单事务

```mermaid
flowchart LR
    A["G0、幂等身份、实例、M/2、UTC纳秒"] --> B["特征owner预形成：值事实 + 当前值槽"]
    A --> C["状态owner预形成：状态 + 主体/实例关系 + 当前选择"]
    B --> D{"两个参与者有效且绑定同一G0？"}
    C --> D
    D -- "否" --> X["零提交"]
    D -- "是" --> E["L1双参与者原子提交"]
    E --> F{"提交状态"}
    F -- "已提交/精确重复" --> G["按共同G1读回值、状态、选择"]
    F -- "已可能发布" --> Y["空载荷；保留原幂等身份重放"]
    F -- "其它非成功" --> X
    G --> H{"值==状态精确值 且 三者形成代次==G1？"}
    H -- "否" --> Z["内部不一致"]
    H -- "是" --> I["成功；动态为空"]
```

业务权威顺序仍是：

```text
业务确定当前值
→ 建立当前值权威
→ 记录初始状态
```

物理同代提交不改变当前值与状态记录的职责差异。

## 3. 重启恢复

```mermaid
flowchart TD
    A["程序重启"] --> B["按固定幂等身份恢复定义和目标合同"]
    B --> C["按唯一自我 + 特征定义恢复唯一实例"]
    C --> D["读取当前值与当前状态选择"]
    D --> E{"当前值和当前状态是否都存在？"}
    E -- "是" --> F["互证；不得重置为M/2"]
    E -- "否，二者都无" --> G["执行首次单事务形成"]
    E -- "仅一边有" --> X["材料未闭合，停门"]
    F --> H["按目标四元组恢复合同、需求和列表项"]
    G --> H
    H --> I["冻结新的Gfinal并完整重读"]
    I --> J["形成同一组稳定身份的新值式锚点"]
```

旧锚点截止不跨启动复用。

## 4. 二次特征

```mermaid
flowchart LR
    A["持久：安全差值或服务差值概念定义"] --> B["治理轮次按需读取当前根值"]
    B --> C["局部计算 Delta = I64_MAX - 当前值"]
    C --> D["用于本次目标比较"]
    D --> E["立即销毁局部二次特征值"]
    E --> F["零实例、零当前值槽、零状态、零动态、零恢复"]
```

## 5. 关键分支

| 分支 | 处理 |
| --- | --- |
| 首次空库 | 固定顺序形成，最终同 Gfinal 读回 |
| 完整重启 | 恢复同一身份，保留运行后当前值 |
| 目标合同已形成但需求未形成 | 按合同幂等首次事实恢复后继续 |
| 列表项已形成但需求未形成 | 精确查询列表项后加入需求 |
| 当前值和当前状态都缺失 | 首值首态单事务形成 |
| 当前值和当前状态都存在 | fresh 互证，不再次形成 |
| 当前值和当前状态仅一边存在 | 材料未闭合，停门 |
| 原子提交已可能发布 | 空载荷，原键重放或重启后正式恢复 |
| 任一截止不等 Gfinal | 当前性漂移，丢弃组合结果 |
| 角色多义或交叉 | 引用冲突/内部不一致，不任选 |
| 初始化失败 | 失败阶段21，不创建自我线程 |
