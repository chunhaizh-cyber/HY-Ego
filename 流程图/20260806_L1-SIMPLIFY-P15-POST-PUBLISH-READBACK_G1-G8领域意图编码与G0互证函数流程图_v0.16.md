
各 G 函数不接受自由操作标签；标签、域前缀、格式版本和字段顺序均由固定重载绑定。核心不得从 G0 写集覆盖调用方的领域摘要。

## 主流程

```mermaid
flowchart TD
 A["公开请求 DTO"] --> B["对应 G1-G8 固定字段编码"]
 B --> C["固定域前缀/组号/格式1/操作标签"]
 C --> D["公共大端原语与嵌套标签编码"]
 D --> E["唯一 SHA-256 得领域意图摘要"]
 E --> F["写入请求意图凭证与摘要"]
 F --> G["provider 前探测幂等"]
 G -->|同义| H["账读回/发布后读回，provider=0/0"]
 G -->|异义或错误| I["冲突/入口拒绝，无业务载荷"]
 G -->|未找到| J["按矩阵读取 provider 与写前见证"]
 J --> K["独立形成 G0 规范化写集摘要"]
 K --> L{"组号/版本/标签/幂等键互证"}
 L -->|失败| I
 L -->|成功| M["核心保留领域摘要，不得覆盖"]
 M --> N["一次 L1 v2 提交"]
 N --> O["通用发布后读回与首次证据"]
 O --> P["账/审计/恢复重算双摘要"]
 P -->|矛盾| Q["内部不一致并隔离"]
 P -->|一致| R["首次结果 DTO"]
```

## 拒绝路径和静态门禁

```mermaid
flowchart TD
 A["恢复候选"] --> B{"能按 G 组 DTO 重算?"}
 B -->|否| X["缺字段/未知标签拒绝"]
 B -->|是| C{"领域摘要与首次账一致?"}
 C -->|否| X
 C -->|是| D{"独立 G0 摘要与写集一致?"}

```
