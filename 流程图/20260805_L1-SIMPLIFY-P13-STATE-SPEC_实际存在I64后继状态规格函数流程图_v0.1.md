## 1. 组合入口

```mermaid
flowchart TD
    A[接收后继状态规格请求] --> B{合同 规则 身份 时间完整}
    B -- 否 --> X1[入口拒绝 零规格]
    B -- 是 --> C[读取L1起始完整快照G]
    C --> D[调用P10和P8读取存在宿主新当前]
    D --> E{完整成功且截止为G}
    E -- 否 --> X2[映射非成功 零规格]
    E -- 是 --> F[以主体 实例槽 新时间调用P12]
    F --> G{P12结果}
    G -- 无前状态 --> X3[返回无前状态 不调用首态入口 零规格]
    G -- 非成功 --> X4[映射非成功 零规格]
    G -- 已选择 --> H[取得P9不可变前状态和选择证据]
    H --> I[调用P11比较旧采样与新当前]
    I --> J{P11完整成功}
    J -- 否 --> X5[返回不可比较或对应错误 零规格]
    J -- 是 --> K[校准主体 场景 实例槽 定义 来源 时间 截止]
    K --> L{全部同义且后时间严格更晚}
    L -- 否 --> X6[入口拒绝或内部不一致 零规格]
    L -- 是 --> M[读取L1结束完整快照G1]
    M --> N{G与所有provider截止及G1相同}
    N -- 否且未重试 --> C
    N -- 否且已重试 --> X7[版本漂移 零规格]
    N -- 是 --> O[形成已校准纯值材料]
    O --> P[调用L1状态服务形成关系19状态规格]
    P --> Q{P11等价}
    Q -- 是 --> R[已形成 禁止生成迁移动能]
    Q -- 否 --> S[已形成 携带允许动态消费的迁移证据]
```

## 2. 状态领域规格形成入口

```mermaid
flowchart TD
    A[接收已校准后继状态材料] --> B{材料和规格版本完整}
    B -- 否 --> X1[内部不一致 零规格]
    B -- 是 --> C{整理幂等身份同义}
    C -- 同键异义 --> X2[冲突 零规格]
    C -- 同义或首次 --> D[建立状态命名空间十二个本地键]
    D --> E[形成后状态节点和见证节点]
    E --> F[形成资格 时间 引用 I64采样五值]
    F --> G[形成关系19角色1到角色5]
    G --> H[形成五个属性槽]
    H --> I{二节点 五值 五关系 五槽且键唯一}
    I -- 否 --> X3[内部不一致 零规格]
    I -- 是 --> J[按固定字段序列形成确定性摘要]
    J --> K{比较材料等价}
    K -- 是 --> L[返回完整规格 禁止生成迁移动能]
    K -- 否 --> M[返回完整规格和迁移证据 允许形成动态规格]
```

## 4. 边界

图中所有成功结果仍只是内存纯值规格。本叶不调用 L1 写入，不发布第二状态或关系20，不生成动作动态，不建立最终幂等账。状态服务不导入特征比较服务；跨领域调用只在无写权组合器中发生。
