# L2-DYNAMIC-REGISTRY-NEUTRAL-WRITE-MIGRATION 建立登记函数流程图 v0.1

日期：2026-08-08

根函数：`L1动态服务::建立登记(const L1动态登记请求&)`

边界：只画这一根函数及其直接调用的私有校验 / 读回步骤；不画 `读取当前登记`、状态迁移动能规格、其它状态动态逻辑或 L1 内部事务实现。图是目标设计，不是当前代码事实。

```mermaid
flowchart TD
    A["进入建立登记，请求为调用方值"] --> B["取得L1动态服务递归互斥锁并进入异常边界"]
    B --> C{"合同、规则、幂等身份、期望事实代次是否合法"}
    C -- "否" --> R0["返回入口拒绝，不带登记"]
    C -- "是" --> D["调用读取中性当前事实代次"]
    D --> E{"读取成功、合同正确且代次非零"}
    E -- "否" --> R1["映射读取非成功，不带登记"]
    E -- "是" --> F{"当前代次等于请求期望代次"}
    F -- "否" --> R2["返回版本漂移，不带登记"]
    F -- "是" --> G["以保留域0x0F映射不透明中性幂等键"]
    G --> H["形成固定中性写集：10节点、0关系、0值、0槽变更、0退出"]
    H --> I["恰一次调用提交中性写集"]
    I --> J{"写入状态是否成功或精确重复"}
    J -- "否" --> R3["映射幂等冲突、版本漂移、未找到、入口拒绝、资源失败或内部不一致；不带登记"]
    J -- "是" --> K{"成功类合同是否完整：版本、键、代次、发布标志、重试边界"}
    K -- "否" --> RI["返回内部不一致，不带登记"]
    K -- "是" --> L{"新编码映射是否恰含本地键1至10且编码非零、两两唯一"}
    L -- "否" --> RI
    L -- "是" --> M["按1至10固定顺序取得十个稳定编码"]
    M --> N["读回G0：读取中性当前事实代次"]
    N --> O{"G0成功、合同正确且非零"}
    O -- "否" --> R4["映射读取非成功，不带登记"]
    O -- "是" --> P["循环十编码：逐项调用读取中性当前节点"]
    P --> Q{"每项成功、查询编码一致、读取代次等于G0、节点未退出且形状匹配"}
    Q -- "读取非成功" --> R5["映射读取状态，不带登记"]
    Q -- "成功但字段或形状矛盾" --> RI
    Q -- "十项全部成立" --> S["读回G1：再次读取中性当前事实代次"]
    S --> T{"G1成功、合同正确、非零且等于G0"}
    T -- "读取非成功" --> R6["映射读取状态，不带登记"]
    T -- "G1或节点代次不等G0" --> R2
    T -- "是" --> U["按固定字段映射组装现有L1动态结构登记，事实截止代次取G0"]
    U --> V{"登记完整性校验通过"}
    V -- "否" --> RI
    V -- "是" --> W["更新非权威登记定位缓存"]
    W --> X["首次成功与精确重复统一返回已登记并携带读回登记"]
    B -. "bad_alloc" .-> RA["返回资源失败，不带登记"]
    B -. "其它异常" .-> RI
```
