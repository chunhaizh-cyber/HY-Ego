# P24 指定实际存在集合当前实例特征槽结构读取函数流程图 v0.1

日期：2026-08-05

## 1. 调用边界

```mermaid
flowchart TD
    A["调用方持有P21完整主体范围"] --> B["P17尝试读取完整快照"]
    B --> C{"P17结果"}
    C -- "许可拒绝/资源失败/内部不一致" --> R0["立即返回；P23/P24调用0"]
    C -- "成功且载荷完整" --> D["P24静态纯函数：主体范围 + P23定位请求 + 同一快照"]
    D --> E["同一快照调用P23静态定位"]
    E --> F["实例特征领域解释宿主槽与定义模板关系"]
    F --> G["返回同截止完整槽结构组"]
```

P24 不调用 P17、P21、P22、L1 服务或其它 provider，不取对象锁，不重取快照。P17 非成功由调用方在进入 P24 前分账。

## 2. `从快照读取当前实际存在实例特征槽集合`

```mermaid
flowchart TD
    A["A【输入】读取请求 + 一份P17完整快照"] --> B{"B【判断】外层/P21/P23请求版本匹配？"}
    B -- "否" --> R1["R1【返回】入口拒绝；空事实/诊断"]
    B -- "是" --> C{"C【判断】P21完整、排序、唯一且见证形状正确？"}
    C -- "非完整" --> R1
    C -- "声称完整但损坏" --> R2["R2【返回】内部不一致 + 稳定诊断"]
    C -- "是" --> D{"D【判断】主体范围为空？"}
    D -- "是" --> R3["R3【返回】已读取；同截止完整空组；P23调用0"]
    D -- "否" --> E["E【调用】P23从快照读取登记定位"]
    E --> F{"F【判断】P23结果"}
    F -- "非成功" --> R4["R4【返回】保持具名状态；内部损坏映射诊断"]
    F -- "坏成功" --> R2
    F -- "已读取" --> G{"G【判断】P21=P23=P17非零截止？"}
    G -- "否" --> R5["R5【返回】事实代次漂移；空事实/诊断"]
    G -- "是" --> H{"H【判断】快照节点/关系基础形状正确？"}
    H -- "否" --> R2
    H -- "是" --> I["I【指令】按P21主体建立固定空槽组"]
    I --> J["J【指令】召回主体源端的角色1宿主槽关系"]
    J --> K{"K【判断】槽当前普通、反向恰一宿主？"}
    K -- "否" --> R2
    K -- "是" --> L{"L【判断】每槽恰一角色2定义关系且定义端点当前普通？"}
    L -- "否" --> R2
    L -- "是" --> M{"M【判断】同主体同定义是否唯一槽？"}
    M -- "否" --> R2
    M -- "是" --> N["N【指令】主体升序；槽按定义、槽身份升序"]
    N --> R6["R6【返回】已读取；完整=true；诊断空"]
```

## 3. 零命中与非成功分账

```mermaid
flowchart LR
    A["合法空P21主体范围"] --> S1["已读取空主体组"]
    B["非空主体但某主体无宿主槽关系"] --> S2["已读取该主体空槽组"]
    C["P23登记未加载"] --> F1["登记未加载"]
    D["P23四身份确定未命中"] --> F2["未找到"]
    E["同截止见证与快照矛盾"] --> F3["内部不一致"]
    F["P21/P23/P17截止不同"] --> F4["事实代次漂移"]
```

“无槽”是合法完整事实，不得误判未找到；`未找到` 只沿 P23 对必需登记身份的确定未命中传播。

## 4. 稳定输出

```mermaid
flowchart TD
    A["P21主体组"] --> B["主体按稳定编码升序且一一保留"]
    B --> C["每主体槽按定义编码、槽编码升序"]
    C --> D["宿主关系/定义关系放入固定具名字段"]
    D --> E["截止=P17快照代次；完整=true；缺项空"]
```

本图不包含当前值、属性槽、材料、来源、定义详情、状态或动态读取。
