## 1. `L1实际存在服务::尝试读取当前登记`

```mermaid
flowchart TD
    A["A【输入】实际存在登记读取请求"] --> B{"B【判断】合同版本和规则版本是否匹配"}
    B -- "否" --> R1["R1【返回】入口拒绝，空登记；锁尝试0"]
    B -- "是" --> C["C【指令】以try_to_lock尝试一次实际存在服务锁"]
    C --> D{"D【判断】是否取得许可"}
    D -- "否" --> R2["R2【返回】许可拒绝，空登记；零等待零重试"]
    D -- "是" --> E["E【函数调用】复制已持锁当前登记"]
    E --> F{"F【判断】登记缓存是否存在"}
    F -- "否" --> R3["R3【返回】未找到，空登记；不扫描L1"]
    F -- "是" --> G{"G【判断】合同/规则/幂等身份/验证代次/两个编码完整且互异"}
    G -- "否" --> R4["R4【返回】内部不一致，空登记"]
    G -- "是" --> H["H【指令】逐字段复制不可变定位材料"]
    H --> R5["R5【返回】已读取，完整登记副本；返回前释放锁"]
    H -. "bad_alloc" .-> R6["R6【返回】资源失败，空登记"]
    H -. "其它异常" .-> R4
```

## 2. 定位材料与当前资格事实分账

```mermaid
flowchart LR
    A["P20 尝试读取当前登记"] --> B["存在服务身份/资格属性类型/登记验证代次"]
    C["P17 尝试读取完整快照"] --> D["当前节点/值/槽及当前事实截止代次"]
    B --> E["后继实际存在资格集合读取"]
    D --> E
    E --> F["按P20身份在P17副本中解释当前实际存在资格"]
    B -. "登记验证代次不得冒充当前截止" .-> D
```

本叶只形成 A—B。P20 返回并释放存在服务锁后，后继才可调用 P17；禁止跨 provider 持锁。

```mermaid
flowchart TD
```
