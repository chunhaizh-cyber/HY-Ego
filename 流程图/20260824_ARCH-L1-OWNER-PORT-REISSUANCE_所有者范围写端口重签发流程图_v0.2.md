# ARCH-L1-OWNER-PORT-REISSUANCE 所有者范围写端口重签发流程图

版本：v0.2
对应详细设计：`规范/详细设计/20260824_ARCH-L1-OWNER-PORT-REISSUANCE_所有者范围写端口重签发中性恢复提供者详细设计_v0.2.md`
图类型：单一 L1 管理函数；不表示现有代码已实现

```mermaid
flowchart TD
    A[重新签发所有者范围写端口] --> B{合同版本、owner、建立幂等身份有效?}
    B -- 否 --> X[重入结果入口拒绝；建立结果默认；无端口]
    B -- 是 --> C{运行包有效?}
    C -- 否 --> Y[重入结果许可拒绝；无端口]
    C -- 是 --> D[取得端口锁并读取 owner 当前事实、独占范围与建立账]
    D --> E{owner、建立账、范围和代次逐字段互证?}
    E -- 否 --> Z[未找到/已退出/引用冲突/幂等冲突/内部不一致；无端口]
    E -- 是 --> F{同 owner 已有活动端口?}
    F -- 是 --> Y
    F -- 否 --> G[登记唯一活动 owner并构造 move-only 端口]
    G --> H{构造和登记成功?}
    H -- 否 --> W[资源失败或内部不一致；回滚活动登记；无端口]
    H -- 是 --> I[重入结果成功；建立结果默认；回显当前代次；不推进事实代次]
```

同一 `L1所有者范围交付` 追加 `重入结果` 字段但保留既有 `建立结果`/`写入端口`；建立函数只填建立结果，重签发只填重入结果。所有非成功分支端口为空，日志不参与机器断言；不建立 owner、不发布事实、不进入 L2/L4。
