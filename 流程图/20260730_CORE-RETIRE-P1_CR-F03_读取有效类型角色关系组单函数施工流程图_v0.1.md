# CR-F03 读取有效类型角色关系组单函数施工流程图

版本：v0.1
创建侧代码基线：`57866ac5ca63235ed12da60f635d29f1aacd718b`
根函数：`正式关系仓库::读取有效类型角色关系组`
完整签名：`std::vector<正式关系记录> 正式关系仓库::读取有效类型角色关系组(关系类型 类型, std::int64_t 顺序号) const`
归属模块 / 文件：`海中鱼巣.核心.仓库.正式关系` / `海中鱼巣/核心/仓库.正式关系.ixx`；待新增公开成员。
参数与所有权：`类型`、`顺序号` 按值传入；`顺序号` 允许全部 I64 值并由具名领域复判其角色语义。
返回与所有权：返回调用方独占的关系记录副本组；空组合法。
非法值与错误：未知关系类型返回空组、零写入；`顺序号` 不设哨兵值；`std::bad_alloc/std::length_error` 原样传播；后置不变量破坏抛 `std::logic_error`。事务外由 CR-F56 映射为结构化内部不一致，事务内由写执行器撤销收口。
结果语义：普通视图中类型、顺序号相等且已发布有效、两端点仍有效的记录，按 `关系编号` 严格升序。
