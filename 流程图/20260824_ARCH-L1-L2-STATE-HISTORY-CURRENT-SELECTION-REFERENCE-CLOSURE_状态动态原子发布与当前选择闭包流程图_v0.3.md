# ARCH-L1-L2-STATE-HISTORY-CURRENT-SELECTION-REFERENCE-CLOSURE

## 状态动态原子发布与当前选择引用闭包流程图 v0.3

> 设计基线：`main@4a05152a01676341e8ff9bb9b706dc8621c1f79e`
> 单一施工流程图；不表达任务、方法、需求或 L4 工作包持久化。

```mermaid
flowchart TD
    A[保留 v1 十项登记<br/>0x20 / 原十项本地键] --> B[独立 v2 当前选择登记<br/>域 0x23 / 关系类型 0x02040103<br/>写集局部键 0x02041103]
    B --> C{登记请求版本、幂等域、端点角色、局部键均合法?}
    C -- 否 --> C0[入口拒绝<br/>公共入口拒绝 + 操作入口拒绝<br/>零载荷/零写]
    C -- 是 --> D[现有新增状态唯一首态入口<br/>固定字段顺序 + 当前选择局部键 + 幂等材料]
    D --> E{已有选择或旧状态事实?}
    E -- 同义完整相等 --> E1[精确重复<br/>公共精确重复 + 操作精确重复<br/>返回状态/自有关系/当前选择]
    E -- 异义当前 --> E2[已有异义当前<br/>公共引用冲突 + 操作已有异义当前<br/>零载荷/零写]
    E -- 旧事实无选择 --> E3[待迁移<br/>公共入口拒绝 + 操作待迁移<br/>不得映射 task owner v1 待迁移]
    E -- 无旧事实 --> F[状态 owner 同一 G1<br/>永久状态事实 + 当前选择关系]
    F --> G{交换前 G0、宿主/主体、闭包、代次均通过?}
    G -- 否 --> G0[公共对应失败 + 同名操作失败<br/>零载荷/零写/不写幂等账]
    G -- 是 --> H[生产顺序：状态 owner 后动态 owner<br/>动态前态→旧状态；后态→新状态]
    H --> I[统一代次/解析局部引用/全局闭包检查]
    I --> J{闭包与幂等账可提交?}
    J -- 否 --> J0[引用冲突或内部不一致<br/>交换前零写]
    J -- 是 --> K[写幂等账并交换正式仓库]
    K --> L[公开独立读回：状态事实、当前选择、动态前后、宿主/主体]
    L --> M{同一截止且唯一当前选择互证?}
    M -- 是 --> N[首态/迁移成功<br/>公共已提交 + 操作已提交]
    M -- 否：交换后缺项 --> N1[已可能发布<br/>公共内部不一致 + 操作已可能发布<br/>不回滚/不宣称零写]
    M -- 否：未知读回 --> N2[发布未知<br/>公共内部不一致 + 操作发布未知<br/>同键重放并正式读回]
    P[动态→状态逆序矩阵] --> Q[仅 D:\TEMP 专项 helper/接缝<br/>不进生产 DTO/工程/运行包]
    Q --> I
    R[具名当前选择读取<br/>最多一条选择关系] --> S{当前选择结果}
    S -- 已读取 --> T[唯一当前性权威]
    S -- 待迁移 --> U[底座迁移事项<br/>不使用 L4 业务枚举 15]
    S -- 其它失败 --> V[按专用操作状态分账<br/>不猜测、不重试业务、不建第二工作包]
    W[按特征实例读取全部当前状态] --> X[兼容包装/辅助视图<br/>不得裁决当前性]
    T --> Y[P1/A1 仅保存状态身份<br/>恢复时当前选择读取+状态身份互证]
    X --> Y
```

图中只有一个 Mermaid、一个 `flowchart TD`。交换前失败和交换后读回失败严格分账；L4 的 `初次请求版本待迁移=15` 只属于 task owner 历史 v1 八槽请求，不承载本底座当前选择缺失。

`TASK-ROUND-INITIAL-STATE-ARCH-L2-MIGRATION v0.3` 保持待激活；底座发布不会自动解除其 ABI/工作包证据门禁，后续须由 L4 同身份 v0.4 接管。
