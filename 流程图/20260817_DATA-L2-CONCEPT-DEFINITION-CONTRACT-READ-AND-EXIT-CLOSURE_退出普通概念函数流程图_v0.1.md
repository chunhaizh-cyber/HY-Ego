# 退出普通概念函数流程图

日期：2026-08-17

版本：v0.1

身份：`DATA-L2-CONCEPT-DEFINITION-CONTRACT-READ-AND-EXIT-CLOSURE`

目标函数：`L2概念结构服务::退出普通概念(const L2普通概念退出请求&)`

```mermaid
flowchart TD
    A["接收退出普通概念请求"] --> B{"请求、预算、幂等身份有效？"}
    B -- "否" --> R1["入口拒绝；空载荷；零变化"]
    B -- "是" --> C["读取本 owner 首次写入材料"]
    C --> D{"已有同幂等结果？"}
    D -- "同请求" --> E["从首次截止重建退出概念、退出边、替代边"]
    D -- "异请求" --> R2["幂等冲突；空载荷；零变化"]
    D -- "无首次结果" --> F["在 G0 完整读取普通概念与退役生命周期"]
    F --> G{"普通概念、非根、退役见证精确成立？"}
    G -- "否" --> R3["按未找到、已退出、入口拒绝或引用冲突返回"]
    G -- "是" --> H["同 G0 读取直接上下位、支持、反向定义与外部引用保护"]
    H --> I{"存在支持、定义、名称或外部当前引用？"}
    I -- "是" --> R4["引用冲突；空载荷；零变化"]
    I -- "否" --> J["移除目标和值式重建同根 DAG"]
    J --> K{"图完整、无环、剩余概念唯一根可达？"}
    K -- "否" --> R5["内部不一致或数量预算不足；零变化"]
    K -- "是" --> L["确定排序父×子组合并计算必要替代直接边"]
    L --> M["形成退出全部自有事实、退出关联边、建立替代边的单 owner 写集"]
    M --> N["以原幂等身份提交 L1 原子写集"]
    N --> O{"提交状态"}
    O -- "已提交或精确重复" --> E
    O -- "漂移、引用、许可或资源失败" --> R6["保持原分类；空载荷；零变化"]
    O -- "坏形状" --> R7["内部不一致；空载荷"]
    E --> P{"首次截止完整读回且生命周期同截止？"}
    P -- "否" --> R7
    P -- "是" --> Q["返回成功：已退出概念 + 已退出边 + 替代边"]
```

边界：本函数不退出名称、世界事实、支持或其它概念定义，不级联跨 owner 事实，不原地改写定义签名，不把日志当机器事实。
