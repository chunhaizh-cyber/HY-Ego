flowchart TD

    R4 -- 是 --> S0["已发布等价后状态或幂等读回"]
    R7 -- 是 --> S1["已发布后状态与迁移动能或幂等读回"]
    R4 -- 否 --> X["锁外内部不一致：保留事实与证据；不二次写、不补偿"]
    R7 -- 否 --> X

## 4. P15 v0.2 双摘要精确重复

```mermaid
flowchart TD
    A["公开请求"] --> B["形成32字节请求意图摘要"]
    B --> C["provider前探测幂等"]
    C --> D{"探测结果"}
    D -- 异义 --> E["冲突；provider零调用"]
    D -- 同义 --> F["读取首次执行证据、映射、完整读回、结果摘要和发布代次"]
    D -- 未找到 --> G["首次形成P13/P14与32字节执行证据"]

```

不得因后来 provider、登记、当前值、执行证据或写集变化改判同义；不得扫描稳定编码猜测首次映射。P13无前态不提交幂等记录，后续仍未找到时可以重新评估。
