# INSTINCT-STAGE3-SERVICE-CONTRACT-FACT-OWNER 服务合同事实完整集合业务流程图 v0.1

日期：2026-08-29

## 1. 业务目标

把“当前有哪些有效未满足服务合同、有哪些正式到期未满足事件”收口为唯一 owner 在同一事实截止下可证明完整的强类型集合，不再用四次相同的“按自我读取全部当前状态”猜测业务分类。

## 2. 流程

```mermaid
flowchart TD
    A["普通应用构造服务合同事实 owner"] --> B["幂等建立结构登记、合同索引根和到期事件索引根"]
    B --> C["不自动建立任何合同或到期事件"]
    C --> D["治理调用方冻结 G0"]
    D --> E["读取当前有效合同关系类型完整闭包"]
    E --> F{"owner、登记、闭包和 G0 是否完整"}
    F -- "否" --> X["结构化非成功：空载荷、截止 0"]
    F -- "是" --> G["逐合同重建外部引用、不可变合同事实和唯一当前状态"]
    G --> H{"是否全部为有效未满足且规范有序"}
    H -- "否" --> X
    H -- "是" --> I["形成合同完整集合见证；0 项也必须保留见证"]
    I --> J["读取到期事件关系类型完整闭包"]
    J --> K{"事件 owner、登记、载荷和引用是否完整"}
    K -- "否" --> X
    K -- "是" --> L["形成到期事件完整集合见证；0 项也必须保留见证"]
    L --> M["读后当前事实代次仍等于 G0"]
    M --> N{"是否仍为 G0"}
    N -- "否" --> X
    N -- "是" --> O["返回两类强类型完整集合，供阶段三后继组合"]
```

## 3. 发布边界

```mermaid
flowchart LR
    P["未来有效人类服务需求准入"] --> Q["形成合同 owner 参与写集"]
    Q --> R["形成服务值当前值、状态、动态参与写集"]
    R --> S["L1 有限 N 分区原子事务"]
    S --> T["同一 G1 最后发布合同和 30% 预支"]

    U["本切片"] --> V["只实现 owner 登记与完整读回"]
    V --> W["不公开独立合同写入口"]
```

## 4. 完成边界

该流程图只冻结结构 owner 和完整集合读回。合同准入、预支、终态、有效活动、衰减、回归和生产线程消费仍由后继流程图与计划承接。
