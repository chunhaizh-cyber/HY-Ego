## 1. 调用边界

```mermaid
flowchart TD
    C["后继治理/业务消费者"] --> F["世界树业务服务三读门面"]
    F --> E["查询存在完整事实"]
    F --> S["查询场景完整事实"]
    F --> W["读取完整世界事实快照"]
    E -->|"原请求/恰1次"| P30["快照读取服务::读取存在完整事实"]
    S -->|"原请求/恰1次"| P31["快照读取服务::读取场景完整事实"]
    W -->|"原请求/恰1次"| P29["快照读取服务::读取完整世界事实快照"]
    P30 -->|"原结果"| E
    P31 -->|"原结果"| S
    P29 -->|"原结果"| W

    F -. "禁止" .-> X1["其它门面根/provider/第二读取链"]
    F -. "禁止" .-> X2["L1/锁/仓库/SQL/缓存/材料/历史"]
    F -. "禁止" .-> X3["校验/映射/重试/写事实"]
```

门面只改变公开服务身份和依赖方向，不改变任何请求、结果或机器事实语义。

## 2. 三根同构流程

```mermaid
flowchart TD
    A["进入一个门面读根"] --> B["const借用原强类型请求"]
    B --> C["调用唯一对应快照读取根恰1次"]
    C --> D["取得调用方拥有的完整值式结果"]
    D --> E["逐字段原样返回"]

    A -. "调用0" .-> N1["其它两个快照读取根"]
    A -. "指令0" .-> N2["准入复核/状态映射/缺项加工"]
    A -. "循环0" .-> N3["retry/sleep/fallback"]
    A -. "状态0" .-> N4["缓存/保存请求或结果"]
```

## 4. 结果透明边界

```mermaid
flowchart LR
    P["provider结果"] --> A["已读取/合法空组"]
    P --> B["未找到/入口拒绝/漂移/许可拒绝"]
    P --> C["资源失败/内部不一致/未实现"]
    A --> R["门面逐字段原样返回"]
    B --> R
    C --> R

    R -. "禁止" .-> M["改判/补默认/重排/二次读取"]
```

P29 的最多两轮、P30/P31 的对象投影和全部缺项诊断继续由快照读取服务唯一拥有；门面不复制这些流程。
