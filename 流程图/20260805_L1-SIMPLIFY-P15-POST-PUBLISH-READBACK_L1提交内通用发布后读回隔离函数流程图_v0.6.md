## 流程图

```mermaid
flowchart TD
    N01["N01【指令】校验L1 v2合同、请求意图摘要、幂等键和发布后计划"] --> N02{"N02【指令-判断】合同完整?"}
    N02 -- 否 --> X1["X01【指令-返回】入口拒绝 零业务变化"]
    N02 -- 是 --> N03["N03【指令】取得唯一独占锁"]
    N03 --> N04{"N04【指令-判断】幂等账已有记录?"}
    N04 -- 是且摘要相同未隔离 --> S1["S01【指令-返回】首次结果读回 不访问provider"]
    N04 -- 是且摘要不同 --> X2["X02【指令-返回】幂等冲突 零变化"]
    N04 -- 是且已隔离 --> X3["X03【指令-返回】隔离拒绝 失败见证"]
    N04 -- 否 --> N05{"N05【指令-判断】当前状态已隔离?"}
    N05 -- 是 --> X3
    N05 -- 否 --> N06["N06【指令】形成请求意图/执行证据双摘要并探测幂等"]

    N07 -- 是 --> N09["N09【指令】读取provider并形成候选"]
    N09 --> N10["N10【指令】提交写集并推进一次事实代次"]
    N10 --> N11["N11【指令】同锁执行发布后权威读回"]

    N12 -- 是 --> S2["S02【指令-返回】首次结果/完整读回/摘要"]
    N12 -- 否或异常 --> X4["X04【指令-返回】失败见证、审计并进入隔离"]
```
