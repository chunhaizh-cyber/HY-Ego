## 函数流程

```mermaid
flowchart TD
    A[接收合同 规则 查询身份 主体 实例槽和拟发布时间] --> B{入口字段完整?}
    B -- 否 --> X1[入口拒绝 空载荷]
    B -- 是 --> C[读取起始L1完整快照G0]
    C --> D{主体和实例槽当前可解析?}
    D -- 否 --> X2[未找到 空载荷]
    D -- 是 --> E[按关系19源分组并校验角色1至5]
    E --> F{查询范围结构完整且唯一?}
    F -- 同时间多状态 --> X3[冲突 空载荷]
    F -- 残缺重复或矛盾 --> X4[内部不一致 空载荷]
    F -- 是 --> G[筛选同主体 同实例槽且时间严格更早]
    G --> H{候选为空?}
    H -- 是 --> I[读取结束快照G1]
    H -- 否 --> J[按发生时间取唯一最大项]
    J --> K[由G0构造P9具名读取请求]
    K --> L[调用P9公开读取入口]
    L --> M{P9完整且身份 时间 截止一致?}
    M -- 否 --> X5[映射非成功或内部不一致]
    M -- 是 --> N[读取结束快照G1]
    I --> O{G0等于G1?}
    N --> P{G0等于P9截止等于G1?}
    O -- 否且未重试 --> C
    P -- 否且未重试 --> C
    O -- 否且已重试 --> X6[版本漂移 空载荷]
    P -- 否且已重试 --> X6
    O -- 是 --> Z1[无前状态 完整零前态证据]
    P -- 是 --> Z2[已选择 完整P9前状态和选择证据]
```
