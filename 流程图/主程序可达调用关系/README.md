# `main` 当前可达调用关系

本目录独立记录从正式入口 `int main(int 参数数量, char* 参数组[])` 出发、在当前正式工程配置和真实接线下可达的项目自定义函数与调用关系。

## 统计口径

- 唯一根：`海中鱼巣/入口.cpp:8` 的 `main`。
- 项目函数：只收录当前配置下能沿项目调用边从根递归到达的项目自定义函数。
- 外部边界：标准库、Windows、SQL/ODBC、RealSense、编译器隐式函数等单独登记，不生成项目函数身份。
- 未解析调用：函数指针、虚调用、回调或其它无法唯一确定目标的调用单独登记，不猜测唯一被调方。
- 排除：条件编译关闭、装配为空、仅定义未调用、旧不可达路径和不可满足分支必须具名记录。

本目录不改写 `流程图/代码流程图/` 中以单函数制图进度为目的的既有统计。两套材料的职责不同：

- `流程图/代码流程图/`：单函数流程图、逐行映射及其制图进度。
- 本目录：`main` 当前可达函数身份和调用关系的独立核对表。

## 形成方法

本批以已发布调用图为可复用基座，并使用 fresh codebase-memory MCP、MSVC `Debug|x64` 模块依赖扫描、Clang AST/libclang 候选和逐调用点源码复核交叉收口。模块候选观测提交为 `4c89f990`，该提交至本表代码基线的 `海中鱼巣/**` 源码差异为零；普通 `.cpp` 候选已在当前基线重新扫描。工具输出只用于发现候选；以下情况均由源码和当前装配最终裁决：

- 同名与重载目标；
- 条件编译和当前参数模式；
- 函数指针、回调、局部 lambda 和递归回边；
- 结构事务接线的唯一目标或未解析状态；
- 项目函数与标准库、Windows、SQL/ODBC、RealSense 等外部边界。

当前完整自检入口只登记入口初始化 14 项及 `F27/F29`，未登记的特征体系分层自检及其批次写入链不进入可达闭包。显式 `= default` 且没有用户函数体的特殊成员也不建立独立项目函数身份；只有源码显式调用的生命周期边界才单独登记。

`rs_context.h`、标准库、Windows、ODBC、RealSense 等外部定义不进入项目函数表，只在外部边界表中登记显式调用。当前未提交的 F0356—F0361 单函数流程图及其聚合 WIP 原样保留在原目录，不属于本目录完成数，也不作为本目录的正式可达证据。

## 验证边界

发布前机械检查必须证明：

- `F0001` 的 BFS 闭包与函数身份表完全相等；
- 函数 ID、完整限定签名和重载身份均唯一；同一模板体的不同实例允许共享定义行，但“定义位置 + 完整重载身份”必须唯一；
- 每条项目边端点存在，调用方/被调方正反投影闭合；
- 回调、递归、未解析调用、外部边界和配置排除分账；
- JSON 可解析，Markdown 与 JSON 数量一致；
- `git diff --check`、未跟踪文件差异检查和 `tools/check_specs.py --strict` 通过。

本目录不生成新的单函数流程图，不恢复旧制图完成数，也不形成代码修订计划。
