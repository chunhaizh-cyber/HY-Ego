## 增量维护

代码、调用图、流程图、正式规范或验证证据发布新基线后，按受影响子图刷新稳定条目、候选分类、去重和覆盖统计。流程图缺失不阻断索引；代码或合同证据不足必须显式保留缺口，不得补造默认值。

## 完成边界

本目录只证明冻结基线下的能力证据分类已经形成：

- 不定义新的机器逻辑；
- 不授权代码实施；
- 不修改计划或计划索引；
- 不证明任一候选适合新业务；
- 不证明构建、运行、生产闭环、自我循环、苏醒或成熟完成。
