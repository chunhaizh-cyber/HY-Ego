## 统一执行顺序

```mermaid
flowchart TD
 A["真实公开请求 DTO"] --> B["HZY-L1G4 + 格式1 + L1标签 + 变体编码"]
 B --> C["领域 G4 摘要"]
 C --> D["provider 前探测幂等"]
 D -->|同义| E["首次账/首次结果 DTO 读回，0/0"]
 D -->|异义、缺字段、错误变体| X["拒绝/隔离，无业务载荷"]
 D -->|未找到| P["读取 provider/场景/定义/事实"]
 P --> Q["独立 G0 规范化写集摘要"]
 Q --> I{"标签+变体+版本+领域摘要+G0 互证"}
 I -->|失败| X
 I -->|成功| J["保留调用方摘要"]
 J --> K["一次 L1 v2 提交"]
 K --> L["真实首次结果 DTO"]
 L --> M["发布后读回/恢复按同一点重算"]
 M --> N["施工记录与验证记录留证"]
```

0x15000401 的 F02/F03、0x15000403 的 F03-T1/F03-T2 共享底层标签但不共享领域操作身份；变体是摘要字段，不是新增 L1 标签。F02 首次结果绝不映射为 `实例特征登记结果`。
