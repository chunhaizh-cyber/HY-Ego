```text

未实现：当前没有满足目标身份和语义的函数
实现漂移：当前存在相邻入口，但行为顺序、事实来源、职责或错误语义违反目标合同
证据待刷新：源码已进入正式main，但代码图谱或能力目录尚未刷新到该代码基线
```

## 9. 使用方法

每完成一条目标业务链，按以下顺序追加：

```text
目标函数完整签名
-> 查询能力目录取得候选
-> 回读当前正式源码和代码流程图
-> 比较输入、输出、事实来源、线程、事务、非成功和版本
-> 裁决一致 / 部分实现 / 未实现 / 实现漂移 / 证据待刷新
-> 只对仍隐藏非平凡过程的目标函数继续分解
```

本表不是代码实施许可。代码修订后由代码流程图维护智能体刷新当前事实图谱，再由设计或验收侧复核对应状态；不得直接把“未实现”改成“一致”。
