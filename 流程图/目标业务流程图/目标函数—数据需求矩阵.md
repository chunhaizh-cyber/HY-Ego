# 目标函数—数据需求矩阵

更新时间：2026-08-16

## 1. 身份与用途

本矩阵逐项覆盖当前有效目标单函数图，从各图已经登记的根函数、完整签名和节点合同“事实读写”列提取数据需求。它用于自上而下验证L1通用服务是否充分，并为后续详细设计提供核对入口；不替代正式规范、目标函数图、详细设计、计划或代码实现证明。

`BIZ-L1/L2/L3/L4`表示目标图分解深度，不等于0050定义的语义责任L1—L5。矩阵中的L1只指4015通用事实基座。

## 1.1 2026-08-13 正式增量口径

本节优先于下文按旧 L1 有限访问模式生成的全量表。旧表只保留 2026-08-04 目标图的历史提取结果；其中 `A01—A12`、旧节点直接入口、旧事实截止向量或“事实所有者内部可消费 L1”等裁决，不得直接用于 2026-08-13 之后的新施工。

## 3. L1有限访问模式

| 模式 | 通用数据需求 | 当前裁决 |
| --- | --- | --- |
| A00 | 不消费L1；纯值算法、线程、消息、平台或支持旁路 | 无需L1新服务 |

| A05 | 读取当前事实代次并执行首末代次一致性复核 | 需要补充或明确由现有服务组合承接 |
| A06 | 提交完整不可变L1写集；携带期望事实代次和幂等键 | 现有 |
| A07 | 按原幂等身份和发布代次完成发布后权威读回/未知收敛 | 需要补充或明确由现有服务组合承接 |
| A08 | 读取单项历史事实 | 现有 |
| A09 | 按写集幂等键读取审计记录 | 现有 |
| A10 | 读取完整快照或形成/验证隔离恢复材料 | 现有 |
| A11 | 调用具名领域服务取得领域投影；本函数不得直连L1 | 服务边界；不是L1函数 |

A11不是新的L1函数。它明确组合器、线程、投影和普通调用方只能消费具名领域服务，不得把上层组合需求误算成L1万能查询。

## 6. 使用门禁

1. `需按4015重基线`的行必须先删除旧节点直接、旧参与者组、对象版本或事实截止向量口径，再进入详细设计。
2. `存在未决`只由目标图中的明确设计治理标记产生；许可待裁决、事实待核验、执行未冻结等合法业务状态不属于设计未决。未决行只登记缺口，不得据此新增L1业务语义或默认算法。
3. A03/A04/A05用于反推有限批量读取、关系枚举和事实代次读取合同；不得实现成任意查询语言。
4. A06只允许事实所有者把完整业务意图中性化为节点、关系、值和属性槽写集后使用；组合器、线程和投影不得直连。
5. 每个实施叶进入计划前，详细设计仍须逐字段冻结DTO、基数上限、稳定排序、分页/有界条件、幂等、并发、非成功和发布后读回。
6. “领域关键词范围”和“访问性质初判”是从目标图节点合同提取的检索辅助项；机器语义仍以来源目标图和正式规范为准。

## 7. 更新方法

新增、替换或删除目标单函数图后，运行：

```powershell
python .\tools\generate_target_function_data_matrix.py
```

生成器只读取目标单函数Markdown并重建本矩阵，不修改目标函数图。人工裁决应先回写目标函数图的节点合同，再重新生成，禁止只手工修改生成结果隐藏来源缺口。
