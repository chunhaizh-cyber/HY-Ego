# 目标线程归属与跨线程材料

更新时间：2026-08-26

## 1. 身份

本文件是目标函数图的线程归属与材料路由映射，不是线程数量配置、代码实现证明或机器逻辑规范。

## 2. 核心线程与数量

| 线程角色 | 数量口径 | 目标职责 | 禁止拥有的事实 |
| --- | --- | --- | --- |
| 程序主线程 | 1 | 模式路由、装配、启动、等待停止、分阶段收口 | 所有业务领域事实 |
| 自我线程 | 每个自我运行实例 1 | 为什么做、做哪个、优先做什么；触发维护与结算 | 任务状态、方法选择、世界事实、队列状态 |
| 任务管理线程 | 每个任务管理域至少 1 | 任务状态合同、下一工作阶段裁决、许可协调、筹办 / 执行工作包派发、回执提交 | 需求、世界、因果、价值、安全 / 服务值 |
| 任务工作线程 | 可配置线程池 | 每次按强类型种类推进一个筹办或执行工作包并发布回执 | 工作种类裁决、需求满足、价值结算 |
| 控制面板线程 | 普通控制面板模式 1 | UI 消息循环、只读投影、程序控制消息 | 可写仓库与业务裁决 |
| 外设线程 | 按外设或采集管线形成线程组 | 采集、时间对齐、形成并发布外设材料 | 世界事实、需求、任务和因果结论 |

事件日志、缓存统计、持久证据 / SQL 审计写入属于支持线程或工作池。它们可以独立运行以隔离阻塞，但不得成为业务主链的前置成功条件或事实所有者。

## 3. 四类连接

| 类型 | 定义 | 允许示例 | 禁止解释 |
| --- | --- | --- | --- |
| 直接函数调用 | 同一线程在队列锁外同步调用领域能力并取得值式结果 | 自我线程调用安全维护；工作线程按工作包调用筹办或执行 | 不等于跨线程调用 |
| 异步消息后继 | 发送方发布不可变材料并结束当前阶段，接收线程以后消费 | 具体需求任务承接意图、self后继决议定位、工作包、工作回执、外设材料 | 不得用虚线后继伪装同步返回 |
| 只读投影 | 从权威事实形成值式显示 / 查询材料 | 控制面板、线程生命周期投影 | 不得反写事实或证明业务成功 |
| 支持线程旁路 | 日志、缓存、SQL、独立材料等工程旁路 | 最佳努力审计、事件日志 | 失败不得覆盖已成立业务结果 |

## 4. 核心消息路由

```text
自我线程 --一个具体需求任务承接意图或一个self后继决议定位--> 任务管理线程
任务管理线程 --不可变筹办/执行工作包--> 任务工作线程池
任务工作线程 --同种类不可变工作回执--> 任务管理线程
任务管理线程 --独立回读引用/任务治理结果--> 自我线程
外设线程 --不可变外设材料--> 6340 正式承接路径 --> 任务管理或领域消费者
全部线程 --生命周期消息--> 控制面板只读投影
全部已发布业务批次 --旁路材料--> 日志/缓存/持久证据支持线程
控制面板线程 --程序停止控制消息--> 程序主线程
```

世界事实服务、需求服务、任务服务、方法服务、安全 / 服务维护和因果服务是被各线程在锁外调用的领域能力，不拥有隐含线程。

## 5. 跨线程材料最小合同

每条业务材料至少冻结：

```text
消息稳定身份
+ 运行代次
+ 业务对象稳定身份
+ 业务轮次 / 尝试
+ 材料类型和版本
+ 来源事实截止向量，或按材料范围裁出的具名所有者子向量
+ 幂等键
+ 值式载荷或稳定材料引用
```

禁止传递调用方栈引用、容器元素引用、可变服务内部指针、仓库写令牌、事务对象和锁所有权。

```text
发送方锁外冻结材料
-> 短时持锁入队
-> 接收方短时持锁取出并移动 / 复制
-> 释放队列锁
-> 调用领域服务或方法动作入口
-> 冻结新的结果材料
-> 短时持锁上行
```

## 6. 任务链线程归属

| 函数 | 所在线程 | 后继 |
| --- | --- | --- |
| 裁决生存控制并选择当前具体需求D | 自我线程 | 形成一份只绑定D的任务承接意图；不携带调度资格或许可 |
| 建立或复用需求任务树 | 任务管理线程 | 读取状态并裁决下一工作阶段 |
| 裁决任务下一工作阶段 | 任务管理线程 | 构造筹办 / 执行工作包或形成等待 / 收口 |
| 派发一个不可变任务工作包 | 任务管理线程 | 异步筹办 / 执行工作包 |
| 消费并推进一个不可变任务工作包 | 任务工作线程 | 按强类型种类调用筹办或执行链 |
| 筹办并冻结方法候选 | 任务工作线程 | 筹办工作回执 |
| 上报一条任务工作结果 | 任务管理线程 | 独立回读 |
| 独立回读任务实际结果 | 任务管理线程 | 任务状态提交与自我治理消息 |
| 按需求实际使用时fresh独立核算 | 自我线程或其它合法需求使用入口触发；读取本需求目标与同G0当前事实，来源任务结果/调用只作可选线索 | 已满足则零动作形成本需求结论；未满足则继续自身任务/方法；可选服务输入进入后续服务生存维护 |

## 7. 启动与停止阶段

启动同时服从8120 v0.10固定初始化顺序和“先消费者、后生产者”。阶段20叶先创建唯一自我线程并用内部进入/停门见证证明其停在关闭的治理运行门；它尚不得消费治理批次。其余运行线程就绪后才开放该门：

```text
初始化普通系统并让自我线程停在治理运行门
->
支持线程
-> 任务工作线程池
-> 任务管理线程
-> 外设线程组
-> 开放自我线程治理循环
-> 控制面板线程
```

停止不能简单反向 `join`，必须保护在途结果：

```text
锁存停止并禁止控制面板/外设新输入
-> 自我线程停止产生新任务意图
-> 任务管理线程停止新派发
-> 外设线程与任务工作线程完成或合法收口在途材料
-> 任务管理线程排空回执并停止
-> 自我线程排空最终治理消息与已允许结算并停止
-> 控制面板停止
-> 支持线程刷新后停止
-> 程序主线程完成 join 和结果映射
```

精确超时、取消、强制故障和剩余材料恢复合同仍须由详细设计冻结；本文件不授权丢弃在途工作或用线程退出代替任务结果。

## 8. 当前实现差异

- 当前代码存在任务管理、任务工作、运行宿主、外设采样材料、事件日志和缓存统计等线程壳及部分消息桥；当前没有正式自我线程模块、独立治理运行门或内部停门见证，不能用相邻线程壳补位。
- 当前执行请求路由只覆盖执行类相邻路径；目标线程池还需增加筹办类强类型工作包、通用工作回执和同任务筹办 / 执行互斥。
- 当前普通控制面板宿主仍可在程序主线程同步运行窗口；目标控制面板独立线程尚不能据此宣称已实现。
- 现有线程壳、队列和回执入口只证明相邻能力，不能证明本文件的完整启动顺序、阶段停止和业务闭环已经接通。
- 需求—任务—方法链的跨线程职责已经由 BIZ-L1-T02—T04 和 BIZ-L2-004-01—08 分别冻结，不存在额外的跨线程总根函数。
