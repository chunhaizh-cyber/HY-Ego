# L2 目标函数流程图

更新时间：2026-08-03

## 规则

L2 是 L1 线程所有者函数在队列锁外调用的领域能力、消息桥或只读投影。每份图仍只冻结一个根函数；异步消费者不是发送函数的同步子调用。

```text
唯一线程所有者调用点
+ 独立明确能力
+ 完整签名和物理位置
+ 输入、结果、事实读写和事务边界
+ 调用类型：直接 / 异步 / 只读 / 支持旁路
```
