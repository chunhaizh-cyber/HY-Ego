# L2 目标函数流程图

更新时间：2026-08-26

## 规则

`BIZ-L2` 只表示目标业务函数的第二层分解深度，不是 0050 / 4190 的数据服务 L2。数据服务 L1—L5 全部只拥有结构 CRUD；本目录中的业务函数、消息桥和只读投影均位于该数据分层之外，且只能经具名公开数据服务交互。每份图仍只冻结一个根函数；异步消费者不是发送函数的同步子调用。

```text
唯一线程所有者调用点
+ 独立明确能力
+ 完整签名和物理位置
+ 输入、结果、事实读写和事务边界
+ 调用类型：直接 / 异步 / 只读 / 支持旁路
```
