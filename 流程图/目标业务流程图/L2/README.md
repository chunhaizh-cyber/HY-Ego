# L2 目标函数流程图

## 规则

本目录每份 `BIZ-L2-*` 图只冻结一个 L2 根函数。L2 不是“更详细的业务描述”，而是父 L1 函数真实调用的目标函数合同。

L2 图只有在同时满足下列条件时才成立：

```text
有唯一父函数调用点
+ 独立承担明确业务能力
+ 完整签名和物理位置已冻结
+ 输入、结果、事实读写和事务边界可说明
+ 内部节点能区分下一层函数调用与本函数内指令
```

若一个节点只是一条判断、计算、构造或返回，不为层级整齐单独建立包装函数。若一个被调函数具有独立事实所有权、复杂事务、复用价值或非平凡错误合同，则继续建立 L3 图。
