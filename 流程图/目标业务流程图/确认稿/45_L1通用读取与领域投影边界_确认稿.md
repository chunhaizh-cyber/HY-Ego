# 第 45 项：L1 通用读取与领域投影边界

状态：已确认设计输入；非正式规范。

目标业务函数读取事实时固定采用以下边界：

```text
目标业务函数
-> 调用唯一事实所有者的领域服务或正式组合服务
-> 领域服务使用 L1 精确读取、同代次批量读取、节点属性组读取或有界关系组读取
-> 领域服务解释节点、关系和值并形成强类型领域投影
-> 多次 L1 调用执行首末事实代次复核
-> 返回同代次完整领域结果或具名非成功
```

普通目标业务函数不得读取完整 L1 快照后自行扫描，也不得把索引、缓存、SQL、材料或控制面板投影作为当前事实。L1 关系组查询只接受端点、方向、关系类型及可选角色或顺序；需求有效、任务状态、自我资格等业务条件由相应领域服务解释。

单次读取超过冻结容量限制时必须整体返回 `结果超限`，不能截断为部分成功。当前目标不引入跨事实代次分页游标。关系组按关系稳定编码排序，属性组按属性类型节点稳定编码排序。

后续校准目标函数图时，凡是出现“读取完整 L1 快照后业务扫描”、逐项读取但未复核事实代次、直接查询 L1 业务谓词或把缓存命中当事实的节点，均登记为设计漂移并改为上述领域读取链。本确认稿不证明正式目标图、详细设计、计划或代码已经完成修订。
