# 第 42 项：控制面板与支持旁路的主图连接纠正

状态：已确认设计输入；非正式规范。

当前 `BIZ-MAIN-001` 将 S01、S02 分别画成 A03“自我治理”与 A14“方法动作”的专属后继，容易把显示刷新误解为治理快照副本，也会错误缩窄支持旁路的合法消费范围。后续目标业务图必须改为面向全部合规领域发布点的独立旁路。

固定控制面板路径为：

```text
任一合规领域发布已完成业务批次、动态或运行事件
-> 产生仅用于唤醒显示读取的刷新提示
-> T05 按当前显示范围调用对应领域的正式只读投影
-> 显示只读投影
```

T05 不接收 A03 的治理快照副本，不持有第二份业务事实。刷新提示只负责唤醒读取，不携带、合成或反写世界、自我、需求、任务、安全、服务或线程事实。读取或显示失败不改变任何业务事实。

固定支持旁路路径为：

```text
任一合规领域已发布的业务批次、动态或运行事件
-> 支持旁路按合同读取已发布材料或稳定引用
-> 事件日志、运行日志、缓存统计、普通 SQL 审计或持久证据消费
```

支持旁路不只消费 A14 方法动作；它不得反写主链，不得裁决任务、需求或动态结果。普通发布后旁路失败不撤销已发布业务结果。

若某项正式合同要求写前持久证据，该证据是对应业务事务内部的发布前门禁；不得混入 S02 的普通发布后旁路，也不得由控制面板或支持旁路替代该门禁。

后续修订 `BIZ-MAIN-001` 时，S01、S02 必须改画为面向各正式领域发布点的独立投影 / 支持旁路，不再画成 A03 / A14 的专属后继。本确认稿不证明目标图、详细设计、计划或代码已经完成修订。
