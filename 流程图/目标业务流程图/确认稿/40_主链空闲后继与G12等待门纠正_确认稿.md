# 第 40 项：主链空闲后继与 G12 等待门纠正

状态：已确认设计输入；非正式规范。

当前 `BIZ-MAIN-001` A19 把“无正差距、等待、缺口、完成或取消”的后继直接画回 A02，容易表达成无条件循环，并绕过已确认的 G12。后续目标业务图治理必须把 A19 改为有效运行与可唤醒等待门。

固定主链为：

```text
本轮治理结果全部收束
-> G12 读取当前有效运行依据
-> 判断是否已有可立即消费的合法后继
   -> 有：结束本批，进入下一治理批次
   -> 无：登记合法等待对象和重新触发条件
          -> 等待具名事件、完整秒推进或停止控制
          -> 被唤醒后重新从 A02 冻结新批次
   -> 生存控制或停止候选：分流至对应专用入口
```

A19 不能表示无条件立即回环，禁止空邮箱、无任务或仅有未成熟材料时忙循环。没有正差距、没有主需求或任务进入等待，不等于程序停止、休眠或终止。

唤醒只触发新一轮读取，不证明等待条件已经满足。新一轮必须重新冻结事实截止和治理批次，不复用上一轮快照、权限、差距或后继判断。

程序停止请求只交 T01；休眠、终止和唤醒候选只交专用生存控制入口。G12 只裁决当前有效运行或合法等待及其依据。

后续修订 `BIZ-MAIN-001` A19、对应 T02 / G12 目标函数图、详细设计和施工计划时必须保持该分流；本确认稿不证明目标图或代码已经完成修订。
