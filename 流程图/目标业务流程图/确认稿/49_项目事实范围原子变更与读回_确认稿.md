# 第 49 项：项目事实范围原子变更与读回

状态：依据正式材料和用户授权已裁决；非正式规范。

项目事实范围内容变更的目标流程固定为：

```text
读取原范围稳定编码下的完整当前属性与关系
-> 复核期望事实代次、预期当前集合和范围变更授权
-> 比较完整目标集合
-> 无变化则返回精确无变化
-> 不满足范围不变量则写前拒绝
-> 形成保留项、退出项、新建项和属性槽变更的一个 L1 写集
-> 原子发布一个新事实代次
-> 按原范围稳定编码和新代次完整读回
-> 返回已发布范围投影或具名非成功
```

普通范围内容变化始终保留范围稳定编码。当前性不能由版本号、时间、SQL行、容器顺序、名称或配置决定。发现多个当前值、唯一关系复义或端点损坏时进入内部不一致，不允许自动选择。

后续修订范围变更目标函数时，输入必须区分预期当前集合与完整目标集合，发布后必须完整读回。建立另一个独立项目范围属于单独迁移业务，不是本函数分支。本裁决不证明正式目标图、详细设计、计划或代码已经完成修订。
