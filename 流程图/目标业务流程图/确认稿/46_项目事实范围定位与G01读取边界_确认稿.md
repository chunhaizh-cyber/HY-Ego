# 第 46 项：项目事实范围定位与 G01 读取边界

状态：已确认设计输入；非正式规范。

G01 及其项目事实范围读取链固定为：

```text
启动恢复完成
-> 从安装登记取得项目事实范围稳定编码定位材料
-> 项目事实范围领域服务按稳定编码和期望事实代次读取 L1 当前事实
-> 验证范围节点、范围业务类型、唯一当前范围事实和唯一项目根自我资格关系
-> 全部材料同代次时返回不可变范围投影
-> G01 消费该投影形成治理坐标
```

安装登记、SQL、配置、缓存和日志只提供定位或诊断材料，不得直接成为 G01 的范围事实。G01 不得按名称或节点类型扫描范围，不得选择第一项，也不得在未找到时自动建立范围。

未找到、已退出、类型错误、多项冲突、资格关系缺失或复义以及事实代次漂移必须保持互异结果。定位材料损坏或指向无效范围时，普通运行门保持关闭并进入具名恢复或人工重新登记流程。

全新安装的范围创建属于独立 `项目范围首次建立` 入口；其函数合同、资格规则身份和授权证据另行裁决。本确认稿不证明正式 G01 流程图、详细设计、计划或代码已经完成修订。
