# 第 48 项：对象建立授权票据与同写集证据

状态：已确认设计输入；非正式规范。

项目范围内对象的首次建立流程固定为：

```text
目标对象事实所有者提交完整建立意图
-> 项目事实范围授权服务复核范围、资格规则、对象类型、事实所有者、幂等键和当前事实代次
-> 拒绝则零写入返回具名结果
-> 接受则返回不可伪造、单次消费的未发布值式授权票据
-> 目标对象事实所有者形成目标对象、完整初始事实和授权证据的一个 L1 写集
-> L1 在同一事实代次原子发布目标对象及授权证据
-> 按新稳定编码读回目标对象、证据节点及其范围、规则、签发服务和目标对象关系
```

未发布授权票据必须绑定授权服务、项目范围、资格规则、对象业务类型、目标事实所有者、完整建立意图、写集幂等键、目标写集本地键和授权时事实代次。事实代次漂移后票据失效；不得按墙上时间续期，也不得把票据持久化为第二权威。

目标对象和授权证据必须同写集发布。授权接受不等于对象已经发布；写集发布后则只以已发布授权证据事实证明原授权，值式票据立即失去作用。发布结果未知只能按原幂等键和原写集收敛。

后续目标函数图不得画成“先建立对象、以后补授权”，也不得让 G01、L1 或普通调用方签发首次建立授权。本确认稿不证明正式目标图、详细设计、计划或代码已经完成修订。
