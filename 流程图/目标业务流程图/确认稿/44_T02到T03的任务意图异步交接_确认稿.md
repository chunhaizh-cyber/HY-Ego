# 第 44 项：T02 到 T03 的任务意图异步交接

状态：已确认设计输入；非正式规范。

`BIZ-MAIN-001` 中从正差距或任务后继裁决进入任务树管理时，T02 与 T03 之间是异步消息边界，不是跨线程同步函数调用。T02 只决定“为什么需要形成哪类任务治理意图”，不建立、复用或修改任务树。

固定顺序为：

```text
T02 根据一致治理事实形成任务治理裁决
-> 冻结不可变任务治理意图及其来源、运行代次、事实截止和幂等身份
-> 提交到 T03 治理邮箱
-> T03 独立取出并复核输入信封与绑定事实
-> 复核成功后才建立或复用对应需求任务树
```

消息提交成功只证明意图进入 T03 的输入边界，不证明任务树已经建立。队列满、停止阶段、重复、漂移、材料缺失或复核失败必须形成具名结果；不得由 T02 越权补写任务事实，也不得让 T03 使用消息载荷替代正式需求、授权或任务事实的独立读回。

后续修订 `BIZ-MAIN-001` 时，A05 到 A06 之间必须显式画出不可变任务治理意图的提交、取出和复核边界，不再画成 T02 直接调用 T03 建立任务树。本确认稿不证明目标图、详细设计、计划或代码已经完成修订。
