# 第 47 项：G01 资格规则身份与兼容门

状态：已确认设计输入；非正式规范。

G01 的资格规则复核链固定为：

```text
取得期望资格规则稳定编码
-> 读取项目根自我资格及其实际规则稳定编码
-> 两者相同则规则身份匹配
-> 两者不同时读取“当前规则直接接受旧规则”关系
-> 存在直接有向兼容关系则继续完整治理坐标验证
-> 不存在则返回资格规则不兼容并保持普通运行门关闭
```

不得按版本数值、名称、时间、结构相似或兼容关系链推断资格规则兼容。兼容关系只允许 `当前资格规则 -> 直接接受的旧资格规则`，反向和传递均不成立。

规则兼容不是治理坐标成功。即使规则可直接兼容，G01 仍须验证项目事实范围、自我结构、资格关系、授权证据及同代次一致性。不兼容规则需要独立 `项目根资格重新确认` 事务，G01 本身不得修改资格、补造证据或原地改写旧规则。

后续修订 G01 目标函数图时必须显式画出同规则、直接兼容和不兼容三个分支。本确认稿不证明正式目标图、详细设计、计划或代码已经完成修订。
