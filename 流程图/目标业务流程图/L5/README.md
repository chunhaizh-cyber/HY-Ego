## 定位

本目录保存 `BIZ-L5-*` 目标业务函数设计图。`BIZ-L5`只表示目标业务自上而下的第五层分解深度，不是未定义的 `DATA-L5`，也不等于当前代码调用深度 `CF-L5`。

## 边界

- 新增 BIZ-L5 图必须能回指唯一 BIZ-L4 父节点，不得用相同层号推导 DATA 或 CF 归属。
- 本目录只冻结目标函数合同，不证明 C++ 文件、provider、装配或运行路径已经存在。
