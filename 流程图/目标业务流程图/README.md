# 目标业务流程图目录

更新时间：2026-08-27

## 1. 定位

本目录保存 `BIZ-*` 目标业务函数设计图。它按正式逻辑规范自上而下冻结目标函数规格、物理位置、线程归属和组合关系，不证明当前代码已经实现。

```text
正式逻辑规范
-> BIZ-L0 系统启动、运行模块运行、运行模块结束和系统结束
-> BIZ-L1 线程所有者与生产调用方
-> BIZ-L2 业务目标的第二层函数分解
-> BIZ-L3 及以下更细的目标函数分解
-> 详细设计冻结 ABI、所有权、生命周期和验证
-> 计划智能体制定并登记实施计划
```

`BIZ-L0`—`BIZ-Ln` 只表示目标业务图的分解深度和稳定身份，不等于数据服务架构层级。当前只定义 `DATA-L1`—`DATA-L3`；`DATA-L4`、`DATA-L5` 保留但未定义，业务资格、目标、动作和结果解释位于整个 `DATA` 命名空间之外。当前代码调用图另用 `CF-L0`—`CF-Ln` 表示从具名根入口展开的静态调用深度。三套层号彼此独立，完整消歧和兼容边界读取 `.codex/rules/层级命名空间规则.md`。

目标图不得用“领域 `DATA-L2`”“事务 `DATA-L3`”或类似说法给业务函数授予数据服务层级语义，也不得从相同层号推导 `BIZ-Ln`、`CF-Ln` 与 `DATA-Ln` 已经对应或接线。

## 2. 多线程校准口径

活动目标模型固定为：

```text
程序主线程只启动、等待停止和分阶段收口
自我线程独立治理
任务管理线程独立推进任务状态合同并决定下一工作阶段
任务工作线程池异步推进筹办或执行不可变工作包
控制面板线程只读显示并提交程序控制消息
外设线程组采集并发布不可变外设材料
日志 / 缓存 / 持久证据线程只作支持旁路
```

世界树、安全、需求、任务、方法、因果、观察和审计是领域能力，不是由程序主线程顺序调用的常驻 `BIZ-L1` 阶段。跨线程后继必须通过不可变值式材料表达，不能画成一次同步函数返回。

## 3. 与现状代码图的边界

| 身份 | 表达内容 | 依据 | 能否证明代码已存在 |
| --- | --- | --- | --- |
| `BIZ-*` | 目标业务和线程应如何成立 | 正式逻辑规范与已裁决目标设计 | 不能 |
| `CF-*` | 当前代码实际如何调用 | 已发布源码与静态图谱 | 只能证明静态事实，不能证明运行成功 |

目标函数状态使用 `当前复用 / 适配扩展 / 待新增 / 待核`。当前图谱已经覆盖正式代码基线的可达函数，但执行侧未提交代码候选不能计入目标函数的现状实现证明。

目标函数到当前实现的逐批裁决读取 `目标函数到当前代码实现对应.md`。该表同时保存“继续分解 / 复用终止 / 平台终端 / 依赖未决”审计；必须记录代码函数稳定编号、代码图路径、正式源码位置和一致 / 部分实现 / 未实现 / 实现漂移 / 证据待刷新状态，缺少代码图时不得用目标函数名补造当前实现。

### 4.1 BIZ-L0 / BIZ-L1 粗层接线复核

截至2026-08-26，普通控制面板和无窗口常驻两种模式的粗层接线已统一为：T01负责启动、三来源停止等待和分阶段收口；T02—T06只作为并发线程根入口；支持线程组作为T01下的非业务旁路子能力。T01 v0.3已显式把T02、T03、T04、可选T05、T06和支持旁路全部纳入结构化停止/连接边界，不再用对象析构或线程`join`冒充正常业务收口。

这只证明普通模式的BIZ-L0/BIZ-L1目标分解在粗层上可接线，不证明当前代码已经实现。当前仍有四类上层缺口：

- T02、T03、T04永久provider失败或动作后材料无法交付时的可恢复停机合同未冻结，三个具名DRIFT继续有效；
- T05、T06及支持线程组仍未接入生产，T03也未接6340外设承接；
- T03到T02的结算定位与T02到T03的self后继决议已由 BIZ-L3/L4-001-14 重建为双向共同排空目标函数组；当前代码仍未实现这些接口，且具名接管 owner 的最终公开合同仍须由有效详细设计和计划冻结后施工；
- 生产运行期虽已能由`--runtime-context`到达，但独立会话的等待、停止、收口和结果矩阵未冻结，`DRIFT-BIZ-L1-PRODUCTION-RUNTIME-SESSION-LIFECYCLE-UNFROZEN`使整个项目的L1模式覆盖仍不完整。

## 5. 分层和使用规则

1. 一张目标函数图只冻结一个根函数；节点只能是具名被调函数或本函数内具体指令。
2. 计划智能体先从 `BIZ-L0` / `BIZ-L1` 选择线程所有者，再沿调用类型读取 `BIZ-L2`：
   - `直接函数调用`：同一线程、锁外同步取得值式结果；
   - `异步消息后继`：发送方结束本阶段，接收线程以后独立消费；
   - `只读投影`：不反写业务事实；
   - `支持线程旁路`：失败不得改写已经成立的业务结果。
