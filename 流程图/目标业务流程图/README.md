# 目标业务流程图目录

更新时间：2026-08-14

## 1. 定位

本目录保存 `BIZ-*` 目标业务函数设计图。它按正式逻辑规范自上而下冻结目标函数规格、物理位置、线程归属和组合关系，不证明当前代码已经实现。

```text
正式逻辑规范
-> BIZ-L0 顶层模式路由
-> BIZ-L1 线程所有者与生产调用方
-> BIZ-L2 业务目标的第二层函数分解
-> BIZ-L3 及以下更细的目标函数分解
-> 详细设计冻结 ABI、所有权、生命周期和验证
-> 计划智能体制定并登记实施计划
```

`BIZ-L0`—`BIZ-Ln` 只表示目标业务图的分解深度和稳定身份，不等于 0050 / 4190 的数据服务 `DATA-L1`—`DATA-L5`。`DATA-L1`—`DATA-L5` 全部只拥有数据结构 CRUD；业务名称、资格、目标、动作和结果解释统一位于 `DATA-L5` 之外。当前代码调用图另用 `CF-L0`—`CF-Ln` 表示从具名根入口展开的静态调用深度。三套层号彼此独立，完整消歧和兼容边界读取 `.codex/rules/层级命名空间规则.md`。

目标图不得用“领域 `DATA-L2`”“事务 `DATA-L3`”或类似说法给业务函数授予数据服务层级语义，也不得从相同层号推导 `BIZ-Ln`、`CF-Ln` 与 `DATA-Ln` 已经对应或接线。

## 2. 多线程校准口径

活动目标模型固定为：

```text
程序主线程只启动、等待停止和分阶段收口
自我线程独立治理
任务管理线程独立推进任务状态合同并决定下一工作阶段
任务工作线程池异步推进筹办或执行不可变工作包
控制面板线程只读显示并提交程序控制消息
外设线程组采集并发布不可变外设材料
日志 / 缓存 / 持久证据线程只作支持旁路
```

世界树、安全、需求、任务、方法、因果、观察和审计是领域能力，不是由程序主线程顺序调用的常驻 `BIZ-L1` 阶段。跨线程后继必须通过不可变值式材料表达，不能画成一次同步函数返回。

## 3. 与现状代码图的边界

| 身份 | 表达内容 | 依据 | 能否证明代码已存在 |
| --- | --- | --- | --- |
| `BIZ-*` | 目标业务和线程应如何成立 | 正式逻辑规范与已裁决目标设计 | 不能 |
| `CF-*` | 当前代码实际如何调用 | 已发布源码与静态图谱 | 只能证明静态事实，不能证明运行成功 |

目标函数状态使用 `当前复用 / 适配扩展 / 待新增 / 待核`。当前图谱已经覆盖正式代码基线的可达函数，但执行侧未提交代码候选不能计入目标函数的现状实现证明。

目标函数到当前实现的逐批裁决读取 `目标函数到当前代码实现对应.md`。该表同时保存“继续分解 / 复用终止 / 平台终端 / 依赖未决”审计；必须记录代码函数稳定编号、代码图路径、正式源码位置和一致 / 部分实现 / 未实现 / 实现漂移 / 证据待刷新状态，缺少代码图时不得用目标函数名补造当前实现。

## 5. 分层和使用规则

1. 一张目标函数图只冻结一个根函数；节点只能是具名被调函数或本函数内具体指令。
2. 计划智能体先从 `BIZ-L0` / `BIZ-L1` 选择线程所有者，再沿调用类型读取 `BIZ-L2`：
   - `直接函数调用`：同一线程、锁外同步取得值式结果；
   - `异步消息后继`：发送方结束本阶段，接收线程以后独立消费；
   - `只读投影`：不反写业务事实；
   - `支持线程旁路`：失败不得改写已经成立的业务结果。
3. 每个跨线程材料必须是不可变值式材料，携带稳定身份、运行代次、业务版本和幂等键；不得传递栈引用、事务令牌、锁或服务内部可变指针。
4. 锁内只入队、出队、复制 / 移动和更新队列自身状态；领域服务、方法动作、独立回读和持久化适配均在锁外调用。
5. `适配扩展`和`待新增`进入计划前，详细设计仍须冻结 DTO 字段、枚举数值、构造依赖、所有权、生命周期、事务、错误和验证矩阵。
6. 本目录不登记计划状态，也不构成执行许可。
7. 同一图身份在本目录只保留当前有效文件；修订时原地更新或用新文件替换并删除旧文件。只有明确需要历史回查时，旧文件才可移入独立的 `历史版本/` 子目录，且不得继续出现在当前有效索引中。
8. 计划智能体设计启动、停止或线程所有权时必须读取 BIZ-L2-001-01—15 及 `L3/README.md`；普通系统初始化固定沿 `I1 -> I2 -> SELF-FORM -> 存在/特征/动态/因果链四个语言无关本体根生产初始化` 展开。I1 失败映射阶段 14，成功直接把同次结果交给 I2；阶段 15 永久缺号且数值不复用。I2 失败映射阶段 16，真实自我缺失 / 失败映射阶段 17，四个本体根生产初始化缺失 / 失败映射阶段 18。阶段 18 不读取或建立语言、词条、词性、普通概念或二次特征概念；因果链根只初始化为空根，不读取动态列表、不形成因果候选、不发布直接因果事实或普通因果链概念。阶段 18 解除前不得进入方法根、自我线程、概念支持、投影、信号或宿主。启动候选回收仍不替代正式停机。设计自我治理主链时先读 BIZ-MAIN-001，再沿阶段读取对应 T01—T06 和目标单函数图。
9. 设计任务管理与任务工作线程时，T03 必须读取 BIZ-L2-004-02、004-04、004-08—14，T04 必须读取 BIZ-L2-004-07、004-15；004-03、004-05 是其 `BIZ-L2` 内部调用，不能误列为 `BIZ-L1` 的第二个直接入口。
10. T05 只经 BIZ-L2-005-01—06 读取和显示值式投影或请求程序停止；T06 只经 BIZ-L2-006-01—04 形成和发布外设材料。T06 发布重试必须再次调用 006-04 并保留同一报告身份与幂等键，不得建立第二个“重试发布”权威函数。
11. 控制面板页面、投影缓存和显示状态永远不反写业务事实；用户操作只能形成正式请求，由对应业务入口重新执行准入、权限、版本和事务裁决。
12. BIZ-L3-003-01-03 在6140与4220冻结两个互异动态身份的合同前保持待规范裁决：三个既有主键不得伪造第四主键，状态变化动态不得自引用为关系20角色8的同源状态迁移动能。
