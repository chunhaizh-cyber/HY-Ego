# 目标业务流程图 L3 索引

更新时间：2026-08-27

`BIZ-L3` 是目标调用深度，不是 0050 / 4190 的数据服务 L3。每份图只冻结一个由 BIZ-L2 根函数直接调用的函数；业务函数只能经具名公开数据服务消费基础数据，不得取得 owner、仓库、锁或内部事务。若该函数内部仍有非平凡调用，后续再按实际需要进入 BIZ-L4。
