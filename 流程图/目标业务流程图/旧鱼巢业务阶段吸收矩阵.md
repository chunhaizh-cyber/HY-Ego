# 旧鱼巢业务阶段吸收矩阵

更新时间：2026-08-03

## 1. 用途

本表逐项记录 `流程图/鱼巢流程/**` 中成熟业务阶段如何进入当前目标业务图。旧图只提供覆盖线索；现行规范决定机器语义，当前目标函数图决定函数和线程归属。

裁决值固定为：

```text
保留：业务阶段和顺序仍成立，可按当前合同表达
改写：业务目标仍成立，但类型、写权、存储、线程或证据合同必须替换
排除：旧语义会产生第二事实、越权写入或旧实现依赖，不进入目标设计
```

## 4. 覆盖结论

旧鱼巢十六份参考图中的六个主业务包及专项线索已对应到：

```text
T01 初始化
-> T02 冻结批次、需求重判
-> T03 任务承接、父等待、工作阶段裁决与异步派发
-> T04 / L2-004-03 筹办反推与冻结，或 T04 / L2-004-07 方法执行、动态与实际结果
-> T03 独立回读和任务结论
-> T02 需求 / 服务结算与下一轮
```

两条旁路分别对应：

```text
T06 外设报告 -> 6340 任务域唯一承接 -> 正式领域处理
已发布事实 -> 日志 / 持久证据 / SQL 审计 / T05 控制面板只读投影
```

本矩阵只证明旧业务阶段已经被逐项裁决，不证明目标函数、线程接线或业务闭环已实现。
