# L2-FEATURE-COMPARISON-REGISTRY-NEUTRAL-WRITE-MIGRATION 建立登记函数流程图 v0.1

日期：2026-08-08

根函数：`特征比较服务::建立登记(const 特征比较登记请求&)`

边界：只画 M01 根函数及其直接调用的私有校验、映射和权威读回；不画 `读取当前登记()`、M02 `0x15000802U`、M03 `0x15000803U`、运行期比较、状态动态联合发布或 L1 内部事务。图是目标施工事实，不是当前实现事实。

```mermaid
flowchart TD
    A["进入建立登记，请求为调用方值"] --> B["取得特征比较服务互斥锁并进入异常边界"]
    B --> C{"合同、规则、幂等身份、期望事实代次是否合法"}
    C -- "否" --> R0["返回入口拒绝，无登记；零预读、零提交"]
    C -- "是" --> D["预读P：读取中性当前事实代次"]
    D --> E{"合同正确、读取成功且P非零"}
    E -- "否" --> R1["映射结构化非成功，无登记；零提交"]
    E -- "是；不以P和请求期望不等提前返回" --> F["以保留域0x08映射中性幂等键"]
    F --> G["形成固定中性写集：6节点、0关系、0值、0槽变更、0退出；原样保留期望代次"]
    G --> H["恰一次调用提交中性写集"]
    H --> I{"L1写入状态"}
    I -- "事实代次漂移" --> RD["返回版本漂移，无登记"]
    I -- "幂等冲突或入口拒绝" --> RR["返回入口拒绝，无登记"]
    I -- "资源失败" --> RX["返回资源失败，无登记"]
    I -- "内部不一致或本写集不可能的未找到/已退出" --> RI["返回内部不一致，无登记"]
    I -- "成功" --> J0{"P等于请求期望代次"}
    J0 -- "否；与冻结L1顺序矛盾" --> RI
    J0 -- "是" --> J1["核对成功合同：版本、键、非零首次代次、发布标志true、重试不适用"]
    I -- "精确重复；允许P高于原期望" --> J2["核对重复合同：版本、键、非零首次代次、发布标志false、原键读回收敛"]
    J1 --> K{"六项本地键映射是否完整、有效、唯一"}
    J2 --> K
    K -- "否" --> RI
    K -- "是" --> L["按键1至6取得首次六稳定编码"]
    L --> M["读回G0：读取中性当前事实代次"]
    M --> N{"G0合同正确、成功且非零"}
    N -- "否" --> R2["映射读取非成功，无登记"]
    N -- "是" --> O["依次读取六个中性当前节点"]
    O --> P{"每项回显和读取代次等于G0，节点当前未退出、无属性、形状正确，六创建代次同为首次代次"}
    P -- "读取状态未找到、退出或资源失败" --> R3["映射读取非成功，无登记"]
    P -- "回显、形状或创建代次矛盾" --> RI
    P -- "读取代次不等G0" --> RD
    P -- "六项成立" --> Q["读回G1：再次读取中性当前事实代次"]
    Q --> S{"G1合同正确、成功、非零且等于G0"}
    S -- "读取非成功" --> R4["映射读取非成功，无登记"]
    S -- "G1不等G0" --> RD
    S -- "是" --> T["按六节点组装现有特征比较登记；事实截止代次取G0"]
    T --> U{"登记完整且与已有六编码定位相同或缓存为空"}
    U -- "否" --> RI
    U -- "是" --> V["更新非权威登记定位缓存"]
    V --> W["首次成功与精确重复统一返回已比较并携带当前登记"]
    B -. "bad_alloc" .-> RX
    B -. "其它异常" .-> RI
```

## 固定节点映射与顺序

```text
键1 服务身份                 普通
键2 合同配置I64组属性类型     属性类型 / I64组
键3 合同字段关系类型          普通
键4 无单位                    普通
键5 标量维度                  普通
键6 标量分量角色              普通
```

```text
领域预读 P
-> 不提前用 P 裁决请求漂移
-> 恰一次提交完整原请求
-> L1：精确重复 -> 同键异义 -> legacy 键占用 -> 期望代次漂移 -> 首次候选发布
-> 成功类按首次六编码执行 G0 + 六节点 + G1 当前读回
```

业务标签 `0x15000801U`、G8 登记意图、旧幂等预探测、完整快照和首次请求缓存不进入目标流程。流程图不授权修改 M02/M03 或运行比较。
