依据：`规范/4015_子规范_L1简化事实基座.md`、`规范/详细设计/20260804_L1-SIMPLIFY-P0-FIX_合同补齐详细设计_v0.1.md`。

## 提交写集

根函数：`L1写入结果 L1事实基座仓库::提交(const L1写集请求& 请求)`

物理位置：`海中鱼巣/核心/仓库.L1事实基座.ixx`

```mermaid
flowchart TD
    A["取得独占锁并规范化请求"] --> B{"幂等键是否已有记录"}
    B -->|同义| C["在候选审计状态中登记精确重复"]
    C --> D["一次交换审计状态，不推进事实代次"]
    D --> E["返回首次冻结结果"]
    B -->|异义| F["返回幂等冲突，零事实变化"]
    B -->|没有| G{"期望事实代次是否等于当前"}
    G -->|否| H["返回事实代次漂移，零事实变化"]
    G -->|是| I["复制完整仓库状态为候选"]
    I --> J["只在候选中分配编码并应用节点、关系、值、槽和退出"]
    J --> K["校验类型形状、端点、生命周期和完整引用"]
    K --> L["在候选中形成结果、幂等账和审计"]
    L --> M{"发布后读回形状是否完整"}
    M -->|否| N["返回内部不一致，旧状态不变"]
    M -->|是| O["候选代次加一并一次 noexcept 交换"]
    O --> P["返回已冻结成功结果"]
    I -->|异常或资源不足| Q["返回资源失败，旧状态和下个编码不变"]
```

## 确认恢复候选

根函数：`L1恢复结果 L1事实基座仓库::确认恢复候选()`

物理位置：`海中鱼巣/核心/仓库.L1事实基座.ixx`

```mermaid
flowchart TD
    A["取得独占锁"] --> B{"隔离候选是否存在"}
    B -->|否| C["返回无候选"]
    B -->|是| D{"当前代次是否等于候选基线"}
    D -->|否| E["丢弃候选并返回事实代次漂移"]
    D -->|是| F["最终复核候选完整不变量"]
    F -->|失败| G["丢弃候选并返回材料不完整或内部不一致"]
    F -->|通过| H["设置目标代次为当前代次加一"]
    H --> I["一次 noexcept 状态交换"]
    I --> J["同锁独立形成完整快照读回"]
    J -->|一致| K["返回恢复已发布和新代次"]
    J -->|矛盾| L["标记隔离并返回内部不一致"]
```

恢复建立只负责在隔离对象中构造和验证候选；撤销只丢候选。二者都不改变当前事实代次，也不伪造零幂等键审计。
