## 关键边界

1. C1 不 import C2—C5；C2—C5 只 import C1 的公开值类型。
2. 字段缺失先于三轴非法和负载错配，复合错误不随遍历顺序变化。
3. 稳定子集不得复制原始逐簇点云、掩码或局部图。
4. 报告、候选、队列项和索引都不是世界事实。
