# P25 实例槽引用 I64 特征定义详情集合读取函数流程图 v0.1

日期：2026-08-05

## 1. 调用边界

```mermaid
flowchart TD
    A0["P17成功：调用方持有一份完整快照"] --> A["P24用该快照形成完整槽结构"]
    A --> B{"槽总数为0？"}
    B -- "是" --> Z["复用形成P24的同一P17快照；P22调用0；P25形成完整空定义组"]
    B -- "否" --> C["P22尝试读取当前登记"]
    C --> D{"P22结果"}
    D -- "许可拒绝/未加载/拒绝/失败" --> R0["立即返回；P25调用0；不重取P17"]
    D -- "已读取完整登记" --> E["复用形成P24的原P17完整快照"]
    E --> G["P25只读投影模块纯函数：P24事实 + P22登记 + 原P17快照"]
```

P22 锁和 P17 许可都在 P25 调用前释放。P25 是特征定义领域的新无状态只读投影模块，不调用 provider、不取锁、不重取快照；现有特征定义 / 实例特征模块不反向导入它。

## 2. `从快照读取实例槽引用I64特征定义详情集合`

```mermaid
flowchart TD
    A["A【输入】读取请求 + 一份P17完整快照"] --> B{"B【判断】外层和P24版本/完整性正确？"}
    B -- "非完整" --> R2["R2【返回】入口拒绝"]
    B -- "声称完整但排序/见证损坏" --> R3["R3【返回】内部不一致 + 稳定诊断"]
    B -- "正确" --> C{"C【判断】P24定义引用为空？"}
    C -- "是" --> D{"D【判断】P24截止=P17快照代次？"}
    D -- "否" --> R4["R4【返回】事实代次漂移"]
    D -- "是" --> R5["R5【返回】已读取；完整空定义组"]
    C -- "否" --> E{"E【判断】P22登记定位存在且完整？"}
    E -- "缺失" --> R6["R6【返回】登记未加载"]
    E -- "非法" --> R2
    E -- "完整" --> F{"F【判断】P24截止=P17快照代次且登记代次不晚于快照？"}
    F -- "否" --> R4
    F -- "是" --> G{"G【判断】登记四节点同快照当前、形状和创建代次正确？"}
    G -- "全未命中" --> R7["R7【返回】未找到"]
    G -- "部分/损坏" --> R3
    G -- "正确" --> H["H【指令】从P24精确提取并去重定义身份"]
    H --> I{"I【判断】每个定义节点与P24见证一致？"}
    I -- "否" --> R3
    I -- "是" --> J{"J【判断】三属性槽唯一完整且无额外槽？"}
    J -- "否" --> R3
    J -- "是" --> K{"K【判断】三I64值所属/类型/来源/生命周期正确？"}
    K -- "否" --> R3
    K -- "是" --> L{"L【判断】标记=1且下界<=上界？"}
    L -- "否" --> R3
    L -- "是" --> M["M【指令】按定义稳定编码升序形成详情"]
    M --> R8["R8【返回】已读取；完整=true；诊断空"]
```

## 3. 范围与去重

```mermaid
flowchart LR
    A["P24全部槽的定义身份"] --> B["按稳定编码排序去重"]
    B --> C["每个唯一身份精确读定义详情"]
    C --> D["输出恰等于引用集合"]
    E["快照中其它合法定义"] --> F["不召回、不夹带"]
```

共享定义只输出一次；当前值后继通过定义稳定编码机械联结，不再解释定义属性结构。

## 4. 非目标

本流程不读取实例槽当前值，不执行上下界判断，不读取历史、状态、动态或恢复材料。
