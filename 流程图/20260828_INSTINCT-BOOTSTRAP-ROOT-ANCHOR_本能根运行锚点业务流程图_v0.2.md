# INSTINCT-BOOTSTRAP-ROOT-ANCHOR 本能根运行锚点业务流程图 v0.2

日期：2026-08-28

状态：设计候选，待创建侧验证与发布

## 1. 启动主流程

```mermaid
flowchart TD
    A["真实自我、四本体根、方法登记根成功"] --> B["形成请求：唯一自我 + 本次启动UTC纳秒"]
    B --> C{"合同、自我和时间有效？"}
    C -- "否" --> X["入口拒绝；锚点空；不创建自我线程"]
    C -- "是" --> D["按安全/服务固定幂等键形成或恢复两份一阶定义"]
    D --> E["形成或恢复两份 M-X 二次特征概念"]
    E --> F["形成或恢复唯一自我下两份根实例"]
    F --> G{"每个根的当前值和当前状态情况"}
    G -- "都不存在" --> H["调用具名跨owner入口：首值 M/2 + 初态 + 当前选择同G1"]
    G -- "都存在" --> I["fresh互证当前值、状态、主体、实例和UTC时间；不重置当前值"]
    G -- "仅一边存在" --> Y["材料未闭合；锚点空；停门"]
    H --> H0["首次动态新增量必须为0"]
    H0 --> J["形成或恢复两份目标判断比较注册"]
    I --> J
    J --> K["按固定键形成或恢复两份 I64_MAX 目标合同"]
    K --> L["形成或恢复两份根需求、列表项和成员关系"]
    L --> M["根需求组和父关系读回证明父为空"]
    M --> N["冻结 Gfinal"]
    N --> O["全部材料按 Gfinal 正式重读"]
    O --> P{"安全组/服务组具名身份、合同、关系、唯一性和截止全部闭合？"}
    P -- "否" --> Z["结构化非成功；锚点空；不创建线程"]
    P -- "是，本次有新发布" --> Q1["已形成 + 完整值式锚点"]
    P -- "是，本次零新发布" --> Q2["已恢复 + 完整值式锚点"]
    Q1 --> R["锚点进入自我线程合同v2锁定请求"]
    Q2 --> R
    R --> S["创建自我线程并停在治理运行门"]
    S --> T["全部启动阶段成功后开放治理循环"]
```

具名安全/服务字段是值式角色绑定。它们由两组固定幂等身份和同 `Gfinal` 正式读回共同证明，不建立角色节点、第二 owner 或索引。

## 2. 首值与初始状态跨 owner 单 G1

```mermaid
flowchart LR
    A["G0 + 组合/首值/首态三键 + 实例 + M/2 + UTC + 正式来源"] --> B["特征owner私有预形成：首值事实 + 当前值槽"]
    A --> C["状态owner私有预形成：初态 + 主体/实例关系 + 当前选择"]
    B --> D{"两个强类型参与者有效并绑定同一G0？"}
    C --> D
    D -- "否" --> X["结构化非成功；全部载荷空；共同代次0"]
    D -- "是" --> E["状态服务协调一次L1双参与者原子提交"]
    E --> F{"提交结果"}
    F -- "已提交/精确重复" --> G["按共同G1读回值、初态、选择"]
    F -- "已可能发布" --> Y["空载荷；保存原完整请求；仅原键收敛"]
    F -- "其它非成功" --> X
    G --> H{"三者形成代次=G1且值/主体/实例/来源闭合？"}
    H -- "否" --> Z["内部不一致；空载荷"]
    H -- "是" --> I["成功；动态新增量0"]
```

L1 运输槽固定映射为“状态槽承载初态 owner、动态槽承载首值 owner”；运输字段名不改变业务语义，本入口从不形成动态。

## 3. 重启恢复

```mermaid
flowchart TD
    A["L1持久事实隔离恢复成功"] --> B["按两组固定幂等身份恢复定义、实例、比较注册和目标合同"]
    B --> C["按唯一自我 + 具名根定义读当前值与当前状态选择"]
    C --> D{"值和状态存在情况"}
    D -- "都存在" --> E["同截止互证；不得重置为M/2"]
    D -- "都不存在" --> F["以本次启动时间执行首次单G1入口"]
    D -- "仅一边存在" --> X["材料未闭合；停门"]
    E --> G["按目标四元组恢复需求和列表项"]
    F --> G
    G --> H["冻结新的Gfinal并完整重读"]
    H --> I["形成同一组稳定身份的新值式锚点"]
```

已有首态首次账时必须恢复其原 UTC 时间，不以新启动时间重放同一首态身份。旧锚点截止不跨启动复用。

## 4. 二次特征

```mermaid
flowchart LR
    A["持久：安全差值或服务差值概念定义"] --> B["治理轮次按需冻结fresh G0"]
    B --> C["读取对应根当前值"]
    C --> D["局部计算 Delta = I64_MAX - 当前值"]
    D --> E["用于本次目标比较"]
    E --> F["调用结束立即销毁"]
    F --> G["零实例、零当前值槽、零状态、零动态、零恢复"]
```

## 5. 非成功矩阵

| 分支 | 处理 |
| --- | --- |
| 坏合同、零自我、零 UTC | 入口拒绝，锚点空 |
| fixed key 绑定异义材料 | 幂等冲突，锚点空 |
| 两根交叉、重复或绑定错误 | 引用冲突，锚点空 |
| 当前值/状态仅一边存在 | 材料未闭合，锚点空 |
| 合同或必要角色材料已退出 | 角色已退出，锚点空 |
| 原子结果未知 | 已可能发布，空载荷，原键收敛 |
| 任一读回截止不等 Gfinal | 当前性漂移，丢弃组合结果 |
| 端口、映射或载荷矛盾 | 内部不一致，锚点空 |
| 任一初始化非成功 | 失败阶段21，不创建自我线程，不开放治理门 |

新 DATA 合同不产生 `许可拒绝`。验收由生产二进制之外的调用者在实际使用阶段执行；生产 `入口.cpp` 不增加专项模式或运行器。
