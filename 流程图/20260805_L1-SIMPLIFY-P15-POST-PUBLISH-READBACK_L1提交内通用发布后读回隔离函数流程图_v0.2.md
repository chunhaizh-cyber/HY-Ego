## 1. 领域写入口与幂等探测

```mermaid
flowchart TD
    A["接收公开业务请求"] --> B["领域按固定编码形成请求意图摘要 SHA-256"]
    B --> C["L1.探测幂等：键+请求意图摘要"]
    C --> D{"探测结果"}
    D -- "同义已发布" --> E["返回首次执行证据、代次、映射、完整读回、结果摘要；provider零调用"]
    D -- "异义冲突" --> F["幂等冲突；零provider、零写"]
    D -- "已隔离/内部不一致" --> G["结构化拒绝；返回允许的定位证据"]
    D -- "未找到" --> H["读取provider和当前事实"]
    H --> I["形成确定性写集和非空通用读回计划"]
    I --> J["领域形成首次执行证据摘要 SHA-256"]
    J --> K["提交同一L1 v2入口"]
```

## 2. L1 探测函数

```mermaid
flowchart TD
    A["探测幂等(合同、键、意图摘要)"] --> B{"版本、键、摘要完整？"}
    B -- 否 --> B0["入口拒绝"]
    B -- 是 --> C["取得一次共享锁，只读内存幂等账"]
    C --> D{"目标键存在？"}
    D -- 否且隔离 --> D0["已隔离；空首次载荷"]
    D -- 否且未隔离 --> D1["未找到"]
    D -- 是 --> E{"账/审计/结果摘要完整？"}
    E -- 否 --> E0["内部不一致"]
    E -- 是 --> F{"意图摘要相同？"}
    F -- 否 --> F0["异义冲突"]
    F -- 是且隔离 --> F1["已隔离；返回首次载荷和失败见证"]
    F -- 是且未隔离 --> F2["同义已发布；返回首次完整载荷"]
```

探测不访问 SQL、provider、普通事实、索引，不写审计、不推进代次、不外泄锁或容器引用。

## 3. L1 提交和双摘要裁决

```mermaid
flowchart TD
    A["提交L1 v2写集"] --> B["取得唯一独占锁"]
    B --> C{"隔离？"}
    C -- 是 --> C0["许可拒绝"]
    C -- 否 --> D{"同幂等键存在？"}
    D -- "存在且意图不同" --> D0["幂等冲突"]
    D -- "存在且意图相同" --> D1["直接返回首次完整结果；忽略后来执行证据/写集；不追加审计"]
    D -- 不存在 --> E{"双摘要、代次、写集、非空计划完整？"}
    E -- 否 --> E0["入口拒绝；零候选"]
    E -- 是 --> F["形成候选、首次双摘要、映射、读回预期、结果摘要、幂等账和提交审计"]
    F --> G{"全部资源和失败容量已预留？"}
    G -- 否 --> G0["资源失败；零发布"]
    G -- 是 --> H["swap：业务代次推进一次"]
    H --> I["仍持独占锁，从权威状态按通用计划逐项读回"]
    I --> J{"读回完整一致？"}
    J -- 是 --> J0["返回首次映射、完整读回和结果摘要；释放锁"]
    J -- 否/异常 --> K["先隔离，再安装预构造失败见证和失败审计"]
    K --> K0["返回内部不一致；保留发布代次和首次幂等记录；释放锁"]
```

## 4. 结果摘要编码

```mermaid
flowchart LR
    A["HZY-L1RS魔数"] --> B["结果摘要版本/L1版本/摘要版本"]
    B --> C["幂等键"]
    C --> D["请求意图摘要"]
    D --> E["首次执行证据摘要"]
    E --> F["首次发布代次"]
    F --> G["按本地键排序的映射"]
    G --> H["按计划顺序的完整中性读回"]
    H --> I["标准SHA-256 32字节"]
```

整数网络字节序；集合先写 U64 数量，空集合写 U64 零；禁止地址、padding、`std::hash`、容器迭代序或平台布局。

## 5. 恢复互证

```mermaid
flowchart TD
    A["恢复材料中的幂等账"] --> B["校验双摘要非零"]
    B --> C["重算首次确定性结果摘要"]
    C --> D["互证首次代次、映射、完整读回、提交审计"]
    D --> E{"存在发布后失败？"}
    E -- 否 --> F["继续完整恢复候选校验"]
    E -- 是 --> G["互证失败见证、隔离审计和同一双摘要"]
    G --> F
    B -. "缺字段/默认补零/反推意图" .-> X["材料不完整或内部不一致；拒绝恢复"]
    C -. "摘要不等" .-> X
    D -. "任一矛盾" .-> X
```
