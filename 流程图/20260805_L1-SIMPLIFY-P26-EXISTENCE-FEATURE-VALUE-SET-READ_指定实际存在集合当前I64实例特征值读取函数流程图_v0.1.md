# P26 指定实际存在集合当前 I64 实例特征值读取函数流程图 v0.1

日期：2026-08-05

## 1. 调用边界

```mermaid
flowchart TD
    A["调用方持有一份P17完整快照"] --> B["P24用该快照形成完整槽结构"]
    B --> C{"P24成功？"}
    C -- "否" --> R0["返回P24非成功；P25/P26调用0"]
    C -- "是" --> D["P25用原快照形成完整定义详情"]
    D --> E{"P25成功？"}
    E -- "否" --> R1["返回P25非成功；P26调用0"]
    E -- "是" --> F["P26纯函数：P24 + P25 + P23定位请求 + 原P17快照"]
```

P17 许可拒绝发生在 P24 前并立即返回；P26 不重取快照，不调用 P17/P22/P24/P25 服务。P23 仅在非空槽分支以同一快照执行一次无锁纯值定位。

## 2. `从快照读取当前实际存在I64实例特征值集合`

```mermaid
flowchart TD
    A["A【输入】读取请求 + 原P17快照"] --> B{"B【判断】自身/P24/P25版本与完整性正确？"}
    B -- "版本或非完整" --> R2["R2【返回】入口拒绝"]
    B -- "声称完整但范围/排序损坏" --> R3["R3【返回】内部不一致 + 稳定诊断"]
    B -- "正确" --> C{"C【判断】P24/P25/P17根、截止与定义集合一致？"}
    C -- "仅截止不同" --> R4["R4【返回】事实代次漂移"]
    C -- "范围矛盾" --> R3
    C -- "一致" --> D{"D【判断】实例槽总数为0？"}
    D -- "是" --> R5["R5【返回】按P24主体一一形成完整空特征组；P23调用0"]
    D -- "否" --> E["E【调用】P23从原快照读取登记定位"]
    E --> F{"F【判断】P23已读取、完整且同截止？"}
    F -- "具名非成功" --> R6["R6【返回】保持P23状态"]
    F -- "坏成功" --> R3
    F -- "正确" --> G["G【指令】取得当前I64值属性类型见证"]
    G --> H{"H【判断】每个P24槽节点与快照一致？"}
    H -- "否" --> R3
    H -- "是" --> I{"I【判断】目标类型当前属性槽恰一？"}
    I -- "否" --> R3
    I -- "是" --> J{"J【判断】同槽同类型当前值恰一且与槽指向一致？"}
    J -- "否" --> R3
    J -- "是" --> K{"K【判断】I64材料、来源节点和生命周期正确？"}
    K -- "否" --> R3
    K -- "是" --> L{"L【判断】值落在P25定义上下界内？"}
    L -- "否" --> R3
    L -- "是" --> M["M【指令】按P24主体/定义/槽顺序形成完整项"]
    M --> R7["R7【返回】已读取；完整=true；诊断空"]
```

## 3. 字段与所有权

```mermaid
flowchart LR
    A["P24槽结构"] --> O["P26完整当前特征投影"]
    B["P25定义详情"] --> O
    C["P23当前I64值属性类型"] --> O
    D["P17属性槽/值/来源/生命周期"] --> O
    E["快照其它槽和值"] --> X["不召回、不夹带"]
```

P26 只解释实例槽当前属性和值；P24 关系结构和 P25 定义详情保持其原事实所有权。I64 上下界复核是定义值域准入，不调用比较算法。
