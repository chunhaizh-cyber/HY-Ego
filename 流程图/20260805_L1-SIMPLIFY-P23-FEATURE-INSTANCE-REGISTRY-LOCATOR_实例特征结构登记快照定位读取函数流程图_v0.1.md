对应详细设计：`规范/详细设计/20260805_L1-SIMPLIFY-P23-FEATURE-INSTANCE-REGISTRY-LOCATOR_实例特征结构登记快照定位读取详细设计_v0.1.md`

## 1. 首次登记结果形成定位见证

```mermaid
flowchart TD
    A["A【输入】P3实例特征登记结果"] --> B{"B【判断】状态为已提交或幂等读回且登记存在"}
    B -- "否" --> R1["R1【返回】空见证"]
    B -- "是" --> C{"C【判断】登记版本/发布代次/四编码完整且两两唯一"}
    C -- "否" --> R1
    C -- "是" --> D["D【指令】复制登记并标记来源=首次登记结果"]
    D --> R2["R2【返回】不可变定位见证；零服务/零L1调用"]
```

`已读取` 缓存结果不得冒充首次登记来源；恢复装配见证由未来具名 provider 按同一完整性合同形成。

## 2. `L1实例特征服务::从快照读取登记定位`

```mermaid
flowchart TD
    A["A【输入】定位请求 + 调用方传入的一份P17完整快照"] --> B{"B【判断】请求版本是否匹配"}
    B -- "否" --> R1["R1【返回】入口拒绝；空事实/诊断"]
    B -- "是" --> C{"C【判断】定位见证是否存在"}
    C -- "否" --> R2["R2【返回】登记未加载；不读缓存不扫描"]
    C -- "是" --> D{"D【判断】见证来源/版本/发布代次/四编码完整且唯一"}
    D -- "否" --> R1
    D -- "是" --> E{"E【判断】快照非零且当前节点组稳定排序、唯一、生命周期完整"}
    E -- "否" --> R3["R3【返回】内部不一致 + 快照损坏诊断"]
    E -- "是且快照早于登记" --> R4["R4【返回】事实代次漂移"]
    E -- "是" --> F["F【指令】仅按四个见证编码二分查找当前节点"]
    F --> G{"G【判断】命中数量"}
    G -- "0" --> R5["R5【返回】未找到；不扫描替代"]
    G -- "1至3" --> R6["R6【返回】内部不一致 + 部分缺失诊断"]
    G -- "4" --> H{"H【判断】三普通节点 + 一I64属性类型节点形状准确"}
    H -- "否" --> R7["R7【返回】内部不一致 + 角色形状诊断"]
    H -- "是" --> I{"I【判断】四创建代次均等于登记发布代次"}
    I -- "否" --> R8["R8【返回】内部不一致 + 发布代次诊断"]
    I -- "是" --> J["J【指令】形成固定四角色当前节点见证；截止=P17快照代次"]
    J --> R9["R9【返回】已读取、完整=true、诊断空"]
```

根函数是静态纯函数：不访问 `this/登记_/锁_`，不调用 P17、L1 或其它领域 provider。

## 3. 后继依赖与锁边界

```mermaid
flowchart LR
    A["P17尝试读取完整快照"] --> B{"P17结果"}
    B -- "许可拒绝/资源失败/内部不一致" --> C["调用方直接返回；P23调用0"]
    B -- "成功" --> D["调用方拥有的一个纯值快照"]
    E["首次登记结果或恢复装配定位见证"] --> F["P23请求"]
    D --> G["P23从快照读取登记定位"]
    F --> G
    G --> H["同截止实例特征登记定位事实"]
    H --> I["后继全部当前实例特征读取"]
```

P17 返回前已释放 L1 许可；P23 不重新取得任何许可。登记见证只提供候选四编码，成功仍由同一 P17 当前快照互证。
