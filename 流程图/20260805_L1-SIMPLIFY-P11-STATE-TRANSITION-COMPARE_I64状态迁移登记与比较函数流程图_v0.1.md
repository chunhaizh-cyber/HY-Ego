# I64 状态迁移登记与比较函数流程图 v0.1

## 登记迁移合同

```cpp
I64状态迁移比较合同结果 特征比较服务::登记I64状态迁移比较合同(
    const I64状态迁移比较合同登记请求& 请求);
```

```mermaid
flowchart TD
    A[接收固定状态迁移合同登记请求] --> B{版本 幂等身份 期望代次\nP2定义与实例登记完整?}
    B -- 否 --> X1[入口拒绝 空合同]
    B -- 是 --> C[读取一次L1完整快照]
    C --> D{服务登记 P2定义三值\n实例登记均同代次有效?}
    D -- 否 --> X2[映射漂移 未找到或内部错误]
    D -- 是 --> E{特征定义加状态迁移\n已有当前路由?}
    E -- 同义 --> R[按正式编码独立读回合同]
    E -- 异义或多路由 --> X3[幂等冲突或内部不一致]
    E -- 无 --> F[构造0x0E单写集]
    F --> G[一注册节点 一配置值 一槽\n七条节点目标字段关系]
    G --> H{L1提交成功或精确重复?}
    H -- 否 --> X4[映射结构化非成功]
    H -- 是 --> R
    R --> I{配置 七关系 七节点\nP2三值完整互证?}
    I -- 否 --> X5[内部不一致 空合同]
    I -- 是 --> Z[返回当前迁移合同]
```

## 比较状态迁移

```cpp
I64状态迁移比较结果 特征比较服务::比较I64状态迁移(
    const I64状态迁移比较请求& 请求) const;
```

```mermaid
flowchart TD
    A[接收前状态 后当前和预期截止] --> B{请求有效且P9 P8已绑定?}
    B -- 否 --> X1[入口拒绝 零载荷]
    B -- 是 --> C[读取起始L1完整快照G0]
    C --> D[调用P9读取不可变前状态]
    D --> E[调用P8读取存在宿主后当前]
    E --> F[读取结束L1完整快照G1]
    F --> G{G0 G1 P9 P8和预期截止相同?}
    G -- 否且未重试 --> C
    G -- 否且已重试 --> X2[版本漂移 零载荷]
    G -- 是 --> H[仅取P8真实P2定义\n路由定义加状态迁移合同]
    H --> I{唯一当前注册?}
    I -- 无 --> X3[未注册]
    I -- 多个或损坏 --> X4[内部不一致]
    I -- 是 --> J{同主体 同采样场景\n同实例槽和真实定义?}
    J -- 否 --> X5[左右角色或定义拒绝]
    J -- 是 --> K{旧值在前状态后退出\n新值创建不早于旧值退出\n类型 单位 维度 值域合法?}
    K -- 否 --> X6[时间 类型或值域拒绝]
    K -- 是 --> L[固定旧值为左 新值为右]
    L --> M[安全比较三态]
    M --> N{新减旧可由I64表示?}
    N -- 否 --> X7[差异不可表示 全部比较载荷空]
    N -- 是 --> O[计算新减旧并裁决等价]
    O --> P{材料关系}
    P -- 增加 --> Q1[-1 状态迁移增加 非等价]
    P -- 相等 --> Q2[0 状态迁移等价 等价且差异0]
    P -- 减少 --> Q3[1 状态迁移减少 非等价]
    Q1 --> Z[返回注册身份 完整输入和纯值证据]
    Q2 --> Z
    Q3 --> Z
```

边界：比较服务不解析关系19，只消费P9完整DTO；不发布第二状态、关系20、动态或因果。3F只能消费成功纯值证据，不能提供算法、注册或动态身份。
