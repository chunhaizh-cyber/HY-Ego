# 真实当前值变化与中性状态动态原子记录业务流程图

日期：2026-08-28
版本：v0.1
状态：目标业务流程

```mermaid
flowchart TD
    A["调用方已裁决新值并冻结 G0"] --> B["正式读取特征实例与旧当前值"]
    B --> C{"请求旧值是否等于正式当前值"}
    C -- "否" --> X1["当前性漂移或引用冲突，零写"]
    C -- "是" --> D{"新值是否等于旧值"}
    D -- "是" --> N["无变化：返回旧当前值与 G0，零记录"]
    D -- "否" --> E["读取固定角色的中性当前状态选择"]
    E --> F{"是否有恰一完整中性前状态"}
    F -- "是" --> G["采用现行中性前状态"]
    F -- "否且无选择" --> H["受约束读取 legacy 首态"]
    H --> I{"legacy 是否唯一且与旧值匹配"}
    I -- "否" --> X2["材料不足，零写"]
    I -- "是" --> J["预形成迁移时刻旧值中性基线"]
    F -- "多义或坏闭包" --> X3["内部错误，零写"]
    G --> K["预形成新当前值、新中性状态和新选择"]
    J --> K
    K --> L["预形成状态迁移动能与上下文"]
    L --> M{"有正式来源方法"}
    M -- "是" --> O["预形成动作致变动态及同源关系"]
    M -- "否" --> P["不建立动作致变动态"]
    O --> Q["参与者1特征 / 2状态 / 3动态"]
    P --> Q
    Q --> R["提交 L1 三分区原子事务 v2"]
    R --> S{"提交结果"}
    S -- "失败且未交换" --> X4["结构化失败，零公开变化"]
    S -- "已可能发布" --> X5["仅返回提交见证，原请求重放"]
    S -- "已提交或精确重复" --> T["以首次 G1 正式独立读回"]
    T --> U{"当前值 / 状态 / 选择 / 动态 / 上下文是否完整"}
    U -- "否" --> X5
    U -- "是" --> V["返回完整变化结果与 G1"]
```

## 接线边界

```text
业务规则只负责裁决新值、主体、共同场景和来源
L2组合服务只负责结构、引用、幂等、原子发布和读回
特征当前值是后继比较权威
状态/动态只保存记录、上下文和变化证据
```

本图不包含安全/服务维护规则、根需求自检和任务执行；这些是阶段三及后继流程。
