# L1-SIMPLIFY-P3-FEATURE-INSTANCE 建立初始场景 I64 实例特征函数流程图 v0.2

依据：P3 v0.2 详细设计、P2 非空 L1 组合登记补充设计、4015/0050；目标函数图，不描述当前代码已实现能力。

## 函数合同

```text
根函数：L1实例特征服务::建立初始场景I64实例特征
调用顺序前置：世界登记 -> 初始场景 -> P2登记/定义 -> P3登记
返回：I64实例特征结果；成功/幂等、具名非成功、资源失败或内部不一致
```
