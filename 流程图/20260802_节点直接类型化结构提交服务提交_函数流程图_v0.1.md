## 节点合同

| 节点 | 类型 | 输入 / 输出 | 事实读写 | 后继 / 验证 |
| --- | --- | --- | --- | --- |
| N01—N02 | 本函数内指令 | 请求 -> 准入分类 | 无 | 坏请求不调用数据操作、持久端口和执行器 |
| N03 | 本函数内指令 | 服务请求 -> 数据操作请求；验证请求意图摘要/执行证据摘要均非全零并原样保留 | 无 | 逐字段复制，不按布局转换；L1 不计算、不重算、不解释任一摘要 |
| N04 | 函数调用 | 数据操作请求 -> 数据操作结果 | 数据操作形成中性规格并调用执行器原子裁决 | 双向引用内部事务图 |
| N05 | 本函数内指令 | 数据操作结果 -> 服务结果或内部不一致 | 无 | 明确状态映射；只有提交/幂等允许成功读回 |
| R01—R03 | 本函数内指令 | 分类 -> 返回值 | 无 | 全部分支返回具名结果 |

