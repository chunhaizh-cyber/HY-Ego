## 流程图

```mermaid
flowchart TD
    A["N01【指令】校验请求并读取G0"] --> B{"N02【指令-判断】请求和G0有效?"}
    B -- 否 --> X1["X01【指令-返回】入口拒绝 空载荷"]
    B -- 是 --> C["N03【函数调用】P10/P8读取当前事实(请求) -> 当前事实"]
    C --> D{"N04【指令-判断】当前事实完整且截止等于G0?"}
    D -- 否 --> X2["X02【指令-返回】对应非成功 空载荷"]
    D -- 是 --> E["N05【函数调用】L1状态服务::选择实际存在I64相邻前状态(P12请求) -> P12结果"]
    E --> F{"N06【指令-判断】P12状态?"}
    F -- 无前状态 --> X3["X03【指令-返回】无前状态 零规格"]
    F -- 非成功 --> X4["X04【指令-返回】映射P12非成功 空载荷"]
    F -- 已选择 --> G["N07【指令】直接绑定P12完整前状态和选择证据为P11左输入"]
    G --> H["N08【函数调用】特征比较服务(前状态, 当前事实) -> 比较结果"]
    H --> I{"N09【指令-判断】比较和身份见证完整?"}
    I -- 否 --> X5["X05【指令-返回】不可比较或内部不一致 空载荷"]
    I -- 是 --> J["N10【指令】读取G1并校准共同截止"]
    J --> K{"N11【指令-判断】G0/provider/G1同代次?"}
    K -- 否且未重试 --> A
    K -- 否且已重试 --> X6["X06【指令-返回】版本漂移 空载荷"]
    K -- 是 --> L["N12【函数调用】L1状态服务::形成已校准实际存在I64后继状态规格(纯值材料) -> 状态规格"]
    L --> M{"N13【指令-判断】规格结构和本地键完整?"}
    M -- 否 --> X5
    M -- 等价 --> S1["S01【指令-返回】已形成 禁止生成迁移动能"]
    M -- 增加或减少 --> S2["S02【指令-返回】已形成 允许形成迁移动能规格"]
```

P12 只在 N05 调用一次；其 `已选择` 返回已完成 P9 读回互证的完整前状态，P13 不再另造 P9 调用。P12 v0.4 专项仍由既有顺序360承载，不新增顺序370。
