# L1-SIMPLIFY-P15-POST-PUBLISH-READBACK L1提交内通用发布后读回隔离函数流程图 v0.1

日期：2026-08-05

状态：设计就绪；代码未实现

## 1. 普通提交与通用发布后读回

```mermaid
flowchart TD
    A[接收版本2 L1写集和非空通用读回计划] --> B{合同 计划 覆盖 引用 幂等有效}
    B -- 否 --> X1[入口拒绝 零发布]
    B -- 是 --> C[规范化写集和读回计划]
    C --> D[取得仓库唯一独占锁]
    D --> E{仓库已隔离或状态损坏}
    E -- 是 --> X2[内部不一致 零后继写]
    E -- 否 --> F{幂等键已存在}
    F -- 同义 --> X3[返回首次代次 映射和完整读回]
    F -- 异义 --> X4[幂等冲突]
    F -- 未找到 --> G[复核期望事实代次]
    G --> H[形成并完整校验候选]
    H --> I[形成预期读回 幂等账 提交审计]
    I --> J[预留失败审计容量并预构造见证]
    J --> K[swap发布权威状态并推进一次代次]
    K --> L[仍持独占锁按映射从权威状态重新读回]
    L --> M{项目逐字段和生命周期全部一致}
    M -- 是 --> N[返回成功 完整读回并释放锁]
    M -- 否 --> O[先单调设置隔离]
    O --> P[无分配安装失败见证和审计]
    P --> Q[返回内部不一致 已发布代次 映射和见证身份]
```

## 2. 通用计划覆盖与解析

```mermaid
flowchart TD
    A[规范化读回项目] --> B[每个新节点关系值匹配一个同种类当前项目]
    B --> C[每个退出编码匹配一个本次发布退出项目]
    C --> D[每个槽变更匹配一个当前槽项目]
    D --> E{遗漏 重复 异义或错种类}
    E -- 是 --> X1[swap前入口拒绝]
    E -- 否 --> F[允许追加既有稳定编码中性互证]
    F --> G[本地键只从本次映射解析]
    G --> H[稳定编码只从当前或历史权威表解析]
    H --> I[节点 关系 值 槽逐字段比较]
```

## 3. 失败见证与隔离恢复

```mermaid
flowchart TD
    A[发布后读回矛盾] --> B[独占锁内设置当前隔离]
    B --> C[安装幂等键加审计序号失败见证]
    C --> D[追加发布后读回失败隔离审计]
    D --> E[普通提交 当前历史快照读取均拒绝]
    D --> F[审计读取仍可取得完整失败证据]
    F --> G[建立既有两阶段恢复候选]
    G --> H{材料完整互证并包含原失败见证}
    H -- 否 --> X1[材料不完整 保持隔离]
    H -- 是 --> I[确认恢复候选并原子替换]
    I --> J{恢复发布后权威读回成功}
    J -- 否 --> X2[内部不一致 继续隔离]
    J -- 是 --> K[解除当前隔离 保留历史失败见证和审计]
```

流程中不存在领域回调、第二L1写请求、SQL运行期裁决、事实扫描猜测、swap回滚、删除或补偿写。
