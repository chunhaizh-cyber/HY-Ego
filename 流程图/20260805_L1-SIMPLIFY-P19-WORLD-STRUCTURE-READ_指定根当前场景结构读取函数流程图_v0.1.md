## 1. `L1场景结构服务::读取当前世界结构`

```mermaid
flowchart TD
    A["A【输入】当前世界结构读取请求"] --> B{"B【判断】合同/规则/读取规则和指定根形状有效"}
    B -- "否" --> R1["R1【返回】入口拒绝；provider调用0"]
    B -- "是" --> C["C【函数调用】P18 尝试读取当前登记"]
    C --> D{"D【判断】P18成功且登记完整"}
    D -- "许可竞争" --> R2["R2【返回】许可拒绝；零等待零重试"]
    D -- "未加载/坏成功/异常" --> R3["R3【返回】内部不一致；空事实"]
    D -- "成功" --> E{"E【判断】指定根等于正式登记根"}
    E -- "否" --> R4["R4【返回】未找到；P17调用0"]
    E -- "是" --> F["F【函数调用】P17 尝试读取完整快照"]
    F --> G{"G【判断】成功且快照代次非零"}
    G -- "许可竞争" --> R2
    G -- "资源失败" --> R5["R5【返回】资源失败；空事实"]
    G -- "其它非成功/坏成功" --> R3
    G -- "是" --> H["H【指令】在唯一纯值快照中互证登记五身份和生命周期"]
    H --> I["I【指令】按场景标记识别全部当前场景"]
    I --> J["J【指令】校验根/唯一父/环/可达闭包和全部父关系"]
    J --> K["K【指令】校验全部当前成员关系和唯一归属"]
    K --> L["L【指令】形成并稳定排序缺项诊断"]
    L --> M{"M【判断】缺项是否为空"}
    M -- "否" --> R6["R6【返回】内部不一致；空事实+完整稳定诊断"]
    M -- "是" --> N["N【指令】按稳定编码排序场景/父子/成员组"]
    N --> R7["R7【返回】已读取；完整=true；截止=P17快照代次；缺项空"]
```

## 2. 场景与直接关系解释边界

```mermaid
flowchart LR
    A["P18不可变登记定位"] --> D["L1场景结构服务"]
    B["P17当前L1纯值快照"] --> D
    D --> E["场景标记值=1的当前普通节点"]
    D --> F["登记父关系类型的当前关系"]
    D --> G["登记成员关系类型的当前关系"]
    E --> H["指定根当前可达场景组"]
    F --> I["直接父子关系组"]
    G --> J["直接成员关系组"]
    J -. "只证明结构归属" .-> K["后继存在服务互证P7实际存在资格"]
```

L2 组合器不得直接消费 A、B 后复制本图解释；只能调用场景结构服务的公开结果。

## 3. `L1场景结构服务::读取当前事实代次`

```mermaid
flowchart TD
    A["A【输入】当前世界事实代次读取请求"] --> B{"B【判断】合同/规则/根形状有效"}
    B -- "否" --> R1["R1【返回】入口拒绝+代次0"]
    B -- "是" --> C["C【函数调用】P18 尝试读取当前登记"]
    C --> D{"D【判断】成功且请求根等于正式根"}
    D -- "许可竞争" --> R2["R2【返回】许可拒绝+0"]
    D -- "根不等" --> R3["R3【返回】未找到+0"]
    D -- "其它非成功" --> R4["R4【返回】结构化非成功+0"]
    D -- "是" --> E["E【函数调用】P17 尝试读取当前事实代次"]
    E --> F{"F【判断】成功且代次非零"}
    F -- "否" --> R4
    F -- "是" --> R5["R5【返回】已读取+P17当前事实截止代次"]
```

P18 的 `已验证事实代次` 不进入 R5；后继总快照以本函数作为 G1 场景领域门面。
