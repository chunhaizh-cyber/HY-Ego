## 1. `L1特征定义服务::尝试读取当前登记`

```mermaid
flowchart TD
    A["A【输入】特征定义登记读取请求"] --> B{"B【判断】合同版本和规则版本是否匹配"}
    B -- "否" --> R1["R1【返回】入口拒绝，空登记；锁尝试0"]
    B -- "是" --> C["C【指令】以try_to_lock尝试一次特征定义服务锁"]
    C --> D{"D【判断】是否取得服务锁"}
    D -- "否" --> R2["R2【返回】许可拒绝，空登记；零等待零重试"]
    D -- "是" --> E["E【函数调用】复制已持锁当前登记"]
    E --> F{"F【判断】登记缓存是否存在"}
    F -- "否" --> R3["R3【返回】登记未加载，空登记；不扫描L1"]
    F -- "是" --> G{"G【判断】合同/规则/验证代次和四编码完整且两两唯一"}
    G -- "否" --> R4["R4【返回】内部不一致，空登记"]
    G -- "是" --> H["H【指令】逐字段复制不可变定位材料"]
    H --> R5["R5【返回】已读取，完整登记副本；返回前释放锁"]
    H -. "bad_alloc" .-> R6["R6【返回】资源失败，空登记"]
    H -. "其它异常" .-> R4
```

## 2. 定义定位与后继当前特征事实分账

```mermaid
flowchart LR
    A["P22 尝试读取特征定义登记"] --> B["服务身份/定义标记类型/I64上下界类型/登记验证代次"]
    C["后继实例特征结构登记非阻塞定位"] --> D["宿主槽关系类型/定义模板关系类型/当前I64值类型"]
    E["P17 尝试读取完整快照"] --> F["当前节点/关系/值/槽及事实截止代次"]
    G["P21 当前实际存在资格集合"] --> H["指定根合法宿主范围及共同截止"]
    B --> I["后继全部当前实例特征读取"]
    D --> I
    F --> I
    H --> I
    I --> J["在一个P17副本中解释真实定义、实例槽、当前值、材料和来源"]
    B -. "登记验证代次不得冒充当前截止" .-> F
```

本叶只形成 A—B。P22 返回并释放特征定义服务锁后，后继才可调用其它 provider；禁止跨 provider 持锁。

## 3. 新旧入口唯一解释

```mermaid
flowchart TD
    O["P2既有读取当前登记：阻塞兼容入口"] --> L1["取得阻塞锁"]
    N["P22尝试读取当前登记：STEP-4非阻塞入口"] --> L2["尝试一次服务锁"]
    L1 --> P["唯一私有复制已持锁当前登记"]
    L2 --> P
    P --> U["未加载/坏登记/完整副本唯一判定"]
```

禁止为新入口建立第二登记缓存或复制登记完整性判断。
