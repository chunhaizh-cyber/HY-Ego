## 1. `L1事实基座服务::尝试读取完整快照`

```mermaid
flowchart TD
    A["A【输入】L1完整快照读取请求"] --> B{"B【判断】合同版本是否为实际L1 v2"}
    B -- "否" --> R1["R1【返回】入口拒绝，空快照"]
    B -- "是" --> C["C【函数调用】仓库.尝试读取完整快照"]
    C --> D["D【指令】以try_to_lock尝试一次共享许可"]
    D --> E{"E【判断】是否取得许可"}
    E -- "否" --> R2["R2【返回】许可拒绝，空快照；零等待零重试"]
    E -- "是" --> F{"F【判断】隔离是否成立且权威状态是否完整"}
    F -- "隔离或损坏" --> R3["R3【返回】内部不一致，空快照"]
    F -- "完整" --> G["G【函数调用】唯一私有形成完整快照副本"]
    G --> H["H【指令】复制当前节点/关系/值/永久编码和事实代次"]
    H --> I["I【指令】四组按稳定编码升序排序"]
    I --> J{"J【判断】副本是否完整且代次等于持锁权威状态"}
    J -- "否" --> R3
    J -- "是" --> R4["R4【返回】成功，完整纯值副本；返回前释放许可"]
    G -. "bad_alloc" .-> R5["R5【返回】资源失败，空快照"]
    G -. "其它异常" .-> R3
```

既有阻塞式 `读取完整快照` 也复用 `形成完整快照副本`，但本叶不迁移旧调用点。STEP-4 后继领域读取只能使用本图的新非阻塞入口。

## 2. `L1事实基座服务::尝试读取当前事实代次`

```mermaid
flowchart TD
    A["A【输入】L1事实代次读取请求"] --> B{"B【判断】合同版本是否为实际L1 v2"}
    B -- "否" --> R1["R1【返回】入口拒绝，代次0"]
    B -- "是" --> C["C【函数调用】仓库.尝试读取当前事实代次"]
    C --> D["D【指令】以try_to_lock尝试一次共享许可"]
    D --> E{"E【判断】是否取得许可"}
    E -- "否" --> R2["R2【返回】许可拒绝，代次0；零等待零重试"]
    E -- "是" --> F{"F【判断】隔离是否成立且权威状态是否完整"}
    F -- "隔离或损坏" --> R3["R3【返回】内部不一致，代次0"]
    F -- "完整" --> G["G【指令】复制权威状态事实代次"]
    G --> H{"H【判断】代次是否非零"}
    H -- "否" --> R4["R4【返回】未找到，代次0"]
    H -- "是" --> R5["R5【返回】成功，非零事实截止代次；返回前释放许可"]
    C -. "异常" .-> R3
```
