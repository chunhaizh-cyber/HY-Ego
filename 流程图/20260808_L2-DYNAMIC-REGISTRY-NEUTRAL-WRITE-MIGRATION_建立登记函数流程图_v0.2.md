# L2-DYNAMIC-REGISTRY-NEUTRAL-WRITE-MIGRATION 建立登记函数流程图 v0.2

日期：2026-08-08

根函数：`L1动态服务::建立登记(const L1动态登记请求&)`

边界：只画这一根函数及其直接调用的私有校验 / 读回步骤；不画 `读取当前登记`、状态迁移动能规格、其它状态动态逻辑或 L1 内部事务实现。图是目标设计，不是当前代码事实。v0.2 的关键裁决是提交前代次预读只做入口健康和首次成功诊断，不提前阻断精确重复到达 L1。

```mermaid
flowchart TD
    A["进入建立登记，请求为调用方值"] --> B["取得L1动态服务递归互斥锁并进入异常边界"]
    B --> C{"合同、规则、幂等身份、期望事实代次是否合法"}
    C -- "否" --> R0["返回入口拒绝，不带登记，零提交"]
    C -- "是" --> D["预读P：调用读取中性当前事实代次"]
    D --> E{"预读成功、合同正确且P非零"}
    E -- "否" --> R1["映射读取非成功，不带登记，零提交"]
    E -- "是；不比较P与请求期望后提前返回" --> G["以保留域0x0F映射不透明中性幂等键"]
    G --> H["形成固定中性写集：10节点、0关系、0值、0槽变更、0退出；保留原期望代次"]
    H --> I["恰一次调用提交中性写集"]
    I --> J{"L1写入状态"}
    J -- "幂等冲突" --> RC["返回幂等冲突，不带登记"]
    J -- "事实代次漂移" --> RD["返回版本漂移，不带登记"]
    J -- "其它非成功" --> R3["映射未找到、入口拒绝、资源失败或内部不一致，不带登记"]
    J -- "成功" --> K0{"P等于请求期望代次"}
    K0 -- "否；L1成功与冻结顺序矛盾" --> RI["返回内部不一致，不带登记"]
    K0 -- "是" --> K1["核对首次成功合同：版本、键、非零首次发布代次、发布标志true、重试不适用"]
    J -- "精确重复；允许P高于原期望" --> K2["核对重复合同：版本、键、非零首次发布代次、发布标志false、原幂等键读回收敛"]
    K1 --> L{"成功合同及十项新编码映射是否完整唯一"}
    K2 --> L
    L -- "否" --> RI
    L -- "是" --> M["按1至10固定顺序取得首次十个稳定编码"]
    M --> N["读回G0：读取中性当前事实代次"]
    N --> O{"G0成功、合同正确且非零"}
    O -- "否" --> R4["映射读取非成功，不带登记"]
    O -- "是" --> P["循环十编码：逐项调用读取中性当前节点"]
    P --> Q{"每项成功、查询编码一致、读取代次等于G0、节点未退出且形状匹配"}
    Q -- "读取非成功" --> R5["映射读取状态，不带登记"]
    Q -- "成功但字段或形状矛盾" --> RI
    Q -- "十项全部成立" --> S["读回G1：再次读取中性当前事实代次"]
    S --> T{"G1成功、合同正确、非零且等于G0"}
    T -- "读取非成功" --> R6["映射读取状态，不带登记"]
    T -- "G1或节点代次不等G0" --> RD
    T -- "是" --> U["组装现有L1动态结构登记；事实截止代次取G0，不要求等于首次发布代次"]
    U --> V{"登记完整性校验通过"}
    V -- "否" --> RI
    V -- "是" --> W["更新非权威登记定位缓存"]
    W --> X["首次成功与精确重复统一返回已登记并携带当前读回登记"]
    B -. "bad_alloc" .-> RA["返回资源失败，不带登记"]
    B -. "其它异常" .-> RI
```

## 顺序与数据形状

```text
领域预读 P
-> 不提前比较 P 与请求期望并返回
-> 恰一次提交完整原请求
-> L1：精确重复 -> 同键异义 -> 期望代次漂移 -> 首次候选发布
-> 成功类按首次十编码读取当前 G0 / G1
```

固定节点形状：1—2 为普通节点；3—5 为 I64 属性类型；6—7 为 U64组属性类型；8 为 I64 属性类型；9 为 U64组属性类型；10 为 I64组属性类型。业务操作标签、意图组、入口变体、领域意图凭证、旧幂等探测、完整快照和首次请求缓存不进入本流程。
