## 函数合同

根函数：`L1提交内通用发布后读回服务::形成首次执行证据`

新增只读入口：`L1事实可重建索引::读取提供者身份() const noexcept`、`L1场景结构服务::读取提供者身份() const noexcept`。它们分别返回 P-I `(0x4C31495800000001,1,1)` 与 P-S `(0x4C31534300000001,2,1)`；L1 provider 仍返回 `(0x4C31464200000001,2,0)`。

## 流程图

```mermaid
flowchart TD
 A["编码公开请求意图"] --> B["L1探测幂等(意图)"]
 B --> C{"未找到?"}
 C -- 否 --> D["账读回/冲突/隔离，provider 0/0"]
 C -- 是 --> E{"调用点 I02/F02/X02?"}
 E -- I02 --> I["读取 P-I 身份；读取 L1-S"]
 E -- F02 --> F["读取 P-S、P-D、L1-S 身份与见证"]
 E -- X02 --> X["读取 P-E、P-S 身份与见证"]
 E -- 其它 --> L["按 v0.14 来源矩阵读取"]
 I --> V["校验身份/合同/规则、共同截止、排序"]
 F --> V
 X --> V
 L --> V
 V --> Q{"调用数=矩阵且去重数=唯一身份?"}
 Q -- 否 --> R["材料不完整或内部不一致并隔离"]
 Q -- 是 --> S["形成首次证据摘要并写幂等账/审计"]
 S --> T["一次 L1 提交与发布后读回"]
```

身份读取只产生合同见证，不改变事实代次；同一 provider 的多次读取按稳定身份去重，但调用次数保留。身份缺失、版本错、伪造来源、材料字段缺失或恢复重算不等均拒绝；本图不证明实现、构建或运行验证。
