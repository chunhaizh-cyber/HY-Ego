## 统一执行顺序

```mermaid
flowchart TD
 A["真实公开请求 DTO"] --> B["HZY-L1G6 + 格式1 + L1标签 + 变体"]
 B --> C["领域 G6 意图摘要"]
 C --> D["provider 前探测幂等"]
 D -->|同义| E["首次账/真实首次结果 DTO，0/0"]
 D -->|异义/缺字段/错标签| X["拒绝或隔离，无业务载荷"]
 D -->|未找到| P["读取 provider/场景/事实"]
 P --> Q["独立 G0 规范化写集摘要"]
 Q --> I{"标签+变体+版本+领域摘要+G0 互证"}
 I -->|失败| X
 I -->|成功| J["保留调用方领域摘要"]
 J --> K["一次 L1 v2 提交"]
 K --> L["E01登记结果或X02实际存在结果"]
 L --> M["发布后读回/恢复同点重算"]
 M --> N["施工记录与验证记录"]
```

E01 不得改用 `实际存在读取请求` 或 X02 请求；X02 不得改用读取 DTO 或 E01 登记结果。两点的标签、变体和首次结果在账、审计、读回及恢复中保持同一身份。
