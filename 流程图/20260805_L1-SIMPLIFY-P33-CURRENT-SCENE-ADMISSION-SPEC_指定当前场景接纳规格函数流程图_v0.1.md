```cpp
当前场景接纳规格结果 L1场景结构服务::形成当前场景接纳规格(

```

## 1. 调用与所有权边界

```mermaid
flowchart TD
    C["后继实际存在创建组合器"] --> F["L1场景结构服务::形成当前场景接纳规格"]
    F --> R["P18 世界登记服务::尝试读取当前登记"]
    F --> S["P19 L1场景结构服务::读取当前世界结构"]
    R --> T["直接成员关系类型"]
    S --> G["目标当前性 + P17事实截止"]
    T --> O["调用方拥有的不可变接纳规格"]
    G --> O

    F -. "禁止" .-> X1["原始P17快照/L1/仓库/SQL/锁"]
    F -. "禁止" .-> X2["扫描场景或从成员关系猜关系类型"]
    F -. "写入0" .-> X3["创建存在/提交归属/幂等账"]
```

P33 只拥有场景侧接纳解释；P18 拥有登记定位，P19 拥有当前场景结构，后继组合器拥有跨存在规格与场景规格的一次原子提交。

P33 函数体直接调用 P18 恰1次、P19 恰1次；P19 内部按其合同再次调用 P18，因此完整成功调用链中 P18 总计2次。两次均为独立 try-lock，任一许可拒绝都立即返回。

## 2. 固定函数流程

```mermaid
flowchart TD
    A["进入：版本/根/目标/期望代次"] --> B{"provider前请求完整?"}
    B -- "否" --> R1["入口拒绝；空规格；P18/P19调用0"]
    B -- "是" --> C["P18尝试读取当前登记恰1次"]
    C --> D{"P18状态"}
    D -- "许可拒绝" --> R2["许可拒绝；立即返回"]
    D -- "资源失败" --> R3["资源失败"]

    D -- "完整已读取" --> E{"请求根 == 登记根?"}
    E -- "否" --> R5["未找到；P19调用0"]
    E -- "是" --> F["P19读取当前世界结构恰1次"]

    G -- "坏成功/其它" --> R8["内部不一致"]

    J -- "恰1且完整" --> K["复制根、目标、P18直接成员关系类型、P19截止"]

```

## 3. 字段来源与代次绑定

| 输出字段 | 唯一来源 | 禁止替代 |
| --- | --- | --- |
| `指定世界根` | P19 完整事实，且等于 P18 登记根 | 请求回显、显示名、配置 |
| `目标当前场景` | P19 当前场景组唯一命中项 | 父关系出现、编码区间、缓存 |
| `直接成员关系类型` | P18 不可变正式登记 | P19 成员关系反推、扫描 L1 |
| `事实截止代次` | P19 本轮 P17 快照代次 | P18 已验证代次、时间戳、运行期纪元 |

返回后规格不保证仍是最新事实；后继唯一 L1 提交必须原样使用该截止作为期望代次。P33 不重试漂移，也不为调用方刷新规格。

## 4. 空场景与非成功边界

```mermaid
flowchart LR
    V["P19完整当前场景"] --> A["正式根场景"]
    V --> B["无子场景"]
    V --> C["无当前成员"]
    A --> S["合法形成规格"]
    B --> S
    C --> S

    X["目标不在当前场景组"] --> N["未找到"]
    Y["结构损坏/重复目标/坏成功"] --> I["内部不一致；无部分规格"]
    Z["截止不等"] --> D["版本漂移；零重试"]
```

合法空成员场景仍必须从 P18 取得直接成员关系类型；空成员不等于登记缺失，也不允许返回无类型规格。
