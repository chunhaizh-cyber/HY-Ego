## 1. `L1实际存在服务::读取当前实际存在资格集合`

```mermaid
flowchart TD
    A["A【输入】合同/规则/读取版本 + P19完整成员范围"] --> B{"B【判断】请求版本和P19完整成功形状有效"}
    B -- "否" --> R1["R1【返回】入口拒绝；P20/P17调用0"]
    B -- "是" --> C["C【指令】机械校验P19排序/非零身份并按成员稳定编码形成唯一候选"]
    C --> D{"D【判断】范围形状、排序和成员唯一性成立"}
    D -- "否" --> R2["R2【返回】内部不一致；空事实+稳定诊断；provider调用0"]
    D -- "是" --> E["E【函数调用】P20 尝试读取当前登记"]
    E --> F{"F【判断】P20成功且登记完整"}
    F -- "许可竞争" --> R3["R3【返回】许可拒绝；零等待零重试"]
    F -- "未加载" --> R4["R4【返回】未找到；空事实"]
    F -- "资源失败" --> R5["R5【返回】资源失败；空事实"]
    F -- "其它非成功/坏成功" --> R6["R6【返回】内部不一致；空事实"]
    F -- "成功" --> G["G【指令】P20返回并释放存在服务锁"]
    G --> H["H【函数调用】P17 尝试读取完整快照"]
    H --> I{"I【判断】P17成功、快照完整且代次非零"}
    I -- "许可竞争" --> R3
    I -- "资源失败" --> R5
    I -- "其它非成功/坏成功" --> R6
    I -- "是" --> J{"J【判断】P17代次等于P19成员范围截止"}
    J -- "否" --> R7["R7【返回】版本漂移；空事实；零内部重试"]
    J -- "是" --> K["K【指令】在一个P17副本中互证登记节点与全部候选资格"]
    K --> L["L【指令】按稳定规则形成并排序完整诊断"]
    L --> M{"M【判断】诊断是否为空"}
    M -- "否" --> R8["R8【返回】内部不一致；空事实+完整诊断"]
    M -- "是" --> N["N【指令】按存在稳定编码形成一一对应资格项"]
    N --> R9["R9【返回】已读取；完整=true；截止=P17=P19；诊断空"]
```

## 2. 领域所有权与字段来源

```mermaid
flowchart LR
    A["P19当前世界结构事实"] --> B["成员范围/场景与成员关系见证"]
    C["P20实际存在登记"] --> D["服务身份/资格属性类型"]
    E["P17当前L1纯值快照"] --> F["成员节点/资格槽/资格值/当前截止"]
    B --> G["P21实际存在资格集合读取"]
    D --> G
    F --> G
    G --> H["成员稳定编码排序的完整资格集合"]
    B -. "只作输入范围见证，不由P21解释L1关系" .-> H
```

P21 不调用 P19 服务，也不解析 L1 中的场景关系；调用方必须传入 P19 完整成功事实。

## 3. 空成员与全有或全无

```mermaid
flowchart TD
    A["P19成员关系组为空"] --> B["仍调用P20并释放锁"]
    B --> C["仍调用P17并校准共同非零截止"]
    C --> D{"登记节点当前且截止一致"}
    D -- "否" --> E["结构化非成功"]
    D -- "是" --> F["已读取 + 完整空资格组"]

    G["P19成员关系组非空"] --> H["逐成员扫描全部资格"]
    H --> I{"任一缺项"}
    I -- "是" --> J["内部不一致 + 空事实 + 完整诊断"]
    I -- "否" --> K["已读取 + 完整一一对应资格组"]
```

禁止返回“已通过成员的部分集合”。
