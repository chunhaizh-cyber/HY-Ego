## 1. 调用边界

```mermaid
flowchart TD
    C["后继统一世界树只读门面/治理消费者"] --> P30["读取存在完整事实"]
    P30 -->|"恰1次"| P29["读取完整世界事实快照"]
    P29 --> W["P28完整世界事实快照"]
    W --> F["P30纯值存在投影"]

    P30 -. "直接调用0" .-> N1["P19/P21/P17/P22/P24—P28"]
    P30 -. "禁止" .-> N2["L1解析/仓库/SQL/缓存/历史"]
    P30 -. "禁止" .-> N3["第二整树读取/重试/写事实"]
```

P30 不形成第二世界读取链。P29 内部最多两轮是唯一漂移重试；P30 无额外 provider 或重试。

## 2. 公开函数流程

```mermaid
flowchart TD
    A["进入读取存在完整事实"] --> V{"世界请求/投影规则/目标见证有效?"}
    V -->|"否"| RI["入口拒绝\nP29调用0/空载荷"]
    V -->|"是"| R["调用P29整树读取恰1次"]
    R -->|"普通非成功"| M["同名映射\n空子快照/空缺项"]
    R -->|"内部不一致"| MI["内部不一致\n稳定缺项原样转交"]
    R -->|"坏成功"| BI["内部不一致\n空子快照"]
    R -->|"已读取完整快照"| E{"目标在存在组恰一命中?"}
    E -->|"零命中"| NF["未找到\n空子快照"]
    E -->|"重复/异内容"| II["内部不一致\n稳定缺项"]
    E -->|"是"| S{"当前场景和归属恰一闭合?"}
    S -->|"否"| II
    S -->|"是"| H{"宿主特征组恰一且完整?"}
    H -->|"否"| II
    H -->|"是"| ST["筛选主体为目标的状态组"]
    ST --> D["筛选主体/来源/改变目标相关动态组"]
    D --> Q{"状态动态端点与目标范围闭合?"}
    Q -->|"否"| II
    Q -->|"是"| O["保持P28稳定顺序形成子快照"]
    O --> OK["已读取\n同根同次/完整=true/缺项空"]

    A -. "bad_alloc" .-> RM["资源失败\n不二次调用P29"]
    A -. "其它异常" .-> RX["内部不一致\n不二次调用P29"]
```

## 3. 唯一字段来源

| 输出字段 | 唯一来源 | 规则 |
| --- | --- | --- |
| 合同/世界/组合/完整性/排序版本 | P28完整快照 | 必须等于正式常量 |
| 投影规则版本 | P30常量1 | 请求必须精确等于1 |
| 世界根/截止 | P29成功快照 | 原样复制，截止非零 |
| 存在 | P28存在组唯一目标 | 当前树成员恰一命中 |
| 存在内当前场景/归属 | P28存在事实 + 场景组校验 | 场景和归属双向闭合；不复制完整场景组 |
| 宿主特征 | P28宿主特征组 | 目标恰一组；零槽为空vector |
| 状态组 | P28状态组稳定子序列 | 主体等于目标 |
| 动态组 | P28动态组稳定子序列 | 主体/来源为目标或改变目标属于目标槽 |
| 完整 | 全部检查后的true | 任一失败不形成部分子快照 |
| 缺项 | P28稳定诊断类型 | 仅内部不一致可非空 |

## 4. 合法空组与范围

```mermaid
flowchart LR
    A["目标是当前树成员"] --> B["当前场景/归属闭合"]
    B --> C["宿主组存在但实例特征为空"]
    C --> D["相关状态/动态为空"]
    D --> OK["合法完整成功"]

    X["移出树但仍存在/历史事实"] --> NF["未找到\n不得扫描或回源"]
```

P30 只在整树中验证当前场景和归属；输出由目标存在事实携带这两个见证，不复制当前场景的其它子场景或成员关系。
