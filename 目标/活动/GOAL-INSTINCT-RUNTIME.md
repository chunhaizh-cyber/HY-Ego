## 1.1 目标问题与优先级

目标问题是现行系统尚未具备经正式世界事实、实例特征和现实锚点驱动的多轮本能运行闭环。它是当前已确认的最高路线目标；优先级由用户确认、8120的启动顺序和8300的集成验收门槛共同决定。

## 2. 目标结果、范围与排除

目标结果是在正式启动与恢复后，系统能够基于权威世界事实、实例特征和本能根运行锚点，进入受治理的自我运行线程；经需求、任务、方法、实际作用、实际读回、结算与后继决议形成连续多轮运行基础。

本目标消费而不重新定义世界事实、IF/R、根特征值域、特征当前采用、根需求或线程机器合同；这些分别受现行正式规范及后续合法设计包约束。观察候选、日志、缓存、代码提交、构建成功或启动成功不得被当作世界事实、持续运行或集成能力完成。

## 3. 完成条件与证据下限

1. 正式启动 / 恢复能够读回世界根、真实自我、方法登记根、IF/R 所需事实和完整本能根运行锚点；
2. 安全与服务根的实际 F、独立根需求 D、根列表项 L 和当前成员关系均按其 owner 合同建立、恢复和同截止读回；
3. 运行门开放后，需求到任务、方法选择、实际作用、实际读回、结算和下一轮决议可按正式合同连续运行；
4. 按`规范/8300_子规范_自我内部循环最小生命闭环验收_20260720.md`达到第 7 级工程验收，证明没有重复任务风暴、无限派生、空转或主链断裂；
5. 具名正式集成验收在精确提交基线上通过。

最低证据为每个下位目标的正式设计、代码、构建 / 运行 / 恢复记录及最终具名集成验收；任何较低层证据只证明其自身范围。
