## 2. 问题、目标结果与优先级

仅验证给定词条后的反问，不能证明初始化、网页真实入站、自我认知和任务筹办已经接通。本目标从网页原始输入开始，经正式治理组织交互，回答关联原问题并继续原理解工作；已有需求D时保持同一D，信息充分后由自我决定承接并交任务管理建立任务。

未知词面可能早于完整需求D的形成，不得为进入追问先伪造完整D或词条。词边界、词条身份、概念归类、字段完整和自我承接分别判断，具体语义由现行规范及本窗口已确认的具名裁决承担。本目标为当前主推进；先修最早真实缺口，不以HTTP接纳、候选生成、输出入列或编译替代后续完成。

## 3. 阶段路线与完成条件

| 阶段 | 必须取得的结果与证据 |
| --- | --- |
| P0 启动与会话 | 实际项目编译链接通过；正常入口初始化完成，网页窗口、真实会话及必需运行依赖可用。 |
| P1 入站与认知入口 | 网页表单输入经正式接收；外设场景保留原始消息及对应状态／动态；自我取得原文、说话者、窗口和作用域。HTTP 202不单独证明认知完成。 |
| P2 理解与缺口 | 已知表达正常理解；未知范围保留固定原文、来源和范围。边界未定能询问分界；边界及规范化材料具备后在纯读之外取得词条、重解释、按需归类。不臆造切分、词义或现实事实。 |
| P3 筹办与方法 | 补全子需求经自我确认、建任务、查找／采用／执行方法；不把不完整被认知材料直接当完整任务目标。查到方法头但无可用配对时验证既有通用学习及重新筹办，不手工补配对；未触发不宣称学习链已验收。 |
| P4 正式输出 | 正式表达需求、语言知识装配及回读、发送裁决、外设入列、传输完成和网页显示分别取证，不用预置整句、回声或操作员供稿冒充自主询问。 |
| P5 回答接续 | 真实回答关联原问题／原文范围；分界、归类和字段回答分别消费。按对应owner写回后重读、重理解／筹办，已有D不重复创建，不以空值冒充完成。 |
| P6 承接与退出 | 需求符合正式规格后，自我决定并确认承接，任务管理建立对应任务；邮箱接纳不等于任务已建立。测试结束主动正式退出，核对线程回收及退出结果，不遗留本轮进程。 |

整体完成要求：上述阶段在精确已发布代码基线上取证，按届时现行清单完成本范围具名正式集成验收。局部样例、设计、代码提交或编译均不单独满足集成能力目标。
