## 1.1 目标问题、优先级与设计承载

当前基础I64类型入口把所有类型强制解释为外设来源，不能合法表达无外设提供者的先天定义类型；普通应用也没有形成安全值/服务值FT及其完整域顶层概念。没有这两层初始化交付，后续单值概念缺少合法完整域上位，实际F provider也无法只读取得稳定FT。

本目标优先完成：删除旧强制外设入口，系统初始化形成安全值/服务值两个先天FT和两个独立完整域概念，再由实例provider只读消费该交付形成初值实际F、IF/R和当前采用。优先级由用户已确认语义、6130双根定义和8121阶段21依赖共同决定。

设计由`计划/20260921_SYSTEM-ROOT-I64-ACTUAL-F-PROVIDER_系统根I64实际F提供者代码实施计划_v0.1.md` v0.4承载，并受1120、2220、4120、6130、7160、8120、8121约束；不另建重复详细设计。
