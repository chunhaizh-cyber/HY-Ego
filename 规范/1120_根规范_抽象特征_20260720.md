# 1120 根规范 抽象特征

编号：1120
日期：20260907
版本：v0.6
状态：正式根规范

## 1. 根定位

抽象特征是特征类型、值域、叶子或复合形态以及抽象特征结构的权威本体。正式特征类型必须由稳定的特征定义身份及其结构关系表达，不是裸词面、名称词条、名称关系、硬编码枚举或显示文本。

状态抽象统一回到抽象特征结构；不得另建与抽象特征平行的权威抽象状态树。

## 2. 本项目承载

海中鱼巣以“特征定义节点”承载抽象特征：

```text
节点类型为特征的定义节点及稳定句柄
+ 唯一非零稳定主键和当前节点句柄
+ 抽象特征之间的普通结构关系或具名组成关系
+ 值域、模板条件和语义入口的正式关系
+ 用于定位的索引
```

特征定义节点与既有实例特征槽位可以复用 `节点类型::特征`，但必须由结构角色区分：定义节点不得带有“槽位到特征定义”的模板关系；既有实例槽位必须具有唯一宿主和唯一特征定义。节点类型相同不等于业务身份相同。1130 的新特征信息只需引用正式特征类型，不以唯一宿主成立；其值域细分子节点仍属于该类型，不因成为子节点而取得特征定义身份。

词条只通过正式概念名称关系充当名称和查找材料；机器判断、需求匹配、方法能力匹配和特征值解释必须回读特征定义节点或目标概念的正式强类型身份。

## 3. 事实与边界

1. 抽象特征可以表达值域、复合组成、抽象上下位关系和状态模板条件。
2. 抽象特征不得承载实例当前值、业务完成结论、安全或服务画像、运行期评估结果。
3. 叶子与复合形态必须由正式结构关系成立，不得由名称后缀、显示类型或注释推断。
4. 同一词条即使命中一个特征名称，也只证明名称关系成立；特征类型必须从目标概念和特征定义节点读回，不得把词条改成类型入口或在词条上保存类型。
5. 不得新增硬编码“特征类型总枚举”取代特征定义节点；默认初始化可以显式创建定义节点，但结果必须进入正式抽象特征结构。
6. 实例期把多个已经成立的一次特征事实组成一个静态事实集合，不新增抽象类别定义，也不改变成员的特征定义；该结构由 4125 治理。事实集合身份、成员关系或显示名称不得反向冒充抽象特征类型、概念或归类结论。

## 4. 写入、读取与验证

抽象特征只能由特征领域服务创建、绑定和修改；数据操作层在不透明结构写入会话中完成节点、特征域类型化记录、关系和索引的原子发布。特征值服务、高级业务服务、外设、显示层和普通调用方不得直接创建或改写抽象特征。

读取方必须通过特征领域服务取得稳定定义身份、结构关系和值域材料。验证至少回读：节点当前有效、类型为特征、稳定主键唯一、定义角色成立、全部关系端点、领域记录与版本当前。

## 5. 生命周期与当前性

抽象特征身份长期存在；定义内容变化必须保留版本和来源。名称关系变化、词索引重建或显示名称变化不得改变抽象特征身份。定义失效或替换后，既有实例槽位和历史事实仍须能够回查原定义版本。

## 7. 类型完整域与长期区间

特征类型必须声明允许的完整值域、实际表示、单位、量化缩放及适用比较规则版本。完整域是该类型下顶层特征概念的定义，不等于语言无关特征本体根。标量边界、结构材料格式和不支持类型必须显式成立，不可从显示词面或某次样本推测。

本节下述“同存在同类型、首代表及校正阈值”的长期区间规则只约束既有具名观察合同，不是 1130 新特征信息的域形成算法或附加稳定门槛。新对象可以维护多个类型相容的范围，按 1130、4110 的逐域三次命中规则，由特征类接收新值后内部自动建立同类型细分子节点，保留父节点及其全部值域；不需要外层再确认稳定。类型完整域仍由本规范定义，候选域和局部子域不自动成为抽象类型或共享概念。逐域命中次数按新合同保留，不从旧观察合同额外引入宿主、版本、时间窗口或统计稳定字段；域形成规则的适用性仍须明确，不能因已固定命中阈值就默认采用旧校正算法。

既有同一存在与同一特征类型的长期区间由特征侧保存。每个区间固定首个合法观测的代表值和所采用校正阈值；此后只积累观测与实际范围，不移动代表、扩大匹配半径或改写原始值。标量匹配域为代表加减阈值后与类型完整域的交集，全部运算检查溢出；结构域是固定代表、比较版本及半径定义的类型化谓词，不能改写成距离数值的一维域。

形成范围负责观察归属，概念身份只由特征类型及规范化值域成立。区间、校正、观测、宿主和概念分别有真实身份，不可用一份应用缓存承担它们的持久事实。规则或边界变化形成新版本及新域，旧区间仍可回查。
