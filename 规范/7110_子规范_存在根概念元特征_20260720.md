# 7110 子规范 存在概念根与存在抽象边界

编号：7110

日期：20260912

版本：v1.6

状态：正式子规范

直接上级规范：2220。

直接依赖规范：1120、1130、1140、1150、1160、1170、1180、1190、7100。

相关边界规范：2210、7140、7150、7160、7210。

## 1. 定位

本规范规定 2220 存在概念根中，具体世界存在和能够作为存在处理的材料对象形成抽象的最小边界。存在概念根是语言无关本体根，不是名词词性、世界树根、场景树根、具体存在或名称。

## 2. 存在概念根

存在概念根可以从具有稳定世界身份的具体存在和能够作为存在处理的材料对象事实中形成抽象。不同来源对象可以在存在根内拥有共同上位概念，但概念身份始终独立于来源对象身份。

```text
存在概念根
-> 生物概念
   -> 鱼概念
      -> 世界存在实例叶级引用
```

以上路径只是示例，不冻结固定词面或唯一分类。真实上下位由 7140 的同一本体根内 DAG 关系成立。

## 3. 存在抽象

存在抽象描述“这些世界对象是什么类”，可以承载抽象签名、上位、定义约束和名称，但不得用具体实例当前值、位置、状态、动态、安全评估、任务结果或运行统计充当定义。特征值域、子存在类别、数量及排列关系可以作为抽象约束；具体实例是否满足它们由世界事实见证。用途计量独立于定义，按 7140 治理。场景只组织世界事实层级，不进入存在根成为“场景概念”。事件和变化过程归入动态概念根，不因语言中可作名词而进入存在根。

存在概念根自身使用独立概念身份和固定根角色成立；它不能使用世界根、自我存在、普通存在节点或显示分类身份代替。

## 4. 世界事实叶级引用

具体世界存在通过支持关系成为存在概念锥体的叶级成员。一个实例可以同时支持存在根中的多个概念，也可以另行支持特征根或动态根中的适用概念。

存在根只拥有概念和支持关系，不拥有世界实例。实例最近是否仍被确认存在，必须由场景、状态、动态和观察事实判断，不能由概念支持或概念活动状态推出。支持关系只证明其证据范围内的满足；历史依据及支持保留不证明本次仍满足定义，当前归类须按第5节重新核验，不因采用切换自动删除旧支持。

## 5. 定义与实例扩充

存在概念可以引用抽象特征、结构约束或其它定义材料。根据概念创建已分类实例时，L5 之外业务组合可以按 7100 显式扩充允许的缺失结构；概念定义自身不得直接写世界实例。

越具体的约束越应下沉到越具体概念。存在概念根不得挂载只适用于部分对象的颜色、位置、能力、用途、行为、安全、任务或方法等约束。

### 5.1 定义、证据与精确复用

存在概念的定义是以下约束的合取；各组可以为空，全部为空时只使用既有存在概念根：

```text
自身特征约束：特征类型及特征概念值域
+ 组成约束：子存在的概念、组成角色与数量
+ 关系约束：自身及各组成角色之间的具名排列、位置或其它关系
```

组成角色用于区分定义中的参与位置，不是自然语言名称。特征概念和子存在概念均使用具名定义引用；具体存在、特征实例、值事实、世界组成关系和本次观察截止属于形成 / 支持证据，不参与概念等价。来源宿主、名称、生成顺序、查找命中次数不参与定义签名。

精确复用比较规范化后的完整含义：特征类型相同、类型化值域相同、组成类别及数量相同、关系类型及参与角色相同。不能仅比较特征类型集合，也不能只比较某次传入的模板身份序列。多个特征概念身份表达同一类型及值域时，须先正式读回并证明定义等价，再规范化其约束；不能仅凭编码不同重复创建存在概念。不同类型即使数值相同也不同义。类型自身的单位、比较方式、规则版本参与其正式含义。

无序约束必须排序、去重；有序组成保留顺序，重复部件保留数量；对称角色的编号置换不得产生不同概念。相同规则下相同完整定义保持当前唯一。概念引用形式、规范化规则及版本必须可读回，散列只能加速查找，不能代替完整比较。修改已发布含义应建立新身份，不能原地扩大或缩小旧定义。

形成实例支持前，在同一证据截止读取真实存在及所需FT的实际采用，再读取目标F的固定准确类型和值，同时读取子存在组成、子存在概念依据和关系见证。已知集合中仍可读的其它F不并入本次观察；当前无采用不等于可任取历史值。历史材料只在其明确证据范围内核验，不能跨截止拼成本次满足。所有约束逐项成立后才发布支持。同一类型可以有多项相容约束，同一实际特征可以见证多项约束；要求多个部件时必须有对应数量的互异子存在，不能用一个实例重复充数。资料不足、类型不支持、预算耗尽和读取失败均不得解释为“未找到”，继而猜造概念。

### 5.2 分割聚合与分类聚合

分割聚合把已观察材料按具名规则组织为子存在和更高层存在。一个子存在相对于自身仍是完整存在，相对于父存在可以承担组成特征。其具体组成由世界存在关系承载，存在概念只引用对应类别和约束，不复制子存在，也不把子存在身份塞进标量特征值。

分类聚合依据共同特征类型、特征概念值域和结构约束，把多个存在或存在概念归入共同类别。分类可以先对同层组成单元归组，再使用“类别、数量、关系”描述父存在；同类的多个实例保持各自身份。例如四个车轮可以由车轮概念描述，但四个实例及其位置不会合并成一个车轮实例。

分割聚合、分类聚合可以在各层递归配合，不强制单一执行顺序。分割形成的“部分—整体”与分类形成的“下位—上位”是不同关系；“车轮组成车辆”不得写成“车轮是车辆的一种”。某个子存在属于哪个类别，还须独立证明其概念约束，不能从组成位置直接推出。

### 5.3 自动形成流程

存在应用在一个实例的本次可观察描述完整读回后执行；本次自身特征指证据截止下的实际采用，不是该存在全部已知F的并集：

```text
取得本次存在、实际采用的准确特征和组成事实
-> 先形成或复用子存在概念及适用特征概念
-> 规范化当前聚合层的完整存在定义
-> 全定义精确查找，命中复用、未命中新建普通存在概念
-> 新概念暂以既有存在概念根为直接上位，发布本次真实支持
-> 按相同特征类型及可对齐结构检索相关概念，进行分类聚合
-> 在当前聚合层枚举合法约束组合，形成或复用更抽象概念
-> 证明约束包含，整理直接多父关系并完整读回
```

每个新普通存在概念在分配或发布新概念身份前，必须明确至少一个当前直接上位绑定节点。直接上位须为同一存在本体根内已发布且当前有效的概念；新概念身份、定义、形成依据及全部本次直接上位边在同一可靠发布中成立。暂以存在概念根为直接上位仍属于显式绑定，不能由数据服务在空输入时自动补根。请求缺少直接上位或字段不可解释时返回结构化入口拒绝；直接上位未找到、已退出、错根、引用冲突、事实代次漂移、资源失败或历史不一致时保留各自精确的结构化非成功。上述任一失败均须在最终责任边界触发一次统一调试诊断并保持零新概念身份、零定义、零关系；诊断关闭不得改变机器结果。本体根自身只由固定系统初始化建立，不递归要求另一个普通上位，也不能由普通概念创建入口选择该例外。

生成并发布的就是可立即复用的概念，不设“候选概念”节点类别、成熟度字段或等待长期使用才取得概念资格的阶段。内部未发布写集和本次尚未处理的组合不具有已发布概念身份；它们是事务或遍历状态，不是概念生命周期。查找返回的既有概念组也不构成另一种概念节点。

实例先由世界服务合法发布，再由应用推进概念形成。没有足够描述时可以暂时未归类；概念形成失败不得伪报世界实例创建失败或暗中删除它。分阶段发布、恢复和完成判定服从 4240，数据服务不在存在 CRUD 内隐式执行抽象算法。

### 5.4 按特征概念分类与上位形成

新存在概念优先与同级可比较概念聚合，但召回范围不得仅限当前直接兄弟。先前聚合已改变父边时，仍须按类型组合及结构索引召回其它分支的相关概念，否则同一组输入会因插入顺序产生不同分类结果。索引只是入口，每项须在同截止核验完整定义。

在可对齐的特征角色上，利用同一特征类型的特征概念包含关系、聚合值域和类型比较规则形成更宽的约束。不同类型不能仅因数值接近合并；只有类型集合相同也不足以合并成同义概念。多个适用分类可以并存，在能证明共同上位含义时生成或复用共同上位，并保留全部合法多父边。

存在上位的成立条件是：满足下位完整定义必然满足上位定义，且上位确有更宽含义。同义定义只复用。合法抽象包括删除部分约束、用特征概念上位域替换原域、用子存在上位概念替换原组成类别，以及有依据地放宽数量或关系约束。仅有图边、相似度或名称不能证明语义包含；不能任意加强剩余条件。

对多个特征域分别放宽可能允许尚未观察的值组合，例如红色圆形与蓝色方形的共同上位可能容许红色方形。这是抽象的适用范围，不证明该实例已经存在，不得为未观察组合建立世界事实或支持关系。保留原下位定义及关联，不能用父域覆盖原始相关性。

### 5.5 聚合层内穷举

穷举对象是当前层已经聚合的描述单元，包括自身特征概念约束、子存在类别及数量、具名关系约束；不把各层重新摊平成原始像素、点、体素或全部底层特征的无差别组合。分类归组后数量仍是描述的一部分，不能去重后丢失重复部件。

对本次确定的有限描述单元集合，枚举全部非空子集；角色关系依赖必须闭合。含关系而缺少参与角色等非法组合剔除；重复、同义或与既有概念同义的组合复用；零约束归根。不得以“可能没用”为由将其放入候选概念池或设置生成资格门槛。定义成立即可生成，用途由后续使用和退出过程决定。

本次枚举绑定输入事实截止、聚合规则及版本、确定的层内单元集合和遍历位置。新生成的父概念不自动作为同一轮的新原子不断扩张输入；向更上层推进时形成新的有限输入。计算可以分批执行，预算只限制单批工作，不得把未完成遍历报告为全部完成。恢复须使用原输入及原幂等身份；新观察进入新一轮，不能混入旧截止。

分层聚合降低参与穷举的单元数，但不保证任意规模下组合数都很小：若本层有 m 个互相独立单元，仍有最多 2^m−1 个非空组合。规则必须保留完整遍历与中断恢复边界；去重、直接边精简和长期退出分别控制重复、图冗余及存量，不以隐藏截断代替穷举。

### 5.6 精简、使用与退出

形成更抽象概念后，按定义包含整理直接边；存在其它可达路径的冗余直接边可以移除。移除边不等于删除概念，中间概念的退出必须服从 7140 的生命周期、引用保护及替代边事务。

概念使用后可以留下，长期无使用则由具名治理规则推进冷却、退役或退出，不要求预先证明有用。没有“候选转正式”或“成熟后可用”过程；使用计量不进入定义。自动枚举、后台扫描和幂等重放不得通过自增命中制造用途，定义引用保护也不等于被实际使用。

### 5.7 层次与递归边界

从世界实例向上形成的金字塔表示抽象方向，不改变 2220 的正交结构。具体存在始终通过支持关系成为底部引用，多父关系完整保留，层数、路径和树形展开按请求重建；世界树不成为存在概念根所拥有的子树。

组成定义引用与分类上下位分别校验，不能用一个 DAG 的无环检查替代另一个。沿子存在组成递归形成概念时，必须检测循环及非法自引用，并按已闭合子定义向父定义推进；尚缺真实组成提供者时返回能力或事实缺失，不能从场景树父子关系推定子存在组成。

### 5.8 共享特征域前置

存在约束消费2220第6.1节及7160的共享特征概念：FC身份为FT与规范化域，不含形成宿主。每个存在须用证据截止H下自己的实际采用与准确值逐项见证约束，不能从另一个存在的命中或自身全部已知F推断本次满足；子存在类别及其它约束也须在相同证据范围内独立成立。

EC定义直接引用所选FC的固定定义，不通过F的可变名称引用间接决定含义。无名称F只要类型和值可完整核验，也可见证适用域；F改名、换绑或解除名称不改已发布EC的定义，不要求先命名F才能归类。没有完整可用的域规则或定义时只报告相应形成缺口，不猜造域或准确值。

多个互不包含的适用域用于F单一名称选择时，按7160形成或复用精确并集共同上位；EC仍按自身已经确定的完整合取定义逐项核验，多个适用分类可以并存。不得将“多个谓词均满足”自动改成“任一谓词满足”，也不以并集覆盖不同历史F后声称它们本次同时成立。有依据地采用更宽域形成存在上位时按第5.4节建立或复用另一完整定义，保留原EC含义；精确并集不填平空隙，轮廓差异值和代表编码仍不充当准确特征值。

特征前置实现与本规范的完整存在层内穷举分别报告。仅适配既有EC / 动态 / 场景消费者到新共享域，不证明已经实现第5.5节的全部组合、组成和关系抽象；不能以局部适配登记整个存在目标完成。

## 6. 语言名称

概念名称由 2210 的名称关系表达。名词、代词、短语或其它语言形式可以经 7210 形成存在根候选，但词条、词性和名称只用于召回和消歧，不决定根归属、概念上下位、签名或实例支持。

同一词条可以命名多个存在概念，也可以命名特征根或动态根中的概念。一次语言位置的词性解析不得永久改变词条或概念。

## 7. 禁止规则

1. 禁止把世界树根、场景树根、具体存在和存在概念根合并。
2. 禁止让具体存在或抽象存在节点兼任概念身份。
3. 禁止把存在根视为全部概念空间。
4. 禁止让名词或任何词性自动建立本体根、概念或实例支持。
5. 禁止把具体世界事实复制到概念定义或概念树叶子。

## 8. 验证合同

验证至少覆盖：

1. 存在根与世界根 / 场景根独立，组成关系不冒充分类边，世界实例只作叶级引用。
2. 同定义跨实例复用；类型相同但域不同、数量不同、有序关系不同不误合并；对称角色换号和模板同义不重复生成。
3. 子存在保持独立身份，多个同类部件保留数量，缺少见证和重复实例充数拒绝。
4. 先插入 A、B 再插入 C 与换序输入得到等价定义及分类可达关系；已换父分支仍能参与聚合。
5. 放宽特征域、删除约束和子概念上位替换均有语义包含证据；同义不生父边，零约束复用根，多父不丢失。
6. 层内完整合法组合、非法依赖剔除、同义去重、预算续行无漏重；新观察与原截止隔离。
7. 未观察的交叉值组合不生成实例或支持；新概念立即可用，无候选概念类别或成熟度门槛。
8. 使用计量去重，后台生成不自证有用，长期未使用按规则治理；引用受保护，退出后历史及原世界事实保留。
9. 多阶段失败报告真实已发布部分，原键恢复无重复；名称与词性不决定概念或实例支持。
10. 已知F20与F30但本次只采用F30时，不把二者拼作本次描述；无采用不以历史兜底，历史支持不证明当前满足。
11. F无名称仍可作适用域见证；F名称替换或解除后已发布EC定义不变，多个域的单名称并集选择不改写EC合取，也不删除其它适用分类。
