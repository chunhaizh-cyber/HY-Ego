# 7110 子规范 存在概念主动归纳与归类

编号：7110

日期：20260916

版本：v2.0

状态：正式子规范

直接上级规范：2220。

直接依赖规范：7100、1130、1140、4180、4181、7150、7160。

相关边界规范：1150、2210、4240。

## 1. 定位

存在概念形成有两条不能互相替代的路径：

```text
首次路径：拟建立E的全部已知信息
      -> 按7100完整匹配、复用或建立最具体EC
      -> 建立E并关联EC

归纳路径：明确业务/认知需求选定多个已发布EC或E
      -> 提取共同的特征类型和值域
      -> 形成/复用共同上位EC，并建立必要直接边
```

归纳是主动的归类行为，不是概念树、世界树、存在类或概念树类在节点新增时的全局扫描副作用。

## 2. 定义、概念图与来源边界

存在概念的定义固定为自身特征值域组和已知子存在概念组。物理父子存在关系只用于读取子存在，不是概念图上下位关系；关系类型、成员角色、关系端点和名称不参与归纳，也不作为概念边的依据。

概念图边方向固定为“上位概念 -> 下位概念”。同类别边构成无环多父图，只保存必要直接边；层号、路径、兄弟列表和根链均为可重建投影。零直接上位的存在概念组成存在概念根链投影，但不产生持久概念总根或默认父。

## 3. 主动归纳请求

归纳只能由有明确目标的业务/认知应用发起。一次请求至少明确有限且不少于两个的来源存在或来源概念、拟比较的特征范围、同一读取截止和非零预算。

来源为E时，应用必须读回E当前用于概念定义的全部特征、全部已知子存在及其已发布概念；来源为EC时，必须完整读回其两组定义。读取不完整、跨截止、来源退出、预算不足或类别不符不是“无共同点”。

## 4. 共同约束提取

归纳应用只保留对全部来源成立的共同自身特征约束：

1. 正式特征类型必须可对齐；
2. 值域完全等价时保留；
3. 同一类型存在已发布共同上位特征概念值域，且每个来源值域均被其包含时，可以以该值域替换；
4. 子存在概念只有在所有来源均具有同一已知子存在概念时，才可保留为共同子存在概念组成员。

不同类型不得因数值接近合并。名称、实例位置、索引、成员角色、关系类型、关系端点或单条物理组织边均不构成共同约束。特征比较或值域包含能力缺失时必须返回该能力缺失，零概念、零边写入；不得猜测或降级为相等。

## 5. 形成、复用和归类

共同特征组为空，或不足以满足请求明确的归纳目标时，返回“未形成共同概念”；这是正常的零写入结果。不得为所有数学上可能的特征子集或未被请求的组合预建概念。

共同定义成立后，应用按以下顺序执行：

```text
规范化共同定义
-> 在存在类别中完整比较并选择唯一最具体候选，或确认零匹配后创建
-> 对每个来源概念证明：来源定义蕴含候选定义，且至少一个特征值域严格更具体
-> 建立必要的 上位EC -> 下位EC 直接边
-> 删除被新中间概念严格覆盖的冗余直接边
-> 完整读回定义和受影响直接边
```

如果并列最具体候选，或来源不能证明严格包含，返回逻辑错误或逐项不归类；不得任意接边。一个请求可只使部分来源通过包含核验，结果必须逐项报告。既有合法多父边不得因新归纳被删除。

## 6. 后续细化、实例关联与分工

概念定义不可原地改义。新的实例事实由7100重新完整匹配后复用或建立更具体概念；新的归纳需求由本规范形成或复用上位概念。每个E仍只通过自己的`E -> EC`使用引用关联最具体概念；概念上下位边不自动更改实例组织，也不自动改变E的使用引用。

概念树类只保存已经裁决的概念定义、类别、直接边、生命周期及读回；它不选择来源、提取共同点或决定归纳目标。世界树类仅执行7100的顺序编排。L3应用组织调用L2、逐项读回、失败停止和结果汇总；它不直达L1或自行定义数据对象字段。

## 7. 验证语义

验证至少覆盖：

1. 首次形成与主动归纳分离，节点新增不触发全局扫描；
2. 共同特征和值域不足时零写入；
3. 特征类型、值域包含和子存在概念组按完整规则参与归纳；
4. 角色、关系类型、关系端点、名称和实例位置不进入共同定义；
5. 上位严格更宽、同义复用、多父保留、传递边不重复且无环；
6. 并列最具体和能力缺失不伪造一个可用概念；
7. 根链是零上位投影，不建立概念总根。

## 8. 退役口径

下列口径退出新生产：

- 将组成角色、关系类型或参与角色作为存在概念定义或共同约束；
- D/O/R或等价关系约束的归纳、持久化和查询路径；
- 用名称、词性、相似度、位置或单条物理组织边直接生成概念；
- 每次实例增加后自动扫描同级概念、穷举组合或自动归类；
- 将分类上下位边当作父子实例组成边，或反向由概念边补造世界事实。
