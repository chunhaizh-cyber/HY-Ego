# 4000 子规范 基础抽象命名规则

编号：4000
日期：20260814
状态：正式子规范

## 1. 定位

本规范定义世界信息族内部的领域抽象锚点。名称只用于定位已存在结构，不以字符串承载机器逻辑；2220 的存在、特征、动态三个概念本体根另有独立身份。

直接上级规范：1120、1140、1150、1160、1170。

直接依赖规范：无。

相关边界规范：1130、1180、2100、4210。

## 2. 领域抽象锚点

场景、存在、特征和变化分别是对应世界信息族的领域抽象锚点。它们用于组织对象结构、特征定义或动态模式，不直接兼任 2220 概念空间的本体根；需要成为自然语言概念时，必须另有独立概念身份，并由对应世界事实或领域定义通过支持 / 定义关系连接。场景只组织世界事实层级，不存在场景概念根。

动态节点是事实承载对象，“变化”是动态信息领域抽象锚点，二者不得合并或改名替代；动态概念本体根是独立概念身份，动词只可作为后继语言表达候选，不能兼任或决定该根。

## 3. 有效动态抽象

有效动态抽象不能只停在“变化”。它必须能沿正式关系回读：

```text
场景抽象
存在抽象
特征抽象
变化抽象
初始状态抽象
结果状态抽象
时间关系
来源低层动态或模式证据
```

不同场景中的同类数值变化可以有不同语义；匹配必须同时检查场景、存在、特征、状态端点和变化关系。向领域抽象锚点上溯提供结构兼容性，中间锚点提供区分性；不得把该结构上溯冒充概念空间的上下位图。

## 4. 动作信息边界

动作信息是对一组可复现动态模式的压缩身份，不是动态根概念，也不是方法编号或文本签名。方法可以作为动作信息的来源、识别和执行入口，但不得直接冒充因果动作本体。

## 5. 禁止事项

- 禁止把根名作为普通枚举、日志标签或兜底字符串参与判断。
- 禁止只按“变化”或动作名匹配动态。
- 禁止用黑盒编号、自由文本或显示名替代抽象关系。
- 禁止新增与动态节点平行的世界事实“变化”结构；独立动词概念身份按 2220 建立，不属于本禁令所指平行世界事实。
