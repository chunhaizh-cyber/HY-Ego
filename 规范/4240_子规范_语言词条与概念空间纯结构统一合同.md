# 4240 子规范 DATA-L2语言语素词条与概念结构统一合同

编号：4240

日期：20260815

状态：正式子规范

直接上级规范：0050。

直接依赖规范：1190、2200、2210、2220、4010、4015、4020、4030、4040、4050、4060、4230、7140。

相关边界规范：0500、1100、4310、4320、7100、7200、7210、ACCEPTANCE-01。

## 1. 定位

本规范冻结语言身份、独立语素、正式词性、词条、存在 / 特征 / 动态 / 因果链四个语言无关本体根、独立概念、概念名称关系和概念核心关系在 `DATA-L2` 中的唯一结构所有权、强类型身份、依赖方向、当前 / 历史读取和生命周期边界。

4230 只承接场景、存在、特征、状态、动态和因果六类世界结构，不代表全部 `DATA-L2`。语言、语素、词条、词性和概念结构同样建立在唯一 `DATA-L1` 事实基座上，但概念本体不依赖语言或词性成立，并与六类世界结构正交；不得把概念塞入任一世界服务，也不得把现有 `L2结构聚合服务` 改成概念写入口。

本规范只授权保存调用方已经裁决的结构请求。分词、语素识别与解释、词性判断、概念抽象成立、同义判断、事实归类、名称接受和语境消歧均位于 `DATA` 之外。

## 2. 公开身份、owner 与来源

### 2.1 五个新增节点族

在 4230 七个节点族之外，L2 公共合同增加五个彼此不可转换的强类型身份：

```text
L2语言身份
L2语素身份
L2词条身份
L2词性身份
L2概念身份
```

`L2节点族` 闭合增加 `语言、语素、词条、词性、概念`，总计十二族。五族分别拥有两两不同、且与既有七族不同的独占结构 owner、族锚点、族归属关系类型和公开身份来源读取。稳定编码、名称、词面、外部标签、普通 L1 节点或强类型包装均不能单独证明身份。

语言、语素、词条和词性分别具有唯一强类型 CRUD 公开面及不可交换 owner 交付；概念由唯一 `L2概念结构服务` 持有一份概念 owner 交付。后继可以把多个语言结构范围装入同一服务实例，但每个函数必须静态路由到唯一 owner，禁止通用 owner 选择、通用跨族 CRUD、把语素写成词条或用词条 owner 形成语素来源。每个公开节点与本族非自环归属关系必须同 owner、同写集、同创建代次建立。

### 2.2 关系所有权

语言关系归语言 owner；语素自身结构关系归语素 owner；词条归属、词条结构及“词条由语素组成”关系归词条 owner；本体根归属、签名、上下位、定义约束、世界事实支持和生命周期关系归概念 owner。概念名称关系由独立 `L2概念名称结构服务` 的名称关系 owner 唯一拥有；该 owner 不拥有语素、词条或概念节点。

跨 owner 端点只表示强类型引用，不转移节点所有权。关系类型节点、关系事实和关系写端口必须同 owner；任一服务不得借跨 owner 引用写入另一服务的节点、值或关系。

## 3. 不可变材料前置合同

词面、规范化合同、签名规则、签名中的非内联材料和发布证据不得编码为自由 JSON、字符串拼接、裸路径或临时 `U64` 打包。它们通过唯一 `不可变材料服务` 形成强类型 `不可变材料身份`，至少包含：

```text
非零稳定身份
格式身份
字节长度
SHA-256 摘要
来源节点
创建 / 退出生命周期
可选物理定位
```

服务先形成不可变文件候选，复读核对格式、长度和摘要，再以自己的材料 owner 在 L1 发布材料节点及来源结构。失败候选不得成为运行期事实；物理路径不是身份，移动文件不得改变身份或摘要。同一格式、同一摘要和同一完整字节内容只形成一个当前材料身份；摘要相同但复读内容不同属于内部不一致。

词面材料固定为严格 UTF-8、无 BOM、无无效序列、无 `U+FFFD` 的非空字节组。规范化合同和签名规则可以使用其它正式登记格式，但必须由材料服务公开读回证明。材料服务不解释文本、规则或概念语义。

## 4. 语言、语素、正式词性与词条

### 4.1 语言和词性

`L2语言事实` 至少包含语言身份、正式登记键、来源和生命周期。`L2词性事实` 至少包含词性身份、语言身份、正式词性键、来源和生命周期。

同一语言登记键至多一个当前语言；同一语言和正式词性键至多一个当前词性。外部分词器标签只能成为调用方材料，不能替代正式词性身份。退出仍被词条、语言记录或其它已登记持久结构引用的语言 / 词性必须返回引用冲突；7210 的任务局部路由结果不持久化、不形成引用保护。概念本体根和概念身份不引用词性，不能反向阻止语言结构独立换代。

### 4.2 语素

`L2语素事实` 固定至少包含：

```text
语素身份
语言身份
规范化合同材料身份
规范化语素材料身份
来源
生命周期
```

语素是可参与构词、命名或概念表达的结构单位，不是词条的别名、字段或兼容身份。同一语言、同一规范化合同和同一规范化材料至多一个当前语素；数据服务只校验调用方提交的规范化结果和结构，不判断语素切分或解释是否正确。

词条与语素之间使用具名有序组成关系：方向固定为“词条 -> 语素”，每项保存非零顺序和非零角色。同一语素可参与多个词条，同一词条可由一个或多个语素组成；一个词条只有一个组成项也不得与该语素共用身份。组成关系不自动建立概念名称或概念表达；后继需要语素直接表达概念时必须另行冻结具名关系，不能借旧“语素入口”恢复通用中间壳。

### 4.3 词条

`L2词条事实` 固定包含：

```text
词条身份
语言身份
规范化合同材料身份
规范化词面材料身份
来源
生命周期
```

唯一键为“语言身份 + 规范化合同材料身份 + 规范化词面材料的格式、摘要和长度”。同键同完整内容精确重复；同键异内容为幂等冲突或内部不一致。词条服务不执行规范化，只校验调用方提交的规范化结果与材料读回一致。

词索引是从当前词条确定重建的非权威加速结构。索引命中后必须回读词条；清空、缺失或重建不得改变语素、词条、组成关系、名称关系或概念。

## 5. 概念本体与核心关系

### 5.1 本体根和签名

存在、特征、动态和因果链恰各有一个当前本体根；四个根分别使用普通 `L2概念身份` 加不可变系统根角色成立，并永久活跃。词性、名称、场景身份和外部标签不得成为根角色或根身份。概念事实至少包含：

```text
概念身份
本体根概念身份
签名规则材料身份
确定排序的签名值式项组
确定排序的签名定义引用项组
来源与发布证据
生命周期
```

本体根首次建立写集必须原子包含概念节点、概念族归属、固定根角色关系，以及能够在正式读取中逐字段回显的首次幂等身份和首次期望事实代次见证；这些是必含事实，不是“精确仅三项”的物理写集上限。DATA 所有者可以在不扩大 BIZ 公开 ABI、不形成第二事实来源的前提下冻结同 owner 事务所需的内部属性类型、值槽和其它结构事实。首次请求字段、进程内定位缓存或调用方副本不能替代持久见证。

本体根还必须使用与后继 C2/C3 共享的正式直接上位关系类型读取当前目标关系组。根建立完成时该组必须为空；空组来自同一根、同一概念 owner、同一非零事实截止的正式枚举，不由省略字段、未登记关系类型或 BIZ 常量推断。根不建立直接上位边，后继普通概念仍须至少一条直接上位边。

签名值式项固定包含非零角色、非零顺序和 `L2原始值材料`；定义引用项固定包含非零角色、非零顺序和强类型目标引用。同一角色 / 顺序不得重复。签名值式项与定义关系分别保存且逐项互证，不复制关系目标为值。

同一本体根、同一签名规则材料和同一完整签名只允许一个当前概念。签名发布后不可原地改义；含义变化建立新概念身份。普通概念创建必须在一份概念 owner 写集中同时建立节点、族归属、本体根归属、签名材料、至少一条直接上位边及全部初始定义关系，使提交后立即同根、无环且根可达。

二次特征概念固定归入特征根，其定义关系必须能够引用 1180 的正式派生特征事实或概念业务提交的强类型派生材料，并逐项保存真实阶次、直接来源特征关系、输入角色、派生规则和适用范围。实际二次至 n 次统一称为二次特征，但全部复用特征身份与节点族，不建立按阶次扩张的新族；同一概念跨存在、动态或其它宿主使用不得复制身份。

因果链概念固定归入因果链根。其签名和定义关系必须引用至少一个 1190 已发布、方向明确且版本有效的直接因果事实，并逐项保存直接组成角色、确定顺序、分支关系、适用范围和因果规则版本；多个组成必须形成方向一致、连通且无环的直接因果拓扑，允许共同原因、替代原因和共享分支。一个直接因果构成最小链，同一直接因果可以支持多个完整签名不同的链概念。概念结构不得复制原因果条件、动作、结果、证据或版本，不保存传递推导出的间接因果、固定层号和展开路径。应用按目标、范围、版本和展开截止取得的分层因果链是调用方拥有的值式投影，不能反写概念或因果事实。

### 5.2 上下位和定义

直接上位关系方向固定为“上位概念 -> 下位概念”。同根允许多父；自环、跨根、成环和提交后不可到达唯一根在写前拒绝。只保存直接边，不保存传递闭包、高度、坐标、锥面或显示路径。

定义约束目标使用闭合强类型联合，不接受裸稳定编码。v1 至少允许目标为当前概念、场景范围、存在、特征实例、特征值、二次特征、状态、动态、因果、普通关系事实、场景父子关系或场景成员关系；每项必须经对应公开服务在同一期望截止验证身份和完整结构。后继新增世界事实类别必须建立新合同版本，不得用裸节点兼容猜测。

### 5.3 世界事实支持

`L2世界事实引用` 使用与定义目标相同的闭合类别，并携带类别所需的强类型身份或关系 / 值稳定身份。世界事实支持关系方向固定为“世界事实 -> 概念”，由概念 owner 拥有。

同一世界事实与同一概念至多一条当前支持关系。支持多对多并允许跨本体根；写前只验证端点和结构，不判断归类正确性。退出支持关系不得退出世界事实或概念。场景身份、场景树根和场景父子层级不得用于建立场景概念，只能作为定义范围或来源材料；语言使用事实尚未有正式提供者时必须结构化拒绝，不能用词条或普通节点冒充。

### 5.4 生命周期与退出

普通概念当前生命周期为 `活跃、冷却、退役` 之一，合法迁移服从 7140。四个本体根永久活跃。迁移建立新生命周期事实并退出旧事实，不原地覆写。

不可逆退出必须在同一事务中闭合签名、定义、上下位、支持、名称以外的概念 owner 当前关系和生命周期；名称关系由名称服务在前置事务中退出。中间概念退出时，按 7140 计算并原子建立必要替代直接边。来源世界事实、词条和名称历史不得删除，旧概念编码永久不得复用。

## 6. 概念名称关系

`L2概念名称事实` 固定包含关系身份、概念身份、词条身份、名称角色、适用语言、来源和生命周期。名称角色闭合为 `首选名称、别名、简称`。

同一概念、同一语言最多一个当前首选名称；同一概念 / 词条 / 角色 / 语言当前关系不得重复。同一概念可有多词条，同一词条可命名多个概念。名称服务经概念、词条和语言公开身份来源校验端点，不创建、改义或退出端点。

按词条读取候选时，名称结构服务只返回当前名称关系命中的全部概念并稳定排序，不接收词性路由、不调用 7210，也不缩小结果。`DATA` 外业务如需按词性缩小或排序，必须把完整名称候选作为值式输入另行调用 7210；零路由、零概念和多项均为合法业务结果，不得反向改写名称结构。

## 7. 单向依赖与装配

依赖方向固定为：

```text
不可变材料服务 -> L1事实基座
L2语言结构服务 -> 不可变材料服务只读 + L1事实基座
仅本体根 L2概念结构服务 -> L1事实基座
后继普通概念结构能力 -> 仅本体根 L2概念结构服务只读
                       + 不可变材料服务只读
                       + 六类世界结构公开读取
                       + 特征结构公开读取（含真实阶次与直接来源）
                       + L1事实基座
L2概念名称结构服务 -> L2概念结构服务只读
                       + L2语言结构服务只读
                       + L1事实基座
DATA-L3 概念空间聚合（现行 ABI 名 L2概念结构聚合服务） -> L2概念结构服务；零写入所有权
六类世界结构服务 -X-> 语言 / 概念服务
```

不得增加世界服务反向依赖、同层循环、第二写入口、中央通用 CRUD、裸 L1 仓访问或把非权威索引升级为事实。最终普通应用可以同时持有 `DATA-L3` 世界树结构聚合与概念空间结构聚合；二者并列，不互相包含、不复制服务实例。

`L2概念结构聚合服务` 是保留现行 C++ 名称的 `DATA-L3` 概念空间聚合入口。它只保存一份 non-owning `L2概念结构服务&`，只提供 const / non-const 同实例 getter；它没有 owner、写入口、锁、缓存或 DTO 映射。阶段 18 和其它概念结构 BIZ 消费者只能经该聚合取得唯一 C1，不得直达 L1，也不得建立第二 C1 getter。

当前仅本体根 `L2概念结构服务` 的构造依赖只包含 `const L1事实基座服务&` 与唯一概念 owner 交付；公开面只承载建立一个本体根、按角色读取当前根和读取全部当前根。不可变材料、六类世界结构、二次特征和语言均不是这三个入口的构造或请求依赖。普通概念、上下位、定义、支持和名称等后继能力必须另行形成具名能力合同，并复用同一概念 owner 与唯一 C1 事实入口；不得为了后继能力改写阶段 18 请求、增加第二根服务或提前扩张仅本体根 ABI。

上述“三个入口”只限定 C1 的公开操作数量，不限定每根内部写集为三个事实。根事实必须完整读回上一节规定的节点、族归属、根角色、首次请求见证和直接上位空组；DATA 内部怎样用 owner-scoped L1 结构原子承载，由 C1 实现合同独立冻结，BIZ 不直达 L1 或暴露内部属性槽。

不可变材料、语言、词条和概念名称服务继续按本规范各自独立装配。后继确需组合这些语言表达结构时，必须形成另一具名设计；该设计不得包含、复制或转发 `L2概念结构服务`，不得复活旧 `L2语言概念结构聚合服务` 四服务入口。最终普通应用可同时持有六类世界结构聚合、单服务概念结构聚合和后继具名语言表达聚合；三者并列且互不包含。

## 8. 读取、状态与验证

请求 / 结果头、当前 / 历史、幂等、漂移、引用冲突、资源失败和内部不一致沿用 4230 v1 共同合同。`L2概念本体根写入结果` 和 `L2当前概念本体根读取结果` 分别以 `optional<L2概念本体根事实>` 承载单根，`L2当前概念本体根组读取结果` 以 `vector<L2概念本体根事实>` 承载根组。成功结果必须携带单一非零事实截止；写成功的事实截止必须晚于建立请求的非零期望代次，变更事实代次等于该成功截止；写成功和单根读成功的 optional 必须有值，全组读取成功允许空 vector。任一非成功的 optional 必须为空、根组 vector 必须为空、变更事实代次必须为空，且不得改变权威事实；非成功携带根、根组或变更事实代次均是坏服务形状，只能由消费者映射为内部不一致。

仅 `读取全部当前概念本体根` 允许请求头 `期望事实代次=0`，含义是选择该调用进入时最新的当前快照；成功必须返回非零事实截止，空根组也是成功负载，零请求返回事实代次漂移或未找到属于坏服务形状。连续消费中的后一次零代次读取不得返回早于调用方已正式取得截止的旧快照。该入口使用非零期望代次时是当前代次乐观守卫，不一致返回零变化、无首次结果的事实代次漂移；成功结果的事实截止必须精确等于请求中的非零期望代次。`按角色读取当前概念本体根` 和 `建立概念本体根` 必须使用非零期望事实代次；单根读成功的事实截止也必须精确等于请求期望代次。单根读取同代未找到和任一成功空负载属于内部不一致，不得解释为正常竞争。

合法消费者在实际使用时只经公开服务入口，以结构化结果和权威读回判断当前所需能力。施工期间临时专项可以按分叶覆盖：合法创建与逐字段读回、精确重复 / 同键异义、非法零变化、当前 / 历史、换代 / 退出、引用保护、稳定排序和同截止；语素与词条专项还应覆盖身份互异、跨词复用、有序组成和旧入口零恢复。概念专项还可以覆盖四个本体根独立且永久、场景 / 词性零额外根、同根多父 DAG、成环 / 跨根拒绝、签名唯一、高阶特征真实阶次和同概念跨宿主复用、因果链只引用已发布直接因果事实、共享分支和方向可回查、固定层号 / 间接边 / 展开路径零持久化、世界事实多对多支持、名称多对多、首选唯一、生命周期迁移和退出替代边。临时专项不编译进生产目标，完成后清理，不建立替代实际消费的独立验收结论。

设计、计划或接口存在只证明合同已冻结；不得宣称材料、语言、词条、词性、概念、名称、装配或旧模型清理已经实现。

## 9. 旧模型退出

新结构真实接线并完成引用迁移后，必须由独立清理计划删除旧 `语素入口身份`、`语素对应信息`、`语素概念追溯`、历史复用世界对象身份的旧场景 / 存在 / 特征 / 动态四类根、每词性一根结构、复用世界对象身份的概念关系以及相关生产消费者和工程登记。这里删除的是词条与概念之间的旧通用入口壳，不得删除、禁止或降级本规范新增的独立语素节点族。删除前必须证明零当前消费者或替代路径真实完成；历史流程图、能力目录和版本历史只保留为旧模型证据。
