## 1. 定位与边界

本规范固定二次特征应用的调用期输入、来源图、结果完整性、读取一致性和RC求值合同，不增加数据owner、持久二次实例或特征对象字段。准确计算和求值位于DATA之外；结构服务保存、读取和校验已裁决定义，比较提供者按4180执行算法。

调用合同不以已经保存一份绑定具体输入的派生根定义为前置。允许引用已有合法定义，也允许按已成立FT、用途和K组织本次临时计算；两条路线使用同一规则校验和计算语义。读取已保存定义不等于保存本次结果，临时计算也不自动建立定义。

本规范冻结逻辑请求、返回和副作用合同；不为既有C++枚举重新编号。具名C++声明、构造交付及旧入口兼容映射由对应实施合同承接，不以本文登记证明提供者已经实现。

## 2. 依赖交付与操作边界

应用只经正式公开接口取得准确特征/值、类型及比较注册、所需状态/参与者来源，以及RC固定定义。所有来源服务须绑定同一事实基座和相容读取合同；构造不创建类型、根、规则或概念，不取得数据写端口。

基础计算不强制依赖RC、自然语言或具体存在身份；只有请求的角色和适用语义需要时才读取对应材料。概念形成应用消费准确计算材料并调用唯一概念数据服务，计算应用不反向依赖形成应用。

| 逻辑操作 | 输入与输出 | 副作用 |
| --- | --- | --- |
| 计算具名二次特征 | 有限输入图、正式比较目的和所需输出，返回完整准确结果及来源闭包 | 零持久写入 |
| 读取并核对派生来源 | 已保存定义或本次来源图，返回真实直接来源、规则、输出声明及基础叶 | 零持久写入，不自动计算或形成RC |
| 求值既有关系概念 | RC身份、固定定义读取上下文和具体有序输入，返回完整满足/不满足及依据 | 零持久写入，不记录用途 |
| 提取概念形成材料 | 同次合法计算及已核验来源，返回供7180消费的材料 | 不形成RC，不把材料升为持久事实 |

操作可以组合实现，不要求每行建立独立类、仓库或第二公开写端口。结构定义的建立/退出继续属于原结构服务，不与本次计算成功混为一个返回。

## 3. 输入的闭合联合

### 3.1 来源种类

本节通用调用期计算图的每个输入位置必须且只能使用以下一种来源：

1. 准确F引用：按1130/4110完整读取FT和准确内容；内联I64不补造值身份，值引用按2100及类型合同完整解析。
2. 已保存派生定义的具名输出引用：读取完整定义、规则和直接来源，将其展开为本次依赖图后复算；不直接相信历史计算值。
3. 本次图内上游输出引用：引用本次唯一局部编号及其具名输出角色。编号只在本次图中有效，不是稳定节点编码；上游输出必须由本次合法计算得到。

裸I64、调用方自报阶次、节点主键、名称和上轮缓存不能替代来源。跨调用传递的旧结果不凭“以前成功”直接准入；必须重新取得其合法来源和规则，纳入本次图并复算。目标常量也须具有其正式目标/类型来源，不能以便利参数绕过事实读取。

### 3.1.1 固定状态端点的具名只读适配

[4242](4242_子规范_二次关系概念精确结构与操作合同.md)另行冻结供RC及7191消费的状态端点求值合同。其输入以4203完整绑定B定位C/E/S，按4212读取S内固定正式FT、准确值及强时间；不能以裸S、裸I64或当前采用值替代B及来源核验。适配取得合法准确I64后，只调用正式K及其公开计算能力，不创建F、值、状态、二次实例或支持记录。

该适配使用独立强类型DTO和专属入口，不把第四个变体静默插入既有三类计算来源联合，不复义旧图内局部编号。它仍遵守本规范G/H、固定K与本次合法路由互证、完整适用核验、预算及全请求失败合同；结果没有持久身份。B/S材料的读取成功不证明发生时包含、观察覆盖或场景来源完整，后者按4202/4204与7191分别核验。未满足4242限定的值类型、规则或来源时明确非成功，不用默认算子或伪造F回退。

### 3.2 图、输出与上下文

每个计算项包含本次唯一局部编号、正式FT/用途和可确定的K、按角色组织的直接输入，以及非空且不重复的所需输出角色。已有规则能唯一读回的信息不重复成为F字段。输出类型、单位、尺度和算法不得在普通计算中临时创建。

一次请求指定非空根输出组；公共上游可以在本次图内共享。来源边保留输入位置和角色，同一F在不同位置出现不得合并成一个无角色集合。同类型的多个成员也不得按FT覆盖。

适用上下文只包含本次用途真正需要的有序A/B、取值位置、观察/状态时间和坐标参照。多人比较属于多个有序对象对，不得合成同一A/B的AND。状态时间可以不同，读取事实的一致截止不能因此混用多个“最新”。

无RC基础计算从FT及K启动，不伪造FC/EC约束。已有RC求值必须取得4241完整定义并核验其全部FC/EC与参照限制；基础计算成功不能替代该适用核验。

## 4. 一致读取与有界复算

一次请求冻结非零读取守卫G及具名来源截止H，满足0 < H <= G。G约束本次读取期间的事实基座及合法比较路由，H约束来源材料；它们不是观察时间，也不进入准确F字段。其材料映射固定如下：

| 材料 | 读取含义 |
| --- | --- |
| 本次待求值RC、其FC/EC固定定义、有效K及用途路由 | 按G核对完整定义和本次合法适用性；不因来源较早而假定RC在H已经存在 |
| 具体来源F、参与者采用/归属及已保存上游派生定义 | 按H及来源服务的具名合同读取；状态固定来源如指向更早事实截止，沿该显式来源继续读取，不能换成本次最新值 |
| 已保存定义引用的固定K、FT及量化解释 | 保留原固定含义，并与G下本次合法路由核对；不相容则拒绝，不替换后复算 |
| 本次局部图 | 按本次请求和G下合法规则解释；局部编号没有H下的持久事实身份 |

当前来源判断使用H=G；H<G表示用本次合法定义分析具名时点的来源材料，不自动表示复现H时系统曾经作出的判断。例如RC在120形成、H=100、G=130，允许在来源完整且规则相容时用该RC分析历史材料，但不能声称该RC在100已经成立或已被采用。复现过去判断还需要当时完整RC、规则及采用证据的独立历史合同，不由本次计算/求值入口推定或补造。

全部读取必须遵循上述已声明映射及各服务的成功谓词、历史可读范围；不把本节解释为任意服务都已提供历史读取。返回前复核G；发生漂移则本请求无成功载荷。不能通过连续读取“最新”、混拼未声明截止或沿用上轮输入消除漂移。

预算必须显式限制图项数、来源边数、基础叶数、读取材料总量、展开深度及对外结果项数；所需上限非零，不采用零表示无限。读取和展开时逐步扣除，不能先分配无界集合再检查。字节/元素计数及阶次本身也须检查溢出。

应用按有向无环依赖顺序执行：

```text
校验请求与预算 -> 读取/展开真实来源 -> 检查环和角色
-> 核对FT、K及输出能力 -> 按依赖顺序计算
-> 核验完整结果与来源 -> 返回前一致性复核 -> 返回
```

共享子图可以在同次调用内只计算一次，但深度须按每条使用路径校验。基础特征阶次按其正式类别取得；派生项阶次为所有直接特征输入的最高阶次加一。关系、状态或时间约束不以容器层数伪造特征阶次。

每个算子仍受4180/4181/4182的用途、范围与失败合同约束。缺少某非标量算法只使该请求失败，不要求其它合同完整的标量请求同时停止。内部计算缓存仅为本次非权威工作材料，用毕释放。

## 5. 返回结构与成功谓词

准确计算成功必须同时具有：请求对应关系、G/H及一致性结果、全部所需具名输出、各项FT/I64/角色/单位量化/有效K/真实阶次，以及到准确来源的完整有序闭包。闭包可以在同一返回包内去重保存并由局部编号引用，不复制成每个输出一棵树，也不能只回显平坦叶集合。

只把上游输出的值、阶次和定义身份放进直接回执而无法继续读到其输入，不构成完整来源闭包。本次局部编号不能被用于跨调用、持久支持关系或世界节点引用。

任一所需输出失败，整个请求没有成功计算载荷。内部已算出的部分值、错误码、预算剩余量和诊断信息不是可继续消费的二次特征。独立请求可以分别报告结果，但不能把其中成功部分冒充一份完整多结果请求。

准确零是合法结果，不与缺值或失败共用含义；排序量、关系编码和有向差异必须按真实输出FT解释。D归类只消费7180允许的准确判定量，不把任意正整数关系编码当作正域关系。

## 6. 已成立RC求值

求值先完整读取RC定义、必要引用及其合法治理状态，保持固定含义；再按同一有序A/B绑定具体来源。子RC展开保留全部角色化FC/EC、取值、K和参照限制，外层约束不能覆盖内层必要条件。

全部必要条件均适用且完成计算后，才形成“满足”或“不满足”。任一必要项缺源、不可比、超预算或未完成时，整次求值非成功，不能用另一项已经为假提前掩盖失败。输入不满足适用前置与合法结果不落入D分开返回。

结果保留被求值固定定义、具体绑定和必要判定依据。不满足不修改或淘汰RC；求值成功不创建概念、记录支持或累计用途。上层真实采用后，才由7180/7140对应应用提交用途。

## 8. 迁移与验证边界

已有标量算法、来源检查及预算机制只能在核对等价后复用；不能把DATA中的计算入口长期保留为新应用的业务实现。结构读取和可靠性留在原owner，输入绑定、来源图调度、计算及RC求值迁到各自应用/比较提供者。

旧定义的建立、读取和退出不是持久实际值CRUD。迁移不得因名称含“二次节点”删除合法定义或历史数据；也不得将旧形成宿主、具体输入或平坦左右叶组当作RC完整定义。被替换的公开入口须与其声明、实现和消费者同次迁移后退出，不保留同义双入口；未被替换且仍有合法结构职责的入口不随之删除。

最低验证覆盖：三类输入；有序角色与重复FT；无环共享DAG及预算；内联/值引用准确读取；高阶来源完整复算；单项与多结果失败原子性；精确零/量化零/容差分账；当前与历史读取；RC适用失败与不满足；完整AND；零持久副作用及旧消费者对应关系。结果只证明已覆盖输入和用途，不因一个标量闭环成立宣称全部算法或两个应用完整实现。
