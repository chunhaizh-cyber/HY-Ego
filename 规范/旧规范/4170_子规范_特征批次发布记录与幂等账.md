# 4170 子规范 特征批次发布记录与幂等账

编号：4170
日期：20260907
版本：v0.11
状态：正式子规范

## 1. 定位

旧特征实例槽模型已退役。本规范不再定义其批次创建、换代、专用参与者或生产重放入口，只约束已存在的退役批次材料识别、历史读取和引用保护；不得据此恢复旧槽、旧批次新生产或双轨写入。

直接上级规范：1130、2100。
直接依赖规范：4010、4020、4040、4110。
相关边界规范：4050、4060、4070。

## 2. 历史材料与引用保护

1. 已发布旧记录不得被原地改义为新特征信息，记录中的域、格式、完整有序项目、新值及写前值引用按其原格式解释。
2. 旧记录只证明其当时的发布结果，不证明独立特征节点的当前字段、当前宿主采用、状态或动态。
3. 历史读取必须核对完整材料、来源和所引用事实；格式未知、材料缺失或引用不一致时明确返回不能读回，不得补造字段、拼接不同旧域或返回部分历史成功。
4. 删除影响面须同时覆盖每项的新值引用和写前值引用；同一项目不得重复计数，不得只查新值而遗漏历史依赖。
5. 退役不授权物理擦除旧数据。历史、恢复、审计和其它合法引用尚未闭合时保持保护；后续删除或迁移须有明确范围，不从新特征节点普通 CRUD 隐式触发。
6. 恢复读取不得使旧槽重新成为当前生产模型；读取旧证据与将数据重新准入新结构是不同动作，后者须有正式迁移合同。

## 3. 现行操作边界

1130 / 4110 的特征节点与字段操作组合 L1 可靠写入；2100 值对象不带批次、幂等、版本或生命周期字段，也不要求新建 L2 特征批次专用账。L1 事务、内部幂等、引用保护及恢复义务不变。

本规范不撤销其它具名业务对观察、状态、动态或审计证据的保存义务；这些证据按其所属业务合同处理，不能与退役的特征槽批次账互相替代。
