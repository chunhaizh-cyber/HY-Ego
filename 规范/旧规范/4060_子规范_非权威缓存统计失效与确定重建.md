# 4060 子规范 非权威缓存、索引失效与确定重建

编号：4060
日期：20260802
状态：正式子规范

直接上级规范：0050。

直接依赖规范：4010、4020、4040。

相关边界规范：4070。

## 1. 定位

本规范规定内存权威仓库之外的热缓存、查询索引和统计投影的身份、三态读取、失效、清空与确定重建。它们的唯一来源是指定内存已发布代次，永远不取得事实裁决权。内存已发布权威仓库不是缓存，不得因同处内存而归入可丢弃结构。

## 2. 缓存身份

缓存条目必须绑定查询命名空间、完整键、来源内存代次或事实截止、数据版本和投影规则版本。缺少任一项的条目不得命中。

## 3. 读取三态

```text
命中：条目版本适用且完整，返回值式副本
确定未命中：当前缓存范围已覆盖该键且确认无条目
缓存不可用：未加载、过期、损坏、版本未知或范围不完整
```

缓存不可用必须回读同一内存已发布代次或返回具名结果；不得降级成业务未找到。即使确定未命中，业务合同要求权威确认时仍须读取内存权威仓库；不得改查 SQL 当前行补判。

## 4. 失效与清空

1. 内存新代次原子发布后按代次发布证据失效相关命名空间或版本范围。
2. 失效可以粗于变更范围但不能遗漏受影响条目。
3. 清空缓存、索引或统计投影不得改变内存已发布事实、持久材料引用或业务结果。

## 5. 确定重建

1. 重建只读取指定内存已发布代次 / 事实截止和规则版本。
2. 重建输出先进入独立候选容器，完整验证后一次替换缓存视图；替换不是业务事实发布。
3. 缓存候选损坏只丢弃候选并重新读取内存权威，不写业务事实、SQL 或材料。
4. 相同内存已发布代次和规则版本必须得到语义相同的缓存结果。

## 6. 统计投影

计数、成功率、热度和排序只作解释或优化材料，必须保存来源范围和规则版本；不得反写身份、关系、因果、需求权重或任务状态。
