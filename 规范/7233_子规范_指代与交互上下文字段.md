## 1. 结构约定

本规范按1110分解调用期交互上下文、代词概念统一定义形状和场景指代实例、出现关联与绑定字段。结构约定沿7230第1节；交互记录见7230第3节。

本规范始终分开四种对象（1110第2节）：代词概念定义（第3节）；语言出现，即原文中某一范围及其所属解析；指代实例，即完整指代表达在自然语言场景中形成的指代材料；所指目标，即具有明确类型和身份的节点或有界目标成员组。对应链为“语言出现 → 指代实例 → 所指目标”，实例采用代词概念定义；任何两种对象不得以同一身份、同一字段或互相替代的路径承载。

## 2. 本次交互上下文

```text
交互上下文（调用期）
  本次交互与材料范围
  自然语言场景引用或待保存场景材料
  关联现实场景引用组及关联依据
  当前说话者、受话者组
  当前话题/显著对象有序组
  参考中心、采用维度、参考时间与地点及其来源
  引语作用域栈
  接收方可用的角色/指示/前文/共同知识依据
  近期自然语言场景引用组及选取依据   // 跨场景回指的查找范围
  活动指代实例及待解候选组
  已采用出现到实例、目标或作用域变量的解释组
  待回答问题组
```

不是每个人永久持有一张全局代词表。可用数组/映射实现当次“我、你、这里、刚才”等取值，但键包含交互、作用域和出现位置。单指“你”须能唯一定位受话对象；多人场合需构式确定个人或群体。第三方角色、焦点顺序或出现先后都不足以单独确定“他/它”。时间、地点、参考中心未知就保留所缺约束，不采用机器当前时间或self所在场景补值。

已解释出现保留实际采用目标或变量；上下文更新只影响活动选择和后续解释，不能改变已保存解析内容。引用框架入栈/出栈恢复原说话者及参考信息；未解决的并列候选不任选首项。指代保存按1110发布与读回，并引用具体解析结果而非仅引用规则定义。

需要保存解析/学习时，只保存实际采用的固定语境材料：来源交互或教学材料引用、实际用到的说话者/受话者绑定、参考中心与时地、引语范围、指示/前文/共同知识依据及各项来源引用；缺省项显式未使用/未知，不复制整个会话缓存。无上下文依赖必须显式标记，不能以缺失引用冒充已核验；语境修正以完整当前语境材料整体发布，仍被引用的原依据按引用计数保留，不增加事实截止或历史载荷字段。

### 2.1 三种场景／上下文用语

三种用语的唯一定义见1150；本规范中的字段位置为：自然语言场景——指代实例、主张、自然语言世界场景引用；调用期交互上下文——第2节「交互上下文（调用期）」整表，不是持久世界树节点；现实交互场景——关联现实场景引用组所指向的现实世界窗口场景。不得裸称「交互场景」。

入站「帮我…」的我／你绑定见7240第4.4节。代词有定义／名称关系不等于字段确定值。

## 3. 代词概念的统一定义

代词概念归属自然语言世界：它是语言owner维护的信息存在，置于自然语言世界的场景中，不在2220的四根概念空间内，也不按普通概念类别登记或挂接概念根（1110）。其定义按下列统一形状由语言owner唯一写入。

```text
代词概念定义
  信息存在身份（自然语言世界）
  允许目标类型范围
  参数角色定义组           // 目标、作用域、参照角色/中心、限制域等
  特征约束组               // 正式特征类型 + 被约束角色 + 值/值域
  关系约束组               // 具名关系/求值规则 + 类型化角色映射
  组合及适用条件
```

这是1110规定的统一逻辑定义形状，不是新增的C++类型表。定义的具体参数值由实例语境提供；身份查重使用规范化完整定义，名称和当次目标不参与。特征约束可以限定合法离散值、数值或有类型引用，也可以给出对应类型的允许值域；当次准确值与允许值域分开，不能一律压成数轴。二次特征必须声明输入角色、正式计算规则和结果域，其当次计算结果不写入通用定义。

以下是可组合的特征/约束维度示例，发布时必须映射为可读正式类型和规则；中文说明不是可任意解释的字段字符串，也不是固定代词分类表：

| 维度 | 类型化值或约束 | 定义与本次取值的分界 |
| --- | --- | --- |
| 目标范围 | 已登记节点类型的允许集合及概念条件 | “杯子”约束可进入表达组合；具体杯子身份属于实例 |
| 交互角色 | 本作用域说话者、受话者、第三方；可不施加角色限制 | 角色规则稳定，具体参与者从作用域取得 |
| 指示取向 | 近指、远指及所需参照角色/维度规则 | “这/那”不固定距离值，中心和适用维度来自语境 |
| 数量与群体组成 | 单项、多个、数量值域，包含/排除指定角色的条件 | 具体成员及“我们”是否含受话者由构式和语境决定 |
| 同一与回指 | 与某一绑定角色相同，或满足其回指约束 | “自己”须有可识别绑定域，不能永久等同于系统自我 |
| 选择与量化 | 待求角色、限制域、全称/存在/任指条件 | 量化作用域与谓词按7240组合，不把未求值当作不成立 |
| 关系参与方式 | 集合整体、成员逐项、具名互指规则 | 关系方向和覆盖要求由构式给出，不能由复数自动推全配对 |

典型定义组合及本次应用如下；每行只是用法，不能转为互斥的概念大类：

| 表达 | 主要定义约束 | 本次必须确定或保留的参数 |
| --- | --- | --- |
| 我 / 你 | 目标承担说话者 / 受话者角色 | 本次作用域和参与者；引语可以改变角色取值 |
| 他 / 她 / 它 | 第三方及该语言用法的目标类别/称谓条件 | 可恢复的具体目标；称谓不能直接当生理事实 |
| 这 / 那 | 近指 / 远指，依赖相应参考中心 | 指示依据、维度和目标范围；不限于物理空间 |
| 谁 | 可承担相应主体角色的待求身份 | 限制域、变量及其绑定作用域；是否询问由整句决定 |
| 什么 | 待求内容或对象，范围由角色约束限定 | 不预设为具体物体；保留类型候选和本次用途 |
| 这里 / 那里 / 什么时候 | 地点或时间角色与相应指示/待求约束 | 合法时地信息或语言内容中的变量，不能用裸时钟补值 |
| 我们 / 你们 / 他们 / 这些 | 数量和群体条件，组合角色或指示约束 | 集合范围与成员；“我们/咱们”的受话者包含按用法判断 |
| 自己 / 彼此 | 作用域内回指 / 具名互指关系 | 绑定角色、群体和关系参数，不凭词面生成全部事实边 |
| 每个 / 任何一个 / 某个 | 限制域与量化条件，依附完整表达 | 谓词作用域、分配方式或未知成员；不要求先枚举未来成员 |

## 4. 场景指代实例、出现关联与绑定

指代实例的单位是完整指代表达：“这杯水”“那个蓝色的杯子”与“它”“多少”同样各自形成指代实例，近指/远指、修饰、类别、数量等约束都属于该实例，不能只给“这”“那”或单个代词建实例而丢掉其余约束。不同语言出现可以经核验复用同一兼容实例（如后文“它”关联前文“这杯水”的实例），也可以各自保留不同实例；复用与否按本节和第4.2节核验，不由词面相同或不同决定。

```text
场景指代实例
  实例身份                 // 建立信息存在节点时为节点身份；否则为所属含义网内的局部标识
  所属自然语言场景引用
  采用的代词概念定义引用组
  表达组合规则及定义参数映射
  本次作用域与固定语境依据
  本次附加类型/特征/关系约束
  指向内容 = 已确定目标 | 作用域变量 | 待消歧候选
  持有“指代消解结果”实例特征F    // 仅建立节点的实例持有；值为已确定目标引用，未确定时为空

已确定目标
  单目标强类型引用，或明确范围的完整目标成员组
  实际选取依据

作用域变量
  变量所属规则/查询材料与局部编号
  类型与限制条件
  绑定/量化作用域及用途

待消歧候选
  零个或多个强类型候选
  已检查范围与完整性
  待补约束及来源

指代表达出现
  来源材料固定范围、所属解析引用
  指代实例引用
  本次采用定义/表达规则及附加约束
  本次采用的目标或变量，或明确未决内容
  本次作用域与采用依据
```

按第4.1节建立节点的指代实例是自然语言世界场景中的信息存在。“指代消解结果”F由语言owner维护：指向内容变化（取得、更换或撤销已确定目标）时，与指向内容在同一次发布中更新该F，当前值实际改变时按1160生成状态并挂入该实例所在的自然语言场景。需求必需字段的“有确定值”判定和指代澄清子需求的目标特征都以该F为准（1110、7240），统一使用此名称。

“这个杯子”整体形成一个实例：近指条件、杯子条件及数量共同约束所指；“那本书”是另一个实例。后续“它”可在相同语境和兼容约束下引用前者，并保存本次采用的杯子目标。再次出现“这个杯子”不因词面相同就强制复用；重新指向另一个杯子时，须区分后续活动选择与此前出现的固定解释。

变量属于场景内规则/查询等信息的内容，不取得虚构现实存在身份。相同变量的多处使用须映射到同一所属材料与局部编号；不同作用域的同名变量不合并。候选、变量和已确定目标互为不同载荷分支，不能同时假称唯一绑定；它们与7231的解析覆盖结果、7240的表达目的和工程失败分开。

纯解析可以只产生调用期实例材料。按请求保存语言场景时，符合第4.1节条件的指代实例建立信息存在节点，其余随含义网记录；两者都允许保存语义完整的作用域变量或有来源的未决内容，不要求先造一个具体目标。建立节点的未决实例有自身信息身份，不等于已成立指向具体对象的关系。语言场景结构与实例内容的写入分别遵守既有场景/语言服务合同，场景成员关系只保留一份权威。

“杯子A/杯子B”等实例专名经其所属领域别名合同指认已有目标；可减少代词使用，却不删除目标原有指代实例，也不把实例别名改为概念名称。指代实例不是目标本身、词条出现或名称关系，三条路径不可相互替代。

### 4.1 建立信息存在节点的条件

指代实例满足下列任一条件时，由语言owner在所属自然语言场景中为其建立独立的信息存在节点：

1. 需要独立身份，例如须与同场景其它实例区分并被后续出现复用；
2. 被其它内容单元、其它自然语言场景（跨场景引用）或需求引用；
3. 需要维护其“指代消解结果”F及由此生成的状态。

不满足上述条件的指代实例只作为所属语言场景含义网中的指称材料记录，保留本节结构中的定义引用、约束、作用域和指向内容，不取得信息存在身份，也不持有“指代消解结果”F；一旦后续出现上述条件，再按同一内容建立节点，并改由节点承载，含义网只保留一份权威。是否建立节点只看上述需要，不按词面区分：完整指代表达与单个代词、疑问代词适用同一规则。

### 4.2 消解顺序与跨场景回指

后出现的指代表达按下列顺序寻找可复用的实例或所指目标，每一步都须核验本次定义、修饰、类型、数量与作用域约束相容：

1. 本语言场景内已有的兼容指代实例（篇章内共指）；
2. 交互上下文给出的近期自然语言场景中的兼容指代实例，经含义网中带类型的跨场景“引用”关联（如“刚才说的那杯”）；
3. 按交互上下文和本次允许的只读查询范围寻找所指目标。

任一步出现多个合法候选时保留待消歧候选，不取首项，也不因前一步有候选就省略对歧义的检查。跨场景回指只表达所指关系：不把原场景实例移入或复制为本场景成员，不改变原场景成员归属，也不改写原出现的固定解释；本场景需要另带作用域或附加约束时，另建本场景实例，并以跨场景引用关联原实例。被跨场景引用的原实例按第4.1节须有节点。回答、确认、纠正、拒绝等跨场景“回应”引用由7240规定，不在本规范展开。

没有交互上下文时只建立本语言场景内的篇章内共指，不查找近期语言场景，也不按焦点、self或当前窗口补值；所指目标保持待绑定，“指代消解结果”F为空。

### 4.3 疑问代词实例

“谁”“什么”“多少”等疑问代词形成的指代实例，是带明确类型和作用域的待求位：指向内容取“作用域变量”分支，类型与限制条件来自代词概念定义、所在角色和修饰约束（如“水温多少”中待求位类型为温度值），作用域为包含它的询问内容。是否构成向受询者提问由外层询问及表达用途决定（7240），识别出疑问代词本身不等于提问。待求位不是所指目标，也不虚构目标节点；其“指代消解结果”F（建立节点时）在取得回答前为空。回答方语言场景中的跨场景回应关联该待求位、回答已理解为该类型的合法值后，由语言owner在同一次发布中把回答值写入该F，当前值改变时按1160生成状态并挂入询问所在的自然语言场景；原询问中已保存的解释不改写。

## 5. 写入和引用闭包

指代实例内容（含建立节点的实例与仅记录在含义网内的实例）、跨场景引用、出现绑定及其“指代消解结果”F静态路由既有语言owner；代词概念与语言实例分别写入；实例指向任何领域目标都不取得目标写入权。指代保存按1110发布与读回，并引用具体解析结果（7231）而非仅引用规则定义。物理删除及引用完整性遵守0050。

## 6. 最低验证

应覆盖：多方/引语/日记指代；完整短语实例及后续“它”的兼容复用；建节点三项条件与仅记录在含义网内的实例分开；同场景、近期场景、所指目标的消解顺序及多候选保留；无交互上下文时只建篇章内共指；跨场景回指不移动、不复制原实例；疑问代词待求位的类型与作用域；同目标多实例与同词面不同目标；变量、候选与唯一绑定分支；当前焦点变化不改原解释；专名与代词并存；“指代消解结果”F与指向内容同次发布。验证实施与是否运行测试按AGENTS第7.1节。
