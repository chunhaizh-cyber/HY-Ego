# 2100 根规范 特征值

编号：2100
日期：20260824
状态：正式根规范

## 1. 根定位

特征值是某一实例特征在一个已发布事实代次中的不可变类型化取值事实。每项正式特征值具有唯一非零稳定事实身份、所属实例特征、值表示、原始材料或独立材料引用、来源和创建 / 退出生命周期，但它不是节点，不通过节点关系冒充值身份。

特征值只承载原始材料和证明该材料当前性的结构事实，不承载坐标、轮廓、颜色、需求满足、任务完成或其它业务解释。业务含义由正式特征定义、状态、动态、二次特征、因果证据和比较注册解释。

### 1.1 运行期权威

特征值的运行期权威由同一内存已发布事实截止中的实例特征身份、特征定义、唯一当前属性槽、值事实身份、值表示、材料、来源、生命周期和发布证据共同成立。已发布载荷不可原地改变；SQL、序列化、哈希、缓存和显示只作持久证据、恢复输入或非权威投影。

独立材料文件只有先经唯一不可变材料服务发布为强类型不可变材料身份，再被已发布值事实引用，才参与运行期事实。裸路径、摘要、长度、缓存键或任意节点编码均不能替代不可变材料身份。

## 2. 本项目承载

```text
实例特征节点
+ 宿主关系和特征定义关系
+ 按正式值表示类型唯一指向当前值事实的属性槽
+ 具有稳定编码、所属实例、类型化材料、来源和生命周期的值事实
+ 退出当前后仍可按稳定编码和事实截止读取的历史值事实
```

值事实的原始材料只允许：

```text
I64
I64组（有序 VecI64）
U64组（有序 VecU64 / 稳定身份组）
独立材料引用
```

一个向量取值整体属于一个值事实；不得为每个分量、每个采样点或每一种可能取值建立节点。分量角色、单位、维度、顺序和业务含义属于特征定义及其比较合同，不进入 L1 原始材料解释。

轮廓、图像、点集、点云和其它大型或需要独立引用的材料，使用一个不可变材料身份承载完整载荷，特征值事实只保存稳定材料引用。不得把大型材料拆成无业务必要的节点组；也不得用区间、摘要或文件长度代替准确材料。

## 3. 值事实、节点和值域分账

1. 普通标量、向量和材料引用是值事实，不是节点。
2. 需要独立关系、独立来源角色、独立生命周期或被多个结构独立引用的材料对象必须先作为独立材料节点发布，再由值事实引用。
3. 区间、点集、允许目标集合和其它值域项描述某特征定义允许的取值集合；它们不是某次实际特征值，也不得替代实际观测材料。
4. 量化分箱、召回区间、容差和不确定性边界是具名合同或派生材料；除非对应领域服务重新准入，否则不成为原始特征值。
5. 同一值事实只能有一种值表示和一组自洽材料。材料发生变化必须形成新值事实；不得推进旧载荷后继续沿用旧事实身份。
6. 原始材料形状不产生业务解释。三个 I64 不自动成为坐标，I64 组不自动成为轮廓，U64 组不自动成为集合。

## 4. 特征定义准入

每个叶子特征定义必须在允许实例值进入正式链路前冻结：

```text
允许的唯一原始值表示
内联材料或独立材料引用策略
适用时的单位、维度、分量角色和顺序
允许值域及值域版本
适用时的材料格式、解析合同和合同版本
来源类型与生命周期边界
```

同一当前特征定义不得同时允许多个相互替代的原始值表示。需要从 I64 改为向量、从内联向量改为独立材料或发生其它不兼容解释变化时，必须形成新的特征定义或新的明确兼容合同；调用方不得仅通过选择另一个材料变体改变机器语义。

向量值域不得默认压成一个标量区间。逐分量区间只表达轴对齐允许区域；不能表达分量相关性、方向、单位向量、旋转、拓扑或形状约束。需要这些约束时必须使用具名值域结构和版本化规则。

## 5. 写入、换代与读回

特征领域服务是实例槽、当前属性槽和值事实的唯一公开写入方。需求、任务、方法及其它高级服务只能经特征领域服务取得值式投影，不得直接写 L1 值事实或把材料缓存作为当前值。

新增当前值必须在一项原子写入中：

```text
验证实例特征、正式特征定义和共同事实截止
验证定义允许的值表示和值域
验证来源身份和生命周期
独立材料引用适用时，经唯一不可变材料服务在同一事实截止完整读回
发布一个新值事实
把实例特征的唯一当前属性槽指向该值事实
读回并逐字段证明成功
```

换代必须额外验证写前当前属性槽和值事实仍与请求一致，并在同一事务中退出旧值事实、发布新值事实和切换当前属性槽。拒绝、版本漂移、许可拒绝、资源失败或内部不一致不得留下半切换状态。

L1 只验证稳定编码、owner、当前节点存在、值表示和结构引用闭包；它不证明一个独立材料引用具有不可变材料资格。该资格必须由特征领域服务通过不可变材料服务的强类型读回取得，不能仅检查编码非零或节点存在。

有效当前读回必须在同一事实截止证明：

```text
实例特征及宿主 / 定义关系当前有效
特征定义允许的值表示和值域合同当前有效
唯一当前属性槽指向唯一当前值事实
值事实所属实例、值表示、完整材料、来源和生命周期一致
独立材料引用适用时，材料身份、格式、长度、摘要、来源和生命周期完整
```

历史读回按值事实稳定编码和历史截止返回已发布材料及生命周期；不得通过当前属性槽反推丢失的历史值。

## 6. 幂等、批次与生命周期

新增、换代和批次写入必须使用具名幂等身份。同键同义只能读回同一值事实和同一发布截止；同键异义、写前当前值漂移或定义合同漂移均零写入。

4170 的批次发布记录只证明请求项目、顺序、写前值和发布后值的幂等及审计语义，不成为实例当前值的第二权威。当前值始终由实例特征当前属性槽和值事实共同裁决。

值事实退出当前后继续作为历史事实保留。退役影响面必须覆盖其在 4170 批次账中的新值角色和写前值角色，并按项目去重；批次账异常不得改写值事实历史。

独立材料节点退出必须遵守 L1 当前引用闭包：仍被当前值事实引用时不得单独退出。值事实退出不自动删除材料；材料是否仍被其它值或结构引用必须由材料服务和 L1 引用闭包共同裁决。
