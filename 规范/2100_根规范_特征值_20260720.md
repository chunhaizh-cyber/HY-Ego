## 1. 权威边界

本规范是特征值信息的现行机器合同。特征值是可独立、长期保存和复用的最小原始材料对象；旧规范中与统一稳定编码、材料类型、完整原始材料、压缩树和全零材料规则冲突的条款退出。

规范正式成立不自动授权迁移或物理删除旧数据，也不证明当前实现、持久化和恢复已经完成。

## 2. 根定位

特征值信息是需要独立、长期保存和复用的最小原始材料对象。它只回答：

```text
这份材料的稳定节点身份是什么
材料采用哪一种物理类型
完整原始材料是什么
为快速查询形成了哪些有损粗筛用压缩层
```

特征值信息不回答材料代表什么业务特征、属于哪个存在或场景、何时观察、当前是否采用、形成哪个区间或概念。

特征值信息可以先独立建立，后续再由特征节点引用。保存后的原始材料不可原地修改；新材料必须建立或复用另一个特征值节点。

## 3. 身份与节点类型

### 3.1 稳定身份

新版特征值身份就是基础数据集分配的特征值节点稳定编码。稳定编码在同一基础数据集中全局唯一；编码自身不携带类型，调用方必须通过统一节点类型字段确认目标确实是特征值节点。

禁止使用材料摘要、容器位置、内存地址、字符串名称或压缩根值冒充特征值身份。

### 3.2 共享结构节点

特征值类初始化必须形成或恢复下列共享结构节点：

```text
节点类型字段节点
特征值类型节点
二维压缩层类型节点
三维压缩层类型节点
材料物理类型字段节点
原始材料字段节点
压缩材料字段节点
```

二维和三维压缩层使用不同类型节点，防止相同 `uint64` 材料在二维根与三维根之间被错误复用。不得仅依赖运行期索引中的附加枚举区分两者。

这些结构节点必须在基础数据集中长期保存。初始化应先按固定结构身份恢复并完整核验；只在确认尚不存在时建立。不得在每次构造特征值类对象或每次程序启动时重新建立一套结构节点。

## 4. 固定字段

### 4.1 特征值节点

每个正式特征值节点固定包含以下字段：

| 字段 | 类型 | 基数 | 含义 |
| --- | --- | --- | --- |
| 节点身份 | 稳定编码 | 恰一 | 基础数据集分配的特征值节点身份。 |
| 节点类型 | 节点引用 | 恰一 | 指向共享的特征值类型节点。 |
| 材料物理类型 | I64编码 | 恰一 | 由调用特征类明确提供，特征值类不得猜测。 |
| 原始材料 | 强类型直接值 | 恰一 | 完整、不可变的原始材料或规范化全零描述。 |

除上述字段外，不得增加：

```text
业务特征类型
所属特征、存在、场景或任务
单位、坐标系、观察时间
当前、历史、区间、概念或比较规则
宽、高、深
压缩层数量或压缩层列表
压缩根值
版本、事实代次、幂等身份或操作记录
```

### 4.2 压缩层节点

每个压缩层节点固定包含：

| 字段 | 类型 | 基数 | 含义 |
| --- | --- | --- | --- |
| 节点身份 | 稳定编码 | 恰一 | 基础数据集分配的普通节点身份。 |
| 节点类型 | 节点引用 | 恰一 | 指向二维或三维压缩层类型节点。 |
| 压缩材料 | `vector<uint64_t>` | 恰一 | 该分辨率下的纯占用材料。 |

压缩层节点不保存材料物理类型字段、宽高深字段、层号字段、根值字段或内部上级节点字段。二维或三维由压缩层类型节点区分；分辨率由材料长度和对应几何规则确定。

## 5. 材料物理类型

新版特征值类允许以下材料物理类型：

| 类型 | 原始材料 | 说明 |
| --- | --- | --- |
| `U64数组` | `vector<uint64_t>` | 完整、有序、保留重复的无符号数组。 |
| `I64数组` | `vector<int64_t>` | 完整、有序、保留重复的有符号数组。 |
| `UTF8字符串` | `string` | 完整UTF-8字节序列。 |
| `二维二值格` | `vector<uint64_t>` | 正方形二值占用格，支持分层压缩。 |
| `三维二值格` | `vector<uint64_t>` | 正方体二值占用格，支持分层压缩，不包含颜色。 |

材料物理类型只描述保存和查询材料所需的物理形态，不是业务特征类型。空间坐标、轮廓、体素、颜色、尺寸等业务解释由特征类的正式特征类型提供。

单个 `int64_t` 不建立独立特征值节点，由特征类直接保存在准确特征节点中。

特征值类禁止根据 `vector<uint64_t>` 的长度、内容或调用路径自行判断它是普通数组、二维格还是三维格。调用特征类必须显式提交材料物理类型，类型与材料变体不相容时拒绝且零写入。

## 6. 普通材料保存与复用

`U64数组`、`I64数组`和`UTF8字符串`不建立空间压缩树。

两份普通材料只有在以下条件全部相同时才是同一特征值：

```text
材料物理类型相同
容器长度相同
每个同下标元素或每个字节完全相同
```

顺序和重复均参加比较，不自动排序、去重或解释成集合。精确相同内容必须全局复用同一特征值节点；零项时新建一项，多项时属于内部不一致，不得选择首项或继续建立第三项。

字符串保存前必须是合法UTF-8；空字符串是否允许由调用特征类型的准入规则决定，特征值类不赋予其业务含义。

## 7. 二维二值格

### 7.1 形状

二维二值格采用正方形 `N×N`：

```text
N = 8 × 2^k，k >= 0
总位数 = N²
vector<uint64_t>.size() = N² / 64
```

无法连续减半到 `8×8` 的分辨率拒绝。位序固定为：

```text
i = y × N + x
字索引 = i / 64
位索引 = i % 64
```

低位先行；1表示占用或黑色，0表示未占用或白色。二维格不保存现实坐标、尺寸、单位或颜色。

### 7.2 压缩

每次把下层 `2×2` 子格按逻辑 OR 汇总为上层一个格：

```text
任一子格为1 -> 上层为1
全部子格为0 -> 上层为0
```

逐层压缩到 `8×8`，根层恰由一个 `uint64_t` 保存。

## 8. 三维二值格

### 8.1 形状

三维二值格采用正方体 `N×N×N`：

```text
N = 4 × 2^k，k >= 0
总位数 = N³
vector<uint64_t>.size() = N³ / 64
```

无法连续减半到 `4×4×4` 的分辨率拒绝。局部原点位于立方体一个角，三个维度只沿局部正方向编号：

```text
i = (z × N + y) × N + x
字索引 = i / 64
位索引 = i % 64
```

三维二值格只表示占用，不包含颜色，不表达现实空间坐标、尺寸或姿态。

### 8.2 压缩

每次把下层 `2×2×2` 八个子格按逻辑 OR 汇总为上层一个体素，逐层压缩到 `4×4×4`；根层恰由一个 `uint64_t` 保存。压缩层不保存颜色。

## 9. 全零材料

逻辑全零格不把展开后的全部零块写入特征值类。调用方的具名材料准备能力负责识别逻辑全零并转换为规范化描述；该转换不属于特征值类：

```text
二维全零描述：[0, 1, N]
三维全零描述：[0, 2, N]
```

特征值类只接受已经规范化的全零描述，不负责从任意大型全零输入扫描并决定转换。描述作为对应二维或三维材料的完整原始材料保存，不为它建立实际压缩层节点。

读取后，由上层解析能力根据类型和 `N` 确定性展开逻辑形状；特征值类不分配展开后的零块。

全局复用规则为：

```text
每个二维分辨率N至多一个全零特征值节点
每个三维分辨率N至多一个全零特征值节点
二维和三维不得共用同一节点
不同N不得共用同一节点
```

普通完整二值格如果所有位均为0，属于非规范化输入，应在进入特征值类前由上层转换；若仍以普通完整输入提交，特征值类拒绝且零写入。

## 10. 压缩树物理组织

压缩树只使用基础数据集的外部父子关系：

```text
粗粒度压缩层节点
──父子关系──>
细粒度压缩层节点
──父子关系──>
完整原始特征值节点
```

例如：

```text
8×8二维压缩根
└─ 16×16二维压缩层
   └─ 32×32二维压缩层
      └─ 64×64完整原始特征值节点
```

原始分辨率已经是根分辨率时，仍使用：

```text
根压缩层节点
└─ 完整原始特征值节点
```

压缩层只是查询索引材料，不是正式特征值，不能挂到特征节点、场景、存在、任务或概念上。只有完整原始特征值节点可以被其它对象引用。

同一物理类型下，相同压缩材料及相同上级路径必须复用同一压缩层节点。二维和三维即使根值相同也不得共用根节点。

压缩是单向查询索引，不要求从根值恢复完整原始材料。正式读取始终从完整原始特征值节点读取原始材料字段。

## 11. 保存流程

### 11.1 普通材料

```text
接收明确材料物理类型和完整材料
-> 核验类型与材料变体
-> 通过内容索引召回候选
-> 从基础数据集完整读回候选字段
-> 精确相同则复用
-> 无候选则建立完整特征值节点和三个固定字段
-> 完整读回后返回节点编码
```

### 11.2 二值格

```text
接收明确二维/三维物理类型和最高分辨率材料
-> 核验形状、分辨率和位序
-> 拒绝未规范化全零普通输入
-> 逐级计算压缩材料
-> 按物理类型和根材料查询或建立根节点
-> 沿父子关系逐层查询或建立更细压缩层
-> 在最细压缩层下查询完整原始材料节点
-> 精确相同则复用，否则建立
-> 完整读回后返回原始特征值节点编码
```

任一步失败不得把字段不完整的节点报告为成功。基础数据集尚未提供原子变化集时，实现必须逆序删除本调用尚未公开且未被复用的字段、关系和节点；不能删除已复用结构。

## 12. 查询流程

### 12.1 按节点读取

按节点读取必须核验：

```text
节点存在
节点类型字段恰一并指向特征值类型节点
材料物理类型字段恰一且受支持
原始材料字段恰一且与物理类型相容
二值格材料形状或全零描述合法
```

任一字段缺失、重复、类型错误或引用损坏均不得返回部分成功。

### 12.2 按完整材料查询

普通材料使用内容索引召回后进行完整内容复核。

二值格查询使用与保存相同的压缩算法：

```text
计算根材料
-> 查询同物理类型根候选
-> 沿父子关系逐级核对每层压缩材料
-> 到达完整特征值节点
-> 核对完整原始材料
-> 完全一致才命中
```

哈希、根值和中间压缩层只能缩小候选范围，不能单独证明材料相同。

## 13. 公开能力

新版特征值类至少提供：

```cpp
bool 初始化();

稳定编码 保存或取得特征值(
    材料物理类型,
    const 新特征值材料&);

std::optional<新特征值信息> 获取特征值(
    稳定编码 特征值节点);

std::vector<稳定编码> 查询特征值(
    材料物理类型,
    const 新特征值材料&);

bool 是特征值节点(
    稳定编码 节点);
```

保存接口同时承担新增与精确复用，不另建一个允许重复写入的普通“添加”入口。

保存后的原始材料不可修改，因此不提供普通修改函数。特征值节点默认永久保留，本版不提供主动删除；将来需要回收时必须先建立完整引用查询和受保护回收合同，不能直接调用基础数据集删除节点。

## 14. 职责边界

### 14.1 特征值类负责

- 结构节点初始化和恢复；
- 材料物理类型与材料变体核验；
- 普通材料精确查重；
- 二值格形状核验、分层压缩、树形查询和复用；
- 特征值节点完整读回及类型确认；
- 不完整写入的本调用清理。

### 14.2 特征值类不负责

- 建立或解释业务特征类型；
- 决定材料属于坐标、轮廓、体素、颜色、尺寸或其它业务概念；
- 特征值区间、漂移范围、代表值和比较算法；
- 建立准确特征、子特征、存在、场景、状态、动态或因果；
- 特征概念形成、概念归纳和概念上下位；
- 观察时间、当前采用、历史记录或任务治理；
- 体素颜色保存。

特征类是材料物理类型的提供者。特征类先依据正式业务特征类型确定材料物理类型，再调用特征值类；特征值类不得反向查询特征类型或概念。

## 15. 基础数据集要求

正式实现至少需要基础数据集提供或由其上层唯一封装以下通用能力：

1. 普通节点、父子关系、节点字段和值字段的增删改查；
2. 稳定编码持久保存，并在程序重启后恢复；
3. 共享结构节点的固定身份恢复或确定性查找；
4. 按字段节点及字段内容查询候选，或能从固定根完整遍历；
5. 节点、字段和关系的原子变化集，或等价的可靠失败清理；
6. 同内容并发保存时的唯一性保证；
7. 读取时能够区分不存在、字段缺失、字段重复、引用损坏、资源失败和内部不一致。

索引可以是非权威加速材料，但跨启动复用不能只依赖特征值类对象内部的 `std::map`。命中索引后必须回读基础数据集中的正式节点、关系和值。

## 16. 非成功结果

公开操作至少应能区分：

```text
入口非法
未初始化
材料类型不相容
材料格式不合法
未规范化全零输入
未找到
重复候选或结构不唯一
字段缺失或重复
关系损坏
并发冲突
资源失败
发布结果未知
内部不一致
```

空编码、`false`或空容器可以作为当前初版代码的最小返回形态，但不能在正式应用中混淆上述原因；进入正式业务链前应形成结构化结果。

## 17. 旧特征值合同替代范围

本规范替代旧2100/4120中的下列冲突口径：

| 已退出旧口径 | 现行口径 |
| --- | --- |
| 值身份不是节点身份 | 特征值身份就是经类型字段确认的普通节点稳定编码。 |
| 只允许I64、I64组、U64组、独立材料引用 | 独立特征值节点允许U64数组、I64数组、UTF8字符串、二维二值格、三维二值格；单I64仍由特征节点内联。 |
| 二维/三维只是U64组的业务解释 | 二维/三维是明确的材料物理类型，但仍不等于业务特征类型。 |
| 原始层和全部压缩层共同放入一个U64组 | 原始材料只保存最高分辨率完整材料，压缩层分别保存为普通节点并用父子关系组织。 |
| 体素材料包含颜色段 | 新版三维二值格只保存占用，不包含颜色。颜色由独立特征表达。 |
| 通用值事实owner和旧L1可靠性合同 | 采用基础数据集节点、关系和值字段；正式持久恢复和原子性需由新底座补齐。 |

1130、1140、1150、1165、1170和7160已经按本规范的身份和值承载方式同步正式化；代码与数据迁移仍须独立证明。

## 18. 非权威实现符合性

- 五种材料物理类型；

1. 相同普通材料重复保存返回同一节点；不同材料返回不同节点；
2. U64/I64数组保持顺序和重复，字符串按完整UTF-8字节复用；
3. 二维 `8、16、32、64...` 和三维 `4、8、16...` 合法，不规则分辨率拒绝；
4. 每层压缩结果严格等于下一细层对应子格OR；
5. 二维和三维相同根值不共用根节点；
6. 不同高分辨率材料允许共享相同粗层前缀；
7. 最终命中必须核对完整原始材料，不能仅凭根值命中；
8. 全零描述按类型和N精确复用，普通全零展开材料拒绝；
9. 压缩层节点不能作为正式特征值返回或挂到特征节点；
10. 任一中间写入失败不暴露字段不完整的成功节点；
11. 程序重启后恢复同一结构节点和同一特征值身份；
12. 并发保存相同材料只形成一个正式特征值节点；
13. 无引用保护时不提供主动删除；
14. 不写业务特征类型、单位、场景、存在、区间、概念或历史字段。
