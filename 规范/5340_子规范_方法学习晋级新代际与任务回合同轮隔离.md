# 5340 子规范 方法学习晋级新代际与任务回合同轮隔离

## 1. 定位

本规范定义从状态、动态、因果及必要治理上下文的调用期值式学习材料形成非权威方法学习候选，经独立晋级授权发布不可变新方法代际，并保证新代际不反写产生它的任务回合。晋级授权是具有独立发布效果的业务治理事实，不是认知证据或“系统理解”的证明。

本链只允许单向推进：

```text
已发布状态 / 动态 / 因果 + 必要任务 / 方法 / 结算上下文
-> 按非零事实截止形成可重建调用期学习材料
-> 可重建统计
-> 非权威学习候选与确定差异
-> 独立晋级复核和授权
-> 方法领域发布不可变新代际
-> 后续任务筹办重新召回并补全候选与条件信息
-> 执行前选择和冻结
```

统计、学习候选、工程见证、线程或一次成功都不能直接证明方法好用、修改现有方法、创建任务或授权动作。调用期学习材料不取得独立生产事实身份。

## 2. 方法内容快照与调用期学习材料

学习候选必须以动作执行前冻结的方法完整内容快照为来源。快照至少包含：

```text
来源方法稳定身份
+ 独立方法内容版本
+ 确定排序的全部条件规格
+ 确定排序的全部结果规格
+ 完整动作入口规格
+ 输入 / 输出场景规格
+ 来源生命周期和适用范围
```

条件或结果规格各自的来源版本、任务选择时生命周期、任务回合编号和日志版本都不能替代方法内容版本。

调用期学习材料必须由 4330 在指定非零事实截止按正式来源读回组合，按“任务 / 回合 + 状态 / 动态 / 直接因果身份 + 方法内容版本 + 结算分栏 + 规则版本”确定排序和去重，并逐项复核来源、适用范围和当前性。状态、动态和因果是认知证据；任务、方法、选择、实际结果和结算只作治理上下文。待结算材料不得进入效果差异；冲突、非法、过期或来源缺失材料不得由统计层静默挑选、补造观察节点或修补。

调用期学习材料不得持久化为节点、关系、阶段账或恢复事实。候选需要重建时，只按正式来源身份、事实截止和规则版本重新读取；G0、幂等账、事务见证、发布读回、恢复材料和消费水位不得进入学习语义或样本计数。

## 3. 学习候选性质与差异合同

学习候选是值式、非权威、可清空重建的材料，只能由学习候选服务从完整方法快照、确定调用期学习材料和 5330 允许的学习能力形成。候选必须保留来源方法、内容版本、来源身份与共同事实截止、候选规则版本、适用范围和确定差异。

差异只能按正式方法结构角色和完整规格裁决：

| 差异 | 裁决 |
| --- | --- |
| 新增 | 新规格存在，来源版本没有对应正式角色规格 |
| 保留 | 正式角色和完整规格相同 |
| 移除 | 来源规格存在，候选明确表明新版本不再具有 |
| 替换 | 同一正式角色存在唯一旧规格和唯一新规格，且完整内容不同 |
| 未知 | 材料不足，无法确定新增、移除或替换 |
| 冲突 | 同一角色多映射、同身份异内容或正式材料互相矛盾 |

正式角色、方法内容版本或调用期学习材料不足时必须输出未知或冲突，不得按概率、单一分数、哈希、名称、任务序号或向量首项猜测差异。

尝试学习、定向学习和练习继续服从 5330：它们只形成各自允许的候选、值式材料或缺口，不得越权创建方法首、动作入口、稳定条件结果对、新代际或证据专用生产事实。

## 4. 独立晋级复核与授权

晋级必须由独立晋级服务复核，至少同时确认：

1. 来源方法身份和内容版本仍是候选声称的版本；
2. 来源状态、动态、因果和治理上下文仍有效，统计能够从同一事实截止和来源集合确定重建；
3. 候选完整，全部差异可确定，没有未知或冲突；
4. 任务或治理对象提供了明确、当前且范围匹配的晋级授权；
5. 晋级规则版本受支持，安全、禁止项、动作入口和验证合同通过；
6. 同一来源版本、调用期学习材料和候选未被同义重复消费，也不存在异义晋级冲突；
7. 新代际的全部条件、结果、动作和适用范围可以形成自足的完整方法结构。

晋级服务只输出强类型晋级授权或拒绝，不直接写仓库、方法关系、生命周期或当前选择。统计线程、学习材料组合方、学习候选服务和任务执行体均不得代替晋级服务授权。晋级授权只裁决新方法代际能否发布，不证明来源认知正确或方法已经好用。

材料缺失、来源版本漂移、授权失效、规则不支持、未知差异或冲突必须在发布前结构化拒绝；前置通过后出现候选自相矛盾、重复当前授权或发布读回异常，属于内部逻辑错误。

## 5. 不可变新代际

只有方法领域服务可以消费有效晋级授权并发布新代际。新代际必须同时具有：

```text
新的稳定方法身份
+ 来源方法 / 父代的正式代际关系
+ 独立方法内容版本与代际身份
+ 完整条件、结果、条件结果来源和动作入口
+ 适用范围、生命周期、验证和来源事实追溯
+ 发布版本与当前性
```

新代际是可独立召回和完整复核的方法事实，不是差异补丁、统计行或旧方法上的可变覆盖。来源方法及其既有追溯信息继续保留审计；不得原地修改来源方法身份、内容版本或既有运行事实来伪造晋级，也不得建立“来源观察关系”复制调用期学习材料。

父方法、前置方法、后续方法和任务序号只表达各自业务关系，不能充当父代、代际号或新方法身份。发布新代际也不自动使其可执行；后续召回仍须按 5300 回读当前生命周期、完整规格、动作入口、条件和风险。

## 6. 任务回合同轮隔离

任务回合在动作前按 5230 冻结任务、筹办轮次、方法身份、方法内容版本、动作入口、条件、输入、授权、路径和验证合同。该冻结一旦进入执行，本轮形成的状态 / 动态 / 因果材料、统计、学习候选、晋级授权和新代际都不得：

- 改变本轮已冻结的方法或动作；
- 事后替换本轮选择记录或结果归因；
- 把新代际结果回写成来源方法本轮已有能力；
- 在本轮执行中绕过重新筹办直接使用新代际；
- 以同义候选或相同结果把两代方法合并为一项事实。

新代际只对后续任务回合可见。后续回合必须重新取得该任务的筹办执行权，权威重读方法登记和内容版本，按状态完成找方法与查条件；随后由执行前选择 fresh 复核、采用并形成新的执行冻结。若相关方法版本在旧冻结执行前已经变化，旧冻结按 5230 失效，而不是就地切换到新代际。

不同任务可以在各自回合并发复用同一来源方法或后继代际；隔离键仍是各任务稳定身份及其正式回合，不得因共享方法而错误串行化任务。

## 7. 幂等、冲突与恢复边界

同一来源方法版本、同一确定调用期学习材料、同一候选规则和同一完整差异形成学习候选稳定键：

```text
同键同义 -> 候选或晋级请求幂等读回。
同键异差异、异授权范围或异目标代际 -> 冲突，零方法结构变化。
同一父代和代际身份出现多个已发布当前方法 -> 内部不一致，停止并追根因。
```

学习候选、统计和召回索引可以清空重建；晋级授权和已发布方法代际是权威业务事实，必须保留来源与版本。恢复材料只能作为工程恢复输入；恢复完成后仍须从正式状态、动态、因果和业务上下文重新组合调用期学习材料。恢复过程不得自动晋级、自动发布新代际、自动选择方法或执行动作。

## 8. 写入与消费权

| 环节 | 唯一业务权力 | 禁止 |
| --- | --- | --- |
| 状态 / 动态 / 因果与业务上下文 | 各自正式 owner | 不为学习另建证明事实 |
| 调用期学习材料 / 统计 / 学习候选 | 当前组合方、统计与学习候选服务 | 值式、非权威，不形成晋级事实 |
| 晋级授权 | 独立晋级服务 | 不直接写方法仓库，不冒充认知证据 |
| 新代际发布 | 方法领域服务及专用数据操作 | 不改任务冻结或来源方法历史 |
| 后继选择 | 取得执行前选择工作项执行权的任务领域 | 不由筹办、学习或方法服务代选 |

## 9. 验证

验证至少覆盖：

- 完整方法内容快照与规格来源版本、任务序号分离；
- 调用期学习材料确定排序、去重、同截止复核和待结算排除；
- 新增、保留、移除、替换、未知和冲突六类差异；
- 候选非权威、独立晋级授权和方法服务唯一发布；
- 新代际使用新稳定身份、保留父代且不原地覆盖；
- 本轮结果不改变本轮冻结，新代际只在后续回合重新筹办后可见；
- 同义幂等、异义冲突、多当前代际追根因和恢复不自动晋级；
- 不生成用途观察、目标裁决证据或其它证明型节点 / 关系，工程正确性材料不进入学习样本。
