# 2310 根规范 段落

编号：2310
日期：20260911
版本：v0.5
状态：正式根规范

## 1. 根定位

段落是一次实际段级语言材料，承载原文范围与有序自然句组成。可以独立用于交互，也可以组成文章；不必为单独段落创建空文章。它不是任务容器、业务状态或段落组织知识。

## 2. 固定字段与结构

段落逻辑内容字段为节点身份、原文范围；范围引用固定文本材料，不保存可与原文漂移的第二段落文本。语言从文章或独立来源继承，未知/混合按7220处理。

沿用4010段落节点类型17与段落身份命名域。可选文章归属、自然句有序组成和解析关联通过语言owner关系承载；范围、关系及固定定义按7230。上下级字段投影不能成为第二组成权威。

## 3. 组成、范围与历史

1. 独立段落无文章父；已组成的段落在同一发布版本中恰一文章父，父内序号唯一。
2. 自然句也可独立；进入段落后同一版本恰一段落父，并保留句序与重复出现。
3. 重复文本可共享值或材料，但不同使用位置仍有不同节点/组成身份。
4. 同源自然句范围包含在段落范围内，兄弟有序不重叠；原始空白和分隔符由源文保留。
5. 修订形成新固定内容/解析或组成发布，保留历史和来源，不在旧范围下静默更换原文。

## 4. 写入、读取与语义边界

语言结构服务唯一保存段落、组成与解析，读取必须互证角色、源范围、适用父归属、顺序和固定版本。

概念/世界陈述、需求目标提议、任务叙述或方法学习内容只作为带来源的解析材料提交。独立外来请求先交self；任务内子目标继续按现行父任务承接链处理，不把所有语言请求强制塞入父任务。需求仍只由self产生并确认，不回写为段落业务字段。

## 5. 禁止与路由

禁止以段落文本、摘要、行号、指针链或界面分组建立身份和业务结论；禁止复制目标领域事实形成第二权威。表达知识由2340保存，组织与解析算法按7240，学习按7250。
