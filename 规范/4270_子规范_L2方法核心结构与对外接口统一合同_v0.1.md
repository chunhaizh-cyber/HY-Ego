## 1. 定位

本合同冻结 DATA-L2 方法结构的长期信息模型、公开结构接口，以及 DATA 外按任务目标特征查找方法并使用方法自身能力描述的职责边界。

在全局架构中，方法结构属于 `ARCH-L4` 的业务兼容记录，不定义 `DATA-L4`。本合同保留现有 C++ 名称与 ABI，但方法虚拟存在、方法治理状态和方法治理动态不得继续充当 ARCH-L2 通用结构的第二权威；后继方法业务 provider 只能经 ARCH-L2 通用虚拟存在、状态、动态公开服务取得/提交结构引用。DATA-L2 仍只做结构 CRUD，不判断方法成功、任务完成或目标达成。

长期方法信息只允许三类方法结点：

```text
方法头结点
条件结点
结果结点
```

方法整体结构固定为：

```text
方法头
├── 一个当前主动作绑定
├── 一个或多个当前方法用途事实
├── 唯一方法治理虚拟存在
├── 零个或多个条件结点
├── 零个或多个结果结点
├── 零个或多个条件结果关系
├── 零个或多个输入规格关系
└── 零个或多个限制条件关系
```

动作绑定、用途、输入规格、限制条件、条件结果关系、版本和生命周期只能作为强类型关系、引用或值式记录存在，不得增加第四类长期方法知识结点。

DATA-L2 只负责结构 CRUD、共同截止读取、值式投影、预算和中性错误；方法是否匹配任务、是否当前适用、是否可以执行统一由 DATA 外业务提供者裁决。

## 2. 强类型与值域

### 2.1 身份

固定使用：

```text
L2方法身份
L2方法条件身份
L2方法结果身份
L2方法治理虚拟存在身份
L2方法输入规格身份
L2方法限制条件身份
L2方法用途身份
L2方法条件结果关系身份
```

上述身份均为强类型稳定编码包装，不得以显示名称、字符串、枚举序号、函数地址或集合下标替代。

目标对象类型不建立方法专属身份，固定引用概念 owner 的 `L2概念身份`，并且该概念必须在同一事实截止正式读回为存在本体根或归属于存在本体根的当前普通概念。方法 owner 只保存跨 owner 强类型引用，不复制概念身份、根归属或生命周期。

结果类型不建立方法专属身份，固定使用闭合强类型引用：

```cpp
using L2方法结果类型引用 = std::variant<
    L2目标状态合同身份,
    L2概念身份>;
```

联合分支机器序号固定为：

```text
1 = L2目标状态合同身份
2 = L2概念身份（动态根或动态根下普通概念）
```

持久负载固定为两个 `U64`：`[分支机器序号, 强类型身份.稳定编码值]`。完整性、幂等材料、索引键和稳定排序都先比较分支机器序号，再比较稳定编码值；不得使用 `std::variant::index()`、编译器布局、类型名、哈希值或访问器顺序作为机器合同。

`L2目标状态合同身份` 由状态结构 owner 在同一截止正式读回；`L2概念身份` 作为结果类型时必须在同一截止正式读回为动态本体根或归属于动态本体根的当前普通概念。两种分支不可互换，即使底层稳定编码数值相同也不相等。任意稳定编码、目标值、显示名称、方法来源编码或不可变材料身份均不得冒充结果类型。

动作入口若已有独立动作域，方法头引用正式动作入口身份；当前工程仍使用稳定动作键时，稳定动作键只作为动作绑定中的稳定引用，不构成第四类方法知识结点。

### 2.2 变化方向

统一三态为：

```text
负方向 = 1
无变化 = 2
正方向 = 3
```

零值非法。不得从目标数值大小、日志文本、比较返回码或特征名称临时推导方向。

### 2.3 限制类别

限制条件类别固定为：

```text
禁止项 = 1
适用范围 = 2
规格约束 = 3
安全限制 = 4
```

零值和未知值非法。限制类别只描述结构来源，不判断限制当前是否成立。

## 3. 方法头、动作与治理虚拟存在

方法头至少包含：

```text
方法身份
身份来源
方法内容版本
方法规格版本
当前主动作绑定
方法治理虚拟存在身份
方法 owner 生命周期事实
```

一个当前方法头恰有一个当前主动作绑定和一个方法治理虚拟存在。动作换代、内容换代或规格换代必须旧退新建并保留历史。

方法治理虚拟存在（ARCH-L4 兼容宿主引用）：

```text
不属于世界 L2存在身份
不进入世界树
不能被多个方法共享
方法 owner 只承载业务关系和治理引用；生命周期和方法状态结构由 ARCH-L2 通用虚拟存在、状态和动态服务唯一承载
```

DATA 不执行动作，不判断动作能否实现用途，也不把方法状态解释为任务状态。

## 4. 方法用途事实

每个当前方法至少一项当前用途。每项用途精确包含：

```text
L2方法用途身份 身份
L2方法身份 方法
U64 作用对象角色
L2概念身份 目标对象类型
L2特征定义身份 可改变特征类型
L2方法变化方向 变化方向
L2方法结果类型引用 结果类型
稳定编码 来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

用途只承担粗召回四元组：

```text
目标对象类型
+ 可改变特征类型
+ 变化方向
+ 结果类型
```

用途命中只证明“可能相关”，不得直接成为正式候选、当前就绪、当前路径或执行许可。

同一方法允许多个用途；用途事实按完整四元组、作用对象角色和身份稳定升序返回。重复的同义当前用途属于内部不一致，不得静默去重掩盖结构错误。

## 5. 条件、输入规格与结果

### 5.1 条件事实

每项条件精确包含：

```text
L2方法条件身份 身份
L2方法身份 方法
U64 作用对象角色
L2概念身份 目标对象类型
optional<L2场景身份> 场景
L2特征定义身份 特征定义
L2目标状态合同身份 条件状态合同
稳定编码 来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

条件表示会使相同动作产生不同结果的正式状态条件。零场景表示不限制具体场景，不得用零特征、零状态合同或自由文本表达万能条件。

### 5.2 输入规格关系

输入规格是方法头或具名条件引用的强类型值式关系，不建立输入规格结点。每项精确包含：

```text
L2方法输入规格身份 身份
L2方法身份 方法
optional<L2方法条件身份> 条件
U64 作用对象角色
U64 顺序
L2方法规格材料 规格
稳定编码 来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

`条件`为空表示全方法输入规格；非空时必须引用同一方法的当前条件。相同方法、条件、角色和顺序至多一项当前关系。

### 5.3 结果事实

每项结果精确包含：

```text
L2方法结果身份 身份
L2方法身份 方法
U64 作用对象角色
L2概念身份 目标对象类型
L2特征定义身份 特征定义
L2方法变化方向 变化方向
L2方法结果类型引用 结果类型
稳定编码 来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

结果第一层只表达对象类型、特征、方向和结果类型。变化量、速度、持续时间、频率和单位变化对应量必须引用正式动态或二次特征材料，不得无限增殖结果类型。

方法新增或替换写前，方法结构服务必须在调用方给出的同一非零期望事实代次，经 `L2概念结构服务` 正式读取目标对象类型及概念型结果类型，经 `L2状态结构服务` 正式读取状态合同型结果类型。任一端点未找到、已退出、错根、混代或读回不完整均结构化拒绝且零方法事实写入；DATA 不判断该对象类型或结果类型是否适合某个任务。

## 6. 条件结果关系与限制条件

### 6.1 条件结果关系

条件结果关系精确包含：

```text
L2方法条件结果关系身份 身份
L2方法身份 方法
L2方法条件身份 条件
L2方法结果身份 结果
U64 顺序
稳定编码 来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

结构门禁：

```text
条件.方法 == 结果.方法 == 关系.方法
条件、结果和关系的内容版本相同
条件、结果和关系在读取截止均有效
```

同一条件允许关联多个结果，同一结果允许由多个条件关联。相同方法、条件、结果和顺序至多一项当前关系。关系不得跨方法头。

### 6.2 限制条件关系

限制条件是方法头或具名条件引用的强类型值式关系，不建立限制结点。每项精确包含：

```text
L2方法限制条件身份 身份
L2方法身份 方法
optional<L2方法条件身份> 条件
L2方法限制条件类别 类别
U64 作用对象角色
U64 顺序
L2方法规格材料 规格
稳定编码 来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

`条件`非空时必须引用同一方法当前条件。相同方法、条件、类别、角色和顺序至多一项当前关系。

DATA 只保存限制的结构类别与材料，不判断禁止项是否命中、适用范围是否满足、规格是否兼容或安全限制是否授权。

## 7. 六项静态能力值式投影

### 7.1 投影身份与数量

一份方法可以形成零份、一份或多份六项静态能力投影。投影不是持久节点、关系、第二权威事实或永久布尔值。

每个当前结果是投影主轴。只有存在与该结果四元组完全相同的当前用途时，才能形成该结果对应的结构投影：

```text
用途.目标对象类型 == 结果.目标对象类型
用途.可改变特征类型 == 结果.特征定义
用途.变化方向 == 结果.变化方向
用途.结果类型 == 结果.结果类型
用途.作用对象角色 == 结果.作用对象角色
```

用途缺失、四元组冲突或同义用途复义时，该粗召回项只能形成结构缺口，不得伪造投影。

作用对象角色是上述完整配对合同的一部分。用途与结果的作用对象角色不相等时，DATA-L2 固定形成`用途结果冲突`结构缺口，不形成该用途 / 结果对的六项投影。投影 DTO 中只保留五项互证通过后的单一能力签名角色，不携带“用途角色 / 结果角色”双字段，也不表达半配对材料。DATA 外 provider 必须直接消费结构缺口分账，不得把角色不等重新解释为任务相对不兼容，不得扩张投影 DTO，也不得额外读取完整方法来重复执行 DATA-L2 已拥有的用途 / 结果结构配对裁决。

### 7.2 投影结构

每份投影精确为：

```text
输入条件
目标对象类型
可改变特征类型
变化方向
结果类型
限制条件
```

其中：

```text
输入条件
    = 与主轴结果具有当前条件结果关系的条件语义项
    + 这些条件引用的输入规格项
    + 全方法输入规格项

限制条件
    = 这些条件引用的限制条件项
    + 全方法限制条件项
```

条件语义项只包含：作用对象角色、目标对象类型、场景、特征定义、条件状态合同。输入规格项和限制条件项只包含结构类别、角色、顺序和规格材料；方法身份、节点身份、来源稳定编码、创建代次和显示文本不参与语义等值，但必须在完整读回中可追溯。

一个结果没有任何条件结果关系时，输入条件组可以为空；这只表示静态签名没有条件项，不证明当前就绪。若方法存在当前条件但主轴结果没有任何关系，DATA 结果必须同时标记“条件结果关系缺失”结构缺口，后继不得把空组解释为完整关系。

### 7.3 规范化

DATA-L2 形成投影时必须：

1. 固定调用方给出的非零事实截止；
2. 在该截止读取方法头、用途、条件、结果、关系、输入规格和限制条件；
3. 按字段字典序稳定排序输入条件和限制条件；
4. 同义重复项只允许在来源关系不同但语义项完全相同且不违反当前唯一键时值式去重；
5. 任何必需字段非法、跨方法引用、混代或当前唯一键复义均返回内部不一致；
6. 对语义完全相同的投影稳定去重；
7. 投影组按目标对象类型、特征、方向、结果类型、输入条件、限制条件和主轴结果身份稳定升序返回。

不得按内存布局、哈希碰撞、字符串拼接、名称或函数地址形成投影等值。

### 7.4 投影消费边界

六项投影是方法自身的完整描述，不是任务目标解析结果，也不是任务查找请求。任务取得特征粗召回项后，可以读取投影用于对象类型、变化方向、结果能力、条件、输入规格、限制条件和结构缺口复核；不得要求任务在取得方法前预先形成输入条件或限制条件，再与方法投影六项逐项相等。

投影中的空输入条件组或空限制条件组只描述该方法结果当前没有对应结构项，不是通配符。方法名称、函数名、标签、稳定编码或显示文本仍不得代替任一正式能力字段。

## 8. DATA-L2 方法结构公开接口

### 8.1 CRUD

方法结构服务必须提供：

```text
新增方法头
替换方法内容
退出方法头
读取方法头

新增、读取、退出方法用途
新增、读取、退出方法条件
新增、读取、退出方法结果
建立、读取、退出条件结果关系
建立、读取、退出输入规格关系
建立、读取、退出限制条件关系
读取完整方法
```

写入口负责结构类型、端点、基数、版本、幂等、事务、生命周期和独立读回，不判断方法业务真实性。

### 8.2 完整读取

`读取完整方法` 在一个调用方冻结的事实截止返回：

```text
方法头
动作绑定
用途组
方法治理虚拟存在身份
条件组
结果组
条件结果关系组
输入规格组
限制条件组
内容版本、规格版本和生命周期
共同事实截止
结构缺口组
```

当前读取使用请求头的期望事实代次作为共同截止；历史读取使用显式历史截止。服务不得把旧截止自动升级到最新事实代次。

结构缺口只允许表示缺用途、用途结果冲突、条件结果关系缺失、输入规格引用冲突或限制引用冲突；它不是能力缺口节点、方法不可用裁决或学习需求。

### 8.3 按目标特征类型粗召回

公开只读入口：

```text
按特征读取方法用途粗召回组
```

请求精确包含：

```text
读取类别
事实截止
可改变特征类型
最大扫描用途事实数
最大粗召回方法数
```

结果返回稳定升序的零个或多个方法身份、命中的用途事实、实际扫描数和共同事实截止。预算不足必须返回数量预算不足且不携带截断后伪完整候选。

粗召回只比较`用途.可改变特征类型`与请求目标特征定义，不读取名称、函数名或分类标签，也不判断对象类型、变化方向、结果类型、条件、限制或任务适用性。现行`按用途读取方法粗召回组`四元组精确键接口退出；不得保留为任务查找旁路。

### 8.4 投影读取

公开只读入口：

```text
读取方法六项静态能力投影组
```

请求精确包含方法身份、读取类别和事实截止；结果返回规范化投影组、结构缺口组和同一共同事实截止。它不接收任务，不执行匹配，不写事实。

## 9. DATA 外任务筹办消费边界

DATA 外任务筹办提供者负责：

```text
接收任务目标特征、同截止目标比较结果和对象概念材料
→ 调用按特征读取方法用途粗召回组
→ 逐方法读取六项静态能力投影组
→ 按对象类型兼容、所需变化方向和结果能力兼容形成适用候选
→ 取得候选后才读取并评估方法自己的条件、输入规格、限制条件和条件结果关系
→ 只为实际采用的一份方法方案形成缺失条件草案或合法等待
```

对象兼容、多概念保留、目标是否已完成、所需方向、结果能力兼容、条件满足、方案采用和当前就绪均属于 DATA 外业务判断。DATA-L2 只返回同截止结构事实和有界粗召回结果。

提供者必须区分完整特征粗召回为空、存在粗召回但无适用候选、方法结构不完整、多候选缺选择证据、采用方案无需条件草案、采用方案存在缺失条件、合法等待、数量预算不足、当前性漂移、引用冲突、入口拒绝、资源失败和内部错误。结构不完整项不得吞并为“没有相关方法”。

任务相对不兼容证据只从已经形成的完整投影与任务目标材料比较产生，包括目标对象类型、所需变化方向、结果类型种类和目标状态合同身份。用途 / 结果作用对象角色不等时投影尚未成立，只能沿`用途结果冲突`结构缺口进入`方法结构待补齐`分账；不得要求该分支形成任务不兼容证据或动态覆盖不存在的投影。

任务侧不再建立`方法静态能力准入请求.需求`六项镜像，也不执行`L2方法六项静态能力签名相同(投影, 任务需求)`。原`方法静态能力候选准入提供者::读取匹配候选`必须迁移为上述分阶段业务提供者或删除，不得保留旧精确相等旁路。

该提供者只读结构事实，不直接写需求树，不创建路径、实例、执行冻结、学习需求、能力缺口对象或任务状态。

## 10. 版本、替换与历史

以下变化必须增加方法内容版本并形成不可变新代际或正式替换：

```text
动作绑定改变
用途改变
条件改变
结果改变
条件结果关系改变
输入规格改变
限制条件改变
```

内容版本、规格版本和生命周期版本继续分账。新版本不得修改已经冻结的任务路径或实例方法；旧版本必须能够按历史截止完整读回和重新形成当时的投影。

现有只按目标状态合同组织结果、没有方向、结果类型、用途或条件结果关系的旧普通方法结构不能自动升级。迁移必须由方法 owner 以新合同明确补齐或替换；缺项时只返回结构缺口，不得从目标值、名称、场景或旧结果键反推。

## 11. 禁止事项

禁止：

- 方法长期信息出现头、条件、结果之外的第四类知识结点；
- 持久化六项能力投影、匹配 bool 或能力缺口节点作为第二权威；
- 把特征粗召回命中当适用候选；
- 把适用候选或方案采用当当前就绪；
- 把当前就绪当已经选择或执行；
- 用方法名称、动作名称、函数名、分类标签或固定编号参与语义匹配；
- 从目标状态数值临时推导变化方向或结果类型；
- 要求任务在查找方法前预知输入条件或限制条件；
- 用空输入条件或空限制条件充当通配符；
- 在预算不足时返回截断候选并标记成功；
- DATA 判断条件当前成立、方法适合任务、动作能够成功或任务已经完成；
- 方法运行结果直接覆盖长期方法知识；
- 用方法成功证明目标达成、路径验证、任务完成、需求满足或正式结算。

---

## 12. 验证

结构与业务验证至少覆盖：

1. 一个方法的多个用途和多个结果形成多份独立投影，不发生笛卡尔误配；
2. 条件只进入其正式关联结果的输入条件组；
3. 全方法和条件级输入规格、限制条件合并后稳定排序、去重和读回；
4. 特征粗召回只按可改变特征类型命中，不提前过滤对象、方向、结果或条件；
5. 六项投影继续完整返回方法自身条件、输入规格和限制条件，空组不作为通配符；
6. 用途命中但缺用途结果互证、缺条件结果关系或引用冲突时进入结构缺口分账；
7. 全量特征扫描无命中且无预算失败时才返回粗召回空；
8. 预算不足不返回伪完整候选；
9. 同一共同截止下当前、历史读取和投影重建一致；
10. 新方法版本不改变旧任务冻结和旧截止投影；
11. DATA-L2 全链零任务业务判断、零路径和实例写入；
12. 旧四元组粗召回和任务六项精确相等提供者没有残留调用点；
13. 全流程不建立能力缺口节点、关系、owner 或数量事实。

---

## 13. 完成边界

本合同正式生效只证明以下机器语义已经冻结：

```text
方法头、条件、结果三类长期知识结点
方法动作、用途和治理虚拟存在
统一三态变化方向、存在概念目标对象类型和闭合强类型结果引用
条件结果、输入规格和限制条件正式关系
一方法零到多份六项静态能力值式投影
同一截止规范化与稳定排序
特征类型粗召回、投影读取和 DATA 外适用判断职责分账
结构缺口、空候选和预算不足分账
版本、历史和旧结构不得自动反推迁移
```

不证明：

```text
方法结构迁移已经实现
六项投影、特征粗召回或 DATA 外适用判断代码已实现
任务筹办已经消费候选
当前就绪复判、路径、实例或执行冻结已实现
真实方法执行、任务完成、需求结算或价值回流已实现
```
