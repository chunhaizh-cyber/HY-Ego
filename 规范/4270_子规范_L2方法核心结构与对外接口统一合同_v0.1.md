# 4270 子规范 L2方法核心结构与对外接口统一合同

日期：20260817

编号：4270

直接上级规范：0050。

直接依赖规范：3300、4010、4015、4030、4190、4200、4230。

相关边界规范：3200、4260、5230、5250、5300—5340、4201、ACCEPTANCE-01。

## 1. 定位

本合同冻结 L2 方法结构的最小长期信息模型和公开服务接口。

长期方法信息只允许三类方法结点：

```text
方法头结点
条件结点
结果结点
```

方法整体语义固定为：

```text
方法头
├── 方法动作
├── 方法用途
├── 方法虚拟存在关系
├── 条件结点组
└── 结果结点组

条件结点
    -> 条件结果关系
    -> 结果结点
```

其它长期结构只能以：

```text
关系
引用
版本
生命周期
状态载体
```

存在，不增加第四类方法信息结点。

---

## 2. 强类型身份

冻结：

```text
L2方法身份
L2方法条件身份
L2方法结果身份
L2方法虚拟存在身份
```

动作入口若已有独立动作域，则使用动作域强类型身份。

否则保留：

```text
L2稳定动作身份 / 稳定动作键
```

作为动作绑定中的稳定引用。

不得把 `L2方法动作入口身份` 继续解释为第四类方法信息结点。

---

## 3. 方法头事实

建议核心 DTO：

```text
L2方法头事实
{
    L2方法身份 方法;
    L2节点族身份来源事实 身份来源;

    L2方法动作绑定事实 动作;
    L2方法用途事实 用途;

    L2方法虚拟存在身份 方法虚拟存在;

    L2方法内容版本 内容版本;
    L2生命周期 生命周期;
}
```

方法头不直接内嵌完整条件组 / 结果组。

完整方法读取通过共同事实截止组合：

```text
方法头
+ 条件组
+ 结果组
+ 条件结果关系组
```

形成值式读取结果。

---

## 4. 方法动作绑定

`L2方法动作绑定事实` 至少表达：

```text
方法身份
稳定动作身份 / 稳定动作键
optional 输入场景
optional 输出场景
来源稳定编码
版本
生命周期
```

动作绑定属于方法头关系，不是独立方法知识类别。

规则：

1. 一个当前方法头最多一个当前主动作绑定；
2. 动作换代旧退新建；
3. 历史动作绑定保留；
4. DATA 不执行动作；
5. DATA 不判断动作能否实现用途。

---

## 5. 方法用途事实

`L2方法用途事实` 至少表达：

```text
方法身份
作用对象角色
L2特征定义身份 目标特征
L2变化方向 期望方向
来源稳定编码
版本
生命周期
```

变化方向必须使用项目统一三态：

```text
负
零
正
```

用途用于粗粒度能力召回。

第一版建议：

```text
一个方法头至少一个当前用途
```

若未来一个方法明确具有多个主要用途，应允许：

```text
方法头 -> 1..N 用途关系
```

但用途仍不是第四类方法结点，可以是值式关系事实。

---

## 6. 条件事实

`L2方法条件事实` 最小结构：

```text
L2方法条件身份 身份
L2方法身份 方法

作用对象角色
optional<L2场景身份> 场景
L2特征定义身份 特征定义
L2目标状态合同身份 条件状态合同

来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

条件只负责表达：

> 会导致结果方向发生区别的状态条件。

不得把所有任务运行参数无差别固化成长期条件。

---

## 7. 结果事实

`L2方法结果事实` 最小结构：

```text
L2方法结果身份 身份
L2方法身份 方法

作用对象角色
L2特征定义身份 特征定义
L2变化方向 变化方向

来源稳定编码
L2方法内容版本 内容版本
L2生命周期 生命周期
```

第一层结果不保存某次运行的具体最终值。

若需要表达：

```text
变化量
变化速度
持续时间
单位变化对应量
```

必须引用正式二次特征 / 动态关系材料，不得污染第一层方向结果。

---

## 8. 条件结果关系

冻结：

```text
L2方法条件结果关系事实
{
    关系稳定编码 身份;
    L2方法身份 方法;
    L2方法条件身份 条件;
    L2方法结果身份 结果;
    std::uint64_t 顺序;
    L2方法内容版本 内容版本;
    L2生命周期 生命周期;
}
```

结构门禁：

```text
条件.方法 == 结果.方法 == 关系.方法
```

同一条件允许多结果。

同一结果允许被多个条件关系引用。

关系不得跨方法头。

---

## 9. 方法虚拟存在

每个当前方法必须恰好一个：

```text
L2方法虚拟存在身份
```

固定关系：

```text
方法头 -> 方法虚拟存在
```

方法虚拟存在：

```text
不属于世界 L2存在身份
不进入世界树
不能被多个方法共享
```

方法状态接口必须基于该虚拟存在，但方法状态内容不作为 `L2方法头事实` 的固定字段扩张。

---

# 10. L2方法结构服务公开接口

## 10.1 方法头接口

固定：

```text
读取方法身份来源
新增方法头
读取方法头
退出方法头
```

### `新增方法头`

请求至少包含：

```text
L2结构请求头
L2结构幂等身份

动作绑定材料
用途材料
内容版本
生命周期材料
```

原子形成：

```text
方法头节点
方法族归属
方法动作绑定
方法用途
方法虚拟存在
方法 -> 虚拟存在关系
```

新增方法头时允许：

```text
条件组 = 空
结果组 = 空
```

表示方法知识尚未补全，但不得被业务层误认为已可执行方法。

---

## 10.2 条件接口

固定：

```text
新增方法条件
读取方法条件
按方法读取当前条件组
退出方法条件
```

新增条件时必须验证：

```text
方法身份当前合法
条件特征身份合法
条件状态合同合法
内容版本合法
```

DATA 不判断该条件是否真的会导致结果差异。

---

## 10.3 结果接口

固定：

```text
新增方法结果
读取方法结果
按方法读取当前结果组
退出方法结果
```

新增结果时必须验证：

```text
方法身份当前合法
结果特征身份合法
变化方向合同合法
内容版本合法
```

---

## 10.4 条件结果关系接口

固定：

```text
建立条件结果关系
读取条件结果关系
按方法读取当前条件结果关系组
按条件读取当前结果组
退出条件结果关系
```

建立关系必须验证：

```text
方法 / 条件 / 结果同属一个方法
均当前有效
内容版本兼容
```

---

## 10.5 方法完整读取

固定：

```text
读取完整方法
```

返回：

```text
方法头
动作绑定
用途
方法虚拟存在身份
条件组
结果组
条件结果关系组
共同事实截止
```

这是值式组合读取，不产生“完整方法节点”。

---

## 10.6 按用途召回方法

固定：

```text
按用途读取当前方法候选
```

请求至少包含：

```text
目标特征
目标方向
最大扫描预算
最大候选方法数
```

返回：

```text
0..N 个方法头身份 / 简要用途事实
共同事实截止
```

只按长期用途做粗召回。

---

## 10.7 按结果召回方法

固定：

```text
按结果方向读取当前方法候选
```

请求至少包含：

```text
结果特征
结果方向
optional 作用对象角色
预算
```

查询链：

```text
结果规格
-> 结果结点
-> 方法头
```

返回方法候选，不自动判断当前条件是否成立。

该接口替代当前过重的“按完整结果状态合同直接绑定方法结果”的唯一召回模型。

---

# 11. 方法状态服务接口

方法虚拟存在的状态接口至少固定：

```text
读取方法虚拟存在
读取方法当前状态
提交方法状态变化
读取方法状态历史
读取方法状态动态
```

方法状态服务只负责“方法现在怎么样”。

不得与：

```text
方法动作
方法用途
条件
结果
```

长期知识混写。

---

# 12. DATA 外方法业务接口

至少固定以下业务入口：

```text
登记方法
补充方法条件
补充方法结果
建立条件结果知识
读取方法能力
按任务目标召回方法
裁决方法当前适用性
形成任务方法路径
实例化方法
提交方法运行证据
提交方法学习证据
发布方法新代际
```

---

## 12.1 `登记方法`

职责：

```text
确认动作身份
确认用途
建立方法头
建立方法虚拟存在
```

只建立头不代表方法知识已经足以执行。

---

## 12.2 `按任务目标召回方法`

输入：

```text
任务目标特征
目标方向
```

流程：

```text
先按用途粗召回
必要时按结果方向补召回
去重方法头
返回候选
```

不得按方法名称模糊命中。

---

## 12.3 `裁决方法当前适用性`

输入：

```text
方法头
当前世界事实
当前任务上下文
```

流程：

```text
读取方法条件
读取条件结果关系
读取当前事实
判断哪些条件当前成立
确认对应结果方向
```

输出例如：

```text
当前适用
当前不适用
条件不足
结果方向不匹配
证据不足
当前性失效
```

DATA-L2 不执行这个判断。

---

## 12.4 `形成任务方法路径`

业务输入：

```text
任务
候选方法
当前成立条件
对应结果
当前输入 / 参数 / 上下文
```

输出：

```text
任务方法路径候选
```

方法本体不保存该任务路径。

---

## 12.5 `实例化方法`

从当前选中任务方法路径形成本轮不可变实例方法。

实例方法冻结：

```text
来源方法
内容版本
任务
路径
动作
成立条件
预期结果方向
输入
参数
验证 / 归因
```

---

# 13. 版本与换代

长期方法知识发生语义变化时不得原地覆盖。

以下变化至少触发内容版本换代：

```text
方法动作改变
方法用途改变
条件改变
结果方向改变
条件结果关系改变
```

后天运行证据本身不立即改写方法知识。

必须：

```text
运行证据
-> 学习裁决
-> 新方法知识代际
```

---

# 14. 禁止事项

禁止：

- 方法长期信息出现头 / 条件 / 结果之外的第四类知识结点；
- 把动作入口误当方法知识节点；
- 把方法虚拟存在误当方法知识节点；
- 把每个参数都自动提升为长期条件；
- 把禁止项 / 适用范围无条件提升为长期方法节点；
- 结果第一层保存大量具体实例值；
- 同特征同方向仅因变化量不同无限增殖结果；
- DATA 自动判断条件是否成立；
- DATA 自动判断方法是否适合某任务；
- DATA 自动实例化方法；
- 运行结果直接覆盖长期方法知识；
- 用方法成功证明任务完成。

---

# 15. 完成边界

本合同正式生效只证明：

```text
方法头 / 条件 / 结果三类长期信息节点
动作与用途进入方法头
结果第一层按变化方向表达
条件用于区分不同方向结果
条件结果正式关系
方法虚拟存在作为状态唯一承载体
L2方法结构公开接口
DATA外方法业务接口
```

已经冻结。

不证明：

```text
现有 L2普通方法结构已迁移
旧规格身份已删除
方法召回已重写
任务方法路径已实现
实例方法已实现
方法学习闭环已实现
```
