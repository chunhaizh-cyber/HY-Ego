# 7110 子规范 存在概念中间层归纳与归类

编号：7110
日期：20261105
版本：v3.1
状态：正式子规范

直接上级规范：2220。

直接依赖规范：7100、1130、1140、4180、4181、7160。

相关边界规范：1150、2210、4240、7140。

## 1. 定位

存在概念演进有两条不能互相替代的路径：

```text
实例化与专属派生（7100）：存在以存在根实例化 -> 有特征后派生专属概念，挂存在根下
中间层归纳（本规范）：选定至少两个来源 -> 提取共同特征值域与共同子存在概念
                      -> 在存在根与专属概念之间形成或复用中间层概念
```

存在概念图以存在根为唯一顶层；未经归纳的专属概念直接上位为存在根。中间层概念是可共享的类别概念。

## 2. 定义与概念图

1. 存在概念定义固定为自身特征值域组和已知子存在概念组。物理父子存在关系只用于读取子存在，不是概念上下位关系；关系类型、成员角色、关系端点和名称不参与归纳。
2. 概念图边方向固定为“上位 -> 下位”，同类别边构成以存在根为顶层的多父无环图，只保存必要直接边；层号、路径和兄弟列表均为可重建投影。

## 3. 触发

归纳可以由以下两种方式触发，均不在每次实例插入时做全图扫描：

1. **明确需求触发**：业务或认知应用为具体目标发起，明确有限且不少于两个的来源存在或来源概念、拟比较的特征范围及非零预算。
2. **数量阈值周期触发**：同一直接上位下的专属概念数超过子规范规定的阈值时，由宿主维护周期发起一次限定于该上位下的归纳；阈值为可修订规则参数。

来源为存在时，应用须读回其当前全部特征、已知子存在及其概念；来源为概念时，须完整读回两组定义。读取不完整、来源退出、预算不足或类别不符不是“无共同点”。

## 4. 共同约束提取

只保留对全部来源成立的共同约束：

1. 正式特征类型必须可对齐；
2. 值域完全等价时保留；同一类型存在共同上位特征概念值域且各来源值域均被其包含时，以该值域替换；
3. 子存在概念只有在所有来源均具有同一已知子存在概念（或其共同上位）时才保留。

不同类型不得因数值接近合并。比较或值域包含能力缺失时返回能力缺失，零写入，不降级为相等。

## 5. 形成、复用与归类

共同特征组为空或不足以满足归纳目标时，返回“未形成共同概念”，零写入；不为全部可能的特征子集预建概念。

共同定义成立后：

```text
规范化共同定义
-> 在存在类别的类别概念中完整比较，选择唯一最具体同义概念复用，或确认零匹配后创建
-> 对每个来源证明其定义蕴含候选定义且至少一项严格更具体
-> 新中间层的直接上位为存在根或仍包含它的已有中间层
-> 建立 中间层 -> 来源 直接边，删除被其严格覆盖的“存在根 -> 来源”等冗余直接边
-> 完整读回定义与受影响直接边
```

同义复用时出现两个以上并列的同义概念（定义完全相同而身份不同），属于概念图内部不一致，逐项报告逻辑错误；来源不能证明严格包含时不归类。两者都不得任意接边。上位候选中多个互不包含的最具体者是合法多上位（7100第5节），分别接边，不属于内部不一致。既有合法多父边不因新归纳删除。

## 6. 修订与同义复用

1. 专属概念随实例原地同步（7100）。
2. 中间层概念可随来源变化原地修订其定义与上位位置（认知漂移，0050第1.5节）。修订后若与同类别已有类别概念完整定义相同，直接复用已有概念，被修订概念的全部引用改接后按引用归零退出（7140）。
3. 专属投影不适用同义复用（2220）。

## 7. 分工

概念树服务只保存已裁决的定义、类别、直接边和生命周期并读回；不选择来源、不提取共同点、不决定归纳目标。归纳应用组织调用、逐项读回、失败停止和结果汇总，不直达基础数据集。

## 8. 验证语义

1. 实例化与归纳分离，插入不触发全图扫描；数量阈值触发只限定于对应上位；
2. 共同约束不足时零写入；
3. 角色、关系类型、端点、名称和位置不进入共同定义；
4. 中间层严格更宽、同义复用、多父保留、无环；
5. 冗余“存在根 -> 来源”直接边在被中间层覆盖后删除；
6. 并列同义概念和能力缺失不伪造概念；互不包含的多个最具体上位分别接边。

## 9. 退役口径

下列口径退出新生产：

- 零上位“根链投影”与“不产生持久概念根”的表述（存在根为先天顶层）；
- “概念定义不可原地改义”；
- 将组成角色、关系类型作为定义或共同约束；
- 用名称、相似度、位置或单条组织边直接生成概念；
- 每次实例增加后自动扫描全部概念或穷举组合。

旧路径名“存在根概念元特征”只作迁移定位。
