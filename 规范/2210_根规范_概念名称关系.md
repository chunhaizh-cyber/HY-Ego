# 2210 根规范 概念名称关系

编号：2210

日期：20260815

状态：正式根规范

直接上级规范：0050。

直接依赖规范：2200、2220。

相关边界规范：1100、7140、7200、7210。

## 1. 根定位

概念名称关系是 2220 独立概念身份把词条作为名称成员的权威有向关系事实。它具有关系稳定身份和生命周期，但不建立独立“语素入口”、语素或信息入口类型节点；本关系的权威结构只有词条、独立概念和两者之间的具名名称关系。

```text
词面输入
-> 非权威词索引召回词条
-> 反查当前概念名称关系
-> 得到零个、一个或多个候选概念
-> DATA 之外业务层按上下文裁决
```

## 2. 概念唯一性边界

1. 每个概念具有独立稳定身份；同一本体根、同一签名规则和同一完整抽象签名不得同时存在两个当前概念。
2. 概念唯一性只由 2220 / 7140 的本体根、抽象签名、直接上下位关系和定义约束共同裁决，不由名称、词条、解析标签、索引、显示文本或首次命中裁决。
3. 名称相同不等于概念相同；名称不同也不等于概念不同。
4. 每个概念恰好归入存在、特征、动态或因果链一个本体根；一个概念可以在该根内具有多个直接上位概念。本体根属于概念结构，不是世界树根、场景树根、词条、解析标签或名称。

## 3. 正式结构

概念名称关系从概念指向词条，至少具有：

```text
关系稳定身份
源概念身份
目标词条身份
名称角色：首选名称 / 别名 / 简称
适用语言
创建 / 退出生命周期
来源与发布代次
```

约束如下：

1. 同一概念可以有多个当前名称，同一词条可以命名多个概念，整体是多对多关系。
2. 同一概念、同一语言最多一个当前首选名称；别名和简称允许多个。
3. 同一概念、词条、名称角色和语言的当前关系不得重复；重复同义请求必须幂等读回。
4. 退出名称关系不退出概念或词条；退出概念或词条时必须按引用闭包处理仍有效的名称关系。
5. 名称关系只证明该词条当前可以作为该概念的名称，不证明输入上下文当前采用该概念。

## 4. 一词多义与一义多名

```text
同一词条 -> 多个概念候选        一词多义
同一概念 -> 多个词条名称        一义多名
```

候选数大于一时，数据服务返回确定排序的完整集合，不得猜选首项；候选数为一也只证明名称关系唯一命中，不自动证明语境理解、现实对象识别或业务结论。

名称结构服务始终返回未过滤的完整当前名称候选。`DATA` 外业务必须逐项读回候选概念的本体根和正式强类型材料，再结合本次语言位置、句法关系和上下文缩小或排序；没有类型材料或上下文不足时保持未理解或保留完整候选，不得根据词面、外部词性标签或首项猜选默认根、概念或对象类型。

## 5. 词索引边界

词索引唯一负责从 2200 规范键召回词条身份。概念反向名称索引可以从当前名称关系确定重建，用于从词条召回概念候选；两类索引均不是权威事实。

索引命中后必须在同一读取截止下回读词条、名称关系和概念身份。索引缺失、清空或重建不得改变任何词条、名称关系或概念事实；索引与权威结构矛盾时丢弃索引并回源，不得反写权威事实。

## 6. 写入权和层次

`DATA-L2` 中的词条和名称关系服务只校验稳定身份、关系形状、角色、语言、生命周期、幂等、期望代次和引用完整性。是否接受某个名称、是否属于同一概念、当前语境选择哪个概念，由 `DATA` 之外的语言理解或概念业务服务裁决后形成强类型请求。

概念名称服务不得创建或改义目标概念，不得以名称关系替代概念签名；概念服务也不得把自由文本直接写成概念名称而绕过词条规范化。

## 7. 原语素入口退役

“语素入口节点”“词到语素入口组成关系”“语素对应信息关系”和“语素概念追溯关系”不再取得现行结构授权。当前也不建立新的语素身份、语素 CRUD 或词条—语素组成关系。历史代码、设计、计划和材料中的旧入口名称只证明旧模型曾存在，不得作为新实现依据。

迁移必须重建为：

```text
旧入口的规范化语言材料 -> 当前词条
旧入口所命名的概念      -> 当前概念
二者有效名称语义          -> 当前概念名称关系
```

无法确定目标是概念名称、实例别名、语言候选还是其它对象路由时保持未迁移并形成具名缺口，不得按旧入口形状自动猜测。

## 8. 验证

验证至少覆盖：

- 同一规范词条幂等与异义冲突；
- 同概念多名称、同词条多概念；
- 同语言首选名称唯一；
- 名称同而概念不同、名称异而概念相同；
- 名称关系退出不删除词条或概念；
- 索引清空后可确定重建且回读结果等价；
- 候选多项不猜选；
- 不存在语素、语素入口、持久词性或信息入口类型中间节点，也不存在第二权威索引。

## 8.1 L5 裁决证据与生产绑定边界

名称关系只能由 `DATA` 之外的 `概念名称绑定业务` 在取得具名、可回读的语言候选裁决证据后提交。请求必须同时给出概念、词条、名称角色、适用语言、共同事实截止、绑定幂等身份和裁决证据身份 / 版本；没有裁决证据、证据已过期、候选仍多义、上下文不足、语言或词条未正式读回时，入口拒绝且零结构变化。

绑定业务只调用现有 L2 语言、词条和概念名称结构公开入口：写入后必须在同一后继截止独立按名称关系、按概念和按词条三路正式读回，并逐字段互证。成功只证明一条已裁决名称关系在两端当前结构中闭合，不证明自然语言理解、对象真实性或概念唯一性；概念和词条均不得由名称绑定业务创建。

默认汉语及其它生产语言身份必须由 L2 语言结构服务的正式新增 / 精确重复结果和独立按登记键、按身份读回形成。语言登记键、词面、名称、索引和进程内缓存均不是语言身份权威；旧“语素对应信息”“概念追溯”或通用对应关系不得参与绑定。
