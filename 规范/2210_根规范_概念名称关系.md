# 2210 根规范 概念名称关系

编号：2210

日期：20260815

状态：正式根规范

直接上级规范：0050。

直接依赖规范：2200、2220。

相关边界规范：1100、7140、7200、7210。

## 1. 根定位

概念名称关系是 2220 独立概念身份把词条作为名称成员的权威有向关系事实。它具有关系稳定身份和生命周期，但不建立独立“语素入口”节点；本关系的权威结构只有词条、独立概念和两者之间的具名名称关系。2200 / 4240 的独立语素节点族可以存在并参与构词或表达候选，但不自动成为概念名称关系，也不恢复旧入口中间壳。

```text
词面输入
-> 非权威词索引召回词条
-> 反查当前概念名称关系
-> 得到零个、一个或多个候选概念
-> DATA 之外业务层按上下文裁决
```

## 2. 概念唯一性边界

1. 每个概念具有独立稳定身份；同一本体根、同一签名规则和同一完整抽象签名不得同时存在两个当前概念。
2. 概念唯一性只由 2220 / 7140 的本体根、抽象签名、直接上下位关系和定义约束共同裁决，不由名称、词条、词性、索引、显示文本或首次命中裁决。
3. 名称相同不等于概念相同；名称不同也不等于概念不同。
4. 每个概念恰好归入存在、特征、动态或因果链一个本体根；一个概念可以在该根内具有多个直接上位概念。本体根属于概念结构，不是世界树根、场景树根、语素、词条、词性或名称。

## 3. 正式结构

概念名称关系从概念指向词条，至少具有：

```text
关系稳定身份
源概念身份
目标词条身份
名称角色：首选名称 / 别名 / 简称
适用语言
创建 / 退出生命周期
来源与发布代次
```

约束如下：

1. 同一概念可以有多个当前名称，同一词条可以命名多个概念，整体是多对多关系。
2. 同一概念、同一语言最多一个当前首选名称；别名和简称允许多个。
3. 同一概念、词条、名称角色和语言的当前关系不得重复；重复同义请求必须幂等读回。
4. 退出名称关系不退出概念或词条；退出概念或词条时必须按引用闭包处理仍有效的名称关系。
5. 名称关系只证明该词条当前可以作为该概念的名称，不证明输入上下文当前采用该概念。

## 4. 一词多义与一义多名

```text
同一词条 -> 多个概念候选        一词多义
同一概念 -> 多个词条名称        一义多名
```

候选数大于一时，数据服务返回确定排序的完整集合，不得猜选首项；候选数为一也只证明名称关系唯一命中，不自动证明语境理解、现实对象识别或业务结论。

人类词性只能经 7210 的 `DATA` 外任务局部多对多路由形成零个、一个或多个本体根 / 对象角色候选并缩小名称候选，但不替代名称关系，也不能直接建立根、概念或选择唯一概念。名称结构服务始终返回未过滤的完整当前名称候选；外部分词器标签必须先形成正式词性候选，缺少合法路由结果时保持未理解或使用未过滤名称候选，不得猜选默认根。

## 5. 词索引边界

词索引唯一负责从 2200 规范键召回词条身份。概念反向名称索引可以从当前名称关系确定重建，用于从词条召回概念候选；两类索引均不是权威事实。

索引命中后必须在同一读取截止下回读词条、名称关系和概念身份。索引缺失、清空或重建不得改变任何词条、名称关系或概念事实；索引与权威结构矛盾时丢弃索引并回源，不得反写权威事实。

## 6. 写入权和层次

`DATA-L2` 中的词条和名称关系服务只校验稳定身份、关系形状、角色、语言、生命周期、幂等、期望代次和引用完整性。是否接受某个名称、是否属于同一概念、当前语境选择哪个概念，由 `DATA` 之外的语言理解或概念业务服务裁决后形成强类型请求。

概念名称服务不得创建或改义目标概念，不得以名称关系替代概念签名；概念服务也不得把自由文本直接写成概念名称而绕过词条规范化。

## 7. 原语素入口退役

“语素入口节点”“词到语素入口组成关系”“语素对应信息关系”和“语素概念追溯关系”不再取得现行结构授权。它们是旧的词条—概念通用中间壳，不等于 2200 / 4240 的独立语素身份、语素 CRUD 或词条—语素有序组成关系。历史代码、设计、计划和材料中的旧入口名称只证明旧模型曾存在，不得作为新实现依据。

迁移必须重建为：

```text
旧入口的规范化语言材料 -> 当前词条
旧入口所命名的概念      -> 当前概念
二者有效名称语义          -> 当前概念名称关系
```

无法确定目标是概念名称、实例别名、语言候选还是其它对象路由时保持未迁移并形成具名缺口，不得按旧入口形状自动猜测。

## 8. 验证

验证至少覆盖：

- 同一规范词条幂等与异义冲突；
- 同概念多名称、同词条多概念；
- 同语言首选名称唯一；
- 名称同而概念不同、名称异而概念相同；
- 名称关系退出不删除词条或概念；
- 索引清空后可确定重建且回读结果等价；
- 候选多项不猜选；
- 不存在语素入口中间节点或第二权威索引。
