# 第 45 项：L1 面向领域服务的通用读取边界

状态：已确认机器语义输入；非正式规范。

## 已确认口径

1. 普通 L2—L4 领域服务不得通过读取完整 L1 快照后自行扫描来完成日常业务查询。
2. L1 在现有按稳定编码精确读取之外，提供以下业务中性读取能力：

```text
读取当前事实代次
按稳定编码组批量读取当前节点、关系和值
读取一个节点的全部当前属性槽及其当前值
按端点、方向和关系类型读取完整当前关系组
```

3. 每次读取函数调用只取得一次内部共享读取边界；同一结果中的全部材料必须属于同一个事实代次，并以不可变值式结果返回。
4. 当前关系组按关系稳定编码排序；节点属性组按属性类型节点稳定编码排序。
5. 请求超过冻结容量限制时整体返回具名 `结果超限`，不得截断材料后返回部分成功；当前合同不建立跨事实代次分页游标。
6. L1 查询条件只允许稳定编码、端点、方向、关系类型及可选角色或顺序等业务中性结构条件。L1 不接受需求有效、任务待执行、属于自我等业务谓词。
7. 一个领域投影需要组合多次 L1 调用的，由领域服务执行首末事实代次复核；发生漂移时完整重试一次，仍漂移则返回具名非成功，不返回混代材料。
8. `读取完整快照` 只用于恢复、审计、索引重建和独立验收，不作为普通业务热路径。
9. 索引和缓存保持 L1 内部可重建加速结构，不形成第二套公开事实读取接口或权威。

## 适用边界

本项只冻结 L1 通用读取能力的语义形状，不冻结具体 C++ 类型名、字段布局、容量数值、物理索引结构或实施计划。正式吸收时必须核对 0050、4015、4030、4070、4200 及全部受影响领域读取合同。

本确认不证明当前 L1 已经实现批量读取、属性组读取、关系组读取或轻量事实代次读取，也不证明 L1 已经闭合。
