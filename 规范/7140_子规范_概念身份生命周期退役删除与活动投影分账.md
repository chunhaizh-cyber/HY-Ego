# 7140 子规范 概念身份生命周期退役删除与活动投影分账

编号：7140

日期：20260812

状态：正式子规范

直接上级规范：2220。

直接依赖规范：4010、4020、4030、4040、4050、4060。

相关边界规范：1110、2200、2210、7100、7200、7210。

## 1. 定位

本规范展开独立概念身份、概念维度根、抽象签名、世界事实支持关系、维度内上下位、定义约束、生命周期、退役、不可逆退出、历史审计和可重建投影。概念空间本体和世界树正交关系唯一服从 2220。

## 2. 维度根与普通概念

每个正式登记词性恰好对应一个当前概念维度根。维度根使用独立概念身份和固定系统角色稳定编码共同成立；名称、词性枚举数值、登记数组、索引、活动快照和显示树均不能单独证明根身份。

维度根永久活跃，不允许冷却、退役、不可逆退出或被普通概念替换。新增、合并或拆分词性维度会改变概念身份空间，必须先修订 2220 及对应语言规范，不得由外部分词器标签自动完成。

普通概念使用独立概念身份，不沿用世界存在、特征、状态、动态、关系、因果或语言对象身份。每个普通概念必须通过维度内直接上位关系到达且只到达一个维度根。

## 3. 抽象签名

概念抽象签名至少包括：

```text
所属概念身份
概念维度根身份
签名规则身份与版本
确定排序的值式约束项组
由具名定义关系承载的句柄型约束角色组
来源事实摘要与发布证据
记录格式和生命周期
```

签名值式约束不得复制定义关系目标或关系身份。需要引用世界事实、其它概念或结构对象的约束必须由具名关系承载，并以非零角色与签名约束项互证。

签名发布后不可原地改义。抽象含义实质变化建立新的概念身份；旧概念、签名、关系和支持证据保留历史。维度根的空签名由固定根身份确定重建，不保存第二份空签名事实。

## 4. 四类核心关系

### 4.1 世界事实支持概念

源为一个当前或可审计历史世界事实，目标为当前概念。世界事实可以是存在实例、场景事实、特征 / 属性值事实、状态、动态、关系、因果或语言使用事实。

同一来源事实和目标概念的当前支持关系不得重复。支持关系必须保存来源、建立依据、生命周期和发布证据；它只证明该事实支持该抽象，不证明概念自动适用于其它事实。

支持关系允许多对多和跨维度：同一世界事实可以支持多个概念，同一概念可以由多个事实支持。退出支持关系不删除世界事实或概念。

### 4.2 维度内概念上下位

源为直接上位概念，目标为直接下位概念。两端必须归入同一维度，允许多父，整体必须为无环 DAG。每个非根当前概念必须可到达唯一维度根；自环、跨维度、成环和无法到根在第一笔写入前拒绝。

只保存直接边。传递闭包、树路径、层级、锥面和高度是可重建投影。

### 4.3 概念定义约束

源为概念，目标为结构化定义对象、世界事实或其它概念。关系角色必须与抽象签名已登记的非零角色逐项互证；同一概念同一单值角色至多一个当前目标，多值角色必须具备确定顺序和基数合同。

跨维度概念联系使用本类具名定义或相关关系，不得伪装成上下位关系。

### 4.4 概念生命周期

每个当前普通概念恰有一项当前生命周期事实：活跃、冷却或退役。合法迁移为：

```text
活跃 -> 冷却
冷却 -> 活跃
冷却 -> 退役
退役 -> 活跃
```

迁移形成新生命周期事实并退出旧当前事实，历史连续可查。统计、召回和活动投影只能提出迁移候选，不能替代权威迁移。

## 5. 写入与解释权

L1—L5 概念结构服务只负责独立身份、维度根、签名记录、关系、生命周期的结构 CRUD、幂等、同截止读回、引用保护和中性错误。

L5 之外概念抽象业务负责：

- 选择词性对应的概念维度；
- 从世界事实提取抽象候选；
- 判断签名是否同义、是否足以发布；
- 裁决上位、定义、支持关系和生命周期迁移请求；
- 接受名称并完成语境消歧。

概念业务不得绕过世界对象领域改写世界事实；世界对象领域也不得根据相似度、名称或词性自行创建概念。

## 6. 活动投影与锥体视图

以下材料均为非权威可重建投影：

| 投影 | 唯一来源 |
| --- | --- |
| 概念维度根登记 | 当前维度根身份 |
| 概念树 / 锥体 | 维度内上下位关系与世界事实支持关系 |
| 叶级世界事实 | 支持关系目标反向投影，不复制世界事实 |
| 祖先、后代和根可达摘要 | 当前上下位 DAG |
| 活动概念组 | 当前概念生命周期 |
| 名称候选 | 当前概念名称关系 |
| 用途和支持统计 | 当前 / 历史支持证据的值式统计 |

投影可以清空、失效和确定重建。投影失败不得改变概念或世界事实；投影与权威结构矛盾时丢弃投影并追根因。

## 7. 退役与不可逆退出

退役只改变普通概念的当前生命周期，不删除身份、签名、上下位、定义、名称或支持历史。退役概念退出普通主动召回，但仍可审计并经合法迁移重新活跃。

不可逆退出前必须确认：

```text
目标不是维度根
目标当前生命周期为退役
没有当前世界事实支持关系
没有当前概念名称关系或概念结构外引用
签名、定义、上下位和生命周期同截止完整
退出后同维度图仍无环且全部剩余概念唯一根可达
所需替代直接边已确定形成
技术写入权和事务边界成立
```

退出中间概念时，对每组直接上位与直接下位纯值重算替代直接边；只有在剩余图中不存在绕开目标的其它可达路径时才增加替代边。替代边、目标相关当前边和当前签名 / 生命周期退出必须由合法结构事务闭合，不得只修改投影。

不可逆退出不删除来源世界事实。旧概念身份永久保留审计，不得复用；以后形成等价概念必须取得新身份。

## 8. 持久恢复

长期材料保存独立概念身份、维度根、抽象签名、当前及历史关系、生命周期和退出审计。维度根登记、概念锥体、活动集合、候选组、统计和显示路径不作为恢复权威。

恢复至少验证：

- 每个登记词性恰一当前维度根；
- 每个普通概念独立于世界事实身份且唯一维度根可达；
- 同维度无环，多父关系完整；
- 签名角色与定义关系逐项互证；
- 世界事实支持关系端点、来源和历史完整；
- 每个当前普通概念恰一生命周期；
- 已退出概念无当前关系、签名或索引，历史仍完整。

验证通过后从权威候选重建全部锥体、树形、叶级事实和活动投影；旧四类根或复用世界对象身份的材料不能无歧义转换时必须拒绝，不得半迁移。

## 9. 错误分账

| 分类 | 情况 |
| --- | --- |
| 入口拒绝 | 无效身份、错误维度、维度根退出、世界事实端点错误、跨维度上下位、写入权不符 |
| 逻辑内结果 | 候选不足、同义精确命中、事实代次漂移、引用冲突、退役或退出条件不满足 |
| 内部不一致 | 独立身份复义、同维度签名重复、多根可达、无根可达、成环、签名 / 关系 / 生命周期缺项、叶级引用复制或混代 |

## 10. 验证合同

验证至少覆盖：

1. 多个词性维度根独立、永久活跃且不可退出。
2. 普通概念不复用任何世界事实身份。
3. 同维度签名唯一、跨维度同名和同值签名可并存。
4. 支持关系多对多、跨维度合法且不复制世界事实。
5. 同维度多父 DAG、唯一根可达、跨维度上下位拒绝。
6. 签名值与定义关系角色互证。
7. 生命周期当前唯一、连续历史和合法迁移。
8. 清空全部锥体 / 树形 / 活动投影后权威读回等价。
9. 退出中间概念时替代直接边同事务形成，来源世界事实保持不变。
10. 旧四类根复用身份材料不能证明新概念结构完成。
