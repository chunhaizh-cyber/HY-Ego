## 1. 定位

本规范展开概念独立身份、类别、抽象签名、世界挂接/支持、同类别上下位、定义约束、生命周期、退役、不可逆退出、历史审计和可重建投影。**四本体根布局**（存在／特征／动态／因果链）保持不变；概念根为全局变量，**不为根另建词条**，根不可退役。概念可先于实例成立，真实世界信息经引用/支持关联世界树；因果链是四根中独立的那一根（归类不以之为终点）；功能词不进概念树。

## 2. 类别与普通概念

普通概念具有不可变类别：存在、特征或动态。类别是强类型事实，不是概念节点、根节点、显示目录或永久占位。每个普通概念使用独立概念身份，不沿用世界事实身份。

首次形成必须具有完整、可核验的概念签名及零个或多个显式同类别直接上位。世界树的完整建点材料可以先用于概念定义创建，不能强制对应世界实例已经存在；暂未被世界引用不构成损坏。若声明来源或支持，必须另有真实已发布端点。四本体根本身上位为空且不可退役；存在／特征／动态树下普通概念应可追溯至所属根；非根节点保持同类别无环。

2220的具名通用存在规则同样产生普通概念，不获得永久保留或退出豁免。世界存在对已发布概念的必要使用引用由概念owner保存，独立于形成来源、支持、观察和名称；当前使用以及其它当前定义对概念的引用均阻止将目标退役或不可逆退出。冷却仍可复用；不可逆退出继续要求先退役，不允许因暂时无人使用而从活跃/冷却直接物理退出。定义创建失败后的清理也不得绕过此生命周期。

二次关系概念仍属于特征类别，动态动作仍属于动态类别，不建立阶次根、类型根或动作根。类型完整域等结构锚只能是普通概念。因果链不是第四概念类别或概念总根。

## 3. 抽象签名

概念抽象签名至少包括：

```text
所属概念身份
不可变概念类别
签名规则身份与版本
确定排序的值式约束项组
具名定义关系承载的句柄型约束角色组
来源事实摘要与发布证据
记录格式和生命周期
```

签名发布后不可原地改义。含义变化建立新身份；同类别、同规则和同完整签名只能有一个当前概念。来源和发布证据不参与值域特征概念的同义判定，但必须可回查。

## 4. 核心关系

### 4.1 世界事实支持与位置挂接

源为当前或可审计历史世界事实/世界位置，目标为当前概念。支持和挂接可以多对多，必须保存来源、建立依据、生命周期和发布证据。它只证明该事实支持该抽象，不证明概念自动适用于其它事实。

挂接边不参与世界树单父，不把概念变成场景成员、子存在、子特征或实例组织成员。退出支持/挂接不删除世界事实或概念。首次来源以后退出时保留历史见证；当前世界投影只显示当前有效挂接。

### 4.2 同类别概念上下位

方向固定为“上位概念 -> 下位概念”。两端类别必须相同，允许多父，整体无环。顶层概念可以没有上位；非顶层创建必须显式提交全部直接上位，不能由数据服务猜测。

创建前核验定义、请求已声明端点、生命周期、类别和无环；概念身份、类别、完整签名/定义、生命周期及初始直接上位在概念 owner 内完整发布。世界支持可以在真实实例成立后单独建立，不能因尚无支持拒绝完整定义，也不能把待建实例编码成已发布证据。非法引用、跨类别、成环、漂移和资源失败均不得暴露半概念。只保存直接边，传递闭包和层级是投影。

### 4.3 概念定义约束

源为概念，目标为结构化定义对象、世界事实或其它概念。关系角色必须与签名逐项互证；单值角色至多一个当前目标，多值角色必须有确定顺序和基数。跨类别语义使用定义关系，不伪装为上下位。

### 4.4 概念生命周期

每个当前普通概念恰有一项当前生命周期：活跃、冷却或退役。合法迁移为：

```text
活跃 -> 冷却
冷却 -> 活跃
冷却 -> 退役
退役 -> 活跃
```

迁移形成新事实并退出旧事实。统计、召回和投影只可提出治理请求，不能替代生命周期写入。类别本身没有节点或生命周期。

## 5. 写入与解释权

概念owner唯一保存概念结构，概念树类提供对应增删改查。世界树类通过这些公开函数先取得概念，再通过世界信息L2函数建立节点及引用；不直接写任一owner。纯图投影仍只读。抽象业务负责定义和含义判断，数据层只核验并保存已裁决结构；引用、支持、名称的所属合同不因编排顺序改变。

任何创建、迁移、退役和退出都使用明确G0、幂等身份和非零预算。发布前失败零写；已发布后读回失败返回发布未知并以原请求收敛，不换身份重造。

## 6. 活动投影

以下均是非权威可重建投影：

| 投影 | 唯一来源 |
| --- | --- |
| 世界位置下概念图 | 当前世界挂接、概念类别和同类别直接边 |
| 顶层概念组 | 当前挂接且没有当前上位的普通概念 |
| 祖先、后代和可达摘要 | 当前同类别上下位图 |
| 活动概念组 | 当前生命周期 |
| 名称候选 | 当前名称关系 |
| 支持/用途统计 | 正式支持、命中和采用记录 |

投影可以清空和重建。一个概念在多个世界位置出现不复制身份或增加世界结构父。投影矛盾时丢弃并返回结构化错误。

## 7. 退役与不可逆退出

退役只改变生命周期，不删除身份、签名、上下位、定义、名称或支持历史。不可逆退出前必须确认：

```text
目标当前为退役
没有当前世界挂接/支持、名称或外部引用
签名、定义、上下位和生命周期同截止完整
退出后同类别图仍无环
下位概念仍有完整合法定义及同类别无环的直接上位结构；允许零上位且暂未被世界引用
所需替代直接边已经确定
```

退出中间概念时，下位改接到其上一级；若没有上一级，则改接到所属类别根（存在／特征／动态）。替代边和目标当前结构退出在一个合法事务闭合。**根不可退役**。每个保留下位仍必须满足定义引用闭包及同类别无环，不能因暂未被世界引用误判为半概念。

旧概念编码永久不复用；不可逆退出不删除世界事实。

## 8. 恢复与迁移

恢复只从L1权威事实重建概念、类别、签名、直接边、挂接和生命周期，不从缓存或显示树补造。四本体根由全局变量持有正式引用；初始化幂等并以正式根组读回为权威。四根生产初始化、公开接口与根视图保留，不做迁移删除。

四本体根布局不做迁移；根组读回成功是根已形成的权威证明。规范发布不宣称代码装配已经实现。

## 9. 错误分账

入口字段无效返回入口拒绝；目标缺失/退出、类别冲突、成环、引用冲突、事实代次漂移、历史材料不可用、预算不足、资源失败和内部不一致分别返回稳定状态。合法空投影不等于目标缺失，发布未知不等于回滚。

## 10. 最低验证

- 四本体根（存在／特征／动态／因果链）各恰一，为全局变量；不为根建词条；根不可退役；不得另造第五根或隐藏总根；功能词不进概念树；
- 完整定义可先于对应实例发布；普通概念可追溯至所属存在／特征／动态根；声明的支持必须有真实端点；
- 世界挂接不改变场景/存在/特征结构父；
- 生命周期迁移不改签名或世界事实；
- 中间退出时下位改接上一级，无上一级则改接所属根；保留下位仍有完整定义及合法概念图；
- 四根初始化／接口／视图保留且不做迁移；根组读回为权威；
- 因果链独立且不进入普通概念生命周期。
