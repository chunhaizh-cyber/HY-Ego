直接依赖规范：4010、4020、4030、4040、4050、4060。

## 1. 定位

本规范展开独立概念身份、存在 / 特征 / 动态 / 因果链四个本体根、抽象签名、世界事实支持关系、根内上下位、定义约束、生命周期、退役、不可逆退出、历史审计和可重建投影。概念空间本体和世界树正交关系唯一服从 2220。

## 2. 本体根与普通概念

存在、特征、动态和因果链恰各有一个当前本体根。每个根使用独立概念身份和固定系统角色稳定编码共同成立；名称、词性枚举数值、登记数组、索引、活动快照和显示树均不能单独证明根身份。

四个本体根永久活跃，不允许冷却、退役、不可逆退出或被普通概念替换。新增、合并或拆分本体根会改变概念身份空间，必须先修订 2220、4240、本规范和阶段 18 合同；不得由语言、词性、外部分词器标签、显示分类或运行期样本自动完成。

普通概念使用独立概念身份，不沿用世界存在、特征、状态、动态、关系、因果或语言对象身份。每个普通概念必须通过根内直接上位关系到达且只到达一个本体根。

二次特征概念必须归入特征根，并以定义约束保存真实阶次、直接前驱、派生规则和适用范围。实际二次至 n 次统一称为二次特征；同一概念作为存在、动态或其它宿主特征使用不改变概念身份、所属根或真实阶次。

因果链概念必须归入因果链根，并以定义 / 支持关系引用一个或多个已发布直接因果事实。一个直接因果可以构成最小链，多个直接因果必须形成方向一致、连通、无环且允许共同原因、替代原因和共享分支的直接拓扑；不得复制原因果条件、动作、结果、证据或版本。固定层号、间接因果边和展开路径不属于概念身份或持久关系，应用只能按目标、范围、版本和展开截止形成调用方拥有的值式投影。

## 3. 抽象签名

概念抽象签名至少包括：

```text
所属概念身份
本体根概念身份
签名规则身份与版本
确定排序的值式约束项组
由具名定义关系承载的句柄型约束角色组
来源事实摘要与发布证据
记录格式和生命周期
```

签名值式约束不得复制定义关系目标或关系身份。需要引用世界事实、其它概念或结构对象的约束必须由具名关系承载，并以非零角色与签名约束项互证。

签名发布后不可原地改义。抽象含义实质变化建立新的概念身份；旧概念、签名、关系和支持证据保留历史。本体根的空签名由固定根身份确定重建，不保存第二份空签名事实。

## 4. 四类核心关系

### 4.1 世界事实支持概念

源为一个当前或可审计历史世界事实，目标为当前概念。世界事实可以是存在实例、场景事实、特征 / 属性值事实、状态、动态、关系、因果或语言使用事实。

同一来源事实和目标概念的当前支持关系不得重复。支持关系必须保存来源、建立依据、生命周期和发布证据；它只证明该事实支持该抽象，不证明概念自动适用于其它事实。

支持关系允许多对多和跨根：同一世界事实可以支持多个概念，同一概念可以由多个事实支持。退出支持关系不删除世界事实或概念。

### 4.2 本体根内概念上下位

源为直接上位概念，目标为直接下位概念。两端必须归入同一本体根，允许多父，整体必须为无环 DAG。每个非根当前概念必须可到达唯一根；自环、跨根、成环和无法到根在第一笔写入前拒绝。

只保存直接边。传递闭包、树路径、层级、锥面和高度是可重建投影。

### 4.3 概念定义约束

源为概念，目标为结构化定义对象、世界事实或其它概念。关系角色必须与抽象签名已登记的非零角色逐项互证；同一概念同一单值角色至多一个当前目标，多值角色必须具备确定顺序和基数合同。

跨根概念联系使用本类具名定义或相关关系，不得伪装成上下位关系。

### 4.4 概念生命周期

每个当前普通概念恰有一项当前生命周期事实：活跃、冷却或退役。合法迁移为：

```text
活跃 -> 冷却
冷却 -> 活跃
冷却 -> 退役
退役 -> 活跃
```

迁移形成新生命周期事实并退出旧当前事实，历史连续可查。统计、召回和活动投影只能提出迁移候选，不能替代权威迁移。

用途少、长期未使用或存在更简结构只能提出冷却 / 退役候选，不自动删除或改义正式概念。任务局部二次特征候选尚未成为正式概念时不进入本生命周期；晋升后才按本节治理。

### 4.5 成熟度与实例名称字段节点

普通特征概念的成熟度与治理生命周期正交。尚未成熟的概念可以活跃并被实例复用；活跃不证明成熟，冷却或退役也不删除其成熟证据。成熟记录至少引用概念身份、具名规则及版本、所采用观测证据和评估截止；业务依据长时间内独立观测的重复出现裁决，数据层只机械保存结构，不根据计数自动升格。

观测证据必须绑定同一存在、同一特征类型、已发布特征和值事实、观测身份及时间，同时保存观测采用的事实截止和当时宿主成员关系的可回查见证。后续按该截止读取原实例、原值和归属，不要求历史实例仍为当前，也不能把后来新增的成员关系当作原观测的归属。相同观测身份同义重放不得重复计数，异义必须冲突。观察窗口、候选计数及匹配列表可以重建，不得成为第二概念仓或覆盖原始事实。证据不足、规则失效、范围不符与读取失败必须分开，不能把读取失败解释为概念不成熟。

实例的名称字段节点引用由概念 owner 保存，方向为特征实例到概念，当前至多一项，且不依赖自然语言词条存在。建立、替换和退出均保持历史；任何当前名称字段节点引用都阻止概念不可逆退出。该引用退出不删除实例、概念、观测或词条，实例退出也不得自动删除概念。实例退出前应解除当前引用；清理入口仍须允许根据关系建立时的历史端点见证解除当前引用，不得因实例已退出而永久锁死概念退役后的清理。成熟记录换代不得修改概念签名；调整值域或含义时按第 3 节创建新概念。

## 5. 写入与解释权

L1—L5 概念结构服务只负责独立身份、本体根、签名记录、关系、生命周期的结构 CRUD、幂等、同截止读回、引用保护和中性错误。

L5 之外概念抽象业务负责：

- 按抽象结果选择存在、特征、动态或因果链本体根；
- 从世界事实提取抽象候选；
- 判断签名是否同义、是否足以发布；
- 裁决上位、定义、支持关系和生命周期迁移请求；
- 接受名称并完成语境消歧。

概念业务不得绕过世界对象领域改写世界事实；世界对象领域也不得根据相似度、名称或词性自行创建概念。

## 6. 活动投影与锥体视图

以下材料均为非权威可重建投影：

| 投影 | 唯一来源 |
| --- | --- |
| 本体根登记 | 当前四个本体根身份 |
| 概念树 / 锥体 | 根内上下位关系与世界事实支持关系 |
| 叶级世界事实 | 支持关系目标反向投影，不复制世界事实 |
| 祖先、后代和根可达摘要 | 当前上下位 DAG |
| 活动概念组 | 当前概念生命周期 |
| 名称候选 | 当前概念名称关系 |
| 用途和支持统计 | 当前 / 历史支持证据的值式统计 |

投影可以清空、失效和确定重建。投影失败不得改变概念或世界事实；投影与权威结构矛盾时丢弃投影并追根因。

## 7. 退役与不可逆退出

退役只改变普通概念的当前生命周期，不删除身份、签名、上下位、定义、名称或支持历史。退役概念退出普通主动召回，但仍可审计并经合法迁移重新活跃。

不可逆退出前必须确认：

```text
目标不是本体根
目标当前生命周期为退役
没有当前世界事实支持关系
没有当前概念名称关系、实例名称字段节点引用或概念结构外引用
签名、定义、上下位和生命周期同截止完整
退出后同一本体根内的图仍无环且全部剩余概念唯一根可达
所需替代直接边已确定形成
技术写入权和事务边界成立
```

退出中间概念时，对每组直接上位与直接下位纯值重算替代直接边；只有在剩余图中不存在绕开目标的其它可达路径时才增加替代边。替代边、目标相关当前边和当前签名 / 生命周期退出必须由合法结构事务闭合，不得只修改投影。

不可逆退出不删除来源世界事实。旧概念身份永久保留审计，不得复用；以后形成等价概念必须取得新身份。

## 8. 持久恢复

长期材料保存独立概念身份、本体根、抽象签名、当前及历史关系、生命周期和退出审计。本体根登记、概念锥体、活动集合、候选组、统计和显示路径不作为恢复权威。

恢复至少验证：

- 存在、特征、动态、因果链恰各一当前本体根，且没有词性或场景额外根；
- 每个普通概念独立于世界事实身份且唯一根可达；
- 同根无环，多父关系完整；
- 签名角色与定义关系逐项互证；
- 世界事实支持关系端点、来源和历史完整；
- 每个当前普通概念恰一生命周期；
- 已退出概念无当前关系、签名或索引，历史仍完整。

验证通过后从权威候选重建全部锥体、树形、叶级事实和活动投影；历史复用世界对象身份的旧场景 / 存在 / 特征 / 动态四类根、每词性一根材料或场景概念根材料不能无歧义转换时必须拒绝，不得半迁移。

## 9. 错误分账

| 分类 | 情况 |
| --- | --- |
| 入口拒绝 | 无效身份、错误本体根、根退出、世界事实端点错误、跨根上下位、写入权不符 |
| 逻辑内结果 | 候选不足、同义精确命中、事实代次漂移、引用冲突、退役或退出条件不满足 |
| 内部不一致 | 独立身份复义、同根签名重复、多根可达、无根可达、成环、签名 / 关系 / 生命周期缺项、叶级引用复制或混代 |

## 10. 验证合同

验证至少覆盖：

1. 存在、特征、动态、因果链四个本体根独立、永久活跃且不可退出，词性和场景不建立额外根。
2. 普通概念不复用任何世界事实身份。
3. 同根签名唯一、跨根同名和同值签名可并存。
4. 支持关系多对多、跨根合法且不复制世界事实。
5. 同根多父 DAG、唯一根可达、跨根上下位拒绝。
6. 签名值与定义关系角色互证。
7. 生命周期当前唯一、连续历史和合法迁移。
8. 清空全部锥体 / 树形 / 活动投影后权威读回等价。
9. 退出中间概念时替代直接边同事务形成，来源世界事实保持不变。
10. 历史旧场景 / 存在 / 特征 / 动态四类根、每词性一根或场景概念根材料不能证明新概念结构完成。
11. 二次特征概念位于特征根，真实阶次和前驱可回查，同一概念跨宿主使用不复制身份。
12. 因果链概念位于因果链根，只引用已发布直接因果事实；共同原因、替代原因和共享分支可回查，固定层号、间接因果边和展开路径零持久化。
