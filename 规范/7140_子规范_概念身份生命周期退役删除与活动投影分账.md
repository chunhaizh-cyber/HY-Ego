## 1. 定位

本规范展开概念独立身份、类别、抽象签名、世界挂接/支持、同类别上下位、定义约束、生命周期、退役、不可逆退出、历史审计和可重建投影。存在、特征、动态概念依附唯一世界树，不建立独立本体总根；因果链按1190/2220独立。

## 2. 类别与普通概念

普通概念具有不可变类别：存在、特征或动态。类别是强类型事实，不是概念节点、根节点、显示目录或永久占位。每个普通概念使用独立概念身份，不沿用世界事实身份。

首次形成必须同时具有完整签名、至少一个已发布世界来源或世界位置挂接，以及零个或多个同类别直接上位。顶层概念允许无上位，但不能无挂接；非顶层概念必须经直接上位图保持同类别无环。旧“零约束复用存在根”与“普通概念必须到达本体根”规则退出。

二次关系概念仍属于特征类别，动态动作仍属于动态类别，不建立阶次根、类型根或动作根。类型完整域等结构锚只能是普通概念。因果链不是第四概念类别或概念总根。

## 3. 抽象签名

概念抽象签名至少包括：

```text
所属概念身份
不可变概念类别
签名规则身份与版本
确定排序的值式约束项组
具名定义关系承载的句柄型约束角色组
来源事实摘要与发布证据
记录格式和生命周期
```

签名发布后不可原地改义。含义变化建立新身份；同类别、同规则和同完整签名只能有一个当前概念。来源和发布证据不参与值域特征概念的同义判定，但必须可回查。

## 4. 核心关系

### 4.1 世界事实支持与位置挂接

源为当前或可审计历史世界事实/世界位置，目标为当前概念。支持和挂接可以多对多，必须保存来源、建立依据、生命周期和发布证据。它只证明该事实支持该抽象，不证明概念自动适用于其它事实。

挂接边不参与世界树单父，不把概念变成场景成员、子存在、子特征或实例组织成员。退出支持/挂接不删除世界事实或概念。首次来源以后退出时保留历史见证；当前世界投影只显示当前有效挂接。

### 4.2 同类别概念上下位

方向固定为“上位概念 -> 下位概念”。两端类别必须相同，允许多父，整体无环。顶层概念可以没有上位；非顶层创建必须显式提交全部直接上位，不能由数据服务猜测。

创建前核验端点、生命周期、类别和无环；概念身份、类别、签名/定义、首次来源/挂接和初始直接上位同次原子发布。缺首次挂接、跨类别、端点无效、成环、漂移、资源失败或内部不一致保持零半事实。只保存直接边，传递闭包和层级是投影。

### 4.3 概念定义约束

源为概念，目标为结构化定义对象、世界事实或其它概念。关系角色必须与签名逐项互证；单值角色至多一个当前目标，多值角色必须有确定顺序和基数。跨类别语义使用定义关系，不伪装为上下位。

### 4.4 概念生命周期

每个当前普通概念恰有一项当前生命周期：活跃、冷却或退役。合法迁移为：

```text
活跃 -> 冷却
冷却 -> 活跃
冷却 -> 退役
退役 -> 活跃
```

迁移形成新事实并退出旧事实。统计、召回和投影只可提出治理请求，不能替代生命周期写入。类别本身没有节点或生命周期。

## 5. 写入与解释权

概念owner唯一保存概念结构。世界服务只提供来源和位置的公开读回，不写概念；DATA-L3只聚合投影，不写任何一侧。抽象业务负责候选、签名、类别、挂接选择和含义判断，数据层只核验并保存已裁决结构。

任何创建、迁移、退役和退出都使用明确G0、幂等身份和非零预算。发布前失败零写；已发布后读回失败返回发布未知并以原请求收敛，不换身份重造。

## 6. 活动投影

以下均是非权威可重建投影：

| 投影 | 唯一来源 |
| --- | --- |
| 世界位置下概念图 | 当前世界挂接、概念类别和同类别直接边 |
| 顶层概念组 | 当前挂接且没有当前上位的普通概念 |
| 祖先、后代和可达摘要 | 当前同类别上下位图 |
| 活动概念组 | 当前生命周期 |
| 名称候选 | 当前名称关系 |
| 支持/用途统计 | 正式支持、命中和采用记录 |

投影可以清空和重建。一个概念在多个世界位置出现不复制身份或增加世界结构父。投影矛盾时丢弃并返回结构化错误。

## 7. 退役与不可逆退出

退役只改变生命周期，不删除身份、签名、上下位、定义、名称或支持历史。不可逆退出前必须确认：

```text
目标当前为退役
没有当前世界挂接/支持、名称或外部引用
签名、定义、上下位和生命周期同截止完整
退出后同类别图仍无环
下位概念仍有至少一项合法世界挂接或合法直接上位
所需替代直接边已经确定
```

退出中间概念时，对直接上位和下位计算必要替代边；只有不存在其它路径时才新增。替代边和目标当前结构退出在一个合法事务闭合。顶层概念退出不需要“改接总根”，但每个保留下位仍必须满足挂接/上位闭包。

旧概念编码永久不复用；不可逆退出不删除世界事实。

## 8. 恢复与迁移

恢复只从L1权威事实重建概念、类别、签名、直接边、挂接和生命周期，不从缓存、显示树或旧全局根变量补造。旧四根、根归属和应用静态根引用只可用于具名存量迁移读取；新生产入口不得创建或依赖它们。

物理迁移必须原子或分阶段可证明：新类别和挂接完整、全部消费者切换、旧根写入口零可达、独立读回成功后，才能退出旧根关系。规范发布不宣称迁移已经实现。

## 9. 错误分账

入口字段无效返回入口拒绝；目标缺失/退出、类别冲突、成环、引用冲突、事实代次漂移、历史材料不可用、预算不足、资源失败和内部不一致分别返回稳定状态。合法空投影不等于目标缺失，发布未知不等于回滚。

## 10. 最低验证

- 三类概念没有独立总根或永久根生命周期；
- 顶层概念有世界挂接，非顶层保持同类别多父无环；
- 世界挂接不改变场景/存在/特征结构父；
- 生命周期迁移不改签名或世界事实；
- 中间退出形成必要替代边，下位仍有挂接或上位；
- 旧根只读迁移边界和新生产写入严格隔离；
- 因果链独立且不进入普通概念生命周期。
