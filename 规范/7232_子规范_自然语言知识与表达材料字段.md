# 7232 子规范 自然语言知识与表达材料字段

编号：7232
日期：20261105
版本：v1.0
状态：正式子规范

直接上级规范：2340。

直接依赖规范：2200、2210、4120、7230、7231。

相关边界规范：1150、2220、7165、7240、7250、7270。

## 1. 结构约定

本规范按2340分解语言知识的核心、目标、角色与描述结构，当次表达与解析对齐，复合特征条件主张，无上下文基础句型转换材料，以及学习与使用关联。结构约定沿7230第1节。

## 2. 核心、目标与角色

```text
语言知识 { 节点身份, 目标描述引用, 描述结构引用 }

目标描述
  目标定义身份
  表达目的              // 陈述、提问、提出需求；子片段可继承
  角色定义组
  含义结构
  适用条件组

角色定义
  局部角色编号
  角色种类
  数量约束              // 单项、可选单项、有界集合
  必要约束组
```

角色种类闭合为概念引用、领域对象引用、特征类型引用、准确值、时间、语言材料引用、含义子项；领域对象再显式区分存在/场景视角、特征、状态、动态、关系、因果、需求、任务、方法。引用不能在这些类别之间靠数值强转。必要约束只使用7240的有限操作。

构式示例可将同一角色的多个允许领域对象类别简写为 `R1:{E,F}`：`R1` 是该规则内一个角色，`{E,F}` 是允许绑定类别的集合，不是新信息节点类型、集合对象或话语含义中的析取。正式知识仍用一个“领域对象引用”角色和必要约束中的有限类别条件表达；不得把不同角色种类（如概念引用与领域对象引用）强并为一个角色，跨种类用独立规则或已有子规则映射。若组合是否合法依赖多个角色，应在同一规则的适用条件中列出完整的合取分支，再以条件 OR 连接；例如“`R1` 属普通存在且 `C1` 为存在概念，或 `R1` 属实例特征且 `C1` 为特征概念”。仅写 `R1:{E,F}` 不保证 `C1` 与实际绑定类别相配。分支改变含义操作或作用域时必须拆成不同知识规则，不以条件分支掩盖不同含义。

含义结构由7240规定的类型化项、角色引用和作用域构成。未绑定变量、明确未知值、查询变量和已经绑定的对象不同；未知不填0、不等于否定。某角色是概念不表示另建一种概念本体，D/T/M使用对应对象引用或提议结构。

## 3. 描述结构

```text
描述结构
  结构定义身份
  结构类别              // 基础表达、内容组织
  语言约束              // 指定正式语言；组织层可随子规则
  结构项有序组

基础结构项 = 固定词项 | 角色表达项 | 子规则项
固定词项   { 局部项编号, 词条引用或固定标点值 }
角色表达项 { 局部项编号, 角色编号, 表达方式 }
子规则项   { 局部项编号, 子知识定义引用, 角色映射 }

内容组织项
  局部项编号
  子表达目标
  取材规则
  子规则固定引用或按子目标选择
  角色映射
  展开方式              // 单项、逐项、分组
  选用条件
  缺材处理              // 必需不足、可选略去、明确表达未知
  衔接关系              // 无、并列、时间先后、转折、条件、因果、回应
```

结构项顺序为规则内顺序，不使用可变容器地址。角色表达方式允许名称表达、明确对象描述、已消解指代、作用域明确的变量指代表达、类型化字面值和子含义表达；变量表达必须保留其类型、绑定域、量化/查询用途和共享角色，不能用“谁/什么”掩盖原本要求唯一对象而尚未消歧的缺口。没有名称不能泄露句柄冒充自然语言名称。规则自身的标题或注释不参与执行。

“明确表达未知”必须是目标允许报告缺失，不能凭字段未查询就说“不知道”。因果/转折/条件衔接必须有对应含义输入，不能因结构项相邻就补写“因此”。用于省略的角色必须由唯一上下文或子映射可恢复；否则该结构不支持当前双向使用。

内容组织规则之间允许共享无环定义引用；按子目标选择形成的运行期递归遵守7240的完整范围和严格进展规则。不得把引用环称作语言递归并无限展开。

## 4. 当次表达与解析对齐

```text
本次表达项
  局部出现编号
  所用知识定义引用
  本次角色绑定组
  本次选取的信息引用组
  子表达项有序组
  输出材料范围?          // 仅生成后有

含义对齐项
  来源材料范围
  含义项局部编号
  所用规则及角色映射
```

本次表达树、候选含义组和分数默认调用期保存，可随请求结束释放；需要留存的原文、已采用解析和学习样本由语言owner保存。对齐只能指向实际存在的材料与规则；不为证明正确性复制世界状态、二次特征结果或治理事实。

## 5. 已采用复合特征条件主张

按请求保存“`A 有事`”等集合条件陈述时，语言owner保存一项有来源的已采用主张，而不是把条件直接写成现实存在的实例特征。项目不设独立的集合条件概念：这类条件由多个不同特征类型构成的复合特征表达，复合特征只在特征类实现（4120、7165），主张引用该复合特征类型及其值域：

```text
复合特征条件主张
  主张身份
  所属交互语言场景引用
  来源语言材料与文本范围
  已采用解析及含义对齐项引用
  主体的强类型存在引用
  复合特征类型引用及值域条件
  表达者引用或明确来源未明
  陈述作用域引用              // 普通陈述或具名引述范围
  时间参照                    // 来源表达时间引用、具名参照或明确未定
  本次主体绑定依据引用
```

主张只在主体已唯一绑定、复合特征类型及值域的完整定义已读回、来源范围、含义对齐项和作用域一致时采用；含义对齐项以解析材料、含义项局部编号及规则/角色映射区分同一句内重复构式。缺少具体集合成员、表达者身份或绝对时间，或未进行现实求值，均不妨碍保存有来源主张；时间参照未定时不得把“当前”用于现实求值。主体未决、复合特征类型未形成或来源不可读时保留解析候选及缺口，不以空引用伪造一条已采用主张。重复陈述保留各自来源出现；后续纠正以完整当前解释整体发布；原主张仍被正式事实引用时按引用计数保留，不另设历史版本。主张身份与特征类型身份、主体身份、任务身份分开；主张的存在不构成世界事实支持边，也不使主体正式拥有任务。

**当前场景与其它场景**：对话提到的对象若属**当前场景**，须先取得其它证据并绑定现实存在后，才允许写入内部世界权威材料；若属**其它场景**，允许先保存为有来源主张，待后续绑定。自然语言世界树匿名出现不因此取得现实树身份。

## 6. 无上下文基础句型的转换材料

本节是单个短语/短句在空白自然语言场景中转换所需的逻辑材料，不新增节点族、持久知识核心字段或一套概念名称关系。物理合同可以沿用已有类型化候选和含义载荷，但必须能够分别表达：

```text
基础句型转换材料
  语言与固定原文
  语境依据 = 明确无交互上下文依赖
  所用知识引用及构式种类
  命名出现组
    局部出现编号、角色、原文范围
    词条引用、名称关系引用、来源概念引用
  固定词出现组
    结构项位置、原文范围、词条引用
  整数出现组（构式需要时）
    局部出现编号、原文范围、原始数字词面、规范十进制字符串
  类型化主张或被询含义
  场景及对象绑定组（构式需要且已取得时）
    自然语言场景引用
    局部对象出现编号、临时存在引用、来源概念引用
  候选组或唯一采用含义、实际完成阶段与未完成项
```

命名出现的概念引用与对象角色的存在引用不是同一个身份。普通类名先召回概念；S01、S03和S05需要的存在由7240第4.3节在候选唯一后建立，不要求调用方先给现实E或场景专名。S05的部分和整体按两个独立出现分别绑定，即使来源概念相同也保留两个存在身份；同一角色的显式映射仍须保持一致。这里的匿名存在不是7233第4节的指代实例，不需要代词概念或指向才能成立。S02及以它为子含义的S09只保留概念、知识和来源对齐，不要求空壳场景或对象绑定。

整数出现保存原词面和规范十进制字符串，具体词法按7240第4.3节；它是已识别整数含义的精确文本表示，不是未知值占位符。语言转换不得以`int64`承载范围裁剪整数，也不据此发布真实实例特征值。FT的正式类型约束、语言数字表示、领域准确值构造分别核验，不把三者混为一次赋值。

多候选阶段保存出现与候选解释，不为每个候选预建场景或存在。唯一采用后，场景结构和对象身份由所属世界树/存在公开入口取得；主张、对齐和采用解释可仅为调用期材料。返回场景及E不等于已持久保存完整主张、特征或组成关系；需要保存解析或主张时另按本规范第8节及7231第3节办理。技术失败后的实际已取得身份与可交付完整含义分别返回，不用旧候选伪装成功，也不谎称已经发生的写入为零。

## 7. 学习与使用关联

```text
语言学习关联
  关联身份
  样本材料及固定范围
  语境依据              // 明确无依赖，或当时固定语境材料引用
  含义依据引用组
  学习目标               // 名称、含义对齐、基础结构、组织结构
  知识定义引用或结构候选材料引用
  样本与规则角色对应
  反馈/纠正材料引用组

知识采用关系
  关系身份
  知识定义引用
  采用范围与使用方向
  使用方式               // 限定试用、正常使用、停止新用
  依据学习关联组
```

采用范围/使用方式是语言业务结论，结构服务只保存；不新增通用“成熟度分数”字段。样本、反馈、采用和索引分账，命中次数可由实际关联统计重建，不按重复转写或自我生成循环虚增独立样本。自动淘汰须按7250，结构/名称学习不替代概念的7140治理。

## 8. 写入和引用闭包

语言知识、知识内目标/结构、已采用复合特征条件主张以及学习/采用关系均静态路由既有语言owner；概念、特征类型和名称仍归各自owner。同一知识及初始目标/结构/全部组成在语言owner内完整发布。只停止知识采用不等于删除知识定义。知识定义可原地修订（0050 §1.5），已形成的本次表达树只记录所用定义身份，不冻结定义内容；物理删除及引用完整性遵守0050，不建立历史版本服务。

## 9. 最低验证

应覆盖：两次规则复用不合并表达项；知识/学习跨owner部分失败与原请求读回；复合特征条件主张的主体、来源、作用域与时间参照。

无上下文基础句型另须覆盖：概念引用与临时存在引用分离；同概念双出现的两个E；整数原词面与规范值对齐；纯概念分支无场景；候选唯一前零场景写入；写入中断保留实际身份而不交付假完整含义。验证实施与是否运行测试按AGENTS第7.1节，不因列有用例就推定已执行。
