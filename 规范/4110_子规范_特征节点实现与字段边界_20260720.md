# 4110 子规范 特征节点实现与字段边界

编号：4110
日期：20260907
版本：v0.13
状态：正式子规范

## 1. 定位

本规范展开 1130 特征信息的封闭字段、关系、数据操作及输入处理。特征定义规定类型含义，特征信息节点保存该类型下的具体信息；两者按正式身份和结构角色区分，不以是否绑定宿主区分。

### 1.1 权威模型

特征信息由正式节点、类型关系、类型化字段材料及其它已声明关系共同承载，索引和读回对象只是投影。特征节点可以独立存在；已挂接宿主只引用节点，不取得内部字段的第二写入入口。旧宿主实例槽模型及其生产合同退出，不对新信息保留双轨写入。

底层复用 4010—4040 的节点、关系、值、通用属性槽和可靠读写能力；技术分区和发布记录不进入 1130 的五字段。2100 值身份不是节点身份；内联 I64 不伪造独立值身份。

直接上级规范：1120、1130、2100。

直接依赖规范：4010、4020、4160。

相关边界规范：4120、4140、4170、4180。

### 1.2 新特征信息字段与关系展开

#### 1.2.1 特征值承载

1130 第 1.1 节的准确当前观察值、历史具体值项及每个域的代表值，统一采用以下互斥的有标签联合：

| 承载分支 | 内容与校验 |
| --- | --- |
| 内联 I64 | 一个完整有符号 64 位整数；没有独立 2100 值身份，不分配伪值节点。 |
| 2100 值身份引用 | 一个可经特征值服务可靠读回的强类型值身份；实际值表示和完整内容以 2100 读回为准，不以编码非零或任意节点存在替代。 |

承载分支必须显式可读；可以由强类型联合的活动分支表达，不另存可漂移的重复枚举。禁止凭正负、大小、数值区间或地址猜测“整数还是引用”。同一正式类型允许的原始表示仍唯一：I64 类型可内联整数或引用 I64 值，引用向量不使该类型自动改为向量；其它表示按类型合同使用值引用。承载方式不是轮廓、坐标、颜色等业务类型。

准确当前观察值是本节点最近一次成功接收的完整实际值，与每个域的固定代表分开；即使命中原域或与历史项相同，也必须按本次输入确认当前值，不能以代表值或域引用替换。父节点可以维护多个形态范围，不能随最新观察覆盖一个全局代表而改变所有范围含义。共享同一特征信息的各宿主当前采用须由各自关联表达，不能把本节点最后接收值同时宣称为所有宿主的当前观察。

同一正式类型内的准确值去重，以原始表示及完整内容的精确相等为准；内联 I64 与引用相同 I64 内容可以归为同一个具体值项。值身份、材料引用身份或摘要相同与否都不能单独替代内容校验；材料须经正式接口完整读回。相似或差异处于允许范围不等于精确相等，不能借去重丢掉尚未被稳定域概括的不同值。若准确材料需复用，使用已有值引用，不复制独立权威载荷；被其它事实依赖的内容仍须可回查。

#### 1.2.1.1 历史值集合与简化

历史值集合用于后续识别，成员为互斥的两类：具体值项采用第 1.2.1 节的值承载；值域引用项使用本节点第 1.2.2 节的稳定值域项标识，正式读回该域，不复制域定义、不指向容器下标或其它节点的同号域。最新准确输入也按此规则纳入历史，不要求先退出当前；本节点的准确当前值始终单独保留。

合法输入未被可用于简化的域覆盖时，按精确相等去重后保存具体值项；被覆盖时可不再增加具体项。可用于简化的域必须在本节点累计命中至少 3 次，复用分裂的固定门槛，不增加其它稳定阈值。首次达到门槛时，历史集合加入该域引用，并移除其中已被该域覆盖的具体项；普通候选域在同次处理建立子节点，继承域的建子例外按第 1.2.3 节执行。域引用不重复，同一具体项被多个稳定域覆盖时只移除一次，各域本身仍分别保留。

例如历史 `{V1,V2,V3,V4}` 中前三项被稳定域 D1 覆盖，可简化为 `{D1,V4}`。这是观察形成的识别范围概括，不是无损压缩：不保证还原全部原始值，也不表示 D1 内每个值均被实际观察过；按单一域代表匹配不保证等价于遍历全部历史样本。仍要求逐次准确观察证据的用途，应读取各自正式观察记录，不能从本集合反推。

简化只改变本集合成员，不删除父域，不自动物理删除 L1 值事实或独立材料；当前值、域代表及其它事实的准确引用继续受保护。历史识别范围既不是技术恢复历史，也不自动成为状态 / 动态记录。

#### 1.2.2 值域集合与值域项

值域集合保存范围及按 1130 三次命中判据必需的积累数据；各项都解释为同一特征类型下的允许集合。每项使用稳定的父内标识，不以容器下标、显示顺序或可变边界作身份。域之间可以重叠；必须保留各自含义，不能仅因相交、同中心或命中同一样本就合并为同一节点。

值域项字段清单封闭如下；不额外设置“稳定”“已分裂”或观察生命周期字段：

| 字段 | 固定含义 |
| --- | --- |
| 值域项标识 | 父特征信息内唯一、稳定、非零且不复用的局部键；以父身份与该键共同定位域项，不是新增全局节点族或结构 owner。 |
| 代表值 | 该域固定采用的准确代表材料，使用内联 I64 / 2100 值身份引用；新域按合法输入形成时保留该输入代表，不从区间中点伪造样本。 |
| 值域表示 | 区分 I64 区间与结构域，可以由范围内容的强类型联合活动分支表达，不另存重复标签。 |
| 范围内容 | 与值域表示相容的范围定义，按下表解释。 |
| 命中次数 | 本父节点下该域累计有效命中的非负整数；由特征类输入处理累计，不由普通字段写入伪造。 |

范围内容固定为以下分支，不设任意扩展包：

| 值域表示 | 范围内容 |
| --- | --- |
| I64 区间 | `下界`、`上界`，均为 I64 且下界不大于上界；本新字段合同使用闭区间，单点为上下界相等。 |
| 结构域 | `正式比较规则引用`、`允许差异范围`；使用本域项的代表值，差异范围是与规则输出同量纲的 I64 闭区间。 |

结构域表示满足具名比较谓词的原始值集合，不把原始结构改成一个距离标量特征。比较规则必须唯一确定材料解释、左右角色、输出类型、单位 / 缩放与适用范围，取自 4120、4180 的正式合同；不能只传函数地址、字符串或在同一字段中附带可任意更换的算法版本。规则尚不存在或输入不支持时不得猜测算法，不得把不可比较当成域外。不同结构域必须各自明确代表材料，不共用可变的最新快照。

多个区间或结构域组成集合，不能用一个总最小最大区间填平中间空隙。范围保存本身不表示已满三次，也不替代准确当前值；历史具体项只按第 1.2.1.1 节简化。以上两个结构分支固定本次字段边界，不扩展 4180 的已实现算法矩阵；其它值域形状需要正式扩展后才能进入新字段，不能通过任意字节或嵌套结构绕过。

代表值须属于本域所表达的范围。域项的代表、范围或比较含义发生变化时，不得沿用原标识和原命中计数为新域证明三次命中；新域另取父内标识并独立计数。只为本判据无需增加完整历史窗口或时间字段；原始观察的其它保存用途仍按其所属记录合同处理。

#### 1.2.3 关系字段与索引

| 关联 | 唯一事实承载与基数 |
| --- | --- |
| 特征类型 | 特征信息到正式特征定义的关系；完整信息恰一类型，读回投影为 1130 的特征类型字段。 |
| 值域细分父子 | 父特征信息到子特征信息的有向生成关系，须精确定位形成该子的父内值域项及子节点对应的继承域项；每个父域最多关联一个生成子节点。父可有零到多个子节点，在该分裂树内每个非根节点恰一直接分裂父，禁止自环、成环和重复生成。 |
| 宿主、场景、来源、观察及当前采用 | 由各自正式关系 / 记录关联；不作为新特征信息自身必填字段，不用父子关系代替。 |

细分子节点与父节点具有相同特征类型，子节点以对应已确认稳定域形成自己的范围描述；父已声明总体允许集合时，子域必须属于父范围。结构域包含不能仅凭中心距离与半径相加推断，须按正式谓词规则证明。细分关系不同于抽象类型上下位关系、复合特征组成关系和概念支持关系，不复用其角色含义。

同一父节点的某个已有值域形成子特征信息后，该域及其命中记录仍留在父节点的值域集合中；子节点保存自己的范围表达，不取得删除或替换父域的含义。分裂动作不得包含父值域移除、清空、缩减、范围覆盖或父节点退出，正常计数增加及第 1.2.1.1 节的历史成员简化不属于父域删除或范围覆盖；材料回收仍须服从各自合同。

子节点初始复制的域为继承域，由上述生成关系及对应完整域定义识别，不另加“继承”或“已分裂”布尔字段。继承域保留原代表、比较含义和范围，继续用于命中、计数与识别；本地满三次后可以简化自己的历史，但不得再次仅因满三次生成同域孙节点。不能只换局部标识把同域伪装成新域；只有后来按正式规则形成的真正新细分域才进入后续建子判定。首次从父域建立子节点不要求子初始域严格小于该父域。更深细分的形成规则和输入路由未由本条凭空提供。

父节点身份、子节点列表和某域已经生成的子节点由该关系索引查询后正式读回；不得再在节点值记录中持久化父指针、子列表、子数量或已分裂布尔值作为第二权威。关系必须精确绑定父身份和域项标识，不能事后凭范围相等或第几个子节点猜来源。形成节点、字段与细分关系须共同发布，不能以内部稳态表新增项或未挂父关系的半结构返回分裂完成；精确物理关系编码不由本条指定。

#### 1.2.4 输入数据与自动分裂

外层只提交合法新观察值；以下处理由特征类内部自动完成，不要求外层另行调用分裂或后台观察线程：

1. 数据来自正式接收的实际值输入，目标信息和正式类型必须明确；输入为直接整数或已保存值的强类型引用。完整解析和校验后在工作副本更新准确当前值，并按第 1.2.1.1 节去重、维护历史；不从范围上下界、当前缓存或计数补造新样本。
2. 按该类型合法比较合同对全部既有域判定命中；同一次输入命中多个重叠域时，各命中域各计一次，不按容器顺序任选一个。未命中不增加；不可比较、缺材料或比较失败不能当作全不匹配。
3. 全部不匹配时，按 4120 第 3.3 节的类型绑定规则，以本次首次合法输入为固定代表，结合允许误差建立新候选域和新的父内标识，首次输入计一次。缺比较、域形成规则、参数或解析能力时拒绝本次自动处理，不猜零半径、默认误差或不受限区间。
4. 每个域的本地累计命中达到或超过 3 次时，按第 1.2.1.1 节简化历史。该域不是继承域且没有生成子关系时，同次自动建立同类型子节点；已有生成关系或属于继承域时只继续维护，不重复建子。固定门槛 3 不增加时间窗口、连续帧数、边界收敛或置信门槛。
5. 新子节点的当前值取本次触发分裂的准确输入，历史集合先保存该准确具体值；初始继承域复制父域固定代表、比较含义及范围，本地计数为 0。不得把当前值设为域代表、复制父计数或父历史，也不能借父域满三次立即简化子历史；生成关系共同明确父域及对应继承域。
6. 创建子节点不算一次新观察，同次输入不再递归灌入刚创建的子节点。后继对子节点的输入与新细分域形成须按明确的调用和类型规则执行，不承诺未定义的自动递归路由或默认缩小误差。
7. 命中次数是合法实际输入次数，不是历史项数或不同值身份数。相同内容的不同真实输入可以各计一次；普通读取、重读保存结果和技术重试不计新命中。后续同域输入不增加已被稳定域覆盖的历史具体项，但仍确认准确当前值并累计各命中域。
8. 本次当前值、历史集合、域及计数、所有应建子节点及其字段和生成关系按第 1.2.5 节共同可靠保存；任何失败都不得返回当前已更新、计数已准入或分裂已完成的半结构。

命中次数只证明本次操作性“稳定”判据，不证明统计稳定性或输入真实性。规则来源固定为特征类型绑定，实际参数、入口真实输入识别、继承域关系编码、完整错误返回 ABI 与更深细分提供者仍须后继合同落实，不能因有字段就宣称运行能力已存在。

#### 1.2.5 内存组织与共同可靠保存

特征类可在内存使用强类型联合、历史成员集合及按稳定局部键组织的值域集合；关系索引用于查找类型、父子及继承来源。容器只是正式读回投影或本次工作副本，不是第二事实仓。索引命中后仍须正式读回，数组位置不承担域身份。

字段维护与类内自动处理分开：自动处理形成完整结构修改，底层数据操作通过 L1 既有节点、关系、值及属性槽能力共同可靠提交。不得原地改写已发布的 L1 值或直接对其中的命中次数做 `++`；工作副本计数更新后以合法新值保存、属性槽切换及关联写集发布，失败不暴露半更新，技术重试不重复计数或建子。此要求不向对象字段回填幂等、批次、版本或代次，也不新增 L1 特征领域入口。

集合持久承载须由特征类具名封闭编解码合同映射到 L1 现有值表示；不能直接转储 C++ 容器内存、任意 JSON 或假定 L1 支持结构体数组。准确值、域代表、历史域引用和生成关系须共同校验引用完整性；L1 不会自动把整数序列中的任意整数识别为值引用，后继物理合同必须落实强类型读回与退出保护，不以集合编码成功代替引用安全。

#### 1.2.6 排除字段与验证边界

不增加特征专属名称、宿主、当前稳态索引、技术当前 / 历史封套、默认值、观察时间、近帧值 / 时间缓冲、重复的本体命中总数、置信度、稳定标志、继承 / 已分裂标志、连续次数阈值、测量误差预算、淘汰参数、版本、代次、幂等、批次或生命周期字段。准确当前观察值、识别历史集合和逐域命中次数是明确保留的业务数据；名称 / 节点类型沿用通用结构，技术可靠性归 L1。结构域允许差异范围是域定义，类型规则参数不重复成为节点本体字段。

验证至少覆盖下表；它是后继实现的验收要求，不是本次已经执行的代码验证：

| 场景 | 必须成立的结果 |
| --- | --- |
| 不同准确值同域、同内容不同值身份、内联 / 引用 I64 同内容 | 当前值准确更新；具体历史按完整内容去重，相似不冒充相等；命中与去重分账。 |
| 普通候选域 0 / 1 / 2 / 3 / 4 次 | 前三种不建子、不用该域简化；第 3 次简化并建子；以后不重复建子。首次形成域计一次。 |
| 多域、交替、重叠及旧形态重现 | 每个命中域各计一次，稳定域引用去重；不填平域间空隙，不以最新输入移动代表吞并漂移。 |
| 继承域及子初始化 | 子当前为触发准确值、历史为该值、域代表保持原值、计数 0；本次不递归输入；其本地满 3 可简化但不建同域孙节点。 |
| 历史简化 | 被覆盖具体项替换为本节点稳定域引用；不伪称无损或全域均观察过，准确当前及其它准确材料引用不丢失。 |
| 缺规则 / 参数 / 材料、解析失败、不可比较 | 拒绝本次自动处理，不伪装全不匹配或猜默认域；当前、历史、计数与子结构不部分发布。 |
| 读取、技术重试、发布失败、重新读回 | 不新增命中、不重复建子；共同写入和读回一致，父域完整保留，无悬空引用或第二权威。 |
| 域含义变化、生成关系及继承来源 | 代表 / 范围 / 比较含义改变不复用旧键和旧计数；换局部键不规避继承限制，同类型、无环及每域至多一子。 |

本规范固定字段、规则来源、按节点操作及自动处理语义；具体函数签名、封闭持久编码和缺失提供者属于后继实现设计，不能从旧实例槽 ABI 直接改义得到，也不能将尚未实现重新解释为字段尚未决定。

## 2. 按节点的数据操作

### 2.1 定位与函数范围

特征类必须同时提供整节点操作、已确认字段的独立操作和本类负责的已确认关系的独立操作。已有特征信息以节点身份定位；不得要求调用方先枚举宿主、反查实例槽或传回完整旧对象才能操作某字段。

| 对象 | 数据操作边界 |
| --- | --- |
| 特征信息节点 | 创建、读取、修改、删除及按正式类型与值条件查询；身份由 L1 创建且稳定，不提供改写身份的普通 setter。 |
| 特征类型 | 根据特征节点读取、建立、修改或移除类型关联；完整信息恰一正式类型，变化时须校验已有值、历史、域及细分关系相容。 |
| 准确当前观察值 | 根据特征节点读取、设置、修改或移除；合法新观察输入同时按第 1.2 节维护历史、域和细分，不能用孤立 setter 绕过该输入处理。 |
| 历史值集合 | 根据特征节点读取集合、增删改查具体值项或本节点域引用；保持精确去重、域引用有效及与准确当前值的既定关系。 |
| 值域集合与域项字段 | 根据特征节点定位集合，根据“节点身份 + 稳定域项标识”操作域及其字段；域身份不改写，代表 / 范围改义不复用旧键和计数，命中计数不允许普通写入伪造。 |
| 类型与细分关系 | 由特征类按正式端点与角色增删改查，不复制字段事实或形成第二父子列表。 |
| 宿主采用关系 | 由引用方所属类按各自合同操作；只引用特征节点并保持引用完整，不取得特征内部字段写权，也不由特征类接管宿主成员 CRUD。 |

“按节点操作”指节点是定位起点，不是每个函数只能有一个参数。设置值仍需要新值，集合操作仍需目标成员或局部键，建立关系仍需目标节点；调用者不必自行展开底层关系、技术分区或 L1 写集。

已确认的不可变身份、派生计数和整体完整性约束仍然有效；独立字段函数不意味着所有字段都能任意赋值。移除尚被历史或生成关系引用的域、改变类型导致已有值不相容等操作，须共同解决关联或明确拒绝，不能返回悬空引用或半更新。

### 2.2 未设置、查询与关联

未设置与已设置的 0 必须区分。逐字段维护可以明确读回缺字段结果；缺少正式类型或准确当前值的节点不得被完整信息读取伪装成完整对象，也不得以默认值补齐。

按类型和值查询使用正式类型身份与类型相容的值条件，索引只召回，结果经正式字段读回核对；精确值匹配按第 1.2.1 节，范围或结构比较按类型绑定规则及 4180。多个匹配节点应完整表达，不新增“同类型同值唯一节点”规则。

宿主引用允许后续建立和解除，不以宿主存在验证作为特征节点创建或字段操作的前置。宿主关系自身必须校验其端点和所属结构规则；解除一条关系不等于删除特征对象。特征节点删除及值材料回收仍须保护其它合法引用。

## 3. 类型、组合与比较路由

正式特征类型从 1120 / 4120 定义身份读回；先天 / 后天分类属于类型定义，不扩充特征信息五字段。名称或字符串只用于召回，不替代类型身份。

值表示、材料解析、叶子 / 复合组成和类型域来源由 4120 规定；精确比较、差异与合法算法分别按 4130、4180。组合求值读取被引用的特征信息，不再按宿主懒建实例槽，也不把复合组成、类型上下位与值域细分三种关系混用。旧批次材料只按 4170 保护历史引用，不成为任何新字段操作的前置。
