# 4110 子规范 特征节点实现与字段边界

编号：4110
日期：20260907
版本：v0.11
状态：正式子规范

## 1. 定位

本规范展开 1130 新特征信息的封闭字段和值域细分关系，并区分抽象定义、既有实例槽、当前值、组合和兼容入口。第 1.2 节是新字段展开的唯一正文；第 1.1、2—8 节的宿主唯一槽及当前发布要求仅适用于既有具名合同，不得反向扩充新对象或替代其细分关系。

### 1.1 权威模型裁决

特征事实由内存已发布代次中的宿主身份、特征类型合同、定义版本、实例身份、宿主关系、定义关系、唯一当前属性槽、值事实和发布证据共同成立。SQL 只保存对应持久证据、恢复输入和交互投影；固定关系编号、固定准入表下标、节点类型数值和运行期完整句柄数值不构成跨层公开机器语义。

本规范继续保留“同宿主同类型唯一实例、实例唯一当前值、换代保留历史、领域服务唯一写入和写前基数复核”的业务意图；其物理合同统一服从 4010—4040 与 4190。特征值具有稳定事实身份，但不是节点；不得为了统一节点遍历而把值事实升级成节点。

直接上级规范：1120、1130、2100。

直接依赖规范：4010、4020、4160。

相关边界规范：4120、4140、4170、4180。

### 1.2 新特征信息字段与关系展开

#### 1.2.1 特征值承载

1130 第 1.1 节的特征值固定采用互斥的有标签联合：

| 承载分支 | 内容与校验 |
| --- | --- |
| 内联 I64 | 一个完整有符号 64 位整数；没有独立 2100 值身份，不分配伪值节点。 |
| 2100 值身份引用 | 一个可经特征值服务可靠读回的强类型值身份；实际值表示和完整内容以 2100 读回为准，不以编码非零或任意节点存在替代。 |

承载分支必须显式可读；可以由强类型联合的活动分支表达，不另存可漂移的重复枚举。禁止凭正负、大小、数值区间或地址猜测“整数还是引用”。同一正式类型允许的原始表示仍唯一：I64 类型可内联整数或引用 I64 值，引用向量不使该类型自动改为向量；其它表示按类型合同使用值引用。承载方式不是轮廓、坐标、颜色等业务类型。

本条信息的特征值与每个值域自己的代表值分开：父节点可以维护多个形态范围，不能随最新观察覆盖一个全局代表而改变所有范围含义。若同一准确材料需复用，使用已有值引用，不复制为多个独立权威载荷。被其它事实依赖的准确内容仍须可回查，不能以本条字段维护替换其已引用材料。

#### 1.2.2 值域集合与值域项

值域集合保存范围及按 1130 三次命中判据必需的积累数据；各项都解释为同一特征类型下的允许集合。每项使用稳定的父内标识，不以容器下标、显示顺序或可变边界作身份。域之间可以重叠；必须保留各自含义，不能仅因相交、同中心或命中同一样本就合并为同一节点。

值域项字段清单封闭如下；不额外设置“稳定”“已分裂”或观察生命周期字段：

| 字段 | 固定含义 |
| --- | --- |
| 值域项标识 | 父特征信息内唯一、稳定、非零且不复用的局部键；以父身份与该键共同定位域项，不是新增全局节点族或结构 owner。 |
| 代表值 | 该域固定采用的准确代表材料，使用内联 I64 / 2100 值身份引用；新域按合法输入形成时保留该输入代表，不从区间中点伪造样本。 |
| 值域表示 | 区分 I64 区间与结构域，可以由范围内容的强类型联合活动分支表达，不另存重复标签。 |
| 范围内容 | 与值域表示相容的范围定义，按下表解释。 |
| 命中次数 | 本父节点下该域累计有效命中的非负整数；由特征类输入处理累计，不由普通字段写入伪造。 |

范围内容固定为以下分支，不设任意扩展包：

| 值域表示 | 范围内容 |
| --- | --- |
| I64 区间 | `下界`、`上界`，均为 I64 且下界不大于上界；本新字段合同使用闭区间，单点为上下界相等。 |
| 结构域 | `正式比较规则引用`、`允许差异范围`；使用本域项的代表值，差异范围是与规则输出同量纲的 I64 闭区间。 |

结构域表示满足具名比较谓词的原始值集合，不把原始结构改成一个距离标量特征。比较规则必须唯一确定材料解释、左右角色、输出类型、单位 / 缩放与适用范围，取自 4120、4180 的正式合同；不能只传函数地址、字符串或在同一字段中附带可任意更换的算法版本。规则尚不存在或输入不支持时不得猜测算法，不得把不可比较当成域外。不同结构域必须各自明确代表材料，不共用可变的最新快照。

多个区间或结构域组成集合，不能用一个总最小最大区间填平中间空隙。范围保存不表示样本已稳定，也不替代准确值。以上两个结构分支固定本次字段边界，不扩展 4180 的已实现算法矩阵；其它值域形状需要正式扩展后才能进入新字段，不能通过任意字节或嵌套结构绕过。

代表值须属于本域所表达的范围。域项的代表、范围或比较含义发生变化时，不得沿用原标识和原命中计数为新域证明三次命中；新域另取父内标识并独立计数。只为本判据无需增加完整历史窗口或时间字段；原始观察的其它保存用途仍按其所属记录合同处理。

#### 1.2.3 关系字段与索引

| 关联 | 唯一事实承载与基数 |
| --- | --- |
| 特征类型 | 特征信息到正式特征定义的关系；完整信息恰一类型，读回投影为 1130 的特征类型字段。 |
| 值域细分父子 | 父特征信息到子特征信息的有向关系，须同时明确形成该子的父内值域项标识；每个父域最多关联一个生成子节点。父可有零到多个子节点，在该分裂树内每个非根节点恰一直接分裂父，禁止自环、成环和重复生成。 |
| 宿主、场景、来源、观察及当前采用 | 由各自正式关系 / 记录关联；不作为新特征信息自身必填字段，不用父子关系代替。 |

细分子节点与父节点具有相同特征类型，子节点以对应已确认稳定域形成自己的范围描述；父已声明总体允许集合时，子域必须属于父范围。结构域包含不能仅凭中心距离与半径相加推断，须按正式谓词规则证明。细分关系不同于抽象类型上下位关系、复合特征组成关系和概念支持关系，不复用其角色含义。

同一父节点的某个已有值域形成子特征信息后，该域及其命中记录仍留在父节点的值域集合中；子节点保存自己的范围表达，不取得删除或替换父域的含义。分裂动作不得包含父值域移除、清空、缩减、范围覆盖或父节点退出，正常命中计数增加不属于范围覆盖。已有观察数据和材料引用也不因该域已经形成子节点而被回收；是否需要另行调整范围或回收材料须服从其各自合同。

父节点身份、子节点列表和某域已经生成的子节点由该关系索引查询后正式读回；不得再在节点值记录中持久化父指针、子列表、子数量或已分裂布尔值作为第二权威。关系必须精确绑定父身份和域项标识，不能事后凭范围相等或第几个子节点猜来源。形成节点、字段与细分关系须共同发布，不能以内部稳态表新增项或未挂父关系的半结构返回分裂完成；精确物理关系编码不由本条指定。

#### 1.2.4 输入数据与自动分裂

1. 数据来自特征类正式接收的合法特征值输入，目标父信息和正式特征类型必须明确；输入可以是直接整数或已保存值的强类型引用，不从范围上下界、当前缓存或命中计数补造样本。
2. 按该类型合法比较合同对既有域判定命中；同一次输入命中多个重叠域时，各命中域各计一次，不按容器顺序任选一个。未命中不增加；不可比较、缺材料或比较失败不能当作全不匹配。
3. 全部不匹配时，只有已具备该类型明确的域形成规则才建立新候选域，记录本次代表、合法范围和新的父内标识，首次输入计一次。范围不得由实现者随意设为零半径、默认误差或不受限区间；没有对应规则只能报告缺口，不得宣称候选域形成成功。
4. 每个域累计命中次数达到或超过 3，且没有生成子关系时，特征类内部自动建立子信息。阈值 3 是本合同固定规则，不是每个节点另带的可变参数；不增加时间窗口、连续帧数、边界收敛或置信门槛。
5. 子信息采用同一类型、本域代表值与范围，并建立绑定父域项的父子关系。命中计数更新及本次应有的子节点、字段、生成关系组成同一完整逻辑写入，交 L1 可靠发布；失败不得返回计数已准入或分裂已完成的半结构，技术重试不得重复计数或重复建子。
6. 同域后续命中保留父域并更新其计数，已有生成关系时不重复建子。普通读取不增加命中；相同内容的不同真实输入可以分别计数，重读同一保存结果或重试同一逻辑操作不能伪装成新输入。
7. 子节点建立不算一次新观察，也不继承父域的累计命中次数；子节点初始范围的本地命中次数为 0。同一次输入只处理调用目标的已有域，不自动递归灌入刚创建的子节点。后继对子节点的输入与域形成须按届时明确的调用合同执行，本条不承诺未定义的自动递归路由。

命中次数直接支撑本次操作性“稳定”定义，不是统计稳定性证明。域范围如何由类型规则形成、输入入口如何取得真实材料、关联的精确物理映射和错误返回 ABI 仍须由后继完整合同确定，不能因有计数就宣称已有运行能力。

#### 1.2.5 排除字段与验证边界

不增加特征专属名称、宿主、当前稳态索引、当前 / 历史、默认值、观察时间、近帧值 / 时间缓冲、重复的本体命中总数、置信度、稳定标志、已分裂标志、连续次数阈值、测量误差预算、淘汰参数、版本、代次、幂等、批次或生命周期字段。逐域命中次数明确保留；名称 / 节点类型沿用通用结构，技术可靠性归 L1。结构域允许差异范围是该域定义，不等于外设误差预算或“三次命中”阈值。

验证应覆盖每域 0 / 1 / 2 次不建子、3 次建子、4 次及以后复用、交替与多域命中、首次建域计一次、普通读回和技术重试不计新命中、缺比较 / 域规则拒绝、范围含义不复义、父域完整保留、计数与子结构可靠发布，以及新子不继承计数或在本次递归触发。精确比较、值来源、同类型关系、无环和准确材料不丢失继续按各自合同核验。本次固定字段与三次命中规则，不冻结完整新 CRUD ABI、存储布局或旧入口物理迁移；不得直接给旧实例槽删宿主、增加子关系或换字段后声称兼容。

## 2. 抽象与实例分离

1. 正式特征类型必须是抽象特征定义节点，不是语素、文本或硬编码枚举。
2. 创建实例特征前必须存在对应抽象特征定义。
3. 实例特征由宿主归属关系、定义模板关系、唯一当前属性槽和值事实承载；写当前值入口只接受实例特征槽。
4. 实例化不深复制抽象特征子树。需要细化特征时，在同一宿主下按抽象定义懒创建独立实例槽。
5. 实例当前值必须回到抽象值域解释；无命中保留为观察和定义缺口，多命中记录重叠事实。

## 2.1 特征实例关系

合法实例槽只使用两类业务关系：

| 关系 | 源节点类型 | 目标节点类型 | 当前基数 |
| --- | --- | --- | --- |
| 宿主关系 | 存在、场景、需求、任务或方法 | 特征（实例槽） | 每个宿主零到多；每个实例槽反向恰一宿主 |
| 定义关系 | 特征（实例槽） | 特征（抽象定义） | 每个实例槽恰一当前定义 |

不得为自我、任务、方法或其它宿主另建平行槽位关系。关系类型、顺序号和物理编码由当前 L2 特征结构合同封装，不作为跨层调用方可以构造的公开 ABI。

同一宿主和同一抽象定义在同一当前版本下只能形成一个有效实例槽；该唯一性必须在同一事实截止同时回读宿主关系和定义关系，不能靠索引、名称或任一单边关系裁决。未知关系类型、非法宿主类型、抽象定义 / 实例槽身份混淆、槽位多宿主或多模板必须写前拒绝；前置通过后的基数异常属于内部逻辑错误。

核心关系仓库只执行通用端点、句柄、状态、版本和候选发布，不得被解释为已经完成特征业务准入。宿主关系和定义关系的创建、失效或读取不得绕过特征领域数据操作直接开放给其它领域服务。

### 2.2 当前属性槽和值事实

本节描述实例关联及 L1 值事实封套；所属实例、来源、生命周期和当前槽不属于 2100 新特征值对象的字段。当前槽选择的是某实例当前采用的值，不使其它已保存值丧失其原始材料身份。

每个实例槽在一个已发布事实截止最多有一个当前属性槽。设置当前值后必须恰有一个当前属性槽指向一个当前值事实；未设置值时允许属性槽不存在，不得用空值节点、零编码或第二当前表表达“尚未设置”。

当前属性槽和值事实必须同时满足：

```text
属性类型与特征定义冻结的原始值表示一致
值事实具有唯一非零稳定编码且所属实例等于该实例槽
值事实的材料、来源和生命周期完整
独立材料引用适用时已由不可变材料服务在同一事实截止强类型读回
当前属性槽唯一且没有第二当前权威
```

当前值换代必须在同一事务中退出旧值事实、发布新值事实并把唯一当前属性槽切换到新值事实；不得原地改写旧载荷。旧值事实及其来源、材料和生命周期继续保留历史读回，但旧属性槽指向和批次账不得冒充当前值。

L1 的属性槽和值事实能力只证明业务中性的稳定编码、owner、值表示和结构引用；特征定义允许的值表示、值域以及独立材料资格必须由特征领域服务在写前准入并在写后读回。

## 3. 细化和补位

读取和使用时优先选择满足目标语义的最细当前子特征；子特征缺失、无当前值或不可比较时，才允许父特征粗略补位，并记录实际采用口径。

父特征补位不能伪装成子特征精确值。多个子特征同时可用时，必须由目标、方法输入或正式组合规则选择。

## 4. 值类型和比较边界

1. 每个叶子特征定义必须冻结唯一允许的原始值表示、值域、适用时的单位、维度、分量角色、顺序和材料策略；调用者不得在多种原始表示间临时选择。
2. I64 可以进入正式区间和值域比较；U64 必须先有明确、可逆或有版本的 I64 映射 / 量化合同。
3. VecI64、VecU64 的完整向量由一个值事实保存；不得为分量或可能取值建立节点。坐标、句柄组和其它业务解释由特征类型专用读取规则处理。需要比较或形成差异时，该专用规则必须通过 4180 登记特征定义、比较用途、算法族、单位、维度、左右角色、误差和版本，不得按向量形状猜测算法。
4. 区间只表达值域、容差、分类或不确定性边界，不是实际标量或向量值。逐分量区间只能表达轴对齐允许区域，不能替代相关性、方向、旋转、拓扑或形状约束。
5. 引用 / 句柄不做地址区间比较；按稳定身份相等、集合关系或专用二次特征比较。轮廓、图像、点集、点云等独立材料必须先经不可变材料服务解析并由值事实稳定引用。
6. “不等于零”是两个区间或组合规则，不能伪造为一个连续区间。
7. 不得为业务解释向特征值类型化原始记录新增业务类型或编码字段。
8. 批次身份、规则版本、项目顺序、来源版本和换代证据不得写入特征值原始记录、实例槽位、宿主或来源对象的领域记录；只有既有具名批次合同的历史重放继续使用 4170 专用记录。2100 新值对象及普通操作不以建立该账为前置，其可靠读写复用 L1 能力。

轮廓、3D 坐标、颜色等标志只属于特征类关联的特征定义，不是原始值表示枚举。具体单位、坐标、格式与解析规则由 4120、4180 解释；值对象保存完整数据但不判断业务含义。

## 5. 区间重叠和个体覆盖

同层抽象区间允许重叠。实例值同时命中多个区间时必须记录涉及定义、次数、时间和来源，不得强行只留一个。

重叠长期稳定时由特征治理决定细分、合并或保留。实例宿主可有具名局部值域覆盖，但必须关联抽象定义、宿主、来源和版本，不能改写全局定义。

## 6. 组合特征

组合特征由有向无环的输入定义关系和收束规则形成，不把输入关系混入普通细化父子链。求值时按输入定义找到同一宿主上的实例槽，执行缺失策略和收束规则，再把输出写入组合特征实例槽。

长期语义字段、枚举、状态和嵌套结构应逐步转为抽象特征定义、实例值和组合规则；DTO 只作本轮传递。

## 7. 能力和类型入口

自我能力等枚举型特征使用正式枚举定义和值域；任务和方法按特征引用或稳定主键表达，不按动作名或显示文本。

`_按类型`、按词条或按字符串入口只能作为兼容 / 初始化召回入口，必须先经名称候选和目标正式强类型读回解析到已理解抽象特征，再创建或读取实例槽。词条和字符串不保存特征类型；没有抽象定义和值域的兼容特征不得进入需求、方法、因果或结算主链。

## 8. 写入与验证

在本规范既有实例当前值发布路径中，特征服务是实例槽、宿主 / 定义关系、当前属性槽、值事实和命中事实的唯一公开写入方；该路径的特征值服务仅为其内部参与者。此既有依赖关系不扩充 2100 新值对象字段，也不单独冻结新值类的完整公开 CRUD ABI 或迁移方案。

验证覆盖唯一宿主、唯一定义、唯一当前属性槽、值事实稳定身份、定义值表示与值域准入、独立材料同截止读回、无命中、多命中、父补位、局部覆盖、组合 DAG 和兼容入口解析。
