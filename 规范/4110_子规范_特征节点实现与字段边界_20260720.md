## 1. 权威与职责

本规范只展开 1130 的准确特征节点及其允许操作。身份、类型与准确值由特征结构服务唯一保存；名称逻辑字段由概念结构服务的特征到概念关系提供；存在拥有自身已知特征和当前采用关系。索引、容器和组合读回均不是第二事实仓。

不再在特征数据类维护观察历史、值域集合、命中计数或自动分裂。类型积累与特征概念应用按 7160，二者复用 4120 / 4180 的类型解释与比较能力，不复制一套算法或反向扩张 L1。

## 2. 准确值与内容同一性

### 2.1 值承载

准确值采用互斥的有标签联合：

| 分支 | 合同 |
| --- | --- |
| 内联 I64 | 一个完整有符号 64 位整数，没有独立 2100 值身份，不分配伪值节点。 |
| 2100 值身份引用 | 经特征值服务完整读回的强类型值引用；独立材料按其正式解析合同读取。 |

不能凭整数正负、大小、地址或是否为零猜分支。正式类型的原始表示唯一：I64 可内联或引用同内容 I64，不能因此临时改为向量或材料表示。向量、轮廓等保持完整材料，不能用节点编号、摘要、域代表或距离值代替。

未设置与合法整数 0 分开；类型或准确值不完整的材料不得发布为完整特征。名称未设置不属于准确内容缺项。

### 2.2 固定内容与复用

同一正式类型下按原始表示和完整内容精确相等判定；内联 I64 与引用相同 I64 内容可以匹配。引用身份或摘要只用于召回，不能单独证明内容相同。相似、误差范围内或命中同一概念不属于准确内容相等。

创建请求可以先查询并复用已有相同内容特征；多个合法匹配必须完整表达，不按容器首项暗中裁决。本文允许内容复用，不据此自动合并或删除历史上不同的节点身份。

特征成立后，类型及准确值内容固定。修改类型、改值、移除必需值或重挂不同值内容均不得作为原节点普通 setter；新内容另建或复用特征，再由引用方改变采用。名称的补充、替换、解除不构成准确值变化。

## 3. 关系和读回

| 结构 | 写入责任与边界 |
| --- | --- |
| 特征类型关系及准确值字段 | 特征结构服务；成立时完整，之后不原地改义。 |
| 特征到所采用概念的名称引用 | 概念结构服务；当前至多一项，引用定义适用且已正式成立的概念。 |
| 概念到词条名称关系 | 既有名称关系服务；不把语言文字复制进特征准确值或另设平行名称槽。 |
| 存在已知特征与当前采用关系 | 存在结构服务按 7150；只引用准确特征，不取得其内容写权。 |
| 状态、动态及其它来源引用 | 各自具名结构服务；不由特征创建自动补造。 |

特征内容读取从节点定位，不要求概念先存在；内容读回不代替4205位置完整性。完整带名称的应用视图通过特征和名称关系的公开读取组合；名称关系真实为空与读取失败必须分开，不能在引用损坏时伪装成未命名。特征存储函数不反向调用概念生成业务，也不提供跨 owner 的另一条名称写入口。

涉及存在的当前查询必须先读取该存在的当前采用，再读取所引用准确特征。旧特征一直可读不证明它仍被采用；不能缓存固定 F 后永远把它当成存在当前值。已知特征集合不等于当前采用，也不等于按时间排列的每次观察档案。

## 4. 最小操作语义

| 操作 | 结果与约束 |
| --- | --- |
| 创建准确特征 | 必须接收并预核验场景C、组织父P、正式类型及完整准确值；缺位置零写，F内容与C已知引用、P到F组织边共同发布；名称、状态、动态不作出生前置。 |
| 按节点读取 | 返回身份、正式类型和完整准确值；无节点、旧格式或材料错误分别返回，不猜默认值。 |
| 按类型与准确内容查询 | 索引召回后核对完整内容，返回全部合法匹配；查询本身不计观察或用途。 |
| 按正式条件查询 | 范围或结构条件按类型绑定规则比较，只返回匹配，不改写值、不生成概念。 |
| 删除 | 核验全部合法引用；不级联删除存在、概念、状态或独立材料，不越权解除其它对象引用。 |

名称操作通过其既有唯一 owner 提供读取、建立、替换和解除；应用可以组合，但不得复制 CRUD。特征类型和值不再保留“逐字段任意修改”入口；关系可操作不等于可改变固定准确内容。

## 5. 输入、应用组合与可靠保存

真实观察由应用处理：形成或复用准确特征，按用途更新存在采用，并把同类型观察交 7160 积累。真实观察次数与新特征数量分开；20、22、20 三次观察可仅用两个特征节点。普通读取、技术重试及重新读回不构成新观察。

准确特征、概念、名称引用及存在采用按各自公开合同发布；不默认跨对象全流程原子。准确特征已经成立而概念形成或名称关联失败时，保留真实结果，不回称全流程完成，也不删除已成立准确事实。需要跨对象原子性的具名业务必须另以已有 L1 能力和完整合同组合，不能靠顺序调用冒充。

L1 继续提供可靠读写、原子发布、引用保护与恢复；这些保证不向四逻辑字段回填版本、代次、幂等、批次或生命周期。不得直接对已发布不可变材料改值。内存对象和索引仅为读回投影或工作副本，不直接转储容器内存为持久权威。

### 5.1 定位创建与存量边界

禁止保留无位置的公开准确F创建入口、以默认根补位置、先提交F再补组织或把临时F向正常读取暴露。组合数据服务复用三个现有owner及4015三分区原子事务：1为F内容、2为C已知F、3为P到F组织边，同一G发布，当前采用不变。概念形成及名称随后独立发布；应用完整结果包含F、位置及最终概念或具名概念未完成。

复用必须核验准确内容和请求C/P与实际组织位置相等；跨位置只允许既有使用引用，不改变原位置。相同内容多个候选须显式选择；错位置不得静默复制。旧无父F不删除、不猜位置、不得经新创建入口假称已定位；只有调用方明确给定C/P后按4205既有组织合同迁移。存量内容及生命周期证据仍可审计，未迁移对象不得取得新定位建点成功。位置不参与FT加准确值的内容相等，不成为概念语义签名。

## 6. 退役模型、承接与完成边界

4110 v1.0 之前的旧特征信息合同已退役；旧五字段记录、特征当前值改写、历史域简化、三次命中生成子特征及其生成关系不得用于新生产；旧宿主实例槽也不恢复。旧记录只按原格式解释，不将其节点自动当成固定准确 F 或把旧分裂子节点重释为概念身份。

后继实施必须具名列出旧声明、定义、调用、存量格式与删除集；在同次消费迁移后物理删除被替代生产入口，不保留别名、空函数、双写或“先旧后新”回退作为新模型完成证明。既有与本对象无关的状态、动态、材料和 L1 ABI 不在本条批量改义。

存量处理须分别保护：

- 能确证的准确类型与值，建立或复用新 F；
- 某存在已知及当前采用的真实归属，不凭全类型概念反推；
- 旧域所表达的识别概括及其适用依据，不伪造域内所有准确观察；
- 状态、模板、概念及其它原生引用，不在迁移前提前回收端点。

不能无歧义转换的材料保持历史解释并返回具名不支持，不拼造事实。按 1130 v0.11 / 4110 v0.13 合同形成的旧 I64 实现不构成本版四字段或概念形成的实现依据；本条不宣称已经完成迁移。

本规范固定结构及操作语义，不伪造尚未设计的 C++ DTO、关系编码、跨 owner 原子入口或迁移程序。尚无正式合同的实现分支不能仅凭本文开始施工。

## 7. 验证要求

| 场景 | 必须成立 |
| --- | --- |
| 名称为空、已共同定位 | 准确F已成立，应用明确概念未完成。 |
| 内联 / 引用 I64 同内容 | 可精确匹配；不伪造值身份。 |
| 不同准确值落入同域 | 不合并 F，不将同概念当作无变化。 |
| 20、22、20 三次观察 | 可以复用两个 F；由应用分别记录三次真实输入，读回不增计数。 |
| 存在切换采用 | 旧 F 类型和值不变；旧缓存不能证明当前采用。 |
| 名称改变或解除 | 准确内容、状态依据不变，概念关系只有一份权威。 |
| 类型 / 值 setter | 不允许原地改变已成立准确内容。 |
| 名称或概念失败 | 准确事实结果与名称结果分开，不返回虚假的全流程成功。 |
| 旧五字段、旧分裂关系 | 不作为新格式或概念；既有材料和引用保护完整。 |
| 删除和清理 | 受其它合法引用保护，不级联误删事实。 |
