# 6180 子规范 自我稳定身份、项目资格与具名事实范围

编号：6180
日期：20260802
状态：正式子规范

直接上级规范：0050。

直接依赖规范：4010、4020、4040、4190。

相关边界规范：6100—6170、7130、8100、8200、8300—8320。

## 1. 定位

本规范承接海鱼 3010、3100、3110—3115 中已经确认的自我稳定身份、项目根资格、具名事实范围和对象合法建立授权。它不建立第二套自我身份，也不冻结 SQL 表、接口或线程实现。

## 2. 自我稳定身份

1. 自我是项目根概念，由唯一稳定存在身份直接承载，不是从多个存在中运行期选择的普通角色。
2. 不建立候选自我列表、当前自我选择、替代自我或身份缺失时的降级角色。
3. 自我换代保持同一存在身份，形成新的自我结构版本。结构版本、特征定义版本、特征当前关系版本和值版本分别管理。
4. 名称、配置、路径、内存地址、线程、缓存键、场景位置、显示顺序和日志均不能建立自我身份。
5. 身份缺失、重复、复义、损坏或内存权威读回不一致时必须拒绝并进入恢复，不得选择另一个存在冒充。SQL 与当前内存代次不一致时只能作为持久证据异常处理，不能覆盖当前自我身份。

## 3. 自我结构与当前值

1. 新结构继承旧定义时，可以继承未变化定义对应的当前值；继承本身不产生虚假特征变化。
2. 发生定义更新时，必须先具备合法新值；新值与原当前值相同不得形成更新。
3. 特征值更新保留旧值历史，只把当前关系换代到新值；不得原地覆盖旧值。
4. 仅有当前值变化不等于自我换代，也不产生新自我身份。
5. G01 只建立和验证治理坐标，不允许仅凭自我身份直接建立系统级根需求。

## 4. 项目根自我资格

1. 项目根自我资格是该稳定存在在本项目治理中的唯一业务语义，不是与承载存在分离的第二身份。
2. 资格必须绑定已发布通用存在身份、适用的项目正式事实范围、资格规则版本和完整证据。
3. 名称、配置、场景位置、线程、启动顺序、缓存或日志不能单独或组合建立资格。
4. 资格成立只允许后续自我结构责任继续验证，不自动建立需求、任务、方法、场景或治理状态。

## 5. 具名项目事实范围

1. 项目正式事实范围是具名业务对象，具有稳定范围身份、范围业务类型、范围版本、当前性、生命周期和发布证据。
2. 范围身份与项目主体、自我身份、通用身份、命名空间和物理 SQL 范围分离；物理共址、同一数据库范围或同一通用身份不能充分证明同一业务范围。
3. 正常范围换代不更换稳定范围身份；名称调整、进程重启、缓存丢失和存储迁移也不能改变身份。
4. 当前范围版本必须唯一。未知、冲突、跨范围、漂移和损坏必须显式返回，不能默认选择一个版本。
5. 退役保留身份、历史版本和历史判断，不得删除或复用范围身份。

## 6. 合法建立授权

1. 只有具名范围领域责任可以裁决范围对象建立授权；普通调用方、L1、通用类型合同所有者或缓存均无此权力。
2. 建立授权必须具有合法授权主体、明确建立意图、适用项目范围、拟建通用身份引用、拟发布初始版本语义以及无冲突对象前置。
3. 授权接受不等于对象发布。接受、拒绝、重复复用和竞争结果在内存事实代次发布前都不得产生普通业务可见的范围对象、当前性、生命周期或发布证据。
4. 精确重复可以返回原授权或原已发布结果；同键异义必须冲突。竞争建立至多一个接受；无法证明唯一合法者时允许零接受。
5. 初始版本、唯一当前、生命周期、退役和发布证据仍由相邻对象责任在同一发布事务中完成，授权阶段不得越权代写。

## 7. G01—G12 治理坐标

```text
G01 自我治理坐标
G02 安全正差距
G03 服务正差距
G04 当前值变化事实
G05 比较与条件裁决
G06 差距准入为需求
G07 需求授权转为任务
G08 任务按结果能力匹配方法
G09 方法授权下动作事实
G10 方法缺口候选
G11 权威回读与重新比较
G12 有效运行与可唤醒等待裁决
```

1. 每个目标保持单一责任，输出只交给具名消费者；不得让后层倒写前层事实。
2. 安全和服务都以各自独立的有符号 I64 根值域及 `I64_MAX` 为目标。只有严格正差距可以进入需求候选；身份、事实和证据不得混用。
3. G04 的事实变化与 G09 的动作证据分离；被动变化不伪造方法动作。
4. G11 必须从权威领域独立回读后重新比较；预期、日志或方法返回不能替代。
5. G12 只裁决有效运行、等待及其依据；休眠、停机、终止和唤醒的精确机器状态仍待专门规范。

## 8. 未决门禁

项目事实范围的精确识别输入、资格规则版本兼容、授权证据结构、范围换代选择、零差距保证机制、方法缺口分流以及休眠 / 停机 / 终止语义尚未冻结，不得从旧实现补造。
