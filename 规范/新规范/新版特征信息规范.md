# 新版特征信息规范

日期：20260928

版本：v0.1

状态：新规范草案，未登记

适用实现：`海中鱼巣/领域/新_特征类.h/.cpp`

直接依赖：`新版基础数据集规范`、`新版特征值信息规范`、`新版特征概念信息规范`

## 1. 权威边界

本文件位于`规范/新规范/`，用于冻结新版实例特征信息的目标模型、字段、持有关系、准确值写入、准入值域和历史聚合值域。它尚未登记到`规范/规范目录.md`，当前不覆盖现行正式特征规范，也不授权旧特征数据迁移、删除或生产消费者切换。

本文中的“历史不同值”是某个实例特征实际出现过的去重准确值集合，用于形成该实例的历史聚合值域；它不是L1操作历史、事务日志、事实代次或审计账，不恢复已经取消的通用历史机制。

## 2. 根定位

新版特征信息是一个由具体节点持有的实例特征节点。它回答：

```text
谁持有这个特征
+ 该特征采用哪个特征概念
+ 这个实例允许接收什么值
+ 当前值是什么
+ 实际出现过哪些不同值
+ 这些历史不同值当前聚合成什么值域
```

持有节点可以是存在节点、场景节点或其它特征节点。特征类只要求持有节点存在，不解释持有者的业务类别。

## 3. 外部持有关系

持有关系使用基础数据集外部父子关系：

```text
持有节点 --父子关系--> 特征节点
```

规则如下：

1. 源节点是持有节点，目标节点是特征节点。
2. 每个特征节点必须恰有一个持有节点。
3. 同一持有节点与同一特征概念组合最多只有一个特征节点。
4. 特征节点不得依靠节点编码推断持有者类型。
5. 当前不自动为特征节点建立兄弟关系。

## 4. 特征节点固定字段

每个特征节点包含：

| 字段 | 类型 | 基数 | 含义 |
| --- | --- | --- | --- |
| 节点类型 | 节点引用 | 恰一 | 指向共享特征节点类型。 |
| 特征概念 | 节点引用 | 恰一 | 指向一个已存在的特征概念节点。 |
| 实例准入值域 | 私有值域节点引用 | 恰一 | 建立实例时从概念复制，控制该实例可接收的准确值。 |
| 实例历史聚合值域 | 私有值域节点引用 | 可选一 | 当前完整历史不同值集合的聚合结果。 |
| 实例单位 | 节点引用 | 可选一 | 建立实例时从概念复制。 |
| 当前值 | I64直接值或特征值节点引用 | 可选一 | 最近一次成功写入的准确值。 |
| 历史不同值 | I64直接值或特征值节点引用 | 零到多 | 该实例实际出现过的去重准确值集合。 |

比较规则和聚合规则继续由特征概念节点提供，实例节点不复制第二份规则。

## 5. 准确值承载

准确值使用：

```cpp
std::variant<std::int64_t, 稳定编码>
```

规则如下：

1. I64标量直接写入特征节点字段。
2. U64数组、I64数组、UTF8字符串、二维二值格和三维二值格必须先由新版特征值类保存，再以特征值节点引用写入。
3. 非I64值不得把原始数组或字符串直接复制进特征节点。
4. 特征值节点必须存在、可完整读回，并与特征概念材料物理类型一致。

## 6. 实例准入值域

实例准入值域是实例自己的写入准入事实：

```text
建立实例
-> 读取特征概念
-> 复制概念当时的值域和单位
-> 建立实例私有、不可变的准入值域节点
```

规则如下：

1. 后续添加值必须按实例准入值域判断，不能改用概念节点当前值域替代。
2. 实例保存建立时的概念值域快照；未来概念迁移不在本版合同内，既有实例准入域不得被隐式覆盖。
3. 当前值和全部历史不同值都必须命中实例准入域。
4. 本版没有实例准入域原地修改接口；需要改变准入域时必须先另行冻结迁移或新实例合同。
5. 实例单位是建立时的概念单位副本，不要求永久等于概念节点后续读回值。

## 7. 实例历史聚合值域

实例历史聚合值域与准入值域是两类不同事实：

```text
准入值域：允许写入什么
历史聚合值域：实际出现过什么形成的域
```

历史聚合值域初始为空。只要历史不同值非空，特征类就使用特征概念的聚合规则对完整历史不同值集合重新计算。

发布必须采用：

```text
完整建立新的私有不可变值域节点
-> 按材料类型完整读回并与目标值域精确比较
-> 新增或单次切换特征节点的历史聚合值域引用
-> 切换成功后尽力回收旧私有值域节点
```

建立、读回或引用切换失败时，不得破坏原历史聚合域引用。旧值域节点只允许由本实例私有持有，不得与其它实例共享；回收失败可以留下不可达孤儿，但不得影响活动特征。

若历史聚合域缺失，或其合法内容与完整历史集合重新聚合的结果不一致，读取结果必须把历史聚合域报告为空，使后续同值重试能够重新发布。物理结构损坏、引用损坏或值越出准入域属于结构不一致，不承诺自动修复。

## 8. 私有值域节点

准入值域和历史聚合值域都使用特征类内部建立的私有值域节点。值域节点身份不进入公开`新特征信息`，不得被上层持有或共享。

私有值域支持与特征概念一致的四种表示：

- I64闭区间集合；
- 全材料值域；
- 特征值节点有限集合；
- 有序结构化I64分量值域。

每个私有值域节点必须有恰一节点类型字段并指向私有值域节点类型。四种表示在物理字段上必须互斥：I64值域字段恰一、全材料标记字段恰一、非I64值域字段一到多或结构化分量字段一到多，四族只能选择其一，其余必须为零项。

结构化分量使用独立普通节点。每个分量节点必须有恰一节点类型字段并指向私有结构化分量节点类型，同时保存连续顺序、角色节点引用、可选单位节点引用和I64分量值域。角色和单位必须保存为真实节点引用，不能作为普通U64数字数组写入。

## 9. 建立特征

建立或取得特征的流程为：

```text
核验持有节点存在
-> 核验特征概念节点存在且完整
-> 在持有节点直接子节点中查找同概念特征
-> 恰一则完整读回并复用
-> 多于一项返回结构冲突
-> 未找到则建立特征节点
-> 写节点类型和概念引用
-> 复制并建立实例准入值域
-> 复制实例单位
-> 建立持有父子关系
-> 完整读回新特征
-> 成功后返回特征节点
```

建立新特征时不要求已有当前值，历史不同值和历史聚合值域均为空。

## 10. 添加特征值

添加值流程为：

```text
完整读回特征
-> 按实例准入值域核验新值
-> 用概念比较规则检查历史集合中是否已有等价值
-> 首次出现则加入历史不同值
-> 与当前值不同则更新当前值
-> 用完整历史集合执行概念聚合规则
-> 必要时安全发布新的历史聚合值域
-> 返回结构化结果
```

规则如下：

1. 给特征节点添加值就是更新当前值。
2. 历史集合没有等价值时才新增；已有等价值时不重复写入。
3. 当前值如果存在，必须同时存在于历史不同值集合中。
4. 判断“相同”必须使用概念比较规则，不能只比较variant索引或节点编码。
5. 即使新值已是当前值且已在历史集合中，只要聚合域缺失或过期，也必须允许同值调用重新计算并发布聚合域。
6. 聚合动作不建立特征概念，不自动形成子概念或上位概念。

## 11. 一致性不变量

任一可完整读回的特征节点必须满足：

1. 节点类型字段恰一并指向特征节点类型；
2. 特征概念字段恰一并指向现存特征概念；
3. 外部父子上位关系恰一；
4. 实例准入值域字段恰一并可完整读回；
5. 实例历史聚合值域字段至多一项；
6. 实例单位字段至多一项且目标节点存在；
7. 当前值字段至多一项；
8. 历史不同值在概念比较规则下两两不等价；
9. 当前值和历史不同值全部命中实例准入值域；
10. 当前值存在时，历史不同值中恰有一个等价值；
11. 只有对外报告为有效的历史聚合值域，才必须等于完整历史集合按概念聚合规则重新计算的结果。物理记录允许在部分成功后暂时缺失或过期；此时对外报告为空，但当前值和历史不同值仍保持有效。

## 12. 公开能力

新版特征类至少提供：

```cpp
bool 初始化() noexcept;

稳定编码 建立或取得特征(
    稳定编码 持有节点,
    稳定编码 特征概念节点) noexcept;

std::optional<稳定编码> 查询特征(
    稳定编码 持有节点,
    稳定编码 特征概念节点) const noexcept;

std::optional<新特征信息> 获取特征(
    稳定编码 特征节点) const noexcept;

bool 是特征节点(稳定编码 节点) const noexcept;

新特征值添加结果 添加特征值(
    稳定编码 特征节点,
    const 新特征准确值& 新值) noexcept;
```

本版不提供特征节点主动删除、变更持有者、变更概念、修改准入域、删除历史值或直接写历史聚合域的公开入口。

## 13. 写入结果

添加值至少区分：

```text
已完成
无变化
入口拒绝
特征不存在
概念不存在
材料类型不相容
结构不一致
值已更新但聚合未完成
资源失败
```

正式目标还必须区分“材料承载或材料类型不相容”和“材料类型正确但值不在实例准入域”。当前初版枚举把这两种原因合并为`材料类型不相容`，尚不足以作为完整生产错误合同。

结果同时携带：

- 当前值是否改变；
- 历史集合是否增加；
- 本次聚合结果。

`值已更新但聚合未完成`表示当前值或历史集合已经发生有效变化，但聚合计算或聚合域发布没有完成。调用方不得把它解释为零写入失败，也不得重新分配特征节点；应保留原特征并允许同值重试收敛聚合域。

## 14. 多步写入与失败边界

当前基础数据集没有组合原子变化集，因此添加值的“历史集合、当前值、聚合域”三步不是原子事务：

- 新历史字段写入后，如果当前值写入失败，本调用尝试删除新历史字段；
- 当前值或历史值已经成功后，如果聚合失败，不回滚已经成立的准确值事实；
- 聚合新域必须在引用切换前完整建立和读回；
- 聚合引用切换失败保留旧域；
- 同值重试负责补齐缺失或过期的合法聚合域。

正式生产链若要求跨步骤不可见半状态，必须先由新版基础数据集提供组合原子发布或等价可靠事务，不能把当前局部补偿描述为完整原子性。

## 15. 职责边界

特征类负责：

- 初始化共享特征节点类型和字段节点；
- 建立持有节点下的唯一实例特征；
- 复制实例准入值域和单位；
- 读回并校验特征完整结构；
- 更新当前值和历史不同值；
- 调用概念比较与聚合规则；
- 安全发布实例历史聚合值域。

特征类不负责：

- 保存非I64原始材料；
- 建立特征值压缩树；
- 建立或修改特征概念；
- 自动形成子特征、特征概念或上位概念；
- 推断持有节点是存在、场景还是其它特征；
- 存在、场景、状态、动态、因果、需求、任务或方法治理；
- 自然语言名称的建立与解释；
- L1操作历史、事务日志或事实代次。

## 16. 生命周期、并发与持久化

当前实现使用进程内递归互斥保护新版特征类操作，并要求新版特征值类和特征概念类操作同一个全局基础数据集且比特征类对象存活更久。

当前值、历史不同值、准入有限集合和聚合有限集合引用的非I64特征值节点按上游新版特征值规范默认长期保留；在完整引用查询和受保护回收合同建立前不得删除。

共享类型节点、字段节点和私有值域节点当前只存在于内存。程序重启后尚不能恢复同一身份，因此当前不证明：

- 特征节点和字段身份跨启动稳定；
- 同一持有者与概念组合在重启后仍只存在一个特征；
- 实例准入域、当前值、历史集合和聚合域能够恢复；
- 多进程并发建立不会产生重复特征。

## 17. 当前代码符合性与缺口

当前代码已经实现：

- 特征类初始化；
- 通过新版特征类入口、在同一进程互斥范围内完成持有节点加概念的唯一特征查找和建立；
- 实例准入值域与历史聚合值域物理分离；
- I64直接值和非I64特征值节点写入；
- 当前值、历史不同值和聚合域维护；
- 私有不可变值域节点、结构化分量节点和单引用切换；
- 缺失或过期聚合域的同值重试恢复；
- 添加值的初版结构化写入状态，但失败原因仍不完备。

尚未实现或尚未证明：

- 基础数据集持久化和跨启动恢复；
- 多步变化的组合原子发布与发布未知收敛；
- 特征类共享类型节点和字段节点初始化的组合原子发布；初始化中途失败时可能留下供重试复用的部分进程内结构；
- 新建特征在返回前的独立完整读回；当前新建路径在字段和持有关系写入成功后直接返回，只有复用已有特征时执行完整读回；
- 旧私有值域节点回收失败后的孤儿节点集中回收；
- 物理损坏聚合域的自动修复；
- 特征删除、持有者迁移、概念迁移、准入域迁移和历史值清理；
- 持有节点退出时解除特征持有关系并安全处理特征生命周期；
- 生产上层消费者调用；
- 根工程完整构建、重启恢复和集成验收。
- 统一领域写授权或封装；其它调用方可绕过特征类直接写基础数据集，从而破坏唯一持有者、同持有者同概念唯一和字段基数；当前约束只由本类入口局部维护。
- 上游新版特征值能力完整闭合；非I64准确值的合法性和身份稳定性不强于特征值提供者，其UTF8核验、全零输入/描述、二维与三维压缩层类型区分、跨实例/跨启动复用和原子发布缺口会继续传导到本类。

因此，目前只能确认新版特征类具备单进程初版数据能力，不能宣称已经接入存在、场景或自我治理流程。

## 18. 验证要求

后续至少验证：

1. 同一持有节点和概念重复建立只返回同一特征；
2. 不同持有节点或不同概念建立不同特征；
3. 建立后准入域和单位与建立时概念一致，当前值和历史为空；
4. I64和五类非I64材料按准入域正确接纳或拒绝；
5. 新值更新当前值并只追加一次历史不同值；
6. 重复等价值不重复写历史；
7. 当前值始终能在历史集合中找到等价值；
8. 准入域不因历史聚合变化而改变；
9. 聚合新域在完整读回前不切换引用；
10. 聚合失败不会破坏旧聚合域或已成立准确值；
11. 缺失或过期聚合域可由同值重试恢复；
12. 结构化分量角色和单位按节点引用完整读回；
13. 任一字段缺失、重复或类型错误时，获取入口拒绝完整读回；添加入口经获取失败映射为结构不一致。后续还需为获取入口建立结构化查询结果；
14. 程序重启后恢复同一特征身份和完整字段；
15. 上层生产消费者通过公开入口完成真实写入和独立读回。
