## 1. 权威边界

本文件位于`规范/新规范/`，用于冻结新版特征概念信息的目标模型、字段、关系、值域、初始化、查询和规则职责。它尚未登记到`规范/规范目录.md`，当前不覆盖现行正式特征、特征概念或概念树规范，也不单独授权旧实现迁移、删除或生产切换。

本文依据本窗口已经确认并由`概念_特征类`初步实现的新版模型形成。当前代码事实与目标合同不一致之处集中列入第16节，不得把“已有初版代码”扩大解释为持久化、恢复或生产接线已经完成。

## 2. 根定位

特征概念是没有实例持有者的特征定义节点。它回答：

```text
这是哪一种特征
+ 该特征使用什么物理材料
+ 哪些值属于该概念
+ 值如何比较
+ 历史准确值如何聚合成值域
+ 它有哪些自然语言名称关系
```

特征概念不是实例特征，不保存某个存在、场景或其它持有节点的当前值和历史不同值。实例特征必须引用特征概念，但特征概念不反向保存全部实例。

## 3. 全局组织

全局基础数据集中只建立一个特征概念树根节点：

```text
全局基础数据集
└─ 特征概念树根
   ├─ 特征类型概念A
   │  └─ 更具体的子值域概念
   ├─ 特征类型概念B
   └─ ……
```

组织规则如下：

1. 特征概念树根只是组织根，不是特征概念。
2. 特征概念树根的直接子节点是根链特征类型概念，其节点身份就是特征类型身份。
3. 根链概念不因材料、单位和值域相同而合并；不同特征类型允许具有相同物理结构。
4. 更具体概念通过基础数据集外部父子关系挂到上位概念下。
5. 字段节点、类型节点、分量角色节点和单位节点是独立结构节点，不挂入概念树根链。
6. 当前模型按单父树组织；一个概念节点不得同时挂到多个上位概念。

## 4. 特征概念固定字段

本版特征概念节点的业务字段封闭为：

| 字段 | 类型 | 基数 | 含义 |
| --- | --- | --- | --- |
| 节点类型 | 节点引用 | 恰一 | 指向共享的特征概念节点类型。 |
| 材料物理类型 | I64枚举 | 恰一 | 决定准确值的物理承载。 |
| 值域 | 封闭联合 | 恰一 | 允许值的完整范围或集合。 |
| 单位 | 节点引用 | 可选一 | 概念整体单位；结构化分量可各自带单位。 |
| 比较规则 | I64枚举 | 恰一 | 两个准确值如何比较。 |
| 聚合规则 | I64枚举 | 恰一 | 一组历史不同值如何形成值域。 |
| 名称关系 | 节点引用 | 零到多 | 指向后续由自然语言类提供的名称关系节点。 |

名称关系不参与概念的结构身份判断。同一概念可以有多个名称；新增名称不建立新的同结构概念。

概念类只保存和追加名称关系节点引用；词条节点、名称关系类型、名称语义以及名称关系节点本身由后续自然语言提供者建立。

## 5. 材料物理类型

材料物理类型的封闭集合为：

```text
I64标量
U64数组
I64数组
UTF8字符串
二维二值格
三维二值格
```

准确值承载规则：

```text
I64标量 -> 直接I64值
其它材料 -> 新版特征值节点稳定编码
```

特征概念只解释特征值节点的业务用途，不重复保存非I64原始材料。非I64值域中的节点必须能由新版特征值类读回，并且材料物理类型必须一致。

## 6. 值域封闭联合

特征概念值域只允许四种表示。

### 6.1 I64闭区间集合

用于I64标量：

```text
[(下界1, 上界1), (下界2, 上界2), ...]
```

区间必须满足下界不大于上界。写入前按下界排序，并归并重叠或相邻区间。规范化后不得为空。

### 6.2 全材料值域

表示某种非I64材料类型下全部合法元素。它是明确的全集标记，不是空集合，也不得用全零特征值冒充。

### 6.3 特征值节点有限集合

由一个或多个完整特征值节点组成。节点按稳定编码排序并去重；每个节点必须存在且材料类型一致。

### 6.4 结构化I64值域

结构化I64值域由有序分量定义组成：

| 分量字段 | 类型 | 基数 | 含义 |
| --- | --- | --- | --- |
| 节点类型 | 节点引用 | 恰一 | 指向共享的结构化分量节点类型。 |
| 顺序 | I64 | 恰一 | 从0连续递增。 |
| 角色 | 节点引用 | 恰一 | 分量角色身份。 |
| 材料类型 | I64枚举 | 恰一 | 当前固定为I64标量。 |
| 分量值域 | I64闭区间集合 | 恰一 | 该分量允许值域。 |
| 分量单位 | 节点引用 | 可选一 | 该分量的单位。 |

维度数量由有序分量数量唯一得出，不再保存第二份“维度数量”字段。分量角色在同一结构化值域中不得重复。

四种值域在物理字段上必须满足互斥基数：

| 值域表示族 | 物理字段基数 |
| --- | --- |
| I64闭区间集合 | I64值域字段恰一，其余三族零项。 |
| 全材料值域 | 全材料值域标记字段恰一，其余三族零项。 |
| 特征值节点有限集合 | 非I64值域字段一到多，其余三族零项。 |
| 结构化I64值域 | 结构化分量字段一到多，其余三族零项。 |

四个表示族必须恰有一个非空。混合表示、重复单值字段或四族全部为空均属于结构不一致。

## 7. 比较规则

当前比较规则封闭集合为：

```text
I64数值
完整材料精确
```

### 7.1 I64数值

只适用于I64标量，返回相等关系、大小次序和无溢出的绝对差。

### 7.2 完整材料精确

适用于非I64材料。它通过新版特征值类完整读回两个值节点，材料类型一致且原始材料完全相同才算相等。

节点编码相同本身也不能绕过节点存在、材料类型和完整材料读回；哈希、压缩根、中间压缩路径或其它近似关系均不能独立证明相等。

## 8. 聚合规则

当前聚合规则封闭集合为：

```text
不自动聚合
I64连续值归组
完整材料精确集合
```

规则含义：

1. `不自动聚合`：不做区间扩张；I64历史值形成单值区间集合，非I64历史值形成精确节点集合，结果状态可以是无变化。
2. `I64连续值归组`：只用于I64标量；排序去重后，把相邻或重叠的单值归并为闭区间。
3. `完整材料精确集合`：用于非I64材料；完整核验每个特征值节点后形成排序去重的节点集合。

聚合函数只计算规范化值域，不建立新概念节点，不自动形成上位概念，也不修改概念树。

## 9. 上下位概念

建立子概念时必须同时满足：

1. 上位节点是已存在的特征概念节点；
2. 子概念与上位概念材料物理类型相同；
3. 概念整体单位相同；
4. 子值域被父值域完整包含；
5. 至少一处发生严格收缩，不能建立同值域父子；
6. 结构化值域的分量数量、顺序、角色和单位一致，仅允许一个或多个分量值域收缩。

全材料值域可以包含同材料类型的有限特征值节点集合。有限集合只能包含其真子集。当前不允许从有限集合返回全材料值域。

同一个直接父节点下，结构定义完全相同的子概念只保留一个；再次提交时复用已有节点并补充尚未存在的名称关系。根链特征类型概念不执行这种跨类型复用。

## 10. 精确查找

### 10.1 按完整定义查询

按材料类型、规范化值域、单位、比较规则和聚合规则进行完整匹配。名称关系不参与结构匹配。查询范围是整棵特征概念树，结果可以是零个、一个或多个节点。

### 10.2 按准确值查找最具体概念

调用方必须先给出根链特征类型概念，再提供准确值和单位。查询只在该根链分支内进行：

```text
核验根链身份、材料和单位
-> 遍历严格子值域层级
-> 保留包含准确值的概念
-> 选择值域最具体的候选
-> 无候选返回未找到
-> 多个互不从属的同等最具体候选返回匹配冲突
```

I64标量以命中区间宽度判断具体性；有限节点集合以集合项数量判断具体性；结构化值域以已经建立的严格子值域层级判断具体性，维度数量不作为尺度。

## 11. 先天特征概念初始化

系统初始化时必须建立以下共享结构节点：

- 特征概念树根；
- 特征概念节点类型及全部字段节点；
- 结构化分量节点类型及全部分量字段节点；
- 毫米单位节点；
- 坐标、尺寸和RGB的九个分量角色节点。

并在特征概念树根链建立五个先天特征概念：

### 11.1 三维空间坐标

```text
材料：I64数组
X分量：INT64_MIN～INT64_MAX，毫米
Y分量：INT64_MIN～INT64_MAX，毫米
Z分量：INT64_MIN～INT64_MAX，毫米
比较：完整材料精确
聚合：完整材料精确集合
```

### 11.2 三维空间尺寸

```text
材料：I64数组
X向跨度：0～INT64_MAX，毫米
Y向跨度：0～INT64_MAX，毫米
Z向跨度：0～INT64_MAX，毫米
比较：完整材料精确
聚合：完整材料精确集合
```

### 11.3 RGB颜色

```text
材料：I64数组
R：0～255，无单位
G：0～255，无单位
B：0～255，无单位
比较：完整材料精确
聚合：完整材料精确集合
```

### 11.4 二维轮廓

```text
材料：二维二值格
值域：该材料类型全部合法元素
比较：完整材料精确
聚合：完整材料精确集合
```

### 11.5 三维体素

```text
材料：三维二值格
值域：该材料类型全部合法元素
比较：完整材料精确
聚合：完整材料精确集合
```

三维体素只描述占用，不包含颜色。颜色必须由独立RGB特征表达。

当前初始化不建立显式坐标系节点，也不为单位、角色和五个先天概念写入自然语言名称关系；这些能力必须由后续自然语言和坐标系设计补齐，不能从变量名反推为正式名称事实。

## 12. 公开能力

新版特征概念类至少提供：

```cpp
bool 初始化(const 新_特征值类&) noexcept;
std::optional<先天特征概念集合> 获取先天特征概念() const noexcept;

稳定编码 建立或取得特征概念(
    const 特征概念定义&,
    const 新_特征值类&,
    std::optional<稳定编码> 上位概念) noexcept;

std::optional<特征概念信息> 获取特征概念(稳定编码) const noexcept;
std::vector<稳定编码> 查询特征概念(const 特征概念定义&) const noexcept;
特征概念按值查找结果 查找值对应的最具体概念(...) const noexcept;
bool 是特征概念节点(稳定编码) const noexcept;
特征概念比较结果 执行比较规则(...) const noexcept;
特征概念聚合结果 执行聚合规则(...) const noexcept;
```

本版不提供概念原地修改、概念删除、自动上位概念形成或概念树自动修剪。

## 13. 非成功结果

规则执行至少区分：

```text
已完成、无变化、入口拒绝、材料类型不相容、值不存在、
规则不支持、资源失败、内部不一致
```

按值查找至少区分：

```text
已找到、未找到、入口拒绝、材料类型不相容、单位不相容、
匹配冲突、结构不一致、资源失败
```

当前部分创建和查询入口仍用空编码、空`optional`或空`vector`合并失败原因；进入正式业务链前必须形成足够的结构化结果，不能把空结果一律解释为“确实不存在”。

## 14. 职责边界

特征概念类负责特征类型身份、值域、单位、比较规则、聚合规则、名称关系、上下位组织和先天类型初始化。

特征概念类不负责：

- 保存非I64原始材料；
- 保存某个实例的当前值和历史不同值；
- 决定实例由哪个存在、场景或其它节点持有；
- 自动把聚合结果发布为新概念；
- 自动进行概念归纳、归类、上位形成或层级修剪；
- 建立自然语言词条和名称关系；
- 保存体素颜色；
- 需求、任务、方法或内部治理。

## 15. 生命周期、并发与持久化

特征概念一经建立，材料类型、值域、单位和规则在本版中不可原地修改。名称关系可以追加。概念节点默认长期保留，本版不提供主动删除。

有限值域引用的非I64特征值节点按上游新版特征值规范默认长期保留；在完整引用查询和受保护回收合同建立前不得删除。

当前实现使用进程内递归互斥保护概念类操作，依赖全局基础数据集，并用进程内静态变量记录树根、字段节点、先天概念和角色节点身份。它尚不能证明：

- 程序重启后恢复同一特征概念树；
- 五个先天概念取得与上次相同的稳定编码；
- 多进程或多个基础数据集实例共享同一概念身份；
- 多步概念建立具备原子发布和发布未知恢复。

## 16. 当前代码符合性与缺口

当前代码已经实现：

- 四种值域表示及规范化；
- 概念节点、结构化分量节点和上下位父子关系；
- 根链类型不合并、直接子概念复用和严格子值域校验；
- 完整定义查询和按值查找最具体概念；
- 两类比较规则和三类聚合规则；
- 五个先天特征概念初始化及同进程读回。

尚未实现或尚未证明：

- 基础数据集持久化和跨启动恢复；
- 字段节点、单位节点、角色节点及先天概念的固定身份恢复；
- 概念建立的组合原子发布和发布未知收敛；
- 概念初始化的组合原子发布；树根、字段节点、角色/单位节点或先天概念建立中途失败时，可能留下供重试复用的部分进程内结构；
- 结构化创建失败时所有中间节点在所有异常路径上绝对零残留；
- 自然语言名称关系提供者和正式名称写入；
- 显式坐标系概念；
- 自动概念归纳、归类、上位形成和树修剪；
- 生产消费者接线、完整工程构建和跨进程验证。
- 统一领域写授权或封装；其它调用方可绕过概念类直接写基础数据集，从而制造多父、环、重复边或非法子域；当前树约束只由本类入口在同一进程互斥下维护。
- 上游新版特征值能力完整闭合；非I64概念的合法性和身份稳定性不强于特征值提供者，其UTF8核验、全零输入/描述、二维与三维压缩层类型区分、跨实例/跨启动复用和原子发布缺口会继续传导到本类。

因此，当前代码是单进程新版概念模型初版，不等于新版特征概念体系已经完成生产切换。

## 17. 验证要求

后续至少验证：

1. 五个先天概念结构、材料、分量顺序、单位和值域准确；
2. 重复初始化在同一数据集内不重复建立；
3. 根链同结构概念仍保持不同类型身份；
4. 同父同结构子概念复用，名称可追加且不参与结构身份；
5. 非严格子值域、材料不一致、单位不一致和重复角色拒绝；
6. I64区间规范化、有限集合排序去重和结构化分量顺序读回一致；
7. 按值查找只遍历指定根链分支；
8. 多个互不从属的同等最具体候选返回冲突；
9. 比较和聚合只消费相容材料；
10. 聚合函数不建立概念节点；
11. 程序重启后恢复同一结构身份；
12. 任一中间失败不公开字段不完整的概念节点。
