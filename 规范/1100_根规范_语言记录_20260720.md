# 1100 根规范 语言记录

编号：1100
日期：20260815
状态：正式根规范

## 1. 根定位

语言记录是保存外来或内部语言材料、结构位置、解析版本和入口关系的语言域对象。它是材料与解析锚点，不是世界事实、需求、任务、方法或因果结论。

## 2. 本项目承载

语言记录使用含直接稳定主键的语言对象节点、语言域类型化原文 / 位置 / 解析版本材料、组成 / 归属 / 顺序关系和索引共同承载。不得因缺少专用语言对象角色而用词条节点或基础信息节点冒充；专用角色仍必须复用节点、稳定句柄、关系和索引架构。

## 3. 事实边界

语言记录可以承载原始文本材料、语言类型、位置、组成关系、解析候选和来源时间。文本、外部分词器给出的词性标签和其它解析标签都只是绑定本次位置与解析版本的语言材料，不直接成为业务语义权威，也不建立持久词性身份。

语言材料触发业务逻辑时，必须经解析、词条 / 概念名称候选或对应领域提交入口，转换为有稳定身份和正式关系证据的项目对象。

项目默认自然语言固定为汉语。默认值只在概念形成之后、调用方未显式指定人类语言时选择正式汉语语言身份，用于接收、词条、名称和表达；它不建立语言记录、语言身份、词条或概念。正式汉语身份尚未由后继语言能力建立并读回时，返回结构化“默认语言能力未形成”，不得把字符串、区域设置、界面语言或外部分词器标签冒充正式身份。

当前不建立正式词性节点、词性 CRUD、持久信息入口类型或固定汉语词性枚举。后继语言理解若需要词性，只能依据本次词出现、未过滤名称候选、候选目标的正式节点类型、句法关系和上下文形成可丢弃、可重算的任务局部判断；该判断不得反写词条、名称关系、概念或目标对象。阶段 18 和零概念启动均不读取、建立或推断这类判断。

## 4. 写入、当前性与禁止

语言领域服务是语言记录和组成关系的写入方；其它领域只读取或提交解析结果。解析更新必须保留来源版本、当前发布和历史版本。

禁止把原文、标题、句子、日志或解析标签直接作为存在身份、状态、需求、任务、方法、因果或结算事实。

## 5. 子规范路由

2300—2330 分别规定文章、段落、自然句和子句的结构层级；2200、2210 规定词条、概念名称关系和词索引。
