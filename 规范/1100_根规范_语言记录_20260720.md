# 1100 根规范 语言记录

编号：1100

状态：正式根规范

## 1. 根定位

语言记录是保存外来或内部语言材料、结构位置、解析版本和入口关系的语言域对象。它是材料与解析锚点，不是世界事实、需求、任务、方法或因果结论。

## 2. 本项目承载

语言记录使用含直接稳定主键的语言对象节点、语言域类型化原文 / 位置 / 解析版本材料、组成 / 归属 / 顺序关系和索引共同承载。不得因缺少专用语言对象角色而用词条节点或基础信息节点冒充；专用角色仍必须复用节点、稳定句柄、关系和索引架构。

## 3. 事实边界

语言记录可以承载原始文本或音频材料、语言类型、文字位置或音频时间范围、组成关系、解析候选和来源时间。语音转写保留原音频、对齐及识别规则版本，修正转写不得覆盖原始材料。文本、外部分词器给出的词性标签和其它解析标签都只是绑定本次位置与解析版本的语言材料，不直接成为业务语义权威，也不建立持久词性身份。

语言材料触发业务逻辑时，必须经解析、词条 / 概念名称候选或对应领域提交入口，转换为有稳定身份和正式关系证据的项目对象。

项目默认自然语言固定为汉语。默认值在调用方请求使用默认语言时选择正式汉语语言身份，用于接收、词条、名称和表达；概念名称绑定仍以后续正式概念为前提；它不建立语言记录、语言身份、词条或概念。正式汉语身份尚未由后继语言能力建立并读回时，返回结构化“默认语言能力未形成”，不得把字符串、区域设置、界面语言或外部分词器标签冒充正式身份。

接收原始语言材料不要求其所指概念已经形成；语言未知或尚未理解时保留材料，不能虚构正式语言、词条或概念。未指定且请求默认、识别失败、显式未知和混合语言按7220分流，后几项不得自动当作汉语。

本接入链不设置词性字段、词性节点、词性 CRUD、持久信息入口类型或固定词性枚举，也不把词性作为理解、命名或表达的必需中间结果。外部标签只作原始解析来源，不反写词条、名称关系、概念或目标对象。句法与上下文关系仍须保留。阶段18和零概念启动不依赖语言或词性。

## 4. 写入、当前性与禁止

语言领域服务是语言记录和组成关系的写入方；其它领域只读取或提交解析结果。解析更新必须保留来源版本、当前发布和历史版本。

禁止把原文、标题、句子、日志或解析标签直接作为存在身份、状态、需求、任务、方法、因果或结算事实。

## 5. 子规范路由

2300—2330分别规定文章、段落、自然句和子句；2200、2210规定词条和名称关系；7220统一规定多语种/读音衔接、文字与语音接入、命名学习和表达输出。
