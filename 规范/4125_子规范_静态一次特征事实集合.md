# 4125 子规范 静态一次特征事实集合

编号：4125

日期：20260905

版本：v0.1

状态：正式子规范

直接上级规范：1120、1130。

直接依赖规范：4015、4040、4120、4230。

相关边界规范：4150、4160、4180、2220。

## 1. 定位

静态一次特征事实集合是在特征实例结构范围内，对若干已经发布的一次特征事实节点形成的可追溯集合事实。集合身份表达“这一组事实”，例如一个正面轮廓事实集合或一个侧面轮廓事实集合；名称只是上层显示或召回材料，不建立类别、概念或归类结论。

集合事实不是原始传感值，也不是由成员计算出的派生值。它只保存成员关系，因而仍属于一次特征实例事实结构。若消费者对成员执行比较、差值、方向、变化率、评分或其它计算，结果必须进入二次特征或上层治理结果。

## 2. 身份与版本

每个集合具有一个稳定、长期可追溯的集合身份 `S`。每次有效成员快照具有一个不可变版本身份 `V`。当前事实由 `S -> V` 的唯一当前版本关系成立；首次创建同时发布 `S`、`V`、唯一当前版本关系和完整成员关系。

成员修改不得原地增删关系。换代必须在特征 owner 的一个写集中：验证调用方提交的旧当前版本；建立新版本及完整新成员组；建立 `新版本 -> 旧版本` 的唯一前版本关系；建立新的当前版本关系；退出旧当前版本关系与旧版本的当前成员关系。旧版本节点、已退出成员关系及前版本链保留历史。

集合退出必须在一个写集中退出集合身份、其当前版本关系和该版本全部当前成员关系；版本节点、历史成员关系和前版本链保留。已退出集合不得复活或复用身份。

## 3. 成员合同

一个版本至少包含一个成员，成员数不得超过 provider 构造时冻结的非零预算。每项固定包含：非零连续顺序 `1..N`、非零成员角色、当前有效的一次特征事实节点身份。

同一版本不得重复成员身份；成员角色可以重复，除非上层定义另有业务约束。顺序与角色只用于稳定结构、完整读回和复现实例布局，不表示排名、分类概率或概念层级。

写前必须在同一 `G0` 经当前特征公开读取证明每个成员为完整、当前、普通一次特征事实。二次 / 更高阶派生定义、集合身份、集合版本、裸 L1 节点、已退出特征和未知结构都不能充当成员。成员关系冻结提交时的特征节点身份；成员以后退出不改写历史集合版本，新的当前集合必须显式换代。

## 4. owner 与结构关系

集合身份、版本节点、当前版本关系、成员关系和前版本关系全部由现有特征实例 owner 独占写入；不得新增 owner、事实仓、类别节点族或概念节点族。集合与普通有值特征共享 owner，不等于共享普通 `特征类结点` 值式投影：集合版本没有原始值属性槽，必须由专用强类型 DTO 和入口读取。

结构类型由 provider 构造时注入并验证为四个互异的当前关系类型：集合族归属、当前版本、成员、前版本。普通调用请求不得选择关系类型、owner、本地键或稳定编码。

集合族归属关系从集合身份与版本节点分别指向同一个 provider 私有集合锚点，并以互异角色区分二者；它只证明本服务创建的集合结构，不是类别、概念或成员关系。

## 5. 读取与追溯

公开读取至少包括：按集合身份与 `G0` 读取完整当前版本；按集合身份、`Gread` 与显式 `H <= Gread` 读取 H 截止的完整版本；按成员特征身份与 `G0` 反向读取全部当前集合；按版本身份与截止读取版本、前版本及完整成员关系。

所有成功结果必须在同一非零截止闭合集合族归属、版本关系、成员端点、角色 / 顺序、生命周期与唯一性。当前集合组按集合身份稳定编码升序，成员按顺序再按关系身份稳定排序。反向查询必须具有调用方提交的非零数量预算；超预算返回具名失败，不截断成成功。

“历史”只表示调用方给定 H 的完整截止投影或给定版本身份的完整追溯，不承诺枚举无限时间线。L1 缺少完整历史集合枚举时不得从当前容器、日志或缓存拼造时间线。

## 6. 幂等、失败与发布未知

创建、换代和退出各自接受非零幂等身份。精确相同请求重放返回首次正式结果且零新代次；同键异义返回幂等冲突。期望事实代次漂移、旧版本不是唯一当前版本、成员不完整、重复成员、结构闭包不唯一、引用冲突、数量超限和资源失败必须分账。

写集提交前失败为零写。L1 已确认成功或精确重复后，专用正式读回失败不得回滚、补偿删除或返回成功；结果为 `已可能发布`，只回显原幂等身份和可能的首次提交代次，调用方以原完整请求原键重放收束。

## 7. 明确禁止

- 不建立分类体系、类别定义、样本归属、互斥 / 多标签判断、置信度、阈值、训练记录或算法见证；
- 不调用 4180 形状距离或任何分类算法，不解析轮廓材料；
- 不 import、调用、强转或复制旧 `服务.L2*`；
- 不复用 `特征类派生定义事实`、不增加实际阶次、不被 `二次特征类` 当作行动方向；
- 不依赖概念空间或世界事实支持概念关系；
- 不把非原子的先删后加伪装成换代，不用补偿删除冒充事务回滚。

## 8. 完成声明边界

实现专用 DTO 和数据操作只证明事实集合 provider 候选成立。未完成构建、运行、生产装配、真实消费者和独立验收时，不得声明事实集合能力在普通应用可用；更不得声明轮廓识别、分类、概念形成或二次特征推理已经完成。
