# 4140 子规范 枚举型实例特征值合法来源

编号：4140
日期：20261105
版本：v1.0
状态：正式子规范

直接上级规范：1130。

直接依赖规范：1120、1160、4110。

相关边界规范：2100、4120、4160、5170、5260、5350。

## 1. 定位

本规范区分枚举值域定义和枚举实例值生产，规定实例特征F取枚举准确值时必须有合法生产者和证据。枚举值是内联I64点值，不经过2100特征值节点。

## 2. 两层结构

1. 枚举值域是抽象特征定义的一部分（1120、4120），声明允许的I64点值及含义；建立值域不需要为每个值创建本能方法。
2. 枚举具体值由合法生产者写入实例特征F（1130、4110），其值变化由1160生成状态；需要来源时按相应生产流程关联动作动态或规则身份。
3. 值域初始化不得被误写成实例状态产生。

## 3. 合法生产者

| 枚举事实类型 | 合法生产者 |
| --- | --- |
| 结构或生命周期状态 | 对应领域创建、迁移或提交入口 |
| 直接观察/检查结果 | 具有明确输入输出的观察、检查或外设方法 |
| 综合判断结果 | 已登记输入特征族和收束规则的判断方法/服务（4160） |
| 数值比较归类 | 特征比较与枚举映射规则 |
| 外部反馈状态 | 外部材料承接、验证和世界事实提交链 |
| 初始化事实 | 具名初始化入口及初始化来源证据 |

线程内部局部标记若不进入机器事实可留在局部结构；一旦参与需求、因果、调度或结算，就必须进入上述正式生产链。

## 4. 专用方法判定

运行时必须通过观察、控制、验证或综合判断才能成立的枚举值，需要具名方法或判断服务。由生命周期、结构初始化或已有规则直接决定的枚举，不为每个值另建专用本能方法。

方法状态、任务状态等由各自领域统一提交，不允许任意线程裸写。

枚举型需求目标的合法性由5170规定；判断型枚举结果的持久化边界由4160规定。

## 5. 禁止事项

- 禁止由说明文字、日志、UI 或随手赋值产生枚举事实。
- 禁止无动作动态、来源动态或规则证据的枚举修改。
- 禁止把多个层级状态压成一个过重枚举。
- 禁止为结构型枚举每值盲目建立本能方法。
