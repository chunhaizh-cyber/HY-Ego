## 1. 并入 4110

| 原出处 | 条款 |
| --- | --- |
| 1130 v2.5 §3 | 准确值载体为`std::variant<std::int64_t, 稳定编码>`（不据此限制逻辑引用类别）。 |
| 1130 §5 | 公开入口`稳定编码 建立或取得特征(稳定编码 持有节点, 稳定编码 特征概念节点, std::optional<新特征准确值> 实际值 = std::nullopt) noexcept;`。流程：核验持有节点和传入概念→查找持有者下实例（新口径按特征类型根查找）→恰一则完整读回并复用，多项则拒绝→可选原始材料按物理类型核验，直接信息引用按1130 §3.1、§3.2核验→提供实际值时在同一类型根下查找包含该值的最具体概念，唯一找到则采用，未找到或冲突则采用类型根→建立节点类型、概念引用、可选单位和持有关系→增加所选概念的当前实例引用数量→返回实例节点。该函数不写实际值，建立后当前值、标准值、历史和聚合均为空。 |
| 1130 §6 | 公开入口`新特征值添加结果 添加特征值(稳定编码 特征节点, const 新特征准确值& 新值) noexcept;`。流程：完整读回实例和当前概念→原始材料核验物理类型，直接信息引用核验并保护目标→用概念比较规则查找等价历史值→已有值增加命中次数，新值建立命中记录→与当前值不等时更新当前值→首个值成为标准值→候选命中次数严格超过现标准值时替换，并列不替换→尝试归组子特征→用全部历史值执行聚合规则→发布实例历史聚合值域→同步正式所属概念→返回结构化结果。 |
| 1130 §11 | 公开能力：`初始化`、`建立或取得特征`、`查询特征`、`获取特征`、`是特征节点`、`添加特征值`、`比较特征值`、`比较特征`、`比较特征概念值域关系`、`计算特征概念值域重叠度`、`计算特征概念材料接近度`。不提供主动删除、变更持有者、删除历史值或直接写聚合域的入口。 |
| 1130 §12 | 添加值结果区分：已完成、无变化、入口拒绝、特征不存在、概念不存在、材料类型不相容、结构不一致、值已更新但聚合未完成、资源失败；结果同时报告当前值、历史集合、命中次数、标准值是否变化，并可返回接收子特征和聚合结果。“值已更新但聚合未完成”只作为基础数据集组合原子发布实现前的过渡状态；调用方须保留原实例并允许同值重试，不重新分配实例。 |

## 2. 并入 4115

| 原出处 | 条款 |

| 1130 §7 | 实例历史聚合值域由完整历史不同值重新计算，不使用当前概念值域冒充实例实际历史。归组：初始相似度阈值固定为`9000`，当前不动态调整；I64标量按单维相对相似度并允许连续连接判断，其它支持类型按材料接近度判断；只有一个稳定区间时可只保留父实例；出现两个及以上差异区间时建立或复用相应子概念和子实例特征；新值同时连接多个区间时选择与各区间标准值相似度最高者，并列按子特征稳定编码确定性选择；新值不得触发多个已有区间自动合并；每个归组子特征保存成员历史记录引用、当前值、标准值和自身历史聚合值域。归组和概念同步是添加值调用链的一部分，不是永久完成标记。 |
