## 条款 1：世界信息建立流程（替换“先概念后实例”）

- 原出处：2220 v1.28 §6 中的世界树建点流程：

```text
完整查询命中 -> 取得并核验该概念
完整查询确认不存在 -> 按建点材料中的完整定义创建概念并读回
取得已发布概念身份 -> 带着身份建立世界信息节点、挂靠及引用 -> 完整读回
```

以及“存在建点的完整定义必须覆盖本次已知特征值域和已知子存在概念……首次比较必须核对特征类型集合完全一致……选择唯一最具体候选”。

- 处理：上述流程按本轮用户裁决**退出**，4200 中与之相同或依赖它的条款须删除或改写。
- 建议并入位置：4200 世界树上层应用中“实例建立”章节。

替换为：

1. 根概念先天建立，故“先有概念、后有实例”在根这一层天然成立。
2. 普通存在实例化时可以零特征，直接引用存在根；世界树服务不在建立实例前做完整概念匹配。
3. 存在添加特征后，由概念 owner 派生其专属存在概念并挂在存在根下；之后特征变化原地同步投影。
4. 与既有中间层概念的匹配和归类属于识别或归纳步骤（7110），不是建立实例的前提；中间层概念只在专属概念增多后经明确归纳需要派生。
5. 概念成功而世界操作失败时保留合法概念并报告实际阶段；重试先查询并复用，不自动删除可能共享的概念。

- 同步影响：4230 中“L2 接收已有概念身份”的边界须按此复核。
