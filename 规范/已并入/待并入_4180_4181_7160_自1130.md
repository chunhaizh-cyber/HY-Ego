## 1. 并入 4180、4181

| 原出处 | 条款 |
| --- | --- |
| 1130 v2.5 §9.1 | 特征owner分别提供`比较特征值`与`比较特征`。I64标量返回饱和有向差值，溢出分别饱和为`INT64_MAX`或`INT64_MIN`；需要相似度的算法返回`0～10000`；没有适用量化算法时返回`-1`或规则不支持，不得把无法比较伪装成完全不同。实例比较材料选择顺序：双当前准确值→一方当前准确值与另一方历史聚合值域→双历史聚合值域→仅剩概念时只报告概念关系，不产生实例数值相似度。 |
| 1130 §9.2 | 已有材料算法：I64标量饱和有向差值；结构化I64先尝试最具体概念关系，再按逐维相对比例形成相似度兜底；RGB按三个`0～255`通道形成相似度；二维轮廓从原始二值图生成各分辨率灰度层由粗到细比较，任一层低于50%立即返回0，否则返回最细共同层相似度；三维体素生成XY、XZ、YZ三个正交轮廓投影分别比较后等权汇总，不直接比较体素块；UTF-8字符串完整字节相等返回`10000`、不等返回`0`，不做模糊、语义或Unicode规范化比较；其它没有专用接近算法的不同材料返回规则不支持。 |
| 1130 §9.3 | `比较特征概念值域关系`、`计算特征概念值域重叠度`、`计算特征概念材料接近度`分别表达集合关系、值域重叠比例和材料内容接近程度，不能互相替代；只处理同一特征类型根内的单特征概念，不处理存在概念或其它多特征组合概念。 |

## 2. 并入 7160

| 原出处 | 条款 |
| --- | --- |
| 1130 §8 | 实例所属概念自动同步：历史聚合值域形成后，查找当前类型根下能包含完整历史域的最具体概念；有准确概念时复用并改挂；当前概念包含历史域但没有准确下位时建立严格子概念；历史域扩大时允许更新当前概念值域，必要时先调整上位位置；根概念不能包含实际历史域时允许扩展同表示的类型根再建立或复用准确概念；当前概念与上位等值时改挂上位；越过直接上位时重挂到最近合法祖先，无合法祖先先扩展类型根；概念变化后处理同父兄弟：等值时复用，包含时调整上下位，相交或分离时不自动合并。实例改挂顺序“新概念引用数加一→修改实例概念字段→原概念引用数减一”。 |
| 1130 §9.3 | H需求单D采用7160第5.1节独立需求身份精确规则，当前/历史均为D引用，新增需求发生由正式S读取，不从D判等或数量推导；旧服务对象需求集合及仍具独立集合合同的类型保留原7160第9.1节算法供具名调用/迁移（同集10000、异集0、条件包含1/0，非有向差值），不套到当前H需求FT。 |
| 1130 §9.3 末段 | 存在引用集合按7160第5.2节采用独立存在身份核验与判等；自我交互对象F按持有者与类型根定位唯一直接特征，多项或损坏不得任选或当作未建立；成员身份合法不证明人类、当前连接、服务关系或授权；集合提供者不得把旧单值服务对象或网页消息列表自动当作已连接成员；初始化只写合法初始空集，不预造变化动态或业务动作。U64成员须有正式引用保护，覆盖当前、历史、标准、域及状态保留的完整材料；成员从当前值移除不等于历史引用退出。 |
