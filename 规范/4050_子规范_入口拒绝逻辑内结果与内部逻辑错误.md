# 4050 子规范 入口拒绝、逻辑内结果与内部不一致

编号：4050
日期：20260802
状态：正式子规范

直接上级规范：0050。

相关边界规范：4010—4070。

## 1. 定位

本规范统一成功、协议内非成功、资源失败、提交未知和内部不一致的分类。结果必须绑定请求身份、事实截止、版本和副作用边界。

## 2. 写前拒绝

无效身份、未知类型、权限不足、值域越界、错归属、版本漂移、关系前置不满足和材料校验失败必须在第一笔内存候选写入前拒绝，并保证内存已发布代次、当前性和运行期发布证据不变。

## 3. 逻辑内结果

未找到、已退役、候选为空、目标已满足、合法等待、显式未实现、精确重复和业务前置不满足属于协议允许结果。必须使用具名强类型值返回，不得压成裸 `bool`、空句柄或异常文本。

## 4. 资源与提交结果

SQL / 文件 / 环境不可用属于外部资源失败，并明确是否可重试。内存代次发布结果未知和持久证据写入结果未知是两个独立类别：前者只能按原幂等身份和发布见证回读权威终态，后者不得改变内存事实，只能按原持久请求收敛。

## 5. 内部不一致

前置通过后发生身份复义、类型合同冲突、关系基数矛盾、半结构可见、提交后读回不一致、证据集合与计数不一致或同一事实多当前，属于内部不一致。

内部不一致必须停止依赖路径，保留结构化证据并交 4070 审计恢复；不得包装成普通业务拒绝、等待、学习缺口或幂等成功。

## 6. 结果最小字段

每个公开结果至少明确：结果类别、请求 / 幂等身份、适用内存代次或事实截止、相关稳定身份与版本、是否形成内存权威发布、权威代次 / 发布见证、持久证据状态、材料是否被引用、可重试性和后继动作。无适用字段必须显式“不适用”，不得使用零值冒充。

## 7. 禁止事项

日志、弹窗、字符串、缓存命中、索引命中和函数异常不能单独承担结果语义，也不能修复事实。
