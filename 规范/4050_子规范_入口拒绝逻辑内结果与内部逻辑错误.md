# 4050 子规范 入口拒绝、逻辑内结果与内部不一致

编号：4050
日期：20260812
状态：正式子规范

直接上级规范：0050。

相关边界规范：4010—4070。

## 1. 定位

本规范统一成功、协议内非成功、资源失败、提交未知和内部不一致的分类。结果按公开操作所需最小字段绑定请求、事实截止、版本和副作用边界，不要求无关管理字段占位。

## 2. 写前拒绝

无效身份、未知类型、版本漂移、关系前置不满足和中性材料形状校验失败必须在第一笔内存候选写入前拒绝，并保证内存已发布代次和当前性不变。业务权限、业务值域与业务归属由 L5 之外业务层在调用 L1—L5 数据服务前裁决；任一数据层不得通过业务操作标签或领域见证重复裁决。

owner-scoped v2 中，非法合同版本、零身份、坏请求形状或 v1 触碰独占 owner 事实 / 类型固定 `入口拒绝`。端口失效或跨实例、owner 已退出、第二活动端口、writer owner 与关系类型 / 所属节点 / 属性类型 / 新值 / 退出事实 owner 不符固定 `许可拒绝`。两者都必须在第一笔候选前返回、零普通事实变化；不能伪装成未找到、精确重复、资源失败或引用冲突。

## 3. 逻辑内结果

未找到、已退役、候选为空、目标已满足、合法等待、显式未实现、精确重复和结构前置不满足属于协议允许结果。必须使用具名强类型值返回，不得压成裸 `bool`、空句柄或异常文本。

`L1所有者范围CRUD合同版本=2` 至少分账：`成功`、`精确重复`、`已读取`、`入口拒绝`、`许可拒绝`、`未找到`、`已退出`、`属性未设置`、`事实代次漂移`、`幂等冲突`、`引用冲突`、`资源失败`、`内部不一致`。目标编码未占用 / 已退出不得覆盖已经可判定的 owner 不符；owner 正确但外部当前引用未闭合才进入引用冲突。

## 4. 资源与提交结果

SQL / 文件 / 环境不可用属于外部资源失败，并明确是否可重试。内存代次发布结果未知和持久证据写入结果未知是两个独立类别：前者只能按原幂等身份和发布见证回读权威终态，后者不得改变内存事实，只能按原持久请求收敛。

## 5. 内部不一致

前置通过后发生身份复义、类型合同冲突、关系基数矛盾、半结构可见、提交后读回不一致、证据集合与计数不一致或同一事实多当前，属于内部不一致。

端口前置已通过后 owner 事实缺失或复义、同一事实 owner 读回变化、owner 生命周期覆盖不了事实创建、活动端口计数矛盾、owner 与普通事实半发布或恢复后 owner 域不一致，同样属于内部不一致；不得降级成许可拒绝以掩盖仓库损坏。

内部不一致必须停止依赖路径，保留结构化证据并交 4070 审计恢复；不得包装成普通业务拒绝、等待、学习缺口或幂等成功。

## 6. 结果最小字段

普通 CRUD 结果只携带结果类别、合同版本、适用的请求 / 幂等身份、相关稳定编码、事实代次、是否形成内存权威发布及中性可重试边界；创建 / 更新成功返回确定性稳定编码映射，读取返回完整中性事实，退出成功返回退出事实代次。owner-scoped v2 写结果另回显端口隐式绑定的 owner 身份；建立 / 重入 / 退出结果回显值式 owner 事实，只有成功交付可与非 DTO 的 move-only 端口成对返回。持久证据状态、材料引用、恢复批次、发布见证、端口租约 / nonce 和业务后继不得作为普通 CRUD 固定字段；业务结果解释由 L5 之外业务层完成。

## 7. 禁止事项

日志、弹窗、字符串、缓存命中、索引命中和函数异常不能单独承担结果语义，也不能修复事实。生产程序可以保留具名人读日志观察公开 CRUD 的调用类别和结构化状态，但日志不是机器事实、验收结论或精确读回替代品。
