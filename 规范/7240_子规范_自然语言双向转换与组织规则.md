## 1. 输入、输出和内部治理边界

语言知识有两条使用方向：结构化表达目标→描述结构→语言材料，以及语言材料→描述结构匹配→候选含义。两者共享类型化含义、角色约束和组合规则；解析搜索与输出取材不是同一个算法。

代词两向使用共享1110的概念定义和7230的类型化约束；输入索引、输出索引与焦点缓存只帮助召回，不另存一套代词含义。自然语言场景承载描述/规则/问题及指代实例；现实场景中的事实仍由对应领域裁决。调用期解释与按请求保存语言场景是两个步骤，后者也不授权写入被描述的现实对象。

自然语言解析、表达规划、名称选择、指代、匹配、规则学习是DATA外内部治理功能，不因是函数就全部注册为现实动作方法。外部发言、发送消息、设备播放等实际动作按0050/5360的调用与授权边界执行；语言生成器不直接发送或调用文中提及的方法。

本规范定义有限结构解释器，不定义任意中文理解能力。支持集合以可读的具名知识定义和已实现的语义操作为准；未知构式返回未理解/部分理解，不能交给无约束脚本执行。

## 2. 可执行解释的有限含义结构

### 2.1 引用、值和作用域

```text
含义项
  局部项编号
  操作种类
  具名角色参数组
  作用域引用

参数 = 已绑定强类型引用 | 规则角色变量 | 查询变量 | 明确未知
作用域 = 普通陈述 | 提问范围 | 请求范围 | 否定 | 条件假设 | 引述
```

每个作用域包含子项或引用已定义父域，无环且局部编号唯一。普通陈述仍是“说话者的陈述”，不是世界事实标记。否定必须指定否定哪个项；“没有观察到”不能归并为“确定没有”。条件假设不发布为现实，引用保留原说话者与材料范围。

查询变量标明待求的角色/内容；明确未知表示已确认此项尚无知识；规则变量在具名规则作用域内受约束并被共享使用。三者可作为自然语言场景内规则、查询或描述信息的内容，不取得虚构现实存在身份。变量以所属规则/查询和局部编号定位；复用规则必须重新映射局部变量，不能跨作用域串用。值使用原领域类型、单位、值表示与准确值合同，不能用字符串“红”“高”填充缺失准确值。

### 2.2 首版语义操作闭集

下表是含义项的参数签名，不是DATA新关系类型表。正式写入必须由相应对象应用/owner裁决，不能将操作种类数值直接写成L1关系。

| 操作 | 必需角色与含义 |
| --- | --- |
| 概念归类 | 对象或下位概念、目标概念；实例归类与概念上下位由参数种类区分 |
| 对象指认 | 两个对象指称候选；只表达同一性主张，不合并稳定身份 |
| 特征描述 | 主体E、正式FT、准确值或特征概念条件；准确赋值与概念归类互斥标记 |
| 组成描述 | 整体E、部分E；不能把所有“有”解释为物理组成 |
| 场景包含 | 场景C、成员E；直接归属与递归包含明确区分 |
| 关系描述 | 有序A/B、具名关系概念及角色绑定；二次结果仅按现行临时计算使用 |
| 状态描述 | 场景C、主体E、状态内容（FT、准确值、时间）或已有完整C/E/S引用 |
| 变化描述 | 主体E、变化内容、发生范围；已有动态引用或带缺项的变化主张，不伪造端点 |
| 因果描述 | 已有因果/因果链引用，或条件/动作/结果的语言主张；两种来源不可混同 |
| 需求描述 | 已有需求引用及目标投影，或提出者、目标主体、期望特征/状态、作用范围的提议 |
| 任务描述 | 已有任务引用、关联需求目标、所查询/陈述的阶段或实际过程；不得虚构来源需求 |
| 方法描述 | 已有方法引用、可改变FT、所描述的条件/预期结果；未登记文本方法只是学习材料 |
| 能力描述 | 主体A、方法M、预期改变及适用条件、能力主张或当前可行性范围；输出肯定能力须有对应应用裁决，函数存在不能证明A能使用 |
| 信息请求 | 受询者（可由语境给出）、被询含义及查询变量/确认范围 |
| 条件联系 | 前件含义X、后件含义Y、共享角色映射；方向固定为X成立时主张Y，不得交换前后件或确认现实中X/Y成立 |
| 量化限定 | 量化方式（全称/存在/任指）、变量、具名限制域、谓词子含义及绑定作用域；数量限制另带类型化值/值域，不把理解量化规则等同于枚举或证明全部成员 |
| 群体作用 | 限定群体、谓词及角色映射、整体/逐项/具名互指规则；实际关系覆盖要求由所用规则规定，整体谓词不自动分配到每个成员 |
| 行动请求 | 受请求者、期望目标、限制；只是请求内容，不是执行命令对象 |
| 并列/顺序组合 | 子含义有序组、关系种类；叙述顺序与事件时间先后分开 |
| 语言回应 | 被回应材料/含义、回应方式（回答/确认所指/赞同主张/纠正/拒绝请求）及相关内容 |

“是”至少可能对应归类或指认，“有”至少可能对应特征、组成或场景包含，“会”可能是能力或未来预期。必须由整个结构及强类型参数判断；没有唯一解释就返回候选，不建立一词一关系永久表。

以上操作用句法角色和强类型数据区分含义，不新增持久词性/信息入口类型。它们是受支持操作的有限集合，不是代词八分类或自然语言用法的永久全集。所有扩展必须具名增加参数签名、匹配与求值合同；学习算法只能组合已有操作，不能从新词面发明可运行操作。定义已正式化而对应解释器尚未实现时，返回能力缺失，不能宣称已有运行支持。

### 2.3 条件和取材的有限集合

条件只允许：角色已绑定、角色类别匹配、概念约束匹配、引用相同/不同、字段已知、字段精确相等、正式值比较、明确存在的关系、集合数量约束，以及这些项的AND/OR/NOT。每项求值为成立、不成立、未知或技术失败；NOT未知仍为未知，不把技术失败当不成立。

AND/OR子项均为非空有序组，先完整求值各项；不以逻辑短路隐藏技术失败或未覆盖范围。任一子项技术失败，整体返回技术失败并保留实际失败项；预算到限返回预算未完成，不继续计算逻辑结论。在全部子项无技术失败时：AND含不成立即不成立，全成立才成立，其余未知；OR含成立即成立，全不成立才不成立，其余未知。NOT交换成立/不成立，未知保持，技术失败原样传播。目标的适用条件组为空表示无附加条件，不用空AND/OR猜默认值。

正式值比较由所属特征比较应用返回结果；不在语言规则内重写坐标/颜色/轮廓算法。条件求值只读，不修改概念、特征或知识。

取材只允许以下有界算子：

1. 绑定角色：取得调用方提供并核验的强类型输入。
2. 读具名字段：由对象公开内容读取投影选取签名允许的字段；字段缺失不得反射猜取。
3. 枚举具名关系：经相应只读服务取得完整成员、事件或组成，保留来源、顺序和未覆盖范围。
4. 过滤、按具名字段分组：按上述条件筛选；未知项另列，不丢弃后伪称完整。
5. 排序：源材料顺序、正式执行步骤顺序、可比较事件时间、调用方明确的叙述顺序。时间相等保持无先后，技术身份只用于稳定展示，不推导因果。
6. 投影与子目标：从已有字段/关系形成子含义，交子规则表达。

不得在知识中保存SQL、任意字段名路径、脚本、函数地址或网络调用。每个具名字段/关系选择器必须有静态的输入类型、输出类型、公开读取提供者和失败映射；提供者未实现就返回能力缺失，不静默返回空集合。

### 2.4 指代、量化与群体组合

1. 定指表达按定义、修饰和作用域求唯一对象或范围明确的集合；缺少指示/角色材料是指代未决，不自动转换成一个未知存在。焦点只提供候选或可核对依据，不能覆盖类型、限定词和来源。
2. 待求表达先建立有类型、有作用域的变量，再由整句确定是否构成信息请求。“我不知道谁负责”中的待求内容不自动变为向听者提问；“谁先到谁先选”在条件和结果中使用同一变量。所属构式缺少知识时返回缺规则，不因识别出“谁”就猜整句含义。
3. 量化限定的输入须给出变量、限制域、量化方式、谓词和绑定域。匹配先核对这些项并统一变量；缺项保留候选。解释完整时可保存规则而不枚举实例；实际对已知有限域求值才逐项代入，并按2.3先完成本次必要求值，工程失败或未完成不得被逻辑结论掩盖。在此前提下，全称有反例即不成立，存在有见证即成立；肯定全称或否定存在必须有完整域和全部必要结果。空域的全称成立、存在不成立，二者都不宣称域内有成员；未知成员、未知条件和工程失败不得被当作完整枚举。
4. 任指表示规则对满足限制的任意选取都适用，不是随便选一个候选便证明全部成立。开放域或未来成员可以参与规则描述，但缺少规则级证明时不能仅凭目前有限样本肯定全域。求值遵守2.3的技术失败独立传播和未完成边界；理解规则不要求现在完成求值。
5. 群体作用先核验集合范围与谓词输入类型：整体把群体作为共同参与角色；逐项才将谓词应用于每个成员；互指按具名构式规定参与方向、所需覆盖和自指限制。所有必需映射完成才解释成功，关系事实另由输入证据决定。没有具名互指规则不得推测边集合。
6. “所有学生一起搬桌子”中，全称限定群体成员，“一起”使搬桌子的参与方式为整体；不能推出每个人单独搬桌子。“三个人互相传球”也不默认每两人双向均有传球事实。语言含义成立和实际发生分开。
7. “自己”的绑定对象取所属构式允许的先行角色；多个合法先行项保留歧义。“我们”须包含本次说话者，是否包含受话者另按用法和语境判断；“咱们”也按采用定义核验，不能将两词设为全场景互斥的包含/排除开关。

## 3. 输出操作

### 3.1 请求与结果

```text
输出请求
  结构化表达目标
  角色绑定与来源引用组
  语言选择
  本次交互上下文
  允许省略/详略要求
  有界资源预算

输出结果
  阶段结果与实际完成范围
  文本材料或调用期文本
  本次表达树与含义对齐
  使用的知识/名称固定定义
  未表达项及原因
```

完整成功要求全部必需目标表达且来源、角色、否定、时间、条件、引述和准确性保持。允许的可选省略须回显；预算不足不能截断成完整句/篇成功。送达结果不在生成结果中假定，必须独立取得实际通道结果。

### 3.2 算法

1. 固定表达目标与本次采用的当前可读材料；读取输入对象内容，分清现实事实、语言场景中的主张、预期、规则、提问与请求。需求/任务/方法直接从其正式对象取得可表达投影，不要求三类概念。
2. 按表达目的、含义操作、角色类型和语言从知识索引召回；精确读回全部候选定义及采用范围，匹配目标含义并求值条件。索引只召回。
3. 先排除不适用规则；多个可用规则若表达等价，按明确的详略要求、覆盖完整性、适用范围及固定定义身份稳定排序选择。排序只决定表达形式，不裁决真实含义；候选含义不同就返回歧义/缺材。
4. 基础结构绑定角色并选择名称/明确对象描述/合法指代；选择代词时，以目标、当前说话者/受话者、表达目的和参照条件求值同一份指代定义，形成完整表达及出现关联。内容组织结构按取材规则形成子表达目标并递归展开。请求详述任务时读取真实执行材料，不能用方法预测填补实际步骤。
5. 确定性实例指认须让接收方能够从角色、有效指示、前文或共同知识恢复同一目标；不能只凭系统自身焦点判断。代词不满足时使用已成立专名或更充分描述，仍不足就返回缺少指认材料；“桌子”等类名不能唯一定位多个同类实例。用于提问、条件或量化规则的变量则须恢复相同类型、限制、绑定域和共享关系，不要求已有具体答案。
6. 自底向上生成句段篇及范围对齐；检查必需含义覆盖、否定/条件/引语作用域、角色一致与来源，不添加输入中不存在的事件、原因或结果。
7. 返回生成结果。留存时作为新的语言材料经语言服务保存；发送/显示/播放由已授权通道执行并保留其实际结果。生成成功≠发送成功≠对方理解。

换说话者时重新依据角色选择“我/你”等表达，不交换所述参与者身份；引语内按引语角色表达，不能直接套用外层说话者。“杯子A/杯子B”等可恢复专名与代词可以并用；改用专名不改变目标，也不要求删除已有指代实例。

## 4. 输入操作

### 4.1 请求与结果

输入请求包含固定材料及范围、语言选择、当前交互上下文、所允许的只读对象查询范围和资源预算。结果返回已覆盖范围、候选含义组、角色绑定/未决组、所用知识及来源对齐、可供后续应用处理的类型化提议，不包含语言器自授的世界或任务写入资格。

“理解成功”只指在当前受支持规则及完整查找范围内形成唯一、角色一致的含义；完整候选数不足以证明世界为真。唯一含义可以含合法查询/规则变量，尚未获得答案不等于未理解。确定性指认仍有多候选则保持待解；解析技术成功但含义多项，结果仍为多义待解。

### 4.2 算法

1. 保留原始材料并确定语言；先形成句段边界候选，标点只是边界线索，引号内标点不自动截断外层意义。
2. 通过已知词条/概念名称匹配形成词序候选；未知处可调用具名外部分词服务取得候选，或保留未知范围。外部服务是可选辅助，不取得词义裁决或执行权。分词不强制产出词性。
3. 召回结构规则并进行有界匹配：每个状态至少包含规则定义、结构项位置、原文位置、角色环境与作用域。固定词项匹配词条/标点，角色项匹配合法范围与类型候选，子规则项递归匹配；缓存相同状态避免重复搜索，不以首个命中结束所有歧义检查。
4. 按7200/7210读回词条名称全部候选及目标强类型；结构词可由知识固定词项识别，不强制每个“是、有、因为”都命中世界概念。
5. 按完整指代表达取得/组合1110定义与7230特征约束，将“这个杯子”“那本书”分别形成调用期场景实例材料。先核对是否能复用同一作用域内兼容的已有实例，再寻找强类型目标或保留合法变量/未决候选；后续“它”也须核验本次约束。同目标不强制合并实例，同词面不强制指向同一目标；泛指类名不强制实例化。
6. 结合场景、参与者、指示依据、修饰、数量和来源消歧，核对比较方向、时间、否定、条件、量化和引述范围。近远取向只能按已采用中心/规则解释，不能猜固定距离或采用焦点首项。句法和指代可按新约束再次收敛，不能采用不可回退的一次流水。
7. 用组织知识组成句段篇含义；保留事件顺序与叙述顺序。段落可能混合陈述、提问和请求，不按首句目的覆盖全部子句。
8. 对已理解项形成对应查询、规则或领域提议；定指未决、缺数据或预算未完成项保留来源和缺口。按保存请求可将语言场景、实例和采用解释交所属结构服务发布与读回，不先造现实节点再纠错；世界、需求、任务、方法仍由其应用入口处理。需要新增可复用概念定义时另交概念业务，不能在只读查询中写概念。

## 5. 提议转换与事实边界

| 语言所得材料 | 允许的后继 | 禁止的捷径 |
| --- | --- | --- |
| 指代、规则或查询变量 | 在自然语言场景中保存带作用域的实例/内容，合法目标经强类型引用关联 | 未绑定就虚构现实存在，或用活动目标槽改写此前出现 |
| 新词/概念说明 | 学习提议；按概念合同形成后再命名 | 词面或词性直接造概念，空定义冒充通用根 |
| 对象/特征/关系陈述 | 查找已有对象或交世界应用裁决来源与创建/更新 | 自动复制实例、用概念区间补准确值、写L1关系 |
| 状态陈述 | 同时交付C、E及FT/准确值/时间材料；不足就明确未完成 | 用self当前场景/时钟补未知C或事件时间 |
| 动态叙述 | 已有动态定位，或变化候选交动态应用验证合法端点/组成 | “走了”凭空生成两个状态；从叙述次序确认相邻 |
| 关系/比较 | 按现行RC/比较合同求值或形成关系主张 | 把临时二次值持久化绕过C038 |
| 因果句 | 已有因果引用或学习主张；按因果业务筛选证据 | “因为…所以…”一句话确认客观因果 |
| 外来需求/指令 | 服务/目标提议送self；处于父任务内的子目标按既有承接链 | 语言器确认需求、任务manager越权产生需求 |
| 任务过程 | 只读已有记录或形成带来源叙述 | 把叙述动作当成已执行，把“完成”词当正式任务完成 |
| 方法说明 | 与现有登记能力对齐后交方法学习治理 | 文本变成函数、预测当实际、句法顺序直接执行 |

正式“有类型未知概念”及原身份补全在2220/7140没有专属合同前，只能保留明确类型依据与学习请求并返回`概念形成合同缺失`。这与“明确未知值”不同，不能把语言变量当正式未知概念；该分支不阻断已有概念的输入、输出或规则学习。

提问不自动成为系统需求；只有self决定要解答并承接时才走需求/任务。接收、理解、同意、承接、开始和完成是不同事实，不由“收到”“明白了”等词自动互推。不得自动派生所有句子都需要一个任务。

## 6. 段落与文章组织

详述任务的典型组织为：关联需求目标→相关起始条件→有依据的实际步骤及实际结果→存在的问题/调整→最终结果与未完成事项。每项均可用7230组织项表达；无问题就略去可选项，实际结果未知就明确未知，不补造成功故事。

文章可以按主题或场景/时间分组，再调用段落规则。分组边界属于表达组织，不据此创建现实场景、移动现实存在或改变事件归属；需要保存自然语言场景时按其明确材料及结构合同办理，不把每个段落自动变成场景。相同事件被摘要和详述两次是两个表达出现，仍引用同一原始事件。

输入方向从局部已解含义和衔接证据反推组织候选，不能因某文章符合典型任务模板就补出遗漏步骤。输出规划不等于反向恢复完整现实；省略信息可以未知，不要求编造以实现字符串往返。

## 7. 有界执行与非成功

预算至少分别限制源文标量数、词序候选、语义候选、读取条目、规则深度、匹配状态数、组织展开项数与输出标量数。每项为有限非负上限，非空工作所需上限不得为0；具体默认值由调用合同提供，不能在学到的规则中修改全局预算。

匹配递归必须前进原文位置或消费严格更小的有限子结构；组织递归必须消费尚未处理成员或严格更小的子目标。相同规则/输入范围/角色环境无进展再入立即返回循环错误，子规则静态引用环在发布前拒绝。达到任一预算返回具名未完成及剩余范围，不能当未找到。

结果至少区分：已接收未解析、完整已解、部分已解、多义待解、上下文不足、未知词、缺名称、缺规则、概念形成合同缺失、对象/读取提供者缺失、查询无匹配、格式失败、引用失效、读取漂移、预算不足、资源失败、内部不一致。独立可完成项可返回明确部分结果；需要共同角色/范围的含义组不得部分提交为完整事实。

纯理解、输出规划和条件求值零领域写入。语言场景/指代实例保存、概念定义形成、命名及现实事实裁决分别是显式后继步骤，沿所属owner合同办理；已经保存原文但解析失败不得说成零操作。下层失败保留原状态和来源，不包装成语言否定、无对象或代词特征值。

## 8. 验证矩阵

至少覆盖：同义不同句式、多义相同词面、同词多次出现、未知词与无名称分流、多人同类对象、引语内“我”、跨段省略、否定/条件/提问/引用不写事实；D/T/M直接表达而无新概念族；状态缺时间与动态缺端点；因果句只作主张；单句到段落到文章的源对齐；不同排序不造因果；查询空与未查完分开；循环及各预算边界；规则/名称已不可读时不猜旧定义；生成/送达/理解三分账。

指代专项至少覆盖：完整短语实例与后续“它”的复用；首次出现“你好/看那个人”；同词面不同实例、同目标不同实例；说话者互换和嵌套引语；缺参考中心的“这/那”；“我不知道谁负责”不自动向外提问；“谁先到谁先选”的同一变量；空域及开放域量化；集体搬桌子与互相传球不误推逐项/全配对；“我们/咱们”的不同包含用法；现实场景与语言场景分账；焦点更新、显式纠正与旧出现保真；接收方不能恢复时改用名称/描述或返回不足。

同一已知含义在输出后解析，比较的是角色映射、约束、作用域和明确省略项，不强求字符串一致。该往返用例与独立真实样本/反馈分别记录，不能自证语言能力可靠。
