## 1. 结构约定

本规范按2320分解自然句解析记录承载的词出现、未知片段、分界与覆盖字段，以及语言场景中语言出现、含义网承载与采用记录的字段。结构约定沿7230第1节；文本范围按7230第2.1节。

## 2. 解析与词出现

```text
句子解析材料
  解析材料身份
  来源自然句及固定内容引用
  解析规则定义引用
  语境依据              // 明确无语境依赖，或固定语境材料引用
  分段项有序组
  子句组成组
  候选含义网组            // 调用期候选；每项结构按7232第2.1节
  覆盖结果               // 完整、部分、未解析；显式给未覆盖范围

分段项 = 已确认词出现 | 未知片段 | 分隔片段
已确认词出现 { 局部出现编号, 原文范围, 正式词条引用 }
未知片段     { 局部出现编号, 原文范围, 词面候选组 }
分隔片段     { 原文范围 }
```

未经分词的句子可以先保存；无解析记录、完整空结果、部分解析不能互换。正式词出现必须读回词条；未知片段不填零词条或临时整数伪装正式词条。多种分词分别属于独立候选序列，不混成一个有重叠词序的假完整解析。

子句范围与组成按2330：子句使用所属解析中的词出现索引半开区间，不是7230第2.1节的文本标量范围；含未解决词边界的范围只保留为解析候选。每个词出现同时关联源文范围，二者通过该映射换算，不改义旧位置字段。修正分词以完整当前解析整体发布；旧解析中的子句、词出现等元素仍被正式事实引用时保留至引用全部解除，再按引用计数清理（2320、2330），不构成历史版本；使用相同算法/规则重新解析不要求新建规则定义，规则改变才引用新规则定义。本文“解析结果材料”和“解析规则定义”是两个不可互换的引用。

## 3. 语言出现、含义网承载与采用记录

一条输入消息或一次输出话语对应一个语言场景。本节只列该场景内语言内容的字段；单元、内容算子、组合、表达用途和跨场景引用的语义只由7240第2节定义，含义网字段见7232第2.1节，指代实例按7233，场景结构由自然语言世界树维护。

```text
语言出现
  局部出现编号
  所属语言场景引用
  原文范围              // 文章、段落、自然句或子句的固定文本范围（7230第2.1节）
  所属解析引用?          // 句子解析材料；尚未解析时显式标记未解析

含义网承载
  所属语言场景引用
  含义网引用            // 7232第2.1节
  出现与内容项对齐组     // 语言出现、所用解析、含义网内容项局部编号

采用记录
  所属语言场景引用
  采用结果              // 唯一、多义、缺规则、部分理解
  候选含义网组          // 多义时逐项保留；唯一时一项
  未解范围组            // 原文范围及缺口种类
  外层算子确定性组       // 每个已理解内容：其外层否定、条件、引述、态度、量化是否全部确定
  主张草稿引用组         // 只含外层算子全部确定的完整内容
```

同一文字多次出现是不同的语言出现，各自保留局部编号与原文范围，不合并。语言出现是原文范围及其解析，不是指代实例，也不是所指目标（1110、7233）。

含义网是这段文本意义的唯一正式承载；已采用含义（U）保存含义网，不另存按场合列举的含义操作、作用域枚举或专用槽位。

采用结果为多义时保留全部候选，不按顺序任选；缺规则时不补造含义。部分理解时已理解的片段可以保存；只有外层否定、条件、引述、态度、量化均已确定的完整内容才产出主张草稿，外层未确定时只保留片段与缺口，不交接（例如条件句只理解后件时，不得交成无条件内容）。主张草稿按7240的分派规则交对应owner的公开入口；保存语言场景不授权写入被描述的对象（7240第1节）。

## 4. 写入与发布

句子解析材料、分段项、词出现及子句组成，以及语言出现、含义网承载与采用记录，静态路由既有语言owner。同一解析及其词序、子句、对齐在语言owner内完整发布；原文先独立发布，解析失败不撤销已接收原文（7230第4节）。解析纠正不得伪改仍被引用材料的原含义；物理删除及引用完整性遵守0050。

## 5. 最低验证

应覆盖：原文先存后解析；未知片段不造词；多种分词分别成为候选序列；子句词索引与文本范围不可互换；修正分词整体发布、被引用旧元素按引用计数保留；同文重复出现不合并；U只保存含义网；部分理解且外层算子未确定时不产出主张草稿。验证实施与是否运行测试按AGENTS第7.1节。
