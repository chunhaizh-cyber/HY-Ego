## 1. 范围与唯一解释

本规范固定方法信息的逻辑字段、条件—结果配对树、查找、学习交接及结构操作边界。函数流程由5360展开，学习细分判据由5370规定，任务时序由5260规定。所有逻辑信息用节点、关系和值承载；“字段”不要求成为内联成员，也不增加新的L1业务入口。

方法结构记录面只保存、读取、校验已经裁决的结构。适用判断、二次特征求值、横竖细分、可靠性评估、登记业务准入和学习裁决都在DATA之外。既有名称含L2的方法服务仅为方法结构兼容实现，不进入DATA-L2基础节点族。

## 2. 方法头的逻辑字段

| 字段 | 必需性与含义 |
| --- | --- |
| 方法身份 | 必需；独立稳定方法节点身份，不能用名称或函数地址代替。 |
| 名称引用 | 可选；复用合法名称关联，不因本规范建立方法概念根或另一名称仓。 |
| 动作函数注册引用 | 必需；恰一当前主动作绑定，完整读回正式函数声明和调用合同。 |
| Vm引用 | 必需；恰一专属方法虚拟存在。 |
| 根条件入口 | 成组配对树的根条件关系集合；每个根无方法内父条件。 |
| 全方法共同约束 | 显式集合，可空；作用范围、对象角色、必要输入/输出规格、安全限制、禁止项和现实副作用声明。 |

上述是业务字段清单。方法来源、治理历史和可靠性元数据按其所属正式合同关联，不伪装成条件或结果。作用范围继续区分内部治理、现实观察、现实改变；外部运动、通信或写入不得借总标签隐藏副作用。共同约束中的每项结果判定要求只引用第5节的定义，不另建效果算法。

可改变FT的检索信息由正式声明与配对结果关联得到，作为可重建检索投影，不在头与结果两处形成可独立修改的完整效果定义：

- 有完整配对时，按合法结果项及其来源建立FT到方法头索引。
- 只有登记声明时，可索引声明的可改变FT，但回执必须明确配对缺失，不能据此报告已掌握、适用或可执行。
- 索引命中必须读回实际声明/配对；缓存、标签、名称不构成能力来源。

## 3. 条件节点与条件项

一个条件节点 C 保存一组完整条件，作为整份配对的定位身份。

| 字段 | 合同 |
| --- | --- |
| 条件身份 | 必需，不能用条件列表顺序或哈希代替。 |
| 所属方法引用 | 必需，唯一方法归属。 |
| 条件项集合 | 显式0..N；组内为AND，空组只表示明确无额外条件，不免除全方法共同约束。 |
| 对应结果引用 | 正常完整配对恰一R；第4节异常条件组可有多个备选R。未知结果保留结果节点及未知值，不冒充完整可采用配对。 |
| 父条件引用 | 根为空，其它恰一同方法父C；子组应包含父组全部必要约束并严格细分适用范围。 |

每项条件完整表达：

1. 输入绑定位置：作用对象角色或参数规格的明确位置；不是本次具体存在身份，也不新建独立世界属性上下文。
2. 正式特征类型与必要对象类别约束；类型、值域可从FC/EC固定定义唯一取得时只保存引用，不复制第二定义。
3. 允许值/域或关系条件：数值范围、结构值域、特征概念或二次关系概念。具体轮廓作为固定目标/代表引用，不对节点编号作算术。
4. 引用的比较规则需要的双方取值、单位、坐标及参照；可由规则唯一读回的部分不重复保存。

同类型可以出现在不同对象或参数位置，不能按FT合并输入。不同条件组表示不同配对，不将其全部条件合并成一组。每个C独立保存完整语义；父关系用于组织和验证细分，不以遗漏继承内容的私有运行补丁替代完整读回。

## 4. 结果节点与结果项

一个结果节点 R 保存与一个C对应的一组预测结果。正常完整知识中C与R一对一；按5370确认已无法细分的同一完整C有不同结果时，该异常C可对应多个备选R，每个R仍只归属该C。多个配对不共享一个可独立变更的R，底层概念、值与规则定义仍可共享。

| 字段 | 合同 |
| --- | --- |
| 结果身份 | 必需，独立结果节点身份。 |
| 所属方法引用 | 必需，与对应C的方法相同。 |
| 结果项集合 | 非空；每项明确被改变对象角色、被改变FT及第5节判定定义。未知项的结果值/域可无值，但不能用零、预测或其它运行补造；结果节点存在不等于效果已知。 |
| 结果时间约束 | 按结果需要声明观察时机、允许延迟或持续条件；缺少决定效果的时间约束不能默认“函数返回即达到”。 |
| 联合结果约束 | 有跨结果相关性时必需；定义同一次执行中共同成立的关系，不把各项独立区间任意组合。 |

结果组不是本次准确状态、动态、执行回执或任务完成状态。一个方法可影响一个或多个FT，各分支不要求全部FT均改变；允许明确无变化结果，但不能以观察缺失冒充无变化。

一个R内的多项表示同次执行共同成立的联合结果；异常C下的多个R表示同条件的不同备选结果，二者不可合并。异常标记须能定位方法及具体C，保留各R和来源，不取平均或合并宽域掩盖差异。未知值不计为一个观测结果，更不以未知和已知的区别制造多结果异常。异常认定与结束规则由5370负责。

结果项引用的是作用对象的预期效果；方法自身的可用性、练习程度、治理状态不混入现实动作结果。内部治理方法可引用相应内部作用对象的合法类型和结果合同。

## 5. 二次特征判定定义

每项结果必须能完整读回以下逻辑信息：

| 信息 | 解释 |
| --- | --- |
| 作用对象角色与FT | 绑定到任务实际对象后定位被描述特征，不由名称推断。 |
| 比较用途/规则引用 | 决定正式算法、输出类型、角色、单位和误差含义；已有RC完整定义能承载时直接引用。 |
| 输入绑定说明 | 明确执行前、执行后、另一对象或目标规格分别进入哪个比较位置。 |
| 目标来源 | 特定目标时必需：合法固定准确F/值来源、概念域，或Vm规格中声明的任务目标参数；非目标比较不补造常量。 |
| 允许结果约束 | 共享方向域、完整匹配、容差或进一步范围约束；由既有定义承载时不重复保存。 |

变化方向按4180将执行前绑定左、执行后绑定右；有序差异为后值减前值。实际与目标的左右映射由具名规则固定。增大、减小和特定值/轮廓匹配均通过二次特征能力判断，不在方法类再实现一套比较。

共享负、零、正域只负责基础方向。增加5..10等精度要求须对准确增量设置合法域约束，必要时进一步比较其上下界；不能给共享D偷偷改成任意区间。容差命中不等于准确相等；轮廓距离零不保证完整轮廓相等。缺源、不可比、算法缺失或溢出均无成功值，不当作零。

多个具名I64输出分别保存计算语义；复合RC仍遵守同一有序A/B。不同对象对的结果可以组成方法的联合要求，但不得伪装成同A/B的一个RC。正式定义与本次计算分开；本次二次结果按4151使用，不借方法学习解除C038的持久实例限制。

## 6. Vm与参数规格

Vm固定承载方法自身特征/治理状态、参数规格关系及必要结构引用，不是世界存在或任务Vt。其规格与本次实参分离：

| 参数规格信息 | 合同 |
| --- | --- |
| 明确数量和顺序 | 显式0..N；非空按1开始连续有序，不重复、不缺位。 |
| 参数类别 | 场景、存在、特征等已经正式声明的类别；现有三类编码不由本规范扩展。 |
| 类型/概念约束 | 正式FT及其合法表示；必要FC/EC约束不从名称猜测。 |
| 角色及取值要求 | 明确哪个对象/输入项、如何绑定到函数参数。 |
| 必要限制 | 与全方法或具名条件关联，不能把限制写成默认实参。 |

规格由方法函数登记部分经方法记录面提交，方法参数规格定义由该方法唯一Vm正式承载；方法头和函数注册表不复制。完整方法读取DTO可以投影Vm规格，但不取得独立写入或权威身份。方法完整实例化仍复制自身Vm及规格；交付任务时，由任务owner按5260将实例规格、条件组及共同约束所表达的执行要求传递到Vt，保留节点引用、角色、值域与来源关联。这是任务的条件应用信息，不是另一份可独立改写抽象方法知识的规格定义；旧“任务均不得复制第二份参数规格”不得再用于禁止这项必要传递。

条件信息必须能表达所需存在、特征、值域及对象间关系，不只列特征类型名称。例如“自我的服务任务集合有成员T”与“T的状态为完成”必须共享同一成员角色，不能以两个无关联对象各自满足代替。规格声明不产生实际条件成立事实，也不凭声明预造长期条件—结果配对。

任务依据Vt条件信息查找正式节点并为本次调用构造临时参数场景；场景包含条件及结果所需的角色化引用，不能用无角色的裸值替代实参绑定。绑定容器只读，所引用信息按方法声明及正式owner合同读写，结果从这些引用重新读回。模拟场景只允许改变隔离的模拟实例，不持有可写的现实实例引用。执行前复核、缺口交付和失效处理统一按5260/5360。参数场景用完即释放，不作为临时实参容器写入Vt；一次真实执行不能回写共享Vm规格。

方法及具体配对的可靠性评估归方法治理；用C身份定位配对，来源仍引用已有任务/运行事实。命中数、支持数、反例数和误差统计可重建或缓存，不参与条件/结果定义身份，不新增第二样本权威仓。

### 6.1 方法运行统计与可靠度

方法唯一Vm增加三个正式特征类型。它们不属于条件/结果定义，不保存第二份运行样本：

| 特征 | 值与来源 |
| --- | --- |
| 方法运行次数 | 非负整数；依据正式实际运行身份，每次真实进入动作只计一次。登记、条件核验、未执行、模拟、知识推演及重复交付不增加。 |
| 成功次数 | 非负整数且不超过运行次数；同次真实结果经独立读回，符合执行前固定的方法声明结果要求才增加一次，不以函数返回成功或任务需求满足代替。结果未取得/未判定不增加，后续补齐仍归原运行。 |
| 可靠度 | 可无值的整数，取得值时范围0..10000；由以下规则计算，不能由调用方任意设置。无值与0严格区分。 |

唯一计算规则：

1. 当前方法没有异常条件组：`可靠度 = floor(成功次数 × 10000 / 方法运行次数)`；运行次数为0时无值。
2. 当前方法存在第4节异常条件组：`可靠度 = floor(正常条件组数 × 10000 / 全部条件组数)`，使用此分支而不与运行成功率相乘或取最小值。正常组是完整且有一个已知R的C，异常组是具名的同条件多R组；分母是当前方法全部已发布合法C，结果尚未知的合法C不冒充正常组，也不从“全部”中排除。每个C只计一组，不按R条数、重复样本或关系数量重复计数；同义条件组在计数前必须复用归一。分母为0时无值。
3. 非负整数除法向下取整，计算须防乘法溢出；溢出或材料读取错误是工程故障，不回填默认可靠度。

唯一方法owner消费正式运行及独立结果核验材料维护次数，经方法治理计算并发布可靠度；同一次真实运行及成功确认必须去重，统计与据此派生的可靠度一致发布并读回。模拟形成的新C/R真实命中次数为0；模拟/知识推演不增加实际运行、成功或真实命中次数，不用推演自证运行可靠。异常知识发布会按上述第二分支重新计算可靠度，不改变真实次数。

异常不自动停用或删除方法，仅降低可靠性评价；其它独立安全和执行约束仍有效。该规则不为任务新增多结果选择策略，任务使用策略不属于学习职责。工程故障仍走诊断和调试修复链，不作为方法业务反例或异常R。

## 7. 配对树及两种拆分

### 7.1 组织和基数

关系包括：方法到根C、正常C到唯一R（异常C按第4节到多个备选R）、子C到唯一父C、具名来源和治理引用。R的组织层级由配对和C父关系推导，不另建可独立变化的结果父树。方法内无环、无多父，全部C/R可从方法头完整到达，子C和R不跨方法。

分支出现不删除父配对；父配对仍有效时保留粗粒度用途。父定义被真实反例否定时转入知识修订/治理，不能因保留节点就继续声称父范围全部可靠。同一输入多分支命中时必须返回完整候选及差异，不靠遍历首项或深度自动决定采用。

### 7.2 横向方向拆分

方向分支的学习判据、样本可比性、抖动与未知边界处理统一读取[5370第5.1节](5370_子规范_方法学习与知识形成.md)。本节只约束形成后的结构仍满足第7.1节，不由结构写入口自动拆分。

### 7.3 竖向精度拆分

精度细分的依据、粒度与停止条件统一读取[5370第5.2节](5370_子规范_方法学习与知识形成.md)。配对树关系保存拆分性质及所细分输入位置/规则引用，不新增“横向节点”“竖向节点”类型；已发布子域和父子关系仍按第3节及第7.1节完整校验。

## 8. FT粗召回与后续细查

查找固定顺序：

```text
目标正式FT
→ 按可改变FT检索方法
→ 回读命中方法及各自完整配对
→ 细查方向、目标/区间、对象和参数条件
→ 在任务执行前阶段选择、实例化与冻结
```

1. 粗召回输入为FT及明确扫描范围/预算，输出去重方法、命中来源、完整性及结构缺口。方向、区间、目标值、名称、代价不成为粗召回精确相等门槛。
2. 多FT目标可分别召回并在应用层核对是否由一个方法合法覆盖；不得把多个方法各自可改变一项误报为单方法可同时改变全部项。
3. 方向、区间和目标细查绑定真实目标合同，调用二次特征定义/求值；必须保持“方法—条件组—结果组”的对应，不拼接跨分支有利项。
4. 5260中的筹办仍只找方法、读候选条件并核验当前具备性，不做适用性裁决或采用；后续执行前选择才裁决效果、限制、安全与代价。服务的读取/静态投影不代替任务决策。
5. 查找未完成、预算不足、比较失败、结构缺口不是方法不存在。候选非空但全不适用，与完整范围无能力候选分别报告。
6. 方向/区间符合只证明该项效果兼容，不证明全部条件具备、已获现实授权、函数可调用或目标必然达成。
7. 登记头无配对时不能用于普通目标达成承诺；试验入口和风险边界须由专项任务合同给出，不能自动执行探索。

能力投影用后可弃，不保存第二用途/结果账。历史“六项”只可作为从完整定义得到的兼容视图，不继续作为新查找或新字段全集。

## 9. 从任务结果完善方法

方法学习的材料准入、完整条件组合及对应结果形成、反例与冲突处理、候选差异和独立评审，统一读取[5370《方法学习与知识形成》](5370_子规范_方法学习与知识形成.md)。本节只作为结构服务的学习交接入口，不重复定义学习规则。

方法owner接收按5370评审通过的发布请求，按本规范第3—7节与第11节校验完整结构并发布。运行材料取得由5360负责；合法初始声明仍走5360登记合同，不要求伪造经验样本。

## 11. 一致性、历史与失败

同义登记/发布可重入，未经授权的异义冲突零覆盖；已用身份和关系编码不可复用。第11.1节是本轮同条件多结果异常修订的具名例外，不授权登记函数覆盖学习知识。方法结构使用current-only完整读写；需要保留旧代际时建立仍可独立读取的旧方法节点，不依赖DATA-L1事实截止、历史读回或墓碑。发布未知只按原请求查询和收敛，这些技术材料不变成方法效果语义字段。

完整配对发布至少包括C、R、所属方法、条件成员、结果成员、全部必要引用、配对及父/根组织；学习修订保护旧引用。跨概念owner和方法owner不宣称无合同的大事务，引用概念先完整发布再进入方法配对。

分别返回合法不存在、不适用、缺规格/配对、冲突、超预算、不可比、引用失效、发布未知和内部不一致。失败不能回填空条件、零效果或默认参数。退出保护尚在运行或被历史任务/学习引用的结构；未发布完整的对象不能由普通完整方法读取冒充可用。

内容、规格、绑定和生命周期继续在各自承载中分账，方法治理不复用世界状态作为方法生命周期权威。除第11.1节外，动作、条件、结果、配对组织、输入规格或限制改义须按独立新代际合同处理，旧内容以显式节点保护，不恢复历史截止读取。

### 11.1 同条件多结果覆盖原方法的限定发布
