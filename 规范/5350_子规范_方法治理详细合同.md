## 1. 适用范围

本规范统一承接原4270与5300—5340中仍有效的方法结构、公开能力、召回、运行、本能、学习、晋级、代际、事务、错误和验证合同。它不恢复这些旧文件的分散权威，也不把本能或学习专用条款推广为所有方法的共同前置条件。

任务何时找方法、查条件、选择、冻结、执行和结算读取5260；需求及self产生确认读取3100与5170；动作动态与因果学习材料读取4220与4330；安全硬门读取6150。本规范只冻结方法域自身事实及相邻消费边界。

## 2. 长期方法、实例与运行分账

长期方法只允许方法头、条件、结果三类知识结点。动作绑定、用途、条件结果关系、输入规格、限制、方法虚拟存在、版本、生命周期、投影、运行、学习和代际均不得成为第四类知识结点。

```text
长期方法       可复用能力知识
任务方法路径   任务某筹办轮次的具体方案，由task owner管理
实例方法       某执行轮次的不可变冻结，由task owner管理
方法运行事实   一次真实调用的过程与结果证据
学习材料       从正式运行、状态、动态、因果形成的值式材料
学习候选       非权威、可清空重建的候选知识
新方法代际     独立晋级后由方法owner发布的长期方法
```

共享方法不得保存某个任务的参数、输入、授权、冻结、状态、结果或结算。一个长期方法可以被多个任务并发复用；隔离键属于各任务及其轮次。

## 3. 强类型身份与固定值域

方法结构固定使用以下互不替代的强类型身份：

```text
L2方法身份
L2方法条件身份
L2方法结果身份
L2方法治理虚拟存在身份
L2方法输入规格身份
L2方法限制条件身份
L2方法用途身份
L2方法条件结果关系身份
```

目标对象类型引用概念owner的`L2概念身份`。结果类型固定为闭合联合：

```cpp
using L2方法结果类型引用 = std::variant<
    L2目标状态合同身份,
    L2概念身份>;
```

联合分支机器序号固定为`1=目标状态合同身份`、`2=动态根或其下普通概念身份`，持久负载为`[分支机器序号, 强类型身份稳定编码]`两个U64。不得使用`variant::index()`、编译器布局、类型名、哈希、名称或访问顺序作为机器合同。

变化方向固定为：`负方向=1`、`无变化=2`、`正方向=3`。限制类别固定为：`禁止项=1`、`适用范围=2`、`规格约束=3`、`安全限制=4`。方法作用范围固定为：`仅内部治理=1`、`现实观察=2`、`现实改变=3`。各值域零值和未知值非法。

混合方法逐动作保存作用范围与现实副作用；方法级投影只取最严格范围。主动探测、设备运动、发射、外部通信、外部系统写入及其它现实副作用必须归为现实改变，不能以总标签隐藏。

## 4. 方法结构、用途、条件与结果

方法整体结构为：

```text
方法头
├─ 恰一当前主动作绑定
├─ 一项或多项当前用途
├─ 唯一方法虚拟存在 Vm
├─ 零项或多项条件
├─ 零项或多项结果
├─ 条件结果关系
├─ 输入规格关系
└─ 限制条件关系
```

方法头至少保存方法身份及来源、内容版本、规格版本、当前动作绑定、方法作用范围与逐动作副作用、Vm身份和方法生命周期。

动作入口的输入 / 输出场景使用4010冻结的专用关系17：源精确为动作入口方法节点，目标精确为场景，顺序1表示输入场景，顺序2表示输出场景。同一完整源动作入口和同一角色至多一条当前有效关系；同一场景可以分别承担输入和输出。方法owner是该关系的唯一业务写入与解释方；未知顺序、错误端点或同源同角色复义必须写前拒绝，普通引用槽不得替代关系17。

每项用途精确包含且按此顺序保存用途身份、方法、作用对象角色、目标对象类型、可改变特征、变化方向、结果类型、来源、内容版本和生命周期。用途只形成对象类型、特征、方向、结果类型四元组的粗能力说明；命中只证明可能相关。同一方法、作用对象角色和完整四元组构成当前唯一键；同键同义幂等读回，同键复义属于内部不一致。用途组按完整四元组、作用对象角色和身份稳定升序返回。

每项条件精确包含且按此顺序保存条件身份、方法、作用对象角色、目标对象类型、可选场景、特征定义、条件状态合同、来源、内容版本和生命周期。零场景表示不限制具体场景；零特征、零状态合同或自由文本不能表示万能条件。

输入规格是方法头或具名条件的强类型值式关系，精确包含且按此顺序保存身份、方法、可选条件、作用对象角色、顺序、规格材料、来源、内容版本和生命周期。条件为空表示全方法规格；非空必须引用同一方法当前条件。方法、可选条件、作用对象角色和顺序构成当前唯一键。

每项结果精确包含且按此顺序保存结果身份、方法、作用对象角色、目标对象类型、特征定义、变化方向、结果类型、来源、内容版本和生命周期。变化量、速度、持续时间、频率和单位对应量引用正式动态或二次特征材料，不通过增殖结果类型表达。

方法新增或替换写入前，方法结构服务必须在调用方给出的同一非零期望事实代次，正式读回全部跨owner端点：目标对象概念必须是存在本体根或其下当前普通概念；概念型结果必须是动态本体根或其下当前普通概念；状态型结果必须经状态owner读回为当前目标状态合同。任一端点缺失、已退出、错根、混代或读回不完整均结构化拒绝且零方法事实写入。

条件结果关系精确包含且按此顺序保存身份、方法、条件、结果、顺序、来源、内容版本和生命周期，并满足`条件.方法 == 结果.方法 == 关系.方法`、内容版本相同且同截止有效。一个条件可关联多个结果，一个结果可由多个条件关联；关系不得跨方法。方法、条件、结果和顺序构成当前唯一键。

限制条件是方法头或具名条件的强类型值式关系，精确包含且按此顺序保存身份、方法、可选条件、限制类别、作用对象角色、顺序、规格材料、来源、内容版本和生命周期。方法、可选条件、限制类别、作用对象角色和顺序构成当前唯一键。记录面只保存限制结构，不判断其当前是否命中。

上述输入规格、条件结果和限制关系的当前唯一键统一执行：同键同义幂等读回，同键异义结构化冲突并保持零变化；不得按遍历顺序静默选取。

无条件方法必须通过完整方法结构中的显式空条件组表达。存在条件却缺少应有条件结果关系属于结构缺口，不能解释为空条件组。

## 5. 方法虚拟存在、生命周期与版本

一个方法恰有一个Vm。Vm不是世界存在，不进入世界树，不得共享，也不得承载任务状态或本轮运行数据。

方法生命周期由方法owner的强类型治理事实承载，每份至少包含方法身份、从1连续递增的生命周期版本、发生时间、来源和结构创建 / 退出生命周期；同一方法恰有一份当前生命周期，迁移时同事务旧退新建并保留历史。

方法治理状态和动态如需通用认知结构，必须经ARCH-L2正式结构唯一承载，方法owner只保存业务引用；它们不能替代方法生命周期。方法身份、内容版本、规格版本、动作绑定版本和生命周期版本必须分账。

动作、用途、条件、结果、条件结果关系、输入规格或限制任一变化，都必须形成新内容版本或不可变新代际。旧版本必须能按历史截止完整读回并重建当时投影；不得原地覆盖。

## 6. 六项能力投影与结构缺口

每个当前结果作为一条投影主轴；只有当前用途与结果的目标对象类型、特征、方向、结果类型和作用对象角色全部相等，才能形成投影。角色不等固定形成`用途结果冲突`，不得被业务层重新解释为任务不兼容。

每份投影固定包含：

```text
输入条件
目标对象类型
可改变特征类型
变化方向
结果类型
限制条件
```

输入条件由主轴结果关联的条件语义、条件级输入规格和全方法输入规格组成；限制条件由条件级与全方法限制组成。投影在一个非零共同事实截止读取完整方法后形成：输入条件和限制条件分别按字段字典序稳定排序；语义完全相同且不违反当前唯一键的值式项才可去重；投影组按目标对象类型、特征、方向、结果类型、输入条件、限制条件和主轴结果身份稳定升序返回。投影用后可丢弃，不得持久化为节点、关系、布尔值或第二权威。

结构缺口只表示缺用途、用途结果冲突、条件结果关系缺失、输入规格引用冲突或限制引用冲突。它不是能力缺口对象、方法不可用裁决、条件不具备、学习需求或任务失败。

## 7. 结构记录面公开能力与ABI连续性

方法结构记录面至少提供：

```text
新增方法头、替换方法内容、退出方法头、读取方法头
新增 / 读取 / 退出方法用途
新增 / 读取 / 退出方法条件
新增 / 读取 / 退出方法结果
建立 / 读取 / 退出条件结果关系
建立 / 读取 / 退出输入规格关系
建立 / 读取 / 退出限制条件关系
读取完整方法
按特征读取方法用途粗召回组
读取方法六项静态能力投影组
```

`读取完整方法`在请求指定的共同截止返回方法头、动作绑定、作用范围及逐动作副作用、用途组、Vm、条件组、结果组、三类关系组、内容 / 规格 / 生命周期版本、结构缺口和截止。当前读取使用期望事实代次，历史读取使用显式历史截止，不自动升级截止。

粗召回请求精确包含且按此顺序保存读取类别、事实截止、可改变特征类型、最大扫描用途数和最大方法数；结果稳定返回零到多项方法及命中用途、实际扫描数和共同截止。预算不足返回具名技术非成功和零伪完整候选。粗召回只比较可改变特征，不提前判断对象、方向、结果、条件、限制或任务适用性。

投影读取请求精确包含且按此顺序保存方法身份、读取类别和事实截止；结果返回规范化投影组、结构缺口组和共同截止，不接收任务、不执行匹配、不写事实。

旧四元组精确粗召回、任务侧六项镜像以及要求任务先形成六项再逐项相等匹配的旁路均已退出，不得恢复。任务只可先按目标特征有界粗召回，再消费完整方法、投影和结构缺口。

本次规范合并不改变原4270、5300—5340已经冻结并进入生产声明的公开ABI：既有接口名、合同版本、请求 / 结果类型、字段顺序、状态值域、成功谓词、非成功零业务载荷、失败优先级、幂等及读回语义继续保持。任何字段、机器码、入口或行为变化必须另立ABI迁移，完成消费者同步和验证后登记；不得借规范简化静默改变。

## 8. 召回、筹办、执行前选择与运行

方法必须正式声明任务执行时需要挂载的输入、参数、阶段、共同场景、逐动作直接作用主体、现实副作用、预计因果后果、安全限制、禁止项、验证、归因、失败处理和输出路由；组合方法还须声明跨方法协调、顺序、并行、回流和失败收束。任务只能挂载这些正式声明，不得自行发明。只有包含现实改变步骤的实例方法，才由task owner依5260在执行冻结后、动作入口开始前请求并读回self业务owner发布的现实执行授权，随后依6150执行安全硬门复核；self授权不能越过安全硬否决，安全许可也不能替代self正向授权。内部治理和纯现实观察不把该授权声明成方法条件。

任务筹办消费方法结构时固定分为：先在明确范围内完整找方法，再对全部候选逐项读取全部正式条件组并核验当前具备性。筹办可以多次调用，但不判断对象、方向和结果适用性，不比较代价，不采用方法，不建立路径、实例或冻结。

执行前选择必须在新共同截止fresh读取候选的完整方法、生命周期、动作入口、条件组、输入、参数、范围、验证 / 归因、禁止、安全和成本材料，依次完成适用性、当前可用性、硬门和可比较性复核，再从可比较候选中选择综合代价最小的一项。

合法代价只来自具有正式来源、单位、作用范围、规则版本和共同截止的安全值 / 服务值收益与付出、时间成本、资源成本和运行质量；不建立第二持久成本账。安全硬否决不可被收益抵销；未知、不可比或并列最优时不选择。

每次真实方法运行必须具有独立运行身份，关联方法、任务或调用上下文、共同场景、直接作用主体、预计间接结果主体、开始 / 结束时间、动作动态、执行摘要和版本。直接作用主体的改变与间接结果主体的实际变化分账；间接结果必须由其事实owner独立读回。

方法运行成功只证明本次方法合同返回，不能证明任务目标达成、任务结算、需求满足、安全值 / 服务值变化或价值结算。

## 9. 本能方法限定合同

本节只适用于本能方法，不推广为所有方法的执行实现。

函数只有同时具备明确方法身份、输入输出合同、动作入口、作用对象、条件结果规格和落账边界，才具备本能方法资格。名称、地址、标签、方法头存在或成功码均不能证明资格。

本能方法进入核心逻辑前必须读回当前方法及生命周期、唯一Vm、当前动作入口、输入输出场景、显式条件组、结果规格、本轮运行身份、内容版本和当前性。执行期不得补造方法头、条件、结果、动作入口或Vm。

学习或练习方法A处理目标方法B时，必须分别读取两套身份、Vm、规格、运行事实和场景；A不得把B的环境当作自身环境，也不得在确保自身环境时改写B。

标准调用顺序为：形成运行身份、复核自身环境、解析条件、绑定对象 / 输入 / 参数、执行核心动作、经各事实owner写入并独立读回输出和动态、形成运行事实、返回运行身份。绑定或执行失败仍应形成强类型运行结果；本应能形成运行身份却失败属于内部错误。

本能函数返回本轮方法运行事实身份，不直接返回任务状态、需求状态或单个业务结果。参数不得猜测；当前值从目标宿主正式当前投影读取；I64运算必须有溢出策略；底层通用写入不是任意业务目标的语义方法。

## 10. 练习、尝试、因果反推与学习候选

学习只分为练习、尝试、因果反推：练习复验已有方法；尝试在安全边界内探索条件、参数和效果；因果反推从客观因果、可控制状态与动作能力形成方法能力变化材料。原“定向学习”不再是并列类别。

普通任务真实运行自然产生练习材料。学习旁路只消费正式运行、状态、动态、因果和必要治理上下文，不改变普通任务结论，也不阻塞其结算。

调用期学习材料必须在指定非零事实截止按正式来源读回，并按“任务 / 回合 + 状态 / 动态 / 直接因果身份 + 方法内容版本 + 结算分栏 + 规则版本”确定组合、排序和去重；它是值式、可重建、非权威材料。待结算材料不得进入效果差异；冲突、过期、非法或来源缺失材料不得由统计层挑选、补造或修补。日志、工程见证、G0、事务、幂等账、恢复材料和消费水位不进入学习语义或样本计数。

完整方法查找范围零候选只形成任务材料。是否产生学习需求由self依照5170的产生确认与子目标准入合同裁决；学习函数、筹办和方法owner均不得直接创建需求、任务、方法首、能力缺口节点 / 关系 / owner或数量账。

从已有方法形成的学习候选必须绑定动作前冻结的来源方法完整内容快照、来源身份、共同截止、规则版本、适用范围和确定差异。差异固定区分新增、保留、移除、替换、未知、冲突；材料不足时不得猜测。

来源方法版本、确定学习材料、候选规则和完整差异共同形成候选稳定键：同键同义幂等读回；同键异差异、异授权范围或异目标代际必须冲突并保持零方法变化。学习候选、统计和召回索引可以清空重建；晋级授权与已发布方法代际是权威事实，恢复时不得把前者替代后者，也不得从恢复材料自动晋级或发布。

零候选后的因果反推可以形成非权威候选材料，但现行首代方法发布缺少无父代的完整发布合同。在该合同另行裁决前，此类材料不得冒充可晋级候选或直接发布首个方法。

## 11. 晋级、新代际与同轮隔离

候选不能自证晋级。独立晋级服务至少复核来源方法和版本、来源材料可重建性、差异完整性、晋级授权、安全与动作入口、重复消费和新结构自足性；它只输出强类型授权或拒绝，不直接写方法仓库。

只有方法owner可以消费有效晋级授权并发布新代际。新代际使用新的稳定方法身份和独立内容版本，保存父代关系、完整条件 / 结果 / 动作 / 范围 / 生命周期 / 验证和来源追溯；它不是差异补丁，也不得覆盖来源方法。

任务回合在动作前冻结的方法身份、内容版本、入口、条件、输入、授权、路径和验证合同不受本轮后续学习材料、候选、晋级或新代际改变。新代际只对后续任务回合可见；后续必须重新筹办、选择和冻结。

## 12. 写入、事务、幂等、恢复与错误

方法owner是方法头、动作绑定、用途、条件、结果、关系、生命周期和新代际的唯一业务写入方。基础结构同代原子发布；条件、结果和关系按具名事务发布；不同owner不拼接无边界大事务。

当前组合读取共享共同事实截止，历史读取使用显式历史截止。同幂等身份与同完整请求精确重复；同键异义冲突；事实代次漂移零变化；发布未知只用原键和原请求收敛。恢复不得自动晋级、发布、选择或执行。

至少分账：业务入口拒绝、结构缺口、业务不适用、条件变化、输入过期、预算不足、当前性漂移、引用冲突、幂等冲突、资源失败、发布未知和内部不一致。技术非成功不能包装成方法 / 条件缺失、合法等待或业务失败；内部错误停止受影响调用并追根因。

## 13. 验证与完成边界

验证至少覆盖：

- 三类长期知识结点上限及Vm唯一隔离；
- 强类型身份、结果联合机器码、方向、限制和作用范围；
- 多用途、多条件、多结果不发生笛卡尔误配；
- 显式空条件组与结构缺失分离；
- 同截止完整读回、投影重建、稳定排序与结构缺口；
- 粗召回不提前适用判断，预算不足不返回伪完整候选；
- 方法owner、任务选择权、现实授权和安全硬门分权；
- 本能资格、环境分离、运行身份返回和事实owner写入；
- 三类学习、候选非权威、独立晋级和首代发布停点；
- 新代际不覆盖父代、不反写本轮冻结；
- 幂等、漂移、发布未知、历史和ABI连续性。

本规范生效只证明统一方法详细合同取得正式承载，不证明公开ABI、代码、运行、学习闭环或验收已经实现。
