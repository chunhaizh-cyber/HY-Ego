## 1. 范围与唯一解释

本规范固定方法信息的逻辑字段、条件—结果配对树、查找、学习细分及结构操作边界。函数流程由5360展开，任务时序由5260规定。所有逻辑信息用节点、关系和值承载；“字段”不要求成为内联成员，也不增加新的L1业务入口。

方法结构记录面只保存、读取、校验已经裁决的结构。适用判断、二次特征求值、横竖细分、可靠性评估、登记业务准入和学习裁决都在DATA之外。既有名称含L2的方法服务仅为方法结构兼容实现，不进入DATA-L2基础节点族。

## 2. 方法头的逻辑字段

| 字段 | 必需性与含义 |
| --- | --- |
| 方法身份 | 必需；独立稳定方法节点身份，不能用名称或函数地址代替。 |
| 名称引用 | 可选；复用合法名称关联，不因本规范建立方法概念根或另一名称仓。 |
| 动作函数注册引用 | 必需；恰一当前主动作绑定，完整读回正式函数声明和调用合同。 |
| Vm引用 | 必需；恰一专属方法虚拟存在。 |
| 根条件入口 | 成组配对树的根条件关系集合；每个根无方法内父条件。 |
| 全方法共同约束 | 显式集合，可空；作用范围、对象角色、必要输入/输出规格、安全限制、禁止项和现实副作用声明。 |

上述是业务字段清单。方法来源、治理历史和可靠性元数据按其所属正式合同关联，不伪装成条件或结果。作用范围继续区分内部治理、现实观察、现实改变；外部运动、通信或写入不得借总标签隐藏副作用。共同约束中的每项结果判定要求只引用第5节的定义，不另建效果算法。

可改变FT的检索信息由正式声明与配对结果关联得到，作为可重建检索投影，不在头与结果两处形成可独立修改的完整效果定义：

- 有完整配对时，按合法结果项及其来源建立FT到方法头索引。
- 只有登记声明时，可索引声明的可改变FT，但回执必须明确配对缺失，不能据此报告已掌握、适用或可执行。
- 索引命中必须读回实际声明/配对；缓存、标签、名称不构成能力来源。

## 3. 条件节点与条件项

一个条件节点 C 保存一组完整条件，作为整份配对的定位身份。

| 字段 | 合同 |
| --- | --- |
| 条件身份 | 必需，不能用条件列表顺序或哈希代替。 |
| 所属方法引用 | 必需，唯一方法归属。 |
| 条件项集合 | 显式0..N；组内为AND，空组只表示明确无额外条件，不免除全方法共同约束。 |
| 对应结果引用 | 完整配对恰一R；未完成结构不得进入可采用配对集合。 |
| 父条件引用 | 根为空，其它恰一同方法父C；子组应包含父组全部必要约束并严格细分适用范围。 |

每项条件完整表达：

1. 输入绑定位置：作用对象角色或参数规格的明确位置；不是本次具体存在身份，也不新建独立世界属性上下文。
2. 正式特征类型与必要对象类别约束；类型、值域可从FC/EC固定定义唯一取得时只保存引用，不复制第二定义。
3. 允许值/域或关系条件：数值范围、结构值域、特征概念或二次关系概念。具体轮廓作为固定目标/代表引用，不对节点编号作算术。
4. 引用的比较规则需要的双方取值、单位、坐标及参照；可由规则唯一读回的部分不重复保存。

同类型可以出现在不同对象或参数位置，不能按FT合并输入。不同条件组表示不同配对，不将其全部条件合并成一组。每个C独立保存完整语义；父关系用于组织和验证细分，不以遗漏继承内容的私有运行补丁替代完整读回。

## 4. 结果节点与结果项

一个结果节点 R 保存与一个C对应的一组完整预测结果。同一发布内容中，C与R一对一；多个配对不共享一个可独立变更的R，底层概念、值与规则定义仍可共享。

| 字段 | 合同 |
| --- | --- |
| 结果身份 | 必需，独立结果节点身份。 |
| 所属方法引用 | 必需，与对应C的方法相同。 |
| 结果项集合 | 非空；每项明确被改变对象角色、被改变FT及第5节判定定义。 |
| 结果时间约束 | 按结果需要声明观察时机、允许延迟或持续条件；缺少决定效果的时间约束不能默认“函数返回即达到”。 |
| 联合结果约束 | 有跨结果相关性时必需；定义同一次执行中共同成立的关系，不把各项独立区间任意组合。 |

结果组不是本次准确状态、动态、执行回执或任务完成状态。一个方法可影响一个或多个FT，各分支不要求全部FT均改变；允许明确无变化结果，但不能以观察缺失冒充无变化。

结果项引用的是作用对象的预期效果；方法自身的可用性、练习程度、治理状态不混入现实动作结果。内部治理方法可引用相应内部作用对象的合法类型和结果合同。

## 5. 二次特征判定定义

每项结果必须能完整读回以下逻辑信息：

| 信息 | 解释 |
| --- | --- |
| 作用对象角色与FT | 绑定到任务实际对象后定位被描述特征，不由名称推断。 |
| 比较用途/规则引用 | 决定正式算法、输出类型、角色、单位和误差含义；已有RC完整定义能承载时直接引用。 |
| 输入绑定说明 | 明确执行前、执行后、另一对象或目标规格分别进入哪个比较位置。 |
| 目标来源 | 特定目标时必需：合法固定准确F/值来源、概念域，或Vm规格中声明的任务目标参数；非目标比较不补造常量。 |
| 允许结果约束 | 共享方向域、完整匹配、容差或进一步范围约束；由既有定义承载时不重复保存。 |

变化方向按4180将执行前绑定左、执行后绑定右；有序差异为后值减前值。实际与目标的左右映射由具名规则固定。增大、减小和特定值/轮廓匹配均通过二次特征能力判断，不在方法类再实现一套比较。

共享负、零、正域只负责基础方向。增加5..10等精度要求须对准确增量设置合法域约束，必要时进一步比较其上下界；不能给共享D偷偷改成任意区间。容差命中不等于准确相等；轮廓距离零不保证完整轮廓相等。缺源、不可比、算法缺失或溢出均无成功值，不当作零。

多个具名I64输出分别保存计算语义；复合RC仍遵守同一有序A/B。不同对象对的结果可以组成方法的联合要求，但不得伪装成同A/B的一个RC。正式定义与本次计算分开；本次二次结果按4151使用，不借方法学习解除C038的持久实例限制。

## 6. Vm与参数规格

Vm固定承载方法自身特征/治理状态、参数规格关系及必要结构引用，不是世界存在或任务Vt。其规格与本次实参分离：

| 参数规格信息 | 合同 |
| --- | --- |
| 明确数量和顺序 | 显式0..N；非空按1开始连续有序，不重复、不缺位。 |
| 参数类别 | 场景、存在、特征等已经正式声明的类别；现有三类编码不由本规范扩展。 |
| 类型/概念约束 | 正式FT及其合法表示；必要FC/EC约束不从名称猜测。 |
| 角色及取值要求 | 明确哪个对象/输入项、如何绑定到函数参数。 |
| 必要限制 | 与全方法或具名条件关联，不能把限制写成默认实参。 |

规格由方法函数登记部分经方法记录面提交。任务按5260复制规格到Vt专属实例并绑定具体F，执行时读取其内联值或强类型值引用；不能用裸值替代实参绑定身份。方法读取完整任务参数后机械赋值。一次真实执行不能回写共享Vm规格。

方法及具体配对的可靠性评估归方法治理；用C身份定位配对，来源仍引用已有任务/运行事实。命中数、支持数、反例数和误差统计可重建或缓存，不参与条件/结果定义身份，不新增第二样本权威仓。

## 7. 配对树及两种拆分

### 7.1 组织和基数

关系包括：方法到根C、C到唯一R、子C到唯一父C、具名来源和治理引用。R的组织层级由配对和C父关系推导，不另建可独立变化的结果父树。方法内无环、无多父，全部C/R可从方法头完整到达，子C和R不跨方法。

分支出现不删除父配对；父配对仍有效时保留粗粒度用途。父定义被真实反例否定时转入知识修订/治理，不能因保留节点就继续声称父范围全部可靠。同一输入多分支命中时必须返回完整候选及差异，不靠遍历首项或深度自动决定采用。

### 7.2 横向方向拆分

横向只按具名结果方向区分。在其它相关条件可比、沿明确参数变化取得连续或相邻有效样本时，一旦确认被改变特征的效果方向改变，就必须形成不同方向的配对分支。

方向必须绑定第5节的具体判定量及参照。动作前后增减、相对目标的残差方向、参数增加时输出曲线的趋势是不同量；未经显式规则不得相互代用。轮廓非负距离没有可证明的反向时不伪造负方向。量化零、无变化与读取失败分别处理。

测量抖动不自动证明真实转向。分界只定位到现有样本及规则能够支持的范围；尚不能确定精确边界时保留待补观察的过渡范围，不将未采样区间补成事实。需要补观察/试验时由合法任务取得，不由数据CRUD主动执行动作。多个结果以明确的方向组合区分，不丢失其角色和关联。

### 7.3 竖向精度拆分

竖向在既有合法范围内形成更细条件—结果配对，目的是提高预测和调用精度。可以从0..MAX逐层细分到相邻刻度如0..1；此处1必须是该FT实际表示和量化合同的粒度，不是所有特征共用的物理精度。

每次子域严格缩小，端点、开闭边界、允许集合和对应结果来源完整。数值连续范围不能填平已知空隙；结构值按固定代表、比较规则和允许差异形成更细允许集合，不能拆值节点编号。数据编码分辨率不证明传感器达到同等精度。

分割依据和停止条件来自正式类型/细分规则及真实任务需要：达到所需精度、最小合法粒度、无新增有效材料或资源预算时停止当前细分。不得默认全域均分、预建所有叶、次数增加就减半误差或用一次样本反复递归冒充新观察。尚无具体分割规则时保留已形成知识，只停止该自动细分分支。

横向与竖向可以交替；关系附带拆分性质及所细分输入位置/规则引用，但不新增“横向节点”“竖向节点”类型。精度细分不能改变动作、角色、FT或比较含义，改义须形成新定义并重新评审。

## 8. FT粗召回与后续细查

查找固定顺序：

```text
目标正式FT
→ 按可改变FT检索方法
→ 回读命中方法及各自完整配对
→ 细查方向、目标/区间、对象和参数条件
→ 在任务执行前阶段选择、实例化与冻结
```

1. 粗召回输入为FT及明确扫描范围/预算，输出去重方法、命中来源、完整性及结构缺口。方向、区间、目标值、名称、代价不成为粗召回精确相等门槛。
2. 多FT目标可分别召回并在应用层核对是否由一个方法合法覆盖；不得把多个方法各自可改变一项误报为单方法可同时改变全部项。
3. 方向、区间和目标细查绑定真实目标合同，调用二次特征定义/求值；必须保持“方法—条件组—结果组”的对应，不拼接跨分支有利项。
4. 5260中的筹办仍只找方法、读候选条件并核验当前具备性，不做适用性裁决或采用；后续执行前选择才裁决效果、限制、安全与代价。服务的读取/静态投影不代替任务决策。
5. 查找未完成、预算不足、比较失败、结构缺口不是方法不存在。候选非空但全不适用，与完整范围无能力候选分别报告。
6. 方向/区间符合只证明该项效果兼容，不证明全部条件具备、已获现实授权、函数可调用或目标必然达成。
7. 登记头无配对时不能用于普通目标达成承诺；试验入口和风险边界须由专项任务合同给出，不能自动执行探索。

能力投影用后可弃，不保存第二用途/结果账。历史“六项”只可作为从完整定义得到的兼容视图，不继续作为新查找或新字段全集。

## 9. 从任务结果完善方法

学习仍区分练习、尝试和因果反推：练习复验已有方法，尝试在合法任务与安全边界内探索条件/参数/效果，因果反推从概念化因果和可控动作形成候选。学习或练习方法A处理目标方法B时，两套方法身份、Vm、规格和运行来源严格分开，不将B的实参当作A自身环境。

基本路径是同次真实材料形成配对支持，发现方向差异后横向分支，发现可提高精度的对应关系后竖向细分，再由后续任务复验：

1. 按同一次任务执行关联实际条件、实参、来源方法/配对及原预测、实际动作、独立观察和任务验证。不得拆开样本左右集合任意配对。
2. 成功、失败、额外结果和反例都可供学习；未执行、未观察、来源不完整和技术失败不能作为某效果无效的正常反例。
3. 条件相同却出现明显不同结果时检查遗漏条件、干扰、不同输入及观察误差；不能只把结果范围无限拆小或宣称结果必然唯一。
4. 预测相符、目标达成及归因成立是不同结论。任务成功不证明所有配对可靠，结果相关性不单独证明因果。
5. 形成候选差异及来源，经独立学习/方法评审后由方法owner发布。普通任务不等待学习完成，也不由验证器直接提高方法可靠性。
6. 定义域和配对关系改变不覆盖本轮冻结内容。采用既有内容更新或学习新代际合同，保留来源及历史；已发布新知识只供后续任务重新选择。
7. 精确计数、最低样本要求、噪声控制和分割算法须有真实规则来源，不把旧“三次命中”自动解释成方法可靠或细分许可。

调用期学习材料按具名共同截止读回，按任务/执行轮次、状态/动态/因果来源、方法内容版本、结果 / 验证 / 停止收束及规则确定组合、排序和去重。正式效果差异只消费已收束且来源完整的实际执行与独立验证材料；任务完成结算仅在存在时引用，不是失败 / 取消反例的前置。失败 / 取消本身也不证明方法无效，仍须满足本节反例准入。冲突、过期、非法和来源缺失不得由统计层修补。候选差异区分新增、保留、移除、替换、未知与冲突。工程日志、幂等账、事务、恢复见证和消费水位不进入学习语义或样本计数。

无父代函数登记头由5360的限定登记合同处理。首代完整配对及新知识正式发布仍须具备合法来源、独立评审、完整结构与可追溯发布；本规范不以一个头或一次成功绕过这些条件。

## 10. 方法类所需能力

| 面 | 逻辑操作集 | 边界 |
| --- | --- | --- |
| 结构记录 | 建立/查询登记头及函数绑定、Vm规格、共同约束 | 只接收已裁决结构；不会运行函数。 |
| 结构记录 | 完整建立/读回/修订/退出配对，读取整树/子树及历史 | C、R、归属和必要关系共同成立；不公开半对。 |
| 结构记录 | 建立/调整细分关系、来源/治理关联、引用保护 | 机械校验同方法、单父、无环及完整引用；不自动学习。 |
| 检索读取 | 按可改变FT粗召回、完整结构/配对/规格/静态投影读取 | 零业务裁决，不因首项命中提前报告完整。 |
| 方法应用 | 条件核验、结果方向/区间求值、提供预测材料 | 复用二次特征；任务仍拥有采用与效果验证。 |
| 学习/治理应用 | 任务材料分析、横竖细分候选、评审申请、授权后的发布和退出 | 不产生任务事实、执行许可或第二数据owner。 |

这些是逻辑能力，不是新C++函数签名。完整读取必须限定数量和一致截止，返回完整内容或明确非成功，不以截断树、遗漏分支和混合当前/历史冒充成功。运行材料、世界状态/动态及任务结果只经各自正式owner取得。

## 11. 一致性、历史与失败

同义登记/发布可重入，异义冲突零覆盖；已用身份和关系编码不可复用。方法结构写入仍遵守既有共同事实截止、事务、幂等、发布未知原请求收敛和历史读回合同，这些不变成方法效果语义字段。

完整配对发布至少包括C、R、所属方法、条件成员、结果成员、全部必要引用、配对及父/根组织；学习修订保护旧引用。跨概念owner和方法owner不宣称无合同的大事务，引用概念先完整发布再进入方法配对。
