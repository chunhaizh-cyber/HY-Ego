## 1. 根定位

概念是从世界树中的具体事实或其它已发布事实中抽取共同结构后形成的独立抽象身份。概念不是世界节点、世界事实副本、名称词条、解析标签、显示分类或索引项。

世界首先由场景构成。唯一世界根及多层场景形成世界树主体；场景、存在、特征、状态和动态等事实在这棵树中取得位置。概念空间不再建立存在、特征、动态三个独立本体总根，也不把因果链根作为第四个世界外概念总根。存在、特征和动态概念通过显式世界挂接关系依附世界树，并随世界事实、合法抽象和用途逐步完善。因果链保持独立，只引用已发布因果信息及必要概念角色。

场景自身不建立场景概念族。场景需要宏观描述时以同一节点作为存在处理；存在需要微观描述时以同一节点启用场景视角。由此形成的世界事实可以支持存在、特征或动态概念，但不改变场景/存在的稳定身份和唯一结构父。

## 2. 独立身份与类别

每个正式概念具有独立概念身份，不复用世界树中的场景、存在、特征、状态、动态、关系、因果或语言记录身份。世界事实退出、名称变化或投影清空不得改变概念身份；概念退出也不得删除来源世界事实。

普通概念至少由以下结构共同成立：

```text
概念稳定身份
+ 不可变概念类别（存在 / 特征 / 动态）
+ 完整抽象签名
+ 零个或多个同类别直接上位概念
+ 一个或多个首次世界事实支持或世界位置挂接
+ 零个或多个定义约束
+ 生命周期、来源与发布证据
```

类别不是概念节点或总根身份。不得用词条、名称、外部词性标签、世界事实首项、首次观察顺序、索引键或本地枚举代替概念身份、类别或抽象签名。

## 3. 世界挂接与概念图

世界挂接关系的语义方向是“已发布世界事实或世界位置支持该概念”。它使概念图能够从世界树的相应位置展开，但不把概念变成世界树普通子节点，不参与场景/存在的单父和无环裁决，也不取得世界事实写入权。

1. 一个概念可以挂接多个世界位置；一个世界事实也可以支持多个概念类别。
2. 建立普通概念时至少有一项已发布来源或挂接依据。来源必须按其公开合同在同一截止读回，不能由名称、缓存、当前画面或索引猜测。
3. 顶层概念可以没有直接上位概念，但必须有可回查的世界挂接；非顶层概念的全部直接上位必须与其类别相同。
4. 同类别直接上位关系构成多父无环图。只保存直接边，不保存传递闭包、固定层号、坐标、锥面或显示路径。
5. 概念支持关系退出不删除概念或世界事实。历史支持仍可审计；当前投影只能显示请求截止仍合法的挂接。
6. 跨类别语义只能用具名定义关系表达，不能伪装为上下位关系。

世界树投影的逻辑方向为：

```text
世界场景或世界事实
-> 直接挂接的顶层/适用概念
-> 同类别下位概念图
-> 其它支持世界事实引用
```

同一概念出现在多个世界位置投影中只是同一身份的多处引用，不复制概念，不新增世界结构父。

## 4. 三类概念

| 类别 | 负责抽象 | 不负责 |
| --- | --- | --- |
| 存在概念 | 身份对象、材料对象、组成结构及可作为世界存在处理的对象类别 | 场景结构父、具体实例当前值、语言名词身份 |
| 特征概念 | 特征类型和值域、关系投影、状态性描述、二次至n次派生特征 | 具体值事实、任务判断结果、形容词或副词身份 |
| 动态概念 | 变化、过程、动作及由动态事实支持的抽象结构 | 具体动态实例、动词身份、因果结论 |

二次至n次特征仍属于特征类别，不按阶次建立概念总根、节点族或owner。二次关系概念的定义由7170/7180展开；实际派生结果和当次输入只作来源，不进入通用定义。

存在概念从自身特征、子存在组成及关系中提取抽象。分割聚合建立或消费部分—整体事实，分类聚合依据共同约束形成上下位；两者不合并为一种关系。零约束不再“复用存在根”，只能由具名抽象规则形成有世界挂接依据的顶层存在概念。

动态概念以主体/参与角色的存在概念、关键变化的特征概念或合法子动态概念及必要时间约束组成；具体主体、具体场景和绝对发生时间不进入通用签名。定义必须能由真实状态/变化求值，不循环等待自身成立。

## 5. 因果链独立边界

因果信息是1190定义的概念化规律，不建立因果实例类。因果链不挂入世界树单父结构，也不归入存在、特征或动态概念图；它以独立链身份、方向、直接组成和参与者角色映射组织已发布因果信息。

一个已发布因果信息可以构成最小链；多个因果信息可以形成方向一致、角色可衔接且连通的有限有向结构，并允许共同原因、替代原因和共享分支。链不得复制原因果条件、动作、结果或证据，不持久化间接因果边、固定层号和展开路径。应用按目标、范围和截止形成的因果层次是值式投影。

预测、相关候选、样本分组和未闭合链都不冒充已发布因果信息或世界事实。零因果实例、主动/被动因果及证据边界继续服从1190、4310—4340。

## 6. 概念形成与唯一性

概念由DATA之外的抽象业务依据已发布事实形成候选，顺序固定为：

```text
取得一致截止的来源事实和合法规则
-> 选择存在、特征或动态类别
-> 提取共同结构和定义约束
-> 形成规范化完整签名
-> 在同类别查找当前同义概念
-> 同义复用，异义建立新身份
-> 同次发布概念、类别、初始挂接/支持及必要直接上位和定义关系
-> 完整读回
```

同类别、同签名规则和同一完整签名只能有一个当前概念。名称、词条、外部词性、语言习惯、相似度、索引首项和单个样本不能裁决唯一性。一次完整事实可以形成具名定义，不设置固定样本次数；数据层只保存调用方已裁决的结构，不判断抽象是否正确。

首次世界挂接、全部定义端点和直接上位必须在分配身份前核验。入口失败、端点缺失/退出、跨类别上位、成环、事实代次漂移、资源失败或内部不一致均不得暴露半概念。发布后读回失败不得假称回滚，只能以原键原请求收敛。

## 7. 特征概念、名称与语言

普通值域特征概念的签名为正式特征类型和规范化值域，细则由7160展开。准确F保持固定类型和值及可选名称，不维护概念总根、当前值历史集合或分裂树。类型完整域概念只是普通特征概念，不是永久根；同类概念允许多父。

概念名称由2210的概念—词条关系表达。一个概念可以有多个名称，同一词条可以命名多个概念或多个类别。自然语言只在概念形成后承担名称和表达；词条、读音、词性或解析标签不得建立概念、选择类别或改义。

标准解析链为：词出现及语言位置 -> 名称关系召回全部候选 -> 逐项正式读回类别和结构 -> DATA消歧。零项、多项和上下文不足都是正常结果，不改变概念事实。

## 8. DATA分层与公开读取

DATA-L1只保存节点、关系和值。DATA-L2概念结构服务负责概念身份、不可变类别、抽象签名、上下位、定义、世界挂接/支持、生命周期及结构化CRUD。DATA-L3只组合世界树与概念服务的公开读取，形成调用方拥有的值式投影，不直达L1，不复制CRUD，不保存第二图权威。

公开读取至少提供：

- 按概念读取当前/历史完整结构；
- 按世界节点或事实读取直接挂接概念和有界同类展开；
- 按概念读取直接上位、直接下位及支持事实；
- 按词条读取全部未过滤名称候选；
- 按因果链读取直接组成和有界值式展开。

请求必须明确事实截止、范围及非零数量/边预算。成功返回实际截止、概念类别、直接边和所选支持引用；保留全部多父边，不生成传递边。预算不足、端点缺失、跨截止、重复身份、跨类别直接边、环或引用闭包不一致返回精确结构化非成功和零假完整载荷。

## 9. 生命周期与投影

普通概念生命周期为活跃、冷却、退役和不可逆退出，细则由7140展开。类别没有独立节点和生命周期；不得为了保存旧根ABI而创建隐藏总根、永久占位概念或全局静态根编码。

概念图、世界挂接视图、祖先/后代、名称候选、活动图和统计都是可重建投影。清空投影不改变概念、世界事实或支持关系；投影与权威结构冲突时丢弃投影并返回结构化错误。

## 10. 迁移和完成边界

现行代码中的四本体根交付、根归属字段、按根创建入口、静态根引用和阶段18四根初始化均属旧物理合同。它们在新数据合同完成迁移前只作为存量历史读取边界，不得产生新概念、新根或新的生产依赖。迁移必须以新合同、消费者切换、旧写入零可达和独立读回为门禁，不能把字段改名当作完成。

本规范发布只完成机器语义裁决，不声明概念代码、存量数据、普通应用装配、阶段18或控制面板投影已经迁移。

## 11. 禁止规则

1. 禁止建立存在、特征、动态或因果链概念总根。
2. 禁止把概念挂接边当作场景/存在结构父，或把实例组织锚当作概念根。
3. 禁止让概念与世界事实共用身份或复制世界事实。
4. 禁止把多父概念图改写为单父权威树。
5. 禁止由概念关系反向补造未发布世界事实。
6. 禁止让预测、相关性或任务局部判断冒充因果事实。

## 12. 最低验证

合法实现至少证明：

- 唯一世界根可读，三类概念均无独立总根；
- 概念类别、身份、签名和世界挂接完整；
- 顶层概念可直接挂接世界位置，非顶层保持同类别多父无环；
- 同一概念多位置投影不复制身份、不增加世界结构父；
- 场景四个实例组织锚继续存在且不进入概念图；
- 因果链独立、零因果实例，预测不写入事实；
- 旧根入口零生产可达，失败和预算不足不返回假完整投影。
