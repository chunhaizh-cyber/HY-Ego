# 2220 根规范 概念空间

编号：2220

日期：20260812

状态：正式根规范

直接上级规范：0050。

直接依赖规范：1100、1110、2200。

相关边界规范：1120—1190、2210、4010、4020、4060、4190、4200、7100、7140、7200、7210。

## 1. 根定位

概念是从世界树中的具体世界事实、语言事实或其它已发布事实中抽取共同结构后形成的独立抽象身份。概念不是世界节点、世界事实副本、名称词条、词性标签、显示分类或索引项。

世界树与概念空间是两个正交维度：

```text
世界树
-> 组织具体存在、场景、特征、状态、动态、关系、因果及语言记录
-> 回答“具体存在什么、发生什么”

概念空间
-> 按概念维度组织抽象身份、上下位和事实覆盖
-> 回答“这些具体事实可以抽象为什么”
```

“世界树是平面三角、每个概念维度在其上形成三维锥体”是本规范的结构模型：世界事实构成共同基底，每个概念维度具有独立维度根，概念从具体到抽象逐层汇聚到该根。该几何模型不授权持久化坐标、高度、锥体编号或显示路径；权威机器事实只由身份和具名关系成立。

## 2. 独立身份

每个正式概念具有独立概念身份，不复用世界树中的存在、特征、状态、动态、关系、因果或语言记录身份。世界事实退出、名称变化或显示投影清空不得改变概念身份；概念退出也不得删除其来源世界事实。

概念至少由以下结构共同成立：

```text
概念稳定身份
+ 唯一概念维度根
+ 完整抽象签名
+ 零个或多个直接上位概念
+ 零个或多个定义约束
+ 生命周期
+ 来源与发布证据
```

不得以词条、名称、词性、世界事实首项、首次观察顺序、索引键或本地枚举值代替概念身份。

## 3. 词性维度与概念维度根

每一种正式登记的自然语言词性对应一个概念维度及一个独立概念维度根。词性用于选择抽象方向；概念维度根是该方向的最高抽象身份，两者不能合并为裸枚举或显示标题。

第一阶段至少允许登记以下维度族：

| 词性或语言作用 | 主要抽象来源 |
| --- | --- |
| 名词 | 存在、场景、材料、事件等具体对象事实 |
| 形容词 | 特征、属性值、形态和状态事实 |
| 动词 | 动作、动态和变化过程事实 |
| 副词 | 程度、时间、频率和方式等修饰事实 |
| 数词、量词 | 数量、单位和计量结构事实 |
| 方位词、介词 | 空间、时间和对象关系事实 |
| 连词 | 并列、条件、转折和因果等组合关系事实 |
| 代词及其它功能词 | 指代、语法和语言使用事实；不自动建立外部对象概念 |

登记新词性必须建立新的概念维度根或明确复用已有正式词性身份；不得因为实现方便把不同词性压入一个通用根。一个词条在不同语言位置具有不同词性时，可以分别召回不同概念维度中的概念。

词性只选择维度和缩小候选，不能凭自身建立具体概念、选择唯一概念或证明某个世界事实属于该概念。词性与概念维度的登记关系是正式结构，外部分词器标签只是候选材料。

## 4. 世界事实作为叶级成员

世界树中的具体实例或事实通过“世界事实支持概念”关系接入概念空间，并在从该概念维度向下展开的投影中成为叶级成员：

```text
概念维度根
-> 上位概念
-> 下位概念
-> 叶级世界事实引用
-> 世界树中的唯一具体事实身份
```

叶级成员只引用世界树权威身份，不复制世界节点、值、状态、动态或关系。控制面板可以把引用目标显示为概念树叶子，但概念空间不拥有该世界事实。

同一世界事实可以同时支持多个概念，也可以跨多个概念维度成为多个叶级成员；同一概念可以由多个世界事实支持。支持关系必须保存来源、生命周期和发布证据，不能由显示位置或索引命中补造。

语言记录及词出现也是世界树可记录的具体事实。功能词没有外部对象实例时，可以由相应语言事实支持语言结构概念；不得因此伪造外部存在、状态或关系事实。

## 5. 概念图结构

同一维度内的直接上位关系组成有向无环图：

1. 每个非根当前概念必须可到达且只归属于一个概念维度根。
2. 一个概念可以有多个直接上位概念；不得为了显示成单父树删除合法父边。
3. 直接关系只保存直接边，传递闭包、层级高度、锥面和树形路径均为可重建投影。
4. 不同概念维度之间不得建立上下位关系；跨维度语义使用具名跨维度概念关系。
5. 一个世界事实支持多个维度或多个概念不构成概念图成环。

## 6. 概念形成与唯一性

概念由 L5 之外的抽象业务依据已发布事实形成候选，并按以下顺序裁决：

```text
取得同截止世界事实或语言事实
-> 选择正式概念维度
-> 提取可回查的共同结构和定义约束
-> 形成完整抽象签名
-> 在该维度精确查找已有概念
-> 同义则复用，异义则建立新概念候选
-> 业务准入通过后发布概念结构
-> 建立事实支持关系
-> 完整读回概念、上位关系和叶级事实引用
```

同一概念维度、同一签名规则和同一完整抽象签名只能有一个当前概念。名称、词性、词条、语言习惯、相似度、索引首项和单个样本不能裁决概念唯一性。

概念形成不要求多个样本达到固定次数；一次完整事实可以形成具名候选，但是否足以发布为稳定抽象由对应业务规则裁决。数据层只保存调用方提交的强类型概念结构，不判断抽象是否正确。

## 7. 名称、词条与语言使用

概念名称由 2210 的概念—词条具名关系表达。一个概念可以有多个名称，同一词条可以命名多个概念或多个维度中的概念。

标准语言解析链为：

```text
词出现及当前词性候选
-> 选择概念维度
-> 由词条反查该维度中的名称关系
-> 得到零个、一个或多个概念候选
-> 结合上下文消歧
```

词性、词条和名称关系不改变概念抽象签名；概念形成也不得反向改写历史语言位置的词性。

## 8. 写入、读取与分层

L1 只保存节点、关系和值。L1—L5 的概念结构服务只负责独立概念身份、维度根、上下位、定义约束、事实支持、名称关系所需结构及其增删改查、同截止读取、幂等、引用保护和生命周期。

L5 之外业务层负责选择抽象维度、提取共同结构、判断概念候选是否成立、复用或建立概念、接受名称及完成语境消歧。数据层不得从世界树扫描后自行宣称概念成立，也不得让词性直接触发概念写入。

概念空间公开读取至少分别提供：

- 按概念读取当前 / 历史完整结构；
- 按维度根读取直接概念或有限展开投影；
- 按世界事实读取所支持的概念组；
- 按概念读取直接支持事实组；
- 按词条和词性维度读取名称候选组。

## 9. 生命周期与投影

概念的当前、冷却、退役和不可逆退出由 7140 展开。概念维度根永久存在，不得冷却、退役、删除或被普通概念替换。

概念树、锥体、叶级世界实例、祖先集、后代集、根可达摘要、名称候选、活动图和统计均是从当前概念、关系和世界事实引用形成的可重建投影。清空这些投影不得改变概念、世界事实或支持关系。

## 10. 禁止规则

1. 禁止把世界树根与任一概念维度根合并。
2. 禁止把概念树作为世界树的子树或把世界树作为某一概念树的子树。
3. 禁止让概念与世界事实共用身份或复制叶级世界事实。
4. 禁止把词性枚举、词条、显示标题或索引项作为概念本体。
5. 禁止按词性直接创建或选择唯一概念。
6. 禁止把多父概念图强制改写为单父权威树。
7. 禁止用几何坐标、高度或锥体显示位置承载概念语义。
8. 禁止由概念关系反向补造未在世界树发布的具体事实。

## 11. 验证合同

验证至少覆盖：

- 世界根与多个概念维度根身份独立；
- 每个登记词性恰有一个当前维度根；
- 概念独立身份、同维度签名唯一和跨维度同名并存；
- 同一世界事实跨维度支持多个概念；
- 同一概念由多个事实支持；
- 叶级引用不复制或改写世界事实；
- 同维度多父 DAG、唯一维度根可达和跨维度上下位拒绝；
- 词性只选择维度、不直接建立或裁决概念；
- 清空锥体 / 树形投影后权威结构和读回等价；
- 概念或支持关系退出后历史仍可回查，来源世界事实不被误删。
