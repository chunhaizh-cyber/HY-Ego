## 1. 根定位

概念是依据完整信息定义，或从世界事实及其它已发布事实中抽取共同结构后形成的独立抽象身份。概念不是世界节点、世界事实副本、名称词条、解析标签、显示分类或索引项。

世界由场景构成。程序持有唯一的物理全局根，现实、自然语言、模拟、内部治理及今后新增的各类世界，各以一个世界根场景挂在其下；各世界在逻辑上相互独立（见 [1150](1150_根规范_场景节点.md)）。场景、存在、特征、状态和动态等事实在所属世界中取得位置。

概念空间保持四本体根布局：**存在、特征、动态、因果链**。四个根是先天建立的正式概念节点，各恰一，由全局变量持有受保护引用，是四类概念的顶层；不为根另建词条。存在、特征和动态概念在各自根树内组织，因果链是四根中独立的一根，只组织已发布因果信息。功能词不进概念树，只取得合法词条与语言结构作用。

统一表示、信息存在及先天概念生成的详细合同由 [7165](7165_子规范_概念统一表示与先天概念生成.md) 唯一展开，其首要目的是让语言含义与系统认知共享概念、实例和关系；语言消费由 7260 展开。

场景自身不建立场景概念族。场景需要宏观描述时以同一节点作为存在处理；存在需要微观描述时以同一节点启用场景视角。

## 2. 独立身份与类别

每个正式概念具有独立概念身份，不复用世界中的场景、存在、特征、状态、动态、关系、因果或语言记录身份。世界事实退出、名称变化或投影清空不得改变概念身份；概念退出也不得删除来源世界事实。

普通概念至少由以下结构共同成立：

```text
概念稳定身份
+ 概念类别（存在 / 特征 / 动态），与所属根一致
+ 完整抽象签名
+ 一个或多个同类别直接上位（顶层普通概念的直接上位就是所属根）
+ 零个或多个已经成立的世界事实支持或世界位置挂接
+ 零个或多个定义约束
+ 来源与生命周期
```

每个普通概念都至少有一条同类别上位链通到所属根，不存在没有上位的普通概念。类别不是另造的隐含总根身份。不得用词条、名称、外部词性标签、世界事实首项、首次观察顺序、索引键或本地枚举代替概念身份、类别或抽象签名；功能词词条不得冒充概念根或普通概念。

代词概念不属于本概念空间：它是自然语言世界中由语言owner维护的信息存在，定义形状、作用域、初始化与目标规则由 [1110](1110_根规范_指代.md) 承载，字段由 7233 规定；不进入四本体根，不套用普通概念模板，也不能把交互角色、参照中心规则或变量绑定关系偷放进普通存在概念签名。

不设独立的集合条件概念。由多个不同特征类型共同构成的条件（如“有事”）以复合特征表达，只在特征类别中实现（复合特征定义见 4120，概念见 7160），不另建类别、总根或存储 owner。

### 2.1 结构型信息存在概念与先天来源

具体任务、方法属于信息存在，归属内部治理世界的场景；具体需求不是存在，不归属场景（0050第1.4节）。需求、任务、方法的类别概念是**存在根的直接下位**，使用独立概念身份，不复制其业务实例，也不使业务节点自动成为普通世界存在节点。其共同结构可由正式领域定义直接形成，不按每个业务名称另建本体类别、根或 owner。

完整定义须表达“特征类型→范围概念”、必需/可选、基数、有序/无序组织、互斥分支、阶段及跨内容关联。具体对象引用与概念定义引用有类型地区分；私有 schema 锚或字段名不是概念定义。概念仍由合法唯一提供者核验、查重、发布及读回，不由语言解释器或各业务模块自行维护第二概念权威。

正式先天信息结构定义是实例专属投影和后天共同归纳之外的合法形成来源，类别可在零实例时初始化。先天定义、实例专属概念和后天归纳分别成立；相互依赖定义须完整闭合后才交付，重复初始化复用同义定义，既无样例也不增加经验统计。

## 3. 世界挂接与概念图

世界挂接关系的语义方向是“已发布世界事实或世界位置支持该概念”。它使概念图能够从世界的相应位置展开，但不把概念变成世界树普通子节点，不参与场景/存在的单父和无环裁决，也不取得世界事实写入权。

1. 一个概念可以挂接多个世界位置；一个世界事实也可以支持多个概念类别。
2. 声明的世界挂接端点必须已发布并可读回，不能把待建实例、名称、缓存或当前画面当作证据。完整定义已发布但暂未被世界实例引用的概念是合法状态。
3. 非顶层普通概念的全部直接上位必须与其类别相同；顶层普通概念的直接上位为所属根。
4. 存在概念、动态概念的同类别直接上位关系构成多父无环图；特征概念是例外，在其类型根下为单父值域层级（7160）。只保存直接边，不保存传递闭包、固定层号、坐标或显示路径。
5. 概念支持关系退出不删除概念或世界事实；投影只显示当前仍合法的挂接。
6. 跨类别语义只能用具名定义关系表达，不能伪装为上下位关系。

同一概念出现在多个世界位置投影中只是同一身份的多处引用，不复制概念，不新增世界结构父。

## 4. 三类普通概念

| 类别 | 负责抽象 | 不负责 |
| --- | --- | --- |
| 存在概念 | 以自身特征值域及已知子存在概念组织的身份对象、材料对象、信息存在及可作为世界存在处理的对象类别 | 场景结构父、具体实例当前值、语言名词身份、关系角色与端点 |
| 特征概念 | 特征类型和值域、关系投影、状态性描述、二次至 n 次派生特征 | 具体值事实、任务判断结果、形容词或副词身份 |
| 动态概念 | 变化、过程、动作及由动态事实支持的抽象结构 | 具体动态实例、动词身份、因果结论 |

二次至 n 次特征仍属于特征类别，不按阶次建立概念总根、节点族或 owner；二次关系概念由 7170/7180 展开。

### 4.1 存在概念的形成与演进

根概念先天建立，因此“先有概念、后有实例”在根这一层天然成立。存在概念按以下顺序演进（与 [1140](1140_根规范_存在节点.md) 一致）：

1. **以存在根实例化**：存在实例化时可以没有任何特征，直接引用存在根；此时尚无专属存在概念，只在“存在”层次可匹配和归类。
2. **派生专属概念**：存在添加特征后，派生自身专属存在概念，挂在存在根下；之后特征变化时原地同步其特征投影。
3. **派生中间层**：同类专属概念增多后，按明确归纳需要从至少两个来源提取共同特征值域及共同子存在概念，派生位于存在根与专属概念之间的中间层概念（7110）。

存在概念只从自身特征值域及已知子存在概念中提取抽象。父子存在和其它关系是读出这些信息的物理组织，不是概念定义、角色语义或概念图边。分割聚合建立或消费部分—整体事实，分类聚合依据共同约束形成上下位；两者不合并为一种关系。节点增加不触发全局扫描、自动穷举或未被请求的概念生成；与既有中间层概念的匹配、归类属于识别或归纳步骤，不是建立实例的前提。

动态概念以主体/参与角色的存在概念、关键变化的特征概念或合法子动态概念及必要时间约束组成；具体主体、具体场景和绝对发生时间不进入通用签名。定义必须能由真实状态/变化求值，不循环等待自身成立。

## 5. 因果链独立边界

因果信息是 1190 定义的概念层规律：条件和结果以存在概念或角色、特征类型、值域概念和动作概念表达，具体存在、准确值和时间只属于作为实例的动态。因果链不挂入世界结构，也不归入存在、特征或动态概念图；它以独立链身份、方向、直接组成和参与者角色映射组织已发布因果信息。

一个已发布因果信息可以构成最小链；多个因果信息可以形成方向一致、角色可衔接且连通的有限有向结构，并允许共同原因、替代原因和共享分支。链不得复制原因果条件、动作、结果或证据，不持久化间接因果边、固定层号和展开路径。应用按目标和范围形成的因果层次是值式投影。

预测、相关候选、样本分组和未闭合链都不冒充已发布因果信息或世界事实；归类向上抽象不以因果链根为终点。

## 6. 概念形成、修订与唯一性

概念树服务负责概念的结构增删改查。调用方提供已裁决的类别、完整定义及规范化依据；数据服务核验格式、引用、唯一性和生命周期，不自行推定抽象含义。可复用定义不包含仅用于描述当次实例的宿主身份或发生事实。

概念区分两类：存在专属投影（按所属存在维护，包含当前确定值，见1140）与可共享的类别概念。下列唯一性与同义复用只适用于可共享的类别概念；专属投影即使内容暂同也不合并。同类别、同签名规则和同一完整签名只能有一个当前类别概念。名称相同、相似度或索引首项不证明同义；读取失败、歧义、退役或发布未知都不等于未找到。并发创建必须精确复用或返回真实冲突，不能生成两个当前同义身份。

**认知可以漂移**：概念按当前认知维护，可以随实例材料和归纳原地修订其值域、定义约束和上位位置，不保留旧定义版本或形成过程。引用该概念的状态、动态和其它事实按当前概念解释，事实的稳定性只由准确值和强时间保证。类别概念修订时若发现已有同义概念，直接复用该已有概念，不再新建；被修订概念的全部引用（实例、下位概念、名称关系、因果角色）改接到复用的概念，原概念按引用归零退出（7140）。

概念成功而后续世界操作失败时，保留合法概念并报告实际阶段；重试先查询并复用，不能自动删除可能共享的概念。发布后读回失败须以原请求核对真实结果，不假称回滚或继续制造新身份。

## 7. 特征概念、名称与语言

普通值域特征概念的签名为正式特征类型和规范化值域，细则由 7160 展开。实例特征 F 保存当前值、去重历史值及命中次数、标准值和聚合值域（1130），其所属概念随实际历史同步；概念不复制实例准确值。类型完整域概念只是普通特征概念，不是根；特征概念在类型根下单父（见第3节第4条）。先天定义的 FT 可以在类型初始化阶段由概念唯一 owner 同步形成其完整域顶层概念，挂在特征根下；FT 节点与概念节点身份独立。

概念名称由 2210 的概念—词条关系表达。一个概念可以有多个名称，同一词条可以命名多个概念或多个类别。自然语言只在概念形成后承担名称和表达；词条、读音、词性或解析标签不得建立概念、选择类别或改义。词条所指类型已知而定义未知时，不新建概念，名称直接挂到已知的上位概念Y；以后定义补齐且确与Y不同时，再在Y下派生新概念并把名称改挂过去（2210、7250）。

标准解析链为：词出现及语言位置 -> 名称关系召回全部候选 -> 逐项正式读回类别和结构 -> DATA 外消歧。零项、多项和上下文不足都是正常结果，不改变概念事实。

## 8. DATA 分层与公开读取

DATA-L1 只保存节点、关系和值。DATA-L2 概念树服务负责概念身份、类别、抽象签名、上下位、定义、世界支持、生命周期及结构增删改查。世界树服务组合概念树服务和世界信息各类的公开函数，实现世界信息增删改查及实例化流程；纯图投影仍只读。两者均不直达 L1，不复制结构写入权，不保存第二图权威。

公开读取至少能按概念读取当前完整结构，按世界节点读取直接挂接概念和有界同类展开，按概念读取直接上位、直接下位及支持事实，按词条读取全部未过滤名称候选，按因果链读取直接组成和有界值式展开。读取须声明范围；保留全部多父边，不生成传递边；端点缺失、重复身份、跨类别直接边、环或引用闭包不一致返回结构化非成功和零假完整载荷。

## 9. 生命周期与投影

普通概念生命周期为活跃、冷却、退役和不可逆退出，细则由 7140 展开；退役改接上一级或所属根。四本体根为先天形成的持久概念节点，各恰一，根不可退役；不为根另建词条。不得另造隐藏总根、第五根或永久占位概念。归类向上抽象的终点是存在、特征、动态三根。

概念图、世界挂接视图、祖先/后代、名称候选、活动图和统计都是可重建投影。清空投影不改变概念、世界事实或支持关系；投影与权威结构冲突时丢弃投影并返回结构化错误。

## 10. 禁止规则

1. 禁止另造第五根或隐藏总根；禁止功能词进入概念树；禁止为根另建词条。
2. 禁止出现没有上位链通到所属根的普通概念。
3. 禁止把概念挂接边当作场景/存在结构父。
4. 禁止让概念与世界事实共用身份或复制世界事实。
5. 禁止把存在、动态概念的多父图改写为单父权威树。
6. 禁止由概念关系反向补造未发布世界事实。
7. 禁止让预测、相关性或任务局部判断冒充因果事实。
8. 禁止为保留旧含义而并存同签名的两个当前概念。
