# 2220 根规范 概念空间

编号：2220

日期：20260815

状态：正式根规范

直接上级规范：0050。

直接依赖规范：1100、1110、2200。

相关边界规范：1120—1190、2210、4010、4020、4060、4190、4200、7100、7140、7200、7210。

## 1. 根定位

概念是从世界树中的具体世界事实或其它已发布事实中抽取共同结构后形成的独立抽象身份；概念抽象能力成立后，已发布语言事实也可以形成或支持语言结构概念。零概念启动、阶段 18 和四个初始本体根形成不得消费语言事实。概念不是世界节点、世界事实副本、名称词条、解析标签、显示分类或索引项。

世界树与概念空间是两个正交维度：

```text
世界树
-> 组织具体存在、场景、特征、状态、动态、关系、因果及语言记录
-> 回答“具体存在什么、发生什么”

概念空间
-> 按存在、特征、动态和因果链四个语言无关本体根组织抽象身份、上下位和事实覆盖
-> 回答“这些具体事实可以抽象为什么”
```

“世界树是事实平面、每个本体根在其上形成抽象锥体”是本规范的结构模型：世界事实构成共同基底，存在、特征、动态和因果链四个本体根分别组织对应抽象，概念从具体到抽象逐层汇聚到所属根。该几何模型不授权持久化坐标、高度、锥体编号或显示路径；权威机器事实只由身份和具名关系成立。

场景只负责组织世界树中的层级、成员和事实范围。场景身份、场景树根、场景父子层级和“第一棵树”等材料都不建立场景概念根，也不自动生成普通概念；场景中的存在、特征、动态和关系事实可以按本规范成为概念形成或支持材料。

## 2. 独立身份

每个正式概念具有独立概念身份，不复用世界树中的存在、特征、状态、动态、关系、因果或语言记录身份。世界事实退出、名称变化或显示投影清空不得改变概念身份；概念退出也不得删除其来源世界事实。

概念至少由以下结构共同成立：

```text
概念稳定身份
+ 唯一本体根概念身份
+ 完整抽象签名
+ 零个或多个直接上位概念
+ 零个或多个定义约束
+ 生命周期
+ 来源与发布证据
```

不得以词条、名称、外部词性标签、世界事实首项、首次观察顺序、索引键或本地枚举值代替概念身份。

## 3. 语言无关本体根、二次特征与因果链

项目概念空间固定只有四个顶层本体根：

| 本体根 | 负责抽象 | 不负责 |
| --- | --- | --- |
| 存在概念根 | 身份对象、材料对象和能够作为世界存在处理的对象类别 | 场景树层级、具体实例当前值、语言名词身份 |
| 特征概念根 | 基础特征、关系投影、状态性描述及实际二次至 n 次派生特征 | 具体值事实、任务判断结果、形容词或副词身份 |
| 动态概念根 | 变化、过程、动作和能够由动态事实支持的抽象结构 | 具体动态实例、动词身份、因果结论本身 |
| 因果链概念根 | 由一个或多个已发布直接因果事实支持的方向性因果链、共享分支和可复用因果模式 | 原始状态 / 动态、未发布相关候选、复制的因果事实、固定层号或间接因果边 |

四个根使用彼此独立的概念身份和不可变系统根角色成立，永久活跃。新增、合并、拆分或改变根语义会改变整个概念身份空间，必须先修订本规范、4240、7140 和阶段 18 合同；语言、词条、解析标签、名称、外部分词器、显示分类和运行期样本均无权增删本体根。

二次至 n 次特征本体上都属于特征根，数据结构上不为每个阶次建立独立节点族。正式派生特征统一使用特征身份，并保存非零真实阶次、直接来源特征关系、输入角色、派生规则和适用范围；阶次大于一的派生特征统称“二次特征”。二次特征概念形成后可以作为存在、动态或其它适用对象的特征使用，复用同一概念身份，不按阶次、来源或宿主复制概念。

因果链概念本体上属于因果链概念根。其完整抽象签名和定义关系只引用 1190 已发布、方向明确且版本有效的直接因果事实或同身份模板角色，并保存直接组成、方向、分支、适用范围和规则版本；一个直接因果构成最小链，多个直接因果可以形成共享分支的有向无环拓扑。同一直接因果可以支持多个因果链概念，概念不得复制原因果条件、动作、结果和证据。因果链的层次不属于概念签名或持久关系；应用给定目标、范围、版本和展开截止后，才从直接拓扑形成本次值式分层投影。

自然语言在概念形成之后承担名称和表达。词条只通过名称关系召回概念候选；每个候选属于哪个本体根、具有什么对象类型，必须从候选概念和目标对象的正式强类型结构读回。业务层可以结合本次语言位置、句法关系和上下文缩小候选，但该值式判断不能建立、改义、排除或唯一裁决概念。

## 4. 世界事实作为叶级成员

世界树中的具体实例或事实通过“世界事实支持概念”关系接入概念空间，并在从所属本体根向下展开的投影中成为叶级成员：

```text
本体根概念
-> 上位概念
-> 下位概念
-> 叶级世界事实引用
-> 世界树中的唯一具体事实身份
```

叶级成员只引用世界树权威身份，不复制世界节点、值、状态、动态或关系。控制面板可以把引用目标显示为概念树叶子，但概念空间不拥有该世界事实。

同一世界事实可以同时支持多个概念，也可以跨多个本体根成为多个叶级成员；同一概念可以由多个世界事实支持。支持关系必须保存来源、生命周期和发布证据，不能由显示位置或索引命中补造。

语言记录及词出现也是世界树可记录的具体事实。功能词没有外部对象实例时，可以由相应语言事实支持语言结构概念；不得因此伪造外部存在、状态或关系事实。

## 5. 概念图结构

同一本体根内的直接上位关系组成有向无环图：

1. 每个非根当前概念必须可到达且只归属于一个本体根。
2. 一个概念可以有多个直接上位概念；不得为了显示成单父树删除合法父边。
3. 直接关系只保存直接边，传递闭包、层级高度、锥面和树形路径均为可重建投影。
4. 不同本体根之间不得建立上下位关系；跨根语义使用具名跨根概念关系或定义约束。
5. 一个世界事实支持多个根或多个概念不构成概念图成环。

## 6. 概念形成与唯一性

概念由 `DATA` 之外的抽象业务依据已发布事实形成候选，并按以下顺序裁决：

```text
取得同截止世界事实或已发布二次特征候选材料
-> 按抽象结果选择存在、特征、动态或因果链本体根
-> 提取可回查的共同结构和定义约束
-> 形成完整抽象签名
-> 在所选本体根内精确查找已有概念
-> 同义则复用，异义则建立新概念候选
-> 业务准入通过后发布概念结构
-> 建立事实支持关系
-> 完整读回概念、上位关系和叶级事实引用
```

同一本体根、同一签名规则和同一完整抽象签名只能有一个当前概念。名称、词条、外部词性标签、语言习惯、相似度、索引首项和单个样本不能裁决概念唯一性。

二次特征概念的候选形成特别服从 1180、4150：当前比较或判断需求先使用已有特征和关系，原始事实缺失时继续观察，事实完整而表达不足时才形成最小任务局部派生候选。候选解决当前需求只证明本轮有用；是否成为正式概念由跨需求复用、抽象签名和概念业务准入裁决，不要求固定样本次数，也不得按使用次数自动发布。

因果链概念的候选形成特别服从 1190、4310、4320：动态序列分组、前置状态 / 动态筛选、相关统计和未闭合样本都只能形成因果候选；只有一个或多个正式直接因果事实已经发布，且其方向、适用范围、版本和链内连通性可回查时，才可形成因果链概念候选。发布普通因果链概念不得反向补造、改义或退出任何直接因果事实。

概念形成不要求多个样本达到固定次数；一次完整事实可以形成具名候选，但是否足以发布为稳定抽象由对应业务规则裁决。数据层只保存调用方提交的强类型概念结构，不判断抽象是否正确。

## 7. 名称、词条与语言使用

概念名称由 2210 的概念—词条具名关系表达。一个概念可以有多个名称，同一词条可以命名多个概念或多个本体根中的概念。

标准语言解析链为：

```text
词出现及其语言位置
-> 由词条反查全部当前名称关系
-> 逐项正式读回候选概念的本体根和目标对象强类型
-> DATA 外业务按 7210 结合句法与上下文形成任务局部的零个或多个对象角色候选
-> 得到零个、一个或多个概念候选
-> 结合上下文消歧
```

名称候选缺失、目标类型未形成、上下文不足、零项或多项都是正常候选状态。词条、名称关系和任务局部类型 / 词性判断不改变概念本体根或抽象签名；概念形成也不得反向改写历史语言位置的解析材料。

## 8. 写入、读取与分层

`DATA-L1` 只保存节点、关系和值。`DATA-L2` 概念结构服务负责独立概念身份、四个本体根、根归属、上下位、定义约束、事实支持、名称关系所需结构及其增删改查、同截止读取、幂等、引用保护和生命周期。

`DATA-L3` 概念空间聚合只组合 `DATA-L2` 概念及其公开引用结构，形成根视图、DAG 展开和调用方拥有的值式投影；它不写概念事实、不复制 CRUD。多父 DAG 是权威概念结构，“概念树”只是按给定根、截止和展开条件重建的显示或消费投影。

`DATA` 之外业务层负责按抽象结果选择本体根、提取共同结构、判断概念候选是否成立、复用或建立概念、接受名称及完成语境消歧。数据层不得从世界树扫描后自行宣称概念成立，也不得让词条、解析标签或任务局部类型判断直接触发概念写入。

概念空间公开读取至少分别提供：

- 按概念读取当前 / 历史完整结构；
- 按本体根读取直接概念或有限展开投影；
- 按世界事实读取所支持的概念组；
- 按概念读取直接支持事实组；
- 按词条读取全部未过滤名称候选；候选目标强类型正式读回与上下文缩小由 `DATA` 外业务按 7210 完成。

## 9. 生命周期与投影

概念的当前、冷却、退役和不可逆退出由 7140 展开。四个本体根永久存在，不得冷却、退役、删除或被普通概念替换。

概念树、锥体、叶级世界实例、祖先集、后代集、根可达摘要、名称候选、活动图和统计均是从当前概念、关系和世界事实引用形成的可重建投影。清空这些投影不得改变概念、世界事实或支持关系。

## 10. 禁止规则

1. 禁止把世界树根或场景树根与任一本体根合并。
2. 禁止把概念树作为世界树的子树或把世界树作为某一概念树的子树。
3. 禁止让概念与世界事实共用身份或复制叶级世界事实。
4. 禁止把词条、外部词性标签、任务局部类型判断、显示标题或索引项作为概念本体。
5. 禁止根据词面、解析标签或默认词到类型表建立本体根、直接创建概念或选择唯一概念。
6. 禁止把多父概念图强制改写为单父权威树。
7. 禁止用几何坐标、高度或锥体显示位置承载概念语义。
8. 禁止由概念关系反向补造未在世界树发布的具体事实。

## 11. 验证合同

合法消费者在实际使用时至少应能证明：

- 世界根、场景树根与存在 / 特征 / 动态 / 因果链四个本体根身份独立；
- 四个本体根恰各一当前身份、永久活跃，场景和语言解析标签均不建立额外根；
- 概念独立身份、同根签名唯一和跨根同名并存；
- 同一世界事实跨根支持多个概念；
- 同一概念由多个事实支持；
- 叶级引用不复制或改写世界事实；
- 同根多父 DAG、唯一根可达和跨根上下位拒绝；
- 二次特征位于特征根下、真实阶次可回查且同一概念跨宿主复用；
- 因果链概念只由已发布直接因果事实支持，链内方向和共享分支可回查，未持久化固定层号、间接因果边或展开路径；
- 候选目标类型来自正式目标结构，任务局部类型 / 词性判断只形成零至多个值式候选，不直接建立根、概念或唯一裁决；
- 清空锥体 / 树形投影后权威结构和读回等价；
- 概念或支持关系退出后历史仍可回查，来源世界事实不被误删。
