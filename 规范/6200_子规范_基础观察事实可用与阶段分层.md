# 6200 子规范 基础观察事实可用与阶段分层

编号：6200
日期：20261105
版本：v1.0
状态：正式子规范

## 1. 定位

本规范规定观察材料到基础观察事实可用的阶段分层，以及材料质量、新鲜度和枚举判断生产权边界。安全因果风险树、风险因素搜索与风险评估由6160规定；安全结算由6100规定。

直接上级规范：1160。

直接依赖规范：1130、2100、4130、4140。

相关边界规范：1150、1170、1180、6160、6210、6300。

## 2. 五个阶段不得合并

```text
观察材料取得
-> 观察帧或材料集容器成立
-> 有效可观测单位覆盖与特征材料完整
-> 基础观察事实可用
-> 安全因果风险评估成立（6160）
```

前一阶段成立不证明后一阶段成立。观察了一帧、像素可回查、质量可用、特征明确、风险已判断和风险可接受分别是不同事实。

## 3. 材料合同

基础观察材料至少携带来源外设、材料集或帧身份、采集时间、观察范围、坐标系、质量、有效可观测区域和回查索引。

深度无效、遮挡、反光、缺失、过期、冲突和不可解引用必须保留为材料质量或不可观测事实。不得填零、补背景、沿用旧值或用 `I64_MAX` 伪装当前观察。

接口层可以使用外设帧号和帧内索引；进入自我事实层后必须转换为观察材料集、观察范围、可观测单位和稳定来源关系。

## 4. 枚举判断的生产权

“已建立、已取得、已覆盖、已完成、已完备、新鲜、可用、已明确”等枚举型实例特征值必须有合法生产者、输入证据、判定规则、输出宿主、输出特征和来源动态或规则证据。

观察年龄与需求的最大允许年龄比较可以产生新鲜度证据；它不要求单独建立“判断新鲜度”本能方法。线程、任务筹办、显示、日志和只读快照不得直接写这些枚举值。

## 5. 基础观察事实可用

基础观察事实可用只证明当前限定范围内的观察材料已经满足本轮认知入口的覆盖、质量、可回查和时效要求。它不证明：

- 可观测单位已经对应存在；
- 场景风险已经明确或可接受；
- 世界对象已经确认；
- 安全值、服务值或需求满足可以写入。

低质量或过期材料不得作为正常事实提交，但仍可作为可审计失败材料，形成补观察、重新校正或父任务筹办材料。

## 6. 验证

验证覆盖材料来源、质量和新鲜度生产者、阶段隔离、枚举判断生产权，以及基础观察事实可用不推出存在对应、风险明确或核心值可写。
