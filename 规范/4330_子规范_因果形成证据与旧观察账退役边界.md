# 4330 子规范 因果形成证据与旧观察账退役边界

编号：4330

版本：v1.1
状态：正式子规范

直接上级规范：1190。

直接依赖规范：4211、4220、4310、4320。

相关边界规范：3100、3200、3300、4230、4240、5260、5350。

## 1. 定位

本规范冻结因果形成证据、零因果实例、候选和统计边界，以及旧用途观察生产账的退役规则。精确DTO、同次发生来源核验、证据索引与关系共同发布/退出由4340承接；元数据属于因果附属来源关系，不建立证据组节点。文件物理路径保留旧编号只为历史引用稳定，不授权恢复用途观察节点、阶段账或因果实例。

## 2. 形成证据

因果信息的形成证据只能引用已经发布且可回查的事实：

```text
条件来源：具体状态、存在/场景组织及必要关系事实
变化来源：具体动态及其前后状态
动作来源：4220正式动作来源关系及实际动作事实
结果来源：具体结果状态及相关动态
```

证据必须冻结非零事实截止并保存到原事实身份的强类型引用。具体事实只支持因果定义，不进入因果的参与者概念角色、条件概念、动作概念、结果状态模式或唯一键。

证据关联应以已有动态或动作事实为锚点回查同一次发生。4340 v1使用已发布动态来源闭包，动作来源无正式实现时结构化拒绝；关系身份不作为L1关系端点，值内关系身份不自动取得原生引用保护。项目不建立因果实例节点、因果样本节点、因果证据组节点或平行账；如果现有事实无法确定哪些条件、动作和结果属于同一次发生，则返回证据不足，不新建中间节点补齐。

## 3. 候选与发布分账

因果发现、历史检索、角色绑定、正负样本、反例、场景复现和确认材料都是调用方拥有的值式候选。候选不具有稳定因果身份、当前性、生命周期、恢复或下游引用资格。

候选确认后，先由因果owner发布或复用1190完整概念化定义，再分阶段关联来源证据。定义发布成功而证据关联失败时保留已发布定义并报告真实阶段，以原请求补齐证据；不得重复建同义因果，也不得因后续关联失败伪装定义未发布。

活动证据引用由因果owner维护，会阻止来源端点单独退出；释放由调用方先经4340退出关联并读回，再让来源owner清理，否则明确引用冲突，不能跨owner隐式级联。历史关系仍可回查不保证原载荷尚存，源材料已清理须返回不足。

证据新增不改写因果定义。新证据暴露反例或定义变化时，由4310重新确认并形成更窄、补完或替代的因果信息；原状态、动态和动作事实保持不变。

## 4. 非权威统计

样本数、正样本数、负样本数、反例数、命中率、稳定度、置信度、成功率、排序分和用途次数只能从指定事实截止下的正式证据确定重建，均不是因果本体字段。

统计可清空、重建或丢弃，不改变因果、状态、动态、动作、需求、任务或方法事实。单一分数、次数阈值、名称或哈希不能确认因果；不同规则的统计必须分栏，不能用版本号猜测兼容。

学习、方法评审或任务复盘需要因果材料时，调用方按共同截止只读组合状态、动态、动作、因果及必要业务上下文。组合材料没有独立节点、关系、生命周期或恢复资格，不得反写来源事实。

## 5. 旧用途观察编码退役

4010历史登记的下列编码只用于既有ABI、持久材料和历史结果解码：

```text
节点类型15：用途观察记录
关系类型18：用途观察证据角色
稳定主键命名域：用途观察记录身份
```

当前固定：

1. 不新增节点类型15、关系类型18或用途观察记录；
2. 旧数值不删除、不重排、不复义，只读历史材料不得恢复为当前生产事实；
3. 不以观察、见证、证明、审计、样本或阶段为名建立同义生产账；
4. 历史观察账不能替代缺失的状态、动态、动作和因果来源；
5. 工程幂等、事务、发布读回、恢复见证和线程水位不属于认知证据。

## 6. 具体发生的复盘

需要回答“当时为什么发生”时，调用方读取概念化因果信息并把角色临时绑定到历史具体存在，再沿证据锚点回读当时状态、动态、动作和场景。该复盘是值式解释，不发布因果实例。

只有实际事实能够满足因果条件、动作和结果的链段才能说明本次发生。能够产生相同结果但没有历史证据支持的其它因果，只是解释候选。

## 7. 非成功收口

| 场景 | 结果 |
| --- | --- |
| 来源事实缺失或已清理 | 证据不足，不补默认事实 |
| 动作未知 | 只能支持被动因果候选或已发布被动因果 |
| 事实截止漂移 | 丢弃本次组合并重新读取 |
| 预算不足 | 返回不完整，不以空组表示完整 |
| 候选未确认 | 零因果发布、零证据关系 |
| 已发布定义的证据续行 | 复用原身份，不重建同义因果 |
| 来源正式事实互相矛盾 | 内部不一致并停止受影响路径 |

## 8. 验证

验证至少覆盖具体事实零进入本体、证据锚点可回查、候选零持久、零因果实例、定义与证据分阶段续行、新证据不改定义、反例触发重新确认、统计可重建、旧节点15/关系18零生产及历史只读兼容。
