## 1. 定位与适用范围

本规范在4180统一比较合同下定义可复用的算法正文、输入解释、零值含义、数值边界和拒绝条件。算法输出用于取得特征差异或关系；识别某一存在、判定变化、匹配概念和判断需求是否达成仍由对应应用依据完整材料完成。

直接上级规范：4180。

直接依赖规范：4120。

相关边界规范：1120、1130、1180、2100、4130、4150、4160、4182、7160、7170、7180。

本文规定算法逻辑，不建立新的数据服务、值表示、节点族或C++ ABI。算法有正文不等于具体FT已经绑定，也不等于解析、计算、注册或消费者已经实现；启用必须满足4182。旧v1允许集、既有具名算法及稳定编码不因本规范增加而自动变化。

## 2. 算法共同前置

1. 两侧输入必须是指定比较用途要求的同正式特征类型，或已由独立正式转换合同形成同类型输入；不得比较节点号、指针或名称来替代值比较。
2. 内联I64直接取得准确内容；值引用通过对应公开服务读取完整不可变值，独立材料再经其正式解析入口取得完整结构。相同值表示不是相同业务类型。
3. 每次比较固定左右角色。普通差异为右减左；关系描述A减B按4180固定左=B、右=A。内部算法变量重排不得改变来源角色。
4. 单位、缩放、维度、分量顺序、坐标、有效范围和材料格式均须匹配；必要转换先独立形成可回查材料，比较器不临时猜测或补齐。
5. 每项对外结果有正式输出FT和一个I64值。多结果分别具名并保留共同来源；中间向量、浮点、宽整数和位集不是另一份业务结果，也不改变1180来源与真实阶次规则。
6. 中间运算采用已登记的可检查数值范围。不得先在I64溢出再转宽；不得用饱和、回绕、NaN替代、缺值补零形成成功。已请求的必需项有一项失败则该请求全部无值；仅作内部诊断的部分值不得外泄。
7. 量化是算法定义的一部分，不是误差容忍。若近似数值计算不能确定唯一的规定整数结果，必须返回误差合同不成立或相应无值失败，不能依赖平台浮点差异任选结果。

## 3. 完整内容精确匹配

本节属于4180的“完整内容相等”逻辑类别，不是“稳定身份相等”。精确匹配必须核对同一正式表示和解释合同下全部有意义内容：标量完整值；向量维度、顺序与全部分量；结构材料的完整格式解释、坐标/网格参数、有效性标记和载荷。

允许先用摘要、尺寸或索引排除不匹配候选；摘要相同仍须完整匹配。两个不同值身份可以具有相同内容；两个物理编码只有经过正式、无损且确定的规范化合同才能按同一规范表示比较。不得默认补零、排序、旋转、重采样或忽略未知位来制造相等。

新具名“完整内容差别标志”可采用无量纲I64：0表示完整内容精确相同，1表示完整内容不相同；只说明相同/不同，不表示大小或差距。该映射只属于此具名输出，不重排旧关系编码。用于准确F复用的完整读取和判等仍遵守4110；本节不另建一套去重owner。

完整匹配后仍不能推导两个存在身份相同。输入缺失、不合法或解析失败没有差别标志，不能视为不同。

## 4. 标量与数值向量

### 4.1 有序I64

| 具名用途 | 算法 | 零的含义 |
| --- | --- | --- |
| 排序 | 按4130安全比较左值与右值，不先作危险减法 | 两个同域标量相等 |
| 有向差异 | 右值−左值，保持同一输入单位和缩放 | 同域标量差异为零 |
| 差异幅度 | 数学上的绝对值abs(右值−左值)，检查I64可表示性 | 同域标量相等；非零不带方向 |

负数取绝对值须先防止INT64_MIN溢出。仅请求排序不因未请求的差异不可表示而失败；请求差异不可表示时不回传半成功排序。类别、身份或枚举只有明确的顺序合同才可使用有序算法；“有桌子”之类存在性属性须先形成4120的具名存在性合同，不能从任意对象引用直接相减。

### 4.2 向量分量与幅度

逐分量差异只按4180在同维、同顺序、同分量角色下计算；每项分量对外分别为具名I64。混合单位的组成项不得求一个无定义总差。

“数值向量距离”逻辑类别下可定义以下不同算法：

```text
di = 右分量i − 左分量i
L1 = Σ abs(di)
平方L2 = Σ di²
L2 = sqrt(Σ di²)
```

各分量须属于同单位、同缩放的可相加域，或已经完成另行登记的无量纲转换。L1输出沿用输入单位；平方L2单位为输入单位平方、物理缩放为输入缩放的平方；L2输出采用其独立登记单位及量化规则。不允许把平方L2命名为原量纲距离。L2通常不是整数，注册未冻结量化时不得直接转I64。L1及平方L2精确计算为零才可推出全部参与分量相同；不能推出未参与分量或完整宿主相同。

本节不默认归一化到0—10000，不默认补齐不等长向量，不混加原始差值与已经归一化的评分。加权或相对差异需要另外冻结分母、零分母、权重来源、单位、范围与量化，未闭合前不启用；原始差异不能被评分覆盖。

## 5. 坐标距离与方向

### 5.1 比较对象

坐标关系描述采用“距离＋具名方向角”的组合。一般三维方向需要方位角和仰角；只有已声明的二维平面约束才可省去仰角。距离、方位角、仰角分别形成具名I64，组合关系按7170/7180使用，不打包成一个整数，也不要求一项新复合标量。

纯位置差异检测可以有独立的距离用途；它与完整空间关系描述的结果集合不同。三轴位移可作内部材料，已有逐分量输出合同仍保留，不能将其静默改成角度输出。

### 5.2 具名极坐标关系合同

注册须提供共同坐标系及有来源的正交单位基：水平零轴e1、水平正转轴e2、向上轴u，及其手性、轴向和变换合同。不能直接把外设的右/下/前三轴当成人类前/左/上的语义。

在共同合同中令d=右坐标−左坐标，x=d·e1、y=d·e2、z=d·u：

```text
水平距离ρ = sqrt(x²+y²)
空间距离r = sqrt(x²+y²+z²)
方位角θ = atan2(y,x)
仰角φ = atan2(z,ρ)
```

本具名合同的方位正向由e1转向e2；方位归一化为[-π,π)，仰角范围[-π/2,π/2]。它比较的是参照点到被描述点的位移方向，不是两条“原点到目标”向量的无向夹角。需要后者时必须使用另一个具名方向比较合同，不能复用名称或输出FT。

本具名合同的距离输出单位、正有理缩放由FT绑定；距离量化采用最近整数、恰好半格远离零。角度以一整周P个整数刻度表达，P为正I64且能被4整除；按同样舍入规则量化θ×P/(2π)、φ×P/(2π)，方位在舍入后再归一化到[-P/2,P/2)。因此正半周归入-P/2；仰角极值为±P/4。P不是全局常量，也不为已有算法提供默认值。其它量化或归一化方案必须使用另一份明确合同，不能修改此合同或覆盖已有v1数值。

坐标转换、平方和、开方、角度及量化均必须验证数值与误差边界；注册不能只写“调用atan2”而遗漏确定性及有效范围。不存在合法的坐标/变换、缩放或解析合同，不建立该当前有效注册。

### 5.3 退化与角度差

重合和极轴依据本次合法坐标材料产生的位移、在输出量化前判断，不能从量化距离0或量化仰角±P/4反推。输入分辨率及误差的含义仍按其正式坐标合同，不声称取得分辨率以外的现实精度。

- d=0时，距离为0，两角均未定义。
- ρ=0且z≠0时，方位未定义，仰角为正或负四分之一周。
- 未定义角不填0、不沿用上一角；请求三项完整关系时任一角未定义则整次无值失败。独立距离用途可以合法比较重合点。
- 精确方位角0表示水平投影沿注册零轴，精确仰角0表示处于注册水平面；输出I64为0只证明量化到零刻度，不能证明严格沿轴、共面或位置相等。
- 方位角比较按4180环形差合同，须冻结周期、正向和半周期裁决。本具名合同的仰角是[-P/4,P/4]有界量，按同尺度下右减左形成独立I64差异，不按整周折返；正极到负极为−P/2，反向为+P/2。角度本身、角度差、无向夹角是不同结果。

## 6. 颜色

### 6.1 颜色编码差异

颜色的完整输入必须明确色彩空间、通道顺序、每通道范围、传递函数及适用时的白点/标定。RGB和BGR不是同一分量顺序；有无透明度、亮度处理或不同曝光解释也不能默认兼容。

对于明确为三个通道、每通道0—255整数、相同编码合同的BGR值，具名“BGR编码L1差异”定义为：

```text
D = abs(B右−B左) + abs(G右−G左) + abs(R右−R左)
结果范围 = 0—765，单位 = 通道编码差单位，缩放 = 1
```

该精确整数结果为0当且仅当三个参与通道全部相同。它属于数值向量距离，不是空间距离，不是人眼感知色差，也不默认除以765或量化为评分。额外通道不能被悄悄忽略后声称完整颜色相同。

Lab、ΔE等感知色差不能由上式冒充。其白点、转换、色差公式、参数、输出缩放、允许误差及算法族承接尚未完整登记时，不启用相应感知色差用途；本规范不以旧代码或显示名称补齐。

### 6.2 颜色概念分类

两色差异只回答两输入的差异，不能唯一决定某输入属于红、绿、蓝或七彩中的哪一类。颜色分类由7160完整概念域及其代表/规则完成；采用色相区间时还必须定义色相环绕、饱和度和亮度范围、无彩色及边界归属。三原色不是对任意颜色的三个完备互斥区间，不能据名称预建错误划分。

本规范不固定七彩边界、感知误差半径或外设校准阈值。缺少相应来源只阻止该分类或容差用途，不把合法的颜色编码差异改成失败或默认相等。

## 7. 轮廓、位图与体素

### 7.1 结构输入与用途分离

轮廓/体素按4120取得完整材料与解析合同。比较必须明确是完整内容匹配、像素/体素占据差异、边界漂移，还是经过有来源对齐后的形状比较。稠密/稀疏布局、宽高深、网格原点、每轴分辨率、位序、坐标和有效掩码均属于解释合同，不从向量长度推断。

未知、未观察、无效、已知空与已知占据不得混同。稀疏缺项只按格式已定义的含义解析；没有定义时不能补空。滤波、填洞、PCA对齐、缩放及重采样形成新的派生材料，必须保持原观察来源，不能改写原材料或把补算区域标为真实测量。

### 7.2 完整已知位图的海明差异

对同网格、同解释、全部比较单元已知的规范位图，具名海明差异为有意义单元上不同位的数量：

```text
H = Σ popcount(左块 XOR 右块)，仅统计合法单元
```

填充位须按格式验证，不参与几何单元计数；维度或布局不匹配必须拒绝，不能按较短长度截取或在尾部补零。H采用差异单元数、缩放1的非负I64，计数超范围拒绝。此时H=0证明比较范围内全部位相同，不证明其它属性或存在身份相同。

二值图的像素差异与二值体素的占据差异分别绑定真实FT，不能因都是U64组而共用无语义类型。海明公式是“形状距离”族中的离散占据差异用途，不替代几何距离；实际启用仍服从4180形状解析门禁。含未知单元的全范围几何差异不适用本算法；仅比较共同可见部分须有另行冻结的范围、覆盖及未知处理合同，本版不以掩码默认打开该用途。

### 7.3 二值边界距离及多分辨率材料

二值轮廓漂移唯一引用4180第11节的既有四邻边界、双向平均最近边界距离、向下取整及校正合同；本规范不复制第二份公式、不改变其输入入口，也不以海明替换。其零值与完整内容相等按4180第2.2节分账。

OR池化金字塔、包围盒、摘要和遮挡友好评分可在具名用途下辅助候选召回；粗层相同或子集相似度为1不能直接证明完整材料相同。若用于安全排除候选，必须有不会漏掉目标的正式判据；缺少该证明不能因粗层阈值就终止精确比较。

任意点云、旋转不变形状距离、体素表面几何距离、遮挡相容度等用途，本版只规定输入及启用边界；各自公式、预处理和误差未冻结前不取得默认算法。不把旧二值“占据/未知共用1”的雕刻编码当作具备独立未知状态的体素事实。

## 8. 后天特征与组合结果

比较合同复用和递归来源展开由4182规定。本规范只提供具名算法，不从名词或子概念自动推导算子。产生新属性后，应比较该属性的值；组成槽位匹配、源值差异集合与新属性差异不是同一结果。

距离、角度、颜色差等不同结果的组合保留各项输出FT、准确值及来源；条件合取引用7170/7180。评分或单一汇总值需要自身的派生规则、单位和失败合同，不得为了“最后是一个整数”擅自求和、平均或把AND压成总分。

## 9. 最低验证语义

下表是算法应满足的合同样例，不是本项目已经运行通过的测试记录。单位和缩放均采用表内前提；实际绑定还须覆盖自身极值和材料上限。

| 样例 | 预期 |
| --- | --- |
| 有序I64左170、右180 | 排序为负，有向差异+10，幅度10；描述A=180、B=170时仍左=B、右=A |
| 左INT64_MIN、右INT64_MAX | 仅排序可判；请求差异则不可表示且请求载荷全空 |
| 同单位向量(0,0)、(1,1) | L1=2，平方L2=2；L2为√2，未给量化合同不产生I64距离 |
| 同维规范位图共157块、恰好1个合法位不同 | 海明H=1；不能沿用旧Q10000截断结果0证明精确相等 |
| 同BGR合同纯红与纯绿、纯红与纯蓝 | 两次编码L1差异均510；不能据同一差值推出同一颜色类别 |
| 同网格边界A={(0,0)}、B={(0,0),(1,0)}，既有边界算法S=1 | 量化边界距离0，完整内容不相等；登记的闭阈值0可命中，不等于准确单点域 |
| 同3×3图：全前景与仅中心为背景 | 四邻边界均为外圈8点，边界距离任何合法S下均0；完整图不相等 |
| 单点边界相差1格，S=1，闭阈值1 | 边界距离1、域命中、完整内容不相等 |
| 极坐标关系d=0 | 独立距离结果0；要求完整距离和两角时无值失败 |
| 极坐标关系d沿+u且非零 | 方位未定义，仰角+P/4；不得填方位0 |
| 同坐标合同d沿+e1或−e1，角度尺度P | 方位分别0或−P/2；不解释为位置相等或大小关系 |
| 极坐标P=360作验证尺度，d=(1000000,1,1)为上述正交基分量 | 两角均量化为0，但不是严格沿零轴或处于水平面；不能把零格当精确方向 |
| 同尺度仰角从+P/4到−P/4，以及反向 | 差异分别−P/2、+P/2，不执行方位半周期折返 |
| 位图相同块内容但宽高、坐标或未知语义不匹配 | 不得输出完整相等或几何差异成功 |

还须验证非法输入、类型/单位/角色错配、所有必要数值中间步骤溢出、材料读取失败、资源不足、确定性量化及零机器事实写入。编译、公式计算样例或旧包函数存在不能替代正式消费者的验证。
