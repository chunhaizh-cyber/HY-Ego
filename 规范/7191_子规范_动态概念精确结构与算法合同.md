## 1. 范围与支持边界

本规范冻结7190普通动态概念定义的逻辑结构、规范化与包含算法、来源获取与识别算法、唯一概念owner的数据操作与发布规则、方向模式格式及首次建点来源。C++头源归属、DTO与构造签名、物理关系类型、外部初始化写集和旧入口替换闭包属于施工内容，由对应详细设计承载。

定义、形成依据、支持、名称和用途分别成立；动态概念属于动态类别，以先天动态根为顶层（2220、7190），不建立第二动态数据类、第二概念仓或第二动态根。实例动态保持1170/4211的身份、主体和原子/复合/动作内容；场景组织由1150、4202提供；RC及FC/EC求值由4242提供。本规范不重新定义RC结构、比较方向或先天算法，不把裸时间/次数包装成F调用比较。

支持范围：已发布I64域FC、4242支持的有序RC、具有可求值叶的既有子DC、有限角色/位置绑定、相对端点时间约束、关键条件抽象和有限重复结构。非I64域、未支持的复杂EC、无正式提取规则的派生量（速度、频率等）返回`规则不支持`；不生成虚假准确F或动作事实。

## 2. 完整类型化定义

定义由下列逻辑组成，索引均为定义内局部序号，不是世界节点身份：

```text
动态概念模式定义
  角色组      序号1..R → EC（存在根或其下任意存在概念）；角色1为整体被描述主体
  同异组      (左角色, 右角色, 同一|不同)
  位置组      序号1..P，每项为：
                原子位置：主体角色 + 类型域FC（某FT完整允许域的类型根）
                子位置：  子DC + 角色映射（子角色 → 本地角色）
  条件组      序号1..C，每项为：
                状态条件：位置端（位置, 前|后） + FC
                关系条件：RC + 输入组（规范原子序号, A位置端, B位置端）
  时间组      (起位置端, 止位置端, 可选最小纳秒, 可选最大纳秒)
```

规则：

1. 角色和位置非空，各自编号1..N；角色1不参与与其它角色的互换，其余角色只能在完整规范化时重命名。每个角色必须被至少一个位置使用或经子DC映射使用。EC可以是存在根（不附加类别限制）或其下的任意存在概念；EC不附加限制不表示无需真实存在身份。
2. 原子位置绑定一个真实原子动态D；D的前后状态属于同一实例特征F，F的特征类型等于该FC所在类型根。类型根只限定所比较属性类型，细域条件由状态条件另表达。
3. 子位置绑定一个动态D及既有完整子DC；角色映射恰覆盖子DC每个角色，子角色1映射到本地被描述主体角色。展开必须有可求值原子叶，无自引用、定义引用环或未完成定义。
4. 条件可空，但位置不可空：原子位置本身已有“该角色该FT发生变化”的约束，子位置已有子DC约束。没有位置的零约束定义非法；没有其它可证明上位的合法DC挂在动态根下。
5. 状态条件只指向本定义原子位置的前/后端点，FC须与该位置FT相容；子DC的内部状态不通过裸序号穿透，需访问时先显式展开其完整位置并保留映射。
6. 关系条件的输入恰覆盖4242规范化原子组的每一项，序号取完整RC读回顺序；每个A/B指向原子位置端点，按4242求值。同一RC的全部分量必须归并为同一有序参与者A/B，且各方材料同一F持有者、同一强时间；不能以不同时刻的值拼成一次多维输入，也不能忽略子RC约束。
7. `t止−t起`须在显式闭区间内；至少一个界存在，双界时最小≤最大，允许负界表达逆向不等式。空界表示不限制，不是零。原子“前<后”是隐含约束；子位置的起止为该次完整子匹配的最早前端和最晚后端，只是包络，不代表持续变化或观察覆盖。
8. 同异组做等价闭包，不同约束不得落在同一等价类；未声明同/异时不推定。
9. 不同发生位置使用互不重叠的原子D集合；一个原子可以为同一位置的多个条件提供来源，但不能同时充当两个重复位置；不同D重复包装同一叶集合不增加发生次数。

定义不含具体存在、状态、动态、绝对UTC、名称、支持次数、置信分、创建者或调用批次。FC/EC/RC/子DC按当前定义解释（0050第1.5节），不跟随实例当前名称改义。

## 3. 重复、规范化和包含

重复是有限位置模式，不另建计数节点或通用表达式。一个AB单元由两个位置及连接约束表达；要求重复k次时，将单元实例化为k组互异位置，并保留每组内部及B到下一A的必要时间连接。k由调用方明确输入，是定义基数而非资源参数。`ABABAB→AB`若只保留一单元，结果不要求重复；若声称周期性，必须保留至少两组发生与连接。不同相位不默认等价。

规范化按以下固定顺序执行，不读仓、不写数据，只消费已完整读回的定义引用闭包：

1. 核验索引、分支、引用与基数；条件内完全重复的同一谓词去重，不同位置的相同谓词保留。
2. 保持角色1，枚举其余角色及全部位置的所有双射重编号，同步更新条件、时间端、同异和子角色映射；无法完成全部排列时返回资源失败，不退回原始顺序签名。
3. 每个排列中完全相同的条件去重排序并重新连续编号；同异组规范为等价类及类间不同约束。
4. 时间转为差分约束`xj−xi≤b`，每个位置加入`前−后≤−1纳秒`；用完整 Floyd-Warshall 求闭包，负环即定义矛盾。运算使用检查溢出的整数，不以饱和数代替无穷；有限闭包项按端点序号保存为单向最紧上界。
5. 将规范化结构按字段顺序形成临时词典序序列，选最小序列。序列只用于比较与查重，不持久化为万能字节包。有限排列产生相同序列时为同义，不合并真实重复位置。
6. 签名包含规范化规则身份、固定引用和完整规范化内容，不包含来源、父边或治理；摘要只加速召回，完整结构比较裁决相等。

包含只证明可机械判定的充分条件：枚举上位角色/位置到下位的单射；原子FT相同；EC/FC/RC/子DC引用相同或为下位；上位每个谓词能在下位对应位置找到同义或更窄的谓词；下位差分闭包蕴含上位全部界；同异约束同理。至少一个映射成立为`已证明包含`；完整枚举无映射为`未证明包含`，不是已证明现实不包含；资源失败或引用缺失不能变成未证明。动态根包含一切动态概念，挂动态根不需要包含证明；其它父边只连接具有包含证明的同类别DC。插入中间层同时提交受影响父组变更，不先断边后补边。

## 4. 数据操作

唯一概念owner提供下列动态概念操作，均为 current-only 读写：

| 操作 | 语义与成功形状 |
| --- | --- |
| 读取定义 / 查询 / 读取图 / 读取关联 / 读取名称 | 零写读取；定义查询有精确定义时规范化查重最多一项；图返回动态类别下完整DC及全部直接多父边 |
| 发布或复用 | 完整定义、完整父组（无其它可证明上位时为动态根）与形成依据同次成立；同义已存在则复用、零写 |
| 原地修订 | 同一DC提交新完整定义；与他者同义时返回“已合并到既有”，在同一写集内把原DC的引用（动态实例概念引用、父/子边、名称、因果角色）改接到既有DC，原DC按引用归零退出；否则原地更新 |
| 追加支持 | 恰一DC与一个动态的支持关系；同D/DC已存在则复用 |
| 追加形成依据 | 新增依据组；全部已存在则复用；不修改定义或支持 |
| 退出关联 | 退出支持或依据关联，不删除来源动态 |
| 组织 | 提交受影响父组及准确退出边集合，非受影响合法父不变 |
| 生命周期治理 | 按7140改变活跃/冷却/退役，不改定义 |
| 不可逆退出 | 确认无名称、外部定义、支持等活动引用；计算必要替代父边（子概念可改挂动态根）保持图完整无环；不连带退出FC/EC/RC |
| 名称 | 按2210与4240维护名称关系，不改动态或DC |

写入在一次锁内完成校验与修改，需跨基础操作共同成立的写入提交一个组合变化集并一次发布（0050第1.2节）。唯一键为“动态类别 + 规范化规则 + 完整规范化定义”，相同键当前至多一个（含退役但未不可逆退出者）。实例支持唯一键为（D, DC）。数据层不调用RC算法或判断样本归类正确；应用先求值，数据层核验结构和正式来源。非成功清空业务载荷，保留真实阶段；提交未知只能按原请求收敛，不换请求盲重试。

形成依据非空，可为完整动态样本或较早完整DC；DC依据须为同类别已成立定义并由完整包含检查支撑抽象。形成依据不加入定义键；同义复用不自动吞并新依据，需显式追加。

## 5. 应用参数

应用参数均由调用方显式提供，不采用隐藏的成熟次数、三次命中、置信阈值或默认天数。显式样本、候选库、位置范围、重复次数、时间分界、形成目的、识别范围和所需结果共同定义本次完整业务范围；执行资源不得改变该范围或已完整求出的定义语义。发现覆盖、独立支持、反例和重复参数只筛选本次候选或限定可声明的可靠区分范围，不进入DC身份，不构成全局发布门槛；一次完整来源可按7195形成合法定义。

每次调用必须同时回显：形成目的（完整原型/条件模式/复用足够区分定义）、识别范围（任一完整命中/区分指定候选/完整命中集合/精确原型比较）、完整判定条件及其正式来源、所需结果集合、停止条件，以及可选相似度的类型/算法/量化/完整性要求。需求判定条件只选择4180/4182固定算法结果怎样参与本次判定，不改写准确结果、单位或量化。相似度只有完整合同完成时存在，不用于精确同义查重。

## 6. 确定性获取、暂配和识别算法

### 6.1 来源获取与独立性

样本为一个已挂接的动态D。由D读出前后状态S，由S得到实例特征F，由F得到持有存在E，发生场景取场景动态列表（1150、1160、1170）；样本全部相关S的F持有者须与D主体或其子存在一致，不能只取一个S忽略其余冲突。跨场景样本按7190第5.5节由共同上位场景以范围包含读取。

发生期依据（G5-5）：单主体原子或复合动态以“挂接时的场景核验 + 状态F的持有者”为发生期依据，挂接时已核验主体属于发生场景、状态与动态不迁移；只有涉及多主体组成关系的样本才需另行取得组成关系的适用期依据：该依据来自子存在“所属整体”F（7150）值变化生成的保留状态与动态；所需状态、动态已按生命周期删除或不覆盖该期间时返回`发生期依据不足`。

同一D、祖先D及其子D、具有共同原子叶的D不能跨发现/独立支持/反例组重复计数；有重叠的样本拒绝为入口不独立，不自动删重后改变样本权重。样本内部原子按`前强时间、后强时间、FT、D身份`稳定排序；该排序只控制枚举，不创造同时、相邻、连续或因果关系。所需来源已按生命周期删除时返回材料不足；无数据与完整不命中分账。

### 6.2 无目标DC启动与暂配

可用EC/FC/RC/子DC列表是调用方明确给定的有限候选库，逐一正式读回；空子DC库合法，不要求目标概念预先存在。EC库须包含存在根，FC须包含各欲使用FT的最宽完整域概念和可能细域，RC按4242读取。缺少某FT最宽完整域时不临时制造概念，返回所需材料不足。

发现样本组必须非空；位置参数满足`1≤最小位置数≤最大位置数`，最少重复次数非零；比例阈值分母非零、分子不大于分母；时间分界严格升序。从每个发现样本枚举最小..最大位置数的原子子集及已给子DC可匹配位置，保留真实端点时序。角色1先用存在根；需要更窄EC时由合法定义和4242角色求值提供，不能按具体存在编码建定义。两个候选只在规范化完整定义相同或显式共同谓词交集可成立时暂配，不对“甲像乙、乙像丙”做传递。

给每个候选位置按候选库枚举类型域、端点FC命中、合法A/B RC命中、已有子DC；时间候选仅来自调用方给定的时间分界，以实际差值所在闭区间形成，相邻区间半开转闭须检查±1溢出。不得从当前样本最小最大值自动创造稳定经验域。发现覆盖率用已完整判断的命中数/样本数与阈值交叉相乘判断，检查乘法溢出；未知不计作负例，不缩分母。同一调用必须完整枚举请求范围；资源耗尽整体非成功，不保存后台积累候选或第二样本仓。

### 6.3 逐位置绑定与唯一求值

匹配按规范化位置序号枚举样本闭包中的兼容D；原子位置只绑原子，子位置对既有子DC递归匹配，环检测阻止自引用。发生位置的原子集合互不相交；不同条件共享同一位置的合法端点，不重复计发生。

每个完整绑定依次检查角色EC→位置FT→FC端点→RC条件→时间闭包。FC/EC/RC只经4242求值；一方材料由同一F持有者、同一强时间的状态端点组成；绝不取F当前值覆盖过去状态的准确值。同一角色EC在每个实际参与的观察时刻分别求值，材料不足为证据不足，不借另一时刻或当前F补齐。

一个绑定的全部条件必须完整求值，即使前面已有false也不跳过后项以掩盖缺来源或资源失败。识别范围为“任一完整命中”时，至少一个完整绑定全部机械成立后可结束其它替代绑定；要求完整命中集合、全域不命中或候选比较时必须完成全部有限绑定。全部绑定完整不成立才能机械不命中；存在未知绑定且无已成立绑定时证据不足；资源或内部错误整体失败。

### 6.4 独立检验与关键条件简化

形成候选先用发现样本，不将这批材料再次标记成独立支持。独立支持与反例分别按完整候选重新求值，按本次需求中具名且来源合法的阈值裁决；独立支持为空可形成一次来源可用定义，但“独立检验已完成”为假，不得声称可靠区分已得证明；反例为空不证明没有反例。

简化按规范化顺序枚举原定义全部非空位置子集及条件子集；删除位置时一并删除依赖该位置的谓词，但保留投影到剩余端点的差分闭包，故A…C仍保持B曾影响的必要时间界。子集逐一对原发现/独立支持/反例范围重验；满足阈值的候选按位置数、条件数、时间界数及规范化序列排序，返回完整枚举所得全部不可继续删减候选。删去B/D若使反例也命中且超过明确最大反例命中阈值，不能宣称保留原区分能力，只能作为更宽定义候选（7195简化）。

## 7. 发布应用与上位形成

`形成或复用动态概念`重读引用并规范化传入定义，在其验证范围逐项求值与阈值核验，完整来源条件不足零新写；通过后以发现样本为形成依据发布，初始父组显式给定（无其它可证明上位时为动态根）。定义已复用只返回相同身份；发布不自动增加支持、名称或用途。

`建立动态概念支持`对恰一DC和样本重新识别，机械命中仍须通过第6.1节来源准入，再追加支持并从概念端、动态端独立读回。

`形成上位动态概念`按封闭步骤执行：

1. 读取下位定义及当前完整图，规范化上位；与下位同义则复用下位，不制造自父边。其余候选必须取得“上位包含下位”的完整证明并计算反向包含；反向也已证明则同义，按原地修订合并处理。
2. 用定义键发布/复用上位，调用方显式提交上位完整父组：能证明现有父概念包含该上位时保留为其父，否则挂动态根；形成依据为该下位DC。
3. 重读上下位完整定义与下位全部直接父边，再核验包含；上位不得为下位本身或其后代，新边成环即拒绝。下位新父组为“原父组中未被新上位严格替代的全部父 + 新上位”；只有已证明同时包含新上位和下位、且由新上位承接的旧父边才可替换，其余合法多父一律保留。
4. 在一次组合发布中提交下位父组变更，再从上下位两端独立读回；并发父组变化拒绝，不自动丢弃并发加入的合法父。

两阶段分别保存原请求和真实回执；上位已发布而组织失败时保留其身份与阶段，不声称回滚。分析和识别零写。

## 8. 方向模式格式与首次建点来源

### 8.1 信息分层

方向模式信息分三层：定义层持久保存概念身份、固定规则、覆盖语义、关注FT/槽位、方向条件、比较位置、衔接/时间约束及上下位关系；来源层按生命周期保存真实存在、动态、状态、形成依据和支持关系；计算层只在调用期保存准确I64结果、位置绑定、展开缓存、搜索栈、候选域和规范化临时序列。计算层清空不改变世界事实；需要持久的二次结果按1180由所属动态作为实例特征持有，不由本合同另建。

### 8.2 定义种类、覆盖语义和组成槽位

动态类别下普通动态概念定义分三类：条件模式、类型变化范围定义、方向模式定义。原普通模式只解释为条件模式，不自动改成完整范围。

方向模式定义至少包含：覆盖语义；关注根FT组；完整组成槽位组；角色组；比较位置组；FC/RC条件组；端点衔接组；相对时间约束组；必要角色同异约束。覆盖语义恰为`完整范围`或`条件模式`：前者要求声明范围内全部实际位置、槽位占用、衔接和时间关系一一对应；后者只要求列出的非空条件。覆盖语义参与同义判定，不是调用者可切换的开关。

每个组成槽位具有局部序号、父槽位序号、4120正式角色、正式FT引用、最小/最大基数和单项/有序组/无序组语义；父序号0表示关注范围顶层；同一父内角色唯一；闭包无环。共享子FT在不同完整角色路径上保留不同使用位置；只沿4120正式组成边展开，不沿派生来源、概念上下位、向量元素或任意对象关系展开。

类型变化范围定义只保存关注FT、其正式槽位闭包、主体/必要角色约束及合法比较规则引用，不保存样本固定位置数、固定方向或绝对时间。单叶FT要求至少一个真实变化位置；复合FT要求所有声明槽位按正式基数可核验、至少一个叶位置有真实变化来源并能在同一整体绑定中解释。

### 8.3 比较位置与方向条件

比较位置包含局部序号、主体角色、叶槽位、来源种类、固定FT完整域FC及前后端。来源种类只有：`原生变化`，绑定真实原子D或首次建点配对并要求真实变化；`状态比较`，绑定合法状态对，用于保持或补充条件而不产生D。具体D或状态只存在于形成依据、支持或调用期绑定，不写入通用定义。

同一原生位置可承载正式比较规则的多个具名I64方向条件，共用同一真实端点而不增加发生次数；状态比较位置不能满足要求另一真实发生的重复位置。每个方向条件绑定叶FT、固定规则、输入/结果角色及正式结果域；同号而FT或规则不同不构成同一方向条件。合法零结果可以成为复合模式保持条件，但零状态比较不建立零动态；缺值、缺规则、已删除或读取失败不产生零条件；全部位置均为保持且无真实变化来源时不得发布普通动态原型。

### 8.4 两类来源请求

来源请求为互斥分支：已有动态样本分支输入真实D；首次动态建点分支输入将交给世界树/动态服务的发生场景、主体存在、动态变化内容及补充状态比较配对。补充配对引用已发布状态，并带正式槽位角色路径和比较目的；未来父D不能作为先决引用或占位身份。

首次建点形成依据增加具名`建点来源`分支，引用已存在的场景、存在、全部前后状态及组合中已存在的直接子D。动态实例D先按1170/4211成立并挂接场景，首次建点只把已成立D的建点材料交动态类；动态类随后形成或复用DC并为D登记概念引用，不要求先发布DC再建立D；真实支持通过独立操作追加，不预登记未来实例已经支持概念。两类来源均按7192形成同一调用期来源视图，并共享7193比较解释；发生期依据按第6.1节。

### 8.5 匹配绑定与兼容

统一结果至少包含操作状态、可选逻辑判定、请求范围、完整性、业务载荷与发布阶段。逻辑判定只为满足、不满足、证据不足；入口非法、规则不支持、发布结果未知、来源已删除、资源失败和内部不一致为独立操作状态。`未完整且无命中`不能驱动新建。匹配成功可返回一致的角色、槽位、位置和端点时间绑定供调用方复核；该绑定零持久身份、零生产事实权力。

旧D-only原子位置无损映射为原生变化位置；旧定义没有保持位置，不因缺项补零。无法无损转换的旧定义返回`旧格式不支持`或进入具名迁移，不被查询忽略后声称全范围不存在。新旧格式共同查重时完整范围与条件模式不因一次样本相同而合并。
