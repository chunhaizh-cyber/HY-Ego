# 4060 子规范 非权威缓存、索引失效与确定重建

编号：4060

日期：20261105

版本：v2.0

状态：正式子规范

直接上级规范：0050。

直接依赖规范：4010、4015、4040。

相关边界规范：4050、4070。

## 1. 定位

本规范规定内存权威数据集（4015）之外的热缓存、查询索引和统计投影的身份、三态读取、失效、清空与确定重建。它们的唯一来源是锁保护下的当前权威状态，永远不取得事实裁决权。内存权威数据集不是缓存，不得因同处内存而归入可丢弃结构。

DATA-L1不提供事实代次、读取截止或版本（0050第1.2节）；缓存不得以任何代次、截止或版本冒充事实身份，也不得用来跨调用拼接材料。

## 2. 缓存身份

缓存条目必须绑定查询命名空间、完整键，以及下列之一的失效依据：

1. **发布序号**：数据集为缓存失效维护的进程内技术计数，每次组合原子发布后单调增加。它不持久化、不进入公开结果、不作事实读取依据，也不是事实代次。
2. **失效通知**：数据集或其上层owner在发布后发出的显式失效通知，指明受影响的命名空间或键范围。

缺少完整键或失效依据的条目不得命中。投影规则原地修订时，按失效通知清除受影响条目，不为规则保存版本。

## 3. 读取三态

```text
命中：条目失效依据仍有效且内容完整，返回值式副本
确定未命中：当前缓存范围已覆盖该键且确认无条目
缓存不可用：未加载、已失效、损坏或范围不完整
```

缓存不可用必须回读当前权威状态或返回具名结果，不得降级成业务未找到。即使确定未命中，业务合同要求权威确认时仍须读取内存权威数据集，不得改查持久材料补判。

## 4. 失效与清空

1. 每次组合原子发布后，按发布序号或失效通知失效相关命名空间或键范围。
2. 失效可以粗于变更范围，但不能遗漏受影响条目。
3. 物理删除（4015第12节）后，指向被删对象的缓存、索引和统计条目必须随同失效；它们不构成保护性引用，不阻止删除（0300 R39）。
4. 清空缓存、索引或统计投影，不得改变内存权威状态、持久材料或业务结果。

## 5. 确定重建

1. 重建只在一次共享锁内读取完整当前权威状态，并按现行投影规则计算。
2. 重建输出先进入独立候选容器，完整验证后一次替换缓存视图；替换不是业务事实发布。
3. 缓存候选损坏只丢弃候选并重新读取内存权威，不写业务事实或持久材料。
4. 相同的当前权威状态和相同的现行规则，必须得到语义相同的缓存结果。
5. 重建所需的执行资源不足时返回资源失败，不得截断成看似完整的结果。

## 6. 统计投影

计数、成功率、热度和排序只作解释或优化材料，必须保存来源范围；不得反写身份、关系、因果、需求权重或任务状态。上层对象保存的引用计数同样只是快速判定材料，与引用闭包查询不一致时按内部不一致处理（4050）。
