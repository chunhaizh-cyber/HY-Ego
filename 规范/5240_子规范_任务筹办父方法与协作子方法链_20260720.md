# 5240 子规范 任务筹办父方法与协作子方法链

编号：5240
日期：20260903
版本：v0.4
状态：正式子规范

## 1. 定位

本规范定义不同任务形态的方法承接、复合方法与协作子方法链、执行前选项比较、方法特征挂载和方法切换。

直接上级规范：3200、3300。

直接依赖规范：5230、5250。

相关边界规范：5300、5310。

## 2. 任务形态与方法承接

1. 管理、汇总、AND、OR、方法路径和因果支撑任务由复合方法、任务抽象方法或路径治理合同承接，不要求直接绑定单步本能动作。
2. 普通可任务化原子任务必须最终绑定可执行本能方法或正式动作入口，并直接产生可验收结果。
3. “有方法承接”不等于已经可执行，也不授权无候选时创建占位方法首。
4. 对外任务可以合法等待外在表达、回执、观察事实或外部支撑，不得假设其它存在的内在状态。

## 3. 协作方法链

当父方法目标需要多个中间状态或动作时，必须以组合方法及其协作契约声明各子方法、次序、并行关系、中间特征、回流和失败收束。

任务筹办只按当前状态查找组合 / 子方法，或查找并核验各候选方法自己的条件组；不递归执行子任务、学习链或动作链，也不选择、冻结或切换方法。每个中间变化仍由对应方法执行并形成自己的运行事实与动作动态。

领域前置关系必须来自需求条件、因果、方法条件、条件结果对或已入树子目标，不得写入通用筹办器的领域分支。

## 4. 筹办补齐与执行前选项比较

任务筹办必须先补齐当前任务的候选方法身份、内容版本、各候选方法正式条件组及其当前核验信息；长期方法定义和正式条件关系仍由方法 owner 持有，筹办不得创建或修改。task owner 提交这些任务信息且 manager 独立读回、把任务状态推进到待执行前选择后，执行前选择才对 fresh 可用执行选项按以下顺序分层比较：

1. 结果目标一致程度：宿主、目标特征、目标状态/值、满足关系和直接性；
2. 条件与输入闭合程度：条件满足、参数可绑定、动作入口当前；
3. 禁止与风险：禁止项、权限、安全、前置冲突和副作用；
4. 运行质量：复现、失败、稳定证据、预计耗时、资源和成本。

结果更一致的方法优先于仅因当前易执行但结果粗略的方法。直接达成方法优先于只补齐方法结构的方法。这些优先关系只约束执行前比较，不允许筹办据此截断候选补齐范围。

学习方法必须通过自己的结果能力进入候选，不得按“学习”“练习”名称或固定编号特判。

### 4.1 C031 分层比较只属于执行前选择

筹办不排序、不比较、不采用候选。它先完整查找方法，后在独立状态中查找并核验每个候选自己的条件组是否具备。第 4 节的四层是执行前选择对 fresh 可用执行选项的比较顺序，不是筹办 provider 的筛选规则，也不允许把“条件较少”“编码较小”“先枚举到”解释为更优。

执行选项固定为`方法 + 内容版本 + 条件组 + 输入 / 参数绑定 + 动作范围`。条件组间的可替代或组合语义只来自方法合同；没有强类型组语义时不选择。运行质量中只有单位、范围、来源和规则版本都已登记且可比较的材料可参与；安全硬否决和生存安全控制态是先行否决，服务根当前值、服务合同 / 余额、队列和线程状态均不得进入总成本。

## 5. 方法特征契约

当前方法冻结时，任务必须挂载该方法正式声明的任务特征类型，并记录来源方法、内容版本、特征角色、激活原因、筹办轮次、必需性和当前性。

任务不得临时发明跨方法协调特征；组合方法必须声明协调、顺序、反馈、失败收束和验证特征。

方法切换不得删除旧方法特征和值。旧挂载转为历史或停用，新方法特征全部写入并验证后才能激活。

## 6. 学习与目标方法分账

学习或练习方法 A 不得写目标方法 B 的运行次数、成功次数、连续成功次数、状态、稳定性或最近运行事实。B 的长期账只能由 B 自身执行路径或方法领域提交入口更新。

缺动作入口、多步动作组合或未知动作语义时，学习方法只能形成结构化缺口或候选线索，不得伪造真实动作句柄或把多步组合压成单个本能入口。

## 7. 闭合与验证

旧“五类闭合结果”表述退出当前资格。筹办只报告当前找方法或查条件步骤的覆盖进度、方法 / 条件阶段性信息补全结果；manager 独立读回后推进任务状态。技术非成功保持原业务状态并重试 / 修复，执行前选择才可能形成冻结。

验证必须覆盖父方法、组合方法、原子方法、同结果不同条件、方法切换、旧特征保留、学习方法选择以及无候选不创建方法首。
