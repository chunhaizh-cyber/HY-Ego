# 4320 子规范 因果链组织与应用

编号：4320
日期：20260909
版本：v1.0
状态：正式子规范

直接上级规范：1190。

直接依赖规范：4310。

相关边界规范：2220、3100、3200、3300、4240、4330、5260、5350、6100、6110、6140、6150、7140。

## 1. 定位

本规范定义因果链的连接条件、角色映射、正反向搜索、简化、展开和方法边界。因果链连接概念化因果信息，不连接因果实例；项目不存在独立因果实例类。

## 2. 因果链结构

因果链由一个或多个1190已发布因果信息及它们之间的有向连接组成。上游结果只有同时满足下列条件时才能连接到下游条件：

1. 结果承担角色能够映射为下游条件角色；
2. 特征概念相同或存在正式兼容/包含关系；
3. 结果固定值、值域或相对形成规则能够满足下游判断；
4. 场景、参与者约束和相对时序兼容；
5. 连接没有把被省略的动作或其它未满足条件伪装成已经成立。

结果只满足下游部分条件时，其余条件作为链缺口保留。只按时间先后、名称、相似度、同一主体或同一特征类型不得建立连接。

## 3. 图而非单一列表

因果链底层是有限有向结构，允许一因多果、多因一果、共同原因、替代原因和共享分支。多原因汇合时必须显式保存合取；多结果分支分别保持方向。持久直接连接不得保存由传递推导产生的间接边。

一次调用可以从该结构取得一条路径或一个有限子图。查询层次、路径序号、深度、搜索队列和剪枝结果只属于调用方值式投影，不进入因果信息或链概念字段。

规律层可以出现循环，例如重复调节过程；具体推演必须按时间展开为有限发生序列，并设置深度、节点数及重复访问预算，不得在同一时间层让结果成为自己的原因。

## 4. 主动与被动混合

链内允许主动因果与被动因果混合。被动因果条件满足后可以继续预测其稳定结果；主动因果条件满足后仍必须等待对应动作实际执行。

```text
条件满足
-> 遇到被动因果：可继续预测
-> 遇到主动因果：形成待执行动作与能力检查，不自动越过
```

因此因果链描述客观可达路径，不等于自动执行流程。不存在动作能力、动作入口或当前授权时，链仍可作为知识存在，但不能成为可执行方法。

## 5. 三种搜索

### 5.1 由因求果

从当前角色绑定、条件和已发生/候选动作出发，沿连接方向求出直接及后继结果，用于预测、观察重点、风险传播和副作用枚举。每个结果必须保留来源因果、未满足条件和是否仍需动作；预测结果不得写成状态事实。

### 5.2 由果查因

从目标状态模式反向查找能够形成它的因果信息，再递归查找其前置条件来源。搜索在以下边界停止：

- 已由当前正式事实满足的条件；
- 自我或指定角色具备并允许执行的动作；
- 无法满足的条件或能力缺口；
- 预算、环或事实截止边界。

反向结果是方法形成材料，不直接创建需求、任务或方法。

### 5.3 事实解释

对已经观察到的结果，反向查找可能因果链并与当时场景、状态、动态和动作事实逐项核对。能够产生该结果的链只是解释候选；只有历史事实支持的链段才能说明本次发生，缺失部分必须标记未知。

## 6. 角色映射与适用性

链内每条连接保存上游结果角色到下游条件角色的确定映射。同一概念不表示同一参与者；同一具体存在也不能违反因果定义中的不同角色约束。角色实例绑定只存在于调用期值式求值中。

因果链应用必须冻结共同事实截止，并从因果、概念、场景、存在及当前状态公开服务分别读回所需材料。跨owner读取不能伪装全局原子；任何漂移使本次链投影失效并重新形成。

## 7. 简化与展开

稳定因果链可以按用途形成保留来源的简化规律：

```text
完整链：C + A1 -> R1 -> C2 + A2 -> R2
简化主动因果：C + A1 -> R2
简化被动因果：C -> R2
```

简化不得删除原因果信息，也不得宣称首尾之间是未经中间环节的直接作用。简化因果必须引用完整来源链，保留适用范围，并在方法、安全或解释需要时能够展开动作、中间状态和分支。

简化只保留当前用途需要的端点，不意味着客观中间结果或副作用不存在。方法形成必须按需展开并重新检查被省略动作、能力、风险和条件。

## 8. 持久链概念与调用期投影

一个因果信息可以构成最小链。多个方向一致、角色映射完整且连通的因果信息可以形成可复用因果链概念，并归入2220因果链概念根。链概念保存直接因果引用、直接连接、分支和角色映射，不复制因果字段。

临时目标搜索得到的链不因有用而自动持久化。持久链概念的形成、查重、上下位和治理服从2220、4240和7140；调用期路径、固定层号、间接边、具体存在绑定和预测结果零持久化。

## 9. 因果链与方法

```text
因果链 = 客观上如何由条件和动作逐步形成结果
方法 = 自我为了目标选择链、补齐条件并组织实际动作
```

因果链不判断结果是否满足自我需求，也不判断收益、代价、安全或可忽略性。方法应用读取需求目标，反查因果链，核验自我“我能……”的动作能力，安排动作顺序、等待和停止条件，并独立观察实际结果。

同一链可被多个方法利用；一个方法也可组合多条链。主动链缺动作能力时只返回能力/方法缺口，被动链缺已知动作时可用于预测、等待、回避和进一步观察，不生成“执行未知动作”。

## 10. 非成功与验证

无路径、部分条件满足、角色不兼容、动作能力缺失、读取漂移、预算耗尽、环、被简化来源缺失和内部不一致分别返回；不得把部分路径伪装成完整可达。

验证至少覆盖单节点链、线性链、汇合、分支、主动/被动混合、角色换位拒绝、值域满足/不满足、部分条件缺口、正反向搜索、有限循环展开、简化可回源、调用期零持久化及方法零越权。
