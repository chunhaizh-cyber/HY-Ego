# 5100 子规范 需求下级规则

编号：5100
日期：20260824
版本：v0.6
状态：正式子规范

## 1. 定位

本规范展开需求的单目标、目标比较、角色、来源和当前满足合同。

直接上级规范：3100。

直接依赖规范：4130。

相关边界规范：3200、5110、5120。

## 2. 单目标合同

1. 一个需求只能绑定一个目标宿主、一个目标特征和一个目标状态合同。
2. 多目标必须由管理需求的直接子需求展开；每个子需求仍是单目标。
3. 一个任务只承接一个确定任务目标，但可以承接一个或多个当前有效、目标语义等价且分别保留活动资格与来源的需求；任务权威目标仍是单目标，来源需求集合和任务缓存均不得成为第二套目标定义。本条不定义目标等价算法；任务单目标传递和方法多结果归类仍由 5120 承接。需求活动资格不构成现实执行授权。
4. 逻辑组织语义不新增到需求节点通用字段或需求域平行记录。AND、OR、因果支撑和方法路径使用普通需求节点、强类型目标和正式路径关系表达。

## 3. 目标比较合同

1. 需求目标是目标状态合同。该合同规定参与特征、目标值、类型 / 维度 / 单位、比较关系和组合规则；它不是当前状态记录，也不取得当前值权威。固定值、区间、枚举集合和方向关系由特征定义及判断收束规则表达。
2. 需要方向比较时，正式比较关系只允许“大于、小于、等于”三种原子关系；大于等于、小于等于和可接受集合由组合规则表达。
3. 建立、刷新、取得、确认、明确、新鲜、改善、避免、补齐和验证不是比较关系，只能落入目标特征、目标值、生成类型、方法语义或派生原因。
4. 枚举目标只能用等于或等于集合，并且值必须属于特征定义值域。
5. 需求领域不得比较裸原始值，也不得把状态记录、动态后状态或状态当前选择当作当前输入。它必须冻结非零事实截止，经特征服务读取目标涉及的当前特征值完整投影，再由判断收束服务按目标状态合同形成具名裁决；状态和动态只能提供来源、历史、变化解释及审计证据。

## 4. 角色与任务化

1. 管理、执行、逻辑组织、路径支撑等角色由目标语义、路径关系、承接方式、活动状态和特征集合共同成立。
2. 有无子节点只说明拓扑，不得单独决定角色或是否可任务化。
3. 管理和逻辑组织需求不得被当作普通执行需求直接任务化；必须先按其展开、路径选择、聚合或结算规则处理。
4. 单次方法查找只面向已经通过任务化闸门的具体执行需求，不面向多目标管理包。

## 5. 来源与当前满足

1. 自检、观察、任务筹办、执行结果、方法能力、因果反推和结算等内容只作为父任务材料或正式子目标承接记录的裁决依据，不得直接建立需求或需求来源关系，也不改变入树后的目标语义。
2. 当前满足必须在同一事实截止读取目标涉及的当前特征值完整投影和目标状态合同实时裁决，并记录来源、截止和合同版本。历史状态、动态通知和任务结果只能触发重检或提供证据，不能代替本次当前值读回。
3. 活动承接截止、历史满足或历史结算不得被解释为永久满足。
4. 目标宿主是特征挂载主体，不是“整体被改变”的自由文本对象。
5. 当前自我服务根需求的宿主和所属存在均为唯一自我；它承载唯一自我的长期普通服务方向。外部服务请求只进入该服务根治理任务的材料边界，不能直接创建需求。
6. 通用需求结构按所属存在参数化：每个普通需求唯一属于一个存在，非根需求必须具有一个属于同一存在的父需求。当前自我内部治理实例只接受所属存在为唯一自我的需求，并要求其父链有限回溯到该自我的安全根或服务根；其它存在的需求由其具名治理 owner 和正式根语义负责，不得借用当前自我入口。
7. 子需求只由父需求所承接任务的正式子目标承接记录衍生。子目标必须是已正式选择且当前有效的父目标实现路径所必需、且能够由自身目标状态合同独立验证的目标，并有必要条件、正式因果或具名筹办材料依据；未选择的替代路径只保留为路径或方法候选，任务不能脱离父需求目标自行制造需求。记录必须与父需求、任务、筹办轮次、路径来源、目标和事实截止一致；缺记录、记录父需求不等、目标不等或记录不属于该任务均不得创建子需求。
8. 外部请求者、观察主体或其它来源存在 E 只作父任务材料的来源归因，不取得子需求所有权。人类/非人类分类不参与内部治理需求准入。
9. 同一父需求下同目标活动子需求按 5110 复用或合并；新的正式子目标记录可以附着到既有子需求。不得因来源不同建立第二 D，也不得建立通用请求节点、S、来源 registry 或请求状态机。
10. 写幂等只服务工程收敛。既有任务子目标记录、需求来源关系以及需求 / 列表项 / 成员历史 ABI 已足以承载来源和读回，不得增加平行来源账；子需求建立与后继筹办必须分账。

## 6. 结构映射与验证

需求节点及稳定句柄承载身份；正式关系承载主体、宿主、场景、目标特征、父子和路径；目标状态合同承载目标值与比较规则；特征实例唯一当前属性槽和值事实承载当前比较输入；状态、动态、来源和结算关系承载过程证据。

验证必须证明目标唯一、关系端点合法、目标状态合同完整、角色不是仅由拓扑推断、当前满足来自同截止当前特征值和正式比较合同，并证明状态记录、动态后状态和状态当前选择均不能代替当前值。
