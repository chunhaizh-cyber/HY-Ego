## 1. 定位

本规范定义有限、类型化的特征比较算法族，冻结特征定义到算法的注册关系、比较请求与结果合同、策略调度、单位和维度能力矩阵，以及差异计算的方向、误差和溢出边界。

本规范不把 `I64`、`VecI64` 或 `VecU64` 解释为坐标、颜色、轮廓、集合或其它业务事实；业务解释仍由特征定义和已登记比较合同提供。算法族有限表示比较能力必须从正式登记的类别中选择，不表示所有原始材料都能比较，也不表示二次及以上特征统一使用减法。

比较输入中的实际值、值域和独立材料必须分账：实际向量由一个值事实承载完整向量；区间只表达值域、容差、分类或不确定性边界，不得代替实际标量、向量或形状材料；独立材料引用必须先由不可变材料服务在同一事实截止强类型读回。

直接上级规范：2100。

直接依赖规范：4130。

相关边界规范：1180、4110、4120、4150、4160、4210、6210。

## 2. 比较量、差异量与左右角色

排序比较量和变化差异量是两个不同结果：

```text
排序比较量 = compare(左值, 右值)
排序比较量 < 0 表示左值小于右值

变化差异量 = difference(左值, 右值)
有序标量变化差异量 = 右值 - 左值
变化差异量 > 0 表示从左值到右值沿该值域正方向增加
```

在普通有序标量且两者均非零时，排序比较量与变化差异量的符号相反；不得把其中一个作为另一个返回，不得用同一字段名承载两种语义。

7170/7180关系概念的普通差值简式为`A值-B值`，A是被描述方，B是参照方；调用本规范差异算子时固定映射`左=B、右=A`，不改变本规范原有方向。该映射由正式K确定，不授权调用方为切换关系名称随意交换参数；结果三域也不能替代原准确差值或注册容差下的等价判断。

状态迁移固定 `左值 = 旧值`、`右值 = 新值`，差异方向固定为 `新值 - 旧值`。目标判断必须在注册项中明确实际值和目标值分别绑定到哪一侧；调用者不得通过临时交换左右值复用另一种业务方向。无方向的身份、集合、区间或形状关系可以没有数值差异，但仍必须返回具名关系结果。

### 2.1 对外结果类型与内部算法材料

本规范算法族中的向量分量、区间端点、形状与序列材料可以作为输入或内部计算材料。全部正式二次至 n 次实例依 1180、4150 为 I64；对外业务比较结果必须输出具名标量特征组：每项具有独立真实特征类型及一个 `int64` 值，共享真实输入、算法版本、左右方向和必要时空关联。不得把内部向量差异原样暴露为一个二次实例；多分量分别对应类型，不以打包整数替代。排序、具名关系、差异各属独立结果类型，不因一次调用而共用一个输出类型。

类型注册必须冻结结果种类与合法值映射、单位 / 维度 / 分量角色、正有理缩放、允许范围、量化与溢出策略。纯 I64 比较首版只接受输入量化一致、不进行转换的确切运算：排序与关系输出无量纲离散整数，差异为右减左并保持输入单位及缩放。计算中间溢出、输出范围不适用、类型或算法缺失均返回无值失败；不能截断、饱和、回绕或回填零。格式与算法版本独立，旧格式不得在只读比较中自动升级或产生输出类型节点。

二维轮廓 / 三维体素完整观测依 2100 第 2.1 节；本规范不增加其提取、体素化或形状距离实现。当前缺少具名解析或相应算法时，必须明确拒绝，不能按向量字典序、材料身份、长度或打包整数产生貌似合法的比较结果。

## 3. 有限比较算法族

当前正式算法族只允许下列类别；新增类别必须先修订本规范和能力矩阵，不得由调用者、字符串或默认分支临时发明：

| 算法族 | 合法材料与主要结果 | 禁止的默认解释 |
| --- | --- | --- |
| 稳定身份相等 | 稳定身份相等 / 不等 | 指针地址排序、主键差值 |
| 标量有序比较与安全差异 | 同域 `I64` 的三态顺序和可表示差异 | 跨单位、跨版本或回绕减法 |
| 区间关系 | 相等、包含、被包含、相交、不交及具名端点关系 | 把区间压成单个标量普通减法 |
| 向量逐分量差异 | 同维、同单位、同分量角色的逐分量结果 | 向量词典序、整组无语义大小 |
| 角度环形差 | 具名周期内的最短有符号角差 | 线性普通减法后不归一化 |
| 旋转或方向差 | 具名表示和约定下的相对旋转、夹角或方向关系 | 欧拉分量、四元数分量普通减法 |
| 集合关系 | 相等、真 / 非真子集、真 / 非真超集、相交、不交和具名差集材料 | 按元素数量替代集合关系 |
| 空间位移与距离 | 同坐标合同下的位移向量及具名距离 | 坐标系不明、轴方向不明或调用者自选距离 |
| 形状距离 | 轮廓、包围盒、点集或点云的具名版本距离及误差材料 | 原始向量逐项相减即宣称形状相似 |
| 时间序列变化 | 已对齐窗口内的具名趋势、变化率、聚合或序列距离 | 缺样本时补零、窗口错位或无版本插值 |

类别状态、生命周期码和其它枚举材料只有在特征定义登记了有序值域时才能使用标量有序比较；否则只能使用稳定身份相等或该特征定义登记的专用关系算法。

## 4. 比较算法注册合同

每项有效注册以以下四元组唯一定位：

```text
特征定义稳定身份
+ 比较用途
+ 算法族
+ 算法版本
```

注册项至少包含：

1. 注册身份、当前状态和算法版本；
2. 特征定义稳定身份与比较用途；
3. 算法族及允许的原始值类型；
4. 单位、维度和每个分量的稳定角色；
5. 左右角色及差异正方向；
6. 适用时的周期、坐标系类型、三轴正方向、旋转表示、集合元素身份规则或序列时间基准；
7. 误差预算、相等容差、边界包含方式和量化规则；
8. 适用范围、当前版本、失效条件和被替代版本；
9. 输入输出所有权与生命周期；
10. 允许的结果种类、结果原始类型和是否允许进入持久化准入；
11. 溢出、缺值、未知值、余数、半周期并列、缺样本和版本不匹配的精确处理规则。

同一注册键同时出现多个有效注册属于内部逻辑错误。没有有效注册、注册失效、算法版本不一致、原始类型不匹配或能力矩阵不成立时必须结构化拒绝；禁止回退到普通减法、字节比较、词典序、元素数量、默认单位、默认坐标系或最近似算法。

同一“特征定义稳定身份 + 比较用途”在一个当前版本中只能路由到一个当前有效的算法族和算法版本。旧算法注册可以作为历史证据保留，但不得同时进入当前路由。算法族和算法版本由正式注册路由选择，不由业务调用者临时指定。

注册是特征定义的业务解释合同，不进入 2100 的特征值原始记录。注册表及其索引必须能够按特征定义、比较用途和明确版本确定性读取；缓存只作非权威加速，命中后仍须回读注册身份和当前版本。

## 5. 请求、结果与拒绝合同

新 2100 特征值作为比较输入时，以稳定值身份和对应不可变内容确认输入，不要求值对象携带“原始值版本”。算法、特征定义、材料格式、坐标 / 位姿 / 时间等合同版本属于比较上下文，不进入值对象。以下请求、结果、状态矩阵和第 9 节的“原始值版本”“输入版本”要求只约束既有具名比较 ABI，不是新值对象的字段或普通调用前置。后继新输入合同须明确稳定值身份与原输入回执的承接关系，不得默认补 0、伪造版本或强制新值对象继承；本次不更改既有比较 DTO 和稳定数值合同。

1130 / 4110 的准确特征允许内联 I64 或2100强类型值引用。内联分支没有独立值身份，不伪造值身份、版本或以节点身份冒充；完整准确内容发布后不变。7160 的域匹配使用正式比较规则和固定代表，参数来源按4120第3.3节；比较只返回排序、关系或差异，不写F、存在采用、观察计数、概念或名称。新输入接线须具备独立完整合同，不改变既有DTO、算法和无值失败边界。

准确内容精确匹配与概念域命中分开：前者核对正式表示及完整内容，后者判断完整值相对固定代表的差异是否在域范围内。同域不等于准确相同，域不证明所有成员被观察过，也不保证代表匹配等价于扫描全部历史材料。缺材料或比较失败不能当作不命中；比较成功不证明概念已发布或名称已绑定。观察积累、概念形成和用途计量由7160/7140负责，不再交由F维护历史、计数或建子。

预期算法族和版本只能用于确认上游已经冻结的合同没有漂移；为空时按当前唯一注册路由，非空且与当前路由不一致时拒绝。调用者不得用该字段覆盖注册、选择另一个有效算法或请求默认回退。

`差异材料` 是本轮只读计算结果，必须同时携带结果种类、原始类型、单位、维度、分量角色、方向、算法版本和可表示性。裸 `I64` 或裸向量不得脱离这些材料被解释为变化事实。

`比较拒绝原因` 至少区分：未注册、注册不唯一、注册失效、算法版本不匹配、原始类型不匹配、单位不匹配、维度不匹配、左右角色不合法、值域不允许、坐标或位姿不成立、时间基准不成立、样本不足、差异不可表示、距离不可表示、误差合同不成立和输入版本失效。注册不唯一及前置通过后的算法内部结构异常属于内部逻辑错误，不得伪装成普通不可比。

比较服务只读输入并返回结果，不写特征值、状态、动态、二次特征、因果或其它机器事实。需要持久化时，调用方必须把输入事实、注册身份、算法版本、差异材料和适用范围交给二次特征、状态、动态或其它具名领域服务重新准入。

等价统一入口为：

```cpp
特征比较结果 比较特征(const 特征比较请求& 请求);
```

具体代码文件、模块边界和 C++ 结构字段顺序不在本规范中指定；稳定状态、拒绝原因和结果要求的数值合同由下节冻结。任何实现都必须满足本节行为合同。

## 6. 单位、维度与能力矩阵

比较调度前必须同时验证原始类型、单位、维度、分量角色、算法族和结果种类。最低能力矩阵如下：

| 能力 | 必需前置 | 可产生结果 |
| --- | --- | --- |
| 标量顺序 | 同特征定义、同单位、同版本的有序 `I64` 值域 | 排序三态 |
| 标量差异 | 标量顺序前置成立且差异可表示 | 带单位的 `I64` 差异 |
| 向量分量差异 | 同维、同分量角色、同单位且每分量可表示 | `VecI64` 差异材料 |
| 角度差 | 同角度定义、同单位、同周期和方向约定 | 归一化有符号角差 |
| 空间位移 | 同坐标系，或已有可回查位姿补偿结果；轴和单位一致 | 三维位移材料 |
| 空间距离 | 空间位移成立且指定距离算法和结果单位 | 距离或平方距离材料 |
| 集合关系 | 元素稳定身份规则和去重规则一致 | 具名集合关系及可选差集 |
| 形状距离 | 同形状定义、预处理、采样、尺度和算法版本 | 具名距离及误差材料 |
| 序列变化 | 时间基准、对齐、窗口、缺样本和聚合规则成立 | 具名趋势、变化率或序列距离 |

### 6.1 当前 v1 材料能力边界

当前 v1 比较服务只允许为能够完全由内存权威 `类型化值材料` 和注册上下文计算的算法建立当前有效注册：稳定身份相等、标量有序比较与安全差异、区间关系、向量逐分量差异、角度环形差、集合关系、空间位移与距离。

`旋转或方向差`、`形状距离`、`时间序列变化` 的算法族数值继续保留，但在旋转表示、不可变材料服务只读解析端口、形状 / 序列材料和版本合同形成前不得建立当前有效注册。请求命中零当前注册时返回 `未注册/未注册`；禁止仅凭引用编码非零、节点存在、SQL、裸文件、缓存、SHA-256 或字节数推断材料内容。后继若要启用这些算法族，必须建立新的合同版本，冻结合法材料解析依赖，并在输入值事实的同一事实截止读回材料身份、类型、格式、长度、摘要、来源和生命周期，不得静默改变 v1 构造。

单位可转换时必须先由已登记、可回查且有版本的转换合同形成同单位材料；比较器不得自行猜测比例。维度相同但分量角色不同仍不可比较。

## 7. 精确算法边界

### 7.1 标量、区间与向量

标量差异固定为 `右值 - 左值`。区间算法操作的是正式值域或区间材料，必须登记上下端点是否包含、无界端点表达和关系优先级；区间关系本身不是单个差值，也不得把区间中点、上下界或命中区间当作实际标量值。

向量只在注册项逐一冻结分量角色后，对两个完整向量值事实进行逐分量差异。每个分量独立执行 `右分量 - 左分量` 和可表示性检查；任一必需分量失败时整项拒绝，不得返回可读半结果。逐分量成功 / 缺口仅允许作为内部诊断，业务失败结果不得携带已算出的分量值，不得登记为完整比较成功。逐分量值域区间只能裁决轴对齐允许区域，不得被解释为分量相关性、方向、旋转、拓扑或形状距离。

### 7.2 角度与旋转

角度环形差必须登记周期、正方向、归一化区间和半周期并列裁决。默认形式是把 `右角 - 左角` 归一化为注册区间内的最短有符号差；恰好半周期时必须按注册项选择固定正向、固定负向或结构化拒绝，不得依赖平台余数符号。

旋转或方向差必须使用已登记的相对旋转或夹角算法，并冻结坐标手性、旋转次序、表示方式、归一化和奇异点处理。不得把欧拉角、旋转矩阵或四元数分量直接普通减法后解释为旋转差。

### 7.3 空间位移与距离

三轴位移向量在此只作输入 / 内部计算材料；对外每个分量须成为独立具名 I64 结果。距离、方位、仰角等只是在相应类型与算法已登记时可用的例子，不由本节或标量合同提供实现。

空间位移固定为：

```text
位移 = 右坐标 - 左坐标
```

状态迁移时即 `新坐标 - 旧坐标`。三轴名称、正方向、坐标单位和坐标系版本必须来自注册项。左右材料必须处于同一场景 / 空间坐标系，或先形成带来源位姿、补偿版本和误差预算的可回查补偿结果。

欧氏距离、平方距离、曼哈顿距离或其它距离是不同注册结果，调用者不得自行切换。选择欧氏距离时必须冻结平方、求和、开方、整数舍入和结果单位；选择平方距离时结果单位必须明确为原单位平方，不得伪装成原距离单位。

误差内相等必须由注册项冻结容差形状、包含边界和误差合成方法。没有合法误差预算时不得以经验阈值裁决静止、移动或空间相等。

### 7.4 集合、形状与时间序列

集合比较必须先按稳定元素身份和登记规则去重；顺序不属于集合关系，元素数量相同不等于集合相等。

包围盒、二维轮廓、点集、点云和三维体素按 4120 第 3.1 节保持完整结构，并必须登记不可变材料类型、解析合同、预处理、尺度、采样、对齐、距离算法、误差和版本。比较前必须经不可变材料服务同截止读回并解析两侧完整材料；不得只比较稳定引用、摘要、长度或编码。没有这些合同和解析能力只能保存原始材料或形成结构化缺口，当前 v1 不得宣称已实现形状距离。

时间序列比较必须登记时间基准、窗口边界、采样对齐、重采样 / 插值、缺样本、聚合、变化率分母和输出单位。不得默认补零、默认沿用上一样本或用循环次数替代时间。

## 8. I64 计算、溢出与量化

1. 禁止有符号溢出、无符号回绕、静默饱和和截断后宣称有效结果。
2. 计算 `右值 - 左值` 前必须检查结果是否可由 `I64` 表示；不可表示时返回“差异不可表示”。
3. 即使差异不可表示，标量三态顺序仍可通过不执行危险减法的安全分支得到；不得因差值失败而丢失已经合法可判的顺序。
4. 向量每个分量独立检查。乘法、平方、距离平方和、加权和、比例缩放和时间差必须在每一步检查可表示性。
5. 中间结果或最终结果不能由注册指定类型表达时必须拒绝，不得把更宽概念结果压回有效 `I64` 或 `VecI64`。
6. `VecU64` 只有在注册项冻结合法映射、运算和结果类型时才参与数值差异；不得先强制转换到 `I64`。
7. 整数除法余数直接舍弃，结果最小值为 1 等量化规则不是全局默认。只有目标算法注册项明确冻结适用范围、符号、零值和最小值规则时才能使用；未登记时只执行语言定义的安全整数运算并返回实际结果。

## 9. 调度、版本与持久化边界

比较策略调度顺序固定为：

```text
验证请求和输入身份
-> 按特征定义和比较用途读取唯一当前注册，并核对可选预期算法门禁
-> 验证类型、单位、维度、角色和上下文版本
-> 调用注册算法
-> 验证结果可表示性和误差合同
-> 返回带注册身份和输入版本的结果
```

策略调度不得按原始值形状猜测算法；三个 `I64` 不自动等于三维坐标，两个向量不自动等于轮廓或集合。算法版本、单位合同、坐标 / 位姿版本或输入当前性在调用期间变化时，本轮结果失效并结构化返回，不得以旧结果写入当前事实。

比较结果默认生成即弃。持久化比较或差异事实必须保留两侧输入事实、左右角色、注册身份、算法版本、单位 / 维度、误差和适用范围；输入选择或解释 / 注册合同变化后旧结果只作历史证据，不因此给不可变值对象增加版本。

## 10. 验证

验证至少覆盖：

1. 每个算法族的合法注册和无注册拒绝；
2. 同键多有效注册或同一当前用途多路由的内部逻辑错误；
3. 排序比较量与变化差异量符号不混用；
4. 状态迁移 `新值 - 旧值` 和目标判断左右角色；
5. 类型、单位、维度、分量角色、版本和上下文失配；
6. `I64` 极值差异、向量分量、平方、乘法、加权和与距离累加溢出；
7. 角度跨周期、半周期并列和旋转表示拒绝；
8. 坐标系 / 位姿补偿、轴方向、距离种类及误差边界；
9. 集合去重、形状预处理和序列缺样本；
10. 比较服务零机器事实写入，以及持久化必须重新经过领域服务准入。

## 11. 二值轮廓漂移比较与校正

本节是具名长期特征比较合同 v1，独立于第 6.1 节旧比较注册 v1 的形状能力矩阵；不修改旧注册允许项或旧比较入口。合同显式解析 4120 第 3.2 节的完整二值 U64 组材料，来源为特征服务具名历史合同提供的精确事实。既有 v1 的“独立值节点”仍经原特征值服务公开历史入口恰一次解引用，继续不调用旧不可变材料服务；该旧承载不能等同 2100 新值身份，也不要求新值对象提供历史截止或节点字段。

采用 2100 新值对象的新输入合同，以稳定值身份和不可变内容参与比较；值内容为独立材料引用时按 2100 经正式不可变材料服务读回。该材料服务要求只适用于新输入合同，不改换上一段既有 v1 的提供者。材料语义和全部格式校验属于具名比较合同，不由值类猜测；新输入接线须具备正式合同，本文不宣称已有实现或静默改写旧读取 ABI。

本节具名校正与固定代表规则只按其已登记适用范围复用，不自动成为所有FT的域形成规则。新概念域从真实输入及4120第3.3节类型绑定参数形成，7160负责共享积累、定义查重和首见生成；准确F只保存固定内容。取消首次概念三次门槛不取消以下校正算法的真实样本及参数要求。比较成功、一次越界或内部原型新增不等于概念已发布，也不恢复旧F分裂链。

标量漂移使用独立具名的I64非负绝对差算法，结果大于INT64_MAX时拒绝；它与通用有符号右减左是不同输出类型和规则，不能混用。校正和运行使用同一幅度算法，反序样本{4,2,0}与{0,2,4}产生相同阈值。

输入使用 4120 第 3.2 节的同格式二值图，坐标系、尺寸、分辨率和量化一致。本算法不平移对齐、不旋转、不拉伸；姿态改变保留为观察差异。令非空边界点集为A、B，d(a,B)为到B最近像素中心的欧氏距离。输出为两个方向平均距离之和的一半。实现按注册的正I64定点缩放S，将每个最近距离量化为 floor(sqrt((dx²+dy²)×S²))，再对两个方向的距离和作精确有理合并，最终向下取整；分辨率、单位和缩放由真实输出FT及规则绑定。中间整数采用可检查的充分宽度或安全多字运算，任何溢出拒绝，不能绕回或返回0。

全部输入与正式来源共同回执返回一个具名I64差异结果项，真实阶次为直接来源最高阶次加一，失败无值。不增加持久二次值实例。校正与运行严格使用同一算法版本、缩放和坐标处理；不能在校正时去姿态而在运行时保留姿态。

静止多帧校正至少包含两个互异真实观察身份，可具有相同内容；在同一已声明校正上下文中计算所有无序样本对，阈值为最大差异加同量纲外设误差裕量。裕量及来源参数、样本集合、比较规则、阈值正式保存；不只比较相邻帧，不因缺少参数默认为0。校正失败或总和溢出不得发布阈值。

本距离不是度量：一维边界A={0}、B={0,4}、C={4}时，未缩放距离为1、1、4，违反三角不等式。结构域包含只由完整相等、显式原子集合包含及完整域规则证明，禁止用中心距离加半径推包含。校正样本{0}、{2}、{4}与裕量1得到阈值5（同单位缩放为1）；空前景、错坐标或错单位拒绝。
