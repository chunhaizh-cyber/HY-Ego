# 4182 子规范 特征类型比较绑定与启用规则

编号：4182
日期：20260908
版本：v0.1
状态：正式子规范

## 1. 定位

本规范规定正式特征类型怎样绑定比较合同，先天与后天类型怎样复用算法，以及何时可以形成当前有效注册。它承接4180注册与返回合同、4181算法正文，不建立平行注册表、特征类型总枚举、值字段或独立CRUD服务。

直接上级规范：4180。

直接依赖规范：4120、4181。

相关边界规范：0050、0500、1120、1130、1180、2100、4110、4150、4160、7160、7170、7180。

FT指1120的正式特征定义身份，F指1130的准确特征信息。FT决定值如何解释，F只提供固定准确值；名称、概念域、外设标签及旧代码枚举均不能替代FT。

## 2. 唯一路由及承载

运行时按“FT＋比较用途”读取4180唯一当前注册。一次请求不能因某算法失败而试用另一个算法，不由调用方选取最有利分数。不同用途可以有不同算法，但每个用途必须说明其判定对象和独立输出类型，不能仅靠改名称复制相同路由或绕过注册唯一性。

算法绑定属于FT的业务解释合同及正式关联，不进入2100值对象或1130准确F字段。结构保存由既有特征/规则承接合同经DATA公开服务完成；比较应用位于DATA之外，只读注册与准确输入，不反向调用定义创建、概念形成或观察积累。DATA-L1的可靠性职责及DATA-L2结构职责不因新算法扩大。

定义应用负责形成并核对绑定；初始化只提交已经完整的绑定材料，不在普通比较中临时建FT、输出FT或默认规则。当前没有合法保存/读回承接合同的绑定保持未启用，不以新增私有表、字符串字典或进程单例冒充正式注册事实。

## 3. 类型比较绑定清单

以下是逐项绑定必须证明的内容，不是新增DTO、持久字段或运行期状态码；能从正式FT、算法或关系读回的内容不得重复形成第二权威。

| 绑定项目 | 必须取得的依据 |
| --- | --- |
| 输入类型与用途 | 稳定FT、正式定义内容、用途、所比较属性及适用范围 |
| 值读取 | 内联I64或准确值引用分支、公开读取入口；材料引用适用时的完整解析合同 |
| 值解释 | 表示、单位、缩放、合法范围、维度、顺序及角色；适用时的坐标/颜色/网格/时间合同 |
| 具名算法 | 4180允许的逻辑类别、4181或其它正式专项的精确合同、算法版本及当前路由 |
| 参与方 | 左右固定语义、A/B映射、状态旧/新值或目标/实际值绑定 |
| 输出 | 每项真实输出FT、I64单位/缩放/范围、排序/关系/差异种类、共同来源和必要结果集合 |
| 判等与误差 | 完整判等对象、零值含义、容差及来源、量化与边界；不适用时明确不适用，不伪造校准值 |
| 非成功 | 未注册、材料缺失、错型、错域、未定义、溢出和资源失败的确定分流；必需项失败整次无值 |
| 复用或派生 | 既有算法的适用证明，或新属性形成规则、来源角色、输出类型及依赖终止条件 |
| 可用性 | 真实提供者与读回、适用材料能力、正式注册身份及对应实现验证；不以本文表格证明已实现 |

仅有“类型名字＋算法名字＋默认阈值”不满足清单。正有理缩放必须是正式值合同的参数，不把外设分辨率、软件整数尺度和测量误差混作同一参数。

## 4. 先天类型绑定

先天类型按4120由外设供给规格进入正式定义，不能从当前机器安装了某设备就推定其全部输出已合法可读。初始化必须分别明确值规格、解析、比较用途和参数来源；不同外设只有解释合同一致或已经完成正式转换，才可复用同一比较规则。

比较算法不裁决类型先天/后天来源。轮廓、体素、坐标等名称本身不能证明是设备直接提供或系统后续形成；来源按1120/4120、1180和相应观察规范判断。无论来源为何，进入比较的输入都必须满足同样的完整合同。

外设误差、色彩标定、坐标变换、概念半径和校正裕量只能来自设备正式规格、真实校准或已批准规则。缺少这些材料时，只拒绝依赖它们的比较、容差或分类用途；不把阈值默认设0，也不把其它合同完整的准确F保存、读取和比较一并禁止。

## 5. 后天类型的比较路径

后天类型可以复用有限算法，但必须先明确该类型究竟表达什么属性。其来源最终可追到先天类型，不构成“将源值逐项差异求和即为后天差异”的依据。

### 5.1 语义不变的算法复用

后天类型的值表示、单位、角色、判等对象及零值含义与某项现有算法相容时，可在该后天FT自己的正式绑定中引用同一算法合同。缩小允许域必须证明算法在新域仍成立；若需转换，先形成独立合法转换材料。

复用的是算法，不把新FT偷换为来源FT，不把父类型、根概念或相同名称当作当前注册。某后天类型未绑定时不得沿祖先链随意选取最近算法；复用关系必须在比较前已经明确并可确定读回。

### 5.2 新属性先形成，再比较

对比例、数量、统计量或其它由输入生成的新属性，先按其正式派生规则取得两侧该属性的完整值，再使用该输出FT的比较绑定。规则须固定输入角色、选取范围、缺值处理、分母、单位、量化和失败边界，来源按1180/4150保留。

例如长宽比：长宽(2,1)与(4,2)形成的比例均为2，比例差异为0；分别比较长和宽得到的非零差异不是比例差异。例子不初始化“长宽比”FT，也不提供默认的比例缩放或零分母处理。此类规则缺失时返回缺口，不改为比较源值来冒充所请求属性。

“有桌子的房间”比较的是正式存在性属性时，只关注该属性的有效值；若需比较桌子数量、大小或布局，必须另有相应属性和用途，不能用任意一张桌子的身份或整个房间差异替代。

### 5.3 组成槽位逐项比较

对象表达的是4120具名组成结构时，先按父内角色、顺序和基数对齐，再依每个成员FT的合法绑定比较。允许同一FT在不同角色多次出现，不能用map[FT]覆盖重复成员。集合槽位还须具有成员匹配和去重合同，不把任意排列当稳定对应。

输出保留具名明细；需要AND/OR、评分或总体差异时必须引用独立规则。无规则时不生成“整体相同”“平均差异”或总分；一个项目不同也不能未经识别规则就断言两个存在身份不同。

对仅需区分指定属性的用途，可按已经登记的短路条件结束；需要完整比较或完整合取时必须处理全部必需项，未比较项不能标相同。缺材料、不可比较和计算不同是不同分支。

### 5.4 依赖与终止

来源展开遵循有序角色和明确的无环依赖；递归终止于已具备合法输入与比较合同的叶子，不一定每次重新展开到外设原始样本。已经正式形成的后天准确值可以直接按其FT比较，但来源仍须符合相应用途的读取条件。

循环依赖、槽位不足、缺少派生规则或资源边界不成立时结构化失败。不得以无限递归、自动穷举、丢弃难比较的成员或重复回退算子掩盖缺口。实例归属与复合关系概念仍遵守原规范，本节不新增持久高阶实例。

## 6. 启用条件与适用清单

须区分三项独立事实：算法合同已定义、具体类型绑定已完整、对应实现与消费者已验证。只有前两项和正式可用的解析/计算/注册承接能力同时成立，才允许相应当前注册供调用；已验证结论另须给出真实代码基线及验证范围。规范目录中的一行不是运行期注册项。

以下清单只规定算法的适用与门禁，不建立任何真实FT或注册身份，也不证明运行能力：

| 类型/用途 | 算法来源 | 启用前必须补齐或核对 |
| --- | --- | --- |
| 同域有序I64的排序、有向差异、幅度 | 4180、4181第4节 | 实际FT/用途注册、单位缩放、输出FT和提供者；旧v1只按其原允许结果使用 |
| 完整内容精确匹配 | 4181第3节 | 完整读取及精确表示合同；新增逻辑类别的ABI承接不复用旧稳定身份比较编码 |
| 普通数值向量或BGR编码L1差异 | 4181第4、6节 | 数值向量距离类别承接、分量单位/范围/编码、输出合同和实际注册；不进入旧v1允许集 |
| 空间距离与极坐标关系 | 4180、4181第5节 | 共同坐标、基准三轴、输入变换、距离/角度缩放、退化及必需结果集合、真实计算实现；新角度输出不伪装成旧位移输出 |
| 既有二值轮廓边界漂移 | 4180第11节 | 原具名提供者与完整材料；新2100输入还须独立完成原回执承接，不改变既有公式 |
| 完整已知位图/体素占据差异 | 4181第7节 | 同网格完整解析、合法单元、未知分账、输出FT和形状算法启用合同；不扩大旧v1形状允许面 |
| 感知色差、颜色概念分类 | 4181第6节、7160 | 感知算法及族归属、标定、精确量化或完整概念域；本版不默认启用 |
| 任意点云几何、旋转不变形状、部分可见相容度、时间序列 | 4180、4181的能力边界 | 各自完整算法、材料、对齐、有效性与误差合同；本版不提供兜底算法 |
| 后天属性与组成槽位 | 本规范第5节 | 复用/派生/槽位路线明确、完整来源、每叶绑定、有限依赖及结果合成规则 |

没有当前有效注册，仍按4180返回未注册；注册不唯一属于内部不一致；已声明能力却缺失其必需提供者不能返回成功。本文不新增“待启用”运行状态枚举；缺口描述只用于辨认未具备的合同或能力，不代替原结构化拒绝。

先天与后天共享此门禁。类型允许保存不等于每种用途均可比较；一种比较用途已可用不等于分类、命名、变化判定及其它算法均已可用。

## 7. 规则变更、旧材料及验证

算法公式、角色、缩放、量化、坐标、颜色解释、材料格式或判等对象改变时，按4180和原注册合同形成可区分的新解释，不能原地改义后复用旧输出或阈值。算法及解释版本留在规则/比较上下文，不重新加入值对象或准确F字段；既有版本、状态码、结果位集和历史记录不因本规范被重排。

参考实现的策略表、字符串链键、默认K、命中次数和指针类型不取得正式注册身份。自动补零、同类型覆盖、异量纲汇总、海明率截断零冒充精确相等、边界相似冒充完整判等等做法不得进入当前绑定。参考算法须经过完整合同、目录归属、实际提供者与验证，不凭“曾运行”启用。

最低验证包括：

1. 同FT同用途唯一路由；多注册、无注册、失效和版本漂移正确分流。
2. 名称相同、值表示相同、上位概念相同不能跳过输入类型/用途核对。
3. 新内联I64、准确值引用、独立材料分支正确读取，不伪造值身份或版本。
4. 后天比例例子、重复FT的不同槽位、无环和资源不足、缺规则不得回退。
5. 精确匹配、量化零、容差等价、域命中的独立结果与用途限制。
6. 算法专项边界样例、全部失败无值、比较零机器事实写入。
7. 新算法文档或绑定声明不能绕过旧v1能力矩阵、当前输入合同及C038持久实例限制。

规范完成不证明代码、注册事实、外设标定、解析、运行或业务验收完成；未启用条目不得因目录登记转为已实现。
