# 1110 根规范 指代

编号：1110
日期：20260911

状态：正式根规范

## 1. 根定位

指代是在确定交互、来源位置、引语作用域和解析结果材料内，将一次语言出现绑定到具体可读对象的引用。代词文本、词条或概念名称关系都不是被指代对象身份。

## 2. 本项目承载

持久指代使用指代关系身份、来源语言材料及固定范围、目标强类型引用、所属解析结果材料和交互作用域承载。出现序号与位置属于来源内定位，不是目标身份；活动发布与历史沿既有结构服务保存。字段和临时交互结构由7230统一规定。

数组或映射可以承载调用期代词候选，但不能构成全局“词面→对象”永久表，也不按每个交互者永久维护一份固定代词表。

## 3. 成立与消歧边界

1. 来源、固定解析、作用域和目标必须完整；首次发布时目标须经对应公开服务在所声明截止可读。
2. “我”取当前说话者，“你”须唯一确定当前受话对象；“他/它/这/那”按类型、焦点和语境消歧。多候选保留，不能按数组首项猜选。
3. 引语可以改变说话者、参考时间与地点，退出引语恢复外层语境。作者、说话者、引用来源和被回应者不同。
4. 文章、日记和单向输出仍可含指代，不强制实时交互、确定收件人或被回应消息。引用对象缺失就返回未决，不伪造接收者。
5. 关系成立仅证明本次解释所指；不证明目标的状态、陈述真伪或对方同意。

## 4. 写入和历史

DATA外语言应用裁决本次指向，既有语言结构服务唯一发布。临时未决项不取得持久指代身份；需要保存的完整已解绑定经正式服务写入并读回。

旧指代按原材料与解析结果材料读取，不因后续“他”转指他人、焦点更换或目标当前退出而重新指向。历史读取依所声明历史截止与引用保护执行，不要求过去目标在今天仍活动，也不能把历史绑定冒充当前可执行对象。

解析纠正建立新解析结果/新绑定并退出原当前发布，保留历史；不得原地覆盖旧目标后声称原句一直指向新对象。

## 5. 禁止与路由

禁止按代词、显示名、词面、日志或数组下标直接取得业务身份；禁止把引用成立升级为需求确认、动作授权或世界状态。候选、上下文和结构读取失败由7240分账；不为说明指代冲突额外制造世界状态、动态或证据节点。
