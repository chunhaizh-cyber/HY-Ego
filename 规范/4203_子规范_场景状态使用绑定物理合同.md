## 1. 定位与对象边界

本规范只把4202已经确定的 `发生场景 C + 被描述存在 E + 中性状态 S` 完整使用绑定落实为可独立引用、写入、读回、退出和恢复互证的物理合同。它不重新讨论状态或动态模型，不恢复属性上下文P，不增加状态本体字段，不冻结场景七字段的其它实现，也不建立新的节点族或技术 owner。

绑定由场景结构 owner 唯一写入。状态类仍唯一拥有S内容；存在类仍唯一确认E结构身份；场景状态绑定只保存三者在一次具体使用中的共同关联。共享S、相同C/E/S或同E同FT均不自动合并不同观察。

## 2. 固定物理结构

一份绑定以普通节点B承载。B属于场景结构 owner，节点种类为普通，无属性和值，不取得独立族锚点。B经同一场景 owner 的一个稳定成员关系类型恰好建立三条出向关系：

| 角色 | 源 | 目标 | 含义 |
| --- | --- | --- | --- |
| 1 | B | C | 发生场景 |
| 2 | B | E | 被描述存在 |
| 3 | B | S | 中性状态 |

B、C、E及S编码均非零；B与C/E/S均互异，S与C/E均互异。C与E允许是同一底层节点编码，但仍必须分别通过场景族和存在族身份确认，两个角色不得合并。三条关系编码互异。成员关系类型与场景族锚点、场景族归属关系类型互异。B和三条关系必须在一个 owner-scoped 写集中发布或退出，禁止半组公开、后续补边、按孤立边拼接或笛卡尔组合。

B身份只有在指定截止内同时证明普通空节点、三条角色唯一关系、精确C/E/S目标、场景owner及三族身份后成立。旧场景状态成员边、存在状态成员边、C到S/E到S散装关系、状态当前选择、数组或旧关系编号均不能重释为B。

## 3. 精确 C++ 合同

### 3.1 模块与无环依赖

新增 `海中鱼巣/领域/合同.场景状态使用绑定.ixx`，模块名固定为 `海中鱼巣.领域.合同.场景状态使用绑定`。该模块只导出本节值式DTO、守卫和两个抽象只读接口 `存在结构身份只读提供者`、`状态使用绑定只读提供者`；不得 import 场景类、存在类、动态类或应用层。

`海中鱼巣.领域.数据服务.场景类` import该合同并由场景类数据服务实现状态使用绑定窄接口；它只通过 `const 存在结构身份只读提供者&` 消费存在身份，并可依赖状态类，不得 import 或持有完整存在类。后继动态类只 import 本合同并持有 `const 状态使用绑定只读提供者&`，不得 import 或反向持有完整场景类。

结构交付三项非零互异、属于同一场景owner且当前可读。成员类型不得兼作场景族归属关系类型。

创建、读取、退出结果各携带可选完整绑定事实；组查询携带按B编码严格升序且无重复的完整事实组。空组是合法成功；预算不足不得截断成功。

`状态使用绑定事实完整`固定检查全部编码、截止、生命周期和互异约束：C与E可相同；B与C/E/S互异，S与C/E互异；三关系彼此互异且不得等于B/C/E/S。`状态使用绑定创建结果::成功()`只接受已创建/精确重复、非零且相等的结果截止/变更代次、完整当前绑定和创建代次相等；读取成功只接受已读取、无变更代次和同截止完整载荷；组查询还要求空组合法、非空组按B严格升序；退出成功只接受已退出/精确重复、`H=Gexit-1`、退出代次等于结果截止和完整退出前载荷。`存在结构身份只读结果::成功()`只接受已读取、版本1、`0<H<=Gread`、四个身份编码及创建代次完整、且H早于可选退出代次。所有 `未实现` 的成功谓词恒为false。

创建或精确重复成功时变更代次非零，载荷 `Gread=H=变更代次`。当前读取成功时 `Gread=H=G0`；历史读取成功时载荷 `Gread` 与请求一致且 `H` 精确回显；退出成功载荷采用 `Gread=Gexit、H=Gexit-1`，B和三条关系的退出代次均为Gexit。

`存在结构身份只读提供者` 在本合同中先作为最终抽象边界发布；ABI骨架阶段不要求当前存在类继承或实现该接口，也不得为取得一个骨架实现而迁移存在类中的旧状态消费者。它只允许由后继合法存在族身份生产切片在正式生产模块中实现。状态类继续复用4212的 `确认当前状态结构身份`、`读取当前状态`、`读取状态历史内容`和历史身份见证，不增加绑定字段。场景族当前/历史共同身份入口继续由4230约束，不混入本合同绑定ABI；其合法生产路径未形成前，绑定真实实现不得发布成功。

窄接口只包含 `绑定于(const L1事实基座服务&)`、`读取当前状态使用绑定`、`读取状态使用绑定历史`。它不暴露写端口、场景组织、反向组查询或完整场景读取。

### 3.4 编译骨架

4201允许在本节最终ABI上先形成显式未实现骨架。任何骨架结果固定为：合同版本正确、状态为 `未实现`、事实截止代次为0、变更事实代次为空、全部optional/vector载荷为空；不得访问L1事实、写端口、其它provider、幂等账、索引、时钟或日志。调用方必须立即停止成功路径，不得把 `未实现` 映射成未找到、空组成功、资源失败或动态来源成立。

只有场景C和存在E的合法族身份生产及4230当前/历史确认路径发布后，才能在同一模块、同一签名中以真实实现替换骨架；不得保留运行期开关、回退或双实现。骨架只证明模块、DTO、接口和安全拒绝可编译，不证明B事实的创建、读取、退出、恢复或后继动态依赖满足。

## 4. 创建、读取与幂等

创建先固定G0。场景owner内部确认C当前；分别调用存在和状态的具名当前身份确认；状态确认成功后还必须读取S完整内容。所有结果截止均为G0后，才能提交B与三边同写集。

提交或精确重复后，以首次发布代次独立完整读回。已绑定幂等键先读取首次规范化请求和首次结果：同义请求返回首次结果，异义请求返回幂等冲突。只有事实代次漂移明确不绑定幂等身份；提交后读回失败不得回滚，返回已可能发布并保留原键供重放收敛。

当前/历史读取必须在一个固定截止内读回B及三边，并调用三族具名身份或内容提供者互证。不得把当前成员、当前采用或晚于H的事实补进历史。反向查询按成员类型与目标召回，再按角色筛选；预算计算包含全部召回候选，逐B完整读回后稳定排序。

## 5. 退出、引用保护与恢复

退出只退出B和三条自有关系，不删除或退出C、E、S。存在活动动态或其它正式引用时返回引用冲突。H早于退出代次时历史内容仍完整；H不早于退出代次时返回目标已退出，不用残余关系重建完整绑定。

本合同不建立独立恢复写入口。4070只恢复L1节点、关系及生命周期；恢复后本服务用相同结构交付执行有界当前/历史闭包互证，只重建可丢失索引，不补边、不猜角色、不更换B。缺失、重复、错owner、错角色或混代均失败开放为内部不一致或历史材料已清理。

存量旧结构没有无歧义转换规则。本版不扫描迁移、不双读双写；新入口对旧散装形状返回旧格式不支持或入口拒绝。旧L1事实继续按原生命周期保护。

## 6. 实施与验证边界

首段ABI骨架允许只实现本合同、持有抽象存在provider引用的场景绑定骨架及工程登记；不要求存在类提供骨架实现。存在共同身份生产及其接口实现留给合法存在族身份生产后继，不得借本段迁移旧状态消费者。首段不实现完整场景七字段、动态、动态概念、动作、因果、SELF或普通应用装配。

最低验证覆盖：一B三边；角色唯一；C/E/S缺失、退出或错族；共享S的两绑定不串配；同键同义与异义；当前/历史/退出；三类反查空集、多项及预算不足；外部引用保护；旧散装零解析；窄接口零写；模块import无环。构建证据与当前其它空模块或异主WIP导致的根工程失败分账。
