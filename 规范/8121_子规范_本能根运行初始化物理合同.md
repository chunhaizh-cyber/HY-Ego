# 8121 子规范 本能根运行初始化物理合同

编号：8121
日期：20261004
版本：v1.0
状态：正式子规范

直接上级规范：8100。

直接依赖规范：0050、3100、6130、7130、8120。

相关边界规范：1130、1140、4015、8200。

## 1. 范围

本规范规定self线程初始化时如何建立并读回世界树、自我和安全/服务双根。它只定义初始化物理顺序和结果，不建立运行锚点、初始化包、业务历史或第二当前权威。

## 2. 唯一结构

初始化完成后必须具备：

```text
全局基础数据集
├─ 世界树根场景
│  └─ 自我所在场景
│     └─ 自我存在节点
├─ 需求树根
│  ├─ 安全根需求
│  └─ 服务根需求
└─ 方法根
```

特征值组织根、特征概念树根、存在概念图根和自然语言组织根按各自规范初始化，不因本规范另建第二份。

全局`世界树根节点`、`自我所在场景节点`和`自我节点`保存对应稳定编码；稳定编码本身是身份，但业务类型和结构仍须经各类完整读回确认。

## 3. 初始化顺序

1. 初始化基础数据集及持久单调编码高水位。
2. 初始化先天特征类型和特征概念根。
3. 调用世界树类初始化函数建立或精确复用世界树根场景。
4. 在世界树根下建立或精确复用自我所在场景。
5. 在该场景内建立或精确复用自我存在，并设置三个全局节点变量。
6. 初始化需求树；通过需求类一次建立或精确复用安全根与服务根。
7. 初始化方法根和本能函数登记。
8. 分别完整读回世界树、自我、双根目标和当前值。
9. 全部成功后才允许self治理开门。

前一步未完成时不得越过建立后一步。普通初始化重复调用必须精确复用现有结构；发现同一角色多个节点、父关系不一致或定义异义时返回结构冲突。

## 4. 双根合同

安全根和服务根：

- 目标固定为`INT64_MAX`；
- 首次当前值固定为`INT64_MAX / 2`；
- 各自拥有独立特征定义、实例特征、目标合同、根需求和固定列表项；
- 由需求类具名角色读取，不按顺序、名称、编码大小或目标值猜测；
- 读取采用current-only，不携带事实截止、合同版本或历史见证；
- 双根共同建立失败时不得返回半成功。

根身份直接来自正式需求结构。不建立`本能根运行锚点_v1`、角色节点、角色关系、固定业务幂等身份、原请求账或第二需求账。

## 5. 结果与失败

初始化返回结构化状态，至少区分：

```text
已建立
已复用
入口拒绝
定义冲突
结构不一致
依赖未实现
资源失败
```

成功结果必须包含世界树根、自我所在场景、自我、安全根、服务根和方法根身份，并由调用方再次完整读回。

当前基础数据集没有跨多个业务类的崩溃原子事务时，初始化只能分阶段发布；后段失败保留已经合法发布的前段结构，下一次按current-only结构精确复用并继续。不得通过删除已发布世界、自我或根需求来伪造整体回滚。

## 6. 禁止与验证

禁止：

- 在应用入口或manager重复拼装世界树、自我或双根字段；
- 以线程创建成功代替初始化成功；
- 为初始化步骤建立任务；
- 使用事实代次、历史读回、运行锚点或初始化包证明当前结构；
- 只建立一个根却打开治理门；
- 用默认编码、名称或创建顺序猜测根角色；
- 因后段失败删除已经合法发布的前段结构。

最低验证覆盖首次建立、重复精确复用、单根失败停门、角色复义、父关系错误、双根定义冲突、后段失败再入、完整读回和治理门控制。
