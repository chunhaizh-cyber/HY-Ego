# 4115 子规范 实例特征容器与区间材料

编号：4115
日期：20260915
版本：v0.1
状态：正式子规范

直接上级：1130、1140、2100。直接依赖：4015、4030、4040、4050、4110、4120、7150、7160。

## 1. 定位

实例特征容器 `IF` 是同一存在 `E` 对同一正式特征类型 `FT` 的唯一持久结构入口。它不是准确特征 `F`、特征值、概念或存在当前采用关系；一个 `IF(E,FT)` 可组织多个准确 `F` 和一组持久区间材料 `R`。同一 `(E,FT)` 至多一个当前 IF；不存在当前采用不妨碍 IF、F 或 R 存在。

F 仍按1130/4110具有一个固定准确值、明确 C/P 位置及一个已发布单值特征概念 `FCv` 的使用引用。IF 不是 F 的组织父 P；F 的 C/P、holder、已知引用和位置不因 IF 新增而改变。

## 2. 结构、写入者与读回

存在 owner 唯一写入 IF、IF 到 F 成员、R集合身份、R集合不可变版本、版本到 R 项和 R 项到形成 F 成员；它同时仍唯一写入 E 已知 F 与 `E+FT -> 当前采用F`。概念 owner 唯一写入 `(R集合版本, 概念汇聚)` 幂等完成记录、FC、F 到 FC 使用和概念上下位；概念应用只组合这两类已发布事实，不取得第三个写 owner。不得建立第二当前值、第二已知 F 列表或第二概念仓。

IF 成功读回必须同截止返回 `E、FT、成员F*、R集合当前版本、R项*`；R 项按稳定排序读回其类型解释、成员 F 和生命周期。任何空、预算不足、退出、引用损坏、代次漂移和内部不一致分别返回，不能截断为完整成功。

## 3. F 加入与 R 自动维护

建立/复用 F 前，应用按7160在该 FT 的全部适用 FC 中查找；没有匹配时仅可使用“准确输入加 FT 已冻结域规则”建立并读回首个 FC。不得以 R、裸值或未发布 F 建立 FC。随后 F 与其直接 FC 使用引用共同成立，再将 F 加入 IF；新 F 不隐式改变存在当前采用。

IF 的比较基准是本次一致读取中的 `E+FT` 当前采用 F。没有当前采用时首个 F 形成首个 R。I64 只按完整准确值相等归入同一 R；不同 I64 必须形成新单值 R，不使用 `值±误差`、相邻或重叠合并。其它枚举表示由 FT 已发布的比较/阈值合同判定：未超过阈值归入当前 R，超过阈值形成新 R；合同未启用时返回具名不支持且零 IF/R 写入。R 变化只在成员或规范化 R 集合实际变化时发布新集合版本。

## 4. 概念汇聚

每个新 R集合版本以 `(R集合身份,版本身份)` 唯一触发一次概念汇聚。概念类按该版本完整读回 R、FT 和成员 F：没有 FT 明确归并规则时成功收束为零上位 FC 写入；有规则时查重或建立区间/组概念 `FCr`，并将 `FCr` 建为其单值 `FCv*` 的上位概念。不得替换 F 到 FCv 的直接使用引用，R/FCr 也不得充当 F 的名称字段。

汇聚失败不回滚已发布 R；完成记录不成立，重试必须复用同一 R版本幂等身份。R 未变化不得创建触发或概念写入。

## 5. 退出与禁止

移除成员、R 版本换代或 IF 退出须先核验当前采用、F 位置、概念使用、R 汇聚记录及外部引用；历史版本和已退出关系按4015保留。不得原地改 F 的类型或准确值，不得将概念允许域、2100值对象、I64误差域或旧特征分裂树冒充 R。
