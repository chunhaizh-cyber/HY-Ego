# 4115 子规范 实例特征容器与区间材料

编号：4115
日期：20260918
版本：v0.5
状态：正式子规范

直接上级：1130、1140、2100。直接依赖：4015、4030、4040、4050、4110、4120、7150、7160。

## 1. 定位

实例特征容器 `IF` 是同一存在 `E` 对同一正式特征类型 `FT` 的唯一持久结构入口。它不是准确特征 `F`、特征值、概念或存在当前采用关系；一个 `IF(E,FT)` 可组织多个准确 `F` 和一组持久区间材料 `R`。同一 `(E,FT)` 至多一个当前 IF；不存在当前采用不妨碍 IF、F 或 R 存在。R 的区间材料是 FT 解释的实例归组摘要，不是2100实际值、准确 F 或特征概念允许域；它可按正式 FT 规则给出调用期代表值，但代表值不是实际观察的准确值。

F 仍按1130/4110具有一个固定准确值、明确 C/P 位置及一个已发布单值特征概念 `FCv` 的使用引用。IF 不是 F 的组织父 P；F 的 C/P、holder、已知引用和位置不因 IF 新增而改变。

## 2. 结构、写入者与读回

IF、R集合、R集合版本和R项均是存在 owner 按需建立的独立普通节点；不得预建空 IF/R 占位。存在 owner 唯一写入 IF、IF 到 F 成员、IF 到 R集合、R集合到当前版本、版本到 R项及 R项到形成 F 成员；它同时仍唯一写入 E 已知 F 与 `E+FT -> 当前采用F`。概念 owner 只写 FC、F 到 FC 使用和概念上下位；概念应用只组合已发布 IF/R 与概念事实，不取得第三个写 owner，也不保存汇聚回执。不得建立第二当前值、第二已知 F 列表或第二概念仓。

存在类初始化以其唯一固定初始化幂等身份登记并读回六个稳定关系类型，顺序固定为：`E→IF`、`IF→F成员`、`IF→R集合`、`R集合→版本`、`版本→R项`、`R项→F成员`。登记只建立关系类型节点，结果以值式`实例特征结构交付`注入存在类构造；它不建立任何 IF/R 实例。首次材料、精确重放、异义键、类型数量/顺序/退出和交付不完整必须分账。构造器拒绝缺失、重复、相等、退出或未绑定于同一 L1/存在 owner 的交付。

每个 IF 在当前范围内至少有一个 F成员并从该成员读取唯一 FT；全部成员的正式 FT 必须相同。每个 IF 当前恰有一个 R集合，R集合当前恰有一个版本，版本至少有一个 R项；每个 R项都有一个非空、由 FT 解释的区间材料，并至少保留一个形成它的 F成员，相关成员均属于该 IF。R项的区间材料与其 F成员固定；漂移内候选值不形成 F，但使区间材料变化时，必须建立新 R项快照，不能原地改旧项。R集合版本更新时退出旧的`R集合→版本`当前关系、建立新版本及完整当前 R项组；未变化的 R项可被新版本复用，变化的 R项必须新建，不得修改旧项。上述节点、关系、旧版本退出与新版本快照在存在 owner 的一次写集中发布，失败零 IF/R 发布或按原请求读回已可能发布结果。

IF 成功读回必须同截止返回 `E、FT、成员F*、R集合当前版本、R项*及各自区间材料`，并回显六关系身份、各节点及关系的创建/退出事实代次；R 项按 R项节点编码和成员 F 编码稳定排序读回。任何空、预算不足、退出、引用损坏、代次漂移和内部不一致分别返回，不能截断为完整成功。

### 2.1 IF/R 的 L2 读取与目标写入合同

存在类的 `读取IF/R结构` 请求只接受非零 `E、FT、Gread`，以及分别非零的 `F成员上限、R项上限、关系上限`；它不接受“首次”“后续”“结构异常”“观察”或任何业务阶段字段。成功以同一 `Gread` 返回完整 IF/R 当前投影及实际读取截止；任一上限不足必须返回预算不足，不能截断成员、R项或关系后宣称完整成功。

存在类的 `提交IF/R目标结构` 请求必须同时携带：

```text
E、FT
+ 非零预期快照截止 G0
+ 预期 IF/R 完整当前快照
+ 规范化目标 R 项组（每项的形成 F 成员及区间材料）
+ 本次存在结构写入幂等身份
+ 成功完整读回所需的三项预算
```

预期快照在首次路径明确为 IF/R 均不存在；当前采用不属于该快照。在后续路径，快照明确包含当前 IF、成员 F、R集合、当前版本、R项、各 R项区间材料、六类关系及其当前性所需身份；L2 只核验该快照，不自行判定首次、后续、结构异常或当前采用。规范化目标 R 项组是一个非空、按每项最小形成 F 编码升序的序列；每项形成 F 成员编码严格升序、非空且全局不重复，区间材料按 FT 的正式规范化规则相等才可复用。目标项组必须覆盖预期 IF 的全部成员；首次或后续新增的其它 F 必须在 G0 时已是 E 的已知同 FT 准确 F，L2 在本次写集中建立其 IF 成员关系。不能以裸值、概念、隐式当前采用、局部差异或调用方顺序代替。

L2 按预期快照和完整目标项组只进行中性结构核验、R项复用/新建、旧版本退出和新版本原子发布；它不创建 F、FCv、FCr、当前采用或业务诊断。目标与当前规范化项组相同则成功读回既有版本且不建立新版本；不同才发布完整新版本。预期快照在交换前不符时返回漂移或引用冲突并零本次写，不重新分类或改写目标。幂等身份只在存在结构请求命名域内按完整请求绑定：同键同完整请求读回原结果，同键异请求返回幂等冲突。

读取与写入分别精确区分：请求非法、未找到、已退出、预算不足、漂移、引用冲突、幂等冲突、资源失败、发布未知和内部不一致。交换前非成功不产生本次 IF/R 事实；发布未知或发布后读回失败保留原幂等身份并按原请求读回收束，不得假称零写或回滚。

## 3. F 加入与 R 自动维护

候选新值先与该 IF 的全部当前 R项区间材料进行同截止、同 FT 的归组比较；存在当前采用 F 不得作为比较输入、默认基准或回退。R归组、区间更新、代表值和 R→FCr 归并规则均由正式特征类型定义 owner 持久保存、发布并按 FT 读取；概念 owner 只消费归并输出建立/复用 FCr 及其上下位，不保存或解释 FT 规则。正式 FT 的 R归组规则必须返回唯一“命中 R项并给出更新后区间材料”、`形成新R`、`比较未启用`或具名非成功；同时命中多个 R项属于内部不一致，不能任选。命中唯一 R项时不建立或复制 F，只按规则给出的新区间材料发布新的 R项快照；新区间材料与原材料相等时零 IF/R 写入。形成新R时才建立/复用对应准确 F：应用按7160在该 FT 的全部适用 FC 中查找；没有匹配时仅可使用“准确输入加 FT 已冻结域规则”建立并读回首个 FC。不得以 R、裸值或未发布 F 建立 FC。随后 F 与其直接 FC 使用引用共同成立，并形成以该 F 为形成成员的兄弟 R项；新 F 不隐式改变存在当前采用。

I64 仍只按完整准确值相等归入同一 R；不同 I64 必须形成新单值 R，不使用 `值±误差`、相邻或重叠合并。非 I64 的 R归组、区间材料更新和代表值选择均只能调用 FT 的已发布规则；枚举、轮廓、体素等不具有天然中位值，不能默认把任一值、编码、向量分量或材料摘要当作代表值。需要单点计算时，应用可读取 FT 规则从完整 R区间材料导出的调用期代表值；该值不是准确 F、实际观察或存在当前采用，不能写入 F 或替代要求真实准确值的读取。

## 4. 概念汇聚

每个实际新 R集合版本成功发布后，应用只可在该次成功发布所在的调用链内至多同步尝试一次概念汇聚；这是一项 best-effort 调用期动作，不承诺跨进程、恢复后或全局的恰一次、至少一次或最终必达语义。归并规则是 FT 的正式、已发布且可读取的规则数据；它接收该版本完整的 R项、成员 F 及其 FCv，并返回零个或多个规范化 `FCr` 定义及各自的 `FCv*` 直接下位集合。没有 FT 明确归并规则时该次尝试成功收束为零上位 FC 写入；有规则时概念类按返回定义查重或建立区间/组概念 `FCr`，并将 `FCr` 建为其 `FCv*` 的上位概念。不得替换 F 到 FCv 的直接使用引用，R/FCr 也不得充当 F 的名称字段。

汇聚不保存 `(R集合身份,版本)` 回执、完成记录、重试任务或恢复游标；进程在 R 发布后、汇聚调用前或调用中终止，不要求后续恢复补做该次尝试。汇聚在 R 已发布后失败时，调用结果必须明确为“R已发布、汇聚未完成”，并保留已发布 R，不得回滚 R 或自动重试；未来对历史版本的再次汇聚属于独立治理能力。R 未变化不得创建触发或概念写入。

## 5. 退出与禁止

移除成员、R 版本换代或 IF 退出须先核验当前采用、F 位置、概念使用及外部引用；历史版本和已退出关系按4015保留。不得原地改 F 的类型或准确值，不得将概念允许域、2100值对象、I64误差域或旧特征分裂树冒充 R。
