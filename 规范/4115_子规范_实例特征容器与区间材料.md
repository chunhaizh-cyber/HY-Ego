# 4115 子规范 实例特征容器与区间材料

编号：4115
日期：20260915
版本：v0.1
状态：正式子规范

直接上级：1130、1140、2100。直接依赖：4015、4030、4040、4050、4110、4120、7150、7160。

## 1. 定位

实例特征容器 `IF` 是同一存在 `E` 对同一正式特征类型 `FT` 的唯一持久结构入口。它不是准确特征 `F`、特征值、概念或存在当前采用关系；一个 `IF(E,FT)` 可组织多个准确 `F` 和一组持久区间材料 `R`。同一 `(E,FT)` 至多一个当前 IF；不存在当前采用不妨碍 IF、F 或 R 存在。

F 仍按1130/4110具有一个固定准确值、明确 C/P 位置及一个已发布单值特征概念 `FCv` 的使用引用。IF 不是 F 的组织父 P；F 的 C/P、holder、已知引用和位置不因 IF 新增而改变。

## 2. 结构、写入者与读回

IF、R集合、R集合版本和R项均是存在 owner 按需建立的独立普通节点；不得预建空 IF/R 占位。存在 owner 唯一写入 IF、IF 到 F 成员、IF 到 R集合、R集合到当前版本、版本到 R项及 R项到形成 F 成员；它同时仍唯一写入 E 已知 F 与 `E+FT -> 当前采用F`。概念 owner 只写 FC、F 到 FC 使用和概念上下位；概念应用只组合已发布 IF/R 与概念事实，不取得第三个写 owner，也不保存汇聚回执。不得建立第二当前值、第二已知 F 列表或第二概念仓。

存在类初始化以其唯一固定初始化幂等身份登记并读回六个稳定关系类型，顺序固定为：`E→IF`、`IF→F成员`、`IF→R集合`、`R集合→版本`、`版本→R项`、`R项→F成员`。登记只建立关系类型节点，结果以值式`实例特征结构交付`注入存在类构造；它不建立任何 IF/R 实例。首次材料、精确重放、异义键、类型数量/顺序/退出和交付不完整必须分账。构造器拒绝缺失、重复、相等、退出或未绑定于同一 L1/存在 owner 的交付。

每个 IF 在当前范围内至少有一个 F成员并从该成员读取唯一 FT；全部成员的正式 FT 必须相同。每个 IF 当前恰有一个 R集合，R集合当前恰有一个版本，版本至少有一个 R项，R项至少有一个 F成员；相关成员均属于该 IF。R项与其 F成员固定，R集合版本更新时退出旧的`R集合→版本`当前关系、建立新版本及完整当前 R项组；未变化的 R项可被新版本复用，变化的 R项必须新建，不得修改旧项。上述节点、关系、旧版本退出与新版本快照在存在 owner 的一次写集中发布，失败零 IF/R 发布或按原请求读回已可能发布结果。

IF 成功读回必须同截止返回 `E、FT、成员F*、R集合当前版本、R项*`，并回显六关系身份、各节点及关系的创建/退出事实代次；R 项按 R项节点编码和成员 F 编码稳定排序读回。任何空、预算不足、退出、引用损坏、代次漂移和内部不一致分别返回，不能截断为完整成功。

## 3. F 加入与 R 自动维护

建立/复用 F 前，应用按7160在该 FT 的全部适用 FC 中查找；没有匹配时仅可使用“准确输入加 FT 已冻结域规则”建立并读回首个 FC。不得以 R、裸值或未发布 F 建立 FC。随后 F 与其直接 FC 使用引用共同成立，再将 F 加入 IF；新 F 不隐式改变存在当前采用。

IF 的比较基准是本次一致读取中的 `E+FT` 当前采用 F。没有当前采用时首个 F 形成首个 R。I64 只按完整准确值相等归入同一 R；不同 I64 必须形成新单值 R，不使用 `值±误差`、相邻或重叠合并。非 I64 仅可调用特征类的只读`FT+R归组用途比较`：请求同时给出 FT、当前采用基准 F、候选 F、同截止和预算；结果仅为`归入当前R、形成新R、比较未启用`或具名非成功。只有相同 FT、两个完整准确 F 且已启用的正式比较方案才能返回前两项；当前没有真实提供者时必须返回`比较未启用`，并且零 IF/R 写入。不得把比较未启用解释为“形成新R”，不得假称枚举算法已经实现。R 变化只在成员或规范化 R 集合实际变化时发布新集合版本。

## 4. 概念汇聚

每个实际新 R集合版本发布后，应用只同步尝试一次概念汇聚。概念类按该版本完整读回 R、FT 和成员 F：没有 FT 明确归并规则时该次尝试成功收束为零上位 FC 写入；有规则时查重或建立区间/组概念 `FCr`，并将 `FCr` 建为其单值 `FCv*` 的上位概念。不得替换 F 到 FCv 的直接使用引用，R/FCr 也不得充当 F 的名称字段。

汇聚不保存 `(R集合身份,版本)` 回执、完成记录、重试任务或恢复游标。汇聚失败不回滚已发布 R，也不自动重试；未来对历史版本的再次汇聚属于独立治理能力。R 未变化不得创建触发或概念写入。

## 5. 退出与禁止

移除成员、R 版本换代或 IF 退出须先核验当前采用、F 位置、概念使用、R 汇聚记录及外部引用；历史版本和已退出关系按4015保留。不得原地改 F 的类型或准确值，不得将概念允许域、2100值对象、I64误差域或旧特征分裂树冒充 R。
