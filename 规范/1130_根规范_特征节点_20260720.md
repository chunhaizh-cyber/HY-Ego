编号：1130
日期：20260907

## 1. 根定位

新 DATA-L2 特征信息是由正式特征类型、特征值和值域集合描述、以特征节点身份独立引用的数据对象。它不以先存在某个宿主、当前属性槽、观察时间或稳态结论为成立前提。多个同类型特征信息可以通过值域细分形成父子层次；特征信息节点与 2100 的值事实身份不是同一种身份。

本次固定第 1.1 节的新字段和第 1.2 节的细分关系，不新增结构 owner，不把既有特征实例身份或持久编码静默改义。第 2—5、7 节只约束既有具名宿主实例槽、当前值发布及长期观察合同；它们不再是新特征信息对象的字段清单或无宿主数据创建的业务前置。旧合同迁移前继续在原路径有效，不因此授权第二写入入口。新字段不等于完整 CRUD、持久映射、迁移或分裂应用已实现。

### 1.1 新特征信息固定字段

新特征信息对象只包含以下四个逻辑字段，清单封闭；父子和宿主等关联另由关系事实承载：

| 字段 | 固定含义 |
| --- | --- |
| 特征信息身份 | L1 分配的唯一、稳定、非零节点身份；不是值身份、类型身份、名称或内存地址。 |
| 特征类型 | 一个正式特征定义的稳定身份；说明所表达的特征及其值解释，不是硬编码业务枚举或显示词条。 |
| 特征值 | 带明确分支的 `内联 I64` 或 `2100 值身份引用`；表示本条信息所表达的值，不自动表示某存在的最新实测值。 |
| 值域集合 | 本特征信息维护的零到多个值域项；各项保存父内稳定标识、代表值、范围描述和命中次数，具体封闭字段由 4110 第 1.2.2 节规定，不能以一个可变代表值解释全部形态。 |

完整特征信息必须具有合法身份、正式类型和一个明确的特征值。值域集合为空只表示尚无范围描述，不表示任意值均适用。逐字段维护时的未设置由操作结果明确表达，不能把整数 0、空引用或默认范围伪装成已经设置的内容；整数 0 本身是合法值。

逻辑字段不要求全部内联在一条物理节点记录中：身份来自节点，特征类型关联来自正式关系，值及范围由类型化材料承载，读取时组合；索引只加速定位。字段的承载方式、值域项最小结构和父子关系由 4110 第 1.2 节展开，不另建平行事实仓。

名称和节点类型沿用通用节点 / 名称关联规则，不增加特征专属名称必填项或可与正式类型矛盾的类型标志。父节点身份、子节点列表、宿主、场景、来源和观察时间不重复存入本体字段。版本、事实代次、当前 / 历史、幂等、批次和生命周期留在相应关联、操作或 L1 内部可靠性边界，不通过公共头或嵌套包重新扩充本清单。

### 1.2 三次命中与被动分裂

特征类围绕同一父特征信息，在接收新观察值时被动积累多个候选值域；某个值域确认稳定后，由特征类内部自动形成一个独立子特征信息，并建立父特征信息到子特征信息的细分关系，不要求外层另行调用分裂。子节点保持同一特征类型，具有自身身份、所表达的代表值和值域。父节点及其已有值域全部保留；分裂动作本身只增加子节点及父子关系，不删除、搬移、清空、缩减或覆写父节点的值域，也不使父节点退出。

例如父特征信息维护 D1、D2、D3，其中 D1 稳定后形成子特征信息 F1，则父节点仍维护 D1、D2、D3，F1 独立表达 D1。分裂不是把 D1 从父节点移交给子节点，也不是用子节点列表替换父值域集合。后续观察对父值域的正常维护与本次建立子节点是不同操作，不能以“分裂完成”为由自动改动原域。

本合同将“稳定”限定为该值域已经被命中、具有被利用价值的操作性判据：某一值域累计命中三次，即具备建立子特征信息的条件；不要求连续命中、持续时间、边界收敛或置信度。该判据不宣称统计稳定性、物理对象静止或输入真实性。命中次数是必要业务数据，不是版本、代次、幂等或其它可靠性元数据；它保存于对应值域项，不另建本体级重复总计数或稳定布尔值。

处理数据来自特征类接收的每次合法特征值输入，类型由目标特征信息的正式特征类型确定；值域代表、范围及比较规则用于判断命中，不从当前一份快照倒推观察历史。新域由一次合法输入按已明确域形成规则建立时，该次输入计为首次命中；已有域每次有效命中增加一次。只读回已有信息不增加命中，可靠性重试也不能冒充新的输入。判定及发布边界由 4110 第 1.2.4 节展开。

细分子节点不是新的特征类型、共享概念、状态、动态或旧值版本。域内归类也不表示实测内容相同；精确观察按其正式记录保留，不能用代表值或区间替代实际材料。宿主的当前采用关系与特征信息本体分开维护，不能从父子层次、最新创建子节点或某个范围的存在反推当前观测。

特征类内部区分字段数据操作和由新值输入触发的自动处理：自动处理完成值域匹配、累计命中及满三次后的子节点建立，不需要外层另行决定是否分裂，也不需要后台观察线程；底层数据操作组合 L1 能力可靠保存字段、计数和关系。该自动处理只属于特征类，不改变 L1 的业务中立性，不向 L1 增加“特征分裂”等入口。完整新 ABI、域形成规则的具体提供者、物理映射及旧入口接替仍须另行闭合，不以本次字段规范冒充现成能力。

## 2. 既有实例槽的本项目承载

实例特征由以下结构共同承载：

```text
节点类型为特征的实例槽位及稳定句柄
+ 宿主到槽位的唯一归属关系
+ 槽位到特征定义的唯一模板关系
+ 槽位中按正式值表示类型唯一指向当前特征值事实的属性槽
+ 具有独立稳定编码、来源和生命周期的当前值事实及历史值事实
+ 状态和来源证据关系
+ 主键与定位索引
```

宿主必须是规范允许拥有特征的稳定对象。允许的宿主类型为存在、场景、需求、任务和方法；新增宿主类型必须先修订正式规范。

## 3. 事实与边界

1. 一个实例槽位必须引用一个正式特征定义；词条、枚举或显示名称不得替代该定义身份。
2. 同一宿主与同一特征定义在同一当前版本下只能有一个有效实例槽位。
3. 实例槽位通过属性槽引用唯一当前值事实；历史值由已退出值事实及其生命周期读回，不再为当前值或历史值建立节点间关系，也不得复制原始材料。
4. 特征解释必须来自特征定义、二次特征、状态、动态或因果证据，不得写入自由文本业务字段。
5. 仅凭词条、外部词性标签或类型标签不能成立实例特征；正式写入必须先从名称候选和上下文解析并读回特征定义节点。
6. 4125 的静态一次特征事实集合是本实例结构内的专用复合记录：集合版本没有原始值属性槽，以完整成员关系表达事实组成；它不替代普通实例槽位，也不得由普通“唯一当前值”入口读取或写入。

## 4. 写入、读取与验证

实例槽位、当前值属性槽和值事实只能由特征领域服务写入。特征领域服务负责宿主类型、定义身份、唯一槽位、特征定义允许的值表示和值域、值来源及独立材料准入；数据操作层负责同一写入会话中的节点、关系、类型化值事实、属性槽和索引发布。

需求、任务、方法及其它高级服务只能经特征领域服务读取宿主的当前特征值完整投影，不得绕过特征服务读取或改写底层值事实。有效读回必须在同一事实截止证明宿主关系、模板关系、唯一当前属性槽、值事实身份、值表示、材料、来源及生命周期一致。业务比较只消费该当前值事实；状态、动态及其当前选择不得替代。

## 5. 生命周期与当前性

槽位身份随宿主和特征定义长期可追溯。当前值换代必须经统一变化入口：业务规则先裁决新值，再依次预形成新值事实、新状态记录和引用既有前状态的新动态，最终原子发布新值事实、切换唯一当前属性槽、退出旧值事实并发布新状态 / 新动态；不得改写旧载荷，也不得从新状态或动态后状态反推新值。旧值退出当前后仍保留来源、材料和生命周期。

首次赋值没有前状态，只原子发布首个当前值和对应初始状态，不生成动态。新值与旧值完全相同时不形成换代、状态或动态。历史补录状态 / 动态不得切换当前属性槽；状态记录引用缺失的旧数据必须先走迁移或返回材料不足，禁止临场伪造前状态。宿主、定义、属性槽或值事实发生版本漂移时，旧读回不得继续冒充当前特征值事实或当前特征值投影。

## 7. 既有长期观察与独立子特征

同一存在、同一特征类型可以长期积累多个独立形态区间；它们是历史观察的子特征记录，不是多个未经裁决的当前实例槽。区间身份与一次观测的特征实例身份分开，不能因返回旧形态而伪造旧实例仍为当前。

一次观察先在同一事实截止证明存在、直接特征成员、实际值、类型及观察身份，再按固定校正规则与该范围内全部保留区间比较。返回全部适用区间和各自差异；只有完整读取并确认全部超过阈值时才能创建新区间。读取失败、预算不足和不支持比较均不属于全不匹配。多命中不创建新区间，也不按稳定编码或创建先后选一个形态。

区间固定首代表可阻止小步渐变无限吞并新形态；旧形态重现复用原域。观测时间、原事实截止、成员关系及实际值可回查；同一观测同义重放不重复积累，异义拒绝。实际最小最大值只作统计证据，不修改概念匹配域或原实例值。

实例换代、宿主成员变更、区间记录和概念关联由各自唯一 owner 发布。跨 owner 流程保留完整原请求和各阶段正式回执，不能宣称整体单事务；当前完成必须重新核验共同截止下的真实实例及关联。
