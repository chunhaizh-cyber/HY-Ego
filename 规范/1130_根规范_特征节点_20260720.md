# 1130 根规范 特征节点

编号：1130
日期：20260828
版本：v0.6
状态：正式根规范

## 1. 根定位

特征节点表示某一合法宿主上的具体实例特征槽位，连接宿主、正式抽象特征、当前特征值事实、历史值事实和特征关系。实例特征不另建平行身份类型或无类型通用值容器。特征值事实具有稳定事实身份，但不是节点；只有需要独立关系、独立生命周期或被其它节点引用的材料对象才另建节点。

## 2. 本项目承载

实例特征由以下结构共同承载：

```text
节点类型为特征的实例槽位及稳定句柄
+ 宿主到槽位的唯一归属关系
+ 槽位到特征定义的唯一模板关系
+ 槽位中按正式值表示类型唯一指向当前特征值事实的属性槽
+ 具有独立稳定编码、来源和生命周期的当前值事实及历史值事实
+ 状态和来源证据关系
+ 主键与定位索引
```

宿主必须是规范允许拥有特征的稳定对象。允许的宿主类型为存在、场景、需求、任务和方法；新增宿主类型必须先修订正式规范。

## 3. 事实与边界

1. 一个实例槽位必须引用一个正式特征定义；词条、枚举或显示名称不得替代该定义身份。
2. 同一宿主与同一特征定义在同一当前版本下只能有一个有效实例槽位。
3. 实例槽位通过属性槽引用唯一当前值事实；历史值由已退出值事实及其生命周期读回，不再为当前值或历史值建立节点间关系，也不得复制原始材料。
4. 特征解释必须来自特征定义、二次特征、状态、动态或因果证据，不得写入自由文本业务字段。
5. 仅凭词条、外部词性标签或类型标签不能成立实例特征；正式写入必须先从名称候选和上下文解析并读回特征定义节点。

## 4. 写入、读取与验证

实例槽位、当前值属性槽和值事实只能由特征领域服务写入。特征领域服务负责宿主类型、定义身份、唯一槽位、特征定义允许的值表示和值域、值来源及独立材料准入；数据操作层负责同一写入会话中的节点、关系、类型化值事实、属性槽和索引发布。

需求、任务、方法及其它高级服务只能经特征领域服务读取宿主的当前特征值完整投影，不得绕过特征服务读取或改写底层值事实。有效读回必须在同一事实截止证明宿主关系、模板关系、唯一当前属性槽、值事实身份、值表示、材料、来源及生命周期一致。业务比较只消费该当前值事实；状态、动态及其当前选择不得替代。

## 5. 生命周期与当前性

槽位身份随宿主和特征定义长期可追溯。当前值换代必须经统一变化入口：业务规则先裁决新值，再依次预形成新值事实、新状态记录和引用既有前状态的新动态，最终原子发布新值事实、切换唯一当前属性槽、退出旧值事实并发布新状态 / 新动态；不得改写旧载荷，也不得从新状态或动态后状态反推新值。旧值退出当前后仍保留来源、材料和生命周期。

首次赋值没有前状态，只原子发布首个当前值和对应初始状态，不生成动态。新值与旧值完全相同时不形成换代、状态或动态。历史补录状态 / 动态不得切换当前属性槽；状态记录引用缺失的旧数据必须先走迁移或返回材料不足，禁止临场伪造前状态。宿主、定义、属性槽或值事实发生版本漂移时，旧读回不得继续冒充当前特征值事实或当前特征值投影。
