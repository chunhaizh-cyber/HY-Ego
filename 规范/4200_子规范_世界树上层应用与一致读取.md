# 4200 子规范 世界树上层应用与一致读取

编号：4200
日期：20261105
版本：v2.1
状态：正式子规范

直接上级规范：0050。

直接依赖规范：4015、1140、1150、1160、1170、2220。

相关边界规范：4190、4202、7110、7150、7165。

## 1. 定位

世界树类位于各领域数据类之上，组合场景、存在、特征、状态、动态和因果等公开函数，实现世界信息的增删改查；它不是数据类，不拥有底层结构的第二写端。

1. 世界树类持有物理全局根的受保护引用（4202）。每个请求明确目标世界根，或由直接父节点推定；场景范围、迁移、查询上行和一致性核验均以世界根为上界。
2. 跨世界的父子关系、成员关系和迁移一律拒绝；世界之间只建立强类型引用，例如动作动态的目标引用与结果关系、实例特征准确值中的信息节点引用。跨世界引用不改变被引用节点的归属和写入权。
3. 只设一个世界树类；新增世界类型只需登记世界类型并建立对应世界根，不新增服务实例。
4. 需求、任务、方法等内部治理信息存在归内部治理世界场景，词条、语言材料范围、指代实例、代词概念等语言信息存在归自然语言世界场景（4202第2节）；它们的F变化生成的状态挂入所在场景。

## 2. 挂靠规则

1. 新场景取直接父场景；世界根的父是全局根，只能经系统引导入口建立。
2. 新存在取直接所属场景，可同时具有父存在组成关系（1140）；父存在须属于同一世界。
3. 新特征取持有节点：存在、场景、特征、状态或动态（1130）。
4. 状态与动态不由调用方选择组织父：由存在或场景owner在同一组合发布中生成并挂入发生场景列表（1160、1170）。

## 3. 实例建立与概念派生

1. 根概念先天建立，故“先有概念、后有实例”在根这一层天然成立。
2. 普通存在实例化时可以零特征，直接引用存在根；世界树类不在建立实例前做完整概念匹配。
3. 存在添加特征后，由概念owner派生其专属存在概念并挂在存在根下；之后特征变化原地同步投影（专属投影包含当前确定值，按所属存在维护，内容暂同也不合并）。
4. 与既有中间层概念的匹配和归类属于识别或归纳步骤（7110），不是建立实例的前提；中间层概念只在专属概念增多后经明确归纳需要派生。
5. 概念成功而世界操作失败时保留合法概念并报告实际阶段；重试先查询并复用，不自动删除可能共享的概念。

## 4. 修改、迁移与删除

1. 修改按所属领域合同执行；可共享类别概念随认知原地修订，撞同义直接复用（0050 §1.5）。
2. 存在可在同一世界内迁移场景；迁移在组合发布中替换成员关系，场景归属与父存在组成替换原子完成、无环、身份不变。已挂接的状态和动态仍留在原发生场景，不随存在迁移。
3. 存在不做逻辑删除：位置不能确认时逐级迁往上位场景，最远到所属世界根；世界根内的存在按具名硬删除规则清理，有外部正式引用者本轮跳过（1140）。
4. 场景只删除非世界根的空场景（1150）；状态、动态按0050 §1.5与4190第7节定期定量删除。

## 5. 一致读取

1. 一次读取在一次共享锁内形成完整值式结果；不提供历史读取、截止读取或代次比较。
2. 世界位置投影为：节点、直接父、父关系种类（场景层级、场景成员、存在组成、特征持有）、所属世界根及有界上行路径。投影不扫描L1，不复制包含写入口。
3. 存在、特征、动态概念与世界的挂接由概念owner保存，不是世界树包含边，不参与单父和无环裁决；因果链独立组织，世界树只提供其实例（动态）引用。

## 6. 发布与非成功

1. 同一次业务变化提交一个组合变化集并整体发布；发布前失败零变化。同键同结构请求精确复用，异结构返回冲突。
2. 跨多个owner的编排在原子发布能力具备前须返回实际已发布阶段，不伪称整体原子；该过渡状态由所属子规范定义。
3. 非成功至少区分：目标世界不明、跨世界拒绝、父节点不存在、归属冲突、形成环、根不可操作、结构不一致、资源失败。

## 7. 禁止

- 数据层或世界树类自动从当前值、状态或动态推导新状态、动态或因果（4190）。
- 以无父节点、名称、缓存或画面位置猜测世界根或归属。
- 为证明结构完整而复制底座数据或建立第二世界登记。
