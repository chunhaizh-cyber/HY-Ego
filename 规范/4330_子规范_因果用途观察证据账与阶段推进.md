## 1. 定位

本规范冻结因果完整结构键、调用期学习材料、非权威统计消费以及旧用途观察生产账的退役边界。为保持正式路径和历史引用稳定，文件名继续保留“用途观察证据账与阶段推进”，但该历史名称不再授权生产用途观察节点、证据关系或同账阶段事实。

状态记录事实，动态记录变化，因果记录变化之间的关系；三者构成认知证据。任务、方法、选择、实际结果和结算是必要业务治理上下文，不是第四类认知证据。G0、幂等、事务、发布读回、恢复和消费水位只服务工程正确性。

## 2. 因果完整结构键

因果完整结构键由以下业务组成共同成立：

```text
身份格式版本
+ 原因动态的完整模式身份与动态规则版本
+ 结果动态的完整模式身份与动态规则版本
+ 原因 / 结果有序角色
+ 因果规则版本
```

每个动态模式身份必须能够回读目标主体、目标特征、变化前状态、变化后状态、来源动作是否存在及其稳定身份、动态规则版本，以及适用时的二次角色。原因与结果不得排序后交换；交换两种角色形成不同结构键。

两个结构键只有在格式、原因完整身份、结果完整身份和因果规则版本全部相同时才相同。稳定哈希只用于选择候选桶；哈希命中后仍须逐项全字段比较。哈希碰撞、名称相同、概念相同、节点类型相同或单个概率相同均不得合并事实。

身份材料不完整、原因结果非法相同或版本不在显式兼容表时，不形成可召回结构键；不得以默认值、宽松版本判断或哈希值补齐。

## 3. 调用期学习材料

学习、统计或方法评审调用方必须先冻结非零事实截止，再从现有公开读回组合一组调用期学习材料。该组至少按实际用途包含：

```text
认知证据：目标 / 实际状态、同源动态、可选直接因果及其完整结构键
业务上下文：任务与回合、动作前方法内容快照、选择与冻结、实际结果、正式结算或未达成结论
裁决边界：共同事实截止、各来源版本、适用范围和学习规则版本
```

这里的目标 / 实际状态只用于学习已经发生过的历史效果和变化关系，不重新裁决目标当前是否满足。任何当前满足比较仍须 fresh 读取同截止特征当前值完整投影和目标合同；历史状态、动态后状态或学习材料不得代替当前值。

固定规则：

1. 状态、动态和因果身份必须逐项来自已发布正式事实；业务上下文必须来自各自唯一 owner 的正式读回。
2. 调用期学习材料是调用方拥有的不可变值式组合，不建立独立稳定身份、节点、关系、当前选择、生命周期或持久恢复资格。
3. 同一输入集合、事实截止和规则版本必须产生确定排序、确定去重和确定输出；组合摘要只用于幂等与候选比较，不是业务身份或认知事实。
4. 调用方需要稍后重算时，只保存合法来源身份、事实截止和规则版本；不得保存目标 / 实际状态值、关系端点或因果字段的第二权威副本。
5. 任务结果、结算或方法版本变化后必须重新冻结截止和重建材料，不得在旧组合上补写阶段。

## 4. 旧用途观察编码与生产入口退役

4010 历史登记的下列编码只用于既有 ABI、持久材料和历史结果解码：

```text
节点类型 15：用途观察记录
关系类型 18：用途观察证据角色
稳定主键命名域：用途观察记录身份
```

当前生产规则固定为：

1. 不新增节点类型 15，不新增关系类型 18，不建立用途观察业务服务或专用生产数据操作。
2. 旧数值不得删除后复用、重排或改义；历史读取可以按旧格式只读解码，但不得把历史观察账恢复为当前生产事实、阶段水位或方法晋级前置。
3. 若代码中尚无正式用途观察 provider 或生产写入口，保持没有生产者；不得为了“补齐规范”新建实现。
4. 若历史快照包含旧观察记录，恢复层只作兼容识别和审计分账。当前学习必须回到状态、动态、直接因果及业务上下文的正式来源读回，历史观察记录不能替代缺失来源。
5. 任何新 DTO、服务、实现解释材料或流程图不得以“观察、见证、证明、审计、完整性”为名恢复同义生产账。

## 5. 结果分栏与消费顺序

任务结果和需求结算继续由各自规范独立发布；它们不是用途观察阶段。学习消费固定为：

```text
任务动作前冻结方法内容
-> 执行动作并独立读回状态 / 动态 / 因果材料
-> 任务 owner 发布实际结果和本轮结论
-> 需求 owner 按需发布正式结算
-> 学习调用方冻结截止并组合调用期学习材料
-> 形成非权威统计、学习候选或材料不足结果
```

尝试未达成和最终已结算可以作为调用期分栏；尚待结算的任务只保留正式业务上下文，不进入方法效果统计。后继结算发布后重新读取并重建材料，不对旧观察账执行“待结算到最终”的阶段推进。

学习材料形成失败不撤销任务结果、结算、状态、动态或因果，不重复动作，也不补建待办观察节点。调用方只返回材料不足、版本漂移、规则不支持或其它具名结果，并在来源事实变化后重新调用。

## 6. 非权威统计与学习消费

统计只能从第 3 节材料确定重建，并遵守：

1. 按完整因果结构键、适用范围、方法内容版本和统计规则版本分组；
2. 尝试未达成与最终已结算分栏，待结算不进入效果统计；
3. 样本数、正负结果数和派生比例分别保留，不压成单一好坏分、置信度或效用；
4. 清空、重建或丢弃统计不改变状态、动态、因果、任务、需求或方法事实；
5. 概念标注、候选排序、缓存和统计结果均为非权威材料，只能交 5340 继续复核；
6. 单次成功、失败、偏差或动作完成消息不得自动晋级方法、创建新代际或反写来源回合。

概念映射只能形成零、一或多项非权威标注。单项映射也不得替代完整因果结构键；多项不得按名称、类型、哈希或首项猜选。

## 7. 写入与消费权

| 对象 | 唯一权力 | 本规范边界 |
| --- | --- | --- |
| 状态 / 动态 / 因果 | 各自正式 owner | 唯一认知证据来源；本规范只读 |
| 任务结果 / 结算 / 方法快照 | 各自业务 owner | 只作治理上下文；不改写 |
| 调用期学习材料 | 当前调用方 | 值式组合，用完即弃或按来源重建 |
| 统计 / 学习候选 | 统计与学习候选服务 | 非权威、可清空重建 |
| 旧用途观察编码 | 历史解码与恢复审计边界 | 只读兼容，禁止新生产 |

## 8. 非成功收口

| 场景 | 分类 | 收口 |
| --- | --- | --- |
| 状态、动态、因果或必要业务上下文缺失 | 材料不足 | 零生产事实，不补默认值或观察节点 |
| 格式或规则版本不受支持 | 逻辑内不支持 | 不猜测兼容，不降级读取 |
| 事实截止漂移 | 当前性漂移 | 丢弃本次值式组合，重新冻结并读取 |
| 因果哈希未命中或桶内无完整相同键 | 正常召回未命中 | 不形成因果、观察身份或晋级结论 |
| 同输入同规则重算 | 正常成功 | 返回确定等价值式材料 |
| 来源正式事实内部矛盾或读回不一致 | 内部不一致 | 停止依赖路径并追根因 |

## 9. 验证

验证至少覆盖：

- 完整因果结构键的有序角色、版本拒绝和哈希碰撞后全字段比较；
- 状态 / 动态 / 因果与任务 / 方法 / 结算上下文分账；
- 同截止值式材料的确定排序、去重、重建和漂移丢弃；
- 待结算排除、后继结算后重新构建，以及不建立阶段观察账；
- 节点 15、关系 18 和用途观察身份没有新生产调用，旧编码仍可只读解码且不复用；
- 统计清空不改变任何生产事实；
- G0、幂等、事务、读回、恢复和水位材料不进入认知证据；
- 本轮结果不能反写本轮选择、方法内容或动作事实。
