## 1. 冻结范围

本规范冻结动态数据服务的C++源级合同、专属类型、物理字段、读写及失败合同。这里的ABI指同一工具链重编译的源级公开面，不承诺跨编译器的C++二进制布局，也不得以对象内存镜像作为持久格式。

4211规定信息和操作语义，本规范唯一展开物理合同。动态生成应用、动态概念生成算法、场景组织和动作来源不属于动态数据服务；它们的接口不能从本规范类推。合同冻结不表示依赖提供者已经实现，不解除计划、所有权和S0门禁。

实现范围明确分账：原子动态支持现有正式I64比较合同，包括内联I64及完整读回为I64的值引用；不能读成I64的输入返回`比较依据不支持`，不得比较材料身份或原始字节。组成存在成员的发生期语义尚缺正式UTC适用期来源，v1固定返回`组成发生期依据不足`；同主体组合可正常实现。此拒绝不是临时假实现，也不得在代码中改成按入库代次推定发生期；解除该限制须先补7150的发生期来源合同并修订本规范。

这些是11项逻辑操作的12个内容/身份函数；另有绑定查询、构造与析构。不得再提供字段setter或同义转发服务。逐字段CRUD映射为：新增由两个完整创建函数共同发布对应分支；删除只由整体退出/清理维护不可变闭包；修改主体/端点/成员均为不适用且禁止；读取由完整读取和三个字段索引入口完成。名称关系不由本类维护。这是不可变结构的字段映射，不授权制造必然拒绝的setter。

成功谓词按以下穷尽规则实现，并由调用方额外互证原请求身份及过滤条件：

| 结果用途 | 成功状态和完整性 |
| --- | --- |
| 创建 | 已创建/精确重复，阶段已读回，非零发布G，操作Gread=本次实际读回守卫>=发布G、H=发布G，内容同Gread/H且创建G=发布G、无退出 |
| 当前/历史内容 | 已读取、无写入、无发布G；内容Gread/H精确等于操作，创建<=H且H早于退出；当前H=G0，历史H等于请求 |
| 组查询 | 已读取、无写入、无发布G；全部同Gread/H、完整、身份升序无重复；空组合法 |
| 展开 | 已读取、无写入、无发布G；根存在、所有已声明范围完整、每个原子都有B/S互证；身份升序无重复，不返回截断来源 |
| 退出 | 已退出/精确重复、阶段已读回、发布G>1；操作和内容Gread=本次实际守卫>=发布G、H=发布G-1、自有事实共同退出于发布G |
| 清理 | 已清理/精确重复，阶段已读回、发布G非零且墓碑完整非空；或首次无候选的已读取、零发布、空墓碑 |
| 历史身份 | 已读取、无写入、无发布G；完整见证Gread/H精确回显并证明身份在H有效 |

全部成功共同要求合同版本1、0<H<=Gread、状态与阶段/发布G组合符合本表。动态内容中身份/主体和全部自有编码非零，族归属/主体/UTC/变化关系与节点互异，自有事实编码不重复；分支、顺序、计数及生命周期符合第6节。历史身份的身份/锚点/归属类型/归属关系四编码非零互异，创建<=H且H早于退出；锚点及类型生命周期由服务内部核验，不复制owner。展开成功谓词只判断结果内部结构完整，直接/递归请求范围必须由调用方结合原请求互证，不能由无参谓词声称已证明未回显的请求。

清理服务返回前必须核验墓碑与原退出写集中按种类/身份排序的完整集合一一相等、无缺失/额外项，每项创建/退出/清理代次有效且清理G=本次所回原清理发布G；节点1、关系原子4或组合N+2、值1，不套用状态的固定数量。操作Gread为本次读回守卫、H=原清理发布G；零候选为Gread=H=请求G0、无发布G。无参清理成功谓词只检查结果自含的状态/阶段/G/H/非空墓碑/墓碑自身生命周期和排序；原退出集合互证由服务完成，不能让无参函数读取不可见的原写集。

所有非成功的内容、组、来源、墓碑和身份见证清空；操作仍保留可靠发布阶段及已知发布G。已提交但读回失败返回`内部不一致+已提交待读回`，不表示回滚；L1不能判定提交返回`已可能发布+未知`。非成功不得返回可供业务采用的部分事实。

稳定类型编码由唯一结构初始化者经L1正常分配，不硬编码裸数字，不复用旧角色20的机器含义。格式锚点到其余7项依次用`字段登记关系类型`、角色1—7登记；同一格式锚点下恰有这些角色、每角色唯一、端点均为交付对应节点；格式锚点身份及精确登记布局识别v1格式，不保存或解析字符串标记，不参与业务身份。交付九个编码非零且互异，均由动态owner拥有；首次UTC属性节点种类为属性类型、表示I64，其余为普通节点。创建代次不得晚于所承载动态，生命周期覆盖当前内容及历史保护需要。类型、锚点和登记边错误在构造拒绝，不用名称查找猜测。初始化不得由动态服务构造/读取隐式进行。v1没有组成成员关系编码，不能把未证明分支写成普通节点或未知数值角色。

新动态使用普通节点，由一条`动态→动态族锚点`关系证明所属族。自有事实精确为：节点1、族归属关系1、主体关系1、首次形成UTC I64值及属性槽1，加以下互斥分支：

- 原子：动态→前B、动态→后B各1，关系类型分别为前/后绑定类型，角色固定0；B不可相同。
- 组合：动态→子动态N条，均用同主体成员类型；角色为1..N连续顺序，N>=1且子身份无重复。

族归属关系角色1，主体关系角色0；时间只存首次形成UTC用于保留策略，事件时间从B/S展开得到。内容读取按关系类型解码互斥分支，对本owner自有事实的任何混合、缺项、多项、未知类型、角色或owner错配均拒绝；其它owner合法维护的名称、场景组织、动作或因果引用不计作动态自有字段，不因它们存在拒绝内容读取。所有自有事实同笔owner写集创建/退出；跨owner引用目标只读核验，不归入写集。

`动态自有事实清单.变化关系组`原子按前/后、组合按成员顺序；其余事实编码均非零且彼此不重叠，创建和退出同次。历史读取严格使用H投影，未来退出不回显；退出结果是专属例外，以Gexit-1内容加已核验的Gexit退出见证组成，不改普通历史语义。

## 7. 首次写入、变化依据和组合

1. 先检查版本1、非零G0/来源H/幂等、H<=G0、预算五项均非零，数量转换无溢出。
2. 先查owner幂等原材料；已绑定按第9节重放，不重验现时来源。未绑定才核对G0和全部来源。
3. 主体经存在窄历史接口在来源H确认；B经4203历史读取、S经4212历史内容读取，均使用同一Gread=G0、H=来源H。历史读取中当前已退出不否定H有效；H时已经退出则来源已退出。但首次新建当前D引用还须另行在G0确认E/B/子D目标当前有效；当前已退出则写前来源已退出，不能用历史成功越过L1当前引用闭包。B/S回显不一致、假成功或缺字段均内部不一致。
4. 两B同C、同E=主体，两S同FT且使用实例绝对UTC纳秒，前t<后t。C可以等于E；不新增独立属性P，也不要求B创建顺序等于事件顺序。
5. 对两端准确值，先调用`特征类数据服务::核验正式特征类型准确值`在G0/来源H证明类型和值当时有效且相容；内联直接取得I64，引用调用同仓`特征值类数据服务::获取特征值`读不可变内容，再校验G0未漂移。此公开函数无H参数，历史有效性只能以前一步的窄核验为准，不能由它单独证明。无法完整读取、非I64或独立材料只得到引用时不能继续。两种表示解析为同一I64即`无变化`，不因F/S/值身份不同放行。
6. 变化依据的K快照只接受`特征比较合同来源::当前独立绑定`，通过`特征类数据服务::读取当前I64比较绑定`在G0按FT+变化分析有界召回唯一K，再逐字段互证FT、用途、角色、算法/版本、量化、容差及输出类型；K的Gread=H=G0。状态内容仍按来源H，比较规则使用本次G0，不要求该规则在历史事件时已经存在。用途恰为`特征I64比较用途::变化分析`，左角色恰为`旧状态`、右角色恰为`新状态`，上下文要求位为0；输入绑定固定前值为左、后值为右，须匹配K登记角色；不把应用的自由数值当作注册。
7. 比较请求/结果均须其正式成功形状成立，请求身份、K、算法版本、要求/实际结果位和输出描述一致；至少请求并取得排序三态，其值非零。其它已请求分量也必须全部成功，不能丢弃溢出分量后伪装成功。DATA核验回执和输入，不重新调用比较算法；算法执行与真实性由4210应用承担。比较失败、零差异或不支持分别返回，不持久化二次实例或比较结果节点。
8. 组合先核成员顺序、重复及同主体/组成角色；组成分支按第1节拒绝。同主体成员在来源H完整读回并递归展开，确认所有子主体相同和来源有界无环。新节点不能被既有来源引用，但仍须检查原图损坏；不以新身份天然无环跳过检查。
9. 全部核验通过后才形成一个完整动态写集。最终以G0提交，漂移零发布；首次UTC由系统取得，纳入L1首次规范化请求。独立读回新内容及来源闭包后才成功。场景挂接、名称、动作、因果都不在本笔写集。

## 8. 读取、查询和预算

全部读取入口零写，前后校验Gread守卫；0<H<=Gread。普通完整内容只还原动态自有字段及强类型引用，不强迫跨owner来源当前活跃；`展开动态来源`才按指定H读取B/S闭包，不以内容读取成功冒充完整来源仍可用。

直接展开包含根与直接子动态，原子项各自返回B/S；若直接子是组合，不再向孙代展开，其边界由请求`直接`明确，不称全递归闭包。递归方式返回根到全部叶的有限DAG；共享子动态只读一次，边逐条计数，DFS灰色重访为环、黑色重访为共享，禁止无界C++递归。

三个查询仅通过主体/前后B/成员关系类型反向召回，先过滤动态owner、类型、方向及H有效，再完整读取候选。查询前/后B合并去重；同一子动态的多父是合法来源复用。全部结果按身份升序；无匹配与来源缺失分账，不能把未知目标作为成功空组。

最大候选数计过滤前已召回的本owner相关关系；最大动态数计去重D；最大来源边数计全部D→D和D→B以及B→S读取项；深度根=1；最大读取材料数只按本服务通过公开接口实际接收的节点、关系、值、墓碑各计1，不含下层未公开的内部访问；K候选扫描另以当前K请求的明确扫描/材料预算限制，调用前用本请求剩余对应预算作上限。复用的同G/H材料不重计。预算是整个调用共享，不在每个成员重新分配。无论哪项耗尽都返回`数量预算不足`、空载荷；不建立游标、第二快照或成功截断。

## 9. 幂等、错误优先级和清理

幂等相等以L1首次规范化写集可恢复的内容为准：操作类别、原G0、主体、互斥原子B对或有序成员组；退出以原G0和完整退出事实集合为准。来源H、比较请求/回执和预算是首次准入/资源参数，不进入内容键、不要求L1保存其原DTO，重放允许调整这些非语义参数但仍须入口形状合法。已经成立的同键内容不重新执行准入；不同B/主体/成员或原G0变化为冲突。首次UTC是服务首次分配并在原写集保存的技术材料，不由调用方重造。重放先读原写集/结果，恢复原发布G，使用本次实际Gread守卫+原发布H读回，返回原身份/原发布G和本次Gread；不能要求仓库当前代次回到发布G。来源后续退出不影响同键精确请求重放。原材料矛盾、已清理或无法确定发布必须保持原键并明确失败，不新建同义动态。

失败优先级：请求版本/形状→已绑定键冲突/重放→G漂移→目标身份/墓碑/旧格式→B/S/FT来源→时间→比较→成员角色/组成依据/环→预算→写前引用闭包→L1提交→发布后读回。候选遍历依稳定身份与成员顺序固定，禁止依哈希容器顺序选错误。提供者未实现映射`依赖未实现`；未找到/已退出/清理映射来源对应状态；资源、漂移映射同名；未知状态和成功回显矛盾为内部不一致。正式比较拒绝映射比较依据不支持，无成功排序或零排序不得创建。

每个公开服务入口承担本地诊断，合法拒绝/空组不记内部错误；私有辅助向上送出，不重复日志。成功谓词及绑定查询为无适用错误分支，分配或比较异常在noexcept谓词内返回false，不影响正式结果传播。

普通退出仅退出一份动态的全部自有事实；仍被活动父组合、场景、概念、动作或因果引用则返回引用冲突，不级联退出其它owner。历史仍可按退出前H读取。

同步清理完全复用4212第8—9节的L1双键分时绑定规则，但候选对象换为动态：首次按TTL及同类数量上限、首次形成UTC/身份升序确定并集；全量候选超预算零写。父组合引用在候选集合内可同笔退出，集合外活动父及其它owner引用导致整批引用冲突，不自动把未达清理条件的父加入；之后只清理原完整退出集合。清理集合含每个D节点、族归属/主体/变化关系和首次UTC值，绝不包含B/S/E、类型、锚点或概念。

退出键只在逻辑退出被L1接受并成账后绑定原有序集合/Gexit；清理键只在L1物理清理接受并成账时绑定。已存在退出首次材料时不重扫、不换集合；首次调用在逻辑退出发布后以本次取得的Gexit作为紧接物理清理的期望代次；已有退出首次材料的后续调用以本次请求G0>=Gexit作期望代次。两者都不改变原退出集合。L1清理接受前允许新G0/新清理键对原集合重试，接受后仅原键原完整请求精确重放。首次无候选不绑定任一键。不得建立动态pair账、线程或后台清理器。

历史命中墓碑返回历史材料已清理和空内容；不得凭墓碑重建端点或族归属。只有可靠阶段可回显已知退出/清理发布G。原生引用保护不覆盖藏在值中的关系身份，v1不以这种编码承载组成证据。
