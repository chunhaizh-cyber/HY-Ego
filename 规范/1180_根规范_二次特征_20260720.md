## 1. 根定位

二次特征属于统一特征体系，是为了完成当前比较或判断需求，从已有特征、关系、动态或其它派生特征中经可复算限定、比较、组合或归一化形成的高阶派生特征。它复用正式特征身份和节点族，不是与特征并列的本体类别、独立节点族或独立 CRUD 服务，也不得替代输入世界事实、状态、动态、关系、因果或任务结果。

“二次特征”是实际二次至 n 次特征的统一称呼。每个派生特征必须保存非零真实阶次和直接来源特征关系；由一个或多个输入形成的新派生特征，其真实阶次固定为输入中最高特征阶次加一。没有特征阶次的关系、状态或动态只能作为具名来源和约束参加推导，不得靠调用顺序猜测阶次，也不得把 n 次来源链压平为一个无来源值。

本对象的用途是把已有事实中需要计算才能取得的差异或关系显式提供给识别、变化分析、关系判断和目标判断，并为概念形成及语言表达提供可追溯材料。它不只表达大小，也不只用于名称。具体用途、输入、类能力和非成功分流由4150展开；计算能力由DATA之外的二次特征应用承接，结构保存继续复用既有owner。

### 1.1 比较派生的标量边界

全部正式二次至 n 次特征的每个实例只有一个 `int64` 实际值。所有对外提供的业务特征比较结果均属于二次特征；由已有特征组合、归一化或继续推导形成的正式派生特征也遵守同一标量合同，每项具有具名结果角色、真实特征类型、输入见证、派生规则、真实阶次和适用范围。排序量、具名关系量、差异量是不同类型；一次计算可以形成共享来源的多个结果实例，不能把多分量打包为一个整数，也不能仅给一个裸值改名。

标量限制针对全部正式二次至 n 次特征，不针对所有原始材料或所有处理步骤。一次特征允许标量、完整向量和完整结构材料。二维轮廓、三维体素的观测表达及原始材料提取不因内部使用算法便自动成为比较派生，也不因材料为结构形状便自动取得一次身份；须依据明确的来源步骤、特征定义和形成用途裁决。对轮廓、体素等执行比较形成的距离、面积差、体积差或评分，分别按具名比较类型成为标量结果；其源结构仍完整保留。一旦由既有特征通过组合、归一化形成正式派生特征，其每项输出仍须为 I64，多分量必须分为具名类型。完整轮廓或体素不是非标量二次特征的例外。

输出类型必须明确单位、维度、分量角色、缩放及量化约定、允许范围和溢出处理；缺少正式合同、解析能力或真实来源时拒绝，失败没有结果值，不能返回零冒充相等、无变化或空观测。当前算法只处理已经具有相同量化合同的 I64，不暗中转换单位或取向量首分量。

内部流程判断、容器比较和控制枚举不是对外业务特征输出；它们仍可使用 bool、三态或控制枚举。将比较结果交给业务使用时，必须进入上述类型化结果合同。任务局部值式实例没有 L1 发布身份；计算成功不代表发布了持久值事实。

## 2. 需求驱动形成

主形成链固定为：

```text
当前需求需要比较、判断或区分
-> 依次使用已有特征事实和关系事实
-> 已有材料足够则直接使用；若对外给出新的比较结果，按类型形成值式二次特征
-> 原始事实缺失则继续观察或读取，不生成二次特征
-> 原始事实完整但缺少可表达所需差异的派生结构
-> 形成能够解决当前需求的最小任务局部二次特征候选
-> 以当前需求结果验证候选
-> 后续复用、持久化和概念沉淀分别裁决
```

“无法区分”至少区分已有值相同、输入缺失、类型不可比较、关系不足、事实冲突和确实无可派生差异。只有“已有合法事实可以经新派生结构显式形成所需差异”允许进入二次特征生成；不得用二次特征凭空补造缺失事实、目标优先级或因果。

对于只需证明两个对象不同的需求，任一当前可靠特征或关系差异均可成为依据。对于选择哪个对象更符合当前需求的判断，差异还必须经该需求结果验证；无关差异不得提前结束判断。

## 3. 本项目承载

承载必须区分正式类型/派生规则定义、本次准确计算材料和二次关系概念。定义使用既有特征结构；计算材料包含有序真实来源、具名准确结果、规则、实际阶次及适用上下文；概念使用7170/7180的独立概念身份。三者不能共用一个含糊的“二次特征节点”名称来代替身份判断。

直接来源、角色和规则须完整可回查；技术代次、幂等和发布记录归所属可靠性合同，不扩充为二次特征业务字段。值式结果不因携带完整来源而取得节点身份。组成关系的有序性不自动表达关系概念的AND；准确来源、定义组成和采用关系按4150、7180分别承载。

## 4. 事实、概念与使用边界

1. 二次特征可以表达比较、方向、区间、覆盖、稳定性、变化率、关系投影、归属冲突和任务范围阈值等派生特征事实。
2. 二次特征不得替代一阶特征值、状态事实、动态事实或因果账本。
3. 自然语言关系理解结果不得直接写成权威二次特征。
4. 存在可以是二次比较的参与方，也可以是关系判断的被描述方。存在内部子存在之间的比较属于其内部场景应用；同一主体前后时点的比较属于变化应用。数据归属、场景索引和状态/动态发布由对应owner负责，不能由计算结果自动建立；持久实例采用仍受第6节及C038限制。
5. 二次关系概念按7170、7180定义，属于2220特征概念根下的独立概念；单个派生结果的值域概括不代替其完整关系定义。具体宿主、时间、输入及准确结果属于实例/来源材料，不进入通用概念身份。`DATA-L2`特征结构服务不形成候选，不自动建立或命名概念；概念应用经唯一概念结构服务保存已裁决定义。
6. 同一二次特征概念可以作为存在、动态或其它适用对象的特征使用，必须复用同一概念身份；来源于动态的“速度”等概念用于存在时，不得复制或降级为另一份一阶概念。
7. 临时比较、筛选、评分、排序和一次性推导形成任务局部候选并在使用后丢弃。旧“后续事实、证据、因果样本、需求任务方法输入或审计需要回查即可允许持久化”属于0300 C038未决分支，不是现行新增持久实例许可。

## 5. 写入、读取与验证

`DATA` 之外的二次特征应用负责按具名目的绑定输入、经4180的唯一注册路由计算、校验结果及来源、按完整概念条件求值。需求是否达成由需求应用判定；概念查重、形成、复合定义、名称和用途治理由概念应用及名称服务负责，二次计算只提供材料。`DATA-L2` 特征/概念结构服务只保存和校验已裁决的定义与关系，`DATA-L1` 负责可靠原子读写；不新增独立二次CRUD、第二写入owner或从数据层到概念应用的反向调用。

验证必须证明组成项非空、稳定身份与允许重复角色合法、顺序连续、角色和值域合法、真实阶次正确、输入符合本次选择及时间合同、规则版本可用、结果可从输入确定复算。判断型二次特征还必须满足4160的收束证据合同。

## 6. 生命周期与当前性

当前按0050第7节执行：任务局部准确结果用完即弃，不取得持久世界实例、当前值、状态或动态资格。旧持久高阶特征条款要求适用范围、来源版本、实际阶次、直接来源和失效条件，但是否允许保存及其完整合同尚在0300 C038裁决范围；这些必要条件不构成新增写入授权。已合法保存的定义、概念及来源保护不因该冻结被删除。

准确来源内容不变不代表旧计算永远适用于当前判断；存在采用、时间范围或规则解释变化时必须重新读取并计算。结果不得经缓存或上轮材料冒充本轮当前比较，不要求为此给准确F或值对象增加版本、当前/历史集合或生命周期字段。

使用次数少不自动删除权威事实或正式概念。用途、最近使用、需求贡献和可替代性只能形成后续生命周期候选；仍被世界事实、概念、因果、需求、任务或方法引用时必须保留历史和引用闭包。
