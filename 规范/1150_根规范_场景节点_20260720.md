## 1. 根定位

场景是按一定内部范围组织存在及其特征、状态、动态和关系描述的信息对象。场景自身具有特征，可以作为存在被识别和使用；同一对象的存在视角与场景视角使用同一个稳定节点，不为内部展开复制第二个对象身份。普通存在按需要启用场景视角，不要求所有存在预建完整场景。

“作为存在”描述对象自身，“作为场景”组织其内部。场景身份及组织根归属稳定，不等于空间位置绝对不变；位置、姿态、范围和参照系按特征及相应空间合同表达。场景不是任务回执容器，不裁决业务真实性、需求满足或价值结算。

状态和动态按被描述对象的层级归场景组织：整体描述归其发生所在场景，内部存在的描述在该对象展开的场景视角中递归组织。观察者位置、相机画面或观察精度不自动决定场景；具体状态须能通过完整使用绑定确定被描述存在及属性，组织根不能代替主体，细则唯一见4202第3节。

## 2. 场景信息的固定逻辑字段

| 字段 | 含义 |
| --- | --- |
| 场景节点身份 | 对象的唯一稳定节点；作为存在使用时仍是同一身份。 |
| 特征根 | 组织场景自身特征的实际根节点，不是场景内全部成员特征的汇总根。 |
| 状态根 | 组织状态实例的实际根节点；本场景具体状态视图须核验完整使用绑定，外部共享内容只引用、不另增组织父。 |
| 动态根 | 组织该场景内产生的动态信息的实际根节点。 |
| 关系根 | 组织场景内存在之间上下、内外、远近等关系描述的实际根节点。 |
| 存在列表 | 直接场景成员存在的引用集合；成员迁移改变归属关系，不复制存在。 |
| 直接子场景集合 | 递归展开的直接子场景关系；与存在视角的包含读取使用同一事实，不重复建父关系。 |

这是七项封闭逻辑字段，不是 C++ 布局。四个根分别组织独立实例树，集合通过关系读取；根与组织边是持久事实，读取数组和索引才是可重建投影。完整场景每类恰有一个根，树允许为空。

名称由该对象作为存在时关联的存在概念取得，再经概念名称关系读取语言表达；不另设场景名称副本或场景概念本体根。节点类型沿用通用结构，类型不因使用视角而原地变更。父场景、递归包含、当前特征采用及来源按相应关系查询，不另存第二权威集合。版本、事实代次、幂等、批次、生命周期及通用来源/时间封套不进入上述字段；必要可靠性和具名事实的来源、时间合同不因此删除。

## 3. 组织与归属原则

1. 四棵实例组织树分别单根、组织父单一且无环；跨树使用是引用，不成为第二组织父关系。准确特征和状态允许共享，不为树形复制相同事实。
2. 对同一对象，场景成员、组成父及子场景包含按 4202 / 7150 联合保持唯一直接归属。父场景可以递归包含后代存在，但不得补越级直接归属。
3. 实例根、普通存在成员、子场景和概念本体根属于不同关系角色。实例根不是场景普通成员，实例树不是概念分类树；动态组成来源也不等于组织父子。
4. 除场景树根外，每个当前场景角色必须具有一个由调用方明确指定并经同截止核验的直接父场景。普通建立不得只沿普通存在组成父上溯后启用场景角色；普通退出必须携带原直接父场景，并与该父子关系共同退出。根只走系统结构引导入口且无父；对根内成员或实例的操作仍以根本身作为所属场景，不要求根再具有上级。
4. 成员存在离开或场景位置变化，不迁移、改写原场景已经形成的状态、动态及关系事实。组织根可以增长；固定归属不等于禁止受保护删除，也不承诺实例永不清理。
5. 关系根不是 L1 关系表，不是任意语义边容器，也不是新二次特征持久化入口。0300 C038 继续约束二次实例，合法临时比较不能因挂根取得持久资格。
6. 需求、任务、方法、概念、显示摘要和任务回执不得成为场景普通成员或借实例根取得世界事实身份。因果仍按自身合同承载。

## 4. 操作、旧合同与子规范

场景类提供按稳定节点操作场景角色、四根、实例组织关系、成员列表及子场景的能力。各事实的数据类保留唯一内容写入责任，世界树只组合公开能力，不向 L1 增加领域入口。原子变更、读回、失败、共享引用、删除和迁移边界由 4202 展开。

本版替代旧场景承载清单、独立宿主场景身份及“仅事实目录/索引而无实际根”的新模型依据。4230 旧场景 DTO、R1 树登记及宿主关系只在明确旧格式边界保留，不得重释为这七字段；后继须冻结新物理合同和迁移，不宣称代码已经实现。

| 子规范 | 负责内容 |
| --- | --- |
| 4202 | 七字段展开、四棵实例树、同节点视角、唯一归属、操作、读回和旧格式边界。 |
| 7150 | 存在已知特征、当前采用、组成及跨角色直接归属。 |
| 4200、4230 | 世界树组合、结构分工及既有 ABI 隔离。 |
| 4210、7190 | 动态实例形成及独立动态概念；不混用两种根。 |
| 4150、4151 | 二次特征计算与实例持久化限制。 |
| 7130 | 自我场景视角与旧自我装配合同的迁移边界。 |
