## 1. 对象和边界

本规范展开二次关系概念，不将7160的值域概念、1180的准确派生结果和具体关系实例混为一个对象。记号如下：

| 记号 | 含义 |
| --- | --- |
| D | 共享的比较结果允许域。 |
| FC | 参与比较的特征概念约束；从其定义读回正式类型及允许集合。 |
| EC | 参与比较的存在概念约束。 |
| K | 唯一确定比较含义的正式规则合同；不是新增本体概念。 |
| A、B | K固定的被描述方、参照方两个参数位置；不是具体存在身份。 |
| RC | 二次特征概念的独立概念身份。 |

```text
原子 RC：D + FC + EC                      （K及双方语义已唯一确定的简式）
复合 RC：(D1 + FC1) AND ... AND (Dn + FCn) + 共同EC
```

简式不删除必需语义。FC或现有规则引用不能唯一决定取值角色、比较用途、方向和参照时，定义必须显式引用K。双方FC或EC不同则分别绑定到K的A/B角色；相同则共享一份约束，不为形式对称复制字段。

## 2. 必须可读回的逻辑信息

下列是节点、关系和值共同承载的逻辑信息，不要求全部成为一个C++结构体的内联字段：

| 逻辑信息 | 承载原则 |
| --- | --- |
| 概念身份与定义种类 | 既有独立概念节点；区分原子条件和非空合取定义，不按阶次新增节点族。 |
| 比较结果域 | 原子项引用共享D；D不得由名称文字或当次结果值冒充。 |
| 特征概念约束 | 原子项到FC的固定定义引用；通过K保留双方取值及分量角色。 |
| 存在概念约束 | 共用EC或分别约束A/B；实际改变适用范围的约束进入完整定义。 |
| 比较规则与参照含义 | 能由已有引用唯一读回则不重复保存；否则补K引用。单位、方向、参照点、坐标解释等不得缺失。 |
| 复合组成 | 对原子条件或已成立RC的具名定义引用，固定AND及同A/B绑定；不复制为普通父子边。 |
| 根归属与直接上下位 | 位于既有特征本体根下，允许多父DAG；不存在按层级推算阶次的字段。 |
| 形成依据、支持、名称及用途治理 | 复用概念关系和7140记录，独立于定义；有真实行为才记录，不伪造首次用途。 |

定义中的FC、EC和子RC均引用概念身份及固定定义，不引用它们的名称字段或当次实例。定义引用不得随来源F改名或存在当前采用变化而悄悄改变含义。K仍是具名机器规则引用，不要求把算法改造成语言概念。

具体A、B及输入特征、准确计算结果、采样时间、形成宿主、命中计数、用途、技术幂等与事实代次不参与RC同义身份。可靠性材料留在所属数据合同；实例与来源材料中的真实角色和来源不能因此丢失。

## 3. 三个共享基础域

对成功产生、允许范围合法的有符号I64结果r，基础域固定为：

| 逻辑常量 | 允许集合 |
| --- | --- |
| D_NEG | `{r ∈ I64 \| r < 0}` |
| D_ZERO | `{r ∈ I64 \| r = 0}` |
| D_POS | `{r ∈ I64 \| r > 0}` |

三域互斥，其并集覆盖合法I64结果；实际应用还需与K的输出允许范围相容。它们是共享的不可变域定义，每个RC只引用，不为身高、体积或坐标各复制一组三域。上表是逻辑身份，不指定C++枚举、L1编码或新永久本体根；物理编码与提供者必须在实施合同中明确。

需要`>=0`、`<=0`、`!=0`时使用基础域的精确并集。域内OR只定义允许集合，不把复合关系的AND改成OR；不能用不同维度的并集冒充同时成立。

零域是精确零。允许测量误差时，由具名比较/量化/容差规则决定输入或结果如何判定；规则必须参与含义，不能把非零准确结果悄悄当作零。缺值、不可比、算法缺失、溢出和读取失败均不命中任何成功域。

三域不预先生成所有RC，也不限定整个系统只有三个RC。非有序集合关系、复杂形状包含或任意关系码，只有在具名算法已定义合法有符号判定量时才能使用三域；本规范不发明把任意输出编码减零解释为关系的方法。

## 4. 比较规则、双方和实例输入

普通差值规则：`r = A值 - B值`，A为被描述方，B为参照方。4180的`difference(左,右)=右-左`保持不变，本模型明确映射`左=B、右=A`。`compare(左,右)`的排序符号不得冒充difference的符号；调用方不能为获得所需词语临时交换规则角色。

K至少能够唯一读回输入/输出类型、取值方式、双方角色、单位与量化、参照约定、适用条件及失败边界。普通同型比较可以共用FC；比较不同端点、不同特征类型或角色限制时，必须由合法K分别解释，不能只因单位相同就认定特征相同。

实际计算时，全部输入必须成组绑定到同一有序A/B及其上下文。相同结果可由多组输入产生，不能把各组左输入、右输入分别摊平成集合再任意配对。每个准确输出保留具名类型和值，结果域只负责归类，不能替代`+10`、`-10`等实际数值。

特征内联I64直接使用完整准确内容；特征值节点引用按2100及其类型解析完整材料。轮廓、坐标等比较不能对节点编码做减法。当前判断读取存在实际采用和准确F；历史/状态比较读取其明确时间证据，不能混用“最新”输入。

## 5. 通用优先与完整定义判等

### 5.1 通用优先

选择能完整表达关系且保证K适用的最一般FC/EC。通用位置关系不因对象是人、车或箱子复制概念；只适用于轴对齐盒的算法必须保留该约束，不能推广为所有形状。

根只提供一般范围；下级概念用来增加必要条件，不用于扩大根的外延。缺材料、读取失败或尚未实现不能成为擅自收窄或放宽定义的理由。具体输入是否满足FC/EC与K由应用真实核验，不能由根覆盖或名称相同直接证明。

### 5.2 规范化与同义查重

完整定义包含D、FC约束、必要EC约束，以及决定含义的K与参照约定。共同约束只保存一次，角色和条件配对仍须可回读。只用D、单个结果FT或名称查重不完整；过度具体化的形成宿主也不能成为避免查重的方法。

AND可在同一A/B和相容参照下展开、规范化排序和去重。项的规范键保留`K/取值角色 + FC约束 + D`的完整配对，再结合共同EC约束；不得分别排序域列表和FC列表后丢掉原配对。A/B位置不可交换，维度不可互换。

展开子RC时，必须保留各子定义的全部角色化FC/EC、参照及适用条件，并与外层约束共同合取。只有具备完整等价依据时才能共享或消除冗余；不得以外层较通用EC替换子定义的必要限制。不能无损规范化时保留完整子引用或报告缺口，不得丢项发布；规范键和完整读回须覆盖这些保留约束。

一项合取规范化为对应原子定义；重复相同条件不形成新概念。互斥域在同一判定量上同时被要求、或其它可证明矛盾的合取不得发布。不能判定必要等价/一致性时报告缺口，不随意合并或用新身份绕过。

不同K只有具名合同证明完整含义等价时才可复用；相同几个样本或同一结果符号不足以证明算法等价。不同身份但有正式等价依据的定义由统一签名规则处理，不能用名称/数值大小猜测。

## 6. 形成流程

### 6.1 首次形成与已有概念复用

1. 取得当前比较目的、已成立的合法来源、正式类型及K；原始事实缺失先读取/观察，规则或算法缺失报告缺口，不假造比较结果。
2. 查询已有适用比较定义和所需FC/EC；合法缺失的FC按7160、EC按7110先形成并完整读回。不得以具体存在节点代替EC，也不要求先有待形成的普通RC。
3. 在明确一致的输入与参照下完成合法计算，取得实际结果及D；已有RC路径则正式读取其固定定义再计算和判定。本次临时结果无持久身份不阻止使用其已成立来源和K形成概念依据，不能把临时结果声称为已发布世界事实。
4. 按通用优先形成原子完整定义；需要组合时取得各项与同A/B上下文，按第5节形成完整AND定义。
5. 在既有特征本体根内按完整规范化定义精确查重。同义活跃/冷却则复用，合法缺失才提交新概念；退役和技术非成功按第9节处理。
6. 经唯一概念结构服务完整发布定义、必要关系及根可达结构，独立读回后即可使用；不等待三次、成熟度或固定天数。
7. 名称、事实支持及实际用途分别按其合同处理，不以概念发布成功冒充这些后继动作成功；不伪造持久二次实例来补支持端点。

原子RC从合法结果与完整条件形成；复合RC从已成立的条件定义及可回查共同满足依据形成。单次真实完整输入可以支持形成，但单个样本或同时出现本身不能证明定义完整、通用或因果成立。

### 6.2 搜索与生成分账

本规范不在DATA CRUD中触发全场穷举，不将“枚举到”当作概念或用途。按需比较继续使用4150的当前搜索合同。

现场有限枚举可以作为后继应用输入路线；其输入集合、合法配对、维度、深度、数量预算、停止与续行必须有具名调度合同后才实施。本次固定概念定义和对合法完整输入的形成规则，不以此开放无界扫描，也不将调度尚未冻结误称为概念定义未明确。

## 7. 复合与组织

多个原子关系组合成RC时，AND条件必须指向同一有序A/B及相容坐标、参照点、观察/时间上下文。不同维度分别计算和判断；复合概念不要求把多个准确输出打包成一个I64、向量或普通值域。

概念之间的三类关系分别成立：

| 关系 | 含义 |
| --- | --- |
| 定义组成引用 | 某原子条件或RC是另一个RC的AND组成，决定含义。 |
| 直接上下位 | 完整定义之间存在可证明的适用集合包含。 |
| 形成/支持依据 | 哪些真实材料或既有定义支持形成，不成为定义成员。 |

组成引用不是上下位边，数据容器成员也不自动表示AND。复合引用允许复用已有RC，但不得自引用、循环，或者把一般OR概念当作本规范的合取项偷偷展开。

组织沿用特征本体根内的多父DAG。比较类型/规则分类入口只作组织和查找，若作为普通概念必须有完整定义；不新建永久二次本体根或仅有名称的空概念。7160按FT形成的完整域锚点仍服务值域概念，不强迫跨维度RC归到一个伪造结果FT下。

从通用到具体可以通过增加必要条件形成细分RC；删除条件或放宽必要约束形成上位时必须有完整含义包含依据。允许中间插层，只改真正相关的直接边，保留其它合法父边及原有概念含义；边替换按7140保持同事务根可达。不同K没有包含依据时不能仅按共享D接父子。

## 8. 最小语义样例

### 8.1 高于与矮于

甲身高170、乙身高180，单位一致：乙为A、甲为B，差值`+10`命中正域，形成/复用“高于”；甲为A、乙为B，差值`-10`命中负域，形成/复用“矮于”。两者是不同的有序关系概念。FC/EC相同不意味着RC相同；互逆表述可以描述同一事实，不合并两个概念。

### 8.2 指定参照点正上方

同一坐标系，Y轴向上，取值参照点由K固定：

```text
(A.Y - B.Y > 0)
AND (A.X - B.X = 0)
AND (A.Z - B.Z = 0)
```

三个D与对应FC分别成对引用，共享A/B及必要EC约束。此定义只描述参照点正上方，不自动证明整体分离、接触、支撑或覆盖；近似对齐必须另有显式容差规则。

### 8.3 有界区间包含

对同一坐标轴上的合法闭区间，严格包含可用：

```text
A下界 - B下界 > 0
AND A上界 - B上界 < 0
```

例如A=[2,8]、B=[0,10]同时满足。允许接触边界时分别采用非负/非正精确并集。轴对齐盒可在具名算法下逐轴组合，包围盒包含不等于任意形状的真实内部或容器空腔。

`A最低点Y - B最高点Y > 0`可以证明相应整体上方关系；其负域可能包括重叠，不能直接命名为“整体下方”。域名称必须服从完整K，不能预设正负都是反义词。

## 9. 非成功、完善与淘汰

| 情况 | 必须行为 |
| --- | --- |
| 完整查找确认同义缺失 | 仅在定义、真实依据及准入完整时新建。 |
| 冷却同义RC | 按7140复用和记录真实用途，不重复创建。 |
| 退役同义RC | 返回待具名治理；恢复前不换键创建同义替代。 |
| 已不可逆退出的等价旧RC | 保留旧历史，按7140以新身份形成，不复活旧编码。 |
| 材料/规则缺失、不可比、溢出、读取漂移、预算不足 | 分别返回真实缺口或失败，不回填0，不视为查无概念或当前不满足。 |
| 部分维度成功 | 可以报告各计算的真实状态；不得宣称完整复合判断成功，完整定义/依据未闭合不发布RC。 |
| RC已发布而支持或名称失败 | 保留并报告真实已发布阶段，重试查重复用，不重建RC或声称全部完成。 |

概念定义与其全部必要组成/约束、根归属和初始直接边由概念owner同笔完整发布，失败不得公开半定义。跨世界来源、名称和多个概念的形成不默认全局原子；各阶段按真实结果收敛，内部可靠性不作为RC业务字段。

用途及治理沿用7140：实际关系判断、识别选择、条件采用或语言理解/表达使用具有真实依据时才计量。生成、后台扫描、重复计算、支持建立、多父重复到达和技术重放不自证新用途；计量读取失败不是零用途。

增加名称、来源和合法关系不改变RC身份；改变D、K含义、FC/EC限制或AND组成形成新定义并查重。被其它有效RC/EC/动态/方法定义引用的概念不能因自身少用直接删除；定义引用与可释放来源引用分账。中间层退出保持根可达，不删除准确F、值、存在、状态或其它世界事实。

## 10. 结构承接与完成声明

复用4240的唯一概念结构所有者，以具名值式定义和强类型关系承接D、FC、EC、K及合取组成。每项逻辑定义必须可完整读回，定义中的概念引用与实际来源记录分开；L1不增加专用业务入口，数据层不以名称或扫描替应用判定同义和适用。

本规范不冻结C++ DTO、类型编码、共享域的物理引用格式或新关系角色编码。旧FT加域签名与旧概念服务不因文档路由更新自动支持新模型；具体提供者须先完成具名结构、失败、发布、读回及迁移设计，不能静默重用旧编码或ABI。不在本次规范重建中生成代码计划、迁移持久数据或改变实例持久化权限。
