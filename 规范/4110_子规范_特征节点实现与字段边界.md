## 1. 定位与职责

本规范展开1130实例特征与2100特征值的物理合同：实例特征字段、建立与添加值流程、公开能力与结果状态，以及特征值节点的结构节点、字段、物理类型、压缩树、保存查询流程、独立材料文件和回收。历史聚合与子特征归组的算法由4115规定，比较算子与算法由4180、4181规定，实例所属概念同步由7160规定。

特征owner唯一写入实例特征；特征值类唯一写入特征值节点及压缩层。二者只通过4015公开的基础函数和组合原子发布操作数据，不访问底座内部容器、编码计数器或锁；底座也不识别特征、二维格、三维格、全零描述或压缩算法。

## 2. 实例特征字段

| 信息 | 基数 | 物理承载与含义 |
| --- | --- | --- |
| 节点类型 | 恰一 | 字段关系指向共享实例特征节点类型 |
| 持有节点 | 恰一 | 外部父子关系的父端；可以是需求、存在（含任务、方法、词条、语言材料范围、指代实例等信息存在）、场景、其它特征、状态或动态（1130） |
| 正式特征概念 | 恰一 | 字段关系指向当前用于分类、单位及规则选择的特征概念 |
| 实例单位 | 至多一 | 建立时从模板概念复制 |
| 当前值 | 至多一 | 最近一次成功写入的准确值 |
| 标准值 | 至多一 | 历史值中命中次数最高的稳定代表值 |
| 历史值命中记录 | 零到多 | 每项保存准确值、命中次数和所属实例 |
| 实例历史聚合值域 | 至多一 | 完整历史不同值按概念聚合规则计算的值域（4115） |
| 归组子特征标记 | 子特征恰一 | 仅归组子特征具有；子特征由父特征经外部父子关系持有 |

准确值载体为`std::variant<std::int64_t, 稳定编码>`：I64标量直接保存；非I64原始材料保存特征值节点编码；有类型的信息节点引用（存在、场景、需求、任务、方法、二次特征定义或实例等）保存目标节点编码，由特征类型限定目标类别，不送入原始材料读取路径（1130、1160）。该载体不据此限制逻辑引用类别。

历史不同值由命中记录唯一得出，不建立第二套历史；比较与聚合规则只由正式特征概念提供，实例不复制规则。

## 3. 建立或取得实例特征

公开入口：

```cpp
稳定编码 建立或取得特征(
    稳定编码 持有节点,
    稳定编码 特征概念节点,
    std::optional<新特征准确值> 实际值 = std::nullopt) noexcept;
```

流程：

```text
核验持有节点和传入概念
-> 按“持有节点 + 特征类型根”查找直接持有的实例特征
-> 恰一则完整读回并复用；多项为结构不一致并拒绝
-> 可选原始材料按物理类型核验；信息节点引用按1130核验类别、身份、结构与引用保护
-> 提供实际值时，在同一特征类型根下查找包含该值的最具体概念；唯一则采用，未找到或冲突则采用类型根
-> 在一次组合发布中建立节点类型、概念引用、可选单位和持有关系，并增加所选概念的当前实例引用数量
-> 返回实例节点
```

该函数不写入实际值；建立后当前值、标准值、历史与聚合均为空。同一持有者同一特征类型根至多一个直接实例特征；唯一例外是状态或动态持有的二次特征，按“类型＋结果方向”唯一（4180第9节）。

持有者为信息存在时，其实例特征与普通存在相同：当前值变化生成的状态挂入该信息存在所在的内部治理世界或自然语言世界场景的状态列表（4212）。

## 4. 添加特征值

公开入口：

```cpp
新特征值添加结果 添加特征值(
    稳定编码 特征节点,
    const 新特征准确值& 新值) noexcept;
```

流程：

```text
完整读回实例和当前概念
-> 原始材料核验物理类型；信息节点引用核验并建立目标引用保护
-> 用概念比较规则查找等价历史值
-> 已有值增加命中次数；新值建立命中记录
-> 与当前值不等时更新当前值
-> 首个值成为标准值；候选命中次数严格超过现标准值时替换，并列不替换
-> 按4115尝试归组子特征并重算历史聚合值域
-> 按7160同步正式所属概念
-> 当前值实际改变时，由持有节点所属存在或场景owner在同一次组合发布中生成状态并挂入其发生场景（1160）
-> 返回结构化结果
```

持有者为状态或动态的实例特征（含二次特征）建立时一次写入，之后固定：对其调用`添加特征值`返回入口拒绝，不生成状态。归组子特征随父特征同次更新，不单独生成状态。

实际值不受当前概念值域限制。每次调用都增加命中次数；只有当前值、历史集合、命中次数、标准值、子特征、聚合域和概念同步均无变化时才可返回“无变化”。一次业务变化整体发布；基础数据集组合原子发布能力未覆盖的步骤，结果报告“值已更新但聚合未完成”，这只是过渡状态：调用方须保留原实例并允许同值重试，不重新分配实例，不把它解释为零写入失败。

## 5. 公开能力与结果状态

公开能力：`初始化`、`建立或取得特征`、`查询特征`、`获取特征`、`是特征节点`、`添加特征值`、`比较特征值`、`比较特征`、`比较特征概念值域关系`、`计算特征概念值域重叠度`、`计算特征概念材料接近度`。比较类入口的语义由4180、4181规定。不提供主动删除、变更持有者、删除历史值或直接写聚合域的入口；实例所属概念只由7160同步链改变。

添加值结果至少区分：已完成、无变化、入口拒绝、特征不存在、概念不存在、材料类型不相容、结构不一致、值已更新但聚合未完成、资源失败。结果同时报告当前值、历史集合、命中次数、标准值是否变化，并可返回接收子特征和聚合结果。资源失败、结构不一致不得改写为业务“不符合”或合法空值。

## 6. 特征值共享结构节点与字段

特征值类初始化形成或恢复下列共享结构节点，按固定结构身份恢复并完整核验，只在确认不存在时建立：

```text
节点类型字段节点
特征值类型节点
二维压缩层类型节点
三维压缩层类型节点
材料物理类型字段节点
原始材料字段节点
压缩材料字段节点
```

二维与三维压缩层使用不同类型节点，不得仅依赖运行期索引附加枚举区分。

特征值节点固定四字段：节点身份、节点类型（指向特征值类型节点）、材料物理类型（I64编码，由调用特征类明确提供）、原始材料（完整不可变的强类型直接值或规范化全零描述）。不得增加业务特征类型、所属特征/存在/场景/任务、单位、坐标系、观察时间、当前/历史/区间/概念/比较规则、宽高深、压缩层数量或列表、压缩根值、版本、事实代次、幂等身份或操作记录。

压缩层节点固定三字段：节点身份、节点类型（二维或三维压缩层类型节点）、压缩材料（`vector<uint64_t>`）。不保存物理类型、宽高深、层号、根值或内部上级字段；分辨率由材料长度和对应几何规则确定。

## 7. 材料物理类型

| 类型 | 原始材料容器 | 说明 |
| --- | --- | --- |
| `U64数组` | `vector<uint64_t>` | 完整、有序、保留重复 |
| `I64数组` | `vector<int64_t>` | 完整、有序、保留重复 |
| `UTF8字符串` | `string` | 完整UTF-8字节序列，保存前必须是合法UTF-8；空字符串是否允许由特征类型准入决定 |
| `二维二值格` | `vector<uint64_t>` | 正方形二值占用格，支持分层压缩 |
| `三维二值格` | `vector<uint64_t>` | 正方体二值占用格，支持分层压缩，不含颜色 |

单个I64不建立特征值节点。特征值类不得根据容器长度、内容或调用路径自行判断材料类型；类型与材料变体不相容时拒绝且零写入。普通材料（U64/I64数组、字符串）不建立空间压缩树，精确相同（同类型、同长度、逐元素或逐字节相同）全局复用同一节点。

## 8. 二维与三维二值格

二维：形状`N×N`，`N = 8 × 2^k`（k≥0），总位数`N²`，容器长度`N²/64`；位序`i = y × N + x`，字索引`i/64`，位索引`i%64`，低位先行，1为占用、0为未占用。每次把下层`2×2`子格按逻辑OR汇总为上层一格，逐层压缩到`8×8`，根层恰由一个`uint64_t`保存。

三维：形状`N×N×N`，`N = 4 × 2^k`（k≥0）；位序`i = (z × N + y) × N + x`；每次把`2×2×2`子格按OR汇总，逐层压缩到`4×4×4`，根层恰由一个`uint64_t`保存；不保存颜色、现实坐标、尺寸或姿态。

无法连续减半到根分辨率的输入拒绝。

## 9. 全零材料

逻辑全零格由上层具名材料准备能力识别并转换为规范化描述：二维`[0, 1, N]`、三维`[0, 2, N]`。特征值类只接受规范化描述，作为对应材料的完整原始材料保存，不为其建立压缩层；读取后由上层解析能力确定性展开。每个维度、每个分辨率至多一个全零节点，二维与三维、不同N不得共用。以普通完整输入提交的全零材料拒绝且零写入。

## 10. 压缩树与保存查询流程

压缩树只用外部父子关系组织：粗压缩层→细压缩层→完整原始特征值节点；原始分辨率已是根分辨率时为根压缩层→完整节点。同物理类型、同压缩材料、同上级路径复用同一压缩层节点；二维与三维即使根值相同也不共用根。压缩层只是查询索引材料，不能被特征、场景、存在、任务或概念引用；正式读取始终从完整原始节点取材料，不要求从根值恢复。

普通材料保存：核验类型与变体→内容索引召回候选→完整读回候选→精确相同则复用→否则在一次组合发布中建立节点与字段→读回后返回。

二值格保存：核验形状、分辨率和位序→拒绝未规范化全零→逐级计算压缩材料→按类型与根材料查询或建立根→沿父子关系逐层查询或建立→在最细层下查询完整原始节点→精确相同则复用，否则建立→读回后返回。组合原子发布未覆盖时，失败须逆序删除本调用尚未公开且未被复用的字段、关系和节点，不得删除已复用结构。

按节点读取须核验：节点存在、节点类型恰一并指向特征值类型、材料物理类型恰一且受支持、原始材料恰一且与类型相容、二值格形状或全零描述合法；任一缺失、重复或损坏均不返回部分成功。按完整材料查询：普通材料索引召回后完整复核；二值格按相同压缩算法逐级核对后核对完整原始材料。哈希、根值和中间层只能缩小候选，不能单独证明相同。

公开能力：`初始化`、`保存或取得特征值`、`获取特征值`、`查询特征值`、`是特征值节点`。保存同时承担新增与精确复用，不另建允许重复写入的“添加”；原始材料不可修改，不提供修改入口。

## 11. 独立材料文件

大材料或原始采集可保存为不可变独立文件。材料只有在格式、长度、摘要、来源和类型校验通过并被正式特征值或实例特征引用后才参与运行期事实；文件路径只是定位，不是对象身份，移动物理位置不改变材料身份与摘要。未被引用的材料是待回收材料，不能反向创建对象、值或关系；恢复时只能作为隔离输入重新准入。

## 12. 回收

不再被任何实例特征、状态、动态、概念值域或其它正式事实引用的特征值节点及其专用压缩层、独立材料，按回收规则清理（0050第1.5节、2100）。回收前由特征值类用4015第10.1节引用闭包查询证明无引用，并在独占锁内复核；被复用的共享压缩层仍被其它节点引用时保留。共享结构节点不回收。

## 13. 非成功与最低验证

特征值操作至少区分：入口非法、未初始化、材料类型不相容、材料格式不合法、未规范化全零输入、未找到、重复候选或结构不唯一、字段缺失或重复、关系损坏、并发冲突、资源失败、发布结果未知、内部不一致。进入正式业务链的接口须返回结构化结果。

最低验证：同持有者同类型根唯一；当前值、命中、标准值及“无变化”判定；值已更新但聚合未完成的同值重试收敛；相同普通材料复用、不同材料分离；U64/I64保持顺序与重复，字符串按完整UTF-8字节复用；二维`8、16、32…`、三维`4、8、16…`合法、不规则分辨率拒绝；每层压缩等于下层OR；二维三维同根值不共用；最终命中核对完整原始材料；全零描述按类型与N复用、普通全零拒绝；压缩层不得被引用；中间失败不暴露字段不完整的节点；重启后恢复同一结构节点与特征值身份；并发保存相同材料只形成一个节点；无引用时按回收规则清理、有引用时保留。

## 14. 迁移说明

下列旧口径退出正向语义，只作代码与数据迁移定位：固定不可变的准确F与存在“已知特征/当前采用”双结构；场景C/组织父P/三父定位、`Gread/H`、首次账与七引用位置；按C/P位置与内容复用F；值身份不同于节点身份、只允许I64/I64组/U64组的旧值合同；原始层与全部压缩层共放一个U64组；体素含颜色段。1130、1140、1150、1160、1170和7160已按2100的身份与值承载方式同步。
