# 4070 子规范 持久证据恢复候选、内存原子发布、审计与材料回收

编号：4070
日期：20260828
状态：正式子规范

直接上级规范：0050。

直接依赖规范：4010—4060。

## 1. 定位

本规范规定启动和运行期恢复的候选隔离、全量互证、重新准入、内存代次原子发布、审计和材料回收。原文件名为兼容引用保留；SQL、快照、事件和材料文件都只是恢复输入或持久证据，不是恢复后的运行期权威。

恢复、完整快照、审计和材料回收属于独立管理面，不是普通 L1 CRUD 的隐式前置、参与者或固定结果字段。普通 CRUD 不调用本规范入口；只有启动 / 运维策略或具名恢复请求显式进入本规范。

受 `INSTINCT-BOOTSTRAP-ROOT-ANCHOR` 的跨进程重启读回目标驱动，启动期完整 L1 持久证据与隔离恢复现重新进入实施范围。唯一合法实现对象是完整 L1 中性事实状态，不得只保存本能根、两个根值、业务锚点或其它领域子图。恢复管理面仍不得成为普通查询回源、第二事实 owner 或业务服务。

本次恢复目标至少证明受控退出后的进程重启；崩溃、断电、介质损坏恢复和长期材料保留只有在独立验证实际覆盖后才能声明。原无参数 `建立L1事实基座运行包()` 可以继续作为仓库外隔离测试使用的纯内存运行包，不得用于普通应用生产装配。持久运行包只在配置显式有效时增加持久准备；普通读取不访问磁盘，纯内存运行包不承担快照、恢复或审计成本。

## 2. 恢复候选

1. SQL 行、快照、事件、材料文件或外部数据库记录首先都是恢复材料，不是当前事实。
2. 每次恢复具有稳定恢复批次编码、来源、格式标识、目标事实范围和事实截止代次。
3. 候选在隔离区解析和互证，不得进入普通查询、缓存或领域当前视图。

### 2.1 受控存储会话

1. 持久运行包接收版本化、绝对且规范化的受控存储根；路径只属于装配配置，不进入 L1 普通 CRUD 请求、事实或公开读回。
2. 一个存储根同一时刻只允许一个进程持有操作系统级独占会话。不能取得独占会话时返回“存储占用”，不得退化为新空仓。
3. 固定材料只包括一个当前清单、两个轮换快照槽、一个会话锁和一个有界恢复审计账。不存在清单且两个快照槽均不存在时才是合法空仓；清单缺失但任一槽存在、清单指向槽缺失或摘要不符，均不得按空仓启动。
4. 清单固定记录格式版本、单调快照序号、事实代次、活动槽、载荷长度和 SHA-256。快照采用显式小端定长整数、长度前缀和稳定枚举标签；禁止直接写 C++ 对象布局、地址、`sizeof` 填充、`variant::index()`、容器桶序或未冻结类型哈希。
5. 写入先形成非活动槽临时文件并刷新，再原子替换非活动槽；随后形成并刷新新清单，再原子替换当前清单。清单是恢复材料提交见证，不是运行期事实权威。
6. 未被当前清单选择的完整槽只作上一轮回退材料，不得在当前清单有效时择新、择大或择优采用；当前清单无效时也不得自行回退旧槽冒充成功恢复。

## 3. 全量互证

恢复必须验证：

```text
全局稳定编码占用及不可复用
+ L1 结构所有者当前 / 历史事实及范围种类
+ 节点类型与属性类型节点及状态
+ 节点 / 关系 / 值的不可变 owner，值事实及材料摘要
+ 全部关系端点、关系类型 owner、角色和创建 / 退出事实代次
+ 当前 / 历史 / 已退出生命周期与属性槽一致性
+ v1 legacy 与 owner-scoped 两套幂等域和发布证据
```

完整持久载荷必须逐字段覆盖：

```text
事实代次与下个稳定编码
+ 当前 / 历史结构所有者事实
+ 当前节点、关系和值
+ 全部历史事实和物理清理墓碑
+ 永久占用稳定编码集合
+ 物理清理、中性 legacy、所有者建立、所有者范围写入和跨所有者原子事务幂等账
+ 旧共享 owner 定位
```

当前源 / 目标 / 关系类型索引、当前节点引用索引和历史候选索引都是非权威派生物，不进入快照；恢复候选必须从已解码权威字段确定重建，再执行完整状态互证。运行期端口集合、锁、地址、缓存和正在形成但尚未发布的候选不得持久化。

0050 已冻结的实例材料周期维护前缀 `0x4E43'0000'0000'0000` 属于进程生命周期内幂等域，其账项不跨进程恢复；其它未被正式声明为进程生命周期的幂等账必须完整恢复。不得借此例外丢弃本能根、结构登记、owner 建立或普通写入幂等证据。

缺项、混批、编码复义、事实代次矛盾、材料损坏、关系断裂、owner 缺失 / 复义、事实 owner 在创建截止无效、独占 / legacy 范围非法、关系类型 owner 与关系 owner 不同、节点槽 / 值 owner 不同、退出跨 owner 或幂等 owner 域矛盾，均拒绝整批或按正式批次合同隔离，不得默认 legacy、补 owner 或发布半结构。L1—L5 只验证各自中性数据结构完整性；业务不变量由 L5 之外业务层在业务入口重新开放前独立复核，不得让数据恢复事务调用业务服务或接收业务回调。

## 4. 重新准入与发布

1. 恢复不得把 SQL 行、文件记录或外部对象直接放入当前视图；候选必须经过 L1 中性结构准入。领域业务重新准入是发布后的独立开放门禁，不是 L1 恢复事务参与者。
2. 启动恢复前不存在运行期权威。恢复材料之间同义只说明可组成候选；异义、缺项、过期、已退出事实复活或事实代次冲突必须拒绝或隔离，不得择优拼接。
3. 完整候选通过 4040 的内存事实事务一次原子发布；该内存代次切换是恢复的唯一运行期事实发布点。
4. 发布后按恢复批次编码、节点 / 关系 / 值编码和事实代次见证从内存权威读回；随后从该内存代次确定重建索引和缓存，并记录持久证据采用结果。
5. 恢复材料只重建 owner 事实和普通事实 owner，不重建运行期能力。发布成功后，由新 `L1事实基座运行包` 的唯一签发器按具名重入请求、当前独占 owner 事实和“同 owner 无活动端口”条件重新签发；SQL 行、缓存、名称、旧 token 或 owner 编码不能取得端口。
6. 持久运行包中的每个成功写候选必须先按本节形成新快照与清单，持久准备成功后才执行现有无抛出内存状态交换。持久准备失败时不交换内存状态、不推进事实代次、不返回新编码映射。
7. 进程在新清单提交后、内存交换前终止时，下一进程可以采用该完整候选；上一调用属于未知结果。持久化的原幂等账必须使原请求重放收敛，禁止分配第二组编码。
8. 资源、共享、磁盘空间或刷新失败映射为中性资源失败；编码器无法表达已验证状态、清单与载荷自相矛盾或持久成功后内存读回不一致映射为内部不一致。普通 CRUD 不新增业务许可或持久路径字段。
9. 精确重复、只读和零变化操作不写新快照、不增加快照序号，也不推进事实代次。

## 5. 启动与运行期

启动恢复必须在任何 owner 写端口签发、L2 服务构造和普通业务入口开放前完成整仓审计并原子发布内存权威。固定顺序为：取得独占存储会话，读取清单和活动槽，在隔离状态解码，重建非权威索引，执行整仓不变量互证，更新有界恢复审计，以一次无抛出交换发布内存状态，随后才允许签发器按现行 owner 建立幂等事实形成新进程端口。合法空仓直接建立代次零内存仓并绑定持久会话，不伪造恢复见证。

普通应用必须使用持久运行包工厂；配置、恢复或审计任一失败时装配失败，后续 L2 owner、真实自我、本体根、本能根和线程均不得形成。运行期恢复必须限制受影响事实范围，验证相对当前事实代次的并发与当前性，并通过新代次原子建立新事实与退出旧事实；本次计划不实现运行期局部恢复入口。

`L1所有者范围写端口`、签发器内部租约、nonce、地址、进程 / 线程身份、模块名和服务枚举只属于当前运行包瞬时能力，不得持久化或随恢复材料、审计、SQL、日志和界面传播。旧进程端口在恢复后永久无效。

## 6. 审计

审计记录恢复批次编码、SQL / 文件等输入来源与摘要、判定规则标识、每类拒绝、内存代次发布结果、持久证据状态和发布后读回。审计材料只供回查，不能修复事实或替代内存发布证据。

本次启动恢复审计采用固定上限 128 条的值式环形记录；超限只淘汰最早审计记录，不删除当前清单、活动快照、上一完整槽、事实或幂等证据。审计更新失败时不得开放持久运行包。

owner 审计只记录值式 owner 事实、普通事实 owner、owner 生命周期、幂等 owner 域和签发 / 重入 / 退出的结构化结果类别；不得记录或回显可复用 raw 端口、租约、nonce、地址或 token。

## 7. 退役与回收

1. 退出先在内存已发布代次中写入退出事实代次并保留历史、引用和证据；SQL / 材料随后保存对应持久证据。
2. 材料只有在当前、历史、审计、恢复、法律保留和并发读者均不再引用时才可进入回收候选。
3. 回收失败不反向恢复业务当前性；删除 SQL 行或目录文件不得改变内存已发布事实。
4. 独占 owner 只能在无活动端口、无该 owner 当前节点 / 关系 / 值、无待收敛幂等提交且恢复 / 审计引用闭合后退出。owner 历史和稳定编码永久保留，不得复活或重新签给另一服务。

## 8. 结构化结果

至少区分建立空仓、恢复成功、入口拒绝、存储占用、材料不完整、格式不支持、摘要不一致、编码 / owner / 关系 / 属性槽冲突、事实代次漂移、资源失败、持久证据未知和发布后内部不一致。恢复材料 owner 缺项属于材料不完整；材料校验通过后 owner 复义、半发布或新代次读回变化属于内部不一致。操作系统文件访问拒绝是技术存储失败，不是 DATA 业务许可拒绝。业务入口是否重新开放由 L5 之外独立裁决，不进入恢复结果状态。
