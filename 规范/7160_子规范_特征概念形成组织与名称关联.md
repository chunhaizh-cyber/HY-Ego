# 7160 子规范 特征概念形成组织与名称关联

编号：7160
日期：20260912
版本：v0.4
状态：正式子规范

直接上级规范：2220。
直接依赖规范：1120、1130、4120、4180、7140。
相关边界规范：0050、0500、1140、1160、2100、2210、4030、4110、4230、4240、7150、7200、7210、7220。

新准确F观察必须先经1130/4110/4205定位创建准入。没有C/P不得创建F、登记观察或形成概念；准确F与位置共同成立后才进入本规范概念流程。应用建点结果必须返回实际最终特征概念信息，或“特征已定位、概念未完成”及真实失败/待收敛原因。场景位置不进入FT加规范化域的概念身份；F位置与概念上下位、名称引用分账，概念失败不回滚出生事务。

## 1. 定位与分工

特征概念是某一正式特征类型下确定允许值域的抽象身份，复用 2220 的通用概念结构、形成流程和 7140 的治理机制；不建立第五本体根、第二概念仓或新的概念身份体系。

本规范只定义“FT加域”的值域特征概念。二次关系概念由7170/7180独立定义为共享结果域、特征概念和存在概念约束及其AND组合，不能套用本规范签名删掉关系条件。派生所得单个准确标量仍可以按其类型形成值域概括，但该概括不等于完整RC；先天/后天类型共享积累规则不因此改变。

本规范展开特征概念应用；准确特征、存在采用、类型规则和概念数据操作各自独立：

| 对象 / 能力 | 唯一职责 |
| --- | --- |
| 准确特征 F | 按 1130 / 4110 保存固定类型与准确值，名称只是可选概念引用。 |
| 正式特征类型 FT | 按 1120 / 4120 提供完整允许域、表示、解析、比较和域形成参数来源。 |
| 类型积累器 | 特征概念应用内部按 FT 共享的处理机制，维护真实观察输入与域形成材料，不按存在建立第二套积累。 |
| 特征概念 C | 保存 FT 与规范化域定义、根归属及正式关系；不保存某存在的当前观察或历史值集合。 |
| 存在 E | 按 7150 维护自己的已知 F 和当前采用，不能由全类型概念反推个体经历。 |
| 概念形成 / 命名应用 | 查找适用概念、形成完整定义、精确查重、提交发布、绑定名称和提出治理请求。 |
| 概念结构服务 | 复用既有唯一 owner 保存、读取、校验概念及关系；不从普通 CRUD 自行学习或创造概念。 |

先天和后天类型使用同一模型，仅类型来源不同。跨存在共享不等于无类型地混合数值：相同 int64 表示但类型、单位、坐标或解释不同的输入不能混积。存在身份不进入特征概念签名，也不是 F 到 C 名称关联的必需前置。

按 FT 积累和建立类型完整域根，适用于具有独立准确值及正式完整允许域合同的类型。4120 中没有自身原始值域的复合特征模板只承载组成结构，不能为套用本流程伪造准确值、完整域或类型根；其组成中的合法值类型分别进入本机制。若复合计算另行形成具备完整值与域合同的正式结果类型，该结果类型同样适用，不因先天 / 后天来源区别处理。

## 2. 定义、身份与字段归属

### 2.1 专项定义

特征概念的专项语义定义固定为：

```text
一个正式特征类型 FT
+ 一个规范化值域 D
```

完整语义签名在特征本体根内查重。同 FT、同规范化域及同解释含义复用同一仍当前的概念身份；代表、比较规则等只有在决定域含义时参与定义。命中次数、形成宿主、名称文字、观察顺序、积累记录身份、用途及发布证据不参与同义身份判定。

| 逻辑信息 | 承载与约束 |
| --- | --- |
| 概念节点身份 | 既有独立概念身份，不复用 F、FT 或值身份。 |
| 特征类型 | 一个正式类型引用，定义成立后不得改义。 |
| 规范化值域 | 一个完整允许集合；数值域与结构域按第 3 节解释。 |
| 所属根及直接上下位 | 既有概念关系，根内无环、允许多父，不复制父指针或子列表为第二权威。 |
| 来源支持与语言名称 | 既有具名关系；不复制准确 F 或语言材料。 |
| 用途及治理记录 | 保留，用于保留、冷却、退役与淘汰策略；独立于定义保存，复用 7140，不增加成熟资格、固定层号或技术版本本体字段。 |

用途及治理记录是服务淘汰策略的关联信息，不参与概念定义或同义签名，也不要求概念先有使用记录才能成立。真实用途及治理行为发生时按 7140 保存，不为凑齐字段伪造记录。

概念是否已命名、被采用或经常出现，不改变其 FT 和域定义。一个域可只含一个准确值，但单点概念仍不是准确 F。

### 2.2 积累材料不成为平行概念

每个 FT 在逻辑上只有一套共享积累，物理使用现有节点、关系和值承载，不因此增设独立本体根或私有权威仓。类型根提供组织入口，不是把全部过程数据内嵌在根节点。

尚未形成概念的输入 / 域材料属于过程材料，不建立另一种候选概念资格。概念发布后，以 C 引用关联后续命中和依据，不再维护另一份可独立改义的已发布域定义。暂存材料、必要来源和计量按其正式提供者可靠保存；可重建计数或索引不成为第二份权威依据。

已知参数不足不能以任意半径、空定义或“三次稳定”补齐；材料保留策略和缺失提供者须在实施前的具名合同中明确，不以无限累积代替设计。

## 3. 值域形成与比较规则

### 3.1 可复用规则

域规则沿用 4120 第 3.3 节的类型绑定来源，比较沿用 4180；不在准确特征类和概念类各实现一套算法。

1. 新原子域以合法真实输入作为固定代表，按正式允许误差 / 范围参数形成，不能从区间中点伪造观察样本。
2. I64 原子域使用下界、上界明确的闭区间，单点上下界相等；端点必须可表示且符合类型允许集合。禁止整数绕回、默认截断或无限区间掩盖无效结果。
3. 轮廓等结构原子域由完整固定代表、正式比较规则和同量纲允许差异范围共同定义。域表示的是满足比较谓词的原始结构值集合，不是材料编号或距离数值本身。
4. 正式规则决定表示、单位、坐标、方向、解析及适用范围；同类型全局积累不授权默认对齐、旋转归一化或混合不同解释。
5. 代表与域含义固定后不随后续输入移动。改变域含义应形成新定义并查重，不继续使用旧身份或旧计数证明新域已被观察。

缺规则、误差参数、解析能力或材料时，返回对应缺口 / 失败，不当作不命中，也不阻止独立合法准确 F 保存。已有比较或校正算法的样本要求仍按其本来合同；取消概念首次次数门槛不意味着所有比较都不需要材料。

### 3.2 匹配、相等、包含与并集

精确值相等、值命中域、域同义和域包含是四种不同判断。命中同一个值、域相交或代表接近都不证明两个域相同或具有上下位关系。

原子域及其合法精确并集按真实允许集合规范化。多个不连续区间保留空隙，不能用总最小最大区间填平；结构并集是谓词析取，不能替换成包围半径。正式二次至n次输出仍各是一项I64；其合法标量域的精确并集不是多分量特征值，也不是7180的跨维度AND关系定义。

结构包含只能由完整域含义相等、显式原子集合包含或正式规则证明。4180 的非度量轮廓距离不能使用三角不等式或“中心距离 + 半径”推包含。不能证明包含时不得猜父子关系。

## 4. 按类型组织、向下生成与中间插层

### 4.1 组织形态

```text
特征概念本体总根
-> 各正式 FT 的完整允许域概念（类型根）
-> 同 FT 的较细范围概念
-> 更具体的范围概念
```

“树林”表示按类型分区的组织和展开方式；权威仍是 2220 的多父无环图，不强制所有概念只有一个父。类型根是普通概念，不与 FT 定义节点共用身份，也不是新增永久本体根。相同原始数值但不同 FT 的概念不建立域细分父子。

生成主要从已有类型完整域向叶方向进行，由实际输入及完整域定义驱动，不预先均分完整域，也不靠枚举区间端点制造事实。每个普通同类型概念经该类型完整域锚点到达特征总根；只保存直接边，不持久化层号或树路径。

### 4.2 新域挂接与生成终止

应用区分“归类查找”和“完整新域定义的形成 / 查重”。父域适用不等于已有同义细域：不能因为输入命中类型完整域或某上位，就禁止形成有独立完整定义的更细域。

有新域 D 时，先在同 FT 范围内按完整规范化定义查重；不存在同义身份才建立。挂接依据是可证明包含：在适用上位中保持全部必要直接边，并对被新域真正包含的下位调整直接关系，不按容器首项、创建时间或单一最近距离决定归属。

相同域只复用，不创建同域子孙；继续生成真正子域必须严格缩小允许集合。固定误差规则可能反复产生相同域，这时停止新增层级；不得默认逐层减半误差、增加次数就缩域或递归把一次输入当成多次观察。本规范不发明更深细分参数；只有正式类型 / 细分规则已经给出完整新定义时才进入该分支。

### 4.3 中间插层

在同 FT 的 P 到 C 之间插入 M，必须证明：

```text
D(C) 严格包含于 D(M)，D(M) 严格包含于 D(P)
```

M 已存在则复用，相等域不插层。只调整 M 真正覆盖的下位；其它非冗余父边保留。P、C 的身份、域及事实支持不变，不删除父域或复制 C。边替换在概念结构服务的合法事务中共同成立，不暴露断根、环或半层结构。

例如 [0,100] 到 [45,55] 之间，若按合法规则形成 [40,60]，可插入中间概念；不能只因想增加一层就编造该域。重叠域 [0,6]、[4,10] 的公共子域 [4,6] 必须保留两个合法上位，不复制子概念。

## 5. 查找、生成与名称关联流程

### 5.1 正常形成

建立或复用准确特征的应用按以下流程自动组合，不要求用户逐次手动调用概念生成：

1. 取得正式 FT、完整准确输入及可回查来源；可以先查询已有概念。新概念的形成依据必须已正式成立，尚未发布输入不能冒充已发布世界事实；必要时先建立无名称的准确 F。
2. 先定位该 FT 类型根；尚未建立时，以已正式成立的 FT 及其完整允许域定义精确查重，合法缺失才经普通概念准入建立并直接挂接已发布特征总根，完整读回后再向下查找适用的保留概念。同义则复用，退役及技术失败按第 5.2 节分流；完整域缺失不造根，不跳过类型锚点，也不重新建立本体总根。根或上位的覆盖只是导航 / 粗分类，不冒充已有细分域；遇到完整新细域定义时仍按第 4.2 节处理。
3. 已有适用概念按 2220 的正式规则选用；多个互不包含的适用结果形成或复用其精确并集共同上位，不任选首项，也不复制多个当前名称字段。
4. 没有适用细分概念时，按类型规则形成完整域定义，再做同义精确查重；同义则复用，否则经统一准入发布新概念及必要根归属 / 关系。定义完整则首见生成并立即可用，不等待三次命中、成熟评估或固定天数。
5. 概念完整发布并读回后，通过概念结构服务建立或替换 F 到 C 的名称引用。准确 F 的类型和值须适用于所选 C；不要求先有存在或自然语言词条。只有同时宣称某存在已采用 / 已归类时，才额外核验该存在自己的关系。
6. 名称当前至多一个，表示采用的概念身份；C 到自然语言词条按 2210 / 7220。概念尚无文字名称不阻止 F 到 C 的绑定，文字变化也不改变 F 的准确内容。

尚未形成概念不否定准确 F。名称暂空与关系读取失败分别报告；概念改名不改 F 值，同概念不证明无准确变化。

### 5.2 未找到、退役与失败

| 结果 | 处理 |
| --- | --- |
| 完整查找确认没有同义概念 | 仅在定义、来源及准入完整时新建。 |
| 域规则 / 参数不足 | 不伪造域；准确特征可以保留无名称结果，积累 / 名称缺口单独报告。 |
| 材料缺失、预算不足、读取或比较失败 | 不当作未找到，不据此重复创建。 |
| 冷却同义概念 | 按 7140 复用 / 治理，不创建第二身份。 |
| 退役同义概念 | 经具名治理恢复后使用；未恢复前不新建同义替代。 |
| 已不可逆退出的等价旧概念 | 旧身份只作审计，按 7140 用新身份重新形成。 |
| 新概念已发布、名称绑定失败 | 保留真实 C 和 F，返回名称未完成；重试查重并补绑定，不重建 C 或隐瞒已发布结果。 |

准确 F、类型积累、概念定义及名称绑定不默认构成跨 owner 单一事务。每次宣称概念发布成功必须完整读回其定义、根归属和必要关系；中间插层不允许半结构。整体操作不能用部分成功冒充命名完成。

## 6. 观察、命中、采用与识别

每个 FT 接收相同模型的独立真实观察，不按存在分桶。20、22、20 可以复用两个准确 F，但积累输入仍为三次观察；不能只在新 F 创建时输入积累。普通读取、技术重试、重放与重复投递不增加观察命中。

一次输入适用多个重叠域时，各域最多计一次；多父路径重复到达同一 C 时按 C 去重。观察命中、业务适用查找与真实业务采用分别按 7140 保存依据，计量由已有具名记录重建，不依赖私有缓存。生成、支持、图维护或后台喂样本不自证用途，不存在首次三次准入门槛。

概念域是识别概括，不证明域内每个值都曾出现。某存在的已知 F 及采用由 7150 保留；全类型支持材料不等于该存在的历史。如果用概念简化个体识别材料，必须保留该概念为何适用于这个存在的依据，不能把其它存在的观察转为本存在事实。本规范不要求永久保留每帧，也不以临时状态记录替代长期识别材料。

## 7. 完善与淘汰

增加支持依据、名称、真实用途和可证明的上下位关系可以保持概念身份；形成新细域保留父域。改变允许集合、代表所决定的匹配含义或比较解释必须形成新定义并查重，不能原地扩大 / 缩小旧域使历史名称和模板改义。

冷却、退役、恢复、不可逆退出及物理清理分别服从 7140。观察积累与生成不自动延长实际使用窗口；计量读取失败不是零用途。本规范不另设无使用天数或统计门槛。

退出概念不删除准确 F、值、存在或状态；名称、模板、有效定义和其它原生引用分别保护。中间层退出须维护必要替代直接边及同 FT 类型分区。仍有保留细分概念时，不能移除其必需类型完整域锚点，再以直接接特征总根冒充完整；类型根可按普通概念治理，不因此成为新增永久根。退役中间节点不作为普通命名候选，但结构展开不得因此漏掉仍有效的下位。

## 8. 最小能力与验证

| 能力 | 最小合同 |
| --- | --- |
| 按 FT 输入真实观察 | 完整类型和值来源；重复输入与新观察分开。 |
| 查找适用概念 | 类型限定、完整域匹配、全部合法分支，不只返回索引首项。 |
| 按完整域查重 / 建立 | 同义复用，定义完整缺则建；既有退役与技术失败不伪装不存在。 |
| 读取概念及上下位 | 完整定义、类型根归属、多父直接边和治理情况。 |
| 维护名称关联 | 按 F 定位读、建、替换、解除；类型 / 值适用，当前至多一个，不复制文字。 |
