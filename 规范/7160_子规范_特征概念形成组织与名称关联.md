## 1. 权威边界

本规范是单特征概念的数据结构、值域、规则、形成和生命周期的现行机器合同。

特征概念描述一个特征类型或该类型内部的具体值域。它不描述存在、场景或由多个不同特征类型构成的组合概念。

旧稿中的“概念建立后值域不可修改、概念默认永久保留、特征聚合不得生成概念”已经退出。当前模型允许依据实例实际历史调整概念值域，并在引用减少后删除零引用叶概念。

## 2. 概念树和类型身份

全局基础数据集中保存一个全局变量：

```cpp
稳定编码 特征概念树;
```

组织规则：

1. 特征概念树根只是组织根，不是特征概念。
2. 根的直接子节点是根链特征类型概念；根链节点身份就是特征类型身份。
3. 根链概念不因材料、单位和值域相同而互相合并。
4. 同一特征类型内部的具体概念通过外部父子关系形成从宽到窄的值域层级。
5. 当前采用单父树；每个概念恰有一个直接上位节点。
6. 字段节点、类型节点、角色节点和单位节点不挂入概念树。

新建全新特征类型时，不传上位概念；在既有类型内细化时，必须提供上位概念或由特征类先定位类型根。

## 3. 特征概念固定信息

每个概念节点包含：

| 信息 | 基数 | 含义 |
| --- | --- | --- |
| 节点类型 | 恰一 | 指向共享特征概念节点类型。 |
| 材料物理类型 | 恰一 | 决定准确值承载和可用规则。 |
| 值域 | 恰一 | 该概念当前覆盖的规范化范围或集合。 |
| 单位 | 可选一 | 概念整体单位；结构化分量可各自带单位。 |
| 比较规则 | 恰一 | 准确材料的等价比较规则。 |
| 聚合规则 | 恰一 | 历史不同值形成值域的规则。 |
| 名称关系 | 零到多 | 指向自然语言类后续建立的名称关系节点。 |
| 当前引用实例数量 | 恰一 | I64值；当前由实例正式概念字段直接引用的数量。 |

名称关系不参与概念结构身份匹配。概念类只保存名称关系节点引用，不建立词条、名称语义或名称关系节点。

当前引用实例数量不包含概念父子关系、查询结果或临时使用。

## 4. 材料物理类型和准确值

既有原始材料类型为（直接节点引用另见第5.3节）：

```text
I64标量、U64数组、I64数组、UTF8字符串、二维二值格、三维二值格
```

准确值承载：

```text
I64标量 -> 直接I64值
其它原始材料 -> 新版特征值节点稳定编码
```

非I64概念值域引用的特征值节点必须存在、可完整读回且材料类型一致。概念节点不重复保存原始数组、字符串、轮廓或体素材料。

## 5. 值域联合

基础值域表示如下；具名集合及直接信息引用扩展按第5.1至5.3节：

1. I64闭区间集合。
2. 某种非I64材料的全材料值域。
3. 一个或多个特征值节点组成的有限集合。
4. 由有序I64分量组成的结构化I64值域。

I64闭区间按下界排序，并归并重叠或相邻区间。有限节点集合排序去重。结构化分量的顺序从0连续递增，角色不得重复；维度数量由分量数量唯一得出，不保存第二份数量字段。

各表示在物理字段上互斥且恰有一种成立。材料类型、值域表示、单位和规则不相容时拒绝建立、更新或比较。

### 5.1 服务对象需求单节点引用

服务对象需求使用独立先天特征类型，不与服务任务集合或一次特征事实集合混用。一个准确值直接引用一个正式被认知需求D，比较采用需求身份精确判等；不对D编码求大小、距离、数量或方向。主体关系、内容完整性、确认及需求发生资格由需求owner按5170核验，概念比较不裁决承接。

类型根覆盖合法需求节点引用；有限节点域只表达可接受的D身份，不是需求集合快照。当前单D与历史去重D分别读取；“有新需求发生”按正式需求发生S读取，不由当前D是否第一次见到、历史D数量、命中次数或集合基准B推算。D完整内容由原owner独立读取，不能把需求发生S当成完整性概念。

需求身份由需求owner提供强类型只读合同；概念侧不解码需求私有字段，不在比较锁内递归确认或承接业务。身份非法、未装配或工程读取失败不折算为正常不满足。旧服务对象需求集合只按明确合同只读迁移，不以迁移派生状态触发新的现实需求；不因本规则改变自我交互对象、方法或任务集合。

### 5.2 存在引用集合与自我交互对象

自我“交互对象”使用独立先天特征类型，准确材料为正式存在稳定编码的U64无序去重集合；成员可以是人类、设备或其它存在，不限定人类，不冒充服务对象集合。只保存引用，不改变成员的场景归属；与单个存在引用、服务任务集合、服务对象需求单D引用分开。

类型根为U64全材料域、无单位，采用独立存在集合身份判等和完整快照精确聚合。正向约束域只含“必含存在节点组”“至少一个存在”：满足当且仅当当前集合包含全部必含成员且满足非空要求；无序去重规范化，域包含按同类集合数学处理。成员由存在owner独立核验，不能复用需求或任务身份。目标概念的人类筛选、连接状态和业务纳入资格不由集合身份算法推断。

同一特征类型根内，合法准确集合判等为整数10000或0；约束满足为整数1或0。有限材料域保存若干完整集合快照，不是成员并集。非零但非存在的节点不合法；不存在、未装配、读取异常不能伪装为合法空集或不满足。

U64数组不是底座引用关系。凡作为本类型准确材料、历史/标准值、有限快照域、正向约束域或状态材料保留的存在成员，必须建立正式成员引用保护；对应材料或域仍保留时，不得清理成员存在的身份内容。保护只在其引用来源确已退出后解除，不因当前集合移除了成员便删除历史保护。成员保护发布与存在退出须在底座完整联合快照上竞争，不能“先删除、后比较发现无效”。只读身份核验不得在概念比较锁内获取存在或特征业务锁。

生产首次为自我建立该特征时，只有确实尚无本字段且没有可证明应已纳入的正式成员事实时才建立空集并形成初始状态；旧单值“服务对象”字段不能自动迁移为已连接成员。已有集合完整读回复用，不清空、不从历史恢复当前值。本提供者不裁决断连、TTL、移除或重连策略；非空业务纳入须由后继方法依据正式连接事实执行，不将服务对象需求单D规则外推至本集合。

### 5.3 方法、需求、任务的类型化节点引用与集合

方法、任务特征保持同类别节点引用集合，单元素集合仍为集合。服务对象需求特征适用第5.1节的当前单D与历史D例外，不再套集合判等、包含或数量变化合同；其它具名引用类型不因本次局部裁决改变。实例组织、发布及生命周期按[1130第3.1、3.2节](1130_根规范_特征节点_20260720.md#31-方法需求任务的信息引用型特征)。引用保留原M、D、T身份，不复制其内容。

对仍采用集合的类型，一个准确值是完整、无序、去重的成员集合；已知空集合法，当前值未知须单独表示。类型根覆盖本类别的合法集合；有限快照域的每项是一份完整集合，不能把多个快照成员并集当成一个准确值。必含成员、至少一个成员等正向约束域沿用具名类型的明确数学语义；不得把成员有限列表误解成准确集合或完整快照域。服务任务集合的成员及宿主合同保持，不因本次需求特例放宽。

比较采用集合判等、包含、交集等明确规则；成员身份须由原领域owner核验，不对编码求差值、距离或方向。身份判等与条件满足的数值刻度分别按对应正式比较规则，不暗中混用。集合数量、数量变化及单位时间变化按二次特征合同处理，不从编码或历史并集推导。

内容或状态比较由原owner读取成员信息；方法能力、需求满足及任务完成不属于集合身份判等。集合未变不能推定成员内容未变。概念范围用于分类、匹配和条件核验，不改变实际值不受较窄概念值域准入限制的原则；目标类别及结构有效性仍是强类型约束。

写入、读取、比较须核验每个成员类别及可读身份，业务关联和权限由原领域裁决。目标不存在、读取故障、依赖未装配不能伪装成空集或正常不包含。历史聚合保留完整集合快照，不取历史成员并集冒充当前值，不冻结成员旧内容；全部保留来源遵守1130目标保护与退出合同。

正式特征概念为集合提供类型与范围，不因此创建独立的方法、需求、任务概念树。集合原始材料如何承载、通用类别约束及比较接口在物理设计中冻结；普通数组读取器不能据编码猜目标类型。当前仅有部分需求/任务/存在集合能力，方法集合、完整通用保护及消费者仍待实现。旧单值只可在明确迁移合同下转为单元素集合，不能把旧数据或ABI原地改义。

## 6. 建立、查询和更新

### 6.1 建立或取得

```cpp
稳定编码 建立或取得特征概念(
    const 特征概念定义&,
    const 新_特征值类&,
    std::optional<稳定编码> 上位概念 = std::nullopt) noexcept;
```

- 未给上位概念：建立新的根链特征类型概念，不跨根链按结构合并。
- 给出上位概念：材料、单位、规则必须相容，子值域必须被父值域包含并至少严格收缩一处。
- 同一直接父下存在相同结构定义时复用已有概念，并补充尚不存在的名称关系。
- 新概念的当前引用实例数量从0开始。

### 6.2 完整定义查询和按值查找

完整定义查询按材料类型、规范化值域、单位、比较规则和聚合规则匹配；名称关系不参加结构身份。

按值查找必须从一个根链特征类型概念开始，只遍历其子树：

```text
核验根链、材料和单位
-> 查找包含准确值的概念
-> 选择最具体候选
-> 没有候选返回未找到
-> 多个互不从属的同等最具体候选返回匹配冲突
```

### 6.3 值域更新

```cpp
bool 更新特征概念值域(
    稳定编码 特征概念节点,
    const 特征概念值域& 新值域,
    const 新_特征值类&) noexcept;
```

当前模型允许原地修改既有概念值域。更新必须保持材料物理类型、单位、比较规则、聚合规则和概念身份不变，并完整核验新值域。概念值域变化后，层级合法性由特征类的实例概念同步链继续处理。

## 7. 概念自动生成和层级维护

概念类提供建立、复用、值域更新、关系比较和引用计数能力；自动触发和业务顺序由特征类负责。

实例写入形成新的历史聚合值域后，特征类可以：

- 在当前概念下建立严格子概念；
- 在同一类型根下建立新的具体概念；
- 扩大当前概念或类型根值域；
- 将实例改挂到已有最具体概念；
- 调整与直接上位重复或越界的概念位置；
- 对同父兄弟执行等值复用和包含关系重挂。

相交或分离的兄弟概念不自动合并。当前模型不自动从多个同层概念提取共同点形成新的共同上位概念，也不自动修剪概念树层级。

## 8. 当前引用实例数量与删除

公开入口：

```cpp
bool 增加当前实例引用(稳定编码 特征概念节点) noexcept;
bool 减少当前实例引用(稳定编码 特征概念节点) noexcept;
```

规则如下：

1. 新实例正式引用概念时增加一次。
2. 复用已有实例不重复增加。
3. 实例改挂时，先增加新概念计数，再改实例字段，最后减少原概念计数。
4. 计数不得为负，增加不得溢出I64。
5. 只有发生减少动作且减少后为0时，才检查删除。
6. 引用数为0且没有子概念时，删除该概念的字段、结构化分量、概念树关系和概念节点。
7. 引用数为0但仍有子概念时保留。
8. 根链概念和普通下位概念不设类型例外；是否能够触发删除只由真实减少动作、零引用和无子概念共同决定。
9. 没有发生减少动作时，不对现有零引用概念做后台清扫。

当前实例特征没有主动删除入口，因此引用减少目前只由实例概念改挂链触发。

## 9. 比较与聚合规则

### 9.1 准确材料等价比较

概念类提供：

```cpp
特征概念比较结果 执行比较规则(...);
```

- I64数值：返回相等、大小次序和无溢出的绝对差。
- 完整材料精确：完整读回非I64材料，只有物理类型及原始材料完全一致才相等。

UTF-8字符串在特征类的相似度结果中采用二值表达：完整字节内容相等为`10000`，不相等为`0`。概念类不进行自然语言意义、模糊字符串或Unicode规范化比较。

当前H需求单D按第5.1节独立FT的需求身份精确判等，不采用集合算法。旧服务对象需求集合仅迁移保留，其原算法及其它仍有正式集合合同的类型不被删除或改义：合法成员规范化后同集为整数10000、异集为整数0；无顺序含义，不表示增减或数量。正向约束满足返回整数1/0并可给出缺少成员，不与判等刻度混用。集合历史聚合保存完整快照，不取成员并集冒充当前值；服务任务集合身份规则保持独立。

### 9.2 值域关系和单特征概念关系

`比较值域(...)`只返回相等、左包含右、右包含左、相交或分离，不把关系强行转换为相似度。

`比较单特征概念(...)`只处理同一根链特征类型内部的同一、上下位、共同上位或无可比关系，不处理多特征类型组合概念。

### 9.3 聚合

既有材料聚合规则为；信息引用另按第5.3节：

- `不自动聚合`：I64形成单值区间集合，非I64形成精确节点集合。
- `I64连续值归组`：相邻或重叠I64值形成闭区间。
- `完整材料精确集合`：非I64材料形成排序去重节点集合。

`执行聚合规则(...)`只计算规范化值域，不直接建立概念。概念节点的建立或更新由特征类在取得聚合结果后显式调用概念类入口完成。

## 10. 先天特征概念初始化

初始化建立特征概念树、共享字段和类型节点、毫米单位及分量角色；基础根链如下，当前H需求单D使用现独立需求FT，不合并其它已有类型。旧需求集合FT仅为存量迁移保留，不作为当前需求发生目标：

| 先天特征类型 | 材料和值域 |
| --- | --- |
| 三维空间坐标 | 三个I64分量，均为`INT64_MIN～INT64_MAX`，毫米。 |
| 三维空间尺寸 | 三个I64分量，均为`0～INT64_MAX`，毫米。 |
| RGB颜色 | 三个I64分量，均为`0～255`，无单位。 |
| 二维轮廓 | 二维二值格全材料值域。 |
| 三维体素 | 三维二值格全材料值域，不包含颜色。 |
| 服务对象需求 | 单D直接节点引用、全合法需求引用域、无单位；需求身份精确判等，发生按正式S读取。 |
| 旧服务对象需求集合（仅迁移保留） | 原U64数组全材料值域及专用集合判等/完整快照算法保留；不用于当前H需求发生。 |
| 自我交互对象集合 | U64数组全材料值域，无单位；专用存在身份判等、完整快照精确聚合，允许人类、设备及其它正式存在。 |

维度数量由结构化分量数量确定。当前初始化不建立坐标系概念，不写自然语言名称关系，不包含亮度特征类型。

```cpp
特征概念比较结果 执行比较规则(...) const noexcept;
特征概念值域比较结果 比较值域(...) const noexcept;
单特征概念关系结果 比较单特征概念(...) const noexcept;
特征概念聚合结果 执行聚合规则(...) const noexcept;
```

概念删除不是任意公开操作，只能由`减少当前实例引用()`在零引用叶概念条件成立时触发。

## 12. 非成功边界

规则执行至少区分：

```text
已完成、无变化、入口拒绝、材料类型不相容、值不存在、
规则不支持、资源失败、内部不一致
```

按值查找区分：

```text
已找到、未找到、入口拒绝、材料类型不相容、单位不相容、
匹配冲突、结构不一致、资源失败
```

部分创建、查询和更新入口仍使用空编码、空`optional`、空`vector`或`false`合并失败原因。调用者不得把所有空结果解释为“确定不存在”。

## 13. 职责边界

特征概念类负责：

- 特征类型根和单特征概念身份；
- 值域、单位、比较规则、聚合规则和名称关系引用；
- 同一特征类型内部的上下位组织；
- 完整定义查询和按值查找；
- 值域更新；
- 当前直接实例引用数量及零引用叶概念删除；
- 已登记先天特征类型初始化；旧服务对象需求集合类型及算法仅说明既有迁移能力，不作为当前H单D规则的完成证据。

特征概念类不负责：

- 保存非I64原始材料；
- 保存实例当前值、历史值和标准值；
- 决定实例持有者；
- 自动触发实例写入后的概念同步顺序；
- 多特征类型组合概念；
- 主动共同上位概念归纳和概念树修剪；
- 自然语言词条和名称关系节点建立；
- 体素颜色、坐标系、存在、场景、状态、动态、因果或内部治理。
