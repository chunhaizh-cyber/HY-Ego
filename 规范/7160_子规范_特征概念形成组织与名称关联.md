## 1. 权威边界

本规范是单特征概念的数据结构、值域、规则、形成和生命周期的现行机器合同。

特征概念描述一个特征类型或该类型内部的具体值域。它不描述存在、场景或由多个不同特征类型构成的组合概念。

旧稿中的“概念建立后值域不可修改、概念默认永久保留、特征聚合不得生成概念”已经退出。当前模型允许依据实例实际历史调整概念值域，并在引用减少后删除零引用叶概念。

## 2. 概念树和类型身份

全局基础数据集中保存一个全局变量：

```cpp
稳定编码 特征概念树;
```

组织规则：

1. 特征概念树根只是组织根，不是特征概念。
2. 根的直接子节点是根链特征类型概念；根链节点身份就是特征类型身份。
3. 根链概念不因材料、单位和值域相同而互相合并。
4. 同一特征类型内部的具体概念通过外部父子关系形成从宽到窄的值域层级。
5. 当前采用单父树；每个概念恰有一个直接上位节点。
6. 字段节点、类型节点、角色节点和单位节点不挂入概念树。

新建全新特征类型时，不传上位概念；在既有类型内细化时，必须提供上位概念或由特征类先定位类型根。

## 3. 特征概念固定信息

每个概念节点包含：

| 信息 | 基数 | 含义 |
| --- | --- | --- |
| 节点类型 | 恰一 | 指向共享特征概念节点类型。 |
| 材料物理类型 | 恰一 | 决定准确值承载和可用规则。 |
| 值域 | 恰一 | 该概念当前覆盖的规范化范围或集合。 |
| 单位 | 可选一 | 概念整体单位；结构化分量可各自带单位。 |
| 比较规则 | 恰一 | 准确材料的等价比较规则。 |
| 聚合规则 | 恰一 | 历史不同值形成值域的规则。 |
| 名称关系 | 零到多 | 指向自然语言类后续建立的名称关系节点。 |
| 当前引用实例数量 | 恰一 | I64值；当前由实例正式概念字段直接引用的数量。 |

名称关系不参与概念结构身份匹配。概念类只保存名称关系节点引用，不建立词条、名称语义或名称关系节点。

当前引用实例数量不包含概念父子关系、查询结果或临时使用。

## 4. 材料物理类型和准确值

材料物理类型封闭为：

```text
I64标量、U64数组、I64数组、UTF8字符串、二维二值格、三维二值格
```

准确值承载：

```text
I64标量 -> 直接I64值
其它材料 -> 新版特征值节点稳定编码
```

非I64概念值域引用的特征值节点必须存在、可完整读回且材料类型一致。概念节点不重复保存原始数组、字符串、轮廓或体素材料。

## 5. 值域联合

特征概念值域只允许四种表示：

1. I64闭区间集合。
2. 某种非I64材料的全材料值域。
3. 一个或多个特征值节点组成的有限集合。
4. 由有序I64分量组成的结构化I64值域。

I64闭区间按下界排序，并归并重叠或相邻区间。有限节点集合排序去重。结构化分量的顺序从0连续递增，角色不得重复；维度数量由分量数量唯一得出，不保存第二份数量字段。

四种表示在物理字段上互斥且恰有一种成立。材料类型、值域表示、单位和规则不相容时拒绝建立、更新或比较。

## 6. 建立、查询和更新

### 6.1 建立或取得

```cpp
稳定编码 建立或取得特征概念(
    const 特征概念定义&,
    const 新_特征值类&,
    std::optional<稳定编码> 上位概念 = std::nullopt) noexcept;
```

- 未给上位概念：建立新的根链特征类型概念，不跨根链按结构合并。
- 给出上位概念：材料、单位、规则必须相容，子值域必须被父值域包含并至少严格收缩一处。
- 同一直接父下存在相同结构定义时复用已有概念，并补充尚不存在的名称关系。
- 新概念的当前引用实例数量从0开始。

### 6.2 完整定义查询和按值查找

完整定义查询按材料类型、规范化值域、单位、比较规则和聚合规则匹配；名称关系不参加结构身份。

按值查找必须从一个根链特征类型概念开始，只遍历其子树：

```text
核验根链、材料和单位
-> 查找包含准确值的概念
-> 选择最具体候选
-> 没有候选返回未找到
-> 多个互不从属的同等最具体候选返回匹配冲突
```

### 6.3 值域更新

```cpp
bool 更新特征概念值域(
    稳定编码 特征概念节点,
    const 特征概念值域& 新值域,
    const 新_特征值类&) noexcept;
```

当前模型允许原地修改既有概念值域。更新必须保持材料物理类型、单位、比较规则、聚合规则和概念身份不变，并完整核验新值域。概念值域变化后，层级合法性由特征类的实例概念同步链继续处理。

## 7. 概念自动生成和层级维护

概念类提供建立、复用、值域更新、关系比较和引用计数能力；自动触发和业务顺序由特征类负责。

实例写入形成新的历史聚合值域后，特征类可以：

- 在当前概念下建立严格子概念；
- 在同一类型根下建立新的具体概念；
- 扩大当前概念或类型根值域；
- 将实例改挂到已有最具体概念；
- 调整与直接上位重复或越界的概念位置；
- 对同父兄弟执行等值复用和包含关系重挂。

相交或分离的兄弟概念不自动合并。当前模型不自动从多个同层概念提取共同点形成新的共同上位概念，也不自动修剪概念树层级。

## 8. 当前引用实例数量与删除

公开入口：

```cpp
bool 增加当前实例引用(稳定编码 特征概念节点) noexcept;
bool 减少当前实例引用(稳定编码 特征概念节点) noexcept;
```

规则如下：

1. 新实例正式引用概念时增加一次。
2. 复用已有实例不重复增加。
3. 实例改挂时，先增加新概念计数，再改实例字段，最后减少原概念计数。
4. 计数不得为负，增加不得溢出I64。
5. 只有发生减少动作且减少后为0时，才检查删除。
6. 引用数为0且没有子概念时，删除该概念的字段、结构化分量、概念树关系和概念节点。
7. 引用数为0但仍有子概念时保留。
8. 根链概念和普通下位概念不设类型例外；是否能够触发删除只由真实减少动作、零引用和无子概念共同决定。
9. 没有发生减少动作时，不对现有零引用概念做后台清扫。

当前实例特征没有主动删除入口，因此引用减少目前只由实例概念改挂链触发。

## 9. 比较与聚合规则

### 9.1 准确材料等价比较

概念类提供：

```cpp
特征概念比较结果 执行比较规则(...);
```

- I64数值：返回相等、大小次序和无溢出的绝对差。
- 完整材料精确：完整读回非I64材料，只有物理类型及原始材料完全一致才相等。

UTF-8字符串在特征类的相似度结果中采用二值表达：完整字节内容相等为`10000`，不相等为`0`。概念类不进行自然语言意义、模糊字符串或Unicode规范化比较。

### 9.2 值域关系和单特征概念关系

`比较值域(...)`只返回相等、左包含右、右包含左、相交或分离，不把关系强行转换为相似度。

`比较单特征概念(...)`只处理同一根链特征类型内部的同一、上下位、共同上位或无可比关系，不处理多特征类型组合概念。

### 9.3 聚合

聚合规则封闭为：

- `不自动聚合`：I64形成单值区间集合，非I64形成精确节点集合。
- `I64连续值归组`：相邻或重叠I64值形成闭区间。
- `完整材料精确集合`：非I64材料形成排序去重节点集合。

`执行聚合规则(...)`只计算规范化值域，不直接建立概念。概念节点的建立或更新由特征类在取得聚合结果后显式调用概念类入口完成。

## 10. 先天特征概念初始化

初始化建立特征概念树、共享字段和类型节点、毫米单位、分量角色，并建立五个根链先天特征概念：

| 先天特征类型 | 材料和值域 |
| --- | --- |
| 三维空间坐标 | 三个I64分量，均为`INT64_MIN～INT64_MAX`，毫米。 |
| 三维空间尺寸 | 三个I64分量，均为`0～INT64_MAX`，毫米。 |
| RGB颜色 | 三个I64分量，均为`0～255`，无单位。 |
| 二维轮廓 | 二维二值格全材料值域。 |
| 三维体素 | 三维二值格全材料值域，不包含颜色。 |

维度数量由结构化分量数量确定。当前初始化不建立坐标系概念，不写自然语言名称关系，不包含亮度特征类型。

## 11. 公开能力

当前公开能力包括：

```cpp
bool 初始化(...) noexcept;
std::optional<先天特征概念集合> 获取先天特征概念() const noexcept;
稳定编码 建立或取得特征概念(...) noexcept;
std::optional<特征概念信息> 获取特征概念(...) const noexcept;
bool 更新特征概念值域(...) noexcept;
bool 增加当前实例引用(...) noexcept;
bool 减少当前实例引用(...) noexcept;
std::vector<稳定编码> 查询特征概念(...) const noexcept;
特征概念按值查找结果 查找值对应的最具体概念(...) const noexcept;
bool 是特征概念节点(...) const noexcept;
特征概念比较结果 执行比较规则(...) const noexcept;
特征概念值域比较结果 比较值域(...) const noexcept;
单特征概念关系结果 比较单特征概念(...) const noexcept;
特征概念聚合结果 执行聚合规则(...) const noexcept;
```

概念删除不是任意公开操作，只能由`减少当前实例引用()`在零引用叶概念条件成立时触发。

## 12. 非成功边界

规则执行至少区分：

```text
已完成、无变化、入口拒绝、材料类型不相容、值不存在、
规则不支持、资源失败、内部不一致
```

按值查找区分：

```text
已找到、未找到、入口拒绝、材料类型不相容、单位不相容、
匹配冲突、结构不一致、资源失败
```

部分创建、查询和更新入口仍使用空编码、空`optional`、空`vector`或`false`合并失败原因。调用者不得把所有空结果解释为“确定不存在”。

## 13. 职责边界

特征概念类负责：

- 特征类型根和单特征概念身份；
- 值域、单位、比较规则、聚合规则和名称关系引用；
- 同一特征类型内部的上下位组织；
- 完整定义查询和按值查找；
- 值域更新；
- 当前直接实例引用数量及零引用叶概念删除；
- 五个先天特征类型初始化。

特征概念类不负责：

- 保存非I64原始材料；
- 保存实例当前值、历史值和标准值；
- 决定实例持有者；
- 自动触发实例写入后的概念同步顺序；
- 多特征类型组合概念；
- 主动共同上位概念归纳和概念树修剪；
- 自然语言词条和名称关系节点建立；
- 体素颜色、坐标系、存在、场景、状态、动态、因果或内部治理。

## 14. 非权威实现完成边界

基于当前代码，以下能力已经具备并不再作为本阶段待完善项：

- 四种值域表示、规范化、建立和完整读回；
- 根链特征类型与下位概念建立、复用和查询；
- 按准确值查找最具体概念；
- 值域原地更新；
- 值域关系和单特征概念关系比较；
- 比较与聚合规则；
- 五个先天特征概念初始化；
- 当前实例引用计数；
- 引用减少后的零引用叶概念删除；
- 由特征类驱动的具体概念生成、实例改挂和层级整理。

以下事项属于当前阶段接受的边界，不因本规范更新宣称已经实现：

- 基础数据集持久化和跨启动固定身份恢复；
- 组合原子发布、发布未知恢复及跨进程并发唯一性；
- 自然语言名称提供者和显式坐标系；
- 实例主动删除引发的引用减少；
- 主动共同上位概念归纳和概念树修剪；
- 统一领域写授权；其它代码仍可绕过概念类直接写基础数据集；
- 生产消费者接线、根工程构建、跨进程恢复和集成验收。

当前代码是单进程新版概念模型实现。独立编译和仓库外运行验证不等于生产切换或完整业务闭环。
