# 1170 根规范 动态节点

编号：1170
日期：20260909
版本：v0.10
状态：正式根规范

## 1. 根定位

动态节点描述具体某一存在在一段时间内发生的变化，承载原子状态变化及其组合；合法动作致变记录在此基础上由4220收紧。动态信息由场景组织，独立动态概念由2220/7190在已有动态根下组织；“变化”领域锚点不兼任概念身份，不另设并列动态模板根。

动态只记录已经发生的变化、组成、来源及其业务引用，不承载特征当前值。涉及存在的业务比较先重读其当前采用，再按 1130 / 2100 取得对应固定准确 F 的完整值；不能以旧 F 可读、最后动态、动态后状态、时间或目录顺序推定当前采用。

## 2. 本项目承载

```text
动态节点及稳定句柄
+ 被描述主体存在关系
+ 变化内容：原子端点/属性绑定，或直接子动态/组成角色
+ 可选名称概念引用
```

上述四项为本体逻辑信息，由节点、关系和值共同表达，不是C++布局。实际时间范围由端点/成员派生；场景动态根及组织归属由场景类维护，二者不混入本体字段。必要来源、归组依据及动作扩展依4210/4220承载，不是额外通用封套。组合不伪造总体端点，不以旧单目标角色承接新结构。来源动作必须指向合法方法动作入口或领域服务动作事实，线程、调度器、外部输入、日志和界面不得占位。

## 3. 事实与边界

1. 原子变化保留真实状态端点；组合保留子动态来源、角色和实际时序。主体、场景、被描述属性、用途及来源由独立强类型关系承载，不进入成员状态本体。原子端点按4202/4210完整使用绑定核验同主体、同属性及发生上下文，不能从共享中性状态或组织根推定；整体/内部描述沿4202递归组织。技术可靠性和保留合同不新增为本轮业务字段；没有动作证据的被动变化不得伪造方法动作。
2. 外部变化只能记录为观察动态或外部事件动态，不得伪装成自我方法动作。
3. 原子及组合动态通过1150/4202的实际场景动态根组织为实例树；组织父单一，组合来源可复用引用。不得把动态当作普通场景成员、存在组成部分或特征分裂子节点；旧全面禁止动态实例树的条款退役。
4. 简单动态可以聚合成复杂动态，但聚合只能形成动态域内部的来源证据链，不改变原子动态的场景归属。
5. 基础事实池或索引登记不构成业务世界树层级或动态聚合层级。

## 4. 写入、读取与验证

DATA之外的动态应用负责相邻变化判断、时间段归组与递归组合，再向唯一动态结构服务提交规范化请求。数据服务只校验来源、组成、时间、关系和既有可靠性/清理约束并发布、读取结构；不得在DATA内判断概念、业务许可、目标满足或动作成功。新结构的精确物理合同须另行闭合，不把本规范当作已有ABI。

动态内容读回由动态类闭合主体、端点或直接成员、来源及派生时间；场景内动态完整视图再组合场景类的实际组织关系和归根路径。两者不冒充同一个owner的写入或成功，按4210第9节区分内容发布、场景组织及完整读回；动态类不反向写场景。动作证据按4220另核。前置通过后的内部结构缺口不得包装成普通动态缺失。

动态可以触发或定位某个特征需要重新检查，但消费者必须先冻结非零事实截止，重新读取目标涉及的当前特征值和目标状态合同后比较。动态前值、后值及其状态记录只能作为历史、来源、变化解释和审计证据，不能直接形成自检、需求满足或目标差距结论。

## 5. 生命周期与当前性

变化主体、端点、组成及来源事实不可覆写；调整组合或动作解释须形成合法新结果。可选名称关系按正式合同单独增、换、退，不改变化内容、不复制动态、不覆盖历史名称。实例保留、有限TTL、数量上限、墓碑与历史已清理按0050/1160/4230；索引裁剪和事实清理分账，不承诺旧载荷永久可读。来源/组合闭包必须受保护，概念抽象不隐式删除来源动态。
