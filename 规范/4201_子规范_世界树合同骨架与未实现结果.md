# 4201 子规范 世界树合同骨架与未实现结果

编号：4201
日期：20260803
状态：正式子规范

直接上级规范：0050。

直接依赖规范：4200。

相关边界规范：4170、4180。

## 1. 定位

本规范允许世界树后继提供者在真实业务行为完成前，先发布最终公开合同和显式未实现骨架，以消除模块身份、完整签名、DTO 所有权、工程登记、链接和合法消费者拒绝分支的依赖门控。

骨架不是业务能力。它不得建立、读取后伪装、修改、发布或恢复任何机器事实，也不得解除要求真实成功行为、同代次事实、事务发布、权威读回或正式入口闭环的依赖门控。

## 2. 稳定未实现状态

1. 世界树目标服务的公开结果枚举必须为骨架保留具名状态 `未实现`；该状态必须具有固定非零数值，且不得与成功、未找到、入口拒绝、资源失败或内部不一致复用。
2. 现行稳定值冻结为：

```text
节点直接世界引导状态::未实现 = 11
节点直接世界结构读取状态::未实现 = 8
节点直接特征读取状态::未实现 = 8
节点直接存在规格状态::未实现 = 5
节点直接场景写入状态::未实现 = 9
节点直接状态动态读取状态::未实现 = 8
节点直接状态动态发布状态::未实现 = 14
世界树业务状态::未实现 = 11
特征比较状态::未实现 = 8
特征比较拒绝原因::未实现 = 20
节点直接特征批次提交状态::未实现 = 9
```

3. `节点直接世界结构读取状态` 是 L2 世界结构提供者自己的公开状态，稳定值为：`已读取=1、未找到=2、入口拒绝=3、版本漂移=4、许可拒绝=5、资源失败=6、内部不一致=7、未实现=8`。它不得直接复用 L1 `节点直接结构服务状态`，从而避免让 L2 合同受 L1 内部查询分类反向拥有。
4. `节点直接特征读取状态` 的完整稳定值为：`已读取=1、未找到=2、入口拒绝=3、版本漂移=4、许可拒绝=5、资源失败=6、内部不一致=7、未实现=8`。它属于 L2 特征事实所有者，不复用 L1 查询状态。
5. `特征比较状态` 的完整稳定值和 `特征比较拒绝原因` 的完整稳定值由4180 §5.1冻结。比较骨架必须固定返回 `状态=未实现(8)、拒绝原因=未实现(20)、代次/注册/版本/输入回执=0或空、全部比较载荷为空`，不得回显请求或进入注册/算法分支。
6. `节点直接状态动态读取状态` 的完整稳定值为：`已读取=1、未找到=2、入口拒绝=3、版本漂移=4、许可拒绝=5、资源失败=6、内部不一致=7、未实现=8`。它属于 L2 状态动态事实所有者，不得复用 L1 查询状态。
7. `节点直接特征批次提交状态` 的完整稳定值为：`已提交=1、幂等读回=2、入口拒绝=3、幂等冲突=4、版本漂移=5、许可拒绝=6、资源失败=7、内部不一致=8、未实现=9`。它属于L2节点直接特征写入服务；骨架固定返回 `未实现(9)、发布代次0、持久证据不适用、读回空、缺项组空`，不得读取请求或调用查询、批次数据操作和L1提交依赖。
8. 当前尚未形成正式稳定枚举的其它提供者不在上述稳定值表内，其骨架公开合同不得发布。后继规范必须先冻结完整枚举及 `未实现` 的精确非零值，不得以“最大值加一”作为运行期动态规则。
9. `未实现` 一经进入公开合同即作为兼容值保留。真实实现完成后，正式成功路径不得继续返回它，但不得复用或删除其数值。

## 3. 骨架函数合同

1. 骨架必须使用最终模块名、最终中文函数名、最终参数与返回类型、最终可见性和最终构造依赖；禁止先发布万能参数、临时 DTO、`void*`、JSON、裸 I64 或以后必须破坏性改签的占位接口。
2. 每个骨架公开函数只允许：

```text
构造一个由调用方拥有的结果值
-> 设置 状态=未实现
-> 设置 发布代次/事实截止代次=0
-> 设置 持久证据状态=不适用（若该结果具有此字段）
-> 清空 optional、读回、缺项组和其它业务载荷
-> 返回结果
```

3. 骨架不得调用仓库、SQL、材料、L1/L2 提供者、事务、许可、锁、缓存、日志写入或时钟；不得分配稳定身份、探测幂等、取得事实代次或读取当前事实。
4. 骨架构造函数只保存最终合同要求的非空引用；不读取依赖、不执行恢复、不注册运行期入口。最终依赖类型尚未成立时不得发布骨架，不得用删除依赖、空指针或临时前置声明改变最终合同。
5. `未实现` 是合法结构化非成功，不是异常、资源失败或内部不一致。最近服务边界不得把它记录为机器错误；调用方必须原样拒绝继续成功路径。
6. 状态动态最终合同骨架固定为三类返回：查询返回 `未实现(8)、事实截止代次0、状态组/动态组/缺项组空`；状态写项形成返回 `未实现(14)、空局部身份、空写项组、空读回规格`；发布返回 `未实现(14)、发布代次0、持久证据不适用、读回空、缺项组空`。三类函数均不得读取请求或调用保存依赖。
7. 骨架不得为了提前编译删除最终构造依赖。状态动态查询服务必须保存世界结构读取服务和L1结构查询服务；动态业务服务必须保存查询、特征、比较、状态、状态动态数据操作和L1提交服务六项最终引用。

## 4. 合法消费与门控

1. 合法消费者可以基于骨架完成编译、链接、结构化结果分支和安全入口巡检；收到 `未实现` 后必须立即结束本次业务调用，保持零机器事实变化。
2. 禁止把 `未实现` 转换为成功、空成功、未找到、资源失败后重试、旧栈回退、SQL 回源或默认对象。
3. 骨架最多解除以下门控：

```text
模块和文件身份已存在
公开 DTO 与完整签名已进入代码基线
最终依赖方向可以编译和链接
合法消费者能够识别并安全停止于未实现
```

4. 骨架不能解除以下门控：

```text
真实领域准入和业务结果
幂等、事务、撤销、最后发布和发布后读回
非零事实截止代次或发布代次
同代次组合和稳定排序
恢复、持久证据或 SQL 故障分支
正式生产入口接线
局部可继续或服务验收通过
```

5. 消费者只要求合同存在和安全拒绝时，可以依赖骨架结果；任何业务要求真实成功行为、权威终态或独立读回时，必须依赖对应真实行为已经成立的服务结果。

## 5. 骨架替换与验收

1. 真实行为实现必须在原模块和原签名内替换骨架函数体，不建立第二入口、不改变 DTO 所有者、不保留骨架旁路。
2. 替换前必须核对精确函数签名和 `未实现` 数值；发现不一致时不得用重载或适配壳兼容。
3. 骨架代码只允许取得 `编译接入通过`，以及在安全入口真实进入、返回 `未实现`、零副作用时取得 `入口巡检通过`。不得声明 `局部可继续`、`服务验收通过`、提供者完成或生产接线完成。
4. 验证至少覆盖：完整函数清单、全部骨架返回 `未实现`、所有代次为 0、全部读回为空、零 L0/L1/L2 调用边、零机器事实变化、调用方不进入成功后继。
5. 状态动态真实查询与发布必须在原模块、原类和原签名内替换骨架函数体；查询和发布的 `未实现=8/14` 永久保留，不建立第二入口或兼容重载。

## 6. 非目标

- 不允许用骨架跳过真实提供者。
- 不把空函数当作业务完成或执行许可。
- 不要求所有简单纯值辅助函数返回 `未实现`；本规范只约束尚未具备真实业务行为的公开服务骨架。
- 不改变 4200 已冻结的世界事实、事务、同代次和 SQL 非权威语义。
