## 1. 具名裁决与目的

本函数改变自我所在现实场景中自我的交互对象特征当前引用，原因是固定外设场景的窗口接收数量状态在本次观察期间更新，目的是记录自我与已明确对端的连接关系。自我不迁入外设场景，不修改外设事实；外设类和外设世界独立接收、记录F/S/D。未知对象身份可使用已建立的匿名具体存在，不把“交互对象”概念当作该实例。

用户已替换旧“发收／收发两步证明连接”语义：首次读取仅建立基准，每轮读取固定窗口接收数量最新状态，与上轮状态比较，更新即建立关系。禁止发送`.`、展开消息集合、理解正文、要求发收次序或第三条消息、用历史非零接收量直接成功。不设业务超时，只在主动终止或连接成立时正常退出；工程错误仍进入既有工程链，不伪装业务否定。停止控制复用现本能停止守卫，不在本叶实现单工作独立停止。

## 2. 能力核对与范围

已有`新_状态类::按实例特征查询状态`、world场景状态列表、`新_二次特征类::计算`和正式特征变化组合入口可组合复用。二次比较左减右，最新为左，上轮为右。旧`新交互连接过程`含两消息和提交号，旧`核验消息连接过程`、真实运行服务、模拟世界以及学习事实消费必须一起迁移，不能留下两步核验。

唯一C++入口仍是`新_本能函数集::建立连接(const 方法参数场景&) noexcept`。任务/直接调用身份及资源只由执行适配持有，不加函数参数，不新增全局停止布尔量，不另写专用模拟学习。

## 4. 最新状态读取和二次比较

真实适配在固定外设场景正式状态列表内筛选：被描述存在=5、来源实例特征=6、FT与6定义一致。选同时间语义下强时间最大的唯一状态；不同状态同最大时间是工程不一致，不按编码或容器顺序选取。以状态固定准确值读取整数，不用当前数量替代历史基准，不自行对稳定编码相减。

首次取得状态固定为基准；不存在基准属于材料不齐而非成功。每轮已读基准和最新状态相同则等待；新状态必须时间较后。调用`新_二次特征类::计算`，左右输入均为`二次特征准确特征输入{状态节点,该状态FT,固定准确值}`，左最新、右基准，由现规则推导/复用比较概念。成功差值为0则更新基准继续等待；非零冻结前后状态来源并进入关系发布。真实累计数单调性由外设事实发布服务保证，本函数不重复承担外设治理；模拟按合法参数域可产生双向更新。计算错误不包装成无新输入。

每次未成功比较后将已处理最新状态设为下一轮基准；等待复用可停止等待，保持现约50ms节奏。基准与最终状态在在途调用中受现状态引用保护，取消/退出释放，最终连接证据持有的状态继续保护；不得用局部稳定编码代替寿命保护。

二次特征对象在连接服务内组合`新_二次特征类(特征服务,世界.获取事实服务引用().二次特征概念服务)`，不扩大普通装配ABI。模拟也使用同计算规则，不直接编造差值。

## 5. 执行、关系写入与证据合同

核心现场删除提交号、收先、发送/接收消息及发送阶段，改为基准状态和更新状态。阶段为待接收状态更新、待关系发布、已确认关系、已取消及既有工程/来源收口。入口只读取已正式绑定的参数和初始数量状态，不重复任务筹办的整套条件核验；正常写入服务承担目标有效性与合法发布保障。动作仍以self交互对象F为目标，在正式写之前记录；外设状态由外设更新形成，不能登记成连接动作直接制造。

得到更新后保留本次正式绑定和两状态来源，冻结本次发布许可，不重新展开整套条件复核。通过既有world引用更新入口写入对端引用并正式读回，写入服务核验目标有效性并取得实际S/D及结果关系。无变化可成功但不造变化动态。按此前许可点裁决，许可已冻结后的网页关闭不撤销已确认事实；主动停止在写入前检查，写后保留真实事实。

`新隔离连接完成材料`改为`{新交互绑定 绑定; 稳定编码 调用节点,主动作,基准状态,更新状态;}`。`核验消息连接过程`同名保留但合同整体改为数量状态更新语义，完整签名保持`新交互求值状态 核验消息连接过程(const 新交互连接过程&, const 新特征信息&, const 新交互绑定&, const 新消息连接输入构成&)`；不兼容转发旧两步实现。核验动作归属、真实状态相同F/FT/窗口/外设场景、时间递增、比较非零结果、交互者当前或历史含目标引用。不得仅凭引用值已经等于对端而补造本次状态更新证据。

## 6. 通用模拟输入提供者闭环

已有通用`新模拟输入事件{目标参数,值}`、方法`初始模拟事件参数组`和`推进模拟输入`，本叶直接复用。v3声明`初始模拟事件参数组={6}`，移除旧连接消息输入方案，不新增调用进行中枚举、正文范围或消息FT定位。通用采样仍按合法I64范围独立生成输入与事件值，不用方法名定制参数生成。

`推进模拟输入`末段当前只调用`替换模拟数值`，应扩为通用环境数值变化组合发布：取得参数F、所属存在和场景、FT、当前材料/值及最近状态；同值无新状态，异值在一次现有本地组合发布中更新F当前/历史，生成实际新状态和前后变化动态并挂入对应模拟场景，更新本地收集与写入来源为环境。初始数值参数必须建立初始状态。仅环境事件这条消费路径增加S/D，不能把方法写回的来源改成环境，亦不能把环境计数变化当方法结果。

首次环境推进发生在核心建立基准后；每个事件成功后游标前进一次，异常不伪装事件已消费。初值和事件相同可不完成，模拟输入耗尽时返回未完成材料，不造成功；不同值经同二次计算可形成连接，再仅以方法真正写入self交互F抽取结果。模拟允许自行生成所需条件信息，因此不必为数量变化伪造正文或消息节点；这些隔离条件不能反向传给现实world。

模拟窗口所属外设场景与self场景独立表达；撤销、关闭及归档保护全部本地状态引用，数量与关系状态分别归对应场景。没有正式原始绑定时不从私有容器顺序猜场景。
