# 本能根运行锚点详细设计 v0.1

基线：`b84d76895914b280f57d1abb021ddb8ebf81fb8e`。本设计落实8121，不使用旧候选中的`.ixx`路径。

## 施工对象

新增`业务/本能根运行初始化.数据.h/.cpp`与`业务/应用服务.本能根运行初始化.h/.cpp`；扩展`领域/数据服务.特征类.h/.cpp`、`状态类.h`、`需求类.h`，以及`装配.普通应用.h/.cpp`、`启动.应用程序.cpp`、项目文件。禁止线程文件与旧`L2*`模块。

ARCH-L2新增：按幂等身份正式读取特征定义/实例/比较注册；状态服务的“首值+初态+当前状态选择”跨owner单事务入口。ARCH-L4需求服务新增：目标合同CRUD和按幂等身份读回、根D（含父空）建立/读回、列表项及当前成员建立/读回；所有请求携带G0和固定键，所有成功回显完整实体与截止。

业务provider按8121顺序逐步补齐；每一步读当前G0，提交后重新读取。最终只在同一Gfinal形成锚点；调用方不得从中取得可写端口。普通应用增加`初始化普通应用本能根()`，启动在阶段19成功后调用，成功仍停在阶段20以前。

非成功逐层保留来源状态并归一为8121结果；资源失败、异常、代次漂移、幂等冲突、引用冲突、材料未闭合、已可能发布均零锚点。时间首次锁定在首次请求材料，重复和重启不重置根值。

验证：专属隔离驱动覆盖8121 §5矩阵；Debug/Release x64 Rebuild；静态检查无`.ixx`、无自我线程调用、无硬编码根节点编码。
