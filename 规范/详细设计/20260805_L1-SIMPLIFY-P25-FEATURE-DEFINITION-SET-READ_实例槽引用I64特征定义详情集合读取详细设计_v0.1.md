## 1. 目标与边界

本叶是 SELF-GOV-CLOSURE STEP-4 在 P24 之后的下一最早提供者。它在特征定义领域新增唯一无对象状态的只读投影模块 `海中鱼巣.领域.服务.L1特征定义集合读取`，提供一个公开纯函数，消费：

1. P24 成功形成的指定实际存在集合当前实例特征槽结构事实，其中嵌套保留 P21 主体见证；
2. P22 `尝试读取当前登记` 成功复制的不可变 `特征定义登记`；
3. 调用方通过 P17 一次非阻塞读取取得、且与 P24 同截止的一份 `L1完整快照`。

函数先在该快照内权威互证 P22 登记四节点，再从 P24 全部槽中提取精确去重定义身份，逐定义读取当前普通定义节点、唯一标记 / 下界 / 上界属性槽及三条 I64 值事实，形成完整类型化定义详情集合。输出定义集合必须与 P24 引用集合严格相等，不得扫描召回、夹带未被引用定义或省略损坏定义。

本叶不读取实例槽当前值，不比较当前值与定义上下界，不解释状态、动态、历史、审计、恢复装配、显示名称或其它类型定义。

## 2. 正式依据与能力矩阵

- 0050：属性类型和值必须有稳定编码、表示、所有者、来源、生命周期和发布证据；当前槽是唯一当前值指针。
- 1130：实例槽必须引用正式特征定义；定义身份不得由名称、枚举或显示材料替代。
- 4015：当前节点 / 值 / 属性槽只来自一个当前快照；值材料必须匹配属性类型表示。
- 4030：领域读取返回调用方拥有的不可变完整投影，不外泄仓、锁、事务或缓存。
- 4110：实例当前值必须回到抽象值域解释；定义与实例分账，定义领域拥有定义详情解释权。
- 4190：特征由类型身份、定义和当前值共同成立，组合服务不得直接解释 L1。
- 4200 §5.2/§5.3：完整宿主特征必须携带定义；悬空定义或定义材料矛盾不得部分成功。

## 3. 所有权、物理位置与依赖方向

定义事实解释权保持属于 `海中鱼巣.领域.服务.L1特征定义` 所在领域；P25 是该领域唯一批量定义详情只读投影，不是第二写入服务、第二登记或第二定义权威。不能把 P25 函数直接放进现有 `L1特征定义服务`：P24 DTO 位于实例特征模块，而实例特征模块已经单向依赖特征定义模块，反向导入会形成 MSVC 模块环。

因此未来物理位置固定为：


固定调用方向：

```text
后继特征 / 世界快照调用方
-> P17 尝试读取一份完整快照（返回并释放L1许可）
-> P24 用该快照形成完整槽结构
-> 非空槽时 P22 L1特征定义服务::尝试读取当前登记（返回并释放服务锁）
-> 海中鱼巣.领域.服务.L1特征定义集合读取
```

P25 模块固定 `export import 海中鱼巣.领域.服务.L1特征定义` 与 `export import 海中鱼巣.领域.服务.L1实例特征` 以使公开签名中的 P22/P24 类型可达，并私有 import L1 纯值合同；现有特征定义和实例特征模块都不得反向 import P25。纯函数不调用 P22、P17、P24、实例特征服务、L1 服务、仓库或 SQL，不存在 `this/登记_/锁_`。

不得给 P25 增加构造函数、对象状态、写入口、登记缓存、定义索引或按节点形状扫描定义的旁路。新模块只因现有依赖环无法原位承载而建立，不取得实例槽解释权或 L1 通用解析权。

## 5. 固定读取流程

### 5.1 上游分账与空定义集合

P17 非成功由调用方在形成 P24 前立即分账，P24/P22/P25 调用0。P17 成功后，调用方用该快照形成 P24，再按 P24 结果和实例槽总数分支。P24 非成功时 P22/P25 调用0；非空槽成功分支固定执行 P22：

- `许可拒绝/入口拒绝/登记未加载/资源失败/内部不一致` 立即返回，P25 调用0；
- 只在 `已读取 + 完整登记` 时调用 P25，并继续使用形成 P24 的同一份 P17 快照；

P25 校验外层合同、规则、读取规则和 P24 完整事实。P24 合同 / 规则 / 读取 / 排序版本必须匹配，`完整=true`、世界根有效、截止非零；主体槽组和槽必须保持 P24 的主体、定义、槽排序与唯一性，具名结构见证完整。

若 P24 的全部主体槽组合法且实例槽总数为0，P25 只要求传入快照头有效且 `快照.事实代次 == P24截止`，直接返回 `已读取`、空定义组、`完整=true`。该分支不要求登记定位载荷；没有定义引用就没有可遗漏的定义。调用方可以跳过新的 P22/P17 调用，直接复用形成 P24 时仍由调用方持有的同一份 P17 纯值快照；不得另造空快照或省略截止校准。

### 5.2 登记定位与同快照权威互证

非空定义引用时，`登记定位` 必须存在且满足 P22 冻结的完整性和四编码两两唯一；缺失返回登记未加载，非法返回入口拒绝。

固定校准：

```text
P24事实截止 == P17快照代次 != 0
P22登记.事实截止代次 <= P17快照代次
```

第一项不等返回事实代次漂移。登记首次验证代次不冒充当前截止。

在 P17 当前节点组按四编码确定查找：

- 服务身份是当前普通节点，属性类型表示为空，当前属性组为空；
- 定义标记、I64下界、I64上界三节点均为当前属性类型节点，表示精确为 I64，当前属性组为空；
- 四节点编码两两不同，创建事实代次全部精确等于 P22 登记事实截止代次；
- 四节点生命周期当前，创建代次不晚于快照截止。

四节点全未命中沿 P25 返回未找到；部分缺失、形状或代次矛盾属于内部不一致，不扫描其它节点替代。

### 5.3 精确形成被引用定义集合

从 P24 全部槽结构中读取 `特征定义.身份`，按稳定编码排序去重形成目标定义集合。去重只合并相同非零定义编码：同一定义被不同主体 / 槽引用合法；P24 已保证同一主体同定义仅一槽。

不得遍历普通节点召回“看起来像定义”的候选。P17 中未被 P24 引用的定义不进入输出，即使它合法且当前。

每个 P24 定义见证必须在 P17 当前节点组命中同编码普通节点，实际创建代次与 P24 见证一致；P24 同截止成功见证与快照矛盾为内部不一致。

### 5.4 每定义节点、属性槽和值

每个目标定义固定要求：

1. 定义节点为当前普通节点，属性类型表示为空；
2. `当前属性` 精确三项，属性类型分别为 P22 登记的定义标记、I64下界、I64上界；
3. 三个属性类型各恰一槽、当前值编码有效且三值编码两两不同；不得存在第四当前属性；
4. P17 当前值组中每个槽指向值恰一命中；值所属节点等于定义，属性类型与槽一致；
5. 三值来源均等于 P22 服务身份，材料均精确为 I64，退出代次为空；
6. 三值创建代次非零且不晚于快照截止；属性槽指向精确等于对应值编码；
7. 定义标记值精确为1，下界不大于上界。

缺槽、重复槽、额外槽、值缺失 / 重复、错误所属 / 类型 / 来源 / 材料、坏生命周期或上下界颠倒均为内部不一致，整个结果事实为空。

本叶只验证定义自己的三类属性，不读取实例槽的当前属性或值；不得用下界 / 上界判断任何实例值。

### 5.5 成功、排序与诊断

全部通过后：

- 特征定义详情按定义稳定编码严格升序，每个被 P24 引用的定义恰一项；
- 登记四节点见证放入固定具名字段，不依赖快照容器顺序；
- 三类值见证分别放入定义标记 / 下界 / 上界字段；
- 世界根复制 P24，事实截止等于 P17 快照代次；
- `完整=true`，缺项诊断为空。

内部不一致诊断按 `种类、特征定义身份、相关事实身份` 数值升序并确定去重。所有非成功事实为空；只有内部不一致允许非空诊断。不得返回已通过定义作为部分结果。

## 6. 并发、生命周期和状态边界

P25 纯函数只读两个 const 值，不取锁、不等待、不 sleep、不重试，不写缓存、SQL、日志、材料或 L1。多线程相同输入逐字段结果一致，不依赖地址、容器原顺序、显示名或时间戳。

P22 服务锁和 P17 L1 许可均在调用 P25 前释放。之后事实推进不改变本结果所代表的截止；后继由 G0/G1 与其它领域截止校准，P25 不自行重取。

状态分账：

| 条件 | P25 状态 | 事实 / 诊断 |
| --- | --- | --- |
| 外层或 P24 版本错、P24 非完整 | 入口拒绝 | 空 / 空 |
| 合法零槽 | 已读取 | 完整空定义组 / 空 |
| 非空引用但登记定位缺失 | 登记未加载 | 空 / 空 |
| 登记四节点全部确定未命中 | 未找到 | 空 / 空 |
| P24 与 P17 截止不同 | 事实代次漂移 | 空 / 空 |
| P22/P24 声称成功但快照矛盾 | 内部不一致 | 空 / 稳定诊断 |
| 分配失败 | 资源失败 | 空 / 空 |
| 其它异常 | 内部不一致 | 空 / 稳定诊断 |

许可拒绝只由 P22/P17 调用方立即映射；P25 函数调用0，不新增第二种许可状态。
