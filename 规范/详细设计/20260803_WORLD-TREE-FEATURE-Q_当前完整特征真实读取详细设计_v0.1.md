## 1. 目标、范围与完成边界

本设计把 WORLD-TREE-P1BF v0.4 预冻结的
`节点直接特征查询服务::读取宿主组完整当前特征` 从安全 `未实现` 原位替换为真实只读行为。
服务只调用一次 WORLD-TREE-P1A2G 已发布的
`节点直接结构查询服务::读取两级关系与目标当前类型化值`，在其单一非零事实截止内解释
关系类型 `特征实例角色(22)` 的角色1宿主槽、角色2定义模板、角色3当前值，并逐字段形成
P1BF v0.4 最终 `世界树特征事实`。

完成条件：合法宿主组返回全部当前实例槽、定义、当前值、原始类型化材料、来源和发布代次；
合法空宿主组、宿主零槽成功；业务不完整返回稳定缺项且零部分特征；公开 `noexcept` 边界
完整分类资源与其它异常；原顺序200自检身份原位扩充且顶层数量不变。

本设计不读取具名历史特征值，不读取或建立4170批次账，不写特征，不实现比较、状态动态、
世界树快照重试、生产装配或集成验收。

## 4. 请求准入和 P1A2G 请求形成

### 4.1 准入

进入任何分配和下层调用前，依次要求：

1. 查询合同版本、`请求.头.合同版本` 均等于各自正式版本；
2. `请求.头.世界规则版本 == 世界树规则版本`；
3. 世界根见证完整且节点类型为场景；
4. 每个宿主见证完整，类型只允许存在、场景、需求、任务或方法；
5. 宿主组内以稳定主键唯一；同主键第二项无论内容相同或不同均入口拒绝；
6. 世界根与某宿主同稳定主键时必须逐字段完全相同，否则入口拒绝；相同则在必须节点组只保留一份。

宿主组允许为空。服务复制宿主组后按节点稳定身份的命名域、键值、节点类型稳定值、身份版本排序。

### 4.2 唯一下层请求

```cpp
节点直接两级关系值投影请求 投影请求;
投影请求.合同版本 = 节点直接两级关系值投影合同版本;
投影请求.必须节点组 = 世界根与宿主组的规范化并集;
投影请求.根节点组 = 规范化宿主组;
投影请求.关系种类 = 关系类型::特征实例角色;
投影请求.第一跳角色 = 1;
投影请求.类型化值目标角色 = 3;
```

生产函数只允许一次成员调用：

```cpp
结构_.读取两级关系与目标当前类型化值(投影请求)
```

禁止调用 `读取当前节点`、单项关系/值读取、SQL、旧特征服务或第二次 P1A2G；禁止重试。

## 5. 关系22解释和业务完整性

P1A2G 成功后，先要求非零事实截止，且返回必须节点组逐字段等于第4节规范化并集。

### 5.1 角色1宿主槽

第一跳关系组的每项必须满足：

```text
类型 = 特征实例角色
角色或顺序 = 1
源端属于请求宿主组且逐字段相同
目标端类型 = 特征
```

目标端解释为实例槽。每个槽按稳定主键只能属于一个请求宿主；同身份异关系内容、槽出现两个宿主、
请求外宿主或端点方向错误均记 `世界树缺项种类::特征槽`。宿主没有角色1关系是合法零特征。

### 5.2 角色2定义模板和角色3当前值

对每个已发现槽，从 `中间节点相关关系组` 只解释以该槽为源的关系：

- 角色2必须恰一，目标类型为特征，解释为抽象定义；
- 角色3必须恰一，目标类型为特征值，解释为当前值；
- 该槽参与的角色1必须与第一跳唯一宿主关系逐字段相同；
- 角色1—3之外的关系22、槽作为角色2/3目标、端点类型错误或同一角色多项均为业务不完整。

角色2缺失/冲突记 `特征定义`；角色3缺失/冲突记 `特征当前值`；其它槽结构矛盾记 `特征槽`。

同一宿主与同一抽象定义稳定身份组合只能对应一个当前实例槽；出现两个不同槽记 `特征槽`。

### 5.3 角色3目标值投影

`目标值组` 必须与全部合法角色3关系按关系稳定主键一一对应，不得缺项或多项。每项：

1. `目标关系` 逐字段等于角色3关系；
2. `当前值组` 必须恰一项；零项或多项均记 `特征当前值`；
3. 值所属身份逐字段等于角色3目标，`当前=true`；
4. 合同身份/版本、值记录身份/版本、材料、前一版本和两个发布代次完整；
5. 首次发布代次与当前状态发布代次均不晚于 P1A2G 事实截止；
6. 来源联合必须是完整节点见证，节点类型为存在；服务身份来源在普通特征事实中不成立；
7. 同值记录稳定身份异内容或同合同键出现多个当前记录均为内部不一致。

P1A2G 的通用完整性不替代上述特征业务复核。

## 6. 字段来源和输出

成功时每个 `世界树特征事实` 逐字段形成：

| 字段 | 唯一来源 |
| --- | --- |
| `宿主` | 角色1源端当前节点见证 |
| `实例槽` | 角色1目标端 |
| `特征定义` | 角色2目标端 |
| `宿主关系` | 角色1完整关系见证 |
| `定义关系` | 角色2完整关系见证 |
| `当前值关系` | 角色3完整关系见证 |
| `当前值` | 角色3目标端 |
| `原始值类型合同身份/版本` | 角色3目标的唯一 `类型化值读回` |
| `原始值记录身份/版本` | 同一读回 |
| `前一原始值版本` | 同一读回的前一值记录版本 |
| `原始值` | 同一读回材料 |
| `来源存在` | 同一读回来源中的节点见证 |
| `首次发布代次/当前状态发布代次` | 同一读回 |

禁止从请求回显、关系第四角色、SQL、显示名称、时间戳、默认版本或容器位置补造字段。

特征组固定按以下三段键升序，当前值不参与排序键：

```text
宿主（命名域、键值、身份版本）
-> 特征定义（命名域、键值、身份版本）
-> 实例槽（命名域、键值、身份版本）
```

任一完整键出现同身份异内容为内部不一致，不以排序择一。

## 7. 缺项合同

宿主零槽不是缺项。发现槽后才适用定义、当前值和原始记录完整性。

缺项形成规则：

| 类别 | `对象` | `关系` |
| --- | --- | --- |
| 特征槽 | 可解析时为宿主或槽；否则空 | 直接导致矛盾的关系可用时填入 |
| 特征定义 | 实例槽 | 缺失时空；冲突时取稳定排序首个冲突关系 |
| 特征当前值 | 实例槽或当前值节点 | 角色3存在时填角色3；缺失时空 |

收集全部可判定缺项后，按 `种类 -> 对象稳定身份 -> 关系稳定身份` 排序并逐字段去重。没有对象/关系
排在对应有值项之前。只要缺项非空，结果固定为 `内部不一致`、P1A2G 非零事实截止、特征组空、
稳定缺项组；禁止同时返回部分特征。

同稳定身份异内容、未预期额外关系等无法准确称为“缺失”但可归到上述三类影响对象；缺项只是稳定
诊断，不改变内部不一致分类。

## 8. 状态、异常与并发

### 8.1 状态映射

| P1A2G/本层分支 | 读取状态 | 事实截止 | 特征组 | 缺项组 |
| --- | --- | --- | --- | --- |
| 成功且业务完整 | 已读取 | P1A2G非零代次 | 完整 | 空 |
| 未找到 | 未找到 | 原样 | 空 | 空 |
| 入口拒绝 | 入口拒绝 | 0 | 空 | 空 |
| 版本漂移 | 版本漂移 | P1A2G非零代次 | 空 | 空 |
| 许可拒绝 | 许可拒绝 | 0 | 空 | 空 |
| 资源失败 | 资源失败 | 0 | 空 | 空 |
| P1A2G内部不一致 | 内部不一致 | 0 | 空 | 空 |
| 业务缺项 | 内部不一致 | P1A2G非零代次 | 空 | 稳定缺项 |
| 未预期异常 | 内部不一致 | 0 | 空 | 空 |

`未实现` 永久保留但真实函数正常路径不再返回。消费者必须逐状态处理，禁止把未找到或内部不一致
映射为空成功。

### 8.2 `noexcept` 和异常

函数整体在 `try` 中完成准入、复制、索引、缺项、事实构造和排序。进入 try 前以固定空结果表达式
分别 `static_assert(noexcept(...资源失败...))` 与 `内部不一致`。

- 捕获 `std::bad_alloc`、`std::length_error`：资源失败、代次0、两组空；
- 捕获其它异常：内部不一致、代次0、两组空；
- 不在异常分支形成字符串、缺项或日志载荷；异常不得越过公开边界。

本服务不持 L1 许可；P1A2G 内部一次 try-lock 许可是唯一事实截止来源。许可拒绝立即返回，不等待、
不 sleep、不循环。服务只读且零机器事实变化。
