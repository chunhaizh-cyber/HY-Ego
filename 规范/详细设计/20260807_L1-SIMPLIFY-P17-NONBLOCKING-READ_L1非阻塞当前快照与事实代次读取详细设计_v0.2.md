## 3. P17 目标、接口和算法（其余 v0.1 合同不变）

P17 仍是 STEP-4 最早前置叶，只在唯一 L1 事实基座内提供：

```cpp
L1完整快照结果 L1事实基座服务::尝试读取完整快照(
    const L1完整快照读取请求& 请求) const;

L1事实代次读取结果 L1事实基座服务::尝试读取当前事实代次(
    const L1事实代次读取请求& 请求) const;
```

两个入口均只尝试一次 `std::try_to_lock` 共享许可；竞争立即返回 `许可拒绝`，不等待、sleep 或重试。快照和事实代次来自同一权威内存状态；快照投影复用唯一私有实现，四组事实按稳定编码排序；返回纯值，不泄漏仓库、锁、令牌、事务或会话。空 L1 的快照可成功返回代次0，代次入口返回 `未找到`；正常非零代次返回 `成功`；隔离/损坏返回 `内部不一致`；资源分配失败返回 `资源失败`。

P17 不解释世界、场景、存在、特征、状态、动态、关系19/20或完整世界快照；后继领域所有者分别消费本叶入口并自行完成同代次校准。本节之外的 DTO、状态顺序、投影、异常和验证合同逐字继承 v0.1 详细设计。
