# TARGET-GAP-REGISTERED-COMPARE-CONSUME 注册比较目标差距消费详细设计 v0.1

日期：2026-08-16
版本：v0.1

## 1. 目标、范围与完成边界

本叶为 BIZ-L3-004-01-02 v0.2 建立唯一目标差距收束服务。调用方提供非零比较请求身份和一份成功的 `需求目标当前事实结果`；服务以父结果中的同一 `G0`、目标合同、比较注册和当前 I64 值构造一次 `L2特征比较请求`，只调用一次 `L2特征结构服务::比较特征`，再把完整结构化比较结果裁决为已满足、存在可处理正差距、方向相反或约束冲突。

完成只表示这一枚 BIZ 只读比较叶已实现、验证并发布。它不读取目标材料、不创建需求 / 任务、不写世界或业务事实、不让普通应用持有本服务，也不证明 BIZ-L2-004-01、BIZ-L2-004-05、需求活动重判或系统治理闭环完成。

## 2. 正式依据与当前事实

- 0050：BIZ 只能经公开强类型服务消费 DATA；业务含义、目标满足与差距方向不进入 DATA。
- 3100、5100：目标合同是长期目标的唯一权威；确认差距不要求需求已经存在。
- 4160：材料缺失、类型不可比较和事实矛盾必须分账；当前叶只支持已冻结的 I64 目标判断材料。
- 4180：目标判断的左右角色固定为当前事实 / 目标状态，差异方向固定右减左；算法由当前注册选择，BIZ 不按类型临场分派。
- BIZ-L2-004-01 v0.1 明确要求差距方向、差距量、单位 / 维度 / 分量角色、比较注册、算法版本、误差量化与输入回执由完整 `L2特征比较结果`承载。
- `L2特征结构服务::比较特征(const L2特征比较请求&) const` 已正式实现并退出；它在请求 `差异材料` 时若 I64 右减左不可表示，返回 `入口拒绝 + 差异不可表示`，不会只返回已算出的具名关系。
- `TARGET-CURRENT-FACTS-COMPOSE v0.1` 已冻结父 DTO / provider 合同并登记待激活；其两个 L4 前驱和父函数尚未实现。

## 3. 物理归属与依赖

新建：

```text
海中鱼巣/领域/目标差距比较.数据.h
  -> 目标差距比较合同 / 规则版本、状态、请求、结果和纯值 helper

海中鱼巣/领域/服务.特征判断收束.ixx
  -> 导出 特征判断收束服务
  -> 只持 const L2特征结构服务&
  -> 实现一个 const noexcept 目标差距裁决成员
```

数据头用自己的 `TARGET_GAP_COMPARE_NO_INCLUDES` 宏保护依赖包含；普通头模式直接包含 `<cstdint>`、`<optional>`、`需求目标事实.数据.h`和 `L2特征结构.数据.h`，不依赖传递包含。模块全局片段只包含标准库并定义该宏，随后 `export module 海中鱼巣.领域.服务.特征判断收束;`，`export import 海中鱼巣.领域.提供者.需求目标事实;`与 `export import 海中鱼巣.领域.服务.L2特征结构;`，最后在 `export {}` 中包含自己的数据头；不得反向 import `服务.需求`、普通应用或聚合模块。

工程在 `海中鱼巣.vcxproj` 与 `.filters` 各登记一次。合法消费者经普通应用现有 `L2结构聚合服务` const getter取得同实例 `L2特征结构服务`并构造本服务；本计划不修改普通应用，也不新增专用 getter。

依赖固定为：

```text
特征判断收束服务::按注册比较合同裁决目标差距
-> L2特征结构服务::比较特征
-> DATA 内部按同一 G0 读取当前唯一目标判断比较注册
```

不得新建 BIZ 注册读取、算法表、第二特征服务、缓存或 DATA 适配壳。

## 4. DTO 与公开 ABI

```cpp
inline constexpr std::uint32_t 目标差距比较合同版本 = 1;
inline constexpr std::uint32_t 目标差距比较规则版本 = 1;

enum class 目标差距比较状态 : std::uint8_t {
    已满足 = 1,
    存在可处理正差距 = 2,
    方向相反 = 3,
    约束冲突 = 4,
    不可比较 = 5,
    算法未登记 = 6,
    版本漂移 = 7,
    入口拒绝 = 8,
    许可拒绝 = 9,
    资源失败 = 10,
    未实现 = 11,
    内部不一致 = 12
};

struct 目标差距比较请求 final {
    std::uint32_t 合同版本 = 目标差距比较合同版本;
    std::uint32_t 规则版本 = 目标差距比较规则版本;
    std::uint64_t 比较请求身份 = 0;
    需求目标当前事实结果 目标当前事实;
};

struct 目标差距比较结果 final {
    目标差距比较状态 状态 = 目标差距比较状态::入口拒绝;
    std::uint32_t 合同版本 = 目标差距比较合同版本;
    std::uint32_t 规则版本 = 目标差距比较规则版本;
    std::uint64_t 比较请求身份 = 0;
    std::uint64_t 事实截止代次 = 0;
    std::optional<L2特征比较结果> 比较证据;
    bool 已形成业务裁决() const noexcept;
};

class 特征判断收束服务 final {
public:
    explicit 特征判断收束服务(const L2特征结构服务& 特征服务) noexcept;
    目标差距比较结果 按注册比较合同裁决目标差距(
        const 目标差距比较请求& 请求) const noexcept;
};
```

请求 helper 要求两个版本为当前值、比较请求身份非零、父结果 `成功()`、父结果和材料截止为同一非零 `G0`，两份子材料完整且逐字段闭合。父入口拒绝发生在 DATA 调用前，比较证据为空。

`已形成业务裁决()`只接受前四个业务状态、当前版本、非零请求身份 / G0、存在且 `成功()`的完整 `L2特征比较结果`，并要求其请求身份和截止精确回显。其它状态不冒充业务裁决；DATA 调用后的非成功仍保留原始比较结果供诊断。

## 5. 唯一 L2 请求构造

请求头固定为 `{L2结构合同版本, G0}`，请求身份直接使用 BIZ 的非零比较请求身份，特征定义、算法族和算法版本只来自父材料中的正式注册。

左输入：

```text
事实身份 = 当前值.值稳定编码
类型化不可变材料 = 当前值.类型化不可变材料
来源稳定编码 = 当前值.来源稳定编码
输入版本 = 当前值.生命周期.创建事实代次
生命周期 = 当前值.生命周期
原始类型 = I64
单位 / 维度 / 分量角色 = 注册合同
角色 = 当前事实
```

右输入：

```text
事实身份 = 目标合同.目标值稳定编码
类型化不可变材料 = int64_t{目标合同.目标I64}
来源稳定编码 = 目标合同.来源稳定编码
输入版本 = 目标合同.生命周期.创建事实代次
生命周期 = 目标合同.生命周期
原始类型 = I64
单位 / 维度 / 分量角色 = 注册合同
角色 = 目标状态
```

用途固定为目标判断，预期算法族 / 版本精确来自注册合同，`要求结果位`固定为 `具名关系 | 差异材料 = 6`。不得请求排序三态，不得把调用方参数、特征类型或函数名当作算法选择依据。

## 6. 成功互证与业务裁决

`L2特征比较结果`只在下列条件全部成立时进入业务裁决：

```text
状态=已比较、拒绝原因=无、成功谓词成立
请求身份=原比较请求身份、事实截止代次=G0
注册身份=目标合同引用且等于父材料注册身份
算法版本=父材料注册版本
实际结果位=6
排序三态为空、具名关系和差异材料存在
实际单位 / 维度 / 分量角色、左右角色、方向、误差、容差、边界、量化和误差合同版本与注册相同
左右输入回执逐字段等于请求的事实身份、来源、输入版本和创建事实代次
差异材料的原始类型、单位、维度、分量角色、右减左方向和算法版本与注册相同
```

具名关系到允许关系位固定映射：当前低于目标 `1`，当前达到目标 `2`，当前高于目标 `4`。先把具名关系映射为一位，再与目标合同 `允许关系位`相交：

| 关系与允许位 | BIZ 状态 |
| --- | --- |
| 当前关系位命中允许位 | 已满足 |
| 当前低于目标且未命中 | 存在可处理正差距 |
| 当前高于目标且未命中 | 方向相反 |
| 当前达到目标、只允许高于 | 存在可处理正差距 |
| 当前达到目标、只允许低于 | 方向相反 |
| 当前达到目标、同时允许低于和高于但不允许达到 | 约束冲突 |

完整 DATA 比较结果原样进入 BIZ 结果。BIZ 不重算差值、不从差值符号覆盖具名关系，也不建立简化比较证据。

## 7. 非成功映射、异常与并发

| DATA 状态 / 原因 | BIZ 状态 |
| --- | --- |
| 未注册 | 算法未登记 |
| 版本漂移 | 版本漂移 |
| 许可拒绝 | 许可拒绝 |
| 资源失败 | 资源失败 |
| 未实现 | 未实现 |
| 内部不一致 | 内部不一致 |
| 入口拒绝 + 差异不可表示 / 距离不可表示 / 值域不允许 / 样本不足 / 误差合同不成立 / 要求结果组合不支持 | 不可比较 |
| 入口拒绝 + 请求版本 / 身份、输入版本、原始类型、单位、维度、左右角色、坐标或时间基准冲突 | 内部不一致 |
| 未知枚举、坏成功形状、错请求回显、错 G0、错注册或错输入回执 | 内部不一致 |

每次调用只使用局部值式材料，零锁、零等待、零重试、零缓存、零截止重选、零事实写入。DATA 方法不是 `noexcept`，本服务捕获 `std::bad_alloc`、`std::length_error`为资源失败，其它异常为内部不一致；异常发生在 DATA 调用期间且没有完整结果时，比较证据为空。

并发推进注册或输入生命周期时只能得到完整同 `G0` 比较结果、版本漂移或结构化非成功，不能用新截止重读或拼接另一结果。
