# L1-SIMPLIFY-P1-WORLD-STRUCTURE 初始场景写读闭环详细设计 v0.3

创建侧代码基线：`e7592cc08c43e5147ad5a24e655b0eb6a16e749b`。

## 1. 目标与完成边界

本叶是 `L1-SIMPLIFY-P1B-WORLD-REGISTRY v0.1` 之后最小可独立实施的 L1 领域消费者：在隔离的 `L1事实基座服务` 与已加载的 `世界登记服务` 上，由新 `L1场景结构服务` 在一个写集中建立唯一首个子场景，并通过 L1 的独立节点、属性、值和关系读取入口重新取得权威当前事实。

本叶只闭合“世界根 -> 初始场景”的直接结构事实。它不创建存在，不接入运行期，不恢复登记或场景，不读取 SQL / 材料，不形成状态、动态、动作消息或业务功能，不迁移或删除旧场景入口。动作完成消息、预计动作动态及其事实校准仍按目标业务流程确认链另行冻结，不在本叶预造。

完成条件：首次请求产生一笔“三个新编码”的原子写集；成功结果只来自提交后的独立读取；同键同义不推进事实代次，同键异义、错误登记、错误根、非初始基线和新键代次漂移均零新增事实。

## 2. 正式依据与当前事实

- 4015：L1 只有节点、关系和值三类事实；写集由 L1 分配稳定编码，同键同义精确读回，同键异义冲突。
- 4190：场景树单根、单父、无环；世界组合服务不拥有 L1 写权。
- 4200：场景结构关系的唯一业务写入方为新 L1 场景业务服务；父场景到子场景使用登记中的直接父场景关系类型、方向 `父 -> 子`、顺序 `0`；世界根 / 初始场景资格来源固定为世界结构服务。
- P1B 正式结果 `e7592cc0`：`世界登记服务` 公开 `建立空世界` 与 `读取当前登记`；登记含服务身份、场景标记属性类型、直接父场景关系类型、直接成员关系类型、世界根和已验证事实代次。P1B 建立后的精确 L1 形状为五节点、一值、一属性槽、零关系、六个永久编码；属性类型节点自身必须无属性。

旧 `领域/服务.场景.ixx` 仍属于旧基座，不能扩展为新 L1 写入方。为避免同名类型和旧依赖渗入，本叶新建 `L1场景结构服务`；后继迁移完成前两者不得互调。

## 5. 创建事务

### 5.1 写前准入

1. 校验合同版本、世界规则版本、非零幂等键、非零期望代次；请求世界根必须是 `普通`。
2. 调用 `世界登记_.读取当前登记()`；只接受 `已读取 + 完整登记`。请求规则和世界根必须分别等于登记规则与登记世界根。
3. 调用 `L1_.读取完整快照()`。读取失败按第 7 节映射。若快照代次等于请求期望代次，则它必须精确匹配 P1B 已验证基线：登记的五节点类型、根标记 I64 值 / 槽 / 来源完整，零关系，五节点一值六编码均当前且互异；否则返回 `入口拒绝`，不提交。
4. 若快照代次不等于请求期望代次，不在服务层猜测“已执行”或改写请求；仍形成同一确定性写集交给 L1。只有 L1 账中同键同写集可返回精确重复，其它请求由 L1 返回版本漂移或幂等冲突。

### 5.2 唯一写集

本地键固定：

| 键 | 项目 | 内容 |
| --- | --- | --- |
| 1 | 节点 | 初始场景，`普通`，无属性类型表示 |
| 2 | 值 | 所属节点=本地1；属性类型=登记场景标记属性类型；材料=`I64{1}`；来源=登记服务身份 |
| 3 | 关系 | 源=登记世界根；目标=本地1；类型=登记直接父场景关系类型；顺序=`0` |
| — | 属性槽变更 | 本地1的场景标记属性槽指向本地2 |

写集不含其它节点、关系、值或退出事实。`期望事实代次` 与 `幂等键` 逐字取请求。调用一次 `L1_.提交写集`，不得换键、重算身份、第二次写入或回滚已发布事实。

### 5.3 权威读回

L1 返回成功或精确重复后，按本地键解析且只接受三项互异非零编码。随后形成 `初始场景读取请求`，通过与写入返回分离的读取路径依次读取：世界根节点、初始场景节点、场景标记属性类型节点、服务身份节点、场景标记属性、标记值、直接父关系和直接父关系类型节点。

每项必须成功、事实副本类型正确，且全部 `读取事实代次` 相等且非零；节点、值、关系的字段必须与第 5.2 节完全一致，均为当前且创建代次不晚于事实截止。首次 `成功` 的读回代次必须严格等于写入结果代次；`精确重复` 允许在更晚的同次完整当前读取中返回事实。任一代次不同返回 `版本漂移`，任一字段矛盾返回 `内部不一致`，不得返回部分事实。

`创建初始场景` 只把独立读回所得事实装入结果：L1 成功映射 `已提交`，精确重复映射 `幂等读回`。动作自身的编码映射与预计状态不能直接成为成功事实。

## 6. 独立读取

`读取初始场景` 校验合同、规则、世界根和三个目标编码，并重新读取登记；请求世界根必须等于登记根。它只执行第 5.3 节读取，不读取服务缓存、不扫描关系组、不按名称或固定编码寻找目标。合法且完整返回 `已读取 + 事实`；任一目标不存在返回 `未找到`，已退出 / 错类型 / 字段矛盾返回 `内部不一致`，多次读取代次不等返回 `版本漂移`。

这个入口是创建返回之外的权威确认途径。它不把动作完成消息、日志、自检结果或写入返回的预计状态当成当前事实。

## 7. 状态映射与异常

| 来源 | 世界结构状态 |
| --- | --- |
| L1 写入成功 / 精确重复 | 完整读回后分别为 `已提交` / `幂等读回` |
| L1 幂等冲突 | `幂等冲突` |
| L1 事实代次漂移 | `版本漂移` |
| L1 入口拒绝、登记未加载、请求错误 | `入口拒绝` |
| L1 读取未找到 | `未找到`（只用于公开读入口） |
| L1 资源失败或 `std::bad_alloc` | `资源失败` |
| L1 内部不一致、类型/字段/映射矛盾或未知异常 | `内部不一致` |

本叶没有可见 L1 许可，因此不产生 `许可拒绝`，但保留 4200 的稳定编号。发布前失败必须零新增事实；发布后读回失败保留 L1 已发布事实并返回结构化非成功，不做补写。
