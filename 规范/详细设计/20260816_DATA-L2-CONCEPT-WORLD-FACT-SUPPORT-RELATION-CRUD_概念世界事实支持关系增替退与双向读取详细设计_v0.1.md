# DATA-L2 概念世界事实支持关系增替退与双向读取详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-CONCEPT-WORLD-FACT-SUPPORT-RELATION-CRUD`

状态：设计就绪

## 1. 目标与完成边界

在唯一 `L2概念结构服务` 内，为 `DATA-EXT-08` 增加世界事实支持关系的完整中性结构 CRUD：

```text
新增世界事实支持关系
+ 原子替换一条世界事实支持关系
+ 退出一条世界事实支持关系
+ 按概念读取直接支持世界事实组
+ 按世界事实读取所支持概念组
```

领域方向固定为 `世界事实 -> 概念`。同一世界事实与同一概念至多一条当前支持关系；关系允许多对多和跨本体根。服务只校验世界事实、概念、建立依据、发布证据、生命周期、幂等和共同事实截止，不判断该事实是否真的支持该概念。

本叶复用现有概念 owner、概念写锁、完整普通概念构造依赖、`L2概念结构服务` 和概念聚合 getter。它不建立第二 owner、第二 C1、通用关系服务、世界事实副本、支持正确性判断、概念树权威或非权威缓存。

定义约束独立 CRUD 仍保留具名 `DRIFT-DATA-L2-CONCEPT-DEFINITION-ROLE-CARDINALITY-AND-SIGNATURE-CLOSURE`；本叶不修改定义项或抽象签名，也不依赖该裁决。

## 2. 正式依据与当前事实

正式依据：0050 v1.3、2220 v1.5、4030 v1.9、4040 v1.5、4050 v1.4、4190 v0.6、4240 v0.6、7140 v1.2，以及已经退出的普通概念 DTO、普通概念服务和直接上下位关系 CRUD 三叶。

当前事实：

1. `L2概念定义目标` 已闭合编码概念、场景、存在、特征定义 / 实例 / 值、状态、动态、因果和十三类世界关系；支持关系尚无公开 DTO 和生产结构。
2. 2220 的上级合同要求支持源是世界树中的具体实例或事实，不能是概念；因此 `L2世界事实引用` 复用现有闭合编码规则但排除 `L2概念身份` 分支。概念之间的联系继续使用定义或其它具名概念关系。
3. 普通概念完整构造已经借入不可变材料、场景、存在、特征、状态、动态和因果七份只读服务，并已实现全部世界引用的同截止强类型读回；本叶抽取并复用该私有验证逻辑，不增加世界服务反向依赖。
4. L1 owner 写集允许同事务新增 / 退出节点、关系和值，并保留历史；owner 历史关系组可从具名内部登记根枚举指定截止的支持事实项。
5. 现有普通概念内部登记幂等身份和首次写集不可改写。本叶使用新的内部登记幂等身份扩展支持结构，不修改 `概念身份来源登记幂等身份`、`概念本体结构登记幂等身份` 或 `普通概念结构登记幂等身份` 的既有规范化写集。

## 5. 同截止端点与材料验证

写前和成功读回均在一个非零 `G0/H` 验证：

1. 世界事实通过对应场景、存在、特征、状态、动态或因果公开服务完整读回；关系和值引用还须逐字段命中公开关系 / 值稳定编码和端点。
2. 当前读 / 写要求世界事实及其必需端点在 `G0` 当前；历史读要求它们在 `H` 存在且生命周期覆盖 `H`。
3. 概念目标可以是四个永久根或完整普通概念；当前写要求目标在 `G0` 当前。历史读允许关系在 `H` 指向当时存在的概念。
4. 建立依据和全部发布证据经不可变材料服务在同一截止完整读回。材料缺失 / 已退出沿公开状态返回；坏成功形状返回 `内部不一致`。
5. 世界引用不复制世界节点、关系、值或材料内容。数据层不从来源类型、本体根或证据内容推断支持是否正确。

定义目标现有私有校验拆为“单个闭合引用同截止校验”，普通概念定义读回和本叶世界事实读回共同调用；概念分支只允许定义关系使用，世界事实 helper 从类型上排除该分支。

## 6. owner 内部结构与恢复兼容

使用新的固定内部登记身份：

```cpp
inline constexpr L1所有者范围写入幂等身份
    概念世界事实支持结构登记幂等身份{0x4C32'434F'5247'0003ULL};
```

它只在完整构造中建立支持结构定位，不改写前三份登记写集。登记写集固定建立：

| 内部事实 | 用途 |
| --- | --- |
| 支持登记根节点 | 枚举当前 / 历史支持事实项；不是概念、世界事实或公开根 |
| 支持登记成员关系类型 | `登记根 -> 支持事实项` 的同事务权威登记 |
| 世界事实支持关系类型 | `支持事实项 -> 概念`，其稳定编码作为公开关系编码 |
| 世界事实引用编码属性类型 | 保存闭合世界事实引用编码 |
| 建立依据材料属性类型 | 保存一项不可变材料身份 |
| 发布证据材料组属性类型 | 保存严格升序的非空材料身份组 |

每条支持事实使用概念 owner 新建一项内部普通节点。新增同一写集包含：支持事实节点、登记成员关系、支持事实到概念关系、三个属性值和三个属性槽。领域方向由强类型负载固定为 `世界事实 -> 概念`；内部节点只解决世界关系 / 特征值等非节点事实不能直接作为 L1 关系端点的问题，不取得第二事实来源。

替换在同一写集退出旧支持事实节点、登记关系、支持关系、三个旧值，并建立一份完整新支持事实；退出关闭上述全部当前事实。历史事实继续可查。禁止只退出公开关系而遗留当前内部节点或属性。

## 7. 双向当前 / 历史读取与预算

按概念读取以概念作为支持关系目标端点读取；按世界事实读取从支持登记根枚举指定截止的支持事实项，再按规范化世界引用编码筛选。两条路径最终都必须重建完整支持事实并验证内部登记关系、支持关系、三个属性值、材料与端点来自同一截止。

按世界事实读取在取得登记成员组后、逐项展开前执行请求预算校验；L1 返回的成员数超过 `扫描预算` 时立即返回 `数量预算不足`、空组、零变更，不继续逐项世界 / 概念 / 材料读回。任一结果超过 `数量预算` 同样拒绝。按概念读取只需结果数量预算。现行 L1 闭包入口没有读前数量参数，本叶不得假称底层提前截断；该入口只保证 L2 在取得组后立即停止展开和后继依赖读取。

成功组按以下键严格升序：

```text
规范化世界事实引用编码
-> 概念编码
-> 关系稳定编码
```

当前成功只返回未退出关系；历史成功返回在 `H` 有效的关系投影。空组合法，表示该概念当前 / 当时没有直接支持事实，或该世界事实当前 / 当时不支持任何概念。

## 8. 写前唯一性、替换和幂等

全部写入口先取得现有概念写锁，再在请求 `G0` 完整读取当前支持登记：

1. 现状中每个内部支持节点恰有一条登记关系、一条到概念关系和三个当前属性；缺项、复义、混代或孤儿项为 `内部不一致`。
2. 新增若 `(规范化世界事实引用, 概念)` 已有当前关系返回 `引用冲突`。
3. 替换 / 退出必须由公开关系稳定编码、旧世界事实和概念三者精确命中同一当前关系；只命中部分返回 `引用冲突`，全未命中返回 `未找到`。
4. 替换保持概念端点不变，允许更换世界事实、建立依据或发布证据；候选新 `(世界事实, 概念)` 不得与排除旧项后的其它当前关系重复。
5. 退出支持关系不得退出或修改世界事实、概念、材料、定义、上下位或生命周期。

调用方幂等身份直接映射到概念 owner 写幂等身份。提交前读取首次写入材料：同规范化写集精确重复，异写集幂等冲突，未找到才提交。首次成功与精确重复都按首次结果截止历史重建旧 / 新支持事实；发布未知、资源失败或发布后读回失败保留原完整请求和原幂等身份重放。

## 9. 成功形状与错误映射

写成功只允许 `已提交` / `精确重复`，非零截止、非空变更代次且二者相等：

| 操作 | `当前关系` | `已退出关系` |
| --- | --- | --- |
| 新增 | 新关系，截止当前 | 空 |
| 替换 | 新关系，截止当前 | 旧关系，退出代次等于截止 |
| 退出 | 空 | 旧关系，退出代次等于截止 |

任一非成功的两个 optional 为空、变更代次为空。组读成功只允许 `已读取`、非零共同截止、零变更；非成功关系组为空。

| 条件 | `L2结构状态` |
| --- | --- |
| 无效请求、概念作为世界事实、根专用实例调用 | `入口拒绝` / `未实现` |
| 世界事实、概念、材料或旧关系未找到 | `未找到` |
| 端点或材料在目标截止已退出 | `已退出` |
| 非零守卫不再当前 | `事实代次漂移` |
| 同幂等身份异写集 | `幂等冲突` |
| 重复当前支持、旧关系部分命中 | `引用冲突` |
| 扫描或结果超过预算 | `数量预算不足` |
| L1 或公开依赖资源失败 | `资源失败` |
| 坏成功形状、内部登记缺项 / 孤儿 / 复义或混代 | `内部不一致` |
