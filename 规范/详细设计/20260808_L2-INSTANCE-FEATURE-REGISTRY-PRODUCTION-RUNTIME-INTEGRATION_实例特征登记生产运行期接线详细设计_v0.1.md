# 实例特征登记生产运行期接线详细设计 v0.1

日期：2026-08-08

状态：设计就绪；只冻结后续实施合同，不证明代码、生产运行或第一层完善。

## 1. 目标与最早缺口

当前 `L1实例特征服务` 已由唯一生产运行期上下文构造并拥有，具备四节点结构登记、实际存在 I64 实例特征发布、当前值换代和公开当前读回。生产启动已经建立特征定义结构登记，但仍未建立实例特征结构登记。没有本登记，后继不能合法创建任何实例槽或首个状态。

本叶只闭合最早独立缺口：

```text
复用运行期上下文现有 L1实例特征服务
-> 在特征定义结构登记成功后建立实例特征结构登记
-> 经同一第二层公开服务权威读回登记
-> 把登记完整性纳入候选上下文发布条件
-> 发布后的运行期租约继续暴露同一服务
```

本叶不创建具体特征定义、实例槽、实例值或状态；因此不会为了证明第一层制造业务数据。

## 2. 正式依据与当前事实

- 1120：特征定义节点和实例槽位必须由结构角色区分；实例槽位必须具有唯一宿主和唯一特征定义。
- 4015：第一层只承担业务中性 CRUD、原子提交和最小幂等；能力只由下游真实使用自然累计。
- 4030：领域服务拥有业务准入、结构、不变量和结构化结果，不得为补齐第一层矩阵制造请求。
- 4050：入口拒绝、逻辑内结果和内部不一致必须结构化分账，不能由日志或退出码替代。
- 8120、ACCEPTANCE-01：生产入口不承载自检或验收运行器；生产初始化可保留保证自身后置条件所需的写后读回。

当前代码事实：

1. `运行期上下文` 已唯一拥有 `L1实例特征服务_`，其构造复用同一第一层服务、场景结构服务、特征定义服务和实际存在场景组合服务，并已有 const / 非 const 服务访问器。
2. `L1实例特征服务::建立登记` 已固定形成一个普通服务节点、两个普通关系类型节点和一个 I64 属性类型节点，以一次中性写集原子提交并精确读回。
3. `读取当前登记` 已返回值式 `实例特征登记结果`，并在同一当前事实代次逐字段核对四节点。
4. 生产启动已经按世界、场景、实际存在、状态、动态和特征定义登记顺序执行，但没有实例特征登记请求、结果回显或候选完整性读回。
5. 具体特征定义和实际存在 I64 实例特征都需要真实业务输入；本结构登记不需要这些输入，且是后继实例能力的必要生产前置。
6. 当前计划索引没有可执行项；三个生产文件已释放，异主修复、路线、旧世界树与 `.codex-build` 不重叠。

## 4. 运行期上下文合同

### 4.1 新增窄入口

在现有特征定义登记入口之后新增：

```cpp
实例特征登记结果 初始化实例特征登记(const 实例特征登记请求& 请求);
实例特征登记结果 读取实例特征登记() const;
bool 实例特征登记完整() const;
```

规则：

- 初始化入口只核对结构核心和 `实例特征登记请求有效`，然后恰一次委托现有 `建立登记`；
- 读取入口恰一次委托现有 `读取当前登记`；
- 完整判断只接受 `已读取 + 非空完整登记`；
- 不新增服务成员、代理、缓存、第二登记定位或第二业务解释者。

### 4.2 候选完整性

`运行期上下文::完整()` 增加一次实例特征登记当前读回。发布候选必须同时满足：

- 实例特征登记结果为 `已读取`；
- 登记非空且通过 `实例特征结构登记完整`；
- 实例特征登记事实截止与特征定义登记及此前世界、场景、实际存在、状态和动态材料的当前共同截止完全相同。

该检查只核对生产候选中的当前权威结构登记，不证明已有具体特征定义或实例槽。

## 5. 固定生产配置

`生产运行期配置` 新增：

```cpp
特征操作幂等身份 实例特征登记幂等身份;
```

固定值为 `{1}`。该身份进入实例特征服务自己的登记幂等域，与特征定义登记的同值身份属于不同正式域，不形成同键冲突。配置形成、全等和有效性同步核对该字段。

配置头在未由模块导入实例特征数据时包含 `领域/L1实例特征.数据.h`；生产运行期模块使用显式宏边界避免重复声明。

不增加命令行覆盖、环境变量、配置文件、随机身份或运行时补造。

## 6. 生产启动流程

在特征定义结构登记成功后、系统角色初始化前形成：

```cpp
const 实例特征登记请求 实例特征登记请求值{
    L1实例特征合同版本,
    L1实例特征规则版本,
    配置.实例特征登记幂等身份,
    特征定义登记结果值.登记->事实截止代次};
```

然后恰一次调用：

```cpp
候选->初始化实例特征登记(实例特征登记请求值)
```

成功只接受 `已提交` 或 `幂等读回`，且结果必须携带完整登记。其它结果立即返回新增的 `实例特征登记初始化错误`，不继续系统角色、概念活动或候选发布。

`生产运行期启动结果` 增加实例特征登记业务状态。已有当前上下文回显 `已读取`；早期失败保持入口拒绝；执行后的分支回显真实领域状态。

## 7. 事务、幂等和失败边界

- 四节点仍由现有实例特征服务的一次中性写集原子提交；本叶不修改事务。
- 同一固定请求按现有完整写集幂等合同收敛；不增加第二账、摘要、业务标签或重试循环。
- 实例特征登记失败时候选不发布；此前局部候选随生命周期销毁，不增加撤销或恢复协议。
- 启动层只映射具名初始化错误并保留实例特征结构化状态。
- 当前阶段不处理崩溃、重启、断电或跨进程恢复。
