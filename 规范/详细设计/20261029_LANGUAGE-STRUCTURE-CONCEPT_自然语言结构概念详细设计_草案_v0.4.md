## 1. 目标（相对 v0.3）

落地用户已批准的六条：

1. `E需要H` 只带核心 `H`；紧急度/期限等 → 可选**修饰槽**（有值才展开）。
2. 增补任务陈述种子：`T进行到…了`、`T失败了`、`T取消了`；其填项问/是非问**规则派生**。
3. `SC-请求执行方法` 参数尾**跟随 Vm 规格**（无固定上限）。
4. `请用M` = 该结构概念的**同义模式**（参数从语境补；不另注册结构概念）。
5. **S13** ∈ **信息请求**（特征值/需求的指令行）；**请求执行方法**仅动作请求；对应表分行。
6. 理解未登记量词：匹配 `数+未知量词+名` → 量词**缺口** + **样例**入学。

推迟：对应表 DTO；非汉语形态闭集。

## 2. 布局与对应表

同 v0.3（结构概念 / 模式自有槽位+映射 / 语法 / 对应表四查询 / `新_语言类` 幂等重建）。

对应表须能区分：

```text
种类=特征值, 细目=指令, 结构概念=SC-特征值-信息请求  → S13
种类=方法,   细目=指令, 结构概念=SC-请求执行方法     → 请+V+… / 请用M
```

## 3. 需求修饰槽

```text
核心含义角色：E1, H1
修饰角色（可选）：紧急度?, 期限?, …（正式需求投影有值才绑定）
汉语模式：E1+需要+H1 + 〔修饰段〕*
生成：无值修饰 → 省略该项；禁止输出占位空话
```

## 4. 请求执行方法

```text
含义角色：M1 + P_1…P_n（n = 候选方法 Vm 参数规格长度；动态尾）
模式1：请+V+（按 Vm 序的槽）
模式2（同义）：请+用+M1   // 无额外参数槽；P_i 从语境/筹办补全，补不全→待绑定
理解：查询候选方法；零/多候选按既有策略；交 5260；C→R 只读预期结果
```

## 5. 任务状态种子与派生

**显式种子（陈述）**

| ID | 模式 |
| --- | --- |
| SC-任务-进度陈述 | T1+进行到+PROG1+了 |
| SC-任务-失败陈述 | T1+失败+了 |
| SC-任务-取消陈述 | T1+取消+了 |

另保留 v0.3：进行/目的/完成陈述、状态填项问、完成是非问、任务指令。

**派生规则 R-ASK**（对进度/失败/取消陈述骨架）：

- 填项问：将进度值等换查询变量，或「…到哪里了」类登记模式；
- 是非问：陈述骨架 + `吗`（及体标记保留）。

派生后写入对应表状态=已登记，来源=规则派生；不重复人工种子文件条目。

## 6. 量词理解

```text
匹配：数词槽 + 词面W + 名词槽
若 W ∈ {个,位,名,件,项,次} → 正常 H-AGR-02
否则 → 建立/取得量词缺口(W)；保存本句样例到学习材料；
      句内其它已匹配结构仍可形成部分理解
生成：未知搭配 → 回退「个」并回显
```
