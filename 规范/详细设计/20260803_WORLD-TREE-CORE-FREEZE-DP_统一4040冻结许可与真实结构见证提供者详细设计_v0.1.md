# WORLD-TREE-CORE-FREEZE-DP 统一4040冻结许可与真实结构见证提供者详细设计 v0.1

创建侧正式基线：`1d7667118f63b4c3be15571c7214c2efb577b6d0`

状态：F0安全骨架设计完成；R1真实实现待正式语义裁决。

## 1. 目标

本包只为FEATURE-W-DP及后继统一冻结协调方提供：

```text
最终统一冻结许可ABI
真实冻结见证值式ABI
事务域所属/错域校验ABI
已发布代次见证位
类型化值仓真实结构版本、数量和全量已发布副本ABI
```

它不冻结节点、关系、索引、领域批次仓、SQL、日志、外设或全进程；不建立第二类型化值权威，不增加无类型值仓。

## 2. 当前事实与不足裁决

当前正式代码：

- `节点直接身份结构读取许可` 已用事务域 `shared_mutex` 的try共享锁阻止同域独占写，并只公开已发布代次。
- `节点直接身份结构事务域` 没有运行期域身份、统一冻结规则版本或所属域校验。
- `节点直接类型化值仓库` 有独立 `shared_mutex` 和 `导出权威状态()`，能复制全部已发布记录，但没有真实结构版本和记录数量合同。
- `完成发布()` 可在同一4040事务中逐候选调用；恢复安装另走 `完成发布恢复候选()`。

4040只规定发布线性化、许可边界和锁序应由实现合同冻结；4170要求真实运行期域身份、同一冻结见证及两仓真实结构版本。现行正式规范没有唯一裁决：

1. 运行期域身份由何种权威材料签发、是否跨进程/恢复保持、签发失败如何收口；
2. 类型化值仓结构版本按候选、按事务还是按4040代次推进；
3. 恢复安装时结构版本是恢复、重新起算还是与来源见证建立映射；
4. 版本溢出应在候选前拒绝、隔离还是停止后继。

因此本包不选择随机数、地址、静态计数器、安装实例身份、最大记录版本或4040代次冒充答案。先以F0建立最终ABI和固定未实现骨架；R1需在正式裁决后原位实现。

## 5. 锁序与许可生命周期

R1最终锁序固定为：

```text
事务域统一冻结许可持有的4040共享冻结边界
-> 节点直接类型化值仓库共享锁
-> FEATURE-W-DP本域批次记录仓共享锁
```

许可由统一协调方栈对象拥有，move后源对象无效；析构无异常释放共享冻结边界。许可不保存上层回调、仓指针、SQL端口或业务DTO；上层不能取得锁守卫、互斥、原子指针或可写事务许可。持有许可期间不得做I/O、日志、等待或反向取得同事务域独占许可。

`复制全部已发布记录`只在调用期间借用许可，不保存引用。FEATURE-W-DP先调用 `事务域.冻结许可属于本域(许可)`，通过后才调用访问器；访问器再次要求许可有效并复制其见证，但不自行签发第二许可。

## 8. R1值式复制与错误合同

R1需满足：

1. 事务域签发许可时见证三字段来自自身真实状态，调用方不能输入域身份或代次。
2. 所属域判断使用许可内部不可伪造归属，不比较公开数值或对象地址。
3. 类型化值访问器在一次仓共享锁内读取真实结构版本、数量并复制所有 `已发布` 记录；候选、待退役未发布态不进入副本。
4. 返回前在仍持统一许可时复核见证、结构版本和数量；任何变化整体内部不一致、optional空。
5. 重复值记录身份、不完整记录、同一合同多个当前记录或数量不等属于内部不一致。
6. `bad_alloc`/`length_error` 为资源失败；其它异常为内部不一致；所有非成功副本空。
7. SQL、日志、材料、缓存和最大记录版本调用数0。

## 9. 恢复边界

F0不改变恢复。R1的许可只在普通入口开放、未隔离的已恢复运行期域中形成；等待恢复或恢复独占阶段不签发普通统一冻结许可。恢复材料不能提供或覆盖当前运行期域身份；来源快照域身份只是值式证据，不能替代新运行期域的真实身份。

类型化值结构版本的恢复安装语义尚属 `FREEZE-R1-TYPE-VERSION`，F0和执行者不得自行决定。SQL成功/失败不改变内存许可、见证、代次或结构版本。

## 10. 自检与顺序

F0建立唯一 `WORLD-TREE-CORE-FREEZE-DP-S01`，顺序225；开工记录顶层数量 `N`，目标 `N+1`。R1原位扩充同一身份、名称和顺序，不改名、不新增第二项，顶层数量保持R1开工时的 `N`。

F0矩阵：

- DTO字段、状态数值、默认值、move-only类型性质；
- 所有版本输入固定未实现；默认和移动许可始终无效/零见证；
- 所属域固定false；两个事务域交叉也不产生许可；
- 类型化值仓空/非空夹具调用复制均未实现空副本；
- 调用前后事务域代次、隔离、开放状态及类型化值权威导出逐字段相等；
- SQL、日志、锁、仓导出调用0；模块依赖无环。
