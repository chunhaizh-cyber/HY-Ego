本版本只修订 P12 依赖版本、实际 DTO/结果字段和专项顺序。P13 的业务目标不变：从 P10/P8 新当前事实、P12 相邻前状态选择和 P11 状态迁移比较的同一事实截止，形成与 P9 同形的二节点、五值、五关系19、五属性槽纯值规格；不写 L1、不分配稳定编码、不发布第二状态或关系20。

## 2. P12 v0.4 机器合同

P13 唯一调用：

```cpp

    const I64相邻前状态选择请求& 请求) const;
```

请求字段必须逐字段来自 P13 业务请求：


P13 不传入前状态、P9读取请求、算法、注册身份、截止代次、动态身份、许可、事务或稳定编码分配结果。P12 返回：

```text

          主体、实例槽、拟发布后状态发生时间、前状态编码、前状态发生时间
```

`已选择` 时 P13 直接消费 P12 返回的完整前状态和选择证据；不得再次调用 P9 或从历史关系枚举补造前状态。`无前状态` 时规格、迁移证据和摘要均为空；不得降级为 P9 首态。P12 `未找到`、`冲突`、版本/许可/资源/内部失败均按 P13 对应非成功状态收口，非成功载荷为空。后来退出端点无当前关系19候选已由 P12 v0.4 映射为 `未找到`，不得在 P13 恢复为成功前态。

## 4. 形成与状态映射

1. 校验业务身份、发生时间、合同/规则版本；非法返回 `入口拒绝`。
2. 读取 G0，调用 P10/P8；任何非成功或截止不等于 G0，返回对应非成功并清空载荷。
3. 用同一主体、实例槽、发生时间和派生业务查询身份调用 P12；不得把前状态放入请求。
4. P12 `无前状态` 立即返回 P13 `无前状态`；P12 `已选择` 才继续，且只使用其完整前状态/选择证据。
5. 用 P12 前状态作为左、P10/P8 新当前作为右调用 P11；校准所有身份、类型、来源、时间和截止。
6. 读取 G1；G0、P10/P8、P12、P11、G1 截止不一致时丢弃整轮并完整重试一次，仍漂移返回 `版本漂移`。
7. 将已校准值式材料交给 L1 状态服务形成二节点、五值、五关系19、五槽纯值规格。

等价成功形成规格并标记 `禁止生成迁移动能`；增加/减少成功形成同形规格并携带完整迁移证据、标记 `允许形成迁移动能规格`。任何坏成功、跨场景、时间不递增、来源非主体、P12/P11见证矛盾均返回 `内部不一致`，不形成部分规格。
