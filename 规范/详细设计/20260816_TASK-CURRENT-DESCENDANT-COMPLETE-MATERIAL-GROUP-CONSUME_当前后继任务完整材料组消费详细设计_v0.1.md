# 当前后继任务完整材料组消费详细设计 v0.1

日期：2026-08-16

计划身份：`TASK-CURRENT-DESCENDANT-COMPLETE-MATERIAL-GROUP-CONSUME`

## 1. 目标与完成边界

实现当前任务树的第四个输入叶：

```text
BIZ-L4-004-02-02-04 v0.1
任务业务服务::读取全部后继任务完整承接与生命周期事实
-> 接收03在同一非零G0返回的完整成功读取结果
-> 先互证03状态、请求回显、固定版本、节点/关系预算、事实截止和optional快照
-> 排除根后形成全部非根后继任务组
-> 非空时只经DATA-EXT-13恰一次批量读取完整承接/目标/场景/生命周期结构
-> 空后继组零DATA调用并合法成功
-> 形成稳定排序、不可变、零部分载荷的BIZ值式组
```

本叶补齐父级在 03 拿到拓扑后仍缺少的非根任务材料。它不修改已发布 02 的入口见证语义，不扩张 03 的拓扑/治理职责，也不新增 DATA “完整任务树大投影”。根材料继续只来自 02，父级负责最终集合合并和树级业务裁决。

## 2. 正式依据与当前事实

设计 S0 基线为 `main@ee11d4877c15d0080b4e216eefeba619a55f9ef9`，发布前已在 `main@8a6c14289af5bcec2727ad9d97308d88642cdd73` 增量复核：

1. 0050 要求同一组合快照使用显式共同截止、完整不可变投影和结构化失败；正交组读可以共享同一G0，不要求把不同职责合成一个超大DTO。
2. 3200、5200、5210 要求每个任务可回读全部来源、唯一目标、唯一运行场景和唯一当前生命周期；阶段枚举不能替代完整结构。
3. 5090 规定任务树独立于需求树；后继任务通常承接各自子需求，不能伪造为入口来源需求的直接承接任务。
4. 02 v0.2 的 BIZ 请求绑定 01 的入口来源承接见证，只适用于根候选组；它要求的底层 DATA 操作本身是通用“按任务身份组与指定G0批量完整读取”。
5. 03 v0.2 只返回完整父子拓扑和逐任务治理存在，明确不读取来源、目标、场景和任务生命周期；父级不能从03材料推断这些事实。
6. 当前真实代码仍没有任务结构服务、任务公开DTO、`服务.任务.ixx`或四个BIZ函数；01—03均为待激活设计，DATA-EXT-13仍只是最终需求合同。
7. 直接把02用于全部后继任务会违反其“每项必须含入口来源见证”的合同；扩张03会重复职责；让父级逐任务读取会破坏有界组读和失败守恒。
8. 03 的裸快照不携带已读取状态、请求回显和预算见证，不能单独证明它确实是同一固定配置下的03成功结果；04 必须接收完整03读取结果并防御性互证，不能让调用方拆出快照后丢失来源见证。

裁决为：新增04叶，复用同一 DATA-EXT-13 批量完整读取操作。后继组为空时本地成功，非空时恰一次调用；父级后续把02选中根、04后继材料和03拓扑/治理存在按任务身份精确合并。

## 3. 输入、输出与 DATA 消费合同

### 3.1 请求

请求必须携带：

```text
03完整当前子任务拓扑治理存在读取结果
同一非零G0
运行代次（只匹配BIZ固定配置）
事实范围版本
存在范围版本
场景范围版本
需求范围版本
任务范围版本
任务父子关系规则版本
任务治理存在关系规则版本
治理存在资格规则版本
任务树读取规则版本
任务目标关系规则版本
任务来源关系规则版本
任务场景关系规则版本
任务生命周期规则版本
读取规则版本
最大后继任务数量（非零）
全部后继当前来源关系总预算（非零）
```

03 读取结果必须为 `已读取`，请求回显完整，事实截止等于同一非零 G0，optional 快照有值；`03请求回显.运行代次 == 04请求.运行代次 == 同一任务业务服务固定配置.运行代次`，03 回显中的事实/任务/存在/场景范围版本以及父子关系/治理存在关系/治理资格/任务树读取规则版本也必须逐字段匹配同一服务固定配置。节点/关系两项预算必须非零，并与快照实际数量和03结果互证。03 回显根见证的任务身份必须等于快照唯一根。BIZ 排除根后按任务稳定身份排序；任何非成功03结果、空optional、回显/截止/根见证/预算不一致、重复任务、根缺失/重复、混代或后继数量超预算均在 DATA 调用前拒绝；运行代次或版本不等归 `当前性漂移`。

### 3.2 空组和唯一 DATA 操作

若排除根后没有后继任务：

```text
零DATA调用
-> 返回已读取
-> optional有值且组为空
-> 事实截止=G0
```

非空时复用 02 要求的同一公开 const 操作：

| 操作 | 请求 | 成功返回 | 非成功 |
| --- | --- | --- | --- |
| 按任务组与指定截止有界读取完整承接生命周期结构 | 非空、无重复非根任务身份组；非零G0；事实/需求/任务范围版本；目标/来源/场景/生命周期/读取规则版本；后继任务数和全部后继来源关系数两项非零总预算 | 与规范化非根任务组等长同序的完整任务结构项；每项含任务身份及来源、全部当前来源关系、唯一目标状态合同引用、唯一运行场景引用、唯一当前生命周期结构、各结构版本和单项G0；回显版本、两预算和共同G0 | 请求拒绝、任务未找到、任务已退出、预算不足、事实代次漂移、许可拒绝、资源失败、未实现和内部不一致；整组失败零成功前缀。因03同G0已证明任务当前存在，BIZ把未找到/退出升级为内部不一致 |

最终 DATA DTO、字段顺序、状态数值和 C++ 签名待 DATA 所有者发布后机械匹配。04 不要求新 DATA 操作，不建立兼容壳、第二 owner 或第二任务服务。

### 3.3 完整任务项与稳定顺序

04 复用 02 冻结的 `任务完整承接生命周期值式事实`语义：

```text
任务身份及身份来源
全部当前任务—来源需求关系及身份来源/端点/生命周期/版本/G0
唯一当前任务目标关系和L2目标状态合同身份
唯一当前任务运行场景关系和L2场景身份
唯一当前任务生命周期结构、阶段投影、业务状态段引用、发生时间、当前性、版本和G0
任务结构版本及共同G0
```

结果任务项按任务稳定身份排序；逐任务来源关系按需求稳定身份、关系稳定身份排序。根任务不得出现，输出任务集合必须与03节点组排除根后的集合完全相等。排序不使用显示名称、创建时间、容器顺序或 enum 裸底值。

### 3.4 不属于04的内容

```text
根任务完整材料
父子关系和治理存在资格
来源目标等价结论
当前根资格和任务树唯一性
任务阶段业务解释、完成、调度、方法、执行权或权限
历史生命周期、创建、迁移、写入或退出
```

## 5. 固定顺序与失败映射

```text
校验固定配置完整，否则内部不一致且零DATA调用
-> 校验合同、03完整读取结果、G0、版本和04两项非零预算
-> 要求03状态已读取、结果截止等于G0、optional快照有值，且03请求回显合同、根见证、节点/关系预算完整
-> 03回显、04请求和固定配置的运行代次三者相等，且03回显与04请求中的范围/规则版本逐字段匹配同一固定配置；任一不等则当前性漂移且零DATA调用
-> 互证03回显根见证、节点/关系预算、快照根/节点/治理项和共同G0，排除根后稳定排序
-> checked复核后继数量；重复、混代或超预算请求拒绝
-> 空后继组直接形成optional有值空候选并返回已读取/G0
-> 非空时构造不含运行代次、父子关系和治理存在的DATA请求并恰一次批量读取
-> DATA未找到/退出升级内部不一致；精确映射预算、漂移、许可、资源和未实现
-> 互证回显、G0、版本、两预算、结果与非根任务组等长同序且集合相等
-> 逐任务互证身份来源、全部当前来源、唯一目标、唯一场景和唯一当前生命周期
-> checked累计来源关系数并复核总预算；拒绝根混入、重复、错端点、半结构和混代
-> 稳定排序，形成完整不可变候选并无抛出交换
-> 返回已读取和G0完整组
```

| 情形 | BIZ状态 | 载荷 |
| --- | --- | --- |
| 固定配置坏 | 内部不一致 | 空；零DATA调用 |
| 坏合同、03非成功/空optional、零G0/版本/预算、03回显或根见证或预算坏、重复/超量后继 | 请求拒绝 | 空；零DATA调用 |
| 运行代次或版本不等 | 当前性漂移 | 空；零DATA调用 |
| 空后继组 | 已读取 | G0和optional有值空组；零DATA调用 |
| DATA任一后继未找到/已退出 | 内部不一致 | 空；与03同G0拓扑见证矛盾 |
| DATA预算不足 / 漂移 / 许可 / 资源 / 未实现 | 对应BIZ状态 | 空 |
| DATA请求拒绝、未知状态、未知异常或坏成功形状 | 内部不一致 | 空 |
| 完整非空成功 | 已读取 | G0和完整非根任务材料组 |

所有分配、累计和排序位于异常收口内。`std::bad_alloc`、`std::length_error`映射资源失败，未知异常映射内部不一致；成功交换前零部分发布。

## 7. 验证矩阵与声明边界

- 坏配置、坏请求、03非成功/空optional/坏回显、03结果截止不等G0、03根见证或节点/关系预算与快照不一致、零G0/预算、重复/超量后继分别验证零DATA调用；03回显/04请求/固定配置运行代次任一不等或任一版本不等均返回当前性漂移且零DATA调用；
- 单节点树返回已读取、G0和optional有值空组，零DATA调用；两级、多层、多分支树只对全部非根任务恰一次调用；
- DATA请求不含运行代次、根、父子关系或治理存在；零逐任务/逐关系读取、分页、补读和缓存；
- DATA后继未找到/退出升级内部不一致；预算、漂移、许可、资源、未实现和未知状态分别映射；
- 缺项/多项/错序、根混入、错任务集合、空来源、重复来源、错端点、目标/场景/生命周期非唯一、混代、错版本和超预算全部拒绝且零前缀；
- 输入和DATA内部顺序扰动后输出仍按正式稳定身份值式相等；
- 源码静态证明零根材料重复读取、零父子/治理存在读取、零目标等价/当前根资格/阶段解释/完成/调度/方法/权限、零L1/owner/仓库/DATA写/retry/sleep；
- 根工程 Debug/Release、专项双配置、strict、UTF-8/XML、工程唯一登记和生产零专项痕迹。

真实验证必须经 DATA-EXT-13 正式公开入口。真实资源耗尽、DATA私有损坏、跨进程恢复、父级最终集合合并/目标等价/当前根裁决、完整当前任务树发布、任务创建/迁移/调度/完成和系统业务闭环保持 `NOT_RUN`。

本设计发布不证明 DATA-EXT-13、04 BIZ代码或当前任务树已经实现。未来本计划结果最多证明同一G0下全部非根后继任务完整承接/目标/场景/生命周期材料的中性消费闭合。
