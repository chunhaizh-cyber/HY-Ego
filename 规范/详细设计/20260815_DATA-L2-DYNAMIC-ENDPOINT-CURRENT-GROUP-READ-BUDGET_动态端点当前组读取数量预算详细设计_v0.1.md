# DATA-L2 动态端点当前组读取数量预算详细设计

日期：2026-08-15

版本：v0.1

身份：`DATA-L2-DYNAMIC-ENDPOINT-CURRENT-GROUP-READ-BUDGET`

## 1. 目标

为唯一 `L2动态结构服务` 的三个既有当前组入口补齐非零动态对象数量预算：

```text
按主体读取全部当前动态
按前状态读取全部当前动态
按后状态读取全部当前动态
```

服务继续按动态身份严格升序返回同一非零守卫截止下的完整当前动态组。匹配动态数超过预算时必须返回 `L2结构状态::数量预算不足`、空动态组和空变更代次，不截断、不分页、不改判资源失败。

本叶只闭合 DATA-EXT-05 的主体 / 前状态 / 后状态当前条件查询预算；不实现时间范围查询，不改变动态写入、替换、退出、来源查询、owner、装配或其它服务。

## 2. 正式依据与当前事实

依据 0050、4015、4230 及 `计划/数据服务最终需求清单.md` 的完整枚举、数量预算、同截止和结构化非成功合同。

创建侧基线为 `main@bc44caecc2355899c98e4ad0ffd98324e7c24445`，`main == origin/main`、index 空。

当前事实：

1. 三请求已有非零事实代次守卫和强类型端点，但没有 `最大数量`；按来源请求已有同名非零预算。
2. 三公开入口已先经存在 / 状态服务同截止验证端点，再调用同一个私有 `按端点读取动态组`，并保留 `收敛并发条件读取` 对内部不一致与真实代次漂移的区分。
3. 私有实现以动态 owner 的 L1 一致当前投影读取目标关系组，拒绝重复动态身份，排序后逐项调用 `读取完整动态`；结果成功谓词已经要求严格升序、当前完整和同截止。
4. `数量预算不足 = 15` 与空组失败形状已经发布；不扩枚举。
5. 生产仓库没有三请求或三公开入口调用方；不建立无预算兼容重载。
6. 本叶只修改已登记的动态头和模块，不触碰异主 EVENT 工程 / 普通应用 WIP。

## 3. 精确 ABI

```cpp
struct L2按主体当前动态读取请求 final {
    L2结构请求头 请求头;
    L2存在身份 主体存在;
    std::uint64_t 最大数量 = 0;
    friend bool operator==(...) = default;
};

struct L2按前状态当前动态读取请求 final {
    L2结构请求头 请求头;
    L2状态身份 前状态;
    std::uint64_t 最大数量 = 0;
    friend bool operator==(...) = default;
};

struct L2按后状态当前动态读取请求 final {
    L2结构请求头 请求头;
    L2状态身份 后状态;
    std::uint64_t 最大数量 = 0;
    friend bool operator==(...) = default;
};
```

三个请求 helper 在原合同版本、非零守卫和端点有效条件上增加 `最大数量 != 0`。结果复用 `L2当前动态组读取结果`，不增加分页、游标、总数量、读取幂等身份或第二结果类型。

私有函数增加一个预算参数：

```cpp
L2当前动态组读取结果 按端点读取动态组(
    const L2结构请求头& 请求头,
    稳定编码 端点,
    动态端点角色 角色,
    std::uint64_t 最大数量) const;
```

三个公开入口逐项传入自己的 `请求.最大数量`。`收敛并发条件读取` 的输入输出和漂移收敛逻辑不变。

## 4. 读取与预算过程

既有端点强类型读回和 L1 一致当前投影不变。私有实现固定：

```text
验证登记与端点
-> 同守卫读取当前目标关系组
-> 逐条验证 owner、类型、方向、固定角色、生命周期和当前源动态节点
-> 收集动态身份并拒绝重复
-> 按身份稳定编码排序
-> 动态对象数 > 最大数量：数量预算不足 + 空组
-> 否则逐项同守卫读取完整动态并互证主体 / 前状态 / 后状态端点
-> 返回完整同截止严格升序组
```

预算按最终动态对象数计数，不按关系或值事实数计数。预算等于数量成功，少一拒绝，零匹配成功空组。预算拒绝发生在逐项完整动态读回前；已经取得的关系组仅用于同一截止的数量与结构判定，不进入失败载荷。

本叶不修改 L1 一致当前投影 ABI，因此只保证公开结果不截断，不宣称限制底层关系组构造的内部暂存量。

## 5. 状态与禁止范围

无效预算固定 `入口拒绝`。明确漂移 / 资源失败沿用同名状态；登记、关系、端点、重复身份、完整动态或同截止矛盾映射 `内部不一致`，并继续由现有 `收敛并发条件读取` 在适用时重分类真实并发漂移。全部非成功空动态组、空变更代次。
