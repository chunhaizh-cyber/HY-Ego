# INSTINCT-STAGE3-MAINTENANCE-BASE-SNAPSHOT-COMPOSER 本能被动维护基础快照组合器详细设计 v0.1

日期：2026-08-29

设计身份：`INSTINCT-STAGE3-MAINTENANCE-BASE-SNAPSHOT-COMPOSER`

## 1. 目标与边界

本设计实现阶段三的只读基础快照：在同一事实截止 `G0` 下绑定安全根当前定义及当前值、服务根当前值、本能被动维护游标和当前单调完整秒证据，为后继服务合同 / 活动完整集合提供稳定的基础输入。

它不创建持久 owner，不发布或缓存 A、V、L/H、游标或时间，不读取服务合同 / 活动 / 到期事件，也不把“当前尚无完整集合 provider”解释为空集合。它不推进游标、不调用单秒规则内核、不发布状态 / 动态。

L/H 是版本化可变定义：当前定义版本 1 为 `floor(INT64_MAX*30/100)` 与 `floor(INT64_MAX*80/100)`；后继可以发布新定义版本改变 L/H。同一快照只消费 `安全根定义与当前值服务` 在 `G0` 返回的一个正式定义版本和值，不在组合器重算百分比，也不固定版本 1。

## 2. 当前事实与复用裁决

直接复用：

- `安全根定义与当前值服务::读取安全根定义与当前值_v1`：同 G0 返回正式安全根定义、L/H、定义版本和 A 当前值。
- `L2特征结构服务::读取特征当前值`：按本能根锚点中的服务根特征实例读取 V 当前值。
- `本能被动维护游标服务::读取当前本能被动维护游标_v1`：读取运行代次、时间纪元、上一已维护完整秒和版本。
- `完整秒时钟服务::读取当前完整秒边界`：以正式游标为请求键读取当前单调完整秒观察与 0/N 区间。
- `本能根运行锚点_v1`：提供唯一自我及安全 / 服务根正式实例绑定。

退出旧占位口径：`运行期只读查询` 中从安全根特征值向量位置猜 A/L/H、从服务值向量位置猜游标，以及四次读取同一主体全部状态冒充四类完整集合，均不得被本组合器复用。该旧模块不在本切片修改面。

新建理由：现有服务均只负责单项权威事实，尚无一个公开结果同时证明它们在同一 G0、同一自我、同一运行代次和同一时间纪元下闭合；值式组合器不会形成第二持久权威。

## 4. DTO 与完整性

合同版本：1。

请求字段顺序：

```text
合同版本
L2结构请求头（G0）
本能根运行锚点
期望运行代次
```

`G0`、期望运行代次必须非零；锚点必须完整且锚点事实截止不晚于 G0。请求不得携带 L/H、A、V、时间纪元、上一边界或时间源版本。

快照字段顺序：

```text
本能根运行锚点
安全根定义与当前值快照
L2特征值事实 服务值当前值事实
int64 当前服务值
本能被动维护游标事实
完整秒边界读取状态
完整秒边界观察
optional<完整秒区间> 待维护区间
本次正式读回截止G0
```

完整性必须同时证明：

1. 锚点完整，锚点截止不晚于 G0；
2. 安全快照完整，定义的自我、特征定义和特征实例逐字段等于锚点，安全快照截止等于 G0；
3. 服务值事实是锚点服务根特征实例在 G0 的未退出 `int64` 当前值，值域为 `0..INT64_MAX`；
4. 游标完整，游标自我等于锚点自我，运行代次等于请求期望值；
5. 时间观察的运行代次、时间纪元、上一边界、时间源版本逐字段等于游标；
6. `无新完整秒` 时区间为空且当前边界等于上一边界；`已读取` 时区间非空，首边界等于上一边界加 1、末边界等于当前边界、数量精确等于两边界差且大于 0；
7. 所有 L2 正式读回截止均为同一 G0。

结果状态：

```text
已读取
无新完整秒
入口拒绝
定义未发布
当前值未设置
游标未建立
当前性漂移
运行代次漂移
时间纪元漂移
时间源版本漂移
时间倒退
引用冲突
材料不闭合
资源失败
内部错误
```

只有 `已读取`、`无新完整秒` 携带完整快照且截止等于 G0，`成功()` 为真；`可维护()` 只在 `已读取` 且待维护区间数量大于 0 时为真。其余状态快照为空、截止为 0、两个谓词均为假。

## 5. 读取过程与错误映射

固定顺序：

```text
请求守卫
-> G0 读取当前游标
-> 绑定自我、期望运行代次、时间纪元和时间源版本
-> 以游标调用完整秒时钟
-> G0 读取安全根定义与当前值
-> G0 读取服务根当前值
-> G0 再读游标并与首次结果逐字段一致
-> 形成并完整性复核快照
```

映射规则：

- 定义未发布、当前值未设置、游标未建立保留具名状态；不得补默认值。
- 任一 L2 正式截止非零但不等于 G0，或末次游标与首次不同，映射当前性漂移。
- 游标运行代次不等于请求，映射运行代次漂移。
- 时钟的纪元错配、时间源版本漂移、时间倒退分别保留。
- 身份、实例、定义、类型或字段互证失败映射引用冲突或材料不闭合；不能改写成空集合或无新完整秒。
- `bad_alloc`、`length_error` 映射资源失败；其它异常映射内部错误。

组合器是只读确定函数：同一依赖快照和同一请求逐字段返回相同结果，无幂等写账，也没有撤销或已可能发布状态。

## 6. 验证矩阵与完成边界

至少覆盖：

- P00 请求、合同、锚点、G0、运行代次守卫及全部非成功空载荷；
- P01 定义未发布、A/V 未设置、游标未建立；
- P02 定义版本 1 的 30%/80% 精确值，以及发布后继定义版本后快照读取新 L/H、旧 G 不混读；
- P03 无新完整秒形成完整成功快照但 `可维护()==false`；
- P04 单秒和多秒区间形状、数量与边界精确；
- P05 运行代次、时间纪元、时间源版本和时间倒退；
- P06 G0 前后漂移、末次游标互证；
- P07 服务值必须来自锚点实例的正式 `int64` 当前值，错误实例 / 类型 / 退出事实阻断；
- P08 仓库外 ABI consumer 导入模块并调用；专项至少把成功基础快照投影为单秒规则请求的 A/V/L/H/定义版本，证明消费者不使用硬编码阈值。
