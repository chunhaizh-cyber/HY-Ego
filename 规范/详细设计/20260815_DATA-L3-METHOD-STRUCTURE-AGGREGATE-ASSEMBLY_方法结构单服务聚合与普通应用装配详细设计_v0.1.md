# DATA-L3 方法结构单服务聚合与普通应用装配详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L3-METHOD-STRUCTURE-AGGREGATE-ASSEMBLY`
状态：设计就绪、待激活

## 1. 目标与边界

建立唯一 `L2方法结构聚合服务`，让普通应用从同一 L1 运行包建立并持有唯一方法 owner、唯一 `L2方法结构服务` 和一份只引用该实例的聚合，并只向调用方公开 const / non-const `取得L2方法结构聚合服务()`。

唯一链路为：

```text
普通应用唯一 L1 运行包
-> 唯一方法 owner 交付
-> 唯一 L2方法结构服务
-> 唯一 L2方法结构聚合服务
-> 普通应用聚合 getter
-> 聚合取得同一 L2方法结构服务
```

聚合没有 owner、写端口、锁、缓存、DTO 映射、通用查询或执行入口。普通应用不增加直接方法服务 getter；BIZ 只能经聚合取得方法服务。

本叶不建立方法登记根、不创建普通方法登记或执行规格、不接线阶段 19，也不修改世界结构聚合、概念结构聚合或其它 DATA 服务。

## 3. 唯一聚合模块

新文件：`海中鱼巣/领域/服务.L2方法结构聚合.ixx`。

```cpp
export module 海中鱼巣.领域.服务.L2方法结构聚合;

import 海中鱼巣.领域.服务.L2方法结构;

export namespace 海中鱼巣 {

class L2方法结构聚合服务 final {
public:
    explicit L2方法结构聚合服务(L2方法结构服务& 方法结构服务) noexcept
        : 方法结构服务_(方法结构服务) {}

    L2方法结构聚合服务() = delete;
    L2方法结构聚合服务(const L2方法结构聚合服务&) = delete;
    L2方法结构聚合服务& operator=(const L2方法结构聚合服务&) = delete;
    L2方法结构聚合服务(L2方法结构聚合服务&&) = delete;
    L2方法结构聚合服务& operator=(L2方法结构聚合服务&&) = delete;

    L2方法结构服务& 取得L2方法结构服务() noexcept {
        return 方法结构服务_;
    }
    const L2方法结构服务& 取得L2方法结构服务() const noexcept {
        return 方法结构服务_;
    }

private:
    L2方法结构服务& 方法结构服务_;
};

}
```

该模块只 import 方法结构服务。禁止 import L1、概念、需求、任务、BIZ、线程或世界结构服务。

## 4. 普通应用装配

普通应用在概念服务 / 概念聚合之后依次声明：

```cpp
std::unique_ptr<L2方法结构服务> 方法服务_;
std::unique_ptr<L2方法结构聚合服务> 方法聚合服务_;
```

聚合成员声明在服务之后，使析构时聚合先于被引用服务销毁。上下文私有构造增加两份右值 `unique_ptr` 参数并按同序保存。

只新增：

```cpp
L2方法结构聚合服务& 取得L2方法结构聚合服务() noexcept;
const L2方法结构聚合服务& 取得L2方法结构聚合服务() const noexcept;
```

不得新增 `取得L2方法结构服务()`、pointer / optional getter、第二方法聚合或按枚举选服务入口。

`构造普通应用上下文` 在概念服务与概念聚合完整成功后依次：

1. 经同一运行包签发器以 `方法所有者建立身份` 建立独占 owner；失败映射 28；
2. 形成 `L2方法所有者交付`；失败映射 29；
3. 构造唯一 `L2方法结构服务`；失败映射 30；
4. 构造唯一 `L2方法结构聚合服务`；失败映射 31；
5. 全部成功才把方法服务和聚合移动进入上下文。

装配状态尾部追加：

```cpp
方法所有者范围建立失败 = 28,
方法所有者交付形成失败 = 29,
方法服务构造失败 = 30,
L2方法结构聚合服务构造失败 = 31
```

状态 0—27 不变。失败依赖 RAII 回收候选，不返回半上下文、不把缺少方法服务表达为阶段 19 的运行结果。

## 6. 并发、生命周期和失败

- 聚合没有自己的并发状态，调用直接落到唯一方法服务；
- 上下文、方法服务和聚合不可复制 / 移动，引用地址在上下文生命周期内稳定；
- 聚合不延长服务生命周期，成员声明顺序保证安全析构；
- owner、交付、服务或聚合构造失败均使普通应用装配失败，不退化成缺方法能力的成功上下文；
- 方法根不存在或方法服务返回业务内非成功不属于装配失败，由合法消费者处理。
