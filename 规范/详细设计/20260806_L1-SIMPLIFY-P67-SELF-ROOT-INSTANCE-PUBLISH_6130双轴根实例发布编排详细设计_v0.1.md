## 2. 目标与最大边界

新增唯一公开根：

```cpp
自我双轴根实例发布结果 L1自我根实例发布服务::发布自我双轴根实例(
    const 自我双轴根实例发布请求& 请求) const;
```

固定流程：

```text
纯值校验P67版本和嵌套P66请求版本
-> 调用P66形成双轴根实例批次规格恰一次
-> P66非成功时具名映射并返回，P40调用0
-> P66成功时逐字段验证A=1/V=0、顺序0/1和恰两项
-> 把规格中的P40批次请求原样委托P40恰一次
-> 逐字段校验P40状态、批次、项目、4170记录和发布边界
-> 返回首次、幂等或具名非成功结果
```

本叶不形成P36规格、不构造P40写集、不新增幂等身份、L1键、操作标签、摘要、provider证据、稳定编码、4170账、事务参与者、提交或独立读回。它不读取P17/P24—P26，不形成根需求、状态、动态、因果，不做生产装配、恢复、旧栈删除或正式验收。

## 5. 入口、P66调用与短路

任何依赖调用前只验证：顶层合同/发布规则精确，嵌套P66合同/规格规则精确，批次在P40合法56位范围。失败返回入口拒绝，P66/P40调用均0。P67不重复校验完整自我、根定义、A/V或P7/P2请求；这些由P66唯一形成。

入口合法后调用：

```cpp
规格服务_.形成自我双轴根实例批次规格(请求.规格请求)
```

恰一次。P66状态映射固定：

| P66 | P67 | P40调用 |

| 已形成且规格完整 | 继续 | 1 |
| 入口拒绝 | 入口拒绝 | 0 |
| 完整自我未发布 | 完整自我未发布 | 0 |
| 根定义未发布 | 根定义未发布 | 0 |
| 事实代次漂移 | 事实代次漂移 | 0 |

P66成功必须携带规格，结果批次/截止等于规格；`A=1/V=0`；P40请求恰两项；项目0安全值1、项目1服务值0；两项共同宿主、来源、截止，来源等于宿主，定义互异。任一矛盾是内部不一致且P40调用0。P67不修正、排序、裁剪或重建P66规格。

## 6. P40唯一发布与结果映射

只把`P66规格.批次请求`以const引用传给：

```cpp
批次发布服务_.发布实际存在I64初始特征批次(规格.批次请求)
```

恰一次。不得先探测P15/P38、逐项调用P36、直接调用P39、重试或提交第二批次。

P40状态同名映射：`已提交/幂等读回/入口拒绝/登记未加载/未找到/事实代次漂移/幂等冲突/许可拒绝/未知格式/资源失败/内部不一致`。成功或幂等必须满足：

1. 批次等于P66规格批次，L1键高8位为0x0F且低56位等于批次；
2. 事实代次非零且不早于P66共同截止，`L1发布已存在=true`；
3. 项目恰两项、顺序0/1、I64值1/0、定义和来源逐项等于P66请求；
4. 每项实例槽、宿主关系、定义关系和当前值编码非零，组内按P40合同完整；
5. 4170记录存在，批次、规则、宿主、项目数、顺序、定义、来源和发布代次与结果及P66请求一致；
6. P40成功载荷没有第三项、交换项、部分项或宿主其它槽。

成立后把P66规格和完整P40结果值式放入发布事实，P40`已提交/幂等读回`原样成为P67状态。P40非成功必须无业务项目和记录；若其`L1发布已存在=true`，只允许内部不一致且代次非零。坏成功、坏失败、错键、错批次、错项目或未知状态统一内部不一致；已经发布时保留P40代次和布尔值，不回滚、补写或再次调用。

## 7. 并发、异常与生命周期

P67不加锁、缓存或首次账。相同请求并发会各自调用P66一次并进入P40；同批同义/异义和探测后竞争完全由P40的P15/4170双账收口。不同批次仍由P40/L1串行提交，P67不扩大并发语义。

P66返回后不持锁；P40调用完成后全部结果复制为调用方值。函数不`noexcept`，P66/P40结构化失败按表映射；P67自身在构造事实时`std::bad_alloc`映射资源失败，其它未分类异常映射内部不一致。若P40已经确认发布，任何P67异常保留发布代次和`L1发布已存在=true`。零sleep、零retry、零时间/日志裁决。

## 8. 为什么发布后读取不是本叶前置

P40成功已经用P15同锁读回和4170记录证明本批次两槽、两关系组、两值与属性槽共同发布；P67必须互证并返回该完整证据。为首次发布再调用P24—P26会产生事务外第二快照，只能证明稍后的当前状态，不能加强或替代P40原子提交证据。

运行期根差距、自检和需求形成需要在任意后续代次独立读取当前双轴值；该能力应复用P17/P24—P26并按P65定义身份筛选，属于P67发布完成后的下一独立叶。P67不得把一次初始化结果缓存为永久根当前值。
