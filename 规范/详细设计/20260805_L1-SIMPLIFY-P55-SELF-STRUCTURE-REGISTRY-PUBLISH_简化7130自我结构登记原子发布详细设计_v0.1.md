P53只冻结自我结构登记DTO、唯一投影和非阻塞读取；P54只冻结该投影的P37具体附属事务参与者及一次内部提交根。两者均不形成公开业务请求、请求意图摘要、结构化执行证据、L1写集或登记发布结果。

能力矩阵如下：

| 所需能力 | 唯一现有或冻结提供者 | P55裁决 |
| --- | --- | --- |
| 世界登记稳定身份定位 | P18 `世界登记服务::尝试读取当前登记` | 复用，不扫描或猜测登记 |

| 公开登记业务原子发布 | 无 | **本叶最早缺口** |

不另建“登记写入规格provider”：本地键、两普通节点、读回计划和P54草案均已由P54冻结，且只依赖公开请求和P18/P17值式事实；拆分会制造第二写集解释者。不另建透明门面：本叶本身就是登记领域唯一业务发布服务。完整自我五身份五关系规格仍是后继独立叶。

P55不能把非空L1中的两节点新增伪装为P15 `空仓纯G0`。首次路径必须以P18定位材料和同一次P17快照形成`事实互证`模式的提供者版本、写前事实见证、共同截止和规范化写集摘要。

## 5. 幂等键、请求意图与探测

身份固定且创建侧扫描未占用：

```text
L1幂等域高8位 = 0x13
低56位 = 登记身份.值
领域操作标签 = U32 0x5033'5501
专项顺序 = 555
```

入口在任何依赖调用前验证：合同/规则均为1；世界规则版本非零且能无损匹配P18的U32世界规则版本；登记身份在合法值域；期望事实代次非零。失败返回入口拒绝，探测/P18/P17/P54调用均为0。

请求意图摘要按P15网络字节序固定编码：

```text
ASCII HZY-L1ID
+ U32编码格式版本1
+ U32操作标签0x50335501
+ U8请求意图模式1
+ U32发布合同版本
+ U32发布规则版本
+ U64世界规则版本

```

摘要不编码P18/P17结果、本地键、稳定编码、地址或显示名。全零摘要为内部不一致且不探测。

调用`L1事实基座服务::探测幂等`恰一次：未找到才进入首次路径；同义已发布要求首次两节点读回、首次代次、结果摘要及失败/隔离形状完整，P15首次键/意图必须与本次请求一致，再只调用P53读取一次，互证登记身份、世界版本和发布代次与P15首次结果一致后返回幂等读回；异义映射幂等冲突；已隔离映射许可拒绝；入口拒绝、资源失败、内部不一致和未知值逐类收口。P55不读取P54私有提交绑定。所有非未找到分支P18/P17/P54调用为0。

## 6. P18/P17当前性与结构化执行证据

仅探测未找到时固定调用：

1. `世界登记服务::尝试读取当前登记({世界登记合同版本, 请求.世界规则版本})`恰一次；
2. 成功后调用`L1事实基座服务::尝试读取完整快照({L1事实基座合同版本})`恰一次。

P18登记未加载映射世界登记未加载，许可拒绝/资源失败/内部不一致同名映射，其它坏成功内部不一致。P17许可拒绝、资源失败、内部不一致同名映射；快照缺失、代次0或代次不等请求期望代次映射事实代次漂移或内部不一致，不重取。

在P17副本中逐项互证P18五个稳定编码互异且当前：服务身份、直接父场景关系类型、直接成员关系类型和世界根场景为普通节点；场景标记属性类型为`属性类型 + I64`。五项创建代次均不晚于快照代次；世界规则版本精确相等。P18的`已验证事实代次`只证明首次登记建立，不冒充当前截止。

P15 `L1执行证据材料`固定为`事实互证`：

- 提供者版本组恰一项：身份=P18登记服务身份，合同版本=世界登记合同版本，规则版本=世界登记规则版本；
- 写前事实见证组恰五项：P18服务身份、场景标记属性类型、直接父场景关系类型、直接成员关系类型、世界根场景的P17当前节点事实摘要，按稳定编码升序唯一；
- 共同事实截止=P17快照代次=请求期望代次；
- 规范化写集摘要=第7节精确两节点写集摘要；
- 材料摘要与执行证据摘要严格按P15 v0.11编码，不复制或改写P15算法。

任何提供者版本、见证、排序、摘要或截止矛盾均在P54前拒绝。

## 8. 结果映射、并发与失败

P54 `已提交/精确重复`分别映射公开`已提交/幂等读回`；两者必须携带同一登记身份、幂等键、非零同代次、`L1发布已存在=true`、完整P53登记及恰两项映射。公开结果隐藏本地键映射，只返回完整登记。

P54入口拒绝、事实代次漂移、幂等冲突、许可拒绝、资源失败和内部不一致逐类映射。坏成功、错世界版本、错节点种类、错映射、错代次或登记不完整映射内部不一致，不补写、不重试、不回滚。

不同登记身份并发首次由L1独占域串行；第一项成功后，后到项即使使用不同L1键也由P54参与者检测P53已加载并返回幂等冲突。相同身份同义只发布一次；相同身份异义由P15冲突。服务自身不加锁、不建第二账。

所有请求、P18/P17副本、摘要、写集、材料、草案和结果均为同步调用栈值。`bad_alloc`映射资源失败，其它未分类异常映射内部不一致。零等待、零sleep、零内部重试、零SQL/材料/旧栈回源。
