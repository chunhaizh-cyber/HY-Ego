# L2-SELF-E-ROLE 存在单例角色结构详细设计 v0.1

日期：2026-08-13

## 1. 目标与边界

在唯一 `L2存在结构服务` 和既有存在 owner 内增加业务中性的单例角色结构，使上层能够以一个不透明角色键唯一定位一个正式存在。L2 不定义“自我”角色、不建立项目资格、不读取 I2、不接触场景，也不增加 owner 或世界服务。

本叶是 7130 真实自我三叶的第一叶。它只证明通用结构能力，不删除启动阶段 17。

## 2. 当前事实与复用裁决

设计基线 `1f0019c9d827f21438b7f7305b43aef8187e92db` 的存在服务已拥有唯一存在 owner、族锚点 / 族归属、节点新增、当前 / 历史来源与完整读取、属性和退出。当前没有单例角色登记或角色查询；`句柄.h` 的旧 `自我结构角色 = 21` 与 `服务.L1自我结构登记` 属于旧中性登记闭包，不可复用。

复用存在 owner、端口、来源读回、全局幂等域、状态分账和 L1 owner-aware 读取；原位扩展两个存在生产文件。禁止恢复关系 21、旧完整自我、专用自我 DTO、资格属性或第二幂等账。

## 3. 结构所有权和事实

全部角色结构由存在 owner 写入：

```text
角色登记锚点（私有普通节点）
角色关系类型（私有普通节点）
角色事实：角色登记锚点 --角色关系类型 / 角色键--> 正式存在
```

角色键为非零、正值 `int64_t`；L2 不登记固定键含义。一个角色键至多一条当前关系；一个存在可承载多个不同角色键。登记锚点和类型不是 `L2存在身份`，无族归属，不退出。

新增角色化存在的一笔 owner-scoped 写集固定为：存在节点、存在族归属、角色关系三项；把既有存在绑定角色只新增一条角色关系。替换角色目标同事务建立新关系并退出旧关系；退出角色只退出具名关系。存在退出由 L1 当前引用保护阻止仍被角色关系引用的存在退出。

## 4. DTO 与公开 ABI

物理位置固定为 `海中鱼巣/领域/L2存在结构.数据.h`：

```cpp
struct L2存在单例角色键 final { std::int64_t 值 = 0; };
struct L2存在单例角色关系类型身份 final { 稳定编码 值; };

struct L2存在单例角色结构登记 final {
    std::uint32_t 合同版本;
    std::uint32_t 规则版本;
    L2结构幂等身份 首次幂等身份;
    稳定编码 角色登记锚点稳定编码;
    L2存在单例角色关系类型身份 角色关系类型;
    L2生命周期 锚点生命周期;
    L2生命周期 类型生命周期;
    std::uint64_t 事实截止代次;
};

struct L2存在单例角色事实 final {
    L2存在单例角色键 角色;
    L2存在身份 存在;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
};
```

同一数据头定义登记请求 / 结果、`L2角色化存在新增请求 / 结果`、`L2存在单例角色绑定请求`、`L2存在单例角色替换请求`、`L2存在单例角色退出请求`、统一写结果、当前 / 历史读取请求 / 结果。读取请求含共同请求头、读取类别、角色键和显式历史截止；非成功空载荷。

唯一存在服务原位新增：

```cpp
L2存在单例角色结构登记结果 建立存在单例角色结构登记(...);
L2存在单例角色结构登记结果 读取当前存在单例角色结构登记() const;
L2角色化存在写入结果 新增角色化存在(...);
L2存在单例角色写入结果 绑定存在单例角色(...);
L2存在单例角色写入结果 替换存在单例角色目标(...);
L2存在单例角色写入结果 退出存在单例角色(...);
L2存在单例角色读取结果 读取存在单例角色(...) const;
```

登记固定身份由数据头公开一个常量，构造期在存在来源登记之后建立；实现 S0 须先扫描最终存在服务键域，再选择并冻结不冲突的 `0x0101'13xx` 本地键。业务请求使用调用者给定 `L2结构幂等身份`，命中登记保留值固定拒绝。

## 5. 校验、读取与并发

所有写先核对共同合同、非零期望代次、角色键、幂等身份和适用存在来源。绑定 / 替换目标必须是当前正式存在；读取按精确关系类型、锚点、owner、角色、端点和生命周期返回。零关系为 `未找到`，重复同角色关系、错 owner / 类型 / 方向 / 角色或退出混代为 `内部不一致`。

当前读取共享请求指定的当前截止；历史读取隐藏截止后的未来退出。首次 / 精确重复均从首次变更截止正式读回。并发同角色不同目标至多一条成功，其余返回漂移、幂等冲突或引用冲突；不得按关系遍历顺序取首项。
