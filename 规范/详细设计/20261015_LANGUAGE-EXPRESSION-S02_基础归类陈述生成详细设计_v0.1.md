# LANGUAGE-EXPRESSION-S02 基础归类陈述生成详细设计

日期：2026-10-15。版本：v0.1。状态：设计就绪；代码尚未实现。代码基线：`42d925ad2c48740a8388662dd4573bfbeb7e4fe4`。

## 1. 目标与首叶边界

用户的长期目标是在具体表达要求已明确时，按表达目的、目标对象类型和类型化含义召回语言知识，绑定角色并生成自然语句。本叶交付一个可供业务调用的通用**基础表达入口**和实际成功路径：两个已登记的存在概念，以明确选择且可完整读回的同语言名称，使用现行基础结构生成“狗是一种动物”形态的汉语归类陈述，并回传规则、角色、名称及 Unicode 标量范围对齐。例句仅说明形态，不是初始化数据或已经存在的事实。

成功范围严格限于：目的=陈述；作用域=普通陈述；操作=概念归类；两个参数均为存在概念；结构为当前可读的基础表达，角色项均为名称表达，固定项均为词条。选择规则依完整定义匹配，不依赖种子标签 `S02`。同类别的两个概念及句型只表达**调用方给定的归类主张**；生成器不据此建立上下位、事实、需求或任务。

其它已发布的 S01/S03/S05 可作为知识候选被召回，但其“明确对象描述”没有本叶可核验的接收方可恢复指称材料，返回具名缺指称；特征概念 S02、提问、提出需求、D/T/M、代词、内容组织和句段篇作为后继目标，不以空实现宣称支持。对象类型与用途是召回条件，完整操作与角色合同仍决定最终结构。

## 2. 当前能力与归属

现行 `新_语言类` 拥有知识定义、固定词条与来源的结构读回，`查询语言知识`要求完整定义，`获取语言知识`要求已知身份；没有“给定用途/含义/类别”的候选枚举。`初始化.语言知识`已声明五条基础规则，现行结构枚举只有陈述、普通陈述和归类/特征/组成三个操作；初始化不等于运行期生成。`概念_名称关系类::获取名称关系`、`新_词类::获取词条`、`概念_存在类::获取存在概念`可用于强类型名称核验。不存在可复用的生成业务函数。

复用裁决：扩展语言 owner 一个**只读候选枚举**，复用其现有完整知识/固定词端点读回与复核链；在 `海中鱼巣/业务/表达.基础语言.h/.cpp` 新建 DATA 外表达业务。知识 owner 不判断本次概念、名称或含义，不拼句子；业务不直接读取基础数据集内部索引，不创建第二语言知识仓。当前无生产交互调用者；本叶交付正式可调用业务入口，不假装已经由 self 触发或送达。

## 3. 冻结公开合同

### 3.1 语言 owner 的候选读取

在 `新_语言类.h/.cpp` 新增：

```cpp
struct 新语言知识候选列表结果 final {
    新语言知识状态 状态 = 新语言知识状态::输入拒绝;
    std::vector<新语言知识信息> 信息组;
};
新语言知识候选列表结果 新_语言类::枚举语言知识候选(
    稳定编码 语言节点, std::size_t 最大条目数,
    const 新_词类& 词服务) const;
```

在 `新语言知识状态` 末尾增加 `额度不足`。输入语言必须正式可读，额度为有限正数。先用现有“语言→结构”反查取得身份组，在**读任一候选完整知识结构前**检查反查成员数；超过额度即返回 `额度不足` 且空组，不读取前缀、也不声称候选集合完整。未超限才按现有“逐个完整读回全部定义→锁外读词条→锁内复核快照”路径完成候选。底层反查本身返回整组结构引用，故本叶额度限制的是完整知识定义和词端点读取数，不宣称底层索引查询的内存占用也受该额度约束；若未来此整组反查成为资源瓶颈，须另设计底层有界反查合同。成功时按知识节点稳定编码升序返回该语言**全部**完整定义，包括不适合本次请求的定义。无知识为成功空组；任何已开始读的候选/固定词/来源结构失效按已有状态映射整体失败。该入口只供业务召回，不发布业务事实、不持久化缓存。

### 3.2 表达业务请求与结果

在 `表达.基础语言.h` 声明唯一业务入口（`.cpp`定义）：

```cpp
enum class 基础表达参数种类 : std::uint8_t { 概念 = 1, 领域对象, 特征类型, 准确值 };
struct 基础表达参数 final {
    新语言知识参数角色 参数;
    新语言知识角色类别 类别;
    基础表达参数种类 种类;
    std::variant<稳定编码, std::int64_t> 内容;
    std::optional<稳定编码> 选用名称关系;
};
struct 基础表达请求 final {
    稳定编码 语言节点;
    新语言知识表达目的 目的;
    新语言知识含义操作 操作;
    新语言知识作用域 作用域;
    std::vector<基础表达参数> 参数组;
    std::size_t 最大知识条目数;
    std::size_t 最大名称条目数;
    std::size_t 最大输出标量数;
};
enum class 基础表达状态 : std::uint8_t {
    已生成, 输入拒绝, 缺规则, 缺名称, 名称待选, 缺指称, 多规则待选,
    能力未支持, 引用不可读, 读取漂移, 额度不足, 工程未完成, 内部不一致
};
struct 基础表达对齐项 final {
    std::size_t 起始标量, 结束标量;
    std::int64_t 结构项编号;
    std::optional<新语言知识参数角色> 参数;
    std::optional<稳定编码> 词条节点;
    std::optional<稳定编码> 名称关系节点;
};
struct 基础表达结果 final {
    基础表达状态 状态 = 基础表达状态::输入拒绝;
    std::string 文本;
    std::optional<稳定编码> 知识节点;
    std::vector<基础表达参数> 已用绑定;
    std::vector<基础表达对齐项> 对齐组;
};
基础表达结果 生成基础语言表达(
    const 基础表达请求& 请求,
    const 新_语言类& 语言服务, const 新_词类& 词服务,
    const 概念_名称关系类& 名称服务,
    const 概念_存在类& 存在概念服务);
```

`std::variant` 的当前成功分支只接受概念稳定编码。参数名唯一，概念参数必须是正式存在概念身份。先完整查询该概念的当前名称关系并按正式词条语言过滤：目标语种无名称返回缺名称；只有一条则直接选用；多条须有调用方明确指定的名称关系，否则返回名称待选。指定关系必须属于该概念且为目标语言，失效或错误端点返回引用不可读/输入拒绝，不能静默换用别的关系。调用方明确选择同语言别名是允许的；本叶不从词面猜首选名称。参数类别由业务重新核验，不相信调用方枚举。三个额度都必须为有限正数；名称全组超过额度即返回额度不足，不截断候选。所有输入均为调用期值，不创建表达目标持久节点或外部来源事实。

完整成功时 `文本` 是严格 UTF-8，`知识节点` 和 `已用绑定` 存在；`对齐组`按结构项顺序覆盖每个非空输出片段，范围为零起点、半开 Unicode 标量区间，固定词项给词条，角色项给参数与名称关系。失败时文本、知识节点、绑定和对齐均为空，不输出残句。生成结果本身不证明主张为真、文本已保存、已发送或被理解。

## 4. 选择与生成流程

1. 预检请求合法枚举、唯一具名参数、正额度和已存在语言；以 `目的/操作/作用域/实参类别`形成召回键。调用 `枚举语言知识候选`，未完成原样映射，绝不把额度不足当缺规则。
2. 对全部完整定义筛选目的、单一含义项操作及作用域，并通过含义参数名→规则角色映射逐项核验种类/类别约束；不使用 `S02` 标签、固定词面或知识节点号判断含义。没有结构匹配为缺规则；两个或更多**不同知识身份**完整匹配时，直接返回多规则待选，不按枚举顺序选择。owner 已按完整定义消重的同一身份只计一次，不另造“等价”判据。
3. 若匹配规则需要 `明确对象描述`，返回缺指称；若属于本叶尚未实现的特征概念联合根、变量、条件、子规则或内容组织等，返回能力未支持。不得把一个不支持项跳过后选择语义不同规则。
4. 对成功范围中的两个存在概念，分别调用 `获取存在概念`并核对身份与类别；`查询概念名称`必须完成全组读取、额度核验，再逐条 `获取名称关系`和`获取词条`筛选目标语言，按 §3.2 选择关系。重新读已选端点及名称全组，若当前材料变化返回读取漂移。跨服务没有共同事务，不把一次分步读取声明成原子世界快照。归类主张来自请求，业务只核验类型与可表达材料，不自动宣称两个概念有正式上下位关系。
5. 按选中**正式结构项**自左向右读取固定词条或角色名称词面，严格 UTF-8 解码计数并累计标量位置。所有片段在调用期暂存，完整通过引用与总输出额度核验后一次组成结果；超过额度返回额度不足，不截句。实现为结构项解释，不专门拼“是一种”。
6. 填写规则固定身份、参数绑定与每项来源对齐。调用方需保存或发送时分别交语言材料服务或已授权通道；本函数零领域写入、零发送。任何错误均不修改概念、名称、词条、世界、需求、任务或方法。

读回完整性优先于加速：owner 的索引只召回，业务必须取完整定义，名称关系和词条均核对端点；工程异常/资源失败独立返回或按现行工程诊断处理，不伪装为“无规则”“无名称”。
