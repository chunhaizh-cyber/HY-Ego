## 1. 版本关系与裁决

本文件是对同身份 v0.1 的不可变执行期修订，不覆盖或改写已经发布的 v0.1。执行时以 v0.1 为完整基础，并由本文件精确替代 v0.1 的第 3.2 节相关能力裁决、第 6.1 节步骤 3—4、流程中的成员/列表项读取节点以及 V02、V06、V07、V13、V14 的受影响验证合同；未被本文件替代的 DTO、目标、白名单、比较算法、错误状态、事务、副作用、后继和完成声明边界继续按 v0.1 生效。发生冲突时以 v0.2 为准。

裁决采用执行侧请求的 A 路径：

```text
读取需求成员列表
-> 只取得当前成员关系和列表项身份投影
-> 从当前成员关系.列表项取得列表项身份
-> 在同一 G0 调用 L2需求结构服务::读取需求列表项完整
-> 以完整列表项事实参加四字段互证和成功快照
```

不修改 `L2需求结构服务`、`L2需求成员列表读取结果` 或其投影实现。该路径只组合两个已经公开的 L2 读取入口，补齐原设计误判的字段来源；不改变需求当前满足机器语义、公开 DTO、组合器签名、状态枚举、白名单或完成边界，也不扩大到独立 L2 provider 修正目标。

## 2. 当前事实与冲突根因

当前源码已经唯一证明：

1. `L2需求结构服务::读取需求成员列表(L2需求成员列表读取请求)` 位于 `海中鱼巣/领域/服务.L2需求结构.ixx`，其成功结果允许携带 `当前成员关系` 和 `所属列表项`，但成功谓词不要求两个 optional 都存在。
2. `读取需求成员列表当前投影` 构造的 `所属列表项` 明确是“简化：仅身份和生命周期”；当前实现只赋值 `身份`，其它列表项核心契约字段保持默认值。`L2需求成员列表读取结果::成功()` 只检查结果头，不证明该投影是完整列表项事实。
3. `L2需求结构服务::读取需求列表项完整(L2需求列表项完整读取请求)` 是同一服务现有公开 const 入口。其成功谓词要求 `L2需求列表项事实完整`，完整投影包含身份、所属存在、目标宿主、目标特征、目标状态合同、生命周期和自有关系。
4. 已发布生产调用方已经采用“先读成员关系，再按 `当前成员关系->列表项` 调用 `读取需求列表项完整`”的组合方式；这不是新合同或测试专用路径。
5. 执行 WIP 的 V02 已证明原五个诊断读取均在同一 G0 成功，成员端点正确；失败只发生在把简化身份投影当作完整列表项并与需求四字段比较时，现实现因默认字段而正确返回 `引用冲突`。

因此，v0.1 中“`读取需求成员列表`直接返回当前成员和完整所属列表项”的能力裁决不成立。扩大到修改 L2 provider 会改变本叶文件所有权和公共返回形状，且不是完成原目标所必需，不采用 B 路径。

## 3. 修订后的能力复用裁决

| 所需能力 | 当前入口 | v0.2 裁决 |
| --- | --- | --- |
| 当前需求目标 | `L2需求结构服务::读取需求完整` | 直接复用 |
| 当前成员关系与列表项身份 | `L2需求结构服务::读取需求成员列表` | 直接复用；只把 `当前成员关系.列表项`视为后续完整读取身份来源 |
| 完整所属列表项 | `L2需求结构服务::读取需求列表项完整` | 新增一次同 G0 组合读取；请求身份只能来自当前成员关系 |
| 目标宿主当前特征实例和值 | `L2特征结构服务::按存在读取全部当前特征` | 与 v0.1 相同，严格 0/1/>1，值不追加第二次读取 |
| 目标合同 | `L2状态结构服务::读取完整目标状态合同` | 与 v0.1 相同 |
| 比较注册和正式比较 | `读取当前特征比较注册`、`比较特征` | 与 v0.1 相同 |

正常路径固定为六个公开读取和一次正式比较：

```text
1 读取需求完整
2 读取需求成员列表
3 读取需求列表项完整
4 按存在读取全部当前特征
5 读取完整目标状态合同
6 读取当前特征比较注册
7 比较特征
```

六个读取和比较全部使用同一个 `L2结构请求头{L2结构合同版本, G0}`；函数内不得刷新截止、循环重试或把任一读取降为历史推断。

## 4. 修订后的成员与列表项算法

v0.1 第 6.1 节步骤 1—2不变。其步骤 3—4替换为：

1. 调用 `读取需求成员列表({头, 当前, 请求.需求, 0})`。
2. 先检查结果头回显截止。回显非 G0 或状态为`事实代次漂移`时返回`当前性漂移`和零裁决。
3. 非成功按 v0.1 的结构失败映射处理，但当前成员关系尚无属于本需求当前结构不完整，映射为`内部错误`，不映射为`证据不足`。
4. 成功结果必须有`当前成员关系`；缺失说明当前需求没有唯一当前成员关系，返回`内部错误`。成员结果中的 optional `所属列表项`不属于本算法输入，不要求存在，也不读取其身份、核心字段或生命周期。
5. `当前成员关系.需求`必须等于请求需求，`当前成员关系.列表项`必须有效；否则返回`内部错误`。
6. 形成 `L2需求列表项完整读取请求{头, 当前, 当前成员关系.列表项, 0}`，调用公开 `L2需求结构服务::读取需求列表项完整(...)`。
7. 列表项完整读取回显截止非 G0或状态为`事实代次漂移`，返回`当前性漂移`。
8. 列表项完整读取的`未找到/已退出/属性未设置`说明当前成员关系引用的当前列表项不存在或不完整，返回`内部错误`；`入口拒绝/许可拒绝/引用冲突/资源失败或数量预算不足`分别映射为`入口拒绝/许可拒绝/引用冲突/资源失败`；未知状态、已读取但 `成功()==false` 或没有`列表项`均为`内部错误`。
9. 完整列表项身份必须等于`当前成员关系.列表项`；不等返回`引用冲突`。
10. 使用`读取需求完整`取得的需求事实和`读取需求列表项完整`取得的完整列表项事实逐字段互证`所属存在、目标宿主存在、目标特征定义、目标状态合同`。任一不等返回`引用冲突`。

上述步骤完成后，v0.1 第 6.2—6.4 节继续生效。成功快照的`所属列表项`必须赋值为完整读取结果中的列表项事实，不得赋值为成员读取结果中的简化身份投影。

## 5. 修订后的错误与恢复合同

| 条件 | 公开状态 |
| --- | --- |
| 成员读取或完整列表项读取回显非 G0；任一返回`事实代次漂移` | `当前性漂移` |
| 当前成员关系缺失、关系指向的列表项未找到/已退出/属性未设置、成员成功载荷缺项 | `内部错误` |
| 完整列表项身份与成员关系端点不一致，或需求与完整列表项四字段不一致 | `引用冲突` |
| 完整列表项读取入口拒绝、许可拒绝、资源失败/数量预算不足 | 保持`入口拒绝`、`许可拒绝`、`资源失败`分账 |
| 完整列表项已读取但成功谓词不成立、载荷缺失、未知枚举或其它异常 | `内部错误` |

所有非成功继续零裁决。调用方遇到`当前性漂移`只能取得新 G 发起一轮新裁决；不得在本函数内重试，也不得用简化列表项投影降级继续。
