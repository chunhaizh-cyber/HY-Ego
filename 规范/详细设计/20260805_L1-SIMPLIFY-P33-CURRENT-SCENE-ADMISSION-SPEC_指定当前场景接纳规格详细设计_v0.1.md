## 1. 目标与完成边界

本叶原位扩展唯一 `L1场景结构服务`，为 4200 第一项写能力“在指定当前场景创建实际存在并接纳”补齐最早场景侧 provider：

```text
指定正式世界根 + 目标当前场景 + 期望事实代次
-> P18 非阻塞取得不可变世界登记
-> P19 非阻塞读取指定根完整当前场景结构
-> 场景事实所有者确认目标恰在当前可达场景集合
-> 返回目标场景、直接成员关系类型和精确事实截止组成的不可变接纳规格
```

完成必须同时成立：

- 任意当前可达场景均可形成规格，包括正式根场景、无子场景和无成员场景；
- 直接成员关系类型只取自 P18 正式登记，目标当前性只取自 P19 完整结构结果；
- 规格事实截止精确等于 P19 本轮 P17 快照代次，并且必须等于请求期望事实代次；
- P18/P19 任一许可拒绝立即返回，不等待、不 sleep、不重试；
- P19 的结构诊断原样保留，目标缺失、重复或载荷矛盾不返回部分规格；
- 函数不读取原始 L1 快照、不取得锁、不保存缓存、不扫描猜测场景或关系类型；
- 规格只供后继原子创建组合器消费，不产生任何机器事实写入。

本叶不创建实际存在、不形成存在资格规格、不提交 L1 写集、不发布归属关系，也不设计 P32 六写门面、治理白名单路由、特征/状态/动态写入、移动、移除、动作动态、因果、任务/结算、恢复装配、运行期接线、旧入口删除、集成验收或 STEP-5。

## 4. DTO、公开函数与完整性

在 `L1场景结构.数据.h` 追加：

```cpp
inline constexpr std::uint32_t 当前场景接纳规格规则版本 = 1;

struct 当前场景接纳规格请求 final {
    std::uint32_t 合同版本 = L1场景结构合同版本;
    std::uint32_t 世界规则版本 = 世界登记规则版本;
    std::uint32_t 规格规则版本 = 当前场景接纳规格规则版本;
    世界结构节点身份见证 指定世界根;
    世界结构节点身份见证 目标当前场景;
    std::uint64_t 期望事实代次 = 0;
    friend bool operator==(const 当前场景接纳规格请求&,
        const 当前场景接纳规格请求&) = default;
};

struct 当前场景接纳规格 final {
    std::uint32_t 合同版本 = L1场景结构合同版本;
    std::uint32_t 世界规则版本 = 世界登记规则版本;
    std::uint32_t 规格规则版本 = 当前场景接纳规格规则版本;
    世界结构节点身份见证 指定世界根;
    世界结构节点身份见证 目标当前场景;
    世界结构节点身份见证 直接成员关系类型;
    std::uint64_t 事实截止代次 = 0;
    friend bool operator==(const 当前场景接纳规格&,
        const 当前场景接纳规格&) = default;
};

struct 当前场景接纳规格结果 final {
    世界结构状态 状态 = 世界结构状态::入口拒绝;
    std::optional<当前场景接纳规格> 规格;
    std::vector<世界结构缺项诊断> 缺项诊断;
    friend bool operator==(const 当前场景接纳规格结果&,
        const 当前场景接纳规格结果&) = default;
};
```

追加唯一公开函数：

```cpp
当前场景接纳规格结果 L1场景结构服务::形成当前场景接纳规格(
    const 当前场景接纳规格请求& 请求) const;
```

函数不 `noexcept`；捕获 `std::bad_alloc` 为 `资源失败`，其它异常为 `内部不一致`。成功时状态固定为 `已读取`、规格存在、诊断为空。非成功时规格必须为空；只有 P19 `内部不一致` 分支原样携带其稳定诊断，其它非成功和 P33 自身发现的 provider 坏成功诊断组固定为空，不临场发明第二诊断枚举。

完整规格必须满足：三个版本精确匹配；根、目标和关系类型均为非零普通节点见证；目标来自 P19 当前场景组恰一项；根等于 P18 登记根和 P19 指定根；直接成员关系类型编码精确等于 P18 登记；事实截止非零且等于请求期望代次和 P19 结果截止。

## 5. 固定形成流程

### 5.1 provider 前校验

在任何 provider 调用前校验：

- 合同、世界规则和规格规则版本；
- 指定根与目标均为非零普通节点见证；
- 期望事实代次非零。

任一不成立返回 `入口拒绝`、空规格、空诊断，P18/P19 调用均为0。

### 5.2 P18 登记定位

P33 函数体直接调用 `世界登记服务::尝试读取当前登记({世界登记合同版本, 世界登记规则版本})` 恰1次。随后 P19 按其自身冻结算法还会内部调用 P18 恰1次，因此完整成功调用链中 P18 总调用数为2；两次都必须保持非阻塞并独立允许许可拒绝。固定映射：

| P18 结果 | P33 结果 |
| --- | --- |
| `许可拒绝` | `许可拒绝`，立即返回 |
| `资源失败` | `资源失败` |
| `已读取` 且完整 | 继续 |
| `登记未加载`、`内部不一致`、空/坏成功或其它状态 | `内部不一致`，诊断空 |

登记根与请求根不等返回 `未找到`，P19 调用0。登记的直接成员关系类型必须非零，且按 P18 合同为普通节点；不得使用 `已验证事实代次` 与请求代次比较。

### 5.3 P19 当前结构互证

用请求版本、规则和根构造 `当前世界结构读取请求`，由 P33 函数体直接调用本服务 `读取当前世界结构` 恰1次。该函数内部仍按 P19 固定调用 P18/P17；P33 不读取 P17、不取得或传递许可，也不得把 P19 内部调用计入 P33 自身的直接 provider 调用数后误判为重复实现。

- `未找到`、`许可拒绝`、`资源失败`按同名状态返回；
- `内部不一致` 返回空规格并逐项原样保留 P19 已稳定排序诊断；
- 入口拒绝、写状态、空成功、`完整=false`、事实内诊断非空、根/版本错误或顶层诊断与事实矛盾均视为 provider 坏成功，返回 `内部不一致`；
- 成功事实截止不等于请求期望代次返回 `版本漂移`，不重试；
- 成功当前场景组必须按 P19 合同稳定有序，目标编码必须出现恰一次且节点见证与请求完全相等。

目标未出现返回 `未找到`；出现多次、编码相同但类型不等或当前场景组违反排序/唯一性返回 `内部不一致`。根场景可作为目标；目标没有子场景或当前成员时仍合法成功。

### 5.4 形成规格

全部校验成立后逐字段复制：

```text
指定世界根       <- P19 成功事实.指定世界根
目标当前场景     <- P19 当前场景组中的唯一目标见证
直接成员关系类型 <- P18 登记.直接成员关系类型 + 普通节点类型
事实截止代次     <- P19 成功事实.事实截止代次
```

函数不读取 P19 当前成员关系来猜测类型，不检查或创建待接纳成员，不保存规格。返回后世界可能推进；后继写入口必须把 `事实截止代次` 原样作为唯一 L1 提交期望代次，漂移由 L1 拒绝，禁止静默重取后继续原请求。

## 6. 状态、异常、并发与生命周期

| 条件 | 状态 | 载荷 | 副作用 |
| --- | --- | --- | --- |
| 请求版本、身份或零代次错误 | `入口拒绝` | 空 | provider调用0 |
| P18/P19许可竞争 | `许可拒绝` | 空 | 立即返回、零重试 |
| 请求根非正式根或目标不在当前场景组 | `未找到` | 空 | 零写入 |
| P19截止不等于期望代次 | `版本漂移` | 空 | 零重试 |
| 登记未加载、坏成功或目标重复 | `内部不一致` | 空/诊断空 | 不返回部分规格 |
| P19结构矛盾 | `内部不一致` | 空/P19稳定诊断原样 | 不返回部分规格 |
| 分配失败 | `资源失败` | 空 | 零写入 |
| 完整目标当前 | `已读取` | 完整规格 | 零写入 |

本函数不取得 `L1场景结构服务::锁_`，不持锁跨 provider 调用，也不建立循环或缓存。显式 P18 调用与 P19 内部 P18 调用可能分别许可拒绝；任一拒绝都立即结束。登记在服务生命周期内不可变，两次读取不构成事实截止；当前性只由 P19 截止表达。

规格由调用方拥有，只对其非零截止有效。服务和 provider 生命周期由装配宿主负责；本叶不设计生产装配或恢复后登记加载。
