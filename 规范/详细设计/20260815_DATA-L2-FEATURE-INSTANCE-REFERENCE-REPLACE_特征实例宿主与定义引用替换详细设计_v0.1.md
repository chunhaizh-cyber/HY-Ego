# DATA-L2 特征实例宿主与定义引用替换详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-FEATURE-INSTANCE-REFERENCE-REPLACE`

## 1. 目标与边界

补齐 `计划/数据服务最终需求清单.md` 的 `DATA-EXT-03`：在唯一 `L2特征结构服务` 中，以一笔特征实例 owner-scoped 写集原子替换一个当前特征实例的宿主存在引用与特征定义引用，并使旧引用保留为可核对的历史退出事实。

本叶把宿主与定义视为一份完整引用对：每次替换都同时退出两条旧关系、建立两条新关系。实例身份、族归属、实例生命周期和可选当前值保持不变。本叶不判断新宿主与新定义是否具有业务适用性，不新增特征节点族、owner、实例副本、当前值、业务专用入口或跨 owner 写集。

## 2. 当前事实与唯一裁决

1. 4230 已冻结：实例节点、宿主 / 定义关系和实例当前值只由特征实例 owner 写；关系替换、退出、幂等与历史读取属于结构合同。
2. 当前公开面已有实例新增、当前 / 历史完整读取、按存在读取、当前值增改退和实例退出，但没有实例引用替换入口。
3. 当前 `形成F2特征实例事实(...)` 强制两条关系创建代次等于实例节点创建代次，只适用于首次建立。替换后必须改为：两条当前关系创建代次相等、均不早于实例创建代次且不晚于投影截止；实例节点创建代次继续作为实例生命周期起点。
4. 单独替换一条关系会让同一实例的引用对分属不同发布代次，也无法用一份结果证明完整结构。因此公开入口固定替换完整引用对，不提供单角色 variant 或两个分步写入口。
5. 新宿主必须经 `L2存在结构服务::读取存在身份来源` 证明当前存在来源；新定义必须经 `L2特征结构服务::读取完整统一特征定义` 证明当前完整定义。数据层只核对强类型端点和生命周期。
6. 同键同完整请求返回首次结果；同键异义冲突。资源失败、异常或发布结果未知必须保留原完整请求重放；只有明确零变化且无首次结果的事实代次漂移可由上层正式重读后重组。

## 3. 精确公开 ABI

在 `海中鱼巣/领域/L2特征结构.数据.h` 增加：

```cpp
struct L2特征实例旧引用退出投影 final {
    稳定编码 宿主关系稳定编码;
    L2存在身份 旧宿主存在;
    L2生命周期 宿主关系生命周期;
    稳定编码 定义关系稳定编码;
    L2特征定义身份 旧特征定义;
    L2生命周期 定义关系生命周期;
    friend bool operator==(const L2特征实例旧引用退出投影&,
        const L2特征实例旧引用退出投影&) = default;
};

struct L2特征实例引用替换请求 final {
    L2结构请求头 请求头;
    L2结构幂等身份 幂等身份;
    L2特征实例身份 特征实例;
    L2特征实例自有关系引用 旧引用;
    L2存在身份 新宿主存在;
    L2特征定义身份 新特征定义;
    friend bool operator==(const L2特征实例引用替换请求&,
        const L2特征实例引用替换请求&) = default;
};

struct L2特征实例引用替换结果 final {
    L2结构结果头 结果头;
    std::optional<L2特征实例事实> 当前特征实例;
    std::optional<L2特征实例自有关系引用> 当前自有关系;
    std::optional<L2特征实例旧引用退出投影> 已退出引用;
    bool 成功() const noexcept;
    friend bool operator==(const L2特征实例引用替换结果&,
        const L2特征实例引用替换结果&) = default;
};

inline bool L2特征实例自有关系引用有效(
    const L2特征实例自有关系引用&) noexcept;

inline bool L2特征实例旧引用退出投影完整(
    const L2特征实例旧引用退出投影&, std::uint64_t 退出代次) noexcept;

inline bool L2特征实例引用替换请求有效(
    const L2特征实例引用替换请求&) noexcept;
```

`L2特征实例引用替换请求有效` 固定要求：共同请求头有效且期望代次非零；幂等身份、实例、新宿主和新定义身份非零；两条旧关系编码非零且互异。

在 `海中鱼巣/领域/服务.L2特征结构.ixx` 的 `L2特征结构服务` 原位增加：

```cpp
L2特征实例引用替换结果 替换特征实例引用(
    const L2特征实例引用替换请求& 请求);
```

## 4. 成功与非成功形状

成功只允许 `已提交` 或 `精确重复`；结果截止非零，变更代次存在且等于结果截止。三份 optional 全部存在，并满足：

- `当前特征实例` 在结果截止未退出，身份等于请求实例，宿主 / 定义等于新端点；实例创建代次和可选当前值不因替换改变；
- `当前自有关系` 两编码非零、互异，且均不同于已退出的两条旧关系；
- `已退出引用` 的两个端点等于写前端点，两条关系退出代次均等于结果截止，创建代次合法且两条旧关系编码互异；
- 新旧端点对至少有一项不同，禁止把完全相同端点对包装为替换成功。

全部非成功结果的三份对象 optional 为空。写前拒绝、L1 明确零发布非成功和无法确认发布的失败，其变更代次为空；只有 L1 已确认首次发布或精确重复的首次结果、但发布后正式读回发现内部矛盾时，返回 `内部不一致` 并携带已知首次变更代次，禁止把已发生发布伪装成零变化。坏请求为 `入口拒绝`；实例 / 新端点未找到或已退出沿正式读取状态返回；旧关系与当前实例关系不一致、完全相同端点对、错端点或错关系类型为 `引用冲突`；陈旧守卫为 `事实代次漂移`；同幂等异义为 `幂等冲突`；资源、许可、发布未知和内部结构矛盾按现行状态分账，不猜成功。

## 5. 原子写入与读回

1. 校验纯值请求，读取当前特征关系类型登记。
2. 形成特征实例 owner 写集：建立“实例 -> 新宿主”的宿主关系和“实例 -> 新定义”的定义关系；`退出事实` 精确包含并排序两条旧关系；写入幂等身份复用特征实例 owner 的现有映射。
3. 安全取得当前事实代次。若等于请求守卫，正式读取当前完整实例：旧关系编码必须逐字段匹配，当前端点对不得与新端点对完全相同；随后在同一守卫下读回新宿主来源和新完整定义。任一步失败均零写返回。
4. 若当前代次已变化，不用新事实改写请求，直接提交原写集，让 L1 裁决精确重复、漂移或幂等冲突。
5. 提交一次写集。首次成功必须形成发布且重试边界不适用；精确重复必须零新发布且按原幂等身份收敛。成功映射恰有两条互异新关系编码。
6. 以写入代次为历史截止读回完整实例及当前自有关系，读回两条旧关系历史事实，并核对 owner、类型、源实例、旧端点、角色、生命周期和同代退出。
7. 首次提交时把写前实例与写入截止实例逐字段比较：身份、实例生命周期和可选当前值保持；只允许宿主、定义和两条自有关系编码变化。精确重复以首次写入截止的历史投影重现同一结果。
8. 任一成功形状矛盾返回 `内部不一致`。不新增轮询、sleep、deadline、内部重试或故障 seam。

## 6. 完整读取兼容修正

`形成F2特征实例事实(...)` 的关系代次判定机械修订为：

```text
宿主关系创建代次非零
+ 定义关系创建代次非零
+ 两条关系创建代次相等
+ 关系创建代次 >= 实例节点创建代次
+ 关系创建代次 <= 投影截止
+ 两条关系在投影截止仍为当前
```

首次新增仍自然满足“关系创建代次等于实例创建代次”；替换后完整当前 / 历史读取选择指定截止上唯一当前引用对。族归属关系及身份来源仍与实例节点首次建立同代，不随引用替换变化。
