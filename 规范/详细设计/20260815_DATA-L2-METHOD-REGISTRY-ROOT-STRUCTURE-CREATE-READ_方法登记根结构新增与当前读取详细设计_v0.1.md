# DATA-L2 方法登记根结构新增与当前读取详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-METHOD-REGISTRY-ROOT-STRUCTURE-CREATE-READ`
状态：设计就绪、待激活

## 1. 目标与完成边界

在唯一 `L2方法结构服务` 和独占方法 owner 内，建立一个永久方法登记根，并提供：

```text
读取全部当前方法登记根
+ 建立方法登记根
+ 按角色读取当前方法登记根
```

同一叶同时建立正式 `L2方法结构.数据.h`、方法 owner 交付、根结构服务和工程登记，避免产生未被任何生产模块编译的孤立 DTO 头。

本叶不创建普通方法登记、方法首、治理虚拟存在、条件、结果、动作入口、参数、禁止项、生命周期迁移、候选索引、聚合、普通应用装配或阶段 19 BIZ provider。方法登记根永久存在，因此不公开替换或退出入口。

## 3. 公开 DTO

新文件：`海中鱼巣/领域/L2方法结构.数据.h`。

它在 `namespace 海中鱼巣` 内定义：

```cpp
enum class L2方法登记根角色 : std::uint8_t {
    方法登记根 = 1
};

struct L2方法登记根角色事实 final {
    L2方法登记根角色 角色 = L2方法登记根角色::方法登记根;
    friend bool operator==(const L2方法登记根角色事实&,
        const L2方法登记根角色事实&) = default;
};

struct L2方法登记根事实 final {
    L2方法身份 根方法;
    L2节点族身份来源事实 身份来源;
    L2方法登记根角色事实 根角色;
    L2结构幂等身份 首次幂等身份;
    std::uint64_t 首次期望事实代次 = 0;
    friend bool operator==(const L2方法登记根事实&,
        const L2方法登记根事实&) = default;
};
```

请求与结果逐字为：

```text
L2当前方法登记根组读取请求{请求头}
L2方法登记根建立请求{请求头, 幂等身份, 角色}
L2当前方法登记根读取请求{请求头, 角色}
L2当前方法登记根组读取结果{结果头, vector<方法根>, 成功()}
L2方法登记根写入结果{结果头, optional<方法根>, 成功()}
L2当前方法登记根读取结果{结果头, optional<方法根>, 成功()}
```

公共纯值 helper 只新增：

```cpp
L2方法登记根建立请求有效(const L2方法登记根建立请求&) noexcept;
L2方法登记根事实完整(const L2方法登记根事实&, std::uint64_t) noexcept;
```

`L2结构幂等身份有效` 复用共同头唯一实体，不在方法头重复声明或定义。读取请求验证由服务内部完成，不增加 BIZ 未要求的第二套公共 helper。

`L2方法登记根事实完整` 固定要求：

- 截止非零、根方法身份非零；
- 身份来源在截止完整，节点族为方法，节点编码等于根方法；
- owner、节点、族锚点、关系类型和族归属关系五份生命周期均未退出；
- 根角色精确为 `方法登记根`；
- 首次幂等身份、首次期望事实代次非零，且首次期望事实代次严格早于结果截止。

根 DTO 不携带方法首、名称、普通方法生命周期、条件、结果或动作入口。角色关系的编码和生命周期属于服务同截止验证材料，不形成第二公开事实来源。

## 4. 请求与结果形状

- 全组读取请求只要求合同版本 1；`期望事实代次=0` 表示在一个 L1 原子读取许可内选择调用时最新快照，非零值是乐观当前守卫。
- 建立和单根读取要求合同版本 1、非零期望事实代次；建立另要求非零幂等身份和唯一角色。
- 写成功只接受 `已提交 / 精确重复`，截止非零、变更代次存在且等于截止、optional 根存在完整，截止严格晚于首次期望代次。
- 单根读成功只接受 `已读取`，截止非零、变更代次为空、optional 根存在完整。
- 全组读成功只接受 `已读取`，截止非零、变更代次为空，允许 0—1 根；根存在时必须完整且角色唯一。
- 任一非成功载荷为空、变更代次为空。服务拒绝未知枚举、成功空 optional、第二根、坏角色、混代和错误首次见证。

非零读取守卫成功时，结果截止必须等于请求守卫；不相等返回零变化 `事实代次漂移`。建立成功返回首次提交截止；精确重复可以返回早于当前全局截止的同一首次结果，调用方若需当前证明必须再正式读取。

## 6. 私有登记与根写集

方法 owner 内部固定登记：

```text
方法身份来源登记幂等身份     = 0x4C32'4944'5352'430B
方法族锚点本地键             = 0x020B'6001
方法族归属关系类型本地键     = 0x020B'6002

方法根结构登记幂等身份       = 0x4C32'4D52'4F4F'0001
方法根角色锚点本地键         = 0x020B'6101
方法根角色关系类型本地键     = 0x020B'6102
首次请求见证属性类型本地键   = 0x020B'6103
```

首次请求见证属性类型固定为 `U64组`。根角色关系方向为“根方法 -> 方法根角色锚点”，角色为 1。

首次建立写集固定本地键：

```text
根方法节点             = 0x020B'1001
方法族归属关系         = 0x020B'1002
方法根角色关系         = 0x020B'1003
首次请求见证值         = 0x020B'1004
```

一份方法 owner 写集原子包含根方法节点、方法族归属关系、方法根角色关系、`[首次幂等身份.值, 首次期望事实代次]` 两项 U64 见证值及其当前属性槽。节点、两关系和值事实同代创建。普通方法、方法首和生命周期不进入该写集。

两项内部登记幂等身份是方法 owner 保留值；公开请求使用相同值固定入口拒绝。公开请求向 L1 幂等身份逐值映射，不增加通用前缀，维持 owner 全局幂等域。

## 7. 读取、建立与首次结果

全组读取恰调用一次 L1 owner-aware 关系类型闭包投影：入口关系类型为方法根角色关系类型；源节点属性选择首次请求见证；源节点源关系选择方法族归属关系；其它关系选择为空。

一次同截止投影必须同时证明方法 owner、根节点、角色关系、角色锚点、族归属和首次见证。允许成功空组或一个根；第二根、重复角色、同根多角色、错 owner / 锚点 / 方向 / 关系类型、见证缺失 / 重复 / 非两项、生命周期已退出或混代均为 `内部不一致`。

单根读取复用同一次全组读取核心并选择唯一角色。非零同代全组成功但根不存在固定返回 `未找到`、空 optional、零变更；与概念四根不同，方法登记根在阶段 19 前允许合法尚未建立，因此不得把同代缺失误报内部不一致。

建立入口在私有锁内：

1. 验证请求和保留幂等身份；
2. 以非零守卫预读全组；
3. 已有根且首次幂等身份 / 首次期望代次 / 角色与请求全等，直接返回首次 `精确重复`；已有根但首次请求不同返回 `引用冲突`；同幂等身份被异义写集占用返回 `幂等冲突`；
4. 根缺失时提交固定写集一次；预读漂移时仍只提交原固定写集一次，用于收敛此前发布未知，不重组守卫、不循环；
5. L1 成功 / 精确重复后，经唯一写端口读取首次写入材料，逐字段互证首次规范化写集和首次写入结果；
6. 按首次结果映射取得根节点、族归属关系、角色关系、见证值四个非零互异编码，并以首次提交截止 owner-aware 历史读回完整根事实；
7. 返回首次截止作为事实截止与变更代次。任何发布后无法闭合的结果映射 `资源失败` 或 `内部不一致`，不得猜测未发布。

资源失败、异常和发布结果未知统一保留原完整请求重放；服务不换幂等身份、不 sleep、不忙重试、不从日志 / SQL / 缓存猜测根。
