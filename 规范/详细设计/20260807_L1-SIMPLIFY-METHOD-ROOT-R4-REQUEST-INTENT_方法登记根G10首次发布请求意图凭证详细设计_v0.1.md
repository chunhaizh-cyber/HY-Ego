## 2. 目标与最大边界

唯一目标：由方法领域协议所有者把版本化首次发布公开请求确定编码为一个完整 G10
`L1领域意图凭证`，使后继原子发布者可以用同一凭证做 provider 前幂等探测并把逐字同义限定为
公开输入相同。

本叶冻结生产操作标签和请求编码，但下列事项全部为零：事实读取/写入、R1/R2/P15/L1 调用、
幂等键或幂等域映射、稳定编码分配、空仓首次证据模式、执行证据、结果见证、锁、事务、提交、
读回、缓存、SQL、日志机器事实和生产装配。它不创建方法登记根、方法首、条件、结果、动作
入口、需求、任务、服务候选、安全或因果事实。

当前只覆盖同一生产进程正常存活期间的纯值形成；不覆盖崩溃、异常终止、断电、重启或跨进程
恢复/重放。

        const 方法登记根首次发布幂等身份&) = default;

struct 方法登记根首次发布意图请求 final {

enum class 方法登记根发布意图状态 : std::uint8_t {

幂等身份只允许 `1..0x00FF'FFFF'FFFF'FFFF`，这里只参与公开请求同义编码，不映射为
`写集幂等键`。顶层或嵌套合同/规则版本不匹配返回版本漂移；身份越界或 R2 预期事实代次为0
返回入口拒绝。只有已形成携带凭证；全部非成功凭证为空。分配失败返回资源失败，未分类异常或
哈希返回全零为内部不一致。

## 5. 唯一身份与确定编码

正式树中生产幂等域 `0x01—0x10` 已有所有者，`0x15001101U` 与顺序586均无正式占用。
本叶只把 `0x15001101U` 冻结为“方法登记根首次发布”生产操作标签；它不因此分配 `0x11`
幂等域，后继必须另行裁决并复核当时占用。

凭证固定为：

```text
请求意图组 = L1方法登记根领域意图组（G10）
请求意图格式版本 = L1请求意图格式版本（1）
请求意图操作标签 = 0x15001101U
请求意图摘要 = 下述 SHA-256
领域结果计划摘要 = 全零
```

摘要输入逐字固定为以下网络大端序列：

```text
ASCII "HZY-L1G10"
-> 请求意图格式版本 U32
-> 操作标签 U32
-> 入口变体 U8（1）
-> 顶层合同版本 U32
-> 顶层规则版本 U32
-> 幂等身份值 U64
-> R2 写集请求合同版本 U32
-> R2 写集请求规则版本 U32
-> R2 预期事实代次 U64
```

编码只覆盖公开请求声明字段。R2 草案/结果、当前快照、provider 结果、幂等键、稳定映射、
执行证据、日志、地址、线程、随机数和系统时间一律不编码。相同公开输入重复或并发形成逐字段
相等凭证；任一公开字段变化必须改变摘要。不得从结构体内存布局、RTTI、显示名称或旧主键
编码。

## 6. 分账与后继消费边界

| 情形 | 状态 | 凭证 | 调用/写入 |
| --- | --- | --- | --- |
| 顶层或 R2 版本不匹配 | 版本漂移 | 空 | 全0 |
| 身份为0、越过56位或截止为0 | 入口拒绝 | 空 | 全0 |
| 合法公开请求 | 已形成 | 唯一完整G10凭证 | 仅纯值编码 |
| 哈希全零/未知异常 | 内部不一致 | 空 | 全0 |
| 分配失败 | 资源失败 | 空 | 全0 |

后继发布者必须使用同一个 `方法登记根首次发布意图请求` 同时调用 R4 与 R2，逐字段确认 R2
输入一致；再另行冻结幂等域/映射、P15 provider 前探测、非空仓事实互证、一次提交、稳定编码
映射和 R1 定位凭证形成。R4 不接受发布者把 R2 草案或当前事实加入请求意图后重新定义同义。

方法登记根首次发布发生在已有 L1 世界/结构之后，不能把通用空仓或领域空仓夹具当生产证据。
本叶不裁决后继执行证据的精确 provider/见证数量，但明确禁止用日志、默认 L1 身份、首个快照
事实或业务事实编码补造。
