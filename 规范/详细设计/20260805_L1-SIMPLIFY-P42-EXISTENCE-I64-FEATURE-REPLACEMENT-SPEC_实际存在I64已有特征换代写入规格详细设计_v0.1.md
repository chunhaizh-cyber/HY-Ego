# L1-SIMPLIFY-P42 实际存在 I64 已有特征换代写入规格详细设计 v0.1

日期：2026-08-05

## 1. 目标、身份与完成边界

本叶原位扩展唯一 `L1实例特征服务`，新增一个零事实写入的单项换代规格 provider：

```cpp
实际存在I64已有特征换代写入规格结果
L1实例特征服务::形成实际存在I64已有特征换代写入规格(
    const 实际存在I64已有特征换代写入规格请求& 请求) const;
```

它在调用方给出的一个非零 `期望事实代次` 下，互证指定实际存在、指定 I64 特征定义、唯一既有实例槽、当前值、写前来源、新值、新来源和 P8 四个登记节点，返回调用方拥有的不可变纯值规格。规格只描述一项完整换代的写前权威材料，不提交 L1，不形成 4170 批次账，不分配稳定编码、本地键或摘要。

本叶不重复 P10 单项换代写入口。P10 会自行提交一个 `0x07` 写集，逐项调用会形成多个事实代次，不能满足 4170 完整批次语义。后继换代批次发布者必须消费一组 P42 规格，形成一个确定性 L1 v2 写集和一条 P39/P38 换代批次记录，再由后继世界树业务第三写透明委托。

本叶不进入完整换代批次发布、P32/P41 后继第三写、混合批次、状态/动作动态、因果、任务/结算、恢复装配、运行期接线、旧入口删除、集成验收或 STEP-5。

## 5. 固定执行流程

函数取得既有 P8 `recursive_mutex` 后固定执行：

1. 校验规格两版本、非零期望代次、当前事实、写前来源资格和新来源三个读取请求完整；写前来源资格的存在编码必须等于当前事实来源编码；失败返回 `入口拒绝`。
2. 登记未加载返回 `登记未加载`；实际存在 provider 未绑定返回 `入口拒绝`。
3. 调用 P7 `读取实际存在(请求.当前事实.宿主)` 恰一次；非 `已读取` 按现有映射返回，坏成功为 `内部不一致`。
4. 调用 P8 `读取实际存在I64实例特征(请求.当前事实)` 恰一次；必须已读取且事实、宿主关系、定义关系完整并逐字段等于请求。
5. 调用 P2 `读取I64特征定义(请求.当前事实.定义)` 恰一次；新值越界返回 `入口拒绝`。
6. 调用 P7 `读取实际存在资格(请求.写前来源资格)` 恰一次；资格事实的存在编码必须等于写前事实来源编码。
7. 调用 P7 `读取实际存在(请求.新来源)` 恰一次。
8. 宿主与新来源的世界根必须相等，跨世界返回 `入口拒绝`；上述五个结果的事实截止必须全部等于请求期望代次，否则返回 `事实代次漂移`。写前来源资格不携带世界归属，不从显示、历史关系或扫描补造。
9. 依固定顺序读取登记的服务身份、宿主槽关系类型、定义模板关系类型和当前 I64 值属性类型四节点；每项只读一次且截止必须相等。退出、错种类、重复编码或坏形状为 `内部不一致`。
10. 调用 `L1_.读取完整快照({})` 恰一次；许可/资源/内部状态按现行 P8 状态映射，截止不等返回 `事实代次漂移`。
11. 在该快照调用既有 `检查宿主定义唯一性`；必须恰一匹配。随后逐项确认唯一实例槽、两结构关系、当前值和当前属性槽就是请求/P8 写前见证；零匹配为 `未找到`，多匹配或任何结构矛盾为 `内部不一致`。
12. 构造完整不可变规格并返回 `已读取`。任何坏成功或空规格为 `内部不一致`。

P7/P8/P2/L1 各调用结果先复制为调用方自有值，不跨函数保存许可或引用。没有 sleep、隐式重试、第二提交、SQL、材料文件、进程缓存或批次账读取。

## 6. 状态、并发与失败边界

| 条件 | 结果 |
| --- | --- |
| 请求版本/形状错误、写前来源资格编码不匹配、新值越界、新来源跨世界 | `入口拒绝` |
| P8 登记未加载 | `登记未加载` |
| 宿主、定义、新来源或指定当前事实确定未找到 | `未找到` |
| 任一截止不同、快照截止不同 | `事实代次漂移` |
| P7/P8/P2/L1 许可拒绝 | 映射到现有可表达状态并立即返回；若 P15 实际接口无法无损映射，激活前退回计划支撑 |
| 写前事实请求与读回矛盾、重复槽/关系/值、错类型、悬空、坏成功 | `内部不一致` |
| 分配失败 | `资源失败` |
| 全部互证且恰一当前槽 | `已读取` + 完整规格 |

所有非 `已读取` 结果的 `规格` 必须为空。P42 从不写事实，因此没有撤销、发布后读回、隔离或补偿。并发调用可各自形成等值规格；后继发布必须仍以共同截止作为 L1 v2 期望代次，期间任一事实推进都会零写漂移。

## 7. 后继换代批次发布者边界

后继发布者必须另行冻结：

```text
非空批次身份和规则版本
+ 项目顺序恰为0..N-1、同宿主、定义/实例槽唯一
+ 全部规格同一非零截止、同一四登记见证
+ 每项1新值 + 1属性槽切换 + 1旧值退出，零新节点/新关系
+ 请求意图摘要与首次执行证据摘要
+ P39换代草案和4170完整有序记录
+ 一次P37/P39/P15事务提交
+ 新当前值、旧值历史、结构关系和批次账全量读回
```

它不得逐项调用 P10，不得把 P42 规格直接当 L1 万能写集，不得支持初始/换代混合批次，除非另有正式设计明确授权。
