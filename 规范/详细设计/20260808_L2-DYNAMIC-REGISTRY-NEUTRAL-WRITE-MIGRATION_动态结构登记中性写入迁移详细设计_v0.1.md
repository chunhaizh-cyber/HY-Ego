## 1. 目标与完成边界

把 `L1动态服务::建立登记` 从 legacy 的领域意图、幂等预探测、完整快照和带业务标签提交迁移为正式业务中性 CRUD：领域服务自行校验公开请求并解释结构化结果，只向 L1 提交恰十个节点的不可变中性写集、期望事实代次和不透明幂等键。登记发布成功或精确重复后，领域服务按十个稳定编码从 L1 精确读回同一当前事实代次，再形成现有 `L1动态结构登记`。

本设计保持下列公开合同不变：

- `L1动态登记请求`、`L1动态登记结果`、`L1动态结构登记` 的字段、默认值和可见性；
- `L1动态服务::建立登记(const L1动态登记请求&)`；
- `L1动态服务::读取当前登记() const`；
- `L1动态服务(L1事实基座服务&)` 的构造和对象所有权；
- 登记幂等域 `0x0F` 及现有业务结果枚举。

完成条件是目标两份生产代码在本叶范围内满足：建立登记不再产生或提交业务标签、意图组、入口变体、领域意图凭证，不再调用旧幂等探测、完整快照或 legacy 写入口；恰一次提交固定十节点中性写集；成功类结果的十项映射完整唯一；建立登记和读取当前登记均以中性当前代次首末一致、十节点精确当前读取闭合。

## 6. 建立登记控制流

1. 取得现有递归互斥锁并进入现有异常边界。
2. 校验公开请求；失败返回 `入口拒绝`、无登记。
3. 调用一次 `读取中性当前事实代次`。结果必须为成功、合同版本精确、代次非零；其代次不等于请求期望值时返回 `版本漂移`。不得读取完整快照，也不得要求仓中已有任意节点、关系或值。
4. 映射中性幂等键，形成 §5 固定写集。
5. 物理调用 `提交中性写集` 恰一次。
6. 按 §7 映射非成功；非成功始终不带登记。
7. 对成功或精确重复，核对中性成功合同：合同版本精确、回显幂等键一致、事实代次非零、十项新编码映射完整唯一。首次成功还必须 `是否形成内存权威发布=true` 且重试边界为 `不适用`；精确重复必须发布标志为 false 且重试边界为 `原幂等键读回收敛`。矛盾返回 `内部不一致`。
8. 从本地键 1—10 取得十个非零、彼此唯一稳定编码，执行 §8 读回。读回漂移返回 `版本漂移`；其它读取非成功按业务状态映射；成功但字段矛盾返回 `内部不一致`。
9. 成功时以读回登记更新 `登记_` 定位缓存，并统一返回 `已登记`。首次成功和精确重复在公开合同中均为 `已登记`；区分只用于内部合同校验，不新增业务状态。
10. `std::bad_alloc` 映射 `资源失败`，其它未知异常映射 `内部不一致`。

## 7. 中性写入状态映射

| L1 中性写入状态 | L1动态状态 | 登记材料 |
| --- | --- | --- |
| 成功 | 已登记 | 完成成功合同与精确读回后携带 |
| 精确重复 | 已登记 | 完成重复合同与精确读回后携带 |
| 幂等冲突 | 幂等冲突 | 无 |
| 事实代次漂移 | 版本漂移 | 无 |
| 资源失败 | 资源失败 | 无 |
| 内部不一致 | 内部不一致 | 无 |
| 入口拒绝 | 入口拒绝 | 无 |
| 未找到、已退出 | 未找到 | 无；固定十个全新节点写集正常不应产生此分支 |

任何成功状态而成功合同、映射或读回不完整都升级为 `内部不一致`，不得降级为入口拒绝或伪造登记。

## 8. 十稳定编码精确中性读回

私有读回 helper 由建立登记和读取当前登记共同复用：

1. 输入首次幂等身份和按 §5 顺序排列的十个稳定编码；先验证身份有效、编码全部有效且两两不同。
2. 读取中性当前事实代次 G0；要求成功、合同版本精确、G0 非零。
3. 按固定顺序对十个编码各调用一次 `读取中性当前节点`。每项要求状态成功、合同版本精确、查询编码回显一致、读取事实代次等于 G0、事实存在、事实编码一致、未退出，并符合 §5 的节点种类和中性属性类型表示。成功但形状矛盾属于内部不一致。
4. 再读取中性当前事实代次 G1；要求成功、合同版本精确、G1 非零且 `G1 == G0`。任一节点读取代次或 G1 与 G0 不同返回 `版本漂移`，不返回混代登记。
5. 只在上述全部成立时按本地键固定顺序组装现有 `L1动态结构登记`，其 `事实截止代次=G0`，再以 `L1动态结构登记完整` 验证并返回。

`读取当前登记()` 仅从 `登记_` 复制首次幂等身份和十个定位编码，然后调用上述 helper。无定位缓存或缓存结构不完整返回 `登记未加载`；helper 成功时公开状态为 `已读取`。它不得直接返回缓存，不得调用 legacy 当前读取、完整快照、审计或历史入口。

## 9. 并发、事务、生命周期与失败收口

- 服务对象继续以现有递归互斥锁串行保护登记定位缓存；L1 原子性和幂等由 `提交中性写集` 自身负责。
- 建立登记的写前当前代次核对是领域前置，不替代 L1 提交时的期望代次校验；两者之间发生并发发布时由提交返回事实代次漂移。
- 发布后读回期间发生其它发布时，首末代次不一致返回版本漂移；不缓存混代材料、不重试、不补写、不生成第二幂等键。
- 精确重复必须复用 L1 首次结果中的十编码映射，零新编码、零新发布；同键异中性写集由 L1 返回幂等冲突。
- `登记_` 只定位已发布稳定编码，不是事实副本权威。其生命周期仍绑定 `L1动态服务` 对象；L1 当前读取才裁决节点是否存在、退出和类型是否一致。
- 写前或提交非成功保持零新登记缓存；发布成功后读回异常不能撤销已发布事实，返回内部不一致或版本漂移并保留 L1 已发布状态。
