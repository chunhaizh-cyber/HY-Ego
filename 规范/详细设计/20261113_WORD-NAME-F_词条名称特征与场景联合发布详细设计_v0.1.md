## 1. 目标、基线和边界

源码基线：`0e0dc13d7bb7a7c356677538a8c78370870856ec`。施工树：`D:\worktree\DICT-TRUSTED-LEARNING\海中鱼巣`；分支：`codex/dict-trusted-learning`。

为正式词条 W 配置“概念名称挂接”实例特征 F 和自然语言场景归属。普通名称、指代名称的新增或删除，名称反向引用、F 新当前值、由该变化产生的新状态 S 及场景对 S 的引用，一次组合发布。只有真实状态已存在后才形成原子变化动态，并挂入同一自然语言场景。

本叶是结构提供者，不实现本能函数，不生成子需求，不改变词典文件，不自动接受名称归类，不把词条转成普通存在或创建其副本。方法参数、词条动作目标、归类写回本能、释义转换和概念完善仍由后继叶实现。初次支持动态概念命名属于本叶，不能只使写入口接受而读取仍拒绝。

按用户最新裁决，DATA-L1 负责读写引用完整性、原子性和删除安全。上层只取得本次操作所需当前材料、作名称去重及值变化计算，不增加身份读取器、整组旧快照比较或发布后互证。保留 owner 唯一写入、必要锁、工程错误传播。L1 既有宿主追加/字段修改所要求的联合快照仍提供给 L1；不得声称已删除该底层合同。

## 3. 数据与接口

### 3.1 词条及特征

保留 `新词条信息` 五项及唯一键（语言、规范化合同、规范化词面）。新增独立读回 DTO `新词条挂接信息`，包含旧词条信息、`概念名称挂接特征`、`所属自然语言场景`；`读取词条挂接信息(W)` 使用现词条查询状态体系，不给正常空概念集合赋“未知”含义。

W 新增两个单值正式引用字段：上述 F 和场景。更新普通读取与保护读取的解码器、索引重建读取，允许完整旧格式在启动补齐阶段被读取；补齐结束后的正常新建必须同时给出两个字段。不改变词条旧查询 ABI，旧 DTO 不承担新扩展读回。只缺其一是工程结构错误，不推测另一个。

先天槽 `先天特征类型槽::概念名称挂接 = 1501`（基线未占用）：U64 数组材料、无单位、`概念集合身份判等`、`完整材料精确集合`聚合、全域。所有语言共用类型根，每个 W 持有独立 F。初始值是准确空集合 V，F 历史中的集合材料可有多个，但当前只引用一个 V。

新增私有、仅名称 owner 可调的词条更新参与入口，输入 W、经名称 owner 计算的当前概念集合及名称封存片段。它串行组织该 W 的 F、状态和动态；业务不得直接任意写挂接 F。新增普通公开读口只返回事实，不授权名称写入。

### 3.2 特征候选材料

在 `新特征当前值组准备` 上增加仅词条/状态协作可消费的只读候选材料。精确内容为 F、特征概念、类型根、本次准备采用的当前准确值和 `当前值已改变`。当前准确值从准备内部最终 `核心预期组` 取得，不能用未经规范化的调用输入代替（历史材料可能复用旧 V）。

材料由特征 owner 的私有入口出具，绑定当前准备对象，构造与修改不公开；只在同线程、准备尚未提交的作用域使用。它不是公开当前事实、授权节点或第二 current。名称及词条 owner 不解析特征私有字段，不自行构造 S 的值。

### 3.3 状态和场景受限共同片段

`新_状态类` 增加词条友元参与，接收词条 owner 的 W/F/场景定位和特征 owner 候选。只在 changed 时构造 S。S 准确值引用候选中既有 V；初始场景引用计数为 1，由状态 owner 编码。

`新_场景类` 增加词条场景参与能力。自然语言世界在装配阶段出具只供词条 owner 使用的不可变绑定，固定场景 owner、根场景身份和已初始化的字段键材料；不得在持有特征准备锁时读取可变根引用或回调世界树。词条既有场景字段为所属权威，绑定只是构造协作能力，不是另一个可变所属表。

同一私有请求中，状态 owner 编码新 S 的完整节点并返回本片段局部槽 k；场景 owner 仅追加 `scene→S(k)` 状态列表字段。二者共同封存后只能读，调用者无裸字段写权。若同一操作有多个 S，必须放在同一共享片段，不能跨片段向同一 scene/状态列表键多写。

该路径只构造尚未发布对象，不调用旧 `建立状态/添加状态/增加引用`。不取得状态锁或场景锁，不调用带这些锁的 getter；仅使用初始化时复制的不可变结构键、受限候选及 DATA-L1 读取。初始化完成先于线程启动，运行期不得重新装配或并发初始化这些绑定。

L1 封存要求被追加场景宿主包含在联合预期中：取得该场景单节点当前联合快照，原样交 L1。上层不复核快照；提交时场景变化由 L1 拒绝本批，零事实发布。不得传只读字段预期冒充满足宿主联合预期。不设自动无限重试。

回执定位 S 使用共同片段的新节点数组 k；初始计数与场景引用已生效，不再补挂、补计数或重新读整份结构证明发布成功。场景无状态列表内存缓存，现 L1 索引随发布生效。

### 3.4 名称与反向概念

名称 owner 写 N 自身字段和 N 的组织父边；FC、EC、DC 各 owner 仅写自己的 C→N。新增时由名称 owner 给出 const 的 N 请求，目标概念 owner 经私有 friend 入口补自身引用，并封存为同一片段，反向引用指向该片段局部新 N。私有调用边限制出具者，const 本身不是来源认证。

删除时 N 与 C 已有身份，各 owner 出具删除片段，和 F/状态片段同发。L1 检查所有剩余外部引用；语言知识真实引用指代 N，不能强删或级联删知识。普通删除状态末尾追加 `引用保护`，指代删除沿用已有同名状态；L1 `引用仍存在` 映射该状态，不映射资源失败。

维持普通 N 当前 `(C,W)` 唯一和现三字段格式；指代 N 保留 `(C,W,角色,语言)`、首选限制及来源六字段格式。本叶不声称已统一2210所有名称元数据，不扩大成全量普通名称迁移。

F = 该 W 全部当前普通/指代 N 所指 C 的去重集合。增加另一角色 N 若 C 已在集合，F 不变且不增加命中；删除一个 N 后还有另一同 C/W 的 N，保留 C。删掉最后一个关系后写准确空集合，不能清空 current。取得既有 N 不产生新 S、动态或历史命中。

从目标 W 的当前名称关系索引范围计算集合，不重新核验名称全集。首次初始化为重建当前索引可以扫描一次；不能把启动扫描复制到每次写入口。

## 4. 创建、更新、删除和动态流程

### 4.1 新 W

取得名称挂接类型和准确空集合 V，调用特征 owner 建立独立空 F（合法已有结构，不是 W 空壳）。准备 F 的空集合 current；词条 owner 编码新 W 的完整字段和组织父边；状态 owner 在同一 W 请求追加 S，主体引用本片段 W 槽，场景 owner 加 scene→S。把 W+S+scene 共享片段和 F 核心一次发布。

成功后按回执取得 W/S，完成并结束 F 准备，再更新词条非权威索引；不补造前状态，因此首态无动态。发布零写失败时取消 F 准备，再由特征 owner 删除本次独立且未被采用的空 F；不得删除已复用 V/概念。清理失败按工程故障报告，不伪装完全回滚。

### 4.2 名称变化

名称 owner 持本类协调锁，取得该 W 当前名称关系和计算后的去重 C 集合；形成 N+C 共同片段或删除片段，然后交词条 owner。词条 owner 持词条锁读取自己的 F/场景，并在取得 F 准备锁前取得可用前态材料。

特征 owner 准备新集合 current；若 changed，状态/场景纯构造入口形成 S+scene 共同片段；把 N/C、F、S/scene 一次提交。失败则取消准备，不更新索引和任何名称事实。成功完成 F 后释放特征准备锁；在词条协调仍持有时消费真实两端状态建立并挂接变化动态。最后释放词条、名称锁。

同值的名称角色变更只提交 N/C，没有 F 变化与 S；删除同 C 最后一个 N 才改变 F。重复请求从当前名称身份返回，不重放成功的封存片段。

### 4.3 状态时间及动态

强时间取实际系统 UTC 纳秒，不以节点号、循环序号或 `前时间+1` 代替。建立 S 不要求伪造更晚时间；原子动态要求两端真实时间严格递增及准确值不同。

前态只从该 F 的真实状态中选：先用 L1 目标字段索引定位，读取该 W/F 且准确值等于修改前 current 的状态，按真实 UTC 取最新可用者；不得全表扫描或补造旧 S。没有前态、前态已被清理，或真实时间未严格递增时，不形成动态，保留真实新 S，在返回诊断中列明原因。这是动态形成所需材料判断，不是上层旧快照一致性门禁；名称与 F 不因无前态被拒绝。

有可用两端时，在 F 准备锁释放后复用 `建立原子动态(W,前S,后S)` 及自然语言场景动态挂接。既有动态函数仍可能在发布后发生工程故障；保留实际 N/F/S/动态身份并停止受影响操作，不回滚或伪造完整成功。本叶不承诺动态与前述四方全在一个事务，也不承诺崩溃后自动补造未形成动态。状态与名称不会因此缺失。

当前状态物理格式仍保存主体和特征概念，现 getter 仍返回旧 DTO；本叶受限路径沿用该格式。1160/4212关于从 F 持有链派生这些读值的全局迁移不在本叶，须明确作为既有差距，不把本叶完成写成1160全实现。

## 5. 动态概念命名和旧入口退出

`概念_动态类` DTO 追加名称关系组，初始化登记其私有名称字段；动作、变化读取均输出，动态根仍不命名。提供仅名称 owner 可用的新增/删除封存参与入口；不使动作专用定义保护函数充当通用动态概念 reader。

名称类别分派、端点读取、概念持有关系读取、初始化全集准备、普通名称保护、概念名称查询、词条候选读取均补 DC。世界树名称类构造依赖增加 DC 实例，保持真实同实例装配。DC仅依赖FC、V、二次FC及EC；在世界树头文件把DC成员声明移动到名称服务之前，并同步构造初始化列表。结构初始化也将DC初始化移动到名称初始化之前，避免名称启动读取已有DC关系时服务尚未就绪。

删除被替代的普通创建逐步 CRUD/回滚和普通删除先解绑再重绑；删除 FC 旧绑定/解绑及 EC 对应普通、信息定义版入口；替换并删除旧指代互引准备 DTO、组装和补齐旧预期 helpers。删除前搜索全部调用者并一并迁移，避免保留旁路。L1 公共互引函数不在本叶删除，只记录已失去调用者情况。

已有仍供其它路径使用的保护读取 API 不能盲删；本叶新路径不调用它们重建整组旧证明。只删除所有消费者已被本叶替换的 helper。

## 6. 启动、旧数据和读取

按第5节调整DC先于名称的低层初始化；其余依赖顺序保持。普通启动在自然语言世界初始化完成之后、第一权限人及首批名称种子建立之前，调用具名装配入口，把稳定根场景参与能力及 F/V/S/动态服务连接到词条 owner；名称 owner 取得同一词条实例和三类概念 owner。

装配阶段先为全部既有 W 补齐扩展，再开放新建/名称写入。旧 W 的唯一键、稳定身份、旧 N 不变；从当前 N 推导集合，为 W 增加 F 和所属场景字段。新 F 初值与初态及场景引用同次发布；时间是本次补齐时实际 UTC，不声称原名称建立时间，无前动态。已经完整扩展的 W 只读取其当前材料，不为启动重复生成 S/命中，不按有值无状态自动补造历史（状态可能已正常清理）。

旧 W 补齐与新 W 创建共享 F/状态参与能力，但旧 W 是既有引用，不用局部新 W。一词一事务，允许中途工程失败后下次启动只处理尚未扩展的词条；不形成全词库巨大事务。同一 W 的两个扩展字段必须同次写入。

自然语言世界增加只读 `读取词条场景记录`，明确接受根场景，返回当前状态/动态编码列表及具名读取状态；不改 `读取复制场景` 对含状态动态场景仍未支持的边界。不开放通用场景服务写端口。场景owner另增受限的 `读取词条场景记录(绑定) const`，返回 `新词条场景记录读取结果`：状态枚举为已读取=1、场景不存在=2、资源失败=3，载荷为场景身份、状态编码组、动态编码组。通过L1单次查询目标场景的完整结构解析两个字段列表，取得的是该次当前结构；不遍历状态/动态内容，不作发布后证明。解析错误走工程异常，不返回空列表。旧 `查询状态列表/查询动态列表` vector接口在其它消费者中保留，新入口不得调用其吞失败路径。

## 7. 锁、生命周期与失败

主要操作锁序：名称协调 → 词条协调 → 特征准备 → DATA-L1。概念片段在特征准备前形成并释放概念锁。状态/场景参与的纯构造阶段不取得它们的运行锁，不从特征锁内回调 W、名称或自然语言世界。后置动态在 F 锁释放后使用现有动态/状态/场景锁方向；词条 mutex 非递归，内部采用已加锁读取，不能调用公开 getter 重入。

初始化时将状态/场景构造所需固定 schema 复制为不可变绑定；并发初始化不属于支持操作。缺装配是依赖未就绪，不生成半个 W；引用删除与现有结构变化最终由 L1 处理。场景联合预期冲突是本批零发布，交调用方按最新事实重新处理，不在函数里无限轮询。

状态引用计数在 S+scene 同发后为1；动态后续增加自己的端点引用，维持原机制。W 不增加“最新状态”强引用，不额外永久保留状态；现有场景清理策略继续拥有生命周期。N 外部引用导致删除拒绝时，C/N/F/S/scene 均零变化。

发布前资源失败、预期变化和引用保护分别映射现有具名工程/操作状态。发布成功后回执解析或收尾故障保留事实，不变成资源失败后换身份重建；无跨进程通用重放账。现行函数为 noexcept 的边界按工程终止路径传递，不吞异常成空集合或业务未归类。
