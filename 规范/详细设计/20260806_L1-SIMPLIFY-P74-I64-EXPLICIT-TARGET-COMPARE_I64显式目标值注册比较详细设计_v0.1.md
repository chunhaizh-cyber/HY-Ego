## 1. S0 与最早缺口裁决

P73 已冻结当前双轴根需求唯一读取解释者：它从 P56、P69、P17 取得同根同自我同一非零截止，返回安全与服务两个活动无父根需求、当前实例槽和值、目标状态和值，以及完整关系与字段见证。P73 明确不裁决满足。

3100、5100、4130 与 4180 共同要求需求域不得直接比较原始值；当前满足必须先调用特征、状态或正式判断收束服务。当前正式 P6 虽已实现 I64 目标判断注册比较，但其合同和代码把右值身份固定为 P2 当前上界值：

```text
请求.右.目标值 == 合同.上界值
右值所属节点 == P2特征定义
右值属性类型 == P2上界属性类型
```

因此 P6 可覆盖服务根 `当前值 == I64_MAX` 的方向材料，却不能覆盖安全根 `当前值 > 1`：安全通用定义上界仍为 `I64_MAX`，目标值 1 属于 P72 发布、P73 当前互证的独立目标状态。把 1 伪装成 P2 上界、让 P73/6170/装配直接比较、或复用待激活旧 WORLD-TREE/SELF-GOV 骨架，都会产生第二解释者或绕过 4180 注册。

最早独立叶据此裁决为：在现有特征比较域增加一个按“特征定义 + 目标判断用途”注册的 I64 显式目标值比较 provider。它允许右值来自已登记的目标状态值槽合同，不把右值固定为定义上界；仍由注册选择算法，调用方不能选择或覆盖算法。本叶不命中“大于/等于”模板，不返回满足布尔值。

父子/路径读取依赖当前满足材料而不是其前置；6170 维护、完整自我连接和生产装配均必须消费唯一需求读取与正式比较结果，故都晚于本叶。

## 2. 目标与完成边界

本叶新增三个公开入口：

```cpp
I64显式目标判断比较合同结果 特征比较服务::登记I64显式目标判断比较合同(
    const I64显式目标判断比较合同登记请求& 请求);

I64显式目标判断比较合同结果 特征比较服务::读取I64显式目标判断比较合同(
    const I64显式目标判断比较合同读取请求& 请求) const;

特征比较结果 特征比较服务::比较显式I64目标(
    const I64显式目标判断比较请求& 请求) const;
```

前两者形成、回读一个特征定义的当前显式目标判断注册；第三个函数在一次 L1 完整快照中校验注册、左当前事实和右目标状态事实，返回 4130 三态、具名关系及按请求位形成的安全 `右值 - 左值` 差异。

本叶不读取 P73，不解释根角色、需求、目标比较种类或满足；不写需求、满足、状态、动态、因果、父子、路径、6170 输入、差距、任务或装配事实。注册入口是本叶唯一写入路径；比较和读取均零写。P15 只作为注册写入的未来真实 L1 v2 提交接口及共享资源门禁，不能把其未发布内部 DTO 复制进设计。

## 5. 注册事实、幂等与多合同路由

新登记使用私有幂等域 `0x17`，操作标签固定 `0x50337401`。一次登记只面向一个特征定义，形成：

- 一个普通注册身份节点；
- 一个 I64 组配置值及注册节点当前槽；
- 九条合同字段关系，按角色固定指向特征定义、定义模板关系类型、当前 I64 值属性类型、目标状态值属性类型、目标状态来源服务、单位、维度、分量角色和定义来源服务；
- 配置材料冻结用途、算法族/版本、原始类型、左右角色、差异方向、允许结果位、有效位、边界/量化/误差版本及定义下上界。

P2 定义标记、下界、上界三个值只作定义事实互证，不是显式目标端点。注册成功后的右值可以是任一经当前目标状态值槽互证、属性类型与来源服务符合合同、材料处于定义闭区间的 I64 值。

同幂等身份、规范化请求摘要相同为精确重复并读回同一合同；同身份异摘要为幂等冲突。不同身份可为不同特征定义各形成一项合同；同一“特征定义 + 目标判断用途”出现多个当前有效显式合同为 `内部不一致/注册不唯一`。P6 上界专用合同不进入显式合同集合，也不与本叶互相替代。

登记前验证全部版本、身份、代次、登记与定义编码、实例登记、目标属性类型和来源服务。使用 P15 正式接口一次提交并同锁读回；非成功按 P15/L1 正式状态映射，坏成功为内部不一致。不得自建幂等账、参与者、编码器或缓存。

## 6. `比较显式I64目标` 单函数合同

固定流程：

1. 校验请求版本、非零请求身份/截止、特征定义、左右见证、单位/维度/分量和结果位；失败零 L1 调用。
2. 以请求特征定义和固定目标判断用途从内存登记索引取得唯一当前显式合同；零项返回未注册，多项返回注册不唯一，失效返回注册失效。
3. 可选算法族/版本只作漂移门禁；单位、维度和分量必须等于合同。
4. 调用 L1 `读取完整快照`恰一次；快照截止必须等于请求预期截止，禁止重试、等待或跨快照拼接。
5. 从同一快照回读注册节点、配置、九关系、P2 定义和值域；逐字段等于内存合同。
6. 左值必须为当前实例槽的当前 I64 值，定义关系必须把该槽指向合同特征定义；所属、属性类型、来源、创建代次和预计值逐项匹配。
7. 右目标状态必须当前；其目标值属性槽恰一并指向请求目标值。值所属节点等于目标状态，属性类型等于合同目标状态值属性类型，来源节点等于合同目标状态来源服务，创建代次和预计值逐项匹配。
8. 左右材料均须位于合同闭区间。计算 `compare(左,右)` 得到 `-1/0/1`，映射当前低于目标、达到目标、高于目标；只在请求差异位时做溢出前置并计算 `右 - 左`。
9. 返回注册身份、算法版本、同一截止、实际上下文和完整左右输入回执；未请求载荷保持空。

比较成功不等于满足：安全目标“大于 1”只有后继在 P73 比较种类约束下命中排序 `1` 才满足；服务目标“等于 I64_MAX”只有命中排序 `0` 才满足。P74 不执行这两项模板，不返回 bool，也不持久化结果。

## 7. 非成功、并发与生命周期

- 请求合同版本错误：`入口拒绝/请求合同版本不匹配`。
- 身份、截止、见证或固定上下文不完整：`入口拒绝/请求身份或特征定义不完整`。
- 无当前合同或合同失效：`未注册/未注册`或`未注册/注册失效`。
- 多当前合同：`内部不一致/注册不唯一`，不暴露候选。
- 算法门禁、截止、注册、左右事实或输入回执漂移：`版本漂移/算法版本不匹配`或`版本漂移/输入版本失效`。
- 单位、维度、分量、值域和差异不可表示按 4180 精确拒绝；不得返回半成功载荷。
- L1 许可竞争不适用于阻塞完整快照入口；资源失败映射资源失败，其它坏读回为内部不一致。

服务锁只保护登记请求/合同索引的短时复制与首次确认；不得持锁调用 P15 或 L1。比较取得合同副本后解锁读取快照，返回前若合同被替代或失效则本轮版本漂移。注册历史可保留，但当前路由每定义唯一。
