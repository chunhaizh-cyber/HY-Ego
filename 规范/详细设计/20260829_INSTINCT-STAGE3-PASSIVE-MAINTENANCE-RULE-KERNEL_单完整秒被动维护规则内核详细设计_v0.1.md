## 1. 目标与完成边界

本切片把 6170 v0.6 已冻结的一个完整秒内服务值衰减、服务比例和生存安全根被动回归规则实现为无事实读写、无时间读取、无持久副作用的确定性纯值内核。

```text
完成 = 强类型输入与结果矩阵
    + 单秒 V 衰减全部分支
    + 单秒 A 回归全部分支
    + I64 安全整数实现
    + Debug / Release 专项与 ABI consumer
```

本切片不证明合同全集、到期事件、有效活动或安全门禁已经由生产 owner 完整裁决；不读取时钟、当前值、定义、合同、任务、状态或动态；不推进维护游标；不发布 A/V、状态或动态；不接普通应用和线程。后继聚合入口只有在同一事实截止取得完整权威材料后，才可构造本内核请求。

- 无需求：有效数量 0、无最长等待、到期事件 0。

## 5. 根函数与算法

```cpp
本能单完整秒被动维护结果_v1 计算本能单完整秒被动维护候选_v1(
    const 本能单完整秒被动维护请求_v1& 请求) noexcept;
```

### 5.1 服务值

```text
无有效未满足且无到期事件：D=1
存在未满观察窗需求：D=max(1, D0+floor(D0*t/T))
三十天门禁已成立：无活动目标0；有活动且V>0目标1；V=0保持0
```

普通衰减使用饱和减法。有活动且 `V>0` 时下界为 1；`V=0` 不因活动变成 1。`D0*t/T` 使用无溢出的商余分解或等价检查乘除，不使用浮点和回绕后钳制。

服务比例只在新 V 大于 0 时形成：`P=min(99, 1+floor(V/U))`；新 V 为 0 时比例为 0，且安全分支先进入休眠收敛。

### 5.2 生存安全根

服务值候选形成后按唯一顺序：

```text
A=0 -> 保持0
同秒主动安全已改变A -> 保持传入A并跳过被动回归
Vnew=0且A>=1 -> Anew=1
Vnew>0且A<L -> 读取低位回升门禁
L<=A<=H -> 保持
Vnew>0且A>H -> 向H回落
```

低位允许：`step=max(1,floor((L-A)/100)*P)`，封顶 L。低位禁止：A 不变。低位材料不足：返回 `材料不足`、无载荷。高位：`step=max(1,floor((A-H)/100)*(100-P))`，封底 H。全部计算只在非负 I64 内完成。

## 6. 生产消费边界

本内核不是事实 owner，也不证明输入真实。后继唯一服务生存治理聚合入口必须：

1. 冻结 G0 和本秒完整合同 / 活动 / 到期 / 主动安全 / 回升门禁材料；
2. 从正式安全定义与当前值 provider 读取 A/L/H，从本能根锚点读取 V 实例并读回 V；
3. 逐秒或按已证明等价的分段算法调用本内核；
4. 以最终候选组织 A/V、状态、动态、合同结构和游标的有限 N 原子事务；
5. 提交后独立读回。

生产模块不得把测试请求、默认枚举、空 vector、日志或“当前没有 provider”当成完整集合见证。
