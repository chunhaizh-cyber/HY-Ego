# WORLD-TREE-P1A2 索引发布后读回零版本语义详细设计 v0.3

日期：2026-08-03

状态：P1A2 执行期设计漂移裁决；与 P1A2 v0.3 共同生效

来源问题：`DRIFT-WORLD-P1A2-INDEX-READBACK-EXPECTED-VERSION-UNFROZEN`

## 1. 唯一裁决

`节点直接发布后读回项::预期版本` 在 `当前索引` 和 `已移除索引` 两种读回中固定必须为 `0`。

此处的 `0` 是“该字段对可重建索引不适用”的唯一哨兵，不是索引版本、未知版本、目标节点版本或可以忽略的占位值。索引没有独立稳定身份和版本；任何非零值都在持久准备、候选建立和事实写入前返回 `入口拒绝`。

本裁决在 P1A2 原目标内精确替代此前未冻结的索引读回版本语义。P1A2 v0.2 的显式命名域、私有恢复解码、事务顺序、持久证据、六仓恢复和其它对象读回版本合同继续生效。

## 2. 依据与能力复用裁决

正式 4010 只把索引定义为查询键到稳定身份候选的可重建映射，并要求命中后回读同一内存已发布代次的权威对象；它没有给索引建立独立版本。当前 `可重建索引读回` 也只包含物理键、当前性、节点目标和关系目标。

| 备选 | 裁决 | 原因 |
| --- | --- | --- |
| 删除统一 DTO 的 `预期版本` 字段 | 不采用 | 改变全部读回种类的共享 DTO 和确定性编码，超出本缺口所需范围 |
| 忽略索引读回的任意字段值 | 不采用 | 同一语义会出现多个编码，破坏请求意图、幂等和恢复材料唯一性 |
| 固定非零值 | 不采用 | 会伪造索引自身版本或复义目标节点版本 |
| 固定 `0` | 采用 | 与无独立版本事实一致，保持统一 DTO 且形成唯一机械编码 |

不得为本裁决新增索引版本、墓碑、历史仓、兼容双读或第二套物理移除证明。

## 3. DTO、字段来源与确定性编码

共享 DTO 形态不变：

```cpp
struct 节点直接发布后读回项 {
    节点直接发布后读回对象种类 种类 = 节点直接发布后读回对象种类::当前节点;
    std::variant<
        节点直接写集局部身份,
        节点稳定主键,
        关系稳定主键,
        类型化值记录稳定身份,
        索引物理键> 身份;
    std::uint64_t 预期版本 = 0;
};
```

字段合同：

| 读回种类 | `身份` 唯一分支 | `预期版本` | 版本语义 |
| --- | --- | --- | --- |
| `当前索引` | 完整 `索引物理键` | 必须为 `0` | 不适用哨兵 |
| `已移除索引` | 完整 `索引物理键` | 必须为 `0` | 不适用哨兵 |
| 其它现行种类 | 其现行身份分支 | 继续要求真实对象非零版本 | 节点、关系或类型化值自身版本 |

`预期版本=0` 仍按现行 U64 网络字节序进入请求意图摘要、确定性写集材料、幂等同义比较、持久准备材料和恢复解码。非零不是另一种合法写法，不允许编码后归一化为零。

## 4. 请求准入和一一配对

### 4.1 静态准入

`请求静态完整_` 对索引读回必须同时确认：

1. 种类恰为 `当前索引` 或 `已移除索引`；
2. 身份 variant 恰为完整 `索引物理键`；
3. `预期版本` 恰为 `0`；
4. 同一读回规格内不存在重复的 `(种类,索引物理键)`；
5. 同一物理键在整个写集中只有一条索引创建或移除操作，禁止同键创建/创建、移除/移除和创建/移除混合；
6. 本项能够与写集中的恰一项同键索引操作配对。

非零、错误 variant、无配对或多配对统一在持久准备调用次数为零时返回 `入口拒绝`。

### 4.2 `当前索引`

每项必须与写集中恰一条相同键的 `节点直接索引创建项` 配对。本版公开创建项只支持节点端点目标：

- 创建目标若是局部节点引用，先用本事务计划身份映射解析为节点稳定身份见证；
- 创建目标若是既有节点见证，原样复核；
- 发布后在原独占许可内调用索引仓当前读取，必须恰有一条同键当前记录；
- 输出 `可重建索引读回{键, 当前=true, 节点目标=已解析创建目标, 关系目标=nullopt}`；
- 仓读回节点目标必须逐字段等于已确认候选和创建项解析目标。

### 4.3 `已移除索引`

每项必须与写集中恰一条相同键的 `节点直接索引移除项` 配对：

- 移除项的 `预期目标` 必须与写前当前记录和已确认移除候选逐字段一致；
- 发布后在原独占许可内读取同键必须未命中；
- 输出 `可重建索引读回{键, 当前=false, 节点目标=移除项.预期目标, 关系目标=nullopt}`；
- `节点目标` 来自本事务不可变移除项和已确认候选，不来自已经物理删除的仓记录。

“发布后未命中”单独不能证明成功移除；它必须与本事务唯一同键移除项、写前当前记录、已确认候选和完成发布共同成立。本读回不声称索引仓保存移除历史。

## 5. 发布后收口与幂等读回

| 分支 | 持久准备 | 索引候选 | 发布后读取 | 结果 |
| --- | --- | --- | --- | --- |
| 索引读回非零版本/坏键/错分支 | 不调用 | 不建立 | 不调用 | `入口拒绝` |
| 无同键写项或同键多配对 | 不调用 | 不建立 | 不调用 | `入口拒绝` |
| 当前索引创建并读回一致 | 已完成 | 建立、确认、发布 | 同键当前命中且目标一致 | `已提交`，保存当前索引读回 |
| 已移除索引并读回一致 | 已完成 | 建立、确认、发布 | 同键未命中，目标取已确认移除材料 | `已提交`，保存已移除索引读回 |
| 已发布后读回不一致 | 已完成 | 已发布 | 命中/未命中或目标不符 | 隔离并返回 `内部不一致`，不伪回滚 |
| 精确幂等重放 | 不查持久端口、不重写 | 不建立 | 读取不可变原结果 | 返回同一索引读回及原发布代次 |

幂等原结果和结果摘要必须区分 `当前=true` 与 `当前=false`，并编码键、节点目标和空关系目标。两种索引读回的 `预期版本` 都固定为零，但种类不同，不能互认为同义。

## 6. 旧歧义直接退出

以下路径或口径不再允许：

```text
把索引目标节点的身份版本填入读回项.预期版本
把 0 解释成未知索引版本或以后可补版本
忽略任意非零预期版本
给可重建索引增加独立版本字段
仅凭发布后仓未命中形成已移除索引成功读回
为读回新增索引墓碑、历史仓或兼容双读
```

## 7. 验证合同

专项自检至少新增：

1. `当前索引` 与 `已移除索引` 的 `预期版本=0` 均通过静态准入；`1`、`UINT64_MAX` 在持久准备/候选调用次数均为零时入口拒绝。
2. 相同索引操作仅改变预期版本 `0 -> 1` 时，不得进入幂等冲突或归一化路径，必须先入口拒绝。
3. 当前索引创建支持局部节点目标和既有节点目标；发布后目标、键和 `当前=true` 逐字段一致，关系目标为空。
4. 已移除索引要求写前当前目标、移除项预期目标和候选一致；发布后未命中，输出保留原节点见证且 `当前=false`。
5. 已移除索引在“从未存在而未命中”、错误预期目标、无配对、重复配对时均不得成功。
6. 当前索引发布后未命中、目标不符，或移除后仍命中，都隔离并返回内部不一致。
7. 精确幂等重放返回原索引读回和原发布代次，不查持久端口、不推进代次。
8. 编码黄金材料明确包含索引种类、U64 零值和索引物理键；非零材料不被解码为合法请求。

完成只证明索引发布后读回版本语义、配对、结果形成和验证合同已机械闭合；不证明执行 WIP 已实现、编译、运行或形成 P1A2 完成结果。
