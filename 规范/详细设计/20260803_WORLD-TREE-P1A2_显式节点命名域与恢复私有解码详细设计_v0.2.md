# WORLD-TREE-P1A2 显式节点命名域与恢复私有解码详细设计 v0.2

日期：2026-08-03

状态：P1A2 执行期设计漂移裁决；与 P1A2 v0.2 共同生效

来源问题：`DRIFT-WORLD-P1A2-NODE-NAMESPACE-UNFORMABLE`

## 1. 裁决与替代范围

本设计在 WORLD-TREE-P1A2 原目标内修订两条不可施工合同：

1. 普通节点创建由业务事实所有者显式给出 `节点稳定主键命名域`，L1 只验证命名域与节点类型的合法组合并在对应命名域分配计划键；L1 不再从节点类型猜测命名域。
2. 恢复服务只读取持久端口、完成端口级状态分流并把原始值式材料交给数据操作；恢复尝试审计、唯一解码、强类型恢复请求聚合归数据操作，私有解码器不扩大可见性。

本设计精确替代以下旧口径：

```text
WORLD-TREE-P1 函数功能确认 v0.1 中“L1 按节点类型命名域分配节点稳定主键”
WORLD-TREE-P1 函数功能确认 v0.1 中“恢复服务形成完整强类型恢复请求”
WORLD-TREE-P1 逐节点实现分析 v0.1 中与上述两条相同的形成路径
世界树详细设计 10.1 中恢复服务在聚合 DTO 前完成全部材料审计的责任描述
20260802_执行节点直接类型化结构事务_函数流程图_v0.1.md 的 N06 节点
```

其余事务顺序、持久证据、六仓恢复、代次开放、读回和隔离合同继续由原设计包冻结。旧推断和重复解码路径不得作为兼容路径保留。

## 2. 当前事实与能力复用裁决

当前正式代码基线包含执行安全 WIP `9e2383ed2dcc51a215c08c86940908abcd36ee98`：

- `节点直接节点创建项` 只有 `局部身份` 和 `类型`，无法区分 `词身份/语素入口身份` 或 `抽象特征定义身份/实例特征槽身份`。
- `节点直接身份仓库::命名域已定义` 与 `节点直接身份仓库::命名域与节点类型匹配` 已覆盖 ABI 1 的全部合法组合，可直接复用为 L1 写前验证；不得复制第二张运行期映射表。
- `节点直接结构恢复服务` 尚未形成；数据操作现有 `恢复(const 节点直接恢复结构事务请求&)` 要求上层先构造强类型请求，而唯一 `解码恢复写集` 是数据操作私有函数，调用边不可达。
- `节点直接恢复材料读取结果` 已由 `海中鱼巣.核心.端口.节点直接持久证据` 唯一导出，数据操作可以合法 import 该模块并按只读引用消费。

复用裁决：

| 所需能力 | 当前能力 | 裁决 |
| --- | --- | --- |
| 命名域存在性及类型组合验证 | 节点身份仓两个静态验证函数 | 直接复用 |
| 命名域内高水位分配 | 节点身份仓现有高水位与历史占用 | 直接复用；执行器在独占许可内编排 |
| 持久材料读取 | 恢复材料读取端口 | 直接复用 |
| 原始材料解码 | 数据操作私有 `解码恢复写集` 骨架 | 扩展为唯一实现；保持 private |
| 六仓恢复发布 | 执行器恢复窄入口与六仓候选合同 | 继续原设计；不改变调用方 |

## 3. 普通节点创建的显式命名域合同

### 3.1 DTO 与字段来源

`海中鱼巣/核心/节点直接结构合同.数据.h` 中公开业务中性创建项修订为：

```cpp
struct 节点直接节点创建项 {
    节点直接写集局部身份 局部身份;
    节点稳定主键命名域 命名域 = 节点稳定主键命名域::无效;
    节点类型 类型 = 节点类型::未分类;
};
```

字段来源唯一为提出节点创建意图的 L2 事实所有者：

| 字段 | 唯一形成方 | L1 行为 |
| --- | --- | --- |
| `局部身份` | L2 本次写集 | 校验非零、种类为节点、全写集唯一和引用顺序 |
| `命名域` | L2 事实所有者依据其公开强类型请求显式选择 | 只验证已定义及与类型匹配；不改写、不默认 |
| `类型` | L2 事实所有者 | 只验证与命名域匹配 |

提交服务和数据操作逐字段原样复制完整写项；不得删除、覆盖或重算 `命名域`。执行器取得独占许可后，在第一笔持久准备和内存候选之前调用现有命名域验证能力，随后按 `(命名域底层值, 局部身份.值)` 稳定排序，在每个命名域分别读取高水位并形成连续计划键。

| --- | --- |

| `需求身份` | `需求` |
| `任务身份` | `任务` |
| `方法身份` | `方法` |
| `动态身份` | `动态` |
| `因果身份` | `因果引用` |
| `状态身份` | `状态` |
| `二次特征身份` | `二次特征` |

### 3.3 摘要、编码、幂等与恢复

- L2 形成的公开请求意图摘要必须把每个节点创建项的命名域底层 `uint64` 纳入原顺序编码；同局部身份和类型但命名域不同属于异义请求。
- L1 确定性写集编码中，节点创建项字段顺序固定为 `variant 标签 -> 局部身份种类 -> 局部身份值 -> 命名域 uint64 -> 节点类型 uint32`，数值继续使用现行网络字节序。
- 本版把 `写集规则版本` 和持久 `材料格式版本` 同步冻结为 `2`；合同版本仍为 `1`。旧版本 `1` 不含显式命名域，只作安全 WIP 历史，不再接受、升级或双读。
- `节点直接计划身份映射项.稳定身份命名域` 必须逐值等于创建项显式命名域；不允许由节点类型反推后填入。
- 执行证据摘要、写集材料摘要、幂等比较、持久证据和恢复解码都消费同一显式字段；旧材料格式没有该字段时按格式版本拒绝，不做双读。
- 恢复历史仍以持久材料中的稳定主键命名域为准并复核节点类型；不从节点类型补造缺失命名域。

### 3.4 旧路径直接删除

执行切片必须直接删除以下目标逻辑，不建立兼容分支：

```text
节点类型 -> 单一节点稳定主键命名域 的 switch / if / 查表推断
无效命名域时按节点类型补默认命名域
语素统一落入词身份或特征统一落入抽象特征定义身份的 fallback
旧格式节点创建项双读或缺字段自动升级
服务、数据操作或执行器中的第二份命名域—节点类型映射表
```

现行仓库验证函数不是旧推断路径：它只裁决显式二元组是否合法，继续保留并复用。

## 4. 恢复材料的唯一私有解码链

### 4.1 物理位置和完整签名

| 函数 | 唯一文件 / 模块 | 形态与可见性 | 完整签名 |
| --- | --- | --- | --- |
| `恢复安装实例` | `海中鱼巣/核心/服务.节点直接结构恢复.ixx` / `海中鱼巣.核心.服务.节点直接结构恢复` | 导出服务成员 | `节点直接结构恢复结果 恢复安装实例(const 节点直接安装实例恢复请求& 请求) const` |
| `恢复` | `海中鱼巣/核心/数据操作.节点直接类型化结构.ixx` / `海中鱼巣.核心.数据操作.节点直接类型化结构` | 数据操作公开窄入口，仅恢复服务调用 | `节点直接恢复数据操作结果 恢复(节点直接事务幂等身份 安装实例身份, const 节点直接恢复材料读取结果& 材料) const` |
| `解码恢复写集` | 同一数据操作模块 | `private static` | `static 节点直接恢复解码结果 解码恢复写集(std::span<const std::uint8_t> 材料)` |
| `执行节点直接恢复事务` | `海中鱼巣/核心/执行器.节点直接身份结构写入.ixx` | 执行器窄入口，仅数据操作调用 | `节点直接恢复数据操作结果 执行节点直接恢复事务(const 节点直接恢复数据操作规格& 规格) const` |

数据操作模块新增 `import 海中鱼巣.核心.端口.节点直接持久证据;`。服务和数据操作同步借用 `节点直接恢复材料读取结果`；端口调用返回值由恢复服务局部拥有，覆盖数据操作同步调用，不保存引用。

### 4.2 调用与责任

```text
节点直接结构恢复服务::恢复安装实例
-> 节点直接恢复材料读取端口::读取安装实例
-> 端口级状态/合同版本/安装实例身份分流
-> 节点直接类型化结构数据操作::恢复(安装实例身份, 原始材料结果)
-> 数据操作审计全部事务尝试和发布连续性
-> 数据操作私有 解码恢复写集(每个唯一已见证材料)
-> 数据操作聚合并互证 节点直接恢复结构事务请求
-> 节点直接身份结构写入执行器::执行节点直接恢复事务
```

恢复服务只负责：请求合同和身份准入、调用读取端口、对 `确认从未发布` 调用现有空域治理入口、对 `存在事务证据` 调用数据操作恢复、显式映射数据操作结果、承担本地诊断边界。它不遍历写集字节、不解码、不形成六仓强类型请求。

数据操作负责：再次确认安装状态为 `存在事务证据` 且材料组非空；按 `(事务身份命名域,事务身份键值,尝试序号)` 稳定排序；验证尝试从 1 连续、唯一已见证、无见证后尝试、发布代次连续；忽略但审计 `已撤销未发布`；若全部尝试均明确撤销且没有任何见证/准备/未知/损坏，则在本类内部调用既有 `初始化确认空域治理代次(安装实例身份)` 并返回其结果；否则对唯一已见证材料调用私有解码器，验证双摘要、结果摘要、侧账、已发布幂等记录、高水位和历史占用，聚合唯一强类型恢复请求，随后调用执行器。

`已准备`、结果未知、损坏、零/断序/回绕尝试、多个见证、见证后续尝试、已隔离幂等记录或解码不一致均在执行器调用前返回现有具名非成功并保持普通入口关闭。

### 4.3 旧路径直接删除

```text
恢复服务形成 节点直接恢复结构事务请求
恢复服务或其它模块复制 解码恢复写集
把 解码恢复写集 改为 public/export
跨模块 friend 调用私有解码器
服务与数据操作同时审计或同时解码同一材料
旧恢复请求入口与原始材料入口并存双路接受
```

执行后数据操作只保留新的原始材料入口；现有 `恢复(const 节点直接恢复结构事务请求&)` 直接删除。强类型请求只在数据操作内部形成并经规格传给执行器。

## 6. 验证合同

至少新增并真实运行以下断言：

1. 21 个命名域全部接受其唯一节点类型；`词身份/语素入口身份` 与 `抽象特征定义身份/实例特征槽身份` 分别得到不同计划主键域。
2. 无效、未知和每个表外组合在持久准备调用次数为 0、六仓候选次数为 0 时返回入口拒绝。
3. 同局部身份/类型但命名域不同产生不同请求意图摘要并构成幂等冲突。
4. 确定性编码黄金材料在节点类型前包含显式 8 字节命名域；旧缺字段材料按格式不支持拒绝。
5. 服务模块中 `解码恢复写集`、`节点直接恢复结构事务请求` 和六仓聚合逻辑零命中。
6. `解码恢复写集` 只有数据操作私有声明和数据操作内部调用；无 friend、导出或第二实现。
7. 数据操作旧 `恢复(const 节点直接恢复结构事务请求&)` 签名零命中；恢复服务只调用原始材料入口。
8. 端口五状态、全部尝试审计分支、解码失败、聚合冲突和六仓故障矩阵均保留原普通入口关闭/隔离边界。

完成只证明 P1A2 修订合同机械闭合；不证明执行 WIP 已实现、编译或通过运行验证。
