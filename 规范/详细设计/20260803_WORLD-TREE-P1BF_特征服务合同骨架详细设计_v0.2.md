## 1. 目标、业务位置与完成边界

本设计按 `流程图/目标业务流程图/业务节点到能力与目标函数映射.md` 的“世界事实维护”归属，为 `流程图/20260802_WORLD-TREE-P1_世界树业务服务业务流程图_v0.1.md` Q01/Q02 的完整快照特征读取子提供者预先建立唯一公开 ABI。代码结果只形成安全合同骨架：公开函数对任意输入都返回稳定 `未实现`，事实截止代次为0，特征组与缺项组为空，并且零机器事实写入、零 SQL/材料读取、零 L1/L2 调用边。

本叶子只清理“共享特征事实、模块、DTO、签名、构造和链接身份尚不存在”的门禁，不解除任何消费者对真实特征成功行为的依赖。P1B、P1C 和世界树快照仍须等待 WORLD-TREE-P1A2G 与 WORLD-TREE-FEATURE-Q 的真实结果；消费者遇到 `未实现` 必须停止成功后继，不得转换为成功空组、未找到、默认值、旧栈回退或 SQL 回源。

特征批次写入不属于本叶子。当前 P1A2 通用类型化结构提交请求没有 4170 特征批次专用记录参与者，因而不能把 `节点直接类型化结构提交服务&` 冻结成特征写入服务的最终充分依赖。写入骨架必须等待核心通用参与者协议与领域专用特征批次参与者边界被独立设计冻结，禁止发布以后需要破坏性改签的占位构造。

上游业务领域归属依据为 `流程图/目标业务流程图/业务节点到能力与目标函数映射.md` 第4节“世界事实维护”，具体闭环依据为 WORLD-TREE-P1 总业务流程图 Q01/Q02；该映射不替代函数合同。直接函数依据为 `流程图/20260803_节点直接特征查询服务读取宿主组完整当前特征_函数流程图_v0.2.md`，直接规范依据为4020、4030、4110、4170、4200 v0.8和4201 v0.2。

## 3. 共享特征事实 DTO

唯一文件：`海中鱼巣/领域/世界树事实.数据.h`。P1A3F 成功结果建立该头后，本叶子只追加以下结构；P1A3F 已有字段逐字不改。

```cpp
struct 世界树特征事实 {
    世界树节点身份见证 宿主;
    世界树节点身份见证 实例槽;
    世界树节点身份见证 特征定义;
    世界树关系身份见证 宿主关系;
    世界树关系身份见证 定义关系;
    世界树关系身份见证 当前值关系;
    世界树节点身份见证 当前值;
    类型合同稳定身份 原始值类型合同身份;
    std::uint32_t 原始值类型合同版本 = 0;
    类型化值记录稳定身份 原始值记录身份;
    std::uint64_t 原始值版本 = 0;
    std::optional<std::uint64_t> 前一原始值版本;
    类型化值材料 原始值;
    世界树节点身份见证 来源存在;
    std::uint64_t 首次发布代次 = 0;
    std::uint64_t 当前状态发布代次 = 0;
};
```

字段顺序和类型永久稳定。结构由调用方按值拥有，可复制/可移动，不含引用、指针、句柄、锁、许可、会话、仓库、SQL标识或材料路径。

4110 的关系22只有宿主、定义和当前值三个角色；来源来自 4020 `类型化值读回.来源`，不存在第四条“来源关系”。真实形成时只接受来源联合中的已发布存在节点见证，并逐字段复制类型合同身份/版本、值记录身份/版本、前一版本、材料、来源和两个发布代次；不得从关系、显示名、SQL或默认值补造。

目标真实排序规则固定沿 4200：宿主稳定身份 → 特征定义稳定身份 → 实例槽稳定身份，各键均比较命名域、键值和版本；当前值不参与排序键。本骨架不构造任何实例，因此不执行排序。

## 4. 查询合同与物理位置

唯一模块/文件：

```text
export module 海中鱼巣.领域.服务.节点直接特征查询;
海中鱼巣/领域/服务.节点直接特征查询.ixx
```

模块依赖和声明顺序固定为：

```cpp
module;

#include "世界树事实.数据.h"

export module 海中鱼巣.领域.服务.节点直接特征查询;

import 海中鱼巣.核心.服务.节点直接结构;
```

不得 import 旧特征模块、仓库、数据操作、SQL、材料或其它 L2 服务。

公开实体全部位于 `export namespace 海中鱼巣`：

```cpp
inline constexpr std::uint32_t 节点直接特征查询合同版本 = 1;

enum class 节点直接特征读取状态 : std::uint8_t {
    已读取 = 1,
    未找到 = 2,
    入口拒绝 = 3,
    版本漂移 = 4,
    许可拒绝 = 5,
    资源失败 = 6,
    内部不一致 = 7,
    未实现 = 8
};

struct 节点直接宿主组特征读取请求 {
    std::uint32_t 合同版本 = 节点直接特征查询合同版本;
    世界树请求头 头;
    std::vector<世界树节点身份见证> 宿主组;
};

struct 节点直接特征组读取结果 {
    节点直接特征读取状态 状态 = 节点直接特征读取状态::入口拒绝;
    std::uint64_t 事实截止代次 = 0;
    std::vector<世界树特征事实> 特征组;
    std::vector<世界树缺项> 缺项组;
};

class 节点直接特征查询服务 final {
public:
    explicit 节点直接特征查询服务(
        节点直接结构查询服务& 结构) noexcept
        : 结构_(结构) {}

    节点直接特征组读取结果 读取宿主组完整当前特征(
        const 节点直接宿主组特征读取请求& 请求) const noexcept;

private:
    节点直接结构查询服务& 结构_;
};
```

`结构` 由装配宿主拥有并长于服务；构造只保存非空引用，不读取、不分配、不恢复、不写事实，不提供默认构造、setter、指针或运行期替换。骨架函数不读取 `请求` 字段、不调用 `结构_`，直接返回 `{状态=未实现,事实截止代次=0,特征组={},缺项组={}}`。

函数体固定直接返回以下 prvalue，不建立命名临时值，不执行容器扩容：

```cpp
static_assert(noexcept(节点直接特征组读取结果{
    节点直接特征读取状态::未实现, 0, {}, {}}));

return 节点直接特征组读取结果{
    节点直接特征读取状态::未实现, 0, {}, {}};
```

断言不成立即编译失败并返回设计支撑，不得删除 `noexcept`、改用捕获异常后再次构造同一结果，或临场改变结果字段。

## 5. 后继真实查询的原位替换门禁

真实 FEATURE-Q 只能原位替换上述函数体，不改模块、DTO、构造或签名。它必须等待 P1A2G 在现有 `节点直接结构查询服务` 中提供一次共享许可内的业务中性投影：验证世界根和全部宿主、读取关系22第一跳、读取槽位全部相关关系，并读取角色3目标的全部当前类型化值，结果只携带一个非零事实截止代次。

后继查询必须从该单次值式投影形成关系22完整事实；不得用当前多个独立许可函数事后比较代次拼接，也不得取得或传递 L1 许可。P1A2G 尚未真实成功前，本骨架不能取得 `局部可继续`。

真实 FEATURE-Q 保持本设计冻结的 `noexcept` 签名。其后继设计必须把容器分配、排序和投影形成包在服务边界内：`std::bad_alloc` / 容量不可满足映射为 `资源失败`，其它未预期异常映射为 `内部不一致`；两者都返回代次0、空特征组和空缺项组，不得让异常越过公开服务边界。业务可判定的不完整仍按4200只在 `内部不一致` 分支携带稳定缺项组，不与异常分支混用。

## 6. 所有权、异常、并发与消费合同

1. 请求为同步调用期间的 const 借用，服务不保存引用；返回值由调用方拥有。
2. 骨架函数固定 `noexcept`，其成立由第4节静态断言和无分配函数体共同保证；不得用 catch-all 隐藏类型合同漂移。
3. 骨架不取得读取/独占许可，不持锁，不等待，不 sleep，不访问时钟、随机源、日志、缓存、材料、SQL或外设。
4. `未实现` 是稳定非成功，不记录逻辑错误日志。合法消费者必须保留原状态并停止成功后继；自检只验证结构化结果。
5. 只有后继 FEATURE-Q 计划可以原位替换函数体；不得新增同名重载、旧句柄重载、兼容转发或第二服务类。
