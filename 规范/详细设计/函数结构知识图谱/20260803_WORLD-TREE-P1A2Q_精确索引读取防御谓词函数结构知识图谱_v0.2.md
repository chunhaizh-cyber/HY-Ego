## 1. 模块与所有权

```mermaid
flowchart LR
    W["执行器.节点直接身份结构写入\n现有低层统一事务"] --> F["自检.节点直接结构查询\n隔离双目标索引夹具+专项根"]
    R["仓库.可重建索引\n正反绑定+结构化读取"] --> F
```

执行器、会话和三个权威仓继续拥有候选事务；P1A2Q 自检只拥有隔离对象、夹具编排和验证断言。公开 P1A2 提交服务只支持节点目标索引，不在关系夹具调用图中。

## 3. 隔离夹具形成调用图

```mermaid
flowchart TD
    F["形成已发布双目标索引夹具"] --> X["节点直接身份结构写入执行器::执行(callback)"]
    X --> N1["会话::创建节点候选 x2"]
    N1 --> N2["会话::读取节点 x2"]
    N2 --> R1["会话::创建关系候选"]
    R1 --> R2["会话::读取关系"]
    R2 --> I1["会话::创建索引候选\n节点目标"]
    I1 --> I2["会话::创建索引候选\n关系目标"]
    I2 --> I3["会话::读取索引物理键 x2"]
    I3 --> D["会话::请求提交 或 请求撤销"]
    D --> C["执行器统一确认/逆序撤销/发布"]
    C --> P["事务域::取得读取许可\n读取非零代次"]
    P --> B1["仓库::读取索引物理键结构化 x2"]
    B1 --> B2["查询服务::读取当前索引 x2"]
```

同一次执行器事务拥有两节点、一关系和两索引候选。节点索引记录为 `{节点键, 节点, 文章节点, {}}`；关系索引记录为 `{关系键, 关系, {}, 关系句柄}`。禁止直接调用仓库确认、发布、恢复或私有容器。

## 4. 专项宏内测试调用图

```mermaid
flowchart TD
    S["运行节点直接结构查询专项自检"] --> F["形成已发布双目标索引夹具"]
    S --> SR["索引仓::测试_令下次结构化精确读取抛出资源异常"]
    S --> SO["索引仓::测试_令下次结构化精确读取抛出其它异常"]
    S --> SI["索引仓::测试_令下次结构化精确读取模拟内部损坏"]
    S --> QR["查询服务::测试_令下次当前索引读取抛出资源异常"]
    S --> QO["查询服务::测试_令下次当前索引读取抛出其它异常"]
    S --> QI["查询服务::测试_令下次当前索引读取模拟内部损坏"]
    SR --> RF["索引仓实例私有 atomic<uint8_t>"]
    SO --> RF
    SI --> RF
    QR --> QF["查询服务实例私有 atomic<uint8_t>"]
    QO --> QF
    QI --> QF
    RF --> G["读取索引物理键结构化\n合法键后 exchange(0)"]
    QF --> Q["读取当前索引\n合法键后 exchange(0)"]
```

六个设置函数唯一项目调用方是专项自检。非法键不消费；合法键后一次消费；第二次同输入恢复正常。两类关系服务模式只使用关系索引键，节点模式只使用节点索引键。

## 7. 结果追踪与完成边界

| 不变量 | 机械证明 |
| --- | --- |
| 关系夹具可形成 | 单次低层执行器调用已提交，关系索引仓/服务基线读回均成功 |
| 节点关系同代次 | 两索引服务结果代次等于事务域同一非零发布代次 |
| 候选原子性 | 任一形成/读回失败时执行器撤销，零部分发布 |
| 防御场景可构造 | 五个索引仓模式和三个服务模式各到达匹配节点 |
| 注入零事实变化 | 每项调用前后代次和六仓权威导出逐值相等 |
| 一次性恢复 | 首次失败后第二次同输入返回基线结果 |
| 宏关闭零实体 | 测试枚举、六设置函数、两个字段和分支均不存在 |
