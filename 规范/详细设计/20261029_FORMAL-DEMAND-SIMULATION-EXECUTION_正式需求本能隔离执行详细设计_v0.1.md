## 1. 修改对象、原因、目的

只改变本次模拟场景内服务对象H的需求特征F：将其当前引用落实为参数指定的完整本地需求D。D本身内容不在本叶修改。执行者是自我，不是H；自我身份由正常装配精确提供，经单向复制形成本次本地身份映射。自我不是第四个业务参数，H/F/D固定规格和原本能核心不改。原因是参数提供者已实现，但正式结果声明被误作FT、模拟需求运行口未装配，原函数仍不能正常执行；目的为同一注册函数使用隔离参数执行到出口，由外层独立读取实际本地结果。

不改现实或治理Vm特征，不调用现实需求/发布owner，不造任务。动作记录执行发生；后状态及合法双状态动态依据实际引用写回形成，不从声明预造结果。空白/部分D、正式C/R抽象和发表、本能核心重写、学习完成及服务闭环不在本叶。

依据：AGENTS.md本能分析顺序及用户最新具名裁决，0050、4030、1170、5360、5370、5170。用户已明确执行者为自我，允许同叶补齐精确self来源和隔离映射，不改变三业务参数；动态无前值分支执行1170双状态原则。

### 3.1.1 动作依赖与连接场景事实解耦（施工支撑修订）

旧world五参动作构造和学习服务选择条件把动作三依赖与连接场景事实一起要求，导致无连接facts时退到仅M构造，需求执行再次丢失已具备的动作依赖。本叶需求只需动作依赖，不以连接facts为隐含条件。在既有world头/源增加精确四参重载：

```cpp
新_模拟世界类(新_方法类&,
    const 动作方法定义只读提供者&,
    新_动态类&, const 概念_动态类&) noexcept;
```

四参构造委托现单M构造，按现有构造异常处理合同保存三项动作依赖，不设置场景事实提供者；既有五参构造改为委托四参，再保存其第五参facts。学习服务创建样例时，动作三依赖齐备且有facts走原五参，动作三依赖齐备但无facts走四参，动作三依赖未就绪保留单M路径并由需求预检具名报依赖未就绪，不能进入原函数后才变成缺端口。不得为满足构造编造空facts或复用现实连接来源。

旧连接路径及其 `获取隔离执行接口` 的场景事实要求不放松；需求运行接口/需求私有动作helper只消费自己的依赖，不经连接facts getter。依赖仍只读借用、启动期不可变，无新owner/文件、无场景事实语义扩展。此修订不改变其他冻结合同。

## 4. 精确执行者来源、落图与fresh

1. 学习服务按启动配置源E调用E身份保护，再经EC完整普通存在概念保护取得专属C，确认种类专属、对应存在恰为配置E；前后核E→C/定义一致。未配置映学习规格未支持并诊断依赖未装配；源不存在/真实变化沿定义前提变化或当前已有采集漂移路径重采，不能猜另一E；资源失败映资源不足，稳定损坏走工程链。
2. 将源E/C的本次完整保护合入构造输入CAS。world在同一建立样例事务中建立本地身份用途E：私有样例类型、根、所属样例、正式专属C引用。若已有同源普通E输入，则复用其同一本地映射并核C一致；否则独立身份E不加入业务有序参数/候选，也不填self业务F。它只证明源身份的隔离映射，不冒称完整自我状态或满足自我概念全部特征约束。
3. 源E只在内存身份映射中溯源，不写作本地可写引用；本地动作字段引用本地actor而非源E。不得改共享专属C的对应存在为本地E，概念仍为共享定义。每个样例重新分配本地身份，跨样例不复用；来源索引、actor身份、本次动作许可随样例释放。
4. actor落图会给专属C增加合法入向；初采源保护仅服务该次落图CAS。确保正式动作定义时也可能增加C/FT入向。因此动作顺序固定为：准备动作定义概念→锁外fresh读源E身份和完整专属C（E→C仍一致）及动作定义保护→回world锁核样例、actor映射和许可→以本次fresh保护提交动作。不得合并落图前旧C保护、忽略入向、按编码删冲突或重建替代概念。
5. 动作后的材料/结果reader同样重新采集当前定义和本地保护；旧材料完整保护可能包含N、样例根或D/FT入向，只用于动作前复核，不跨本次预期写动作继续当最终CAS。发布比较动作前业务投影是否仍相同，再使用fresh保护，不能把自己合法建立A造成的变化误判为外部漂移。

## 5. 结果声明识别与通用未知F候选

先以正式EC结构读口识别 `方法头.可能结果概念组`。可读FT沿原路径；信息结构只支持EC `读取引用内容筹办概念()` 返回的精确 `完整被认知需求`，不是按名称/登记名或“任意信息结构”放行。读取其完整有效内容和定义保护；其它结构结果仍规格未支持。函数H/F/D规格与所属关系另按结构合同核验，不从登记名推断。普通FT结果采集不变。

必须提供无当前需求值的合法F样例，否则只有一个D候选时F.current恒等于D且没有本地首次A，所有样例都会被预检拒绝。

- 在 `新模拟特征初值方式` 尾部追加 `概念构造未知=3`，保留常规/复制准确/复制未知的原数值与语义。当前通用能力仅支持单需求节点引用F，不扩展所有FT，也不增加方法专名分支。
- 完整F、所属及正式FT仍存在；此方式不写current、历史、标准值或假D，不表示数值0或空集合。与值/材料/普通引用/需求引用/完整复制特征等当前值权威互斥，非复制来源。
- 对别名簇统一检查有效共同/分支条件和已有C取样限定：若有当前值/域/精确域/引用内容/状态动态条件、涉及该F的值引用关系，或所属E附属FT条件要求当前材料，则不生成未知候选；只声明F类型/所属而没有要求current已知时允许。无法证明可缺current时不放行。不改任何已有规格/条件或域以容纳未知。
- 现需求引用候选轴可加内部序号0表示“选未知”，与所有已知D图序号一同合法枚举；落图前转为新枚举并清空旧 `引用需求输入`，不发布稳定编码0。别名共享该轴。原已知候选保留；未知F不要求先有F.current的D，但第三参数仍必须是合法完整D候选。
- world在建立样例入口独立核新方式、FT类别、互斥字段、别名一致及上述有效条件。此分支不误走完整复制输入处理；落图后getter应返回合法F且current为空。其它完整复制历史材料原样保留。

两个必经消费者同时迁移，不增加公开接口：

1. `新_方法类::建立模拟参数场景` 的特征分支目前在current空时拒绝。仅对同模拟owner已核验的合法F身份/范围，且正式定义为“需求节点引用＋需求身份精确”时允许current空绑定；其它FT保留原门。固定规格只限定F身份/范围，业务当前值要求仍交有效条件与原core，不按方法名例外，不全面删除current门。
2. `动作概念.方法投影服务::读取动作方法投影` 与 `概念_动态类` 的有序参数存在范围校验，须允许EC正式信息结构概念作为有序“存在”参数范围，以正式概念身份及结构定义保护读取，不以名称判定。动态概念cpp新增私有“读取有序存在范围保护”helper：先普通EC完整定义保护，只有明确非本提供者才读正式结构完整保护并要求信息结构定义；基础数值/其它结构不得冒充存在范围。普通或正式读口前提变化抛既有动作类别前提变化，资源失败抛bad_alloc，稳定损坏走原工程链。规范化校验、编码及解码都调用该helper；编码/解码并入具体范围full，不仅采类别根证明，现动作定义保护reader据此fresh收全。动作投影ordered支同样按此类型分流。只有该有序范围位置扩展；执行主体/普通目标和旧角色范围仍要求普通存在概念。保留三规格中的D范围及完整定义保护，不将D忽略或强塞普通存在；不需增加新动态cpp第九源。

无完整D候选仍沿上一叶规格未支持，不为打通本叶伪造D。对初始F.current或历史已经含目标D、但没有本地首次发布关联的组合，预检报告规格未支持，不进入原函数/动作；继续枚举其它候选，若全部未支持才报告本分支未支持，不因首个已知组合拒绝而跳过后续未知正向样例。

## 6. 材料读取、完整判定和回调合同

调用窗前预检确认同owner模拟scene、三位置H/F/D类型及绑定、F确属H且为单需求引用/需求身份比较、D本地、D主体=H且被认知、actor映射与正式依赖、结果概念为本叶支持范围。检查初始发布来源及不支持的内容形状。工程读取失败不映空或false。正常业务材料未齐仍交原运行口返回材料待齐/需重新确认，不构造子需求。

`读取新需求材料`在调用窗内正式读取H/F及D十五项投影、完整本地D/U/C/R/L、正式结果概念，组装既有治理DTO：D身份/主体/域/目标/权重/活动/来源均从本地DTO映射，`完整目标={本地目标E,目标定义}`，只有实际完整且经下述判定成立才设 `信息完善阶段=已完善`；未有字段保持空，不填真实任务/承接/治理结果。D内容不写回。动作前F快照为真实getter读回，不从候选输入恢复。

复用EC `判定正式结构内容`，不另造“D图完整即符合”的判断器。direct回调只读本D十五项FT映射，遇到其它实例/未支持路径返回未支持；同一FT重复是工程错误。callbacks固定支持如下：

- 合法存在：仅成功重建的本地普通E；合法FT根/特征概念：FC正式定义保护并核类型根；合法比较关系：RC正式定义保护；正式概念身份：依次正式FC/RC/EC读口，保存实际成功owner保护。不能将任意稳定编码视为概念。
- 具名领域身份2/3分别核本地U/C及准确种类和本D认知来源；15核本地D身份；正式信息身份也必须匹配本地正式信息种类，不无条件返回符合。未知原语/类别返回未支持。
- 概念判定器自身处理整数域/枚举、值/方向择一、被认知执行域及必需项；本地确认的 `需重新确认` 为真单独返回需重新确认。D与U/C的主体、目标、来源R、会话/语言场景关联必须由既有本地reader逐项一致性核验，不跨D拼字段。
- 对 `域属于FT` 只接受项目顺序恰为先天槽“目标域、需求目标FT”，无额外整数/引用参数；用FC正式读回确认域的类型根=目标FT，材料/单位/比较规则一致，目标域是其合法子范围。不得仅因为引用都存在就通过。
- 对 `比较适用于目标` 只接受“目标比较、需求目标FT、目标域”的精确项目序列及空附加参数。本叶值目标比较支持现有构造器的有向特征差值：两个输入顺序0/1，角色左/右，来源均特征准确值，两输入FT均为目标FT，参照概念恰为本D目标域，结果域为包含于参照值域；以RC/FC正式读回核其输出材料/单位/比较及参照范围。其它算法/结果域为规格未支持，不把任意RC判适用。对照U固定语义的FT/域/比较完整快照，真实变化返回需重新确认。方向分支不得携带值域/比较。
- 其它关联约束若EC内部不能独立判定，返回未支持，不按模板序号臆测。所有回调保护按节点合并并最终fresh核同，稳定非法材料给出不符合/材料待齐，真实变化给前提变化，资源错误给资源路径，稳定物理损坏走工程链。

预检与运行读取共同复用私有材料helper，但预检不创建动作/调用记录、不计本能实际读取；只有调用窗内的真实读沿原内容记录登记。`复核新需求材料`重新读取、比较本次H/F/D业务投影并核动作前完整保护，成功后发放同N/绑定的一次动作许可。

## 7. 动作、停止及引用发布事务

### 7.1 取消许可点与真实动作

窗口由当前world唯一执行线程串行持有。材料读取/复核在world锁外采样停止回调并按既有N记录取消；成立则返回前提已变化，原core零A退出。复核成功是本次动作许可点；之后新到的停止不撤回该许可。`开始本次需求动作`不再采样回调，不以无效A或异常表达取消；只核同一尚打开N、绑定及许可，复用同N已建立A或原子建立真实A。不得外部线程绕过world直接写N取消字段。

需求动作使用新私有正式动作发布helper：目标H/F、执行者本地actor、方法M、唯一来源N、抽象相对时间及正式动作定义。可提取连接现有helper共用的构造代码，但连接public原位置检查和事实核验绝不放松；不直接调用连接p2接口。依第4节确保定义及fresh核同后，动作与N主动作引用、必要真实前状态、进展一次发表，预留容量后提交并收集节点。已有current有真实值而无前S时可按读到的实际前值建立前S，不凭空生成旧值；原current空绝不造前S。

发布前再次采样停止：已取消返回发布前提变化，保留A、零目标写。提交许可后新到停止由关闭窗记录，不能回滚已发生F/S/记录；外层按取消结束，不造C/R。所有取消均为正常控制路径，不向原本能noexcept抛取消异常。

### 7.2 本地需求发布记录和原子写回

在world私有schema尾部追加节点种类“需求发布记录”及专用字段，不改已有编号。记录P的最小字段：类型/模拟根、所属结果场景、主体H、特征F、目标D、来源N、本次动作A、首次发布动作A0、后状态S、可选前状态/变化动态、可选首次记录P0。N经专用“需求发布成员”字段引用P，不能复用连接过程的集合成员字段。首记录P0的A0=A、无其它首次记录；后续复用P引用P0且保留其A0。D内容字段不变；首次来源按样例本地发布记录的D/H/F唯一身份读取，内存索引只加速，不作为成功权威。

| 发布前事实 | 本叶处理 |
| --- | --- |
| 目标D不在F当前/历史且无P0 | 真正首次落实；新P0、F.current=D、真实后S，同次原子发布 |
| F.current空 | 不造前值/前S/原子动态；P0显式关联N/A/真实后S |
| F.current为另一合法D | 取真实前S，建立新后S及双状态变化，A→变化、N→变化显式关联 |
| F.current=D且本地P0完整合法 | 本次真实A已经记录，发布复用P，保留A0；不造新S/变化，不改current或历史 |
| current/history已含目标D但无本地P0 | 调用前规格未支持，不假造首次A |
| history含目标D且有P0但current为其它值 | 当前叶不定义重新选旧需求为current的业务策略，调用前规格未支持 |

真正首次写回必须把F当前字段替换/空值追加、历史、后S、合法变化及动作/调用关联、P0和N→P0、进展放在同一个原子追加请求中。旧current为空时只后S/P0，不向 `调用证据.变化组` 塞无前S的伪原子动态。新S必须含H/F/正式FT/D/实际抽象时间和A引用；P0也显式保存N/A/S，成为首值的独立来源证据。成功新状态组仅含本次新S；复用返回空新状态组。

历史兼容：先用正式本地F getter取得两种编码（旧 `历史引用` 与完整复制的 `历史项引用`）的逻辑历史，核各项为本地同主体合法D，做联合去重；本次只向 `历史项引用` 添加缺失的实际旧current和新D，不再向旧字段重复写。旧复制的标准值、实例域、聚合、历史命中及无关历史保持不变。已有某值命中项重复/非合法计数属稳定结构错误；新D第一次实际写入新增命中1，实际旧current原未记历史时可记录该已知出现一次，已有计数不因“搬入历史”递增；重复同D无实际新写不递增。新增历史和命中放同事务，getter读回不得因跨格式重复产生重复逻辑值。

事务前重新正式读取业务材料与当前定义；只比较原材料H/F/D投影，不复用已被本次动作改变的旧联合保护。完整保护和取消许可固定后，以现world原子端点保护/预留/提交/收集机制发布；写回槽在实际成功后标方法来源。CAS前提不符返回前提变化保留A；资源失败/稳定工程失败进入工程路径，不伪装正常业务结果。后读发生真实变化则返回已发布但当前读回变化，保留已经发布事实，不自动再调用原函数。

## 8. 实际结果独立读回、关闭与收束

发布内部先通过私有同窗核验P及F/S/D实际事实，才返回六引用结果；外层在函数返回、关闭窗口后必须调用public `核验本次需求执行结果(scene,N,result)` 再独立读取，不能只比较原函数自报DTO。

`读取已关闭调用证据`保持既有DTO：继续登记合法双状态变化；另核N专用发布成员引用的P及其后S/A来源，即使变化组为空仍能独立证明首值。public需求结果reader交付完整保护，不需扩通用关闭证据DTO。学习服务在正式结果路径中：原函数返回→关闭窗→取消检查→通用动作/变化核验→public需求结果核验→记录“本次实际隔离结果已独立读回”→在现C/R门报告后继未支持。该记录是有限本次执行证据，不是已发表知识，不发送正常学习完成消息，不改 `本支有正式结果` 为真。
