# 六类基础句型统一双向与空白语言场景特征组成详细设计

身份：`LANGUAGE-BASIC-SIX-BIDIRECTIONAL`。版本：v0.1。日期：2026-10-16。代码起点：main `2eb167af34c3cb5b9fb94697078619d1766fec5b`，包含 S01 结果 `ce7e682ea7468d361bc8f8b3e21c797a26d1be00`。本包新建 S03 两分支及 S05，并按 §8 组合已发布 S01/S02/S09，交付六构式统一双向入口；全部为一个同 owner、同 ABI、同工程的代码切片。

## 1. 目标与本次裁决

在每次新建的空白自然语言场景中，转换一个无修饰基础句型；交付调用期、带原文来源的类型化主张，并从该材料生成可由同一零写解释过程唯一回读的文字：

| 构式 | 有序结构 | 直接形成的含义 |
| --- | --- | --- |
| S03 概念条件 | `E1 的 FT1 是 概念 C1` | 本次匿名 E1 的 FT1 满足特征概念 C1 的主张 |
| S03 整数 | `E1 的 FT1 是 整数 V1` | 本次匿名 E1 的 FT1 取规范十进制数字 V1 的主张 |
| S05 组成 | `E2 是 E1 的 一部分` | 本次匿名 E2 为匿名 E1 部分的主张 |

`E` 槽的词面从已登记词条召回抽象存在概念，唯一后按每次**出现**分别实例化；不是查找现实中某个同类 E。S05 的部分是第一词出现、整体是第二词出现；即使两个词对应同一个 C，也分别建立两个匿名 E，必须有不同实例身份。S03 只为主体 E 建实例；FT、C、数字都是主张的参数，不为它们建立虚构存在，也不更新 E 的正式特征槽。主张关系保存在返回 DTO 中；语言场景 owner 只保存本次匿名概念实例。两者不能混称为已经持久化的组成/特征事实。

用户本窗口对具名范围已裁决：本次只做空白语言场景中单个短语/句型转换，不以交互上下文、现实归并、代词指向或正式语言记录保存作为前置。这个裁决替代 7250 一般输入“不自动建立实例”在本临时语言场景中的限制，不外推到现实世界。

整数用阿拉伯数字词面，不用 `int64` 表示本次主张值。当前种子知识以 `I64标量特征类型/I64标量` 编码；本叶仍识别这条现存知识的结构，但其数值槽在本具名词面转换范围采用本次裁决：保存规范化十进制字符串，不转整数机器类型，不计算、不用 `int64` 上下界或 FT 值域拒绝词面，不调用特征值服务。FT 仍须是**整数兼容**的正式特征类型根：正式读取的材料类型为 `I64标量` 且值域为 `vector<特征概念I64闭区间>`；不把颜色等数组、字符串或存在引用类型当整数 FT。仅 V 的表示和数值范围不沿用机器整数限制，FT 的类型角色约束继续保留。它不修改持久知识定义、特征概念定义、正式特征准确值合同，也不建立任意精度算术服务。

正式依据：[0050](../0050_项目通用机器逻辑与禁止性规则总纲_20260721.md) §3.2、[1100](../1100_根规范_语言记录_20260720.md)、[2210](../2210_根规范_概念名称关系.md)、[2220](../2220_根规范_概念空间.md)、[2340](../2340_根规范_自然语言知识.md)、[7160](../7160_子规范_特征概念形成组织与名称关联.md)、[7230](../7230_子规范_语言材料知识与交互字段.md)、[7240](../7240_子规范_自然语言双向转换与组织规则.md)、[7250](../7250_子规范_最小汉语知识与语言学习.md)。当前具名裁决与旧物理知识形状的适配只按上段执行，不推广为全仓规则。

## 4. 只读解释、数字及检索合同

首版只接受上表三个结构，全部命名槽各为一个完整已登记词条。固定词均来自所用已发布知识，并读回校验为 S03 的“的/是/概念”或“的/是/整数”、S05 的“是/的/一部分”。不接受首尾空格、标点、修饰、子规则、代词和未覆盖片段；词项之间可以全部无空格，也可以每两个项之间恰一个 ASCII 空格，不能混用两种布局。源范围均为零基、半开 Unicode 标量范围，空格不属于角色或固定词范围。

命名槽经 `按已登记词条最长匹配` 及词条 getter 对齐；固定项与知识词条逐项相同。S03 整数前五项照此处理，末尾数字按知识中“类型化字面值”项识别：数字串无需事先作为一个完整词条登记，已有数字词条或数字内部的最长匹配切分不得改变整个末槽范围。接受词法 `[+-]?[0-9]+`，至少一位 ASCII 数字；去可选正号、去绝对值前导零，全部为零时结果为 `0`，否则保留负号；没有数字位数上限，不能转换到机器整数。拒绝小数点、指数、分组符、汉字数词和全角数字为本构式不支持的词面；大于 `int64` 的合法数字仍完整形成主张。输出使用规范十进制；原文数字及范围始终保留，往返比较规范值，不要求 `+0005` 原样复现。词面合法不跳过 FT 的整数类型约束；非整数 FT 返回角色不相容，而不是数值越界。

两端名称召回必须读完全部名称关系，指代名称虽须读回但不作为本叶命名槽候选。E 只保留抽象存在概念；FT/C 只保留特征概念。FT 用 `比较单特征概念(FT,FT)` 核验根身份等于 FT。概念分支再对每个 `(FT,C)` 调用 `比较单特征概念(FT,C)`，只保留返回的正式根为 FT 的组合；这就是依据句型缩小检索范围。不能因其它根的 C 先出现就丢弃，不能选排序首项。整数分支还按 §1 正式读取 FT 材料类型及值域 variant，筛出整数型根；只确认类型形状，不将十进制 V 转成区间端点，也不验证该值是否可写入 FT。S05 没有已发布的类型间组成适用约束，故不能臆造“车轮只能属于汽车”等过滤；分别保留两个 E 槽的全部抽象存在概念组合。

三个私有子解释器只读，主只读分派合并全部候选后判断：跨构式含义多项为`构式多义待解`；同构式不同概念角色组合为`概念多义待解`；相同语义多适用知识为`多规则待解`。同一词条同一概念的重复名称证据不构成语义多义；完整保留证据，并按名称关系稳定编码选择唯一执行代表。候选排序键为 `(构式,知识,逐角色概念/规范数字,逐名称关系,逐范围)`，绝不按数量预算截断候选。任何知识、词条、名称、根比较读取未完成时，清空依赖完整性的候选并退出，不能把部分候选当全部。词条完整缺失为未知词；已知词无名称为缺名称；只有不相容类别为角色不相容。

私有主要函数签名固定如下，声明及定义均仅在新 cpp 匿名命名空间内。`只读上下文`只借用五个 const 服务，字段名依次为`语言服务/词服务/名称服务/存在概念服务/特征概念服务`，不持有可写端口；`只读结果`为输入状态、完整候选组与本次知识/词条/名称/概念/根比较值式快照。工程可拆纯辅助函数，但不得改变以下职责和字段来源。

## 5. 形成场景与部分写入

公开正向函数依序完成：只读主分派→唯一结果→同材料复核→`建立空场景()`一次→按 E 出现顺序调用`实例化概念()`→写后全部读回→返回含义。

S03 只对出现1调用一次；S05 对出现1和2分别调用，概念相同也不能合并、复用或先查询已有 E。既有实例化服务给出的对象是匿名语言实例，不生成“杯子A”或永久名称。实例建立成功即加入`已取得对象绑定组`；任何失败都保留已经实际取得的场景/对象身份，不自行回滚、删除或补造尚未成功的对象。

写后核验场景确实存在，每个 E 的场景、来源概念、存在概念实例种类与本次角色一致；S05 两 E 身份必须不同。重新读取正式知识、固定词、命名出现及根比较并与写前材料逐字段核对，一致才形成完整含义。若已建场景但某个实例失败或读回失败且函数以结构化非成功返回，返回具名未完成和实际可确认的身份；`含义`为空。成功后绑定组恰有 S03 一项或 S05 两项。这里不是跨 owner 原子事务，不把正常返回非成功说成零副作用。身份回传保证仅适用于这种结构化返回；工程异常向上送出时保留已经发生的结构、不伪称回滚，但不承诺有返回 DTO，不新增携带身份的异常类型、异常公开合同或日志链。

统一输入请求全部读取额度必须大于零，只为原有公开读取/解释 API 适配而保留；按同名字段原样传入 S02/S09，不写极大常数，不以语法限制冒充额度。三构式与 S01 请求按同名必要字段构造；统一层核验原文标量数。名称/组合/确认或知识资源不能完成范围时是非成功，完整候选组清空；不能以剩余已成功分支宣布唯一。这些旧 ABI 债不改变 0050 的完整范围要求，本包不扩展其使用成新持久预算账。

六构式只读分派调用所有已发布适用结构的识别分支，S01 私有只读函数提到共同 cpp 后由旧 S01 与本统一入口共同调用，完整签名为：

```cpp
struct S01只读结果 final {
    语言场景归类输入状态 状态;
    std::vector<语言场景归类候选> 完整候选组;
};
S01只读结果 只读识别语言场景S01(const 语言场景归类输入请求&,
    const 新_语言类&, const 新_词类&, const 概念_名称关系类&,
    const 概念_存在类&, const 概念_特征类&);
```

它只公开在业务内部共同头，不产生节点；旧 S01 两入口改调该函数，保留签名/枚举不变。新基础 cpp 的统一零写分派私有函数签名为`语言基础统一输入结果 只读识别六类基础句型(const 语言基础统一输入请求&, const 新_语言类&, const 新_词类&, const 概念_名称关系类&, const 概念_存在类&, const 概念_特征类&, const 新_存在类&)`；其含义/场景/绑定输出始终为空，只回完整候选和判定状态。它必须区分“该结构没有句面匹配”与“已适用结构但完整读取失败”，不能把无关分支的正常结构未支持当作工程失败，也不能隐藏适用分支真实读取未完成。

统一层先按完整知识的有序结构、词条边界及固定项确定句面适用分支，再调用相应零写解释；这一步只是结构筛选，不从固定词直接裁决语义。六分支候选按 §4 原则去重和判定，跨分支多结果保留完整 variant 候选。S02/S09 内部多义候选必须原样保留；图范围无唯一时不按固定词或枚举顺序强选。再次完整只读识别且所有字段一致后，唯一 S01 才调用已有正向写函数，唯一 S03/S05 才调用 §3 正向写函数；二次调用的子结果仍须与先前选定候选一致，任何差异按实际副作用返回未完成。S02/S09 直接形成纯概念含义而不建立空场景。写入后统一结果适配真实场景和对象绑定，不能只保留成功枚举而丢失部分写入身份。

统一输出按含义 variant 分派：S01/三构式直接复用各自可逆输出；S02 先核验纯概念来源、当前概念/知识和类别，再构造现行 `基础概念上下位可逆表达请求`，按候选构造两概念参数与名称选择，调用已有可逆生成；未选名时用共同函数完整枚举当前名称并逐组尝试，不忽略多义。S09 的私有内容入口签名为`语言基础统一输出结果 生成无受询者概念归类确认文字(const 语言基础统一输出请求&, const 新_语言类&, const 新_词类&, const 概念_名称关系类&, const 概念_存在类&, const 概念_特征类&, const 新_存在类&)`，严格按上述子 S02 可逆生成和外层正式知识组织；不调用旧强制受询者的 S09 输出入口。

纯概念来源对齐覆盖完整原文有序叶，校验与 §6 相同；S02 两名称对应主体/归类，S09 两名称与外层子含义角色映射一致，提问范围、确认范围为主张成立与否，外层/子知识和“吗”位置保留。统一输出请求全部额度字段必须大于零；对所有六分支，按**实际生成文本**严格 UTF-8 解码得到标量长度，在统一回读前同时核验 `最大输出标量数` 和 `最大回读原文标量数`。超出任一字段即返回`额度不足`，清空文本、构式、对齐与知识输出；不能因 S01/新三构式子 API 没有同名参数而忽略外层字段，也不能截断文字后回读。该检查只履行本次请求，旧子 API 的额度语义不扩展。任何实际生成文本随后必须经六构式共同零写识别再次唯一回读，与原含义的构式、概念身份、类别、方向、知识组、作用域、数字相同才交付；旧子输出自行回读不能替代统一完整闭集回读。S09 受询者仍为空；S02/S09 不生成匿名 E。输出知识组 S09 为外层、子层顺序，其余一项；输出对齐范围全部针对实际输出文本，不能转抄旧原文范围。
