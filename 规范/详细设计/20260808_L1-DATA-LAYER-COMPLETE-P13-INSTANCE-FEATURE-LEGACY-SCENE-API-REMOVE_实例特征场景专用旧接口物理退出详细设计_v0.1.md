# L1-DATA-LAYER-COMPLETE-P13-INSTANCE-FEATURE-LEGACY-SCENE-API-REMOVE 实例特征场景专用旧接口物理退出详细设计 v0.1

日期：2026-08-08

## 1. 目标与完成条件

本叶物理删除 `L1实例特征服务` 中已经没有生产调用者、仍依赖第一层业务标签、领域意图、旧幂等探测、完整快照和 legacy `提交写集` 的三条“初始场景宿主”旧入口：

- `建立初始场景I64实例特征`；
- `换代I64实例特征当前值`；
- `读取I64实例特征`。

当前正式生产链已经由“实际存在宿主”入口替代：`建立实际存在I64实例特征`、`读取实际存在I64实例特征` 和 `换代实际存在I64实例特征当前值` 均使用第一层业务中性 CRUD，并由运行期上下文公开持有同一具名服务。旧三入口在当前生产代码中只有定义、没有调用者，继续保留只会维持第二套业务标签提交面和普通读取完整快照成本。

完成必须同时满足：旧三入口及其专属 DTO、校验、编码、幂等账、快照扫描和 legacy 写入辅助从生产代码消失；保留入口的签名、DTO、三处中性写入、逐项读取、锁、定位、状态映射和运行期装配零语义变化；双配置完整构建与模块依赖扫描通过。

本叶不是第一层验收，不新增替代入口、兼容转发、测试驱动或日志 PASS，也不证明第一层已经完善。

## 2. 当前代码事实与裁决

基线 `64ab43f1fd4f319dab36664dcc2749515f70475f` 的当前事实：

1. 三个旧公开函数和三个旧 DTO 在 `海中鱼巣/` 内均只有声明或定义，没有调用点；
2. 同一服务中正式“实际存在宿主”入口已经形成中性登记、实例建立、当前值换代和权威读回；
3. 旧三入口专属代码仍贡献两处 `探测幂等`、两处 legacy `提交写集` 和三处 `读取完整快照`；
4. 当前全领域仍有 5 个文件、9 处 legacy `提交写集` 和 5 个文件、10 处旧 `探测幂等`；本叶完成后目标分别降为 4 文件 7 处和 4 文件 8 处；
5. `L1实例特征.数据.h` 和 `服务.L1实例特征.ixx` 当前没有异主 dirty，现有 P0-FIX、路线、旧 WORLD-TREE 和构建目录与本叶路径不重叠。

正式依据为 4015 v0.6、4030 v1.4、ACCEPTANCE-01 v0.4、4110、4170，以及 P7/P8 已发布的“实际存在宿主”中性入口合同。旧 P3/P4 详细设计和 P15 领域意图设计只作历史材料，不能要求继续保留与现行规范冲突的未调用入口。

裁决为“删除”，不是“迁移”：初始场景是场景事实，不是实例特征宿主业务身份；当前合法宿主由实际存在事实所有者提供。把旧入口改成另一个中性转发仍会保留重复业务语义和第二公开面。

## 3. 精确删除与保留合同

### 3.1 数据头删除

从 `海中鱼巣/领域/L1实例特征.数据.h` 删除且不替代：

```text
初始场景I64实例特征建立请求
I64实例特征读取请求
I64实例特征当前值换代请求
初始场景I64实例特征建立请求有效
I64实例特征当前值换代请求有效
```

保留登记、实际存在宿主建立 / 读取 / 换代请求、实例事实、状态和结果 DTO。合同版本不提升，因为本叶删除的是无生产调用者且已被正式中性入口替代的旧表面；任何仍试图编译旧类型的代码必须显式失败，不能获得兼容别名。

### 3.2 服务删除

从 `海中鱼巣/领域/服务.L1实例特征.ixx` 删除且不替代：

1. 三个旧公开函数；
2. 只为旧函数服务的领域意图编码、请求比较、legacy 写集形成 / 提交、首次请求 / 首次结果缓存；
3. 只为旧场景宿主实例读取服务的完整快照唯一性扫描与逐项 legacy 读取；
4. 只为旧换代入口服务的变体账、提供者见证、执行证据和快照前探测；
5. 删除后变成未使用的私有类型、字段、函数和头文件。

删除必须以符号依赖闭包为准，不能按行号硬切；若某个辅助仍被保留的实际存在入口使用，则保留并不得改写。

### 3.3 必须保持不变

下列公开能力和行为必须逐项保持：

```text
建立登记（const 与兼容非 const 转发）
读取当前登记
建立实际存在I64实例特征（const 与兼容非 const 转发）
读取实际存在I64实例特征
换代实际存在I64实例特征当前值（const 与兼容非 const 转发）
```

保留入口仍只使用 `提交中性写集`，仍以实际存在、特征定义和逐项中性事实读回完成业务裁决；不得增加完整快照、业务标签、领域意图、旧幂等探测、缓存事实或第一层专用验证。

## 4. 错误、事务与生命周期

本叶不执行事实写入，不迁移已有内存数据，不改变幂等键域或中性事务。被删除旧入口在当前生产代码中不可达，因此没有运行期兼容期和状态迁移。

保留入口的失败分类、同键同义、同键异义、事实代次漂移、资源失败、内部不一致和写后权威读回保持原样。编译期仍引用旧 DTO 或旧函数是明确的源码迁移错误，不通过默认结果或兼容重载隐藏。
