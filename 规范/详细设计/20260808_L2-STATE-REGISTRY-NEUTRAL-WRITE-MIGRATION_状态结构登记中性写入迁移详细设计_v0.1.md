## 6. 建立登记唯一控制流与裁决顺序

1. 取得现有递归互斥锁，进入现有异常边界。
2. 校验公开请求；失败返回 `入口拒绝`、无登记，零代次预读和零提交。
3. 调用一次 `读取中性当前事实代次` 得到预读 P。要求状态成功、合同版本精确且 P 非零；否则映射结构化读取非成功。P 只证明入口健康并保存首次成功诊断，**不得因 `P != 请求.期望事实代次` 在提交前返回**。
4. 映射 `0x0C` 中性幂等键，形成第 5 节完整原请求写集。
5. 对每个通过公开校验且预读健康的请求物理调用 `提交中性写集` 恰一次。禁止先调用 `探测幂等`，禁止以缓存或 P 代替 L1 最终裁决。
6. 先按 L1 返回状态裁决：
   - `成功`：映射 `已提交`；额外要求 P 等于请求期望代次。若 L1 返回成功但 P 不等，冻结的 L1 顺序或结果发生矛盾，返回 `内部不一致`。
   - `精确重复`：映射 `幂等读回`；允许 P 高于原请求期望代次，不得提前阻断。
   - `幂等冲突`：映射 `幂等冲突`。同键只改变期望代次也是完整请求异义，不得改写成漂移。
   - `事实代次漂移`：映射 `版本漂移`。新键旧期望及 P 后竞争推进均由 L1 最终裁决。
   - `入口拒绝`、`未找到`、`已退出`、`资源失败`、`内部不一致`：按中性映射返回，无登记。
7. 成功类共同核对合同版本、回显幂等键、非零首次发布代次和七项映射完整唯一。首次成功必须 `是否形成内存权威发布=true` 且重试边界为 `不适用`；精确重复必须发布标志 false 且重试边界为 `原幂等键读回收敛`。
8. 以映射取得七编码，调用 `精确读回状态登记`。首次 / 重复均传入 L1 返回的首次发布代次，要求七节点共同创建代次等于该值；当前读回截止可以晚于首次发布代次。
9. 读回成功后，若已有定位缓存则要求七编码逐项相同；只在成立时更新 `登记_` 的当前截止并返回原写入业务状态（`已提交` 或 `幂等读回`）。
10. `std::bad_alloc` 返回 `资源失败`；其它未知异常返回 `内部不一致`。

顺序矩阵：

| 请求 / 当前状态 | L1 最终裁决 | 状态领域结果 |
| --- | --- | --- |
| 新键，P 等于期望，提交时仍同代 | 成功并发布新代次 | 精确读回后 `已提交` |
| 原请求精确重复，当前代次已高于原期望 | 精确重复，复用首次七编码，零发布 | 精确读回后 `幂等读回` |
| 同键、同七节点但更换期望代次 | 同键异义冲突 | `幂等冲突` |
| 新键，P 已不等于期望 | 事实代次漂移，零发布 | `版本漂移` |
| 新键，P 等于期望但提交前竞争推进 | 事实代次漂移，零发布 | `版本漂移` |

## 7. 七编码精确中性读回

共享私有 helper 由建立登记和读取当前登记复用：

1. 输入七编码，要求全部有效且两两不同；创建路径另输入非零首次发布代次。
2. 调用 `读取中性当前事实代次` 得到 G0；要求成功、合同精确、G0 非零。
3. 按本地键顺序循环七编码，各调用一次 `读取中性当前节点`；要求合同精确、查询编码回显一致、读取事实代次等于 G0、事实存在、编码一致、未退出、当前属性组为空、节点形状符合第 5 节。
4. 七节点创建事实代次必须非零、彼此相同且不晚于 G0；创建路径还要求共同创建代次等于 L1 成功类结果的首次发布代次。
5. 再读当前事实代次 G1；要求成功、合同精确、G1 非零且等于 G0。逐项读取代次或 G1 不等 G0 返回 `版本漂移`，不返回混代登记。
6. 组装现有 `L1状态结构登记`，`事实截止代次=G0`，通过现有完整性校验后返回 `已读取`。

读取中性状态映射固定：未找到、已退出、属性未设置返回 `未找到`；入口拒绝、资源失败和内部不一致保持相应分类；成功但合同、回显、事实、生命周期或形状矛盾返回 `内部不一致`。

L1 成功类结果的 `事实代次` 是首次发布代次；登记中的 `事实截止代次` 是本次 G0 当前读截止。精确重复或后续当前读取时二者允许不同，不能强制当前截止等于首次发布代次。

`读取当前登记()` 取得锁后：无 `登记_` 返回 `未找到`；有定位时复制七编码并调用上述 helper，不直接返回缓存。helper 成功维持 `已读取` 并携带本次截止的完整登记；失败无部分登记。

## 8. 并发、失败与生命周期

- 服务锁只保护定位缓存；L1 最终拥有完整请求幂等、代次、候选和原子发布。
- 预读 P 不是幂等探测、事务许可或提交授权。它只能在 L1 首次成功后检查不可能的顺序矛盾，不能覆盖 L1 的精确重复、冲突或漂移。
- 精确重复复用首次七编码并零新发布；同键异义包括只改期望代次，由 L1 返回冲突。
- 发布后精确读回发生并发推进时返回版本漂移；不重试、不补写、不换幂等键、不缓存混代材料。
- 发布成功后读回失败不能撤销已发布事实，只返回结构化非成功并保留 L1 实际状态。
- 登记缓存不拥有节点当前性；L1 中性当前读取裁决节点是否仍存在、退出和形状是否一致。
