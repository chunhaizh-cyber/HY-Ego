## 1. S0 与最早缺口裁决

创建侧基线为 `e2fc1ce4caf49412d9df11fa7a2e16ed020b7758`，`main == origin/main`、
ahead/behind 为 `0/0`、Git index 为空。该基线相对派发基线只增加 P16 独立验收记录；其失败
收口属于 P16 原计划返工，不改变方法登记根合同，也不是本叶依赖。

正式 `L1-SIMPLIFY-METHOD-ROOT-R1-CURRENT-READ` 已冻结方法登记根、系统角色属性类型、方法
领域服务和固定强类型角色值的当前读取形状，但定位凭证只能来自后继正式发布结果或其强类型
读回。当前正式代码没有等价的新 L1 方法登记根写集 provider；旧 `服务.方法.ixx`、旧
`数据操作.需求任务方法.ixx` 和旧四仓/句柄链不能提供新 L1 三类事实草案。

依赖链机械顺序为：

```text
R1 当前读取合同
-> 本叶固定首次完整 L1 草案
-> 后继固定领域意图、幂等和原子发布
-> 从正式映射形成 R1 强类型定位凭证
```

因此原子发布者之前仍有一个可独立施工的纯值缺口：把 R1 已冻结的四项结构材料确定映射为
连续本地键、L1 三类写项、属性槽和通用发布后读回计划。本叶不证明仓内尚无登记根；“首次”
只表示草案形状用于后继首次发布路径。唯一首次意图、同义/异义和重复发布防线归后继发布者。

## 3. 唯一所有者、物理位置和依赖方向

未来实现只新增：


`L1方法登记根首次写集数据操作` 是方法领域中首次登记根 L1 草案形状的唯一所有者。它无
成员、可默认构造，只执行同步纯值变换。数据合同依赖 R1 数据合同以复用唯一
`方法固定系统角色`，不得复制第二角色枚举或让 R1 反向依赖本叶。

```text
后继方法登记根原子发布者
-> L1方法登记根首次写集数据操作::形成方法登记根首次L1草案
   -> R1 方法登记根数据合同 + L1事实基座写项DTO
```

本叶不调用 R1 根函数；后继发布成功后从 P15 新编码映射形成 R1 定位凭证。草案、本地键和
输入引用只活到调用栈结束，不得保存为当前事实、缓存或正式定位。

合同/规则版本不匹配返回版本漂移；零预期事实代次返回入口拒绝。只有已形成携带草案，全部

## 5. 连续本地键和唯一事实形状

本地键固定连续为 1—4，不接受调用方选择：

| 本地键 | 事实 | L1 形状 |
| ---: | --- | --- |
| 1 | 方法登记根 | 普通节点 |
| 2 | 系统角色属性类型 | 属性类型节点，值表示种类 `I64` |
| 3 | 方法领域服务 | 普通节点 |
| 4 | 登记根角色值 | 值；所属键1、属性类型键2、材料I64值1、来源键3 |

属性槽恰一：`(所属键1, 属性类型键2) -> 当前值键4`。关系、退出事实均为空。强类型值必须由
`static_cast<std::int64_t>(方法固定系统角色::方法登记根)`形成，精确为1；不得使用旧
`分层方法角色::方法登记根 = 6`、名称、主键、数组位置、默认稳定编码、日志或显示编号。

精确数量固定：

```text
新节点3；新关系0；新值1；属性槽变更1；退出事实0；首次新编码4。
```

三个节点与角色值一起构成 R1 后继定位/读取所需的完整最小结构。节点类型不授予额外方法
资格；方法首、生命周期、规格和动作入口必须在各自后继叶另行发布。

## 6. 通用发布后读回草案

`发布后读回计划.计划版本` 固定为 `L1通用发布后读回计划版本`，项目恰5项，顺序固定：

1. 节点键1：普通、本次发布创建、当前；
2. 节点键2：属性类型、I64、本次发布创建、当前；
3. 节点键3：普通、本次发布创建、当前；
4. 值键4：逐字段复制所属、属性类型、材料和来源，本次发布创建、当前；
5. 属性槽：键1/键2当前值精确为键4。

计划覆盖全部4个新编码和1个当前槽，不多读、不漏读，不含关系或退出读回。它只是后继发布
请求的读回草案，不执行读取，也不证明根已经发布或仍为当前。

## 7. 确定性、完整性和后继消费边界

形成后必须自证：

1. 本地键1—4连续、非零、唯一；
2. 三节点的种类和属性类型表示逐项精确；
3. 值键4只引用键1—3，材料形状为I64且角色精确为1；
4. 唯一槽逐字段指向键4；
5. 关系/退出均为0，读回恰覆盖4个新事实和1个槽；
6. 草案不含稳定编码、幂等、摘要、标签、领域意图组、执行证据、事务或发布结果。

相同合法请求在单线程、重复调用和并发调用中逐字段相等；函数不读取时间、随机数、线程号、
日志、SQL、索引、旧仓或当前 L1。

后继发布者必须独立冻结并验证：固定 G 组/入口变体/业务操作标签、领域意图确定编码、幂等域、
P15 provider 前探测、同义/异义、一次事务和新编码映射。后继只有在正式发布及读回成功后，
才能把映射键1—3和键4机械转换为 R1 定位凭证与角色值见证。本叶不得以草案成功替代上述
首次唯一性、发布或当前读取证明。
