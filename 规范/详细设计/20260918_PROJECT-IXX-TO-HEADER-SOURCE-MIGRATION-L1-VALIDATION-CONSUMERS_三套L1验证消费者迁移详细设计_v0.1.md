# 三套 L1 验证消费者迁移详细设计

设计身份：`PROJECT-IXX-TO-HEADER-SOURCE-MIGRATION-L1-VALIDATION-CONSUMERS`

日期：2026-09-18
版本：v0.1
状态：施工设计

## 1. 目标与当前事实

本设计承接 `PROJECT-IXX-TO-HEADER-SOURCE-MIGRATION-POST-CONSUMER-CLOSURE-AUDIT` 的已发布审计结论。审计输入基线 `f28ac086ecf3db403945945e92ac05d606a1161a` 中，以下三套仍有实际回归价值的 L1 参数验证工程均为活动旧格式消费者：每套各有一个 C++ `import 海中鱼巣.核心.服务.L1事实基座;`，以及五个 `.ixx` `ClCompile` 项，共 18 条活动引用。

```text
L1中性当前引用闭包保护参数验证
L1历史关系组参数验证
L1历史属性值组参数验证
```

生产主链已经是 `.h/.cpp`，公开替代入口为 `海中鱼巣/核心/服务.L1事实基座.h`。该头已传递包含三项验证实际使用的 L1 公共 DTO、CRUD、仓库与恢复声明，故迁移不新增适配层、生产函数、L1 ABI 或验证语义。

完成条件是三套验证工程都仅以该公开头编译原有验证源，并在 Debug/Release x64 保持其既有可执行验证行为；三项目、三源均不再有旧模块格式活动依赖。

## 2. 冻结范围与不变合同

唯一允许修改的生产外文件为：

```text
验证工具/L1中性当前引用闭包保护参数验证.cpp
验证工具/L1中性当前引用闭包保护参数验证.vcxproj
验证工具/L1历史关系组参数验证.cpp
验证工具/L1历史关系组参数验证.vcxproj
验证工具/L1历史属性值组参数验证.cpp
验证工具/L1历史属性值组参数验证.vcxproj
```

每个 `.cpp` 的唯一变更是以：

```cpp
#include "../海中鱼巣/核心/服务.L1事实基座.h"
```

取代其唯一 module `import`。验证参数、断言、写集、退出码、输出文本和运行入口均不得改变。

每个 `.vcxproj` 只删除恰好五项旧 `.ixx` `ClCompile`：`合同.L1公共事实`、`合同.L1事实基座`、`合同.L1中性CRUD`、`仓库.L1事实基座`、`服务.L1事实基座`。保留该验证自身 `.cpp` 的唯一 `ClCompile`、全部配置、工具集、链接选项和工程标识；不新加头文件项，不修改 solution、filters 或任何生产工程。

禁止修改 `海中鱼巣/**`、L1 头/源/ABI、三份 PowerShell 运行器、世界树根专项、其它验证工程、正式规范、迁移历史记录及当前异主 WIP。专属施工/验证记录是额外允许输出。

## 3. 施工顺序与失败收口

1. S0 必须从当前正式 HEAD 重新读三源、三项目和 `服务.L1事实基座.h`，确认每源仅有目标 `import`、每项目仅有五项目标旧 `ClCompile`，并确认文件与语义没有其他写入所有者。若实际基线已不同，停止本计划并由计划支撑修订；不得猜测删除项。
2. 对每个验证源完成单行入口替换；不改变任何验证逻辑。
3. 对对应项目删除五项旧模块编译项；该项目不得再把同名 `.h` 当作编译单元加入。
4. 静态复核三源无 `import`/`module`/`.ixx`/`.cppcpp`，三项目无 `.ixx`/`.cppcpp` `ClCompile`，且仍各有且仅有本验证 `.cpp` 编译项。
5. 以隔离 `OutDir`、`IntDir` 分别 Rebuild Debug、Release x64；按每个项目原有运行合同调用输出 EXE，并保留命令、退出码与结构化输出。编译或断言失败只在上述六文件中追溯头源迁移错误；若发现 L1 公开头缺少原验证所需声明，停止并具名退回 L1 提供者设计，禁止以本计划扩展 L1。

## 4. 验证合同与声明边界

每一项目在 Debug/Release x64 均必须：工程 Rebuild 退出 0、原验证程序退出 0、输出保留原成功断言。所有六次构建使用任务专属 `D:\TEMP\海中鱼巣\PROJECT-IXX-TO-HEADER-SOURCE-MIGRATION-L1-VALIDATION-CONSUMERS\<轮次>\` 输出，避免读取或改写仓库构建产物。

另运行目标路径 `git diff --check`、`python .\tools\check_specs.py --strict`，并保存三源/三工程的旧格式零命中清单。提交只可包含本设计明确的六文件和专属施工/验证记录。

本计划完成仅证明三套既有 L1 回归验证消费者完成物理头源迁移，及其既有检查仍能执行；不证明 L1 逻辑、持久恢复、生产主链、其它验证消费者或全项目业务闭环。
