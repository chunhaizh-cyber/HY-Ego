# DATA-L2 普通概念建立与完整读取公开值式合同详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-ORDINARY-CONCEPT-PUBLIC-DTO`

状态：设计就绪

## 1. 目标与完成边界

在不改变现有四本体根三入口的前提下，为 `DATA-EXT-08` 冻结普通概念“原子建立 + 当前 / 历史完整读取”的第一份公开值式 C++ 合同。合同必须让后继唯一 `L2概念结构服务` 能机械实现：独立概念身份、本体根归属、完整抽象签名、至少一个直接上位、初始定义关系、来源证据和初始活跃生命周期同一概念 owner 事务建立，并在具名截止逐字段读回。

本叶只新增合同头并登记工程，不增加服务函数、owner、写入口、普通应用 getter 或生产装配。世界事实支持关系、独立上下位 / 定义增改退、生命周期迁移、普通概念不可逆退出、名称关系和概念树投影均为后继叶；四本体根 DTO、请求和三项 C1 入口保持逐字不变。

## 2. 正式依据与当前事实

依据 0050、2220 v1.5、4240 v0.6、7140 v1.2、现行 `L2结构公共.数据.h`、`不可变材料.数据.h` 与根服务结果 `73ef1172ae468246c1ec71613f60e42a832c4d8d`。

当前正式代码只有 `L2概念本体根建立请求`、按角色读取和全部当前根读取；没有普通概念 DTO 或服务入口。不可变材料服务已经发布，六类世界结构和概念 owner 已存在，但材料生产根尚未进入普通应用配置，所以本叶不得借 DTO 施工选择默认路径或宣称普通概念服务可运行。

普通概念合同使用独立头 `海中鱼巣/领域/L2普通概念结构.数据.h`。该头正常包含共同 L2 合同和不可变材料数据头；不修改 `L2概念结构.数据.h`，从而保持阶段 18 根合同的物理依赖和 ABI 不变。

## 3. 精确公开类型

合同版本固定：

```cpp
inline constexpr std::uint32_t L2普通概念结构合同版本 = 1;
```

### 3.1 生命周期与世界关系强类型引用

```cpp
enum class L2概念治理生命周期状态 : std::uint8_t {
    活跃 = 1,
    冷却 = 2,
    退役 = 3
};

struct L2概念特征值引用 final {
    L2特征实例身份 特征实例;
    稳定编码 值稳定编码;
    friend bool operator==(...) = default;
};

struct L2概念动作引用 final {
    稳定编码 值;
    friend bool operator==(...) = default;
};

using L2概念世界关系端点 = std::variant<L2场景身份, L2存在身份,
    L2特征定义身份, L2特征实例身份, L2状态身份, L2动态身份,
    L2因果身份, L2概念动作引用>;

enum class L2概念世界关系类别 : std::uint8_t {
    场景父子 = 1,
    场景成员 = 2,
    场景宿主存在 = 3,
    特征宿主 = 4,
    特征定义 = 5,
    状态主体 = 6,
    状态特征实例 = 7,
    动态主体 = 8,
    动态前状态 = 9,
    动态后状态 = 10,
    因果条件状态 = 11,
    因果动作引用 = 12,
    因果结果状态 = 13
};

struct L2概念世界关系引用 final {
    L2概念世界关系类别 类别 = L2概念世界关系类别::场景父子;
    稳定编码 关系稳定编码;
    L2概念世界关系端点 源;
    L2概念世界关系端点 目标;
    friend bool operator==(...) = default;
};

using L2概念定义目标 = std::variant<L2概念身份, L2场景身份,
    L2存在身份, L2特征定义身份, L2特征实例身份,
    L2概念特征值引用, L2状态身份, L2动态身份, L2因果身份,
    L2概念世界关系引用>;
```

关系类别固定校验端点方向：场景父子为场景到场景；场景成员 / 宿主为场景到存在；特征宿主为特征实例到存在；特征定义为特征实例到特征定义；状态主体 / 特征实例为状态到对应端点；动态主体 / 前状态 / 后状态为动态到对应端点；因果条件 / 结果为因果到状态；因果动作为因果到独立强类型 `L2概念动作引用`。该动作引用只包裹现行 `L2因果事实::动作` 的非零稳定编码，不把它猜成方法身份或动作入口身份。裸稳定编码、错端点 variant 或未知枚举无效。

`L2特征定义身份` 同时承载基础与正式派生特征身份；是否为二次至 n 次特征，必须由后继服务在同一截止经 `L2统一特征定义事实` 的真实阶次、直接来源和派生规则完整读回证明，DTO 不建立第二种特征身份。`L2概念世界关系引用` 只闭合当前六类世界服务已经公开、可以凭稳定关系编码和强类型端点正式读回的十三类关系，不建立通用裸关系入口。

### 3.2 请求项与正式事实项

```cpp
struct L2概念签名值式项 final {
    std::uint64_t 角色 = 0;
    std::uint64_t 顺序 = 0;
    L2原始值材料 值;
    friend bool operator==(...) = default;
};

struct L2概念定义引用项 final {
    std::uint64_t 角色 = 0;
    std::uint64_t 顺序 = 0;
    L2概念定义目标 目标;
    friend bool operator==(...) = default;
};

struct L2概念本体根归属事实 final {
    L2概念身份 本体根;
    L2概念身份 概念;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};

struct L2概念签名规则事实 final {
    L2概念身份 概念;
    不可变材料身份 规则材料;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};

struct L2概念签名值式事实 final {
    L2概念身份 概念;
    L2概念签名值式项 项;
    稳定编码 值稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};

struct L2概念定义关系事实 final {
    L2概念身份 概念;
    L2概念定义引用项 项;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};

struct L2概念直接上位事实 final {
    L2概念身份 上位概念;
    L2概念身份 下位概念;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};

struct L2概念来源证据事实 final {
    L2概念身份 概念;
    不可变材料身份 证据材料;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};

struct L2概念治理生命周期事实 final {
    L2概念身份 概念;
    L2概念治理生命周期状态 状态 = L2概念治理生命周期状态::活跃;
    稳定编码 事实稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};
```

签名值式项和定义引用项分别按 `(角色, 顺序)` 严格升序，并且两组的键联合不得重复。两个签名项组都允许为空；完整签名仍由非零签名规则材料和两个确定组共同成立，数据层不得另行发明“至少一项”门槛。直接上位按上位概念编码严格升序；来源证据按材料身份编码严格升序。普通概念至少一项直接上位、至少一项来源证据。

### 3.3 完整普通概念、建立和读取

```cpp
struct L2普通概念事实 final {
    L2概念身份 概念;
    L2节点族身份来源事实 身份来源;
    L2概念本体根归属事实 本体根归属;
    L2概念签名规则事实 签名规则;
    std::vector<L2概念签名值式事实> 签名值式项;
    std::vector<L2概念定义关系事实> 定义关系;
    std::vector<L2概念直接上位事实> 直接上位;
    std::vector<L2概念来源证据事实> 来源证据;
    L2概念治理生命周期事实 治理生命周期;
    friend bool operator==(...) = default;
};

struct L2普通概念建立请求 final {
    L2结构请求头 请求头;
    std::uint32_t 普通概念合同版本 = L2普通概念结构合同版本;
    L2结构幂等身份 幂等身份;
    L2概念身份 本体根;
    不可变材料身份 签名规则材料;
    std::vector<L2概念签名值式项> 签名值式项;
    std::vector<L2概念定义引用项> 初始定义;
    std::vector<L2概念身份> 直接上位;
    std::vector<不可变材料身份> 来源证据材料;
    friend bool operator==(...) = default;
};

struct L2普通概念写入结果 final {
    L2结构结果头 结果头;
    std::optional<L2普通概念事实> 概念;
    bool 成功() const noexcept;
    friend bool operator==(...) = default;
};

struct L2普通概念读取请求 final {
    L2结构请求头 请求头;
    std::uint32_t 普通概念合同版本 = L2普通概念结构合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    L2概念身份 概念;
    std::uint64_t 历史截止事实代次 = 0;
    friend bool operator==(...) = default;
};

struct L2普通概念读取结果 final {
    L2结构结果头 结果头;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    std::optional<L2普通概念事实> 概念;
    bool 成功() const noexcept;
    friend bool operator==(...) = default;
};
```

建立请求只接受非零期望代次、非零幂等身份、非零根 / 材料身份和上述确定排序。初始生命周期固定为活跃，不允许调用方选择冷却或退役。当前读取要求历史截止为零；历史读取要求非零历史截止且不晚于请求头期望代次。

## 4. 纯值 helper 与成功形状

同一头唯一公开：

```cpp
bool L2概念世界关系引用有效(const L2概念世界关系引用&) noexcept;
bool L2概念定义目标有效(const L2概念定义目标&) noexcept;
bool L2普通概念建立请求有效(const L2普通概念建立请求&) noexcept;
bool L2普通概念读取请求有效(const L2普通概念读取请求&) noexcept;
bool L2普通概念事实完整(const L2普通概念事实&, std::uint64_t 截止) noexcept;
```

事实完整 helper 只检查值式形状：概念身份来源族为概念且编码匹配；本体根归属、签名规则、签名值、定义、直接上位、来源证据和治理生命周期全部非零、同概念、确定排序；每项生命周期均满足创建代次不晚于具名截止，且可空退出代次不存在或不晚于具名截止；普通概念不等于本体根或任一直接上位；治理状态属于闭集。它不要求任一特定治理状态，也不读取材料、世界事实、根身份或 DAG，不替代后继服务的权威校验。

写成功只允许 `已提交 / 精确重复`，共同合同版本正确、截止非零、变更代次存在且等于截止、概念负载完整；治理状态必须为活跃，概念节点和全部初始自有事实必须未退出。首次建立与精确重复均返回首次结果截止。读成功只允许 `已读取`，共同合同版本正确、截止非零、零变更、负载完整、读取类别 / 历史截止自洽；当前读取还要求概念身份来源和全部当前自有事实未退出，但治理状态可以是活跃、冷却或退役；历史读取允许返回在历史截止已经退出的完整事实。其它状态 optional 必须为空、变更代次必须为空；坏成功形状不得猜成功。
