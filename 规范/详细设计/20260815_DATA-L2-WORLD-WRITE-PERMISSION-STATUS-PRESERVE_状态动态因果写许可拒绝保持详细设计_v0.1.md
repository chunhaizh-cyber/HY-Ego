# DATA-L2 状态动态因果写许可拒绝保持详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-WORLD-WRITE-PERMISSION-STATUS-PRESERVE`

## 1. 目标与完成边界

补齐 `L2状态结构服务`、`L2动态结构服务` 和 `L2因果结构服务` 对 L1 `许可拒绝` 的无损状态映射。L1 已公开 `L1所有者范围写入状态::许可拒绝`，三类 L2 的共同结果状态及三份结构类型登记状态也都已有同名枚举；当前六个映射函数遗漏该 case，因而会落入 `内部不一致`。

本叶只做已有枚举之间的机械映射，不新增公开 DTO、函数、状态或数值，不改变写集、owner、许可判断、事务、幂等、读回或业务语义。完成只证明三服务不再把 L1 明确许可拒绝误报为内部不一致，不证明任一服务整体或《数据服务最终需求清单》整体完成。

## 2. 正式依据与当前事实

- `规范/4230_子规范_L2六类纯结构统一合同.md` 冻结 `许可拒绝=6`，并要求非成功结果结构化区分、空成功载荷、零假成功。
- `海中鱼巣/核心/L1所有者范围CRUD.数据.h` 已冻结 `L1所有者范围写入状态::许可拒绝=4`。
- 三份 `L2*结构.数据.h` 的共同写结果使用 `L2结构状态::许可拒绝`；三份结构类型登记状态均已有 `许可拒绝`，不需要修改数据头。
- 场景、存在和特征写状态映射已经覆盖许可拒绝；本叶不得重复修改。

## 3. 精确代码修正

只修改三个既有服务实现文件：

1. `海中鱼巣/领域/服务.L2状态结构.ixx`
   - `映射写入状态(...)`：追加 `L1所有者范围写入状态::许可拒绝 -> L2结构状态::许可拒绝`；
   - `映射登记写入状态(...)`：追加 `L1所有者范围写入状态::许可拒绝 -> L2状态结构类型登记状态::许可拒绝`。
2. `海中鱼巣/领域/服务.L2动态结构.ixx`
   - `映射写入动态(...)`：追加 `L1所有者范围写入状态::许可拒绝 -> L2结构状态::许可拒绝`；
   - `映射登记写入动态(...)`：追加 `L1所有者范围写入状态::许可拒绝 -> L2动态结构类型登记状态::许可拒绝`。
3. `海中鱼巣/领域/服务.L2因果结构.ixx`
   - `映射写入状态(...)`：追加 `L1所有者范围写入状态::许可拒绝 -> L2结构状态::许可拒绝`；
   - `映射登记写入(...)`：追加 `L1所有者范围写入状态::许可拒绝 -> L2因果结构类型登记状态::许可拒绝`。

六处分支都必须位于相应 switch 内。未知枚举和其它不应出现的写状态继续收敛为 `内部不一致`；不得扩大为默认许可拒绝。

## 4. 非成功形状与风险

现有写入口在映射后继续使用各自的失败形成函数。许可拒绝必须保留空业务载荷、不得形成新编码映射、不得形成内存权威发布，也不得携带伪成功变更。若 L1 返回的结果形状本身矛盾，仍按现有后置检查升级为 `内部不一致`，不能只因枚举为许可拒绝而掩盖坏形状。

合法生产装配给三服务注入各自有效 owner 写端口，公开调用方没有稳定入口制造许可拒绝。不得为动态命中增加第二 owner、失效端口、私有访问、测试 friend 或故障注入 seam；真实许可拒绝动态分支记 `NOT_RUN`，以源码精确映射和编译链接证明本叶修改。
