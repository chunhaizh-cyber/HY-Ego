## 1. 新设计门禁

未完成代码计划只有形成以下闭合链，才允许在计划索引登记为 `可执行`：

```text
现行正式规范
-> 施工流程图
-> 逐节点实现分析
-> 函数功能确认
-> 完整详细设计
-> 函数结构知识图谱
-> 不可变施工计划
-> 计划索引精确版本 / blob
```

逐节点实现分析和函数功能确认是详细设计的输入与覆盖证明，不能替代详细设计。详细设计必须成为代码实施的直接依据；施工计划只冻结详细设计版本、实施切片、允许 / 禁止文件、开工 / 完成条件和验证合同，不重新裁决字段、签名、算法或失败处理。
