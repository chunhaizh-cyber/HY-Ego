## 1. 机器语义裁决

P12 v0.3 关于端点三态的来源判定保留，但收窄“后来退出端点不得隐藏候选”的边界。现行 L1 权威不变量禁止当前关系19引用已退出主体/实例槽；P9/L1 历史入口只能按已知稳定编码读取历史材料，没有关系19历史枚举入口。因此 P12 不得用当前+历史关系19拼装候选，也不得扩展为通用历史查询。

P12 的合法候选组只来自 G0 当前快照中的当前关系19。当前关系19的源、目标和候选状态端点必须在该快照中当前有效；后来退出的端点或已退出关系19不形成 P12 成功候选。P9 历史入口仅用于已选当前关系19候选的完整状态读回互证，不用于发现候选。

## 2. 端点与结果映射

| 情形 | P12 处理 |
| --- | --- |
| 请求主体/实例槽及其当前关系19范围均可在 G0 当前快照解析 | 进入当前关系19候选枚举 |
| 主体/实例槽当前读取与历史均未找到 | `未找到`；不得写成 `无前状态` |
| 两个端点当前均合法，但 G0 当前关系19范围为空 | `无前状态`，并返回完整零前态证据 |
| 端点后来退出、历史材料可读但当前关系19不再存在 | 不产生成功候选；在本读取边界映射 `未找到`，不伪造历史候选 |
| 当前/历史状态矛盾、退出见证损坏、当前关系19端点违反 L1 不变量 | `内部不一致` |
| 当前端点存在且候选集合合法但没有严格更早状态 | `无前状态`，仅此时允许零前态证据 |

这一区分不把“已退出”与“从未存在”当作机器事实相等：内部自检必须分别构造并验证两者；公开 P12 结果因没有退出端点载荷字段，只在当前候选读取边界统一返回 `未找到`。不得声称后来退出端点仍能成功选择前状态。

## 4. 选择与读回流程

1. 读取 G0 当前完整快照并解析请求主体、实例槽的当前端点；任一端点当前/历史均未找到即返回 `未找到`。
2. 仅扫描 G0 当前关系19，校验五角色、当前端点、关系唯一性和状态资格/发生时间槽；已退出关系或历史关系不进入枚举。若两个端点均当前合法但关系19范围为空，保留零前态证据并返回 `无前状态`。
3. 严格筛选发生时间小于拟发布时间，等时间多状态冲突，唯一最大时间进入 P9 公开读取；若范围内只有后来退出端点关联的历史关系而无当前关系19，则按 `未找到` 收口。
4. P9 读取可按已知编码使用当前/历史入口互证退出生命周期和完整状态，但不得返回与 G0 当前关系不一致的成功材料。
5. G0、P9 读取截止与 G1 同代次；变化完整重试一次，仍变化返回 `版本漂移`。

## 5. 自检与完成边界

顺序 360 的既有状态自检追加：当前端点合法无候选、从未存在、后来退出端点无当前关系、已退出关系、L1 不变量拒绝、当前关系候选成功、P9历史读回互证、P9坏成功、许可/资源/漂移和载荷映射。不得把退出端点场景断言为成功候选。

只可声明当前关系19范围内的相邻前状态选择候选合同完成；不声明退出关系历史枚举、P9/P10/P11、第二状态、关系20、迁移动能、动态、装配、恢复、集成验收或治理闭环完成。
