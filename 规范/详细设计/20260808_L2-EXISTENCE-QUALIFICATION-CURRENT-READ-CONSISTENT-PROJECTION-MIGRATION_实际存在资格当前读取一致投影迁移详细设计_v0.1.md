# 实际存在资格当前读取一致投影迁移详细设计 v0.1

日期：2026-08-08

状态：设计就绪；只冻结后续实施合同，不证明代码、运行或消费者验收完成。

## 1. 目标与裁决

把 `L1实际存在服务::读取资格实现` 从“首读事实代次、依次读取三个节点和属性槽、再读取资格值、末读事实代次”的分散当前读取，迁移为现有 `L1事实基座服务::尝试读取中性一致当前投影`。第一层只按稳定编码和指定事实代次返回业务中性的节点与属性值投影；实际存在服务继续解释资格、类型、来源和业务状态。

该函数已经被下列正式生产服务真实消费：

- 初始场景实际存在原子发布的权威读回；
- 初始场景完整事实组合读取；
- 实际存在当前场景移除的写前与写后资格互证；
- `读取实际存在资格` 与 `读取当前实际存在资格` 两个领域公开入口。

因此本叶来自第二层现有服务需要，不是为了补第一层覆盖制造的新请求。上一叶已经完成实际存在登记一致读回；本叶是其后最早、最窄的真实读取缺口。

## 2. 保持不变的合同

- `L1实际存在合同版本 = 2`、`L1实际存在规则版本 = 1`；
- `实际存在资格读取请求`、`实际存在资格定位读取请求`、`实际存在资格事实`、`实际存在资格结果` 的字段、全等和完整性规则；
- 两个公开资格读取函数的签名、锁边界和状态枚举；
- 登记建立、中性写集、幂等、稳定编码、场景关系和组合服务调用关系；
- 当前资格仍由实际存在节点的资格属性槽唯一指向，资格值材料仍必须为固定 I64 资格值，来源仍必须是登记服务身份。

不新增第一层 DTO、业务标签、资格字段、缓存、锁、索引、写入口、自检或验收入口。

## 3. 正式依据与当前事实

- 4015 要求组合当前读取在同一事实代次形成完整值式投影，普通 CRUD 不固定扫描全仓；第一层只由后续层真实使用自然证明。
- 4030 要求领域服务解释资格与业务结果，只向第一层提交或查询业务中性结构。
- 4050 要求未找到、许可拒绝、版本漂移、资源失败和内部不一致结构化分账。
- 4200 要求实际存在资格由其唯一领域服务拥有，许可竞争不得等待或隐式循环。
- ACCEPTANCE-01 禁止第一层独立验收和生产内验收代码；后续验收只能验证合法消费者自身合同。

当前 `读取资格实现` 仍包含两个事实代次读取、三个节点读取、一个属性读取和一个值读取。现有一致当前读取的属性值投影已经同时携带属性槽与当前值事实，所以不需要再单独请求值。

## 5. 固定读取请求

首轮期望代次唯一来自 `当前登记.事实截止代次`。每轮请求固定为：

```cpp
L1中性一致当前读取请求 请求;
请求.合同版本 = L1中性一致当前读取合同版本;
请求.期望事实代次 = 本轮期望代次;
请求.节点 = {
    存在编码,
    当前登记.实际存在资格属性类型,
    当前登记.服务身份};
请求.关系 = {};
请求.值 = {};
请求.属性值 = {{存在编码, 当前登记.实际存在资格属性类型}};
请求.源关系组 = {};
请求.目标关系组 = {};
```

六组长度固定为 `3/0/0/1/0/0`，节点顺序固定为实际存在、资格属性类型、登记服务来源。属性投影本身携带当前值事实，`值` 组必须为空。显式资格值只在领域层与投影中的槽和值编码互证，不能进入第一层业务字段。

## 6. 控制流与重做边界

1. 登记不完整、存在编码无效或显式资格值无效时返回内部不一致，零第一层调用；公开入口仍先按原合同校验请求。
2. 每轮只调用一次一致当前投影。
3. 首轮合法事实代次漂移时，确认失败结果六组为空、回显期望代次正确且实际代次非零不同；丢弃本轮材料，以回显实际代次完整重做一次。
4. 第二轮仍漂移，返回版本漂移；不得第三次调用、等待或休眠。
5. 许可拒绝立即返回许可拒绝，零重试；资源失败返回资源失败；入口拒绝、内部不一致或坏失败形状返回内部不一致。
6. 成功结果必须满足合同、期望代次、读取代次、六组长度和请求顺序全部精确，读取代次非零且等于本轮期望代次。
7. 任一项目成功却无事实、非成功却带事实或属性投影，属于内部不一致。
8. 任一节点未找到，或资格属性未找到、未设置，且不存在更严重项目错误时返回未找到；已退出、种类不匹配或坏项目形状返回内部不一致。内部错误优先于未找到。
9. 非成功不返回部分资格事实，不修改登记定位，不补写、不恢复、不换编码。

允许一次完整重做，是因为当前登记只提供稳定的资格类型和服务来源身份；重做会重新取得实际存在节点、类型节点、来源节点、属性槽和当前值的同一新截止完整投影，不混用上一轮材料。

## 7. 成功业务形状

成功后按请求顺序解释三个节点和一个属性值投影：

- 实际存在节点：查询编码与事实编码等于请求存在编码，种类为普通，未退出；
- 资格属性类型节点：编码等于登记资格属性类型，种类为属性类型，值表示精确为 I64，未退出；
- 来源节点：编码等于登记服务身份，种类为普通，未退出；
- 实际存在节点的当前属性中，资格属性类型槽恰一项，且与属性投影中的槽全等；允许该节点拥有其它不同类型属性；
- 属性投影查询节点和类型精确匹配请求，槽当前值等于投影当前值事实编码；
- 显式资格值有值时，必须等于槽与当前值事实编码；无值时直接采用投影当前值事实编码；
- 当前值事实所属节点、属性类型、来源节点分别等于实际存在、资格属性类型和登记服务身份；未退出，材料为 I64 且等于正式实际存在资格值；
- 节点和值的创建代次非零且不晚于共同读取代次。

满足以上条件才形成 `实际存在资格事实`，事实截止等于一致投影读取代次；否则返回内部不一致。
