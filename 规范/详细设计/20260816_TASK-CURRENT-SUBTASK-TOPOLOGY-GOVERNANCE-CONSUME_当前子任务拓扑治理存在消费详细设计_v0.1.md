# 当前子任务拓扑治理存在消费详细设计 v0.1

日期：2026-08-16

计划身份：`TASK-CURRENT-SUBTASK-TOPOLOGY-GOVERNANCE-CONSUME`

## 1. 目标与完成边界

实现当前任务树的第三个输入叶：

```text
BIZ-L4-004-02-02-03 v0.2
任务业务服务::读取当前子任务拓扑和运行态治理存在
-> 接收父级依据02-02同一非零G0材料裁决出的唯一当前根完整见证
-> 只经DATA-EXT-13唯一任务结构服务恰一次有界读取完整当前子任务拓扑和逐任务治理存在
-> 互证有根树、全部父子端点、共同截止和每任务独占的唯一治理存在
-> 形成稳定排序、不可变、零部分载荷的BIZ值式快照
```

本叶只形成“任务树拓扑 + 运行态治理存在”中性结构投影。它不重复读取02-02已经返回的来源、目标、场景和生命周期，不裁决来源目标等价、当前根资格、阶段业务含义、完成、调度、方法或权限，不读取历史父子关系。

## 2. 正式依据与当前事实

设计 S0 基线为 `main@b13fffc87b14c34f0e1330bc3ac5ec9f84711ed7`：

1. 0050 要求组合读取显式声明事实截止并只返回调用方拥有的不可变完整投影；DATA-L2 可以校验强类型结构和引用完整性，不能替 BIZ 作任务业务裁决。
2. 1140 规定实际存在和治理虚拟存在复用统一存在节点结构；治理虚拟存在必须回读唯一来源关系并证明未进入世界根、现实场景、内部世界场景或普通场景成员投影，其生命周期受来源领域对象控制。
3. 3200 定义任务节点、来源、目标、场景、生命周期和“任务唯一运行态治理存在”为共同任务结构，并明确该治理存在不是世界事实存在；每个任务独占，不同任务不得共享。
4. 5090 规定需求树、任务树和方法列表相互独立，同一有效来源需求只对应一个当前任务树；当前树唯一性和根资格仍由父级业务裁决。
5. 5200 把任务运行态治理存在冻结为任务—唯一虚拟存在关系；5210 要求任何有效任务阶段都能回读唯一治理存在，但阶段投影不得替代完整结构。
6. BIZ-L4-004-02-02-02 v0.2 已正式接管每任务全部当前来源关系、唯一目标、唯一场景和唯一当前生命周期读取，02-03 不得建立第二来源入口。
7. 数据服务最终需求清单 DATA-EXT-13 已要求唯一任务结构服务读取任务树、治理存在、版本和共同事实截止，并结构化返回任务环、预算、漂移和内部不一致。
8. 当前真实代码只发布共同 `L2任务身份`、`L2存在身份`和对应节点族；不存在生产 `L2任务结构服务`、任务树公开 DTO、任务—治理存在资格 DTO、`服务.任务.ixx`或本函数。普通 `L2存在事实`不能单独证明任务治理资格。
9. 02-01 和 02-02 仅有待激活设计；02-03 必须等待它们真实结果和 DATA 最终 ABI 后才可施工，但代码尚未实现不阻断本叶消费合同冻结。
10. 旧 BIZ-L4 v0.1 让 BIZ 逐任务读取子关系、来源和治理存在，既重复02-02职责，也不能保证一次共同截止的完整整树结果。

裁决为：以 v0.2 原位替代 v0.1；扩展同一未来 `任务业务服务`，要求 DATA-EXT-13 增加一次有界整树组读。治理存在复用统一 `L2存在身份`载体，但资格只由任务结构服务通过任务—治理存在关系和世界成员排除证据证明；BIZ 不自行 BFS 调用 DATA，不建立治理存在第二 owner，也不把任意世界存在冒充任务治理存在。

## 3. DATA-EXT-13 消费合同

### 3.1 唯一公开操作

本叶要求同一 `任务结构服务`提供一个公开 const 组读能力，语义冻结为：

| 操作 | 请求 | 成功返回 | 非成功 |
| --- | --- | --- | --- |
| 按任务根与指定截止有界读取当前子任务拓扑和治理存在组 | 非零根任务身份；非零G0；事实/任务/存在/场景范围版本；父子关系/治理存在关系/治理资格/任务树读取规则版本；任务节点数和当前父子关系数两项非零总预算 | 以指定根为唯一根的完整当前任务节点组、全部当前父子关系、逐任务恰一治理存在资格项；资格项含 `L2存在身份`及来源、任务—治理存在强类型关系和世界/场景成员排除证据；共同及单项G0、请求版本和两预算回显；稳定排序和零截断 | 请求拒绝、根未找到、根已退出、节点或关系预算不足、事实代次漂移、任务环、重复父属、治理存在冲突、治理资格冲突、许可拒绝、资源失败、未实现和内部不一致分账；整组失败零成功前缀。BIZ把 DATA 治理存在冲突和治理资格冲突统一映射为 `治理存在冲突`，并在同G0上游根见证语境中把根未找到/退出升级为内部不一致 |

最终 DATA 请求 / 结果 DTO 名、字段顺序、状态数值和函数签名由 DATA 唯一所有者发布后机械匹配。BIZ 不建立兼容壳、第二 owner、第二任务服务或同义 DATA 接口。

### 3.2 节点、父子关系与治理存在

每个成功节点项至少包含：

```text
非零L2任务身份和完整任务身份来源，节点族=任务
该任务恰一运行态治理存在的L2存在身份和完整存在身份来源，节点族=存在
任务—治理存在绑定关系的强类型身份、端点、当前生命周期、关系/资格规则版本和G0
证明该存在未进入世界根、现实场景、内部世界场景或普通场景成员投影的完整资格材料
任务结构版本和单项事实截止
```

每条当前父子关系至少包含：

```text
关系强类型身份及来源
父任务源端点和子任务目标端点
当前生命周期、父子关系规则版本、任务树版本和G0
```

`任务运行态治理存在`不另造与存在节点并列的第二身份体系；其身份载体固定复用 `L2存在身份`。DATA-EXT-13 必须发布任务结构内部的强类型治理资格投影，把存在身份、存在身份来源、任务—治理存在关系、生命周期、资格版本和世界成员排除证据绑定为完整项。裸 `L2存在身份`、普通 `L2存在事实`、显示名称或 bool 都不能替代完整资格；BIZ 只经任务结构服务取得，不直达存在结构服务、世界树或 DATA-L3 拼装。

### 3.3 完整树不变量

成功快照必须同时满足：

1. 节点组非空，指定根恰好出现一次且没有当前父关系；
2. 每个非根任务恰有一条当前父关系，方向固定为父任务到子任务；
3. 所有父子端点都属于返回节点组，从根沿子关系可达全部且只达一次；
4. 无自环、无有向环、无重复节点、无重复关系、无外部端点和无多父；
5. 完整闭合后 `当前父子关系数 = 任务节点数 - 1`，使用 checked 运算；
6. 每个任务恰有一项治理存在绑定，不同任务的治理存在身份两两不同；
7. 全部身份来源、生命周期、版本和单项G0完整，且共同G0等于请求G0；
8. 节点数和关系数分别不超过两项总预算，成功零截断。

单节点树是合法成功：节点组只有根，关系组为空，治理存在组恰一。

### 3.4 稳定顺序

- 节点按任务稳定身份排序；根资格由显式根身份表达，不依赖容器首项。
- 父子关系按父任务稳定身份、子任务稳定身份、关系稳定身份排序。
- 治理存在绑定按任务稳定身份、治理存在稳定身份、绑定关系稳定身份排序。
- 排序只使用正式强类型身份，不使用显示名称、创建时间、到达顺序、容器原序或 enum 裸底值。

### 3.5 DATA 不承担的业务语义

DATA 不返回或裁决：

```text
指定根是否是来源需求唯一当前根
各任务来源目标是否等价
任务阶段、业务状态段、完成、失败或调度资格
方法选择、执行权、执行冻结或权限
应否创建、扩展、迁移、退出或重新筹办任务
```

## 5. 固定读取与发布顺序

```text
校验服务固定配置完整，否则内部不一致且零DATA调用
-> 校验BIZ合同、02-02根完整见证、非零G0、版本和两项非零预算
-> 互证根见证任务/身份来源/当前结构完整且单项G0等于共享G0
-> 请求版本逐字段匹配固定配置；不等则当前性漂移且零DATA调用
-> 构造不含运行代次、来源、目标、场景和任务生命周期的DATA-EXT-13整树读请求
-> 恰一次调用按任务根与指定截止有界读取当前子任务拓扑和治理存在组
-> 精确映射DATA非成功；整组失败零成功前缀
-> 互证请求回显、根、G0、版本和两预算完全一致
-> 互证节点非空、根恰一且无父、非根恰一父、关系端点全部闭合
-> 从根执行BIZ本地有界图互证：全可达、无环、无多父、无重复节点/关系
-> checked复核关系数=节点数-1以及节点/关系实际数量不超预算
-> 逐任务互证L2存在身份/来源、任务治理关系和资格证据、恰一基数、端点与G0；拒绝跨任务共享或任何世界/场景成员资格
-> 按正式稳定身份排序，形成完整不可变候选
-> 无抛出交换并返回已读取
```

BIZ 本地图互证只消费一次 DATA 结果，不再次读取事实。所有 vector / 集合分配、累计、排序和图遍历位于异常收口内；`std::bad_alloc`、`std::length_error`映射资源失败，未知异常映射内部不一致；成功交换前不得发布部分节点、关系或治理存在。

## 6. 非成功与坏形状

| 情形 | BIZ状态 | 载荷 |
| --- | --- | --- |
| 固定配置无效 | 内部不一致 | 空；零DATA调用 |
| 坏合同、零根/G0/版本/预算、根见证不完整或见证截止不等G0 | 请求拒绝 | 空；零DATA调用 |
| 合法请求与固定配置版本不等 | 当前性漂移 | 空；零DATA调用 |
| DATA返回根未找到或已退出 | 内部不一致 | 空；与02-02同G0根见证矛盾 |
| DATA节点或关系预算不足 | 数量预算不足 | 空；不得截断 |
| DATA事实代次漂移或成功共同/单项截止不等G0 | 当前性漂移 | 空 |
| DATA明确报告任务环 / 重复父属 | 同名BIZ状态 | 空 |
| DATA明确报告治理存在冲突或治理资格冲突 | 治理存在冲突 | 空；两类提供者结构失败不扩张BIZ状态枚举 |
| DATA明确许可拒绝 | 提供者拒绝 | 空 |
| DATA资源失败、`std::bad_alloc`、`std::length_error` | 资源失败 | 空 |
| DATA未实现/未装配 | 未实现 | 空 |
| DATA请求拒绝、未知状态、未知异常或坏成功形状 | 内部不一致 | 空 |
| 完整成功 | 已读取 | G0和完整值式快照 |

坏成功形状包括：空节点组、根缺失/重复/有父、非根无父或多父、错方向、外部端点、断链、自环、有向环、重复节点/关系、关系数不等于节点数减一、超预算、治理存在缺失/重复/跨任务共享、治理关系或资格证据缺失、治理存在进入任一世界/场景成员投影、错身份来源/生命周期/版本/G0、半结构或任何不可解释附带载荷。DATA 声称成功时发现这些形状一律归 `内部不一致`，不伪装成 DATA 已经正确报告的结构状态。

## 7. 激活门禁

专项至少覆盖：

- 坏固定配置、坏请求、零根/G0/预算、坏根见证和版本不等均零DATA调用；
- 单节点树合法成功：一节点、零关系、一治理存在；多层、多分支树和输入乱序成功，输出稳定；
- DATA恰一次调用；运行代次、来源、目标、场景和生命周期不进入DATA请求，零逐节点/分页/补读；
- DATA根未找到/已退出固定升级内部不一致；两类预算不足、漂移、环、多父、治理冲突、许可、资源和未实现分别映射；未知状态归内部不一致；
- 根缺失/重复/有父，非根无父/多父，错方向，外部端点，断链，自环、多节点环、重复节点/关系、关系数不守恒和混代全部拒绝且零前缀；
- 每任务治理存在零项、多项、错端点、错身份来源/生命周期/版本/G0、跨任务共享、缺治理关系/资格或进入世界/场景成员投影全部拒绝；裸 `L2存在身份`不得单独通过完整资格合同；
- 节点和关系数量恰好预算通过、超一项失败，并覆盖 checked 累计与 `节点数-1`运算；
- 源码静态证明零来源/目标/场景/任务生命周期读取、零目标等价/当前根资格/阶段解释/完成/调度/方法/权限、零L1/owner/仓库/DATA写/缓存/retry/sleep；
- 根工程 Debug/Release、专项双配置、strict、UTF-8/XML、工程唯一登记和生产零专项痕迹。

真实验证必须经 DATA-EXT-13 正式公开入口，不得由专项直接构造 DATA 成功结果或增加生产 seam。公开 ABI 无法构造的坏成功形状只作 BIZ 静态防御证据，并与 DATA 黑盒拒绝分账。

真实资源耗尽、DATA私有损坏、跨进程恢复、父级目标等价/当前根裁决、后继对子任务复用02-02承接/生命周期读取、完整当前任务树发布、任务创建/迁移/调度/完成以及系统业务闭环保持 `NOT_RUN`。

本设计发布不证明 DATA-EXT-13、本叶 BIZ 代码或当前任务树已经实现。未来本计划结果最多证明同一 `G0` 下给定根的完整当前子任务拓扑和逐任务唯一治理存在中性消费闭合。
