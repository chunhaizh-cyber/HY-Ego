# DATA-L2 方法公共身份闭合详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-METHOD-IDENTITY-CLOSURE`

## 1. 目标与边界

依据 3300、5300、8120 v0.10 与《数据服务最终需求清单》DATA-EXT-14，只在 `L2结构公共.数据.h` 中补齐 `L2方法身份` 与 `L2节点族::方法`，使后继唯一方法 owner、方法登记根及方法结构 CRUD 能够使用共同的强类型身份来源事实。

本叶只建立公共值式身份合同，不建立方法 owner、族锚点、节点、关系、方法登记根、方法登记、执行规格、索引、服务、聚合、普通应用装配或机器事实。BIZ 的方法登记根预冻结合同只作公开需求输入，不取得 DATA 实现所有权。

## 2. 当前事实与裁决

创建侧基线为正式 `main@443d9ad984ceb4c76a6165c771958537a61a6ac9`，`main == origin/main`、index 空。

- 当前 `L2结构公共.数据.h` 已有世界结构 1—7、语言 8、词条 9、概念 10，共十个节点族；没有 `L2方法身份` 或方法节点族。
- 3300 与 5300 要求方法具有稳定独立身份，方法登记根、方法首、规格和动作入口只能由方法领域服务及专用数据操作写入。
- 8120 v0.10 与 `METHOD-REGISTRY-ROOT-PRODUCTION-INIT v0.1` 要求方法登记根正式读回包含非零 `L2方法身份` 和方法节点族身份来源；预冻结需求不是当前 ABI。
- DATA-EXT-14 要求唯一方法结构服务后继承载方法登记根、方法登记和执行规格，不允许用函数名、任务、日志、普通节点或裸稳定编码替代方法身份。
- 当前 C0 概念 DTO WIP、EVENT 工程 WIP、SELF 和流程图 WIP均不修改本叶唯一目标公共头；代码施工仍须等待唯一活动代码段释放并在 S0 重新确认所有权。

尾部数值 `方法 = 11` 是对现有闭集的机械追加。既有 1—10 均已发布，不允许插入、重排或复用。

## 3. 精确公开合同

在现有强类型身份宏块尾部追加：

```cpp
定义L2强类型身份(L2方法身份);
```

在 `L2节点族` 尾部追加：

```cpp
方法 = 11
```

`L2节点族身份来源事实完整(...)` 的闭合枚举判断同步接受 `L2节点族::方法`。通用 helper 仍只判断值式形状；接受方法族不证明方法 owner、节点、登记根、登记项或服务已经存在。

## 4. ABI、不变项与禁止范围

- `L2方法身份` 继续沿用现有显式 `稳定编码` 包装、默认零值和逐字段相等；不得隐式转换为概念、存在、任务或普通稳定编码。
- 不改变 `L2结构合同版本`、`L2结构状态` 1—15、读取类别、请求 / 结果头、既有十个身份或节点族 1—10 的数值与布局。
- 不在本叶增加 `L2方法登记根角色`、请求、结果或 `成功()`；它们由后继方法登记根公共 DTO 叶唯一拥有。
- 不建立通用节点族 CRUD、通用 owner 选择、第二写入口、方法名称、函数指针、动作执行、业务判断、日志、验证 seam、deadline、sleep 或重试 ABI。
- 不修改 L1、任一现有 L2 服务、聚合、普通应用、工程、BIZ、线程、规范、流程图或最终需求清单。

## 5. 物理范围与验证

生产代码唯一目标为：

```text
海中鱼巣/领域/L2结构公共.数据.h
```

施工形成同名专属施工 / 验证记录。验证至少包含：

1. 静态核对 `L2方法身份` 是独立显式包装；
2. 静态核对 `L2节点族::方法 == 11`，既有 1—10 与状态 1—15 零变化；
3. 静态核对共同身份来源 helper 接受方法族且拒绝未知值；
4. 根工程 x64 Debug / Release Rebuild；
5. diff、strict、UTF-8、白名单与生产零验证痕迹检查。

不新增独立验收计划或生产外动态专项。真实方法 owner、方法节点、方法登记根和方法 CRUD 为 `NOT_RUN`，因为本叶没有这些能力。

## 6. 完成声明边界

本叶完成只证明方法公共强类型身份和节点族闭集可被后继代码编译消费；不证明 DATA-EXT-14、方法登记根、方法聚合、阶段 19、方法登记 / 召回 / 执行或最终需求清单整体已经实现。
