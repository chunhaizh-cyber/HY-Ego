## 1. 已确认的合同

七个世界节点族的当前结构身份不再是读取 / 投影服务，而是一个无载荷的结构当前性确认：

```text
确认当前{族}结构身份
  输入 = 非零 G0 的 L2结构请求头 + 本族强类型身份
  返回 = 既有 L2结构结果头
```

七个函数的逻辑名称固定为：

```text
确认当前场景结构身份
确认当前存在结构身份
确认当前特征定义结构身份
确认当前特征实例结构身份
确认当前状态结构身份
确认当前动态结构身份
确认当前因果结构身份
```

成功当且仅当返回头合同版本正确、状态为 `已读取`、事实截止代次精确等于请求 `G0`、变更事实代次为空。成功只说明“该请求身份在该 G0 的结构当前性已确认”；它不回显请求身份，也不返回节点、锚点、归属关系类型、归属关系、角色 / 顺序、生命周期、内部 owner 或任何新的当前 DTO。

provider 必须在一次 owner-aware 一致当前投影中确认目标节点、族锚点、族归属关系类型、唯一归属关系和内部 owner 全部仍在 G0 当前。确认不得依赖最大代次、空退出集合、历史见证或已有结果头的反向推断；不得补偿写入；不得把状态当前选择、动态当前值或特征当前值当作结构身份当前性。

## 2. 历史见证与既有完整 DTO

```text

成功 = H == 结果头.事实截止代次
```

`L2节点族身份来源事实`继续包含六个结构字段与四份生命周期。它不收缩、不改名、不改成当前确认结果，并继续由既有完整创建、完整读取、DATA-L3 聚合以及其它已冻结合同按原职责使用。未来退出相对 H 的投影保持历史见证职责，不得通过当前确认补造。
