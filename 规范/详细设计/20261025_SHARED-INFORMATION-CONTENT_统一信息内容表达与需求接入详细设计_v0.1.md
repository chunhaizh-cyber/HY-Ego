## 1. 用户目标与最早闭环

需求、任务、方法是信息存在；其内容以“正式特征类型 FT → 有类型的内容值”表达，与普通存在的特征表达兼容。被服务对象需求特征引用的 D 和独立读取的 D 是同一节点，不复制为普通存在，不建立假特征实例，不取得任意写权。

## 3. 唯一公共类型合同

新文件：`海中鱼巣/领域/信息内容.数据.h`。它只声明值式数据，按 CODE-FILE-01 §3.1 无独立算法、编排或非 inline 实现，因此不建立 `.cpp`。包含 `<cstdint>`、`<optional>`、`<variant>` 及 `../核心/基础数据集.h`取得唯一稳定编码定义；不包含需求、任务、方法、概念类头，避免反向领域依赖。使用 `#pragma once`及现命名空间。

完整声明冻结为：

```cpp
enum class 正式内容值种类 : std::uint8_t {
    I64数值=1, 存在引用, 概念引用, 需求引用, 语言理解引用, 内容确认引用
};
enum class 正式内容值状态 : std::uint8_t { 已知=1, 当前未知, 不适用 };
using 正式内容准确值=std::variant<std::int64_t,稳定编码>;
struct 正式内容值 final {
    正式内容值种类 种类{};
    正式内容值状态 状态{};
    std::optional<正式内容准确值> 值;
};
struct 正式直接内容项 final {
    稳定编码 特征类型;
    正式内容值 内容;
};
```

不额外增加T/M/字符串/集合种类、通用节点类别、路径协议或新reader。6类数值和现 `正式内容值`字段顺序、底层载荷形状保持不变。共享项用于FT到值的值式组织，不是持久F。类别是值语义，不是底层节点类型替代，不因底层同为稳定编码允许互换。

不变式沿当前reader和判定边界复核：已知必须有值，I64必须持I64，其余五类必须持合法非零稳定编码；未知/不适用必须无值。`当前未知`表示适用内容尚未取得；`不适用`表示当前合法形式无此项，不当空值、失败或条件满足。单位/范围仍从正式FT与概念定义获得，不复制进此DTO。

## 7. 不能冒称已实现的兼容

普通E实际快照同时包含物理类型、比较规则、单位、当前完整材料、实例区间值。I64和存在引用在意义上可映共享6类子集，但UTF8、数组、二值格及引用集合不能当概念/需求引用；缺准确值但有区间也不能伪已知准确值。本叶没有需要普通E→共享6类的新真实消费者，因此不建立只为通用性服务的适配接口，不改既有普通E算法。

本叶交付准确称为“公共FT→typed内容表达统一，并接入现需求真实消费者”。**不称为普通E全类型统一reader、T/M直接内容reader、任意多项内容或递归查询已完成。**普通E完整适配需随后由具体消费者明确材料种类、区间、单位及保护合同；T/M也必须从原owner分别读取，不填假支持。这些只记录缺口，不在本轮新增后继计划。
