## 1. 目标与完成边界

本叶新建唯一 `海中鱼巣.领域.服务.L1动态`，完成三项真实能力：

1. 在 L1 正式建立并读回关系20状态迁移动能所需的服务、关系类型和八个属性类型登记；
2. 只在 P13 非等价成功且明确允许动态时，形成版本化、确定性的关系20纯值写入规格；
3. 在未来原子发布后，按动态稳定身份和完整定位编码从 L1 当前或历史事实独立读回一条完整状态迁移动能。

动态领域唯一拥有关系20、动态资格、动态种类、聚合规则、迁移比较/差异证据的登记、规格解释和读取。状态服务、P13组合器和未来最终发布者均不得解释关系20。

本叶建立登记时会真实调用 L1；形成动态规格和读取专项均有真实成功行为。但它不提交 P13 后状态或动态规格，不建立跨域最终幂等账、事务、撤销或发布后组合读回。读取成功专项只能用通用 L1 测试夹具预置完全合法的已发布事实，不能新增生产旁路写入口。

## 2. 正式依据与复用裁决

- 4015：关系端点只能是节点；值必须由强类型属性类型、所属、来源和不可变材料成立；一次最终写集只用一个幂等键和期望事实代次。
- 4180：持久差异必须保留两侧输入、注册、算法、结果类型、单位、维度、分量角色、方向、误差/量化和适用范围，裸 I64 不能独立解释为变化事实。
- 4190：原子动态只由相邻、同主体、同具体特征且材料变化的前后状态形成；动态领域不得补建缺失状态。
- 4200：状态迁移动能关系20只有角色1—5和9有值，角色6—8为空；动态种类固定 `状态迁移`，聚合规则版本固定0；跨领域最终发布者只拼接事实所有者形成的不可变规格。
- 4210：角色1主体、2场景、3被改变目标、4前状态、5后状态、9来源存在均恰一；前后状态必须同主体、同场景、同特征且时间有序。
- P13 v0.1：等价和非等价都形成后状态规格，但只有非等价成功返回 `允许形成迁移动能规格`；后状态本地键固定 `0x53000001`，并携带 P12/P11/P10 完整纯值证据。

当前新 L1 没有动态领域模块。旧 `组合.状态动态`、`数据操作.状态动态`、旧节点直接服务和 WORLD-TREE 计划消费句柄、对象版本和旧提供者，只作负面差异证据，不包装、不迁移。

## 5. 登记 L1 结构与幂等

登记私有幂等域固定 `0x0F`，映射为：

```text
(0x0F << 56) | 动态操作幂等身份.值
```

`建立登记` 在一个 L1 写集建立十个节点：

| 本地键 | 节点 |
| --- | --- |
| 1 | 普通动态服务身份 |
| 2 | 普通关系20类型 |
| 3 | I64 动态资格属性类型 |
| 4 | I64 动态种类属性类型 |
| 5 | I64 聚合规则版本属性类型 |
| 6 | U64组 时间范围属性类型 |
| 7 | U64组 迁移比较合同属性类型 |
| 8 | I64 迁移差异属性类型 |
| 9 | U64组 比较输入引用属性类型 |
| 10 | I64组 比较输入材料属性类型 |

登记写集零关系、零值、零槽、零退出。成功或精确重复必须取得十个完整、非零、互异映射，并在同代次从 L1 独立读回普通/属性类型节点及精确表示种类后才保存登记。一个服务实例只允许一份登记；同键同义读回，同键异义或第二首次登记为 `幂等冲突`。

公开函数：

```cpp
explicit L1动态服务::L1动态服务(L1事实基座服务& L1) noexcept;
L1动态登记结果 L1动态服务::建立登记(const L1动态登记请求& 请求);
L1动态登记结果 L1动态服务::读取当前登记() const;
```

`读取当前登记` 必须逐项从 L1 验证十节点当前有效和表示，服务缓存只能提供定位编码，不能证明登记事实。

## 7. P13 分支准入

固定映射：

| P13结果 | P11证据 | P14结果 |
| --- | --- | --- |
| `无前状态` | 空 | `无需形成/无前状态`，零规格 |
| `已形成`且禁止动态 | 完整等价、差异0、等价关系 | `禁止形成/材料等价`，零规格 |
| `已形成`且允许动态 | 完整非等价、增加或减少、差异非零且可表示 | 继续形成规格 |
| P13其它非成功 | 任意 | 映射对应非成功，零规格 |
| 禁止动态但非等价，或允许动态但等价/差异0 | 任意 | `内部不一致/迁移证据不完整` |

值编码、创建代次或事实截止变化不能绕过 P11 等价裁决。P14 不重新调用比较器，也不接受调用方替换比较结果。

## 8. 关系20角色与局部键

动态规格命名空间固定 `0x44`，共十五个键：

| 本地键 | 事实 |
| --- | --- |
| `0x44000001` | 普通状态迁移动能节点 |
| `0x44000002` | 动态资格 I64 值1 |
| `0x44000003` | 动态种类 I64 值1=`状态迁移` |
| `0x44000004` | 聚合规则版本 I64 值0 |
| `0x44000005` | 时间范围 U64组 `[T0,T1]` |
| `0x44000006` | 迁移比较合同 U64组 |
| `0x44000007` | 迁移差异 I64 |
| `0x44000008` | 比较输入引用 U64组 |
| `0x44000009` | 比较输入 I64组 `[旧值,新值]` |
| `0x4400000A` | 关系20角色1，目标=P13/P11主体 |
| `0x4400000B` | 关系20角色2，目标=前后相同场景 |
| `0x4400000C` | 关系20角色3，目标=P8实例槽 |
| `0x4400000D` | 关系20角色4，目标=P9/P12前状态稳定编码 |
| `0x4400000E` | 关系20角色5，目标=P13本地键`0x53000001` |
| `0x4400000F` | 关系20角色9，目标=P13/P11来源存在 |

六条关系源均为本地动态键1，类型均为登记关系20，顺序精确为1、2、3、4、5、9。角色6—8在写集中的关系数量必须为零；禁止建立空节点、零目标、占位关系或未知角色。

八个值都属于动态节点，八个属性槽分别指向键2—9。资格、种类和聚合规则来源为动态服务身份；时间、比较、差异和输入见证来源为角色9来源存在。规格零退出事实。

## 9. 类型化比较证据

`迁移比较合同` U64组固定20项：

```text
[证据版本1,
 P2抽象特征定义编码,
 P11注册身份编码,
 算法版本,
 比较用途=状态迁移,
 结果原始类型=I64,
 具名关系=状态迁移增加或减少,
 三态编码（旧<新为1，旧=新为2，旧>新为3）,
 等价=0,
 单位编码,
 维度编码,
 分量角色编码,
 差异方向=右减左,
 可表示=1,
 边界包含枚举,
 量化规则枚举,
 误差合同版本,
 比较事实截止代次,
 迁移差异I64属性类型编码,
 适用范围版本=1]
```

`比较输入引用` U64组固定13项：

```text
[前状态编码,
 旧P8值编码, 旧值属性类型编码, 旧值创建代次, 旧值退出代次或0, 旧来源编码,
 新P8当前值编码, 新值属性类型编码, 新值创建代次, 新来源编码,
 P8实例槽编码, P2抽象定义编码, 共同事实截止代次]
```

`比较输入I64组` 固定两项 `[旧采样I64, 新当前I64]`。迁移差异键7固定为 checked `新值-旧值`，必须非零并等于 P11 差异。时间范围 `[T0,T1]` 取 P9 前状态业务时间和 P13 后状态业务时间，`0<T0<T1`。派生时间值不能替代角色4、5状态端点。

P9被采样值属性类型只进入旧输入见证，不作为 P2定义或注册路由；P2上界不进入动态事实。差异 I64 必须和合同组中的结果类型、单位、维度、分量角色、方向、误差/量化和适用范围一起解释。

## 10. 确定性与线程边界

相同动态登记、P13状态规格、P12选择证据、P11比较证据和 P10/P8后当前见证必须生成逐字段相同的十五键规格与摘要。摘要按固定字段序列编码，不包含地址、容器顺序、锁、缓存、许可、未来稳定编码或日志。

函数为 `const`。它只在动态服务锁内复制登记定位材料，解锁后校准 P13 值式结果；不跨服务持锁，不调用 L1 写入。并发登记漂移时返回 `版本漂移` 或 `登记未加载`，不形成混用登记的规格。

动态规格生成即弃，不维护幂等账。丢弃、异常或资源失败只销毁内存对象；未来最终发布失败的撤销和隔离不在本叶。

```cpp
状态迁移动能结果 L1动态服务::读取状态迁移动能(
```

读取固定执行：首快照 `G0`；十五项先读当前、已退出则按同编码读历史；验证动态源、关系20类型、角色1—5/9恰一且角色6—8为零；验证八槽、表示、材料、来源和生命周期；验证前后时间、主体/场景/实例槽/来源及比较证据自洽；末快照 `G1`。`G0==G1` 才成功，一次完整重试仍漂移返回 `版本漂移`。

读取不调用 P11、不重新路由注册、不依赖缓存、日志、SQL或请求回显。它只验证已发布差异事实内部保存的类型化算术不变量，不以重新比较替代持久证据。端点后来退出不删除动态；按 L1 历史入口仍可互证。

## 12. 错误映射

| 情形 | 结果 |
| --- | --- |
| 合同/规则/幂等/截止/编码非法 | `入口拒绝` |
| 登记尚未建立或不能读回 | `登记未加载` |
| 登记同键异义或第二首次登记 | `幂等冲突` |
| P13无前态或等价成功 | `无需形成` + 具名原因 + 零规格 |
| P13明确禁止动态但不是规范等价成功 | `禁止形成` 或矛盾时 `内部不一致` |
| P13/P11其它非成功 | 对应 `入口拒绝/未找到/版本漂移/许可拒绝/资源失败` |
| 主体、场景、实例槽、状态、来源、时间或比较证据不一致 | `入口拒绝`；前置成功后发现坏载荷为 `内部不一致` |
| 角色6—8非空、缺/重角色、错端点、坏槽/类型/材料 | `内部不一致` |
| 首末截止或登记版本漂移 | `版本漂移` |
| 分配失败 | `资源失败` |

除 `已登记/已读取/已形成` 外，对应登记、事实或规格载荷为空。`无需形成` 和 `禁止形成` 是明确的零规格结果，不等于未实现。

## 13. 验证矩阵

新增顶层专项顺序390，至少覆盖：

1. `0x0F`登记十节点、精确重复、异义冲突、十映射和独立读回；
