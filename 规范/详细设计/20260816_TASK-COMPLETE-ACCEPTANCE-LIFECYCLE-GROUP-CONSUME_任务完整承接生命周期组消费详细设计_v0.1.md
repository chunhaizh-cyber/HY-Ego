# 任务完整承接生命周期组消费详细设计 v0.1

日期：2026-08-16

计划身份：`TASK-COMPLETE-ACCEPTANCE-LIFECYCLE-GROUP-CONSUME`

## 1. 目标与完成边界

实现当前任务树的第二个输入叶：

```text
BIZ-L4-004-02-02-02 v0.2
任务业务服务::读取各任务完整承接与生命周期事实
-> 接收02-01在同一非零G0返回的入口来源需求和非空当前承接任务组
-> 只经DATA-EXT-13唯一任务结构服务恰一次批量读取
-> 完整互证每个任务的全部当前来源关系、唯一目标引用、唯一运行场景和唯一当前生命周期结构
-> 形成稳定排序、不可变、零部分载荷的BIZ值式组
```

本叶只形成“任务完整承接与当前生命周期”中性读取投影。它不读取来源需求的目标内容，不裁决目标等价、当前根、任务树唯一性、任务完成、阶段业务含义、调度或权限；不读取子任务拓扑和运行态治理存在；不读历史生命周期前驱或迁移证据。

## 2. 正式依据与当前事实

设计初始 S0 基线为 `main@66e6677116df99521feb431bc526d7062da71a39`；发布前已在不重叠的 DATA 设计与索引提交后增量复核到 `main@2e37ae2ca448b9e88b35d96d7592bd77468d9e53`：

1. 0050 要求组合读取显式声明事实截止并只返回调用方拥有的不可变完整投影；DATA-L2 可以校验任务强类型结构，但不能判断任务完成或调度。
2. 3200 规定一个任务只有一个确定目标，但可承接一个或多个目标等价来源需求；全部来源必须保留，任务身份、目标、场景和生命周期不得复制为第二权威。
3. 5090 规定同一有效来源需求复用唯一任务树，但“唯一当前任务树”是父级业务裁决，不属于 DATA 或本叶。
4. 5200 把任务身份、全部来源关系、运行场景、目标关系和当前生命周期定义为结构锚点；运行态治理存在是独立结构锚点，由后继 02-03 v0.2 读取。02-03 v0.1 的来源集合读取职责由本叶正式替代并退出。
5. 5210 规定生命周期阶段只是路由投影，不能替代完整任务状态；本叶因此只返回当前生命周期结构，不把阶段枚举解释成完成、失败或可调度结论。
6. 数据服务最终需求清单 DATA-EXT-13 已要求唯一 `任务结构服务`读取完整任务投影、来源关系、目标引用、场景、生命周期、版本和共同事实截止，并显式处理范围、预算和结构化失败。
7. 当前真实代码只闭合共同 `L2需求身份`、`L2任务身份`和节点族身份来源；不存在生产 `L2任务结构服务`、任务结构公开 DTO、`服务.任务.ixx`或本函数。
8. `TASK-CURRENT-ACCEPTANCE-GROUP-BY-DEMAND-CONSUME v0.1` 已冻结 02-01 的同一 `任务业务服务`、同一 DATA-EXT-13 const 借用和按来源需求当前承接关系组读取，但仍待 DATA 最终 ABI 激活。
9. 旧 BIZ-L4 v0.1 逐任务分别读取承接材料和关系14历史前驱，既不能保证一次共同截止完整组，也把当前树读取扩大成历史审计。

裁决为：以 v0.2 原位替代 v0.1；扩展同一未来 `任务业务服务`，要求 DATA-EXT-13 增加一次批量完整读取。当前缺真实 ABI 只形成待激活门禁，不阻断 BIZ 合同冻结。

## 3. DATA-EXT-13 消费合同

### 3.1 唯一公开操作

本叶要求同一 `任务结构服务`提供一个公开 const 组读能力，语义冻结为：

| 操作 | 请求 | 成功返回 | 非成功 |
| --- | --- | --- | --- |
| 按任务组与指定截止有界读取完整承接生命周期结构 | 非空、无重复任务身份组；非零G0；事实/需求/任务范围版本；目标/来源/场景/生命周期/读取规则版本；任务数和全部来源关系数两项非零总预算 | 与规范化任务组等长同序的完整任务结构项；每项含任务身份及来源、全部当前来源关系、唯一目标状态合同引用、唯一运行场景引用、唯一当前生命周期结构、各结构版本和单项G0；回显请求版本、两预算和共同G0 | 请求拒绝、指定任务未找到、指定任务已退出、指定预算不足、事实代次漂移、许可拒绝、资源失败、未实现和内部不一致分账；整组失败零成功前缀。BIZ在本叶同G0上游见证语境中把未找到/退出升级为内部不一致 |

最终 DATA 请求 / 结果 DTO 名、字段顺序、状态数值和函数签名由 DATA 唯一所有者发布后机械匹配。BIZ 不建立兼容壳、第二 owner 或同义 DATA 服务。

### 3.2 完整结构项

每个成功项至少同时包含并互证：

```text
非零任务身份及完整任务身份来源，节点族=任务
全部当前任务—来源需求关系；每项含关系强类型身份及来源、任务源端点、需求目标端点、当前生命周期、关系版本和G0
唯一当前任务目标关系；目标端点为非零L2目标状态合同身份，关系身份/来源/版本/G0完整
唯一当前任务运行场景关系；场景端点为非零L2场景身份，关系身份/来源/版本/G0完整
唯一当前任务生命周期关系及生命周期事实；任务端点、阶段投影、业务状态段引用、发生时间、当前性、生命周期版本、规则版本和G0完整
任务结构版本、目标关系版本、来源关系版本、场景关系版本、生命周期规则版本与请求完全匹配
```

本叶不要求 DATA 返回来源需求完整目标材料、子任务关系、运行态治理存在、任务特征全集、筹办/执行权、方法选择、冻结、工作项或结果。它们分别属于父级目标等价裁决、02-03 和后续任务业务叶。

### 3.3 共同截止、预算和稳定顺序

- BIZ 请求携带 02-01 的完整当前承接任务见证组；每项见证必须绑定同一入口来源、同一非零 `G0`和完整任务/关系身份来源。BIZ 从见证提取规范化任务身份组后调用 DATA，运行代次和入口来源不进入 DATA 请求或当前性判断。
- 任务数量预算约束规范化输入任务组及成功结果项数量；来源关系总预算约束全部任务的当前来源关系累计数。两者均为非零总预算，超限必须整组失败，不分页、不截断。
- BIZ 在调用前按任务稳定身份排序，重复身份直接请求拒绝且零 DATA 调用。DATA 成功结果必须与该任务组等长同序、集合相等。
- 每个任务的来源关系按需求稳定身份、关系稳定身份排序。排序只能使用正式强类型身份，不使用名称、创建时间、容器顺序或 enum 裸底值。

### 3.4 DATA 不承担的业务语义

DATA 不返回或裁决：

```text
入口来源与其它来源的目标是否等价
哪个任务是当前任务树根
任务生命周期阶段在当前业务中是否有效、完成、失败或可调度
任务是否具有执行权限
任务树是否唯一
应否创建、复用、扩展、迁移或退出任务
```

## 4. BIZ 类型与物理位置

### 4.1 值式合同头

新增：

```text
文件：海中鱼巣/领域/任务完整承接生命周期组.数据.h
所有者：BIZ任务完整承接生命周期消费值式合同
可见性：任务业务服务、合法父级组合器和专属验证
```

冻结 BIZ 形状：

```cpp
inline constexpr std::uint32_t 任务完整承接生命周期合同版本 = 1;

struct 任务完整承接生命周期固定配置 final {
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 需求范围版本;
    std::uint64_t 任务范围版本;
    std::uint64_t 任务目标关系规则版本;
    std::uint64_t 任务来源关系规则版本;
    std::uint64_t 任务场景关系规则版本;
    std::uint64_t 任务生命周期规则版本;
    std::uint64_t 读取规则版本;
};

struct 任务完整承接生命周期读取请求 final {
    std::uint32_t 合同版本;
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 需求范围版本;
    std::uint64_t 任务范围版本;
    std::uint64_t 任务目标关系规则版本;
    std::uint64_t 任务来源关系规则版本;
    std::uint64_t 任务场景关系规则版本;
    std::uint64_t 任务生命周期规则版本;
    std::uint64_t 读取规则版本;
    std::vector<当前承接任务值式事实> 当前承接任务组;
    std::uint64_t 共享事实截止;
    std::uint64_t 最大任务数量;
    std::uint64_t 最大当前来源关系总数量;
};

struct 任务完整承接生命周期值式事实 final {
    L2任务身份 任务;
    L2节点族身份来源事实 任务身份来源;
    std::vector<任务来源需求关系值式事实> 全部当前来源关系;
    任务目标关系值式事实 唯一当前目标关系;
    任务运行场景关系值式事实 唯一当前运行场景关系;
    任务当前生命周期值式事实 唯一当前生命周期;
    std::uint64_t 事实截止;
};

enum class 任务完整承接生命周期读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    数量预算不足 = 3,
    当前性漂移 = 4,
    提供者拒绝 = 5,
    资源失败 = 6,
    未实现 = 7,
    内部不一致 = 8
};

struct 任务完整承接生命周期读取结果 final {
    std::uint32_t 合同版本;
    任务完整承接生命周期读取状态 状态;
    任务完整承接生命周期读取请求 请求回显;
    std::uint64_t 事实截止;
    std::optional<std::vector<任务完整承接生命周期值式事实>> 任务材料组;
};
```

四个任务关系 / 生命周期类型名是 BIZ 预冻结语义名。最终 DATA ABI 发布后机械匹配或映射成 BIZ 私有值式类型，不得退化为裸稳定编码、通用关系、自由文本或 bool。只有 `已读取`携带 `任务材料组`和非零事实截止；全部非成功载荷为空、事实截止为零。

```text
文件：海中鱼巣/领域/服务.任务.ixx
模块：海中鱼巣.领域.服务.任务
所有者：DATA之外的任务读取业务解释
```

新增固定配置成员并冻结入口：

```cpp
任务完整承接生命周期读取结果 读取各任务完整承接与生命周期事实(
    const 任务完整承接生命周期读取请求& 请求) const noexcept;
```

服务继续只持同一个 DATA-EXT-13 const 稳定借用，不新增第二任务结构服务、L1 / owner / 仓库入口、缓存或写权。若 02-01 最终构造函数只接受一份固定配置，本计划可以机械扩展为组合不可变配置，但不得形成第二 `任务业务服务`实例所有者或第二 DATA 借用路径。

## 5. 固定读取与发布顺序

```text
校验服务固定配置完整，否则内部不一致且零DATA调用
-> 校验BIZ合同、非空02-01见证组、同一入口来源/G0、版本和两项非零预算
-> checked复核任务组大小不超预算
-> 复制并按任务稳定身份排序；重复身份请求拒绝
-> 请求版本逐字段匹配固定配置；不等则当前性漂移且零DATA调用
-> 构造不含运行代次和入口来源需求的DATA-EXT-13批量读请求
-> 从见证组提取任务身份，恰一次调用按任务组与指定截止有界读取完整承接生命周期结构
-> 精确映射DATA非成功；整组失败零成功前缀
-> 互证请求回显、G0、版本、预算、结果项与请求任务组等长同序且集合相等
-> 逐任务互证身份来源、全部当前来源关系和对应02-01见证关系恰一存在
-> 互证唯一目标、唯一运行场景、唯一当前生命周期的端点、来源、当前性、版本和G0
-> checked累计全部来源关系数并复核不超总预算
-> 拒绝空来源、重复来源需求、重复关系、错端点、半结构、混代和未知字段状态
-> 逐任务来源关系稳定排序，形成完整不可变候选
-> 无抛出交换并返回已读取
```

所有 vector 复制、分配、累计和排序位于异常收口内。`std::bad_alloc`、`std::length_error`映射资源失败，未知异常映射内部不一致；成功交换前不得发布部分任务组。

## 6. 非成功与坏形状

| 情形 | BIZ状态 | 载荷 |
| --- | --- | --- |
| 固定配置无效 | 内部不一致 | 空；零DATA调用 |
| 坏合同、零入口来源/G0/版本/预算、空见证组、见证混代/错来源、重复任务或任务数超预算 | 请求拒绝 | 空；零DATA调用 |
| 合法请求与固定配置版本不等 | 当前性漂移 | 空；零DATA调用 |
| DATA返回任一任务未找到或已退出 | 内部不一致 | 空；与02-01同G0当前承接见证矛盾 |
| DATA预算不足 | 数量预算不足 | 空；不得截断 |
| DATA事实代次漂移或成功共同/单项截止不等G0 | 当前性漂移 | 空 |
| DATA明确许可拒绝 | 提供者拒绝 | 空 |
| DATA资源失败、`std::bad_alloc`、`std::length_error` | 资源失败 | 空 |
| DATA未实现/未装配 | 未实现 | 空 |
| DATA请求拒绝、失败任务不明/不在请求组、未知状态、未知异常或坏成功形状 | 内部不一致 | 空 |
| 完整成功 | 已读取 | G0和完整值式组 |

坏成功形状包括：任务集合不等、错序、重复、超预算、空来源、未包含入口来源、重复来源需求、错任务/需求端点、目标/场景/生命周期缺失或多项、错强类型端点、生命周期非当前、混合G0、版本冲突、半结构或任何不可解释附带载荷。

## 7. 激活门禁

计划只登记 `待激活`，直到同时满足：

1. `TASK-CURRENT-ACCEPTANCE-GROUP-BY-DEMAND-CONSUME v0.1`真实结果发布并登记退出，同一 `任务业务服务`、值式合同和 DATA-EXT-13 const 借用最终 ABI 已可机械扩展；
2. DATA-EXT-13 唯一 `任务结构服务`及第 3 节批量完整读取真实实现、普通推送并由 DATA 所有者登记退出；
3. DATA 最终 DTO / 状态 / ABI 与一次组读、非零G0、任务/来源两预算、整组失败、完整当前来源、唯一目标、唯一场景、唯一当前生命周期和失败零前缀语义机械匹配；
4. 目标状态引用使用已发布 `L2目标状态合同身份`或最终等价强类型 ABI，运行场景使用最终 `L2场景身份`，不得退化为实例状态、裸值或通用编码；
5. DATA 的唯一任务结构服务已由普通应用同一 L1 运行包构造并具有最终合法 const 取得路径；
6. `服务.任务.ixx`、工程、唯一代码段、构建和专项资源全部释放，并从最新 `main == origin/main`、index空重做S0。

最终 ABI 若改变上述任何机器语义，必须具名退回计划支撑；不得由执行者拆成逐任务调用、直达L1或静默改变结果形状。

## 8. 验证矩阵与完成声明

专项至少覆盖：

- 坏固定配置、坏请求、空任务组、零G0/预算、重复任务、任务数超预算和版本不等均零DATA调用；
- 单任务、多任务、多来源任务、输入乱序和来源乱序成功；输出稳定且含入口来源；
- DATA恰一次调用；运行代次和入口来源需求不进入DATA请求，入口来源只用于BIZ跨叶互证；
- DATA任务未找到/已退出固定升级内部不一致；两类预算不足、漂移、许可、资源和未实现分别映射；未知状态归内部不一致；
- 任务集合缺项/多项/错序、空来源、缺入口来源、重复来源、错端点/角色/节点族、目标/场景/生命周期零项或多项、错当前性/版本/G0和半结构全部拒绝且零前缀；
- 成功累计来源关系数恰好预算通过、超一项拒绝，并覆盖 checked 累计溢出；
- 源码静态证明零需求目标读取/等价判断、零当前根/阶段业务解释/完成/调度/权限、零子任务/治理存在/历史、零L1/owner/仓库/DATA写/缓存/retry/sleep；
- 根工程 Debug/Release、专项双配置、strict、UTF-8/XML、工程唯一登记和生产零专项痕迹。

真实验证必须经 DATA-EXT-13 正式公开入口，不得由专项直接构造 DATA 成功结果或增加生产 seam。公开 ABI 无法构造的坏成功形状只作 BIZ 静态防御证据，并与 DATA 黑盒拒绝分账。

真实资源耗尽、DATA私有损坏、跨进程恢复、父级目标等价/当前根裁决、02-03子任务树和治理存在、任务创建/迁移/调度/完成、完整任务状态以及系统业务闭环保持 `NOT_RUN`。

本设计发布不证明 DATA-EXT-13、本叶 BIZ 代码或当前任务树已经实现。未来本计划结果最多证明同一 G0 下给定任务组的承接、目标引用、运行场景和当前生命周期中性消费闭合。
