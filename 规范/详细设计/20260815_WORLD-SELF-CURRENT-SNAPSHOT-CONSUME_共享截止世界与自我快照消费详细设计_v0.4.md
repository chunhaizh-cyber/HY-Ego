# 共享截止世界与自我快照消费详细设计 v0.4

日期：2026-08-17

计划身份：`WORLD-SELF-CURRENT-SNAPSHOT-CONSUME`

替代关系：同身份 v0.4 替代已发布 v0.3；v0.3 保留为历史证据，不得原位改写或恢复执行。

## 1. 目标与当前门禁

本叶实现 `BIZ-L3-002-02-01`：按父级冻结的一个非零共享事实截止，经同一 `L2结构聚合服务`读取现实世界整树、自我角色、完整自我存在、当前场景成员和内部世界宿主，全部截止与身份逐字段互证后返回完整值式快照。

本次只修订并发验证合同，不改变 DTO、六入口顺序、业务状态集合、物理模块或三件永久生产 / 工程 WIP。所有非成功仍零快照；BIZ 不直达 L1、不等待、不重试、不吞错、不猜测漂移。

执行现场已经复现：L1 锁竞争返回许可拒绝，`服务.L1事实基座.ixx::映射中性读取状态`压成 `L1中性读取状态::资源失败`，`服务.L2场景结构.ixx::映射事实代次探测失败`继续传播 DATA 资源失败，WORLD-SELF 正确返回 BIZ 资源失败。该结果证明 DATA 前置缺口，不是 WORLD-SELF 合法并发第四状态。

因此 v0.4 创建后索引状态必须为`待激活`。只有具名独立 DATA 前置 `DATA-L2-L1-PERMISSION-REJECTION-PROPAGATION v0.1` 的真实结果进入 main、经接受并与实际 DTO / ABI 匹配后，WORLD-SELF 才能重新 S0 并由索引所有者恢复为可执行。

## 2. 正式依据与裁决

正式依据：0050、4015、4030、4190、4200、4230、6180、7130、CODE-FILE-01，及已发布 WORLD-SELF v0.3 三文档。复核基线：`main == origin/main == 36ce5804b47238ba4b66210d13cd8e98b758acb8`，代码 / 工程 / 验证 WIP 未暂存。

机器裁决：

1. `L1许可拒绝`必须逐层保留为 L2 `许可拒绝`，再由 WORLD-SELF 映射 BIZ `提供者拒绝`；不得压成资源失败。
2. 资源失败仍是公开非成功状态 6，但本次并发专项观察到的资源失败属于 DATA 映射缺口，不能计入合法并发矩阵，不能被设计解释为第四个正常结果。
3. 只有 DATA 明确返回事实代次漂移，或锁内实际观察到已发布 `G1 != G0`，才映射 BIZ 当前性漂移；`Gobs == G0`、零观察截止、预留代次、日志和进行中写入均不构成漂移。
4. BIZ 不修改 DATA 状态、不重试、不等待、不建立第二观察源；坏成功、错截止、结构矛盾仍为内部不一致。

## 3. 基础消费合同

复用 DATA-EXT-01、DATA-EXT-02、DATA-EXT-07 的现有六入口 DTO、同一非零请求截止和服务 getter。读取顺序、字段来源、宿主正反向互证、成员恰一和完整快照形状均与 v0.3 相同；本版本不读取安全、服务、需求、任务、方法、线程或恢复材料。

## 5. 状态映射与失败守恒

| DATA / 请求结果 | BIZ 状态 | 规则 |
| --- | --- | --- |
| 坏合同、零截止、零身份、非法关系 | 请求拒绝 | 零 DATA 调用或首个可判定点停止；零快照 |
| 必需对象未找到 / 已退出、合法成员空材料 | 材料缺失 | 不补默认、历史值或缓存 |
| DATA 明确事实代次漂移，或锁内已发布 `G1 != G0` | 当前性漂移 | 零快照；由调用方按新 G0 重新发起 |
| DATA `L2许可拒绝`，包括无观察截止的锁竞争 | 提供者拒绝 | 零快照；不得称漂移 |
| 固定合法请求被入口 / 引用 / 预算拒绝 | 提供者拒绝 | 零快照，不降级为空 |
| DATA 资源失败 | 资源失败 | 零快照；不等待、不重试；并发专项计为门禁失败而非合法矩阵结果 |
| DATA 内部不一致、坏成功、错截止、复义、拓扑矛盾 | 内部不一致 | 零快照，停止依赖路径 |

异常映射保持 v0.3：分配异常为资源失败，其它未处理异常为内部不一致。任何状态均不得携带部分快照。

## 6. 固定顺序与并发矩阵

请求校验后依次读取整树、角色、完整存在、成员、宿主正向、宿主反向；每次原样传入同一非零 G0，逐项先看结构化状态、再看截止、最后看载荷。首个非成功立即收束。

合法并发矩阵只有三类：

| 观察 | DATA 结果 | BIZ 结果 | 是否计入并发门禁 |
| --- | --- | --- | --- |
| 六项按 G0 成功且互证一致 | 已读取 | 已形成 | 是 |
| DATA 明确漂移或锁内已发布 `G1 != G0` | 事实代次漂移 | 当前性漂移 | 是 |
| L1 / DATA 锁竞争明确保留许可拒绝 | 许可拒绝 | 提供者拒绝 | 是 |

若并发专项仍观察到 `DATA 资源失败`（包括 v0.3 已复现的 `46=40+6`、`83=70+13`），只记录为 DATA 前置未满足并立即失败；不得把它扩成第四个合法矩阵值、改成提供者拒绝、改成漂移或由 BIZ 重试。

## 7. 独立 DATA 前置与恢复门禁

具名前置：`DATA-L2-L1-PERMISSION-REJECTION-PROPAGATION v0.1`。该前置由计划智能体另立独立计划，不属于本 WORLD-SELF 代码白名单，本版本不伪造其结果。

前置结果必须机械证明：

- L1 许可拒绝经 `服务.L1事实基座.ixx::映射中性读取状态`保持许可拒绝；
- L2 六个当前读取入口及 `映射事实代次探测失败`逐项显式传播许可拒绝和零载荷；
- 不新增第二状态、原子镜像、等待、重试、日志事实或 BIZ 特例；
- Debug / Release 并发专项不再把合法锁竞争报告为 DATA 资源失败；真实资源失败仍保持状态 6；
- 结果提交进入正式 main、经交互接受、临时资源释放，且实际 DTO、状态值、函数签名和调用次数与本计划机械匹配。

在以上条件全部成立前，索引只能登记 v0.4 `待激活`，执行侧不得施工。前置完成后必须从新 HEAD 完整 S0，重新核对六入口 ABI、三件永久 WIP、工程资源和并发矩阵。
