# L1-SIMPLIFY-P3-FEATURE-INSTANCE 初始场景实例特征槽与初始值详细设计 v0.1

更新时间：2026-08-04

## 1. 目标与非目标

本设计在已发布的 `L1-SIMPLIFY-P2-FEATURE-DEFINITION v0.1` 之后建立首个最小实例特征叶：只允许把一个已验证 I64 抽象特征定义实例化到已验证初始场景，并在同一 L1 写集中发布实例槽、宿主关系、定义关系、初始 I64 值和当前属性槽。

本叶不实现其它宿主、当前值换代、关系 22 固定编号、特征批次、比较、状态动态、恢复、生产初始化、旧特征体系兼容或删除。

## 2. 正式依据与当前事实

- `0050`、`4015`、`4030`—`4050`：运行期内存已发布代次、业务中性 L1、领域唯一写入、结构化非成功和发布后读回。
- `1120`、`1130`、`2100`、`4110`：定义与实例分离；实例槽必须有唯一宿主、唯一定义和唯一当前值；新槽与初始值共同发布。
- 0050/4015 是物理合同上级：当前值由节点属性槽和值事实承载；4110 中旧“关系 22 / 完整句柄”只保留业务角色意图，不作为本叶固定物理编号或可变版本合同。
- 正式结果 `0041f974614a64f74d387209c45ec2c403f43213` 提供 `L1场景结构服务::读取初始场景`；正式结果 `263a658ada4bf4a284901d084f993564b4b6a8df` 提供 `L1特征定义服务::读取I64特征定义`。
- 当前 L1 写集可在一个代次内建立节点、关系、值和属性槽；期望事实代次使并发写者不能在同一旧基线上同时成功。

## 3. 模块、依赖与所有权

新增：

```text
海中鱼巣/领域/L1实例特征.数据.h
海中鱼巣/领域/服务.L1实例特征.ixx
海中鱼巣/领域/自检.L1实例特征.ixx
```

生产模块：`海中鱼巣.领域.服务.L1实例特征`。

模块导入固定为：

```cpp
export import 海中鱼巣.领域.服务.L1场景结构;
export import 海中鱼巣.领域.服务.L1特征定义;
import 海中鱼巣.核心.服务.L1事实基座;
```

前两个导出导入使公开 DTO 中嵌套的场景/定义读取请求对消费者完整可见；不得导出导入 L1 完整合同或 L1 服务。

依赖方向：

```text
L1实例特征服务
  -> L1场景结构服务（证明宿主是当前初始场景）
  -> L1特征定义服务（证明抽象定义和值域当前有效）
  -> L1事实基座服务（形成业务中性原子写集并独立读回）
```

实例槽、宿主/定义角色和当前值准入唯一归 `L1实例特征服务`；调用方不取得 L1 写集、锁、候选或撤销能力。

## 5. 服务合同

```cpp
class L1实例特征服务 final {
public:
    L1实例特征服务(L1事实基座服务& L1,
        L1场景结构服务& 场景结构,
        L1特征定义服务& 特征定义) noexcept;

    实例特征登记结果 建立登记(const 实例特征登记请求& 请求);
    实例特征登记结果 读取当前登记() const;
    I64实例特征结果 建立初始场景I64实例特征(
        const 初始场景I64实例特征建立请求& 请求);
    I64实例特征结果 读取I64实例特征(
        const I64实例特征读取请求& 请求) const;
};
```

服务长期持有三个依赖引用和私有互斥；不得复制、移动或导出 L1 完整合同。

## 6. 登记写集

私有幂等域固定：登记 `0x05`，实例建立 `0x06`。身份仍限 56 位，映射为 `(域 << 56) | 身份.值`。

登记在调用时当前事实代次必须等于请求期望代次，写集精确建立四节点：

| 本地键 | 节点 | L1 类型 |
| --- | --- | --- |
| 1 | 服务身份 | 普通 |
| 2 | 宿主槽关系类型 | 普通 |
| 3 | 定义模板关系类型 | 普通 |
| 4 | 当前 I64 值属性类型 | 属性类型 / I64 |

成功或精确重复后逐节点同代次读回并缓存登记；同键异义返回幂等冲突。

## 7. 实例建立事务

### 7.1 第一写前

1. 校验合同、规则、幂等身份、非零期望代次和来源编码。
2. 登记必须已加载。
3. 调用 `场景结构_.读取初始场景(请求.宿主)`；只接受 `已读取` 和完整事实。
4. 调用 `特征定义_.读取I64特征定义(请求.定义)`；只接受 `已读取` 和完整事实，且 `初始值` 位于闭区间 `[下界, 上界]`。
5. 用 L1 读取来源节点；必须为当前有效普通节点。
6. 场景、定义、来源及 L1 完整快照的事实代次必须全部等于请求期望代次。
7. 扫描同一完整快照：若已有当前宿主关系指向某槽，且该槽已有当前定义关系指向请求定义，则返回入口拒绝；任何多宿主、多定义、悬空端点或登记类型复义返回内部不一致。

### 7.2 单一写集

精确形状：

```text
节点 1：实例槽（普通）
关系 2：宿主 -> 实例槽 / 宿主槽关系类型 / 角色1
关系 3：实例槽 -> 抽象定义 / 定义模板关系类型 / 角色2
值 1：所属实例槽 / 当前I64值属性类型 / 初始I64 / 请求来源节点
属性槽变更 1：实例槽 + 当前I64值属性类型 -> 新值
退出事实 0
```

槽和初始值必须共同发布同一新事实代次；不得创建角色3关系、索引、批次账或第二当前值表。

### 7.3 独立读回

从写入映射取得槽、两关系和值编码，构造公开读取请求并调用 `读取I64实例特征`。读取函数必须重新调用场景/定义服务并从 L1 逐项读取：实例槽、两关系、关系类型、属性槽、当前值、属性类型和来源节点；所有读取事实代次相同，端点、角色、材料和值域逐字段一致才返回 `已读取`。建立函数再把状态改为 `已提交` 或 `幂等读回`。

## 8. 非成功与并发

- 无效合同、未加载登记、来源无效、初始值越界、宿主或定义未命中：入口拒绝或未找到，零写入。
- 同幂等键同义：精确重复并独立读回；同键异义：幂等冲突。
- 期望代次不等、嵌套服务读回代次不一致：事实代次漂移。
- 写前通过后出现多宿主、多定义、当前槽/值矛盾或发布后读回不一致：内部不一致。
- `bad_alloc`：资源失败；其它异常：内部不一致。
- 服务锁串行同实例调用；跨实例并发由 L1 期望代次保证最多一个旧基线写集成功。

## 9. 运行期与自检

运行期上下文在 `L1特征定义服务` 之后持有 `L1实例特征服务`，提供 const/非 const 访问器，不改变 `完整()`。

新增顺序 `320` 专项，完整自检总数 `26 -> 27`。专项至少覆盖：登记未加载、登记成功/幂等/冲突、非法合同、初始场景与定义真实组合、同事务形状、成功读回、幂等读回、越界、重复宿主+定义、来源未找到、代次漂移、错误关系/值读取、资源失败后零事实变化、同一运行期服务身份连续性。

## 10. 完成边界

完成只证明一个已验证初始场景上的 I64 实例槽和初始值可按新 L1 合同原子发布并独立读回。其它宿主、值换代、批次、比较、状态动态、恢复和生产业务仍须独立后继叶。
