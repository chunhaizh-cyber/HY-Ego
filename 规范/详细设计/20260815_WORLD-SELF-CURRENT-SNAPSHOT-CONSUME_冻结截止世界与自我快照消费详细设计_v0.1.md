## 1. 目标与完成边界

实现 `BIZ-L3-002-02-01`：根据父级冻结的场景 owner 截止和存在 owner 截止，经普通应用同一 `L2结构聚合服务`取得同实例场景、存在服务，正式读取现实世界整树、项目唯一自我角色、自我存在、当前场景成员和内部世界宿主，逐字段互证后形成调用方拥有的值式世界—自我快照。

旧名“读取同代次世界与自我快照”会暗示跨 owner 全局原子代次，现行规范不允许该解释。本版本改名为“读取冻结截止世界与自我快照”：

```text
本函数证明：每个 owner 的正文与该 owner 冻结截止一致
父函数证明：读取前向量 == 全部子快照来源见证 == 读取后向量
两者共同成立，才形成跨 owner 一致事实
```

本叶全程只读，零 DATA 写、零 BIZ 缓存、零默认补造。它不读取安全、服务、需求、任务、方法、线程或控制面板事实，不建立新的自我 provider，不实现发布见证向量服务，也不开放自我治理运行门。

## 3. 基础数据公开服务消费清单

本叶复用 `计划/数据服务最终需求清单.md` 的 `DATA-EXT-01`、`DATA-EXT-02` 和 `DATA-EXT-07`。父级 `BIZ-L3-002-01-03` 另需 `DATA-EXT-17`。下表只冻结 BIZ 根据什么参数获取什么数据，不规定 DATA 内部实现。

| 业务目的 | 公开服务与操作 | 输入参数 | 成功返回 | 空 / 失败处理 |
| --- | --- | --- | --- | --- |
| 取得同实例 provider | `const L2结构聚合服务::取得L2场景结构服务()`、`取得L2存在结构服务()` | 普通应用同一聚合服务 const 引用 | 两个同实例服务 const 引用 | 未装配 / 实例不一致是装配失败，不在本函数补建 |
| 读取现实世界整树 | `L2场景结构服务::读取场景树` | `{合同版本, 场景截止}`、当前类别、现实世界树、历史截止 0 | 完整整树、根、场景组、父子组和相同截止 | 树 / 场景缺失为材料缺失；漂移和其它失败分账 |
| 反向读取自我当前成员关系 | `读取存在当前场景成员引用` | `{合同版本, 场景截止}`、自我存在 | 稳定排序的当前场景成员引用组 | 空组为材料缺失；多于一项或端点矛盾为内部不一致 |
| 双向读取内部世界宿主 | `读取场景宿主存在关系`、`读取存在当前宿主场景` | 同一场景截止 + 内部世界场景；同一场景截止 + 自我存在 | 同一条场景—宿主存在关系的正反向事实 | 任一未找到、复义或不相等整体失败 |
| 读取项目唯一自我角色 | `L2存在结构服务::读取存在单例角色` | `{合同版本, 存在截止}`、当前类别、自我角色键、历史截止 0 | 角色关系和存在身份来源 | 未绑定为材料缺失；绑定内容不符为内部不一致 |
| 读取完整自我存在 | `读取完整存在` | `{合同版本, 存在截止}`、当前类别、自我存在、历史截止 0 | 完整活动存在事实 | 未找到 / 已退出为材料缺失；角色结果不能代替正式存在读回 |

所有单对象 / 条件读取都使用非零 owner 截止。BIZ 不直达 L1 取截止，不把 `期望事实代次=0`用于这些读取，也不把一个 owner 的截止复制给另一个 owner。

## 4. 函数与 DTO 合同

### 4.1 物理形态

新建真实模块：

```text
文件：海中鱼巣/领域/组合.运行期只读查询.ixx
模块：海中鱼巣.领域.组合.运行期只读查询
```

模块唯一拥有 `运行期只读查询组合器` 及本叶 DTO。组合器只借用 `const L2结构聚合服务&`，不拥有 DATA 实例、事实或锁。

### 4.2 请求

```cpp
inline constexpr std::uint32_t 世界自我冻结截止快照合同版本 = 1;

struct 世界自我事实截止 final {
    std::uint64_t 场景结构事实截止 = 0;
    std::uint64_t 存在结构事实截止 = 0;
};

struct 世界自我冻结截止快照请求 final {
    std::uint32_t 合同版本 = 世界自我冻结截止快照合同版本;
    std::uint64_t 运行代次 = 0;
    std::uint32_t 事实范围版本 = 0;
    L2场景树身份 现实世界树;
    L2场景身份 根场景;
    L2存在单例角色键 自我角色;
    L2存在身份 自我存在;
    稳定编码 自我角色关系编码;
    L2场景身份 自我所在场景;
    稳定编码 所在场景成员关系编码;
    L2场景身份 自我内部世界场景;

```

身份与关系编码必须从上游 SELF-FORM 成功值复制，只作选择和互证，不能替代本次正式读回。

### 4.3 结果

状态稳定值固定为：

```text
已形成、请求拒绝、材料缺失、当前性漂移、提供者拒绝、资源失败、内部不一致
```

值式快照精确包含：

```text
合同版本、运行代次、事实范围版本、两个 owner 截止
+ 完整现实世界树
+ 自我角色关系
+ 自我存在身份来源
+ 完整自我存在
+ 唯一所在场景成员引用
+ 内部世界场景宿主关系
```

整树内嵌的根、所在场景、内部世界场景、直接成员和当前宿主是快照的一部分，不再复制成第二套事实字段。结果只在 `已形成` 时携带快照；其它状态快照必须为空。结果另带具名失败来源枚举，但不得夹带部分成功事实。

```cpp
class 运行期只读查询组合器 final {

    explicit 运行期只读查询组合器(
```

组合器不可复制、不可移动；构造只保存 const 引用，不触发读取。入口诊断责任为“向上送出”，不自行写日志。

## 5. 固定读取与互证顺序

```text
校验请求、身份 / 关系编码、范围版本和两个非零截止
-> 经 const 聚合服务取得同实例场景 / 存在服务
-> 按场景截止读取现实世界整树
-> 按存在截止读取项目唯一自我角色
-> 按存在截止读取完整自我存在
-> 按场景截止反向读取自我当前场景成员引用组
-> 按场景截止正向读取内部世界宿主
-> 按场景截止反向读取自我当前宿主场景
-> 全部成功后逐字段互证
-> 完整候选一次构造并返回已形成
```

互证必须同时满足：

1. 所有场景结果截止恰等于请求场景截止；所有存在结果截止恰等于请求存在截止。
2. 整树身份、根场景与请求一致，`L2场景树事实完整`成立。
3. 根、所在场景和内部世界场景互异，均在整树中恰一；整树父子关系恰证明 `根 -> 所在 -> 内部世界` 两条直接边。
4. 反向成员引用组恰一，关系编码、场景、存在与请求相等；整树所在场景内嵌直接成员中存在同一关系，内部世界场景不得把自我存在列为直接成员。
5. 内部世界场景内嵌宿主、正向宿主和反向宿主三者逐字段相等，且关系编码 / 场景 / 宿主与请求相等。
6. 自我角色键、角色关系编码和目标存在与请求相等；存在身份来源节点族为存在且编码与自我存在一致。
7. 完整存在身份与请求一致，生命周期在存在截止为活动。

## 6. 非成功与守恒

| 情况 | BIZ 状态 | 守恒 |
| --- | --- | --- |
| 请求字段无效、零截止、身份关系非法 | 请求拒绝 | 在首个可判定点停止；零快照 |
| 任一必需读取未找到 / 已退出，或成员组为空 | 材料缺失 | 不用旧快照或默认事实补齐 |
| 任一读取事实代次漂移 | 当前性漂移 | 父级重新取得完整向量后发起新批次 |
| 固定合法请求被入口拒绝、幂等 / 引用冲突或预算拒绝 | 提供者拒绝 | 不降级为空 |
| 任一资源失败 | 资源失败 | 本次零快照；可重新只读调用 |
| 坏成功载荷、截止不等、复义、关系编码 / 拓扑矛盾 | 内部不一致 | 零部分发布 |

本函数无可变已发布值。失败守恒就是“本次结果不携带快照且 DATA 零写”；重试不需要 BIZ 幂等账。

## 7. 并发与跨 owner 一致性

- 组合器无锁、无缓存；每次调用只使用局部值式结果。
- DATA 服务负责各 owner 内部同截止读取；BIZ 不取得 owner、仓库、锁或事务。
- 两个 owner 截止可以数值相同或不同；数值相同不升级为全局代次，数值不同也不表示不一致。
- 父级必须在正文后再次读取同一范围发布见证向量，要求前向量、两个来源截止和后向量逐项相等；否则整体版本漂移。
- 任一 owner 漂移时本叶整体失败，不只重读一个对象，不混用新旧结果。

## 8. 物理归属与查重

当前正式代码不存在 `组合.运行期只读查询.ixx` 或同义入口。该函数组合两个 DATA owner 的公开结果但不属于任一 DATA owner；放入场景 / 存在服务会让 DATA 承担自我解释，放入普通应用上下文会扩大装配职责。

| 函数 / 类型 | 所有者 | 形态 / 可见性 | 允许 / 禁止调用方 | 诊断责任 |
| --- | --- | --- | --- | --- |
| 本叶 DTO | BIZ 值式组合合同 | 新模块导出类型 | 自我治理父级和专项 | 无适用错误分支 |
| 组合器构造 | 只读组合器 | 导出公开构造 | 普通应用装配 / 自我治理持有者 | 无适用错误分支 |
| `读取冻结截止世界与自我快照` | BIZ 跨 owner 只读组合 | 导出 const 成员 | 具名自我治理读取；禁止 DATA 反向调用 | 向上送出 |
| 私有互证辅助 | 纯值检查 | 模块内部自由函数 | 仅本入口 | 无适用错误分支 |

工程以 `ClCompile` 唯一登记 `.ixx`，使用方只可 import，禁止 include。公开实体只由模块消费者使用，因此本叶不新建传统数据头。

## 9. 验证矩阵与完成声明

专项至少覆盖：坏请求零 DATA 调用；两个 owner 截止分别传递；整树 / 根 / 两父子边；角色 / 来源 / 完整存在；成员恰一；宿主内嵌 / 正向 / 反向三路一致；每类失败独立映射；坏成功形状和混截止为内部不一致；并发发布只产生已形成或漂移；源码零 L1、SQL、缓存、日志文本和 DATA 写。

父级发布见证向量、SELF-FORM 实际生产结果、普通应用持有组合器、自我治理前后向量闭合、运行门、真实资源耗尽、跨进程恢复和集成验收均为 `NOT_RUN`。

本设计完成只证明 BIZ 世界—自我冻结截止消费合同闭合。即使后继代码通过本叶矩阵，也不能宣称跨 owner 治理一致快照、SELF-FORM、自我治理循环或系统业务闭环完成。
