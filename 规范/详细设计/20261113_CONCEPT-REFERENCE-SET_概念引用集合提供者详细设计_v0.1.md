## 3. 表示与语义

在 `概念_特征类.h` 追加：

```cpp
struct 特征概念概念集合值域 final {
    std::vector<稳定编码> 必含概念节点组;
    bool 至少一个概念 = false;
    friend bool operator==(const 特征概念概念集合值域&,
        const 特征概念概念集合值域&) = default;
};
```

追加到 `特征概念值域` 末尾，不重排旧alternative。`特征概念比较规则` 末尾追加 `概念集合身份判等 = 10`，旧持久值不变。材料物理类型仍为U64数组，无单位，聚合规则为完整材料精确集合。其它材料/规则组合拒绝，不能自动猜成概念集合。

三种域：全材料值域表示全部合法概念集合；`vector<稳定编码>`表示一组完整集合材料节点形成的有限域（不是成员列表）；新struct表示包含指定概念身份并满足非空约束的正向条件。空“必含组”且非空标志为false规范化为全材料域；必含组非空时非空标志规范化为true。所有概念身份组升序去重，排序仅作物理规范化，没有顺序语义。

准确值是一个U64材料节点，里面保存完整成员身份组；所有成员经正式概念owner证明。允许存在、特征（包括二次特征）、动态的正式概念；正式根也是合法概念引用，是否可作为名称目标另由名称owner裁决。本叶不接受因果链、词条、方法实例、普通存在、材料节点或组织根冒充概念。

准确空集合、没有当前值和条件“至少一个概念”分别成立。相同集合不同顺序/重复输入同义，规范化指取得排序去重的成员签名，不修改不可变原始材料或要求const值服务生成新材料。有限域按签名去重，同签名多V用最小编码作为纯存储代表；定义同义和包含仍按签名，不按代表编码。F写入命中既有历史同签名值时复用该历史V累加命中，首次签名保留输入V；不得创建两个语义相同的历史值。不能按数组长度把单成员集合变成单引用。成员概念内容更新不改变集合身份，不冻结概念定义；每次需要定义由原owner读取。概念改接须由后继合法治理更新集合，不能在读取时暗中改写。

保留已有类型和状态，不新增业务真假状态。在 `概念_特征类` 扩展：

```cpp
bool 装配概念集合成员读取接口(
    std::span<const 正式概念身份读取接口* const>) noexcept;

    const 特征概念准确值&, const 新_特征值类&,

    稳定编码 类型根, 稳定编码 材料,
```

装配复制非拥有指针组，拒绝空指针/重复指针；空span表示解除。不存调用方span，不拥有reader。与既有结构初始化和工作线程启动同序：线程启动前装配、全部join之后解除。请求查询期间不得替换reader。先形成合法引用结构再交付，reader成功载荷错误属于工程错误。

通过原有 `建立或取得特征概念强类型`、`更新特征概念值域强类型`、`读取特征概念定义保护`、`比较值域`、`执行比较规则` 闭合新类型；不新建旁路建概念函数。普通完整getter和有限域读取也必须认识该struct和规则。准确集合对约束域的满足可由私有helper提供，再以既有FT比较入口交付，不另造公共结果合同。

## 5. 成员身份、保护与事务

### 5.1 读取

首次接纳读取材料物理类型及完整数组，规范化成员；逐个通过注入reader找到正式身份。合法但不属于该reader继续其它reader；读取前提变化上送，不把它当非概念；所有reader均不认识才为类型不相容。未装配为读取接口未装配。未知类别不取默认类型。

无成功载荷的状态不填输出；成功载荷须包含原目标身份及其自身快照。只核身份和必需结构，不重新计算概念定义正确性、扫描全概念树或比较全部旧快照。写前提交使用本次相关成员身份与保护记录的局部前提；允许其后合法修改定义。

已有持久保护的材料读取只核材料、保护记录及其真实成员引用一致；FC普通定义解码、定义保护读取及正式身份reader不得递归调用成员reader组。成员准入与解码分离，避免FC/RC自引用或互引递归。首次接纳的身份快照仍按现有L1联合快照CAS提交，可能因同节点其它字段变化保守返回前提变化；本叶不声称已实现只比较身份字段，也不为此新增世代/缓存合同。

### 5.2 持久引用

沿用存在集合保护组织模式，在概念owner私有组织内增加“概念集合保护记录类型、材料来源字段、成员保护字段”。每个完整材料至多一个保护记录，保存材料引用及去重概念成员字段；字段必须是稳定编码引用，不能把编码放入基础数值而绕过入向保护。保护记录和成员引用同次原子发布。精确重复复用，成员不等于材料内容为结构损坏，不补造成功。

有限域逐个保护其完整集合材料；条件域的必含成员以概念定义自身的具名成员字段保护，在定义建立/更新同次发布，更新只移除已退出该定义的引用。保护记录与不可变材料同寿命；失败后已建立的合法材料保护保留并可复用，不冒称零写入，不删除用户材料。当前值改变不会解除历史、标准值、状态或有限域仍需的保护。

保护建立与目标退出在L1原子发布边界竞争。必须将成员正式身份读回及保护记录的局部前提并入实际追加请求，不能“先检查再裸追加”。删除目标时原owner及L1完整引用检查须看到真实入向字段；不增加全局锁、不更改L1、不允许清理器抹掉外部保护后强删目标。

### 5.3 特征更新

准备阶段验证类型及集合材料，取得或建立保护；只占用本次F/相关结构。提交沿原封存片段机制与调用方附加片段共同发布。完成按既有规则更新历史命中、标准值、聚合及概念同步，再结束占用。已发布不能取消成“没执行”；完成失败保留事实并走工程链。未知当前值保持原缺值含义，不用空集合代替。

同值的真实再次写入按1130增加命中次数；上层同一业务请求幂等复用不应再次提交该写入。状态/动态属于后继持有者owner，不由本提供者假造词条状态。

## 6. 比较与包含算法

1. 准确集合：按规范化成员身份逐项相等；判等返回现有bool载荷，旧相似度入口等为10000、不等为0。概念上下位相似不等于成员身份相等，不按地址大小求差。
2. 准确集合满足条件域：必含成员是当前成员子集，且非空要求满足。只比较合法正式成员，不凭当前名称或概念内容变化替代身份。
3. 条件域强A蕴含弱B：B必含组为A必含组的子集，且B要求非空时A必含组非空或A非空标志为true。双向蕴含为相等，单向为包含；既无包含又无排斥约束时为相交。只使用正向约束，不发明互斥或排除条件。
4. 有限域之间：按规范化完整集合内容判重、相交及包含，不按材料节点编码代替内容语义。
5. 有限域与条件域：逐个完整集合检查。全命中表示条件域包含有限域，部分命中为相交，零命中为分离。不能因当前已知概念数量少就反向声称有限域穷尽条件域。
6. 全材料域按全部合法集合解释，与空约束同义。有限域本身仍须非空；其中唯一成员可以是准确空集合。

类型错误、成员身份未就绪、资源失败和结构损坏各自沿现有技术状态/工程路径传播，不能转换成“不满足”。本叶是身份约束，不调用成员概念归属推理，不增加“归属未知”的新来源。

## 7. 动态概念reader与锁

`概念_动态类` 实现 `正式概念身份读取接口`，新增同签名 `读取正式概念身份保护(稳定编码) const noexcept override`。使用既有动态互斥的 `try_to_lock`，失败立即返回前提已变化，不sleep、不轮询、不改共享锁。取得锁后仅用L1读本owner身份/组织，不调用特征、二次特征、存在getter，不计算动作效果或定义包含。

固定身份分支：

- 语义根：图根的动态语义根字段唯一指向目标；目标类型为动态根概念类型；图根到目标的父子角色为1。组织图根不是概念。
- 变化实例：实例类型；组织父子角色1；恰一对应动态引用；定义类别缺省或变化1。
- 变化聚合：聚合类型；组织父子角色1；无对应动态引用；定义类别缺省或变化1。
- 动作：聚合类型；定义类别动作2；组织父子角色0；无对应动态引用。

不能要求所有非根概念均直接挂语义根，合法聚合会整理冗余根边。返回含目标与组织登记的身份快照；非本族返回非本提供者，损坏的本族身份走工程链。当前创建/失败回滚在动态锁内，try_lock成功隔离其临时半结构；正式删除仍由入向字段拒绝及L1原子删除裁决，无需改变创建算法。
