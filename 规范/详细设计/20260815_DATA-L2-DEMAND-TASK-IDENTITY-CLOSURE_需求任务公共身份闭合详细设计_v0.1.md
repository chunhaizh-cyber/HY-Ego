# DATA-L2 需求任务公共身份闭合详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-DEMAND-TASK-IDENTITY-CLOSURE`

## 1. 目标与完成边界

只在共同值式合同 `海中鱼巣/领域/L2结构公共.数据.h` 中追加独立 `L2需求身份`、`L2任务身份` 以及 `L2节点族::需求=12`、`L2节点族::任务=13`，并扩展共同身份来源完整性 helper 的闭集，为 DATA-EXT-12 / 13 后继唯一 owner 和强类型结构 CRUD 提供不可混用的身份前置。

本叶不建立需求或任务 owner、节点、目标、来源、父子关系、路径、活动事实、结算、运行态治理存在、执行权、方法选择、工作项、结果、服务、聚合、普通应用装配或机器事实。它也不判断需求是否有效、目标是否满足、任务是否完成或方法是否成功。

## 2. 正式依据与当前事实

- 0050 与 4030：需求、任务、方法是 DATA-L2 的三类强类型治理记录，分别校验自身结构，但业务真实性、有效性、完成性和成功性位于 DATA 之外。
- 3100：需求是单一权威目标的长期目标契约，具有独立稳定身份，不得与任务、方法、日志或显示摘要合并。
- 3200：任务是对确定需求目标的授权承接对象，拥有独立稳定身份；来源需求可以多项，但不得合并身份或与需求、方法共用节点。
- 《数据服务最终需求清单》DATA-EXT-12 / 13 要求公开请求和结果使用需求、任务强类型身份；当前精确 CRUD ABI 尚待后继设计冻结。
- 当前公共头已经发布世界结构 1—7、语言 8、词条 9、概念 10、方法 11；没有 `L2需求身份`、`L2任务身份` 或对应节点族。

尾部数值 12、13 是对已发布闭集的机械追加。既有 1—11 不得插入、重排或复用。

## 3. 精确公开合同

在现有强类型身份宏块尾部依次追加：

```cpp
定义L2强类型身份(L2需求身份);
定义L2强类型身份(L2任务身份);
```

在 `L2节点族` 尾部依次追加：

```cpp
需求 = 12,
任务 = 13
```

`L2节点族身份来源事实完整(...)` 的闭合枚举判断同步接受 `L2节点族::需求` 和 `L2节点族::任务`。共同 helper 仍只判断值式身份来源形状；接受某节点族不证明对应 owner、节点或服务已经存在。

## 4. ABI、不变项与禁止范围

- 两个身份分别沿用现有显式 `稳定编码` 包装、默认零值和逐字段相等；不得隐式转换为彼此、方法、概念、存在或裸稳定编码。
- 不改变 `L2结构合同版本`、`L2结构状态` 1—15、读取类别、请求 / 结果头、既有身份和节点族 1—11 的数值与布局。
- 不在本叶增加需求 / 任务请求、结果、状态、角色、成功 helper 或通用治理记录联合。
- 不建立通用节点族 CRUD、按枚举选择 owner、万能治理服务、第二写入口、业务规则版本、完成见证、deadline、sleep、重试 ABI 或生产验证逻辑。
- 不修改 L1、任一服务、聚合、普通应用、工程、BIZ、线程、规范、流程图或最终需求清单。

## 5. 物理范围与验证

生产代码唯一目标：

```text
海中鱼巣/领域/L2结构公共.数据.h
```

施工形成同名专属施工 / 验证记录。验证至少包含：

1. 两个身份各自精确定义一次，类型不可互换；
2. `L2节点族::需求 == 12`、`L2节点族::任务 == 13`，既有 1—11 与状态 1—15 零变化；
3. 身份来源 helper 接受需求 / 任务并仍拒绝未知值；
4. 根工程 x64 Debug / Release Rebuild；使用专属仓库外输出，不修改或评价暂停 EVENT WIP；
5. diff、strict、UTF-8、白名单、生产零验证痕迹和专属输出清理。

不新增独立验收、临时专项或生产 seam。真实需求 / 任务 owner、节点和 CRUD 均为 `NOT_RUN`，因为本叶没有这些能力。
