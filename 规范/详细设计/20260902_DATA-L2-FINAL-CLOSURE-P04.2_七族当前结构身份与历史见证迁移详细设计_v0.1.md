## 1. 目标、边界与前置顺序

目标是把世界七族（场景、存在、特征定义、特征实例、状态、动态、因果）的“当前结构身份”从携带四份生命周期的共同身份来源见证中分离出来：

```text
当前结构身份
  = 同一 G0 内由 provider 验证四项来源均当前
  + 结果头事实截止 G0
  + 六项结构字段

各族已有或未来经正式明确的历史身份来源见证，以及其专属退出 / 恢复 / 审计路径
  = 在该路径确有需要时使用非零 H
  + H == 结果头事实截止
  + 完整 L2节点族身份来源事实（仍含四份生命周期）
```

本项的唯一前置施工叶是 `P04.1.1`：状态、动态、因果既有历史成功谓词先补齐 `历史截止事实代次 == 结果头.事实截止代次`。它与 P04.2 共用三族头文件和 ABI 链，必须先发布、重新 S0；不得合并成同一计划，也不得并行抢占。

本项不做下列事情：

- 不原位收缩或删除 `L2节点族身份来源事实`、`L2生命周期` 或历史见证；
- 不把“当前”解释为最后观察、最大时间、最大事实代次、首次命中或“未退出集合”扫描；
- 不统一七族退出的业务保留语义；
- 不处理状态 / 动态墓碑、清理、TTL、当前选择旧 owner、legacy 或最终 ABI（均为 P08）；
- 不迁移语言、词条、概念、不可变材料、概念名称关系，或 ARCH-L4 需求 / 任务 / 方法兼容 ABI；
- 不在 DTO 中建立新的持久格式、线程传输格式或长期“旧当前 + 新当前”双入口。

## 2. 已核实事实与漂移

现有公共类型 `L2节点族身份来源事实` 位于 `海中鱼巣/领域/L2结构公共.数据.h`，含六项结构字段和节点、族锚点、关系类型、归属关系四份 `L2生命周期`。其 `L2节点族身份来源事实完整(来源, 截止)` 允许生命周期在该截止前退出；因此它可证明历史投影完整，却不能单独证明“此刻仍当前”。

七个现有 `读取*身份来源` 入口把当前和历史混在 `L2读取类别` + `历史截止事实代次` 中，并在两个类别都回传共同完整 DTO。现行 `4230` 仍把该形状视为共同读取合同；0050 要求字段语义、公开 DTO 和一致性边界的变化先由具名正式合同裁决、明确迁移或拒绝，不能由代码静默改写。故确认的目标 ABI 与现行 0050 / 4030 / 4230 / 4240 / 0300 / 规范目录之间存在真实漂移，而非普通实现缺口。

P03 已经使 L1 owner 及其生命周期退出公开共同 DTO；服务内部 owner 校验仍保留。P04.2 不能借此把其余四项来源生命周期误删或把内部 owner 重新公开。

## 3. 目标公共类型与物理位置

仅在正式同步后，新增以下公共瘦类型；不修改现有共同见证类型。物理位置固定为 `海中鱼巣/领域/L2结构公共.数据.h`：

```cpp
inline bool L2节点族属于世界七族(L2节点族 节点族) noexcept;

struct L2世界七族结构身份 final {
    L2节点族 节点族;
    稳定编码 节点稳定编码;
    稳定编码 族锚点稳定编码;
    稳定编码 族归属关系类型稳定编码;
    稳定编码 族归属关系稳定编码;
    std::int64_t 角色或顺序 = 0;
};

inline bool L2世界七族结构身份完整(
    const L2世界七族结构身份& 身份) noexcept;
```

`L2节点族属于世界七族` 只接受场景、存在、特征定义、特征实例、状态、动态、因果；它不把语言、词条、概念、不可变材料或 ARCH-L4 兼容族纳入。

`L2世界七族结构身份完整` 只校验该六字段的纯结构形状、有效稳定编码、节点族范围、互异约束和该族既有角色 / 顺序约束。它没有生命周期字段，不能、也不得伪造“未退出”证明。`L2节点族身份来源事实完整` 继续只服务各族适用的完整历史见证及其明确专属路径，不能被改名为该新谓词，也不要求所有退出结果使用它。

## 4. 七个新的当前读取合同

每个族在自己的 `L2*结构.数据.h` 中新增强类型请求 / 结果；请求严格只有 `L2结构请求头 + 本族身份`，没有 `L2读取类别`、没有历史截止。结果严格只有 `L2结构结果头 + optional<L2世界七族结构身份>`，不含四份生命周期。

| 族 | 请求 / 结果类型 | 服务公开函数 |
| --- | --- | --- |
| 场景 | `L2场景当前结构身份读取请求` / `L2场景当前结构身份读取结果` | `L2场景结构服务::读取当前场景结构身份` |
| 存在 | `L2存在当前结构身份读取请求` / `L2存在当前结构身份读取结果` | `L2存在结构服务::读取当前存在结构身份` |
| 特征定义 | `L2特征定义当前结构身份读取请求` / `L2特征定义当前结构身份读取结果` | `L2特征结构服务::读取当前特征定义结构身份` |
| 特征实例 | `L2特征实例当前结构身份读取请求` / `L2特征实例当前结构身份读取结果` | `L2特征结构服务::读取当前特征实例结构身份` |
| 状态 | `L2状态当前结构身份读取请求` / `L2状态当前结构身份读取结果` | `L2状态结构服务::读取当前状态结构身份` |
| 动态 | `L2动态当前结构身份读取请求` / `L2动态当前结构身份读取结果` | `L2动态结构服务::读取当前动态结构身份` |
| 因果 | `L2因果当前结构身份读取请求` / `L2因果当前结构身份读取结果` | `L2因果结构服务::读取当前因果结构身份` |

新请求的 `请求头.合同版本` 必须匹配目标合同，`请求头.期望事实代次` 必须为非零 `G0`。成功时结果头必须是 `已读取`、合同版本正确、`变更事实代次` 为空、`事实截止代次 != 0`，且结果截止精确等于该请求 `G0`。结果中的 `节点族` 必须等于函数所属族；六字段必须完整。

结果对象自身的 `成功()` 只可验证它能表达的局部事实：正确状态头、非零 G0、无变化代次、payload 存在、所属族相等和 `L2世界七族结构身份完整`。它不能从瘦 DTO 推断生命周期未退出。请求 G0 与结果 G0 的相等、以及四项来源均当前，是 provider 的服务合同和调用级验证条件，而不是向结果塞回四份生命周期或伪造纯值谓词的理由。

## 5. 当前成功的同 G0 provider 证明

七个 provider 必须在一次 owner-aware、一致的当前投影内取得并验证同一 `G0`。成功蕴含以下全部事实，而不只是“目标节点未退出”：

1. 目标节点、族锚点、归属关系类型、归属关系都属于正确内部结构范围，创建边界适用于 G0，且在 G0 均未退出；内部 owner 同样必须当前，但不回传到 DTO。
2. 目标节点的稳定编码、锚点、类型与关系编码与该族定位一致；关系源 / 目标方向符合本族定义。
3. 归属关系在 G0 恰有一条；角色 / 顺序与实际关系一致，并满足该族的基数 / 角色合同。
4. 返回六字段逐一来自这一次投影；不得从不同代次拼接，禁止按最大代次、空退出集合扫描或结果字段反向猜测当前性。
5. 读取不写入、不补偿、不重试造成公开变化；G0 漂移由结构化失败表达。

该证明是七族新的当前 API 的唯一权威。各族适用的历史见证或专属退出路径可以看到某项曾经退出，但不能反向使当前 API 接受退出项；这不把共同见证升级为所有退出结果的统一形状。同样，瘦结果的字段形状正确不能替代 provider 的当前证明。

## 6. 非成功状态与空载荷形状

所有非成功结果都必须令 `当前结构身份 == nullopt`、`变更事实代次 == nullopt`，不得泄露半个六字段 DTO，也不得写入事实。除入口拒绝外，若 provider 已在同一读投影得到 G0，结果头可回显该 G0；零 payload 不等于机械把已取得的工程截止清零。正式 4230 同步必须冻结每个既有 L1 读取失败到此头字段的精确映射。

| 情形 | 目标状态 | 空载荷 / 截止要求 |
| --- | --- | --- |
| 合同错误、零 G0、无效本族身份、调用方 / 返回族不匹配 | `入口拒绝` | 空 payload、零截止、零 L1 读取、零公开变化 |
| 在同一 G0 找不到目标节点 | `未找到` | 空 payload；只可回显已实际取得的 G0 |
| 目标节点在 G0 已退出 | `已退出` | 空 payload；不以旧见证降格为当前成功 |
| 锚点、关系类型、内部 owner 或归属关系缺失、退出、归属不符 | `内部不一致` | 空 payload；不能把基础结构破坏伪装成“目标已退出” |
| 归属关系零条 / 多条、方向或角色 / 顺序矛盾 | `内部不一致` | 空 payload；重复关系不是多成功结果 |
| 当前投影无法满足请求 G0 | `事实代次漂移` | 空 payload、零变化；不得偷偷改用最新 Gread |
| L1 / 内部资源、异常或未知读状态 | 现行结构化映射（资源失败 / 内部不一致等） | 空 payload、零变化 |

“wrong family = 入口拒绝”只适用于请求 / 返回的族合同不匹配；provider 自身读到基础定位错族、错误 owner 或关系错配属于 `内部不一致`。这一分界避免调用者错误和提供者结构损坏混账。

## 7. 旧共同入口的退役与历史见证

在将来的一份单一迁移计划内，七个旧 `读取{族}身份来源` 当前分支必须被完整退役，不能保留转发、别名或兼容开关作为第二个当前公开面。目标形状为：

```text
读取当前{族}结构身份
  = 唯一公开当前入口

读取{族}身份来源见证
  = 仅该族已有或未来经正式明确的历史见证、专属退出 / 恢复 / 审计入口
  + 强类型本族身份
  + 非零 H
  + 在该路径确有需要时返回完整共同身份来源见证
  + H == 结果头.事实截止代次
```

历史见证请求不再以 `L2读取类别::当前` / `历史` 复用一条入口；它只接受非零 H。仅适用的历史见证或专属退出 / 恢复 / 审计结果可使用完整 `L2节点族身份来源事实`，四份生命周期保持原意；普通退出结果不因此被要求统一携带该 DTO。场景、存在、特征定义、特征实例既有同截止成功谓词继续保持；状态、动态、因果先由 P04.1.1 收紧后，才可进入本项的重命名 / 分流。

退出不在七族间统一。各族历史见证、退出读回、引用保护和恢复路径保留其已定义的专属条件；本项只禁止把退出事实伪装成当前身份。状态 / 动态的墓碑、TTL、清理顺序、当前选择、legacy 和旧双 owner 路径明确留给 P08，不能随瘦 DTO 迁移夹带修改。

旧格式也不由此 DTO 建立新的解码、消息或持久化格式。仓内已核实共同 DTO 未进入 DATA-L1 持久恢复、4070 输入、线程传输或入口序列化；将来旧格式恢复 / 拒绝矩阵只能由 DATA-L1 / 4070 的合法恢复边界承担，不能以保留第二当前入口代替。该事实不证明仓外不存在源码消费者，故公开旧符号的退出仍须在单一迁移计划中列全已知消费者并明确拒绝策略。

## 8. 场景树、聚合和非七族隔离

## 11. 后续验证合同与完成边界

未来实现验证至少要证明：

1. 每个新当前入口在同一请求 G0 只在四项来源均当前、关系唯一且方向 / 角色正确时成功；任何一项退出或失配均空载荷失败。
2. 成功结果结构完整、结果 G0 等于请求 G0；瘦 DTO 不含生命周期或内部 owner。
3. 旧当前分支不可达 / 被拒绝且零 L1 读取；适用的显式历史见证只接受非零 H，在该族正式规定的路径返回完整见证，并满足 `H == 结果截止`；普通退出结果不被强制统一为该形状。
4. 完整当前 / 历史调用白名单已逐项分流，尤其是状态动态原子发布的首次 G0 当前与非首次 H 重放分支，以及需求服务的四项当前证明依赖。
5. 场景树、语言 / 概念、ARCH-L4、P08、L1 / 4070 和异主 WIP 未被越权改变。

本设计完成只证明 P04.2-A 的口径、目标 ABI、边界和未来门禁已明确记录。它不证明正式规范已同步、P04.1.1 已发布、任何代码已修改、任何消费者已迁移、恢复已验证，或 DATA-L2 已 `FROZEN`。
