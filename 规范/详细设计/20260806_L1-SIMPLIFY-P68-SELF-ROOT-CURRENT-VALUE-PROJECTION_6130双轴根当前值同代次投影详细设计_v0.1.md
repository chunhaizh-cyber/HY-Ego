## 1. S0、能力矩阵与最早缺口

正式 HEAD 的 P67 只冻结双轴根发布编排：P66 恰一次，且仅成功时把其中的 P40 请求
原样委托 P40 恰一次。P40 的提交证据证明出生批次原子发布，不证明任意后继代次的槽和值
仍为当前。

P1—P67 能力按本叶需要收束如下：

| 计划链 | 已冻结责任 | P68 裁决 |
| --- | --- | --- |
| P1—P16 | L1、定义、存在、特征基础写读与事务 | 不复制；只通过正式上游结果传递 |
| P17—P26 | 同截止世界范围、槽、定义和当前 I64 值 | P26 是当前值完整投影的唯一输入 |
| P27—P52 | 状态动态、完整世界和世界树九能力 | 本叶不需要状态动态或完整世界门面 |
| P53—P56 | 自我登记、发布和唯一完整自我读取 | P56 成功事实是唯一自我范围见证 |
| P57—P62 | 完整自我创建、发布和初始化入口 | 只通过 P56 当前读取结果传递 |
| P63—P65 | 双轴根定义规格、写集和原子发布 | P65 成功事实提供安全、服务定义身份 |
| P66—P67 | A=1/V=0 出生规格和 P40 发布编排 | 出生值只作历史发布证据，不作当前值 |

候选裁决：

| 候选 | 结论 | 理由 |
| --- | --- | --- |
| 直接使用 P67/P40 成功结果 | 否 | 只能证明发布时批次，不能证明后继当前性 |
| 直接新增生产协调读取服务 | 否 | 会同时冻结 provider 顺序、短路、重试和投影两层责任 |
| 调用 P29 完整世界快照后筛选 | 否 | 会把状态、动态及其登记错误地升级为根值读取前置 |
| 复制 P56 内部 P19/P21/P17 材料 | 否 | P56 不公开中间副本，调用方不得伪造 P21 范围 |
| P56、P65、P26 成功事实的纯值同代次投影 | **最早缺口** | 只闭合双轴筛选和同截止完整性 |

因此 P68 采用与 P28 先组合、P29 后协调相同的分层：本叶先冻结无对象状态的纯值投影；
后继独立叶再协调 P56、P19、P21、P17、P24—P26 和本函数。这样不建立第二世界快照，
也不让调用方从 P26 全世界集合中自行解释哪两个槽是双轴根。

## 2. 目标与最大边界

新增唯一公开纯值函数：

```cpp
自我双轴根当前值投影结果 组合同代次自我双轴根当前值(
    const 自我双轴根当前值投影请求& 请求,
    const 完整自我结构事实& 当前自我,
    const 自我双轴根定义发布事实& 根定义,
    const 当前实际存在I64实例特征值集合事实& 当前特征值);
```

固定流程：

```text
校验请求版本与三份成功事实形状
-> 校准P56与P26根、唯一自我和非零共同截止
-> 从P65事实取得互异的安全/服务通用定义身份
-> 在P26自我主体组中精确筛选两个定义
-> 逐字段互证主体、槽、定义、当前值、来源和值域
-> 形成A、V、两个完整特征见证和共同截止
-> 只由A派生终止/休眠/主动运行控制态
```

本叶零 provider 调用、零锁、许可、等待、重试和缓存，零 P15/P17/P19/P21/P22/P24—P26
服务调用，零 L1 解析或事实写入。它不协调生产读取，不读取 P67/P40 出生值，不形成根需求、
维护身份、合同、进展、时间游标、状态、动态、因果、结算、装配、恢复或正式验收。

## 5. 输入合同与同代次门禁

请求合同或投影规则错误返回入口拒绝，不遍历任何输入容器。

三份输入只允许由上游成功结果拆出的完整事实：

- P56 必须 `完整=true`，五身份五关系和自我资格形状符合冻结合同，根和自我非零；
- P65 必须有非零发布代次、完整登记和安全/服务两个发布事实，两个通用定义非零互异；
- P26 必须 `完整=true`，规则、排序、定义详情、主体组和事实截止符合冻结合同；
- P56 与 P26 世界根必须相等，事实截止必须非零且完全相等；
- P65 发布代次不得晚于共同截止，两个通用定义在 P26 定义详情中必须逐字段一致。

P56/P26 截止不等返回事实代次漂移、空事实。声称成功但根、自我、排序、完整性、定义身份
或生命周期矛盾返回内部不一致。上游非成功没有合法事实参数，后继协调者必须先短路，
不得调用本函数；本函数不复制上游状态枚举。

## 6. 唯一双轴抽取算法

先在 P26 主体特征组中按稳定编码查找 `P56.自我存在`：

1. 未命中返回当前值缺失；多项、主体资格或成员见证与 P56 矛盾返回内部不一致；
2. 其它主体合法存在但不参与本结果，不扫描其值补足自我；
3. 在唯一自我组中按定义身份筛选 P65 安全和服务两个通用定义；
4. 任一根为零项返回当前值缺失；同一根多项、一个槽同时冒充两定义或第三定义冒充根，
   返回内部不一致；
5. 每项的宿主必须等于自我，定义必须等于对应 P65 通用定义，槽、两关系和值编码非零；
6. 当前值材料形状必须是 I64，数值只取项目的 `当前值.I64值`；来源节点沿 P26 原样保留；
7. 两值都必须满足 `0..I64_MAX`，不得把负数、哨兵、缺失或溢出裁剪为边界值。

成功后逐字段复制两个 `当前完整I64实例特征项`，不重建第二套槽/值见证。数值投影固定为：

```text
A = 生存安全.完整特征.当前值.I64材料
V = 服务.完整特征.当前值.I64材料
A == 0 -> 终止
A == 1 -> 休眠
A > 1  -> 主动运行
```

控制态只由同次 A 机械派生，不读取线程、任务、合同、日志或 P67 出生值。V 不直接改变控制态；
V 对 A 的后续维护只能由 6170 正式事务形成新当前值。

## 7. 状态、异常、并发与生命周期

| 条件 | 状态 | 事实 |
| --- | --- | --- |
| 请求版本错误 | 入口拒绝 | 空 |
| P56/P26 非零截止不同 | 事实代次漂移 | 空 |
| 自我或某一根当前项合法缺失 | 当前值缺失 | 空 |
| 坏成功、重复根、错宿主、错定义或坏值域 | 内部不一致 | 空 |
| 分配失败 | 资源失败 | 空 |
| 两根唯一完整且同截止 | 已形成 | 完整双轴事实 |

函数不 `noexcept`；捕获 `std::bad_alloc` 为资源失败，其它未分类异常为内部不一致。输入和
临时引用都属于同步调用栈。相同值输入并发调用必须逐字段相等，不依赖地址、容器原顺序、
显示名、线程或时间。返回事实永久只代表其非零截止；后继事实推进不修改旧副本。
