## 1. 目标与完成边界

本叶把语义归属 L2 存在领域的 `L1实际存在服务::建立登记` 从 legacy L1 合同迁移到业务中性的 `L1中性写集请求`，并在真实 `生产运行期会话::启动` 中，于初始场景成功之后、旧系统角色初始化之前恰一次调用。存在服务自行拥有实际存在资格的业务含义、登记准入、幂等域、两节点写集形状、状态解释和登记投影；L1 只原子发布一个普通服务身份节点和一个 I64 属性类型节点，分配稳定编码并提供精确当前读。

生产调用只有同时取得 `实际存在登记结果` 成功状态、完整登记和后续公开权威读回时才可继续。代码发布后的独立消费者验收只累计本消费者实际覆盖的两节点新增、查询和同一写集原子性；不为补覆盖表注入重复、非法、并发、恢复或其它非业务调用。

本叶不在场景中创建实际存在，不创建资格值或场景归属关系，不迁移 `L1实际存在场景组合服务`，不建立特征、状态或动态，不执行修改或退出，不建立 L1 自检、专用 L1 驱动、第二程序、日志 PASS 或独立 L1 结论；不考虑崩溃、重启、断电和跨进程恢复。

## 3. 所有权、合同与物理位置

### 3.1 责任

```text
实际存在资格含义、登记准入、幂等域、两节点形状、登记投影和状态：L2 存在服务
节点、稳定编码、事实代次、原子提交和最小幂等：L1 事实基座
```

类名中的历史前缀 `L1` 不赋予存在服务 L1 语义；它仍是实际存在资格的 L2 事实所有者。本叶不做跨仓重命名，以免牵动实际存在场景组合、实例特征和状态消费者。

### 3.2 实际存在合同 v2

`L1实际存在合同版本` 从 1 升为 2，`L1实际存在规则版本` 保持 1；现有 DTO 字段和 `实际存在状态` 枚举稳定值不重排。新增纯值判断：

```cpp
bool 实际存在登记请求有效(const 实际存在登记请求&) noexcept;
bool 实际存在登记结果::成功() const noexcept;
```

登记请求必须是合同 2、规则 1、非零且不越过 56 位的幂等身份、非零期望事实代次。`实际存在登记结果::成功()` 只接受 `已提交 / 幂等读回 / 已读取` 且登记存在并通过 `实际存在结构登记完整`。

`实际存在结构登记::事实截止代次` 表示本次权威读取的当前事实截止，不再永久等同于登记节点的创建代次。缓存中的首次幂等身份和两个稳定编码只作定位；读取结果用本次首末一致的当前事实代次覆盖返回副本的截止。合同升版同步作用于现有存在 DTO 的合同字段，但本叶不改变创建存在、读取资格或场景接纳的业务语义。

## 4. 两节点中性写集

最终技术幂等键保持既有领域隔离：

```text
实际存在登记中性幂等域 = 0x0A
最终键 = (0x0AULL << 56) | 请求.幂等身份.值
```

`建立登记` 在自身锁内验证请求后直接形成：

| 本地键/项目 | 中性字段 |
| --- | --- |
| 1 节点 | `普通`；实际存在服务身份 |
| 2 节点 | `属性类型`；表示种类=`I64`；实际存在资格属性类型 |
| 关系、值、属性槽、退出 | 全部为空 |

请求只含中性合同 1、调用方期望事实代次、最终幂等键和上述节点组。不得调用 `探测幂等`、`读取完整快照`、legacy `提交写集`、审计、恢复、SQL 或旧仓；不得形成业务操作标签、G6 意图、摘要、执行证据、提供者见证、领域结果见证或发布后读回计划。`提交中性写集` 恰一次。

成功类结果必须满足合同 1、回显最终键、事实代次非零、两项本地键/稳定编码映射各自唯一且编码互不相同。`成功` 必须形成内存权威发布且重试边界为不适用；`精确重复` 必须不形成新发布且重试边界为原幂等键读回收敛。坏成功一律映射内部不一致，不缓存定位。

写入状态映射：成功→已提交，精确重复→幂等读回，入口拒绝→入口拒绝，事实代次漂移→版本漂移，幂等冲突→幂等冲突，资源失败→资源失败；未找到、已退出和内部不一致在纯新建两节点写集下均为内部不一致。

## 5. 权威读回与定位缓存

从成功映射形成 `实际存在结构登记` 定位。私有读回固定：

```text
L1 读取中性当前事实代次（起始）
-> 精确读取实际存在服务身份节点
-> 精确读取实际存在资格属性类型节点
-> L1 读取中性当前事实代次（结束）
-> 首末及两项读取代次相等
-> 逐字段验证节点种类、属性类型表示、创建代次和当前性
-> 返回当前截止下的完整实际存在结构登记
```

两个节点必须编码有效且互不相同、均未退出、创建代次同一且非零、不晚于本次截止；普通服务身份不得携带属性类型表示，I64 属性类型节点必须携带唯一正确表示，两个节点当前属性均为空。创建路径另要求共同创建代次等于中性写入结果事实代次。读回允许后续无关写使当前截止大于登记创建代次。

服务用既有锁保护 `std::optional<实际存在结构登记> 登记定位_`，其中首次幂等身份和两个稳定编码只作定位。只有首次创建成功且权威读回完整时写入；重复创建形成的定位必须与既有定位的首次幂等身份和两个编码全等，否则内部不一致。删除 `首次登记请求_`，不得缓存节点事实或从缓存直返成功。

`读取当前登记()` 无参数公开签名保持不变：未加载定位返回未找到；已加载时调用同一私有精确读回并返回已读取。资源失败→资源失败，首末或逐项代次不等→版本漂移，编码未找到、已退出、种类或字段矛盾→内部不一致；所有非成功均无部分登记。

现有 `形成实际存在写入规格` 与 `读取实际存在资格` 保留。它们继续以登记定位调用正式事实入口，不取得本叶两节点的第二所有权；后续实际存在创建消费者迁移时再收敛其 legacy 读取和写入链。
