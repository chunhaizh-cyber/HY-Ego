# DATA-L2-SCENE-STATE-USE-BINDING-ABI-SKELETON 场景状态使用绑定ABI骨架详细设计

日期：20260909
版本：v0.3
状态：ABI骨架可实施详细设计

## 1. 执行期问题与裁决

v0.2要求当前 `数据服务.存在类.ixx` 继承并实现 `存在结构身份只读提供者` 的两个未实现入口，同时要求存在、合同和场景模块形成Debug/Release IFC/OBJ。执行S0确认存在类仍调用状态v1入口 `状态类数据服务::查询状态`；4212又明确存在消费者迁移不属于状态本体切片，必须按后继正式合同另行重扫。即使为当前空动态模块建立仓库外替身，存在模块仍不能在不迁移该旧消费者的情况下形成目标产物。

裁决为从本ABI骨架片移除存在类。4203已经冻结最终抽象 `存在结构身份只读提供者`，场景骨架只需保存 `const 存在结构身份只读提供者&`，无需本轮出现具体生产实现。后继合法存在族身份生产切片在4230当前/历史身份合同闭合后实现该接口。本修订不改变4203 DTO、枚举、函数签名、owner、事务、状态或动态模型。

## 2. 目标和完成条件

依据4201、4203 v0.3、4212和4230，发布C/E/S完整使用绑定的最终ABI与显式未实现场景骨架。完成条件仅为：

1. 合同模块导出精确DTO、守卫和两个最终抽象窄接口；
2. 场景模块按最终构造和公开函数形状持有抽象存在provider引用并实现状态使用绑定只读接口；
3. 所有场景骨架业务入口稳定返回 `未实现`、合同版本1、零代次、无变更、空载荷，且不访问L1、写端口、状态服务或任一provider；
4. 合同模块和场景模块分别在隔离Debug/Release配置形成IFC和OBJ；
5. 生产存在类零修改、零编译门禁，场景模块import闭包不包含完整存在类或动态类。

本片不创建、读取、退出或恢复B事实，不交付具体存在provider，不解除真实绑定或动态实现门禁。

## 3. 当前事实与复用裁决

- `数据服务.状态类.ixx` 已形成状态v2四字段和读取接口；本片只在最终构造类型中持有其引用，不调用、不修改。
- `数据服务.存在类.ixx` 是含状态v1消费者的异主旧实现；本片不import、不修改、不编译它，也不要求它继承窄接口。
- `合同.场景状态使用绑定.ixx` 当前候选已按4203 v0.2形成最终DTO、守卫和两个抽象接口，可在v0.3中按同一ABI继续使用。
- `数据服务.场景类.ixx` 当前执行候选仅包含绑定骨架；本片保留这一窄形状，不恢复完整场景旧实现。
- L1真实数据能力只供后继真实实现复用；本片骨架不得调用。

## 4. 生产文件与依赖方向

| 文件 | 变化 | 责任 |
| --- | --- | --- |
| `海中鱼巣/领域/合同.场景状态使用绑定.ixx` | 新增 | 最终DTO、守卫、两个抽象窄接口 |
| `海中鱼巣/领域/数据服务.场景类.ixx` | 重建本片范围 | 最终构造、B操作签名、状态使用绑定只读接口和显式未实现结果 |
| `海中鱼巣.vcxproj` / `.filters` | 最小登记 | 登记合同模块及依赖顺序 |

生产依赖固定为：

```text
状态类 ───────────────┐
                     v
绑定合同（抽象存在provider、抽象绑定provider） <- 场景类骨架
                     ^
后继合法存在身份生产 ─┘  （本片不实现）

后继动态类 -> 绑定合同中的绑定只读provider
```

场景类不得import完整存在类或动态类。抽象接口不需要具体派生类即可编译；如专项消费者需要实例化场景骨架，只能在专属 `D:/TEMP` 验证目录定义返回 `未实现` 的假provider，禁止把它加入生产源码或工程。

## 5. 骨架行为

合同模块严格实现4203第3.2节全部类型、枚举数值、守卫和成功谓词。场景类构造接收L1、场景owner写端口、结构交付、抽象存在provider和状态类服务；除 `绑定于` 只比较既有L1对象地址外，创建、当前读、历史读、按C/E/S反查和退出均直接返回：

```text
状态 = 未实现
合同版本 = 1
事实截止代次 = 0
变更事实代次 = 空
optional/vector载荷 = 空
成功() = false
```

骨架不得校验请求，不得解引用存在provider或状态服务，不得访问L1、写端口、幂等账、索引、时钟或日志。它不进入真实失败优先级，也不实现4203第4—5节任何事实流程。

## 6. 排除项与后继

明确排除：修改或编译存在类、迁移 `查询状态` 等状态v1消费者、具体存在provider、合法C/E身份生产、真实B写读退、恢复、P、状态字段变化、完整场景七字段、场景树、动态组织、动作来源、动态/动态概念/因果、普通应用装配、L1修改和旧散装迁移。

后继真实绑定提供者必须等待场景C与存在E合法族身份生产及4230当前/历史确认分别发布，再在同一最终ABI内替换未实现分支。存在provider的生产实现由该合法存在身份后继交付，不从本骨架计划恢复存在类修改。

- 对合同模块和场景模块分别在仓库外隔离Debug/Release配置形成IFC和OBJ；存在类不是目标、依赖或验证输入。

合法首次/重复、B写读退、反查、恢复、具体存在provider和动态消费全部记录为 `NOT_IMPLEMENTED/NOT_RUN`。编译通过不证明真实绑定、运行装配或业务闭环。
