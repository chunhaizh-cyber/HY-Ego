根资格。当前根准入仍必须先于任何方法登记根 P15 提交。

## 2. 唯一目标与最大边界

在唯一 L1 事实基座原位新增非阻塞纯值入口：

```cpp
L1已发布领域意图结果组读取结果 L1事实基座服务::尝试读取已发布领域意图结果组(
    const L1已发布领域意图结果组读取请求& 请求) const;
```

它只在一次 try-lock 共享许可内，按请求意图组、格式版本和操作标签筛选全部已成功发布的幂等
账记录，在请求期望事实截止上返回稳定排序的完整首次结果副本。空组是合法成功，不是未找到。

本叶不解释方法根，不形成零/一/多根结论，不调用 R1—R5，不探测某个请求键，不形成执行
证据，不提交写集，不分配稳定编码，不持有事务或把幂等账升级成业务当前事实。方法根、方法首、
规格、动作入口、需求、任务、服务候选、安全和因果写入均为0。

当前只覆盖同一生产进程正常存活期间的内存权威账读取；不设计崩溃、异常终止、断电、重启、
恢复导出或跨进程重放。正式日志只用于人读观察，不是结果组或当前事实来源。

## 4. DTO、签名与生命周期

在唯一 L1 数据合同追加：

```cpp
struct L1已发布领域意图结果组读取请求 final {
    std::uint32_t 合同版本 = L1事实基座合同版本;
    std::uint8_t 请求意图组 = 0;
    std::uint32_t 请求意图格式版本 = L1请求意图格式版本;
    std::uint32_t 请求意图操作标签 = 0;
    std::uint64_t 期望事实截止代次 = 0;
    friend bool operator==(const L1已发布领域意图结果组读取请求&,
        const L1已发布领域意图结果组读取请求&) = default;
};

struct L1已发布领域意图首次结果副本 final {
    写集幂等键 幂等键;
    L1领域意图凭证 领域意图凭证;
    std::uint64_t 首次发布事实代次 = 0;
    L1写集请求 首次规范化写集;
    std::vector<std::pair<写集本地键, 稳定编码>> 首次新编码映射;
    L1通用发布后读回结果 首次完整读回;
    L1确定性摘要 确定性结果摘要;
    friend bool operator==(const L1已发布领域意图首次结果副本&,
        const L1已发布领域意图首次结果副本&) = default;
};

struct L1已发布领域意图结果组读取结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    std::uint64_t 事实截止代次 = 0;
    std::vector<L1已发布领域意图首次结果副本> 结果组;
    friend bool operator==(const L1已发布领域意图结果组读取结果&,
        const L1已发布领域意图结果组读取结果&) = default;

```

不增加第二状态枚举；复用 P17 已冻结的 `L1读取状态`。请求/结果均由调用方按值拥有；仓库许可
在函数返回前释放，副本不携带锁、仓库引用、事务令牌、恢复能力或可变账对象。

入口前置固定为：合同版本等于实际 L1 v2；请求意图组非0且不超过实际公共上限；格式版本精确
等于 `L1请求意图格式版本`；操作标签和期望事实截止代次均非0。失败返回入口拒绝、代次0、空组，
仓库调用0。R6 不把 G10 或方法标签硬编码进 L1；它们由后继请求传入并由 R3/R4 强类型合同约束。

## 5. 唯一读取算法与状态分账

仓库同名函数固定执行：

1. 只尝试一次 `std::shared_lock<std::shared_mutex>{锁_, std::try_to_lock}`；竞争立即返回许可拒绝；
2. 已隔离或全局状态不完整返回内部不一致，不返回部分记录；
3. 当前事实代次不等于请求期望截止返回事实代次漂移、实际安全取得的当前代次和空组；
4. 在许可内遍历唯一幂等账；每项必须满足现有 `幂等记录完整`，坏项使整次读取内部不一致；
5. 只选择首次规范化写集领域意图凭证的组、格式和操作标签与请求逐字段相等的成功记录；
6. 从账记录深复制本 DTO 的七项字段；任何副本与原账幂等键、凭证、发布代次、映射、读回或
   确定性结果摘要不等，返回内部不一致；
7. 按 `首次发布事实代次` 升序、再按 `幂等键.值` 升序稳定排序；重复键、零发布代次、发布代次
   晚于共同截止或同代次多记录均为内部不一致；
8. 返回成功、请求期望截止和完整结果组；零项仍为成功空组。

| 条件 | 状态 | 事实截止 | 结果组 |
| --- | --- | ---: | --- |
| 请求非法 | 入口拒绝 | 0 | 空 |
| 共享许可竞争 | 许可拒绝 | 0 | 空 |
| 当前代次漂移 | 事实代次漂移 | 实际当前代次 | 空 |
| 隔离、坏账、坏副本或未知异常 | 内部不一致 | 安全取得值或0 | 空 |
| 分配失败 | 资源失败 | 安全取得值或0 | 空 |
| 合法且0项 | 成功 | 期望截止 | 空 |
| 合法且1/N项 | 成功 | 期望截止 | 完整稳定组 |

函数零等待、零 sleep、零重试、零缓存、零写入、零事实代次推进。它不调用审计读取或恢复导出，
也不从审计事件、日志或 SQL 回填缺失账记录。

## 6. 方法根后继消费边界

下一叶必须用固定请求 `G10 + L1请求意图格式版本 + 0x15001101U + R4预期事实截止` 调用本入口
恰一次，并调用 P17 同截止完整快照恰一次。只有两个成功结果截止一致，才可逐项验证：

- 幂等键高8位是否为 R5 `0x19`，低56位是否与 R4 身份一致；
- 首次规范化写集是否精确等于一份合法 R2 `3/0/1/1/0/5` 草案；
- 新编码映射和完整读回是否一一形成 R1 三节点和角色值定位凭证；
- 0项是否可准入首次发布，1项是否是同义已存在，多项或半结构是否内部不一致。

本叶不提前冻结上述方法领域状态 DTO，也不决定同义复用、异义拒绝或发布竞争。后继原子发布者
仍须以同一共同截止提交；若资格读取后发生任意发布，P15 的期望事实代次门必须拒绝旧截止，
不能把一次零项读取当作跨事务锁。
