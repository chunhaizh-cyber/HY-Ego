# L2-SELF-ROOT-NEUTRAL-PRODUCTION-PUBLISH 6130 双轴根定义与实例中性生产发布详细设计 v0.2

日期：2026-08-08
状态：设计冻结，等待独立前置提供者
替代：v0.1

## 1. 修订结论

v0.1 把 `完整自我当前事实.自我所在场景` 机械塞入 `实际存在读取请求.当前场景`，并据此调用现有 `L1实例特征服务`。该假设不成立：现行字段类型是 `初始场景读取请求`，现行实际存在组合读取又固定调用 `读取初始场景实际存在`；完整自我中的自我所在场景直接父端是世界根内部世界场景，不是世界根。

本版禁止放宽初始场景不变量、禁止把自我所在场景伪装成初始场景，也禁止让双轴根服务或实例特征服务临时解释完整自我结构。根计划改为等待一个独立、可复用的“当前实际存在”领域提供者及实例特征强类型入口；提供者真实实现、发布并释放共享文件前，本计划保持 `待激活`。

## 2. 根计划目标保持不变

提供者门禁满足后，唯一 `L1自我双轴根服务` 仍负责：

1. 从完整自我事实形成当前自我的根到场景有序路径；
2. 经正式当前实际存在提供者取得自我宿主事实；
3. 经现行特征定义服务发布安全、服务两个 `0..I64_MAX` 定义；
4. 经实例特征服务的新强类型入口发布当前自我的两个实例，固定 `A=1`、`V=0`；
5. 经相同公开服务正式读回，四项共同截止且逐字段一致后才允许生产候选继续。

本叶仍不形成阈值、维护规则、根需求、状态、动态、因果、恢复或旧系统角色迁移。

## 3. 已核实当前事实

- `实际存在读取请求::当前场景` 的真实类型是 `初始场景读取请求`。
- `L1实际存在场景组合服务::读取实际存在` 固定转发 `初始场景实际存在原子发布服务::读取初始场景实际存在`。
- 该原子发布服务固定调用 `L1场景结构服务::读取初始场景接纳`。
- 初始场景读取要求直接父关系源端等于世界登记世界根。
- `完整自我当前事实` 的路径是 `世界根 -> 世界根内部世界场景 -> 自我所在场景`；自我归属关系是 `自我所在场景 -> 自我存在`。
- 现行实例特征建立与读取均通过初始场景专用实际存在请求验证宿主，当前没有任意已登记场景的替代入口。

因此本问题是公开合同缺口，不是九文件白名单内的局部代码错误。

## 4. 独立前置提供者最终合同

这些文件属于独立提供者计划，不属于本根计划 v0.2 的代码白名单。提供者计划不得修改生产启动顺序或提前发布双轴根。

### 4.2 当前场景路径合同

`L1当前实际存在.数据.h` 最终声明：

```cpp
inline constexpr std::uint32_t L1当前实际存在合同版本 = 1;
inline constexpr std::uint32_t L1当前实际存在规则版本 = 1;

struct 当前场景路径项 final {
    世界结构节点身份见证 场景;
    世界结构值见证 场景标记;
    世界结构关系身份见证 直接父关系;
};

struct 当前实际存在读取请求 final {
    std::uint32_t 合同版本 = L1当前实际存在合同版本;
    std::uint32_t 规则版本 = L1当前实际存在规则版本;
    std::uint64_t 期望事实截止代次 = 0;
    世界结构节点身份见证 世界根;
    std::vector<当前场景路径项> 根到当前场景路径;
    世界结构节点身份见证 存在;
    世界结构值见证 资格;
    世界结构关系身份见证 当前场景归属关系;
};

struct 当前实际存在结果 final {
    实际存在状态 状态 = 实际存在状态::入口拒绝;
    std::optional<实际存在事实> 事实;
    bool 成功() const noexcept;
};
```

请求由调用方拥有；路径按世界根向当前场景排序且不得为空。第一项直接父关系源端必须是世界根，后续项源端必须是前一项场景，最后一项场景必须是当前归属关系源端，归属关系目标端必须是存在。路径节点、存在、资格和全部关系编码必须非零且按身份种类完整，路径场景不得重复。

### 4.3 唯一公开读取根

```cpp
class L1当前实际存在服务 final {
public:
    L1当前实际存在服务(
        const L1事实基座服务& L1,
        const 世界登记服务& 世界登记,
        const L1实际存在服务& 实际存在) noexcept;

    当前实际存在结果 读取当前实际存在(
        const 当前实际存在读取请求& 请求) const;
};
```

公开根必须：

1. 读取世界登记和实际存在资格各一次；
2. 以一次业务中性精确一致当前投影读取世界根、路径全部场景、存在、全部场景标记、全部直接父关系和当前归属关系；
3. 用世界登记中的场景标记属性类型、直接父场景关系类型和直接成员关系类型逐项互证；
4. 要求登记、资格和精确投影共同截止等于请求截止；
5. 成功只返回现行 `实际存在事实`：世界根、存在、当前场景、资格、当前场景归属关系；路径只用于准入，不复制进结果；
6. 不扫描全仓，不读取初始场景完整结构，不调用初始场景接纳，不写 L1，不缓存第二份权威事实。

状态映射固定为：无效请求=`入口拒绝`；任一精确项目不存在=`未找到`；截止不同=`版本漂移`；L1许可拒绝=`许可拒绝`；资源失败=`资源失败`；成功形状、类型、路径、属性、关系或提供者互证矛盾=`内部不一致`；仅全部成立时=`已读取`并携带完整事实。

### 4.4 实例特征强类型入口

`L1实例特征.数据.h` 增加两个请求，字段顺序与现行实际存在入口一致，仅把宿主类型替换为 `当前实际存在读取请求`：

```cpp
struct 当前实际存在I64实例特征建立请求 final {
    std::uint32_t 合同版本 = L1实例特征合同版本;
    std::uint32_t 规则版本 = L1实例特征规则版本;
    特征操作幂等身份 幂等身份;
    std::uint64_t 期望事实代次 = 0;
    当前实际存在读取请求 宿主;
    I64特征定义读取请求 定义;
    std::int64_t 初始值 = 0;
    稳定编码 来源节点;
};

struct 当前实际存在I64实例特征读取请求 final {
    std::uint32_t 合同版本 = L1实例特征合同版本;
    std::uint32_t 规则版本 = L1实例特征规则版本;
    当前实际存在读取请求 宿主;
    I64特征定义读取请求 定义;
    稳定编码 实例槽;
    稳定编码 宿主关系;
    稳定编码 定义关系;
    稳定编码 当前值;
    稳定编码 来源节点;
};
```

`L1实例特征服务` 增加且只增加：

```cpp
I64实例特征结果 建立当前实际存在I64实例特征(
    const 当前实际存在I64实例特征建立请求& 请求) const;

I64实例特征结果 读取当前实际存在I64实例特征(
    const 当前实际存在I64实例特征读取请求& 请求) const;
```

服务构造函数增加唯一 `const L1当前实际存在服务&` 依赖。新旧入口必须先分别取得权威宿主事实，再进入同一私有建立/读取实现；幂等身份账和 `(存在, 定义)` 组合唯一账必须共用，禁止形成第二实例仓、第二编码空间或同宿主双发布者。当前实际存在状态到现行 `实例特征状态` 的映射固定为：`已读取 -> 已读取`、`未找到 -> 未找到`、`版本漂移 -> 事实代次漂移`、`资源失败 -> 资源失败`、`内部不一致 -> 内部不一致`，`入口拒绝`、`许可拒绝`、`已提交`、`幂等读回`、`幂等冲突`及未知值统一映射为 `入口拒绝`。不得新增实例特征状态。

## 5. 根计划消费转换

根服务从 `完整自我当前事实` 形成请求时固定：

```text
世界根 = 完整自我.世界根
期望事实截止代次 = 完整自我.事实截止代次
路径[0] = 世界根内部世界场景 + 其标记 + 世界根内部世界关系
路径[1] = 自我所在场景 + 其标记 + 自我所在场景关系
存在 = 完整自我.自我存在
资格 = 完整自我.自我存在资格
当前场景归属关系 = 完整自我.自我所在场景成员关系
```

生产请求路径长度必须恰为 2；不得使用出生期成员、旧系统角色或初始场景请求替代。安全/服务定义和初值仍分别为 `0..I64_MAX / 1` 与 `0..I64_MAX / 0`，来源节点仍为当前自我存在。

根服务只调用新实例特征建立/读取入口，不直接调用当前实际存在提供者；宿主读取由实例特征事实所有者按强类型请求完成，避免根服务成为第二宿主准入解释者。
