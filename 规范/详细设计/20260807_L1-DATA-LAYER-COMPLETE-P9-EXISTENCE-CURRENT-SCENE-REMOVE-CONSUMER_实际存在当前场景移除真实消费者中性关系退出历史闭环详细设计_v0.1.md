## 1. 目标与完成边界

本叶原位扩展唯一 `L1实际存在场景组合服务`，新增合法第二层公开入口 `移除实际存在当前场景`。它只使请求中实际存在的唯一当前场景归属关系退出，不退出或删除实际存在节点、资格值、资格属性槽、场景、特征、状态、动态及其它事实。

合法第二层消费者先经同一具名服务创建一个非启动锚定的普通实际存在，再调用本入口。入口以一个 L1 业务中性写集完成一条既有关系退出，随后只经正式中性当前关系、历史事实、当前节点、当前值和当前属性入口重新核对：旧关系当前不可读、历史关系完整且携带本次退出代次、实际存在和原场景仍为当前、资格值与资格属性槽保持不变。

本叶不是 L1 自检，也不建立专用验收入口、第二程序、双目标或 PASS 聚合。消费者验收通过后，只累计证明本消费者实际覆盖的一条关系退出、当前不可读、历史可回查、精确重复、同键异义和非法请求零变化；不得由此宣称 L1 自证或整体完善。

本叶不移动实际存在到另一场景，不发布新关系，不删除实际存在，不创建或删除场景，不处理子场景，不迁移旧节点直接世界树骨架，不覆盖关系替换、关系条件集合查询、并发、崩溃、重启、断电或跨进程恢复。

## 4. 请求有效性、幂等与定位

请求有效必须同时满足：

1. 合同和规则版本匹配；幂等身份有效；期望事实代次非零；
2. `当前事实` 自身完整，且其合同、规则与外层相等；
3. `当前事实` 中存在、资格值、归属关系互异；世界根、场景、存在和关系定位非零；
4. 外层期望事实代次是首次移除写前共同截止，不从日志、缓存或请求时间推导。

中性幂等键固定为：

```text
移除键 = (0x1AULL << 56) | 请求.幂等身份.值
```

正式生产幂等域 `0x01—0x19` 已有代码或正式设计所有者；本叶使用创建基线未占用的 `0x1A`。执行 S0 必须从实时 HEAD 再次确认唯一，不能临场换号。

组合服务新增同锁、非权威 `实际存在移除幂等定位`，只保存已经进入本入口且可能形成权威发布的幂等身份，不保存请求、写集、首次结果、关系事实或领域事实：

1. 首次身份先插入暂定定位，再执行全部写前准入；提交未形成成功类结果时删除暂定定位。
2. 成功、精确重复或发布后读回失败时保留定位，使原请求再次经 L1 精确重复收敛。
3. 已定位身份不再要求旧关系仍为当前，直接由本次完整请求形成同一退出写集并提交；L1 唯一裁决精确重复或同键异义。
4. 当前不考虑进程重启。定位不是业务事实，不得宣称恢复；未来非空恢复必须另行设计。

## 5. 首次写前领域准入

只有身份尚未定位时执行：

1. 读取中性当前事实代次作为起始，必须等于请求期望事实代次。
2. 经同一组合服务既有正式入口 `读取实际存在` 读取请求当前事实；必须返回完整当前实际存在，世界根、存在、当前场景、资格值和当前归属关系逐字段等于请求。
3. 再读取中性当前事实代次作为结束；起始、领域事实截止和结束必须等于同一请求期望事实代次。
4. 当前归属关系必须是 `原场景 -> 存在`、角色或顺序为零，且关系类型由 P5/P3 已发布的当前事实证明；不得从旧世界树 DTO 或显示信息补造。

任一非成功在提交前返回并删除暂定定位，权威状态零变化。已定位重复或冲突路径不重新读取已经退出的当前关系，但仍校验请求 DTO 并由 L1 完整写集幂等账裁决。

既有 `L1场景结构服务::读取初始场景接纳` 的失败映射同步收窄：当且仅当成员、场景结构和关系类型读取没有先失败，而请求的精确归属关系返回中性 `已退出` 且不携带当前事实时，返回 `世界结构状态::未找到`。组合服务据此返回 `实际存在状态::未找到`。归属关系未找到、错类型或携带坏事实，以及成员、场景、关系类型任一退出，继续按既有合同返回未找到或内部不一致，不得把结构损坏伪装成合法移除。

## 6. 唯一中性写集与提交

写集只由本次公开请求形成：

| 类别 | 数量 | 固定内容 |
| --- | ---: | --- |
| 节点新建 | 0 | 无 |
| 关系新建 | 0 | 无 |
| 值新建 | 0 | 无 |
| 属性槽变更 | 0 | 无 |
| 退出事实 | 1 | `请求.当前事实.当前场景归属关系` |

函数恰一次调用 `L1事实基座服务::提交中性写集`。成功类结果必须满足合同版本、幂等键、首次发布代次、发布标志、重试边界和零新编码映射完整：首次成功形成一次权威发布，精确重复不形成新发布并回显首次发布代次。

写集不含业务标签、意图、摘要、执行证据、提供者见证、领域结果见证、审计或恢复材料。函数不调用 legacy `提交写集`、`探测幂等`、`读取完整快照`，也不使用旧节点直接场景服务。

## 7. 发布后权威读回

首次和精确重复固定执行同一组读回：

1. 读取中性当前事实代次为读回起始；不得早于首次发布代次。
2. 当前关系入口按旧归属稳定编码读取，必须返回 `已退出`、不带当前事实、读取代次为零。
3. 历史入口按同一编码读取，必须返回完整关系事实；编码、源端、目标端、关系类型和角色逐字段等于请求写前关系，创建代次不晚于请求期望代次，退出代次等于首次发布代次。
4. 中性当前节点入口分别读取存在和原场景，两者必须仍为未退出普通节点。
5. 中性当前值入口读取资格值，必须仍为未退出 I64 值，所属节点等于存在，材料等于资格常量，来源与请求写前资格一致。
6. 中性当前属性入口读取存在的资格属性类型，必须仍指向同一资格值。
7. 经既有正式组合读取入口重新读取同一实际存在定位，必须稳定返回 `未找到` 且不携带当前实际存在事实。
8. 再读取中性当前事实代次；起始、存在、场景、资格、属性和结束必须是同一非零截止。

由历史关系、当前存在、当前场景和当前资格组装 `实际存在当前场景移除事实`。任何读回失败或字段矛盾都返回对应结构化非成功，不用缓存、日志或首次请求补成成功。

## 8. 非成功与零变化

| 场景 | 结构化结果 | 权威状态要求 |
| --- | --- | --- |
| 版本、身份、期望代次或当前定位无效 | 入口拒绝 | 零变化 |
| 首次写前实际存在已移动、已移除或字段不一致 | 未找到、版本漂移或内部不一致 | 零变化 |
| 首次提交前事实代次变化 | 版本漂移 | 零变化 |
| 同一幂等键携带不同完整退出写集 | 幂等冲突 | 保持首次结果，不产生第二退出 |
| 精确重复 | 幂等读回 | 旧关系仍退出，历史仍为首次记录 |
| 资源失败或内部不一致 | 对应状态 | 不返回部分事实，不补写 |

外部合法消费者验收必须在每个非成功调用前后经正式领域读取或本入口规定的公开终态读取比较适用权威状态。生产服务不形成 PASS 状态，不解析日志。
