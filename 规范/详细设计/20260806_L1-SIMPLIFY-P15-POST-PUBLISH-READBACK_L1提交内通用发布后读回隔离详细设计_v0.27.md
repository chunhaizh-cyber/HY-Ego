## 1. 唯一裁决

正式模块事实是：`核心/合同.L1可重建索引.ixx`只导出 `L1可重建索引.数据.h` 的 DTO；`L1事实可重建索引` 类声明及其成员定义均位于 `核心/索引.L1事实基座.ixx`。C++ 不允许在合同模块为另一个模块中已经定义的类补成员声明。

本版本采用最小、无 ABI 扩张的方案：保持现有模块结构，不迁移类、不引入 PIMPL、不改为合同自由函数或新独立接口。

- DTO：`核心/L1可重建索引.数据.h`，由 `核心/合同.L1可重建索引.ixx` 导出；该合同模块只承载 DTO/常量，不承载 `L1事实可重建索引` 类声明。
- 类声明与成员实现：同归 `核心/索引.L1事实基座.ixx` 的导出模块接口；消费者通过导入该索引模块使用类。
- P-I 函数保持 `L1事实可重建索引::读取提供者身份() const noexcept`，稳定身份 `0x4C31495800000001`，合同/规则版本 `1/1`。
- 类实例构造后持有非拥有的 `L1事实基座服务&`，至实例销毁前有效；不可复制，不新增堆/PIMPL 状态，不改变既有 ABI 形态或生命周期。

v0.26 的 RP/G6/RW/v1/v2 字节合同、E01 node-only 结果计划、三副本原子交换、失败/恢复矩阵、调用计数、24 项代码路径 + 2 条专属记录全部保持。v0.27 只裁决 P-I 的模块归属与验证门禁。

## 3. P-I 所有权、生命周期与既有摘要合同

P-I 不并入 L1 provider。DTO 仍为 `{稳定身份(U64), 合同版本(U32), 规则版本(U32)}`，由合同模块公开；类的公开声明和实现仅在索引模块。`读取提供者身份()` 为纯只读、`const noexcept`，不读事实、不分配身份、不改变代次，返回固定身份/版本值。类构造函数接收既有 `L1事实基座服务&` 非拥有引用，类实例不跨模块复制，构造后至销毁保持引用有效。

消费者分层固定：只需 DTO 的合同消费者导入 `海中鱼巣.核心.合同.L1可重建索引`；需要 `L1事实可重建索引` 行为的消费者导入 `海中鱼巣.核心.索引.L1事实基座`，不得从合同模块假定类成员存在。

v0.25 字节裁决保持：

```text
G6：HZY-L1G6 → U32格式 → U32 0x15000301 → U8变体
  → 变体后只插入一次 RP 原始32字节 → U32合同 → U32规则 → U64幂等 → U64期望代次
RP：HZY-L1-RP + 大端字段计划 → SHA-256/32字节
RW：HZY-L1-RW + 大端发布代次/幂等键/字段稳定编码 → SHA-256/32字节
E01结果 v2：一次 HZY-L1RS + 一次 U32(2)
  → v1 去除前缀与版本后的字段载荷（合同版本至逐项通用读回）
  → RW原始32字节 → SHA-256；绝不嵌套 v1 前缀/U32(1)
```

同义命中原样返回首次 RW、结果摘要版本和结果摘要；恢复按保存版本重算，E01 为 RW v1 + 结果摘要 v2，非 E01 保持结果摘要 v1。缺版本、缺字段、摘要不等或三副本不等按既有 `材料不完整`/`内部不一致` 合同拒绝或隔离。
