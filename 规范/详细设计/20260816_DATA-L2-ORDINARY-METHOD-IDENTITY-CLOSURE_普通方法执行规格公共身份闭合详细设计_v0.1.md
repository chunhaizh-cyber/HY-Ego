# DATA-L2 普通方法执行规格公共身份闭合详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-ORDINARY-METHOD-IDENTITY-CLOSURE`

状态：设计就绪

## 1. 目标与完成边界

为 `DATA-EXT-14` 普通方法登记的后继公开 DTO 闭合最小强类型身份前置，新增独立传统数据头 `海中鱼巣/领域/L2普通方法结构.数据.h`，使后继设计能够分别表达：

```text
方法首的唯一治理虚拟存在
+ 方法条件节点
+ 方法结果节点
+ 方法动作入口节点
+ 独立方法内容版本
+ 独立方法规格版本
```

本叶只发布六种值式类型和六个纯值有效性 helper，并在根工程唯一登记新头。它不建立普通方法登记事实、作用对象绑定、场景 / 特征 / 目标状态引用、动作键、参数、禁止项、生命周期关系 23、候选索引、CRUD、owner、服务函数或普通应用装配。

完成只证明后继普通方法 DTO 不再需要用裸 `稳定编码`、字符串、函数地址、方法身份或版本号互相代替；不证明方法可登记、可召回、可执行或 `DATA-EXT-14` 完成。

## 4. 精确公开 ABI

所有类型位于 `namespace 海中鱼巣`，节点身份沿用共同强类型身份的形状，版本使用独立非零 `uint64_t` 值。字段顺序、默认构造和相等合同固定如下：

```cpp
#pragma once

#ifndef L2_ORDINARY_METHOD_STRUCTURE_NO_INCLUDES
#include <cstdint>
#include "L2结构公共.数据.h"
#endif

namespace 海中鱼巣 {

inline constexpr std::uint32_t L2普通方法结构合同版本 = 1;

#define 定义L2普通方法节点身份(类型名) \
    struct 类型名 final { \
        稳定编码 值; \
        explicit 类型名(稳定编码 编码 = {}) noexcept : 值(编码) {} \
        friend bool operator==(const 类型名&, const 类型名&) = default; \
    }

定义L2普通方法节点身份(L2方法治理虚拟存在身份);
定义L2普通方法节点身份(L2方法条件身份);
定义L2普通方法节点身份(L2方法结果身份);
定义L2普通方法节点身份(L2方法动作入口身份);

#undef 定义L2普通方法节点身份

struct L2方法内容版本 final {
    std::uint64_t 值 = 0;
    friend bool operator==(const L2方法内容版本&,
        const L2方法内容版本&) = default;
};

struct L2方法规格版本 final {
    std::uint64_t 值 = 0;
    friend bool operator==(const L2方法规格版本&,
        const L2方法规格版本&) = default;
};

} // namespace 海中鱼巣
```

四种节点身份的 `值` 是方法 owner 下已发布节点的全局稳定编码。它们彼此不可隐式转换，也不可与 `L2方法身份`、`L2存在身份`、`L2状态身份` 或裸函数地址互换。治理虚拟存在是方法内部长期能力基底，不是世界结构的 `L2存在身份`。

`L2方法内容版本` 标识一份完整不可变方法内容快照；`L2方法规格版本` 标识条件或结果规格的来源版本。二者不是稳定节点编码、事实代次、生命周期顺序、任务轮次或合同版本，不能相互替代。精确重复可以回显原版本；新代际必须形成新方法身份和独立内容版本，具体单调 / 父代规则留给后继正式发布合同。

## 5. 纯值 helper

同一头定义：

```cpp
inline bool L2方法治理虚拟存在身份有效(
    L2方法治理虚拟存在身份 身份) noexcept;
inline bool L2方法条件身份有效(L2方法条件身份 身份) noexcept;
inline bool L2方法结果身份有效(L2方法结果身份 身份) noexcept;
inline bool L2方法动作入口身份有效(L2方法动作入口身份 身份) noexcept;
inline bool L2方法内容版本有效(L2方法内容版本 版本) noexcept;
inline bool L2方法规格版本有效(L2方法规格版本 版本) noexcept;
```

前四项只判断 `有效(身份.值)`；后两项只判断 `版本.值 != 0`。helper 不证明节点存在、属于方法 owner、当前、唯一或与任何方法关联，也不证明版本已经发布或可执行。

## 6. 后继合同门禁

后继 `DATA-L2-ORDINARY-METHOD-PUBLIC-DTO` 至少必须在本结果上继续冻结：

1. 方法登记根归属、方法身份来源和唯一治理虚拟存在事实；
2. 作用对象的强类型绑定槽，以及条件 / 结果各自的场景、特征、目标状态合同、来源版本和确定顺序；
3. 动作入口的输入 / 输出场景、稳定动作键和当前性；
4. 参数与禁止项的强类型结构引用，不使用自由 JSON、字符串、裸编码或通用 I64 槽；
5. 方法内容版本、规格版本、生命周期关系 23 及其状态事实的分账；
6. 新增、不同新身份替换、退出、当前 / 历史读取和按结果规格候选身份组读取的请求 / 结果 / 成功形状；
7. 候选索引只返回身份组，命中后必须按同一截止权威读回完整方法。

若上述字段仍需新增共享强类型，继续建立最小提供者叶；不得由执行者在服务实现中临场选择字段或编码。
