## 1. 目标、依据与替代关系

本设计在 P1A3F 最终公开合同内原地实现现实世界引导、世界结构读取、实际存在规格、创建接纳、成员移动和存在移除。它不改变 P1A3F 已冻结的公开 DTO、模块、类、构造依赖或稳定枚举值；七个公开函数的 `未实现` 骨架由真实函数体原位替换，不建立第二重载或兼容入口。

上游业务归属依据为 `流程图/目标业务流程图/业务节点到能力与目标函数映射.md` 第4节“世界事实维护”；具体闭环依据为 `流程图/20260802_WORLD-TREE-P1_世界树业务服务业务流程图_v0.1.md` 的 B01/B02、C01/C02、Q01/Q02、M01/M02 与 W01/W02。该映射只裁决业务领域和合法线程调用方，不替代本设计的函数合同。直接函数依据为六份同代 v0.2 目标函数图。本设计的引导函数只提供 B01 中“世界根、初始内部场景和直接结构”子能力，不创建或确认唯一自我，因此不单独闭合世界、自我和场景全部材料；唯一自我接纳必须由后继世界树门面消费正式自我身份后在独立事务中闭合。移动和移除函数分别提供 M01/M02 下层能力，业务门面和最终完整快照仍由 P1C/P1D 承接；Q01/Q02、F02、S00 等其它能力由具名后继提供者承接。

直接依据：4020（类型合同、强类型来源与 SQL 非权威）、4040（候选确认、逆序撤销、最后发布与原许可读回）、4200 v0.8、4201 v0.2、上述现行领域归属映射、WORLD-TREE-P1 总业务流程图与六份 v0.2 目标函数图、`20260803_WORLD-TREE-P1A3F_世界结构合同骨架详细设计_v0.1.md` 的未替换段落及 `20260803_WORLD-TREE-P1A3F_世界结构合同骨架详细设计_v0.2.md`。本文件只消费 4020/4040 的现行合同，不复制 L1 事务实现。本文件替代总函数确认 v0.1 中 P1A3 的行为描述；共享值式字段仍以该总函数确认 blob `c27b2ab72042102604ae94553929201ebb120f9d` 的 §2.1 为准。

本设计不实现特征、状态动态、完整快照、统一门面、生产路由或旧入口删除；这些由 P1B、P1C、P1D 承接。

## 2. 前置提供者与硬门禁

P1A3 只能在以下 P1A2/P1A2Q 真实行为进入正式代码后执行：

1. `节点直接结构查询服务` 的节点、关系、类型合同、类型化值、索引和事实代次读取均返回值式结果及非零同代次见证；
2. `节点直接类型化结构提交服务::{探测幂等,提交}` 支持预期事实代次、双摘要、固定局部身份、通用原许可内读回和持久状态；
3. `节点直接结构恢复服务::恢复安装实例` 的成功结果必须携带非零恢复发布代次；恢复结果只负责证明恢复分类和事实截止，不承担导出全量当前索引；
4. WORLD-TREE-P1A2Q 的 `节点直接结构查询服务::读取当前索引(const 索引物理键&) const` 已真实实现；P1A3 用本文件固定的世界根索引键和初始场景索引键分别调用一次，两个结果必须与恢复代次相等并各含恰一个当前节点目标。

第 3—4 项不满足时，P1A3 返回 `DRIFT-P1A2Q-CURRENT-INDEX-READBACK`，零代码修改。禁止增加 SQL 回源、按显示名扫描、猜测根节点、反向遍历全部索引或临时新查询重载。

P1A3F v0.2 骨架只解除 ABI、模块、链接、四依赖构造和安全拒绝门禁；它不满足本节任何真实行为门禁。

P1A2 还必须在正式合同或成功结果中唯一冻结 `节点直接发布后读回项.预期版本` 对 `当前索引/已移除索引` 的机器语义。索引读回值本身无版本字段，P1A3 不得自行猜测 `0` 或 `1`。该语义未随已发布依赖成立时，P1A3 保持待激活并具名返回 `DRIFT-P1A2-INDEX-READBACK-EXPECTED-VERSION`；其它不涉及索引读回的设计切片继续闭合。

### 3.1 事务命名域、索引与摘要

```cpp
enum class 世界树结构事务命名域 : std::uint64_t {
    无效 = 0,
    现实世界首次引导 = 0x5754525800000001ULL,
    创建并接纳实际存在 = 0x5754525800000002ULL,
    移动世界树成员 = 0x5754525800000003ULL,
    移除世界树存在 = 0x5754525800000004ULL
};
```

首次引导事务键等于安装实例键；其它请求的幂等身份命名域必须与操作匹配，键值非零。禁止与 P1A2 `安装实例初始化` 治理事务复用命名域。

索引规则版本为 1：

| 索引 | 所有者键 | 命名域 | 键值 |
| --- | --- | --- | --- |
| 世界根 | `世界结构服务身份.键值` | `0x57545201` | 安装实例键值 |
| 初始场景 | `世界结构服务身份.键值` | `0x57545202` | 安装实例键值 |
| 实际存在业务身份 | `存在服务身份.键值` | `0x57545203` | 创建幂等键值 |

三者 `键格式版本=1`、`探测规则版本=1`。存在业务索引标识存在本体，移动和移除不得删除。

请求意图摘要固定编码 `格式版本1 + 操作标签 + 公开请求全部字段声明顺序`；执行证据摘要固定编码 `格式版本1 + 操作标签 + 意图摘要 + P1A3/P1A2合同版本 + 写前事实截止代次 + 本操作相关写前事实稳定排序 + 完整写项组 + 完整读回规格`。操作标签固定为首次引导1、创建2、移动3、移除4。`P1A2合同版本U32` 固定写入 `static_cast<std::uint32_t>(节点直接结构服务合同版本)`，当前值1；其后独立写入 `写集规则版本U32`，当前值2，不得用材料格式版本或本文版本号替代。整数网络字节序，枚举按冻结底层宽度，optional 先写 U8 0/1，variant 先写 P1A2 材料格式稳定标签，vector/集合先写 U64 数量；禁止结构体内存布局、RTTI、`variant.index()`、显示名称和容器迭代顺序。资格 I64 材料固定写入稳定材料标签、I64 字节长度8和网络字节序有符号值。SHA-256 使用标准算法和标准测试向量。

### 3.3 摘要逐字段顺序

意图摘要的字节序列固定为：`格式版本U32 -> 操作标签U8 -> 公开请求各字段的声明顺序 -> 本操作所有节点创建项按写项顺序的(局部身份种类U8,局部身份值U64,节点命名域U64,节点类型U32)`。无节点创建的移动/移除最后部分为零项。

执行证据摘要字节序列固定为：`格式版本U32 -> 操作标签U8 -> 意图摘要32字节 -> 世界树服务合同版本U32 -> 世界树规则版本U32 -> P1A2合同版本U32(节点直接结构服务合同版本=1) -> 写集规则版本U32(2) -> 写前事实截止代次U64 -> 操作相关写前事实 -> 完整写项组 -> 完整读回规格`。相关写前事实顺序为：首次引导空集；创建为世界根、目标场景、两者资格及目标场景当前父关系；移动为世界根、成员、旧父、新父、旧关系及子场景情形的成员后代闭包；移除为世界根、存在、预期场景及归属关系。每一写前事实组先写 U64 数量，再按本文件对应稳定键升序；每个 optional 先写 U8 0/1；每个见证按稳定主键命名域/键值、类型、版本、关系端点和角色顺序的 DTO 声明顺序编码。完整写项组与完整读回规格同样先写 U64 数量，再逐项写 P1A2 材料格式稳定标签和该项全部字段；类型化值的材料按 §3.1 的稳定材料标签、长度和值编码，不自建第二套 variant 标签。

## 4. 根函数合同与调用顺序

### 4.1 `确保现实世界已引导`

完整签名、参数和返回类型沿用 P1A3F §3.4。唯一施工图：`流程图/20260803_确保现实世界已引导_函数流程图_v0.2.md`。

顺序固定为：入口校验 → `恢复_.恢复安装实例` → 恢复判定 → 恢复后索引/结构读回，或治理代次1首次提交 → 原独占许可内通用读回逐项映射 → 直接构造引导读回 → 返回。首次创建成功分支禁止在事务释放后再调用普通世界结构快照来证明原提交，否则会把合法并发前进误判为内部不一致。

恢复映射：`已恢复/精确同义` 进入恢复后读回；`已初始化确认空域/已恢复治理空域` 只在代次恰为1时进入首次提交；`材料不完整` 映射 `无可验证历史`；`版本漂移/资源失败` 原类映射；格式不支持、身份冲突、关系矛盾、发布未知、内部不一致映射 `内部不一致`。

恢复成功后先确认恢复代次非零，再分别调用 `结构_.读取当前索引(世界根索引键)` 和 `结构_.读取当前索引(初始场景索引键)`。两个结果都必须成功、事实截止代次等于恢复代次、索引组恰一、物理键逐字段等于请求键、`当前=true`、仅有节点目标且节点类型为场景；随后用根调用世界结构服务，要求同代次、根无父、初始场景是根的唯一具名初始场景资格直接子场景，返回 `已恢复`。精确索引未找到、零项、多项、目标错型、键错配或代次不等均为内部不一致；许可拒绝、资源失败按同类结果映射；查询入口拒绝或内部不一致映射内部不一致，不用第二来源补判。

首次提交写项顺序：两个资格类型合同、根节点 `节点:1`、初始场景节点 `节点:2`、根资格值 `类型化值记录:3`、初始资格值 `类型化值记录:4`、根到初始场景关系 `关系:5`、世界根索引、初始场景索引。局部身份值在全写集跨种类唯一。两资格来源固定 `世界结构服务身份`；关系为根到初始场景的 `普通父子` 顺序0。读回规格按上述局部身份顺序包含两个当前节点、两个当前类型化值、一个当前关系和两个当前索引。成功发布代次必须为2；L1 返回后引导服务必须逐项要求根、初始场景、两资格值、父子关系和两索引数量、身份、类型、来源、端点、顺序、当前性及预期版本与本事务一致，直接构造 `节点直接世界引导读回`并返回 `已创建`。任一通用读回不一致映射 `内部不一致`，不二次写入或普通快照补判。L1 幂等读回也必须映射同一专属读回。

### 4.2 `读取世界结构`

唯一施工图：`流程图/20260803_读取世界结构_函数流程图_v0.2.md`。每轮先读首代次和两个资格合同，再用稳定主键小根堆 BFS 读取根、场景、直接父子、归属和资格。每个 L1 成功结果必须携带首代次；按源/目标/相关关系组查询返回 `未找到 + 空组 + 首代次` 时，只在本调用位置的“合法零关系”分支接受为空：根的父关系、叶场景的子场景/成员关系和没有额外相关边均可为空。节点、资格合同、资格值或非根父关系等必需事实未找到仍为非成功。末次代次相等才发布。

根无父；非根场景恰一父；存在恰一当前归属。场景资格恰一：根=`现实世界根`、初始场景=`初始场景`、其它=`普通场景`，来源为世界结构服务；存在资格恰一、值=`实际存在`、来源为存在服务。多父、多位置、环、根作子节点、悬空端点、方向/顺序错误、资格缺失/重复/错来源均返回内部不一致并携带稳定排序缺项。

只有全部子读成功或属于上述合法空关系，但其非零代次不等时完整重试一次；许可拒绝、资源失败、必需事实未找到和内部不一致不进入漂移重试。第二轮仍漂移返回版本漂移。成功结果按 4200 稳定键排序。

唯一施工图：`流程图/20260803_节点直接世界结构读取服务读取当前事实代次_函数流程图_v0.2.md`。

函数不接收参数，不保存本次任何材料；返回值由调用方拥有。唯一下层调用为：

```cpp

节点直接结构查询服务::读取当前事实代次() const;
```

下层结果映射固定为：

| 下层状态/材料 | 世界结构结果 |
| --- | --- |
| `成功` 且代次非零 | `已读取`，原代次 |
| `未找到` 且代次为0 | `未找到`，代次0 |
| `入口拒绝` | `入口拒绝`，代次0 |
| `版本漂移` | `版本漂移`，代次0 |
| `许可拒绝` | `许可拒绝`，代次0 |
| `资源失败` | `资源失败`，代次0 |
| `内部不一致` | `内部不一致`，代次0 |
| 成功却零代次、未找到却非零代次，或任一非成功携带非零代次 | `内部不一致`，代次0 |

`映射状态` 是本函数内的一次 `switch`，不建立新辅助函数。`std::bad_alloc` 映射资源失败，其它异常映射内部不一致；异常不越过 L2 边界。全路径零机器事实写入、零 SQL/持久材料读取、零重试。

## 5. 状态映射、所有权和并发

L1 提交八种状态逐项同义映射到场景写入状态。世界结构状态映射：已读取继续；未找到→版本漂移；入口拒绝/版本漂移/许可拒绝/资源失败/内部不一致/未实现逐项映射。真实 P1A3 成功后七函数不得主动返回未实现，但稳定枚举值保留。

公开结果全部由调用方拥有；服务只保存由装配拥有且生命周期更长的非空引用。内部规格和摘要只活到同步提交返回。不得缓存世界结构、保存许可、持队列锁调用结构事务或跨调用保存请求引用。

世界结构只允许一次完整漂移重试；三个写入口只允许提交版本漂移后从幂等探测开始完整重算一次。许可竞争立即返回，不等待、不 sleep。

七个公开函数和四个事务形成函数都必须在各自边界捕获异常：`std::bad_alloc` 映射本层 `资源失败`，其它异常映射 `内部不一致`；非成功不得携带部分结构或假读回。P1A3 本叶子只形成并传播结构化结果，不直接调用日志函数；后继 P1D 的正式运行期请求入口是该错误因果链的唯一最终记录责任边界，只对未处理异常、资源失败、内部不一致和发布结果未知记录一次。合法入口拒绝、未找到、幂等冲突、版本漂移和许可拒绝不记录逻辑错误；自检直接调用时以断言/结构化报告承载，不补写生产日志。日志不参与返回或事实裁决。
