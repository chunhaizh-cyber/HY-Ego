## 1. 目标及不变边界

由现有真实 I64 特征输入建立带独立输出类型的比较定义，在共同 G 下按正式来源 DAG 有界复算，一次返回要求的排序、关系和差异三个角色中的具名 I64 结果；需求、任务、方法沿新合同消费实际二次至 n 次材料。每个结果是任务局部值式实例，其关联身份由请求身份、根定义、G、输出角色及完整来源见证共同成立，不是伪造的 L1 节点 / 值身份。定义、注册和输出 FT 是真实持久事实；计算本身零写。

一次 I64、VecI64、VecU64 和独立完整材料不变。二维轮廓、三维体素按 2100 新条款承载完整材料，当前新值服务仅提供原始载荷及身份生命周期，尚无具名解析；本轮不新增无人消费的结构 DTO、序列化、提取、体素化、向量 / 形状比较算法。一次材料准备与比较派生按来源步骤分流，不能按材料形状判阶次。

不改变 FC 身份、宿主、成熟、观测、名称、支持或聚合选层算法；这些新需求仍在原大计划待修范围。本轮规范要求全部正式二次至 n 次类型为 I64，代码仅闭合已存在的 I64 比较算法，故其概念域限精确 I64 / 一维区间，不建立概念或持久结果实例。禁止旧 L2、额外 owner、全局根建立、主程序接线、L1 修改和其它 WIP 的清理 / 发布。

## 2. 当前供给与复用裁决

特征类已有派生定义 / 注册同 owner 原子发布、二元直接来源、最高来源阶次加一、I64 安全排序与右减左及原键首次查询。其基础来源实际为普通 F 实例，递归来源为派生定义；不是把 FT 当定义节点。现比较输入可把无关真实 I64 值与声明来源拼接，必须改成服务从正式 F 读值。现输出 int8 三态 / 关系枚举 / 差异材料混用一个定义，不能直接作为新业务输出。

二次特征类是无 owner 的新链包装，五个现有方法可适配新 DTO；需求类当前将来源 F 身份与 FT 比较并拒绝同 FT，方法 / 需求还把阶次固定为 2，均须修正。任务仅转发方向材料。当前新 F 精确及按实例历史读、FT 历史读提供叶实例 / 类型见证；L1 当前 / 历史关系和首次规范化写集提供定义重建。知识库基线滞后，以本次实际源文件为复用依据。

旧派生格式 v1 的 U64[16] / I64[4] 保留只读治理及已绑定原键恢复；新增业务使用具名 v2 合同，不将旧 DTO 的左右字段重新解释。旧可执行业务比较入口及裸比较结果退出公开面。旧 v1 未绑定新建请求拒绝，不自动升级或生成输出类型。旧 v1 定义可以查询、退出、精确重放；不作为 v2 比较的可执行上游。

## 3. 类型及公开合同

### 3.1 类型与定义

现 `特征类派生结构类型` 保留七项用途和值；尾增 `输出类型关系类型`，是外部交付、同 F owner 的真实普通关系类型，须与原七项互异。旧七项构造只提供 v1 治理；v2 必须完整交付八项，不初始化任何全局对象。二次类构造核验 F、E 均绑定同一传入 L1；没有额外 port。

新 `特征类标量结果角色:uint8` 固定 `排序=1、关系=2、差异=3`，角色位为 `1 << (角色-1)`。`特征类标量量化合同` 为 `{稳定编码 单位,维度,分量角色; uint64 缩放分子,缩放分母; int64 下界,上界; 量纲类别; 舍入; 溢出}`。分子分母为约分后正数，范围闭区间；量纲类别只含无量纲 / 有量纲，舍入只含不转换，溢出只含拒绝。元数据是类型的显式声明，不猜测单位代码的含义，不进行单位换算。比较两输入共享同一量化合同，实际值必须在输入范围内。

新 `特征类标量输出提交项 {角色,量化}`，读回事实再含 `{稳定编码 特征类型,归属关系,格式标记值事实}`。排序范围恰 [-1,1]、无量纲、缩放 1/1；关系无量纲 / 1/1，目标判断范围恰 [1,3]，状态迁移恰 [4,6]；值映射沿原具名关系：低于 / 达到 / 高于=1/2/3，增加 / 等价 / 减少=4/5/6。差异单位、维度、分量角色、量纲类别及缩放必须等于输入，范围由注册显式给定。输出类型是发布时新建的不同真实 I64 属性类型，不能复用同一个 FT 充当多个角色，也不接受调用方仅给非零 FT。

新 `特征类标量派生来源提交项 {uint32 顺序,输入角色; 特征类定义身份 来源; uint8 上游输出角色}`：恰两项，顺序 1、2；角色分别等于注册左右角色；直接来源身份互异。基础 F 的输出角色为 0，派生来源为 1..3 且该上游输出真实存在。基础实际阶次=1，派生阶次为其正式事实值，结果=max+1，溢出拒绝。来源及选择角色发布后不可变；F 退出或换代不重绑定新 F。

新 `特征类标量比较注册合同` 含原用途 / 算法版本 / 左右角色 / 允许结果位 / 误差合同版本 / 可选误差预算及相等容差，加输入量化、按角色升序的输出提交组。至少一项且恰覆盖允许结果位，最多三项。本轮执行算法仅既有 I64 注册算法版本 1，派生规则版本与算法版本一致；误差及容差仍为非负 I64，沿原明确关系判定使用，不能改动实际排序或差异值。v2 格式不意味着算法版本 2。

新 `特征类派生读取预算 {uint64 最大定义数,最大关系数,最大叶数,最大属性值数,最大深度}`，五项必正，不能用零表示无限。定义数按不同派生定义计一次；关系数按实际读取 / 校验的不同本 owner 关系计一次（来源、宿主、注册、输出及反向归属）；叶数按不同 F 计一次；属性值数按实际消费的不同值事实计一次，包括定义 / 注册、输出 FT 格式标记及叶值；深度按根至基础 F 的最长路径，根计 1。重复访问仍核对身份等义但不重复计数。读取组先按剩余额度裁决，禁止默截断。新建自己的固定写集亦先计入预算，不能提交后才发现必需读回预算不足。

### 3.2 方法与结果

在 `数据服务.特征类.ixx` 的唯一 F 服务增加：

```cpp
特征类标量派生写结果 建立标量派生定义(const 特征类标量派生建立请求&);
特征类标量派生读取结果 读取标量派生定义(const 特征类标量派生读取请求&) const;
特征类标量派生写结果 退出标量派生定义(const 特征类标量派生退出请求&);
特征类标量比较结果 比较派生特征(const 特征类标量比较请求&) const;
```

前三项是新具名入口；第四替代旧比较重载，不能保留旧业务输出入口。请求均使用独立 `标量派生合同版本=2`，不修改普通特征 / 历史 FT / v1 治理合同版本。

- 建立请求：`{版本,G,幂等身份,来源组,派生规则,optional宿主E,标量注册,预算}`。
- 读取请求：`{版本,Gread,H,定义身份,预算}`，`0<H<=Gread`，没有隐式 H=0。
- 退出请求：`{版本,G,幂等身份,定义身份,预算}`。
- 比较请求：`{版本,G,请求身份,根定义,用途,预期算法版本,要求结果位,预算}`。请求身份非零，属于本次纯计算关联，不是幂等写键；不接收左右裸值、伪来源编码或外部上一结果。

新 `特征类标量派生事实` 含定义身份、真实阶次、两项直接来源事实（含真实关系 ID）、规则、optional E / 宿主关系、注册身份与两个载荷值 ID、完整注册、输出类型事实组、创建 / 退出 G；另读取投影含去重基础叶 `{F,FT,值事实,创建/退出G}` 及根左右各自可达叶身份组。这些集合由正式图重建，不持久化第二叶索引。每项真实输出 FT 在 H 为 I64 属性类型、同 owner、创建 H 与定义相同；按输出类型关系反向读回恰一条归属、源为该定义且角色一致。注册声明必须同该关系集合逐项相等。每个输出 FT 恰一项自身类型属性槽（槽类型等于该 FT），指向同 owner、所属及来源均为该 FT、与 FT 同创建代次的 I64 格式标记值 `0x5343414C41520002`；该数只识别标量派生格式 v2，不是业务类别或概念身份。定义读取须核槽唯一、值类型 / 编码 / marker / 生命周期，标记本身不能证明输出资格。

读取结果：`{版本,状态,Gread,H,optional定义事实,基础叶组,左叶组,右叶组}`；失败清空全部事实载荷。v1 对象从此 v2 入口返回格式不支持，由原 v1 查询治理，不把缺输出解释为空成功。

写结果：`{版本,状态,Gread,首次发布H,发布确定性,optional定义事实,optional正式L1写入回执}`。确定性为未派发 / 确认未发布 / 确认已发布 / 可能已发布。回执来自实际 L1，只在真实取得时保留；失败清除成功事实，但保留已知 H、正式回执和确定性。成功谓词检查自有形状；消费者仍逐字段互证请求、owner派生身份、G/H、完整写集映射。已知成功后读回失败或异常统一已可能发布，保留已知首次 H；外围异常不猜测零发布。

新 `特征类标量比较结果` 为 `{版本,状态,拒绝原因,G,请求身份,根定义,注册身份,算法版本,真实阶次,实际结果位,完整输入量化/误差合同,optional固定二项数组直接输入回执,基础叶回执组,结果组}`。直接输入回执精确为 `optional<array<直接输入回执项,2>>`；成功时存在且恰两项，失败时为空，不以默认两个空项冒充清空。直接输入回执项为闭合 variant：基础 `{F,FT,值事实,值,创建/退出G,角色}` 或上游 `{定义,输出FT,输出角色,值,实际阶次,角色}`；叶回执包含真实 F / FT / 值事实 / I64 / G 及生命周期。结果项为 `{输出FT,角色,int64值,完整量化合同,方向}`；方向按排序左对右、关系左到右语义、差异右减左明确保存。全部结果共用同一来源回执，按角色升序且恰对应请求位。没有单独公开三态、关系枚举或差异裸材料成功通道。

读取 / 比较状态具名闭集：已读取 / 已比较、入口拒绝、未找到、已退出、格式不支持、算法不支持、类型不匹配、来源不匹配、单位量化不匹配、结果范围不满足、运算溢出、预算不足、历史材料不可用、事实代次漂移、资源失败、内部不一致；写再含已创建 / 已退出 / 精确重复 / 幂等冲突 / 引用冲突 / 已可能发布。使用独立枚举，不能复用其它状态数值强转。资源与内部失败保留实际类别；历史清理不当未找到。比较任何失败（包括任一要求角色失败）清空全部值及来源载荷，仅保留版本、请求身份、实际可证明 G、状态和原因；0 只可作为合法成功值。

## 4. v2 持久布局、事务及历史

原 v1 七种结构类型、原本地键与布局不改义。v2 定义 / 注册仍为原节点族。对 n 个输出（按角色升序）在同一个 F owner 写集中建立：定义普通节点键 1；注册普通节点键 0x30001；输出 I64 属性类型节点键 `0x40000+角色`。原阶次值键 2、规则值键 3、来源边 0x10001/2、optional宿主边 0x20001、注册归属边 0x30002、U64/I64 注册值 0x30003/4 及四个槽保持原用途。新增 `定义→输出FT` 边键 `0x41000+角色`，使用第八类型，关联值=角色。每个输出 FT 另建立标记值键 `0x42000+角色` 及 FT→自身类型的属性槽，值为 `0x5343414C41520002`、所属与来源均为该 FT。节点 2+n、值4+n、关系3+宿主数+n、槽4+n，新身份映射数 `9+宿主数+3*n`；均必须真实回读，不能沿用 v1 固定映射数量。

注册 U64 v2：先保留 v1 的 16 个固定位置及语义，位置0改为2；其中单位 / 维度 / 分量来自输入量化。追加位置16/17为两来源所选输出角色，18/19为输入缩放分子 / 分母，20为舍入=1（不转换），21为溢出=1（拒绝），22为输出项数 n，23为输入量纲类别（无量纲=1、有量纲=2）。随后每输出9个U64，顺序为 `角色,单位,维度,分量,缩放分子,缩放分母,量纲类别,舍入,溢出`。总长 `24+9*n`。I64 v2 前4项保留误差 / 容差有无位及值，4/5为输入下界 / 上界，随后每输出2项下界 / 上界，总长 `6+2*n`。不存在 optional 的载荷仍固定零，无额外尾项；有符号范围不转成 U64 数量。输出 FT 通过 native 边持久化，不能只把 FT 数字写进数组。

v2 直接来源边继续以 `(顺序<<32)|输入角色` 承载原结构角色，所选上游输出角色由注册固定位置及来源边逐项互证。注册读、创建、原键重建、首次 H 读回、退出历史读必须共用同一严格版本化编解码，不复制一处当前解析却遗漏退出路径。v1 恰16/4，v2恰上述长度；畸形 / 混合格式拒绝，不宽松降级。

建立先纯值检查版本、键、形状及预算；再查本 owner 原键。已绑定时精确比较原规范化写集（保留原 G，不换键），用真实映射 / 首次 H 重建并在当前 Gread 读取 H 投影；即使来源或本定义之后退出，也不要求它们目前活动。未绑定才在请求 G 读取全来源，核阶次、输出类型、相同量化、基源实际 I64、optional E；形成完整写集并同 G 原子提交。新候选以请求 G 校验，不预测 G+1；发布后用实际 H 回读自身，来源按 H 仍活动，前后实际 Gread 守卫。来源坏、漂移或预算不足均不派发；派发以后非成功按真实回执保守分账。原键材料缺失不能按“未绑定”重建。

退出 v2 先原键恢复，再在 G 读完整自有结构；原子退出定义、注册、所有输出 FT、四个原值及全部 n 个标记值、全部自有关系，退出写集只提交上述完整事实退出集合，`属性槽变更` 必须为空，不提交显式槽移除。L1 不允许槽变更的所属或类型节点同时进入退出集合；槽随所属节点退出离开当前结构，退出节点保留原槽历史，值退出仅移除仍活动节点中指向该值的槽。首次请求、原键等义重建与退出恢复均使用同一零槽变更写集，不以历史槽仍存在认定退出未完成。退出集合按稳定编码全局升序，无按事实种类分组；类型仍被其它事实、派生来源或概念引用时，由已知反查及 L1 同 G 守卫拒绝，不自动释放别人的关系。依赖该定义的下游 native 来源边也阻止退出。输出 FT 不可单独换型、解绑、替换或保留成无主类型。退出后按早 H 读取应保留真实未来退出代次并采用 `创建<=H<退出` 判定；退出回执在退出 H 重建被退结构时以实际退出集及首次证据互证，不能要求 H 当前活动。物理清理依 L1 native 历史引用合同，本轮不增加清理入口或永保承诺。

旧 v1 新增接口只允许既有键精确恢复；未绑定返回原 `特征类派生数据状态::不支持`（数值19），表示该旧格式不再允许新建，不新增或重排旧状态值。其当前查询、退出和历史原键路径保持原格式，不能产生 v2 类型或业务计算输出。新 v2 不能引用 v1 作为可执行上游；业务显式建立 v2 新定义，不修改旧身份。普通 F 新增 / 修改保持原始值表示合同，但在 FT 当前事实中发现任何自引用属性槽（槽的属性类型==FT）就拒绝将该 FT 用作普通实例类型；不论标记值合法、损坏、未知版本或未配置第八关系类型，都不能降级成一次。此保留形状可由所有旧 / 新构造直接读取 FT 识别，无需全局初始化。普通写入拒绝不把自槽单独认作合法派生类型；类型完整资格仍由 v2 归属与注册证明。F 原键已绑定的历史恢复保持原历史裁决，不能在新规则前置处误当新写。当前本轮没有持久派生值入口，不能把裸 I64 用此 FT 发布成结果实例。

## 5. 有界计算算法与类型来源

比较先验证新请求形状及前 G，读取根定义与已注册算法。在同一 G 以显式栈遍历来源 DAG；灰色重复为环 / 内部不一致，黑色可共享计算；去重以真实定义身份为键。每条来源边、输出反向归属、值及叶按 §3 预算累计，深度受控，不利用递归 C++ 栈隐含无限能力。排序仅为确定返回顺序，不作为类型意义。

基础叶用实际 F 精确读或按实例历史读 `{Gread=G,H=G}`，核 F / 值 owner、FT、唯一当前槽、值所属 F、创建 / 退出以及 FT 的 I64 表示；实际值必须为直接 I64。当前算法不解析独立材料引用，也不接受 VecI64 / VecU64，不能从其它 I64 值事实借值。不满足时类型不匹配，无计算结果；一次原始材料仍可正常保存。

派生输入读取选定上游输出 FT 的真实关系与合同，并有界复算该上游所选角色。上游的单位 / 维度 / 分量 / 缩放 / 量纲 / 舍入 / 溢出必须与本级输入合同相同；上游允许域须包含本次实际值，不要求上下级范围完全相同。根每项及被依赖角色一次同 G 计算，共享定义按所需角色并集最多计算一次；不可拿调用方裸结果当缓存。所有正式来源参与完整性校验，即使最终只请求一种结果。

排序用安全有序比较得到 -1/0/1；关系严格沿既有算法及用途的容差规则取得1..6中合法值；差异先可表示性判断后执行右减左，再检查输出范围。输入合法但差异溢出只在请求差异或上游依赖差异时失败，不禁止仅排序的合法极值比较。任何要求项失败则全部无值，不能返回可消费半结果。末 G 与请求 G 不同则无值漂移。计算从不创建 FT、定义、结果值或缓存权威；相同完整输入重复读不绑定幂等键、不增加任何计数。

本版无独立时空变换算法：共同 G、optional宿主以及全部叶的事实来源 / 生命周期作为实际已具备范围；注册不允许要求未供给的坐标、动态时间或场景补偿。不能从 G 推出绝对时间或空间。后继有相应输入 / 算法时必须扩充具名合同，而不是省略必要关联。

## 6. 二次、需求、任务、方法消费

二次类保留原五个服务方法名，用新具名请求 / 结果替换其业务签名：生成接受 `二次标量特征生成请求{标量派生建立请求}`；查询 / 退出接受新标量定义请求；计算接受 `二次标量特征计算请求{标量比较请求}`；概念材料读接受新标量定义读取请求，返回新 `二次标量特征概念材料结果`。材料只是完整定义 / 输出类型 / 真实阶次 / 左右叶闭包的值式投影，不是概念节点。旧业务 DTO / 比较重载不再导出，v1 治理仍从 F 原公开入口可达。

包装保持 F/E 同 L1 身份检查；计算仅转发新比较并互证，不能重算其它算法。optional宿主新建准入真实读取 E；原键恢复不先要求当前 E 活动。写包装前后 G 与 provider 的 Gread 对照，首次 H 与当前读截止分开；失败不能把 provider 已可能发布改成裸漂移或丢失 H。历史查询不以今天退出否定 H 活动。

需求新增具名 `需求类标量方向读取请求{版本=1,G,请求身份,需求,当前F,要求结果位,派生预算}` 与 `需求类标量方向读取结果`（原需求 / 当前F / 目标F / 定义回显，加 optional新比较结果）。原 `计算临时需求方向` 改接这组新 DTO，旧方向请求 / 结果退出；需求持久记录及其版本不重排。任务同理新增 `任务类标量目标方向读取请求 / 结果`，原 `读取任务目标方向` 替换参数 / 返回，并将预算完整传递，不使用隐藏无限额度。

需求方向新建 / 新绑定须引用 v2 正式定义、用途为目标判断、宿主等于真实目标 E、阶次>1。从根右来源闭包证明静态目标 F 是真实可达叶，从 E 当前直接成员证明每个叶 F 的宿主；计算再要求本次当前 F 在根左来源闭包。左右闭包可以共享叶，但直接来源身份仍互异，不能用角色交换偷换方向；定义就是调用方已选定的变换规则，不宣称一个锚点等于整个高阶目标。所有叶都须是真实 E 成员；同 FT 的不同 F 允许比较，拒绝 FT等于F 的假身份。当前F/目标F换代后需显式新定义 / 新业务请求，不自动映射。

已有需求持久记录治理读取仍可识别其 v1 来源，不因旧输出类型缺失把记录当损坏；进入计算则明确方向不可用 / 格式不支持，无业务值。方法现有结果方向验证改为真实阶次>1：新绑定须有 v2 输出 FT，存量 v1 记录治理读保留原事实；不能因‘二次’名词而强制阶次2。方法没有比较算法，不新增计算流程。需求 / 方法准入用显式固定的结构读取上限 `{1024定义,8192关系,2048叶,16384属性值,64深度}`，这是资源上限，不是语义阈值；计算请求预算由调用方给出并可更小。

任务方向透传的新结果必须逐项互证需求 / 定义 / G / 请求身份 / 所要求输出角色，失败保留来源错误且没有比较值；不能通过需求返回成功即猜测业务目标已经达成。新增状态映射应显式覆盖预算、格式、源不匹配及上游失败；计算结果成功不变成需求满足、任务完成或方法执行结论。
