## 依赖方向

```text
入口.cpp
-> 启动.程序入口
-> 启动.应用程序
-> 装配 / 初始化 / 投影 / 审计 / 宿主 / 自检
-> 既有领域服务和适配器
```

禁止反向依赖：

```text
生产领域模块 -> 自检
领域服务 -> 控制面板窗口
系统初始化 -> SQL 读回裁决
入口.cpp -> 节点/关系/语素/需求/概念图
```

`启动.应用程序` 是进程最外层组合根，不是领域生产模块；只有该组合根可为显式完整自检模式导入自检入口。装配、初始化、投影、审计、宿主及全部领域模块均不得 import 自检模块。

## 现有被调合同

42 个既有函数以机器源 `existing_callees` 固定签名和当前文件。C01-C42 全部只读；其中 C12/C17 的中央运行器公开登记/运行合同仅由新增模块调用，不修改实现。调用点必须逐项复核实际接口。任一签名或后置条件漂移即停止关联函数，不由执行者猜测适配。
