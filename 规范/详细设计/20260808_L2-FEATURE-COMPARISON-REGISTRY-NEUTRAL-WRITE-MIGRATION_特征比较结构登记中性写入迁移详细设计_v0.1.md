## 1. 目标、边界与完成条件

把现有 `特征比较服务::建立登记(const 特征比较登记请求&)` 和 `读取当前登记() const` 从 legacy G8 领域意图、预探测、完整快照和带业务标签提交迁移到正式 L1 中性 CRUD。领域服务继续拥有比较结构登记的业务准入和结果解释；L1 只接收固定六节点中性写集、请求期望事实代次和不透明幂等键。

本叶只处理第一登记根 M01：

```text
特征比较登记请求
-> 建立登记
-> 六项结构稳定编码
-> 读取当前登记
```

严格排除：

- M02 `登记I64目标判断比较合同` 及标签 `0x15000802U`；
- M03 `登记I64状态迁移比较合同` 及标签 `0x15000803U`；
- 两类比较合同读取、运行期目标判断比较、状态迁移比较和状态动态联合发布；
- 状态、动态、因果、核心 L1、启动、运行期上下文、工程登记和异主 WIP；
- 为本叶新增业务标签、意图组、预探测、专用查询 provider、第二幂等账、完整快照或专项 L1 自证入口。

完成条件：M01 不再产生或提交 `0x15000801U`、G8 登记意图凭证、legacy 幂等探测、legacy 写集或完整快照；固定 `6/0/0/0/0` 中性写集恰一次提交；原请求精确重复可以在当前代次高于原期望时到达 L1 并复用首次六编码；成功类经 `G0 + 六节点 + G1` 权威当前读回后才返回登记；`读取当前登记()` 不直接返回缓存。


`特征比较登记请求`、`特征比较登记结果`、`特征比较登记` 的字段、默认值、可见性与合同/规则版本均不变。`特征比较状态` 的稳定枚举不新增“幂等冲突”；同键异义继续沿当前公开兼容语义返回 `入口拒绝`，不得借迁移改变 ABI 或结果值。

幂等域数值 `0x08` 不变。允许将它从服务私有常量迁到数据头，命名为唯一 `特征比较登记幂等域`；`合同幂等域=0x09` 与 `迁移合同幂等域=0x0E` 保持原位和原语义。

### 3.2 私有 helper 裁决

允许在 `服务.特征比较.ixx` 的现有私有边界新增或改写以下中文 helper：

- `映射登记中性幂等键`：返回 `L1中性写集幂等键`，数值为 `(0x08 << 56) | 身份.值`；不得改变 M02/M03 使用的 legacy `映射幂等键`。
- 中性写入/读取状态映射：只服务 M01，并遵守 §6。
- 六项中性映射查找与完整唯一校验。

删除 M01 唯一旧件：`形成G8特征比较登记意图凭证`、`登记请求相同`、`登记请求_`、M01 对旧探测/完整快照/legacy 提交的调用。保留 M02/M03 或运行比较仍消费的 `形成G8凭证`、`形成G8比较合同登记意图凭证`、legacy 映射、快照查找、状态映射及全部合同缓存。

`登记_` 必须保留，因为 M02/M03 和运行比较仍从中取得六个稳定编码；但它只是不权威定位缓存。只有权威读回完整后才可更新，`读取当前登记()` 不得原样直返。

### 3.3 锁与生命周期

M01 建立和当前读取继续使用服务现有互斥量保护 `登记_`。共享读回 helper 不自行重复取得同一非递归互斥量，由公开调用方在锁内调用；M02/M03 现有锁语义不变。L1 自身负责幂等、独占事务和代次原子发布，领域锁不替代 L1 最终裁决。

服务重建后没有六编码定位时，`读取当前登记()` 继续返回 `未注册`；本叶不增加扫描恢复、固定编码猜测或持久恢复入口。

## 4. 固定中性写集

写集类型为 `L1中性写集请求`：

```text
合同版本 = L1中性CRUD合同版本
期望事实代次 = 请求.期望事实代次
幂等键 = (特征比较登记幂等域 << 56) | 请求.幂等身份.值
节点/关系/值/属性槽变更/退出事实 = 6/0/0/0/0
```

| 本地键 | 登记字段 | 节点种类 | 中性属性类型表示 |
| --- | --- | --- | --- |
| 1 | 服务身份 | 普通 | 空 |
| 2 | 合同配置I64组属性类型 | 属性类型 | `I64组` |
| 3 | 合同字段关系类型 | 普通 | 空 |
| 4 | 无单位 | 普通 | 空 |
| 5 | 标量维度 | 普通 | 空 |
| 6 | 标量分量角色 | 普通 | 空 |

写集不得包含业务标签、领域意图凭证、请求摘要、执行证据、provider 见证、关系、值、槽变更、退出或持久材料。

## 5. `建立登记` 唯一控制流

1. 进入现有异常边界并取得服务互斥锁。
2. 校验合同版本、规则版本、幂等身份和非零期望代次；失败返回 `入口拒绝`、无登记，零中性代次读取、零提交。
3. 调用一次 `读取中性当前事实代次` 得到预读 P。要求合同版本正确、状态成功且 P 非零；否则按 §6 返回。P 只证明中性入口健康并为首次成功提供诊断，**不得在提交前因 `P != 请求.期望事实代次` 返回漂移**。
4. 映射 `0x08` 域中性幂等键，形成 §4 完整固定写集，保留原请求期望代次。
5. 恰一次调用 `提交中性写集`。不得预探测，不得因 P 与请求期望不等跳过提交。
6. L1 非成功优先映射并立即返回。成功与精确重复进入合同核对：合同版本、回显幂等键、非零首次发布代次、六项映射完整唯一。
7. 首次成功还要求 `P == 请求.期望事实代次`、`是否形成内存权威发布=true`、重试边界为 `不适用`；否则 `内部不一致`。精确重复允许 P 高于原期望，但要求发布标志 false、重试边界为 `原幂等键读回收敛`。
8. 按本地键 1—6 取得六编码，调用 §7 helper，并把 `写入.事实代次` 作为首次共同创建代次约束。只有读回完整才更新 `登记_`。
9. 若已有 `登记_` 的六编码与新读回不同，返回 `内部不一致`，不得覆盖定位缓存。否则首次成功和精确重复统一返回 `已比较` 并携带当前读回登记。
10. `std::bad_alloc` 返回 `资源失败`；其它未知异常返回 `内部不一致`。

### 5.1 顺序矩阵

| 场景 | L1 最终裁决 | M01 结果 |
| --- | --- | --- |
| 新键，P 等于期望且提交时仍同代 | 成功并发布六节点 | 权威读回后 `已比较` |
| 原请求精确重复，当前代次已高于原期望 | 精确重复，复用首次六编码 | 不被 P 提前阻断；读回后 `已比较` |
| 同键、同六节点但只更换期望代次 | 完整请求不同，幂等冲突 | `入口拒绝`，保持旧公开状态集合 |
| 新键，P 已不等于期望 | 事实代次漂移 | `版本漂移` |
| 新键，P 相等但提交前发生竞争发布 | 事实代次漂移 | `版本漂移` |

## 6. 状态映射

### 6.1 中性写入

| L1 中性写入状态 | `特征比较状态` | 登记 |
| --- | --- | --- |
| 成功、精确重复 | `已比较` | 仅成功合同与 §7 读回完成后携带 |
| 事实代次漂移 | `版本漂移` | 空 |
| 幂等冲突、入口拒绝 | `入口拒绝` | 空 |
| 资源失败 | `资源失败` | 空 |
| 内部不一致 | `内部不一致` | 空 |
| 未找到、已退出 | `内部不一致` | 空；本固定新建写集无既有事实引用，该返回与合同矛盾 |

### 6.2 中性读取

- 未找到、已退出、属性未设置：`未注册`。
- 资源失败：`资源失败`。
- 合同、回显、形状或内部状态矛盾：`内部不一致`。
- G0、节点读取代次、G1 不同：`版本漂移`。
- 由服务内部构造的合法读取请求若被 L1 返回入口拒绝：`内部不一致`，不得伪装成调用方入口错误。

## 7. 六稳定编码权威当前读回

共享私有 helper 接受六编码和可选首次共同创建代次：

1. 六编码必须有效且两两不同；可选首次创建代次若存在则非零。
2. 调用 `读取中性当前事实代次` 得到 G0；合同正确、状态成功且 G0 非零。
3. 依本地键 1—6 顺序各调用一次 `读取中性当前节点`。每项必须满足：合同版本正确、查询编码回显一致、读取事实代次等于 G0、事实存在、事实编码一致、未退出、当前属性为空，并符合 §4 节点种类/表示。
4. 六节点创建代次均非零、不晚于 G0 且彼此相等。建立登记传入首次发布代次时，共同创建代次还必须等于 `写入.事实代次`。
5. 再读当前事实代次 G1；合同正确、状态成功、G1 非零且等于 G0。任一读取代次与 G0 不同返回 `版本漂移`，不返回混代登记。
6. 组装现有 `特征比较登记`：`事实截止代次=G0`，其余字段按键 1—6；通过既有 `登记完整` 后返回 `已比较`。

`写入.事实代次` 是首次发布代次；登记的 `事实截止代次` 是本次当前读回 G0。精确重复或后续读取时 G0 可以高于首次发布代次，不得强制两者相等。

`读取当前登记()` 在持锁和异常边界内复制 `登记_` 的六编码；缓存缺失或不完整返回 `未注册`，否则调用同一 helper且不传首次创建代次。它不得返回缓存中的旧 `事实截止代次`。
