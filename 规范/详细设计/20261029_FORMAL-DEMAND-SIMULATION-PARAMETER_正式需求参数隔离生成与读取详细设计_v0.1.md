## 1. 本叶目的与边界

本叶不是本能函数实现，不改变现实存在、任务虚拟存在或方法虚拟存在的业务特征值。它让通用参数生成器将“存在＝正式需求根”的参数落实为本次模拟 owner 管理的真实需求节点 D，并由现成方法参数场景工厂正确绑定、读取。创建的实例与引用限于模拟样例，现实来源只能单向复制。

必须同时交付生成、裁剪重映射、落图、按位绑定、正式 owner 读取及现有消费者接线，不能只交付孤立 reader。仅支持正式需求根的精确范围身份，不宣称任意需求子概念、任务、方法或全部信息类型已支持。

现有 `新模拟需求输入图` 要求完整目标、主体和目标普通存在，以及相应来源图。本叶保持这个合同：可以生成或复制完整 D；不支持空白/部分 D，也不把其缺项补造为完整。根范围表示参数的合法类别，不要求生成的每个实例都不完整。有限构造闭包没有候选，只表示该模拟规格目前没有可用输入，不能推出需求概念没有实例。

明确排除：本能 writer／`获取需求运行接口`、本能函数改写、结果概念解读、条件结果对 C/R 抽象及发表、T 的生成或召回、筹办首次建立空白 D、现实服务需求挂接。现有学习服务在结果声明阶段仍可能因“完整被认知需求”不是 FT 而报告未支持；本叶不绕过它，也不以本叶完工声称模拟学习已经完成。

### 3.1 独立 D 参数输入

在 `新模拟有序参数输入` 结构末尾追加，不改旧聚合初始化位置：

```cpp
// 参数本体引用本次需求图的D；不是F.current引用。
std::uint32_t 需求参数输入 = 0;
```

非零只能用于信息类型为存在、范围恰为正式需求根的槽；值为 `需求图.需求组` 的序号，不是任何世界的稳定编码。该槽必须非零。普通 E/F 槽必须为零。原 `引用需求输入` 保持 F.current 语义，D槽必须为零。D槽不得同时填写所属普通 E、普通存在引用/集合/历史引用、普通材料/值、来源任务成员、语言场景所属/引用或普通存在构造范围等异类字段；`同一参数` 仍可用，`复制上下文` 可保留实际来源标志，实际来源身份由需求图来源索引维护。

### 3.2 方法 owner 的精确只读薄口

在方法类现有模拟只读口邻近声明、定义：

```cpp
先天特征类型槽结果 读取模拟先天特征类型槽(
    std::uint32_t 语义序号) const noexcept;
```

函数体仅返回 `特征概念服务_.读取先天特征类型槽(语义序号)`，状态、类型根及完整保护原样保留；不筛结果、不将失败转空成功、不建立概念、不缓存新权威。允许消费者仅为模拟 world 正式参数读取和本叶必要读回。包含类型沿方法头现有依赖复用。

### 3.3 world 的正式 owner reader

```cpp
正式信息参数读取结果 读取正式信息参数保护(

```

复用既有 `正式信息参数读取结果`，不扩枚举或改变场景 ABI。内部分类、候选序号轴、局部投影 helper 均在两 cpp 的既有实现/匿名命名空间，最小可见性；不新增公共生成服务。

## 4. D 与普通 E 的分类及全循环迁移

固定规格的类别由正式 owner 判断，不按名字、编码区间、参数邻接或“唯一人类”猜。学习服务及 world 各在本次调用生成一致的内部分类表：普通 E、正式 D、F。正式信息范围只有根 D 被接纳，其它仍规格未支持；正式定义变化走现有漂移路径。追加的来源/概念原型也必须显式属于普通 E 或 F，不能因 `defs[i]` 为空就视为普通 E。

以下为必须逐项迁移的检查表；位置行号仅作定位，不是合同：

| 处理位置 | 普通 E | 正式 D |
| --- | --- | --- |
| 规格、别名、范围收窄（服务约405起；world1119起） | 原普通范围及专属原型算法 | 根D精确身份，不走普通存在范围/构造范围 |
| 初始存在条件、附属F（服务438/512；world1140/1196） | 原条件和附属特征展开 | 只支持参数存在条件明确为根D；内容条件、附属F条件等仍未支持，不当普通E处理 |
| 来源存在复制、主体/目标候选（服务746/1108） | 正式普通E原型 | 不作来源E、D主体或目标E候选 |
| 引用及集合候选（服务1285；world1431/1478/1795） | 普通E引用只指普通E | 不进入普通E集合、历史引用、F所属或语言场景普通成员 |
| 场景关系及场景参数（world1301起） | 维持既有场景/成员算法 | 不充当场景或普通场景成员；不新增场景父子边 |
| 节点分配与绑定（world1315/1442/1745） | 原E分配与归属 | 使用需求图已分配D节点，不重复建E；有序引用类型仍为存在，信息节点为本地D |
| 需求图裁剪与重映射（服务1368/1418） | 原关系 | 新字段作为D根，闭包及序号同步重映射 |
| 读取记录和C/R前段（服务1592及后续） | 原普通附属快照 | 不调用普通E附属读口，不把D当普通E抽象；已有正式内容/C-R未支持边界保留 |

world 内 `实现::是本地参数(n,存在)` 的旧“枚举相同”不足以判断普通 E。对主体、目标、理解来源/目标、要求来源/目标、语言场景成员/边界等全部普通E调用改用内部普通E谓词；其依据为已登记本地参数分类且非本地需求身份，不能只靠“不是D”接受其它异类。D绑定登记在通用参数索引，但不能因此取得普通E资格。

同一关系先校验信息类型，再校验内部类别。D/E 同一为输入不合法；D/D 同一共享一个需求选择轴和本地节点；F等原有别名算法不改。别名输入一致性须加入 `需求参数输入`。所有原按 `信息类型==存在`、`!defs[i]`、原型数组或通用参数枚举分类的循环，施工时逐一核对上表，不只改最早拒绝处。

涉及D的非同一/不同关系（尤其现行“特征引用存在”、场景包含等）仍规格未支持；本叶不将其含义扩展到需求引用，不通过隐含相等偷偷满足。没有声明的 H/D主体等关系不靠位置推定，候选按正式概念合法生成，函数自己的必要检查保持原职责。

## 5. 候选、组合及无候选合同

1. 发现根D参数后，允许进入已有需求图采集/构造流程；将其纳入“需要需求构造”触发，不要求另有一个需求引用F。根D参数候选列表与F.current候选列表分开维护，元素均为需求图序号。
2. 复制候选限于现有正式来源闭包已采集的合法完整D，使用现成业务来源owner及完整保护。该集合不是全仓枚举。源D不完整、引用内容目标或其它现有图不能表达的内容，保留明确未支持；不丢字段冒充复制完成。
3. 构造候选复用正式需求根、值/方向/被认知子概念及已有活动/执行域/权重等正式范围；主体从合法人类普通E原型取，目标从普通E原型取，目标FT从其正式附属FT闭包取，值从其合法域取。原已有构造要求合法I64 FT的能力边界保留，没有该FT时不新造无依据FT。允许复用已复制完整D；若其候选已足够，不因备用构造支路不具备材料而覆盖成功候选。自建D仍真实建立D/U/C/R/L，不伪造方法执行结果。
4. 构造循环不再只以需求引用F为输出槽；同一正式候选图可以供多个D参数选择，不为每槽复制一份内容。对每个D代表参数建立独立选择轴；非别名允许选择同一D，除非声明了不同关系。`生成通用模拟枚举候选`只对合法序号采样/重排，不抽取稳定编码。
5. 同一簇先合并；D/D不同约束在当前组合选出序号后、裁剪/落图前按实际选中D序号判断，不以“代表位置不同”冒充节点不同。相同则跳过该组合并推进游标。D/E不同由类别不相交自然成立；同一和不同自相矛盾按现有输入不合法路径报告。world再核实际D序号/本地身份，不能仅核代表位置。
6. 每个D槽的候选先去重。未有任何合法完整D候选时，`不支持(位置,具体原因)`，对应现有 `新学习运行异常原因::规格未支持`；原因区分无来源候选、构造闭包缺人类/目标FT及图形状未支持，不能作为方法业务否定结果。已有合法候选但所有组合均被显式关系排除，沿现行“本支无合法样例”的 `输入不合法` 路径；不发表空条件结果对。
7. 组合赋值时仅给D槽写新字段；F.current仍写旧字段。`选择需求图`把两字段分别作为D根，保留父D、U/C/R/L及它们的引用闭包；裁剪后两个字段分别按D映射重排，D主体/目标仍按原普通E映射重排，所有源实例引用变成本地引用。复制来源身份只作溯源，不能成为模拟可写引用。

## 6. world 落图、真实绑定与读回

建立有序样例时，先核方法/固定规格/分类/别名和输入图完整性；再复用既有准备、原子追加、正式保护提交及失败清理。D由需求图prepare统一分配，直接参数用相同D序号resolver取本地D。普通E分配列表、普通场景成员及构造范围读回不包含D；不得为D套普通E类型字段。

绑定保留每个固定参数位置，不改变规格序号/范围。有序引用为 `{位置,存在,本地D}`；世界场景定位为本次模拟样例场景，仅表示调用owner上下文，不表示D作为普通成员进入该场景。`实际存在节点`等旧业务封套保持新格式原合同，不填假普通E。相同D的多个位置都保留。

`内容参数位置`从直接D根传播其D/U/C/R/L闭包，同时保留既有F引用D传播。已复制D及关联内容实际读取时，沿原 `记录内容` 和复制上下文标志登记，不能漏掉隐性依赖。建立样例后的全图读回及方法场景工厂的调用前校验在实际调用窗之外，不计作本能函数的实际读取。

完整样例发表后，对直接D槽用新reader逐个读回，确认节点身份、根类别及15项投影一致。随后现成 `新_方法类::建立模拟参数场景` 正式分支应能消费同owner投影，不能新增独立测试工厂或用现实需求owner替代。当前writer仍未装配，不能因此授予执行写权。

## 7. 正式reader：投影、保护和fresh顺序

### 7.1 身份与保护算法

1. 先经M读取先天信息概念组和根D正式结构，确认范围恰为该根。依赖未就绪/未找到映依赖未就绪，前提变化映前提已变化，其他范围映范围未支持。不能以范围未支持掩盖已登记D的稳定结构损坏。
2. 持world既有递归互斥，确认当前样例有效、N为本地需求索引成员。未建立样例、无效N或非本地D返回信息不存在。已登记D却无节点或类型/owner损坏走工程链；禁止回调现实D reader“试试看”。固定当前样例场景、方法、本地节点身份列表和本地D/U/C/R/L来源索引。
3. 首版保护上界固定为本次样例全部 `通用节点` 的当前完整联合快照，加其字段实际引用的共享端点完整联合快照；字段关系/外部关系本身包含在完整联合快照，不把关系编码当节点查询。共享端点只取这一跳，不按概念入向遍历世界，不纳入仅保存在内存来源索引中的现实源D/E。凡本地字段按现图合同必须指本地而实际指外界，沿既有reader报结构损坏，不能靠加入保护让越界合法化。捕获前后样例身份集合必须一致。此上界是有限保守保护，非跨调用锁定或全世界快照。
4. 在该样例锁内调用既有 `读取模拟需求(N)` 正式重建并校验D；按既有本地reader核必要U/C/R/L身份和关系一致性，不直接信任输入图DTO。输出只从重建结果取得。首版图已完整，因此无法表达的部分内容不填默认值。原实际调用读取记录沿原入口保留。
5. 释放world锁后，使用M先天槽薄口fresh取得下表15个不同FT及完整保护，重读根D正式结构与先天根身份。成功结果必须有类型根和非空保护；值不存在/读取接口未装配映依赖未就绪，前提变化映前提已变化，资源失败映资源失败，其它稳定异常走工程链。按节点合并全部保护，同节点快照不同返回前提已变化。
6. **只能使用样例已落图后的fresh定义保护。** `需求图.正式定义保护` 只服务落图前原子提交，不得把它复用到reader返回：落图本身会给概念增加合法入向。这里不忽略当前入向、不缩减正式owner返回保护，也不按编码删除冲突以假装核同。
7. 重入world锁，核固定样例、全部身份/来源索引及本地节点列表仍同，重新读取本次D并比较值投影、重新捕获第3步保护。释放锁后，完整核第5步正式保护及全部端点/本地联合快照仍同；任意真实变化返回前提已变化。缺失若来自释放/替换同样返回变化；未变化下的稳定坏结构走工程链。最后返回当前投影与合并完整保护，不返回落图前的旧保护。

不持world锁调用M/FC跨owner读口，不反入任务/self，不引入外部生命周期租约；M薄口也不反入world。样例锁只保护本地索引和读过程，L1完整保护解决跨调用一致性。返回后消费者仍按既有factory/scene规则fresh核保护；不承诺无限期有效。

### 7.2 15项投影合同

根FT身份只来自 `先天特征类型槽` 常量对应的正式owner结果，不从模板序号或名称猜。投影固定每槽一项，共15项，无重复FT；`信息节点=N`、`类别概念=正式需求根`。

| 槽 | 正式内容种类 | 值来源 |
| --- | --- | --- |
| 需求主体 | 存在引用 | 本地D主体普通E |
| 需求执行域 | I64数值 | 本地D执行域枚举 |
| 需求目标存在 | 存在引用 | 本地D目标普通E |
| 需求目标FT | 概念引用 | 本地D目标正式FT |
| 需求目标形式 | I64数值 | 本地D目标形式 |
| 需求权重 | I64数值 | 本地D权重 |
| 需求活动 | I64数值 | 本地D活动状态 |
| 目标域 | 概念引用 | 值目标的正式域；方向目标不适用 |
| 目标比较 | 概念引用 | 值目标的正式比较；方向目标不适用 |
| 目标方向 | I64数值 | 方向目标的方向；值目标不适用 |
| 父需求 | 需求引用 | 本地父D；被认知或自我根不适用 |
| 需求来源 | I64数值 | 来源类型；被认知或自我根不适用 |
| 需求根角色 | I64数值 | 实有根角色，否则不适用 |
