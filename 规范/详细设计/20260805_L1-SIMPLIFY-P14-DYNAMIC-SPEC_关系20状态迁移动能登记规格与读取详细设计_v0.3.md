## 1. 裁决与范围

本版本只补齐 P14 关系20登记入口接入当前 L1 v2 的公开请求、领域意图、预探测、
首次结果和执行证据合同。P13 v0.2、P12 v0.4、关系20语义、`0x44` 纯值规格、
十五项独立读取、顺序390及 v0.2 的八路径范围保持不变。

P14 的机器事实所有者是独立的状态迁移动能领域，不是 G8 比较器，也不是 P78 的
动态因果领域。依据 4200 §4.3、§7.8，关系20 状态迁移动能是状态动态入口的类型化
结果，故其唯一领域意图组归入既有 G7 状态/状态动态族，固定为 **G7、入口变体3**；
不占用 G9。G7 已有 T01/T02 仍分别使用各自既有标签，P14 不复用它们的标签。
P78 当前未跟踪设计保留 G9 作为动态因果领域；P14 不修改其核心扩展、不依赖其发布。

P14 登记操作标签固定为 `0x15000F01U`，只属于 `L1动态服务::建立登记`；
私有 L1 幂等域固定为 `0x0F`。G7 组相同不表示与 T01/T02 共享幂等域、DTO 或摘要。
P14 不使用 G0 作为领域身份，不把 G0 规范化写集摘要冒充领域请求意图摘要。

本版本不修改 P12/P13、P15、L1 核心、P78、P16、恢复材料、崩溃/重启/跨进程恢复、
SQL、日志或其它 WIP。

## 3. 入口身份与写入/纯值分账

| 入口 | 机器职责 | L1写集 | 意图/幂等 | provider与提交计数 |
| --- | --- | --- | --- | --- |
| `L1动态服务::建立登记(const L1动态登记请求&)` | 登记关系20所需服务、关系和八个属性类型 | 真实写入十节点，零关系/值/槽/退出 | G7组、变体3、`0x15000F01`、域`0x0F` | 首次 `探测1/提交1`；同义/异义均 `0/0`；外部领域provider为0 |
| `L1动态服务::读取当前登记() const` | 逐项读回十个登记节点 | 0 | 不形成领域意图 | L1读取十项；领域provider/提交 `0/0` |
| `L1动态服务::形成状态迁移动能规格(const 实际存在I64后继状态规格结果&) const` | 只消费 P13 值式结果形成 `0x44` 纯值规格 | 0 | 纯值 G0 互证，不探测 | provider/提交 `0/0` |

P14 只在登记入口拥有一次 L1 写入。

## 4. P14 登记 DTO、版本、幂等与结果

P14 领域公开 DTO 只携带登记请求的业务字段，不携带 L1 仓库、锁、许可、本地键、
稳定编码或 provider 返回：

```cpp
inline constexpr std::uint32_t L1动态合同版本 = 1;
inline constexpr std::uint32_t L1动态规则版本 = 1;
inline constexpr std::uint64_t L1动态登记幂等域 = 0x0FULL;
inline constexpr std::uint32_t L1动态登记操作标签 = 0x15000F01U;
inline constexpr std::uint8_t L1动态登记意图组 = 7;
inline constexpr std::uint8_t L1动态登记入口变体 = 3;

struct 动态操作幂等身份 final { std::uint64_t 值 = 0; };

struct L1动态登记请求 final {
    std::uint32_t 合同版本 = L1动态合同版本;
    std::uint32_t 规则版本 = L1动态规则版本;
    动态操作幂等身份 幂等身份;
    std::uint64_t 期望事实代次 = 0;
};
```

L1 幂等键唯一映射为：`(0x0F << 56) | 幂等身份.值`。请求有效条件是合同/规则
精确为1、身份非零且不超过56位、期望事实代次等于当前完整快照代次且不为0；
P14 登记不走空仓模式，避免在 P14 白名单外修改 L1 核心的空仓标签表。

登记写集固定十个节点，写集本地键及形状为：

| 本地键 | 节点/属性类型 |
| --- | --- |
| 1 | 普通动态服务身份 |
| 2 | 普通关系20类型 |
| 3 | I64 动态资格属性类型 |
| 4 | I64 动态种类属性类型 |
| 5 | I64 聚合规则版本属性类型 |
| 6 | U64组时间范围属性类型 |
| 7 | U64组迁移比较合同属性类型 |
| 8 | I64迁移差异属性类型 |
| 9 | U64组比较输入引用属性类型 |
| 10 | I64组比较输入材料属性类型 |

关系、值、属性槽、退出均为空；每个键必须映射唯一非零稳定编码，十项互异。

首次成功或精确重复的结果 DTO 固定为：

```cpp
struct L1动态结构登记 final {
    动态操作幂等身份 首次幂等身份;
    std::uint64_t 事实截止代次 = 0;
    稳定编码 服务身份;
    稳定编码 关系20动态组成关系类型;
    稳定编码 动态资格属性类型;
    稳定编码 动态种类属性类型;
    稳定编码 聚合规则版本属性类型;
    稳定编码 时间范围属性类型;
    稳定编码 迁移比较合同属性类型;
    稳定编码 迁移差异I64属性类型;
    稳定编码 比较输入引用属性类型;
    稳定编码 比较输入I64组属性类型;
};
enum class L1动态状态 : std::uint8_t {
    已登记=1, 已读取=2, 已形成=3, 无需形成=4, 禁止形成=5,
    登记未加载=6, 入口拒绝=7, 未找到=8, 幂等冲突=9,
    版本漂移=10, 许可拒绝=11, 资源失败=12, 内部不一致=13
};
struct L1动态登记结果 final {
    L1动态状态 状态 = L1动态状态::入口拒绝;
    std::optional<L1动态结构登记> 登记;
};
```

L1 `成功`/`精确重复` 必须在同一事实代次逐项读回十项后才能形成 `已登记`/`幂等读回`。
`幂等冲突`、入口拒绝、版本漂移、资源失败和内部不一致都返回空登记。

## 5. G7 领域意图、公开字段顺序与测试向量

登记意图摘要唯一编码为以下声明顺序；所有 U32/U64 为现有大端写入，ASCII 为原始
固定字节，不写长度和 NUL：

```text
ASCII "HZY-L1G7"
→ U32 请求意图格式版本 = 1
→ U32 业务操作标签 = 0x15000F01
→ U8 入口变体 = 3
→ U32 P14领域合同版本 = 1
→ U32 P14领域规则版本 = 1
→ U64 动态操作幂等身份
→ U64 期望事实代次
→ SHA-256 = L1领域意图凭证.请求意图摘要
```

凭证固定为 `{请求意图组=7, 请求意图格式版本=1, 请求意图操作标签=0x15000F01,
请求意图摘要=上述摘要, 领域结果计划摘要=全零}`。G7 T01/T02 的标签和字段不被
P14 复用；G8 和 G9 亦不被 P14 混入。

可复现测试向量（身份1、期望代次0，仅用于摘要纯值测试）：

```text
字节：48 5A 59 2D 4C 31 47 37
      00 00 00 01 15 00 0F 01 03
      00 00 00 01 00 00 00 01
      00 00 00 00 00 00 00 01
      00 00 00 00 00 00 00 00
SHA-256：dce2fa27b2cf2c92eacded983ae3b3e5b3e45fd14470841c1a64f5bcd0155b53
```

provider 前只允许先调用一次 `探测幂等`。未找到后读取 L1 当前完整快照并构造上述
十节点写集；不得先调用 P13/P12/P11 或任何动态/因果 provider。

## 6. 执行证据、模式与失败矩阵

P14 首次登记在非空、已发布 L1 基线上执行，固定使用 `L1执行证据模式::事实互证`：
L1 核心 provider 版本见证为 `0x4C31464200000001`、合同2、规则0、调用1；写前
事实见证取完整快照中按对象种类再按稳定编码升序的首项，观察代次等于共同截止。
P14 领域外部 provider 组和调用数为0。空仓纯 G0 与空仓领域首次模式均禁止，避免
扩展 L1 核心空仓标签并改变 P15 既有边界。

| 阶段 | 可检测事实 | 固定结果 | 候选/交换 |
| --- | --- | --- | --- |
| 锁前请求/意图/幂等键非法 | 合同、规则、身份、期望代次或摘要不合法 | `入口拒绝` | 不形成候选 |
| 探测 | 同键同摘要 | `幂等读回`，原登记 | provider/提交 `0/0` |
| 探测 | 同键不同摘要 | `幂等冲突` | 不形成候选、`0/0` |
| 探测 | 已隔离/内部不一致/未知状态 | 对应拒绝或内部不一致 | 不形成候选 |
| 未找到后读快照 | 代次不等、快照损坏或首项不可形成见证 | `版本漂移`/`内部不一致`/`资源失败` | 不交换 |
| 候选构造 | 十项形状、类型、键或证据不一致 | `内部不一致` | 候选不交换 |
| L1提交 | 成功/精确重复 | `已登记`/`幂等读回` | 仅一次交换；随后十项权威读回 |
| 交换后读回 | 任一键、类型、代次或数量矛盾 | `内部不一致` | 已发布事实保留并隔离，禁止二次补写 |

首次结果中的十项映射、发布代次、幂等键和执行证据只来自同一次 L1 候选/读回；
同义重试原样返回首次登记，不按当前快照重算。恢复材料不属于本目标。

## 7. 纯值规格与读取保持 v0.2

`形成状态迁移动能规格` 只消费 P13 v0.2 `已形成` 结果：无前态、等价/禁止和任何
非成功均零规格；仅非等价增加/减少、差异非零且迁移证据完整时形成 `0x44` 一节点、
八值、六关系、八槽，关系20角色1—5/9，角色6—8为空，角色5单向引用 `0x53000001`。
该函数不使用 G7 领域意图、幂等域、provider 或 L1 写集。

`读取状态迁移动能` 只按十五个已发布稳定编码读取当前/历史，G0/G1 同代次才成功，
一次完整重试仍漂移返回 `版本漂移`；不调用 P11、缓存、SQL、日志或恢复材料。
