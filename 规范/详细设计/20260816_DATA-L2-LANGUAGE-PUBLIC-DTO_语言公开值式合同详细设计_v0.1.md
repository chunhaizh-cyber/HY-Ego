# DATA-L2 语言公开值式合同详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-LANGUAGE-PUBLIC-DTO`

## 1. 目标与完成边界

为 `DATA-EXT-10` 的语言部分冻结唯一公开值式合同，使后继 `L2语言结构服务` 可以机械实现语言新增、替换、退出、按身份读取和按登记键读取，而无需临场决定字段、生命周期、读取截止或成功载荷形状。

本叶只新增传统数据结构头 `海中鱼巣/领域/L2语言结构.数据.h` 并登记根工程；不建立服务、owner、普通应用装配、词条、概念名称、语言记录、语素或词性，不写任何机器事实。完成只证明 DTO ABI 可编译消费，不证明 `DATA-EXT-10` 已实现。

## 4. 精确 ABI

头文件依赖固定为 `<cstdint>`、`<optional>`、`L2结构公共.数据.h` 和 `不可变材料.数据.h`。所有类型位于 `namespace 海中鱼巣`，字段顺序如下，均保留逐字段默认相等：

```cpp
inline constexpr std::uint32_t L2语言结构合同版本 = 1;

struct L2语言登记键 final {
    不可变材料身份 材料;
    friend bool operator==(const L2语言登记键&,
        const L2语言登记键&) = default;
};

struct L2语言登记键事实 final {
    L2语言身份 语言;
    L2语言登记键 登记键;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(const L2语言登记键事实&,
        const L2语言登记键事实&) = default;
};

struct L2语言来源事实 final {
    L2语言身份 语言;
    不可变材料身份 来源材料;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(const L2语言来源事实&,
        const L2语言来源事实&) = default;
};

struct L2语言事实 final {
    L2语言身份 语言;
    L2节点族身份来源事实 身份来源;
    L2语言登记键事实 登记键;
    L2语言来源事实 来源;
    L2生命周期 生命周期;
    friend bool operator==(const L2语言事实&,
        const L2语言事实&) = default;
};
```

`L2语言事实::生命周期` 是语言节点生命周期的公开简明回显，必须逐字段等于 `身份来源.节点生命周期`；它不是第二生命周期权威。登记键关系、来源关系、语言节点和族归属关系由同一语言 owner 写集同时创建，退出时在同一提交截止同时退出。owner、族锚点和关系类型自身保持活动。

### 4.1 写请求

```cpp
struct L2语言新增请求 final {
    L2结构请求头 请求头;
    std::uint32_t 语言合同版本 = L2语言结构合同版本;
    L2结构幂等身份 幂等身份;
    L2语言登记键 登记键;
    不可变材料身份 来源材料;
    friend bool operator==(const L2语言新增请求&,
        const L2语言新增请求&) = default;
};

struct L2语言替换请求 final {
    L2结构请求头 请求头;
    std::uint32_t 语言合同版本 = L2语言结构合同版本;
    L2结构幂等身份 幂等身份;
    L2语言身份 旧语言;
    L2语言登记键 旧登记键;
    不可变材料身份 旧来源材料;
    L2语言登记键 新登记键;
    不可变材料身份 新来源材料;
    friend bool operator==(const L2语言替换请求&,
        const L2语言替换请求&) = default;
};

struct L2语言退出请求 final {
    L2结构请求头 请求头;
    std::uint32_t 语言合同版本 = L2语言结构合同版本;
    L2结构幂等身份 幂等身份;
    L2语言身份 语言;
    L2语言登记键 登记键;
    不可变材料身份 来源材料;
    friend bool operator==(const L2语言退出请求&,
        const L2语言退出请求&) = default;
};
```

三个写请求都要求合同版本精确、非零期望事实代次、非零幂等身份、非零材料身份。替换请求还要求旧语言非零，且“旧登记键 + 旧来源材料”与“新登记键 + 新来源材料”不完全相同；新语言身份由唯一语言 owner 在原子提交中分配，必须与旧身份不同。相同登记键可以在同一替换事务中从旧身份交接给新身份，但提交截止上至多一个当前语言。

### 4.2 读请求

```cpp
struct L2语言读取请求 final {
    L2结构请求头 请求头;
    std::uint32_t 语言合同版本 = L2语言结构合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    L2语言身份 语言;
    std::uint64_t 历史截止事实代次 = 0;
    friend bool operator==(const L2语言读取请求&,
        const L2语言读取请求&) = default;
};

struct L2语言按登记键读取请求 final {
    L2结构请求头 请求头;
    std::uint32_t 语言合同版本 = L2语言结构合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    L2语言登记键 登记键;
    std::uint64_t 历史截止事实代次 = 0;
    friend bool operator==(const L2语言按登记键读取请求&,
        const L2语言按登记键读取请求&) = default;
};
```

两类读取均要求非零期望事实代次。当前读取固定 `历史截止事实代次=0`，成功截止精确等于请求守卫；历史读取固定非零历史截止且 `历史截止 <= 期望事实代次`，成功截止精确等于显式历史截止。

按身份历史读取返回该身份在显式截止内可证明的完整记录，可以回显已经退出的历史身份。按登记键历史读取是“该截止上当前语言”的唯一选择，不是枚举该键全部历史身份；成功载荷在该历史投影中必须未退出。完整历史枚举不属于 v1。

### 4.3 结果

```cpp
struct L2语言新增结果 final {
    L2结构结果头 结果头;
    std::optional<L2语言事实> 当前语言;
    bool 成功() const noexcept;
    friend bool operator==(const L2语言新增结果&,
        const L2语言新增结果&) = default;
};

struct L2语言替换结果 final {
    L2结构结果头 结果头;
    std::optional<L2语言事实> 当前语言;
    std::optional<L2语言事实> 已退出语言;
    bool 成功() const noexcept;
    friend bool operator==(const L2语言替换结果&,
        const L2语言替换结果&) = default;
};

struct L2语言退出结果 final {
    L2结构结果头 结果头;
    std::optional<L2语言事实> 已退出语言;
    bool 成功() const noexcept;
    friend bool operator==(const L2语言退出结果&,
        const L2语言退出结果&) = default;
};

struct L2语言读取结果 final {
    L2结构结果头 结果头;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    std::optional<L2语言事实> 语言;
    bool 成功() const noexcept;
    friend bool operator==(const L2语言读取结果&,
        const L2语言读取结果&) = default;
};

struct L2语言按登记键读取结果 final {
    L2结构结果头 结果头;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    std::optional<L2语言事实> 语言;
    bool 成功() const noexcept;
    friend bool operator==(const L2语言按登记键读取结果&,
        const L2语言按登记键读取结果&) = default;
};
```

分开新增、替换和退出结果，避免一个通用结果无法机械证明操作形状。写成功只接受 `已提交` 或 `精确重复`，要求非零截止、`变更事实代次 == 事实截止代次`，且：

- 新增：只携带一个未退出当前语言，其创建代次等于提交截止；
- 替换：同时携带新当前语言和旧退出语言，新旧身份不同，新语言创建代次和旧语言退出代次均等于提交截止；
- 退出：只携带一个退出语言，其退出代次等于提交截止。

读成功只接受 `已读取`、非零截止、无变更代次和一个完整语言。当前读的语言必须未退出；历史按身份读取可回显截止内已退出事实；历史按登记键读取的所选语言必须在该历史投影上未退出。

任一非成功结果的所有 `optional` 必须为空、`变更事实代次` 必须为空，不得改变权威事实。携带半结构、错误身份、错误截止或错误操作形状只能判为内部不一致。

## 5. 纯值 helper 合同

数据头公开以下 helper，全部 `inline bool ... noexcept`：

```text
L2语言登记键有效
L2语言事实完整
L2语言新增请求有效
L2语言替换请求有效
L2语言退出请求有效
L2语言读取请求有效
L2语言按登记键读取请求有效
L2语言新增结果::成功
L2语言替换结果::成功
L2语言退出结果::成功
L2语言读取结果::成功
L2语言按登记键读取结果::成功
```

`L2语言事实完整(事实, 截止)` 至少机械证明：

1. 截止、语言身份、登记键材料、来源材料、两个关系编码均非零；两个关系编码互异；
2. 身份来源完整、节点族为语言、节点编码等于语言身份；
3. 登记键事实和来源事实都指向同一语言；
4. 公开生命周期等于身份来源节点生命周期、族归属关系生命周期、登记键关系生命周期和来源关系生命周期；
5. 创建代次非零且不晚于截止；退出代次若存在，不早于创建且不晚于截止；
6. owner、族锚点和关系类型生命周期在该投影中仍活动。

helper 只能证明值式形状，不能证明材料真实存在、内容严格 UTF-8、同键唯一、owner 同址或事务已经发布；这些必须由后继服务在同一 L1 许可内通过正式提供者证明。

## 6. 后继服务必须遵守的事务与材料门禁

本 DTO 公开面冻结以下服务级后置条件，后继实现不得改写：

1. 语言 owner 唯一拥有语言节点、族归属、登记键和来源关系；材料节点仍由不可变材料 owner 拥有，语言服务只读引用。
2. 写前和正式读回均通过现有 `不可变材料服务::读取不可变材料(...) const` 在同一非零截止完整读回登记键和来源。登记键材料必须为严格 UTF-8；来源材料可以使用该服务支持的正式格式。
3. 材料未找到、已退出、代次漂移、资源失败按原状态分账；材料形状与请求身份不一致、同截止回读矛盾或唯一键出现两个当前语言为内部不一致。
4. 同幂等身份同完整请求返回原成功结果；同幂等身份异义返回幂等冲突。另一个请求占用同一当前登记键返回引用冲突，不伪装精确重复。
5. 替换必须在一个语言 owner 事务中退出旧节点、旧族归属、旧登记键和旧来源关系，并建立新身份及其完整结构；发布前失败零变化，发布结果未知只允许原完整请求重放。
6. 退出在仍被当前词条、语言记录或其它已登记持久结构引用时返回引用冲突；不删除来源材料和历史语言事实。
7. `未找到`、`已退出`、`事实代次漂移`、`幂等冲突`、`引用冲突`、`资源失败` 和 `内部不一致` 保持不同结构化结果；不增加公共状态枚举。

状态裁决沿用 4230 的共同优先级，并在语言 v1 中固定为：

- 合同版本、零守卫、零幂等、零身份、零材料、坏读取类别或替换前后完全同义属于 `入口拒绝`；
- 期望代次不等于调用时当前代次属于 `事实代次漂移`，零变化、无首次结果且不绑定幂等身份；
- 按身份读取未知编码为 `未找到`，当前入口命中已退出语言为 `已退出`；按登记键在指定截止没有当前语言为 `未找到`，不得任选一个历史身份；
- 替换或退出请求中的旧登记键 / 旧来源材料与正式旧事实不符，以及其它请求已经占用同一当前登记键，属于 `引用冲突`；
- 当前语言仍有受保护引用时退出属于 `引用冲突`；同幂等身份异义属于 `幂等冲突`；
- 底层材料或 L1 明确资源失败、发布结果未知统一对外为 `资源失败`，但未知发布仍保留原完整请求重放；
- 同一截止出现双当前登记键、身份复义、关系混代、材料读回与身份不符、发布后成功载荷缺失或读回矛盾属于 `内部不一致`。

所有写成功截止必须严格晚于请求的非零期望代次；当前读成功截止必须等于请求守卫；历史读成功截止必须等于显式历史截止。精确重复返回首次请求的原结果和原变更截止，不再次推进代次。
