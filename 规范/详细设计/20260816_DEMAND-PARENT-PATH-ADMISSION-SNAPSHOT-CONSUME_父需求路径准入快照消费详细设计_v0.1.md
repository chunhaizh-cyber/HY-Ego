# DEMAND-PARENT-PATH-ADMISSION-SNAPSHOT-CONSUME 父需求路径准入快照消费详细设计 v0.1

日期：2026-08-16
状态：待激活设计

## 1. 目标与边界

本设计闭合 `BIZ-L5-004-02-01-04-01`：在一个调用方指定的非零事实截止 `G0` 下，一次读取从结构根到指定父需求的完整当前父链，以及每个父链节点用于后继路径准入裁决的全部中性结构材料。

本叶只读取和互证结构，不裁决：

```text
候选目标是否与父目标重叠
候选需求是否形成业务循环
路径角色是否合法
OR / AND 应怎样选择
父权重 W 的数值类型、W/n、余量归属或新增成员后的重分配
哪个路径应活动、结算或任务化
```

上述机器语义分别保留给 `BIZ-L5-004-02-01-04-02` 与 `BIZ-L5-004-02-01-04-03` 的后继裁决。旧 `BIZ-L4-004-02-01-04 v0.1` 的“无父根见证”和虚构“路径治理当前事实”退出：普通提交已经要求非零父需求，根需求只允许具名冷启动入口。

## 2. 正式依据与当前事实

- 0050：需求权重完整维度仍属未决，不能从旧材料补造。
- 3100：父子拓扑只表达展开；角色必须由目标语义、路径关系、承接方式、活动状态和相应特征共同裁决。
- 5100：逻辑组织使用普通需求、强类型目标和正式路径关系表达，不新增通用字段。
- 5110：路径组之间按 OR，确定 OR 路径内成员按 AND；父权重不得丢失；目标重叠和父子循环必须拒绝。
- 5150：逻辑上应存在的父需求、关系端点或状态损坏属于开发诊断，不得包装为普通业务拒绝。

当前正式代码只有公共 `L2需求身份`；没有 `L2需求结构服务`、需求结构 DTO、普通应用合法取得路径、`需求父路径准入快照.数据.h`、`服务.需求.ixx`或本函数。DATA-EXT-12 的本操作因此是预冻结公开消费需求，不是当前真实 ABI。

现有 `需求业务服务::读取需求父链与活动路径事实`只组合当前父关系与已发布活动子关系，且明确不读取父权重、全部路径关系和预算来源，不能替代本叶的完整准入快照。

```text
禁止依赖：L1、owner、仓库、DATA私有幂等账、缓存、SQL和第二需求服务
```

目标函数：

```cpp
需求父路径准入快照读取结果 需求业务服务::读取父需求路径准入快照(
    const 需求父路径准入快照读取请求& 请求) const noexcept;
```

## 5. 成功值式投影

下列结构名冻结 BIZ 语义身份；其中需求、父关系、直接子关系、路径关系、路径组、父权重和预算来源的最终成员类型与字段顺序，必须在 DATA-EXT-12 正式 ABI 发布后机械匹配，不得从旧设计发明：

```cpp
struct 父链当前需求项 final {
    当前需求值式事实 当前需求;
    std::optional<当前父需求关系值式事实> 当前父关系;
};

struct 逐父路径准入结构组 final {
    当前需求值式事实 父需求;
    std::vector<当前直接子需求结构事实> 全部当前直接子关系;
    std::vector<当前需求路径关系结构事实> 全部当前路径关系;
    std::vector<当前需求路径组结构事实> 全部当前路径组;
};

struct 需求父路径准入快照 final {
    std::uint64_t 需求树版本;
    std::vector<父链当前需求项> 根到父需求链;
    std::vector<逐父路径准入结构组> 逐父结构组;
    需求父权重结构事实 请求父需求当前权重;
    std::vector<需求路径预算来源结构事实> 请求父需求全部当前预算来源事实;
};

enum class 需求父路径准入快照读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    父需求未找到 = 3,
    父需求已退出 = 4,
    深度预算不足 = 5,
    直接子关系预算不足 = 6,
    路径关系预算不足 = 7,
    路径组预算不足 = 8,
    预算来源事实预算不足 = 9,
    当前性漂移 = 10,
    提供者拒绝 = 11,
    资源失败 = 12,

    内部不一致 = 14

struct 需求父路径准入快照读取结果 final {
    std::uint32_t 合同版本;
```

只有 `已读取`携带值且`事实截止 == G0`；全部非成功的值为空、事实截止为零。成功值必须完整、自包含、不可变，不暴露 DATA 结果对象或内部引用。

## 6. DATA-EXT-12 公开服务最终需求

唯一具名能力语义为：

```text
L2需求结构服务::按父需求与指定截止有界读取父链及当前路径准入材料
```

请求必须承载非零父需求、非零 `G0`、事实范围 / 需求范围 / 需求树 / 路径结构 / 路径当前性 / 权重事实 / 预算来源 / 读取规则版本，以及父链深度、直接子关系、路径关系、路径组、预算来源事实五项独立预算。

成功必须在一次公开调用中返回：

1. 非空、无重复、从无父结构根到请求父需求的完整当前父链；每项含完整当前需求、生命周期、目标语义材料和可空唯一当前父关系。
2. 与父链等长同序的逐父结构组；每组含该父全部当前直接子关系及完整子端点。
3. 每组全部当前路径关系、路径组、角色、显式顺序、当前性、生命周期和活动版本；不得只返回活动子集。
4. 仅请求父需求的一份唯一当前权重事实及其权威来源和版本；请求父需求全部当前路径预算来源事实。不得为了本叶额外读取祖先权重。
5. 请求版本、五项预算、共同 `G0`与每项事实截止；零截断、零重复、零混代。

“父权重事实”这里只要求 DATA 回显权威已存事实，不定义 `W` 的数值类型、范围、除法或余量算法。没有正式父权重和来源时不得伪造默认值；DATA 返回未实现或结构化失败，本计划继续待激活。

DATA 只作中性读取和结构校验，不返回候选重叠、候选成环、角色合法、OR / AND 选择、权重重分配、活动路径选择、结算或任务化结论。

## 7. 合法空与完整性

合法成功形状：

- 请求父需求自身是结构根时，父链仍有一项且根项父关系为空；这只是读取能力的通用形状，不恢复普通提交建立根。
- 某父节点没有直接子关系时，其直接子、路径关系和路径组均可为空。
- 请求父需求首次展开时可没有既有路径关系。
- 预算来源事实组可为空，但请求父需求自身的权威父权重及其来源不得缺失。

以下不是合法空：父链为空、父未找到 / 已退出、未到无父根、父关系半结构 / 错端点 / 重复身份、直接子存在但路径材料被截断、路径关系引用不存在的组或端点、父权重或来源缺失、混合 `G0`、版本冲突、重复或超预算。

## 8. 固定控制流

```text
校验固定配置自身完整且共同字段一致
-> 校验请求、父需求、G0和五预算
-> 逐字段匹配请求版本与固定配置
-> checked 构造一份 DATA 请求；运行代次不下传
-> 恰一次调用 DATA-EXT-12
-> 精确映射 DATA 非成功
-> 互证请求回显、G0、全部版本和预算
-> 互证父链非空、根到父、末项等于请求父需求且身份无重复
-> 互证根项父关系为空，其余父关系端点连接前一项
-> 互证逐父结构组与父链等长同序
-> 互证全部直接子、路径关系和路径组的端点、生命周期、版本和G0
-> 互证请求父需求唯一当前权重及其全部当前预算来源、版本和G0
-> checked 复核父链、直接子关系、路径关系、路径组和预算来源事实五类实际数量不超预算
-> 互证稳定排序、零重复、零截断
-> 一次构造不可变候选并无抛出交换
-> 返回已读取
```

固定为零自动重试、零 `G0` 重选、零缓存拼装、零分次 DATA 读取、零 L1 / owner / 仓库访问、零事实写入。

稳定顺序：父链使用权威根到父拓扑序；逐父结构组与父链同序；直接子按子需求稳定身份再按父子关系稳定身份；路径组按组稳定身份；路径关系按组稳定身份、显式顺序、子需求稳定身份、关系稳定身份；预算来源按强类型来源身份及关系稳定身份。禁止按显示名称、到达时间、容器原序或 enum 裸底值排序。

## 9. 状态映射与异常

| 下层或本地条件 | BIZ状态 | 守恒 |
| --- | --- | --- |
| 固定配置坏或共同字段冲突 | 内部不一致 | 零 DATA 调用，值空 |
| 请求坏、零父 / G0 / 任一预算、转换溢出 | 请求拒绝 | 零 DATA 调用，值空 |
| 合法请求版本与固定配置不等 | 当前性漂移 | 零 DATA 调用，值空 |
| DATA 明确“请求指定父需求”未找到 / 已退出 | 父需求未找到 / 父需求已退出 | 值空 |
| DATA 沿父关系展开时祖先未找到 / 已退出，或未区分失败对象 | 内部不一致 | 值空；不得降级成请求父业务状态 |
| DATA 某预算维度不足 | 对应五类预算不足 | 值空、零截断 |
| DATA 事实代次漂移或成功截止不等 G0 | 当前性漂移 | 值空、零重试 |
| DATA 许可拒绝 | 提供者拒绝 | 值空 |
| DATA 资源失败、`bad_alloc`、`length_error` | 资源失败 | 值空 |
| DATA 未实现 / 未装配 | 未实现 | 值空 |
| DATA 请求拒绝、引用冲突、断链、重复、坏成功形状、未知状态或其它异常 | 内部不一致 | 值空 |
| 完整成功 | 已读取 | `G0`和完整快照 |

既有父链自身出现重复或环属于已发布结构损坏，必须映射内部不一致；本叶不得把它包装成“候选成环”业务结论。

## 10. 并发、截止和失败守恒

调用方选择一个非零 `G0`，本叶从头到尾只使用该截止。DATA 必须在读取前后守卫 `G0`；并发发布导致漂移时返回当前性漂移，BIZ 不自动重读、不选择新截止。调用方可以重新发起一份完整新请求。

本叶没有事务和写锁。完整结果先在局部构造，全部互证通过后一次无抛出交换；任何非成功、异常或坏成功形状都不能发布部分父链、部分路径组或旧缓存。

## 11. 验证矩阵

1. 固定配置坏、请求坏、版本不等分别验证零 DATA 调用。
2. 单项根父需求、零直接子和零路径组合法成功；不把该形状升级为普通提交可建根。
3. 两级、多级父链验证根到父顺序、末项身份和每级父关系端点。
4. 每父零 / 一 / 多直接子；同一子参与多条路径关系不得折叠；路径组允许独立计数且必须受路径组预算约束；祖先权重不得进入结果。
5. 多路径组、多角色、多顺序、非活动但仍当前的路径材料全部返回，本叶不筛选。
6. 五项预算分别覆盖恰好边界、超一项和 checked 累计溢出；孤立路径组也计入路径组预算，不以“必有成员”假设绕过预算。
7. 请求父未找到 / 已退出分别映射；祖先未找到 / 已退出固定内部不一致；漂移、许可、资源、未实现逐项映射且非成功值为空。
8. 空父链、断链、既有环、错末项、错端点、重复、截断、缺路径组、缺父权重 / 来源、混代和错版本固定内部不一致。
9. 输入顺序扰动后仍按正式稳定键得到值式相同顺序。
10. 静态证明零目标重叠判断、零候选防环、零角色合法性、零 OR / AND 与权重计算、零写、零 L1 / owner / 缓存 / retry / sleep。
11. DATA 最终 ABI 发布后，以真实公开服务覆盖合法根、完整多级链、合法空组和公开可构造失败；无法公开构造的坏成功形状只保留 BIZ 防御分支静态证据，禁止生产 seam。

真实并发、资源耗尽、DATA 私有损坏、跨进程恢复、04-02 / 04-03、05发布、06读回、父提交整体与需求树闭环均为 `NOT_RUN`。
