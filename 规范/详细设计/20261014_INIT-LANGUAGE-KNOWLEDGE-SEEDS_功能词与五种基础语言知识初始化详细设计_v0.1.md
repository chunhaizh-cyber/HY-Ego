# 功能词与五种基础语言知识初始化详细设计

身份：`INIT-LANGUAGE-KNOWLEDGE-SEEDS`。版本：v0.1。日期：2026-10-14。代码核对基线：`43a5d6c7c6c978e10b93381345f007c61c59c689`；落盘工作树HEAD为`065b6cd2895f0469edd57c61eacdea32a09147e6`，中间仅因果设计、计划和索引文档，不改变本叶生产接口。本文冻结实施合同，不宣称提供者已经实现。

## 1. 首叶范围与规范依据

依据2340§2/5、7230§3/5、7240§2及7250§2/3.2，语言知识由既有语言owner保存可读目标、角色约束、含义及有序描述结构。扩展`新_语言类`，不新建语言知识服务、世界知识副本、概念根或通用节点族。数据服务只核验并发布已裁决结构，不解释句意、不匹配当次世界对象、不执行知识。

首叶严格限定五个陈述基础结构：S01存在对象归类；S02存在/特征概念上下位；S03 I64准确值特征描述与特征概念条件描述各一；S05存在整体/部分组成描述。角色都是未绑定的规则变量，不创建现实存在或自然语言场景实例。五条均可完整读回，不声称产品解释器已消费、双向转换或学习采用完成。

只登记实际固定项所需六个词面：`是`、`一种`、`的`、`整数`、`概念`、`一部分`。它们只取得合法词条，不强制成为概念或Name关系；词性和“功能词”不是新增持久字段。`能`、提问、内容组织、代词、任意条件DSL及后天来源保留不足，不进入本叶。

## 3. 首叶结构校验与规范化

只允许陈述、普通陈述域、基础结构、一个含义项、单项角色及空目标适用条件组。每角色恰一类别匹配约束，指向自己；允许类别非空、排序去重。存在对象只允许`存在`，概念角色可为`存在概念`/`特征概念`的非空集合，FT角色恰为正式特征类型或I64标量特征类型，准确值恰为I64标量。I64 FT类别是对未来已绑定FT材料物理类型的限制，不创建FT；本叶保存约束，不执行绑定求值。其它有限操作/条件/材料或子规则均明确未支持，不能空存后称已完成。

概念归类恰有主体/归类概念：主体为存在对象则归类概念只允许存在概念；主体为概念则双方为概念角色。特征描述恰有主体/特征类型/特征值，主体是存在、P是FT；准确值分支V是I64且P为I64 FT，概念分支V为特征概念。组成恰有整体/部分，均为存在。特征分支只在特征操作有值，其它操作必须缺省；参数名不得重复，所有角色必须在目标与结构实际被引用。

概念归类与特征描述具有不可省略的参数联合类型规则，依据2220、7160及7240§2.2，不新增条件DSL：S02所属的概念参数分支，两角色允许类别组必须一致，实际绑定时两个概念必须同类别；特征概念必须同FT类型根，不能跨根解释为上下位。特征描述的准确值须与P材料/单位相容，概念条件V必须属于P的FT类型树。联合规则由操作/参数种类/值分支承载，不由S编号决定，未来消费该知识时必须执行并保留读取或类型未完成。本叶发布只核验变量及允许类型的静态相容，不执行世界绑定、不把未绑定参数当已通过联合校验。

名称表达只用于概念/FT，明确对象描述只用于存在，类型化字面值只用于I64准确值。固定项必须实际读回正式词条，语言与描述结构一致，规范化合同为本叶严格UTF8字节精确合同；不从词面反推语义操作。描述向量顺序是唯一规则顺序，局部项编号规范化为0连续递增；按角色首次结构出现顺序重编号并完整改写所有角色/约束/参数引用。参数按具名参数枚举排序；语序及重复出现不排序。完整规范化相等才复用，同目标不同语序/固定词/表达方式是不同知识。

角色组按重编号后的0连续编号重排；本叶唯一含义项的局部编号规范化为0。重复角色编号、重复项编号、负编号和悬空引用在重写前拒绝。无引用编号或声明排列变化不得因默认`operator==`造成第二身份；相反，有序结构语序变化必须保留区别。

## 4. 唯一语料格式及五条定稿

唯一生产文件为`初始化材料/最小语言知识种子.txt`，UTF8无BOM、LF/CRLF均合法。每非空行一个结构声明，行内词用恰一个ASCII空格分隔；无首尾空格、注释或其它空白。空行只分组。关键字为`知识/目的/操作/角色/参数/项/结束`；它们属于初始化元格式，不作为自然语言功能词登记。

首叶元格式闭集：`知识 标签`开启；`目的 陈述`；`操作 操作名 普通陈述 [准确值|概念条件]`；`角色 N 种类 类别或类别+类别 单项`；`参数 参数名 N`；`项 N 词 词面`或`项 N 角色 N 表达方式`；`结束`关闭。标签仅本批诊断/来源定位，不转成正式身份或用于生成知识switch。解码按实际操作、角色、参数和有序项形成通用DTO；新语法不调用原六模板解释器冒充知识定义形成。所有整数是原严格标准I64非负子集，所有元字段和引用先整批校验。

唯一正文须由执行者按下列内容交付；目标/角色/有序项明确写在文本中，业务不得内置第二份正文或用S编号补字段。

写/读均先对整批固定原文解码、规范化、验证有限角色/操作/项/全部范围。解码只产CPP内部未绑定草稿：目标为类型化变量，结构项用词面字符串或合法局部角色引用，绝不以零编码/局部编号填正式词条字段。草稿的角色种类、操作联合签名、参数、顺序、规范化和范围按§3逐项机械核验；合法固定词面以词服务现有严格UTF8字节合同核验。允许业务草稿与owner正式定义分别核验相同结构合同，不复制分词/句意推测逻辑。全部词条取得并读回正式身份后，才由专属绑定函数形成public定义，结果的定稿optional此前保持空。

全批预检先于词条、来源、知识任何写入。固定输入额度为1MiB字节/262144标量/4096非空行/128知识块/每块128角色、128参数、512结构项；任一到限设置独立工程控制为资源未完成及准确到限额度，状态optional为空，不产生文本或定义语义结论、截断成功或缩小范围重试。分配/实现异常向上送出。空批或块不完整才返回文本未完成；不接受未知元字段或标签重复，但标签不参加正式知识查重。

首次先`初始化语言知识结构`，经正式中文/合同核验后按首次固定词出现顺序发布并读回六词；再发布/读回完整固定先天来源，再逐知识使用已确认词条形成定稿/来源范围请求，调用正式提供者并完整读回。阶段失败保留词、来源和已成立定义，不跨owner回滚。五项全部定稿/来源/端点真实读回才成功；通用提供者支持合法同结构异来源，不限定S编号。

只读入口没有初始化结构/发布能力：查询六词、完整来源、规范化知识和所需来源关系；缺失即未完成，不修补、不伪造已复用。普通应用在ctx锁前由实际exe旁读取第三固定文件；首次旧Name/子域初始化完成后调用本叶，再继续人类/治理；重复成功装配在既有双只读之后加本叶只读。上下文及公开结果追加`optional<初始化语言知识结果> 语言知识`，成功必须同时工程控制已完成且状态为已完成；独立消费catch与完整结果拷贝保障沿现有工程终点，不能落入旧资源catch。

## 6. 提供者存储、锁、来源复用和真实边界

知识根只保存类型及目标/结构两个核心引用。语言归属只在描述结构的正式语言引用上保存；不能给知识再造相冲突语言字段。目标拥有角色/含义，结构拥有有序项；使用同一字段引用关系正反读取归属和组成，序号是私有辅助节点的局部I64值，不额外维护第二父指针或成员列表。所有类型/字段标识为语言owner私有正式节点，局部角色/参数/枚举值为经校验原始I64，不是世界目标身份。首叶每个完整知识拥有自己的目标/结构/组成，不单独公开半结构建立接口。

复用L1原子节点组一次发布知识、目标、全部角色/约束/含义参数、结构/全部项及初始来源关联；组内引用用组内节点引用，正式语言/词/来源用强节点字段。底座组接口没有外部边，不能在之后加父子边才能变完整；知识与来源集合通过正式字段反向查询，不靠进程map或裸ID数组作权威。来源关联是独立节点，含知识引用、来源引用和标量范围，不塞到知识核心字段。

保持现有非递归`新语言互斥`。词服务持词锁可进入语言：外部词读取均在语言锁外，锁内只用现有私有语言读取及底座完整读取，不调用public语言入口或词服务。发布亦采用三段：锁内取得同语言完整全候选/来源/所有固定词ID；锁外读取全部候选词及请求词的正式词信息和完整基础节点快照；再次锁内读回整个候选范围/内容和各词完整结构。任一范围或内容漂移返回读取漂移且零本次发布，不以旧集合建立第二身份、不无限重试；最终语言锁保持至查重及原子发布/来源补充。词owner现行身份字段无修改/删除入口，本叶不新增该能力；底座词快照只作不透明逐字段相等检查，不解释词私有字段或成为第二词权威。

读取/查询未知知识固定词时分三段：语言锁内读取完整候选定义/来源与固定词ID副本；解锁后逐词经词owner正式读取、核验语言和规范化合同；重新取语言锁读回同一完整候选及当前范围，身份/定稿/来源集漂移则返回读取漂移且零完整信息。只读不作无限重试，不在锁内反向进入语言或词服务。所有候选包括未匹配结构均完整核验，损坏不能continue成未命中；词面索引/知识缓存只可召回，命中必须正式完整读回。

已有同规范化定义时不因来源改变新建知识。先完整读回已有定义/实际来源：请求来源关系完全相同则真实复用；缺少的新来源关联在同owner内用第二个原子节点组补充，已有目标/结构不改。如果补来源或最终读回失败，写结果保留已发生定义身份和实际阶段，状态未完成，不伪称整批原子、来源已补或重新换键建立定义。来源集合按来源节点/起始/结束排序去重，重复组织关联是内部不一致；定义相等而来源不同是同一知识多来源。

查询语言知识以描述结构的语言强引用反查完整结构，再通过知识的结构引用反查唯一知识，完整读取目标/结构/全部组成/来源。已知ID读取同样核验类型、每字段基数、引用闭包、单一归属、完整序号与全部合法枚举；多于一个同定义知识是内部不一致，不任选首项。读回来源是仍保存的原文与范围，不是历史版本服务。首叶来源入口只支持经确认先天定义；后天教学/学习未来扩同一知识结构及来源分支，不另建规则仓，本叶不伪造学习/采用关系。

定义、原文及来源关联不提供更新或删除入口，不注册恢复能力。现行基础数据集仅进程内，字段化正式保存与读回不能报告成磁盘持久化、跨启动幂等或恢复已完成；源txt是唯一可重新提供的初始化正文，不是已恢复语言身份。后续修订形成新完整定义，原使用/来源引用保护遵守0050，不在本叶发明退出后读取例外。
