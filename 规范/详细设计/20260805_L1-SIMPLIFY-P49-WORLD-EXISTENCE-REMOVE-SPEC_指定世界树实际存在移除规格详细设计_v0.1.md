## 2. 目标与完成条件

新增唯一无状态函数：

```cpp
世界树实际存在移除规格结果 形成世界树实际存在移除规格(
    const L1场景结构服务& 场景结构,
    const L1实际存在服务& 实际存在,
    const 世界树实际存在移除规格请求& 请求);
```

函数只完成：

```text
请求纯值校验
-> P19恰一次读取指定根完整当前结构并精确校准当前场景/旧成员边/截止
-> P21恰一次消费本轮P19事实并互证实际存在资格与输入成员边
-> 返回同根同截止、调用方拥有的不可变移除规格
```

完成必须同时满足：

- 请求强类型固定为实际存在，不接受成员种类、新父、场景移除、子树或删除选项；
- P19与P21各恰调用1次，P21只消费本轮P19成功纯值事实；
- 当前场景、实际存在、当前归属关系和实际存在资格在一个非零事实截止内逐字段互证；
- 调用方必须提供完整预期场景、预期归属关系和期望代次，不允许只传存在编码后猜边；
- 所有非成功规格为空，不重取快照、不扫描补全、不部分成功；
- 生产路径零L1写、零幂等身份、零摘要、零稳定编码分配、零事务、零读回、零锁和零缓存。

## 5. 固定形成算法

### 5.1 provider前校验

在任何provider调用前校验三版本精确、期望代次非零；根/实际存在/预期场景均为有效非零普通节点且互异；预期归属关系见证完整、顺序0、源端等于预期场景、目标端等于实际存在。任一失败返回`入口拒绝`、空规格和双空诊断，P19/P21调用均为0。

### 5.2 P19当前结构与乐观旧边

构造`当前世界结构读取请求`并调用`场景结构.读取当前世界结构`恰1次。固定映射：完整`已读取`继续；`未找到/版本漂移/许可拒绝/资源失败/内部不一致`同名映射，其中内部不一致原样保留结构缺项；入口拒绝、写状态、空/坏成功或未知值映射`内部不一致`且不伪造诊断。

成功事实必须版本、根、完整标志、稳定排序、空缺项和非零截止均符合P19。截止不等于请求期望代次返回`版本漂移`，不重试。随后固定校准：

1. 预期场景在当前场景组恰一项且见证逐字段全等；缺失为`未找到`，重复或同编码异见证为`内部不一致`。
2. 实际存在不得出现在当前场景组；出现说明P19坏成功或请求种类矛盾，返回`内部不一致`。
3. 预期归属关系在当前直接成员关系组恰一条逐字段全等，且目标实际存在没有第二条当前成员边。
4. 实际存在及成员边均已不在当前结构返回`未找到`；目标仍有当前成员边但场景或完整关系见证与请求不同返回`版本漂移`；重复、多场景或矛盾返回`内部不一致`。

P49不从原始L1重解释关系类型，也不扫描父链、子树、特征、状态或动态。P19已经证明直接成员关系的正式类型、方向、基数和顺序。

### 5.3 P21资格互证与规格形成

用完整P19事实构造`当前实际存在集合读取请求`并调用`实际存在.读取当前实际存在资格集合`恰1次。P21的`未找到/版本漂移/许可拒绝/资源失败/内部不一致`同名映射，内部不一致原样保留存在缺项；入口拒绝、空/坏成功或未知值映射`内部不一致`。

P21成功必须版本完整、稳定排序、空缺项、同根且截止与P19完全相等。在资格集合中按实际存在稳定编码精确找到一项，其`存在`必须等于P19成员目标，`输入成员关系见证`必须逐字段等于预期当前归属关系。缺失、重复或矛盾是P21坏成功，返回`内部不一致`，不得补扫。

全部成立后逐字段形成规格：根、当前场景、实际存在与归属关系来自P19精确见证；资格来自P21；截止来自P19。返回`已形成`、完整规格和双空诊断。

## 6. 引用、防悬空、状态与生命周期

P49不以“存在仍有特征/状态/动态”为拒绝条件，也不读取这些领域。4200固定移除只退出世界树当前成员边，不删除、退役或物理回收存在本体，不删除其特征、状态、动态或历史关系；这些事实仍指向存在本体，因此不悬空。移出树后该存在不进入普通世界树快照，但仍可由各事实所有者审计读取。场景和子树不属于请求，故没有场景子树悬空分支。

| 条件 | 状态 | 规格/诊断 | 副作用 |
| --- | --- | --- | --- |
| 请求版本、身份、关系、自洽或零截止错误 | `入口拒绝` | 空/双空 | provider调用0 |
| 当前场景、存在或成员边确定缺失 | `未找到` | 空/双空 | 零写入 |
| 请求截止或旧边已变化 | `版本漂移` | 空/双空 | 零重试 |
| P19/P21许可竞争 | `许可拒绝` | 空/双空 | 立即返回 |
| P19结构坏成功 | `内部不一致` | 空/结构缺项 | 不返回部分规格 |
| P21资格坏成功 | `内部不一致` | 空/存在缺项 | 不返回部分规格 |
| 分配失败 | `资源失败` | 空/双空 | 零写入 |
| 完整移除材料 | `已形成` | 完整规格/双空 | 零写入 |

函数不`noexcept`；捕获`std::bad_alloc`为资源失败，其它异常为内部不一致。函数不取服务锁、不持锁跨provider、不等待、不sleep、不重试。规格由调用方拥有，只对该事实截止有效；后继发布者必须把截止用作唯一L1期望代次，不能用旧规格静默重读。
