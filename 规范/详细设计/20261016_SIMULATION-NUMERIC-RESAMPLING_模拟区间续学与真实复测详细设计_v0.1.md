范围：完整数值区间续学、各条件三点合法组合、偏差细分、真复测、未知与同输入差异材料交付，连同现有服务和实际项目自检消费者适配。算法不拥有世界、方法树、需求、任务或真实次数，不能凭数字向量宣称完整语义条件已经审核。

## 3. 精确公开合同

全部数值结构与入口继续在`海中鱼巣/业务/模拟学习.算法.h`声明，定义在同名`.cpp`；属于业务数值算法owner，允许模拟服务及正式自检使用。它们不含稳定编码，不读写世界；来源、角色、FT、关系及知识发布由调用方持有。所有新增成员追加在现有聚合尾部，不改已有枚举数值。

### 3.1 新增和扩展结构

```cpp
struct 数值模拟起始区域 final {
    std::vector<数值模拟输入区间> 输入区间组;
};
// 数值模拟细分请求尾部追加：
std::vector<数值模拟起始区域> 已有区域组;

// 数值模拟样例状态尾部追加：输入组合不合法

struct 数值模拟未知输入 final {
    std::vector<std::int64_t> 输入值组;
    数值模拟样例状态 原因 = 数值模拟样例状态::结果未知; // 只能是输入不可求值或结果未知
};
struct 数值模拟同输入差异 final {
    std::vector<std::int64_t> 输入值组;
    std::vector<std::vector<std::int64_t>> 不同输出组;
};
struct 数值模拟求值材料 final {
    std::vector<std::int64_t> 输入值组;
    数值模拟样例结果 结果;
    bool 收尾复测 = false;
};
// 数值模拟材料读取结果尾部追加：
std::vector<数值模拟完成区域> 未完善区域组;
std::vector<数值模拟未知输入> 未知输入组;
std::vector<std::vector<std::int64_t>> 不合法输入组;
std::vector<数值模拟同输入差异> 同输入差异组;
std::vector<数值模拟求值材料> 实际求值组;
// 数值模拟推进结果尾部追加：
std::optional<数值模拟求值材料> 本次求值;
// 数值模拟进度尾部追加：
std::size_t 实际求值次数 = 0;
std::size_t 未完善区域数 = 0;
```

原有`数值模拟样例`、`数值模拟完成区域`及其字段保留；输入区间可添加默认相等操作以支持精确区域去重，无业务语义扩张。`样例组`只包含当前运行中**只有一个已知输出的唯一输入**；差异输入从该组移出并进入`同输入差异组`，不能静默保留第一次结果。`实际求值组`按真实callback顺序包含每一次已正常返回的求值（含复测、合法未知及不合法组合），是调用期材料，不是持久样本仓。发生工程错误的callback不成为正常结果材料。

`未知输入组`和`不合法输入组`是各输入最近一次实际求值的未完善/排除状态，同输入后续已知时从这些组移出；旧未知仍在`实际求值组`中保留。若旧值已知而最新复测未知，该输入不能参与本次收尾的共线判断，其旧已知样例保留为历史采样材料而非当前复测结果。判差异应比较同输入全部已取得输出，不因中间一次未知而忘记前值。材料组按输入字典序稳定排列，只有`实际求值组`保持发生顺序；结果未知与差异是不同材料。

原有`已求值样例数`仍等于`样例组.size()`，不冒充实际调用次数。`本次新样例`仅在首次出现一个已知输入时交付；复测相同结果只交付`本次求值`。异常差异的完整输入和两个已取得结果通过材料读回。已完成区域只表示采样及收尾均完成，不表示全域已证真。

### 3.2 既有四入口维持签名

```cpp
数值模拟操作状态 数值模拟细分器::初始化(
    const 数值模拟细分请求&, const 数值模拟求值函数&) noexcept;
数值模拟推进结果 数值模拟细分器::推进() noexcept;
数值模拟进度 数值模拟细分器::读取进度() const noexcept;
数值模拟材料读取结果 数值模拟细分器::读取材料() const noexcept;
```

`初始化`中`输入区间组`始终是本次允许总域，`已有区域组`为空时只从总域起步；非空时只从这些已形成的区域起步，不自动补齐总域未覆盖部分。每个区域维数必须相同、上下界合法且逐轴包含于总域，完全相同的区域去重；不同区域可以重叠，保持各自已知适用范围，不取包络填平空隙。拒绝请求不替换现有作业，不调用求值。合法初始化以一个新实现整体交换，不继承上次缓存或假造已有输出；续学起点来自调用方已读出的知识区域，不是第二长期事实账。

求值回调沿用现有签名。它在调用原函数前负责检查所有非数值条件、角色/关系及联合限制：已确定违反组合限制返回`输入组合不合法`且空输出，跳过原方法；缺信息不能判合法返回`输入不可求值`，合法但结果未知返回`结果未知`，两者空输出。`求值失败`、抛异常、错误维数、无穷哨兵是独立工程异常，不得改为未知。合法性检查及方法运行合为一个回调，算法不增加第二可写场景或约束owner。

每次`推进`最多一次求值；单对象串行，回调可重入读取，不可重入初始化/推进/析构。不增加线程或预算上限。停止调用即暂停，继续同对象从游标恢复；显式重新初始化才开始新调用期。状态`已完成`表示本次采样结束，可以带未完善区域或差异；不是“学习成功”。工程终态维持既有枚举，重复推进不重跑callback。

### 3.3 内部计算合同

现有匿名命名空间的`有序坐标`、`区间中点`、`相乘`、`差的幅度`、`精确共线`复用，保持I64极值哨兵拒绝及无浮点截断判断。内部`工作区域::准备网格(bool)`改为`准备网格()`，固定每轴最小/下中点/最大去重后完整笛卡尔积；移除五点/四分位阶段。匿名`区域阶段`和`实现`私有调度状态可调整，不能导出。

`实现::采一个点`扩展为按普通采样/收尾标志决定是否允许缓存；`查一条线`只在该线三点均合法已知且无差异时用原共线算法检查；`收束区域`保存完成或未完善，或沿首个有偏差轴二分；`前进一步`管理全局收尾波次。这些函数仍私有，不读取外部世界或签发方法事实。

## 4. 计算流程与准确结束

1. 完整校验请求并建立起始区域队列。每区域三点网格按轴输入次序稳定枚举；使用混合基数游标，不预分配笛卡尔积，不用总组合数溢出裁剪范围。
2. 普通采样允许同一调用期、同输入已知材料复用；本次没有真实callback就不递增实际求值次数，也不交付伪造`本次求值`。未知/不合法标志只用于当次波次，不升级为永久知识。
3. 已求值后校验维数、I64合法性，追加本次正常求值材料。一个完整数值向量再次取得不同输出，保留两个输出、置差异终止，立即停止本轮后续取样；不把它平均为宽域，不因外层大域宽而丢弃差异。数值输入本身是零宽，但上层仍须审核完整语义条件再形成异常方法。
4. 逐轴固定其它坐标，比较该线最小/下中点/最大结果；所有输出分量均须精确共线。缺少合法已知三点时不算零偏差，不用`map.at()`强取被关系过滤的点。该区域存在未知点，或稀疏合法网格缺少判定所需完整线时标记未完善；仍可完成本轮枚举。全不合法域也列未完善，不列完成确定域；由`不合法输入组`且无`未知输入组`区分其与“合法输入但结果未知”。单点/相邻轴因没有内部整数，本就无需三点共线比较，不误判缺线。
5. 任一可分轴有偏差，按现有保序中点分成`[lo,mid]`、`[mid,hi]`；选输入轴次序最先的偏差轴，左后右确定遍历。只有`lo < mid < hi`才二分；相邻整数端点区间不再分。非线性可能产生多个叶区间，不预建全域单点。
6. 待处理队列耗尽，形成一层未再派生新区间的叶集合（完成和未完善均保留）。开始全局收尾波次：对每个叶区域重新枚举其三点合法组合，**全部实际回调**，即使该输入已见、两个区域共享端点，也不能用缓存跳过该区域的复测。同输入不同输出按第3项立即终止。收尾中获得的未知/非法不因旧缓存已知而消失。
7. 收尾发现偏差产生新区间，则移出受影响的已完成区域，恢复普通细分，随后对当前所有叶区域再做收尾；未受影响区域仍保留。没有新区间且整层收尾完成时置`已完成`；合法未知/全非法范围保留`未完善区域组`，允许本次结束，不计通过。
8. 差异终止时`状态=已完成`且`同输入差异组`非空；受影响当前域及尚未结束的域列入未完善，已有合法不受影响材料保留。工程终态保留已有材料供诊断，不标完成、不重试动作。

旧五点补测不再是本叶默认流程。例如`x*(x-4)*(x-8)`在`[0,8]`三点都为0，收尾也相同，本次可结束，但必须明确没有验证其它点；不得保留旧“必然发现隐藏偏差”断言。三点线性采样也不把多条件轴线共线提升为完整多元线性证明。后继方法线性关系形成仍须5370的联合来源约束。

## 5. 现有服务消费者适配及来源保留

只修改`模拟学习服务::学习`函数体，不改其公开签名、构造、结束通知或线程消息：

4. 引擎结束带未知/差异/未完善时，本次零调用`追加模拟条件结果`，只返回原`新学习结束通知{方法节点}`；不得把差异送旧单R入口，也不能以抛工程异常代替合法未完善。已经存在的方法知识不删、不覆盖、不停用；本叶尚不发布异常标记或可靠度。

## 6. 工程、事务、生命周期及诊断

算法没有底座事务，仅私有内存状态；初始化候选整体交换，读取返回值式副本，分配失败返回具名`资源失败`，不得空成功。工程失败后锁定当前数值作业，重复推进零callback；不丢弃已经正式发生的模拟事实。

算法四入口及有分配/回调的内部函数诊断责任为“向上送出”；纯整数变换和无失败特殊成员为“无适用错误分支”。生产服务适配新增分支必须逐项区分合法未知、同输入差异和工程失败。现有`新学习运行异常`继续用于停止取消与具名工程交付，不能变成业务知识。数值引擎的资源失败映射`资源不足`，其它输入维数/哨兵/不变量错误映射`结构不一致`，回调已有`exception_ptr`优先重抛，不以其兜底`求值失败`吞掉原因。当前学习线程通过promise异常交self，不是方法业务结果；本叶保留这条独立技术交付链，不改线程、不声称已完成全链工程弹窗终止治理。实际项目已有最终日志处理与全规范要求间的差距须在施工记录如实保留，不能以本叶名义暗改全部学习异常生命周期。自检是自己捕获并报告的最终验证边界。

新内部helper只能定义在算法`.cpp`匿名命名空间或`实现`内，功能分类仍为数值计算/状态推进；完整公开合同以上述四入口唯一承载。不存在持久迁移、删除、版本字段或新增工程登记。模拟正式事实持久恢复与方法owner未来发布不由本叶承诺。
