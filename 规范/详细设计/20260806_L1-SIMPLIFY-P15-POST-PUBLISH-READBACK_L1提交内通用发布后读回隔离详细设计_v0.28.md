## 1. 唯一裁决

恢复材料必须从生产持有的唯一 `L1事实基座服务` 导出；不得由领域层或外部调用方另建 `L1事实基座仓库`。在既有 24 项代码白名单内新增服务转发、请求/结果 DTO 与仓库只读导出能力，不新增文件、第二状态仓或旁路 ABI。

冻结公开入口：

```text
L1恢复材料导出结果
L1事实基座服务::导出恢复材料(
    const L1恢复材料导出请求& 请求) const
```

`核心/合同.L1事实基座.ixx` 导出请求 DTO；`核心/L1事实基座.数据.h` 导出结果状态、结果 DTO 和既有 `L1恢复材料`；`核心/服务.L1事实基座.ixx` 只校验合同版本并转发；`核心/仓库.L1事实基座.ixx` 在唯一私有状态上持共享锁，确定性复制材料。领域调用链只能经过服务入口，不能取得 `仓库_` 或复制仓库。

导出是只读快照，不改变事实代次、隔离位、候选、幂等账或审计。`候选_` 若存在，导出只包含已发布 `状态_`，不序列化未确认候选。状态完整且已隔离时仍允许成功导出，并保留隔离标志和失败见证，以便恢复/诊断；状态不完整或隔离见证不一致时返回内部不一致且不返回材料。

v0.27 的 P-I 模块归属、RP/G6/RW/v1/v2 字节合同、E01 node-only 结果计划、三副本原子交换、失败/恢复矩阵、调用计数和 24 项代码路径 + 2 条专属记录全部保持。

## 2. 正式事实与边界

正式服务当前只公开建立、确认、撤销恢复候选；`仓库_` 为 `L1事实基座服务` 私有成员。仓库已有 `L1恢复材料`、候选生命周期和状态完整性检查，但没有服务导出入口。外部新建仓库只能得到另一份空状态，不能作为本服务恢复材料来源。

不变门禁：正式 HEAD 16 文件/50 个直接 `.提交写集(` 表达式；执行安全断点/完成目标 16 文件/49 表达式；32 个生产/业务场景 + 18 个自检场景 = 50/50；R01 标签、X01 同义提交 0、X02 唯一共享 `0x15000901U`；P-L1/P-I/P-S、G1—G8/G0、24+2=26 全部保持。

## 3. 导出 DTO、状态与确定性材料

请求 DTO（合同模块）：

```cpp
struct L1恢复材料导出请求 final {
    std::uint32_t 合同版本 = L1事实基座合同版本;
};
```

结果状态与 DTO（数据头）：

```cpp
enum class L1恢复材料导出状态 : std::uint8_t {
    成功 = 1, 入口拒绝 = 2, 资源失败 = 3, 内部不一致 = 4
};
struct L1恢复材料导出结果 final {
    L1恢复材料导出状态 状态 = L1恢复材料导出状态::入口拒绝;
    std::uint64_t 事实代次 = 0;
    bool 当前隔离 = false;
    std::optional<L1恢复材料> 材料;
};
```

成功材料字段来源固定为同一 `状态_` 读锁内的：当前快照、历史节点/关系/值、审计记录、幂等账、发布后读回失败见证组、当前隔离见证。当前快照按既有编码排序；历史三类按编码升序；幂等账按幂等键升序；审计按 `(幂等键, 事件序号)` 升序；失败见证按 `(幂等键, 审计事件序号)` 升序。导出结果的 `当前隔离` 与材料中的 `当前隔离见证身份` 必须互相一致。

## 4. 服务/仓库调用、锁和失败矩阵

1. 服务入口先检查 `请求.合同版本 == L1事实基座合同版本`；不等返回 `入口拒绝`、无材料、事实代次 0，不访问仓库。
2. 合法请求唯一转发 `仓库_.导出恢复材料() const`；仓库取得 `std::shared_lock<std::shared_mutex>`，覆盖状态完整性检查和全部副本复制/排序。
3. `状态完整(状态_)` 为假，或 `状态_.隔离` 与 `当前隔离见证身份` 不一致，返回 `内部不一致`、无材料；不得清除隔离或候选。
4. 状态完整且未隔离返回 `成功`、当前事实代次、`当前隔离=false` 和材料。
5. 状态完整且已隔离返回 `成功`、当前事实代次、`当前隔离=true` 和包含失败见证/隔离见证的材料；导出不解除隔离，后续恢复仍须经过既有建立/确认候选入口。
6. 复制/排序期间 `std::bad_alloc` 返回 `资源失败`、无材料；其它异常返回 `内部不一致`、无材料。所有失败不交换状态、不写审计、不改变代次。

该入口不持有独占锁、不调用提交、不读取或导出未确认 `候选_`，也不接受外部仓库实例。恢复调用链固定为：生产服务导出 -> 外部保存/验证 -> 同一 `L1事实基座服务::建立恢复候选` -> `确认恢复候选` 或 `撤销恢复候选`。

## 5. P-I、RP/RW 与完整范围

P-I 仍为合同模块 DTO、索引模块类声明/成员实现，身份 `0x4C31495800000001`、合同/规则 `1/1`；不迁移类、不引入 PIMPL/自由函数/新 ABI。

v0.25 字节裁决保持：

```text
G6：HZY-L1G6 → U32格式 → U32 0x15000301 → U8变体
  → 变体后只插入一次 RP 原始32字节 → U32合同 → U32规则 → U64幂等 → U64期望代次
RP：HZY-L1-RP + 大端字段计划 → SHA-256/32字节
RW：HZY-L1-RW + 大端发布代次/幂等键/字段稳定编码 → SHA-256/32字节
E01结果 v2：一次 HZY-L1RS + 一次 U32(2)
  → v1 去除前缀与版本后的字段载荷（合同版本至逐项通用读回）
  → RW原始32字节 → SHA-256；绝不嵌套 v1 前缀/U32(1)
```
