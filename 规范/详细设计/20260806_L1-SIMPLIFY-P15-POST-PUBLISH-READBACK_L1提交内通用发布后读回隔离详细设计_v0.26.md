## 3. P-I/P-S 与 RP/RW 合同

P-I 与 P-S 不并入 L1 provider。P-I DTO 为 `{稳定身份(U64), 合同版本(U32), 规则版本(U32)}`，公开只读 `const noexcept`，实例生命周期为构造后恒定至销毁，不读事实、不分配身份、不改变代次。P-I 的声明/合同路径固定为 `核心/合同.L1可重建索引.ixx`，实现路径固定为 `核心/索引.L1事实基座.ixx`；该合同路径属于本计划第 24 项白名单。

v0.25 字节裁决保持：

```text
G6：HZY-L1G6 → U32格式 → U32 0x15000301 → U8变体
  → 变体后只插入一次 RP 原始32字节 → U32合同 → U32规则 → U64幂等 → U64期望代次
RP：HZY-L1-RP + 大端字段计划 → SHA-256/32字节
RW：HZY-L1-RW + 大端发布代次/幂等键/字段稳定编码 → SHA-256/32字节
E01结果 v2：一次 HZY-L1RS + 一次 U32(2)
  → v1 去除前缀与版本后的字段载荷（合同版本至逐项通用读回）
  → RW原始32字节 → SHA-256；绝不嵌套 v1 前缀/U32(1)
```

同义命中原样返回首次 RW、结果摘要版本和结果摘要；恢复按保存版本重算，E01 为 RW v1 + 结果摘要 v2，非 E01 保持结果摘要 v1。缺版本、缺字段、摘要不等或三副本不等按既有 `材料不完整`/`内部不一致` 合同拒绝或隔离。
