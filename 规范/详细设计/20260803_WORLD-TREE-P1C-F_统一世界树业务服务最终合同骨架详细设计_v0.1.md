## 1. 目标、事实与裁决

本叶把 4200 的九项公开能力冻结为 `世界树业务服务` 最终 ABI 安全骨架。它只建立最终模块、门面专属请求/写结果、五引用构造和九根固定未实现函数；不执行旧 P1C 大计划中的真实三读六写。

当前正式事实：P1A3F 已发布存在/场景最终类型和安全骨架；FEATURE-W-F、P1B-F、P1C-QF 均在计划索引待激活，正式代码尚无其目标模块；P1C-Q 也待激活。旧 `20260802_WORLD-TREE-P1C` 详细设计/计划和六张写图混合真实行为，只作字段与差距证据，不取得本叶施工身份。正式代码不存在 `服务.世界树.ixx` 或 `世界树业务服务`。

直接依据：0050、4030、4170、4200 v0.9、4201 v0.5；P1A3F v0.3 已发布接口；现行 P1C-QF v0.1 最终读取 ABI。FEATURE-W-F v0.1 和 P1B-F v0.2 只作为待实现提供者合同，必须先发布真实代码结果并在 S0 逐签名复核，WIP 文档本身不解除门禁。

## 3. 最终 DTO

```cpp
struct 世界树创建存在请求 {
    世界树请求头 头;
    世界树节点身份见证 场景;
    世界树幂等身份 幂等身份;
};

using 世界树写后事实 = std::variant<
    世界树创建存在读回,
    世界树特征批次读回,
    世界树状态动态读回,
    世界树移动读回,
    世界树移除读回>;

struct 世界树写入结果 {
    世界树业务状态 状态 = 世界树业务状态::入口拒绝;
    std::uint64_t 发布代次 = 0;
    持久证据状态 持久状态 = 持久证据状态::不适用;
    std::optional<世界树节点身份见证> 目标;
    std::optional<世界树关系身份见证> 旧关系;
    std::optional<世界树关系身份见证> 新关系;
    std::optional<世界树写后事实> 操作读回;
    std::vector<世界树缺项> 缺项组;
};
```

字段顺序、整数宽度、variant 替代项顺序和默认值固定。请求/结果由调用方按值拥有，服务只在同步调用期 const 借用请求且不保存。DTO 不得出现句柄、仓库、许可、事务、参与者、锁、SQL、路径、日志文本、指针、回调或引用。

`世界树业务状态::未实现=11` 由 P1C-QF/4201 唯一拥有并永久保留，本模块不得复制枚举。骨架写结果固定为未实现、代次0、持久不适用、四个 optional 空和缺项组空。

