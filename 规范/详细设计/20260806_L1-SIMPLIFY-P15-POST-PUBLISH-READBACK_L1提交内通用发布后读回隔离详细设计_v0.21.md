## 3. 确定性领域摘要

公共编码原语唯一使用 `海中鱼巣/核心/L1事实基座.数据.h` 的 `L1确定性编码内部`；领域摘要函数归属各自领域入口模块，纯值、只读、无锁、无事实写入。域前缀为 `HZY-L1G6`，格式版本为 `1`，整数网络大端，所有嵌套 DTO 按声明顺序递归编码，最终使用既有 SHA-256 原语。

摘要根顺序固定为：域前缀、格式版本 U32、物理 L1 标签 U32、公开 DTO 变体 U8、请求 DTO 全部字段。E01 字段顺序为合同版本 U32、规则版本 U32、幂等身份固定编码、期望事实代次 U64；X02 在相同前缀后依次编码合同版本 U32、规则版本 U32、目标场景递归编码、幂等身份固定编码、期望事实代次 U64。optional、variant、vector、array 和嵌套请求均使用 G1—G8 已冻结公共规则；结果 DTO、provider 版本、写前见证和 G0 写集不进入领域意图摘要。

## 4. 预探测、G0 互证与恢复

E01/X02 的调用顺序均为：真实公开请求 DTO → 领域 G6 摘要 → 立即 `探测幂等` → 同义时以 `0/0` 读回首次公开结果 → 仅在 `未找到` 后读取 provider/场景/事实 → 独立形成 G0 规范化写集摘要 → 互证标签、变体、版本、领域摘要和 G0 → 一次 L1 v2 提交 → 返回真实首次结果并执行发布后读回。核心不得把 G0 摘要覆盖调用方领域摘要。

恢复必须从首次账保存的真实入口 DTO、物理标签、变体和首次结果 DTO 重算：E01 只能重算 `实际存在登记结果`，X02 只能重算 `实际存在结果`。缺字段、错误 DTO、错误标签/变体、摘要与 G0 混用、首次账/审计/读回不一致、provider 在摘要前读取或同义路径出现第二次提交均拒绝或隔离，业务载荷为零。E01 与 X02 之间不得互换恢复材料。

以下向量以同一合同版本、规则版本、幂等身份和期望代次为基准，只改变标注字段；摘要编码必须在变更处产生不同摘要：
