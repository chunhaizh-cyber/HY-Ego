## 1. 目标、修改对象和边界

缺字段追问由**任务链**发现并执行：任务查找方法、采用、执行对应本能方法函数。自我只承接与确认需求，**不直接执行本能方法函数**，也不亲自满足自己的需求。

本本能（“想”侧）的直接产物是正式**表达需求**对象（由自我/任务侧提出、语言模块消费），不是已经入列的外设消息。语言模块根据该表达需求生成**候选话语**；是否发送属于另一动作（“做”），须先经发送判断，通过后才由入列本能改变外设对话框输出队列。D 主体仍是服务对象；把对方回答写回 D 字段属于输入侧/另一本能，不在本函数内完成。

本轮闭合“正式表达需求—语言知识装配与独立回读—候选话语—发送判断—输出入列”的分账边界。不改任务筹办算法本身、子需求确认、被动因果执行、服务承接或结算，不做自然语言批量合句。单次询问本能调用结束于候选话语（或明确缺材），不等待回复、不暂停 worker、不以再次执行本函数来确认效果。

## 3. 输入冻结：不新增参数类别

语义输入为 D＋指定字段＋交互上下文。物理上用**已有内容子目标需求 Q**承载 D＋正式路径，避免把 FT 概念误绑成实例 F，也避免临时创造定位需求。

| 位置 | 固定规格 | 实际含义 |
| --- | --- | --- |
| 1 | 存在＝正式需求根概念 | 已存在 Q；只作定位材料，其 `引用内容定位` 唯一指向 D 和一个 FT。 |
| 2 | 存在＝自我范围概念 | 本次实际执行主体 S；其角色绑定的世界场景为动作发生的现实场景。 |
| 3 | 存在＝人类概念 | 受询者 H；必须等于 D 正式内容的需求主体。不得根据 Q 主体猜 D 主体。 |
| 4 | 存在＝通用存在概念 | 外设窗口 W；角色绑定的世界场景为正式外设场景。 |
| 5 | 特征＝外设对话框输出队列 | W 持有的正式输出队列 Fout。 |

Q 可以来自既有子需求，也可以在模拟世界按同型结构构造，不要求真实任务、Vt 或 X。函数不建立 Q、不读任务管理线程的当前目标、不选取“最新需求”。Q 自身不是待完善 D。

首版正式路径长度恰为 1；支持需求目标存在、目标 FT、目标形式、目标域、目标比较、目标方向六个正式槽。多级路径明确返回定位未支持，不截断；治理字段与内容确认字段不进入询问范围。

必要关系：S≠H；D 的主体＝H；Fout 所属＝W；W 属于传入外设场景。五参显式选择的H/W配对就是本次交互上下文；`读取对话框来源(W)`只核W的正式定位，不证明H身份。外设不负责认知H，不新增连接/收发握手或会话身份证明前置。S不必、也不得被要求存在于外设场景，不从焦点、同名或最近接收猜配对。

### 3.1 字段已明确与分支

从正式 owner 读取 D 对应项：`已知＋值存在` 即字段已明确，0 是有效值；`当前未知` 才询问；`不适用` 无动作返回。内部生成/写入保证类型、范围和关联，本能不再整体验证 D 是否完整、是否得到对方确认。

正式投影标为不适用的项不问。本函数只处理输入指定字段，不改变询问目标、决定字段顺序或派生子需求；哪个字段先被筹办由上游决定。

## 4. 最简输出需求和语言共同表示

唯一新共享值类型文件 `海中鱼巣/领域/字段询问.数据.h`，只含 DTO，无 cpp；不承载仓库/服务实现。

```cpp
struct 新正式字段询问目标 final {
    正式内容引用定位 被询内容; // D + 完整单项路径
    稳定编码 需求范围概念, 语言节点;
    稳定编码 说话者, 受询者, 交互窗口, 交互作用域;
    稳定编码 第三方指代概念, 选用指代名称关系;

```

领域数据头不反向包含业务语言头，文字结果使用以下独立枚举，不依赖业务侧的基础表达状态：

```cpp
enum class 新字段询问文字状态 : std::uint8_t {
    已生成且唯一回读=1, 缺知识, 缺名称, 缺指称,

struct 新字段询问文字结果 final {
    新字段询问文字状态 状态;
```

工程错误向上抛出，不成为上述业务文字状态。DTO 只表达现有正式定位、角色和语言选择，不创建新的业务特征类型或“字段确认类型”。函数内部由输入构造该目标，调用方不得预传成品问句或完整表达需求替代。

### 4.1 统一含义图扩展

在 `新_语言类.h` 的既有枚举末尾追加 `新语言知识角色类别::正式信息节点`，不改变原数值。领域对象引用允许存在或正式信息节点，各条规则仍声明具体类别，不使任意节点合法。

`表达.基础语言.h` 增：

```cpp
struct 语言图待求值 final {
    std::int64_t 局部变量编号=0;
    稳定编码 内容范围概念;
    friend bool operator==(const 语言图待求值&,const 语言图待求值&)=default;

// 将语言图待求值追加到既有语言图绑定值variant尾部。
```

被询图根为“信息请求／提问范围／填项内容”，子含义是“特征描述／提问范围”，三个角色分别为正式 D、正式 FT、待求值；根以被询内容边引用子含义。该子含义的特征值分支为空，不把存在引用、概念引用和枚举字段强行归为I64准确值或概念条件；只有在填项问中且值角色为查询变量时允许这一形状，不放宽普通特征陈述。路径完整保留在 `语言图含义材料` 尾部新增的 `optional<正式内容引用定位> 被询正式内容` 中，不能只保留末端 FT 丢失 D。材料尾部再增`optional<稳定编码> 正式指称作用域`，本轮只容纳一个正式信息称谓的同一交互作用域；语言服务从`新正式字段询问目标.交互作用域`原样赋值，不造默认scope。该值只用于生成后指称绑定，不是答案、领域事实或待求语义；无合法scope则缺指称零输出。

待求变量的范围来自正式 D 类别结构对应槽的内容概念；未知字段不填假准确值、0、空节点或“未知”概念。变量在本次含义出现中局部编号，不能使用全局稳定编码作为变量身份。生成与回读比较 alpha 等价、范围相同，不要求局部编号相等。

### 4.2 知识表达项，而非代码问句

追加 `新语言知识表达方式::带概念指代`、`查询变量词面`；`新语言知识图角色表达项` 尾部追加五个可选字段：`指代概念节点`、`指代名称关系节点`、`概念前词条节点`、`概念后词条节点`、`查询词条节点`。带概念指代要求前四项齐备且查询词条空；查询变量词面只允许查询词条有值；其它表达方式五项必须空。

带概念指代作用于正式信息角色：顺序输出指定指代名称、知识中概念前词条、D 范围概念的正式名称、知识中概念后词条，首版得到“它（需求）”。括号来自知识词条，不在 renderer 或本能硬编码；D 范围来自同一 `语言图引用值.来源概念`，不虚设第二对象或增加无定义的额外含义角色。

查询变量词面项作用于唯一查询变量角色，输出知识中指定的“什么”词条。解释时实际匹配这一词面，再在该含义局部生成变量，并从已解析 FT 的正式槽规则取得范围；不能从原图拷贝变量或答案。

种子语法新增：`项 n 图角色 含义号 角色号 带概念指代 <指代语义键> （ ）`；`项 n 图角色 含义号 角色号 查询变量词面 什么`。图定义校验、规范化、完整序列化、反序列化、查重、引用端点保护、来源及完整读回必须同步实现，不能只有 enum 和输出分支。

首版规则为单个字段问句，不要求实现一般 S13 外层长请求、任意缺项或合句。所有字段共享同一含义/装配骨架；字段差别来自 FT 名称和槽范围，不为六个字段编写六个本能函数。

### 4.3 指称依据与缺名称

不使用“这”的近指规则。既有“他”的概念定义是作用域第三方、目标为强类型信息节点；7250第2.1节已允许他/她/它关联同类第三方指代，本轮为同一概念新增“它”别名，使用 `建立或取得指代名称关系` 的别名角色，原首选名称不改。初始化来源明确绑定新增语言种子行，不伪造原指代种子来源。

本次交互上下文明示 D 是被谈论的内容对象且 D≠S、D≠H，因而第三方目标明确；无需比较距离。没有该显式唯一 D 上下文时返回缺指称零输出，不能用焦点、当前任务、最近 D 猜定。

普通 D 无专名时由上述代词＋范围名称表达，不创建普通 E 镜像。FT 必须具有正式名称；本轮为六个既有 FT 及正式需求概念补齐中文名称，未知新 FT 无词条仍明确缺名称，不能从 C++ 字段名临时拼文字。

`新本能函数本次结果`尾部新增`optional<新本能字段询问返回材料> 字段询问`，唯一owner为`新_本能函数集.h`；其原因枚举为字段已有值、字段不适用、前提已变化、定位未支持、缺语言知识、缺名称、缺指称、多义、**已交付候选**（成功想侧；不含入列）。本函数返回材料不携带入列 receipt；入列由独立发送判断与入列本能分账（7240）。已有执行状态不扩成不相干语言枚举，具体映射如下：

```cpp
enum class 新本能字段询问原因 : std::uint8_t {
    字段已有值=1,字段不适用,前提已变化,定位未支持,
    缺语言知识,缺名称,缺指称,多义,已交付候选
};
struct 新本能字段询问返回材料 final {
    新本能字段询问原因 原因;
    std::optional<正式内容引用定位> 正式定位;

    // 可选：本次表达需求标识与候选 UTF8；不含窗口队列入列 S/D

```

`正式定位`和`已读取字段`仅在本次实际读取成功时设置，已有值分支保留它们且receipt为空；不扩一般模拟C/R条件快照采样算法。为保持既有本次结果默认相等比较可编译，新增载体实现逐字段相等比较（正式定位比较节点/完整路径；字段内容比较种类/状态/可选值），不要求改变共同`信息内容.数据.h`；该结构相等不作为语言变量语义比较。

| 实际分支 | 执行状态/动作阶段/取得状态 | 字段询问原因 |
| --- | --- | --- |
| 仅登记完成 | 已按合同返回/未进入动作/未取得 | 不返回字段运行材料 |
| 已有值或不适用 | 已按合同返回/未进入动作/已取得 | 对应原因，只有实际读取材料、无receipt，不声称任务完成 |

| 语言缺知识/名称/指称/多义 | 入口拒绝/未进入动作/未取得 | 分别保留实际原因，不包装成功 |
| 语言范围未支持 | 入口拒绝/未进入动作/未取得 | 定位未支持 |

| 已交付候选话语 | 已按合同返回/已按函数合同返回/已取得 | 已交付候选（无入列 receipt） |
| 工程错误 | 工程诊断终止，不返回正常结果 | 保留A和已发表事实 |

本函数成功仅证明想侧候选已交付，不证明发送判断通过或外设已入列。建议观察不把队列 Fout 当作本本能完成条件。运行条件只保存实际消费的Q/D定位及E/F材料，不为填满结构而补造条件快照。

动作来源由外层执行守卫/直接调用身份提供；若合法直接调用没有 X，运行服务经方法 owner 以当前五参建立独立调用来源并在本次结束时收束，不制造任务。该身份只用于工程/动作来源关联，不参与业务输入选择。模拟使用该次隔离调用身份。严禁要求真实任务才能提问。

## 7. 现实正式输出扩展

`新外设输出提交请求` 尾部新增 `optional<稳定编码> 来源动作`；`新外设输出队列结果` 尾部新增 `optional<稳定编码> 入列状态,入列动态`。旧调用为空，既有行为保留。

`提交输出→输出入列_已加锁→更新输出队列→更新窗口特征并形成动态` 沿实际该次返回 S/D。内部更新 helper 将原 void/状态返回改为私有结构，保留旧调用适配；不向外公开无类型结构写入。

来源动作存在时，输出 owner 在实际 D 已形成后，以显式 A 调 `关联动作结果(A,D,导致变化)` 再完成正式动态处理和读回。不得在提交后扫最近状态/动态猜来源。动作建立失败零入列；入列后关联失败保留既有事实，工程终止，不再输出一遍。

仅新入列返回本次 S/D。幂等复用返回原消息但新增 S/D 为空，不能冒充新变化；本能本次正常提交采用 owner 分配新提交序号，实际返回必须是新入列。领取、取消、清空不沿用旧入列动作，不改变实际发送链语义。

## 8. 模拟提供者：同一函数，只有参数世界不同

`新_模拟世界类` 实现同一询问运行接口，借用同一个只读语言接口，使用自己的正式 reader 读取模拟 Q/D，不调用现实 D owner、外设 host 或现实提交函数。

该类显式继承`正式信息参数读取接口`，现同名两参reader成为其override。模拟所需语言与登记定义必须沿同一条显式装配链交付，冻结以下签名，替代v0.1仅传语言接口的签名：

```cpp
// 海中鱼巣/业务/模拟学习.服务.h/.cpp，现模拟学习服务公开成员。
void 配置字段询问语言(std::shared_ptr<const 新字段询问语言接口>,
    std::optional<新字段询问登记配置>);
// 海中鱼巣/领域/新_模拟世界类.h/.cpp，公开成员。
void 设置字段询问语言(std::shared_ptr<const 新字段询问语言接口>,
    std::optional<新字段询问登记配置>);
```

普通应用从已经通过现实初始化读回的同一`新字段询问登记配置`取值，向学习服务传入该只读定义值及共享语言接口。学习服务在每个模拟world建立样例前把两项一起传入；world按值保存配置、按shared持有语言接口。配置只含正式概念、FT、语言及指代名称定义身份，允许共享，不含现实实例或调用身份；运行Q/D/S/H/W/F仍只来自该样例参数。模拟`读取询问材料`调用本节5.1的通用helper，显式传入本地配置及`*this`正式reader；不存在向现实登记端口补读配置的路径。

两项均非空表示安装，必须在无活动样例/调用时完成，首次固定、同义重复复用、不同接口或异义配置拒绝并向上送出工程错误；一项空一项非空是装配错误。两项均空是唯一清空形状，用于停止并释放活动模拟样例后关闭；不能在运行中替换或清空。设置器只保存依赖，不生成Q/D、动作、样本或长期C/R。`获取字段询问运行接口() noexcept override`只返回本owner的运行接口；缺少本地成对依赖不得回退现实。调用方若要求本轮询问能力却未完整装配，属于工程配置错误，不伪装普通业务缺项。

`模拟需求.数据.h` 增 `新模拟引用内容定位输入{uint32_t 引用需求输入;vector<稳定编码> 正式内容路径;}`，`新模拟需求输入` 尾部新增 `optional<...> 引用内容定位输入`。这是输入图内索引，不允许来源 D 稳定编码直接进入模拟定位。

`建立有序样例`继续拒绝原`目标.引用内容定位`中携带的裸现实身份；改为支持上述合法图内索引。**Q保留原目标普通E输入并单向映射该E（当前字段Q通常为服务对象H），定位另指同图D**。不能把Q目标E改成D或令该位置0；`新_任务类`约13932和真实需求目标核验仍保持原语义，本轮不改它们。Q的引用目标形状为值目标、具有要求概念域、无比较关系/变化方向，不能沿普通值目标强制要求比较关系。预检图内E及定位D、单项路径和FT正式定义后，预留D身份，只将定位中的引用需求索引重映射到本地D；原子发表和读回一起完成。Q不加入现实需求树、不虚构完成任务。模拟正式reader保留Q的目标E及引用概念语义，另读取D的真实已知/未知项，支持自我执行定位Q与被认知D。

### 8.1 部分已知D与独立保护

现模拟reader强制完整目标/被认知U/C，不能直接表达本轮必需的未知字段。故`新模拟需求输入`及`新模拟需求信息`尾部同时新增`新需求信息完善阶段 信息完善阶段=已完善`和`optional<新部分服务要求目标> 已知目标`：既有输入默认保持旧完整分支；待完善被认知D必须显式提供已知目标（允许全空），主体必有、权重0、无父/根、无U/C；原全量目标字段只允许默认空形状，不同时作为第二份目标。已知目标中的裸目标存在引用必须空，已知E只经原`目标存在输入`图内位置给出；位置0表示未知。

待完善发表只写已知字段，未知槽不存默认0或假概念；模拟reader按实际字段有无形成`当前未知`，已知0形成已知。已完善D仍保持原完整目标及U/C合法关联约束，不因本轮询问放宽；未完善D按真实`建立待完善被认知需求`现合同允许没有U/C，不新增“先取得对方确认”的条件。真实D writer完全不改。

`读取模拟需求`不得继续无条件必读目标E或`读模拟目标`；先读执行域和完善阶段，待完善D走部分目标解码，自我定位Q仍解码普通目标E并另读本地D定位、要求概念域且不要求比较关系，其它走原完整解码。正式投影槽语义与现实一致；分支已知时不适用项明确标记，形式未知时不伪造值目标。

现实Q/D保护来自场景已绑定的正式reader；D必须沿Q的实际引用取得，不允许运行提供者任意选择D。模拟保护来自本地Q、D、字段实际节点、本地引用关系及共享正式定义的完整保护组，前后复核只核该样例；不拿现实Q/D快照替代本地保护。语言生成和独立回读均使用调用者提供的同一模拟reader，所有实例引用重映射后才能使用。

新建中性模拟请求 `新模拟队列提交请求{uint32_t 窗口位置,对端位置,输出特征位置;稳定编码 动作;string UTF8正文;}`，公开函数 `新隔离提交结果 提交本地输出队列(const 方法参数场景&,const 新模拟队列提交请求&)`。只发布输出消息及队列变化，复用 `发布本地消息` 的原子路径；没有发送 F、不推进输出、不造实际发送记录、不要求旧七参。receipt 存入该次本地调用记录，回读消息/本地 S/D 及 A 关联，不靠最近项推断。

动作复用现动作投影及动作定义 owner，但新增 `新模拟参数动作请求{uint32_t 主体位置,目标存在位置,目标特征位置;}` 和 `稳定编码 建立参数动作(const 方法参数场景&,const 新模拟参数动作请求&)`；按显式位置读 S/W/F，旧连接动作入口可适配至中性实现，保留原合同。询问采用 2/4/5，不硬编码七位或连接阶段。

`模拟学习.服务` 仅配置语言接口并传给新建的每个模拟 owner；不按本能名添加采样或回答生成。现通用参数生成器是否已自动构造 Q/D 图另行如实报告；本轮不改采样算法、不把这个 getter 和图输入能力称为自动学习完成。

## 9. 装配、生命周期、锁与错误

在普通应用上下文持有共享语言服务、现实询问运行服务；单源语言知识初始化按4.4节移后，D/FT和指代材料就绪后完成全部语言知识，再在外设输出类型就绪后装配运行提供者，运行一次空登记场景。只登记新函数头，不初始化主动学习、不自动输出。

模拟语言接口随模拟学习服务传入，owner寿命覆盖各模拟调用；关闭顺序为禁止新调用、停止/join工作、释放参数场景与模拟实例、关闭登记端口、释放运行服务、最后销毁共享事实服务。不得为本轮另建线程池或常驻询问线程。

方法owner增加`bool 解除字段询问运行接口(const 新本能字段询问运行接口&) noexcept`：仅精确匹配当前provider才解绑，同一provider可幂等解绑；不允许拿另一个provider解除本owner。应用先停止新方法调用并join工作，再调用现实服务`关闭()`、解绑方法owner、关闭登记端口、释放活动模拟样例，调用`配置字段询问语言({},std::nullopt)`成对清空学习服务的语言接口和定义配置，最后reset上下文两shared服务，均在D/外设/语言owner仍活着时完成。独立模拟owner关闭同样先结束调用再用`设置字段询问语言({},std::nullopt)`清空。旧参数场景即使因只读保留而延寿，provider关闭后所有操作先检查关闭门、不访问借用owner。不得只reset应用成员却让方法owner永久持有服务直到D/外设销毁。

只在各 owner 内短持自身锁；生成/回读前复制必要值式材料并释放业务锁。禁止持方法锁跨语言、需求、外设调用。Q/D 前提保护沿正式 reader，无新事实代次/公共版本/TTL。D/Q 内容与输出不是跨域伪原子事务；Q/D只读，实际唯一业务写入在外设队列 owner 内完成。

诊断责任：私有解析、构图、普通运行核心向上送出；本能 `noexcept` 边界/正式初始化装配边界本地记录后工程终止；外设现 `noexcept` 最终边界保持一次诊断。缺规则、缺名称、缺指称、多义、合法前提变化零动作，属于具名正常非成功；provider丢失、结构损坏、owner错配、写后读回不一致不能吞成缺项。

停止只在动作前检查已有线程停止信号；动作一旦发表，正常立即提交及读回，不为了停止把实际入列说成未执行。故障保留全部实际材料，禁止补造状态、动态、回复或字段值。
