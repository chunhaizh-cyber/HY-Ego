## 3. Vm 运行声明：唯一含义和物理合同

在 `新_方法公共类型.h` 新增下列结构，并在 `新方法知识建立请求`、`新方法信息` **尾部**追加 `std::optional<新方法场景运行声明> 场景运行声明;`，旧聚合参数位置不移动：

```cpp
enum class 新方法场景执行性质 : std::int64_t { 参数数字信息 = 1, 仅现实执行 = 2 };
struct 新方法结果位置声明 final {
    稳定编码 参数角色节点;
    稳定编码 特征类型概念节点;
    稳定编码 结果值域概念节点;
    std::optional<稳定编码> 变化方向概念节点;
    bool 主要结果 = false;
    friend bool operator==(const 新方法结果位置声明&, const 新方法结果位置声明&) = default;
};
struct 新方法场景运行声明 final {
    新方法场景执行性质 执行性质 = 新方法场景执行性质::仅现实执行;
    std::vector<新方法结果位置声明> 结果位置组;
    friend bool operator==(const 新方法场景运行声明&, const 新方法场景运行声明&) = default;
};
```

声明只说明运行合同和结果读取位置，不保存实际输入/输出，不使用经验 `结果节点` 类型，不生成 C/R、命中或可靠度。条件规格仍唯一来自既有 `参数规格组`；输出位置必须唯一对应其中已声明的 `角色+FT`，本包因此只支持输入同时作为输出的普通 I64 特征。纯输出尚无初值、创建新存在、创建新特征不在本包。

`结果值域概念节点` 必须正式属于对应 FT、单位相同，且直接包含于头的 `可能结果概念组`；输出 FT 必须包含于头的 `涉及特征类型概念组`。头仍仅用于召回，不能由头的顺序反推输出位置。声明是预期域，**不是实际结果准入约束**；读到域外有限实际结果必须保留，不截断、不改写成未知。经验 R 独立记录真实观察，可与声明预测不同；只能学习评审修订知识，不能为迎合声明改事实。

新增内部节点类型为“方法场景运行声明”“方法结果位置声明”，均归 Vm 所有；Vm 通过一个可选单引用连接声明，声明通过有序引用连接位置。位置保存角色、FT、结果域、可选方向、主结果布尔。方法结构读回必须区分整项缺省（旧方法合法）和存在但字段缺失/重复（工程结构错误）。复制闭包增加上述节点及内部引用重映射；概念引用继续共享。参数规格节点和任务 Vt 不变。

`确保本能方法登记`：

1. 旧声明空、新声明非空：只在现有方法头、作用域、实现方式、参数规格、登记名完全匹配且新声明合法时，原 M/Vm 增补一次；保留所有 C/R、命中、启用状态和身份。
2. 两边声明相同：精确复用；已有声明非空而调用者未携带声明：只读复用，不清除。两份非空声明不同：登记冲突、零写，不自行覆盖。
3. 先离线建立声明子结构、严格读回，再在方法结构锁下以底座原子比较追加发布 Vm 唯一引用。并发者只允许由“无引用”变为预期新引用；败者删除自己未发表材料，不动胜者。发布后读回失败保留现场，以结构错误报告，不重建方法。
4. 本包不产生声明版本号。新声明对以后新建模拟场景生效；已建立场景使用冻结声明，旧真实任务组织继续依原参数规格执行。

构造规则：

1. 每个普通角色生成独立模拟 E；所有角色处于一个新模拟场景 C。每个已声明 FT 生成模拟 F。I64 当前值来自本次准确输入，值域引用/快照来自冻结概念，不填现实当前值。
2. 任务虚拟存在角色生成模拟 T、Vt 和其状态 F；T 不登记到真实需求或任务树。任务状态同样从输入取得，本包不把数字 9 当通用常量。
3. 非空任务集合仅接受正式 `特征概念任务集合值域{至少一个任务=true}` 且无必须具体任务编码，并且有一个或多个任务角色用正式成员约束指向此集合；集合内容恰为这些新模拟 T，去重排序。没有关联任务可作证时 `合法不支持`，不伪造无来源占位 T。
4. 无存在概念限制的普通角色、无二次特征约束、非空有限 I64 区间并集及以上集合是本包支持域。存在概念约束、动态/状态概念条件、集合具体成员、任意集合枚举、服务要求分项、字符串及设备数据等合法定义先正常停止学习。损坏节点、非法枚举、重复位置不属于“暂不支持”。
5. 实例引用全部是新建模拟 ID；共享的只限概念和方法来源身份。实例间成员、Vt/F、场景归属全部指向同一个样例内节点。禁止把现实节点 ID 当模拟成员，禁止模拟 owner 返回现实可写端口。
6. 每次普通求值和收尾复测都建独立场景；先建未挂根节点、读回和隔离闭包校验，最后发布模拟根成员。未发表材料可回滚；已发表事实保留，析构只释放索引和共享指针，不删除事实。

动作与写入：每次样例最多建立一个主动作；重复建立为工程入口错误，不能伪造第二次执行。写口必须拿本样例动作、声明允许的输出位置和有限 I64 值；输入-only F、跨样例动作/特征、现实 ID 全部零写拒绝。先动作后写值和对应前后状态/动态，显式引用该动作；同值写不伪造变化动态，可返回同一状态、动态为空。多输出允许逐项写，部分失败保留已发生模拟事实，以工程状态停止，禁止把部分结果当完整向量。

结果读回以 `参数场景.读取绑定特征` 为唯一值来源，不能用函数返回 DTO 数字或算法预期值代替。结果为未知需要本次函数明确报告结果尚未取得；已声称取得却输出不可读是工程错误。模拟状态、动作、动态只在模拟根，不能进入现实/内部治理事实树；本包沿现有模拟节点表示实现，不声称已完成中立状态类的统一迁移。

## 6. 原结算函数和生产学习消费

### 6.1 原函数单一运算体

`执行服务值结算` 登记/现实路径仍取得现有真实端口；登记请求增加声明：性质为参数数字信息，结果位置是 `服务值角色+服务值FT`，域为现有 `目标值域`，方向为现有增加方向，主结果 true。原输入规格不变，仍不预造 C/R。

模拟分支不租真实端口、不读现实登记、不确保真实首子需求：从场景冻结定义取得唯一普通输出位置，从其角色绑定取得 C/E/F，从任务角色和集合约束取得来源、集合 F；校验结算自身预期形状（一个服务值输出、一个任务状态输入和对应集合）。方法 ID 用场景方法 ID。准确服务前值、任务状态、集合必须 fresh 读场景。

保留一个共享执行段完成当前前提核对、记录本次条件、`当前值 + 1` 和结果 DTO 填充；现实动作/写入使用旧端口，模拟动作/写入使用第4节通用入口。既有真实冻结值要求不扩大；模拟输入必须属于冻结规格，不能将现实冻结值额外塞入模拟。只有数据取得和副作用端口有分支，不允许再写一个“模拟结算算法”。本包不修改现有固定加1为子任务计值等另一切片。

### 6.2 驱动和域提取

`模拟学习服务` 增加二参数构造 `(新_方法类&, 概念_特征类&) noexcept`；旧三参数构造保留并委托二参数版本，只为源兼容，第三参数不保存、不读取。删除服务成员 `登记读取_`，普通装配因此无需改动。

`学习(M)` 先冻结定义。不支持/仅现实/无声明时返回既有 `新学习结束通知{M}`，零动作零方法写入；错误仍经既有 `新学习运行异常` 技术链。支持时：

1. 输入维按参数规格顺序、特征规格顺序提取 I64 位置，不能使用 FT 相等替代角色身份。集合是固定结构前提，不是数字维。输出按声明位置顺序提取；顺序只在冻结定义内有效。
2. 没有 C/R 时使用输入声明的各有限区间笛卡尔积为起始区域；已存在 C/R 时只采用覆盖同一完整输入位置、单项/全部成立且无额外条件的合法配对，按其输入域续学。无法表示的合法配对不能被投影丢掉约束；该方法本轮合法不支持。范围均与当前冻结声明核对；禁止用不同条件的输出拼一个结果。经验点C不能替代原声明宽域，也不能不经偏差就按点间空洞生成新子区间。完成叶域到正式区间知识的合同尚有第7.1节具名裁决点；该点闭合前此段不得宣称通用区间续学已可施工。
3. 不连续域以多起始区域交给前置引擎，总外包域只作请求外界，不能在空洞采样。各组合用正式成员/域规则判断；不成立交付 `输入组合不合法`，不执行方法。
4. 每次 callback 新建隔离样例和参数场景，调用 `方法_.调用本能函数` 原登记入口一次，按同场景声明结果位置 fresh 读取完整 I64 向量，再核对冻结含义。调用前从场景读取完整条件快照；调用返回的实际消费条件必须逐角色、FT、实例归属及准确值匹配该快照，集合材料必须为同次样例成员；缺项、重复、跨样例或凭空出现未声明条件属于工程合同错误，不能生成候选。本能条件失效且零动作是合法不可执行组合；工程返回、结构损坏、资源错误独立抛技术异常。未知结果保留未知，不填零。
5. 复用前置数值引擎的已有区域、三点、偏差细分、真实收尾、未知和重复准确输入差异；不重写算法，不建立服务私有长期样例 map。每次已发表模拟事实仍挂模拟根。

### 6.3 方法知识边界

正常单结果样例可以形成完整数字准确点C及准确点R；非数字集合前提保留原正式概念。不根据稀疏样本伪造整个区间已验证事实，不任意填线性方向。当前完成域用于本轮收尾与候选资格核验，不能作为“全域已验证”知识发布。只发布准确点会使宽域续学入口丢失，不能作为本包最终方案；区间候选抽象须先闭合第7.1节，不能另建学习服务私有长期域仓来掩盖该缺口。

同一准确完整条件多结果、未知、未完善区域保留在已发表模拟事实并正常结束，不用旧单R接口抹掉一个结果；本包**不宣称**异常原方法覆盖或通用区间知识发布完成。服务无额外自动长期缓存。可靠度和真实运行统计均零写；模拟不能增加实际次数。

### 6.4 正常候选独立评审和授权消费

当前`方法问题学习服务`只有原始归档收集，没有可复用的候选、评审、授权能力；不能把旧服务直调`追加模拟条件结果`推广到通用方法。本包在既有`模拟学习.服务.h/.cpp`建立独立的`模拟方法候选评审器`，它与候选构造函数分离，仅持有只读方法/模拟来源接口，不持有方法写口，不真实运行函数，不由候选的自检bool决定授权。

**正式来源读回**：模拟owner在动作前保存完整输入位置和值，在每次结果写入保存动作身份及前后材料；样例完成后封存结果快照，后续写口拒绝。新增公开读取DTO及入口（均在`新_模拟世界类.h/.cpp`，不新建仓）：

```cpp

    稳定编码 场景节点, 方法节点;
    新方法模拟冻结定义 冻结定义;
    std::vector<新方法模拟数字输入> 动作前输入组;
    std::vector<新方法模拟数字输入> 实际结果组;
    std::vector<新方法参数角色绑定> 角色绑定组;

};
struct 新模拟封存读取结果 final {
    新模拟场景操作状态 状态 = 新模拟场景操作状态::入口拒绝;

新模拟封存读取结果 读取封存样例(稳定编码 场景节点) const noexcept;
```

封存是模拟owner既有场景事实的一次原子终结字段发布，先读回全部事实再标记；读接口可读取本模拟根任一合法已封存样例，不依赖某个已析构owner的临时map。字段持久化包含完整冻结定义的必要取值（共享概念身份及当时语义值）、条件前值、实际后值和角色实例映射，不能仅保留当前概念裸引用后再重释。未封存、封存后仍可变、动作来源不一致为工程错误。后继评审读取封存事实，不读取候选提供的数字当证据。

新配对的模拟来源引用组和评审依据（冻结定义、评审时旧配对身份、所授权完整配对）作为method owner配对附属信息与新配对一起发表，不建立第二方法owner；读回核对来源完整。新增内部来源/评审附属节点类型、引用组同时加入方法复制闭包，概念和封存模拟场景仍共享只读引用。旧没有此来源字段的配对合法保留，不补造历史评审；新通用入口必须提供。授权可重复提交但只精确复用同义既有对，不重复计数；内容不同不得复用请求。发表后未知沿原候选/来源读回，不生成新身份，不删除已发表事实。

来源不足/候选不相符/同条件多结果是评审拒绝，保留事实并正常结束；结构损坏、资源失败独立工程异常。只有取得授权才交owner；授权后并发知识变化允许重新评审同一已封存材料，不重新动作。新旧配对快照比较忽略命中计数变化但比较节点身份和完整定义，避免真实命中使无关正常学习失效。

## 7. 验证、错误与完成边界

当前仅编译/链接授权。新增或迁移现有实际工程自检代码，但不运行；禁止临时测试项目。验证资源独占，命令见[计划](../../计划/20261016_SIMULATION-PARAMETER-SCENE_通用模拟参数场景计划_v0.1.md)。

未来具名测试矩阵：声明新建/原ID补登/冲突零写/旧无声明；多角色同FT唯一定位；多 I64 输入和多输出；非连续域不采空洞；已有配对续学；收尾独立场景；集合成员重映射；写输入-only/现实ID/跨样例动作拒绝；同值零伪动态；动作后部分失败保留；结果域外实际值保留；概念中途改变不再发布；真实结算值、真实任务树、运行统计不变；未知与工程错误分账。方法owner存取/复制和现有任务规格相等比较不得回归。

技术状态映射：资源失败→`资源不足`；结构不一致/不合法引用→`结构不一致`；定义变化→`停止取消`并在记录具名说明，不是知识失败；发布后未知→`发布结果未知`；函数工程停止→`本能运行异常`。合法不支持、合法条件不成立、结果未知不进入工程异常，也不生成成功/失败经验配对。

完成只表示：有限支持域有通用参数场景提供者、原结算函数消费和生产学习驱动，方法声明存取/冻结闭合，实际工程编译链接通过。尚不证明运行正确、全部本能支持、尝试代入、异常发布、可靠度或完整内部治理。具名裁决闭合、父级审查通过及索引登记之前，不得标可执行。

### 7.1 尚未闭合：完成叶域到结果区间的抽象

不能把准确点C的集合当原宽声明域已覆盖，也不能因出现点就无偏差自动分割空洞。应消费算法真正形成并完成复测的叶域作为候选C，保留当叶全部同次联合样例来源；但结果R的形成仍须明确：是否允许将当叶实际输出的最小/最大值构成可修正的预测区间，而不宣称全域所有值已实测或必然可达？现行5370允许有依据区间知识，但没有给出这一包络抽象规则；现有特征聚合规则也不能自动填平离散值空洞。

多输出还受5350“联合结果约束”约束：逐输出取包络不能自动证明各区间任意组合可达，当前结果DTO无显式联合值域对应关系。最小可闭合选择是本包先只正式发布单输出区间候选，多输出仍经通用场景求值并保留材料、不发布；这仍需确认单输出区间抽象规则。不得由代码执行者临场选择。

### 7.2 留存复核说明（不是裁决）

后续独立复核进一步收窄第7.1节的建议：保留“叶区域＋该叶完整联合样本”，不丢失宽域续学入口。单输入、单输出且样本支持现有线性模型时，可以讨论生成可修正的预测区间条件结果对；必须保留模拟来源、零真实命中和有限采样边界，不能表述为全域已经实测。

一般多输入、多输出不能只按各输出的最小值、最大值生成独立包络。例如 `x → (x, -x)` 的独立包络会引入未出现的输出组合；`y = x * z` 的逐轴线性也不证明全局仿射。因此“仅单输出”本身不足以保证已有模型能完整表达多输入关系。只发布准确点会丢失宽域续学入口；按声明域减已知点补洞则会引入未经偏差判定的细分，这两条都不作为已确认方案。

留待用户裁决的问题是：是否先保留完整联合样本，只发布现有模型能够完整表达的区间，其余保持未知，不擅自推算；或者另行明确一般联合预测模型。当前用户要求完整提交信息，并未对该问题作出裁决。本文前面的准确点候选接口仍是未收口草稿，不得据其直接实施；待裁决后统一修订候选、评审和发布合同。
