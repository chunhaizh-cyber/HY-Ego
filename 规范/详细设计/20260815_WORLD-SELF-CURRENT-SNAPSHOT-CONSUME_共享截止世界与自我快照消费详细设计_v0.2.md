# 共享截止世界与自我快照消费详细设计 v0.2

日期：2026-08-15

计划身份：`WORLD-SELF-CURRENT-SNAPSHOT-CONSUME`

替代关系：同身份 v0.2 正式替代 v0.1；v0.1 的两个 owner 可异截止合同永久冻结，不得实施。

## 1. 目标与完成边界

实现 `BIZ-L3-002-02-01 v0.3`：根据父级冻结的一个非零共享事实截止，经普通应用同一 `L2结构聚合服务`取得场景与存在服务，依次读取现实世界整树、自我单例角色、完整自我存在、当前场景成员反向关系以及内部世界宿主正反向关系。全部结果截止必须等于请求截止，全部身份、关系和拓扑逐字段一致后才返回完整值式快照。

本叶只读，零 DATA 写、零 BIZ 缓存、零默认补造。它不实现共享截止读取函数、不读取安全、服务、需求、任务、方法或线程事实，不持有普通应用上下文，也不开启自我治理运行门。

完成只证明本叶 provider 能按一个共享截止形成世界—自我快照。父级 `G0/G1` 闭合、SELF-FORM 实际结果复制、普通应用装配、自我线程接线和集成验收保持 `NOT_RUN`。

## 2. 当前事实与漂移裁决

正式基线 `52bd417011dc98ebc22a47b0b7b653079ae68301` 中：

- 4015 固定每次成功写集推进同一 L1 的一个全局事实代次；owner 只约束写入来源。
- 4230 固定普通应用七个世界结构 owner 使用同一个 `L1事实基座运行包`；场景与存在读取共用事实代次空间。
- `L2结构聚合服务`已有场景、存在 const / non-const 同实例 getter。
- 场景服务已有整树、存在当前成员反向组、场景宿主正向和存在宿主场景反向读取；存在服务已有单例角色和完整存在读取。

## 3. 基础数据消费合同

本叶只复用 `计划/数据服务最终需求清单.md v0.4` 的 DATA-EXT-01、02、07。

| 业务目的 | 公开服务与操作 | 输入 | 成功结果 | 非成功 |
| --- | --- | --- | --- | --- |
| 取得同实例服务 | `L2结构聚合服务::取得L2场景结构服务()`、`取得L2存在结构服务()` const getter | 构造注入的同一聚合服务 | 两个 const 服务引用 | 装配失败不在本函数补建 |

所有请求头的 `期望事实代次`都使用同一个非零截止。BIZ 不直达 L1，不以 `期望事实代次=0`读取单对象，也不读取 owner 身份或发布见证 token。

## 4. 函数、DTO 与物理位置

新建真实模块：

```text

模块：海中鱼巣.领域.组合.运行期只读查询
唯一所有者：BIZ 跨结构只读组合
```

公开合同固定为：

```cpp
inline constexpr std::uint32_t 世界自我共享截止快照合同版本 = 2;

struct 世界自我共享截止快照请求 final {
    std::uint32_t 合同版本 = 世界自我共享截止快照合同版本;
    std::uint64_t 运行代次 = 0;
    std::uint32_t 事实范围版本 = 0;
    L2场景树身份 现实世界树;
    L2场景身份 根场景;
    L2存在单例角色键 自我角色;
    L2存在身份 自我存在;
    稳定编码 自我角色关系编码;
    L2场景身份 自我所在场景;

    L2场景身份 自我内部世界场景;

```

结果状态稳定顺序为：

```text
已形成=1、请求拒绝=2、材料缺失=3、当前性漂移=4、提供者拒绝=5、资源失败=6、内部不一致=7
```

`世界自我共享截止快照`精确包含合同版本、运行代次、事实范围版本、事实截止代次、完整现实世界树、自我角色关系、自我存在身份来源、完整自我存在、唯一所在场景成员引用和内部世界宿主关系。整树已经内嵌的根、场景、成员和宿主不复制成第二权威字段。

结果只在 `已形成` 时携带快照；其它状态快照必须为空。结果可以另带具名失败来源枚举，但不得携带成功前缀或部分 DATA 载荷。

```cpp
class 运行期只读查询组合器 final {
public:
    explicit 运行期只读查询组合器(
        const L2结构聚合服务& 结构聚合服务) noexcept;

    世界自我共享截止快照结果 读取共享截止世界与自我快照(
        const 世界自我共享截止快照请求& 请求) const noexcept;

```

组合器不可复制、不可移动，只借用聚合服务 const 引用。构造不读取事实，不缓存 getter 结果或上次快照。

## 5. 固定读取与互证顺序

```text
校验合同、身份、关系编码、范围版本和非零共享截止
-> 取得同实例场景 / 存在服务
-> 以共享截止读取现实世界整树
-> 以共享截止读取项目唯一自我角色
-> 以共享截止读取完整自我存在
-> 以共享截止反向读取自我当前场景成员组
-> 以共享截止正向读取内部世界宿主
-> 以共享截止反向读取自我当前宿主场景
-> 复核全部结构化状态、载荷和结果截止
-> 逐字段互证
-> 局部完整候选一次构造并返回
```

逐字段互证至少满足：

1. 六项读取结果截止全部等于请求 `事实截止代次`；任一漂移整体失败。
2. 整树身份、唯一根和请求一致，根、所在场景、内部世界场景互异且各恰一存在。
3. 整树父子关系恰证明 `根 -> 所在 -> 内部世界` 两条直接边。
4. 自我当前成员反向组恰一，与请求关系编码、场景、存在相等，并与整树所在场景的正向成员完全相等；内部世界不得把自我列为直接成员。
5. 内嵌宿主、正向宿主和反向宿主逐字段相等，并与请求关系编码、内部世界场景和自我存在一致。
6. 自我角色键、角色关系编码和目标存在与请求一致；身份来源属于存在族且编码等于自我存在。
7. 完整存在身份与请求一致，并在共享截止上处于活动生命周期。

## 6. 状态映射与失败守恒

| DATA / 请求情况 | BIZ 状态 | 守恒 |
| --- | --- | --- |
| 坏合同、零截止、零身份或非法关系编码 | 请求拒绝 | 零 DATA 调用或在首个可判定点停止；零快照 |
| 必需对象未找到 / 已退出、成员组为空 | 材料缺失 | 不用默认值、历史值或缓存补齐 |
| 任一 DATA 结果事实代次漂移 | 当前性漂移 | 父级必须从新 G0 重新开始整轮读取 |
| 固定合法请求被入口拒绝、引用冲突或预算拒绝 | 提供者拒绝 | 不降级为空 |
| 任一资源失败 | 资源失败 | 本次零快照；只读调用可由父级重新发起 |
| 坏成功形状、截止不等、复义、拓扑或关系矛盾 | 内部不一致 | 零部分发布，停止依赖路径 |

本函数无可变已发布值和幂等账。异常捕获中 `std::bad_alloc`、`std::length_error` 映射资源失败，其它异常映射内部不一致。

## 7. 并发与一致性

- 组合器无锁、无缓存，每次调用只使用局部值式结果。
- DATA 服务各自按请求共享截止执行严格乐观守卫；BIZ 不取得仓库、锁或事务。
- 同一 L1 的任何 owner 发布都会推进全局事实代次，使后续读取返回漂移或父级 G1 不等于 G0。
- 任一漂移时不只重读失败对象，不把新结果与本轮旧结果拼装。
- 父级最终成立条件固定为 `G1 == G0 == 每项子结果截止`。
