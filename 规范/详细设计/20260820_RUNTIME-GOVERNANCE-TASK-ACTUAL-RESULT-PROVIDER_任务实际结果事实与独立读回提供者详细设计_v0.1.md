# 任务实际结果事实与独立读回提供者详细设计

日期：2026-08-20

身份：`RUNTIME-GOVERNANCE-TASK-ACTUAL-RESULT-PROVIDER v0.1`

代码基线：`946e3be8167d25ba0d4d7c11a9342030d8ebbb42`

## 1. 目标与边界

本叶建立治理判断所缺少的第一份正式任务实际结果：任务 owner 以不可变追加事实保存一次任务执行轮次与独立状态、动态及执行上下文的绑定，并由现有运行期只读查询组合器在调用方给定的同一 `G0` 下重新读取全部权威事实。

完成条件：

```text
任务 + 执行轮次唯一实际结果
+ 同义重复幂等 / 异义重复冲突
+ 按结果身份读取 / 按任务与执行轮次读取
+ 公开接口写入后经公开组合器同G0独立读回
+ v3任务结果输入的全部字段逐项有权威来源
```

本叶不裁决任务完成、需求满足、方法成功或价值结算；不接 002-04，不调用 002-06，不进入任务筹办或任务执行。任务实际结果不提供普通更新、替换、退出或删除。

## 2. 当前事实与必要前置

当前 `L2任务结构.数据.h` 只有任务、任务方法路径和实例方法事实；没有任务实际结果身份、事实或读写函数。`L2实例方法事实`也不能表示实际状态或动态。

现行 `L2任务结构服务` 的 `发布当前选中路径`、`创建实例方法`、`读取实例方法`、`按任务读取当前实例方法`仍是占位：合法创建固定返回入口拒绝，读取返回空的已读取结果。若不在同一 owner 内补齐这些入口，任务实际结果无法通过公开 DATA-L2 接口合法建立，验证只能伪造私有事实。

裁决：本叶在相同数据头、相同任务 owner 和相同服务文件内，先机械激活发布当前选中路径、创建实例方法、按身份读取实例方法和按任务读取当前实例方法，再建立实际结果。它只是 DATA-L2 结构能力，不执行方法、不选择候选、不决定筹办状态。

旧 `BIZ-L4-002-04-01-01 v0.1` 中“工作项、任务结论和任务业务服务”不是当前可实现合同；本设计只替代其最底层实际结果提供者部分，不宣称该图或 002-04 已实现。

## 3. 任务实际结果公开合同

### 3.1 身份与事实

在 `海中鱼巣/领域/L2任务结构.数据.h` 新增：

```cpp
struct L2任务实际结果身份 final { 稳定编码 值; };

struct L2任务实际结果事实 final {
    L2任务实际结果身份 身份;
    L2任务身份 任务;
    L2实例方法身份 实例方法;
    std::uint64_t 执行轮次;
    L2方法身份 方法;
    L2方法动作入口身份 动作入口;
    L2场景身份 场景;
    L2存在身份 主体;
    L2状态身份 实际状态;
    L2动态身份 动态证据;
    std::uint64_t 来源材料版本;
    std::uint64_t 运行代次;
    L2生命周期 生命周期;
};
```

全部身份和四个数值必须非零。事实只保存结构绑定，不保存“成功、完成、满足、结算”布尔值或枚举。

### 3.2 DTO 与公开函数

新增请求/结果和值式守卫：

```cpp
L2记录任务实际结果结果 L2任务结构服务::记录任务实际结果(
    L2记录任务实际结果请求 请求) noexcept;

L2任务实际结果读取结果 L2任务结构服务::读取任务实际结果(
    L2任务实际结果读取请求 请求) const noexcept;

L2按任务与执行轮次读取实际结果结果
L2任务结构服务::按任务与执行轮次读取实际结果(
    L2按任务与执行轮次读取实际结果请求 请求) const noexcept;
```

记录请求含 `L2结构请求头`、`L2结构幂等身份`及事实除身份、生命周期外的全部字段。两个读取入口都接受当前或历史截止；本叶专项使用当前读取和调用方非零 `G0`。不存在指定结果时返回已读取且空载荷；坏端点、重复槽、半结构和同截止矛盾返回内部不一致。

### 3.3 唯一性、幂等与不可变性

唯一键固定为 `任务 + 执行轮次`。在任务节点建立一条“任务实际结果槽”关系，关系源为任务、目标为结果、`角色或顺序=执行轮次`。同一任务同一轮次当前恰零或一条：

- 零条：允许首次追加；
- 一条且全部字段与首次规范化事实相等：返回精确重复，沿用首次事实代次和结果身份，不推进代次；
- 一条但任一字段不同：返回引用冲突，零写入；
- 多条或端点坏形状：内部不一致。

结果节点、关系和值发布后不原地修改，也不提供普通退出或删除。任务退役不得删除结果历史。

## 4. 结构登记与事务

禁止修改既有两个固定登记写集后使用原幂等键重放；这会把已发布登记变成异义冲突。新增两个独立的追加登记幂等身份：

```text
任务实际结果身份来源登记：0x4C32'5441'5253'4944
任务实际结果结构类型登记：0x4C32'5441'5253'5459
```

保留键范围固定为：

```text
身份来源/属性类型：0x0301'2015—0x0301'201A
公开关系类型：    0x0301'2141—0x0301'2149
单次结果写集：    0x0301'2231—0x0301'223C
```

身份来源登记承载结果族锚点、族归属关系类型、族归属固定关系、实例方法执行轮次属性类型、来源材料版本属性类型和运行代次属性类型。公开关系类型依次为结果族归属、任务结果槽、实例方法、实际状态、动态证据、方法、动作入口、场景和主体。

首次结果写集固定为：一个结果节点；结果到族锚点、实例方法、实际状态、动态、方法、动作入口、场景、主体八条关系；任务到结果一条轮次槽关系；来源材料版本、运行代次两个单元素 `VecU64` 值及两个属性槽。执行轮次只由任务结果槽的正数 `角色或顺序`权威承载，不再保存第二份数值；执行轮次进入该有符号槽前拒绝超过 `INT64_MAX`，来源材料版本和运行代次不做有符号窄化。

实例方法激活使用既有登记和关系类型，只新增上述“实例方法执行轮次属性类型”。创建实例方法原子写入一个节点、实例方法族归属、实例方法到任务、实例方法到路径、任务到当前实例方法四条关系，以及一个执行轮次 I64 属性。筹办轮次、来源方法和内容版本从不可变路径事实读回并与请求逐项相等，不另存第二权威。

发布当前选中路径在同一写集中退出旧当前关系并建立新当前关系；新路径必须当前、属于同一任务。创建实例方法前必须确认请求路径就是当前选中路径。既有当前实例方法存在时本叶返回引用冲突，不隐式替换；退出和下一执行轮次切换留给后继独立设计。

## 5. 字段权威来源

运行期公开读回请求不导入线程协议，直接承载与 v3 消息等形的强类型期望字段：任务、实际状态、动态、方法、动作入口、场景、主体；另含执行轮次、来源材料版本、运行代次、共享事实截止 `G0`和最大需求成员数。002-04 后继只负责值式适配，不得让 DATA/BIZ 反向依赖线程模块。

| 字段 | 权威来源与同G0互证 |
| --- | --- |
| 任务 | 实际结果事实、`读取任务`和实例方法的任务必须相等 |
| 执行轮次 | 任务结果槽顺序、实例方法执行轮次和请求必须相等 |
| 方法 | 实际结果事实、实例方法来源方法、选中路径来源方法必须相等 |
| 动作入口 | 实际结果中的强类型身份，其稳定编码必须等于选中路径完整材料的动作入口；不从日志或方法返回推断 |
| 实际状态 | 实际结果引用与 `L2状态结构服务::读取完整状态`身份相等 |
| 动态证据 | 实际结果引用与 `L2动态结构服务::读取完整动态`身份相等；动态后状态等于实际状态 |
| 主体 | 实际结果、状态主体和动态主体三者相等 |
| 场景 | 当前状态/动态 DTO 没有场景字段，因此作为结果事实的强类型执行上下文直接冻结；同时读取完整场景，并确认主体的当前场景成员引用包含该场景。不推断其一定是方法输入场景或输出场景 |
| 来源材料版本 | 实际结果不可变 I64 属性与请求相等；不使用消息编号、日志版本或任务序号代替 |
| 运行代次 | 实际结果不可变 I64 属性与请求相等；不等同事实代次 |
| G0 | 只来自本次公开读回请求；全部 DATA-L2 结果头的事实截止代次必须精确等于该值 |
| 来源需求成员 | 从任务读取需求列表项，再由 `读取需求列表项完整`、`读取需求列表成员`取得全部当前成员关系，并逐成员调用 `读取需求完整`；稳定排序且不得截断 |

v3 现行载荷没有执行轮次；本叶 provider 以显式执行轮次参数完成独立服务验证。后继 002-04 不得把 `来源任务序号`解释为执行轮次；它必须从正式执行绑定取得轮次，若届时仍无来源，应具名退回协议修订。本边界不阻断本叶 DATA/provider 独立实现。

## 6. 运行期只读提供者

在 `运行期只读查询.数据.h` 新增：

```cpp
enum class 任务实际结果独立读回状态 : std::uint8_t {
    已形成, 尚未形成, 请求拒绝, 轮次不匹配, 当前性漂移,
    数量预算不足, 引用冲突, 资源失败, 内部不一致
};

struct 任务实际结果独立读回请求 { /* §5 全部期望字段 */ };
struct 任务实际结果独立读回快照 {
    L2任务实际结果事实 结果;
    L2实例方法事实 实例方法;
    L2任务方法路径事实 选中路径;
    L2任务事实 任务;
    L2状态事实 状态;
    L2动态事实 动态;
    L2场景事实 场景;
    L2存在事实 主体;
    L2需求列表项事实 需求列表项;
    std::vector<L2需求列表成员关系事实> 来源成员关系组;
    std::vector<L2需求事实> 来源需求组;
    std::uint64_t 事实截止代次;
};
```

在 `运行期只读查询组合器` 构造中新增 `const L2动态结构服务&`，并新增：

```cpp
任务实际结果独立读回结果 读取任务本轮实际结果与独立读回(
    const 任务实际结果独立读回请求& 请求) const noexcept;
```

顺序固定为：守卫请求；按任务+轮次读结果；空结果返回尚未形成；按结果字段读实例方法、路径、任务、状态、动态、场景、主体、列表项、成员组和逐成员完整需求；每笔先检查结果头截止等于 `G0`，再检查成功形状；最后执行 §5 全字段互证并形成不可变快照。任何笔截止漂移立即返回当前性漂移且不返回部分快照。

需求成员超过请求预算时返回数量预算不足，不能截断。成员关系和完整需求按身份稳定排序，重复身份、关系/事实数量不等、列表项错配或空列表项但任务引用它均为内部不一致。

## 8. 公开模拟验证

只使用普通应用/现有公开服务和公开组合器：建立需求列表项及至少两个当前需求成员、任务、方法路径、当前选中路径、实例方法、场景/主体、状态、动态，再记录实际结果；取得新 `G0` 后通过公开组合器读回并逐字段比较。

必须覆盖：

1. 首次记录和全部字段同G0成功读回；
2. 同幂等身份和同字段精确重复不推进代次；
3. 同任务+同执行轮次异义提交引用冲突且原结果不变；
4. 未记录的下一轮返回尚未形成；
5. 请求轮次与实例方法/结果槽不配返回轮次不匹配或尚未形成，不误读其它轮次；
6. 使用旧 `G0` 读取随后发布的结果返回尚未形成，任一子读截止不等请求 `G0` 返回当前性漂移；
7. 方法、动作入口、场景、主体、状态、动态、来源材料版本或运行代次任一不配均不得成功；
8. 两个来源需求成员完整、稳定排序且预算不足不截断；
9. 根工程 Debug/Release fresh Rebuild、两配置 `--test-治理`、strict 和 diff 检查通过。

验证不允许直接调用 L1、私有 helper、测试 seam 或手工构造结果事实。

## 9. 完成声明边界

完成只证明任务实际结果不可变结构、最小实例方法结构前置和同G0公开独立读回 provider。它不证明任务结果可由当前 v3 消息直接定位，不证明 002-04 已消费，不证明任务完成、需求满足、结算、任务筹办、任务执行或真实治理闭环。
