# RUNTIME-DEMAND-CURRENT-SATISFACTION-ADJUDICATION 需求当前满足实时裁决详细设计 v0.1

日期：2026-08-23
版本：v0.1

## 1. 目标、范围与完成条件

本设计闭合子需求回流后父需求重判路线中当前最早缺失的代码 provider：

```text
调用方给出一份当前需求和共同事实截止 G0
-> 读取该需求的当前目标三元组及当前列表成员关系
-> 读取目标宿主当前特征实例与当前值
-> 读取目标状态合同与正式目标判断比较注册
-> 调用 L2 特征比较服务
-> 返回携带需求身份、目标、当前事实、来源、规则版本、比较证据和 G0 的值式裁决
```

完成必须同时成立：

1. `运行期只读查询组合器`公开提供`裁决需求当前满足`；
2. 裁决以需求身份为入口，逐份需求读取其当前成员关系，不以列表项或任务替代需求身份；
3. 目标宿主、目标特征、目标状态合同、当前特征实例、当前值和比较注册全部来自同一 G0 的公开 L2 读回；
4. 只有正式`L2特征结构服务::比较特征`的具名关系与目标合同允许位共同形成`已满足/未满足`；
5. 需求节点不新增永久满足布尔值，组合器零机器事实写入；
6. 没有当前任务、没有任务实际结果或没有旧筹办轮次时，需求当前满足仍可独立裁决；
7. 实现不需要执行者再决定 DTO、函数位置、字段来源、错误映射、共同截止、比较规则或验证标准。

本 provider 完成后，直接后继才可以消费`子需求已回流待父需求重判`记录，先对显式父需求调用本入口，再按当时当前列表成员和列表项当前任务关系选择“不筹办 / 初次筹办 / 新重筹办轮次”。

## 2. 明确排除项

本叶不做：

- 不消费任务子目标承接记录，不扫描待父需求重判记录；
- 不直接唤醒来源任务，不保存永久来源任务关系；
- 不建立新任务、初次筹办请求、重筹办请求、路径、实例或冻结；
- 不复活旧任务、旧路径、旧实例、旧冻结或旧筹办轮次；
- 不修改需求节点、列表项或任务状态；
- 不执行逐需求成员结算、结果共用/争用裁决、成员分配优先级、价值、预算或归因分配；
- 不把任务完成、方法成功、历史结算、回流记录、当前任务存在或日志当作需求当前满足；
- 不扩展特征比较算法、原始类型、单位、维度或目标合同语义；首版只消费当前已实现的 I64 目标判断合同；
- 不修改治理线程、任务管理线程、普通应用装配、工程登记、正式规范、知识库或两个维护智能体拥有的聚合文件。

## 4. 正式依据与机器不变量

- 0050：机器事实、值式裁决、非成功、日志和完成声明分账。
- 3100：需求目标是`目标宿主 + 目标特征 + 目标状态合同`；当前满足必须实时读取当前事实并经正式比较/判断收束；任务完成、方法成功、历史结算均不能替代。
- 3200、5090、5100、5200、5210、5220：任务承接需求目标但不修改需求；子需求回流只触发重新裁决；现行任务主链按需求列表项查询当前任务，不恢复旧任务父子树。
- 4010、4030、4050：组合器只经公开 L2 服务读取；引用、当前性、许可、资源和内部错误分账。
- 4110：同一宿主和同一抽象特征定义在同一当前版本只能有一个有效实例槽，多项是唯一性破坏。
- 4160、4180：目标判断必须经注册的强类型比较算法；左右角色、单位、维度、算法版本和值域拒绝不得由调用者猜测或交换。
- 4190、4230：当前特征值、状态和动态是分立结构；按存在读取的完整当前特征组已经在同一截止承载实例及 optional 当前值。本叶消费当前特征值作为目标当前事实，不从它补造`L2状态事实`或`L2动态事实`。
- 4250 第 13—16 节仅用于解释现有 DATA 外业务接口方向；该文件在规范目录中仍带待确认边界，不能单独作为机器语义来源。
- 0600、CODE-FILE-01：优先扩展职责匹配的既有 BIZ 组合模块；函数、变量和业务成员使用中文；代码结果形成函数级知识交接。

固定不变量：

```text
需求当前满足
= 当前需求目标三元组
+ 目标宿主在同一 G0 的当前特征值
+ 同一 G0 的目标合同和目标判断比较注册
+ 正式比较结果
```

并且：

```text
需求当前满足 ≠ 任务完成
需求当前满足 ≠ 方法成功
需求当前满足 ≠ 回流记录存在
需求当前满足 ≠ 列表项存在当前任务
需求当前满足 ≠ 永久写回需求节点
```

同一列表项中的成员可以得到相同目标和当前事实比较材料，但每次公开调用必须保留请求中的具名需求及其当前成员关系，不能只返回列表项级无成员裁决。

当前需求目标三元组没有场景字段。本入口不要求调用方补造目标场景或场景树；`按存在读取全部当前特征`已经以强类型目标宿主读取其当前实例组。场景资格、状态、动态或因果若成为其它业务前置，应由对应后继以独立正式合同读取，不能塞入需求当前满足三元组或从当前特征值推导。

## 6. 固定算法与分支

全部公开读取使用请求中的同一`G0`；任一结果回显截止不等于 G0，立即返回`当前性漂移`和零裁决，不在本函数内取得新截止重试。

### 6.1 入口与需求结构

1. 校验合同版本、非零裁决请求身份、有效需求身份、非零 G0；失败为`入口拒绝`。
2. 调用`读取需求完整({头, 当前, 请求.需求, 0})`。
   - 未找到、已退出、属性未设置：`证据不足`；
   - 入口拒绝：`入口拒绝`；许可拒绝：`许可拒绝`；
   - 资源失败/数量预算不足：`资源失败`；
   - 其它坏成功形状：`内部错误`。
3. 调用`读取需求成员列表({头, 当前, 请求.需求, 0})`。当前需求没有唯一当前成员关系或完整所属列表项，或关系端点不是请求需求，属于统一需求结构破坏，返回`内部错误`。
4. 逐字段互证需求与列表项的所属存在、目标宿主、目标特征和目标状态合同完全一致；不一致返回`引用冲突`。

### 6.2 当前事实选择

5. 调用`按存在读取全部当前特征({头, 需求.目标宿主存在})`。
6. 只保留`宿主存在 == 目标宿主`且`特征定义 == 目标特征`的当前特征实例：
   - 零个：`证据不足`；
   - 恰一个：继续；
   - 多于一个：`内部错误`，因为违反同宿主同定义当前实例唯一性；禁止按遍历顺序或稳定编码任选。
7. 直接读取唯一完整实例的`当前值`：
   - `当前值`为空：`证据不足`；
   - 当前值的特征实例不是唯一实例：`引用冲突`；
   - 当前值生命周期、来源或截止投影不完整：`内部错误`。

`按存在读取全部当前特征`的成功载荷已经把实例及 optional 当前值闭合在同一 G0；禁止再调用`读取特征当前值`形成第二次读取或混代机会。

### 6.3 目标合同与正式比较

8. 读取完整目标状态合同和当前目标判断比较注册。缺合同为`证据不足`；缺注册/未实现为`不可比较`。
9. 互证合同身份、合同特征定义、合同比较注册、合同比较用途、注册特征定义和注册用途均指向需求目标；不一致为`引用冲突`。
10. 首版要求当前值材料为 I64，目标合同使用 I64；其它类型返回`不可比较`，不做隐式转换。
11. 形成`L2特征比较请求`：
    - `请求身份 = 裁决请求身份`；
    - 左输入事实身份/值/来源/版本/生命周期来自`当前特征值`；
    - 右输入事实身份/值/来源/版本/生命周期来自`目标合同`；
    - 单位、维度、分量角色和算法族/版本来自当前比较注册；
    - 用途固定`目标判断`，左右角色固定`当前事实/目标状态`，要求结果位固定`具名关系`。
12. 调用`比较特征`并完整核对请求身份、G0、注册、算法版本、结果位、具名关系、左右输入回执、单位、维度、分量角色和角色。坏成功形状为`内部错误`。
13. 使用现有`运行期只读查询细节::目标判断关系位`取得关系位；不支持的具名关系为`不可比较`。
14. `目标合同.允许关系位 & 关系位`非零返回`已满足`，否则返回`未满足`；两者都携带完整快照。

### 6.4 统一非成功映射

| 底层状态/条件 | 公开状态 |
| --- | --- |
| 任一结果截止不等于 G0、`事实代次漂移` | `当前性漂移` |
| 当前需求/当前特征实例值/目标合同尚无、已退出 | `证据不足` |
| 比较注册不存在、算法未实现、类型/单位/维度/角色/值域不支持 | `不可比较` |
| 当前实例复义 | `内部错误` |
| 需求—列表—实例—合同端点不一致 | `引用冲突` |
| 请求/底层入口拒绝 | `入口拒绝` |
| 底层许可拒绝 | `许可拒绝` |
| 资源失败、数量预算不足、`bad_alloc`、`length_error` | `资源失败` |
| 已读取/已比较但载荷缺失或回执矛盾、未知枚举、其它异常 | `内部错误` |

所有非成功返回必须为零裁决；不得把证据不足写成未满足，也不得把不可比较写成未满足。

## 7. 事务、并发、生命周期和副作用

- 本函数只顺序调用公开 const 读取/比较入口，不取得 L1、仓库、端口或内部锁；每个服务自行完成其短锁读取。
- 本函数不跨调用持锁，不存在多仓锁序、锁升级、持锁 I/O 或等待。
- 请求和结果均为调用期值；组合器只继续借用现有服务实例，不新增 owning 状态。
- 整个函数零 DATA 写、零任务写、零需求写、零缓存、零事件、零邮箱和零日志机器语义。
- `G0`只证明该截止下的当前满足裁决；未来事实变化后必须重新调用，历史成功不永久有效。

## 10. 直接后继与用户新增约束

本 provider 发布后，父需求回流编排必须：

```text
读取一份待父需求重判的回流记录
-> 从记录取得显式父需求
-> 调用本入口实时裁决父需求当前满足
-> 读取当时当前需求成员和列表项当前任务
-> 已满足：不形成新筹办
-> 未满足且无当前任务：形成新任务的初次筹办请求
-> 未满足且有当前任务：只能按当前任务事实决定是否形成全新筹办轮次
```

后继不得永久直连唤醒记录中的旧来源任务，不得复用旧路径、旧实例、旧冻结或旧轮次。

更后的逐成员结果核算保留用户本轮新增约束，但不进入当前 DTO、函数或验证：

- 先裁决结果与各需求之间是`可共用`还是`争用`；
- 可共用结果允许多个合格需求共同引用，但必须逐需求独立重读、判定和结算，价值、预算和归因不得重复领取；
- 争用结果必须冻结待分配结果、合格需求候选和正式成员分配优先级证据，按该优先级逐一分配，每次扣减剩余后再处理下一成员；
- 禁止把任务执行优先级、队列顺序、需求权重、预算、创建时间或稳定编码冒充成员分配优先级；该优先级尚无正式机器合同，后继不得自行猜测。

## 11. 完成声明边界

未来代码与验证完成后只证明：任一当前需求可以在同一 G0 下，经当前需求/成员/列表项、目标宿主当前特征值、目标合同、比较注册和正式比较形成值式`已满足/未满足`裁决，并保留完整来源与比较证据。

不得声明：

- 子需求回流已经自动触发父需求重判；
- 父需求已被永久标记满足；
- 新任务、初次筹办或重筹办已经形成；
- 旧任务、路径、实例或冻结已经合法复用；
- 逐成员结算、结果共用/争用、成员分配优先级、价值、预算或归因已经实现；
- HY-Ego 顶层闭环已经完成。
