## 1. 目标及边界

针对已经明确主体 H、指定被认知需求 D、要求概念及来源自我需求 G 的整体内容目标，正确区分：稳定尚未挂接与本次读取发生变化。只有 H 的需求特征当前引用指定 D，且 D 内容符合要求，才判整个目标已满足。

本叶只改变服务对象需求发布服务的只读判定，不实现本能函数，不修改现实存在或虚拟存在的特征值。原因是当前整体目标调用严格当前定位读口，把 F 缺失、current 空或 current 为另一 D 当成漂移，阻止已有公开目标求值的真实消费者继续分解。目的为返回有完整当前保护的未满足及字段缺口，不补造动作、状态、动态或因果。

用户当前已明确：内容完整与落实到 H 的需求特征是两个事实；缺值不能当工程故障，工程故障也不能当业务缺口。目标静态不改，D 不因本叶进入自我需求树。

本叶不创建 G/D，不承诺正常启动已能首次产生未挂接 D 的整体目标，不实现方法召回、正式 F→D 结果关系、学习、参数绑定、字段写方法、目标实例绑定或发布本能。它接通的是既有 G/D 的公开求值及现有提议消费者，不是首次来源提供者。

## 4. 关联读取流程与负事实保护

1. 拷贝初始保护。它必须已含核验内容定义的 H 完整联合快照及指定 D 身份/内容保护；不得以只有 H 编码代替持有 F 组的负事实依据。通过存在 owner 获取 H 的完整 DTO，保留本次特征组供末尾重核；读取失败时先核保护是否变化，稳定损坏走原发布故障。
2. 经世界根公开 getter、场景 owner 获取场景及直接所属/父链，确认 H 仍直接属于传入场景且场景位于该世界。用现有中性捕获 helper 保护场景、世界根及从该场景到根的实际父链；parent 值由场景 DTO 取得，不解码私有字段。父链环/稳定破损仍工程故障，真实关系变化返回前提已变化。不能只读场景 bool 而丢弃定位保护。
3. 调用现有找特征(H,新类型,&保护)，完整扫描 H 全部持有 F 及各 FC 定义。E 的完整快照必须先合入，所有 F/FC 保护必须合入，不能从空 optional 直接判未满足。扫描同类型多 F、非顶层或稳定不可读 F 保持原故障边界。
4. 新 F 不存在时，再以同保护扫描旧类型：有旧类型 F 则未支持，保留原材料，不迁移、不当作新型 F 缺失。没有新旧 F 且完整保护和 fresh 映射均仍一致，返回已读取、已关联=false、F为空。新 F 存在时不因同时保留了合法旧迁移材料而额外阻挡当前新 F；不扩展旧迁移判断。
5. 新 F 存在时，复用已捕获 F 完整原始联合快照，正式 getter 取得 current；FC 定义保护确认根为配置新类型，材料为需求节点引用、比较为需求身份精确、单位及实例单位为空，且 F 顶层并确属 H。快照与 getter 交叉读变化先返回前提变化；稳定类型/归属损坏走工程故障。
6. current 空时暂记未关联；不要求历史为空，不读取状态/动态，不从历史挑 D，也不把历史仍含目标 D 判当前已关联。历史结构和值合法性沿 F getter 原合同，不冻结历史 D 的全部内容。
7. current 非空时必须是合法稳定节点引用 D0。调用需求 owner 读取需求节点引用身份(D0)，确认成功载荷的节点为 D0、主体为 H、被认知=true，合入身份保护。依赖未装配返回依赖未就绪，资源失败返回资源失败，owner 前提变化返回前提已变化。值不存在、错误主体/域/类型或稳定坏结构先复核保护：变化则前提变化；保护仍同则走原工程故障，不伪造正常未满足。只比较 D0==指定 D；不比较编码大小、不切换求值对象。
8. helper 返回前重新取得 H DTO、直接所属场景/世界根，并重核场景父链及找特征映射。与本次已固定材料不同，或新扫描保护不能与原保护核同合并，都返回前提已变化。最后用需求内容联合仍相同完整复核合并保护；缺失/修改/类型变化均不能发表负事实成功。已读取返回真实 F（若有）、已关联 bool 和全部保护。

保护比较是当前完整材料一致性，不引入事实代次、不宣称跨调用持锁快照，也不提供生命周期租约。捕获完整快照只为预期保护，不自己解析领域字段。相同 F/FC 重读复用现有合并规则；本叶不改变已有 helper 的旧调用语义。

## 5. 整体状态合成及旧入口隔离

求值内容内部保留原调用占用、定义核验、场景定位、显式 D 内容读取、概念判断器、必要项目、分支及完整保护算法。

仅当 `要求当前引用==true && 正式内容路径.empty()` 时，替换原读取当前结构(预期 D)调用为新 helper；合并 helper 保护并记录真实 F 及已关联。依赖/未支持/资源/前提变化分别映射已有公开状态，不能折算成 false。

关联 false 不提前返回。继续对指定 D 做原纯内容读取与正式概念判定，保留缺值项目、关联约束及择一分支；不拿实际 current 的 D0 拼内容。原算法最终判定及非成功优先级保留，仅在原来将返回已满足时：

| 关联 | 指定 D 内容 | 整体结果 |
| --- | --- | --- |
| 已关联 | 符合 | 已满足 |
| 未关联 | 符合 | 未满足，必要项目可以为空 |
| 任意 | 明确不符/有未知必需项 | 原未满足及实际必要项目 |
| 任意 | 分支待定 | 原分支待定及分支信息 |
| 任意 | 依赖、未支持、资源、读取变化 | 原具名非成功，不被关联 false 覆盖 |

整体成功/未满足载荷保留场景；有新 F 时实际特征节点为它，即使 current 空或另 D；无新 F 时为空。所有正常状态发表前，按原结尾逻辑核全部内容、关联、负事实及范围保护。

`要求当前引用==false`：求值指定需求内容完整保留，不读关联、不要求 F，不降为未满足。

非空正式内容路径：保持原严格读取当前结构(预期 D)及旧求值语义，不借本叶放开单字段任务。公开读取当前需求结构内容及其内部读取当前结构实现不改，避免更改条件定位消费者的当前 D 固定合同。

## 6. 真实消费者与不扩张边界

当前真实调用边为：需求类复核引用内容目标 → 服务公开求值引用内容目标；任务提议任务复合目标 → 该判定及显式纯内容求值；需求复核当前满足/筹办资格 → 同一判定。

已回读：需求类复核当前满足把未满足映为未满足但无有向差值，复核筹办资格对引用内容目标允许该状态且不要求实际 F。任务复核任务筹办资格对内容目标直接使用核验批中该资格，不进入普通目标 F 缺失门。因此本叶不改需求/任务/线程即可让既有整体 G/D 稳定未挂接时取得未满足及纯内容分解材料。

不以纯内容齐备标记父任务完成。纯内容已满足而未挂接时，现有复合提议可以返回已形成空子目标组；后续继续父方法候选、F→D 正式关系及执行仍是未实现缺口，本叶不绕过。单字段叶子、已有执行前收束状态及其他消费者均不因本叶取得方法执行资格。

## 7. 所有权、锁与错误

root 是两源代码、Git/index、编译资源唯一所有者。计划智能体仅创建本设计及对应计划，不写生产、索引或 Git。

同一主体占用由原求值函数取得一次/释放一次；新 helper 不重新进入服务占用。服务互斥只维护占用集合，不持它跨 owner 调用；不增加任务锁/需求锁/存在特征锁的外部嵌套，不反入 task/self。owner 自己在公开读口内取锁，编排在各调用之间保留值式保护，最后完整 fresh 检查。

工程异常走原日志/弹窗/中止链；bad_alloc 映资源失败，既有需求结果读取变化映引用前提已变化。整个操作零事实写入，失败无回滚、无补状态、无自动重发。不得把 owner 失败变空 F 或 false 继续运算。
