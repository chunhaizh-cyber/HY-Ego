# DATA-L2 特征实例当前值具名读取详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-FEATURE-CURRENT-VALUE-READ`

## 1. 目标与边界

补齐 `计划/数据服务最终需求清单.md` 的 `DATA-EXT-03`：在唯一 `L2特征结构服务` 中提供具名“读取特征实例当前值”入口，使调用方无需读取并自行拆解完整实例，便可区分当前值存在、当前值未设置以及实例读取失败。

本叶只增加一组纯值读取 DTO、请求 helper、结果成功谓词和一个只读服务入口。它复用现有 `读取完整特征实例(...)` 的同截止事实，不新增 owner、写端口、当前槽、缓存、索引、工程登记、普通应用 getter 或 DATA-L3 转发，也不解释值的业务含义。

## 2. 当前事实与裁决

1. `L2特征实例事实::当前值` 已是 `std::optional<L2特征值事实>`，完整实例当前读取可以在非零事实代次守卫下返回同截止的可选当前值。
2. 现行公开服务已有 `新增特征当前值`、`换代特征当前值` 和 `退出特征当前值`，但没有具名当前值读取请求、结果或函数；要求调用方调用完整实例读取再拆字段，不满足最终需求清单明列的独立“读取实例当前值”操作。
3. 当前值为空是合法实例形状，但对具名当前值读取必须映射为 `属性未设置`，而不是 `已读取 + 空 optional`，从而让成功结果始终携带完整值事实。
4. 新入口只委托现有完整实例当前读取，沿用其 owner、身份来源、值类型登记、截止和坏形状校验；不直接读取 L1，不复制完整实例投影逻辑。
5. 单对象读取只接受非零 `期望事实代次`。零守卫仍只属于正式“读取全部当前组”入口，不在本叶扩张。

## 3. 精确公开 ABI

在 `海中鱼巣/领域/L2特征结构.数据.h` 增加：

```cpp
struct L2特征当前值读取请求 final {
    L2结构请求头 请求头;
    L2特征实例身份 特征实例;
    friend bool operator==(const L2特征当前值读取请求&,
        const L2特征当前值读取请求&) = default;
};

struct L2特征当前值读取结果 final {
    L2结构结果头 结果头;
    std::optional<L2特征值事实> 当前值;
    bool 成功() const noexcept;
    friend bool operator==(const L2特征当前值读取结果&,
        const L2特征当前值读取结果&) = default;
};

inline bool L2特征当前值读取请求有效(
    const L2特征当前值读取请求&) noexcept;
```

请求有效固定要求：共同合同有效、`期望事实代次 != 0`、特征实例身份非零。

在 `海中鱼巣/领域/服务.L2特征结构.ixx` 的 `L2特征结构服务` 原位增加：

```cpp
L2特征当前值读取结果 读取特征当前值(
    const L2特征当前值读取请求& 请求) const;
```

函数名、参数名和新增局部变量继续使用中文。

## 4. 成功与非成功形状

成功只允许 `结果头.状态 == L2结构状态::已读取`；结果截止非零，变更事实代次为空，`当前值` 必须存在并满足：

- `L2特征值事实截止投影完整(*当前值, 结果头.事实截止代次)`；
- 当前值所属特征实例等于请求实例；
- 当前值生命周期在结果截止仍未退出。

全部非成功的 `当前值` 为空且变更事实代次为空：

- 请求字段无效：`入口拒绝`；
- 实例不存在、已退出、许可拒绝、事实代次漂移、资源失败或内部不一致：机械保持现有完整实例读取的结构状态与事实截止；
- 实例存在且完整，但当前值为空：`属性未设置`，回显完整实例读取的非零事实截止；
- 完整实例读取声称成功却缺实例、返回退出值、错实例值或其它坏成功形状：`内部不一致`，不得降级为未设置或未找到。

`L2特征当前值读取结果::成功()` 只验证可独立证明的结果形状；请求实例与值所属实例的等式由服务入口在形成结果前机械校验。

## 5. 实现流程

1. 用 `L2特征当前值读取请求有效(...)` 校验纯值请求；失败返回默认入口拒绝、零截止、空载荷。
2. 机械调用：

```cpp
读取完整特征实例({请求.请求头,
    L2读取类别::当前, 请求.特征实例, 0})
```

3. 若完整实例读取非 `已读取`，保持其状态与事实截止，清空载荷和变更代次后返回。
4. 若结果声称已读取但实例 optional 缺失，返回同截止 `内部不一致`。
5. 若实例当前值为空，返回同截止 `属性未设置`。
6. 若当前值不完整、所属实例不等于请求、或生命周期已退出，返回同截止 `内部不一致`。
7. 移动形成 `已读取`、同一非零截止、零变更、完整当前值结果，并以结果成功谓词复核；谓词失败收敛为同截止 `内部不一致`。
8. `std::bad_alloc`、`std::length_error` 映射 `资源失败`；其它异常映射 `内部不一致`。不重试、不改守卫、不生成幂等身份。
