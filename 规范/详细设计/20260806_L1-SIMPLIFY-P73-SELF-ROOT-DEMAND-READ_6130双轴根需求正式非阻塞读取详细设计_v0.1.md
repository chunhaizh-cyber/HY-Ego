## 1. S0、P1—P72能力矩阵与最早缺口裁决

正式 `main` 尚无 `L1自我根需求` 代码文件。P70/P71/P72依次冻结双轴根需求纯值规格、
`19/26/14/26/0/59/85` L1草案和领域原子发布者，但P72明确说明其59项映射与85项同锁
读回只证明发布当次结果，不证明后继代次需求仍活动、仍无父或仍与当前自我和双轴根值一致。

P1—P72按本叶需要收束如下：

| 能力链 | 已冻结责任 | P73裁决 |
| --- | --- | --- |
| P17 | 一次try-lock的业务中性当前L1完整快照 | 直接调用一次，取得需求事实唯一当前截止 |
| P18—P21 | 正式世界定位、结构和当前实际存在资格 | 经P56/P69真实结果传递，不重复解释 |
| P24—P26 | 同快照实例槽、定义和值 | 经P69双轴当前值事实传递，不在需求域重读 |
| P53—P56 | 自我登记和唯一完整当前自我 | P56直接调用一次，提供当前场景和自我见证 |
| P63—P69 | 双轴定义、实例槽和当前值生产读取 | P69直接调用一次，提供当前槽和值见证 |
| P70/P71 | 根需求规格和L1物理形状 | 只用于解释正式字段、角色和值槽合同 |
| P72 | 稳定服务/类型/字段及初始双根发布定位 | 只消费成功发布事实值，不调用发布入口 |
| 旧需求服务与ENTRY-ONLY S12 | 旧仓、旧句柄和初始化返回值读回 | 不复用，不是L1当前读取 |
| 父子/路径、满足、6170、任务、装配 | 需要正式当前根需求输入 | 均晚于本叶，保持后继分叶 |

直接进入父子路径会在根需求当前资格尚未独立成立时解释角色8；直接进入满足会违反3100/5100
要求的正式比较服务边界；直接进入6170或装配会迫使维护或调用方解析P72发布结果，形成第二
需求业务解释者。另建登记投影、参与者或读取缓存也无依据：需求服务、关系类型和十三字段
类型已经由P72作为L1事实发布，P17快照足以按需求领域规则解释。

故P72之后唯一最早独立叶是需求领域正式非阻塞读取provider。它以P72成功发布事实作为
稳定语义定位锚，但从P56/P69/P17重新取得同根同截止当前事实；定位锚不是当前结果，P72
同锁读回不得直接返回给调用方。

P15 v0.24已正式替代并激活，其结果见证持久化修订不改变P73机器语义。P73不调用P15、
不消费其私有DTO或复制执行证据语义；P15及活动代码计划只构成上游真实结果和共享资源门禁。

## 2. 目标与最大边界

新增唯一公开根：

```cpp
自我双轴根需求读取结果 L1自我根需求读取服务::读取当前自我双轴根需求(
    const 自我双轴根需求读取请求& 请求) const;
```

固定流程：

```text
校验请求和P72稳定发布定位
-> P56读取当前完整自我恰一次
-> P69读取当前双轴根值恰一次
-> P17尝试读取当前L1完整快照恰一次
-> 校准三份事实同根、同自我、同一非零截止
-> 互证服务、关系类型和十三字段属性类型当前存在
-> 读取安全/服务需求与目标状态的当前值槽
-> 校验两需求角色1—7各一、角色8为零
-> 互证当前状态槽和P69当前根值、出生值证据和P72定位
-> 排除额外活动冷启动双轴根候选
-> 返回同截止不可变双轴当前需求事实
```

本叶只读取两个活动无父冷启动根需求及其目标、关系、字段、当前槽和值。它不裁决当前满足，
不读取或创建父子路径、合同、条件性子需求、差距、任务、结算或6170维护输入；不执行初始化、
生产装配、恢复、旧栈删除或正式集成验收。


`L1自我根需求读取服务`是当前根需求结构、活动资格、无父资格和字段/关系完整性的唯一解释者。
P56仍唯一解释完整自我，P69仍唯一解释双轴根当前槽和值，P17只提供业务中性快照。后继父子、
满足和维护服务必须消费本叶成功事实，不得直接解析P72结果或P17快照。

```cpp
class L1自我根需求读取服务 final {
public:
    L1自我根需求读取服务(
        const L1事实基座服务& L1,
        const L1完整自我结构服务& 完整自我,
        const L1自我根当前值读取服务& 根当前值,

        const 自我双轴根需求读取请求& 请求) const;

```

三个provider为非拥有引用，宿主寿命覆盖服务和同步调用；稳定发布定位按值深复制。服务不可
默认构造、复制或移动，不保存快照、当前读取结果、锁、许可、缓存或上轮截止。构造只校验并
保存定位，不调用provider。

```text

-> L1自我根需求读取服务::读取当前自我双轴根需求
   -> P56 L1完整自我结构服务::读取完整自我结构
   -> P69 L1自我根当前值读取服务::读取当前双轴根值
   -> P17 L1事实基座服务::尝试读取完整快照
```

P17/P18—P26/P53—P72和L1核心不得反向依赖本服务。本模块不import P15、P37/P54、仓库、
旧需求服务、旧初始化、SQL、运行期上下文或旧WORLD-TREE。

## 5. 入口、稳定定位与调用顺序

调用provider前校验顶层版本、两个嵌套读取请求版本和世界根；两个请求指定根必须逐字段相同。
保存的P72定位必须具有非零发布代次、服务、关系类型、十三字段属性类型、两个互异需求和目标
状态，角色、字段数组和初始化规格完整。错误请求返回入口拒绝；损坏定位返回内部不一致；三次
provider调用均为0。

固定调用顺序和直接次数为：

1. 调用P56恰一次。只接受`已读取`完整事实；尚无自我同名映射；登记/世界未加载映射未找到；
   版本漂移、许可拒绝、资源失败同名映射；坏成功和未知状态映射内部不一致。
2. 调用P69恰一次。只接受`已读取`完整双轴事实；尚无自我同名映射；未找到同名映射；
   当前值缺失、版本漂移、许可拒绝和资源失败逐类映射；坏成功映射内部不一致。
3. 调用P17 `尝试读取完整快照`恰一次。成功快照必须非空、截止非零；未找到在两上游成功后
   映射内部不一致；许可拒绝、资源失败、内部不一致同名映射。

P56、P69和P17的世界根、自我必须相等；P56自我所在场景必须有效；三个事实截止必须完全
相等且非零。任一不等返回版本漂移、空事实、零内部重读。P18/P19/P21通过P56/P69门禁传递，
本叶直接调用均为0。

## 6. 当前根需求结构算法

### 6.1 服务、字段和候选定位

在P17快照中先互证P72定位的需求服务、关系类型和十三字段属性类型均为当前普通节点，创建
代次不晚于本轮截止，互异且属性类型均为I64。P72发布代次必须不晚于截止，但不得冒充当前
截止。

只把同时满足以下条件的当前普通节点作为冷启动双轴根候选：

- 十三个字段中需求八字段各有恰一当前属性槽和当前I64值，来源服务等于定位服务；
- 需求资格为1，根角色为生存安全或服务，来源种类为冷启动双轴根；
- 生命周期为活动，生命周期和根路径规则版本等于P72初始化规格；
- 来源截止低/高位可无损重组非零U64且不晚于当前截止；
- 该节点使用定位关系类型，角色1—7各恰一，角色8当前关系为0。

安全与服务候选必须各恰一。两者都为0返回`尚无当前双轴根需求`；只缺一项、任一角色多项、
同一节点冒充双角色、额外活动冷启动同角色候选或未知关系角色均为内部不一致。不得按编码、
创建代次、容器顺序或P72结果数组位置选择一个竞争项。

### 6.2 七角色与当前状态材料互证

每个候选的七关系按角色升序形成结果，关系源必须等于需求，类型等于定位关系类型：

| 角色 | 当前目标与互证 |
| ---: | --- |
| 1需求主体 | 等于P56/P69当前自我 |
| 2目标宿主 | 等于当前自我 |
| 3目标场景 | 等于P56当前自我所在场景 |
| 4目标特征 | 等于P69对应根的当前定义 |
| 5当前状态材料 | 等于P69对应根的当前实例槽 |
| 6出生来源值证据 | 等于P72对应根发布定位中的出生当前值 |
| 7目标状态 | 等于本候选唯一完整目标状态 |

角色5只定位可换代当前实例槽；当前值和值来源原样取P69同截止事实。角色6只证明出生来源，
不得冒充当前值。P69当前值可以晚于且不同于P72出生值；P73不据此判满足或漂移。

### 6.3 目标状态和值槽

角色7目标节点必须当前，且五字段各有恰一定位属性槽：资格1、P72目标状态合同版本、比较
种类、目标值和比较合同版本。安全固定为`大于1`，服务固定为`等于I64_MAX`。字段来源服务
等于定位服务，值/槽当前且创建代次不晚于截止。

需求八字段和目标五字段逐项形成`字段值`，按`自我根需求字段`枚举升序稳定排序。P73不把
原始字段直接解释为满足结果；后继必须调用正式特征比较或状态判断收束服务。

## 7. 非成功、并发与生命周期

本函数不取得自身锁，不持一个provider许可跨下一调用。三份provider结果和P17快照都是
调用栈纯值副本；许可竞争立即返回，零等待、零sleep、零重试、零缓存。

P72定位中的初始需求或目标节点已退出、字段槽缺失、生命周期不活动或角色8出现时，该节点
不再是当前无父根候选；若双轴均合法退出则返回尚无当前双轴根需求，单边缺失或结构矛盾返回
内部不一致。父子路径、终态和满足的历史读取由后继独立合同处理，本叶不扫描历史事实。

`std::bad_alloc`映射资源失败，其它未分类异常映射内部不一致。相同快照重复读取逐字段相等；
返回后L1可继续推进，旧结果只证明其截止代次。
