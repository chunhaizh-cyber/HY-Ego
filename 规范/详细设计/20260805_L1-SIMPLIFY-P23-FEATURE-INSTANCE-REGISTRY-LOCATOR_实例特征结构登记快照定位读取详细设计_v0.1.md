# L1-SIMPLIFY-P23-FEATURE-INSTANCE-REGISTRY-LOCATOR 实例特征结构登记快照定位读取详细设计 v0.1

## 1. 身份、目标与完成边界

计划身份：`L1-SIMPLIFY-P23-FEATURE-INSTANCE-REGISTRY-LOCATOR`

版本：`v0.1`

创建侧正式代码基线：`fc798cc9d639c1fe74f8ea528dd64c1f96878b6d`

本叶是 SELF-GOV-CLOSURE STEP-4 在 P22 之后的下一最早提供者。它原位扩展唯一 `L1实例特征服务`，以一个无对象状态的公开静态纯函数，消费调用方提供的不可变 `实例特征登记定位见证` 和同一份 P17 `L1完整快照`，在该快照内验证 P3 登记四个稳定编码的当前节点形状、创建代次和唯一性后返回同截止定位事实。

机器语义按 4200 §2.2/§2.3 的正式裁决固定：登记是对 L1 已发布事实的不可变值式定位材料，不是第二仓或运行期权威；定位见证可以来自 P3 首次登记成功结果，未来也可由恢复/装配提供。P23 不得为了取得见证读取 P3 进程缓存、扫描猜测或重建登记。

完成必须同时成立：

- 公开调用输入固定为“版本化定位请求 + 一份调用方已取得的 P17 完整快照”，不得在函数内部调用 P17 或 L1；
- 定位见证缺失、结构非法、确定全未命中、部分缺失和事实损坏分账明确；
- 成功只在四编码均于同一 P17 快照内唯一命中、当前、形状正确且创建代次等于登记发布代次时形成；
- 输出携带 P17 非零事实截止、P3 登记发布代次、见证来源和四个确定角色的当前节点见证；
- 纯函数不取得 `L1实例特征服务` 互斥量或任何 L1/领域锁，不读取 `登记_`，不重取快照，不等待、不 sleep、不重试；
- 不修改 P3 四节点登记写集，不新增标记值、关系、索引、固定编码或第二登记事实。

本叶不读取特征定义详情、实例槽集合、当前值、材料、状态、动态或历史，不形成完整世界快照、统一世界门面或 STEP-5。

## 2. 正式依据、S0 事实与复用裁决

正式依据：

- 0050 §2—§6：运行期当前事实只来自内存已发布代次；缓存和定位材料不是第二权威，命中后必须回读同代次事实；
- 1120、1130、4110：实例槽、定义模板和当前值由特征领域唯一解释，跨领域调用不得直接按 L1 形状猜测业务角色；
- 4015：`L1完整快照` 只含当前节点、关系、值、属性槽和永久占用编码，不含历史或审计；
- 4030：组合服务只经事实所有者具名强类型服务消费，不取得仓库、锁、事务或可变对象；
- 4200 §2.2/§2.3、§5.1—§5.3：登记是不可变值式定位材料；领域读取必须返回同一非零截止，全部当前实例特征不得缺项或混代；
- P3 v0.2 正式结果：登记写集精确建立服务身份、宿主槽关系类型、定义模板关系类型和当前 I64 值属性类型四节点；
- P17 v0.1：冻结一次 try-lock 的完整当前快照，但尚未实现；
- P21/P22：分别冻结实际存在资格范围和特征定义登记定位，均不提供 P3 登记四编码。

从正式 HEAD 得到的能力矩阵：

| 能力链 | 当前代码 | 冻结合同 | 裁决 |
| --- | --- | --- | --- |

P3 登记的三个普通节点和一个 I64 属性类型节点之间没有标记值或关系，仅靠快照不能证明它们属于同一登记。P23 因此既不扫描，也不把创建代次、稳定编码邻接、容器顺序或“同代次三普通加一属性类型”当作候选召回规则；四编码只能来自具名定位见证。

P22 与 P23 分账：P22 提供特征定义登记定位；P23 只提供实例特征结构登记定位。二者均不解释实例槽集合，后继才在同一 P17 快照中组合两类定位材料和 P21 宿主范围。

P7 结果提交精确修改其十一文件，与 P23 三个实例特征代码文件零路径重叠；P7 不是本叶机器语义前置。

-> P17 尝试读取完整快照

## 4. DTO、见证来源与公开函数

在 `L1实例特征.数据.h` 追加：

```cpp
inline constexpr std::uint32_t 实例特征登记定位规则版本 = 1;

enum class 实例特征登记定位见证来源 : std::uint8_t {
    首次登记结果 = 1,
    恢复装配 = 2
};

struct 实例特征登记定位见证 final {
    std::uint32_t 合同版本 = L1实例特征合同版本;
    std::uint32_t 规则版本 = L1实例特征规则版本;
    std::uint32_t 定位规则版本 = 实例特征登记定位规则版本;
    实例特征登记定位见证来源 来源 =
        实例特征登记定位见证来源::首次登记结果;
    实例特征结构登记 登记;
};

struct 实例特征登记定位请求 final {
    std::uint32_t 合同版本 = L1实例特征合同版本;
    std::uint32_t 规则版本 = L1实例特征规则版本;
    std::uint32_t 定位规则版本 = 实例特征登记定位规则版本;
    std::optional<实例特征登记定位见证> 定位见证;
};

enum class 实例特征登记节点形状 : std::uint8_t {
    普通 = 1,
    I64属性类型 = 2
};

struct 实例特征登记当前节点见证 final {
    稳定编码 身份;
    实例特征登记节点形状 形状 = 实例特征登记节点形状::普通;
    std::uint64_t 创建事实代次 = 0;
};
```

定位见证来源只记录上游形成路径，不取得事实裁决权。`首次登记结果` 必须由 P3 `已提交/幂等读回` 的完整登记结果机械形成；`恢复装配` 必须由未来具名恢复/装配 provider 给出同形不可变见证。两者都必须接受 P23 对当前 P17 快照的完整互证。

追加纯值辅助：

```cpp
bool 实例特征登记定位见证完整(
    const 实例特征登记定位见证& 见证) noexcept;

std::optional<实例特征登记定位见证>
从首次登记结果形成定位见证(
    const 实例特征登记结果& 结果) noexcept;
```

辅助只接受 `已提交` 或 `幂等读回` 且登记完整、四编码有效并两两不同的结果；它复制 DTO，不读取服务或 L1。`已读取` 缓存结果不得冒充首次登记来源。未来恢复装配不复用此辅助，而是按相同公开完整性谓词形成 `来源=恢复装配` 的见证。

缺项诊断固定为：

```cpp
enum class 实例特征登记定位缺项种类 : std::uint8_t {
    快照头或节点组损坏 = 1,
    登记节点部分缺失 = 2,
    服务身份形状错误 = 3,
    宿主槽关系类型形状错误 = 4,
    定义模板关系类型形状错误 = 5,
    当前I64值属性类型形状错误 = 6,
    登记发布代次矛盾 = 7
};

struct 实例特征登记定位缺项诊断 final {
    实例特征登记定位缺项种类 种类;
    稳定编码 相关身份;
};

struct 实例特征登记定位事实 final {
    std::uint32_t 合同版本 = L1实例特征合同版本;
    std::uint32_t 规则版本 = L1实例特征规则版本;
    std::uint32_t 定位规则版本 = 实例特征登记定位规则版本;
    std::uint64_t 事实截止代次 = 0;
    实例特征登记定位见证来源 见证来源;
    实例特征结构登记 登记;
    实例特征登记当前节点见证 服务身份;
    实例特征登记当前节点见证 宿主槽关系类型;
    实例特征登记当前节点见证 定义模板关系类型;
    实例特征登记当前节点见证 当前I64值属性类型;
    bool 完整 = false;
};

struct 实例特征登记定位结果 final {
    实例特征状态 状态 = 实例特征状态::入口拒绝;
    std::optional<实例特征登记定位事实> 事实;
    std::vector<实例特征登记定位缺项诊断> 缺项诊断;
};
```

`L1实例特征.数据.h` 因新增 vector 结果显式包含 `<vector>`，仍不得出现 L1 写集、仓库、锁、服务或事务类型。

在现有类中新增公开静态函数：

```cpp
static 实例特征登记定位结果 从快照读取登记定位(
    const 实例特征登记定位请求& 请求,
    const L1完整快照& 快照);
```

静态形态明确禁止访问 `this`、`登记_`、`锁_` 和三个 provider 引用。它不 `noexcept`，内部捕获 `std::bad_alloc` 为资源失败、其它异常为内部不一致。

## 5. 固定定位算法

### 5.1 请求和上游分账

1. 校验请求合同、规则和定位规则版本；错误返回 `入口拒绝`，空事实/诊断；
2. `定位见证` 为空返回 `登记未加载`，空事实/诊断；不得读取当前服务缓存补齐；
3. 见证存在但来源枚举、嵌套版本、登记发布代次、四编码或两两唯一性非法，返回 `入口拒绝`；
4. P17 若在调用前返回 `许可拒绝/资源失败/内部不一致`，调用方必须直接映射且 P23 调用次数为 0；P23 只接受 P17 成功载荷中的 `L1完整快照`，自身不产生许可拒绝。

### 5.2 单快照中性校验

对传入快照固定执行：

- `事实代次` 必须非零；当前节点组必须按稳定编码严格升序、编码有效且无重复；
- 每个节点创建代次非零且不大于快照代次，退出代次必须为空；
- 见证登记发布代次大于快照代次时返回 `事实代次漂移`，空事实/诊断；
- 只按四个见证编码对已排序当前节点组做确定二分查找，不遍历召回候选，不读取关系、值、属性槽、永久编码组或审计。

快照头、节点排序、重复编码或生命周期基础形状损坏返回 `内部不一致` 和稳定诊断，不继续形成定位事实。

### 5.3 未命中、部分缺失和形状

- 四编码全部未命中：`未找到`，空事实/诊断。这是确定未命中，不扫描其它节点替代；
- 一至三个编码命中：`内部不一致`，空事实，按缺失角色形成 `登记节点部分缺失` 诊断；
- 四编码全部命中后逐项验证：
  - 服务身份、宿主槽关系类型、定义模板关系类型均为 `节点种类::普通`、`属性类型表示` 为空、当前属性组为空；
  - 当前 I64 值属性类型为 `节点种类::属性类型`、表示精确为 `值表示种类::I64`、当前属性组为空；
  - 四节点创建事实代次全部精确等于见证 `登记.事实截止代次`，且该代次不大于快照截止；
  - 四个实际编码与四个见证角色逐字段相同。

任一形状或创建代次矛盾均为 `内部不一致`，不得降级未找到，也不得返回通过项。P3 登记节点没有 L1 来源字段；P23 不补造节点来源。结果中的 `见证来源` 只表达定位见证由首次登记或恢复装配形成，不替代节点当前性和形状验证。

### 5.4 成功、排序与完整性

全部通过后形成 `已读取`：

- 事实截止代次精确等于传入 P17 快照代次；
- 嵌套登记保留 P3 登记发布代次，不用当前截止覆盖；
- 四个当前节点见证按固定角色字段返回，不依赖容器顺序；
- 三个普通形状与一个 I64 属性类型形状精确；四节点创建代次均等于登记发布代次；
- `完整=true`，缺项诊断为空。

内部不一致诊断按 `种类、相关身份` 数值升序并确定去重。非成功均不返回定位事实；只有内部不一致分支允许非空诊断。

## 6. 并发、生命周期和所有权

P23 只读取调用方拥有的两个 const 值：请求和快照。函数不访问服务对象，不取得领域/L1 锁，不调用 provider，不写缓存、日志、SQL、材料或事实，不建立线程局部状态。多线程对相同输入调用必须逐字段得到相同结果。

调用方在 P17 返回后才调用 P23；P17 锁已经释放。之后事实继续推进不改变本次结果的值式证据，后继通过 P23 `事实截止代次` 与 P21/P22/其它服务截止比较，并由世界快照首末 G0/G1 处理漂移。P23 不建立自己的 retry。

登记四节点任一后来退出时不会出现在 P17 当前节点组：全退为确定未找到，部分退出为内部不一致。历史和审计必须走独立接口，本叶不读取。生产重启后首次登记见证如何由恢复/装配持久取得属于后继生产装配边界；缺失时只能登记未加载，不能扫描补造。

## 7. 验证矩阵

原位扩展顺序 320 的 `海中鱼巣.领域.自检.L1实例特征`，不新增模块、工程项、启动单元或完整自检计数。至少覆盖：

1. P3 真实首次登记 `已提交` 和精确重复结果均可机械形成见证；`已读取`、非成功、空/重复编码不能形成首次登记见证；
2. 请求版本错、规则错、定位规则错、来源枚举错、见证零编码/重复编码在快照解释前入口拒绝；
3. 定位见证为空返回登记未加载，不读取当前服务 `登记_`；新服务实例与已登记服务实例对同输入静态调用结果相同；
4. P17 许可拒绝由调用方直接返回，P23 调用 0；P23 生产代码对 P17/L1 服务调用 0；
5. P3 真实登记成功后的一个 P17 快照中四编码全部命中，返回同截止完整事实，角色/形状/创建代次逐项准确；
6. 快照代次早于登记发布代次返回事实代次漂移；登记发布代次早于或等于当前快照允许成功；
7. 四编码全部移除为确定未找到；分别缺一个和缺多个为内部不一致及稳定部分缺失诊断；不扫描替代；
8. 三个普通节点逐个改为属性类型、增加属性表示或属性槽，当前 I64 属性类型改普通/非 I64/带属性槽，均内部不一致；
9. 任一节点创建代次不等于登记发布代次、退出代次非空、节点组乱序或重复编码，均内部不一致；
10. 首次登记见证与恢复装配见证对相同登记/快照形成除来源枚举外等价定位事实，来源不能绕过校验；
11. 无关同形节点、同创建代次节点和相邻稳定编码不会被召回；改变容器构造顺序后结果不变；
12. 资源失败映射资源失败，其它异常映射内部不一致，零部分事实；
13. P3/P4 既有登记、实例建立、读取和换代专项不退化；
