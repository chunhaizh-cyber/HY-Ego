# DATA-L2 词条公开服务闭合详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-LANGUAGE-LEXEME-SERVICE-CLOSURE`

## 1. 目标与完成边界

本设计依据 0050、2200、4240 和《数据服务最终需求清单》DATA-EXT-10，在现有唯一 `L2语言结构服务` 中一次闭合词条公开 DTO、独立词条 owner、按规范化键新增、退出、按身份及按规范化键当前 / 历史读取。词条与语言由同一服务类静态路由到两个不可交换 owner，不建立通用 owner 选择、第二语言服务、词索引权威缓存或第二写入口。

本叶完成必须由生产代码外合法消费者在同一 `L1事实基座运行包` 中构造不可变材料、语言和词条两个 owner，建立语言后新增词条，并完成当前读、键读、历史读、退出和引用保护验证。

普通应用尚无不可变材料受控存储根配置来源，具名漂移 `DRIFT-DATA-L2-IMMUTABLE-MATERIAL-PRODUCTION-ROOT-CONFIG-UNDEFINED` 仍未裁决。因此本叶不修改普通应用，不选择默认目录，不宣称 DATA-EXT-10 整项或生产装配完成。该漂移只阻断装配，不阻断词条公开结构本身。

本设计不建立语素、词性、语言记录、概念名称关系、分词、规范化算法、词义解释、目标类型或概念候选。

## 2. 当前事实与复用裁决

- `L2语言身份`、`L2词条身份` 和 `L2节点族::语言 / 词条` 已在共同公开头正式发布。
- `L2语言结构.数据.h` 已冻结语言 DTO；`L2语言结构服务` 已持有唯一语言 owner，实现语言新增、新身份替换、退出和两类当前 / 历史读取。
- `不可变材料服务` 已提供格式、长度、SHA-256、严格 UTF-8、来源和生命周期的正式写入 / 读取；服务能机械证明与给定 L1 实例相同。
- L1 owner 写集已经提供原子发布、首次规范化写集读回、跨 owner 当前入边引用保护、当前 / 历史关系组读取和共同事实代次。
- 当前没有词条 DTO、词条 owner、词条函数或普通应用取得路径。

裁决：扩展现有语言头与服务模块；词条使用独立 owner 和独立写锁，但由同一 `L2语言结构服务` 暴露具名函数。工程文件已经登记两个生产文件，不修改工程。

## 3. 公开 DTO

在 `海中鱼巣/领域/L2语言结构.数据.h` 增加：

```cpp
inline constexpr std::uint32_t L2词条结构合同版本 = 1;

struct L2词条规范化键 final {
    L2语言身份 语言;
    不可变材料身份 规范化合同材料;
    不可变材料身份 规范化词面材料;
};

struct L2词条语言归属事实 final;
struct L2词条规范化合同事实 final;
struct L2词条规范化词面事实 final;
struct L2词条来源事实 final;

struct L2词条事实 final {
    L2词条身份 词条;
    L2节点族身份来源事实 身份来源;
    L2词条规范化键 规范化键;
    L2词条语言归属事实 语言归属;
    L2词条规范化合同事实 规范化合同;
    L2词条规范化词面事实 规范化词面;
    L2词条来源事实 来源;
    L2生命周期 生命周期;
};
```

四个关系事实都保存词条身份、强类型目标、关系稳定编码和生命周期。完整词条的节点、族归属、语言归属、规范化合同、规范化词面和来源必须在同一创建截止成立并拥有相同生命周期；身份来源节点族固定为 `词条`。

规范化键的机器含义固定为：

```text
当前语言身份
+ 当前规范化合同材料身份
+ 当前严格 UTF-8 规范化词面材料的格式、摘要、长度
```

不可变材料服务已经保证同一格式、摘要、长度和完整字节内容只有一个当前材料身份；词条服务必须在请求截止正式读回材料后才使用其身份比较，不能仅相信调用方包装值。

## 6. 独立 owner 与构造合同

在服务模块公开：

```cpp
inline constexpr L1所有者范围建立幂等身份 词条所有者建立身份{...};

class L2词条所有者交付;

std::optional<L2词条所有者交付> 尝试形成L2词条所有者交付(
    const L1事实基座服务&, L1所有者范围交付&&) noexcept;
```

`L2词条所有者交付` 与语言交付不可转换、不可复制，只能单次移动。`L2语言结构服务` 构造改为：

```cpp
explicit L2语言结构服务(
    const L1事实基座服务&,
    const 不可变材料服务&,
    L2语言所有者交付&&,
    L2词条所有者交付&&);
```

构造机械验证 L1、材料服务和两个 owner 均属于同一 L1 实例；两个 owner 身份必须不同。服务分别持有两份写端口和两把写锁，读取不取得写锁。

词条 owner 私有登记固定包含词条族锚点、族归属关系类型、语言归属关系类型、规范化合同关系类型、规范化词面关系类型和来源关系类型。登记与业务幂等身份不得冲突。

固定技术身份为：词条 owner 建立身份 `0x4C32'4C45'5845'0001`，词条登记写入身份 `0x4C32'4944'5352'4309`；登记本地键使用 `0x0209'6001`、`0x0209'6002`、`0x0209'6101`—`0x0209'6104`，业务节点 / 五关系本地键使用 `0x0209'1001`—`0x0209'1006`。它们只承担 owner-scoped 技术幂等与写集本地映射，不进入公开 DTO，不取得业务语义。

## 7. 新增事务

```text
纯值请求校验
-> 取得词条写锁
-> 按词条 owner 幂等身份读取首次规范化写集
-> 已有首次：重建原新增请求；同义返回首次结果，异义幂等冲突
-> 在 G 当前读回语言、规范化合同材料、规范化词面材料和来源材料
-> 规范化词面必须为严格 UTF-8；合同和来源必须是完整当前材料
-> 按规范化词面目标关系读取候选词条并完整重建
-> 精确键零占用才允许写；同键由其它请求占用返回引用冲突
-> 一份词条 owner 写集建立节点、族归属及四条结构关系
-> 在 W 完整读回词条、语言和材料，W 必须大于 G
-> 返回已提交或首次精确重复
```

规范化服务位于 DATA 之外。词条服务只验证调用方给出的三个材料身份及正式读回，不改变字节、不选择合同、不生成词面。

## 8. 读取与唯一键

按身份读取必须从词条 owner 的节点、族归属和四条结构关系重建完整事实；语言与三份材料在同一读取截止正式读回。当前入口使用同一非零守卫，历史入口使用指定历史截止。

按键读取先正式读回语言和两份键材料，再以规范化词面材料为目标端点读取词条 owner 对应关系组；逐项完整重建后只保留语言和规范化合同同时精确匹配的词条。零项返回 `未找到`；一项返回完整词条；两项及以上属于当前或历史结构复义，返回 `内部不一致`，不得任取一项。关系命中只是定位候选，不能代替完整词条读回。

历史键读回返回历史截止上仍活动的唯一词条；后继退出不会抹除该投影。

## 9. 退出与引用保护

退出在 G 按身份完整读取词条并逐字段核对规范化键和来源；一份词条 owner 写集退出节点、族归属和四条结构关系。L1 全局引用保护必须拒绝当前概念名称关系、语言记录或其它 owner 对该词条的当前入边；服务不级联退出引用方。

语言归属是词条 owner 指向语言 owner 的当前跨 owner 入边，因此语言退出会被 L1 引用保护拒绝。词条退出不退出语言或三份不可变材料。

精确重复必须从首次退出写集和首次结果截止历史重建同一退出事实，不因后继状态变化再次推进事实代次。

## 10. 状态与异常

| 条件 | 状态 |
| --- | --- |
| 坏合同版本、零守卫 / 幂等、坏身份、当前 / 历史形状错误 | `入口拒绝` |
| 语言、合同、词面或来源未找到 / 已退出 | 原结构状态 |
| 规范化词面不是严格 UTF-8 | `入口拒绝` |
| 同幂等身份异完整请求 | `幂等冲突` |
| 同规范化键被另一请求占用、退出仍被引用 | `引用冲突` |
| 请求前后事实代次变化 | `事实代次漂移` |
| L1 / 材料明确资源失败或发布未知 | `资源失败` |
| 双当前键、错 owner / 类型 / 端点、混代、发布后坏读回 | `内部不一致` |

`bad_alloc` 和 `length_error` 映射资源失败；其它异常映射内部不一致。异常和所有非成功结果不得泄漏部分词条。
