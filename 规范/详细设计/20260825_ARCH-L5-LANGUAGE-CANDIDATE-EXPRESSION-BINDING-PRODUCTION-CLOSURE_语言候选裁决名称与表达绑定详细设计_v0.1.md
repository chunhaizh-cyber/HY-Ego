## 1. 目标与非目标

本设计冻结一个完整的 L5 生产闭环：正式语言准备、语言候选路由、唯一候选裁决、裁决后概念名称绑定以及只读自然语言表达。它不把任何候选、裁决或表达变成第二事实仓，不创建概念、词条、语言或对象，不建立语素、对应信息、概念追溯、持久词性或通用路由节点。

非目标包括：概念形成 / 准入、世界事实真实性、实例别名、一次指代、需求 / 任务 / 方法、L4 业务执行、语言模型训练、默认字符串常量和名称索引写入。

## 2. 当前能力与复用裁决

| 能力 | 当前正式入口 | 本设计复用 |
| --- | --- | --- |
| 语言身份 | `L2语言结构服务::新增语言`、`读取语言`、`按登记键读取语言` | 生产语言准备只编排这些公开入口，正式写入后独立双读回 |
| 词条 | `L2语言结构服务::新增词条`、词条按身份 / 规范化键读取 | 路由只读；语言和词条结构不由 L5 重建 |
| 名称候选 | `L2概念名称结构服务::按词条读取概念名称候选组` | 返回完整未过滤当前组，按稳定身份排序 |
| 名称写入 | `L2概念名称结构服务::新增概念名称关系` | 只由绑定业务在具名裁决证据下调用 |
| 名称读回 | `按概念读取名称关系组`、`按词条读取概念名称候选组`、按名称关系读取 | 绑定成功必须三路同截止读回 |
| L5 业务 | 当前未见正式生产 route / adjudication / binding / expression provider | 本设计新冻结唯一业务 owner 和入口 |

## 3. 版本、状态与强类型值

新增独立 L5 合同版本，均从 `1` 开始，不改变 L2 合同版本：

```text

L5语言候选路由合同版本 = 1
L5语言候选裁决合同版本 = 1
L5概念名称绑定合同版本 = 1
L5自然语言表达合同版本 = 1
```


所有请求携带 `L2结构请求头`，非零期望代次表示 G0 守卫；路由 / 裁决 / 表达只读结果不得产生变更代次。候选、裁决和表达均为值式材料，不取得稳定身份、生命周期或引用保护。

候选状态闭集：`已形成候选、语言未找到、词条未找到、名称候选为空、目标强类型未形成、候选已退出、事实代次漂移、许可拒绝、资源失败、数量预算不足、内部不一致`。

裁决状态闭集：`已裁决唯一候选、未理解、多义待裁决、上下文不足、候选已退出、事实代次漂移、许可拒绝、资源失败、内部不一致`。

绑定状态闭集：`已提交、精确重复、无裁决证据、候选已过期、语言未找到、词条未找到、关系已存在异义、多首选冲突、事实代次漂移、许可拒绝、资源失败、内部不一致`。

表达状态闭集：`已形成、绑定未确认、上下文不足、未理解、事实代次漂移、许可拒绝、资源失败、内部不一致`。

## 5. 生产语言准备

`生产语言准备业务::确保正式语言` 是路由前唯一语言准备入口。请求携带 `L2语言登记键`、来源材料、L2 请求头和幂等身份，不携带“汉语”字符串或进程缓存标记。首次缺失调用 `L2语言结构服务::新增语言`；写结果为已提交或精确重复后，必须按登记键和按身份独立读取，使用同一 G1 逐字段互证语言身份、登记键、来源和当前生命周期。已存在时也必须按登记键、按身份正式读取，不得由缓存直接成功。

准备结果只有在 L2 写 / 精确重复结果与双读回一致时才成功；语言未找到、已退出、G0 漂移、许可、资源、材料或内部不一致均返回结构化失败且不形成 L5 事实。默认语言选择只消费正式读回，项目配置只能提供登记键材料，不能提供身份权威。

## 6. 路由、裁决、绑定与表达顺序

唯一公开业务函数及其 owner 固定为：

```text
生产语言准备业务::确保正式语言(
    const L5生产语言准备请求&) -> L5生产语言准备结果
语言候选路由业务::形成候选(
    const L5语言候选路由请求&) const -> L5语言候选路由结果
语言候选裁决业务::裁决(
    const L5语言候选裁决请求&) const -> L5语言候选裁决结果
概念名称绑定业务::提交裁决后绑定(
    const L5概念名称绑定请求&) -> L5概念名称绑定结果
自然语言表达业务::形成表达(
    const L5自然语言表达请求&) const -> L5自然语言表达结果
```

其中生产语言准备和名称绑定是唯一可能编排 L2 写入口的业务 owner；路由、裁决和表达只读。所有函数只接受本设计 DTO，不接受字符串、裸稳定编码、旧语素材料或进程缓存句柄。

1. 路由服务先确保语言正式读回，再按词条身份读取词条和完整未过滤名称候选；每个名称目标必须经概念或对象领域公开服务读回强类型。
2. 候选以 `(目标角色, 目标身份稳定编码, 名称角色, 名称关系稳定编码)` 升序稳定排序。候选预算不足返回数量预算不足，不截断后继续裁决。
3. `语言候选裁决业务::裁决` 只在完整候选恰有一个、上下文和规则材料完整、输入 G0 未漂移时返回已裁决唯一候选，并形成具名证据；未理解、多义、坏上下文、候选退出和其它失败都不得写名称关系。
4. `概念名称绑定业务::提交裁决后绑定` 校验裁决状态、证据材料和选中候选，将证据材料身份值作为现有 `来源稳定编码` 的来源引用，调用 L2 名称关系新增入口。它不创建概念、词条或语言。
5. L2 写结果得到 G1 后，绑定业务必须按名称关系身份、按概念和按词条三路读取，三者均以 G1 守卫且逐字段一致；同幂等键精确重复返回原关系和读回，异义当前 / 多首选 / 引用冲突零写。
6. `自然语言表达业务::形成表达` 只消费成功绑定、上下文、预登记的表达材料和表达规则材料，形成值式结果；不写语言、词条、概念、名称或索引。

## 7. 失败与幂等矩阵

| 阶段 | 条件 | 结果 | 写入 |
| --- | --- | --- | --- |
| 语言准备 | 登记键非法、材料未正式读回、G0 / 许可 / 资源失败 | 结构化失败 | 零 L5 写；L2 写若已提交按正式读回报告 |
| 路由 | 语言 / 词条未找到、名称为空、目标类型缺失、预算不足 | 对应候选状态、完整可回显材料 | 无 |
| 裁决 | 零候选、多义、未理解、上下文不足、证据过期 | 非成功裁决状态 | 无 |
| 绑定 | 无唯一裁决、异义当前、多首选、G0 漂移、许可 / 资源失败 | 对应绑定状态 | L2 入口前零写；提交后只按 L2 正式结果报告 |
| 绑定重复 | 同幂等键同义 | 精确重复 + 三路读回 | 不推进新代次 |
| 表达 | 绑定未确认、材料 / 上下文缺失、G0 漂移 | 对应表达失败 | 无 |
| 全链成功 | 唯一裁决、L2 绑定闭合、表达材料可读 | 已形成 / 已提交结果 | 仅名称关系由 L2 owner 写入 |
