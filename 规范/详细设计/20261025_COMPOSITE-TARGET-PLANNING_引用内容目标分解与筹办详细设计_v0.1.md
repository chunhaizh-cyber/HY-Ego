## 2. 目标表达：保留值/方向，不新增形式3

在`新_需求类.h`、现`新需求目标定义`前定义：

```cpp
struct 新需求引用内容定位 final {
    稳定编码 引用需求节点;
    std::vector<稳定编码> 正式内容路径;
    friend bool operator==(const 新需求引用内容定位&,
        const 新需求引用内容定位&) = default;

```

`新需求目标定义`尾部追加`std::optional<新需求引用内容定位> 引用内容定位;`，默认空。原`目标存在节点`仍是根E，`目标特征类型概念节点`仍是E的需求FT。没有定位时所有旧字段/核验/求值原义不变。有定位时：

- 只允许`目标形式=值`，`目标值域概念节点=C`必须是正式内容/结构范围；`目标比较关系概念节点`、`目标变化方向`必须空。匹配由正式内容符合语义执行，不假造二次比较RC。

- C及路径FT均是正式概念身份，路径不是底层字段编码或字符串。场景只作运行定位，不自动固化进静态目标；每次从E定位当前场景再调用同D组合读取。

## 4. typed符合与择一求值

本轮范围比较须随消费者交付，不拆空壳提供者。依据正式概念定义和值类型判定：合法存在、合法FT/特征/比较概念、正式概念/信息身份、I64区间/有限枚举、唯一存在、需求本次所需理解/确认身份；其它未支持原语受控返回未支持，不当不符合或零候选。

判定状态区分`符合、不符合、当前未知、不适用、未支持、前提已变化、资源失败`。原provider的已知项才比较实际值；当前未知不等于不符合，更不等于否定事实。不适用项在未选择分支中不参加AND；被选分支必需项不适用则该分支不符合。typed值自身与正式owner字段种类矛盾是工程错误；目标要求合法但实际值不在范围是正常不符合。

共同必需项逐项AND，跨项约束另核：FC属于目标FT、RC确与同一目标FT/FC相容；不能跨D或用其它需求拼齐。D主体/域/权重/活动的缺失或坏枚举是工程结构错误，不能产生补字段子需求。

择一先读正式判别FT及各分支范围：未知判别项→分支待定；不能任选，也不将204/205全部AND。恰一分支判别符合、其它判别不符时才确定本次分支，然后核该分支完整必需项；已确定不等于已满足。多个分支判别成立或全部不符均保留真实冲突/不符合，不挑有利分支。判别未知只针对判别项生成静态目标；分支确定后才展开该分支特有必要项。

U/C必须是D当前认知来源的真实成对关联：C关联U、主体E、目标E/FT/形式/全部载荷及来源要求与同D一致。不能“任意合法U＋任意合法C”就算符合。复用确认身份读取而非fresh执行资格；已过期确认不得被本叶伪称当前可执行，本叶结构完整与正式服务采用的fresh确认门分别保留。

单项范围比较与结构/分支判定均不写世界，不新增状态或经验；递归定义不能凭visited判符合，无法有限判定时具名未支持。联合保护覆盖所有正式定义、同D内容与引用，变化零载荷重筹办，不拼接不同批次。

## 5. 求值端口与锁边界

需求域只声明只读端口，不包含业务服务实现，pub服务实现端口，ordinary应用在线程创建前绑定；关闭时先解除端口再关闭pub。不改需求constructor，不形成头文件循环。

求值不得在需求领域锁内反入pub→需求内容读取：先锁内捕获自我目标D及完整预期，释放需求锁，调用端口，随后重核原自我D/目标与返回联合保护。定义核验也在锁外，创建候选以所得保护并入原建立CAS。需求列表/候选材料解码只还原结构与静态定位，不偷偷fresh求值或发起装配。

对方D正文仍仅由原需求owner改；服务组合只读。引用内容身份变化与内容变化分别判断，D内容补齐不制造F引用变化。完成判定必须重读父目标，不以子任务完成数量或消息代替真实内容满足。

`新需求当前满足状态`保留原1—15不变，尾加`目标引用前提已变化=16、目标内容未支持=17、目标内容分支待定=18、目标内容依赖未就绪=19、目标内容定义不合法=20`。引用内容判定依次映射：已满足→原已满足；未满足→原未满足但无有向差值；分支待定→18；未支持→17；依赖未就绪→19；引用前提已变化→16；定义不合法→20；资源失败→原资源失败。无I64准确差异，不填0充数。

新定位的筹办资格映射为：已满足→目标已满足；未满足或分支待定→允许筹办（前者可继续结构分解，后者只补正式判别项目）；未支持或依赖未就绪→等待普通材料且保留完整具名原因；引用前提已变化→材料已变化；定义不合法→目标定义不合法；资源失败→资源失败。所有新状态同步到任务/self/manager消费者，不由默认分支吞成结构损坏或方法缺失。

只读端口装配同指针重复返回`新需求操作状态::无变化`；空槽绑定或停止后解除返回`已修改`；已有另一非空指针时返回`入口拒绝`且不替换。该接口的线程前/停止后约束由普通应用装配与停机顺序保证，不能在运行中热换端口。
