## 2. F公开原子判定与拟建值预检

A的比较长期特征要求两真实观察；匹配长期区间要求观察E==跟踪E，不能用来给任意E的共享FC判定。本片新增两个具名const成员，不修改A请求解释、不取原E伪装新实例、不在concept/app复制二值距离。

`特征原子域判定请求{uint32_t 版本=1;特征长期读头 读头;特征类型域身份 类型域;特征类型化原子域 原子;特征原子实际值见证 实际;特征长期预算 预算;}`。`判定特征原子域(const 特征原子域判定请求&) const -> 特征长期读取结果<特征原子域判定事实>`。事实{类型域完整事实,规范化原子,特征类结点 实际F,可选引用材料,特征原子实际值见证 实际,bool 适用,optional<特征原子差异标量> 差异}；不回写F，不产生持久派生值。

判定先同G读取真实类型域及输出FT，要求请求原子.类型完整等于真实类型合同；区间非空且在完整I64域内，二值原子格式完全一致、半径>=0且代表图完整有效。实际F先按实际.H通过`按实例读取特征历史事实`证明该H完整属性组及唯一实际值，再以`读取特征历史事实`精确互证请求value；累计属性/历史预算，不能只读碰巧存在的指定值而跳过唯一性。禁止错valueID回退；实际FT必须等于类型FT，独立材料仅一次历史解引用。F只核验自己事实，存在上下文 / 成员定位不证明E归属，由应用另查E。前后G一致；原子代表直接来自完整请求，不要求其旧实例仍活动或原来源payload仍可回查。数据不宣称此请求已经是某个正式FC定义，concept需先从自己的正式定义读出相同原子。

I64区间用精确集合成员谓词，端点不改、无舍入；结果适用表示域成员判定，不另导出无类型布尔特征值。二值原子复用A `长期差异` 的同一私有实现、逐像素解析与预算，差异<=半径才适用。`特征原子差异标量{输出FT,类型域身份,单位,缩放,真实阶次=2,特征类型化原子域 左域输入,特征原子实际值见证 右实际,int64 值}` 是新具名值式合同，来源如实标记本次类型化域输入，不伪造左F或FC身份；其来源并不自行证明FC记录存在。二值比较失败或超预算整项失败无值；I64区间判定差异空，不能用0冒充二值比较回执。

`特征拟建值预检请求{uint32_t 版本=1;特征长期读头 读头;特征类型域身份 类型域;稳定编码 FT;特征类值 原始值;特征长期预算 预算;}`；`预检长期特征拟建值(const 特征拟建值预检请求&) const -> 特征长期读取结果<特征拟建值预检事实>`。事实{FT,类型域完整事实,原始值,variant<int64_t,特征二值图> 已解析值,可选引用材料}。复用普通F新建的FT活动 / 表示 / 禁用输出FT自槽准入及A格式解析，只读、零写；不伪造F/value身份、观察或二次比较结果，不提前执行共享域匹配。它仅防止先发布F后才发现不支持格式；F后续新增仍必须按新G自身重新验证。

两个方法预算复用A现七字段，所有实际类型/节点/值/像素/边界对都累计，读取前后守卫共同G。错误沿特征长期状态1—17：未知类型/坏格式/原子越界入口拒绝或类型不支持；真实历史缺失与预算、漂移、资源、差异不可表示分开，失败无读取成功载荷。原F退出后早H合法投影仍可判定；当前业务成功由应用另行fresh读。原子判定的bool只是域成员控制回执，不是新建无类型二次特征；真正暴露的二值差异量始终具名I64。

新增`特征原子实际值见证{稳定编码 F,值事实,FT;uint64_t H;}`，身份均非零；H与读头投影截止一致。它是本次只读判定的真实值来源，不要求观察标识、时间、E或成员关系，不产生A观察记录。FC把已验证观察映射成该四字段，EC/DC从其同H真实特征见证映射；不得用G冒充时间或填常数观察ID。F读取该真实F/value/FT的历史事实后复用A私有解析及差异内核，不能调用要求完整观察资格的A入口并伪填字段；原A12入口合同不变。

## 3. 共享FC定义、相等与包含

新增独立`概念树共享特征定义{概念树特征类型引用 FT;特征类型域内容 类型;bool 完整域=false;vector<特征类型化原子域> 原子组;}`。种类4=共享特征，根角色仍特征，旧kind1宿主定义不原地删字段；kind2/3不重编号。所有原子类型必须完整等于类型，FT相等。完整域=true时原子组必须空；false时必须非空。类型域记录ID和区间来源ID不进入等价，类型内容包括实际FT/单位/格式/算法/缩放，不能仅比较编码或哈希。

规范化：I64原子依下界/上界排序，合并重叠及无间隙相邻整数区间（邻接运算防溢出），若覆盖完整域则规范成完整域；不得填补间隙。二值原子按完整图格式、像素及半径全结构排序去重，此序只为稳定表示，不是向量距离。二值两个不同原子不借三角不等式推包含。相等=规范形式全等；包含=同类型TOP、I64集合包含、二值原子集合精确包含。新形成概念由FT+规范域共享，宿主/校正记录/来源观察/名称/计数不进入签名。

FT完整域为该FT顶层普通概念，直挂已有特征根；不新建本体根。单原子、多原子精确并集属于同一表示闭集；union操作是类型化集合析取，不能用包围半径代替。定义不可原地改义，当前（含退役）同义唯一；真实退出后新形成可获新身份，旧key始终恢复原身份。
