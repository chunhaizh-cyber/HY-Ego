## 1. 目标及裁决

用户本轮明确：筹办先核对概念化目标的实例结构；每个必要字段，包括目标特征类型、范围、比较关系，都必须有对应实例信息节点和关系；实际值允许未知；已有实例、关系和值复用，再分解需要行动补齐的内容。概念仍可作为实例信息节点的实际值，不把概念定义本身改写为实例。

当前第一项硬缺口是：先天需求内容 FT 使用 `信息节点引用` 表示，而特征 owner 连此类空 F 都拒绝建立。本叶只补其原 owner 的真实空 F 建立及读回。该 F 不是装着字段编码的定位包装，也不保存第二份需求内容。

本叶直接操作的是信息实例骨架节点，不是现实外界事实；没有本能方法执行、业务动作、状态、动态或自我需求的生成。后续持有者 D 的字段关系、非空引用值、存量迁移和筹办接线尚需下一代码结果，不在本叶冒称完成。

## 3. 唯一所有者、位置及签名

F 的唯一结构 owner 是 `新_特征类`；FC 定义及当前实例引用数的唯一 owner 是 `概念_特征类`。二者均属 ARCH-L2 / DATA-L2。只有各自 owner 编码本族写集，经 DATA-L1 中性组合发布；不把 FC 私有字段身份交给 F owner，不增加业务写入面。

四个生产文件：

- `海中鱼巣/领域/新_特征类.h`、`海中鱼巣/领域/新_特征类.cpp`。
- `海中鱼巣/领域/概念_特征类.h`、`海中鱼巣/领域/概念_特征类.cpp`。

保留所有现有公开签名。概念 owner 仅新增一个私有友元协作入口，`friend class 新_特征类`，不对业务公开：

```cpp
基础片段组合结果 联合发布新增空实例引用(
    const 特征概念信息& 预期概念,
    const 基础封存追加片段& 空实例片段) noexcept;
```

声明在 `概念_特征类` 私有区，定义在现有 `.cpp`、当前引用管理实现邻近；不新增文件、构造依赖、工程项、全局实例、线程或持久 schema。允许调用者唯一为特征 owner 的信息引用型空 F 创建分支；不回调 F owner、不解析 F 私有字段、不接受业务方裸请求。

此协作的片段来源保障是 C++ 私有访问限制及唯一调用边审查；DATA-L1 的封存 token 只证明同数据集、不可变内容，不负责领域来源认证。F owner 构造片段前完成 F schema、类型、模板和零值约束校验。

## 4. 空 F 内容与正常创建

空 F 必须共同具有：一个特征节点身份、恰一正式类型字段、恰一 FC 引用字段、按模板可选的单位字段。没有当前值、标准值、历史命中记录、旧历史字段、实例区间、历史聚合、归组子节点；不写空编码、不造“空值节点”、零数值或空引用集合来替代未知。

该入口建立独立 F，持有者关系仍由原存在/需求等 owner 按其合同建立。它不自动将 F 接到 D，也不猜持有者。下一骨架叶必须闭合 D→F 关系与正式读回，不可把本入口的独立 F 当整个骨架。

创建顺序：

1. 持有 `新特征互斥`，核特征 schema 已初始化，FC 是正式特征概念且完整可读。
2. 普通材料及已有引用类型继续原实现；若是 `信息节点引用` 且提供实际值，返回材料类型不相容，零写入。
3. 该类型且实际值未知：采用传入的正式 FC，不查值最具体概念，不运行身份 reader、匹配、聚合或归组，不补任何默认值。
4. F owner 构造一项新节点及完整初始字段，保存必要已存在 schema、FC、可选单位的只读预期，然后封存为一个不可变片段；封存零事实写入。
5. 调用私有概念协作入口。它在整个核验、计数封存、组合提交、计数读回期间持有概念锁。
6. 协作入口重读同一 FC，核验节点、材料类型、值域、单位、比较规则及聚合规则与预期模板一致；名称、当前引用数不要求等于模板旧值。实际引用数读取锁内当前值，要求非负且可受检加一。
7. 由概念 owner 读取 FC 当前完整联合预期，封存恰一计数字段替换 `n→n+1`；F owner 不读取或改写该私有字段。两片段的 FC 预期若冲突，零变化返回预期不符，不拼接新旧定义。
8. 一次 `原子追加封存片段组({空实例片段,计数片段})`，提交期间概念锁仍持有。成功后核计数恰为 `n+1`，返回与两个原片段严格绑定的回执。
9. F owner 检查成功回执数量及片段身份，从 F 片段回执取得恰一新节点；以 `获取特征` 独立读回 F，核同 FC、模板单位及全部值材料为空；成功才返回 `已完成` 和 F。

不能先公开 F 再补引用数，也不能先加计数再建 F；不得借失败回滚制造概念计数先减/后加。FC 可读性和引用寿命在共同发布点竞争，概念删除同样受其锁、计数及底座入向引用约束。

## 5. 读回、捕获及非空边界

`获取特征` 和 `捕获特征匹配实例` 对信息引用型空 F 均返回真实 `新特征信息`/匹配快照，节点及 FC 正确，所有值字段为空。不要求装配需求或其它目标身份 reader，因为没有目标值。

必须检查所有可能承载值的物理位置，而不只检查已投影的当前值：当前、标准、旧历史、命中记录、区间、聚合、归组标记/子节点。该类型出现本叶尚不支持的非空材料或损坏声明时走现有工程异常终止链，不能静默清空、当未找到或合法未知。不得泛化为拒绝其它已经支持的材料类型。

非空写入继续返回既有材料类型不相容；它是接口能力尚未开放，不产生业务“不符合”事实或学习反例。空 F 的比较若尚无适用信息引用规则，继续原显式未支持，不以“无值”冒充符合/不符合。不新增通用信息身份 registry 或将信息编码交给原始材料 reader。

## 6. 失败、并发、重复与生命周期

锁序固定为 `新特征互斥 → 特征概念树互斥 → DATA-L1锁`。不引入反向调用。概念增减等既有操作在概念锁上串行，不能在计数封存与共同提交之间覆盖新值。F 片段准备期间 FC 定义变化按预期不符处理，不能按新计数掩盖旧模板。

既有 `新特征写入状态` 映射：资源/长度分配失败为资源失败；正式 FC 缺失为概念不存在；共同提交的预期不符、节点/引用在准备后消失为前提已变化；入口及非法非空值分别保持入口拒绝/材料类型不相容。合法内部片段出现结构冲突、非法载荷、计数为负/溢出或成功回执不可读走工程保障链，不转换成业务未知。失败结果不携 F 成功载荷。

片段封存和提交前拒绝均零公开变化；提交成功后的计数或 F 读回不一致保留已提交事实并工程报告/中止，不返回资源失败、不重造 F 补偿。当前同步 DATA-L1 组合接口不提供跨启动未知恢复；不能承诺幂等账或通过重发收敛未知。

本接口维持独立创建语义，不自动按 FC 去重；不同显式调用可以建立不同合法 F。目标骨架的“已有实例则复用”由下一持有者叶按目标实例/字段身份唯一定位，不能在此全局按 FC 共用 F。一次已成功却上层丢失返回值时不得盲目重新建点。

生命周期复用原 `获取特征`、`删除特征`、概念引用减少及零引用叶概念清理；本叶静态确认空值、空历史可沿原路径释放，存在外部引用时仍不得破坏性退出。不改变任何 owner、退出规则或删除 ABI，不物理迁移旧 D/F。原通用删除分步执行及故障中途边界保留，未证实原子删除或运行恢复；本叶只保证新增 F 与概念计数的共同出生原子性。
