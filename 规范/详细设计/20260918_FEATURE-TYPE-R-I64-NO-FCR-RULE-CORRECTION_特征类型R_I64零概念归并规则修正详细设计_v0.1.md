# 特征类型 R I64 零概念归并规则修正详细设计 v0.1

状态：可执行。此设计只修订已发布 R 规则提供者的 I64 概念归并含义。

## 决策和边界

I64 R 是按准确值相等形成的单点集合。用户已裁决它不能产生严格包含其成员 FCv 的独立上位 FCr。7160 的同 FT、同规范域同义唯一因而不会再被用于建立 FCr→FCv 自环。

归并公开 DTO 不删除：它仍是未来其它 FT 专用规则的返回外壳。I64 路径固定成功零输出；零输出不是未启用、失败或需要重试。

## 物理规则与恢复

用途1归组和用途2代表继续是 I64 R 的必要规则。用途3概念归并从新建和补齐写集退出。已有 FT 若保留用途3历史关系，读取归并时不得访问它，补齐只检查用途1/2并零写成功；本切片不退出旧关系、不改变历史 H 解释。

归并对 I64 只读取 FT 定义以确认类别和截止；不消费 R项、成员、材料、FCv、域形成或用途3。因此这些未使用预算必须全为零，和无域已有零输出分支一致。任何非零未使用预算返回入口拒绝。结果回显 Gread/H、状态已归并零输出、项为空。

## 代码点与验证

特征类数据服务的 添加I64默认R规则 和 补齐I64默认R规则 固定两条规则；归并入口移除 I64 域形成和 FCv聚集分支。禁止修改头文件 ABI，除非编译揭示 private 声明必须同步且不改变公开类型。

专项夹具以真实 I64 FT、真实 F 与 R材料调用归并，断言带域/无域都成功零项；以 L1 读回断言新 FT 或补齐没有用途3；旧第三规则存在时补齐稳定零写。再编译 Debug/Release 的特征类翻译单元。
