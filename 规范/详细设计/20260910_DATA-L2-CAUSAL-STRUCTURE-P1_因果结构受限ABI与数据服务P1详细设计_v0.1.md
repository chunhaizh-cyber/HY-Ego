## 1. 目标、依赖与完成边界

本设计只实现4340 v0.1已经冻结的因果源级ABI和失败完备的数据服务P1：新增独立因果合同模块，原地重建当前0字节因果类，在因果owner内完成概念化定义发布/复用、当前历史及两类查询、自然定位证据关联/读取/退出、因果退出和两项身份读取。

唯一施工前置是`DATA-L2-DYNAMIC-STRUCTURE-P1`结果提交正式发布`海中鱼巣.领域.合同.动态结构`及4213只读provider。没有该结果时因果合同无法编译，计划保持`待激活`。

其它当前缺失不是施工ABI缺口，而是4340已冻结的运行分支：

- 当前概念树未实现`因果概念核验提供者`时，需概念核验的首次发布/证据关联返回`依赖未实现`、零写；
- 主动证据固定返回`动作来源未实现`；
- 准确值身份隐藏引用、参数二元RC等固定返回`约束不支持`；
- 未实现RC、动作DC、链或其它必要概念类别由provider返回依赖未实现；
- 真实B或动态来源不完整按对应来源状态失败。

隔离探针可以注入只实现公开抽象接口的确定概念/B/动态provider，证明被动定义、内联/域/区间及provider已核验RC、单主体原子或交叠原子组证据路径；这不等于生产概念、B、动作或因果确认算法已经实现。

本设计不修改动态、场景、状态、存在、概念、动作、动态概念、因果应用/链、L1、普通应用或消费者；不实现因果实例，不恢复旧ABI。完成不证明因果真实、实验确认、预测、生产装配或业务闭环。

## 4. 公开ABI与封闭定义

合同模块逐字实现4340第3—6节：合同版本1、五种概念强类型引用、主动/被动、角色、条件/动作/结果/时序/来源封闭联合、证据DTO、请求结果、状态数值、发布阶段、概念核验provider、因果只读provider、17项结构交付及全部成功谓词。不得改名、重编号、加字段、别名、重载或旧兼容类型。

`因果类数据服务 final`逐项实现只读provider七个const入口，并只增加`发布或复用因果`、`关联因果证据`、`退出因果证据`、`退出因果`，合计11个内容/身份函数。禁止因果实例CRUD、任意字段setter、物理清理、应用确认、动作调用或因果链建树入口。

结构预检查机械执行：角色1..R连续；条件/结果各非空且序号连续；同异闭包无冲突；主动恰一动作、被动无动作；参数角色唯一；时序端存在且差分约束可满足；variant不得valueless；值身份约束、参数RC等不支持分支在provider调用和写入前拒绝。定义规范化排序、去重和保序规则逐字服从4340第6节，不进行角色alpha重命名、定理等价或析取消除。

## 5. 交付、定义编码与v1识别

构造只读核验17编码非零互异、同一因果owner；定义属性和证据索引属性是U64组属性类型，其余为普通节点。格式锚点以字段登记类型向后续15项建立角色1..15恰一登记，端点和生命周期完整且无额外角色；构造不初始化、不补边。

定义U64组严格采用`[4340,1,正文元素数]`前缀和4340第6节递归编码：enum非零值、uint32上界、I64位型、vector长度、optional 0/1、variant声明顺序tag、强类型节点引用写本地引用序号。解码必须精确耗尽，无未知tag、截断、尾部、溢出或关系缺/多/错配。

普通Q在一个因果owner写集中同时发布：节点、族归属、定义值/槽、全部定义引用关系、初始空证据索引值/槽。定义引用依固定遍历逐出现编号，关系角色为该正序号；重复目标不合并。准确值身份只编码识别，首次新写出现即`约束不支持`，不得把值事实作为关系端点。

读取分类：非因果owner/不存在为`未找到`；因果owner普通节点无v1族归属且非17项元节点为`旧格式不支持`；v1族归属存在但布局缺损/混合/错owner或角色为`内部不一致`；H时退出为`目标已退出`。不解析HEAD旧条件/结果实例、用途观察节点、旧公共DTO或动态版本绑定。

## 6. 发布、查重与读取

入口顺序固定为版本/形状与预算 → 幂等重放/冲突 → G守卫 → 目标/旧格式 → 角色时序与硬拒绝 → 概念核验 → 原因果来源 → 全量同义查重 → 预算/引用 → 提交 → 独立读回。

概念provider使用同G/H和本次剩余预算，成功必须回显完整规范化定义、逐引用槽概念组和用量；provider未实现或必需类别缺失映射`依赖未实现`，任何假成功为内部不一致。原因果引用由本服务同截止读取；链概念只由provider核验，不回调因果展开。

查重以规范化定义hash有界召回，再逐字段完整比较。当前同义Q恰一返回`已复用`、零写且不绑定新键；多项为内部不一致；未命中才提交。hash碰撞不能视为相等。原已退出Q不复活，可形成新Q。

已绑定幂等键从L1首次规范化写集恢复操作、原G0、完整规范化定义/证据/退出集合和原结果；同义重放不重新核验当前概念或来源，使用本次Gread和原发布H读回。预算可变化但必须合法。异义返回幂等冲突。

当前/历史完整读取只解析Q自有结构，不重新调用概念provider。精确定义查询最多一项，按特征概念查询全量按Q编码升序；空组合法，预算不足不得截断成功。当前/历史身份仅核验族来源及生命周期，当前无来源载荷。

## 7. 证据关联、读取和退出

证据不建节点，身份是`Q + 发生锚点D`自然定位。Q上证据索引U64组采用`[4341,1,最大已用本地序号,活动数,...]`；新增关联与换出的新不可变索引值、Q→D/E/B关系同一因果owner写集发布，旧索引值同笔退出。本地序号单调不复用，关系分配顺序固定为锚点D、角色E、每个状态项原子D与B。

未绑定关联依次核验：Q当前、定义概念、0<证据截止<=G0、角色恰一及同异约束、动态锚点递归来源、每个条件/结果恰一证据、原子D位于闭包、条件B为前端/结果B为后端、B的E和S/FT匹配角色与FC。全部引用原子时间区间须共同非空交叠，且所有条件时刻早于所有结果时刻；所有新关系端点还须G0当前有效。

被动定义拒绝动作来源字段；主动定义无真实动作来源时固定`动作来源未实现`、零写。服务只证明结构来源，不判断样本足以证明因果。

同定位同规范化证据由不同键请求时返回`已复用`零写；同定位异内容返回引用冲突，必须先退出。读取按Q证据索引完整还原，并按原证据截止读取D/B/S；任一来源缺失/清理/预算不足则整个结果空载荷失败。未指定锚点的真实空组合法，指定不存在返回未找到。

退出证据在同一写集退出该定位全部Q→D/E/B关系并换出不含该项的新索引值；不退出来源。退出因果要求当前无活动证据和其它owner引用，只退出Q、族归属、定义引用、定义值及当前空索引值，不级联概念、原因果、动态或链。因果规律无TTL，本服务没有物理清理入口。

## 8. 预算、错误和可靠阶段

六项预算均非零，全调用共享；计量和向概念/动态provider换算逐字按4340第8节。缓存只复用同G/H公开材料，查询/证据不得截断成功。

所有非成功清空内容、组和见证，仅保留可靠发布阶段及provider用量。交换前失败=`无写入`；已确认提交但读回失败=`内部不一致 + 已提交待读回 + 发布G`；提交未知=`已可能发布 + 未知`。provider未实现→依赖未实现，来源不足/清理/漂移/资源同名映射，未知枚举或成功回显矛盾→内部不一致。

`bad_alloc/length_error`映射资源失败，其它未预期异常映射内部不一致。公开入口只记录一次本地诊断；私有辅助和provider不重复记录。本计划不新增日志ABI。
