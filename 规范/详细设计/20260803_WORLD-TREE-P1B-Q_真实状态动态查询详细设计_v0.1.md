## 1. 目标、范围与能力裁决

本叶子在 P1B-F 最终查询 ABI 内原位替换 `未实现` 函数体，组合 P1A3 世界结构结果与 P1B-M 同许可反向源投影，形成关系19状态事实和当前可完整证明的关系20非聚合动态事实。聚合动作致变与聚合动态在 DAG、层级、时间窗和聚合算法证据尚未冻结前，整次查询固定返回结构化 `未实现`，不得误报内部不一致或返回部分事实。

当前基线核对结论：P1A3F v0.3 已使 `海中鱼巣/领域/服务.节点直接世界结构.ixx` 的最终类型进入正式代码，但读取仍固定返回 `未实现`；P1B-F 查询模块和 P1B-M 最终生产接口尚未形成。故本设计可以冻结，但这些真实提供结果进入正式代码前，S0 必须零代码修改并按具名依赖漂移收口。旧 P1B 函数确认只作差异证据，不能证明四个状态/动态类型合同身份已进入正式共享头。

能力裁决：

| 所需能力 | 裁决 | 原因 |
| --- | --- | --- |
| 根、场景、存在的当前世界范围 | 复用 P1A3 最终 `读取世界结构` | 不复制第二套世界遍历 |
| 从主体/场景反向发现关系19/20源并取得源全关系和值 | 复用 P1B-M 最终函数 | 多个普通 L1 读取不能事后拼成同许可事实 |
| 状态/动态领域角色和值解释 | 本 P1B-Q 原位实现 | 属于 L2 状态动态事实所有者；聚合分支保持未实现 |
| 本层首次内部异常诊断 | 复用 `追根因检查` 的模块私有无抛包装 | 只诊断本根首次发现的资源失败、材料矛盾或异常；不成为机器事实 |
| SQL、材料、比较、提交 | 禁止 | SQL不是权威事实；本叶子只读且不比较、不写入 |

## 4. 请求准入与世界范围复核

准入条件：

- `请求.合同版本 == 节点直接状态动态查询合同版本 == 1`；
- `请求.头.合同版本 == 世界树服务合同版本`；
- `请求.头.世界规则版本 == 世界树规则版本`；
- 世界根见证完整且类型为 `场景`；
- 场景组每项完整且类型为 `场景`，主体组每项完整且类型为 `存在`；
- 两组各自按稳定身份唯一，不接受重复主键、同主键异内容或重复完整见证。

失败返回 `入口拒绝`、代次0、三组空。场景组和主体组均允许为空。

随后恰调用一次：

```cpp
世界结构_.读取世界结构(节点直接世界结构读取请求{1, 请求.头});
```

只接受 `已读取` 且代次非零。请求世界根必须与结果世界根逐字段相等；每个请求场景必须在结果场景组中有精确当前身份，每个请求主体必须在结果存在组中有精确当前身份。同稳定主键但类型或版本不同返回 `版本漂移`；没有稳定主键命中返回 `未找到`。两者都不返回部分事实。

世界结构非成功映射：全部同名状态原样映射，包括 `未实现`；任何非成功均返回代次0、三组空，且不重复诊断。世界结构成功且任一请求组为空时直接返回 `已读取 + 世界结构非零代次 + 三组空`，不调用要求筛选组非空的 P1B-M。

## 5. P1B-M 请求与事实截止

两组均非空时构造：

```text
必须节点组 = 世界根 + 全部请求场景 + 全部请求主体，按完整见证精确去重
每个主体 -> 状态事实角色/角色1，动态事实角色/角色1
每个场景 -> 状态事实角色/角色2，动态事实角色/角色2
```

恰调用一次：

```cpp
结构_.读取目标角色命中源的当前关系与类型化值(投影请求);
```

P1B-M 非成功按 `节点直接结构服务状态` 同名映射；不得保留部分材料。成功必须携带非零代次，且与世界结构代次完全相等，否则返回 `版本漂移`、代次0、三组空，不重试。P1C 是跨服务完整快照重试的唯一所有者。

P1B-M 的一个源可能因任一筛选命中而返回；P1B-Q 必须检查该源的全部同类型当前关系，并且只纳入主体、场景都属于请求范围的完整事实。其它完整但不同时匹配两组的源不进入结果，也不是缺项。

## 6. 关系19状态解析

源必须为 `状态` 节点，源组关系种类必须为 `状态事实角色`。其全部当前关系只能含下表角色：

| 角色 | 目标类型 | 基数 | DTO字段 |
| --- | --- | --- | --- |
| 1 | 存在 | 恰一 | 主体、主体关系 |
| 2 | 场景 | 恰一 | 场景、场景关系 |
| 3 | 特征 | 恰一 | 特征、特征关系 |
| 4 | 特征值 | 恰一 | 特征值、值关系 |
| 5 | 存在 | 恰一 | 来源存在、来源存在关系 |

未知角色、缺项、重复角色、额外关系、源端不等于本源、关系类型/版本/端点不完整均为状态材料内部不一致。

源的当前类型化值组中必须恰有一个 `状态发生时间类型合同 v1`，材料分支必须为 `std::uint64_t`。该值要求：`当前=true`、所属身份等于状态源、值记录身份和值记录版本完整、首次发布代次和当前状态发布代次非零且不晚于共同事实截止、来源为节点见证且等于角色5来源存在。映射到 `世界树U64类型化值事实` 时逐字段保留身份、版本、前一版本、值、来源和两个发布代次。

同一状态身份出现异内容、同一合同出现多个当前值或状态表同身份异事实均为内部不一致。

## 7. 关系20动态解析

源必须为 `动态` 节点，关系种类必须为 `动态事实角色`。公共必需角色：

| 角色 | 目标类型 | 基数 |
| --- | --- | --- |
| 1 主体 | 存在 | 恰一 |
| 2 场景 | 场景 | 恰一 |
| 3 被改变目标 | 特征或特征值 | 恰一 |
| 4 前状态 | 状态 | 恰一 |
| 5 后状态 | 状态 | 恰一 |
| 9 来源存在 | 存在 | 恰一 |

当前叶子可完整证明的种类适用性：

| 动态种类 | 角色6 来源动作 | 角色7 来源低层动态 | 角色8 同源迁移动能 | 聚合规则版本 |
| --- | --- | --- | --- | --- |
| 状态迁移=1 | 空 | 空 | 空 | 0 |
| 原子动作致变=2 | 方法恰一 | 空 | 动态恰一 | 0 |
| 观察=3 | 空 | 空 | 空 | 0 |
| 外部事件=4 | 空 | 空 | 空 | 0 |
| 聚合动作致变=2 | 方法恰一 | 动态至少一项且目标唯一 | 动态恰一 | 非零 |
| 聚合=5 | 空 | 动态至少一项且目标唯一 | 空 | 非零 |

源当前类型化值必须分别恰有：

```text
动态种类类型合同 v1 -> std::int64_t，值域1..5
动态发生时间类型合同 v1 -> std::uint64_t
动态聚合规则版本类型合同 v1 -> std::uint64_t
```

三值都必须满足状态值相同的记录身份、当前标志、所属、发布代次条件，来源均为节点见证且等于角色9来源存在。强类型 `世界树动态种类` 必须与 I64 数值精确一致。

关系20出现以下任一合法聚合形状时，不继续验证其 DAG，也不把它登记为缺项：`动作致变=2` 且角色7非空，或 `聚合=5` 且角色6/8为空、角色7至少一项并按目标唯一。两类形状都要求聚合规则版本非零。本轮清空全部状态、动态和缺项，返回 `未实现`、代次0。原因是现行 P1B-F DTO 与 P1B-M 材料尚未冻结聚合规则身份、层级、完整时间窗、递归低层闭包以及适用的 4180 注册算法/单位/维度证据；执行者不得临场推导、限制深度或把合法聚合误报为内部不一致。

`动作致变=2` 的角色6和8仍必须各恰一。角色7为空时只接受聚合规则版本0并作为原子动作致变继续；角色7非空时只接受聚合规则版本非零并按上段返回未实现。角色7非空但版本0、角色7空但版本非零、角色6/8基数错误仍是材料内部不一致。

`聚合=5` 不是动作致变的别名：角色6和8必须为零，角色7必须至少一项且同一目标不得重复，聚合规则版本必须非零。角色6/8任一存在、角色7为空/重复或版本为0均是材料内部不一致；不得因尚未实现 DAG 而跳过这些已经由 4210 冻结的基础形状准入。

## 8. 动态端点一致性

动态的前、后状态必须都已在本轮成功解析状态表中，禁止另行查询或补造。固定验证：

1. 两端状态主体、场景、特征逐字段相等；
2. 前状态发生时间严格小于后状态发生时间；
3. 动态发生时间等于后状态发生时间；
4. 角色1/2等于两端共同主体/场景；
5. 角色3为特征时等于共同特征；为特征值时必须等于前状态值或后状态值；
6. 非聚合分支的角色6—8及聚合版本满足 §7；合法聚合形状已在端点复核前结构化返回未实现。

任一失败形成 `世界树缺项种类::端点`，对象为动态源；有直接错误关系时携带该关系，否则关系为空。

## 9. 缺项、排序和结果

业务材料缺项形成：

- 状态角色/值问题：`状态角色`，对象为状态源；
- 动态角色/值问题：`动态角色`，对象为动态源；
- 前后状态及跨事实一致性问题：`端点`，对象为动态源。

现有 DTO 不含角色号，所以相同 `(缺项种类,对象,关系)` 精确去重，不修改 DTO。只要存在一个缺项，最终返回 `内部不一致 + 共同非零代次 + 状态组空 + 动态组空 + 稳定缺项组`，禁止部分成功。

稳定身份键均按 `稳定主键.命名域 -> 键值 -> 身份版本`：

- 状态：场景身份、主体身份、特征身份、发生时间U64、状态身份；
- 动态：场景身份、后状态发生时间U64、动态身份；
- 缺项：种类数值、对象有无/对象身份、关系有无/关系身份。

排序后精确去重；同身份异内容不是去重，而是内部不一致。全部范围有效、共同代次一致且没有匹配状态/动态时，返回 `已读取 + 非零共同代次 + 三组空`。

## 12. 零代码机械推演

1. 空场景组、非空主体组：P1A3验证根和主体后直接成功空结果，P1B-M调用0。
2. 一场景一主体、零关系命中：P1A3与P1B-M同代次，返回已读取空组。
3. 完整关系19：五角色和值证据通过，形成一状态；无动态合法。
4. 状态时间值来源不等于角色5：记录状态角色缺项，最终内部不一致且不返回该状态。
5. 完整原子动作致变动态：角色6方法、角色8动态恰一，角色7空、聚合版本0；两端状态和时间通过后形成动态。
6. 合法聚合动作致变或聚合动态：清空全部载荷，返回未实现、代次0；不记录逻辑异常。
7. 聚合角色形状与版本互相矛盾：记录本层逻辑异常一次，形成动态角色缺项，最终内部不一致。
8. P1A3代次10、P1B-M代次11：丢弃全部材料，版本漂移、代次0，不重试。
9. 容器分配失败：安全诊断一次，资源失败、代次0、三组空，零机器事实变化。
