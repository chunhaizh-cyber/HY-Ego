# WORLD-TREE-P1A2Q 故障注入补充详细设计 v0.2

日期：2026-08-03

设计身份：WORLD-TREE-P1A2Q

来源问题：`DRIFT-P1A2Q-INTERNAL-CORRUPTION-TEST-UNFORMABLE`

## 1. 裁决、范围与替代关系

保留 `WORLD-TREE-P1A2Q` 详细设计 v0.2 §5 的内部损坏矩阵，不把无法由正常公开生命周期构造的损坏项删除或降级为静态扫描。正常生命周期必须继续保证发布时把候选事务序号清零、正反绑定同步形成并拒绝重复；专项自检不得为了制造坏数据而增加可写容器、友元、恢复旁路或旧域仓库依赖。

本版唯一裁决为：在既有专项宏内，对两个生产读取根的**防御性判断谓词**增加实例私有、一次性测试模式。测试模式只让下一次合法调用在精确检查节点把指定谓词视为失败，不修改正向表、反向表、节点仓、关系仓、发布代次或其它机器事实。调用开始即以原子 `exchange(0)` 消费，第二次同输入调用自动回到正常路径；因此恢复方式是“一次消费后自动恢复”，不是先破坏再修补机器结构。

本文件完整替代 `20260803_WORLD-TREE-P1A2Q_故障注入补充详细设计_v0.1.md`。详细设计 v0.2 的生产函数、DTO、锁、状态和正常控制流继续有效；本版只替代其自检可构造性与验证方式。

受影响生产文件仍只有：

```text
海中鱼巣/核心/仓库.可重建索引.ixx
海中鱼巣/核心/服务.节点直接结构.ixx
```

唯一测试消费者仍为 `海中鱼巣/核心/自检.节点直接结构查询.ixx`。不得修改共享合同、候选生命周期、恢复入口或其它仓库。

## 2. 编译边界、实体所有权与共同生命周期

下列测试枚举、函数、字段、私有异常和所有注入分支必须全部位于：

```cpp
#if defined(HY_EGO_ENABLE_STRUCTURE_COMMIT_FAULT_SELF_TEST)
// P1A2Q 专项自检实体和分支
#endif
```

宏关闭时两个类的生产布局、公开实体、函数体和调用边不含本设计内容。禁止第二宏、全局或静态共享故障状态、环境变量、命令行开关、运行期配置、可写容器引用和跨实例传播。

每个目标对象只保留 v0.1 已冻结的一个 `mutable std::atomic<std::uint8_t>` 故障字段；资源异常、其它异常和本版内部损坏共用该字段，不增加第二状态。设置函数以 `store(..., std::memory_order_release)` 覆盖尚未消费的模式；合法键通过后、取得仓锁或事务域许可前，根函数恰一次 `exchange(0, std::memory_order_acq_rel)`。非法键不消费。测试指令不是机器事实、事务版本或业务并发协议。

诊断责任固定为：两个设置函数都是宏内测试适配，非法枚举只返回 `false`，无适用错误分支；两个读取根继续按生产合同向上送出结构化状态，不写日志。

## 3. 索引仓根的精确测试合同

唯一物理位置：`海中鱼巣.核心.仓库.可重建索引` / `海中鱼巣/核心/仓库.可重建索引.ixx`，类 `可重建索引仓库` 的 public 区域，仅宏内可见：

```cpp
enum class 可重建索引精确读取内部损坏测试种类 : std::uint8_t {
    已发布候选事务序号非零 = 1,
    记录键错配 = 2,
    反向绑定缺失 = 3,
    反向绑定重复 = 4,
    目标权威不可读 = 5
};

bool 测试_令下次结构化精确读取模拟内部损坏(
    可重建索引精确读取内部损坏测试种类 种类) noexcept;
```

函数只接受稳定值 1—5：合法时把共用原子字段写为 `2 + static_cast<std::uint8_t>(种类)` 并返回 `true`；其它底层值不改字段并返回 `false`。v0.1 的两个异常设置函数继续分别写稳定值 1、2。不得增加重载、通用“写测试状态”函数或暴露原子字段。

`读取索引物理键结构化` 消费后的局部模式只在下列原生产检查点生效：

| 稳定模式 | 精确检查节点 | 注入行为 | 预期结果 |
| --- | --- | --- | --- |
| 3 | 已发布条目的 `候选事务序号 == 0` | 把本次判断视为不成立 | `内部不一致`、空记录 |
| 4 | `记录.物理键 == 输入键` | 把本次判断视为不成立 | 同上 |
| 5 | 反向目标组存在 | 把本次查找视为未命中 | 同上 |
| 6 | 反向组中输入键计数恰为 1 | 把本次计数视为 2 | 同上 |
| 7 | 释放索引锁后的 `目标权威可读_` | 把本次结果视为 `false`；不得跳回持锁区 | 同上 |

模式只在正向条目真实存在且已发布、流程到达对应节点时生效； fixture 不满足前置时模式仍已消费并按实际生产路径返回，专项自检必须把这种情况判为夹具失败。注入不得改写容器或候选，不得持索引锁调用节点/关系仓。

## 4. 查询服务根的精确测试合同

唯一物理位置：`海中鱼巣.核心.服务.节点直接结构` / `海中鱼巣/核心/服务.节点直接结构.ixx`，类 `节点直接结构查询服务` 的 public 区域，仅宏内可见：

```cpp
enum class 节点直接当前索引读取内部损坏测试种类 : std::uint8_t {
    节点目标权威读回缺失 = 1,
    关系目标权威读回缺失 = 2,
    关系端点见证不可形成 = 3
};

bool 测试_令下次当前索引读取模拟内部损坏(
    节点直接当前索引读取内部损坏测试种类 种类) noexcept;
```

合法值 1—3 分别写入共用原子稳定值 3—5并返回 `true`；其它底层值不改字段并返回 `false`。v0.1 的资源/其它异常设置函数继续写 1、2。

`读取当前索引` 在合法键后消费模式；异常模式 1/2 继续在许可前抛出并由现有边界分类。内部损坏模式只在仓结构化读取已经成功后生效：

| 稳定模式 | 精确检查节点 | 注入行为 | 预期服务结果 |
| --- | --- | --- | --- |
| 3 | 节点目标分支的 `节点_.读取节点` 结果检查 | 以空 `optional` 进入原失败判断 | `内部不一致`、代次0、空组 |
| 4 | 关系目标分支的 `关系_.读取关系` 结果检查 | 以空 `optional` 进入原失败判断 | 同上 |
| 5 | `形成关系见证_` 完整性检查 | 以空 `optional` 进入原失败判断 | 同上 |

测试模式与真实目标种类不匹配时视为夹具失败：函数仍返回 `内部不一致`，专项自检不得把它计入对应具名场景。注入只替换当前栈上的只读结果，不写仓、不释放后重入、不改变共享许可生命周期。

## 5. 专项自检与恢复证明

专项先通过 P1A2 正式提交服务建立隔离的已发布节点索引和关系索引；不得直接填充私有表。每个模式使用新对象或先证明上一个模式已消费。矩阵至少覆盖：

| 根函数 | 模式 | 第一次合法调用 | 第二次同输入调用 | 必须证明 |
| --- | --- | --- | --- | --- |
| 仓结构化读取 | 候选序号非零、记录键错配、反向缺失、反向重复、目标权威不可读 | 内部不一致、空记录 | 已读取、恰一原记录 | 前后权威导出逐值相等；无实际容器损坏 |
| 查询服务读取 | 节点目标读回缺失 | 内部不一致、0、空组 | 成功、原代次、恰一节点目标 | 事务域代次与六仓导出不变 |
| 查询服务读取 | 关系目标读回缺失、关系端点见证不可形成 | 内部不一致、0、空组 | 成功、原代次、恰一关系目标 | 同上 |
| 两根 | 资源异常、其它异常 | 保持 v0.1 分类 | 第二次恢复正常 | 一次性消费未回归 |
| 两根 | 非法枚举设置 | 设置返回 `false` | 后续合法读取正常 | 原模式未被覆盖 |
| 两根 | 先设模式后调用非法键 | 入口拒绝且不消费 | 下一次匹配合法调用命中预设模式 | 准入顺序正确 |

专项还须静态证明测试设置函数的唯一项目调用方是 `自检.节点直接结构查询.ixx`；Release 或其它宏关闭配置的编译实体中，两个测试枚举、六个设置函数/字段及测试异常均不存在。生产正常路径的源级条件仍必须独立包含真实字段比较，禁止用测试模式替代生产校验。
