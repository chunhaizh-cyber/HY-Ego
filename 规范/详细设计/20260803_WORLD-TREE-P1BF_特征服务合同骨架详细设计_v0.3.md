## 1. 修订目标与当前事实

本设计是全新不可变 v0.3，供计划 v0.4 替代尚未执行的 v0.3。它保留原“宿主组完整当前特征”最终合同，并在同一共享事实头、同一查询模块、同一服务类和同一顺序200自检中，新增“具名已发布特征值材料”最终合同。两个函数对任意输入固定返回安全 `未实现`，参数读取、依赖调用和机器事实变化均为0。

当前正式代码已有 `领域/世界树事实.数据.h`，但尚无 `世界树特征事实`、`世界树特征值材料事实`、特征查询 DTO、查询模块或顺序200自检；P1BF v0.3 在索引中可执行但尚未执行。P1A3F v0.3 结果 `3242c16640da898b546f294199c00c08032ba49c` 已建立共享头，P1A2Q v0.7 结果 `2c78d4c59262796c42fc929c0192a37ed11e5be3` 已占顺序190，P1A2G v0.2 结果 `98858a7fd25b1b85b80c3872b48c7646ed0c612d` 已提供后继真实查询可消费的 L1 业务中性投影，但本骨架不调用它。

## 4. 服务类、构造与两个骨架函数

最终模块和物理文件不变：

```text
export module 海中鱼巣.领域.服务.节点直接特征查询;
海中鱼巣/领域/服务.节点直接特征查询.ixx
```

最终类完整公开面：

```cpp
class 节点直接特征查询服务 final {
public:
    explicit 节点直接特征查询服务(
        节点直接结构查询服务& 结构) noexcept
        : 结构_(结构) {}

    节点直接特征组读取结果 读取宿主组完整当前特征(
        const 节点直接宿主组特征读取请求& 请求) const noexcept;

    节点直接具名特征值材料读取结果 读取具名已发布特征值材料(
        const 节点直接具名特征值材料读取请求& 请求) const noexcept;

private:
    节点直接结构查询服务& 结构_;
};
```

构造引用由装配宿主拥有并长于服务；服务不拥有、不替换依赖。两个请求均为调用期 const 借用且不保存，结果由调用方按值拥有。

宿主组函数继续固定：

```cpp
static_assert(noexcept(节点直接特征组读取结果{
    节点直接特征读取状态::未实现, 0, {}, {}}));
return 节点直接特征组读取结果{
    节点直接特征读取状态::未实现, 0, {}, {}};
```

具名材料函数固定：

```cpp
static_assert(noexcept(节点直接具名特征值材料读取结果{
    节点直接特征读取状态::未实现, 0, std::nullopt}));
return 节点直接具名特征值材料读取结果{
    节点直接特征读取状态::未实现, 0, std::nullopt};
```

两个函数都不得命名参数、解引用请求、读取 `结构_`、构造默认结果、分配容器、捕获异常、诊断、取得许可或调用任何函数。固定 prvalue 无抛断言失败即编译失败，不得删除 `noexcept`。

## 5. 后继替换合同

FEATURE-Q 只原位替换 `读取宿主组完整当前特征`；FEATURE-HQ 只原位替换 `读取具名已发布特征值材料`。二者不新建服务、模块、DTO、重载、自检项或兼容入口。

真实 FEATURE-HQ 必须从当前内存中一次共享许可下的已发布 `类型化值读回` 形成材料，严格验证完整特征值身份、当前性、合同身份/版本、记录身份/版本、来源为存在节点及两个发布代次；SQL、持久材料、日志、缓存和旧特征栈均不得成为运行期来源。真实设计尚未形成前，本包不替它决定状态映射和读取算法。

## 7. 工程、自检和验证

复用唯一模块 `海中鱼巣.领域.自检.节点直接特征查询合同骨架`、唯一报告、唯一适配函数和唯一顶层身份 `WORLD-TREE-P1BF-S01` / 顺序200。v0.4 只把该自检从单函数矩阵扩为双函数矩阵；正式顶层自检仍从20增加到21，不新增第二顺序200项。

必须覆盖：两函数默认/非法/完整/边界请求均固定未实现；DTO字段顺序和状态1—8静态断言；具名材料全部10字段类型静态断言；两个函数参数引用和调用边均0；`结构_` 只在构造初始化和成员声明出现；调用前后权威仓、幂等账、持久侧账和事实代次相等；SQL/材料/缓存/旧栈开关不影响结果；消费者收到任一未实现后成功后继调用数0。

MSVC Debug/Release 构建、自检、strict、模块依赖和两个完整函数源码闭包是必过门禁。Clang 仅按现行规则作为可用时诊断，不得因既有 PCM 失败扩大白名单。
