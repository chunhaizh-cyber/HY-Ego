# INSTINCT-STAGE3-HARD-DENIAL-RULE-UNIVERSE 任务现实执行硬否决规则宇宙详细设计 v0.1

日期：2026-08-31

## 1. 目标与完成边界

本叶建立唯一、版本化、封闭的任务现实执行硬否决规则宇宙，并让既有硬否决 provider 只消费该宇宙的强类型全集读回结果。完成后具备：

```text
显式发布完整规则宇宙
-> 同一 owner 原子形成宇宙、规则、成员索引和当前版本
-> 退出旧宇宙及旧规则但保留历史
-> 在 Gnow 完整枚举当前宇宙
-> 对每条规则裁定版本、生命周期、self、共同作用场景和现实改变动作范围
-> 输出规范有序适用规则事实身份组与逐项覆盖见证
-> hard-veto 只以完整强类型结果裁决未命中 / 命中
```

本叶不发布任何真实规则清单，不自动发布空宇宙，不接 FRESH composer、任务最终复核或普通应用，不产生正向授权，不写任务、方法、状态、动态、场景或 L/H。

当前生产定义保持：

```text
值域 = 0..INT64_MAX
L = 2,767,011,611,056,432,742
H = 7,378,697,629,483,820,645
安全根定义版本 = 1
主动安全结算规则版本 = 1
```

“阈值浮动”只表示未来可以发布新定义版本；当前实例不重算、不原地修改版本 1。

## 2. 当前事实与复用裁决

当前正式 `main@912b8543976e9ebe7ebb4818a6b85eee3bcfa3af` 已有：

1. L1 owner-scoped 原子写集、当前 / 历史读取、首次幂等材料和关系类型闭包；
2. L2任务冻结动作项、动作作用范围、L2存在 / 场景强类型身份；
3. L2场景结构公开完整读取，可在一个非零 `Gnow` 证明共同场景和直接成员；
4. 6150 v0.12、5230 v1.6 已冻结单一共同作用场景：控制室、车间、设备、自我是场景成员存在，不是并列动作场景；
5. 工作区存在未发布候选安全 owner，但其请求、键段、生命周期和多场景同层算法与现行合同不符，只作待替换 WIP，不能成为实现依据。

复用裁决：

- 新增唯一安全规则结构 owner，不修改任何 L1 源码；
- 复用 L2场景服务公开读取，不复制树 / 成员算法；
- 规则完整集合只由本 owner 当前成员关系重建，不持久化第二份成员 vector；
- hard-veto provider 保持无持久事实，只消费 owner 的正式读回结果；
- 没有正式规则宇宙时全部现实改变路径 fail-closed，fixture 的空宇宙不代表生产安全闭环。

## 4. 规则定义 ABI

共同 L2 请求头保持现行版本；本合同专属版本固定为 2。

enum class L2硬否决约束模式 : std::uint8_t {
    任意 = 1,
    精确集合 = 2

struct L2硬否决动作作用范围约束_v2 {
    std::vector<任务动作作用范围> 包含范围;

struct L2任务现实执行硬否决规则定义材料_v2 {
    L2任务现实执行硬否决规则语义身份 语义身份;

有效性：

1. 任意模式成员必须空；精确集合必须非空、有效、严格升序且无重复；
2. 包含范围非空，按枚举值严格升序且无重复；
3. 物理来源组非空、严格升序且无重复；
4. 同语义身份多份输入只有三类约束逐字段相同才归一；物理来源取规范并集；约束异义返回引用冲突；
5. 发布前形成按语义身份严格升序的规范规则组。输入分组和顺序不形成第二身份，规范结果相同即为同义。

## 5. 持久事实与版本发布

```cpp
struct L2任务现实执行硬否决规则宇宙事实_v2 {
    L2任务现实执行硬否决规则宇宙身份 宇宙;
    std::uint64_t 规则版本;
    std::uint64_t 成员集合版本;
    std::vector<L2任务现实执行硬否决规则语义身份> 规范成员语义身份组;
    L2生命周期 生命周期;
};

struct L2任务现实执行硬否决规则事实_v2 {
    L2任务现实执行硬否决规则事实身份 身份;
    L2任务现实执行硬否决规则宇宙身份 宇宙;
    std::uint64_t 规则版本;
    std::uint64_t 成员集合版本;
    L2任务现实执行硬否决规则定义材料_v2 定义;
    L2生命周期 生命周期;
};

enum class L2任务现实执行硬否决规则版本切换原因_v2 : std::uint8_t {
    首次发布 = 1,
    撤销 = 2,
    失效 = 3,
    替代 = 4,
    组合修订 = 5
};
```

宇宙成员关系由同一写集按规范规则顺序 `1..N` 形成。`N=0` 合法；完整成员组只从同截止成员关系重建。

发布请求字段顺序：

```cpp
struct L2任务现实执行硬否决规则宇宙发布请求_v2 {
    std::uint32_t 合同版本 = 2;
    L2结构请求头 请求头;
    L2结构幂等身份 幂等身份;
    std::uint64_t 新规则版本;
    std::uint64_t 新成员集合版本;
    L2任务现实执行硬否决规则版本切换原因_v2 切换原因;
    稳定编码 切换依据事件;
    std::vector<L2任务现实执行硬否决规则定义材料_v2> 完整规则组;
};
```

发布规则：

1. 无当前宇宙时两个新版本必须均为 1，原因必须为首次发布；
2. 后继两个版本必须分别等于当前版本 `+1`，原因不得为首次发布；加一溢出返回版本漂移；
3. 一个 owner 写集退出旧当前关系、旧宇宙、旧规则及其全部 owner 内值 / 关系，建立新宇宙、全部规则、成员关系和当前关系；外部 self / 场景端点不得退出；
4. 撤销、失效、替代或组合修订的旧生命周期结束边界均为实际新版本发布 `G1`；历史读取保留全部旧事实；
5. 精确重复返回首次 `G1` 且零第二写；同键异义为幂等冲突；
6. 提交后读回失败只返回四字段提交见证：owner、幂等身份、首次提交事实代次、新规则版本；同键重试必须从首次规范写集收束；
7. 显式空规则组是一个有版本的已发布空宇宙；“没有收到规则记录”不是空宇宙。

发布状态：

```text
已发布、精确重复、入口拒绝、许可拒绝、当前性漂移、版本漂移、
幂等冲突、规则集合不闭合、引用冲突、资源失败、内部错误、已可能发布
```

只有已发布 / 精确重复且宇宙、完整规则组和正式读回截止完整时成功；已可能发布只携带提交见证。

公开入口：

    const L2任务现实执行硬否决规则宇宙发布请求_v2&) noexcept;

## 6. Gnow 全集读回与共同场景

读取请求字段顺序：

```cpp
struct L2任务现实执行硬否决规则全集读取请求_v2 {
    std::uint32_t 合同版本 = 2;
    L2结构请求头 请求头;
    L2存在身份 自我;
    std::vector<任务冻结动作项> 完整有序冻结动作范围;
};
```

请求不携带宇宙身份或规则版本；服务固定绑定唯一当前宇宙。动作范围必须非空、顺序连续、身份 / 材料有效且动作入口不重复。

共同作用场景裁决只消费现实改变动作：

1. 零现实改变动作时不建立共同场景；hard-veto 生产消费者应直接走“不适用”，无需调用规则全集；owner 若被独立调用，任意场景约束裁定匹配，精确场景约束裁定不匹配；
2. 存在现实改变动作时，每项必须携带同一个非零 `作用场景`；任一缺失或不一致返回场景范围不闭合；
3. 服务以 L2场景公开完整读取在 `Gnow` 证明该场景当前存在，并证明 self 与全部现实改变动作直接作用主体都是该场景的当前直接成员；漏项、额外归属歧义、场景退出或读回漂移均返回场景范围不闭合 / 当前性漂移；
4. 内部治理和纯现实观察动作的可选场景不参与硬否决场景匹配，也不能建立第二任务级场景；
5. 控制室、车间、设备、自我是共同场景中的存在，禁止恢复“多个动作场景同树同层”算法，禁止从 self 当前位置、公共祖先或首项补造共同场景。

覆盖项字段固定为：

```cpp
struct L2任务现实执行硬否决规则覆盖项_v2 {
    L2任务现实执行硬否决规则语义身份 规则语义身份;
    L2任务现实执行硬否决规则事实身份 规则事实身份;
    bool 规则版本一致;
    bool Gnow生命周期有效;
    bool self匹配;
    bool 场景匹配;
    bool 动作作用范围包含;
};
```

`适用()` 只有上述五个判定全真。动作范围包含只检查现实改变动作子集；每项的作用范围都必须位于规则包含范围。

完整集合见证字段：

```cpp
struct L2任务现实执行硬否决规则完整集合见证_v2 {
    L2任务现实执行硬否决规则宇宙身份 宇宙;
    std::uint64_t 规则版本;
    std::uint64_t 成员集合版本;
    std::uint64_t 声明成员数;
    std::vector<L2任务现实执行硬否决规则覆盖项_v2> 覆盖项组;
    std::uint64_t Gnow;
};
```

完整必须证明：覆盖项数等于声明数；覆盖身份与成员索引逐项相同；无漏、多、重；每项五项判定均已裁定；适用事实身份组恰等于全部 `适用()` 项并按语义身份规范有序。禁止摘要或裸 bool 代替覆盖。

读取状态：

```text
已读取、未发布、入口拒绝、许可拒绝、当前性漂移、场景范围不闭合、
规则宇宙不闭合、适用性未裁定、引用冲突、资源失败、内部错误
```

成功载荷为宇宙事实、完整规则组、适用规则事实身份组、完整见证和 `Gnow`。合法空适用组只允许已发布宇宙且见证覆盖全部 `N` 项。全部非成功为空载荷、截止 0。

## 7. hard-veto v2 消费

既有 v1 裸 `vector<稳定编码>` 仅保留源码兼容，生产调用归零。v2 请求必须携带正式规则全集读取结果。

裁决固定为：

```text
零现实改变
-> 不适用；不要求规则宇宙

含现实改变 + 全集不完整 / 未发布
-> 材料不足；零动作

含现实改变 + 完整见证 + 适用事实组为空
-> 未命中

含现实改变 + 完整见证 + 适用事实组非空
-> 已命中；命中证据为强类型规则事实身份组
```

provider 不枚举、拼接、缓存或发布规则宇宙，不拥有 owner，不把非完整集合降级为空。
