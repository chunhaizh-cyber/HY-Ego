# DEMAND-CURRENT-SAME-PARENT-TARGET-CONSUME 同父同目标当前需求消费详细设计 v0.2

日期：2026-08-16
版本：v0.2

## 1. 修订目标与完成边界

本版同身份替代 v0.1，并实现 BIZ-L4-004-02-01-02 v0.3。精确复用键、零 / 一 / 多裁决和单次 DATA-EXT-12 组读不变；修正 v0.1 把需求当前路径错误冻结为单数的问题。唯一需求结果必须完整携带同一父需求下全部当前路径关系组，而不是任选一个 `当前路径身份`。

完成仍只证明这一枚 BIZ 只读定位叶；不复核正差距或来源资格，不新增 / 合并需求，不裁决路径角色、防环、活动路径选择或结算，不创建任务。

## 2. 正式裁决与当前事实

- 0050、4030：BIZ 只经公开强类型 DATA 服务消费值式结构，零 L1、owner、仓库和事务参与者。
- 3100、5100：一个需求只有一个主体、目标宿主、目标特征和目标状态合同；来源和路径不改变目标身份。
- 5110：同一父需求下同目标当前需求必须复用或合并；父级可以同时存在多个 OR 替代路径，每条 OR 又可有多个 AND 成员，实际结算只能由一条合法活动 OR 路径领取一次。
- 上述规则共同决定：同一需求身份可以经多条互异当前路径关系参与同一父需求的不同路径组；关系各自拥有角色、顺序、当前性和版本。否则同父同目标复用与多替代路径无法同时表达。
- v0.1 的精确目标语义键仍成立：`需求主体 + 可空父需求 + 目标宿主 + 目标特征定义 + {完整L2特征比较I64合同材料,目标I64,允许关系位,目标状态合同规则版本}`。目标合同 / 比较注册身份只作权威引用；来源、时间、目标场景和路径不入键。
- DATA-EXT-12 精确组读和需求结构生产 ABI 尚未发布；当前只有 `L2需求身份`及需求节点族。本设计是消费合同，不把待实现接口写成当前能力。

具名修订原因：

```text
DRIFT-DEMAND-CURRENT-SAME-PARENT-TARGET-CURRENT-PATH-CARDINALITY
```

## 3. DATA-EXT-12 预冻结消费合同

语义能力名保持：

```text
需求结构服务::按主体父需求与目标结构材料有界读取当前需求组
```

请求至少携带共同 L2 请求头、主体、可空父、目标宿主、目标特征、权威目标合同身份、完整目标状态语义键、事实 / 需求范围及需求树 / 父关系 / 目标 / 路径 / 来源授权 / 生命周期 / 读取规则版本，并分账三个非零总预算：当前需求数、全部来源与授权项数、全部当前路径关系数。

成功为 `已读取 + optional 有值`，值包含零或多项匹配需求以及三类预算回显、共同 G0 和零变更代次。每个需求至少完整携带：

```text
需求身份、身份来源、主体
目标场景、目标宿主、目标特征、目标合同 / 比较注册引用、完整目标状态语义键
可空唯一当前父需求及父关系见证
全部当前来源证据与当前授权组
全部当前路径关系组 {
  路径关系身份与身份来源,
  父需求与子需求端点,
  路径组强类型身份,
  路径角色强类型身份,
  路径顺序强类型值,
  当前性强类型事实,
  生命周期与路径结构版本,
  单项事实截止G0
}
需求生命周期、全部结构版本、单项事实截止G0
```

同一需求下的路径组必须零重复、零截断，并按路径组身份、角色、顺序、路径关系身份稳定排序。不同路径关系不得因父子端点相同而折叠。DATA 不判断哪条路径合法活动或应结算；无匹配需求是成功空组，任一预算不足均零需求组拒绝。

精确 C++ 类型名、字段顺序和状态数值待 DATA 正式发布后机械匹配。最终需求清单必须把完整当前路径关系组及独立预算纳入同一中性组读，不得恢复单路径 optional、逐路径 BIZ 回读或业务路径选择参数。

## 4. BIZ DTO 与物理位置

计划仍使用：

```text
海中鱼巣/领域/需求同父目标读取.数据.h
海中鱼巣/领域/服务.需求.ixx
```

预冻结 BIZ 请求在 v0.1 字段基础上把一个数量预算拆为：

```cpp
std::uint64_t 当前需求数量预算;
std::uint64_t 来源授权总数量预算;
std::uint64_t 当前路径关系总数量预算;
```

`当前单目标需求值式事实`把旧单数路径替换为：

```cpp
std::vector<当前需求路径关系值式事实> 当前路径关系组;
```

`当前需求路径关系值式事实`必须覆盖第 3 节全部路径字段；具体强类型名机械匹配 DATA-EXT-12 最终 ABI，不得用裸整数、字符串或 bool 代替路径组、角色、顺序、当前性和生命周期。父需求为空时路径关系组必须为空；父需求非空时路径关系组必须至少一项。违反任一基数条件，以及错端点、重复关系、同一关系多版本当前、组内混代或超过预算，均为内部不一致、零业务载荷和零事实截止。

其它合同保持：两份固定配置共同字段不重复；结果状态仍为不存在、唯一当前需求、多个当前同目标、请求拒绝、当前性漂移、数量预算不足、提供者拒绝、资源失败、内部不一致。只有唯一状态携带完整需求 optional；已读取零 / 一 / 多回显 G0，其它状态截止为0。

## 5. 固定流程与异常映射

```text
校验两份固定配置
-> 校验请求和三类非零预算
-> 校验请求版本匹配固定配置
-> 构造一次 DATA-EXT-12 精确目标键组读
-> 恰一次调用需求结构服务
-> 互证请求回显、G0、版本、三类预算和 optional
-> 逐需求互证身份、主体、父和精确目标键
-> 零项返回不存在；多项返回多个当前同目标
-> 唯一项互证目标、来源 / 授权、生命周期和全部当前路径关系
-> 对路径组稳定性、唯一性、端点、角色、顺序、当前性、版本、G0和总预算做 checked 校验
-> 一次值式复制完整需求并返回唯一当前需求
```

DATA 请求拒绝 / 引用冲突映射请求拒绝；漂移、任一预算不足、许可和资源分别同名映射；运行态未实现 / 未装配、未知状态、坏 optional、错键、错父、重复需求、路径组截断 / 重复 / 混代 / 错端点及其它半结构映射内部不一致。`std::bad_alloc`、`std::length_error`映射资源失败，其它异常映射内部不一致。函数零写、零锁、零等待、零重试、零缓存和零截止重选。

## 6. 验证矩阵

1. 三类预算任一为零、请求坏或版本不匹配在 DATA 调用前拒绝；
2. 已读取空组 / 唯一组 / 多项组精确分账，多项不任选；
3. 路径差异不进入目标键；同父同目标但路径组不同仍返回同一需求，唯一项携带全部当前路径关系；
4. 父需求为空且路径组为空才成功；父需求为空但路径组非空为内部不一致；父需求非空时路径组至少一项，空组为内部不一致；两个及以上互异路径关系完整保留；上述内部不一致均零业务载荷、零事实截止；
5. 路径组按稳定键排序，重复、错端点、同关系多当前版本、未知角色 / 当前性、坏生命周期、混代、截断和 checked 累计溢出收敛内部不一致；
6. 来源、时间和场景仍不进入键；不同合同 / 注册身份但同语义键仍须同组；
7. 只有完整已读取零 / 一 / 多回显 G0，其它状态零事实截止、零业务载荷；
8. 源码静态证明恰一次 DATA 组读、零 DATA 写 / L1 / owner / 历史拼装 / 缓存 / retry；根工程双配置、生产外专项、diff、strict、UTF-8、工程唯一登记和清理后复验通过。

## 7. 激活与完成边界

本计划保持待激活，直到：最终需求清单登记本版中性组读的完整路径组与三类预算；DATA-EXT-12 最终 DTO / 状态 / ABI 正式发布并支持跨引用身份的同语义键组读；普通应用合法取得路径发布；`DEMAND-CURRENT-ROOT-GROUP-CONSUME`真实结果 / 退出 / 清理并释放 `服务.需求.ixx`；共享工程、代码段和构建资源释放。

激活前从最新 HEAD 机械匹配路径组强类型、基数、排序、预算、G0、服务构造和工程所有权。任何恢复单路径、改变精确复用键或路径多重性、把路径选择下沉 DATA、或改变结果 optional 的漂移，固定具名 `DRIFT-DEMAND-CURRENT-SAME-PARENT-TARGET-PATH-GROUP-OR-ABI`并退回计划支撑。

代码结果最多证明本只读定位叶。候选准入、来源授权、路径角色 / 防环、需求发布 / 合并、结算、任务树、T03和系统闭环保持 `NOT_RUN`。
