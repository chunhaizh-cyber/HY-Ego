# 识别本能方法实现详细设计

编号：视觉-本能方法-001

状态：待确认详细设计

------------------------------------------------------------------------

# 1. 定位

本设计作为第一个真实本能方法样板，用于验证：

    3300 方法根规范
    5310 本能方法自身环境
    5320 本能函数接口
    5230 任务执行桥

之间的完整闭环。

识别本能方法负责：

    对进入视野中的观察材料进行存在身份确认

不负责：

-   直接修改需求
-   创建任务
-   判断服务完成
-   直接结算
-   修改长期方法结构

------------------------------------------------------------------------

# 2. 方法定义

方法身份：

    识别

方法类型：

    本能方法

核心动作：

    确认当前观察目标对应的存在身份

方法用途：

    将未确认观察材料关联到已有存在

------------------------------------------------------------------------

# 3. 输入环境

识别本能方法执行环境：

    识别执行环境
    {
        方法身份

        方法虚拟存在

        当前实例方法

        当前视野

        观察材料

        候选存在集合

        匹配限制条件

        本轮运行虚拟存在
    }

------------------------------------------------------------------------

# 4. 输入材料

识别输入来自：

    外设观察材料
            ↓
    视觉中间层
            ↓
    候选存在材料

输入包括：

-   图像特征
-   深度特征
-   轮廓特征
-   空间位置
-   已知存在特征
-   当前场景约束

禁止：

直接读取显示信息、文本名称作为识别依据。

------------------------------------------------------------------------

# 5. 识别流程

流程：

    读取观察材料

    ↓

    生成候选存在集合

    ↓

    特征匹配

    ↓

    计算一致性

    ↓

    确认存在身份

    ↓

    生成识别结果场景

    ↓

    生成运行虚拟存在

------------------------------------------------------------------------

# 6. 特征匹配边界

识别依据：

    存在特征
    +
    当前观察特征
    +
    场景约束

禁止：

    名称匹配
    文本匹配
    显示标签匹配

------------------------------------------------------------------------

# 7. 输出结果

识别结果写入：

    输出结果场景

包含：

    识别状态

    目标存在身份

    匹配证据

    匹配特征

    置信材料

    时间信息

不直接：

    修改世界树
    修改存在身份
    完成需求

------------------------------------------------------------------------

# 8. 运行虚拟存在

每次识别必须生成：

    识别运行虚拟存在
    {
        输入观察材料

        候选集合

        匹配过程

        最终结果

        错误状态

        时间信息
    }

用于：

-   学习
-   复验
-   因果分析

------------------------------------------------------------------------

# 9. 失败处理

## 无候选

表示：

    当前观察无法关联已有存在

输出：

    识别失败事实

不直接创建新存在。

------------------------------------------------------------------------

## 多候选无法区分

输出：

    需要更多观察材料

进入：

-   跟踪
-   观察
-   学习

------------------------------------------------------------------------

## 特征不足

输出：

    观察材料缺口

由上层决定：

-   增加观察
-   补充外设信息
-   形成需求

------------------------------------------------------------------------

# 10. 与其他视觉本能方法关系

## 扫描

负责：

    发现已识别存在特征变化

------------------------------------------------------------------------

## 观察

负责：

    获取存在当前特征值

------------------------------------------------------------------------

## 跟踪

负责：

    持续维护同一存在变化

------------------------------------------------------------------------

## 识别

负责：

    建立观察材料与存在身份关系

------------------------------------------------------------------------

# 11. 学习接口

识别运行产生：

    运行事实

    ↓

    5330学习分析

    ↓

    学习候选

可学习：

-   特征匹配范围
-   新识别条件
-   误识别原因

不能：

直接修改识别方法。

------------------------------------------------------------------------

# 12. 禁止事项

禁止：

1.  使用名称识别存在。
2.  使用单一特征确认身份。
3.  识别方法直接创建世界存在。
4.  识别方法直接修改需求状态。
5.  识别方法直接完成任务。
6.  识别方法直接产生正式结算。
7.  单次识别结果直接形成长期能力。

------------------------------------------------------------------------

完整链路。
