# DATA-L2 语言结构增替退与当前历史读取服务详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-LANGUAGE-STRUCTURE-CRUD-SERVICE`

状态：设计就绪

## 1. 目标与完成边界

本设计在已经冻结的 `L2语言结构.数据.h` ABI 上建立唯一 `L2语言结构服务`，闭合语言节点、语言族归属、登记键关系和来源关系的同 owner 原子新增、不同新身份替换、退出、按语言身份当前 / 历史读取以及按登记键当前 / 历史读取。

本叶完成只证明语言结构服务可以经公开 DTO 执行语言半部 CRUD。它不装配普通应用，不实现词条、语言记录、概念名称、默认汉语身份、语素或词性，也不完成 `DATA-EXT-10`。

## 2. 正式依据与当前事实

- 0050 把语言列为 `DATA-L2` 强类型结构，要求唯一写入服务、强类型请求、同一事实截止、结构化非成功和不可变完整投影。
- 1100 规定语言身份不能由字符串、区域设置、界面语言或解析标签冒充，默认汉语只在正式语言身份已经建立后由 `DATA` 外业务选择。
- 2200 和 4240 规定语言与词条可以后继共处一个 `L2语言结构服务`，但每一结构族必须静态路由到自己的唯一 owner；当前叶只建立语言 owner。
- 4240 固定 `L2语言结构服务 -> 不可变材料服务只读 + L1事实基座`，登记键材料必须是严格 UTF-8，不可变材料服务不解释语言学正确性。
- `CONCEPT-SPACE-STRUCTURE-CRUD-REBUILD-M1 v0.3` 已发布不可变材料写入、当前 / 历史读取和退出服务；其实现内部保存 `const L1事实基座服务&`，但当前没有给语言服务使用的同实例证明入口。
- `DATA-L2-LANGUAGE-PUBLIC-DTO v0.1` 已冻结语言请求、结果和值式 helper，当前仍等待代码结果；本计划不能越过该结果施工。
- 当前不存在 `服务.L2语言结构.ixx`、`L2语言所有者交付` 或语言 CRUD 公开函数。普通应用上下文也没有不可变材料服务、语言服务或语言聚合 getter。

## 3. 唯一所有权与物理位置

### 3.1 模块和公开实体

新建模块：

```cpp
export module 海中鱼巣.领域.服务.L2语言结构;
```

物理文件：`海中鱼巣/领域/服务.L2语言结构.ixx`。

模块公开：

```cpp
inline constexpr L1所有者范围建立幂等身份 语言所有者建立身份{
    0x4C32'4C41'4E47'0001ULL};

class L2语言所有者交付 final;

std::optional<L2语言所有者交付> 尝试形成L2语言所有者交付(
    const L1事实基座服务&, L1所有者范围交付&&) noexcept;

class L2语言结构服务 final;
```

`L2语言所有者交付`沿用现行方法 / 概念服务的不可复制、单次移动交付形态，只能由 `尝试形成L2语言所有者交付(...)` 验证独占结构 owner 后形成。外部不能取得其写端口。

### 3.2 owner 范围和登记

语言 owner 使用节点族编号 8 对应的固定私有键空间 `0x0208'....`。服务构造时以一份 owner 登记写集建立：

| 私有事实 | 本地键 | 形态 |
| --- | --- | --- |
| 语言族锚点 | `0x0208'6001` | 普通节点，永久活动 |
| 语言族归属关系类型 | `0x0208'6002` | 关系类型，永久活动 |
| 语言登记键关系类型 | `0x0208'6101` | 关系类型，永久活动 |
| 语言来源关系类型 | `0x0208'6102` | 关系类型，永久活动 |

登记写入幂等身份固定为 `0x4C32'4944'5352'4308`。四个登记事实必须同 owner、同创建代次、互异且当前活动。任一登记复义、缺项、错 owner、错节点种类或混代令构造失败。

语言实例固定使用本地键：

```text
语言节点                 0x0208'1001
语言族归属关系           0x0208'1002
语言登记键关系           0x0208'1003
语言来源关系             0x0208'1004
```

关系方向固定为：

```text
语言族锚点 -> 语言节点           // 语言族归属关系类型
语言节点 -> 登记键材料节点       // 语言登记键关系类型
语言节点 -> 来源材料节点         // 语言来源关系类型
```

登记键材料和来源材料可以是同一不可变材料身份，但两条关系编码和关系类型必须不同。材料节点仍由不可变材料 owner 拥有，语言 owner 只拥有指向材料的关系。

### 3.3 同一 L1 实例门禁

`不可变材料服务`增加最小中性构造校验面：

```cpp
bool 使用同一L1事实基座实例(
    const L1事实基座服务&) const noexcept;
```

该函数只比较服务内部保存的 `L1事实基座服务` 实例地址，不导出 L1、owner、锁、仓库或事实，不成为 BIZ 数据查询入口。它是材料服务对自身构造绑定的通用中性谓词，不引用 `L2语言结构服务`，因此依赖方向仍是语言模块单向 import 材料模块。语言服务构造必须验证材料服务与构造参数中的 L1 为同一实例；不一致直接抛出构造异常。

这一私有门禁是共享事实截止的机械保证。不能用相同数值的事实代次推断两个 L1 实例相同，也不能把检查下放给调用方约定。

## 4. 服务构造与公开 ABI

唯一完整构造：

```cpp
explicit L2语言结构服务(
    const L1事实基座服务& 第一层服务,
    const 不可变材料服务& 材料服务,
    L2语言所有者交付&& 语言所有者交付);
```

服务不可默认构造、复制或移动。构造顺序固定为：

```text
验证并移动语言 owner 交付
-> 验证材料服务使用同一 L1 实例
-> 建立或精确重复语言私有登记
-> 从 L1 正式读回四项登记
-> 完成构造
```

新模块的依赖形态固定为：

```cpp
export import 海中鱼巣.领域.合同.L2结构公共;
import 海中鱼巣.核心.服务.L1事实基座;
import 海中鱼巣.领域.服务.不可变材料;

export {
#include "L2语言结构.数据.h"
}
```

`L2语言结构.数据.h` 继续是 DTO 唯一实体所有者；服务模块只导出 owner 交付和服务函数。根工程把新文件按现有领域服务模块形态唯一登记为 C++ 模块编译项，filters 使用现有领域模块筛选器。

公开函数固定为：

```cpp
L2语言新增结果 新增语言(const L2语言新增请求&);
L2语言替换结果 替换语言(const L2语言替换请求&);
L2语言退出结果 退出语言(const L2语言退出请求&);
L2语言读取结果 读取语言(const L2语言读取请求&) const;
L2语言按登记键读取结果 按登记键读取语言(
    const L2语言按登记键读取请求&) const;
```

函数名和变量名保持中文。服务不提供通用 owner 选择、裸编码 CRUD、字符串兼容入口、索引对象、缓存对象或材料写入入口。

## 5. 共同读回核心

### 5.1 截止选择

两类读取都先验证 DTO helper。当前读取使用请求头中的非零期望事实代次 `G`；历史读取使用非零 `H=历史截止事实代次`，同时把请求头中的非零期望代次作为调用时当前守卫 `G`。

服务固定执行：

```text
读取 L1 当前事实代次，必须等于 G
-> 在语言 owner 的正式当前 / 历史投影中读取语言结构
-> 以相同 G 守卫，通过不可变材料服务读取登记键和来源材料
   当前读使用截止 G；历史读使用截止 H
-> 再读 L1 当前事实代次，必须仍等于 G
-> 形成截止为 G 或 H 的完整值式结果
```

任一步观察到当前事实代次变化都返回 `事实代次漂移`，无语言载荷、无变更代次。不得用前后两个不同截止拼接结果。

### 5.2 语言结构重建

按身份当前读取使用 L1 owner 一致当前读取，以语言节点为目标读取唯一族归属关系，并以语言节点为源读取登记键和来源关系组；历史读取使用现有 `读取所有者范围历史事实(...)` 与 `读取所有者范围历史关系组(...)` 在 H 上取得同样结构。两者都必须唯一找到：语言节点、从语言族锚点指向该节点的一条族归属关系、从该节点指向登记键材料的一条登记键关系、从该节点指向来源材料的一条来源关系。

按登记键读取先正式读回请求登记键材料，再以该材料节点为目标端点、以语言登记键关系类型为关系类型执行精确关系组读取：当前入口使用 L1 owner 一致当前目标关系组，历史入口使用 `读取所有者范围历史关系组(...)` 的目标方向与 H。返回关系必须全部由语言 owner 写入、使用固定关系类型并指向请求材料；其源语言在对应截止未退出的候选必须恰为零或一。两个当前语言命中同一登记键，或关系组混入错 owner / 错类型 / 错端点事实，属于 `内部不一致`，不得过滤后任选一个。

身份来源由语言节点、族锚点、族归属关系及登记创建截止重建。公开 `L2语言事实::生命周期` 必须与节点、族归属、登记键和来源关系的生命周期逐字段一致。材料事实身份必须精确等于关系目标；登记键材料格式角色必须为 `严格UTF8`，格式身份必须等于同截止材料登记读回的严格 UTF-8 格式身份。来源材料只要求是不可变材料服务支持且完整的正式材料。

### 5.3 未找到与已退出

- 按身份当前读取未知编码返回 `未找到`；命中已退出语言返回 `已退出`。
- 按身份历史读取在 H 之前尚未创建返回 `未找到`；在 H 上可以完整回显已经退出的语言。
- 按登记键当前 / 历史读取在对应截止没有当前语言返回 `未找到`；不得返回 `已退出` 或任选该键的一个旧身份。
- 当前成功必须回显未退出语言；按登记键历史成功也必须回显在 H 上未退出的语言。

材料未找到、已退出、事实代次漂移或资源失败按材料服务状态机械保持。关系宣称引用材料但同截止材料不存在、身份不符或格式登记矛盾属于 `内部不一致`。

## 6. 新增事务

`新增语言(...)`固定流程：

```text
DTO helper 与保留幂等身份检查
-> 取得语言写锁
-> 按映射后的 owner 幂等身份读取 L1 首次规范化写集
-> 若已有首次材料，按原写集与原截止重建并比较完整新增请求
   同义直接返回首次结果，异义返回幂等冲突
-> 以请求 G 读取登记键和来源材料
-> 按登记键读取当前语言
-> 形成四事实 owner 写集
-> 以 G 提交一次 L1 owner 中性写集
-> 在提交截止 W 正式读回新语言和两份材料
-> 返回已提交或精确重复
```

首次提交建立不同的新稳定编码：语言节点、族归属关系、登记键关系和来源关系。新语言创建代次等于 `W`，`W > G`。

同幂等身份同完整请求精确重复必须从 L1 首次规范化写集、首次写入结果和原编码映射重建原结果，回显原 `W`，不得再次推进代次。即使该语言在后继事务中已经替换或退出，精确重放仍返回首次新增在原 W 上的完整成功结果，不能按调用时当前状态降级为新建、未找到或引用冲突。另一个幂等身份已经占用同一登记键返回 `引用冲突`，不能冒充精确重复。

## 7. 替换事务

`替换语言(...)`不是原地改义。固定流程为：

```text
DTO helper 与保留幂等身份检查
-> 取得语言写锁
-> 按映射后的 owner 幂等身份读取 L1 首次规范化写集
-> 若已有首次材料，按原退出 / 新建写集和原截止重建并比较完整替换请求
   同义直接返回首次结果，异义返回幂等冲突
-> 在 G 上按旧身份读取完整旧语言
-> 逐字段核对旧登记键和旧来源材料
-> 在 G 上读回新登记键和新来源材料
-> 检查新登记键当前唯一性（允许仍由本次旧语言占用）
-> 一份 owner 写集退出旧四事实并建立新四事实
-> 在 W 上同时正式读回旧退出语言和新当前语言
-> 返回已提交或精确重复
```

新语言身份与四个新事实编码必须不同于旧编码。旧节点、旧族归属、旧登记键和旧来源关系的退出代次，以及新四事实的创建代次，都必须等于同一 `W`。提交截止上同一登记键最多一个当前语言。

旧请求材料与正式旧事实不符、或新登记键被另一个当前语言占用，返回 `引用冲突`。同幂等身份异义返回 `幂等冲突`。精确重复从首次写集退出编码、新编码映射和原 W 历史投影回显首次替换的同一新旧身份与原 `W`，不受新语言后继替换或退出影响。

## 8. 退出事务

`退出语言(...)`固定流程：

```text
DTO helper 与保留幂等身份检查
-> 取得语言写锁
-> 按映射后的 owner 幂等身份读取 L1 首次规范化写集
-> 若已有首次材料，按原退出写集和原截止重建并比较完整退出请求
   同义直接返回首次结果，异义返回幂等冲突
-> 在 G 上按身份读取完整当前语言
-> 逐字段核对登记键和来源材料
-> 一份 owner 写集退出语言节点及三条关系
-> 由 L1 全局引用保护拒绝任何当前跨 owner 入边
-> 在 W 上历史读回完整退出语言
-> 返回已提交或精确重复
```

当前词条、语言记录或其它已登记持久结构仍引用语言时，L1 必须返回 `引用冲突`；语言服务不得级联退出引用方。退出不删除登记键材料、来源材料或历史语言事实。

写成功要求 `W > G` 且变更事实代次等于 W。精确重复从首次退出写集和原 W 历史投影回显首次退出结果，不受后继事实变化影响，也不再次推进代次。

三个入口把公开 `L2结构幂等身份` 的数值一对一映射为语言 owner 的 `L1所有者范围写入幂等身份`。与语言私有登记写入幂等身份冲突的公开请求在写前返回 `入口拒绝`。首次材料的规范化写集必须精确回显原 `期望事实代次`、操作对应的新建 / 退出形状、关系类型和材料端点；任何缺项、多项、错本地键、错 owner、错首次结果或无法唯一判定操作类别均为 `内部不一致`。

## 9. 状态、异常与发布未知

共同状态映射沿用 `L2结构状态`，不新增枚举：

| 条件 | 状态 |
| --- | --- |
| 坏合同、零守卫、零幂等、坏身份 / 材料、读类别冲突、替换前后完全同义 | `入口拒绝` |
| G 与调用时当前代次不同或读链期间代次变化 | `事实代次漂移` |
| 目标身份或登记键在指定截止不存在 | `未找到` |
| 当前按身份读命中退出语言 | `已退出` |
| 同幂等身份异义 | `幂等冲突` |
| 登记键被异请求占用、旧事实材料不匹配、退出仍被引用 | `引用冲突` |
| L1 或材料服务明确资源失败、发布结果未知 | `资源失败` |
| 身份复义、双当前键、关系混代、错 owner、坏材料回显、发布后读回矛盾 | `内部不一致` |

发布结果未知统一对外为 `资源失败`，但服务必须保留 L1 首次写入可收敛材料；调用方只能原幂等身份、原 G 和原完整请求重放。异常边界只把分配 / 长度失败映射为资源失败，其它异常映射为内部不一致，均不得泄漏半载荷。

## 10. 并发、锁与生命周期

- 服务只有一把语言写锁，串行化语言新增、替换和退出的预读—提交—读回链。
- 读取不取得语言写锁，只使用 L1 正式读取和前后同代守卫。
- 锁只保护进程内服务编排；事实线性化点仍是 L1 原子发布。
- 服务借入 `const L1事实基座服务&` 和 `const 不可变材料服务&`，二者必须比语言服务寿命长；语言服务独占持有语言 owner 写端口。
- 不建立进程内登记键权威索引。按键读取直接复用 L1 的精确目标端点关系组读取；后继可以建立确定重建缓存，但命中后仍须按同一事实截止回读，本叶不实现。
