# 自我当前根需求组消费详细设计 v0.1

日期：2026-08-15

计划身份：`DEMAND-CURRENT-ROOT-GROUP-CONSUME`

## 1. 目标与完成边界

实现单一业务叶：

```text
BIZ-L4-002-02-03-01 v0.2
需求业务服务::读取自我当前根需求组
-> DATA-EXT-12 按自我和非零共享截止有界读取完整当前根需求结构组
```

调用方给出唯一自我、运行代次、事实范围版本和父级共享事实截止 `G0`。本叶一次调用 DATA-EXT-12，逐字段复核完整根需求结构事实后返回调用方拥有的不可变值式组。根需求组为空是合法成功。

本叶全程只读，不建立、修改、退出或重判需求，不读取当前目标事实，不判断满足，不形成活动路径、任务树、权限、结算或主需求。完成最多证明这个具名 BIZ provider 真实消费 DATA-EXT-12；不证明 BIZ-L3-002-02-03、父级 G0/G1、自我治理一致事实或需求—任务业务闭环完成。

## 3. 基础数据公开消费合同

### 3.1 唯一 DATA 操作

DATA-EXT-12 必须提供具名操作：

| 操作 | 请求 | 成功返回 | 合法空与失败 |
| --- | --- | --- | --- |
| 按自我和指定截止有界读取当前根需求组 | 合同版本、唯一自我 `L2存在身份`、非零 `G0`、事实范围版本、需求范围版本、读取规则版本、非零最大根数量 | 稳定身份严格排序的完整当前根需求结构组、三个版本回显、结果截止 `G0`、零变更代次 | 空组为已读取成功；超预算零组拒绝；许可拒绝、漂移、资源失败和内部不一致分别返回；正式接线后不存在运行态“未实现/未装配”成功降级 |

每项完整结构事实至少必须携带：

```text
L2需求身份及身份来源
需求主体且等于请求自我
唯一目标宿主强类型身份
唯一目标特征强类型身份
唯一 `L2目标状态合同身份`（预冻结名，待 DATA 结果机械匹配）
当前父需求 optional；根项必须为空，且该空值是 G0 下完整枚举的权威结果
完整需求来源证据值式组和当前授权事实值式组
需求生命周期和结构当前性
目标、父关系、来源授权和生命周期各自的结构版本
单项事实截止 G0
```

“至少”表示 DATA 可以为自己的完整需求结构增加其它来源明细、路径引用或治理材料，但上述是本 BIZ 叶成功必需字段；它不授权 DATA 判断目标是否满足、需求是否合理、当前是否主需求或能否任务化。

### 3.2 目标状态合同身份门禁

本设计冻结以下唯一语义：目标状态合同是独立、非零、强类型、可由正式 provider 读回的身份引用；现行 DATA 设计预冻结名为 `L2目标状态合同身份`，provider 为唯一 `L2状态结构服务::读取完整目标状态合同(...) const`。它不能是：

- `L2状态身份`实例状态；
- 目标值、I64、枚举底值或字符串；
- 特征定义身份的别名；
- 需求 owner 内部临时编码、缓存键或请求字段副本。

provider 归属和预冻结 C++ 名已由 DATA 设计裁决，但仍须等待真实代码结果机械确认 ABI。本叶只透明保存并回显该强类型引用，不读取合同正文，也不比较目标；若 DATA 实现改变身份归属或允许与实例状态互换，属于真实设计漂移。

### 3.3 范围与规则版本绑定

`事实范围版本`、`需求范围版本`和`读取规则版本`不是调用方自报标签。普通应用构造 `需求业务服务` 时必须一次注入同一运行上下文的固定配置；每次 BIZ 请求都要与该固定配置逐字段相等。DATA-EXT-12 请求必须原样携带这三个版本，成功结果也必须逐字段回显。`运行代次`只绑定 BIZ 服务固定配置和调用批次，不成为 DATA 事实截止；DATA 当前性仍只由非零 `G0`守卫。

### 3.4 截止、预算与失败守恒

- 请求必须使用父级给出的非零 `G0`，不得请求“最新”或使用 owner 子截止。
- DATA-EXT-12 必须与参加同一自我治理读取的其它 DATA 服务来自普通应用同一个 `L1事实基座运行包`；相同数值但不同 L1 实例不是同一截止。
- 成功结果头必须为已读取、截止恰等于 `G0`、变更事实代次为空；其它形状整体失败。
- 数量超过预算必须在 DATA 层返回数量预算不足且零事实组；不得截断。
- BIZ 不在多次调用之间拼装组，不因漂移只重读部分，不缓存补缺。

## 4. BIZ 类型与物理位置

### 4.1 值式合同头

新增：

```text
文件：海中鱼巣/领域/需求当前根组.数据.h
所有者：BIZ 需求当前根组值式合同
可见性：只由需求业务服务、运行期只读查询组合器和专属验证消费
```

冻结语义类型：

```cpp
inline constexpr std::uint32_t 需求当前根组合同版本 = 1;

struct 需求当前根组固定配置 final {
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 需求范围版本;
    std::uint64_t 读取规则版本;
};

struct 自我根需求组读取请求 final {
    std::uint32_t 合同版本;
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    L2存在身份 唯一自我;
    std::uint64_t 共享事实截止;
    std::uint64_t 需求范围版本;
    std::uint64_t 读取规则版本;
    std::uint64_t 最大根数量;
};

struct 根需求值式事实 final {
    L2需求身份 需求;
    L2节点族身份来源事实 身份来源;
    L2存在身份 主体;
    目标宿主强类型身份 目标宿主;
    目标特征强类型身份 目标特征;
    L2目标状态合同身份 目标状态合同;
    std::optional<L2需求身份> 当前父需求;
    需求来源证据值式组 来源证据;
    需求授权事实值式组 当前授权事实;
    需求结构生命周期 结构生命周期;
    std::uint64_t 目标结构版本;
    std::uint64_t 父关系版本;
    std::uint64_t 来源授权版本;
    std::uint64_t 生命周期版本;
    std::uint64_t 事实截止;
};

enum class 自我根需求组读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    当前性漂移 = 3,
    提供者拒绝 = 4,
    数量预算不足 = 5,
    资源失败 = 6,
    内部不一致 = 7
};

struct 自我根需求组读取结果 final {
    std::uint32_t 合同版本;
    自我根需求组读取状态 状态;
    自我根需求组读取请求 请求回显;
    std::uint64_t 事实截止;
    std::optional<std::vector<根需求值式事实>> 根需求组;
};
```

其中目标宿主 / 目标特征身份、`L2目标状态合同身份`、`需求结构生命周期`、来源证据组和授权事实组必须在 DATA-EXT-12 与目标状态合同最终 ABI 发布后机械匹配或由正式 DATA DTO 逐字段复制；执行者不得自行选用裸稳定编码、现有实例状态类型或自造来源 / 授权布尔值。只有 `已读取`携带 optional；空组表示 optional 有值且 vector 为空。

### 4.2 需求业务服务

新增：

```text
文件：海中鱼巣/领域/服务.需求.ixx
模块：海中鱼巣.领域.服务.需求
所有者：DATA 之外的需求读取业务解释
```

最终形态：

```cpp
class 需求业务服务 final {
public:
    需求业务服务(
        const 需求结构服务& 数据服务,
        const 需求当前根组固定配置& 固定配置) noexcept;

    自我根需求组读取结果 读取自我当前根需求组(
        const 自我根需求组读取请求& 请求) const noexcept;
};
```

`需求结构服务`是 DATA-EXT-12 最终公开类型的语义名。服务只保存一个稳定 const 借用和一份不可变固定配置，不可复制、不可移动；构造零读取、零缓存、零 owner / L1 / 仓库持有。固定配置若含零运行代次或零版本，所有读取都在 DATA 调用前返回内部不一致；调用请求自身坏合同 / 零字段 / 零预算返回请求拒绝；字段本身合法但运行 / 范围 / 规则版本与有效固定配置不等返回当前性漂移。普通应用后继唯一拥有 DATA 服务和 BIZ 服务并保证借用生命周期；固定配置来自同一普通应用运行上下文，不由单次调用临时生成。

## 5. 固定读取和互证顺序

```text
校验服务固定配置完整，否则内部不一致
-> 校验 BIZ 请求自身全部字段，否则请求拒绝
-> 逐字段匹配服务固定配置，否则当前性漂移
-> 一次调用 DATA-EXT-12 按自我、G0、事实范围/需求范围/读取规则版本、最大根数量读取当前根需求组
-> 映射 DATA 结构化非成功
-> 互证结果合同、已读取、三个版本回显、截止=G0、零变更和预算
-> 按 DATA 稳定顺序逐项验证身份来源、主体、单目标三引用、当前父 optional 为空、来源证据、当前授权、生命周期、各结构版本和单项截止
-> 互证需求身份严格递增且无重复
-> 一次形成完整候选组
-> 无抛出交换到结果 optional
-> 返回已读取；空候选组仍成功
```

不允许 DATA 先返回主体候选、BIZ 再逐项跨调用读需求 / 父关系；该旧形态会放大漂移窗口并复制 DATA-EXT-12 的完整结构读取职责。

## 6. 非成功映射与异常

| DATA / BIZ 情形 | BIZ 状态 | 载荷 |
| --- | --- | --- |
| 服务固定配置含零运行代次或零范围 / 规则版本 | 内部不一致 | 空；零 DATA 调用 |
| BIZ 请求自身坏合同、零字段或零预算 | 请求拒绝 | 空；零 DATA 调用 |
| BIZ 请求字段均合法，但运行 / 范围 / 规则版本与有效固定配置不等 | 当前性漂移 | 空；零 DATA 调用 |
| DATA 已读取且空组 | 已读取 | 有值空 vector |
| DATA 事实代次漂移或结果截止不等于 G0 | 当前性漂移 | 空 |
| DATA 明确许可拒绝 | 提供者拒绝 | 空 |
| BIZ 前检通过后 DATA 仍返回请求拒绝；组操作返回单项未找到/已退出；运行态未实现/未装配；其它不属于该组操作的状态 | 内部不一致 | 空 |
| DATA 数量预算不足 | 数量预算不足 | 空 |
| DATA 资源失败、`std::bad_alloc`、`std::length_error` | 资源失败 | 空 |
| DATA 坏成功形状、重复身份、错主体、有父项、坏目标引用、错生命周期、未知异常 | 内部不一致 | 空 |

任何非成功都回显输入合同版本和分类所需最小诊断，不携带部分根组、事实截止或可消费目标引用。

## 8. 验证矩阵与完成声明

专项至少覆盖：

- 固定配置零运行代次或零范围/规则版本映射内部不一致；请求坏版本、零字段、零自我、零 G0、零预算映射请求拒绝；合法请求与固定配置版本不等映射当前性漂移；三类均零 DATA 调用；
- 空组合法成功；单根、多根、恰好预算、超预算；
- 请求运行/范围/规则版本与固定配置逐字段匹配，事实范围/需求范围/读取规则版本原样进入 DATA 请求并由成功结果回显；
- G0 原样传递且结果截止必须等于 G0；
- 根身份稳定严格排序、重复、坏身份来源、错主体、有当前父关系、已退出 / 错当前生命周期；
- 目标宿主、目标特征、目标状态合同任一缺失或错类型；
- 来源证据、当前授权、目标/父关系/来源授权/生命周期版本和单项 G0 任一缺失或矛盾；
- 每类 DATA 非成功独立映射，坏成功形状收敛内部不一致；
- 并发发布只产生完整 G0 成功或漂移，零混代拼装；
- 源码零 L1、owner、仓库、DATA 写、目标比较、任务/权限/结算、缓存和日志裁决；
- 根工程 Debug / Release、专项双配置、UTF-8/XML、模块和工程唯一登记、生产零专项痕迹。

本设计发布不证明 DATA-EXT-12、`DATA-L2-ABSTRACT-TARGET-STATE-CONTRACT-CRUD` 或 BIZ 代码已经实现；未来本计划结果也只证明当前根需求组读取 provider，不证明需求活动性、目标满足、任务树或系统业务闭环。
