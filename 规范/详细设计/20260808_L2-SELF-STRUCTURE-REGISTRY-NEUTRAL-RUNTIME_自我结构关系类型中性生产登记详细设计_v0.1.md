# 自我结构关系类型中性生产登记详细设计 v0.1

日期：2026-08-08

状态：设计就绪；只冻结后续实施合同，不证明代码、生产运行、完整自我或第一层完善。

## 1. 目标与最早缺口

7130 要求完整自我使用关系 21 表达自我内部世界和出生期成员。当前第一层的每条关系事实都必须引用一个已发布的关系类型节点；现有世界登记只提供直接父场景和直接成员两类关系类型，状态、动态、特征和实例特征也各自拥有独立生产登记，但当前没有自我结构关系类型的现行中性登记。

完整自我的五项身份、五条固定关系及出生期成员必须同一事务发布，因此不能先建立普通子场景或任一完整自我关系。本叶只发布后继完整自我事务必需的领域基础登记：

```text
自我结构领域服务身份普通节点
+ 自我结构关系类型普通节点
-> 一次 L1 中性写集
-> 同一领域服务正式当前读回
-> 纳入生产运行期候选完整性
```

登记不创建自我、场景、存在、关系、值或属性槽，不会暴露半个完整自我，也不是为了补第一层覆盖矩阵制造的请求。

## 2. 正式依据与当前事实

- 4015：第一层只承担业务中性 CRUD、原子提交、最小幂等和正式读取；其能力只由第二至第五层真实服务使用自然证明。
- 4030：领域身份、关系类型、准入和结果解释归具名领域服务；第一层不得解释自我语义。
- 4040：本次两个节点必须以一个完整不可变中性写集提交，同键同义逐字段重复、同键异义冲突。
- 7130：关系 21 是完整自我内部世界与成员结构的唯一专用关系类型；完整自我本体必须后续同事务发布。
- ACCEPTANCE-01：生产目标不携带自检、验收运行器或覆盖补格；日志只供人观察。

当前代码事实：

1. `L1事实基座服务` 已提供中性写集提交、按稳定编码读取节点及一致当前投影。
2. 世界、实际存在、状态、动态、特征定义和实例特征登记均采用“领域 DTO + 具名服务 + 中性写集 + 正式读回 + 运行期上下文唯一拥有”的模式。
3. 生产启动在系统角色初始化前已经完成上述登记；系统角色初始化仍走旧数据路径。
4. 当前没有 `L1自我结构登记服务`、自我结构关系类型节点或等价生产登记。
5. 旧 P53—P55 依赖已退出的业务标签、意图组、执行证据、附属参与者和专项自检，不能恢复或局部拼接。

## 4. 数据合同

合同版本与规则版本均为 1。私有中性幂等域固定为 `0x1B`，与当前代码和计划索引中的既有领域不重叠。

```cpp
struct 自我结构登记操作幂等身份 final {
    std::uint64_t 值 = 0;
};

struct 自我结构关系登记 final {
    std::uint32_t 合同版本 = L1自我结构登记合同版本;
    std::uint32_t 规则版本 = L1自我结构登记规则版本;
    自我结构登记操作幂等身份 首次幂等身份;
    std::uint64_t 事实截止代次 = 0;
    稳定编码 服务身份;
    稳定编码 自我结构关系类型;
};

struct 自我结构登记请求 final {
    std::uint32_t 合同版本 = L1自我结构登记合同版本;
    std::uint32_t 规则版本 = L1自我结构登记规则版本;
    自我结构登记操作幂等身份 幂等身份;
    std::uint64_t 期望事实代次 = 0;
};

struct 自我结构登记结果 final {
    自我结构登记状态 状态 = 自我结构登记状态::入口拒绝;
    std::optional<自我结构关系登记> 登记;
    bool 成功() const noexcept;
};
```

状态至少分账：`已提交`、`幂等读回`、`已读取`、`登记未加载`、`入口拒绝`、`幂等冲突`、`事实代次漂移`、`许可拒绝`、`资源失败`、`内部不一致`。成功只接受前三类且携带完整登记；不同入口不得用默认成功合并状态。

幂等身份值必须非零且只占低 56 位。映射规则固定为：

```text
(0x1B << 56) | 幂等身份.值
```

## 5. 建立登记

公开入口：

```cpp
自我结构登记结果 建立登记(const 自我结构登记请求& 请求);
```

唯一流程：

1. 校验合同、规则、幂等身份和期望事实代次；失败零写。
2. 形成中性写集：本地键 1 为领域服务身份普通节点，本地键 2 为自我结构关系类型普通节点；关系、值、属性槽和退出项全部为空。
3. 以 `0x1B` 私有域形成不透明中性幂等键，恰一次调用 `L1事实基座服务::提交中性写集`。
4. 只接受成功或精确重复；其它中性状态逐类映射并原样停止。
5. 互证新编码映射恰有本地键 1、2，编码互异且均为普通当前节点。
6. 以写入结果事实代次调用第一层一致当前投影，精确读取两个节点；不得调用完整快照、审计、恢复或 legacy 入口。
7. 两节点逐字段一致后形成登记并在服务局部锁内发布定位；已有定位必须逐字段相同，否则内部不一致。
8. 返回已提交或幂等读回及完整登记。

第一层只看到两个普通节点和不透明幂等键，不接收“自我”“关系 21”或其它业务标签。

## 6. 当前读取

公开入口：

```cpp
自我结构登记结果 读取当前登记() const;
```

规则：

- 局部锁内深复制登记定位，未加载返回 `登记未加载`；
- 锁外以定位中的两个稳定编码和截止代次调用一致当前投影；
- 两节点必须均为当前普通节点、编码互异，首次幂等身份与私有键映射一致；
- 成功时以本次读取事实代次更新返回值中的截止代次，不改写第一层；
- 许可拒绝、事实代次漂移、资源失败和内部不一致结构化返回，不退回缓存副本。

不得使用日志、内存定位存在或初始化返回值代替正式读回。

## 7. 生产运行期接线

固定生产配置增加：

```cpp
自我结构登记操作幂等身份 自我结构登记幂等身份{1};
```

运行期上下文在实例特征服务之后构造唯一 `L1自我结构登记服务`，新增初始化、当前读取、完整判断及 const / 非 const 服务访问器。生产启动在实例特征登记成功后、旧系统角色初始化之前，以当前截止形成请求并恰一次建立登记。

非成功立即返回具名 `自我结构登记初始化错误`，不继续系统角色、概念活动或候选发布。候选 `完整()` 必须经同一服务重新读取登记，要求已读取、登记完整，并与世界、场景、实际存在、状态、动态、特征定义和实例特征登记处于同一当前截止。

启动结构化结果增加自我结构登记状态。首次成功、已有上下文及各失败阶段只回显真实已执行状态；未执行阶段保持入口拒绝。

## 8. 失败、事务与边界

- 两节点只由一次中性事务原子发布；不存在领域附属参与者或第二投影提交。
- 同键同写集返回原结果；同键异写集冲突；事实代次漂移不局部改写请求重试。
- 服务定位只用于下一次正式读回，不取得独立权威。
- 候选上下文失败时不发布运行期上下文；不新增补偿、跨进程恢复或持久证据。
- 当前阶段不考虑崩溃、重启、断电和跨进程恢复。

明确排除：完整自我五身份五关系、场景或存在创建、出生期成员、安全 / 服务根、实例槽、根值、根需求、概念根、方法根、旧系统角色迁移、第一层新接口、业务标签、意图、执行证据、专项自检、独立 L1 验收和第二可执行目标。
