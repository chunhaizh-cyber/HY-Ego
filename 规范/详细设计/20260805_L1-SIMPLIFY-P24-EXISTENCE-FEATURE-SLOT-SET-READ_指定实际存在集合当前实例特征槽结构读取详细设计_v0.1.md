## 1. 目标与边界

本叶是 SELF-GOV-CLOSURE STEP-4 在 P23 之后的下一最早提供者。它原位扩展唯一 `L1实例特征服务`，以一个无对象状态的公开静态纯函数，消费：

1. P21 成功形成的指定世界根完整当前实际存在资格集合；
2. P23 冻结的实例特征登记定位请求；
3. 调用方已通过 P17 一次非阻塞读取取得的同一份 `L1完整快照`。

函数先在该快照上复用 P23 `从快照读取登记定位`，再由实例特征事实所有者解释宿主槽关系与定义模板关系，确定性形成范围内全部实际存在的当前实例特征槽结构组。结果包含每个输入实际存在，即使它当前没有任何实例槽；成功事实完整、同截止且稳定有序。

本叶只读取结构：实际存在、实例槽、定义端点、宿主关系和定义关系。它不读取或解释当前值、属性槽、材料、来源、值域、比较、状态、动态、历史、审计或恢复装配。

## 5. 固定读取流程

### 5.1 外层请求和空范围

先校验外层合同、规则、读取规则，以及 P21 主体范围：

- P21 合同 / 规则 / 读取 / 排序版本匹配，`完整=true`、世界根有效、事实截止非零；
- 主体组按存在稳定编码严格升序、无重复，每项节点和资格见证完整，输入成员关系见证非零；
- P24 只机械验证 P21 载荷形状，不重新解释实际存在资格、当前归属或场景关系。

请求版本、P21 非完整载荷或空世界根为入口拒绝；声称完整但排序、唯一性或见证矛盾为内部不一致和稳定诊断。

若 P21 主体组合法为空，直接返回 `已读取`：世界根和截止复制自 P21，`主体槽组` 为空、`完整=true`、诊断为空。该分支不需要登记定位见证，也不调用 P23；空范围没有可被遗漏的实例槽。嵌套登记定位的三个版本字段仍必须匹配，禁止用未知合同伪装空成功。

### 5.2 同一快照定位与代次校准

非空主体范围固定执行：

```text
从快照读取登记定位(请求.登记定位, 快照)
-> 只接受已读取且完整定位事实
-> 校准 P21截止 == P23截止 == P17快照代次 != 0
-> 在同一快照内读取全部槽结构
```

P23 的 `登记未加载、未找到、入口拒绝、事实代次漂移、资源失败、内部不一致` 分别保持同名状态；内部不一致诊断映射为 `登记定位损坏`。P23 坏成功为内部不一致。代次不等返回事实代次漂移、空事实和空诊断，不重取快照。

P17 在调用 P24 前若返回许可拒绝、资源失败或内部不一致，调用方必须立即原样映射，P23/P24 调用次数均为0；本函数自身不产生许可拒绝。

### 5.3 快照基础完整性

本函数只使用当前节点和当前关系组，但必须机械验证：

- 快照代次非零；当前节点、当前关系分别按稳定编码严格升序且无重复；
- 所用节点和关系编码有效，创建代次非零且不大于快照代次，退出代次为空；
- 所用关系类型、源端和目标端均能在当前节点组唯一命中；
- P23 的两个关系类型节点在本快照中仍为当前普通节点；
- 每个 P21 主体在快照中唯一命中当前普通节点，并与 P21 节点见证编码、类型一致。

快照基础形状、同代次 P21/P23 见证与当前快照矛盾属于内部不一致，不降级未找到。

### 5.4 宿主槽候选与跨宿主校验

只把同时满足下列条件的当前关系作为范围内宿主槽候选：

```text
关系类型 == P23.登记.宿主槽关系类型
角色或顺序 == 1
源端属于 P21 主体集合
```

对于源端属于主体集合但角色不是1的同类型关系，直接内部不一致。每个候选目标必须是当前普通节点，作为实例槽。

候选槽形成后，再扫描该宿主槽关系类型的全部当前关系，按目标槽核对反向基数：每个候选槽必须恰有一个角色1宿主关系，且唯一源端就是结果所属 P21 主体。外部宿主或第二个范围内宿主指向同槽均为 `实例槽多宿主`，不得把该槽归给任一主体后部分成功。

某主体没有任何候选关系是确定的“当前零实例槽”，返回该主体和空槽组；不是未找到。全部主体均无候选时仍返回已读取完整空槽组集合。

### 5.5 定义模板与唯一性

对每个候选槽，在定义模板关系类型中固定要求：

- 以该槽为源端的当前关系恰一条；
- 角色或顺序精确为2，关系类型精确等于 P23 定义模板关系类型；
- 目标定义端点是当前普通节点；
- 关系与两端生命周期不晚于快照截止且当前有效。

零条为定义关系缺失，多条为重复；错误角色、方向或端点均为内部不一致。同一主体下，两个不同槽若指向同一特征定义，固定为 `同宿主同定义重复槽`。本叶不读取定义标记、上下界、值域或来源，不把“当前普通定义端点”升级为定义详情已验证。

只检查与范围主体及其候选槽有关的关系；其它合法宿主类型的实例槽不进入结果，也不因不在 P21 世界成员范围而报错。但它们若作为候选槽的第二宿主，仍触发跨宿主损坏。

### 5.6 成功、排序与诊断

全部通过后：

- `主体槽组` 与 P21 主体一一对应，按主体稳定编码升序；
- 每个主体的槽按“特征定义稳定编码、实例槽稳定编码”升序；
- 关系见证固定放入具名宿主关系 / 定义关系字段，不依赖关系容器顺序；
- 世界根和 P21 主体资格见证原样保留，结果截止等于 P17 快照代次；
- `完整=true`、缺项诊断为空。

内部不一致时事实为空，诊断按 `种类、主体身份、实例槽身份、相关事实身份` 数值升序并确定去重。入口拒绝、登记未加载、未找到、事实代次漂移和资源失败均为空事实、空诊断。不得返回通过的主体或槽作为部分结果。

## 6. 并发、生命周期与错误边界

P24 只读取调用方拥有的 const 请求和快照。多线程对相同值输入必须逐字段得到相同结果；不得依赖容器原顺序、地址、线程、显示名称或时间戳。函数不取锁、不等待、不 sleep、不重试、不写缓存、日志、SQL、材料或 L1。

P17 许可释放后事实可以继续推进，但本次纯值结果仍只代表其非零截止代次。后继世界快照服务必须将本结果截止与 G0/G1 及其它领域结果校准；P24 不建立自己的重试。

当前值不存在、多值、材料或来源损坏不在本叶判定范围，必须由紧随其后的当前值集合叶完整检测。历史关系和值不在 P17 当前快照中，本叶不得调用历史或审计入口补齐。
