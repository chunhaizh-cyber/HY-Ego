## 3. 收口后的生产链

```text
已存在任务的子目标正式回流记录
  -> 任务子目标回流重判提供者：同 G0 读取父需求、当前任务和轮次权威
  -> L2任务结构服务::提交任务子目标回流后继筹办准备
       （同键读取 / 冲突检查 / 同代写入 / 正式读回）
  -> 任务子目标回流同轮次筹办定位
  -> 通用 任务主阶段治理请求
  -> manager 的通用主阶段治理队列
```

该链仅处理已经存在的任务的同轮次后继筹办。它不创建需求、任务、任务轮次、第二任务状态权威或执行冻结，也不以回流记录证明目标已经满足。父需求当前满足时，回流提供者只返回已满足裁决且零后继写入。

### 4.2 回流写入函数的完整合同

`L2任务结构服务::提交任务子目标回流后继筹办准备(请求)`必须按下列既有 DTO 合同完成，签名不变：

1. 校验请求、读取当前代次和同幂等键首次写入材料；已有首次写入必须读回后继记录并仅在 `子目标回流后继与请求一致` 时返回精确重复。
2. 首次不存在时，要求 `G0 == 当前代次`；读取当前筹办准备和对应轮次权威，验证任务、回流记录、首次准备记录、前一后继记录和前一轮次完全一致。
3. 调用既有 `形成子目标回流后继筹办准备写集`，经 task owner 的第一层写入端口提交；只接受已提交或精确重复。
4. 从写入编码映射取得后继记录，按写入截止历史读回，逐字段验证其与请求一致；成功只返回已提交/精确重复和该记录。资源、漂移、引用、幂等、内部错误均返回相应结构状态；没有落出函数的控制路径。

该函数的提交和读回只形成一条后继筹办准备记录及当前指针转换；不改变需求、任务身份、任务轮次、现实执行授权或结算。
