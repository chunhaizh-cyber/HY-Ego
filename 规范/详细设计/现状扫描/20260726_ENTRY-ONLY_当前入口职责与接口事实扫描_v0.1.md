## 3. 当前模式事实

| flag | 当前行为 | 漂移 |
| --- | --- | --- |
| 无参数 | 先运行入口自检正文、投影、SQL 往返，再 UI | 普通启动重复执行完整自检 |
| `--headless` | 同上，最后轮询停止标志 | 不应先跑投影/完整自检 |
| `--runtime-context` | 部分互斥后调用 `会话.启动({})` | 未拒绝 self-test 组合；请求与结果合同未显式 |
| `--self-test-exit` | 执行 14 项入口 bool 汇总 | 未使用中央运行器；不隔离数据 |
| `--database-self-test-exit` | 仍先运行入口自检正文，再 SQL 往返 | 专项被普通自检污染 |
| `--warehouse-performance-self-test-exit` | 同时设置 self-test bool | 专项与完整自检耦合 |
| `--d455-real-sample-exit` | 同时设置 self-test bool | 专项与完整自检耦合 |
| 未知参数 | 静默忽略 | 必须结构化拒绝 |
