## 1. 修订边界与权威关系

本版本是 v0.1 的不可变修订版。v0.1 中未被本文件替换的 DTO、公开函数、比较算法、错误映射、并发、验证和完成边界继续有效；本文件对服务登记和 I64 比较合同登记的 L1 事实形状具有优先权。执行者不得按 v0.1 中已被替换的“六个普通节点”或“值事实关系目标”施工。

本叶仍只形成一个真实 I64 目标判断比较提供者：在一次 `L1完整快照` 内校准 P2 I64 定义、P3/P4 实例当前值和本叶注册，返回排序三态、具名关系及安全 `右值 - 左值` 差异。不实现 STEP-3、运行期装配、比较收束、恢复、SQL、旧消费者迁移或旧入口删除。

## 2. 正式事实裁决

4015/4020 的物理规则在本叶固定为：

1. 关系事实的源和目标都必须是当前节点编码；值事实不是关系端点。
2. `合同配置I64组属性类型` 是 `节点种类::属性类型`，不是普通节点；它通过注册节点的当前属性槽承载配置值事实。
3. P2 的定义标记、下界和上界是三个独立 I64 值事实，继续由 P2 的读取 DTO 提供稳定编码和材料。它们不复制成关系端点，也不创建代理节点。
4. 合同配置值的有序 I64 组同时保存这三个 P2 值的材料和标量比较合同。注册读回在同一快照中按稳定编码定位 P2 三个值，并逐项比较材料；任何缺失、退出、类型/所属/来源错误或材料不相同均拒绝。

因此，合同仍然真实绑定 P2 三个值事实，但绑定方式是“值事实稳定编码 + 同快照材料互证”，不是非法的值端点关系。

## 4. 服务登记的唯一合法写集

首次 `建立登记` 必须先读取同一 L1 的完整快照；请求期望事实代次必须精确匹配读回代次，且本服务实例尚未保存登记。不得要求 L1 为空，也不得清空或改写已有世界、场景、P2、P3 或 P4 事实。成功写集严格建立六个节点：

| 本地角色 | 节点种类 | 事实语义 |
| --- | --- | --- |
| 服务身份 | 普通 | 本服务作为值事实来源 |
| 合同配置 I64 组属性类型 | 属性类型，值表示 `I64组` | 注册节点配置槽的唯一合法属性类型 |
| 合同字段关系类型 | 普通 | 本叶八条字段关系的关系类型节点 |
| 无单位 | 普通 | 标量合同字段节点 |
| 标量维度 | 普通 | 标量合同字段节点 |
| 标量分量角色 | 普通 | 标量合同字段节点 |

六项均由一次 L1 写集原子发布，逐项同代次读回后才缓存登记。精确重复返回幂等读回；异义或第二当前登记返回幂等冲突/内部不一致；非成功零新增事实。

## 5. I64 目标判断合同的唯一合法写集

`登记I64目标判断比较合同` 先从请求中的 P2 定义登记、P2 定义读取见证和 P3 实例登记取得字段来源，并在一个完整快照内确认所有输入仍处于同一当前代次。单写集严格包含：

1. 一个普通注册身份节点；
2. 一个 I64 组配置值，所属注册身份、属性类型为服务登记中的 `合同配置I64组属性类型`、来源为服务身份；
3. 注册身份的一个当前配置属性槽；
4. 八条合同字段关系，源固定为注册身份，关系类型为 `合同字段关系类型`，目标只能是节点：

| 角色 | 节点目标 |
| --- | --- |
| 1 | P2 抽象特征定义节点 |
| 2 | P3 定义模板关系类型节点 |
| 3 | P3 当前 I64 属性类型节点 |
| 4 | P2 I64 上界属性类型节点 |
| 5 | 无单位节点 |
| 6 | 标量维度节点 |
| 7 | 标量分量角色节点 |
| 8 | P2 定义来源服务节点 |

P2 定义标记、下界、上界三个值事实不出现在关系表。配置 I64 组的固定顺序为：

```text
[配置版本1, 用途1, 算法族1, 算法版本1, 原始类型1,
 左角色1, 右角色2, 差异方向1, 允许结果位7, 当前有效1,
 边界包含1, 量化规则1, 允许直接持久化0,
 溢出处理1, 缺值处理1, 输入版本规则1, 误差合同版本1,
 P2定义标记I64材料, P2下界I64材料, P2上界I64材料]
```

请求/结果 DTO 中的 `定义标记值`、`下界值`、`上界值` 仍保存 P2 三个值事实的稳定编码；`配置值` 保存本写集配置值编码。执行者不得把三个值编码塞入关系目标，也不得以代理节点、第二份值事实或裸字段替代上述互证。

## 6. 读回与比较约束

合同读回必须在同一完整快照中检查：注册节点、配置属性槽、配置 I64 组材料、八条关系、八个节点目标，以及 P2 三个值事实的稳定编码、所属节点、属性类型、来源、当前性和 I64 材料。任一关系目标不是当前节点、关系数量不为八、配置属性类型不是属性类型节点、或配置三项材料与 P2 值材料不相等，均返回 `内部不一致` 或对应结构化版本/未注册结果，绝不返回部分合同。

`比较特征` 仍只调用一次 `L1事实基座服务::读取完整快照({})`，不调用 P2/P3/P4 逐项入口拼接代次；在该快照中以 P3/P4 当前 I64 值为左值，以配置中经 P2 值事实互证的上界为右值，保持 v0.1 的三态、结果位和安全差异算法。比较零写入、零日志、零索引变化。

## 7. 验证增量与完成边界

专项自检必须新增并明确覆盖：六节点中恰有五普通节点和一个属性类型节点；合同写集恰有一配置 I64 值、一槽变更和八条节点目标关系；三个 P2 值事实只经稳定编码和同快照材料互证；任何值端点关系、代理节点、配置属性类型错误或三值材料不一致均拒绝且零事实变化。v0.1 的比较、极值、幂等、并发和静态禁用项矩阵继续有效。
