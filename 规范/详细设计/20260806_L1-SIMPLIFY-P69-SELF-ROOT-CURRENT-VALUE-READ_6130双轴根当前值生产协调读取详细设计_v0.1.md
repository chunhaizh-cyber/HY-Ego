## 1. S0、P1—P68 能力矩阵与最早缺口

P68 已冻结无对象状态纯值函数，只接受 P56、P65、P26 三份成功事实。它不调用 provider，
也不负责许可拒绝、上游状态短路、同代次材料取得或完整重读。调用方若自行拼接这些材料，
就会重复 P29 已证明必须由唯一协调层拥有的调用顺序和漂移边界。

能力矩阵收束如下：

| 计划链 | 已冻结责任 | P69 裁决 |
| --- | --- | --- |
| P1—P16 | L1、定义、存在、实例特征基础能力 | 不复制；由正式上游调用传递 |
| P17/P19/P21 | 非阻塞快照、世界范围和存在资格 | 第二条范围链的唯一 provider |
| P22 | 特征定义登记一次 try-lock 读取 | P24 非空槽时 P25 的必要定位 provider |
| P23/P24—P26 | 实例槽、定义详情和当前 I64 值 | 同一 P17 快照内固定顺序复用 |
| P29 | 完整世界生产协调与一次组合漂移重读 | 复用协调模式，不调用其状态动态全链 |
| P53—P56 | 自我登记和唯一当前完整自我读取 | 第一条当前自我范围链的唯一 provider |
| P63—P65 | 双轴根定义和稳定发布事实 | P65 成功事实只作不可变定位锚 |
| P66—P67 | 出生 A=1/V=0 规格与发布证据 | 不作任意后继当前值来源 |
| P68 | P56/P65/P26 纯值同代次双轴投影 | 每轮全部成功后唯一组合函数 |

候选裁决：

| 候选 | 结论 | 理由 |
| --- | --- | --- |
| 直接进入根需求 | 否 | 尚无生产入口取得可短路、可重读的双轴当前事实 |
| 直接进入 6170 维护输入 | 否 | 当前 A/V 尚未由具名生产读取闭合，且维护还需独立时间账 |
| 调用 P29 后筛选双轴 | 否 | 会把 P27 状态动态及其登记升级为根值读取前置 |
| 新增根定义当前读取账 | 否 | P65 锚给出稳定角色；P25 在本轮快照权威互证定义当前性 |
| 让调用方传入伪造 P21 单主体范围 | 否 | P21 只接受 P19 完整成员范围，不允许增删候选 |
| 新增双轴根生产协调读取服务 | **最早缺口** | 只闭合两条正式链、短路和 P68 组合漂移重读 |

P65 事实与 P29 保存的 P23/P9/P14 定位材料同属不可变强类型定位锚。P69 不把它当当前值；
P25/P26 会在本轮 P17 快照中重新互证定义、槽和值，P68 再校准 P65 发布代次与共同截止。
生产恢复或装配如何取得该锚属于后继边界，不要求本叶建立第二登记或读取账。

因此 P69 是 P68 之后唯一最早独立叶。根需求、维护输入、安全/服务更高层读取适配、初始化
和生产装配都只能消费本叶后继结果，不能在本叶混入。

## 2. 目标与最大边界

新增唯一公开根：

```cpp
自我双轴根当前值读取结果 L1自我根当前值读取服务::读取当前双轴根值(
    const 自我双轴根当前值读取请求& 请求) const;
```

每轮固定流程：

```text
P56读取完整自我结构
-> P19读取指定根当前世界结构
-> P21读取该完整成员范围的实际存在资格
-> P17取得一份非阻塞L1完整快照
-> P24从该快照读取全部实例槽
-> 非空槽时P22尝试读取特征定义登记；空槽跳过
-> P25以同一快照读取被引用定义详情
-> P26以同一快照读取全部当前I64实例特征值
-> P68组合P56/P65/P26双轴当前值
```

任一 provider 非成功或坏成功立即短路。只有第一轮所有上游都成功且 P68 返回
`事实代次漂移`，才丢弃全轮材料并完整执行第二轮；第二轮结果直接返回。

本叶零写入、事务、幂等、稳定编码、摘要、账、恢复和生产装配；不形成根需求、6170 维护
输入、合同进展、时间游标、状态、动态、因果、结算、旧栈删除或正式验收。

## 5. 入口和构造定位门禁

调用任何 provider 前校验：

- 请求合同、协调规则、世界规则及指定世界根合法；
- 保存的自我结构登记身份、实例特征登记定位请求符合各自冻结版本和非零形状；
- 保存的 P65 事实发布代次非零，登记完整，安全/服务角色正确且通用定义非零互异；
- P65 两个定义值域均为 `0..I64_MAX`，不得交换角色或用专用根记录冒充通用定义。

请求错误返回入口拒绝、阶段无。保存定位声称成功但形状损坏返回内部不一致、阶段无。
构造函数只复制引用和值，不读 provider；所有权和实际当前性只在公开读取调用中验证。

## 6. 每轮唯一调用顺序

### 6.1 P56 当前自我

以保存的自我结构登记身份、请求根和正式版本形成 `完整自我结构读取请求`，调用 P56 恰一次。
`已读取`且完整事实才继续；`尚无已发布自我`同名返回。三类登记/世界未加载统一映射未找到，
版本漂移、许可拒绝、资源失败同名映射；入口拒绝、坏成功、未知状态映射内部不一致。

### 6.2 P19、P21 与 P17

1. 以请求根形成 P19 请求并调用恰一次；只接受完整、非零截止且根相等的已读取事实；
2. 把 P19 成功事实原样放入 P21 请求并调用恰一次，不另传或裁剪候选成员；
3. 以正式 L1 合同形成 P17 请求并调用 `尝试读取完整快照`恰一次；
4. P21 成功已保证 P19/P21 与其内部 P17 同截止，本轮 P17 快照还必须非零且精确等于
   P19/P21 截止；不同映射版本漂移，不继续调用 P24。

未找到、版本漂移、许可拒绝和资源失败同名映射并标记当前阶段；入口拒绝、内部不一致、
坏成功或未知状态统一内部不一致。任一非成功时后继调用和本轮 P68 均为 0。

### 6.3 P24—P26 同一快照链

以 P21 完整事实和保存的 P23 定位形成 P24 请求，调用 P24 静态函数恰一次。P24 事实必须
完整、根和截止等于本轮 P17；非成功按阶段映射并短路。

计算 P24 全部主体槽总数：

- 总数为 0：P22 调用 0，以空登记定位形成 P25 合法空请求；
- 总数大于 0：调用 P22 `尝试读取当前登记`恰一次，只接受完整登记成功；
- P22 许可拒绝、未加载、资源失败分别映射；坏成功、入口拒绝和未知状态内部不一致。

随后依次调用 P25、P26 各恰一次，始终传入本轮同一 P17 快照。两者成功事实必须完整、
根与截止逐项相等，P26 主体组必须精确覆盖 P21；任何坏成功内部不一致，不返回部分事实。

### 6.4 P68 组合与结果

以正式 P68 投影版本、P56 完整事实、保存的 P65 事实和 P26 完整事实调用 P68 恰一次：

| P68 状态 | P69 结果 | 是否完整重读 |
| --- | --- | --- |
| 已形成且事实完整 | 已读取、阶段无、原样事实 | 否 |
| 事实代次漂移 | 第一轮暂不返回；第二轮版本漂移 | 第一轮是 |
| 当前值缺失 | 当前值缺失、双轴投影阶段 | 否 |
| 资源失败 | 资源失败、双轴投影阶段 | 否 |
| 入口拒绝、内部不一致或坏成功 | 内部不一致、双轴投影阶段 | 否 |

P68 成功事实的根、自我、定义、A/V、截止和控制态必须满足 P68 冻结合同。P69 不重算、
排序、裁剪或重建 P68 结果。

## 7. 有限重读、并发与生命周期

只有第一轮全链成功而 P68 报告 P56/P26 共同截止不同，才销毁本轮全部局部材料，从 P56
重新开始第二轮。禁止只重读 P56、P17、P26 或 P68，禁止跨轮复用 P22 登记或 P65 之外
任何事实，禁止 sleep、yield 或无限 retry。

任一上游自身返回版本漂移、许可拒绝、未找到、资源失败或内部不一致时立即返回，不消耗
完整重读。P29 的 P19 G1 是 4200 完整世界合同，不是本双轴投影输入；P69 不新增 G1。
P56 和 P21 已各自校准正式范围，P24—P26 共享第二条链同一 P17 快照，P68 再比较两链截止。

单次公开调用最大调用数：P56/P19/P21/P17/P24/P25/P26/P68 各 2；P22 每轮按槽空 0、
非空 1，总计最多 2。P65/P67/P29/P40/P15 调用均为 0。

服务无共享可变状态；多线程调用的轮次材料只属于各自调用栈。函数不 `noexcept`；
`std::bad_alloc` 映射资源失败并标记当时阶段，其它未分类异常映射内部不一致。返回事实只
代表其非零截止，之后事实可以继续推进。
