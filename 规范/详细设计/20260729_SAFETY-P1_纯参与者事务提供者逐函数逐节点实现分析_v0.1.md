# SAFETY-P1 纯参与者事务提供者逐函数逐节点实现分析 v0.1

日期：2026-07-29

状态：现行提供者分析；合同 `CORE-C1/v1`

## 1. 当前事实

当前普通 `节点直接身份结构写入执行器::执行(回调, span)` 必须由回调调用公开 `请求提交()`。当前会话在核心写集为空且没有核心幂等读回时固定记录 `内部不一致`；因此它不能提交只有领域参与者的正式维护账。该拒绝用于防止普通入口空事务，必须保留。

## 3. F-S109 节点分析

| 节点 | 实现分析 | 结果 |
| --- | --- | --- |
| B01 | 复用执行器有效性和既有指针唯一性检查，并追加非空组门禁 | 入口拒绝 |
| C02—C05 | 取得同一事务域独占许可，构造空写集会话，只调用私有 F-S110 | 许可拒绝或进入准备 |
| C09/B10/N11 | 准备必须逐项返回 `已提交` 或 `幂等读回`；记录是否全部幂等 | 其它状态按内部不一致撤销 |
| C13/B14 | F-S111 只确认空会话阶段 | 失败撤销 |
| C17/B18 | 参与者按登记顺序确认 | 失败逆序撤销 |
| C20—C22 | 空会话先完成发布，随后参与者按登记顺序完成发布 | 进入现行无失败区 |
| R23 | 全部参与者幂等才返回幂等读回；混合或全部新候选返回已提交 | 诊断数值全零 |

## 4. F-S110/F-S111 节点分析

F-S110 只接受执行器友元调用，检查写入中、无失败、核心写集为空且无核心幂等结果，然后设置独立的仅参与者标记和提交阶段。失败复用会话的首次失败收口。

F-S111 只接受同一标记、已请求提交、无失败、核心写集为空且无核心幂等结果，随后把空会话推进到已确认待发布。它不遍历参与者，不返回业务身份。

## 5. 生命周期、异常和锁序

```text
调用方拥有参与者对象
-> F-S109 借用非空 span
-> 事务域独占许可
-> F-S110 标记空核心会话
-> 参与者顺序准备
-> F-S111 确认空会话
-> 参与者顺序确认
-> 空会话完成发布
-> 参与者顺序完成发布
-> 释放许可
-> span 失效前返回
```

回调、业务 DTO、仓库、节点/关系/索引候选均不进入公开合同。准备或确认抛异常沿既有安全包装和逆序撤销收口；完成发布保持既有 `noexcept` 无失败区。撤销失败继续隔离事务域，不新增降级。
