# DATA-L2 四本体根公开值式合同详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-CONCEPT-ONTOLOGY-ROOT-PUBLIC-DTO`

## 1. 目标与完成边界

在已经发布的 `L2概念身份` 与 `L2节点族::概念=10` 之上，建立四个语言无关概念本体根三项公开操作所需的唯一值式 DTO 头 `海中鱼巣/领域/L2概念结构.数据.h`。

本叶只冻结并实现可独立编译的公开值式合同，不建立概念 owner、节点、关系、服务模块、聚合、普通应用装配或机器事实，也不登记生产工程。后继 C1 必须直接包含并导出本头，禁止复制同名 DTO 或形成第二 ABI。

## 2. 正式依据与当前事实

- 2220 与 4240 v0.6：固定存在、特征、动态、因果链四个永久本体根；概念与语言、词条正交，语素和词性不形成持久节点族。
- 4230：共同请求 / 结果头、生命周期、身份来源和结构状态。
- 公共身份闭合结果 `5bb120f2529633e3edcec35dae92a1842f628557` 已发布；当前公共头 blob `b6851a2f95b0f472907f7be15d5d982436ea9d3c`。

- `海中鱼巣.vcxproj` 与 `.filters` 当前由异主 EVENT WIP 占用；本叶不修改二者，使用生产工程外临时编译探针证明头文件自洽，探针完成后删除。

## 3. 唯一公开类型

新头在 `namespace 海中鱼巣` 内逐字定义：

```cpp
enum class L2概念本体根角色 : std::uint8_t {
    存在 = 1,
    特征 = 2,
    动态 = 3,
    因果链 = 4
};

struct L2概念本体根角色事实 final {
    L2概念本体根角色 角色 = L2概念本体根角色::存在;
    L2概念身份 根概念;
    稳定编码 关系稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(const L2概念本体根角色事实&,
        const L2概念本体根角色事实&) = default;
};

struct L2概念本体根事实 final {
    L2概念身份 根概念;
    L2节点族身份来源事实 身份来源;
    L2概念本体根角色事实 根角色;
    L2结构幂等身份 首次幂等身份;
    std::uint64_t 首次期望事实代次 = 0;
    std::vector<L2概念身份> 直接上位概念;
    friend bool operator==(const L2概念本体根事实&,
        const L2概念本体根事实&) = default;
};
```

请求 / 结果固定为：

```text
L2概念本体根建立请求{请求头, 幂等身份, 角色}
L2概念本体根写入结果{结果头, optional<本体根>, 成功()}
L2当前概念本体根读取请求{请求头, 角色}
L2当前概念本体根读取结果{结果头, optional<本体根>, 成功()}
L2当前概念本体根组读取请求{请求头}
L2当前概念本体根组读取结果{结果头, vector<本体根>, 成功()}
```

全部结构使用逐字段默认相等。不得增加 owner 编码、内部属性类型、deadline、名称、语言、词条、普通概念或测试字段。

## 4. 纯值 helper

本头唯一拥有以下 `inline noexcept` helper：

```cpp
L2概念本体根角色有效
L2概念本体根角色事实完整
L2概念本体根事实完整
L2概念本体根建立请求有效
L2当前概念本体根读取请求有效
L2当前概念本体根组读取请求有效
```

精确判据：

- 角色只接受 1—4。
- 角色事实要求截止非零、角色闭合、根与关系编码非零、生命周期创建不晚于截止且未退出。
- 根事实要求根身份非零；身份来源在截止完整、节点族为概念且节点编码等于根；身份来源 owner / 节点 / 族锚点 / 关系类型 / 归属关系五份生命周期均未退出；角色事实完整且根相同；首次幂等身份和首次期望代次非零，首次期望代次严格早于根角色关系创建代次；直接上位组为空。
- 建立请求只接受合同版本 1、非零期望代次、非零幂等身份和闭合角色。
- 单根读取只接受合同版本 1、非零期望代次和闭合角色。
- 全组读取只要求合同版本 1；期望代次允许 0 表示调用进入时最新，也允许非零乐观守卫。

## 5. `成功()` 形状

- 写成功只接受 `已提交` / `精确重复`，要求非零截止、变更代次存在且等于截止、根 optional 存在并在截止完整、截止严格晚于根回显的首次期望代次。
- 单根读成功只接受 `已读取`，要求非零截止、零变更、根 optional 存在且完整。
- 全组读成功只接受 `已读取`，要求非零截止、零变更、0—4 根全部完整、角色严格升序、角色不重复且根身份互异。空组是合法成功。

`成功()` 只判断结果自身形状，不能校验请求回显；服务和消费者仍须校验非零守卫成功截止等于请求守卫、单根角色等于请求角色。
