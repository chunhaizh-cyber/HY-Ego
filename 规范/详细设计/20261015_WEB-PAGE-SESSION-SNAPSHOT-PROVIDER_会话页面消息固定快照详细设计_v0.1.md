# WEB-PAGE-SESSION-SNAPSHOT-PROVIDER 会话页面消息固定快照详细设计

日期：2026-10-15；版本：v0.1。设计代码基线：main/origin/main `bc18b435b2f64cb38c6123ba661a6bbddc8528b7`。本文件冻结宿主调用期只读合同，不新增正式语言或世界事实。

## 1. 目标与边界

本叶交付一个可供后继语言处理调用的宿主页面消息快照：按公开会话标识，在同一次 `共享状态.互斥` 锁内核验活跃会话、固定页面序号上界并复制有界、有序的消息前缀。其事实仅为消息已追加到宿主页面可读取列表；现有 `网页对话已显示消息` 是历史类型名，不能由此推断浏览器已渲染、人物已观看、唯一接收者或指代目标。快照是调用期值式材料，会话结束后宿主清除会话身份、消息组不再可读；本叶不持久化语言材料、交互记录、自然语言场景、指代实例或文本范围到强类型目标的固定关联。

交互者 POST 先调用上层消息接收函数，上层接纳后才尝试 `追加交互者消息`；上行序号与页面序号分账。仅页面列表成功追加者属于本入口来源。自我文本由 `提交网页对话待提交文本` 在宿主锁内追加后属于来源，待提交状态本身不属于。HTTP 202 或读取接口提供给浏览器的数据均不证明客户端实际渲染。来源成功不自动提供代词“它”的唯一指认依据。

正式依据：[0050](../0050_项目通用机器逻辑与禁止性规则总纲_20260721.md)的单次锁内完整值式读取与跨函数分步不拼快照、[1100](../1100_根规范_语言记录_20260720.md)的语言材料/世界事实分账、[1110](../1110_根规范_指代_20260720.md)的出现及目标分账、[7230](../7230_子规范_语言材料知识与交互字段.md)第4节的交互与固定语境、[7240](../7240_子规范_自然语言双向转换与组织规则.md)的接收方可恢复依据，以及[代码归属规范](../代码文件建立归属与模块命名规范.md)。本次设计选择以宿主页面消息固定快照作为最早独立代码叶，后续目标绑定与持久交互记录留在路线输入。

## 2. 现行能力与物理归属

`海中鱼巣/界面/宿主.网页对话.h/.cpp` 唯一持有 `网页对话共享状态` 及其互斥、会话标识、消息组和下一页面序号。会话开始清空消息组并把下一序号置1；交互者追加和自我提交在同一锁内把 `{页面序号, 角色, UTF8正文}` 追加、然后增加序号。当前 `核验网页对话当前会话` 与 `读取网页对话已显示消息` 各自加锁，后者无会话参数、无复制额度或完整性；其组合无法保证同一时刻同一会话。现有无参会话读取与HTTP/本能消费维持原合同，不改调用路径，不用其结果拼新快照。

新能力是宿主所拥有运行期列表的只读扩展，直接放在既有头源，靠近会话核验/消息读取声明及实现。它是公开自由函数，不新增类、文件、工程登记、全局缓存、DATA/语言 owner 入口或生产调用者；只复用既有消息载荷类型，不复用无会话参数读取函数。允许后继表达/理解编排调用，宿主内部也可调用，但不得把未消解消息当正式语言交互记录或指代目标。

## 3. 精确公开合同

在 `宿主.网页对话.h` 增加 `<cstddef>` 并声明：

```cpp
enum class 网页对话页面消息快照状态 : std::uint8_t {
    已完成 = 1, 额度不足, 宿主未运行, 会话不匹配,
    输入拒绝, 资源失败
};
struct 网页对话页面消息快照结果 final {
    网页对话页面消息快照状态 状态 = 网页对话页面消息快照状态::输入拒绝;
    std::string 公开会话标识;
    std::uint64_t 请求已读页面序号 = 0;
    std::uint64_t 截止页面序号 = 0;
    std::uint64_t 已覆盖页面序号 = 0;
    bool 覆盖完整 = false;
    std::vector<网页对话已显示消息> 消息组;
};
网页对话页面消息快照结果 读取网页对话会话页面消息快照(
    std::string_view 公开会话标识,
    std::uint64_t 已读页面序号,
    std::size_t 最大消息条数,
    std::size_t 最大正文总字节数) noexcept;
```

输入会话标识必须非空且为宿主现行 `是有效UTF8` 所认可的字节串。两额度均须大于0，且 `最大消息条数<=1024`、`最大正文总字节数<=8*1024*1024`；否则 `输入拒绝`。字节额度只累计 `UTF8正文.size()`，不包含标识、角色、序号或容器元数据；不拆消息、不裁剪 UTF-8 正文。调用者要取得更大范围须用页面序号分页，不能传无界额度。 `已读页面序号` 是调用方提供的读取下界；宿主只核验它不超过当前会话截点，不证明该游标来自同一会话先前读取，成功时只返回页面序号大于它的最早连续前缀，保留原序号与角色；若大于当前截止，`输入拒绝`。零序号表示从本会话首条开始。所有序号属于宿主页面列表，不是交互者上行序号、语言记录身份或基础数据稳定编码。

`已完成` 仅表示所选区间 `(请求已读页面序号, 截止页面序号]` 全部覆盖，`覆盖完整=true` 且 `已覆盖页面序号=截止页面序号`；空会话和 `已读=截止` 均合法，可返回空消息组。`额度不足` 表示尚有下一条消息不能完整放入剩余额度，允许返回已复制的前缀，`覆盖完整=false`，`已覆盖页面序号` 为前缀末序号；第一条就放不下时消息组为空、`已覆盖页面序号=请求已读页面序号`，但仍回显会话标识、请求下界和同锁截止。调用者可用这些字段识别零进展，不得因空组判定无消息，也不得把部分结果当完整前文。无消息且额度正数时返回 `已完成`，绝不返回 `额度不足`。

仅 `已完成` 和 `额度不足` 携带有效会话标识、下界、截止、覆盖、消息组。其它状态全部返回缺省元数据和空组；`资源失败` 不暴露已复制的部分前缀。内部代码错误按工程致命诊断终止。结果独立于共享状态生命周期；返回以后会话可能结束或出现新消息，结果只能证明加锁时的列表截点，不证明返回时仍活跃。

## 4. 锁内步骤、错误与不变量

1. 锁前检查会话标识、额度；无外部服务调用。取得 `共享状态.互斥` 后，先查运行中，再精确比对公开会话标识；不匹配返回独立状态，不泄露其它会话数据。检查 `下一页面序号` 非零，固定 `截止页面序号=下一页面序号-1`；`已读>截止` 为输入拒绝。当前消息组按追加规则应从1连续到截止，若其个数、顺序或角色出现不一致，进入工程致命诊断，不返回普通结果。
2. 在同一锁内复制会话标识及消息；从 `已读+1` 开始按升序逐条检查额度，累计正文长度前先用减法比较避免溢出。只有整条容得下才复制和推进 `已覆盖页面序号`，否则停在该条前，返回 `额度不足`。达到当前截止时返回 `已完成`。条数和字节都不超过请求额度，条目原值不改动。
3. `std::bad_alloc`、`std::length_error` 归 `资源失败`，返回全新缺省失败结果；其余异常和宿主内部不变量破坏经既有 `核心/容错检查.h::工程异常终止` 进行具名日志、弹窗与进程终止，不回到业务判断。函数是 `noexcept`；诊断责任为`本地记录`，资源失败为明确的资源状态，代码错误为致命工程诊断。只读本宿主锁；诊断工具由独立线程输出，不在持锁当前线程直接执行日志I/O或回调业务、语言、概念、外设。任何异常或不变量破坏都不能伪装“无消息”，不写世界/语言事实。
4. 本入口零写共享状态、无持久事务、无发布未知或重试副作用。会话结束与本次读取按同一锁串行；结束先取得锁则返回宿主未运行，读取先取得锁则返回合法调用期快照。后继若跨调用分页，必须由调用方自行保存并核对同一公开会话标识、各次截点和游标来源，再依其自身合同组合；本叶单次结果不证明游标来源，也不声称跨调用共同快照。
