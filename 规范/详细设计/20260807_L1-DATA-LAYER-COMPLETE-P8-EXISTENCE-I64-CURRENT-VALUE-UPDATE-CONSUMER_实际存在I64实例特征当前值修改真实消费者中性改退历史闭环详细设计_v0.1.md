## 1. 目标与完成边界

本叶原位迁移唯一 `L1实例特征服务::换代实际存在I64实例特征当前值`，使具名第二层服务通过 L1 业务中性 CRUD 完成一次当前值修改：建立一个新 I64 值事实，把实例槽的当前属性指向新值，并在同一原子写集中退出旧值。成功后只经正式公开入口重新读取新当前值、旧值当前状态、旧值历史记录和当前属性槽。

本叶是实际存在实例特征消费者对“改、退、历史查”的真实使用，不是 L1 自检。第一层只裁决完整中性写集、最小幂等、稳定编码、原子提交和中性读回；实例特征服务负责当前事实、定义值域、新来源资格和领域结果解释。合法消费者验收通过后，只累计本消费者实际覆盖的一个新值创建、属性槽切换、旧值退出、当前不可读、历史可回查、精确重复、同键异义和非法请求零变化。

本叶不迁移 `换代I64实例特征当前值`，不退出实例槽、宿主关系或定义关系，不修改初始场景实例，不建立关系替换、显式对象删除、批次、状态、动态、因果、恢复或其它消费者。当前不考虑崩溃、重启、断电和跨进程恢复。

## 4. 请求、定位与幂等顺序

请求字段保持：合同版本、规则版本、幂等身份、期望事实代次、完整写前读取请求、新 I64 值和新来源节点。

中性幂等键继续使用实例特征换代隔离域：

```text
换代键 = (0x07ULL << 56) | 请求.幂等身份.值
```

服务新增一份同锁、非权威的 `实际存在换代幂等定位`，只记录已经进入本入口且可能已经形成 L1 权威发布的幂等身份；不保存请求、写集、旧值材料、新值编码、首次结果或事实副本。它只解决当前不考虑重启条件下的重复请求路由：

1. 身份已定位：不重读已经退出的旧当前值，直接由本次请求与当前登记机械形成完整中性写集，恰一次提交，由 L1 返回精确重复或幂等冲突。
2. 身份未定位：先插入暂定定位；完成全部写前领域准入后恰一次提交。提交未形成成功类结果时删除暂定定位。
3. L1 返回成功或精确重复后保留定位，再执行全部权威读回。发布后读回失败时定位也保留，使同一请求可以再次经 L1 精确重复收敛，不由缓存返回成功。
4. 同键不同写前事实、新值、新来源、期望代次或其它字段形成不同完整中性写集，由 L1 返回幂等冲突；服务不自行把相似字段解释为同义。

当前运行期上下文从空 L1 构造唯一长寿命实例服务，且不考虑恢复。未来非空装配、重启或恢复需要独立定位重建合同，本叶不得以进程内定位宣称跨进程完整。

## 5. 首次写前业务准入

身份未定位时，const 实现固定执行：

1. 校验请求 DTO；失败返回入口拒绝。
2. 读取当前登记，取得当前 I64 值属性类型；首次候选的登记事实截止必须等于请求期望事实代次。已定位的重复 / 冲突路径只要求登记当前完整，不要求当前截止仍停在首次期望代次。
3. 读取中性当前事实代次作为起始代次；必须等于请求期望事实代次。
4. 经 P7 正式入口 `读取实际存在I64实例特征` 读取写前实例；结果必须完整，且宿主、定义、实例槽、宿主关系、定义关系、当前值和来源逐字段等于请求。
5. 经 P6 正式入口读取 I64 定义；定义身份和事实截止必须匹配请求，且新值位于闭区间内。
6. 经 L1 中性当前节点入口读取新来源；必须是未退出普通节点，查询编码、事实编码和读取代次必须匹配。
7. 再读取中性当前事实代次作为结束代次；登记、起始、实例、定义、来源和结束必须等于同一请求期望代次。

任一提供者或中性读取非成功都在提交前返回。未找到、已退出、事实代次漂移、资源失败和内部不一致按现有显式映射返回；不存在裸枚举转换。新值越界、新来源不是普通节点或请求字段矛盾返回入口拒绝或内部不一致，权威状态零变化。

## 6. 唯一中性写集

中性写集只由请求、P7 已冻结的登记和写前准入结果形成：

| 类别 | 数量 | 固定内容 |
| --- | ---: | --- |
| 节点新建 | 0 | 无 |
| 关系新建 | 0 | 无 |
| 值新建 | 1 | 本地键 1；所属现有实例槽；属性类型为登记当前 I64 值属性类型；材料为请求新 I64 值；来源为请求新来源节点 |
| 属性槽变更 | 1 | 现有实例槽 + 登记当前 I64 值属性类型指向本地值 1 |
| 退出事实 | 1 | 请求写前当前值编码 |

函数恰一次调用 `L1事实基座服务::提交中性写集`。成功类结果必须满足：合同版本、幂等键、事实代次、重试边界、是否形成内存权威发布和唯一一个本地键 1 映射完整；成功必须形成权威发布，精确重复不得再次形成发布，并必须回显首次新值编码和首次发布事实代次。

中性写集不含业务操作标签、领域意图、请求意图摘要、执行证据、提供者见证、领域结果见证、读回计划、审计或恢复材料。函数不调用 `探测幂等`、legacy `提交写集` 或 `读取完整快照`。

## 7. 发布后权威读回

从成功类结果的本地键 1 映射形成新的 `实际存在I64实例特征读取请求`：保留宿主、定义、实例槽、宿主关系和定义关系，把当前值替换为映射新编码，把来源替换为请求新来源。

读回固定在一个稳定的中性当前截止内执行：

1. 读取中性当前事实代次为读回起始。
2. 经 P7 正式入口读取新当前实例，逐字段验证宿主、定义、实例槽、两关系、新值、新来源和新当前值编码。
3. 经 L1 中性当前值入口读取旧值，必须返回已退出且不带当前事实。
4. 经 L1 中性历史入口读取旧值，必须返回完整 I64 值事实；所属实例槽、属性类型、旧来源、旧材料和创建代次与写前事实一致，退出事实代次等于首次发布事实代次。
5. 经 L1 中性当前属性入口读取实例槽当前值，必须指向映射新值编码。
6. 再读取中性当前事实代次为结束；起始与结束必须相同，P7 新当前事实截止和当前属性读取代次必须等于该截止。

新值事实创建代次与旧值退出代次必须等于首次发布事实代次；共同读回截止可以等于或晚于首次发布事实代次，但不得早于它。这样允许其它无关写集已经推进全局事实代次，同时仍要求本次修改在一个无混代窗口内完整可见。

首次和精确重复都执行同一组权威读回。精确重复不推进事实代次，不产生第二新值或第二退出，返回同一个新值编码；领域结果状态映射为幂等读回。任何读回矛盾返回内部不一致，不以日志或缓存补成成功。

## 8. 非成功与零变化

| 场景 | 结果 | L1 写入 | 权威状态要求 |
| --- | --- | ---: | --- |
| 请求版本、身份或读取请求无效 | 入口拒绝 | 0 | 零变化 |
| 写前当前值已经漂移、已退出或字段不一致 | 未找到、事实代次漂移或内部不一致 | 0 | 零变化 |
| 新值越界或新来源不是普通当前节点 | 入口拒绝 | 0 | 零变化 |
| 同一幂等键携带不同完整中性写集 | 幂等冲突 | 1 次裁决、0 次发布 | 新当前、旧历史和属性槽零变化 |
| 首次提交期望代次漂移 | 事实代次漂移 | 1 次裁决、0 次发布 | 零变化 |
| 精确重复 | 幂等读回 | 1 次裁决、0 次新发布 | 保持首次新当前、旧历史和属性槽 |
| 资源失败或内部不一致 | 对应结构化状态 | 不补写 | 不返回部分领域事实 |

外部合法消费者验收中的每项非成功必须在调用前后经正式公开入口比较新当前、旧历史和当前属性槽；不得由服务内部建立验收矩阵或 PASS 状态。
