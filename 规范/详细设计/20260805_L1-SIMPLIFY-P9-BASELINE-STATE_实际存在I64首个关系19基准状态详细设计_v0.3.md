# L1-SIMPLIFY-P9-BASELINE-STATE 实际存在 I64 首个关系19基准状态详细设计 v0.3

日期：2026-08-05

状态：设计就绪；代码未实现；计划必须待激活

替代关系：本版完整替代 v0.2。v0.2 已解决当前投影耦合，但错误地把被采样 P8 值事实的属性类型解释为 P2 抽象特征定义，禁止施工。

## 1. 目标与边界

本设计只完成 SELF-GOV-CLOSURE STEP-3C：为 P7 实际存在及其 P8 存在宿主 I64 实例槽发布第一个关系19基准状态，并按状态自身稳定身份和完整见证读取一份不可变状态快照。

保留 v0.2 已冻结的首态二节点、五值、五关系、五属性槽单写集，以及 L1 当前/历史分支、读取截止/采样截止分账和首末快照校准。

本版唯一语义修订是删除状态结果中伪造的 `特征定义`。P8 值事实的 `属性类型` 是 P8 登记的当前 I64 值属性类型，不是 P2 抽象特征定义。状态领域只返回角色3实例槽和被采样值的真实属性类型、材料、来源与生命周期，不解释 P8 定义关系。

本入口不选择当前或相邻状态，不实现第二状态、值换代、关系20、动作动态、因果、运行期装配、SQL、持久恢复或旧消费者迁移。

## 2. 正式裁决

- 4200 §5.2 要求状态事实包含场景、主体、特征、值、发生时间和状态身份；4210 将关系19角色3冻结为特征节点。本叶角色3已经是 P8 具体实例槽。
- P8 合同把 P2 抽象定义节点、实例槽到定义的关系、以及当前 I64 值属性类型冻结为三个不同身份。
- `值事实.属性类型节点` 只解释该值载荷的表示与属性槽，不证明实例槽指向哪个 P2 定义。
- 4210 后继比较必须按真实特征定义路由，但应由后继用“P9角色3实例槽 == P10新当前实例槽”证明同一具体特征，再从 P10/P8 合法读回中的定义和定义关系取得 P2 身份。
- P9 不复制定义关系，不猜测定义，不让比较服务解析关系19，也不扩大首态写集。

公开函数数量和签名不变，不新增第二状态读取入口。

## 6. 发布与立即读回

发布前仍由 P8/P7 当前入口在请求期望代次取得宿主、场景、实例槽、P2定义、定义关系、当前值和来源，以验证采样资格并形成写集。P2定义只用于发布前证明 P8 组合完整，不进入 P9 结果或写集。

写集成功或精确重复后，以本地键映射形成只含状态自身编码的读取请求，调用同一 `读取实际存在I64基准状态`。立即读回时状态自有事实和被采样值均走当前分支，读取截止等于发布代次，采样截止等于写前基线，状态自有事实创建代次等于采样截止加一。

## 7. 不可变读取算法

1. 校验合同、规则与稳定编码；非法返回 `入口拒绝`。
2. 读取起始 L1 完整快照得到 `G0`。
3. 对状态、值见证、五关系和五状态域值先读当前；当前返回 `已退出` 时按同编码读历史。不得扫描猜测。
4. 从五关系验证同源状态、同一关系19类型、角色1—5恰一，并由端点确定主体、采样场景、角色3实例槽、值见证和来源存在。
5. 从当前或历史节点记录的属性槽验证五个状态域值；校验资格、时间、四项引用、采样 I64、所属、来源和生命周期。
6. 从四项引用取得被采样 P8 值编码，以 L1 当前或历史入口取得真实值事实。
7. 被采样值必须为 I64；所属节点必须等于角色3实例槽；属性类型非零但不解释为 P2 定义；来源、创建代次和材料分别等于冻结引用与采样 I64；创建不晚于采样截止，退出为空或晚于采样截止。
8. 主体、场景、实例槽和来源存在在采样截止时有效；后来退出合法。状态自有二节点、五关系和五值创建代次统一等于采样截止加一。
9. 读取结束完整快照得到 `G1`。`G0==G1` 且当前读取代次一致才成功；一次完整重试仍漂移返回 `版本漂移`。

P10 换代后旧值从历史入口互证；P7 当前场景移动后仍返回角色2冻结场景。读取函数不得调用 P7/P8，不得读取或推断 P2 定义关系。

## 8. 后继3E接口边界

P9只向3E提供：主体、采样场景、角色3实例槽、被采样值真实见证、采样I64、发生时间、来源和稳定状态身份。

3E必须另从 P10/P8 新当前组合取得同一实例槽、真实 P2 定义与定义关系，并校验：

```text
P9.特征.编码 == P10/P8.实例槽
```

只有该等式成立，后继才可以使用 P10/P8 返回的 P2 定义路由4180。调用方、P9或被采样值属性类型均不得提供或猜测该定义。

## 9. 错误、并发与验证

错误映射、非成功零载荷、发布互斥、L1幂等账、发布后不补写不回滚、首末快照并发边界保持 v0.2。

专项必须覆盖：

1. v0.2 的登记、首态写集、幂等、冲突、并发和全部当前/历史读取矩阵；
2. 结果 DTO 不含 `特征定义`，不新增定义节点、定义关系或定义复制写项；
3. 被采样值属性类型精确等于 P8 当前 I64 值属性类型，并只按属性类型本义返回；
4. P2 抽象定义编码故意不同于当前 I64 值属性类型时，结果不混淆、不输出 P2 定义；
5. P10换代、P7场景移动及端点后来退出后仍读回同一状态；
6. 读取函数 P7/P8/P2/4180 调用均为零；
7. 后继输入机械证明只可用角色3实例槽与新当前实例槽对齐，不能使用值属性类型代替定义；
8. Debug/Release Rebuild、两配置完整自检、strict、MSVC模块扫描和 diff check 通过。
