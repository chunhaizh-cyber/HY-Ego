# 实例特征 IFR L2 布局基础详细设计 v0.1

## 物理布局

v2 交付包含：`E到IF`、`IF到F`、`IF到R集合`、`R集合到版本`、`版本到R项`、`R项到F` 与 `R项材料属性类型`。前六项必须是本存在 owner 创建的未退出普通节点；第七项必须是同 owner 创建的未退出属性类型节点，且唯一表示为 `L1所有者范围值表示种类::U64组`。七项互异，且不得与子存在、特征或当前采用关系类型相同。

登记的 v2 幂等身份为 `0x4946525354525632`；它刻意不同于历史 v1 的 `0x4946525354525543`。首次写集只创建七个元结构节点，不含关系、值、属性槽变更或退出事实。键1..6是普通节点，键7是属性类型节点并声明 U64组。重放仅接受相同 v2 首次写集；任何旧 v1 首次材料均不读取、不迁移、不退出。

构造器拒绝非 v2 交付。普通装配采用 v2 请求，成功后把 v2 交付交给存在服务；它不创建 IF、R集合、版本、R项或材料值。

## 验证边界

静态探针必须确认 v2 键、7节点、键7属性类型/U64组、六关系仍为普通节点、写集无关系/值/属性槽/退出，以及装配未调用 IF/R 业务入口。编译范围只覆盖受影响翻译单元和依赖；完整启动及持久恢复不由本片声明。
