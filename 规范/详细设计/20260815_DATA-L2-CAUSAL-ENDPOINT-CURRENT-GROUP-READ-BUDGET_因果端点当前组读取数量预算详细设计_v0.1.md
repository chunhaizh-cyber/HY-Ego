# DATA-L2 因果端点当前组读取数量预算详细设计

日期：2026-08-15

版本：v0.1

身份：`DATA-L2-CAUSAL-ENDPOINT-CURRENT-GROUP-READ-BUDGET`

## 1. 目标与完成边界

为唯一 `L2因果结构服务` 的三类既有端点当前组查询补齐非零因果对象数量预算：

```text
按条件状态读取全部当前因果
按动作读取全部当前因果
按结果状态读取全部当前因果
```

调用方继续提供非零当前事实代次守卫和一个强类型端点，并新增非零 `最大数量`。服务必须返回按因果身份稳定编码严格升序、同一事实截止的完整当前因果组；当前匹配对象数超过预算时返回 `L2结构状态::数量预算不足`、空因果组和空变更代次，不截断、不分页、不把预算不足改判为资源失败。

本叶只闭合 DATA-EXT-06 的端点条件查询预算，不新增因果、替换、退出、来源查询、历史单对象读取、owner、装配或第二查询服务，也不证明 DATA-EXT-06 整项或最终需求清单整体完成。

## 3. 精确公开 ABI

在现有三类请求尾部逐项追加同名字段：

```cpp
struct L2按条件状态当前因果读取请求 final {
    L2结构请求头 请求头;
    L2状态身份 条件状态;
    std::uint64_t 最大数量 = 0;
    friend bool operator==(...) = default;
};

struct L2按动作当前因果读取请求 final {
    L2结构请求头 请求头;
    稳定编码 动作;
    std::uint64_t 最大数量 = 0;
    friend bool operator==(...) = default;
};

struct L2按结果状态当前因果读取请求 final {
    L2结构请求头 请求头;
    L2状态身份 结果状态;
    std::uint64_t 最大数量 = 0;
    friend bool operator==(...) = default;
};
```

三项既有纯值请求 helper 在原条件上增加 `最大数量 != 0`。请求头仍要求合同有效和非零 `期望事实代次`；端点身份继续按原强类型或非零稳定编码校验。

结果继续复用：

```cpp
struct L2当前因果组读取结果 final {
    L2结构结果头 结果头;
    std::vector<L2因果事实> 因果;
    bool 成功() const noexcept;
};
```

不增加分页、游标、截断标记、总数量、读取幂等身份、deadline 或第二结果类型。

## 4. 服务过程与预算线性化

三类公开函数保持名称和返回类型不变，把请求中的 `最大数量` 传给同一个私有端点读取实现：

```cpp
L2当前因果组读取结果 按端点读取(
    const L2结构请求头& 请求头,
    稳定编码 端点,
    端点角色 角色,
    std::uint64_t 最大数量) const;
```

私有过程固定为：

```text
读取当前因果结构类型登记
-> 以请求非零守卫在一次 L1 一致当前投影中读取目标端点关系组
-> 逐条验证 owner、关系类型、方向、角色、生命周期和目标端点
-> 收集关系源因果编码
-> 按稳定编码排序并去重
-> 若去重后的因果数量 > 最大数量：返回数量预算不足和空组
-> 否则逐项以同一请求头调用读取完整因果
-> 互证端点确实存在于完整因果对应角色
-> 返回严格升序、同截止完整组
```

预算以最终因果对象数计数。关系组中同一因果因多个条件或结果顺序重复命中同一端点时只计一次；不同因果各计一次。预算等于匹配数量成功，少一返回预算不足；零匹配为成功空组。

本叶不修改 L1 一致当前投影 ABI。L1 仍原子返回该端点的完整当前关系组；L2 在同一已取得截止内去重后实施公开对象预算。该预算保证不返回截断组，不承诺限制底层关系组构造时的内部暂存量；若后继需要存储资源上界，必须另立 L1 有界关系组读取合同，不能由本叶假装已实现。

## 5. 结果与错误映射

| 条件 | 状态 | 事实截止 | 因果组 |
| --- | --- | --- | --- |
| 零匹配或匹配数不超过预算且全部完整 | 已读取 | 请求非零守卫 | 完整严格升序组，可空 |
| 去重后的匹配因果数超过预算 | 数量预算不足 | L1 一致读取取得的安全截止 | 空 |
| 请求版本、守卫、端点或预算无效 | 入口拒绝 | 0 | 空 |
| L1 明确漂移 / 资源失败 | 同名状态 | L1 安全截止 | 空 |
| 端点正式读取未找到 / 已退出 | 原既有映射 | 对应安全截止 | 空 |
| 登记、关系组、完整因果或同截止互证矛盾 | 内部不一致 | 已取得安全截止 | 空 |

`数量预算不足` 是完整枚举保护，不是资源耗尽，不绑定写幂等身份，也不推进事实代次。全部非成功结果必须为空因果组、空变更事实代次；不得先压入预算内前缀再返回非成功。
