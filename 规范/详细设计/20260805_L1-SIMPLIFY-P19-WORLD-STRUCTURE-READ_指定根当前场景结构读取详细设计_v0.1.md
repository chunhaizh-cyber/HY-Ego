# L1-SIMPLIFY-P19-WORLD-STRUCTURE-READ 指定根当前场景结构读取详细设计 v0.1

## 1. 身份、目标与完成边界

计划身份：`L1-SIMPLIFY-P19-WORLD-STRUCTURE-READ`

版本：`v0.1`

创建侧正式代码基线：`d8e0ee739c2e029334a7dc14194bef001cd01dd6`

本叶是 SELF-GOV-CLOSURE STEP-4 在 P17、P18 冻结之后的下一最早缺口。它只原位扩展唯一 `L1场景结构服务`，由场景结构事实所有者消费 P18 世界登记定位副本和 P17 非阻塞 L1 完整快照，在一个纯值快照内解释指定正式世界根的全部当前场景、直接父子和直接成员，并提供同一领域门面的非阻塞当前事实代次读取。

完成必须同时成立：

- 许可竞争在 P18 或 P17 任一入口发生时立即返回 `许可拒绝`，不等待、不 sleep、不重试；
- 成功结果携带非零事实截止代次，且该截止只能来自本轮 P17 快照；
- 根、登记身份、场景标记、父子和成员关系在同一快照中完成当前生命周期和类型校准；
- 所有输出按稳定编码确定排序，完整成功的缺项诊断组必须为空；
- 任一结构矛盾返回空业务事实和稳定诊断，不返回部分树；
- 合法根只有自身、没有子场景或没有成员时成功返回对应空组；
- 后继 L2 只调用本领域公开函数，不直接解析 L1 快照或调用 L1 当前代次入口。

本叶不读取存在资格、实例特征、关系19状态、关系20动态或历史事实，不形成完整世界快照或统一世界只读门面。

## 3. 物理位置、所有权与依赖方向

只原位修改未来代码：

```text
海中鱼巣/领域/L1场景结构.数据.h
海中鱼巣/领域/服务.L1场景结构.ixx
海中鱼巣/领域/自检.L1场景结构.ixx
```

不新建第二场景服务、查询引擎、仓库、缓存、索引、模块或工程登记。`L1场景结构服务` 仍是场景标记、直接父场景关系和直接成员关系的唯一业务解释者。

依赖方向固定为：

```text
后继世界树快照读取服务
-> L1场景结构服务::读取当前世界结构 / 读取当前事实代次
-> 世界登记服务::尝试读取当前登记
-> L1事实基座服务::尝试读取完整快照 / 尝试读取当前事实代次
```

L1 和世界登记均不反向依赖场景结构；后继 L2 不得绕过场景结构服务解析 L1。两个公开读取函数不取得现有 `L1场景结构服务::锁_`，也不持有本服务锁跨 provider 调用。

## 4. DTO、状态与公开函数

在 `L1场景结构.数据.h` 新增版本化纯值 DTO。下列字段名和类型是施工合同，不得临场改成句柄或弱类型集合：

```cpp
inline constexpr std::uint32_t 当前世界结构读取规则版本 = 1;
inline constexpr std::uint32_t 当前世界结构排序规则版本 = 1;

struct 当前世界结构读取请求 final {
    std::uint32_t 合同版本 = L1场景结构合同版本;
    std::uint32_t 世界规则版本 = 世界登记规则版本;
    std::uint32_t 读取规则版本 = 当前世界结构读取规则版本;
    世界结构节点身份见证 指定世界根;
};

enum class 世界结构缺项种类 : std::uint8_t {
    登记身份缺失或损坏 = 1,
    根场景标记缺失或损坏 = 2,
    根存在父关系 = 3,
    场景标记缺失或损坏 = 4,
    非根场景无父 = 5,
    场景多父 = 6,
    场景成环 = 7,
    不可达或跨世界场景 = 8,
    结构关系端点缺失 = 9,
    结构关系顺序错误 = 10,
    重复父子关系 = 11,
    不可达或跨世界关系 = 12,
    重复成员关系 = 13,
    成员多场景 = 14,
    成员端点是场景 = 15,
    成员端点缺失或种类错误 = 16
};

struct 世界结构缺项诊断 final {
    世界结构缺项种类 种类;
    稳定编码 主身份;
    稳定编码 关系身份;
    稳定编码 相关身份;
};

struct 当前场景结构项 final {
    世界结构节点身份见证 场景;
    世界结构值见证 场景标记;
};

struct 当前世界结构事实 final {
    std::uint32_t 合同版本 = L1场景结构合同版本;
    std::uint32_t 世界规则版本 = 世界登记规则版本;
    std::uint32_t 读取规则版本 = 当前世界结构读取规则版本;
    std::uint32_t 排序规则版本 = 当前世界结构排序规则版本;
    世界结构节点身份见证 指定世界根;
    std::uint64_t 事实截止代次 = 0;
    std::vector<当前场景结构项> 当前场景;
    std::vector<世界结构关系身份见证> 当前直接父子关系;
    std::vector<世界结构关系身份见证> 当前直接成员关系;
    bool 完整 = false;
    std::vector<世界结构缺项诊断> 缺项诊断;
};

struct 当前世界结构读取结果 final {
    世界结构状态 状态 = 世界结构状态::入口拒绝;
    std::optional<当前世界结构事实> 事实;
    std::vector<世界结构缺项诊断> 缺项诊断;
};

struct 当前世界事实代次读取请求 final {
    std::uint32_t 合同版本 = L1场景结构合同版本;
    std::uint32_t 世界规则版本 = 世界登记规则版本;

};

    世界结构状态 状态 = 世界结构状态::入口拒绝;

```

`当前世界结构事实` 成功时 `完整=true` 且两个缺项组都为空。非成功时 `事实` 必须为空；结构矛盾使用结果顶层的稳定诊断，不允许在不完整事实中夹带部分树。

新增公开函数：

```cpp
当前世界结构读取结果 L1场景结构服务::读取当前世界结构(
    const 当前世界结构读取请求& 请求) const;

    const 当前世界事实代次读取请求& 请求) const;
```

第二个函数是后继 G1 的唯一场景领域门面。它先用 P18 校验指定根是正式登记根，再调用 P17 `尝试读取当前事实代次`；不得由后继 L2 直接调用 L1。

## 5. 当前事实识别与完整性算法

### 5.1 公共请求和 provider 顺序

两个公开函数先在锁外校验合同、世界规则、读取规则（适用时）和非零普通节点根。`读取当前世界结构` 固定顺序：

```text
校验请求
-> P18 尝试读取当前登记
-> 校准请求根等于登记世界根
-> P17 尝试读取完整快照
-> 只在该纯值副本中解释全部结构
-> 返回P17快照事实代次
```

P18 `许可拒绝` 立即映射 `世界结构状态::许可拒绝`；登记未加载、坏成功或身份不完整映射 `内部不一致`；请求根不等于登记根返回 `未找到`。P17 许可拒绝、资源失败、内部不一致分别同名映射；P17 成功但快照为空、事实代次为0或坏成功返回 `内部不一致`。

`读取当前事实代次` 同样先调用 P18 并互证根，再调用 P17 `尝试读取当前事实代次`；成功必须返回非零代次。它不形成结构、不缓存上轮结果，也不把 P18 `已验证事实代次` 当作当前截止。

### 5.2 登记身份与场景标记

在同一 P17 快照内必须逐项互证：

- 登记服务身份、直接父场景关系类型、直接成员关系类型、世界根均是当前普通节点；
- 场景标记属性类型是当前 `I64` 属性类型节点；五个登记身份非零且互异；
- 世界根具有且只具有该场景标记槽，当前值是未退出 I64 值1，所属根、属性类型和来源服务身份全部匹配；
- 任一具有该属性槽的当前普通节点只有一个当前标记值，材料必须为 I64 1；这类节点且仅这类节点是本轮当前场景候选。

禁止用显示名、节点编码区间、创建时间或父关系出现来猜测场景。场景标记槽为空、重复、错类型、错来源、非1、悬空值或生命周期矛盾均形成稳定缺项。

### 5.3 父子闭包与唯一性

只解释关系类型等于登记 `直接父场景关系类型` 的当前关系，固定要求：关系类型、源、目标均为当前节点；源和目标均为当前场景；`角色或顺序==0`。

以指定根进行确定遍历，并同时检查全部当前场景候选和全部当前父关系：

- 根入度必须为0；
- 每个非根当前场景必须恰有一个父关系；
- 相同源目标多条关系是重复父子关系；同一目标来自多个源是多父；
- 深度优先颜色或等价确定算法检测环；不得依赖容器遍历顺序；
- 所有当前场景和父关系必须属于根的可达闭包；在当前单一正式登记合同下，闭包外标记场景或结构关系即为不可达/跨世界矛盾，不得静默过滤。

合法根只有自身时，当前场景组含根一项，父子关系组为空，仍是完整成功。

### 5.4 直接成员关系

只解释关系类型等于登记 `直接成员关系类型` 的当前关系，固定要求：

- `角色或顺序==0`；
- 源端是根闭包内当前场景；
- 目标端是当前普通节点且不是当前场景；
- 相同源目标重复关系、同一目标属于多个场景、悬空端点、错种类或闭包外源端均为结构矛盾。

本叶只证明成员关系的结构归属。目标普通节点不因此成为 P7 `实际存在`；存在资格和当前归属必须由后继存在事实所有者独立互证。移出树但仍存在、没有当前成员关系的主体不进入结果。

### 5.5 输出和稳定排序

全部校验成功后才构造结果：

- 当前场景按场景节点稳定编码升序；
- 父子关系和成员关系各按关系稳定编码升序；
- 缺项按 `种类、主身份、关系身份、相关身份` 的数值序升序并确定去重。

禁止句柄、容器顺序、SQL 行序、显示名、业务时间戳或地址参与排序。若诊断非空，返回 `内部不一致`、空事实和完整诊断；若诊断为空，返回 `已读取`、完整事实和空诊断。

## 6. 状态、异常、并发与生命周期矩阵

| 条件 | 状态 | 事实/诊断 | 副作用 |
| --- | --- | --- | --- |
| 请求版本、规则或根形状错误 | `入口拒绝` | 空/空 | provider调用0 |
| 请求根不是P18正式根 | `未找到` | 空/空 | P17调用0 |
| P18或P17许可竞争 | `许可拒绝` | 空/空 | 立即返回，零重试 |
| P18登记未加载或坏成功 | `内部不一致` | 空/登记诊断 | 不扫描恢复 |
| P17空代次或坏成功 | `内部不一致` | 空/稳定诊断 | 不返回部分材料 |
| 当前结构任一矛盾 | `内部不一致` | 空/稳定诊断 | 不返回部分树 |
| 复制/排序分配失败 | `资源失败` | 空/空 | 零写入 |
| 其它异常 | `内部不一致` | 空/稳定内部诊断 | 零写入 |
| 合法完整结构 | `已读取` | 完整事实/空 | 零写入 |

读取函数不取得现有服务 `锁_`，不持锁跨 P18/P17，不等待其它读写，也不建立缓存。P18 调用完成后才调用 P17。P17 返回后只操作本轮纯值副本，后续 L1 推进不改变本轮结果的事实截止含义。

本叶内部不重试。后继总快照仅在所有领域读取成功但 G0/G1 不同或领域截止不等时完整重试一次；P19 的许可拒绝立即上传，不消耗漂移重试。

## 7. 验证矩阵

执行至少验证：

1. 合同错、世界规则错、读取规则错、零根或非普通根在 provider 前入口拒绝；
