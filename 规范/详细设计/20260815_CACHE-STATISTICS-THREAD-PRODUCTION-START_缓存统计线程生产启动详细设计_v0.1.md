# 缓存统计线程生产启动详细设计 v0.1

日期：2026-08-15

计划身份：`CACHE-STATISTICS-THREAD-PRODUCTION-START`

当前状态：BIZ 详细设计候选；未登记计划索引，未实施代码，未构建，未接线。

## 1. 目标与完成边界

启动唯一缓存统计支持线程。v0.1 只读取 8110 当前线程生命周期投影组，形成可丢弃的线程统计快照并一次替换当前统计视图；本叶不以 EVENT 线程实现完成为前置，只有上层支持线程组最终组合同时依赖各具体叶。

本叶不读取 DATA-L1—DATA-L3，不统计世界、概念、需求、任务或方法，不建立“任意领域数据读取”万能端口。以后出现具名统计用途时，必须在对应业务详细设计中另列“输入参数 -> 返回数据 -> 空 / 失败语义”，不能扩大本叶。

线程统计只服务控制面板观察和诊断；当前线程数、分类计数、生命周期计数和排序都不是业务事实，不能裁决需求满足、任务完成、方法成功、世界状态或因果。

本叶不实现普通应用装配、支持线程组、阶段 15 总收口、持久证据线程、任务线程、自我治理运行门、SQL 回源、跨进程缓存恢复或其它缓存命名空间。

## 2. 正式依据与当前事实

正式依据：0050、4060、8110、8120，`BIZ-L3-001-04-02` 与 `BIZ-L4-001-04-02-01`；工程归属读取 CODE-FILE-01。

当前事实：

- SUPPORT 候选生命周期 provider 已发布，可复用创建、进入等待和失败安全回收能力；
- EVENT 是同一上层组合中的另一支持线程叶，当前由执行侧独立施工；该顺序不构成本叶依赖；
- 8110 已发布 `线程生命周期投影读取端口::读取当前线程投影组`；
- 当前正式代码没有缓存统计线程生产文件；
- 旧目标图仍写成员 `启动`、当前租约同义复用和旧入口签名，与最终 SUPPORT 的同代逻辑身份墓碑、唯一移动租约和 `支持线程入口端口` ABI 漂移，不能直接施工。

DATA 是否实现不影响本叶，因为本叶没有 DATA 消费需求。

### 3.1 DATA 消费需求

```text
DATA-L1：无
DATA-L2：无
DATA-L3：无
```

8110 线程生命周期投影是运行基础设施投影，不因本叶读取而归入 DATA。不得为满足表格形式新增 DATA 服务或复制 8110 当前投影。

### 3.2 唯一读取参数和返回数据

缓存统计线程只根据以下参数读取：

```cpp
当前线程投影组读取请求{
    .合同版本 = 线程生命周期投影合同版本,
    .运行代次 = 当前普通应用运行代次
}
```

只需要以下返回数据：

```text
读取状态
+ 当前线程生命周期投影组
```

不读取日志文本、显示名称、SQL 行、DATA owner、节点、关系、属性、历史幂等材料或控制台输出。

## 4. 线程统计快照

统计候选精确包含：

```text
合同版本
+ 运行代次
+ 统计规则版本
+ 来源当前消息身份组
+ 当前线程总数
+ 按线程类别计数组
+ 按所属模块计数组
+ 按当前生命周期计数组
+ 系统线程身份已绑定数
+ 未见创建数
+ 前置不完整数
+ 已进入终态数
```

三类计数组分别使用强类型统计项向量，覆盖全部有效线程类别、所属模块和生命周期枚举，按枚举值稳定排序；即使数量为零也保留对应项。来源当前消息身份组从本次组读结果逐项取得，并按线程逻辑身份稳定排序。它是统计快照的来源见证，不是业务事实或跨进程恢复身份。

`已读取 + 空组`必须形成来源身份组为空、全部计数为零的合法快照。不得把空组解释成投影不可用，也不得用旧快照冒充本次全零结果。

相同运行代次、相同当前投影组和相同统计规则版本必须形成语义相同的统计候选。

## 5. 启动函数与唯一租约

启动函数预冻结为：

```cpp
缓存统计线程启动结果 启动缓存统计线程(
    const 缓存统计线程启动请求& 请求,
    const 线程生命周期投影读取端口& 读取端口,
    线程生命周期发布端口& 发布端口) noexcept;
```

该签名属于 BIZ 线程消费端；不产生 DATA ABI。最终实施前只需机械匹配 8110 与 SUPPORT 已发布类型。

启动请求精确包含：

```text
合同版本
+ 运行代次
+ 非零线程逻辑身份
+ 非零进入等待毫秒
+ 非零回收诊断等待毫秒
+ 非零统计规则版本
+ 非零刷新队列容量
```

启动结果精确区分：

- `已进入`：返回唯一移动缓存统计线程租约和内部进入见证；
- `请求拒绝`；
- `身份已使用`；
- `候选创建失败`；
- `进入超时但已安全连接`；
- `失败回收异常`；
- `内部不一致`。

最终 SUPPORT 不提供同义复用，也不允许读取“当前租约”取得第二 owner。同一 `(运行代次, 线程逻辑身份)` 最多使用一次；失败重试必须使用新身份。

## 6. 刷新提交与线程入口

刷新提交是 BIZ 运行基础设施，不是 DATA。公开请求与结果精确冻结为：

```text
缓存统计刷新请求：合同版本、运行代次、统计规则版本
缓存统计刷新提交状态：已接受、队列满、已停收、请求拒绝、资源失败、内部不一致
缓存统计刷新提交结果：状态、可选接受位置
```

v0.1 不为刷新提交建立幂等账。每次合法提交只是一次最佳努力排队；队列满、已停收、资源失败或请求拒绝不改变当前统计视图，也不影响业务结果。接受位置在单一队列锁内从 1 单调分配，零值永远非法。

缓存统计线程租约公开能力精确冻结为：

```cpp
缓存统计刷新提交结果 提交刷新(
    const 缓存统计刷新请求& 请求) noexcept;
缓存统计快照读取结果 读取当前统计快照() const noexcept;
缓存统计停止接收结果 停止接收并取得截止() noexcept;
缓存统计处理位置 读取处理位置() const noexcept;
缓存统计完成等待结果 等待完成到截止(
    const 缓存统计完成等待请求& 请求) const noexcept;
缓存统计未处理刷新丢弃结果 冻结并丢弃未处理刷新(
    const 缓存统计未处理刷新丢弃请求& 请求) noexcept;
缓存统计线程停止连接结果 停止并连接(
    const 缓存统计线程停止连接请求& 请求) && noexcept;
```

`读取当前统计快照` 只返回值式副本，结果区分 `已读取 / 尚无统计 / 统计不可用 / 请求拒绝 / 资源失败 / 内部不一致`；结果只在 `已读取` 时携带快照。尚无统计不等于全零，只有一次正式组读返回 `已读取 + 空组` 才发布全零快照。最近一次合法刷新若因投影暂不可用或资源失败而不可用，旧成功候选可在模块内部保留但不再对外作为本次快照返回；下一次成功刷新才重新进入 `已读取`。停收截止、处理位置、等待和冻结丢弃都绑定同一接受位置序列；冻结丢弃只允许对已停收且未处理位置大于已完成位置的同一截止执行，返回丢弃数量和最终位置，不改当前统计快照。显式停止连接必须先复核“已完成到截止”或“同截止未处理刷新已冻结丢弃”，随后移动唯一 SUPPORT 租约安全 stop + join；前置未闭合仍安全连接但不得返回正常收口。析构只作 fallback。

公开结果形状固定如下；所有可选载荷只在表列成功状态存在，其他状态必须为空：

| DTO | 状态集合 | 必含 / 可选载荷 |
| --- | --- | --- |
| `缓存统计刷新提交结果` | 已接受、队列满、已停收、请求拒绝、资源失败、内部不一致 | 已接受时可选接受位置恰有值 |
| `缓存统计快照读取结果` | 已读取、尚无统计、统计不可用、请求拒绝、资源失败、内部不一致 | 已读取时快照恰有值 |
| `缓存统计停止接收结果` | 已停收、已经停收、请求拒绝、内部不一致 | 已停收 / 已经停收时截止位置有效 |
| `缓存统计完成等待结果` | 已完成到截止、等待超时、截止不匹配、请求拒绝、内部不一致 | 始终返回值式处理位置 |
| `缓存统计未处理刷新丢弃结果` | 已冻结并丢弃、无需丢弃、截止不匹配、请求拒绝、资源失败、内部不一致 | 成功状态返回丢弃数量和最终处理位置 |
| `缓存统计线程启动结果` | 已进入、请求拒绝、身份已使用、候选创建失败、进入超时但已安全连接、失败回收异常、内部不一致 | 仅已进入含唯一移动租约；已创建后的分支返回 SUPPORT 见证 |
| `缓存统计线程停止连接结果` | 已安全连接、前置未闭合但已安全连接、入口故障已安全连接、请求拒绝但已安全连接、租约已消费、内部不一致 | 安全连接状态返回最终 SUPPORT 见证和处理位置 |

模块私有入口实现 `支持线程入口端口::运行线程入口(std::stop_token) -> 支持线程入口结果`，固定编排：

```text
等待刷新提交、停止或队列故障
-> 收到刷新：调用读取当前线程投影组({合同版本, 运行代次})
-> 已读取：构造完整线程统计候选
-> 候选完整：一次替换当前统计视图
-> 暂不可用 / 资源失败：标记该目标版本统计不可用并继续等待
-> 请求拒绝 / 错代 / 未找到 / 内部不一致：固定内部请求或借用服务合同不一致，返回入口内部故障；组读空集合只能由已读取状态表达
-> 队列损坏或替换内部故障：返回入口内部故障
-> 停止：停止取新刷新，完成当前已取刷新后返回已响应停止
```

缓存统计结果不能反写 8110 投影，不能发布 DATA 或业务事实，也不能改查 SQL。

## 7. 所有权、并发与停止

- 缓存统计线程租约内部拥有地址稳定的刷新队列、统计视图、模块私有入口和唯一 SUPPORT 候选租约；裸 SUPPORT 租约不公开。
- 读取端口为 const 借用，发布端口为可变借用；生命周期均必须覆盖缓存统计线程租约。
- 统计候选完整后才以一次值式替换公开；半候选不可见。
- stop 后不再取出新刷新；已经取出的当前刷新最多处理一次。停收本身不触发 stop，允许入口继续处理到截止；冻结丢弃后入口不得再取出被冻结范围。
- 析构只作安全 fallback，不能替代正式阶段 15 的停收、处理截止、未取出材料接管和连接证据。
