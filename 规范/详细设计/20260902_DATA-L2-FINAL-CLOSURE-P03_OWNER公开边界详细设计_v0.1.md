## 1. 目标与不变量

将 `L2节点族身份来源事实` 从“公开结构身份加 L1 物理分区证明”收敛为只表达公开结构身份。

```text
L1 owner / owner 生命周期 / 写端口
    = L2 服务私有路由、写集分区和内部一致性校验材料

节点族 + 节点 + 族锚点 + 归属关系类型 + 归属关系 + 角色/顺序
+ 节点、锚点、关系类型、归属关系的生命周期
    = L2 公开身份来源事实
```

本项不得改变以下不变量：

1. 各结构 owner 的唯一性、L1 写端口私有性和服务内 owner 校验继续存在；
2. 调用方不能选择、取得、回显、摘要化或借来源字段重建 owner；
3. 节点、族锚点、关系类型、归属关系四份生命周期暂时保留，P04 单独裁决其最终公开边界；
4. 结构读取仍在同一事实截止互证，owner 内部错误仍映射既有结构化失败；
5. 旧含 owner 的 L1 恢复材料继续只由 L1 内部读取、校验和审计，不能重新投影为当前 L2 DTO。
6. P03 只收缩 `L2节点族身份来源事实`及直接承载它的身份来源读取结果；状态当前选择、墓碑和其它具名 L2 结果中的旧 owner 兼容字段不在本项范围，必须由 P04 / P08 按各自 ABI 裁决，不得以本项完成宣称全 L2 公开面已经无 owner。

## 2. 当前事实与替换点

1. `L2结构公共.数据.h` 的 DTO 当前把 `写入所有者` 和 `所有者生命周期`置于公开字段中，完整性判断也直接要求两者有效。
2. 七族世界服务、语言、概念以及 ARCH-L4 兼容记录面在服务内部已经读取 owner 事实，并用它验证节点、关系、值和本族定位；这些内部读取不能删除。
3. 当前唯一生产代码把公开 owner 再次作为 L1 请求输入的位置是 `L2特征结构服务::按存在读取全部当前特征`。L1 一致当前投影的 `所有者`集合只要求和回显 owner 事实；节点和关系组投影并不依该集合筛选。因此该函数可以移除 owner 集合，而保留节点与特征实例 owner 的内部关系校验。
4. `L2方法结构服务`和`L2需求结构服务`仍构造同一公共 DTO；它们是 ARCH-L4 兼容记录面，必须一并适配，否则公共 DTO 缩减后无法编译。其业务 WIP 不纳入 P03，只修改身份来源构造的精确字段片段。
5. 隔离候选首次 Debug 重建还发现 `业务/初始化.系统世界树根.inl::身份来源事实相同`直接比较该公开 DTO 的 owner 与 owner 生命周期。该函数只用于同一公开读回的值式相等，不拥有 owner、写端口或 L1 事实；继续比较会使上层重新依赖已撤出的物理分区。它必须只比较 P03 后保留的十项公开字段和四份公开生命周期，不改动初始化、装配或启动行为。

## 3. 冻结 DTO 合同

`L2节点族身份来源事实` 的字段顺序固定为：

```text
节点族
节点稳定编码
族锚点稳定编码
族归属关系类型稳定编码
族归属关系稳定编码
角色或顺序
节点生命周期
族锚点生命周期
关系类型生命周期
归属关系生命周期
```

以下公开字段永久删除：

```text
写入所有者 : L1结构所有者身份
所有者生命周期 : L2生命周期
```

`L2节点族身份来源事实完整(来源, 截止)`不再检查 owner；仍要求剩余十项完整、角色为 1、四份生命周期在截止可用。服务内部必须在构造该 DTO 前确认 owner 事实、节点/锚点/关系类型/关系的实际 owner 与私有定位一致。

## 4. 施工映射

| 切片 | 施工动作 | 保留的内部校验 |
| --- | --- | --- |
| 共同 DTO | 删除两字段及两项公开完整性谓词 | 无变化；服务内部 owner 校验不下沉到 DTO |
| 场景、存在、特征、状态、动态、因果、语言、概念服务 | 每个来源 DTO 聚合初始化移除 owner 与 owner 生命周期实参 | 当前/历史 owner 读取、节点/关系 owner 比对、错误映射不变 |
| 场景、方法、概念、普通概念、语言数据头 | 来源“全部当前”谓词移除 owner 生命周期一项 | 其余四份生命周期继续判定 |
| ARCH-L4 需求/方法兼容服务 | 仅更新来源 DTO 构造，保留现有业务 WIP | 不改需求/方法业务语义或新增入口 |
| 特征按存在读取 | 删除以公开 `存在身份来源->写入所有者`组成 L1 请求的旁路 | 仍先经存在公开读取确认存在身份，并在结果投影中核对实例关系和内部 owner |
| 系统世界树根初始化值式读回 | 从 `身份来源事实相同`删除 owner 与 owner 生命周期比较 | 仍逐字段比较全部 P03 保留的公开身份材料；不接触 L1、不新增读取或 owner 判断 |

## 5. 恢复与旧格式矩阵

| 材料 | P03 处置 |
| --- | --- |
| L1 owner 事实、端口建立账、节点/关系/值事实 | 保持现有内部恢复、互证和审计；不变更格式 |
| `L2节点族身份来源事实` | 派生读取 DTO，不是 L1 持久事实载荷；不建立新的持久格式 |
| 旧的身份来源 DTO / 日志 / 测试材料中的 owner | 仅作旧 ABI 诊断、内部解码或审计输入；不得由现行身份来源读取重新返回 |
| 当前身份来源读取结果 | 只返回收缩后的 DTO；任何残留 owner 字段或换名证明均为失败；其它具名 L2 结果不由 P03 裁决 |
