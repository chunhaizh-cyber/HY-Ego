# 方法完整复制与任务绑定详细设计

身份：METHOD-GRAPH-INSTANCE；版本：v0.1；日期：2026-10-10。

代码起点：`9486a070621a598a599c86080554a699cb865827`。本设计由本窗口用户“完整复制方法树、如何使用由任务类决定；任务绑定副本根，副本保存来源方法”的明确裁决形成。当前服务值结算未提交现场是需要保护的独立切片，不是本设计的实现依据或交付内容。

## 1. 目标和边界

实现方法完整图复制和任务对已生成副本根的显式绑定。方法类复制结构，任务类决定何时使用；复制不按目标筛选条件、结果或路径，不执行方法。分支汇合和循环保持原结构，不能将图按树展开。

本轮不实现自动筹办选择、复杂方法解释执行、参数绑定持久化、经验学习回写、实例更换或删除、跨进程恢复、概念值域快照。外部概念仍是引用，因此副本结构独立不等于外部可变概念内容被冻结；SERVICE-SETTLEMENT-INSTINCT-CONSUMER 的初始条件概念扩域问题继续未解决。

直接依据为用户当前裁决，以及现行 0050、3200、3300、5350、5360 中不冲突的规则。当前代码依据是 `新_方法公共类型.h`、`新_方法类.h/.cpp`、`新_任务类.h/.cpp` 和 `基础数据集.h`；知识库尚未覆盖现行源码，没有可直接采用的方法复制用途卡。本轮扩展原 owner，不创建第二方法仓库。

## 2. 当前可复用能力和物理位置

方法类已有方法头、Vm、有序参数规格、C/R 配对、组合步骤、入口步骤和结果转移。根成员字段登记每个方法；`读取方法信息`、`查询候选方法`、`查询本能登记结构`均依赖这套结构。建立入口按定义去重复用，不能拿它循环调用冒充复制，否则会返回旧身份。

任务已有全局递归互斥、完整读回、节点字段写入和反向字段查询；`最近方法节点`只定位实际执行，不能兼任筹办期绑定。任务类已经持有方法服务引用，无需装配或构造函数变化。

基础数据集当前没有组合事务。沿用 3200 第16节已有进程内 owner 锁和失败清理边界；本轮不宣称底座原子、崩溃恢复或发布未知闭合。新增方法发布在 method 锁内收口，任务绑定在 task 锁内收口。原子持久化仍是上级目标，不在本轮补造。

所有代码原地扩展，唯一允许位置为：

| 文件 | 变更 |
| --- | --- |
| `海中鱼巣/领域/新_方法公共类型.h` | 复制状态、映射、结果；方法信息新增来源和实例根 |
| `海中鱼巣/领域/新_方法类.h/.cpp` | 复制入口、元数据读回、召回隔离及组合引用同图校验 |
| `海中鱼巣/领域/新_任务类.h/.cpp` | 绑定结果、任务字段及显式绑定入口 |

没有新生产文件，不修改工程。辅助函数仅在各自 `.cpp` 私有区域。诊断责任均为结构化向上返回，不弹窗、不记录治理消息、不自动重试。

## 3. 公开合同

`新方法信息`尾部新增：

```cpp
std::optional<稳定编码> 来源方法节点;
std::optional<稳定编码> 实例根节点;
```

抽象方法两字段均不存在；副本方法两字段均存在。每个副本方法的来源是其对应抽象方法；同次复制图中的所有方法共享一个新实例根，顶根的实例根等于自身。任一字段重复、仅存在其一、目标类型不符、来源也是实例或图根不一致均为结构不一致。字段只能由复制过程创建，无公开改写入口。

在公共类型头声明：

```cpp
enum class 新方法复制状态 : std::uint8_t {
    已复制 = 1, 入口拒绝, 尚未初始化, 方法不存在,
    来源不是抽象方法, 结构不一致, 资源失败
};
struct 新方法节点映射 final {
    稳定编码 源节点;
    稳定编码 实例节点;
};
struct 新方法复制结果 final {
    新方法复制状态 状态 = 新方法复制状态::入口拒绝;
    std::optional<稳定编码> 方法实例节点;
    std::vector<新方法节点映射> 节点映射组;
};
```

在方法类 `获取方法`附近声明并在同名 `.cpp` 实现：

```cpp
新方法复制结果 复制方法(稳定编码 来源方法节点) noexcept;
```

来源必须是可完整读回的抽象方法；本轮拒绝实例再复制，避免隐式新增来源链语义。停用方法可以完整复制，启用状态照抄，复制不赋予执行资格。每次调用生成不同副本，不按结构复用。成功映射覆盖本轮全部方法内部节点，按原编码排序且一一对应；不包含字段关系编码、类型/字段定义、外部概念或角色节点。任何失败返回空根和空映射。

`新任务信息`尾部新增 `std::optional<稳定编码> 方法实例节点;`，与最近方法及最近执行字段分开。复用`新任务操作状态`，末尾追加`方法实例不合法 = 28`、`任务已有方法实例 = 29`、`方法实例已被占用 = 30`，不得改变既有枚举值。

任务类公开入口：

```cpp
新任务操作状态 绑定方法实例(
    稳定编码 任务节点, 稳定编码 方法实例根节点) noexcept;
```

只绑定已存在副本，不暗中复制。首次成功返回`已修改`，相同绑定返回`精确重复`；不存在使用既有`方法不存在`，非副本或内部子方法返回`方法实例不合法`，其它拒绝复用既有结构化状态。读取通过已有 `获取任务`完成，不在任务上重复保存抽象方法编码。

## 4. 完整复制范围

从源方法沿每个组合步骤的`调用方法节点`遍历方法闭包，每个方法只访问一次；允许共享子方法、调用循环和步骤转移循环。针对每个方法，全部结构字段按当前 schema 保存，而非按欲执行路径裁剪。

| 拥有者 | 纳入复制的子结构 |
| --- | --- |
| 方法 | 方法头、Vm、全部C/R配对、全部组合步骤、全部结果转移 |
| Vm | 全部参数规格节点 |
| 参数规格 | 全部参数特征规格节点 |
| C/R配对 | 条件节点、结果节点 |
| 条件节点 | 全部条件项节点 |
| 结果节点 | 全部结果项、禁止结果项节点 |
| 组合步骤 | 被调用方法的完整闭包 |

复制各节点现有 schema 的全部直接值和字段，包括顺序、作用域、实现方式、启用状态、登记名、关系规则、主要结果标记、结果确认要求。已知结构中方法内容由字段承载，没有需要复制的世界外部父子关系。类型字段和字段定义节点本身不复制。

下列引用按映射改写：方法→头/Vm/C-R/步骤/转移，Vm→所属方法/参数规格，规格→子规格，配对→C/R，C/R→项，组合入口、步骤所属及调用方法、转移所属方法/当前步骤/当前结果/下一步骤。其目标必须在本次映射中。

参数角色、存在/特征/二次特征/状态动态/方向/匹配/等待条件概念，以及头部概念组全部保持原编码；不能仅因为某编码恰好出现在映射中就改写语义上外部引用。来源方法字段也保持源编码。

读源时校验持有结构类型、必需/可选字段基数、有序项顺序、Vm所属、步骤所属、结果转移当前/下一步骤属于本组合、当前结果属于当前步骤调用方法。损坏、悬空或冲突结构在写入前拒绝。内部 owned 子节点不得同时被不同 owning 字段非法共用；调用方法可以共享，由映射保持共享关系。

## 5. 复制过程、发布与失败

1. 取得现有 method 全局互斥，校验初始化和输入，读取并校验完整闭包，保存值式节点/字段材料；遍历采用已访问集合，不能递归展开循环。
2. 在写入前准备足够的映射、节点和字段回滚容器空间。分配全部新节点，记录映射；每个已分配身份立即进入无后续分配风险的清理记录。
3. 为所有新节点写入字段，内部引用使用新编码；每个副本方法增加来源字段和共同实例根字段。
4. 最后为全部新方法增加原有方法组织根成员边，仍持 method 锁；完整读回核对结构和映射之后才返回。不得通过公开建立方法入口的去重路径发布。
5. 任一步失败，逆序删除本轮字段（含根成员边），再删除本轮节点。遇异常同样清理；清理失败返回结构不一致，不冒充资源失败已无残留。源节点及外部引用目标永不删除。稳定编码消耗不回退。

通过 owner 的读写不观察中间图；直接绕过 owner 扫底座不在这项保证内。底座没有故障注入或事务恢复能力，不得虚构已覆盖崩溃原子性。

## 6. 副本隔离和通用调用兼容

所有副本方法仍是正式方法，可用 `获取方法`、`是方法节点`直接读回；它们不能作为抽象方法进入 `查询候选方法`、`查询本能登记`或建立方法知识的结构去重复用。登记名查找必须跳过全部副本，否则相同登记名会变成重复登记冲突。

本能函数登记名原样复制，调用器仍以该名称查 C++ 入口；参数场景的`方法节点()`必须保留副本身份，并与调用请求相等。不得临时改为抽象方法编码以蒙混校验。现 HEAD 网页函数通过管理器转发入口，现有通用解析可以复用。专项以一个注册的只读本能函数验证副本身份正确传到函数，且调用一次。

未发布服务值结算函数额外比较登记方法编码，属于旧切片独立消费者，本轮不迁移、不声称支持它。该 WIP 必须原样保留；基于 HEAD 的验证不引用它。

添加组合步骤及读回中补齐隔离：抽象方法只能引用抽象方法；副本方法只能引用同一实例根的副本方法。现有结果转移所属校验继续保留。不存在将任意可复用方法直接挂回实例内部的旁路。

## 7. 任务绑定与并发

任务类新增私有字段节点`任务方法实例字段`，初始化照现有 schema 模式建立。旧任务缺省为空，不能因新增字段导致现存任务失效。

绑定在 task 全局互斥内完成：完整读取任务，读取方法确认来源和实例根，实例根必须等于请求方法自身；反向查询`任务方法实例字段`确认没有其他任务占用。固定锁序为 task→method→基础数据集；方法复制不回调任务，不建立逆向持锁路径，也不持锁调用本能函数。

精确重复在校验根和唯一占用后返回，不受之后任务已进入执行或终态影响。已有不同绑定返回`任务已有方法实例`，不替换。首次绑定仅允许任务处于`已建立`、`待查找方法`、`待检查条件`、`等待条件`；其余返回`任务状态不允许`。

同一全局 task 锁保证两个任务并发绑定一个副本最多一方成功，同一任务并发绑定两个副本也最多一方成功。首次绑定只写一条节点字段并完整读回；读回不符则删除本次关系，原副本仍然是合法的未绑定产物，不能代替调用者删除。

绑定不修改任务状态、候选材料、最近方法、执行记录、需求或世界特征。已绑定副本与任务共存；本轮没有解绑、替换和删除入口。任务终结不自动删除实例，确保来源与执行经验仍可追溯。

在`开始方法执行`新增最小采用守卫：有正式绑定的任务，请求方法须可由方法owner读回且`实例根节点`等于该任务绑定根；允许同一复制图内的子方法实际调用，但不允许来源抽象方法、其他复制图方法或任意节点。守卫失败返回`方法实例不合法`，零新X、零状态变化。未绑定旧任务保持既有入口合同，本轮不强制迁移其生产调用；该兼容边界不能被描述为全部任务已经采用实例。已有X精确重复仍需遵守其既有身份与状态合同，不允许借重复请求更换方法。
