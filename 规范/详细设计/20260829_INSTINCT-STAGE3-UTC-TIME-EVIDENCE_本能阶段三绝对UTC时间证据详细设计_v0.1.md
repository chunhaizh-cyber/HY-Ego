# INSTINCT-STAGE3-UTC-TIME-EVIDENCE 本能阶段三绝对 UTC 时间证据详细设计 v0.1

日期：2026-08-29

状态：设计完成；只闭合实例状态变化所需的绝对 UTC 发生时间来源

## 1. 目标与完成边界

本设计建立一个公开、强类型、无持久副作用的 UTC 时间证据适配器，并让生产启动用它替代直接调用 `std::chrono::system_clock` 形成本能根首次状态时间。后继安全 / 服务被动维护可以复用同一入口取得 `L2特征当前值变化记录请求_v1::变化UTC纳秒`。

本切片只回答“本次记录发生在 Unix epoch 的哪个正 UTC 纳秒”。它不回答经过了多少完整秒，不证明跨运行代次连续时长，不推进维护游标，不计算 A/V，不读取 L/H、合同、安全事件或活动集合，也不形成状态 / 动态。

## 4. 公开 ABI

```cpp
inline constexpr std::uint32_t UTC时间证据合同版本_v1 = 1;
inline constexpr std::uint32_t 系统UTC时间源版本_v1 = 1;

struct UTC时间证据读取请求_v1 final {
    std::uint32_t 合同版本 = UTC时间证据合同版本_v1;
    std::uint32_t 期望时间源版本 = 系统UTC时间源版本_v1;
};

enum class UTC时间证据读取状态_v1 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    时间源版本漂移 = 3,
    计数不可表示 = 4,
    内部不一致 = 5
};

struct 可信UTC时间证据_v1 final {
    std::uint32_t 合同版本 = UTC时间证据合同版本_v1;
    std::int64_t UTC纳秒 = 0;
    std::uint32_t 时间源版本 = 系统UTC时间源版本_v1;
};

struct UTC时间证据读取结果_v1 final {
    UTC时间证据读取状态_v1 状态 = UTC时间证据读取状态_v1::请求拒绝;
    std::optional<可信UTC时间证据_v1> 证据;
    bool 成功() const noexcept;
};

class UTC时钟适配器 final {
public:
    UTC时间证据读取结果_v1 读取当前UTC时间证据_v1(
        const UTC时间证据读取请求_v1&) const noexcept;
};
```

适配器无配置、可复制且无状态。请求不携带调用方声明的 UTC 值、运行代次、时间纪元、完整秒或事实截止。

## 5. 算法与错误分账

固定顺序：

```text
校验合同版本与期望时间源版本非零
-> 版本不等于 1 时返回时间源版本漂移
-> 调用 std::chrono::system_clock::now()
-> 转换为自 Unix epoch 起的 nanoseconds
-> 值 <= 0 返回内部不一致
-> 不能以 int64_t 表示返回计数不可表示
-> 返回已读取和完整证据
```

默认请求合法。合同版本错误或期望版本为零返回请求拒绝；非零但不支持的时间源版本返回时间源版本漂移。所有非成功结果的 `证据` 必须为空。`成功()` 必须同时验证状态、证据存在、版本逐字段一致且 `UTC纳秒 > 0`。

适配器不得把多个读取结果强行修正为单调递增，不得在时钟回拨时补造时间，也不得把 UTC 差值用作完整秒、TTL 之外的运行时长或维护进度。调用者若需要多个事实的业务顺序，仍由事实代次、正式发布序和领域合同裁决。

## 6. 生产接线

`运行普通程序(...)` 在本能根初始化前构造局部 `UTC时钟适配器`，调用 `读取当前UTC时间证据_v1`。只有完整成功时，才把证据中的正 `UTC纳秒` 转为现有请求要求的 `std::uint64_t` 并提交 `本能根运行初始化请求_v1`；非成功映射为现有 `程序失败阶段::本能根运行初始化`，不得创建自我线程。

启动继续用同一数值形成本次运行代次只是现有兼容边界，本适配器不声明 UTC 时间就是运行代次的长期身份规则。后继若拆分运行代次，只修改启动编排，不改变本适配器 ABI。

## 8. 验证矩阵

- U00 默认请求成功，载荷版本为 1、UTC 纳秒为正。
- U01 合同版本错误：请求拒绝、空载荷。
- U02 期望时间源版本为零：请求拒绝、空载荷。
- U03 非零未知时间源版本：版本漂移、空载荷。
- U04 连续两次合法读取均完整；不要求后值严格大于前值。
- U05 ABI consumer 可在 Debug / Release 中 import、构造并调用公开入口。
- U06 生产启动不再直接调用 `system_clock::now()` 形成本能根初始化时间，且真实消费证据字段。
- U07 两配置全工程构建与专项通过；strict 和精确 diff-check 通过。
