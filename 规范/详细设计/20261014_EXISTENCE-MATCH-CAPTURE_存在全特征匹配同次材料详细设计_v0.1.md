# EXISTENCE-MATCH-CAPTURE 存在全特征匹配同次材料

日期：2026-10-14；版本：v0.1；代码基线：`eef0713f6c1dbe8eef4d6d0c155b6b758705f04c`。

## 1. 最早闭合叶与现状

本叶修复“服务对象材料中的特征快照与匹配结果可能来自不同读取”问题，为后续 task 保存不可变取得材料提供可靠来源。`服务对象本能运行服务::读取存在材料()` 当前先读取 E/F，再调用 `匹配存在概念()` 重读 E/F/EC/FC；枚举结果不一定对应返回的材料。不能把这样的材料直接用于因果或学习。

本叶不改变现实人类特征、不改变 Vt；只增加中立只读捕获与比较，并替换现有本能的观察消费者。实际动作发布方式暂不迁移，独立治理材料动作、材料 FT、需求目标及因果交付另由后继完成。不能据本叶宣称本能材料已成为正式因果端点。

复用既有 `获取存在概念/获取特征概念`、特征类型根定位、准确值材料读取和 `概念_特征类::比较值域` 的纯值分支；E/F 捕获不能调用普通 `获取存在/获取特征`，原因和内部结构投影合同见第3.1节。不改基础数据集、概念_存在类或概念_特征类，不接触名称/指代切片。

## 2. 公开 DTO 与接口

    特征概念材料物理类型 材料类型;

不保存聚合统计、名称、上位下位遍历结果、命中次数或完整 F 历史。准确值若为非存在引用的稳定编码，必须携带相应不可变完整值材料；I64 和存在节点引用不携带该字段。值域中的完整材料有限枚举仍引用值 owner 的不可变身份，不将枚举解释为运行时谓词。

F 新增 public 只读成员：

```cpp
std::optional<新特征匹配定义快照> 捕获特征匹配定义(稳定编码 FC) const noexcept;
std::optional<新特征匹配实例快照> 捕获特征匹配实例(稳定编码 F) const noexcept;
新特征值域关系比较结果 比较捕获特征值域(
    const 新特征匹配实例快照&, const 新特征匹配定义快照&) const noexcept;
```

第一项读 FC 和类型根，核验同树材料类型/单位/规则一致并返回值式定义；第二项按第3.1节只读一次 F 的参与字段，再组合其 FC 定义及准确材料，不调用普通 `获取特征()`，不再读其当前值来求匹配。不存在的顶层请求返回空；已声明引用缺失、坏字段、编码异义、资源异常均工程终止，不空返回。

struct 新存在概念匹配采集结果 {

必需项快照也带默认相等比较。现有 `新存在概念匹配结果` 同步追加默认相等比较，不改变字段或枚举；这样原服务对象 DTO 的默认比较仍可编译。新增 public：

```cpp
新存在概念匹配采集结果 采集存在概念匹配材料(稳定编码 E, 稳定编码 EC) const noexcept;

```

第二函数只比较传入材料，不重读 E/F/EC/FC，不保存任何事实；以 F 的捕获比较入口计算每项。它可以读取已经捕获编码所指的不可变值材料以完成完整枚举比较，但不能读取任务/需求/存在归属等当前外部 owner。`尚缺固定比较依据特征组` 由采集函数根据快照的域分支/规则计算，是解释材料不足的具名信息，不是业务反例。

旧 `匹配存在概念(E,EC)` 保留签名，委托新采集入口返回 `.匹配`，不保留第二份重复算法。它的既有全特征/空定义语义不变；动态依赖未经捕获的域采用本叶明确的保守材料不足。

## 3. 捕获顺序与一致性边界

1. 不存在的 E 返回“不符合”且无材料；非法或不可读目标 EC 为工程错误。
2. 按第3.1节读一次 E 结构投影和一次目标 EC；EC 只投影必需 FT/FC 清单，不复制名称、上下位关系或统计。
3. 每个必需项调用 F 的定义捕获入口；其实际类型根必须等于清单 FT。每个 E 顶层 F 调用实例捕获入口；按 F/FT 排序以便稳定复核。
4. 将同一次捕获集合交纯材料比较函数。不得再调用 `匹配存在概念()` 重新读取。
5. 捕获返回前，对 E 的身份、专属 EC、顶层 F 成员及本次 EC 必需清单、每项 F 语义投影/定义再读一次做相等复核。只比较参与计算字段，名称或统计变化不导致漂移。若不一致，本次返回“材料不足”，材料仍保存第一次捕获内容，`尚缺固定比较依据特征组` 不滥用为漂移清单；在结果追加 `bool 采集期间材料变化 = false` 标明。此次不重试，不把第一次结论当当前有效结果。
6. 无漂移时返回第一次集合和它的计算结果。并发 ABA、跨 owner 同刻原子性不在保证范围；这是一组明确来源材料的结果加前后复核，不是全场景原子快照。

漂移时 `.匹配=材料不足` 是本次当前准入结论，不宣称已捕获旧内容本身不符合。返回前必须清空 `.匹配.不符合特征类型组`、`.匹配.缺少特征类型组` 和 `尚缺固定比较依据特征组`，只保留变化标志、材料不足以及第一次捕获内容，避免把旧清单当成当前反例。旧内容仍能交 `比较存在概念匹配材料()` 复算其固定结果；该纯函数不读取漂移标记，也不因当前变化修改捕获材料。

service-object 仍复核窗口来源前后完全一致；来源变化返回既有空观察材料、不伪造人类不符合。该函数仅在读取期间保持的来源正式存在有结构损坏时终止。

### 3.1 捕获专用物理投影，禁止隐含 live 业务验证

登记前复核确认当前 `获取存在()` 会读取各 F 的完整信息，`获取特征()` 又会对当前/历史存在引用调用 `准确值与概念相容()`，经 `存在节点属于概念()` 查询当前归属。若归属已改变，普通 getter 可以空返回；不能把这种空返回在捕获链解释为数据损坏。此次只在 E/F 已授权文件内增加窄结构投影，不修改普通 getter 及其原有合同。

E cpp 匿名命名空间新增局部结构及 helper（不新增公开 getter）：

```cpp
struct 匹配存在结构投影 {
    稳定编码 存在节点, 专属存在概念节点;
    std::vector<稳定编码> 顶层特征节点组;
    friend bool operator==(const 匹配存在结构投影&, const 匹配存在结构投影&) = default;
};
std::optional<匹配存在结构投影> 读取匹配存在结构投影(稳定编码 E);
```

该 helper 在 E 自己的锁中只读取 E 节点类型、唯一专属 EC 字段、实例特征字段组；编码必须存在，字段表示和数量必须合法，同一 F 持有字段重复为结构错误。它不调用 `获取存在()`、F getter、F 比较或存在归属。释放 E 锁后由成员采集函数读专属 EC，核验种类/对应 E；随后逐个调用 F 捕获入口，F 的 `上级特征节点` 必须为空，才能认定为顶层。第二遍 fresh 复核也用同一投影路径，不能重新落回普通 getter。

F 的 `捕获特征匹配实例()` 在自身锁内使用已有字段解码 helper，读取正式节点类型、唯一 FC、父关系、实例区间字段、实例单位字段和当前值字段。父关系至多一个，存在时核验父节点为特征类型并保存上级编码；不会递归读父当前值。复用 `读取值域节点()` 解码实例区间，但不读取历史域/命中/标准值，不执行聚合或历史重复比较。当前值是 I64 时只校验物理分支；非存在引用编码读取不可变值材料并核验物理类型；存在引用编码只校验有效、节点真实存在，不查询是否属于某 EC。后者随后必走第4节保守不足。

当前值或实例区间超出其来源 FC 定义，是后续业务包含比较的输入，**不是物理读取失败或工程错误**。实例单位与目标单位不同保留在快照，交比较层返回不相容/材料不足；非法单位引用、错误物理分支才是结构错误。不能在投影中调用 `准确值与概念相容()`、`准确值命中值域()`、任务集合条件或存在归属接口。

FC 读取已核对可复用：`获取特征概念()` 对任务集合/存在引用只校验字段表示及引用节点存在，末尾 `规范化定义()` 只做形状、规则与编码正规化；不调用任务成员/存在归属 provider。`比较单特征概念(FC,FC)` 仅通过 `读取单概念路径()` 核验概念类型与父链并取得 FT 根，不进行域包含或 live 业务比较。允许以上两项以及根 FC 的结构读取；禁止用 `比较特征概念值域关系()` 代替类型根定位。EC 的 `获取存在概念()`/`读取特征组()` 只调用该结构定位，允许复用。

这项调整不扩大公开 getter 或持久结构；仅给已冻结实例快照增加 `上级特征节点`，并明确三捕获函数的内部读取边界。旧普通读取的历史校验和语义验证不迁移、不弱化。

## 4. 捕获比较算法和支持范围

先按捕获类型根识别同 FT，不再通过实时概念域关系猜同类；同 FT 两个顶层 F 是工程错误。实例/定义材料类型、规则和单位不相容时，保留原全特征判断的“该必需 FT 尚缺可用材料”含义；同一正式树内定义自相矛盾为工程错误。

准确值优先；无准确值时用实例区间；两者均空为缺少。将 I64 准确值转单点区间；完整材料准确值转单点完整材料枚举；结构化 I64 目标域与准确 I64 数组按捕获结构模板转换为各分量单点。使用捕获目标域，不读取当前 FC 域。

随后只调用既有 `概念_特征类::比较值域(材料类型, 左值域, 右值域)` 的以下纯值形状：I64 闭区间组、全材料域、完整材料有限枚举、结构化 I64。传入前验证形状及准确材料类型，复用当前正规化/包含/相交算法，不复制业务集合算法。

下列情况必须在调用 `比较值域` 前拒绝进入可能回调外部 owner 的分支，**包括左右域恰好相等或另一方全域的早退情形**：

- 任一侧为 `特征概念任务集合值域`；
- 任一侧为 `特征概念存在引用值域`；
- 材料类型为存在节点引用，或比较规则为存在身份精确、服务任务集合身份判等。

这些不是读取失败，也不是“不符合”，而是尚无固定外部依赖证据；F 捕获比较返回既有 `规则不支持` 且无关系值，存在匹配把该 FT 加入缺少和 `尚缺固定比较依据特征组`。不得执行 live provider 再声称固定结果。后继若需要这些域，单独设计外部依赖快照。本叶不新增枚举语义或权限。

关系为相等或右包含左，满足该必需项；准确值不命中，或区间与目标分离，记不符合；区间只是相交/覆盖目标而非被包含，记材料不足。全部 FT 合取：任一已确定不符合优先；否则有缺少为材料不足；否则匹配。空定义无约束，合法存在即匹配，不以名字/性别/物种补定义，也不要求 E 必须有特征。

比较返回仍为现有 int64 五关系；没有二次特征实例、大小方向或速度。工程异常、非法捕获结构、内部比较失败进入日志/弹窗/终止，不转成规则不支持。

## 5. 真实消费者迁移

`新服务对象材料` 追加 `optional<新存在概念匹配采集结果> 概念匹配采集`。本叶实际端口返回时必填；已有 `实际特征快照组` 保留兼容，但由同一次采集的实例投影填充：F、FC、当前值、实例单位、实例区间；历史/标准值/统计字段留空，不另读 F。注释明确这是当前参与匹配投影，不是完整历史快照。

`服务对象本能运行服务::读取存在材料()` 只调用一次新采集入口；实际 E、专属 EC、匹配枚举、属于人类、可选服务对象和所有特征快照均从返回材料派生。采集漂移只返回材料不足、`属于人类=false`、服务对象为空；保留采集证据，不能把漂移解释为确定非人类。`属于人类` 是匹配状态的便捷投影，不是第二判据。

本能原先“动作先登记，再读取材料”的顺序不变；函数返回本次实际材料。运行服务不得再次读取 E/F 重新判人类。`新_本能函数集::获取服务对象()` 不因材料不足生成其它动作或建立正式需求。

数据只存在于此次值式返回，未保存到 Vt 或世界树；本叶不增加持久字段、GC、事务、恢复、方法头参数或工程登记。未持久化快照不能称为正式因果材料。

## 6. 锁、错误与验证

不持存在锁跨特征/概念 owner 回调；各读取函数按已有锁取得副本。捕获比较纯值分支不访问 E/task 当前事实，避免 FC→E→FC 环。采集失败遵循已有统一 `工程异常终止`；读取到合法变化按第3节处理。

允许修改仅：`领域/新_特征类.h/.cpp`、`领域/新_存在类.h/.cpp`、`领域/服务对象.材料合同.h`、`业务/服务对象.本能运行服务.cpp`；必要注释可以修改 `领域/新_本能函数集.cpp` 的获取对象局部，不能改变其它方法。

默认统一实际项目 Debug/x64 编译链接，不运行测试。显式测试时覆盖空定义/完整匹配/缺FT/不符合/区间相交/同FT重复工程终止、准确值与返回快照一致、定义漂移、来源漂移、四种纯域、两种动态域保守不足、无新增S/D/需求和旧入口委托。

完成只证明一致材料的生产读取和编译工程通过；task材料持久化、内部治理动作迁移、因果交付、自动方法串联未完成。
