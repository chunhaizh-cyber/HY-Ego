# CORE-RETIRE-P1 逐函数逐节点实现分析

日期：2026-07-30
版本：v0.1

## 1. 公共实现不变量

全部函数遵守：值式输入输出；类型数值先界限复核；仓库锁内只访问本仓内部结构；跨仓端点复核在不持有本仓锁时完成；结果按关系编号或完整物理键确定排序；空集合是合法结果；资源分配失败不产生半写集。

## 3. `完成发布()` 变更节点

现有函数在 CR-F14 全确认后进入无失败区，CR-F37 顺序固定为节点创建、新关系、关系变更、索引创建、索引移除、节点删除。每个底层 `完成发布` 必须 `noexcept` 且前态不一致立即终止，不返回可继续运行的半结构。专项自检可对自检自建且无领域记录的核心夹具使用空参与者组；生产领域服务调用 CR-F57 时必须把自身领域类型化记录参与者放入现有写执行器同一参与者组，CR-F57 不伪造领域记录退役顺序。
