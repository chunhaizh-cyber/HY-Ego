# 按来源需求当前承接任务组消费详细设计 v0.1

日期：2026-08-16

计划身份：`TASK-CURRENT-ACCEPTANCE-GROUP-BY-DEMAND-CONSUME`

## 1. 目标与完成边界

实现当前任务树的第一个输入叶：

```text
BIZ-L4-004-02-02-01 v0.2
任务业务服务::按来源需求读取当前承接任务组
-> 只经 DATA-EXT-13 一次有界读取指定来源需求在同一非零 G0 下的全部当前承接关系
-> 逐字段互证后形成按任务稳定身份排序的零或多项 BIZ 值式组
```

调用方给出来源需求、运行代次、父级共享事实截止 `G0`、范围 / 规则版本和当前承接关系数量预算。成功返回 optional 有值的完整任务组；没有当前承接关系时 vector 为空但仍是已读取成功。父级 `读取当前任务树` 才负责把空组解释为不存在，并在后继叶读回任务目标、全部来源、场景、生命周期和树结构后裁决唯一当前根。

本叶全程只读，不直达 DATA-L1 / 仓库，不读取历史，不创建、修改或退出任务 / 需求，不判断目标等价、当前任务树、任务阶段、完成、调度或权限。本叶完成最多证明一个 BIZ 承接关系组读取 provider；不证明 DATA-EXT-13 整项、任务完整材料、当前任务树、需求任务后继快照或系统闭环。

## 2. 正式依据与当前事实

候选 S0 基线为 `main@fa3b87d10490a41b374b1b821aa9c83e062ac606`：

1. 0050 要求当前 / 历史读取分离、组合投影显式声明事实截止并只返回调用方拥有的不可变值；DATA-L2 只校验任务强类型结构，不判断任务完成或调度。
2. 3200 规定任务和需求身份分离，一个任务可承接多个目标等价来源需求，全部来源关系必须保留；任务身份、来源集合、目标和生命周期不能复制为第二权威。
3. 5090 规定同一有效来源需求复用唯一当前任务树，但需求可恢复时复用原任务树；运行代次不能被临时解释成任务关系当前性。
4. 5200 把来源需求集合定义为任务—需求正式关系；当前根、目标等价、生命周期和唯一运行态治理存在由后继完整材料联合裁决，不属于本叶。
5. 数据服务最终需求清单 DATA-EXT-13 已要求 `任务结构服务` 按来源需求读取承接任务，返回完整任务投影、来源关系、版本和共同事实截止；无承接任务是合法空，范围 / 预算与结构化失败必须显式。
6. 当前代码只有共同 `L2需求身份`、`L2任务身份`和节点族身份来源合同；没有任务结构 owner / 服务、`服务.任务.ixx`或本函数。计划索引只证明身份闭合结果，不证明 DATA-EXT-13 CRUD。
7. 旧 BIZ-L4 v0.1 直达含糊“正式关系服务”，把空组返回不存在，以运行代次筛关系，且缺少任务范围 / 读取规则版本、数量预算、完整 DTO、异常和失败发布边界。

裁决为：以 v0.2 原位替代 v0.1；复用 DATA-EXT-13，不新增数据服务编号。运行代次只匹配 BIZ 固定配置；空组保持成功；最终 DATA C++ ABI 未发布只构成待激活门禁，不阻断 BIZ 合同冻结。

## 3. DATA-EXT-13 消费合同

### 3.1 具名操作

本叶要求同一 `任务结构服务` 提供一个公开 const 组读能力，语义冻结为：

| 操作 | 请求 | 成功返回 | 合法空与失败 |
| --- | --- | --- | --- |
| 按来源需求与指定截止有界读取全部当前承接关系组 | 非零来源需求、非零 G0、事实范围版本、需求范围版本、任务范围版本、任务来源关系规则版本、读取规则版本和非零关系数量预算 | 零或多项完整当前任务—来源需求关系；每项含任务强类型身份与身份来源、承接关系强类型身份与身份来源、请求来源需求、关系生命周期 / 版本、单项 G0；结果回显全部版本、预算和共同截止 G0 | 空组为已读取成功；预算不足零组拒绝；事实代次漂移、许可拒绝、资源失败、内部不一致分别返回 |

DATA 必须返回全部当前关系，不按目标、任务阶段、运行代次、任务树资格、完成、调度或权限过滤。本表只冻结 BIZ 所需能力语义；最终 DATA 请求 / 结果类型名、字段顺序、状态数值和函数签名由 DATA 唯一所有者发布后机械匹配，BIZ 不建立兼容壳或第二 owner。

### 3.2 同一截止与预算

BIZ 请求中的 G0 必须非零并原样进入 DATA 请求。运行代次只与 `任务业务服务` 的不可变固定配置匹配和回显，不进入 DATA 请求。相同 G0 数值但来自不同 L1 运行包不构成同一快照。

数量预算统计 DATA 返回的全部当前承接关系。DATA 超限必须返回数量预算不足且零业务组；BIZ 对成功结果复核 `组大小 <= 回显预算`，不得截断、分页、预筛或静默去重。

### 3.3 完整性与稳定顺序

每项成功材料必须同时满足：

```text
关系源 = 非零 L2任务身份
关系目标 = 请求来源需求
关系角色 = 来源需求
任务节点族 = 任务，且任务身份来源完整并在 G0 当前
关系身份来源、关系生命周期和任务来源关系版本完整并在 G0 当前
单项事实截止 = 结果截止 = 请求 G0
任务身份在结果组内唯一
承接关系身份在结果组内唯一
```

一个任务可以承接多个来源需求，但在本次指定需求结果中只出现与该需求对应的唯一当前关系。BIZ 完整验证后按任务稳定身份、承接关系稳定身份排序；重复不通过去重修复，而是内部不一致。空组直接形成合法稳定结果。

## 4. BIZ 类型与物理位置

### 4.1 值式合同头

新增：

```text
文件：海中鱼巣/领域/当前承接任务组.数据.h
所有者：BIZ 当前承接任务组消费值式合同
可见性：任务业务服务、合法父级组合器和专属验证
```

冻结 BIZ 形状：

```cpp
inline constexpr std::uint32_t 当前承接任务组合同版本 = 1;

struct 当前承接任务组固定配置 final {
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 需求范围版本;
    std::uint64_t 任务范围版本;
    std::uint64_t 任务来源关系规则版本;
    std::uint64_t 读取规则版本;
};

struct 当前承接任务组读取请求 final {
    std::uint32_t 合同版本;
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 需求范围版本;
    std::uint64_t 任务范围版本;
    std::uint64_t 任务来源关系规则版本;
    std::uint64_t 读取规则版本;
    L2需求身份 来源需求;
    std::uint64_t 共享事实截止;
    std::uint64_t 最大当前承接关系数量;
};

struct 当前承接任务值式事实 final {
    L2任务身份 任务;
    L2节点族身份来源事实 任务身份来源;
    任务来源需求关系强类型身份 承接关系;
    任务来源关系身份来源事实 关系身份来源;
    L2需求身份 来源需求;
    任务来源关系生命周期 生命周期;
    std::uint64_t 任务来源关系版本;
    std::uint64_t 事实截止;
};

enum class 当前承接任务组读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    数量预算不足 = 3,
    当前性漂移 = 4,
    提供者拒绝 = 5,
    资源失败 = 6,
    内部不一致 = 7
};

struct 当前承接任务组读取结果 final {
    std::uint32_t 合同版本;
    当前承接任务组读取状态 状态;
    当前承接任务组读取请求 请求回显;
    std::uint64_t 事实截止;
    std::optional<std::vector<当前承接任务值式事实>> 当前承接任务组;
};
```

三个任务来源关系类型名是 BIZ 预冻结语义名，必须在 DATA-EXT-13 最终 ABI 后机械匹配或由 BIZ 私有值式映射承接；不得退化为裸 `稳定编码`、通用关系或 bool。只有 `已读取`携带 optional 值；空 vector 是成功。任何非成功 optional 为空且事实截止为零。

### 4.2 任务业务服务

新增：

```text
文件：海中鱼巣/领域/服务.任务.ixx
模块：海中鱼巣.领域.服务.任务
所有者：DATA 之外的任务读取业务解释
```

冻结首个构造和公开入口：

```cpp
class 任务业务服务 final {
public:
    任务业务服务(
        const 任务结构服务& 数据服务,
        const 当前承接任务组固定配置& 固定配置) noexcept;

    当前承接任务组读取结果 按来源需求读取当前承接任务组(
        const 当前承接任务组读取请求& 请求) const noexcept;
};
```

服务只保存 DATA-EXT-13 const 稳定借用和不可变固定配置，不建立任务 owner、L1 / 仓库入口、缓存或第二服务。模块私有 helper 只负责请求校验、DATA 状态映射、完整性互证和稳定排序，不得读取目标、生命周期阶段、历史或其它业务服务。

## 5. 固定读取与发布顺序

```text
校验固定配置完整，否则内部不一致且零 DATA 调用
-> 校验 BIZ 请求合同、来源需求、G0、版本和非零预算，否则请求拒绝且零 DATA 调用
-> 匹配全部固定配置版本，否则当前性漂移且零 DATA 调用
-> 构造不含运行代次的 DATA-EXT-13 组读请求
-> 恰一次调用按来源需求当前承接关系组读
-> 精确映射预算、漂移、许可和资源非成功；其它非成功收敛内部不一致
-> 互证请求回显、版本、预算、结果 / 单项截止=G0和 optional 形状
-> 逐项互证任务 / 关系身份来源、端点、角色、生命周期、版本和当前性
-> 复核全部关系计数、任务身份唯一和关系身份唯一
-> 按任务身份、关系身份稳定排序
-> 形成 optional 有值的完整不可变候选并无抛出交换
-> 返回已读取；空 vector 保持成功
```

所有 vector 分配、复制、排序和结果构造位于异常收口内。`std::bad_alloc`、`std::length_error`映射资源失败，未知异常映射内部不一致；成功交换前不发布部分组。

## 6. 非成功映射

| 情形 | BIZ 状态 | 载荷 |
| --- | --- | --- |
| 固定配置无效 | 内部不一致 | 空；零 DATA 调用 |
| BIZ 请求坏合同、零身份 / G0 / 版本 / 预算 | 请求拒绝 | 空；零 DATA 调用 |
| 合法请求与固定配置版本不等 | 当前性漂移 | 空；零 DATA 调用 |
| DATA 空组 | 已读取 | optional 有值空 vector；事实截止 G0 |
| DATA 数量预算不足 | 数量预算不足 | 空；不得截断 |
| DATA 事实代次漂移或结果 / 单项截止不等于 G0 | 当前性漂移 | 空 |
| DATA 明确许可拒绝 | 提供者拒绝 | 空 |
| DATA 资源失败、`std::bad_alloc`、`std::length_error` | 资源失败 | 空 |
| DATA 请求拒绝、未找到 / 已退出、运行态未实现 / 未装配、坏 optional、错端点 / 角色 / 节点族、半结构、重复身份、成功组超预算或未知异常 | 内部不一致 | 空 |

DATA 组读合同不得用未找到 / 已退出表达“没有承接关系”；该情形必须是已读取空组。任何非成功都不携带任务组或事实截止。

## 7. 激活门禁

计划只登记 `待激活`，直到同时满足：

1. DATA-EXT-13 唯一 `任务结构服务`及本设计第 3 节组读操作真实实现、普通推送并由其所有者登记退出；
2. 最终 DATA 请求 / 结果 DTO、状态、空组、预算、共同 G0和函数 ABI 与本设计机械匹配；
3. DATA 的唯一任务结构服务已由普通应用同一 L1 运行包构造，具有稳定生命周期和最终合法 const 取得 ABI；本计划只借入该同实例服务并首次建立 `任务业务服务`，不要求普通应用预先持有或注入尚不存在的 BIZ 服务；
4. `服务.任务.ixx`、工程、唯一代码段、构建和专项资源全部释放；
5. 从最新 `main == origin/main`、index 空重做 S0，目标文件无异主 WIP。

最终 ABI 若改变一次组读、空组成功、全部当前关系、非零 G0、总预算、运行代次零 DATA 语义、完整端点或失败零组，必须退回计划支撑。

## 8. 验证矩阵与完成声明

专项至少覆盖：

- 坏固定配置、坏请求、零 G0 / 预算和版本不等均零 DATA 调用；
- 空组成功且 optional 有值、事实截止=G0；单任务、多任务和一个多来源任务在指定需求下只出现一次；
- DATA 恰一次调用；运行代次不进入 DATA 请求、不参与关系筛选；
- 错源 / 目标端点、错角色、错节点族、退出任务 / 关系、身份来源缺失、重复任务、重复关系、跨截止、错版本和半结构拒绝；
- DATA 预算不足、成功组超预算、漂移、许可、资源、请求拒绝和未知异常独立映射且零前缀；
- 输出按任务身份、关系身份稳定排序；不得根据目标、阶段、创建时间、列表位置或 UI 过滤；
- 源码零 L1 / owner / 仓库 / DATA 写 / 历史 / 目标等价 / 当前根 / 任务阶段 / 完成 / 调度 / 权限 / 缓存 / 日志裁决；
- 根工程 Debug / Release、专项双配置、strict、UTF-8 / XML、工程唯一登记和生产零专项痕迹。

验证必须经 DATA-EXT-13 正式公开入口，不得用专项直接构造 DATA 结果或增加生产 seam。若最终 DATA ABI 封闭坏形状，动态验证只覆盖公开可构造分支，静态防御与 DATA 黑盒拒绝证据分账，不得宣称动态命中。

真实资源耗尽、私有 DATA 损坏、跨进程恢复、普通应用持有 / 公开 `任务业务服务`、完整任务材料、当前任务树、需求任务后继快照、父级 G0/G1和独立集成验收保持 `NOT_RUN`。

本设计发布不证明 DATA-EXT-13 或本叶代码已经实现；未来本计划结果也只证明当前承接关系组 BIZ provider，不证明唯一当前任务树、任务目标 / 生命周期、调度资格、任务完成或系统闭环。
