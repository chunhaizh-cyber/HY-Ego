## 2. 执行退回事实与裁决

### 2.1 已消失的链接阻断

ABI 结果提交 `497746760fada7c989d6747abf42b0f794355875` 发布后，当前工作树 Debug / Release x64 fresh Rebuild 均完整链接成功；旧 `L2任务子目标承接记录结构服务` 未定义符号不再构成 Gseed 阻断。

### 2.2 专项夹具错误

提交 `b38059b6b501c49705249f5d5587f6d1f9dba2e9` 中的 Gseed 专项本身有两个非机器语义错误：

1. `形成隔离配置()` 没有填入当前 `普通应用配置` 必需的 `等待合同登记`，装配返回状态 56；
2. `gseed-v4` 与 `legacy-v1/v2/v3` 子根没有先建立 `l1`、`material` 目录，修复前装配返回不可变材料服务构造失败。

唯一修复是：

```text
形成隔离配置 -> 填入形成普通应用任务筹办等待合同登记()
运行Gseed显式激活专项 -> 建立 gseed-v4/l1 与 gseed-v4/material
验证旧格式 lambda -> 为每个 legacy 子根建立 l1 与 material
```

该修复只作用于 `海中鱼巣/端到端测试.本能被动维护游标.ixx` 的 Gseed 独立测试段；不得恢复或提交外层测试中异主删除的同名等待合同，不改生产代码，不形成第二 owner 或第二业务入口。

### 2.3 无合法夹具项

以下项目不能由本叶合法构造运行材料：

- B 的 `成功维护提交序号 1/N` 只能由未来成功维护原子提交入口形成，而本叶明确不实现该入口；
- 真实普通启动固定使用用户 AppData 并进入等待宿主，当前没有可注入隔离配置和停止资源；
- `已可能发布`、坏材料、部分 v4、双当前、资源失败、内部错误和并发故障没有公开授权的注入夹具。

裁决：这些项目保持 `NOT_RUN`，转交具备合法提供者或夹具后的具名集成验收；不得私写 owner、篡改持久材料、伪造第二入口或污染真实 AppData。它们不再阻断本叶按第 3 节证据收口，但必须继续保留未证明边界。
