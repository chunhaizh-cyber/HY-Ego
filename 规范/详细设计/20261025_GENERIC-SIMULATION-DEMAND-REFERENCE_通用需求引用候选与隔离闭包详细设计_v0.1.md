## 6. 生成分支：值目标不依赖已有真实D

1. 只对`需求节点引用`物理类别进入本分支，比较规则必须为需求身份精确且正式类型域可读。全材料表示所有合法D，不是无条件接受任意编码。
2. 经方法owner只读桥接取得正式需求根、值目标/方向子类及字段FT范围的完整定义和保护。读取结构定义的继承、收窄及约束，不按名称/方法登记号决定字段。
3. 主体和目标从axes之前已经完成的合法E原型池分别选择，保持别名；两者可相同或不同，除非已有明确关系限制。没有人类主体时允许按正式人类概念增加私有E及其必需F，不改变N；精确构造和遍历次序见第18节。正式唯一存在范围必须映射到对应本地E，不能保留真实可写引用。
4. 候选目标FT来自同次正式存在概念的必需特征闭包及直接特征规格，不仅是六个直接实参FT；即使F上下文当前未知，也可按其正式定义生成D的目标要求，而不填写该F当前值。对I64数值FT的每个合法闭区间按现整数三点算法取样。最终生成边界及私有原型展开见第18节；没有合法数值FT时精确报告缺少定义，不临场挑服务值/温度，也不把其所对应值目标偷偷改成方向。
5. 值目标：用FT原材料/单位/比较规则及取样准确域形成目标FC。与当前父定义相等复用父C，严格缩小才调用原owner建子C；不能重犯等父域当严格子域。再由二次概念owner按既有有向特征差值及目标参照定义建立/复用比较定义，精确合同见第13节，不由施工者临时决定。
6. 方向目标：从正式方向允许枚举取合法值，不对编码取中点，不把值目标失败偷换成方向。两种分支分别组织并显式列覆盖，不混用载荷。
7. 权重/活动/执行域等必需字段从正式范围取合法候选并按域约束过滤。首版生成支持正式被认知子类：权重0、无自我父链/根角色/承接，主体必须符合U来源人类范围，U/C/R按第12节形成完整模拟条件。它不是现实确认事实。普通自我执行域无合法父链/根依据时准确报告该生成分支未支持，不任造服务/安全根；这不阻断合法被认知构造，也不将所有需求缩成只能复制。来源类型有精确纯数字合同就按其类型生成，不把“没有真实来源实例”当无法模拟。
8. 惰性组合，有限枚举全量随机排列不放回；数值范围三点，保留种子用于复核，不缓存前组方法结果。局部D选择号可作轴值，必须单独类型分支解释，绝不能被当成D稳定编码。

正式目标概念的建立只形成合法定义，不形成现实实例状态或本次方法结果；除所属概念owner及后续方法知识的既有发布外，本叶不得写现实世界。若当前权威禁止为该模拟请求建立必要共享目标定义，则该部分须单独形成只读输入提供者，不能偷偷新建现实实例代替。

## 7. 隔离发表、读取与释放

world是本地D唯一owner，记录加入既有模拟schema而不在真实需求树登记。新D、其内容字段/必要关联、F→D当前引用与同组E映射在一次L1追加闭合后才交付参数绑定。允许预分配身份以闭合引用，但未完整发表不可读；失败使用完整本地删除集收束，不能留下可见半D。

所有E/F/D实例引用发布为本样例本地身份；FT/FC/RC等正式定义共享。源ID只放调用期映射或明确来源数值材料，不能发布为可遍历的实例字段目标。内容同一保持同一映射；父D链拒绝环，多D共同引用E只建立一份E。条件图可有D→E→F→D内容引用环，先分配身份后填边，不能用递归无限构造。

读取从正式本地字段重建，核类型、所属模拟根/样例、字段基数、目标分支和引用合法性；不只返回内存缓存。F当前引用D是内联准确引用，没有额外普通材料V。复制来源映射不是读取失败时回退真实owner的许可。

释放时D/关联节点/字段/场景边纳入原`通用节点/通用字段/通用外部边`完整删除集，复用`原子删除节点结构`。外部引用导致删除失败按工程故障保留并报告，不扩大删除集到真实对象/正式概念。调用窗口关闭后才能清理，停止同样释放未发布/已发表本地对象；方法知识发布未知不得先清理再重造。

## 8. 单向复制：当前主线被认知D的精确提供者映射

### 18.3 未知准确值和语言场景完整输入

在现`新模拟有序参数输入`尾部追加以下字段，旧调用默认保持常规行为，不重排既有布局含义：

```cpp
enum class 新模拟特征初值方式 : std::uint8_t {
    常规输入=0, 复制准确=1, 复制未知=2
};
// 新模拟有序参数输入尾部

std::uint32_t 所属语言场景输入=0; // 仅F，和所属存在参数互斥
std::uint32_t 引用语言场景输入=0; // 仅私有E别名，映射为同一本地语言场景身份
```

复制准确要求`完整复制特征.当前值`确有值，依原类型映射引用/完整材料；复制未知要求该项无值。两复制方式都禁止同时设置旧`值/材料/引用存在参数/引用需求输入`，不能留空后走默认0/空集合分支。区间、单位和完整历史只从第19节唯一复制结构读取，可明确无值；已有`复制上下文`继续表示读取依赖来源，不被初值方式替代。普通生成F走常规输入并通过取样形成准确值，不被误标复制未知。

world对复制未知F只写合法特征类型/所属/可选实例区间与单位，无`数值/当前材料`字段，不生成当前状态或变化；`读取模拟特征`返回`当前值=nullopt`和原区间，`读取模拟存在参数特征`返回`当前值未取得`且仍有完整特征信息。绝不把正式区间、FT根或未取得读回当成准确当前值。所有前值捕获/条件核对必须接受这个合法状态；父方法若确实要求准确值，则候选条件未具备，不计动作失败，不伪造结果。

来源F用第19节新增只读完整F桥取得，不改变现匹配snapshot ABI，也不从私有字段猜读取。自然语言概念实例常见“有正式区间、无准确当前值”正由此路径复制，不拒绝所有非空语言场景；其标准/历史确实为空才复制为空。

语言场景自身F入同一个F输入队列，`所属语言场景输入`定位唯一语言场景；普通成员/概念实例成员/边界E全部入E队列，重复源E保持同一本地身份。边界E不被移成直接成员。源语言场景本身若作为D目标或E引用出现，用私有E输入`引用语言场景输入`与本地语言场景身份别名，不另造普通E镜像；相应F只属于该场景身份。场景直接子场景、实际S/动态等尚无typed合同的类别仍整组准确未支持，不丢弃普通E/未知F来规避。

`读取模拟语言场景`返回§12.1本地信息：源定义引用（复制时如实共享、生成场景明确无专属定义）、自身F/成员E/边界E及概念实例映射完整；本地身份/集合从L1核完整后返回，没有真实world回退。源组织父根不复制，仅保留样例归属；不把这个重定位说成源场景已经移动。该第5typed口和自身F读取均进实际读取/hidden-dependency轨迹，动作前typed快照不进轨迹。

### 18.4 知识门的唯一时点

动作前对D/U/C/要求/语言场景及未知F的typed捕获只保存本组前值，不拒绝调用、不算函数已读取。原函数实际成功读取上述内容时由world记录轨迹；方法实际写回则用既有本次写回记录定位。形成知识前对实际读取/写回逐项检查现C/R是否能完整表达，不能表达的D/关联内容在此唯一门具名未支持，禁止进入V保存路径；未知准确值不转0。原函数没有读取/写回D时不凭前值存在补造其准确条件，亦不因为有D前快照就一律阻断其它完整知识。

结果归FT检查和调用结果未知仍按原顺序处理，不能绕过原函数的模拟依赖拒绝。临时身份泄漏检查是发布前最后防漏，不替代完整实际读取条件检查。以上次序同时适用于普通参数F和E附属F，不留附属单D或语言场景F旁路。

## 19. 完整F读取、有限历史及typed重映射

### 19.1 唯一来源与能力边界

现`新特征匹配实例快照`只有当前/实例区间，没有标准、历史、聚合及命中。因此`新_方法类.h/.cpp`新增只读桥：

```cpp
std::optional<新特征信息> 读取模拟来源完整特征(稳定编码 F) const;
```

直接委托所属`特征服务_.获取特征(F)`，与既有匹配定义快照共同采集并fresh核同；不扩匹配snapshot ABI，不写真实F。原型上下文及来源E/F队列一律使用完整桥决定可复制性，不先返回伪空完整投影。源E列表中已核F忽然不可读按前提变化/工程读取失败收口，不构造默认F。

支持顶层F（上级特征为空）的I64、UTF8/I64数组/普通U64材料、单存在、单需求以及存在/需求引用集合。标准/历史值和命中次数是源F当前保存的内容，一并typed复制，不增加真实学习运行或命中。复杂引用集合（任务、消息等）历史若没有本叶已有完整typed映射、非顶层特征归组或域中含未支持实例引用，则在采集阶段返回`引用类别未支持`并定位F/字段/类别，整候选不交付残缺F；合法全无标准/历史/聚合才能保持空。

### 19.2 中立完整复制输入

以下结构也放`海中鱼巣/领域/模拟需求.数据.h`，按类型明确局部引用，不保存源稳定编码为可写事实：

```cpp
enum class 新模拟复制值种类 : std::uint8_t {
    I64=1, 普通材料, 存在引用, 需求引用, 存在集合, 需求集合

struct 新模拟复制准确值 final {
    新模拟复制值种类 种类;
    std::variant<std::int64_t,新特征值信息,std::uint32_t,
        std::vector<std::uint32_t>> 内容;

struct 新模拟复制值命中 final {
    新模拟复制准确值 值;
    std::int64_t 命中次数=0;
};
struct 新模拟复制值域 final {
    // 无实例引用的正式域直接保持；有限值域全部转typed准确值后重映射。
    std::variant<特征概念值域,std::vector<新模拟复制准确值>> 内容;
};
struct 新模拟完整特征复制输入 final {
    std::optional<稳定编码> 实例单位;
    std::optional<新模拟复制值域> 实例区间, 历史聚合;
    std::optional<新模拟复制准确值> 当前值, 标准值;

```

`存在引用/存在集合`的u32/向量定位完整base的E输入，`需求引用/需求集合`定位D图需求序号。普通材料用正式`新特征值信息`值副本，节点字段只供来源核同，发布时必须重新形成本地材料V并重置身份；同份源材料复用同一本地V。不能把带业务引用语义的U64数组当普通数字材料复制：按原FT比较规则分类，存在/需求集合逐成员入typed闭包，任务/消息集合没有可用映射时准确不支持（明确空集合仍可合法复制）。

对源F每个当前/标准/历史/命中准确值及有限聚合域成员执行同一转换，不仅转换当前值。I64保持字面数，普通材料完整复制，E/D引用入同一axes前闭包队列并保持别名。`新特征值信息.节点`和任何源编码不直接发布为准确值。区间/聚合是I64/结构化无实例定义时保持原域；含`vector<稳定编码>`的有限域必须根据原FT类型解析成上述typed值组。存在引用域只含共享正式概念时可保留；其它含实例引用却无表达的域整F拒绝，不把区间/聚合默认为空。复制后的有限域用本地准确值或本地材料V身份重建，不能存源域实例编码。

源投影的历史不同值与命中列表必须按原owner合法合同一致；出现重复/次数非法/命中不对应已有值时按工程结构问题收口，不由模拟修正或补计。源F当前未知可同时具有合法标准/历史/区间，三者不能代替当前准确值。

### 19.3 本地发表与完整读回

world每个复制F的完整结构、所需本地材料V、历史/命中有序记录及区间/聚合值域结构同组发布；仅在现schema尾追加私有字段/记录tag，不改旧数值。当前/标准/历史中同一值保持相同本地E/D/V引用，不复制出不同身份。历史顺序和次数按源投影保持，不自行重演写值、不产生虚假状态/变化，不把这些源次数算作新的模拟学习支持。

`读取模拟特征`从本地L1完整重建`新特征信息`全部字段：上级（首版无）、正式概念、实例单位、区间、历史聚合、当前、标准、历史不同值及命中列表。`读取模拟存在参数特征`继续投影其正式合同，但它从同一完整本地F读取，不建立第二值仓。复制未知F不写当前值字段；真实为空与读取失败分开。由于C++不能检测调用者访问结构体成员，禁止返回残缺完整F后声称“尚未读历史”；不支持字段必须在采集或整F读取前拒绝。

动作前完整快照仍不进入函数实际读取轨迹；函数实际取得完整F时记录整份返回投影并按复制来源标hidden-dependency，不能只记录当前值后漏掉历史引用。D历史或标准值一旦包含本地D，发布知识前的实例泄漏检查同样覆盖；不能靠当前值未变忽略完整读取得到的D依赖。所有新增本地历史/材料/域节点加入同一释放删除集，不产生独立历史维护服务或后台扫描。
