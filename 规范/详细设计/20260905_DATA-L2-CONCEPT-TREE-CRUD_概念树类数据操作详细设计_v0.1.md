## 1. 目标、范围与旧方案退出

新建 `海中鱼巣/领域/数据服务.概念树类.ixx`，模块 `海中鱼巣.领域.数据服务.概念树类`，类 `概念树类数据服务`。本类是 DATA-L2 概念owner公开面，只机械承接强类型结构、唯一性、引用、同截止读写、幂等和生命周期。名字中的“树”不把它变成 DATA-L3，也不授权本类从世界扫描后裁决抽象成立。

本类接收外部统一初始化已建立的四个本体根、固定完整结构签名规则、结构类型引用和唯一owner写端口，验证后执行普通特征/存在概念及其定义、上下位、支持、生命周期、当前/历史读写。全局变量只保存正式根节点引用；根的全局声明、创建、唯一性与初始化恢复由统一初始化负责，不在本类实现。本类不导入全局变量模块、不建立根、不补根、不另开owner。

禁止导入、export import、别名、包装或传递依赖旧 `服务.L2概念结构`、`L2概念结构.数据.h`、`L2普通概念结构.数据.h`、旧不可变材料服务及其L2公共合同。允许链为L1与新特征值/特征/状态/动态/存在数据类。旧`应用服务.特征概念类.ixx`尚未迁移，不是本提供者消费者；已退出的`EXISTENCE-CONCEPT-APPLICATION v0.2`不得恢复施工，新存在概念树应用在本提供者之后重新设计。

本轮不修改L1接口、4015、旧概念owner、全局变量或生产初始化；不复制旧四根、不转换旧概念身份、不删除或自动迁移旧数据。对传入旧身份、旧布局或混合布局真实拒绝，而非把稳定编码换包装后当成新结构。自然语言、名称字段、成熟自动评估、自动区间学习、设备和主程序接线不在本次范围。

## 2. 既有能力与外部交付

新数据类依赖链为存在→动态→状态→特征→特征值→L1。复用存在`读取存在历史事实`/`读取特征成员历史事实`；特征`确认特征类型`/`读取特征类型历史事实`/`按实例读取特征历史事实`；值结点历史读；各provider的`绑定于(L1)`；L1现行owner端口、首次规范化写集读回、当前/历史事实、关系组、属性组及同G关系类型闭包。新模块不得绕过world公开provider直接扫描其它owner事实。

外部交付结构名冻结为`概念树结构交付`，由值式`概念树根引用组`、`概念树结构类型`、格式锚点与固定签名规则身份组成。`概念树根引用组`明确含存在根、特征根、动态根、因果链根四个独立`概念树概念身份`；不得由客户端追加根角色或传入重复身份。`概念树结构类型`的各具名类型与完整物理映射在第5节冻结，必须是该owner真实建立的节点，不能由裸枚举冒充。

固定完整结构签名规则是外部已发布的独立真实节点，以具名格式和版本值说明规范化、强类型相等及唯一性。它不代表任何应用抽象算法或任意材料服务。本类只校验和使用这一固定规则，不在构造时创建规则/类型/根或采用无规则默认分支。

统一初始化尚未接线不阻断本数据类的独立施工：验证可以通过真实L1建立符合最终交付布局的根、规则、类型及关系，再移交唯一端口调用本类。该测试只证明真实交付下的数据服务行为，不证明生产全局初始化或存量迁移已实现。构造前置不以测试假对象、内存map、日志或缓存替代。

## 3. 构造、校验责任与生命周期

完整构造签名固定为：

```cpp
概念树类数据服务(const L1事实基座服务& 第一层服务,
    const 特征类数据服务& 特征服务,
    const 存在类数据服务& 存在服务,
    const 特征值类数据服务& 值服务,
    L1所有者范围写端口&& 写入端口,
    const 概念树结构交付& 结构交付);
```

本类禁止默认构造、复制和移动。保存L1和三个world只读provider借用引用，持有移入的唯一owner写端口及已校验的结构定位；调用者保证L1/provider寿命长于本服务。本类销毁只释放端口，不退出根、概念或世界事实，不拥有全局变量生命周期。

构造必须先确认端口有效、绑定本L1，owner当前真实存在且为活动独占结构范围，三个world服务均绑定同一L1；随后在一个真实当前G读取交付的全部根、规则、格式、类型及具名关系，完成以下互证：

- 所有交付身份非零，四根两两不同，根身份与格式/规则/类型身份互不冒用；
- 根、规则、锚点、类型、角色关系和格式/版本值均由端口对应owner写入，当前未退出且节点种类/属性表示正确；
- 四根角色恰为存在1、特征2、动态3、因果链4，各角色恰一；传入根组与正式具名根关系组完整相同，不遗漏或额外扩根；
- 固定规则的身份、格式版本和规则版本与第5节物理合同一致，类型引用逐项匹配而非仅检查非零；
- 格式锚点、根、规则与关系形成规定的新布局闭包；旧布局或混合布局即便经过本模块强类型包装也不通过；
- 全部读取与最终G守卫一致，任何漂移、缺失、错owner、错类型、关系不闭合或资源错误均拒绝构造，不能部分可用。

构造失败用`std::invalid_argument`表达确定的配置/布局错误，资源失败保持`std::bad_alloc`或对应资源异常；诊断责任向调用者送出，最终装配边界负责记录。本类构造不执行任何L1写入；调用者负责重新取得一致真实交付后重试，不能让本类自动修补初始化。后续公开操作仍校验实际事实截止与引用，已保存定位不是第二权威。
## 4. 普通定义与来源的闭集

新导出身份为本模块独立struct：`概念树概念身份`、`概念树规则身份`、`概念树存在引用`、`概念树特征类型引用`、`概念树特征引用`，均只含`稳定编码 值`和显式构造/相等，无旧L2隐式转换。`概念树世界引用=variant<概念树存在引用,概念树特征引用>`；`概念树形成世界引用`在该闭集上增加特征类型引用，只用于形成定义引用读取/释放。

`概念树精确值=variant<int64_t,vector<int64_t>,vector<uint64_t>>`；`概念树I64区间{int64_t 下界,上界}`；`概念树特征值域=variant<概念树精确值,概念树I64区间>`。向量非空且表示类型保持，反向区间拒绝；零宽I64区间规范化成同I64精确值。类型/关系句柄必须由关系保存，不可混入数值载荷。

`概念树特征定义`含`概念树存在引用 形成宿主`、`概念树特征类型引用 特征类型`、`概念树特征值域 值域`；`概念树存在定义`含`vector<概念树概念身份> 特征模板组`。模板组非空，按身份确定排序，重复拒绝。`概念树定义=variant<概念树特征定义,概念树存在定义>`，分别只可在特征根/存在根创建。新特征定义的宿主+FT+值域构成完整签名，存在定义只包含所选新特征概念身份。同FT多个不同模板可保存，不因数值域相似合并。根空定义不可经普通概念创建入口建立。

创建前通过新特征provider的`确认特征类型`在请求G取得真实FT表示。I64区间及I64精确值只接受I64 FT；I64组/U64组精确值分别只接受对应FT。独立材料引用表示在本轮明确不支持，不能给任意FT挂任意值域。该守卫只机械验证类型，不判断抽象正确性。读取已发布特征定义时通过`读取特征类型历史事实`在概念创建H再次核验表示。

`概念树来源项`含`概念树世界引用 世界事实`和`uint64_t 证据截止`；至少一个来源，H非零且不晚于请求G，按世界类别、目标编码、H排序，重复项拒绝。每项经实际新world公开历史读验证；新建L1关系还要求世界端点在请求G当前可引用。数据层不宣称来源足以证明抽象业务成立。来源和直接父不进签名，新实例匹配、选择部分特征及严格子集语义由后续应用负责。

未发布候选尚无概念创建H：创建前只使用请求G验证形成宿主/FT和关系当前端点，来源另核验其证据H；不得预测G+1并预读。发布后从真实概念节点取得创建H，用该H验证形成宿主/FT。概念自身、治理状态、当前上位和定义记录均在本次结构截止读取。形成/来源世界关系允许第7节的显式释放，完整定义从记录创建截止的历史关系重建；模板概念引用、当前支持和上位关系不属于该释放入口，不能因此改变签名或类别。

## 5. 公开DTO、API与精确持久映射

### 5.1 共同合同与结构交付

所有本模块DTO合同版本固定`uint32_t=1`，相等比较纯值；业务写key使用`uint64_t 幂等身份`且非零，不接受旧L2幂等类型。`概念树读取头`含`合同版本,Gread,H`，Gread必须非零，H=0表示当前Gread，否则0<H<=Gread表示历史。`概念树写入头`含`合同版本,期望事实代次,幂等身份`，后两项非零。

`概念树预算`全部字段为非零`uint64_t`：`最大概念数,最大关系数,最大来源数,最大支持数,最大世界成员数,最大特征属性数`。数量全部要求精确完整，不截断成功。计数加法/本地键转换必须溢出检查；实际L1读取无预算参数时不可虚构参数，先用现有具名读取取得集合，再检查该集合和累计预算，超限不继续展开。不得把返回后计数宣称L1底层有新增内存预算。

`概念树根角色 : uint8_t`固定`存在=1,特征=2,动态=3,因果链=4`。`概念树生命周期状态 : uint8_t`固定`活跃=1,冷却=2,退役=3`。`概念树数据状态 : uint8_t`固定顺序：`已创建=1,精确重复,已读取,已添加支持,已退出支持,已添加上位,已替换上位,已退出上位,已迁移生命周期,已退出概念,已释放引用,无须变更,入口拒绝,未找到,目标已退出,引用冲突,形成环,根不可退出,事实代次漂移,幂等冲突,数量预算不足,历史材料不可用,资源失败,内部不一致,已可能发布`。`概念树发布状态`为`未派发=1,已确认发布,可能已发布`，不能将可能发布当成功。

`概念树根引用组`有四个具名`概念树概念身份`字段`存在根,特征根,动态根,因果链根`。`概念树结构交付`字段为`稳定编码 格式锚点`、根组、`概念树规则身份 签名规则`、`概念树结构类型 类型`。结构类型恰为下表28个`稳定编码`具名字段；28个类型节点两两不同，与锚点、规则、根都不得复用身份。

| 事实DTO | 必需字段 |

| 概念树直接上位事实 | `稳定编码 关系`、概念身份`上位,下位`、生命周期 |
| 概念树来源事实 | `稳定编码 记录,成员关系,世界关系,截止值事实`、`概念树来源项 来源`、记录生命周期、`bool 当前世界引用已释放` |
| 概念树概念事实 | 概念身份、根角色、本体根身份、`bool 是本体根`、规则身份、`optional<概念树定义> 定义`、`稳定编码 定义记录,生命周期值事实`、治理状态、概念生命周期、完整来源组与直接上位组 |
| 概念树支持事实 | `稳定编码 记录,归属关系,概念关系,世界关系,截止值事实`、目标概念、世界引用、证据H、记录生命周期 |

根事实无普通定义、定义记录、生命周期值和来源，治理状态固定活跃；普通事实这些结构必须完整，不能用根例外掩盖缺字段。普通定义记录及来源记录的创建G等于概念创建G，全部初始自有值/关系同笔成立。支持记录及其三条关系和一个值共五项事实同创建G。

| 请求DTO | 除明确列出的共同头/预算外全部字段 |

### 5.4 持久记录与本地键规则

普通概念节点只有种类和当前生命周期两个自有属性，另通过概念根归属、概念规则、定义成员关系连接实际根、规则与唯一不可变定义记录。特征定义记录通过定义宿主/FT两条关系表达句柄，并恰有一种精确值属性或下上界两个I64属性；不存在额外“整个定义”打包值。存在定义记录只通过定义模板关系表达按编码排序的特征概念组，不复制其值域。

每个来源是独立记录节点：概念→记录的来源成员关系、记录→世界的对应关系、单元素H属性。定义记录与来源记录不会因当前world引用释放而退出；完整重建从记录真实创建G的历史world关系取得原目标，再由world provider按形成H/证据H验证。记录的当前概念成员关系仍必须存在，历史回查不是容许任意缺失记录。模板概念关系保持当前不可释放。

支持是独立记录节点：格式锚点→记录、记录→概念、记录→存在或特征，以及证据H属性。支持退出同笔关闭这四项和记录；不删除端点，不修改概念定义。按世界双向读通过支持world关系的目标组及记录重建，不使用应用map。

所有值的来源固定其所属节点自身，不以world来源编码作值来源反锁world退出。元数据版本/枚举使用I64，证据H使用严格单元素U64组；这些载荷仅表达具名非句柄字段。根、规则、定义目标、来源目标和成员关系身份绝不装进数值组。

每次普通创建的本地节点键固定1=概念、2=定义记录、3..为规范化来源记录。关系键从`0x0001'0000U`起，依次为根归属、规则、定义成员、按父编码排序的父边、定义宿主/FT或排序模板边、每个来源的成员/世界边；值键从`0x0002'0000U`起，依次概念种类、生命周期、特征精确值或下/上界、来源H。支持创建固定节点键1，关系键依次归属/概念/world，值键H。上位新增/替换的新边用首关系键，生命周期新值用首值键；退出只有退出集以及第7节必要替代边。所有退出集按事实稳定编码全局升序排序。每类局部序号不超过0xFFFF，超过返回预算不足，不溢出或复用键。

## 6. 单笔事务、首次恢复与图闭包

所有写入由本类唯一端口、同一内部mutex串行实施；各public方法只封装正确variant进入`执行写入`。源事实/跨服务读始终经公开provider，无第二owner或本地权威缓存。每笔概念/支持/上位/生命周期/退出/引用释放都只有一个L1 owner写集，成功只推进一个事实G。

### 6.1 创建、查找与图完整

概念创建先规范化有类型定义、来源和直接父；父组必须非空、真实存在且同根，允许根或同根普通概念。类型/来源/定义模板在请求G合法，存在模板目标必须为新provider真实特征概念，不接受旧稳定编码wrapper。同根全范围精确查找已发布定义：规则身份相同且完整定义相等则返回`无须变更`和完整既有概念事实，构成零写成功；不按来源、父、名称或枚举顺序制造另一个身份，不自动激活冷却/退役概念。查找读取本身只比较规范化定义，不把查询材料当新world准入；失败不能当空集合。

读取图从交付根及L1概念根归属类型的完整关系范围重建全部普通概念，不只靠从根BFS而漏掉坏的孤儿；随后收集全部直接边，检查每条端点当前存在、同根、无自环、无重复关系身份或重复端点边，拓扑检测无环且每个非根可到唯一根。根角色交付是闭集，不用新枚举创建根。节点按身份排序，直接边按上位/下位/关系身份排序，支持按世界类别/世界编码/概念/记录排序；保留全部多父，不合并或单父化。预算任一超出即失败零载荷，不“尽力返回”。

直接上位操作按请求完整端点/旧边在原G验证；替换只退出那条旧边并新增指定边，其它父保持。退出一条边后仍须所有当前非根到根，拒绝最后路径丢失、跨根、自环和形成环。本data层不判断父子定义语义包含；存在概念的严格子集证明由应用完成。

支持创建验证目标是当前新概念/根、world端点当前可引用且证据H历史可读；同一world/概念当前支持唯一，已有则返回无须变更与该正式关系，不增加证据计数、不绑定新key。允许同一world支持多个概念、同一概念多个world及跨根支持。按概念/世界的完整读取必须互证同一记录；目标或来源失败不能返回合法空。治理迁移/概念退出/形成引用释放的详细算法在第7节冻结，仍沿本节单事务。

### 6.2 原key重放和不确定发布

入口先验证版本、非零原G/key、预算与请求纯值形状，在类mutex下用该key读取L1首次写入材料。首次key未找到才能进行当前G准入；禁止先按照当前图重新决定请求再查旧key。首次材料有值但头/owner/key/载荷不完整时返回内部不一致或资源失败，保留原请求并标可能已发布。

首次存在时，取得当前Gread，在原请求G的历史结构上重建本操作所需输入和写集，保持原key/原G以及规范化定义、来源、旧边/预期状态/退出集。重建过程不重新选择当前候选、不换目标、不以新G覆写原G；预算只约束本次重建，不计入业务含义。把完整规范化写集与L1首次写集比较，异义则幂等冲突；相等才从首次真实发布H重建结果。历史材料已清理不能猜成功，保留原请求并标可能已发布。读取到已知H就保留H，不能以响应缺载荷抹掉它。

首次未找到时，确认当前G等于原请求G；漂移明确拒绝本次新写，不换key自动尝试。完成全部引用、唯一性、生命周期/图闭包和预算检查后形成规范化写集，最后仍由L1同G守卫提交。L1成功后验证owner、key、映射唯一、发布G和完整载荷，再以新当前Gread/实际H历史回读本操作全部事实和图闭包。原请求完整保留；支持需两个方向在同H读回，替换需旧边在H已退出/新边在H存在，生命周期需旧值已退出/新值一致。

任何实际提交调用之后的异常、失败或不完整结果一律保守`已可能发布`，保留原请求和已知H；不因未拿到节点就宣称零写、不换key重做、不自动补偿删除。派发前失败为本次未派发，但首次key查询失败或已发现首次时不能推导过去未发布。用户以原请求重试即可经同入口收敛，无第二幂等仓、进程bool或完整DTO持久blob。

### 6.3 历史结构与形成来源

公开读取采用Gread下的稳定仓库观察与指定H的可见性，逐项核对返回头和生命周期；完成后同Gread守卫。普通概念来源/形成定义的world边在记录创建H查原端点，再调用world历史provider核验证据H；其他概念、定义记录、成员边和治理状态按所请求H重建。记录创建G只取正式节点事实，不能取客户端时间或最近生命周期值。允许world边合法释放后当前概念继续读取，不能把缺失模板关系或成员记录也解释为释放。

无须变更结果是合法零写读取，不绑定传入key。创建同定义时返回完整既有概念，支持已存在时返回完整既有支持；两者均保留原请求、发布状态为未派发、发布截止为空，事实代次等于原请求G，完成末尾同G守卫才可成功。既有事实的创建G不是本次发布截止；不修改既有来源、父边或治理状态，不宣称本次来源已成为既有概念证据。跨事务流程由后续应用持有各步原请求，不把本模块单笔原子性扩大为“建立概念+支持+接上位”全流程原子。source/member/template历史失败按对应失败返回，不以缓存恢复含义。
## 7. 生命周期、不可逆退出与形成来源引用释放

### 7.1 生命周期及支持退出

普通概念只有活跃→冷却、冷却→活跃、冷却→退役、退役→活跃四条迁移合法。请求当前生命周期值编码、预期状态与概念必须同原G正式事实完全一致；编码/状态不符为引用冲突，非法状态/路径为入口拒绝。同状态请求仍须互证当前编码，合法时无须变更并返回完整概念，零写不绑定key。根返回根不可退出；已不可逆退出的普通身份返回目标已退出，不得借退役→活跃复活。

合法迁移只同笔退出旧生命周期值并建立一项目标状态值，保证任一有效截止恰一项当前状态；不改变定义、父边、来源或支持，新值来源仍为概念自身。不判断成熟、召回或使用频率。发布H独立读回旧值退出H、新值创建H与概念身份不变；旧key重试按第6节重建旧G操作。

支持退出在原G完整重建预期记录，逐字段互证记录、归属/概念/world关系、H值事实、目标、来源、截止和生命周期。已退出记录不能经新key取得成功，只有首次精确重放返回原成功。合法退出一笔关闭记录节点、三条关系和H值共五项，端点保留。原证据按历史H验证，不要求world当前重新符合新支持准入；历史不可读明确失败。发布后两个方向当前查询均无该记录，退出前H历史仍完整。

### 7.2 退役概念不可逆退出

先读目标及同根完整图：根不可退出；非退役或退役值编码不符为引用冲突；已退出身份为目标已退出。前置核验本类已知的当前支持为空、指向目标的定义模板引用为空，并完整核验本类自有定义/来源/上下位与生命周期结构。L1现有源/目标关系组要求具名关系类型，按来源值组也要求owner，本类不能在派发前枚举任意未知关系类型或其它owner的全部引用。名称、实例名称字段节点及其它未知外部引用由L1同G原子引用守卫阻止退出；不能因只检查已知结构而断言全仓引用为空。实际派发后即使L1因外部引用拒绝，本模块仍沿第6节返回可能已发布并保留原请求/已知H，不虚构确定零发布回执。测试可独立核验该真实拒绝的前后G和原key未绑定以证明此用例零事实变化，但不据此放宽生产响应分类或声称预检已枚举外部引用。

在原G纯值复制完整图，记目标直接上位P和直接下位C；移除目标及全部相接边得到剩余图。候选替代边为P×C，按上位编码/下位编码排序去重。逐对检查剩余图（含此前已决定加入的候选边）：已有绕开目标的可达路径则跳过，否则加入直接边。拒绝跨根、自环和成环；最终所有剩余普通概念必须到所属唯一根，保留每对原上位到原下位的可达关系。其它父边与共享分支保持，不持久化间接边、层号或展开路径。候选乘积、遍历计数和新增关系受预算及溢出检查约束。

一笔规范化owner写集新增确定替代边，并退出：目标全部当前上下位边、根归属/规则/定义成员/来源成员关系；定义记录的当前关系和值；来源记录当前world关系及H值；目标种类/退役生命周期值；定义记录、来源记录和目标节点。已释放world边不再次退出，每个当前事实只列一次。自己定义的模板出边属于必要清理，其它概念指向本目标的模板边不可代删。根、规则、结构类型、world及其它概念不退出。替代边从首关系键起按确定顺序分配，所有退出身份按稳定编码全局升序，严格与L1首次规范化材料一致。

派发前引用、图、预算、历史失败返回对应状态；派发后沿第6节可能发布分账。发布H核验全部退出事实的退出H、替代边成立及剩余图闭合，历史定义和来源仍可回查。结果已退出事实是完整真实编码集合，关系组只含本次新增替代边；概念载荷从退出前有效历史重建并携真实退出H，不冒充H时当前概念。以后相等定义取得新身份；当前精确查找不命中退出历史，不复用已退出身份。

### 7.3 形成来源当前world引用释放

只允许定义宿主、定义特征类型、来源存在、来源特征四类world边。按目标完整读取各类型当前入边，验证owner、记录种类、所属概念、记录创建H、关系生命周期及原目标，按关系编码排序。FT仅属于形成引用，不属于支持world类型；模板概念、根/规则/成员、上下位或支持边均不进入返回集合。

请求完整预期当前引用必须与同G正式集合逐字段相同；遗漏、多报、重复、串换关系/目标均引用冲突。两组同为空时无须变更、空退出组，零写不绑定key。原端点按记录创建H历史验证，不要求world当前重新符合新概念准入。释放前原定义与来源必须可重建；资料已清理明确失败，不凭编码猜签名。

合法释放一笔只退出该完整集合的world关系。概念、定义/来源记录、成员边、值域、证据H、治理状态与模板概念引用保持。发布H逐条确认已退出、当前形成引用组为空，以及有关概念仍可完整读取且规范化定义与来源证据相同。退出事实载荷仅含本次world关系。释放不改变模板语义，不宣称解除world全部阻塞；支持走支持退出，其它owner引用由各唯一提供者处理。本模块不提供物理清理或任意概念引用释放。
