# 实例特征 IFR L2 完整投影读取详细设计 v0.1

读取只调用既有 `L1事实基座服务` 的当前事实代次、历史节点、历史关系组和历史属性值组接口；每次读取后重新核验读回代次仍等于请求 Gread。它不使用写端口。

空 IF/R 是合法 `未找到`，由 L3 解释为首个 R；任何已出现的半结构、重复关系、错误 owner/type/direction、属性槽缺失或多值均为 `引用冲突` 或 `内部不一致`，不由 L2 解释业务意义。预算计数包含已读取的所有相关关系；不足即返回并清空投影。R项的材料属性读取以 v2 `R项材料属性类型` 为唯一允许类型，U64组以 `{格式版本,类别,规范化载荷...}` 反序列化。

投影承载所有节点和关系的编码、创建H、可选退出H；当前成功投影仅含 H 时刻活动事实。R项与成员排序由 L2 固定，使后续预期快照逐字段比较不依赖底层返回顺序。
