## 1. 目标与边界

实现 `BIZ-L3-002-01-02`：经同一 `单调时钟适配器`读取当前运行纪元经过纳秒，以 `1,000,000,000`纳秒为一完整秒，结合调用方上一已消费完整秒边界形成当前观察及可选非空后继区间。

本叶只读时间证据，不保存或推进游标，不读取 DATA、墙钟、缓存或日志，不修改安全值、服务值或合同。父级治理批次、普通应用装配、自我线程和实际时间维护均为 `NOT_RUN`。

## 4. 固定算法与映射

```text
校验服务配置为同一非零代次、非零纪元和固定时间源版本
-> 校验请求合同、非零字段和非负上一边界
-> 复核请求代次、纪元和源版本与服务配置一致
-> 使用 L4 自身合同常量形成并调用单调时间证据请求
-> 复核状态、optional、全部回显和非负经过纳秒
-> 当前完整秒边界 = 当前经过纳秒 / 1,000,000,000
-> 与上一已消费边界比较
-> 相等返回无新完整秒
-> 更小返回时间倒退
-> 更大形成 [上一+1, 当前] 和 当前-上一 数量
```

固定状态映射如下：

| 条件 | L3 状态 | 守恒 |
| --- | --- | --- |
| 服务配置的运行代次、时间纪元为零，或配置的时间源版本不是固定版本 | 内部不一致 | 零 L4 调用；观察和区间为空 |
| 请求合同错误、运行代次 / 纪元 / 期望源版本为零，或上一边界为负 | 请求拒绝 | 零 L4 调用；观察和区间为空 |
| 请求运行代次或纪元与服务配置不等 | 纪元错配 | 零 L4 调用；观察和区间为空 |
| 请求期望源版本与服务固定配置不等 | 时间源版本漂移 | 零 L4 调用；观察和区间为空 |
| L4 返回纪元错配、时间源版本漂移或计数不可表示 | 保持 L4 同名状态 | 观察和区间为空 |
| L4 返回请求拒绝或内部不一致 | 内部不一致 | 不把内部构造错误归责给 L3 调用方；观察和区间为空 |
| L4 返回已读取但证据为空、非已读取却携带证据、任一回显不等、经过纳秒为负 | 内部不一致 | 不计算秒边界；观察和区间为空 |
| 当前边界小于上一边界 | 时间倒退 | 观察和区间为空；不钳制、不推进游标 |
| 当前边界等于上一边界 | 无新完整秒 | 携带观察，区间为空 |
| 当前边界大于上一边界 | 已读取 | 携带观察和非空区间 |

L3 请求的合同版本与 L4 请求的合同版本是两个独立常量；不得因为当前数值同为 1 就把 L3 请求值透传为 L4 合同。纳秒非负，整数除法即向零取整，等于向下舍弃余数。

`当前完整秒边界`由非负 `I64` 纳秒除十亿得到。只有在 `当前 > 上一 >= 0` 后才计算区间，因此 `上一 + 1 <= 当前`，`当前 - 上一`处于正 `I64` 范围；先完成这些范围证明，再转换为 `std::uint64_t` 数量。L3 本地不存在一个可达的数量溢出分支；`计数不可表示`只保持 L4 对纳秒计数不可表示的正式结果，任何与上述证明矛盾的本地形状返回内部不一致。
