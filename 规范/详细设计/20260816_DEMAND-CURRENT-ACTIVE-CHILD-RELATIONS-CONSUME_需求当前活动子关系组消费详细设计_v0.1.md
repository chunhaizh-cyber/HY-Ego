# 需求当前活动子关系组消费详细设计 v0.1

日期：2026-08-16

计划身份：`DEMAND-CURRENT-ACTIVE-CHILD-RELATIONS-CONSUME`

## 1. 目标与完成边界

实现单一业务叶：

```text
BIZ-L4-002-04-02-02 v0.2
需求业务服务::读取父链各节点当前活动子关系
-> DATA-EXT-12 按根到叶需求身份链和非零共享截止有界读取全部当前直接子关系及活动材料
```

调用方给出根到叶非空无重复需求身份链、运行代次、父级共享事实截止 `G0`、范围 / 规则版本和当前子关系总数量预算。本叶一次调用 DATA-EXT-12，逐父互证完整父端点、全部当前父子关系、子端点、路径角色和已发布活动结论，只按正式结论选择当前活动项后返回调用方拥有的不可变逐父结果组。任一父空组以及全链空组都是合法成功。

本叶全程只读，不沿父关系重建父链，不重判活动性，不读取权重值、任务、满足、结算或历史隔离摘要，不建立、修改、退出需求或活动事实。完成最多证明这个具名 BIZ provider 真实消费 DATA-EXT-12；不证明父 L3 组合、活动重判、当前任务树、父级 G0/G1 或自我治理业务闭环。

## 3. 基础数据公开消费合同

### 3.1 唯一 DATA 操作

DATA-EXT-12 必须提供具名操作：

| 操作 | 请求 | 成功返回 | 合法空与失败 |
| --- | --- | --- | --- |
| 按父链和指定截止有界读取当前直接子关系与活动材料组 | 合同版本、根到叶非空无重复 `L2需求身份`组、非零 G0、事实范围版本、需求范围版本、需求树规则版本、路径规则版本、活动规则版本、读取规则版本和非零当前子关系总数量预算 | 按请求父链同序的逐父完整结果组；每组含完整父端点、按显式路径角色 / 顺序与稳定身份确定排序的零或多项全部当前直接子关系、完整子端点、当前路径角色、已发布活动结论、全部版本回显、结果截止 G0 和零变更代次 | 每父无当前直接子关系和全链无子关系为已读取成功；总预算超限零组拒绝；父未找到 / 已退出、漂移、许可拒绝、资源失败和内部不一致分别返回，BIZ 再按本设计映射 |

成功必须满足：

```text
逐父组数量 = 请求父链数量
逐父组顺序 = 请求根到叶顺序
每个父组都携带该父需求完整当前端点；空子组仍保留父端点
每项子材料携带：当前父子关系、完整当前子端点、当前路径角色事实、当前活动结论事实；非活动当前子关系也必须完整返回
四项的父需求、子需求、父子关系身份、主体、生命周期、规则版本和单项事实截止 G0 逐字段一致
活动结论明确区分当前活动阻塞与合法非活动分支，BIZ 可据此确定性选择
组内按显式路径角色 / 顺序、再按父子关系或子需求稳定身份确定排序；零重复、零截断
```

DATA 只保存并按正式结构读取已发布事实，不在读取时判断需求是否合理、目标是否满足、哪个子项仍阻塞、权重是否非零或任务是否完成。BIZ 必须接收全部当前直接子关系及完整活动材料，只按已经发布的强类型活动结论选择结果；不得从原始状态、目标、权重或任务事实重新计算。

### 3.2 版本、截止和预算

普通应用在构造 `需求业务服务` 时注入不可变 `需求当前活动子关系固定配置`：运行代次、事实范围版本、需求范围版本、需求树规则版本、路径规则版本、活动规则版本和读取规则版本。每次请求必须逐字段匹配有效固定配置；全部范围 / 规则版本原样进入 DATA 请求并由成功结果回显。

请求只使用父级给出的非零 G0，不请求最新，不使用 owner 子截止、发布见证或缓存版本。运行代次只在 BIZ 请求与固定配置中匹配、回显，不进入 DATA 请求。当前子关系总数量预算必须非零，计数对象是 DATA 返回的全部当前直接子关系而不是筛选后的活动项；DATA 超限返回零业务载荷的数量预算不足，不截断、不分页、不选择前 N 项；BIZ 使用 checked 加法复核全部当前直接子关系累计数量。

DATA-EXT-12 必须与同一需求业务服务其它操作来自普通应用同一个 `L1事实基座运行包`。相同数值但不同 L1 实例不构成同一 G0。

### 3.3 与活动重判分账

本叶只消费已经发布的当前活动事实。活动事实的形成、变化和发布由 BIZ-L3-002-06-03 及其后继事务拥有；DATA 返回全部当前直接子关系及其正式活动材料，BIZ 把正式结论为当前活动且仍阻塞父目标的成员加入结果，把正式结论为已收束、已取消或其它合法非活动的成员确定性排除。缺结论、未知结论、同关系多结论或材料矛盾属于内部不一致；不得根据需求生命周期、目标差距、权重、任务状态或子项数量临时形成新的活动结论。

继续扩展同一文件 / 模块：

```text

模块：海中鱼巣.领域.服务.需求
所有者：DATA 之外的需求读取业务解释
```

最终形态在前两叶构造基础上增加活动子关系固定配置：

```cpp
class 需求业务服务 final {
public:
    需求业务服务(
        const 需求结构服务& 数据服务,
        const 需求当前根组固定配置& 根组固定配置,
        const 需求当前父关系固定配置& 父关系固定配置,
```

## 5. 固定读取和互证顺序

```text
校验服务三份固定配置共同字段及两个需求树规则版本一致，否则内部不一致
-> 校验 BIZ 请求合同、非空无重复父链、G0和非零当前子关系总数量预算，否则请求拒绝
-> 匹配活动子关系固定配置，否则当前性漂移
-> 一次调用 DATA-EXT-12 按父链、G0、范围 / 规则版本和总预算读取全部当前直接子关系及活动材料组
-> DATA 父未找到 / 已退出映射内部不一致；预算不足和其它 DATA 非成功精确分账
-> 互证结果合同、请求回显、版本、预算、截止=G0、零变更和逐父组数
-> 按请求父链顺序逐组互证父身份、完整父端点和单项 G0
-> 逐项互证父子关系、完整子端点、路径角色、活动结论、来源、生命周期、版本和 G0
-> 互证组内严格排序、身份唯一及 checked 累计当前子关系总数量不超过请求预算
-> 按强类型活动结论把当前活动且仍阻塞父目标的成员加入结果，确定性排除合法非活动成员；不重新计算
-> 一次形成完整候选
-> 无抛出交换到结果 optional
-> 返回已读取；允许任一或全部父组为空
```

禁止按父链循环调用 DATA，或先读全部子关系再跨调用读取角色 / 活动。BIZ 必须对同次返回的完整材料只按已发布强类型活动结论选择，不得用需求生命周期、目标、权重、任务状态、子项数量或列表位置重算活动性。

## 6. 非成功映射与异常

| DATA / BIZ 情形 | BIZ 状态 | 载荷 |
| --- | --- | --- |
| 服务固定配置无效、三配置共同字段不等或两个需求树规则版本不等 | 内部不一致 | 空；零 DATA 调用 |
| BIZ 请求坏合同、空 / 重复父链、零字段或零预算 | 请求拒绝 | 空；零 DATA 调用 |
| 合法请求与有效固定配置版本不等 | 当前性漂移 | 空；零 DATA 调用 |
| DATA 任一请求父未找到或已退出 | 内部不一致 | 空；同 G0 父链已由上游冻结，不能降级为普通空结果 |
| DATA 当前子关系总数量预算不足 | 数量预算不足 | 空；不得截断 |
| DATA 事实代次漂移或结果 / 单项截止不等于 G0 | 当前性漂移 | 空 |
| DATA 明确许可拒绝 | 提供者拒绝 | 空 |
| DATA 资源失败、`std::bad_alloc`或`std::length_error` | 资源失败 | 空 |
| DATA 请求拒绝、运行态未实现 / 未装配、逐父缺组 / 多组 / 乱序、错父子端点、半结构、重复、错误路径角色、活动结论缺失 / 未知 / 复义 / 矛盾、坏生命周期、成功组超过总预算、checked 累计溢出或未知异常 | 内部不一致 | 空 |

任何非成功都不携带逐父组、活动关系或事实截止；失败不返回已经完成的前缀组。
