## 1. 目标和完成条件

依据4201、4202、4203、4212和4230，先发布C/E/S完整使用绑定的最终ABI与显式未实现骨架。完成条件仅是：精确DTO、守卫、两个窄接口和场景/存在骨架能够编译；所有骨架入口稳定返回 `未实现`、零代次、空载荷且零L1访问。合法场景C与存在E的族身份生产路径尚未闭合，因此本片不创建、读取、退出或恢复B事实，也不解除动态类真实实现门禁。

## 2. 当前事实与复用裁决

- `数据服务.状态类.ixx` 已实现状态v2四字段、当前/历史完整内容、当前身份确认和历史身份见证，直接复用，不修改。
- `数据服务.存在类.ixx` 当前仍是旧实现，且没有4230族身份来源的合法生产路径；本片只以窄增量实现存在身份只读接口的 `未实现` 骨架，不得用旧 `查询存在` 冒充共同身份确认。
- `数据服务.场景类.ixx` 当前工作树为空，也没有完整七字段场景和场景族身份的合法生产路径；本片只建立状态使用绑定服务的最终签名与 `未实现` 骨架。
- L1 owner-scoped普通节点、关系、同写集、当前/历史读取、幂等及生命周期是后继真实实现的复用基础；本片骨架不得调用任何L1入口。
- 旧散装状态关系没有共同分组身份，裁决为拒绝解释，不迁移。

## 4. 后继真实数据与本片骨架分账

B是后继真实实现中的场景owner普通节点；三条关系均为场景owner、同一成员关系类型，角色1/2/3分别指向C/E/S。首次创建写集固定四项，不含值或属性槽，退出写集固定退出B和三关系。C与E允许同码但必须分别通过两族确认。

后继真实创建流程冻结为：

```text
校验请求/G0/结构交付
-> 场景owner内部确认C族身份
-> 存在窄提供者确认E身份
-> 状态类确认S身份并读取S完整内容
-> 再次确认G0
-> 提交B+三边同写集
-> 按首次发布G完整读回
-> 返回已创建/精确重复或已可能发布
```

本片不执行上述流程。所有创建、当前/历史读取、三类反查、退出和两个身份窄读骨架均不访问依赖，直接返回4203规定的 `未实现`。当前和历史真实读回、反查和幂等流程仍按4203冻结，留待合法C/E生产路径发布后的后继计划实现。

三类反查只改变召回角色：C用角色1、E用角色2、S用角色3。候选预算在过滤前计算，超过预算返回数量预算不足；全部候选完整读回后按B编码排序。

幂等重放比较完整规范化请求。事实代次漂移不绑定；提交已成立后读回失败保留首次事实及幂等账，返回已可能发布。退出前先检查L1当前引用闭包，存在外部活动引用则返回引用冲突。

## 5. 失败优先级

骨架不进入真实失败优先级：无论输入为何均返回 `未实现`、合同版本1、事实截止0、无变更和空载荷。后继真实实现的固定顺序仍为：请求形状 → 当前代次守卫 → C身份 → E身份 → S身份/内容 → B结构 → 引用保护 → 提交 → 发布后读回；该顺序不得由骨架自行实现一部分。

## 6. 迁移、恢复和排除项

没有存量转换算法。旧散装关系、旧成员列表、状态当前选择和旧关系编号零解析、零双写。恢复只消费4070已恢复的L1事实，按指定结构交付和截止重新互证；只重建可丢失索引。

明确排除：P、状态字段变化、完整场景七字段、场景树、动态组织、动作来源、动态/动态概念/因果、普通应用装配、L1修改、物理清理新入口。
