# 5320 子规范 本能函数代码接口详细设计

编号：5320-接口

状态：待确认详细设计

------------------------------------------------------------------------

# 1. 定位

本设计承接：

-   5310 本能方法自身环境就绪
-   5320 本能函数实现与返回边界
-   3300 方法根规范

目标：

将本能方法规范转换为统一代码接口边界。

本设计不负责：

-   方法选择
-   任务创建
-   需求生成
-   方法学习晋级
-   方法代际发布

------------------------------------------------------------------------

# 2. 本能方法执行链路

统一执行链：

    任务实例方法
        ↓
    本能方法执行入口
        ↓
    执行环境建立
        ↓
    条件节点匹配
        ↓
    输入参数绑定
        ↓
    本能函数执行
        ↓
    生成运行虚拟存在
        ↓
    生成输出结果场景
        ↓
    生成动作动态
        ↓
    任务读取结果

------------------------------------------------------------------------

# 3. 本能方法执行环境

执行环境是本能函数执行前必须建立的上下文。

建议结构：

    本能方法执行环境
    {
        方法身份

        方法虚拟存在

        当前实例方法身份

        条件节点集合

        输入条件场景

        参数绑定结果

        目标对象

        执行权限

        本轮运行虚拟存在
    }

------------------------------------------------------------------------

# 4. 执行环境检查

执行前必须检查：

## 方法身份

必须存在：

-   方法头
-   方法动作
-   方法虚拟存在

缺失：

返回方法结构错误。

------------------------------------------------------------------------

## 条件节点

必须：

    当前输入条件
    匹配方法条件节点

禁止：

    输入包字段
    直接替代条件节点

------------------------------------------------------------------------

## 输入参数

必须完成：

    条件节点
    +
    输入场景
    +
    参数绑定

缺失：

返回参数绑定失败。

禁止：

-   默认补齐
-   名称推断
-   隐式转换

------------------------------------------------------------------------

# 5. 本能函数接口

统一形式：

    运行虚拟存在*
    执行本能方法(
        本能方法执行环境&
    )

返回：

    运行虚拟存在

不是：

-   bool
-   单个特征值
-   单个结果节点
-   字符串状态

------------------------------------------------------------------------

# 6. 运行虚拟存在

本轮执行必须生成：

    运行虚拟存在
    {
        方法身份

        方法虚拟存在

        开始时间

        结束时间

        输入场景

        输出结果场景

        执行状态

        错误状态

        动作动态引用

        执行摘要
    }

作用：

记录一次本能方法调用事实。

------------------------------------------------------------------------

# 7. 输出结果场景

输出结果不得直接作为函数返回值。

必须进入：

    运行虚拟存在
        ↓
    输出结果场景

输出包括：

-   结果特征
-   结果状态
-   实际变化
-   结果证据

------------------------------------------------------------------------

# 8. 动作动态生成

本能函数执行完成后：

生成：

    动作动态
    {
        动作入口

        输入

        输出

        时间

        方法身份

        执行结果
    }

动作动态用于：

-   事实记录
-   学习分析
-   因果分析

不能直接等同：

-   任务完成
-   需求满足
-   正式结算

------------------------------------------------------------------------

# 9. 错误返回

失败也必须生成运行虚拟存在。

异常类型：

## 方法环境错误

例如：

-   方法不存在
-   动作入口不存在
-   条件节点缺失

处理：

记录错误并阻断执行。

------------------------------------------------------------------------

## 输入绑定错误

例如：

-   缺输入
-   条件不匹配
-   参数不足

处理：

返回条件不足。

------------------------------------------------------------------------

## 执行错误

例如：

-   动作执行失败
-   外设失败

处理：

生成运行事实。

------------------------------------------------------------------------

# 10. 禁止事项

禁止：

1.  本能函数直接返回任务状态。
2.  本能函数直接修改需求状态。
3.  本能函数直接形成正式结算。
4.  本能函数绕过条件节点。
5.  本能函数使用方法名称判断能力。
6.  本能函数使用显示文本作为逻辑依据。
7.  本能函数直接修改长期方法结构。
8.  本能函数直接发布方法新代际。
9.  本能函数返回单一特征值作为执行结果。
10. 本能函数失败时静默成功。

------------------------------------------------------------------------
