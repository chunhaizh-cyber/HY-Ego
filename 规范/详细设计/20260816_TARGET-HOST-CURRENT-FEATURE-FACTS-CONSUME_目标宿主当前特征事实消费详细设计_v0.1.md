# TARGET-HOST-CURRENT-FEATURE-FACTS-CONSUME 目标宿主当前特征事实消费详细设计 v0.1

日期：2026-08-16

## 1. 目标与完成边界

本叶为 BIZ-L4-004-01-01-02 建立 provider-only 读取能力：在一个调用方给定的非零事实截止 `G0` 下，证明指定场景属于预期具名树，指定宿主是该场景直接成员，宿主存在当前，并取得同宿主同目标特征定义的唯一当前实例及当前值。

完成只表示 BIZ 值式 provider 代码、生产外验证和正式发布完成。它不读取状态 / 动态 / 因果，不比较目标差距，不创建需求 / 任务，不让普通应用持有 provider，也不证明 BIZ-L3-004-01-01、BIZ-L2-004-01 或自我治理闭环完成。

## 2. 正式依据与当前事实

- 4110：同一宿主和同一抽象定义在同一当前版本只能形成一个实例槽；实例允许没有当前值。
- 4160、5100：当前满足由当前事实与目标状态正式比较；需求领域不直接比较原始值。
- 4190、4230：状态 / 动态是调用方完整提交的独立结构，DATA 和 BIZ 均不得从当前特征值补造。
- 4200 v1.4：旧世界树业务门面退出；现行可复用的是具名树归属、完整场景与结构成员读取。
- 当前 ABI 已存在且从同一 `L2结构聚合服务`取得：`L2场景结构服务::读取场景树归属`、`读取完整场景`，`L2存在结构服务::读取完整存在`，`L2特征结构服务::按存在读取全部当前特征`。
- `TARGET-STATE-CONTRACT-DEFINITION-CONSUME v0.1` 已冻结同一 provider、数据头与聚合引用，但代码尚未实现。本叶必须等待它的真实结果 / 退出并串行扩展，不新建第二 provider。

## 3. 物理归属与依赖

生产物理位置固定为：

```text
海中鱼巣/领域/需求目标事实.数据.h
  -> 追加本叶 DTO、状态、helper 和成功谓词

海中鱼巣/领域/提供者.需求目标事实.ixx
  -> 在同一 需求目标事实提供者 中追加 const noexcept 成员函数
  -> provider 继续只持 const L2结构聚合服务&
```

上一叶已负责两个生产文件的工程登记；本叶不得修改 `.vcxproj`、`.filters`、普通应用装配、成员、状态或 getter。每次调用只从聚合引用取得同实例场景 / 存在 / 特征 const 服务。

## 5. 固定调用顺序

1. 纯值校验两个版本、非零 G0 及四个强类型身份；失败返回入口拒绝并保证四服务零调用。
2. 调用 `读取场景树归属({{L2结构合同版本, G0}, 当前, 目标场景, 0})`，互证场景、树、生命周期与 G0。
3. 调用 `读取完整场景({{L2结构合同版本, G0}, 当前, 目标场景, 0})`，在直接成员中按强类型存在端点选择目标宿主：零项为目标范围不成立，多项或坏端点为内部不一致。
4. 调用 `读取完整存在({{L2结构合同版本, G0}, 当前, 目标宿主, 0})`，互证身份、生命周期与 G0。
5. 调用 `按存在读取全部当前特征({{L2结构合同版本, G0}, 目标宿主})`，只按 `宿主存在 == 目标宿主 && 特征定义 == 目标特征定义` 选择。
6. 匹配零项返回目标特征实例未找到；多项违反 4110 唯一性，返回内部不一致；恰一但当前值为空返回目标特征当前值未设置。
7. 逐字段互证四次结果头的合同、截止与空变更代次；前三次读取另查当前类别和历史截止为零，第四次只按其真实 ABI 检查成功谓词、完整实例组、实例宿主 / 定义、生命周期和当前值来源。最后一次构造完整候选并返回已读取。

四次 DATA 调用每次至多一次。禁止用零截止重选最新、把前次回显截止传给后次、局部重试、首末探针、缓存或历史补项。

## 6. 状态映射与守恒

| 来源 | BIZ 状态 |
| --- | --- |
| 请求自身无效 | 入口拒绝，零 DATA 调用 |
| 首笔场景树归属读取返回入口拒绝 | 入口拒绝；wrong-family 不冒充许可问题 |
| 首笔归属未找到 / 已退出 | 目标场景未找到 / 目标场景已退出 |
| 归属树不等、场景无目标宿主成员 | 目标范围不成立 |
| 已证明场景后再读场景缺失 / 退出 / 入口拒绝 / 引用冲突，或已证明成员后存在缺失 / 退出 / 入口拒绝 / 引用冲突 | 内部不一致 |
| 特征组成功空组或无目标定义匹配 | 目标特征实例未找到 |
| 恰一实例但当前值为空 | 目标特征当前值未设置 |
| 任一 DATA 事实代次漂移 | 当前性漂移 |
| DATA 许可拒绝 | 许可拒绝 |
| DATA 资源失败；`bad_alloc` / `length_error` | 资源失败 |
| 已证明完整存在后特征组读取返回入口拒绝 / 引用冲突，或 DATA 内部不一致、未实现、坏成功形状、混代、重复实例及其它异常 | 内部不一致 |

所有结果回显请求携带的合同版本和规则版本；只有两者均为当前值时才可能成功。所有非成功结果的 `材料` 必须为空。成功结果和材料截止均等于请求 G0。入口拒绝回显请求原始截止；进入 DATA 后的非漂移失败回显请求 G0；当前性漂移优先回显首个 DATA 返回的非零实际截止，没有非零回显时保留请求 G0。任何异常都不得泄漏部分材料或改变 DATA 事实。

## 7. 并发、所有权与 noexcept

函数只使用局部值式材料，不持有锁跨 DATA 调用，不保存请求、结果、指针或缓存。调用期间 provider 聚合引用和三个服务实例由消费者保证存活。并发发布导致的合法结果只能是完整已读取或当前性漂移，不允许混代成功。

`noexcept` 边界捕获 `std::bad_alloc`、`std::length_error` 为资源失败；其它异常为内部不一致。业务函数不记录机器事实，日志和诊断不能改变返回状态。

## 8. 验证矩阵

1. 请求 helper：两个版本、零 G0、四个零身份逐项拒绝，四服务零调用。
2. 真实公开 DATA 成功：树归属、场景成员、存在、唯一同定义实例与当前类型化值全部使用 G0，返回材料逐字段一致；I64 适用性由父 L3 与目标合同材料共同互证，本叶不独立猜测值域。
3. 场景未找到 / 已退出分别返回并零材料。
4. 请求树不等、指定场景无目标宿主分别返回目标范围不成立。
5. 合法空特征组或无目标定义返回实例未找到。
6. 唯一实例无当前值返回当前值未设置，不升级为内部不一致。
7. DATA 创建侧证明同宿主同定义第二实例被拒；BIZ 多匹配保留静态防御，无法经公开 ABI 构造时标 `NOT_RUN`。
8. 并发推进任一 owner 时只允许完整已读取或当前性漂移，零混代与部分材料。
9. 首笔场景 wrong-family 映射入口拒绝；后续同 G0 已证明身份的读取再触发入口拒绝 / 引用冲突时映射内部不一致；真实许可拒绝单独映射许可拒绝。资源耗尽、私有坏形状无法稳定注入时如实 `NOT_RUN`，不得增加生产 seam。
10. 源码静态证明固定四读顺序、同一聚合、零 L1 / owner / 仓库 / 缓存 / sleep / 状态 / 动态 / 因果服务引用和零写入口。
11. 根工程 Debug / Release、生产外专项双配置、diff、strict、UTF-8、XML、工程零额外登记及生产零专项痕迹。
