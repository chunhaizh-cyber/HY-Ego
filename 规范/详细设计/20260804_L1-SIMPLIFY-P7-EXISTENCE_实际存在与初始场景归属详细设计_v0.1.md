# L1-SIMPLIFY-P7-EXISTENCE 实际存在与初始场景归属详细设计 v0.1

日期：2026-08-04

状态：设计就绪；代码待实施

对应方案：`规范/详细设计/20260804_SELF-GOV-CLOSURE_自我内部治理初始闭环实现方案_v0.2.md` STEP-3A

## 1. 目标与完成边界

本叶建立新 L1 上第一个实际存在提供者：在已验证的世界根和唯一初始场景中，以一个 L1 写集原子发布实际存在身份、实际存在资格和唯一当前场景归属，并通过正式读取入口逐项同代次读回。

真实成功顺序固定为：

```text
世界登记 -> 初始场景 -> 存在领域登记 -> 创建实际存在并接纳到初始场景 -> 同代次独立读回
```

本叶只负责实际存在资格、稳定身份和初始场景归属。它不创建实例特征、状态、动态、因果、自我资格、治理虚拟存在、内部世界或运行期生产装配。

## 2. 正式依据与能力裁决

- 1140：存在有独立身份；验证实际存在必须回读存在身份和允许的场景归属；存在领域拥有存在身份与资格，场景领域拥有场景接纳。
- 4190：存在和场景分账，实际存在与治理虚拟存在资格不得混同。
- 4200 §3、§4、§7：存在在同一世界恰有一个当前直接场景；创建存在和接纳必须同一事务；直接成员关系固定为 `场景 -> 存在`、登记中的直接成员关系类型、顺序 0；实际存在资格来源固定为存在服务。
- 4015、4020、4030：L1 只承载业务中性事实；L2 通过版本化纯值写集提交，不接触仓库、句柄、许可或事务。

当前能力裁决：

| 能力 | 当前事实 | 裁决 |
| --- | --- | --- |
| 世界根和直接成员关系类型 | `世界登记服务` 已提供正式登记 | 复用，不复制登记 |
| 唯一初始场景 | `L1场景结构服务` 已提供创建与读取 | 复用其完整值式见证 |
| L1 原子写集与稳定编码 | `L1事实基座服务` | 复用 |
| 新 L1 实际存在资格 | 尚无正式提供者 | 本叶新建 |
| 旧存在服务、旧 WORLD-TREE P1A3 | 使用旧句柄、旧仓或旧对象版本 | 仅作负面差异证据，禁止调用、包装或迁移 |

P6 特征比较与本叶没有机器语义依赖。P6 仅在施工期与本叶共享工程和启动聚合文件。

生产模块分工固定为：

- `海中鱼巣.领域.服务.L1实际存在`：登记存在服务、形成实际存在资格不可变规格、读回实际存在资格；是实际存在身份和资格的唯一解释者；

## 6. 登记事实与幂等域

L1 私有幂等键编码固定为：

```text
高 8 位 = 0x0A（存在领域登记）或 0x0B（实际存在创建）
低 56 位 = 对应公开幂等身份.值
```

### 6.1 存在领域登记

`建立登记` 在当前非空 L1 上追加两个节点：

1. 普通节点 `服务身份`；
2. `I64` 属性类型节点 `实际存在资格属性类型`。

请求的期望事实代次必须等于一次完整快照的当前代次；快照内不得已有本服务内存登记。提交后返回映射必须精确包含本地键 1、2 且编码不同。服务再从公开 L1 单项入口逐项同代次读回，确认节点类型和属性表示后才保存登记。

同一服务实例同键同义返回幂等读回；同键异义或登记后不同首次请求返回幂等冲突。新服务实例不扫描 L1 猜测登记，`读取当前登记` 返回 `未找到`。

### 6.2 两份不可变规格

`形成实际存在写入规格` 只在登记已加载且请求代次有效时，从当前登记复制服务身份、资格属性类型和固定资格值1；它不读取或写入场景关系，不提交 L1。

`形成初始场景接纳规格` 调用现有初始场景读取实现，验证世界登记、初始场景和请求代次后，只返回场景身份及世界登记中的直接成员关系类型；它不知道待接纳对象的存在资格，不提交 L1。

两份规格均为调用方拥有的不可变值，只对其 `事实截止代次` 有效。组合服务只接受两份规格代次等于请求期望代次。

场景侧 `世界结构状态` 与组合结果按同名稳定状态一一映射：已提交、幂等读回、已读取、未找到、入口拒绝、幂等冲突、版本漂移、许可拒绝、资源失败、内部不一致。规格入口正常只返回 `已读取` 或非成功；组合服务不得把非成功降级或重分类为空成功。

### 6.3 创建实际存在并接纳初始场景

写前必须依次成立：

1. 请求版本、规则、幂等身份、期望代次和全部稳定编码有效；
2. 存在登记已加载且完整；
3. `L1实际存在服务::形成实际存在写入规格` 成功；
4. `L1场景结构服务::形成初始场景接纳规格` 成功；
5. 两份规格事实代次、请求期望代次相同。存在和场景当前性已经分别由事实所有者在形成规格时验证；组合服务不得再读取完整快照并重解释两域事实。并发变化由 L1 写集的期望代次拒绝。待创建存在使用本地键，因此首次请求天然没有旧归属。

唯一写集固定为：

| 本地键/项 | 内容 |
| --- | --- |
| 节点 1 | 普通节点：实际存在身份 |
| 值 2 | 所属=节点1；属性类型=登记.实际存在资格属性类型；材料=I64 `1`；来源=登记.服务身份 |
| 关系 3 | 源=初始场景；目标=节点1；类型=世界登记.直接成员关系类型；顺序=0 |
| 属性槽变更 | 节点1 的实际存在资格属性槽指向值2 |

L1 写集只提交一次，期望代次来自请求，幂等键使用 `0x0B` 域。成功或精确重复都必须验证新编码映射精确为本地键 1—3，且三个编码非零、互异。

## 7. 独立读取与完整性

`读取实际存在` 不信任创建函数回显。组合服务分别调用 `L1实际存在服务::读取实际存在资格` 和 `L1场景结构服务::读取初始场景接纳`，只在两份事实具有同一非零代次时合并结果。事实所有者内部逐项确认：

- 存在是当前普通节点；
- 资格属性类型是当前 `I64` 属性类型；
- 资格值当前、所属存在、材料为 `1`、来源为存在服务身份；
- 存在当前资格属性槽唯一指向该资格值；
- 归属关系当前，类型为世界登记中的直接成员关系类型，方向 `初始场景 -> 存在`，顺序 0；
- 场景服务在同一完整快照中证明该存在作为目标的当前直接成员关系恰一，且没有第二当前场景归属。

任何必需编码未解析为 `未找到`；请求见证与当前事实不一致为 `版本漂移`；资格、来源、属性槽、关系方向/类型/基数损坏为 `内部不一致`。成功返回调用方拥有的不可变 `实际存在事实`。

创建函数在 L1 发布后构造读取请求调用同一读取实现。读回代次必须等于写入结果代次；不一致返回 `版本漂移`，不得回滚或补写已发布事实。

## 8. 并发、生命周期与错误

- 登记建立由存在服务独占锁串行；同一服务实例只能形成一个登记。
- 组合创建可由多个工作线程调用；每次消费两份不可变规格，幂等和原子性由 L1 写集裁决。同键同义只形成一个发布事实，同键异义为幂等冲突。
- 两个事实所有者分别读回自己的事实，组合服务只校验同代次并组装值式结果；不得跨 L1 调用保存许可或内部投影。
- 发布前任一失败由 L1 保证零普通可读变化；服务不得自行补偿、删除或重试写集。
- 事实随 L1 生命周期长期保存。移除、移动、恢复重载和生产装配不在本叶中实现。

错误映射：

| 情形 | 结果 |
| --- | --- |
| 版本、规则、身份、零代次或形状非法 | `入口拒绝` |
| 登记/世界根/初始场景/存在无法解析 | `未找到` |
| 同键异义或第二首次登记 | `幂等冲突` |
| 请求代次、读回代次或当前编码漂移 | `版本漂移` |
| L1 资源失败或 `bad_alloc` | `资源失败` |
| 多归属、错来源、错类型、错值、映射损坏或未知异常 | `内部不一致` |
