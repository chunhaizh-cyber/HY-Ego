## 3. 自我结果争用成员优先级合同

### 3.1 所有权与结构

该裁决是自我治理事实，唯一业务 provider 位于：

```text
数据：海中鱼巣/领域/自我治理/自我结果争用成员优先级.数据.h
服务：海中鱼巣/领域/自我治理/服务.自我结果争用成员优先级.ixx
module：海中鱼巣.领域.自我治理.服务.自我结果争用成员优先级
结构 owner：L2自我治理结构服务，owner 0x0304
登记键：0x0304'2040..0x0304'206F
```

线程只形成请求；自我领域 provider 验证并发布；结构服务只机械保存和读回。不得把任务执行优先级、队列顺序、需求权重、预算、创建时间、稳定编码或列表顺序转成该优先级。

### 3.2 DTO 与公开入口

为避免 self owner 与 result owner 形成循环依赖或在两个命名 module 中重复拥有同一实体，以下共享值类型唯一声明并导出于`海中鱼巣/领域/合同.任务结果消费共同.ixx`，其 module 唯一为`海中鱼巣.领域.合同.任务结果消费共同`：两种优先级身份、消费形态、扣减维度、容量合同和成员资格材料。该合同 module 只 import`海中鱼巣.核心.合同.L1公共事实`、`海中鱼巣.领域.服务.L2任务结构`、`海中鱼巣.领域.服务.L2需求结构`以及标准`<cstdint>/<vector>`，不含服务、owner、写入口或业务裁决。`服务.L2自我治理结构.ixx`和`服务.L2任务结果消费结构.ixx`必须`export import 海中鱼巣.领域.合同.任务结果消费共同;`后再在各自 module 内声明自有 DTO；禁止任何 `.数据.h`复制、转声明或文本包含这些共享实体。授权事实、授权收口事实、优先级批次/成员事实和后继决议事实统一声明在`L2自我治理结构.数据.h`；三个自我业务数据头只声明各自请求/结果。完整消费分配记录只在 result 数据头声明。

### 3.3 验证算法

provider 固定执行：

```text
验证合同、许可、身份、幂等和共同截止
-> 独立读取正式结果、容量合同及冻结成员集合
-> 候选组按成员身份规范化，但不得据此生成业务顺序
-> 验证每个冻结成员恰有一项候选且没有额外成员
-> 验证优先级序号、同级顺序序号均非零
-> 同一优先级内同级顺序全局唯一
-> 每项理由证据非空、当前且绑定该成员和正式结果
-> 证明容量合同是争用形态；可重复引用不得进入本provider
-> 在自我 owner 单次写集中形成一个批次和全成员事实
-> 独立读回完整批次与成员组
```

同键同义读回首次结果；同键异义、成员漏项/多项、重复同级序号、来源规则或版本变化全部零新增拒绝。

### 4.2 原子形成算法

```text
交换前独立读取结果、冻结成员、容量合同和可选优先级批次
-> 完整验证所有候选、容量、量纲、规则和当前性
-> 可重复引用：按成员身份规范化输出并赋处理顺序1..N；每项共同引用、正式优先级空，最低/期望/分配前/实际/分配后全为0
-> 可分割：按正式全序；剩余=0则结果已耗尽；0<剩余<最低则未获分配且剩余不变；否则实际=min(期望,剩余)且状态已分配
-> 不可分割：初始1、每成员最低/期望1；正式全序首个合法成员分配1，其余结果已耗尽
-> 每一步分配后剩余成为下一步分配前剩余；验证“分配前 - 实际分配 = 分配后”且sum(实际)+最终=初始
-> result owner 一次提交完整记录、关系、成员、优先级引用、逐项链和幂等账
-> 独立读回完整记录
```

逐成员合法矩阵固定为：`共同引用`只允许可重复引用、优先级空且五个分配相关数值为零；`已分配`只允许两类争用且`最低<=实际<=期望、实际<=分配前、分配后=分配前-实际`；`未获分配`只允许可分割、`0<分配前<最低、实际=0、分配后=分配前`；`结果已耗尽`只允许两类争用且分配前/实际/分配后全为零。低于当前成员最低单位后仍继续处理后继成员，禁止把稳定成员身份、任务优先级、需求权重、预算、创建时间或列表顺序补成业务优先级。

禁止逐成员可见提交。任何交换前失败零写；已确认提交后的读回失败保留事实和账，以原键重放。可共用记录不依赖优先级；争用缺任一优先级、同级顺序、单维容量或成员证据时零写并阻断后继核算。
