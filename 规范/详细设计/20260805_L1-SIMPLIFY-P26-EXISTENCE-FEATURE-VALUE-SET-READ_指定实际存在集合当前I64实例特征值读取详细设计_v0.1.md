## 1. 目标与最早缺口裁决

本叶是 SELF-GOV-CLOSURE STEP-4 在 P25 之后的下一最早提供者。它在实例特征领域新增唯一无对象状态的只读投影模块 `海中鱼巣.领域.服务.L1实例特征当前值集合读取`，对 P24 已确定的全部当前实例槽逐一读取唯一当前属性槽、I64 值、材料形状、来源节点和生命周期，并把 P25 已验证定义详情作为值域准入依据，形成完整、同截止、稳定有序的宿主特征集合投影。

当前能力矩阵：

| 所需能力 | 当前代码 / 冻结合同 | 裁决 |
| --- | --- | --- |
| 一份非阻塞当前快照 | P17 v0.1 已冻结、未实现 | P26 唯一权威读取材料 |
| 当前主体与槽结构 | P21/P24 已冻结、未实现 | P24 是精确槽范围，禁止另扫候选 |
| I64 定义详情 | P22/P25 已冻结、未实现 | P25 提供定义身份、标记和上下界，不由 P26 解析定义原始结构 |
| 实例当前值属性类型 | P23 已冻结、未实现 | 必须复用 P23 定位；P24 结果未复制该角色，P26 不得猜测 |
| 单项实例特征读取 | 当前 `读取I64实例特征` 已实现 | 要求调用方提供当前值和来源编码，并持阻塞服务锁，不能发现批量当前值 |
| 旧能力目录候选 | 旧句柄读取存在 | 不证明唯一当前值、同代次或新 L1 结构，只作负面证据 |
| 指定集合完整当前值读取 | 不存在 | 本叶最早缺口 |

本叶不读取历史值，不形成比较、差异、状态或动态，不执行 P6/4180 算法。`P25下界 <= 当前I64值 <= P25上界` 只是已冻结定义值域的当前事实完整性复核，不是特征间比较。

## 5. 固定读取流程

### 5.1 上游顺序与空集合

调用方固定使用一份 P17 快照：P17 非成功时 P24/P25/P26 调用0；P24 非成功时 P25/P26 调用0；P25 非成功时 P26 调用0。任何上游许可拒绝立即返回，不等待、不 sleep、不消耗漂移重试。P26 不调用 P17、P22、P24 或 P25，不重取快照。

P26 先校验自身版本及 P24/P25 的合同、规则、读取、排序、完整性、世界根和非零截止。必须满足：

```text
P24截止 == P25截止 == P17快照代次 != 0
P25定义身份集合 == P24全部槽引用定义身份的排序去重集合
```

P26 还须机械校验 P25 公开 DTO 自身不变量：四个登记节点见证有效，每项定义、标记、上下界身份有效，三值的所属定义、属性类型、来源服务和创建代次与 P25 具名字段一致，标记为1且下界不大于上界。该校验只消费 P25 强类型字段，不重新读取或解释定义的 L1 原始槽和值。

声称成功但范围、顺序、定义身份或截止矛盾属于内部不一致；单纯截止不等返回事实代次漂移。

若 P24 实例槽总数为0，P25 必须是同根同截止完整空定义组。P26 不调用 P23，按 P24 主体组原顺序形成一一对应的空特征组；合法空主体得到空主体组，合法非空主体零槽得到每主体空特征组。输出 `完整=true`、诊断空。

### 5.2 非空登记定位

非空时，P26 调用一次 P23 纯值静态函数 `L1实例特征服务::从快照读取登记定位(请求.登记定位, 快照)`。它不取锁、不读缓存、不重取快照。只接受 `已读取 + 完整事实`，并要求：

```text
P23截止 == P24截止 == P25截止 == P17快照代次
```

P23 的登记未加载、未找到、入口拒绝、事实代次漂移、资源失败和内部不一致保持同名状态；坏成功为内部不一致。`未找到` 只用于 P23 登记四节点全部确定未命中。P24/P25 已成功后，任一槽、当前值或来源节点缺失都是权威事实矛盾，固定为内部不一致，不降级空成功或未找到。P26 只消费 `当前I64值属性类型` 见证，不解释其它登记角色。

### 5.3 快照与逐槽当前属性

P26 只使用 P17 当前节点和当前值组。两组必须按稳定编码严格升序、无重复；所用事实编码有效，创建代次非零且不晚于截止，退出代次为空。P24 声称当前的主体/槽/定义与快照矛盾为内部不一致，不降级未找到。

对 P24 每个槽按输入稳定顺序固定要求：

1. 槽节点当前、普通，编码和创建代次与 P24 见证一致；
2. 槽节点 `当前属性` 中，属性类型等于 P23 `当前I64值属性类型.身份` 的项精确一项；其它属性类型不属于本合同，既不解释也不返回；
3. P17 当前值组中，`所属节点=该槽 + 属性类型=当前I64值属性类型` 的值事实精确一项，且其编码非零并与属性槽指向相同；
4. 值所属节点等于槽，属性类型与属性槽一致，材料分支精确为 I64；
5. 值来源编码非零，在当前节点组唯一命中普通节点，`属性类型表示` 为空；来源节点的当前属性组可非空，P26 不解释其业务资格；
6. 值创建代次和来源节点创建代次不晚于截止，值退出代次为空；
7. 按定义身份在 P25 定义详情中恰一命中，且 `下界.I64值 <= 当前值 <= 上界.I64值`。

目标类型属性缺失或重复、错类型、悬空值、错所属、错材料、悬空来源、坏生命周期或越界均为内部不一致，整个结果事实为空。P26 不读取历史入口补齐已退出值，不以调用方提供的值或来源回显补齐。

### 5.4 成功、排序和无夹带

成功时：

- 主体特征组与 P24 主体槽组一一对应，顺序相同；
- 每主体实例特征与 P24 槽一一对应，保持“定义稳定编码、槽稳定编码”升序；
- 每项复制 P24 槽结构，当前属性槽和值/来源见证来自同一快照；
- P25 完整定义详情原样保留，不把定义详情复制成 P26 第二权威；
- 快照中其它槽、值或来源不进入输出；相同来源可被多项引用，不另建来源集合；
- `完整=true`，缺项诊断为空。

内部不一致诊断按 `种类、主体身份、实例槽身份、相关事实身份` 数值升序并确定去重。所有非成功事实为空；只有内部不一致允许非空诊断，不返回已通过槽作为部分事实。
