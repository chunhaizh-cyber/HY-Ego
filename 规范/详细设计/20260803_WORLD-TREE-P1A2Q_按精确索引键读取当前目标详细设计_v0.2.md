# WORLD-TREE-P1A2Q 按精确索引键读取当前目标详细设计 v0.2

日期：2026-08-03

设计身份：WORLD-TREE-P1A2Q

## 1. 目标与当前能力裁决

P1A3 恢复后必须按两个固定 `索引物理键` 唯一读取世界根和初始场景。当前 `节点直接结构查询服务` 只有按目标反向枚举索引；`可重建索引仓库` 已真实提供 `读取索引物理键(const 索引物理键&)` 正向读取。恢复包装没有冻结携带全部当前索引，不能把偶然读回形状写成 P1A3 依赖。

现有 `可重建索引仓库::读取索引物理键` 只返回 `optional`，会把“键不存在”“正反绑定矛盾”和“目标权威记录不可读”压成同一个空值；它不能直接支撑 4010 要求的结构化结果。本设计因此先在同一索引仓内增加一个内部结构化精确读取，并让旧 optional 普通重载降为该结构化读取的兼容值式包装；随后扩展现有 L1 查询服务，复用现有 `节点直接索引读取结果` 对 L2 返回稳定见证。它不建立新仓、缓存、SQL回源、恢复旁路或第二事实代次。

上游业务归属由 `流程图/目标业务流程图/业务节点到能力与目标函数映射.md` 的“世界事实维护”冻结；直接闭环依据为 `流程图/20260802_WORLD-TREE-P1_世界树业务服务业务流程图_v0.1.md` 的 B01/B02。本叶子只提供世界根和初始场景引导所需的 L1 精确索引读取，不直接完成世界引导；所有已退出的旧业务图版本均不再构成本设计依据。

正式依据：4010、4030、4040、4200，`流程图/目标业务流程图/业务节点到能力与目标函数映射.md` 的 BIZ-L1-002 映射，以及 P1A1/P1A2 已冻结的 L1 内存权威、共享许可和值式结果合同。

### 1.1 创建侧当前接口行为与能力裁决

创建侧代码基线为 `8d8236e7ff46f58a3edd8f3120ca18fcf4ca772d`；工作区内 P1A2 执行 WIP 不作为当前能力证据。按该基线逐签名核对：

| 证据 | 当前行为 | 裁决 |
| --- | --- | --- |
| `核心/服务.节点直接结构.ixx::节点直接结构查询服务` | 已持事务域、节点、关系、索引、类型合同、类型化值六个依赖；没有按精确物理键读取函数 | 扩展现有服务，不新建第二查询服务 |
| `核心/仓库.可重建索引.ixx::读取索引物理键(const 索引物理键&)` | 正向定位并回读权威目标，但以 `optional` 合并未命中与内部矛盾 | 保留签名作兼容包装；新增同仓结构化读取作为唯一真实实现 |
| `核心/仓库.可重建索引.ixx::读取目标索引物理键组` | 只能按目标反向取键，不能从固定键唯一取目标 | 不组合为反向扫描，不用于本目标 |

| SQL、恢复材料、显示名 | 能提供持久证据或人读投影，不是运行期索引权威 | 全部拒绝回源 |

能力裁决为“同仓扩展 + 现有服务扩展”：不适合仅组合现有 optional，因为那会丢失内部不一致；不适合新建仓或缓存，因为索引仓已经拥有正反绑定和目标复核；不适合修改公开 DTO，因为现有结果足够承载。

## 2. 最终函数与内部读取合同

### 2.1 索引仓内部结构化读取

唯一物理位置：`海中鱼巣/核心/仓库.可重建索引.ixx`，模块导出但只允许 L1 内部消费：

```cpp
enum class 可重建索引精确读取状态 : std::uint8_t {
    已读取 = 1,
    未找到 = 2,
    入口拒绝 = 3,
    资源失败 = 4,
    内部不一致 = 5
};

struct 可重建索引精确读取结果 {
    可重建索引精确读取状态 状态 = 可重建索引精确读取状态::入口拒绝;
    std::optional<可重建索引记录> 当前记录;
};

可重建索引精确读取结果 读取索引物理键结构化(
    const 索引物理键& 键) const;
```

`当前记录` 含内部句柄，只能在 L1 内部同步值式使用，不得进入公开服务结果。状态与载荷固定为：键不完整返回入口拒绝；正向无条目或只有其它事务未发布候选返回未找到；已发布条目的记录不完整、记录键错配、候选事务序号非零、反向组缺失或同键计数不等于1、目标种类与句柄二选一矛盾、目标权威节点/关系不可读均返回内部不一致；分配失败返回资源失败；只有全部成立才返回已读取和恰一记录。

函数在索引仓共享锁内只验证并复制正向条目与反向绑定，然后释放索引仓锁，再回读节点/关系仓；调用它的查询服务始终持有事务域共享许可，因此两段仓读取属于同一已发布代次。禁止持索引仓锁调用节点/关系仓。现有普通重载：

```cpp
std::optional<可重建索引记录> 读取索引物理键(
    const 索引物理键& 键) const;
```

原位改为只调用结构化函数一次，仅 `已读取` 取出记录，其它状态返回 `nullopt`；不得保留第二套正向/反向校验逻辑。带事务序号的候选视图重载不在本计划修改。

### 2.2 查询服务公开读取

唯一物理位置：`海中鱼巣/核心/服务.节点直接结构.ixx`，现有类 `节点直接结构查询服务` 的 public 区域：

```cpp
节点直接索引读取结果 读取当前索引(
    const 索引物理键& 键) const;
```

参数 `键` 为本次同步调用 const 借用；函数不保存引用。返回值由调用方拥有：

| 条件 | `头.状态` | `事实截止代次` | `索引组` |
| --- | --- | --- | --- |
| 键完整且当前索引唯一可读 | 成功 | 当前非零已发布代次 | 恰一项，`键`逐字段相等、`当前=true`、节点/关系目标恰一 |
| 键完整、代次非零但当前无此索引 | 未找到 | 当前非零已发布代次 | 空 |
| 键不完整 | 入口拒绝 | 0 | 空 |
| 共享许可竞争 | 许可拒绝 | 0 | 空 |
| 仓记录、目标种类、内部句柄或端点矛盾 | 内部不一致 | 0 | 空 |
| 内部分配失败 | 资源失败 | 0 | 空 |

公开函数不新增公开状态枚举或 DTO。成功仍返回 vector 是为了复用现有 ABI；函数自身保证数量恰一，调用方不得把多项当作可选结果。

## 3. 唯一调用顺序

唯一施工图：

```text
流程图/20260803_节点直接结构查询服务读取当前索引_函数流程图_v0.2.md
流程图/20260803_可重建索引仓库读取索引物理键结构化_函数流程图_v0.2.md
```

1. 先调用 `索引物理键完整(键)`；非法立即入口拒绝，零仓调用。
2. `事务域_.取得读取许可()`；竞争立即许可拒绝，不等待。
3. 从许可读取当前已发布代次；零代次返回未找到、代次0、空组。
4. 调用 `索引_.读取索引物理键结构化(键)`：未找到返回未找到及本轮非零代次；资源失败返回资源失败、代次0；入口拒绝或内部不一致在入口已通过的前提下统一映射内部不一致、代次0。
5. 已读取记录的物理键必须等于输入，目标种类必须与恰一个目标字段一致：
   - 节点目标：`节点_.读取节点(内部节点身份)`，形成稳定节点见证；
   - 关系目标：`关系_.读取关系(内部关系身份)`，再调用现有 `形成关系见证_` 复核两个端点并形成稳定关系见证。
6. 构造一个 `可重建索引读回`，`当前=true`，加入结果组并返回成功及本轮代次。
7. 第2—6步整体捕获异常：`std::bad_alloc` 映射资源失败、代次0、空组；其它异常映射内部不一致、代次0、空组。异常不得越过服务边界。

不允许先释放许可后再读仓，不允许通过 `读取目标当前索引组` 反向扫描，不允许用仓库号/编号、显示名、SQL或材料文件补判。

## 4. 所有权、并发与诊断

查询服务继续只保存事务域和六仓引用；依赖由装配拥有并长于服务。读取许可只在函数调用内存续。仓库内部锁仍由仓库管理，上层不接触锁顺序。索引仓结构化结果只在函数栈内存续，服务在返回前把内部句柄转换为稳定身份见证并销毁内部记录副本。

函数作为 L1 查询提供者只返回结构化状态，不写日志；最近 L2 服务边界决定是否记录。未找到、入口拒绝和许可拒绝不是内部错误。所有返回路径零机器事实写入。

## 6. 创建侧零代码机械推演与提供者—消费者闭合

| 场景 | 仓库结构化结果 | 查询服务结果 | 事实变化 | 消费者裁决 |
| --- | --- | --- | --- | --- |
| 键不完整 | 不调用 | 入口拒绝、0、空 | 无 | P1A3 不重试、不补判 |
| 合法键、代次0 | 不调用 | 未找到、0、空 | 无 | 尚无已发布事实，不构造根 |
| 非零代次、正向无键/仅候选 | 未找到、空 | 未找到、同代次、空 | 无 | P1A3 将固定必需键缺失判内部不一致 |
| 已发布节点索引且正反/目标一致 | 已读取、节点内部记录 | 成功、同代次、恰一稳定节点读回 | 无 | P1A3 继续核对场景类型和键 |
| 已发布关系索引且正反/端点一致 | 已读取、关系内部记录 | 成功、同代次、恰一稳定关系读回 | 无 | 其它 L2 可按合同消费；P1A3 固定根键不接受关系目标 |
| 正反绑定缺失/重复、已发布候选序号非零或记录键错配 | 内部不一致、空 | 内部不一致、0、空 | 无 | 禁止降级成未找到或 SQL 回源 |
| 目标节点/关系或关系端点悬空 | 内部不一致或服务二次复核失败 | 内部不一致、0、空 | 无 | 禁止返回部分见证 |
| 许可竞争 | 仓库不调用 | 许可拒绝、0、空 | 无 | 调用方按自身合同决定，不在本函数重试 |
| 分配失败/其它异常 | 资源失败/内部不一致 | 同类结构化结果、0、空 | 无 | 异常不越过服务边界 |

提供者只有索引仓结构化读取和查询服务公开读取；直接消费者为 P1A3 的现实世界引导服务，后继可能复用但不得绕过查询服务向 L2 暴露仓库结果。P1A2Q 不消费 P1A3 事实，依赖方向保持 L2 -> L1。旧 optional 重载的既有 L1 消费者保持原签名，其空值语义不升级为结构化诊断。

## 7. 完成边界

完成只证明 L1 按精确索引物理键读取当前值式目标的提供者代码候选通过矩阵；不证明 P1A3 世界根、恢复、世界结构或任何 L2 业务已完成。
