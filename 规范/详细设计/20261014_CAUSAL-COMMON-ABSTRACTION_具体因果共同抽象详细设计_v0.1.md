# CAUSAL-COMMON-ABSTRACTION 具体因果共同抽象详细设计

日期：2026-10-14；版本：v0.1；代码基线：`3c1cc0d5fb3985db656f463e6f1a26849838ddf6`。

本文件是施工设计，不修改正式规范。用户最新裁决替代先前“每条具体因果先转成概念”的方案：具体规律保留；至少两条具体规律按结构共性形成概念因果；原规律作为来源被引用；已知/未知动作分账，不同成因不混合；保留完整条件—结果分支，不从独立槽位值域组合补造未观察组合；统计依据真实发生身份去重。

## 1. 最早代码叶和明确未覆盖

本叶实现唯一因果owner的共同抽象、来源查重、概念查询及具体规律形成/更新后的自动触发。世界树两次结果之间的窗口采集尚未接通，本叶不伪装完成全世界被动因果形成。新具体规律记录输入的真实共同场景；旧具体规律没有该字段，保留准确定义及统计，不猜当时场景，不能进入要求场景证明的自动抽象。

当前因果root和架构字段均为进程静态编码，初始化无可定位跨启动恢复；源码没有外部生产调用。新概念层使用现有因果根，不建立第二平行根、不清空原具体节点、不静默改读旧准确值字段。原1190具体规律算法保留作为下层，其多源材料/全树窗口/反例完善均未由本叶声明完成。

## 3. 具体来源、场景和保守分组

来源至少两个不同、可完整读取的具体因果节点；不接受概念因果当来源，首代不递归分层。来源具体规律相同编码去重后不足两个返回来源不足。来源有明确场景字段且场景均同一实际共同场景才进入同组；该场景公开读取取得正式专属存在C，不新建虚构上层场景。

新具体发生处理读取`新因果发生记录`中的场景。待形成值式材料保留该字段；具体两次形成分组新增实际场景相等条件，防止材料跨场景求交。来源节点/状态/动态的归属由中立场景公开服务核验同一范围及真实子场景，不调用世界树回调，不扫描世界根补窗口。没有所需场景身份的任务Vt结果排除，不补造普通存在或EC。

抽象分组必须同已知/未知、同结果FT、同条件状态FT布局、同条件动态DC布局、同角色同异拓扑；已知动作还必须同正式动作C和动作角色位。未知动作不因时间邻近绑定动作。已知动作C通过现有动态概念服务核验定义类别为动作；只有技术M/定义节点而没有正式动作C的来源保留、不假定为C。

## 4. 唯一角色对齐与存在共性

每份具体来源从条件/结果和动作参与E构造局部角色绑定，真实E只属于本次来源材料，不进入概念定义。先固定结果承担E为角色1，随后按执行主体、作用部位、作用对象的固定语义顺序分配新角色；同一E复用已有角色，不把同类概念当成同一个E。余下参与者按其完整条件FT集合及DC集合签名排序；不同E签名完全相同、无法唯一定位时返回角色对齐不唯一，保留具体规律，不按E编码猜对应。

对齐要求每个角色的状态/动态布局完全相同，条件内同FT多项按已有准确值排序仅确定同一来源规范顺序，不据此推断跨来源因果关系；同一角色同FT出现多个不同条件值时属于无法唯一定位槽位，返回无结构共性，不缩减条件或任取一项。

每角色从各来源E读取正式专属存在C，作为“参与者属于哪个已有概念”的分类材料；具体条件及结果值仍只来自来源规律，不读E当前值覆盖发生材料。所有来源该角色C相同直接复用；两个以上不同C调用`概念_存在类::抽象共同存在概念()`，至少一个真实共同特征才可建立。无共同点返回无共同存在概念，不造空概念；资源/结构异常按工程故障终止。角色组编号连续1..R，不同槽位代表不同参与者；相同E合槽，因此同异拓扑由槽位关系保持。

## 5. 精确特征概念与分支绑定

首代精确域支持I64标量。具体状态保存的特征概念可能是FT根或其子C；先以`比较单特征概念(C,C).特征类型根`解析正式FT根，布局及精确FC均使用该根，不能把子C误当另一个FT。对各来源条件及结果的固定准确值，在FT根内调用特征owner建立/取得单点子概念，沿用FT材料类型、比较和聚合规则，域为`[v,v]`，依赖构造借用的正式特征值服务。核对所有来源为同一合法类型根且v在其合法域内；实际值在根域外时不扩根、不新建另一个同名FT，具体规律保留并返回值不在合法类型域内。

非I64准确材料现有物理域无法在本叶统一证明精确表达，返回精确值域尚不可表达；这是明确首代范围，不把读取异常/非法材料误判为不支持。准确值读取异常、节点失效或自相矛盾走工程路径。不能以最具体宽根C代替精确域，不能把1→10与2→20投影成同一个宽条件→宽结果。

每个来源保持完整分支：条件状态组与条件动态组共同成立，唯一结果与该分支绑定。不同分支为替代关系，绝不把各条件/结果值域独立合并后做笛卡尔组合。角色C是共同分类，FT/DC布局是共同结构；实际具体对应关系保存在各分支中，不推导未出现的输入/输出。分支按来源具体因果编码排序；来源引用属于来源层，不冒充概念条件。

首代DC槽位要求概念编码完全一致，不主动调用变化聚合扩大DC域，不把不同动作C聚合为同一个动作。共同FT/DC结构不成立的不同成因保留为其它组，不能仅因同果归并。

## 6. 持久格式、查重及引用保护

同一因果root下新增明确概念因果节点类型。概念因果使用`原子建立节点({上级=因果root, 初始完整字段组})`完整单节点发布，其父子关系角色固定0。旧具体成员使用既有因果成员角色，旧查询只读该角色及具体类型；概念查询只读角色0及完整新类型，不把混型当部分具体规律。root保留唯一，不创建第二根。

单节点字段：新类型、因果类型、场景C、角色C重复引用组、可选动作C、来源具体因果重复引用组、分支值域/DC引用组，以及技术形状I64数组。形状前六项为`角色数,有动作,动作执行角色,动作部位角色或0,动作对象角色或0,分支数`；每分支写`条件状态数,条件动态数,结果角色`，再逐状态项`角色`、逐动态项`角色`。引用顺序：角色C组；每分支来源Q→每状态FT/精确FC→每动态DC→结果FT/精确FC。动作C、场景C有各自独立字段；源Q和全部概念引用都为节点字段，不能把编码塞入数组。shape只保存技术角色、形状及数量。逐字段/组解码恰消费全部，无剩余或不足。

完整定义查重包含来源Q集合和全部分支绑定，不只比较公共头。来源集发生变化形成另一个完整概念因果，旧概念保留，不原地改义；重复同一规范化来源集复用零新节点。发布后完整读回核对角色、类型、场景、来源及每分支FC与来源准确值一致。

共享EC/FC/DC可被其它owner更新。读取概念因果时重新证明精确FC仍是对应来源I64的单点，类型根未变；若FC已变宽或不相容返回概念已不相容，不按新宽域解释旧分支。EC与所有来源角色C的完整包含/正式分类相容须读回核验；不保存版本号或假历史快照。节点引用保护已发布概念与具体来源，不挪用FC实例引用次数计概念引用。

已有DC删除先拆字段再底座删除，会在因果引用阻止最终删除时破坏内容。冻结最小纯结构保护：底座新增`bool 有入向字段引用(稳定编码 节点) const noexcept`，只查其它所属节点的字段内容引用目标，不计自身字段或概念组织关系；这是优化预检，不单独证明删除安全。最终删除新增精确签名：

```cpp
基础结构操作状态 原子删除节点结构(
    const std::vector<稳定编码>& 节点组,
    const std::vector<稳定编码>& 字段关系组,
    const std::vector<稳定编码>& 外部关系组) noexcept;
```

基础状态新增`引用仍存在`合法拒绝。入口单独占底座锁，先校验集合非空、身份合法无重复、所有待删项存在；删除集必须覆盖每个待删节点的全部自身字段结构，以及与它相连且owner明确授权删除的外部组织关系。集合外字段内容/字段类型引用待删节点、集合外外部关系端点引用待删节点均返回引用仍存在。字段列表只能属于被删节点；外部关系列表至少一端属于被删节点，不得夹带其它结构。全部校验完成后才erase，实施阶段不分配、不调用公开重入函数；所有失败零字段/关系/节点拆除。该入口不公开owner、不推断业务归属、不增加历史或权限。

FC/DC owner收集自己现有删除helper本来要删除的私有节点、字段和组织关系全集，再调用上述原子入口；不得由因果owner跨类清理概念。DC的状态/动态特征私有项必须并入删除集，准确列清全部内字段，不把全局类型/字段架构节点并入。新_动态类::删除动态在任何动态字段、状态引用或成员拆除前，若当前实例DC有因果入字段引用，直接返回仍被引用并保留D与DC；不能先拆D再发现DC不能删。底座原子删除再防预检后新增引用竞态。共享聚合C不随D删除，FC实例计数规则不改，概念引用不挪用实例计数。工程异常由各owner终止，合法引用阻止是零变更拒绝。

## 7. 自动触发与统计

具体规律完整发布/更新后，在具体返回前调用owner私有`尝试共同抽象(具体Q)`。抽象依赖齐备才枚举已有具体Q，同真实场景和保守结构键召回；每一合格组至少两个具体Q，调用同一公开抽象实现。无共性/精确域不可表达/场景不足是保留具体材料的正常边界，不回滚已形成具体规律；工程异常必须终止，不能返回资源失败表示没有规律。触发在因果owner递归锁内串行，读取直接基础服务，不调用世界树或线程回调，避免世界锁/因果锁倒序。

概念层统计只返回来源具体规律的`已计数发生身份组`去重并集及其长度“覆盖发生次数”。旧统计没有每ID的正负/尝试明细，不能把该并集称符合次数、合计尝试次数或可靠性。来源各四统计保持原定义且可分别读取。重复源引用和同发生经不同源出现均仅一个ID。统计调用期计算，不维护第二份可变计数字段、不新建观察/样本/事件账；I64长度溢出工程终止。

## 8. 装配、失败及验证

世界树已有实例/概念/场景服务可构造完整因果owner，初始化独立因果root后保留其寿命；在`新世界事实服务引用`增加因果服务引用供上层提交已经组织好的发生材料，不新增主动窗口或改变本能函数合同。世界树特征发布当前不自动提供完整窗口，本叶不声称该生产触发已闭合；owner内具体成功后的抽象触发实际接通。

新公开边界捕获工程异常使用`工程异常终止()`日志、弹窗、进程终止。触及的旧具体发布/统计路径遇资源/读回/恢复失败同样不得伪装无因果或成功；既有尽力恢复不升级为原子事务。本叶新概念发布原子；旧具体多步布局不是本叶强制迁移目标。

实际项目Debug/x64一组改动统一编译链接，未明确测试不启动程序。获测试指令后覆盖：两条具体同结构不同I64分支；同来源重复零新节点；1→10/2→20不生成1→20；角色重合与不同拓扑；同FT多角色歧义拒绝；动作C不同不并；无场景旧规律保留；多来源共享发生ID去重；FC变宽拒绝旧精准解释；被引用DC删除零拆除；具体成功后实际自动抽象；全世界窗口仍未接线。
