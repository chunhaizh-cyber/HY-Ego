# 语言词条与四本体根概念空间结构 CRUD 详细设计 v0.3

日期：2026-08-14

## 1. 目标、替代关系与完成边界

本设计按 2220 v1.3、4020、4240 v0.3、7140 v1.2 和 8120 v0.8 重基线语言 / 概念纯结构链，替代旧“每个正式词性建立一个概念维度根”的机器合同。新结构固定为：

```text
不可变材料 M1
├─ 语言 / 正式词性 / 词条 L1
└─ 概念身份 / 四个语言无关本体根 / 抽象签名 C1
   └─ 同根多父 DAG 与定义约束 C2
      ├─ 世界事实支持概念 C3
      └─ 概念名称关系 N1（另依赖 L1）
         └─ 生命周期、退出与本体结构投影 C4
            └─ 语言概念透明聚合 A1
```

概念空间固定只有 `存在、特征、动态、因果链` 四个本体根。语言、词性、词条和名称只负责表达、检索和任务局部路由，不建立、改义、排除或唯一裁决概念。本设计不建立场景概念根，不把场景层级复制为概念层级，不按汉语或其它语言枚举根。

本设计只形成数据结构提供者合同，不实现概念抽象、二次特征需求驱动生成、因果候选筛选、直接因果形成、语言形成、词性判断、短语表达、语境消歧、自我线程、方法根、宿主或跨进程恢复。阶段 18 生产初始化是 C1 / A1 完成后的独立后继提供者，不由 C1 构造器或 CRUD 自动执行。

## 2. 当前事实与漂移裁决

### 2.1 当前实现事实

正式 BIZ 阶段 18 图已在该基线冻结“四个语言无关本体根”的消费者需求，只作为 C1 / A1 后继消费证据；BIZ 不定义 M1 公开 ABI，不成为 M1 机器依赖，也不能用业务图反向改变本节数据合同。

### 2.2 旧设计退出项

以下旧合同退出且不得迁移：

## 3. 依赖方向、物理归属与唯一所有者

### 3.1 机器依赖

```text
不可变材料服务 -> L1事实基座
L2语言结构服务 -> 不可变材料服务只读 + L1事实基座
L2概念结构服务 -> 不可变材料服务只读

                   + 二次特征结构公开读取
                   + 直接因果事实公开读取
                   + L1事实基座

                       + L2语言结构服务只读
                       + L1事实基座
```

`M1 -> L1` 与 `M1 -> C1` 是两条机器依赖分支；C1 不依赖 L1。为服从唯一活动代码段，可以调度为 M1、L1、C1，但该调度不得被解释为概念依赖语言或词性成立。

M1 是纯 provider 叶，只依赖正式规范、L1 owner-scoped v2 公开合同和调用方显式交付的强类型存储配置 / owner 交付。普通应用、启动、S-HOST、SELF-FORM、既有六服务聚合和后继 A1 都不是 M1 机器依赖。调用方负责选择受控物理根；M1 只验证、规范化并在服务实例生命周期内持有该配置，不选择默认路径，也不读取环境变量、工作区或用户主目录推导路径。


构造输入默认构造、禁止复制、允许默认移动，不提供相等。构造结果因含 `unique_ptr` 不提供相等；其 `成功()` 精确谓词为 `状态 == 成功 && 合同版本 == L2结构合同版本 && 服务 != nullptr`，任一非成功状态必须 `服务 == nullptr`。构造状态固定为 `成功=1、配置无效=2、所有者交付无效=3、目录资源失败=4、登记失败=5、资源失败=6、内部不一致=7`；调用方必须显式给出非空绝对受控根和与同一 L1 实例绑定的 owner 交付；服务不提供默认构造、路径回退或第二构造入口。

写入结果 `成功()` 精确要求：状态为 `已提交` 或 `精确重复`，合同版本正确、事实截止非零、变更事实代次存在，`材料` 存在且为该截止完整活动事实，并且 `*变更事实代次 == 结果头.事实截止代次 == 材料.生命周期.创建事实代次`；精确重复仍返回首次截止读回。退出结果 `成功()` 精确要求：状态为 `已提交` 或 `精确重复`，合同版本正确、事实截止非零、变更事实代次存在，`已退出材料` 存在且完整，其退出事实代次同时等于变更事实代次和事实截止。登记读取结果 `成功()` 精确要求：状态为 `已读取`，合同版本正确、事实截止非零、无变更事实代次，登记存在且登记事实截止等于结果截止，并且系统签发者、两个格式身份和三个属性类型身份均非零、两两互异；自身读取字段还必须满足当前读取时历史截止为 0，历史读取时历史截止非零且等于结果截止。六项当前性和属性类型表示由读取函数在形成值式登记前正式互证，不增加未冻结的生命周期字段。材料读取结果虽不提供 `成功()`，其 `已读取` 完整形状同样必须校验自身读取类别 / 历史截止与结果截止。所有其它状态以及成功状态缺载荷均返回 `false`。

公开状态集合固定为：写入 `{已提交, 精确重复, 入口拒绝, 许可拒绝, 未找到, 已退出, 事实代次漂移, 幂等冲突, 资源失败, 内部不一致}`；读取 `{已读取, 入口拒绝, 许可拒绝, 未找到, 已退出, 事实代次漂移, 资源失败, 内部不一致}`；退出 `{已提交, 精确重复, 入口拒绝, 许可拒绝, 未找到, 已退出, 事实代次漂移, 幂等冲突, 引用冲突, 资源失败, 内部不一致}`；登记读取 `{已读取, 入口拒绝, 许可拒绝, 未找到, 事实代次漂移, 资源失败, 内部不一致}`。任一非成功状态的 optional 载荷必须为空；当前材料已永久退出返回 `已退出`，从未存在或历史截止早于创建返回 `未找到`，不得混为同一状态。

构造顺序固定为：纯值校验配置；打开并规范化根、取得卷身份；逐级验证或建立固定子目录；验证 owner 交付与传入 L1 同实例、owner 身份及独占范围；提交固定登记；从登记发布截止正式读回；最后形成服务实例。配置或目录失败发生在登记写前。固定登记只接受 L1 `成功` / `精确重复`；L1 `资源失败` 映射构造 `资源失败`，固定内部请求得到其它逻辑拒绝映射 `登记失败`，发布后登记读回缺项或混代映射 `内部不一致`。构造失败销毁传入端口租约但不退出已经存在的 owner 或已原子发布登记；调用方只能经 L1 正式重入重新取得交付后，以同一配置重试。

物理实现依赖冻结为 Windows 现有工具链内的系统文件句柄、卷身份和系统 SHA-256；若系统 SHA-256 采用 BCrypt / CNG，必须只在本叶允许的 `海中鱼巣.vcxproj` 登记 `bcrypt.lib` 链接，不引入第三方库。逐组件句柄、卷身份、SHA-256 和路径互证的私有 helper 可由执行者按上述公开语义机械实现，但不得形成第二模块、第二公开入口或验证 seam。

来源不得由调用方自报文本、名称、路径、SQL 行、日志、线程、服务对象或任意裸编码成立。写入前必须经 `L1事实基座服务::读取中性当前节点` 证明来源节点当前存在、查询编码与返回编码精确匹配、事实截止非零且生命周期覆盖本次写入；读取完成后释放读取，再进入材料 owner 写入。提交携带来源读取的期望事实代次；来源漂移返回事实代次漂移且零材料事实写入，不得由执行者选择其它读取入口。

M1 自己是材料签发服务，必须在构造登记中以材料 owner 的固定登记写集正式建立并读回：一个具名系统签发者普通节点、严格 UTF-8 格式普通节点、通用字节格式普通节点，以及格式身份、字节长度、SHA-256 三个 U64 组属性类型节点。公开 `读取不可变材料登记` 返回六个身份和同一非零事实截止。系统签发请求只能引用该登记中的签发者；普通来源请求仍须正式读取调用方提交的已发布节点。空来源、服务对象和调用方自报签发者全部拒绝。

构造登记固定为幂等身份 `0x4C32'4D41'5452'4701`，本地键依次为 `0x3000'1001`（系统签发者）、`0x3000'1002`（严格 UTF-8 格式）、`0x3000'1003`（通用字节格式）、`0x3000'1101`（格式属性类型）、`0x3000'1102`（长度属性类型）、`0x3000'1103`（摘要属性类型）。激活 S0 必须机械查重；冲突保持待激活，不得改值绕过。

每份材料新建写集固定复用请求局部键：`0x3000'2001`（材料节点）、`0x3000'2101`（格式值）、`0x3000'2102`（长度值）、`0x3000'2103`（摘要值）。局部键只在单写集内解析，不进入稳定身份或跨请求唯一键；调用方幂等身份原值作为 L1 owner 写入幂等身份，不做截断、散列或另造第二 L1 写键。

### 5.2 受控物理根和目录合同

受控根必须由调用方显式提交为非空绝对路径，且在构造前已经存在并为普通目录。服务按逐组件句柄检查拒绝 `.` / `..` 残留、符号链接、挂载点或其它重解析点，取得规范化绝对根和卷身份后只读持有；根失效时不改选其它目录。配置为空、相对路径、根不存在、非目录或含重解析点返回 `配置无效`；打开、查询卷或逐级验证 / 建立固定子目录的已知 I/O 失败返回 `目录资源失败`；无法唯一裁决的路径 / 卷状态返回 `内部不一致`，全部发生在材料登记写入前。已经存在的固定子目录也必须是同卷普通目录且无重解析点；缺失时只允许服务逐级建立这两个固定目录层级，不接受调用方改名或另行配置。

根内布局固定为：

```text
<受控根>/候选/
<受控根>/对象/sha256/<摘要前两位小写十六进制>/<64位小写十六进制摘要>.bin
```

服务只接受 `候选/` 下已经存在的普通文件。根、候选路径及其全部已有父级、对象分片目录和最终对象都不得是重解析点；规范化后不在根内、路径穿越、目录输入或重解析越界均返回 `入口拒绝`。根内判断必须使用逐级打开句柄得到的最终规范化路径、卷身份和目录身份，不得使用大小写敏感字符串前缀、未解析路径或仅词法 `lexically_normal` 作为安全证明。候选句柄、同一摘要分片目录中的临时文件和最终对象必须经卷身份证明与受控根同卷；不同卷返回 `入口拒绝`，不得尝试复制后假装原子发布。

最终物理定位只由 SHA-256 摘要派生。服务先在最终分片目录建立唯一临时普通文件，写入并复读完整字节、长度和摘要，关闭写句柄后执行同卷、不可覆盖的原子 rename 到最终路径。最终路径已存在时不覆盖：完整复读与摘要一致则物理精确收敛；任一字节、长度或摘要不同返回 `内部不一致`。rename 竞争中若目标刚出现，按同一规则复读收敛；已知目录 / 打开 / 读写 / rename I/O 失败返回 `资源失败`。rename 结果未知时必须重新打开摘要定位：存在且完整一致才按物理收敛继续，不存在返回 `资源失败`，存在但不一致返回 `内部不一致`；不得根据异常文本猜成功。rename 前失败必须尝试删除本次唯一临时文件；清理失败只留下受控根内孤立临时文件，不改变原失败状态，也不得继续发布 L1。

服务重启时使用调用方再次显式给出的同一规范化根，并按摘要唯一派生物理位置、复读长度 / 摘要 / 完整字节；不依赖进程内路径表恢复。路径只作为可选定位返回，不进入材料身份、幂等键或 L1 业务事实。L1 发布前形成而未被事实引用的临时或最终文件仍是孤立候选；L1 发布后目标缺失或复读不一致返回 `内部不一致`，不撤销已发布事实。

### 5.3 公开能力和写入顺序

```cpp
不可变材料写入结果 写入不可变材料(const 不可变材料写入请求& 请求);
不可变材料读取结果 读取不可变材料(const 不可变材料读取请求& 请求) const;
不可变材料退出结果 退出不可变材料(const 不可变材料退出请求& 请求);
不可变材料登记读取结果 读取不可变材料登记(
    const 不可变材料登记读取请求& 请求) const;
```

写请求包含共同头、幂等身份、闭合格式角色、隔离候选路径、字节长度、SHA-256，以及 `系统签发` 或 `已发布节点` 的闭合强类型来源联合。顺序固定为：

1. 校验纯值、路径位于固定 `候选/` 根、同卷、无重解析点、格式登记、非零长度与来源字段；
2. 正式读取来源节点并保存来源事实代次；
3. 复读候选，校验格式、长度、SHA-256；严格 UTF-8 还须非空、无 BOM、无无效序列和 `U+FFFD`；
4. 在最终摘要分片目录形成同卷临时文件，按第 5.2 节原子 rename 或与既有对象逐字节收敛；
5. 用来源期望代次在材料 owner 单写集中发布一个材料普通节点、格式 / 长度 / 摘要三个值和三个当前属性槽；三个值的来源节点必须相同；
6. 从首次发布代次正式读回并逐字段互证后返回结果。

候选或文件失败不产生 L1 事实。L1 发布后物理材料缺失属于内部不一致。相同格式、摘要、完整字节和解析来源精确重复返回同一首次事实；同内容异来源或同幂等身份异义返回幂等冲突；摘要相同但复读字节不同返回内部不一致。生产写入状态机和全部私有辅助只存在于 `服务.不可变材料.ixx`，不得为了验证拆出 `.inl`、模板访问器、故障注入、测试宏、友元、私有状态出口、运行期测试模式或第二实现入口。

服务实例私有维护两个非权威协调索引：调用方幂等身份到“完整原请求 / 待决或首次结果”的请求账，以及“格式身份 + 字节长度 + SHA-256”到材料身份的内容索引。命中从不直接返回缓存，必须复读摘要对象并正式读取 L1 当前 / 历史事实后才返回；索引缺失不证明事实不存在。一次公开调用只在短临界区内登记或观察待决项，进入文件系统或 L1 前释放服务锁，禁止持服务锁跨外部调用。

同调用方幂等身份异完整请求立即返回幂等冲突。同完整请求或同内容键并发时只允许一个 leader 执行物理 / L1 写入，其余等待 leader 形成可读回结果；leader 成功后，即使调用方幂等身份不同，只要格式、摘要、长度、完整字节和解析后的来源节点都与首次事实相同，也返回同一首次材料身份的精确重复。同内容键但来源节点不同返回 `幂等冲突` 且不得建立第二材料身份；增加多来源结构必须另行修订正式合同。当前材料已退出时不复用旧编码，只有新的调用方幂等身份才能建立新身份。发布结果未知时请求账保留原完整请求为待决；只允许原幂等身份原请求重放，另一个幂等身份命中同内容待决项返回 `资源失败` 和“原幂等键重放”边界，不得建立第二节点。索引冲突、索引命中但 L1 / 文件读回异义或 leader 无法收敛均返回 `内部不一致`。

这两个索引只覆盖唯一服务实例生命周期，不是恢复权威。当前 L1 的固定材料登记若为 `精确重复`、内容索引又无命中且最终摘要对象已经存在，服务无法证明“仅有物理孤儿”还是“已有当前材料但索引丢失”，必须返回 `内部不一致`，不得再建节点；只有固定登记在新 L1 中首次发布时，既有物理对象才能按 4020 作为孤立候选重新准入。跨进程恢复和“保留当前 L1 事实但丢失服务索引后重新构造 provider”不在 M1 完成声明内；后继恢复计划若要支持，必须先提供 owner 范围枚举或等价正式能力，不能由 M1 扫路径补造身份。

### 5.4 当前结构定位、退出闭包和历史守恒

材料读取和登记读取都复用现行 L2 截止规则：请求头合同版本必须等于 `L2结构合同版本` 且 `期望事实代次` 非零；`读取类别 == 当前` 时 `历史截止事实代次` 必须为 0，成功结果截止等于请求头期望代次；`读取类别 == 历史` 时历史截止必须非零且不大于请求头期望代次，成功结果截止等于历史截止。两类读取都只返回该截止的单一完整 `optional` 快照，不返回从创建到截止的事件序列或 vector 历史。当前截止已退出返回 `已退出` 空载荷；历史截止早于创建返回 `未找到` 空载荷；历史截止在创建之后时返回截止投影，若退出代次不晚于该截止则生命周期保留该退出代次。登记永久不退出，历史截止早于登记建立返回 `未找到`，其余合法截止返回单一登记快照。

每个材料首次写入固定在同一 owner 写集中建立一个材料普通节点，随后依次建立格式值、长度值和摘要值并设置三个当前属性槽；因此材料节点稳定编码小于同写集三个值编码。三个属性类型只能取构造登记中的固定身份，值的所属节点都等于材料节点，来源节点都等于解析后的同一来源，材料分别为 `[格式身份]`、`[字节长度]`、按网络字节序每八字节组成四项的 `[SHA-256 U64组]`。

读取当前材料时必须先按材料身份读取 owner-scoped 当前节点，证明写入 owner 正确、恰有且只有登记中的三个当前属性槽；再从槽中权威取得格式值、长度值、摘要值三个稳定编码，以同一事实截止分别读取当前值并互证所属节点、属性类型、来源、表示、材料、创建 / 退出代次。任何槽缺失、额外槽、编码复用、混代、来源不一或值不完整均返回 `内部不一致`。这三个槽中的当前值编码是退出闭包的唯一权威定位，不得从摘要、分配顺序、进程缓存、路径、日志或请求回显猜测。

退出请求公开面仍只携带材料身份。服务先完成上述一致当前读回并保存退出前完整事实，再提交一份材料 owner 写集，`节点/关系/值/属性槽变更` 均为空，`退出事实` 精确包含材料节点及槽中取得的格式、长度、摘要三个值编码。依赖当前 L1“节点先于值分配稳定编码、退出集合按稳定编码升序规范化”的正式实现事实，材料节点先进入历史，三个历史值再同代退出并从当前节点移除相应槽；该事实若在激活 S0 漂移必须退回计划支撑，不得临场改变退出方案。成功后四个事实的退出代次必须相同且等于写集发布代次。

外部引用门禁不由服务扫描后自行猜测。包含四个自有编码的完整退出集合交给 L1 当前引用闭包裁决：材料节点仍被外部关系、其它当前值的所属 / 类型 / 来源或独立材料引用指向时，L1 返回 `引用冲突` 且整个写集零变化；只有材料自有三值形成的节点引用被同一退出集合闭合时才允许提交。服务不得把外部 owner 事实加入退出集合，也不得先退三值、清槽或改物理文件后再试退节点。

退出成功后必须按发布截止读取历史材料节点和三个历史值，证明节点历史仍保留退出前三槽，三值逐字段与退出前事实一致，四者创建代次合法且退出代次相同；当前读取不得再返回任一四事实。任一历史缺项、槽值不匹配或混代返回 `内部不一致`，不回滚已发布退出。物理文件不随结构退出删除，回收属于独立后继维护策略。

```text
新增词条 / 读取完整词条 / 按规范键读取词条 / 退出词条
重建当前词索引
```

词条唯一键为“语言身份 + 规范化合同材料身份 + 规范化词面材料的格式、摘要和长度”。词面材料必须是正式严格 UTF-8 材料。服务只校验并保存调用方已规范化结果，不执行规范化、分词或词性判断。词索引可清空重建，命中必须回源，不得成为权威。

L1 与概念根数量无关。词性退出不受概念根反向引用阻止；概念名称只引用词条和适用语言。L1 v0.1 叶级正文可保留，但索引必须绑定本设计和最终 M1 ABI。

## 7. C1—C4 与 N1 冻结合同

### 7.1 C1：概念身份、四本体根和签名

新增闭合 `L2本体根角色 { 存在, 特征, 动态, 因果链 }`。公开能力至少包含：

```text
读取概念身份来源
建立概念本体根
按本体根角色读取当前根
读取全部当前本体根
新增概念 / 读取完整概念 / 按完整签名读取当前概念
```

四角色恰各一根、身份互异、永久活跃、无上位且零额外根。固定角色是唯一根键；词性、名称、场景身份和调用顺序均不是根事实。普通概念唯一键为“本体根 + 签名规则材料 + 完整有序签名”。普通概念提交后必须同根、无环、可达唯一根，并同时发布全部初始定义与至少一条直接上位边。

二次特征概念归特征根，保存真实阶次、直接前驱、输入角色、派生规则和适用范围。因果链概念归因果链根，首次建立至少引用一项已发布、方向明确、版本有效的直接因果事实；多项必须方向一致、连通、无环，允许共同原因、替代原因和共享分支。只保存直接组成角色、顺序、分支、范围和规则版本，不复制条件 / 动作 / 结果 / 证据，不保存固定层号、间接边或展开路径。

当前直接因果公开事实尚未提供 1190 所需的适用范围、规则版本与发布证据，所以 C1 精确直接因果引用 DTO 只能预冻结，待最终提供者 ABI 机械匹配；不得从当前 `L2因果事实` 或执行 WIP 补造字段。

### 7.2 C2：同根多父 DAG 与定义

公开能力为直接上位组 / 定义约束组整组替换、直接上下位读取及有界祖先 / 后代投影。上位边只允许同一本体根，多父合法；自环、跨根、成环和替换后根不可达在提交前拒绝。

定义目标使用闭合强类型联合。因果链概念替换后仍须至少一项正式直接因果引用，并重新验证方向、连通、无环、适用范围、规则版本和签名 / 定义逐项互证。祖先 / 后代只投影概念 DAG，不得冒充因果应用层级。

### 7.3 C3：世界事实支持概念

`L2世界事实引用` 使用闭合强类型类别，不接受裸稳定编码或“其它”。因果分支必须是经因果公开服务同截止读回证明的直接因果事实引用，字段机械匹配最终 ABI。

支持关系方向为“世界事实 -> 概念”，多对多、可跨本体根，同一直接因果可支持多个因果链概念。服务只持有引用，不复制世界或因果事实。候选、已退出、错方向、错版本、错范围或非直接因果全部拒绝。

### 7.4 N1：概念名称与完整候选

公开能力为建立 / 退出名称、按概念读取全部当前名称、`按词条读取全部当前概念候选` 和重建反向索引。候选请求不含词性；名称服务必须完整、稳定返回四根内全部当前命中，不调用 7210、不猜默认根、不猜选单项。

L5 外业务如需按词性缩小，只能把完整候选作为值式输入另行调用 7210。零候选、单候选和多候选均为合法业务结果。

### 7.5 C4：生命周期、退出与投影分账

四个本体根永久活跃，不可迁移或退出。普通概念退出前必须清理名称、支持和外部应用引用等跨 owner / 外部阻断项并满足替代边合同；签名、定义、目标相关直接边和生命周期由 C4 在概念 owner 的退出事务中原子闭合，不得先把定义清零而制造非法中间态。退出概念不得修改世界事实或直接因果事实。

C4 只形成本体 DAG、直接定义与直接支持的有限值式结构投影。因果应用层次由 L5 外后继按“目标状态或动态、适用范围、因果版本、展开截止”形成调用方拥有的值式投影；不反写 L2概念结构，不持久化固定层号、路径或间接边。

## 8. A1 聚合、阶段 18 与施工顺序

`L2语言概念结构聚合服务` 透明持有材料、语言、概念、概念名称四个同实例非 owning 引用并提供 const / 非 const getter。它与六类世界 `L2结构聚合服务` 并列，不互相包含、不复制 CRUD。

阶段 18 的独立生产提供者必须经普通应用持有的同一个聚合取得同一个 C1 服务，依次建立或幂等收敛四个固定根，每根正式读回，再读取全部当前根，证明恰四根、身份互异、角色正确、永久活跃、无上位且零额外根；最后以完整候选材料无抛出值式发布。阶段 18 不直达 M1 / L1，不读取语言、词条或词性，不扫描动态，不生成普通概念、二次特征、直接因果或普通因果链概念。

设计流水顺序冻结为：

```text
总设计 v0.3 + M1 v0.3
-> C1 v0.2
-> C2 v0.2
-> C3 v0.2
-> N1 v0.2
-> C4 v0.2
-> A1 同身份新版本
-> CONCEPT-ONTOLOGY-ROOTS-PRODUCTION-INIT v0.1
```

L1 v0.1 在 M1 之后实施，可在 C1 前调度，但不构成 C1 机器依赖。代码执行仍一次一叶；待激活计划不得施工。

阶段 18 启动连续链为 `I1 -> I2 -> E-ROLE -> S-HOST -> SELF-FORM -> 四本体根生产初始化`。E-ROLE、S-HOST、SELF-FORM 是阶段控制前置，不是阶段 18 的数据输入；阶段 18 直接依赖最终 C1 和 A1。阶段 15 永久退出且数值不复用。
