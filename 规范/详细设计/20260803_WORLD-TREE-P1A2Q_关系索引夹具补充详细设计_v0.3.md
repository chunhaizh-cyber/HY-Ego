# WORLD-TREE-P1A2Q 关系索引夹具补充详细设计 v0.3

日期：2026-08-03

设计身份：WORLD-TREE-P1A2Q

来源问题：`DRIFT-P1A2Q-RELATION-INDEX-FIXTURE-UNFORMABLE`

## 1. 裁决、替代范围与当前接口事实

`节点直接索引创建项` 的正式公开合同只有：

```cpp
struct 节点直接索引创建项 {
    索引物理键 键;
    节点直接节点端点引用 目标;
};
```

因此 `节点直接类型化结构提交服务` 只能形成节点目标索引，不能形成关系目标索引。P1A2Q v0.5 计划和故障注入补充详细设计 v0.2 §5 要求“通过 P1A2 正式提交服务建立节点索引和关系索引”不可施工；不得把关系句柄塞入节点端点、扩展共享 DTO、增加写项 variant 或让专项自检临场选择旁路。

当前核心已有唯一合法低层路径：

```cpp
节点直接身份结构写入执行器::执行(
    const std::function<void(节点直接身份结构写入会话&)>& 回调) const

节点直接身份结构写入会话::创建节点候选(
    节点类型 类型,
    节点稳定主键 稳定主键)

节点直接身份结构写入会话::创建关系候选(
    关系类型 类型,
    节点句柄 源节点,
    节点句柄 目标节点,
    std::int64_t 顺序号,
    关系稳定主键 计划稳定主键)

节点直接身份结构写入会话::创建索引候选(
    可重建索引记录 记录)
```

其中 `可重建索引记录` 已以 `索引目标种类::{节点,关系}` 和互斥的 `节点句柄/关系句柄` 表达两类目标，仓库会在同一事务序号下复核目标权威可读。现有 `自检.节点直接身份结构写入.ixx` 已证明专项自检可以在隔离对象上经这一执行器建立节点、关系和索引候选并统一提交。

本版裁决为：P1A2Q 专项自检的**节点目标索引和关系目标索引统一通过上述现有低层执行器形成**。不再要求关系夹具经过 P1A2 公开提交服务，也不新增任何生产接口。该路径只属于专项自检夹具形成，不成为 L2、生产提交或公开 DTO 的第二业务入口。

本文件只替代 `20260803_WORLD-TREE-P1A2Q_故障注入补充详细设计_v0.2.md` §5 中“夹具来源”和与其直接相关的形成步骤；v0.2 §§1—4、§5 的故障模式/恢复证明矩阵、§6—§7 继续有效。主详细设计 v0.2 的生产函数和正常查询矩阵不变。

## 2. 唯一内部结构与函数

物理位置固定为 `海中鱼巣.核心.自检.节点直接结构查询` / `海中鱼巣/核心/自检.节点直接结构查询.ixx` 的模块私有命名空间；不导出，不进入共享头：

```cpp
struct 精确索引查询已发布夹具 {
    索引物理键 节点索引键;
    索引物理键 关系索引键;
    节点句柄 节点目标;
    关系句柄 关系目标;
    std::uint64_t 已发布代次 = 0;
};

std::optional<精确索引查询已发布夹具>
形成已发布双目标索引夹具(
    精确索引查询隔离夹具& 夹具);

bool 允许精确索引查询自检关系(
    节点类型 源类型,
    节点类型 目标类型,
    std::int64_t 顺序号) noexcept;

完整正式关系准入表
形成精确索引查询自检关系准入表();
```

`精确索引查询隔离夹具` 同样是本模块私有结构，唯一拥有本轮隔离对象：

```text
节点直接身份仓库
正式关系仓库（完整正式关系准入表）
可重建索引仓库
节点直接身份结构事务域
节点直接类型合同仓库
节点直接类型化值仓库
节点直接事务幂等仓库（只用于六仓权威导出零变化证明）
节点直接身份结构写入执行器
节点直接结构查询服务
```

成员按被引用对象在前、执行器和查询服务在后的顺序声明；所有对象生命周期覆盖专项自检本轮。不得保存外部生产对象引用，不得共享到其它自检。

函数参数是非空生命周期内借用；函数不保存引用。成功返回调用方拥有的值式身份组；失败返回 `std::nullopt`，且执行器已经按现有事务合同完成撤销或未发布收口。

关系准入回调固定返回 `true`；准入表构造函数逐个填写全部正式关系 ABI 槽，稳定准入身份以本专项固定前缀加槽序号形成、版本固定1、三个布尔准入位均为 `true`，回调均指向上述函数。两函数只负责构造隔离关系仓依赖，不拥有生产准入事实，不导出且无其它调用方；执行者不得只填普通父子一个槽或复用其它自检模块私有函数。

## 3. 同一事务形成顺序

函数只调用一次 `节点直接身份结构写入执行器::执行(callback)`。回调内顺序固定为：

1. 以两个不同且合法的稳定主键建立场景节点和文章节点候选；任一失败立即 `请求撤销()`。
2. 对两个节点分别 `读取节点`，证明候选在本事务可读并满足完成确认的读回边界。
3. 以 `关系类型::普通父子`、场景为源、文章为目标和唯一合法关系稳定主键建立关系候选；失败立即撤销。
4. `读取关系` 得到本事务关系记录并标记关系候选已读回。
5. 用节点索引键形成 `{节点索引键, 索引目标种类::节点, 文章节点句柄, {}}`，调用 `创建索引候选`，再以 `读取索引物理键` 逐字段确认。
6. 用不同的关系索引键形成 `{关系索引键, 索引目标种类::关系, {}, 关系句柄}`，调用 `创建索引候选`，再以 `读取索引物理键` 逐字段确认。
7. 只有两节点、关系和两个索引候选全部成功且逐项读回时调用 `请求提交()`；其它分支调用 `请求撤销()`。

执行器统一完成：取得独占许可、回调、会话确认、全部候选确认待发布、节点/关系/索引按现有顺序完成发布，以及失败时逆序撤销和隔离。专项自检不得自行取得独占许可，不得直接调用仓库的 `结构化创建索引候选`、`确认候选`、`完成发布` 或 `从权威记录重建`。

执行结果必须为 `节点直接身份结构写入状态::已提交`。随后函数取得一次读取许可，要求已发布代次非零，并分别调用：

```text
可重建索引仓库::读取索引物理键结构化(节点索引键)
可重建索引仓库::读取索引物理键结构化(关系索引键)
节点直接结构查询服务::读取当前索引(节点索引键)
节点直接结构查询服务::读取当前索引(关系索引键)
```

四次基线读回都成功、代次一致、目标种类及句柄/稳定见证分别匹配时才返回已发布夹具。否则返回空并使专项自检失败；不得补写或重建夹具。

## 4. 字段来源和提供者—消费者矩阵

| 字段 / 材料 | 唯一来源 | 形成时机 | 消费者 |
| --- | --- | --- | --- |
| 两个节点稳定主键 | 专项自检固定且互异的合法命名域/键值 | 回调前值式形成 | `创建节点候选` |
| 关系稳定主键 | 正式关系命名域和隔离夹具唯一键值 | 回调前值式形成 | `创建关系候选` |
| 节点目标句柄 | 文章节点候选返回 | 同一回调 | 节点目标 `可重建索引记录` |
| 关系目标句柄 | 关系候选返回 | 同一回调 | 关系目标 `可重建索引记录` |
| 节点/关系索引键 | 专项自检固定、完整且互异的值 | 回调前值式形成 | 两次索引创建与后续读取 |
| 事务序号 | 执行器取得独占许可后注入会话 | 执行期间 | 节点、关系、索引三个仓 |
| 已发布代次 | 同一执行器成功发布后由读取许可返回 | 回调结束后 | 基线读回和全部故障模式断言 |

公开 `节点直接索引创建项` 不参与关系夹具形成；P1A2 提交服务不是本函数提供者。低层执行器和会话只提供现有 CORE-C1/v1 事务能力，P1A2Q 专项自检是唯一新增消费者。

## 5. 分支、事务与验证矩阵

| 分支 | 回调决定 | 执行器结果 | 发布事实 | 专项结论 |
| --- | --- | --- | --- | --- |
| 任一节点/关系/索引创建失败 | 请求撤销 | 入口拒绝、内部不一致或候选已撤销 | 零发布 | 夹具失败 |
| 任一候选读回不匹配 | 请求撤销 | 候选已撤销或内部不一致 | 零发布 | 夹具失败 |
| 全部候选及读回完整 | 请求提交 | 已提交 | 两节点、关系、两索引同代次发布 | 继续基线读取 |
| 发布后仓读回失败 | 无新事务 | 已提交已经发生 | 保留已发布隔离事实 | 夹具失败，不修补 |
| 发布后服务读回失败/代次不等 | 无新事务 | 已提交已经发生 | 保留已发布隔离事实 | 夹具失败，不修补 |

专项仍须证明故障注入前后六仓权威导出和已发布代次逐值相等。这里的夹具形成会写入**隔离自检对象**，但注入测试本身零写；不得把“形成基线夹具”与“被测读取函数零机器事实写入”混为一项声明。

## 6. 禁止边与完成边界

```text
专项自检 -X-> 节点直接类型化结构提交服务形成关系目标索引
专项自检 -X-> 扩展节点直接索引创建项或写项 variant
专项自检 -X-> 直接调用仓库候选确认/发布/恢复入口
专项自检 -X-> 直接写正向绑定_/反向绑定_
专项自检 -X-> 生产 SQL、缓存、日志或全局夹具
低层夹具函数 -X-> 成为生产/L2调用入口
```

本设计只闭合 P1A2Q 关系目标索引夹具的合法形成路径。它不扩展公开提交服务的关系索引能力，不证明 P1A2Q 已实现、构建或运行，也不证明生产环境存在关系目标索引发布入口。
