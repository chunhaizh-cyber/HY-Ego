# 二次特征节点生成计算与概念服务详细设计

日期：2026-09-04

版本：v0.1

身份：`DATA-L2-SECONDARY-FEATURE-CLASS`

## 1. 目标与完成边界

在禁止 import、调用或转换任何旧 `服务.L2*` 身份、DTO 和函数的前提下，扩展当前新数据服务链：

```text
数据服务.特征类：唯一持有特征 owner 写端口；承载统一特征定义、派生来源、I64 比较注册和只读比较
数据服务.二次特征类：无 owner、无写端口；编排派生定义生成、读取、计算和概念侧值式投影
数据服务.存在类：只在二次特征请求携带可选宿主时，同截止确认宿主存在身份
DATA-L1：唯一节点、关系、值、幂等、事实代次和原子发布底座
```

本叶完成后只允许声明：新数据服务链已经具备二元、可递归升阶的派生特征定义生成与退出、完整当前读取、已注册 I64 标量比较，以及面向概念消费者的值式材料读取能力。

不承诺生产装配、旧 L2 迁移或退役、概念创建 / 晋升、需求是否需要派生、派生规则业务正确性、通用 n 元计算、向量 / 角度 / 集合 / 空间 / 形状 / 时间序列算法、计算结果持久化、构建、运行、故障注入或独立验收。

## 2. 正式依据与当前事实

### 2.1 正式依据

- 0050：DATA-L2 只保存强类型结构；同一结构唯一写入服务；比较和派生的业务意义位于 DATA 之外。
- 1180：二次至 n 次特征复用统一特征身份和节点族；真实阶次等于直接来源最高阶次加一；来源、角色、规则和版本必须可回查。
- 4150：任务局部结果默认生成即弃；持久定义必须保存实际阶次、直接来源和规则，不得压平来源链。
- 4180：算法必须由正式注册路由；比较状态、拒绝原因、左右角色、结果位、单位、维度、误差和 I64 溢出边界固定；比较零机器事实写入。
- 4230：高阶特征不增加独立 owner；定义、来源和比较注册均属于特征 owner。

### 2.2 已核对当前代码

基线为 `fe41078faceb0a11863848eb1fcc0967c5e5ad26`。

- `海中鱼巣/领域/数据服务.特征类.ixx` 已由一个 `L1所有者范围写端口`独占写入，公开现有特征新增、换代、退出、按身份读取及按类型和值查询；派生定义、阶次、直接来源和比较注册尚不存在。
- 现有普通 `特征类结点`只有一项类型化当前值。本叶保持其 DTO、函数签名和普通节点闭包不变；派生定义使用同 owner 内独立且可辨识的派生定义形状，旧 `查询特征`不把派生定义解释为普通特征值节点。
- `数据服务.存在类.ixx` 已公开 `查询存在(...)`，可以在调用方给定事实代次确认可选宿主；它不提供、也不需要提供特征 owner 写能力。
- `L1事实基座服务::读取中性当前事实代次(...)`、一致当前投影、owner 范围当前 / 历史读取和 owner-scoped 中性写集足以形成读前 / 读后守卫、单写集、幂等重放和读回。
- 旧 `服务.L2特征结构.ixx` 虽有相邻能力，但本叶禁止 import、调用、强转其身份 / DTO、复制函数体或把它作为结果依据。实施只能从本设计、正式规范和新数据服务链当前接口机械完成。

## 3. 物理模块、所有权与依赖

### 3.1 `数据服务.特征类.ixx`

继续是唯一特征 owner 写端口持有者。现有构造器追加一个末尾配置参数：

```cpp
struct 特征类派生结构类型 final {
    稳定编码 实际阶次属性类型;
    稳定编码 派生规则属性类型;
    稳定编码 直接来源关系类型;
    稳定编码 宿主关系类型;
    稳定编码 比较注册归属关系类型;
    稳定编码 比较注册U64属性类型;
    稳定编码 比较注册I64属性类型;
};
```

七项必须非零、互异并由同一个特征 owner 当前持有；两个 I64 属性类型分别为 `实际阶次属性类型`和`比较注册I64属性类型`，两个 U64 组属性类型分别为`派生规则属性类型`和`比较注册U64属性类型`，三种关系类型均为普通节点。构造器配置失败抛 `std::invalid_argument`；不创建类型节点，不借用旧 L2 登记。

### 3.2 `数据服务.二次特征类.ixx`

模块名固定为 `海中鱼巣.领域.数据服务.二次特征类`，只允许：

```cpp
export import 海中鱼巣.领域.数据服务.存在类;
```

由于存在类已导出新特征类依赖，二次特征模块不得再次 import 旧服务。服务构造器固定为：

```cpp
二次特征类数据服务(const L1事实基座服务& 第一层服务,
    特征类数据服务& 特征服务,
    const 存在类数据服务& 存在服务);
```

三个引用必须绑定同一运行期 L1 实例；当前公开类型没有跨服务 `绑定于`函数，故本叶不伪造指针或 owner 等式。构造器只保存引用；每次操作以共同 G0、L1 前后代次守卫及各服务结果代次相等证明本次一致性。二次特征服务不得保存 owner、写端口、稳定编码映射、缓存或可变仓库对象。

依赖方向固定：

```text
二次特征类 -> 特征类 / 存在类 / L1只读
特征类 -> 特征值类 / L1
存在类 -> 特征类 / 状态类 / 动态类 / L1（既有方向，不由本叶扩大）
```

二次特征类不得调用状态、动态、场景、因果或任何旧 `服务.L2*`。

本新链对来源身份的辨识固定为：目标节点只有现有普通特征的一项类型化当前值、没有任一派生结构类型属性或关系时，必须先由既有`查询特征`完整读回，再作为兼容基础定义返回值式阶次 1；目标节点命中派生阶次属性时，只能走本节派生闭包读取，不能再由普通特征读取兜底。两种形状同时成立、普通节点带部分派生字段或派生节点缺字段均为内部不一致。该兼容投影不向基础节点补写阶次，也不把任意 L1 普通节点当特征定义。

比较注册与派生规则必须满足：用途只允许`目标判断`或`状态迁移`；左右角色与用途固定匹配；算法版本必须等于派生规则版本；单位、维度、分量角色非零；允许结果位为 1..7；误差合同版本非零；两个可选误差值如存在均非负。

## 5. owner 单写集与读取

### 5.1 新增

固定控制流：

1. 校验请求、两个来源、规则、宿主编码和 I64 比较合同；任何 L1 写前失败均零变化。
2. 先按完整规范化请求读取本 owner 首次幂等材料；同键同义读回首次完整定义并返回精确重复，同键异义返回幂等冲突。
3. 在同一 G0 逐项调用特征类自己的统一定义读取：基础定义固定阶次 1；派生定义读取其非零显式阶次。来源未找到 / 已退出结构化返回；不得以节点形状、编码或调用顺序猜阶次。
4. 计算`实际阶次=max(两个来源阶次)+1`，检查上溢和来源环。禁止直接来源为待创建自身；历史递归闭包发现任一来源最终引用另一来源不构成环，只有回到候选身份才是环；候选身份发布前不可得，故首次创建通过直接来源互异与既有来源闭包无环证明。
5. 若有宿主，二次特征门面已经用存在类在 G0 确认；特征类仍以 L1 当前普通节点读回确保端点存在，但不把普通节点读回重演成存在身份。
6. 一份特征 owner 写集原子创建：派生定义节点、实际阶次 I64 值和槽、派生规则 U64组值和槽、两条有序来源关系、可选宿主关系、比较注册节点、定义到注册关系、U64 合同值和 I64 误差值及两个槽。全部本地键固定互异；两个来源关系角色编码固定为`(顺序 << 32) | 输入角色`。
7. U64 合同固定顺序：合同版本、用途、算法族=2、算法版本、原始类型=1、左角色、右角色、方向=1、单位、维度、分量角色、允许结果位、边界=1、量化=1、误差合同版本、规则身份。I64 合同固定为误差预算存在位 / 值、相等容差存在位 / 值。
8. 恰一次提交 owner 写集；交换前失败零变化。成功或精确重复必须完整读回定义、来源、宿主和注册，逐字段等于规范化请求且全部自有事实同代创建。
9. 已确认提交后读回不能闭合时返回`已可能发布`、非零事实代次、空定义；调用方只能用原请求和原幂等身份重放收束。

写集本地键固定为：定义节点`1`、阶次值`2`、规则值`3`、第一 / 第二来源关系`0x00010001/0x00010002`、宿主关系`0x00020001`、注册节点`0x00030001`、定义到注册关系`0x00030002`、注册 U64 值`0x00030003`、注册 I64 值`0x00030004`。无宿主时不得占用宿主关系键；其余键恒定存在。

### 5.2 读取

`查询派生特征定义`在请求 G0 用一次一致闭包读取派生节点、两个属性、来源关系、可选宿主关系、注册节点 / 关系 / 两值和 owner；随后逐个来源用本类公开定义读取证明来源身份与阶次。读前和读后事实代次都必须等于 G0。

关系按顺序 1、2 返回；缺项、多项、坏 owner、错类型、错端点、错角色、混代、阶次公式不成立、规则与注册版本不等或注册合同坏形状均返回内部不一致，禁止部分载荷。

### 5.3 退出

退出先幂等重放，再完整读取当前定义；一个 owner 写集退出派生节点、两个定义值、两条来源关系、可选宿主关系、注册节点 / 关系 / 两个注册值。L1 外部当前引用保护返回引用冲突且零变化。成功后在退出代次历史读回完整原定义，证明全部自有事实同代退出；不退出来源、宿主或任何输入事实。

## 6. I64 注册比较

`比较派生特征`固定：

1. 校验合同版本、G0、请求身份、定义、用途、两个输入、生命周期、角色及 1..7 结果位。
2. 在 G0 完整读取派生定义及其唯一注册；不存在注册返回`未注册/未注册`，多注册或坏闭包返回`内部不一致/注册不唯一或无`。
3. 预期版本只作漂移门禁；不能覆盖注册。规则身份取自定义，规则版本必须等于注册算法版本。
4. 输入单位、维度、分量角色、左右角色必须逐项等于注册；输入版本非零、不晚于 G0，创建代次不晚于输入版本，且 G0 时未退出。
   左输入的`来源稳定编码`必须等于定义直接来源顺序 1 的特征定义身份，右输入必须等于顺序 2；`事实身份`是承载本轮不可变 I64 材料的非零事实身份，不要求等于定义身份。
5. 排序三态使用分支，不做减法。相等容差只影响具名等价关系，不改变精确排序三态。
6. 差异固定`右值-左值`并在计算前检查 I64 可表示性。请求差异而不可表示时整项`入口拒绝/差异不可表示`，不得返回半成功。
7. 按结果位返回排序、具名关系和 / 或差异；回显注册、版本、单位 / 维度 / 分量角色、误差、角色及两侧输入版本。
8. 函数只读、无写端口调用。`bad_alloc`和`length_error`为资源失败，其它异常为内部不一致。

状态、拒绝原因和载荷矩阵逐字服从 4180 第 5.1 节；当前只实现算法族 2。其它算法请求固定返回未实现或未注册，不得回退为 I64 减法。

## 7. 二次特征门面公开函数

二次特征模块复用特征类 DTO，并新增：

```cpp
struct 二次特征节点生成请求 final {
    特征类派生定义新增请求 定义请求;
};

struct 二次特征计算请求 final {
    特征类比较请求 比较请求;
};

struct 二次特征概念材料 final {
    特征类定义身份 特征身份;
    std::uint32_t 实际阶次 = 0;
    std::vector<特征类派生来源事实> 直接来源;
    特征类派生规则 派生规则;
    特征类比较注册身份 比较注册;
    std::uint32_t 算法版本 = 0;
    std::optional<稳定编码> 宿主存在;
    std::uint64_t 事实截止代次 = 0;
};

struct 二次特征概念材料结果 final {
    特征类派生数据状态 状态 = 特征类派生数据状态::入口拒绝;
    std::uint64_t 事实代次 = 0;
    std::optional<二次特征概念材料> 材料;
    bool 成功() const noexcept;
};

特征类派生定义结果 生成二次特征节点(const 二次特征节点生成请求&);
特征类派生定义结果 查询二次特征节点(const 特征类派生定义查询请求&) const;
特征类派生定义结果 退出二次特征节点(const 特征类派生定义退出请求&);
特征类比较结果 计算二次特征(const 二次特征计算请求&) const;
二次特征概念材料结果 读取二次特征概念材料(
    const 特征类派生定义查询请求&) const;
```

每个入口先用 L1 当前事实代次读取冻结 G0，并要求它等于请求代次；结束前再次读取，非相等返回事实代次漂移且清空成功载荷。

生成时如果带宿主，先调用`存在类数据服务::查询存在`；只有`已读取 + 成功 + 身份吻合 + 事实代次=G0`才调用特征类写入口。门面不调用存在类任何写函数。

所有门面入口只接受实际阶次大于 1 的完整派生定义。概念材料是调用方拥有的值式投影，不调用概念服务，不建立概念身份、名称、支持关系或晋升判断。
