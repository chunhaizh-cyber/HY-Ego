只有 `已读取` 的读取结果可以携带与入口匹配的完整快照；世界快照的 `完整` 表示整个根世界闭合，存在快照的 `完整` 表示该存在的当前位置、全部当前特征及相关状态动态闭合，场景快照的 `完整` 表示请求场景、直接父关系、全部直接子场景、全部直接成员存在及这些成员的特征状态动态闭合。单对象入口从一次已通过同代次完整性检查的完整世界快照形成专用子集，不把子集伪装成完整世界快照。只有 `已提交/幂等读回` 的写入结果可以携带与入口匹配的 `操作读回`。写入结果不附带事务释放后重新读取的“当前快照”，避免并发合法前进被误判为原提交不一致。`缺项组` 只用于 `内部不一致`，按缺项种类、对象稳定主键、关系稳定主键排序；其它状态必须为空。所有 DTO 可复制/可移动，不含引用、指针、锁、令牌、SQL、材料路径或内部句柄。

`持久证据状态` 复用 4040 的稳定枚举：`已与内存代次一致=1`、`待持久化=2`、`持久化结果未知=3`、`持久证据落后=4`、`持久证据损坏=5`、`不适用=6`。写前准备失败返回 `资源失败`、发布代次为零且状态为 `不适用`；内存已发布但发布见证追写未知时仍返回 `已提交`、非零代次和操作读回，同时持久状态为 `持久化结果未知`，调用方不得把它改写成“事实未发生”。幂等读回返回原提交的持久状态或经同键追写后收敛的新状态。

`持久证据状态` 的唯一物理定义位于 `核心/节点直接结构合同.数据.h`；L1 提交结果、幂等支持仓和 L2 世界事实值直接复用，不在任何服务模块复制第二组稳定值。该共享头只依赖 `句柄.h` 与所需 STL，不依赖任何命名模块，防止 L1→L2 反向依赖。

状态的五个关系字段必须分别精确对应关系 19 顺序 1—5。动态的九类关系字段对应关系 20 顺序 1—9：状态迁移的来源动作/低层/同源迁移均为空且聚合规则版本为 0；动作致变要求来源动作和同源迁移恰一；聚合要求来源低层动态组非空且聚合规则版本非零；观察/外部事件按 4210 允许的可选动作边界形成。节点组与关系组逐项一一对应并按稳定身份排序，任何适用字段缺失或不适用字段非空均为内部不一致。

类型化值完整性固定为：表示枚举与 variant 分支一一对应；区间要求 `下界 <= 上界`；有序组按合同声明保留顺序且不得以容器地址比较；稳定身份组每项完整；独立材料引用要求身份、格式、字节数和 SHA-256 非零。类型合同同身份同版本异内容为内部不一致；兼容只认具名直接版本和方向，不传递推导。`类型化值读回` 的当前记录恰一；首次记录的 `前一值记录版本` 为空且值记录版本为 1，换代记录的前一版本非空且新版本恰为前一版本加一。`首次发布代次` 与 `当前状态发布代次` 均非零且后者不早于前者；退役历史保留首次发布代次并以退役事务代次更新当前状态发布代次。索引读回的节点/关系目标恰一；已移除时 `当前=false` 但保留目标历史见证。

- 关系读取唯一功能：在普通或本事务视图按稳定主键定位唯一当前关系，或按源、目标、相关节点返回值式内部记录。普通重载只投影已发布当前关系；带事务序号重载要求事务序号非零，只额外投影该事务自己的创建、失效和重挂候选，并以候选写后视图替换同一关系的写前当前，不看见其它事务候选。合法零项固定返回 `已读取 + 空关系组`；无效节点句柄、未定义关系类型或零事务序号返回 `入口拒绝 + 空关系组`；任一关系两端不能在同一普通/事务视图解析为有效节点、稳定主键重复、关系记录与永久占用/高水位不一致时返回 `内部不一致 + 空关系组`。成功枚举统一按关系稳定主键命名域、键值、关系版本升序，不使用顺序号、内部关系编号或容器迭代顺序。上述 `正式关系记录` 只在 L1 仓库和事务内部按值使用，允许携带调用期内部句柄；对 L2 暴露的查询服务必须在许可内把它转换为稳定身份见证，任何公开服务 DTO 均不得携带句柄。
- 关系权威材料导出唯一功能：复制全部已发布/历史关系记录、每命名域高水位和永久历史占用键并分别稳定排序；不包含未发布候选、锁或容器引用。P1A1 只提供仓库级导出，P1A2 的冻结/恢复聚合器再消费该值式材料，不在 P1A1 修改冻结模块。
- 关系计划身份唯一功能：固定执行器在已持事务域独占许可且尚无候选时读取 `关系稳定主键命名域::正式关系` 高水位，检查未到 `UINT64_MAX` 后形成 `高水位 + 1` 的计划稳定主键；会话只逐字段转交该计划键，关系仓创建入口只接受该命名域、键值恰为当前高水位加一且未被历史占用的计划键。候选建立才推进仓内高水位和临时占用，撤销未发布候选恢复写前高水位/占用；完成发布后永久占用。P1A1 自检在会话创建前从关系仓读取高水位并形成测试计划键；生产计划键只能由 P1A2 固定执行器在独占许可内形成。L2、服务请求和普通调用方不得读取高水位或指定计划稳定主键。
- 代次读取唯一功能：在有效共享或独占许可内读取当前内存已发布代次；无效许可返回 `0`。
- 前置：许可由同一节点直接身份结构事务域产生且仍持锁。
- 后置：无写入；返回值在许可存续期间不变。
- 非成功：代次为 `0` 表示尚无已发布事实或许可无效；调用方先以 `有效()` 区分两者。
- 并发：每个成功的结构事务最后发布恰推进一次；回滚、拒绝和幂等纯读回不推进。
- 溢出：达到 `UINT64_MAX` 时禁止后继发布并隔离事务域，不能回绕。

提交服务逐字段把 `节点直接类型化结构事务请求` 复制为 `节点直接类型化结构数据操作请求`，调用数据操作后按同数值状态表逐字段映射为服务结果；探测和见证重试同样只做显式状态映射。数据操作和执行器的公开签名不得出现服务模块拥有的请求、状态或包装结果，服务模块也不得声明或构造数据操作规格。恢复服务把安装实例请求及持久端口材料准入后形成数据操作恢复请求，并把 `节点直接恢复数据操作结果` 映射为自有 `节点直接结构恢复结果`；两层同值枚举是不同模块实体，禁止 `reinterpret_cast`、按内存布局复制或重复声明。

`节点直接结构查询服务` 完整构造固定持有事务域、节点、关系、索引、类型合同和类型化值六个依赖；每次调用内部取得一次 try-lock 共享许可，竞争立即返回 `许可拒绝`，不阻塞、不睡眠、不隐式重试。成功/未找到都携带同次非零代次；其它状态代次为零。`读取精确类型合同` 只调用构造注入的类型合同仓，不允许从类型化值或 SQL 反推合同。

`节点直接类型化结构提交服务` 是 L1 业务中性的唯一公开结构提交服务。公开 `提交` 只接受服务模块自有的版本化纯值请求并返回服务模块自有的纯值结果；服务只保存安装实例身份和数据操作引用。`节点直接类型化结构数据操作` 只保存执行器引用，负责把服务请求逐字段复制为模块自有中性规格、确定性编码并调用执行器，不保存服务请求/结果。完整执行器构造固定持有事务域、节点、关系、索引、类型合同、类型化值、幂等和持久证据端口，且这些依赖都由运行期装配拥有并长于执行器、数据操作、提交/恢复服务和全部同步调用；既有四参数构造的对象 `类型化结构有效=false`，调用新提交或恢复一律入口拒绝。参与者登记顺序固定为 `类型合同 -> 节点身份 -> 类型化值 -> 正式关系 -> 可重建索引 -> 节点删除 -> 事务幂等记录`，由执行器完整构造依赖和数据操作规格固定，调用方不能传参与者指针、回调、会话、候选、事务视图、许可或锁。`类型化值材料` 只能是 4020 已登记类型合同允许的强类型材料 variant，不允许任意 JSON、无类型字节包、万能 I64 或领域自定义未登记分支。

`探测幂等` 是业务服务在读取可变提供者或计算执行证据前的纯值入口。请求意图摘要由 L2 事实所有者按其公开请求全部机器字段的合同版本 1 确定性编码计算，不含后来解析出的前态、比较提供者或计划身份。探测内部取得一次共享许可并只读幂等仓和持久证据状态侧账：未找到返回 `未找到`；同身份同意图且记录已发布返回 `同义已发布`，其 `原结果` 状态统一写为 `幂等读回` 并携带原发布代次、原通用读回和当前内存持久证据状态；同身份异意图返回 `异义冲突`；待发布/隔离返回 `待发布或隔离`；许可竞争立即返回许可拒绝。其它分类的 `原结果` 必须为空。探测不访问 SQL、不推进代次、不重算执行证据。真实新提交的执行证据摘要由 L2 事实所有者按本操作冻结算法对请求意图、解析前态、采用提供者身份/版本、比较分类和最终确定写集形成，并显式写入事务请求；L1 只验证摘要非全零、持久保存和参与结果摘要，不解释其业务字段。

所有 L2 写事实所有者都必须在形成 `节点直接类型化结构事务请求` 时写入非全零请求意图摘要和执行证据摘要；L1 只验证摘要非全零、同键比较和确定性编码版本，不猜测领域字段。需要读取可变提供者才能形成写集或可能在到达 `提交` 前逻辑拒绝的入口，必须先调用 `探测幂等`；只依赖不可变请求即可直达提交的入口可以由固定事务独占许可内最终幂等裁决收敛，但仍须按冻结算法形成执行证据摘要。

`服务稳定身份`、`类型合同读回`、`类型化值来源见证`、`节点直接类型合同仓库` 和 `节点直接类型化值仓库` 物理位置固定为 `核心/节点直接结构合同.数据.h`、`核心/仓库.节点直接类型合同.ixx` 和 `核心/仓库.节点直接类型化值.ixx`。提交服务、数据操作和执行器分别由 `核心/服务.节点直接类型化结构提交.ixx`、`核心/数据操作.节点直接类型化结构.ixx`、现有 `核心/执行器.节点直接身份结构写入.ixx` 唯一拥有；模块之间不前置声明同名服务、不使用跨模块 friend。提交服务只调用数据操作，数据操作只调用执行器，L2 只 import 提交服务；`核心/服务.节点直接结构.ixx` 只定义纯值查询服务。类型合同仓以 `(合同身份, 合同版本)` 为不可变主键；同键异内容拒绝，同键同内容幂等。类型化值仓以 `类型化值记录稳定身份` 保存历史，以 `(所属身份, 类型合同身份, 合同版本)` 裁决唯一当前记录；换代只把旧记录转为历史并发布新版本，不覆盖旧材料。类型化值来源必须是已发布节点见证或类型合同所有者服务身份：节点来源按同代次解析；服务来源只允许系统签发资格 / 分类事实且必须逐字段等于合同所有者服务，禁止空来源、SQL 行和调用方自报。上面公开的仓库函数只供 L1 查询服务和固定参与者使用，不对 L2 导出仓库对象。

三个新仓候选生命周期完全采用同一状态机：`结构化...未发布候选` 只在事务序号非零、计划身份/版本/材料完整且无异事务占用时返回一个 move-only 候选；普通读取看不到候选，固定执行器只通过候选对象的 `读取候选合同/读取候选值/读取候选记录` 取得值副本。三个读回函数只在阶段 `持有` 或 `已确认待发布` 且候选内部条目仍完整匹配时返回值；`已撤销/已发布/已移动`、候选丢失或内部记录矛盾均返回 `nullopt`，不泄漏引用、容器或写权。`确认候选` 只允许 `持有 -> 已确认待发布`；`撤销候选` 只允许 `持有/已确认待发布 -> 已撤销` 并逐字段恢复写前当前/历史/高水位；`完成发布` 只允许 `已确认待发布 -> 已发布`，清除候选事务标记并使计划记录对普通读取可见。重复同阶段调用返回精确同义，错事务、错阶段、记录矛盾或候选丢失返回内部不一致。每个仓内部自行持独占锁，候选对象不暴露容器、锁或可写引用；固定执行器按 `类型合同 -> 节点 -> 类型化值 -> 关系 -> 索引 -> 删除 -> 幂等` 建立/确认，按逆序撤销，并逐项检查 `完成发布` 的返回状态，任何部分发布立即隔离事务域。幂等记录候选的计划状态必须为 `待发布`、发布代次等于预计后继代次、摘要和读回完整；`完成发布` 是把记录状态切换为 `已发布` 的唯一入口。持久证据状态侧账不属于该不可变候选，单独按下文状态表更新。

类型合同完整性固定为：稳定身份、命名空间和所有者服务身份均完整；合同版本非零；表示与值域 variant 分支一一对应；所有区间下界不大于上界；项目数上下界合法；直接兼容项的另一身份/版本/操作/方向完整且按 `(另一身份, 另一版本, 操作, 方向)` 排序去重；首次发布代次和当前状态发布代次由 L1 填充且非零、后者不早于前者。普通发布只允许首次 `当前可写` 合同或同内容幂等；`停止新写`、`退出普通使用` 只能由后继具名生命周期入口按原合同换代，不在世界树 v1 暴露通用修改函数。世界资格/状态/动态合同的命名空间固定为 `世界领域类型合同命名空间={(类型合同命名域::L2领域),1}`；其它命名空间不能发布本包六个合同。值域分别冻结为正文列出的枚举集合或完整 U64 区间。

同一写集内每个 `节点直接写集局部身份.值` 必须非零且跨全部种类全局唯一，只在本次请求和原幂等读回中有效；局部身份种类必须与写项匹配。普通提交不接受任何待分配稳定主键或身份版本：L1 按节点类型命名域分配节点稳定主键、按正式关系命名域分配关系稳定主键；节点/关系普通新建版本固定为 `1`；类型化值记录初始版本固定为 `1`，存在预期当前版本时新版本必须由 L1 计算为 `预期当前 + 1`，溢出拒绝。关系端点只能引用已发布节点见证或本写集更早的 `节点` 局部身份；类型化值所属和索引目标同样只允许节点引用；类型化值来源允许节点引用或合同所有者服务身份，节点分支服从相同引用顺序。读回项必须按对象种类引用匹配的局部身份。禁止前向引用、循环局部引用或由 L2 读取高水位后自行分配稳定键。

计划稳定身份按命名域分别分配。每个命名域内先按 `局部身份.值` 严格升序排列创建项，从当前高水位后一项开始分配连续键；跨命名域互不比较。局部身份重复、排序后非严格递增、所需数量使高水位超过 `UINT64_MAX`、或计划键已在历史占用表出现时，在持久准备和候选前返回内部不一致并隔离溢出域。确定性写集材料必须保存每个 `(局部身份种类, 局部身份值) -> (稳定身份命名域, 计划键, 初始版本)` 映射、预计后继代次和解析后的全部已发布端点；恢复不得重新排序或重新分配。

`预期事实截止代次` 对所有公开真实新提交必须非零，并等于 L2 完成写前业务读取时所有成功结果的唯一代次。固定事务入口取得独占许可后先比较当前已发布代次；不等返回 `版本漂移`，零写入且不调用持久端口。公开 `提交` 无空域例外。恢复服务在持久端口确认安装实例从未发布后，唯一调用数据操作模块的恢复专用 `初始化确认空域治理代次`：该入口只接受当前代次 0、全部业务仓为空且实例证据状态为 `确认从未发布`，以固定事务命名域 `安装实例初始化`、键值等于安装实例键值建立仅含 L1 幂等治理记录的代次 1，并完成写前准备、最后发布和发布见证；它不创建节点、关系、类型合同、类型化值或索引。该治理事务的节点组、关系组、类型化值组、索引组、计划身份映射和业务操作读回必须全部为空；结果摘要固定覆盖 `(材料格式版本=1,写集规则版本=1,安装实例身份,治理事务身份,请求意图摘要,执行证据摘要,发布代次=1,空计划身份映射,空通用读回)`，不得省略空集合或以 SQL 自增号代替。随后世界引导按普通公开提交使用预期代次 1 创建世界事实。只有 `节点直接结构恢复服务` 允许 import 并调用该恢复专用入口；普通提交服务、L2、组合和路由均无调用边。

恢复精确身份不属于公开普通 `提交` DTO。`节点直接结构恢复服务` 唯一定义在 `核心/服务.节点直接结构恢复.ixx`，拥有安装实例恢复请求、恢复判定和恢复包装结果；它完成持久材料准入后调用 `节点直接类型化结构数据操作::恢复`。恢复数据操作请求/规格归数据操作模块，包含持久证据给出的稳定主键和精确版本，只能由恢复服务逐字段形成；执行器只接受数据操作规格。任何 L2 服务都不能 import 数据操作或执行器，不能构造恢复规格，也不存在跨模块 friend。

服务在第一笔候选前校验合同、幂等摘要、写项顺序、类型合同、身份和预期版本；候选确认失败按上述固定顺序逆序撤销。最后发布与代次推进后、独占许可释放前，服务按通用 `节点/关系/类型化值/索引 + 当前/失效/移除 + 身份 + 预期版本` 读回项调用内部固定读回器形成结果。L1 不知道“世界引导、创建存在、特征、状态动态、移动或移除”等业务种类；L2 事实所有者负责把通用读回映射成自己的操作专属结果。读回失败时事实保持已发布，返回 `内部不一致`、保留非零发布代次且不携带假成功材料。L2 各领域服务只能形成职责内写项并映射结果，不能把这个 L1 服务暴露为万能 CRUD。

幂等裁决只读取内存幂等仓：先行探测与独占许可内最终复核均以 `(幂等身份, 请求意图摘要)` 比较；同键同意图且状态 `已发布` 直接返回记录中的原发布代次、原通用读回和内存持久证据状态侧账，不推进代次；同键异意图返回幂等冲突；`待发布/已隔离` 返回内部不一致。真实新提交把幂等记录候选与业务写集同事务发布，记录同时保存请求意图摘要、由完整写集/解析前态/提供者版本等确定性执行材料形成的执行证据摘要、原发布代次和通用读回。执行证据变化不会把同意图重试变成新事务；只有未找到分支才允许形成一次执行证据。记录进入冻结、持久证据和 4070 恢复材料；运行期禁止通过 SQL 回查幂等结果。

现有 `节点直接身份结构写入执行器::执行` 在返回后即释放独占许可，不能直接承担本合同的发布后读回。P1A2 必须在现有执行器模块增加 `执行节点直接类型化结构事务(const 节点直接类型化结构数据操作规格&)` 与 `执行节点直接恢复事务(const 节点直接恢复数据操作规格&)`；两种规格、内部结果与确定性编码器只由 `核心/数据操作.节点直接类型化结构.ixx` 声明和形成。执行器函数只供该数据操作模块调用；计划以 import 静态扫描确保 L2、组合、路由和其它服务没有执行器调用边，不依赖 friend 或重复类声明实现可见性。提交/恢复服务各自拥有公开请求副本至同步调用返回，不保存引用；数据操作逐字段形成规格，执行器捕获全部异常，分配失败映射资源失败，其它异常映射内部不一致，异常最终由对应服务边界本地记录一次。它不接受外部参与者组或业务回调。内部阶段固定为：取得独占许可 -> 校验幂等、预期代次与完整写集 -> 只读解析当前事实并从各命名域高水位计算本事务计划稳定身份、预计后继代次和确定性写集材料（此时不推进高水位、不建立候选） -> 写前持久准备 -> 按计划身份建立类型合同/节点/类型化值/关系/索引/删除和幂等候选 -> 按固定顺序确认 -> 失败项逆序撤销 -> 全部参与者最后发布 -> 已发布代次恰推进一次 -> 在原许可内按读回规格复核 -> 对全部发布后分支尝试追写持久发布见证 -> 返回并释放许可。写前准备失败时尚无候选、高水位或普通事实变化；独占许可保证准备完成前计划身份不被并发占用。幂等纯读回在计划身份计算前返回，不调用持久端口、不推进代次。

幂等候选在最后发布前保存计划身份映射、预计后继代次、计划通用读回和由这些确定性材料形成的结果摘要；与全部参与者一起从 `待发布` 原子转为 `已发布`，然后事务域才推进代次。原许可内发布后读回只负责逐字段验证，成功时返回记录中的同一结果；验证失败时不得二次改写已发布幂等事实，而是立即隔离事务域，以 `(材料格式版本, 写集规则版本, 事务身份, 请求意图摘要, 执行证据摘要, 发布代次, 计划身份映射, 状态=内部不一致)` 形成失败见证摘要并返回内部不一致。隔离后普通入口无法取得许可，因此该计划材料不会再向普通调用者返回。恢复读取到这类失败见证时只能形成隔离审计候选并拒绝整批普通恢复，必须保持普通入口关闭；不得把 `已隔离` 记录连同业务事实发布到可开放的普通域，也不得由恢复者自行选择“拒绝或开放”。正常和失败两种读回分支都必须尝试写发布见证；见证成功/未知只单调更新幂等仓内独立的非权威持久证据状态侧账，不修改幂等业务记录、不推进代次。后续幂等探测从该内存侧账返回最新状态，禁止查询 SQL。见证失败优先保留业务分类：成功读回返回已提交和持久化结果未知，失败读回返回内部不一致和持久化结果未知。

`节点直接身份结构事务域` 是已发布代次的唯一内存所有者：初始为 `0`；共享许可和独占许可只提供只读见证；仅上面的固定事务入口可在全部参与者完成发布后把它从 `n` 推进到 `n+1`。`UINT64_MAX` 时在第一笔候选前拒绝并隔离，不回绕。普通结构查询若代次为 `0` 返回未找到或内部不一致，不能把事务序号、结构编号、时间或仓库高水位冒充代次。

持久证据策略固定为“写前准备 + 发布后见证”：候选确认前，持久端口按幂等身份、请求意图摘要、执行证据摘要和完整写集写入并读回 `已准备` 证据；失败则 `资源失败` 且零内存写入。准备成功后内存持久状态侧账记为 `待持久化`。内存发布和操作读回完成后，端口追写发布代次、结果摘要和 `已与内存代次一致` 见证；追写成功侧账单调转为 `已与内存代次一致`，失败/未知转为 `持久化结果未知`，均不改变业务代次。启动恢复从已见证 SQL 证据重建该侧账；只有准备证据而无可验证发布见证时返回 `发布未知` 并阻止普通入口，不得猜测已发布或未发布。

持久二进制编码的每个 `std::variant` 先写一个 `U8` 稳定分支标签，再写该分支字段；未知标签、重复字段、尾部多余字节或标签与合同表示不一致均拒绝。标签固定为：`节点直接类型化结构写项` 按声明顺序 `类型合同发布=1、节点创建=2、关系创建=3、关系失效=4、类型化值发布=5、类型化值退役=6、索引创建=7、索引移除=8、节点删除=9`；`节点直接节点端点引用` 为 `已发布节点=1、写集局部节点=2`；`节点直接类型化值来源` 为 `节点引用=1、服务稳定身份=2`；`类型化值材料` 与 `类型化值表示种类` 共用 `I64=1、U64=2、I64区间=3、I64有序组=4、U64有序组=5、稳定身份有序组=6、独立材料引用=7`；`类型合同值域` 使用相同 1—7 标签；`节点直接发布后读回项.身份` 为 `局部身份=1、节点稳定主键=2、关系稳定主键=3、类型化值记录稳定身份=4、索引物理键=5`。`optional` 统一先写 `U8 0/1`，随后才写值；布尔统一 `U8 0/1`；枚举按其冻结底层宽度和稳定值写网络字节序。写集编码器和恢复解码器都定义在数据操作模块内部并以同一材料格式版本 1 互测，不使用 `variant.index()`、RTTI、结构体内存布局或编译器枚举布局。

材料格式版本 1 的单事务 `写集材料` 上限固定为 `67,108,864` 字节；任一 vector 声明数量上限固定为 `1,048,576` 项，同时仍受总字节上限约束。编码前用无符号检查证明累计字节数不超过上限；普通新请求超限返回 `入口拒绝`，零持久/内存写入。解码先读取 SQL `DATALENGTH` 并验证总上限，再对每个 U64 数量依次验证 `数量 <= 1,048,576`、`数量 <= SIZE_MAX`、最小项目字节数不超过剩余字节，全部通过后才允许 `reserve/resize`；任何乘加溢出、截断、尾随字节或超限均返回 `损坏/持久证据损坏` 并保持普通入口关闭，不尝试部分恢复。两个 32 字节摘要按原样固定写读恰 32 字节，不带长度前缀。

SQL 物理证据表固定为 `[dbo].[节点直接结构事务证据_v1]`，主键为 `(安装实例命名域 BINARY(8), 安装实例键值 BINARY(8), 事务命名域 BINARY(8), 事务键值 BINARY(8))`。其余列固定为：`材料格式版本 INT NOT NULL`、`请求意图摘要 BINARY(32) NOT NULL`、`执行证据摘要 BINARY(32) NOT NULL`、`写集材料 VARBINARY(MAX) NOT NULL`、`证据状态 TINYINT NOT NULL`、`发布代次 BINARY(8) NULL`、`结果摘要 BINARY(32) NULL`、`创建时间 DATETIME2(7) NOT NULL`、`更新时间 DATETIME2(7) NOT NULL`。全部无符号 64 位值按网络字节序写入 `BINARY(8)`；摘要为 SHA-256；写集材料使用合同版本 1 的确定性二进制编码，字段顺序严格按 DTO 声明顺序，整数网络字节序、vector 写 `U64 数量 + 项目`，禁止 JSON、SQL 行序或本机结构体内存布局。`证据状态` 稳定值为 `已准备=1、已与内存代次一致=2、发布结果未知=3、已判损坏=4`。表的唯一作用是持久证据和恢复输入，普通业务查询模块不得引用。

`SQL节点直接持久证据适配` 唯一定义在 `海中鱼巣.适配.SQL.节点直接持久证据` / `海中鱼巣/适配/SQL.节点直接持久证据.ixx`，同一实例同时实现写入和恢复两个端口；构造只借用一个生命周期更长的 `SQL数据库适配`，不取得运行期事实权威，不保存长期 ODBC 连接。每次调用先复用 `SQL数据库适配::初始化数据库()` 确认数据库存在，再以该适配的只读配置建立本次 ODBC 连接；因现有 ODBC 辅助在 `.cpp` 私有，新模块只建立模块私有 RAII 连接/语句/参数绑定辅助，不导出通用 SQL 或复制业务审计入口。`初始化证据结构`、`准备`、`标记已发布` 和 `读取安装实例` 由模块内部互斥串行化，数据库事务不持有任何核心仓库锁；同一运行期只装配一个该适配实例并同时注入恢复服务与完整执行器。

初始化固定在单个 SQL 事务内检查并按固定 DDL 建立两张 v1 表、约束和主键；只有两表均由本次事务首次建立时才插入该安装实例的 `确认从未发布` 行。两表已存在但实例行缺失、只存在一表、列/类型/约束漂移或实例状态与事务行矛盾返回 `损坏`，不补表、不补实例行。`准备` 在一个 SQL 事务中以主键查旧行：无旧行则插入 `已准备` 并把实例状态从确认无历史切换为存在事务；完全同义返回 `精确同义`；任一摘要/材料不同返回 `冲突`。`标记已发布` 只允许同义已准备行按发布代次和结果摘要转为已见证；完全同义已见证返回 `精确同义`。连接、超时、分配或明确回滚失败映射 `资源失败`；执行/提交后连接丢失且无法从同一调用确认提交结果映射 `结果未知`；列值、长度、状态或摘要矛盾映射 `损坏`。禁止以异常文本、SQL 行序或本地时间改变分类。

持久状态侧账转移唯一允许：`不适用 -> 待持久化`（准备成功后、第一笔候选前）、`待持久化 -> 已与内存代次一致/持久化结果未知`（发布见证明确成功/未知）、`持久化结果未知 -> 已与内存代次一致`（具名重试成功）、以及任一非损坏状态在持久材料确证矛盾时转为 `持久证据损坏`；`持久证据落后` 只由恢复/审计发现证据最大代次低于内存见证时设置。禁止从损坏、落后或一致回退到待持久化。`单调记录持久证据状态` 在准备后首次更新失败时停止候选并返回内部不一致；发布后的侧账更新失败时隔离事务域并返回内部不一致，同时保留已经发布的业务代次。`重试持久发布见证` 只读取不可变已发布幂等记录副本和当前侧账，释放仓锁后调用同一适配 `标记已发布`，成功再单调更新侧账；它不改业务事实、不推进代次、不查普通 SQL 业务表。重复成功返回无需重试，未知保留未知，冲突/损坏隔离事务域。

安装实例表固定为 `[dbo].[节点直接安装实例证据_v1]`，主键为安装实例两个 `BINARY(8)` 字段，另含 `实例状态 TINYINT NOT NULL`、`创建时间/更新时间 DATETIME2(7)`。只有适配器在同一数据库事务中确认两张 v1 表都是本次新建时，才插入 `实例状态=确认从未发布(1)`；表已存在但实例行缺失、事务表存在行而实例仍为从未发布、或任一表损坏均不得补插，返回损坏。第一条准备证据与实例状态切换为 `存在事务证据(2)` 必须在同一 SQL 事务提交。运行期普通服务没有登记全新实例函数。

L1 数据操作结果先由对应 L1 提交服务映射为服务结果，再由 L2 事实所有者映射成自己的场景/特征/状态动态结果，最后由世界树门面映射为 `世界树写入结果`。各层基本状态固定逐项为：`已提交 -> 已提交`、`幂等读回 -> 幂等读回`、`入口拒绝 -> 入口拒绝`、`幂等冲突 -> 幂等冲突`、`版本漂移 -> 版本漂移`、`许可拒绝 -> 许可拒绝`、`资源失败 -> 资源失败`、`内部不一致 -> 内部不一致`。不得跨过事实所有者直接把 L1 结果交给门面，不得把许可竞争映射成资源失败，不得把读回不一致映射成业务拒绝。只有前两项允许非零发布代次和操作读回；其中幂等读回携带原提交代次，不推进当前代次。

L1 查询到世界树读取映射固定为：`成功且完整 -> 已读取`、`未找到 -> 未找到`、`入口拒绝 -> 入口拒绝`、`版本漂移 -> 版本漂移`、`许可拒绝 -> 许可拒绝`、`资源失败 -> 资源失败`、`内部不一致 -> 内部不一致`。成功子结果只有代次不等时由组合层进入一次完整重试；其它状态禁止重试或降级为空成功。

门面持有服务引用，生命周期短于运行期业务装配且长于所有请求。它不缓存世界根或快照，不捕获线程对象，不进行 SQL 回源。每个写函数只接受领域服务在原独占事务内形成的 `发布代次 + 操作读回` 并映射统一结果；事务释放后的当前世界读取只能由独立查询入口执行。

`节点直接状态业务服务` 必须提供 public 窄强类型函数 `形成完整世界实例状态写项(const 世界树完整状态请求&)`，只允许 `节点直接动态业务服务` 和本服务专项自检调用，并以关系 19 角色 1—5 形成值式写项结果；它不通过 friend 暴露私有规格，旧裸 I64 入口不能被世界树服务调用。`节点直接动态业务服务::发布状态并整理动态(const 世界树状态动态请求&)` 是公开唯一入口：在同一事实截止内读取主体、场景、特征完全相等的全部已发布状态。零项为基准态；非空时最大 `发生时间戳` 必须恰一项，且新时间必须严格大于该最大时间，才把它作为唯一相邻前状态。新时间小于当前最大时间返回 `历史插入拒绝` 并映射世界树 `入口拒绝`；不重算、不换代、不改写既有状态或动态。已存在同一采样时间的状态时，同幂等身份同义返回原结果，其它情况为幂等冲突，不以稳定主键排序择一。没有前状态时同事务只发布基准状态；有前状态时经 4180 当前唯一注册比较路由裁决等价或合法差异，等价只发布后状态，合法差异同事务发布后状态和关系 20 状态迁移动能。未注册、不可比、差异不可表示、同采样位置已有异义状态或前状态不唯一时第一笔写前拒绝。调用方不得指定前状态、来源动作或动态稳定身份；真实差异分支由动态领域分配，整理幂等身份同义重试返回原状态/动态读回。动作致变动态及其来源动作由 4220 的独立入口形成并引用本次迁移动能，不在此函数中顺带创建。

状态/动态入口只使用外层 `整理幂等身份` 作为一次原子事务身份；不得再为后状态建立第二事务幂等键。状态写项的局部身份固定为：状态节点 `节点:1`、发生时间值记录 `类型化值记录:2`、关系 19 角色 1—5 分别为 `关系:101—105`。差异分支追加动态节点 `节点:201`、动态种类/发生时间/聚合规则版本值记录 `类型化值记录:202—204`、关系 20 角色 1—5 和 9 分别为 `关系:301—305、309`；角色 6—8 不建立写项并保留局部值 306—308 未使用。基准和等价分支不得出现 201—309。所有局部身份只在本请求及原幂等读回内有效，禁止持久解释其数值。

`形成完整世界实例状态写项` 固定依次形成：状态节点、状态发生时间类型化值、关系 19 的主体/场景/特征/特征值/来源存在五项和相应读回规格。状态发生时间值记录的 `来源` 固定为请求的 `来源存在`。动态服务仅在合法差异分支固定追加：动态节点、动态种类/发生时间/聚合规则版本三项类型化值、关系 20 的主体/场景/被改变目标/前状态/后状态/来源存在六个实际关系；角色 3 `被改变目标` 固定指向请求的特征定义，不指向前值或后值；动态发生时间严格等于后状态发生时间；三个动态类型化值的 `来源` 都固定为请求的 `来源存在`；状态迁移角色 6—8 不适用，因此不建立对应关系，读回必须证明三类为空且聚合规则版本为 0。`节点直接动态写项形成结果` 是模块私有中间值，不是第二参与者或第二事务入口。

状态动态入口在任何状态查询或 4180 比较前，先按合同版本 1 对 `(世界树请求头全部字段, 后状态全部字段, 整理幂等身份)` 做字段顺序固定、整数网络字节序的确定性编码并形成 `请求意图摘要`，调用 L1 `探测幂等`。同义已发布直接映射原结果；异义冲突、待发布/隔离、许可拒绝和内部不一致立即返回；只有未找到才继续。新事务的 `执行证据摘要` 必须包含请求意图摘要、解析出的唯一前状态（若有）、4180 当前比较提供者稳定身份/合同版本/算法版本、比较分类、预期事实截止代次和最终确定性写集材料。后来比较注册变化不会改变同意图重试的原结果。同采样位置检测、前状态选择、比较路由和全部端点完整性必须在调用 L1 提交服务前完成；随后把请求意图摘要、执行证据摘要和该次查询的唯一非零代次分别写入 `节点直接类型化结构事务请求.请求意图摘要/执行证据摘要/预期事实截止代次`，由 L1 独占许可内最终复核幂等和代次。L1 不重算或解释执行证据摘要，只验证其非全零并原样纳入准备证据、幂等记录和结果摘要。

P1B 采用的 4180 比较提供者必须把当前唯一注册及其生命周期发布到 P1A2 建立的同一 L1 事务域，并在 `特征比较结果` 中增加非零 `事实截止代次`、注册稳定身份、比较合同版本和算法版本。状态动态服务只接受比较结果代次与状态查询代次完全相等的成功分类；不等立即返回 `版本漂移`。最终 L1 提交再以该共同代次作预期事实截止，因而注册、前状态或端点任一在比较后变化都会被拒绝。若 4180 最终实现不能提供同一 L1 代次见证，WORLD-TREE-P1B 保持待激活，不得用比较服务私有计数、缓存版本或调用时间替代。

状态动态结果到世界树结果映射固定为：`已提交->已提交`、`幂等读回->幂等读回`、`入口拒绝->入口拒绝`、`幂等冲突->幂等冲突`、`前状态不唯一->内部不一致`、`比较未注册->资源失败`、`不可比->入口拒绝`、`差异不可表示->入口拒绝`、`版本漂移->版本漂移`、`许可拒绝->许可拒绝`、`资源失败->资源失败`、`内部不一致->内部不一致`、`历史插入拒绝->入口拒绝`。禁止把比较能力缺失伪装成无变化成功。

P1B 首次真实状态事务必须同写集幂等发布 `状态发生时间类型合同`（U64标量，所有者状态）；首次真实动态事务必须同写集幂等发布 `动态种类类型合同`（I64标量，值域 1—5）、`动态发生时间类型合同`（U64标量）和 `动态聚合规则版本类型合同`（U64标量，状态迁移固定 0，聚合非零）。同身份同版本异内容为内部不一致。状态/动态记录 DTO 是这些类型化值和关系 19/20 的组合投影，不新增领域参与者或无类型记录仓。

`节点直接特征写入服务::提交世界树特征批次` 是 4170 的稳定身份适配入口：初始项目要求 `实例槽、写前当前关系、写前当前值、写前原始值版本` 全空，换代项目要求四项全有；调用方不指定新槽或新值稳定主键。原始值必须携带当前正式类型合同稳定身份/版本，并且 `类型化值材料` 分支与合同表示完全匹配；不得引用未提交 NT-P2A WIP 中的 `特征值原始值式材料` 或把它当当前代码事实。真实新建分支由特征领域按命名域高水位连续分配稳定主键，候选值只在事务内可见；同一批次幂等身份同义读回原分配结果，异义冲突。世界树初始入口要求全部项目为初始，更新入口要求全部项目为换代。节点直接特征提供者的最终合同尚未进入当前基线，因此 P1C 在该提供者实现、发布并由计划智能体按当前代码重核依赖前保持待激活。

## 5. 禁止替代

- 不把 `运行期纪元`、许可序号、时间戳或仓库编号写入 `事实截止代次`。
- 不保留、转发或通过 `世界服务.h` 补齐任何字段；切换时删除该文件及真实调用边。
- 不让 L2 传入事务参与者、发布后回调、事务视图、仓库或锁；L1 只接受通用对象读回项，不解释业务操作种类。
- 不新增万能 `增删改查(variant)`；九个函数保持具名语义。
- 不把物理删除扩入移动或移除关系。
- 不让执行者自行选择 DTO 字段、枚举值、模块位置或错误映射。
