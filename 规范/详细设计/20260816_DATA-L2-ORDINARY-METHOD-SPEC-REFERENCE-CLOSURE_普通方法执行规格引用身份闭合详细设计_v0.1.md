# DATA-L2 普通方法执行规格引用身份闭合详细设计

日期：2026-08-16

身份：`DATA-L2-ORDINARY-METHOD-SPEC-REFERENCE-CLOSURE`

版本：`v0.1`

## 1. 目标与完成边界

本设计在已发布的 `L2普通方法结构.数据.h` 上一次性闭合后继普通方法完整 DTO 仍缺少的五类公共强类型引用：

```text
作用对象绑定身份
+ 参数规格身份
+ 禁止项规格身份
+ 适用范围身份
+ 稳定动作键
```

完成后，条件、结果、动作入口和后继方法完整事实可以引用具名类型，不再使用裸 `稳定编码`、裸 `uint64_t`、字符串、函数地址或通用 I64 槽表达这些角色。本叶只建立值式 ABI 和工程登记检查，不建立对应节点、关系、事实、CRUD、候选索引、动作映射或业务解释。

本叶不证明参数已经绑定、禁止项已经裁决、方法可执行或 `DATA-EXT-14` 已完成。

## 2. 正式依据与当前事实

创建侧基线从最新正式 `main` 重做 S0 后记录。当前已确认：

| 依据 / 事实 | 结论 |
| --- | --- |
| 0050 v20260815、4030 | DATA-L2 只保存并校验强类型方法结构，不判断参数是否合适、禁止项是否命中或方法是否成功。 |
| 3300 v0.3 | 方法条件和结果必须具有作用对象；动作入口必须具有稳定动作键；完整方法还必须保留适用范围。 |
| 5300 v0.4 | 作用对象绑定不得使用文本绑定名；参数、禁止项和适用范围必须与条件 / 结果 / 动作入口分账，召回命中后仍需权威读回。 |
| 5230 v0.6、5310 v0.1、5320 v0.1、5340 v0.1 | 任务冻结必须精确绑定参数、禁止项、作用对象、动作入口和方法适用范围；执行期不得补造这些结构。 |
| `L2结构公共.数据.h` | 已有场景、存在、特征、状态、方法、需求和任务等公共身份，不存在本叶五类角色类型。 |
| `L2普通方法结构.数据.h` | 已有治理虚拟存在、条件、结果、动作入口四种方法节点身份以及内容版本、规格版本；没有绑定、参数、禁止项、范围和强类型动作键。 |
| `协议.任务执行请求.ixx` | 历史执行协议仍以裸 `uint64_t` 保存稳定动作键；本叶不修改该异层协议，也不把旧字段反向定义为 DATA ABI。 |

现行正式规范尚未唯一冻结参数值域算法、禁止项比较算法、作用对象端点集合或适用范围展开算法。因此本叶只建立这些正式结构角色各自的不可混用身份；其完整事实字段由后继 `DATA-L2-ORDINARY-METHOD-PUBLIC-DTO` 冻结，不以一个万能 variant、裸编码或通用材料提前猜测。

## 4. 精确公开 ABI

在既有 `L2普通方法结构合同版本 = 1` 之外新增独立引用合同版本，不改变上一叶已经发布的常量：

```cpp
inline constexpr std::uint32_t L2普通方法规格引用合同版本 = 1;

struct L2方法作用对象绑定身份 final {
    稳定编码 值;
    explicit L2方法作用对象绑定身份(稳定编码 编码 = {}) noexcept
        : 值(编码) {}
    friend bool operator==(const L2方法作用对象绑定身份&,
        const L2方法作用对象绑定身份&) = default;
};

struct L2方法参数规格身份 final {
    稳定编码 值;
    explicit L2方法参数规格身份(稳定编码 编码 = {}) noexcept
        : 值(编码) {}
    friend bool operator==(const L2方法参数规格身份&,
        const L2方法参数规格身份&) = default;
};

struct L2方法禁止项规格身份 final {
    稳定编码 值;
    explicit L2方法禁止项规格身份(稳定编码 编码 = {}) noexcept
        : 值(编码) {}
    friend bool operator==(const L2方法禁止项规格身份&,
        const L2方法禁止项规格身份&) = default;
};

struct L2方法适用范围身份 final {
    稳定编码 值;
    explicit L2方法适用范围身份(稳定编码 编码 = {}) noexcept
        : 值(编码) {}
    friend bool operator==(const L2方法适用范围身份&,
        const L2方法适用范围身份&) = default;
};

struct L2方法稳定动作键 final {
    std::uint64_t 值 = 0;
    friend bool operator==(const L2方法稳定动作键&,
        const L2方法稳定动作键&) = default;
};
```

前四种身份属于普通方法结构 owner 下待发布结构角色的强类型身份，只承载非零不透明稳定编码。它们彼此不可隐式转换，也不可与方法、条件、结果、动作入口、存在、状态或裸稳定编码互换。它们的存在不证明对应节点已发布、当前、属于某方法或内容完整。

`L2方法稳定动作键` 是 DATA 保存的非零不透明动作映射键。它不是 L1 节点 / 关系 / 值稳定编码，不是方法或动作入口身份，不是函数地址、回调、插件句柄、枚举动作类型或执行成功证据。DATA 不解释该键对应哪个函数；DATA 之外的合法动作桥只能在完整方法规格和任务冻结已经权威读回后机械匹配受支持键。

## 5. 纯值 helper

同一头新增：

```cpp
inline bool L2方法作用对象绑定身份有效(
    L2方法作用对象绑定身份 身份) noexcept;
inline bool L2方法参数规格身份有效(
    L2方法参数规格身份 身份) noexcept;
inline bool L2方法禁止项规格身份有效(
    L2方法禁止项规格身份 身份) noexcept;
inline bool L2方法适用范围身份有效(
    L2方法适用范围身份 身份) noexcept;
inline bool L2方法稳定动作键有效(L2方法稳定动作键 动作键) noexcept;
```

前四项只调用 `有效(身份.值)`；动作键只判断 `动作键.值 != 0`。helper 不读取事实，不证明引用当前、内容完整、允许执行、已绑定或未命中禁止项。

## 6. 后继 PUBLIC-DTO 门禁

`DATA-L2-ORDINARY-METHOD-PUBLIC-DTO` 必须在本叶结果与上一身份叶结果上继续冻结，而不能只返回本叶身份：

1. 每个绑定、参数、禁止项和适用范围的完整强类型事实字段、关系角色、基数、确定顺序、版本和生命周期；
2. 条件 / 结果与场景、特征定义、目标状态合同、作用对象绑定和规格来源版本的完整关系；
3. 动作入口与输入 / 输出场景、稳定动作键、当前性和规格版本；
4. 方法登记根归属、方法身份来源、唯一治理虚拟存在、内容版本和关系 23 生命周期事实；
5. 新增、不同新身份替换、退出、当前 / 历史完整读取，以及按结果规格读取候选身份组后同截止权威读回；
6. 非成功空载荷、数量预算、幂等、事实代次和发布未知收敛边界。

如果后继仍不能从正式规范唯一裁决某个完整事实字段，必须具名退回对应规范 / 设计缺口，不能把本叶身份或动作键当作内容本身。
