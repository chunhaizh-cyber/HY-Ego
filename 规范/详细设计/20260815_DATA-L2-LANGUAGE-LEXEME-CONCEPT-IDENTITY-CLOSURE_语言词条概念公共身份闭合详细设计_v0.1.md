# DATA-L2 语言词条概念公共身份闭合详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-LANGUAGE-LEXEME-CONCEPT-IDENTITY-CLOSURE`

## 1. 目标与边界

依据 4240 v0.6，只在 `L2结构公共.数据.h` 中补齐语言、词条、概念三个彼此不可转换的强类型身份和节点族闭集，使后继各族服务能够使用同一公共身份来源事实形状。

本叶只建立值式类型合同，不建立任何 owner、节点、关系、CRUD、聚合、装配或机器事实。语素和词性按现行规范不形成持久节点族，禁止恢复对应身份或枚举。

## 2. 当前事实

## 3. 精确公开合同

在现有强类型身份宏块尾部追加：

```cpp
定义L2强类型身份(L2语言身份);
定义L2强类型身份(L2词条身份);
定义L2强类型身份(L2概念身份);
```

现有 `L2节点族` 1—7 数值不变，只在尾部追加：

```cpp
语言 = 8,
词条 = 9,
概念 = 10
```

`L2节点族身份来源事实完整(...)` 的闭合枚举判断同步接受这三值。通用 helper 只判断值式形状；它接受某个节点族不证明该族 owner、CRUD、节点或身份来源事实已经存在。

## 4. ABI 与禁止范围

- 三个身份继续沿用现有显式 `稳定编码` 包装、默认零值和逐字段相等，不新增隐式转换。
- 不改变 `L2结构合同版本`、`L2结构状态` 1—15、读取类别、请求 / 结果头、既有七个身份或既有节点族数值。
- 不修改任何 L1、结构服务、聚合、普通应用、工程、BIZ、线程、规范或最终需求清单。
- 不新增验证 helper、测试 seam、日志、sleep、deadline 或运行时分支。

## 5. 验证与完成声明

施工只需静态核对精确类型 / 数值 / helper 闭合，并执行根工程 x64 Debug / Release Rebuild、diff、strict、UTF-8、白名单和生产零验证痕迹检查。真实语言、词条或概念事实读写 `NOT_RUN`，因为本叶没有服务，也不得为了命中而增加生产入口。

本叶完成只证明公共身份类型和节点族闭集可被后继代码编译消费；不证明语言、词条、概念根、普通概念、概念聚合或最终需求清单任何服务整项已经实现。
