## 1. 替代关系与保留边界

v0.17 替代并禁止施工 v0.16 中 G7/G8 的首次 DTO 映射部分。v0.16 已成立且本版本不得改变的合同包括：G1—G6 编码、唯一公共原语、领域摘要与 G0 摘要独立互证、核心不得覆盖调用方摘要、P-L1/P-I/P-S 身份、合同/规则版本、I02=`2/2`、F02=`3/3`、X02=`2/2`、模式 1/2/3、32 个生产/业务场景、18 个自检调用、32→50、16 文件/50 物理调用点和 24 文件白名单。

本版本只修订 T01/T02（G7）和 M01/M02/M03（G8）的真实写入口 DTO、摘要字段顺序、固定标签、同义/异义分组、测试向量、首次结果 DTO 映射和恢复重算。它不实现代码，不扩展 P15 原目标，不证明当前 provider 前探测已接通。

## 3. G7 修订：字段矩阵、入口和结果

公共原语、域前缀 `HZY-L1G7`、格式版本 `1`、字段头、网络大端、optional/variant/vector/array 和 SHA-256 继续沿用 v0.16。G7 函数位于 `海中鱼巣/领域/服务.L1状态.ixx`，不接受自由操作标签：

```text
形成G7状态登记意图摘要(const L1状态登记请求&) -> L1确定性摘要
形成G7首个基准状态发布意图摘要(const 实际存在I64首个基准状态发布请求&) -> L1确定性摘要
```

字段号即编码顺序：

| 点/标签 | 真实请求 DTO | 字段顺序 |
|---|---|---|
| T01/`0x15000601` | `L1状态登记请求` | 1 合同版本(U32)，2 规则版本(U32)，3 状态操作幂等身份(U64)，4 期望事实代次(U64) |
| T02/`0x15000602` | `实际存在I64首个基准状态发布请求` | 1 合同版本(U32)，2 规则版本(U32)，3 状态操作幂等身份(U64)，4 期望事实代次(U64)，5 当前特征(嵌套 `实际存在I64实例特征读取请求`)，6 发生时间戳(U64) |

T02 的嵌套当前特征按其 DTO 声明顺序编码：合同版本、规则版本、宿主实际存在读取请求、I64 特征定义读取请求、实例槽、宿主关系、定义关系、当前值、来源节点；嵌套的宿主/定义读取请求继续按自身字段声明顺序递归编码。T01 不携带当前特征、时间戳或 provider/结果材料。

首次结果映射保持真实入口：T01 映射 `L1状态登记结果`，T02 映射 `实际存在I64基准状态结果`；结果状态、登记/事实副本、provider 版本和执行证据只进入首次执行材料，不进入领域请求意图摘要。

## 4. G8 修订：字段矩阵、入口和结果

G8 函数位于 `海中鱼巣/领域/服务.特征比较.ixx`，公共域前缀 `HZY-L1G8`、格式版本 `1` 保持；三个固定标签绑定三个真实写入口，不能以读取 DTO 或业务比较 DTO 代替：

```text
形成G8特征比较登记意图摘要(const 特征比较登记请求&) -> L1确定性摘要       // M01
形成G8目标判断合同登记意图摘要(const I64目标判断比较合同登记请求&) -> L1确定性摘要 // M02
形成G8状态迁移合同登记意图摘要(const I64状态迁移比较合同登记请求&) -> L1确定性摘要 // M03
```

字段号即编码顺序：

| 点/标签 | 真实请求 DTO | 字段顺序 |
|---|---|---|
| M01/`0x15000801` | `特征比较登记请求` | 1 合同版本(U32)，2 规则版本(U32)，3 特征比较操作幂等身份(U64)，4 期望事实代次(U64) |
| M02/`0x15000802` | `I64目标判断比较合同登记请求` | 1 合同版本，2 规则版本，3 特征比较操作幂等身份，4 期望事实代次，5 定义登记(嵌套 `特征定义登记`)，6 特征定义(嵌套 `I64特征定义读取请求`)，7 实例登记(嵌套 `实例特征结构登记`) |
| M03/`0x15000803` | `I64状态迁移比较合同登记请求` | 1 合同版本，2 规则版本，3 特征比较操作幂等身份，4 期望事实代次，5 定义登记(嵌套 `特征定义登记`)，6 特征定义(嵌套 `I64特征定义读取请求`)，7 实例登记(嵌套 `实例特征结构登记`) |

M02 与 M03 的字段形状相似，但固定标签和用途不同，必须使用不同域摘要；M01 只有四个顶层字段，不能把登记后生成的配置值、合同字段关系、单位、维度或算法结果提前编码。首次结果映射分别为 `特征比较登记结果`、`I64目标判断比较合同结果`、`I64状态迁移比较合同结果`。

嵌套字段的顺序冻结如下：`特征定义登记` 为合同版本、规则版本、事实截止代次、服务身份、定义标记属性类型、I64 下界属性类型、I64 上界属性类型；`I64特征定义读取请求` 为合同版本、规则版本、特征定义、定义标记值、下界值、上界值；`实例特征结构登记` 为合同版本、规则版本、事实截止代次、服务身份、宿主槽关系类型、定义模板关系类型、当前 I64 值属性类型。

## 5. 同义/异义、预探测和 G0 互证

T01、T02、M01、M02、M03 各自是独立业务操作身份；同一点同一 DTO 全字段相等为同义，任一公开字段差异为异义。不同点即使字段相同也因固定操作标签不同而异义，不能共享摘要或幂等域。

每一点必须先由上述真实写入口 DTO 形成领域摘要，再以该摘要执行 provider 前 `探测幂等`；只有 `未找到` 后才读取 provider、事实或嵌套 provider。核心独立形成 G0 规范化写集摘要，只作互证，不得覆盖 `L1写集请求` 中调用方的领域摘要、组号、格式版本和操作标签。任何把读取 DTO、结果 DTO 或 G0 写集倒灌为 T01/M01 意图摘要的路径均入口拒绝且零写。

## 6. 首次 DTO、恢复重算和拒绝矩阵

恢复必须按首次账中保存的点、固定标签和真实首次 DTO 重算：

| 点 | 首次 DTO/结果 | 同义 | 异义/缺字段/错误 DTO |
|---|---|---|---|
| T01 | `L1状态登记请求` → `L1状态登记结果` | 摘要相等，provider/提交 `0/0`，读回首次登记 | 拒绝；不得用 T02 请求替代 |
| T02 | `实际存在I64首个基准状态发布请求` → `实际存在I64基准状态结果` | 摘要相等，provider/提交 `0/0`，读回首次基准状态 | 拒绝；缺当前特征/时间戳拒绝 |
| M01 | `特征比较登记请求` → `特征比较登记结果` | 摘要相等，provider/提交 `0/0`，读回首次登记 | 拒绝；不得用 M02/M03 合同登记请求替代 |
| M02 | `I64目标判断比较合同登记请求` → `I64目标判断比较合同结果` | 摘要相等，provider/提交 `0/0`，读回首次目标判断合同 | 拒绝；不得用只读合同请求或业务比较请求替代 |
| M03 | `I64状态迁移比较合同登记请求` → `I64状态迁移比较合同结果` | 摘要相等，provider/提交 `0/0`，读回首次状态迁移合同 | 拒绝；不得用 M02 DTO 替代 |

缺字段、字段顺序/类型错误、标签错误、领域摘要与 G0 摘要混淆、首次账/审计/读回不一致均拒绝；双账或发布后读回矛盾进入内部不一致并隔离。G1—G6 的恢复矩阵、身份/版本/调用去重、32/18/50 和模式 1/3 空组裁决不变。
