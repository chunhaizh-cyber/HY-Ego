# 静态一次特征聚合分类规范治理输入

日期：2026-09-05

身份：`DATA-L2-FEATURE-AGGREGATION-CLASSIFICATION`

版本：v0.2

状态：已由用户纠正并转入 `DATA-L2-FEATURE-FACT-SET` 正式治理；本文件不再授权“类别 / 归类”模型

## 1. 用户纠正

用户明确：“和概念不是同一回事，是事实的分类，在这里可以看作是一个事实的集合，不是归类”。因此原 v0.1 的“类别定义 + 样本分类结果 + 算法见证”解释全部撤销。

“正面轮廓”“侧面轮廓”等例子在本目标中只表示不同的静态特征事实集合身份。数据层保存集合由哪些已经成立的特征事实组成；它不声明某个样本属于哪个概念类别，不执行分类判定，不保存置信度、阈值、训练模型或算法身份 / 版本。

## 2. 正式治理路由

本目标改由 4125《静态一次特征事实集合》承载，并同步收口 1120、1130、4120、4150、4160、4230：

- 复用 4120 的复合特征“具名成员结构”原则，但把定义期的复合槽位与实例期的事实集合版本严格分开；
- 集合成员必须是已发布的一次特征事实节点，成员关系只表达集合组成及结构角色 / 顺序；
- 集合不产生新的原始采集值，也不从成员计算另一个值，所以仍属于静态一次特征事实层；
- 任何比较、差值、变化率、方向或其它计算结果仍由 1180 / 4150 的二次特征承载；
- 概念空间、世界事实支持概念关系和 4180 比较算法均为零依赖。

## 3. 被撤销的旧假设

以下 v0.1 内容不得再被设计、计划或代码恢复：分类体系 / 维度、类别定义、样本归属、互斥或多标签分类、分类结果、分类规则 / 算法见证、置信度、重分类以及形状距离启用。原具名 DRIFT 已由本次正式规范治理消解，不再冻结特征集合代码。

## 4. 完成边界

本文件只记录用户纠正和旧输入退役。正式机器合同见 4125，最早代码叶见 `DATA-L2-FEATURE-FACT-SET` 详细设计与计划；它们均不实现分类算法、概念形成或二次特征计算。
