# DATA-L2 特征实例当前值独立退出详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-FEATURE-CURRENT-VALUE-EXIT`

## 1. 目标与边界

补齐 `计划/数据服务最终需求清单.md` 的 `DATA-EXT-03`：在唯一 `L2特征结构服务` 中，让合法调用方具名退出一个特征实例的当前值，同时保留实例、宿主关系、定义关系、族归属关系和历史值。

本叶不新增特征节点族、owner、属性类型、空值、墓碑值或第二当前槽；不改变特征定义 / 实例创建、值新增 / 换代、实例 / 定义退出和按存在读取；不解释材料业务含义。

## 2. 当前事实与裁决

1. `L2特征实例事实::当前值` 已是 optional；没有当前值是合法完整结构。
2. 当前公开面已有值新增、换代和历史读取，但没有不退出实例的值退出入口。
3. `L1所有者范围写集请求::退出事实` 退出当前值时，会在同一候选状态内移除所有指向该值的当前属性槽；无需也不允许伪造新值进行清槽。
4. 特征实例端口唯一拥有实例和值；退出值继续使用该端口及现有全局幂等域，不建立第二写入口。
5. 4230 v0.9 已冻结：未设置返回 `属性未设置`，具名值不是当前值返回 `引用冲突`；精确重复返回首次结果，资源失败或未知发布使用原完整请求收敛。

## 3. 精确公开 ABI

在 `海中鱼巣/领域/L2特征结构.数据.h` 增加：

```cpp
struct L2特征当前值退出请求 final {
    L2结构请求头 请求头;
    L2结构幂等身份 幂等身份;
    L2特征实例身份 特征实例;
    稳定编码 当前值稳定编码;
    friend bool operator==(const L2特征当前值退出请求&,
        const L2特征当前值退出请求&) = default;
};

struct L2特征当前值退出结果 final {
    L2结构结果头 结果头;
    std::optional<L2特征实例事实> 特征实例;
    std::optional<L2特征实例自有关系引用> 自有关系;
    std::optional<L2特征值事实> 已退出值;
    bool 成功() const noexcept;
    friend bool operator==(const L2特征当前值退出结果&,
        const L2特征当前值退出结果&) = default;
};

inline bool L2特征当前值退出请求有效(
    const L2特征当前值退出请求&) noexcept;
```

请求有效固定要求：共同合同有效、期望事实代次非零、幂等身份有效、实例身份非零、当前值稳定编码非零且不等于实例编码。

在 `海中鱼巣/领域/服务.L2特征结构.ixx` 的 `L2特征结构服务` 原位增加：

```cpp
L2特征当前值退出结果 退出特征当前值(
    const L2特征当前值退出请求& 请求);
```

## 4. 成功与非成功形状

成功只允许 `已提交` 或 `精确重复`；结果截止非零，变更代次存在且等于结果截止。三份 optional 全部存在：

- `特征实例` 在结果截止仍为当前，身份等于请求实例，`当前值` 为空；
- `自有关系` 的宿主 / 定义关系编码非零、互异，且与实例完整读回一致；
- `已退出值` 的实例等于请求实例，值编码等于请求当前值编码，退出代次等于结果截止，材料、来源和创建代次保持首次值事实。

全部非成功的三份 optional 为空且变更代次为空。入口错字段为 `入口拒绝`；实例或值不存在 / 已退出沿现行读取映射；当前值为空为 `属性未设置`；当前值存在但编码不同为 `引用冲突`；期望代次过期为 `事实代次漂移`；幂等异义为 `幂等冲突`；许可、分配和未知发布按现行结构化状态返回，不猜成功。

## 5. 实现流程

1. 校验纯值请求。
2. 读取实例身份来源和当前值类型登记，固定实例 owner 与值类型。
3. 形成只含 `退出事实={请求.当前值稳定编码}` 的 owner-scoped 写集；写入幂等身份继续使用现有特征实例端口映射。
4. 若安全取得的当前事实代次等于请求守卫，正式读取实例并校验当前值存在且编码等于请求；为空返回属性未设置，异值返回引用冲突。若代次已变化，不用新事实改写请求，直接提交让 L1 裁决漂移或精确重复。
5. 提交一次写集。首次成功与精确重复均核对合同、owner、幂等身份、事实代次、发布 / 重试边界和唯一退出项映射。
6. 以写入结果代次形成历史截止：读回实例在该截止仍当前且当前值为空，读回具名历史值且退出代次等于截止；宿主 / 定义 / 族归属关系保持原样。
7. 任一成功形状矛盾返回内部不一致；资源与未知结果不生成新幂等身份、不改写完整请求。
