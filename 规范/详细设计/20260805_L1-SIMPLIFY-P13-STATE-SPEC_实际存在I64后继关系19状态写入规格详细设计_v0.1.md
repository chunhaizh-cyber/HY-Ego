## 1. 目标与完成边界

本叶形成“实际存在 I64 后继关系19状态”的版本化纯值写入规格。它从 P10/P8 的新当前事实、P12 的相邻前状态选择和 P11 的状态迁移比较取得同一截止材料，经状态领域校准后，确定构造与 P9 v0.3 完全同形的二节点、五值、五关系19、五属性槽写集规格。

真实成功行为包括：

1. 比较等价：形成后状态规格并明确 `禁止生成迁移动能`；
2. 比较不等价：形成同一后状态规格并携带后继动态领域可消费的迁移纯值证据。

本叶只形成内存纯值规格，不调用 L1 写入、不分配稳定编码、不发布第二状态或关系20、不登记动态、不执行最终幂等提交。无前状态、比较非成功或材料不一致均不形成任何规格。

## 2. 正式依据与能力裁决

- 4190 要求原子状态属于同一存在主体的一个具体特征，并以业务发生时间、状态身份和事实截止明确读取。
- 4200 §7.8 禁止调用方提供前状态；§7.9 固定无前态、等价和有差异分支；状态与动态须由各自领域形成规格后再由后继组合发布者原子提交。
- 4210 冻结关系19五角色和“无材料变化不生成迁移动能”；值事实不能直接作为关系端点。
- P9 v0.3 冻结关系19及状态值见证的唯一结构：二普通节点、五值、五关系、五属性槽，且状态领域拥有解释权。
- P10 v0.1 提供存在宿主新当前事实，P12 v0.1 选择相邻前状态，P11 v0.1 以旧采样值为左、新当前值为右形成迁移比较纯值证据；三者均仍是待实现合同。
- 当前 L1 写集只要求本地键非零且写集内唯一，不要求连续。因此可用业务中性的命名空间本地键拼接多个领域规格；不得让执行侧临场重编号。

依赖裁决：P11 已冻结 `特征比较服务 -> L1状态服务`。若状态服务反向调用比较服务会形成模块环。因此新增无事实写权的组合模块负责依次调用 P10/P8、P12、P11；最后调用同一 L1 状态服务的“已校准规格形成入口”。状态服务仍是关系19和状态写集规格唯一所有者，组合器不是第二状态服务。

## 5. 固定组合流程与同截止校准

组合器固定执行：

1. 校验合同、规则、规格、业务请求身份、整理幂等身份和新发生时间均非零；非法返回 `入口拒绝`。
2. 读取 L1 完整快照 `G0`，取得非零事实截止 `G`。
3. 以请求中的 P10/P8 当前组合请求调用存在宿主当前读取，取得主体、当前场景、实例槽、真实 P2 定义及定义关系、新当前值、当前属性槽和来源；只接受完整成功且截止为 `G`。
4. 以该主体、实例槽、新发生时间和由业务请求身份确定派生的查询身份调用 P12。调用方不能传前状态。P12 必须在截止 `G` 返回结果。
5. P12 返回 `无前状态` 时立即返回 `无前状态`，零规格、零迁移证据；不得调用 P9 首态入口或把请求降级成首态。
6. P12 返回前状态时，使用选择器形成并已通过 P9 v0.3 读取的完整不可变前状态，不复制关系19解释。
7. 由组合器从 P12 返回的完整 P9 事实逐字段机械重建 `实际存在I64基准状态读取请求`，再与原 P10/P8 后当前读取请求一起调用 P11；预期截止固定为 `G`。业务调用方不得提供前状态读取请求、算法或注册。
8. 校准 P12选择证据、P9前状态、P11输入左侧、P10/P8当前和P11输入右侧完全同义；主体、实例槽和真实P2定义一致；前后场景必须相等；新发生时间严格晚于前状态发生时间；来源、值编码、创建/退出代次和比较注册/算法/用途完整。
9. 再读 L1 完整快照 `G1`。只有 `G0.事实代次 == P10/P12/P11截止 == G1.事实代次` 才可继续。漂移时丢弃整轮材料并完整重试一次；仍漂移返回 `版本漂移`。
10. 把已校准值式材料传给状态服务形成规格。状态服务不得读取比较服务或自行选择前态。

P11 等价成功和非等价成功都形成后状态规格。P11 非成功、坏成功载荷、跨场景、时间不递增或任何见证矛盾都不形成规格。

## 6. 关系19状态规格和字段来源

规格精确复用 P9 v0.3 的结构，零退出事实：

```text
2 个普通节点
5 个值
5 条关系19
5 个属性槽
```

本地键固定：

| 本地键 | 事实 | 来源 |
| --- | --- | --- |
| `0x53000001` | 后状态节点 | 整理幂等身份、主体、实例槽、新发生时间、规格版本的确定映射 |
| `0x53000002` | 状态特征值见证节点 | 后状态节点与P10新当前见证的确定映射 |
| `0x53000003` | 状态资格值 | P9登记的状态资格属性类型，材料固定1 |
| `0x53000004` | 新发生时间值 | 请求新发生时间 |
| `0x53000005` | 见证资格值 | P9登记的见证资格属性类型，材料固定1 |
| `0x53000006` | 新当前引用值 | `[值编码, 创建代次, G, 来源编码]` |
| `0x53000007` | I64采样值 | P10/P8新当前I64材料 |
| `0x53000008` | 关系19角色1 | 源=键1，目标=P10主体 |
| `0x53000009` | 关系19角色2 | 源=键1，目标=P10当前场景 |
| `0x5300000A` | 关系19角色3 | 源=键1，目标=P8实例槽 |
| `0x5300000B` | 关系19角色4 | 源=键1，目标=本地键2 |
| `0x5300000C` | 关系19角色5 | 源=键1，目标=P10来源存在 |

五个属性槽分别把键3、键4挂到键1，把键5、键6、键7挂到键2；属性类型、所属、来源和生命周期完全沿用 P9 v0.3。v1 固定 `来源存在 == 主体`，否则返回 `入口拒绝`；不得把未经存在资格验证的普通节点放入角色5。

值事实不是关系端点；角色4只指向本地见证节点。P2抽象定义不复制入状态规格，状态角色3仍是具体实例槽。

## 7. 跨领域本地键组合合同

本地键为 32 位非零纯值：高8位是领域规格命名空间，低24位是该规格内局部序号。状态规格固定命名空间 `0x53`，动态规格后继可使用不同命名空间，例如 `0x44`。

最终组合发布者必须：

- 直接拼接各领域不可变规格；
- 不重编号、不重映射、不解释状态字段；
- 验证全写集本地键全局唯一；
- 允许动态规格单向引用 `0x53000001` 后状态节点；
- 禁止状态规格反向引用任何动态键。

命名空间只在一次 L1 写入请求内有效，不是稳定编码、业务身份或持久合同。最终稳定编码只由后继 L1 原子写入分配。本叶不得提前调用分配器或猜测编码。

## 8. 确定性、幂等与纯值摘要

相同合同/规则/规格版本、业务请求身份、整理幂等身份、P10/P12/P11完整见证、新发生时间和截止必须逐字段生成相同规格及相同摘要；容器地址、迭代顺序、线程、缓存、锁、许可和未来稳定编码不得进入摘要。

摘要输入按固定字段序列编码，至少包含：规格版本、整理幂等身份、主体、场景、实例槽、P2定义、P10新值完整见证、前状态身份/发生时间/选择规则、P11注册身份/算法版本/三态/具名关系/等价/差异、共同截止和十二个本地键事实的规范字段。摘要只用于检测规格同义与冲突，不是权威事实、审计证明或最终提交幂等结果。

同一整理幂等身份和同义材料返回相同规格；同一整理幂等身份但材料、时间、前态、比较合同或截止不同返回 `冲突`，不形成规格。服务可以在锁内复制只读登记，但不得维护规格幂等账或缓存；最终持久幂等由后继原子发布者处理。

## 9. 成功形状与错误映射

| 条件 | 结果 |
| --- | --- |
| P11等价成功、差异0、关系为状态迁移等价 | `已形成` + 完整规格 + 完整迁移证据 + `禁止生成迁移动能` |
| P11非等价成功、差异与三态/具名关系一致 | `已形成` + 完整规格 + 完整迁移证据 + `允许形成迁移动能规格` |
| P12合法无前态 | `无前状态`，规格和迁移证据为空 |
| 合同/规则/身份/时间/请求非法、跨场景、来源非主体、时间不递增 | `入口拒绝` |
| P10/P12/P9材料缺失 | `未找到` |
| 同时间多前态或同整理身份异义材料 | `冲突` |
| P11不可比较、未注册、溢出或其它具名拒绝 | `不可比较` |
| 首末快照或任一provider截止不一致 | `版本漂移` |
| provider许可竞争 | `许可拒绝` |
| provider或规格分配失败 | `资源失败` |
| 坏成功载荷、关系/见证/摘要/键冲突或未知状态 | `内部不一致` |

除 `已形成` 外，`状态写入规格` 和 `迁移证据` 均为空、摘要为零。`已形成` 时十二个键、十七项事实、共同截止、迁移证据和摘要必须全部完整。

值编码或代次变化但 I64 材料相同只能进入等价成功，动态准入必须为禁止。三态、具名关系、等价和差异之间任何矛盾均为内部不一致。

## 10. 并发、生命周期与撤销边界

组合函数不持状态/比较/实例特征服务锁跨 provider 调用，不持 L1 写许可。每轮 `G0 -> P10 -> P12/P9 -> P11 -> G1 -> 纯值规格` 使用一个共同截止；并发写导致漂移时整轮丢弃并至多重试一次，不返回混代规格。

规格对象生成即弃、不可变、可复制；析构或丢弃不触发撤销，因为本叶零写入。资源失败、异常或后继拒绝只销毁内存规格，L1旧事实完全不变。后继最终发布失败、确认、撤销、发布后读回及事务参与者属于原子组合发布叶，不在本叶实现。
