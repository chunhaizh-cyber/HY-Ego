# INSTINCT-STAGE3-ACTIVE-SAFETY-FACT-GENERATION-COVERAGE 主动安全事实代次覆盖裁决详细设计 v0.1

日期：2026-08-30

设计身份：`INSTINCT-STAGE3-ACTIVE-SAFETY-FACT-GENERATION-COVERAGE`

## 1. 目标与边界

在现有永久变化账 provider 增加按事实代次范围的完整 `0/N` 读回，并在现有本能被动维护基础快照组合模块形成直接业务裁决。调用方给出上次已经消费的主动安全变化事实代次，组合器以本轮基础快照冻结的 `G0` 为包含终点，完整读取 `(旧水位,G0]`。

当前生产主动安全来源规则版本 1 的完整方法集合显式为空。因此本叶只有一项成功业务形状：事实代次范围完整、变化组显式为空，返回“没有尚未消费的主动安全变化”。任何非空变化组都返回来源未裁定；不得推进水位、解释 UTC、调用单秒规则、写 A/V、状态、动态或游标。

事实代次负责不重不漏的生产覆盖，UTC 只负责变化事件时间。二者不得互相推导。本叶不修改以下固定生产材料：

```text
值域 = 0..INT64_MAX
L = 2,767,011,611,056,432,742
H = 7,378,697,629,483,820,645
安全根定义版本 = 1
主动安全结算规则版本 = 1
```

## 2. 当前事实与复用裁决

- 4230 v0.20 已冻结按特征实例与事实代次范围读回、完整见证及登记边界。
- 6170 v0.8 已冻结事实代次水位是生产连续消费依据；当前规则 1 下非空组必须 fail-closed。
- `L2状态动态原子发布服务` 已有唯一账登记、全量账扫描、逐项完整性校验和 UTC 范围读回；新入口复用同一 private 全量扫描与验证，不建立第二账、第二索引或第二 owner。
- `本能主动安全UTC窗口裁决组合器` 已证明基础快照、来源规则、永久账和二次基础快照可在同一 G0 组合；新组合器复用相同依赖和状态映射，但不调用 UTC 入口。
- 现有维护游标 v1 尚未携带主动安全事实代次水位。本叶只闭合 provider 与直接裁决，不扩展游标或生产维护事务。

## 4. L2 事实代次范围 ABI

合同版本继续为 2。

```cpp
struct L2特征当前值变化事实代次组读取请求_v2 final {
    std::uint32_t 合同版本;
    L2结构请求头 请求头;
    L2特征实例身份 特征实例;
    std::uint64_t 排除起始事实代次;
    std::uint64_t 数量预算;
};
```

入口要求：共同头有效且 `G0!=0`；特征实例有效；排除起点非零且 `<=G0`；数量预算非零。读到账登记后，排除起点必须 `>=账登记事实代次`。

```cpp
struct L2特征当前值变化事实代次完整集合见证_v2 final {
    std::uint64_t 账登记事实代次;
    L2特征实例身份 特征实例;
    std::uint64_t 排除起始事实代次;
    std::uint64_t 包含结束事实代次;
    std::uint64_t 声明成员数;
    std::vector<L2特征当前值变化账身份_v2> 规范成员身份组;
    std::uint64_t G0;
};
```

成员按 `形成事实代次、账身份` 严格升序。包含结束事实代次必须等于 `G0`。完整谓词逐项验证请求、成员范围、顺序、数量、身份组和同一 G0。

```cpp
enum class L2特征当前值变化事实代次组读取状态_v2 : std::uint8_t {
    已读取 = 1,
    账未登记 = 2,
    入口拒绝 = 3,
    当前性漂移 = 4,
    覆盖边界不可用 = 5,
    数量预算不足 = 6,
    集合不闭合 = 7,
    引用冲突 = 8,
    资源失败 = 9,
    内部错误 = 10
};
```

结果字段固定为合同版本、状态、完整变化组、可选完整见证和本次正式读回截止。只有 `已读取 + 完整组 + 完整见证 + 截止=G0` 成功；全部非成功为空组、空见证、截止 0。

公开函数：

```cpp
L2特征当前值变化事实代次组读取结果_v2
L2状态动态原子发布服务::按特征实例与事实代次范围读取完整变化组_v2(
    const L2特征当前值变化事实代次组读取请求_v2&) const noexcept;
```

固定过程为：准入、G0 读前守卫、登记读回、全量账读取和完整性验证、登记边界验证、范围筛选、规范排序、预算、见证、G0 读后守卫。不得复制一套较弱的账校验算法；应抽取或复用现有 UTC 入口的 module-private 完整验证路径，使两个公开入口只改变筛选键和排序键。

## 5. 主动安全事实代次覆盖裁决 ABI

合同版本为 1。

```cpp
struct 本能主动安全事实代次覆盖裁决读取请求_v1 final {
    std::uint32_t 合同版本;
    本能被动维护基础快照读取请求_v1 基础快照请求;
    std::uint64_t 排除已消费变化事实代次;
    std::uint64_t 数量预算;
};

enum class 本能主动安全事实代次覆盖裁决_v1 : std::uint8_t {
    无尚未消费变化 = 1,
    存在尚未消费变化 = 2
};
```

版本 1 只允许成功返回 `无尚未消费变化`；第二枚举保留为未来新规则的强类型投影，不授权当前空来源规则产生成功。

```cpp
struct 本能主动安全事实代次覆盖裁决快照_v1 final {
    本能被动维护基础快照_v1 基础快照;
    主动安全结算来源规则事实_v1 来源规则;
    L2特征当前值变化事实代次组读取结果_v2 永久变化账完整组;
    std::uint64_t 排除已消费变化事实代次;
    std::uint64_t 包含结束变化事实代次;
    本能主动安全事实代次覆盖裁决_v1 裁决;
    std::uint64_t 本次正式读回截止;
};
```

完整谓词必须证明：基础快照完整；来源规则完整且等于定义绑定版本；当前只接受规则版本 1 的空来源方法组；事实代次组成功、特征实例等于安全根实例、范围为 `(请求起点,G0]`；组和见证均为 0 项；裁决恰为无尚未消费变化；所有截止相同。

读取状态固定为：`已读取、入口拒绝、定义未发布、当前值未设置、游标未建立、规则未发布、规则版本漂移、账未登记、覆盖边界不可用、当前性漂移、运行代次漂移、时间纪元漂移、时间源版本漂移、时间倒退、数量预算不足、集合不闭合、来源未裁定、引用冲突、材料不闭合、资源失败、内部错误`。只有已读取返回完整快照和 G0，其它状态空载荷、截止 0。

```cpp
class 本能主动安全事实代次覆盖裁决组合器 final {
public:
    本能主动安全事实代次覆盖裁决组合器(
        const 本能被动维护基础快照组合器&,
        const 安全根定义与当前值服务&,
        const L2状态动态原子发布服务&) noexcept;

    本能主动安全事实代次覆盖裁决读取结果_v1
    读取事实代次覆盖主动安全变化裁决_v1(
        const 本能主动安全事实代次覆盖裁决读取请求_v1&) const noexcept;
};
```

固定过程：第一次基础快照取得 G0；同 G0 读来源规则；同 G0 读事实代次范围；规则 1 下非空组返回来源未裁定、空组形成候选；第二次基础快照逐字段互证；完整谓词通过后返回已读取。

## 6. 失败与异常

- 起点早于登记代次：覆盖边界不可用；不得扩大成登记前合法空集。
- 起点等于 G0：允许完整空组；仍须执行全量账完整性和双守卫。
- 非空组：来源未裁定；不根据来源方法缺省、UTC、变化方向或当前 A 猜测。
- 下层账未登记、预算不足、集合不闭合、引用冲突和当前性漂移保持结构化映射。
- `bad_alloc/length_error` 映射资源失败；其它异常映射内部错误。
- 任一失败不得修改永久账、A/V、状态、动态、游标或规则定义。

## 7. 验证矩阵

- L2 请求坏合同、坏 G0、坏特征、零 / 大于 G0 起点、零预算；
- 登记边界：起点小于 / 等于 / 大于登记代次；
- 范围：`0/1/N`、起点排除、G0 包含、未来项不出现、规范排序、预算不足；
- 全集完整性：坏锚点载荷、重复身份、同特征同 G1 多账、参与者错 G1；
- 组合器：规则 1 空来源 + 事实组空返回已读取；非空返回来源未裁定；
- 两次基础快照之间事实推进、运行代次 / 纪元 / 时间源漂移；
- 现有 UTC 读回和 UTC 窗口裁决回归不变；
- Debug / Release 根工程、两份现有专项、仓库外 ABI consumer、strict 和精确差异检查；
- 安全根值域、L/H、定义版本、来源规则版本及生产初始化文件 blob 零变化。
