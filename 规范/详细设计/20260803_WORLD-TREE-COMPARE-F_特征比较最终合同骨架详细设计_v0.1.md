# WORLD-TREE-COMPARE-F 特征比较最终合同骨架详细设计 v0.1

日期：2026-08-03

设计身份：WORLD-TREE-COMPARE-F

创建侧代码复核基线：`0f7e2840498a984f2b16dc831d41f929fd40137d`

## 1. 目标、范围与完成边界

本叶子把4180 v0.2冻结的比较语义落成唯一 L2 C++ ABI，并以4201 v0.3允许的稳定 `未实现` 骨架进入代码。骨架只解除模块、DTO、完整签名、构造、工程登记、链接和合法消费者安全拒绝门禁；不读取注册、不执行算法、不返回比较成功、不写机器事实。

直接依据：0050、4020、4030、4050、4180 v0.2、4201 v0.3，以及 P1B 对“同一次同代次比较同时取得具名关系与差异材料”的提供者需求。后继 `WORLD-TREE-COMPARE-R` 必须原位替换函数体，不改本设计的模块、DTO、构造或签名。

## 3. 稳定枚举与辅助函数

```cpp
inline constexpr std::uint32_t 特征比较服务合同版本 = 1;
inline constexpr std::uint32_t 特征比较结果要求ABI版本 = 1;

enum class 特征比较用途 : std::uint8_t {
    未定义 = 0, 状态迁移 = 1, 目标判断 = 2,
    二次特征 = 3, 派生动态 = 4
};

enum class 特征比较算法族 : std::uint8_t {
    未定义 = 0,
    稳定身份相等 = 1,
    标量有序比较与安全差异 = 2,
    区间关系 = 3,
    向量逐分量差异 = 4,
    角度环形差 = 5,
    旋转或方向差 = 6,

    形状距离 = 9,

enum class 特征整数量化规则 : std::uint8_t {
    未定义 = 0, 精确无量化 = 1, 向零截断 = 2,
    向负无穷取整 = 3, 向正无穷取整 = 4,
    最近值并列向偶数 = 5
};

enum class 特征比较状态 : std::uint8_t {
    已比较 = 1, 未注册 = 2, 入口拒绝 = 3, 版本漂移 = 4,
```

结果要求只允许1至7；0和未知位入口拒绝。P1B 状态迁移固定一次请求 `具名关系|差异材料`，需要排序时再加 `排序三态`，不得拆成两次比较。

## 4. 请求、上下文与结果 DTO

```cpp
struct 特征比较请求身份 {
    std::uint64_t 命名域 = 0;
    std::uint64_t 键值 = 0;
    bool 完整() const noexcept { return 命名域 != 0 && 键值 != 0; }
    friend bool operator==(const 特征比较请求身份&,
        const 特征比较请求身份&) = default;
};

struct 特征比较上下文合同 {
    std::optional<节点稳定身份见证> 单位;
    std::uint32_t 维度 = 0;
    std::vector<节点稳定身份见证> 分量角色组;
    std::optional<节点稳定身份见证> 坐标或位姿合同;
    std::optional<std::uint64_t> 坐标或位姿版本;
    std::optional<节点稳定身份见证> 时间基准合同;
    std::optional<std::uint64_t> 时间基准版本;
    std::optional<std::int64_t> 周期;
};

struct 特征比较误差量化合同 {
    std::uint32_t 合同版本 = 0;
    std::optional<类型化值材料> 误差预算;
    std::optional<类型化值材料> 相等容差;
    特征边界包含方式 边界包含 = 特征边界包含方式::未定义;
    特征整数量化规则 量化规则 = 特征整数量化规则::未定义;
};

struct 特征比较输入 {
    类型合同稳定身份 类型合同身份;
    std::uint32_t 类型合同版本 = 0;
    类型化值记录稳定身份 值记录身份;

    特征比较上下文合同 上下文;

    std::uint32_t 合同版本 = 特征比较服务合同版本;
    特征比较请求身份 请求身份;
    节点稳定身份见证 特征定义;

    std::optional<std::uint32_t> 预期算法版本;
    节点稳定身份见证 左角色;
    节点稳定身份见证 右角色;
    特征比较输入 左;
    特征比较输入 右;
    特征比较结果要求 要求结果 = 特征比较结果要求::无;
};

struct 特征比较输入版本回执 {
    类型合同稳定身份 类型合同身份;
    std::uint32_t 类型合同版本 = 0;
    类型化值记录稳定身份 值记录身份;
    std::uint64_t 原始值版本 = 0;
};

struct 特征差异方向合同 {
    特征差异方向语义 语义 = 特征差异方向语义::未定义;

    类型合同稳定身份 结果类型合同身份;
    std::uint32_t 结果类型合同版本 = 0;
    类型化值材料 材料;
    std::optional<节点稳定身份见证> 单位;
    std::uint32_t 维度 = 0;
    std::vector<节点稳定身份见证> 分量角色组;
    特征差异方向合同 方向;

};

    特征比较状态 状态 = 特征比较状态::入口拒绝;
    特征比较拒绝原因 拒绝原因 = 特征比较拒绝原因::无;

    特征比较上下文合同 实际右上下文;
    特征比较误差量化合同 实际误差量化;
    特征比较输入版本回执 左输入回执;
    特征比较输入版本回执 右输入回执;
};
```

字段顺序、底层整数类型和枚举值稳定。左右角色只在请求顶层各出现一次。已比较时 `已形成结果` 必须逐位等于请求，要求项有值、未要求项为空；差异项必须 `可表示=true`。其它状态严格遵守4180 §5.1矩阵。

已比较时，左右输入回执必须逐字段等于本次已复核输入的类型合同身份/版本、值记录身份和原始值版本；实际左右上下文必须逐字段等于当前注册归一化后的左右上下文。实际误差量化合同版本必须非零，边界包含和量化规则不得为未定义。注册判定不适用时固定使用 `边界包含=不适用、量化规则=精确无量化`，误差预算和相等容差均为空；适用时两个 optional 是否有值及材料必须逐字段等于当前注册合同。

要求差异材料时，结果类型合同身份和版本必须完整，差异算法版本必须等于顶层算法版本，方向语义不得为未定义，`可表示` 必须为 true；单位、维度、分量角色和正方向角色必须逐字段等于当前注册形成的输出合同。任一不满足均不得构造已比较结果，映射为内部不一致并清空全部比较载荷。

## 5. 服务、骨架与异常

```cpp
class 特征比较业务服务 final {
public:
    explicit 特征比较业务服务(
        节点直接结构查询服务& 结构) noexcept
        : 结构_(结构) {}

    特征比较业务服务(const 特征比较业务服务&) = delete;
    特征比较业务服务& operator=(const 特征比较业务服务&) = delete;
    特征比较业务服务(特征比较业务服务&&) = delete;
    特征比较业务服务& operator=(特征比较业务服务&&) = delete;

    特征比较结果 比较特征(
        const 特征比较请求& 请求) const noexcept;

private:
    节点直接结构查询服务& 结构_;
};
```

骨架不读取请求、不调用 `结构_`，固定执行：

```cpp
static_assert(noexcept(特征比较结果{
    特征比较状态::未实现,
    特征比较拒绝原因::未实现,
    {}, 0, std::nullopt, 0,
    特征比较算法族::未定义, 0,
    特征比较结果要求::无,
    std::nullopt, std::nullopt, std::nullopt,
    {}, {}, {}, {}, {}}));

return 特征比较结果{
    特征比较状态::未实现,
    特征比较拒绝原因::未实现,
    {}, 0, std::nullopt, 0,
    特征比较算法族::未定义, 0,
    特征比较结果要求::无,
    std::nullopt, std::nullopt, std::nullopt,
    {}, {}, {}, {}, {}};
```

固定结果不回显请求，代次/注册/版本/输入回执为0或空，全部比较载荷为空。断言失败即编译失败，不得删除 `noexcept` 或以 catch-all 掩盖合同漂移。

## 6. v1 真实替换边界

v1 只允许注册4180 §6.1具名的内联材料算法子集；旋转或方向差、形状距离和时间序列变化不得形成当前有效注册。独立材料引用的SHA-256和字节数不是材料本体，禁止 SQL、文件或缓存回源。

COMPARE-R v1 通过同一 `节点直接结构查询服务&` 消费一次许可内的注册、类型合同和输入当前性投影，不新增构造参数。它另行冻结注册生命周期、L1投影、算法步骤、溢出/误差和异常矩阵。收到未注册保持未注册；P1B可映射为比较资源不可用，但比较层不得改写为资源失败。

## 7. 状态、消费者与零代码机械推演

- `未实现` 固定与拒绝原因20配对，所有载荷为空；合法消费者立即停止成功后继。
- `未注册` 可携带非零截止和输入版本；不得伪造当前注册。
- 入口拒绝、许可拒绝、资源失败、内部不一致均无部分比较载荷。
- 比较只读，零特征/状态/动态/二次特征/因果写入。
- 骨架调用顺序：进入 → 不读取请求 → 构造固定 prvalue → 返回。
- P1B 的关系与差异必须由未来一次真实调用同时返回，骨架不能解除该门禁。
