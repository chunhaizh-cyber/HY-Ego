## 1. 目标、直接操作和边界

本叶修改方法Vm附属初始必要条件的登记、结构保存与读取，不改变现实对象特征值。原因是合法的“参数1存在＝人类”被仅支持附属FT的登记器拒绝；目的是让相同正式概念在规格、声明、读取、筹办和模拟材料构造中保持同义。登记不是动作，不生成长期C/R、运行次数或真实效果。

依据：5350第3、6节；5360第2、3节；7165第2—5节及用户本窗口最新概念统一裁决。现行规格与实例、内容范围与当前取值、实例所属概念与分类上下位必须分别处理。不增本能名称专属分支，不改变D/T/M节点身份或领域owner。

本叶不实施类别枚举改为概念ABI，不建立新的存在/特征本体根，不移动需求/任务/方法分类，不改语言理解、不接通新本能模拟或服务业务链。上述只为后续路线；需求/任务/方法作为存在根直接下位的用户裁决保留，不能用本叶宣称已经落实。

## 3. 初始声明逻辑合同

本叶通用初始声明是非空AND条件组，参数序号非零，所指规格是存在参数。每项只允许下列一种形状，其他DTO字段均保持默认：

1. `参数序号＋存在概念节点`：该具体存在须符合指定正式存在概念。
2. `参数序号＋特征类型概念节点`：该存在须具有该正式FT；不自动要求准确当前值，不把子值域当FT。

禁止同一项同时填两字段；需要两种约束时分成两个AND项。禁止在该通用初始声明中混入角色、成员变量、值域、精确区间、二次特征、动态、引用内容、参数关系或场景限定。原格式1的具名完整声明保持原入口和合同，不混入本通用写入口。

合法请求在进入登记的形状核验及现有精确相等比较前规范化：按`(参数序号，项类别：存在在前/FT在后，概念稳定身份)`排序，仅去除完全相同的项；不合并参数位置、不按名称合并概念、不删除额外上位/下位约束。不把互非上下位认定为矛盾，多上位图可能存在交集；不得为此新建通用求交求解器。不能证明可构造时由既有消费者保留明确未支持/未能判定，不默认成功。

规格与声明均不原地改义。显式存在约束可以等于规格范围，也可进一步限定；与规格共同形成合取。规格限定仍须由现有参数绑定和执行复核生效，不因有效投影去重而取消。

## 4. 保存格式和兼容读取

采用新增**初始声明格式3**；不扩宽旧格式2以免将旧损坏数据解释成合法新结构：

| 格式 | 本叶处理 |
| --- | --- |
| 1 | 原专用形状、原读回及补齐入口不变；保持省略请求只读保留的例外。 |
| 2 | 仍严格只有FT项；原排序、所有权、字段数及概念核验不变。新纯FT声明继续写2。 |
| 3 | 至少一个纯存在项，可与FT项混合；新含存在声明写3。 |

格式3根字段为类型、格式、所属Vm、AND规则及有序子项引用；N项根恰为N＋4字段。每项恰五字段：类型、所属声明根、顺序、参数位置、存在概念/FT二选一。顺序从0连续，参数位置从1且必须合法；每项只有唯一根父引用。拒绝双概念、无概念、同字段多值、未知字段、伪序号、重复项、非规范顺序和共享声明子项。格式3纯FT材料拒绝，保持单一新写形状。

`读取初始必要条件`、`核验初始声明补齐`格式白名单、`读取方法信息`关联规格核验和执行结构闭包全部识别3。现存1/2零改写、零升级、零删除，不增加全库迁移；旧格式数据的损坏仍按工程错误处理。

读回DTO保存显式声明，**不把规格派生项写回原声明**。请求规范化只影响新请求及同义比较；旧1/2原义和固定规格不改变。允许精确重复或排列不同的同一声明复用；显式声明的增删及概念身份变更仍按现非空声明冲突规则，不把一般逻辑等价推理引入登记器。

## 5. 唯一物理位置与完整读写链

所有声明私有能力位于`领域/新_方法类.cpp`现匿名命名空间，不新建文件或公开ABI。将旧通用附属FT三个helper更名为通用概念版本；完整签名保留入出形状：

```cpp
bool 通用概念必要声明形状有效(const 新方法初始必要条件定义&);
bool 规范化通用概念必要声明(新方法初始必要条件定义&);
新方法操作状态 核验通用概念必要声明(
    const 新方法知识建立请求&, const 概念_存在类&,
    const 概念_特征类&, std::vector<基础联合节点快照>&);
void 追加通用概念必要声明(
    基础节点组追加请求&, 基础组内字段内容,
    const 新方法初始必要条件定义&);
```

规范化helper只接通用形状，失败返回false且不发布；在局部副本完成，不变更调用者输入。`确保本能方法登记`及`发布方法结构`的通用请求路径使用规范化后的局部请求进入后续验证、补齐候选、预期DTO和读回相等；同一事务链不得有的地方使用原请求、有的使用规范化请求。格式1专用入口不调用此规范化helper。

存在项保护读取目标存在概念及其正式定义，复用`读取普通存在概念定义保护`；同时保存规格存在范围原保护。FT项继续复用`读取特征概念定义保护`并核为类型根。错类别/非法引用/越界序号返回`参数规格不合法`；保护前提变化返回`结构不一致`或所属公开入口现有`定义前提已变化`映射；已确认为正式节点但读取损坏/缺完整保护不得当成业务不存在，走原工程异常链。不得以bool false、空参数或缺业务条件吞掉工程故障。

首次发布与空头补齐沿原原子片段、完整CAS保护、发布及读回链。补齐仍仅允许尚无C/R且对应声明空；已经非空的异义请求返回登记冲突，同请求其它待补项不部分发布。格式3不是绕过固定规格或既有知识的迁移通道。

必查调用群：`行为声明有效`、`读取方法信息`、`核验初始声明补齐/发布初始声明补齐`、`发布方法结构`初核/末核/写入/读回、`确保本能方法登记`、`读取方法执行结构闭包`、复制/克隆/组合及缺失引用保护。旧`通用附属FT必要声明形状有效`约277/1840/1971/2124/2970/3371/4939，以及核验约2991/3227/3342/4488/4942、写入约3018/3447必须全部替换，不留新3读取后被旧2判断再次拒绝。

`方法复制字段规格`现已覆盖存在字段，不扩schema；克隆和复制使用同一外部概念引用并保留格式3、声明根/子项内部重映射和owner，不能复制出第二概念或共享独占子项。完整闭包、缓存的DTO相等、保护重核必须包含新声明原内容，不能只比较方法编码。引用退出与物理删除仍按原图闭包处理，无新增清理行为。

## 6. 有效必要条件与消费者

`读取执行分支必要条件(M,B)`保留公开签名及DTO。按固定顺序组合：有序**存在规格**投影的纯存在项→显式初始声明→所选分支必要条件→原初始位置关系；按完整条件身份精确去重，保留所有额外条件，场景项沿原独立组汇合。无分支且B空也必须返回同样规则的有效视图；原有分支缺失、选错、前提变化状态不改。

FT规格只限定可选特征信息对象，不自动表示当前值必须存在。因此**不把FT规格投影成FT值域条件**；FT范围、材料/比较含义继续由现参数绑定核验及模拟defs直接消费。完整执行合同是“固定规格＋有效必要条件”，不是仅一个条件DTO。旧角色规格及专用格式1保持原行为，不为它们编造有序存在项。

本叶统一的是调用期有效条件视图，不增加“历史配对必须显式覆盖所有规格派生项”的新硬门，不回写旧C/R或补造条件知识。`配对分支来源有效`及其`条件涵盖必要项`保持原覆盖语义，不将规格投影机械加入历史配对准入；该链未与调用期视图完全统一，完成报告必须保留这一边界。

`模拟学习.服务.cpp`参数采集与`新_模拟世界类.cpp`隔离构造取消“只有有分支才读取有效声明”的局部门：所有受支持有序规格均从同一读入口取有效视图。保留前提变化、取消和未支持语义；不得把无分支忽略声明当作合法路径。存在范围用现通用构造，FT规格用现defs，不新增新本能名称判断。
