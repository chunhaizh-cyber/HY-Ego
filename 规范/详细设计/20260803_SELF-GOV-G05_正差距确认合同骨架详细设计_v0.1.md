# SELF-GOV-G05 正差距确认合同骨架详细设计 v0.1

日期：2026-08-03

## 1. 目标、范围与当前事实

本叶在既有 `海中鱼巣.领域.服务.需求` 中建立 `需求业务服务::确认当前正差距` 的最终公开签名、需求包装 DTO 与固定结构化 `未实现`。它只清理需求侧接口、编译和安全入口门控，不实现世界事实读取、比较注册、差距计算、需求准入或生产接线。

当前代码核对：

```text
服务.需求.ixx 已唯一拥有 需求业务服务、需求请求和需求包装结果。
需求业务服务 当前借用 需求任务方法数据操作 与 状态业务服务 两个引用依赖。
现有 判定目标状态达成 只处理已存在需求与状态等值，不支持无需求目标、注册比较或同代次世界快照。
节点稳定身份见证、类型合同稳定身份 已由 核心/节点直接结构合同.数据.h 唯一拥有。
COMPARE-F 详细设计已冻结完整 特征比较请求/结果 ABI，但其模块尚未进入正式代码；本叶必须等待该代码结果，不能复制或压缩比较类型。
世界结构、真实比较和完整快照成功能力尚未全部进入正式代码；不得写成当前可复用能力。
```

禁止复用旧 `需求服务.h`、旧线程根需求初始化、裸 I64 减法、SQL 查询或日志判断。

### 3.2 请求、载荷和结果

以下四个需求结构按给定顺序由 `海中鱼巣.领域.服务.需求` 唯一导出。`特征比较算法族` 和 `特征比较结果` 由 `海中鱼巣.领域.服务.特征比较` 唯一导出，本模块只 import 使用。

```cpp
struct 需求正差距请求身份 {
    std::uint64_t 命名域 = 0;
    std::uint64_t 键值 = 0;
};

struct 需求正差距请求 {
    std::uint32_t 合同版本 = 需求正差距合同版本;
    需求正差距请求身份 请求身份;
    节点稳定身份见证 自我;
    节点稳定身份见证 目标宿主;
    节点稳定身份见证 场景;
    节点稳定身份见证 目标特征;
    节点稳定身份见证 目标状态;
    类型合同稳定身份 目标状态类型合同;
    std::uint32_t 目标状态类型合同版本 = 0;
    节点稳定身份见证 世界根;
    std::uint64_t 事实截止代次 = 0;
    std::uint32_t 世界规则版本 = 0;
    std::optional<特征比较算法族> 预期算法族;
    std::optional<std::uint32_t> 预期比较合同版本;
    std::optional<std::uint32_t> 预期算法版本;
};

struct 需求正差距载荷 {
    节点稳定身份见证 目标状态;
    节点稳定身份见证 当前事实状态;
    特征比较结果 比较结果;
};

struct 需求正差距结果 {
    需求正差距状态 状态 = 需求正差距状态::未实现;
    需求正差距请求身份 请求身份;
    std::uint64_t 事实截止代次 = 0;
    std::optional<需求正差距载荷> 载荷;
    bool 形成内存权威发布 = false;
    bool 可重试 = false;
};
```

请求中的 `世界根 + 事实截止代次 + 世界规则版本` 共同标识本次允许读取的世界快照；不新增第二个快照身份。需求载荷直接保存完整 `特征比较结果`，包括拒绝原因、注册、算法族/版本、已形成结果、关系、差异、实际上下文、误差量化和左右输入版本回执；需求领域不得另建摘要或重新解释裸值。

本函数的比较用途固定为 `特征比较用途::目标判断`，不作为请求字段交给调用方选择。后继真实实现固定 `左材料=当前事实、右材料=目标状态`；三个预期字段只是上游漂移门禁，不能覆盖当前唯一注册、选择另一算法或交换左右角色。正差距必须由注册方向、具名关系和可表示差异共同裁决，不能只看裸差值符号。

### 3.3 最终函数

```cpp
需求正差距结果 确认当前正差距(
    const 需求正差距请求& 请求) const;
```

位置：`需求业务服务` 的公开读取/裁决函数区，插入在 `判定目标状态达成` 之前。现有构造、成员和依赖不变；函数不得新增重载、自由函数包装或第二模块所有权。

## 4. 骨架行为和最终状态矩阵

当前叶唯一函数体：

```cpp
return {};
```

默认构造精确产生：`未实现`、零请求身份、事实截止代次 0、空载荷、`形成内存权威发布=false`、`可重试=false`。函数不读取 `请求`，不调用任何依赖。函数签名严格沿用已移交目标身份，不额外增加异常说明符；固定函数体没有可抛表达式。

后继真实实现必须原位替换函数体，并满足以下外层状态矩阵；内层 `特征比较结果` 必须逐字段满足 4180 与 COMPARE-F，不能由需求层改写：

| 状态 | 事实截止 | 载荷 | 发布 | 可重试 | 后继 |
| --- | --- | --- | --- | --- | --- |
| 未实现 | 0 | 空 | false | false | 消费者保持待激活 |
| 已满足 | 非零 | 完整目标/当前事实；比较结果已比较且具名关系证明满足 | false | false | 不形成需求候选 |
| 存在可处理正差距 | 非零 | 完整目标/当前事实；比较结果同时含具名关系与可表示差异 | false | false | 可交 G06 重新准入 |
| 约束冲突、不可比较 | 非零 | 空或保留完整非成功比较结果，不得保留半成功载荷 | false | false | 结构化返回，不默认成功/失败 |
| 材料缺失 | 已读到权威事实时非零，否则 0 | 空 | false | true | 补齐材料后新请求 |
| 比较未注册 | 非零 | 完整目标/当前事实及 `未注册` 比较结果 | false | false | 形成具名比较能力缺口，不回退算法 |
| 版本漂移 | 非零 | 只在 COMPARE-F 允许时保留完整漂移比较结果 | false | true | 刷新快照后新请求 |
| 入口拒绝 | 0 | 空 | false | false | 修正请求 |
| 许可拒绝、资源失败 | 0 | 空 | false | true | 释放许可或资源恢复后新请求 |
| 内部不一致 | 0 | 空 | false | false | 停止依赖路径并交审计恢复 |

本叶只实现 `未实现` 行。其余行只冻结外层承载和无损边界；真实字段来源、读取与映射由后继实现设计闭合，不得由本叶执行者决定或提前编码。

## 7. 全分支事务与锁矩阵

本叶无事务、无许可、无锁、无 SQL、无日志和无回调。对任意输入只有固定返回，内存已发布代次、需求/任务/方法结构、关系、索引、持久证据和线程队列全部不变。后继真实实现仍必须全程只读，并要求调用方在进入前释放消息/队列锁。

## 8. 零代码机械推演

```text
先等待 COMPARE-F 结果把特征比较模块与完整类型发布到 main
-> 编译器进入 服务.需求.ixx
-> 由节点直接结构合同.数据.h 取得共享稳定身份类型
-> import 特征比较模块取得唯一完整比较类型
-> 在需求模块唯一导出需求包装 DTO 与状态
-> 需求业务服务新增一个 const 成员
-> 任何调用进入后执行单一 return {}
-> 默认结果为未实现/零代次/空载荷/零发布
-> 不触碰两个现有引用依赖
-> 既有需求任务方法分层自检实际调用并比较全字段
-> 调用前后结构数量相等
-> 只能形成 L0/L1 证据
```

机械推演未发现工程登记、生命周期、事务或错误传播选择留给执行者。COMPARE-F 未进入代码时 import 无法形成，因此该依赖不能由空函数绕过。

## 9. 验证矩阵、独立复核与完成边界

执行期必须验证：

- COMPARE-F 结果提交、模块和完整比较类型逐字段一致；
- 需求 DTO 枚举数值、字段顺序、默认值和完整成员函数指针类型的 `static_assert`；
- Debug/Release x64 Rebuild；双配置完整自检 exit 0；
- 专属调用确认 `未实现/0/nullopt/false/false` 与结构数量不变；
- AST/源码确认函数唯一、单一 return、项目内直接调用边除专属自检外为 0、被调函数为 0；
- `check_specs.py --strict` 与 `git diff --check`。

创建侧独立只读复核首次结论为 NOT PASS，发现自定义差距摘要有损且错误绕过 COMPARE-F、字段来源出现 G05 自循环；本版已经删除摘要、直接复用完整比较结果、建立真实类型依赖并修正来源。第二轮独立只读复核结论为 PASS：无损 ABI、真实依赖、字段来源、固定未实现机械语义和弱验收边界均闭合，没有遗留给本叶执行者决定的机器语义。具名目标业务图文件的写权由交互智能体在本轮明确移交，未取得其它目标业务图聚合写权。

允许声明：`编译接入通过`、`入口巡检通过`。

禁止声明：`局部可继续`、真实正差距已计算、G01—G06 完成、需求层闭合、自我治理闭环或服务验收通过。
