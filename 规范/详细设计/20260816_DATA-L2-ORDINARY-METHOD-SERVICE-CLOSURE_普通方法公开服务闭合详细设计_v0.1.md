# DATA-L2 普通方法公开服务闭合详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-ORDINARY-METHOD-SERVICE-CLOSURE`

## 1. 目标与完成边界

本设计在现有唯一 `L2方法结构服务` 和方法 owner 内一次闭合 `DATA-EXT-14` 当前要求的普通方法公开结构：完整公开 DTO、新增、新身份替换、退出、当前 / 历史完整读取，以及按完整结果规格读取当前候选身份组。现有 `L2方法结构聚合服务` 和普通应用 getter 原位复用，不建立第二方法服务、第二 owner、第二 DTO 解释或业务选择入口。

完成必须由生产代码外合法消费者经 `构造普通应用上下文(...) -> 取得L2方法结构聚合服务() -> 取得L2方法结构服务()` 完成一次公开新增、当前读、候选读、替换、历史读和退出读回。构建或头探针本身不能宣称 `DATA-EXT-14` 完成。

本设计不执行方法、不判断方法可用或好用、不选择候选、不创建任务 / 需求，不建立条件结果样本、运行账、学习晋级或跨进程恢复。

## 2. 当前事实与复用裁决

- `L2方法身份`、方法 owner、族身份来源、唯一方法登记根及其三入口已经发布。
- `L2普通方法结构.数据.h` 已有治理虚拟存在、条件、结果、动作入口、作用对象绑定、参数、禁止项、适用范围身份，以及内容 / 规格版本和稳定动作键。
- `L2方法结构服务` 已持有唯一方法 owner 写端口；`L2方法结构聚合服务` 与普通应用 getter 已装配同一实例。
- 5300 v0.6 已退出固定关系 23 和世界状态复用；方法生命周期改由方法 owner 的强类型治理记录承载。
- 当前缺少普通方法事实 DTO、完整 CRUD、候选读取和真实普通应用黑盒读回。

裁决：扩展现有两个生产头 / 模块和普通应用构造依赖，不新建模块。跨结构端点只经现有场景、特征和状态结构公开服务在同一非零事实截止验证；方法服务不得直达其它 owner 的 L1 事实。

## 3. 公开 DTO

在 `L2普通方法结构.数据.h` 增加以下强类型值：

```text
L2方法生命周期版本 { uint64_t 值 }
L2方法规格材料 { 非零角色, 非零顺序, L2原始值材料 值 }

L2方法作用对象绑定事实
  { 身份, 方法, 规格材料, 来源稳定编码, 生命周期 }
L2方法参数规格事实
  { 身份, 方法, 规格材料, 来源稳定编码, 生命周期 }
L2方法禁止项规格事实
  { 身份, 方法, 规格材料, 来源稳定编码, 生命周期 }
L2方法适用范围事实
  { 身份, 方法, 规格材料, 来源稳定编码, 生命周期 }

L2方法条件事实 / L2方法结果事实
  { 身份, 方法, 作用对象绑定, 场景, 特征定义,
    目标状态合同, 规格版本, 来源稳定编码, 生命周期 }

L2方法动作入口事实
  { 身份, 方法, 输入场景, 输出场景, 稳定动作键,
    规格版本, 来源稳定编码, 生命周期 }

L2方法生命周期事实
  { 方法, 生命周期版本, 发生时间I64, 来源稳定编码, 生命周期 }

L2普通方法事实
  { 方法, 身份来源, 治理虚拟存在, 内容版本, 规格版本,
    条件组, 结果组, 唯一动作入口, 作用对象绑定组,
    参数组, 禁止项组, 适用范围组, 生命周期事实 }
```

条件组和结果组均非空；动作入口恰一；其余规格组允许空。全部组按各自身份稳定编码严格升序、无重复。每个子事实的方法必须等于父方法，子身份跨组不可复用。规格材料的角色 / 顺序在同组内唯一，材料必须通过 `L2原始值材料`现有纯值完整性检查。发生时间只记录调用方提交的结构值，DATA 不解释时钟真实性。

`L2方法结果规格键` 精确由作用对象绑定、场景、特征定义、目标状态合同和规格版本组成。候选读取只做该键逐字段相等，不做目标等价、场景兼容、状态满足或候选优劣判断。

## 4. 请求、结果与函数

公开请求 / 结果：

```text
L2普通方法新增请求 / 结果
L2普通方法替换请求 / 结果
L2普通方法退出请求 / 结果
L2普通方法读取请求 / 结果
L2当前方法候选读取请求 / 结果
```

公开函数固定为：

```cpp
L2普通方法写入结果 新增普通方法(const L2普通方法新增请求&);
L2普通方法替换结果 替换普通方法(const L2普通方法替换请求&);
L2普通方法退出结果 退出普通方法(const L2普通方法退出请求&);
L2普通方法读取结果 读取普通方法(const L2普通方法读取请求&) const;
L2当前方法候选读取结果 按结果规格读取当前方法候选(
    const L2当前方法候选读取请求&) const;
```

新增请求携带完整事实材料、非零期望代次和幂等身份。替换请求携带旧方法身份、旧内容 / 规格 / 生命周期版本及完整新材料；成功建立全新方法身份并在同一方法 owner 事务退出旧方法全部当前事实。退出请求携带方法身份和三个版本见证并退出完整当前结构。当前 / 历史读取都必须使用非零当前守卫；历史另带非零历史截止。

同幂等身份、同完整请求返回首次原结果；同键异义返回 `幂等冲突`。替换绝不原地改写旧方法；退出保留全部历史。发布未知只允许原请求重放。

候选请求携带完整结果规格键、非零事实守卫和两个非零预算：最大扫描结果事实数、最大候选方法数。服务使用方法 owner 已登记的结果规格键属性类型调用 L1 按 owner / 属性类型当前值组读取，在同一守卫筛选精确键，再按方法身份升序去重并逐项权威读回完整当前方法。空候选合法成功；任一预算不足零候选返回；索引 / 属性命中不得代替完整方法读回。

## 5. 内部承载与依赖

普通方法及全部子事实使用现有方法 owner。服务私有登记普通方法所需的关系类型、属性类型和结构锚点；登记只形成内部定位，不进入公开 DTO。一次新增写集原子建立方法节点、族归属、治理虚拟存在、全部子节点 / 关系 / 值和生命周期事实。替换原子建立完整新结构并退出完整旧结构；退出原子退出全部本 owner 当前事实。

`L2方法结构服务` 构造增加同一 L1 运行包中的 `const L2场景结构服务&`、`const L2特征结构服务&` 和 `const L2状态结构服务&`。新增 / 替换前在同一期望事实代次分别验证全部场景、特征定义和目标状态合同；缺失 / 已退出 / 漂移分账，成功后方法 owner 提交仍用同一守卫。服务只保存 const 引用，不取得其它 owner 写权。

普通应用现有方法 owner 建立顺序不变，只在构造方法服务时传入已经装配的三个服务。聚合类和 getter ABI 不变。

## 6. 状态映射与失败形状

- 请求版本、零守卫、零幂等、空条件 / 结果、坏排序、重复角色 / 顺序、坏材料或零来源：`入口拒绝`，零写。
- 跨结构端点未找到 / 已退出：保持对应结构状态；同一完整方法内出现互相矛盾的端点材料：`引用冲突`。
- 守卫变化：`事实代次漂移`，零写 / 零载荷。
- 同幂等异完整请求：`幂等冲突`。
- 被当前外部引用的普通方法退出：L1 `引用冲突`原样映射。
- 预算不足：`数量预算不足`，候选组为空。
- 发布后缺项、子事实错方法、混代、重复当前生命周期、读回与首次请求不一致：`内部不一致`。
- `bad_alloc` / `length_error`：`资源失败`；其它异常：`内部不一致`。

所有非成功结果不得携带可消费普通方法、退出方法、候选身份或变更代次。

## 7. 验证矩阵

生产外专项必须经普通应用公开 getter 覆盖：新增与逐字段同截止读回；精确重复 / 同键异义；空规格组；坏条件 / 结果 / 动作；端点缺失 / 错类型；新身份替换与旧历史；退出当前不可见和历史仍可读；外部引用保护；内容 / 规格 / 生命周期版本分账；精确候选、空候选、非匹配排除、稳定排序、扫描预算和候选预算；非权威命中后完整权威读回；并发守卫漂移。

另运行根工程 x64 Debug / Release fresh Rebuild、strict、XML、UTF-8、diff、生产零测试痕迹和精确白名单检查。资源耗尽、发布结果未知、跨进程恢复、真实方法执行、任务选择和 BIZ 消费保持 `NOT_RUN`。
