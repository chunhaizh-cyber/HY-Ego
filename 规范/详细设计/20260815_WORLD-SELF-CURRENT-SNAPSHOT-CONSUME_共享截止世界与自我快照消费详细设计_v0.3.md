# 共享截止世界与自我快照消费详细设计 v0.3

日期：2026-08-17

计划身份：`WORLD-SELF-CURRENT-SNAPSHOT-CONSUME`

替代关系：同身份 v0.3 替代 v0.2；v0.2 保留为历史证据，不得恢复执行。

## 1. 目标与完成边界

实现 `BIZ-L3-002-02-01`：根据父级冻结的一个非零共享事实截止，经普通应用同一 `L2结构聚合服务`取得场景与存在服务，依次读取现实世界整树、自我单例角色、完整自我存在、当前场景成员反向关系以及内部世界宿主正反向关系。全部结果截止必须等于请求截止，全部身份、关系和拓扑逐字段一致后才返回完整值式快照。

本叶只读，零 DATA 写、零 BIZ 缓存、零默认补造。它不实现共享截止读取函数，不读取安全、服务、需求、任务、方法或线程事实，不持有普通应用上下文，也不开启自我治理运行门。

完成只证明本叶 provider 能按一个共享截止形成世界—自我快照。父级 `G0/G1` 闭合、SELF-FORM 实际结果复制、普通应用装配、自我线程接线和集成验收保持 `NOT_RUN`。

## 2. 正式依据、当前事实与本次裁决

正式依据为 0050、4015、4030、4190、4200、4230、6180、7130、CODE-FILE-01，以及 v0.2 的 DTO、调用顺序和三件执行 WIP。设计基线为 `main == origin/main == 70e98efc2ee56a12c39dc3a9334b82f6f98b4df7`，创建侧验证前不改变代码。

L1 当前非阻塞读取在 `std::try_to_lock` 未取得共享锁时返回 `许可拒绝`，没有已发布事实截止可供回显；写入代次只在独占锁内候选交换后发布。锁竞争本身不能证明已发布且不同于请求 `G0` 的 `G1`，不得把请求守卫、预留代次或进行中写入称为事实漂移。

因此本版撤销 v0.2 所要求的 DATA “锁竞争必须返回实际非零事实代次漂移”前置方案，也不建立原子代次镜像、第二观察源、等待或重试。DATA 保持公开 `L2结构状态::许可拒绝` 和零载荷；只有 DATA 明确返回事实代次漂移，或锁内实际观察到已发布 `G1 != G0`，才映射当前性漂移。

`映射事实代次探测失败` 未显式传播 L1 许可拒绝的分支登记为后续 DATA 风险与验证观察点。本版不修改 DATA 代码，不把该风险伪装成漂移修复；若该分支实际折成 DATA 内部不一致，必须另立提供者修订。

## 3. 基础数据消费合同

本叶只复用 `计划/数据服务最终需求清单.md v0.4` 的 DATA-EXT-01、02、07。

| 业务目的 | 公开服务与操作 | 输入 | 成功结果 | 非成功 |
| --- | --- | --- | --- | --- |
| 取得同实例服务 | `L2结构聚合服务::取得L2场景结构服务()`、`取得L2存在结构服务()` const getter | 构造注入的同一聚合服务 | 两个 const 服务引用 | 装配失败不在本函数补建 |
| 读取现实世界整树 | `L2场景结构服务::读取场景树` | 当前类别、现实世界树、同一非零截止 | 完整树、根、场景、父子、成员、宿主和相同截止 | 未找到/已退役为材料缺失；漂移、许可和其它状态分账 |
| 读取项目唯一自我 | `L2存在结构服务::读取存在单例角色`、`读取完整存在` | 自我角色键、自我存在、同一非零截止 | 角色关系、身份来源、完整活动存在和相同截止 | 未绑定/未找到/已退出为材料缺失 |
| 互证当前位置 | `L2场景结构服务::读取存在当前场景成员引用` | 自我存在、同一非零截止 | 稳定排序当前成员反向组 | 空组材料缺失；多项或端点矛盾内部不一致 |
| 互证内部世界宿主 | `读取场景宿主存在关系`、`读取存在当前宿主场景` | 内部世界场景、自我存在、同一非零截止 | 同一宿主关系的正反向值式事实 | 任一缺失为材料缺失；复义或不等内部不一致 |

所有请求头的 `期望事实代次`都使用同一个非零截止。BIZ 不直达 L1，不以 `期望事实代次=0`读取单对象，也不读取 owner 身份或发布见证 token。

## 5. 固定读取与互证顺序

```text
校验合同、身份、关系编码、范围版本和非零共享截止
-> 取得同实例场景 / 存在服务
-> 以共享截止读取现实世界整树
-> 以共享截止读取项目唯一自我角色
-> 以共享截止读取完整自我存在
-> 以共享截止反向读取自我当前场景成员组
-> 以共享截止正向读取内部世界宿主
-> 以共享截止反向读取自我当前宿主场景
-> 复核全部结构化状态、载荷和结果截止
-> 逐字段互证
-> 局部完整候选一次构造并返回
```

全部读取结果截止必须等于请求截止；任一非成功立即收束，禁止把旧结果与新结果拼装。

## 6. 状态映射与失败守恒

| DATA / 请求情况 | BIZ 状态 | 守恒 |
| --- | --- | --- |
| 坏合同、零截止、零身份或非法关系编码 | 请求拒绝 | 零 DATA 调用或首个可判定点停止；零快照 |
| 必需对象未找到 / 已退出、成员组为空 | 材料缺失 | 不用默认值、历史值或缓存补齐 |
| DATA 明确返回事实代次漂移 | 当前性漂移 | 父级按新 G0 重新开始整轮；BIZ 不猜测、不重分类 |
| DATA 明确返回 `L2结构状态::许可拒绝`，包括锁竞争且无观察截止 | 提供者拒绝 | 零快照；不把 Gobs、G0 或未发布代次称为漂移 |
| 固定合法请求被入口拒绝、引用冲突或预算拒绝 | 提供者拒绝 | 零快照，不降级为空 |
| 任一资源失败 | 资源失败 | 零快照；本函数不等待、不自动重试 |
| DATA 内部不一致、坏成功形状、错截止、复义、拓扑或关系矛盾 | 内部不一致 | 零快照；不得因截止、时序或日志推测并发 |

本函数无可变已发布值和幂等账。异常捕获中 `std::bad_alloc`、`std::length_error`映射资源失败，其它异常映射内部不一致。

## 7. 并发与一致性矩阵

并发专项允许且必须逐项区分以下结果：

| 并发观察 | DATA 公开结果 | BIZ 结果 | 载荷 / 控制 |
| --- | --- | --- | --- |
| 六项读取均按 G0 成功且逐字段一致 | 已读取 | 已形成 | 返回完整快照 |
| 锁内实际观察到已发布 G1 且 `G1 != G0`，或 DATA 明确漂移 | 事实代次漂移 | 当前性漂移 | 零快照，调用方可按新 G0 重新发起 |
| `try_to_lock` 竞争、无可证明不同已发布截止 | 许可拒绝 | 提供者拒绝 | 零快照；本函数不等待、不重试 |
| 坏形状或真实结构矛盾 | 内部不一致 | 内部不一致 | 零快照，停止依赖路径 |

BIZ 不取得仓库、锁或事务，不建立截止启发式，不把 `Gobs == G0`、零观察截止或日志文本改写为漂移。并发矩阵中的三类正常结果是“已形成 / 当前性漂移 / 提供者拒绝”；其它非成功仍按公开状态独立分账。
