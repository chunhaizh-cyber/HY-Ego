# LANGUAGE-INPUT-S02-GRAPH-NARROW 已知上下位图候选收窄详细设计

日期：2026-10-16。版本：v0.1。代码起点：`39d53625b32f8a648e2ec0132d30d171b16f4d88`。本文件是待集成设计，不证明代码已经实现。

## 1. 目标与权威

本叶是在**现行旧预算 ABI 可以完整枚举的请求范围内**增加 S02 图消歧的增量能力，不宣称已完成 0050 §3.2 的全范围读取迁移。本叶只修改已发布的 S02 `C1 是 一种 C2` 概念上下位陈述解释：按词条召回全部当前名称关系，先以句型的概念角色类别形成整句候选；若出现多个不同的概念语义，再利用同类别概念图的**已有严格上下位路径**收窄。无图路径命中时保留全部全局候选；仍有多个解释时返回候选组给后续交互消歧。图关系只用于解释本次语句，不证明这句陈述为真，不发表概念边，不创建新概念或实例。

用户本轮已裁决检索顺序和结果边界：全局多候选才按句型缩小范围；C1 多义时从已知 C2 向下找，C2 多义时从已知 C1 向上找；仍多解则交互场景处理。实现统一从每个 C1 沿直接上位边求严格祖先，与 C2 候选求交，等价覆盖上述两个方向及两边均多义的情况。全局唯一时不以图中尚无边否定新关系主张；全局多义但图中零路径时同样不造概念、不删候选。

依据：[0050](../0050_项目通用机器逻辑与禁止性规则总纲_20260721.md) §3.2、[2210](../2210_根规范_概念名称关系.md) §4、[2220](../2220_根规范_概念空间.md) §3、[4240](../4240_子规范_语言词条与概念空间纯结构统一合同.md) §5.2、[7200](../7200_子规范_词条概念候选与上下文消歧.md) §2、[7240](../7240_子规范_自然语言双向转换与组织规则.md) §4、[7250](../7250_子规范_最小汉语知识与语言学习.md) S02。0050 是上级规范：7240 与现有 S02 中的底层读取额度只作旧 ABI 迁移识别；本叶不新增图读取额度，也不能把额度、资源失败或未读完当作“没有路径”。

## 3. 语义和算法

令 `G` 为当前 S02 全量名称召回、规则匹配、角色类别匹配及既有同 FT 根核验之后的**整句候选组**；语义键为 `(类别,C1,C2)`，名称关系与规则身份仍留在每个候选中。相同语义键的不同名称关系不是另一词义，既有多规则判定保持独立。

| 前提 | 图评估 | 返回的整句候选 |
| --- | --- | --- |
| `G` 的语义键数为 0 或 1 | 不做图消歧 | 沿用现有零／唯一边界；唯一即使无边仍是可理解的新关系主张 |
| 语义键数大于 1；至少一个键存在严格 `C1→…→C2` 路径 | 必须评估**全部**相容语义键，不能见首项即停 | 仅保留图支持的键及其全部名称／规则候选 |
| 语义键数大于 1；完整图检索后零路径 | 已知图尚不支持任一解释 | 原样保留 `G`，返回多义或原多规则 |
| 图材料无法完整读回或比较技术失败 | 不得解释成零路径 | 清空依赖完整性的候选，返回具名非成功 |

路径为同类别的严格直接边传递闭包，长度至少 1；`C1==C2` 不算图支持，`共同上位` 不算上下位。存在类别对每个不同 C1 沿 `上位概念组` 向上读至顶层，逐节点完整读回，保留多父分支，用活动路径识别自环／环，用已读缓存去重复读；任何无效编码、父节点非正式存在概念、反向直接边不一致或环按内部不一致处理，不把该分支当空。遍历的全部节点值式材料写入调用期私有快照，并以 C2 集合判断是否到达。特征类别复用已经针对全部同根候选对取得的 `单特征概念关系结果`；仅 `右为上位` 是严格 C1 下位于 C2，其它合法比较为图不支持，同 FT 根检查仍先执行。

先按现有 `最大组合候选数` 旧 ABI 检查当前全局组合；不得在其溢出时仅形成前缀候选或以图收窄绕过未完成的全局召回。图遍历不另设深度、节点数或步数业务上限；按 0050 §3.2 完成该句全量候选所需的完整图范围，资源不能完成则非成功且零候选，不返回局部“唯一”。此叶不迁移已有 S02/知识／名称组合读取的旧预算 ABI；后继另作完整读取合同迁移。

筛后按现有稳定顺序排序。若匹配的不同规则身份超过一项，保持 `多规则待解`；否则按筛后不同语义键数返回 `已形成唯一含义` 或 `概念多义待解`。返回候选仍携原文位置、名称关系及知识节点；本次消歧不回写词条名称，也不提前形成互动问题或实际上下位关系。

## 4. 函数、材料、错误与读回合同

唯一代码所有者为 DATA 外 `海中鱼巣/业务/解释.基础语言.cpp`。公开 `解释单句概念上下位`、`生成可唯一回读的概念上下位表达`、S09 和总分派的签名、DTO、枚举数值、调用点均不变；新逻辑使用其现有服务参数。新增的函数仅为该 cpp 匿名命名空间内的最小私有辅助：

```cpp
S02状态 读取S02存在严格上位闭包(
    稳定编码 起点, const 概念_存在类& 存在概念服务,
    std::map<稳定编码, 存在概念信息>& 已读图节点,
    std::set<稳定编码>& 严格上位);
```

它是只读业务辅助，自起点完整遍历并填充严格上位集合；对同一调用内另一 C1 可复用 `已读图节点`，但每个起点仍正确计算自己的闭包。无公共声明、无工程登记、无锁持有跨公开调用；诊断责任为`向上送出`，不能记录一次业务未命中为错误。若局部容器分配无法完成，须经既有工程诊断／资源失败控制链中止本次解释，返回 `工程未完成` 且零候选；不得捕获后当空集合。当前 `获取存在概念` 只有 `optional`：遍历中已由正式边引用的父节点返回空映射 `引用不可读`，不是无上位。提供者内部不可恢复异常按其工程终止链处理。特征比较返回 `资源失败`／`读取接口未装配` 按现有 `核验S02同根` 映射 `工程未完成`；已完成但结构不完整映射 `内部不一致`。

修改 `S02读取快照`：增添按节点稳定编码排序的存在图节点读回组；`读取S02一次` 先形成原全局组、必要时完整图收窄，然后定最终状态；`S02快照相同` 比较新增图节点全组、原名称／知识／特征比较和最终候选。初次与末次任何必要材料不一致，沿现有 `解释单句概念上下位` 的 `引用不可读` 失败和空候选收口；不宣称跨服务原子快照或 ABA 不可能发生。图读取失败早于双次读回时，按原错误直接返回零候选。

S09 通过当前 `映射S09子状态` 传播 S02 的 `引用不可读/工程未完成/内部不一致`，不能在子结果为空时组装“吗”；候选成功时只复用筛后的完整 S02 候选。总分派保留 S02/S09 各自分支载荷并将该类非成功判为`分支未完成`。S02 可逆表达继续从实际生成文字调用同一更新后的解释函数；图收窄后若唯一候选并与生成的两个概念、两个名称关系、知识节点及位置逐项一致，才返回 `已生成且可唯一回读`；多义或多规则仍返回 `回读语义未闭合` 且无可用表达。普通 `生成基础语言表达` 仍只负责生成，不冒称发送、理解或事实采纳。
