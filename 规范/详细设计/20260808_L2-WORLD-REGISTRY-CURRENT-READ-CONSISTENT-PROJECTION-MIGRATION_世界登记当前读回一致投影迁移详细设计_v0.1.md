## 1. 目标、完成边界与最早叶裁决

把 `世界登记服务::按登记读取权威事实(const 世界结构登记&) const` 从“事实代次首读 + 五次节点读取 + 属性读取 + 值读取 + 事实代次末读”的多次许可拼接，迁移为一次 `L1事实基座服务::尝试读取中性一致当前投影`。世界登记服务继续解释五个登记节点和世界根场景标记的 L2 业务形状；L1 只在一次共享 `try-lock` 许可内按指定事实代次返回中性当前投影。

本叶保持下列现有公开合同不变：

- `世界登记合同版本 = 3`、`世界登记规则版本 = 1`；
- `世界结构登记`、`世界登记建立请求`、`世界登记结果` 的字段、默认值和全等；
- `世界登记状态` 的十个稳定枚举数值；
- `世界登记服务` 构造、`建立空世界`、`读取当前登记` 的公开签名和锁所有权；
- 世界登记 `0x01` 中性幂等域、固定五节点 + 一值 + 一槽写集及其提交路径。

本叶只改一个私有读回根，不改写入口、DTO、启动、运行期上下文或生产调用者。完成条件是该根只经新一致投影一次完整尝试、必要时按回显实际代次完整重试一次，严格重建现有世界登记业务不变量，并由现有生产运行期路径自然消费。它不迁移方法登记根或其它 L2—L5 消费者。

候选裁决：`服务.L1方法登记根当前读取.ixx` 的完整快照误用虽然更孤立，但当前没有生产调用点；单独迁移不能在本叶形成真实消费者使用证据。世界登记服务已经由正式生产会话建立、由 `运行期上下文::完整` 与多个公开读回根消费，只需修改一个生产服务文件，是当前最早、最窄、可独立施工且能自然运行的真实消费者叶。

```cpp
世界登记结果 世界登记服务::按登记读取权威事实(
```

输入 `登记` 由世界登记服务的值式定位缓存拥有；函数不修改缓存。L1 仍唯一拥有事实代次、共享许可和当前事实，世界登记服务唯一拥有五节点与场景标记的业务解释。函数返回调用方拥有的 `世界登记结果`；所有非成功必须空登记。


## 5. 唯一控制流与重试边界

1. 先调用 `世界结构登记完整`；失败返回 `内部不一致`、空登记，零 L1 调用。
2. 第一次期望代次固定为 `登记.已验证事实代次`。该字段是最后一次已验证截止，不是当前权威；只用作一次精确读取请求。
3. 调用 `尝试读取中性一致当前投影` 一次。
4. 若第一次返回 `事实代次漂移`，必须同时满足合同版本正确、回显期望等于第一次期望、`读取事实代次` 非零、六结果组全空；以该实际代次重建完整请求并只重试一次。
5. 第二次仍为事实代次漂移时，要求同样的顶层失败形状，返回 `世界登记状态::事实代次漂移`。不得第三次重试、循环、等待、sleep 或改用旧读取入口。
6. 任一尝试返回许可拒绝、资源失败、入口拒绝、内部不一致或坏失败形状时立即按第 7 节收口；只有第一次的合法事实代次漂移允许重试。
7. 成功只接受合同版本正确、期望代次回显精确、读取代次等于期望且非零、六组长度精确为 `5/0/0/1/0/0` 的完整结果；随后执行第 6 节业务验证。
8. 成功后复制输入登记，只把 `已验证事实代次` 更新为本次 `读取事实代次`，返回 `已读取 + 完整登记`。

一次完整重试是 4015 允许的混代收敛边界，不是许可竞争重试。许可拒绝始终立即返回。

## 6. 成功结果的业务形状验证

### 6.1 五节点

五个节点结果必须与请求同序，逐项满足：

- 查询编码精确等于对应登记编码；
- 项目状态为 `成功` 且事实存在；
- 事实编码回显一致、未退出；
- 第 2 项场景标记属性类型节点种类为 `属性类型`，表示为 `I64`；其余四项种类为 `普通` 且无属性类型表示；
- 五项创建事实代次共同、非零且不晚于读取代次；
- 前四项当前属性为空；世界根当前属性恰一项。

任一项目未找到、已退出、种类不匹配、事实缺失或字段矛盾均表示已保存登记无法与权威当前事实互证，返回 `内部不一致`，不得降级为 `登记未加载`。

### 6.2 世界根属性值投影

唯一属性值结果必须满足：

- 节点为 `登记.世界根场景`，属性类型为 `登记.场景标记属性类型`；
- 项目状态为 `成功` 且投影存在；
- 世界根唯一当前属性槽、投影属性槽逐字段相等，槽绑定上述属性类型和投影当前值编码；
- 当前值事实编码等于槽中当前值，所属节点为世界根，属性类型节点为场景标记类型；
- 来源节点为 `登记.服务身份`；
- 创建事实代次等于五节点共同创建代次且不晚于读取代次，未退出；
- 材料强类型为 `std::int64_t` 且值精确为 `1`。

属性未设置、投影缺失、额外根属性、悬空值或任一绑定矛盾均返回 `内部不一致`。

### 6.3 空组与坏成功

关系、值、源关系组、目标关系组必须全部为空。顶层成功但合同、代次、长度、顺序、状态或业务形状任一矛盾属于坏成功，返回 `内部不一致`；不得挑选部分项目、重新排序、扫描补齐或返回部分登记。

## 7. 顶层状态映射、并发与生命周期

| 一致投影结果 | 世界登记结果 |
| --- | --- |
| 成功且第 6 节全部成立 | `已读取` + 更新截止后的完整登记 |
| 第一次合法事实代次漂移 | 只按回显实际代次完整重试一次 |
| 第二次合法事实代次漂移 | `事实代次漂移` + 空登记 |
| 许可拒绝 | `许可拒绝` + 空登记；零等待零重试 |
| 资源失败 | `资源失败` + 空登记 |
| 入口拒绝、内部不一致、顶层失败形状矛盾 | `内部不一致` + 空登记 |
| 顶层成功但任一项目或业务字段矛盾 | `内部不一致` + 空登记 |

`std::bad_alloc` 映射 `资源失败`，其它未知异常映射 `内部不一致`。服务互斥锁继续保护登记缓存；本叶不改变其阻塞语义。L1 的共享 try-lock 只在每次一致投影内部存续，不泄漏给 L2。读回失败不修改缓存、不补写、不恢复、不换登记编码。
