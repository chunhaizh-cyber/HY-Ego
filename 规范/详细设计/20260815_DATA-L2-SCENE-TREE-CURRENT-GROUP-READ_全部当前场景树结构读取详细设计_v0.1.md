# DATA-L2 全部当前场景树结构读取详细设计

日期：2026-08-15  
版本：v0.1  
身份：`DATA-L2-SCENE-TREE-CURRENT-GROUP-READ`

## 1. 目标与边界

本设计补齐 `计划/数据服务最终需求清单.md` 中 `DATA-EXT-01` 的一个独立缺口：调用方尚不知道任一树身份时，可以经唯一 `L2场景结构服务` 原子读取全部当前场景树；当前没有树时返回合法成功空组。

本叶只增加读取能力，不创建、替换或退出场景、树、关系和值，不新增 owner、仓库、聚合、缓存或第二写入口。它不实现独立父关系退出、场景业务解释、世界选择、自我初始化或其它 `DATA-EXT` 项。

## 2. 当前事实与复用裁决

当前实现已经具备：

- 场景 owner 下不可变的场景树登记锚点、根标记关系类型和树归属关系类型；
- `建立场景树根`，其根场景身份同时是 `L2场景树身份`；
- `读取场景树`，可在非零事实代次守卫下返回一棵完整当前树；
- `L1事实基座服务::尝试读取所有者范围一致当前投影`，其中零守卫可在同一次共享许可内选择最新当前截止，并按目标端点与关系类型枚举全部当前关系。

因此本叶不扩展 DATA-L1。根标记关系的目标固定为树登记锚点，按该锚点和根标记关系类型做一次目标关系组投影即可取得当前树身份闭集；随后以选中的同一非零截止调用现有单树完整读取。

## 3. 公开值类型

在 `海中鱼巣/领域/L2场景结构.数据.h` 增加：

```cpp
struct L2当前场景树组读取请求 final {
    L2结构请求头 请求头;
    friend bool operator==(const L2当前场景树组读取请求&,
        const L2当前场景树组读取请求&) = default;
};

struct L2当前场景树组读取结果 final {
    L2结构结果头 结果头;
    std::vector<L2场景树事实> 场景树组;
    bool 成功() const noexcept;
    friend bool operator==(const L2当前场景树组读取结果&,
        const L2当前场景树组读取结果&) = default;
};
```

并增加纯值 helper：

```cpp
bool L2当前场景树组读取请求有效(
    const L2当前场景树组读取请求&) noexcept;
```

请求只要求合同版本有效。`期望事实代次=0` 表示由本入口在调用时原子选择最新当前截止；非零表示乐观当前守卫。该零守卫语义只属于此具名“全部当前组”入口，不改变单树和写请求的非零守卫规则。

`成功()` 的完整谓词为：

1. 状态严格为 `已读取`；
2. 事实截止非零，变更事实代次为空；
3. 空组合法；
4. 非空时每棵树都满足 `L2场景树事实完整`，其 `事实截止代次` 等于结果截止；
5. 场景树按 `树.值` 严格升序，树身份互异；
6. 不同树的场景身份集合互不重叠。

任一非成功状态必须返回空组且无变更事实代次。

## 4. 公开服务 ABI

在现有 `L2场景结构服务` 原位增加唯一入口：

```cpp
L2当前场景树组读取结果 读取全部当前场景树(
    const L2当前场景树组读取请求& 请求) const;
```

普通应用和 `L2结构聚合服务` 已经返回同一场景服务实例，不增加 getter 或转发函数。BIZ 仍通过现有聚合同实例引用调用本入口。

## 5. 原子读取过程

实现顺序固定为：

1. 校验请求；坏合同返回 `入口拒绝`、空组、零变更。
2. 在 `场景树结构登记锁_` 下复制已有不可变树结构定位；未建立登记返回 `入口拒绝`，不能把服务未装配伪装成“零棵树”。
3. 形成一次 L1 一致当前投影：
   - 期望代次原样使用请求守卫；
   - 读取场景 owner、树登记锚点、根标记关系类型；
   - 读取 `{目标=树登记锚点, 关系类型=根标记关系类型}` 的目标关系组。
4. L1 零守卫成功返回的 `读取事实代次` 是本次唯一截止；非零守卫成功时读取代次必须严格等于守卫。漂移、资源失败和其它失败按现有映射结构化返回。
5. 对每条根标记逐项验证：关系和根节点均属于场景 owner、当前未退出；关系方向、类型、固定角色、端点和创建代次正确；根节点为普通节点且不是属性类型。任何坏成员、重复根或附加坏形状返回 `内部不一致`，不得过滤。
6. 按根场景稳定编码升序形成树身份组。逐项以 `{合同版本, 本次截止}` 调用现有 `读取场景树` 当前入口；任一单树非成功、混代、身份不符或坏完整形状使整组失败并返回空组。
7. 复核不同树的场景身份不重复。
8. 最后读取当前事实代次；若已不同于本次截止，返回 `事实代次漂移`，避免空组或末项之后的并发新增被漏报。
9. 返回 `已读取`、单一非零截止、空变更代次和稳定排序完整树组。

本入口不做忙重试。调用方收到漂移后自行决定是否重新调用；零守卫的新调用重新选择当时最新截止。

## 6. 失败与异常

- 请求坏形状、结构登记未加载：`入口拒绝`；
- 非零守卫过期或读取期间事实代次推进：`事实代次漂移`；
- 分配或长度失败：`资源失败`；
- L1 成功形状矛盾、根标记复义、跨 owner、坏端点、重复树、单树读回坏形状或跨树场景重复：`内部不一致`；
- 其它异常：`内部不一致`。

所有非成功结果均为空组、无变更事实代次。当前无独立公开“发布结果未知”状态；本叶是纯读取，不引入该写入重放问题，也不修改现行 14 个 `L2结构状态`。

## 8. 施工检查与完成边界

风险相称检查至少覆盖：

- 请求 helper 接受零和非零守卫、拒绝坏合同；
- 已装配但零棵树时，零守卫读取成功、截止非零、组为空；
- 两棵非空树时按树身份严格升序，单树和组内节点逐字段完整且共用截止；
- 非零同代守卫成功，陈旧守卫返回漂移与空组；
- 并发新增使进行中的旧截止读取返回漂移，不返回遗漏后的假成功；
- 结果纯值谓词拒绝零截止、变更代次、坏树、乱序、重复树和跨树场景重复；
- 生产源码零测试、故障注入和验证专用分支。

若当前公开 API 不能稳定制造私有坏根标记，则该分支只保留源码防御检查，不为覆盖而增加生产 seam。施工构建和检查只证明本入口的已发生范围；是否满足实际消费者由其经正式聚合、结构化结果和权威读回使用时判断。

本叶完成不代表独立父关系退出、场景全量 CRUD、其它世界服务、概念结构、治理结构、DATA-L3 聚合视图或《数据服务最终需求清单》整体完成。
