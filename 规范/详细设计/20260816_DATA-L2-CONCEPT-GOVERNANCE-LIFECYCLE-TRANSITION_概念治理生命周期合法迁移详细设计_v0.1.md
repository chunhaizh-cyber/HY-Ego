# DATA-L2 概念治理生命周期合法迁移详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-CONCEPT-GOVERNANCE-LIFECYCLE-TRANSITION`

状态：设计就绪

## 1. 目标与完成边界

在唯一 `L2概念结构服务` 内补齐 `DATA-EXT-08` 的普通概念治理生命周期结构能力：

```text
按概念读取当前或指定历史截止的治理生命周期
+ 以具名旧生命周期见证原子迁移到合法目标状态
+ 首次提交与精确重复均读回同一新旧生命周期事实
```

本叶只保存调用方已经裁决的生命周期迁移。数据层不根据用途次数、支持数量、名称、召回结果、统计、时间或业务价值自动冷却、退役或重新激活概念。

本叶复用现有概念 owner、普通概念结构登记、治理生命周期属性类型、概念写锁和 `L2概念结构服务`；不建立第二 owner、第二 C1、通用状态服务、定时治理、活动索引或业务判断入口。四个本体根永久活跃且不进入本合同。

## 2. 正式依据、当前事实与独立缺口

正式依据：0050 v1.3、2220 v1.5、4030 v1.9、4040 v1.5、4050 v1.4、4190 v0.6、4240 v0.6、7140 v1.2，以及已经退出的普通概念 DTO、普通概念服务、直接上下位关系和世界事实支持关系四叶。

当前事实：

1. `L2普通概念事实` 已包含唯一 `L2概念治理生命周期事实`；普通概念首次建立在概念 owner 写集中发布一项 `活跃` 生命周期值并把它设置为当前属性槽。
2. `服务.L2概念结构.ixx` 已登记唯一 `概念治理生命周期属性类型`，材料表示固定为 `I64`；当前 / 历史普通概念重建已能从具名截止投影该值的稳定编码和完整生命周期。
3. L1 owner 写集支持在一份原子发布中建立新值、退出具名旧值并切换同一属性槽；旧值保留历史。
4. 7140 唯一冻结的合法迁移为 `活跃 -> 冷却`、`冷却 -> 活跃`、`冷却 -> 退役`、`退役 -> 活跃`。同状态、`活跃 -> 退役` 和 `退役 -> 冷却` 均不是迁移。
5. 冷却或退役不删除身份、签名、定义、上下位、支持或来源事实。当前支持关系、名称、用途或统计不构成本叶的 DATA 写前拒绝条件；它们只能由 DATA 外业务决定是否提出请求。

两个独立 DRIFT 不进入本叶：

- `DRIFT-DATA-L2-CONCEPT-DEFINITION-ROLE-CARDINALITY-AND-SIGNATURE-CLOSURE`：现行定义引用 DTO 未保存单值 / 多值角色基数合同，且全部定义引用已进入不可原地改义的完整签名。
- `DRIFT-DATA-L2-IMMUTABLE-MATERIAL-PRODUCTION-ROOT-CONFIG-UNDEFINED`：普通应用尚无不可变材料受控存储根来源，不能改用概念服务完整构造。

生命周期值由概念 owner 自有事实独立成立，本叶不修改定义项、签名、材料服务或普通应用配置，也不依赖上述 DRIFT 的裁决。

## 3. 公开 DTO 与纯值 helper

全部新增类型由 `海中鱼巣/领域/L2普通概念结构.数据.h` 唯一拥有：

```cpp
inline constexpr std::uint32_t L2概念治理生命周期合同版本 = 1;

    L2结构请求头 请求头;
    std::uint32_t 生命周期合同版本 = L2概念治理生命周期合同版本;

    L2概念身份 概念;

struct L2概念治理生命周期写入结果 final {
```

迁移请求要求共同请求头有效、非零期望事实代次、非保留幂等身份、概念身份和旧生命周期稳定编码非零，并且状态对属于合法迁移矩阵。当前读取要求历史截止为零；历史读取要求 `0 < 历史截止事实代次 <= 请求头.期望事实代次`。

`L2普通概念事实完整(...)` 改为复用新的生命周期事实 helper，不改变现有普通概念字段和成功形状。

## 4. 公开服务 ABI

唯一 `L2概念结构服务` 增加：

```cpp
L2概念治理生命周期写入结果 迁移概念治理生命周期(
    const L2概念治理生命周期迁移请求& 请求);

L2概念治理生命周期读取结果 读取概念治理生命周期(
    const L2概念治理生命周期读取请求& 请求) const;
```

读取入口只返回概念 owner 自有的治理生命周期事实，不重复返回普通概念签名、定义、上下位或世界事实。它与 `读取普通概念(...)` 读取同一属性事实，不形成第二事实来源；后者仍是完整概念读取。

生命周期入口不依赖不可变材料或六类世界服务，因此根专用构造和完整构造使用同一实现。但输入必须命中普通概念结构中的概念；四个本体根、未知概念和已不可逆退出概念不能借本入口形成治理生命周期。

## 5. 当前与历史读取

读取核心只使用当前普通概念结构定位和概念 owner：

1. 先按请求头取得当前事实代次；当前读取要求守卫等于当前代次，历史读取的外层当前代次仍等于请求守卫。
2. 证明目标是普通概念节点，且概念族归属、本体根归属和普通概念首次见证结构没有复义；本体根不具有普通概念首次见证和治理属性槽，固定返回 `入口拒绝`。
3. 当前读取从治理生命周期属性槽取得恰一个未退出当前值；历史读取从 owner 历史属性值组选择在 `H` 有效的恰一个治理生命周期值。
4. 值必须属于目标概念、属性类型等于唯一治理生命周期属性类型、来源节点等于目标概念、材料为 `I64` 且在 `1—3` 闭集内。
5. 当前或历史同一截止出现零项、重复当前项、槽与值不一致、混代、错 owner / 类型 / 来源或非法状态均为 `内部不一致`；目标普通概念在截止前不存在返回 `未找到`，已不可逆退出按当前 / 历史类别精确分账。

当前成功返回请求守卫；历史成功返回 `H`。成功均为 `已读取`、非零事实截止、零变更代次和非空完整生命周期。非成功 optional 为空、变更代次为空。

## 6. 原子迁移与幂等

迁移使用现有概念写锁和概念 owner，不增加内部登记。新生命周期值使用固定本地键：

```cpp
inline constexpr std::uint32_t 概念治理生命周期迁移值本地键值 =
    0x020A'5001U;
```

规范化写集固定包含：

```text
建立一项属于目标概念的新治理生命周期 I64 值
+ 退出请求具名的旧生命周期值
+ 把目标概念的治理生命周期属性槽切换到新值
```

新值来源节点仍为目标概念。概念节点、族归属、本体根归属、签名、定义、直接上位、来源证据、支持关系和其它属性槽零变化。

执行顺序：

1. 校验纯值请求和保留幂等身份；形成完整规范化写集。
2. 若当前事实代次等于请求守卫，在同一守卫读取当前生命周期；概念、旧稳定编码和旧状态必须逐字段命中，迁移矩阵再次成立。部分命中或当前已是其它状态返回 `引用冲突`，零写。
3. 若当前代次已经变化，不用新事实改写请求，直接向 L1 提交原规范化写集，让 L1 裁决精确重复、事实代次漂移或幂等冲突。
4. 首次成功必须形成一次 owner 原子发布；精确重复不得形成新发布，并从首次结果截止重建同一新旧生命周期。
5. 发布未知、资源失败或无法证明首次结果时返回 `资源失败`，保留原完整请求和原幂等身份重放；不增加 deadline、sleep、轮询或内部重试。

同状态请求不是精确重复合同。只有与首次请求完整相等且使用相同幂等身份的重放，才能由 L1 返回 `精确重复`。

## 7. 成功形状与错误映射

写成功只允许 `已提交` / `精确重复`，事实截止非零，变更事实代次存在且等于事实截止；两个 optional 均有值：

- `当前生命周期`：目标状态，创建事实代次等于结果截止，无退出代次；
- `已退出生命周期`：请求旧状态和旧稳定编码，退出事实代次等于结果截止，创建事实代次早于结果截止；
- 两项概念身份相同、稳定编码互异，状态对符合合法迁移矩阵。

任一非成功的两个 optional 为空，变更事实代次为空。发布后读回坏形状返回 `内部不一致`，不得把缺项猜成成功。

| 条件 | `L2结构状态` |
| --- | --- |
| 无效合同、零守卫、零身份、非法迁移、保留幂等身份、本体根 | `入口拒绝` |
| 普通概念或历史目标不存在 | `未找到` |
| 普通概念已经不可逆退出 | `已退出` |
| 当前生命周期稳定编码 / 状态与请求不符 | `引用冲突` |
| 非零守卫不再当前且不是精确重复 | `事实代次漂移` |
| 同幂等身份异写集 | `幂等冲突` |
| L1 许可拒绝 | `许可拒绝` |
| L1 资源失败或发布结果未知 | `资源失败` |
| 重复当前值、槽错位、错 owner / 类型 / 来源、混代或坏成功形状 | `内部不一致` |
