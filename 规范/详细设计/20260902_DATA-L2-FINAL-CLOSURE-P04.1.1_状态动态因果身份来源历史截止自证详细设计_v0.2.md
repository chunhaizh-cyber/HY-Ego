## 2. 目标与完成边界

本叶只纠正状态、动态、因果三个身份来源读取结果的成功谓词：历史读取成功必须同时证明结果回显的历史截止与结果头事实截止相等。

```text
当前读取成功
  = 读取类别为当前
  + 历史截止事实代次为 0
  + 身份来源在结果头事实截止完整

历史读取成功
  = 读取类别为历史
  + 历史截止事实代次非 0
  + 历史截止事实代次 == 结果头事实截止代次
  + 身份来源在该结果头事实截止完整
```

这只收紧调用方拥有的值式结果自证，不改变 `DATA-L1` 事实、任何服务读写、当前选择、历史投影、退出、恢复、TTL、墓碑或公开 DTO 字段。

## 4. 冻结的谓词合同

三个 `成功()` 均采用如下闭合顺序：

```cpp
结果头.状态 == L2结构状态::已读取
&& 结果头.事实截止代次 != 0
&& !结果头.变更事实代次
&& 身份来源
&& 身份来源->节点族 == 本族
&& L2节点族身份来源事实完整(*身份来源, 结果头.事实截止代次)
&& (读取类别 == L2读取类别::当前
    ? 历史截止事实代次 == 0
    : 读取类别 == L2读取类别::历史
        && 历史截止事实代次 == 结果头.事实截止代次)
```

未知读取类别、当前读取携带非零历史截止、历史读取携带零历史截止、或历史截止与结果头截止不等，均必须使 `成功()` 返回 `false`。本叶不得改变服务对请求的既有拒绝 / 失败映射。
