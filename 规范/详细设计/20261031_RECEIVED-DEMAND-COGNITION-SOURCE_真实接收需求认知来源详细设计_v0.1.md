## 4. 唯一来源与重入

来源键K逻辑形状固定为`{真实接收消息M, 原文标量起点0, 原文标量终点N, 根需求出现路径空组}`。本叶只处理一条完整自然句且根即需求陈述，不切分多句/不从嵌套提问取需求；N由M固定UTF8严格解码得到。不得使用运行次数、队列编号、可变知识版本、目标值、H姓名或时间作替代来源键。

M的正式来源为会话、页面、接收方向、上行序号；语言/页面原文不是新来源ID。U和D各自保存K的正式引用关系并由owner在同一来源范围完整查重；H或内容异义是冲突，不换键建立。相同文本的新M允许新K。

| 重入位置 | 必须行为 |
| --- | --- |
| M已接收、尚未认知 | 读取原M，按仍保留的已接纳会话H来源处理；不重新收件。 |
| S已建立、U未发表 | 以M来源取得同一S；保留合法空S，不另造同源S。 |
| U已发表、D未发表 | 先按K正式读取U，以原U继续；当前词义/知识变化不能重写同源U。 |
| D及来源已发表、F失败 | 查询同源D，调用原目标F承载补齐并读回；不再建D。 |
| U/D均可读 | 返回同一身份和实际阶段；不重复写目标值/状态/动态，不重复入H特征。 |
| 同K异H/原文/含义/目标 | 明确来源冲突，保留原事实，不覆盖或合并。 |

没有跨owner原子保证：S、U、概念目标及D依次发表，只有各次已完成组合拥有原子性。发布未知只能按同K读取各owner收敛；不能换K、补造成功或声称回滚。

## 5. 逐出现专名绑定提供者

统一转换增加显式对象绑定及语境范围输入，旧调用空绑定保持。绑定生产算法不是操作员提供坐标/编码：解释器在匹配知识的`明确对象描述`角色时已有精确的UTF8标量起止，完整查询该词条的全部名称关系，逐项读回强类型概念。

只有存在专属概念且具有正式`对应存在节点`才可尝试实例专名绑定；核E的`专属存在概念节点==C`及C的对应E均成立。E必须在调用方明确的现实世界根完整递归成员范围（包含根场景及其全部后代，不含外设、自然语言或治理世界）中。读取采用世界/场景/存在owner正式接口，不用底座存在性替代。

一出现有两个合法E，保留多义；一般类名无专属对应不因只找到H而绑定。两次同专名各保留各自标量范围，可分别绑定同一E，不合并出现。根需求主体最终须等于已绑定会话H；目标E独立解析，不因角色相邻或H唯一而复制H。

纯统一入口由外层业务主动调用，完整仲裁及其末次复核核原文/知识/名称/专属身份/现实成员依据不漂移，随结果冻结全部实际读集；后续采用来源reader只机械重读这些依据，不重跑解释器。未决角色不生成匿名现实E。首版不新增对“我/你”的词面特别处理。

## 7. D首次来源与目标字段

本叶D的信息完善阶段保持待完善；已理解全部字段也不自动生成旧确认来源或加入H特征。沿原`要求目标特征实例承载`建立五F及字段关系，未知值可为空但节点/关系完整；其跨owner实际写入按现算法分阶段保留，首次D来源K已存在，因此补齐失败仍可读回同一D。

## 8. 正常接线、调度与寿命

### 8.1 H冻结先于接收，原始M承担处理债务

不使用有界逐消息认知队列。`开始普通应用网页会话(std::string_view 会话)`在原可信登录名核验得到H之后、向宿主返回会话开始成功之前，调用认知服务登记不可变会话级`{公开宿主会话, H, 现实根, 语言}`语境；该现有入口不具有页面参数，不新增默认页面或假页面绑定。每条M的真实页面只取外设正式来源。只有语境登记及读回成功才使这次可信会话可接收消息。配置为空的匿名会话登记明确匿名，不猜H；资源失败发生在会话建立阶段，不能先开放网页再丢来源。相同会话不可重绑定另一H，原语境保持至self最终join；真正换身份必须使用新会话来源。

其后外设仍只按原准入合同发布并读回M，不调用认知服务。M的会话精确匹配已经登记的不可变语境，其页面再经外设owner核本M正式来源，因此H来源在真实M接纳时已经确定，不是在异步消费时查询“当前H”。关闭只封存本会话、不抹语境，不接受关闭之后伪造的新接收；关闭前已经正式发布的M仍可被补扫。不存在该已接纳语境的M保留原文并报告来源未接入，不默认第一权限人。

新增外设owner公开只读口`新外设接收记录完整结果 完整读取仍保留的接收记录() const noexcept`（完整DTO见§12.2）。在原外设互斥内读取消息根全部正式登记，逐条由现`读取正式消息`核完整结构、唯一来源、根快照，选接收方向，按`会话、页面、来源序号、M`稳定排序；完成且空与资源失败分别返回，不以空vector混淆，任何根/成员损坏工程终止且不交部分结果。这个口不是L1历史接口，也不读“当前接收消息集合”；当前引用移除后仍保留的M必须继续返回。它只读事实，不依赖self/语言/需求，不新建消息任务账。

self已绑定认知服务时，首次工作循环即补扫正式M；之后固定最多每500ms补扫一次，并可由轻量通知提前唤醒。因此通知遗漏、投递失败、邮箱满不取消原始M的债务。临时只存本进程调度状态：每M最近阶段、终结非成功及需重试时点；这是可从M与同源U/D重建的工程状态，不充当语言/需求事实源，不跨进程承诺恢复。进程正常终止仍未消费的M保持原始事实并明确报告未处理，绝不写成完成。

### 8.2 实际调用、清标志竞态和合法重入

普通应用新增收件后通知，仅携带`会话、页面、序号`，放在外设接收成功后；不因显示追加或认知是否成功撤销M，也不向HTTP映射认知错误。通知只调用`新_自我线程类::通知接收认知变化() noexcept`，在self状态锁内设置`接收认知待唤醒=true`并`notify_all`，不分配逐M邮箱项。POST202继续仅表示外设准入成功，后续任何解析/D失败不得改成可重发503。

self在`实现::运行`首次准备完成后、原`while`每轮入口检查认知推进机会；每次最多处理一条M的一阶段，随后至少让出一轮既有治理工作。调用前在self状态锁内取走并清除唤醒标志、记录本次500ms补扫时点，随后释放self锁调用认知服务；owner调用完成后再取锁。清除只能发生在扫描之前，不能在扫描之后覆盖并发新通知。新M在清标志后或补扫后出现：其通知重新置位，原等待predicate立即见真；若通知丢失，下个500ms截止点补扫发现。原`等待推进`把该标志加入提前返回和wait predicate，把最近补扫/资源重试时点合并到`wait_until`，不可仍在无认知条件的无限wait中睡眠。

来源相同的合法重入只有这些实际生产调用：首次/周期补扫、收件通知提前推进、到期资源重试。前提变化（知识、名称、身份或世界成员读回与本次快照不一致）不标终结，保留M并以500ms重试点重新读取；发布结果未知先按同K查询已发表S/U/D，再决定剩余阶段，不重建前缀。资源不足不标完成，独立工程诊断并延后500ms，self仍受原停止token控制。确定匿名、当前支持范围外、唯一解析不存在或多义等记录明确非成功；没有新M或显式后续重处理入口时，不每500ms反复重解这种终结项。本叶不新建人工强制重处理/恢复接口。结构损坏或不变量错误走工程终止路径，不可当正常重试。

### 8.3 停止、锁和寿命

认知服务由普通上下文唯一持有，启动前绑定self；self在原循环锁外推进，不新增OS线程或manager T，不通过筹办/模拟学习调用。不持普通上下文互斥进入语言/需求/外设owner，不由认知服务回调普通上下文或self；唤醒是宿主到self的单向通知，避免锁环。不可变会话语境登记/读取使用服务自身短锁，释放后才进入owner；服务单消费者为self。

停止先封会话入口并停止接纳，原始M及已发表S/U/D保留；self同源停止token在每次补扫和owner调用前后检查，已进入的单次组合可完成并保留真实回执，随后不进入下一阶段。停止不排空认知债务、不等待新消息，未处理和已完成分账；新解析/单getter内部不承诺硬中断，不延长5000ms、不跳最终join。普通上下文在宿主结束、停止广播、所有线程最终join后才销毁认知服务、语境及其注入owner。原外设独立模块寿命/关闭顺序保持。无TLS、全局停止变量、跨进程恢复或新的物理清理协议。

两F及其保护正式完成后再进入语言锁，同K复查。若已有一致U，则本次为并发输家：先取原U的实际F组并释放语言锁，确认本次候选F不在任何已采用U/角色引用中，调用`准备特征组清理({本次两个候选F}, {})`；只有`新特征清理准备状态::已准备`且凭据非空才调用`执行已准备特征组清理(凭据)`。出现外部引用、被采用或快照不符不得删除，走工程问题并保留现场；不把外部字段放入“允许解除”绕过保护。候选尚未被采用但一F写入失败，同样在语言锁外按已实际建立的候选组回收。若状态/引用不确定，只报告保留，不盲删。

若仍无U，则把两F及其完整保护并入语言组合追加预期，同次公开U/角色→F引用。U追加失败或返回未知先按K读实际U；实际U引用本次F就视为已采用，不准清理；命中另一U则按上述输家清理；完整确认尚无U且本次F未被消费才可清理。不能把存在快照和U锁伪称跨owner原子。F从实际写入起已阻止E身份清理，直到未采用F被F owner正式回收；已采用U永久持有其F，本叶不提供U/F清理或改值入口。

读取U采用两阶段：语言锁内读取U/角色全部结构及F定位，释放后由F owner完整读F/FT/当前值，随后语言锁内核原U结构保护及F完整保护未变，再交付结果。U已采用的F不得改值；读到当前值改变或类型/保护缺失是引用/结构工程问题，不能从历史值找回E冒充当时当前。FT1001/1003的实际语义和引用类型在本叶初始化只读核验，不建立新词义/新槽。只在U主体H及目标E两实际角色使用，不拿该FT承载会话、M或现实根。

**S/F的本轮自致变化不构成语义变化。** 初次解释后建立S会增加M入向引用，建立并写角色F会增加E的保护引用/概念引用统计。语言owner不能拿准备前旧联合快照直接CAS（会自致失败），也不能无条件用fresh覆盖。两F正式完成、U公开之前，语言锁外再次调用上述来源读取器；必须证明原文与源会话、完整名称候选、采用/候选知识定义、全部实际FT/特征概念的上述语义定义/根链依据、每出现角色定位及C↔E身份、现实根完整场景/成员范围和目标内容均与最初解释一致，且两个F当前仍是拟采用E。即使图中的FT编码/文字不变，只要材料类型、单位、值域或同根/比较依据变化也必须前提变化，不准改取fresh后继续采用。通过后，使用这些正式owner现在返回的完整保护作为最终U追加预期；与语义无关的入向引用数量/实例引用统计不被固化为句子含义，不另建差分许可框架。任何原语义依据改变则前提变化，清理确未采用F并同源重入；CAS前实际新保护仍失败则按同K查已发表结果后处理，不能无限建F/换K。本轮来源reader调用全在语言锁外；最终语言锁内只做源K查重、实际保护CAS和自身schema读回，不反向调用外设/词名/场景/F。

### 12.3 v0.2执行退回：混合指代端点/来源正式只读保护

**语言来源owner算法。** `读取知识先天来源保护(source)`在原语言锁内复用`知识模式状态已加锁`和`读取知识来源细节已加锁`的`知识读取现场`；保留现场实际读到的来源节点、来源种类/语言/固定原文、语言身份及所用schema/类型端点的完整联合结构，包含模式检查实际依赖的必要键节点。返回来源typed信息及同一闭包读得的`语言信息`，两者的语言节点必须一致，名称owner不另拿一个无保护语言getter拼typed结果。将现场已读结构批量提升为联合快照，末次与原读/原typed结果核同，矛盾返回`前提已变化`；不是仅对一个source节点拍快照，更不能由名称层读取私有来源字段。来源不存在与模式未初始化分别明确返回；合法source若被已冻结名称硬引用后消失，消费侧按前提变化/依赖变化中止本次采用，不改成普通缺名称。`已读取`须携来源/语言两份typed信息及非空完整保护，源结构损坏或成功缺任一载荷抛工程异常；资源独立返回。不要求该source必须出现在当前候选知识来源组，也不建立第二来源仓。

**名称消费及最终CAS。** 名称owner的完整混合候选保护对每个实际独立指代项，使用新CE reader取得概念typed/闭包、现词条保护取得词面、使用新语言来源reader取得来源及语言typed/闭包；语言来源的语言身份必须与该项正式语言及词条语言互证。对每个source分别读取，不能以“当前语言资源保护已包含”省略。typed含义仍为现`指代名称关系信息`，普通项路径不变；相关保护与名称组织/角色/范围/反向互证实际读集在原名称锁外取其它owner、原名称锁内末次复核后合并返回。重复依赖可在同次只读上下文缓存，但必须携原完整保护，不能伪造成功。两reader的漂移/依赖变化映射名称原`读取漂移/依赖已变化`，资源映射`资源失败`，未就绪映射读取未完成；损坏按工程异常。其后仍沿冻结名称候选依据→机械来源复核→U最终CAS传递，指代含义/来源改变必须前提变化，不重解释、不扩代词理解。

本修订不新增未实现后继计划或架构；仅新增两个缺失reader，现语言资源reader仍负责它原来的知识闭包。受影响名称分支待修订发布后重新S0，root外设/场景等非重叠分支继续原已冻结施工。
