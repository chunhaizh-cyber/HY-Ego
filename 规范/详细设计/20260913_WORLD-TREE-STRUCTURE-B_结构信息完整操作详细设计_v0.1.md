## 1. 单一闭环与不变边界

世界树应用只调用DATA-L2公开结构服务；DATA-L2唯一owner经现有DATA-L1中性写集/有限N事务发布。B不新增DATA-L1写口，不恢复旧概念根，不增加第二世界树/概念仓，不运行方法/任务/线程，不擅自创建传感器数据。概念定义及需要的材料必须先真实发布，世界新F随后与唯一组织父及概念使用引用共同成立。

交付必须同时具备：三种F父×四原始表示；四种E归属迁移；同节点视角；任意共同截止历史位置；当前采用与概念细化；受保护非递归删除；普通自我实际消费者及持久重启保留合法后继。

## 2. 结构位置唯一语义

### 2.1 E与C

E的唯一对象结构父来自场景成员、存在组成或直接子场景的联合结果，父不是另一份字段。C是E同节点角色；世界根特殊保护。角色启用/退出不改变E原身份或制造第二结构父。

四种存在迁移按原父/新父分为场景→场景、场景→父E、父E→场景、父E→父E；直接子场景是有场景角色对象的场景父组织分支，不产生另一对象。输入必须明确旧来源、旧父、旧关系身份和目标父分支。对同一合法位置返回具名无变化，零写；不是任何错旧边请求都可因目标相同而成功。

### 2.2 F的三父与真实C

F唯一组织父为场景、普通存在或父F。存储组织边统一归scene owner；场景分支以该C真实特征根为源，存在分支以E为源，父F分支以父F为源。边不是对象结构父，不加入E/C单父计数。

强类型输入：

```cpp
struct 特征场景父_v2 { 稳定编码 C; };
struct 特征存在父_v2 { 稳定编码 E; };
struct 特征特征父_v2 { 稳定编码 F; };
using 特征组织父_v2=std::variant<特征场景父_v2,特征存在父_v2,特征特征父_v2>;
struct 特征位置指定_v2 { 稳定编码 期望世界根,上游场景; 特征组织父_v2 父; };
```

场景父：上游C必须等于指定C，持有者为C；普通存在父：沿E的严格祖先联合路径找到最近活动场景C，排除E自身角色，持有者为E；父F：从父F唯一组织路径继承持有者及上游C。E无需先启用场景角色。描述E宏观特征与在E同节点场景内组织内部特征由强类型分支区分。

持有者→F的已知关系归existence owner；父F分支同时要求父F已在同一持有者的已知组。其它E可增加共享已知/采用引用，不改变F唯一组织父。组织边仍存在时禁止单独退出必要的持有者已知关系。

同FT/完整准确值只提供候选；同位置同义命中可复用。跨位置候选不能移动或复制为同一个位置命中，只能按明确请求添加共享引用；多个同位置候选是结构矛盾，零写拒绝。F自身类型/准确值永不原地替换。

普通E移动后，其自身组织的F随E保持原边和身份；上游C由同截止历史联合路径推导，不能保留第二个易漂移的F→C缓存事实。原场景观察、状态、动态和来源不随之搬移。场景角色自己的四根随同节点保留。

## 3. 共同截止、状态编号、预算与恢复约束

所有新B结构请求使用版本1并以具名后缀`_B1`与A旧ABI区别；原A参数、布局和稳定状态数值不重用。读取必须0<H<=Gread，Gread须等于本次入口及退出时DATA-L1当前G；历史H仅决定生命周期可见性。当前接口显式H=Gread，不以0代最新。已退出对象可在退出前H读回，不用当前位置/当前角色替代历史。

预算八个非字节字段各0..1048576，最大材料字节数0..16777216。0是该维度本次不能再消耗的硬上限，不表示未提供、无限、自动默认或忽略检查；超过任一原上限为入口拒绝9。`世界结构预算有效`只检上述逐维上界，所有使用`世界结构预算_B1`的B公开入口与成功谓词采用同一准入，不另加九维皆正的局部守卫；DTO整数类型、字段顺序及B1请求版本不变。具体操作仍保留自己的非预算形状约束，材料载荷/格式N、非空域、非零身份和G等要求不因预算0而放宽。

实际发生正消耗前，先逐维检查所需量<=真实剩余，再扣减并累加用量；不足返回数量预算不足24，不以预算格式错误9代替。该次消耗的各维先全部核验才扣减，乘加先查溢出，禁止无符号减法回绕或溢出后再比较。不使用的维度需要量为0，即使该维余量0也可继续；若后来该维需要正消耗，必须在发生前24。零预算不能用来跳过必要的节点/字段/文件核验、返回截断空组或编造零用量成功。全部九维为0本身可通过预算形状校验，但本包任何必须读取真实对象/布局/值/材料的请求都应在其必需消耗处24，无事实写；不得据预算有效直接判操作成功。失败仍报告真实已发生用量，已知H及发布分账按原合同保留。

共同计量贯穿父路径、候选、概念、材料和提交后读回，不给每次递归重置满预算。同一公开子调用内部按唯一事实ID去重；跨公开子调用/阶段把其实际用量相加，重复完整核验确实消耗的读取再次计数，避免要求上层取得未公开内部读轨迹才能全局去重。完整材料字节逐次实际读取计数。上层仅把逐维真实剩余传给下一公开子调用，包括0余量；禁止0补1、抬高未使用维度、延后记入已发生消耗或漏算失败阶段。结果成功须逐维用量<=本请求预算，预算0的维度用量必须恰0，其余对象/截止/完整性谓词原样保留。同类内部可以共用私有完整核心和计量，跨owner仍走已冻结公开口，不能借私口规避准入。无截断成功、无限重试、自动提预算或猜缺项。

每个族拥有各自状态及发布枚举，按上述字典分配具名项的稳定数值，不以alias、继承或公共结果模板合并协议。§12精确列出各结果字段、载荷及成功状态集合；共同文字只约束G/H/预算及错误保存。首次H来自真实首次账，不由Gread推算；退出的历史前态读H=exitH-1，退出事实还要核验精确exitH。发布后读回失败必须保留已知H和真实发布状态。

入口先做不依赖当前状态的形状校验，再查原键首次材料。已有账先完整历史恢复，再读取合法当前后继；不得先以当前父/当前采用/当前概念/退出状态拒绝已完成原请求。全无账才进入新操作；部分账或不相容账不能降成未派发。相同原规范化写集经原G0、原组合键、原分区键重放，使用DATA-L1原子幂等合同校验组合身份，禁止只凭同H猜组合。

### 12.1 无环import与值式事实

模块DAG固定为：L1→公共纯合同→材料服务→特征值服务→特征解释纯合同→定位特征；特征类导入定位特征并实现其内容参与者，不能由定位模块反向导入特征类。概念纯合同导入特征解释纯合同；绑定存在导入原场景角色合同及概念纯合同；存在/场景导入绑定存在和定位特征，概念服务导入绑定存在/定位特征/特征类并实现概念参与者；世界导入这些L2服务，自我导入世界，普通装配导入自我及所需L2构造。箭头只表示“左侧先有，右侧可import左侧”；公共纯合同不导入材料、值、概念或场景；材料绝不借用概念生命周期。联合小合同导入公共纯合同，场景角色合同继续导入联合小合同。所有事实中出现的纯概念身份/定义放在概念纯合同之后的定位/绑定模块，禁止为公开F位置把概念服务import到纯解释合同。
