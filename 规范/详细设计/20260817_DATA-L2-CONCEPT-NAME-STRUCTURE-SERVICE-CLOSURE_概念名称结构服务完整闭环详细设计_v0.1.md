## 1. 目标与完成边界

本设计闭合《数据服务最终需求清单》`DATA-EXT-11` 的一个完整 provider 结果：

```text
强类型概念名称 DTO
+ 独立名称关系 owner
+ 唯一 L2概念名称结构服务
+ 新增 / 原子替换 / 退出
+ 单项当前 / 历史读取
+ 按概念正向完整当前名称组读取
+ 按词条反向完整未过滤当前候选组读取
+ 普通应用同实例装配与 const / non-const getter
+ 生产二进制外合法普通应用消费者首次权威读回
```

本叶只保存调用方已经裁决的“概念可由某词条按某角色、某语言命名”结构，不判断名称是否正确，不创建、改义或退出概念、词条、语言或来源节点，不执行分词、词性判断、同义判断、类型路由或上下文消歧。

完成最多证明 `DATA-EXT-11` 公开 provider 的生产 ABI、唯一 owner、普通应用装配和施工验证进入正式 Git。它不证明任一名称在业务上正确，不证明输入上下文采用某一概念，不证明 `DATA-EXT-01—14` 整体完成，也不建立生产内自检或独立验收结论。

## 3. 所有权与依赖裁决

### 3.1 唯一 owner

新增一份 `独占结构范围`：概念名称关系范围。固定建立幂等身份为：

```cpp
inline constexpr L1所有者范围建立幂等身份 概念名称所有者建立身份{
    0x4C32'434E'414D'0001ULL};
```

`L2概念名称所有者交付` 是不可复制、可移动的私有能力交付，只能由同一 L1 实例的 `尝试形成L2概念名称所有者交付(...)` 形成并移动进入唯一服务。服务不得导出 owner、写端口、owner 选择或第二工厂。

### 3.2 唯一依赖方向

```text
L2概念名称结构服务
  -> 同一 const L1事实基座服务&
  -> 同一 const L2概念结构服务&
  -> 同一 const L2语言结构服务&
  -> 唯一 L2概念名称所有者交付
```

构造函数冻结为：

```cpp
explicit L2概念名称结构服务(
    const L1事实基座服务& 第一层服务,
    const L2概念结构服务& 概念服务,
    const L2语言结构服务& 语言服务,
    L2概念名称所有者交付&& 名称所有者交付);
```

构造时必须互证三服务绑定同一 L1；交付 owner 与语言、词条、概念 owner 两两不同。名称服务只读调用概念和语言服务，不取得其端口，不反向 import BIZ，不增加六类世界服务依赖。

不新建“语言概念万能聚合”或第二概念 getter。`L2概念名称结构服务` 本身就是 4240 所要求的具名语言表达结构；普通应用直接持有其唯一实例并提供同名 getter。

### 4.1 基础事实

```cpp

    稳定编码 值;
    explicit L2概念名称关系身份(稳定编码 编码 = {}) noexcept : 值(编码) {}
    friend bool operator==(const L2概念名称关系身份&,
        const L2概念名称关系身份&) = default;
};

enum class L2概念名称角色 : std::uint8_t {
    首选名称 = 1,
    别名 = 2,
    简称 = 3
};

struct L2概念名称事实 final {
    L2概念名称关系身份 名称关系;
    L2概念身份 概念;
    L2词条身份 词条;
    L2概念名称角色 角色 = L2概念名称角色::首选名称;

    稳定编码 来源稳定编码;

```

`名称关系.值` 是名称 owner 中私有关系记录节点的稳定编码。它是公开关系稳定身份，不形成第十一种节点族，不可转换为概念、词条、语言或普通 L1 节点身份。`来源稳定编码` 只要求同截止存在的非零 L1 节点引用；DATA 不解释其业务含义。

## 6. 私有物理承载与稳定编码

### 6.1 一次性结构登记

名称 owner 使用固定登记写幂等身份：

```cpp
inline constexpr L1所有者范围写入幂等身份 概念名称结构登记幂等身份{
    0x4C32'434E'5247'0001ULL};
```

一次性原子登记四个普通关系类型节点：

| 本地键 | 私有用途 |
| --- | --- |
| `0x0211'6001` | 概念端点关系类型 |
| `0x0211'6002` | 词条端点关系类型 |
| `0x0211'6003` | 语言端点关系类型 |
| `0x0211'6004` | 来源端点关系类型 |

`0x0211` 在设计基线的生产源码、本轮有效计划和工程登记中零占用。执行 S0 必须全仓复核；发现正式占用即停止受影响切片并返回计划支撑，不得临场换号。

### 6.2 单个名称关系写集

新关系固定使用：

| 本地键 | 事实 |
| --- | --- |
| `0x0211'1001` | 私有名称关系记录节点，也是公开 `L2概念名称关系身份` |
| `0x0211'1002` | `概念 -> 名称记录`；角色字段精确编码名称角色 |
| `0x0211'1003` | `名称记录 -> 词条`；角色固定 1 |
| `0x0211'1004` | `名称记录 -> 语言`；角色固定 1 |
| `0x0211'1005` | `名称记录 -> 来源节点`；角色固定 1 |

这是概念到词条多对多关系的 owner-scoped 物理线性化，不增加公开节点族。权威读回必须同时命中唯一记录节点、四条精确类型关系、角色、端点、owner 和共同生命周期；缺项、复义、错向、错 owner 或混代均为 `内部不一致`。

新增写集原子建立上述五项。替换写集原子退出旧五项并建立新五项。退出写集只退出旧五项。任何一项失败整笔零变化；不得先写记录再补端点，也不得把索引当权威关系。

## 7. 写前端点与唯一性裁决

全部写入口持有名称服务唯一写锁，并以请求非零 `G0` 完成：

1. 经唯一概念服务读取全部当前根；目标命中一个根时接受，否则经 `读取普通概念` 读取当前完整普通概念。两条路径都不得返回坏成功形状。
2. 经唯一语言服务按身份读取当前完整词条和当前完整适用语言。
3. 词条事实的语言身份必须等于请求适用语言；否则 `引用冲突`。
4. 经同一 L1 在 `G0` 读取来源节点；来源不存在或已退出分别保持 `未找到` / `已退出`。
5. 正向读取目标概念全部当前名称，验证同一概念 / 词条 / 角色 / 语言至多一项；若新角色为首选名称，再验证同概念 / 同语言没有另一当前首选名称。
6. 替换时先逐字段命中旧关系，并在唯一性计算中排除该旧身份后验证新关系；退出只接受逐字段精确旧事实。
7. 全部前置读取与提交共同使用 `G0`。任一并发发布使提交守卫失效时明确返回 `事实代次漂移`，不得自动重选截止或内部重试。

端点已经退出时，名称退出仍必须先按请求 `G0` 读取旧名称关系并依赖 L1 允许同一名称 owner 关闭自身事实；概念 / 词条 / 语言正常退出由其 owner 的引用保护要求名称关系先退出。名称服务不级联退出端点。

## 8. 幂等、替换、退出与发布未知

三种写请求把调用方 `L2结构幂等身份.值` 一对一映射为名称 owner 的写幂等身份，并排除结构登记保留身份。

提交前以活动写端口 `读取首次写入材料(...)`：

- 同一首次规范化写集：从首次提交截止历史重建同一结果，返回 `精确重复`；
- 同幂等异写集：`幂等冲突`；
- 未找到：才执行当前端点、唯一性和提交；
- 发布未知、资源失败或读回失败：调用方保留原请求、原 `G0` 和原幂等身份重放，不得依据新当前状态改造请求。

替换的新关系获得新稳定身份，旧关系五项的退出代次等于提交截止。退出不产生新编码。首次和精确重复结果均按首次截止返回相同新旧载荷，不把后继关系状态混入首次结果。

## 9. 当前、历史、正向与反向读取

### 9.1 单项读取

当前读取在请求 `G0` 读取名称记录和四端点关系。记录已退出返回 `已退出 + 空载荷`。历史读取在 `H` 重建完整事实：`H` 早于创建为 `未找到`；达到创建后返回完整生命周期，晚于退出时仍返回已退出历史事实。

历史端点验证使用相同 `H`：概念根永久当前；普通概念、词条和语言分别使用其公开历史读取。不得用当前端点补历史名称事实。

### 9.2 正向名称组

只读名称 owner 的“概念端点关系类型”当前源关系组，逐项回到名称记录并完整读回。稳定排序固定为：

```text
(适用语言编码, 角色枚举值, 词条编码, 名称关系编码) 严格升序
```

### 9.3 反向未过滤候选组

只读名称 owner 的“词条端点关系类型”当前目标关系组，逐项回到名称记录并完整读回。稳定排序固定为：

```text
(概念编码, 适用语言编码, 角色枚举值, 名称关系编码) 严格升序
```

反向结果返回全部当前 `L2概念名称事实`，不读取或返回词性，不按本体根、目标类型、上下文、业务优先级或首项过滤。零候选成功。候选多项不猜选；单项也不证明语义理解。

两类组大小超过预算均返回 `数量预算不足 + 空组`，不得截断成功。组读取前后事实代次不等于请求 `G0` 返回 `事实代次漂移 + 空组`。

## 10. 状态和成功形状

| 条件 | 状态 |
| --- | --- |
| 合同、角色、身份、预算、截止或替换无变化无效 | `入口拒绝` |
| 概念、词条、语言、来源或名称身份不存在 | `未找到` |
| 端点或名称当前已退出 | `已退出` |
| 词条语言与适用语言不符、旧事实字段不符、重复关系或首选占用 | `引用冲突` |
| 请求守卫不再当前 | `事实代次漂移` |
| 同幂等异规范化写集 | `幂等冲突` |
| 请求预算不足以返回完整组 | `数量预算不足` |
| 分配、容量或长度资源失败 | `资源失败` |
| owner / 类型 / 端点 / 生命周期复义、坏成功形状或混代 | `内部不一致` |

写成功只允许 `已提交` / `精确重复`，截止非零，变更代次存在且等于截止：

| 操作 | 当前关系 | 已退出关系 |
| --- | --- | --- |
| 新增 | 新关系有值 | 空 |
| 替换 | 新关系有值 | 旧关系有值且退出代次等于截止 |
| 退出 | 空 | 旧关系有值且退出代次等于截止 |

读成功只允许 `已读取`，变更代次为空；单项成功 optional 有值，组成功允许空 vector。所有非成功载荷为空、变更代次为空、权威事实零变化。
