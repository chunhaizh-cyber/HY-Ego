## 5. 唯一函数算法

函数体固定为：

```cpp
状态动态原子发布结果 世界树业务服务::发布状态并整理动态(
    const 状态动态原子发布请求& 请求) const {
    return 发布实际存在I64后继状态与迁移动能(
        L1_, 实例特征_, 状态_, 比较_, 动态_, 请求);

```

调用前后不得增加：

- 对合同、规则、整理幂等身份、时间、当前事实请求或结果状态的校验；
- 前状态读取、P13/P14调用、P15幂等探测、摘要、局部键、写集、提交或读回；
- 状态映射、optional补造、结果重组、无前状态改判或部分成功包装；
- try/catch、日志、计时、retry、sleep、fallback、旧入口回退或第二 provider 调用；
- 世界快照预读、前三写调用、缓存或跨调用状态。

P16 返回什么，门面逐字段返回什么，包括状态、内部原因、精确重复标志、首次证据、后状态事实、可选迁移动能事实和 L1 失败见证。异常若越过 P16 合同，门面不捕获改判。

## 6. 既有六根、并发与生命周期

P32 三读、P35 第一写、P41 第二写和 P44 第三写全部保持原函数体与一对一 provider。新增五引用不能被既有六根访问；第四写对快照、P34、P40、P43直接调用为0。

门面不加锁、不排队、不重试。P16 独占状态动态准入、幂等、事务、读回和并发结果；其它写 provider 各自独占其领域事务。门面不建立跨入口顺序、第二幂等身份或第二失败见证。

构造只绑定引用，不读取、不恢复、不登记、不发布事实。未来装配必须先构造九个依赖再构造门面；这是依赖合同，不授权本叶写运行期文件。
