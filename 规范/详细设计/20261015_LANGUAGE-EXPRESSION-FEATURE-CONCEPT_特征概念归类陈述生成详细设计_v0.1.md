# LANGUAGE-EXPRESSION-FEATURE-CONCEPT 特征概念归类陈述生成详细设计

日期：2026-10-15。版本：v0.1。状态：设计就绪，代码未实现。设计代码基线：`60f6fb067600b89c272f83c20f8eaa9e18f2cca0`。

## 1. 目标、依据和事实

长期目标是在具体表达要求明确时，用表达目的、对象类别及类型化含义选择语言知识，生成自然语句。本叶在已发布 `LANGUAGE-EXPRESSION-S02` 的通用基础表达入口上，让 `概念归类` 的两个角色**都是正式特征概念**时，也能按当前语言知识结构与正式名称生成完整汉语陈述和来源/含义对齐。它不另建句型，不修改知识定义或世界事实，不按词面选择规则。

正式依据：[0050](../0050_项目通用机器逻辑与禁止性规则总纲_20260721.md)、[2340](../2340_根规范_自然语言知识.md)、[7230](../7230_子规范_语言材料知识与交互字段.md)、[7240](../7240_子规范_自然语言双向转换与组织规则.md)、[7220](../7220_子规范_概念多语种表达与自然语言接入.md)、[2210](../2210_根规范_概念名称关系.md)、[7160](../7160_子规范_特征概念形成组织与名称关联.md)及[代码归属规范](../代码文件建立归属与模块命名规范.md)。本叶表达**调用方已指定的主张**，不核验该主张是否为正式上下位事实。特征概念归类的联合类型约束要求两端属于**同一个正式 FT 类型根**；这只决定这项主张是否可按本构式表达，不证明实际存在父子关系或值域包含。只有后续领域采纳/求真才交概念业务裁决。

[初始化详细设计](20261014_INIT-LANGUAGE-KNOWLEDGE-SEEDS_功能词与五种基础语言知识初始化详细设计_v0.1.md) §3 的原句是“特征概念必须同FT类型根，不能跨根解释为上下位”。本叶落实其中的同根联合类型约束；同时遵守 2340/7240 的主张与事实分账：同根但互为兄弟的两个概念也可被调用方组成归类主张，其生成成功不证明归类为真。`概念_特征类::比较单特征概念` 在此只提供正式同根类型判定，不用其“左/右为上位”结果作生成前置。

已发布 `生成基础语言表达` 在 `海中鱼巣/业务/表达.基础语言.h/.cpp`，现能枚举完整语言知识、匹配 `目的/操作/作用域/角色类别`，对两个存在概念选择正式同语种名称，展开基础结构并返回 UTF-8 文本与标量对齐。现行 S02 知识允许两个概念角色各为存在概念或特征概念；业务实现当前把非存在概念返回 `能力未支持`。`概念_特征类::获取特征概念`能正式读取特征概念及其名称关系引用；`概念_名称关系类`和 `新_词类`公开入口已支持两类概念名称。当前生成入口无其它生产调用者；无须改变语言 owner、词条/名称 owner 或工程登记。

## 2. 冻结接口、位置与依赖

仅修改 `海中鱼巣/业务/表达.基础语言.h/.cpp`。公开函数保留名字与结果 DTO，签名扩为：

```cpp
基础表达结果 生成基础语言表达(
    const 基础表达请求& 请求,
    const 新_语言类& 语言服务, const 新_词类& 词服务,
    const 概念_名称关系类& 名称服务,
    const 概念_存在类& 存在概念服务,
    const 概念_特征类& 特征概念服务);
```

头文件仅前向声明 `概念_特征类`，源文件正常包含其头；业务借用只读引用，不取得其所有权、生命周期或写权限。当前无生产调用点需要迁移；若执行 S0 发现新增调用者，先暂停受影响切片并退回计划支撑修订设计、允许文件白名单及索引精确版本，修订发布并重新 S0 后才能迁移已确认调用点，不留下无法链接的旧签名壳。禁止新增第二生成入口或 DATA 层反向依赖业务。

请求、结果、`基础表达状态`、知识候选额度、名称额度、输出标量额度、失败空载荷及对齐语义均沿用 S02 已发布合同；不加新字段/状态。`基础表达参数`中的两端仍用 `基础表达参数种类::概念`、`新语言知识角色类别::特征概念`和正式稳定编码，允许各自可选的明确名称关系。混合存在/特征概念参数不属于本叶成功范围，保留现行 `能力未支持`；不把两类概念强制视为可互换。首叶已支持的两端存在概念结果不得回退。业务借用 `概念_特征类::比较单特征概念`的只读结果，且只读其同根资格和漂移，不发布新的概念关系。

## 3. 执行顺序与非成功

1. 沿用现有完整候选枚举和规则匹配。只在同一正式知识身份完整匹配后检查两端均为存在概念或均为特征概念；两个存在概念沿原实现，两端特征概念进入本叶。其它操作、目的或结构继续按当前能力边界返回。
2. 对特征概念分支，先分别调用 `获取特征概念`核验两端正式身份，再调用 `比较单特征概念(主体,归类概念)`。`已完成`且 `特征类型根`有效、关系为同一/左为上位/右为上位/具有共同上位之一，表示两端同根，允许继续；`已完成`且 `无可比关系`表示跨根，返回 `输入拒绝`。这里不要求关系必须为“右为上位”；即使比较结果为“具有共同上位”，也只说明类型可比，不证实本次归类主张。`值不存在`映射 `引用不可读`，`资源失败`映射 `工程未完成`，`入口拒绝`或`规则不支持`映射 `能力未支持`，`内部不一致`及其它不可能的状态/完成形状映射 `内部不一致`。保存比较结果的状态、类型根、关系及最近共同上位作为本次只读复核材料，不持久化。
3. 把现有业务私有 `名称快照` 的概念材料改为类型化 `std::variant<存在概念信息, 特征概念信息>`；`读取名称`按绑定类别分别调用 `获取存在概念`或 `获取特征概念`，核对返回节点与类别，不直接查基础数据集。概念不可完整读回返回 `引用不可读`，不降格成缺名称。名称选择保持 S02 合同：查询该概念的完整名称关系组，按词条语言过滤；目标语言零名称返回 `缺名称`，一名称自动选，多名称无明确选择返回 `名称待选`，有明确选择须核对端点。任何列表/端点资源故障与漂移保留原状态类别。
4. 按所选**正式语言知识**的有序固定词/名称角色项生成片段，并回传规则、词条、名称关系和参数标量范围；不得硬编码“是一种”或拼接类型根名称。成功回显本次实际选用的两条名称关系。输出预算不足或任一片段失败不返回残句。
5. 结束前复读两个概念的同类型完整信息、全部名称关系组、已选关系与词条、同根比较结果及语言知识候选；比较结果的状态、类型根、关系或共同上位变化，以及其它所用材料变化，均返回 `读取漂移`，工程故障独立返回。业务全程只读，跨 owner 分步读回不构成共同事务或事实快照。生成成功不证明归类主张真实、文本已保存、已发送或被理解。

正常成功需两端正式特征概念可读且同 FT 根、可选定的目标语言名称均可读、唯一知识规则匹配、输出额度足够。无法读概念、跨根、无名称、多名称未选、知识缺失/多规则、候选/名称/输出额度不足、读取漂移、资源失败分别沿用现有具名非成功；不能把 `比较单特征概念` 的上位/共同上位结果当作归类真假结论。
