## 1. 目标和真实边界

已有正式词条 W、概念名称挂接实例特征 F、自然语言场景及名称联合写入。本叶让它们被需求目标、真实方法参数、任务取参和动作记录正确消费。W 仍是词条，F 仍由名称关系的唯一写入链维护；不复制普通存在，不造布尔归类镜像，不在参数绑定时写概念名称关系。

本叶是提供者及其现有消费者的整体接线，不创建无材料可用的归类写回本能，也不宣称词典学习闭环完成。归类材料的正式承载、查词典与语言转换、写回本能及原句继续由紧邻后继闭合。独立的隔离词条写入图未实现前，模拟遇到词条参数报告具名能力缺口，不生成结果、不借用现实 W、不调用现实名称 writer；本叶只使新增类别在读取和采样分派中安全识别，不声称支持词条模拟。

上层根据本次需要读取当前材料，不增加整组旧 DTO 比较、跨 owner 保护全集或写后互证。L1 零发布冲突由拥有完整输入的最外层释放本轮准备后重读重算；没有固定重试次数错误出口。成功发布的动作与写入不得重放。目标确实已删除属于当前事实缺失，资源和结构故障独立处理。

## 3. 正式类型与范围

### 3.1 词条范围

在概念 owner 登记具名范围：基础范围概念原语 `具名领域身份`，判定编号16，正式槽516，定义参数严格为 `{16}`。14/514与15/515已有其它用途，不复用。范围含义为“由词条 owner 正式读取为 W 的信息节点”；空挂接集合也属于该范围。它不是空概念，也不是完整词条内容的结构投影，不要求把语言、词面、规范化合同迁移成FT。

新增 `概念_存在类::建立或取得词条身份范围概念() noexcept` 返回 `正式结构概念结果`，`读取词条身份范围概念保护() const noexcept` 返回现有保护结果供旧签名适配。实现只读当前定义；保护载荷不得被新消费者拿来做整组旧快照相等门。建立在L1零发布变化时整轮重读，已有定义按固定槽读取，不另建平行范围。该范围形成先于需要词条类别的声明与装配。

### 3.2 参数与持有者

`新方法参数信息类型::词条 = 3`；已有数值1、2不改。按位引用仍是序号、类型、信息编码。方法持久类别字段保存槽516正式概念引用；任务及历史运行内现有数值类别格式扩展为1..3，不改旧值。

词条位置是可持有特征的信息存在位置。既有字段 `必需特征类型组` 允许词条位置声明FT1501；`所属存在位置` 保留名字和存储，语义为特征持有者位置，可指向普通存在或词条位置。通过统一纯类型分派判断“可持有特征”，不要把所有 `类型 != 存在` 都解释为特征。W仅支持本叶已有挂接F，不能接受任意附属FT。

词条参数范围本叶只接受槽516。其它范围正常不相容，不拿存在根或词条命名的概念猜类型。范围相容只证明W身份和规格所需F；F的值、是否非空、是否包含C分别由C/R及需求目标比较。W自己的概念名称挂接集合不是W的类别概念。

## 4. Owner 接线与读取

方法、需求、任务各 owner 增加线程启动前一次 `装配词条读取(const 新_词类&)`；动态 owner 使用§10.1带词条范围的签名。均保存非拥有 const 引用；重复同实例允许，运行期更换不支持。世界树现有词服务覆盖消费者寿命，停线程并join后回收。不得从持有特征准备锁的路径回调词条或其它owner。

`方法参数场景::读取词条参数挂接(uint32_t) const noexcept` 返回 `新方法词条参数读取结果`（§10.1）：仅在绑定类别=词条时调用W owner；登记场景无实参。执行读取W当前材料；模拟在隔离提供者未实现时返回明确未支持，由调用边界保留缺口，绝不走现实owner。以独立参数读取状态区分未绑定、未支持和信息不存在，不扩张词条owner的查询状态。

`读取存在参数特征` 的历史函数名保留，但接受可持特征的W位置：从W读F，再从特征owner读定义/current/材料；不扫描名称列表证明F，不用旧W DTO判等。独立F参数按其所属位置精确取F。缺F、多个同FT或物理错误分别按真实合同处理；不把错误当未归类。

## 5. 需求目标与当前求值

自我仍确认D入树。完整键仍是目标信息编码、FT及值合同或方向，不增需求种类。需求主体、双根角色仍必须是既有自我/人类等普通主体，不因目标支持W而放宽主体。

目标定位按已支持对象分派：既有普通存在/场景保留，W经词条公开读取取得挂接F。`建立或取得普通需求`、受限子需求准入、列表查重和读取、`复核筹办资格`、`复核当前满足`、任务按目标收集候选都使用同一语义。只改目标分支，服务对象、执行主体等分支不放宽。没有新增公开任意节点写入口。

先天需求类别槽1的“需求目标存在”项由槽401合法存在改为槽405正式信息身份；其它项不改。现有目标FT本来就是信息对象引用，不改物理材料、不迁移D编码。已有先天定义在概念owner里按精确旧项原地替换该内容范围，保留概念、子项和需求身份；只接受已知旧形状或新形状，不用无条件覆盖。L1原子替换冲突重读；零发布才重试。这是现行0050/3100统一目标的实现，不生成另一套词条需求概念。

需求直接内容的目标引用投影须识别W；在 `正式内容值种类` 末尾追加 `词条引用=9`（原1..8不变），禁止继续让W进入普通存在reader。判定槽405只需要正式信息引用；槽401仍不能因此接受W冒充普通世界存在。既有普通目标的值、方向、引用内容路径不改。

W归类目标采用FT1501下的概念集合条件：`至少一个概念=true`，比较关系沿该类型现有满足规则。空准确集合为未满足，当前值未知为材料不足；有合法概念时满足。最终由特征owner读当前值比较，方法调用成功码和名称写回回执不代替这一判断。删除最后名称后再读自然回到未满足。

## 6. 方法、任务及直接调用消费者

方法头登记、规格持久读写、结果组、共同条件、参数关系及实际绑定均识别词条类别。方法头的作用概念使用正式词条范围；涉及FT含FT1501；不要求W已经归类。读取类别不为每次绑定核验全部其它类别快照。

任务优先按当前D中已明确的目标W绑定作用对象，F按该W定位；其它词条参数若需枚举，调用词条owner的正式按语言候选读取并保留全部候选，不取第一项、不扫描普通存在。候选范围及可见语境由既有任务约束限定；没有定位或可限定枚举范围时保留参数缺口，不全词库强行补一个值。

任务保存的规格、冻结参数、条件/结果引用、直接调用身份的建立与读取须统一新增类别。条件同一/不同关系按信息引用身份解释，集合成员关系仅在现有集合规则支持时使用，不把概念集合成员当词条实例。结果作用W的FT通过对应参数或具名目标定位，沿现有真实状态读取，不凭类型类别建立预测结果。

模拟/学习所有遇到 `词条` 的旧二分支须显式识别：未支持的隔离构造保持方法知识缺口，不进入特征分支、不复制现实W，不伪造长期条件结果对。现有E/F模拟不改。真实W支持与隔离W支持分别报告。

## 7. 动作和场景

新增明确的词条动作目标种类，保留旧1..3的语义和数值。词条目标有独立字段/类型分派，不能把W装进普通目标字段骗过存在reader。请求包含执行主体、动作定义、执行来源、W、可选F和UTC；由动态owner确认目标F属于W，来源仍为正式X或现有直接调用身份。

动作概念的参数类型、方法投影、动态创建、持久读回、按来源复用与结果关联同叶贯通。动作先记录，再由将来的本能经名称owner修改W.F；本叶不引入写F旁路。动作挂执行主体所在场景；W的状态及变化动态仍留在语言场景。跨世界只作动作目标/导致变化引用，不增父子或场景成员边。任务/方法治理动作保持原规则。

## 10. 精确新增合同与迁移落点

### 10.1 参数读取DTO

新增在 `新_方法参数场景.h`：

```cpp
enum class 新方法词条参数读取状态 : std::uint8_t {
    已读取=1, 未声明, 参数未绑定, 信息类型不符,
    参数已失效, 能力未支持, 依赖未就绪, 资源失败
};
struct 新方法词条参数读取结果 final {
    新方法词条参数读取状态 状态=新方法词条参数读取状态::参数未绑定;
    std::optional<新词条挂接信息> 信息;
};
```

包含现有词条头以复用载荷；新动态头只前置声明词类，避免词→场景→动态→词的包含环。参数场景构造尾部追加 `const 新_词类* 词条读取 = nullptr`，由方法owner传入，不开放任意外部构造。真实W实例读取只有此owner指针来源；登记场景返回未声明；无绑定返回参数未绑定；当前W已删除返回参数已失效；模拟提前返回能力未支持，不能透过该指针读取现实W。

方法、需求、任务的装配签名为 `void 装配词条读取(const 新_词类&) noexcept`，类型范围由其原有概念服务取得。动态的签名为 `void 装配词条读取(const 新_词类&, 稳定编码 词条范围概念) noexcept`，由启动已取得结果提供并保留正式引用，不在动态内按名称反查范围。装配仅保存只读服务与固定范围，首次生产装配在线程启动前；已有普通世界消费者可不使用W路径，但不允许未装配却成功读取W。

现有 `新方法参数特征读取状态` 在末尾追加 `能力未支持`；其历史读取存在参数特征入口遇到模拟W时使用该值，不能借未声明或特征未取得掩盖能力缺口。

### 10.3 动作格式

`新动作目标种类::词条=4`。新增 `新词条动作动态建立请求`，字段为执行主体节点、动作定义节点、动作来源节点、目标词条节点、optional目标特征节点、动作时间。新增公开 `新_动态类::建立词条动作动态(const 新词条动作动态建立请求&) noexcept`，返回现有 `新动态建立结果`。内部复用同一动作构造/来源查重/概念形成链，不复制另一动作仓。

`动作参数对象类别::词条=9`；`动作概念角色` 追加 `optional<稳定编码> 词条范围概念节点`，W角色只有这一范围，不把槽516塞进旧的普通存在概念节点；普通和治理角色的旧字段原义保留。`动作方法投影请求` 追加 `optional<稳定编码> 词条目标范围概念节点`，与普通目标概念和两种治理目标互斥。投影的作用目标类别为词条、范围为槽516，保持真实方法及有序参数引用。`概念_动态类` 的参数、目标类别读写及定义比较接受新增值。有序动作定义含W角色/参数时采用新增格式5，显式编码词条范围和参数类别3；无W时继续沿现格式生成，旧格式2/3/4按旧布局读取，其整数类别界限1/2不放宽。格式5覆盖同一含W定义的所有角色和参数，读写布局一致；新字段进入定义相等/查重。W角色范围调用词条具名范围读取，不调用普通存在概念reader。既有动作不重写。

格式5精确布局冻结如下，数字形状与引用字段分别编码：

1. 形状前缀为 `[-1, 5]`，随后依次为原七项头：执行主体对象类别、作用目标对象类别、有主体角色、有普通目标概念、有目标角色、有目标FT、参数数目；再追加第八项 `有词条目标范围`（0或1）。随后每个有序参数固定三项：`序号、必需FT数量、所属存在位置`。因此最小头长为10，参数头总长为 `10 + 3 × 参数数目`；信息关系格式`[-2,1]`不扩张。
2. 单值字段新增 `动作词条目标范围字段`，有词条目标范围时恰好引用槽516，否则无该字段；它不占 `动作规格引用字段` 的序位。原主体概念、普通目标概念、角色及FT字段不换含义。词条目标的普通目标概念字段必须为空；执行主体仍为普通存在。
3. `动作规格引用字段` 按参数顺序保存 `类别概念、范围概念、必需FT组`；词条参数的类别及范围均引用槽516。不能把整数3写进概念引用。每个参数消费 `2 + 必需FT数量` 个引用；读完不得余留形状或引用项。
4. 格式5只用于含词条目标或词条有序参数的定义，且有序参数数目大于0。本叶不新增无有序规格的词条动作格式。读取旧2/3/4时仍拒绝词条类别及词条目标范围字段；格式4的必需FT与所属位置解析同时适用于5。无W定义继续产生格式4，旧记录不重写。
5. 新字段加入定义允许字段、保护/封存引用、完整读取及定义相等判定；形状的存在标志须与单值字段一致。上述是编解码自身的合法布局处理，不追加上层跨时点快照判等；读取遭遇底层正常变化时重读本次材料。

### 10.5 实时变化的处理边界

正常并发变化不是方法失败、需求不满足或工程错误。每次调用先读本次需要的最新数据；只有L1原子发布拒绝且确认零发布时，才释放本轮锁及准备对象，从原始稳定定位重新读取、计算并提交，不沿用旧DTO或已失效的封存片段，不设置“重试若干次后返回错误”的出口。等待期间必须让出所持业务锁，不能在锁内阻止另一更新者完成。

纯读取需要多个材料时按L1已有一致读口获取，不增加上层全集复核。底层报告本轮读取失效时丢弃未完成的计算并重新读取。新读结果显示值已改变，就按新值进行目标求值、参数选择或后续处理，不把“与上次不同”归为错误；相关任务已有停止机制时仍服从停止，不无限阻止停止收束。

已发布的写入、已记录的动作不能为了取得更新快照而重复执行。发布后再读只观察当前事实；后续状态变化不撤销此前真实发生的动作。对象确已删除、依赖尚未装配、能力尚未实现及真实资源/结构故障，分别沿各自正式合同处理，不能混称并发变化，也不能用循环掩盖真实故障。
