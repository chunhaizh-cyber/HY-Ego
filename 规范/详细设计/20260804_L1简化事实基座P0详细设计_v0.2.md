# L1 简化事实基座 P0 详细设计 v0.2

修订基线：`af9957faeba7a5152b88f244185ba7ca439c9574`

本版本不可变替换 v0.1，修订具名问题：`DRIFT-L1-SIMPLIFY-P0-READ-AUDIT-RECOVERY-CONTRACT`。

## 1. 目标、范围和完成边界

P0 建立不接入运行期上下文的独立 L1 三类事实基座：节点、关系和值共用稳定编码，由一次完整写集原子发布一个事实代次。P0 公开当前读取、历史读取、审计读取、完整快照和两阶段恢复候选入口；所有结果均为调用方拥有的值式副本。

P0 不接入世界树、特征、状态、需求、任务、方法、SQL、材料文件或运行期上下文；不删除旧四仓、节点直接五仓、旧句柄或旧版本 DTO。代码候选、编译、自检和 API 矩阵通过不等于迁移或生产能力完成。

## 2. 当前事实、能力复用和修订裁决

4015 v0.2 已冻结：

1. 节点、关系和值的三类事实模型与非零永久稳定编码；
2. 当前、历史、审计、恢复四条读取路径显式分离；
3. 当前组合读取首末事实代次相等，否则一次重试后返回事实代次漂移；
4. 恢复必须保留三类事实、永久编码占用、属性槽、关系端点、幂等账和审计证据。

旧四仓、节点直接五仓和旧对象版本 DTO 不复用。现有 4040 候选确认 / 逆序撤销 / 最后发布能力只复用事务语义，不复用旧事实 DTO 或旧仓库类型。P0 新建独立 L1 文件，避免旧接口兼容壳和第二权威。

## 4. 基础 DTO 与原始值材料

### 4.1 基本类型

```cpp
struct 稳定编码 final { std::uint64_t 值 = 0; };
struct 写集本地键 final { std::uint32_t 值 = 0; };
struct 写集幂等键 final { std::uint64_t 值 = 0; };
struct 独立材料引用 final { 稳定编码 编码; };
using 事实引用 = std::variant<稳定编码, 写集本地键>;
using 原始值材料 = std::variant<
    std::int64_t,
    std::vector<std::int64_t>,
    std::vector<std::uint64_t>,
    独立材料引用>;
```

稳定编码和独立材料引用均不得为零；`写集本地键` 只在同一请求内有效，不得出现在任何读回、快照、历史、审计或恢复 DTO。原始值材料不允许空字节、字符串、未注册变体或调用方自定义分支。

```cpp
enum class 节点种类 : std::uint8_t { 普通 = 1, 属性类型 = 2 };
enum class 值表示种类 : std::uint8_t {
    I64 = 1, I64组 = 2, U64组 = 3, 独立材料引用 = 4
};
```

属性类型节点的 `值表示种类` 与新值材料分支必须精确匹配；L1 只验证形状，不解释业务值域。

### 4.2 三类事实和槽

```cpp
struct 属性槽 final {
    稳定编码 属性类型节点;
    稳定编码 当前值;
};

struct 节点事实 final {
    稳定编码 编码;
    节点种类 种类 = 节点种类::普通;
    std::uint64_t 创建事实代次 = 0;
    std::optional<std::uint64_t> 退出事实代次;
    std::vector<属性槽> 当前属性; // 按属性类型编码严格升序
};

struct 关系事实 final {
    稳定编码 编码;
    稳定编码 源节点;
    稳定编码 目标节点;
    稳定编码 关系类型节点;
    std::int64_t 角色或顺序 = 0;
    std::uint64_t 创建事实代次 = 0;
    std::optional<std::uint64_t> 退出事实代次;
};

struct 值事实 final {
    稳定编码 编码;
    稳定编码 所属节点;
    稳定编码 属性类型节点;
    原始值材料 材料;
    稳定编码 来源节点;
    std::uint64_t 创建事实代次 = 0;
    std::optional<std::uint64_t> 退出事实代次;
};
```

当前快照只携带仍有效的三类事实和当前属性槽；历史 DTO 只携带已退出事实；同一稳定编码不得同时出现在两个历史事实种类或重复记录中。

### 4.3 写集和写入结果

```cpp
struct 节点新建项 final {
    写集本地键 本地键;
    节点种类 种类 = 节点种类::普通;
    std::optional<值表示种类> 属性类型表示;
};
struct 关系新建项 final {
    写集本地键 本地键;
    事实引用 源节点;
    事实引用 目标节点;
    事实引用 关系类型节点;
    std::int64_t 角色或顺序 = 0;
};
struct 值新建项 final {
    写集本地键 本地键;
    事实引用 所属节点;
    事实引用 属性类型节点;
    原始值材料 材料;
    事实引用 来源节点;
};
struct 属性槽变更项 final {
    事实引用 所属节点;
    事实引用 属性类型节点;
    写集本地键 新当前值;
};
struct L1写集请求 final {
    std::uint64_t 期望事实代次 = 0;
    写集幂等键 幂等键;
    std::vector<节点新建项> 节点;
    std::vector<关系新建项> 关系;
    std::vector<值新建项> 值;
    std::vector<属性槽变更项> 属性槽变更;
    std::vector<稳定编码> 退出事实;
};
enum class L1写入状态 : std::uint8_t {
    成功 = 1, 精确重复 = 2, 入口拒绝 = 3, 未找到 = 4, 已退出 = 5,
    事实代次漂移 = 6, 幂等冲突 = 7, 资源失败 = 8, 内部不一致 = 9
};
struct L1写入结果 final {
    L1写入状态 状态 = L1写入状态::入口拒绝;
    std::uint64_t 事实代次 = 0;
    std::vector<std::pair<写集本地键, 稳定编码>> 新编码映射;
};
```

写集规范化排序后参与同键同义比较；摘要、索引或记录数量不能替代逐字段比较。成功首次提交分配新编码、替换属性槽、标记退出事实并一次推进事实代次；精确重复不推进代次；其它非成功不返回部分业务事实。

## 5. 四条读取路径及结果合同

### 5.1 当前事实读取

```cpp
enum class L1读取状态 : std::uint8_t {
    成功 = 1, 入口拒绝 = 2, 未找到 = 3, 已退出 = 4,
    属性未设置 = 5, 事实代次漂移 = 6, 资源失败 = 7, 内部不一致 = 8
};
using L1事实副本 = std::variant<节点事实, 关系事实, 值事实>;
struct L1读取结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    std::uint64_t 读取事实代次 = 0;
    std::optional<L1事实副本> 事实;
};
```

`读取当前节点/关系/值(稳定编码)` 各自只返回对应 variant。零编码入口拒绝；有效但不存在返回未找到；只在历史表存在而当前表无该编码时返回已退出，且事实 optional 为空；成功必须带非零读取事实代次和一个完整事实副本。

### 5.2 当前属性读取

```cpp
struct L1属性读取副本 final {
    稳定编码 节点;
    稳定编码 属性类型节点;
    稳定编码 当前值;
};
struct L1属性读取结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    std::uint64_t 读取事实代次 = 0;
    std::optional<L1属性读取副本> 属性;
};
```

节点不存在 / 已退出沿用当前读取分类；节点当前存在但属性槽不存在返回 `属性未设置`；成功只返回当前槽指向的值编码，不返回历史值或值材料。该入口在一把共享锁内完成，首末代次不一致时一次重试，仍漂移返回 `事实代次漂移`。

### 5.3 历史读取

```cpp
struct L1历史事实副本 final {
    稳定编码 查询编码;
    L1事实副本 事实;
    bool 当前有效 = false;
};
struct L1历史读取结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    std::optional<L1历史事实副本> 历史;
};
```

服务入口：

```cpp
L1历史读取结果 读取历史事实(稳定编码 编码) const;
```

它只按稳定编码读取一条完整事实记录（当前或已退出），不返回属性槽表、审计账、幂等账、索引材料或恢复候选。零编码入口拒绝，未知编码未找到，读取成功不改变任何事实。

### 5.4 审计读取

```cpp
enum class L1审计事件 : std::uint8_t {
    提交成功 = 1, 精确重复 = 2, 幂等冲突 = 3, 候选撤销 = 4,
    恢复候选建立 = 5, 恢复候选撤销 = 6, 恢复发布 = 7, 恢复拒绝 = 8
};
struct L1审计记录 final {
    写集幂等键 幂等键;
    std::uint64_t 事件序号 = 0;
    L1审计事件 事件 = L1审计事件::候选撤销;
    L1写入状态 结果状态 = L1写入状态::入口拒绝;
    std::uint64_t 事实代次 = 0;
    std::vector<std::pair<写集本地键, 稳定编码>> 新编码映射;
};
struct L1审计读取结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    std::vector<L1审计记录> 记录组;
};
```

服务入口：

```cpp
L1审计读取结果 读取审计(写集幂等键 幂等键) const;
```

审计组只包含同一幂等键的不可变事件，按事件序号严格升序；无记录返回未找到和空组。审计记录是旁路证据，不得被当前读取、幂等裁决或恢复确认单独当作事实成功。

### 5.5 完整当前快照

```cpp
struct L1完整快照 final {
    std::uint64_t 事实代次 = 0;
    std::vector<节点事实> 当前节点;
    std::vector<关系事实> 当前关系;
    std::vector<值事实> 当前值;
    std::vector<稳定编码> 永久占用编码;
};
struct L1完整快照结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    std::optional<L1完整快照> 快照;
};
```

服务入口：

```cpp
L1完整快照结果 读取完整快照() const;
```

快照只返回一个事实代次内的当前节点、关系、值、当前属性槽（嵌在节点事实）和永久编码占用；不包含已退出历史事实、审计记录、幂等账、索引候选或 SQL 材料。空库成功快照的事实代次为 0、三组为空、永久占用为空。

## 6. 恢复候选、确认和拒绝发布

### 6.1 恢复材料

```cpp
struct L1幂等账记录 final {
    写集幂等键 幂等键;
    L1写集请求 规范化写集;
    L1写入结果 首次结果;
};
struct L1恢复材料 final {
    L1完整快照 当前快照;
    std::vector<节点事实> 历史节点;
    std::vector<关系事实> 历史关系;
    std::vector<值事实> 历史值;
    std::vector<L1审计记录> 审计记录;
    std::vector<L1幂等账记录> 幂等账;
};
enum class L1恢复状态 : std::uint8_t {
    候选已建立 = 1, 恢复已发布 = 2, 候选已撤销 = 3, 无候选 = 4,
    入口拒绝 = 5, 材料不完整 = 6, 事实代次漂移 = 7,
    资源失败 = 8, 内部不一致 = 9
};
struct L1恢复结果 final {
    L1恢复状态 状态 = L1恢复状态::入口拒绝;
    std::uint64_t 事实代次 = 0;
};
```

恢复材料的历史组只能包含已退出记录，不得与当前快照重复；审计 / 幂等记录必须按键唯一且可互证。永久编码占用来自当前快照，必须覆盖当前和历史全部编码。

### 6.2 服务入口

```cpp
L1恢复结果 建立恢复候选(
    const L1恢复材料& 材料,
    std::uint64_t 期望事实代次);
L1恢复结果 确认恢复候选();
L1恢复结果 撤销恢复候选() noexcept;
```

`建立恢复候选` 在仓库隔离副本中执行完整性检查：

1. 当前、历史三类事实分别完整，编码非零且全局唯一；
2. 当前槽唯一并指向当前值，值所属节点 / 属性类型 / 来源均存在且材料分支匹配；
3. 关系端点、关系类型节点和生命周期代次有效；
4. 所有当前 / 历史编码均在永久占用集合中，永久占用没有未解释重复；
5. 幂等账规范化写集完整，首次结果与审计成功事件相互一致；
6. `期望事实代次` 与当前运行期基线在建立时只作写前准入，候选建立不改变当前状态。

任一失败返回 `入口拒绝`、`材料不完整`、`资源失败` 或 `内部不一致`，并保证无候选、零代次变化、零当前事实变化。

`确认恢复候选` 取得独占许可后重新比较当前代次与建立时基线：不等返回 `事实代次漂移` 并丢弃候选；相等则一次替换当前不可变状态，发布目标事实代次为确认时当前代次加一，返回 `恢复已发布` 和新代次。发布后任一读回矛盾进入内部不一致 / 隔离，不逐项回填。

`撤销恢复候选` 是拒绝发布入口：有候选时丢弃隔离副本并返回 `候选已撤销`，无候选返回 `无候选`；两者均不改变当前状态。异常和资源失败不伪装成成功或精确重复。

## 7. 事务、生命周期和错误映射

仓库一把 `shared_mutex` 保护不可变当前状态指针、历史、永久占用、幂等账和审计账。普通写集在独占锁内完成最终代次复核、候选确认和一次替换；读入口只在共享锁内形成值式副本；锁内不调用领域、日志、SQL、文件、回调或其它服务。

正常写入、当前读取、历史读取、审计读取和完整快照均不保存跨调用借用引用。所有非成功业务结果的 optional 为空；审计无记录返回空组；恢复非成功不带事实材料。

异常映射固定：输入无效为入口拒绝，分配失败 / `bad_alloc` / `length_error` 为资源失败，结构互相矛盾 / 未知异常为内部不一致，当前代次变化为事实代次漂移。任何异常路径都不发布、不删除旧当前状态、不清空历史或审计。

## 8. 业务节点—能力—函数矩阵

| 业务节点 | 能力 | 函数 / 入口 | 权威来源 |
| --- | --- | --- | --- |
| 当前事实查询 | 单事实当前读 | `读取当前节点/关系/值` | 当前不可变状态 |
| 当前属性查询 | 槽到当前值投影 | `读取当前属性` | 当前节点属性槽 + 当前值 |
| 历史追溯 | 单编码生命周期读 | `读取历史事实` | 历史事实表 |
| 幂等审计追溯 | 事件旁路读 | `读取审计` | 不可变审计账 |
| 当前一致快照 | 同代次值式复制 | `读取完整快照` | 当前状态 + 永久占用 |
| 恢复准备 | 隔离完整性验证 | `建立恢复候选` | 恢复材料 |
| 恢复发布 | 代次复核后一次替换 | `确认恢复候选` | 当前基线 + 隔离候选 |
| 恢复拒绝 | 丢弃隔离候选 | `撤销恢复候选` | 候选生命周期 |

## 9. P0 自检矩阵与完成边界

专项自检 `L1-SIMPLIFY-P0-S01` 顺序 270，目标为 S0 顶层数量 `N+1`。至少覆盖：

1. 三类事实、四种原始材料和属性类型匹配；
2. 当前节点 / 关系 / 值、属性槽、历史事实和审计记录分别读取，DTO 不交叉；
3. 空库和非空库完整快照字段、永久占用和单一事实代次；
4. 恢复材料完整、缺项、重复编码、槽矛盾、关系断裂、幂等 / 审计互相矛盾；
5. 建立候选不改变当前，确认一次发布代次加一，漂移确认丢弃候选，撤销拒绝发布；
6. 当前、历史、审计、恢复非成功分支均无部分业务事实；
7. Debug / Release、模块依赖、旧仓 import 零命中和顺序 270。

P0 只证明新 L1 内核及上述值式合同进入工程；不证明任何运行期消费者迁移、旧基座删除、SQL / 材料持久化或领域服务验收。
