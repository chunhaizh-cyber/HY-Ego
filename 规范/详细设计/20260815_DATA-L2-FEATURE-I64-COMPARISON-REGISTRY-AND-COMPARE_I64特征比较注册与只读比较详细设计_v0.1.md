# DATA-L2 I64 特征比较注册与只读比较详细设计

日期：2026-08-15
版本：v0.1
身份：`DATA-L2-FEATURE-I64-COMPARISON-REGISTRY-AND-COMPARE`

## 1. 目标与完成边界

在唯一 `L2特征结构服务` 内补齐 4130、4180 要求的第一份可施工比较能力：保存并读取“特征定义 + 比较用途”的唯一当前 I64 比较注册，并按该注册对两份不可变 I64 输入材料执行只读比较。

本叶只支持 `标量有序比较与安全差异`，服务于目标判断和状态迁移两个结构用途。它不实现向量、角度、旋转、集合、空间、形状或时间序列算法，不形成抽象目标状态模板，不写状态、动态、二次特征、因果、需求、任务或方法事实。

完成必须同时满足：

1. 比较注册的结构类型登记、增改退、当前 / 历史读取和只读比较 ABI 已进入现有两个特征生产文件；
2. 注册由现有特征定义 owner 独占写入，零第二 owner、第二服务和第二写入口；
3. 同一“特征定义 + 用途”在一个截止至多一个当前注册；
4. 比较只读取注册并计算，零机器事实写入；
5. 4180 的稳定状态、拒绝原因、结果要求、左右角色、单位 / 维度 / 分量角色、误差、版本和溢出合同在 I64 范围内机械闭合；
6. 根工程 Debug / Release 构建和静态合同检查通过；不另建专项验收，真实合法消费者运行留待实际使用时判断。

### 2.3 归属裁决

比较注册是特征定义的结构解释合同，唯一归属现有特征定义 owner；比较函数是 `L2特征结构服务` 的只读能力。禁止建立 `L2特征比较服务`、独立 owner、普通应用第二 getter、跨服务通用比较器或调用方算法选择入口。

本叶只实现 I64 标量。4180 中其它算法族数值可以进入公开枚举以保持正式词汇一致，但注册 helper 和服务写入口只接受 `标量有序比较与安全差异`；其它算法不得以 `未实现` 注册为当前事实，也不得由材料形状猜测。

## 4. 物理结构与唯一 owner 事务

### 4.1 结构类型登记写集

复用现有特征定义写入端口，固定新建三节点：

| 本地键 | 含义 | 节点种类 | 值表示 |
| --- | --- | --- | --- |
| 1 | 比较注册归属关系类型 | 普通 | 空 |
| 2 | 比较注册 U64 合同属性类型 | 属性类型 | U64组 |
| 3 | 比较注册 I64 合同属性类型 | 属性类型 | I64组 |

写集固定为 3/0/0/0/0。幂等域使用新的服务私有常量，不能复用关系类型、值类型、定义属性类型或任何旧比较 G8 域。首次 / 重复、代次、映射、当前权威读回和缓存规则机械沿现有三类类型登记；缓存只保存定位，公开读取必须回到 L1 当前事实。

### 4.2 注册新增写集

新增注册在同一特征定义 owner 事务内固定形成：

- 一个普通注册节点；
- 一条“特征定义 -> 注册节点”的归属关系，关系类型为登记项，角色=1；
- 一个 U64组属性值及当前槽；
- 一个 I64组属性值及当前槽。

U64组按固定位置编码：合同版本、规则版本、用途、算法族、算法版本、原始类型、左角色、右角色、差异方向、单位编码、维度编码、分量角色编码、允许结果位、边界包含、量化规则、误差合同版本、首次幂等身份、首次期望事实代次。I64组固定四项：误差预算存在位、误差预算值、相等容差存在位、相等容差值；存在位只能为0或1，不存在时对应值必须为0。

两个值的来源节点固定为目标特征定义。禁止写业务名称、用途文本、目标值、状态值、需求身份、调用方算法选择、日志或比较结果。

新增写前以请求非零守卫一次一致读取：结构类型登记、完整特征定义、单位 / 维度 / 分量角色三个当前普通节点，以及该特征定义全部当前比较归属关系。相同“特征定义 + 用途”已有一个当前注册返回 `引用冲突`；多于一个属于 `内部不一致`。写前扫描结果与提交之间由 L1 期望代次最终裁决。

### 4.3 替换与退出

替换在一个 owner 写集中退出旧注册节点、旧归属关系、旧 U64/I64 值，并建立一个全新注册节点、关系和值；旧注册身份永久保留且不可复用。新旧用途必须相同，调用方不得借替换迁移到另一 key。

退出在一个 owner 写集中退出注册节点、归属关系和两个值；请求必须回显四个精确稳定编码。特征定义退出前必须确认不存在当前比较注册；本叶必须把该引用保护加入现有 `退出统一特征定义(...)`，不得留下活动注册指向退出定义。

新增、替换、退出都使用 `L2结构幂等身份` 的完整请求语义：同键同义返回首次结果，异义返回幂等冲突；资源失败或发布未知不得换键重试。L1 当前没有独立“发布结果未知”公共状态，本叶不得新增状态；只能保持原完整请求供调用方重放，并按 L1 实际结果映射资源失败或内部不一致。

### 4.4 当前与历史读取

当前读取以非零守卫一次取得：结构类型登记、特征定义、该定义的当前归属关系组、候选注册节点、两个当前属性值。零项返回 `未找到`；一项完整返回 `已读取`；同用途多项、坏端点、错 owner、错类型、坏向量、混代或退出半结构返回 `内部不一致`。不得过滤坏项后伪装未找到。

历史读取按注册身份和显式非零历史截止读取节点、归属关系和两值的历史投影；只返回该截止可见的完整注册。历史截止大于请求头守卫、身份复义或半结构均拒绝 / 内部不一致，不拼接当前值。

## 5. `比较特征(...)` 控制流

在现有 `L2特征结构服务` 原位增加：

```cpp
L2特征比较结果 比较特征(const L2特征比较请求& 请求) const;
```

固定流程：

1. 纯值校验合同版本、非零守卫、请求身份、用途、两输入和要求结果位；失败返回 `入口拒绝` 及 4180 对应拒绝原因，零截止、零注册和零比较载荷。
2. 以请求守卫按“特征定义 + 用途”读取唯一当前注册。未找到 / 已退出映射 `未注册`，携带本轮非零事实截止；注册不唯一映射 `内部不一致/注册不唯一` 且不暴露候选。
3. 可选预期算法族 / 版本只作漂移门禁；与当前注册不等返回 `版本漂移/算法版本不匹配`，可回显当前注册身份、版本和截止，比较载荷为空。
4. 校验输入材料的原始类型、单位、维度、分量角色、左右角色、生命周期和版本；不一致按 4180 映射入口拒绝或版本漂移。不得临时交换左右值。
5. 安全读取两个 `std::int64_t`。排序三态用分支比较，不做减法；相等容差若存在，只影响具名等价关系，不改变排序三态的原始三态结果。容差命中使用无有符号溢出的安全差距比较；`INT64_MIN` / `INT64_MAX` 两端不得先相减或取可能溢出的有符号绝对值。排序非零但落入容差时，排序三态仍保留精确方向，具名关系可以是目标达到 / 迁移等价，两者语义不得混写。
6. 差异固定为 `右值 - 左值`。先做可表示性检查；请求差异且不可表示时整项 `入口拒绝/差异不可表示`，不得返回半成功排序或关系。没有请求差异时不得为形成排序执行危险减法。
7. 按用途形成具名关系：目标判断比较当前事实 / 目标状态；状态迁移比较前状态 / 后当前事实。`实际结果位` 必须逐位等于请求结果集合；排序三态、具名关系、差异材料按位存在，未请求项为空。
8. 形成已比较结果，回显注册、算法版本、上下文、误差量化和两输入版本；用公开成功谓词复核。坏成功形状收敛为 `内部不一致`，不返回半载荷。
9. `std::bad_alloc`、`std::length_error` 映射资源失败；其它异常映射内部不一致。函数不重试、不改守卫、不写 L1、不发布比较结果。

状态 / 载荷矩阵逐字服从 4180 第 5.1 节。`L2特征比较结果::成功()` 只允许已比较 / 无拒绝 / 非零截止 / 完整注册与版本 / `实际结果位` 为1—7且无未知位 / 对应请求项完整且未请求项为空 / 上下文和回执完整。

## 7. 状态映射与并发

注册 CRUD 使用共同 `L2结构状态`：成功写只允许已提交 / 精确重复，读取只允许已读取；未找到、已退出、漂移、幂等冲突、引用冲突、许可拒绝、资源失败和内部不一致保持独立。全部非成功 optional 为空且变更代次为空。

结构类型登记使用专用登记状态，机械沿现有特征登记实现。比较结果只使用 4180 专用稳定状态，不把 `L2结构状态` 数值混入。

服务私有互斥量只保护结构类型定位缓存；注册唯一性与原子发布由 L1 期望代次和 owner 写端口裁决。公开入口不得持锁调用日志、I/O、线程等待或其它上层服务；不得共享锁升级、忙重试或 sleep。
