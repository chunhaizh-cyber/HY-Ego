## 1. 目标、范围与完成条件

本设计只退役服务合同记账及其被动时间维护体系，不建立替代账：

```text
删除合同、预算、30% / 70%、准备、进展、到期和服务维护历史的生产入口
-> 删除 Gseed、维护游标、基础快照和单完整秒被动维护链
-> 服务请求只归入普通需求、任务、方法、正式结果
-> 结果继续形成状态、动态、因果认知证据
-> 安全根只由主动安全结算改变
```

完成必须同时满足：

1. 生产装配和启动不再创建、恢复、读回或维护服务合同专属事实、历史、游标或 Gseed；
2. 自我线程不再调用合同驱动的服务 / 生存被动维护；
3. 公开 DTO、骨架函数、工程登记和专项测试不再暴露退役体系；
4. 运行期只读查询只读取同一 `G0` 的安全根当前值、`A=0/1/>1` 控制态和服务根普通当前值；
5. 安全根定义的新载荷不再写被动服务维护规则槽，既有九项载荷仍能由原解码位置识别并忽略该退役槽；
6. 旧持久数据不被物理擦除，也不能重新进入当前写入、恢复或调度；
7. 通用当前值、状态、动态、因果、主动安全、分层安全和独立正式时间能力保持可用。

## 2. 当前事实与复用裁决

当前代码有一条独立于普通需求闭环的第二账务链：

```text
普通应用装配签发游标 / 合同事实 owner
-> 启动读取服务维护历史 v2
-> 建立完整秒边界
-> 显式激活 Gseed / 维护纪元
-> 读回游标 v4
-> 自我线程每轮调用“维护服务与生存安全”
```

该链还通过运行期只读查询重复读取四次同一主体状态，分别命名为合同、准备、进展和到期组；这既不能证明四类业务事实，也形成重复记账和重复读取，应整体退出。

复用裁决如下：

| 能力 | 裁决 |
| --- | --- |
| 普通需求、任务、方法、正式结果 | 保留，作为真实服务请求唯一业务路径 |
| L2 特征当前值与状态 / 动态 / 因果 | 保留，作为当前坐标和认知证据 |
| 6100 主动安全结算、6140 分层安全维护、6150 安全门控 | 保留；安全根无被动服务维护写入者 |
| `海中鱼巣/领域/服务.完整秒时钟.ixx` | 保留；它是独立正式时间能力，不因旧消费者退出而删除 |
| 服务根 | 保留为普通根当前坐标；本计划不新增自动生产者 |
| 服务合同、准备 / 进展 / 到期、维护历史、Gseed、游标、单秒衰减 | 删除生产 ABI 和装配，不复用、不改名 |

当前代码没有已经接线的“人类服务请求专用入口”。本设计只证明第二账务入口退出，不把缺失入口伪装成已实现，也不顺手新增服务 API。

### 4.3 运行期本能根当前快照

`海中鱼巣/领域/运行期只读查询.数据.h` 与 `海中鱼巣/领域/组合.运行期只读查询.ixx` 将 `生存服务*` 公开 ABI 原位收缩并重命名为本能根当前快照：

```cpp
enum class 本能根当前快照状态 : std::uint8_t {
    已形成 = 1, 请求拒绝 = 2, 尚无权威 = 3,
    材料缺失 = 4, 当前性漂移 = 5,
    资源失败 = 6, 内部不一致 = 7
};

struct 本能根当前快照请求 final {
    std::uint32_t 合同版本 = 运行期只读查询合同版本;
    std::uint64_t 运行代次 = 0;
    std::uint64_t 事实范围版本 = 0;
    L2存在身份 唯一自我;
    std::uint64_t 共享事实截止G0 = 0;
    L2特征定义身份 安全根特征定义;
    L2特征定义身份 服务根特征定义;
};

struct 本能根当前快照 final {
    生存安全根当前值 安全根;
    std::int64_t 服务根当前值 = 0;
    std::uint64_t 事实截止代次 = 0;

struct 本能根当前快照结果 final {
    本能根当前快照状态 状态 = 本能根当前快照状态::材料缺失;
    std::optional<本能根当前快照> 快照;

```

公开函数固定为：

```cpp

    const 本能根当前快照请求& 请求) const noexcept;
```

实现只进行两次同 `G0` 特征当前值读取：安全根取 `A/L/H` 并派生 `A=0` 终止、`A=1` 休眠、`A>1` 主动运行；服务根只取普通 I64 当前值。删除完整秒、时间纪元、上一结算秒、数量预算、四组状态及四次重复读取。无合法定义、无唯一当前值或材料类型错误返回结构化失败，不以零值伪造权威。

## 5. 数据、事务、版本与生命周期

- 本计划不创建新服务合同事务，也不迁移或物理删除旧持久值；删除生产模块只使其失去当前装配和公开写入口。
- 旧维护游标中的时间纪元、安全变化水位等字段只是退役维护链的协调副本，不是时间或安全权威；删除游标后不恢复这些副本。正式时间与安全事实继续从各自现行 owner 读取，因此无需游标 v5。
- 普通需求、任务、方法和结果沿各自现有 owner、版本、事务与读回规则运行，本设计不改变其 ABI。
- 安全根新定义仍走现有 owner 和原子发布；仅载荷去掉退役槽。八 / 九项解码都必须在原读取事务内完成，失败不产生写入。
- 运行期本能根快照是值式只读投影，不保存副本、不取得 owner、不推进 `G0`。
- 服务根当前值在本计划中只有读取者，没有新增自动写入者；缺少当前值时返回失败，不用时间、次数或固定值补位。

## 6. 启动、重启与失败矩阵

| 场景 | 预期结果 | 写入边界 |
| --- | --- | --- |
| 新数据普通启动 | 不装配合同 / 游标模块，继续完成本能根和安全根初始化 | 无合同专属写入 |
