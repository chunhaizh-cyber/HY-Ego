## 3. 七项修订方向的收敛

| 项目 | 收敛方向 | 必须保留的边界 |
| --- | --- | --- |
| A1 编排发布 | 有条件接受具名编排直调中性组合发布口 | 只提交各结构类公开入口出具的已校验片段，不能自行构造领域裸写集再封存；空壳转发门面不自动增加安全 |
| A2 单结构代发 | 允许而非强制；单结构默认本类完整提交，参与跨结构组合时可由具名编排代发 | 校验和读回责任不随最后提交人转移；不强制所有对象增加编排层 |
| A3 中性读取 | 结构类与具名编排按合同读取；普通业务经结构类 | 编排只做引用、预期和组合一致性读取，不自行解析领域私有schema，不代替正式类型读口 |
| A4 D/T/M归属 | 保持ARCH-L4结构记录面与业务应用面分账，记录面可使用同一底座 | 不因代码已存在、概念统一或物理结构相同而重新划入DATA-L2；不是取消其正式记录能力 |
| A5 4030处理 | 原地修订为唯一现行分层正文 | 不另建4035并行权威；只保留必要迁移定位 |
| A6 细粒度入口 | 先明确仅结构类按本族合同使用 | 规范约束不等于编译期隔离；是否收窄接口及技术方案另按代码合同决定 |
| A7 模拟/语言聚合 | 同样遵守结构服务和受限编排边界 | 取消仅因模拟身份取得底座直写特权的推荐；确需通用复制时另闭合具名复制合同 |

## 4. 结构校验、编排与发布合同

### 4.1 责任链

```text
业务层：形成已裁决的业务请求
→ 结构类：核验本族字段、关系、基数、范围及生命周期
→ 单结构直接完整提交，或出具供具名编排使用的不可变片段
→ 编排：组合合法来源片段，不修改片段、不补造领域字段
→ DATA-L1：锁内核验中性引用、预期和组合冲突，一次发布
→ 各结构类：按正式读口读回，核对回执与本族结果
→ 业务层：独立解释业务结果
```

结构类负责结构合法性，底座负责中性原子发布，二者不代替业务资格或执行授权裁决。已经裁决的业务记录可以作为字段、引用或前置保存，不能把“不得裁决业务”误写为“不得承载业务信息”。

### 4.2 中性封存不证明领域来源

当前片段内容不可变、构造受限，但公开的底座封存函数接受调用方组装的中性请求；没有认证出具结构类，也不验证领域字段、基数和生命周期。拿到片段不证明已经通过对应领域校验。

正式设计须指明出具结构类公开入口、消费编排及其允许操作，并区分以下两种保障：

- 调用边和工程审查约束；
- 受限类型、能力或接口访问的技术保证。

不能把前者宣称为后者已经实现，也不能增加一个仍接受任意裸请求的门面就宣布唯一结构写入权闭合。编排不得调用通用封存为自己编码的领域写集取得“已校验”外观。

### 4.3 跨片段新节点绑定：待闭合

当前片段可引用既有正式节点，或本片段局部新节点。组合发布调整各片段自己的局部偏移，但不提供“片段B引用片段A尚未发布新节点”的正式绑定能力。

不得把现有追加片段组合描述为任意跨结构新建图能力。首个实际操作需要此能力时，后续设计须闭合逻辑槽位、类型校验、引用解析、循环引用、冲突拒绝和结果映射；不由编排拆改封存内容补接，不先公开空壳身份规避原子建立。具体物理表示仍待设计与审批，本提纲不选定ABI。

### 4.4 生命周期、重复发布与失败：待闭合

1. 封存本身零事实写入；持有不可变请求不保护业务引用存活，不持跨调用锁，不阻止节点删除。实际发布必须核验当前引用和预期。
2. 同批拒绝重复片段不等于跨调用幂等。当前片段没有一次性消费保证，重发可能重建节点或因预期变化失败；不得以重发代替结果确认。
3. 未发布、已发布但上层读回失败、发布结果未知分别处理。已发生发布不能因上层缺确认被解释为零变化或重新建立。
4. 本轮不批准新的公开准备态。若准备阶段以后需要分配真实节点，须另定身份、可见性、撤销、引用保护与清理，不能与零事实写入封存含糊并列。
5. 每个具体设计须闭合锁顺序、保护预期、回执对应、读回、保护释放及失败中止范围。封存不能代替执行授权；事后读回不能补救发布时缺少结构校验。
6. 多次读取不承诺跨owner原子快照，不把来源已经读过当作发布时仍然有效。

## 5. 中性读取与领域读取

| 读取目的 | 责任入口 | 不得替代 |
| --- | --- | --- |
| 节点、引用、联合预期和组合一致性 | 结构类或具名编排的中性读取 | 领域类型合法性、业务资格 |
| 完整需求、任务、方法及其当前状态 | 对应结构类公开读口 | 不能由编排或普通业务自行解析私有字段 |
| 需求成立、方法适用、目标满足、动作效果 | 正式业务治理 | 结构存在、发布成功、缓存命中不是结论 |

普通业务缺少读取能力时补正式提供者，而不是长期自行解码。中性读取不自动赋予写权、生命周期保护或现实执行资格。
