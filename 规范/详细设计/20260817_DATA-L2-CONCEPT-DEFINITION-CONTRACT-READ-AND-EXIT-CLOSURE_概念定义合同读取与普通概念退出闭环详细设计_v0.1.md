# DATA-L2 概念定义合同读取与普通概念退出闭环详细设计

日期：2026-08-17

版本：v0.1

身份：`DATA-L2-CONCEPT-DEFINITION-CONTRACT-READ-AND-EXIT-CLOSURE`

状态：设计就绪

## 1. 目标与完成边界

本叶在唯一 `L2概念结构服务`、唯一概念 owner 和现行普通应用同实例装配上，闭合 `DATA-EXT-08` 当前最早未满足的结构提供者：

```text
普通概念定义角色的单值 / 多值基数合同
+ 按概念正向、按定义目标反向的当前 / 历史有界读取
+ 退役普通概念的不可逆原子退出
+ 退出后当前不可见、历史完整可读和替代直接边同事务读回
```

本叶不建立第二概念服务、第二 owner、第二聚合 getter、通用查询服务或 BIZ 组合器；不修改普通应用、概念聚合、六类世界服务、L1、工程文件或最终需求清单。

完成只证明上述生产 ABI 和实现进入正式 Git，并通过施工门禁。它不证明定义在业务上正确、某个概念应退出、真实消费者已使用、概念名称结构、`DATA-EXT-11—14` 或 `DATA-EXT-01—14` 整体完成。

## 3. 定义约束语义裁决

4240 与 7140 明确规定：定义关系角色进入抽象签名，签名发布后不可原地改义；含义变化必须建立新的概念身份。因此：

1. 定义关系的首次新增仍由 `建立普通概念(...)` 与其它签名事实同写集完成。
2. DATA 不提供对既有概念原地“新增 / 替换 / 退出定义目标”的公开写入口。
3. 需要增、替、退定义目标时，调用方以新完整签名调用现有 `建立普通概念(...)`，取得新概念身份；旧概念按生命周期迁移到退役，满足退出条件后调用本叶 `退出普通概念(...)`。
4. 本叶提供定义关系当前 / 历史双向读取，使调用方能机械重建签名和检查引用；不把目标复制为普通值。

这不是缩减正式能力，而是消除最终需求清单与不可变签名合同的冲突。任何原地改写旧概念定义的实现都属于禁止项。

## 4. 公开 DTO 与合同版本

全部新增 / 修订类型由 `海中鱼巣/领域/L2普通概念结构.数据.h` 唯一拥有。

### 4.1 角色基数合同

新增：

```cpp
inline constexpr std::uint32_t L2概念定义合同版本 = 1;

struct L2概念定义角色合同 final {
    std::uint64_t 角色 = 0;
    std::size_t 最小数量 = 0;
    std::size_t 最大数量 = 0;
    friend bool operator==(...) = default;
};

struct L2概念定义角色合同事实 final {
    L2概念身份 概念;
    L2概念定义角色合同 合同;
    稳定编码 成员关系稳定编码;
    稳定编码 角色值稳定编码;
    稳定编码 最小数量值稳定编码;
    稳定编码 最大数量值稳定编码;
    L2生命周期 生命周期;
    friend bool operator==(...) = default;
};
```

有效合同固定满足：角色非零，`最大数量 > 0`，`最小数量 <= 最大数量`。合同组按角色严格升序且角色唯一。每个定义项必须命中一个角色合同；同角色项的顺序必须从 1 开始连续、不得重复，项数位于 `[最小数量, 最大数量]`。单值角色固定为 `0或1` 或 `1到1`；多值角色必须给出有限非零最大数量，不使用 0 表示无界。

`L2普通概念建立请求` 与 `L2普通概念事实` 各新增：

```cpp
std::vector<L2概念定义角色合同> 定义角色合同;       // 请求
std::vector<L2概念定义角色合同事实> 定义角色合同;   // 事实
```

`L2普通概念结构合同版本` 从 1 提升为 2。v2 完整签名唯一键增加确定排序的角色合同组；已有签名值式项和定义目标组继续参与唯一键。当前范围不做持久恢复或跨进程迁移；根 DTO 不变。若运行包中发现缺少角色合同的普通概念 v1 当前事实，不得猜测单值 / 多值，读取与写入固定返回 `内部不一致`，由调用方停止并重建运行包。

### 4.2 定义关系读取

```cpp
struct L2按概念定义组读取请求 final {
    L2结构请求头 请求头;
    std::uint32_t 定义合同版本 = L2概念定义合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    L2概念身份 概念;
    std::uint64_t 历史截止事实代次 = 0;
    std::size_t 数量预算 = 0;
    friend bool operator==(...) = default;
};

struct L2按定义目标概念组读取请求 final {
    L2结构请求头 请求头;
    std::uint32_t 定义合同版本 = L2概念定义合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    L2概念定义目标 目标;
    std::uint64_t 历史截止事实代次 = 0;
    std::size_t 扫描预算 = 0;
    std::size_t 数量预算 = 0;
    friend bool operator==(...) = default;
};

struct L2概念定义组读取结果 final {
    L2结构结果头 结果头;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    std::vector<L2概念定义角色合同事实> 角色合同组;
    std::vector<L2概念定义关系事实> 定义关系组;
    bool 成功() const noexcept;
    friend bool operator==(...) = default;
};
```

正向结果包含目标概念的全部角色合同和定义关系；反向结果包含命中目标的全部定义关系，以及这些关系实际使用到的 `(概念, 角色)` 合同，每份合同只返回一次。合同组按 `(概念编码, 角色)` 排序，关系组按 `(概念编码, 角色, 顺序, 关系稳定编码)` 排序。合法空组只允许反向当前 / 历史查询未命中；按概念查询必须先证明普通概念存在，零定义概念成功返回完整合同组与空关系组。

### 4.3 普通概念退出

```cpp
inline constexpr std::uint32_t L2普通概念退出合同版本 = 1;

struct L2普通概念退出请求 final {
    L2结构请求头 请求头;
    std::uint32_t 退出合同版本 = L2普通概念退出合同版本;
    L2结构幂等身份 幂等身份;
    L2概念身份 概念;
    稳定编码 当前退役生命周期事实稳定编码;
    std::size_t 图扫描预算 = 0;
    std::size_t 关系数量预算 = 0;
    friend bool operator==(...) = default;
};

struct L2普通概念退出结果 final {
    L2结构结果头 结果头;
    std::optional<L2普通概念事实> 已退出概念;
    std::vector<L2概念直接上位事实> 已退出直接关系;
    std::vector<L2概念直接上位事实> 新增替代关系;
    bool 成功() const noexcept;
    friend bool operator==(...) = default;
};
```

成功只允许 `已提交 / 精确重复`，事实截止与变更事实代次相等且非零，`已退出概念` 有值；其中节点、族归属、根归属、签名规则、签名项、定义角色合同、定义关系、来源证据、治理生命周期及全部目标相关直接上下位关系的退出代次均等于结果截止。新增替代关系在同一截止建立。非成功 optional 和两个 vector 均为空，变更事实代次为空。

## 6. 私有承载与确定写集

在现有 `普通概念结构登记幂等身份` 的登记写集中增加四项概念 owner 类型：

```text
定义角色合同成员关系类型        0x020A'6206
定义角色值属性类型              0x020A'6219
定义最小数量属性类型            0x020A'621A
定义最大数量属性类型            0x020A'621B
```

每份角色合同由“一个普通节点 + 概念到该节点的成员关系 + 三个 I64 值 + 三个属性槽”承载，全部同 owner、同创建代次。普通概念首次写集使用以下不重叠确定分区：

```text
0xB000'0000 + i：角色合同项节点
0xC000'0000 + i：角色合同成员关系
0xD000'0000 + i：角色值
0xE000'0000 + i：最小数量值
0xF000'0000 + i：最大数量值
```

角色合同数量上限固定小于等于 `0x1000'0000`，与现有 `0x1—0xA` 分区零重叠。登记、创建、首次请求见证、首次结果重建和当前 / 历史读取必须逐字段互证；进程缓存或请求副本不能替代事实。

退出写集不建立第二登记。它关闭目标概念全部自有当前事实和涉及目标的当前直接上下位关系，并按第 8 节建立必要替代边。世界事实支持必须在退出前为零；指向目标的其它概念定义、概念名称或任意外部 owner 当前引用由显式预读与 L1 当前引用闭包双重保护，不在本事务中级联退出。

## 7. 定义读取与共同截止

当前读取要求非零 `G0` 且请求守卫等于当前事实代次；历史读取要求 `0 < H <= 请求头.期望事实代次`，结果截止固定为 `H`。

正向读取先证明目标是普通概念，再从同一概念 owner、同一截止读取角色合同与定义关系，逐项经现有强类型目标校验函数验证。反向读取只在概念 owner 范围按预算枚举当前或截止内普通概念和定义项；它不是全仓扫描，也不读取 BIZ、名称或世界服务私有存储。扫描耗尽返回 `数量预算不足` 和零载荷。

依赖公开读取返回漂移、未找到、已退出、资源失败时保持原分类；成功但截止、强类型、关系方向或负载不匹配返回 `内部不一致`。定义目标合法但零命中是成功空组。

## 8. 不可逆退出算法

退出在现有概念写锁内按以下固定顺序执行：

1. 校验请求、预算、非保留幂等身份；优先读取本 owner 首次写入材料。同幂等同写集直接重建首次结果，同幂等异请求返回 `幂等冲突`。
2. 在 `G0` 完整读取目标普通概念；本体根、未知概念、非退役生命周期、退役稳定编码不匹配分别返回 `入口拒绝 / 未找到 / 引用冲突`。
3. 在同一 `G0` 读取全部当前直接上位、直接下位、世界事实支持和按定义目标反向关系。任一当前支持、外部定义引用或无法在预算内证明完整均返回 `引用冲突` 或 `数量预算不足`，零写。
4. 读取同根当前完整 DAG；移除目标及其关联边后检查无环和全部剩余普通概念唯一根可达。
5. 对每个 `(直接上位 P, 直接下位 C)` 按编码升序组合。若移除目标后 `P` 到 `C` 已存在其它可达路径，则不新增；否则加入一条 `P -> C` 替代直接边。重复边去重并稳定排序。
6. 形成确定写集：退出目标节点及全部自有事实、退出目标相关直接边、建立替代边。名称、世界事实、支持关系、其它概念定义和任何外部 owner 事实不写。
7. 以原幂等身份提交一次 L1 owner 写集。L1 当前引用保护是最终防线；在候选形成后出现名称或其它外部引用时返回 `引用冲突`，不得部分发布。
8. 首次成功或精确重复均从首次结果截止重建同一退出概念、退出边和替代边；读回不完整返回 `内部不一致`。

不使用级联删除、全仓扫描、第二事务、内部重试、sleep、日志判定或调用方自报“无引用”。

## 9. 当前与历史读回

退出成功后：

- `读取普通概念(当前)` 固定返回 `已退出`、空概念、零变更；
- `读取普通概念(历史, H < 退出截止)` 返回 H 时完整活动事实；
- `读取普通概念(历史, H >= 退出截止)` 返回完整已退出事实，全部自有生命周期携带同一退出截止；
- 定义正向当前读取返回 `已退出` 和空组；历史读取返回截止内合同与关系；
- 定义反向当前读取不再包含该概念，历史读取按 H 返回；
- 直接关系当前读取只见替代边，历史读取仍能读到已退出边。

历史读回不得用当前事实补缺，也不得把“已退出”解释为“未找到”。

## 10. 状态映射

| 条件 | `L2结构状态` |
| --- | --- |
| 无效版本、零守卫、零身份、保留幂等、零预算、根退出 | `入口拒绝` |
| 普通概念或定义目标不存在 | `未找到` |
| 目标已经不可逆退出 | `已退出` |
| 守卫不再当前且非精确重复 | `事实代次漂移` |
| 同幂等异规范化写集 | `幂等冲突` |
| 非退役、退役稳定编码不符、当前支持 / 定义 / 名称 / 外部引用存在 | `引用冲突` |
| 图或反向读取超过预算 | `数量预算不足` |
| L1 许可拒绝 | `许可拒绝` |
| 分配、依赖或 L1 资源失败，发布未知 | `资源失败` |
| 缺角色合同、基数不符、混代、多根、成环、坏成功形状 | `内部不一致` |

所有非成功结果零机器事实变化，日志只供人读。

## 12. 施工验证合同

执行侧使用 `D:\TEMP\DATA-L2-CONCEPT-DEFINITION-CONTRACT-READ-AND-EXIT-CLOSURE\<run-id>` 的仓库外临时专项，不把验证代码编译进生产目标。最低矩阵：

1. v2 普通概念零 / 单 / 多值角色合同建立与完整读回；非法角色、乱序、缺合同、超基数零变化。
2. 正向 / 反向当前与历史读取、合法空组、稳定排序、预算拒绝。
3. 定义变化只能建立新概念身份；生产 ABI 零原地定义写入口。
4. 退役叶概念退出、精确重复、同幂等异请求、当前已退出、历史前后截止完整读回。
5. 中间概念退出时必要替代边建立、已有绕行路径时零冗余边、多父图保持唯一根可达。
