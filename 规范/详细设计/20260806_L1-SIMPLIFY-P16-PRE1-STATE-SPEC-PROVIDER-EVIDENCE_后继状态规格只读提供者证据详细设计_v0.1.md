## 1. 裁决、目标与最大边界

P16 v0.2 的下一次修订需要把 P13 后继状态规格与可选 P14 迁移动能规格作为强类型执行证据材料交给 P15；P15 统一负责规范化、形成执行证据摘要并重建通用读回计划。当前 P13 公开结果只返回状态规格与迁移证据，没有稳定提供者身份、直接调用计数、共同截止和可供 P15 规范化的完整写前事实来源；P16 无权以默认 L1 身份、首个快照中的任意事实、业务事实编码或 P13/P14 私有登记冒充这些材料。

本叶只扩展 P13 唯一后继状态规格所有者，形成真实只读提供者证据合同。P13 成功结果一次性回显：

- P13 固定、公开、版本化的提供者身份；
- P16 对 P13 的直接调用次数与去重后提供者见证数量；
- P13 最终成功轮次的共同事实截止；
- 状态登记、后当前、前状态、前态选择和比较结果五类强类型来源材料；
- 从五类材料机械抽取的写前事实身份组、逐项完整 `L1事实副本` 及去重后数量。

P13/P14 是不同事实与接口所有者。P13 在等价与非等价分支均为必经且先发生，P14 只在非等价分支调用；把两者放入一叶会让状态规格模块拥有动态提供者身份与生命周期。因此本叶只闭合 P13。下一叶具名为 `L1-SIMPLIFY-P16-PRE2-DYNAMIC-SPEC-PROVIDER-EVIDENCE`，由动态所有者独立冻结 P14 证据，不在本包预分配其身份、DTO 或白名单。

本叶零 L1 写、零事实发布、零 P15/P16 调用，不修改 P15/P16 代码或旧三文档；不涉及因果、生产装配、崩溃、重启、断电或跨进程恢复。

P12 仍是独立前状态选择所有者，本叶不修改 `I64相邻前状态选择结果`、`实际存在I64基准状态事实` 或 P12 实现。P13 只消费现有 P12 公开强类型见证来限定允许历史回退的身份，并使用自身已有 `L1事实基座服务&` 读取完整不可变历史副本；不得要求 P12 新增原始事实材料。

## 6. 直接提供者与传递见证边界

P16 对 P13 的一次公开函数调用只产生一个直接提供者版本见证：

```text
(0x4C31535000000001, 合同1, 规则1, 调用次数1)
```

因此成功凭证固定 `直接调用次数=1`、`去重后提供者见证数量=1`。P13 内部的两次 L1 截止读取、实例特征读取、P12 选择、P11 比较和状态规格形成都是 P13 合同内部的传递调用；P16 不把它们再次登记为自己的直接 provider，也不得从其业务事实编码推导服务身份。它们对写入决定的事实贡献由本凭证五类强类型来源和写前事实身份组承载。

首次成功轮次之前若发生一次完整漂移重试，P16 的直接 P13 调用仍为一次；内部传递调用次数不改写直接调用次数。P13 必须丢弃失败轮次全部材料，只能返回最终成功轮次凭证。

## 7. 共同截止与五类来源

共同截止固定为最终成功轮次 `G0 == 后当前截止 == P12前状态截止 == P12选择截止 == 比较截止 == G1` 的同一非零值。凭证来源逐项固定：

| 来源段 | 唯一来源 | 用途 |
| --- | --- | --- |
| 状态登记 | `形成已校准实际存在I64后继状态规格` 同锁返回的 `状态登记证据` | 服务身份、关系19类型、五个状态属性类型 |
| 后当前 | P11 成功结果 `I64状态迁移完整输入见证::后当前`，并与本轮实例特征结果逐字段互证 | 主体、场景、归属关系、实例槽、定义、定义关系、当前值及来源 |
| 前状态 | P12 成功结果携带的完整 `实际存在I64基准状态事实` | 前状态节点、关系19、值事实和历史/当前见证 |
| 前态选择 | 同一 P12 成功结果的 `I64相邻前状态选择证据` | 选择规则、前状态身份、发生时间与截止 |
| 比较 | P11 成功结果的完整 `特征比较结果` | 注册身份、算法版本、左右回执、单位/维度/角色、差异和具名关系 |

不得以 P13 请求回显、状态规格 U64 确定性摘要、局部键、G0/G1 容器首项、日志或私有登记地址替代上述来源。

## 8. 写前事实身份抽取、数量与排序

成功轮次按下列固定闭包抽取身份；所有身份的 `观察事实代次` 均写共同截止：

1. 状态登记中的服务身份、关系19类型和五个属性类型，种类均为节点；
2. 后当前中的主体、场景、实例槽、特征定义、当前值属性类型、当前值来源、实际单位/维度/分量角色，种类为节点；当前场景归属关系、宿主关系、定义关系为关系；当前值为值；
3. 前状态六个节点见证、五个关系见证、状态资格/发生时间/特征值见证资格/被采样值引用/采样I64/被采样P8值六个值见证；
4. 前态选择只互证主体、实例槽和前状态，均必须已由第2或第3项覆盖，不新增种类解释；
5. 比较注册身份、实际单位、实际维度、实际分量角色和左右输入回执中的来源节点为节点；左右输入回执的事实身份按其对应的前状态值/后当前值既有种类互证，不允许调用点猜种类；
6. P13 最终 `0x53` 写集中所有非本地端点、类型和来源必须在上述集合中恰有一项；本地键不得进入写前事实身份组。

抽取后按 `(种类稳定值, 稳定身份)` 严格升序；同种类同身份只保留一项，不同种类同身份、零身份、零截止、重复未去除或写集引用缺见证均为 `内部不一致`。每个去重身份必须在同索引位置绑定一份完整 `L1事实副本`，副本对象种类、编码与身份项完全相等：

1. 先在最终 G1 的对应当前节点/关系/值容器中按稳定编码查找；恰一命中时取该不可变值副本，来源记 `最终G1当前事实`；
2. G1 零命中时，只允许该身份已经由现有 P12 完整前状态见证列出且其退出代次非空、不大于共同截止；P13 使用自身已有 `L1事实基座服务&` 以该身份恰调用一次 `读取历史事实`，要求成功、`当前有效=false`、查询编码和完整副本编码相等，并逐字段互证 P12 强类型见证，来源记 `P12前状态历史事实`；
3. G1 多命中、当前与历史同时成立、P12 未列出的历史回退、历史副本与 P12 不一致，均为内部不一致；不得从类型默认值重建 `节点事实/关系事实/值事实`。

全部历史读取后再读取末次完整快照 G2，要求 `G2事实代次 == G1事实代次 == 共同事实截止`；否则按既有首轮完整重试/第二轮漂移处理。`写前事实身份组.size() == 写前事实副本组.size() == 去重后写前事实见证数量`，P13 `已形成` 时数量必须大于0；任何非成功结果两组均空，不用空组冒充成功。具体数量由五类固定闭包中的真实稳定身份相等关系机械唯一决定，不使用容器次序或硬编码首项；专项夹具必须断言其已知事实图的精确去重数量。

P15 后继修订只允许逐项对同索引完整副本调用 `形成L1写前事实摘要`，再转为 `L1写前事实见证`；不得由 P16 自行哈希、补身份、重读事实或选择读回项目。

## 9. 根函数机械流程

`形成实际存在I64后继状态规格` 保留现有最多两轮完整漂移重试。最终成功轮次在 G1 校准后：

1. 调用状态规格形成函数，要求规格与状态登记证据同时存在；
2. 读取固定 P13 提供者身份；
3. 用本轮后当前、P12结果、比较结果和状态登记形成五类值式来源；
4. 按 §8 抽取、排序、去重身份，绑定最终 G1 当前副本或 P12 具名历史副本；
5. 读取末次 G2，互证 P13 规格截止、写集期望代次、G1/G2 和凭证共同截止完全相等；
6. 互证身份组、副本组和数量一一对应后，一次返回状态规格、迁移证据和提供者证据。

任何凭证形成失败都返回 `内部不一致` 和全空载荷，不能保留“规格成功但凭证缺失”的半成功。`std::bad_alloc` 仍映射 `资源失败`。

## 10. 非成功、漂移与并发

- 入口拒绝、无前状态、未找到、冲突、不可比较、许可拒绝、资源失败：沿既有状态返回，提供者证据为空；
- 首轮任一截止漂移：丢弃首轮规格与证据，完整重试一次；第二轮仍漂移返回版本漂移空载荷；
- provider身份值/版本不符、五类来源缺项、副本缺失或错种类、排序或数量矛盾：内部不一致空载荷；
- 函数仍零写、无跨 provider 锁、无 sleep；并发写只通过既有 G0/G1 截止导致完整重试或漂移；
- 身份读取是纯常量，不形成新的事实竞态。

## 11. P16 消费边界

后继 P16 只能在幂等探测 `未找到` 后恰调用 P13 一次。P13 `已形成` 时，P16机械检查提供者身份、合同/规则、直接调用次数1、提供者见证数量1、共同截止、五类来源、写前身份/副本一一对应、数量和 P13 规格截止；随后把整个强类型凭证连同 P13 规格交给 P15 后继统一证据接口。

P16不得：

- 把 `L1事实基座服务::读取提供者身份()` 当 P13 身份；
- 从 P13 写集局部键、状态/比较事实编码或私有登记反推身份；
- 自行形成 `L1写前事实见证.事实摘要`、执行证据摘要或通用读回计划；
- 把 P13 的传递调用拆成未经所有者签发的 provider 见证；
- 在等价分支伪造 P14 凭证，或在非等价分支缺 P14 凭证时提交。

本叶真实结果进入 main 仍只解除 P13 一侧门禁；P16 必须继续等待 P14 独立证据叶和计划支撑替代版。
