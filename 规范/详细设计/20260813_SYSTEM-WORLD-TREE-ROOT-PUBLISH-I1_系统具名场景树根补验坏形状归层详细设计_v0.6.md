# SYSTEM-WORLD-TREE-ROOT-PUBLISH-I1 系统具名场景树根补验坏形状归层详细设计 v0.6

日期：2026-08-13

## 1. 来源问题与裁决

本修订只处理 `DRIFT-I1-V05-ROOT-PARENT-CROSS-LAYER-UNCONSTRUCTIBLE`。执行者在正式 `32fad8089fcda7d31ada1ec6676b000bb247c034` 继续组 5B 时机械确认：

- 根写结果只要根节点携带 `直接父关系`，`L2场景树节点写入结果::成功()` 就先返回 false；
- 整树结果只要任一父子关系把根作为子节点，`L2场景树事实完整()` 就先返回 false，继而 `L2场景树读取结果::成功()` 返回 false；
- 因此不能构造“根具有父关系、该整树读取仍满足 L2 `成功()==true`、随后才由 I1 跨结果互证拒绝”的 DTO 状态。

进一步机械审计 v0.5 组 5B 全部十二项后，确认误归层不只根父关系一项：根标记类别与三个端点、根父关系、登记结果头与载荷错截止、读取结果头与整树错截止也均由公开 L2 成功谓词或完整性谓词先拒绝。v0.6 将十二项冻结为本文件第 4 节的逐项可构造归层表；不得再把全部组 5B 统称为“I1 跨结果互证反例”。

本修订不删除或改变 I1 内部的根写、根标记、根父关系等防御检查。它们可以作为生产源码防御冗余保留，但在当前公开 L2 DTO `成功()` 合同之后不可独立动态到达时，只能登记为静态源码合同，不能伪装成 I1 层动态命中。

本修订不改变公开 ABI、机器语义、`.inl` 永久单源、九条白名单、provider-only、A1 同实例、四层证据、七组矩阵、启动 `NOT_RUN` 或 I2 冻结边界。

## 2. 正式依据与继承关系

除本文件明确替换的坏形状归层和组 5B 验证合同外，以下合同继续有效：

- `规范/详细设计/20260813_SYSTEM-WORLD-TREE-ROOT-PUBLISH-I1_系统具名场景树根补验单源模板详细设计_v0.4.md`；
- `规范/详细设计/20260813_SYSTEM-WORLD-TREE-ROOT-PUBLISH-I1_系统具名场景树根补验可构造反例详细设计_v0.5.md`；
- I1 v0.2 未被 v0.4—v0.6 改写的公开合同和状态机语义。

当前代码事实以以下公开谓词为准：

1. `L2场景树归属事实完整()` 已约束根类别时树、场景、根场景三个端点及物理目标；
2. `L2场景树节点事实完整()` 已约束节点、身份来源和树归属共同指向同一场景；
3. `L2场景树事实完整()` 已约束根标记、根节点唯一性、根零入边、全部非根单入边、连通、无环和同截止；
4. 三类结果 `成功()` 分别约束成功枚举、必要 optional、结果头 / 载荷截止和上述完整性。

执行侧已有局部动态结果只允许从新正式版本复核继承。执行者回传的既有 `32/32` 局部 PASS 不等于 v0.6 完整接受；G5B-06 修改后尚未重跑，组 6—7、双配置、静态合同和永久记录仍须按新合同完成。

## 3. 两层动态证据与一个静态层

### 3.1 L2 成功 / 完整性层先拒绝

构造类型正确但破坏公开 L2 完整性或结果头—载荷自洽的坏样本，先独立断言对应 L2 `成功()==false`，再把结果交给 I1 并断言阶段入口拒绝、后继短路、结果 optional 格和两状态槽守恒。记录必须写明“L2 先拒绝”；不得声称 I1 跨结果 helper 被独立动态命中。

读取结果仍使用 `已读取` 成功枚举、但载荷不完整时，I1 当前合同返回 `根读回不一致`；这表示 I1 对“成功枚举携带坏成功载荷”的阶段拒绝，不把坏载荷升级为成功读取。

### 3.2 I1 跨结果互证层

参与比较的每一个 L2 返回对象必须各自满足其公开 `成功()==true`，只让不同阶段返回对象或既有发布材料之间不一致。I1 必须返回 `根读回不一致`、不得形成新发布，并保持规定的待收敛槽或旧发布值。

同一结果对象内部的结果头—载荷错截止不能放入本层。可用的截止反例是：后二次登记与整树读取各自内部自洽且成功，但二者事实截止不同。

### 3.3 I1 源码防御冗余层

`.inl` 中根写携带父关系、根标记坏端点、整树中根有入边等检查允许原样保留。静态证据只证明生产源码存在这些防御，不证明在当前公开 L2 `成功()` 之后动态可达。不得为了制造动态可达性而修改 L2 DTO、伪造 `成功()`、绕过公开谓词或新增测试专用生产入口。

## 5. G5B-12 实现缺口裁决

G5B-12 不是可删除或改归 L2 的用例。既有 v0.4 已冻结“发布材料跨结果错截止拒绝”，公开 `系统世界树根读回` 也独立携带 `事实截止代次`；I1 在消费既有发布材料前必须互证：

```text
既有发布.事实截止代次
== 既有发布.正式树读回.事实截止代次
== 本轮根读回前登记结果头.事实截止代次
== 本轮整树读取结果头.事实截止代次
```

当前 WIP 的 `根读回一致()` 尚未显式比较既有发布的独立截止字段。若执行者从 v0.6 重新 S0 并复跑 G5B-12 后确认 I1 允许用本轮新读回纠正坏旧值并成功发布，这属于原计划范围内生产代码缺陷，不是新设计漂移。执行者可在既有九路径白名单内修复私有逐字段互证，使其拒绝且保持旧发布值；不得新增公开字段、运算符、setter、验证入口或改变状态枚举 / 机器语义。
