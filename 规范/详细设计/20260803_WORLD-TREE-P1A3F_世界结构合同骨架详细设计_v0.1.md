# WORLD-TREE-P1A3F 世界结构合同骨架详细设计 v0.1

日期：2026-08-03

设计身份：WORLD-TREE-P1A3F

## 1. 目标与边界

本设计只把 P1A3 最终公开 DTO、服务类、构造依赖和七个公开函数以显式 `未实现` 骨架接入工程，使后继计划能够编译最终接口并验证安全拒绝分支。骨架不读取或写入世界事实，不取得 L1 许可，不调用恢复、提交、仓库、SQL或其它领域服务。

本设计不实现现实世界恢复/首次创建、世界结构遍历、创建存在、移动、移除、幂等、事务、发布、读回或生产装配。上述行为仍由 WORLD-TREE-P1A3 真实行为计划负责。

正式依据：0050、4200 v0.8、4201 v0.1、ACCEPTANCE-01。共享稳定值字段只复用 `20260802_WORLD-TREE-P1_函数功能确认_v0.1.md` blob `c27b2ab72042102604ae94553929201ebb120f9d` 的 §2.1；该节除本文件明确排除的 P1C 专属读取请求/结果外继续有效。

本文件从 v0.1 起对上述旧函数确认作以下精确替代，执行者不得在两套签名间选择：

| 被替代条目 | 本文件唯一现行合同 |
| --- | --- |
| §2.3 `节点直接世界引导服务` 二依赖构造 | §3.4 三依赖构造：恢复、提交、世界结构；DTO 字段保持本文件 §3.2 |
| §2.4 `世界结构读取结果` 使用 L1 状态 | §3.1 L2 专属 `节点直接世界结构读取状态` |

## 4. 七个骨架函数的唯一行为

| 函数 | 返回值 | 必须写入返回值 | 禁止动作 |
| --- | --- | --- | --- |
| `读取世界结构` | `世界结构读取结果` | `状态=未实现`、`事实截止代次=0`、根为默认无效值、三组为空 | 不读取 `请求` 以外事实；不调用 `结构_` |
| `读取当前事实代次` | `节点直接世界事实代次读取结果` | `状态=未实现`、`事实截止代次=0` | 不调用 `结构_` |
| `确保现实世界已引导` | `节点直接世界引导结果` | `状态=未实现`、`发布代次=0`、`读回=nullopt` | 不调用恢复、提交、世界结构 |
| `形成实际存在写入规格` | `节点直接实际存在规格结果` | `状态=未实现`、`规格=nullopt` | 不形成幂等或资格事实 |
| `在已有场景中创建并接纳实际存在` | `节点直接场景写入结果` | `状态=未实现`、`发布代次=0`、`持久状态=不适用`、`读回=nullopt`、`缺项组为空` | 不调用世界结构或提交 |
| `移动世界树成员` | 同上 | 同上 | 同上 |
| `移除世界树存在` | 同上 | 同上 | 同上 |

以上函数允许读取参数以消除未使用告警，但不得据此返回其它状态。骨架不校验业务参数；参数合法性属于真实行为计划。任何异常都不得由骨架主动产生；若结果值构造本身异常，按普通 C++ 异常传播，不伪造内部不一致。
