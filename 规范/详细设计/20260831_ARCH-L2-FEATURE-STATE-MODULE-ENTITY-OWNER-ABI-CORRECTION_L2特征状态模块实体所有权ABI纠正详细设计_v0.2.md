## 1. 修订目标与完成条件

在 v0.1 原目标内继续消除特征模块对 `L2状态动态原子发布服务` 的错误前置声明和 friend，使该类只归属：

```text
海中鱼巣.领域.服务.L2状态动态原子发布
```

依赖保持单向：

```text
海中鱼巣.领域.服务.L2状态动态原子发布
    -> import 海中鱼巣.领域.服务.L2特征结构
海中鱼巣.领域.服务.L2特征结构
    -/-> 海中鱼巣.领域.服务.L2状态动态原子发布
```

完成必须同时满足：

1. 特征模块内 `class L2状态动态原子发布服务;` 和 `friend class L2状态动态原子发布服务;` 均归零；
2. 动态发布模块和普通应用中的同名类、getter、公开操作及消费组合器都只使用动态发布模块附着身份；
3. 动态发布服务原来经 friend 消费的 4 个结果类型和 5 个 helper 由特征 owner 提供精确公开窄合同；
4. 动态发布模块不直接读取特征服务私有字段或端口，不新增反向 import、第二 provider 或平行声明；
5. v0.1 已完成的状态模块调用改接和特征首值窄合同原样保留；
6. 函数体、字段、DTO、请求、返回、错误映射、事务参与者、owner、幂等键、写集、永久账、恢复和读回语义零变化；
7. v145/v143 Debug/Release x64 仓库外 fresh Rebuild 全部最终链接成功。

本修订不改变正式机器语义，不增加业务能力，不接管 Gseed 源码或运行验证。

## 3. 实际调用面与最小合同裁决

动态发布模块对 `特征服务_` 只有下列调用：

| 调用 | 当前可见性 | 裁决 |
| --- | --- | --- |
| `读取完整特征实例(...)` | 已公开 | 原样复用 |
| `形成当前值变化三分区参与者_v1(...)` | 私有 | 连同结果类型改为 public |
| `确保当前值变化账登记_v2(...)` | 私有 | 连同结果类型改为 public |
| `读取当前值变化账登记_v2(...) const` | 私有 | 复用同一登记结果类型并改为 public |
| `形成当前值变化三分区参与者_v2(...)` | 私有 | 连同结果类型改为 public |
| `扫描全部当前值变化账_v2(...) const` | 私有 | 连同结果类型改为 public |

端口裁决：动态发布模块没有 `特征服务_.特征实例写入端口_` 或其它特征私有字段访问；三分区提交继续由动态发布服务自己的 `L1三分区原子事务凭证_v2` 完成。因此不新增端口 getter、不暴露特征实例写入端口、不改动态发布源码调用文本。动态发布源码只作为必须重编译和核对对象身份的验证输入，不是写白名单。

把动态发布源码无条件加入写白名单没有事实依据，会扩大执行者自由裁量；本设计明确禁止。

- 当前值变化 v1/v2、永久账登记/读取/扫描和首值状态原子事务的所有拒绝、许可失败、漂移、冲突、资源失败、内部不一致和已可能发布映射保持当前函数体；
