## 1. 目标与完成边界

本叶只纠正状态、动态、因果三个身份来源读取结果的成功谓词：历史成功必须同时证明结果回显的历史截止与结果头事实截止相等。

```text
当前读取成功
  = 读取类别为当前
  + 历史截止事实代次为 0
  + 身份来源在结果头事实截止完整

历史读取成功
  = 读取类别为历史
  + 历史截止事实代次非 0
  + 历史截止事实代次 == 结果头事实截止代次
  + 身份来源在该结果头事实截止完整
```

这只收紧由调用方拥有的值式结果自证，不改变 `DATA-L1` 事实、任何服务读写、当前选择、历史投影、退出、恢复、TTL、墓碑或公开 DTO 字段。

## 2. 当前事实与问题

场景、存在、特征定义和特征实例的同类成功谓词已经以结果头事实截止验证来源，并显式封闭当前 / 历史类别。以下三个结果仍把来源完整性检查的截止切换为 `历史截止事实代次`，却没有断言它等于结果头：

| 结果类型 | 当前缺口 | 实际服务构造证据 |
| --- | --- | --- |
| `L2状态身份来源读取结果::成功()` | 历史截止可与结果头截止不相等仍可能通过 | `服务.L2状态结构.ixx` 的当前构造回显 `0`，历史构造回显请求历史截止并作为结果头截止 |
| `L2动态身份来源读取结果::成功()` | 同上 | `服务.L2动态结构.ixx` 的当前 / 历史构造已满足同一回显关系 |
| `L2因果身份来源读取结果::成功()` | 同上 | `服务.L2因果结构.ixx` 的当前 / 历史构造已满足同一回显关系 |

因此，真实服务成功结果不应改变；本叶只使手工构造、错误回填或未来漂移构造的矛盾结果不能冒充成功。

## 3. 冻结的谓词合同

三个 `成功()` 均必须采用与场景来源读取结果等价的闭合顺序：

```cpp
结果头.状态 == L2结构状态::已读取
&& 结果头.事实截止代次 != 0
&& !结果头.变更事实代次
&& 身份来源
&& 身份来源->节点族 == 本族
&& L2节点族身份来源事实完整(*身份来源, 结果头.事实截止代次)
&& (读取类别 == L2读取类别::当前
    ? 历史截止事实代次 == 0
    : 读取类别 == L2读取类别::历史
        && 历史截止事实代次 == 结果头.事实截止代次)
```

未知读取类别、当前读取携带非零历史截止、历史读取携带零历史截止、或历史截止与结果头截止不等，均必须使 `成功()` 返回 `false`。本叶不改变服务对这些输入请求的既有拒绝 / 失败映射。

## 5. 非成功与兼容边界

1. 三个服务已经在当前结果中固定回显历史截止 `0`，在历史结果中把请求历史截止同时写入结果头；本叶不得加入补偿、改写或重试分支。
