## 1. 目标与完成边界

实现 `BIZ-L3-002-01-03 v0.2`：在一个普通应用上下文内，经同一 `L2结构聚合服务`取得 `const L2存在结构服务&`，调用现有无对象入口 `读取当前事实代次()`，复核成功形状后返回与本次运行代次、事实范围版本绑定的单一非零共享事实截止。

本叶全程只读，不枚举结构 owner，不读取存在对象，不建立 DATA-EXT-17、provider 组、发布见证 token、缓存或自动重试。完成只证明 BIZ 可以取得共享截止；父级治理批次冻结、世界—自我正文、其它子快照、读后 G1 和 `G1==G0` 闭合保持 `NOT_RUN`。

## 2. 当前事实与复用裁决

正式基线 `bcad7128b48cfdac0c35dd206d9952bfbd8699ff` 中：

- 4015 固定同一 L1 每次成功写集只推进一个全局事实代次；owner 不各自拥有时钟。
- 4230 固定普通应用七个世界结构 owner 使用同一个 `L1事实基座运行包`。
- `L2结构聚合服务`已有 `const L2存在结构服务& 取得L2存在结构服务() const noexcept`。
- `L2存在结构服务::读取当前事实代次() const`已公开；它调用 L1 当前事实代次读取，成功返回 `L2结构结果头{L2结构合同版本, 已读取, 非零事实截止, nullopt}`，资源竞争返回资源失败，零代次或坏形状返回内部不一致。
- 聚合与存在服务 HEAD blob 分别为：

```text
bcd299df2fe8393585706398d2a867e882caf8c9
ae15e6c05f3a3c38e0038886d073b7202c91ff18
```

因此不要求 DATA 新增接口。把同义函数再加到核心、逐 owner provider 或新 DATA 服务会制造重复入口；本叶只建立 BIZ 外层绑定和结果收口。

### 4.1 配置与请求

```cpp
inline constexpr std::uint32_t 共享事实截止读取合同版本 = 1;

struct 运行期事实版本服务配置 final {
    std::uint64_t 运行代次 = 0;
    std::uint32_t 事实范围版本 = 0;
};

struct 共享事实截止读取请求 final {
    std::uint32_t 合同版本 = 共享事实截止读取合同版本;
    std::uint64_t 运行代次 = 0;
    std::uint32_t 事实范围版本 = 0;
};
```

配置和请求的运行代次、事实范围版本必须非零且逐字段相等。请求不含读取幂等身份、开始见证、截止、owner 组、provider 引用或 DATA 合同版本。

### 4.2 结果

```cpp
enum class 共享事实截止读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    资源失败 = 3,
    内部不一致 = 4
};

struct 已发布共享事实截止 final {
    std::uint32_t 合同版本 = 共享事实截止读取合同版本;
    std::uint64_t 运行代次 = 0;
    std::uint32_t 事实范围版本 = 0;
    std::uint64_t 事实截止代次 = 0;
};

struct 共享事实截止读取结果 final {
    共享事实截止读取状态 状态 = 共享事实截止读取状态::请求拒绝;
    std::optional<已发布共享事实截止> 截止;
};
```

只有 `已读取` 可以携带 `截止`，且四字段完整非零。其它状态 `截止` 必须为空；不得返回上次成功值、DATA 原结果头或部分载荷。

### 4.3 服务

```cpp
class 运行期事实版本服务 final {
public:
    运行期事实版本服务(
        const L2结构聚合服务& 结构聚合服务,
        运行期事实版本服务配置 配置) noexcept;

    运行期事实版本服务(const 运行期事实版本服务&) = delete;
    运行期事实版本服务& operator=(const 运行期事实版本服务&) = delete;
    运行期事实版本服务(运行期事实版本服务&&) = delete;
    运行期事实版本服务& operator=(运行期事实版本服务&&) = delete;

    共享事实截止读取结果 读取当前已发布共享事实截止(
        const 共享事实截止读取请求& 请求) const noexcept;
};
```

服务只借用 `const L2结构聚合服务&`并保存值式配置。构造不读取 DATA；不缓存存在服务引用、事实截止或调用结果。

## 5. 固定控制流

```text
校验配置完整
-> 校验请求合同、运行代次、范围版本完整且与配置相等
-> 经聚合 const getter 取得同实例存在服务
-> 调用读取当前事实代次()
-> 复核 L2 合同版本、状态、非零事实截止和变更事实代次为空
-> 一次构造已发布共享事实截止
-> 返回已读取
```

状态映射固定为：

| 条件 | BIZ 状态 | 结果守恒 |
| --- | --- | --- |
| 配置或请求零字段、合同不匹配、运行代次 / 范围不等 | 请求拒绝 | 零 DATA 调用，截止为空 |
| DATA 状态为资源失败 | 资源失败 | 截止为空，可由父级重新发起整轮读取 |
| DATA 合同错误、入口拒绝、内部不一致、其它不应出现状态、零截止或变更代次非空 | 内部不一致 | 截止为空，停止依赖路径 |
| DATA 已读取且成功形状完整 | 已读取 | 一次构造截止材料 |

`noexcept`边界捕获 `std::bad_alloc`、`std::length_error`为资源失败，其它异常为内部不一致。当前 DATA 入口自身把异常收口为内部不一致；BIZ 仍保留自身值式构造的异常分账。

## 6. 并发、一致性与生命周期

- 服务无锁、无缓存、无静态当前值；线程安全性等于只读配置、只读聚合引用和 DATA const 调用。
- 一次调用只读取一个瞬时全局事实代次。它不保证后续正文期间不发布；父级必须读后再次调用取得 G1。
- 两次调用可以返回不同截止，这表示两次调用之间发生 L1 发布，不是服务内部漂移或自动重试理由。
- 返回材料归调用方所有，不泄漏 DATA 引用、L1、owner、锁或事务。
- 聚合服务与本服务生命周期由后继普通应用装配保证覆盖调用；本叶不新增全局单例或第二 provider。
