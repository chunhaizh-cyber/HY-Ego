# WORLD-TREE-CORE-FREEZE-DP 统一4040冻结许可与真实结构见证提供者详细设计 v0.3

修订基线：`dd497341216b05e2d4b55af6afa1df5402882cc3`

本版本不可变替换 v0.2。v0.2 的机器目标和 F0 固定未实现边界继续成立，但其独立许可模块中的跨模块 `friend class 节点直接身份结构事务域` 与命名模块实体单一所有权冲突，禁止施工。

具名修订：`DRIFT-CORE-FREEZE-DP-F0-ABI-FRIEND-OWNERSHIP`。

## 1. 目标与不变量

本包为 4170 的后继冻结读取提供最终公共 ABI，并将真实实现继续分账到 R1。F0 只建立可编译的固定未实现骨架：

```text
统一冻结许可及见证 ABI
+ 事务域取得 / 所属域判断根
+ 类型化值冻结读取 DTO 与访问器 ABI
+ 固定未实现专项自检
```

F0 不取得锁、不读取事务域或仓库、不形成许可、不复制记录、不推进代次、不产生机器事实。

以下不变量必须同时成立：

1. `节点直接身份结构事务域` 的唯一声明和定义继续归现有执行器模块；不迁移、不重复声明。
2. `节点直接统一冻结许可` 与事务域同模块，由同模块 `friend` 封闭构造；无跨模块同名前置声明。
3. 类型化值冻结读取模块只单向 import 执行器和类型化值仓；执行器、仓库均不反向 import 它。
4. F0 不修改类型化值仓；R1 如需真实结构版本和有界只读原语，另在仓库所有者内原位增加，不改变本版公共冻结 ABI。
5. 许可外层固定为单一 pImpl；访问器外层固定为单一非拥有仓指针。
6. FEATURE-W-DP 仍等待 R1 真实许可、见证和结构版本，F0 不解除其门禁。

## 2. 当前事实与冲突裁决

当前 `海中鱼巣.核心.执行器.节点直接身份结构写入` 在同一模块内唯一拥有：

```text
节点直接身份结构读取许可
节点直接身份结构事务许可
节点直接身份结构事务域
节点直接身份结构写入执行器
```

事务域仅依赖执行器模块已经可见的标准库状态；其私有独占入口由同模块写入执行器使用。类型化值仓由执行器单向 import。

v0.2 设计要求尚不存在的零项目 import 模块先写：

```cpp
friend class 节点直接身份结构事务域;
```

在没有 import 事务域唯一所有者的情况下，该 friend 会在许可模块形成附着于该命名模块的同名声明；import 执行器以取得既有声明又会造成 `执行器 -> 类型化值仓 -> 许可 -> 执行器` 或 `执行器 <-> 许可` 反向依赖。两条路径均不合法。

### 2.1 唯一裁决

```text
事务域及现有读 / 写许可：继续由执行器模块唯一拥有
统一冻结许可 / 见证 / 状态 / 取得结果：新增到同一执行器模块
类型化值冻结读取 DTO / 访问器：新模块 冻结.节点直接类型化值 唯一拥有
类型化值仓：F0 原样不变
```

不采用的路径：

- 不建立 `许可.节点直接统一冻结.ixx`；该物理路径和模块身份从 v0.3 施工范围退出。
- 不公开统一冻结许可构造器、工厂、通行证或内部状态初始化入口。
- 不迁移事务域、现有读许可或事务许可，不要求全部下游改 import。
- 不用模板、字符串、地址、随机数、函数指针或运行期 cookie 伪装不可伪造构造权。
- 不让类型化值仓 import 执行器或冻结读取模块。

## 5. 生命周期、所有权和安全性

1. 事务域唯一形成有效统一冻结许可；许可构造器私有且 friend 与事务域同模块。
2. 协调方栈对象独占许可所有权；许可 move 后源对象无效，析构无异常。
3. 许可 pImpl 在 R1 持有 4040 共享冻结边界及不可伪造域归属；公开见证不是授权令牌。
4. 冻结读取访问器只借用仓和许可，不保存许可，不取得第二事务域许可。
5. FEATURE-W-DP 必须先调用 `事务域.冻结许可属于本域(许可)`，通过后再调用冻结读取模块；错域、失效或部分结果整体失败。
6. 许可持有期间禁止 I/O、日志、等待、回调和反向取得同域独占许可。

## 9. 恢复与错误合同

F0 不改变恢复。R1 普通统一许可只在已恢复、开放、未隔离的运行期域中形成。恢复材料不能覆盖当前运行期域身份。

R1 的值式复制继续满足：

- 有效许可来自事务域真实状态，调用方不能输入域身份或代次。
- 类型化值复制只包含全部已发布记录；空仓合法但结构版本非零。
- 复制与轻量观察逐字段复核见证、结构版本、数量。
- `bad_alloc` / `length_error` 为资源失败，其它异常为内部不一致。
- 所有非成功结果 optional 为空；SQL、日志、材料和缓存调用数为零。

## 10. F0 专项自检

唯一身份 `WORLD-TREE-CORE-FREEZE-DP-S01`，顺序 225。开工记录顶层数量 `N`，F0 目标 `N+1`；R1 原位扩充同一身份。

除 v0.2 功能矩阵外，必须新增所有权 / 依赖矩阵：

1. 执行器模块是事务域和统一冻结许可唯一声明所有者。
2. 许可 friend 与事务域同模块；其它命名模块对事务域、许可零前置声明。
3. `许可.节点直接统一冻结.ixx` 不存在且不登记工程。
4. 新冻结读取模块唯一拥有冻结读取 DTO / 访问器，只 import 执行器和类型化值仓。
5. 类型化值仓不 import 执行器或冻结读取模块，F0 文件内容零变化。
6. 执行器不 import 冻结读取模块；MSVC 模块依赖零环、零缺失。
7. F0 所有运行根固定未实现 / false / 全零，调用前后事务域和仓权威导出逐字段相等。
