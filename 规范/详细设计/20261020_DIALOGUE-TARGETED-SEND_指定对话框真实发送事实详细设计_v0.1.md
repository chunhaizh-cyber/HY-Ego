## 1. 目标、事实边界与排除

修改对象是外设世界指定对话框窗口E的发送内容和发送数量F，不是任务Vm，也不直接改变现实人的需求或身份。原因是现行“提交”仅追加全局显示列表，无法证明向哪一个对端实际写出了什么；目的为后继连接方法和需求重述提供真实、可定位的本侧发送事实。

本包提供定向提交、实际浏览器取件通道、写出反馈和正式F/S/D/概念处理。连接方法仍须自行依据本次过程起点之后的真实收发判断；保留完整“发—收—发”“收—发—收”方向，不要求先收到文本POST。实际带页面ID的GET可首次建立页面定位，但不认定人类。消息可以无自然语言意义，本包不自动构造握手、自动回复、判定连接或修改任务。

成功发送仅表示本端完整写出一份具名业务载荷，不证明浏览器解析、显示、对端接收、人类理解或需求确认。网络失败/部分写出属于传输事实与技术状态，不算成功发送F，不作为本能条件结果知识。

## 3. 提交身份和投递模型

目标是`公开宿主会话＋对话框ID`，不含秘密URL令牌，不表示人类身份。ID沿用页面内存UUID4；页面reload生成新ID，旧待发送项不迁往新ID。正常GET带ID即可获得正式页面定位；不存在/非法ID不得默认其它页面。

每次显式提交由宿主在锁内分配单调非零`提交序号`，其身份为`会话＋提交序号`，冻结目标和准确UTF8正文。相同文字的两次显式提交是两次独立尝试；不按文本去重。一次提交只有一次自动写出尝试，失败也不自动重排。调用者确要重发时再次显式提交，获得新序号。

宿主队列是当前运行的传输控制状态，不是信息世界消息E、全量入站消费日志或需求节点。正式成功事实仍是窗口F及S/D；提交序号用于本次不可变载荷与写出回调的关联，不把它当人/概念/任务编码。

宿主共享状态改为按对话框ID持独立显示消息vector和待发送提交vector，每项保存完整目标、序号、正文及发送状态/技术回执；上行传输序号仍可全会话递增，不改变现接收合同。显示页面序号改为每个对话框内递增，既有`网页对话已显示消息`字段不变，不以序号单独跨页面定位。

## 5. HTTP、真实写出及显示隔离

`GET /api/messages`、`GET /api/outbound`、原文本POST均须恰一个合法`X-HY-Dialogue-Id`，沿用私有路径令牌。宿主从当前会话与header构成目标，锁外调用确认页面；成功后在宿主锁内复核当前会话并登记传输页。非法请求不发布事实；页面确认只建立/取得C/E/F，不增接收数量。POST继续通过既有真实接收回调更新接收F，再追加到同目标显示列表。

`GET /api/messages`只读目标自己的显示历史，永不返回其它对话框正文。它是页面投影读取，即使物理HTTP写出全部历史，也不增加业务发送F。旧全局历史不能直接复制到每个页面；新运行历史从空开始。

`GET /api/outbound`每次最多取得目标最早`已排队`项，锁内转`正在写出`并复制完整材料，随后释放锁；同一项不能被另一GET再次取走。没有排队项返回204，不形成消息发送事实。请求处理仍沿用现宿主单请求循环，不增加工作线程。

响应正文固定为`{"id":"十进制提交序号","text":JSON转义的UTF8正文}`，序号用字符串避免JavaScript整数精度丢失；原文和ID均来自取出时的不可变材料。开始写出前完整构造HTTP响应字节串，不在写出后重读全局待发文本/其它提交。CSP/私有路径等安全头保留。

内部`发送全部`和`发送响应`改用私有结果：

```cpp
struct 网页HTTP写出结果 final {
    bool 完整写出 = false;
    std::size_t 已写字节数 = 0;
    int 系统错误 = 0;
};
```

`send`逐段累加实际返回字节，只有完整响应均写入本端socket才为true；错误立即保存WSA错误，零返回记连接结束。写出失败/部分写出不属于成功计数；不能因接收方可能收到部分字节就补造完整消息。构造响应的资源异常是工程故障，不是网络失败，按工程链停止。

完整写出后，锁外用冻结事实调用`发送完成`；该回调完成正式外设发布/读回才在宿主锁内将项置`已完整写出`，追加一条此目标的自我显示投影。回调或追加失败须保留已写出事实并终止，不能重新排队、再次发送或报告零发生。网络未完整写出则锁内置`写出未完成`并保存字节/系统错误，不调用成功事实回调、不追加成功自我显示项。对同一完成项的后续查询/历史重绘零增量。

浏览器用同一个ID进行两个GET。每轮先await outbound取件，再刷新显示列表；一次轮询未结束前不启动下一次，避免setInterval积压。outbound的200表示本端返回该载荷，不把页面是否render成功作为发送事实条件；浏览器不回发确认或自动握手，不把空轮询当上行消息。页面状态文案只表示宿主可访问/取件异常，删除“已连接”这一超出证据的用语。

## 6. 外设发送特征与历史兼容

扩展`业务/新_外设世界树类.h/.cpp`，正式新增FT：`外设对话框发送数量`（I64非负、同接收数量定义）、`外设对话框发送内容`（UTF8全材料域、同正文比较定义）。共享概念仍由正式概念owner维护。

`新外设对话框定位`追加两个`std::optional<稳定编码>`字段`发送数量特征`、`发送内容特征`。新创建当前页面具有两个F，数量初值0、正文无当前值；初始S按真实创建时间。旧历史页面缺两F时可读取旧接收事实，但不得将缺失解释为过去发送总数0，不把未知历史回填成未发送。一个有一个无、重复或类型冲突为工程损坏。

当前新宿主会话与旧会话不同；定向发送只接受本次已确认的页面。若当前页面缺发送F，停止报告版本/结构不一致，不自动补旧历史。初始化扩FT不迁移旧页面、不删除任何历史；无热升级或旧会话复活。

增加：

```cpp
新外设对话框建立结果 查找对话框场景(
    std::string_view 公开宿主会话,
    std::string_view 对话框标识) const noexcept;
新外设事实状态 更新发送(
    const 新外设对话框定位&, std::string_view 实际UTF8正文,
    const 新状态强时间& 发布时间) noexcept;
```

`查找对话框场景`在外设owner锁内核验初始化和输入，完整查外设根正式C的两定位F并读回唯一窗口/接收F/可选发送F，不创建节点、F或概念，不以缓存为唯一事实。找到返回`已完成＋定位`；无匹配返回新增`新外设事实状态::未找到`且无定位，该枚举追加于末尾（值6），不改变旧枚举数值；重复或破损走现有工程停止链，不能伪装未找到。`建立或取得`可以复用同一私有只读定位逻辑，但只读函数不调用建立入口。发送完成回调必须调用此只读入口，未找到/缺发送F时工程停止保留真实写出，不懒建“补成功”。

只由普通应用的真实写出回调使用。先复核当前会话/正式页面及两发送F，确认其初始状态已经完成，再实取UTC作为发布时刻；正文和发送计数+1各走既有私有单F编排、S/D及窄自动概念处理。私有白名单从两接收F扩为具名四F，不接受任意F。相同正文重发只增加发送数量，不伪造正文变化。数量与正文仍非双F原子事件，连接将来只需数量S/D顺序，不要求逐次正文关联。提交序号不写成消息E。

本包数量是该页面本会话从发送提供者开始可观测的完整业务写出次数，不统计静态资源、GET历史、204或普通确认HTTP。它不宣称计量所有网络字节或所有历史传输。

## 8. 旧无目标入口退出

普通应用删除设置/提交旧本能适配函数，不再调用`装配网页对话端口`，三个端口保留默认空；manager现有缺端口可用性检查复用，无需放开全空端口装配接口或填失败stub。保留函数注册常量与历史解析，任务不得选入未知旧M后才碰端口故障。

`新_方法类::退役旧网页本能登记`只扩两准确登记名“设置网页对话输入文本”“提交网页对话消息”的启动核验：无M返回方法不存在且零创建；出现M因无正式旧头可识别合同保留并工程停止，不能猜参数/自动退役未知M。已有服务对象退役族和结算Q语义不改。普通装配结果新增两项核验并纳入成功门，在线程启动前完成。

宿主旧无目标`设置网页对话待提交文本`、`提交网页对话待提交文本`保留声明，明确返回既有`入口拒绝`、零写、无页面序号；删除其全局待提交文本状态，不默认首个/最近页面。旧无目标`读取网页对话已显示消息`、`读取网页对话会话页面消息快照`返回对应既有入口/输入拒绝且不带正文、游标或内容；生产HTTP改用新定向读取，不从旧接口兼容回退。

`核验网页对话当前会话`仍只核验会话，`已匹配`不再要求任何页面存在。其兼容字段`当前页面末序号`固定为nullopt并在头声明注明已退出全局游标语义，不返回0或最大各页序号等伪聚合。逐项同步唯一生产消费者`生成普通应用网页自我归类表达`的首次核验与末次复核（当前装配1947/2105）：不得再将nullopt映射为内部不一致或比较全局末序号。输入/应用上下文/活跃会话/宿主状态/独立自我与指代种子检查保留；随后针对明确已退出的旧现实窗口来源返回`来源不可用`和空表达/来源，旧后续生成/末序号复核路径退出生产，不能因某个残留窗口句柄又进入旧路径。不改通用语言表达owner或把其它错误泛化为来源不可用；不拿外设窗口替代人类。

结构化服务接口原授权、求助/确认合同不变，不将其响应混入定向对话消息，不因它们同属HTTP就计发送F。

## 9. 并发、停止与失败保留

锁顺序：普通应用锁可调用外设锁；外设锁可调用world概念锁。宿主队列锁保护取件和状态提交，但在普通应用回调、socket阻塞写出期间释放；普通应用不得在持应用锁时调用宿主提交/查询，必要调用方先值式冻结目标后解锁。单项`正在写出`排除重复GET取件。

宿主会话开始清空上次内存队列/显示投影并分配新公开会话；正式外设历史保留。停止先停止接纳提交并使剩余排队项成为已取消，不重发；当前同步请求完成其已发生事实处理后再结束会话回调、销毁外设owner。重启不恢复排队或重新发送历史，旧会话查询返回失效。被取消/失败项只在当前宿主运行存活期查询，不承诺持久传输日志。
