# DATA-L2 概念直接上下位关系增替退与双向读取详细设计

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-CONCEPT-DIRECT-HIERARCHY-RELATION-CRUD`

状态：设计就绪

## 1. 目标与完成边界

在已发布的唯一 `L2概念结构服务` 内，为 `DATA-EXT-08` 增加普通概念直接上下位关系的完整结构 CRUD：

```text
新增直接上位关系
+ 原子替换一条直接上位关系
+ 退出一条直接上位关系
+ 按下位概念读取直接上位关系组
+ 按上位概念读取直接下位关系组
```

关系方向固定为 `上位概念 -> 下位概念`。写入口只接受调用方已经裁决的结构请求；服务只校验强类型端点、同根、多父 DAG、唯一根可达、幂等、生命周期、同截止和引用保护，不判断上下位关系在业务上是否正确。

本叶复用现有概念 owner、现有直接上位关系类型、现有概念写锁、现有 `L2概念结构服务` 和现有概念聚合 getter。它不建立第二 owner、第二 C1、通用关系服务、裸稳定编码写入口、概念树权威、传递闭包、高度、路径或业务专用快捷入口。

本叶不实现定义约束、世界事实支持、概念生命周期迁移、普通概念不可逆退出、概念名称、按根完整 DAG 投影或普通应用不可变材料装配。

## 2. 正式依据与当前事实

正式依据：0050 v1.3、2220 v1.5、4030 v1.9、4040 v1.5、4050 v1.4、4190 v0.6、4240 v0.6、7140 v1.2，以及已经退出的 `DATA-L2-ORDINARY-CONCEPT-PUBLIC-DTO v0.1` 和 `DATA-L2-ORDINARY-CONCEPT-CREATE-READ-SERVICE v0.1`。

当前事实：

1. `L2普通概念结构.数据.h` 已公开 `L2概念直接上位事实`，但没有独立关系写请求、双向组读请求或结果 DTO。
2. 普通概念首次建立已经在概念 owner 写集中建立一至多条直接上位关系；现行服务可按下位端点重建当前或历史直接上位组。
3. 现行 `重建普通概念自有事实(...)` 错把每条直接上位关系的创建代次限定为概念创建代次，并从读取截止上的当前父组重组首次建立请求。后续关系 CRUD 若不先修正这两点，会把合法后继边判为损坏，或让首次幂等见证随当前父组变化。
4. 概念服务已经保存普通概念完整只读依赖。根专用构造形成的实例没有这些依赖，普通概念及其关系入口必须继续结构化返回 `未实现`；不得绕过材料和世界服务验证端点。
5. 普通应用尚未装配不可变材料服务，不能为装配临场选择默认目录；这不阻塞同一服务内关系 ABI 和生产实现。

## 5. 同截止图读取与首次请求见证修正

### 5.1 当前与历史关系组

组读只经概念 owner 的现有直接上位关系类型读取。按下位使用目标端点关系组，按上位使用源端点关系组；不得扫描通用关系、其它 owner 或裸 L1 仓库。

成功组按 `(上位概念编码, 下位概念编码, 关系稳定编码)` 严格升序，关系不重复，全部关系生命周期覆盖同一返回截止。空组合法：本体根直接上位组为空、叶概念直接下位组为空、历史截止尚无命中均可成功。组大小超过请求预算返回 `数量预算不足`、空组、零变更。

当前端点必须在 `G0` 为四本体根之一或当前完整普通概念；历史端点必须在 `H` 存在完整根或普通概念。每条关系两端都在同一截止正式读回：上位可为本体根或普通概念，下位必须为普通概念，两端归属同一本体根。

### 5.2 首次建立请求不随当前父组变化

普通概念节点创建代次记为 `C0`。现行私有首次见证继续保存 `[首次幂等身份, 首次期望事实代次, 普通概念合同版本]`；该见证只定位首次 owner 写入材料，不复制完整请求。

`重建普通概念自有事实(...)` 改为两条分账：

1. 返回指定截止 `G/H` 的当前结构时，直接上位关系只要求 `创建代次 <= 截止` 且在该截止有效，不再要求关系与概念同代创建。
2. 需要重组首次建立请求时，固定以 `C0` 进行一次历史自有结构重建，只取 `C0` 已创建且当时有效的根归属、签名、定义、初始直接上位、来源证据和初始生命周期；其完整请求必须与 owner 端口按首次幂等身份读取的首次规范化写集逐项互证。

当前父组的后继增替退不得改变首次请求、签名唯一键或首次建立精确重复结果。原建立请求精确重复始终返回 `C0` 历史完整事实，不把后继关系误回显为首次写集。

## 6. 写前结构裁决

全部写入口先取得服务级概念写锁，再在请求 `G0`：

1. 经现有完整公开读回验证旧 / 新上位与下位端点；根可以作上位，不能作下位。
2. 读取四本体根和全部当前普通概念的直接上位组，形成仅属于本次调用的值式 DAG；不持久化图、闭包或索引。
3. 验证当前图中每个普通概念至少一条直接上位、仅能到达一个本体根、两端同根、零自环、零重复边且整体无环。
4. 在值式图上应用候选新增、替换或退出，再次验证同根、无环和全部普通概念唯一根可达。
5. 新增若 `(上位, 下位)` 已有当前边返回 `引用冲突`。替换 / 退出必须由稳定编码、方向和两端精确命中旧当前边；只命中编码或端点返回 `引用冲突`。
6. 退出或替换不得使下位成为零父概念；替换的新边不得与既有当前边重复。

图完整性矛盾、同一稳定编码复义、重复当前边、多根可达或无根可达返回 `内部不一致`。调用方请求本身的跨根、自环或根作下位返回 `入口拒绝`；合法当前冲突返回 `引用冲突`。

## 7. owner 原子写集、幂等与发布未知

不新增关系类型登记。三类请求均以调用方 `L2结构幂等身份` 数值形成 owner-scoped L1 写幂等身份，并与概念根建立、普通概念建立共用同一服务写锁。

固定本地键：

| 本地键 | 用途 |
| --- | --- |
| `0x020A'3001` | 新增或替换形成的新直接上位关系 |

写集：

- 新增：只新增一条 `上位 -> 下位` 的现有直接上位关系类型事实；关系角色 / 顺序使用固定内部值 `1`，不进入公开 DTO。
- 替换：同一写集退出调用方具名旧关系，并新增一条 `新上位 -> 下位` 关系。
- 退出：只退出调用方具名当前关系。

提交前先用 owner 写端口 `读取首次写入材料(...)` 查询同幂等身份：同一首次规范化写集返回精确重复；不同写集返回幂等冲突；未找到才允许提交。首次成功和精确重复都必须按首次结果截止历史读回本次关系变化。发布未知、资源失败或发布后读回失败必须保留并重放原完整请求和原幂等身份；不得用当前图重新猜测一份“等价”请求。

## 8. 成功形状与错误映射

写成功只允许 `已提交` 或 `精确重复`，事实截止非零、变更代次存在且等于事实截止：

| 操作 | `当前关系` | `已退出关系` |
| --- | --- | --- |
| 新增 | 有值，生命周期在截止当前 | 空 |
| 替换 | 有值的新关系 | 有值的旧关系，退出代次等于截止 |
| 退出 | 空 | 有值，退出代次等于截止 |

写成功截止必须晚于首次请求守卫；精确重复返回首次提交截止和首次形状。任一非成功的两个 optional 都为空、变更代次为空。

组读成功只允许 `已读取`，事实截止非零、变更代次为空；当前成功截止等于请求 `G0`，历史成功截止等于 `H`。任一非成功关系组为空、变更代次为空。

错误分账：

| 条件 | `L2结构状态` |
| --- | --- |
| 无效请求、根作下位、跨根、自环、根专用实例调用 | `入口拒绝` 或 `未实现` |
| 端点或旧关系不存在 | `未找到` |
| 端点已退出 | `已退出` |
| 请求守卫不再当前 | `事实代次漂移` |
| 同幂等异写集 | `幂等冲突` |
| 重复边、旧关系编码 / 方向 / 端点不符、退出后零父 | `引用冲突` |
| 组超预算 | `数量预算不足` |
| L1 或依赖资源失败 | `资源失败` |
| 坏成功形状、图已成环、多根 / 无根、重复当前关系或混代 | `内部不一致` |
