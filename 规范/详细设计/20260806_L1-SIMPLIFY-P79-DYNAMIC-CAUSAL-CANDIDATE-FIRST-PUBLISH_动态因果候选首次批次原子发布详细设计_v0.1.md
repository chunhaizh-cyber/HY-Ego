P76 已冻结从调用方已有的 P29 完整世界快照形成动态事件因果候选的唯一纯值解释，包含
待应用确认、材料不足跳过、事件级时间 DAG、类型/对象后续往复允许和合法空。P77 已冻结

`9+16N` 新编码与 `9+23N` 同锁读回。P78 已把公共领域意图合法边界扩展到 G9，且明确

映射、同锁发布后读回和同义/异义分账；P79 只消费公开接口，不复制算法、账、编码器、恢复
载体或内部 DTO。P77 全部新事实只进入 L1，无第二领域投影，故 P37/P54 参与者和第二账为0。

正式候选读取必须晚于候选事实发布；应用确认必须消费已发布候选；安全直接因果图只能消费
已经确认的因果。旧轻量因果引用、因果模式和隔离安全图不是事件候选事实所有者。因此 P78
之后唯一最早独立叶是首次非空候选批次原子发布者，不是读取、确认或安全图 provider。

## 5. G9 操作身份、入口与意图编码

正式树中 `0x01—0x17` 已被既有领域操作占用，P79 固定：

```text
L1幂等域高8位 = 0x18
低56位 = 动态因果候选首次发布幂等身份.值
G9入口变体 = 1
领域操作标签 = U32 0x5033'7901
领域编码前缀 = HZY-L1G9
专项身份 = L1-SIMPLIFY-P79-S01
专项顺序 = 579
```

入口在任何探测或分配前验证：顶层/P76/P77版本精确；幂等身份在
`1..0x00FF'FFFF'FFFF'FFFF`；P76世界根和预期截止非零；P77预期代次等于P76预期截止；
快照完整、世界根/事实截止与P76请求相等。失败返回入口拒绝且探测/P76/P77/提交全0。

G9请求意图摘要按网络大端编码：`HZY-L1G9`、格式1、操作标签、入口变体、顶层合同/规则、
幂等身份、P76请求全部公开字段、P77请求全部公开字段。它不编码快照内容、P76结果、P77草案、
稳定映射、provider结果、日志、锁、地址或系统时间。全零摘要为内部不一致且不探测。

探测只接受 G9 凭证。未找到进入首次路径；同义已发布且材料完整返回幂等读回，P76/P77/提交
为0；异义为幂等冲突；许可拒绝/隔离、资源失败和坏成功分别映射，不携带业务事实。

## 6. P76/P77、合法空与状态分账

仅探测未找到时：

1. 以请求中的投影请求和调用方快照调用 P76 恰一次；P79不读P29。
2. 只接受 P76 成功、完整、根/截止/版本/计数闭合的投影。
3. 以写集请求和 P76 完整投影调用 P77 恰一次。
4. P77 `合法空` 映射 P79 `合法空`，提交0，且不得创建 G9 登记或占用持久幂等账。
5. P77 `已形成` 必须携带非空草案并满足全部数量公式，方可提交。

材料不足可以使 P76 成功投影中存在跳过项；只要候选组非空，P79发布这些候选并在来源投影中
保留跳过分账。跳过项不生成候选事实，不是错误。合法空后材料充分时允许再次调用；因空路径
没有提交和幂等账，不会把自我无知永久冻结。同一幂等键一旦成功发布，再以不同截止或任一
公开字段调用即为异义冲突。

P76/P77入口拒绝、内部不一致、错根/截止/计数或坏成功均映射内部不一致；P76/P77版本不等
映射版本漂移；资源失败同名映射。函数不内部等待、sleep、重试、换键或重读快照。

## 7. 一次正常进程内事务与完整读回

仅从 P77 非空草案构造一个 L1 v2 请求：期望代次取共同截止，幂等键取0x18映射，G9凭证
取第5节摘要，写项和读回计划逐字段复制；P37/P54参与者组为空。P15提交恰一次。

设候选数为N，成功或精确重复必须满足：

1. 发布代次非零且晚于来源截止；映射恰`9+16N`项，本地键连续且各一次；
2. 同锁读回恰`9+23N`项，顺序和内容逐项等于P77计划；
3. 键1/2为服务/关系类型，3—9为七属性类型，10—`9+N`为候选节点；
4. 后续`7N`值和`8N`关系逐候选映射，七槽指向对应值；角色1—8各一次，9/10为0；
5. 节点/关系/值创建代次等于发布代次且当前，关系端点、值来源及U64组材料与P77一致；
6. P76候选键、真实性待应用确认、动作/方法为空、时间顺序和来源截止与发布事实逐项互证。

任一缺项、额外项、重复键、错对象/端点/角色/槽/来源/代次返回内部不一致，保留已发布标志，
不回滚、补写或第二提交。全部登记与候选在同一代次可见；不建候选专用账、稳定编码器、缓存
或第二锁。

本叶只覆盖同一生产进程正常存活期间的原子发布、进程内幂等/冲突和读回。现有P15恢复字段
不在本叶证明范围；不设计恢复介质、启动扫描、崩溃窗口、跨进程成功账或恢复矩阵。
