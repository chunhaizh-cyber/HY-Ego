# L1 简化事实基座 P0 详细设计

日期：2026-08-04
状态：首个可施工叶的冻结设计；只建设独立 L1，不接线运行期，不删除旧基座。

直接依据：0050、4010、4015、4020、4040、4050、4060、4070、CODE-FILE-01，以及 `BIZ-L1-BASE-001`。

## 1. 范围和当前事实

当前 `运行期上下文::L1事实基座` 是旧四仓的引用聚合；节点直接五仓也仍以身份版本、关系版本和值记录版本工作。它们均不得复用为新 L1 的内部实现。

P0 只交付一个可独立构造、可并发读取、可原子提交、可读回和可隔离恢复的 L1 内核。它不接入 `运行期上下文`、世界树、特征、状态、需求、任务、方法、SQL 或材料文件；这些消费者均为后续迁移叶。

## 3. 冻结数据合同

### 3.1 基本类型

```cpp
struct 稳定编码 { std::uint64_t 值 = 0; };
struct 写集本地键 { std::uint32_t 值 = 0; };
struct 写集幂等键 { std::uint64_t 值 = 0; };
using 事实引用 = std::variant<稳定编码, 写集本地键>;

enum class 节点种类 : std::uint8_t { 普通 = 1, 属性类型 = 2 };
enum class 值表示种类 : std::uint8_t { I64 = 1, I64组 = 2, U64组 = 3, 独立材料引用 = 4 };
enum class L1写入状态 : std::uint8_t {
    成功 = 1, 精确重复 = 2, 入口拒绝 = 3, 未找到 = 4, 已退出 = 5,
    事实代次漂移 = 6, 幂等冲突 = 7, 资源失败 = 8, 内部不一致 = 9
};
```

`稳定编码` 仅代表已发布或候选中的节点、关系和值；零无效，发布或退出后永不复用。`写集本地键` 只在一次请求内引用同写集新建项，不能进入读回、索引、恢复材料或领域事实。`写集幂等键` 是操作键，不是节点、关系和值编码。

### 3.2 三类事实与属性槽

```cpp
struct 节点事实 { 稳定编码 编码; 节点种类 种类; std::uint64_t 创建事实代次; std::optional<std::uint64_t> 退出事实代次; };
struct 属性类型规格 { 值表示种类 表示; };
struct 关系事实 { 稳定编码 编码; 稳定编码 源节点; 稳定编码 目标节点; 稳定编码 关系类型节点; std::int64_t 角色或顺序; std::uint64_t 创建事实代次; std::optional<std::uint64_t> 退出事实代次; };
struct 值事实 { 稳定编码 编码; 稳定编码 所属节点; 稳定编码 属性类型节点; 原始值材料 材料; 稳定编码 来源节点; std::uint64_t 创建事实代次; std::optional<std::uint64_t> 退出事实代次; };
struct 属性槽 { 稳定编码 所属节点; 稳定编码 属性类型节点; 稳定编码 当前值; };
```

`属性类型规格` 是属性类型节点的固定内部规格：L1 只验证值材料分支与其匹配，不解释单位、坐标、轮廓或业务值域。系统签发值仍必须引用由签发服务建立的系统签发者节点；L1 不接受空来源或服务对象伪装为来源事实。

节点到节点仅由 `关系事实` 表达。每个 `(所属节点, 属性类型节点)` 至多有一个当前属性槽。节点退出前，所有当前入边、出边和值都必须同写集退出或已不存在；L1 不自动推导退出。

### 3.3 写集和结果

```cpp
struct 节点新建项 { 写集本地键 本地键; 节点种类 种类; std::optional<属性类型规格> 属性类型规格; };
struct 关系新建项 { 写集本地键 本地键; 事实引用 源节点; 事实引用 目标节点; 事实引用 关系类型节点; std::int64_t 角色或顺序; };
struct 值新建项 { 写集本地键 本地键; 事实引用 所属节点; 事实引用 属性类型节点; 原始值材料 材料; 事实引用 来源节点; };
struct 属性槽变更项 { 事实引用 所属节点; 事实引用 属性类型节点; 写集本地键 新当前值; };
struct L1写集请求 { std::uint64_t 期望事实代次; 写集幂等键 幂等键; std::vector<节点新建项> 节点; std::vector<关系新建项> 关系; std::vector<值新建项> 值; std::vector<属性槽变更项> 属性槽变更; std::vector<稳定编码> 退出事实; };
struct L1写入结果 { L1写入状态 状态; std::uint64_t 事实代次; std::vector<std::pair<写集本地键, 稳定编码>> 新编码映射; };
```

空库首写的 `期望事实代次` 必须为 `0`；非空库必须精确等于当前代次。请求内所有本地键全局唯一且非零；每个新建值须由恰一个属性槽变更引用；每个属性槽变更新值必须属于同一宿主和属性类型；已有当前值替换时旧值必须同写集退出。一个新关系可引用本写集新节点，但不能引用新值或新关系。

提交先比较幂等键及规范化写集内容：同键同内容返回首次结果，代次不推进；同键异内容返回冲突。首次提交只在候选副本完整后按稳定的本地键顺序分配编码，并在最后一次状态替换时将全部新 / 退出事实标记为同一个新事实代次。

## 4. 服务与仓库函数

`L1事实基座仓库` 只向 `L1事实基座服务` 暴露候选构造、确认、撤销、发布、恢复候选和只读快照；不导出内部表、锁或候选令牌。

服务唯一公开成员如下：

```cpp
L1写入结果 提交写集(const L1写集请求& 请求);
L1读取结果 读取当前节点(稳定编码 编码) const;
L1读取结果 读取当前关系(稳定编码 编码) const;
L1读取结果 读取当前值(稳定编码 编码) const;
L1属性读取结果 读取当前属性(稳定编码 节点, 稳定编码 属性类型) const;
L1完整快照结果 读取完整快照() const;
L1恢复结果 建立恢复候选(const L1完整快照& 材料, std::uint64_t 期望事实代次);
```

所有读取返回调用方拥有的值式副本。组合读取在同一共享读锁中读取一个代次；首末代次不同仅可重试一次，仍不同返回 `事实代次漂移`。恢复候选和普通写集共用完整性谓词，但恢复不得与普通运行期事实混合或直接覆盖当前状态。

## 5. 事务、并发与异常

仓库以一把内部 `shared_mutex` 保护当前不可变状态指针。写线程在独占锁内复核期望代次、幂等和全部引用，在候选副本上完成分配、退出、属性槽和索引重建；任何分配或校验失败均丢弃候选，不改变当前状态。成功时一次替换当前状态并把事实代次加一。读线程只持共享锁复制当前状态；领域调用、日志、SQL、材料文件、回调和跨服务调用均不在锁内发生。

恢复候选先在独立状态副本中验证全局编码占用、节点 / 值 / 槽 / 关系完整性和事实代次；确认后同样只能一次替换，不可逐项回填。发布后同一服务按新编码、属性槽和代次读回；不一致返回内部不一致，不能以撤销伪装发布后回滚。

## 6. 自检矩阵与完成边界

`运行L1事实基座自检()` 至少验证：

1. 一个普通节点有三个不同属性类型的直接值及两个关系子节点，关系和属性槽不重复记账；
2. 同写集局部键可建立类型节点、宿主节点、值和关系；错误类型、错误材料、跨种类引用和重复本地键在写前拒绝；
3. 属性替换和关系替换均使旧事实退出、新事实新编码发布，旧编码不得复用；
4. 未退出旧值、槽和值归属不符、退出节点仍有当前边或当前值、悬空端点均零发布；
5. 同键同写集精确重复、同键异写集冲突、期望事实代次漂移、资源失败候选和逆序撤销；
6. 当前 / 历史 / 审计读取分离，完整快照不返回混代材料；
7. 索引清空后由三类事实确定重建；恢复材料缺项、编码复义、槽矛盾和关系断裂隔离，完整材料可原子恢复；
8. Debug / Release 完整自检中只新增 `L1-SIMPLIFY-P0-S01`，总数由 S0 的 `N` 变为 `N+1`。

P0 完成只证明新 L1 内核、值式 API、恢复候选和专项自检已进入工程。它不证明运行期已改用新 L1，也不证明世界树、特征、状态、动态、需求、任务、方法、SQL 持久化或旧基座删除已完成。
