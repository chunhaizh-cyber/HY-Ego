## 1. 唯一裁决

本次只闭合第三根因，不改变任何机器语义：

1. `L2状态动态原子发布服务` 只由 `海中鱼巣.领域.服务.L2状态动态原子发布` 首次声明和定义；删除状态模块第 37 行错误前置声明和第 4084 行 friend。装配文件不写，重新编译后两个 getter 自然绑定唯一真实类。
2. `L2状态动态原子发布.数据.h` 是动态发布请求/结果 DTO 的共享普通头。唯一冻结形态是保留现有 global module fragment、`NO_INCLUDES`、module declaration 和 imports，只把 module declaration 后的普通 export-include：

```cpp
export {
#include "L2状态动态原子发布.数据.h"
}
```

机械替换为：

```cpp
export extern "C++" {
#include "L2状态动态原子发布.数据.h"
}
```

该 language-linkage export 同时保持 import 可见性，并使头内 DTO 和其 `成功()` 等函数附着全局模块；`L2状态动态原子发布服务` 类自身仍附着 `海中鱼巣.领域.服务.L2状态动态原子发布`。数据头正文、依赖头和消费者均不修改。

独立 exact 探针已在 v143 14.44 与 v145 14.51 上分别验证三方：仅 import 的模块消费者、普通非模块文本 include 消费者、include+import mixed 消费者全部 compile/link/run exit 0；dumpbin 中生产者定义与文本消费者 UNDEF 使用同一无附着 DTO 方法符号，服务类只保留服务模块附着。因此该裁决不是依赖 import 顺序或链接器偶然选择。

排除项也已冻结：现行普通 `export { #include }` 与 mixed 文本消费者触发 C1117；`export using` 只形成别名，不改变原实体 owner；把真实数据头前移 global module fragment 会迫使其依赖链在 import 前整体文本化并产生 imported/textual 实体重叠风险。不得在施工时改用这些候选，不得再次声明、alias、typedef、包装或复制同名 DTO。

3. 不授权修改 `L2状态动态原子发布.数据.h`：它已有 `#pragma once` 和条件依赖 include，胜出方案无需改正文或守卫。若真实工程在 v143/v145 任一工具链仍出现 DTO 重复实体、不可达或附着分裂，立即按新设计漂移停止，不得临场改 DTO、复制声明或扩大到另一合同模块。

## 2. 状态 owner 的最小公开窄合同

动态发布模块当前对状态服务私有面的消费只有：`结构类型登记定位_`、`状态上下文关系类型定位_`、`中性状态提供者_.形成当前值记录状态参与者_v1(...)` 和 `第一层写入端口_`。不得公开字段、嵌套 provider 或整个 private 区，冻结为以下公开 wrapper：

```cpp
struct L2状态结构服务::当前值记录状态参与者结果_v1 final {
    L2结构状态 状态;
    std::optional<L1三分区原子参与者写集_v2> 参与者;
    L1所有者范围写集本地键 前状态本地键, 后状态本地键, 新选择本地键;
    std::optional<L2中性状态引用事实_v1> 旧选择;
    bool legacy基线兼容;
};

bool 组合发布当前值状态材料就绪_v1() const noexcept;

当前值记录状态参与者结果_v1 形成组合发布当前值记录状态参与者_v1(
    const L2结构请求头&, L2结构幂等身份, L2特征定义身份,
    const L2原始值材料&, const L2原始值材料&, std::int64_t,
    L2存在身份, L2场景身份, L2特征实例身份, L2存在身份,
    稳定编码, const std::optional<L2中性状态引用事实_v1>&,
    bool) const noexcept;

const L1所有者范围写端口& 取得组合发布写入端口() const noexcept;
```

`组合发布当前值状态材料就绪_v1()` 的正文精确等价于当前动态发布前置检查的状态侧条件：`结构类型登记定位_.has_value()` 且 `状态上下文关系类型定位_.关系类型` 有效；它不吸收动态 owner 的材料检查。原子发布侧必须继续先调用该就绪 helper，`false` 精确返回 v1 `材料不足`，不得把这一分支推迟到参与者形成或改成 `入口拒绝`。

参与者 wrapper 只原样委托现有 helper，并由状态 owner 内部注入 `状态上下文关系类型定位_.关系类型`、`结构类型登记定位_->当前选择关系类型` 和 `第一层写入端口_.所有者身份()`。为防止未来误调用在定位缺失时解引用 optional，wrapper 自身还必须先复核同一就绪 helper；失败时返回空载荷、`状态 = L2结构状态::未找到`，使现有 `映射结构失败` 仍归类为 `材料不足`，不得返回会改变外层分类的 `入口拒绝`。动态发布成员类型保持当前 `const L2状态结构服务&`，因此 const 端口 getter 是必需 ABI；它只供既有 `参与者首次完整` 读回。现有非 const getter 保留。wrapper 不新增许可、写入、提交、锁或其它失败映射。

动态发布源码只把 4 类私有访问机械替换为上述 3 个窄入口。两个登记定位不再向外暴露，事务凭证、提交顺序、读回、幂等、漂移、资源失败、内部错误和已可能发布分支全部零变化。
