# ARCH-L3-CONCEPT-SPACE-PROJECTION-PRODUCTION-CLOSURE 概念空间根视图与生产接线详细设计

版本：v0.1
日期：20260825
状态：设计就绪、等待 L4 代码资源释放；不代表代码已实现，不登记执行队列
上游：2220、4190、4200、L2概念结构公开读取能力

## 1. 目标与边界

本设计冻结一个只读的 `DATA-L3` 概念空间根视图聚合：在一个共同 `G0` 截止下读取四个语言无关本体根、普通概念及其完整直接多父边，并按请求可选读取叶级世界事实支持关系引用。它只形成值式投影，不写 L1/L2、不持久化投影、不形成概念、不解释世界真实性。

本设计不实现概念候选形成、概念准入、名称绑定、语言消歧、世界树业务资格、任务 / 方法 / 需求、L4 消费者、L5 表达、根初始化代码改造或任何业务结果。

## 2. 当前事实与复用裁决

| 能力 | 当前事实 | 本设计裁决 |
| --- | --- | --- |
| 四本体根 | `L2概念结构.数据.h` 已有四角色、根组请求 / 结果；服务已公开 `读取全部当前概念本体根` | 直接复用；根组正式读回是唯一权威 |
| 普通概念 / 直接边 | 服务内部已有 `读取当前概念图`、节点和边值式结构，但不是公开 ABI | 先由 L2 公开纯结构读取提供者暴露等价有界合同；L3 禁止调用 private helper |
| 支持关系 | L2 已公开按概念、按世界事实读取支持关系组 | 复用同截止读取；只投影端点和关系稳定编码 |
| L3 聚合壳 | `服务.L2概念结构聚合.ixx` 只有绑定壳，无根视图 ABI | 新建独立 `L3概念空间根视图.数据.h` 与 `服务.L3概念空间聚合.ixx`，不把 L3 DTO 塞入 L2 壳 |
| 根初始化缓存 | 业务初始化仍有“已发布材料”缓存 | 本设计不改代码；后继改造必须把它降为重放证据缓存，不得替代正式根组读回 |

## 3. 合同版本与类型

新增 L3 合同常量：`L3概念空间根视图合同版本 = 1`。L2 结构合同版本保持 `1`，L3 不改变 L2 ABI。

建议在 `海中鱼巣/领域/L3概念空间根视图.数据.h` 中定义以下公开值类型（名称、字段和顺序为冻结合同）：

```cpp
struct L3概念空间根视图预算 final {
    std::size_t 根数量上限 = 4;             // 必须等于四根闭集
    std::size_t 概念数量上限 = 0;           // 非零
    std::size_t 直接边数量上限 = 0;         // 非零
    std::size_t 叶级支持数量上限 = 0;       // 叶级开关为开时非零
    std::size_t 负载字节上限 = 0;           // 0 表示不启用字节预算
};

struct L3概念空间根视图读取请求 final {
    L2结构请求头 请求头;
    std::uint32_t 视图合同版本 = L3概念空间根视图合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    bool 包含叶级支持关系 = false;
    L3概念空间根视图预算 预算;
};

struct L3概念空间根引用 final {
    L2概念本体根角色 角色;
    L2概念身份 根概念;
};

struct L3概念空间概念引用 final {
    L2概念身份 概念;
    L2概念身份 本体根;
};

struct L3概念空间直接边引用 final {
    稳定编码 关系;
    L2概念身份 上位;
    L2概念身份 下位;
};

struct L3概念空间叶级支持引用 final {
    L2概念身份 概念;
    L2世界事实引用 世界事实;
    稳定编码 支持关系;
};

struct L3概念空间根视图 final {
    std::vector<L3概念空间根引用> 根组;
    std::vector<L3概念空间概念引用> 概念组;
    std::vector<L3概念空间直接边引用> 直接边组;
    std::vector<L3概念空间叶级支持引用> 叶级支持组;
};

struct L3概念空间根视图读取结果 final {
    L2结构结果头 结果头;
    std::uint32_t 视图合同版本 = L3概念空间根视图合同版本;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    std::optional<L3概念空间根视图> 视图;
    bool 成功() const noexcept;
};
```

成功的值式条件为：结果状态为 `已读取`，结果合同版本正确，实际截止非零且未产生变更代次，根组恰为四个角色且排序唯一，概念 / 边 / 叶级支持组满足排序、端点和同截止闭包，且 `视图` 非空。任何非成功状态都必须令 `视图` 为空。

## 4. 直接上游 L2 纯结构合同

当前 L2 服务的 `读取当前概念图` 是 private 值，不得被 L3 越权调用。本设计直接冻结其公开、只读、有界的最小合同（仍使用 `L2结构合同版本 = 1`）；代码施工时必须在现有 L2 概念结构数据 / 服务物理位置实现该合同：

```cpp
struct L2当前概念图读取请求 final {
    L2结构请求头 请求头;
    L2读取类别 读取类别 = L2读取类别::当前;
    std::uint64_t 历史截止事实代次 = 0;
    std::size_t 概念数量预算 = 0;
    std::size_t 直接边数量预算 = 0;
};

struct L2概念图节点引用 final {
    L2概念身份 概念;
    L2概念身份 本体根;
};

struct L2概念图直接边引用 final {
    稳定编码 关系;
    L2概念身份 上位;
    L2概念身份 下位;
};

struct L2当前概念图读取结果 final {
    L2结构结果头 结果头;
    std::vector<L2概念本体根事实> 本体根;
    std::vector<L2概念图节点引用> 普通概念;
    std::vector<L2概念图直接边引用> 直接边;
};
```

该合同只公开当前 / 历史结构读回、实际截止、预算和结构化失败；不得公开内部仓库、写端口、业务判定或私有定位对象。L3 只能消费该公开结果，不能访问 L1、private helper 或仓库扫描。

## 5. 唯一生产入口与所有权

未来唯一业务无关入口：

```text
L3概念空间聚合服务::读取概念空间根视图(
    const L3概念空间根视图读取请求&) const
    -> L3概念空间根视图读取结果
```

`L3概念空间聚合服务` 持有同一装配实例的 `L2概念结构服务` 只读引用；叶级支持读取只通过该 L2 服务公开入口完成。L3 不持有 L1 写端口，不拥有任何概念或世界事实身份，不向初始化 provider 索要“已发布材料”。

## 6. 读取顺序与共同 G0

1. 入口先校验 L3 版本、L2 请求头、读取类别、历史截止和全部预算；失败返回入口拒绝或数量预算不足、零载荷。
2. 以请求的期望代次取得 L2 根组。期望代次为零时由根组正式读回取得共同 `G0`；非零时所有后续读取必须使用同一 `G0`。
3. 根组必须恰有存在、特征、动态、因果链各一根，角色和根身份唯一，根事实完整且在 `G0` 可读。
4. 以同一 `G0` 读取 L2 概念图公开合同，核对每个普通概念归属四根之一、所有端点存在、直接边同根且不成环。
5. 若请求包含叶级支持关系，按概念组逐项读取同一 `G0` 的支持关系；核对概念端点、世界事实引用、支持关系生命周期和截止一致。不得用按世界事实扫描替代按概念有界读取。
6. 在临时值对象中去重、稳定排序、执行闭包和负载预算检查；所有检查成功后一次构造结果，不写任何事实。

`G0` 取得后任一上游返回不同截止，或返回 `事实代次漂移`，L3 不升级 / 降级截止、不拼接快照，直接返回对应失败状态和零载荷。

## 7. 投影不变量

- 根排序按 `L2概念本体根角色` 的固定数值顺序；角色集合恰为四项。
- 概念按 `L2概念身份.值` 升序去重；同一概念只能有一个本体根归属。
- 直接边按 `(上位.值, 下位.值, 关系)` 稳定排序，所有直接多父边均保留；不生成传递闭包、单父边、层号或显示路径。
- 叶级支持按 `(概念.值, 世界事实引用稳定排序键, 支持关系)` 稳定排序，同一 `(概念, 世界事实, 支持关系)` 不得重复。
- 叶级支持只带身份 / 关系引用，不复制世界节点、属性值、状态、动态、因果或材料事实。
- 任一端点缺失、重复身份、跨根边、环、跨截止或支持关系不闭合，均为内部不一致并清空完整投影。

## 8. 四本体根初始化与生产接线边界

本叶未来施工白名单包含 `业务/四本体根生产初始化.数据.h`、`业务/初始化.四本体根.inl`、`业务/提供者.四本体根生产初始化.ixx`、`装配.普通应用.ixx`、`海中鱼巣.vcxproj` 和 `海中鱼巣.vcxproj.filters`。初始化 provider 必须经正式初始化入口和普通应用唯一装配实例取得 L2 概念结构服务；生产成功、首次和精确重复均以正式根组 / 公开概念图独立读回裁决。

进程内 `已发布材料` 必须删除，或降级为不参与读入口裁决的内部重放见证；它不得决定当前根、首次、重复或投影成功。缓存与正式根组 / 概念图不一致返回 `内部不一致/发布未知`，不得用缓存覆盖正式读回。

## 10. 验证与完成声明

未来执行必须使用真实 L2 公开读入口和独立读回，不得复制生产算法到测试专用假服务。专项矩阵至少覆盖：四根恰一、根角色重复 / 缺失、概念去重排序、多父边完整保留、跨根边拒绝、环拒绝、叶级支持开关、支持端点坏引用、共同 G0、历史截止、许可拒绝、预算超限、资源失败、非成功零载荷，以及缓存与正式根组不一致。

必须在根工程 Debug / Release、专项中性 harness、普通应用真实装配和正式结构读回中分别记录结果。构建通过只证明编译和结构调用；只有真实 L3 入口在同一 G0 返回完整投影并完成独立读回，才可声明本叶集成闭合。概念形成、语言、L4、L5 和业务正确性均未证明。
