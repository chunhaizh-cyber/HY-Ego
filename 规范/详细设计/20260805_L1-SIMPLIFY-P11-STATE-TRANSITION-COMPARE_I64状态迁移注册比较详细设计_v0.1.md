## 1. 目标与完成边界

本叶原位扩展 `海中鱼巣.领域.服务.特征比较`，建立第一个真实 `I64 + 状态迁移` 注册比较提供者。

一次比较固定以 P9 v0.3 不可变状态采样值为左，以 P10 换代后经 P8 读回的新当前值为右；按 P10/P8 返回的真实 P2 抽象特征定义和 `状态迁移` 用途确定唯一当前4180注册，同时返回排序三态、迁移具名关系、等价结论、安全 `新值-旧值` 差异、注册身份和完整输入见证。

本叶必须形成真实登记、正式读回和只读比较成功行为，不允许固定未实现或零调用骨架。

本叶不发布第二关系19状态、关系20迁移动能、动作动态、来源动作、因果、需求、任务、结算或任何其它机器事实；不实现生产装配、SQL、恢复、旧消费者迁移或3F。

## 2. 正式依据与能力裁决

- 4180：注册以“特征定义+用途+算法族+算法版本”唯一定位；状态迁移固定左旧右新、差异右减左；算法由当前注册路由，不由调用者选择。
- 4190/4210：状态迁移只允许同主体、同场景、同一具体特征；无材料变化不生成动态；比较拒绝不是第四种迁移结果。
- P6 v0.2 冻结同一服务、登记节点、合同配置属性类型、字段关系类型、无单位/标量维度/标量分量角色及目标判断真实合同，但它尚是待实现提供者，且目标判断用途、右值来源与关系语义不得复用为状态迁移合同。
- P9 v0.3 冻结不可变前状态：主体、采样场景、角色3实例槽、被采样P8值真实见证、采样I64、发生时间和来源；它不输出P2定义。
- P10 v0.1 经 P8 当前入口返回同一存在自己的实例槽、真实 P2 定义/定义关系、新当前值和来源；相同材料也会形成新值编码和新代次，编码变化不等于材料变化。
- 当前能力目录与代码图谱没有新 L1 状态迁移比较提供者。旧句柄、旧 `比较特征值候选`、WORLD-TREE比较/状态动态计划和未跟踪草稿只作负面证据。

复用裁决：同服务、同登记体系原位扩展；新增独立迁移用途合同和专用比较入口。不得包装 P6 目标判断入口，也不建立通用类型兼容层。

## 8. 迁移合同 L1 事实结构

使用新私有幂等域 `0x0E`。服务登记仍复用 P6 `0x08`，目标判断合同仍为 `0x09`。

登记请求先从 P2 定义登记/读回和 P3/P8 实例登记取得字段来源，并在同一完整快照确认。唯一写集包含：

- 一个普通注册身份节点；
- 一个 I64组配置值，所属注册身份、属性类型为服务登记的合同配置属性类型、来源为服务身份；
- 一个当前配置属性槽；
- 七条合同字段关系，源为注册身份、类型为同一合同字段关系类型：

| 角色 | 节点目标 |
| --- | --- |
| 1 | P2 抽象特征定义节点 |
| 2 | P3/P8 定义模板关系类型节点 |
| 3 | P3/P8 当前 I64 值属性类型节点 |
| 4 | P6 服务登记无单位节点 |
| 5 | P6 服务登记标量维度节点 |
| 6 | P6 服务登记标量分量角色节点 |
| 7 | P2 定义来源服务节点 |

P2 定义标记、下界和上界值事实不作为关系端点。配置 I64组固定为：

```text
[配置版本1, 用途2, 算法族1, 算法版本1, 原始类型1,
 左角色3, 右角色4, 差异方向1, 允许结果位7, 当前有效1,
 边界包含1, 量化规则1, 允许直接持久化0,
 溢出处理1, 缺值处理1, 输入版本规则1, 误差合同版本1,
 P2定义标记材料, P2下界材料, P2上界材料]
```

合同 DTO 保存三个 P2 值编码，读回时在同一快照互证其所属、属性类型、来源、当前性和材料。一个 `特征定义+状态迁移` 只能有一个当前注册；目标判断注册不与其冲突。

## 9. 单截止输入读取与注册路由

迁移比较固定执行：

1. 校验请求版本、请求身份、预期截止和两份嵌套请求；provider 未绑定或形状非法为入口拒绝。
2. 读取起始 L1 完整快照 `G0`，必须等于请求预期截止。
3. 调用 P9 `读取实际存在I64基准状态`，只接受完整 `已读取`；其 `读取事实截止代次` 必须等于 `G0`。
4. 调用 P8 `读取实际存在I64实例特征`，只接受完整 `已读取`；其事实截止代次必须等于 `G0`。P8 成功同时证明嵌套 P7 当前主体/场景请求和 P2 定义请求有效。
5. 读取结束 L1 完整快照 `G1`；要求 `G0==G1`。一次完整重试仍漂移返回 `版本漂移/输入版本失效`，不返回混代输入。
6. 只使用 P8 实际结果中的 P2 定义，以 `特征定义+状态迁移` 在 `G1` 快照内确定唯一当前合同。调用方不提供算法或注册身份。

注册读回验证注册节点、配置槽、配置值、七关系、七节点目标和 P2 三值事实。零注册为 `未注册/未注册`，失效为 `未注册/注册失效`，多当前为 `内部不一致/注册不唯一`。

## 10. 输入校准

在同一 `G1` 快照逐项证明：

1. `前状态.主体.编码 == 后当前.事实.宿主`；
2. `前状态.特征.编码 == 后当前.事实.实例槽`；这是同一具体特征的唯一主校验；
3. P8 嵌套实际存在请求中的当前场景及归属关系已被 P8 成功校验，且当前场景编码必须等于 `前状态.场景.编码`。本叶不跨场景比较；场景不同为 `入口拒绝/左右角色不合法`；
4. 后当前定义关系在快照中从该实例槽指向 P8 返回的 P2 定义；该定义必须等于注册定义；
5. 前状态被采样值所属节点等于该实例槽。其属性类型、后当前值属性类型和合同当前 I64 属性类型三者相等，但该属性类型不解释为 P2 定义；
6. 前后材料均为 I64，均位于注册的 P2 闭区间；单位、维度、分量角色和原始类型等于合同；
7. 前值编码不同于后当前值编码。前值退出代次必须有值且晚于前状态节点创建代次；后当前值创建代次必须不早于前值退出代次。二者相等表示一次直接换代，后值创建更晚表示第二状态形成前发生了合法中间换代；本叶比较相邻状态的端点净变化，不要求值事实也恰好相邻。这只证明 L1 生命周期先后，不冒充业务发生时间；
8. P9 发生时间必须非零并原样进入输入见证。后继3F发布第二状态时另行提供并校验新的业务发生时间严格晚于前状态；本叶不得用事实代次补造该时间；
9. 来源身份完整；来源不同本身合法，不改变比较方向。

任何值编码或代次变化都不能替代材料比较。P9 被采样值属性类型不能用于注册路由。

## 11. 固定比较算法与成功形状

左值固定 `旧值=P9.采样I64值`，右值固定 `新值=P8.当前I64值`。

排序与关系：

| 条件 | 排序三态 | 具名关系 | 等价 |
| --- | --- | --- | --- |
| 旧值 < 新值 | `-1` | `状态迁移增加` | `false` |
| 旧值 == 新值 | `0` | `状态迁移等价` | `true` |
| 旧值 > 新值 | `1` | `状态迁移减少` | `false` |

差异固定为 `新值-旧值`。checked-wide 合同采用 P6 的无溢出边界判断：只有数学差异可由 I64 表示时才执行减法；不依赖平台扩展宽整数，不允许有符号溢出、回绕、饱和或截断。不可表示返回 `入口拒绝/差异不可表示`，排序、关系、等价、差异和输入全部为空。

相同材料即使值编码和事实代次不同，仍为已比较成功、等价 `true`、差异0。成功结果必须同时包含：

- 当前事实截止、注册身份、算法版本；
- 排序三态、迁移具名关系、等价和 I64 差异；
- 无单位、标量维度、标量分量角色、右减左、精确无量化、误差合同版本1；
- P9完整前状态和由同快照重建的 P8完整后当前见证；
- 左右输入回执分别绑定旧被采样值和新当前值。

比较全程 L1 写入0、注册变化0、状态/动态写入0、索引变化0、日志0。
