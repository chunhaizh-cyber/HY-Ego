## 1. 审计读取结果

4015 §4.2 要求审计结果同时携带状态、被查询写集幂等编码和有序记录组。`L1审计读取结果` 唯一修订为：

```cpp
struct L1审计读取结果 final {
    L1读取状态 状态 = L1读取状态::入口拒绝;
    写集幂等键 幂等键;
    std::vector<L1审计记录> 记录组;
};
```

物理位置：`海中鱼巣/核心/L1事实基座.数据.h`。

`L1审计读取结果 读取审计(写集幂等键 幂等键) const` 函数身份、参数和返回类型不变；只改变返回结构字段和所有构造点。

返回规则固定为：

| 输入/结果 | 状态 | `幂等键` 字段 | 记录组 |
| --- | --- | --- | --- |
| 输入键为零 | 入口拒绝 | 原样回显零键 | 空 |
| 有效键无记录 | 未找到 | 原样回显查询键 | 空 |
| 读取成功 | 成功 | 原样回显查询键 | 仅该键记录，按事件序号严格升序 |
| 资源失败或内部不一致 | 对应状态 | 能取得的原查询键 | 空 |

成功记录组中每项 `记录.幂等键` 必须等于结果 `幂等键`。调用方不得从首项反推查询键；空组仍完整携带被查询键。

## 2. `L1恢复结果.事实代次` 的唯一语义

该字段始终返回“结果形成时已经从仓库权威状态取得的当前事实代次”，不返回预计的未来发布代次。恢复发布成功时，新发布代次已经成为当前代次，因此两者相等。

| 恢复状态 | `事实代次` |
| --- | --- |
| 候选已建立 | 建立成功时的当前基线代次；候选预计目标代次不得返回 |
| 恢复已发布 | 一次替换并读回成功后的新当前代次，即确认前当前代次加一 |
| 候选已撤销 | 撤销完成后的当前代次；与撤销前相同 |
| 无候选 | 检查时的当前代次 |
| 入口拒绝 | 拒绝时的当前代次 |
| 材料不完整 | 校验拒绝时的当前代次 |
| 事实代次漂移 | 漂移判定时重新读取到的实际当前代次，不返回请求值或候选基线 |
| 资源失败 | 若已在锁内取得稳定当前代次则返回该值；锁或状态读取前失败则返回0 |
| 内部不一致 | 若已取得稳定当前代次则返回该值；发布后读回矛盾返回已经发布的新当前代次并进入隔离；无法安全取得当前代次时返回0 |

空库当前代次合法为0。除 `恢复已发布` 外，任何状态都不得用“当前代次+1”表示尚未发布的候选目标。

实现必须在取得锁和读取当前状态后先冻结本次 `结果基线`；异常处理不得在无锁情况下重新读取可变代次来拼装结果。

## 3. 恢复错误分类

### 3.1 `材料不完整`

只表示调用方提供的恢复材料可被确定性证明不满足 4015，当前运行期状态本身没有被证明损坏。至少包括：

- 当前、历史或永久占用编码为零、重复、缺失或不能互相覆盖；
- 当前与历史重复，创建/退出代次逆序或超出材料声明代次；
- 当前属性槽重复、未排序、悬空，或槽值的所属/类型与槽不一致；
- 关系源、目标或关系类型节点缺失/已退出；
- 值所属、来源、属性类型缺失，属性类型种类/表示不成立，或材料分支不匹配；
- 幂等账重复、写集未规范化、首次结果与审计成功事件不能互证；
- 审计键不一致、事件序号非从1连续递增，或精确重复/冲突记录改写首次结果。

建立候选遇到以上任一情况返回 `材料不完整 + 当前事实代次`，候选不存在，当前事实、代次、幂等账和审计零变化。

### 3.2 `内部不一致`

只表示仓库自身、已经通过材料校验的候选构造过程或发布后读回出现不能归因于输入材料的矛盾。至少包括：

- 建立候选前发现当前仓库状态已经违反完整不变量；
- 材料已通过全部确定性校验，但内部候选构造结果不满足同一不变量；
- 一次状态交换后，完整快照读回与候选或新代次矛盾；
- 非资源类未知异常或理论上不可达的状态分支。

发布前内部不一致必须零发布并进入隔离；发布后读回不一致保留已发布当前代次、进入隔离并停止普通提交/恢复确认，不逐项回填。

### 3.3 其它状态

- 已存在未决候选而再次建立候选：`入口拒绝 + 当前事实代次`。
- 建立时请求期望代次不等于当前代次，或确认时候选基线不等于当前代次：`事实代次漂移 + 实际当前代次`；确认漂移同时丢弃候选。
- `bad_alloc`、`length_error` 或等价容量失败：`资源失败`，按第2节返回已安全取得的代次或0。

## 4. 验证增量

在 v0.1 矩阵上追加并机械冻结：

1. 审计零键入口拒绝、有效未命中和成功三分支均回显查询键；空组不能丢键。
2. 成功审计记录全部与结果键相同且事件序号连续升序。
3. 候选建立、撤销、无候选、材料不完整、建立漂移、确认漂移分别断言返回实际当前代次且事实代次不推进。
4. 确认成功只返回新发布代次；候选阶段不得返回预计 `当前+1`。
5. 同一份损坏外部材料返回材料不完整；注入当前状态/候选构造/发布后读回矛盾返回内部不一致，两类状态不得互换。
6. 资源失败在已冻结结果基线后回显该代次，锁前失败返回0；两者均零假发布。
