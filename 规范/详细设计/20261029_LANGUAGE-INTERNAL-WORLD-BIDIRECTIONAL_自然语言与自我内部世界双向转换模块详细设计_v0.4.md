## 1. 模块定位与核心裁决

### 1.1 一句话定位

自然语言模块是 DATA 外内部治理功能：在**不经语言器捷径改写内部世界权威**的前提下，把自然语言与**自我内部世界**（含概念树、现实世界树认知模型、自我场景/特征等）互相翻译；结果是有来源、可回读的类型化信息，不是“理解即采信”。

### 1.2 世界拓扑（非线性；v0.3 用户裁决）

```text
外在物理现实（本系统不直接持有）
        │ 仅经外设感知/执行通道（采集材料、消息、执行器等）
        ▼
┌─────────────────────────────────────────────────────────────┐
│                 自我内部世界（认知整体）                      │
│                                                             │
│  ┌─ 概念树 / 概念空间 ────────────────────────────────────┐ │
│  │  存在/特征/动态等概念、上下位、定义（语言无关）         │ │
│  │  ←── 2210 名称关系 ←── 词条/语种表达                   │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ 现实世界树（自我对现实的认知模型）────────────────────┐ │
│  │  场景/存在/特征实例/状态/动态等；唯一世界根及成员       │ │
│  │  写入仍经世界/结构 owner 裁决，语言模块无写权           │ │
│  │  外设材料经正式承接后才进入本树，≠ 外设原始字节本身     │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ 自我场景视角与投影（7130）────────────────────────────┐ │
│  │  E=C、特征采用、状态/动态投影；自我为现实树中一员       │ │
│  └────────────────────────────────────────────────────────┘ │
│  可指称的信息对象投影：需求 D / 任务 T / 方法 M 等          │
│  （内容归各 owner；认知上由自我持有与查询）                 │
└─────────────────────────────────────────────────────────────┘
         ▲ 按出现实例化概念              ▲ 可选绑定到
         │                               │ 内部·现实树成员
┌────────┴─────────┐                     │ 或自我成员
│ 自然语言世界树    │─────────────────────┘
│ （实例级临时舞台）│  空白语言场景 + 匿名 E
└────────┬─────────┘  ≠ 概念层，≠ 现实树层
         │ 含义/主张引用内部概念与出现
         ▼
┌──────────────────┐
│ 语言 owner 材料   │ 旁路并行：知识·原文·解析·交互·主张
│ 指向内部世界概念  │ 主张 ≠ 现实树事实
└──────────────────┘
```

要点：

1. **概念树 ⊂ 自我内部世界**。  
2. **现实世界树 ⊂ 自我内部世界**：它是自我对现实的**认知模型**；外在物理现实只经**外设**进出，不把世界树等同于外物本身。  
3. **自然语言世界树**是临时**实例舞台**，不是概念与语言材料之间的层。  
4. **语言材料**旁路并行，指向内部概念；不另造概念仓。  
5. 对现实世界树的写入仍由**世界/结构 owner** 裁决；语言模块只产类型化提议/主张，无写权。只读查询针对的是内部世界中的现实树，不是“系统外的物理实在”。

**裁决 A–D**（同 v0.2 精神，措辞按上图）：内部取材优先正式投影；NL 先落内部概念，再按需建舞台与绑定；SHARED-INFO 为枢纽；六构式为最小双向内核。

### 14.x 临时对象 / 未绑定出现的场景分账（v0.4 用户裁决）

对话中提到某个对象、但尚未对应上内部真实存在时：

1. **当前场景内的对象**：必须先取得其它证据，并绑定到现实存在之后，才允许写入内部世界权威材料；不得仅凭这句话把当前场景对象记成已绑定存在。
2. **其它场景的对象**：允许先把该句记为**主张**（保留来源与作用域），待后续证据再绑定。
3. 自然语言世界树中的匿名出现仍是临时舞台，不因主张保存而自动取得现实树身份。

本条约束语言理解后的保存/写回路径，不授权语言模块直接写现实树。
