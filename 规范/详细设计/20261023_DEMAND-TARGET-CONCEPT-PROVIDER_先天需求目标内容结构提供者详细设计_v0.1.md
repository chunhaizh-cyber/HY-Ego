## 1. 当前裁决和完成边界

初始化生成需求D、任务T、方法M三个完整先天概念及其直接必要支持定义，不再只生成需求目标七项。结构项的键为正常正式FT，定义中的值为任意类别正式概念节点引用；该概念规定字段内容范围。可以引用存在、特征、状态、动态、因果及D/T/M等概念，不增加有限类别白名单。

概念引用是约束，不是实际实例值；不把范围概念编码写成FT实例准确值，也不要求所有FT改为概念引用物理类型。旧普通存在/特征`是/获取`及DTO语义不变，新结构采用显式读取入口，仍由既有概念owner保存，不新增第二概念仓。

本叶只实现定义保存、依赖闭合、零实例初始化、正式完整读回和线程前装配。排除全部实例符合性求值、所有概念族生成、模拟参数生成、学习、实际统计维护/可靠度计算、D/T/M物理实例迁移、Vm/Vt合并、自然语言实现及结算方法注册。需求F继续当前一个D编码、历史不同D记录，不外推至T/M。

## 2. 统一表示与owner

结构定义包含有序项目：序号、正常FT根引用、正式内容概念引用、最少/最多数量；另有正式联合约束概念引用。联合约束完整保存分支、顺序、同一性、所属及阶段规则，不以名称字符串或函数地址代替。基础范围、结构及约束均有正式概念身份；schema键不是概念。未知概念族不因非零编码放行，必须通过其owner的正式身份读取协议；无提供者为未能判定/依赖未就绪，身份损坏为工程故障。

复用`概念_存在类`既有owner/root/L1分组发布、`概念_特征类`正常FT、`概念_名称关系类`名称关联。名称关系当前只识别普通E/FT，不能假称通用概念登记器；新增形状需显式路由。普通FT同值域不同语义必须独立身份：无上位创建根每次新建，指定父域才复用直接子域。固定先天语义槽必须正式持久登记、完整核对并保护引用，不能全局同域取首项，静态变量不是长期登记。

定义层允许D/T/M构成递归，分类环仍禁止；不在本叶实现递归实例求值或凭回访判符合。

## 3. 三类字段映射

下述字段均为正常FT语义槽，内容概念限制其实际材料。1=恰一，?=0..1，*=0..不限。各槽独立，不按相同范围合并。

### 3.1 需求D

共同字段：需求主体→合法存在(1)、执行域→{自我1,被认知2}(1)、目标存在→合法存在(1)、目标FT→合法材料FT根(1)、目标形式→{值1,方向2}(1)、目标范围→合法材料特征概念(?)、目标比较关系→合法目标比较关系(?)、目标方向→{增加1,减少2}(?)、权重→[0,INT64_MAX](1)、活动→{活动1,等待2,满足3,非活动4}(1)、根角色→{安全1,服务2}(?)、父需求→D(?)、来源→现有来源信息概念(?)、承接关系→现有承接信息概念(?)、理解材料U/确认材料C/原始要求R→各原领域信息概念(?)。

值分支范围/比较各1、方向0；方向分支范围/比较0、方向1。域属于目标FT；比较关系参照该目标域并适用目标FT，沿现需求准入含义。自我根无父/来源/承接；普通自我D父1+来源1；任务子目标承接按来源合同。被认知D无自我父/根/来源/承接，权重0，U/C各1，R可选。U/C/R只关联现有领域材料，不新增“确认类型”或“确认特征”，不改变语言确认治理，不造确认事实。

### 3.2 任务T

字段：对应D→D(1)、虚拟存在→Vt(1)、候选方法→M(*)、采用方法→M(?)、采用条件→方法C(?)、参数需求→规格(*)、参数绑定→原绑定信息(*)、执行组织→原执行组织(?)、执行实例→X(*)、评估→原评估信息(*)、贡献/结算记录→原贡献信息(*)。

Vt至少包含任务状态→现任务状态FT(1)、任务服务值→现任务服务值FT全I64(1)，以及现Vt合同的治理信息引用。状态从Vt读取，不建立T镜像状态。状态使用当前owner完整1..12，含已结算12，不能沿过期1..11。出生可无M/组织/X/评估/结算，候选可空；执行要求M/组织/条件/绑定完整；X在实际开始后产生；完成不等于已结算。父子经D关系及一D一T恢复，不另造任务父子树。本轮不生成X/动作/贡献实例。

### 3.3 方法M

字段：方法头→方法头结构(1)、Vm→Vm结构(1)、函数绑定→原函数绑定信息(1)、条件→C(*)、结果→方法R(*)。头包含目标FT/能力限制，范围{内部治理1,普通2}、实现{本能1,组合2}、行为{读取1,改变2}。结算不建立M。

Vm含启用→现启用FT{0,1}(1)、有序参数规格(*)、运行次数→[0,INT64_MAX](1)、成功次数→[0,INT64_MAX](1)、可靠度→[0,10000](?)。成功≤运行，运行0时可靠度未知；本轮仅定义，不写统计实例或维护次数。

参数规格含序号1..N、信息类型、正式范围概念引用；空规格合法，非空连续有序。允许任何有正式概念的信息类型，不将现E/F实现枚举当全域。具体条件在C，不在规格写当前参数。

C含所属M、父C、AND条件项和配对R；根无父，子有同M单父且无环。头阶段C/R可均无；正常已知条件配一R，异常一条件多结果允许多R。R含所属M、非空结果项、分组与已知性；未知结果不造准确值。条件/结果项保留具体信息、FT、值/域/方向及关系。正式概念不能被现单R DTO缩窄；本轮不迁移M实例。

必要支持定义仅解释上述现有Vm/Vt、规格、来源、绑定、执行、评估、贡献、C/R等信息的组成及阶段；不能只建同名空节点。完整支持字段合同尚未闭合的部分见第7节，不以此初稿宣称已完成。

## 4. 初始化和发布顺序

基础值/FT/E概念schema→D/T/M schema及既有正式FT初始化、必要reader装配→固定语义FT槽→基础范围/支持结构→D/T/M顶层→名称→完整保护读回→原需求publisher及worker启动。

复用任务状态/服务值FT和方法启用FT，不因同域另造类型。方法统计FT尚无现提供者时，只补类型定义登记，不顺带写Vm值。I64域无需实例reader；非空D引用、T集合、消息集合存在各自reader依赖，不用空集合或假D/T/M打断依赖。本叶只创建概念定义。

同owner内先准备互相引用的定义身份，闭合全部内容后同一L1分组发布正式定义及唯一登记；准备期不对外可读、不挂名称。循环构成的强连通组同批成立，不能分步暴露半定义。外部已发表FT用快照核验，不谎称跨owner全局原子。若既有L1不支持该组发布，必须具名回报，不能临场放宽原子边界。

已有登记按完整有序内容/范围/基数/约束/根归属核验，名称不进定义签名；异义不覆盖，损坏/多owner命中/半定义为工程错误。只回滚本批未发表私有记录；已发表保留并可重入读回，不建第二组。正式引用受删除保护，不新增GC。

### 7.1 已闭合：正式概念身份与保护协议

中立声明放在`海中鱼巣/领域/概念_特征类.h`，复用该头已有稳定编码/快照定义，不反向包含存在、二次特征或业务owner头。需要`<span>`。下述声明不是有限概念类别表：

```cpp
enum class 正式概念读取状态 : std::uint8_t {
    已读取=1, 非本提供者概念, 依赖未就绪, 前提已变化
};
struct 正式概念身份保护 final {
    稳定编码 概念节点;
    std::vector<基础联合节点快照> 完整保护组;
};
struct 正式概念身份读取结果 final {
    正式概念读取状态 状态=正式概念读取状态::非本提供者概念;
    std::optional<正式概念身份保护> 身份;
};
class 正式概念身份读取接口 {
public:
    virtual ~正式概念身份读取接口() = default;
    virtual 正式概念身份读取结果 读取正式概念身份保护(
        稳定编码 概念节点) const noexcept = 0;
};
enum class 结构项概念保护状态 : std::uint8_t {
    已读取=1, 输入拒绝, 依赖未就绪, 未取得正式概念证明, 前提已变化
};
struct 结构项概念保护结果 final {
    结构项概念保护状态 状态=结构项概念保护状态::输入拒绝;
    std::optional<稳定编码> 特征类型根;
    std::optional<稳定编码> 内容概念;
    std::vector<基础联合节点快照> 完整保护组;
};
```

正常FT、二次特征、存在概念owner分别增加最小适配成员，声明在其原头、定义在原cpp，三个类实现上述接口，完整签名一致：

```cpp
正式概念身份读取结果 读取正式概念身份保护(
    稳定编码 概念节点) const noexcept override;
```

各适配只调用本owner正式读取/完整保护：特征owner用`读取特征概念定义保护`，二次特征owner用`读取二次特征定义保护`，存在owner用其普通专属/抽象身份读取及新增结构定义保护，不读其它owner私有schema。已识别身份损坏走工程故障链；不能以非本提供者或依赖未就绪吞掉。正常不识别返回非本提供者，未具备判断所需依赖返回依赖未就绪。

`结构项概念保护结果`及下述接口声明在`概念_存在类.h`，定义在其cpp，归结构概念owner；不将其放入中立头造成反依赖：

```cpp
结构项概念保护结果 读取结构项概念保护(
    稳定编码 特征类型,
    稳定编码 内容概念,
    std::span<const 正式概念身份读取接口* const> 提供者组) const noexcept;
```

先用正常特征owner正式读取证明FT是根，并取得完整保护；非FT根输入拒绝，不以任意下位FC代替。再逐个调用借用提供者读取内容概念正式身份。禁止名称匹配、非零放行或限定概念族。二次特征概念可以同时被二次owner与材料特征owner合法识别，不能要求唯一owner命中；所有成功返回身份必须等于请求节点，先逐项核对同节点快照一致，再合并保护组，不能按首项丢弃多路证明。同节点快照内容/版本冲突返回前提已变化，不按先后选一份。任何必要保护的前提变化优先返回前提已变化。至少一个正式成功保护且无冲突才返回已读取；无成功且存在提供者依赖缺口返回依赖未就绪，全部提供者均不认领返回未取得正式概念证明，两者均不宣判非法/不存在或业务不符合；非本提供者只表示该个体owner不识别。

已读取时两个optional和完整保护必须齐备；其它状态不携带可被当成功使用的身份。该结果只保证FT身份、概念身份及本次保护前提，不证明FT实际材料与内容概念语义相容，不证明某个实例符合；语义相容属于第7.2待闭合合同，不能借身份成功跳过。

调用者在初始化调用栈上构造提供者指针组并传span，owner与适配对象寿命覆盖调用；函数不保存span、指针、callback。无需长期注册或新增全局概念owner。未来概念族按原owner增加同协议适配，不改变结构项表示或恢复有限类别白名单。本次实际引用所需提供者仍须在初始化前具备，第7节其它五项保持待闭合。
