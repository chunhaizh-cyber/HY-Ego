# 先天需求目标内容结构提供者详细设计

标识：DEMAND-TARGET-CONCEPT-PROVIDER；版本：v0.1；日期：2026-10-23。

状态：根复核及独立审查通过，冻结v0.1；施工资格由计划索引精确登记确认。起点main `b0a2e9a1706f0b3d7da308a4128bba52b866fe45`，唯一代码owner为`/root/demand_reference_provider`。默认实际项目编译，不运行测试，依用户要求不推送。本设计不修改正式规范或异主确认材料，冻结不代表代码已实现。

## 1. 最早提供者与完成边界

依据7165第3、4、6、7节及3100目标合同，零个具体D时建立可查询的“需求目标内容”先天结构：需求主体、目标存在、目标特征类型、目标形式，以及值目标/方向目标两个互斥分支和同FT关联。它是需求目标内容定义，不是完整D治理概念，不包含D权重、活动、来源确认或承接资格。

本叶解决后续通用生成器缺少正式结构元信息的问题，不把需求特征全域解释成任取一个默认需求。不实现模拟D生成/有限D复制、不打开获取服务需求模拟入口、不模拟self/manager最终服务任务加一、不恢复Q模拟。未来生成器从正式定义生成合法参数，原方法结果只能从原函数真实写回取得，这些只留直接后继路线。

所有本叶内容是概念定义元信息，不是给自我增加运行特征，不改变“需求F当前一个D、历史不同D集合”的用户裁决。基础判定和结构范围具有独立正式概念身份，不复用D私有schema字段、组织根、函数地址或名称字符串冒充概念。

## 2. 当前事实与唯一owner

- `概念_存在类`现只有专属/抽象、普通特征组及上下位图，无结构项/基数/分支/同FT元信息。人工抽象须有下位，不能用于零D先天定义。
- `概念_特征类`现材料FT无概念/实例元信息角色定义。不能用普通U64数组或无标签编码表示这些角色。
- 7165规定正式结构，但相应公开物理API尚未实现；需求私有字段不是可供生成器读取的概念定义。
- `新_需求类.cpp`的`目标形状合法`及创建准入已经核验值/方向互斥、目标域所属FT及`比较关系适用于目标`。该合法性必须复用，不在概念owner另造更宽或更窄算法。
- 装配现“连接通用存在概念”是从自我专属概念建立的人工分类，不足以证明任意合法存在全域；新基础范围使用具名合法存在判定，不以显示名或空特征人工分类代替。

复用唯一owner：结构和基础范围由`概念_存在类`维护，元信息角色FT由`概念_特征类`维护，名称由`概念_名称关系类`维护；实例合法性仍由正式存在/特征/二次特征及需求owner读取。不新增概念仓或本体根，不把D复制成普通存在。

## 3. 通用表示

### 3.1 结构内容角色FT

物理声明/定义：`海中鱼巣/领域/概念_特征类.h/.cpp`。在该owner既有根下新增“结构内容特征类型”节点形状，不冒充某种可写材料FT，不增加普通F运行值类型。

```cpp
struct 结构内容特征类型信息 final {
```

同一语义固定值类别，初次完整定义后不可改。主体/目标存在分别是不同语义FT、相同值类别；不能因值类别相同合并两个角色。定义同义复用按完整语义+类别，不按名称复用。未知语义或不匹配类别拒绝，不允许任意字符串扩充业务FT。

**全部旧入口及DTO语义不变。** `是特征概念节点`、`获取特征概念`及普通材料比较/根定位只识别原材料型，不将结构内容FT静默纳入。新形状只经新增`是结构内容特征类型节点`及专门读取取得；无需新增意义重复的材料身份getter。元信息FT不强塞虚构材料定义，旧普通特征/二次特征/动态/方法/自然语言消费者对它仍按原入口拒绝。所有原材料FT行为保持，本叶不修改这些消费者，结构元信息不进入`新_特征类::添加特征值`。

元信息FT的新增schema类型标记区别于原特征概念节点类型；仍归现特征概念owner及同组织根。旧根扫描、普通上下位和域比较必须按原材料类型标记过滤，新形状扫描按新增标记过滤，不能将根下任意成员视作材料FT。`是结构内容特征类型节点`对其它形状false，对已识别元信息形状但内容损坏按工程故障报告。


关联不是D专用脚本：第一类约束“左项材料特征概念所属类型=右项材料FT根”；第二类“左项比较关系适用于右项目标FT、参照项目标域”。关联操作数类别及基数必须先验闭合，不允许引用未声明项、分支禁止项或任意执行代码。只实现这些正式需要的具名原语，不给每个D写不同DSL。

## 5. 先天目标内容的唯一定义

| 序号/角色 | 值类别与基础范围 | 默认基数 |
| --- | --- | --- |
| 1 需求主体 | 存在实例引用→合法存在 | 1 |
| 2 目标存在 | 存在实例引用→合法存在 | 1 |
| 3 目标特征类型 | 特征类型概念引用→合法材料FT根 | 1 |
| 4 目标形式 | I64→{新需求目标形式::值, 新需求目标形式::变化方向} | 1 |
| 5 目标范围 | 特征概念引用→合法材料特征概念 | 0..1 |
| 6 目标比较关系 | 比较关系概念引用→合法值目标比较关系 | 0..1 |
| 7 目标变化方向 | I64→{新需求变化方向::增加, 新需求变化方向::减少} | 0..1 |

值分支：4=值，5/6各1，7为0，约束5属于3、6适用于3并参照5。方向分支：4=变化方向，5/6为0，7为1。主体和目标不强等，不要求已经有任务/确认/服务对象。对当前场景找不到目标不否定这个概念定义，实际引用必须合法可读，不用空编码补齐。

先天枚举的正式含义沿需求领域已有枚举，不持久化C++类型地址。本叶固定合法数字与意义映射，若已有枚举变更须合同漂移处理，不能静默复用旧定义。

## 6. 实例合法性复用协议

概念owner不能反读需求私有schema，也不能为校验建立假D。新增中立只读接口（声明在概念_存在类.h），实例owner通过具名协议提供原判定：

```cpp
enum class 信息结构符合状态 : std::uint8_t { 符合=1, 不符合, 内容不完整, 输入拒绝, 前提已变化 };
struct 信息结构符合结果 final {
    信息结构符合状态 状态 = 信息结构符合状态::输入拒绝;
    std::vector<std::uint32_t> 不满足内容项组;
};
class 信息结构基础读取接口 {
public:
    virtual ~信息结构基础读取接口() = default;
    virtual 信息结构符合结果 核验基础信息范围(
        const 基础信息范围定义&, const 概念结构内容值&) const noexcept = 0;
    virtual 信息结构符合结果 核验结构内容关联(
        概念结构关联种类, const 概念结构内容值& 左,
        const 概念结构内容值& 右,
        const std::optional<概念结构内容值>& 参照) const noexcept = 0;
};
信息结构符合结果 判定信息结构内容(稳定编码 结构概念,
    const std::vector<概念结构实际内容项>&, const 信息结构基础读取接口&) const noexcept;
```

接口只是调用期C++协议，不存进概念定义、不持久化函数指针；定义中的谓词枚举只有已实现具名原语。结构owner负责项目、基数、分支、类别及关联调度；协议实现不能忽略这些而返回万能true。

`新_需求类`实现该接口，构造依赖不变。合法存在核验使用原存在服务；合法材料FT/概念用特征概念服务的正式读取及根定位；合法比较关系用既有二次特征概念读取，不解析其schema。

原`比较关系适用于目标`逻辑提升为新_需求类的private只读共用成员，保持参照域**身份恰等目标域**、至少一个特征准确值输入且每个输入FT根同目标FT等原限制；`核验结构内容关联`与原普通/被认知需求创建都调用同一函数。`目标形状合法`的值/方向准入保持不变，结构分支逐项与其对照，不能为通过概念校验放宽实例创建。只读接口不确认需求、不写D、不改变承接/执行权限。

共用private成员声明/定义冻结为`bool 比较关系适用于目标(const 二次特征概念信息&, 稳定编码 特征类型根, 稳定编码 目标值域) const;`，只从本对象既有特征概念服务读根，原free helper的算法整体迁入且原创建调用同步改用它，不保留第二套独立算法。新协议两个override的签名逐字沿上述接口，不新增构造参数、服务指针装配或运行回调注册。

工程读取损坏、资源故障进入现工程报告链并终止操作，不返回不符合；真实无对象/错类型/关联不成立返回不符合；字段缺失返回内容不完整；采集变化返回前提变化。判定前后读回涉及定义，变化时不返回稳定符合，不宣称跨owner原子快照。

内容判定顺序固定：先检查结构定义和调用形状；重复序号、未声明序号、同项多值超过最多数量、值标签与角色类别不符均`输入拒绝`，失败组含全部相关调用项序号（未知序号原样报告），不按首项暗选。再取选择器，缺选择器返回内容不完整且列选择器和全部无条件必需缺项；未知选择值返回不符合，仅列选择器，不猜分支。选择分支确定后，缺各必需项返回内容不完整并按定义序号升序列全部缺项；被分支禁用项却有值返回不符合并列全部禁用项。前述形状和完整性通过后才运行基础范围及关联；收集全部不满足项（关联的全部操作数序号）去重升序返回不符合，全部成立才符合。采集变化优先返回前提已变化，不把本次不稳定缺项混作最终结论。
