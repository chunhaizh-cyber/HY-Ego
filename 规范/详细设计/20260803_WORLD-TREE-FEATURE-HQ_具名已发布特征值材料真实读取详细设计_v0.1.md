## 1. 目标、当前事实与激活门禁

本叶在 P1BF v0.4 的最终模块、DTO、类、构造、第二公开签名和顺序200自检内，原位替换 `读取具名已发布特征值材料` 的固定未实现函数体，形成一个具名特征值的真实内存权威原始材料读取。它不实现宿主组 FEATURE-Q，不读取4170批次账，不读取 SQL、持久材料、缓存或旧特征栈，不写机器事实。

创建侧正式 HEAD 已发布 P1BF v0.4 设计/计划合同，但代码尚无结果；因此本计划只能待激活。开工门禁为 P1BF v0.4 真实代码结果进入正式 main，且 `服务.节点直接特征查询.ixx`、同一顺序200自检写权释放。骨架、消息或设计提交不能满足真实接口存在门禁。

## 2. 能力证据与复用裁决

| 需要能力 | 当前提供者 | 裁决 |
| --- | --- | --- |
| 最终 DTO、服务、构造、签名 | P1BF v0.4 | 代码结果后原位复用，不新建接口 |
| 同许可当前类型化值组 | L1 `节点直接结构查询服务` | 直接且恰调用一次 |
| 特征领域完整性 | 当前不存在 | 在本根纯值判断，不下沉L1 |
| SQL/4170/旧特征 | 非权威或不同职责 | 禁止读取和回退 |

L1函数正式行为是：内部取得一次共享读取许可，以所属稳定主键读取全部当前类型化值并返回一个事实截止代次。它不解释“特征值只有一个原始值合同”的领域基数，故 FEATURE-HQ 必须要求返回组恰一，不能取首项或按合同猜选。

## 4. 请求准入和状态映射

准入同时要求：

```text
请求.合同版本 == 节点直接特征查询合同版本 == 1
请求.特征值 为完整节点稳定身份见证
请求.特征值.类型 == 节点类型::特征值
```

失败固定 `入口拒绝、0、nullopt`。

L1状态映射固定：

| L1 `节点直接结构服务状态` | FEATURE-HQ状态 | 继续 |
| --- | --- | --- |
| 成功 | 仅代次非零时继续 | 是 |
| 未找到 | 未找到 | 否 |
| 入口拒绝 | 入口拒绝 | 否 |
| 版本漂移 | 版本漂移 | 否 |
| 许可拒绝 | 许可拒绝 | 否 |
| 资源失败 | 资源失败 | 否 |
| 内部不一致 | 内部不一致 | 否 |

L1任何非成功返回均丢弃其载荷并返回代次0/nullopt。L1成功但代次0是 provider 合同矛盾，返回内部不一致。

## 5. 唯一记录与身份裁决

L1成功且代次非零后，值组必须恰一：零项或多项均为内部不一致。唯一项必须满足：

1. `所属身份.稳定主键 == 请求.特征值.稳定主键`；否则为内部不一致。
2. 所属完整身份逐字段等于请求特征值；同稳定主键但类型或身份版本不同返回版本漂移。
3. `当前 == true`；否则内部不一致。

不得因为多个类型合同记录中有一个“看起来像原始值”而筛选成功；该选择会补造未冻结的类型合同身份规则。

## 6. 记录、材料、来源和代次完整性

唯一读回还必须满足：

```text
类型合同稳定身份完整；类型合同版本非零
类型化值记录稳定身份完整；值记录版本非零
值记录版本==1 -> 前一值记录版本=nullopt
值记录版本>1 -> 前一值记录版本存在且等于值记录版本-1
当前=true
首次发布代次非零
当前状态发布代次>=首次发布代次
当前状态发布代次<=L1事实截止代次
```

`类型化值材料` 完整性沿 L1 正式规则逐变体复核：I64/U64及正式向量形态直接有效；I64区间下界不大于上界；稳定身份有序组每项见证完整；独立材料引用必须具有有效材料身份、非零格式版本/字节数和非全零SHA256。

来源联合必须命中 `节点稳定身份见证`，见证完整且类型为 `节点类型::存在`。服务稳定身份来源、空/不完整节点来源或其它节点类型均为内部不一致。由于唯一允许的 L1 调用已经返回已发布值式见证，本叶不再第二次查询来源节点，不扩大许可窗口。

任一失败返回内部不一致、0、nullopt。

## 8. noexcept、异常和并发

公开函数保持 `noexcept`，完整实现位于 `try`：

```text
std::bad_alloc / std::length_error -> 资源失败、0、nullopt
其它异常 -> 内部不一致、0、nullopt
```

catch只构造静态证明无抛的空失败结果，不再次分配。合法未找到、入口拒绝、版本漂移和许可拒绝不是异常，不诊断、不重试。函数不 sleep、不循环 try-lock；唯一许可完全封装在 L1调用内。

## 10. 自检与机械推演

原位扩充 `WORLD-TREE-P1BF-S01` / 顺序200，不新增顶层项，顶层登记/执行数量保持21。至少覆盖：非法合同/见证/类型调用0；L1七状态；成功零代次；零/一/多记录；同键异版本；当前=false；每个合同/记录/材料/前一版本/代次缺陷；节点来源正例，服务/错型/不完整来源反例；十字段逐项相等；bad_alloc/length_error/其它异常；SQL、4170和旧栈零调用；调用前后权威事实不变。

机械推演：合法请求调用L1一次，得到代次7和唯一完整当前读回；逐项复核并复制十字段，返回已读取/7/材料。若请求版本旧于当前所属身份，则返回版本漂移；若存在第二当前类型合同记录，则内部不一致而非任选其一。
