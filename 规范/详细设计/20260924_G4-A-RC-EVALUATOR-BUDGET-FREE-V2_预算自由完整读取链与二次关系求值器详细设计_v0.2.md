## 1. 目标与裁决

本设计只闭合 G4-A 当前最早缺口：为 4242 二次关系求值建立一条不含底层资源预算、不会截断成功、不会跨 provider 累加物理用量的完整读取链，并实现 4242 第 7 节 `二次关系求值应用服务`。同一代码切片内完成 RC 专属版本 1 ABI 的消费者迁移和物理退出。

本设计不实现 G4-A 双根业务复核、根治理意图 sink、治理门开放、4213/4340 业务合同、动态/因果自身读取 ABI、动态概念、因果概念或 4242 第 8 节形成应用。`数据服务.动态类.h`和`业务/计算.二次特征.h`只因它们是 4182 canonical K 读取 ABI 的真实生产消费者而做字段删除后的机械调用迁移；不得改变其 DTO、算法、状态、预算或业务语义。

冻结裁决如下：

1. 完整语义范围只由身份、`Gread/H`、显式来源组、RC 完整规范形及其必要引用闭包定义；任何节点、关系、值、材料、候选、深度或步骤计数均不进入新请求、成功谓词或重试语义。
2. 每个 provider 独立完整返回自己负责的载荷，或返回 `资源失败`并清空依赖完整性的载荷。没有共享读取会话、剩余预算传递或跨服务物理总账。
3. 4015、4180 和 4240 的旧预算 ABI 仍被本设计外消费者占用，本包新增版本 2 完整读取入口并只迁移 G4-A 直接消费者。4182 v0.4 则明确要求旧 canonical K 请求的声明、实现和消费者同次退出，因此本包还机械迁移`动态类.h`和`业务/计算.二次特征.h`中的 K 读取调用；禁止借此修改 4213/4340 或动态/二次特征机器语义。
4. 4242 RC 专属旧预算 ABI 的生产消费者只位于概念树服务、双根 RC 初始化、普通应用装配及两个 RC 专项。本包将它们同次迁移并删除 RC 专属 `二次关系预算`、`二次关系读取用量`、请求预算字段、结果用量字段和共享计量私有重载。
5. 现行存在 `读取当前采用`仍携`关系预算`。4242 已要求“完整当前采用读取”，7150 已固定同 `E+FT` 当前采用为 `0..1` 完整组；本设计只为该既有机器语义补充新的物理 v2 只读入口，不改变存在 owner、写入、基数或生命周期。

## 2. 当前代码事实

起点 HEAD 上：

- 4015 第 11 节六项版本 2 完整入口均不存在，现行实现只有带`最大数量`或总量上限的版本 1 入口；
- 4180 只有`特征值域*请求_v1`、`特征值域比较预算_v1`及共享`概念事实读取会话_v1`路径；
- 4182 的固定 K 和当前 K 请求均为版本 1，携物理预算，当前 K 还携`最大扫描候选数量`；
- pure v2 结构读取、存在概念两组读取和 RC 约束读取仍通过概念预算、物理预算或 RC 预算完成；
- 4242 RC 全部结构请求仍为版本 1并携`二次关系预算`，结果携`二次关系读取用量`；
- `业务/计算.二次关系求值.h/.cpp`及`二次关系求值应用服务`不存在；
- 普通应用已拥有 L1、概念、场景/B、状态、存在、特征、特征值和特征值域比较服务，但尚未拥有或公开 RC 求值应用服务。
- 当前只有根工程和三个专项工程直接编译`装配.普通应用.cpp`：根工程、`本能双根二次关系概念初始化专项验证.vcxproj`、`本能根运行生产消费专项验证.vcxproj`、`世界树根启动专项验证.vcxproj`。新增 non-inline `计算.二次关系求值.cpp`后，四个工程都必须登记该源；后两项回归工程若只编译普通应用而不登记求值源，会在链接阶段缺少定义。
- 4182 canonical K 旧读取的真实调用面不仅包括动态、二次特征和双根初始化，还包括`数据服务.概念树类.cpp`的 RC 私有完整性核验、`二次关系概念结构专项验证.cpp`及`本能双根二次关系概念初始化专项验证.cpp`；旧 ABI 物理退出前必须覆盖这些声明、实现和调用点。

上述只是静态实现事实，不证明旧入口运行正确，也不证明新入口已经实现。

每项使用自己的 v2 状态类型，并保留对应 v1 合同除`数量预算不足`之外的状态分支；不得在六项之间复用一个含无关业务解释的状态枚举。`成功(request)`核对版本、请求头、实际截止、稳定编码严格升序、无重复及每项完整性；合法空组成功。

实现规则：

1. 在同一共享锁内先核健康状态和 G 守卫，再由现有权威索引确定完整候选集并逐项与权威事实互证；索引不作最终事实。
2. 任何部分物化、分配失败、长度不可表示、锁/存储资源无法完成统一返回`资源失败`并清空组；索引缺项、多余项、同编码复义或生命周期矛盾返回`内部不一致`。
3. 不以`UINT64_MAX`调用旧函数，不在新函数内部构造旧请求，不先读后用数量比较补报完整。

### 3.4 4180 特征值域 v2

在`数据服务.特征值域比较类.h/.cpp`新增规范明确的三个版本 2 请求：

- `特征值域读取请求_v2{版本=2,Gread,H,FC}`；

新增`特征值域比较状态_v2`，只含：`已读取、已核验、未找到、目标已退出、类别冲突、类型不相容、规则缺失、未实现、事实代次漂移、历史材料不可用、资源失败、内部不一致、入口拒绝`。新增`特征值域关系_v2`固定四值：相等、左包含右、右包含左、不包含。

`特征规范值域_v2`固定为以下强类型联合：

```text
特征规范I64域
特征I64组有限域_v2{按点保序的vector<vector<int64_t>>}
特征U64组有限域_v2{按点保序的vector<vector<uint64_t>>}
特征独立材料有限域_v2{vector<格式身份+完整载荷>}
```

外层有限点组按完整内容确定排序和去重，点内顺序与重复保留；材料身份、摘要、路径、长度和节点编码只召回，不代替完整内容。

`特征值域事实_v2`固定携`FC、FT、原始表示、规则身份、规则版本、规范化值域、特征概念值域基础事实_v2`。读取/关系/命中结果均无预算、无用量，非成功清空域、关系、规则和成功见证。I64 路径必须实际完成；I64组、U64组、独立材料若现有专用适配尚未实现，仍保留紧邻`待实现`并返回`未实现`或`规则缺失`，不得生成伪关系。

v2 服务公开函数在现有名称后加`_v2`，避免静默改变仍被本包外消费者使用的 v1。v2 不声明任何共享读取私有重载。

## 4. 4242 RC 专属 ABI 迁移

`合同.二次关系概念.h/.cpp`中的结构 DTO 按 4242 v0.5 第 5—6 节原名切换为版本 2：

- 所有读取、查找、建立、来源、用途、图、父组、生命周期、来源释放和退出请求删除`二次关系预算`；
- 所有核验、读取、写入、关联、图和治理结果删除`二次关系读取用量`；
- `二次关系数据状态::预算不足`替换为仅供旧材料解码的`旧预算不足`，新生产实现没有产生该状态的分支；
- `二次关系预算`、`二次关系读取用量`及其完整性/累加函数物理删除；
- 概念树类 RC 私有规范化、读取、枚举、约束读取、图、治理和清理函数删除预算/用量/共享会话参数，分别调用本设计 v2 provider；
- 请求/结果其余字段、稳定编码、定义规范形、排序、生命周期、写入头、发布未知及首次材料语义保持 4242 v0.5 不变。

`本能双根二次关系概念初始化请求`及结果原名升级版本 2：请求只保留`版本、G0、先天交付`，删除纯概念、K、候选和 RC 四组预算字段；状态删除`数量预算不足`，旧状态只在测试材料迁移说明中识别。初始化者改用 4240/4182/4242 v2 完整入口。原预算常量物理删除。

公开 DTO、`二次关系判断状态`、见证和四个求值请求逐字段采用 4242 v0.5 第 7.1、7.3 节：

- `二次关系求值请求`；
- `二次关系FC求值请求`；
- `二次关系EC求值请求`；
- `二次关系候选求值请求`；
- `二次关系判断结果`。

本包只实现上述求值服务，不实现第 8 节`二次关系概念应用服务`和形成请求/结果。

`二次关系求值应用服务`构造签名逐字采用 4242 第 7.2 节。对象保存八个 non-owning const 引用，构造核验同一 L1、概念服务与 B provider 绑定一致；无效装配抛`std::invalid_argument`，分配失败抛`std::bad_alloc`。对象不可默认构造、复制或移动。

为使“同一 L1”不被误当作“同一服务实例”，`概念树类数据服务`新增四个只读、`noexcept`、不泄漏指针的身份谓词：

```cpp
bool 使用特征服务(const 特征类数据服务&) const noexcept;
bool 使用存在服务(const 存在类数据服务&) const noexcept;
bool 使用特征值服务(const 特征值类数据服务&) const noexcept;
bool 使用状态使用绑定提供者(const 状态使用绑定只读提供者&) const noexcept;
```

四函数只比较构造时保存的 non-owning 引用地址，不访问仓库、不读取事实、不返回 owner。求值器构造必须同时通过`概念服务.绑定于(L1)`和四个谓词；状态服务、存在服务、特征服务和特征值服务仍各自按已有 L1 绑定守卫核验，缺少或不一致时构造拒绝，不能只凭同一 L1 推断同一实例。

### 5.2 来源解析

1. 请求版本 2、请求身份非零、`0<H<=Gread`、A/B 的 E 非零、来源组非空。
2. 同一参与者只允许全 F 或全 B，不得混用；来源身份无重复，同方同 FT 恰一份。A/B 角色不得交换。
3. F 路径：`读取准确特征事实({1,Gread,H,F})`成功；`读取当前采用完整_v2({2,Gread,H,E,FT})`成功且唯一采用正是 F；`读取存在身份来源历史见证(Gread,H,E)`成功。
4. B 路径：`读取状态使用绑定历史({1,Gread,H,B})`成功且 E 相同；`读取状态历史内容({2,Gread,H,S})`成功；状态值经`核验正式特征类型准确值`取得 I64；存在历史见证成功。一个参与者的全部 B 必须具有相同 C 和强时间。
5. 所有返回见证只保存已由 provider 完整核验的值式事实；不保存服务指针、仓库对象、预算或内部计数。

### 5.3 FC、EC、RC 和 K

1. RC 求值先用版本 2 RC 完整读取，定义截止固定`Gread/Gread`；冷却可求值，退役返回`退役不可用`。候选入口先调用现有公开`规范化二次关系定义`。
2. FC/EC 经`读取二次关系约束定义({2,{1,Gread,Gread},概念})`完整读取。FC 只接受 pure v2 I64 特征概念；通用 EC 只接受规则版本 1、`不预设特征`、空父的通用存在定义；具体 EC 接受完整两组定义并递归核验子 EC，无环且无漏项。
3. 每个原子先`读取I64比较绑定_v2`固定 K，再`读取当前I64比较绑定_v2`确认同 FT+用途唯一当前路由为同一 K。任一不一致返回规则不支持，不选择其它 K。
4. 物理输入固定左=B、右=A。只请求差异角色 4；调用唯一`有序I64特征比较提供者::比较`，不得复制算术。结果差异`r`映射域位：负=1，零=2，正=4。
5. 原子命中=`FC命中 && EC命中 && (D & 域位)!=0`；AND 必须执行并核验全部原子，即使已有一项不命中也不能短路技术失败。
6. 末尾再次核 Gread。只有全部必要项完成才返回`命中/不命中`和完整见证；任何非成功清空条件组、来源组和已核验概念。

### 5.4 失败映射

| 下层或条件 | 求值状态 |
| --- | --- |
| 版本、身份、重复/混合来源、错 E、角色或请求形状 | `入口拒绝` |
| 所需 F/B/S/E、当前采用、FC/EC/K 缺失 | `证据不足` |
| 任一所需对象 H 时已退出、历史材料已清理 | `历史材料不可用` |
| G 守卫变化 | `事实代次漂移` |
| provider 资源失败、分配失败、长度不可表示 | `资源失败` |
| 规则/算法/表示未实现，K 路由缺失或不一致，非 I64 | `规则不支持` |
| FT 不同或输入类型不相容 | `类型不相容` |
| 单位、缩放、量化、输出合同不相容 | `单位量化不相容` |
| K 要求参照而来源无法证明 | `参照不相容` |
| 比较提供者差异不可表示 | `运算溢出` |
| 当前 RC 退役 | `退役不可用` |
| 旧材料明确回显旧预算状态 | `旧预算不足`，仅迁移识别；新链不得产生 |
| 结构矛盾、重复权威项、成功谓词矛盾、未预期异常 | `内部不一致` |

任何 provider 的`资源失败`不得映射为不命中、证据不足或未找到。

## 6. 普通应用装配

`普通应用上下文`新增并按声明顺序析构：

1. `std::unique_ptr<有序I64特征比较提供者>`；
2. `std::unique_ptr<二次关系求值应用服务>`。

构造顺序固定在 L1、特征值、特征、存在、状态、场景、概念及特征值域比较均成功之后；求值器借用当前上下文同实例服务。新增只读取得函数：

```cpp
二次关系求值应用服务* 读取普通应用二次关系求值服务() noexcept;
```

它只返回当前普通应用唯一实例的 non-owning 指针；上下文不存在或求值器未构造时返回空。不得增加第二服务实例、静态缓存、默认假服务或业务求值副作用。
