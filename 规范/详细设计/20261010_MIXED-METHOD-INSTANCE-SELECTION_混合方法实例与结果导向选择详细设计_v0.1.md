# 混合方法实例与结果导向选择详细设计

身份：MIXED-METHOD-INSTANCE-SELECTION；版本：v0.1；日期：2026-10-10。

代码起点：`064eac11f9aa5855a388584852529895071022b1`。直接机器语义依据是当前用户对混合实例结构、结果优先和最大可达变化量的明确裁决。0050、3100、3200、3300、5350、5360及现行完整复制设计只在不冲突范围补充。旧“全部候选中恰好一组条件具备”选择门被本设计替代，不修订其它范围。

## 1. 目标、边界与复用

任务持有自己的混合方法实例结构，包含多个候选方法完整副本。先根据任务目标选结果，再检查该结果对应的条件。优先保证满足目标；否则选择方向一致、同单位有限可达变化量最大的结果。同阶并列返回匹配不唯一。最优结果条件不足时返回筹办材料，不偷偷降级到次优方法。

方法类只负责实例结构、完整配对与来源查询；任务类解释需求、比较结果、筹办条件并调用既有本能执行器。self只消费任务类结果并实施既有双根、安全和冲突决议，不重新实现选择算法。W2工作线程负责首次实例化，manager及self独立读回保持纯读。

当前可复用：方法类`复制方法`完整复制闭包和逆序清理、`获取方法`、参数场景建立及本能调用；任务类`绑定方法实例`、W2条件核验、`核验任务执行方向`、`确认任务进入待执行`、`执行任务本能方法`及真实结果链。扩展而不另造执行器。

现有缺口：任务只绑定一个副本根；W2仍读取抽象候选；self与task两个门仍要求所有候选中唯一条件具备；目标结果检查没有完整解释目标比较关系。上述均在本次修改范围。

不包含：组合方法分支/循环解释执行、自动线性模型、条件反推、自动练习/区间细分、实例替换/解绑/正式删除、概念内容快照、服务结算WIP迁移、新结果渠道、任务优先级和自动子需求发布。条件不足只返回正式配对与核验材料供既有治理链筹办，不宣称自动生成子需求已完成。

本次编排改变任务治理状态，目的为按需求选取并执行合法方法；不把任务编排本身当作现实世界动作。本能方法的实际作用对象、动作先登记、结果独立取得维持既有合同。

## 2. 混合结构与所有权

新增方法域内部类型“混合方法实例根”，不是方法节点，不能被调用、登记或抽象召回。根包含候选入口成员字段；每个成员是对应抽象候选的完整副本入口。图内共享调用、循环和分支按一张源编码映射保留，不重复展开。同次多个入口的闭包交集只复制一次。

所有副本方法的`来源方法节点`仍指各自对应抽象方法；`实例根节点`统一指混合根。旧单方法复制保持旧语义：实例根为副本方法自身。读取方法时允许根为旧副本根或新混合根，必须验证根成员与完整闭包一致。副本仍不参加抽象召回、登记名枚举和长期知识去重。

任务继续只有一个`方法实例节点`字段，可指旧单根或混合根；不新增抽象方法镜像字段。绑定不得共享给其它任务、不得替换已有绑定。混合根的内部候选入口不能单独绑定另一任务。旧副本根按单成员投影兼容；精确重复不重新复制。

混合根创建时只接收非空、无重复、可完整读取的抽象候选根组；排序只用于规范化输出，不赋予优先级。复制停用状态不授予执行资格。候选成员与调用闭包成员有区别：只有候选入口参与任务结果选择，被调用子方法不能越过组合入口直接变成替代方案；组合候选保留结构但本次明确返回执行暂不支持。

`筹办任务条件和参数`保持const纯读。已绑定时从实例候选入口读条件及参数，不再以抽象配对编码输出。旧未绑定直接const筹办可以保留抽象读取路径，但选择和正式本能执行链统一要求合法实例；worker先实例化再筹办。已有纯记录/未绑定任务的`开始方法执行`旧低层合同保持，不暗中创建实例。

## 5. 结果比较算法

### 5.1 对象、类型与关系

读取唯一需求、目标存在、目标FT根、当前准确值及实例单位。读取每个候选入口的完整结果与对应参数规格。只把映射到该目标存在和同FT根的必需结果作为任务目标结果；可选副作用不能用来保证目标。角色绑定不唯一、目标实际特征不唯一或材料缺失，不得随意指定。

先建立角色到实际对象/特征身份的定位，再判断结果能力；不能用当前条件值不满足来提前丢弃适用结果。当前W2规格值域过滤可能导致绑定为空；若完整候选中参数缺失/材料未到导致无法确定目标作用角色，则返回等待条件/材料，不将该候选当作不适用而执行其它方案。本次不创造默认目标角色映射。同一对象类型有多个对象且无法唯一绑定时返回等待材料或结构缺口，不猜目标之外的角色对象。

支持已有结果关系`单项`、`全部成立`、`主要结果及允许副作用`。未知、任一、有序、条件选择以及状态/动态结果保持明确暂不支持。相同目标出现多个互相矛盾的必需结果不能取较有利一项。结构完整但本轮无法解释的同阶候选不能静默当作不存在，返回暂不支持/材料不足，不声称全局最优。

### 5.2 值目标保证满足

必须读取`目标比较关系概念节点`并核验其输入类型和参照值域，不能一律把目标当作“落在目标区间内”。关系组是当前合同中的并集。

对I64目标域T，令L为最小下界、U为最大上界；在完整I64域中构造满足集S：

| 关系 | 满足集 |
| --- | --- |
| 等于、包含于参照值域 | T |
| 小于、低于参照值域 | x < L |
| 小于等于 | (x < L) ∪ T |
| 大于、高于参照值域 | x > U |
| 大于等于 | (x > U) ∪ T |
| 不包含于参照值域 | I64全集减T |
| 任意 | I64全集 |

严格端点在INT64边界生成空集，不做溢出的加减。T可有多个不连续区间，不能用包络填平空洞。关系并集先求S并规范化。完整结果域R非空且R⊆S，才能标为保证满足；R仅与S相交不构成保证。本规则不是声称R为随机，而是当前已有C/R未细化到唯一点时不把部分可达能力误当整个配对保证。

非I64结果仅在现有值域比较能完整证明包含、相等或相离时判断对应集合关系；不支持的有序比较明确返回暂不支持。结构化类型/存在引用等不得按稳定编码大小比较，也不产生幅度排序。

### 5.3 方向与最大能力

无保证满足候选时，值目标所需方向沿用需求fresh复核的`需增加/需减少`；无单一方向时不猜。方向需求直接读取增加/减少。结果方向必须与需求一致。有限R域存在时可由R相对当前值严格位于同侧证明方向；显式方向与值域推导矛盾则结构不一致。方向明确但没有有限幅度不等于无限能力。

同目标同单位I64候选：增加比较R的最大有限上界，减少比较R的最小有限下界。它们与同一当前值的变化量排序等价，因此直接比端点，避免减法和溢出。端点为INT64_MAX/MIN无限哨兵时不能当有限幅度；只有方向的宽域不能战胜有限候选。存在同阶幅度未知候选时返回`幅度材料不足`，不能把未知当零或擅自忽略。

同单位须同时核对当前特征实例单位与R概念单位。单位不同或无法证明相同不换算、不排名。A=[1,100]、B=[10,20]在相同基准的增加能力比较时A优先；此处端点是不同条件下能力边界，不是本次随机结果。

保证满足优先级高于方向推进，保证档只用于值/值域目标的完整比较关系证明。纯变化方向目标直接进入同向最大幅度档，不能因为方向相同就全部进入保证档。保证满足多组并列返回`匹配不唯一`；方向同阶取唯一有利端点最优，端点相同返回不唯一。不以编码、枚举顺序、方法名、条件容易程度或随机打破并列。

### 5.4 选定后核验条件

唯一选定后核验同一配对的C，返回其参数绑定及条件核验材料。条件全部具备才为`已选定`；不具备、参数尚缺或当前值材料未到为`等待条件`；结构/资源错误按对应状态返回。不得拿A的C配B的R，不得在最优C不具备时偷偷改选次优。

区间端点不能线性反推具体C值。已知“条件增加导致结果增加”只说明局部方向，不足以算出取得100的条件。调用使用已存在完整C/R，不补造比例、条件值或准确执行结果。自动练习留后继。

## 6. 生产接线与fresh检查

W2工作线程处理条件筹办工作时先`实例化候选方法(T)`，只有成功/精确重复后调用纯读W2。失败在现有工作结果中明确返回未完成/结构失败，不产生具备材料。manager调用纯读W2做独立读回，不再触发复制。

异常沿既有worker最终诊断向上返回，不新增日志机制、工程文件或专用消息路径。

self分类筹办反馈时调用`选择任务方法结果(T)`，替代统计全部条件具备数量。成功把选定M/P/R用于现有执行前判断；等待条件走已有等待/筹办反馈；并列、无适用、幅度未知和暂不支持不发动作消息。参数绑定来自选定方案的fresh材料，不沿用抽象候选身份。

`核验任务执行方向`先fresh选择，要求传入定位与唯一选择完全一致；继而保持预计变化、结果获取方案、冲突及双根硬门。目标匹配应复用选择算法，不能后段又用旧包含规则否定合法`>`/`不包含`目标，或放过未选中的配对。

`确认任务进入待执行`再次fresh选择核验定位与条件。worker在创建X前重新核验选择、绑定、预计变化及获取方案与请求完全一致；漂移返回定位变化/等待材料，零动作，不自动切换方法。`开始方法执行`对已绑定任务检查调用方法属于该实例根（混合或旧单根），禁止抽象方法/其它任务实例。选择只面向候选入口，不因此开放对子方法的任意执行。

任务锁内完成治理检查与X建立后释放锁，再调用本能函数；不能持任务锁执行阻塞动作或回调。函数返回仍不等于任务完成，W3-B结果获取、影响评估和self决议保持原合同。

## 7. 事务、并发、失败和生命周期

本底座当前无组合事务。本次不宣称崩溃原子或跨进程恢复，沿用已发布完整复制的owner锁及本次新增物反序撤销。混合复制在方法锁内先规划全部源闭包、验证owned引用与外部概念，再分配全部节点、写字段、写来源/根、最后发布根/成员并完整读回；所有写入加入同一撤销账。任何失败不返回可用根/映射；清理失败升为结构不一致并停止受影响操作。

任务实例化持任务锁，方法创建与绑定按task→method固定顺序；方法不回调任务业务。绑定失败时只撤销本次创建的未绑定图，既有绑定及源知识不动。私有撤销在method锁内验证待删集合及外部反向引用，存在已绑定/执行/未知外部引用即拒绝删除并报结构不一致。成功绑定后不删除、不替换、不自动补候选。

根/副本完整读回不等于外部概念内容快照；概念仍共享引用。动作前fresh重核；执行后的概念扩域、旧预测冻结等既有缺口不在本次伪装解决。SERVICE-SETTLEMENT-INSTINCT-CONSUMER未提交函数按原抽象方法身份比较的问题仍属于其本身迁移，不纳入验证成功链。
