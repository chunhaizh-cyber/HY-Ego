## 1. 目标与非目标

本叶把七族旧的“当前 / 历史共用 `读取{族}身份来源`”拆为两种不可混用的公开合同：

```text
当前结构身份
  = G0 + 本族身份
  -> header-only 确认

历史来源见证
  = Gread + 本族身份 + H
  -> H 自证的完整共同见证
```

七族固定为：场景、存在、特征定义、特征实例、状态、动态、因果。

本叶不改变 `L2节点族身份来源事实`的十字段形状，不改语言、词条、概念、不可变材料、概念名称关系、DATA-L3、ARCH-L4、P08、4070 的持久格式或 L1 事实。它不增加世界第八服务、通用跨族服务、当前 DTO、当前 payload、owner 字段或恢复兼容壳。

## 2. 冻结的公开 ABI

### 2.1 当前确认

每个服务只新增 / 保留一个下列形状的当前确认函数：

```cpp
L2结构结果头 确认当前{族}结构身份(
    const L2结构请求头& 请求头,
    L2{族}身份 身份) const;
```

它不接受 `L2读取类别`、历史截止或完整见证；不建立当前 request / result wrapper。成功当且仅当：

```text
合同版本正确
+ 状态 == 已读取
+ 事实截止代次 == G0
+ 变更事实代次为空
```

成功只确认该身份在同一 G0 的结构当前性。provider 在内部同代验证目标节点、族锚点、族归属关系类型、唯一归属关系和内部 owner；调用方不能从成功结果取得或反推任何这些字段、生命周期、当前特征值、状态当前选择或动态当前值。

### 2.2 历史见证

每个族建立独立且不可与当前确认互换的下列形状：

```cpp
struct L2{族}身份来源历史见证读取请求 final {
    L2结构请求头 请求头;                 // 非零 Gread
    L2{族}身份 身份;
    std::uint64_t 历史截止事实代次 = 0; // 非零 H，且 H <= Gread
};

struct L2{族}身份来源历史见证读取结果 final {
    L2结构结果头 结果头;
    std::uint64_t 历史截止事实代次 = 0; // 成功时 == 结果头.事实截止代次
    std::optional<L2节点族身份来源事实> 身份来源见证;
    bool 成功() const noexcept;
};
```

`成功()`必须检查公共结果头、本族枚举、空变更、非空见证、见证在 H 完整，以及：

```text
历史截止事实代次 != 0
&& 历史截止事实代次 == 结果头.事实截止代次
```

H 是响应绑定见证，不能因结果头已有截止而删除。它不是第二权威事实代次；只有 `成功()`完整成立才构成历史见证。

## 3. 当前与历史的读取算法

当前确认先完成 G0 守卫，再只从同一 owner-aware 当前投影取得本族来源闭包；不得回读历史、更改事实、为缺项补写、按最大代次扫描或由空退出集合猜测当前。

历史见证先完成 Gread 守卫，再以 H 读取完整历史节点、锚点、关系类型、归属关系与 owner 生命周期。晚于 H 的退出必须从投影隐藏；H 已包含的退出保留在共同见证的四份生命周期中。历史成功不以“仍当前”为条件，因此合法对象在 H 前退出仍成功，不能被改报 `已退出`。

当前和历史都必须在已接受本族身份后证明唯一、方向、角色、owner、锚点、类型和生命周期同截止闭包；不能把本族身份、来源关系或 owner 解释为业务真实性、状态真实性、因果正确性、需求、任务、方法或权限结论。

## 4. 可观察失败与结果形状

下表是七族共同实现顺序；它替代旧混合入口各自不同的分支顺序。

| 阶段 | 当前确认 | 历史见证 | 结果 |
| --- | --- | --- | --- |
| 请求形状 | 版本错、G0 为零或身份零 | 版本错、Gread / H 为零、H > Gread 或身份零 | `入口拒绝`，空见证、空变更、截止与结果 H 均为零 |
| 守卫 | 不能取得精确 G0 | 读前或读后 Gread 不一致 | `事实代次漂移`，空见证、空变更；只可回显实际已观测代次 |
| 当前存在性 | 编码不存在 | — | `未找到` |
| 当前退出 | 编码已退出 | — | `已退出`；本步骤优先于当前错族判定，且禁止为分类回读历史 |
| 历史存在性 | — | 编码不存在或 H 早于创建 | `未找到` |
| 身份可接受性 | 当前且未退出的错 owner / 非本族 / legacy / 裸节点 / 保留元节点 | H 可见的同类非本族对象 | `入口拒绝` |
| 来源闭包 | 本族目标的 owner、锚点、类型、唯一归属、方向、角色、生命周期或同截止闭包缺失、重复、错配、混代 | 同左，以 H 判断 | `内部不一致` |
| 历史退出 | — | 本族对象在 H 前退出且闭包完整 | `已读取`，返回完整历史见证及 H 可见退出生命周期 |

`bad_alloc`、`length_error`或等价资源不可用返回`资源失败`；其它异常、L1 结果形状 / 合同矛盾、provider 路由或装配矛盾返回`内部不一致`。失败发生在守卫完成后，结果头截止回显已确认的 G0（当前）或 H（历史）；守卫前失败为零。所有非成功均为空见证、空变更、零写入。历史请求已通过形状检查时，结果仍回显输入 H；形状失败时结果 H 为零。

## 5. 迁移和物理退役

旧 `L2{族}身份来源读取请求`、`L2{族}身份来源读取结果`和`读取{族}身份来源`必须在同一代码实施计划、同一最终暂存集内与全部调用点一起物理删除。禁止转发器、别名、拒绝壳、隐藏 overload、开关、双默认或仅为编译保留的类型。

调用点按用途分流：

```text
需要证明“此刻 G0 仍是本族当前结构”
  -> 确认当前{族}结构身份

需要读 H、退出、重放、审计或恢复期间的完整生命周期
  -> 读取{族}身份来源历史见证
```

`服务.L2状态动态原子发布.ixx`的首次分支必须使用当前确认，非首次幂等重放必须使用 H 历史见证，二者不得合并。`服务.L2需求结构.ixx`的当前消费者迁移后只以 header-only 成功与 G0 绑定判断结构当前性，不得再读取旧共同见证的生命周期字段。

`服务.L2需求结构.ixx`、`端到端测试.自我治理一致事实.ixx`、`装配.普通应用.ixx`及其关联 SELF-GOVERNANCE WIP 当前由其它所有者修改。本叶不得覆盖它们；形成代码计划前必须完成交接、完成或从本计划精确排除。全部旧名消费者还必须在届时基线以 `rg` 重新枚举，计划白名单不得引用本设计形成时的旧观察清单。
