## 1. 具名漂移与裁决

执行侧在正式基线 `cfd8e440f143d939c93b7c15348a789e290bce74` 的 S0 中确认：v0.1 要求 `L1实际存在场景组合服务` 直接持有 `L1事实基座服务&`，并自行提交中性写集、读取当前 / 历史中性事实。这违反 4030 §3 的依赖方向，也夺取了 4200 §3.7 已冻结给 L2 场景业务服务的直接存在成员关系准入和唯一写权。即使代码运行成功，也不能作为合法第二层消费者证据。

v0.2 在原目标内作唯一裁决：

```text
L1实际存在场景组合服务
  -> 初始场景实际存在原子发布服务：创建与组合读取
  -> L1实际存在服务：资格权威读取
  -> L1场景结构服务：直接存在成员关系业务准入、唯一退出写入、当前 / 历史关系读回

L1场景结构服务
  -> L1事实基座服务：唯一 0 新建 + 1 退出中性提交与中性读回
```

组合服务不得持有、导入或调用 L1；不得形成中性写集、映射中性状态、读取中性事实或保存关系退出路由。场景结构服务是当前可复用的场景事实所有者：它已经持有 `L1事实基座服务&`，现有初始场景创建和接纳读取也由该服务完成。新退出能力必须进入该服务，不能建立第二个万能关系服务。

本修订不改变用户边界：L1 不自证；由合法第二层消费者经具名领域服务使用正式 L1 增删改查并完成权威读回，只累计证明实际覆盖部分。当前不考虑崩溃、重启或跨进程恢复。

### 4.2 唯一场景写入口


函数形态：`L1场景结构服务` 非 const 公共成员函数。它修改 L1 权威事实并复用类内现有互斥锁；不建立第二把锁或外泄锁生命周期。

诊断责任：向上送出。入口拒绝、未找到、版本漂移和幂等冲突是结构化结果；资源失败和内部不一致继续向调用方上送，生产最终责任边界按现行日志规范记录，不在每层重复记录。

### 4.3 请求有效性

请求有效必须同时满足：

1. 子合同版本、世界规则版本、幂等身份和期望事实代次有效；
2. `场景` 是完整的当前初始场景定位；
3. `存在` 是非零普通节点见证；
4. 当前归属关系稳定编码非零，并与世界根、原场景和存在编码互异；
5. 关系方向、关系类型和角色不由组合服务或请求补造；场景服务必须从当前或历史关系事实读取，并验证为 `场景.初始场景 -> 存在`、当前登记直接成员关系类型、角色或顺序为零；
6. 世界根、原场景和存在满足现有见证不变量。

幂等键固定为：

```text
场景退出键 = (0x1AULL << 56) | 请求.幂等身份.值
```

`0x1A` 由本场景写入口唯一拥有。组合服务只把外层实际存在幂等身份的值无损装入 `世界操作幂等身份`，不形成 L1 键。

## 5. 场景服务内部流程

### 5.1 写前准入

函数取得现有场景服务锁后按固定顺序：

1. 校验请求纯值合同；读取当前世界登记并验证世界根和直接成员关系类型；
2. 读取中性当前事实代次为起始；
3. 复用模块内部 `读取实现` 读取请求初始场景；
4. 读取中性当前节点取得存在；
5. 读取中性当前关系取得请求归属关系；
6. 当前关系成功时逐字段验证编码、端点、登记关系类型、角色和未退出，并要求起始代次等于请求期望事实代次；
7. 当前关系为 `已退出且无当前事实` 时，读取中性历史事实并验证同一完整关系，标记为“已退出候选”；
8. 当前关系未找到、类型错误、携带坏事实，或场景 / 存在 / 登记任一不完整时返回具名非成功；
9. 复读当前事实代次；起始、场景、存在和结束必须同一非零当前截止。当前关系路径还要求该截止等于请求期望事实代次；已退出候选路径要求历史创建代次不晚于请求期望事实代次、历史退出代次不晚于当前截止。若请求期望代次不早于历史退出代次，关系在请求截止前已经退出，直接返回未找到；只有期望代次早于历史退出代次的重复候选才进入 L1 幂等裁决。历史关系的适用代次为其退出代次，不伪装成当前截止。

“已退出候选”不直接算成功：请求截止已经包含该退出时直接返回未找到；请求截止早于退出时才用同一完整请求调用 L1 幂等账。原键同义得到精确重复；其它键因旧期望代次得到版本漂移；同键异义得到幂等冲突。

### 5.2 唯一中性写集

写集固定为：

| 类别 | 数量 | 内容 |
| --- | ---: | --- |
| 节点新建 | 0 | 无 |
| 关系新建 | 0 | 无 |
| 值新建 | 0 | 无 |
| 属性槽变更 | 0 | 无 |
| 退出事实 | 1 | 请求当前归属关系的稳定编码 |

函数恰一次调用 `L1事实基座服务::提交中性写集`。不得建立领域意图、业务标签、执行证据、提供者见证、摘要、完整快照、审计或恢复材料。成功和精确重复必须零新编码映射；首次成功形成一次发布，精确重复回显首次发布代次。

本入口专用状态映射：

| 中性状态 | 场景状态 |
| --- | --- |
| 成功 | 已提交 |
| 精确重复 | 幂等读回 |
| 入口拒绝 | 入口拒绝 |
| 事实代次漂移 | 版本漂移 |
| 幂等冲突 | 幂等冲突 |
| 已退出、未找到 | 未找到 |
| 资源失败 | 资源失败 |
| 内部不一致 | 内部不一致 |

该专用映射不得改变现有初始场景创建函数的通用写入映射。

### 5.3 场景终态读回

成功或精确重复后固定执行：

1. 读取当前事实代次为读回起始；
2. 当前关系入口读取旧归属，必须是 `已退出` 且无当前事实；
3. 历史入口读取同一编码，必须是完整关系，端点、类型和角色等于请求，退出代次等于首次发布代次；
4. 当前节点入口读取原场景和存在，两者仍为当前普通节点；
5. 复读当前事实代次，起始、两个当前节点和结束必须同一非零截止且不早于首次发布代次；
6. 形成 `初始场景直接存在成员退出事实`。

场景服务不读取或解释实际存在资格；资格由实际存在服务拥有并由组合服务写后互证。

## 6. 组合服务公开合同

### 6.1 实际存在包装 DTO

`海中鱼巣/领域/L1实际存在.数据.h` 继续拥有 v0.1 已冻结的四个实际存在包装类型：

```text
实际存在当前场景移除请求
实际存在已退出归属关系见证
实际存在当前场景移除事实
实际存在当前场景移除结果
```

字段形状保持 v0.1：外层合同 / 规则、实际存在幂等身份、期望事实代次、完整 `实际存在读取请求`；结果包含世界根、存在、原场景、资格和已退出归属关系。它们是调用方拥有的不可变组合投影，不是第二事实仓。

### 6.2 构造与函数

构造冻结为：

```cpp
explicit L1实际存在场景组合服务(
    初始场景实际存在原子发布服务& 发布服务,
    L1场景结构服务& 场景服务,
    L1实际存在服务& 实际存在服务) noexcept;
```

只保存三个非拥有引用，不保存 L1、请求、写集、事实、结果、幂等路由或缓存。

公开函数：

```cpp
实际存在结果 在初始场景创建实际存在(
    const 实际存在创建请求& 请求) const;

实际存在当前场景移除结果 移除实际存在当前场景(
    const 实际存在当前场景移除请求& 请求) const;
```

既有非 const 创建入口只转发 const 实现。新增移除函数是唯一 const 业务实现，诊断责任为向上送出。

### 6.3 组合流程

移除函数固定执行：

1. 校验外层请求；
2. 经 `初始场景实际存在原子发布服务::读取初始场景实际存在` 读取写前组合事实。成功时进入“当前候选”，要求全部字段等于请求且截止等于期望代次；精确 `未找到且无事实` 时进入“已退出候选”；其它非成功直接返回；
3. 经 `L1实际存在服务::读取实际存在资格` 读取写前资格。当前候选要求资格逐字段等于写前组合事实且截止等于期望代次；已退出候选要求存在和资格编码等于请求、资格完整且当前截止不早于期望代次；
4. 由请求场景定位、资格返回的当前存在节点见证和请求归属关系稳定编码形成 `初始场景直接存在成员退出请求`，幂等身份值无损传递。组合服务不补造关系端点、关系类型或角色；
5. 恰一次调用 `L1场景结构服务::退出初始场景直接存在成员关系`；
6. 场景非成功按固定映射返回，不调用 L1、不补造事实；已退出候选只有取得场景 `幂等读回` 才能继续，若返回首次 `已提交` 则为内部不一致；
7. 场景成功后再次经实际存在服务读取资格，必须与写前资格相等且截止等于场景结果截止；
8. 再经初始场景实际存在原子发布服务读取同一定位，必须返回 `未找到` 且无事实；
9. 由场景退出事实和写后资格形成实际存在移除事实，当前候选可逐字段返回已提交或幂等读回，已退出候选只返回幂等读回。

组合服务不要求写前 / 写后资格读取与场景服务持有同一锁；它只接受具名服务各自返回的事实截止完全相等。任一漂移返回版本漂移，不把部分材料拼成成功。

状态映射固定：场景已提交 / 幂等读回映射同名实际存在状态；未找到、入口拒绝、幂等冲突、版本漂移、许可拒绝、资源失败、内部不一致逐项同义映射，不降级内部不一致。

## 7. 场景接纳读取的精确退出分账

现有 `L1场景结构服务::读取初始场景接纳` 只作以下窄修订：

- 当场景、成员和直接成员关系类型均为当前完整事实，而请求的精确归属关系读取结果为 `已退出` 且无当前事实时，返回 `世界结构状态::未找到`、空事实；
- 关系编码未找到、类型不符、携带事实矛盾，或场景、成员、关系类型任一退出 / 损坏时，继续返回既有未找到或内部不一致；
- 不把任意成员关系退出泛化为整个场景不存在。

该分账使初始场景实际存在原子发布服务的正式组合读取在移除后得到领域未找到，不需要组合服务解释中性状态。
