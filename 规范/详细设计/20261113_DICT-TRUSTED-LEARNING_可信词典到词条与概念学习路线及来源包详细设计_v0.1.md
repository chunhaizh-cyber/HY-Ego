## 1. 完整目标及不变边界

2026-11-14用户明确本模块承接两类认知需求。

- **词条未知。** 当前词条的含义或对应概念尚未明确，需要取得并理解词典义项，建立正式词条与概念的对应信息，随后重新读取原需求。
- **概念未知或不清晰。** 需要从词典定义取得材料，经语言理解和概念学习，找到或形成对应概念，或补充当前待完善概念的定义、特征及必要区别约束，随后重新读取原需求。

这两类需求分别根据正式词条信息、概念信息是否达到各自当前需求目标判定满足。查词典本能承担共同的材料取得子需求，W.F1502引用Q只标记材料已经取得。完整交付包括语言理解、词条对应写回与概念完善学习，并由自我依据当前信息决定后续工作。已登记词条仍可因为对应概念未知或定义不清晰而需要词典材料，上位需求发现须保留该入口。两类目标需要词典材料时均可派生W.F1502材料子目标，当前DICT-QUERY-MATERIAL完整叶负责该材料子目标。

词典补全词条及概念，不直接提供现实对象的当前事实或服务对象意愿。学习只修改内部知识，不回写词典文件。词典来源受保护与释义理解正确是两件事：正确理解的可信材料直接采用，不新设多轮证明门槛；缺规则、多义未解和解析错误不能冒充知识。

## 3. 第一阶段：包格式与唯一发布点

仅为外部词典材料设批次，不是业务事实代次、历史查询或热重载。

目录结构：

```text
基础数据/词典/
  当前批次.txt                  UTF-8/ASCII，64位小写 SHA256 加 LF
  批次/<清单SHA256>/
    批次清单.tsv
    词典.简体.tsv  繁简表.tsv  词头表.tsv  词性表.tsv
    来源清单.json  LICENSE.md  ATTRIBUTION.md  OpenCC-LICENSE.txt
```

批次清单 UTF-8 无 BOM、LF 换行，无转义：第一行四列 `HY-EGO-DICTIONARY-BATCH`、`1`、简体包标识、原始 raw SHA256；第二行 `OpenCC`、`ver.1.4.2`；其余八行按文件名排序，四列：固定文件名、字节数、SHA256、数据行数。四 TSV 的数据行数不含包头且须大于零；四说明文件行数记 `0`。只允许上述八个叶文件名，不允许任意路径、重复、缺项、附加文件项。批次标识是整份清单原始字节 SHA256，无清单自引用。

维护构建过程：先读受版本控制的来源清单，核 raw、原词典、OpenCC 两表与许可摘要/长度；所有核验在生成前。读输入构建简体正文与三表到同目录独有暂存批次，复制许可和来源说明，关闭全部文件后形成清单。生成批次目录后不再覆盖其内容；已存在同 ID 时核现有完整内容再复用，不修补既有批次。最后以同目录临时文件 `os.replace` 切换当前批次。切换前失败原 current 不变；可能留下未引用的完整批次，报告真实位置，不声称未产生任何文件。无自动删除旧批次，不改用户原始材料。

维护输入由受控来源清单固定，raw/原词典/OpenCC 三文件摘要和来源版本通过批次内的来源清单保留，不再复制为业务 DTO。SHA256 检测错批/损坏，不是恶意篡改者可同时替换清单时的身份认证。普通运行代码只有读接口，维护升级由明确操作执行，不设计自动联网更新、运行时维护或学习回写。本阶段不声称已设置操作系统只读权限或证明断电持久性。

## 4. 打开与错误合同

`离线词典数据源::打开(const std::filesystem::path&) noexcept` 公开签名和返回枚举不变。

1. 读取目录属性；目录缺失为未配置，属性故障/非目录为读取失败。
2. 有 `当前批次.txt` 时只读一次指向，严格检查 ID；核批次清单摘要、格式及八个文件的长度、摘要、数据行数。四个 TSV 在同一读取字节流中增量计算摘要并解析，不用先 hash 关闭再重开代替实际解析字节核验；说明文件只读核验。读取到末尾、摘要及行数一致才允许交付。使用原有解析器建候选索引和辅助表，最后一次交付 const 数据源。正常维护只能切换 current，不修改已引用批次；已打开索引不热更新。
3. 批次任一文件缺失、清单不匹配、包标识不符、辅助表格式不符或 raw 摘要与记录键不符为数据错误，整次打开不交付；无法访问/读取为读取失败；容量异常为资源失败。不得退回旧文件凑成成功。
4. 无 current 时保留旧原包只读查询能力：仅简体文件确实不存在才回退 `词典.tsv`，存在但不是普通文件或属性故障不能回退。没有完整批次凭证时辅助表不启用，诊断“须构建同批词典包”；不让松散辅助表偷偷参与解释。原包查询能力不等于具备可登记的词典学习来源。
5. 批次记录键必须以同一 raw SHA256 加冒号开头，词性表包头也必须一致。合法单项确无词性仍返回空；整包错批不得降为这一正常缺项。
6. 查询期间不读文件、不反复算摘要、不重验整个索引。返回义项副本，不改变来源、语种、多义和候选顺序语义。

不新增业务锁、不持领域锁做 I/O。打开阶段候选局部所有；失败通过原有工程状态上送到装配责任边界，不记录业务未命中。底层私有辅助抛工程异常或返回具名诊断，不能 catch 后伪装空词义。此阶段不改普通启动装配。

## 5. 工程分发及物理归属

工程的 `复制可选词典数据` 改调用具名生产分发脚本，只分发一个已核批次，全部完成后切换产物 current。采用 PowerShell 标准文件/摘要 API，无额外 Python 运行依赖。源 current 不存在时保持旧原包条件复制路径：先暂存并核对原包和说明，准备成功后原子替换产物原包，移除工程自有旧简体/辅助表，最后删除产物 current 作为降级切换点；源无原包时先删除工程自有散包，最后移除 current 表示本轮未配置。切换前失败保留原 current；旧批次仍可用。上述删除仅限产物固定文件，不删除原始数据或批次目录。源 current 存在但损坏时构建失败，不退回旧输出。产物目录必须是 OutDir 下明确的 `基础数据/词典`，不以仓库根作清理对象。分发期间该产物目录不得运行程序，旧索引本身不热更新。

### 7.2 非成功与边界

词典根或指定批次目录确实不存在时返回未配置。属性读取失败、权限问题、非目录返回读取失败。指定目录存在但清单或声明文件缺失、摘要或行数不符、格式损坏时返回数据错误。资源失败沿现有异常映射。current指向缺失批次仍保持原数据错误语义，不用本节放松当前包准入。

如果读取失败后整个指定目录已被外部移除，可在异常边界重新读取该目录是否真实不存在，确实不存在则返回未配置。目录仍存在的残缺保持工程故障，属性复查失败保留读取失败。该检查只处理文件源生命周期，不成为业务快照校验。

Q携带的原包身份与加载结果包身份由上层作一次来源定位。不同批次或不同原包不能混用。学习服务取得源后只使用其辅助能力解析Q内已保存的I，不重新查询当前词典、不逐字段比较旧Q。

### 7.3 租约、缓存与部署

普通启动将实际程序目录下的`基础数据/词典`绝对路径、启动const源及原包身份交给词典语言编排服务。以`批次标识、原包标识`为服务私有成功缓存键，先复用启动源，再按需打开历史批次。失败不长期缓存。第一次读取在self、task及领域锁外完成，后续每行复用shared租约，不重复加载整包。

当前设计缓存成功源至self最终join后释放，服务无独立线程、无源回调。缓存只是外部不可变能力保活，不能取代Q/I正式来源。缺批由现有后台推进和重新发现触发再次取得，避免每条释义行都重试文件打开。

当前工程分发只复制current批次，已有产物历史批次保留。新产物缺历史批次是可达情况，本部分只提供指定批次读取，不宣称自动恢复、下载或复制全部历史批次已实现。
