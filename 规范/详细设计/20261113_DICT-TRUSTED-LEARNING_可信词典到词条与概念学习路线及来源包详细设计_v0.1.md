## 1. 完整目标及不变边界

2026-11-14用户明确本模块承接两类认知需求。

- **词条未知。** 当前词条的含义或对应概念尚未明确，需要取得并理解词典义项，建立正式词条与概念的对应信息，随后重新读取原需求。
- **概念未知或不清晰。** 需要从词典定义取得材料，经语言理解和概念学习，找到或形成对应概念，或补充当前待完善概念的定义、特征及必要区别约束，随后重新读取原需求。

这两类需求分别根据正式词条信息、概念信息是否达到各自当前需求目标判定满足。查词典本能承担共同的材料取得子需求，W.F1502引用Q只标记材料已经取得。完整交付包括语言理解、词条对应写回与概念完善学习，并由自我依据当前信息决定后续工作。已登记词条仍可因为对应概念未知或定义不清晰而需要词典材料，上位需求发现须保留该入口。两类目标需要词典材料时均可派生W.F1502材料子目标，当前DICT-QUERY-MATERIAL完整叶负责该材料子目标。

词典补全词条及概念，不直接提供现实对象的当前事实或服务对象意愿。学习只修改内部知识，不回写词典文件。词典来源受保护与释义理解正确是两件事：正确理解的可信材料直接采用，不新设多轮证明门槛；缺规则、多义未解和解析错误不能冒充知识。

## 3. 第一阶段：包格式与唯一发布点

仅为外部词典材料设批次，不是业务事实代次、历史查询或热重载。

目录结构：

```text
基础数据/词典/
  当前批次.txt                  UTF-8/ASCII，64位小写 SHA256 加 LF
  批次/<清单SHA256>/
    批次清单.tsv
    词典.简体.tsv  繁简表.tsv  词头表.tsv  词性表.tsv
    来源清单.json  LICENSE.md  ATTRIBUTION.md  OpenCC-LICENSE.txt
```

批次清单 UTF-8 无 BOM、LF 换行，无转义：第一行四列 `HY-EGO-DICTIONARY-BATCH`、`1`、简体包标识、原始 raw SHA256；第二行 `OpenCC`、`ver.1.4.2`；其余八行按文件名排序，四列：固定文件名、字节数、SHA256、数据行数。四 TSV 的数据行数不含包头且须大于零；四说明文件行数记 `0`。只允许上述八个叶文件名，不允许任意路径、重复、缺项、附加文件项。批次标识是整份清单原始字节 SHA256，无清单自引用。

维护构建过程：先读受版本控制的来源清单，核 raw、原词典、OpenCC 两表与许可摘要/长度；所有核验在生成前。读输入构建简体正文与三表到同目录独有暂存批次，复制许可和来源说明，关闭全部文件后形成清单。生成批次目录后不再覆盖其内容；已存在同 ID 时核现有完整内容再复用，不修补既有批次。最后以同目录临时文件 `os.replace` 切换当前批次。切换前失败原 current 不变；可能留下未引用的完整批次，报告真实位置，不声称未产生任何文件。无自动删除旧批次，不改用户原始材料。

维护输入由受控来源清单固定，raw/原词典/OpenCC 三文件摘要和来源版本通过批次内的来源清单保留，不再复制为业务 DTO。SHA256 检测错批/损坏，不是恶意篡改者可同时替换清单时的身份认证。普通运行代码只有读接口，维护升级由明确操作执行，不设计自动联网更新、运行时维护或学习回写。本阶段不声称已设置操作系统只读权限或证明断电持久性。

## 4. 打开与错误合同

`离线词典数据源::打开(const std::filesystem::path&) noexcept` 公开签名和返回枚举不变。

1. 读取目录属性；目录缺失为未配置，属性故障/非目录为读取失败。
2. 有 `当前批次.txt` 时只读一次指向，严格检查 ID；核批次清单摘要、格式及八个文件的长度、摘要、数据行数。四个 TSV 在同一读取字节流中增量计算摘要并解析，不用先 hash 关闭再重开代替实际解析字节核验；说明文件只读核验。读取到末尾、摘要及行数一致才允许交付。使用原有解析器建候选索引和辅助表，最后一次交付 const 数据源。正常维护只能切换 current，不修改已引用批次；已打开索引不热更新。
3. 批次任一文件缺失、清单不匹配、包标识不符、辅助表格式不符或 raw 摘要与记录键不符为数据错误，整次打开不交付；无法访问/读取为读取失败；容量异常为资源失败。不得退回旧文件凑成成功。
4. 无 current 时保留旧原包只读查询能力：仅简体文件确实不存在才回退 `词典.tsv`，存在但不是普通文件或属性故障不能回退。没有完整批次凭证时辅助表不启用，诊断“须构建同批词典包”；不让松散辅助表偷偷参与解释。原包查询能力不等于具备可登记的词典学习来源。
5. 批次记录键必须以同一 raw SHA256 加冒号开头，词性表包头也必须一致。合法单项确无词性仍返回空；整包错批不得降为这一正常缺项。
6. 查询期间不读文件、不反复算摘要、不重验整个索引。返回义项副本，不改变来源、语种、多义和候选顺序语义。

不新增业务锁、不持领域锁做 I/O。打开阶段候选局部所有；失败通过原有工程状态上送到装配责任边界，不记录业务未命中。底层私有辅助抛工程异常或返回具名诊断，不能 catch 后伪装空词义。此阶段不改普通启动装配。

## 5. 工程分发及物理归属

工程的 `复制可选词典数据` 改调用具名生产分发脚本，只分发一个已核批次，全部完成后切换产物 current。采用 PowerShell 标准文件/摘要 API，无额外 Python 运行依赖。源 current 不存在时保持旧原包条件复制路径：先暂存并核对原包和说明，准备成功后原子替换产物原包，移除工程自有旧简体/辅助表，最后删除产物 current 作为降级切换点；源无原包时先删除工程自有散包，最后移除 current 表示本轮未配置。切换前失败保留原 current；旧批次仍可用。上述删除仅限产物固定文件，不删除原始数据或批次目录。源 current 存在但损坏时构建失败，不退回旧输出。产物目录必须是 OutDir 下明确的 `基础数据/词典`，不以仓库根作清理对象。分发期间该产物目录不得运行程序，旧索引本身不热更新。

### 7.2 非成功与边界

词典根或指定批次目录确实不存在时返回未配置。属性读取失败、权限问题、非目录返回读取失败。指定目录存在但清单或声明文件缺失、摘要或行数不符、格式损坏时返回数据错误。资源失败沿现有异常映射。current指向缺失批次仍保持原数据错误语义，不用本节放松当前包准入。

如果读取失败后整个指定目录已被外部移除，可在异常边界重新读取该目录是否真实不存在，确实不存在则返回未配置。目录仍存在的残缺保持工程故障，属性复查失败保留读取失败。该检查只处理文件源生命周期，不成为业务快照校验。

Q携带的原包身份与加载结果包身份由上层作一次来源定位。不同批次或不同原包不能混用。学习服务取得源后只使用其辅助能力解析Q内已保存的I，不重新查询当前词典、不逐字段比较旧Q。

模拟世界增加只读入口按local W读取就绪字段和本地普通名称节点组，返回未知或准确的(C,本地名称节点)；正式C只作共享只读引用。读取从L1重建，不从缓存回放，别名指向相同W及名称组。退出沿原闭包删除，不触碰正式名称或C。此提供者只建立和读取前态；后继归类运行需要在同一设计继续闭合名称/F/S及调用回执的原子发表、关闭证据与完整定向样例采集。


### 10.26 定向归类来源的同批读取缺口

现有读取词条当前归类候选只在名称锁内取得普通名称标志，调用返回后再读取词条F1501不能证明两项来自同一底层时点。现有读取模拟来源完整特征也不能提供名称、F及材料的同批投影。定向学习需要名称owner与词条、特征、值owner协作形成本次复制来源，最终输出全部从同一批L1联合读取的实际材料解码。

来源采集先发现W、F、名称和实际值材料所需节点，再同批读取并从该批W/F发现仍需的依赖。发现当前依赖不在本批时扩充并重新读取，直到本批覆盖当前依赖。旧依赖在本批已不再被引用时可丢弃；当前仍引用却缺失的结构按真实工程问题处理。过程中底层变化内部重新读取，不以旧整组快照比较或业务锁嵌套作为一致性机制。各领域负责解释本领域结构。成功后该份前态供一次隔离样例使用，正式W后续变化不重放已执行样例。

通用模拟学习当前拒绝概念集合，定向归类需要保真复制F1501当前值、标准值和历史材料，C保持正式只读身份，并以正式引用保持各C在样例存续期间的依赖，不仅将编码放入U64材料。来源DTO、各owner同批解码参与接口、以及样例生命周期持有和释放方式需结合代码具体冻结后再进入实现。


### 10.27 隔离概念集合材料的引用保持

按实际特征定义的比较规则识别概念集合，不按U64数组本身猜测。模拟值材料保留原U64内容，同时对其中每个正式概念追加本地私有字段引用，材料与引用随样例同批发表并整体回收，概念节点不归样例删除。只读共享引用覆盖当前值、标准值、历史值、历史命中记录和有限实例区间／历史聚合中的每份材料，也覆盖常规材料输入。概念集合值域中的必含概念现已由结构引用保持。

按来源材料身份复用的local V只保留一份材料；即便该V先作为普通材料复制，后续作为概念集合复用时也要为同一local V补足成员引用。按local V与C去重。材料类型应为U64数组，其端点是否存在由L1发布裁定。原普通数组语义和材料不变。提交前按实际追加字段数预留接管容量，成功发表后的引用与节点沿现通用闭包接管；正式C消失或底层依赖发生变化时调用方重新组织来源，不把旧数据当成功结果。

本片只覆盖已有样例输入的概念引用保持；定向来源同批采集、合法下位特征概念识别、本地归类运行新增V及学习发现仍按10.26后继处理。


### 10.28 正式来源同批读取的领域参与

同批来源无需扩展L1。词条、特征、特征值、名称各owner需提供从给定联合快照解码本领域材料及列出直接依赖的能力；名称owner可协调读取W入向名称和F依赖并输出值式来源。词条提供身份、场景及F定位；特征覆盖当前、标准、旧历史、命中记录和有限域；特征值提供材料；名称区分普通与指代关系。最终输出只能由覆盖所有当前依赖的最后一批L1快照解码。

现有F1501由类型根直接建立；正式合同允许的下位特征概念也须支持，同批读取需包含特征概念上位链，由特征概念owner解码及确认类型。不能用另一次旧getter调用冒充同批结果，也不能将只支持根悄然当成完整实现。聚合结果使用现有领域值对象，模拟学习负责转换到本地输入。各参与接口、失效处理和责任需在实施前继续具体冻结。


### 10.29 特征值给定快照解码

同批来源读取需要特征值owner解释调用方已有的L1节点快照。新_特征值类增加解码特征值快照(const 基础节点结构&) const，返回状态与现有新特征值信息，状态区分已解码、未初始化、非本类节点及结构不可解码；不读取L1、不查索引、不修改数据，资源分配异常传给调用方处理。owner锁内读取已初始化且稳定的字段身份，以给定结构解码唯一节点类型引用、物理类型和原始材料，复用现有已知类型及材料形态规则。扩展字段及出入关系不参与材料解码。

实时获取特征值改为一次L1完整节点结构读取，调用同一个私有解码逻辑，避免两套材料语义；节点不存在或结构不对应沿现optional返回，真实资源异常沿既有工程故障处理。给定快照口不推断快照当前性，后继聚合读取负责最终同批依赖覆盖和变化重读。仅改原特征值类头源，不修改词典和数据；后续继续其它owner解码与归类来源聚合。


### 10.30 词条和名称的给定快照解码

为10.28同批来源提供词条及名称owner纯快照接口。词条输入联合快照，输出新词条信息及可选挂接定位（语言场景、原始特征节点组）；旧词条未建立场景和特征时挂接为空。使用本类初始化后稳定的字段身份及词组织根，解码类型、父边、语言、合同、词面、可选来源和扩展，不访问L1或其它owner，不将当前性判断加入接口。词面引用及扩展结构无法解码返回具名状态，资源异常上抛。当前F节点类型由后续特征owner在同批解码。

名称owner提供两个快照口：从词条快照入向字段按目标词条私有键发现名称节点组；解码名称快照的节点、概念、词条以及可选指代角色、语言、来源。普通名称三字段，指代名称包含三个补充字段；I64角色先检查1至3后转换。两个口均不读L1或其它owner，不判断快照新旧；聚合器需在同批重新发现依赖并读取缺失节点。状态区分成功、未初始化、非本类、结构不可解码，资源异常上抛。保留旧公开读取入口与其行为。

本片只新增原始快照投影，不将指代名称伪造成普通名称，不把这些原始信息冒充完整指代概念；特征、特征概念及聚合读取继续后继。


### 10.31 特征与概念链同批读取的依赖

F1501的类型根由特征概念树上的先天槽记录序号1501定位，不将序号当成节点编码。F实际特征概念沿同批唯一父边逐级上行至特征概念树，最后一个材料概念为类型根。合法下位概念须覆盖全材料域、概念集合约束域及有限材料域。概念集合域中的必含C和有限域中V及其概念成员均为真实依赖；不能照搬遗漏必含概念字段的旧保护枚举。

F同批解码应保留实际特征概念、当前值、标准值、旧历史、历史命中记录、实例区间与历史聚合及其实际V依赖。旧历史按现有读取语义形成一次命中，已登记命中记录保留实际次数；未知当前值与已知空集合分别表达。给定批缺少当前依赖时返回需补节点，由聚合器扩展并重新读取整批；不再引用的旧节点消失可忽略。最终数据均从最后一批解码，不在读取时重算历史或比较旧整组。各owner接口与聚合逻辑继续在本设计内闭合。


### 10.32 顶层概念集合特征的同批解码

特征owner提供解码顶层概念集合特征快照(F,本批节点项)。解码只使用调用方提供的L1批次，不读L1及其他owner，不核同新旧数据。状态包括已解码、未初始化、非本类、结构不可解码、需补快照、能力未支持。合法归组子特征本入口返回能力未支持，不把它当坏结构；词条实际顶层F不产生父特征。

F当前值、标准值及旧历史值必须为V引用，保留FC、可选单位和两个可选域；历史命中记录H从同批解码类型、所属F、V及正次数。实例区间及历史聚合域从同批解码全材料标志或有限V组；其余域表示返回能力未支持。历史先收H和实际次数，再收旧历史并记次数1，两组分别按准确值排序，既不去重也不重新计算标准值或历史聚合。无当前值和空集合V分别表示。

F/H/域或被引用V未纳入批次时返回待补节点组；已纳入且仍被本批引用但快照为空返回结构不可解码。成功返回新特征信息及全部需解码V身份，包括有限域V；V内容由已实现的特征值owner快照解码。FC下位归属、其定义和组织槽由特征概念owner后继提供，聚合者从最后一批组织结果。


### 10.33 概念名称挂接特征的同批类型链

特征概念owner新增针对概念名称挂接的给定批次解码。以特征概念树当前槽字段发现槽记录，从同批槽记录取得语义序号1501对应的真实类型根；槽记录由树字段持有，不要求父边。目标特征概念沿同批唯一父子边上行，遇特征概念树停止，树自身不是普通材料概念。链终点与同批槽根不符返回不相容。缺当前依赖列待补并由上层整批重读，不读取L1、不比旧快照。

叶定义返回现有特征概念定义值式材料。仅本归类功能所需的U64概念集合身份判等及完整材料精确集合，支持全材料、有限V及概念集合约束域三种，单位及规则按正式定义原样表达；其它类型或合法域返回能力未支持。有限域V与必含C列直接依赖，未纳入批次待补。根与下位链、目标域和槽均来自最后一次同批。类型链节点只消费身份及父边，不重审名称、计数和无关入向引用；叶定义只解码本功能消费字段。资源异常传上层。

本片提供类型链和域的给定批次解释，后续来源汇总仍需同批整合W/F/V/名称，并用值owner解释V材料及其中C。


### 10.34 正式词条归类前态汇总的后继边界

同批汇总从已绑定的正式W和F出发，避免将同一W下的词典材料等其它特征误当概念集合。名称owner协调词条、特征、特征概念和特征值owner的给定快照解码，各owner调用期间不持另一owner锁。W当前已不持有F时返回需重新组织来源。

以W/F为起点获取L1联合批次；每轮仅按本轮W发现名称、按F发现历史及域材料、按FC发现槽与上位链，再按V的U64成员发现正式C。缺当前依赖时扩展并整批重读，每轮丢弃旧投影；不再被当前事实引用的旧请求节点即使为空也忽略。仅最终依赖完整批次用于产生词条、语言场景、F完整投影、类型根、叶定义、V材料、普通及指代名称和共享C身份；普通名称组为空是已知空。保留原V身份、空集合与未知当前值，不按名称组补造特征值。样例在正式C退出时重新采集，发表后由local引用保持。

归类材料R当前仍由语言owner实时组织读取，不能将其独立结果与W/F汇总假称为同一批四参数来源。语言owner还需提供给定批次的R及其组织依赖解码。后继聚合先闭合W/F/V/名称前态，再将R纳入同一来源闭包，最后接实际隔离归类调用。上述接口和终止责任继续在本设计内冻结。
