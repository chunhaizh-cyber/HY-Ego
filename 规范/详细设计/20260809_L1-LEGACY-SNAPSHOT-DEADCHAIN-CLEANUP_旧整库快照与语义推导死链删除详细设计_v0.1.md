# 旧整库快照与语义推导死链删除详细设计 v0.1

日期：2026-08-09

状态：创建侧验证后登记

## 1. 目标与完成条件

本叶删除旧 L1 整库快照公开面及其全部现存消费者，并物理退出只为状态推导、迁移动能、业务比较、提供者见证和方法根解释服务的未接线死链。不得把这些消费者迁移到中性读取，因为迁移会继续保留现行 4030 已禁止的数据层业务解释。

完成必须同时满足：

1. 生产源码对 `读取完整快照`、`尝试读取完整快照`、`L1完整快照` 和旧完整快照请求 / 结果零定义零引用。
2. 旧 L1 服务公开面不再提供旧节点、关系、值、属性、历史、事实代次和完整快照读取函数；调用方只使用中性读取合同。
3. 未接线的后继状态规格、状态动态原子发布和方法登记根快照解释模块及其专属数据头从源码和工程中消失。
4. `L1状态服务`、`L1动态服务` 和 `特征比较服务` 中只被上述死链调用的状态选择、迁移动能形成 / 读取和业务比较入口、DTO 与私有辅助代码消失。
5. 世界登记、场景结构、特征定义、实例特征、状态登记、动态登记、比较合同登记、完整自我等仍在生产初始化中使用的结构 CRUD 与中性读写入口保持可构建、可启动。

## 2. 当前事实与裁决

正式起点为 `cf9ffde031f694227942cb17055c664e5007d097`。创建侧扫描确认：

- 旧完整快照共十三个生产源码调用点，全部集中在 `L1状态` 的相邻前状态选择、`L1动态` 的迁移动能规格 / 读取、`特征比较` 的运行期比较、后继状态规格组合和方法登记根快照解释。
- 状态动态原子发布模块没有构造者和外部调用者；后继状态规格只被该模块与 `L1动态` 的迁移动能规格入口消费；方法登记根当前读取模块没有构造者和外部调用者。
- `L1状态` 的相邻前状态选择只被后继状态规格调用；`L1动态` 的迁移动能形成 / 读取只被状态动态原子发布调用；状态迁移比较只被后继状态规格调用；通用 `比较特征` 当前没有该服务的调用点。
- 中性当前节点、关系、值、属性、历史、关系条件、事实代次和一致当前投影已经存在并有真实生产调用者，不属于删除范围。
- 工程与 filters 当前另有双轴根草案 WIP；本叶只能暂存本设计列出的删除行，不得夹带双轴根登记。

裁决：这些消费者不是必须迁移的结构服务，而是未接线且含业务推导、提供者见证、请求身份和状态迁移解释的旧链。现行 4030 禁止数据服务拥有这些语义，因此直接删除优于迁移。

### 3.2 核心公开面与实现删除

- 从 `合同.L1事实基座.ixx` 删除旧事实、属性、完整快照和事实代次读取请求以及只为这些请求存在的旧合同版本常量。
- 从 `服务.L1事实基座.ixx` 删除旧当前节点 / 关系 / 值 / 属性、历史、完整快照、尝试完整快照和旧事实代次公开函数。
- 从 `仓库.L1事实基座.ixx` 删除完整快照、尝试完整快照、快照构造和快照排序；内部精确读取继续供中性公开面复用。
- 从 `L1事实基座.数据.h` 删除完整快照及其结果；内部仍被中性适配使用的旧读取状态和内部副本暂留，不在本叶强行重写仓库。

### 3.3 死链局部删除

- `L1状态.数据.h` 与 `服务.L1状态.ixx`：删除相邻前状态选择、后继状态规格形成及其只属私有辅助；保留状态登记、首个基准状态创建 / 读取及现行中性读回。
- `L1动态.数据.h` 与 `服务.L1动态.ixx`：删除迁移动能规格、提供者见证、迁移动能读取及其只属私有辅助，并退出对后继状态规格模块的 import；保留动态登记与登记读取。
- `特征比较.数据.h` 与 `服务.特征比较.ixx`：删除无外部消费者的通用比较请求 / 结果、状态迁移比较请求 / 结果及其只属辅助；保留比较登记、两类比较合同登记 / 读取和其它仍有调用者的结构入口。
- `服务.L1场景结构.ixx`：删除已经没有调用者的旧 `L1读取状态` 映射重载，保留中性读取状态映射。

若实施扫描发现上述对象存在本设计未列出的生产调用者，停止该对象删除并返回具名调用点；不得恢复兼容壳或把业务解释迁到中性读取。
