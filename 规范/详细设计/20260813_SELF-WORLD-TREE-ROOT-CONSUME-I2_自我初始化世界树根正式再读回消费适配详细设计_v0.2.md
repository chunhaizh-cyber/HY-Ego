# SELF-WORLD-TREE-ROOT-CONSUME-I2 自我初始化世界树根正式再读回消费适配详细设计 v0.2

日期：2026-08-13

## 1. 目标、完成条件与声明边界

本设计以正式清理基线 `f5eff1bd64f82f56d2246cf3e458a25e0afa42b1` 重基线同身份 I2。`运行普通程序` 只从同一次 I1 成功结果的 `已发布根` 逐字段形成值式请求；I2 每次经普通应用上下文的 A1 getter 取得同实例 R1，重新读取当前场景树结构登记和目标整树，完整互证后才值式发布自我初始化后继可消费的根材料。

完成必须同时满足：

1. I1 失败返回阶段 14 且 I2 零调用；I1 成功的同次局部结果直接形成 I2 请求，不以 I1 getter 或缓存替代；
2. I2 每次调用都经 `取得L2结构聚合服务().取得L2场景结构服务()`，依次正式读取登记与整树；同请求重复也完整两读；
3. I2、A1、R1 及全部业务事实零写；尤其不得调用 `建立场景树根`；
4. 请求无效、异请求写前冲突、读取失败、坏成功形状、跨结果漂移、异常、并发和值式旧值守恒闭合；
5. I2 失败返回阶段 16；I2 成功而真实自我 provider 缺失时返回阶段 17；阶段 15 永久缺号且数值不复用；
6. 阶段 18、概念维度根、方法根、自我线程、投影、信号、宿主、恢复和跨进程均不在本切片；
7. 生产与专项实例化同一 `.inl` 源码正文但属于不同 TU 实体，分层证据不得冒充同一二进制实例。

I2 成功只证明本轮 R1 正式读回的系统世界树根材料已完成值式消费发布。它不证明真实自我、概念维度根、方法、线程或宿主已经形成。

## 5. 公开 DTO 与函数 ABI

数据头包含 I1 与 R1 数据头，不复制其 DTO。冻结：

```cpp
inline constexpr std::uint32_t 自我世界树根消费合同版本 = 1;

struct 自我世界树根消费请求 final {
    std::uint32_t 合同版本 = 自我世界树根消费合同版本;
    系统世界树根初始化请求 项目树选择;
    L2场景树根建立请求 首次根建立请求;
    L2场景树身份 树;
    L2场景身份 根场景;
    L2场景树归属事实 首次根标记;
};

enum class 自我世界树根消费状态 : std::uint8_t {
    已发布 = 1,
    精确重复 = 2,
    请求无效 = 3,
    已发布选择冲突 = 4,
    树结构登记读取失败 = 5,
    根正式读回失败 = 6,
    根读回不一致 = 7,
    资源失败 = 8,
    内部不一致 = 9
};

enum class 自我世界树根消费来源 : std::uint8_t {
    首次消费 = 1,
    已发布重复消费 = 2
};

struct 自我世界树根消费材料 final {
    自我世界树根消费请求 请求;
    L2场景树结构登记 当前结构登记;
    L2场景树事实 正式树读回;
    std::uint64_t 本次事实截止代次 = 0;
};

struct 自我世界树根消费结果 final {
    自我世界树根消费状态 状态 = 自我世界树根消费状态::请求无效;
    std::optional<自我世界树根消费来源> 来源;
    std::optional<L2场景树结构登记结果> 结构登记读取;
    std::optional<L2场景树读取结果> 根读取;
    std::optional<自我世界树根消费材料> 已发布材料;
    bool 成功() const noexcept;
};
```

普通应用模块唯一新增公开函数：

```cpp
自我世界树根消费结果 消费并发布自我世界树根(
    普通应用上下文& 上下文,
    const 自我世界树根消费请求& 请求) noexcept;

std::optional<自我世界树根消费材料>
读取自我世界树根消费材料(const 普通应用上下文& 上下文);
```

读取函数取得与发布相同的 I2 发布锁后按值复制；未发布返回 `nullopt`，锁取得或复制异常向调用方上送，不伪装为未发布。它只供后继消费或诊断；正式启动与重复消费不得调用它替代 R1 两读。

请求有效性固定为：合同版本正确；I1 选择有效；首次建立请求通过 `L2场景树根建立请求有效` 且幂等身份等于项目树选择；树与根场景身份有效且 `树.值 == 根场景.值`；首次根标记的树/场景/根场景身份均有效，类别为根，三端点分别等于请求树/根场景/根场景，关系稳定编码与物理目标稳定编码非零，生命周期创建事实代次非零且退出事实代次为空。请求不携带 I1 截止，因此不得用需要外部截止参数的完整性谓词替代这些逐字段条件，也不得用名称、缓存、无父或“第一棵树”补造请求。

结果形状固定为：

| 状态 / 来源 | 来源 | 结构登记读取 | 根读取 | 已发布材料 |
| --- | --- | --- | --- | --- |
| `已发布 / 首次消费` | 首次消费 | 成功且有登记 | 成功且有树 | 存在，等于本轮候选 |
| `精确重复 / 已发布重复消费` | 已发布重复消费 | 成功且有登记 | 成功且有树 | 存在，等于本轮刷新候选 |
| `请求无效` | 空 | 空 | 空 | 空；上下文旧值保持 |
| `已发布选择冲突` | 空 | 空 | 空 | 空；上下文旧值保持 |
| `树结构登记读取失败` | 空 | 存在且 `成功()==false` | 空 | 空；上下文旧值保持 |
| `根正式读回失败` | 空 | 成功且有登记 | 存在、`成功()==false` 且结果头状态不是 `已读取` | 空；上下文旧值保持 |
| `根读回不一致` | 空 | 成功且有登记 | 存在；或结果头状态为 `已读取` 但自身 `成功()==false`，或自身成功但跨结果互证失败 | 空；上下文旧值保持 |
| `资源失败` / `内部不一致` | 空 | 空 | 空 | 空；上下文旧值保持 |

`成功()` 只接受前两行，并逐字段验证来源、两个 R1 成功结果、本轮截止和已发布材料。异常路径即使已经得到局部 R1 结果，也清空结果中的两个诊断 optional，避免异常收束再次复制不完整材料；上下文旧发布值始终保持。

## 6. 编排、互证、并发和发布

wrapper 将上下文 I2 锁、发布槽、请求和一个无状态 A1 访问表达式交给 `.inl` 模板。完整持锁算法为：

模板合同冻结为以下等价形状（实现可只调整约束语法，不得改变参数和调用语义）：

```cpp
template<class 场景服务访问器>
自我世界树根消费结果 编排自我世界树根消费(
    std::mutex& 发布锁,
    std::optional<自我世界树根消费材料>& 已发布材料,
    const 自我世界树根消费请求& 请求,
    场景服务访问器&& 取得场景服务) noexcept;
```

访问器必须可在模板持锁后以左值调用、调用本身 `noexcept`，并返回一个生命周期覆盖本次模板调用的非 owning 左值引用；被引用类型必须提供与 final R1 同名同语义的 `读取当前场景树结构登记() const` 和 `读取场景树(const L2场景树读取请求&) const`，返回类型分别精确为 `L2场景树结构登记结果` 和 `L2场景树读取结果`。生产访问器固定为捕获上下文引用的无状态编排 lambda，其函数体只执行 `上下文.取得L2结构聚合服务().取得L2场景结构服务()`；脚本访问器返回脚本场景服务左值，脚本类型只实现上述两个读函数并按调用序列返回强类型结果。模板不得要求脚本服务继承或转换为 final R1，也不得让访问器、服务引用或上下文越过本次调用保存。这样生产与专项实例化同一模板正文但属于不同 TU/不同特化实体。

1. 纯值校验请求；失败返回 `请求无效`，A1/R1 零调用；
2. 已有发布槽且完整请求不同，返回 `已发布选择冲突`，A1/R1 零调用；
3. 调用访问表达式，每次取得 `上下文.取得L2结构聚合服务().取得L2场景结构服务()`；
4. 调用 `读取当前场景树结构登记()`；任何 `!成功() || !登记`（含坏 optional / 坏成功形状）统一映射 `树结构登记读取失败`，只保留实际登记结果；
5. 形成 `{{L2结构合同版本, 登记结果.结果头.事实截止代次}, L2读取类别::当前, 请求.树, 0}`，调用 `读取场景树`；若 `!成功() || !树`，结果头状态为 `已读取` 时映射 `根读回不一致`，否则映射 `根正式读回失败`；两者都保留本轮登记与实际根读取结果；
6. 逐字段互证；
7. 局部完整构造材料和结果，通过编译期无抛出移动/交换断言后，最后一次 `noexcept swap` 发布；
8. 首次返回 `已发布/首次消费`，已有同请求返回 `精确重复/已发布重复消费`。

互证至少包括：

- 登记结果、整树结果和树事实截止相同且非零；读取类别为当前、历史截止为 0；
- 整树内结构登记等于本轮登记载荷；
- 树身份、根场景、树值与请求一致；
- 本轮整树根标记与请求首次根标记逐字段相同，类别为根；此处只比较同类型根标记生命周期，不发明根节点场景生命周期与根标记生命周期跨类型相等；
- `L2场景树事实完整` 成立；场景组恰一根节点且其树归属等于根标记；父子关系不以根为子；
- 首次根建立请求有效，且其幂等身份等于项目树选择。

同请求重复仍每次执行步骤 3—6。I2 锁序唯一为 `I2 发布锁 -> R1 内部锁`；不持有 I1 锁，不调用日志、I/O、等待或回调。`bad_alloc` 映射资源失败，其它异常映射内部不一致；任何失败保持旧发布槽不变。
