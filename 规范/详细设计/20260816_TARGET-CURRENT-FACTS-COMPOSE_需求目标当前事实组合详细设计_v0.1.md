# TARGET-CURRENT-FACTS-COMPOSE 需求目标当前事实组合详细设计 v0.1

日期：2026-08-16

## 1. 目标与完成边界

本叶为 BIZ-L3-004-01-01 v0.3 建立父组合能力：调用方给出一个非零事实截止 `G0`、预期场景树、目标场景、目标宿主、目标状态合同和目标特征定义；同一 `需求目标事实提供者` 先读取完整目标合同定义材料，再以合同正式回显的特征定义读取目标宿主同截止当前特征事实，逐字段互证后一次返回完整值式材料。

完成只表示这一枚 BIZ provider 父组合函数已实现、验证并发布。它不执行目标差距比较，不建立需求 / 任务，不读取状态 / 动态 / 因果，不让普通应用持有本 provider，不新增 DATA 接口，也不证明 BIZ-L2-004-01、BIZ-L2-004-05 或系统治理闭环完成。

## 2. 正式依据与当前事实

- 0050：业务解释位于 DATA 之外；BIZ 只能经公开强类型接口消费值式事实，不直达 L1、owner、仓库或缓存。
- 3100、5100：需求目标由目标宿主、目标特征和目标状态合同组成；需求领域不得直接比较原始值。
- 4110、4160、4180：同宿主同定义当前实例唯一；材料缺失、类型不可比较和事实矛盾分账；当前计划只闭合 I64 目标判断材料，不执行比较。
- 4190、4230：当前特征值不等于状态或动态，读取链不得补造状态 / 动态。
- BIZ-L4-004-01-01-01 v0.2 已冻结 `需求目标事实提供者::读取目标状态合同与值域定义(...) const noexcept`。
- BIZ-L4-004-01-01-02 v0.1 已冻结同一 provider 的 `读取目标宿主同截止当前特征事实(...) const noexcept`。
- `TARGET-STATE-CONTRACT-DEFINITION-CONSUME v0.1` 与 `TARGET-HOST-CURRENT-FEATURE-FACTS-CONSUME v0.1` 均已登记待激活，代码尚未实现；当前正式 main 中 `需求目标事实.数据.h` 与 `提供者.需求目标事实.ixx` 仍不存在。
- 另有三份需求结构消费设计已把未来 `海中鱼巣/领域/服务.需求.ixx`、`需求业务服务`及其 DATA-EXT-12 构造配置冻结为需求结构 owner 消费面。本函数没有需求身份输入，也不读取需求结构；不得提前占用该模块或制造构造 ABI 冲突。

## 3. 唯一物理归属与依赖

本叶只在两个前驱计划建立的现有文件中追加 DTO 和成员函数：

```text
海中鱼巣/领域/需求目标事实.数据.h
  -> 追加父组合请求、材料、结果、状态、纯值 helper 和成功谓词

海中鱼巣/领域/提供者.需求目标事实.ixx
  -> 在同一 需求目标事实提供者 中追加父组合 const noexcept 成员函数
  -> 复用该对象已持有的唯一 const L2结构聚合服务&
```

不修改 `.vcxproj`、`.filters`、普通应用、`L2结构聚合服务`或任何 DATA 文件。两个前驱叶已经负责头和模块的工程登记；本计划只能在它们真实发布、退出并释放同两文件后激活。

物理裁决理由：本函数只组合同一 provider 的两个只读目标事实子叶，目标候选在需求节点尚未建立时也可读取；它不拥有需求结构。放入 `服务.需求.ixx` 会与已冻结的 DATA-EXT-12 需求结构消费计划争用类、构造和文件所有权，并让需求业务服务承担不依赖需求身份的第二事实入口。

依赖方向固定为：

```text
需求目标事实提供者::读取需求目标当前事实
-> 同对象 读取目标状态合同与值域定义
-> 同对象 读取目标宿主同截止当前特征事实
-> 同一 const L2结构聚合服务&
-> 正式 DATA-L2 场景 / 存在 / 特征 / 状态公开能力
```

## 4. DTO 与公开 ABI

```cpp
inline constexpr std::uint32_t 需求目标当前事实合同版本 = 1;
inline constexpr std::uint32_t 需求目标当前事实规则版本 = 1;

enum class 需求目标当前事实状态 : std::uint8_t {
    已形成 = 1,
    入口拒绝 = 2,
    目标材料未找到 = 3,
    目标材料已退出 = 4,
    目标上下文引用冲突 = 5,
    目标场景未找到 = 6,
    目标场景已退出 = 7,
    目标范围不成立 = 8,
    目标特征实例未找到 = 9,
    目标特征当前值未设置 = 10,
    当前值类型不兼容 = 11,
    当前性漂移 = 12,
    许可拒绝 = 13,
    资源失败 = 14,
    内部不一致 = 15
};

struct 需求目标当前事实请求 final {
    std::uint32_t 合同版本 = 需求目标当前事实合同版本;
    std::uint32_t 规则版本 = 需求目标当前事实规则版本;
    std::uint64_t 事实截止代次 = 0;
    L2场景树身份 目标场景树;
    L2场景身份 目标场景;
    L2存在身份 目标宿主;
    L2目标状态合同身份 目标状态合同;
    L2特征定义身份 目标特征定义;
};

struct 需求目标当前事实材料 final {
    目标状态合同定义材料 目标合同定义;
    目标宿主当前特征事实材料 目标宿主当前事实;
    std::uint64_t 事实截止代次 = 0;
};

struct 需求目标当前事实结果 final {
    需求目标当前事实状态 状态 = 需求目标当前事实状态::入口拒绝;
    std::uint32_t 合同版本 = 需求目标当前事实合同版本;
    std::uint32_t 规则版本 = 需求目标当前事实规则版本;
    std::uint64_t 事实截止代次 = 0;
    std::optional<需求目标当前事实材料> 材料;
    bool 成功() const noexcept;
};

class 需求目标事实提供者 final {
public:
    需求目标当前事实结果 读取需求目标当前事实(
        const 需求目标当前事实请求& 请求) const noexcept;
};
```

请求 helper 要求两个版本为当前值、`G0` 非零且五个强类型身份非零。成功谓词只接受：状态为已形成、两个回显版本为当前值、结果与材料截止为同一非零 `G0`、optional 有值、两个子材料各自完整且截止为同一 `G0`。所有非成功结果的材料必须为空。

`需求目标当前事实材料`不复制当前值或成员关系。当前值继续由 `目标宿主当前事实.目标特征实例.当前值`唯一承载；目标 I64、允许关系位和比较注册继续由 `目标合同定义.目标状态合同`及其注册材料唯一承载。

## 5. 固定控制顺序与互证

```text
纯值校验父合同版本、父规则版本、G0和五个身份
-> 构造当前 L4-01 子合同请求
-> 恰一次调用 读取目标状态合同与值域定义
-> 非成功精确映射并立即返回空材料
-> 互证子结果成功、版本、G0、目标合同、特征定义、注册、I64目标判断合同和当前生命周期
-> 以子材料正式回显的特征定义构造当前 L4-02 子合同请求
-> 恰一次调用 读取目标宿主同截止当前特征事实
-> 非成功精确映射并立即返回空材料
-> 互证子结果成功、版本、G0、树、场景、宿主、定义、实例、当前值和当前生命周期
-> 互证两叶目标特征定义相同且当前值载荷为I64
-> 一次性构造完整候选材料
-> 无抛出值式返回已形成
```

两个子调用的请求截止都直接使用父请求 `G0`。不得用第一叶回显截止重选快照，不得零截止读取最新，不得在第二叶失败后重做第一叶，不得缓存任一子结果。

当前值的 `类型化不可变材料` 不是 I64 时返回 `当前值类型不兼容`。这是 4160 要求的具名“类型不可比较”材料结果，不是差距裁决；本函数仍不调用 `比较特征`。当前值缺失由第二叶的 `目标特征当前值未设置` 独立表达，不能与类型不兼容合并。

## 7. 并发、异常与诊断责任

- 每次调用只使用局部值式请求、结果和候选，不加锁、不 sleep、不等待、不重试、不保存缓存。
- 两个子函数均为 `const noexcept`；父函数仍防御值式复制和容器复制异常。`std::bad_alloc`、`std::length_error`映射资源失败，其它异常映射内部不一致。
- 并发发布导致任一子叶无法在 `G0` 读取时整次返回当前性漂移；不得以新截止补读另一半。
- `读取需求目标当前事实`的诊断责任为“向上送出”：全部协议内非成功结构化返回，不在本叶记录日志。
- 请求 helper 与 `需求目标当前事实结果::成功()`为“无适用错误分支”的纯值判断。
