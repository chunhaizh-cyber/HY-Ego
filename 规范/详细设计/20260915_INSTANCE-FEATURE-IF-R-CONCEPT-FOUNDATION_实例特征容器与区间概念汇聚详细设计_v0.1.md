# 实例特征容器与区间概念汇聚详细设计 v0.1

基线：`b48e3826e8288cf31041c037611d895b1481658f`。状态：为 `INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION` 提供施工合同。

## 闭环

```text
输入(E,C,P,FT,准确值,G0)
-> 概念类查询 FT 适用 FC；无匹配则按 FT 域规则建立 FCv
-> 定位建立/复用 F，并取得 F->FCv
-> 存在类读取 E+FT 当前采用 F，建立/读取 IF(E,FT)
-> 按4115更新 R集合版本
-> R变化后仅同步尝试一次概念汇聚；无归并规则零写，有规则建立/复用 FCr 并组织 FCv 上位
-> 同截止读回 IF/R/F/FC；采用仍由存在类独立决定
```

F 不无 FC 创建；概念失败在 F 创建前返回。R 汇聚失败不回滚 R、不保存待收敛身份且不自动重试；R 不变零概念写入。

## 代码合同和位置

扩展 `海中鱼巣/领域/数据服务.存在类.h`，由既有存在 owner 唯一承担 IF/R 的 DTO、关系类型、读写、版本与同截止读回；不得新建实例特征服务或第二写端口。新增公开值式类型为 `实例特征容器身份`、`实例特征R集合身份`、`实例特征R集合版本`、`实例特征R项`、`实例特征读取请求/结果`、`实例特征加入请求/结果` 和 `按存在持有特征变更请求/结果`。前者只维护 IF/R；后者是阶段21唯一消费的组合入口，使用既有当前采用写语义返回实际 F，而不是让 IF/R 改写当前采用的含义。

存在 owner 新增静态`登记实例特征结构`：以固定初始化幂等身份建立并由首次材料读回六个普通关系类型节点，返回值式`实例特征结构交付{版本=1,E到IF,IF到F,IF到R集合,R集合到版本,版本到R项,R项到F}`；精确重放只读回同一交付，异义键、少/多项、重号、退出或跨L1返回具名失败。普通应用在移交存在写端口前先登记并读回该交付，再将它作为存在类构造器的独立末参数注入；不得把六类类型塞入`存在当前采用结构交付`，不得预建IF/R实例。

`实例特征加入` 接收 E/C/P/FT/准确值、G0、定位组合/内容/已知/组织键、IF-R写入键和预算；应用先取得 FCv，随后复用定位 F 创建/复用。存在 owner 在同一写集中按需建立IF、R集合、首次/新版本和必要R项，建立完整六关系并退出被替换的当前版本关系；IF、R集合、版本、R项均为普通节点，IF/R项不允许空成员。成功 DTO 回显`IF、R集合、当前版本、R项组、六关系事实、Gread/H、首次H`；同键异义、节点/关系不闭合、预算、引用、漂移和已可能发布分别返回。`按存在持有特征变更` 仅在 F/IF/R 成功后调用既有 `变更当前采用`；它不定义或改变当前采用语义。

不扩展概念树持久结构。扩展 `海中鱼巣/业务/应用服务.特征概念类.h/.cpp` 的同步入口：输入已发布 R集合版本，完整读回IF/R/FT/F/FCv后调用概念树既有 `查找特征概念`、`建立特征概念`、`变更特征概念组织` 查重、创建和组织上位边，不重写 F 名称。该入口不写回执、不保存重试材料；失败只返回`R已发布且本次汇聚失败`。

I64 分组比较为完整值相等；不得调用 `形成I64特征域` 或 `规范化I64特征域`。特征类新增只读`比较FT的R归组`请求/结果：请求为`版本、Gread、H、FT、用途=R归组、当前采用基准F、候选F、读取预算`；结果为`归入当前R、形成新R、比较未启用`或既有具名读取失败。当前实现仅核验FT与两F的固定内容并在没有正式已启用方案时返回`比较未启用`；不登记、模拟或宣称枚举算法。只有后续具名方案提供者才可返回前两项。

## 原子、失败与验证

概念先行与 F 定位仍按既有多 owner 合同；IF/R 写入在存在 owner 内原子。F 创建成功后 IF/R 写前失败不得谎称完整成功；R 发布后汇聚失败返回“R已发布且本次汇聚失败”，不回滚、不回执、不自动重试。按存在持有特征变更仅在 F/IF/R 成功后调用既有采用写；其失败不伪称阶段21可用的实际 F。重放读取首次材料；同键异义冲突；所有成功结果按同一 H 读回。

施工验证：六关系登记首次/精确重放/异义拒绝；I64首次/相同/不同值；当前采用不变；无当前采用；非 I64未启用零写；R未变化零触发；R变化后一次同步汇聚失败不回滚且不自动重试；有/无归并规则；FCr为FCv上位且F直接FCv不变；退出保护；Debug/Release隔离构建。它不证明非 I64算法、跨进程恢复、观察质量或阶段21运行。
