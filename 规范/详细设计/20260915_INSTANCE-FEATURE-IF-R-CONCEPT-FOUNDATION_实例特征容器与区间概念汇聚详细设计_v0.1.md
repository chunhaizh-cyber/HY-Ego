# 实例特征容器与区间概念汇聚详细设计 v0.1

基线：`b48e3826e8288cf31041c037611d895b1481658f`。状态：为 `INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION` 提供施工合同。

## 闭环

```text
输入(E,C,P,FT,准确值,G0)
-> 概念类查询 FT 适用 FC；无匹配则按 FT 域规则建立 FCv
-> 定位建立/复用 F，并取得 F->FCv
-> 特征实例服务读取 E+FT 当前采用 F，建立/读取 IF(E,FT)
-> 按4115更新 R集合版本
-> R变化则概念汇聚；无归并规则零写，有规则建立/复用 FCr 并组织 FCv 上位
-> 同截止读回 IF/R/F/FC；采用仍由存在类独立决定
```

F 不无 FC 创建；概念失败在 F 创建前返回。R 汇聚失败不回滚 R，保存相同版本的待收敛身份；R 不变零概念写入。

## 代码合同和位置

扩展 `海中鱼巣/领域/数据服务.存在类.h`，由既有存在 owner 唯一承担 IF/R 的 DTO、关系类型、读写、版本与同截止读回；不得新建实例特征服务或第二写端口。新增公开值式类型为 `实例特征容器身份`、`实例特征R集合身份`、`实例特征R集合版本`、`实例特征R项`、`实例特征读取请求/结果`、`实例特征加入请求/结果` 和 `按存在持有特征变更请求/结果`。前者只维护 IF/R；后者是阶段21唯一消费的组合入口，使用既有当前采用写语义返回实际 F，而不是让 IF/R 改写当前采用的含义。

存在类初始化时固定并校验六类关系类型：`E→IF`、`IF→F成员`、`IF→R集合`、`R集合→版本`、`版本→R项`、`R项→F成员`。`实例特征加入` 接收 E/C/P/FT/准确值、G0、组合/内容/已知/组织/IF-R 幂等身份和预算；应用先取得 FCv，随后复用定位 F 创建/复用，再由存在 owner 在同一截止维护 IF/R。`按存在持有特征变更` 仅在 F/IF/R 成功后调用既有 `变更当前采用`；它不定义或改变当前采用语义。

扩展 `海中鱼巣/领域/数据服务.概念树类.h/.cpp`，由概念 owner 保存 `(R集合身份, R集合版本)` 到已完成汇聚的不可变回执，并提供读回/首次登记；扩展 `海中鱼巣/业务/应用服务.特征概念类.h/.cpp`，只接收已发布 R集合版本及其幂等身份，读回 IF/R/FT 后调用概念树既有 `查找特征概念`、`建立特征概念`、`变更特征概念组织` 查重、创建和组织上位边，不重写 F 名称。

I64 分组比较为完整值相等；不得调用 `形成I64特征域` 或 `规范化I64特征域`。非 I64 通过新增只读 `FT枚举R归组比较` 提供者返回“归当前R/新R/未启用”；本计划仅冻结接口和 I64 实现，未启用非 I64 零写，不伪造阈值算法。

## 原子、失败与验证

概念先行与 F 定位仍按既有多 owner 合同；IF/R 写入在存在 owner 内原子。F 创建成功后 IF/R 写前失败不得谎称完整成功；R 发布后汇聚失败返回“R已发布待汇聚”。按存在持有特征变更仅在 F/IF/R 成功后调用既有采用写；其失败不伪称阶段21可用的实际 F。重放读取首次材料；同键异义冲突；所有成功结果按同一 H 读回。

施工验证：I64首次/相同/不同值；当前采用不变；无当前采用；非 I64未启用；R未变化零触发；R变化一次触发与重试；有/无归并规则；FCr为FCv上位且F直接FCv不变；退出保护；Debug/Release隔离构建。它不证明非 I64算法、跨进程恢复、观察质量或阶段21运行。
