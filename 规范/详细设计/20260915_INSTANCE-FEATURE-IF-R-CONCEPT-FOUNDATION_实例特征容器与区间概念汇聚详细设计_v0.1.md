# 实例特征容器与区间概念汇聚详细设计 v1.1

状态：可执行。重新 S0 基线：`b3fef3ef` 已发布并是当前 `main` 的祖先。I64 单点 R 的归并成功固定为 `已归并零输出` 与空项。

## 目标闭环

```text
输入(E,C,P,FT,候选准确值,G0)
-> L3 以同一 Gread/H 读取完整 IF/R
-> 首个 R / 唯一命中 / 形成新 R / 结构异常 / 原具名读取失败
   -> 形成新 R 时才调用既有四 owner I64 出生，取得已发布 FCv 与完整 F
   -> 存在 owner 一次提交中性 IF/R 目标并同截止读回
   -> R 真实变化后仅调用一次特征类归并
      -> I64 已归并零输出：汇聚完成、零概念写
      -> 非 I64 未启用或其它失败：保留已发布 R，映射汇聚未完成
```

`ea195241` 的四 owner 提供者是唯一合法 F 出生路径；不得退回三 owner 定位事务，也不得先创建无 FC 的 F。`3b474a66` 提供 R 材料归组，`b3fef3ef` 提供 I64 零输出归并。当前采用不进入任何 IF/R 读取、归组或 L2 写集。

## L2 公开合同

`海中鱼巣/领域/数据服务.存在类.h` 新增下列纯值类型：

- `实例特征节点时态 { 身份, 创建H, optional<退出H> }`；
- `实例特征关系时态 { 身份, 来源, 目标, 类型, 创建H, optional<退出H> }`；
- `实例特征R项身份 { R项节点, 材料属性槽 }`；
- `实例特征R项投影 { 身份, 材料, 形成成员, 节点时态, 材料属性时态, 成员关系组 }`；
- `实例特征IFR投影 { E, FT, IF, R集合, 当前版本, 成员F组, R项组, 节点组, 关系组 }`；
- `实例特征IFR读取请求/结果` 与 `实例特征IFR提交请求/结果`。

`实例特征结构交付_v2` 在既有六关系类型之外新增 `R项材料属性类型`。它是唯一属性类型节点，不是第七条关系；L1 值固定编码为 `U64组 {材料格式版本, 材料类别, 规范化载荷...}`。读取先反序列化为 `特征R区间材料`，再做规范化、相等或规则调用。

`读取IFR结构(const 实例特征IFR读取请求&) const noexcept` 的请求固定为 `{版本=1,Gread,E,FT,F成员上限,R项上限,关系上限}`。成功仅为 `已读取`，且 `Gread=H=请求Gread`、投影完整、三项预算未超。未找到、已退出、数量预算不足、事实代次漂移、引用冲突、资源失败或内部不一致都清空投影。

`提交IFR目标结构(const 实例特征IFR提交请求&) noexcept` 的请求固定为 `{版本=1,G0,E,FT,optional<预期完整投影>,规范化目标R项组,幂等身份,F成员上限,R项上限,关系上限}`。每个目标项是 `{特征R区间材料, vector<特征信息身份>形成成员}`；目标项按最小形成 F 编码升序，成员非空、严格升序，跨项全局不重复。首次只接受空预期且不存在 `E→IF`；后续预期必须逐字段等于 G0 当前投影。目标成员并集必须恰等 IF 成员 F，新增 F 必须在 G0 是 E 已知的同 FT 准确 F。

成功状态仅为 `已提交`、`精确重复`、`目标已满足`。目标已满足不写 L1 且没有首次 H；三种成功都逐字段回显原请求与完整当前投影。目标不同才由存在 owner 单次写集发布：先 IF/R 集合/新版本/R 项节点，再六类关系，再材料值和属性槽；材料与形成 F 都相同的旧 R 项复用，其余新建。仅退出旧 `R集合→版本` 关系，旧版本、R 项及其成员保留历史。提交后逐项读回当前投影和退出关系；发布未知只以原幂等键读回收束，禁止回滚、换键或假称零写。

L2 不判断首个 R、命中、形成新 R、结构异常或当前采用；预期快照不成立时返回具名漂移或引用冲突并零本次写。

## L3 公开合同与诊断

`特征概念应用服务` 构造器新增 `存在类数据服务&` 和私有可调用 `noexcept` 诊断适配。新增入口 `处理存在特征R` 请求固定为 `{版本=1,G0,E,定位特征位置(C/P),FT,候选准确值,FCv概念键,F出生键,IFR结构键,L2读写预算,R规则预算,既有I64出生预算}`；当前采用、FCr 键和 FCr 预算不进入请求。

结果必须保留原请求、L2 读写结果、规则结果、可选 F 出生与汇聚失败原因，状态固定区分：`已发布且汇聚完成`、`已发布且汇聚未完成`、`R未变化`、`读取IFR失败`、`结构异常`、`归组失败`、`FCv/F出生失败`、`提交IFR失败`、`入口拒绝`。前两项均表示 R 已发布；后者绝不表示汇聚成功，也不回滚或自动重试。

读取完整 IF/R 后：空结构代表首个 R；完整结构交给 FT R 归组；半结构、空 R 项、缺材料、重复或多个命中为结构异常，零 FCv/F/IFR/汇聚写。形成新 R 才调用既有 I64 出生，唯一命中零 F 写；两条路径都只向 L2 提交规范化目标。实际目标与前态不同才调用一次 `归并特征R概念`。I64 `已归并零输出` 映射 `已发布且汇聚完成`，不调用概念 owner、不读取 FCv、不消费 FCr 键。当前非 I64 未启用和所有归并非成功都映射 `已发布且汇聚未完成`，保留 R。

普通应用的私有诊断适配仅在 L3 mutex 与普通应用上下文锁释放后调用一次。它使用既有 `记录逻辑错误日志` 和同因 `MessageBoxW`，捕获全部异常并忽略失败；它不是机器事实、UI 调度或恢复机制。

允许修改 `数据服务.存在类.h`、`应用服务.特征概念类.h/.cpp`、`装配.普通应用.cpp` 与专属施工/验证记录。不得修改四 owner 出生、L1 ABI、特征规则持久结构、概念 tree owner、当前采用、线程、启动或阶段21。非 I64 FCr 语义必须由独立计划冻结。

验证需覆盖：v2 结构登记和构造校验、首个/后续/精确重复/目标已满足、三项预算、预期快照、异常零写、发布未知读回、诊断锁释放与失败隔离、I64 R 未变零触发、R 变化后一次零输出汇聚、装配不调用业务。Debug/Release 隔离构建与专属驱动是最低证据；跨进程恢复、非 I64 比较、无窗口诊断可见性和阶段21明确为 `NOT_RUN`，除非实际补测。
