# 实例特征容器与区间材料详细设计 v0.9

基线：`41d7fe0495db2fa648b50f4bf81b127f4d2fd66c`。状态：可执行；执行前重新 S0。只落实 4115 v0.9 的 IF/R 和 R 归组；不调用 R→FCr，也不创建概念上下位。

## 1. 所有权与现有能力

存在 owner 在 `海中鱼巣/领域/数据服务.存在类.h` 唯一读写 IF/R；特征类只复用已发布的 `归组特征R`、`读取特征R代表值`，**特征类 `.h/.cpp` 零修改**。L3 `特征概念应用服务` 只作分类和调用；普通应用负责构造注入。存在类扩展既有六关系类型交付为 v2：另交付一个 `U64组` 的R项材料属性类型；L1、特征值类和概念树不改动。

## 2. 存在类 ABI

在 `数据服务.存在类.h` 新增下列公开值式 DTO；所有身份均为稳定节点身份，生命周期以既有 `L1所有者范围节点事实` / `L1所有者范围关系事实` 原样投影，禁止另造平行历史字段：

```cpp
struct 实例特征R项身份 { 稳定编码 编码{}; };
struct 实例特征IFR读取预算 { std::uint64_t 最大F成员数, 最大R项数, 最大关系数, 最大材料值数, 最大单材料U64元素数; };
struct 实例特征R项投影 {
    实例特征R项身份 R项;
    特征R区间材料 材料;
    std::vector<特征信息身份> 形成成员; // 严格按 F 编码升序
    L1所有者范围节点事实 节点事实;
    std::vector<L1所有者范围关系事实> 成员关系;
    L1所有者范围值事实 材料值事实;
};
struct 实例特征IFR完整投影 {
    存在信息身份 E; 特征类型身份 FT;
    实例特征容器身份 IF; 实例特征R集合身份 R集合;
    实例特征R集合版本 版本;
    std::vector<特征信息身份> F成员;
    std::vector<实例特征R项投影> R项;
    实例特征结构交付 结构;
    std::vector<L1所有者范围节点事实> 节点事实;
    std::vector<L1所有者范围关系事实> 六关系事实;
};
struct 读取实例特征IFR请求 { std::uint32_t 版本=1; 存在信息身份 E; 特征类型身份 FT; std::uint64_t Gread=0; 实例特征IFR读取预算 预算; };
struct 实例特征IFR目标项 { 特征R区间材料 材料; std::vector<特征信息身份> 形成成员; };
struct 提交实例特征IFR目标请求 {
    std::uint32_t 版本=1; 存在信息身份 E; 特征类型身份 FT; std::uint64_t G0=0;
    std::optional<实例特征IFR完整投影> 预期快照; // nullopt 仅代表 IF/R 均未找到
    std::vector<实例特征IFR目标项> 目标R项;
    L1所有者范围写入幂等身份 幂等身份; 实例特征IFR读取预算 读回预算;
};
enum class 实例特征IFR状态 : std::uint8_t { 已读取, 已发布, 无须变更, 精确重复, 入口拒绝, 未找到, 已退出, 数量预算不足, 事实代次漂移, 引用冲突, 幂等冲突, 资源失败, 已可能发布, 内部不一致 };
struct 实例特征IFR结果 { std::uint32_t 版本=1; 实例特征IFR状态 状态; std::uint64_t Gread=0,H=0; std::optional<std::uint64_t> 首次H; std::optional<实例特征IFR完整投影> 投影; std::optional<提交实例特征IFR目标请求> 原请求; };
```

公开签名固定为：

```cpp
实例特征IFR结果 读取实例特征IFR(const 读取实例特征IFR请求&) const noexcept;
实例特征IFR结果 提交实例特征IFR目标结构(const 提交实例特征IFR目标请求&) noexcept;
```

读取只接受非零 E/FT/Gread 与五项非零预算；返回完整投影或具名失败。R项、形成成员稳定排序；任一预算不足不截断。每项先用R项作为来源读取当前值组，再仅接受所属/来源均为该R项、属性类型等于`结构.R项材料属性类型`、写入所有者等于存在owner、材料为非空U64组且恰一条的值事实。其U64组按`[格式版本,材料类别,载荷项数,载荷...]`解码，要求载荷长度精确相等且版本、类别受支持；其它形态均不得形成投影。提交核验 G0、完整预期快照、目标项非空及其最小 F 升序、成员严格升序且全局不重；首次快照仅在 IF/R 均未找到时合法。新增 F 必须是 G0 时 E 已知同 FT 的 F。相同目标返回 `无须变更` 和既有完整投影；不同目标在一个存在 owner 写集中发布新版本、为每个目标项新建R项及其材料值事实，并退出旧当前版本关系。写前快照冲突零写；发布未知只保留原请求，禁止回滚。幂等比较只比较实际决定规范化写集的 `E、FT、G0、预期快照与目标R项组`；`读回预算`不持久化且不参与比较。重放以本次预算重新读回，预算不足独立返回，不得误报幂等冲突。

`实例特征结构交付` 升为版本 2，固定新增字段 `R项材料属性类型`。登记请求也升为版本 2，固定使用新幂等身份 `0x4946525354525632ULL`（`IFRSTRV2`）：没有 v1 初始化材料时，v2 写集建立六个普通关系类型节点和一个 `节点种类::属性类型 / U64组` 节点；已存在 v1 初始化材料时，先完整读回并核验 v1 六个普通关系类型节点，再以 v2 写集仅建立该属性类型节点，最终交付复用的六项和新第七项。v2 精确重放必须复用同一条既有写集；任何 v1/v2 交付不一致、节点种类/表示错误、退出或跨L1/owner均为具名非成功。普通应用改用v2请求；构造器只接受v2交付。

材料编码、解码和材料值事实的建立/读回只在存在类私有实现；L3不得接触L1原始材料。材料值事实是R项的不可变结构组成，不设置属性槽，不建立2100值身份，也不调用特征值类。R项只由一个`版本→R项`关系引用；一旦目标组不同，新版本中的所有R项、形成成员关系和材料值事实都新建，旧版本及其R项/材料保持可历史读回。

## 3. L3 ABI 与流程

在 `应用服务.特征概念类.h/.cpp` 新增：

```cpp
enum class 实例特征结构异常 : std::uint8_t { 半结构, 空R项, 缺材料, 重复R项, 多重命中 };
using 实例特征结构诊断 = void(*)(存在信息身份,特征类型身份,实例特征结构异常,std::uint64_t,std::uint64_t) noexcept;
struct 实例特征R观察请求 {
  std::uint32_t 版本=1; 存在信息身份 E; 定位特征位置 位置; 特征类型身份 FT; 特征准确值 候选值;
  std::uint64_t G0=0; L1所有者范围写入幂等身份 IFR键;
  原子I64特征出生键 F出生键; L1所有者范围写入幂等身份 FCv概念键;
  实例特征IFR读取预算 IFR预算; 原子I64特征候选读取预算 候选预算;
  原子I64特征组织读取预算 组织预算; 原子I64特征概念读取预算 概念读取预算; 概念树预算 概念预算;
};
enum class 实例特征R观察状态 : std::uint8_t { 已发布IFR, IFR未变更, 读取失败, 结构异常, 比较未启用, 归组失败, F出生失败, IFR写入失败, 入口拒绝 };
struct 实例特征R观察结果 { std::uint32_t 版本=1; 实例特征R观察状态 状态; std::uint64_t Gread=0; std::optional<实例特征IFR结果> IFR; std::optional<I64原子准确特征出生应用结果> F出生; };
```

构造器变为 `特征概念应用服务(特征类数据服务&,概念树类数据服务&,原子I64特征出生数据服务&,存在类数据服务&,实例特征结构诊断) noexcept`。先读 IF/R；读取未找到即首次，完整即调用 `归组特征R`。唯一命中只改材料目标；形成新R才调用既有 I64 原子出生并把其 F 作为新目标成员。非 I64 直接 `比较未启用` 零写。L3 在固定结果、释放自身锁和普通应用上下文锁后，仅对结构异常调用一次诊断；诊断失败不改变结果。任何 R 变化后结束，不调用归并。

## 4. 装配和消费者

`装配.普通应用.cpp` 保持既有六关系登记和存在类构造顺序；在构造特征概念应用服务时增加 `*result->存在` 和私有诊断函数。诊断顺序固定为尽力 `记录逻辑错误日志` 后 `MessageBoxW`，捕获全部异常。`场景成员概念应用服务` 不构造该服务、不新增入口，只保留既有引用，零迁移。工程登记不变。

## 5. 验证和边界

用户取消构建、运行和专项验证；施工只做 `git diff --check`、`git diff --cached --check`。不证明编译、运行、恢复、非 I64、诊断可见性或阶段21。
