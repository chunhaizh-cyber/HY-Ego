# 实例特征容器与区间概念汇聚详细设计 v0.3

基线：`9f6375c3b899819d0d41cfcac400a8d11cf07292`。状态：待激活；为 `INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION` 保留已裁决的后继施工合同，不构成四 owner 特征出生提供者的设计或实现许可。

## 已确定闭环与上游停点

```text
输入(E,C,P,FT,准确值,G0)
-> L3 同截止读取 E+FT 当前采用与 IF/R
-> 首次 / 后续 / 结构异常分类
   -> 结构异常：固定结果、零业务写、释放锁后尽力诊断
   -> 首次或后续：等待已发布的四 owner 原子特征出生提供者
      -> FCv 已发布 + F内容/位置/已知引用/F→FCv同次发布并读回
      -> L2存在 owner 中性IF/R一次写集与同截止读回
      -> 实际R变化后一次R→FCr汇聚
```

四 owner 提供者是唯一上游门禁。当前定位特征服务的三 owner 原子事务不能承担 F→FCv 概念使用引用；概念 owner 的既有名称/用途入口又以已发布 F 为输入。不得把 FCv 塞入三 owner 定位请求后由定位服务越权写概念关系，也不得顺序创建无 FC F 后补写。本详细设计不改变1130、4110、4115、7150或7160；上游合同必须由独立计划冻结。

## L3 分类、L2中性操作与诊断

新显式入口位于 `海中鱼巣/业务/应用服务.特征概念类.h/.cpp`，不得改变旧 `处理类型观察` 或 `收敛类型观察` 的语义。入口先取得同一 `Gread/H`，然后读取当前采用和完整 IF/R：

| 读回结果 | L3结论 | 写入 |
| --- | --- | --- |
| 当前采用为空，且 IF/R 均未找到 | 首次 | 仅在上游完整 F 成功后继续。 |
| IF/R完整，且当前采用F属于IF成员及当前R成员 | 后续 | 仅在上游完整 F 成功后继续。 |
| 两次读取成功但不属上述两类 | 结构异常 | 零 FCv、F、IF/R、采用及汇聚写。 |
| 任一读取失败、漂移、预算不足、退出或结构不完整 | 原具名非成功 | 零业务写；不伪装成结构异常。 |

`海中鱼巣/领域/数据服务.存在类.h` 的 IF/R 接口只接收已经形成的中性目标结构及预期快照，负责读回、一次写集、六关系、引用与形状核验。它不得根据当前采用或缺失 IF/R 解释首次、后续或结构异常；预期快照不再成立时返回漂移或引用冲突，零本次写。当前采用仍由既有存在 owner 入口独立变更，IF/R不得隐式改写它。

普通应用在 `海中鱼巣/装配.普通应用.cpp` 私有构造一个 `noexcept` 诊断适配并注入特征概念应用服务。适配只记录模块、入口、结构异常分类、E/FT及已持有的截止摘要；不为日志新增读取或写入。L3先固定返回结果、退出自身 mutex；普通应用调用入口也必须退出 `上下文锁`，之后才调用适配。适配依次尽力调用 `记录逻辑错误日志` 与同因 `MessageBoxW(nullptr,...)`，捕获全部 C++ 异常并忽略日志返回值和弹窗失败。它不是UI线程调度器、机器结果或恢复材料；无窗口/非交互环境可能看不到弹窗。

## 后续代码位置与禁止项

四 owner 出生提供者不属于本计划，故其 L1、定位特征或概念 owner 文件没有本计划写权。上游发布后，本计划才可扩展存在、特征、特征概念应用和普通应用装配的既有文件：装配在存在类构造前登记/读回六关系类型并末参数注入 `实例特征结构交付`，随后构造定位服务和特征概念应用服务；装配不调用新入口、预建IF/R、启动线程或进入阶段21。

R的 I64 分组仍只按完整准确值相等；非I64仅调用只读 `FT+R归组用途比较`，未启用时零 IF/R 写。R真实变化才进行一次上位 FCr 汇聚；汇聚失败保留R，不回滚、不回执、不自动重试。按存在持有特征变更只在 F/IF/R 成功后独立调用既有当前采用操作；其失败不声称获得阶段21可用实际F。
