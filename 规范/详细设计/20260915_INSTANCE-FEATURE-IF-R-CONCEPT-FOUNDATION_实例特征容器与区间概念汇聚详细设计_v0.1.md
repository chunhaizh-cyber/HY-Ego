基线：`bdb66d35f04cf60c8065fbe021bbc4a4ac10e653`。状态：待激活；直接上游结果：`78fcfeebe`。它已满足上游门禁，但存在类 IF/R 读取/目标写入 ABI、L3 入口/诊断注入及概念 owner 的 FCr 消费接口尚未冻结，必须由计划支撑修订后重新 S0。为 `INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION` 保留已裁决的后继施工合同。I64 四 owner 特征出生提供者已发布；本详细设计不构成 `R→FCr` 归并规则物理提供者的设计或实现许可。

## 已确定闭环与上游停点

```text
输入(E,C,P,FT,候选值,G0)
-> L3 同截止读取 IF/R
-> 首次 / 后续 / 结构异常分类
   -> 结构异常：固定结果、零业务写、释放锁后尽力诊断
   -> 对全部 R区间材料调用 FT 归组规则
      -> 唯一命中：零F写入，更新R项区间材料快照
      -> 未命中：调用已发布的四 owner 原子特征出生提供者
         -> FCv 已发布 + F内容/位置/已知引用/F→FCv同次发布并读回
         -> 以新F建立兄弟R项
      -> L2存在 owner 中性IF/R一次写集与同截止读回
      -> 实际R变化后，等待归并规则物理合同后的一次R→FCr汇聚
```

`ea195241` 的四 owner 提供者已满足 F→FCv 同次发布和读回，不得退回旧三 owner 定位事务，也不得顺序创建无 FC F 后补写。4115 已明确当前采用不参与R归组；漂移内候选不形成F，而按FT规则更新R区间材料快照。两类规则都逻辑并物理归正式特征类型定义 owner。既有 `FEATURE-TYPE-R-INTERVAL-RULE-PROVIDER` 已冻结持久表示、归组和代表 ABI，但其单 R项归并形态不能满足4115 §4；直接上游 `FEATURE-TYPE-R-VERSION-FCR-MERGE-PROVIDER` 必须先发布完整 R集合版本到完整 FCr 定义组的 ABI。该上游只启用已有 I64 FT；非I64无规则时返回未启用或归并零输出且零 IF/R 写。概念 owner 只消费完整版本归并输出创建/复用概念和直接上位边；需要新增非I64概念定义或规则时必须另立计划冻结。本详细设计不改变1130、4110、4115、7150或7160。

## L3 分类、L2中性操作与诊断

新显式入口位于 `海中鱼巣/业务/应用服务.特征概念类.h/.cpp`，不得改变旧 `处理类型观察` 或 `收敛类型观察` 的语义。入口先取得同一 `Gread/H`，然后只读取完整 IF/R；当前采用既不读取也不参与R归组：

| 读回结果 | L3结论 | 写入 |
| --- | --- | --- |
| IF/R 均未找到 | 首个R | 建立 F，再建立以该F为形成成员的首个 R项。 |
| IF/R完整 | 归组 | 调用FT规则；唯一命中则只更新R区间材料快照，形成新R才建立F。 |
| 读取成功但出现半结构、空R项、缺区间材料或多命中 | 结构异常 | 零 FCv、F、IF/R、采用及汇聚写。 |
| 读取失败、漂移、预算不足或退出 | 原具名非成功 | 零业务写；不伪装成结构异常。 |

`海中鱼巣/领域/数据服务.存在类.h` 的 IF/R 接口只接收已经形成的中性目标结构及预期快照，负责读回、一次写集、六关系、区间材料、引用与形状核验。它不得根据当前采用、候选值或缺失 IF/R 解释首个R、归组、形成新R或结构异常；预期快照不再成立时返回漂移或引用冲突，零本次写。当前采用仍由既有存在 owner 入口独立变更，IF/R不得隐式改写它。

普通应用在 `海中鱼巣/装配.普通应用.cpp` 私有构造一个 `noexcept` 诊断适配并注入特征概念应用服务。适配只记录模块、入口、结构异常分类、E/FT及已持有的截止摘要；不为日志新增读取或写入。L3先固定返回结果、退出自身 mutex；普通应用调用入口也必须退出 `上下文锁`，之后才调用适配。适配依次尽力调用 `记录逻辑错误日志` 与同因 `MessageBoxW(nullptr,...)`，捕获全部 C++ 异常并忽略日志返回值和弹窗失败。它不是UI线程调度器、机器结果或恢复材料；无窗口/非交互环境可能看不到弹窗。

## 后续代码位置与禁止项

既有四 owner 出生提供者不属于本计划，故其 L1、定位特征或概念 owner 文件没有本计划写权。`FEATURE-TYPE-R-VERSION-FCR-MERGE-PROVIDER` 发布后，本计划才可扩展存在、特征、特征概念应用和普通应用装配的既有文件：装配在存在类构造前登记/读回六关系类型并末参数注入 `实例特征结构交付`，随后构造定位服务和特征概念应用服务；装配不调用新入口、预建IF/R、启动线程或进入阶段21。

R的 I64 分组仍只按完整准确值相等；非I64只调用FT的“候选值对R区间材料组”归组、区间更新和代表值规则，未启用时零 IF/R 写。R真实变化才进行一次上位 FCr 汇聚；汇聚失败保留R，不回滚、不回执、不自动重试。按存在持有特征变更只在 F/IF/R 成功后独立调用既有当前采用操作；其失败不声称获得阶段21可用实际F。
