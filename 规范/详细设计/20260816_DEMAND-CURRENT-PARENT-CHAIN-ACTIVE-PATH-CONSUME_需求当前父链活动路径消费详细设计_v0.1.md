# 需求当前父链活动路径消费详细设计 v0.1

日期：2026-08-16

计划身份：`DEMAND-CURRENT-PARENT-CHAIN-ACTIVE-PATH-CONSUME`

## 1. 目标与完成边界

实现单一父级业务函数：

```text
BIZ-L3-002-04-02 v0.2
需求业务服务::读取需求父链与活动路径事实
-> 逐项调用 BIZ-L4-002-04-02-01 v0.2 形成根到叶当前父链
-> 一次调用 BIZ-L4-002-04-02-02 v0.2 形成与父链同序的逐父当前活动子关系组
```

调用方给出起始需求、运行代次、父级非零共享事实截止 `G0`、范围 / 规则版本、父链深度预算和当前子关系总数量预算。本函数在同一 `需求业务服务` 内只组合两个下层 BIZ 叶：父关系叶逐项形成无重复父链，活动叶一次消费完整根到叶父链。成功返回非空根到叶父链与等长逐父活动组；每个活动组可以为空。

本叶全程只读，不直达 DATA / L1，不改变需求、父关系、活动结论或生命周期，不读取历史、权重值、任务、满足或结算。本叶完成最多证明父链和活动组 BIZ 组合 provider；不证明活动重判、父 L2 治理输入复核、当前任务树、G0/G1、自我治理循环或系统闭环。

## 2. 正式依据与当前事实

候选 S0 基线为 `main@d5227719d8cf5a95eb9187ffd3d280c5225e77db`：

1. 0050 要求当前 / 历史读取分离、组合投影声明同一事实截止并返回调用方拥有的不可变值。
2. 3100、5100、5110 要求父子拓扑只表达展开，当前活动成员必须依据正式当前性、路径角色和活动结论；权重、数量和列表位置均不能代替。
3. BIZ-L4-002-04-02-01 v0.2 已冻结按单需求和 G0 一次读取完整当前需求、可空唯一父关系及同现父端点；无父合法成功。
4. BIZ-L4-002-04-02-02 v0.2 已冻结按完整根到叶父链和 G0 一次读取全部当前直接子关系及活动材料，由 BIZ 只按强类型活动结论选择；逐父空组合法成功。
5. 两个下层计划均登记待激活，`服务.需求.ixx`和对应合同头尚未实现；DATA-EXT-12 精确 ABI 也尚未发布。
6. 父图 v0.1 仍使用含糊“截止版本”、历史隔离状态和单一活动子链，没有冻结请求 / 结果 DTO、深度与数量预算、初始需求缺失和后继父缺失分账，也没有异常和发布边界。

## 3. 组合不变量

### 3.1 同一截止与版本

请求的运行代次、事实范围版本、需求范围版本、需求树规则版本和读取规则版本必须同时匹配父关系与活动子关系固定配置；父关系规则版本只传给父关系叶，路径 / 活动规则版本和当前子关系总数量预算只传给活动叶。两个叶使用完全相同的非零 G0。

父函数不把运行代次传给 DATA；它只传给两个 BIZ 叶作固定配置匹配。两个叶各自按已冻结合同决定其 DATA 请求字段。相同 G0 数值但不同 `需求业务服务`或不同 L1 运行包不是同一快照。

### 3.2 父链形成

从起始需求开始，父关系叶每次返回完整当前需求和可空唯一父关系：

```text
首次需求未找到 / 已退出 -> 父函数同名逻辑内状态
首次需求无父 -> 单项根到叶父链
有父 -> 父关系子端必须等于当前需求，父端成为下一次读取身份
由前项同 G0 父端材料得到的后继父未找到 / 已退出 -> 内部不一致
先检查身份重复；命中 -> 发现环
仅身份未重复时检查深度预算；尚有父但深度预算已满 -> 深度预算不足
```

父链候选先按叶到根建立，只有到达合法无父根后才反转为根到叶顺序。任何失败均丢弃完整候选，不返回截断父链。

### 3.3 活动组组合

根到叶父链完整形成后，父函数恰一次调用活动子关系叶。成功必须满足：

```text
逐父活动组数量 = 根到叶父链数量
逐父活动组顺序和父身份 = 根到叶父链
每组父端点与对应父链项当前需求的身份、身份来源、主体和生命周期共享字段一致
全部父端点需求树版本非零且唯一；父链中的每条当前父关系使用同一需求树版本
全部结果版本、G0和总预算回显一致
每个父活动组可以为空，父链本身不得为空
```

活动叶已经负责读取全部当前直接子关系、互证完整材料并只按已发布强类型活动结论选择；父函数不得重新筛选、补活动或改变排序。活动叶任一非成功整体映射，父函数不返回父链前缀。

## 4. BIZ 类型与物理位置

### 4.1 值式合同头

新增：

```text
文件：海中鱼巣/领域/需求父链活动路径.数据.h
所有者：BIZ 需求父链与活动路径组合值式合同
可见性：需求业务服务及其合法父级组合器和专属验证
```

冻结语义类型：

```cpp
inline constexpr std::uint32_t 需求父链活动路径合同版本 = 1;

struct 需求父链活动路径读取请求 final {
    std::uint32_t 合同版本;
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 需求范围版本;
    std::uint64_t 需求树规则版本;
    std::uint64_t 父关系规则版本;
    std::uint64_t 路径规则版本;
    std::uint64_t 活动规则版本;
    std::uint64_t 读取规则版本;
    L2需求身份 起始需求;
    std::uint64_t 共享事实截止;
    std::uint64_t 最大父链深度;
    std::uint64_t 最大当前子关系总数量;
};

struct 需求父链项值式事实 final {
    当前需求值式事实 当前需求;
    std::optional<当前父需求关系值式事实> 当前父关系;
};

struct 需求父链活动路径值式结果 final {
    std::uint64_t 需求树版本;
    std::vector<需求父链项值式事实> 根到叶父链;
    std::vector<当前父需求活动子关系组> 逐父活动子关系组;
};

enum class 需求父链活动路径读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    未找到 = 3,
    已退出 = 4,
    深度预算不足 = 5,
    数量预算不足 = 6,
    发现环 = 7,
    当前性漂移 = 8,
    提供者拒绝 = 9,
    资源失败 = 10,
    内部不一致 = 11
};

struct 需求父链活动路径读取结果 final {
    std::uint32_t 合同版本;
    需求父链活动路径读取状态 状态;
    需求父链活动路径读取请求 请求回显;
    std::uint64_t 事实截止;
    std::optional<需求父链活动路径值式结果> 值;
};
```

`当前需求值式事实`与`当前父需求关系值式事实`复用父关系叶合同头；`当前父需求活动子关系组`复用活动叶合同头。不得复制 DATA DTO、父端点 DTO或活动结论解释。只有 `已读取`携带 optional 值；成功值的父链非空且两个 vector 等长，非成功的 optional 为空且事实截止为零。

### 4.2 需求业务服务

继续扩展同一文件 / 模块：

```cpp
需求父链活动路径读取结果 读取需求父链与活动路径事实(
    const 需求父链活动路径读取请求& 请求) const noexcept;
```

函数只调用本服务已有的 `读取需求当前父关系与生命周期(...)`和`读取父链各节点当前活动子关系(...)`。不保存新 DATA 引用、不建立第二服务 / owner / 缓存，也不改变三个既有固定配置。模块私有 helper 只允许负责请求构造、状态映射、父链反转和逐字段互证，不得取得 DATA 或 L1。

## 5. 固定执行顺序

```text
校验服务固定配置共同字段与规则闭合，否则内部不一致
-> 校验请求、起始需求、G0及两个非零预算，否则请求拒绝
-> 匹配全部固定配置版本，否则当前性漂移
-> 当前需求=起始需求，建立叶到根候选和已访问身份集
-> 先复核重复身份，命中即发现环；仅未重复时再复核深度预算
-> 调用父关系叶读取当前需求
-> 首次未找到 / 已退出直接映射；后继父未找到 / 已退出映射内部不一致
-> 互证回显、G0、当前需求和可空父关系形状
-> 追加完整父链项；无父则反转，有父则互证端点并继续
-> 恰一次调用活动子关系叶读取完整根到叶父链
-> 映射非成功；成功时互证逐父一一对应、父端点共享字段、唯一需求树版本、G0和预算
-> 完整候选形成后无抛出交换
-> 返回已读取
```

所有 vector / 身份集分配、复制和结果构造位于异常收口内；`std::bad_alloc`、`std::length_error`映射资源失败，未知异常映射内部不一致。成功交换前不发布部分结果。

## 6. 非成功映射

| 情形 | 父函数状态 | 载荷 |
| --- | --- | --- |
| 固定配置坏或下层共同版本矛盾 | 内部不一致 | 空；零下层调用 |
| 请求坏、零身份 / G0 / 预算 | 请求拒绝 | 空；零下层调用 |
| 合法请求与固定配置版本不等 | 当前性漂移 | 空；零下层调用 |
| 首次父关系叶未找到 / 已退出 | 未找到 / 已退出 | 空 |
| 后继父未找到 / 已退出、错端点、半结构或同 G0 材料矛盾 | 内部不一致 | 空 |
| 身份重复（包括与深度预算边界同次命中） | 发现环 | 空；优先于深度预算判断 |
| 身份未重复且尚有父但深度预算耗尽 | 深度预算不足 | 空；不返回截断父链 |
| 活动叶数量预算不足 | 数量预算不足 | 空 |
| 任一下层当前性漂移 / 许可 / 资源失败 | 当前性漂移 / 提供者拒绝 / 资源失败 | 空 |
| 下层请求拒绝、未实现 / 未装配、坏成功形状或未知异常 | 内部不一致 | 空 |

## 8. 验证矩阵与完成声明

专项至少覆盖：

- 坏固定配置、坏请求、零预算和版本不等的零下层调用；
- 单项根、两级 / 多级父链、根到叶顺序、每级同 G0和规则回显；
- 初始未找到 / 已退出与后继父未找到 / 已退出分账；错子端、错父端、跨主体、跨树、跨截止和半结构拒绝；
- 自环、多节点环、恰好深度预算和超深度零截断；自环 / 多节点环恰好撞上深度边界时仍唯一返回发现环；
- 活动叶只调用一次，逐父组与父链等长同序，父端点共享字段一致且全链需求树版本唯一；单父空、全部空、部分空和多活动成员；
- 数量预算不足、下层漂移 / 许可 / 资源 / 内部错误整体零载荷；任一失败不返回父链前缀；
- 源码零 DATA / L1 / owner / 仓库 / 缓存 / 历史 / 权重 / 任务 / 满足 / 结算调用，零活动重判；
- 根工程 Debug / Release、专项双配置、strict、UTF-8 / XML、工程唯一登记和生产零专项痕迹。

验证必须经两个下层 BIZ 正式公开入口，不得用专项直接构造 DATA 结果或增加生产 seam。若下层最终 ABI 封闭某些坏形状，动态验证只覆盖公开可构造分支，静态证据不得宣称动态命中。

真实资源耗尽、私有 DATA 损坏、跨进程恢复、父 L2 组合、活动重判、当前任务树、G0/G1、自我治理循环和独立集成验收保持 `NOT_RUN`。

本设计发布不证明两个下层 BIZ、DATA-EXT-12 或本叶代码已经实现；未来本计划结果也只证明父链活动路径组合 provider，不证明需求活动性重判正确、任务树或系统闭环完成。
