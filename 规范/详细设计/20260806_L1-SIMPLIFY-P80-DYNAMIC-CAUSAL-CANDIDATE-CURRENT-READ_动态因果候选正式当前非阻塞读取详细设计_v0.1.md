## 1. S0、能力复用与最早缺口

P76 是动态事实到待应用确认候选的唯一解释者；P77 冻结首次非空批次 `9+N/7N/8N/7N/0`
写集、`9+16N`稳定映射和`9+23N`读回；P78冻结G9；P79冻结一次原子发布及发布时完整结果。
四叶均待激活，接口只作待实现门禁，不等于当前代码能力。

P79发布结果只证明发布线性化点的同锁读回，不证明任意后继代次候选仍当前。应用确认若直接
消费P79结果，或自行解析L1关系和值，会形成第二候选解释者并跳过当前性。当前正式树只有旧
`轻量因果服务::读取轻量因果`，其对象是轻量引用；`安全直接因果图提供者`只有抽象和隔离
自检替身。它们均不拥有P77/P79的事件候选事实。

因此P79后的唯一最早独立叶是G9动态因果候选正式当前读取provider。应用确认、可信度修订、
已确认因果读取和安全直接因果图必须消费本叶成功事实，不能与本叶合并。

## 2. 目标与最大边界

新增唯一公开根：

```cpp
动态因果候选当前读取结果
L1动态因果候选读取服务::读取当前动态因果候选(
    const 动态因果候选当前读取请求& 请求) const;
```

固定过程：纯值准入 → P17 `尝试读取完整快照`恰一次 → 校准请求截止 → 校验P79登记定位 →
只解释该关系类型的当前关系 → 按源分组互证角色1—8和七个当前槽 → 稳定排序 → 返回零、一个
或多个当前候选完整纯值事实。

本叶零写、零P15/P79调用、零确认/撤销、零可信度、零图投影。它不返回P76完整状态/动态副本，
只回显已发布候选中的稳定状态、动态引用及候选自身属性事实；后继确认仍须调用相应事实所有者
取得确认所需当前材料。

## 5. 入口、P17与共同截止

入口先验证两个版本、非零世界根/截止/登记发布代次、九个定位编码非零互异。失败为入口拒绝，
P17调用0。有效入口调用P17非阻塞完整快照恰一次：

| P17状态 | P80状态 | 载荷 |
| --- | --- | --- |
| 成功且快照完整 | 继续 | 必须快照代次等于预期截止 |
| 许可拒绝 | 许可拒绝 | 空 |
| 资源失败 | 资源失败 | 空 |
| 未找到、入口拒绝、内部不一致或坏成功 | 内部不一致 | 空 |
| 成功但代次不同 | 版本漂移 | 回显实际非零截止，空集合 |

P80不持P17许可跨返回；快照是调用方拥有的值式副本。一次调用只有一个共同截止，即请求截止
与P17快照代次相等。零内部重试、等待、sleep、第二快照或阻塞式读取。

## 6. 登记、零/一/多与坏事实

在P17当前节点中逐项校验定位：服务与关系类型为普通节点，七属性类型中前四表示`I64`、
后三表示`U64组`；九节点创建代次均等于定位登记发布代次且不晚于当前截止。

- 九节点全部不存在：`尚无候选登记`，空集合；
- 仅部分存在、已错配、创建代次不同、种类/表示错误：`内部不一致`；
- 九节点完整：进入候选解释。

只扫描当前关系中`关系类型节点==定位.候选结构关系类型`的关系，按源候选分组：

1. 无此类关系：返回`已读取`、完整空候选组。这是合法“当前零候选”，不等于登记不存在。
2. 一个源组：形成一个候选；多个源组：逐组形成多个候选，禁止只选最新或最小编码。
3. 每组角色1—8各恰一，源均为同一当前普通候选节点；角色1目标必须是定位候选服务，角色2
   目标必须是请求世界根；角色9/10、未知角色、重复角色或错端点均为内部不一致。
4. 候选节点必须恰有七个定位属性类型的当前槽。槽指向当前值事实；值所属候选、属性类型、
   来源节点=定位候选服务、材料种类和创建代次逐项闭合。
5. 前四材料分别为候选合同版本、真实性、投影规则版本、排序规则版本的I64；后三为单元素
   U64组，分别是条件时间、结果时间、来源截止。
6. 真实性只允许`待应用确认(1)`；来源截止非零且`来源截止 < 登记发布代次 <= 当前截止`；
   条件时间严格早于结果时间。

由角色2—8和三个时间/规则属性机械形成`动态事件因果候选键`；动作和方法不在P77事实中，
角色9/10必须为0，P80不得补默认动作身份。候选键重复、候选编码重复或同一关系跨组复用属于
内部不一致，不得静默去重。

## 7. 排序、完整性与生命周期

候选组按P76同一规则稳定升序：`场景编码、结果发生时间、证据动态编码`，再以完整候选键和
候选编码作确定平局键。输出顺序不得来自容器、关系扫描、线程或哈希顺序。

只有`已读取`携带`完整=true`集合，允许候选数0、1或多。`尚无候选登记`及其它状态均无集合；
版本漂移可回显P17实际截止但无部分候选。当前快照只含当前事实，退出候选不进入结果；只要
同一候选仍有任一当前候选关系却缺其它角色/槽，就属于半结构内部不一致，不能当作已退出。

结果只在返回的事实截止有效，后继应用确认必须显式携带该截止和候选稳定身份再读确认材料。
P80不把读取行为写成用途观察，不改变候选真实性、计数、生命周期或图。

当前只覆盖同一生产进程正常存活期间的当前读取。不设计恢复介质、启动扫描、崩溃窗口、重启
续作或跨进程恢复；日志也不能充当恢复或候选事实。
