# 方法类数据操作详细设计

日期：2026-09-05

版本：v0.1

身份：`ARCH-L4-METHOD-CLASS-DATA-OPERATIONS`

状态：设计已冻结，等待代码实施

## 1. 目标与完成边界

新建`海中鱼巣/领域/数据服务.方法类.ixx`，以独立ARCH-L4 method owner形成可供任务后续
稳定引用的薄记录面：方法头、静态条件项、结果方向项，以及七个新增/查询入口。

本叶只机械保存调用方已裁决的结构。静态条件由当前一次特征结点表达；一个结果方向项由
两个实际阶次恰为2的二次特征定义分别表达“行动/变化方向”和“结果方向”。记录面不解释
它们是否正确、适用、可执行或成功。

本叶不是3300/5350完整正式方法：不建立动作绑定、用途、作用对象、输入规格、限制、条件
结果关系、内容/规格/生命周期版本、粗召回、能力投影、方法选择、任务路径、实例方法、
执行、运行事实、学习、晋级或新代际，不提供替换和退出。

Vm必须延期。当前存在类新增能力是任务Vt专用规格，只接受任务语义与T→Vt关系；普通
存在入口属于世界存在。方法类不得借用任务Vt专用入口，也不得以普通世界存在替代Vm。
因此本叶不创建、不保存、不返回Vm，并明确不得宣称“正式方法头完整发布”。

新旧两套迁移期并行。新模块、owner、稳定编码和DTO与旧方法结构隔离，零import、零调用、
零强转、零DTO复用旧`服务.L2*`；最终替代旧逻辑不属于完成条件。

模块唯一公开导入：

```cpp

```

该导入链已公开传递特征类与存在类类型。方法服务直接持有L1、特征类、二次特征类引用与
一个专属move-only method owner写端口；不持有存在类引用，因为本设计没有合法存在结构
调用。服务不可复制、不可移动，不返回owner、端口、写集、锁或可变引用。

```cpp
struct 方法类结构类型 final {
    稳定编码 方法来源关系类型{};
    稳定编码 方法条件关系类型{};
    稳定编码 条件特征关系类型{};
    稳定编码 方法结果方向关系类型{};
    稳定编码 结果行动方向关系类型{};
    稳定编码 结果结果方向关系类型{};
};

方法类数据服务(const L1事实基座服务& 第一层服务,
    const 特征类数据服务& 特征服务,
    const 二次特征类数据服务& 二次特征服务,

```

六个关系类型必须非零、两两互异、当前、未退出、为method owner持有的无属性普通节点；
owner必须为当前独占结构范围。构造不符抛`std::invalid_argument`，不创建类型或第二端口。

## 3. 依赖白名单与复用裁决

直接调用白名单冻结为：

```text
L1事实基座服务：
  读取中性当前事实代次
  读取当前结构所有者
  读取所有者范围当前节点
  读取所有者范围当前源关系组
  读取所有者范围当前目标关系组
  尝试读取所有者范围一致当前投影
L1所有者范围写端口：
  读取首次写入材料
  提交所有者范围中性写集
特征类数据服务：
  查询特征
二次特征类数据服务：
  读取二次特征概念材料
存在类数据服务：
  零调用
```

`查询特征`用于同G0证明条件引用是当前特征结点并取得其类型和值；它不是条件满足判断。
`读取二次特征概念材料`用于同G0证明两个方向引用当前、完整且实际阶次恰为2；它不是
行动、变化或结果真实性判断。禁止二次特征生成/计算、普通存在、任务Vt专用入口、L1
中性v1写、私有仓库、SQL、raw owner选择、白名单外函数和全部旧`服务.L2*`。

当前没有同一新owner的合法方法记录面，故新建唯一模块；旧L2方法服务只能作为迁移事实，
不得包装。当前白名单没有合法Vm提供者，故延期而非虚构。

## 4. 结构形状与唯一键

长期知识节点严格只有三类：

```text
方法头M --方法来源--> 外部来源普通节点S
方法头M --方法条件--> 条件项C --条件特征--> 一次特征结点F
方法头M --方法结果方向--> 结果项R
结果项R --结果行动方向--> 二次特征定义A
结果项R --结果结果方向--> 二次特征定义O
```

M、C、R均是method owner创建的无属性普通节点。S、F、A、O只被跨owner引用，不被本服务
修改。各关系角色/顺序固定为0且无属性。

唯一键：一个当前来源S最多对应一个当前M；同一M+F最多一个当前C；同一M+A+O最多一个
当前R。编码顺序不是业务顺序；所有返回组按公开字段字典序稳定升序。

基础新增固定本地键M=`1`、来源关系=`2`。条件添加固定C=`1`、M→C=`2`、C→F=`3`。
结果方向添加固定R=`1`、M→R=`2`、R→A=`3`、R→O=`4`。每个入口使用独立幂等身份与
一份method owner L1写集；不同入口不拼接事务。

## 7. 基础方法记录

新增先冻结G0、验证来源节点为L1当前普通节点，再按首次材料处理幂等。随后用来源目标
关系组执行有界精确查询：零项才创建；一项返回`精确记录已存在`且不泄漏非成功载荷；
多项为内部不一致。单一写集原子创建M与M→S关系，提交成功/精确重复后按新编码和Gend
完整读回。已确认发布但读回未闭合返回`已可能发布`，只允许原键原请求重放。

身份查询以method owner一致投影读M和唯一来源关系，再分别读取条件组、结果方向组并验证
所有跨owner端点。精确查询按来源目标关系组零/一/多收口，并调用同一核心读回；不得按
编码选一个。所有读取首尾代次必须等于请求G0。

## 8. 条件项

添加前完整读回M，以`查询特征({版本,G0,F})`证明F当前、未退出且结果完整；不得调用
修改/新增特征。再有界读取M的条件组：同M+F已存在时，首次材料同键同请求返回精确重复，
不同键返回`条件项已存在`。否则一份写集原子创建C、M→C和C→F，三项同创建代次。

读取条件组有界读取M→C，逐项以owner一致投影证明C和两条关系，再恰一次查询各F；按
`条件特征稳定编码、条件项身份`升序，重复F或形状矛盾为内部不一致。空组成功。条件项
只表示静态特征引用，不读取当前世界宿主，不计算条件是否具备。

## 9. 结果方向项

添加前完整读回M，分别对A/O调用`读取二次特征概念材料`，只接受已读取、同G0、身份一致、
完整材料且`实际阶次 == 2`。A和O允许相同；记录面不判断语义是否合理。再有界读取现有组：
同M+A+O按首次材料区分精确重复与`结果方向项已存在`。否则一份写集原子创建R及三条关系，
四项同创建代次。

读取结果方向组有界读取M→R，逐项证明R与三条关系，分别经二次特征类同G0读回A/O；按
`行动变化方向稳定编码、结果方向稳定编码、结果项身份`升序，重复二元组或结构矛盾为
内部不一致。空组成功。不调用二次特征计算，不保存计算结果。

## 10. 失败、幂等与预算

- 所有请求版本、G0、身份、幂等身份和适用预算必须非零；非法入口零写。
- L1未找到/已退出/非普通来源分别映射具名来源状态；特征服务未找到/退出分别映射条件
  状态，其它非成功映射条件特征不可用。
- 二次特征未找到/退出分别映射结果方向状态；成功但阶次不等于2映射
  `结果方向不是二次特征`，其它非成功映射结果方向不可用。
- 任一候选组超过调用方预算返回`数量预算不足`和零业务载荷；不得截断、分页后伪称完整。
- 同键同完整请求返回原结果；同键异义返回幂等冲突。写前失败零变化，每个写入口恰一次
  提交；代次漂移不覆盖，发布未知不撤销、不换键。
- 记录和项不可原地修改。本叶不提供退出、删除、替换、恢复或历史查询。
