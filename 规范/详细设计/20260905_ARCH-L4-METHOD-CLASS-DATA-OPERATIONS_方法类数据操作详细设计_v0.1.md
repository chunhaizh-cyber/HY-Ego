# 方法类数据操作详细设计

日期：2026-09-05

版本：v0.2

身份：`ARCH-L4-METHOD-CLASS-DATA-OPERATIONS`

状态：设计已冻结，等待代码实施重新S0

## 1. 目标与边界

新建`海中鱼巣/领域/数据服务.方法类.ixx`，以独立ARCH-L4 method owner形成方法头M、
条件C、结果R和每方法唯一方法虚拟存在Vm的薄记录面。条件引用当前一次特征结点；结果项
成对引用“行动/变化方向”和“结果方向”两个实际阶次恰为2的二次特征。方法记录可供任务
后续稳定引用，记录面不判断适用、采用、授权、执行或成功。

本叶不是3300/5350完整方法：不建立动作绑定、用途、输入规格、限制、条件结果关系、内容/
规格/生命周期版本、粗召回、能力投影、选择、任务路径、实例方法、执行、学习或晋级，不做
替换/退出。新旧并行且零调用、零import、零强转旧`服务.L2*`。

Vm是方法头抽象信息宿主，不是世界存在，不进入世界树，不得在方法间共享，也不承载任务
状态、本轮参数、授权、运行结果或结算。本叶只建立Vm节点及M→Vm唯一关系；现有普通存在
入口和任务Vt专用入口均不得复用或泛化。

## 2. Vm→Vt实例化裁决

用户所称“合并”固定解释为：采用方法后，把Vm允许实例化的抽象特征/结构投影成某任务Vt
内的实例事实；不是Vm与Vt身份合一，也不是简单持久化Vt→Vm集合关系。Vm保持抽象，Vt
保持任务实例，实例必须至少追踪来源方法头、Vm和抽象项。

正式规范允许该方向，但当前切片不能安全实现：方法类只有method owner端口，不得写task
owner的Vt；存在类不能反向import方法类解释Vm内容，否则形成循环依赖和第二方法解释；
允许文件也不含任务类、Vt实例特征合同或task owner提交入口。因此具名后继
`ARCH-L4-METHOD-VM-TO-TASK-VT-INSTANTIATION`保持未设计路线输入，不登记计划索引。

后继必须另行冻结：允许复制/投影的抽象材料白名单，调用期对象/参数绑定，Vt实例特征与
来源追踪形状，方法头↔Vm与任务头↔Vt双唯一读回，task owner单事务提交，同义幂等、异义
冲突、G0/Gend和发布未知原请求重放。不得把本轮参数/状态/授权/结果回写Vm。本v0.2不建立
简单Vt→Vm关系，不导出伪实例化写集，也不阻断M/C/R/Vm最小叶施工。

源M，防止Vm被多个方法头共享。全部读在同一G0，返回专用值式投影而非`存在类结点`。

## 5. 方法结构、DTO与稳定状态

```text
M --来源--> 外部当前普通节点S
M --方法Vm--> Vm（同method owner，唯一且不可共享）
M --条件--> C --条件特征--> 当前一次特征结点F
M --结果方向--> R --行动变化方向--> 二次特征A
                  └--结果方向--> 二次特征O
```

M/C/R/Vm均为method owner无属性普通节点；S/F/A/O只跨owner引用。唯一键为S→M至多一、
M→Vm恰一完成初始化后不可再建、M+F至多一C、M+A+O至多一R。

```cpp
inline constexpr std::uint32_t 方法类数据合同版本 = 2;
enum class 方法类数据状态 : std::uint8_t {
    已创建=1, 精确重复=2, 已读取=3, 已添加条件项=4,
    已读取条件组=5, 已添加结果方向项=6, 已读取结果方向组=7,
    入口拒绝=8, 未找到=9, 来源节点未找到=10, 来源节点已退出=11,
    来源节点不是普通节点=12, 精确记录已存在=13,
    条件特征未找到=14, 条件特征已退出=15, 条件特征不可用=16,
    条件项已存在=17, 结果方向未找到=18, 结果方向已退出=19,
    结果方向不是二次特征=20, 结果方向不可用=21,
    结果方向项已存在=22, 数量预算不足=23, 事实代次漂移=24,
    幂等冲突=25, 引用冲突=26, 资源失败=27, 内部不一致=28,
    已可能发布=29, 已初始化方法虚拟存在=30,
    方法虚拟存在已初始化=31, 方法虚拟存在未初始化=32,

```

`std::optional<方法虚拟存在投影> 虚拟存在`。新增：

## 7. Vm初始化、幂等与失败

方法头新增和Vm初始化使用不同幂等身份，是两个明确阶段。初始化先在G0读M和首次材料，
再调用方法Vm专用查询；已有合法Vm时原键原请求重放为精确重复，否则返回已初始化。未初始
化时调用规格形成，严格核对版本1、G0、method owner、幂等身份及固定一节点一关系形状，
再由方法类自己的端口恰一次原样提交。成功/精确重复后以Gend专用查询完整读回。

发布已确认但读回未闭合返回`已可能发布`，不撤销、不换键，只允许原请求重放。所有写前
失败零变化；同键同完整请求读回，同键异义幂等冲突；代次漂移不覆盖。来源/特征/方向的
未找到、退出、类型不符、资源失败分别映射v0.2具名状态。方法记录、M/C/R/Vm和关系均不
原地修改，不提供退出、替换、恢复或历史查询。
