# 候选任务当前父关系组消费详细设计 v0.1

日期：2026-08-16

计划身份：`TASK-CURRENT-CANDIDATE-PARENT-RELATION-GROUP-CONSUME`

## 1. 目标与完成边界

实现当前任务树的第五个输入叶：

```text
BIZ-L4-004-02-02-05 v0.1
任务业务服务::读取候选任务当前父关系组
-> 接收02在同一非零G0返回的完整成功读取结果
-> 互证02状态、请求回显、运行代次、范围版本、预算、事实截止和任务材料组
-> 只经DATA-EXT-13恰一次批量读取每个候选任务的可空唯一当前父关系
-> 有父时完整回显父任务端点；无父是合法成功项
-> 形成稳定排序、不可变、零部分载荷的BIZ值式组
```

本叶只提供父级预选唯一零父候选所需的中性父关系材料，解除 03 “先有根、后读整树”与 01/02 “没有父关系”之间的循环。它不自行选择根，不证明完整树，不读取目标语义或治理存在，不改变 02/03/04 职责。

## 2. 正式依据与当前事实

设计 S0 基线为 `main@93b1327b6743fd47c9ea345603f1f57407670500`：

1. 0050 要求组合读取使用显式共同截止、完整不可变投影和结构化失败，禁止跨截止拼装、缓存补缺和部分成功前缀。
2. 5090 规定同一有效来源需求复用唯一当前任务树，但该业务不变量不能由任务列表顺序、创建时间或生命周期阶段替代。
3. 3200、5200 把任务父子拓扑与来源、目标、场景、生命周期分账；父关系是结构事实，BIZ 可裁决零/一/多，但 DATA 不选择当前根。
4. 02 v0.2 已冻结入口候选任务的完整来源、唯一目标、唯一场景和唯一当前生命周期，却明确不读取父关系。
5. 03 v0.2 能证明给定根下的完整有根树，但其请求要求父级先提供唯一根完整见证；因此父级当前存在 `DRIFT-TASK-CURRENT-ROOT-QUALIFICATION-CIRCULAR-INPUT`。
6. DATA-EXT-13 最终需求边界已经包含任务树读取，但尚无“按候选任务组与G0批量读取当前父关系”的最终公开 DTO / ABI；当前真实代码也没有生产任务结构服务或 `服务.任务.ixx`。

裁决为：新增 05 叶，仍使用同一 DATA-EXT-13 任务结构服务，一次返回候选任务逐项可空父关系。父级只在 05 成功后选择唯一零父候选，再调用 03 完整证明有根树；05 不复制 03 的全拓扑和治理资格读取。

## 3. 输入、输出与 DATA 消费合同

### 3.1 BIZ 输入见证

请求必须携带：

```text
02完整任务承接生命周期读取结果
同一非零G0
运行代次
事实范围版本
任务范围版本
任务父子关系规则版本
任务树读取规则版本
读取规则版本
最大候选任务数量（非零）
最大当前父关系总数量（非零）
```

02 结果必须为 `已读取`、事实截止等于 G0、optional 任务材料组有值且非空；02 请求回显、任务组、两预算和版本完整。`02请求回显.运行代次 == 05请求.运行代次 == 同一任务业务服务固定配置.运行代次`，02 与 05 重叠的事实/任务范围版本必须匹配同一固定配置。候选任务取自 02 完整任务材料，不接受调用方另传裸任务列表。

### 3.2 唯一 DATA 操作

本叶要求 DATA-EXT-13 同一 `任务结构服务`提供一个公开 const 操作：

| 操作 | 请求 | 成功返回 | 非成功 |
| --- | --- | --- | --- |
| 按任务组与指定截止有界读取当前父关系组 | 非空、无重复任务身份组；非零G0；事实/任务范围、父子关系/任务树/读取规则版本；候选任务数和当前父关系数两项非零总预算 | 与规范化任务组等长同序的逐任务父关系项；每项含任务身份及来源、可空唯一当前父关系，有父时含完整父任务身份及来源；关系身份/来源、父到子端点、生命周期、版本和单项G0完整；回显版本、预算和共同G0 | 请求拒绝、任务未找到、任务已退出、预算不足、事实代次漂移、重复父属、许可拒绝、资源失败、未实现和内部不一致分账；整组失败零成功前缀 |

运行代次、入口来源需求、目标、场景、生命周期结构、治理存在和父级零父裁决不进入 DATA 请求。最终 DTO 名、字段顺序、状态数值和 C++ 签名待 DATA 所有者发布后机械匹配；BIZ 不建立兼容壳、第二任务服务或同义“根候选”DATA入口。

### 3.3 成功形状

每个值式项冻结为：

```text
候选任务身份及完整身份来源
optional当前父关系
optional当前父任务身份
optional当前父任务身份来源
单项事实截止G0
```

三个父相关 optional 必须同形：

- 全空表示该候选在 G0 下没有当前父关系；
- 全有值表示恰一当前父关系，关系源端点是父任务、目标端点是本候选任务，父身份来源完整；
- 任一半结构、反向端点、自父、同一候选出现多条当前父关系、关系身份在全组重复、候选任务身份在全组重复、生命周期非当前、错版本或错 G0 都是坏成功形状。

当前父任务不要求属于候选任务组；不同候选可以合法共享同一父任务，这表示兄弟节点，不得按父任务身份跨候选去重。结果按候选任务稳定身份排序，父关系存在时再按父任务和关系稳定身份互证；禁止使用名称、创建时间、列表位置或 enum 裸底值排序。

## 4. BIZ 类型与物理位置

新增值式合同头：

```text
海中鱼巣/领域/候选任务当前父关系组.数据.h
```

冻结预实现形状：

```cpp
inline constexpr std::uint32_t 候选任务当前父关系合同版本 = 1;

struct 候选任务当前父关系固定配置 final {
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 任务范围版本;
    std::uint64_t 任务父子关系规则版本;
    std::uint64_t 任务树读取规则版本;
    std::uint64_t 读取规则版本;
};

struct 候选任务当前父关系读取请求 final {
    std::uint32_t 合同版本;
    std::uint64_t 运行代次;
    std::uint64_t 事实范围版本;
    std::uint64_t 任务范围版本;
    std::uint64_t 任务父子关系规则版本;
    std::uint64_t 任务树读取规则版本;
    std::uint64_t 读取规则版本;
    任务完整承接生命周期读取结果 候选任务完整材料结果;
    std::uint64_t 共享事实截止;
    std::uint64_t 最大候选任务数量;
    std::uint64_t 最大当前父关系总数量;
};

struct 候选任务当前父关系值式事实 final {
    L2任务身份 任务;
    L2节点族身份来源事实 任务身份来源;
    std::optional<任务父子关系值式事实> 当前父关系;
    std::optional<L2任务身份> 当前父任务;
    std::optional<L2节点族身份来源事实> 当前父任务身份来源;
    std::uint64_t 事实截止;
};

enum class 候选任务当前父关系读取状态 : std::uint8_t {
    已读取 = 1,
    请求拒绝 = 2,
    数量预算不足 = 3,
    当前性漂移 = 4,
    重复父属 = 5,
    提供者拒绝 = 6,
    资源失败 = 7,
    未实现 = 8,
    内部不一致 = 9
};

struct 候选任务当前父关系读取结果 final {
    std::uint32_t 合同版本;
    候选任务当前父关系读取状态 状态;
    候选任务当前父关系读取请求 请求回显;
    std::uint64_t 事实截止;
    std::optional<std::vector<候选任务当前父关系值式事实>> 父关系组;
};
```

只有 `已读取`携带非空 `父关系组`和非零事实截止；全部非成功 optional 为空、事实截止为零。函数固定扩展同一：

```cpp
候选任务当前父关系读取结果 读取候选任务当前父关系组(
    const 候选任务当前父关系读取请求& 请求) const noexcept;
```

物理位置为 `海中鱼巣/领域/服务.任务.ixx`；服务继续只持同一 DATA-EXT-13 const 稳定借用和组合不可变配置。

## 5. 固定顺序与失败映射

```text
校验固定配置完整，否则内部不一致且零DATA调用
-> 校验合同、02完整成功结果、G0、版本和两项非零预算
-> 互证02状态、请求回显、结果截止、optional任务组、任务集合和预算
-> 互证02回显/05请求/固定配置运行代次三者相等，重叠范围版本匹配
-> 从02任务材料组提取任务身份并稳定排序；重复、空组或超预算请求拒绝
-> 构造不含运行代次、来源、目标、场景、生命周期和治理存在的DATA请求
-> 恰一次调用按任务组与指定截止有界读取当前父关系组
-> 精确映射DATA非成功；同G0任务未找到/退出升级内部不一致
-> 互证回显、G0、版本、两预算、任务组等长同序且集合相等
-> 逐项互证任务身份来源和父关系/父任务/父来源optional同形
-> 有父时互证关系身份来源、父到子端点、生命周期、版本和G0；拒绝自父、同一候选多父、关系身份跨组重复，允许不同候选共享父任务
-> checked累计父关系数并复核预算；输入扰动后稳定排序
-> 无抛出交换完整候选并返回已读取
```

| 情形 | BIZ状态 | 载荷 |
| --- | --- | --- |
| 固定配置坏 | 内部不一致 | 空；零DATA调用 |
| 02非成功/空optional、坏合同、零G0/预算、空/重复/超量候选、坏回显 | 请求拒绝 | 空；零DATA调用 |
| 运行代次或重叠版本不等 | 当前性漂移 | 空；零DATA调用 |
| DATA任务未找到/已退出 | 内部不一致 | 空；与02同G0完整任务见证矛盾 |
| DATA预算不足 | 数量预算不足 | 空；不得截断 |
| DATA事实代次漂移 | 当前性漂移 | 空 |
| DATA明确多父 | 重复父属 | 空 |
| DATA许可/资源/未实现 | 对应BIZ状态 | 空 |
| DATA请求拒绝、未知状态、半结构或其它坏成功形状 | 内部不一致 | 空 |
| 完整成功 | 已读取 | G0和逐任务可空父关系组 |

全部复制、分配、累计和排序位于异常收口内。`std::bad_alloc`、`std::length_error`映射资源失败，未知异常映射内部不一致；成功交换前零部分发布。

## 7. 验证矩阵与声明边界

- 坏配置、02非成功/空optional/坏回显、零G0/预算、空/重复/超量候选、运行代次或版本不等分别验证零DATA调用；
- 单候选零父、单候选有父、多候选零/一父混合和输入乱序成功；输出与候选任务等长同序且稳定；
- 非空候选只调用 DATA-EXT-13 一次；零逐任务、分页、补读、缓存、重试、截止重选和 L1/owner/仓库直达；
- DATA任务未找到/退出升级内部不一致；预算、漂移、重复父属、许可、资源、未实现和未知状态分别映射；
- 父相关optional半结构、错方向、错子端点、自父、重复关系、错身份来源/生命周期/版本/G0和超预算全部拒绝且零前缀；
- 当前父任务不在候选组仍合法；本叶不判断零父候选数量，不读取完整拓扑/治理存在/目标内容/来源内容/阶段/完成/调度/方法/权限；
- 根工程 Debug/Release、专项双配置、strict、UTF-8/XML、工程唯一登记和生产零专项痕迹。

真实验证必须经 DATA-EXT-13 正式公开入口。真实资源耗尽、DATA私有损坏、跨进程恢复、父级唯一根裁决、目标等价、03整树读取、04后继材料读取、完整当前任务树发布、任务创建/迁移/调度/完成和系统业务闭环保持 `NOT_RUN`。

本设计发布不证明 DATA-EXT-13、05 BIZ代码或当前任务树已经实现。未来本计划结果最多证明同一 G0 下候选任务当前父关系组的中性消费闭合。
