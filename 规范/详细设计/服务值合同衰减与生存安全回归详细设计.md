## 2. 当前代码事实

当前 `main` 的只读事实固定为：

1. `初始化.需求.ixx` 能建立安全值 / 服务值语素、实例槽、I64 初值和两个根需求；它没有服务合同、时间维护或任务权限入口。
2. `自我线程.ixx` 等待消息超时后直接继续；循环次数、等待超时和消息批次都不是完整物理秒。
3. `自我治理领域路由.ixx` 是固定安全根兼容链，并明确拒绝服务根需求；不得扩写为本设计的服务领域实现。
4. 需求、任务、方法服务没有服务合同唯一键、预算、30% / 70%、有效进展、准备补回或服务任务分类。
5. 任务执行请求不含安全 / 服务权限材料，任务管理按确认顺序 `push_back` / `pop_front`，没有候选集合权限排序。
6. 当前轻量因果只形成轻量引用，不能裁决任务是安全来源还是服务来源。
7. 节点直接身份结构写入执行器已有多参与者准备、确认、最后发布和逆序撤销底座；#381 结果还提供 `执行仅参与者事务(span)`，空参与者组拒绝、非空参与者组顺序准备 / 确认 / 发布、失败逆序撤销、全幂等返回幂等读回。
8. #377 v0.7 真实结果提交 `999ddbd994dc26f54c7fc41b4c5616d29c582d6b` 已进入 main；协议模块实际提供 `安全权限层来源选择`、显式场景 / 图 / 任务集合版本请求、`权限读取结果 / 载荷` 和 `安全权限规则版本=1`。执行回执曾给出错误完整哈希，设计与索引只能使用 Git 可解析的上述正式对象。
9. #379 十个目标模块当前均不存在；不得把预冻结合同、隔离自检或 #359 未来适配写成当前真实接口。

## 3. 合同分层

### 3.1 `SERVICE-C1 / v1` 服务合同与结算

唯一职责：

```text
读取有效人类需求和准备事实
-> 建立或读回唯一合同
-> 冻结有效期和预算
-> 结算 30% 预支
-> 裁决完成 / 取消 / 到期 / 终止
-> 结算 70% 余款或关闭余款
-> 发布到期未满足事件
-> 结算准备衰减补回
```

合同建立 + 30% 预支可以由合同入口独立原子发布；合同终态、准备补回和同秒时间维护在生产循环中由 `SERVICE-C2` 聚合入口共同提交。`SERVICE-C1` 不计算时间衰减、不计算生存安全根回归、不排序任务。

合同建立入口必须通过 `服务生存事实提供者` 回读当前生存安全根值和版本。`A=0` 时返回 `入口拒绝`、无载荷、零写入；`A=1` 或 `A>1` 才继续合同准入。安全值或定义版本漂移时返回 `版本漂移`，不得用请求、线程状态或旧缓存解释终止态。

### 3.2 `SERVICE-C2 / v1` 服务值与生存安全维护

唯一职责：

```text
读取已发布新合同 / 预支、合同终态、准备、进展、安全和时间事实
-> 聚合调用 SERVICE-C1 纯值终态 / 准备结算合同
-> 计算跨过的完整秒
-> 形成服务衰减段
-> 处理 30 天门禁和有效活动最低 1
-> 新安全事实优先
-> 形成生存安全根值被动回归候选
-> 同事务发布值、状态、动态、游标和幂等账
```

它是生产治理循环中合同终态 / 准备结算与时间维护的唯一聚合提交入口。它不改变 6140 分层安全值，不从任务等待、调度资源紧张或任务数量反写服务值或安全值。

### 3.3 `SERVICE-C3 / v1` 安全 / 服务任务根权限

唯一职责：

```text
读取已发布生存安全根值和阈值
-> 形成安全根权限与服务根权限
-> 安全来源组合 6150 当前五级安全权限
-> 服务来源使用服务根权限
-> 多来源任务取最高
-> 形成确定性排序投影
```

权限是可重建值式投影。只有实际选择 / 派发历史冻结来源与规则版本；不得把当前权限复制为任务第二份权威状态。

## 5. 权威记录与值式 DTO

下列表中没有标注“适用性与可选值”的字段均为必选。任何可能不适用的身份、数值、版本、事件或载荷都必须成对使用 `服务适用性` 和 `std::optional<T>`：适用时可选值必须存在，不适用时必须为空；禁止用 0、负数、空句柄、空字符串或默认构造值表达不适用。禁止在服务协议中重新声明 SAFETY 合同已经使用的通用 `适用性` 名称。

字段表采用以下唯一 C++ 类型映射，执行侧不得另选类型或压成匿名 pair / tuple：

| 字段类别 | 精确类型 |
| --- | --- |
| 自我、提出者、需求、来源事件 / 事实、目标、范围、合同、准备、任务、方法、状态、动态、验证、衰减段、适用场景、因果信息和提交方法等稳定对象身份 | `节点句柄` |
| 幂等主键、事实分段键、归属排序键、创建序号 | `std::uint64_t` |
| 所有记录 / 事实 / 值 / 定义 / 集合 / 纪元 / 代次 / 方法 / 证明版本与发布代次 | `std::uint64_t` |
| ABI、合同 / 时间 / 回归 / 权限 / 排序 / 算法规则版本 | `std::uint32_t` |
| 服务值、安全值、预算、应付 / 写入 / 舍弃量、阈值、权限、任务基础优先级、有效秒、等待秒、单调时间和完整秒边界 | `std::int64_t` |

F-V217—F-V220 是上述同一私有参与者的四个非平凡根函数。F-V217 以 `独占锁_ = unique_lock(仓库_->互斥_)` 取得并保存记录仓独占锁，复核形态 / optional 配对、幂等主键、候选身份版本材料、当前版本和准备只读视图：同键同义把完整已发布结果复制到对应幂等读回 optional 并进入 `幂等已准备`；同键异义返回 `身份冲突`；版本不等返回 `版本漂移`。新候选在锁内先用局部单项 `std::map` 完成全部可能分配，再 `extract` 出唯一 node 存入对应待发布 node，局部图销毁后进入 `新候选已准备`；因此最后发布不再分配。准备成功或幂等读回时独占锁一直跨 F-V218 保持，不得提前释放；F-V218 只把 `新候选已准备 / 幂等已准备` 分别推进到 `新候选已确认待发布 / 幂等已确认待发布`，不得写公开容器。F-V219 对新候选只把已预分配 node 以无分配 node insertion 移入对应已发布 map，随后进入 `新候选已发布`；对幂等候选不重复发布并进入 `幂等完成`；两者均清理私有槽并释放锁。node insertion 未插入、node 类型 / 键不等或非法阶段时保留可清理 node、进入 `内部异常`、释放锁；按本模块唯一写者与跨阶段持锁不变量，该分支不得在合法执行中发生，后继发布后读回必须收口为 `内部不一致`。F-V220 在准备或确认失败时清空两个待发布 node、幂等副本和对应候选暂态，进入 `候选已撤销`、释放仍持有的锁并返回 `候选已撤销`；重复撤销幂等，已经最后发布后撤销返回 `内部不一致` 且不得回删已发布事实。准备阶段失败先清理并当场释放锁。F-V217 的 `unique_lock` 构造发生 `std::system_error` 或其它非分配异常时清理暂态、释放已持锁并返回 `内部不一致`；已发布结果复制或局部 map 分配的 `std::bad_alloc` 返回 `资源失败`。所有异常均在根函数内捕获，非法阶段、半候选、同键异义、发布后读回不等和锁内异常统一 `内部不一致`。四函数不得保存核心准备只读视图，不得取得核心仓库写会话，不得生成身份、版本或发布代次。

### 7.5 服务编排

## 9. 算术合同

### 9.1 预算与结算

```text
M = I64_MAX
T = 2,592,000
D0 = floor(M / T) = 3,558,399,705,576
B = min(M, D0 * 冻结有效总秒)
P0 = floor(B / 10) * 3 + floor((B mod 10) * 3 / 10)
P0 = max(1, P0)
P1 = B - P0
```

乘法使用至少 128 位中间值或等价检查算法。服务值增加先计算 `min(请求增加, M-V)`，减少先计算 `min(请求减少, V)`；禁止先溢出后钳制。

### 9.2 完整秒衰减

```text
无有效未满足需求:
  D = 1

最长等待 t 小于 T:
  D = max(1, D0 + floor(D0 * t / T))

达到 T 或出现到期未满足事件:
  无有效服务活动 -> 目标 V = 0
  有有效服务活动且 V 大于 0 -> 目标 V = 1
  有有效服务活动但 V 等于 0 -> 保持 0
```

普通衰减也执行有效活动最低 1 保护。多个需求只读取最长等待 `t`，并列按提出边界、提出者、需求稳定身份排序，不叠加步长。

批量结算按事实秒、合同终态、30 天边界、服务比例档位、活动保护和饱和边界分段。每段保存请求地板和、实际减少、前后值和跳跃证明版本；结果必须与逐秒参考顺序完全相同。

### 9.3 服务比例与安全根回归

```text
U = floor(I64_MAX / 98)

V = 0:
  A = 0 -> 保持 0
  A 大于等于 1 -> Anew = 1

V 大于 0:
  P = min(99, 1 + floor(V / U))
```

全部普通回归分支前先裁决 `A=0` 保持终止。

```text
A 小于 L:
  距离 = L - A
  步长 = max(1, floor(距离 / 100) * P)
  Anew = min(L, A + 步长)

L 小于等于 A 且 A 小于等于 H:
  Anew = A

A 大于 H:
  距离 = A - H
  比例 = 100 - P
  步长 = max(1, floor(距离 / 100) * 比例)
  Anew = max(H, A - 步长)
```

同秒主动安全结算改变 `A` 时，跳过该秒服务被动回归。安全门禁材料缺失时不允许被动上升。

### 9.4 根权限

F-V204 先调用 F-V201。只有 `已形成` 继续；F-V201 的 `入口拒绝 / 版本漂移 / 结构拒绝` 原样作为无载荷结果返回，任何其它分类映射 `内部不一致`，不得在无效定义上继续计算。

```text
Q = 1,000,000

A 等于 0:
  生存控制态 = 终止
  普通任务竞争状态 = 不适用
  服务根权限 = 0
  安全根权限 = 0

A 等于 1:
  生存控制态 = 休眠
  普通任务竞争状态 = 不适用
  服务根权限 = 0
  安全根权限 = 0

A 大于 1 且 A 小于等于 L:
  生存控制态 = 主动运行
  普通任务竞争状态 = 适用
  服务根权限 = 0
  安全根权限 = Q

L 小于 A 且 A 小于 H:
  生存控制态 = 主动运行
  普通任务竞争状态 = 适用
  服务根权限 = max(1, floor((A-L) * 990,000 / (H-L)))
  安全根权限 = Q - 服务根权限

A 大于等于 H:
  生存控制态 = 主动运行
  普通任务竞争状态 = 适用
  服务根权限 = 990,000
  安全根权限 = 10,000
```

`A=0/1` 时不进入 6150 组合和普通任务排序；终止只保留正式恢复 / 重建与停止控制入口，休眠只保留人类请求接收、合同准入、完整秒维护、安全事实接收和停止控制入口。`A>1` 时，安全来源先按第 7.5 节精确分区：完整层要求 `优先级组` 在 1..5，唯一 SAFETY 数值为 `权限读取载荷.保留权限[优先级组 - 1]`；该值必须在 0..1,000,000。未归层来源的 SAFETY 数值固定为 0；具名缺口不形成数值并返回 `材料缺失`。安全来源最终权限为 `floor(安全根权限 * SAFETY数值 / Q)`；独立服务来源权限为服务根权限。安全兼服务来源只按安全来源计算，不重复取得服务根权限；多来源任务取最高，不求和。

任务有效执行优先级为：

```text
floor(任务基础优先级 * 来源权限 / Q)
```

同值比较依次使用来源权限、任务基础优先级、来源分类、安全具体排序材料、任务创建序号和任务稳定句柄。#359 可以在不改变本公式的前提下把 6150 已冻结的安全组内比较用于安全来源。

## 10. 同秒处理和事务

生产聚合入口 `结算服务生存治理批次` 的逻辑顺序：

```text
冻结事实截止版本
-> 新安全事件、复发和主动安全结算
-> 读取已经原子发布的新合同 / 预支结果
-> 裁决合同完成、取消和正式终止
-> 到期判定及到期未满足事件
-> 预支 / 余款 / 关闭余款
-> 准备完成、失败和此前衰减补回
-> 重算未满足集合和有效活动
-> 完整秒衰减或 30 天门禁
-> 若同秒主动安全值未变化，计算安全根被动回归
-> 形成合同、结算、值、状态、动态、衰减段、游标和幂等候选
-> 加入记录参与者与外部参与包
-> 按执行器协议逐参与者准备；每个参与者在准备阶段完成自身候选写入与写后读回
-> 全部准备与读回通过后按协议确认
-> 最后原子发布
-> 从已发布快照重建权限投影
```

准备或确认失败按加入逆序撤销。禁止在全部确认后才做首次写后读回；确认后新增写入、撤销失败、合同已支付但阶段未发布、游标推进但衰减段缺失或值改变但动态缺失都属于内部逻辑错误。

合同终态、准备补回、服务值衰减和生存安全回归在生产循环中不得分别提交。`建立或读取服务合同` 的合同 + 预支原子事务是唯一例外：它用于接收新的有效人类需求，且安全根被动回归只从后续完整秒进入聚合治理。

### 13.5 当前真实接口行为核对

### 13.6 零代码机械施工推演

逐根从公开请求 / 固定夹具开始，将每个字段映射到唯一来源 DTO，按 F-V201—F-V230 调用图推进。四个公开服务的全部提供者请求都能从公开请求逐字段形成；两个事实载荷回显全部首次读取条件；算法所需新身份、版本、纪元和代次都由具名身份版本材料提供；外部规格的写入输入版本、候选代次和方法绑定组都有唯一字段来源；数据操作类只能使用构造注入的执行器 / 记录仓并总能形成非空记录参与者组，唯一调用真实仅参与者入口；成功 / 幂等都由发布后读回收口；锁和执行器抛出在 `noexcept` 根内有唯一分类，失败在写前、撤销或发布后边界有唯一分类。F-V221 以 F-V230 形成完整本地关系准入表，并按真实构造顺序持有三核心仓、事务域与执行器；多边界夹具按显式 L/C/A 循环逐项调用；全部其它非平凡隔离分支都机械落在 F-V222—F-V229：三只读脚本按请求逐字段相等复制，外部包脚本只移动一次，隔离参与者只按核心真实阶段推进 / 撤销。SS-A20 只验证局部发布后读回，SS-A22 只验证值式不变性，恢复与静态模块边界不伪装成运行期可观测事实。推演不存在填零、隐式最新、服务自增、容器序身份、伪造核心回调、第二写事务、隐藏非平凡夹具函数或执行侧待裁决项。
