# 交互场景分层与自我场景跟随详细设计

标识：`INTERACTION-SCENE-LAYERING`；版本：v0.2（草稿）；日期：2026-11-05；状态：已定稿（第9节用户裁决全A）。

依据：1140 §1；1150 v3.5 §2—§3、§5；6120 v1.3 §11.1—§11.2；6220 v1.2 §2；6320 §3；0300 R89—R91。代码基线：生产代码 main `912a5b61e`（规范提交 `f6f4cc5dc` 及本次 R91 修订不改代码）。

## 1. 目标与完成条件

把 R89—R91 落到代码：
- 外设交互场景打开即建并通知自我线程，自我线程建立或补建对应的现实交互场景及交互窗口副本；
- 外设交互场景首次收到消息时含交互者存在；
- 建立连接 v4 以交互窗口副本为参数，函数内部读外设，写回形成交互者副本并更新自我“交互者”；交互者当前值变化时迁入自我；
- 自我所在场景随迁移更新；内部世界不持久引用外设节点，外设稳定编码只作标识数值保存。

完成条件：
1. 自我迁移后，快照、控制面板、服务值结算、因果筹办均按当前场景工作（切片A）。
2. 外设交互场景按角色识别窗口与交互者；首次收消息派生零特征交互者；新建外设交互场景后发出轻通知（切片B）。
3. 自我线程启动时和收到通知时，为每个尚无对应的外设交互场景建立现实交互场景及交互窗口副本，同一外设场景只对应一个（切片C）。
4. 建立连接 v4 参数全部在内部；写回形成或复用交互者副本、更新交互者、迁入自我；已确认连接事实只含内部节点；现实节点不保存外设节点引用（切片D）。
5. 实际项目编译链接通过；完成声明只到“已编译、未运行测试”。

不在范围：v4 的模拟学习（标记规格未支持，后继计划）；零特征存在不建专属概念的1140偏差（另立计划）；交互者副本判定为人类后与现有人类存在的身份合并；离开现实交互场景的方法；现实交互场景关闭与清理；交互对象集合特征写入。

## 7. 切片D：建立连接 v4、交互者副本与迁入

### 7.1 声明（`builtin.connection.establish.v4`，v3 停用）

| 序号 | 信息类型 | 范围概念 |

| 1 | 存在 | 自我概念 |
| 2 | 特征 | 交互者类型 |
| 3 | 存在 | 通用存在（交互窗口副本） |

### 7.2 执行与写回

1. 函数内读取参数4的值 X，`按场景读取来源(X)`；为空则条件不具备，返回结构化非成功，不进入动作。
2. 外设交互场景无交互者成员则条件不具备。沿用 v3 两步收发判定（窗口接收数量状态变化），全部在函数内读外设。
3. 动作：`建立动作动态(自我所在场景, …)`，动作来源为调用身份。
4. 交互者副本：在参数3所属现实交互场景中查找持有 `外设存在标识 == 外设交互者编码` 的存在；唯一命中复用，无则 `建立场景内存在(该场景, {外设存在标识 = 编码})`；多于一个为结构不一致。
5. `更新存在引用并形成动态(自我所在场景, 自我, 交互者特征, 副本, 动作)`；读回不等为工程故障。
6. 交互者当前值实际变化且自我不在该现实交互场景：`迁移自我(该场景)`；非成功为工程故障，已发生动作与写入保留，不补造。
7. 已确认连接事实：`{连接关系, 现实交互场景, 自我, 交互者副本, 交互者特征}`。调用身份节点去掉外设场景字段与外设参数引用，改记 X 的标识数值。连接服务内存中对外设状态的固定不写入现实节点。

- 字段询问等以外设场景/窗口为输入的本能，本计划只把其参数来源改为交互窗口副本的 `外设场景标识`，函数内部读外设；不改其业务判定。

## 8. 非成功、工程故障与静态复核

- 外设编码找不到、外设无交互者：条件不具备，零写入。
- 副本或现实交互场景多重命中、迁移非成功：结构化非成功，连接以工程故障终止该次执行，保留已发生事实。
- 外设交互者派生失败：外设类按既有“真实输入发布失败”工程异常终止。
- 筹办无/多候选：按既有缺口种类记录，不提议“获取参数对象”子需求。

| 检查 | 方法 |
| --- | --- |
| 自我只经 `迁移自我` 迁移 | 全仓搜 `迁移成员存在`/`迁移存在` 调用点 |
| 无固定场景身份比较残留 | 搜 `自我所在场景 !=`、`作用场景范围概念` 比较 |
| 现实节点不存外设节点引用 | 搜 `直接调用外设场景字段`、`外设窗口`、`外设场景` 的持久写入 |
| 外设编码只作 I64 值 | 读两个标识特征类型定义与全部写入点 |
| 窗口按角色定位 | 读 `读取窗口定位` 全部分支 |

## 9. 用户裁决（2026-11-05，全部采用A）

- **Q1 因果作用场景**：A（推荐）判定改为“自我当前所在场景等于定义作用场景，或在其场景范围内（沿父场景链可达）”；B 迁移时改写先天因果的作用场景范围概念。
- **Q2 外设交互者派生时机**：A（推荐）首次收到消息时；B 外设交互场景建立时。
- **Q3 现实交互场景的父场景**：A（推荐）自我初始化时所在的场景（自我的“原场景”），避免自我已在某交互场景时新场景嵌套到交互场景之下；B 严格按自我当前所在场景（可能嵌套）。
- **Q4 获取服务对象写交互者**：A（推荐）不再写交互者，只读已确认连接事实；B 保留并改写为副本。
- **Q5 迁移的坐标步骤**：A（推荐）存在无绝对坐标特征时跳过置空/写入两步，有则本计划报未支持；B 本计划完整实现1150 §5坐标步骤。
- **Q6 参数3如何与其它存在区分**：A（推荐）筹办按方法声明的“特征所属存在”关系过滤候选（参数3须持有参数4类型的特征），这一修正对所有方法通用；B 另建具名抽象存在概念“交互窗口”作参数3范围。
