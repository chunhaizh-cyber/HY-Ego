## 1. 目标、依据及完成边界

目标是使网页用户能够明确选择一条已经显示的正式出站消息作为本次回复对象，并让真实接收消息M在外设owner内与该对象同次发布、正式读回。正常未选择回复的输入继续作为普通输入；不按最近消息、时间、正文或页面序号推断回复。

依据：[7230第2.4、4.1节](../7230_子规范_语言材料知识与交互字段.md)、[CREATE第6.4(5)节](20261103_LANGUAGE-LEMMA-CREATE-FROM-FRAGMENT_未登记片段建立词条详细设计_v0.1.md)、[1100](../1100_根规范_语言记录_20260720.md)、[7220](../7220_子规范_概念多语种表达与自然语言接入.md)、[0050](../0050_项目通用机器逻辑与禁止性规则总纲_20260721.md)、[4030](../4030_子规范_基础信息服务分层与领域写授权.md)。这是实际回应关联提供者，不是分界解释器或分界目标满足提供者；无需用户重选已批准固定原文/范围专属目标语义。

基线：main/origin/main及设计树HEAD均`ad745885aa423d8ecc4bbe64ee70a2679cf0148c`；树`D:/hy-spec-lemma-create`，分支`codex/language-boundary-runtime-provider-plan-20261103`，开工clean。前U父域材料筹办代码`d0053997d`/main`eed55bed5`已实现、编译发布并正常退出计划；本叶不恢复它或PR11旧计划。

完成范围：现正式控制输出/普通出站队列→实际HTTP完整写出→页面显示携正式输出身份→用户显式选择/取消→本次接收请求携关联→外设同次记录M及回应引用→页面/重试读回真实关联。它仅证明用户选择回复哪条消息，不证明回答正确、正式询问目标、分界成立、语言已理解、子D/T满足或原工作恢复。

不交付：分界规则、结果保存/采用、语言选择独立schema、回答含义/原文对齐、询问本能/表达/发送治理、自动唤醒原M、需求种类实现、服务结算、跨进程恢复。顶层`GOAL-WEB-LANGUAGE-DEMAND-CLOSURE`仍活动；不得以本叶交付冒充完整问答闭环。

## 3. 身份与完整正常链

固定回复目标为正式**输出节点O（方向=输出）**，因为它是入列回执及后续询问发送消费者已有的稳定身份。正式发送节点S（方向=发送）记录实际HTTP完整写出的事实，并保存`对应输出消息=O`；两者不合并。

```text
既有正式控制输出/普通外设入列 → O/提交序号
 → 宿主领取实际O → HTTP完整写出
 → 外设记录S且显式引用O → 独立读回
 → 宿主追加已显示消息（携O），GET页面消息投影回传
 → 用户点选该条“回复”，输入框明确展示所选对象，可取消
 → 浏览器固定本次{正文,replyTo=O}后提交
 → 宿主核同页已显示O/完整写出，沿原路径分配本次上行序号
 → 外设核O/S及同窗口/会话，M与回应O同消息事务发布
 → 正式读回M/关联 → 原接收事实通知 → 页面投影/202
```

S的正式来源必须与O的会话、对话框、场景、窗口和提交序号核同，方向分别为发送/输出；正文相等只作一致性校验，不用于寻找或确定身份。旧发送S没有对应O引用仍可读，但不能因此成为本叶可选回复对象；新通道实际携O。没有完整写出、仅排队/已领取/取消/写出失败的O不得显示为可回复。

## 4. DTO、API与物理归属

### 4.1 外设领域及消息owner

`领域/消息交互.数据.h`在`新外设消息信息`末尾追加：

```cpp
std::optional<稳定编码> 回应消息节点{};       // 接收M -> 正式输出O
std::optional<稳定编码> 对应输出消息节点{};   // 发送S -> 正式输出O
```

两字段均不是来源键成分。普通输入为空；发送只可有对应输出，接收只可有回应，输出两者皆空。旧聚合构造末尾默认空，不把0当未指定。固定正文/材料/来源/时间和已经保存的两类引用都不可原地改义。

`业务/新_外设世界树类.h/.cpp`只扩原两个公开方法的末尾缺省参数：

```cpp
新外设事实状态 更新接收(const 新外设对话框定位&, std::uint64_t 来源序号,
    std::string_view 正文, const 新状态强时间&,
    std::optional<稳定编码> 回应输出消息={}) noexcept;
新外设事实状态 更新发送(const 新外设对话框定位&, std::uint64_t 来源序号,
    std::string_view 正文, const 新状态强时间&,
    std::optional<稳定编码> 对应输出消息={}) noexcept;
```

旧调用缺省行为不变。private原`记录消息`接收两项可选引用，按方向严格校验；复用现正式读口、来源查重、原子封存和F/S维护，不另建写入类。创建发送S时只核正式O、同窗口/会话/提交序号及本次真实HTTP完整写出凭据，再发布S→O，不要求S先存在；创建回应M时才核已经正式存在的S→O及同窗口/会话。正常不合法请求返回入口拒绝，正式结构损坏/工程错误走原工程诊断终止，不返回成功或正常未找到。

### 4.2 网页宿主和独立外设模块

`界面/宿主.网页对话.h`：`网页定向发送事实`末尾追加`std::uint64_t 正式输出消息编码=0;`；`网页对话已显示消息`末尾追加可选正式输出编码及回应输出编码。工程编码使用uint64传输，内部转稳定码前检查非零；所有JSON编码均十进制字符串，不经JavaScript Number。

`网页外设运行回调组::接收消息`及cpp私有别名统一追加`std::optional<std::uint64_t> 回应输出编码`参数，仍沿现bool接纳回执，false不代表正式事实成功。发送完成回调仍用同DTO。`装配.网页外设.cpp`两条实际lambda/实现同步传递可选回应/对应O：收到后调用原world更新，再按原正式来源读回核同全部本次字段；不得仅回true而漏关联。

宿主私有`追加页面消息/追加交互者消息`扩展所需可选值载荷；显示投影保留本次实际正文/原回应。它只是现传输投影，不是外设事实或独立等待/投递账；正式关联权威始终由world读取M。

### 4.3 HTTP与浏览器合同

保持`POST /api/messages`的非空UTF-8纯文本正文及`X-HY-Dialogue-Id`；仅新增可选`X-HY-Reply-To`（非零十进制O）。该头重复/格式错误时拒绝，不能当缺省吞掉。没有该头的请求保持原分配/普通输入语义，不新增clientId或客户端持久待投递包。

宿主仅允许reply引用当前会话、当前页面消息投影内已完整写出且role=self的O；不接受页面序号、S编码、其它页面/会话、正在发送或未来O。外设再独立复核O/S事实，不能把宿主投影当owner授权。

前端在本次提交handler开始时复制正文及当前选中O，HTTP在途期间仅按原提交按钮禁用防重复操作；不因之后改选而改变已提交请求。202后清除本次选中；请求失败保留当前可见输入/选择供用户处理，不自动重发，明确“未能确认接收；再次发送会成为新的实际输入”。刷新后未发送的选择可以清空，不凭最近消息恢复；已发布M的正式回应不变。页面GET消息回传实际`outputMessageId`及`replyTo`，缺省为null；正文用textContent，不注入HTML。

宿主沿原全局下一上行序号分配，每次真实POST接纳依原顺序通知/追加/增长；不按O或正文合并不同输入。world收到同一正式来源键的重投时，原正文/场景/窗口及可选回应必须精确相同才复用，异参不覆盖；这不等于两个HTTP请求自动拥有同一来源。未发布的输入错误返回4xx/正常拒绝，回调未接纳且零正式发布才可返回原503；已发布后工程失败不能伪装503可安全重发。网络响应未知不新增恢复协议，保留实际已发布事实并沿原网页交付语义报告。

## 5. 发布、引用及锁序

消息schema在原外设owner私有句柄尾追加`回应消息`和`对应输出消息`两键，保留既有索引0—11意义。新消息为原10字段加按方向至多1个可选稳定引用；旧10字段仍合法。禁止两个分支混用、重复字段、陌生字段或裸U64数组冒充引用。按同正式来源重投必须连正文、场景/窗口及可选引用精确相同；不同则不覆盖旧固定事实。

接收M的回应O、发送S的对应O均并入原`记录消息`封存片段，与本消息身份、根登记和当前消息集合一次组合发布，不在正文记录后补绑。被引用O只需本次最小正式身份/固定字段只读预期，不取得其入向全快照写资格；新增其它回复的指入引用不得让旧O输入漂移。原消息集合F/S、接收/发送正文及数量仍依现顺序完成，不声称全流程一次跨owner原子；中途失败保留已发生消息/集合/状态，走工程处理，不允许返回可重发否定掩盖已发表前缀。

原`读取正式消息`、`读取消息/保护/当前集合/完整接收记录/查找消息`沿相同私有解析返回真实可选字段；读取关联目标须核方向、同源和引用完整，不递归遍历任意回复链。owner仅读O/S的必要固定字段，不把其新入边作为本M正文一致性依据。

`读取分界消息正文`及语言cpp`核验分界消息端口`的10字段断言必须同步允许接收M的10或11字段，并与返回的可选回应存在性精确对应；只读五个既有端点及本M完整固定字段，不为回应O复制整组快照。`接收需求认知.服务.cpp::同消息`比较两项可选引用；仍只比较本M固定载荷，不把O/S新入边纳入旧源保护。模拟world原聚合构造末尾默认空，保持既有模拟无关联语义，不新增模拟schema或宣称其能模拟本叶回复。

真实O由消息根和本叶新稳定引用保活；移除当前接收/发送集合或输出队列只移除现集合引用，不删O/S/M或回应关系。会话结束/关闭模块清理页面目录和运行投影，但正式消息及其引用不被清空；不新增物理删除/TTL/回收授权。本叶不改不可变正文或旧消息，不新增跨进程持久恢复。

锁序保留现宿主短锁复制/核同→锁外外设回调→外设模块互斥→world外设互斥→既有领域/L1。宿主共享状态锁不能跨回调；队列操作互斥保持原领取/停止串行，不让接收路径反向取得它。HTTP单accept线程完成本请求，页面投影预留可能分配的容量后再发布事实；已发表后投影失败按现唯一最终工程边界终止并保留真实事实，不补造HTTP成功。关闭先停接纳、收束在途回调再撤销world借用，沿现join，不新建线程。
