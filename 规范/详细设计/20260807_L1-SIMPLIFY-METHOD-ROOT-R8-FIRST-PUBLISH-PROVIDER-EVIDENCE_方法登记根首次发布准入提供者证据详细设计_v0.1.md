## 2. 唯一目标与最大边界

新增唯一方法领域根：

```cpp
方法登记根首次发布准入提供者证据结果
L1方法登记根首次发布证据服务::形成方法登记根首次发布准入提供者证据(
    const 方法登记根首次发布准入提供者证据请求& 请求) const;
```

合法入口只做以下步骤：构造并调用 R7 恰一次；只有 R7 返回 `可首次发布` 才继续；从构造 R7
时使用的同一 `L1事实基座服务` 恰一次调用 P17 非阻塞完整快照；要求最终快照截止与 R7 截止、
R2 请求截止三者相等；从完整快照的当前节点、关系和值形成严格排序、无重复、逐项完整事实副本；
一次返回固定 provider 身份、调用计数、R7 准入材料、最终快照和写前事实集合。

允许调用方必须已经使用 R4 意图和 R5 最终键完成 P15 单键探测，并且只有 `未找到` 分支才能
调用本根。`同义已发布`、`异义冲突`、`待发布或隔离`、许可拒绝或坏探测结果的 R8 调用次数
必须为0。R8 不重复探测，也不接受调用方自报的“已探测”布尔值或可伪造许可令牌。

本叶当前只覆盖正常进程存活期间的内存权威。崩溃、异常终止、断电、重启、恢复导出和跨进程
恢复均不在范围内。正式日志仅供人读观察，不是身份、截止、准入或事实副本来源。


依赖方向固定：


R7、R6、P17、P15 和 L1 不得反向依赖 R8。R8 不是第二个准入所有者，也不是通用 L1 执行
证据服务。

## 6. 入口、R7 调用与状态映射

任何 provider 调用前验证：R8 合同/规则为 1；R7 请求、R4/R2 版本和规则合法；R2 预期事实
代次非零；R5 结果已形成且身份、`0x19` 域和低 56 位反解与 R4 公开身份一致。版本不匹配返回
`版本漂移`，字段非法返回 `入口拒绝`，已形成对象间自相矛盾返回 `内部不一致`；R7/P17 调用均为0。

合法入口用同一 `L1_` 构造临时 R7 服务并恰调用一次：

- `可首次发布`：必须截止非零、数量0、唯一候选为空，继续最终 P17；
- `唯一合法候选`：必须数量1且候选完整，映射 `已有登记根`，最终 P17 调用0；
- `多个候选` 或任一坏成功：映射 `内部不一致`；
- `事实截止漂移/许可拒绝/版本漂移/资源失败/内部不一致` 同名映射；
- R7 `入口拒绝` 在 R8 入口已经合法时映射 `内部不一致`；未知状态映射 `内部不一致`。

R7 内部 R6/P17 是 R8 的传递调用，不计作未来发布者的直接 provider。发布者只调用 R8 一次，
故成功凭证固定 `直接调用次数=1`、`去重后提供者见证数量=1`。

## 7. 最终快照、共同截止与事实集合

R7 可首次后，对同一 `L1_` 恰调用一次：

```cpp
L1_.尝试读取完整快照({L1事实基座合同版本});
```

许可拒绝、资源失败、内部不一致同名映射；入口拒绝映射版本漂移。成功必须携带完整快照；快照
事实代次必须等于 R7 截止及 R2 预期事实代次，否则返回事实截止漂移且凭证为空。不重试、不等待、
不跨 R7/P17 持锁。

最终快照必须满足 P17 的完整排序形状：当前节点、关系、值分别按稳定编码严格升序且无重复；
每项为当前有效完整事实，创建代次不晚于共同截止；永久占用编码严格升序且覆盖所有当前事实编码；
属性槽只由节点事实内部承载，不建立第二份槽见证。

写前集合机械形成：

1. 依次遍历全部当前节点，加入 `(节点, 编码)` 与同索引 `L1事实副本{节点事实}`；
2. 再遍历全部当前关系，加入 `(关系, 编码)` 与同索引完整关系副本；
3. 最后遍历全部当前值，加入 `(值, 编码)` 与同索引完整值副本；
4. 因快照各组已按编码升序，联合组天然按 `(种类, 身份)` 严格升序；不得截断、抽样、只取首项、
   只取 R2 将引用的事实或从永久占用编码补造事实；
5. 身份组、副本组和去重数量必须三者相等，每个副本对象种类与编码精确匹配同索引身份；
6. 当前节点、关系和值总数为0时返回 `事实材料不足`、截止保留为本次安全取得的共同截止、凭证空。

第6项不是空仓首次模式。R2/R7 明确要求非零截止，而当前 P15 `事实互证` 模式要求至少一个写前
事实见证；非零截止但全部当前事实为空时，R8 不得用永久占用、历史事实、默认 L1 身份或日志补造
非空见证。该状态只停止本次发布准备，不修改 R7 的零候选判断。

R8 不调用 `形成L1写前事实摘要`。后继只有在幂等探测未找到并决定形成首次请求时，才能逐项对
本凭证完整副本调用该公共原语，再转为最终 `L1写前事实见证`。
