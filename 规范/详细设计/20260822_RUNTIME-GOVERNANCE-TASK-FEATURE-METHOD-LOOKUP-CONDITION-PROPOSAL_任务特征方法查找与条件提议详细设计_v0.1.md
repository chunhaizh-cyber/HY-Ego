# 任务特征方法查找与条件提议详细设计 v0.2

日期：2026-08-22

身份：`RUNTIME-GOVERNANCE-TASK-FEATURE-METHOD-LOOKUP-CONDITION-PROPOSAL`
状态：现行详细设计；解释 3100 v0.7、3200 v0.7、3300 v0.7、4270 v0.3、5090 v0.3、5230 v0.8、5250 v0.7、5330 v0.4；不单独建立机器事实

## 1. 目标和完成边界

本设计形成当前最早可独立施工的只读代码叶：消费一份已经由同一任务`目标未达成`裁决和`目标未达成待重筹办`状态共同形成的合法`下一筹办工作包`，在迁移后的同一事实截止重新读取并互证任务目标与当前事实，按目标特征类型查找方法，判断效果兼容；只有唯一可采用方案时读取该方法自己的条件、输入规格和限制，并形成零个或多个缺失条件草案。

本叶完成不等于当前就绪、当前路径、实例方法或执行冻结。它不写任务、需求树、方法、路径、实例、状态、概念或其它机器事实，也不接`任务管理线程`。

请求有效性同时要求：合同版本正确、`下一筹办工作包完整`、全部八项预算非零、`请求头.期望事实代次 == 工作包.迁移后事实代次`，且映射到`std::size_t`的概念预算不溢出。本接口没有历史读取开关；它只在迁移后的当前截止 G 复核，DATA-L2 粗召回自身的历史 ABI 由专项测试单独覆盖。

`成功()`只校验结果对象自身可取得的内在守恒：状态为`已评估`、结论与`已互证工作包`存在、共同事实截止非零且等于`已互证工作包.迁移后事实代次`，并满足各结论对应载荷守恒。它不访问原请求，也不比较对象外的 G。provider 构造结果的后置条件另行固定为：任一`已评估`结果的`已互证工作包 == 请求.工作包`，且`共同事实截止 == 请求.请求头.期望事实代次 == 请求.工作包.迁移后事实代次`；该后置条件由根函数专项测试证明。所有非`已评估`状态必须把结论、工作包、任务目标、当前状态、比较、方向、概念、粗召回、不兼容证据、候选、缺口、采用方案、输入规格、限制、未绑定证据和草案全部清空，并把共同截止、允许关系位和扫描计数置零。

输入规格 / 限制的内在载荷守恒固定为：每个绑定项保留完整方法事实中的原身份和原语义；作用对象角色等于采用方案主轴结果角色时必须且只能绑定`任务目标.目标宿主`并且没有同项未绑定证据，角色不等时绑定必须为空且必须存在同身份、同角色、同类别的唯一未绑定证据。条件类未绑定证据仍按条件身份执行同样的角色分账。

缺失条件草案只是交需求统一入口的值式草案，不是需求事实。`绑定目标存在`仅在条件角色等于主轴结果角色时取任务目标宿主；其它角色不形成草案并进入`已采用且输入限制待绑定`，不得用空身份表达“待绑定”。

### 5.1 预算映射与无预算 ABI 边界

| Provider 字段 | 被调接口映射 | 性质与失败 |
| --- | --- | --- |
| `最大扫描用途事实数` | `L2方法特征粗召回请求.最大扫描用途事实数` | DATA-L2 真扫描预算；不足映射`数量预算不足`。 |
| `最大粗召回方法数` | `L2方法特征粗召回请求.最大粗召回方法数` | DATA-L2 真候选预算；不足映射`数量预算不足`。 |
| `最大概念支持扫描事实数` | `L2按世界事实支持概念组读取请求.扫描预算` | 目标宿主支持关系反查的真扫描预算。 |
| `最大概念支持关系数` | 同请求`.数量预算` | 支持关系返回数量预算。 |
| `最大概念祖先关系数` | 每次`L2概念直接上位组读取请求.数量预算`取“全局剩余预算”；累计每条去重直接上位边 | 服务有数量预算但无独立扫描预算；全局累计超限整项`数量预算不足`。 |
| `最大主体状态数` | `L2按主体当前状态读取请求.最大数量` | DATA-L2 数量预算。 |
| `最大场景成员数` | `读取存在当前场景成员引用`成功后的`引用.size()`上限 | 现行场景反读请求没有预算字段，也没有已登记硬上限；它不是扫描预算。超限时 provider 丢弃载荷并返回`数量预算不足`，本叶不改变场景 ABI。 |
| `最大方法条件数` | 唯一采用方法`读取普通方法`成功后，与主轴结果关联的条件数 + 关联 / 方法级输入规格数 + 关联 / 方法级限制条件数的总上限 | `读取普通方法`和`读取方法六项静态能力投影组`均无预算字段，也没有方法内已登记硬上限；该字段只是调用后结果上限。超限整项`数量预算不足`，本叶不改变方法完整读取 ABI。 |

不得再宣称“所有扫描都有调用方预算”。场景成员和方法完整 / 投影读取在本叶只能受成功后结果上限约束；若未来要求底层扫描前限流，必须另立 DATA-L2 ABI 计划，不能在本计划临场扩张。

### 5.2 逻辑结论载荷守恒

所有九种`已评估`结论共同必须携带：G、完整`已互证工作包`、任务目标三元组、完整当前实际状态、目标比较具名关系和允许关系位；不适用字段必须为空。

| 结论 | 额外必需载荷 | 明确禁止载荷 |
| --- | --- | --- |
| `所需方向不唯一` | 当前状态、比较未命中且允许低 / 高双向 | 所需方向、概念、粗召回、候选、采用、草案 |
| `对象概念待形成` | 唯一所需方向；当前对象概念与闭包均为空 | 粗召回、候选、采用、草案 |
| `方法能力缺失` | 唯一方向、非空概念 / 存在根闭包、`完整粗召回`存在且为空、扫描计数完整 | 不兼容证据、候选、采用、草案 |
| `当前无适用方法` | `完整粗召回`存在且非空；每份可投影主轴结果均有稳定不兼容证据；适用候选为空、结构缺口为空 | 采用、草案 |
| `方法结构待补齐` | 完整粗召回非空、适用候选为空、结构缺口非空；可同时保留已完成项的不兼容证据 | 采用、草案 |
| `多候选待选择证据` | 完整粗召回非空、适用候选至少两份；不兼容证据和结构缺口可保留 | 采用、未绑定、草案 |
| `已采用且无需条件提议` | 完整粗召回、适用候选恰一、采用方案相同、采用方法输入 / 限制原样返回 | 未绑定、草案 |
| `已采用且存在缺失条件` | 同上且缺失条件草案非空；若同时存在未绑定材料也必须保留 | 无 |
| `已采用且输入限制待绑定` | 同上、草案为空、未绑定输入限制非空 | 草案 |

稳定顺序固定为：粗召回按方法 / 用途；不兼容证据与候选按方法 / 主轴结果 / 用途；结构缺口按方法 / 缺口类型 / 条件 / 结果；输入规格绑定项按输入规格身份 / 顺序，限制绑定项按限制身份 / 顺序，未绑定证据按类别 / 角色 / 对应身份；草案按方法 / 主轴结果 / 条件。稳定顺序不表达优劣。

```cpp
        const 任务特征方法查找请求& 请求) const noexcept;
};
```

构造函数按引用接收`L2任务结构服务`、`L2需求结构服务`、`L2状态结构服务`、`L2特征结构服务`、`L2概念结构服务`、`L2场景结构服务`和`L2方法结构服务`；提供者不可复制移动，不拥有这些服务。

## 7. 固定算法

1. 校验请求、工作包和`期望事实代次 == 迁移后事实代次`。
2. 在 G 调用`L2任务结构服务::读取任务`取得任务；来源只取真实字段`L2任务事实.需求列表项`，再调用`L2需求结构服务::读取需求列表项完整`取得目标三元组。不得使用不存在的`任务.目标来源`。
3. 在 G 调用`按任务与执行轮次读取实际结果`与`读取任务治理状态`，互证工作包的任务、旧执行轮次、旧实际结果、正式待重筹办状态及旧路径 / 实例绑定；还必须互证治理状态和正式裁决材料均为`目标未达成`，裁决后继为`目标未达成待重筹办`。旧实际结果只提供`实际状态`身份；必须再调用`L2状态结构服务::读取完整状态({G, 当前, 实际结果.实际状态})`取得完整状态节点，并通过`读取完整特征实例`互证主体为目标宿主、特征定义为目标特征。该状态及其特征实例在固定 G 返回`未找到/已退出/属性未设置`表示合法工作包引用链矛盾，统一返回`引用冲突`且零载荷；不得降格为业务等待，也不得直接消费身份或旧缓存值。
4. 读取目标状态合同和其目标判断比较注册，以完整当前状态精确值为左、合同目标值为右调用一次`比较特征`。重算具名关系和允许关系位必须与正式未达成裁决证据完全一致且关系不得命中允许位；任一不一致或命中均返回`引用冲突`且零载荷。互证通过后：低于→正方向，高于→负方向，达到而仅允许低于→负方向、仅允许高于→正方向、同时允许低于和高于→`所需方向不唯一`。
5. 调用`按角色读取当前概念本体根({G, 存在})`固定存在根，再以`最大概念支持扫描事实数/最大概念支持关系数`调用`按世界事实读取概念支持关系组`。零支持返回`对象概念待形成`。
6. 对每个支持概念先与存在根身份比较：等于存在根时直接加入“当前对象概念→存在根”闭包，不调用`读取普通概念`；不等于根时才读取普通概念，要求其本体根归属为同一存在根，再以全局剩余`最大概念祖先关系数`调用`读取概念直接上位关系组`逐层展开。根直达、普通概念、多父、去重均合法；错根、退出、环、重复冲突或预算不足不得部分成功。
7. 调用`按特征读取方法用途粗召回组`并把成功结果完整保存到`完整粗召回`。完整空只返回`方法能力缺失`。
8. 按方法去重后逐方法调用无预算 ABI `读取方法六项静态能力投影组`。对每份主轴结果逐项记录角色、对象、方向、结果种类 / 合同不兼容原因；满足全部条件才形成适用候选。动态概念结果记录`结果类型不是目标状态合同`，不得冒充状态合同。
9. 若适用候选为空：存在结构缺口返回`方法结构待补齐`；否则返回`当前无适用方法`，且必须保留完整粗召回和逐候选不兼容证据。结构缺口、不兼容证据和候选分别稳定排序；任何一类都不得被另一类吞并。
10. 多于一份适用候选且本叶没有正式比较选择证据时返回`多候选待选择证据`，保留完整候选与前述证据，不采用、不提条件。
11. 恰一份适用候选时标记为采用方案，再调用无预算 ABI `读取普通方法({G, 当前, 方法})`，互证内容版本、规格版本、主轴结果、匹配用途及条件结果关系。只有该主轴结果关联条件以及方法级 / 关联条件级输入规格和限制进入后续；其数量总和超过`最大方法条件数`时整项`数量预算不足`且零载荷。
12. 从完整方法事实把方法级及主轴结果关联的输入规格、限制条件身份与语义分别原样复制到`任务输入规格绑定项/任务限制条件绑定项`。每项只采用与条件相同的唯一绑定规则：`语义.作用对象角色 == 采用方案所指主轴结果的作用对象角色`时，`绑定目标存在 = 任务目标.目标宿主`；否则`绑定目标存在`为空，并形成同身份、同角色、对应类别的具名`未绑定输入限制`。不得使用其它角色映射、猜对象、丢弃材料或冒充已满足。
13. 条件作用对象角色等于主轴结果角色时绑定目标宿主；其它角色形成`类别=条件`的具名`未绑定输入限制`。已绑定状态条件通过`按主体读取全部当前状态`后逐项`读取完整特征实例`筛选条件特征：零份匹配状态只表示条件未满足并形成草案，一份继续读取目标状态合同和正式比较，多份同特征当前状态形成`引用冲突`；不得把空组或零匹配送入不存在的状态读取。
14. 有场景约束时调用无预算 ABI `读取存在当前场景成员引用`；成功载荷超过`最大场景成员数`时整项`数量预算不足`，否则按场景身份复核。无场景约束不得调用场景反读。暂缺的条件当前状态、零匹配状态或场景成员只表示条件未满足，不是 provider 错误。
15. 未满足的已绑定条件从完整方法事实形成缺失条件草案；满足条件不形成草案。输入规格和限制已按第 12 步原样返回，不在本叶冒充已绑定或已满足。
16. 有草案返回`已采用且存在缺失条件`并同时保留未绑定证据；无草案但有未绑定证据返回`已采用且输入限制待绑定`；二者都没有返回`已采用且无需条件提议`。三者均不表示当前就绪。

## 8. 当前性和错误

- 所有读取固定 G；任一结果截止不是 G 或首末当前事实代次变化，整项`当前性漂移`且零载荷。
- 被调 DATA 读取状态固定映射如下，执行者不得自行合并：

| DATA 状态 | Provider 映射 |
| --- | --- |
| `已读取`且合同、截止、载荷守恒 | 继续；其它成功态`已提交/精确重复`出现在只读调用时为`内部错误`。 |
| `数量预算不足` | `数量预算不足`，零载荷。 |
| `事实代次漂移` | `当前性漂移`，零载荷。 |
| `入口拒绝`、`许可拒绝` | `入口拒绝`，零载荷。 |
| `资源失败` | `资源失败`，零载荷。 |
| `引用冲突`、`幂等冲突` | `引用冲突`，零载荷；只读链出现幂等冲突仍表示引用 / 合同矛盾。 |
| `未实现`、`内部不一致` | `内部错误`，零载荷。 |
| `未找到`、`已退出`、`属性未设置` | 工作包引用的目标实际状态及其特征实例、工作包任务、来源列表项、旧结果、治理状态、目标合同、概念支持所引用概念、方法 / 投影或条件合同出现时均为`引用冲突`；采用方法条件的当前状态或场景成员缺失只表示条件未满足。 |

- 零概念支持只形成`对象概念待形成`；概念环、错根、同身份复义、用途结果复义和重复当前状态形成`引用冲突`，不降格为空候选。
- 仅方法用途、概念支持、概念直接上位和主体状态服务具有本叶可传入预算；场景成员和方法完整 / 投影读取按 §5.1 仅做调用后上限检查。任一真实预算或结果上限不足整项失败，不返回截断候选。
- `bad_alloc`、`length_error`映射资源失败；其它异常映射内部错误。
- 函数和全部被调服务在本叶均零机器事实写入。

## 10. 验证矩阵

- 任务只经`任务.需求列表项`读来源；旧实际结果经`实际状态`身份再读取完整状态与特征实例；不存在`任务.目标来源`调用点。
- 合法工作包的目标当前状态与特征实例完整读回；低于 / 达到 / 高于以及达到但允许仅低 / 仅高 / 双向时的方向分流；重算关系 / 允许位必须与正式未达成裁决一致且不命中允许位。
- 特征粗召回零 / 一 / 多方法；多个用途；当前 / 历史；两类预算不足。
- 对象零 / 单 / 多概念；支持概念就是存在本体根时不读取普通概念；普通概念祖先与存在根兼容；错根 / 退出 / 环；不猜默认概念。
- 对象、方向、结果合同分别不兼容；动态概念结果不冒充状态合同。
- 粗召回空的`方法能力缺失`、粗召回非空全不适用的`当前无适用方法`、结构缺口分账；后两者保留完整证据。
- 单适用候选采用；多候选无选择证据不采用且零草案；稳定编码不作优劣。
- 条件当前状态组为空、组非空但零特征匹配、恰一匹配、多份同特征当前状态；条件满足 / 不满足 / 缺事实 / 场景不满足 / 角色未绑定；草案只来自采用方法。
- 输入规格、限制条件从完整采用方法原样复制身份与语义；作用对象角色等于主轴结果角色时必须绑定任务目标宿主，否则绑定为空并形成对应类别的具名未绑定证据；逐项验证身份、语义、绑定和证据守恒，但不证明规格或限制已经满足。
- `方法能力缺失`和`当前无适用方法`只作为本叶结构化判断结果：前者是否进入学习由后继正式学习门禁裁决，后者不得进入学习；本叶不生产学习需求。
- `成功()`只校验结果内在守恒；provider 的请求工作包 / G 后置条件由专项测试独立证明。
- 概念支持扫描 / 数量、祖先关系、主体状态真预算分别不足；场景成员和方法关联材料调用后结果上限分别不足；后两者不伪装成底层扫描预算。
- 九种合法逻辑结论逐项动态验证 required / forbidden 载荷；所有非`已评估`状态零载荷；穷尽 L2 结构状态映射。
- `目标已完成`和`目标当前事实待形成`不再属于本 provider DTO。目标事实在 G 后变化由真实公开路径动态覆盖`当前性漂移`；固定 G 内目标状态 / 特征实例缺失或重算目标命中只按防御源码分支与零载荷守恒静态穷尽，若没有合法公开注入路径则在验证记录具名记`NOT_RUN`，不得伪造工作包或绕过生产链取得动态 PASS。
- 条件回流后方法版本或事实变化导致重新评估，不复用旧结论。
- 旧四元组粗召回、旧任务六项请求和`读取匹配候选`调用点为零。
- 提供者经普通应用 getter 可取得；全链零写。
