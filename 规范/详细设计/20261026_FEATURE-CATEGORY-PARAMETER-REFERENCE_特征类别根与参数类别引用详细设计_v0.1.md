## 1. 目标、职责与明确排除

正式“特征”类别概念Fcat由现`概念_特征类`唯一维护，没有统一材料/单位/数值域；根链FT自身仍是具体特征类型身份。通过Fcat投影旧FT组织与分类，不能把裸组织根冒充概念，也不能在旧树增加第二父边。

有序Vm规格及直接调用参数记录的新写类别使用“存在/特征”正式根概念引用；旧整数1/2只作为旧材料技术解码。公有`新方法有序参数规格`及`新方法有序参数引用`暂保留枚举技术投影，不把该枚举当第二概念仓；本叶不声明全部信息类型的参数ABI完成。

本叶为方法结构/类别定义治理，不改变现实对象特征值，不执行方法动作、不生成C/R或统计。沿5350第6节、5360第2—3节、7165统一概念语义；7160旧“概念”默认指有材料的单特征概念，保留其全部值域单父合同，不能将新类别根强塞入旧值域类型。用户已批准的类别概念统一覆盖本具名扩展，不修改正式规范。

不改D/T/M实例及普通存在读写，不迁移已有方法固定规格或历史调用，不改任务消费者、模拟算法、动作定义参数持久格式、自然语言语义解析或本能业务逻辑。`概念_动态类.cpp`中的动作参数类型仍按原合同保存，本叶不半迁移该链。广义参数ABI、其他类别根与全语言查询属于路线，不登记后继库存。

## 3. Fcat唯一身份与公共合同

物理组织根上新增单引用`特征类别根登记字段`，指向恰一新节点类型`特征类别根节点类型`的R。R只含恰一类型字段和零到多名称关系；禁止材料/值域/单位/比较/聚合/实例计数等FT字段。R无外部父子边，不放入旧FT树；唯一owner登记及完整定义赋予其“所有合法特征信息的类别”语义，不靠名字或非零编码。

schema键由现特征概念初始化建立并纳入完整性/互异检查。新根允许零FT、零实例、零名称形成。根登记缺失时可原子建立R、类型字段与登记；已登记只完整同义复用，重复登记、多类型、错引用或未知字段不另建根。无旧类别根可自动接管：当前旧裸组织根和名叫“特征”的普通FT一律不是候选。

新增公共类型/方法均在`领域/概念_特征类.h`，定义在同名cpp：

```cpp
struct 特征类别根信息 final {
    稳定编码 节点;
    std::vector<稳定编码> 名称关系;
};
struct 特征类别根读取结果 final {
    正式概念读取状态 状态=正式概念读取状态::非本提供者概念;
    std::optional<特征类别根信息> 信息;
    std::vector<基础联合节点快照> 完整保护组;
};
特征概念编码操作结果 建立或取得特征类别根概念() noexcept;
特征类别根读取结果 读取特征类别根概念保护() const noexcept;

struct 特征分类关系信息 final {
    稳定编码 概念节点;
    bool 是类别根=false;
    std::vector<稳定编码> 直接上位概念组, 直接下位概念组;
};
struct 特征分类关系保护结果 final {
    特征概念规则状态 状态=特征概念规则状态::入口拒绝;
    std::optional<特征分类关系信息> 信息;
    std::vector<基础联合节点快照> 完整保护组;
};
特征分类关系保护结果 读取特征分类关系保护(稳定编码) const noexcept;
```

建立返回已完成或无变化及同一根编码，前提变化/依赖未装配沿现状态；已确认根结构损坏走现工程故障链，不返回假未找到。根读取未登记无载荷，未初始化依赖未就绪，前提变化零信息；正式成功含根及完整保护。共享正式身份reader为R返回身份证明，但不通过普通FT定义保护来解码R。

根身份读取只核登记、根本身、schema与其名称引用的完整快照，**不枚举全部FT**；保持随概念数量不增长的根定位成本（名称数按本根实际内容）。分类列表是独立按需读取，禁止将其藏在每个参数类别解码中。

## 4. 分类投影和旧值域安全

`读取特征分类关系保护(R)`返回无父、旧`特征概念树`直接普通FT子节点作为下位；`读取特征分类关系保护(C)`对普通FT概念，若其物理父是裸组织根则投影语义父R，其他情况投影原FT父；下位仍为原FT直接子。只读投影不写任何新FT父边，不维护FT集合镜像、计数或缓存权威。

读取应完整核物理单父、组织端点和类别根登记，根链多父、环、错误FT端点不按去重掩盖；以活动/完成集合分开环和汇合，并在同一捕获范围联合重核。根视图枚举FT根时覆盖裸根完整出边和每个FT定义，若混入不应在旧树的元节点则工程错误。合法空FT组成功，资源/读取故障不冒充空组。

旧`是特征概念节点(R)`必须仍false，`获取特征概念(R)`不返回伪FT。值域比较、类型根定位、实例特征建立、按值采样和引用次数增减均不得接收R；正式概念身份成立不等于可作为某个FT或准确值域。本叶不把Fcat注册为先天FT槽，不增加实例引用次数，不进入FT零引用叶删除。根锚定与参数单引用通过现基础字段/快照引用闭合保持，不新增通用强引用系统或删除入口。

## 5. 名称服务完整接纳

在名称cpp私有`概念类别`新增`特征类别根`分支，受控识别仅在`读取特征类别根概念保护`已成功且节点等于被识别对象时成立。不能让`是特征概念节点`返回真，也不把R交存在正式结构读取器取得假成功。

Fcat命名发生在D/T/M正式定义schema就绪之前：识别器必须先接受本FT owner已经正式证明的受控根，不得被现“不是普通FT/存在且正式结构依赖未就绪”早退挡住。此路径不要求为了命名Fcat先初始化三类定义。名称局部核验只核本次目标及现接口要求的关联材料，不恢复全名全集重核。

`识别概念类别`、`概念持有关系`、普通名称完整核验/恢复、建立参与和删除参与必须同次支持R。根名称列表来自根DTO；既有friend私有`绑定名称关系/解除名称关系`增加受控根路径或等价私有helper，但对普通FT原逻辑不变。只改名称cpp和特征h/cpp，不新增名称公开DTO。

名字“特征”由app使用现词条/名称服务建立并正式读回。若词条已有不同目标可作多义候选，但app不能据它接管普通FT为类别根，也不能依名称改变参数类型。app最终核新关系确实指R；命名失败保留根，不再建第二根。名称不参与根身份相等或类别判定，名称删除不删除根。现名称索引、局部核验和跨owner锁顺序保留，不能因新增类别回到“每加一名全量扫描”。

## 6. 参数持久格式与技术投影

方法cpp新增`有序参数类别概念字段`；直接调用结构另新增`直接调用类别概念字段`，二者为节点引用字段，不复用旧I64字段名悄改材料类型。范围字段仍原字段。

| 对象 | 旧合法读取 | 新普通写入 |
| --- | --- | --- |
| Vm有序规格 | 序号＋旧I64类型1/2＋范围概念；无新类别字段 | 序号＋类别根概念引用＋范围概念；无旧I64类型字段 |
| 直接调用参数 | 序号＋旧I64类型1/2＋实际引用；无新类别字段 | 序号＋类别根概念引用＋实际引用；无旧I64类型字段 |

新/旧类型字段恰一出现且单值；双写、全缺、错材料、无序号却有类别字段均为结构错误。新类别引用只允许存在owner唯一语义根Rexist或本owner Fcat，读取两owner根证明后比较身份，不按名称、概念编码范围或节点有某字段猜测。当前只支持两种类别，未知正式类别不能回退旧enum或普通存在解码。

公有DTO本叶不加字段：从新持久引用正式解析出存在/特征技术派发hint，旧I64读者按固定旧表得到同hint。函数请求当前hint经owner唯一根映射后存储；持久新类别引用是正式来源，hint只作现C++服务分派。范围、顺序、数量、参数位置和实例身份继续原合同，重复登记完整DTO同义可复用旧规格，无物理迁移或规格改义。新引用格式不授权存在参数直接接D/T/M结构概念范围，现普通范围能力限制保持。

方法cpp匿名命名空间新增公共入口无关的私有类别解析/保护函数，以下完整合同冻结：

```cpp
struct 参数类别概念保护 final {
    新方法参数信息类型 分派类型;
    稳定编码 类别概念;
    std::vector<基础联合节点快照> 完整保护组;
};
参数类别概念保护 读取参数类别概念保护(
    新方法参数信息类型, const 概念_存在类&, const 概念_特征类&);
参数类别概念保护 解析参数类别概念保护(
    稳定编码, const 概念_存在类&, const 概念_特征类&);
```

这两个helper分别用于技术请求映射和新持久引用解码，必须共享同一根准入，不能各写独立名称/枚举判断。依赖未就绪、前提变化及工程错误沿所在公开入口原映射，不伪造业务条件不足；根变化时不得继续使用旧hint完成新写。

## 7. 读写、复制、补齐与保护全链

方法schema键初始化、互异集合、`方法复制字段规格`、`读取参数规格`、`写入参数规格`、`读取方法信息`及所有直接调用参数读写接入新字段。`读取参数规格`私有签名增加存在概念owner引用，由现`读取方法信息`调用方传入；不从全局名称表获取根。

写入Vm之前取得类别根完整证明，并将根登记/schema/节点加入现方法发表/封存片段的CAS预期；新字段作为**外部引用**复制，禁止将根内化为方法owned子节点。`核验方法发表定义`（现保护组准备逻辑）、执行结构闭包及补齐候选的完整方法保护必须保留类别根证明；只有定义/ID读取不够。新直接调用发布也将类别根证明加入原子请求，读回按新字段还原同样的参数组，不改实际存在/特征准入和场景权限。

纯创建和已有非空规格的分工：全新方法登记、重建新代方法规格及全新direct调用使用新字段；重复登记旧方法只按同义DTO复用，不追加新类别字段。初始条件补齐不得趁机改已有规格。无序旧角色规格不改，旧I64范围/参数数目/顺序/历史执行不变。

历史保真复制/克隆/已有图组合允许原样复制旧I64字段，源节点零写；新引用格式按外部引用复制相同类别根。这个例外保证原复制完整同形状和读回签名不被“顺手迁移”破坏，不将“新普通写”外推成对历史保真复制的强制转码。混合新旧方法读回为相同语义DTO，各参数字段仍独立二选一，不能一个参数双写。复制原先完整节点、父代/来源和保护重核保持；本叶不实现全库类型字段替换或物理删除。

类别根不由方法持有所有权，不增加根的普通实例引用次数。方法退出/私有失败回滚只删除自有参数字段，不清理共享类别根；根登记无解除/删除入口。现普通值域FT可能有独立引用清理合同，不能把该计数算法套到Fcat。基础完整快照保存新引用及schema是现恢复承载，不能承诺尚未运行的跨进程恢复已通过。
