版本：v0.1
日期：20260821

状态：历史形成材料。目标裁决证据节点、同写集证明关系、任务 owner 私有治理状态及其生产 / 恢复语义均已由 `20260831_COGNITIVE-EVIDENCE-BOUNDARY_认知证据与工程正确性分界详细设计_v0.2.md` 覆盖并退出；当前任务主阶段 / 业务状态只由 ARCH-L2 通用特征、状态、动态承载，不得从本文件恢复第二状态权威或自动重筹办。

## 1. 目标与完成边界

本叶为任务 owner 增加一组 DATA-L2 纯结构能力：

```text
已经形成的任务目标达成裁决值式快照
→ 原子登记正式目标裁决证据与“执行结果待验证”治理状态
→ 目标未达成时，以同一正式裁决证据推进到“目标未达成待重筹办”
→ 当前、历史、精确重复和异义冲突均可正式读回
```

DATA-L2 只保存、校验引用形状、幂等、代次、事务和读回，不执行目标比较，不判断路径验证，不启动重新筹办。调用方只能是后继 DATA 外任务生命周期业务 provider；自我线程不得直接调用本结构入口。

本叶不实现：

```text
路径验证或任务完成
目标比较算法
自我线程生产消费接线
旧路径、旧实例和旧执行冻结的业务退出
新筹办轮次、方法召回或新实例
需求满足、结算、价值、安全值、服务值、学习和跨进程恢复
```

## 3. 所有权与状态模型

### 3.1 唯一 owner

新增事实全部归现有 `L2任务结构服务`：

```text
任务目标裁决证据节点
任务治理状态节点
任务到当前治理状态关系 14
治理状态迁移证据关系 15
目标裁决证据和治理状态的正式当前/历史读回
```

这里的 owner 只表示结构 CRUD owner。DATA-L2 不解释比较关系是否意味着达成，不判断裁决真实性，也不决定后继。DATA 外业务 provider 负责把正式 BIZ 裁决快照逐字段映射为本设计请求，并选择专用入口。

任务治理状态不是世界 `L2状态身份`，主体是同一任务独占的 `L2任务虚拟存在身份`。不得修改或复用 `L2状态结构服务`、`L2动态结构服务`。

`L2任务目标裁决结构材料` 与当前 BIZ 裁决快照逐字段同构，但属于 DATA 头自己的结构合同：

```cpp
    L2任务身份 任务;
    L2实例方法身份 实例方法;
    std::uint64_t 执行轮次 = 0;
    L2任务实际结果身份 任务实际结果;
    L2需求列表项身份 任务目标来源;
    L2存在身份 目标宿主;
    L2特征定义身份 目标特征;
    L2目标状态合同身份 目标状态合同;
    L2状态身份 实际状态;
    L2动态身份 动态证据;
    L2方法身份 方法;
    稳定编码 路径预期结果;
    稳定编码 路径验证合同;
    L2特征比较注册身份 比较注册;
    std::uint32_t 比较算法版本 = 0;
    L2特征比较具名关系 具名关系 =
        L2特征比较具名关系::当前达到目标;
    std::uint8_t 允许关系位 = 0;
    L2任务目标达成状态 目标达成状态 =
        L2任务目标达成状态::未达成;
    L2任务目标裁决后继准备 后继准备 =
        L2任务目标裁决后继准备::目标未达成待重筹办;
    std::uint64_t 来源共同事实截止 = 0;

```

固定组合只有两种：

```text
目标达成状态=已达成  + 后继准备=待验证后完成
目标达成状态=未达成  + 后继准备=目标未达成待重筹办
```

`L2任务目标裁决证据事实` 精确字段为：证据身份、上述完整材料和 `L2生命周期`。证据是任务 owner 内的正式结构事实；它不创建第二比较算法，也不替代来源目标、实际状态、动态或比较注册。

### 3.4 任务治理状态事实

`L2任务治理状态事实` 精确字段：

```text
身份
任务
任务虚拟存在
运行场景
生命周期发生时间（I64，非零）
生命周期版本（关系 14 的顺序号，从 1 连续递增）
业务状态段
重新触发状态
执行冻结当前性
方法运行当前性
执行结果类型
目标达成状态
本轮推进状态
验证裁决状态
结果当前性
前一治理状态（首态为空，迁移态唯一非空）
来源方法路径
来源实例方法
来源执行轮次
来源任务实际结果
目标裁决证据
来源共同事实截止
生命周期
```

两个状态的固定完整组合：

| 字段 | 执行结果待验证 | 目标未达成待重筹办 |
| --- | --- | --- |
| 生命周期版本 | 1，且任务此前无关系 14 当前项 | 前态版本 + 1 |
| 重新触发 | 未触发 | 已触发 |
| 执行冻结当前性 | 当前 | 已失效 |
| 方法运行当前性 | 已结束 | 已结束 |
| 执行结果类型 | 产生可比较结果 | 产生可比较结果 |
| 目标达成状态 | 取正式裁决证据 | 固定未达成 |
| 本轮推进状态 | 未裁决 | 未裁决 |
| 验证裁决状态 | 未验证 | 未验证 |
| 结果当前性 | 当前 | 当前 |
| 前一治理状态 | 空 | 唯一当前“执行结果待验证”状态 |
| 目标裁决证据 | 新建并绑定 | 与前态相同，不复制第二证据 |

状态段名称不得替代这些字段；读取结果只有在全部字段、关系和值同时闭合时才成功。

## 4. 关系合同

### 4.1 关系 14

任务生命周期关系类型 14 的结构映射：

```text
源：任务
目标：任务治理状态
角色或顺序：生命周期版本，从 1 连续递增
基数：同一任务同一截止恰一条有效当前关系
```

首态要求任务没有当前关系 14，写入版本 1。迁移要求请求前态就是唯一当前目标，原子退出旧关系并写入版本 `前态版本 + 1`；不得由时间戳或节点数量推算版本。

### 4.2 关系 15

每个治理状态都形成关系类型 15 的 40—44 五条证据，45—46 为零：

| 角色 | 目标 | 互证 |
| ---: | --- | --- |
| 40 来源任务 | 请求任务节点 | 与状态任务、裁决材料任务相同 |
| 41 来源方法 | 正式实际结果的方法节点 | 与路径来源方法相同 |
| 42 来源动作 | 与角色 41 相同的方法节点 | 动作入口仍由正式实际结果与路径材料逐字段互证 |
| 43 来源状态 | 正式实际结果的实际状态节点 | 与裁决材料实际状态相同 |
| 44 来源动态 | 正式实际结果的动态节点 | 与裁决材料动态证据相同 |

角色 42 不得指向动作入口节点。5210 §8 明确其允许目标类型是方法；动作入口身份通过“正式实际结果.动作入口 == 当前路径.完整路径材料.动作入口”复核，不改变关系 15 端点类型。

### 4.3 其它结构关系

任务治理状态节点还必须具备：族归属、任务虚拟存在、运行场景、前态（迁移时）、来源路径、来源实例、来源实际结果和目标裁决证据关系。

目标裁决证据节点还必须具备：族归属、任务、实例、实际结果、目标来源列表项、目标宿主、目标特征、目标状态合同、实际状态、动态、方法和比较注册关系。每类恰一条；关系端点不存在时由 L1 引用检查拒绝，DATA-L2 仍必须逐字段互证任务 owner 内可读来源。

## 7. 两笔写入与代次顺序

代次精确区分为：

```text
Gc：BIZ 目标裁决使用并冻结的来源共同事实截止；也是首态写前期望代次
Gs：首态与正式目标裁决证据原子发布后的返回代次
Gr：目标未达成迁移原子发布后的返回代次
```

固定顺序：

```text
Gc --首态写入--> Gs --目标未达成迁移--> Gr
```

不得假定 `Gs = Gc + 1` 或 `Gr = Gs + 1`。裁决证据永久保留来源截止 `Gc`；迁移请求以 `Gs` 写入，但不得把裁决证据截止改写为 `Gs`。

### 7.1 首态原子写集

首态写集同时形成：

```text
治理状态节点（版本1）
目标裁决证据节点
任务到状态关系14（顺序1）
状态关系15（40—44）
状态和证据的全部引用关系
发生时间、治理状态材料、目标裁决材料和值槽
```

写前按 `Gc` 逐项读取任务、虚拟存在、路径、实例、实际结果和当前路径，并互证完整裁决材料。任务已有关系 14 当前项时拒绝首态写入。

### 7.2 目标未达成迁移写集

迁移写集同时形成：

```text
新治理状态节点
新关系14（前态版本+1）
新关系15（40—44）
新状态引用、发生时间和治理状态材料
退出旧关系14
```

目标裁决证据节点及其关系和值不复制、不退出。迁移写前在 `Gs` 读取唯一前态和证据，要求：前态为执行结果待验证、裁决未达成、后继准备为目标未达成待重筹办、结果仍当前、新发生时间严格晚于前态。

## 8. 幂等、重试和错误分账

### 8.1 幂等语义

首态同义键：

```text
任务 + 实例方法 + 执行轮次 + 正式实际结果 + 治理输入幂等键
```

迁移同义键：

```text
任务 + 前一治理状态 + 目标裁决证据
```

同一幂等身份且完整请求不同返回 `幂等冲突`，零新写。精确重复必须返回首次发布代次和首次完整结果，即使对应状态后来已经进入历史。

### 8.2 旧代次重试

当前代次高于原请求期望时，不自动升级请求：

1. 按原截止历史重建完全相同的写集；
2. 使用原幂等身份、原本地键和原完整请求提交；
3. 只接受 L1 `精确重复 + 原发布代次 + 原编码映射`；
4. 其它结果按事实代次漂移、幂等冲突或内部不一致收口。

### 8.3 错误

```text
入口拒绝：合同、身份、枚举、向量或时间形状非法
未找到：请求引用在具名截止不存在
事实代次漂移：首次尝试的当前截止不等于期望且不能按原请求收敛
幂等冲突：同幂等身份不同完整请求
引用冲突：字段、关系、端点、前态或完整裁决材料不绑定
资源失败：分配或资源不足且未形成发布
内部不一致：已发布结构、映射、基数、角色或读回不闭合
```

发布后读回失败不能伪装成零写或回滚。

## 9. 验证与完成声明

允许在现有 `海中鱼巣/端到端测试.自我治理一致事实.ixx` 增加 DATA-L2 专项。该专项复用现有任务、路径、实例、正式实际结果和目标未达成裁决夹具，直接验证结构入口；它不冒充自我线程生产消费全流程。

最低矩阵：

```text
首态首次提交与 Gs 读回
首态精确重复、异义冲突和已有当前关系拒绝
目标未达成迁移与 Gr 当前/Gs 历史读回

发生时间、前态、裁决结论、后继准备和角色端点冲突零写

旧路径、实例、实际结果、首态和裁决证据历史可读
目标已达成材料只能登记待验证首态，不能调用目标未达成迁移

```

完成只证明 DATA-L2 正式保存、迁移和读回能力。后续全流程必须另行验证：DATA 外业务 provider 的 DTO 映射、自我线程消费、旧冻结失效后的真实筹办触发以及目标已达成分支的路径验证和任务完成。
