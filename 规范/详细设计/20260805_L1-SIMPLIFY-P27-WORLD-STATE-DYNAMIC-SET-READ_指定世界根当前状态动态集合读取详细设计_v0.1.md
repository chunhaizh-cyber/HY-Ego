## 1. 目标、边界与最早缺口裁决

本叶是 SELF-GOV-CLOSURE STEP-4 在 P26 之后的下一最早缺口。它新建唯一无对象状态的 `海中鱼巣.领域.服务.L1状态动态集合读取`，由 4200/4201 冻结的 L2 状态动态查询所有者消费调用方传入的一份 P17 `L1完整快照`，以及 P19 世界结构、P21 实际存在集合、P24 实例槽集合、P9 状态登记定位和 P14 动态登记定位，形成指定世界根范围内完整、同代次、稳定有序的关系19状态组与关系20状态迁移动能组。

本叶只读当前 L1 快照中的状态/动态自有事实。合法世界可以同时零状态、零动态并成功返回两个空组。它不重取 P17，不调用 P9/P14 逐项读取，不取 L1 或领域锁，不读缓存、SQL、历史仓、审计或恢复材料，不扫描猜测登记身份，不形成写集或部分成功。

## 5. 请求校验与范围冻结

调用前顺序固定为：协调者先取得 P19 与 P21 成功事实，再调用 P17 取得本轮唯一传入快照；P24 和 P27 依次消费这同一份快照。P19/P21 可由其领域服务内部独立取得同代次快照，但其结果截止必须与本轮传入快照一致。P27 不调用任何 provider。

入口校验：

1. 合同、读取规则及 P19/P21/P24 各自合同、规则、排序版本必须精确匹配；
2. 三个上游事实都必须完整、根相同、截止非零且严格等于 `快照.事实代次`；
3. P21 主体集合必须与 P19 当前直接成员目标一一对应；P24 主体组必须与 P21 一一对应，槽结构稳定排序且无重复；
4. 快照当前节点、关系、值和每节点当前属性必须按稳定编码排序且唯一，全部创建代次不晚于快照代次，当前组不得携带退出代次；
5. P9/P14 登记定位合同与规则匹配、编码非零互异；登记的建立截止只证明定位来源，不要求等于当前截止。

版本字段或调用形状错误返回入口拒绝。全部上游声称成功但根、范围、排序或同代次矛盾时返回内部不一致；只有各成功事实本身完整而截止彼此不等时返回版本漂移。入口失败不返回范围子集。

登记定位必须在传入快照内逐项互证：P9 服务、关系19类型和五属性类型，P14 服务、关系20类型和八属性类型均为当前节点；普通/属性类型节点种类及 I64、I64组、U64组表示精确。定位缺失、零编码、错类型、重复或与快照矛盾不得扫描补造，返回内部不一致和稳定诊断。

## 6. 关系19状态集合算法

先形成三个只读集合：P19 当前场景编码集、P21 当前主体编码集、P24 按主体分组的当前实例槽编码集。随后只按登记的关系19类型分组快照当前关系。

一个关系19源只要任一已识别角色触达本树场景、当前主体或当前实例槽，就成为本轮候选；完全不触达指定根范围的其它世界事实忽略。候选不得因缺少另一个角色而被静默排除。

每个候选必须同时满足：

1. 源为当前普通状态节点，并有状态资格属性槽；角色1—5各恰一、无未知角色，五关系同源、同登记关系类型；
2. 角色1主体属于 P21，角色2场景属于 P19，角色3实例槽属于该主体的 P24 槽组，角色4为当前普通特征值见证节点，角色5来源存在属于 P21且等于角色1；
3. 状态节点恰有状态资格 I64=1和发生时间 U64组一项；特征值见证恰有资格 I64=1、被采样P8值引用 U64组四项、采样I64值一项；各属性槽唯一指向对应当前值；
4. 状态资格、时间、见证资格来源为 P9 状态服务身份；采样引用与采样I64来源为角色5；五值所属、类型、表示、前一值空、退出空和创建代次符合 P9；
5. 采样引用中的值编码、创建代次、采样截止、来源均非零或合法，值创建不晚于采样截止，采样截止严格早于状态自有事实创建代次；引用值若仍在当前快照，必须与所属槽、来源、创建代次和 I64 材料精确互证；若已退出而不在当前快照，仅保留不可变引用，不访问历史仓；
6. 状态、值见证、五关系和五状态域值创建代次一致；节点、关系和值的 `当前状态发布代次` 投影统一填本快照代次。

状态按 `(场景编码, 主体编码, 特征编码, 发生时间, 状态编码)` 升序。完整排序键重复属于内部不一致，不以关系编码、容器顺序或插入次序消歧。

## 7. 关系20迁移动能集合算法

只按 P14 登记的关系20类型分组当前关系。候选触达规则与状态相同：任一角色触达本树场景、主体、槽或已形成状态即进入本轮校验，不能用缺角色逃避。

每个候选必须满足：

1. 源为当前普通动态节点；角色1—5和9各恰一，角色6—8及其它角色数量严格为0；六关系同源、同登记关系类型；
2. 角色1主体、角色2场景、角色3实例槽和角色9来源存在分别属于 P21、P19、该主体P24槽组和P21，来源存在等于主体；
3. 角色4前状态、角色5后状态都必须存在于本轮成功状态组，且二者主体、场景、实例槽、来源与动态对应；
4. 动态资格、动态种类、聚合规则、时间范围、迁移比较合同、迁移差异、比较输入引用、比较输入I64组八槽各恰一，表示、所属、来源、材料长度、生命周期和创建代次满足 P14；
5. 动态种类强类型值等于 `状态迁移`，聚合规则版本为0，时间范围恰为 `[前状态时间, 后状态时间]` 且 `0<T0<T1`；差异非零并等于 checked `新值-旧值`；
6. 迁移比较合同20项、输入引用13项、输入材料2项与前后状态、P24实例槽、P14登记类型及持久比较证据逐字段互证；角色6—8没有占位节点、关系或伪空值。
