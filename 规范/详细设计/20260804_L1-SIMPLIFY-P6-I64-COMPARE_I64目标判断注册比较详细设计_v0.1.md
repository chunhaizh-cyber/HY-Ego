## 1. 目标与完成边界

本叶建立特征比较领域的第一个真实提供者：以正式 L1 事实保存并读取一个 `I64 + 目标判断` 比较合同，在一次 `L1完整快照` 中共同校准注册、当前事实和目标状态，然后返回排序三态、具名关系和安全 `右值 - 左值` 差异。

首个成功路径固定：

```text
左角色 = 当前事实
右角色 = 目标状态
左值 = P3/P4 实例槽的当前 I64 值
右值 = P2 I64 特征定义的当前上界值
比较用途 = 目标判断
算法族 = 标量有序比较与安全差异
算法版本 = 1
```

完成必须证明真实注册、正式读回和真实比较成功行为，不能只建立 DTO、固定未实现入口或零调用骨架。

本叶不修改 L2 DTO 或服务签名，不实现 `特征判断收束服务::按注册比较合同裁决目标差距`，不接入运行期，不实现显式有向类型兼容、领域业务键、SQL/持久恢复、旧消费者迁移、旧入口删除、集成验收或 STEP-3。

## 6. L1 注册事实结构

### 6.1 服务登记

私有幂等域：`0x08`。`建立登记` 仅允许空 L1 或尚无本服务登记的隔离初始化顺序，单写集建立六个普通节点：服务身份、`I64组` 配置属性类型、合同字段关系类型、无单位、标量维度、标量分量角色。成功后必须按返回稳定编码逐项从同一事实代次读回，才更新内存登记。

### 6.2 I64 目标判断合同

私有幂等域：`0x09`。合同登记先要求服务登记已加载，并在一次完整快照中验证请求引用的 P2 定义和 P3 实例登记字段。单写集建立：

- 一个注册身份节点；
- 一个配置值，所属注册身份，属性类型为 `合同配置I64组属性类型`，来源为服务身份；
- 注册身份的当前配置属性槽；
- 11 条 `合同字段关系类型` 关系，源固定为注册身份，目标与角色固定如下。

| 角色 | 目标 |
| --- | --- |
| 1 | P2 特征定义 |
| 2 | P2 定义标记值 |
| 3 | P2 下界值 |
| 4 | P2 上界值 |
| 5 | P3 定义模板关系类型 |
| 6 | P3 当前 I64 属性类型 |
| 7 | P2 I64 上界属性类型，作为目标 I64 属性类型 |
| 8 | 无单位 |
| 9 | 标量维度 |
| 10 | 标量分量角色 |
| 11 | P2 定义来源服务 |

配置 `I64组` 按以下固定顺序保存标量合同，不保存稳定编码：

```text
[配置版本1, 用途1, 算法族1, 算法版本1, 原始类型1,
 左角色1, 右角色2, 差异方向1, 允许结果位7, 当前有效1,
 边界包含1, 量化规则1, 允许直接持久化0,
 溢出处理1(结构化拒绝), 缺值处理1(结构化拒绝),
 输入版本规则1(稳定编码+创建事实代次), 误差合同版本1,
 P2下界, P2上界]
```

同一 `特征定义 + 目标判断` 只能有一个当前有效注册；重复相同请求返回幂等读回，不同内容或第二当前路由返回幂等冲突/内部不一致，绝不选择其中之一。

## 7. 比较函数固定算法

`比较特征` 的唯一外部调用为：

```cpp
const auto 快照结果 = L1_.读取完整快照({});
```

不得依次调用 P2/P3 服务或 L1 单项入口拼接代次。函数在获得不可变快照后完成：

1. 校验合同/规则、请求身份、稳定编码、用途、角色、单位/维度/分量角色和结果位。
2. 在服务互斥量下复制当前登记和合同内存见证后立即解锁；比较期间不持锁。
3. 无登记/合同为 `未注册/未注册`；已加载但失效为 `未注册/注册失效`；双当前路由为 `内部不一致/注册不唯一`。
4. 读取一次完整快照；资源/内部错误按 L1 结果映射。快照事实代次必须等于请求的 `预期事实截止代次`。合同的 `事实截止代次` 是其登记读回代次，不是冻结后续输入的全局代次；只要注册节点、配置值和字段关系在本次快照仍为当前事实，P4 后续合法换代不使合同失效。
5. 在同一快照中唯一匹配注册节点、配置值、11 条字段关系、P2 定义/标记/上下界、P3 定义关系、实例槽当前属性和当前值；逐项核对稳定编码、创建事实代次、来源、值表示、角色和请求预计值。
6. 左输入固定为实例槽当前值；右输入固定为 P2 当前上界值。任一退出/缺失、属性槽不指向左当前值、定义关系不连接相同定义、目标不是注册上界值均为具名拒绝或版本漂移。
7. 排序不做减法：左小于右为 `-1/当前低于目标`，相等为 `0/当前达到目标`，大于为 `1/当前高于目标`。
8. 仅在请求包含差异位时检查并计算差异。安全条件：

```text
若 左 < 0 且 右 > INT64_MAX + 左：差异不可表示
若 左 > 0 且 右 < INT64_MIN + 左：差异不可表示
否则 差异 = 右 - 左
```

检查式本身不溢出。差异不可表示且请求含差异时返回 `入口拒绝/差异不可表示`，全部比较载荷为空；只请求排序或关系时不执行减法，可正常成功。
9. 成功结果只填充请求位对应载荷，未请求项为空；误差预算/相等容差为空，边界包含不适用、精确无量化、误差合同版本 1，并回显左右输入版本。

比较全程零 L1 写入、零注册变更、零索引变更、零日志和零其它机器事实。

## 9. 并发、幂等与生命周期

- 登记和合同建立由服务互斥量串行；不得持服务锁调用 L1。
- 采用“锁内读取内存见证 → 解锁 → L1 写入/读回 → 重新加锁确认见证未变化 → 发布内存见证”的顺序；并发变化返回版本漂移或内部不一致，不覆盖新见证。
- 同一请求只允许一次 L1 写集；精确重复必须从既有 L1 映射和当前事实读回，不重复写入。
- 比较只在锁内复制小型值式见证，之后以单快照只读；并发 L1 新提交只能形成不同事实代次，不能进入本次结果。
- 注册事实生命周期服从 L1；服务内存见证随服务对象销毁而消失。运行期重装载和持久恢复后的登记重建不在本叶完成边界。
