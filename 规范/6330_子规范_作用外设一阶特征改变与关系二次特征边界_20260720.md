# 6330 子规范 作用外设一阶特征改变与关系二次特征边界

编号：6330
日期：20260910
版本：v0.5
状态：正式子规范

## 1. 定位

本规范规定作用外设的直接输出、外界实际回读、关系二次特征和因果确认之间的边界。

直接上级规范：1160、1170、1180、1190、3200、3300

直接依赖规范：4220、4320

相关边界规范：1130、2100、4151、4180、5260、5350、5360

## 2. 直接改变边界

作用外设只能直接改变目标存在或外设自身能够直接观察和回读的一阶特征，例如位置、姿态、开合程度、末端状态、输出强度或工作状态。速度不是外设直接写入的一阶特征；它必须由位置变化量和时间变化量经正式动态与二次特征规则派生。

“靠近、接触、遮挡、包含、夹持稳定、支撑、改善”等关系不是外设直接写入的物理字段。它们必须在动作后由自我读取一个或多个存在的一阶特征，通过合法计算形成二次特征、状态或关系判断。

不得为了表达关系变化而给作用方法新增“关系直接输出”字段。

## 3. 计划、执行和事实分账

必须分开：

| 层级 | 含义 |
| --- | --- |
| 动作计划或预测 | 期望改变、允许误差、风险和副作用预算 |
| 方法执行报告 | 外设命令是否按协议执行以及执行范围 |
| 实际观察回读 | 目标和外设一阶特征实际发生的变化 |
| 二次特征与因果判断 | 由前后事实、时序和作用范围计算的关系与归因 |

方法执行成功只表示作用动作完成，不表示任务目标已达成。预测不是事实，不能覆盖实际回读。

## 4. 动作动态

作用方法的动作执行材料通过同一次运行关联以下信息；这些是运行材料，不是给动态本体追加字段：

- 来源任务和执行方法；
- 作用外设、目标存在和作用范围；
- 动作前目标与外设状态；
- 计划输出、允许误差和副作用门限；
- 执行时间范围和方法结果；
- 需要进行的感知验证。

真实动作动态按1170、4220由合法前后状态及场景/主体关联形成。没有实际变化来源时，只保留执行材料或明确缺口，不能用计划、返回成功或失败补造动态。

感知方法只能记录观察行为产生的材料和事实刷新，不能把外界对象自身变化伪装为自我造成的变化。

## 5. 动作后验证

动作后由任务组织独立来源重新观察并比较；作用方法只声明所需观察/验证规格，不裁决自身效果成功：

- 目标一阶特征是否达到目标范围；
- 外设末端误差是否在允许范围；
- 关系性二次特征是否满足；
- 副作用风险是否可接受；
- 观察材料是否新鲜、稳定且来源一致。

所有比较复用正式二次特征能力，明确特征类型、比较用途/规则、输入角色、目标来源和允许域。业务词不能代替比较方向，容差命中不能冒充准确相等。

作用前预测、执行报告和作用后实际结果必须分账。目标未达成、读回冲突或副作用不可接受时，任务按5260记录并处理结果或形成结构化缺口；失败 / 取消不做任务结算，只有正式完成任务由自我组织一次结算，不得伪造成功状态。

## 6. 关系二次特征

距离、姿态偏差、中心偏差、重合率、接触状态、遮挡程度、包含关系和夹持稳定度等关系，必须由相关存在的一阶特征、比较规则、阈值、来源动态和版本计算。

速度、变化率及其更高阶变化同样属于二次特征：动作后先发布可回查的位置、时间和其它基础变化事实，再由当前比较或判断需求按1180、4151形成合法调用期结果；持久二次实例继续受0300的C038边界限制，不由本规范开放。外设命令、计划速度、控制器设定值和执行报告不得替代实际速度事实。

二次特征的参与者通过稳定句柄和关系引用承载。只有上级二次特征规范允许时，多输入关系才可以沉淀为可复用二次特征；否则只保留为当前运行视图或短期状态。

## 7. 因果确认

相机观察到目标变化，不足以证明作用外设导致该变化。因果判断至少核对：

- 动作时间与变化时间；
- 作用范围和目标身份；
- 动作前后特征；
- 外设传感器与外部观察的一致性；
- 其它可能来源和硬冲突；
- 结果是否在预测误差范围内。

未完成上述验证时，只能记录同时发生或待归因候选，不能写稳定因果结论。

## 8. 任务筹办边界

作用任务的执行合同必须同时具备合法作用入口和独立结果验证路径；方法声明必要验证规格，不意味着动作函数兼任验证器。筹办按目标FT发现已登记方法并核验候选条件，不裁决方向/区间适用性、不采用方法、不现场执行感知、不生成关系事实，也不因缺少候选而创建方法头。方向、区间等细查及采用由5260执行前选择完成。

作用方法执行期若发现冻结前应具备的结构缺口，属于筹办漏检和内部逻辑错误；执行期新出现的外部材料不足或目标变化按结构化结果返回。

5360的独立登记阶段不属于已冻结动作执行阶段；登记只能建立合法声明结构，不执行真实动作，不自动增加启动流程。

## 9. 验证

验证覆盖一阶直接改变、关系二次计算、计划与事实分账、动作后回读、阈值来源、副作用门限、因果反证以及筹办不写关系事实。

没有真实外设动作、实际回读、状态动态和因果证据时，不得宣称作用路径、关系改变或任务目标闭环成立。
