# 8320 子规范 自我初步成熟阶段验收

编号：8320
日期：20261004
版本：v1.0
状态：正式子规范

直接上级规范：8310。

直接依赖规范：1190、4310、4320、5090、5350、8210。

相关边界规范：3100—3300、8000、8200。

## 1. 定位

本规范规定自我在苏醒闭环之上，能够把方法缺口、因果缺口和外界未知转化为可验证目标，安全地学习或探索，并用真实结果改善后续治理的初步成熟验收。

未知、缺口和任务失败都只是材料，不能自动生成需求、方法或因果。

## 2. 学习目标形成

方法或因果缺口进入self后，self必须fresh读取原D、T、当前世界事实和现有能力，确认新目标：

- 独立且必要；
- 属于合法父需求范围；
- 目标宿主、特征类型和值/概念明确；
- 有可最终判定的完成条件；
- 不与现有D精确重复。

满足后由需求类建立或复用子需求。不得由manager、worker、task owner或学习器直接创建D。

## 3. 探索需求

内部信息不足时可以形成探索需求，但必须明确：

- 要获取什么未知；
- 作用对象和可能副作用；
- 安全门禁和停止条件；
- 结果获取渠道；
- 结果如何回写为世界事实或知识材料；
- 结果未知或冲突时如何处理。

没有结果获取渠道的探索同样零动作。探索结果只作为正式世界事实、状态、动态、因果证据或方法学习材料进入相应领域，不自动证明原需求满足。

## 4. 方法学习

方法学习至少消费多个来源完整的执行实例和影响评估，区分：

- 条件适用性；
- 参数绑定；
- 变化方向；
- 幅度或值域；
- 计划外变化和副作用；
- 结果渠道质量；
- 归因充分性。

单次成功或失败不能直接覆盖共享方法知识。候选必须经方法治理独立评审；新知识只供以后筹办使用，不追改已经完成的X和A。

## 5. 因果学习

因果是可修正参考规律。至少两次出现可以形成候选材料，但正式因果必须按1190、4310、4320核验参与者概念、条件、动作、结果、时间先后、重复次数和反例。

状态筛选、动态反转和动作反转可以提供来源材料；具体状态、动态、动作和存在只作证据，不建立因果实例类。因果不能提供百分之百正确保证，方法应用仍须检查当前条件、结果途径和安全门禁。

## 6. 复合动作与能力迁移

从他者动态推测自我能力时，必须明确执行主体、必要子存在/特征、可实现本能动作和结果渠道。例如观察他者“拿”只形成候选；只有自我具备相应执行结构并通过安全试验与真实结果验证后，才能形成自我方法能力。

组合方法以条件—结果分支组织本能方法，允许循环但每次循环必须检查对应特征是否变化；无变化或方向不一致时停止并返回真实结果。

## 7. 初步成熟验收

至少证明一个完整案例：

```text
现有任务暴露真实能力或因果缺口
-> self形成并确认学习/探索D
-> 唯一T推进
-> 有结果渠道的安全动作或观察
-> 正式世界结果、X和A
-> 方法或因果候选独立评审
-> 新知识进入以后一次任务筹办
-> 后一次任务因新知识作出不同且可验证的选择
```

还须覆盖：

- 缺口不成立时零新需求；
- 重复目标复用D；
- 无结果渠道零动作；
- 结果未知不补成功；
- 失败/副作用进入学习材料；
- 安全否决；
- 新知识不追改旧执行；
- current-only读回，不使用事实截止或历史快照拼接当前结论。

## 8. 声明边界

初步成熟只证明至少一个学习或探索闭环改变了后续治理。它不证明开放世界通用学习、复杂自然语言、自主构造任意方法、长期价值最优或所有外设能力已经成熟。
