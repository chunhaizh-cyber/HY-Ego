## 1. 定位

本规范规定因果概念的经验统计、具名代表实例、保护与释放、淘汰原则，以及旧用途观察生产账的退役规则。统计字段和代表实例的精确结构、登记操作及不变量由4340承接；形成与修订算法由4310承接。

## 2. 统计是因果本体字段

1. 因果概念自身保存四项经验统计：符合出现次数、不符合出现次数、自我尝试次数、自我尝试符合次数（1190第6节）。统计是因果本体字段，不是可从证据重建的投影；证据（动态）会按生命周期删除，统计不依赖其存续。
2. 统计只是经验材料，不自动产生概率、置信度、正确等级、验证状态或执行资格。命中率、稳定度、排序分等派生评价由调用方即时计算，不另存为因果字段。
3. 统计随认知漂移按当前定义继续解释：因果原地扩大或缩小后不追溯重算、不清零；两条因果合并时按4340第6、7节合并计数，已同时计入两条因果的同一动态只计一次。
4. 统计只来自前置窗口内的状态和动态（4310第4.1、4.2节）；窗口内无变化的长期背景条件不进入统计，是已接受的限制。

## 3. 代表实例

因果概念保存少量具名代表实例，每个代表实例是对一个动态的强类型引用及其角色：

| 角色 | 基数 | 含义 |
| --- | --- | --- |
| 形成来源 | 经验归纳形成时至少2；修订后不足2时见第3节第6项；预置为0 | 形成该因果的独立发生 |
| 最近反例 | 0至k | 满足条件但结果未出现的最近发生，k为本规范参数，默认取3 |
| 边界实例 | 0至m | 修订时用于确定值域边界的发生，m为本规范参数，默认取2 |

1. 代表实例受保护：被引用的动态及其前后状态在采纳期间不被定期、定量删除（1160、1170）。非代表实例的动态不受保护，其贡献已计入统计，之后按生命周期删除；因果不因此失效。
2. 代表实例必须当前可读，且确实满足（形成来源、边界实例）或违反（最近反例）当前定义。因原地修订而不再满足的代表实例，在同一次修订中解除保护或改标角色。
3. 最近反例按强时间更新：新反例进入时若已满k个，最旧者解除保护。
4. 具体存在、准确值和时间只在代表实例引用的动态中，不进入因果的概念层定义或唯一键。
5. 项目不建立因果实例节点、因果样本节点或证据组节点；代表实例以因果节点上的具名引用承载。
6. 原地修订后仍满足当前定义的形成来源不足2时，从仍保留且符合当前定义的动态中补选；补选后仍不足2的，允许少于2，但在因果节点上标注“来源不足”，并作为第4节的退役候选。统计不因此清零。

## 4. 淘汰

1. 因果可以退役，判断材料包括：使用情况、符合与不符合统计、最近使用、是否被方法或因果链引用、是否存在更具体的替代因果。仍被方法、因果链或在途筹办引用的因果不得退役。
2. 退役时解除对全部代表实例的保护；被解除的动态此后按1160、1170生命周期处理。
3. 动态一侧的“已计入”去重关系不构成阻止因果退役的引用，退役时一并解除。
4. 具体阈值属于可修订的规则参数，由因果owner统一维护；不得用单一分数、次数阈值、名称或哈希单独确认或淘汰因果。

## 5. 复盘

需要回答“当时为什么发生”时，调用方读取概念层因果并把角色临时绑定到具体存在，再沿代表实例或仍保留的动态回读状态、动作和场景。该复盘是值式解释，不发布因果实例。只有保留的实际事实能够满足条件、动作和结果的链段才能说明本次发生；已删除材料保持未知。

## 6. 旧用途观察编码退役

4010历史登记的下列编码只用于既有ABI、持久材料和历史结果解码：

```text
节点类型15：用途观察记录
关系类型18：用途观察证据角色
稳定主键命名域：用途观察记录身份
```

1. 不新增节点类型15、关系类型18或用途观察记录；
2. 旧数值不删除、不重排、不复义，只读历史材料不得恢复为当前生产事实；
3. 不以观察、见证、证明、审计、样本或阶段为名建立同义生产账；
4. 历史观察账不能替代缺失的状态、动态、动作和因果来源；
5. 工程幂等、事务、发布读回、恢复见证和线程水位不属于认知证据。

## 7. 非成功收口

| 场景 | 结果 |
| --- | --- |
| 代表实例引用的动态不可读 | 结构不一致，解除该引用并报告 |
| 动作未知 | 只能支持未知动作因果 |
| 资源不足 | 返回不完整，不以空组表示完整 |
| 计数溢出 | 工程错误，按工程诊断链处理，不改写统计 |
| 来源正式事实互相矛盾 | 内部不一致并停止受影响路径 |

## 8. 验证

验证至少覆盖：统计作为本体字段在证据删除后保持；形成来源至少2；最近反例超过k时最旧者解除保护；修订后不再满足的代表实例解除或改标；退役解除全部保护；仍被引用的因果拒绝退役；零因果实例、零证据组节点；旧节点15/关系18零生产及历史只读兼容。
