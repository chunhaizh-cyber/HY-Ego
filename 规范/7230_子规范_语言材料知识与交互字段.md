直接上级规范：1100、1110、2300、2310、2320、2330、2340。

## 1. 结构约定

本规范固定逻辑字段、基数、数据来源和单一权威。下文结构不是已存在的C++ DTO，也不追加DATA-L1表列。节点承载身份、值承载类型化内容、关系承载引用和有序组成；集合与索引从这些事实读取，不建立第二份父指针或成员列表权威。

“引用”必须有目标种类和可读身份，不接受裸整数、路径或显示名。“?”表示可以缺省，缺省不等于0、空字符串或未知对象身份。“局部编号”仅在所属材料或规则内定位，不是全局节点身份。

语义内容与技术封套分开：下文不把事实代次、幂等、批次、生命周期重复列作每个对象的含义；结构服务仍须支持完整发布、固定定义读回、当前/历史分离与引用保护。

## 2. 原始材料与三种表达尺度

### 2.1 文本材料与范围

```text
文本材料
  材料身份
  文本内容引用             // 固定Unicode标量序列
  原始接入材料引用?         // 原始字节/编码，或本次生成来源
  解码与对齐材料引用?       // 原始字节存在时必有可回查解码依据

文本范围
  文本材料引用
  起始标量位置
  结束标量位置
```

文本范围为零起点半开区间，单位固定为Unicode标量值，不是UTF-8字节、UTF-16代码单元或可见字形。组合附加符、表情、CR与LF分别计数；不能规范化、删空格或变换换行后继续沿用原范围。原始字节保留原编码；解码失败只保留原始材料，返回格式/解码失败，不静默替换字符生成成功文本。原文真实包含的U+FFFD不等于解码成功或失败，亦不受4240“词面材料”禁用字符规则的替代解释。

原始文字可以为空，表示确实收到空内容；空材料不是“解析成功”。正式句子/段落的范围非空且不越界，空白分隔范围不必伪造成句子。字节恢复、材料去重和物理保存复用现有材料合同；值可共享但语言出现身份不得合并。

### 2.2 固定内容字段

| 对象 | 逻辑内容字段 | 外部关系 |
| --- | --- | --- |
| 文章信息 | 节点身份、语言选择、标题值引用?、来源记录引用?、原文材料引用 | 有序段落组成、解析关联、可选文本世界锚点 |
| 段落信息 | 节点身份、原文范围 | 可选文章归属、独立时唯一语言来源关联、有序自然句组成、解析关联 |
| 自然句信息 | 节点身份、原文范围 | 可选段落归属、独立时唯一语言来源关联、解析关联 |
| 有序组成 | 关系身份、父材料节点引用、子材料节点引用、序号 | 属语言owner；文章→段落、段落→自然句 |

语言选择沿7220使用已知语言引用、显式未知或带范围的混合语言，未理解不制造汉语身份。段落/自然句继承文章或独立来源记录的语言选择，不重复保存相冲突的语言。单句、单段交互允许独立材料；没有上级就不制造空壳文章/段落。

独立语言来源关联指向语言owner保存的固定来源材料，其内容为语言选择、原接入来源引用（可缺省）及原文材料引用；范围必须相容。独立材料后来纳入组成时，必须校验继承语言与该来源一致，不能通过换父改变已保存原文的语种解释。来源关联不是额外文章身份。

组成关系按一个固定发布版本读取：每个子出现至多一个直接组成父；已组成时恰一父，父内序号唯一、非负且按升序读取，不要求连续。相同文字在两个位置必须有两个出现身份。不能把同一个子出现挂到两个父；复用材料时新建出现并引用相同内容。

同源文章的子范围必须位于父范围内，按源文次序排列且兄弟不重叠；分隔符可留在原文，不靠重拼子文本恢复全部原文。编辑重排、跨源拼接先形成新固定输出文本与对齐关系，再建立新组成，不伪称它是原文章的位置。父归属和子列表由同一有序组成关系正反读取。

### 2.3 解析与词出现

```text
句子解析材料
  解析材料身份
  来源自然句及固定内容引用
  解析规则定义引用
  语境依据              // 明确无语境依赖，或固定语境材料引用
  分段项有序组
  子句组成组
  候选含义组
  覆盖结果               // 完整、部分、未解析；显式给未覆盖范围

分段项 = 已确认词出现 | 未知片段 | 分隔片段
已确认词出现 { 局部出现编号, 原文范围, 正式词条引用 }
未知片段     { 局部出现编号, 原文范围, 词面候选组 }
分隔片段     { 原文范围 }
```

未经分词的句子可以先保存；无解析记录、完整空结果、部分解析不能互换。正式词出现必须读回词条；未知片段不填零词条或临时整数伪装正式词条。多种分词分别属于独立候选序列，不混成一个有重叠词序的假完整解析。

2330子句继续使用所属解析中的**词出现索引半开区间**，不是本节文本标量范围。正式子句只引用已确认词出现有序组；含未解决词边界的范围保留为解析候选，不伪装完整正式子句。每个词出现同时关联源文范围，二者通过该映射换算，不改义旧位置字段。修正分词建立新的固定解析结果材料，旧子句仍绑定原结果及原序列；使用相同算法/规则重新解析不要求新建规则定义，规则改变才引用新规则定义。本文“解析结果材料”和“解析规则定义”是两个不可互换的引用。

## 3. 语言知识字段

### 3.1 核心、目标与角色

```text
语言知识 { 节点身份, 目标描述引用, 描述结构引用 }

目标描述
  目标定义身份
  表达目的              // 陈述、提问、提出需求；子片段可继承
  角色定义组
  含义结构
  适用条件组

角色定义
  局部角色编号
  角色种类
  数量约束              // 单项、可选单项、有界集合
  必要约束组
```

角色种类闭合为概念引用、领域对象引用、特征类型引用、准确值、时间、语言材料引用、含义子项；领域对象再显式区分存在/场景视角、特征、状态、动态、关系、因果、需求、任务、方法。引用不能在这些类别之间靠数值强转。必要约束只使用7240的有限操作。

含义结构由7240规定的类型化项、角色引用和作用域构成。未绑定变量、明确未知值、查询变量和已经绑定的对象不同；未知不填0、不等于否定。某角色是概念不表示另建一种概念本体，D/T/M使用对应对象引用或提议结构。

### 3.2 描述结构

```text
描述结构
  结构定义身份
  结构类别              // 基础表达、内容组织
  语言约束              // 指定正式语言；组织层可随子规则
  结构项有序组

基础结构项 = 固定词项 | 角色表达项 | 子规则项
固定词项   { 局部项编号, 词条引用或固定标点值 }
角色表达项 { 局部项编号, 角色编号, 表达方式 }
子规则项   { 局部项编号, 子知识固定定义引用, 角色映射 }

内容组织项
  局部项编号
  子表达目标
  取材规则
  子规则固定引用或按子目标选择
  角色映射
  展开方式              // 单项、逐项、分组
  选用条件
  缺材处理              // 必需不足、可选略去、明确表达未知
  衔接关系              // 无、并列、时间先后、转折、条件、因果、回应
```

结构项顺序为规则内顺序，不使用可变容器地址。角色表达方式只允许名称表达、明确对象描述、已消解指代、类型化字面值和子含义表达；没有名称不能泄露句柄冒充自然语言名称。规则自身的标题或注释不参与执行。

“明确表达未知”必须是目标允许报告缺失，不能凭字段未查询就说“不知道”。因果/转折/条件衔接必须有对应含义输入，不能因结构项相邻就补写“因此”。用于省略的角色必须由唯一上下文或子映射可恢复；否则该结构不支持当前双向使用。

内容组织规则之间允许共享无环定义引用；按子目标选择形成的运行期递归由7240预算和严格进展规则终止。不得把引用环称作语言递归并无限展开。

### 3.3 当次表达与解析对齐

```text
本次表达项
  局部出现编号
  所用知识固定定义引用
  本次角色绑定组
  本次选取的信息引用组
  子表达项有序组
  输出材料范围?          // 仅生成后有

含义对齐项
  来源材料范围
  含义项局部编号
  所用规则及角色映射
```

本次表达树、候选含义组和分数默认调用期保存，可随请求结束释放；需要留存的原文、已采用解析和学习样本由语言owner保存。对齐只能指向实际存在的材料与规则；不为证明正确性复制世界状态、二次特征结果或治理事实。

## 4. 交互、指代与学习数据

### 4.1 交互记录

```text
语言交互记录
  记录身份
  表达者引用或来源未明
  接收者引用组或受众说明?
  语言材料引用
  发生时间材料             // 区分表达时间、接收时间及其未知
  回应的交互记录引用?
  引用来源材料组
```

正文仅引用，不复制到交互记录。作者、表达者、转发者、被引用说话者、接收者不同；回应不等于同意，引用不等于回应。日记/文章可以没有确定接收者或被回应消息。

### 4.2 本次交互上下文

```text
交互上下文（调用期）
  本次交互与材料范围
  当前说话者、受话者组
  当前话题/显著对象有序组
  参考时间、参考地点
  引语作用域栈
  待解指代候选组
  已解出现到具体目标的绑定组
  待回答问题组
```

不是每个人永久持有一张全局代词表。可用数组/映射实现当次“我、你、这里、刚才”等取值，但键包含交互、引语作用域和出现位置；“我”由当前说话者取得，“你”须能唯一定位受话对象，“他/它”通过类型约束和焦点候选消歧。时间/地点未知就保留未决，不采用机器当前时间或self所在场景补值。

已解历史出现保留实际目标；上下文更新只影响后续解释，不能改变已发布解析结果。引用框架入栈/出栈恢复原说话者及参考信息；未解决的并列候选不任选首项。持久指代仍按1110单独发布与读回，并引用当时固定解析结果而非仅引用规则定义。

需要保存解析/学习时，只保存实际采用的固定语境材料：来源交互或教学材料引用、实际用到的说话者/受话者绑定、参考时地、引语范围、焦点候选及各项来源引用；缺省项显式未使用/未知，不复制整个会话缓存。所需历史读取截止放在其来源技术封套，不增加到知识核心字段。无上下文依赖必须显式标记，不能以缺失引用冒充已核验；语境修正形成新材料，不改写旧解析依据。

### 4.3 学习与使用关联

```text
语言学习关联
  关联身份
  样本材料及固定范围
  语境依据              // 明确无依赖，或当时固定语境材料引用
  含义依据引用组
  学习目标               // 名称、含义对齐、基础结构、组织结构
  知识固定定义引用或结构候选材料引用
  样本与规则角色对应
  反馈/纠正材料引用组

知识采用关系
  关系身份
  知识固定定义引用
  采用范围与使用方向
  使用方式               // 限定试用、正常使用、停止新用
  依据学习关联组
```

采用范围/使用方式是语言业务结论，结构服务只保存；不新增通用“成熟度分数”字段。样本、反馈、采用和索引分账，命中次数可由实际关联统计重建，不按重复转写或自我生成循环虚增独立样本。自动淘汰须按7250，结构/名称学习不替代概念的7140治理。

## 5. 写入和引用闭包

语言材料、组成、解析、指代、知识、知识内目标/结构以及学习/采用关系均静态路由既有语言owner；词条、名称、概念、原始不可变材料仍归各自owner，不转移所有权。新角色编码与公开读写面由语言专属物理合同集中冻结，不能把本节对象名称直接加到通用节点族枚举。

同一知识及初始目标/结构/全部组成在语言owner内完整发布；同一解析及其词序、子句、对齐同样完整发布。允许原文先独立发布，解析失败不撤销已接收原文。外部端点先取得正式身份，跨owner只能分阶段记录各实际结果，不能伪称一个跨领域原子事务。

读取必须能区分当前定义、明确历史定义和来源已不可读；发布未知按原请求读回，不改键重建；只退出采用关系不删除知识定义。物理回收遵守0050及所属引用保护；本规范不批准清除现有历史材料。

## 6. 最低验证

应覆盖：中文/非BMP字符/组合符/CRLF源范围；原字节解码失败；空输入；独立句段；重复文字不同出现；父内唯一顺序；同源范围越界/重叠拒绝；原文先存后解析；未知片段不造词；子句词索引与文本范围不可互换；两次规则复用不合并表达项；多方/引语/日记指代；历史绑定不随当前焦点变化；知识/学习跨owner部分失败与原请求读回。
