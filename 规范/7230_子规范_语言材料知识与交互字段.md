## 1. 结构约定

本规范固定逻辑字段、基数、数据来源和单一权威。下文结构不是已存在的C++ DTO，也不追加DATA-L1表列。节点承载身份、值承载类型化内容、关系承载引用和有序组成；集合与索引从这些事实读取，不建立第二份父指针或成员列表权威。

“引用”必须有目标种类和可读身份，不接受裸整数、路径或显示名。“?”表示可以缺省，缺省不等于0、空字符串或未知对象身份。“局部编号”仅在所属材料或规则内定位，不是全局节点身份。

语义内容与技术封套分开：下文不把事实代次、幂等、批次、生命周期重复列作每个对象的含义；结构服务按0050支持完整发布、当前可读定义和引用完整性，不恢复业务历史、历史截止或退出后载荷。固定原文/解析材料是仍被保存的语言内容，不是基础数据的历史读取模式。

## 2. 原始材料与三种表达尺度

### 2.1 文本材料与范围

```text
文本材料
  材料身份
  文本内容引用             // 固定Unicode标量序列
  原始接入材料引用?         // 原始字节/编码，或本次生成来源
  解码与对齐材料引用?       // 原始字节存在时必有可回查解码依据

文本范围
  文本材料引用
  起始标量位置
  结束标量位置
```

文本范围为零起点半开区间，单位固定为Unicode标量值，不是UTF-8字节、UTF-16代码单元或可见字形。组合附加符、表情、CR与LF分别计数；不能规范化、删空格或变换换行后继续沿用原范围。原始字节保留原编码；解码失败只保留原始材料，返回格式/解码失败，不静默替换字符生成成功文本。原文真实包含的U+FFFD不等于解码成功或失败，亦不受4240“词面材料”禁用字符规则的替代解释。

原始文字可以为空，表示确实收到空内容；空材料不是“解析成功”。正式句子/段落的范围非空且不越界，空白分隔范围不必伪造成句子。字节恢复、材料去重和物理保存复用现有材料合同；值可共享但语言出现身份不得合并。

### 2.2 固定内容字段

| 对象 | 逻辑内容字段 | 外部关系 |
| --- | --- | --- |
| 文章信息 | 节点身份、语言选择、标题值引用?、来源记录引用?、原文材料引用 | 有序段落组成、解析关联、可选文本世界锚点 |
| 段落信息 | 节点身份、原文范围 | 可选文章归属、独立时唯一语言来源关联、有序自然句组成、解析关联 |
| 自然句信息 | 节点身份、原文范围 | 可选段落归属、独立时唯一语言来源关联、解析关联 |
| 有序组成 | 关系身份、父材料节点引用、子材料节点引用、序号 | 属语言owner；文章→段落、段落→自然句 |

语言选择沿7220使用已知语言引用、显式未知或带范围的混合语言，未理解不制造汉语身份。段落/自然句继承文章或独立来源记录的语言选择，不重复保存相冲突的语言。单句、单段交互允许独立材料；没有上级就不制造空壳文章/段落。

独立语言来源关联指向语言owner保存的固定来源材料，其内容为语言选择、原接入来源引用（可缺省）及原文材料引用；范围必须相容。独立材料后来纳入组成时，必须校验继承语言与该来源一致，不能通过换父改变已保存原文的语种解释。来源关联不是额外文章身份。

组成关系按当前完整结构读取：每个子出现至多一个直接组成父；已组成时恰一父，父内序号唯一、非负且按升序读取，不要求连续。相同文字在两个位置必须有两个出现身份。不能把同一个子出现挂到两个父；复用材料时新建出现并引用相同内容。

同源文章的子范围必须位于父范围内，按源文次序排列且兄弟不重叠；分隔符可留在原文，不靠重拼子文本恢复全部原文。编辑重排、跨源拼接先形成新固定输出文本与对齐关系，再建立新组成，不伪称它是原文章的位置。父归属和子列表由同一有序组成关系正反读取。

### 2.3 解析与词出现

```text
句子解析材料
  解析材料身份
  来源自然句及固定内容引用
  解析规则定义引用
  语境依据              // 明确无语境依赖，或固定语境材料引用
  分段项有序组
  子句组成组
  候选含义组
  覆盖结果               // 完整、部分、未解析；显式给未覆盖范围

分段项 = 已确认词出现 | 未知片段 | 分隔片段
已确认词出现 { 局部出现编号, 原文范围, 正式词条引用 }
未知片段     { 局部出现编号, 原文范围, 词面候选组 }
分隔片段     { 原文范围 }
```

未经分词的句子可以先保存；无解析记录、完整空结果、部分解析不能互换。正式词出现必须读回词条；未知片段不填零词条或临时整数伪装正式词条。多种分词分别属于独立候选序列，不混成一个有重叠词序的假完整解析。

2330子句继续使用所属解析中的**词出现索引半开区间**，不是本节文本标量范围。正式子句只引用已确认词出现有序组；含未解决词边界的范围保留为解析候选，不伪装完整正式子句。每个词出现同时关联源文范围，二者通过该映射换算，不改义旧位置字段。修正分词建立新的固定解析结果材料，旧子句仍绑定原结果及原序列；使用相同算法/规则重新解析不要求新建规则定义，规则改变才引用新规则定义。本文“解析结果材料”和“解析规则定义”是两个不可互换的引用。

## 3. 语言知识字段

### 3.1 核心、目标与角色

```text
语言知识 { 节点身份, 目标描述引用, 描述结构引用 }

目标描述
  目标定义身份
  表达目的              // 陈述、提问、提出需求；子片段可继承
  角色定义组
  含义结构
  适用条件组

角色定义
  局部角色编号
  角色种类
  数量约束              // 单项、可选单项、有界集合
  必要约束组
```

角色种类闭合为概念引用、领域对象引用、特征类型引用、准确值、时间、语言材料引用、含义子项；领域对象再显式区分存在/场景视角、特征、状态、动态、关系、因果、需求、任务、方法。引用不能在这些类别之间靠数值强转。必要约束只使用7240的有限操作。

构式示例可将同一角色的多个允许领域对象类别简写为 `R1:{E,F}`：`R1` 是该规则内一个角色，`{E,F}` 是允许绑定类别的集合，不是新信息节点类型、集合对象或话语含义中的析取。正式知识仍用一个“领域对象引用”角色和必要约束中的有限类别条件表达；不得把不同角色种类（如概念引用与领域对象引用）强并为一个角色，跨种类用独立规则或已有子规则映射。若组合是否合法依赖多个角色，应在同一规则的适用条件中列出完整的合取分支，再以条件 OR 连接；例如“`R1` 属普通存在且 `C1` 为存在概念，或 `R1` 属实例特征且 `C1` 为特征概念”。仅写 `R1:{E,F}` 不保证 `C1` 与实际绑定类别相配。分支改变含义操作或作用域时必须拆成不同知识规则，不以条件分支掩盖不同含义。

含义结构由7240规定的类型化项、角色引用和作用域构成。未绑定变量、明确未知值、查询变量和已经绑定的对象不同；未知不填0、不等于否定。某角色是概念不表示另建一种概念本体，D/T/M使用对应对象引用或提议结构。

### 3.2 描述结构

```text
描述结构
  结构定义身份
  结构类别              // 基础表达、内容组织
  语言约束              // 指定正式语言；组织层可随子规则
  结构项有序组

基础结构项 = 固定词项 | 角色表达项 | 子规则项
固定词项   { 局部项编号, 词条引用或固定标点值 }
角色表达项 { 局部项编号, 角色编号, 表达方式 }
子规则项   { 局部项编号, 子知识固定定义引用, 角色映射 }

内容组织项
  局部项编号
  子表达目标
  取材规则
  子规则固定引用或按子目标选择
  角色映射
  展开方式              // 单项、逐项、分组
  选用条件
  缺材处理              // 必需不足、可选略去、明确表达未知
  衔接关系              // 无、并列、时间先后、转折、条件、因果、回应
```

结构项顺序为规则内顺序，不使用可变容器地址。角色表达方式允许名称表达、明确对象描述、已消解指代、作用域明确的变量指代表达、类型化字面值和子含义表达；变量表达必须保留其类型、绑定域、量化/查询用途和共享角色，不能用“谁/什么”掩盖原本要求唯一对象而尚未消歧的缺口。没有名称不能泄露句柄冒充自然语言名称。规则自身的标题或注释不参与执行。

“明确表达未知”必须是目标允许报告缺失，不能凭字段未查询就说“不知道”。因果/转折/条件衔接必须有对应含义输入，不能因结构项相邻就补写“因此”。用于省略的角色必须由唯一上下文或子映射可恢复；否则该结构不支持当前双向使用。

内容组织规则之间允许共享无环定义引用；按子目标选择形成的运行期递归遵守7240的完整范围和严格进展规则。不得把引用环称作语言递归并无限展开。

### 3.3 当次表达与解析对齐

```text
本次表达项
  局部出现编号
  所用知识固定定义引用
  本次角色绑定组
  本次选取的信息引用组
  子表达项有序组
  输出材料范围?          // 仅生成后有

含义对齐项
  来源材料范围
  含义项局部编号
  所用规则及角色映射
```

本次表达树、候选含义组和分数默认调用期保存，可随请求结束释放；需要留存的原文、已采用解析和学习样本由语言owner保存。对齐只能指向实际存在的材料与规则；不为证明正确性复制世界状态、二次特征结果或治理事实。

### 3.4 已采用集合条件主张

按请求保存“`A 有事`”等集合条件陈述时，语言owner保存一项有来源的已采用主张，而不是把概念直接写成现实存在的实例特征：

```text
集合条件主张
  主张身份
  所属交互语言场景引用
  来源语言材料与文本范围
  已采用解析及含义对齐项引用
  主体的强类型存在引用
  集合条件概念引用
  表达者引用或明确来源未明
  陈述作用域引用              // 普通陈述或具名引述范围
  时间参照                    // 来源表达时间引用、具名参照或明确未定
  本次主体绑定依据引用
```

主张只在主体已唯一绑定、概念的完整定义已读回、来源范围、含义对齐项和作用域一致时采用；含义对齐项以解析材料、含义项局部编号及规则/角色映射区分同一句内重复构式。缺少具体集合成员、表达者身份或绝对时间，或未进行现实求值，均不妨碍保存有来源主张；时间参照未定时不得把“当前”用于现实求值。主体未决、概念未形成或来源不可读时保留解析候选及缺口，不以空引用伪造一条已采用主张。重复陈述保留各自来源出现；后续纠正建立带来源的新解释或纠正关联，不原地改写旧来源。主张身份与概念身份、主体身份、任务身份分开；主张的存在不构成世界事实支持边，也不使主体正式拥有任务。

### 3.5 无上下文基础句型的转换材料

本节是单个短语/短句在空白自然语言场景中转换所需的逻辑材料，不新增节点族、持久知识核心字段或一套概念名称关系。物理合同可以沿用已有类型化候选和含义载荷，但必须能够分别表达：

```text
基础句型转换材料
  语言与固定原文
  语境依据 = 明确无交互上下文依赖
  所用知识引用及构式种类
  命名出现组
    局部出现编号、角色、原文范围
    词条引用、名称关系引用、来源概念引用
  固定词出现组
    结构项位置、原文范围、词条引用
  整数出现组（构式需要时）
    局部出现编号、原文范围、原始数字词面、规范十进制字符串
  类型化主张或被询含义
  场景及对象绑定组（构式需要且已取得时）
    自然语言场景引用
    局部对象出现编号、临时存在引用、来源概念引用
  候选组或唯一采用含义、实际完成阶段与未完成项
```

命名出现的概念引用与对象角色的存在引用不是同一个身份。普通类名先召回概念；S01、S03和S05需要的存在由7240第4.3节在候选唯一后建立，不要求调用方先给现实E或场景专名。S05的部分和整体按两个独立出现分别绑定，即使来源概念相同也保留两个存在身份；同一角色的显式映射仍须保持一致。这里的匿名存在不是第4.4节的指代实例，不需要代词概念或指向才能成立。S02及以它为子含义的S09只保留概念、知识和来源对齐，不要求空壳场景或对象绑定。

整数出现保存原词面和规范十进制字符串，具体词法按7240第4.3节；它是已识别整数含义的精确文本表示，不是未知值占位符。语言转换不得以`int64`承载范围裁剪整数，也不据此发布真实实例特征值。FT的正式类型约束、语言数字表示、领域准确值构造分别核验，不把三者混为一次赋值。

多候选阶段保存出现与候选解释，不为每个候选预建场景或存在。唯一采用后，场景结构和对象身份由所属世界树/存在公开入口取得；主张、对齐和采用解释可仅为调用期材料。返回场景及E不等于已持久保存完整主张、特征或组成关系；需要保存解析或主张时另按本规范第5节办理。技术失败后的实际已取得身份与可交付完整含义分别返回，不用旧候选伪装成功，也不谎称已经发生的写入为零。

## 4. 交互、指代与学习数据

### 4.1 交互记录

```text
语言交互记录
  记录身份
  表达者引用或来源未明
  接收者引用组或受众说明?
  语言材料引用
  发生时间材料             // 区分表达时间、接收时间及其未知
  回应的交互记录引用?
  引用来源材料组
```

正文仅引用，不复制到交互记录。作者、表达者、转发者、被引用说话者、接收者不同；回应不等于同意，引用不等于回应。日记/文章可以没有确定接收者或被回应消息。

### 4.2 本次交互上下文

```text
交互上下文（调用期）
  本次交互与材料范围
  自然语言场景引用或待保存场景材料
  关联现实场景引用组及关联依据
  当前说话者、受话者组
  当前话题/显著对象有序组
  参考中心、采用维度、参考时间与地点及其来源
  引语作用域栈
  接收方可用的角色/指示/前文/共同知识依据
  活动指代实例及待解候选组
  已采用出现到实例、目标或作用域变量的解释组
  待回答问题组
```

不是每个人永久持有一张全局代词表。可用数组/映射实现当次“我、你、这里、刚才”等取值，但键包含交互、作用域和出现位置。单指“你”须能唯一定位受话对象；多人场合需构式确定个人或群体。第三方角色、焦点顺序或出现先后都不足以单独确定“他/它”。时间、地点、参考中心未知就保留所缺约束，不采用机器当前时间或self所在场景补值。

已解释出现保留实际采用目标或变量；上下文更新只影响活动选择和后续解释，不能改变已保存解析内容。引用框架入栈/出栈恢复原说话者及参考信息；未解决的并列候选不任选首项。指代保存按1110发布与读回，并引用具体解析结果而非仅引用规则定义。

需要保存解析/学习时，只保存实际采用的固定语境材料：来源交互或教学材料引用、实际用到的说话者/受话者绑定、参考中心与时地、引语范围、指示/前文/共同知识依据及各项来源引用；缺省项显式未使用/未知，不复制整个会话缓存。无上下文依赖必须显式标记，不能以缺失引用冒充已核验；语境修正形成新材料，不改写原解析依据，不增加事实截止或历史载荷字段。

### 4.3 代词概念的统一定义

```text
代词概念定义
  独立概念身份
  允许目标类型范围
  参数角色定义组           // 目标、作用域、参照角色/中心、限制域等
  特征约束组               // 正式特征类型 + 被约束角色 + 值/值域
  关系约束组               // 具名关系/求值规则 + 类型化角色映射
  组合及适用条件
```

这是1110规定的统一逻辑定义形状，不是新增的C++类型表。定义的具体参数值由实例语境提供；身份查重使用规范化完整定义，名称和当次目标不参与。特征约束可以限定合法离散值、数值或有类型引用，也可以给出对应类型的允许值域；当次准确值与允许值域分开，不能一律压成数轴。二次特征必须声明输入角色、正式计算规则和结果域，其当次计算结果不写入通用定义。

以下是可组合的特征/约束维度示例，发布时必须映射为可读正式类型和规则；中文说明不是可任意解释的字段字符串，也不是固定代词分类表：

| 维度 | 类型化值或约束 | 定义与本次取值的分界 |
| --- | --- | --- |
| 目标范围 | 已登记节点类型的允许集合及概念条件 | “杯子”约束可进入表达组合；具体杯子身份属于实例 |
| 交互角色 | 本作用域说话者、受话者、第三方；可不施加角色限制 | 角色规则稳定，具体参与者从作用域取得 |
| 指示取向 | 近指、远指及所需参照角色/维度规则 | “这/那”不固定距离值，中心和适用维度来自语境 |
| 数量与群体组成 | 单项、多个、数量值域，包含/排除指定角色的条件 | 具体成员及“我们”是否含受话者由构式和语境决定 |
| 同一与回指 | 与某一绑定角色相同，或满足其回指约束 | “自己”须有可识别绑定域，不能永久等同于系统自我 |
| 选择与量化 | 待求角色、限制域、全称/存在/任指条件 | 量化作用域与谓词按7240组合，不把未求值当作不成立 |
| 关系参与方式 | 集合整体、成员逐项、具名互指规则 | 关系方向和覆盖要求由构式给出，不能由复数自动推全配对 |

典型定义组合及本次应用如下；每行只是用法，不能转为互斥的概念大类：

| 表达 | 主要定义约束 | 本次必须确定或保留的参数 |
| --- | --- | --- |
| 我 / 你 | 目标承担说话者 / 受话者角色 | 本次作用域和参与者；引语可以改变角色取值 |
| 他 / 她 / 它 | 第三方及该语言用法的目标类别/称谓条件 | 可恢复的具体目标；称谓不能直接当生理事实 |
| 这 / 那 | 近指 / 远指，依赖相应参考中心 | 指示依据、维度和目标范围；不限于物理空间 |
| 谁 | 可承担相应主体角色的待求身份 | 限制域、变量及其绑定作用域；是否询问由整句决定 |
| 什么 | 待求内容或对象，范围由角色约束限定 | 不预设为具体物体；保留类型候选和本次用途 |

| 每个 / 任何一个 / 某个 | 限制域与量化条件，依附完整表达 | 谓词作用域、分配方式或未知成员；不要求先枚举未来成员 |

“这个杯子”整体形成一个实例：近指条件、杯子条件及数量共同约束所指；“那本书”是另一个实例。后续“它”可在相同语境和兼容约束下引用前者，并保存本次采用的杯子目标。再次出现“这个杯子”不因词面相同就强制复用；重新指向另一个杯子时，须区分后续活动选择与此前出现的固定解释。

变量属于场景内规则/查询等信息的内容，不取得虚构现实存在身份。相同变量的多处使用须映射到同一所属材料与局部编号；不同作用域的同名变量不合并。候选、变量和已确定目标互为不同载荷分支，不能同时假称唯一绑定；它们与7230的解析覆盖结果、7240的表达目的和工程失败分开。

纯解析可以只产生调用期实例材料。按请求保存语言场景和指代实例时，允许保存语义完整的作用域变量或有来源的未决实例，不要求先造一个具体目标；未决实例有自身信息身份，不等于已成立指向具体对象的关系。语言场景结构与实例内容的写入分别遵守既有场景/语言服务合同，场景成员关系只保留一份权威。

“杯子A/杯子B”等实例专名经其所属领域别名合同指认已有目标；可减少代词使用，却不删除目标原有指代实例，也不把实例别名改为概念名称。指代实例不是目标本身、词条出现或名称关系，三条路径不可相互替代。

## 5. 写入和引用闭包

语言材料、组成、解析、指代实例内容与出现绑定、已采用集合条件主张、知识、知识内目标/结构以及学习/采用关系均静态路由既有语言owner；词条、名称、概念、场景结构、原始不可变材料仍归各自owner，不转移所有权。代词概念与语言实例分别写入；实例指向任何领域目标都不取得目标写入权。新角色编码与公开读写面由语言专属物理合同集中冻结，不能把本节对象名称直接加到通用节点族枚举。
