## 1. 结构约定

本规范按1100分解语言记录的原始材料、文本范围、跨对象组成规则、语言材料范围节点和交互记录。句子解析与词出现字段见[7231](7231_子规范_句子解析与词出现字段.md)，语言知识、表达材料及学习字段见[7232](7232_子规范_自然语言知识与表达材料字段.md)，指代与交互上下文字段见[7233](7233_子规范_指代与交互上下文字段.md)；三者共用本节结构约定。

本规范固定逻辑字段、基数、数据来源和单一权威。下文结构不是已存在的C++ DTO，也不追加DATA-L1表列。节点承载身份、值承载类型化内容、关系承载引用和有序组成；集合与索引从这些事实读取，不建立第二份父指针或成员列表权威。

“引用”必须有目标种类和可读身份，不接受裸整数、路径或显示名。“?”表示可以缺省，缺省不等于0、空字符串或未知对象身份。“局部编号”仅在所属材料或规则内定位，不是全局节点身份。

语义内容与技术封套分开：下文不把事实代次、幂等、批次、生命周期重复列作每个对象的含义；结构服务按0050支持完整发布、当前可读定义和引用完整性，不恢复业务历史、历史截止或退出后载荷。固定原文/解析材料是仍被保存的语言内容，不是基础数据的历史读取模式。

## 2. 原始材料与组成

### 2.1 文本材料与范围

```text
文本材料
  材料身份
  文本内容引用             // 固定Unicode标量序列
  原始接入材料引用?         // 原始字节/编码，或本次生成来源
  解码与对齐材料引用?       // 原始字节存在时必有可回查解码依据

文本范围
  文本材料引用
  起始标量位置
  结束标量位置
```

文本范围为零起点半开区间，单位固定为Unicode标量值，不是UTF-8字节、UTF-16代码单元或可见字形。组合附加符、表情、CR与LF分别计数；不能规范化、删空格或变换换行后继续沿用原范围。原始字节保留原编码；解码失败只保留原始材料，返回格式/解码失败，不静默替换字符生成成功文本。原文真实包含的U+FFFD不等于解码成功或失败，亦不受4240“词面材料”禁用字符规则的替代解释。

原始文字可以为空，表示确实收到空内容；空材料不是“解析成功”。正式句子/段落的范围非空且不越界，空白分隔范围不必伪造成句子。字节恢复、材料去重和物理保存复用现有材料合同；值可共享但语言出现身份不得合并。

### 2.2 组成、语言选择与来源

文章、段落、自然句各自的逻辑内容字段与外部关系按2300、2310、2320第2节，本节不重复列字段表，只规定跨对象的组成、语言选择与来源规则。

```text
有序组成
  关系身份
  父材料节点引用
  子材料节点引用
  序号                      // 属语言owner；文章→段落、段落→自然句
```

语言选择沿7220使用已知语言引用、显式未知或带范围的混合语言，未理解不制造汉语身份。段落/自然句继承文章或独立来源记录的语言选择，不重复保存相冲突的语言。单句、单段交互允许独立材料；没有上级就不制造空壳文章/段落。

独立语言来源关联指向语言owner保存的固定来源材料，其内容为语言选择、原接入来源引用（可缺省）及原文材料引用；范围必须相容。独立材料后来纳入组成时，必须校验继承语言与该来源一致，不能通过换父改变已保存原文的语种解释。来源关联不是额外文章身份。

组成关系按当前完整结构读取：每个子出现至多一个直接组成父；已组成时恰一父，父内序号唯一、非负且按升序读取，不要求连续。相同文字在两个位置必须有两个出现身份。不能把同一个子出现挂到两个父；复用材料时新建出现并引用相同内容。

同源文章的子范围必须位于父范围内，按源文次序排列且兄弟不重叠；分隔符可留在原文，不靠重拼子文本恢复全部原文。编辑重排、跨源拼接先形成新固定输出文本与对齐关系，再建立新组成，不伪称它是原文章的位置。父归属和子列表由同一有序组成关系正反读取。

### 2.4 语言材料范围节点与有效分界结果

语言材料范围（来源出现定位＋固定文本材料＋待分界标量范围）由语言owner建成可独立引用的正式信息节点（1100），可作为需求的目标信息节点（3100统一形状，不设专属需求种类）。该节点持有“有效分界结果”实例特征F（方案A，3100），其当前值为当前有效采用的分界结果材料引用；分界结果材料或采用关系变化时，语言owner在同一次组合发布中维护该F，二者不一致属于结构不一致。本节承载其语言结果及来源，不把语言材料变成普通存在、词条或指代实例。

```text
原文范围分界结果材料
  材料身份
  语言材料范围节点引用
    来源出现定位
    固定文本材料引用
    待分界标量范围[start,end)
  同来源语言选择及其读取依据
  有序分界项组
    原文标量子范围
    本次用途 = 拟登记词面 | 分隔材料
  分界依据
    正式规则及其适用范围／必要语境
    或 本次明确分界回答及其询问关联／解释／原文对齐

分界结果采用关联
  针对的语言材料范围节点
  采用的分界结果材料引用
  本次采用依据及适用范围
```

1. **来源与出现。** 来源出现定位优先复用既有正式语言来源键／出现路径；本叶网页链为接收消息M＋固定原理解根范围＋根出现路径。固定文本必须与该来源的正文材料互证，待分界范围非空且在原理解根范围内，坐标遵守第2.1节。根出现可使用正式来源的空路径，不按候选数组位置臆造路径。同一材料用于不同M、不同出现或不同范围时不合并目标；正文或材料哈希相同不建立出现同一性。
2. **来源前置。** 固定接收材料／出现定位不要求完整含义U、正式词条或被认知需求D先存在。具体读口若依赖这些后续对象，须先补齐前置来源提供者，不能伪造U／D使查询成立。采用含义、解析结果和候选序列是依据与接续材料，不进入目标键；重新解释不换原问题键，也不因此重建已有原待完善D。原工作／已有D的接续由明确来源关联处理，不能仅凭结果中的材料身份推断。
3. **先行分界材料与词出现分账。** 有序分界项可先于词条存在，只说明该范围边界的材料与依据，不是7231第2节的「已确认词出现」，不能填0词条或临时词条。完整结果的分界项在目标范围内严格有序、不重叠，合起来覆盖整个目标范围；标点／空白作为分隔也须有依据，不默删字符。部分覆盖只保留部分材料，不报告整个目标有效；正常多套边界保留为不同候选，不混排成一套结果。词条登记、正式读回后才整体发布引用真实词条的当前解析／词出现；原材料和旧解析元素仍被引用时按引用计数保留。
4. **两类依据分别成立。** 正式规则路线须引用实际规则／知识、作用范围及必要语境，能确定该出现的完整边界；明确回答路线须引用实际接收回答、与本次正式询问及目标的明确关联、回答解释和原文对齐。两路不要求同时具备。最长匹配、外部词典前缀、单套候选或未命中本身均不证明边界；收到回复、时间在问句之后或正文相同也不证明回答关联。没有边界依据保留未知，回答仍多解保留歧义，不按时间、编码或数组次序取首。
5. **保存与采用。** 沿1100归既有语言owner保存分界材料和针对目标的采用关联，不另建分词owner，不把材料存在等同当前有效采用。重复的同目标、同边界、同依据提交复用；异义不覆盖仍被引用的固定材料。明确修正整体发布当前采用，旧材料仍被引用时按引用计数保留，不自动采用最新一条。
6. **当前有效与fresh复核。** 以语言材料范围节点及其“有效分界结果”F正式读取：有且只有一个当前有效采用，材料、来源、范围一致，完整边界及依据／必要语境仍适用时，才可向3100交付该目标的有效结果（F当前值）。无结果、部分覆盖、依据不足或仅有未采用候选时不交付已满足材料；依据不再适用时保留旧材料并重新筹办。多个互斥的当前有效采用是结构不一致，不能降为正常歧义。工程读取／发布故障、坏引用和资源失败不能伪装未知、空结果、未满足或前提变化。
7. **准入与语义界限。** 有充分规则依据时可在缺口外保存、正式读回后直接进入规范化／词条准入，不强制人工。未知未登记不自动提出分界子需求。规范化不能修改固定原文和旧范围；产生另一词面值时保留合同与对齐。结果只确定边界，不确立概念含义、现实事实、原句理解、需求确认或self承接；后续仍须登记读回、重新解释和同原工作／已有同D接续。

本节是逻辑材料合同，不是已存在的节点角色、C++ DTO或持久schema。前置来源、结果写入与fresh读口、引用保活／退出及恢复、问题／回答关联、任务消费者及同D接续的实际公开API须另行形成提供者设计；不因本节而取得施工或初始化登记资格。

## 3. 交互记录

```text
语言交互记录
  记录身份
  表达者引用或来源未明
  接收者引用组或受众说明?
  语言材料引用
  发生时间材料             // 区分表达时间、接收时间及其未知
  回应的交互记录引用?
  引用来源材料组
```

正文仅引用，不复制到交互记录。作者、表达者、转发者、被引用说话者、接收者不同；回应不等于同意，引用不等于回应。日记/文章可以没有确定接收者或被回应消息。

本次交互上下文（调用期）见7233第2节。

## 4. 写入和引用闭包

语言材料、组成、语言材料范围节点及其分界结果与采用关联、交互记录均静态路由既有语言owner；解析、知识、学习与指代的写入归属分别见7231、7232、7233。词条、名称、概念、场景结构、原始不可变材料仍归各自owner，不转移所有权。新角色编码与公开读写面由语言专属物理合同集中冻结，不能把本节对象名称直接加到通用节点族枚举。

允许原文先独立发布，解析失败不撤销已接收原文。外部端点先取得正式身份，跨owner只能分阶段记录各实际结果，不能伪称一个跨领域原子事务。读取必须区分当前可读材料和来源已不可读；发布未知按原请求核对真实结果，不改键猜重建；物理删除及引用完整性遵守0050，不建立历史版本服务或退出后读取例外。

## 5. 最低验证

应覆盖：中文/非BMP字符/组合符/CRLF源范围；原字节解码失败；空输入；独立句段；重复文字不同出现；父内唯一顺序；同源范围越界/重叠拒绝；原文先存后解析；交互记录的表达者、接收者、引用与回应分账；跨owner部分失败与原请求读回。

语言材料范围节点与有效分界结果另须覆盖：“有效分界结果”F与采用关联同一次发布一致；无U／词条／D的前置来源；共享材料不同消息／出现不合并；新U不改问题键；先行范围材料与正式词出现分离；部分覆盖与完整结果分账；规则或明确回答分别提供依据；仅一套候选仍不足；唯一当前有效采用及fresh复核；正常歧义与互斥采用损坏分账；规范化保留旧范围；原工作／已有同D接续；技术故障不伪装正常未知。

验证实施与是否运行测试按AGENTS第7.1节，不因列有用例就推定已执行。
