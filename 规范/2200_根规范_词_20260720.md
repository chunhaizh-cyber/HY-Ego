# 2200 根规范 词

编号：2200

日期：20260815

状态：正式根规范

## 1. 根定位

词是自然语言中经分界和规范化确认的可复用语言登记单位。词的文字内容是值；只有当该值需要被语言记录复用、被概念名称关系引用或保持稳定查找身份时，才形成最小词条节点。当前只登记词条，不建立语素或词性节点族。

词条不是概念、概念类型、业务对象、词义裁决或世界事实。某个词在文章、段落或自然句中的一次出现属于语言组成证据，不得与全局词条身份混成同一事实。

## 2. 最小词条结构

正式词条至少由以下结构共同成立：

```text
词条稳定身份
+ 语言身份
+ 规范化词面值
+ 规范化合同身份
+ 来源与创建 / 退出生命周期
```

词条不得保存概念类型、唯一目标概念、业务对象类型、首选名称标记或上下文裁决结果。词条可以成为一个或多个概念的名称成员；名称角色和目标概念由 2210 的具名关系表达，不复制为词条字段。

## 3. 唯一性与规范化

1. 同一语言、同一规范化合同和同一规范化词面只能形成一个当前词条身份；重复创建必须幂等读回。
2. 显示文字相同但语言或规范化合同不同的材料不得直接判为同一词条。
3. 外部编码、分词器标签、大小写变体和兼容字形只能作为来源材料；进入正式词条前必须按具名合同规范化。
4. 自然句中的词序必须保留每次出现及顺序。同一词条重复出现不得因身份相同而去重。
5. 短语、未解析句段、说明性长名称和只为显示产生的字符串只能先进入语言记录或候选；不得绕过规范化准入成为正式词条。
6. 字、词根、词缀或其它构词材料当前只作为绑定语言位置和解析版本的候选材料；不得因一次分词结果建立长期节点或组成关系。只有真实构词业务出现且词条本身不足以表达时，才能先修订本规范和 4240，再决定是否建立新的强类型结构。

## 4. 语素和词性后置边界

当前没有正式语素身份、语素节点族、语素 CRUD、词条—语素组成关系、正式词性身份或词性 CRUD。分词器给出的语素边界、词根、词缀和人类词性标签都只是本次解析候选，至少绑定：

```text
语言记录位置
+ 解析合同与版本
+ 原始材料范围
+ 候选标签与置信材料
```

这些候选可以丢弃和重算，不取得稳定身份、生命周期、引用保护或 DATA 写入权。不得把候选材料写成词条字段，也不得复活“语素入口”作为词条与概念之间的中间身份。

后继若确实需要跨词复用构词单位，必须先证明词条、语言位置和解析候选不能满足需求，并另行冻结强类型身份、唯一性、组成关系、生命周期、发布与读回合同。在该合同形成前，“语素”只是一种解析说法，不是项目机器事实。

词性只允许在后继语言理解任务中，依据本次词出现、名称候选所指目标的正式强类型、句法关系和上下文形成值式判断。该判断不持久化，不反写词条或目标节点，也不得充当信息入口类型、概念根、本体类型或存储路由。

## 5. 与概念的边界

词条与概念通过 2210 的具名概念名称关系直接连接：

```text
概念 --首选名称 / 别名 / 简称--> 词条
```

同一概念可以引用多个词条；同一词条也可以命名多个概念。词条身份、名称关系和概念身份分别拥有自己的生命周期，退出一条名称关系不得删除仍被其它关系或语言记录引用的词条，也不得改变概念本体。

存在 / 特征 / 动态 / 因果链本体根、上位概念、定义约束和类型均属于 2220 概念结构，不属于词条。词条通过名称关系召回零个、一个或多个目标候选；每个候选的类型必须从目标概念、信息节点或其唯一领域服务正式读回。词面、解析标签、名称关系或索引命中都不能单独建立根、概念身份、目标类型或裁决唯一概念。

## 6. 词索引

词索引只按以下最小键召回词条：

```text
语言身份 + 规范化合同身份 + 规范化词面
-> 词条稳定身份
```

索引是从当前已发布词条确定重建的非权威加速结构。索引命中后必须回读词条；概念候选必须继续通过名称关系反查，索引不得直接保存或裁决唯一概念。

## 7. 写入、读取与使用判定

`DATA` 之外具名词面规范化业务负责依据规范化合同，从原始语言材料形成规范化词条候选及其来源证据，但不写语言、词条、名称关系或索引。`DATA-L2` 语言结构服务只校验调用方提交的规范化结果与合同、材料读回一致，负责语言和词条的强类型 CRUD；它不执行分词、规范化算法、词性判断或词义解释。概念名称关系由 2210 规定的唯一名称关系服务写入；外部调用方不得绕过服务直接写节点、关系或索引。

正式读回应至少验证：

```text
词条当前可读
语言、规范化合同和规范化词面完整
同一规范词条无第二当前身份
索引命中后精确回读相同词条
词条的概念候选只来自当前名称关系
```

实际消费者还必须在所需路径读回名称目标的正式强类型身份，并证明词条没有保存或替代该类型；施工检查不替代实际使用判定。

## 8. 禁止事项

- 禁止把词面、显示名、分词结果或人工标签直接作为概念或业务事实。
- 禁止把词条与概念合并为同一节点身份。
- 禁止在词条上保存单一概念指针或概念类型字段。
- 禁止建立持久词性、信息入口类型或默认词到类型路由表。
- 禁止在缺少新正式合同的情况下建立语素身份、语素 CRUD 或词条—语素组成关系。
- 禁止把词索引升级为名称关系或概念唯一性的权威来源。
- 禁止由控制面板、日志或说明文档补造机器中不存在的词条和名称关系。
