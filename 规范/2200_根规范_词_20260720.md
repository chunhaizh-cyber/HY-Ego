# 2200 根规范 词

编号：2200

日期：20260814

状态：正式根规范

## 1. 根定位

词是自然语言中经分界和规范化确认的最小可复用语言身份。词的文字内容是值；只有当该值需要被语言记录复用、被概念名称关系引用或保持稳定查找身份时，才形成最小词条节点。

词条不是概念、概念类型、业务对象、词义裁决或世界事实。某个词在文章、段落或自然句中的一次出现属于语言组成证据，不得与全局词条身份混成同一事实。

## 2. 最小词条结构

正式词条至少由以下结构共同成立：

```text
词条稳定身份
+ 语言身份
+ 规范化词面值
+ 规范化合同身份
+ 来源与创建 / 退出生命周期
```

词条不得保存概念类型、唯一目标概念、业务对象类型、首选名称标记或上下文裁决结果。词条可以成为一个或多个概念的名称成员；名称角色和目标概念由 2210 的具名关系表达，不复制为词条字段。

## 3. 唯一性与规范化

1. 同一语言、同一规范化合同和同一规范化词面只能形成一个当前词条身份；重复创建必须幂等读回。
2. 显示文字相同但语言或规范化合同不同的材料不得直接判为同一词条。
3. 外部编码、分词器标签、大小写变体和兼容字形只能作为来源材料；进入正式词条前必须按具名合同规范化。
4. 自然句中的词序必须保留每次出现及顺序。同一词条重复出现不得因身份相同而去重。
5. 短语、未解析句段、说明性长名称和只为显示产生的字符串只能先进入语言记录或候选；不得绕过规范化准入成为正式词条。
6. 如果未来需要字、词根或子词组成，只能以语言组成关系和顺序表达；不得复活“语素入口”作为词条与概念之间的中间身份。

## 4. 与概念的边界

词条与概念通过 2210 的具名概念名称关系直接连接：

```text
概念 --首选名称 / 别名 / 简称--> 词条
```

同一概念可以引用多个词条；同一词条也可以命名多个概念。词条身份、名称关系和概念身份分别拥有自己的生命周期，退出一条名称关系不得删除仍被其它关系或语言记录引用的词条，也不得改变概念本体。

存在 / 特征 / 动态本体根、上位概念、定义约束和类型均属于 2220 概念结构，不属于词条。词性只能经 7210 的 L5 外任务局部多对多路由形成零个、一个或多个本体根 / 对象角色候选；词面、词性、名称关系或索引命中都不能单独建立根、概念身份或裁决唯一概念。

## 5. 词索引

词索引只按以下最小键召回词条：

```text
语言身份 + 规范化合同身份 + 规范化词面
-> 词条稳定身份
```

索引是从当前已发布词条确定重建的非权威加速结构。索引命中后必须回读词条；概念候选必须继续通过名称关系反查，索引不得直接保存或裁决唯一概念。

## 6. 写入、读取与验证

L5 之外具名词面规范化业务负责依据规范化合同，从原始语言材料形成规范化词面候选及其来源证据，但不写语言、词条、名称关系或索引。L2 语言 / 词条结构服务只校验调用方提交的规范化结果与合同、材料读回一致，负责词条创建、语言归属、词出现和词索引重建；它不执行分词、规范化算法或词义解释。概念名称关系由 2210 规定的唯一名称关系服务写入；外部调用方不得绕过服务直接写节点、关系或索引。

正式读回应至少验证：

```text
词条当前可读
语言、规范化合同和规范化词面完整
同一规范词条无第二当前身份
索引命中后精确回读相同词条
词条的概念候选只来自当前名称关系
```

## 7. 禁止事项

- 禁止把词面、显示名、分词结果或人工标签直接作为概念或业务事实。
- 禁止把词条与概念合并为同一节点身份。
- 禁止在词条上保存单一概念指针或概念类型字段。
- 禁止把词索引升级为名称关系或概念唯一性的权威来源。
- 禁止由控制面板、日志或说明文档补造机器中不存在的词条和名称关系。
