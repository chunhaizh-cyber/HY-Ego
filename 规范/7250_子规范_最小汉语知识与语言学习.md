## 1. 冷启动与学习目标

先天语言知识提供最小可解释的含义—形式对应，后天学习扩展表达和组织。概念知识提供“是什么”，世界与治理信息提供“发生/需要/能做什么”，语言知识提供“怎样说”；三者不能互相替代。

首批范围是有限汉语文字，不要求语音、外部分词器或大模型存在。规则先形成语言域可读知识，再由相同解释器使用；不得硬编码一套输出模板并在学习时另造不兼容知识仓。

“最简句型可穷举”只对本节明确列出的操作和构式闭集成立，不代表全部汉语、全部词或全部含义可一次列全。陌生句可保存、返回未理解并学习，不以追求覆盖率为由猜造事实。

## 2. 最小种子知识集合

表中A/B为有明确类型的参与角色，C为概念，P为正式特征类型的合法表达，V为准确值或显式概念条件，T/M为任务/方法对象，X/Y为子含义。它们是模式变量，不是预先固定的世界身份。每一行发布时要展开为7230完整目标、角色约束、结构与来源，表面文字本身不是可执行数据。

| 种子 | 目标与角色约束 | 典型结构 | 输入关键限制 |
| --- | --- | --- | --- |
| S01 | 对象归类：A对象、C概念 | A是C | 不自动创建实例/支持关系 |
| S02 | 概念上下位：A/C均为概念 | A是一种C | 不与对象指认合并 |
| S03 | 特征描述：A、P、V | A的P是V | 概念值不补准确数值 |
| S04 | 场景包含：B场景、A成员 | B里有A | 直接/递归含义未清则待解 |
| S05 | 组成：B整体、A部分 | A是B的一部分 | 不暗示A穷尽B的全部组成，不把拥有/附近一律当组成 |
| S06 | 空间方位关系：A/B、关系概念 | A在B的R | R须读回空间角色与关系定义，不能套用任意关系 |
| S07 | 具名比较：A/B、P、结果域 | A比B更Q | Q按比较规则和概念解析，不仅凭正负字面 |
| S08 | 否定：子含义X | 不是X／A没有P | 分立具名构式，不用否定词替换任意句 |
| S09 | 确认询问：子含义X | X吗 | 问句不宣称X成立 |
| S10 | 填项询问：P、A、查询变量 | A的P是什么 | 未知变量不是值0或一个未知存在 |
| S11 | 表达需要：A、目标含义X | A需要X | “A需要”只是主张/提议，不等于self确认 |
| S12 | 行动请求：B、目标X | 请B使X | 受请求者、目标及限制须可解析 |
| S13 | 信息请求：B、查询X | 请B告诉我X | 取得信息不等于执行被描述动作 |
| S14 | 能力/方法预期：A、M、FT/结果 | A能通过M使X | “会”含未来义时不能强选能力义 |
| S15 | 任务目标/进度：T及正式投影 | T的目标是X／T已经完成 | 分别对应目标与阶段；输入不能改任务状态 |
| S16 | 变化：A、P、前后材料 | A的P从V1变为V2 | 无时间/场景仅变化主张，不造动态 |
| S17 | 并列/时间：X/Y | X，并且Y／先X，再Y | 两条独立规则，时间顺序非因果 |
| S18 | 条件/因果：X/Y | 如果X，那么Y／因为X，所以Y | 两条独立规则，假设及因果主张不入现实事实 |
| S19 | 引述：来源A、子含义X | A说X | X置于引述域，指代重新绑定 |
| S20 | 回应：来源消息、回应内容 | 关于X，回答是Y／我指的是A | 回答、明确所指、同意及承接不可混同 |

同一行含多个形式时要建立不同基础结构并共用可共用目标，不能依赖斜线在运行时猜句法。关系R、比较Q及对象/概念名称通过已有概念与词条名称取得；缺名称时走7220命名路径，不用固定字面词绕过正式概念端点。固定功能词如“是、的、能”只要求合法词条及已知结构作用，不强制建立世界概念或概念名称关系。

初始组织知识至少覆盖：单项回答；对象的多个特征列举；目标—实际步骤—实际结果的任务过程；按主题/场景/事件时间分段的叙述。每项使用7230的取材和缺材合同。复杂连接、省略、转折、多段总结逐步学习；尚未覆盖的组织返回缺规则。

## 3. 一条样本即可启动的学习过程

### 3.1 输入与分流

学习输入至少包括固定样本/范围、学习目标、可读含义依据、原语境、已有规则候选和有限预算。依据可以来自明确教学指向、已知对象/事实的同期描述、已理解的改述、纠正或独立反馈。外部说话者陈述本身只是语言材料；其事实真伪仍由领域裁决。

有三条合法起点：

1. 已知含义→观察怎样表达：从对象/角色与样本对齐，形成基础规则。
2. 已有语句→归纳结构→寻找含义依据：未找到前只保留结构候选，不凭句频补含义。
3. 已理解子句/事件→观察组合方式：学习选材、分组、顺序与衔接，不重新定义子句含义。

### 3.2 形成步骤

1. 保存样本和原始语境，定位已知词、角色、时间、否定与引语；区分不会分词、缺名称、缺概念、歧义、缺表达规则和缺组织规则。
2. 对齐样本片段与强类型含义。对齐多解则保存候选和差异；没有对齐依据不得发布可用于含义判断的规则。
3. 在单个样本中，将已有对象/值对齐片段替换为受约束角色，保留尚无泛化依据的固定词和范围。不能仅因为A是存在就推广为所有存在；一例可用但范围应限于已证明类别或具体对象。
4. 多样本时比较已对齐含义和形式，抽取共同项、差异角色与可选组织项。差异可以产生多个规则，不强行取交集抹去否定、参与者或因果方向。
5. 生成7230/7240可解释结构，检查角色类型、必需项可恢复、作用域、选择器和子规则可用、定义无环及预算进展。不认识的操作保持候选，不生成脚本或默认调用。
6. 对完整定义做规范化查重：局部角色按首次结构出现顺序重编号；保留角色种类、约束、语序、固定词、作用域、子规则定义与映射；无序AND条件确定排序，顺序组成不排序。完整相等复用，摘要仅索引、内容须精确互证；同目标不同形式是不同知识。
7. 完整定义可经语言owner发布，并以学习关联记录样本/依据；首例按已证明范围限定试用。若仍只有结构候选，不建立正常采用关系。
8. 用新样本、独立反馈或明确教学检验，按实际结果继续采用、收窄、拆成多项、停止新用或发布修订定义。定义变化不得改写此前表达树的所用版本。

## 4. 从句到段到篇的组织学习

不只比较相同词序，也比较“表达目标→选了哪些信息→怎样分组/先后→用了哪些衔接”的对应。

例如已知任务确有目标、两次实际执行、一次纠正和最终结果；对方依此先说明目标、再叙述尝试、最后报告结果。可学习角色化组织规则，取材指向真实任务投影，步骤用有界逐项展开，纠正为有依据的可选分支。不能把示例中恰好两次尝试写成所有任务必有两步。

文章组织进一步复用段落规则，学习主题维持、场景转换、时间跳转、前指和总结。按主题回叙不是实际事件逆序；语言省略不是事件不存在。输出选材完整性取决于用户表达目标，不要求列出全部历史。

## 5. 使用反馈、修订与淘汰

反馈至少区分：指错对象、名称不合适、句式/作用域误解、组织遗漏/顺序不清、来源事实错误、未送达。分别回到指代、名称、规则、组织、对应领域或输出通道；事实错不一定语法错，未送达不等于规则无效。

使用记录保留知识固定定义、实际方向/范围、源样本、对齐和反馈引用。能从关系统计的使用次数、成功率和最近使用不复制为核心字段；没有独立反馈不自动计为成功。“明白了”只保存其实际回应及可确认范围，不将整个知识库可靠性置真。

采用准则：限定试用只在已证明角色/范围内用；独立验证无已知反例且覆盖拟采用范围，才扩大为该范围的正常使用；新反例先定位是否违反规则前提，确属规则误判则收窄或停止受影响范围，不停止无关知识。

淘汰先停止新用，再按知识引用与来源保护退出采用关系；可用更简单规则覆盖同一目标且不损失必需含义时，旧规则可停止优先选择。低频只提供候选理由，不能删除仍有唯一用途或历史引用的定义。物理回收按0050/语言结构合同另行执行，不以“淘汰”直接擦除原始对话。

## 6. 不以自我循环证明学习

自生成→自解析→一致只检查往返合同；重复同一材料、复读、翻译再译回不算新的独立依据。必须另外保留来自真实对象对齐、教学修正、其它已解释材料或交互行为反馈的验证来源。

学习“能描述”的规则不建立“能执行”的方法。通过文章获取方法时只能产生条件/预期结果/步骤学习材料；真实函数注册、参数规格、任务执行验证和方法完善仍服从3300/5350/5360/8210。

“空作为有类型未知的正式概念”是概念侧待补合同，不是本规范新建的语言知识类型。现行普通概念合同尚不支持时，返回概念形成合同缺失，保留类别依据、原文和未完成学习目标；不得宣布已完成从无到空，也不取消这一后继目标。

## 7. 验证与完成边界

至少覆盖种子每一独立构式的正例、近似反例与输入/输出；单例有依据可形成限定规则、无依据只存候选；相同形式多义；对象替换但类型不相容；否定/引语/条件保留；组织可选项缺失；自反馈不算独立验证；扩大范围遇反例收窄；同义查重不合并不同语序；规则退役后旧表达读回；缺概念/名称/提供者不假成功；所有预算及发布失败分支。

达到有限种子闭环、具名组织闭环和真实学习闭环分别报告，不以模板数量、解析成功率或一次回话证明通用语言、思考或自组织治理已经完成。机器函数和物理保存尚须具名实现合同，不由本规范虚报已有代码。
