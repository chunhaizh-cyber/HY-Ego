# 4010 子规范 通用稳定身份、关系与索引边界

编号：4010
日期：20260803
状态：正式子规范

直接上级规范：0050。

相关边界规范：0500、4020—4070。

## 1. 定位

本规范规定 L1 通用稳定身份、版本化关系和非权威索引边界。原文件名为兼容现有引用保留；标题和正文已经退出“运行期统一仓库、固定句柄、固定节点 / 关系编号 ABI”口径。

## 2. 稳定身份

1. 通用身份使用不透明、非零、不可复用的稳定值；内部产生、外部接纳和恢复接纳必须分开准入。
2. 调用方不能指定内部身份，不能从名称、表列、内存地址、节点号、关系号、句柄值或索引键推导身份。
3. 未进入内存已发布代次的候选不是事实，不得外泄。已发布或已退役身份永久占用；未知发布结果不得生成第二身份。
4. 通用身份只证明业务中性对象存在。业务资格、对象类型和领域授权由领域服务另行发布。

## 3. 类型和版本

1. 每个身份必须绑定已发布类型合同身份和版本；未知、停止新写或已退出合同不得用于普通新写。
2. 身份版本、业务对象版本、关系版本和值记录版本分别管理，不得用一个裸版本号复义。
3. 历史版本不可变；当前换代必须使新当前和旧当前退出在同一内存事实事务与代次发布中成立。

## 4. 关系事实

完整关系至少包含：

```text
关系稳定身份
+ 关系类型合同身份和版本
+ 源端稳定身份及要求版本
+ 目标端稳定身份及要求版本
+ 角色 / 顺序
+ 关系版本、生命周期和发布证据
```

1. 内存已发布代次中的关系是拓扑、归属、组成、来源、当前值和引用的运行期权威表达；便利字段、SQL 行和缓存不得形成平行运行期事实。
2. 关系类型、方向、角色、基数和领域语义由对应领域规范裁决；L1 只验证端点、合同、版本、唯一键和通用生命周期。
3. 关系换代、失效和退役保留历史，不得原地重写端点或复用身份。
4. 通用单父、重挂、自动反向边或名称匹配不作为默认规则。

## 5. 索引

1. 索引只保存从查询键到稳定身份候选的可重建映射；物理键不进入公开业务接口。
2. 索引命中后必须回读同一内存已发布代次的身份、类型、关系、版本和生命周期。
3. 索引未命中只能表示候选未召回，除非查询合同明确声明索引覆盖该内存代次及完整键空间，因而可以确认“未找到”。SQL 查询不得作为普通运行期权威补判。
4. 索引可清空、失效和确定重建；重建来源唯一为指定内存已发布代次。

## 6. 写入与读取

1. 只有领域服务可以提出业务合法写意图；L1 接收已经中性化的身份、类型、关系和版本写项。
2. 调用方不得取得内存仓库可变对象、SQL 表名、列名、主键、事务令牌、锁、候选确认或撤销入口。
3. 读取返回不可变值式快照，并明确当前 / 历史 / 审计 / 恢复候选类别。

### 6.1 同许可多结构读取投影

当一个领域事实必须同时核对根节点、第一跳关系、中间节点全部同类型相关关系及关系目标的当前类型化值时，L1 可以提供一个业务中性的组合读取函数。该函数必须：

1. 只接受版本化强类型值式请求，具名给出必须存在的节点见证、第一跳根节点子集、关系类型、第一跳角色和类型化值目标角色；不接受领域名、仓库对象、内部句柄、许可、回调或谓词。
2. 在一次事务域共享读取许可内重新解析全部请求见证，并完成全部节点、关系和类型化值读取；结果只携带一个非零事实截止代次。禁止连续调用多个独立许可函数后比较代次并拼接为同代次结果。
3. 返回调用方拥有的不可变值式副本：已重新解析的必须节点、第一跳关系、中间节点同类型全部当前相关关系、目标节点全部当前类型化值和可选未满足请求见证；不得返回内部句柄、仓库记录、锁或许可。
4. 只做稳定身份、当前性、端点、版本、关系类型、角色筛选和类型化值记录完整性检查，不解释特征、状态、动态或其它领域语义。领域服务必须在该值式材料上继续裁决角色基数、业务唯一性和值域。
5. 全部必须节点有效但没有匹配第一跳关系时返回成功、同次非零事实截止和空业务组。节点未占用 / 仅历史占用返回未找到；当前主键存在但类型或身份版本不同返回版本漂移；悬空端点、同稳定身份异内容或当前记录矛盾返回内部不一致。
6. 非成功不得返回部分节点、关系或值。只有未找到和版本漂移可以携带同次非零事实截止及稳定排序后的第一个未满足请求见证；入口拒绝、许可拒绝、资源失败和内部不一致的业务载荷必须为空。
7. 输出按稳定身份和版本排序；同一稳定身份重复且内容完全相同只保留一项，内容不同属于内部不一致。容器顺序、内部编号、句柄、SQL行序、名称或时间戳不得参与排序和去重。

## 7. 结构化结果

必须区分成功、精确重复、未找到、已退役、版本漂移、类型 / 格式不支持、同键异义、并发冲突、外部资源失败和内部不一致。除成功或精确重复外不得返回可用身份事实。
