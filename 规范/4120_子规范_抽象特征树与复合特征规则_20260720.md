# 4120 子规范 抽象特征树与复合特征规则

编号：4120
日期：20260908
版本：v0.10
状态：正式子规范

## 1. 定位

本规范定义正式特征类型全集、叶子/复合形态、值域、组成槽位、状态抽象和定义视图。

直接上级规范：1120、1160、2100。

直接依赖规范：4160。

相关边界规范：4110、4130、4140、4180、4181、4182。

## 2. 特征类型全集

每个正式特征类型必须定位到抽象特征定义节点。名称词条、名称关系和硬编码初始化清单只是召回入口或种子，运行期同一性以稳定定义身份和抽象关系为准。

抽象状态是去掉具体宿主、发生时间和来源动态后的特征取值模板，复用同一抽象特征体系；不得另建平行“状态抽象树”。

### 2.1 先天与后天类型

先天类型来自外设提供的特征类型。系统初始化负责建立正式定义并关联已有的规格和规则；外设声明或初始化清单只是输入，进入正式定义后才成为可读类型信息。后天类型来自对先天类型的综合应用，必须能追溯输入类型及生成规则；后续再组合的来源链最终仍可追至先天类型，不以名称相同或代码枚举替代来源。

类型来源分类不改变 1180 的一次观测与二次至 n 次派生边界，不把所有后天类型直接归为某一固定阶次。它也不增加 1130 四逻辑字段；特征信息通过类型关系取得这些解释。

### 2.2 先天类型初始化规格

初始化时，对已纳入系统的空间坐标、轮廓、体素等类型，须在正式类型定义及其规则关联中给出：

- 唯一原始表示、完整允许域、适用的单位 / 缩放；
- 分量、顺序、维度、坐标系等值解释，结构材料还须有格式及解析合同；
- 正式比较方式、左右角色、输出表示、单位及适用范围；
- 第 3.3 节域形成方式、允许误差的实际来源与适用范围。

空间坐标须明确坐标系、轴向、单位和分量顺序；轮廓、体素的具体格式要求按第 3.1 节。比较方式必须与该类型绑定，不能只初始化名称后让调用者自行选算法。参数取自已有正式设备规格、校准结果或批准规则；本文不替它们发明具体数值，也不把缺实现的解析 / 比较函数写成已可用能力。

初始化的类型比较绑定按[4182](4182_子规范_特征类型比较绑定与启用规则.md)逐项核对，算法正文由4180及[4181](4181_子规范_特征比较算法专项合同.md)承接。先天或后天只说明类型来源，不证明其算法已注册；未启用的比较用途不能用名称、值表示或旧代码默认策略补齐。

## 3. 叶子抽象特征

叶子必须冻结唯一允许的原始值表示、明确允许值域，以及适用时的单位、维度、分量角色、顺序、材料策略和解析合同。值域只表达允许集合，不提供“任意值”或无约束值域；调用者不得在同一当前定义下临时选择另一种原始值表示。

原始值表示与特征信息的值承载方式不同：1130 / 4110 新特征信息中的内联 I64 与引用一个 I64 值，实际都采用 I64 表示；不能因允许两种承载就在同一类型下任意换成向量或材料引用表示。多个信息节点可共享同一正式类型，7160 的概念域细分不要求新建类型定义。

I64 值域由点值和区间项组成；区间不是实际特征值。点区间必须同时包含上下界。空值只能由显式空值域表达，不作为默认值域。

VecI64 / VecU64 的一次实际取值必须把完整有序向量保存在一个值事实中，不为分量或可能取值建立节点。逐分量区间只表达轴对齐允许区域，不能表示分量相关性、方向、旋转、拓扑或形状；需要这些约束时必须使用具名、版本化值域结构和比较合同。

VecU64 / 稳定身份组值域按稳定目标集合或可解析抽象目标定义，不按地址大小或地址区间。一个值域中的项必须属于同一原始值类型。

轮廓、图像、点集、点云和其它大型或需要独立引用的材料，必须由不可变材料身份承载完整载荷，值事实只保存稳定引用。对应叶子定义必须冻结材料类型、格式、解析合同、维度 / 拓扑要求、完整性字段和合同版本；摘要、长度、路径、缓存键或区间都不能替代实际材料。

只要求“特征存在”时应建立存在性合同或专用特征，不能伪装成任意值域。

轮廓、3D 坐标、颜色等业务标志由特征类关联的正式特征定义表达，不进入 2100 的值对象字段或值表示枚举。值对象只提供原始表示与完整内容；叶子定义及具名比较合同负责单位、分量角色、坐标系、材料格式、解析和比较。材料格式版本不是特征值版本，材料头部等完整内容不得因职责分层被删去。

### 3.1 完整结构观测与比较结果

二维轮廓与三维体素是可以采用完整不可变材料的具名特征类型，不限于某种相机或设备直接输出。二维轮廓的类型 / 材料合同须明确点序、开放或闭合、多环及内外环关系、拓扑、坐标系、轴向、单位、坐标量化和格式版本；三维体素须明确网格原点、坐标系及轴向、每轴分辨率和尺寸、稠密或稀疏布局、索引次序 / 稀疏键规则、占据载荷及未知与空的区别。不能把三个数自动认作坐标，不能把缺失体素自动当空，不能以包围盒、摘要或字节长度代替完整结构。

材料仍经已有独立不可变材料身份整体承载，不为每个点或体素建立无业务必要的特征节点。具名解析合同必须实际可用才能进入对应结构比较；通用材料创建和读回只能证明载荷、身份及存储完整性，不能证明轮廓或体素解析、提取及比较能力已实现。

值形状不决定特征阶次。原始材料准备、观测表达与比较派生按 1180 分流：一次特征仍允许现有 I64、完整向量和独立结构材料；全部正式二次至 n 次特征的每项值只允许 I64；所有对外业务比较结果属于这一范围。多分量比较结果拆为有共同来源的具名标量特征，不拆散原始向量或源结构；单位、缩放、合法范围和溢出依对应类型与 4180 裁决。

### 3.2 二值轮廓观察材料与域

具名二值轮廓观察使用有格式版本的完整二值图材料：宽、高、坐标系身份、轴向、原点、统一分辨率与行优先的 0 或 1 像素。尺寸与像素数量一致，像素内容不得含其它数值；空前景不具备该合同的边界距离。姿态与方向由原坐标结构保留，不默认旋转、平移归一化或非等比拉伸。该格式属于完整值内容的解释，不增加“二值图”值表示枚举或值对象字段。

边界是前景中至少一个四邻位置为背景或图外的像素中心。轮廓原材料仍是完整结构值，差异算法输出是另一个具名 I64 二次特征，不能以差异值、半径、摘要或材料编码替换原图。轮廓原子域由类型、正式比较规则、完整固定代表及半径定义；其并集是谓词析取，不是把材料编码当整数区间。

校正阈值、区间半径和累计范围属于正式规则或观察记录，不是实例的当前观测值。三维体素及其它结构材料仍遵守第 3.1 节，二值算法不冒充其解析或比较能力。

### 3.3 特征概念的域形成规则绑定

7160 的类型积累与概念形成复用本节规则，准确 F 不再维护域或命中计数。域形成规则与允许误差参数由正式 FT 绑定并可确定性读回，不由普通调用者临时选择算法或随意填写半径，不增加特征值对象或准确特征的顶层字段。

| 输入 | 类型规则必须提供 |
| --- | --- |
| 内联或引用 I64 | 同量纲合法允许误差及从真实代表形成闭区间的规则；明确单位 / 缩放、类型允许集合、上下界及可表示性，不允许绕回、默认截断或无界兜底。 |
| 轮廓等结构值引用 | 完整解析合同、正式比较规则及左右角色、差异输出的单位 / 缩放和允许范围；用完整固定代表与输入比较，不对编码或摘要做区间比较。 |

首次合法输入提供固定代表，参数来源及适用范围必须明确；可以消费另有正式合同的校正结果，但比较成功不证明误差参数成立。缺规则、参数或解析能力时不能形成该概念域，不回退到默认0、默认误差或4180旧校正规则；此缺口不阻止其它条件完整的准确 F 保存和使用。

域含义固定后不随后续输入移动；定义变化按7160形成新域并查重。首次概念定义完整即可建立并使用，取消等待三次命中；已有算法自身的样本条件不变。更深细分必须有明确的新域形成依据，本节不默认逐层缩小误差或提供未定义的递归路由。

## 4. 复合抽象特征

组成子链描述不同输入槽位如何构成复合特征，与7160同类型允许域的概念上下位关系分开。概念细分不产生新的组成角色、AND/OR规则或特征类型，也不在准确F之间建立分裂父子链。

二次关系概念的多维AND定义由7170/7180独立承载；其条件组成引用、概念上下位边和本节普通槽位组成是三种不同关系。不能因组成项同时存在便推定逻辑合取，也不能为承载复合RC伪造一个标量结果类型。

复合特征没有自身原始值域，其直接组成关系只承载具名子特征槽位。每个槽位必须有唯一父内角色、特征定义和顺序/基数合同。

同名重复、数组或集合槽位必须由显式关系类型和基数规则表达，不得用重复普通子节点暗示。

判定规则、来源、统计、任务化、AND/OR、因果路径和结算令牌均不进入组成子链；它们使用定义视图、二次特征、规则、状态或提交记录。

复合匹配按具名槽位逐项、递归完成。候选中的额外观测不属于未声明结构；需要参与匹配时必须先补定义槽位。

上述递归是组成槽位匹配，不是任意后天属性的差异汇总。后天类型必须区分“已有语义的比较合同复用”“先按来源形成新属性再比较”“按槽位逐项比较”三种路径，具体按4182。长宽比相同不要求长和宽分别相同；不得因来源最终可追至先天类型，就默认把来源差异求和或平均当作后天属性差异。比较失败不允许反向改写来源或补造值。

本节只定义抽象特征的组成槽位。实例期把多个已经发布的一次特征事实保存为一个集合版本时，复用“具名角色、稳定顺序、完整成员”的结构原则，但使用 4125 的集合身份、版本和成员关系；不得把实例成员塞入定义组成子链，也不得据此产生类别定义、样本归属或派生值。

## 5. 判断型和二值特征

最小传感或直接值类二值特征可使用二值值域，其生产者及来源按正式关联表达；不要求特征节点先绑定宿主或来源动态才能独立创建。

综合判断不得以孤立 bool 作为特征定义。必须列出输入特征族、输入值域、收束规则、写入方、失败分流、来源证据和验证方式；结论可作为状态、二次特征或治理输出保存。

## 6. 定义视图

围绕根特征的正常状态、阈值、必要条件、缺口映射、任务化和路径聚合规则可以作为定义视图关系存在，但不得膨胀抽象特征本体字段。

初始化入口可以创建默认定义，不能作为权威规则表。需求逻辑组织语义由目标特征定义视图解释，不新增需求字段。

## 7. 来源与验证

值域项本身不携带观察、动态或因果来源；来源由关系、动态、因果样本和归纳记录追溯。

创建入口必须在挂接组成关系前验证父形态、子定义、槽位唯一、基数和无环。叶子定义还必须验证原始值表示唯一、值域与表示相容，以及独立材料适用时的格式和解析合同完整。未完成的叶子值域或复合结构不得进入正式需求、方法、因果和结算链。
