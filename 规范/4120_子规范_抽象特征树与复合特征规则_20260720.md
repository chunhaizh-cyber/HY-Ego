# 4120 子规范 抽象特征树与复合特征规则

编号：4120
日期：20260917
版本：v0.14
状态：正式子规范

## 1. 定位

本规范定义正式特征类型全集、叶子/复合形态、值域、组成槽位、状态抽象和定义视图。

直接上级规范：1120、1160、2100。

直接依赖规范：4160。

相关边界规范：4110、4130、4140、4180、4181、4182。

## 2. 特征类型全集

每个正式特征类型必须定位到抽象特征定义节点。名称词条、名称关系和硬编码初始化清单只是召回入口或种子，运行期同一性以稳定定义身份和抽象关系为准。

抽象状态是去掉具体宿主、发生时间和来源动态后的特征取值模板，复用同一抽象特征体系；不得另建平行“状态抽象树”。

### 2.1 先天与后天类型

先天类型来自外设提供的特征类型。系统初始化负责建立正式定义并关联已有的规格和规则；外设声明或初始化清单只是输入，进入正式定义后才成为可读类型信息。后天类型来自对先天类型的综合应用，必须能追溯输入类型及生成规则；后续再组合的来源链最终仍可追至先天类型，不以名称相同或代码枚举替代来源。

类型来源分类不改变 1180 的一次观测与二次至 n 次派生边界，不把所有后天类型直接归为某一固定阶次。它也不增加 1130 四逻辑字段；特征信息通过类型关系取得这些解释。

### 2.2 先天类型初始化规格

初始化时，对已纳入系统的空间坐标、轮廓、体素等类型，须在正式类型定义及其规则关联中给出：

- 唯一原始表示、完整允许域、适用的单位 / 缩放；
- 分量、顺序、维度、坐标系等值解释，结构材料还须有格式及解析合同；
- 正式比较方式、左右角色、输出表示、单位及适用范围；
- 第 3.3 节域形成方式、允许误差的实际来源与适用范围。

空间坐标须明确坐标系、轴向、单位和分量顺序；轮廓、体素的具体格式要求按第 3.1 节。比较方式必须与该类型绑定，不能只初始化名称后让调用者自行选算法。参数取自已有正式设备规格、校准结果或批准规则；本文不替它们发明具体数值，也不把缺实现的解析 / 比较函数写成已可用能力。

初始化的类型比较绑定按[4182](4182_子规范_特征类型比较绑定与启用规则.md)逐项核对，算法正文由4180及[4181](4181_子规范_特征比较算法专项合同.md)承接。先天或后天只说明类型来源，不证明其算法已注册；未启用的比较用途不能用名称、值表示或旧代码默认策略补齐。

## 3. 叶子抽象特征

叶子必须冻结唯一允许的原始值表示、明确允许值域，以及适用时的单位、维度、分量角色、顺序、材料策略和解析合同。值域只表达允许集合，不提供“任意值”或无约束值域；调用者不得在同一当前定义下临时选择另一种原始值表示。

原始值表示与特征信息的值承载方式不同：1130 / 4110 新特征信息中的内联 I64 与引用一个 I64 值，实际都采用 I64 表示；不能因允许两种承载就在同一类型下任意换成向量或材料引用表示。多个信息节点可共享同一正式类型，7160 的概念域细分不要求新建类型定义。

I64 值域由点值和区间项组成；区间不是实际特征值。点区间必须同时包含上下界。空值只能由显式空值域表达，不作为默认值域。

VecI64 / VecU64 的一次实际取值必须把完整有序向量保存在一个值事实中，不为分量或可能取值建立节点。逐分量区间只表达轴对齐允许区域，不能表示分量相关性、方向、旋转、拓扑或形状；需要这些约束时必须使用具名、版本化值域结构和比较合同。

VecU64原始表示只说明完整有序U64值，不自动推出稳定身份集合含义。只有正式FT已经具名声明分量为稳定目标身份并冻结集合/顺序及解析规则时，该稳定身份组的值域才按正式稳定目标集合或可解析抽象目标定义，不按地址大小或地址区间。普通有序数值U64完整点保持分量顺序和重复，按其FT数值解释及完整点域比较；同一值域中的项必须服从同一FT的原始表示和解释合同。

轮廓、图像、点集、点云和其它大型或需要独立引用的材料，必须由不可变材料身份承载完整载荷，值事实只保存稳定引用。对应叶子定义必须冻结材料类型、格式、解析合同、维度 / 拓扑要求、完整性字段和合同版本；摘要、长度、路径、缓存键或区间都不能替代实际材料。第3.1—3.2节明确的局部二值轮廓、局部二值体素例外地以完整 `U64组` 直接承载；不为此建立材料头、版本字段或独立材料身份。

只要求“特征存在”时应建立存在性合同或专用特征，不能伪装成任意值域。

轮廓、3D 坐标、颜色等业务标志由特征类关联的正式特征定义表达，不进入 2100 的值对象字段或值表示枚举。值对象只提供原始表示与完整内容；叶子定义及具名比较合同负责单位、分量角色、坐标系、材料格式、解析和比较。一般独立材料的格式版本与材料头部仍是其完整内容；第3.1—3.2节的局部二值格格式不保存版本或材料头，且不承载现实坐标。

### 3.1 完整结构观测与比较结果

一般二维轮廓、三维体素可以采用完整不可变材料，不限于某种相机或设备直接输出；其材料合同仍须按第3节明确拓扑、现实坐标、未知状态等适用信息。本节另冻结两种不涉及现实空间的局部二值格格式：它们是稠密 `U64组`，只表达自身格内0或1，不为每个像素或体素建立特征节点，也不保存材料头、版本、现实坐标、现实尺寸或未知状态。具名解析合同必须实际可用才能进入对应结构比较；通用材料创建和读回只能证明载荷、身份及存储完整性，不能证明其它轮廓或体素解析、提取及比较能力已实现。

#### 3.1.1 局部二值体素U64组

局部二值体素值是一个非空 `U64组`，且仅允许下列两种规范化形式。二者的局部网格均为 `N×N×N`；`N` 仅允许 `4×2^k (k≥0)`，不能通过逐层二分抵达 `4×4×4` 的分辨率不进入本格式。逻辑起点位于一个角，仅向局部正X、正Y、正Z编号，不表达现实空间的原点、坐标、轴向或尺寸。

1. **全零描述形式**严格为三项 `[0, 2, N]`：首项 `0` 是全零描述标识，第二项 `2` 是局部二值体素类型编码，第三项为 `N`。它表示最高层、每一压缩层全部未占用，颜色序列为空。解析器不得实际分配或回写展开后的零块，只可按本节确定性得出其逻辑格、层数和每层块数。
2. **普通完整形式**第0项为原始最高层分辨率 `N`，后续依本节保存全部位图、颜色和压缩层。普通完整形式若其最高层及全部压缩层均为零且颜色序列为空，是非规范化全零形式；具名格式生产方必须在提交通用U64保存前改写为全零描述，具名解析器也不得将其报告为成功。通用U64保存服务不识别该格式、不负责改写或拒绝普通U64组。

普通完整形式的最高层对 `0≤x,y,z<N` 的线性编号固定为 `i=((z×N)+y)×N+x`，占用位位于组中第 `1+i/64` 项的第 `i%64` 个低位起算比特。位为0表示该局部格未占用，位为1表示已占用；本格式没有“未知”第三状态。最高层的 `N³/64` 个占用块后，颜色项与全部值为1的 `i` 按升序一一对应；每项低24位依次为 `R`、`G`、`B`，每通道范围0—255，其余40位必须为0，颜色项数量必须等于最高层占用位数。

普通完整形式的颜色尾段之后依次保存分辨率 `N/2、N/4、…、4` 的纯占用压缩层；每层有 `M³/64` 个位图块，且每一位必须严格等于其上一层对应 `2×2×2` 八个子格占用位的 OR。压缩层不保存颜色项。普通完整形式的全部层、层序、位序和颜色尾段共同构成完整值内容；不得只保存最高层、懒算压缩层、按N召回或以摘要替代任一层。全零描述的三个已冻结分量是其完整物理值内容，并无损确定其全部逻辑层；不得把描述误写成未知、空材料、摘要或颜色材料。

值形状不决定特征阶次。原始材料准备、观测表达与比较派生按 1180 分流：一次特征仍允许现有 I64、完整向量和独立结构材料；全部正式二次至 n 次特征的每项值只允许 I64；所有对外业务比较结果属于这一范围。多分量比较结果拆为有共同来源的具名标量特征，不拆散原始向量或源结构；单位、缩放、合法范围和溢出依对应类型与 4180 裁决。

### 3.2 二值轮廓观察材料与域

局部二值轮廓值是一个非空 `U64组`，且仅允许下列两种规范化形式。分辨率仅允许 `N=8×2^k (k≥0)`；不能通过逐层二分抵达 `8×8` 的分辨率不进入本格式。

1. **全零描述形式**严格为三项 `[0, 1, N]`：首项 `0` 是全零描述标识，第二项 `1` 是局部二值轮廓类型编码，第三项为 `N`。它表示最高层与每一压缩层全部为白色/非轮廓；解析器只按本节确定性得出逻辑层，不分配或回写零块。
2. **普通完整形式**首段是原始最高层，最高层有 `N²/64` 个位图块，之后依次保存 `N/2、N/4、…、8` 的纯二值压缩层；每层有 `M²/64` 个块，并逐位等于上一层对应 `2×2` 四个子格占用位的 OR。轮廓没有颜色段。普通完整形式若所有层均为零，是非规范化全零形式；具名格式生产方必须在提交通用U64保存前改写为全零描述，具名解析器不得将其报告为成功。通用U64保存服务不解释、改写或拒绝普通U64组。

逻辑起点位于一个角，仅向局部正X、正Y编号，不表达现实坐标、尺寸或版本。普通完整形式的每一层对其自身分辨率 `M` 均用 `i=y×M+x`、第 `i/64` 项、第 `i%64` 个低位起算比特编号；位为1表示黑色/轮廓占用，位为0表示白色/非轮廓。普通完整形式的所有层块数、层序、位序和全部位共同构成完整值内容，不建立像素节点或像素坐标记录，也不得由最高层省略、重建或替代已保存压缩层。全零描述只表示已知全部为0，不增加未知态。

局部二值轮廓的边界、漂移、距离、归一化、阈值及概念域均不由本格式自动推出；只有对应特征类型另有已启用的比较或域合同，才能使用完整位图形成相应结果。三维体素与其它结构材料也不得借本二值轮廓格式冒充已具备解析或比较能力。

### 3.3 特征概念的域形成规则绑定

7160 的类型积累与概念形成复用本节规则，准确 F 不再维护域或命中计数。域形成规则与允许误差参数由正式 FT 绑定并可确定性读回，不由普通调用者临时选择算法或随意填写半径，不增加特征值对象或准确特征的顶层字段。实例IF/R分组另按4115：I64精确相等；其它枚举类型必须具名提供比较/阈值及可选上位归并规则，概念域算法不得被当作实例R分组算法。

| 输入 | 类型规则必须提供 |
| --- | --- |
| 内联或引用 I64 | 同量纲合法允许误差及从真实代表形成闭区间的规则；明确单位 / 缩放、类型允许集合、上下界及可表示性，不允许绕回、默认截断或无界兜底。 |
| 轮廓等结构值引用或局部二值格U64组 | 完整解析合同、正式比较规则及左右角色、差异输出的单位 / 缩放和允许范围；用完整固定代表与输入比较，不对编码或摘要做区间比较。局部二值格只按本节冻结的长度和位序解析。 |

首次合法输入提供固定代表，参数来源及适用范围必须明确；可以消费另有正式合同的校正结果，但比较成功不证明误差参数成立。缺规则、参数或解析能力时不能形成该概念域，不回退到默认0、默认误差或4180旧校正规则；此缺口不阻止其它条件完整的准确 F 保存和使用。

域含义固定后不随后续输入移动；定义变化按7160形成新域并查重。首次概念定义完整即可建立并使用，取消等待三次命中；已有算法自身的样本条件不变。更深细分必须有明确的新域形成依据，本节不默认逐层缩小误差或提供未定义的递归路由。

## 4. 复合抽象特征

组成子链描述不同输入槽位如何构成复合特征，与7160同类型允许域的概念上下位关系分开。概念细分不产生新的组成角色、AND/OR规则或特征类型，也不在准确F之间建立分裂父子链。

二次关系概念的多维AND定义由7170/7180独立承载；其条件组成引用、概念上下位边和本节普通槽位组成是三种不同关系。不能因组成项同时存在便推定逻辑合取，也不能为承载复合RC伪造一个标量结果类型。

复合特征没有自身原始值域，其直接组成关系只承载具名子特征槽位。每个槽位必须有唯一父内角色、特征定义和顺序/基数合同。

同名重复、数组或集合槽位必须由显式关系类型和基数规则表达，不得用重复普通子节点暗示。

判定规则、来源、统计、任务化、AND/OR、因果路径和结算令牌均不进入组成子链；它们使用定义视图、二次特征、规则、状态或提交记录。

复合匹配按具名槽位逐项、递归完成。候选中的额外观测不属于未声明结构；需要参与匹配时必须先补定义槽位。

上述递归是组成槽位匹配，不是任意后天属性的差异汇总。后天类型必须区分“已有语义的比较合同复用”“先按来源形成新属性再比较”“按槽位逐项比较”三种路径，具体按4182。长宽比相同不要求长和宽分别相同；不得因来源最终可追至先天类型，就默认把来源差异求和或平均当作后天属性差异。比较失败不允许反向改写来源或补造值。

本节只定义抽象特征的组成槽位。实例期把多个已经发布的一次特征事实保存为一个集合版本时，复用“具名角色、稳定顺序、完整成员”的结构原则，但使用 4125 的集合身份、版本和成员关系；不得把实例成员塞入定义组成子链，也不得据此产生类别定义、样本归属或派生值。

## 5. 判断型和二值特征

最小传感或直接值类二值特征可使用二值值域，其生产者及来源按正式关联表达；不要求特征节点先绑定宿主或来源动态才能独立创建。

综合判断不得以孤立 bool 作为特征定义。必须列出输入特征族、输入值域、收束规则、写入方、失败分流、来源证据和验证方式；结论可作为状态、二次特征或治理输出保存。

## 6. 定义视图

围绕根特征的正常状态、阈值、必要条件、缺口映射、任务化和路径聚合规则可以作为定义视图关系存在，但不得膨胀抽象特征本体字段。

初始化入口可以创建默认定义，不能作为权威规则表。需求逻辑组织语义由目标特征定义视图解释，不新增需求字段。

## 7. 来源与验证

值域项本身不携带观察、动态或因果来源；来源由关系、动态、因果样本和归纳记录追溯。

创建入口必须在挂接组成关系前验证父形态、子定义、槽位唯一、基数和无环。叶子定义还必须验证原始值表示唯一、值域与表示相容，以及独立材料适用时的格式和解析合同完整；局部二值格U64组则先精确识别三项全零描述并核验其类型和分辨率，或按普通完整形式验证长度、分辨率、位序、逐层OR和颜色载荷，并拒绝非规范化全零普通形式。未完成的叶子值域或复合结构不得进入正式需求、方法、因果和结算链。

## 8. 结构操作B的完整类型解释

B完整类型规格绑定真实来源、唯一原始表示、分量数、有序分量角色和单位、规范化正比例缩放、完整允许域及具名精确规则。A已有标量类型从原字段逐项读回，保留原身份、来源、单位、缩放和规则，不伪造B分量元数据或重建同名FT。新规格缺真实来源、单位、规则时拒绝，不能由普通装配制造设备事实。

I64使用规范化有限区间并集；I64组、U64组与材料完整点使用非空有限完整点集合。集合外层按完整内容排序去重；每个向量点内严格保序并保留重复，不能将分量集合当作取值集合或笛卡尔域。材料域的代表必须是真实已发布M，完整解析后再比较，不能按材料编码范围表达值域。
