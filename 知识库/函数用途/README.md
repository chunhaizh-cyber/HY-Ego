# 函数用途知识

状态：部分候选，待按现行 `.h/.cpp` 逐项复核

本目录只保存仍可从现行头源代码复核的函数用途候选。凡绑定已退出模块、旧模块行号、已删除施工记录或旧调用图的用途卡，已经退出并不得恢复为当前证据。

使用任一用途卡前必须同时核对：

1. 目标文件在当前 HEAD 中存在；
2. 卡内声明、签名、职责和非成功分支与当前定义一致；
3. 当前工程登记及生产调用点与卡内用途一致；
4. 相关正式规范和当前计划没有改变其合同；
5. 绑定基线早于当前代码时，已经完成差异复核。

未通过上述核对的卡只能用于定位候选，不得证明函数当前存在、可复用、已接线或已经运行验证。后续重建时只从现行 `.h/.cpp`、工程登记、生产调用点和正式合同形成新卡。
