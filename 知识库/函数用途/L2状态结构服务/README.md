## 当前生产边界

- 两文件均登记正式工程。普通应用从同一L1运行包形成状态owner交付，构造并持有唯一`L2状态结构服务`；普通应用与`L2结构聚合服务`只返回同一实例引用。
- `L2动态结构服务`和`L2因果结构服务`实际调用`读取状态身份来源`证明状态端点；`L2概念结构服务`实际调用`读取完整状态`；`L2方法结构服务`实际调用`读取完整目标状态合同`。
- 其它状态新增、组查询、替换、换代、退出以及目标合同写入口在本基线没有模块外生产调用点。专项通过不等于正式业务已经消费。
- 状态服务只保存调用方提交的强类型状态记录和目标状态合同结构，不判断状态真实、目标满足或业务资格，也不从当前特征自动生成状态。

## 正式口径缺口

1. `L2结构公共.数据.h`与状态组三类有界查询已使用`L2结构状态::数量预算不足 = 15`，但4230第2.2节共同状态枚举仍止于`内部不一致 = 14`。调用者应按当前ABI识别该状态，同时保持正式规范同步待治理。
2. 1160第2—4节要求实例状态具有场景归属并在完整读回中验证场景；更具体且更新的4230第4.4节固定`L2状态事实`只含主体、特征实例、精确值、时间值、来源和生命周期，当前DTO与服务也没有场景字段或场景依赖。知识库不能自行判定二者如何收敛，该机器语义保持规范缺口。
