## 当前生产边界

- 两文件均登记正式工程。普通应用使用同一L1运行包分别形成特征定义owner和特征实例owner交付，构造并持有唯一`L2特征结构服务`；普通应用与`L2结构聚合服务`只返回同一实例引用。
- 状态服务实际消费特征实例身份来源、完整实例、完整定义及当前/历史比较注册；概念服务实际读取完整定义、完整实例及当前/历史值；方法服务实际读取完整定义。
- 本基线没有模块外生产调用点消费特征公开写入口、按存在组读取或`比较特征`。这些入口的专项或静态检查不能替代正式BIZ消费。
- 服务只保存调用方提交的强类型定义、实例、值和比较合同结构；不判断定义是否有业务意义、值是否真实、比较是否满足目标，也不从特征自动形成状态。

## 正式口径缺口

1. 4110第2.1节仍描述固定关系22与“实例当前值恰一”，而更具体且更新的4230第4.3节及当前ABI允许特征实例当前值为空并可独立退出。知识按当前4230与代码登记，不自行回写旧规范。
2. 1120/4110/4120要求抽象值域、叶子/复合形态、组合DAG和定义视图；4230及当前服务只冻结统一阶次、直接来源、派生规则、固定属性、实例和值结构，不能据此宣称全部抽象特征语义已经实现。
3. 4140要求枚举实例值具有合法生产者及状态、动态或规则证据；当前特征值写入口只保存调用方提供的来源稳定编码和类型化材料，不在DATA内裁决生产者合法性。
