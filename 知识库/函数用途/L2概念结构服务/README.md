## 当前生产边界

- 三个源码均登记根工程。普通应用从同一`L1事实基座运行包`取得概念owner交付，借入材料与六类世界结构服务，构造唯一`L2概念结构服务`，并由`L2概念结构聚合服务`返回同一实例。
- 已发布的四本体根provider经概念聚合调用三个根入口，但provider和三个初始化数据/实现文件未登记根工程、没有生产import，不能据此宣称阶段18或四根生产初始化已接通。
- 除上述候选provider外，20个公开入口在服务模块外没有正式生产调用点。施工专项通过公开ABI形成的证据不等于合法BIZ消费者已经接线。
- 服务只保存调用方已经裁决的概念强类型结构；不判断抽象、定义、归类、名称或退出在业务上是否正确。

## 机器语义与复用边界

- 存在、特征、动态和因果链恰各一个语言无关本体根；四根永久活跃。场景、词条、解析标签和世界树根不得冒充概念本体根。
- 普通概念具有独立概念身份、不可变签名、定义角色合同、同根至少一个直接上位、来源证据和治理生命周期。定义含义变化建立新概念，不能原地改义。
- 直接上下位只保存同根直接边，允许多父但必须无环且唯一根可达。传递闭包、层级、高度和显示树属于可重建投影。
- 世界事实支持关系方向为“世界事实 -> 概念”，允许多对多和跨根；它只保存调用方裁决的支持关系，不证明归类正确。
- 不可逆退出只允许退役普通概念，必须保护当前支持、反向定义、名称外引用并在同一事务建立必要替代直接边；不得删除来源世界事实或复用旧概念身份。
