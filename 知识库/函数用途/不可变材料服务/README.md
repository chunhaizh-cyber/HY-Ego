## 复用边界

上层只允许调用四个公开数据服务入口，并应经普通应用上下文取得同一实例。`不可变材料内部`、`不可变材料服务::实现`和匿名命名空间函数均不是稳定ABI；不得复制路径校验、摘要发布、请求账或L1写集形成第二材料服务。

材料服务只保存和读回不可变字节事实，不解释文本、签名、规则、语言或概念语义。物理路径不是身份；结果`成功()`只校验返回形状，不能替代公开服务调用和权威读回。
