## 机器语义与复用边界

- 真实自我形成是单例操作：使用固定幂等身份（`真实自我存在固定幂等身份`等5个常量）和固定角色键（`海中鱼巣项目唯一自我角色 = {1}`）。
- 形成结果有16种状态枚举值，覆盖成功、幂等重复、请求无效、各步骤失败、资源失败和许可拒绝。
- `成功()`只在状态为`已形成`或`精确重复`且`已形成自我`有值时返回真。
- 提供者不可复制、不可移动；由普通应用构造并唯一持有。
- `读取已发布自我()`使用`std::mutex`保护，支持并发读取。
