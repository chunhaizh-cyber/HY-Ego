## 当前生产边界

- 两个源码均登记根工程。普通应用新增`取得L2概念名称结构服务()` getter并构造唯一服务实例。
- 服务依赖`L1事实基座服务`、`L2概念结构服务`和`L2语言结构服务`，通过`L2概念名称所有者交付`取得L1写入端口。
- 公开写入/读取入口在模块外没有正式生产调用点；普通应用只完成装配和getter暴露，尚未由启动链或BIZ消费者调用。
- 服务只保存调用方已裁决的概念名称关系（概念-词条-角色-语言-来源），不判断名称在业务上是否正确或完备。

## 机器语义与复用边界

- 概念名称关系是概念身份到词条身份的多对多映射，每条边附带角色（首选名称/别名/简称）、适用语言和来源证据。
- 名称写入具有幂等重放语义：新增前读取当前幂等身份的首次写入结果，若已存在相同内容的记录则返回`精确重复`而非报错。
- 替换和退出同样走幂等重放路径；退出必须保护当前活动名称并验证替代关系。
- 服务不解释名称的文本语义、拼写正确性或业务分类合理性；它只维护结构化的名称关系事实。
- `L2概念名称事实`没有`operator==`（有意省略以避免模块边界问题）；冲突检测使用`名称内容匹配`和`唯一性冲突`等内部helper按字段比较。
