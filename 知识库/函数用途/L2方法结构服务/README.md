## 当前生产边界

- 三个源码均登记根工程。普通应用从同一`L1事实基座运行包`建立方法owner交付，构造唯一`L2方法结构服务`，并经唯一`L2方法结构聚合服务`返回同一实例。
- 已发布的`提供者.方法登记根生产初始化.ixx`会调用三个方法登记根入口，但该源码未登记工程、没有生产import，不能据此宣称阶段19、方法根生产初始化或正式BIZ消费已经接通。
- 五个普通方法公开入口在服务模块外没有正式生产调用点。生产外专项通过合法普通应用聚合调用它们，只证明具名39项矩阵，不是生产接线。
- 候选读取只返回召回起点。任务领域必须按当前方法身份重新读取完整方法事实并自行选择；方法服务不判断方法好坏、不替任务选择、不执行动作。

## 机器语义与复用边界

- 方法是有稳定身份、条件、结果和动作入口的能力契约；函数名、显示文本、候选命中和方法首都不能替代完整规格。
- `L2方法治理虚拟存在身份`只属于方法长期治理结构，不是世界事实存在，不得改用`L2存在身份`、世界状态或共享运行实例承载。
- 方法内容版本、规格版本和生命周期版本由方法owner自己的强类型事实承载；旧关系23或世界状态口径不得作为本服务的替代入口。
- 公开CRUD保存和读回调用方已经裁决的强类型结构；它不创建任务或需求，不冻结任务方法，不运行动作，不结算结果，也不学习或晋级方法。

## 验证边界

- 方法公共身份、方法根服务、方法聚合装配、普通方法身份与规格引用均有双配置构建和静态检查记录。
- 普通方法公开服务生产外专项Debug/Release均`PASS 39/39`，覆盖入口拒绝、端点、CRUD、幂等、候选、预算、版本和引用冲突等具名场景。
- 方法登记根真实首次、精确重复、并发、资源失败、发布未知和阶段19仍为`NOT_RUN`；旧R1独立验收固定在旧候选并失败，不能证明或否定当前新服务。
- 真实任务冻结、候选优劣、动作执行、结果权威比较、学习晋级、恢复、跨进程、正式BIZ消费和当前服务具名集成验收仍为`NOT_RUN`。

## 应用示例

若目标是“按预期结果寻找可能的方法”，可把`按结果规格读取当前方法候选`列为候选复用，但必须同时满足：调用方已有同截止的完整结果规格键、设置非零扫描和候选预算、逐个调用`读取普通方法`回读完整当前事实，并由任务领域完成选择。不得直接复用内部索引扫描函数，也不得把候选列表当作已选择、可执行或已验证的方法。
