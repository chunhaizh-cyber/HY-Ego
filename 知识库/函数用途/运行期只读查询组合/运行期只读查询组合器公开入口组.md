## 用途

公开组合入口的执行顺序为：请求形状校验（失败返回请求拒绝）；经 `取得L2场景结构服务` / `取得L2存在结构服务` 取得同实例服务引用；按场景树、存在单例角色、完整存在、存在当前场景成员引用、场景宿主存在关系、存在当前宿主场景顺序读取，逐个以 `读取头有效` 校验结果头并保留首个失败分类；六份材料齐全后依次执行四个业务互证（现实世界拓扑、自我角色与存在、自我场景成员、内部世界宿主）；全部通过才移动形成 `已形成` 快照，最后再用成功谓词兜底复核。失败分类映射：DATA `许可拒绝` 与入口拒绝、引用冲突、数量预算不足同为 `提供者拒绝`；事实代次漂移为 `当前性漂移`；未找到 / 已退出为 `材料缺失`；`bad_alloc` / `length_error` 为资源失败；未知异常为内部不一致。

## 明确非职责

入口不写 DATA、不等待、不重试、不记录日志、不访问 L1 / SQL / 缓存；不裁决业务合法性，只组合并互证六入口已返回的同截止不可变值；不持有聚合所有权，构造借用的聚合生命周期由调用方保证；当前没有生产消费者，不冒充任务闭环或普通应用能力。

## 合法调用语境与依赖方向

只能通过构造时注入的同一 `const L2结构聚合服务&` 依赖场景 / 存在服务，方向为组合器 -> 聚合取得 -> 六个公开 DATA 读取入口；不得绕过聚合直接持有服务，也不得在入口内接入第二权威来源。当前全仓生产 import 与调用点为零；合法消费者待父级共享截止 provider 或普通应用接线后另行登记。
