## 6. 固定结果与失败收口

| 场景 | 固定结果 |
| --- | --- |
| 输入登记不完整 | 内部不一致；零 L1 调用 |
| 当前代次等于缓存截止 | 一次一致投影；完整验证后已读取 |
| 第一次事实代次漂移并回显当前代次 | 丢弃第一轮，完整重试一次 |
| 第二次仍事实代次漂移 | 世界登记事实代次漂移；空登记 |
| 任一尝试许可拒绝 | 世界登记许可拒绝；零等待零重试 |
| 任一尝试资源失败 | 世界登记资源失败 |
| 入口拒绝、内部不一致、顶层非成功形状矛盾 | 世界登记内部不一致 |
| 成功但合同 / 回显 / 代次 / 长度矛盾 | 世界登记内部不一致 |
| 任一节点或属性值未找到 / 已退出 / 未设置 / 异种 / 缺事实 | 世界登记内部不一致；不得当成登记未加载 |
| 五节点、槽或值业务形状矛盾 | 世界登记内部不一致；无部分登记 |

读回失败不得修改缓存、补写、换编码、调用历史 / 恢复或伪装成功。
