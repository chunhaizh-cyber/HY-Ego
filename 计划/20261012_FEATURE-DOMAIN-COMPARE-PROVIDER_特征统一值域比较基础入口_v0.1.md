## 4. 公开合同

以下声明均在`新_特征类.h`中，置于既有比较结果DTO邻近位置：

```cpp
struct 新特征准确I64比较材料 final {
    std::int64_t 值 = 0;
};
struct 新特征直接I64值域比较材料 final {
    特征概念I64闭区间 值域;
};
struct 新特征概念值域比较材料 final {
    稳定编码 概念节点;
};
struct 新特征值域比较输入 final {
    稳定编码 特征类型概念节点;
    std::optional<稳定编码> 单位;
    std::variant<std::monostate,
        新特征准确I64比较材料,
        新特征直接I64值域比较材料,
        新特征概念值域比较材料> 材料;
};
struct 新特征值域关系比较结果 final {
    新特征比较状态 状态 = 新特征比较状态::入口拒绝;
    std::optional<std::int64_t> 关系编码;
};

// 新_特征类 public；定义紧邻旧比较特征概念值域关系。
新特征值域关系比较结果 比较特征值域(
    const 新特征值域比较输入& 左,
    const 新特征值域比较输入& 右) const noexcept;
```

`monostate`只表示未提供材料，必须拒绝，不能当准确0或全域。三种有效材料互斥。单位空表示无单位，不是继承或通配；来源方明确传入所用单位。类型概念可为根或同树子概念，不要求调用者先找根。

成功时`关系编码`为现有`特征概念值域关系`显式枚举值的int64表示：1相等、2左包含右、3右包含左、4相交、5分离。它是名义关系码，禁止按正负、大小或0～10000解释。所有非成功状态无关系编码；状态沿用`新特征比较状态`，不新增失败码，不把失败换算为不包含或分离。

准确值作为`[值,值]`参与值域关系比较，不是调用有向差值函数。直接区间允许`INT64_MIN`至`INT64_MAX`全部端点；禁止溢出减法。不将方法私有域的有限哨兵限制扩散至基础特征能力，方法创建合同保持原状。

类型概念提供类型根、材料物理类型、单位和比较规则，**不作为准确值或直接区间的准入域**。即使给定区间位于类型概念当前域之外，也按同类型材料正常比较，不扩展或修改概念。

## 5. 读取、校验和算法顺序

1. 左右类型编码无效或任一材料缺失：入口拒绝。概念引用材料的编码无效亦入口拒绝。
2. 使用`读取同类型特征概念()`及已有概念公开读取，获得两侧类型概念完整副本和类型根；缺失按概念不存在、不同根按概念不相容、材料差异按材料类型不相容、单位差异按单位不相容、规则差异按结构不一致。
3. 核验每侧显式单位恰好等于其类型概念单位；空不匹配有单位时为单位不相容。类型根定义与该侧类型概念材料/单位/比较规则需一致；异常按对应不相容或结构不一致返回。
4. 概念引用材料：完整读取指定概念，复用同类型校验确认它与该侧类型概念同根、同材料、单位、规则，取其完整值域副本。缺失不是空域。
5. 准确I64或直接I64区间：类型必须I64标量，否则材料类型不相容；准确值变为单点区间，直接区间变为单项区间集合。下界大于上界为入口拒绝。不加概念域包含门。缺失或非概念身份统一为概念不存在。
6. 将两份解析值域交给`概念_特征类::比较值域()`，不复制其规范化/包含/相交算法。沿用`映射概念规则状态()`；已完成却缺少关系或未知枚举值按结构不一致，无载荷。异常按资源失败，无载荷。
7. 非I64只保留“双概念引用”已有能力，不新增非I64准确值/直接域解释，不把数组或节点编码当I64。结构化维度、角色、单位的比较仍由现有算法处理。

复用helper可保持文件内私有；新的适配辅助也只能在`新_特征类.cpp`匿名命名空间，不能作为全局工具或方法/任务服务。诊断责任全部为向上送出，不添加日志、回调、外设或持久化。

## 6. 并发、生命周期与旧入口委托

新入口只读概念服务公开副本，不访问实例特征字段或可变内部容器，因此不获取`新特征互斥`，不新增跨仓持锁；概念公开入口内部自行保护读回。不得伪称多次公开读取是原子快照，不建立代次或长期缓存，不改变原有概念服务的并发合同。

旧`比较特征概念值域关系(稳定编码,稳定编码)`签名和返回类型不变：先读两侧概念取得单位，将其分别用作类型概念与域概念引用，调用新入口，显式switch把1～5还原已有关系枚举；非成功传递状态并保持无关系。旧函数取消无需的实例互斥持有，不在持锁范围调新入口；不扩大任何写入或生命周期职责。入口无效编码与概念缺失保持原有区分。

新DTO仅调用期值式材料，无独立节点、持久字段、长期存储、概念引用计数或新事务。比较成功/失败均不建立或修改概念，不修补材料、不生成状态/动态或二次特征实例。
