## 1. 用户目标与边界

在 `新_语言类` 中按指定语言的已登记词条，逐 UTF-8 码点从左到右最长匹配，输出有序原文片段与可选词条稳定引用。未知材料原样保留；匹配及本轮自检路径都不登记语言、词条、概念、名称关系或世界节点，不消歧、不召回概念、不建场景。

用户本轮明确指定 `新_语言类.h/.cpp` 承载该只读能力。因此，2200 第7节及现有语言类注释中“语言结构不执行分词”的旧描述，仅在本次无语义解释的已登记词面匹配范围内由本轮裁决替代；词类不分词、规范化仅精确校验、名称及概念解释仍分离。本计划不修改正式规范，也不将此局部授权扩展为通用自然语言理解。

本叶不是本能方法，没有动作登记、任务状态或现实特征改变。临时匹配 DTO 没有独立节点、持久身份或引用计数。

## 4. 冻结公开合同

以下实体只由 `新_语言类.h` 定义；新增 `<cstddef>`、`<vector>`，在同一命名空间只前置声明 `class 新_词类;`，实现文件再包含其正式头。该声明引用同层词结构服务，不是底层反向声明上层业务服务；不增加友元或第二实体定义。

```cpp
struct 新语言词条匹配片段 final {
    std::optional<稳定编码> 词条节点;
    std::size_t 原文字节起点 = 0;
    std::size_t 原文字节长度 = 0;
    std::size_t 原文码点起点 = 0;
    std::size_t 原文码点数量 = 0;
    std::string 原文;
    friend bool operator==(const 新语言词条匹配片段&,
        const 新语言词条匹配片段&) = default;
};
struct 新语言词条匹配结果 final {
    新语言查询状态 状态 = 新语言查询状态::输入不合法;
    std::vector<新语言词条匹配片段> 片段组;
};
// 新_语言类 public，const成员，仅组合正式读取与本次值计算。
新语言词条匹配结果 按已登记词条最长匹配(
    稳定编码 语言节点,
    const std::string& 文本,
    const 新_词类& 词服务) const noexcept;
```

引用有值表示已登记词条，无值表示未登记片段，不另存重复类别字段。区间采用零基起点和长度，对应半开区间；长度均非零，片段覆盖全部输入且无重叠无遗漏。码点偏移不是字节偏移，也不是字形簇编号；组合字符不合并。

沿用 `新语言查询状态`：`已找到`表示语言合法且本次匹配完整完成，允许空片段组或全部未知；`未找到`仅表示语言不存在，不表示文本含未知词。其余为输入不合法、结构不一致、资源失败。所有非成功结果片段组必须为空。

输入语言由调用者显式传入，不默认 zh-CN，不自动初始化或登记语言。服务引用只在调用期间借用，不存储到结果或语言对象。

## 5. 校验、词库和算法

1. 先校验语言编码有效及非空文本的 UTF-8；合法空文本单独处理，不改变既有校验器“空字符串无效”的语义。
2. 调用 `获取语言`，非已找到按原状态返回；已找到缺 DTO/编码不等则结构不一致。
3. 合法空文本返回已找到与空片段组，不要求词库初始化，不调用词查询。
4. 非空文本调用 `词服务.查询语言词条`。未找到且 ID 组为空表示合法空词库，全文为一个未知片段。输入不合法/结构不一致/资源失败分别映射同名语言状态；不把服务错误当空词库。已找到但 ID 组为空、未找到但组非空、重复 ID 等异常按结构不一致。
5. 逐 ID 调用 `获取词条`。资源失败映射资源失败；列表中的 ID 回读为其它非成功、无 DTO、节点不等、语言不等、词面空或严格 UTF-8 不合法，一律结构不一致。同词面出现不同身份也按结构不一致。读取只接纳词服务按当前严格规范化合同正式返回的 DTO，不直接读底层节点、关系、字段或词索引。
6. 本次按读回词面的 Unicode 码点构造局部 trie；终端存词条 ID。它仅为本次临时加速结构，不写任何服务缓存或登记索引，调用结束即销毁。
7. 输入只在合法码点边界推进。在当前位置沿 trie 尽量向后，保存最后命中的终端，以最长码点数的终端作为词条片段；相同字节词面唯一，不需要任意平分或消歧。未命中时推进一个完整码点，连续未命中部分合并为一个未知片段。
8. 原文由输入的精确字节区间复制，已登记词和未知片段均保留原始字节。重复词条出现保留多次及位置，不按 ID 去重。拼接所有片段原文必须与输入逐字节一致。

规范化严格沿用现行 `严格UTF8字节精确` 存储口径：不做 NFC/NFKC，不折叠大小写、全半角、空白、标点，不裁剪、不修复编码。拒绝孤立续字节、过长编码、截断、代理码点、超过 U+10FFFF、U+FEFF 与 U+FFFD；ASCII NUL 按现有校验器是合法码点，处理时使用字符串长度，不使用 C 字符串截止。空文本是本入口的合法空材料，不产生空词条。

## 6. 锁、错误与零写

语言获取与词查询均使用已有公开入口锁。新成员本身不得持 `新语言互斥` 调词服务，以免词读回再取语言锁形成反向锁；每次公开读取返回后已有锁已释放，再执行下一调用。局部 trie、UTF-8 解码和片段输出不持数据锁，不返回内部引用。

只允许修改本次局部值容器，不调用初始化、建立或取得、修复索引、字段 CRUD、名称 CRUD 或世界树写入口；不得从语言文件中直接消费其既有底层私有 helper 来取得词材料。

资源分配或容器异常由本入口捕获并返回资源失败及空组，不传播异常、不返回部分片段。先在局部构造完整结果再交付；没有机器事实写集，故无提交、回滚或恢复行为。无预算裁剪、无猜测词条、无读失败降级未知。

## 7. 自检合同

自检只有只读公开入口，接受外部已经准备好的语言/词服务及语言 ID，不自行初始化、建词或创建基础节点：

```cpp
int 运行语言词条匹配自检(
    const 新_语言类& 语言服务,
    const 新_词类& 词服务,
    稳定编码 语言节点,
    const std::string& 短词面,
    const std::string& 长词面,
    const std::string& 未登记文本) noexcept;
```

定义与测试辅助位于 `自检.语言词条匹配.cpp`，声明位于同名 `.h` 并包含语言和词正式头。返回 0 表示本组全部要求具备材料且通过，1 表示实际断言或工程读取失败，3 表示只读前置材料不足导致 NOT_RUN。逐项明确 PASS/FAIL/NOT_RUN，缺材料不能算通过。

先经完整词条 DTO 副本核对短词面和长词面已登记、短词面是长词面的严格完整码点前缀，长词面含多字节 UTF-8；未登记文本非空、严格合法、含多字节且按已登记词面只读核对完全未命中。缺失或不满足样本条件直接输出具名 NOT_RUN、退出3，不把错误样本当算法失败。样本满足后，最长匹配结果不符合预期才是 FAIL、退出1。混合用例只选择未登记文本中不会启动任何登记词面的完整码点作为分隔，还须从完整词库核对该混合文本的已知词起点不存在跨入后续分隔码点的更长登记匹配；否则更换本地样本或报告 NOT_RUN，不临场登记分隔词。

覆盖矩阵：

| 项 | 只读测试材料与断言 |
| --- | --- |
| 长词优先短前缀 | 用已核对的短词面和长词面，以长词文本调用，断言单个长词命中 |
| 未登记保留 | 使用调用者传入的未登记文本，断言一个未知片段及精确字节；不得自动登记 |
| 空文本 | 合法语言+空字符串，已找到、零片段 |
| 混合材料 | 未登记码点+长词面+未登记码点，断言顺序、词条身份和未知片段；样本不足则 NOT_RUN |
| 多字节 UTF-8 | 覆盖多字节未知文本及多字节长词；检查字节区间与码点区间分别正确 |
| 严格规则 | 非法/截断编码、BOM、替换符被拒绝且结果空；NUL按合法码点处理；大小写/空白未自动折叠 |
| 前后只读 | 所有调用前后分别通过获取语言、查询语言词条及逐项获取词条读取完整公开 DTO，逐字段相等；新增调用图静态核对无写入口 |

未知码点查找是对 DTO 的本地计算，不调用建词服务。自检需独占测试读取材料，若外部并发合法写入导致前后不同，应报告材料漂移/无法证明，不归罪或掩盖为匹配成功。

当前没有公开全集写入历史或完整权威快照接口；不得为本自检新增核心计数或监控 ABI。前后 DTO 相等只证明受观察材料未变化，静态零写调用图补充本入口无写路径；不能宣称监控了整个系统的所有瞬时写入。概念、名称和世界树不在匹配调用图，禁止为了观测它们而加入不必要的生产依赖。

本轮用户允许自检 NOT_RUN；未获隔离准备写入裁决前，不增加写夹具，不在主程序启动时自动运行本自检。自检函数及工程编译登记是本叶交付，不强造运行数据或启动入口。后续实际运行需由现有实际工程具名入口提供服务；新增该接线另取得共享入口所有权。
