## 1. 目标与完成条件

在特征定义领域新建唯一无对象状态的 `海中鱼巣.领域.服务.L1特征定义集合读取` 只读投影模块，实现纯函数 `从快照读取实例槽引用I64特征定义详情集合`。函数用 P22 登记副本在调用方传入的 P17 快照内互证登记四节点，并对 P24 槽结构引用的精确去重定义集合形成定义节点、三属性槽及标记 / 下界 / 上界类型化值详情。新模块用于打破“实例特征已依赖特征定义”造成的反向模块环，不是第二写入服务或第二定义权威。

完成必须同时满足：

- 输出定义集合精确等于 P24 引用集合，无扫描、无夹带、无遗漏；
- 合法零槽成功空定义组；共享定义稳定去重；
- 每定义三属性槽唯一完整，三值类型、来源、材料和生命周期闭合；
- P22 登记验证代次不冒充 P17 当前截止；
- 任一损坏零部分事实并形成稳定诊断；
- 纯函数 provider、对象状态、锁、缓存、SQL、重取快照调用均为0，模块依赖环为0；
- 不读取槽当前值或执行值域判断。

- 版本错误或 P24 非完整：入口拒绝；
- 合法零槽：已读取完整空定义组；
- 非空引用但 P22 登记缺失：登记未加载；
- 登记四节点全部确定未命中：未找到；
- P24/P17 截止不同：事实代次漂移；
