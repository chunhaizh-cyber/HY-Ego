## 1. 目标和完成条件

原位扩展唯一世界登记服务，形成版本化纯值 `尝试读取当前登记`：一次 try-lock，许可竞争立即拒绝，完整登记才返回副本。该登记只给后继场景结构服务定位世界根及三类结构身份，不提供当前事实截止。

完成必须满足：

- 请求冻结合同/规则版本；成功返回现有完整 `世界结构登记`；
- 入口拒绝、登记未加载、许可拒绝、资源失败和内部不一致分账真实可测；
- 新旧读取复用唯一私有已持锁复制/完整性判断，不建立第二缓存；
- 新服务实例不扫描 L1、SQL、索引或材料补造登记；
- `已验证事实代次` 不被当作当前 G0/G1；
- 不实现指定根场景结构或任何完整世界快照行为。

唯一实现依据为同名 v0.1 详细设计和函数流程图，以及 4015、4200 §3、§5—§6。

1. 在 `世界登记.数据.h` 新增 `世界登记读取请求` 和合同/规则版本完整性谓词；复用既有状态、登记和结果 DTO。
2. 在服务中抽取唯一私有 `复制已持锁当前登记`，把既有阻塞读取的未加载/完整性判断移入该函数且保持外部语义。
3. 新增 `尝试读取当前登记`：锁外校验版本，一次 `std::try_to_lock`；竞争立即许可拒绝，取得后调用唯一私有复制函数。
4. 捕获复制分配失败为资源失败，其它异常为内部不一致；不返回部分登记。
5. 在现有世界登记自检追加请求错误、未加载、成功逐字段相等、重复确定、锁竞争、坏登记和新服务实例专项。
6. Debug 锁竞争/坏登记辅助只用于专项，不导出生产锁、许可或可写缓存。
7. 形成本计划专属施工/验证记录，不覆盖其它记录。

## 5. 状态和停工条件

固定分支：

- 合同/规则错：`入口拒绝`；
- 锁竞争：`许可拒绝`，零等待、零重试；
- 未加载：`登记未加载`；
- 坏登记：`内部不一致`；
- 完整登记：`已读取`和完整副本；
- 分配失败：`资源失败`；其它异常：`内部不一致`。

出现任一项立即具名退回：

- P15 v0.2 实际世界登记接口与冻结合同漂移；
- 必须扫描 L1、SQL、索引、日志或材料恢复登记；
- 必须传递锁、许可、引用、仓库或事务给调用方；
- 需要等待、sleep、内部重试、第二缓存或第二登记解释逻辑；
- 必须把 `已验证事实代次` 解释为当前事实截止；
- 必须触碰白名单外文件或活动 WIP。

普通 C++ 拼写、try-lock、异常捕获和 Debug 夹具错误若不改变合同，由执行侧在白名单内修复。
