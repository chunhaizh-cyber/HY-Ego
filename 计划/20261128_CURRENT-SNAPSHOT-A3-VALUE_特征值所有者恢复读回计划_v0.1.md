# CURRENT-SNAPSHOT-A3-VALUE 特征值所有者恢复读回 v0.1

起点 a483dbe7f。依 2100 §2.3、§6、4015 §14–15、4070 §5 和普通新库上游。领域文件独占 persist_core_design；启动层、工程登记及发布本窗口。

特征值 owner 的六个已有结构节点依初始化顺序命名为 `HY-Ego/2100/value-node-type-field/v1`、`HY-Ego/2100/value-node-type/v1`、`HY-Ego/2100/compression-layer-type/v1`、`HY-Ego/2100/material-physical-type-field/v1`、`HY-Ego/2100/original-material-field/v1`、`HY-Ego/2100/compressed-material-field/v1`，宿主和字段键同为被标识节点。六个键现有建点阶段之后，独立只读联合核验并在一组既有原子追加发表标记；未全部成功不宣告 owner 已初始化，按既有失败清理，不能让失败材料变普通首份持久见证。

`领域/新_特征值.恢复.h` 暴露只读 `新特征值恢复结构读回`（`状态` 为新特征值保护读取状态，`键` 为六元数组，`解码结构()` 顺序取 0/1/3/4），以及 `读取恢复特征值结构(const 基础持久视图&) noexcept`。精确材料查询 `读取恢复特征值材料(const 基础持久视图&,const 新特征值恢复结构读回&,材料物理类型,const 新特征值材料&) noexcept` 返回现有新特征值保护读取结果。复用不可变自键索引、owner 类型反向读取和现存正式快照解码，禁止裸码、同名、重建所有者或写回。在同一候选中核对标记唯一、各自字段吻合、键互异、正式材料身份唯一及完整。错误与资源状态分别返回。

普通完成全局根复核后，首份提交前以及已有活动库重启，都要求用实际 owner 补核六键和普通装配已有的空 U64 集合材料（并非服务权限数值）。空 U64 是本工厂装配的真实前置，精确材料查询本身不固定测试值。缺结构/值保留独立的失败阶段，普通写门和上层 owner 保持关闭。复用主线日志的正式返回投影（仅阶段、结构码和材料码）。

只改 `领域/新_特征值类.cpp`、新恢复头文件、正式工程与 .filters、`启动.应用程序.cpp`、`程序运行结果.数据.h` 和专项验证记录。实际 Release x64，普通受控冷建后独立重启复核同一值、六键和原全局根，序号/活动槽不变；对上游已成立但无新结构的旧受控快照据正式路径拒绝，不改原材料、不给旧快照补标记。未验证上层所有者和服务登记真实权限。
