## 1. 目标、范围与完成条件

为 L2 六类纯结构的退出引用保护补齐唯一较低层提供者：L1 在 `提交中性写集` 内、在形成第一份可变候选之前，以当前已发布事实和请求显式退出集判定节点引用闭包。任一当前关系或值仍引用目标节点且自身未在同一退出集中闭合时，返回具名中性 `引用冲突`，整笔零变化。

本叶不向 L2 暴露全部引用、仓库、索引或反向消费者；不让 L2 扫描六类结构服务；不自动向退出集补造关系或值编码。原定 L2 场景 S3 仍是后继消费叶，本计划不实现场景固定属性换代、场景退出、完整场景读取或 L2 结果映射。

完成条件固定为：

1. `L1中性写入状态` 保留全部现有数值，新增唯一 `引用冲突 = 10`；
2. L1 仓库在权威当前节点、关系和值之外，只增加一个可重建、不取得事实权的当前节点反向引用索引；
3. 索引完整覆盖当前关系的源节点、目标节点、关系类型节点，以及当前值的所属节点、属性类型节点、来源节点和可选独立材料引用节点；
4. 关系 / 值创建、显式退出和属性换代导致的旧值退出都在同一候选状态中同步更新反向索引；
5. `状态完整` 双向互证索引与权威当前事实，任一缺失、多余、错类型或失序均为 `内部不一致`，不降级为引用冲突；
6. 退出目标存在性、请求内新建引用与退出目标自相矛盾、以及权威当前引用闭包检查全部位于 `状态 候选 = 状态_` 之前；
7. 未闭合当前引用返回当前事实代次、`false` 发布、空新编码映射和 `修正请求后可重试`，当前节点 / 关系 / 值 / 属性槽和幂等账全部不变；
8. 生产外公开服务验证逐角色覆盖关系三引用、值四引用、完整闭包、部分闭包、无引用节点和属性换代旧值索引移除；
9. 主工程 Debug / Release x64 保持完整编译链接，既有中性 CRUD 状态、读取、历史关系组和历史属性值组行为不因本叶改变。

### 2.2 复用 / 扩展裁决

不推荐以现有源 / 目标关系组公开读取拼闭包：调用方必须预先知道全部关系类型，且仍缺少关系类型角色和值四角色的反向引用。也不能在 L2 扫描六类服务，这会形成反向依赖，并且漏掉未来其它合法消费者。

该提供者不新建公开函数、DTO 或组合读取。它只是 `提交中性写集` 内部的当前结构前置，正常消费者只看到现有写入结果中的新具名状态。

## 5. 私有当前节点引用索引

`L1事实基座仓库::状态` 增加：

```cpp
std::unordered_map<std::uint64_t, std::vector<std::uint64_t>>
    当前节点引用索引;
```

键是被引用的当前节点稳定编码，值是仍当前的关系或值稳定编码，按稳定编码严格升序且无重复。全局稳定编码在节点 / 关系 / 值之间不复用，因此候选编码不需要附加类型标签；命中后仍必须在 `当前关系` 与 `当前值` 之间恰一回读并核对角色。

同一事实以多个角色引用同一节点时，对该节点只登记一次事实编码。例如自环关系的源 / 目标相同，或值的所属 / 来源相同，都不得产生重复候选。

新增的最小私有能力固定为：

```text
当前节点引用闭包检查结果 = { 已闭合, 引用冲突, 内部不一致 }
插入当前节点引用索引(状态&, const 关系事实&)
删除当前节点引用索引(状态&, const 关系事实&)
插入当前节点引用索引(状态&, const 值事实&)
删除当前节点引用索引(状态&, const 值事实&)
检查当前节点引用闭包(const 状态&, 稳定编码,
    const std::unordered_set<std::uint64_t>&)
```

闭包检查必须使用上述三值私有结果：索引命中无权威当前事实、同时命中关系和值、或权威事实未真实引用目标节点时返回 `内部不一致`；事实真实引用目标但其编码不在退出集时返回 `引用冲突`；其余才返回 `已闭合`。不得用裸 `bool` 把索引矛盾与真实引用冲突压成同一分支。

关系登记去重后的 `{ 源节点, 目标节点, 关系类型节点 }`；值登记去重后的 `{ 所属节点, 属性类型节点, 来源节点, 可选独立材料引用编码 }`。插入以 `lower_bound` 保持严格升序；删除必须恰一命中并在组空时移除节点键。插入分配异常由公开提交边界映射为资源失败；重复、缺项或角色不完整使候选失败为内部不一致。

候选状态内的唯一更新点固定为：

1. 新建关系成功写入 `当前关系` 及现有源 / 目标 / 历史候选索引后，插入一次当前节点引用索引；
2. 新建值完成类型与材料校验并成功写入 `当前值` 后，插入一次当前节点引用索引；
3. 显式退出关系时，在它从 `当前关系` 删除前，与现有源 / 目标索引同步删除反向引用索引；
4. 显式退出值时，在它从 `当前值` 删除前删除反向引用索引，属性槽仍按现行行为同步移除；
5. 属性槽换代将旧当前值转入历史时，在删除旧 `当前值` 前同步删除旧值的反向引用索引；
6. 节点退出不删除别的当前事实的索引项；它只有在闭包已证明所有引用事实都位于同一退出集时才可继续，后续退出关系 / 值会清空对应索引。

` 状态完整` 对索引做双向互证：

- 每个索引节点键必须是权威当前节点，编码组非空、严格升序且无重复；
- 每个候选编码必须在 `当前关系` 或 `当前值` 恰一命中，权威事实必须真实以索引键担任至少一个已登记角色；
- 每条权威当前关系必须在其三个去重引用节点键下恰一出现，每个权威当前值必须在其三个或四个去重引用节点键下恰一出现；
- 历史关系 / 值不得出现在当前节点引用索引；索引不保存事实副本，不从历史候选索引反推当前引用；
- 任一矛盾使 `状态完整` 失败并返回内部不一致；不在热路径扫描修复、不择优重建、不删除证据。

## 6. 候选前退出闭包裁决

`L1事实基座仓库::提交中性写集` 的独占锁内顺序固定为：

```text
请求规范化与结构校验
-> 取得独占锁
-> 现行状态隔离 / 完整性检查
-> 既有幂等键的精确重复 / 幂等冲突裁决
-> 期望事实代次裁决
-> 退出编码必须均为当前节点 / 关系 / 值，否则未找到 / 已退出
-> 请求内新建关系、新建值或属性槽变更不得引用同请求将退出的既有节点
-> 对每个将退出的当前节点，按当前节点引用索引定位全部候选
-> 每个候选回读权威当前关系 / 值并核对真实角色
-> 候选事实编码必须均位于同一退出集
-> 全部闭合后才执行 `状态 候选 = 状态_`
```

结果优先级与现行语义保持一致：

1. 当前状态已隔离或完整性矛盾，返回 `内部不一致`；
2. 已有幂等键仍先于代次、退出目标和当前闭包裁决；
3. 新幂等键且期望代次不符时返回 `事实代次漂移`，不被引用冲突覆盖；
4. 代次符合后，退出编码未找到 / 已退出优先于引用闭包裁决；
5. 请求内新建事实或槽变更指向同请求将退出的现有节点，是自相矛盾的写集形状，按 4015 / 4050 返回 `入口拒绝`，不冒充“已发布的当前引用未闭合”；
6. 只有权威当前关系 / 值的真实引用仍未被退出集闭合时返回 `引用冲突`；
7. 索引命中与权威事实不一致时返回 `内部不一致`，不降级为引用冲突；
8. 全部闭合后进入现行编码分配、新事实形成、退出、属性槽更新、候选读回、幂等记录和原子交换路径。

退出集可使用请求结构校验已经证明唯一的编码组建立私有 `unordered_set`。关闭包查询只按“将退出节点数 + 其候选引用数”执行，不扫描全部当前关系或当前值。临时集合分配失败由现行公开边界返回资源失败，候选尚未形成，不产生任何事实变化。

## 7. 退出、属性槽与原子边界

当前事实引用边界固定为：

- 只有节点会被关系或值的中性公开引用指向；关系和值共用全局稳定编码，但它们当前不能作为关系端点、关系类型、值所属 / 类型 / 来源或独立材料节点；
- 退出当前关系只移除其当前可见性和当前索引，不退出端点；退出当前值会按现行合同移除指向该值的当前属性槽，不退出所属 / 类型 / 来源 / 材料节点；
- 退出当前节点不自动退出任何关系或值，只有它们的编码已显式出现在同一退出集时才允许节点退出；
- 属性槽换代的新值发布、旧值退出和槽切换仍位于一个 L1 事实代次；旧值的反向引用索引在候选内移除，新值在创建时加入；
- 历史关系 / 值和历史候选索引继续保留完整生命周期；当前节点引用索引不保留历史引用，不影响历史读取。

完整闭包的实例是：若节点 `N` 同时被关系 `R1/R2` 和值 `V1/V2` 以任意登记角色引用，则合法退出集至少包含 `[N, R1, R2, V1, V2]`。若 `V1` 还位于当前属性槽，退出 `V1` 会在同一写集语义中移除该槽；不要求退出所属节点或增加一个不存在的“属性槽退出编码”。

### 8.2 必过矩阵

在一个新 L1 服务实例中，以公开方法建立互不复用的受控节点和引用事实，覆盖：

1. 对每一种角色分别构造唯一目标节点：关系源、关系目标、关系类型、值所属、值属性类型、值来源、值独立材料引用；各目标单独退出都返回 `引用冲突`；
2. 上述七类冲突每次都回显原幂等键和当前代次，零发布、空新编码映射、当前目标及引用事实仍可读，历史不增项；
3. 一个目标同时被多条关系和多个值以重复 / 不同角色引用；退出集缺任意一个引用事实均引用冲突且零变化，包含目标及全部引用关系 / 值时恰一成功推进一个代次；
4. 完整闭包成功后，目标节点和所有关系 / 值当前读取均已退出，历史读取的退出代次全部相同；未被退出的其它端点仍当前可读；
5. 退出一个无任何当前引用的节点直接成功；单独退出当前关系或值仍按现行合同成功，不要求退出它们的节点端点 / 所属 / 类型 / 来源；
6. 当前属性值显式退出后当前槽消失，对原所属 / 类型 / 来源 / 独立材料节点的后续退出不再被该历史值阻断；
7. 属性换代后旧值进入历史、新值为唯一当前槽；旧值不再阻断其引用节点退出，新值仍阻断，仅将新值与目标一起退出才可闭合；
8. 新建关系的源 / 目标 / 类型中任一现有节点同时出现在退出集，分别返回入口拒绝；新建值的所属 / 类型 / 来源 / 独立材料节点或属性槽变更的所属 / 类型同时退出时也入口拒绝，全部零变化；
9. 一个新幂等键同时具有旧期望代次和未闭合引用时先返回事实代次漂移；以不存在 / 已退出编码作为退出目标时分别未找到 / 已退出，不被引用冲突覆盖；
10. 一个已成功的完整退出原请求以相同幂等键和完整形状在后继代次重复，返回首次结果的相同退出代次和 `精确重复`；同键改变退出集返回幂等冲突；
11. 自环关系或同一值多角色引用同一节点时，索引不重复候选；请求退出目标和该唯一引用事实即可成功，不出现伪引用冲突或内部不一致；
12. 非退出的节点 / 关系 / 值新建、属性换代、精确重复、同键异义、非法合同和资源 / 内部非注入路径保持现行结构化语义；验证工具不用日志或输出文本代替断言。

专项入口不注入私有索引损坏、分配失败、锁公平性、崩溃、恢复或跨进程场景；这些未覆盖边界必须在验证记录和完成声明中保留。
