# R125-S09-DIRECTION-TYPE 温度比较方向类型实施计划 v0.2

起点 `daf93afea3e80c55001a330fb68c55403afd8e3a`。主工作区 main，原指挥窗口独占。依赖 [1180 §2、§4、§7](../规范/1180_根规范_二次特征.md)、[4150](../规范/4150_子规范_二次特征边界与承载规则.md) 及 S08 正式三边保存。准入采用周春海明确的存在类型＋基础 FT、有序角色、独立语言方向，无准确值。创建侧证据是 S08 后同构建普通网页 M32352，场景 32765、解释 33778 确证同源三成员三边；温度正式 FT1404 与完整域 C1413 读回；PID 5476 正常退出 0。代码证实已有数值二次派生无合法语言方向输入；不能借换方向或差值定义。

## 范围与合同

允许生产文件仅 `海中鱼巣/领域/概念_二次特征类.h/.cpp` 和 `海中鱼巣/装配.普通应用.cpp`；计划、4150 对齐修订与专属验证记录. 同 owner 类型定义、挂接与正式读回同片。场景写入、当前 F 与历史采用另由场景/特征 owner 消费已交付类型，不能在此片借概念 owner 写实例。

复用同一个概念树、派生定义及两条有序输入项。新增具名派生规则「语言温度比较方向」和输入来源「语言比较端点」。两个输入均引用同一正式温度完整域 C，左为参照 B，右为主体 A；派生结构另以强引用各恰一固定正式温度 FT 和适用存在根；仅这类派生可持有两附加字段。普通启动在温度强类型和存在语义根均已建立后核对 FT→完整域 C 和存在根，再通过既有特征值 owner 取得 2100 三枚完整材料符号 `>0`、`<0`、`=0`。正式类型明确为无量纲、完整材料精确、非聚合的有限 UTF8 材料身份域；这些符号只作分类材料，不是开放文本、准确温差或数值代码。现有数值定义、概念、算法和数据不迁不改。

既有建立/复用入口按材料完整定义、规则、两角色、适用根和 FT 查重。类型发布前确认全部结构，现有派生结构沿原辅助节点建立与类型挂接模式，失败沿已有清理和非成功返回。正式强引用保护包含两个身份、定义和成员值仍可读；普通运行启动只在完成正常正式读回后交付。数值默认生成和按准确 I64 查找保持排除此规则，不生成方向子概念。统一读口按原概念身份独立返回同一根、规则、FT、适用范围、两端角色、有限域并核符号实料；资源不足、类型缺失、错域或重复时无成功回执。日志沿现有普通应用正式温度读回边界，记录实际独立回执，无测试装配。

## 核验

实际工程一次 Release x64 编译，保存构建输入和证据。普通入口隔离运行，通过既有初始化依赖顺序取得正式 FT/C 与存在根，分别由概念所有者读取派生定义和三个符号材料，核一个稳定类型、两端 FT 和角色、适用根及三成员；正常关闭同 PID 0。条件可用则同库重开复核同一稳定类型。方向实例及同项更新/旧采用由紧邻消费片验收，不将类型回执当实例。七组仍 0/7。新实际故障先按 AGENTS §7.1 回报。

## 4. v0.2 首次普通启动故障处置

PID 37784 在方向定义查重时命中旧入口“未完成查询不能折成无匹配”，未监听，错误对话框关闭后退出 574。只读定位到异型需求定义先核验有限域分支，且普通装配在方向类型前尚未装配需求成员读口，源码推得此时有非空有限组会回“读取接口未装配”；原日志未携带此状态。正式输入仍保留三枚 UTF8 V。

追加唯一允许文件 `海中鱼巣/领域/概念_特征类.cpp`。共用定义相等函数先排除异型，随后同型身份、内容及所有者核验原样运行。新方向分支使用特征概念所有者的强类型查重和强类型建立，只有完成才消费候选或交付类型；工程错误保留原强类型状态与阶段，不把未完成解释为零候选。保留其他派生入口及同型需求保护。验收增加普通需求/任务已装配且原 owner 正式控制面可读，类型和 2100 材料单次独立回执、三边回归及同 PID 自然退出 0。
