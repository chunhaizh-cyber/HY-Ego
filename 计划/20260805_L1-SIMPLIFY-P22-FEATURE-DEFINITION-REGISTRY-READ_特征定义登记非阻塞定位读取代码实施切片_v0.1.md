原位扩展 P2 已实现的唯一 `L1特征定义服务`，形成版本化纯值 `尝试读取当前登记`：一次 try-lock，服务锁竞争立即拒绝，完整登记才返回副本。该登记只给后继实例特征集合读取定位定义服务身份、定义标记属性类型和 I64 上下界属性类型，不提供当前事实截止。

完成必须满足：

- 请求冻结 P2 合同/规则版本；成功返回现有完整 `特征定义登记`；
- 在既有状态末尾追加 `许可拒绝=11`，既有 1—10 不重编号；
- 入口拒绝、登记未加载、许可拒绝、资源失败和内部不一致真实分账；
- 新旧登记读取复用唯一私有已持锁复制/完整性判断，不建立第二缓存；
- 新服务实例不扫描 L1、SQL、索引或材料补造登记；
- 登记验证代次不被当作当前 P17 截止、G0/G1 或实例特征结果截止；
- 不读取定义节点、实例槽、当前值、材料、来源或任何完整世界快照材料。

唯一实现依据为同名 v0.1 详细设计和函数流程图，以及 1120、1130、4110、4015、4030、4200 §5—§6 与 P2 v0.1 正式结果。

## 5. 状态和停工条件

固定分支：

- 合同/规则错：`入口拒绝`；
- 锁竞争：`许可拒绝`，零等待、零重试；
- 登记未加载：`登记未加载`；
- 坏登记或重复编码：`内部不一致`；
- 完整登记：`已读取` 和完整副本；
- 分配失败：`资源失败`；其它异常：`内部不一致`。

出现任一项立即具名退回：

- P2 实际登记接口、状态或锁语义与冻结合同漂移；
- 必须扫描 L1、SQL、索引、日志或材料恢复登记；
- 必须传递锁、许可、引用、仓库或事务给调用方；
- 需要等待、sleep、内部重试、第二缓存或第二登记解释逻辑；
- 必须把登记验证代次解释为当前事实截止；
- 必须把实例特征结构登记、定义集合或实例特征集合并入本叶；
- 必须触碰白名单外文件或活动 WIP。

普通 C++ 拼写、try-lock、异常捕获和 Debug 夹具错误若不改变合同，由执行侧在白名单内修复。
