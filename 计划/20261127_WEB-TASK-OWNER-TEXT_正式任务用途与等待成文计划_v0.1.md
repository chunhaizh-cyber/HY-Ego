# WEB-TASK-OWNER-TEXT 正式任务用途与等待成文

版本 v0.1，基线 05c0cc6af7f6267cd15f213b2a04eb8dff8998fd。用户要求实际第 7 组，优先完成任务所有者已具备的成文路径。Windows main 由交互窗口独占本片。许可装配.普通应用.cpp、宿主.网页对话.cpp 的控制页字段描述、专属验证和计划索引。

## 合同

依 7240 §3.3 正式对象表达与 5260 状态合同，从任务所有者当前调度批中取得同一 T、其直接 D 和实际状态，不扫真实世界、不从语言推定已发生事实。当前仅在 T 数据、调度定位与完整自我执行需求身份一致，自我为需求主体，正式状态确是「等待条件」，且目标特征有可读正式名称时成文。文字表达该任务满足自我对应的特征需求，并陈述正式等待状态。需保留稳定 D 及其完整结构化目标供独立核对，语言文本没有内部编号。名称缺失不猜，不把「待检查条件」「待执行」「执行中」当作等待。现有内部管理控制快照任务项增加可空 taskDescription 字段，复用同一批 D/目标投影，不新增路由、窗口授权、可读任务集合或写入。任何其它输入都不触发任务创建、状态写入或外部发话。

这个最小片独立于水温正式前态。旧 S15 已有合法的 D→T 与两次网页来源的历史证据；当前正式语言状态图未有同窗采用的可重用 T 引用。仅凭这次渲染文字或内部启动任务不可把新话语绑定全球 T，不能重开旧域或将内部任务发给任意窗口。正常普通网页核对实际自我 D→T 的对照成文、确定等待状态及目标结构，后用网页新 M 提交第 7 组原文作为来源未齐的负例，从现有按 M 入口读解释并核无任务创建操作。通过仍只验所有者投影，不计原组；原水温 D、T、同窗来源齐备才做独立正回读。

## 验证

实际 Release x64 及普通网页隔离运行。已发布的启动治理需求和任务提供最小现行 D/T，无控制台注入。任务和需求 owner 的编号互证；状态文本按状态读回，不读取线程运行标志代替。控制快照恢复与正常退出。验证材料归入具名验收记录。
