## 4. 机械施工

1. 在 `L1事实基座.数据.h` 按详细设计 §3 逐字建立 `稳定编码`、本地键、幂等键、两种节点种类、四种值表示、三类事实、属性槽、写集、结果和完整性谓词。原始值材料只允许 `I64 / VecI64 / VecU64 / 独立材料引用`。不 include 旧句柄或节点直接合同头。
2. 在 `仓库.L1事实基座.ixx` 建立唯一 `L1事实基座仓库`。当前状态必须同时包含编码占用、三类事实、当前属性槽、幂等结果和可重建关系辅助索引；候选以隔离副本形成，所有校验通过后一次替换，失败销毁候选。不得对已发布记录原地改写，不得在持锁时调用领域、日志、SQL、材料或回调。
3. 只接受详细设计 §3.3 的 `事实引用`：新节点 / 值可被同写集本地键引用，关系只能引用节点；每个新值恰被一个槽变更引用；属性类型节点的材料表示与值分支必须匹配；退出节点必须没有存留当前关系或值。所有本地键、编码、槽和端点异常均在发布前拒绝。
4. 在 `服务.L1事实基座.ixx` 建立唯一 `L1事实基座服务` 和详细设计 §4 的七个公开成员。读取只返回值式副本；当前、历史、审计和恢复候选不混用；非成功不返回部分业务事实。`提交写集` 的同键同内容返回原结果、同键异内容冲突、期望事实代次不等返回漂移。
5. 在 `自检.L1事实基座.ixx` 建立 `运行L1事实基座自检()`。按详细设计 §6 覆盖多值多关系、同写集交叉引用、属性 / 关系替换、所有拒绝、幂等、代次漂移、候选资源失败、当前 / 历史 / 审计分离、索引重建和完整 / 损坏恢复。自检只能使用生产服务公开入口；不得注入生产破坏入口。
6. 将四个新文件登记到工程和 filters；在 `启动.应用程序.ixx` import 专项自检，并仅新增顺序270的 `L1-SIMPLIFY-P0-S01` 适配。登记、执行和摘要数量均由 S0 的 `N` 精确变为 `N+1`。
7. 写入专属施工和验证记录，记录实际基线、允许文件、矩阵结果、构建结果和本计划不接线 / 不迁移 / 不删除边界。
