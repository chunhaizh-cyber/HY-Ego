## 5. 连续实施顺序

### 5.1 叶1：任务初始化与 ARCH-L2 首态

1. 在八文件 WIP 上保留合法 T→D/T→E、R1、P1/A1候选和六阶段显式幂等材料；删除旧融合桥和历史占位。
2. 建立`任务阶段结构消费端口`纯抽象四入口及冻结 DTO；不实现 stub、模拟成功或第二存储。
3. 重写初次筹办 provider，按 E、T/R1、TASKSTAG定义、E阶段实例、无动态首态、P1/A1、第一迁移逐段原键收敛。
4. 每段只在正式独立读回后越段；提交后读回失败保留见证，以原键重放。
5. 普通应用只保存目标端口依赖位置；真实提供者未接入时不声明可运行。

叶末只运行第 7 节机械检查。

### 5.2 叶2：筹办治理与 Stage C 退役

1. 扩展治理函数 v2、执行轮次和冻结合同；冻结只保存条件、输入、参数、限制、验证归因和有序动作范围。
2. 删除`L2任务授权安全复判材料`、授权安全来源、`授权安全等待`及普通应用 Stage C 装配。
3. 任务管理每次经阶段端口独立读取当前阶段后调用唯一筹办 provider；线程槽不保存阶段副本。
4. 同一未收束 Rn 内等待解除/冻结失效只建立新 Pn；执行开始或正式结果形成后禁止该分支。

叶末只做机械检查。

### 5.3 叶3：授权、硬否决、真实执行和结果

1. 新建`L2自我治理结构服务`并登记 0x0304；结构服务机械保存授权、优先级和后继事实，不作业务裁决。
2. 扩展方法动作入口为强类型有序作用范围；普通应用登记唯一稳定动作键端口。
3. 实现实例方法技术许可和真实执行入口；任务工作线程成为唯一真实执行调用方。
4. 实现唯一自我现实执行授权 provider及写/读/收口矩阵。
5. 实现同一只读现实执行硬否决 provider，支持预检和最终复核；请求绑定阶段、完整动作范围、现实影响分类、截止和规则版本，结果分开作用范围证据、安全读回见证与命中证据；不适用只允许零现实改变。
6. 按详细设计 v0.2 第 5 节和流程图 H1V/H3V 固定矩阵实现派发门控。控制、资格、许可或预检不通过时不请求授权；`不适用+含现实改变`、`未命中+零现实改变`和证据形状错配按内部不一致阻断；现实改变取得授权后仍须最终硬否决。
7. 更新强类型执行请求、工作结果、回执和上行桥；动作返回只作待验证材料，实际世界回读与归因后才发布正式结果。
8. 实际结果形成后迁移到执行结果待结算，再进入任务轮次结算中。

叶末只做机械检查。

### 5.4 叶4：自我争用优先级、完整分配、逐需求核算和收束

1. 实现`自我结果争用成员优先级` provider。请求显式携带全成员优先级/同级序号和理由证据；provider只验证并发布，不从禁止字段推导。
2. 自我 owner一次发布一个优先级批次和全成员事实，独立读回后才允许争用分配。
3. 新建`L2任务结果消费结构服务` 0x0305；唯一写入口一次发布完整消费分配记录。v0.1 逐成员公开发布目标退出。
4. 可共用记录按成员身份规范化，处理顺序只表示稳定输出，成员状态全为共同引用且优先级/最低/期望/分配前/实际/分配后全空或零；可分割只允许单扣减维度，按正式全序固定处理耗尽、低于最低单位后继续和正常`min(期望,剩余)`三分支；不可分割只允许首个合法成员获配1，其余结果耗尽。四种成员状态、每步剩余、总量守恒和最终剩余在 result owner 一个事务内提交，多维容量交换前零写拒绝。
5. 新建`L2需求结算结构服务` 0x0306；共同引用和已分配进入各自目标核算，未获分配/结果耗尽只发布具名成员核算；每次只核算一个当前 T→D，分别发布满足/未满足/未获分配/材料不足/不可比较。
6. 所有合格成员恰有一个核算结果、运行停止、冻结和授权收口、适用价值/学习引用均正式读回后，分别发布任务轮次结算和 ARCH-L2 收束迁移。
7. 目标未达成只进入轮次结论，不产生重筹办意图或工作包。

叶末只做机械检查。

### 5.5 叶5：自我后继与新任务轮次

1. 自我线程在新治理批次独立读取轮次结算、需求当前状态、自我整体事实、优先级、安全和服务事实，调用唯一自我后继 provider。
2. 协议只携带决议身份、T/R和版本；任务管理独立读回正式决议。
3. 等待零 task 写；结束和取消各自正式收口；三者不建立新轮次。
4. 只有继续由 task owner建立 R(n+1)、新 P、治理动作和决议引用，再发布到筹办中的阶段迁移。
5. 新轮次不复制旧路径、实例、冻结、结果或授权。

叶末只做机械检查。

### 5.6 叶6：旧权威物理退役

1. 删除 task 数据/服务中的私有治理阶段、目标未达成待重筹办、后继准备和旧读回。
2. 物理整删`任务重筹办.数据.h`、`服务.任务目标未达成重筹办触发.ixx`、`协议.任务重筹办意图.ixx`。
3. 同时删除工程登记、端口、邮箱、处理槽、运行包 provider、重试槽和自动执行队列路由。
4. 所有旧消费者迁为同一未收束 Rn 新 Pn、正式阶段端口或自我后继决议；保留只用于新任务 R1 的初次筹办工作包。
5. 更新最终端到端测试源码，但叶末仍不运行测试。
