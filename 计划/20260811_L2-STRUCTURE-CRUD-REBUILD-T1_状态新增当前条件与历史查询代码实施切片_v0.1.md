## 1. 目标、范围与完成条件

在 4230 v0.3、G2 以及正式 E-ID / F-ID provider ABI 之上，新建唯一 `L2状态结构服务`，完成状态 owner 与身份来源初始化、状态结构类型稳定登记、状态原子新增、状态身份来源及单项当前 / 历史完整读取，以及按主体存在和按特征实例枚举全部当前状态；同时把状态 owner / 服务作为现有普通应用 provider 的下一个唯一前缀装配，不建立世界树聚合或其它服务。

本叶严格对应总体详细设计 T1。T2 才拥有状态主体 / 特征引用替换、精确值 / 时间值换代、状态退出和引用保护；本叶不得提前形成这些写集、DTO、函数或验证。后继顺序仍为 `T1 -> T2 -> DYN1 -> DYN2 -> C1 -> C2 -> A1`。

历史状态 / 动态登记代码只作已删除反例和命名冲突证据，禁止复用、复制、适配、搬移或改名沿用其业务语义、DTO、函数体、关系角色、准入、自动整理、比较、动态生成、因果判断或验证剧本。

完成条件固定为：

1. 以 G2 冻结的 `状态所有者建立身份` 建立独占状态 owner，经 `尝试形成L2状态所有者交付` 形成不可复制、可移动且只供状态服务消费的交付；状态服务私有持有其 move-only `L1所有者范围写端口`；
2. 在状态 owner 内先以独立幂等身份同写状态族锚点和状态族归属关系类型，再建立状态主体 / 特征实例两种关系类型，以及精确值角色和时间值角色各四种材料表示的八种属性类型；来源初始化和内部类型登记使用不同本地键、不同幂等身份，顺序固定且都早于首个状态节点；
3. `新增状态` 以一份 owner-scoped L1 中性写集原子建立一个普通状态节点、状态族归属关系、状态到主体 / 特征实例的两条关系、精确值 / 时间值两个不可变值事实及两个当前属性槽；
4. 写前必须分别调用正式 `读取存在身份来源(当前)` 和 `读取特征实例身份来源(当前)`；两者均须为 `已读取`、载荷完整、载荷节点编码等于请求身份且事实截止等于请求期望代次。同时必须调用 `读取完整特征实例(当前)` 核对实例宿主等于请求主体；完整实例字段不能替代身份来源证明，身份来源也不能替代完整实例宿主字段；不要求实例已有当前值；
5. 精确值和时间值均由调用方显式提交 `L2原始值材料`，分别按材料表示映射到自己的登记类型；二者可以使用相同或不同表示，不能从表示种类猜测结构角色；
6. 两个值事实都使用请求的唯一来源稳定编码，完整读回时两个值来源必须相等并等于 `L2状态事实::来源稳定编码`；
7. 单项当前读取在同一期望事实代次返回状态节点、三关系、两属性、端点和生命周期的完整投影；单项历史读取从具名历史截止重建，不以当前关系、当前属性或当前端点补历史；
8. 单项写入 / 读取结果公开状态族归属、主体、特征实例三条自有关系稳定编码，供 T2 后继显式闭包，不把关系编码塞入 4230 已冻结的 `L2状态事实`；
9. `读取状态身份来源` 支持正式当前 / 历史读取；当前完整状态与条件查询复用同一状态来源判定，历史完整状态以同一历史截止闭合状态来源，不允许不同代次串接；
10. 按主体查询先读存在身份来源，按特征实例查询先读特征实例身份来源；合法端点没有状态时才返回 `已读取` 和空组。每个候选状态再经完整状态读取闭合状态来源，组按状态身份稳定编码严格升序、无重复并共享同一事实截止；wrong-family、裸 L1 普通节点和内部元数据节点不得误报合法空组；
11. 4230 未冻结“同一主体 + 特征实例只能有一个当前状态”，T1 允许多个独立状态节点同时当前，不增加最新状态、时间最大、唯一采样点或自动替换规则；
12. 同一幂等身份同完整请求返回首次完整结果且零推进；同键异主体、实例、材料、时间、来源或期望代次返回幂等冲突；
13. 入口、登记、许可、未找到、已退出、漂移、幂等、引用、资源和内部错误精确分账；全部非成功为空载荷、零普通事实变化；
14. 生产代码零验证专用实体、接口、友元、状态出口、计数器、注入、调度让行或测试分支；临时验证三文件在结果和记录发布、计划退出后由独立清理提交删除；
15. `海中鱼巣/装配.普通应用.ixx` 在既有存在、特征前缀后建立状态 owner、形成状态交付、构造并唯一持有状态服务；装配枚举在现有 `0—10` 后精确追加 `状态所有者范围建立失败 = 11`、`状态所有者交付形成失败 = 12`、`状态服务构造失败 = 13`，getter 只返回同一实例；
16. 两个未跟踪状态草稿只是执行侧暂停现场，未编译、未验证且不构成能力。执行侧从新 HEAD 重新 S0 后按本版逐字段机械复核、修订或替换；不得以保留草稿为理由偏离最终合同。

```text
  幂等冲突=8，资源失败=9，内部不一致=10

L2状态结构类型登记：合同版本、规则版本、首次幂等身份、首次期望事实代次、
  建立事实代次、事实截止代次、十个类型身份
```

```text
0x0204'0301U -> 属性类型 / 时间值 / I64

0x0204'0304U -> 属性类型 / 时间值 / 独立材料引用
```

`建立状态结构类型登记` 使用状态 owner-scoped 写端口和独立类型登记幂等域，以一份独立的 `L1所有者范围写集请求` 建立十个类型节点，关系 / 值 / 槽 / 退出为空。该内部登记写集与 `新增状态` 的普通状态写集不是同一事务；这里的“一份”只禁止拆分十类型登记，不改变第 7 节“每次新增状态恰一份写集”的原子边界。成功 / 精确重复必须取得十个不同非零稳定编码映射并按首次代次 owner-aware 历史读回节点种类、表示和精确状态 owner；服务私有保存只读值式定位。禁止调用旧通用 `L1事实基座服务::提交中性写集`。

`读取当前状态结构类型登记` 只按私有定位用一致当前投影读取十节点，允许一次完整漂移重读；未加载返回登记未加载，不扫描全仓、不猜测稳定编码。登记建立必须在状态 CRUD 并发使用前单线程完成；T1 不允许登记写与 CRUD 并发，也不为此新增服务锁。普通操作遇到登记未加载映射为 L2 `入口拒绝`，登记许可 / 漂移 / 资源 / 内部失败映射同名共同状态。

十个节点只标识状态内部结构角色和材料表示，不解释状态真伪、值域或时间单位。

`状态身份来源登记幂等身份 = 0x4C32'4944'5352'4304ULL`，与状态结构类型登记幂等域及所有普通 CRUD 幂等身份分离。私有 `初始化状态身份来源` 使用状态端口以一份独立 owner-scoped 写集同写锚点和归属关系类型两个普通节点，owner、定位、创建代次和精确重复收敛规则与正式 E-ID/F-ID 同构；该来源初始化写集不属于任何状态节点新增，状态族归属关系本地键只出现在普通状态创建写集。锚点和类型不能作为状态公开身份，不能由普通调用方读取定位或退出。

流程固定为：

```text
纯值校验
-> 读取当前状态结构类型登记
-> 按两份材料选择精确值角色 / 时间值角色的登记类型
-> 构造不可变 L1 写集
-> 探测当前事实代次
-> 实际代次 != 请求期望：恰一次直提原写集，由 L1 裁决重复 / 冲突 / 漂移
-> 同期望：调用读取存在身份来源(当前)与读取特征实例身份来源(当前)
-> 两来源均已读取、有载荷、节点编码精确相等、截止等于请求期望且当前生命周期未退出
-> 调用读取完整特征实例(当前)，要求已读取、有载荷、截止相等、身份相等且宿主等于请求主体
-> 经状态 owner-scoped 写端口恰一次提交
-> 从首次代次 owner-aware 历史节点、三关系、两属性值和端点来源重建首次结果
```

唯一写集为：

```text
节点 = [{状态节点本地键, 普通, 无属性类型表示}]
关系 = [
  {状态族归属关系本地键, 源=状态节点本地键, 目标=私有状态族锚点,
   类型=私有状态族归属关系类型, 角色=1},

   类型=登记特征实例关系类型, 角色=1}
]
值 = [
  {状态精确值本地键, 所属=状态节点本地键,
   类型=按精确值材料选择的登记类型, 材料=请求精确值材料, 来源=请求来源},
  {状态时间值本地键, 所属=状态节点本地键,
   类型=按时间值材料选择的登记类型, 材料=请求时间值材料, 来源=请求来源}
]

  {状态节点本地键, 精确值登记类型, 状态精确值本地键},

```

T1 不要求特征实例 `当前值` 存在，也不比较精确值材料与实例当前值；调用方可以提交与当前特征值不同的状态记录，数据层只保存结构。主体与实例宿主不等返回 `引用冲突`，零提交。未找到 / 已退出 / 许可 / 漂移 / 资源按端点公开读取精确映射；端点载荷、截止或宿主矛盾为内部不一致。

成功 / 精确重复必须取得六个本地键到六个不同非零编码的一一映射，首次事实代次和发布 / 重试边界正确。首次历史读回必须证明普通状态节点、族归属 + 主体 + 实例三条同 owner 同代次关系、两个同 owner 同代次值、两个属性槽角色、共同来源以及两个端点来源在首次截止有效；不得用调用时当前端点或属性替代首次结果。任一缺项、多项、错 owner、错锚点、错类型、错端点、错角色、错来源、混代或材料表示不符返回内部不一致，不二次提交。所有状态类型登记、状态节点、关系和值写入都必须使用状态 owner-scoped 端口；旧通用 `提交中性写集` 调用数为零。

## 8. 单项当前与历史完整读取

### 8.1 当前读取

先读取当前状态结构类型登记。用状态 owner-aware 一致当前投影一次请求精确状态 owner、状态节点、状态族锚点、状态族归属关系类型、族归属 / 主体 / 特征实例三个具名源关系组，以及该状态节点对精确 / 时间全部八个登记类型的属性值选择，使 `读取状态身份来源(当前)` 的来源判定与完整状态字段位于同一投影、同一截止。L1 owner-aware 一致投影可同时返回跨 owner 关系对端事实，但请求中的 owner 选择固定只含状态 owner；主体 / 实例在该投影只作关系对端结构材料，强类型身份仍由随后正式 L2 来源入口证明。状态来源须为已读取；节点必须是当前普通节点，三个关系组各恰一项、源为状态、类型和角色匹配，族归属目标为私有锚点，另外两目标分别形成主体 / 实例身份。八个属性值选择必须恰有一个精确类型和一个时间类型为 `成功` 且携带投影，其余六项为 `属性未设置` 且无投影；节点当前属性槽必须与这两项一一对应，不得先分散读取槽再临场选择第二投影。

随后以同一期望代次调用 `读取存在身份来源(当前)`、`读取特征实例身份来源(当前)` 和 `读取完整特征实例(当前)`；三者均须已读取、有完整载荷、截止相等、编码相等，完整实例宿主等于主体。身份来源不能替代完整实例字段，完整实例也不能替代两端来源证明。必要的第二轮 owner-aware 投影只能用于前后复核，必须逐字段等于第一轮；两值所属状态、类型角色、材料表示、来源和生命周期同截止，形成完整状态和三关系编码。

目标状态当前已退出优先返回 `已退出`；wrong-family、裸 L1、内部锚点 / 类型返回 `入口拒绝`；malformed 状态来源、登记、端点或投影返回 `内部不一致`。许可、漂移、资源精确收口；多槽、少槽、错类型、错关系、端点复义、来源不一或任一部分载荷均内部不一致。全部失败清空状态和自有关系。

### 8.2 历史读取

历史读取固定为：

```text
读取当前事实代次并等于请求期望
-> 以读取状态身份来源(历史, 历史截止)闭合状态 owner、节点、锚点、类型和族归属
-> 按状态 owner-aware 历史入口读取状态节点
-> 按状态为源读取主体 / 特征实例两种历史关系组(历史截止)
-> 读取状态历史属性值组(历史截止)
-> 以同一历史截止调用存在 / 特征实例身份来源历史读取
-> 以同一历史截止调用完整特征实例历史读取并核对宿主
-> 再次读取当前事实代次并等于请求期望
-> 重建截止投影
```

截止有效族归属、主体、实例关系必须分别恰一项，截止有效属性必须恰为一个精确角色和一个时间角色；节点当前槽不得补历史。关系、属性或端点晚于历史截止的未来退出代次在返回投影中清空。状态在截止前未创建返回未找到；历史截止达到状态退出仍按 G2 来源合同返回 `已读取` 和完整退出生命周期，不把历史事实降级为当前 `已退出`；只有当前入口读取已退出状态才返回 `已退出`、空载荷。

两次当前代次任一变化返回事实代次漂移；历史组入口 / 许可 / 资源失败精确映射；关系、属性、端点、宿主、来源或生命周期矛盾返回内部不一致。历史读取不扫描其它状态、不选择最新时间、不自动形成动态。

## 9. 按主体与按特征实例的当前条件查询

按主体流程固定为：

1. 调用 `读取存在身份来源(当前)`，确认请求主体在期望代次属于存在族且当前；
2. 读取当前状态结构类型登记；
3. 状态 owner-aware 一致当前投影的 `.所有者` 请求项固定为状态 owner，`.节点` 请求项固定为空，目标关系组固定为 `{请求主体编码, 状态主体关系类型}`；投影返回的关系和对端源节点必须逐项证明属于状态 owner，主体本身的存在 owner 身份只由第 1 步来源读取证明；
4. 每条关系必须目标为请求主体、角色 1、类型匹配、源为当前普通状态节点；
5. 对每个唯一源状态调用 `读取完整状态(当前)`，由单项读取闭合状态身份来源，要求同一期望代次且主体逐字段相等；
6. 按状态身份编码严格升序返回，重复源、关系与单项读回不一致或混代均内部不一致。

按特征实例流程同构：先调用 `读取特征实例身份来源(当前)`，再以 `.所有者={状态 owner}`、空 `.节点` 和 `{请求特征实例编码, 状态特征实例关系类型}` 目标关系组读取候选；投影关系和对端源节点逐项证明属于状态 owner，再由单项读取闭合状态来源并返回相同特征实例。两个查询都只对已证明合法端点允许空组，不筛选时间、不比较精确值、不返回“最新”状态。wrong-family、裸 L1 普通节点、族锚点、关系类型节点和旧未标记节点透传 `入口拒绝`；malformed 来源透传 `内部不一致`，均不得返回空组成功。

如果任一逐项读取返回许可拒绝、漂移、未找到、已退出、资源或内部不一致，整个组返回对应非成功和空载荷；不得返回部分状态组。所有成功项目的事实截止必须精确等于请求期望代次。

## 10. 状态、幂等、异常和非目标收口

非成功优先级固定为：纯值非法 -> 入口拒绝；来源 / 类型登记未加载 -> 入口拒绝；登记其它失败 -> 对应共同状态；既有幂等 -> 精确重复 / 幂等冲突；新键旧期望 -> 事实代次漂移；主体 / 实例 wrong-family、legacy、裸 L1 或内部元数据 -> 入口拒绝；主体 / 实例未找到或已退出 -> 同名；主体与实例宿主不符 -> 引用冲突；许可 / 资源 -> 同名；malformed 来源、截止或载荷矛盾 -> 内部不一致。所有非成功零状态写入、空状态 / 来源 / 自有关系 / 组载荷。

同一幂等身份只绑定完整请求。精确重复返回首次状态、两值、三关系和首次代次，零推进；同键异字段冲突。发布未知只能以原幂等身份和原请求重提；不得换键或重构材料。

T1 不引入新锁、仓库、缓存、索引、序列化、恢复、SQL、材料读取器或第二幂等账；服务不持 L1 / 存在 / 特征内部锁。来源只作为不透明稳定编码由 L1 值事实引用保护，不解释来源类别。

本叶不实现状态引用替换、值换代、状态退出、场景归属、最新状态、状态真实性、采样时间单位、状态自动形成、特征比较、动态生成、因果判断或世界树聚合。普通应用的状态 provider 前缀是本叶必要装配范围，但不证明生产消费者、生产运行或集成验收。

## 11. 临时生产外验证矩阵

临时验证 cpp 只 import L1 公开服务、正式存在服务、正式特征服务、普通应用和 T1 状态服务。存在、定义、实例、特征值、状态登记和来源夹具全部经正式公开入口建立；不得 import 仓库、访问私有定位 / 锁 / 索引 / 幂等账、解析日志或复用历史状态 / 动态实现。

入口参数固定为：

```text
--幂等基值 <uint64，默认51000>
--精确I64 <int64，默认11>
--时间I64 <int64，默认101>
--时间U64一 <uint64，默认202>
--时间U64二 <uint64，默认303>
```

必过矩阵：

1. 普通应用在现有存在 / 特征前缀后建立状态 owner、形成 move-only 状态交付、构造唯一状态服务；状态装配状态 11—13 精确，重复 getter 返回同一实例，普通调用者不能取得 owner / raw 端口；
2. 初始化状态来源锚点 / 类型，再建立状态十类型登记；十二个内部节点编码唯一非零、同一状态 owner，来源登记与类型登记本地键及幂等域互不重用；原请求重复、同键异规则冲突、未加载、错合同 / 规则 / 身份分账；
3. 经正式 E-ID / F-ID 入口建立两个主体、特征定义、一个空值实例和一个有当前值实例；T1 不直造端点；
4. 对空值实例新增状态成功，证明 T1 不要求实例当前值；状态节点、族归属、主体 / 实例两关系、精确值 I64、时间值 I64 与两槽同 owner 同代次，来源和主体 / 宿主一致；
5. 对有当前值实例提交不同于当前特征值的精确材料仍按结构成功，证明不自动复制 / 比较 / 判断状态真实；
6. 原新增请求精确重复返回首次完整载荷且零推进；同幂等身份改主体、实例、精确材料、时间材料或来源均幂等冲突；
7. 主体与实例宿主不符返回引用冲突；不存在 / 已退出主体或实例、零身份 / 来源、空数组、零独立材料、错合同和旧期望新键均精确非成功且零变化；
8. `读取状态身份来源` 当前 / 历史返回完整状态 owner、节点、锚点、类型和族归属生命周期；当前 / 历史完整状态分别在同一当前投影 / 历史截止闭合状态来源，不串接混代；
9. 单项当前读取返回节点、三关系、两值、来源和端点同截止；单项历史在创建截止返回相同创建投影，后继退出事实晚于历史截止时被夹取；
10. 再建立状态，分别覆盖精确 / 时间的 I64组、U64组和独立材料引用，使八个角色表示登记全部被真实写入 / 读回；
11. 同一主体与特征实例建立两个不同当前状态合法，按主体与按实例查询均返回稳定升序完整组，不选择时间较大项；
12. 合法无状态主体 / 实例查询返回已读取空组；不存在端点不得误报空成功；
13. 人为经 L1 公开入口推进后，以旧期望执行当前、历史和两条件查询，全部返回漂移和空载荷；
14. `std::barrier` 同起步、固定最大轮数、无 sleep 的状态新增写者与两条件读者并发，只接受完整同截止已读取、许可拒绝或漂移，不接受部分组、混代、重复状态或内部不一致；实际窗口命中如实记录；
15. wrong-family 主体 / 实例、原始 L1 普通节点、状态族锚点 / 类型作为状态身份全部 `入口拒绝`；缺失归属、重复归属、错 owner、错锚点、错类型、错角色或生命周期不闭合固定 `内部不一致`；全部空载荷零变化，条件查询不得误报合法空组；
16. 直接核对一次状态写入只有一份 owner-scoped 写集，节点 + 族归属 + 两业务关系 + 两值 + 两槽全成或全不成；状态生产代码旧通用 `提交中性写集` 零调用；
17. 主工程 Debug / Release x64、双配置临时项目、strict、UTF-8、工程隔离和临时生命周期检查通过；结果与记录发布、计划退出后独立清理三份临时验证文件，正式代码零验证专用实体。

未覆盖 T2 替换 / 退出、动态、因果、世界树聚合、生产消费者、业务状态真实性、时间排序、长期公平、真实分配失败、故障注入、恢复、跨进程或独立集成验收。
