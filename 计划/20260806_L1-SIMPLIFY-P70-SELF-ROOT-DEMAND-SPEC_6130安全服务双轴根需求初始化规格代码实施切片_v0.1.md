## 4. 目标接口与实现合同

在共享头冻结详细设计第4节全部版本、状态和规格 DTO。服务模块新增：

```cpp
自我双轴根需求初始化规格结果 形成自我双轴根需求初始化规格(
    const 自我双轴根需求初始化规格请求& 请求,
    const 完整自我结构事实& 当前自我,
    const 自我双轴根当前值事实& 当前根值) noexcept;
```

实现必须：

1. 在解释输入前校验六个请求版本；
2. 逐字段校准 P56/P69 世界根、自我和相同非零截止；
3. 只从 P56 取得自我所在场景，只从 P69 取得双轴定义/槽/值见证；
4. 只接受 `A=1,V=0` 和休眠控制态的首次出生边界；
5. 形成安全 `(大于,1)` 与服务 `(等于,I64_MAX)` 两个规格；
6. 两规格主体和宿主均为自我，场景相同，来源为冷启动双轴根，无父根路径为真；
7. 按安全、服务固定顺序返回；任一非成功返回空规格；
8. 保持无对象状态、固定两个成员、`noexcept`、零动态分配和确定性。

生产函数对所有 provider、P15、P17—P40、P53—P69 服务、P9/P16、L1、仓库、SQL、
配置、日志和时钟调用均为0；不建立本地键、稳定编码、目标状态节点、需求节点、关系、值、
槽、幂等、摘要、操作标签、事务、缓存或重试。
