## 3. 4230 必须冻结的共同合同

### 3.1 唯一公共类型

4230 固定合同版本 1，并冻结下列中文强类型身份；所有身份内部只承载一个非零 `稳定编码`，彼此不可隐式替换：

```text
L2场景身份
L2存在身份
L2特征定义身份
L2特征实例身份
L2状态身份
L2动态身份
L2因果身份
L2结构幂等身份 = 非零 uint64
```

共同枚举固定为：

```text
L2读取类别：当前=1，历史=2
L2结构状态：
  已提交=1，精确重复=2，已读取=3，未实现=4，入口拒绝=5，
  许可拒绝=6，未找到=7，已退出=8，属性未设置=9，
  事实代次漂移=10，幂等冲突=11，引用冲突=12，
  资源失败=13，内部不一致=14
```

共同 DTO 固定为：

- `L2结构请求头`：合同版本、期望事实代次；写请求再带完整请求语义绑定的 `L2结构幂等身份`；
- `L2结构结果头`：合同版本、状态、事实截止代次、可选变更事实代次；非成功时不得携带部分事实；
- `L2有序身份引用`：非零顺序与目标稳定编码；同组按顺序、目标编码稳定排序；
- `L2属性提交项`：属性类型身份、I64 / I64组 / U64组 / 独立材料引用四类之一、来源稳定编码；不得接收通用 JSON、裸字节或调用方指定的 L1 当前值编码；
- `L2属性事实`：属性类型、值编码、类型化不可变材料、来源、创建代次、可选退出代次；
- `L2生命周期`：非零创建事实代次和可选退出事实代次；退出事实不可复活或原地覆写。

`未实现` 只为 4201 的最终合同骨架保留；本路线不创建骨架。真实接口完成后不得用 `未实现` 伪装未覆盖分支。

### 3.2 六类唯一所有权与值式事实

| 结构族 | 唯一服务与 DTO 所有者 | 必须冻结的值式事实 | 唯一写入责任 | 禁止责任 |
| --- | --- | --- | --- | --- |
| 场景 | `L2场景结构服务` / `L2场景结构.数据.h` | `L2场景事实`、`L2场景父子关系事实`、`L2场景成员关系事实`、完整直接子场景 / 成员组 | 场景节点、固定属性、父子与成员关系的创建 / 替换 / 退出 | 判断现实世界、所在场景、成员资格或建立独立世界登记 |
| 存在 | `L2存在结构服务` / `L2存在结构.数据.h` | `L2存在事实`、固定属性、被场景成员关系引用组 | 存在节点与固定属性的创建 / 换代 / 退出 | 判断存在真实性、资格或写场景成员关系 |
| 特征 | `L2特征结构服务` / `L2特征结构.数据.h` | `L2特征定义事实`、`L2特征实例事实`、`L2特征值事实`、按存在稳定排序的当前特征组 | 定义、实例槽、宿主 / 定义引用、当前值换代、实例 / 定义退出 | 按轮廓、颜色、位置建立专用 CRUD 或解释值的业务意义 |
| 状态 | `L2状态结构服务` / `L2状态结构.数据.h` | `L2状态事实`：主体存在、特征实例、精确值、时间值、来源和生命周期 | 只保存调用方完整提交的状态记录及引用替换 / 退出 | 判断状态真实、从当前特征自动补状态 |
| 动态 | `L2动态结构服务` / `L2动态结构.数据.h` | `L2动态事实`：主体、前状态、后状态、起止时间值、来源和生命周期 | 只保存调用方完整提交的动态记录及引用替换 / 退出 | 比较状态、生成动态、判断变化重要性或动作归因 |
| 因果 | `L2因果结构服务` / `L2因果结构.数据.h` | `L2因果事实`：非空有序条件状态组、可空动作引用、非空有序结果状态组、来源和生命周期 | 只保存调用方完整提交的因果记录及引用替换 / 退出 | 判断因果真伪 / 必然、推断动作或自动补条件 / 结果 |

场景父子 / 成员、特征宿主 / 定义、状态 / 动态 / 因果角色都是 L1 关系事实；固定属性和时间 / 原始材料都是属性槽与值事实。DTO 只返回完整值式投影，不泄漏 L1 本地键、写集、锁、许可、仓库或事务对象。

### 3.3 单向依赖图

4230 固定以下无环依赖，后继代码叶不得增加反向 import：

```text
L2场景结构 -> L1事实基座
L2存在结构 -> L1事实基座
L2场景成员关系 -> L2存在结构公开读取 + L1事实基座
L2特征结构 -> L2存在结构公开读取 + L1事实基座
L2状态结构 -> L2存在结构公开读取 + L2特征结构公开读取 + L1事实基座
L2动态结构 -> L2状态结构公开读取 + L1事实基座
L2因果结构 -> L2状态结构公开读取 + L1事实基座
未来 A1 聚合面 -> 六类服务；零写入所有权
```

因果可空动作只以不透明稳定编码验证 L1 当前节点形状，不依赖任务 / 方法业务服务。存在服务不反向依赖场景；“被哪些场景引用”由场景所有者公开反向结构查询提供。

### 3.4 共同事务、读取与验证边界

- 创建 / 替换 / 退出一次形成一份不可变 L1 中性写集并恰一次提交；关系替换、值换代和旧事实退出在同一代次发布；
- 同幂等身份同完整请求返回精确重复，同键异义返回幂等冲突；期望代次不符返回事实代次漂移且零变化；
- 当前组合读取使用 L1 一致当前投影，全部节点 / 关系 / 值共享一个非零截止；历史读取显式按历史类别重建完整结构，不用当前事实补齐；
- 引用未闭合时退出返回引用冲突，零变化；任何成功后缺项、身份复义、混代或读回矛盾均为内部不一致；
- 生产外验证只经公开强类型入口输入可修改参数，逐叶核对合法创建、非法零变化、精确重复、冲突、当前读回、替换后旧历史和退出后当前不可见；日志与生产内自检不裁决通过。
