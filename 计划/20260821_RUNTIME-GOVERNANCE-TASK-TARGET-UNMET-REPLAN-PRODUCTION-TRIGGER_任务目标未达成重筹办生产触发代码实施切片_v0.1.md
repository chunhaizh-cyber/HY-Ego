## 4. 实施合同

### 4.1 协议与身份传递

1. 新建 `海中鱼巣.线程.协议.任务重筹办意图`，按详细设计冻结 DTO、守卫、提交状态和抽象端口。
2. 任务结果回执协议升级为版本 4；工作结果和回执增加两笔任务治理写入身份。
3. 三笔任务 owner 写入身份必须非零、两两不同；同义比较和准入覆盖全部字段。
4. 上行桥把两笔身份原样写入任务结果复核载荷；消息协议同义比较和准入同步更新。
5. 自我线程后继输入、处理槽和意图逐层原样传递，意图同时冻结裁决状态与裁决快照；禁止派生、哈希、截断或默认补值。

### 4.2 DATA-L2 原子迁移

1. 扩展 `L2提交目标未达成待重筹办迁移请求/结果`，显式承载旧当前路径和旧当前实例。
2. 写前在同一事实截止读取并互证唯一当前治理状态、当前实例和当前选择。
3. 在一个 L1 owner 写集中创建新治理状态、退出旧当前治理关系、旧当前实例关系和旧当前选择关系。
4. 旧路径与旧实例节点不退出；历史读取必须继续成立。
5. 迁移发生时间允许等于前态发生时间，只禁止早于前态；生命周期版本和事实代次负责顺序。
6. 精确重复返回首次迁移结果和退出后历史投影；同键异义冲突。

### 4.3 业务提供者

1. 新建业务 DTO 和 `任务目标未达成重筹办触发提供者`。
2. 构造函数只借入现有 `L2任务结构服务`。
3. 公开入口逐字段映射 BIZ 裁决到 DATA 材料，不允许结构体内存转换。
4. 先登记首态，再以首态返回代次提交迁移；每一步按详细设计映射结构化非成功。
5. 成功后独立读取当前治理状态、当前实例、当前选择和历史材料，形成唯一工作包。
6. `新筹办轮次 = 旧筹办轮次 + 1`；溢出内部终止。

### 4.4 线程接线

1. 任务管理线程实现重筹办提交端口和有界处理槽；不持锁调用业务提供者。
2. 结果上行与重筹办意图按轮转规则消费，停止判定覆盖两类队列。
3. 自我线程只在目标未达成时形成意图；队列满/资源等待保留同槽重试。
4. 已接收或精确重复后发布处理槽快照、推进本批次路由、清内部槽并继续治理循环。
5. 目标已达成仍停在待验证后完成，不提交意图。
6. 运行包持有业务提供者并完成端口绑定；启动应用把治理运行门开放移到运行包启动成功之后。
7. 停止顺序按详细设计执行，解除绑定必须无悬空调用。

### 4.5 工程与命名

- 新模块登记到 `海中鱼巣.vcxproj` 和 `.filters`；
- 函数名、变量名使用中文；模块身份和物理文件唯一；
- 不新增生产故障钩子、日志裁决或第二业务入口；
- 只在专属施工记录形成函数级知识变更清单，不直接修改共享知识。
