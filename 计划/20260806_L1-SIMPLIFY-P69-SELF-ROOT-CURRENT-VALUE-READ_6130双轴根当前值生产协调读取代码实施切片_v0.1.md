## 1. 目标与完成条件

实现唯一 `L1自我根当前值读取服务::读取当前双轴根值`：按固定顺序协调 P56、P19、
P21、P17、P24、条件 P22、P25、P26 和 P68，形成具名生产双轴当前值读取结果。

完成必须同时成立：

- 请求、结果、读取状态和失败阶段为版本化强类型 DTO；
- P21 只消费 P19 完整成员范围，P24—P26 只消费本轮同一 P17 快照；
- 空槽跳过 P22，非空槽 P22 恰一次；任一 provider 非成功立即短路；
- 第一轮只因 P68 组合截止漂移完整重读一次，零局部重读和跨轮复用；
- 成功事实逐字段等于 P68 结果，不建立第二双轴事实 DTO；
- 生产代码 P29/P53/P65/P67/P40/P15、写入、事务、缓存、日志和时钟调用为零；
- 顺序 569、两配置构建、自检、strict 和模块扫描通过。

## 3. 实施顺序

### W01：S0 与真实接口门禁

1. 重核 main/origin、ahead/behind 0/0、index、计划状态、plan blob 和唯一活动代码计划；
2. 读取 P17—P26、P56、P65、P68 真实头和公开模块，逐字段比对冻结合同；
3. 确认五个 provider const 引用、三份保存定位值、空槽 P22 规则和 P68 状态可机械消费；
4. 确认顺序 569、三个新文件、工程、filters、启动和验证资源未占用；
5. 真实接口改变状态、字段、截止、空槽或 const 签名时停工并具名退回计划支撑。

### W02：公开 DTO 和服务骨架

1. 新建 `L1自我根当前值读取.数据.h`，定义合同、协调规则、请求、状态、阶段和结果；
2. 新建 `服务.L1自我根当前值读取.ixx`，导入全部公开合同且不导入仓库或写入模块；
3. 构造保存五个非拥有 const 引用及三份 const 定位值；禁止默认构造、复制和移动；
4. 入口先校验请求及保存定位形状，失败时 provider 调用 0。

### W03：单轮固定协调

1. 依次调用 P56、P19、P21、P17，各成功事实完整且同根同截止才继续；
2. 以 P21 原样成员范围和本轮 P17 快照调用 P24；
3. 槽总数 0 时跳 P22；非空时 P22 恰一次并取得登记副本；
4. 用同一快照依次调用 P25、P26，检查完整、根、范围、排序和截止；
5. 用 P56 事实、保存 P65 锚和 P26 事实调用 P68 恰一次；
6. 任一步非成功立即映射状态和最早失败阶段，后继调用 0。

### W04：一次完整组合漂移重读

1. 只识别第一轮 P68 `事实代次漂移`；
2. 销毁第一轮全部自我、范围、快照、登记、定义、当前值和投影局部材料；
3. 从 P56 开始执行完整第二轮，禁止局部重读、跨轮复用、等待或无限重试；
4. 第二轮结果直接返回；provider 自身版本漂移不触发重读。

### W05：顺序 569 专项与发布

1. 新建 `自检.L1自我根当前值读取.ixx` 并登记唯一完整自检入口；
2. 覆盖全部 provider 状态、坏成功、调用次数、短路、空槽和同快照门禁；
3. 覆盖单轮成功、一次漂移后成功、两轮漂移和第二轮中途失败；
4. 覆盖异常、并发、零跨轮材料复用及禁止依赖静态扫描；
5. 写入专属施工和验证记录；串行执行两配置构建、自检、strict、模块扫描和 diff check；
6. 只提交本计划白名单实际切片并普通推送，不夹带异主 WIP。
