## 1. 目标与完成条件

按同名详细设计，在唯一 `L2概念结构服务` 内完成：

1. 直接上位关系新增、原子替换和退出；
2. 直接上位与直接下位关系组当前 / 历史有界读取；
3. 同根、多父 DAG、无环和全部普通概念唯一根可达校验；
4. 普通概念首次建立请求固定从概念创建截止重建，不随后继父边变化；
5. 唯一概念 owner、唯一写端口、现有关系类型和现有概念写锁继续成立。

完成只证明本叶生产代码、公开 ABI 和必要构建检查进入正式 Git；不证明实际消费者、普通应用完整装配、完整概念图、定义 / 支持 / 生命周期 CRUD 或 `DATA-EXT-08` 整项完成。

## 4. 机械施工合同

1. 按详细设计 §3 逐字形成 DTO、五项请求 helper、关系事实截止 helper 和三类结果成功形状。
2. 扩展普通概念自有事实重建：当前关系允许后继创建；首次请求只以概念创建截止的历史结构和 owner 首次写入材料重组并互证。
3. 按目标 / 源端点分别实现直接上位 / 下位当前与历史组读；空组成功、稳定排序、超预算空载荷拒绝。
4. 写前在同一非零 `G0` 重建当前概念 DAG，先证明现状完整，再应用候选并证明同根、无环、非根至少一父且唯一根可达。
5. 新增写一条现有直接上位关系；替换同事务退出旧边并建立新边；退出只退出具名旧边。三者共用概念写锁和调用方幂等身份。
6. 每次先读 owner 首次写入材料：同写集精确重复，异写集幂等冲突；发布未知和资源失败保留原请求重放。
7. 首次成功或精确重复都按首次截止历史读回关系变化；非成功两个 optional 为空、组为空、零变更。
8. 不改变四本体根三入口、普通概念建立 / 读取签名、概念 owner 交付或概念聚合 getter。

并机械检查：

- 新增 DTO 与服务签名唯一、中文函数名 / 变量名；
- 根三入口和普通概念建立 / 读取公开签名仍存在；
- 关系类型登记数量不增加，概念 owner 和写端口仍唯一；

- 非成功 optional / vector 空载荷与零变更 helper；
- 两生产文件 UTF-8 无 BOM；
- 精确白名单与生产代码零测试 / 验收痕迹。

按用户裁决不建立专门验收或动态专项。真实新增 / 重复、替换、退出、当前 / 历史、多父、成环、跨根、并发、资源失败、坏私有事实、普通应用装配和合法消费者使用统一记录 `NOT_RUN`，不得用构建通过代替。
