## 5. 物理实施合同

### 5.1 新服务模块

```cpp
export module 海中鱼巣.领域.服务.服务生存治理;
```

只 import DATA-EXT-15/16 最终公开模块及必要纯值标准库。导出详细设计第 4—5 节 BIZ DTO 和 `服务生存治理服务`。服务保存两个 const 引用，不可复制、不可移动；构造不读取事实。

`读取生存安全根当前值`固定：校验 -> DATA-EXT-15 同 G0 读取 -> 状态/截止/载荷复核 -> A/L/H/版本/来源互证 -> 派生控制态 -> 一次返回。

`读取当前服务生存维护快照`固定：先调用根读取 -> DATA-EXT-16 服务值/游标 -> 四类有界组 -> 全部 G0 互证 -> 连接引用 -> BIZ 活动/最长来源裁决 -> 稳定排序 -> 一次返回。

### 5.2 组合器扩展

在 WORLD-SELF 最终模块中：

- 构造函数增加 `const 服务生存治理服务&`；
- 既有世界结构引用和世界—自我读取正文零语义变化；
- 新增 L3 请求/结果和 `读取生存安全与服务维护当前快照`；
- 入口只调用服务生存治理服务一次，再复核回显/G0和值式载荷；
- 不直接 import DATA-EXT-15/16，不复制 L4 裁决。

### 5.3 状态映射

DATA 未找到/尚无权威按必需材料映射；合法空组保持成功；漂移、入口/许可/预算、资源和内部错误各自映射。坏成功、错截止、复义、重复唯一键或悬空引用固定内部不一致。所有非成功 optional 为空。
