## 1. 目标和完成条件

本叶原位扩展唯一新 L1 事实基座，提供一次 try-lock 共享许可内的当前完整快照副本和当前非零事实代次读取，使后继世界、存在、特征、状态和动态事实所有者能够满足 4200 §5.1 的许可拒绝和事实截止合同。

完成必须满足：

- `尝试读取完整快照` 和 `尝试读取当前事实代次` 真实成功、许可拒绝和内部不一致分支均可测；
- 新入口只返回纯值，不外泄仓库、许可、锁、令牌、事务或会话；
- 许可竞争立即拒绝，无等待、sleep 或内部重试；
- 快照投影复用唯一私有实现，稳定排序且不返回部分材料；
- P15 v0.2 双摘要、通用发布后读回、失败见证、隔离和恢复不退化；
- 不形成任何领域或完整世界快照语义。

唯一实现依据为同名 v0.1 详细设计和函数流程图，以及 4015、4020、4030、4200 §5—§6。

## 5. 状态与停工条件

固定状态矩阵：

- 合同错：入口拒绝；
- 空 L1：快照成功代次0，代次入口未找到0；
- 正常已发布：快照成功完整，代次成功非零；
- 许可竞争：许可拒绝，零载荷，零等待；
- 隔离/损坏：内部不一致，零部分载荷；
- 快照分配失败：资源失败；其它异常：内部不一致。

出现任一项立即具名退回：

- P15 v0.2 实际 L1 接口与冻结合同不一致；
- 必须传递 L1 许可、锁、仓库或事务给领域服务；
- 需要阻塞等待、sleep、隐式重试或旧节点直接接线才能返回；
- 需要第二仓库、旁路索引、SQL、第二快照解释逻辑或修改领域语义；
- 无法在同一共享许可内取得副本和代次；
- 必须触碰白名单外文件或活动 WIP。

普通 C++ 拼写、排序、异常捕获和 Debug 夹具错误若不改变合同，由执行侧在白名单内修复。
