# DATA-L2 全部当前场景树结构读取代码实施切片

日期：2026-08-15
版本：v0.2
计划身份：`DATA-L2-SCENE-TREE-CURRENT-GROUP-READ`

## 1. 目标

按同名详细设计，在唯一 `L2场景结构服务` 增加 `读取全部当前场景树`，让未知树身份的调用方以零守卫原子取得最新当前树闭集，或以非零守卫执行乐观当前读取；零棵树是成功空组。

完成条件：公开 DTO、纯值 helper 和服务入口存在；结果稳定排序、同截止、完整且非成功空载荷；无第二 owner、第二写入口或业务解释；生产文件构建通过，临时检查代码已清理。

## 5. 实施步骤

1. 在场景数据头增加请求、结果、请求 helper 与结果 `成功()`，保持中文业务标识符。
2. 在场景服务内部增加只形成空组失败的辅助。
3. 在公开服务原位实现一次 L1 目标关系组原子枚举、根标记防御校验、同截止单树读回、跨树唯一复核和尾代次复核。
4. 不修改既有单树、写入和聚合入口的语义。
5. 写施工与施工检查记录，只记录实际发生的命令、结果和未证明边界。
6. 删除临时检查驱动并扫描生产零验证痕迹。

## 7. 具名停工条件

- `DRIFT-SCENE-TREE-ROOT-GROUP-NOT-ATOMIC`：现行 L1 目标关系组投影不能在一次零守卫许可内枚举根闭集；
- `DRIFT-SCENE-TREE-READ-NOT-SAME-CUTOFF`：现有单树读取不能机械绑定枚举所得非零截止；
- `DRIFT-SCENE-TREE-REGISTER-WIP-OWNERSHIP`：目标两份场景文件出现其它所有者重叠 WIP；
- 正式规范改变根身份、根标记方向、零守卫或树完整性合同。

普通编译错误、局部算法错误和白名单内可修复检查失败由执行者修复后继续。
