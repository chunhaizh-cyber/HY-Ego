## 1. 目标

实现中性状态、动态、引用、实例材料自动生命周期和任务阶段中性迁移。状态 / 动态分别按首次形成 UTC 的 TTL 与各自数量上限清理；普通应用宿主启动立即及每 60 秒维护。

旧 `新增状态_v2` 与 `发布状态动态原子迁移_v2` 退为零写兼容拒绝，旧账只读。

## 3. 实施顺序

1. 复用已落盘 `L1物理清理事实身份/请求/墓碑/结果` 与唯一 `执行L1物理清理`，不得创建第二套 L1 清理 DTO；L1 文件不得引用、include、import 或返回任何 L2 类型。
2. 复用 `L1中性写入首次结果读取请求/结果` 与 `读取中性写入首次结果` 收束中性首次写；中性和 owner 当前/历史/一致读回必须附完整墓碑投影。
3. 在状态数据头按详细设计第2.1至2.3节原样加入公共类型、状态 DTO 和引用 DTO；不修改旧 DTO 布局。
4. 状态服务只公开八个具名函数；private `执行中性实例状态清理阶段_v1` 只由类内隐藏友元桥转交，避免在状态 named module 前向声明 `L2动态结构服务`，动态服务是唯一生产调用者。所有新公开函数不接收 owner、端口、能力或许可材料。
5. 状态首次提交记录独立 `首次形成UTC纳秒`，正式读回成功后才返回成功；实例绝对时间和抽象相对时间不得互换。
6. 普通引用建立只验证目标正式存在。当前选择设置按 `引用方+引用角色` 唯一，显式比较预期旧关系，只改变引用关系。
7. 在动态数据头按详细设计第2.4和2.5节原样加入动态、策略和清理 DTO。
8. 动态服务只公开 `新增/读取/退出中性动态_v1` 与 `执行中性实例材料清理_v1` 四个入口；它是状态 private 清理阶段的唯一调用者并负责阶段进度。
9. 动态新增先以请求 G0 正式读取全部成员；只接受 2..N、身份唯一、材料类别/时间语义一致、时间非递减的完整组。成员特征类型可以不同，不检查相邻时间连续性。
10. 四项策略独立；TTL 只读取材料 `首次形成UTC纳秒`，不得读取事件时间。
11. 清理按详细设计第6节执行动态阶段和状态阶段：动态服务先清理动态，再经隐藏友元桥转入状态 private 入口；两阶段分别正式读回中性/owner完整墓碑投影并按进度收束，不要求同一 G1。
12. 旧 v1、旧 `新增状态_v2`、旧原子迁移 v2 固定零写拒绝；删除其生产写调用，保留符号和布局；旧 owner/cross-owner 账只读且零追加。
13. 新状态、动态、引用、清理使用四个互异具名幂等域；不得复用旧域或用 XOR 临场派生。
14. 所有 `成功()` 按详细设计矩阵实现。已清理、历史材料已清理、入口拒绝、漂移、冲突、资源失败和内部错误均为失败；无须清理只对清理结果为成功。
15. 普通应用宿主绑定维护回调：启动立即、每 60 秒；资源失败保留请求，漂移换 G0 / 换身份且每周期最多一次，内部不一致或序列耗尽形成程序失败；DATA 服务零线程。
16. 维护身份使用 `0x4E43'0000'0000'0000` 前缀和进程内原子单调低 48 位；抽象完成禁止该前缀。
17. 任务阶段消费端口改用特征 / 状态 / 动态服务并移除原子发布服务，顺序形成中性状态、动态、当前选择并保存独立代次。
18. `任务初次筹办.数据.h`、`任务结果消费分配与轮次结算.数据.h`及下游消费者删除旧状态 / 第一动态 / 旧选择 / 共同 G1 投影，改存中性证据；执行派发阶段证据只保存引用键、状态 / 当前选择强身份及独立代次，最终当前性复核按键 fresh 读取完整事实并解码互证。

## 4. 实际使用阶段验收矩阵

本节是后续真实消费者接入公开 ABI 后必须执行的验收账，不是本轮基础实现的完成门禁。本轮不新增专项测试文件、不建立模拟消费者，也不以静态检查或根工程构建冒充以下业务矩阵已经通过。

| 组 | 实际使用阶段必须覆盖 |
| --- | --- |
| ABI | 全部目标 DTO 物理顺序、默认值、相等性、函数签名和旧 DTO 布局 |
| 状态 | 实例/抽象首次、重复、异义、G0、坏特征、坏值、绝对零、相对负数、正式读回 |
| 动态 | 2项、N项、混合特征、粗粒度跳点、同时间、1项、重复身份、时间语义混合、时间递减、成员缺失/退出/已清理 |
| 引用 | 普通多次引用、首次当前选择、替换、旧关系不匹配、多义坏闭包、目标已清理、无自动回退 |
| TTL | 默认7天策略、显式小策略覆盖、既有装配零修改、状态到期、动态到期、状态到期牵引动态、抽象材料不清理、事件时间不影响 TTL |
| 总量 | 状态上限、动态上限、双上限同时触发、形成时间并列时稳定身份排序、清理后计数满足上限 |
| 抽象完成 | 具名动态和抽象结果见证、动态先清理、共享状态保留、孤立状态清理 |
| 墓碑 | L1自有六字段DTO、L1零L2依赖、L2唯一根墓碑投影、稳定身份不复用、当前读已清理、历史材料已清理、紧凑账精确重复、同键异义 |
| 清理调度 | 启动立即、每60秒、DATA零线程、资源同请求、漂移换键一次、程序失败、抽象幂等域隔离 |
| 失败 | 资源失败、内部写会话失败、交换前零写、提交后读回失败同键收束 |
| 无权限裁决 | 新 DTO/状态枚举/分支零许可拒绝；未取得内部写会话只返回内部错误 |
| 旧 ABI | v1、状态 v2、原子迁移 v2 均零写拒绝，旧账零追加，新域不命中旧账 |
| 任务阶段 | 两个数据头旧承载移除、首态 / 迁移顺序、独立代次和旧 v2 零调用 |
