## 5. 失败收口

- 若发现名称含自检的文件拥有正式生产调用，停止该文件删除并回传 `REMOVE-LEGACY-ACCEPTANCE-CODE-DRIFT-PRODUCTION-CAPABILITY`。
- 若删除故障注入条件后正式候选 / 确认 / 撤销 / 发布 / 读回条件无法唯一恢复，停止对应文件并回传 `REMOVE-LEGACY-ACCEPTANCE-CODE-DRIFT-CONDITION`。
- 若 `程序运行结果` 仍有未扫描的四字段聚合初始化，停止并回传 `REMOVE-LEGACY-ACCEPTANCE-CODE-DRIFT-RESULT-AGGREGATE`。
- 若双配置构建或任一生产模式失败，只修复本计划删除造成的编译 / 路由错误；不得恢复验收模式、宏、夹具或私有探针。
- 若需要修改 legacy 业务标签、意图、领域结果或执行证据合同才能继续，停止并回传计划支撑，不在本叶扩张。
