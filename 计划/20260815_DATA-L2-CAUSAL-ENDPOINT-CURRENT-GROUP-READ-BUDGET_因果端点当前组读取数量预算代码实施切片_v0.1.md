## 1. 目标与完成条件

依据[详细设计](../规范/详细设计/20260815_DATA-L2-CAUSAL-ENDPOINT-CURRENT-GROUP-READ-BUDGET_因果端点当前组读取数量预算详细设计_v0.1.md)，为条件状态、动作、结果状态三类既有当前因果组查询增加非零因果对象数量预算。

完成必须同时满足：

1. 三个公开请求各追加一个 `std::uint64_t 最大数量 = 0`，纯值 helper 拒绝零预算；
2. 三个公开入口把预算逐项传入同一私有端点读取实现；
3. 预算按端点关系源去重后的因果对象数计数，不按关系条数计数；
4. 匹配数大于预算返回 `数量预算不足`、空因果组和空变更代次，不截断；
5. 匹配数不大于预算时继续逐项同守卫完整读回，保持严格升序和同截止；
6. owner、写入口、来源查询、工程、普通应用和其它服务 ABI 零变化；
7. 根工程 Debug / Release 构建及静态合同通过，永久记录如实列出 `NOT_RUN`。
