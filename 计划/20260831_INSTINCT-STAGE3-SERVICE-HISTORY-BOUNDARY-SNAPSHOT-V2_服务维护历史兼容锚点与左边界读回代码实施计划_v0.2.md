## 1. 目标与完成条件

在现有唯一 `服务合同事实权威服务` 内建立不可变服务维护历史兼容锚点，并实现从显式覆盖起点 `Gseed` 到任意 `Gstart/G0` 的左边界与区间变化完整读回。

完成必须同时满足：

1. `0x0307'3060..306B` 以同 owner 独立幂等建立 / 恢复五类 v2 历史根，首次写集把当时当前合同+状态、进展 v2、准备 v2 冻结为覆盖种子；
2. v2 历史成员关系永久保留目标节点，进展 / 准备更新对种子 incumbent 只退出当前关系并同步写入 v1/v2 历史；
3. 新入口从锚点正向重放到 `Gstart`，把左边界四类当前投影、`(Gstart,G0]` 五类变化、范围和成员完整性收束为一个不可拆分的低层完整范围快照；
4. 快照只含请求 self；左边界合同必须仍为有效未满足，foreign self 不进入载荷、声明成员和预算；
5. provider 在返回 `已读取` 前内部把重放所得 `G0` 当前有效未满足合同 / 状态、当前进展和当前准备与既有正式当前读回逐字段互证；公开 `成功()`只验证自包含载荷形状，DTO 不增加第二份 `G0` 终态投影；
6. `Gstart<Gseed`、不可恢复、漏 / 重 / 坏引用、跨 self、任一预算不足、漂移、内部终态不一致和资源失败全部结构化非成功、零快照；
7. 现有 v1 历史范围 ABI 与回归保持；
8. Debug / Release、专项、ABI consumer、持久恢复、diff-check、strict 通过；
9. 形成专属施工 / 验证记录并精确提交、普通推送。

## 5. 实施步骤

1. 候选常量全仓零命中；module-private 建立结构登记和历史成员类型；公开新增低层工程 DTO、严格升序 / 完整性 / `成功()`谓词。
2. 增加 v2 五根登记定位、数据依赖首次写集、首次恢复和构造顺序；首次写集读取当前四类完整集合并形成规范种子。恢复从首次规范写集 / 映射重建种子，不按重启当前集合重算。
3. 修改进展 / 准备 v2 写集分账：旧事实必须有唯一 v2 历史成员；只退出当前关系并保留历史材料；新事实同步写入 v1/v2 历史。
4. 实现 v2 五根和当前根一次 G0 一致读回；全局根先验证，再按请求 self 形成左边界和变化；foreign self 不进入载荷、声明成员或预算。
5. 左边界合同投影必须逐项验证 `当前状态 == 有效未满足`、合同 / 状态身份一一对应和 `已消费有效秒 <= 冻结有效总秒`；终态合同不得留在左边界当前组。
6. `成功()`使用已有字段验证合同、进展和准备直接 self；合同状态和到期事件通过“左边界合同 + 合同变化”唯一合同身份表间接解析 self。缺失、多义或跨 self 引用整体 false。
7. provider 从 Gseed 正向重放到 Gstart，再收集变化并重放到 G0；内部把重放所得 G0 有效未满足合同 / 状态、当前进展和当前准备与既有正式读回逐字段比较。该步骤是返回后置条件，不向快照新增终态副本。
8. 扩展测试宏内 fixture，覆盖锚点前 incumbent、后继更新、坏锚点、预算、漂移、跨 self、左边界终态、provider 内部 G0 终态错配、资源和恢复；生产无 fixture 出口。
9. 形成施工记录中的函数级代码知识变更清单和验证记录。

## 6. 失败收口

- v2 覆盖登记首次建立 / 恢复损坏：服务构造失败，不降级 v1 或空 v2 账。
- `Gstart<Gseed`：覆盖边界不可用；不得补算种子前历史。
- 左边界流缺唯一前驱 / 后继：左边界不可恢复。
- self 引用缺失、多义或跨 self：引用冲突 / 集合不闭合；不得过滤后伪装为合法空集。
- 左边界合同不是有效未满足，或 G0 历史重放与正式当前四类不相等：集合不闭合。
- 数量预算不足：整体失败，不截断；foreign self 不计入请求 self 的预算。
- G0 漂移：丢弃候选并返回当前性漂移。
- 资源 / 异常：资源失败 / 内部错误；快照为空、截止 0。
