## 1. 目标与完成条件

在现有 task owner、运行期只读组合、初次 / 重筹办、冻结、线程协议和普通应用装配中完成一个首叶：

1. 每次任务承接输入携带具体需求 D；
2. 经 D 所属列表项 L 查询 / 防重，建立或复用唯一当前任务 T；
3. task owner 正式持久化、读取并退出 `T→D` 关系；
4. 目标、筹办、冻结和重判只消费当前显式关联 D；
5. 删除 Stage C 五类授权安全事实、provider、缺失默认实现和授权等待；
6. 权限为零不阻断筹办 / 冻结，真实权限仍只允许冻结后、派发前形成；
7. Debug / Release 的需求与治理专项证明上述结构和非成功矩阵。

计划完成不证明 6150 / 6170 生产 provider、自我线程 D 接线、任务结果分配、Release 测试隔离、集成验收或完整生命闭环完成。

## 6. 实施步骤

### S1：task owner 数据与事务

1. 在`L2任务结构.数据.h`新增来源关系强类型、事实、请求 / 结果、有效性和相等合同；任务 / 查询 DTO 中的旧字段机械改名为同类任务查询锚点。
2. 在`服务.L2任务结构.ixx`登记四枚本地键及定位 / 写入映射；不得恢复冲突键。
3. 扩展新任务事务，同代原子发布任务、族归属、T→L、首个 T→D、V、T→V；写后读回全部角色。
4. 实现`承接具体来源需求`：T 有 1..N 项当前有效关联 D 时逐项验证与新 D 目标等价；显式关系为空或全部 D 已失活时，只有在 T 仍为 L 下唯一当前任务、生命周期允许复用且新 D 当前属于 L 时才先幂等新增 T→D。写后目标只从新 D 与其它当前有效 D 形成；异目标 / 错锚点零写，禁止用 L 聚合键形成目标。
5. 实现来源关系组当前 / 历史读取；当前按 D 身份、关系身份稳定升序，无重复；空组成功。
6. 任务退出同代闭合全部当前 T→D；历史仍可读。

### S2：组合快照与目标投影

1. 运行期 DTO 用来源关系组和具体需求目标投影替代列表项成员快照；不增加任务目标副本。
2. 组合器先读取 T、T→D，再逐项读取 D；验证至少一项当前、所属 L 与目标三元组相同。
3. 空组 / 全失活返回具名无当前来源需求；不得读取 L 聚合键或全成员兜底。
4. 任务目标达成、重筹办和回流沿同一投影消费，不建立第二读取路径。

### S3：初次筹办、方法查找与冻结

1. 初次准备 / 工作包保存输入 D、T→D 关系和共同截止；禁止自动纳入 L 其它成员。
2. 方法查找从显式 D 互证目标读取目标特征 / 宿主 / 状态合同。
3. 删除`L2任务授权安全复判材料`、五类 Stage C 身份 / 联合分支、`授权安全等待`、材料来源接口、默认缺失来源和全部消费校验。
4. 当前就绪只检查方法生命周期 / 内容、条件、输入、参数、限制、动作入口、验证、归因和来源需求当前性；权限为零不进入本步骤。
5. 执行冻结保存实际消费 T→D / D 版本，不保存通用授权安全材料。

### S4：线程协议、任务管理与装配

1. 执行请求协议删除 Stage C 冻结材料守恒检查，保留任务、来源、路径、实例、冻结和版本守恒。
2. 任务管理承接输入携带具体 D；按 D→L 查询 T。复用 T 时区分 1..N 个当前有效 D 与 0 个当前有效 D；后者必须验证唯一当前、生命周期允许复用和 D 当前属于 L，生命周期不允许时具名非成功，由业务结束旧 T 后再建新任务，不得偷偷复活。
3. 普通应用删除 Stage C provider 参数、成员、默认实现、构造注入和`授权安全等待`登记。
4. 不接线`创建.自我线程.ixx`；不调用 N16/N17 骨架。普通派发资格生产仍是直接后继，施工完成报告必须保持未证明。

### S5：测试、记录与知识交接

需求专项覆盖 owner 结构、幂等、历史和键；治理专项覆盖 D 承接、目标投影、筹办 / 冻结 Stage C 删除、回流 / 重筹办和协议守恒。测试只能经公开入口构造事实，不得增加生产后门。

施工记录逐函数登记用途、参数来源、事实读写、事务、非成功和验证。知识变更清单至少路由 task owner、运行期组合、初次筹办、当前就绪 / 冻结、任务管理和普通应用装配的用途卡；执行智能体不得直接写共享知识库。

## 7. 固定非成功与恢复合同

- L 查询 0 / 1 / >1 必须分别为合法空、唯一任务、内部不一致；
- `(T,D)`重复为精确重复，不得建立第二关系；
- 同键异义、异目标、错锚点、错 owner、已退出、代次漂移、资源失败分别具名且零写；
- 当前来源组空是读取成功，但目标 / 筹办必须具名停止；
- 承接前显式关系为空或全部 D 已失活，不自动判定 T 不可复用；满足唯一当前、生命周期允许和新 D 属 L 时可先写 `T→D`，否则具名非成功且零写；
- 生命周期不允许复用时由任务业务结束旧 T 后再建立新任务，不得在原 T 上补写生命周期或偷偷复活；
- 发布未知只用原键、原完整请求读首次幂等账；
- 不跨 owner 拼大事务，不新增锁序，不用日志 / 缓存 / 名称补身份；
- 旧列表目标和旧 Stage C 格式只读历史，不默认迁移；
- 缺真实派发资格 provider 不能回退为筹办授权等待、默认成功或普通生产派发完成。
