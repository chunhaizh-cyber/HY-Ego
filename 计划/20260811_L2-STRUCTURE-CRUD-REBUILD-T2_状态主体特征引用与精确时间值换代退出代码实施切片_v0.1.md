### 2.1 规范与事务裁决

以 4230 为状态结构机器语义直接依据：状态主体 / 特征实例由 L1 关系事实承载，精确值 / 时间值由属性槽和值事实承载；关系替换、值换代、旧事实退出和新当前引用必须在同一事实代次原子发布。1160、4210、旧状态 / 动态代码和历史计划中的场景归属、状态业务准入、自动当前性选择、状态比较或动态生成口径均不得进入 T2。

主体和特征实例不是两个可以独立落盘的更新入口。若旧状态为 `主体A + A的实例`，目标为 `主体B + B的实例`，任何单腿更新都会制造主体与实例宿主不一致的公开中间态。因此本计划只建立一个原子引用对替换函数；请求至少改变主体或特征实例之一，但实现始终同时退出两条旧关系并新建两条关系，使结果形状、幂等语义和历史边界唯一。

精确值与时间值使用一个强类型角色枚举选择，但每次只换代一个角色。状态顶层来源由两值共同互证，T2 不提供来源换代；请求必须显式回显当前来源，新值继续引用该来源。若调用方确需改变来源，那是会改变状态完整记录语义的新目标，不能伪装成一次单值换代。

全部 DTO 提供逐字段默认比较。共同有效性固定为合同版本 1、非零期望事实代次、幂等身份和状态身份。`L2状态关系退出事实` 只用于成功结果，要求关系编码非零，生命周期创建代次非零且退出代次存在；退出代次必须等于结果头的变更 / 截止代次。

引用替换要求 `旧引用` 的主体 / 特征实例关系编码非零且互异，新主体 / 新实例非零。两个旧编码由字段名固定角色，不接受排序向量，不允许交换角色而保持同一公开语义；形成 L1 写集时才把两编码排序为唯一退出集合。“新引用对与当前引用对完全相同”只能在当前读回后裁决为 `引用冲突`。请求不复制旧主体 / 实例，不携带族归属关系、关系类型身份或 L1 本地键。

值换代要求角色恰为精确值 / 时间值、旧值和来源非零、新材料满足共同材料规则：I64 任意，I64 组 / U64 组非空，独立材料编码非零。来源是当前状态来源的显式回显和新值来源，不是来源换代入口。

退出闭包以强类型字段准确包含五个自有事实编码：族归属、主体、特征实例三关系和精确、时间两值。五编码必须全部非零、两两不同，且不得等于状态自身编码；字段名固定角色，不以排序向量丢失角色。实现逐字段与当前完整状态 / 三关系投影比较，通过后才把状态节点及五个闭包编码合并、全局排序为六项 L1 退出集合。请求不携带主体、实例、来源、锚点、类型节点或外部引用编码。

成功结果只接受 `已提交 / 精确重复`、非零且相等的事实截止 / 变更代次。引用替换成功同时携带一个截止完整当前状态、含族归属的三条当前关系编码和两条在本次代次退出且带生命周期的旧引用关系；值换代成功携带截止完整当前状态、当前三关系和一个同代次退出的旧值；退出成功携带节点、两值均在本次代次退出的状态和三条带退出生命周期的自有关系。所有非成功载荷为空；提交前失败不携带变更事实代次，L1 已成功发布后的资源 / 内部读回失败可以回显已安全取得的首次变更代次，但不得伪造成功载荷。

三个 `成功() const noexcept` 只核对结果头、可选载荷组合、身份 / 生命周期和角色化关系投影等不依赖私有登记的形状。精确 / 时间值是否属于登记八类型、材料表示、所属状态、来源互证和关系类型角色，必须由服务使用已加载登记在返回前验证；执行者不得把无登记参数的 `成功()` 当成完整业务预言机。

## 6. 共同写前、幂等、提交和首次结果

三个写函数的共同顺序固定为：

```text
纯值校验
-> 读取当前状态结构类型登记
-> 形成完整不可变 `L1所有者范围写集请求`
-> 探测当前事实代次
-> 实际代次 != 请求期望：恰一次直提原写集，由 L1 裁决重复 / 冲突 / 漂移
-> 同期望：调用 T1 读取完整状态(当前)并完成本函数专属前置
-> 恰一次提交同一写集
-> 从首次事实代次历史节点、关系、属性值和端点重建首次结果
```

登记未加载映射 `入口拒绝`，许可拒绝、漂移、资源失败和内部不一致精确映射。实际代次已经偏离时不得先用当前事实重建或改变写集：L1 对原幂等键先比较完整请求，精确重复返回首次结果，同键异义返回幂等冲突；新键只返回漂移。不得换幂等身份、改期望、替换旧编码或二次提交。

普通 T2 幂等身份完整 64 位原样映射为 `L1所有者范围写入幂等身份`，不进入状态登记私有 `0x20` 域。所有写集只经 `第一层写入端口_.提交所有者范围中性写集` 提交，结果必须回显同一状态 owner；不得调用旧 `提交中性写集`、建立 raw L1 写入口或混入其它 owner。T1 五个本地键按每份写集局部作用域合法复用：

```text
状态族归属关系本地键  = 0x0204'2003U
状态主体关系本地键      = 0x0204'1101U
状态特征实例关系本地键  = 0x0204'1102U
状态精确值本地键        = 0x0204'1201U
状态时间值本地键        = 0x0204'1202U
状态端点角色            = 1
```

首次结果只从首次发布代次的 L1 历史事实重建。后继关系 / 值再换代或状态退出后，原请求重复仍返回首次关系、值、状态截止和首次退出事实；不得把未来退出代次、未来端点或未来值混入原结果。

提交前出现的入口、登记、端点、漂移、幂等、引用、许可、资源或内部非成功必须零普通事实变化。L1 已返回成功后，若首次历史重建发生 `std::bad_alloc` / `std::length_error` 或读回矛盾，公开结果为空载荷并映射资源失败 / 内部不一致，但不能宣称零变化；实现必须保留原幂等身份和原完整请求作为唯一收敛路径，不二次提交、不改变请求、不补偿已发布事实。

## 7. 主体 / 特征实例引用对原子替换

引用替换写集固定为：

```text
节点 = []
关系 = [
  {状态主体关系本地键, 源=请求状态, 目标=请求新主体,
   类型=登记主体关系类型, 角色=1},
  {状态特征实例关系本地键, 源=请求状态, 目标=请求新特征实例,
   类型=登记特征实例关系类型, 角色=1}
]
值 = []
属性槽变更 = []
退出事实 = 全局升序唯一[
  请求旧引用的主体关系与特征实例关系编码]
```

请求期望代次匹配时，先调用 T1 `读取完整状态(当前)`，要求返回一个完整状态及族归属 / 主体 / 特征实例三条自有关系；当前主体 / 实例关系编码必须逐角色等于请求 `旧引用`。随后以同一期望代次正式消费 `读取存在身份来源(当前)`、`读取特征实例身份来源(当前)` 和 `读取完整特征实例(当前)`；三个结果截止必须都等于请求期望，且新实例宿主必须等于新主体。存在完整事实不是本端点必需重复读取；身份来源证明新主体强类型身份，完整实例同时证明新实例身份、宿主与当前完整形状。

新主体和新实例都等于当前状态端点时是无变化请求，返回 `引用冲突` 且零提交。只改变主体、只改变实例或同时改变两者都允许，但结果始终新建两条关系并退出两条旧关系；这保证引用对历史形状一致，也避免可选半替换 DTO。新端点未找到 / 已退出、许可、漂移、资源按同名状态；实例宿主与新主体不符或旧关系编码不符返回引用冲突；当前完整状态形状矛盾返回内部不一致。

成功 / 精确重复必须取得两个本地键到两个不同非零新关系编码的一一映射。首次代次历史读回必须证明两旧关系在该代次退出、两新关系在该代次创建、关系类型 / 源 / 新目标 / 角色正确，族归属关系、状态节点和两值未退出且来源、材料、生命周期保持原样；成功结果用带生命周期的双关系退出投影回显两旧关系。任一缺项、多项、错端点、错类型、混代或非预期族归属 / 值变化返回内部不一致，不二次提交。

T1 当前读取在替换代次之后只能返回新端点 / 新关系，历史截止早于替换代次返回旧端点 / 旧关系，截止等于替换代次返回新对；两条件查询随关系权威变化，不复制第二条件索引。

## 8. 精确值 / 时间值跨表示换代

按请求角色唯一选择旧属性和值类型组：

- `精确值`：旧值必须等于当前状态精确值编码，新材料只映射到四个精确值登记类型之一，使用 `0x0204'1201U`；
- `时间值`：旧值必须等于当前状态时间值编码，新材料只映射到四个时间值登记类型之一，使用 `0x0204'1202U`。

唯一写集为：

```text
节点 = []
关系 = []
值 = [{所选本地键, 所属=请求状态,
       类型=按角色和新材料选择的登记类型,
       材料=请求新材料, 来源=请求来源}]
属性槽变更 = [{请求状态, 所选登记类型, 所选本地键}]
退出事实 = [请求旧值稳定编码]
```

请求期望代次匹配时，T1 `读取完整状态(当前)` 必须存在且完整，并在同一结果内闭合当前状态身份来源及三关系；所选旧值编码必须等于请求，状态顶层来源、精确值来源和时间值来源必须三者相等并等于请求来源。另一个未换代角色、状态节点和三关系必须保持当前、完整且同截止。旧值不符或来源回显不符返回引用冲突；缺槽、多槽、两值来源矛盾、所属 / 表示 / 生命周期矛盾返回内部不一致。

新材料可以与旧材料逐字段相同，也可以跨 I64、I64 组、U64 组和独立材料引用表示；显式换代仍建立新的值稳定编码。L1 在同一候选中退出旧值并移除旧槽，再建立新值和新槽，因此一个角色始终至多一个当前值，另一个角色零变化。

成功 / 精确重复必须取得所选唯一新值编码。首次历史属性值组只证明在首次截止所选角色唯一有效值为新值、另一角色仍唯一有效；该提供者的候选来自成功属性槽变更，但不返回历史槽对象。旧值必须另以 `读取中性历史事实(旧值编码)` 证明在首次代次退出。即时首次提交后若仍位于同一代次，可以用一致当前属性投影补充核对槽指向新值；后继事实已经推进后的精确重复不得依赖不存在的历史槽投影。结果的 `当前状态` 是首次代次完整状态，`已退出值` 保留完整退出生命周期。所属、角色类型、材料表示、来源、唯一有效值、编码或生命周期任一矛盾返回内部不一致。

## 9. 状态显式闭包退出与外部引用保护

退出前调用 T1 `读取完整状态(当前)`，取得状态事实和族归属 / 主体 / 特征实例三关系编码；该入口已经在同一截止闭合状态身份来源。将三关系及精确 / 时间两值逐角色与请求强类型闭包五字段比较；任一漏项、错角色或错编码返回 L2 `引用冲突`，零提交。无需另起不同截止重复证明状态来源。

唯一 L1 写集为：

```text
节点 = []
关系 = []
值 = []
属性槽变更 = []
退出事实 = 全局升序唯一[
  状态节点编码,
  请求自有事实闭包的族归属 / 主体 / 实例三关系编码,
  请求自有事实闭包的精确 / 时间两值编码]
```

请求不得携带或退出主体存在、特征实例、来源、十个类型节点、未来动态 / 因果关系或其它外部事实。L1 对最终写集执行二次当前引用闭包保护：任一未来动态前 / 后状态关系、因果条件 / 结果关系、值来源或其它当前事实仍引用状态节点，且未由其合法所有者先行退出时，返回 `L1所有者范围写入状态::引用冲突=9`；T2 精确映射且不扫描消费者、不返回引用者列表、不补造退出项。

成功 / 精确重复要求空新编码映射和首次发布 / 重试边界正确；按首次事实代次历史读取状态节点、族归属 / 主体 / 特征实例三关系、精确 / 时间两值，六项退出代次必须相等。端点、来源、锚点、类型节点及外部已先行闭合事实不由 T2 退出。`已退出状态` 保留状态和两值退出生命周期，`已退出自有关系` 逐角色返回三关系编码与退出生命周期；任一读回矛盾为内部不一致，不补偿已经发布的事实。

## 10. 状态、读取兼容、幂等和异常收口

T2 不改变 T1 六个函数签名。T1 当前 / 历史完整读取必须自然消费关系 / 值历史：

- 引用替换前截止返回旧主体 / 实例，替换截止及之后返回新主体 / 实例；
- 值换代前截止返回旧值，换代截止及之后返回新值；
- 退出前截止返回当时完整状态，退出截止及之后仍返回 `已读取` 和完整退出生命周期；当前入口才返回 `已退出` 空载荷；
- 当前按主体 / 实例查询只随主体 / 实例两条端点关系变化；族归属关系不充当条件索引，结果按状态身份升序且不复制第二权威列表。

同一幂等身份只绑定完整请求。引用替换与状态退出的公开请求以具名字段固定角色，进入 L1 前再把退出编码排序；L1 规范化不改变公开角色语义。精确重复返回首次状态、关系、值和首次代次，零推进；同键异状态、旧引用任一角色、退出闭包任一角色、新端点、值角色、旧值、材料或来源为幂等冲突。发布结果未知只以原请求重提，不换键、不重构材料。

非成功顺序固定为：

```text
纯值非法 -> 入口拒绝
登记未加载 -> 入口拒绝
登记其它失败 -> 对应共同状态

L1 外部当前引用未闭合 -> 引用冲突
许可 / 资源 -> 同名
事实形状矛盾 -> 内部不一致
```

所有 `L1所有者范围写入状态` switch 必须完整覆盖 `引用冲突=9`，并精确映射为 `L2结构状态::引用冲突=12`。T1 完整状态必有三关系和两值，T2 不把缺失角色包装成 `属性未设置`；缺项是内部不一致。全部非成功载荷为空；提交前失败不伪造变更代次，提交后读回失败只回显 L1 已安全取得的首次代次并遵守第 6 节收敛边界。
