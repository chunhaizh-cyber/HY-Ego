## 3. 施工合同

### 3.1 数据与编码

在既有 `核心/L1事实基座.数据.h` 中增加/扩展值式字段：`领域结果见证计划`、`领域结果见证段`、`领域结果见证记录`、`领域结果计划摘要`、`领域结果见证摘要`、`确定性结果摘要版本`。v1 只支持 `节点种类` + `std::optional<值表示种类>`；枚举写 underlying U8，optional 标记 0/1，所有 U32/U64 大端，数组数量 U64 且按标签升序。

公共函数必须唯一：

```text
形成L1领域结果计划摘要(计划)
  "HZY-L1-RP" + U32(1) + U32(0x15000301) + U32合同 + U32规则 + U8变体
  + U64字段数 + 每项(U32标签,U32本地键,U8种类,U8 optional[,U8表示]) → SHA-256

形成L1领域结果见证摘要(结果)
  "HZY-L1-RW" + U32(1) + U32(0x15000301) + U32合同 + U32规则 + U8变体
  + U64代次 + U64幂等 + U64字段数
  + 每项(U32标签,U32本地键,U8种类,U8 optional[,U8表示],U64新编码) → SHA-256
```

G6 调用方只在固定位置把 RP 的 32 原始字节插入 `HZY-L1G6` 序列；不得把 RP 再哈希、写长度或复制到 G0。RW 只在锁内映射完成后形成。

### 3.2 结果摘要与版本

保留现有 `形成L1确定性结果摘要` v1 的非 E01 字节含义。为 E01 增加结果摘要 v2 路径：只写一次 `HZY-L1RS`、只写一次 U32 版本 2，随后写 v1 去除前缀与版本后的字段载荷（从合同版本开始，到逐项通用读回结束），再写 RW 原始 32 字节并 SHA-256；绝不嵌套 v1 前缀或 U32(1)。`摘要合同版本=1` 不变；结果摘要版本必须显式随首次结果、幂等账、审计、恢复材料保存。

同义探测按原请求意图摘要命中后，原样返回首次 RW、结果摘要版本和结果摘要；不得按当前映射/代次重算。恢复按版本分派：E01 `RW v1 + 结果 v2`，其它 `结果 v1`。版本未知、缺少 RW、重算不等或三副本不等均拒绝恢复；交换后读回矛盾为 `内部不一致` 并隔离。
