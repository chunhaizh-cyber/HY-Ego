7. 生产与永久记录发布后，三份临时验证文件经交互接受和索引退出后独立清理。

## 5. 机械实施合同

### 5.1 DTO 与初始化模块

按详细设计第 4 节逐字形成合同版本、生产默认幂等身份、`系统世界树根初始化请求`、十状态枚举、三来源枚举、`系统世界树根读回` 和 `系统世界树根初始化结果`。请求接受任一非零不透明身份以表达本上下文调用方选择并验证异参数冲突；正式启动只使用生产默认身份。三种成功来源的 optional 形状必须逐项匹配详细设计表格，不得复制或改义 R1 DTO。

新模块导出且只导出：

```cpp
系统世界树根初始化结果 初始化并发布系统世界树根(
    普通应用上下文& 上下文,
    const 系统世界树根初始化请求& 请求) noexcept;
```

按详细设计第 6 节实现：请求校验；同锁检查已发布 / 待收敛；读取当前树结构登记；保存完整待收敛根请求；R1 建根；再次读取当前登记；正式读取整树；逐字段验证；局部完整构造后无抛出交换发布。外层捕获分配与其它异常并分账；既有发布值在任何失败下保持不变。资源或提交后读回不确定时保留原请求；明确零变更漂移可清除后重取当前代次。不得自动换幂等身份。

### 5.2 普通应用上下文

在 A1 最终成员之后追加发布锁、待收敛请求和值式根读回；新增按值返回的 const getter和初始化函数 friend。保持运行包、六服务与 A1 的 owner、构造、getter和析构顺序不变。上下文不得出现根 CRUD、根选择算法或第二服务实例。

### 5.3 正式生产入口

`运行普通程序` 在普通应用装配成功后立即构造默认请求并调用 I1。I1 非成功返回 `初始化失败 / 现实世界树根初始化`；I1 成功发布根后，由于本叶不修改 7130，固定返回 `初始化失败 / 自我初始化待适配`。`程序失败阶段` 在旧最大值 13 后连续追加 `现实世界树根初始化 = 14`、`自我初始化待适配 = 15`，不重排旧值。两路都不进入模式分支、控制面板、信号、宿主或旧自我初始化；后继自我适配叶真实接通并验证后才能移除值 15 对应短路。

### 5.4 工程和产物

根工程登记一个新 `.ixx` 和一个新 `.h`；filters 各登记一次。专项三文件不进入根工程或 solution，输出到系统临时 GUID 目录。永久记录必须写实际命令、结果、提交边界和 NOT_RUN 项。

## 6. 失败与生命周期

- 无效请求、已有发布异选择在 R1 写前短路。
- R1 任一非成功保留原状态和阶段结果，不把失败翻译成已发布。
- R1 已发布而正式读回失败时不撤销、不另键重建；原请求后继收敛。
- 成功发布后同请求必须零 R1 写调用并再次正式读取；I1 返回自身的 `精确重复` 消费状态，异请求固定冲突。
- 上下文只持有值式副本和过程状态，根事实生命周期由 R1 owner 管理；上下文析构不退出根。
- 当前进程结束后值式副本消失。新进程没有恢复发布时建立新的运行期根，不声称复用旧编码。
