## 1. 目标和范围

在用户已经清空并授权重建的新特征类中，交付能够实际保存和读取的首段：显式先天有序 I64 类型初始化、独立特征信息节点及五字段操作、按类型和值查询，以及接收准确输入后的历史去重、逐域计数、三次简化和自动建子。这里只冻结这个首段，不声称全部特征类型或整个特征服务已完成。

代码白名单：

- `海中鱼巣/领域/数据服务.特征类.ixx`：所有新特征类型、接口、封闭编解码和实现均在本模块。
- `海中鱼巣/领域/数据服务.特征值类.ixx`：去掉跨模块特征类前置声明和 friend，形成值的公开只读取得能力；不另建值写 owner。
- `施工记录/20260907_FEATURE-NODE-I64_特征节点数据操作施工记录_v0.1.md`：实施事实、知识变更清单和未验证范围。

禁止修改 L1、上层消费者、工程、启动装配、正式规范及共享知识库。不恢复旧宿主实例槽、旧 ABI、批次账、公共技术头或全局概念。不存在类、状态类等其它文件的编译修复不在本计划。

首段明确排除：后天类型生成、向量/材料类型初始化、独立材料保存和解析、结构域比较、复合特征、公开业务比较结果、普通宿主引用、深层输入路由、跨进程业务重试。现有强类型变体保留；未支持分支返回具名能力缺失，不按编码大小猜类型，也不返回空成功。

## 3. 依赖注入、初始化及来源

`特征类数据服务` 构造仅接收同实例 L1 只读服务、移交的唯一 L1 写端口、同实例值服务，以及已经存在的真实输入生产者节点。端口必须由合法装配方新建并专属交付本类，或是本类原分区的合法重新签发；不能把任意现存端口交给本类，更不能从“幂等键1未找到”推断分区为空或可任用。重入必须核对本类首次规范化初始化请求、首次结果和已交付端口来源同一性；缺该装配前置则拒绝初始化，不试图全仓扫描认领。`绑定于` 校验同实例，不能冒充以上来源证明。

此为装配依赖，不进入五字段或普通操作参数。服务实例只接收该生产者送入的数据；不得把内部服务节点、特征节点自指或默认节点冒充真实外设来源。构造/初始化及每次写入均读回来源当前有效；真实性由合法调用者保证，L1 节点存在只证明结构，不证明业务真实性。

定义和信息是不同强类型身份及逻辑角色；本计划只复用一个内部技术分区，不新定义领域 owner、节点族身份或权限。信息通过自己的固定字段属性类型识别，类型通过自己的规格载荷识别，不借宿主是否存在区别二者。

初始化在该端口的专属幂等键 `1` 中一次建立下节固定属性类型/关系类型节点。已有初始化首次写入材料时，精确读回其完整请求、结果映射和当前类型节点；只恢复本类已冻结结构，不能采用其它 owner 的初始化记录。初始化记录就是 L1 原有首次写入材料，不另建初始化账/结构根。普通写入键为本次新鲜 `G0+1`，要求不等于 1、可表示且本类唯一串行提交；同一次调用重试保持原键及完整写集。G0/owner/幂等均只在内部，不进入数据对象或普通 API。

不提供默认设备规格。先天 I64 类型初始化要求显式真实外设提供者、量纲/单位节点、正有理缩放、有限允许闭区间集合、非负同量纲允许误差和真实误差参数来源。来源/单位节点可以跨分区，以正式关系引用。所有身份必须读回；数据服务不凭名称/向量长度推出这些含义。

本首段登记唯一明确规则：有序 I64、无单位转换、闭区间比较；候选区间为 `[准确代表-允许误差, 准确代表+允许误差]`。两次算术须安全可表示，完整区间须属于类型允许集合，否则拒绝；不裁剪、不饱和、不默认零误差。不支持的表示、后天来源或规则不能进入本首段正式类型。

## 4. DTO 与公开函数

既有 `特征信息` 五逻辑字段及值域项封闭结构原样保持。结果采用 `template<class T> using 特征数据结果 = std::variant<T, 特征数据错误>`，有标签分支直接区分完整成功值和无值错误；不新增公共状态/optional包装字段。无数据变更成功使用 `std::monostate`。`enum class 特征数据错误` 的分支固定为：`未找到、未设置、入口拒绝、类型不相容、能力未提供、规则缺失、引用冲突、算术不可表示、并发变化、资源失败、内部不一致、发布结果未确认、前次写入待收敛`。不公开技术回执，不以 variant 默认构造冒充成功。

类型规格 DTO：`先天I64特征类型规格 {稳定编码 外设提供者; 稳定编码 单位; uint64_t 缩放分子; uint64_t 缩放分母; vector<特征I64闭区间> 允许集合; int64_t 允许误差; 稳定编码 误差参数来源;}`。这些是 4120 已确认的类型解释，不扩充特征信息。`先天I64特征类型信息 {特征类型身份 身份; 先天I64特征类型规格 规格; 特征比较规则身份 规则;}` 为类型读取结果。

## 5. 封闭 L1 映射

初始化只创建以下固定通用属性类型/关系类型；编码全部来自 L1 新编码映射，不硬编码稳定身份。初始化写集本地键1—5依次为类型规格(U64组)、规则误差(I64)、准确当前值(I64)、历史集合(U64组)、值域集合(U64组)五个属性类型节点；本地键6—11依次为类型→外设来源、类型→单位、类型→域规则、域规则→参数来源、信息→类型、细分父→子六个关系类型节点。所有普通单值关系角色固定0，仅细分关系角色为局部域键。编码值不是业务特征类型总枚举。

| 逻辑位置 | 物理承载 |
| --- | --- |
| 类型定义 | 普通节点；类型规格属性为 U64 组，固定编码 `缩放分子,缩放分母,允许区间数,(下界位型,上界位型)*`。先天/I64/有序/无转换为本专用合同的固定解释，不重复存可漂移标签。 |
| 类型来源与单位 | 三种具名关系：类型→外设提供者、类型→单位、类型→域规则。每种恰一。 |
| 域规则 | 普通节点；规则误差属性为 I64；规则→误差参数来源恰一。规则类型由固定误差属性及类型绑定成立，不以任意非零节点冒充。该规则同时固定上节闭区间比较及形成方式，不宣称公开 4180 比较服务。 |
| 特征信息身份 | 普通节点；始终保有历史和值域两个字段槽（空集合也写入），据此确认信息角色。没有族归属、宿主或伪类型标志关系。 |
| 特征类型字段 | 信息→类型定义的具名关系；完整对象恰一，可由字段操作移除；其余字段仍可按节点读取。 |
| 准确当前值 | 信息节点的专用 I64 属性；槽缺失表示未设置，不把 0 当缺失。 |
| 历史集合 | 专用 U64 组属性：`成员数,(标签,载荷)*`；标签 0=I64 完整位型，1=本节点域项局部键；不得出现多余尾数据。 |
| 值域集合 | 专用 U64 组属性：`域数,(局部键,代表I64位型,下界位型,上界位型,次数)*`，按局部键升序；首段没有结构引用，不能把 U64 组解释为任意扩展包。 |
| 细分生成关系 | 独立具名关系类型，父→子，角色为父域局部键；子初始继承域使用相同局部键和完整定义。本地键仍以各自节点为作用域，不另存父指针/子列表/继承bool。 |

I64 位型以 `std::bit_cast` 完整保存，不能通过实现定义有符号转换丢失极值。解码检查计数乘加溢出、准确长度、允许标签、键非零/唯一、闭区间、计数及引用相容。内部 codec/工作副本可以有可选字段，但不得导出新的业务字段或技术头。

域局部键分配不用事实代次、时间、全历史扫描或额外水位：首次创建信息时取其已发布类型节点稳定编码的数值；已有信息新增/改义域取当前必存值域字段载荷的 L1 值事实稳定编码数值。每个父每次操作最多一个新域，且任何域变更必形成另一不可变载荷。L1 全局编码永久不复用，所以被删域键也不再出现。继承子沿用父键；它不可能与该子将来的载荷编码相撞。该数字只投影为 `特征值域项标识`，不能凭其数字作为类型或值身份回读。关系角色需可由 I64 表示，超出时返回资源/可表示性失败，不回绕。

## 6. 数据操作和自动处理

所有写操作先读完整受影响结构和类型规则到同一 G0，形成私有副本，校验后只提交一个 L1 写集。改字段以新不可变值替换旧槽，旧值退出与新关系/节点共同提交。完整读取缺类型或当前值返回 `未设置`，字段读取仍可得到其它合法内容。

1. 创建信息和接收观察值：解析/取得准确 I64，检查类型允许域；更新当前准确值。逐一对全部既有闭区间判定，命中各计一次且检查溢出。零命中按本类型规则建立一个新域，首次计 1；不能形成合法区间则整次拒绝。
2. 历史按完整整数精确去重。当前输入被本节点命中次数≥3的域覆盖时不增加具体项；每个新稳定域加入一次域引用，移除其覆盖的具体项。当前准确值永不由域代替。
3. 普通域满3且没有生成子时，在同一写集建立同类型子：准确值为触发输入、历史先为该输入、继承域保留代表/范围且本地计数0；同时建立父域→子的正式生成关系。父域保留。不在本次递归输入新子。
4. 从已存在直接父生成关系与相同局部键/完整域定义识别继承域；本地满3可简化历史但不能再次生成同域孙节点。新域的代表与范围均等于继承域时也按继承域对待，不能换键绕过。
5. 手工添加域为次数0，代表必须在范围内、范围须属于类型允许集合；手工增改不伪造观察。代表/范围改义必分配新键、计数0；被历史域引用、生成关系或父继承关系占用的域明确拒绝改义/删除，不制造悬空引用。完全相同的改写为无变化成功。
6. 历史成员增改删除保持精确去重与本节点域引用有效；手工域引用仅允许已满3域。不允许删除本节点准确当前值的唯一具体历史项，除非已有稳定域概括它；不允许手工操作伪造域命中。
7. 类型改义须所有现有具体值、域与新类型相容；有细分父/子关系则拒绝跨类型修改/移除，避免改一端破坏同类型链。无细分关系时可以移除类型，节点保留；再次设置按全字段检查。整对象修改是该类型修改与接收新观察的一次组合，不接受调用方覆盖命中次数。
8. 准确值移除只退出当前值槽，不删除历史/域。删除信息退出其自有字段值和类型关系，再退出节点；存在细分或外部合法引用时拒绝，不隐式级联删除其它节点。L1 检出未枚举的外部引用时保持引用冲突，不能扩大删除范围。
9. 查询按正式类型关系召回全部节点并固定同截止逐项读回，整数内容精确匹配；多个同值节点全部返回，按稳定编码排序，不新增唯一性规则。缺当前值节点不匹配；损坏或漂移不悄悄漏掉候选。

细分关系由本首段自动过程创建、按节点独立读取；任意手工重接/删除生成来源涉及继承域和终身防重复的迁移合同，不在本首段成功面，不能伪造已完成该关系全部独立 CRUD。后续仅在原目标内冻结安全迁移合同后补齐；不为保存此缺口登记下游计划。

## 7. 失败、收敛与完成声明

读入不支持、缺规则、范围非法、算术溢出等在提交前拒绝且零写。并发 G0 变化返回 `并发变化`，不混代、不忙循环补算。内存分配异常返回资源错误。

不能把 L1 所有资源/内部错误都说成零发布：当前单 owner 仓库可能已完成内部交换而在外层映射分配时失败。服务只保留一份瞬时待确认的完整写集、原键及预期操作结果，不建持久账。遇到不能证明未发布的提交结果，读取本端口首次写入材料并核对完整规范请求和首次成功映射；必要时仅重放原写集。原首次材料只证明原发布及其稳定身份；然后零守卫选择新的原子当前截止 G，固定 G 读回受影响字段、关系和节点，逐项等于原请求/映射预期才返回成功。不能要求世界仍停在首次提交 G1，否则其它分区推进代次会永久阻塞读回。pending 期间本分区没有后续写，外部分区不能改写这些自有字段；发现真实不一致必须保留失败而非解释成正常漂移。初始化重入同样用首次映射与当前截止核对结构类型节点，不强求初始化代次仍为当前。

仍不可确认时返回 `发布结果未确认` 且无成功载荷，保留原请求并拒绝新的写操作；`收敛待确认写入()` 只处理该原请求，确认后解除阻塞。该入口不重新分配键、不重复计数/建子；读操作不产生观察。不存在 pending 时该管理入口无变化成功。进程退出会丢失瞬时调用上下文，本首段不宣称跨进程业务调用去重或恢复闭环。

实现完成条件：全部上列首段成功入口含真实 L1 操作；没有仅修改 DTO 副本的假 CRUD；公开五/三字段清单未扩充；缺类型与材料路径明确拒绝；未决提交不会被新写覆盖。代码完成不等于运行能力证明。
