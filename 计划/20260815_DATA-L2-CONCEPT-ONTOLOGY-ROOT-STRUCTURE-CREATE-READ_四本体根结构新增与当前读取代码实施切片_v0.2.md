4. 每根首次写集原子包含概念节点、族归属、根角色和首次请求见证，正式读取证明直接上位为空；

6. 根工程 Debug / Release 构建、风险相称生产外临时检查和静态边界通过；
7. 临时检查三件套在最终结果前删除，正式代码与生产工程零检查专用逻辑；
8. 实际变更、实际检查和 `NOT_RUN` 写入永久施工 / 检查记录，但不形成独立验收结论。

本计划不以概念聚合、普通应用装配、BIZ 编译或阶段 18 为完成条件。

## 5. 目标函数、DTO 与物理位置

### 5.1 正式前置头

`L2结构公共.数据.h` 必须保持公共身份结果的正式 blob；`L2概念结构.数据.h` 必须来自 C0 正式结果。本叶只读 import / include，不修改、复制或补丁式扩展两个头。

若任一前置 ABI 不足以承载详细设计，不得在服务模块中定义兼容结构，固定对应 DRIFT 并停止。

### 5.2 概念服务模块

新 `服务.L2概念结构.ixx` 是概念 owner 和三项 C1 能力的唯一命名模块所有者，模块名固定：

```cpp
export module 海中鱼巣.领域.服务.L2概念结构;
```

导出函数和类：

```cpp
尝试形成L2概念所有者交付
L2概念结构服务::L2概念结构服务
L2概念结构服务::建立概念本体根
L2概念结构服务::按角色读取当前概念本体根
L2概念结构服务::读取全部当前概念本体根
```

私有辅助必须留在本模块的非导出命名空间或类私有段，不新建 `.h/.cpp` 实现对或独立 `.inl`。

服务私有持有 `std::mutex 概念本体根写入锁_`；建立入口在锁内完成全组预读、身份 / 角色裁决和至多一次 L1 提交。模块私有 `是概念保留登记幂等身份` 独占两项登记值判断，禁止在公开数据头复制私有常量或增加公开运算符。

### 5.3 工程登记

- `L2概念结构.数据.h` 以唯一 `ClInclude` 登记；
- `服务.L2概念结构.ixx` 以唯一 `ClCompile` / C++ module 登记；
- filters 与工程项一一对应；
- 四配置继续保留 `/utf-8`；
- 不登记临时检查程序到生产工程。

## 6. 实施顺序

1. 在 C0 结果退出、临时探针清理和 EVENT 工程所有权释放后，从最新正式 HEAD 重新 S0，固定前置结果、目标文件、index、所有权和构建资源。
2. 只读核对公共身份的概念相关 ABI 子集与 C0 DTO；其它已退出身份闭合计划的尾部追加不构成漂移，任何概念字段 / 数值 / helper 改义仍具名停工；不修改两个前置头。
3. 实现 move-only 概念 owner 交付、两份固定私有登记和唯一概念根写入锁。
4. 实现一次 L1 关系类型闭包的全组读取核心：请求显式选择概念 owner，并在同截止读取 owner、根角色、族归属、首次见证和根作为目标端的直接上位空组；再实现按角色读取，同代缺失固定映射内部不一致。
5. 实现建立入口的当前守卫预读、全组首次身份冲突优先级、陈旧守卫原请求单次提交和 L1 首次结果历史读回。成功 / 精确重复后必须先经概念写端口读取首次写入材料，逐字段互证首次规范化完整写集与首次写入结果，再核对四项新编码映射并用固定首次截止的 owner-aware 历史事实 / 历史目标关系空组重建首次结果；不得虚构属性槽第五映射，也不得以首次旧代次发起当前闭包读取。
6. 在 EVENT 最新正式工程内容上增加 C0 头与 C1 模块唯一登记并完成编译接入，不覆盖或删除其它工程项。
7. 建立临时生产外检查三件套，运行实际选择的风险矩阵并记录结构化结果。
8. 删除临时三件套，复核生产工程零引用、生产源码零检查专用逻辑。
9. 更新永久施工 / 检查记录，只提交白名单五文件；普通推送后回读提交与远端。

任一步发现 L1 闭包无法在一次许可内返回根角色入口、族归属、首次见证和直接上位空组，固定 `DRIFT-CONCEPT-ROOT-L1-CLOSURE-SHAPE` 并停止，不得改成多次零守卫拼接或增加 L1 / 生产 seam。

## 7. 失败收口

- 纯代码、编译或临时检查错误：在本计划白名单内修复并重跑受影响门禁。
- 环境或构建输出冲突：保留现场，释放受影响资源后再从最新 HEAD 核对；不改设计。
- 当前 BIZ 仍写旧枚举数值：记录下游机械匹配门禁，不修改 BIZ，不阻断本 C1 独立模块施工。
- 4240、L1 闭包、owner 交付或节点族合同发生实质变化：停止并退回计划支撑。
- 发布后结果未知：保留本切片提交 / index，不 force、不 reset、不 rebase；先只读核对远端再决定普通重试。
