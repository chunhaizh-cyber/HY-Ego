## 1. 目标、裁决和完成边界

实现一个真正能够调用求值函数、逐步枚举数值输入并形成细分区域的纯值算法提供者，供后续模拟世界学习消费。它不是模拟世界、学习线程或方法知识发布器。

用户已要求开始实现模拟学习；本叶落实当前已经明确的数值算法：有限 I64 闭区间、多输入三点网格、四分位置补测、逐轴精确线性判等、有偏差时二分、完整输入去重以及可逐步暂停续接。用户后续裁决优先：当前区域发现偏差后，沿第一偏差轴二分；每个子区域重新判断，若没有新偏差则补测后结束。步长 1 是最小可分辨粒度，不是首次发现非线性后强制全域穷举到 1。

模拟所得方法配对将来应为全新配对，命中初值为 0；命中增加属于现实使用后的结果确认，本叶完全不读写计数。数值算法只产生值式样例和区域，不能据此声明已经生成方法条件—结果节点。

## 4. 公开 DTO 与签名

全部实体在 `海中鱼巣` 命名空间，唯一声明位于新头文件，非 inline 定义位于同名源文件。头文件只依赖标准库。以下是冻结合同，不是待实现骨架承诺。

```cpp

struct 数值模拟细分请求 final {
    std::vector<数值模拟输入区间> 输入区间组;
    std::size_t 输出维数 = 0;

enum class 数值模拟样例状态 : std::uint8_t {

    std::vector<std::int64_t> 输出值组;

using 数值模拟求值函数 = std::function<数值模拟样例结果(
    const std::vector<std::int64_t>& 输入值组)>;

    std::vector<std::int64_t> 输入值组;
```

值 DTO 可以提供默认 `operator==`，仅作值式相等，不新增其它语义。`std::size_t` 只表达实际容器数量，不是业务阈值或资源预算。没有节点身份、时间戳、合同版本或方法字段。

### 4.1 初始化和生命周期

1. 输入维数、输出维数均必须大于 0；每个区间满足下界不大于上界；端点均不得等于 `INT64_MIN` 或 `INT64_MAX`，这两值在项目中表示无穷哨兵，不作为有限区间参与插值；求值函数必须非空。不设置底层自选维数、区间长度、样例数上限。
2. 成功初始化创建独立运行期作业，复制请求和 callback；初始化不调用 callback。
3. 重复初始化是显式放弃旧作业并建立新作业：先校验并完整分配新实现，成功后替换。拒绝或分配失败不改变已有作业；返回初始化失败状态与旧作业进度分别解释。
4. 所有状态仅在对象生命周期内保存，不持久化、不恢复跨进程游标。析构释放材料，不调用 callback。
5. 同一对象由调用方串行使用；不同对象可独立运行。callback 只允许调用同一对象的两个读取入口，不得重入初始化或推进，也不得保留输入引用或修改本次样例的输入。算法不持有世界锁，不自建工作线程。读取只返回已经保存的材料，不提前反映正在求值的输入。
6. 暂停就是停止调用 `推进()`，续接是对同一对象再次调用；不设超时，不依赖定时器，不把暂停当完成。调用方须保证 callback 在各次调用之间语义保持不变。

`正在推进_` 是类本体上的进程内防重入保护，不能只放在可能被重新初始化释放的 PImpl 中。外层 `推进()` 进入后以 RAII 保证全部返回路径复位；callback 期间重入 `初始化` 或 `推进` 返回 `输入不合法`，不修改外层作业、不替换 PImpl、不把外层作业锁为失败。读取入口允许同线程重入。该保护不是多线程同步承诺，也不允许 callback 析构其正在执行的细分器。

### 4.2 求值合同

每个完整输入向量只能首次遇到时调用 callback。callback 必须先恢复同一基准初始状态，再应用该完整输入并实际求值；不能让上一样例的变化串入下一样例。纯函数天然满足这一合同。算法本身不创建模拟世界，也不能验证外层是否违反恢复承诺，后续模拟 owner 必须提供相应隔离实现。

成功输出长度必须严格等于请求的输出维数，所有输出分量也不得等于 `INT64_MIN` 或 `INT64_MAX`。非成功状态、错误维数、输出无穷哨兵或异常均终止当前作业而不是当作零值、无变化或线性。无穷输出映射 `输出包含无穷哨兵`；callback 的失败状态通过 `求值失败状态` 送出；`std::bad_alloc` 映射资源失败，其它异常映射求值抛异常。失败后 `推进()` 不自动重试 callback，也不继续采样，必须显式重新初始化才开始新作业。

## 5. 采样、判等和细分算法

### 5.1 安全整数坐标

采用保序 rank：`rank(x) = bit_cast<uint64_t>(x) XOR (1ULL << 63)`，逆变换同理。坐标比较与差值在无符号 rank 空间进行。

对 `a <= b`，中点 rank 为 `rank(a) + (rank(b)-rank(a))/2`，再转回 I64。禁止直接计算有符号 `b-a`、`a+b` 或以浮点生成中点。相邻整数由 rank 差为 1 判断；单点差为 0。

### 5.2 工作区域与流式网格

初始工作区域为请求的闭区间直积。按轴输入顺序稳定处理，区间端点顺序递增。

1. 每轴构造去重递增的三点集合 `{下界, 中点, 上界}`。单点仅一个，相邻点仅两个。
2. 用混合基数坐标游标流式枚举各轴三点集合的笛卡尔积；最后一轴最快变化。禁止先求乘积容量或一次建立所有坐标向量。
3. 全部三点样例合法取得后，对每个轴、固定其它轴的每种网格坐标，检查其左端/中点/右端沿该轴是否精确共线。任一输出分量非线性即该轴有偏差。
4. 无论三点阶段是否已有偏差，均补足该区域的一轮五点网格：每轴在左半段、右半段各取一个中点，去重后与原三点集合合并。仍流式枚举**完整五点网格的全部组合**；整输入缓存避免重算三点组合。不能只在其它轴旧三点位置补测而漏掉多轴交互。本叶补测密度固定为这一轮，不新增可调密度参数。
5. 在五点网格上，固定其它轴的每一种五点组合，分别检查该轴整个区间的原中点，以及左右子段的补测中点。没有严格内点的线段无需检查。
6. 偏差轴集合为本区域三点检查与五点检查的并集。没有偏差时将整个区域加入完成区域组；含义只是“本轮完整采样未发现轴向线性偏差”，不证明所有未采样整数都线性。
7. 有偏差时选择输入轴序最小的偏差轴；其区间必有严格内点。沿中点分成 `[a,m]`、`[m,b]` 两个子区域，先左后右深度优先处理，其它轴区间不变。每次只生成两个子区域，不一次物化 `2^N` 个区域。
8. 子区域重新执行本节，不继承“强制细分到 1”标记。没有新偏差、补测也一致则结束该子区域；仍有偏差才继续细分。每次分割严格缩小选定轴的 rank 宽度，不能切分单点或相邻整数。
9. 共享分界点允许同时属于两个闭区域，缓存确保其完整输入只求值一次。所有区域处理完毕才是整个作业已完成；任何缺失、失败、未知样例均不能进入完成判定。

逐轴检查接受例如 `f(x,y)=x*y` 这样的多线性关系，并不要求联合仿射 `Ax+b`。本叶不把多线性称为已证明的全局线性，也不从有限网格推断连续物理规律。

### 5.3 精确有理数线性判断

沿一个轴有 `a < q < b`，某输出分量为 `Ya,Yq,Yb`，只在以下精确等式成立时认为采样点共线：

```text
(Yq - Ya) * (b - a) == (Yb - Ya) * (q - a)
```

输出差用“符号 + U64 绝对值”表示，最大绝对差为 `UINT64_MAX`；坐标距离用 rank 差表示。每侧是一个有符号 128 位积，比较零、符号、高低两个 U64 肢。U64 乘法使用 32 位分肢计算高低积，或同等已证明不溢出的内部实现；不依赖 MSVC 不支持的语言级 `__int128`，不引入第三方库。

不得用浮点误差阈值、先整除再比较、饱和 I64 差或溢出后取极值代替本节等式；这些做法会吞掉合法的非零偏差。128 位工具只作为源文件私有实现，不新增通用公共数学 ABI。每个输出分量分别判断，任一非零偏差即触发该轴细分。

### 5.4 去重、推进和读回

缓存键是有序完整 `vector<int64_t>`，不是某一轴取值、哈希摘要或前一输入。缓存保存成功输出，不保存未确认的默认输出。相邻区域、三点/补测网格和暂停续接共用同一作业内缓存。

`推进()` 每次最多调用一次 callback，可以只完成一个游标、检查或区域状态转换而不调用 callback；每次最多交付一个新样例、一个完成区域。内部应按单坐标/单轴线段检查组织可续接状态，不能一次 `推进()` 无界跑完整大网格。命中缓存时不返回为“本次新样例”。

缓存的推荐实现是 `map<vector<int64_t>, vector<int64_t>>`，自然提供完整输入字典序；DFS待处理区域用私有容器保存，先压右后压左。每次即使命中缓存，也只推进一个格点；每次判等只处理一个轴线段检查。不得在缓存全命中时改成一次吞掉整片网格，也不得预计算网格乘积作为分配容量。

推进过程中可返回部分值式材料，但状态严格为推进中；只有任务栈为空且当前区域已完全处理才返回已完成。终态再次推进返回原终态且不求值、不重复输出新样例或新区域。

`读取进度()` 返回当前状态与实际样例、完成区域数量，无分配、零 callback。`读取材料()` 按完整输入字典序返回样例副本，完成区域按实际完成顺序返回；必须完整复制或返回资源失败并清空两组，不截断成功。进行中/失败作业的材料仍可读作诊断性部分材料，其状态不改成已完成。读取失败不改变内部作业。

成功 callback 后若存储或返回材料分配失败，作业进入资源失败终态，禁止再次执行同一输入以猜补；不声称能够回滚 callback。外层应在后续新作业恢复初始状态，而不是自动重发真实动作。

## 6. 物理实现、诊断与失败边界

| 函数 | 物理位置/职责 | 诊断责任 |
| --- | --- | --- |
| `数值模拟细分器` 构造、析构 | 新头源，空实现与资源回收；不求值 | 无适用错误分支 |
| `初始化` | 新源，校验、独立候选实现、成功交换 | 向上送出；旧作业保持 |
| `推进` | 新源，唯一算法状态推进和 callback 调用 | 向上送出；失败终态不猜补 |
| `读取进度` | 新源，直接值式状态投影 | 无适用错误分支 |
| `读取材料` | 新源，完整值式复制 | 向上送出；失败不改变作业 |
| rank、中点、符号差、128位乘积/相等 | 新源匿名命名空间，纯计算 | 输入不变量下无适用错误分支 |
| 私有网格游标、区域判等、拆分和缓存推进 | 新源 PImpl，运行期非权威材料 | 向 `推进` 送出 |

算法不记录生产日志，不弹窗、不停止工程，不包含基础数据集或世界服务头文件。最终调用者后续消费结构化错误并承担日志责任；本叶没有生产调用者，不能为了诊断接入 self 或模拟线程。

有限输入直积理论上有限，但样例和区域数可能极大。不得加隐式上限后返回完成；分配失败明确资源失败，调用者主动暂停保持未完成。本叶不承诺大维数或全 I64 非线性域能够在现实资源内全部完成。

### 7.1 静态验收矩阵

| 项目 | 必须检查的合同 |
| --- | --- |
| 单点/相邻点/奇数宽度 | 无重复坐标，无空分割，mid严格有界 |
| I64两极 | MIN/MAX输入端点拒绝、输出哨兵失败；合法近两极仍使用rank差U64、输出差符号绝对值、128位乘积，绝无有符号溢出 |
| 线性与多输出 | 每输出分量精确比较，不用平均抵消 |
| 中点恰线性但四分偏差 | 完整五点补测能够触发继续细分 |
| 多输入交互 | 完整补测笛卡尔，固定其它坐标逐轴检查；多线性边界明确 |
| 分区 | 每次最小轴号二分，子区间重新判断，不继承全域穷举标记 |
| 去重 | 完整输入为键，同一作业callback最多一次，边界共享不重算 |
| 暂停/续接 | 每次最多一个求值，无隐式完成，终态零重试 |
| 失败 | 未知/求值失败/异常/输出维错/资源失败均不当作线性成功 |
| 世界隔离 | 新源不依赖世界/方法/数据服务，零真实端口、零外设、零事实写入 |

### 7.2 运行边界

本叶没有实际项目内获准的算法运行入口，因此所有算法行为运行验证明确 `NOT_RUN`。不得另建临时项目、手工链接临时 exe、通过调试器调用业务写函数或修改内存制造通过。编译、链接成功不等于数值结果正确或运行测试通过。

后续实际项目测试入口经用户具名确认后，应覆盖：`x`、`2x+1`、`x*x`、中点掩蔽的局部非线性、`x*y`、只一输出分量非线性、I64近两极合法区间恒等与常数、MIN/MAX端点及输出哨兵拒绝、非整比例、完整输入去重、逐步暂停、失败/异常/输出维错。它们是后续运行验证清单，不是本叶自动授权的测试程序。

## 8. 剩余路线与发布边界

本叶完成后仍需要独立设计、用户裁决和真实验证：

- 模拟世界独立根、源信息单向复制与共享概念写隔离。
- 参数规格到合法初始样例的生成策略及每个样例的状态恢复。
- 同一本能函数通过参数场景进入模拟端口，未支持方法明确拒绝而不回落现实。
- 模拟任务虚拟存在强身份、实际结果独立读回及方法私有精确值域承载。
- 新方法配对完整原子发布、初始命中 0、self 到学习线程的异步消息和结果回流。
- 现实世界的命中增加链，明确不属于模拟世界的职责。

这些仅保留路线输入，不登记远端待激活计划，也不把算法 callback 当作已实现的模拟 owner。施工记录列出完整函数知识增量、静态证据、实际工程构建结果及全部 NOT_RUN。

发布只包含本叶新头源、工程精确新增项与专属证据；不能带入旧消费者 WIP。若工程增量可与主线既有WIP分离，按实际差异精确发布；不能安全分离时保留代码现场并报告，不能整体提交旧项目文件。本计划发布和索引登记由主线串行完成，计划子智能体不自行暂存、提交或推送。
