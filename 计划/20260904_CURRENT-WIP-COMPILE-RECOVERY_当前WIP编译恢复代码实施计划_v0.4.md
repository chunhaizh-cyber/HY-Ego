## 1. 目标与执行前提

不保证运行逻辑。执行者不得重新解释为 v1/v2 ABI 迁移，不得恢复旧筹办或 E2E。

执行前完整读取统一占用登记，并逐项取得下列路径的唯一写入权。`创建.自我线程.ixx` 和
`自我线程生产创建.数据.h` 的既有 `/root` WIP 必须先取得明确交接；后者不在允许写集，
只能保留。不能安全交接时停止受影响文件，不覆盖现场。

## 2. 精确施工步骤

1. 新建 `海中鱼巣/业务/合同.自我世界树根消费.ixx`，精确实施详细设计 §3.2；项目和 filters
   各加一条该 source 的登记。
2. 在真实自我 provider 与自我线程创建模块用该 contract import 替代普通应用 import；不改任何
   `.数据.h`。将真实自我 provider 收缩成详细设计 §3.3 的非成功、零副作用空壳。
3. 在启动模块按详细设计 §3.4 删除普通应用使用链，保留同签名的明确失败 `运行普通程序`。
4. 删除 `海中鱼巣/装配.普通应用.ixx`，并从项目和 filters 各精确删除一条登记。不得触碰根目录
   未跟踪同名副本。
5. 核对旧筹办 module/type 在任务管理线程、运行包和全工程为零；不恢复或构造兼容壳。仅在
   MSVC 实际报 C4715 时，为 L2 任务服务的指定函数追加详细设计 §3.5 的 final non-success return。
6. 对第一个剩余编译错误，先将完整诊断、文件和引用写入施工记录：只有已删除 module 的直接
   import/调用可删除，或已有返回类型可构造明确非成功零副作用值时才在该同一函数内修复；否则
   停止并退回计划支撑，不扩张文件集合。
