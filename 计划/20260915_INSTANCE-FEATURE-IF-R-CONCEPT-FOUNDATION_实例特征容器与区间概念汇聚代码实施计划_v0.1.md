状态：待激活。基线：`bdb66d35f04cf60c8065fbe021bbc4a4ac10e653`。4115 v0.7 已取消 R变化自动概念汇聚；本计划仍缺可施工的公开 ABI 详细合同，必须由计划支撑修订后重新 S0。

## 目标、已保留现场与唯一门禁

目标仍是实现4115的 `IF(E,FT)`、F成员、R集合版本及 I64精确分组；不改变当前采用语义，也不实现概念继续抽象。`ea195241` 已发布 I64 范围内的四 owner 原子准确 F 出生：FCv 先行发布，特征、存在、场景、概念四个 owner 同次发布 F内容、holder已知F、P→F 与 F→FCv 使用引用，并可按原键完整读回。它是本计划可复用的既有提供者，不再构成门禁。

4115 已冻结 IF/R 的 L2 读取、目标写入、预算、预期快照、规范化R项组、幂等、原子发布和读回边界，并明确当前采用不参与R归组。`FEATURE-TYPE-R-VERSION-FCR-MERGE-PROVIDER` 的已发布只读 ABI 不再是本计划依赖：4115已取消 R变化后的自动概念汇聚，本计划不得调用其归并入口或写入 FCr/概念上下位。I64 仍严格相等；非I64未注册归组规则必须结构化返回未启用，不能伪造比较或概念结果。该合同不能由本计划以 L1 ABI 扩展、定位服务越权写概念关系、顺序补写名称/用途，或临时无 FC 的 F 代替。

## 已冻结的后续施工边界

1. 新的显式入口只属于 `特征概念应用服务`。它在任何 FCv 查询/建立、F定位或 IF/R 写前，以同一 `Gread/H` 读取 `E+FT` 的完整 IF/R；当前采用不是该入口的读取前置或输入。读取失败、事实代次漂移、预算不足、退出或不完整必须保留原具名结构化结果并零业务写，不能压缩成结构异常。
2. 成功读取后，IF/R均未找到表示首个 R；完整 IF/R 表示将候选值交给 FT R归组规则。IF/R半结构、空R项、缺区间材料、重复或多个命中 R项均为结构异常，并零 FCv、F、IF/R和当前采用写。L2存在类只提供中性 IF/R 读回、一次写集与引用/形状/预期快照核验；它不判断首个R、命中、形成新R或结构异常。若写前快照已改变，L2返回具名漂移或引用冲突，零本次写，不重新分类。
3. 结构异常由普通应用私有的 `noexcept` 诊断回调处理，经构造注入特征概念应用服务。回调只使用调用点已持有的最小身份与原因摘要，在所有 L3 mutex 和普通应用上下文锁释放后，尝试一次 `记录逻辑错误日志` 与同因摘要的调用线程 `MessageBoxW`；两者任一失败、异常或未显示均不改变已经固定的结构化结果、零写承诺或线程继续条件。不得启用既有全局容错宏、把日志/UI依赖放入L2，或建立全局诊断体系。该回调只保证尽力同步调用，不保证无窗口或非交互会话中的可见性。
4. 首个R或规则返回形成新R时，概念应用先取得 FCv，再调用既有四 owner 提供者建立/复用完整 F。唯一命中R时零F写入；两条路径都由L3向存在 owner 提交中性 IF/R 目标写集。R真实变化在本计划内只发布并读回 IF/R，不触发概念抽象。

## 允许与禁止范围

允许继续本计划原有的 `海中鱼巣/领域/数据服务.存在类.h`、`海中鱼巣/领域/数据服务.特征类.h/.cpp`、`海中鱼巣/业务/应用服务.特征概念类.h/.cpp` 与 `海中鱼巣/装配.普通应用.cpp` 切片，以及必要施工/验证记录。普通应用只持有定位服务、特征概念应用服务及私有诊断适配，不在装配时调用新入口、启动线程或进入阶段21。

本计划禁止实现或修改既有四 owner 出生提供者、L1 ABI、定位特征原子事务、特征类型规则持久结构、`.ixx`、F原地值、I64误差域/相邻合并、当前采用语义、任何概念继续抽象、线程、启动或阶段21。
