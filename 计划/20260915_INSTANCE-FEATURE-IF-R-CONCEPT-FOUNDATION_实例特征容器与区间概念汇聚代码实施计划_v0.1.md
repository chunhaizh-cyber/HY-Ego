## 目标与范围

实现4115的 IF(E,FT)、F成员、R集合版本、I64精确分组、R幂等汇聚及单值FC到上位FCr组织。允许：扩展 `海中鱼巣/领域/数据服务.存在类.h`、`海中鱼巣/领域/数据服务.概念树类.h/.cpp` 与 `海中鱼巣/业务/应用服务.特征概念类.h/.cpp`，以及必要的 `特征类` 窄只读/比较接口、项目 `.vcxproj/.filters` 登记、专属施工和验证记录。禁止：新建实例特征 owner 或第二写端口、`.ixx`、L1 ABI、F原地改值、I64误差域/相邻合并作为R、当前采用语义改变、线程、阶段21、非I64具体比较算法。

## 实施步骤

1. 在存在 owner 建立六种 IF/R 关系类型、结构类型、DTO、初始化、当前/历史读取、首次材料和退出保护；`(E,FT)`唯一，R集合以不可变版本表达实际变化。
2. 冻结 F 加入组合：概念类先查/建 FCv，定位 F 后由存在 owner 建立 IF成员；存在当前采用仅只读作比较基准。另提供仅供阶段21消费的`按存在持有特征变更并返回实际F`组合入口：它沿用存在类既有采用写语义，绝不改变其语义或由IF/R隐式写入。
3. 实现 I64 完整值相等的 R 选择：相同归当前R、不同新单值R；非I64比较提供者未启用时结构化失败零写。
4. 由概念 owner 实现 `(R集合,版本)`汇聚完成回执及读回；由特征概念应用服务执行幂等汇聚。无 FT 归并规则成功零上位写；有规则时复用概念树查重/建立/组织入口，使 FCr 成为 FCv 上位而不替换 F->FCv。
5. 接入工程，写专属施工记录 `施工记录/20260915_INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION_施工记录_v0.1.md` 与验证记录 `验证记录/20260915_INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION_验证记录_v0.1.md`。
