## 公开 L3 ABI

```cpp
struct 实例特征R处理预算 final {
  std::uint64_t F成员上限=0, R项上限=0, IFR关系上限=0,
                既有F映射上限=0;
  特征R规则读取预算 R规则预算;
};
enum class 实例特征R处理状态 : std::uint8_t {
  已发布且汇聚完成=1, 已发布且汇聚未完成=2, R未变化=3,
  读取IFR失败=4, 结构异常=5, 归组失败=6,
  既有F映射失败=7, 新F出生失败=8, 提交IFR失败=9, 入口拒绝=10
};
struct 处理存在特征R请求 final {
  std::uint32_t 版本=1; std::uint64_t G0=0; 稳定编码 E{};
  定位特征位置 位置; 特征类型身份 FT; std::int64_t 候选准确I64=0;
  L1所有者范围写入幂等身份 FCv概念键, IFR结构键;
  原子I64特征出生键 F出生键;
  原子I64特征候选读取预算 候选读取预算;
  原子I64特征组织读取预算 组织读取预算;
  原子I64特征概念读取预算 出生概念读取预算;
  概念树预算 FCv概念预算;
  实例特征R处理预算 预算;
};
struct 处理存在特征R结果 final {
  std::uint32_t 版本=1;
  实例特征R处理状态 状态=实例特征R处理状态::入口拒绝;
  std::uint64_t Gread=0, H=0;
  std::optional<实例特征IFR读取结果> 初始IFR读取, 出生后IFR读取;
  std::vector<存在已知准确特征读取结果> 既有F已知读取组;
  std::vector<原子I64特征出生读取结果> 既有F出生读回组;
  std::optional<特征R归组规则结果> 归组;
  std::optional<I64原子准确特征出生应用结果> 新F出生;
  std::optional<实例特征IFR提交结果> IFR提交;
  std::optional<特征R概念归并结果> 归并;
  处理存在特征R请求 原请求;
  bool 成功() const noexcept;
};
```

每个 optional 只在对应调用实际发生时承载该精确返回，未调用即为空；两个 vector 按 F 稳定编码前缀保存已实际完成的读取，不伪造后续结果。`原请求`始终回显。`成功()`仅接受前三种非失败状态；`已发布且汇聚未完成`仍证明 IFR 已发布，不证明汇聚完成。

## 顺序与失败回显

初始 IFR 非成功为`读取IFR失败`并保留 `初始IFR读取`。`未找到`后同 G0 确认 E 身份且 L2 首建门禁读回 E→IF 空才可继续，否则`结构异常`。对既有 F 逐个同截止读取类型/创建H，再按创建H 调用原子出生读取核验 FCv；类型、创建H、FCv、预算或任一读回失败为`既有F映射失败`，零提交/归并。

归组失败为`归组失败`；新F出生失败为`新F出生失败`。新F出生成功后，以其 Gread 重读 IFR，成功投影是 L2 提交唯一预期；重读失败为`读取IFR失败`。L2 任一非成功为`提交IFR失败`。成功但 R 未变为`R未变化`；R 真变化只归并一次，I64零输出为`已发布且汇聚完成`，其余归并结果为`已发布且汇聚未完成`。

最终 IF成员为前态成员加已确认新 F，旧成员不得丢失。L3 只接受/构造 L2 v0.2 的六类 role 与 R项自来源 U64材料；偏离为`结构异常`、零提交。
