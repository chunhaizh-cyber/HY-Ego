## 1. 目标、范围与完成条件

在 S-ID 最终场景 owner、身份来源和现有 CRUD 真实结果上，原位扩展唯一 `L2场景结构服务`，实现一个底座多棵具名树、每树恰一当前根、每个树内场景恰一树归属、根无父、非根恰一同树父及当前 / 历史完整读回。

完成必须同时成立：

1. `L2场景树身份` 只包装根场景稳定编码，不建立独立节点族、新 owner、第七世界服务或世界登记；
2. 场景 owner 内的树登记锚点、根标记类型和树归属类型固定登记并 owner-aware 读回；
3. 根场景节点、场景族归属和根标记在一笔 owner-scoped 写集中原子建立；
4. 非根场景节点、场景族归属、树归属和直接父关系在一笔写集中原子建立；
5. 删除裸场景创建和可破坏单父不变量的父关系单独新增 / 退出入口，R1 后无公开路径产生新未登记场景；
6. 树归属和整树当前 / 历史读取逐项互证 owner、登记、类型、端点、角色、生命周期和同一截止；
7. 父子替换只允许同树非根，跨树和根作子端拒绝且零变化；
8. 根普通退出固定拒绝，非根只有叶节点可按完整闭包退出，旧裸场景不得自动认领；
9. A1 零写聚合和六服务数量不变，自我初始化不在本叶；
10. 根工程双配置、专项双配置、strict、范围和临时源码清理全部按实际结果记录。

## 6. 固定登记与原子写集

固定幂等身份和本地键逐项采用详细设计第 5 节，不得在 S0 临场换域。构造期只以 `L2场景树结构登记固定幂等身份` 建立一个不可变树登记锚点和两个 L1 正式关系类型身份节点，同场景 owner、编码互异、无场景族归属；三者物理种类固定为 `节点种类::普通` 且无属性类型表示，但两种类型身份必须由正式登记角色证明，不能当作公开普通场景。首次 / 精确重复都从 owner-aware 入口读回。

根请求写集恰为：

```text
1 场景节点 + 1 场景族归属 + 1 根标记
0 值 + 0 属性槽 + 0 退出
```

非根请求写集恰为：

```text
1 场景节点 + 1 场景族归属 + 1 树归属 + 1 直接父关系
0 值 + 0 属性槽 + 0 退出
```

根标记为根场景到登记锚点，树归属为非根场景到根场景，角色均为 1；根不建立自指树归属。非根提交前以同一期望代次证明树根和直接父当前、同树，提交后独立读回四项。两个业务创建入口直接使用请求 `L2结构幂等身份.值`，与全部场景 CRUD 共享同一个场景 owner 全局幂等身份域，不增加操作域或第二账；任意不同完整请求复用同值固定幂等冲突。固定登记身份是保留值，业务请求命中即入口拒绝。首次 / 重复、映射数量、owner、类型、端点、角色和创建代次任一不符均内部不一致。

## 7. 读取、既有 CRUD 与退出

`读取场景树归属` 当前 / 历史只接受根标记或树归属二选一；根标记目标必须是登记锚点，树归属目标必须是当前 / 截止时合法根。全部证据共享截止。旧裸场景返回入口拒绝，不按无父、名称、本地键或缓存认领。

`读取场景树` 按具名树身份读取根、全部指向根的树归属、场景来源、完整场景和父子关系；验证根无父、非根恰一父、父子同树、全成员从根可达、无环且无跨树边。当前 / 历史都返回稳定排序完整投影，任一缺项不返回部分载荷。

父子替换在同一期望代次读取旧父、新父、子三方树归属，三者树身份必须相等且子非根。属性和成员写要求场景已有合法树归属；存在身份和成员关系不决定树归属。

场景退出：根固定引用冲突；已登记非根必须为叶，显式闭合树归属、直接父、场景族归属、成员、属性、值和节点；旧裸场景全部公开入口拒绝，读取 / 清退另立 legacy 退役合同。外部引用冲突零变化，历史保留。R1 不实现整树退出、递归级联或物理回收。

## 8. 状态、幂等、并发与异常

纯值非法、保留幂等身份、跨树、根作子端、旧裸场景写入固定入口拒绝；目标未找到 / 已退出、旧期望、同键异义、引用冲突、许可、资源和内部矛盾按共同状态分账。非成功空载荷且提交前零变化。

同键同完整请求返回首次完整结果，不推进代次；同键异义冲突。发布结果未知只允许原幂等身份、原完整请求重提。登记锁只保护完整登记定位复制，不持锁跨 L1 / E-ID；公开写继续由场景 owner 端口串行化。`bad_alloc / length_error` 映射资源失败，其它未处理异常映射内部不一致。
