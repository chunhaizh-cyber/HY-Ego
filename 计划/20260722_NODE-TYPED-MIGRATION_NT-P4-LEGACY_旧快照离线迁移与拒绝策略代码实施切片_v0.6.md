## 1. 完整公开 DTO 与 ABI

以下枚举底层类型均为 `std::uint16_t`，数值不可重排：

```cpp
enum class 旧快照来源类型 : std::uint16_t {
    未知 = 0,
    权威四仓内存聚合 = 1,
    恢复布尔评估 = 2,
    特征值局部材料 = 3,
    原始字节流 = 4
};
enum class 旧格式识别码 : std::uint16_t {
    当前格式 = 1,
    已登记旧格式 = 2,
    未知 = 3,
    损坏 = 4
};
enum class 旧快照迁移拒绝码 : std::uint16_t {
    支持集合为空 = 1,
    未知版本 = 2,
    布局证据不足 = 3,
    字段不可唯一映射 = 4,
    历史不完整 = 5,
    跨段事实不完整 = 6
};
enum class 旧快照迁移状态 : std::uint16_t {
    已形成 = 1,
    材料拒绝 = 2,
    资源失败 = 3,
    内部不一致 = 4
};
enum class 旧字段映射结论 : std::uint16_t {
    已唯一映射 = 1,
    缺少来源字段 = 2,
    来源语义歧义 = 3,
    历史证据不足 = 4,
    跨段证据不足 = 5
};
```

| 类型 | 精确字段顺序 |

| `旧格式识别结果` | `旧格式识别码 识别码; std::optional<旧格式版本身份> 版本身份; std::optional<旧快照迁移拒绝码> 拒绝码; std::array<std::uint8_t,32> 输入摘要` |

| `旧快照迁移报告` | `旧快照来源类型 来源类型; std::uint64_t 输入长度; std::array<std::uint8_t,32> 输入摘要; 旧格式识别码 识别码; 旧快照迁移状态 迁移状态; std::optional<旧快照迁移拒绝码> 拒绝码; std::vector<旧字段映射项> 映射项组; bool 证据完整; std::vector<std::string> 人读证据组` |

`旧快照只读材料` 是可复制的非拥有借用视图；复制不延长底层字节生命周期。其它 DTO 自有其 vector / optional / 字节材料，按成员自然值语义复制或移动。三函数不得保存 `字节视图`，不得暴露文件句柄、生产仓库、写许可或可变引用。人读证据和 `证据完整` 不裁决迁移，只复述机器枚举、映射项、摘要和输出事实。


## 2. 识别优先级与结果形状

当前支持旧格式版本集合精确为 `{}`。识别顺序不可交换：

1. 来源枚举、`字节长度 == 字节视图.size()` 和标准 SHA-256 必须自洽；不自洽返回 `识别码=损坏`、`拒绝码=布局证据不足`、版本身份空。
2. 完整命中 `HZYCSNP2 / 容器版本2 / 段清单版本2` 返回 `识别码=当前格式`、拒绝码空、版本身份空；当前格式不得进入旧迁移。
3. 可识别当前格式头但存在截断、尾随、越界、整数溢出或头 / 长度损坏，返回 `识别码=损坏`、`拒绝码=布局证据不足`、版本身份空。
4. 其它材料因支持集合为空返回 `识别码=未知`、`拒绝码=支持集合为空`、版本身份空。

只有未来合同升版、支持集非空且精确命中已登记旧格式后，才允许 `识别码=已登记旧格式` 并形成 `旧格式版本身份`。当前任何输入都不得形成旧格式版本身份、字段映射成功组、当前格式输出或输出摘要。

## 3. 六拒绝码唯一映射

语义拒绝统一映射为：

| 叶子语义 | 唯一拒绝码 |
| --- | --- |
| 不是持久格式、缺少权威记录、缺少必需领域段 | `支持集合为空` |
| 未知魔数或未知版本 | `未知版本` |
| 截断、尾随、越界长度或整数溢出 | `布局证据不足` |
| 身份不可唯一、关系不可唯一、领域不可唯一 | `字段不可唯一映射` |
| 缺历史、失效关系或记录版本 | `历史不完整` |
| 缺任务 / 方法事实、概念签名或 4170 | `跨段事实不完整` |

该表冻结未来支持版本的唯一映射，不改变第 2 节当前空支持集优先级：当前集合为空时，`未知版本`、`字段不可唯一映射`、`历史不完整` 和 `跨段事实不完整` 的可解析旧布局夹具不可达。不得为了覆盖拒绝码而伪造旧格式头、记录布局、稳定身份、关系、领域记录、历史或 4170。

映射已证明完整但 #349 编码或 #350 严格恢复失败，只能返回 `状态=内部不一致` 且拒绝码空；资源分配失败返回 `状态=资源失败` 且拒绝码空。二者都不是兼容性拒绝。

## 4. 当前可达验证矩阵

专项源码自检必须机械证明：

- `HZYCSNP2 / 2 / 2` 精确材料只识别为当前格式，不进入迁移；
