# D455 可选 SDK 条件编译提供者代码实施计划

计划身份：`D455-CONDITIONAL-COMPILE-PROVIDER`

日期：2026-09-18
版本：v0.1
状态：已退出

## 1. 目标、范围与完成条件

使默认 `EnableD455RealSense=false` 的 x64 验证工程能够编译 `采集器.D455相机.cpp`，而不要求本机安装或暴露 RealSense SDK。真实 SDK 启用路径保持原有采集器实现；关闭路径不建立采集器、不写任何材料或世界事实。

完成条件：同一公开工厂 `创建并打开D455相机采集器(D455采集配置, D455操作结果&)` 在 SDK 关闭时可从干净翻译单元成功编译并确定地返回空指针和零材料结果；SDK 启用时才允许编译、包含并调用 `librealsense2/h/*`。本计划不接 D455 线程、外设、世界事实、D455 硬件验证或运行装配。

## 2. 正式依据与已验证事实

- 6350 v0.6 与 6340 明确 D455 是独立外设控制域，不能写世界事实；6350 既有设计确认 `EnableD455RealSense` 默认关闭，公开协议不得暴露 SDK 类型。
- 当前主工程已在 `EnableD455RealSense!=true` 时排除 D455 翻译单元；世界树根专项工程却仍编译该源文件。两工程都只在开关为 true 时注入 `HY_EGO_ENABLE_D455_REALSENSE`、SDK include/lib/DLL。
- 当前 `采集器.D455相机.cpp:6-10` 无条件包含五个 RealSense C API 头，故专项默认关闭仍报缺 `rs_context.h`。这是构建条件与翻译单元边界不一致，不是世界树或脚本问题。

验证记录/D455-CONDITIONAL-COMPILE-PROVIDER_验证记录_v0.1.md

禁止修改 D455 协议、公开头、任何 `.vcxproj`、世界树专项 C++、世界树脚本、生产装配、外设线程、正式规范、计划索引以外的计划，以及异主 WIP。

## 4. 冻结实现合同

1. 以唯一宏 `HY_EGO_ENABLE_D455_REALSENSE` 划分整个 SDK 实现区：所有 `<librealsense2/h/*>` 包含、`rs2_*` 类型、释放器、真实采集器类及真实工厂路径均只能位于 `#if defined(HY_EGO_ENABLE_D455_REALSENSE)` 分支。
2. 宏未定义时，同一工厂仍必须有一个定义；不得产生 SDK 类型、动态加载、伪造帧、后台线程、日志、缓存或领域写入。
3. 关闭路径先沿用既有 `D455采集配置有效` 判断：无效配置返回 `{成功=false, 追根因=false, 拒绝原因=配置无效}`；有效配置返回 `{false,false,无设备}` 和空 `unique_ptr`。`无设备` 在此只表示当前构建环境中没有可用的 D455 提供者，不等同于已枚举真实设备。
4. 不新增拒绝枚举或公开 DTO，避免把构建可选性扩张为新的外设业务语义。宏开启时保留现有全部真实实现和失败映射，不得以关闭路径替代真实 SDK 验证。

## 5. 实施步骤与失败收口

1. S0 核对两工程的宏注入条件、当前工厂签名及该源文件没有异主 WIP。
2. 将现有真实实现整体置入开启分支；在关闭分支仅定义上述零材料工厂。
3. 若发现公开协议已要求区分“SDK 未启用”与“无设备”，停止并退回计划支撑；不得临场增加枚举。
4. 真实 SDK 启用编译缺 SDK、库或 DLL 时保留工程既有早期失败，不以关闭宏伪造启用成功。
