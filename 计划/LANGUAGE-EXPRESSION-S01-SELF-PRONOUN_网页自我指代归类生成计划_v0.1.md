# LANGUAGE-EXPRESSION-S01-SELF-PRONOUN 网页自我指代归类生成计划

日期：2026-10-15。版本：v0.1。计划身份：`LANGUAGE-EXPRESSION-S01-SELF-PRONOUN`。状态仅由[计划索引](计划索引.md)维护。

## 1. 目标、依据和起点

以当前正式代词定义及名称，把普通应用活跃网页会话内**拟由自我发出**的 S01 对象归类目标 `A是C` 生成“我是C”调用期文本，并回显已消解指代的本次作用域、唯一目标、名称关系和固定出现范围。A 必须是当前自我存在，C 为正式存在概念；表达主张不证明 A 属于 C，生成不发送消息。无会话、非自我、名称或定义未决时不产残句；不开放“你/他/这/那/它”。

正式依据：[详细设计](../规范/详细设计/20261015_LANGUAGE-EXPRESSION-S01-SELF-PRONOUN_网页自我指代归类详细设计_v0.1.md)、[1110](../规范/1110_根规范_指代_20260720.md)、[7230](../规范/7230_子规范_语言材料知识与交互字段.md)、[7240](../规范/7240_子规范_自然语言双向转换与组织规则.md)、[7250](../规范/7250_子规范_最小汉语知识与语言学习.md)和[代码归属规范](../规范/代码文件建立归属与模块命名规范.md)。创建侧代码基线 main `cb60b784`：S09 已由 `7275179d` 集成并编译链接通过，且本叶允许代码文件自 `e50f355f` 至此未变化；本叶的“已消解指代”知识/来源/出现尚无当前公开合同。执行前须重做 S0，核对计划精确 blob、main/远端、所有权、现行签名和构建资源。

## 2. 唯一切片与公开合同

一个代码所有者同时施工宿主只读会话核验、普通应用已核验自我待发来源、语言知识指代字段/初始化、S01 消费及调用期出现。允许文件：`海中鱼巣/界面/宿主.网页对话.h/.cpp`、`海中鱼巣/装配.普通应用.h/.cpp`、`海中鱼巣/领域/新_语言类.h/.cpp`、`海中鱼巣/业务/初始化.语言知识.h/.cpp`、`海中鱼巣/业务/表达.基础语言.h/.cpp`、`初始化材料/最小语言知识种子.txt`和专属`验证记录/20261015_LANGUAGE-EXPRESSION-S01-SELF-PRONOUN_施工与编译记录_v0.1.md`。不改其它文件、工程入口/配置、概念/名称/词/存在 owner、网页消息接收/提交、共享知识索引或正式规范；确需扩大范围先退回计划支撑修订。

详细设计§3冻结公开 DTO、字段、函数签名和来源类型：语言知识角色项可选指代概念引用、表达请求可选明确指代选择、表达结果调用期出现/对齐、普通应用自我归类表达入口、宿主当前公开会话只读核验。所有新字段参与完整定义查重、发布、读回和漂移检查；旧知识空字段保持同义。网页会话的唯一运行租约只用于说明“我”的说话者角色，不取得受话者唯一性。

## 3. 施工顺序

1. 在宿主增加同锁只读会话匹配入口，不返回私有令牌、不改变消息组/提交；普通应用从活跃会话、已发布自我存在、交互窗口和宿主匹配结果形成待发来源，入口前后复核。进程锁序保持`普通应用上下文锁 → 宿主互斥`，宿主锁内不回调普通应用。
2. 扩展语言知识 owner 的正式结构：`已消解指代`仅对首叶单项存在角色合法，绑定可读的`作用域说话者`指代定义。把概念服务作为只读依赖迁移所有知识发布/查询/枚举生产调用；跨 owner 读取移出语言锁。旧知识与 S09 子知识仍完整读回。
3. 初始化元格式和标准文本追加一个 S01 自我指代变体。普通应用首次路径先显式初始化语言知识 schema 并核`已完成`（不发布功能词/知识）；非成功沿现有初始化工程诊断中止后续阶段，保留已发生身份。再按“指代定义/词条/名称完整读回 → 语言知识完整发布”的依赖顺序施工；语言知识内部再次初始化 schema 必须复用已就绪结构。重复装配只读路径不调写式 schema 入口，按“指代种子完整读回 → 语言知识完整读回”执行。唯一解析“我”定义，不凭种子标签或结果数组位置充当身份；部分发布按实际阶段报告，不假回滚。
4. 扩展基础表达生成：仅请求显式选择且目标等于已核验说话者时筛中指代变体；无选择的现有规则匹配含义不变，但新增知识计入现行全量候选预算，旧额度可能返回`额度不足`。完整读回 A、C、指代定义/名称/词条、固定词和知识范围，形成“我”的标量对齐及一次调用期出现。失败清空全部成功载荷。普通应用包装入口只返回生成结果，不设置或提交网页消息。
5. 完成一组相关改动后在本工作树实际工程统一编译链接；仅用户对本切片明确发出测试/自检/验收指令时运行对应实际项目测试。写专属记录及代码知识变更清单，按工作树和发布租约规则精确提交、普通推送，交主工作区唯一集成者审核并集成。

## 4. 非成功与验证

非法输入、非自我 A、错误作用域为`输入拒绝`；宿主未运行/会话变化为来源不可用或会话失效；宿主资源失败映射`工程未完成`，其它宿主内部错误映射`内部不一致`；正式引用不可读、规则或名称零/多、额度不足、读回漂移分别用详细设计§5具名结果，不转成语言否定。包装入口的未处理异常进入工程诊断与中止，不能越过`noexcept`或冒充`缺指称`。跨 owner 没有原子事务，初始化必须保留已发生身份并按原请求读回；纯生成零事实写入。

创建侧运行`git diff --check`、`git diff --cached --check`，检查计划及详细设计的所有相对链接和基线。执行侧默认工程门槛为实际项目`msbuild .\海中鱼巣.vcxproj /p:Configuration=Debug /p:Platform=x64 /m`编译链接、源/部署种子字节一致及现有 S02/S09 调用签名编译。无本轮测试指令须记录“已编译，未运行测试”。若获指令，测试矩阵按详细设计§5限于本叶和直接旧路径。

完成只证明有限 S01 自我说话者指代生成代码和实际项目编译链接；不证明初始化实际运行、句子语义真实、发送/显示/理解、受话者、焦点回指、持久语言场景和双向转换。若 S0 发现当前生产表达入口、宿主会话语义或正式指代定义与设计不符且影响这些结论，停止该切片并退回计划支撑，不由执行者猜补公开合同。
