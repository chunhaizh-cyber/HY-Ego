# CURRENT-SNAPSHOT-A2A 持久运行包与隔离候选 v0.1

起点 a4b727742。执行与唯一发布所有者为本窗口。承接 [详细设计](../规范/详细设计/20261128_CURRENT-SNAPSHOT-STARTUP_当前事实持久启动详细设计_v0.1.md)、4015 §15、4070 §3–5、CODE-FILE-01 §6.5。只实现具名平台分片，普通启动、全局基础数据集、上层 owner、正式业务写入与恢复开放门保持原状。

## 合同

- 在新 `基础数据集.持久运行包.h/.cpp` 实现 `基础持久运行包`，独占拥有一个现行 `基础持久存储` 会话。打开先从载体取得活动字节，再用 P1 解码并构造隔离 `基础持久视图`。合法空仓成功打开但读取为空；输入拒绝或完整性失配不得返回运行包。视图独占新基础数据集，调用方只持不可变视图和只读数据集引用。
- 数据集通过该具名运行包的友元恢复；使用已有字段和外部关系插入内部原语推导六个索引，并对集合基数复核。只在隔离候选使用原语，无现存读者或数据集锁。载荷映像是暂态，视图只保存三组权威、派生索引、分配高水位和持久身份。技术材料尚无解释合同时，运行包拒绝非空技术材料。载体仍只读取活动槽。
- `读取` 原子取得共享不可变视图。`提交(预期视图, 候选映像)` 仅是底座平台操作，运行期真实 owner 接入须等后继。单会话用非阻塞原子资格串行提交；竞争返回提交占用，不等待或持仓库锁做 I/O。预期必须是当前视图或合法空仓的空指针；过期报前提变化。候选先编解码并恢复验证；禁止改数据集身份、倒退高水位、复用已分配但不存在于原同组的旧编码。权威内容与高水位一致时返回无变化，不写磁盘。
- 只有底座载体成功提交槽与清单后，使用一次无抛出的共享视图原子交换发表候选。所有提前失败保留原视图，无新编码回执；发布未知沿载体保持拒绝后续写入。旧读者持有的视图不变。此分片不解释组合请求收敛材料，不接普通全局权威，不声称现有直接 CRUD 或组合写入已经持久化。
- 允许文件仅核心/基础数据集.h、核心/基础数据集.持久存储.h、核心/基础数据集.持久运行包.h/.cpp、业务/自检.当前快照存储.cpp、主项目及 filters、专属验证记录。其它文件未经另行登记不改。

## 验证

原项目 Release x64。复用已登记的受控临时目录自检入口，追加运行包的打开、提交、失败验证操作。跨进程：空仓无视图、提交后正反查询派生索引、退出重开读回同一权威、两代发布旧视图仍可读。测试错误身份、高水位掉退、已分配编码复用、旧期望、非空技术材料均保留现状。物理失败将非活动槽目标阻断，读者仍持当前，磁盘清单不变；正常重新打开后继续提交。精确核对 SHA、序号和所有退出码。普通入口、并发竞争的可重复正例、发布未知和 A2b 服务动作同次收敛单独列证。
