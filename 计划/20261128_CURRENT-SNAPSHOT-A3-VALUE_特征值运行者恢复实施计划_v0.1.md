# CURRENT-SNAPSHOT-A3-VALUE 特征值运行者恢复实施计划 v0.1

候选方案，未登记。生产基线 `1119ebb8a6624527ecf4413a35c13dbff8669b49`。生产施工与主工作区正式工程验证由交互窗口独占。只解决持久权威上特征值的正式七键、原始材料和派生索引恢复。沿现有普通准入边界，保留持久业务运行者未重绑出口。

正式依据为 [2100 §2–7](../规范/2100_根规范_特征值.md)、[4110 §6–10、§13](../规范/4110_子规范_特征节点实现与字段边界.md)、[4015 §14–15](../规范/4015_子规范_基础数据集.md) 和 [4070 §3–5](../规范/4070_子规范_权威结构快照恢复候选与运行期原子发布.md)。上游 `1119ebb8a` 已实现外设自键的冷暖读回及普通无标记根兼容，持久空仓与独立重启的真实运行尚待具名授权。[上游实际验证](../验证记录/20261128_CURRENT-SNAPSHOT-A3-RUNTIME_外设消息确认自键与独立读回.md)

当前六键共用压缩层类型。二维从占用包围框重采样成灰度层，根是八个 U64。三维 OR 根是单项 U64。旧实现拒绝三项规范化全零描述，却可保存完整全零位图。旧类型可按无父根形状追溯，正式恢复只认可各自的二维和三维类型节点及现行 4110 材料。已有普通原值、压缩层和父子关系的事实分别由值所有者核验，运行索引从事实派生。

## 准入状态

直接保存调用中，普通装配、外设、任务、词典及二次特征按明确物理类型传入普通值。`新_特征类.cpp` 的格比较从正式原值取材料，独立于存储压缩。`模拟学习.服务.cpp` 复制有限材料候选时从正式值节点取得完整材料。`新_模拟世界类.cpp` 的声明样例按定义保留二维、三维类型并复制变体，模拟回读给出同一物理类型和原始材料，`新_方法类::保存模拟材料值域` 原样交给值所有者。已核对的当前调用点范围未发现主动构造完整全零位图并送入正式值保存的生产实现。候选中出现旧格式位图或非法材料时走既有拒绝路径，由上层的未来具名材料准备能力承担新全零输入转换。

## 接口、文件与状态

由 `新_特征值类` 唯一所有者实施。允许 `海中鱼巣/领域/新_特征值类.h`、`海中鱼巣/领域/新_特征值.恢复.h`、`海中鱼巣/领域/新_特征值类.cpp`、`海中鱼巣/领域/新_特征类.cpp`、`海中鱼巣/启动.应用程序.cpp`。如获具名测试授权，可在已登记的 `海中鱼巣/业务/自检.当前快照存储.cpp` 增加两个参数场景。施工证据记录在 `验证记录/20261128_CURRENT-SNAPSHOT-A3-VALUE_特征值运行者恢复验证.md`。现有工程登记、核心持久接口、普通装配、世界/场景/特征概念所有者、外设宿主和业务写入均无修改范围。

在 `新_特征值类.h` 类声明前定义 `enum class 新特征值运行恢复状态 : std::uint8_t { 已恢复 = 1, 精确复用, 未绑定, 格式不支持, 结构不一致, 前提已变化, 资源失败 };`。在类公开部分增加以下入口，在 `.cpp` 的原所有者实现。启动层及获准正式自检可调用。

```cpp
新特征值运行恢复状态 恢复当前权威() noexcept;
```

`新_特征值.恢复.h` 保留两个现有恢复函数，`新特征值恢复结构读回::键` 扩为 `std::array<稳定编码, 7>`。`解码结构()` 顺序为 `[0], [1], [4], [5]`，原公开的 `新特征值快照解码结构` 四字段和物理类型枚举不变。该头另声明同一私有索引构造器的只读核验包装，成功时只返回 `已恢复`，不安装实例。

```cpp
新特征值运行恢复状态 核验恢复特征值索引(const 基础持久视图& 视图) noexcept;
```

新增 `新特征值保护读取状态::格式不支持` 于枚举末尾，仅供恢复视图读口。六键旧版只在六个旧标记均精确合法、两个新版压缩类型标记均未出现时归入该状态。六键损坏、任一新键缺失、旧共享标记混入七键、别名或重复均为 `结构不一致`。资源失败与异常走既有资源或工程异常收口。各入口零部分安装。原公开查询和保存签名保持，保留当前返回形状。正式恢复入口保留精确失败原因。

## 七键与冷建物理合同

按以下顺序发表事务组。每个结构节点的自键宿主、字段键和节点编码相同，材料是直接 UTF8 字符串。任一标记必须全局唯一，七个编码互异。普通未绑定首次初始化只沿现有唯一 owner 构造及空仓协议一次组合发表七键。同一已就绪实例重复初始化时复核缓存七码和精确自键后作零写复用，发现缺失或冲突时中止。绑定恢复和冷建隔离候选的全局标记复核使用 `基础持久视图::查询自键标记`，已知旧共享标记、部分存在或重复按恢复状态规则拒绝。绑定恢复与隔离候选核验都是只读。冷建失败复用已有联合预期及发布收口，只清理本调用未正式采用的结构。

```text
HY-Ego/2100/value-node-type-field/v1
HY-Ego/2100/value-node-type/v1
HY-Ego/2100/compression-layer-2d-type/v1
HY-Ego/2100/compression-layer-3d-type/v1
HY-Ego/2100/material-physical-type-field/v1
HY-Ego/2100/original-material-field/v1
HY-Ego/2100/compressed-material-field/v1
```

- 二维及三维压缩层的节点类型字段明确指向各自类型。两类最粗层都是一个 U64，二维以 `2×2`、三维以 `2×2×2` 做逐层 OR。低位先行，x 最快。按二维 `8×2^k`、三维 `4×2^k` 安全核验长度和乘法。层序按现有数组从原最高分辨率到根，尺寸已是根的原值仍有独立压缩根。移除本 owner 无比较调用的灰度压缩实现，保留比较 owner 的面积和阈值实现。
- 材料归类先按显式物理类型核变体。二维 `[0,1,N]`、三维 `[0,2,N]` 仅在 N 满足对应几何及安全乘法条件时有效。原始节点保存三项描述，无压缩父边，归入 `普通材料索引_`。普通 U64 数组具有相同字面时仍属普通 U64 类型。完整全零格、错标签、坏尺寸和双维误用在任何写入前拒绝。已完成原始材料解码复用同一个私有格形状核验，多项或不合法材料不返回部分成功。
- UTF8字符串分支在值 owner 的统一材料核验中直接验证 Unicode 标量的 UTF-8 字节编码。参考现有网页宿主的字节检查方式，在值 owner 内按 1 至 4 字节序列检查前缀、续字节、最短编码、非代理项和 U+10FFFF 上界，使用剩余长度检查截断。有效码点及原字节完整保留，包含 U+0000、U+FEFF 和 U+FFFD，空字符串的业务准入交给特征类型。保存和查询的非法输入按原入口拒绝，恢复已存非法字符串归入结构不一致。语言词面限制不进入值层。
- 普通保存按既有完整类型与材料精确命中后复用。格保存用已知类型、完整根内容和逐级父子路径查找，最终核原值类型和原位图。不存在时将本次新增的粗细层与原始节点按原有单一结构所有者一起放入既有 `基础节点组追加请求`，经现有原子追加挂入角色 0 的父子边。已有父节点从同一读批取得现有保护，候选要核最初的根/子路径未变化。成功后按组内槽与实际回执取得节点，不先放空节点或以可分配裸码代替新节点引用。索引候选发表前预留，回执通过后无分配更新。明确失败不保留本调用未发表层。已有重复正式身份为工程结构不一致，不挑首项。

## 格比较兼容

`新_特征类.cpp::比较双准确值` 及 `计算节点材料接近度` 的二值格分支在读回并核对正式原值物理类型后，经同一局部适配进入既有 `比较二维轮廓材料` 或 `比较三维体素投影`。比较适配通过 `新_特征值类.h` 声明的领域内部函数复用值 owner 的严格全零描述解析，传入明确物理类型和只读材料，解析成功返回对应位图安全字数。普通位图沿用原只读引用。规范化全零仅在比较局部按安全字数展开，再传入原算法。两个匿名命名空间比较入口去掉内部 `noexcept`，让展开和原算法的分配失败交给各自已有的调用方工程收口，禁止转换为得分或业务否定。既有同完整原始材料的快捷结果，以及不同分辨率的面积覆盖、体素投影和比较阈值沿原算法。正式材料节点保留原始三项描述及身份。

## 独立暖读与运行派生索引

先由 `基础持久运行包::读取已绑定会话(数据集_)` 取得本实例的数据集唯一会话，再固定 `会话->读取()` 到一次不可变视图。以三个节点类型值逆向查询 `节点类型字段`，从该视图独立解码所有原始值和二维、三维压缩层。普通材料键按物理类型与完整值相等，检出同键多节点即结构不一致。格原值逐层复算，从其父子边向上对照完整路径。只有无父且同维度根形状合法的压缩节点进 `根索引_`，键为显式类型与完整根材料。

同一视图必须核对以下不变量。

- 每个层或格原值至多一个压缩父节点。格原值恰一个，普通材料与全零描述无压缩父边。每条边为本 owner 的父子角色 0，禁止非组织引用压缩层。层序、长度和位内容逐层匹配。二维与三维中间层或根不串接。压缩层祖先递减，拒绝环、孤立内部层、同父同型同压缩材料重复和同型同根多节点。
- 一个合法根可连接不同分辨率或不同原始位图的多个值。没有原始叶时，仍只允许自身字段、根及已有内层的物理形状与逐边 OR 一致的分支，查询原始值不返回该分支。若不能证明内层与祖先一致，返回结构不一致，不删旧结构。压缩层永不进入普通原材料索引。
- 候选键、普通索引及压缩根索引在本实例互斥之外构造。持实例互斥安装前重新核对绑定会话及当前视图仍为准备时同一快照。一并移动六个原运行字段加新增的三维类型字段、两个私有索引、绑定会话身份/视图和就绪位，无先行部分就绪。重复同一身份、同一视图和完整状态为 `精确复用`。实例已作为未绑定冷建所有者就绪或绑定身份不同，返回结构不一致。视图改变则 `前提已变化`，保留尚未生效的状态并从现行入口重新取得整个候选。

恢复型实例的正式读取与查询在开始时固定会话当前视图，并使用同一视图的索引、类型节点与正式原材料。若视图已变化，从新视图重建并仅在当时视图仍有效时替换派生索引。旧索引未命中不作为正式不存在。找回既有值时须按原始完整材料再次核对并返回原编码。已绑定实例允许既有值的精确零写复用，缺值沿现有失败返回，本版无持久新增材料分支。未绑定实例的初始化、构建、查询和保存继续按前述物理合同。绑定会话不可变视图能保证同批数据一致，索引未完成或资源不足时不返回部分候选或打开普通写入。
