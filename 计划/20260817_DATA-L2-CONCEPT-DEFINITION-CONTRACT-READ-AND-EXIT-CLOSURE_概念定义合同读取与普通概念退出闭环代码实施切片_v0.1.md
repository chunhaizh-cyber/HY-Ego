## 1. 目标与完成条件

```text

+ 定义关系按概念正向、按目标反向的当前 / 历史读取
+ 退役普通概念不可逆退出、替代直接边和历史读回
```

完成要求：详细设计全部 DTO、函数、写集、错误和读回合同实现；根工程 Debug / Release 构建通过；仓库外自定义参数矩阵通过并清理；只提交允许文件和两份专属记录；结果普通推送并远端读回。

## 5. 私有实现步骤

1. 在普通概念结构登记中加入详细设计固定的 `0x6206 / 0x6219—0x621B` 四类型并扩展定位完整性检查；不得改变既有稳定键。
2. 用 `0xB—0xF` 五个确定分区承载定义角色合同，扩展本地键容量、写集、映射、首次结果和幂等完整请求互证。
3. 扩展普通概念事实完整性：角色合同严格排序，定义项逐角色连续排序且数量满足合同；签名唯一键包含合同组。
4. 实现定义正向 / 反向同截止读取。反向只做概念 owner 范围有界扫描，稳定排序，预算耗尽零载荷。
5. 实现退出前置：根保护、退役见证、当前支持为零、反向定义为零、外部引用保护、完整 DAG 和预算。
6. 实现中间概念替代边算法；只在不存在绕行路径时建立父到子直接边，去重并稳定排序。
7. 形成单 owner 原子退出写集；关闭目标全部自有当前事实及关联直接边，建立必要替代边，不级联其它 owner。
8. 首次 / 精确重复从首次截止重建同一结果；当前读取已退出，历史读取按退出前后截止返回完整事实。
9. 保持根三入口、支持、上下位、生命周期、聚合 getter 和普通应用零语义变化。

## 6. 错误和失败收口

状态映射逐项服从详细设计第 10 节。特别要求：

- 当前支持、反向定义、名称或外部引用统一为 `引用冲突`，不得自动清理；
- 图 / 反向扫描预算不足为 `数量预算不足`，不得返回截断成功；
- 截止变化为 `事实代次漂移`，不得内部重试或重新解释请求；
- 发布未知 / 资源失败保留原请求和原幂等身份重放；
- 缺角色合同、混代、图坏形状和坏成功载荷为 `内部不一致`；
- 所有非成功返回空载荷、空关系组、零变化。
