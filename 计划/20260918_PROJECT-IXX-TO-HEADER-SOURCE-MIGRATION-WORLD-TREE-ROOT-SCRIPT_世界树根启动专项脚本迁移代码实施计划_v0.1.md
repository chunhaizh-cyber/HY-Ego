## 1. 目标与完成条件

按同名详细设计 v0.2，把世界树根启动专项 PowerShell 脚本的四个旧模块格式文本探针替换为现行 `.h/.cpp` 探针。

本计划的完成只证明脚本已正确消费现行物理路径和静态格式断言；专项 Debug/Release 重建、core/ordinary 运行及 JSON 成功合同不再是本计划的完成条件，分别由 `D455-CONDITIONAL-COMPILE-PROVIDER` 与 `WORLD-TREE-ROOT-V4-CONSUMER-MIGRATION` 在其共同上游完成后负责。

## 2. 允许范围与禁止事项

只允许修改 `验证工具/运行世界树根启动专项验证.ps1`，以及本计划专属施工/验证记录。禁止修改生产头源、世界树根专项工程、专项程序、L1/世界树 ABI、其它验证工具、正式规范、计划索引之外的计划和异主 WIP。

## 3. 实施与失败收口

执行同名详细设计 §2—§3：在任何构建前验证当前 header/source 物理形态；保留输出根白名单、构建命令、两个运行命令和 JSON 字段。发现路径或结构事实与设计不一致时具名失败并停止，不以修改生产代码或放宽断言收口。

脚本可以保留既有构建和运行命令，但本计划不得把它们的结果解释为路径迁移是否完成；构建失败应记录为下游输入阻断，不能反向要求本计划改专项 C++、工程或生产代码。

## 4. 验证与发布

检查脚本旧格式路径和断言零残留，运行 PowerShell AST、目标路径 `git diff --check` 与 `python .\tools\check_specs.py --strict`。获得发布租约后仅暂存允许文件并普通提交推送。
