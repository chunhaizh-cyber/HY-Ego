## 1. 目标与完成条件

按同名详细设计，在唯一 `L2概念结构服务` 内完成：

1. 世界事实支持关系新增、原子替换和退出；
2. 按概念与按世界事实双向当前 / 历史有界读取；
3. 世界事实、概念、建立依据和发布证据同截止强类型读回；
4. 同一世界事实 / 概念当前关系唯一，多对多和跨根合法；
5. 新的 owner 内部支持登记根、支持事实项和结构类型使用独立版本化登记写集；
6. 唯一概念 owner、唯一写端口、现有概念写锁与同实例聚合继续成立。

完成只证明本叶生产代码、公开 ABI 和必要构建检查进入正式 Git；不证明支持关系业务正确、实际消费者、定义约束、生命周期、概念退出或 `DATA-EXT-08` 整项完成。

## 4. 机械施工合同

1. 按详细设计 §3 形成 `L2世界事实引用`、支持关系事实、三写两读请求、写 / 组读结果、请求 helper、事实截止 helper 和成功形状。
2. 世界事实类型从现有定义目标闭合类型中排除概念身份；复用现有编码，并抽取单个闭合引用的同截止公开验证，保持普通概念定义读回行为不退化。
3. 用新内部幂等身份 `0x4C32'434F'5247'0003` 建立支持登记根、两种关系类型和三个属性类型；不得修改前三份既有内部登记规范化写集。
4. 完整构造初始化支持定位；根专用构造保留根三入口，支持入口结构化 `未实现`。
5. 每条支持事实同事务建立内部节点、登记关系、到概念关系、世界引用 / 建立依据 / 发布证据三个值与槽。替换同事务完整退旧建新；退出完整关闭旧内部事实。
6. 按概念通过目标关系组读取；按世界事实通过登记根有界枚举并过滤。当前 / 历史都逐项重建同截止完整事实，稳定排序，空组成功，超预算空载荷拒绝。
7. 写前在请求 `G0` 证明现状内部登记完整、端点 / 材料当前和 `(世界事实, 概念)` 唯一。替换保持概念不变；退出不修改世界事实、概念或材料。
8. 首次写入材料驱动精确重复和幂等冲突；首次成功 / 重复按首次截止历史读回。发布未知与资源失败保留原完整请求重放。
9. 不改变四本体根、普通概念、直接上下位关系、概念 owner 交付或聚合 getter 的公开签名与语义。

- 纯代码 / 编译错误：在两生产文件和专属记录范围内修复。

- 若历史双向读回需要第二 owner、非权威缓存、修改 L1，或现行公开世界服务无法在同一截止验证闭合世界引用：具名 `DRIFT-DATA-L2-CONCEPT-WORLD-FACT-SUPPORT-READBACK-OR-SCOPE`，保留现场并停止扩大。
