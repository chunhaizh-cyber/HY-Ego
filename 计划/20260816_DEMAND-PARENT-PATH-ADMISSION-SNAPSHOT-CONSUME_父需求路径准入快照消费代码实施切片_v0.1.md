1. 按详细设计建立请求、固定配置、状态、快照和结果值式合同；函数名、变量名使用中文。
2. 扩展同一 `需求业务服务`，持普通应用同实例唯一 `const L2需求结构服务&`；构造零事实读取。
3. 固定配置坏、请求坏、零父 / G0 / 任一预算、转换溢出和版本漂移在 DATA 调用前精确收口。
4. 构造一份 DATA 请求并恰一次读取；运行代次不下传，零重试、零截止重选。
5. 只有请求指定父需求未找到 / 已退出映射业务状态；祖先展开后缺失 / 退出收敛内部不一致。精确映射五类预算、漂移、许可、资源、未实现和内部错误。
6. 互证完整根到父链、父关系端点、逐父组等长同序、全部直接子 / 路径 / 组，以及请求父需求唯一权重 / 全部预算来源、每项 G0、版本、五预算和稳定排序；孤立路径组也计入路径组预算，祖先权重不得进入结果。
