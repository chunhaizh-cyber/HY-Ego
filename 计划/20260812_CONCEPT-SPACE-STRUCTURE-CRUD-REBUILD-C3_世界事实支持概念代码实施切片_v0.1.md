# 世界事实支持概念代码实施切片 v0.1

日期：2026-08-12

计划身份：`CONCEPT-SPACE-STRUCTURE-CRUD-REBUILD-C3`

状态：`待激活`；设计完成，不等于实施完成

## 1. 目标与依赖

原位扩展概念服务，以闭合 `L2世界事实引用` 实现世界事实到概念的多对多支持关系、双向当前查询、历史读取和关系退出。依赖 C2 结果以及场景、存在、特征、状态、动态、因果最终公开身份 / 完整读取 ABI；语言使用事实不在 v1 范围。

## 2. 允许范围

只改概念数据头 / 服务，新增三份 `L2世界事实支持概念参数验证` 临时文件和两份 CONCEPT-C3 记录，共七路径。不得修改任一世界服务、普通应用、工程、名称服务或公共 variant 类别。

## 3. 接口和事务

公开函数固定为：

```text
建立世界事实支持概念
退出世界事实支持概念
按世界事实读取当前支持概念组
按概念读取当前支持世界事实组
读取世界事实支持历史
```

建立请求含共同头、幂等身份、闭合世界事实引用、概念身份、来源和发布证据。服务按 variant 精确分派目标服务，以同一期望截止证明事实与概念当前有效；随后只用概念 owner 建立一条支持关系。同一端点对当前唯一，多对多和跨维度合法。退出只退出关系，不退出端点。结果按类别、端点稳定键、关系编码确定排序；合法零匹配返回已读取空组。

## 4. 验证与声明

每个 v1 类别至少一条合法支持，另覆盖坏类别 / 错族、同事实多概念、同概念多事实、跨维度、重复、双向查询、退出和历史。不得声明服务判断了归类正确性、复制了世界事实或支持语言使用事实。
