## 4. 机械施工步骤

1. 在现有数据头追加两个实际存在请求 DTO、默认值、相等比较和两个有效性函数；不修改旧 DTO 字段或 P4 场景换代请求。
2. 服务模块单向导入 P7 组合服务，保留三参构造并新增四参构造；以不可变非拥有指针区分是否支持存在入口。
3. 抽取场景与存在入口共用的私有写集构造/提交核心和事实读回核心，保证旧场景入口的签名、状态、形状和幂等域不变。
4. 新增按 `特征操作幂等身份.值` 排序的存在入口值式账；同键同义保存完整读取见证并重复独立读回，同键异义冲突，不同键允许建立不同实例。
5. 建立入口依次读取 P7 实际存在、P2 定义和 L1 完整快照，统一到请求期望代次，确认来源普通节点和指定宿主+定义唯一性。

7. 新增公开读取入口，逐项读取 P7/P2、实例槽、两关系、当前值和当前属性槽，并在同代次快照核验唯一性；建立后只调用该入口返回事实。
8. 原位扩展 `自检.L1实例特征.ixx`，覆盖详细设计 §10 全矩阵并保持现有场景建立/读取/换代用例成立。

## 5. 错误、事务和停工条件

- 入口非法或未绑定 P7 provider 为 `入口拒绝`；P7/P2/L1 状态严格按详细设计映射，不得默认成功。
- 同一宿主+定义多槽、槽多宿主、多定义、多当前值或坏成功载荷为 `内部不一致`；同键异义或已有组合不能精确重复为 `幂等冲突`。
- 单次提交前失败零普通可读变化；发布后读回失败不补写、不回滚、不删除、不发第二写集。
- 当前值历史为空，禁止原地覆写。若需要让 P4 场景换代请求静默接受存在、修改 P7、建立第二实例服务、创建状态/动态/因果或修改白名单外文件，停止并具名退回设计漂移。
