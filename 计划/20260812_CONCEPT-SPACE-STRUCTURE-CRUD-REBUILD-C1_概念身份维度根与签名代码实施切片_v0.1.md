# 概念身份维度根与签名代码实施切片 v0.1

日期：2026-08-12

计划身份：`CONCEPT-SPACE-STRUCTURE-CRUD-REBUILD-C1`

状态：`待激活`；设计完成，不等于实施完成

## 1. 目标

在语言 / 词性 / 词条真实服务上建立唯一 `L2概念结构服务`、概念 owner 和概念节点族，完成维度根、普通概念、不可变抽象签名、初始直接上位 / 定义关系、概念身份来源和当前 / 历史完整读取。

## 2. 依赖与允许范围

依赖 L1 计划真实结果、M1、4240 和总详细设计；还依赖 C1 初始定义引用所需的最终六类世界公开 ABI。未满足时保持待激活。

允许新增 / 修改：`L2结构公共.数据.h`、`L2概念结构.数据.h`、`服务.L2概念结构.ixx`、普通应用、根工程 / filters、三份 `L2概念身份签名参数验证` 临时文件和两份 CONCEPT-C1 记录。禁止修改各端点服务、语言服务、名称服务和现有聚合。

## 3. DTO 和公开函数

公共头新增 `L2概念身份` 与 `L2节点族::概念`。概念数据头唯一拥有 `L2世界事实引用、L2概念定义目标、L2概念签名值式项、L2概念签名定义项、L2概念事实` 以及来源 / 根 / 新增 / 读取请求结果，variant 精确服从总详细设计第 5 节。

公开函数：

```text
读取概念身份来源
建立概念维度根
新增概念
读取完整概念
按词性读取概念维度根
按完整签名读取当前概念
```

维度根原子建立节点、归属、词性维度、根角色和永久活跃生命周期；每个当前词性至多一根。普通概念原子建立节点、归属、维度 / 词性、完整签名、初始定义、至少一条上位和活跃生命周期；初始图在写前模拟无环和根可达。签名键为维度根 + 签名规则材料 + 全部确定排序项；同键唯一。名称、词面和索引不进入签名。

## 4. 验证与声明

覆盖多词性多根、根永久活跃、概念独立身份、签名唯一、跨维度同签名并存、初始多父、坏定义端点、自环 / 跨维度 / 不可达拒绝、当前 / 历史和幂等。只声明 C1 结构；不声明后续 DAG 替换、世界事实支持、名称、生命周期退出或抽象业务成立。
