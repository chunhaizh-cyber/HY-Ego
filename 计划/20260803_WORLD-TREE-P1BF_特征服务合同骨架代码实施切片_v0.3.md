## 5. 失败收口与验证

接口/模块/共享头/顺序漂移时零代码修改返回具名漂移；需要真实行为、旧栈适配、额外共享字段或特征写入服务时停止，不建立临时壳。任一验证失败保留WIP，不声明完成。

```powershell
git diff --check
python .\tools\check_specs.py --strict
msbuild .\海中鱼巣.vcxproj /m /p:Configuration=Debug /p:Platform=x64
msbuild .\海中鱼巣.vcxproj /m /p:Configuration=Release /p:Platform=x64
.\x64\Debug\海中鱼巣.exe --self-test-exit
```

MSVC 全工程模块依赖扫描与目标函数源码闭包是必过门禁；Clang 只作可用时的候选诊断。MSVC 输出只能写系统临时目录：

```powershell
$依赖 = Join-Path $env:TEMP 'WORLD-TREE-P1BF-模块依赖.json'
.\tools\clang_ast\扫描.MSVC模块依赖.ps1 `
  -配置 Debug -平台 x64 `
  -输出路径 $依赖
$依赖材料 = Get-Content -Raw -LiteralPath $依赖 | ConvertFrom-Json
if ($依赖材料.failed_count -ne 0 `
    -or @($依赖材料.cyclic_modules).Count -ne 0 `
    -or @($依赖材料.unresolved_requirements).Count -ne 0) {
    throw 'P1BF MSVC模块依赖未闭合'
}
```

目标函数源码闭包核对必须从 `海中鱼巣/领域/服务.节点直接特征查询.ixx` 中按完整签名定位唯一函数体并保存精确行区间。函数体必须含详细设计要求的 `static_assert(noexcept(...))`，并精确返回 `节点直接特征组读取结果{节点直接特征读取状态::未实现, 0, {}, {}}`；除此之外参数读取、依赖成员读取、直接调用和未解析调用均为0。不得使用会默认形成 `入口拒绝` 的 `return {};`，也不得用全文件命中数替代函数闭包。

另以 `rg` 扫描服务文件不得出现旧特征模块、句柄、SQL、仓库、数据操作、许可或锁；`结构_` 只允许出现在构造初始化和成员声明。

若执行者选择补充运行 Clang，必须按工具 README 的真实参数先生成依赖 JSON，再以 `-模块依赖路径`、`-配置 Debug`、`-平台 x64`、`-目标模块 海中鱼巣.领域.服务.节点直接特征查询` 运行候选扫描。只有全部依赖 PCM 已成功且目标模块自身报告源代码错误时才阻断；既有依赖 PCM 失败、目标依赖不可用或 PowerShell/stderr 工具异常只记录为候选工具不适用，不得覆盖 MSVC、运行自检和源码闭包结论，也不得修改执行器、会话或工具脚本。
