## 7. 当前值初始与跨表示换代事务

新值本地键固定：

```cpp
inline constexpr std::uint32_t 特征当前值本地键值 = 0x0203'1201U;
```

两写固定流程：纯值校验 -> 读取关系类型 / 值类型登记 -> 构造不可变写集 -> 代次探测 -> 旧期望恰一次直提 -> 同期望调用最终完整当前实例并核对槽 / 当前值 -> 恰一次提交 -> 首次代次历史属性值 / 单事实读回 -> 完整结果或内部不一致。

初始写集：`值=[{本地键,实例,按材料选择的登记类型,材料,来源}]`，`属性槽变更=[{实例,同类型,本地键}]`，节点 / 关系 / 退出为空。当前实例必须有效，四个登记类型槽合计零项、实例 `当前值` 为空；任一已有当前值返回引用冲突。

换代写集与初始唯一差异为 `退出事实=[旧值稳定编码]`。当前实例必须恰有一个登记类型槽和一个当前值；未设置返回属性未设置，旧值不符返回引用冲突。新材料可选择与旧值相同或不同的登记类型；L1 在同一候选中先退出旧值并删除旧槽，再应用新槽，因此跨表示换代仍只有一个当前值。

成功 / 精确重复必须取得唯一本地键映射、首次代次与发布 / 重试边界。新值从首次截止历史属性值组重建；换代旧值以单事实历史核对同代次退出。所属、类型表示、材料、来源、槽、编码或生命周期矛盾均内部不一致，不二次提交。

## 8. 当前 / 历史实例和值读取

F2 当前单项读取的第一次节点投影允许实例属性槽为零或恰好一个，且若存在必须属于四个登记值类型。第二次投影在原节点与两个关系组之外请求该具名属性值；节点槽前后逐字段相等，值所属实例、登记类型、材料表示、来源和生命周期同截止，转换为 `当前值`。其它属性类型、多槽或部分值为内部不一致。

F2 历史单项读取在节点 / 两历史关系之间加入：

```cpp
读取中性历史属性值组({L1中性CRUD合同版本,
    请求.特征实例.值, 请求.历史截止事实代次})
```

截止有效属性值只能是四登记类型之一且至多一项；转换后晚于截止的退出代次清空。节点当前槽不得补历史。按存在枚举继续逐项调用最终当前读取，因而组内每项携带零或一个同截止当前值。

`读取特征历史值` 使用前后当前代次夹取和 `读取中性历史事实(值编码)`，核对返回确为值事实、所属实例、登记类型与材料表示一致。它返回该具名值完整创建 / 可选退出生命周期；不要求值在当前，且不改变未来退出信息。值不存在返回未找到，事实种类 / 所属不符内部不一致。

所有读取失败清空整个载荷；许可、漂移、未找到、已退出、属性未设置、资源和内部矛盾不得互相折叠。

## 9. 实例显式闭包退出

退出前调用最终 `读取完整特征实例(当前)`，取得实例事实和两关系编码。实际宿主 / 定义关系编码及可选当前值编码必须与请求逐字段相等；缺项、多项或错项返回 L2 引用冲突，零提交。

唯一 L1 写集为：节点 / 关系 / 值 / 槽变更全空；`退出事实` 是实例节点、宿主关系、定义关系和可选当前值编码的全局升序唯一组。请求不得携带宿主存在、特征定义、来源或材料节点编码。

L1 对最终写集执行二次当前引用保护。未来状态关系、值来源或其它外部事实仍引用实例 / 当前值时返回 `引用冲突=10`，F3 精确映射；F3 不扫描状态服务、不自动退出消费者。调用方先经外部所有者闭合引用，再用新代次和新幂等身份重试。

成功 / 精确重复要求空新编码映射和首次发布 / 重试边界正确；按首次代次历史读取实例节点、两关系和可选值，全部退出代次相等，端点宿主 / 定义仍不退出。`已退出特征实例` 保留退出生命周期和可选已退出值，`已退出自有关系` 返回两编码。任一读回矛盾为内部不一致，不补偿已发布事实。

退出后当前单项 / 枚举不可见；退出前历史截止仍完整，截止等于退出代次返回已退出。F3 不提供复活或物理删除。

## 10. 状态、幂等和异常收口

值类型登记使用独立状态；值写、值读和实例退出使用共同 L2 状态。所有 L1 枚举 switch 完整覆盖 `引用冲突=10`。F2 当前 / 历史映射同步支持属性未设置的合法无值分支：完整实例无值不是整体失败，专用值初始前读取则由实例事实表达空值；`读取特征历史值` 按具名编码不存在返回未找到。

同一幂等身份只绑定完整请求。精确重复返回首次值 / 退出结果且零推进；同键异实例、旧值、材料、来源或闭包为幂等冲突。旧期望新键漂移，旧期望原键直提收敛首次结果。

非成功顺序：纯值非法 -> 入口拒绝；登记未加载 / 失败 -> 对应映射；既有幂等 -> 重复 / 冲突；新键旧期望 -> 漂移；实例未找到 / 已退出 -> 同名；值未设置 -> 属性未设置；旧值 / 退出闭包不符 -> 引用冲突；L1 外部引用 -> 引用冲突；许可 / 资源 -> 同名；事实矛盾 -> 内部不一致。全部非成功载荷为空，不伪造变更代次。

## 11. 临时生产外验证矩阵

临时验证只 import L1 公开服务、E2 存在服务和激活后的 F3 特征服务；定义、实例、登记、值、关系和外部引用都经正式公开入口形成。不 import 仓库，不访问私有定位 / 锁 / 索引 / 幂等账，不解析日志，不引入历史状态 / 动态登记实现。

参数：

```text
--幂等基值 <uint64，默认 41000>
--初始I64 <int64，默认 11>
--换代U64一 <uint64，默认 22>
--换代U64二 <uint64，默认 33>
```

必过矩阵：

1. 建立四种值类型登记，四编码唯一非零、节点表示精确；重复 / 冲突 / 未加载 / 错规则分账；
2. 建立定义、存在和空值实例；F2 当前 / 历史 / 枚举在 F3 前置阶段仍返回空当前值；
3. 初始 I64 当前值只推进一个代次，槽、值、材料、来源和生命周期正确；重复返回首次载荷，同键异材料冲突；
4. 已有当前值再次初始返回引用冲突；无值实例换代返回属性未设置；错旧值返回引用冲突；
5. 从 I64 跨表示换代到 U64 组只推进一个代次，旧槽删除、新槽唯一、旧值同代次退出，当前只有新值；
6. 再在同表示内换代，当前 / 历史各截止无空洞、无双当前，材料和来源逐字段正确；
7. I64 组和独立材料引用分别在其它实例完成初始 / 换代，证明四种登记映射；空数组 / 零独立材料入口拒绝；
8. 具名历史值读取分别返回仍当前的新值和已退出旧值的完整生命周期；错实例 / 错编码分账；
9. F2 当前单项和按存在枚举均返回同截止当前值；换代前 / 后历史实例分别返回对应值；
10. 完整单项读取返回两非零不同自有关系编码；出口闭包漏关系、错关系、漏 / 多值分别引用冲突且零提交；
11. 建立指向实例或当前值的 L1 公开外部关系，实例退出由 L1 引用冲突保护；这不冒充状态服务已实现；
12. 退出外部引用后用新代次 / 幂等身份退出实例，节点、两关系、当前值同代次退出，宿主存在 / 定义 / 来源 / 材料节点仍当前；
13. 退出原请求重复返回首次载荷，同键异闭包冲突；当前单项已退出，按存在枚举不含该实例，退出前历史仍完整；
14. 无当前值实例可用空值闭包退出，节点与两关系同代次退出；
15. 合同错、零身份 / 来源 / 关系 / 值、重复编码、旧期望新键均精确拒绝且零变化；
16. 先确定性推进 L1 后以旧期望读取当前 / 历史 / 枚举，证明漂移和空载荷；
17. `std::barrier` 同起步、固定最大轮数、无 sleep 的公开换代 / 退出并发读取，只接受完整同代次成功、许可拒绝、漂移或已退出空载荷，不接受混代 / 部分组 / 双当前；实际窗口命中如实记录；
18. 主工程 Debug / Release x64、双配置临时项目、strict、UTF-8、工程隔离和临时生命周期检查通过。
