## 1. 目标、范围与完成条件

在 4230、已发布的 L2 公共属性合同、E2 完整存在服务和 L1 中性 CRUD 提供者之上，新建唯一 `L2特征结构服务`，只实现特征定义节点及其固定属性的新增、当前 / 历史完整读取、固定属性初始发布与换代、定义整体退出和引用保护。

本叶不实现特征实例、宿主存在关系、定义引用关系、特征当前值、按存在枚举特征、F2 / F3、状态 / 动态 / 因果、A1 聚合面或任何轮廓 / 颜色 / 位置专用业务函数。特征定义是纯结构，不判断名称、值域、适用性、存在真实性或业务资格。

完成条件固定为：

1. 新建 `L2特征结构.数据.h`，唯一拥有特征定义事实、请求、结果和自身纯值不变式；
2. 新建真实模块 `服务.L2特征结构.ixx`，唯一导出 `L2特征结构服务`，并由主工程按 `ClCompile` 登记；
3. 公开实现特征定义节点新增、固定属性初始、固定属性换代、完整当前 / 历史读取和定义退出五个函数；
4. 定义新增以一份 L1 写集建立一个普通节点；成功载荷是创建代次的完整空属性定义；
5. 固定属性初始以一份 L1 写集同时建立新值并切换当前槽；换代以一份 L1 写集同时建立新值、切换当前槽并退出具名旧值；
6. 初始时同类型已有当前值返回 `引用冲突`；换代时属性未设置返回 `属性未设置`，旧值不符返回 `引用冲突`；
7. 定义退出请求只显式携带该定义当前固定属性值编码组；定义节点与全部当前属性值在一份 L1 写集、同一事实代次退出；
8. 未来 F2 实例等当前关系、值来源或独立材料引用未闭合时，由 L1 当前引用闭包返回 `引用冲突`，F1 不扫描消费者、不补造退出项；
9. 当前完整读取以两次同一期望代次的一致投影取得定义节点和全部当前固定属性；历史读取以前后代次夹取、历史节点和历史属性值组按半开区间重建；
10. 写入成功和精确重复均从首次事实代次的历史节点 / 属性值重建首次原结果，不以调用时当前投影替代；
11. 所有非成功返回空载荷，未找到、已退出、属性未设置、许可拒绝、事实代次漂移、幂等冲突、引用冲突、资源失败和内部不一致精确分账；
12. 生产代码不增加验证专用 DTO、函数、友元、计数器、故障注入、让行点或测试分支；验证只经正式公开入口；
13. 临时验证 cpp / vcxproj / 脚本只保留施工期生命周期；F1 结果记录发布且索引退出后，由后续清理提交删除，施工 / 验证记录、计划、结果提交和 Git 历史继续保留。

struct L2特征定义事实 final {
    L2特征定义身份 身份;

    L2结构结果头 结果头;
    std::optional<L2特征定义事实> 特征定义;
};

struct L2特征定义固定属性新增请求 final {
    L2结构请求头 请求头;
    L2结构幂等身份 幂等身份;
    L2特征定义身份 特征定义;

    L2结构请求头 请求头;

    稳定编码 旧值稳定编码;

    L2结构请求头 请求头;

    L2结构请求头 请求头;

新增头内联纯值辅助：

```cpp
inline bool L2特征定义新增请求有效(
    const L2特征定义新增请求& 请求) noexcept;
inline bool L2特征定义固定属性新增请求有效(
    const L2特征定义固定属性新增请求& 请求) noexcept;
inline bool L2特征定义固定属性换代请求有效(
    const L2特征定义固定属性换代请求& 请求) noexcept;
inline bool L2特征定义退出请求有效(
    const L2特征定义退出请求& 请求) noexcept;
inline bool L2特征定义完整读取请求有效(
    const L2特征定义完整读取请求& 请求) noexcept;
inline bool L2特征定义事实完整(
    const L2特征定义事实& 特征定义, std::uint64_t 截止) noexcept;
```

新增请求要求合同正确、期望代次允许由 L1 裁决且幂等身份非零。属性请求另要求非零期望代次、定义身份和共同属性提交项有效；换代旧值编码非零。退出请求要求合同、非零期望代次 / 幂等 / 定义身份，属性值编码组严格升序、无重复且全非零；空组合法。完整读取当前类别要求历史截止为 0，历史类别要求 `0 < 历史截止 <= 期望事实代次`。

`L2特征定义事实完整` 要求身份非零、生命周期完整且在具名截止可见；固定属性全部满足共同截止投影、无退出，并按“属性类型、值编码”严格升序，同一属性类型至多一项。历史旧截止不得暴露未来退出代次。

固定属性成功结果与 E2 同构：`已提交 / 精确重复`、非零且相等的截止 / 变更代次、一个当前新属性；初始不得有旧属性，换代必须有同类型、不同值编码且在变更代次退出的旧属性。退出成功只接受身份匹配且节点与全部属性均在变更代次退出的完整定义。其它状态所有载荷为空。

模块内部的状态映射、材料转换、当前节点 / 属性投影、历史重建、写集读回和成功形状辅助保持最小可见性，不导出。纯值机械判断登记 `无适用错误分支`；调用 L1、分配或组合事实的辅助登记 `向上送出`。公开服务是本模块结构化非成功责任边界，不新增日志；`std::bad_alloc` / `std::length_error` 映射资源失败，其它未处理异常映射内部不一致。

本叶不涉及跨仓锁、共享锁升级、序列化或恢复；服务只调用 L1 公开值式接口，不持有仓库锁。所有新函数、变量、业务结构、成员和文件名使用中文。

## 6. 本地键、创建与属性修改事务

模块内部本地键固定为：

```cpp
inline constexpr std::uint32_t 特征定义节点本地键值 = 0x0203'0001U;
inline constexpr std::uint32_t 特征定义固定属性值本地键值 = 0x0203'0301U;
```

定义新增的唯一 L1 写集为：`节点=[{定义节点本地键, 普通, 无属性类型表示}]`，关系 / 值 / 槽变更 / 退出全空。L2 幂等身份完整映射为 L1 幂等键。成功 / 精确重复要求唯一新编码映射匹配节点本地键、首次事实代次和发布 / 重试边界正确，再以单事实历史读取重建创建代次的空属性定义；后续属性不得污染首次结果。

固定属性两写复用 E2 已验证路径：先构造不可变 L1 写集，探测当前代次；新幂等身份的旧期望恰一次直提原写集由 L1 裁决漂移，原幂等身份仍由 L1 收敛首次结果；同期望时才做当前定义 / 槽前置，然后恰一次提交。

初始属性写集：`值=[{属性值本地键,定义,类型,材料,来源}]`、`属性槽变更=[{定义,类型,属性值本地键}]`，其它组空。目标必须是当前普通定义，具名属性槽必须未设置；已有当前值返回引用冲突。

换代写集在初始基础上增加 `退出事实=[旧值稳定编码]`。当前槽未设置返回属性未设置；当前值编码不等于请求旧值返回引用冲突；所属、类型、材料、来源、槽或生命周期矛盾返回内部不一致。

属性成功 / 精确重复从首次代次的历史属性值组取得新值，并用单事实历史核对可选旧值；新编码映射必须唯一匹配属性值本地键。任一错映射、缺项、多项、混代或读回矛盾返回内部不一致，不二次提交、不补偿已发布事实。

## 7. 完整当前与历史读取

### 7.1 当前读取

第一次 L1 一致当前投影只请求目标定义节点，要求当前普通节点；其属性槽按类型严格升序，类型和值编码非零且无重复。第二次在同一期望代次重读节点，并按第一次槽组请求全部具名属性值。第二次槽组必须逐字段等于第一次；每个属性项必须成功并回显目标定义 / 类型，槽值与值事实编码相等，值事实所属、类型、材料、来源和生命周期完整。

两次读取都必须在请求期望代次成功。许可拒绝、事实代次漂移和资源失败按同名状态返回空定义；目标未找到 / 已退出精确返回；缺项、复义、错槽、混代或节点 / 值矛盾返回内部不一致。成功属性按“类型、值编码”稳定排序。

### 7.2 历史读取

历史读取固定流程：

```text
读取当前事实前代次并要求等于请求期望代次
-> 读取定义节点单事实历史
-> 读取中性历史属性值组(定义, 历史截止事实代次)
-> 读取当前事实后代次并要求仍等于请求期望代次
-> 按 [创建代次, 退出代次) 形成完整截止投影
```

历史属性值组必须回显所属定义、历史截止和请求期望当前代次。同一属性类型在截止至多一个有效值；晚于截止的退出代次在旧截止投影中清空。节点保存的当前属性槽只做普通节点结构校验，不决定历史属性或补历史缺项。

定义在截止前未创建返回未找到；截止等于或晚于退出代次返回已退出；前后代次变化返回事实代次漂移；历史组入口 / 资源失败精确映射；任何半结构、复义或生命周期矛盾返回内部不一致。任一失败均不返回部分定义。

## 8. 定义退出与引用保护

退出请求只携带特征定义所有者当前固定属性值编码严格升序组，不携带未来实例关系、宿主存在、定义引用、特征值或其它消费者事实。

同期望代次先调用完整当前读取形成权威快照，并将实际固定属性值编码组与请求逐字段比较。缺项、多项或错项返回 L2 引用冲突，零提交。闭包一致后形成唯一 L1 写集：节点 / 关系 / 值 / 槽变更全空，`退出事实` 为定义节点和全部当前属性值的全局升序唯一组。

L1 在候选前执行当前引用闭包保护。未来 F2 实例对定义的当前关系、其它关系、值来源或独立材料引用未在合法写集闭合时返回 `L1中性写入状态::引用冲突=10`；F1 精确映射为 L2 引用冲突。F1 不扫描实例服务，不自动退出消费者，不 import F2，也不因当前 F2 尚未实现而删除该保护门禁。

成功 / 精确重复要求空新编码映射、首次事实代次与发布 / 重试边界正确；按首次代次读取定义节点和请求每个属性值的单事实历史，全部退出代次必须等于变更代次，再形成稳定排序的 `已退出特征定义`。任一缺项、错类、错所属或生命周期矛盾返回内部不一致，不回滚已发布事实。

调用方必须先经引用所有者退出外部引用，再使用新期望代次和新幂等身份退出定义；不得用原引用冲突幂等身份改变请求语义。

## 9. 状态、幂等与非成功收口

模块内部写入映射显式覆盖全部 L1 状态：成功 / 精确重复 / 入口拒绝 / 未找到 / 已退出 / 事实代次漂移 / 幂等冲突 / 资源失败 / 内部不一致 / 引用冲突分别映射到对应 L2 状态；不允许 default 吞掉新状态。

非成功优先级固定为：

```text
纯值非法 -> 入口拒绝
既有幂等键 -> 精确重复 / 幂等冲突
新幂等身份旧期望 -> 事实代次漂移
目标未找到 / 已退出 -> 同名状态
属性未设置 -> 属性未设置
旧值或显式属性闭包不符 -> 引用冲突
L1 外部当前引用未闭合 -> 引用冲突
许可拒绝 / 资源异常 -> 许可拒绝 / 资源失败
成功形状、编码映射、节点、槽、值或历史矛盾 -> 内部不一致
```

所有写入口恰一次 L1 提交。同一幂等身份只绑定完整请求逐字段语义；精确重复返回首次原结果且不推进代次；同键异请求幂等冲突且零变化。非成功不携带定义 / 属性，不伪造变更代次；安全取得的实际当前代次只用于对应漂移或冲突截止。
