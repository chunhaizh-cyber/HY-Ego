日期：2026-08-12

## 1. 目标与完成条件

在 M1 真实结果上新建唯一 `L2语言结构服务`，持有语言、词条、词性三个不可交换 owner，完成三族身份来源、语言 / 正式词性 / 词条 CRUD、规范键精确查找及可清空重建词索引。服务只保存调用方已经规范化的结构，不分词、不判断词性、不裁决概念。

## 2. 依赖与门禁

直接依赖 M1 实施 / 清理结果、4240 和总详细设计。M1 必须进入 `main`、经接受并退出，最终材料 DTO / getter 匹配；当前代码段、普通应用、根工程和验证资源释放后才可激活。

## 3. 允许文件

`海中鱼巣/领域/L2结构公共.数据.h`、`海中鱼巣/领域/L2语言结构.数据.h`、`海中鱼巣/领域/服务.L2语言结构.ixx`、`海中鱼巣/装配.普通应用.ixx`、根工程 / filters、三份 `L2语言词条结构参数验证` 临时文件及两份 CONCEPT-L1 永久记录，共十路径。禁止修改 M1、世界六服务、概念服务、启动入口和流程图。

## 4. 接口和事务

公共数据头追加 `L2语言身份、L2词条身份、L2词性身份` 及 `L2节点族::语言/词条/词性`。语言数据头唯一拥有三族来源 DTO、完整事实和写读退请求结果。

公开面冻结为：

```text
读取语言身份来源 / 读取词性身份来源 / 读取词条身份来源
新增语言 / 读取完整语言 / 退出语言
新增正式词性 / 读取完整词性 / 按语言读取全部当前词性 / 退出正式词性
新增词条 / 读取完整词条 / 按规范键读取词条 / 退出词条
重建当前词索引
```

每族初始化和节点 + 归属同写服从 4240。词条写集由词条节点、归属、语言关系、规范化合同材料关系、词面材料关系组成；写前以同一期望截止读回语言和两份材料。唯一键精确服从 4240；索引只保存候选身份，命中后回源。三个 owner 和端口不得合并为运行时可选 owner。普通应用在材料之后按语言、词条、词性顺序形成 owner 并发布唯一服务。

## 5. 验证与声明

经公开入口覆盖三族来源、语言 / 词性唯一、词条规范键唯一、坏 UTF-8 材料类别、精确重复 / 冲突、索引清空重建、当前 / 历史和引用保护退出。根工程与专项双配置、strict、diff、UTF-8 / XML 通过。不得声明分词、概念维度、名称候选或语言理解完成。
