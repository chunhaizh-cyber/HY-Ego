## 5. 检查矩阵

1. 错合同、零 owner、零属性类型、零守卫、零预算分别入口拒绝；
2. 当前 owner + 当前属性类型 + 无匹配值成功空组；
3. 同 owner 同属性类型一个与多个值完整、严格升序读回；
4. 同属性类型跨 owner 严格隔离；
5. 同 owner 不同属性类型严格隔离；
6. 预算等于数量成功，少一返回数量预算不足且零载荷；
7. 陈旧守卫返回锁内当前代次且零载荷；
8. owner / 属性类型未找到与已退出分账；
9. 当前普通节点作为属性类型时入口拒绝；另一 owner 的合法属性类型成功空组；
10. 索引中关系及其它值角色候选不会混入；
11. 读取前后事实代次不推进，既有来源 / 当前 / 历史 / 一致读取保持。

资源耗尽、私有索引损坏、共享锁长期公平和跨进程恢复没有公开稳定注入时如实 `NOT_RUN`，不得建立生产故障 seam。
