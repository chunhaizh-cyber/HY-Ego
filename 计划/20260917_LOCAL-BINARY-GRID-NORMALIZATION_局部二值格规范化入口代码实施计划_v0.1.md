# DATA-L2 局部二值格规范化入口代码实施计划

身份：`LOCAL-BINARY-GRID-NORMALIZATION`

版本：v0.1

状态：待激活

基线：`664c7fb9d3f2f92498cd9b7f2003bd4fada10e00`

## 1. 目标与完成条件

按同名详细设计 v0.1，在现有局部二值格格式服务中实现唯一 DATA-L2 规范化入口：原始完整轮廓/体素组经完整格式核验后，逻辑全零改写为 `[0,类型,N]`，其它合法组原样返回；解析入口改为只接收成功规范化载荷。

完成条件是旧 v1/v2 裸组解析 ABI 物理退出、v3 规范化及解析入口唯一声明/定义、所有失败零载荷、专项 Debug/Release 成功、主工程两配置 Rebuild 已尝试、施工/验证记录发布。保存、DATA-L3、普通应用、设备、特征值服务和业务消费者不属于完成条件。

## 2. 具名依赖与激活门禁

直接依赖 `LOCAL-BINARY-GRID-U64-PARSER` 发布其 v0.3 的 `.h/.cpp` 代码结果。该计划目前占用同一生产文件；依赖未发布前本计划不得开工、不得登记代码文件、不得改其 WIP。

`U64-GROUP-VALUE-FACT-PERSISTENCE` 不是本计划编译依赖：本叶不保存值。其 B2 API 发布后，另一个具名消费者计划才可把规范化载荷送入通用保存服务。
