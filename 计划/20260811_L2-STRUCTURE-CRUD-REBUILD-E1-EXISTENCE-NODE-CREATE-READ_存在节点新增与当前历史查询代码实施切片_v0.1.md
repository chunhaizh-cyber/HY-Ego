## 1. 目标、范围与完成条件

作为 L2 六类纯结构重建的第二个代码叶，在 4230 合同版本 1 和 S1 实际发布的公共 L2 合同之上，实现 `L2存在结构服务` 的存在节点新增、当前单节点读取和历史单节点读取。

本叶只建立一个无固定属性的普通存在节点。E2 才拥有存在固定属性换代、存在退出和被引用结构查询；F1 及其后继才拥有特征定义、特征实例和值。场景成员关系仍由场景所有者负责，本叶不得 import 场景服务、写场景成员关系或判断存在真实性与业务资格。

完成条件固定为：

1. S1 的公共 L2 合同实际接口与本计划冻结的消费合同逐项匹配，E1 只新增存在 DTO 与存在服务所有者，不复制共同实体；
2. `新增存在节点` 把一份合法请求机械映射为恰一个普通 L1 节点、零关系、零值、零属性槽变更、零退出项的不可变中性写集，并恰一次提交；
3. 首次成功从唯一新编码映射返回 `L2存在身份`，精确重复返回同一身份和首次变更代次，同键异义返回幂等冲突；
4. `读取存在节点` 按显式当前 / 历史类别返回完整 E1 存在事实，当前读取经一致当前投影，历史读取由同一事实代次的前后探测夹住；
5. 生产外自定义参数验证覆盖合法新增、精确重复、同键异义、当前读、历史读、非法请求零变化和事实代次漂移；
6. 新模块进入生产工程但不接入启动、普通应用上下文、场景服务、特征服务或聚合面，Debug / Release x64 保持完整编译链接。

## 6. 新增存在节点的精确 L1 写集

### 6.1 写前与幂等

入口先校验合同版本 1 和非零 L2 幂等身份。L2 幂等身份完整 64 位原样映射为 `L1中性写集幂等键`，不得截断、哈希或另建进程内幂等账。

存在节点固定使用家族专属本地键 `0x0202'0001U`。本地键只参与 L1 请求规范化和新编码定位，不是公开稳定编码；它与 S1 的 `0x0201'0001U` 明确分族，使同一 L2 幂等身份误用于不同完整请求时由 L1 返回冲突，而不会把一个 L1 节点复用为两个结构族。

### 6.2 唯一写集

```text
合同版本 = L1中性CRUD合同版本
期望事实代次 = 请求.请求头.期望事实代次
幂等键 = { 请求.幂等身份.值 }
节点 = [ { 本地键=0x02020001, 种类=普通, 属性类型表示=null } ]
关系 = []
值 = []
属性槽变更 = []
退出事实 = []
```

形成后恰一次调用 `L1事实基座服务::提交中性写集`。不得预探测、预分配稳定编码、调用当前代次读取后改写请求、重试提交或在 L1 之外保存候选。

### 6.3 成功形状与读回

首次成功必须同时满足：L1 状态成功、合同版本与幂等键回显一致、事实代次非零、形成权威发布、重试边界不适用、新编码映射恰一项且本地键为 `0x02020001`。

精确重复必须同时满足：L1 状态精确重复、合同版本与幂等键一致、事实代次非零、未形成新发布、重试边界为原幂等键读回收敛，并返回同一唯一映射。

两类成功均用该编码调用 `读取中性历史事实`，核对其为同编码普通节点、创建事实代次等于 L1 首次结果代次、属性类型表示为空；在 E1 基线下当前属性必须为空。成功形成：

```text
结果头.状态 = 已提交 或 精确重复
结果头.事实截止代次 = L1 首次结果事实代次
结果头.变更事实代次 = L1 首次结果事实代次
存在 = 新身份 + 创建生命周期 + 空固定属性组
```

读回缺失、类型不符、映射重复、映射错键、代次矛盾或成功形状不完整统一返回 `内部不一致` 且不携带存在。

## 7. 当前与历史读取

### 7.1 当前

当前读取构造一份 `L1中性一致当前读取请求`：期望事实代次取 L2 请求头，只选择存在身份对应的一个节点，关系、值、属性值、源关系组和目标关系组全部为空，并恰一次调用 `尝试读取中性一致当前投影`。

成功必须满足合同 / 期望 / 读取代次一致、节点结果恰一项、其余五组为空、项目查询编码一致、项目状态成功、节点为普通、属性类型表示为空、生命周期合法且当前属性为空。返回 `已读取`、非零事实截止代次、无变更代次和完整 E1 存在事实。

顶层入口拒绝 / 许可拒绝 / 事实代次漂移 / 资源失败按同名 L2 状态映射；顶层内部不一致以及项目种类不匹配映射内部不一致；项目未找到 / 已退出分别映射同名状态。失败材料必须为空。

### 7.2 历史

历史读取不把当前入口伪装成历史，固定顺序为：

```text
读取中性当前事实代次并精确比较请求期望代次
-> 读取中性历史事实(存在稳定编码)
-> 再次读取中性当前事实代次并精确比较请求期望代次
-> 两次当前代次相同且历史为普通节点时形成结果
```

任一前后代次不等于请求期望值返回 `事实代次漂移`，不携带存在。前后代次探测的入口拒绝 / 资源失败按同名状态映射，成功以外的其它状态或合同矛盾映射内部不一致；历史读取的入口拒绝、未找到、资源失败和内部不一致分别分账。历史事实必须是同编码普通节点、创建代次非零且不晚于请求截止，退出代次为空或不晚于请求截止，属性类型表示为空；历史返回的读取事实代次必须精确等于节点退出代次（存在时）或创建代次（未退出时）；E1 基线下固定属性组仍必须为空。

成功返回 `已读取`，结果截止代次精确等于请求期望代次，生命周期保留创建与可选退出代次，固定属性组为空。该双代次夹取只保证 E1 单节点历史读取，不替代 E2 对属性历史、退出和引用结构的完整重建。

## 8. 状态映射与失败收口

| L1 来源 | L2 状态 |
| --- | --- |
| 写入成功 / 精确重复 | 已提交 / 精确重复 |
| 写入入口拒绝 / 事实代次漂移 / 幂等冲突 / 资源失败 / 内部不一致 | 同名 L2 状态 |
| E1 一节点写入出现 L1 未找到或已退出 | 内部不一致 |
| 一致读取入口拒绝 / 许可拒绝 / 漂移 / 资源失败 / 内部不一致 | 同名 L2 状态 |
| 当前项目未找到 / 已退出 | 同名 L2 状态 |
| 当前项目属性未设置或种类不匹配 | 内部不一致 |
| 历史读取成功 / 入口拒绝 / 未找到 / 资源失败 / 内部不一致 | 已读取 / 同名状态 |
| 历史入口意外返回已退出或属性未设置 | 内部不一致 |

所有非成功返回合同版本 1、能安全取得的事实截止代次、空变更代次和空存在；`std::bad_alloc` 与 `std::length_error` 映射 `资源失败`，其它异常映射 `内部不一致`，异常路径截止代次为 0。不得抛出到调用方、记录成功日志或用默认身份补齐。`未实现`、`属性未设置`、`引用冲突` 在 E1 公开操作中没有合法产生路径。
