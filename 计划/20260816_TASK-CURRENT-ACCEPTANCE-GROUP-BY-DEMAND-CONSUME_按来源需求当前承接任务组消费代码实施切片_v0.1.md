## 5. 失败收口

- DATA 空组返回已读取，optional 有值、vector 为空且事实截止为 G0；父级才解释当前任务树不存在。
- 数量预算不足独立返回且零组；成功组超过预算、重复任务 / 关系或错端点 / 角色 / 当前性收敛内部不一致。
- 运行代次只匹配 BIZ 固定配置，不进入 DATA 请求、不筛关系。
- `std::bad_alloc`、`std::length_error`映射资源失败；未知异常映射内部不一致；成功交换前不发布部分组。
- 最终 ABI 改变一次组读、空组成功、非零 G0、全部关系、总预算、完整端点或失败零组时零写停止并具名退回计划支撑。
