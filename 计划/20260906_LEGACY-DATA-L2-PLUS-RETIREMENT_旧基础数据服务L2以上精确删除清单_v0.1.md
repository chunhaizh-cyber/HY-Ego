## 1. 口径与计数

本清单由基线树上的机械闭包和旧链专属伴随文件形成：

- 23 个 `服务.L2*.ixx` 的反向 module import 闭包；
- 22 个 `L2*.数据.h` 的反向本地 include 闭包；
- 两闭包并集后补入 12 个承载旧 L2 身份/请求/事实/初始化的专属伴随文件；
- 级联退出只服务于已删旧专项的 2 个验证源、2 个验证工程与 2 个运行脚本；
- 旧 HEAD `应用服务.特征概念类.ixx` 单独按 source blob 从 index 退出，外部重写版工作树文件不物理删除。

结果冻结为：

| 项目 | 数量 |
| --- | ---: |
| 反向 import 闭包 | 64（62 ixx + 2 cpp） |
| 反向 include 闭包 | 70 |
| 两闭包并集 | 103（64 ixx + 37 h + 2 cpp） |
| 旧链专属伴随 | 12（1 ixx + 8 h + 3 inl） |
| 验证工程/脚本级联 | 4（2 vcxproj + 2 ps1） |
| 物理删除 | 119（113 生产 + 6 验证） |
| 旧特征概念版本仅 index 删除 | 1 |
| staged 删除 | 120 |

执行者只可物理删除第 2.1 节 119 个精确路径，并按第 2.2 节只删除一个旧 HEAD source blob 的 index 版本。source blob 不一致即停止并退回计划支撑；不能用同名、近似名或重新解释种子临场改清单。
