## 5. 实施合同

1. 新合同模块同时唯一导出 I1 / I2 两个数据头，只 import `海中鱼巣.领域.服务.L2场景结构`取得所需类型可见性且零服务对象 / 调用；普通应用删除两头 `export include`并改 import，自我线程删除 import 普通应用并 import 合同模块。
2. 普通应用私有三个独立无回绕原子序列，分别签发运行代次、时间纪元和自我线程逻辑身份；进程内唯一、允许跳号、耗尽零回绕，零 DATA / 墙钟 / 地址 / 系统线程 ID / 日志来源。
3. 事实范围固定使用具名 `自我治理事实范围版本`合同常量；不得用裸数值、DATA截止或运行代次替代。
4. L3装配按生命周期服务 -> 单调适配器 -> 完整秒服务 -> 事实版本服务 -> 自我线程顺序构造；任一失败候选为空并逆序释放。
5. 普通应用成员声明顺序保证自我线程最先析构并 join；所有 provider 和其底层依赖覆盖线程完整生命周期。
6. 自我线程构造只保存最终8110发布端口、两个BIZ provider稳定借用和值式配置；零邮箱、零线程、零provider读取。
7. 创建调用后继构造邮箱后立即构造路由，再允许创建物理线程；路由为唯一冻结消费者且邮箱冻结数仍为0。不得公开邮箱 / provider getter或建立第二路由。
8. 本叶生产源码必须保持零 `自我治理批次路由::冻结当前治理批次` 调用；线程入口仍只停在关闭门或沿 SELF-THREAD 既有安全停止路径退出。本叶不新增 DATA 服务调用，不调用事实截止或完整秒读取，不实现父处理槽、治理循环、运行门或停止收口见证。
9. 后继首个路由调用的激活门必须先闭合“停止新输入 -> 停止邮箱并唤醒 -> 路由返回 / 排空 -> 双空或互斥未完成见证 -> join”；不得以本叶的未调用路由析构结论替代真实阻塞等待收口。
