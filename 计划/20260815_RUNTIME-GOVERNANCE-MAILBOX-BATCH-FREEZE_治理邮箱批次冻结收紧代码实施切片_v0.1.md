只追加详细设计第3节两个冻结状态和四个拒绝原因；原有数值和字段顺序不变。入口追加 `noexcept`，负等待在取锁前请求拒绝。非空队列先守卫计数上界，再在锁内完整复制为局部 vector；候选完成前不得递增计数、移动或清除原消息。最后只用默认 allocator 的 vector swap、deque clear 和已检查赋值一次提交结果，并静态确认消息可复制 / 析构不抛出及 swap 无抛出。
