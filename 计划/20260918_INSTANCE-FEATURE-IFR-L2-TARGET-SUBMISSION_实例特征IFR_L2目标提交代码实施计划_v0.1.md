# INSTANCE-FEATURE-IFR-L2-TARGET-SUBMISSION 代码实施计划 v0.2

状态：可执行。基线：`99e9aeaa`；直接依赖已发布 IFR 投影读取 v0.2、v2 布局和存在身份/已知准确特征只读合同。

## 目标

在 `存在类数据服务` 实现唯一中性写入口 `提交IFR目标结构` 及其公开纯值 DTO。它以 G0 的完整 IF/R 前态和规范化目标 R 项组形成或换代存在 owner 的 IF/R 结构；不解释首个 R、命中或归组，不调用出生、规则、概念汇聚或当前采用。

## 公开 ABI

```cpp
enum class 实例特征IFR提交状态 : std::uint8_t {
  已提交=1, 精确重复=2, 目标已满足=3,
  入口拒绝=4, 未找到=5, 已退出=6, 数量预算不足=7,
  事实代次漂移=8, 前态冲突=9, 引用冲突=10,
  幂等冲突=11, 已可能发布=12, 资源失败=13, 内部不一致=14
};
struct 实例特征IFR目标R项 final {
  特征R区间材料 材料;
  std::vector<特征信息身份> 形成成员;
};
struct 实例特征IFR提交请求 final {
  std::uint32_t 版本=1; std::uint64_t G0=0; 稳定编码 E{};
  特征类型身份 FT;
  std::optional<实例特征IFR完整投影> 预期完整投影;
  std::vector<实例特征IFR目标R项> 规范化目标R项组;
  L1所有者范围写入幂等身份 幂等身份;
  std::uint64_t F成员上限=0, R项上限=0, 关系上限=0;
};
struct 实例特征IFR提交结果 final {
  std::uint32_t 版本=1;
  实例特征IFR提交状态 状态=实例特征IFR提交状态::入口拒绝;
  std::uint64_t Gread=0, H=0;
  std::optional<std::uint64_t> 首次H;
  std::optional<实例特征IFR完整投影> 当前投影;
  实例特征IFR提交请求 原请求;
  bool 成功(const 实例特征IFR提交请求&) const noexcept;
};
```

`原请求`始终按值回显。只有三个成功状态携带完整 `当前投影`；`目标已满足` 的 `H=G0` 且无 `首次H`，`已提交`/`精确重复` 的 H 为经读回确认的当前结构截止。失败一律清空 `当前投影` 与 `首次H`，保留 `Gread/H` 到最后已确认的事实读回，禁止用空投影伪装成功。

## 冻结状态与写入合同

- 参数、目标规范化、预算或幂等身份非法为`入口拒绝`；R项/成员/角色/材料来源等结构违反为`引用冲突`；预期与 G0 成功投影不等为`前态冲突`；同键不同规范化写集为`幂等冲突`。
- IFR 读取及首建 E 身份/关系读回的未找到、退出、预算、代次、资源、内部状态分别映射同名状态；无法识别的 L1 写失败为`内部不一致`，发布结果未知为`已可能发布`，只以原键读回收束。
- `预期`非空必须逐字段等于 G0 成功投影。读取`未找到`时只接受空预期：同 G0 `确认当前存在结构身份(G0,E)` 必须成功，且直接读取 `E→IF` 关系组为空，才可首建。
- 最终 IF成员集固定为“前态 IF成员集 ∪ 本次新增F”。前态已有成员一个不得丢失；新增F只可在 G0 由 `确认当前已知准确特征({1,G0,E,F})` 成功、且类型为 FT 后加入。规范化目标 R项形成成员并集必须恰等这个最终集合。
- `E→IF`、`IF→R集合`、`R集合→版本` role=`1`；`IF→F`、`版本→R项`、`R项→F` 对目标稳定编码严格升序 role=`1..N`。材料值唯一为 v2 U64组且来源节点等于 R项自身。任何偏离为`引用冲突`。
- 首建一次写入 IF/R集合/版本/R项/材料及六类关系；后续仅退出旧 `R集合→版本`，旧版本与 R项历史保留。材料和形成成员相等的 R项复用。要求改写既有 IF→F role 的目标拒绝零写。
