## 4. 固定目标合同

实现详细设计第4—8节全部 DTO、根函数与私有状态机：

```cpp
explicit L1实例特征批次数据操作(L1事实基座服务& L1) noexcept;

L1特征批次附属提交结果 提交带特征批次记录(
    const L1写集请求& 请求,
    const L1特征批次发布记录草案& 草案);
```

- P38 `读取发布记录(L1特征批次身份) const` 签名、七状态、try-lock和深副本行为不变；
- 私有参与者精确实现 P37 八个回调，不 export、不返回地址；
- 首次成功只由 P37 单次内部提交形成；精确重复参与者0调用，只按批次读取 P38 首次记录并互证内部首次L1键/意图摘要绑定；
- 仅已提交/精确重复携带完整记录和首次映射；发布后失败只携带已发布代次与 `L1发布已存在=true`。精确重复不表示本次推进代次。

## 6. 事务、失败与禁止实现

固定锁序：L1事务域独占许可 -> 本账独占许可。参与者持账许可覆盖复核、候选、确认、L1发布、P15同锁读回和释放/隔离；不得持账许可反向读取 L1/P8/P36/SQL/材料。

```text
禁止第二4170账、第二L1提交或事务后补账
禁止公开参与者、锁、候选、私有P37入口或草案写权给L2/P32
禁止参与者重算请求意图/执行证据摘要
禁止把本次草案或本次执行证据用于P15精确重复语义比较
禁止记录复制原始值材料、对象版本或生命周期字段
禁止末区分配、异常、失败分支或删除已发布记录
禁止复用/包装旧句柄版参与者
禁止顺带聚合P36、形成最终批次发布者或运行期接线
```

准备前异常按资源失败/内部不一致收口并逆序撤销。确认、撤销、关闭撤销、发布、释放、隔离和析构必须 `noexcept`。撤销不完整或发布后读回矛盾必须单调隔离 L1 与本账，不返回部分成功。
