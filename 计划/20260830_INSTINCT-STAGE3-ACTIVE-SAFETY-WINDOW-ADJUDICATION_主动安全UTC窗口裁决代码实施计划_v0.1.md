计划身份：`INSTINCT-STAGE3-ACTIVE-SAFETY-WINDOW-ADJUDICATION`

## 1. 目标与完成条件

在现有本能被动维护只读组合模块中实现显式 UTC 窗口主动安全变化裁决。完成必须同时满足：

1. 同一 G0 完整消费基础快照、安全根定义绑定的来源规则和永久变化账；
2. 规则版本 1 显式空集合 + 永久账合法空组，唯一成功返回 `未改变A`；
3. 规则版本 1 下任意非空变化组均 `来源未裁定`，不得降级为未改变；
4. 两次基础快照捕获事实、定义、当前值、游标或完整秒漂移；
5. 不选择 UTC / 单调窗口，不写 A/V/状态/动态/游标，不改变值域、L/H 或定义版本；
6. 两配置、专项、ABI consumer、strict 和精确差异门禁通过。

## 6. 验证矩阵

- 请求：合同、基础形状、UTC 半开区间、I64 上界、数量预算；
- 规则：未发布、规则与定义版本错配、规则 1 显式空；
- 永久账：未登记、合法空、非空、预算不足、集合不闭合、引用冲突；
- 裁决：空组唯一 `未改变A`，非空组唯一来源未裁定；
- 当前性：G0、定义、当前值、游标、运行代次、时间纪元、时间源和完整秒前后漂移；
- 不变量：值域 `0..INT64_MAX`、定义版本 1、L/H 和既有公开 ABI 零变化；
- Debug / Release 根工程；扩展专项实际运行；Debug / Release `/GL + /LTCG` ABI consumer；
- `python .\tools\check_specs.py --strict`；切片和 cached `git diff --check`。
