## 4. 冻结测试接口、稳定模式与生命周期

全部故障测试实体和分支只允许存在于：

```cpp
#if defined(HY_EGO_ENABLE_STRUCTURE_COMMIT_FAULT_SELF_TEST)
// P1A2Q 专项自检实体和分支
#endif
```

### 4.1 可重建索引仓库

```cpp
enum class 可重建索引精确读取内部损坏测试种类 : std::uint8_t {
    已发布候选事务序号非零 = 1,
    记录键错配 = 2,
    反向绑定缺失 = 3,
    反向绑定重复 = 4,
    目标权威不可读 = 5
};

bool 测试_令下次结构化精确读取模拟内部损坏(
    可重建索引精确读取内部损坏测试种类 种类) noexcept;
```

合法枚举写入共用原子字段稳定值3—7；非法底层值返回 `false` 且不改字段。资源/其它异常设置函数继续写1/2。`读取索引物理键结构化` 只在合法键后一次 `exchange(0)`，3—7依次强制候选事务序号、记录键、反向存在、反向唯一、解锁后目标权威五个真实谓词失败。

### 4.2 节点直接结构查询服务

```cpp
enum class 节点直接当前索引读取内部损坏测试种类 : std::uint8_t {
    节点目标权威读回缺失 = 1,
    关系目标权威读回缺失 = 2,
    关系端点见证不可形成 = 3
};

bool 测试_令下次当前索引读取模拟内部损坏(
    节点直接当前索引读取内部损坏测试种类 种类) noexcept;
```

合法枚举写入共用原子字段稳定值3—5；非法底层值返回 `false` 且不改字段。资源/其它异常设置函数继续写1/2。节点模式只以节点索引键触发；关系读回和端点见证模式只以关系索引键触发。模式与目标种类不匹配不得计入具名场景。

### 4.3 共同生命周期

两个类各自只保留一个 `mutable std::atomic<std::uint8_t>` 字段；六个设置函数共用所属对象字段。设置使用 release store 并覆盖尚未消费模式；非法键不消费，合法键后一次消费，第二次同输入自动恢复。宏关闭时两个枚举、六个设置函数、两个字段、测试异常和全部注入分支均不存在。

## 5. 唯一夹具形成合同

专项自检模块私有新增：

```cpp
struct 精确索引查询已发布夹具 {
    索引物理键 节点索引键;
    索引物理键 关系索引键;
    节点句柄 节点目标;
    关系句柄 关系目标;
    std::uint64_t 已发布代次 = 0;
};

std::optional<精确索引查询已发布夹具>
形成已发布双目标索引夹具(
    精确索引查询隔离夹具& 夹具);
```

按夹具 v0.1 函数图只调用一次低层执行器。回调内创建并读回两节点、一关系、节点目标索引和关系目标索引；关系索引记录精确为 `{关系索引键, 索引目标种类::关系, {}, 关系句柄}`。全部完整才 `请求提交()`，否则 `请求撤销()`。执行器结果必须已提交；随后取得非零发布代次，并用仓结构化读取和查询服务分别读回两索引。四次结果完整、代次一致且目标匹配才返回夹具。

公开 P1A2 提交服务不参与本函数；不得为了关系夹具修改共享 DTO。夹具形成会写隔离对象；故障注入调用前后才要求代次和六仓导出不变。

## 7. 专项验证矩阵

| 场景 | 第一次调用 | 第二次同输入 | 必须证明 |
| --- | --- | --- | --- |
| 双目标夹具形成 | 单次执行器已提交；两仓/两服务基线读取成功 | 不适用 | 两节点、一关系、两索引同一非零代次发布 |
| 任一候选或读回失败 | 执行器撤销或结构化失败 | 不适用 | 零部分发布，不补写/重建 |
| 索引仓5种内部损坏 | 内部不一致、空记录 | 已读取、原记录 | 正反/权威导出逐值相等 |
| 服务节点目标缺失 | 内部不一致、0、空组 | 成功、原代次、恰一节点 | 六仓和代次不变 |
| 服务关系目标缺失、端点见证不可形成 | 内部不一致、0、空组 | 成功、原代次、恰一关系 | 真实使用关系索引键；六仓和代次不变 |
| 两根资源/其它异常 | 保持资源失败/内部不一致分类 | 恢复正常 | 权威导出不变 |
| 非法枚举设置 | 返回 false | 后续合法读取正常 | 原字段不变 |
| 设置后调用非法键 | 入口拒绝且不消费 | 下一次匹配合法调用命中 | 准入顺序正确 |
| 两实例隔离 | 仅被设置实例命中 | 另一实例正常 | 无跨实例传播 |
| 宏关闭构建 | 测试实体和分支0 | 不适用 | 生产布局和调用边无测试内容 |

六个设置函数和夹具辅助函数的唯一项目调用方均为 `自检.节点直接结构查询.ixx` 内专项根。模式未到达匹配生产节点、目标种类错配、第二次未恢复或夹具绕过执行器，均为失败。
