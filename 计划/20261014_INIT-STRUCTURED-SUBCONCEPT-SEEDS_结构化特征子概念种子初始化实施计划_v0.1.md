## 4. 最小文本与批内符号合同

扩展且仅扩展八词结构：`A 的 分量 N 是 整数区间 L U`。A为概念词面符号；N/L/U均调用既有严格I64字面量解析。解析器不在此判断N非负/维度内或L<=U；这些是后继构造预检。固定词序及所有整数源范围完整保留，不把“分量”或数字伪装正式FT。

在既有公开枚举末尾追加：`初始化最小模板::结构化分量区间`；`初始化源角色::分量序号/区间下界/区间上界`。不改旧枚举数值。定义载荷variant追加：

```cpp
struct 初始化结构化分量区间材料 final {
    初始化符号引用 主体概念;
    std::int64_t 分量序号 = 0, 下界 = 0, 上界 = 0;
};
```

角色来源词序为A=0、N=3、L=6、U=7。只有A产生逐出现概念符号；三个整数是有类型准确材料，不进入符号表。表中结构容量从6扩到8、模板数量从5扩到6；输入匹配仍完整遍历闭集、无递归。原五模板和纯解释零写合同不变。

域初始化只允许三种项：`A 是 一种 B`声明、上述分量域、`A 又称 V`别名。任何旧特征/组成等项在本批返回明确未支持/未覆盖，不能混入构造或略过后说整批完成。

批内局部符号按声明A的字节精确词面键定位，恰一条归类声明确定一个局部声明编号；不是正式概念身份。相同A重复声明即拒绝，不论父是否相同。父B必须精确命中当前显式先天RGB/坐标/尺寸环境之一，不能引用本批子声明作父或凭名称召回猜父。A不得与三个父词面冲突。

全篇先收集声明，再对每个分量/别名主体定位；因此可接受合法的前向出现，但未声明主体、主体多义、非已知父或别名冒充声明键都整批拒绝。同一声明的多处A出现关联同一局部声明，但原出现仍逐项保存。不同A的完整定义若相同，可依法复用正式身份，仅各自增加名称，不能按词面不同时强建两个节点。

每个父的全部有序分量必须恰一条区间：N>=0、可安全转换size_t且小于父分量数；无遗漏/重复（重复同值也拒绝）；L<=U。没有未写分量等于不限制的默认；每个分量范围必须完整给出，即使等于父域。
