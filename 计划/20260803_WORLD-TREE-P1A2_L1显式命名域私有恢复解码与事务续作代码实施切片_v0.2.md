## 4. 精确接口、所有权和物理位置

### 4.1 显式命名域

`海中鱼巣/核心/节点直接结构合同.数据.h` 唯一声明：

```cpp
struct 节点直接节点创建项 {
    节点直接写集局部身份 局部身份;
    节点稳定主键命名域 命名域 = 节点稳定主键命名域::无效;
    节点类型 类型 = 节点类型::未分类;
};
```

服务和数据操作只复制。执行器在第一笔持久准备前复用 `节点直接身份仓库::命名域已定义` 与 `节点直接身份仓库::命名域与节点类型匹配`；合法矩阵只读 v0.2 详细设计的 ABI 1 全量表。节点项按 `(命名域底层值,局部身份值)` 稳定排序，每域独立形成高水位连续键。计划映射命名域必须逐值等于输入字段。

确定性节点创建项编码顺序固定为：

```text
variant标签:u8
局部身份种类:u8
局部身份值:u64
显式命名域:u64
节点类型:u32
```

数值继续使用 v0.1 网络字节序。公开请求意图摘要、执行证据摘要、写集材料、幂等比较、持久证据和恢复材料必须覆盖显式命名域。改变命名域即改变请求语义。本版 `写集规则版本=2`、`材料格式版本=2`；合同版本仍为 `1`。旧版本 `1` 不含显式命名域，直接按不支持拒绝，不双读或升级。

### 4.2 恢复唯一解码链

`海中鱼巣.核心.数据操作.节点直接类型化结构` 新增对持久端口模块的合法 import。具名根函数 `节点直接类型化结构数据操作::恢复` 的公开窄入口冻结为：

```cpp
节点直接恢复数据操作结果 恢复(
    节点直接事务幂等身份 安装实例身份,
    const 节点直接恢复材料读取结果& 材料) const;
```

唯一私有函数 `节点直接类型化结构数据操作::解码恢复写集` 的签名保持：

```cpp
static 节点直接恢复解码结果 解码恢复写集(
    std::span<const std::uint8_t> 材料);
```

具名根函数 `节点直接结构恢复服务::恢复安装实例` 的完整签名不变：

```cpp
节点直接结构恢复结果 恢复安装实例(
    const 节点直接安装实例恢复请求& 请求) const;
```

调用顺序固定为：服务读取端口一次；`确认从未发布` 只调用空域治理入口；`存在事务证据` 把完整值式读取结果借给数据操作；数据操作完成全部尝试审计。若全部尝试均明确撤销且没有见证/准备/未知/损坏，数据操作内部调用既有空域治理入口；否则逐见证 private 解码、聚合强类型请求，再唯一调用 `执行节点直接恢复事务`。执行器不接收原始字节，服务不接收强类型恢复请求。

### 4.3 必须直接删除的旧路径

在白名单中存在即删除，不留废弃符号或未调用兼容壳：

```text
节点类型推断节点稳定主键命名域的 switch/if/查表
无效命名域 fallback 和缺字段旧格式双读
恢复服务内解码、逐尝试聚合或六仓请求形成
数据操作::恢复(const 节点直接恢复结构事务请求&)
第二个解码恢复写集、public/export 解码器或跨模块 friend
新旧恢复入口并存的双路接受
```

不得删除仓库的二元组验证函数、P1A1 当前使用的默认直接开放构造或 P1D 所拥有的跨计划旧生产入口。

1. 从当前 WIP 重核全部白名单差异和真实构建基线；若 WIP 接口已漂移，停止并具名报告，不恢复旧计划语义。

3. 删除旧数据操作恢复签名，形成服务→端口→数据操作原始材料入口→private 解码→执行器强类型规格的唯一链。

5. 在全部代码完成后更新工程登记和专属记录，执行完整静态、构建和运行矩阵。

任何表外命名域组合、摘要/编码不一致、恢复尝试歧义或解码失败都必须在持久准备或六仓候选前拒绝。候选之后的失败、明确未发布见证、部分发布和隔离继续服从 v0.1/4040 合同，不因本版降低门禁。
