## 1. 来源、目标与完成条件

来源具名漂移：`RUNTIME-FACT-CURRENT-CUTOFF-CONSUME v0.1`与`RUNTIME-COMPLETE-SECOND-BOUNDARY-PROVIDER v0.1`的正式 DTO、构造合同和依赖方向均已被当前代码中的另一套实现占用，且旧 ABI 已进入批次路由、自我线程和启动入口；两份原计划白名单无法各自独立修复。

本计划在上游单调时间适配器真实结果进入后，一次完成两个子提供者最终 ABI、删除旧共享 DTO 头并机械迁移全部当前生产消费者。完成必须同时满足：

1. 完整秒服务只消费同实例 `单调时钟适配器`，零直接 `steady_clock`，区间严格为 `[上一+1, 当前]`。
2. 事实版本服务持有同实例 `const L2结构聚合服务&`和值式配置，经存在 const getter读取当前事实代次，成功返回完整 optional 材料。
3. `运行期Provider.数据.h`删除且无兼容别名、fallback、双构造或重复 DTO。
4. 路由、自我线程和启动入口在同一提交中迁移到最终子提供者 ABI，根工程始终保持单一可编译形状。
5. 不声明批次路由目标状态机、T02 最终所有权、自我治理业务或集成验收完成。

## 4. 实施合同

### 4.1 DTO 和提供者

按同名新详细设计第3节执行：

```text
删除旧共享头和工程登记
-> 完整秒模块直接导出自身最终DTO与服务
-> 事实版本模块直接导出自身最终DTO与服务
-> 完整秒import单调适配器
-> 事实版本import L2结构聚合及其实际类型依赖
```

不得保留 `完整秒时钟合同版本`、`事实版本服务合同版本`、`完整秒状态`、裸 `共享事实截止读取结果.共享事实截止`、`时间纪元身份`包装类或旧三参数完整秒构造函数。所有公开名称、字段、状态数值、optional 形状和特殊成员必须与被继承详细设计机械一致。

### 4.2 消费者

- 路由对子结果进行完整状态/optional/回显复核，并保存完整观察、区间和截止材料；不得只保存裸截止或丢失配置回显。
- 自我线程当前构造参数机械改为 `const L2结构聚合服务*`，临时持有 `单调时钟适配器`、完整秒服务和事实版本服务；成员声明顺序保证反向析构时服务先于被借用对象销毁。
- 启动入口只把 `取得L2存在结构服务()`替换为同一上下文的 `取得L2结构聚合服务()`，同步注释；不改变其它启动阶段。
- 当前治理循环只改为通过 getter/完整材料读取所需边界和截止；不得扩展骨架函数或把材料缺失改成成功。

## 5. 实施顺序和失败收口

```text
S0核对上游结果、HEAD/origin、真实ABI、dirty与唯一代码段
-> 在同一未提交代码段迁移两个提供者和DTO所有权
-> 迁移路由、自我线程和启动入口
-> 全仓检索旧DTO/旧构造/直接治理steady_clock残留
-> 专项Debug/Release
-> 根工程Debug/Release fresh Rebuild
-> diff/strict/模块依赖/XML/UTF-8/白名单检查
-> 精确发布并回传交互侧核验
```

任何时候都不得提交只迁移一半的 ABI。若上游接口、L2结构聚合 getter、当前调用点或工程登记发生会改变合同的漂移，保留安全现场并退回计划支撑；普通编译错误和机械字段适配由执行者在本计划范围内修复。
