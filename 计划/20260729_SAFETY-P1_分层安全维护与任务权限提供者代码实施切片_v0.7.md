## 1. 本版修订原因

v0.6 的三个权限公开入口无法机械形成构造期提供者请求：

1. `权限读取请求` 缺维护族和期望当前值版本，也没有枚举维护族的合法接口。
2. `任务权限请求` 缺适用场景、图版本和任务集合版本；`任务排序请求` 缺图版本和任务集合版本。
3. 旧服务合同没有冻结来源请求形成、来源回显、调用次数和失败映射。
4. 旧 F-S104 以完整 `安全组层快照` 同时表达输入和计算后输出，实际代码用零版本层表达材料缺失，违反必选字段和零半结构边界。
5. `读取安全因果分层` 同样是非平凡服务函数，却没有单函数施工流程图和逐节点分析，权限服务不能引用未冻结内部过程。

本版固定裁决：

- 公开权限请求显式携带稳定 `安全权限层来源选择` 组。
- 单任务和排序请求显式携带场景、图版本、任务集合版本和同一来源选择组。
- F-S112—F-S115 分别拥有四个服务入口的来源形成、回显、调用次数和返回合同。
- F-S104 分离完整 `安全组层输入快照` 与 `安全权限材料缺口`，不再接收零版本半结构。
- `D=0` / 无路径保留到未归层来源组；空选择或全部未归层形成五组全零 `权限为零`。

## 5. 精确 DTO 替代

协议模块追加并唯一拥有：

```cpp
struct 安全权限层来源选择 {
    节点句柄 来源需求;
    节点句柄 维护族;
    节点句柄 来源因果信息;
    节点句柄 最终安全结果;
    std::uint64_t 期望当前值版本;
};
```

来源选择组按来源需求、维护族、来源因果信息、最终安全结果升序。四元身份重复、空身份、零期望版本或同身份不同版本为结构拒绝。

`权限读取请求` 精确字段改为：

```text
自我、适用场景、vector<安全权限层来源选择> 安全层来源选择组、
事实截止版本、图版本、权限规则版本
```

`任务权限请求` 精确字段改为：

```text
自我、适用场景、任务稳定句柄、
vector<安全权限层来源选择> 安全层来源选择组、
事实截止版本、图版本、任务集合版本、权限规则版本
```

`任务排序请求` 精确字段改为：

```text
自我、适用场景、vector<安全权限层来源选择> 安全层来源选择组、
候选任务组、事实截止版本、图版本、任务集合版本、
权限规则版本、排序规则版本
```

协议模块新增完整 `安全组层输入快照`，字段为来源需求、维护族、来源因果信息、目标安全结果、最终安全结果、精确深度、优先级组、当前值、值域上下界、低 / 高阈值及图 / 值 / 阈值 / 规则版本；它不含释放倍率。现行 `安全组层快照` 追加维护族和最终安全结果并只作为 F-S104 计算后输出，包含释放倍率。

`权限读取载荷` 追加 `std::vector<安全权限层来源选择> 未归层来源组`。`安全维护事实来源载荷` 追加自我、维护族、适用场景、当前值版本和事实截止版本回显；`安全任务事实来源载荷` 追加自我、适用场景、事实截止版本和任务集合版本回显。

`安全输入版本快照` 保留必选非零图版本和事实截止版本；任务集合、值集合、阈值集合、维护规则、权限规则和排序规则改为 `std::optional`，按结果适用性出现，禁止以零值表达不适用。维护来源只带值 / 阈值 / 维护规则；权限结果带权限规则，存在完整层时再带值 / 阈值 / 维护规则；任务权限追加任务集合；排序结果再追加排序规则。

分层安全维护合同 ABI 和 SAFETY-C1/C2 合同版本保持 v1：#377 尚未形成完成候选，v0.7 在同一未完成合同内修正 DTO 后形成第一份固定候选；任何消费者不得把 v0.6 WIP 当作已发布 ABI。

## 6. 纯值函数替代

F-S104 唯一签名改为：

```cpp
权限读取结果 计算安全五组权限(
    const std::vector<安全组层输入快照>& 有序层组,
    const std::vector<安全权限材料缺口>& 有序材料缺口组,
    const std::vector<安全权限层来源选择>& 有序未归层来源组,
    const 权限读取请求& 请求) noexcept;
```

规则：

1. 完整层组不得含零版本或半结构；缺失层只由具名缺口组表达；D=0 / 无路径只进入未归层组。
2. 三组必须与请求选择组形成无重复、无遗漏的精确分区。
3. F-S104 计算每层释放倍率并形成输出 `安全组层快照`。
4. 完整层和缺口均为空时返回 `权限为零` 完整载荷，五组、四门和已形成总量全零，并保留未归层组。
5. 至少一个完整层且无缺口时五组总量必须为 `1,000,000`。
6. 有缺口时首个缺口组及更高组为零；低组保留；缺口零值不参加完整守恒。

F-S105/F-S106 签名不改，但按新增请求字段完成入口和版本门禁；F-S106 形成单任务请求时必须逐字段复制场景、来源选择、图 / 截止 / 任务集合和权限规则版本。

## 7. F-S112—F-S115 服务编排

### 7.1 F-S112

`安全因果分层服务::读取安全因果分层` 只从公开请求形成图来源请求，调用图提供者一次，复核图身份和版本后调用 F-S102。成功无载荷或身份回显不等为 `内部不一致`；版本不等为 `版本漂移`。

### 7.2 F-S113

`安全任务权限服务::读取安全权限快照`：

1. 复核选择组；
2. 对每项形成分层请求并调用 F-S112；
3. `D=0` / 未归层只记未归层组；
4. `D>=1` 时形成维护来源请求；
5. 维护材料缺失形成已知组具名缺口；
6. 维护成功则复核回显和当前快照，形成完整层输入；
7. 把完整层、缺口、未归层三组和原请求交 F-S104，由 F-S104 复核精确分区并形成成功载荷。

完整层字段映射固定：来源需求取选择项；维护族、来源因果信息和最终安全结果由选择项与当前快照双重核对；目标安全结果、当前值和值版本取当前快照；深度和组取 F-S112；值域 / 阈值取定义；阈值版本等于定义版本，规则版本等于定义规则版本；图版本必须同时等于请求、分层载荷和当前快照。

### 7.3 F-S114

`安全任务权限服务::计算任务安全权限` 从公开请求复制形成权限请求，调用 F-S113 一次；再以自我、场景、截止和任务集合版本调用任务事实提供者一次。双来源身份 / 版本闭合后调用 F-S105。

### 7.4 F-S115

`安全任务权限服务::排序任务执行候选` 按 F-S114 相同规则读取一份权限快照和一份任务事实快照，再调用 F-S106。禁止逐任务重读权限或任务仓。

四函数完整节点、返回和异常映射唯一读取本计划第 2 节四份流程图、逐节点分析和功能确认，不得简化为“读取最新”或通过默认构造补字段。

## 8. 构造、所有权与生命周期

构造签名继续固定：

```cpp
安全因果分层服务(安全直接因果图提供者& 因果图提供者) noexcept;

安全任务权限服务(
    安全因果分层服务& 因果分层服务,
    安全维护事实提供者& 安全事实提供者,
    安全任务事实提供者& 任务事实提供者) noexcept;
```

服务不取得注入对象所有权；注入对象覆盖服务全生命周期。中间完整层、缺口、未归层、权限和任务事实均为函数内值式对象，调用结束销毁；不得保存 span、迭代器、引用或原始指针。

协议模块仍不得 import 核心执行器；只有参与者和数据操作模块允许 import 核心执行器。来源提供者接口不进入公开业务请求或结果。
