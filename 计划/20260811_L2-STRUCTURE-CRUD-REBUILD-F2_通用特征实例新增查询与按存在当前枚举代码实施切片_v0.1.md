## 4. 关系类型登记 DTO 与稳定身份

F1 数据头新增以下登记实体：

```cpp
inline constexpr std::uint32_t L2特征关系类型登记规则版本 = 1;

struct L2特征宿主关系类型身份 final {
    稳定编码 值;
};

struct L2特征定义关系类型身份 final {
    稳定编码 值;
};

enum class L2特征关系类型登记状态 : std::uint8_t {
    已提交 = 1,
    精确重复 = 2,
    已读取 = 3,
    登记未加载 = 4,
    入口拒绝 = 5,
    许可拒绝 = 6,
    事实代次漂移 = 7,
    幂等冲突 = 8,
    资源失败 = 9,
    内部不一致 = 10
};

struct L2特征关系类型登记请求 final {
    L2结构请求头 请求头;
    std::uint32_t 规则版本 = L2特征关系类型登记规则版本;
    L2结构幂等身份 幂等身份{1};
};

struct L2特征关系类型登记 final {
    std::uint32_t 合同版本 = L2结构合同版本;
    std::uint32_t 规则版本 = L2特征关系类型登记规则版本;
    L2结构幂等身份 首次幂等身份{1};
    std::uint64_t 首次期望事实代次 = 0;
    std::uint64_t 建立事实代次 = 0;
    std::uint64_t 事实截止代次 = 0;
    L2特征宿主关系类型身份 宿主关系类型;
    L2特征定义关系类型身份 定义关系类型;
};

struct L2特征关系类型登记结果 final {
    L2特征关系类型登记状态 状态 = L2特征关系类型登记状态::入口拒绝;
    std::uint64_t 事实截止代次 = 0;
    std::optional<L2特征关系类型登记> 登记;
    bool 成功() const noexcept;
};
```

全部结构补齐逐字段默认比较。登记规则固定：私有幂等域 `特征关系类型登记幂等域 = 0x1EULL`，L1 幂等键为 `(域 << 56) | 身份.值`；登记请求只接受合同 1、规则 1、幂等身份 `{1}`。本地键固定为：

```cpp
特征宿主关系类型本地键值 = 0x0203'0101U;
特征定义关系类型本地键值 = 0x0203'0102U;
```

`建立特征关系类型登记` 以一份 L1 写集建立两个普通关系类型节点，关系 / 值 / 槽 / 退出为空。成功 / 精确重复必须取得恰好两个本地键到非零稳定编码的一一映射并按首次代次历史读回；服务私有保存值式定位。`读取当前特征关系类型登记` 只按定位用一次允许重试的一致当前投影读两个普通节点；定位未加载返回 `登记未加载`，不扫描全仓、不猜测编码。

登记节点不承载业务类型名称、宿主资格或定义意义；两个强类型身份只能供特征服务构造 / 识别相应 L1 关系。

## 7. 实例创建的一份 L1 写集

本地键和固定角色为：

```cpp
特征实例节点本地键值 = 0x0203'1001U;
特征实例宿主关系本地键值 = 0x0203'1101U;
特征实例定义关系本地键值 = 0x0203'1102U;
特征实例端点角色值 = 1;
```

实例创建流程固定为：

```text
纯值请求校验
-> 读取完整特征关系类型登记
-> 构造不可变 L1 写集
-> 探测当前事实代次
-> 实际代次 != 期望：恰一次直提原写集，由 L1 裁决重复 / 冲突 / 漂移
-> 同代次：分别公开读取当前宿主存在与特征定义并要求截止一致
-> 恰一次提交同一写集
-> 从三个新编码映射取得实例与两关系编码
-> 以首次代次历史读回节点、关系和两个端点
-> 返回首次完整空值实例或内部不一致
```

写集精确为：

```text
节点 = [{实例节点本地键, 普通, 无属性类型表示}]
关系 = [
  {宿主关系本地键, 源=实例节点本地键, 目标=请求宿主存在,
   类型=登记宿主关系类型, 角色=1},
  {定义关系本地键, 源=实例节点本地键, 目标=请求特征定义,
   类型=登记定义关系类型, 角色=1}
]
值 = []
属性槽变更 = []
退出事实 = []
```

宿主存在读取使用 `读取完整存在(当前)`，定义读取使用 F1 `读取完整特征定义(当前)`；两者结果截止必须等于请求期望代次，事实当前、身份逐字段相等。未找到 / 已退出 / 许可拒绝 / 漂移 / 资源失败按精确状态返回；载荷矛盾为内部不一致。

成功 / 精确重复必须取得三个本地键到三个不同非零编码的唯一映射，首次事实代次和发布 / 重试边界正确。历史读回要求普通实例节点、两条同代次关系、固定类型 / 角色 / 端点和两个端点在首次代次有效；结果当前值为空。任一缺项、多项、错类、错端点、错角色或混代返回内部不一致，不二次提交。

## 8. 单项当前 / 历史完整读取

### 8.1 当前

先读取当前特征关系类型登记。L1 一致当前请求必须包含目标实例节点和两个具名源关系组：

```text
节点 = {实例编码}
源关系组 = {
  {实例编码, 宿主关系类型},
  {实例编码, 定义关系类型}
}
```

实例必须是当前普通节点，F2 阶段当前属性槽为空；两个关系组各恰好一项，源均为实例，类型分别匹配，角色均为 1，目标分别形成宿主存在 / 特征定义身份，关系当前且同截止。随后以同一期望代次分别调用存在 / 定义完整当前读取并核对身份与生命周期。

当前关系多项、缺项、类型 / 角色复义、端点公开读取与 L1 投影不一致、节点出现属性或任一混代均内部不一致。实例未找到 / 已退出按同名状态；登记、许可、漂移和资源失败精确收口。成功返回空当前值的完整实例。

### 8.2 历史

历史流程固定为：

```text
前代次探测 == 请求期望代次
-> 实例节点单事实历史
-> 宿主 / 定义两个历史源关系组(实例, 类型, 历史截止)
-> 宿主存在完整历史读取(同一期望, 同历史截止)
-> 特征定义完整历史读取(同一期望, 同历史截止)
-> 后代次探测仍等于请求期望代次
-> 按半开区间组合空值实例
```

两个历史关系组各恰好一条在截止有效的固定角色关系。端点公开历史结果必须与关系目标、截止和生命周期一致；不得用当前存在 / 定义或当前关系补历史。创建前返回未找到；截止达到实例退出代次时由未来 F3 扩展为已退出；F2 当前没有实例退出写，但读取合同必须接受 L1 历史节点已退出事实并按截止精确分账。

任一前后代次变化返回漂移和空载荷；历史组 / 端点失败按精确状态或内部不一致收口，不返回部分实例。

## 9. 按存在枚举全部当前特征

枚举流程固定为：

1. 调用存在公开完整当前读取，要求请求存在在期望代次完整且当前；
2. 读取当前特征关系类型登记；
3. L1 一致当前投影至少请求 `节点={存在编码}` 和 `目标关系组={{存在编码, 宿主关系类型}}`，防止不存在目标被空组误报成功；
4. 每条目标关系必须类型为宿主关系、角色 1、目标等于请求存在、源为当前普通实例节点、生命周期当前；
5. 对每个唯一源实例调用 `读取完整特征实例(当前)`，要求同一期望代次、宿主等于请求存在且 F2 当前值为空；
6. 按 `特征实例.身份.值` 严格升序返回；同实例重复宿主关系、关系编码重复、单项读取与反向关系不一致均内部不一致；
7. 存在合法且目标关系组为空时返回 `已读取`、非零请求截止、空实例组。

枚举不扫描全仓、不建立第二索引、不缓存组、不循环重试、不 sleep。任何许可拒绝、漂移、未找到、已退出、资源失败或单项矛盾清空整个结果，不返回部分组。

## 10. 状态、幂等与非成功边界

登记使用独立登记状态；实例公开结果使用共同 `L2结构状态`。所有 switch 显式覆盖 L1 当前枚举，不以 default 掩盖新增状态。实例写入的 L1 `引用冲突` 理论上只会来自端点 / 材料保护异常；若到达，精确映射 L2 引用冲突，不降级。

同一实例新增幂等身份只绑定完整请求。精确重复返回首次实例身份、宿主、定义和创建代次，零推进；同键异宿主 / 定义 / 期望为幂等冲突。旧期望新键为漂移；旧期望原键仍直提 L1 收敛首次结果。

非成功优先级：纯值非法 -> 入口拒绝；登记未加载 / 失败 -> 对应映射；既有幂等 -> 重复 / 冲突；新键旧期望 -> 漂移；宿主 / 定义未找到或已退出 -> 同名；许可 / 资源 -> 同名；事实矛盾 -> 内部不一致。所有非成功实例 / 组为空，不伪造变更代次。

`std::bad_alloc` / `std::length_error` 映射资源失败，其它未处理异常映射内部不一致。生产函数不本地记录合法非成功，不增加日志。服务不持 L1 / 存在内部锁，不涉及跨仓锁、序列化或恢复。

## 11. 临时生产外验证矩阵

验证 cpp 只 import L1 公开服务、E2 存在服务和激活后的 F2 特征服务。所有登记、定义、存在和实例均经正式公开入口建立；历史 / 当前事实只经公开读取核对。不 import 仓库，不访问私有定位 / 锁 / 索引 / 幂等账，不复用历史状态 / 动态登记代码。

参数固定为：

```text
--幂等基值 <uint64，默认 31000>
--实例数量 <uint64，默认 3，范围 1..16>
```

临时项目支持 Debug / Release x64、v145、C++20、Unicode 和 `/utf-8`，输出 / 中间目录定向系统临时目录，不进入主工程 / solution。

必过矩阵：

1. 建立两类特征关系类型登记：首次已提交、两个普通类型编码不同且非零；原请求精确重复；读取当前登记逐字段一致；
2. 登记未加载服务实例读取返回登记未加载映射，空载荷；错合同 / 规则 / 幂等身份入口拒绝；
3. 经 E2 / F1 正式入口建立两个存在和两个特征定义；不得用 L1 节点冒充端点成功；
4. 新增一个实例只推进一个代次，节点与两关系同代次，宿主 / 定义 / 角色 / 类型正确，当前值为空；
5. 原实例新增请求精确重复返回首次实例且零推进；同幂等身份改宿主或定义幂等冲突；
6. 不存在 / 已退出宿主或定义、零身份、错合同和旧期望新键精确返回对应非成功且零新实例；
7. 单项当前读取逐字段返回实例、宿主、定义、生命周期和空当前值；不存在 / 已退出实例精确分账；
8. 单项历史读取覆盖创建前未找到、创建截止和后继当前代次，关系 / 端点均按同一历史截止重建；
9. 同一宿主 / 定义创建多个不同实例合法；同宿主不同定义、不同宿主同定义均合法，不增加组合唯一约束；
10. 按存在枚举返回全部且仅返回该存在的当前实例，按实例身份严格升序；另一存在实例不混入；
11. 合法无实例存在返回已读取和空组；不存在 / 已退出存在不得返回空成功；
12. 通过 L1 公开写集建立一条类型相同但角色错误或重复宿主关系的破坏性夹具时，单项 / 枚举必须内部不一致和空载荷；夹具只用于公开结构错误验证，不进入生产代码；
13. 原成功新增在后续代次、端点仍当前时精确重复返回首次结果；同键异请求冲突；
14. 先确定性推进 L1 后以旧期望执行单项 / 枚举，证明漂移和空载荷；
15. 使用 `std::barrier` 同起步、固定最大轮数且无 sleep 的公开写线程并发单项 / 枚举，只接受同代次完整成功、许可拒绝或漂移空载荷，不接受部分组、混代或重复实例；是否命中内部窗口如实记录，不增加测试钩子；
16. 主工程 Debug / Release x64 与双配置临时矩阵通过；验证记录明确 F2 当前值始终为空，不把 DTO 或 F1/F2 成功升级为 F3、生产装配或长期回归完成。

未覆盖 F3 值 / 退出、真实分配失败、长时公平、故障注入、恢复、跨进程、生产消费者、状态 / 动态 / 因果、世界树聚合或独立集成验收。
