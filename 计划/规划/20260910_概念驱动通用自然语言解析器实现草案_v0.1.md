## 1. 目标与确定口径

通用解析器把自然语言转换为可追溯的概念引用、结构化句意、知识补充及对象操作提议。它不是词到字段的字符串替换器，也不把所有词、句、文章都转为新节点。

采用用户本轮明确的学习模型：

- **无到空**：已确定所属概念类别后，建立未知但正式的概念身份；空的是具体内涵，不是身份、类别和结构。
- **空到有**：语句、观察和其它材料围绕该身份补充定义、特征、组成与关系。
- **有到用**：篇章组织条件、目标、过程和结果，支持学习、自我需求确认、任务筹办与方法知识完善。
- 不要求全部理解后才允许任何使用；只允许与已知内容和当前引用闭包相符的具体用途。
- 词、句、文章是学习侧重，不是排他写入边界；一句话也可能给出完整步骤，一篇文章也可能只定义一个概念。

未知正式概念不是临时语言候选，不新建第五概念根或第二概念仓。普通解析的临时符号与学习提交后取得的正式概念身份必须分开。

“通用”指共享语言前端、类型约束、组合语义、来源定位和分流框架，通过具名构式与类别适配器扩展；不承诺任意自然语言都能唯一理解。首版为汉语文字，语音、其它语言及外部模型使用独立适配器，不作为首版必需前置。

## 4. 未知正式概念的最小结构

### 4.1 概念身份先成立

| 内容 | 初建要求 |
| --- | --- |
| 正式概念身份 | 必需，由原概念 owner 经 DATA-L1 分配；与临时符号编号不同 |
| 概念类别/定义合同 | 必需，引用已登记类别合同，确定字段形状和验证规则 |
| 所属本体根 | 必需，由类别映射确定；不能由名词/动词标签直接决定 |
| 引入依据 | 必需，来自明确教学、已知概念约束或可核对的构式类型裁决，关联原材料位置 |
| 已知定义内容 | 可以完全未知，也可以已有部分内容；采用该类别的强类型部分定义 |
| 自然语言名称 | 经词条和名称服务建立关系，概念本体不复制字符串；跨服务分阶段确认 |

建议类别映射为：存在概念→存在根，基础特征概念/二次关系概念→特征根，动态概念→动态根，因果链概念→因果链根。类别合同决定其专属字段；这不是新增本体根。状态不另建概念；场景按存在视角处理；需求、任务、方法首先属于业务信息角色，不能由解析器自行增加对应本体根。

只知道大类、还不能确定所需定义合同的输入，返回类别细分缺口；允许扩展一个经正式批准的大类最小合同，但不能用任意字段包兜底。类别来源未裁决时仍是语言候选，不创建正式未知概念。

### 4.2 未知必须有独立的值语义

部分定义中的每项使用逻辑上等价于下列形式的强类型表示：

```cpp
template<class T>
using 待完善项 = std::variant<未知项, 已知项<T>, 不适用项>;
```

这只是候选表达形状，不是允许跨领域持久化任意 `T` 的万能槽。每一类别的 `T`、基数、允许的不适用、集合完整性及引用规则必须封闭定义。

- 未知不等于数值0、空集合、无穷范围、false或全域通配。
- 集合还要分“已知这些成员，但未声明穷尽”和“完整集合”；不能因未提到其它成员就补成不存在。
- 认识情况从已知槽及完整性校验导出，不在每个节点复制“无/空/有/用”阶段枚举、成熟度、命中阈值或存储可靠性字段。
- 活跃/退役等既有结构生命周期与认识完整性分开。未知概念正式可读、可指代、可提问、可补充，未定义不返回“节点不存在”。
- 按用途分开身份引用、已知字段查询、限定范围计算和完整概念适用。前三者可在所用内容及依赖闭包足够时使用；确认某对象属于整个概念，则必须具备该判定所需的完整条件。例如只知道C具有红色，可以查询这项约束，但不能因对象红色就确认它属于C。
- 使用结果明确原概念、所用内容的读取截止及判定范围；补全不得扩大旧结果的证明范围。条件不足时语义判断为“未知/定义未就绪”，不是假成功，也不是结构读取错误。

### 4.3 根内组织与补全

初建保存明确根归属；概念树视图可在该根下列出未知项。该组织位置不假装已经证明某个普通上位概念的包含关系。已知上位关系有依据时再单独保存，图保持无环；不另建未知根。

填入原来未知的槽保持同一概念身份。相同内容重复提交不重复增加知识；与已知内容冲突则返回两项内容及来源，不能“后来一句覆盖前一句”。首版仅支持补未知、增加不冲突材料与完成定义，不自动修正错误类别或重写已确定的含义。

定义完整时由类别应用校验语义、规范化，概念数据服务按完整签名原子查重。若无同义对象，原未知身份成为该完整定义的规范身份；若命中同根同类别的已有完整概念，原身份保留并建立同义收敛引用，新语义读取返回原身份与规范身份，不改写旧引用。

首版仅在参与签名等价判断的必要概念依赖已于同一截止解析到确定规范身份、且其必需定义闭合时，才允许完成规范化。否则返回依赖未就绪，保留未知/部分定义身份及限定使用能力。避免A引用未知U、B引用未知V后先各自成为规范概念，而U/V随后收敛导致A/B重复。必要定义依赖循环不以递归超限冒充完成；返回具名循环/不支持，递归定义的等价算法及反向依赖重算不在首版暗中实现。

收敛必须禁止环、跨根归并和单凭词面归并；并发相同完整定义只能有一个规范身份。首版收敛目标必须是未转向的完整规范概念，不能形成无界重定向链；已有收敛入边的规范目标不得被静默再次转向。历史读取按当时内容，不能用后来学到的定义追认过去已经理解。误分类走显式纠错设计，不自动换根。

以上是对 2220/7140/4240 的候选变更，现有代码不得用空签名、默认值或旧兼容入口模拟。

## 5. 临时解析数据结构

统一前端只维护本请求内的值式图，不新增通用生产信息节点。稳定概念/存在引用与局部符号引用使用不同强类型分支，即使底层数字相同也不相等。

| 结构 | 建议字段 |
| --- | --- |
| 解析请求 | 已发布材料引用或内联文本分支、明确语言选择、说话者/会话引用、已有对象约束、规则集、预算、取消信号、明确模型选项 |
| 来源片段 | 正式材料引用或请求局部来源编号、实际编码、原字节半开区间；内部 Unicode 标量区间及其到原字节映射 |
| 词出现 | 本地编号、来源片段、原词面、规范化词面、词条候选；同词重复保留各位置 |
| 局部符号 | 本地编号、概念/实例/量值等角色、候选类别集合、类型依据、概念或对象绑定、多义项 |
| 句意节点 | 本地编号、具名 IR 分支、参与者/操作数、来源、显式或推导标识 |
| 篇章结构 | 子句/段落范围、主题、引述说话者、变量与条件作用域、顺序/分支/描述性循环 |
| 知识补充提议 | 正式概念或局部符号、所属类别、类型化增量、前置读取内容、原文来源及采信依据；所属解释分支、作用域及引用依赖 |
| 业务提议 | 强类型查询/世界描述/目标/方法知识/因果主张分支，各自必要来源、解释分支、作用域依赖与缺口 |
| 解析结果 | 覆盖范围、所有未解析片段、打包解析森林、句意图、绑定结果、歧义/冲突、预算使用及实际读取范围；不包含已裁决的学习或业务提议 |

内联文本由解析请求/结果持有其不可变原字节及编码，局部来源编号不能当作稳定材料身份。正式材料读取的字节也保留可核对的位置映射。学习与信息组合入口各自生成提议；解析器只生成语义图及缺口，不另设一套同名提议生产路径。

IR 分支最少包括：`指称、分类定义、属性描述、量值、关系比较、变化描述、And、Or、Not、条件、量词、时间约束、语气、引述、步骤描述`。不是一个 JSON 字典；每个分支有封闭字段、允许的子节点种类、基数和校验器。JSON若用于模型传输，只是外部序列化，校验后才能转换为类型化临时IR，不直接存为世界/概念定义。

语气至少分陈述、疑问、请求、假设、引述；可能、必须、应当等模态另带作用域，不压成一个全句 bool。“未观察到”不等于“不存在”。

预算、规则版本、读取截止和提交身份属于调用/来源/可靠性材料，不扩充特征、状态、需求等本体字段。

## 6. 解析算法

### 6.1 保留未知片段的词序格

1. 解码并保存原文映射；处理换行、标点、引号、括号和列表结构，不覆盖原材料。
2. 识别数字、单位、时间表达和可用词条；中文使用候选词序格，不用一次最长匹配排除其它解释。
3. 无词条命中的片段保留为未知词段，不丢掉整句；重复出现仍保留各自位置。
4. 规范化规则不能把“1.0”与时间、名称中的数字混淆，也不能破坏否定、量词和引述。

### 6.2 构式图表解析

首版采用有预算的 Earley/图表解析，语义动作生成打包解析森林。语法状态按规则、点位置、起止位置去重；同一状态保留各推导的打包边，不把不同语义解释丢成一项。解析器算法固定，语言覆盖由不可变构式规则集扩展。

每条规则包含规则身份、右侧形式、输入槽位约束、语义动作、作用域、来源覆盖要求。规则语义动作只有构造IR和产生约束的能力，没有文件操作、数据库写入或方法执行能力。

森林共享不可变语法片段；类型环境按解释分支隔离，不共享可变约束集合。只有类型、作用域、来源依赖等价的语义节点才允许合并。规则装载时拒绝无限空推导或无输入消耗的语义增生循环；合法左递归由图表去重处理。打包边、分支类型环境、候选展开和内存预留均计入预算，不先穷举全部解释再限制输出数量。

首版构式：

| 构式 | 生成内容 |
| --- | --- |
| “X是一种Y”“这种Y称为X” | 分类/命名提议；已知Y为X提供类别依据 |
| “A的P为V” | 主体、属性和值；是实例陈述还是概念定义结合量词与语境区分 |
| “具有P的A”“A由B和C组成” | 修饰、组成；集合未声明完整时保持开放 |
| “A比B高V”“A在B内部” | 有序双方、比较属性/关系概念、差量；不凭词面生成准确计算结果 |
| “A从X变为Y”“先A再B” | 变化或描述性顺序，缺时间端点就保留缺口 |
| “如果A则B”“并且/或者/不是” | 条件和逻辑组合及明确作用域 |
| “每个/有些/三个”“前者/后者/它” | 量词、基数及指代候选 |
| “请/需要/如何/是否”“直到/重复N次” | 请求/查询/步骤及停止条件，不执行 |

没有匹配的片段显式返回；不采用“名词默认存在、动词默认动作”的兜底。

### 6.3 类别约束与未知概念引入依据

必须区分解析角色、预期概念类别、正式概念类型三件事。前两项可以在未知概念尚未建立时确定；第三项由正式读回证明。

类型约束来源：

1. 明确教学输入指定已登记概念类别，来源与目标范围可核对。
2. “X是一种Y”中的Y已正式读取，且相应构式和量词能证明这是概念分类而非实例命名。
3. 已登记构式/业务目标槽给出唯一类别约束，并通过上下文和其它约束交叉核验。
4. 已读类型/单位合同提供量值类别，但厘米不直接区分长、宽、高，也不证明某词是概念而非实例。
5. 已有概念绑定提供正式类型事实。

每个解释分支内的符号分别维护候选类别集合，工作队列只在同分支传播交集约束：单项且依据成立为该解释内类别已确定；多项为待消歧；空集为该分支冲突。不同合法解析仍为备选，不能跨分支求交集，把OR误算成AND。只因预算剪掉其它分支得到单项，不得算唯一。没有可信类别锚点的未知词互相定义不能循环自证类别。

“桌子”在“有桌子的房间”中仍可引用存在概念；它在句中承担特征描述角色，不因此把桌子概念直接改成特征概念。

模型标签或分类分数不单独构成类型成立依据。未知词、已有词但没有对应名称、已有多义概念、读取未完成、确有新含义分别返回；不能将已有含义暂时消歧失败改成新建未知概念。

### 6.4 数量、单位与时间

- 数量先解析为有界精确整数/十进制系数和尺度或有理数，不先转二进制浮点。
- 按正式FT读取单位、比例、偏移、量化及溢出规则后再转I64或合法值引用；不可精确表示时按明确类型规则处理，否则返回表示不支持，不能静默舍入。
- “约三米”保留近似；“0到10”保留端点开闭；未知单位返回缺口。概念区间不反推准确观察值，不取中点补值。
- “现在/昨天/随后”依据说话时间、时区和篇章关系解析；锚点缺失时保留未解的相对时间表达，不能用接收时间冒充。状态需要的绝对/相对强时间按所属合同形成；不创建零时间占位。

### 6.5 句间组合与指代

以章节、段落、列表、引述和条件块建立作用域。显式同位/指示、类别兼容、主题和距离形成候选；有多个合理对象时不凭最高分强行唯一。

`不是所有A都B`生成`Not(All(A,B))`；`所有A都不B`生成`All(A,Not(B))`。引文中的“我”绑定引文说话者，不自动绑定系统自我。

“先A，再B，直到C”必须保留C控制哪个重复/步骤范围。跨句定义可以提供后文词义的本次局部约束；在正式学习提交前，这种局部理解不是已经改好的概念定义。

部分解析的采纳以作用域闭合为门禁：每项提议记录依赖的来源范围、解释分支、作用域节点和引用；其否定、量词、条件、引述、指代及模态都必须已明确。未解析片段对其可能支配的最小子句/作用域形成屏障，支配范围无法确定时屏障向外扩大。不能抽取尚未识别否定的“A是红色”作为肯定知识。相关范围搜索截断也阻止唯一采纳；不相关段落的缺口不阻断另一份依赖闭合的提议。

### 6.6 规则与模型

规则模式是首版确定性基线。可选模型只提出分词、构式、指代和隐含项候选，不直接产生正式编码，不拥有任何写入/动作工具。

模型返回必须通过schema、原文对齐、局部编号、角色、单位、逻辑作用域和预算校验；隐含内容标为推测。请求未允许外部模型时不得自动发送文本；超时和模型失败有独立结果。分数用于排序，不证明唯一、不证明事实为真。

## 7. 学习提交：从解析符号到正式未知概念

只读解析输出可以含局部未绑定符号。调用方明确进入学习入口后，才执行以下过程：

```text
完整来源与学习范围确认
→ 内联来源经语言材料服务正式建立/复用并读回原文与范围
→ 同截止读取词条/名称候选/现有概念及类别合同
→ 校验类别已确定、概念/实例角色已分清、引入依据成立
→ 复用已有明确概念，或由唯一概念owner建立正式未知身份
→ 正式按身份读回根、类别、未知/已知内容及引入依据
→ 词条/名称各自服务建立关联并独立读回
→ 将本次局部符号映射到正式概念引用
→ 提交已经裁决的类型化补全增量
→ 按概念重新读取完整已知内容与缺口
```

内联来源正式化使用语言材料服务原请求，返回“局部来源编号→正式材料”映射；必须核对原字节、编码、来源及区间，不能仅用文本摘要或进程局部编号冒充持久来源。来源未正式化时保留只读解析结果，但不创建依赖该来源的概念。同一提交重放复用原材料；同字文本在不同表达场合不因文字相同就合并为同一次语言事实。

一份来源中的某词义按“材料身份、原文引入范围、已裁决类别和本次引入依据”定位可重放引入；重读同一引入不能造重复身份。不同来源同词不以词面合并：有明确同义或指代依据才复用，否则保留多义/新的独立引入。

新增未知概念与类别、根归属、首次材料由概念owner在同笔结构发布中闭合；名称属于另一owner，按真实阶段处理。概念已建立而名称失败时，不删除合法概念、也不宣称全部零写；按原请求继续名称阶段。

来源和类别采信是业务应用裁决。学习请求明确选择哪一解释及哪些已闭合作用域，未消除的相关歧义不能按第一项发布。数据服务只核验其强类型请求与结构，不自己理解文字、不判断教学是否可信。定义增量中明确已知的字段才发布；未经裁决的整句主张留在语言记录及值式提议，不用万能原文属性充当正式定义。

对于长期学习，正式概念身份提供跨会话锚点，已知内容和原始来源可读回；缺什么可由类别合同和目标用途重新计算。无需为每次解析额外建立“待学习证明节点”。自我决定是否将缺口形成学习需求。

## 8. 各类信息的请求组合

通用内核不直接维护每个信息类的字段。每类使用一个具名业务适配器，将IR转换为该类封闭的请求/提议分支；适配器表由代码与正式合同登记，不由文章动态增加字段、接口或节点族。

| 输出类别 | 必需材料与去向 | 不能推定的内容 |
| --- | --- | --- |
| 存在概念/实例 | 类别、定义材料或具体指代；分别交概念学习和存在应用 | 概念不是实例，类名不能选定具体对象 |
| 特征概念 | FT/值域等部分或完整定义，交概念学习 | 类别已知不等于FT、量纲、域已经完整 |
| 准确特征 | 正式FT与准确值；经特征应用复用或创建 | 红色等域概念不能补准确RGB值 |
| 状态陈述 | 正式FT、准确值、明确时间；具体发生还需C/E/S绑定及采信 | 语言接收时间不是观察时间，不回写当前采用 |
| 二次关系 | 已有RC/待补RC、有序A/B、取值及参照约束，交比较/关系应用 | 只说“更高”不能造出实际差值；不增加持久二次实例 |
| 动态描述 | 主体、真实端点/子动态、时间与来源；缺失先返回描述提议 | 文本“升温了”不能伪造两个状态端点 |
| 因果主张 | 条件、动作、结果与范围的结构化声称，交因果学习 | “因为…所以…”不是已验证客观因果 |
| 需求/任务 | 服务对象、目标与约束等提议，交自我；确认后任务管理建立任务 | 文章中的目标不是自我的已确认需求或已完成任务 |
| 方法知识 | 作用对象、FT、条件—结果配对、参数、顺序与限制，交方法应用 | 文本算法不是已注册函数，步骤树不是一个方法的条件配对树 |

可复用多步骤描述先用于任务方案材料；只有真实可调用的主动作函数已登记时，才能据合法知识完善其条件—结果配对。不能将文章每一步都直接登记成可执行方法，也不能将自然语言拼接成函数名执行。

## 9. 候选接口与结果合同

以下签名用于明确职责，是待正式化的候选合同，不是现有可调用函数；具体领域引用类型复用届时有效专属ABI，不引入旧公共L2结果头。

```cpp
解析结果 自然语言解析器::解析(const 解析请求&) const;
学习提议组 概念语言学习::形成学习提议(const 解析结果&) const;
学习提交结果 概念语言学习::提交学习(const 学习提交请求&);
信息提议组 语言信息组合::形成提议(const 信息组合请求&) const;
```

`信息组合请求`显式包含原解析结果、选定解释、已发布来源映射、学习结果中的局部符号到正式身份映射及所需正式读回。没有学习时映射允许为空，但不能把未绑定符号伪装为正式引用。组合器先纯值生成新的绑定视图，不原地改写原解析结果；逐项校验同一解析来源、局部符号、已裁决类别与正式身份读回，冲突映射拒绝，未完成项保留。

学习提交结果必须逐项返回实际来源/概念发布、名称关联、补全阶段及其映射，不能只返回一个汇总状态。组合器按对应用途判定阶段要求：例如已创建并读回的C可被身份引用，但依赖词条查找的提议还要名称关联成立。新绑定视图的引用闭包重新在同一有效截止下核对；变化影响原解释时返回需重解析，不把原读取与学习后的读取混合成一致结果。

| 入口 | 成功条件 | 写入及非成功边界 |
| --- | --- | --- |
| 解析 | 所声明范围全部覆盖、候选搜索未截断、引用/类型约束自洽；另行说明是否唯一、是否全部绑定 | 零持久写入；可以完整解析但仍有未知正式概念或局部未绑定项 |
| 形成学习提议 | 每项有来源、类别及目标引用或明确引入依据；冲突分项列出 | 零写，不把提议当正式概念 |
| 提交学习 | 所请求阶段都由实际服务返回并独立读回；返回每项局部符号到正式身份映射 | 只写授权学习范围的语言/概念结构；部分已发布与未发布分开 |
| 形成提议 | 每项满足对应适配器的字段、正式绑定、来源及作用域闭合合同，缺口单列 | 零世界/治理写入，不调用动作；服务未实现不返回可派发提议 |

概念数据侧最小拟扩展操作：`创建未知概念、读取概念认识内容、补充未知定义项、完成定义并收敛`。每项请求和结果至少封闭如下：

- 创建：类别合同、根、引入依据引用、允许的已知部分、该服务原请求身份/期望读取依据 → 首次/重复身份、实际发布结果、完整读回。
- 读取：正式概念引用、明确当前/历史读取与预算 → 原身份、类别、根、已知内容、定义完整性及可选规范身份；未知内容仍是成功读取。
- 补充：正式身份、预期旧内容/所属服务并发守卫、具名类型化增量及来源 → 新内容、未解决项或冲突；不吞掉原结果。
- 收敛：完整定义、签名等价所需的已确定规范依赖闭包、规范化依据及预期旧内容 → 本身成为规范身份或同义指向既有规范身份；依赖未就绪则不完成，查重与发布同一原子闭包。

不得同时提供另一套解析器私有概念仓。业务构造依赖从外部合法装配注入，同底座校验在领域内部完成，不暴露DATA-L1引用或用两个相等的代次数值证明同底座。

结果不是一个bool：至少分别表示覆盖完整/部分、解释唯一/多义/冲突、引用绑定完整/有缺口及发布阶段。取消、预算不足、规则不支持、能力未形成、材料失效、事实读取漂移、资源失败和内部错误均保留来源位置。

## 10. 一致性、重放与副作用

1. 一次只读解析从领域公开合同取得一致读取范围；名称、概念、类型和对象材料不能混用不同截止。只读重试不改变概念。
2. 学习提交前重新校验所依赖材料；发生漂移时重读并重建受影响提议，不在旧提议内偷偷替换身份。
3. 写前失败零该操作写入；某阶段已经发布则返回真实阶段及原请求。发布未知只按原提交身份查回，不改键重复新建。
4. 不要求整篇文章跨所有owner原子提交。采用显式有序操作组与依赖：概念→名称→补全等各有独立结果；一个来源失败不伪装成整篇全部未发生或全部完成。
5. 对本次已确认操作的局部符号映射只指向正式读回身份。崩溃后通过原材料和原服务请求重建，不以进程内映射或模型缓存作为权威。
6. 外部文本中的“删除、执行、忽略规则”等内容都是待解析材料。即使语义完整，也不能改变解析模式、学习范围或工具权限。
7. 世界事实、需求确认、任务执行和方法效果验证继续由各自应用负责。本解析器不会把预测填成观察，不把论文、小说或引文当作直接现实执行指令。

## 12. 演练：词到概念、句到内涵、文到用途

输入及前提：教师明确“温控器属于存在概念”；正式存在根、类别合同与汉语身份可读；后续文本为：

> 温控器是一种控制温度的设备。它根据测得的温度控制加热器。若温度低于十摄氏度，启动加热；达到二十摄氏度后停止。请用它保持水温。

1. 类别已确定：只读解析先产生局部符号U；学习入口创建正式未知概念C，读回后U→C，建立词条名称关系。此时C可以完全没有具体定义内容。
2. 第一、二句：形成存在类别下的功能、涉及特征与组成/关系提议；代词绑定类别为C的泛指局部变量，形成C的内涵提议，不把概念节点本身当现实动作参与者。来源、作用域和专属槽校验通过后补入已知部分，不由“设备”词面创建现实设备。
3. 条件段：形成有条件、停止条件和参照FT的过程描述。10℃和20℃是规则阈值，不是当前水温。
4. 最后请求：形成具体对象仍可能未绑定的目标提议；“它”是否指概念还是某台设备必须核对，不自动取场景首台设备。
5. 自我确认需求且现实设备、函数和条件成立后，由任务侧选择执行。没有函数时返回能力缺口；阅读说明不会自动注册动作代码。
6. 使用反馈回到相应学习/方法应用。概念C最早即有正式身份，后续信息围绕它积累；过去未知的内容不被追认为当时已知。
