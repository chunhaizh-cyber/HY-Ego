## 1. 目标

提供一个真实、只读、无业务解释的 `DATA-L3` 概念空间根视图入口：在共同 `G0` 下正式读取四本体根、概念身份 / 归属、全部直接多父边和可选叶级世界事实支持关系引用，完成去重、稳定排序、预算与闭包验证，并返回结构化结果或零载荷失败。

## 2. 当前事实与前置依赖

- `L2概念结构.数据.h` 已冻结四本体根 DTO 和根组读取结果；`服务.L2概念结构.ixx` 已公开根组、普通概念和支持关系读取，但完整概念图目前只有 private 值式读取。
- `服务.L2概念结构聚合.ixx` 目前只是绑定壳，没有 L3 根视图 ABI。
- 本计划已经冻结最早直接上游的 L2 公开概念图 / 概念身份有界读回合同；代码施工时须先在现有 L2 概念结构数据 / 服务中实现该 ABI，再由 L3 消费。执行者不得调用 private helper、访问 L1 或扫描仓库补齐。

## 4. 目标 ABI 与函数

实现唯一公开函数：

```text
L3概念空间聚合服务::读取概念空间根视图(
    const L3概念空间根视图读取请求&) const
    -> L3概念空间根视图读取结果
```

实现必须按详细设计第 6—9 节的顺序读取根组、L2 概念图和可选支持关系；不得新增写入口、投影持久化、概念形成或业务判定。L2 上游函数必须是纯结构公开读回，返回实际截止和结构化失败，不携带概念是否成立等业务结论。

## 5. 实施步骤

1. 在现有 L2 概念结构数据 / 服务实现并公开概念图读取 ABI；保持 L2 合同版本 1。
2. 新增独立 L3 数据头和服务模块，绑定同一 L2 概念结构服务实例；不得扩张现有 L2 聚合壳承担 L3 DTO。
3. 将四本体根 provider、正式初始化入口、普通应用装配和工程登记接入同一公开服务实例；删除或降权 `已发布材料`，正式根组 / 概念图读回为唯一成功权威。
4. 实现请求验证、共同 G0、四根闭集检查、概念图读取、可选支持读取、去重排序、预算和引用闭包。
5. 统一错误分账：入口拒绝、许可拒绝、事实代次漂移、资源失败、数量预算不足、未实现、内部不一致；所有非成功返回零投影载荷。
6. 对当前 / 历史读回分别验证；历史截止只由请求明确提供，不自动升级。
7. 完成普通应用真实装配和独立正式读回；读回失败只能报告未确认 / 内部不一致，不声称已回滚。
