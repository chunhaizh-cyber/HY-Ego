# INSTINCT-ROUTE 本能路线后续计划制定方案 v0.5

日期：2026-09-01

材料身份：后续计划制定路线输入

替代关系：本文件完整替代 `20260831_INSTINCT-ROUTE_本能路线后续计划制定方案_v0.3.md` 与 v0.4；不继承两份旧文件中未明确重述的阶段、合同或候选。

状态边界：本文件不是机器规范、详细设计、代码计划或计划索引项，不产生施工授权。

## 1. 路线目标

本路线以最少机制形成可运行的服务与安全闭环：

```text
真实服务请求
-> 普通具体需求
-> 普通任务
-> 正式方法与执行冻结
-> 适用安全门禁
-> 现实动作
-> 正式结果
-> 需求 owner fresh 裁决当前满足
-> 状态 / 动态 / 因果记录
```

安全根值只经主动安全结算变化。服务根保留为长期普通需求坐标，不再承担合同账户、余额、时间衰减或安全根调节职责。

## 2. 退出范围

以下体系整体退出，不建立同义替代物：

- 服务合同及合同状态；
- 服务预算、30% / 70% 支付、预支和余款；
- 合同到期、续期、关闭和补账；
- 服务进展 / 服务准备专属事实及准备补回；
- 服务维护历史账、历史水位、Gseed 和新维护纪元；
- 合同驱动的单秒 / 批量服务值维护；
- 30 天门禁、服务值时间衰减；
- 服务值驱动安全根回归、休眠 / 唤醒和安全 / 服务根配额；
- 以 6160、6170 为依据的设计、计划、流程图和生产装配。

已完成计划和提交保持历史事实，不改写为“从未实现”。v0.3、v0.4 只作历史路线证据，不再提供当前阶段或施工依据。

## 3. 保留范围

以下能力不因退出而删除：

- 普通需求身份、目标合同、树 / 列表、fresh 当前满足和 `T→D`；
- 任务筹办、冻结、执行、实际结果、验证和轮次收束；
- 方法身份、路径、实例、运行事实和版本；
- 通用特征当前值及其原子变化记录；
- 状态、动态、因果三类认知证据；
- 主动安全来源方法完整集合、主动安全变化永久账和主动安全结算；
- 分层安全维护、五级安全调度倍率和安全硬否决；
- 独立于合同维护链的正式时间能力；
- 本能根锚点中服务根作为长期普通需求角色的部分。

服务根当前值暂不建立新自动生产者。缺少直接、非记账式的合法维护语义时保持无新写入授权，不用固定值、时间或服务次数补位。

## 4. 旧持久数据边界

既有服务合同、合同状态、到期事件、服务进展、服务准备、服务维护历史、Gseed 和相关游标材料不物理擦除。

这些材料不再是当前业务权威，不允许形成新写入、服务迁移、补账、续期、结算、服务值变化、调度资格或安全根变化。恢复时只作为已退役格式识别、审计和拒绝重新发布的输入；混合旧格式可在内部解码后恢复其中与服务体系无关的安全 / 时间字段，但不得保留服务公开 ABI 或服务业务解释。

为避免增加复杂度，本路线不要求新建兼容数据库、新游标版本、迁移服务或替代账。若现有读路径能够在生产装配退出后保持只读识别，可直接保留；否则由代码退役计划选择最小离线识别入口，不得恢复写能力。

## 5. 当前唯一代码叶

当前只形成一份闭环代码退役计划：

```text
停止服务合同及专属进展 / 准备的新写入
-> 退出合同专属生产装配与启动调用
-> 退出合同驱动单秒 / 批量维护和 Gseed 路线
-> 保留旧格式只读识别与通用当前值 / 状态 / 动态 / 因果能力
-> 调整工程登记和专项验证
-> 证明普通服务请求没有第二业务入口
```

同一 owner、公开 ABI、生产装配和验证资源上的删除合并在这一份计划中；不拆成 DTO、服务、装配、游标、算法等多份排队计划。只有当前自我治理 WIP 已释放重叠文件，或已完成精确 hunk 交接后，计划才可登记为 `可执行`。

该计划必须以当前代码事实冻结：允许删除文件、保留文件、只读函数、退出函数、工程登记、启动接线、持久恢复拒绝行为和验证矩阵。未冻结前不得直接施工。

## 6. 完成条件与声明边界

本路线退出闭合至少证明：

1. 正式规范与目录不再把 6160、6170 作为现行机器语义；
2. 生产启动不再创建、发布、续期、结算或维护服务合同专属事实；
3. 不再按完整秒、到期或准备进展改变服务根或安全根；
4. 普通服务请求只走既有普通需求、任务、方法和正式结果入口；
5. 通用当前值、状态、动态、因果和主动安全能力未被误删；
6. 旧持久格式未被物理清除，且不能重新发布为当前业务事实；
7. 精确重复、旧格式恢复、重启、坏格式和无服务合同模块的普通启动均有结构化结果。

完成本路线退出不等于完整服务能力、本能路线、自我治理闭环或项目完成。它只证明旧服务合同记账与时间维护体系已经退出，保留能力没有被错误扩权。
