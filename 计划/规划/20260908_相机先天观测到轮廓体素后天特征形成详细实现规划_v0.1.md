## 1. 结论与实现目标

该路线有条件可行。采用“外设直接交付的观测种类为先天输入”的边界后，可以从图像和深度形成空间采样、区域、轮廓及体素，再用本项目的特征、存在、关系和概念机制组织、识别与复用。

关键不是把相机数据直接改名为存在，而是建立四种明确能力：

1. 观测解释：将原始像素与深度按设备合同解释为可计算材料。
2. 几何形成：通过标定、邻域比较、连续性判定、分割和结构组织，形成新的完整观测表达。
3. 特征承载：完整材料进入准确特征；比较完整材料时，每项对外二次结果仍为具名 I64。
4. 概念归纳：按同一特征类型积累材料、形成合法相似域和概念，供后续分类、命名及存在描述复用。

节点、关系和值提供承载方式，不自动提供标定、分割、几何或学习算法。上述算法及类型合同必须有真实实现，不能由节点关系的存在推定它们已经具备。

### 1.1 首个完整交付目标

给定一份可重放的深度相机观测，能够：

- 复核完整输入及标定，恢复可见表面采样；
- 形成确定性的表面区域及其轮廓，保留孔洞、开放边界、遮挡与视野截断信息；
- 独立形成具名网格中的稀疏体素观测，区分表面命中、自由射线证据和未知；
- 合法保存完整结构，独立读回后得到等价内容，不靠截图或摘要自证；
- 在已登记类型和算法下比较两份材料，返回具名 I64 差异；
- 在域规则具备时形成或复用特征概念；具名世界接纳合同具备时，才把候选组织为存在及其采用特征。

先以录制输入完成上述局部服务闭环，再接真实相机和正式运行入口。相机实时接通不是几何算法或数据闭环成立的替代证据。

### 1.2 明确不承诺

单帧不恢复被遮挡背面，不补造完整实体内部，不自动识别“桌子”，不证明多个视角属于同一存在，不自动形成状态、动态、因果或行动决策。多帧融合、跟踪及自动发现全新算法列为后续阶段。

## 3. 概念边界与正式规范差异

### 3.1 必须分开的四组概念

| 区分 | 本方案解释 |
| --- | --- |
| 先天 / 后天 | 类型来源：设备直接交付，或系统综合形成；不由程序是否预置决定。按该拟议边界，深度图是先天输入，轮廓与体素是后天类型。 |
| 原始材料 / 特征事实 | 数组可先作为计算材料存在；取得正式类型、完整内容与合法来源后，才经特征服务建立 F。不是每个中间变量都必须持久化。 |
| 完整结构 / 比较结果 | 轮廓点序、连通和体素内容完整保存；比较器另外产生 I64 差异。评分不是轮廓，体积差不是体素。 |
| 类型 / 准确特征 / 概念 | FT 定义如何解释及计算；F 保存某个固定准确值；FC 表达该 FT 的允许域。提取另一条轮廓通常只产生另一个 F，不产生新 FT。 |

深度相机通常交付像素深度和颜色，不是“已归属某存在的完整体素”。深度处理得到的首先是可见表面采样；物体内部、背面和未观测空间均不因此已知。

## 4. 总体处理与职责

```text
外设 / 录制材料
  → 观测合同复核、完整材料承接
  → 深度解释、去畸变、空间反投影
      ├─ 邻域比较 → 表面分区 → 有序边界链/环 → 轮廓材料
      └─ 网格映射、射线遍历 → 稀疏体素观测材料
  → 类型化完整结构 F（准入合同先冻结）
  → 结构比较及域匹配 → 同类型特征概念形成/复用
  → 按需世界接纳、存在特征采用与存在概念处理
```

这是目标数据流程，不是当前代码调用图。轮廓和体素分支可以消费同一份只读空间采样；轮廓不要求先体素化，体素也不要求先识别对象。

- 外设适配：只交付材料、测量上下文和失败，不判断属于哪个存在。
- DATA 之外的视觉应用：解释观测、执行几何与分割、决定哪些结构值得保存；不复制数据仓。
- DATA-L2 特征/材料/存在/场景服务：保存、校验、读取已裁决结构；不在 CRUD 中启动视觉分析或概念学习。
- DATA-L1：保持通用原子读写、引用保护和恢复职责，不解释轮廓、体素或分区。
- 概念应用：同类型积累、域形成、查重、命名和治理；不把相似直接解释为同一存在。

| 轮廓材料 | 格式、坐标框架、轴向、单位/分辨率、完整点序、链/环分段、闭合标志、外环/内环/孔洞关系、各段边界类型、源区域和可见范围。 |
| 体素观测材料 | 坐标框架、网格原点、每轴正格距、索引范围、稀疏布局与排序、每格表面命中/自由射线/冲突标记、完整源观测关联、观测覆盖范围及误差合同。 |

材料共同要求：格式与长度可核验、大小上限明确、完整字节可独立读回；格式解释发生不兼容变化不能原地改义。摘要用于校验和召回，不替代完整内容。点序/像素序保留；只有本身按集合定义的体素键可规范排序去重。

二维网格边轮廓与4120§3.2的“前景边界像素中心”不是同一表达；须采用不同具名格式，或通过明确转换取得旧算法所需完整二值图。不能把新边界点直接送入旧像素中心算法。

### 5.4 节点、关系和值的落点

```text
特征定义 FT ── 解释规则/格式/比较/域形成规则
准确特征 F ── 类型关系 ── FT
准确特征 F ── 准确值引用 ── 值事实 V ── 强类型引用 ── 完整材料节点 M
存在 E     ── 已知特征、当前采用 ── F
特征概念 FC ── FT＋固定规范化域定义
```

这是逻辑关联示意；值事实不是节点，`F→V`使用合法属性/值引用，不能用普通节点关系冒充。来源帧、标定、规则、区域等通过其所属正式关联表达；材料内容中的索引不能替代跨材料强类型引用保护。

F仍只保存身份、类型、准确值及可选概念名称；V仍只有值身份、表示类型、完整内容。当前/历史采用归存在关系，技术代次/重试/发布归可靠性合同，不增设视觉专用事实代次或第二持久账。

## 6. 单帧处理算法

### 6.1 复核与深度预处理

按固定顺序执行：

1. 校验输入格式、流配置、内存跨度和预算；校验每个平面的实际末行可访问范围，不把有步长填充的图像当作紧密数组。
2. 校验内参与实际分辨率匹配、焦距有限且为正、畸变模型有解析器、深度比例有效。
3. 保留原始深度，按合同建立有效性与原因材料。默认不插值填洞、不平滑覆盖原图；后续滤波必须输出另一份有来源材料。
4. RGB可选。需要颜色时，用已核验的内外参将深度点投影到颜色平面，处理出界、遮挡和多深度竞争。固定采样方式，不按相同像素索引强行配对不同分辨率的两幅图。
5. 对曝光时间差超出合同或标定不相容的RGB材料，颜色分支返回不相容；深度分支可独立继续。

失败与空结果分开：格式损坏是拒绝，全帧无合法深度是“无有效观测”，都不能输出“场景为空”。

### 6.2 空间反投影

先按具名畸变模型取得校正射线。记归一化射线 `d = K⁻¹[u,v,1]ᵀ`，其第三分量为1：

```text
设备输出光轴深度 Z：p = Z · d
设备输出沿射线距离 r：p = r · d / ||d||
转换坐标框架：p_target = R · p_source + t
```

不得对未去畸变坐标直接套理想针孔公式。对不支持的畸变模型拒绝，而不是默认为无畸变。

单帧首先落在该相机的具名坐标框架中，保留点到原像素的映射。即使两个像素深度相同，其三维坐标通常也不同。跨相机或世界框架转换必须有真实外参及方向；标定平移量与深度必须先按具名合同统一单位。

内部计算可用 double，但输出量化、舍入、范围与误差须固定。严格逐位跨平台重放还须限定数学函数与临界值处理；只固定容器遍历不能证明跨平台数值确定性。

### 6.3 邻域比较与连通分区

首期选用“有适用范围的连续表面分区”，不承诺通用实例分割。确定性基线如下：

1. 用图像四邻接，仅生成右邻和下邻边；无效像素不建立几何连通边。八邻接或点云邻近算法属于另一配置，不运行期隐式切换。
2. 对邻接有效点计算径向距离 `Ri=||pi||`、`Rj=||pj||`、射线夹角 `α` 和空间距离 `dij=||pi−pj||`。
3. 从已登记误差模型读取 `εi、εj`，从处理规则读取允许的局部径向斜率界 `g` 及邻接空间界 `τp(i,j)`。
4. 一个具体可验证的基线连通条件为：

```text
τR(i,j) = εi + εj + g · max(Ri,Rj) · α
可连通 = 两侧有效
         且 |Ri−Rj| ≤ τR(i,j)
         且 dij ≤ τp(i,j)
```

`α`以弧度计算，所有距离同量纲。`g`与`τp`不是普适自然常数，须由视场、有效坡度范围、采样间距和验证场景确定；未提供参数则本规则不可使用。内置算法形状可以预先实现，实际参数不能现场猜测。

5. 按行优先顺序做连通分量搜索，以每个分量最小像素索引规范编号。固定邻居访问顺序，使输出不依赖线程完成顺序或哈希遍历。
6. 输出完整标签、有效区域范围和未完成标志；小区域可以标记低证据或按具名筛选规则不接纳，但原输入仍保留，不能变成“不存在”。

必须承认以下算法边界：

- 斜面各点深度不同，不等于处处有物体边界；处于规则允许坡度范围时应连续。
- 连通有传递性。同区不代表任意两点相似，更不代表同一概念域；不能把连通分量直接当FC值域。
- 两物体接触且观测连续时可能合区；同一物体因遮挡、缺测或大曲率可能分区。
- 深度差非零仍可连通。归组阈值不改写准确差值；需要正式对外比较时再经注册算子输出I64。

为改善曲面或接触物，可在后继增加法向/局部平面残差、颜色、时间一致性或已知组成约束。每个增强规则都需要独立合同与反例验证，不在首期以“智能分割”占位。颜色默认不作为强制断边条件，避免把彩绘物体机械拆成不同存在。

### 6.4 轮廓追踪

以分区标签为输入，把每个像素看作一个二维网格方格：

1. 某侧不属于同一区域时，建立该侧有向网格边，约定区域始终位于边的同一侧。
2. 每条边记录原因：相邻有效区域不同、相邻无效/缺测、超出视野。有效区域之间的分界首先是算法分界候选，不直接命名为物体外边界。
3. 按最小网格端点和方向选择起边；采用与四邻接一致的固定转向优先级。对角接触不跨角误接；每条边恰消费一次。
4. 输出有序链/环，规范循环起点，保留方向、外内环关系及边原因；若分支或拓扑不符合同则拒绝该轮廓，不任意选一路掩盖错误。
5. 单独给出“完整区域边界”与“可认为是物理边界的片段”。区域边界可以闭合，但其中含视野截断或缺测边，不等于完整物体轮廓。

全幅平面会有图像周界，这只是视野边界。区域内部的无效深度会形成内环，这只是缺测孔洞；若要确认物体真实孔洞，必须有背景可见、几何连通或多视角等额外证据。

二维角点没有直接测得的深度。首期三维关联使用边内侧的真实采样点及来源像素；不得为网格角点随意插值后声称其为准确测得的三维边界。真正三维曲线提取列为独立后继，不由二维轮廓名称自动取得。

### 6.5 稀疏体素与自由射线证据

本节拟议输出是“单帧观测网格材料”，不是6240的已确认存在局部体素模型。观测材料提取入口的资格须先按G07明确，不以更换名称绕过旧融合触发限制。后续转换为存在模型时，必须另行满足其正立方体范围、空边界层、融合点和来源消费合同，不能把任意网格直接交给旧入口。

先固定网格框架、原点 `o`、每轴正格距 `s`、有限处理范围。每格采用半开区间：

```text
格 k 在各轴覆盖 [o + k·s, o + (k+1)·s)
kx = floor((px−ox)/sx)
ky = floor((py−oy)/sy)
kz = floor((pz−oz)/sz)
```

负数必须数学向下取整，不能使用C++整数向零截断。输出网格定位最好在已冻结的定点坐标上进行：原点、格距与点量化合同相容，索引计算检查溢出；不靠临时epsilon移动边界。量化位置只是具名表达，不覆盖原始深度及采样来源。

分别提供两个明确模式：

- 表面模式：只把有效回波终点映射到网格，表示“此格有表面采样命中”；其余格未知。
- 射线证据模式：除表面命中外，在设备回波模型成立时记录表面前有效射线通过的格。请求此模式但无法取得其前置或预算时，不能静默降为表面模式后报告完整成功。

射线证据模式采用固定DDA网格遍历：

1. 从设备可信近界开始，到表面误差带之前结束；不能把相机盲区自动标空。
2. 格面同时命中时同时推进对应轴；仅擦过格边/角而没有正长度穿越的格，不自动取得自由证据。
3. 回波误差带及其后方不写自由证据；缺深度方向和视野外保持未知。
4. 终点格记录表面采样命中，不推断整个格被实体填满；需要不确定性占据带时使用另一个明确字段或模式，不能混同确定命中。
5. 同格可同时有表面命中与另一条自由射线证据，合并采用顺序无关的规则，保留冲突信息。表面证据不能被后写自由覆盖。
6. 结束后按三元键规范排序输出完整稀疏材料；不把三个索引压成无合同的一个整数。

“自由射线证据”只证明相应射线路径上未报告遮挡，不证明整个体素体积完全为空。用于碰撞安全前仍需独立覆盖率、误差及保守膨胀规则；本方案的体素不直接成为运动安全许可。

## 7. 比较规则、I64与零值

### 7.1 原始差异、等价和归组分账

每项算法注册至少固定：输入FT与角色、适用框架/单位、完整解析规则、具名输出FT、结果量纲、量化、范围、零值含义及失败分支。

对当前“找不同”的准确比较路线，要求可检查的零分离性质：`结果=0`当且仅当该输出比较合同认定输入相等。保证针对注册比较器实际接受的输入域；若此前坐标量化已把两个原始点映射为同一值，比较0只说明量化表达相等，不能恢复或否认此前差异。此处相等是该具名合同的相等，不是原始观测完全相同，也不是两个存在身份相同。

容差域命中另行判断。原始差异5、允许误差10时可以同域，但准确差异仍是5；不能改成0。传感噪声下的非零只是本次测量不同，不自动证明现实物体改变。

如果算法本身存在不同输入距离为0的情况，或量化会吞掉非零，不能把该输出用于严格找不同的零判定。旧4180§11的向下量化不在本方案中被偷偷改成向上量化。

推荐首期严格算子：

| 输入 | 输出及判定 | 边界 |
| --- | --- | --- |
| 同单位I64标量 | 安全有符号差 `A−B` | 适配既有“右−左”时，左绑定B、右绑定A。溢出失败。 |
| 同量化坐标 | 注册欧氏距离I64；零仅对应坐标相等 | 首期同整数坐标格可采用精确平方和及向上整数平方根；输出单位、宽中间值和上限必须注册，不改旧算子。 |
| 同格式区域/轮廓 | 完整规范化边/标签内容的差异计数I64 | 对来源时间不敏感还是敏感由FT定义；禁止拿来源身份不同替代几何差异。首期不默认平移、旋转或缩放不变。 |
| 同网格体素 | 指定载荷语义下的不同格计数I64 | 表面键、自由证据及冲突是否参与分别由类型声明；没有共同覆盖前置不能把未知与已知差异解释成实体变化。 |

这些算子是待登记提议，不是现有算法清单。结构差异计数适合精确判异，不是最佳形状相似度；相似度需要另外实现具名距离，不能用同一个算法名随时更换含义。

### 7.2 坐标采用距离与偏移角

保持用户要求的距离＋偏移角路线，但必须区分距离和方向值。令 `Δp=pA−pB`。在一个明确登记“x/y为方位平面、z为仰角轴”的计算框架中：

```text
d = sqrt(Δx² + Δy² + Δz²)
方位角 θ = atan2(Δy, Δx)
仰角 φ = atan2(Δz, hypot(Δx, Δy))
```

实际相机轴向可能不同，须先按固定框架转换；不能把示例轴义直接套到设备。`d、θ、φ`若对外提供，分别是三个具名I64值，各有单位、尺度和来源，不打包成一个I64或一个向量式二次实例。

这里存在一个需要明确合同的语义差别：沿+x的非零位移，其方位角可为0，但两点并不相等。推荐把偏移角作为方向描述值；对两个角度特征另算周期角差时，0才表示两角相等。整体坐标判等使用距离，不以任一角为0判断重合。

若坚持所有对外二次输出的0都表示原始两坐标相等，则偏移方位角不能直接作为该类比较输出；这必须在G03治理时裁决，不能靠编码偏移量藏掉零值。

退化分支：重合点距离为0、两角无定义；极轴上方位角无定义、仰角可为±90°；角差须冻结周期、正向、归一化区间和半周期并列规则。调用方若要求完整三项，某必需角无定义则整组不完整，不返回假0；独立距离请求仍可成功。

### 7.3 颜色、轮廓和体素相似域

颜色可经具名颜色空间转换形成色相、明度、饱和度等类型，再按规则分类。色相七区间只是一种粗分类；低饱和度的黑白灰需要独立条件。色差是两值比较，色相分箱是归类，RGB三原色不是三个互斥颜色类别。

轮廓首期保留观测姿态。后继若需要形状识别的平移/旋转/尺度归一化，须另有具名类型与规则，保留原始结构及变换来源；不能用归一化结果覆盖原值，从而失去位置与尺寸信息。

结构相似域可采用“固定完整代表＋具名距离＋阈值”的谓词，但不同距离的零、拓扑敏感性、对齐要求和非度量性质必须分别验证。4180旧平均边界距离不满足三角不等式，不能据中心距离加半径证明域包含。域包含可先支持完整定义相等、显式原子集合包含等可证明路径；不能证明时返回不支持。

## 8. 后天类型、概念与存在怎样形成

### 8.1 首次建立类型，之后产生实例

建议把生成能力表示为受控的可组合规则：

```text
输入材料/类型签名
+ 前置约束（单位、框架、有效性、数量）
+ 算法或有限处理图及参数来源
+ 输出结构/类型定义
+ 合法比较与域形成规则
```

例如“深度→采样→连续表面→边界链”首次具备完整合同后可登记为轮廓类型的生成路线；后续每帧沿同一路线提取轮廓只形成新材料/F。设备原始输入里没有“轮廓”类型，这一类型在拟议来源口径下仍是后天的，算法可预置不改变来源分类。

若系统后续要自主组合出新的类型：先在有限已知算子集合中形成输入输出相容、无环、预算有界的处理图，验证提取、比较及重复计算，再按规范化完整定义查重建立FT。不能从一个新名称或数次命中自动推导出未实现算法。首期只实现明确的轮廓、体素路线，不宣称通用算法自动发现。

### 8.2 同类型概念形成

1. 取得准确F及其FT和完整结构；概念定义及积累分桶不以产生它的存在区分，以FT进入共享积累，但保留每次真实观察的来源及证据，不能抹去个体来源。
2. 读取类型绑定的域规则与参数，查询已有适用FC；缺规则时F仍可合法使用，但不猜造概念。
3. 域定义完整即可查重建立/复用FC，不重新引入旧“三次命中才可建”的门槛；更细域必须有真实新定义依据。
4. 相似域保留完整固定代表、规则与半径，不移动旧域吞并新样本，不把相似当准确值相同。
5. 概念上下位按定义包含整理，可由根向叶形成或合法插层；按当前7160合同处理多个适用域，不以单次命中覆盖原定义。
6. 名称引用和自然语言映射后置；未命名的F、FC仍可用于合法比较。用途治理保留，但后台枚举不自增“被利用次数”。

观察命中与真实用途分别计量：同一观察的重放、技术重试或重复投递不增加观察命中；独立新观察即使复用同一个准确F，也可以形成新的合法观察。一次观察通过多父路径重复命中同一FC时去重，不能只在创建新F时积累。具体依据使用7160/7140已有具名记录，不新建视觉私有计数账。

### 8.3 区域、子存在与场景

分区标签首先是计算材料。当前目标确需描述区域或部件时，由世界接纳应用根据可观察描述及唯一归属合同建立存在；允许暂未归类，不能要求先认识“桌子”才能保存候选表面。

一个区域是否对应完整存在、某存在的一个表面或多个接触物，需要识别应用和更多证据裁决。建立的存在可持有轮廓、空间采样、体素等已知F，并按同类型至多一个当前采用规则使用；旧视角的准确F继续可读，不因新帧出现删除。

对子存在组织坚持当前单直接归属、单父及无环约束。同一份共享材料可被合法引用，不意味着同一个子存在可以同时属于两个父存在。区域间邻接、接触候选或比较关系不等于组成父子关系；部分—整体也不等于概念下位—上位。

进入“已确认存在内部递归”时继续受6230/6240约束：先确认父身份、外部轮廓、来源、质量和内部认知需求，子候选不越过父归属掩码；颜色分区不直建物理子存在，空间占据、稳定边界、多帧等证据按其正式合同核验。现行6230的8×8停止条款仅用于其具名观察递归，不作为通用存在不可分定义；若新路线要改变该停止或6240独立子模型要求，须先治理，不能由本规划取消。

存在作为场景使用时，已组成宿主的直接子存在仅作为内部场景展开投影出现，不追加第二条直接场景成员边。尚未认定为组成部分的内部成员使用自己的唯一直接场景成员关系；读取须区分这两种来源，不能把全部后代伪装为直接成员。其状态、动态按各自已冻结合同另行形成。本规划不自动记录动态，不以单帧分区生成因果，也不将轮廓相似判作身份同一。

### 8.4 分割聚合与分类聚合的分工

分割聚合解决“哪些观测单元可以组织成区域/部件”；分类聚合解决“哪些对象满足共同概念约束”。两者可以逐层配合，但不能循环自证：不能先假定是桌子分割出桌腿，再以“有桌腿”证明先前假定。

允许既有概念帮助提出分割候选，但接纳与支持必须回到真实观测核验。层内概念组合按7110处理已聚合单元，不摊平到所有像素；有m个独立描述单元时仍可能有`2^m−1`个组合，预算中断不等于完成穷举。

### 9.3 结果形状

纯计算阶段的拟议结果采用互斥联合，而不是`bool成功＋可随意残留载荷`：

```text
完整：所请求分支的完整材料及可复算输入说明
无有效观测：输入合法但无可处理样本；无场景空结论
未完成：明确预算/取消边界；只能提供不可发布的诊断进度
失败：原因、阶段、缺失项；无成功业务载荷
```

原因至少分开：参数/格式拒绝、缺标定、时空不相容、规则未注册、材料提供者缺失、角度无定义、溢出、预算不足、资源失败、取消、内部不一致。正式数字编码待合同冻结，不沿用旧枚举值猜测新语义。

多分支请求分别记录状态：允许独立返回时可报告“轮廓完整、体素未完成”；请求要求两者共同完成时不能顶层宣称完整。单个完整材料不能以“部分成功”名义发布残缺结构。

### 9.4 依赖、线程与背压

调用依赖分别为“视觉应用→外设适配/纯几何”和“视觉应用→已有结构服务→DATA-L1”；材料流入视觉应用不代表适配或几何模块反向依赖视觉应用。纯几何只消费值式材料；它不取得世界树、任务、自我线程或概念服务。

首期单调用串行处理，轮廓和体素共享只读输入；算法可并行的部分也必须有确定性归并。实时阶段由唯一采集所有者持有相机，向有界处理队列交付材料；不能让多个线程分别打开同一设备。

队列同时限制条数与总字节。实时观察模式可按明确规则丢弃尚未接纳的旧帧并记录源序列缺口；录制完整处理模式采用背压或停止。两者不能混用，丢帧不能仍声明连续时间观察。停止顺序为停止接收→取消/完成未发布计算→关闭设备→释放只读材料；已发布引用仍受数据层保护。

## 10. 原子发布、失败与独立读回

### 10.1 保存流程

1. 纯计算期间零事实写入，输入完整材料保持可用；未达到结构完整条件的输出不进入发布。
2. 通过唯一材料提供者保存必需的原始材料、标定/来源及输出结构；先核验材料完整性及引用资格。
3. 特征owner建立准确F时，将自身节点、类型关系、准确值及必需引用在其合法事务内共同提交。裸值号不是关系端点。
4. 跨材料owner和特征owner的原子需求由正式组合合同裁决：若现有有限N分区提供链能够安全承接则复用；不能承接时采用显式分阶段结果，不声称两个普通调用自动原子。
5. 独立读回F→FT→值→完整材料及来源，逐项比对本次预期。成功载荷不能仅复制原请求或计算缓存。
6. 域规则具备时推进概念形成；世界接纳目标具备时再推进存在及采用关系。这些是后续阶段，不反向假装前面的F从未建立。

材料已保存但F失败时，材料仍是材料，不是已采用特征；F已保存但概念失败时，F仍可用且可无名称；存在接纳失败不能触发无依据的原始材料清理。

### 10.2 写后不确定与重试

| 情况 | 必须行为 |
| --- | --- |
| 发布前拒绝、取消、预算不足 | 无对应事实写入；释放本次工作内存，保留合法输入。 |
| 一部分独立阶段已发布 | 回传已确认身份和实际阶段；不得报告“全失败且零写”，不得删除其它合法事实补偿。 |
| 提交可能生效但回执/读回失败 | 返回“可能已发布”或既有等价状态，不重新分配身份盲写；沿原可靠性合同确认。 |
| 同一次调用内部重试 | 原完整请求及原技术调用身份保持，避免重复事实；这些数据不增加到F/V字段。 |
| 当前事实读取发生漂移 | 沿既有服务合同重新读取或返回漂移；不把旧读取与新采用拼接。 |
| 结构引用被使用 | 按正式引用保护处理退出/回收；缓存驱逐不是事实删除。 |

跨调用/跨进程续行只有具备可恢复输入与正式组合合同后才可承诺；缺少时明确“局部计算可重放，发布续行未提供”。禁止为弥补缺口建立视觉专用幂等表或第二事实截止。

### 10.3 保存范围与资源

首次验证可使用小型材料完整留存。生产环境不能默认永久保存每帧所有中间数组：原始观察保留政策、哪些输出成为独立材料、何时允许释放，按其正式用途与引用合同决定。未冻结政策时只允许有界局部验证，不开启无限增长的实时持久化。

不要求保存每条像素邻接差异或全部射线轨迹；可以保留完整原始深度、标定、网格、规则与参数，以便复算。需要作为权威结构使用的轮廓/体素则须完整保存，不能仅存摘要后声称仍可读取原结果。任何允许的压缩必须无损，或明确建立另一种有损表达，不覆盖准确原材料。

## 11. 资源界限与确定性

记像素数N、边界边数B、射线遍历总格数S、输出体素数V：

- 深度解释、四邻接和连通分区：时间O(N)，工作内存O(N)。
- 网格边轮廓：B≤4N，追踪O(B)；规范排序若使用比较排序需另计O(B log B)。
- 只做终点体素：期望O(N)散列归组；完整射线模式O(S)，输出排序O(V log V)。
- 工作内存总体O(N+B+V)，不计外部保留的历史材料；全场点对比较的O(N²)不是默认方案。

限制项必须在申请内存前及增长过程中检查：像素数、完整字节、同时持有帧数、区域数、边数、网格范围、体素数、单射线/总射线步数、概念候选及遍历预算。小格距＋大量程会使S远大于N，必须单独约束。

资源预算属于执行合同，不是自然特征阈值。设备阈值由实测/校准决定，不能为了跑得快随意扩大分割或相似阈值。预算不足返回未完成，不以静默抽样、跳格、抹孔或删除区域维持成功状态。

确定性分三档验收：同二进制同输入同参数得到相同结构；同合同跨构建得到等价规范结构；跨平台逐位相同。前两者通过不自动证明第三者，浮点临界处理和数学库需单独验证。

### 11.1 参数怎样取得

后续校准不以临时试出一组数值即告完成，至少形成以下材料：

1. 固定实际设备配置、深度模式、分辨率、量程与适用环境；收集不同距离、视角的具名平面和深度台阶，保留完整原始帧及参考测量误差。
2. 根据设备规格与静态重复测量建立深度误差模型，区分无效测量、系统偏差和随机波动。样本最大残差只证明本样本范围，不能当作自然界绝对误差上界；裕量及适用范围必须有依据。
3. 用允许斜面样本确定局部斜率/邻接界限的候选参数，用独立台阶和接触物样本检查过分割、误合并。固定参数后在留出的场景验证，不能用同一张图调整至期望区域数后自证泛化。
4. 根据目标最小可分辨尺度、深度误差和资源上限选择网格分辨率。若精度需求与预算不兼容，报告无法同时满足，不暗中改粗网格或提高阈值。
5. 分开保存分割阈值、网格尺度与概念相似域参数的用途和来源；它们不能因为单位相同就互相代用。最终参数随具名规则读回，不增加准确F/V字段。

本轮没有取得真实校准数据，因此不给生产阈值、误差半径或格距填写假定数值。V矩阵中的具体数值只用于验证数学与边界行为。

### 12.1 多帧的最低前置

每帧必须带可回查的`T_world_camera(t)`、时间域转换、估计误差及适用范围。静止相机也需明确固定安装及校准依据，不从图像相似推导。对移动对象，静态世界融合应拒绝、分离或沿已冻结对象位姿合同处理；不能把不同时间的物体位置平均为一团占据。

多帧一致性可以增强轮廓和体素，但旧视角观察仍有自身证据范围。当前采用与历史识别集合分开；新观察不自动撤销旧事实，也不将历史命中当当前存在证据。
