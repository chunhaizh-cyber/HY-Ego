## 4. 机械合同

```text
合同版本 = 1
幂等域 = 0x19
合法身份 = 1..0x00FF'FFFF'FFFF'FFFF
最终键 = (0x19ULL << 56) | 身份值
```

同身份重复/并发结果全等，不同身份键不同；反解必须回到域`0x19`和原身份。版本漂移、身份
非法或反解矛盾均返回非成功且身份/键全零。

本叶不调用R1—R4/P15/L1/provider，不读当前事实，不形成空仓/事实互证执行证据，不分配稳定
编码，不探测、提交、读回或裁决业务唯一根。
