# LANGUAGE-INPUT-S05-COMPOSITION 组成陈述输入解释计划

日期：2026-10-16。版本：v0.1。状态由`计划/计划索引.md`唯一维护。设计与当前代码基线：`4a837d72064fabdd83d789c0d3cad35ebebae6d4`。

## 1. 目标与边界

用户的长期目标是按语言知识中的句型形成各自的双向转换函数，并由主入口按知识定义分派。本叶在现有输入总入口下增加 **S05 组成陈述** 的只读子解释器：用已发布的五项语言知识，把“〔部分对象表达〕是〔整体对象表达〕的一部分”转换为带原文范围、知识身份、所述现实根和两个强类型对象引用的**组成主张候选**。参数方向来自知识定义的`部分→角色0、整体→角色1`，不是按句面位置把 A 误当整体。它不核查主张真假，也不建立或修改现实存在的父子组成。

本叶的对象短语定位与所指绑定由调用方提供。解释器独立核验范围、固定词、E 当前可读及现实树归属，但没有证据证明“这本书”等短语为何指向该 E；该证明属于前置短语/指代解释结果，不能由本函数反猜。缺少两个短语范围时保留`短语定位待提供`，缺少目标 E 时保留`对象待绑定`，不猜场景成员、焦点、词序或稳定编码。这样能消费未来真实短语解析给出的绑定，当前尚无这样的生产提供者，故本叶不宣称自然句端到端理解。

依据：[0050](../规范/0050_项目通用机器逻辑与禁止性规则总纲_20260721.md) §2—5、[2340](../规范/2340_根规范_自然语言知识.md)、[7230](../规范/7230_子规范_语言材料知识与交互字段.md) §3、[7240](../规范/7240_子规范_自然语言双向转换与组织规则.md) §1—2及§4、[7250](../规范/7250_子规范_最小汉语知识与语言学习.md) §2 的 S05、[代码归属规范](../规范/代码文件建立归属与模块命名规范.md) §4.3—4.5。初始化种子只用于核对当前正式知识形态，不能替代语言 owner 的运行期完整读回。

## 2. 已有能力与切片选择

`初始化材料/最小语言知识种子.txt` 的 S05 已定义两个普通存在角色、`整体/部分`参数映射和五项结构；`新_语言类`公开 DTO 已支持`组成描述`、`整体`、`部分`。`海中鱼巣/业务/解释.基础语言.h/.cpp`已有严格 UTF-8 解码、原文标量范围、已登记词条最长匹配、完整知识枚举、S01/S02/S09 子解释器及`解释已支持单句构式`。现有分派会把 S05 列入`尚无输入解释器的知识节点组`。`新_场景类::读取本树范围成员完整()`可带状态完整读回本树普通成员；旧裸`查询场景范围存在`及`存在属于场景范围`不能用来证明读取完整。`新_存在类::获取存在`可核验两个目标的当前存在身份。

复用现有语言解释 owner，新增一个子入口及私有 S05 结构判别/句面匹配；扩展同一总入口的请求、分支载荷和状态归并。无需新增语言知识存储、工程文件、普通应用装配、世界写服务或第二输出总入口。输出`生成基础语言表达`对 S05 的两个`明确对象描述`目前返回`缺指称`或`能力未支持`，故本叶只闭合输入方向；临时专名首次引介、代词、输出读回另行设计。S05 原文中两个对象表达可以是汉字短语，不限于 A/B 技术占位；只有调用方提供范围及其已消解 E 时才算已绑定，函数本身不把裸名词自动实例化。

## 3. 函数、DTO 与所有权

以下新增类型与自由函数声明放在`海中鱼巣/业务/解释.基础语言.h`的 S09 子解释器之后、总分派类型之前；定义及私有 helper 放同名 `.cpp` 中总分派之前。均属 DATA 外语言解释业务 owner；只借用公开只读服务引用，不拥有或修改领域服务。工程已登记此头源，不改工程/filters。公开函数的合法非成功结构化返回，C++异常向上送至实际最终诊断责任边界；私有纯结构 helper 的工程异常也向上送出，不吞为`结构未支持`。

```cpp
struct 解释对象表达槽 final {
    解释原文范围 原文范围;
    std::optional<稳定编码> 已消解存在节点;
};
struct 基础组成输入请求 final {
    std::string 固定原文;
    稳定编码 语言节点;
    std::optional<稳定编码> 未核验来源语言记录节点;
    std::optional<解释目标世界根> 显式所述世界根;
    std::optional<解释对象表达槽> 部分槽, 整体槽;
    std::size_t 最大原文标量数, 最大知识条目数, 最大组成候选数;
};
enum class 基础组成输入状态 : std::uint8_t {
    已形成唯一主张候选, 对象待绑定, 多规则待解,
    短语定位待提供, 结构未支持, 缺规则, 能力未支持, 世界能力未支持,
    世界根不可读, 对象不属于世界, 输入拒绝, 格式失败,
    引用不可读, 额度不足, 读取漂移, 内部不一致, 工程未完成
};
struct 基础组成候选 final {
    稳定编码 所用知识节点;
    解释原文范围 部分范围, 整体范围;
    解释原文范围 是词范围, 的词范围, 一部分词范围;
    std::optional<稳定编码> 部分存在节点, 整体存在节点;
};
struct 基础组成输入结果 final {
    基础组成输入状态 状态;
    std::string 固定原文;
    std::optional<稳定编码> 未核验来源语言记录节点;
    std::optional<解释目标世界根> 实际所述世界根;
    std::vector<基础组成候选> 候选组;
    std::vector<解释原文范围> 未覆盖范围组;
};
基础组成输入结果 解释单句组成陈述(
    const 基础组成输入请求&, const 新_世界树类&,
    const 新_场景类&, const 新_存在类&,
    const 新_语言类&, const 新_词类&,
    const 概念_存在类&);
```

`解释对象表达槽`中的 E 是**调用方已消解的候选目标**，并非本函数证明的词面指称关系；没有 E 时它是有类型的未决槽，不填零。句法范围以 UTF-8 解码后的 Unicode 标量半开区间表示，与当前解释入口一致。`实际所述世界根`仅在成功读得当前现实根后填入。来源语言记录节点始终标记未核验。本函数不保存语言场景、主张或世界事实，不新建事务/迁移/生命周期。

总分派`基础单句构式种类`增加`S05组成陈述 = 4`，保持已有三个枚举数值不变；`基础单句分支载荷`在原三种载荷后追加`基础组成输入结果`；`基础单句分派请求`在现有`S09预算`之后追加`std::optional<解释对象表达槽> S05部分槽, S05整体槽`及`std::size_t S05最大组成候选数 = 0`，不移动旧聚合初始化位置。原 S01 主体绑定、S02/S09 预算和受询者字段原样保留。总入口签名增加现有参数之外**零个服务**：它已持有 S05 所需世界树、场景、存在、语言、词、存在概念服务。只向 S05 透传新槽及新额度；S01/S02/S09 不读它们。`尚无输入解释器的知识节点组`在 S05 结构定义已识别时不再列它，尚未覆盖的 S03 和其它知识继续列出。所有新增/修改公开函数诊断责任为向上送出；此入口不是日志/弹窗最终责任边界。

## 4. S05 输入解释与总分派

1. 严格解码原文，检查语言节点、非空原文及共享原文/知识额度；标量无效为`格式失败`，合法输入域外为`输入拒绝`，额度不能完整承载结果为`额度不足`，不截断候选。拒绝现有单句闭集不允许的空白、标点或附加句段；来源记录只回显。读取语言，按已登记最长词条匹配取得全句片段，完整枚举知识；任一非完整服务结果映射为具名非成功，不以空组代替。**S05 专用候选额度及两槽绑定只在句面可能匹配 S05 后检查**；无关句面必须返回`结构未支持`，不能因调用方没有 S05 材料把已有 S01/S02/S09 解释降为`分支未完成`。
2. 私有`是S05结构(const 新语言知识信息&, 稳定编码)`只识别同语言、基础表达、陈述、两个且仅两个局部编号0/1的单项普通存在角色，各角色恰一条“本角色→存在”必要类别约束，目标适用条件组为空；含义组恰一项`组成描述/普通陈述`，参数组恰两项且仅有`部分→0、整体→1`，`特征值分支/被询含义/确认范围`皆空。结构五项局部编号恰为0..4，依次是角色0`明确对象描述`、固定词、角色1`明确对象描述`、固定词、固定词，两个角色项的`指代概念节点`皆空；任何额外条件、作用域或子规则均不接纳。它不看来源标签“S05”，也不把“有”解释为组成。固定词节点逐一读回为同语言正式词条；本叶可执行词面限已发布 S05 的`是/的/一部分`，形态相符但词面不在本叶支持集合的知识只在其句面实际可能参与时返回`缺规则`，不能据此宣称 S05 全部知识已解释。
3. 句面匹配以完整最长匹配**整序列**和该条知识的三个固定词节点为准：枚举所有有序三元固定片段，要求第一固定片段前有非空部分区间、第一与第二之间有非空整体区间、第二与第三直接相邻、第三结束于句末；这两个对象区间及三词范围连续覆盖从0到句末，任何固定词被长词遮住均不得私拆。对结构相符但词面未支持的知识，也先按其自己三个正式固定词做同一布局可能性检查；只有确有完整布局才报`缺规则`，无布局不得妨碍其它分支。若所有 S05 知识均无完整布局，**先返回`结构未支持`，不检查 S05 专用槽、额度或现实根**。若任一不支持词面的知识自身确有完整布局，则优先返回`缺规则`、候选组空、未覆盖全句；即使另有已支持布局也不交付其候选作可采用结果。否则两槽都无或恰有一槽时统一不采用任何一槽收窄布局：有至少一个布局则为`短语定位待提供`、候选组空、未覆盖范围组为全句。两槽齐全后，先校验各范围非空、界内、不重叠、E 若给出则编码有效；无效为`输入拒绝`。再以两槽范围对布局的两个区间作精确相等核验，不信任调用方句面声明；合法两槽若与所有布局都不相等，则为`结构未支持`，**先于 S05 候选额度检查**。两个槽内可以包含多个词或未知片段，因为前置短语解释负责其内部含义。多个布局或规则匹配时全部保留，不取首项。
4. 两槽范围与至少一个布局精确相等后，S05专用候选额度须非零；每个匹配布局/规则形成一项候选，超额返回`额度不足`且不交付可采用候选。槽缺 E 时先记录对应未决引用及对象范围，最终状态按第5项的多规则优先级裁决；两个 E 都已绑定时未覆盖范围组为空。其余无候选非成功保留全句未覆盖，不能报告解析完成。只有在匹配 S05 句面后才读取世界：`世界树.获取世界树根场景()`必须有效，且与`场景服务.获取根场景()`和`读取本树范围成员完整()`的成功根相同；首次根不一致为`内部不一致`，末尾复读不一致为`读取漂移`。显式所述世界根非此现实根返回`世界能力未支持`。每个已给 E 要经`存在服务.获取存在()`完整读回并在完整成员表中精确出现；初读不可读为`引用不可读`，成功完整表内确实不在根树才为`对象不属于世界`。场景完整读取的`根不可读/读取已变化/结构不一致/资源失败`分别映射`世界根不可读/读取漂移/内部不一致/工程未完成`。两个 E 即使相同，也只是一个待核验的自我组成主张，不据此推出真假。候选按规则身份和实际范围保留，语义等价的多个来源不因排序丢失。
5. 服务非成功映射冻结如下：语言/分词`未找到→引用不可读、输入不合法→输入拒绝、结构不一致→内部不一致、资源失败→工程未完成`；知识`未找到→缺规则、输入拒绝→输入拒绝、尚未初始化或未支持→能力未支持、引用不可读→引用不可读、读取漂移→读取漂移、内部不一致→内部不一致、工程未完成→工程未完成、额度不足→额度不足`；预期固定词`未找到→引用不可读、输入不合法或结构不一致→内部不一致、资源失败→工程未完成`。所用固定词、最长匹配全序列、知识全集、现实根、完整成员表与已用 E 末尾复读；不同 E 内容/根/成员表/规则/分词为`读取漂移`，非完整读取按本项及第4项映射，清空不能作为完整解释采用的候选。跨语言、世界和存在 owner 没有共同原子快照，复读只证明本次观测前后相容，不能保证未检测到 ABA 或并发下绝对最新。候选恰一且两个 E 均已绑定为`已形成唯一主张候选`；任一 E 未绑定为`对象待绑定`；多个可用布局/规则优先为`多规则待解`，即使某候选仍待绑定也保留未决 E。无规则与句面不匹配分开；不支持词面规则若存在完整布局则优先报`缺规则`，不把已支持规则的唯一候选宣称为闭集唯一。
6. 总分派在预读知识定义时把 S05 与 S01/S02/S09 一起判别，同一定义落入两形态为`内部不一致`；每种形态至多调用一次对应子函数，S05 子函数自行覆盖该形态全部知识。无论其它分支成功与否都调用所有已选分支，维持原有全知识复读。新增`裁决分支(const 基础组成输入结果&)`：唯一、待绑定、多规则、句面不匹配分别映射现有`单句分支裁决`，`短语定位待提供`及其它非完整状态映射`未完成`。顶层候选数计算 S05 的**有规则身份和两处有效范围的候选**；待绑定候选仍计为一项，但必须标明未决 E，不能把空占位组算作唯一已解。S05 未完成不清除其它已形成分支；闭集唯一始终只指当前已实现构式闭集，不证明其它知识不能匹配。
