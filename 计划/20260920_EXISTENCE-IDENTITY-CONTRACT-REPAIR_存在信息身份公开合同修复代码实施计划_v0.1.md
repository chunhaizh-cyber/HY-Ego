## 1. 目标、事实与完成边界

修复已发布 IF/R ABI 的编译前提：`海中鱼巣/领域/数据服务.存在类.h`已在`实例特征IFR完整投影`、读取/提交请求和特征概念应用消费者中使用`存在信息身份`，但当前正式代码没有该类型定义。该遗漏使任何合法包含存在类头的翻译单元失败，并阻断`ARCH-L4-INSTINCT-ROOT-DEMAND-PROVIDER`验证。

## 2. 正式依据和裁决

- `规范/1140_根规范_存在节点_20260720.md`：存在身份是世界存在而非概念身份；其事实、生命周期和业务资格不得由裸身份推定。
- `规范/4230_子规范_L2六类纯结构统一合同.md` §4.2：存在 owner 是唯一内容写入者，完整读取在同一截止闭合存在身份来源。
- `规范/4115_子规范_实例特征容器与区间材料.md` §2—§2.1：IF/R 的 E 是存在 owner 的既有存在节点身份，生命周期仍由L1事实投影承载。
- `规范/详细设计/20260915_INSTANCE-FEATURE-IF-R-CONCEPT-FOUNDATION_实例特征容器与区间概念汇聚详细设计_v0.1.md` v0.11：冻结本修复的精确物理位置和 DTO 形状。
- 当前源码与`7c5cce844`变更：该提交首次使公开 IF/R DTO 实际消费未定义的`存在信息身份`；同目录的`特征信息身份`、`状态信息身份`和`动态信息身份`均采用“稳定编码 + 默认相等”强类型模式。

裁决：本修复不是新机器语义。`存在信息身份`只使已经写入 IF/R ABI 的 E 身份类型可解析；它不验证存在、不会转换或复制事实、不改变既有`稳定编码`入口，也不创建新的 owner、事务或生命周期。

## 3. 冻结实现合同

仅在`海中鱼巣/领域/数据服务.存在类.h`的`存在类数据合同版本`之后、所有消费点之前新增：

```cpp
struct 存在信息身份 final {
  稳定编码 编码{};
  friend bool operator==(const 存在信息身份&, const 存在信息身份&) = default;
};
inline bool 有效(存在信息身份 v) noexcept { return 有效(v.编码); }
```

该聚合初始化允许现有调用方用`存在信息身份{稳定编码}`表达已知 E；除默认构造、默认比较和上述有效性谓词外，不新增构造器、隐式转换、哈希、序列化、I/O、读取、写入、缓存或服务入口。所有生命周期、存在族来源、owner 和引用核验继续只由现有存在服务和 L1 事实完成。
