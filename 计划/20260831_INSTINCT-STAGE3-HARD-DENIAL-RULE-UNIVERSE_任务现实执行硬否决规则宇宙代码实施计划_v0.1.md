## 5. 非成功和安全收口

- 坏合同、零 G0、零幂等、坏版本 / 原因 / 事件 / 动作材料：入口拒绝；
- L1 许可拒绝：许可拒绝；
- G0 前后变化：当前性漂移；提交后读回失败例外为已可能发布；
- 首版 / 后继版本不连续：版本漂移；
- 同键异义：幂等冲突；
- 同语义约束异义、外部端点错绑：引用冲突；
- 漏 / 多 / 重当前宇宙或成员闭包：规则宇宙不闭合；
- 现实改变动作缺共同场景、场景不一致或成员不闭合：场景范围不闭合；
- `bad_alloc` / `length_error`：资源失败；其它异常：内部错误；
- 所有非成功发布结果无宇宙 / 规则载荷；仅已可能发布携带四字段见证；
- 所有非成功读取结果空载荷、截止 0。
