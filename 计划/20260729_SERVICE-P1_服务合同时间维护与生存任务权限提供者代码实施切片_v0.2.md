## 9. 算术与结果硬合同

1. `B=min(I64_MAX,D0*有效秒)`；30% 安全分解；`P1=B-P0`；增加按剩余空间、减少按当前值饱和，舍弃不补领。
2. 合同+预支同候选；余款/关闭、准备补回、完整秒衰减和根回归形成单一治理候选。
3. 时间只取单调完整秒；多需求只取最长等待；批量分段与逐秒事实序等价。
4. 30 天无活动目标 0；有活动只保护正值到 1，不从 0 生成值。
5. A=0 先保持终止；同秒主动安全改变跳过被动回归；服务值只调节生存安全根，不改 6140 分层值。
6. A=0/1 两根权限均 0；A>1 两项非负且总和百万。
7. 安全来源组合 SAFETY 权限；独立服务来源取服务根；安全兼服务只走安全；多来源取最高不求和。
8. 全部算术 checked wide；禁止溢出后钳制。
9. 身份/请求非法为入口拒绝；版本漂移、材料缺失、时间证据缺口、结构拒绝、资源失败均按详细设计载荷规则返回。

## 10. 非值式参与与事务

`服务生存外部事实规格` 是协议纯值 DTO。下列三实体只归数据操作：

```text
服务生存外部事实参与载荷
服务生存外部事实参与结果
服务生存外部事实参与提供者
```

载荷只含 `vector<unique_ptr<节点直接身份结构写入事务参与者>>`、候选代次、`服务生存输入版本快照` 和方法绑定组版本；move-only、不可复制，不含无正式所有者候选引用。

参与者工厂、读回和数据操作签名逐项服从详细设计 v0.2 第 7.4 节。固定顺序：

```text
服务生存记录 -> 状态 -> 动态 -> 关系/因果 -> 索引
```

锁序为事务域独占许可 -> 记录参与者锁 -> 外部固定顺序锁 -> 准备/首次读回 -> 确认 -> 最后发布 -> 释放许可 -> 记录仓共享读回。载荷活到执行和读回结束；临时原始指针 span 不保存。

执行器状态映射、读回字段和内部不一致边界以详细设计第 7.4 节为准。
