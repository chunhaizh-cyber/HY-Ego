## 1. 目标与完成条件

以一份代码结果把既有需求、任务 DATA-L2 结构服务装入普通应用唯一 L1 运行包，公开 const / non-const 同实例入口，并让既有合法端到端消费者通过该入口完成需求材料建立及任务核心新增、读取、列表项反查和退出读回。

完成必须同时满足：

1. 普通应用唯一持有需求、任务服务，owner 和服务各只构造一次；
2. 需求服务借用同实例存在 / 特征 / 状态服务，任务服务借用同实例需求服务；
3. 四个 getter 返回上下文内同实例引用，零 L1 能力泄漏；
4. 既有需求测试归零手工 L1 / owner / 服务装配；
5. 通过普通应用入口真实完成任务核心增、读、按列表项反查、退及退出后读回；
6. 根工程双配置、两个现有端到端入口和 strict 通过。
