## 1. 目标、范围与完成条件

为 L2 场景结构 S3 的历史完整场景读取补齐一个业务中性的 L1 提供者：调用方给出所属节点和非零历史截止事实代次，L1 在一次共享许可内返回该截止时由属性槽确认有效的完整属性值事实组，按属性类型稳定编码、值稳定编码升序，并同时回显请求截止和实际读取时当前事实代次。

本叶只增加有界历史属性值组读取，不实现 L2 场景固定属性换代、场景退出、引用保护或完整场景投影。它不建立“所属节点的全部值”枚举、整库历史枚举、分页、审计、恢复、缓存、SQL 回源、业务属性解释或验收专用入口。

完成条件固定为：

1. 公开 DTO 唯一表达所属节点、历史截止、实际读取代次和有序完整属性值组；
2. 仓库只增加保存稳定编码的可重建全生命周期属性槽值候选索引；只有成功属性槽变更新当前值时登记，普通值创建不得登记；
3. 属性换代、显式值退出和所属节点退出后候选编码永久保留；索引不保存第二份值事实、属性槽或生命周期；
4. 查询在一次共享锁内从所属节点候选索引定位，并逐项回读 `当前值` 或 `历史` 中的权威完整 `值事实`，按 `[创建事实代次, 退出事实代次)` 过滤；
5. 同一属性类型在同一历史截止最多一项有效值；多项有效、候选与权威事实或成功属性槽变更记录矛盾均为 `内部不一致`，不得任取一项；
6. 空组成功、非法请求入口拒绝、未来截止事实代次漂移、分配失败资源失败；所有非成功属性值组为空；
7. 生产外公开接口验证覆盖初始槽值、换代、显式退出、节点退出、未入槽值隔离、排序、幂等、非法请求、未来截止和当前读取不受历史候选污染；
8. 主工程 Debug / Release x64 保持完整编译链接，生产入口、L2 模块和工程登记不因本叶改变。

### 2.2 复用 / 扩展裁决

单事实 `读取中性历史事实` 只能按调用方已知的值稳定编码返回一条事实；节点当前属性槽只表达当前值，不能回答旧截止。扫描 `当前值` 会漏掉已退出或已换代值，扫描 `历史`、幂等账或整仓违反 4015 普通 CRUD 的有界访问边界。

也不能直接索引“所属节点的全部值”。现行 L1 允许创建未进入属性槽的值；这类值不是该节点在任何截止下的固定属性，若被条件查询返回会把普通值存在事实伪装成属性事实。

裁决：扩展现有 L1 数据头、仓库和服务，在原权威仓状态中增加一个只保存稳定编码的全生命周期属性槽值候选索引。候选资格唯一来自成功中性写集中的 `属性槽变更`，并以同一不可变幂等记录的 `首次新编码映射` 解析新值编码。普通查询只消费候选索引并回读权威值事实；`状态完整` 才使用成功幂等记录对候选集合做双向互证。

该入口不是当前属性读取、单事实历史读取、全部值枚举、整库读取或验收专用入口的同义门面。L2 后继只消费公开值式结果，不取得仓库、锁、索引、历史表或幂等账访问权。

## 4. 最终公开 DTO 合同

`L1中性CRUD.数据.h` 增加：

```cpp
enum class L1中性历史属性值组读取状态 : std::uint8_t {
    成功 = 1,
    入口拒绝 = 2,
    事实代次漂移 = 3,
    资源失败 = 4,
    内部不一致 = 5
};

struct L1中性历史属性值组读取请求 final {
    std::uint32_t 合同版本 = L1中性CRUD合同版本;
    稳定编码 所属节点;
    std::uint64_t 历史截止事实代次 = 0;
    friend bool operator==(const L1中性历史属性值组读取请求&,
        const L1中性历史属性值组读取请求&) = default;
};

struct L1中性历史属性值组读取结果 final {
    L1中性历史属性值组读取状态 状态 =
        L1中性历史属性值组读取状态::入口拒绝;
    std::uint32_t 合同版本 = L1中性CRUD合同版本;
    稳定编码 所属节点;
    std::uint64_t 历史截止事实代次 = 0;
    std::uint64_t 读取事实代次 = 0;
    std::vector<L1中性值事实> 属性值组;
    friend bool operator==(const L1中性历史属性值组读取结果&,
        const L1中性历史属性值组读取结果&) = default;
};
```

合同版本复用 `L1中性CRUD合同版本=1`，不建立第二版本轴。请求有效条件为：合同版本正确、所属节点非零、历史截止事实代次非零。

结果始终逐字段回显所属节点和请求历史截止。成功时 `读取事实代次` 是持共享锁读取时的权威当前事实代次，允许大于历史截止；事实代次漂移时回显安全取得的实际当前代次；入口拒绝、资源失败和不能信任仓状态的内部不一致不伪造读取代次。所有非成功属性值组为空。

空组是合法成功：未知非零所属节点、该截止尚未形成任何属性槽或全部属性值已在截止前退出，均返回成功、实际读取代次和空组。所属节点本身是否存在、当前或已退出由上层具名节点历史读取裁决；本入口只回答有界属性值集合，不把空组折叠为未找到、已退出或属性未设置。

## 5. 仓库状态、登记与可重建合同

`L1事实基座仓库::状态` 增加一个非权威字段：

```text
历史属性槽值候选索引
  [所属节点稳定编码]
  [属性类型稳定编码]
  -> vector<值稳定编码>
```

名称中的“历史”表示支持任意已发布历史截止的全生命周期候选集合；它同时包含仍当前、已换代和已显式退出的值，但只包含曾由成功 `属性槽变更` 成为当前值的编码。索引不得复制材料、来源、生命周期、属性槽或完整事实，不是第二权威历史表。

唯一更新顺序固定为：

1. 值新建只写候选 `当前值`，不得在值创建循环中登记历史属性槽值候选；
2. 成功处理每项 `属性槽变更` 时，从新当前值本地键取得本次唯一新编码，回读候选 `当前值` 并核对所属节点和属性类型与槽项一致；
3. 在切换 / 新增属性槽的同一候选状态中，按值稳定编码有序且无重复地插入对应 `[所属节点][属性类型]` 候选组；任一解析、互证或插入失败则候选发布失败，不改变权威状态；
4. 已有槽换代时旧值写入 `历史` 并从 `当前值` 删除，但旧候选原项永久保留；
5. 显式值退出、所属节点退出、属性类型节点退出或来源节点退出均不删除候选；退出合法性仍由现行引用闭包和同写集规则裁决；
6. 精确重复在现行幂等读回分支返回，不重复登记；同键异义在候选形成前返回幂等冲突，候选零变化；
7. 不增加从 `当前值`、`历史`、幂等账或整仓热路径重建索引的普通提交 / 查询步骤；进程内状态从空仓开始，候选资格只经同一属性槽变更更新点建立。

新增最小私有辅助固定为：

```text
插入历史属性槽值候选索引(状态&, const 值事实&)
```

辅助只校验非零值、所属节点、属性类型编码和创建代次，按 `lower_bound` 插入稳定编码并拒绝重复；不读当前属性槽、不复制事实、不记录日志。调用方必须先证明该值对应当前成功处理的 `属性槽变更`。

`状态完整` 增加候选索引、成功幂等记录和权威值事实三方互证：

- 每个候选组非空，所属节点键和属性类型键非零，值编码严格升序，且同一值编码在整个候选索引中只出现一次；
- 每个候选编码必须在 `当前值` 或 `历史` 中恰一命中完整 `值事实`，不得指向历史节点或历史关系；所属节点、属性类型、编码和生命周期必须与候选键一致；
- 从每条成功 `中性幂等记录::首次规范化写集.属性槽变更`，使用 `首次新编码映射` 解析 `新当前值`、所属节点和属性类型引用，形成唯一期望候选；每项槽变更恰对应一个候选；
- 每个实际候选反向恰对应一条成功属性槽变更，不允许无记录候选、重复候选或一次槽变更缺候选；
- 候选值的创建事实代次等于该成功记录的首次发布事实代次，且其所属节点、属性类型与槽变更解析结果一致；
- 每个当前节点属性槽的当前值必须命中候选索引对应组；
- 未被任何成功属性槽变更引用的新建值必须保持未索引，永不由本入口返回；候选集合数量必须等于全部成功槽变更解析出的唯一值编码数量；
- 任一矛盾使候选发布失败或现行读取返回内部不一致，不扫描修复、不删除证据、不降级为空组。

幂等账只参与 `状态完整` 的确定互证，不参与普通历史属性值组查询；索引仍可从全部成功不可变记录和当前 / 历史权威值事实确定重建，因此不取得事实权威。

## 6. 仓库查询与公开服务函数

仓库 public 增加：

```cpp
L1中性历史属性值组读取结果 读取中性历史属性值组(
    const L1中性历史属性值组读取请求& 请求) const;
```

服务 public 增加同名唯一入口：

```cpp
L1中性历史属性值组读取结果 L1事实基座服务::读取中性历史属性值组(
    const L1中性历史属性值组读取请求& 请求) const;
```

仓库算法固定为：

```text
纯值校验请求
-> 一次取得阻塞式 shared_lock<shared_mutex>
-> 隔离则内部不一致
-> 当前事实代次小于请求历史截止则事实代次漂移并回显实际当前代次
-> 按所属节点定位历史属性槽值候选索引
-> 无所属节点候选组则成功空组
-> 遍历该所属节点的各属性类型候选组
-> 按候选值稳定编码逐项从 当前值 或 历史 回读权威完整值事实
-> 验证编码、所属节点、属性类型、生命周期和唯一来源
-> 仅保留 创建事实代次 <= 截止 且
   (无退出事实代次 或 截止 < 退出事实代次) 的值
-> 同一属性类型有效项超过一项则内部不一致
-> 按 属性类型稳定编码、值稳定编码 升序形成成功结果
```

历史适用区间唯一冻结为半开区间 `[创建事实代次, 退出事实代次)`。截止等于创建代次时值已有效；截止等于退出代次时值已无效。没有退出代次的当前值从创建代次延续至实际当前代次。请求截止可以等于实际当前代次；大于实际当前代次一律返回事实代次漂移，不返回部分组。

一个候选编码同时命中当前与历史、两处均未命中、命中历史非值事实、所属节点 / 属性类型不匹配、候选编码不递增、生命周期非法、同一属性类型在截止时有两个有效值或最终输出失序，均返回内部不一致并清空属性值组。

服务入口先做相同纯值校验，再调用仓库一次；不另取事实代次、不重试、不二次解释属性资格、不扫描幂等账或整仓。`std::bad_alloc` 和 `std::length_error` 映射资源失败，其它异常映射内部不一致；异常结果回显请求条件、读取事实代次为 0、属性值组为空。函数不写日志、不取得业务解释权。

## 7. 创建、换代、显式退出、节点退出与并发边界

本叶不新增写入口，完整复用 `提交中性写集`：

- 初始属性：新值只有与属性槽变更在同一成功写集中发布后，才从其创建代次起成为历史属性候选；
- 普通值创建：未被同一成功写集属性槽变更引用时保持非属性值，不登记候选，即使所属节点和属性类型与某槽相同也不得返回；
- 属性换代：一个中性写集创建新值、切换槽并退出旧值；旧值适用区间在新代次结束，新值从同一代次开始，不产生空洞或双当前；
- 显式值退出：退出代次是第一个不再适用的事实代次，候选编码永久保留，当前属性槽按现行规则移除；
- 所属节点退出：调用方必须在同一合法写集中显式闭合当前附属值和引用；节点退出后候选仍允许按节点退出前的旧截止回读权威历史值；本入口不据当前节点可见性清除或遮蔽旧截止结果；
- 写候选仍在独占锁内复制、验证并一次交换；历史查询只在一次共享锁内读取，不可能返回候选、混合发布前后状态或把索引命中冒充事实；
- 本叶不把阻塞式共享锁改成 try-lock，不增加 `许可拒绝` 状态。长时间并发、公平性和性能不属于本叶验证范围。

### 8.2 必过矩阵

在一个新 L1 服务实例中按有记录的事实代次顺序验证：

1. 先建立一个普通所属节点、两个不同属性类型节点和所需来源节点，使后续初始属性发布前存在非零历史截止；
2. 一个成功写集为同一所属节点建立两种属性类型的初始值和两个属性槽；创建前截止返回成功空组，创建截止返回两个完整值；
3. 输出按属性类型稳定编码、值稳定编码升序；每项所属节点、属性类型、材料、来源和生命周期逐字段正确；
4. 另建一个所属节点和属性类型相同、但未进入任何属性槽的普通值；当前及历史各截止均不得在属性值组出现该值，单事实当前 / 历史入口仍按自身合同可读；
5. 一个原子写集为第一种属性换代：建立新值、切换槽并退出旧值；换代前截止只含旧值，换代截止只含新值，第二种属性保持不变，且无空洞或双值；
6. 后续显式退出第二种属性的当前值；退出前最后截止仍包含，截止等于退出代次时不包含，历史单事实仍返回完整退出生命周期；
7. 后续在闭合当前附属值和引用后退出所属节点；节点退出后以退出前旧截止查询仍返回当时有效完整属性值，以退出截止查询不把已退出当前值复活；
8. 对一次含属性槽变更的完整原请求使用同一幂等键精确重复，事实代次不推进且查询中对应候选值只出现一次；
9. 对同一幂等键提交逐字段不同请求得到幂等冲突，事实代次、当前属性和历史查询结果零变化；
10. 合同版本错误、零所属节点和零历史截止分别入口拒绝、空属性值组且当前事实代次不变；
11. 以实际当前代次加一查询得到事实代次漂移，准确回显请求截止和实际读取代次，属性值组为空；
12. 每项成功结果的实际读取代次等于调用时当前代次，输出值均满足半开适用区间；当前属性 / 当前值读取在换代和退出后只反映当前事实，证明历史候选未污染当前路径。

资源失败、真实内存分配故障、长时间并发、故意破坏私有索引或幂等账不做黑盒注入；由异常映射、状态完整性源码闭包、Debug / Release 编译和公开矩阵分别覆盖，不得虚报为运行验证通过。
