## 4. 实施步骤

1. 在实际存在数据头新增移除请求、已退出归属关系见证、移除事实、移除结果及纯值有效性 / 完整性函数；不新增状态枚举，不改变现有 DTO 字段或稳定值。
2. 在 `读取初始场景接纳` 的失败分账中，只把精确请求归属关系中性已退出且无当前事实映射为未找到；成员、场景、关系类型等其它必需事实退出继续内部不一致，其余失败语义不变。
3. 为组合服务既有 `在初始场景创建实际存在` 增加 const 重载；非 const 入口只原样转发 const 实现。读取入口和 P5 创建语义不变。
4. 给组合服务构造追加 `L1事实基座服务&` 非拥有引用，新增 `mutable std::mutex` 和只保存幂等身份的移除定位；不缓存请求、写集、关系事实、首次结果或领域事实。
5. 新增唯一 const `移除实际存在当前场景`。请求无效立即入口拒绝；首次身份先建立暂定定位，读取起始代次、经现有正式组合入口读取当前实际存在、复读结束代次并逐字段互证共同截止。
6. 使用高八位 `0x1A` 和公开幂等身份形成最终键；写集固定零节点、零关系新建、零值、零槽和请求旧归属关系一退出，不接受本地键，不产生稳定编码映射。
7. 首次和已定位路径均恰一次调用 `提交中性写集`。提交非成功且为首次暂定定位时删除定位；成功、精确重复或发布后读回失败时保留定位。
8. 成功类结果固定读取起始代次、旧关系当前已退出、同编码历史关系、当前存在、当前原场景、当前资格值、资格属性槽、正式组合读取未找到和结束代次；逐字段验证历史关系退出代次等于首次发布代次，其余事实未退出且同一截止。
9. 从历史关系和当前保留事实形成完整移除事实。任何矛盾返回结构化非成功，不用日志、缓存、请求回显或旧 DTO 补成成功。
10. 运行期上下文把组合服务改为公开导入，构造时追加既有 L1 服务引用，并只新增 const 组合服务访问器；启动锚定位、`完整()`、初始化顺序和其它服务构造零语义修改。
11. 删除本目标路径可能出现的领域意图、执行证据、业务标签、legacy 提交、完整快照、旧世界树骨架和验收逻辑；现有不属于本目标的 legacy 文件原样保留。
