## 5. 机械实施合同

### 5.1 DTO 与适配器

逐字实现详细设计第 4—6 节的合同版本、请求、九状态、两来源、材料、结果和 `自我世界树根消费适配器`。全部业务函数、变量、类成员和类型使用中文。

适配器构造绑定 `L2场景结构服务&`；不可默认、复制或移动。公开函数只为：

```cpp
自我世界树根消费结果 消费(
    const 自我世界树根消费请求& 请求) noexcept;
std::optional<自我世界树根消费材料> 读取已发布材料() const;
```

`消费` 持有唯一 I2 发布锁，按 `请求校验 -> 从已发布材料内嵌请求判定异选择 -> 当前登记读取 -> 当前整树读取 -> 根不变量验证 -> 局部完整构造 -> 唯一 optional noexcept swap` 实现。不得建立第二选择槽。请求只锚定首次根选择和标记，本轮整树及截止只用 R1 返回。重复每次正式读回；异请求零 R1 调用；任一失败保留旧值。

### 5.2 普通应用

在最终六服务和局部 A1 `unique_ptr` 成功后、全部局部对象尚未 move 时，以 `聚合服务->取得L2场景结构服务()` 构造局部唯一适配器。上下文私有构造参数在聚合参数后追加适配器 `unique_ptr&&`，构造初始化列表和成员声明在 I1 发布锁 / 待收敛请求 / 根读回之后追加适配器，最终一次移动运行包、六服务、聚合和适配器发布上下文；禁止先构造上下文后注入。上下文新增 const / 非 const getter。构造失败状态在激活基线最终最大普通应用状态后连续追加；上下文发布前适配器必须存在。

不得让适配器拥有 A1 / R1，不得复制六服务，不得引入第二发布槽到普通应用；I2 状态只在适配器内部。

### 5.3 正式启动和阶段

`运行普通程序` 在 I1 成功后，从该次 `已发布根` 逐字段形成 I2 请求并调用上下文适配器。不得先从上下文缓存另读一次取代成功结果，也不得传入 I1 整树快照作为本轮事实。

- I1 失败保留 `现实世界树根初始化 = 14`；
- 删除枚举 `自我初始化待适配 = 15` 和 I1 成功后的无条件阶段 15 返回，数值 15 不复用；
- 追加 `自我世界树根消费 = 16`；I2 非成功返回 `初始化失败 / 16`；
- 追加 `自我初始化能力未实现 = 17`；I2 成功固定返回 `初始化失败 / 17`。

阶段 17 不得用空函数或固定成功解除。两种普通模式均执行同一路由，所有分支宿主调用数为零。

## 6. 并发、失败和生命周期

- I2 锁序只允许 `I2 发布锁 -> R1 内部锁`；`运行普通程序` 已持有同一次 I1 成功结果的局部值，I2 不调用 I1 getter、不取得 I1 私有锁，也不持有 I1 引用；
- 持锁期间不调用 I1、其它上层服务、日志、I/O、用户回调或等待；
- 同请求并发串行且每个实际调用重新 R1 读回；异请求冲突；
- `bad_alloc` 映射资源失败，其它异常映射内部不一致，`noexcept` 不外泄异常；
- getter按值复制，未发布为空，复制异常不伪装为空；
- 上下文析构只删除适配器和值式副本，不退出 R1 根；
- I2 成功不建立自我，阶段 17 保持后继路径不可达。
