## 4. 物理实现合同

### 4.1 真实模块

新建：

```cpp
export module 海中鱼巣.领域.组合.运行期只读查询;
```

模块只 import 场景、存在和结构聚合三个正式模块；不得 import L1、普通应用、SELF-FORM、线程、缓存或控制面板模块。模块唯一导出详细设计第 4 节 DTO、`运行期只读查询组合器`及读取函数。

组合器只保存 `const L2结构聚合服务&`，不可复制、不可移动。全部中间结果为局部值式材料，不保存上次请求 / 结果，不建立 mutex、幂等账或第二 provider。

### 4.2 固定调用与状态映射

严格按详细设计第 5 节顺序调用。每个请求头使用对应 owner 非零截止和当前读取类别。先复核结构化状态、结果截止和成功形状，再访问载荷；任一非成功立即返回，禁止从后续服务补救前一项。

状态映射固定为：未找到 / 已退出 -> 材料缺失；事实代次漂移 -> 当前性漂移；入口拒绝 / 幂等冲突 / 引用冲突 / 数量预算不足 -> 提供者拒绝；资源失败 -> 资源失败；坏成功形状、其它不应出现状态和异常非资源类 -> 内部不一致。

### 4.3 纯值互证与一次构造

模块私有中文辅助完成严格排序查找和逐字段相等；不导出公共工具。必须检查：

- 根 / 所在 / 内部世界三场景互异，整树单根完整；
- 两个具名场景在整树中各恰一，两条直接父子边各恰一；
- 反向成员引用恰一，与请求关系编码和整树正向成员相等；内部世界不含自我成员；
- 内嵌宿主、正向宿主和反向宿主完全相等；
- 角色键 / 关系编码 / 目标存在、存在来源和完整存在共同闭合；
- 全部活动生命周期、读取类别和结果截止满足正式 DTO 完整性。

完整快照先在局部构造，成功结果最后一次移动形成；资源分配失败返回资源失败。禁止先写 optional 再逐步填充。
