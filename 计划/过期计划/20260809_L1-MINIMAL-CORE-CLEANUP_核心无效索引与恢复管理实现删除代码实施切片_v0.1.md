## 3. 白名单与禁止范围

允许修改和删除的九个生产 / 工程文件、允许新增的一份记录，精确采用详细设计第 4 节。不得修改任何领域代码、启动代码、运行期上下文、生产配置或其它 WIP。

工程和 filters 中已有双轴草案未提交行必须原样保留且不得进入本计划提交；本计划只暂存 L1 索引删除对应的独立差异。

## 4. 实施步骤

1. 删除合同和服务中的提供者身份、审计和恢复入口。
2. 删除仓库中的审计 / 恢复方法、候选状态和旧管理状态；同步删除仅由这些对象消费的数据结构及辅助逻辑。
3. 保持中性 CRUD 全部公开入口、状态与幂等行为不变。
4. 删除可重建索引三个文件和两份工程登记。
5. 全仓扫描目标符号、删除文件、工程引用和生产自检残留。
6. 执行完整验证并写入生产外具名记录。

若构建证明某个拟删除对象存在计划外真实消费者，停止该对象删除并具名返回设计支撑；不得临时恢复兼容壳。
