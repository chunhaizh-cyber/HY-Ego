## 4. 目标代码与物理位置

### 4.1 执行器同模块许可

在 `执行器.节点直接身份结构写入.ixx` 内逐字建立详细设计 §3.1 的规则常量、见证、状态、move-only 许可和取得结果。

许可、事务域必须属于同一命名模块。允许在同模块内把事务域声明锚点放到许可 friend 之前；禁止在任何其它命名模块前置声明事务域或许可。

许可 private 区完整定义空 `私有状态 final {}`，F0 唯一成员 `std::unique_ptr<私有状态> 状态_` 始终为空。默认、移动后 `有效()==false`，`读取见证()=={0,0,0}`。

### 4.2 事务域

在现有 public 区增加：

```cpp
节点直接统一冻结许可取得结果 取得统一冻结许可(
    std::uint32_t 预期冻结规则版本) const;
bool 冻结许可属于本域(
    const 节点直接统一冻结许可& 许可) const noexcept;
```

F0 固定返回 `{未实现,nullopt}` 与 `false`；不得读取成员、取得现有读取许可、锁或修改事务域构造。

### 4.3 类型化值冻结读取模块

新建 `海中鱼巣.核心.冻结.节点直接类型化值`，只 import 执行器和类型化值仓。逐字建立详细设计 §3.3 的读取状态、副本、结果、结构观察 / 结果和访问器。

访问器唯一成员为非拥有 `const 节点直接类型化值仓库*`；构造只保存精确仓地址。两个读取根固定返回 `{未实现,nullopt}`，不读取许可、不解引用仓。

执行器不得 import 新冻结读取模块；类型化值仓不得 import 执行器或新冻结读取模块。

### 4.4 自检与接线

新建骨架自检模块，在 `启动.应用程序.ixx` 登记唯一 `WORLD-TREE-CORE-FREEZE-DP-S01`、顺序 225。S0 记录顶层数量 `N`，目标 `N+1`；R1 只原位扩充该身份。
