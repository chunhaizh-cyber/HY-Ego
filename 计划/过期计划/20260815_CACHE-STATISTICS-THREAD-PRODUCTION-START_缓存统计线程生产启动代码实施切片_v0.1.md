## 1. 目标与完成条件

实现一个真实缓存统计支持线程：按显式刷新请求，经 8110 `const 线程生命周期投影读取端口` 正式读取同运行代次当前投影组，形成确定、可丢弃的线程统计候选并一次替换当前统计视图；线程生命周期复用 SUPPORT 最终候选 provider。

完成必须同时满足：

1. 只新增一个稳定数据头和一个真实模块；不得恢复旧 `缓存统计线程.ixx`、旧有界运行消息队列、旧缓存仓库或第二生命周期 owner。
2. `启动缓存统计线程` 精确组合 SUPPORT 创建、内部进入等待和失败安全回收；成功只返回一份不可复制、只可移动构造的缓存统计线程租约。
3. 租约唯一拥有刷新队列、统计视图、模块私有入口和 SUPPORT 候选租约，并公开刷新提交、快照读取、停收截止、处理位置、等待、冻结丢弃和右值停止连接。
4. 每个有效刷新恰调用一次 `读取当前线程投影组({合同版本, 运行代次})`；`已读取 + 空组`发布合法全零统计，其他状态不得冒充空组。
5. 统计候选完整后一次替换，按线程身份和强枚举稳定排序；统计缺失、不可用、队列满或刷新丢弃均不改变业务事实。
6. 根工程双配置、生产外专项双配置和静态门禁通过；真实资源耗尽等无法确定性注入项保持 `NOT_RUN`。

## 4. 物理实现合同

### 4.1 数据头

新建 `海中鱼巣/线程/缓存统计线程.数据.h`，声明详细设计第 4—6 节全部稳定值类型：合同常量、三类强类型统计项、线程统计快照、刷新请求 / 状态 / 结果、处理位置、快照读取、停收、等待、冻结丢弃、启动和停止连接请求 / 状态。传统 include 时自带标准头与 `线程生命周期.数据.h`；模块定义 `CACHE_STATISTICS_THREAD_NO_INCLUDES` 时只展开正文。移动租约、包含 SUPPORT 见证的组合结果和公开函数留在真实模块唯一声明；不建 `.cpp`。

全部计数使用 `std::uint64_t` 并做饱和累加。统计快照三类计数组覆盖全部有效枚举并按底层枚举值排序；来源消息身份组按线程逻辑身份排序。读取到未知枚举、错运行代次、零身份 / 消息序号、重复线程身份或总数不守恒是内部不一致，候选零发布。

### 4.2 真实模块与公开 API

新建：

```cpp
export module 海中鱼巣.线程.运行.缓存统计线程;
export import 海中鱼巣.线程.候选.支持线程;
```

模块唯一导出数据头正文、`缓存统计线程租约`、启动结果和：

```cpp
缓存统计线程启动结果 启动缓存统计线程(
    const 缓存统计线程启动请求& 请求,
    const 线程生命周期投影读取端口& 读取端口,
    线程生命周期发布端口& 发布端口) noexcept;
```

租约只允许移动构造，移动赋值 / 复制全部删除，析构只作保守 stop + join fallback。公开成员精确匹配详细设计第 6 节七项函数；`停止并连接` 只允许 rvalue 调用并消费内部唯一 SUPPORT 租约。裸 SUPPORT 租约、入口、队列和可变统计容器均不公开。

### 4.3 队列、统计视图与并发

使用一个 mutex、一个 condition_variable 和一个有界 deque；所有提交在短锁内校验停收并线性化接受位置，满时零驱逐。锁内不得调用 8110、SUPPORT、DATA、日志、文件或回调。

入口第一次等待前注册覆盖整个等待期的 `std::stop_callback`，回调只 `notify_all()`。每次从队首移动一个刷新请求到局部后释放锁，随后恰调用一次 const 组读。处理位置在该刷新完成结构化分流后推进；暂不可用和资源失败算该请求已处理，但只有 `已读取` 且候选完整才替换统计快照。固定内部请求若返回请求拒绝、运行代次不匹配、未找到或内部不一致，表明借用服务 / 内部合同漂移，入口以内部故障收束。

统计视图在独立锁内以完整值式候选一次替换；读取返回副本。组读资源失败或复制资源失败保持旧快照，但读取状态必须能表达本次统计不可用，禁止把旧快照冒充本次版本。相同运行代次、相同投影组和相同规则版本形成语义等价快照。

### 4.4 停收、冻结丢弃和连接

停收锁存最后接受位置；等待只绑定该截止。正常路径先等待处理位置到截止。超时后可在同一队列锁内冻结并丢弃尚未取出的刷新，返回同截止丢弃数量；已经取到局部的一项最多处理一次。冻结丢弃只作用于可确定重建的刷新请求，不修改当前统计快照或任何业务事实。

显式右值停止连接先复核“完成到截止”或“同截止冻结丢弃成功”，然后移动内部 SUPPORT 租约执行 stop + join。前置未闭合、坏请求或入口故障仍必须安全连接，并用独立状态返回，不得冒充正常收口；析构不提供正式结果。

### 4.5 启动组合

完整启动请求在任何分配和 SUPPORT 调用前校验。内部机械形成固定 `缓存统计 / 缓存统计` SUPPORT 请求和地址稳定入口；调用 SUPPORT 创建、等待内部进入；见证完整时移动组装租约，其他分支移动候选回收。禁止读取 8110 投影判断物理进入、查找既有租约、同义复用、调用方选择 SUPPORT 类别 / 模块、复制 SUPPORT DTO 或 detach。

函数名、变量名、类内业务成员名和新增项目标识符使用中文；标准库、平台 API 和外部固定名称除外。
