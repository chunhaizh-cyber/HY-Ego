当前 `不可变治理批次`和待完成槽只保存消息编号，完整消息在邮箱冻结结果析构时丢失；`L2治理函数骨架`的同名全局分类函数只接收批次身份并固定返回空批次。必须先修正 002-01→002-03 交接，不能在骨架中伪造分类。

## 5. 实施步骤

1. 路由待完成槽和不可变批次从消息编号组改为直接 move 持有现有完整冻结批次，并补充运行代次；邮箱接口和内部实现保持不变。
2. 把分类 DTO 移入路由模块，删除领域骨架重复 DTO 和固定空分类函数。
3. 在路由实现 const `复核并分类治理批次`，严格按详细设计处理入口、上下文、顺序、重复、拒绝、停止和异常。
4. 自我线程改为调用持有的同一路由实例，并按分类状态分流；普通输入仍止于未实现的 002-04。
5. 扩展治理端到端测试覆盖真实消息保存、分类、拒绝和停止优先；不访问私有队列或路由状态。
6. 形成函数级知识变更清单和验证记录。
