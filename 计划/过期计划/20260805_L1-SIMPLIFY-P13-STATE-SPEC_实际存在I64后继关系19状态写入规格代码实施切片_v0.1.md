## 1. 目标与完成条件

原位扩展同一 L1 状态服务，并新增无事实写权的后继状态规格组合模块，形成真实可测试的 `实际存在I64后继状态规格`：从 P10/P8 新当前、P12 相邻前态和 P11 状态迁移比较的同截止材料，构造与 P9 v0.3 完全同形的关系19纯值写入规格。

完成必须满足：

- 调用方不提供前状态、比较算法、注册、动态身份、事实截止、L1本地键或事务；
- P12 无前态不回落到 P9 首态；P11 非成功不形成规格；
- 等价和非等价均形成后状态规格，但只有非等价允许后继形成迁移动能规格；
- 状态规格为二节点、五值、五关系19、五属性槽，使用固定 `0x53` 命名空间本地键；
- 组合器只编排，状态服务保持关系19和状态规格唯一所有权，模块无环；
- 全程零 L1 写入、零稳定编码预分配、零关系20/动态发布；
- 双配置、自检、strict、模块扫描和静态闭包全部通过。

唯一机器设计依据为同名 v0.1 详细设计和函数流程图，以及 4015、4190、4200、4210、P9 v0.3、P10 v0.1、P11 v0.1、P12 v0.1 冻结合同。

## 4. 机械施工顺序

1. 在 `L1状态.数据.h` 只追加详细设计冻结的规格版本、形成状态、动态准入、业务中性已校准材料、`L1写集请求`规格和形成结果 DTO；禁止依赖比较领域数据类型。
2. 在 `L1状态服务` 原位新增唯一已校准规格形成函数；只校验值式材料并构造 P9 同形规格，不导入或调用特征比较服务。
3. 新建 `组合.后继状态规格.ixx`，在该模块导出跨领域请求、迁移证据和业务结果 DTO，并按固定顺序执行 `G0 -> P10/P8 -> P12/P9 -> P11 -> G1 -> 状态规格形成`；从P12完整事实机械重建P11所需的P9读取请求，业务调用方不得提供；provider 截止不一致整轮重试一次。
4. P12 无前态直接返回具名非成功；不得调用首态发布。P11 非成功、跨场景、时间不递增、来源非主体或任何见证矛盾均返回零规格。
5. 使用精确本地键 `0x53000001..0x5300000C` 构造二节点、五值、五关系19、五属性槽。角色4只指向本地见证节点；不把值事实当关系端点，不复制P2定义。
6. 按固定字段序列计算确定性摘要。同整理身份同义返回相同纯值规格；异义返回冲突。不得建立持久幂等账。
7. 等价成功设为禁止动态；非等价成功携带完整P12/P11/P10见证并允许后继动态规格消费。两者状态写集形状完全一致。
8. 在项目和 filters 精确登记新组合模块；在既有 `自检.L1状态` 内导入组合模块并追加顺序380专项；不改启动文件。
9. 形成两份专属施工/验证记录，逐项记录实际代码、矩阵、静态闭包与未证明边界。

## 5. 停工与设计漂移

出现下列任一情况必须停止受影响切片并具名退回：

- 上游实际接口或事实形状不能机械映射冻结 DTO；
- 需要状态服务导入特征比较服务，形成模块环；
- L1 写集本地键不支持非连续 namespaced 键，且无法按详细设计直接拼接；
- 需要调用方提供前状态、算法、注册、动态身份、截止、许可或事务；
- 需要更改 P9 关系19结构、让值事实成为端点或复制第二状态解释；
- 需要在本叶执行 L1 写入、分配稳定编码、发布关系20/动态或实现最终事务；
- 需要修改白名单外文件。

普通编译错误、包含顺序、构造语法和专项夹具问题若不改变合同，由执行侧在白名单内自行修复，不构成设计漂移。
