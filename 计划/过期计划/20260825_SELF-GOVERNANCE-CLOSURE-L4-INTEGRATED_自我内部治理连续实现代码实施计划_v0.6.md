## 6.1 完成消息运行代次 v2 精确增量

物理 ABI 和施工顺序固定为：

```cpp
inline constexpr std::uint32_t 任务动作完成消息合同版本 = 2;
// 任务动作完成消息既有“动作顺序”字段后：
std::uint64_t 运行代次 = 0;

virtual 任务动作完成消息结果 读取动作完成消息(
    稳定编码 执行幂等身份,
    std::uint64_t 运行代次,
    std::uint64_t 动作顺序) const noexcept = 0;
```

运行代次必须进入消息有效性、默认相等比较、消息账键、独立读取和 manager/上行桥逐字段比较。账键为`{运行代次,执行幂等身份.值,动作顺序}`；同三元键完整消息相等才是精确重复，同三元键异义为幂等冲突，不同运行代次形成不同账项。禁止旧二元键回退、跨代次命中、从线程当前值补写或只检查定位代次非零。权威快照继续嵌入完整消息，不新增第二运行代次字段。
