## 1. 计划目标

实现并验证一个设计就绪的第四层公开 provider：

```text
正式任务实际结果 + G0 冻结需求成员集合 + 完整消费合同
-> 可共用：逐成员形成共同结果引用，不建立优先级账
-> 争用：形成正式成员分配优先级证据，按具名顺序逐项分配并立即扣减
-> task owner 同事务发布关系、证据、步骤链和最终剩余
-> 当前 / 历史独立读回与发布未知恢复
```

详细设计：`规范/详细设计/20260823_RUNTIME-GOVERNANCE-TASK-RESULT-CONSUMPTION-ALLOCATION_任务结果消费关系与争用分配详细设计_v0.1.md`

业务流程图：`流程图/20260823_任务结果消费关系与争用分配_业务流程图_v0.1.md`

本计划把优先级 provider、关系裁决和争用分配合并为一个闭环，因为它们共享 task owner、公开请求、DATA-L2 原子写集、生产文件和验证资源。计划不接生产 consumer，不进入逐需求目标满足或 5160 正式结算。

## 4. 实施顺序

### S1 DATA DTO 与完整性谓词

新增`L2任务结果消费分配记录.数据.h`，完整实现详细设计 §6 的身份、枚举、容量合同、成员资格、正式优先级、成员分配结果、不可变记录、提交 / 读取 / 按幂等读取 DTO 和全部`成功()` / 完整性谓词。

固定约束：

- 所有函数名、变量名、类内业务成员名使用中文；
- 成员组唯一且规范化；规范化顺序不获得优先级语义；
- 可共用与争用成功形状互斥；
- 可共用无优先级、无扣减、无剩余账；
- 争用优先级组一一对应，步骤链连续；
- 新记录初始已分配固定为 0；
- 非成功不携带成功载荷。

### S2 task owner 能力、记录类型和原子写集

在`服务.L2任务结构.ixx`：

1. export 新 DATA 头；
2. 新增只能由`L2任务所有者交付`提取一次的记录写入能力和移动写端口；
3. 登记记录节点、结果 / 任务 / 列表项 / 成员引用、合同字段、规则字段、完整请求、优先级证据、分配步骤和剩余字段所需稳定类型；
4. 实现按幂等身份和裁决元组反查；两者均要求 0..1，重复或复义不得任选；
5. 实现当前 / 历史记录投影；
6. 实现私有`写入已验证任务结果消费分配记录`，在 task owner 现有互斥体内完成恢复、G0 CAS、元组唯一性、一个 L1 所有者范围写集、G1 读回；
7. 保持现有任务结果、任务状态、路径、筹办和子目标记录 ABI 不变。

不得把业务优先级排序或目标满足判断放入 task owner；DATA 只检查强类型记录守恒。

### S3 DATA 记录结构服务

新增`海中鱼巣.领域.服务.L2任务结果消费分配记录结构`：

- 构造时取得任务服务、需求服务和移动写端口；
- 提交前在同一 G0 读取正式结果、任务、列表项成员组和成员需求事实；
- 精确互证冻结成员、目标合同、容量合同和候选记录；
- 调用私有写端口；
- 提供按记录身份当前 / 历史读取及按幂等身份读取；
- 映射未找到、漂移、引用冲突、幂等冲突、资源失败和内部不一致，禁止空成功。

### S4 BIZ DTO 与 provider

新增业务数据头和模块，完整实现详细设计 §7：

1. 入口纯值校验；
2. 按原键恢复优先；
3. 调用现有`读取任务本轮实际结果与独立读回`取得正式结果、任务、列表项、成员组和 G0；
4. 规范化集合互证，不用成员身份顺序分配；
5. 精确裁决可共用 / 争用；
6. 可共用明确拒绝任何优先级材料；
7. 争用形成并绑定每成员正式优先级证据；
8. 只按正式二元序号排序；
9. 逐项复核、形成成员结果并立即更新唯一局部剩余；
10. 构造一份完整候选记录并调用 DATA 提交；
11. 按 G1 独立读回并逐项互证；
12. 结构化映射全部非成功。

provider 不新增缓存、第二余额账、后台续批、日志事实或线程入口。

### S5 工程登记与专项验证

在工程和 filters 登记两个新数据头、两个新模块。只在`端到端测试.自我治理一致事实.ixx`增加专项治理验证；测试不得增加生产专用接口、私有状态出口或故障注入。

## 5. 事务、幂等与恢复硬门禁

1. 一次成功只能发布一条不可变关系 / 分配记录；
2. 关系、优先级证据、逐项步骤和最终剩余必须同写集；
3. `可共用`不排序、不扣减、不建立优先级；
4. `争用`只按正式优先级序号和同级顺序序号；
5. task owner、消息优先级、需求权重、预算、创建时间和稳定编码不得出现在分配比较器；
6. 每一步的分配前剩余等于上一步分配后剩余；
7. 同键同完整请求恢复，异义冲突；
8. 同裁决元组换键冲突；
9. 发布未知只重放原完整请求和原键；
10. 当前性漂移、合同不足、优先级缺失和读回矛盾不得补成功。
