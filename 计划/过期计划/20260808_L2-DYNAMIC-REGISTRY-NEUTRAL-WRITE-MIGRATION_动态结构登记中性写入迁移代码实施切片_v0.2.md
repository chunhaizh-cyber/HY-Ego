## 1. 身份、替代关系与完成条件

计划身份：`L2-DYNAMIC-REGISTRY-NEUTRAL-WRITE-MIGRATION`

本计划替代 v0.1。来源执行漂移为 `DYNAMIC-REGISTRY-IDEMPOTENCY-ORDER`：v0.1 要求提交前因当前代次不等于请求期望代次返回漂移，同时要求原请求在首次发布推进代次后仍到达 L1 精确重复，两者不可同时成立。

唯一施工裁决：公开请求校验通过后预读当前代次 P，但不得因 `P != 请求.期望事实代次` 提前返回；形成完整原请求并恰一次调用 `提交中性写集`。L1 按当前正式合同先裁决同键同完整规范化请求精确重复，再裁决同键异义，最后裁决期望代次漂移。首次成功时 P 必须等于请求期望；精确重复时允许 P 高于原期望并复用首次十编码。

目标仍是把 `L1动态服务` 的结构登记写入和当前登记读取迁移到现有中性 CRUD，保持公开请求、结果、登记结构、构造和幂等域不变。完成条件：两份生产代码和两份专属记录精确完成；固定 10/0/0/0/0 写集恰一次提交；原请求旧期望代次精确重复可达；新键旧代次返回漂移；同键更换期望代次返回冲突；成功类按十编码完成 G0 + 十节点 + G1 当前读回；双配置完整重建、双配置模块扫描、strict、静态门禁和精确范围检查通过。

## 5. 实施步骤

1. 保留现有 WIP 中对 `L1动态登记操作标签`、`L1动态登记意图组`、`L1动态登记入口变体` 的删除；保留 `L1动态登记幂等域=0x0F` 和全部公开 DTO / 校验。
2. 完成中性幂等键映射、中性写入 / 读取状态映射、十项映射校验、中性节点形状校验和共享当前登记读回 helper；不得改写被排除路径使用的 legacy helper。
3. 重写建立登记入口：公开请求校验后调用一次 `读取中性当前事实代次` 并验证成功、合同版本和非零 P；**删除或禁止任何在提交前因 `P != 请求.期望事实代次` 直接返回版本漂移的分支**。
4. 形成合同版本 1、原请求期望代次、`0x0F` 中性键和固定十节点写集，其它四类写项为空；物理调用 `提交中性写集` 恰一次。不得调用旧探测、完整快照或 legacy 提交。
5. 按 L1 返回状态而非 P 最终裁决：精确重复允许 P 与原期望不同；首次成功要求 P 等于期望，否则内部不一致；漂移、冲突和其它非成功原样映射。不得用 P 覆盖 L1 已返回的精确重复、冲突或漂移。
6. 成功 / 精确重复分别核对发布标志和重试边界，共同核对版本、键、非零首次发布代次及十项唯一映射。精确重复复用首次十编码；同键但更换期望代次由 L1 识别为异义冲突。
7. 以十编码执行共享 G0 + 十节点 + G1 当前读回。登记事实截止取 G0，不强制等于 L1 首次发布代次；只有完整同代次时更新 `登记_` 并返回已登记。
8. 重写读取当前登记：缓存只提供定位；每次复用共享当前读回，成功返回已读取。删除 `首次登记请求_` 字段和全部分支。
9. 精确复核被排除的完整快照规格路径、其它状态动态函数和公开 DTO 无差异；只清理本叶唯一退出调用确定不再使用的 include / helper。
10. 形成两份专属记录，明确记录顺序漂移裁决、实际范围、验证、未验证范围和第一层不自证边界。

## 6. 固定结果与失败收口

| 场景 | 固定结果 |
| --- | --- |
| 非法公开请求 | 入口拒绝，零提交 |
| 预读入口非成功 / 合同矛盾 / 零代次 | 对应结构化非成功，零提交 |
| 首次新键、同代 | L1 成功；P 必须等于请求期望；读回后已登记 |
| 原请求精确重复、当前代次已推进 | 不被 P 提前阻断；L1 精确重复、零发布、复用首次十编码；读回后已登记 |
| 同键只更换期望代次 | L1 幂等冲突，不得映射为精确重复或版本漂移 |
| 新键旧期望，或预读后竞争推进 | L1 事实代次漂移；领域版本漂移 |
| L1 返回成功但 P 不等于期望 | 内部不一致 |
| 读回未找到 / 已退出 | 未找到 |
| 成功类合同、映射、节点形状或登记完整性矛盾 | 内部不一致 |
| 读回节点代次 / G0 / G1 漂移 | 版本漂移，无混代登记 |

发布后读回失败不得撤销、补写或生成新幂等键；保留 L1 实际发布状态。

静态门禁：

- 三项登记业务常量、`首次登记请求_`、登记入口 legacy 意图 / 探测 / 快照 / 旧写入口归零；幂等域仍为 `0x0F`。
- `建立登记` 内 `提交中性写集` 恰一个物理调用点，固定写集为 10/0/0/0/0。
- 该提交调用点在所有公开请求已通过且代次预读成功的路径上可达；不得存在由 `P != 请求.期望事实代次` 支配的提交前返回。
- 首次成功分支显式核对 `P == 请求.期望事实代次`；精确重复分支不作该阻断并复用首次映射。
- 同键更换期望代次不在领域层改写为新请求或复用缓存，交给 L1 完整请求幂等返回冲突。
- 共享读回 helper 内 `读取中性当前节点` 恰一个物理循环调用点并执行十编码；事实代次首末各一次；不强制 G0 等于首次发布代次。
- `读取当前登记` 不直接调用 legacy 当前读取、不直接返回缓存。
- 公开 DTO、构造、函数签名和被排除的完整快照规格路径无差异。
- staged 和提交范围只含 §3 四路径；其它生产代码和异主 WIP 零差异。

对结果分支至少形成可审计证据：首次成功；原请求在事实代次推进后的精确重复；同键只更换期望代次冲突；新键旧期望漂移；P 相等后竞争漂移若现有合法入口可确定触发，否则明确记为未运行并以 L1 顺序静态证据保留，不得伪造运行证明。
