## 4. 冻结测试接口、稳定模式与生命周期

全部测试实体和分支只允许存在于：

### 4.1 可重建索引仓库

唯一物理位置：`海中鱼巣.核心.仓库.可重建索引` / `海中鱼巣/核心/仓库.可重建索引.ixx` / 类 `可重建索引仓库` public 宏区：

```cpp
enum class 可重建索引精确读取内部损坏测试种类 : std::uint8_t {
    已发布候选事务序号非零 = 1,
    记录键错配 = 2,
    反向绑定缺失 = 3,
    反向绑定重复 = 4,
    目标权威不可读 = 5
};

bool 测试_令下次结构化精确读取模拟内部损坏(
    可重建索引精确读取内部损坏测试种类 种类) noexcept;
```

合法枚举写入共用原子字段稳定值3—7；非法底层值返回 `false` 且不改字段。v0.4 已冻结的资源/其它异常设置函数继续写1/2。`读取索引物理键结构化` 只在合法键后 `exchange(0, std::memory_order_acq_rel)` 一次消费：3—7依次在候选事务序号为零、记录键相等、反向组存在、同键计数恰一、解锁后目标权威可读五个真实检查节点强制本次谓词失败，返回内部不一致和空记录。

### 4.2 节点直接结构查询服务

唯一物理位置：`海中鱼巣.核心.服务.节点直接结构` / `海中鱼巣/核心/服务.节点直接结构.ixx` / 类 `节点直接结构查询服务` public 宏区：

```cpp
enum class 节点直接当前索引读取内部损坏测试种类 : std::uint8_t {
    节点目标权威读回缺失 = 1,
    关系目标权威读回缺失 = 2,
    关系端点见证不可形成 = 3
};

bool 测试_令下次当前索引读取模拟内部损坏(
    节点直接当前索引读取内部损坏测试种类 种类) noexcept;
```

合法枚举写入共用原子字段稳定值3—5；非法底层值返回 `false` 且不改字段。资源/其它异常设置函数继续写1/2。`读取当前索引` 在合法键后一次消费；3—5依次只替换当前栈上的节点读取结果、关系读取结果或关系见证结果，使原生产失败判断返回内部不一致、代次0、空组。模式与夹具目标种类不匹配仍返回内部不一致，但不得计入对应具名场景。

### 4.3 共同生命周期

两个类各自继续只保留一个 `mutable std::atomic<std::uint8_t>` 字段；六个设置函数共用所属对象字段。设置使用 release store 并覆盖尚未消费模式；非法键不消费，合法键后一次消费，第二次同输入自动恢复。测试模式不进入机器事实、事务版本、持久材料、日志或跨实例状态；宏关闭时两个枚举、六个设置函数、两个字段、测试异常和全部注入分支均不存在。
