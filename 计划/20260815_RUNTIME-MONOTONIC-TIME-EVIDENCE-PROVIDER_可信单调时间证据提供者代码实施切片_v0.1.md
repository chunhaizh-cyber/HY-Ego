## 1. 目标与完成条件

实现 `单调时钟适配器::读取可信单调时间证据`：在一个绑定的运行代次和时间纪元内，读取 `steady_clock`并返回从本实例纪元起点经过的非负 `I64`纳秒。

完成必须同时满足：

1. 只新增一个适配模块并登记工程，不修改 DATA、装配、线程或 D455。
2. 请求不含当前时间和读取序号；运行代次、纪元和固定时间源版本逐字段互证。
3. 只有成功返回完整证据；全部非成功 optional 为空，零墙钟、零缓存、零持久化。
4. 连续和并发读取无内部可变序号，经过纳秒允许相等但不得倒退。
5. 根工程与生产外专项通过；完整秒和治理接线保持 `NOT_RUN`。

## 4. 实现合同

新模块固定为：

```cpp
export module 海中鱼巣.适配.适配器.单调时钟;
```

唯一导出详细设计第 3 节常量、配置、请求、状态、证据、结果和适配器类。适配器保存值式配置和构造时取得的一个 `steady_clock::time_point`；不可复制、不可移动、无堆分配、无锁、无缓存、无静态当前值。

入口固定顺序：配置完整 -> 请求完整 -> 代次 / 纪元互证 -> 时间源版本互证 -> 恰一次当前 `steady_clock::now()` -> 受检差值与纳秒换算 -> 一次构造结果。配置错误、请求拒绝、代次 / 纪元错配和时间源版本漂移均在本次读取的当前 `now()`之前返回；负差不得钳制，溢出不得回绕。

不得新增读取序号、原子计数、墙钟 fallback、调用方时间参数、sleep 轮询、公开 fake clock、日志或 DATA 接口。测试需要私有纯值换算复核时只能验证同一生产源码，不得建立第二实现。
