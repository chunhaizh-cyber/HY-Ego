# DATA-L2 普通方法执行规格引用身份闭合代码实施切片

日期：2026-08-16

身份：`DATA-L2-ORDINARY-METHOD-SPEC-REFERENCE-CLOSURE`

版本：`v0.1`

## 1. 目标

在现有 `L2普通方法结构.数据.h` 中新增作用对象绑定、参数规格、禁止项规格、适用范围四种强类型身份和强类型稳定动作键，使后继普通方法完整 DTO 不再使用裸编码、裸整数、字符串或函数地址表达这些角色。

完成条件是五种类型、五个纯值 helper 与独立引用合同版本按详细设计进入生产头，既有六种身份 / 版本 ABI 和合同版本保持不变，根工程双配置构建及机械检查通过。本计划不实现普通方法事实或服务。

## 4. 精确实施

在 `namespace 海中鱼巣` 中按详细设计原样新增：

```text
L2普通方法规格引用合同版本 = 1
L2方法作用对象绑定身份
L2方法参数规格身份
L2方法禁止项规格身份
L2方法适用范围身份
L2方法稳定动作键
五个同名“有效”纯值 helper
```

四种身份显式包装 `稳定编码`；动作键包装非零 `uint64_t`。不得增加隐式构造、通用基类、variant 万能引用、字符串动作名、函数指针、回调、插件句柄或默认有效值。不得改变 `L2普通方法结构合同版本`、上一叶六种类型或 helper。

## 5. 禁止事项

本计划禁止：

- 新增节点、关系、值、owner、服务、聚合、getter 或普通应用装配；
- 定义参数值域算法、禁止项比较算法、适用范围展开或作用对象端点集合；
- 把五种类型声明为已发布事实、完整方法或可执行能力；
- 修改方法登记根 DTO / 服务、L1、其它 DATA、BIZ、SELF、最终需求清单、正式规范、流程图或异主 WIP；
- 建立测试入口、生产自检、第二写入口或兼容裸编码重载。

## 6. 实施步骤

1. 完成 S0 并固定正式起点、plan / design blob、目标头哈希和工程唯一登记事实。
2. 只修改目标头，按详细设计增加五种类型、合同版本和 helper。
3. 使用仓库外 MSVC C++20 `/W4 /WX /utf-8 /permissive-` 探针检查类型和转换合同；探针不登记生产工程。
4. 根工程 x64 Debug / Release fresh Rebuild。
5. 检查 strict、diff、UTF-8、XML、唯一登记、四配置 `/utf-8`、白名单和生产零测试痕迹。
6. 写专属施工 / 验证记录，精确暂存允许文件，运行 cached diff check 后普通提交和推送。
7. 回传结果提交、实际范围、验证、`NOT_RUN`、HEAD / origin / index 和资源释放；由索引所有者单独登记退出。
