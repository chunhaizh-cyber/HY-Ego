## 5. 目标类型、函数和物理位置

### 5.1 参与者模块

`海中鱼巣.领域.参与者.节点直接特征批次记录` 唯一拥有详细设计 §3 全部DTO、仓、访问器和参与者。关键根：

```cpp
节点直接特征批次候选结果 登记候选(
    const 节点直接特征批次记录& 记录);

节点直接特征批次读取结果 读取已发布批次(
    节点直接特征批次身份 批次身份) const;

节点直接特征批次引用组读取结果 按特征值读取批次引用组(
    世界树节点身份见证 特征值) const;
```

五个private override分别采用已发布FEATURE-W-MC四阶段签名和MC-PW冻结的 `第一写前复核` 签名；MC-PW代码结果形成前不得提前实现猜测签名。参与者准备时只消费只读视图，不保存引用/span；仓独占锁持有至发布或撤销。

### 5.2 数据操作模块

构造固定为：

```cpp
节点直接特征批次数据操作(
    const 节点直接身份结构事务域& 事务域,
    const 节点直接类型化值仓库& 类型化值仓,
    节点直接特征批次记录仓& 批次仓) noexcept;
```

两个精确读取同名转发访问器一次。冻结根固定为：

```cpp
节点直接特征同代次冻结读取结果 复制同代次类型化值与批次记录(
    const 节点直接统一冻结许可& 许可) const;
```

不得增加默认构造、重载、回调、第二许可入口或两个独立optional结果。

### 5.3 自检

新建唯一专项根并在 `启动.应用程序.ixx` 以 `WORLD-TREE-FEATURE-W-DP-S01`、顺序226登记。正式HEAD `c55870c1` 已由F0占用顺序225，226当前空闲；S0仍须按届时正式HEAD记录顶层数量 `N` 并复核226，目标为 `N+1`。顺序225只允许R1原位扩展，顺序230保留给已发布P1B-F设计冻结的FEATURE-W-F/FEATURE-W。
