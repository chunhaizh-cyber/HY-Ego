## 3. 固定接口、键和值合同

必须逐字实现详细设计冻结的：

- `L2任务轮次身份/事实`、`L2任务来源需求关系事实`、`L2任务正式存在关系事实`；

- `新增首次准备记录与P1`及首次记录 / A1 独立读取；
- `L2任务治理函数合同版本=1`、`L2初次筹办推进规则版本=1`、函数定义与 A1；
- 外层 v2 六阶段幂等身份、七段结果头和完整工作包；
- 全局 `TASKSTAG`基础定义、E 唯一实例、`{1,1}`首态、`{1,2}`后态及 `{运行代次,阶段序号}`时间材料；
- R1 作为首态来源，A1 作为第一迁移来源。

键合同：

```text
15 项登记键                              0x0301'2180..0x0301'218E
治理函数定义节点                         0x0301'2185
治理函数定义 U64 属性类型                0x0301'2186
治理函数定义材料值                       0x0301'218F
R1 运行时五项                            0x0301'2660..0x0301'2664

```

定义登记写集必须精确用互异的 2185/2186/218F 三键；材料所属和来源均为定义节点，材料为 `{1,1,1}`，槽引用 218F。15 项登记计数不包含 218F。增加 `static_assert`固定计数 15、`218F == 218E + 1`、三键互异和 `218F < 2201`。

公开定义 DTO 不增加 L1 键或原始值身份。读取只有在定义节点当前属性的所属、类型、来源、U64 三值、槽和生命周期全部互证后才成功；不得从常量补齐。P1、函数名、魔数、日志、缓存、普通方法或旧治理状态均不得替代 A1 / 定义事实。

## 4. 分阶段恢复和失败收口

固定顺序为：准备键历史读回；G0 裁决 D；原存在键建立 / 恢复 E；新截止复核后原核心键建立 / 恢复 T/R1/关系；全局键建立 / 恢复阶段定义；实例键建立 / 恢复 E 实例；首态键建立 / 恢复无动态 `{1,1}`；P1 键同次建立 / 恢复首次记录、P1、A1；独立读回 A1/定义；首迁移键建立 `{1,2}`和第一动态；各 owner 最终独立读回。

任一段非成功但带截止时，只以原键、原请求和该 owner 公开读回收敛，未确认不得越段。已发布前段保留供同键恢复，不跨 owner 回滚、不换键。成功形状不完整为内部错误；同键异义为幂等冲突；当前性漂移要求新业务请求；许可 / 资源失败原样上送。非成功不得携带可冒充完整工作包的载荷。
