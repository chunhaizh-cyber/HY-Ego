# 特征值域比较服务同 L1 绑定 ABI 代码实施计划

开工基线：`68ebb3cc54282e3ab6e18c5b47a6a648eaae73c0`

## 1. 目标与完成条件

实现比较服务只读 `绑定于` ABI，使其仅在内部概念树、特征和特征值服务均绑定传入同一 L1 时返回 true。完成以精确头/源实现、同底座与混用 L1 专项矩阵、零事实写入证据及主工程双配置构建为准。

## 2. 正式依据与当前事实

依据：4180 v0.13 §5.2，及已发布的 `EXISTENCE-CONCEPT-DEFINITION-PROVIDER-REBUILD` v0.6 / 同名详细设计 v0.6 §1、§9。后者的调用期比较服务核验被正式冻结，但当前 `特征值域比较数据服务` 只有构造和三项值域读取/核验入口；私有三引用不可供概念树访问，`Gread/H` 不能代替共同 L1 身份核验。

当前比较服务已经只读保存 `concepts_`、`features_`、`values_` 三引用；三个被引用服务都已有同形 `绑定于`。比较模块 `.h/.cpp` 已在当前工程登记，且没有生产消费者，因此无需迁移或装配修改。

禁止：L1、概念树、特征、特征值、普通应用生产代码、工程登记、正式规范、规则、既有比较 DTO/状态/读取语义、构造参数/私有字段、任何写事实，以及下游两组定义实现。

## 4. 冻结接口与施工

头文件新增且只新增：

```cpp
bool 绑定于(const L1事实基座服务&) const noexcept;
```

源文件唯一实现是三项现有服务 `绑定于` 谓词的逻辑与。不得新增任何字段、缓存、写端口、预算、状态或结果 DTO；不得读取 L1 或调用 `读取特征值域`、`核验特征值域关系`、`核验实例值域命中`。

执行顺序、隔离专项夹具、四项断言、构建命令、失败记录和静态巡检均逐字按同名详细设计 §5—§6。执行者不得为了验证而改变普通应用或下游公开 ABI。

## 5. 失败收口与验证

该谓词只返回 bool：任一内部服务不绑定传入 L1 即 false；不存在假成功、事实写入、幂等、发布未知或恢复分支。异常或资源类问题不由该无分配 `noexcept` 纯判定产生。

运行 `git diff --check`、`python .\tools\check_specs.py --strict`、隔离专项 Debug/Release 运行和主工程 Debug/Release `/m:1` 构建。构建范围外阻断时记录首个错误，保留已独立成功的专项证据，不改对方文件。

发布仅暂存本计划允许的仓内文件，普通推送后回读远端。提交不证明下游存在概念两组定义、非 I64 比较成功、世界树、恢复、运行或业务验收。
