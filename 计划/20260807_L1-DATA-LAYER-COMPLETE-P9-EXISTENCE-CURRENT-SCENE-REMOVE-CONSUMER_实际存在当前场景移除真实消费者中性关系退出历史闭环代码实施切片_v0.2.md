## 1. 目标、完成条件与依据

完成合法第二层“移除实际存在当前场景”消费者闭环：组合服务只调用具名实际存在和场景领域服务；唯一场景事实所有者完成一条直接存在成员关系的业务准入、`0 新建 + 1 退出` 中性提交、当前已退出和历史完整读回；组合服务再互证实际存在资格未变并形成调用方拥有的值式结果。

完成必须同时具备：

1. `L1场景结构服务` 新增强类型直接存在成员退出合同和唯一写入口；
2. 场景退出入口独占 `0x1A`，恰一次形成 0 节点 + 0 关系 + 0 值 + 0 槽 + 1 退出写集；
3. `L1实际存在场景组合服务` 对 L1 直接调用为零，只对场景退出入口恰一次委托；
4. 首次 / 精确重复都经场景当前 / 历史读回和实际存在资格写后读回收敛；
5. 生产代码不新增自检、验收入口、双目标、日志判定、路由缓存或恢复材料；
6. 代码发布后由生产代码外合法第二层消费者完成独立黑盒验收。

正式依据：0050、4015 v0.5、4030 v1.3、4200 v1.2、ACCEPTANCE-01 v0.3、CODE-FILE-01，以及：

## 4. 实施步骤

### 4.1 场景事实所有者

1. 在 `服务.L1场景结构.ixx` 的 `export namespace 海中鱼巣`、类定义之前，新增详细设计 v0.2 §4.1 的子合同版本、请求、已退出关系见证、事实和结果；不修改场景数据头。
2. 新增模块内部纯值有效性 / 完整性函数和本入口专用中性状态映射。不得改变现有初始场景创建的状态映射。
3. 新增非 const `L1场景结构服务::退出初始场景直接存在成员关系`，复用类内现有锁；诊断责任为向上送出。
4. 锁内读取当前世界登记、起始代次、初始场景、当前存在节点和当前归属关系。请求只提供关系稳定编码；端点、登记关系类型和角色必须由场景服务从当前或历史关系事实读取并验证。当前关系成功时标记当前候选；当前关系精确 `已退出且无事实` 时读取同编码历史并标记已退出候选；其它缺失或矛盾返回具名非成功。
5. 复读结束代次，要求当前登记、场景、存在和首末截止处于同一非零当前代次。当前候选还要求当前截止等于请求期望事实代次；已退出候选要求历史创建代次不晚于期望代次且退出代次不晚于当前截止。请求期望代次不早于历史退出代次时直接返回未找到；只有期望代次早于退出代次的重复候选进入 L1 幂等裁决。
6. 以高八位 `0x1A` 和请求世界幂等身份形成 L1 键；写集固定零节点、零关系新建、零值、零属性槽和一个请求旧归属关系退出。
7. 当前候选和仍需幂等裁决的已退出候选都经同一物理调用点恰一次调用 `提交中性写集`。同键同义得到首次成功或精确重复；不同键携带旧期望代次得到版本漂移；同键异义得到幂等冲突。成功类必须零新编码映射。
8. 成功类固定读取读回起始代次、当前关系已退出、同编码历史关系、当前原场景、当前存在和结束代次；历史退出代次等于首次发布代次，两个节点保持当前，形成场景退出事实。
9. 收窄 `读取初始场景接纳` 的失败分账：只把请求精确归属关系 `已退出且无当前事实` 映射未找到；成员、场景、关系类型或其它关系矛盾仍为内部不一致。

### 4.2 实际存在包装与组合服务

10. 在 `L1实际存在.数据.h` 新增 v0.2 详细设计 §6.1 的实际存在移除请求、已退出归属关系见证、事实、结果及纯值完整性函数；不新增状态枚举。
11. 把组合服务构造扩展为持有初始场景实际存在原子发布服务、场景结构服务、实际存在服务三个非拥有引用。删除 v0.1 关于 L1 引用、组合服务锁和幂等定位的全部意图；代码中不得出现这些结构。
12. 为既有创建入口增加 const 实现，非 const 入口只透明转发；既有读取语义不变。
13. 新增唯一 const `移除实际存在当前场景`：先经原子发布服务读取写前组合事实。成功且逐字段匹配、截止等于期望代次时标记当前候选；精确未找到且无事实时标记已退出候选；其它非成功直接返回。
14. 经实际存在服务读取写前资格。当前候选要求资格与写前组合事实完全一致且截止等于期望代次；已退出候选要求资格编码匹配请求、事实完整且当前截止不早于期望代次。
15. 由请求场景定位、资格返回的当前存在见证和请求关系稳定编码形成场景退出请求；外层幂等值无损装入世界操作幂等身份。组合服务不得补造关系端点、类型、角色或 L1 幂等键。
16. 恰一次调用场景服务退出入口。非成功逐项同义映射；已退出候选只有场景返回幂等读回才能继续，返回首次已提交属于内部不一致。
17. 场景成功后再次经实际存在服务读取资格，要求资格未变且截止等于场景结果截止；再经原子发布服务读取同一实际存在定位，要求未找到且无事实。
18. 由场景退出事实与写后资格组装实际存在移除事实；当前候选可返回已提交或幂等读回，已退出候选只返回幂等读回。任何矛盾返回结构化非成功，不使用请求、日志或缓存补成成功。

### 4.3 运行期上下文与记录

19. 运行期上下文按既有对象顺序给组合服务追加场景服务和实际存在服务引用，只新增 const 组合服务访问器，并按现有模块边界公开导入组合服务类型。
20. 启动锚定位、`完整()`、生产入口、P5/P7/P8 路径和其它服务构造保持语义零修改。
21. 写两份专属施工 / 验证记录，记录真实改动、验证、消费者验收待办和未覆盖范围；不得写“L1 自证通过”或“整个 L1 已完善”。

## 5. 非成功、并发与幂等

| 场景 | 结果 | 权威状态 |
| --- | --- | --- |
| 外层或场景请求无效 | 入口拒绝 | 零变化 |
| 写前存在、资格、场景或关系不匹配 | 未找到、版本漂移或内部不一致 | 零变化 |
| 不同幂等键重复退出同一已退出关系 | 请求截止已含退出时未找到；旧截止重放时版本漂移 | 零变化 |
| 同一幂等键携带不同退出写集 | 幂等冲突 | 保持首次结果 |
| 精确重复 | 幂等读回 | 不形成第二退出，历史保持首次记录 |
| 资源失败或内部不一致 | 对应状态 | 不返回部分事实，不补写 |

场景服务现有锁保护本场景业务操作；组合服务不新增锁，不跨领域持锁。L1 幂等账是唯一精确重复权威；不建立领域或组合路由缓存。当前不处理崩溃、重启或跨进程恢复。
