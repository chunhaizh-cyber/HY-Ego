## 1. 目标、当前裁决和完成边界

用户将“想象世界”修正为“模拟世界”：自我发现只有方法头的方法，经消息提交独立学习线程，在独立模拟世界生成输入，实际调用原本能函数，形成全新的方法条件结果对；每对命中次数为0，模拟不算现实命中。本叶闭合到自我非阻塞消费学习结果，并将方法知识变化通知任务管理线程。任务私有域消费、旧方法副本替换、真实使用计数及完整任务执行另有真实缺口，不在本叶冒充完成。

本次本能修改对象是模拟世界独有的服务值特征；修改原因是学习已登记服务结算方法的实际输入输出关系；目的为生成待现实使用验证的方法知识。不是修改现实服务值、现实任务状态或需求。模拟来源任务状态只是条件，保持完成状态9；不能伪造任务结算状态12或现实动作。

用户裁决替代旧材料中“初始化预造条件结果对”“模拟运行增加命中”“必须现实世界信息才能建样例”的冲突口径；旧材料只用来定位差异。共享概念仅只读复用，不能将模拟值写入共享概念域或引用计数。真实本能登记仍只有头、索引和参数规格，零配对、零动作。

第一能力明确限于已登记`执行服务值结算`，且只学习登记材料已有的两个单点输入：服务值`冻结前值`及任务完成值9。不得扩大为任意服务值、任意任务或整个区间，不将有限样例概括为全域线性知识。普通外设方法尚无模拟适配，明确拒绝，不发送真实命令。

## 4. 模拟参数能力与本能函数

`新_方法参数场景.h`声明`新方法模拟运行接口`，继承现有`新内部治理对象读取接口`；前置声明`新服务值结算本能端口`，避免循环包含。接口完整签名：

```cpp
virtual 稳定编码 模拟根节点() const noexcept = 0;
virtual bool 核验模拟参数(稳定编码 方法节点,
    const std::vector<新方法参数角色绑定>&) const noexcept = 0;
virtual std::optional<新特征信息> 读取模拟特征(稳定编码) const noexcept = 0;
virtual std::optional<新特征值信息> 读取模拟特征值材料(稳定编码) const noexcept = 0;
virtual 新服务值结算本能端口* 获取服务值结算模拟端口() noexcept = 0;
```

增加用途`模拟=3`。场景持有一个`shared_ptr<新方法模拟运行接口>`，统一拥有读、写端口及样例寿命，禁止分别配置不同owner。任务虚拟存在/特征/材料读取在模拟用途只委托此接口；缺失、核验失败、读失败原样失败，绝不回退现实。非模拟用途不能取得模拟端口。

方法owner新增：

```cpp
新方法参数场景结果 建立模拟参数场景(稳定编码 方法节点,
    std::vector<新方法参数角色绑定> 绑定,
    std::shared_ptr<新方法模拟运行接口> 模拟) const noexcept;
```

仅接受完整可读、启用、抽象本能方法；owner核验角色/规格，模拟接口核验根归属/绑定，双重通过才返回场景。`调用本能函数`允许此正式构造场景并调用原登记函数指针，不能新增测试函数替代。方法锁释放后调用外部接口和本能。

原结算本能先判断用途：模拟从场景取端口；登记/现实执行维持既有租用守卫。模拟端口缺失直接返回失败，不租现实端口，不报告真实工程停止。模拟同样进入原函数的输入验证、建动作、`当前值+1`、写值和运行结果路径。

原函数参数声明补服务角色`动作前单值域`、来源任务角色`任务完成值域`；方法头仍索引服务值类型及已有目标值域，不生成CR。模拟声明与正式已登记声明必须一致，模拟端口`确保方法登记`仅核验既有方法，不建立需求或重登记。模拟禁止调用`确保首子需求`。网页三入口在任何外设读取、租用或写入前拒绝模拟用途。

每次求值新建owner和fresh样例：场景、自我、服务特征/值材料、来源任务/Vt/状态特征均有独立稳定编码，置于同一模拟根下。仅方法ID、类型和概念ID作为只读语义引用，实际场景/存在/特征/任务全部转换为模拟身份。不得将真实编码写入模拟目标绑定以复用现实写入口。

样例必须完整构造后最后挂模拟根；挂接前失败仅回滚本次自建节点/字段。已发布样例永久保留在本进程数据集中，包括失败后的已知现场；owner析构只释放运行资源，不物理删除已发表事实。无持久恢复承诺。模拟根创建由同owner静态互斥串行，已有根需严格核验，不覆盖。

本能调用先建物理模拟动作，再更新实际模拟特征，再建前后状态及结果动态关联；前后状态保存固定值，动态指向动作/两状态。模拟时间采用`抽象相对`，动作步骤1、结果步骤2，不冒充UTC。当前值更新失败/未知保留事实并返回进度，绝不生成成功CR。端口`报告并停止`只锁存本样例错误，不停止真实系统、不弹窗、不调用现实端口。输入越界、MAX、错误源状态/参数拒绝于动作前。

## 6. 同步学习业务服务

位于`业务/模拟学习.服务.h/.cpp`，它组合算法、模拟owner和方法owner，线程只消费本服务，不拥有领域结构。

借用真实端口仅用于`读取登记材料() const`，不调用任何现实写、停止、登记或需求入口；装配寿命覆盖服务与学习线程。服务不接收任意外设端口。

执行顺序：

1. fresh读方法、登记材料和声明概念域。仅自身登记的启用抽象结算本能；已有非空CR返回精确重复，不学习、不增加命中。非法方法返回方法不可读/输入不支持。
2. 从声明已绑定域核验服务输入确为`[冻结前值,冻结前值]`、任务域为`[9,9]`，均I64且有限；缺域、非单点、MAX、负服务值拒绝。不得读取现实当前值扩大输入域。
3. 初始化现有`数值模拟细分器`：两输入单点，输出维数1（服务值；任务状态只为条件不是输出）。求值回调每次创建fresh模拟样例→正式模拟参数场景→原登记本能→物理fresh读回服务当前值。原函数自身计算加一，模拟端口不能直接返回预知输出替代函数运行。
4. 每次算法推进、求值/原函数调用前及发布CR前检查停止。检查抛异常视作取消。已经进入原函数不强制中断，完成后若取消保留样例但不发布；CR已发布后按成功回流，不改报取消。
5. 要求算法完成、唯一实际样例输入精确相同、函数与物理结果一致、动作/两状态/动态齐全。组装两个条件项的私有单点和一个服务结果私有单点；FT/角色/方向引用来自已核验声明，不新增概念、不把模拟宿主编码当通用条件。概念域字段为空，私有域与概念域互斥。
6. 调方法owner单CR追加，读回新配对及命中0，成功返回已形成知识和身份；方法已被其它合法学习补全映射精确重复。发布前失败为发布失败，发布后未知为发布结果未知且禁止自动重试。失败结果保留已有样例身份。

```cpp
};
```

重复提交返回相同shared_future及精确重复；只在已完成future被self取得后才确认删除去重项，未完成确认拒绝。停止拒绝新工作，队列中未执行项完成为已取消，活动项用服务取消检查收口；所有已接收future最终有结果，不因停止丢promise。完成结果先set_value，再锁外调用唤醒，异常通知不能破坏结果。析构请求停止并join，不detach，不允许等待自身；超时不析构正在使用的依赖。

自我新增`bool 绑定模拟学习(模拟学习服务&) noexcept`，启动前绑定、同实例重复成功、不同实例或运行后替换拒绝。self持有非拥有服务指针及唯一学习线程；启动创建worker并绑定weak桥唤醒self，失败返回既有启动失败且停止已起worker。self启动时对已知结算登记方法进行一次头空检查，提交方法ID；筹办反馈中对真实候选逐个fresh读方法，同一入口发现头空则提交，不能从名称猜ID。

self内部记录在途future及本生命周期已失败/已处理方法集合，失败不因每轮消息反复提交；本叶无定时重试。循环仅`wait_for(0)`，就绪才get，不等待学习；完成唤醒参加self条件变量等待谓词，避免丢通知。结果保存值式最近结果到`新自我线程快照`可选字段，随后确认worker已接收。成功或精确重复向manager提交第9节通知；失败只记录具名状态/日志，工程错误不转认知需求，不停止现实系统。

所有日志在owner锁外，复用现行日志出口，不弹窗，不记每次空轮询。至少记录方法ID、接收/重复/开始/结果、配对或样例ID、取消/未知原因；方法稳定编码是身份，名称只显示。

## 9. 管理线程消息及装配寿命

manager新增对self可见入口`bool 提交方法学习结果(const 新模拟学习结果&) noexcept`，只接受已形成知识/精确重复和有效方法ID，复制到原有邮箱结构，不能由学习线程直接调用。消息处理fresh读抽象方法，核验非空配对和已形成知识时返回配对属于该方法且命中0；记录值式最近结果到manager快照可选字段。未知/不一致消息不修改任何任务状态。
