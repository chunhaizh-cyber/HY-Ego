## 4. 目标函数、DTO 与所有权

- 唯一公开写根：`L1动态服务::建立登记(const L1动态登记请求&)`。
- 唯一公开当前登记读根：`L1动态服务::读取当前登记() const`。
- 公开 DTO：`L1动态登记请求`、`L1动态登记结果`、`L1动态结构登记`，字段和语义不变。
- 领域所有者：`L1动态服务`；L1 只拥有中性写集原子发布、最小幂等和中性精确读取。
- 对象字段：删除 `首次登记请求_`；保留 `登记_`，但它只保存稳定编码定位和首次幂等身份，不裁决当前事实。
- 新增 / 改写私有 helper 全部留在同一模块、中文命名、最小可见性；中性节点形状判断必须与被排除的 legacy 快照节点判断分离。

## 5. 实施步骤

1. 在数据头删除 `L1动态登记操作标签`、`L1动态登记意图组`、`L1动态登记入口变体`；保留 `L1动态登记幂等域=0x0F` 和全部公开 DTO / 校验。
2. 把登记幂等映射改为 `L1中性写集幂等键`，删除只供登记入口使用的领域意图形成函数和旧写入状态映射，建立详细设计 §7 的中性写入映射。
3. 建立中性结果映射查找、十项完整唯一校验、中性节点形状校验和共享精确登记读回 helper；不得改写被排除逻辑使用的 legacy 读取 / 节点 helper。
4. 重写建立登记：请求校验后只先读取中性当前事实代次并核对期望值；删除旧探测、完整快照和非空仓门禁；形成合同版本 1、期望代次、`0x0F` 中性键和固定十节点的中性写集，其它四类写项为空；物理调用 `提交中性写集` 恰一次。
5. 对成功和精确重复核对版本、键、非零代次、发布标志、重试边界与十项唯一映射；其余状态逐项映射。成功类按十稳定编码执行共享 G0 + 十节点 + G1 读回，只有完整同代次时更新 `登记_` 并返回已登记。
6. 重写读取当前登记：缓存只提供首次幂等身份和十定位编码；每次都复用共享中性精确读回，成功返回已读取。删除 `首次登记请求_` 字段和全部分支。
7. 精确复核约 642 行起的状态迁移动能规格完整快照路径、其它状态动态函数和公开 DTO 无差异；只清理因本叶登记代码退出而确定无其它调用的 include / helper。
8. 形成两份专属记录，记录实际范围、验证、未验证范围和第一层不自证边界。

## 6. 固定失败收口

- 非法请求或中性入口拒绝：`入口拒绝`，零登记材料。
- 写前 / 提交 / 读回代次不一致：`版本漂移`，不返回混代登记。
- 同键异义：`幂等冲突`；精确重复复用首次十编码映射且零新发布。
- 中性未找到 / 已退出：`未找到`。
- 分配失败：`资源失败`。
- 成功类结果的版本、键、发布标志、重试边界、映射、节点形状或登记完整性矛盾：`内部不一致`。
- 发布后读回失败不得撤销、补写或生成新幂等键；保留 L1 实际发布状态并返回结构化非成功。
