实现唯一 `四本体根生产初始化提供者`：在阶段 18 经普通应用同一 `L2概念结构聚合服务` 取得同一 C1，建立或幂等收敛存在、特征、动态、因果链四个语言无关空本体根，每根正式读回并最终全组读回互证后，值式发布四根材料。

## 7. 状态与失败收口

成功只有 `已发布 / 精确重复`，且完整材料存在。请求无效和异义选择必须在 C1 getter 前返回。零代次全组预读 / 漂移重读返回漂移或未找到属于内部不一致；非零最终全组和单根读取只有空载荷、零变更事实代次的事实代次漂移属于竞争，同代未找到属于内部不一致。写 / 单根读的非成功 optional、全组读的非成功 vector 和任一非成功变更事实代次必须全部为空；否则直接映射内部不一致。所有全组 / 单根读取失败、四个角色的写失败、事实代次竞争、读回不一致、资源失败和内部不一致均保持旧发布值。

资源失败、异常、坏非成功形状或底层发布结果未知保留原完整建根请求及待重放标记。后次同请求进入该角色时必须先原样重放一次，即使全组预读已经出现该根也不得跳过；结果证据必须回显进入时待重放请求并与第一次实际调用逐字段相等。只有写结果明确为空载荷、零变更、无首次结果的事实代次漂移，才可清除待重放标记并正式重读全组；该角色仍缺失时同角色同幂等身份按新截止重组一次。第二次漂移返回事实代次竞争，不循环。

前根已由 DATA 发布后，后根失败不回滚。BIZ 只有完整四根候选后才交换发布。

## 8. 验证矩阵

### 8.1 动态必须覆盖

- 请求版本、零 / 重复四身份、异义选择零 DATA 调用；
- 0、1、2、3、4 个预存合法根；
- 首次建立四根、同请求重复零预期根写但仍执行全组预读 + 四单根读 + 最终全组读；
- 四角色各自首次 / 精确重复、同键异义和角色被异请求占用；
- 每角色首次漂移后根出现、一次重组成功、第二次漂移竞争；
- 四步任一步后继失败与后次原请求恢复；
- 四角色各自资源失败 / 发布未知后，即使后次预读已出现该根也先原样重放；进入时待重放 optional 与第一次实际请求逐字段相等；
- 三类结果的非成功携带根载荷 / 根组或变更事实代次、写入口返回读取态、读入口返回写态、未知枚举全部拒绝为内部不一致；
- 漂移零代次重读返回旧截止、非零单根读或最终全组读返回不等于请求守卫的截止，全部拒绝为内部不一致且不得降低本地截止；
- 已提交 / 精确重复的成功截止等于或早于实际建立请求期望代次时拒绝为内部不一致；
- 同请求并发串行收敛、异请求在 0—4 根部分完成点均零 DATA 调用拒绝；
- 最终四根身份互异、角色齐全、直接上位空、首次幂等身份 / 首次期望代次与实际建立请求对应、永久当前、零第五根；
- 初始预读或更早角色的漂移重读在本角色处理前已有根时只能是零建根证据；全部处理前快照均缺失才允许建根；漂移重读出现的根必须与单根、最终根和发布根逐字段一致；
- 失败旧发布值逐字段守恒；SELF-FORM 失败零调用，阶段18失败映射18。
