1. 在任务数据头增加 R1、`T→D`、`T→E`、初次筹办推进治理函数定义 / A1 调用事实和核心建立 / 读取、P1/A1 建立 / 读取 DTO；旧虚拟存在类型仅作 E 的兼容引用投影。
2. 在 task owner 按详细设计第 4.5 节固定键登记新锚点、关系类型、属性类型；实现核心建立单 G_T 和首次记录 / P1 / A1 单 G_P1 两个公开事务及当前 / 历史读回。
3. 把外层准备合同升为 v2，增加六个阶段幂等键、完整阶段结果和 `发布未知` 状态；完整性守卫逐项互证七段读回。
