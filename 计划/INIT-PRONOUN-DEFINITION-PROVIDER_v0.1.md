## 1. 目标、边界和完成条件

在现有概念唯一写入方内建立**独立的指代概念定义**结构。调用方能够按完整定义查询、精确复用或新建，并按身份读回同一完整定义。一个定义不依赖现实实例、词条、语言场景或本次目标。此叶只提供定义存取，**不发布“我／你／他／这／那／谁”种子、不接名称、不选择目标、不执行规则**。

公开结果满足：同一规范化定义当前至多一个身份；重复提交返回原身份；已发布的定义及组成可完整读回；损坏候选、依赖变化和发布后读回失败不得当作未找到或重新建点。编译链接通过只证明工程结果，不证明真实节点发布、运行幂等或代词解释。

正式依据：`规范/0050_项目通用机器逻辑与禁止性规则总纲_20260721.md` 第3、5节；`规范/1110_根规范_指代_20260720.md` 第2、4、6节；`规范/2220_根规范_概念空间.md` 第2、6、7节；`规范/7230_子规范_语言材料知识与交互字段.md` 第4.3节；`规范/7240_子规范_自然语言双向转换与组织规则.md` 第2节。用户已确认的首批单项语义见[设计输入](INIT-PRONOUN-CONCEPT_代词定义初始化设计输入_v0.1.md)。

## 2. 现有能力与物理归属

`概念_存在类` 的专属创建要求已存在实例，抽象创建要求来源／下位，均不能承载指代定义；`概念_特征类` 的单 FT 值域也不承载参数角色。`概念_名称关系类` 目前只识别特征与普通存在概念。本叶在 `海中鱼巣/领域/概念_存在类.h/.cpp` 内增加隔离分支，共用该类唯一概念写入对象及互斥，但使用**专用节点类型、专用读取、专用查询和独立 schema 门禁**。`是存在概念节点`、`获取存在概念`、普通存在图及其签名均不包含本分支。此物理归属不表示“代词是普通存在概念”，不新增代词总根或第二套 L1 写入方。

L1 的 `原子建立节点组` 可把定义节点和私有规则／特征项一次发布，并用组内引用连接。`查询目标字段(指代定义节点类型, 节点类型字段)` 可从唯一节点类型标记召回全部候选，无需全节点枚举或额外根。L1 组建立不包括组外关系；本叶不建立外部边。

正式 I64 FT 根与子概念通过 `概念_特征类::获取特征概念` 完整读取，并用 `比较单特征概念(x,x)` 的 `已完成／同一／特征类型根` 证明所在根链。根节点自身也满足该入口；不读取 FT 私有字段，不新增 FT ABI。非 I64 特征约束、二次计算结果、一般关系规则和任何自动求值不在本叶。

本叶组合及适用条件固定为“声明规则及全部特征约束同时成立”，不另设自由字符串条件，也不把规则列表顺序或任意逻辑表达伪装为已实现能力。一个定义仅含一个声明规则；复合短语可在后续语言知识中组合已有定义和本次约束。`指代声明规则` 是可读回的正式声明种类，**不是指向 C++ 函数的指针，也不表示已有求值器**。各规则的精确参数集合如下；参数组按角色枚举升序规范化，缺项、多项、异型或多余项拒绝。

| 规则 | 精确参数及类型 | 声明含义与后继求值边界 |
| --- | --- | --- |
| 作用域说话者／受话者／第三方 | 目标:强类型信息节点；作用域:交互作用域 | 目标受相应参与者角色限制；第三方不包含生理性别断言，不靠位置或焦点首项唯一选取 |
| 相对近指／远指 | 目标:强类型信息节点；作用域:交互作用域；参照中心:参照信息节点；参照维度规则:正式参照规则 | 只声明取向及必需参数；不预设距离阈值、物理空间或当前中心，实际规则身份由使用场景提供并核验 |
| 受限身份变量 | 目标:身份变量；作用域:交互作用域；主体类型限制:正式主体类型限制 | 声明单个待求身份及限制；是否对外提问由整句决定，未绑定时不产生虚构目标 |

参数类型中的“正式参照规则／主体类型限制”是**使用时必须由对应公开合同核验的参数槽类型**，不是本叶已经存在的外部规则端点或运行值。本叶只读写定义，不接受或持久化本次参数实值。没有后继提供者时应用返回能力缺失，不能解释成功。目标范围的“已登记强类型”须由应用时对应领域服务核验具体种类和可读性；本叶不把裸编码当成任意类型的可用指向。

`单个已登记强类型信息节点` 限定的是**未来已绑定所指的合法类型和单项基数**，不要求定义发布时已有目标。`受限身份变量` 中的目标参数是声明型、作用域受限的单项变量，未绑定时不是一个已经登记的所指节点；参数槽不保存零目标、虚构人类或未知存在。参与者身份允许来源于语言场景或引语，不因规则声明被升级为现实存在。枚举只是本提供者的声明字段编码，不是世界对象类型表或八类代词分类。

I64 特征约束是附加限定，不把说话者／第三方永久写成目标的实例特征。请求内 `特征类型根` 必须由自比较证明就是根，正式读取须为 I64 标量、I64 比较规则，`允许值域` 为规范化非空闭区间集合且被根快照值域包含；快照的名称关系列表必须为空，其余字段逐项等于读取到的正式定义（材料类型、值域、单位、比较和聚合规则）。此叶不创建 FT，也不按相同值域建立新 FT。根值域改变后，旧定义按“依赖已变化”读回，不自动改旧快照或把旧请求当新键重建。

FT 核验先自比较再获取完整信息：`入口拒绝`（包括 FT schema 尚未就绪）或 `读取接口未装配` 固定映射读取未完成，`值不存在` 映射依赖缺失，`内部不一致` 映射结构不一致，`资源失败` 映射资源失败。其它自比较非完成状态按自比较合同不可达，固定映射结构不一致。`已完成` 须同时带 `同一` 关系和非零 `特征类型根`；关系／根缺失或违反该自比较不变量，固定映射结构不一致。内容齐全而输入不等于返回根时，才返回输入拒绝。自比较成功而完整获取为空，唯一映射为 `读取未完成`，不返回依赖缺失、未找到或已证实变化。完整信息若不是 I64 标量／I64数值比较，或者快照／区间形状不合法，返回输入拒绝；已取得正式五项内容与请求预期快照实际不等，才返回依赖已变化。公开读取未完成及异常不能通过读取 FT 私有 L1 字段绕过。

## 4. 身份、规范化与唯一性

规范化先校验枚举闭集和规则参数签名，再将参数组按角色排序、特征约束按 `(被约束角色, 特征类型根)` 排序。每个特征约束的被约束角色必须在该规则的精确参数组中出现；适用参数类型闭集固定为 `强类型信息节点` 和 `参照信息节点`，约束其使用时经公开合同取得的 I64 特征材料，绝不约束不透明身份编码本身。对 `身份变量`、`交互作用域`、`正式参照规则`、`正式主体类型限制` 施加 I64 约束均拒绝。因此参与者规则只允许目标约束，相对指示规则允许目标及参照中心约束，受限身份变量规则的特征约束组必须为空；主体限制由声明型参数承载。每个 `(被约束角色, 特征类型根)` 至多一项；重复即拒绝，不自动合并两条不同条件或采用最后一项覆盖。区间两端必须 `下界<=上界`，快照与允许域均先按下界、上界排序并合并重叠或相邻区间；在上界不是 `INT64_MAX` 时才计算上界加一。名称关系非空拒绝，合法单位若有须非零。根快照值域须为非空 I64 区间集合；用所属 FT owner 的 `比较值域` 核验规范化允许域相对根域为相等或被根域包含（允许域在左、根域在右时返回 `相等` 或 `右包含左`），其它关系拒绝，读取／工程非完成单独返回。空特征约束组合法，不伪造 FT；规则本身必须存在。

唯一键为 `目标范围 + 规范化参数组 + 声明规则 + 规范化特征约束组（含正式 FT 根身份、允许域与创建时类型快照）`。词面、概念名称、实际目标、说话者、参照中心、焦点、当前候选和调用顺序不入键。不使用摘要独断相等；查询枚举该专用类型当前全部候选，逐项完整读回并与全键比较。两个完整相等候选是内部不一致，不任选首项。损坏候选或正式依赖无法互证是错误，不跳过后制造新身份。

本叶的精确范围可按字段值规范化判等，不建立长期索引。查询未找到只在候选全集完整、端点读取完整且无错误时成立。按身份获取也须完整校验节点类型、字段封闭集、基数、私有子项唯一归属和完整定义规范化互证。

## 5. L1 节点字段映射与事务

沿用本文件私有的 `节点类型字段`，新建独立的 `指代定义节点类型`、`指代规则项节点类型`、`指代I64约束项节点类型` 及下列字段键，均为 schema 稳定编码而非概念身份：`指代目标范围字段`、`指代参数签名字段`、`指代规则项字段`、`指代约束项字段`、`指代规则种类字段`、`指代约束角色字段`、`指代FT根字段`、`指代允许区间字段`、`指代FT快照字段`、`指代FT快照单位字段`。专用 `初始化指代定义结构()` 检查或建立键，只有全部键存在且类型完整才使本分支可用；不把这些键加入普通 `结构仍存在()`，不得因专用初始化失败破坏普通存在能力。

定义节点：唯一类型引用、唯一目标范围 I64、唯一参数签名 I64 数组、唯一规则项组内引用、零或多项约束项组内引用。参数签名为 `[角色0, 类型0, 角色1, 类型1, ...]`，按角色升序逐对编码；读回必须精确匹配规则签名。规则项：唯一类型引用和唯一规则种类 I64。约束项：唯一类型引用、角色 I64、FT 根强引用、允许区间 I64 数组、FT 快照原始材料及零或一个快照单位强引用。允许区间数组固定为 `[区间数, 下界0, 上界0, ...]`，长度须为 `1 + 2 × 区间数`；快照数组固定为 `[1, 材料类型, 比较规则, 聚合规则, 根区间数, 下界0, 上界0, ...]`，首项是版本，长度须为 `5 + 2 × 根区间数`。计数非负、非零且乘加须先验证无尺寸溢出，逐对端点对应规范化后的顺序。单位若存在只保存于专门的节点引用字段，不把不透明 `uint64` 编码强转成 I64。只支持上述 I64 根形状，任何多余或截断项拒绝。名称关系不写入快照，因为它不是 FT 值域语义。读取时用正式 FT 完整读取与自比较互证；私有项通过 L1 反向引用检查恰好一个定义持有。

专用 schema 由未来初始化业务显式调用 `初始化指代定义结构()`；本叶不修改普通应用装配。前置固定为普通 `概念_存在类::初始化()` 已完整成功。本入口在现有概念互斥内只读核验普通结构及共享 `节点类型字段`：普通句柄尚未完整初始化时返回 `指代定义结构状态::入口拒绝`；句柄已经存在而节点／结构不可完整核验时返回 `内部不一致`；明确底座资源失败返回 `资源失败`。不得在本入口暗中调用普通初始化、补建共享字段、重置普通句柄或扩大普通 `结构仍存在()` 的依赖。

新 schema 的三个类型标记及十字段键共十三个私有技术节点，以一个 `原子建立节点组` 一次建立，节点本身采用与现行普通标记相同的空初始字段技术形状；它们不是世界节点或概念总根。固定 `std::array<稳定编码,13>` 分别保存可用句柄与已发布待核验句柄，顺序固定为：定义类型、规则项类型、I64约束项类型、目标范围字段、参数签名字段、规则项字段、约束项字段、规则种类字段、约束角色字段、FT根字段、允许区间字段、FT快照字段、FT快照单位字段；共享 `节点类型字段` 不在这十三项中。L1 返回组建立成功后立即无分配地保存全部真实句柄至待核验数组，再做后续完整读取；其后工程异常保留该数组并向上抛出。全部基础完整结构读回并逐项核验互异、非零、空字段形状后，才赋可用句柄。若节点组发布后读回失败，只保存该组真实句柄及未就绪状态，后续初始化只能重新核验该组，不能重建第二组；不撤销已发生的技术事实。尚未初始化时建立／查询／获取返回依赖缺失；已经发布而待核验或损坏时返回结构不一致或准确资源失败，均不自动补建。只读入口保持零写入。

发布／查询采用三段准备，复用现有 `存在概念图互斥`，不得锁内调用 FT 公共接口：A段锁内读取专用 schema、完整候选集合及每项结构，收集请求和全部候选使用的 FT 根；B段锁外逐根自比较、正式完整读取、规范化五项快照，再记录不透明的完整基础节点结构及该根全部入向父子关系，前后用同一公开 FT 读取互证；C段重新加锁读回候选全集、每项完整结构及该根不透明基础结构／入向关系。三段只做一次；任一候选集合／内容或不透明端点复核实际不等时返回 `读取漂移`，零本次发布，不在锁内回调、不解析 FT 私有字段、不无限重试。FT 的当前正式五项与定义保存快照实际不等时返回 `依赖已变化`；未取得完整材料不能凭时间先后宣称发生漂移。完整快照忽略 FT 名称关系与实例引用计数，但不透明基础结构变化仍阻止使用旧准备结果继续发布。

C段最终锁持续至全键查重及本 owner 原子发布。已有相等定义时，先在无分配的栈上结果保存其真实身份与 `已发布待核验`，再生成或复制完整复用信息；全部读回成功才返回已复用。无相等且全部候选健康时，构造定义＋规则项＋约束项的 `基础组内新节点`，一次调用 `原子建立节点组`。L1 失败零该组事实；成功后立即在任何后续分配、诊断或复制之前保存定义身份与 `已发布待核验`，并保持至正常返回或携带异常返回。锁内仅做完整结构读回；解锁后再次正式核验本定义的 FT 快照，成功才填完整信息和已建立／已复用。跨 owner 不承诺共同事务或某一共同读取瞬间。

发布／已确认复用后，读回与原请求不等返回结构不一致；正式 FT 快照实际不等返回依赖已变化；完整读取为空返回读取未完成；准确 L1 非完成按其工程状态返回。所有这些路径保留真实身份及阶段，无完整信息，不假称回滚、换键或重新发布。需要形成诊断文字的分配也在同一保障边界内。其后任意异常由狭窄 catch 保存 `std::current_exception()` 并返回 `资源失败 + 已发布待核验 + 已发生身份`；上层工程终点须先固定身份／阶段再记录并中止，不能把异常变成业务否定。未取得任何真实身份前的异常直接向上送出。使用原请求重试仍保留原快照，依赖已变化时停止，不取最新域偷偷改请求。

跨 FT owner 无共同业务事务：FT 请求快照是调用方声明的预期；概念 owner 发布前正式验证，发布后再次正式读回。只有实际取得的内容复核不等，才报告相应依赖已变化或读取漂移；不声称检测两次读取之间的每一次变化，也不因尚未读回就推断变化。已发布定义保持事实。不得用同一数值句柄可读取代替快照相等。存储不添加世界支持、名称、实例、上下位或外部边。

写入结果包含独立阶段、真实身份、可选完整信息及准确状态；查询结果没有发布阶段、已发生身份或异常指针。`指代概念发布阶段` 表示所取得定义的当前核验阶段：`未发布` 是本调用尚未取得真实定义身份；`已发布待核验` 是该身份已存在但本调用尚未完成全部读回；`已完整读回` 是本调用已完成全部核验。它不表示本次新发布动作，查重复用同样进入身份已存在的核验阶段。`已发生身份` 只固定已经存在的真实身份，失败时不得据此声称本次新建；只有成功状态 `已建立`／`已复用` 分别说明本次新发布／复用完成。两类结果均区分依赖缺失、正式内容已变化、完整读取未完成、候选或不透明端点已证实漂移、结构不一致及资源失败。`已发布待核验` 永远不标为已建立；L1 资源失败或内部不一致不转为“未找到”。读取与工程状态是定义存取的技术完成状态，不是指代条件真伪或方法业务结果。查询／获取抛出的工程异常直接向上送出；取得新发布或复用身份后的异常携带身份与阶段交上层唯一工程终点，不制造语言解释或世界事实。
