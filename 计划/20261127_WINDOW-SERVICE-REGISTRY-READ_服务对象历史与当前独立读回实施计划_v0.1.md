# 服务对象历史与当前独立读回实施计划

标识 WINDOW-SERVICE-REGISTRY-READ，v0.1。基线 e47d31ef48faf652169971ea4562959e282d4249。本交互窗口独占。依赖 R130、[5380 §3.4](../规范/5380_子规范_本能方法函数合同.md)、[1130 §4](../规范/1130_根规范_特征节点.md) 及上一片[普通网页证据](../验证记录/20261127_WINDOW-SERVICE-EVENT_新窗取材与判定正式验证.md)。

仅允许修改海中鱼巣/装配.普通应用.cpp 与本片正式验证记录。现有普通 /api/control 从自我正式快照取得已定位服务对象 F，通过新_特征类::获取特征读取同次当前引用、历史不同值。现有投影新增 serviceObjectRegistry 字段，返回 status、feature、current 和 history。feature、current 与 history 项按现行稳定编码字符串。正式读到空当前、空历史时返回已读取、null、空数组。未准备或值形状不合现行正式合同标暂不可用，区分空事实；沿同一快照完整性机制，不从窗观察、账号或需求推导引用，不新增路由或读权限。既有 JSON 字段不变，无业务写入、跨窗口数据查找、数据迁移或权限值派发。

施工前检查源码和索引所有权、目录引用与实际基线。使用实际 vcxproj Release x64，普通网页窗口两窗开页、同窗多消息、分别确认。用 /api/control 读独立的自我 F 编码，比较初始、重复消息、确认前后同 F + current=null + history=[]。窗口判定仍欠定义时不进入资格写回，保持普通退出同 PID 0。已有正向历史及权限读回需后继真实材料验证，本片不造样本。若真实运行失败先记录与说明再改或复测。
