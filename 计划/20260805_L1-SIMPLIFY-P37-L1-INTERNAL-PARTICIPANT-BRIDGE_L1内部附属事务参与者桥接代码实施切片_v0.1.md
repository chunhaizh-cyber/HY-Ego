## 4. 固定函数合同

```cpp
L1内部附属提交结果 L1事实基座仓库::提交带附属参与者(
    const L1写集请求& 请求,
    std::span<L1事实附属事务参与者* const> 参与者组);
```

固定调用顺序：P15 入口/幂等/代次 -> 全部第一写前复核 -> L1候选与映射 -> 全部准备 -> 全部确认 -> P15无分配预构造 -> 全部关闭撤销 -> 单次swap -> 全部发布但保持许可 -> P15同锁读回 -> 成功释放或失败隔离释放。

失败固定对已进入组逆序撤销；撤销失败/未知时隔离 L1 和相关参与者。已有同义/异义、隔离、漂移等 P15 短路分支参与者调用0。

## 6. 创建、异常与生命周期

未来数据操作在同步调用栈拥有参与者对象和指针组；桥不保存。参与者第一写前复核/准备允许返回结构化失败；确认、撤销和四个末区函数必须 `noexcept`。内部双层结果精确保留失败参与者顺序和状态，公开空组提交不暴露该见证。资源失败、异常、坏阶段、重复参与者和撤销未知严格按详细设计收口。

参与者候选在最终发布完成且 P15 同锁读回成功释放自有许可前对普通读取不可见。P15 发布后读回失败时，参与者仍持许可并与 L1 同步隔离后释放，不撤销已发布 L1 或参与者记录。
