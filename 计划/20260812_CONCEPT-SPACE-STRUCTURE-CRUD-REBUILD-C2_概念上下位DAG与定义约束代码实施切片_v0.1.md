# 概念上下位 DAG 与定义约束代码实施切片 v0.1

日期：2026-08-12

计划身份：`CONCEPT-SPACE-STRUCTURE-CRUD-REBUILD-C2`

状态：`待激活`；设计完成，不等于实施完成

## 1. 目标与依赖

原位扩展唯一概念服务，完成直接上位组和定义约束组的原子替换，以及直接上下位、祖先、后代同截止投影。依赖 C1 最终实现 / 清理 / 退出及其 DTO、owner、类型登记和 provider ABI。

## 2. 允许范围

只允许修改 `L2概念结构.数据.h`、`服务.L2概念结构.ixx`，新增三份 `L2概念DAG定义参数验证` 临时文件和两份 CONCEPT-C2 记录，共七路径。不得修改普通应用、工程、端点服务、规范、索引或流程图。

## 3. 接口和事务

公开函数固定为：

```text
替换概念直接上位组
替换概念定义约束组
读取概念直接上位组
读取概念直接下位组
读取概念祖先投影
读取概念后代投影
```

请求携带共同头、幂等身份、目标概念、旧关系稳定编码闭包和确定排序新项。上位替换先读回当前同维度图，在纯值副本中移除旧边、加入新边，证明非根至少一个父、自环 / 跨维度 / 成环为零且唯一根可达，再以概念 owner 一份写集退出旧边并建立新边。定义替换逐项按闭合 variant 调对应公开服务核对，不接受裸编码。祖先 / 后代只作有界投影，最大深度和项目数由请求强制限制，超限入口拒绝；不持久化闭包、高度或路径。

## 4. 验证与声明

覆盖多父、整组替换、成环 / 自环 / 跨维度 / 根不可达零变化、定义多类型端点、稳定排序、当前 / 历史和幂等。只证明 DAG / 定义切片，不证明事实支持、名称、生命周期退出或投影业务正确性。
