# LANGUAGE-OBJECT-PHRASE-CANDIDATES 现实对象短语概念候选提供者计划

日期：2026-10-16。版本：v0.1。状态由`计划/计划索引.md`唯一维护。代码起点：`5cb2e9bcbd4073335ffac9f27e2fcfe5ce20b484`；执行前重新 S0。

## 1. 目标与完成边界

S01/S03/S05 的对象角色已有句面范围或由调用方提供范围，但现行解释只接受调用方已消解 E，不能从普通概念名称与现实场景成员给出证据化对象候选。本叶提供一个独立只读业务函数：对一个**恰好覆盖单个已登记词条片段**的类名范围，完整读回名称目标，取其中**抽象存在概念**，并对现实世界树本树范围的每个 E 计算概念匹配三态，返回完整、可复核的`名称关系×概念×E`评估矩阵。专属存在概念虽可被普通名称关系命名，但它绑定特定 E，不能以全特征宽匹配推广给其它 E；本叶将其保留在未过滤名称组，不纳入抽象类名矩阵。它不是定指裁决；即使只有一个`匹配`，也不自动把短语绑定为 E。空特征约束的抽象概念本来可宽匹配，不能被解释为已唯一指认。

输入范围可以位于整句任意标量位置，但本叶不判断它是否是上层**完整对象表达**，也不处理复合短语、修饰、临时专名、代词、首次引介或未知词反推。调用方可把“这个杯子”里的`杯子`作为类名子范围送来召回中间 E 证据，但不得据此采用 E；完整表达仍要按1110/7230/7240组合`这`与`杯子`的约束，再交后续指代实例/目标消歧。调用本提供者不修改现有 S01/S03/S05 子解释器或总分派；后继消费需要独立冻结句型角色映射、定指依据与采用合同。

正式依据：[0050](../规范/0050_项目通用机器逻辑与禁止性规则总纲_20260721.md) §3.1—3.2、[1110](../规范/1110_根规范_指代_20260720.md)、[7200](../规范/7200_子规范_词条概念候选与上下文消歧.md) §2—4、[7210](../规范/7210_子规范_语言候选与对象领域路由.md) §2—5、[7220](../规范/7220_子规范_概念多语种表达与自然语言接入.md) §4、[7240](../规范/7240_子规范_自然语言双向转换与组织规则.md) §2.4/§4。具名实现证据：[场景完整成员](../验证记录/20261015_SCENE-RANGE-COMPLETE-MEMBERS_施工与编译记录_v0.1.md)、[存在概念全特征匹配](../验证记录/20261014_EXISTENCE-MATCH-CAPTURE_施工与编译记录_v0.1.md)、[S03 概念条件](../验证记录/20261016_LANGUAGE-INPUT-S03-CONCEPT_施工与编译记录_v0.1.md)。

## 2. 现行能力与复用裁决

`海中鱼巣/业务/解释.基础语言.cpp`已有严格 UTF-8 标量/字节映射、`解释原文范围`、`读取强类型名称`（包括普通存在/特征与指代目标的完整类型读回）、词条/名称前后核验及现实根核对模式。该私有 helper 把名称服务的资源失败与工程未完成合并为旧分支状态，**不能直接作为新入口的失败映射**；本叶在同文件建私有精确读回适配，复用其强类型核验顺序而保留原服务状态，既有 helper 和旧分支合同不改。`新_语言类::按已登记词条最长匹配`返回整个原文的已登记片段和未知范围；`概念_名称关系类::查询词条候选概念`返回完整关系身份组；`新_场景类::读取本树范围成员完整`无成员预算并区分空集与读取失败；`新_存在类::采集存在概念匹配材料`返回匹配/不符合/材料不足、实际材料与采集期变化。组合复用这些公开读取能力；S01 专用`语言候选路由业务::形成候选`强制 A—Z 主体和 S01 知识，不可冒充通用对象短语提供者。

新入口仍归 DATA 外基础语言解释业务，直接声明于`海中鱼巣/业务/解释.基础语言.h`并定义于同名`.cpp`；头文件增加`../领域/新_存在类.h`以声明下述匹配材料 DTO。不新建 DATA 结构、名称权威、工程模块或持久候选。现有跨服务读回不能提供一个共同原子快照；本叶只形成本次调用期的前后相容证据，必须回显其界限，不冒称7200所需的最终同截止名称绑定裁决。后继采用时须按其正式合同重新验证，而不能保存本矩阵为长期指向。

## 3. 公开函数和 DTO

```cpp
struct 基础现实对象短语候选请求 final {
    std::string 固定原文;
    稳定编码 语言节点;
    std::optional<稳定编码> 未核验来源语言记录节点;
    std::optional<解释目标世界根> 显式所述世界根;
    解释原文范围 短语范围;
};
enum class 基础现实对象短语候选状态 : std::uint8_t {
    已形成完整评估, 未知词, 缺名称, 无抽象存在概念名称,
    短语结构未支持, 世界能力未支持, 世界根不可读,
    输入拒绝, 格式失败, 引用不可读, 资源失败,
    读取漂移, 内部不一致, 工程未完成
};
struct 基础现实对象短语评估项 final {
    稳定编码 词条节点, 名称关系节点, 存在概念节点, 存在节点;
    新存在概念匹配结果 匹配;
    新存在概念匹配材料 匹配材料;
    std::vector<稳定编码> 尚缺固定比较依据特征组;
};
struct 基础现实对象短语候选结果 final {
    基础现实对象短语候选状态 状态;
    std::string 固定原文;
    稳定编码 语言节点;
    std::optional<稳定编码> 未核验来源语言记录节点;
    std::optional<解释目标世界根> 实际所述世界根;
    解释原文范围 短语范围;
    std::optional<新语言信息> 语言信息;
    std::optional<新词条信息> 词条信息;
    std::vector<语言名称候选读回> 未过滤名称候选组;
    std::vector<基础现实对象短语评估项> 评估组;
};
基础现实对象短语候选结果 枚举现实对象短语概念候选(
    const 基础现实对象短语候选请求&, const 新_世界树类&,
    const 新_场景类&, const 新_存在类&, const 新_语言类&,
    const 新_词类&, const 概念_名称关系类&,
    const 概念_存在类&, const 概念_特征类&);
```

`短语范围`为本提供者所评估的原文零基 Unicode 标量半开区间，不声明它已覆盖上层完整对象表达；语言、词条信息为首次读出的完整值式快照，成功前须复读相等。`未过滤名称候选组`按名称关系身份升序保留词条命中的**全部**正式目标，包括专属存在概念、特征概念和指代；`评估组`只为其中种类为`抽象`且`对应存在节点`为空的存在概念名称关系与现实本树 E 构成全笛卡尔积，按名称关系节点、概念节点、E 节点升序，重复关系或 E 身份判内部不一致，不按相同概念压掉不同名称来源。专属概念若缺对应 E、抽象概念若带对应 E 为`内部不一致`，不以异常结构创建或删除矩阵项。每项保留 `采集存在概念匹配材料`的完整材料和三态；`材料不足`是评估结果，不是`不符合`。只有`已形成完整评估`时评估组可消费，空场景成员可以合法返回空评估组；结果状态不表达短语唯一指向、现实归类事实或已经发布的正式 L5 裁决。

## 4. 输入、读取和失败顺序

1. 严格解码整个原文；校验语言身份、短语范围非空且界内。用现行最长匹配服务读取整个原文的完整片段组；只接受**恰好一个非空已登记片段完全等于短语范围**，且其词面经`获取词条`与原文字节范围和语言身份相等。只有完整等于范围的一个未知片段才为`未知词`；范围跨已登记与未知片段、跨多个片段或只覆盖片段一部分时为`短语结构未支持`。短语内含控制/句读也为结构未支持；句中其它范围未知不影响本次短语。已匹配词条的身份、词面或语言经`获取词条`读回不相容时，复读完整匹配和词条：材料变化为`读取漂移`，稳定矛盾为`内部不一致`，不得当普通句面不支持。
2. 取得正式现实世界树根，显式根若不同返回`世界能力未支持`；现实根缺失为`世界根不可读`，场景 owner 根与有效现实根不同时为`内部不一致`。读取完整本树成员，并核验场景项、范围成员身份、重复与边界；空范围合法。该读取的`根不可读/读取已变化/结构不一致/资源失败`分别映射`世界根不可读/读取漂移/内部不一致/资源失败`。取得词条完整名称关系列表，逐一按新私有精确适配读回指代或普通名称、词条及目标强类型。没有关系为`缺名称`，有关系但无抽象存在概念目标为`无抽象存在概念名称`，其它目标继续保留在未过滤组。绝不因某个名称目标不是抽象存在概念而跳过其读回错误。名称列表与单关系的`资源失败/工程未完成/读取未完成`分别映射`资源失败/工程未完成/工程未完成`；`结构不一致`映射`内部不一致`，`读取漂移/依赖已变化`映射`读取漂移`。列表`输入不合法`映射`输入拒绝`，列表`依赖不存在`在语言/词条稳定复读仍存在时为`内部不一致`，否则为`读取漂移`；已列出的关系随后`未找到/依赖缺失/输入拒绝`按完整关系列表复读判`读取漂移`或稳定`内部不一致`。指代关系读取用其同义状态映射，不把正常`未找到`（转入普通关系读取）当错误。语言/词条服务的资源失败、结构不一致、输入不合法分别映射资源失败、内部不一致、输入拒绝；已命中的词条稳定消失按复读判漂移或内部不一致。
3. 评估范围由完整抽象存在概念名称关系组与完整 E 成员组唯一确定，不另设数量预算。乘积大小溢出或分配资源不足时返回`资源失败`并清空依赖完整性的矩阵，不截断成功。对每个 E 先用`获取存在(E)`证明它仍是当前成员，对每个目标先`获取存在概念(C)`证明目标定义可读，然后调用`采集存在概念匹配材料(E,C)`；捕获材料中的 E/C 身份及必需特征组必须与所读 E/目标定义相容。场景列出 E 而稳定读回 E 不存在、目标名称指向已退出 C、捕获材料为空，都不能当`不符合`：若复读显示成员/名称已变化返回`读取漂移`，稳定矛盾为`内部不一致`。`采集期间材料变化`直接为`读取漂移`。匹配、不符合及有完整材料的材料不足逐项原样保留；缺固定比较依据另列于该项，不补造比较值。概念无必需特征时的宽匹配照实保留，不赋予优先级。
4. 公开返回前复读语言、完整最长匹配片段、目标词条、全量名称关系列表及每项强类型目标、现实根、完整本树成员、E 内容、参与的存在概念定义和每对匹配采集材料/结果；只有全部与首次相容才返回`已形成完整评估`。任何变化或采集期变化为`读取漂移`且清空评估组；非成功也不交付可采用的部分矩阵。前后相容不证明共享原子快照或排除 ABA；调用方不得拿本次矩阵做永久身份绑定。
5. 格式/输入、未知词、无名称、无抽象存在概念、世界能力不足、资源和读取失败分别返回具名状态。`获取存在`与`获取存在概念`的可选值缺失需按上述复读定位漂移或稳定矛盾；本函数自身的配对数溢出、`std::bad_alloc`或`std::length_error`映射`资源失败`并清空矩阵，其它工程异常交现有最终诊断责任边界，不捕获为`不符合`或空候选。全程零事实写入、零场景指代实例和临时专名发布。
