记录新增、身份查询、精确查询、目标方向读取、Vt初始化、方法节点添加、方法节点组读取。

完成要求四个允许文件按v0.2设计发布。它不是完整正式任务治理；不建立查询锚点、Vt首态、
R1、状态、轮次、路径、执行、结算或调度，不证明方法业务资格，不调用、迁移或退出旧
`服务.L2*`。

## 3. 冻结 ABI 与依赖

构造注入L1、需求类、存在类、task owner move-only写端口及四个结构关系类型。公开入口：

```cpp
任务类记录结果 新增任务记录(const 任务类新增请求&);
任务类记录结果 查询任务记录(const 任务类身份查询请求&) const;
任务类记录结果 按所属存在和来源需求精确查询(const 任务类精确查询请求&) const;
任务类目标方向读取结果 读取任务目标方向(const 任务类目标方向读取请求&) const;
任务类虚拟存在结果 初始化任务虚拟存在(const 任务类虚拟存在初始化请求&);
任务类方法结果 添加方法节点(const 任务类方法添加请求&);
任务类方法组结果 读取方法节点组(const 任务类方法组读取请求&) const;
```

完整DTO、31个稳定状态、成功谓词、结构、失败映射和白名单以详细设计第3—9节为准。模块
只`export import 海中鱼巣.领域.数据服务.需求类;`。普通存在、直接特征/二次特征、白名单
外函数和旧L2调用为零。

## 4. 施工步骤与 DRIFT

1. 新建模块，定义版本2、31个状态、结构类型、请求/结果DTO和不可复制服务类。
2. 校验task owner端口与四个当前、普通、无属性、同owner、两两互异关系类型。
3. 实现一节点两关系基础记录的幂等新增、同G0读回、二元精确唯一查询。
4. 扩展查询，读取零或一Vt投影及有预算、稳定排序、唯一的方法节点组。
5. 实现方向读取，只经需求类形成调用期结果，零写、零目标复制。
6. 实现Vt初始化：处理首次材料，调用提供者形成固定规格，以自有端口恰一次原子提交，
   再经提供者专用读回；不得借端口或调用普通存在入口。
7. 实现方法添加，只证明当前普通节点并原子增加一条T→方法关系；实现方法组读取。
8. 收口分阶段双幂等、代次推进、精确重复、冲突、资源失败和发布未知原请求重放。
9. 唯一登记工程/filters并形成施工记录，列出ABI、知识变更和全部未验证项。

上游ABI/规格漂移、借task端口、使用世界owner/普通存在/`存在类结点`、复制需求目标、
判断方法资格、扩成完整正式任务核心、调用白名单外函数或旧L2、扩大生产文件，均为DRIFT。
