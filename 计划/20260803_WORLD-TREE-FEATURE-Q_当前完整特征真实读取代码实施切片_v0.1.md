## 6. 状态、缺项和排序机械检查

必须静态与动态共同证明：

```text
角色1：宿主 -> 实例槽，槽唯一宿主
角色2：实例槽 -> 抽象定义，恰一
角色3：实例槽 -> 特征值，恰一
角色3目标值投影：与角色3一一对应，恰一当前原始记录
同宿主 + 同定义：恰一当前槽
来源：只接受已发布存在节点见证，不接受服务来源
成功排序：宿主 -> 定义 -> 槽，各按命名域/键值/身份版本
关系/值去重身份不含版本；版本只参与冲突与排序
```

业务不完整缺项只使用 `特征槽、特征定义、特征当前值` 三类，结果特征组必须为空。异常或
L1内部不一致不得伪造缺项。
