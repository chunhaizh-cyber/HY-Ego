## 4. 精确接口与实施步骤

目标服务保留既有非 const 写函数并新增：

```cpp
特征定义登记结果 建立登记(const 特征定义登记请求& 请求) const;
I64特征定义结果 建立I64特征定义(
    const I64特征定义建立请求& 请求) const;
```

实施固定为：

1. 把 v0.1 两条写函数的唯一实现迁入对应 const 重载；机器分支、写集、状态映射和读回不变。
2. 既有非 const 重载只以 `static_cast<const L1特征定义服务&>(*this)` 调用对应 const
   重载；禁止复制正文、另取锁或改变结果。
3. 保持 `mutable std::mutex 锁_`，把四编码 `登记定位_` 声明为 `mutable`；`L1_` 仍是
   私有非公开依赖，不新增访问器。
4. 两种重载在同一锁内共享登记定位、幂等键域、中性提交、成功映射校验和权威读回。
5. 不修改 `运行期上下文租约`、`运行期上下文`、`运行期上下文宿主` 或 `生产运行期会话`；
   不把服务引用存出租约生命周期。
6. 更新两份既有专属记录，写明 v0.1 验收退回、v0.2 实际代码、验证和未覆盖边界。

普通编译错误或 const 机械修饰问题在白名单内修复。若实现需要修改数据头、合同版本、
租约、上下文、L1、工程或验收目录，立即停止并具名退回计划支撑。
