# 宿主会话页面消息快照提供者

身份：`WEB-PAGE-SESSION-SNAPSHOT-PROVIDER`；版本：v0.1；日期：2026-10-15。设计代码基线：main/origin/main `bc18b435b2f64cb38c6123ba661a6bbddc8528b7`。精确合同见[详细设计](../规范/详细设计/20261015_WEB-PAGE-SESSION-SNAPSHOT-PROVIDER_会话页面消息固定快照详细设计_v0.1.md)。本计划经索引登记与main发布后才可选择，执行前重做 S0。

## 1. 目标与完成条件

提供一个在同一宿主锁内完成活跃公开会话校验、页面消息序号截点、有限额度前缀复制和覆盖完整性回显的公开只读入口。来源仅是当前宿主已追加的页面可读取消息列表，包括交互者消息在上层接纳后成功追加、自我消息在待提交文本真正提交后成功追加。返回调用期原文、角色、页面序号，不产生正式语言交互记录、指代实例、强类型所指或世界事实。完成以源代码按冻结合同实现、实际项目 Debug|x64 编译链接通过、专属记录和精确发布为限；未获本轮测试指令时记录“未运行测试”。

本叶不能用 `核验网页对话当前会话` 与无会话参数的 `读取网页对话已显示消息` 分步拼接。旧 `已显示` 类型名只是可复用载荷，不证明浏览器渲染或观看。文本范围到强类型目标的固定关联、持久语言材料/交互记录、接收方可恢复指认与后续“它”均是后继，不得用本入口结果直接宣称已解决。

唯一事实所有者是 `海中鱼巣/界面/宿主.网页对话.h/.cpp` 的共享状态及互斥；消息追加、会话开始/结束和页面读取已在同一模块。现有会话核验与读取各自加锁，读取还缺会话参数、额度、覆盖字段，故裁决为扩展既有宿主模块的一个新入口，不新建服务、外部桥或语言 owner 读入口。没有代码前置提供者；本计划不消费尚未形成的语言物理合同。

## 4. 公开接口、算法与失败收口

精确ABI、字段含义和锁内步骤以详细设计第3—4节为准。新自由函数 `读取网页对话会话页面消息快照(string_view, uint64_t, size_t, size_t) noexcept` 只读共享状态；新状态为 `已完成/额度不足/宿主未运行/会话不匹配/输入拒绝/资源失败`。成功与额度不足均回显匹配会话标识、请求已读序号、同锁截止序号、已覆盖序号、完整性和按序整条消息；额度不足包括首条超额的零进展，永不伪装完整。其它状态零载荷。额度要求 `1..1024` 条、`1..8MiB` 正文字节，正文按原UTF-8字节计，不拆分。

执行顺序固定：锁外输入校验 → 取得宿主唯一互斥 → 运行与精确会话核验 → 截止及连续性/下界核验 → 同锁预算前缀复制 → 返回完整或不足。会话结束和读取由同锁排序，读取不回调其它服务、不更改共享状态；`bad_alloc/length_error` 映射资源失败，其它异常或不可能结构进入既有工程致命诊断，记录具名错误、弹窗并终止进程。失败不泄露半复制消息，不把资源故障映射空会话。若当前源事实、公开ABI或诊断规则在S0发生会改变合同的漂移，执行者具名退回计划支撑，不临场改变语义。
