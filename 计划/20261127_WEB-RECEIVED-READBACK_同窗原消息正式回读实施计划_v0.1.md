# WEB-RECEIVED-READBACK 同窗原消息正式回读实施计划

版本 v0.1，施工基线 ead184e07260faaa82fd2c5c60b1f47833814146。2026-11-27 原七组验收与具名授权。D:/海中鱼巣 main，交互窗口唯一所有者。许可源文件为 海中鱼巣/界面/宿主.网页对话.h、海中鱼巣/界面/宿主.网页对话.cpp、海中鱼巣/装配.普通应用.cpp，另含本计划、索引项及专属证据。其它工作树的旧差异不迁入，不扩大机器语义。

## 1. 现状与目标

ead184e07 的验收原件显示普通控制快照的「最近观察」被较早 M 的续办覆盖。7241 的既有同源语言解释读口才是事实来源。为已确认的原入站，加一个按本页传输序号定位的普通网页只读回执，不改口径、存储或写 owner。保留最新快照原合同，不用观察服务代替事实 reader。

## 2. 合同与失败

正式 POST 已接收时，原有 HTTP 202 JSON 追加正十进制字符串 ingressSequence，值只来自已写正式事实的本次上行序号。GET /api/control/received?id=序号 严格取原宿主会话、现有对话框能力 UUID 和入站序号，核对回环 Host 和可选 Origin（与确认只读路由相同）；无正文或非法标识拒绝。客户端不得提交内部 M、来源范围或其它窗口的会话。后台读当前该窗的正式交互确认，沿外设 owner 的查找消息读取原 M，核原 M 方向、来源、场景及窗口，再用现有正式角色读口要求原消息已固化两端且有内部交互场景，旧消息不自动补证。缺确认、同页不存在该序号或原消息无完整角色均为 404，响应不带任何消息身份。受读保护漂移、采集资源不可用则 503。没有已保存的解释则 202，调用方可重新 GET。已读 200，投影外设 M、正式解释记录和定义、正式采用（若有）、从同次解释读到的逐句范围及结构操作、正式含义，不声称事实采用或生成效果。任何非成功无正式载荷。

## 3. 实施与资源

复用 普通控制快照缓存 和既有采集线程。只存一个待采集或正在采集/已读完的键（宿主、页、序号）；HTTP 只提交/取走所请求键的值式结果，收件线程不查询业务 owner 或等业务锁。其他键遇在途返回 503；已完成异键可替换，读取对应结果后消费，刷新由新请求驱动。这是有界临时回执而非事实仓；停机没有跨会话结果。用正式角色、已确认窗口和原文完整标量范围调用 读取接收语言解释，不写数据库，不读取实际状态或需求/任务，不添语言规则。控制采集快照的原锁与节奏保留，定向读取移出锁并唤醒采集线程。代码工程错误按现有终止约定处理，内存失败防止槽永久占用。

## 4. 验证

实际 Release x64。普通程序真实 HTTP 在 A 窗确认并发送单句已登记的类别陈述作为读取对照，抓 202 ingressSequence；等正式解释与采用，随后 A 再发一条，仍单独读回第一句原 M、定义和采用。B 未确认及 B 自己确认后均不能用 A 的 ingressSequence 读取；A 在确认之前已入站的消息也不能通过原角色门槛。逐次保留请求、回应、进程和关闭，进程正常退出 0。无需重跑第 2 组问句，不计七组，不改第 1 组待裁决续用政策。
