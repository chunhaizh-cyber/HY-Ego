## 4. 实施步骤

1. 新建专属路径结构服务，冻结构造和新增入口。
2. 在同一请求代次读取当前普通方法；读取失败原样传播，内容版本不符返回 `引用冲突`。
3. 将现有路径原子写入正文降为基础任务服务私有承载入口，并授权新服务调用。
4. 普通应用装配唯一实例并提供两个 getter；工程登记新模块。
5. 任务筹办把路径新增调用改走专属服务，不修其它筹办缺口。
6. 扩展 `--test-需求`：建立真实方法，验证错误版本零写、正确版本写入和公开读回一致。
7. 形成函数级代码知识变更清单和验证记录。
