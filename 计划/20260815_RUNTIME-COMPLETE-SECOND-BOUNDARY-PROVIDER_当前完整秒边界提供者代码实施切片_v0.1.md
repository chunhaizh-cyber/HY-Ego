## 4. 实现合同

模块固定 `export module 海中鱼巣.领域.服务.完整秒时钟;`，导出详细设计第3节 DTO 和服务。服务借用 L4 const 引用、保存值式配置，并在公开 ABI 中显式删除复制构造、复制赋值、移动构造和移动赋值；无锁无缓存。

顺序固定：配置准入 -> 请求准入 -> 与配置匹配 -> 使用 L4 自身合同常量调用 -> 状态 / optional 配对 -> 正式状态分派 -> 回显 / 非负纳秒复核 -> 纳秒整除十亿 -> 比较上一边界 -> 构造观察和可选区间。坏配置返回内部不一致，坏请求返回请求拒绝；两者均零 L4 调用。代次 / 纪元不等返回纪元错配，源版本不等返回时间源版本漂移。L4 的已读取必须恰有证据，任一非成功必须无证据；非法状态 / optional 组合、坏回显形状、L4 请求拒绝或内部不一致统一映射内部不一致，其它正式 L4 非成功保持同名。全部非成功零载荷；无新秒有观察无区间。

区间只在 `当前 > 上一 >= 0` 后形成；先证明 `上一 + 1 <= 当前`且 `当前 - 上一`位于正 `I64` 范围，再把数量转换为 `uint64_t`。L3 本地不建立不可达的数量溢出成功分支；矛盾形状返回内部不一致，`计数不可表示`只保持 L4 同名结果。
