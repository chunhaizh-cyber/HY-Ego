# WINDOW-INTERACTOR-SOURCE 获取交互者按窗取材

v0.1。基线 `7a73789c8837bde8195dc1d3e2d43b2255667061`，Windows 主工作区，main。此交互窗口是唯一施工与运行资源所有者。依据 R127、[5380 §3.3](../规范/5380_子规范_本能方法函数合同.md)、[6120 §11.1](../规范/6120_子规范_自我存在服务与生存基本因果闭环.md)、[7241 §1](../规范/7241_子规范_句子转换与交互场景同步.md) 和 [详细设计](../规范/详细设计/20261126_SENTENCE-SCENE-SYNC_句子转换与交互场景同步详细设计_v0.1.md)。现行提供者都在同一生产装配，已核真实前置及单向依赖。原 INSTINCT-CONTRACT 阶段 2 是旧合同实施历史，本计划只替换具名按窗取材口径。

允许文件为 `业务/服务对象.本能运行服务.h/.cpp`、`线程/新_自我线程类.h/.cpp`、`装配.普通应用.cpp`、本计划、索引与专属验证记录。绝不改领域、D/T、执行参数合同、实际出站机制、词典、账号认证、跨父生命周期、旧消息或其它工作树。

本能运行服务新增只读 `获取已确认窗口交互事实(会话,对话框)`，直接复用外设 `读取已确认临时场景来源`，返回原结构。自我用启动前绑定传入的同一个服务，在明确确认分支调用它；移除本分支直接读取外设来源。只有已完成且有本窗实体来源才调用既有世界树场景发布。非成功沿既有边界，结构损坏由工程分支上送，无半结构。锁外读取后沿既有世界树连续复核与正式发布；同步、去重、历史保存在原所有者。本能端口随普通应用保活至自我归并。既有任务执行沿外设根枚举、核同正式窗源，缺唯一确认不猜。当前无按窗现实身份提供者，不能写全局“交互者”；保留零动作未取得。删除无调用消费者的旧全局绑定人回调。服务对象方法及其参数保持原样。观察只在既有控制投影读外设对端字段，并在正常明确按窗取材后记现有运行日志，日志失败不影响事实。

验证以实际工程 Release x64 和普通正式网页为准。双窗同进程核只开页不发表、明确确认后原来源与两个不同内场景及局部端、重复 A 复用、旧消息无角色回填新 M 入站双方、实际 Send 可得时同窗反向、现实归属未写、正常 HTTP 关闭与同 PID 退出 0。按窗本能入口回执和同源场景读回互证，不能用旧直接路径或测试专用生产分支；若原治理任务实际尝试仅记录观测，当前计划不证明原服务根父任务完成。
