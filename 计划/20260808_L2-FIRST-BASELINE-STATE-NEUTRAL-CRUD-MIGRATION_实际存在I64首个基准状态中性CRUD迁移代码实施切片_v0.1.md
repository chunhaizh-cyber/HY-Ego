## 6. 固定结果与失败收口

| 场景 | 固定结果 |
| --- | --- |
| 非法公开请求 / 登记缺失 | 入口拒绝；零 provider、零提交 |
| 新键旧代次 | 版本漂移；零 P7 / P8、零提交 |
| 首次合法且无已有首态 | 固定中性写集一次提交；精确读回后已提交 |
| 已有同主体同实例槽完整首态 | 入口拒绝；零提交 |
| 相关关系角色 / 端点 / 节点形状矛盾 | 内部不一致；零提交 |
| 同键同公开请求，当前代次已推进 | 复用账内写集；L1 精确重复、零发布；精确读回后幂等读回 |
| 同键异公开请求 | L2 幂等冲突；零 L1 提交 |
| 首次材料完成后并发推进 | L1 事实代次漂移；领域版本漂移 |
| 中性结果合同 / 映射 / 发布标志 / 重试边界矛盾 | 内部不一致 |
| 发布后精确读回失败 | 返回读回非成功；保留事实与定位，禁止补写或伪回滚 |
| 当前事实已退出但历史自洽 | 继续形成原不可变状态事实 |
| G0 / 当前读取 / 源关系组 / G1 漂移 | 一次完整重试；持续漂移返回版本漂移 |
