## 冻结行为

1. 归并入口保持版本、Gread/H、FT 和 current-G 守卫。无类型能力或无域形成的既有零输出语义保持。
2. 对已读到的 I64 FT，无论旧定义是否带域形成，归并均不读取用途3规则、不读取 R项成员或材料、不形成域；要求所有规则、R项、R成员、材料和候选值预算均为零，随后返回已归并零输出与空项。
3. 新 I64 FT 和全无规则的旧 I64 FT 补齐只建立用途1归组、用途2代表规则。已有用途1/2 完整时，即使遗留用途3仍存在，也以零写入成功；用途1/2 半结构、版本或参数漂移仍为内部不一致。
4. 非 I64 与其它既有失败映射不变。任何非成功清空项。
