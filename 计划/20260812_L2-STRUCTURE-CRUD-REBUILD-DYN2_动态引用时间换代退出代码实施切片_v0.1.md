完成必须同时满足：

1. `替换动态引用` 每次只接受 `主体`、`前状态`、`后状态` 三种强类型角色之一，在一份 L1 中性写集中退出该角色一条具名旧关系并建立一条新关系；另两条关系保持不变；
2. 主体新目标必须经 E-ID `读取存在身份来源(当前)` 证明当前正式来源，前 / 后状态新目标必须经 T1 / T2 最终 `读取状态身份来源(当前)` 证明当前正式来源；角色与目标强类型不匹配时入口拒绝；

4. `换代动态时间值` 只接受 `起始时间` 或 `结束时间` 两种强类型角色，在一份写集中建立新值、退出具名旧值并切换对应当前属性槽；允许四种材料表示之间换代；
5. 时间值换代必须显式回显并保持当前动态来源，不能借换代改变顶层来源，也不比较起止值、不解释单位或时间先后；
6. `退出动态` 显式闭合动态节点、三条自有关系和起始 / 结束两个当前值；六个事实在一个事实代次退出，主体、前后状态、来源和类型节点保持当前；
7. 请求旧关系、旧值或退出闭包与当前完整动态不符时返回 `引用冲突` 且零提交；
8. 其它当前关系、其它当前值以动态为所属节点、值来源或独立材料仍引用动态节点时，由 L1 当前引用闭包返回 `引用冲突`；DYN2 不扫描消费者、不自动退出外部所有者事实；
9. DYN1 当前 / 历史单项读取和三类当前条件查询保持原签名：替换 / 换代截止返回完整、同代次、无混合投影；退出截止由 `退出动态` 结果携带完整退出投影，DYN1 单项返回 `已退出` 空载荷且三条件组不含该动态；
10. 同一幂等身份同完整请求返回首次完整结果且零推进，同键异动态、角色、旧事实、新端点、材料、来源或闭包返回幂等冲突；

### 2.1 引用替换、时间换代与退出裁决

4230 v0.3 保留 v0.2 冻结的动态主体、前状态和后状态三个彼此独立的强类型结构引用，并以 G2 身份来源补齐强类型证明；三者不要求满足等式或共同业务解释。因此一个角色替换完成后，另外两个角色保持原值仍是合法完整动态；本叶选择“一个请求只换代一个角色”的最小原子边界。强制三腿整体换代会无理由退出两个未变化关系；允许一个请求携带可选多角色则会引入新的组合幂等和部分变更语义，均不属于 4230 已冻结合同。

主体目标只接受 `L2存在身份`，并以请求原期望事实代次调用 E-ID `读取存在身份来源(当前)` 验证；前 / 后状态目标只接受 `L2状态身份`，并以同一期望事实代次调用 T1 / T2 后续按 G2 实现的 `读取状态身份来源(当前)` 验证。引用角色与目标使用封闭变体逐字段绑定，不接受裸稳定编码、通用节点、字符串标签或运行时名称推断。新目标与该角色当前目标相同是无变化请求，返回 `引用冲突` 且零提交；DYN2 不对存在主体与状态端点作跨强类型等式判断，仅同为 `L2状态身份` 的前状态与后状态允许相同。

起始 / 结束时间使用一个强类型角色枚举选择，但每次只换代一个角色。动态顶层来源由两值共同互证，DYN2 不提供来源换代；请求必须显式回显当前来源，新值继续引用该来源。起止材料相等、数值逆序或跨表示均合法，L2 不解释时间。

```cpp
    L2动态身份 动态;
    std::vector<稳定编码> 自有事实闭包;
};

struct L2动态退出结果 final {
    L2结构结果头 结果头;
    std::optional<L2动态事实> 已退出动态;
    std::optional<L2动态自有关系引用> 已退出自有关系;
    bool 成功() const noexcept;
};
```

全部 DTO 提供逐字段默认比较。共同有效性固定为合同版本 1、非零期望事实代次、幂等身份和动态身份。

引用替换要求角色恰为主体 / 前状态 / 后状态、旧关系非零；主体角色的新目标 variant 必须是非零 `L2存在身份`，前 / 后状态角色的新目标必须是非零 `L2状态身份`。请求不携带其它两条旧关系、关系类型身份或 L1 本地键；实现从正式当前动态取得角色化关系并比较所选旧编码。新目标与当前所选目标相同只能在当前读回后裁决为 `引用冲突`。

时间值换代要求角色恰为起始 / 结束、旧值和来源非零，新材料满足共同材料规则：I64 任意，I64 组 / U64 组非空，独立材料编码非零。来源是当前动态来源的显式回显和新值来源，不是来源换代入口。

退出要求自有事实闭包恰为五个非零、严格升序且无重复的稳定编码；实现把当前三关系和两个值编码形成同样的排序集合后逐项比较。动态编码不得出现在闭包中。请求不携带角色标签、主体、状态、来源、类型节点或外部引用编码；闭包的公开语义就是一个集合，从而与 L1 规范化幂等语义一致。

成功结果只接受 `已提交 / 精确重复`、非零且相等的事实截止 / 变更代次。引用替换成功携带首次截止的完整当前动态、当前三关系和一条在本次代次退出的具名旧关系；时间值换代成功携带首次截止完整当前动态、当前三关系和一个同代次退出的旧值；退出成功携带节点、两值均在本次代次退出的动态和三条已退出关系编码。所有非成功载荷为空；提交前失败不携带变更事实代次，L1 已成功发布后的资源 / 内部读回失败可以回显已安全取得的首次变更代次，但不得伪造成功载荷。

三个 `成功() const noexcept` 只核对结果头、可选载荷组合、身份 / 生命周期、角色、非零编码和排序等不依赖私有登记的形状。起始 / 结束值是否属于登记八类型、材料表示、所属动态、来源互证和三关系类型 / 角色，必须由服务使用已加载登记在返回前验证；执行者不得把无登记参数的 `成功()` 当成完整结构预言机。

## 6. 共同写前、幂等、提交和首次结果

三个写函数的共同顺序固定为：

```text
纯值校验
-> 读取当前动态结构类型登记
-> 形成完整不可变 L1 中性写集
-> 探测当前事实代次
-> 实际代次 != 请求期望：恰一次直提原写集，由 L1 裁决重复 / 冲突 / 漂移
-> 同期望：调用 DYN1 读取完整动态(当前)并完成本函数专属前置
-> 恰一次提交同一写集
-> 从首次事实代次历史节点、关系、属性值和端点重建首次结果
```

登记未加载映射 `入口拒绝`，许可拒绝、漂移、资源失败和内部不一致精确映射。实际代次已经偏离时不得先用当前事实重建或改变写集：L1 对原幂等键先比较完整请求，精确重复返回首次结果，同键异义返回幂等冲突；新键只返回漂移。不得换幂等身份、改期望、替换旧编码或二次提交。

普通 DYN2 幂等身份完整 64 位原样映射为 L1 幂等键，不进入动态登记私有 `0x21` 域。DYN1 五个关系 / 值本地键按每份写集局部作用域合法复用：

```text
动态主体关系本地键    = 0x0205'1101U
动态前状态关系本地键  = 0x0205'1102U
动态后状态关系本地键  = 0x0205'1103U
动态起始值本地键      = 0x0205'1201U
动态结束值本地键      = 0x0205'1202U
动态端点角色          = 1
```

首次结果只从首次发布代次的 L1 历史事实重建。后继关系 / 值再换代或动态退出后，原请求重复仍返回首次关系、值、动态截止和首次退出事实；不得把未来退出代次、未来端点或未来值混入原结果。

提交前出现的入口、登记、端点、漂移、幂等、引用、许可、资源或内部非成功必须零普通事实变化，结果头不携带变更事实代次。L1 已返回成功后，若首次历史重建发生 `std::bad_alloc` / `std::length_error` 或读回矛盾，公开结果为空载荷并映射资源失败 / 内部不一致，可以回显已安全取得的首次变更事实代次，但不能宣称零变化；实现必须保留原幂等身份和原完整请求作为唯一收敛路径，不二次提交、不改变请求、不补偿已发布事实。

## 7. 单角色引用原子替换

按请求角色唯一选择关系类型、本地键、当前目标和新目标 provider：

- `主体`：使用主体关系类型与 `0x0205'1101U`，新目标必须是 `L2存在身份` 并调用存在完整当前读取；
- `前状态`：使用前状态关系类型与 `0x0205'1102U`，新目标必须是 `L2状态身份` 并调用状态完整当前读取；
- `后状态`：使用后状态关系类型与 `0x0205'1103U`，新目标必须是 `L2状态身份` 并调用状态完整当前读取。

唯一写集为：

```text
节点 = []
关系 = [
  {所选关系本地键, 源=请求动态, 目标=请求新目标,
   类型=所选登记关系类型, 角色=1}
]
值 = []
属性槽变更 = []
退出事实 = [请求旧关系稳定编码]
```

请求期望代次匹配时，先调用 DYN1 `读取完整动态(当前)`，要求返回一个完整动态及三条自有关系；所选角色当前关系编码必须等于请求旧关系，随后以原请求期望事实代次验证新目标：主体调用 E-ID `读取存在身份来源(当前)`，前 / 后状态调用 T1 / T2 最终 `读取状态身份来源(当前)`。角色 / variant 不匹配在纯值层入口拒绝；新目标未找到 / 已退出、许可、漂移、资源按同名状态；新目标等于所选当前目标或旧关系编码不符返回引用冲突；当前完整动态形状矛盾返回内部不一致。

成功 / 精确重复必须取得所选本地键到一个非零新关系编码的唯一映射。首次代次历史读回必须证明旧关系在该代次退出、新关系在该代次创建，关系类型、源、新目标和角色正确；并以同一首次变更事实代次为历史截止调用 E-ID `读取存在身份来源(历史)` 验证主体、调用 T1 / T2 最终 `读取状态身份来源(历史)` 验证前状态和后状态。另两关系、动态节点、两值、来源和创建代次保持首次截止有效且不变，端点晚于该截止的未来退出不得混入首次结果。任一缺项、多项、错端点、错类型、混代或非预期事实变化返回内部不一致，不二次提交。

DYN1 当前读取在替换代次之后只能返回所选新端点 / 新关系，历史截止早于替换代次返回旧端点 / 旧关系，截止等于替换代次返回新关系；对应当前条件查询从旧端点移除并加入新端点，另外两类条件查询不变。主体替换不要求前 / 后状态主体随之改变；前 / 后状态替换也不要求动态主体或另一状态改变。

## 8. 起始 / 结束时间值跨表示换代

按请求角色唯一选择旧属性和值类型组：

- `起始时间`：旧值必须等于当前动态起始时间值编码，新材料只映射到四个起始登记类型之一，使用 `0x0205'1201U`；
- `结束时间`：旧值必须等于当前动态结束时间值编码，新材料只映射到四个结束登记类型之一，使用 `0x0205'1202U`。

唯一写集为：

```text
节点 = []
关系 = []
值 = [{所选本地键, 所属=请求动态,
       类型=按角色和新材料选择的登记类型,
       材料=请求新材料, 来源=请求来源}]
属性槽变更 = [{请求动态, 所选登记类型, 所选本地键}]
退出事实 = [请求旧值稳定编码]
```

请求期望代次匹配时，DYN1 当前完整动态必须存在且完整；所选旧值编码必须等于请求，动态顶层来源、起始值来源和结束值来源必须三者相等并等于请求来源。另一个未换代角色必须保持当前、完整且同截止。旧值不符或来源回显不符返回引用冲突；缺槽、多槽、两值来源矛盾、所属 / 表示 / 生命周期矛盾返回内部不一致。

新材料可以与旧材料逐字段相同，也可以跨 I64、I64 组、U64 组和独立材料引用表示；显式换代仍建立新的值稳定编码。L1 在同一候选中退出旧值并移除旧槽，再建立新值和新槽，因此一个角色始终至多一个当前值，另一个角色零变化。DYN2 不比较起止材料，也不按数值或单位拒绝逆序。

成功 / 精确重复必须取得所选唯一新值编码。首次历史属性值组只证明在首次截止所选角色唯一有效值为新值、另一角色仍唯一有效；该提供者候选来自成功属性槽变更，但不返回历史槽对象。旧值另以 `读取中性历史事实(旧值编码)` 证明在首次代次退出。即时首次提交后若仍位于同一代次，可以用一致当前属性投影补充核对槽指向新值；后继事实已经推进后的精确重复不得依赖不存在的历史槽投影。结果的 `当前动态` 是首次代次完整动态，`已退出值` 保留完整退出生命周期。所属、角色类型、材料表示、来源、唯一有效值、编码或生命周期任一矛盾返回内部不一致。

## 9. 动态显式闭包退出与外部引用保护

退出前调用 DYN1 `读取完整动态(当前)`，取得动态事实和三关系编码。把三关系和起始 / 结束两值共五个编码形成全局升序唯一集合，必须与请求自有事实闭包逐项相等；任一漏项、错项或多项闭包返回 L2 `引用冲突`，零提交。

唯一 L1 写集为：

```text
节点 = []
关系 = []
值 = []
属性槽变更 = []
退出事实 = 全局升序唯一[
  动态节点编码,
  请求自有事实闭包的五个编码]
```

请求不得携带或退出主体存在、前 / 后状态、来源、十一项类型节点或其它外部事实。L1 对最终写集执行二次当前引用闭包保护：任一其它当前关系、任一闭包外当前值以动态为所属节点、值来源或独立材料仍引用动态节点，且未由其合法所有者先行退出时，返回 `引用冲突=10`；DYN2 精确映射且不扫描消费者、不返回引用者列表、不补造退出项，也不把外部所属值追加到五项自有闭包。

调用方必须先经外部结构所有者闭合当前引用，再使用新的期望代次和新的幂等身份重试；不得用原引用冲突请求身份改变闭包。动态当前自有关系与两值已经显式位于本写集，因而只闭合动态自身不会被自身引用伪阻断。

成功 / 精确重复要求空新编码映射和首次发布 / 重试边界正确；按首次事实代次历史读取动态节点、三关系、两值，并以同一首次事实代次为历史截止调用 E-ID `读取存在身份来源(历史)` 验证主体、调用 T1 / T2 最终 `读取状态身份来源(历史)` 验证前状态和后状态，六项自有事实退出代次必须相等。端点晚于首次截止的未来退出不得混入结果；主体、状态、来源、类型节点及外部已先行闭合事实不由 DYN2 退出。`已退出动态` 保留动态和两值退出生命周期，`已退出自有关系` 返回三编码；任一读回矛盾为内部不一致，不补偿已经发布的事实。

退出后 DYN1 当前单项返回已退出，三条件当前组不再包含该动态；退出前历史截止仍完整，截止等于或晚于退出代次返回已退出空载荷。完整退出投影只由本次 `退出动态` 成功 / 精确重复结果携带。DYN2 不提供复活、物理删除或持久证据清理。

## 10. DYN1 读取兼容、状态、幂等和异常收口

DYN2 不改变 DYN1 七个函数签名。DYN1 当前 / 历史完整读取必须自然消费关系 / 值历史：

- 引用替换前截止返回所选旧目标，替换截止及之后返回新目标；另两角色不变；
- 时间值换代前截止返回旧值，换代截止及之后返回新值；
- 退出前截止返回完整动态，退出截止及之后返回已退出空载荷；
- 当前三条件查询只随对应当前关系变化，按动态身份升序且不复制第二权威列表。

同一幂等身份只绑定完整请求。引用替换的角色 / variant / 旧关系和动态退出的公开闭包进入 L1 前已经具名或严格升序；精确重复返回首次动态、关系、值和首次代次，零推进；同键异动态、角色、旧事实、新目标、材料、来源或闭包为幂等冲突。发布结果未知只以原请求重提，不换键、不重构材料。

非成功顺序固定为：

```text
纯值非法或角色 / 目标类型不匹配 -> 入口拒绝
登记未加载 -> 入口拒绝
登记其它失败 -> 对应共同状态
既有幂等 -> 精确重复 / 幂等冲突
新键旧期望 -> 事实代次漂移
动态或新端点未找到 / 已退出 -> 同名
引用替换无变化 -> 引用冲突
旧关系 / 旧值 / 来源回显 / 退出闭包不符 -> 引用冲突
L1 外部当前引用未闭合 -> 引用冲突
许可 / 资源 -> 同名
事实形状矛盾 -> 内部不一致
```

所有 L1 写入状态 switch 必须完整覆盖 `引用冲突=10`。DYN1 完整动态必有三关系和两值，DYN2 不把缺失角色包装成 `属性未设置`；缺项是内部不一致。全部非成功载荷为空；提交前失败不伪造变更代次，提交后读回失败只回显 L1 已安全取得的首次代次并遵守第 6 节收敛边界。

## 11. 临时生产外验证矩阵

临时验证 cpp 只 import L1 公开服务、E-ID 存在服务、T1 / T2 最终状态服务和 DYN1 / DYN2 动态服务。主体、状态端点、动态登记、动态、来源与外部引用夹具全部经这些正式公开入口建立；状态端点所需的上游材料由 T1 / T2 最终公开入口闭合，DYN2 验证器不得直接 import 或调用 F-ID。不得 import 私有仓库、访问登记定位 / 锁 / 索引 / 幂等账、解析日志或复用历史状态 / 动态实现。

入口参数固定为：

```text
--幂等基值 <uint64，默认81000>
--起始初始I64 <int64，默认101>
--起始换代U64一 <uint64，默认202>
--起始换代U64二 <uint64，默认303>
--结束初始I64 <int64，默认404>
--结束换代I64 <int64，默认505>
```

必过矩阵：

1. 经 E-ID、T1 / T2 最终状态服务和 DYN1 正式入口建立两个主体、至少三个状态、动态十一类型登记和一个完整当前动态；DYN2 不直造端点或动态，也不直接消费 F-ID；
