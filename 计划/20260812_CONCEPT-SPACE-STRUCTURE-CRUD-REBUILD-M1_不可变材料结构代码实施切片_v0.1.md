## 4. 接口和实施

数据头唯一拥有 `不可变材料身份、材料SHA256摘要、不可变材料事实`，以及写入 / 读取 / 退出请求结果；字段精确服从总详细设计第 5、6.1 节。服务模块为 `海中鱼巣.领域.服务.不可变材料`，形成材料 owner 交付并私有持有写端口。

公开函数固定为：

```cpp
不可变材料写入结果 写入不可变材料(const 不可变材料写入请求& 请求);
不可变材料读取结果 读取不可变材料(const 不可变材料读取请求& 请求) const;
不可变材料退出结果 退出不可变材料(const 不可变材料退出请求& 请求);
```

写入顺序固定为：纯值 / 路径边界校验 -> 复读候选 -> 格式、长度、SHA-256 校验 -> 在服务材料根形成同卷临时文件 -> 原子替换到摘要定位 -> owner-scoped 写集发布材料节点、族归属、格式 / 长度 / 摘要 / 来源值 -> 从首次代次历史读回。候选或文件失败不写 L1；L1 发布后物理材料缺失为内部不一致。普通应用新增唯一材料 owner、服务成员和 const / 非 const getter，不接入业务入口。
