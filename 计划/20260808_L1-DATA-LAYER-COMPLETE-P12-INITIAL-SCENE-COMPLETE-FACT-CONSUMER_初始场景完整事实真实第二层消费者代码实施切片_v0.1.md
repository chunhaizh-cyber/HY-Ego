## 4. 实施步骤

### 4.1 场景结构 DTO

1. 在 `L1场景结构.数据.h` 增加 `<vector>`。
2. 按详细设计 §4.1 新增 `直接子场景结构事实`、`直接存在成员结构事实`、`初始场景完整结构事实` 和 `初始场景完整结构结果`；不提升既有合同版本。
3. 新增三个纯值完整性函数，冻结节点 / 值 / 关系身份、世界根、共同截止、方向、角色、组内无重复及稳定排序不变量。

### 4.2 场景领域读取

4. 在 `L1场景结构服务` 新增 const `读取初始场景完整结构`，沿用既有互斥锁和异常映射。
5. 复用当前登记和既有 `读取实现` 验证请求中的初始场景，不复制初始场景解释。
6. 在一次逻辑读取轮次中，以初始场景为源，分别调用 P11 读取直接父类型出边和直接成员类型出边各一次。
7. 对每个直接子场景精确读取当前节点、属性槽、场景标记值、标记类型和来源；调用 P10 目标关系查询验证恰一直接父且等于源枚举关系。
8. 对每个直接成员精确读取当前节点；调用 P10 目标关系查询验证恰一归属且等于源枚举关系。
9. 验证场景资格、方向、类型、角色、单父 / 单归属、局部可达无环、跨组不重复、生命周期和共同截止；任何矛盾整组失败。
10. 子场景和成员分别按业务稳定编码排序。合法零组返回 `已读取` 空组；不扫描全仓、不调用完整快照或 `状态完整`。

### 4.3 实际存在资格定位

11. 在 `L1实际存在.数据.h` 新增 `实际存在资格定位读取请求` 及纯值有效性函数；不改变旧资格读取 DTO。
12. 在实际存在服务私有区抽取唯一“已持锁资格读取”实现；旧显式资格值入口改为调用该 helper，外部签名和结果语义不变。
13. 新增 const `读取当前实际存在资格`：从当前登记的资格属性类型和当前属性槽定位资格值，再调用同一 helper 完整读取。
14. 两个公开入口都只取得一次既有锁；禁止持锁递归调用、改递归锁、缓存资格值或暴露登记定位。

### 4.4 跨域完整事实组合

15. 在组合模块增加 `<cstdint>`、`<vector>`，按详细设计 §6.1 新增 `初始场景完整事实 / 结果`、完整性函数和纯值 `成功()`。
16. 新增 const `读取初始场景完整事实`；首先调用场景完整结构入口恰一次。
17. 零成员直接成功，实际存在资格和原子发布读取调用数为零。
18. 每个成员依次调用 `读取当前实际存在资格` 和 `读取初始场景实际存在` 各恰一次；由返回事实机械形成请求，不猜测资格值、关系或版本。
19. 互证世界根、初始场景、成员、资格、归属关系和共同截止；任一失败销毁整组，零部分成功。
20. 完整成员组按存在编码严格升序并与场景成员组一一对应；组合服务对第一层直调为零。

### 4.5 记录

21. 专属施工记录只记录七路径实际变更、依赖方向、共同截止、排序和未覆盖范围。
22. 专属构建与生产链验证记录只记录真实构建、模块扫描、静态门禁和生产公开链可达性；不得写“第一层通过”“第一层已完善”或未运行的消费者结果。

## 5. 状态与调用矩阵

| 场景 | 结果 | 提供者调用 |
| --- | --- | --- |
| 无效初始场景请求 | 入口拒绝、空事实 | 场景完整结构入口一次；其内部第一层读取零或最小拒绝 |
| 合法场景、零子场景、零成员 | 已读取、两个空组 | 场景入口一次；资格 / 组合事实读取零 |
| 一项成员 | 已读取、一项完整成员事实 | 场景入口一次；资格一次；组合事实一次 |
| 多项成员 | 已读取、严格升序完整组 | 每成员资格一次、组合事实一次 |
| 场景或成员提供者版本漂移 | 版本漂移、空事实 | 已调用部分不重试 |
| 枚举成员后资格 / 完整事实未找到 | 内部不一致、空事实 | 不保留部分结果 |
| 错方向、错角色、多父、多归属、错标记、重复或同截止字段矛盾 | 内部不一致、空事实 | 不保留部分结果 |
| 分配异常 | 资源失败、空事实 | 零写入 |

全部路径写入、幂等、事务、缓存、SQL、材料、日志、完整快照、审计和恢复调用均为零。
