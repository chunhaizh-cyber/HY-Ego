## 1. 目标、范围与完成条件

在 4230 v0.5、G2 七族身份来源合同和 C1 v0.2 正式冻结的唯一 `L2因果结构服务`、因果登记、完整读取、自有事实投影与三类当前查询之上，原位完成因果条件 / 结果有序状态引用组原子替换、可空动作引用替换、来源独立材料引用属性换代、因果完整结构显式退出和 L1 当前引用闭包保护。

本叶严格是纯结构 C2。它不形成 A1 聚合面，不建立因果业务证明、动作解释、证据动态、概率、模板、用途或准入，也不修改 C1 创建合同。旧因果 / 动态模式和历史状态 / 动态代码只作已删除反例，禁止复用、复制、适配、搬移或改名沿用。

完成条件固定为：

1. `替换因果状态引用组` 每次只选择 `条件` 或 `结果` 一组，以一份 owner-scoped L1 写集退出该组全部当前关系并建立一个新的非空有序状态引用组；另一组、动作、来源、因果节点与创建代次不变；
2. 新条件 / 结果组逐项以原请求期望事实代次调用 T1 / T2 最终 `读取状态身份来源(当前)`，保持非空、顺序 / 目标非零、按 `(顺序, 目标)` 严格升序无重复和每组最多 `0x0FFF` 项；
3. 不提供单项条件 / 结果增加、删除、移动或覆盖入口；调用方必须提交完整新组，避免半组机器事实和第二权威列表；
4. `替换因果动作引用` 以一份写集覆盖空到有、有到空和有到不同动作三种变化；新动作非空时只是不透明非零稳定编码，由 L1 一致当前投影证明当前普通节点；
5. 动作当前为空且新动作仍为空、或当前动作与新动作相同，固定为无变化 `引用冲突`，零提交；C2 不把空动作解释为被动，也不把非空动作解释为主动、方法或可执行动作；
6. `换代因果来源` 以新来源建立新的独立材料引用属性值、退出具名旧来源值并切换唯一当前来源属性槽；旧值保留历史，新来源由 L1 验证当前可引用；
7. 来源换代是显式值版本动作，新来源可以等于当前来源，仍建立新值编码；它不解释来源类别、质量、完整性或业务证据；
8. 条件 / 结果关系替换、动作关系替换和来源值换代均在一个事实代次原子发布；旧事实编码必须与当前完整因果精确匹配，否则 `引用冲突` 且零提交；
9. `退出因果` 显式闭合因果节点、唯一族归属关系、全部条件关系、可选动作关系、全部结果关系和唯一来源值；全部自有事实在一个事实代次退出，状态端点、动作、来源、类型节点、锚点保持不变；
10. 闭包外任一当前关系、所属值、值来源或独立材料仍引用因果节点时，由 L1 二次当前引用闭包返回 `引用冲突`；C2 不扫描消费者、不返回引用者列表、不补造外部退出项；
11. C1 当前 / 历史完整读取和三类当前查询保持原签名：替换 / 换代截止只返回完整同截止投影；退出后当前单项 `已退出` 空载荷且三类当前组不含该因果，历史截止达到退出代次仍为 `已读取` 并返回完整退出生命周期；
12. 同一幂等身份同完整请求返回首次完整结果且零推进，同键异因果、角色、旧闭包、新组、动作、旧值、新来源或退出闭包返回幂等冲突；
13. 入口、登记、许可、未找到、已退出、漂移、幂等、引用、资源和内部错误精确分账；提交前非成功为空载荷且零普通事实变化，发布后读回失败不补偿，只允许原请求收敛；
14. 生产零验证专用实体、接口、友元、状态出口、计数器、故障注入、sleep 或测试分支；临时三文件在结果、永久记录和计划退出后由独立清理提交删除；
15. C1 最终修复结果被交互接受、索引退出、临时验证资源独立清理且逐字段匹配 C1 v0.2 前，C2 保持 `待激活`，不得施工或建立骨架；T1 / T2 已满足状态服务直接依赖，DYN1 / DYN2 已满足路线与资源释放前置，但都不把 C1 候选结果升级为最终 ABI。

C2 不判断因果真实、必然、主动或被动，不要求条件与结果不同，不执行无环证明，不比较状态内容、时间或主体，不从动态 / 历史统计生成因果，不推断动作，也不提供复活、物理删除、恢复或生产业务接线。

状态组替换要求角色有效，旧关系闭包和新状态组均非空；旧闭包严格升序、无重复且非零；新组按 `(顺序, 目标)` 严格升序、无重复，每项非零且不超过 `0x0FFF` 项。旧闭包只表达所选组的当前关系集合，角色另字段绑定，不能附带另一组、动作、族归属或来源值。

动作替换的旧关系与新动作均可空；有值时非零。当前动作关系为空 / 非空必须与旧字段形状精确相同；当前与新动作结构相同为引用冲突。请求不携带动作关系类型、本地键或另三类关系。

来源换代要求旧值和新来源非零。新来源是新值的独立材料引用和值来源节点；即使与当前来源相同也执行显式换代。退出请求的自有事实闭包是非空、全局严格升序、无重复的扁平编码集合，请求因果编码不能出现在闭包中。请求不携带分组标签；实现从 C1 当前分组投影展平并排序后比较，从而使公开请求语义与 L1 规范化退出集合一一对应，避免不同错误分组在后继代次的原键重提中被误判为同一写集精确重复。

成功结果只接受 `已提交 / 精确重复`、非零且相等的事实截止 / 变更代次。状态组替换成功携带首次截止完整当前因果、当前自有事实和本次同代退出的非空旧关系组；动作替换成功携带首次截止完整当前因果、当前自有事实和与旧动作关系同形的可选已退出关系；来源换代成功携带首次截止完整当前因果、当前自有事实和同代退出的旧来源值；退出成功携带完整退出生命周期的因果与全部已退出自有事实。全部非成功载荷为空；提交后资源 / 内部读回失败可以回显 L1 已安全取得的首次代次，但不得伪造成功载荷。

四个 `成功() const noexcept` 只核对结果头、载荷组合、角色、身份、生命周期、非零编码和排序等不依赖私有登记的形状。关系类型 / 角色、来源属性类型、材料和值来源、所属因果及当前组完整性由服务使用已加载登记在返回前验证；不得把无登记参数的 `成功()` 当作完整结构预言机。

同一 `L2因果结构服务` 在 C1 八个公开函数之后新增：

```cpp
L2因果状态引用组替换结果 替换因果状态引用组(
    const L2因果状态引用组替换请求& 请求);
L2因果动作引用替换结果 替换因果动作引用(
    const L2因果动作引用替换请求& 请求);
L2因果来源换代结果 换代因果来源(
    const L2因果来源换代请求& 请求);
L2因果退出结果 退出因果(
    const L2因果退出请求& 请求);
```

不新增 `增加条件`、`删除结果`、`移动顺序`、`设置主动动作`、`设置被动动作`、`解释来源` 或业务专用入口。服务仍不可复制，成员顺序仍为 const L1、const 状态服务、因果 owner 写端口、来源定位、结构登记定位。

公开函数与调用 L1 / L2 的辅助为 `向上送出`，只返回结构化状态，不新增日志。纯值排序 / 映射为无适用错误分支；`std::bad_alloc` / `std::length_error` 映射资源失败，其它未处理异常映射内部不一致。业务标识符全部中文，技术边界 `L1`、`L2` 和标准库名可保留。

## 5. 共同写前、幂等、提交和首次结果

四个写函数共同顺序固定为：

```text
纯值校验
-> 读取当前因果结构类型登记
-> 形成完整不可变 owner-scoped L1 写集
-> 探测当前事实代次
-> 实际代次 != 请求期望：恰一次直提原写集，由 L1 裁决重复 / 冲突 / 漂移
-> 同期望：调用 C1 读取完整因果(当前)并完成本函数专属前置
-> 恰一次提交同一写集
-> 从首次事实代次历史节点、关系、属性值和端点重建首次结果
```

实际代次偏离时不得先读当前因果、改变排序或重构写集。L1 先以完整幂等请求裁决：原键原请求精确重复，同键异义幂等冲突，新键旧期望漂移。不得刷新期望、换幂等身份、替换旧编码或二次提交。

普通 C2 幂等身份完整 64 位原样映射 L1 因果 owner 写域，入口继续拒绝 C1 冻结的来源登记和结构登记两个保留值。C1 本地键在每份写集局部作用域复用：

```text
条件关系本地键基值 = 0x0206'2000U + 项序号
动作关系本地键     = 0x0206'3001U
结果关系本地键基值 = 0x0206'4000U + 项序号
来源值本地键       = 0x0206'5001U
```

首次结果只从首次发布代次历史事实重建。后继再次替换、换代或退出后，原请求重复仍返回首次当前因果、首次新 / 旧关系或来源值和首次代次；不得混入未来退出、未来端点或未来来源。

提交前非成功零普通事实变化。L1 已成功发布后，首次重建资源失败 / 矛盾返回空载荷并可回显安全取得的首次代次，但事实可能已形成；只允许原幂等身份和原完整请求收敛，不补偿、不回滚、不二次提交。

## 6. 条件 / 结果有序状态引用组原子替换

按角色唯一选择关系类型和本地键域。唯一写集为：

```text
节点 = []
关系 = 新组逐项[
  {所选本地键基值 + 项序号, 源=请求因果, 目标=项.目标,
   类型=所选条件 / 结果关系类型, 角色=项.顺序}
]
值 = []
属性槽变更 = []
退出事实 = 请求旧关系闭包
```

同期望时，C1 当前完整因果必须完整。把所选当前关系编码按稳定编码升序形成集合，与请求旧闭包逐项相等；另一状态组、动作关系、族归属和来源值不得进入闭包。新组逐项调用最终 `读取状态身份来源(当前)`，全部共享原期望截止。

新组与当前所选 `L2有序身份引用` 逐字段完全相同为无变化 `引用冲突`。允许不同顺序指向同一状态，也允许同一顺序指向不同状态；只拒绝 `(顺序, 目标)` 完全重复、零值和非法来源。端点未找到 / 已退出 / 入口拒绝、许可、漂移、资源按同名状态；旧闭包不符返回引用冲突；当前形状矛盾返回内部不一致。

成功 / 精确重复必须取得新组全部本地键一一对应的不同非零关系编码。首次历史读回证明旧组全部关系在首次代次退出、新组全部关系同代次创建，类型、源、目标、顺序正确；以首次截止逐项调用 `读取状态身份来源(历史)`。另一组、动作、来源值、节点和创建代次保持不变。

C1 当前条件 / 结果查询随权威关系变化：替换后从旧端点组移除并加入新端点组；另一类查询和动作查询不变。历史截止早于替换返回旧组，等于及晚于替换返回新组，直到后继再替换或退出。

## 7. 可空动作引用替换

唯一写集按当前 / 新形状形成：

```text
节点 = []
关系 = 新动作有值 ? [
  {动作关系本地键, 源=请求因果, 目标=新动作,
   类型=动作关系类型, 角色=1}
] : []
值 = []
属性槽变更 = []
退出事实 = 旧动作关系有值 ? [旧动作关系] : []
```

同期望时，C1 当前完整因果的动作关系可空形状及编码必须与请求旧字段精确相同。新动作有值时用 L1 一致当前投影证明当前普通节点；C2 不要求其属于任务、方法、动态或其它 L2 族。

空到空、同动作到同动作固定引用冲突；空到有只创建，有到空只退出，有到不同动作同代退出旧关系并创建新关系。旧字段形状 / 编码不符返回引用冲突；多条当前动作关系、错角色 / 类型或动作投影矛盾返回内部不一致。

有新动作时必须取得唯一非零新关系编码；无新动作时新编码映射必须为空。首次历史读回证明旧可选关系在首次代次退出、新可选关系同代创建，条件 / 结果、来源、节点不变。动作当前查询从旧动作移除并按新动作加入；空动作不进入任何动作查询。

## 8. 来源独立材料引用属性换代

唯一写集为：

```text
节点 = []
关系 = []
值 = [{来源值本地键, 所属=请求因果,
       类型=来源属性类型,
       材料=L2独立材料引用{请求新来源},
       来源=请求新来源}]
属性槽变更 = [{请求因果, 来源属性类型, 来源值本地键}]
退出事实 = [请求旧来源值]
```

同期望时，C1 当前完整因果必须有唯一来源槽和值；当前自有事实来源值编码必须等于请求旧值，值的所属、类型、材料和值来源必须互证 C1 顶层来源。以 L1 当前事实证明新来源非零且当前可引用。

旧值不符返回引用冲突；缺槽、多槽、材料不是独立材料、材料编码与值来源 / 顶层来源不等或生命周期矛盾返回内部不一致。新来源等于当前来源仍是合法显式换代，建立新值编码并保留旧值历史；C2 不把它宣称为来源业务变化。

成功 / 精确重复必须取得来源本地键的唯一新值编码。首次历史属性值组证明首次截止新值是唯一有效来源值；旧值另以具名历史事实证明同代退出。后继事实推进后的精确重复不得依赖当前槽，而只从首次历史材料重建。条件 / 动作 / 结果关系、因果节点与创建代次保持不变。

## 9. 因果显式闭包退出与外部引用保护

退出前调用 C1 `读取完整因果(当前)`，先验证当前分组投影为族归属一条、条件 / 结果各非空、动作 0 或 1、来源值一条且全部编码全局不同，再展平为全局升序集合并与请求闭包逐项比较。任一漏项、错项或多项返回引用冲突；闭包纯值非法入口拒绝。

唯一写集为：

```text
节点 = []
关系 = []
值 = []
属性槽变更 = []
退出事实 = 全局升序唯一[
  请求因果节点,
  请求自有事实闭包]
```

请求不得携带或退出条件 / 结果状态、动作、来源、锚点、关系 / 属性类型或外部事实。L1 对最终写集二次执行当前引用闭包：任一闭包外关系、所属值、值来源或独立材料引用因果节点且未由合法所有者先退出时返回引用冲突；C2 不扫描、不补项。

调用方必须先经外部所有者闭合引用，再使用新期望代次和新幂等身份重试；不得以原引用冲突请求身份改变闭包。因果自有关系和值已在写集内，不被自身引用伪阻断。

成功 / 精确重复要求新编码映射为空。按首次截止历史读取因果节点；因果在 C2 退出前必为当前，所以退出代次必须严格大于创建代次。以 `退出代次 - 1` 读取族归属、条件、动作、结果历史关系组和来源历史属性值组以发现退出前最后有效的全部自有编码，再按首次退出截止逐编码调用 L1 单事实历史读取，证明全部自有事实退出代次等于因果退出代次。以首次退出截止逐项历史验证状态端点，并历史读取动作 / 来源；端点、来源、类型、锚点与外部事实不由 C2 退出。不得直接以退出截止调用历史组后把空组解释成合法退出，也不得用请求闭包代替 L1 历史发现和逐项互证。

退出后 C1 当前单项返回 `已退出` 空载荷，三类当前组不含该因果；退出前历史返回当时完整结构，历史截止等于或晚于退出代次仍返回 `已读取` 和完整退出生命周期。`退出因果` 成功 / 精确重复结果也携带同一首次退出投影；不提供复活或物理删除。

## 10. C1 读取兼容、状态与异常收口

C2 不改变 C1 八个函数签名。C1 当前 / 历史读取必须自然消费关系 / 值历史：

- 状态组替换前截止返回旧组，替换截止及以后返回新组；
- 动作替换前 / 后分别返回旧 / 新可空动作；
- 来源换代前 / 后分别返回旧 / 新来源；
- 退出后当前入口返回已退出空载荷；历史退出前截止返回当时完整结构，退出截止及以后返回带完整退出生命周期的已读取投影；
- 三类当前查询只随对应当前关系变化，按因果身份升序，不复制索引。

`读取因果身份来源(历史)` 与 `读取完整因果(历史)` 的退出后取数顺序固定为：

```text
读取前当前事实代次并等于请求期望
-> 读取因果节点单事实历史，校验 owner / 普通节点 / 编码与创建代次
-> 创建代次晚于历史截止：未找到
-> 节点退出代次存在且 <= 历史截止：要求退出代次 > 创建代次，结构发现截止 = 退出代次 - 1
-> 否则：结构发现截止 = 历史截止
-> 身份来源入口以结构发现截止读取唯一族归属关系组
-> 完整入口以结构发现截止读取族归属、条件、动作、结果历史关系组与来源历史属性值组
-> 以原历史截止逐编码读取节点、关系和值单事实历史，验证 owner、类型、端点、角色 / 顺序、材料、值来源和生命周期
-> 若节点已在原截止退出，全部自有事实必须携带与节点相同的退出代次；若节点尚未在原截止退出，隐藏所有晚于原截止的未来退出代次
-> 状态端点、动作和来源仍以原历史截止调用其合法历史入口
-> 读取后当前事实代次仍等于请求期望
-> 返回事实截止 = 原历史截止的唯一完整投影
```

结构发现截止只用于发现该历史时点有效的角色编码，不改变公开截止，不把退出前一代伪装成返回事实截止。组读取和每次单事实读取报告的当前事实代次都必须等于请求期望；任一组空缺 / 多项、编码在结构发现截止无效、单事实不存在、退出代次不闭合、字段不匹配或前后代次漂移均返回对应漂移 / 资源或内部不一致，禁止回退请求闭包、扫描历史索引或猜测编码。该顺序与已发布 T2 状态历史退出投影使用的 `退出代次 - 1` 发现机制一致，但不得复制状态业务 DTO 或调用状态私有实现。

非成功顺序固定为：

```text
纯值非法 -> 入口拒绝
登记未加载 -> 入口拒绝
登记其它失败 -> 对应共同状态
既有幂等 -> 精确重复 / 幂等冲突
新键旧期望 -> 事实代次漂移
因果或新状态 / 动作 / 来源未找到、已退出或入口拒绝 -> 同名
状态组 / 动作无变化 -> 引用冲突
旧关系闭包 / 旧动作关系 / 旧来源值 / 退出闭包不符 -> 引用冲突
L1 外部当前引用未闭合 -> 引用冲突
许可 / 资源 -> 同名
事实形状矛盾 -> 内部不一致
```

所有 L1 写入状态 switch 完整覆盖 `引用冲突`。C1 完整因果必有非空条件 / 结果、0—1 动作和唯一来源值；缺项不包装成属性未设置，固定内部不一致。全部非成功载荷为空；提交前失败不伪造变更代次，提交后失败只回显已安全取得的首次代次。

## 11. 临时生产外验证矩阵

临时 cpp 只 import L1、T1 / T2 最终状态服务和 C1 / C2 因果服务。状态、动作、来源、因果和外部引用夹具全部经正式公开入口建立；不得 import 私有仓 / 端口 / 锁 / 定位 / 幂等账，不解析日志，不复用旧因果、动态模式或历史状态 / 动态代码。

入口参数固定：

```text
--幂等基值 <uint64，默认101000>
--条件一顺序 <uint64，默认10>
--条件二顺序 <uint64，默认20>
--结果一顺序 <uint64，默认30>
--结果二顺序 <uint64，默认40>
```

必过矩阵：

1. 经 T1 / T2、C1 正式入口建立至少五个状态、动作、两个来源和两个完整因果；C2 不直造状态或因果；
2. 把一个因果的两项条件组整体换成另一非空有序组，只推进一个代次，旧条件关系同代退出、新组同代创建，结果、动作、来源、节点不变；条件查询从旧端点移除并加入新端点；
3. 整体替换结果组，条件 / 动作查询保持不变；替换前 / 后历史分别返回旧 / 新完整组，不出现空组、半组或双当前组；
4. 新组与当前组完全相同、旧闭包漏 / 错 / 多分别引用冲突且零推进；空组、零顺序 / 目标、重复项、未升序、超 `0x0FFF` 项或闭包非法入口拒绝；
5. wrong-family、legacy、裸 L1 和同 owner 无状态来源端点由最终状态服务结构化拒绝，C2 原样映射且零变化；
6. 状态组替换原请求立即及后继代次重复返回首次结果；同键改角色、新组或旧闭包幂等冲突；
7. 动作空到有、有到异值、有到空各只推进一个代次；动作查询准确增删，条件 / 结果 / 来源不变；
8. 空到空和同动作替换引用冲突；旧动作关系空 / 有形状或编码不符引用冲突；非当前 / 非普通动作精确非成功且零推进；
