## 1. 目标与当前裁决

用户已经明确确认：方法条件、结果节点可以直接保存自身精确值域，不通过修改共享概念来保存本次材料。本叶仅支持有限I64闭区间的建立、读取、复制、合法性检查；所有未支持私有值域的既有任务语义消费者必须明确拒绝，不能默认为无约束。

冻结口径：

- 复用纯值类型`特征概念I64闭区间`，它只有上下界，没有概念身份。
- 同项`特征值域概念节点`与`精确数值域`互斥，双写直接拒绝，不取交集、不覆盖。
- 必须同时明确特征类型，且该特征概念当前材料类型为I64标量。数值以该特征类型自身单位解释，不进行隐式单位换算。
- 区间有限且下界不大于上界；INT64_MIN/MAX作为无限哨兵均拒绝。单点是上下界相等的区间。
- 存储能力允许完整有限区间，但未来模拟首次发布只使用实际采样单点，不将有限采样推断成全域经验。
- 只沿现有建立新方法结构、完整复制结构的入口保存，不新增原地改写已使用CR、模拟追加CR或自动学习入口。既有空组本能登记不预造CR。
- 本叶不处理命中次数；未来模拟生成新配对的命中初值为0，现实验证之后才增加。

## 2. 当前实现及复用

`新_方法公共类型.h`的条件项/结果项当前只有概念值域引用；结果禁止项复用结果项类型。`概念_特征类.h`已有纯值闭区间，`基础值`已有`vector<int64_t>`材料，无需扩展底座或新建通用数值类型。

任务筹办在只有类型、没有概念值域时可能直接判具备；结果方向可在私有域被忽略时单独进入执行判断。故仅加字段会有真实误放行风险，必须同叶封堵。已有影响评估/冲突DTO不能携带该私有域，本叶不扩展这些DTO，而是在转换为该材料之前拒绝。

## 4. 数据布局和唯一权威

在`新方法条件项定义`和`新方法结果项定义`现有数据成员末尾、默认operator==之前追加：

```cpp
std::optional<特征概念I64闭区间> 精确数值域;
```

头文件包含唯一类型所有者`概念_特征类.h`，不复制声明；追加位置保留既有聚合初始化字段顺序，缺省为空，默认相等比较自动包含该字段。结果禁止项自然获得同一字段。

物理采用方法owner唯一字段`项精确数值域字段`，条件项和结果项共用该标签但每个所属项独立拥有直接值。添加到当前schema编码组，按现有初始化分配稳定编码，不硬编码编号。每项最多一条字段，内容必须为`基础值{vector<int64_t>{下界,上界}}`；单字段保存两个端点，不能拆成半区间可见的两条字段。旧项没有字段合法，不自动迁移或补写。

读取规则：字段0条返回缺省；1条严格解析两元素I64数组且检查有限有序；多条、节点引用、非I64数组、长度非2、倒置、无限哨兵均结构不一致。双写概念域、缺FT、FT不存在或非I64同样拒绝。条件、结果、禁止结果统一校验。

新字段只是方法项材料，无独立身份，不增加特征概念引用计数，不创建或修改概念节点。单位只来自项的`特征类型概念节点`当前定义；本叶消费者暂不支持，因此不发生按错误单位计算或执行。

## 5. 方法owner实现合同

私有新增入口只放同cpp匿名命名空间，诊断责任均向上送出：

```cpp
bool 精确数值域有效(
    const std::optional<特征概念I64闭区间>& 域,
    const std::optional<稳定编码>& 类型,
    const std::optional<稳定编码>& 概念域,
    const 概念_特征类& 概念服务);

std::optional<std::optional<特征概念I64闭区间>>
读取可选精确数值域(稳定编码 项节点);

bool 写入精确数值域(
    稳定编码 项节点, const 特征概念I64闭区间& 域,
    std::vector<稳定编码>& 已写字段);
```

外层optional表示结构读取成功，内层optional表示字段有无；不得把结构坏读为缺省。写入函数调用现有`添加字段值`，成功关系进入现有回滚清单；失败返回false，不单独发表结构。

`结果项有效`、`条件结果有效`补同一值域合法性检查；`读取条件`、`读取结果项`读字段后立即执行合法性检查；`读取结果`继承普通结果及禁止结果拒绝。校验取用正式`概念_特征类::获取特征概念`只读入口，不查看概念owner私有字段。

为保持读取及校验使用当前服务，不引入全局服务指针或临时第二owner：在需要概念检查的既有私有函数末尾显式传`const 概念_特征类& 概念服务`，向上传递到既有成员的`特征概念服务_`。受影响链包括`读取方法信息`、`读取多节点字段`（根成员读取会调用方法读回）、`读取有序子节点`、`读取参数规格`、`读取实例根结构`、`读取条件`、`读取结果项`、`读取结果`、`结果项有效`、`条件结果有效`、`查询本能登记结构`和`发布方法结构`。这些都是同文件私有签名调整；公开`新_方法类`头文件和调用签名不变。机械转递不能改变旧字段语义。

`写入条件结果`的条件项循环和`写入结果项`在挂所属项之前保存可选私有域；禁止结果继续复用结果项写入器。`方法复制字段规格`在条件项/结果项的直接值白名单加入该字段，原始两元素数组按值复制，不映射为节点引用。新建、复制前校验以及完成读回均须覆盖，确保结果材料等于输入且来源私有值域未被改写。

失败映射保留现有合同：请求非法返回`条件结果不合法`且不新建；坏结构读回为空/结构不一致；复制坏结构返回`新方法复制状态::结构不一致`；分配/写入失败返回资源失败并回滚本次未发布节点/字段。已根发布后读回失败保留现场，不删除可能已可见材料。持方法锁组织、按既有方式最后挂根，不声称跨底座读取者原子；未改变共享概念，没有新增跨owner写事务。

方法锁→概念只读查询方向不得新增回调或反向方法调用；不持锁调用外部函数/日志。既有`调用本能函数`仍在释放方法锁后调用，不在本叶改为模拟函数。

## 6. 消费者安全拒绝

任务cpp添加匿名只读检测辅助，签名`bool 含私有数值域(const 新方法条件结果信息&) noexcept`和`bool 含私有数值域(const 新方法信息&) noexcept`；完整检查条件项、结果项、禁止结果项。辅助仅检查optional，不查询世界、不分配、不裁决已满足。不得隐藏在“没有概念域”分支之后。

| 既有入口 | 拒绝时点与返回 |
| --- | --- |
| `筹办任务条件和参数` | 获取候选方法后、条件判具备前，方法含私有域则该候选`结构缺口`；不当作参数齐全 |
| `选择任务方法结果` | 遍历实例配对时发现私有域则返回`结果定义暂不支持`，不依据其变化方向选中、不遗漏后选次优 |
| `提议任务条件子需求` | 已定位配对的任一私有条件/结果/禁止项，返回`暂不支持`且不提出子需求 |
| `判断父子需求方向一致` | 父/子候选方法读取后、匹配方向前发现私有域返回`结构不一致`；根链继承该拒绝 |
| `核验任务执行方向` | 正式定位方法/配对后，转换预计变化、禁止结果及冲突输入之前，返回`结果定义暂不支持`；不生成丢失私有域的预计材料 |
| `开始方法执行` | 请求方法必须正式可读；包含私有域返回`方法影响定义不合法`，在执行实例/动作产生之前零写拒绝，堵住绕过筹办的直接调用 |
| `评估方法执行影响` | 从执行实例的方法节点正式读取方法；缺失返回结构不一致，含私有域返回`方法影响定义不合法`，在复用既有评估或形成新评估之前拒绝 |

`查找冲突需求`只处理已经生成的预计阶段材料，本叶不为其伪造私有域字段；上游核验必须先拒绝，且开始执行硬门再次拒绝。不得声称冲突算法已经支持私有数值域。`复核条件子需求就绪`、`确认任务进入待执行`、`执行任务本能方法`复用正式选择/核验入口，读回确认无旁路；如存在直接跨越本表的调用，只增加相同拒绝，不扩展完整消费。

结算运行服务在读取登记方法后、旧CR恢复前检查所有私有域，遇到则用既有失败出口说明“私有数值域暂不支持”；确认收尾在读取执行方法后同样拒绝，不能因旧预计DTO不含字段而确认成功。可在该文件匿名空间使用同形私有检测辅助，不新增共享工具ABI，不增加本能动作。

以上拒绝表示能力尚不支持，不代表区间数学不合法。既有enum有暂不支持/结构缺口时优先使用；没有时使用表中明确现有失败状态，不扩展枚举。
