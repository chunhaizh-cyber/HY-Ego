## 4. 目标代码

### 4.1 许可模块

逐字建立详细设计 §3.1 的常量、见证、状态、move-only许可和取得结果。F0许可保留固定布局的不透明私有状态指针但始终为nullptr，不分配且不含有效锁或域材料：默认/移动后 `有效()==false`，`读取见证()=={0,0,0}`。R1只能实现既有私有状态，不得改变许可对象布局。

### 4.2 事务域

只新增：

```cpp
节点直接统一冻结许可取得结果 取得统一冻结许可(
    std::uint32_t 预期冻结规则版本) const;
bool 冻结许可属于本域(
    const 节点直接统一冻结许可& 许可) const noexcept;
```

F0函数体分别固定返回 `{未实现,nullopt}` 与 `false`。不得读取现有事务域成员、取得普通读取许可或修改构造。

### 4.3 类型化值仓模块

建立详细设计 §3.3 的状态、值式副本、结果和访问器。访问器构造只绑定仓引用；`复制全部已发布记录` 固定返回 `{未实现,nullopt}`，不得调用 `导出权威状态()`、取得仓锁或读取许可。

### 4.4 自检

新建骨架自检模块并在 `启动.应用程序.ixx` 以唯一编号 `WORLD-TREE-CORE-FREEZE-DP-S01`、顺序225登记。S0记录顶层数量 `N`，目标 `N+1`；R1只原位扩充该身份。
