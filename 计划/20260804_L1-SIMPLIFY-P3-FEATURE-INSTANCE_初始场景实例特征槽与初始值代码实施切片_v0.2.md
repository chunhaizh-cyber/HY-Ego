## 3. 实施与验证合同

1. 运行期初始化固定为世界登记 -> 初始场景 -> P2 登记/定义 -> P3 登记/实例；任一步失败停止后继，不回滚已发布事实。
2. P2 登记首次调用读取同一 L1 完整快照，接受非零且精确等于请求期望代次、服务自身未登记的状态，追加固定四节点；代次漂移、内部矛盾和重复登记按补充设计返回。
3. P3 登记不要求代次0，只要求同一 L1 当前代次精确匹配；实例写集仍为一节点、两关系、一 I64 值、一属性槽，成功后公开独立读回。
4. 自检必须在一个隔离 L1 中覆盖完整顺序、每次代次推进、P2 非空追加四节点、P2/P3 同代次读回、重复/冲突、实例幂等和失败零新增事实。
