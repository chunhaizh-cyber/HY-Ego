# 数据服务最终需求清单

日期：2026-08-16
版本：v0.7
身份：`BIZ-DATA-EXTERNAL-SERVICE-REQUIREMENTS`
状态：当前目标业务所需公开服务需求基线

## 1. 文件用途

本文件是 BIZ 向基础数据系统提出的唯一总清单。它只回答四件事：

```text
调用哪个公开服务
+ 根据什么参数读取或提交
+ 返回什么结构化数据
+ 空结果和失败怎样区分
```

“最终”表示本文件是当前目标业务范围内的最终汇总入口，不再通过聊天消息维护另一份接口清单。它不表示所有 C++ ABI 已实现，也不规定基础数据系统的内部架构、实现或施工顺序。

本文件中的“公开服务”均指 BIZ 可以通过普通应用上下文取得并调用的强类型服务。BIZ 不直达通用事实仓，不传入内部路由选择，不根据裸稳定编码猜测对象类型。

## 2. 所有公开服务的共同合同

### 2.1 读取请求

读取请求按能力需要包含：

- 合同版本；
- 当前或历史读取类别；
- 一个或多个强类型稳定身份；
- 期望事实代次或事实截止；
- 需要完整枚举时的数量预算、分页限制或继续游标；
- 业务已经冻结的范围、规则或版本身份。

只有具名“读取全部当前组”入口可以把 `期望事实代次=0` 定义为“选择调用时最新当前快照”。单对象读取、条件读取和全部写请求必须使用非零事实代次守卫。

### 2.2 写请求

新增、替换、迁移、退出或发布请求按能力需要包含：

- 完整强类型提交材料；
- 非零期望事实代次；
- 非零幂等身份；
- 全部引用对象的强类型身份和合同版本；
- 发生时间、来源身份或规则版本（仅当目标结构本身需要保存这些字段时）。

同一幂等身份和逐字段相同请求必须收敛为首次结果；同键异义必须结构化拒绝。资源失败或发布结果未知时，调用方只会使用原幂等身份和原完整请求收敛，不会换键重试。

### 2.3 结构化结果

每个结果至少能够区分：

```text
已读取 / 已提交 / 精确重复
未找到 / 已退出 / 属性未设置 / 合法空组
事实代次漂移 / 幂等冲突 / 引用冲突 / 请求拒绝
资源失败 / 发布结果未知 / 内部不一致
```

成功结果必须带一个非零事实截止以及完整值式事实或完整事实组。失败结果不得夹带可被误当成成功的对象、变更代次或部分事实。一次组合读取中的节点、关系、值、生命周期和身份来源必须来自同一事实截止。

### 2.4 共享事实截止

普通应用中参加同一次业务组合读取的公开结构服务必须使用同一个 `L1事实基座运行包`。当前自我治理一致事实范围至少包括 DATA-EXT-01、02、12、13、15、16；结构 owner 只约束写入来源，不各自拥有事实时钟。同一次 L1 原子发布形成全局唯一事实代次，来自不同 L1 实例的相同数值不得视为同一截止。跨结构组合读取固定为：

```text
读取前共享事实截止 G0
-> 全部 L2 当前读取统一使用非零 G0 守卫
-> 读取后共享事实截止 G1
-> G1 == G0 且全部子结果事实截止 == G0 才成立
```

事实截止就是 L1 当前原子发布边界，不再增加“发布见证”第二字段。运行代次、事实范围版本、时间戳、最大版本、owner 身份和读取幂等账都不能替代事实截止。

### 3.5 不建立独立发布见证服务

旧 `DATA-EXT-17 运行期事实发布见证服务`自 v0.4 退出最终公开服务清单。它把同一 L1 全局事实代次错误复制为逐 owner 向量，并额外发明无独立来源的发布见证字段、provider 合同版本和 owner 请求组。

BIZ 当前只经 DATA-EXT-07 同实例取得 DATA-EXT-02，并调用现有 `L2存在结构服务::读取当前事实代次()`读取共享截止。该调用不读取存在对象、不取得 L1、owner、仓库或锁。若 DATA 后继把同义入口提升到 `L2结构聚合服务`，只能机械保持“无对象参数 -> 单一非零共享事实截止”的合同，不得恢复逐 owner provider 组。

## 4. 本清单不要求的基础数据公开服务

当前不要求语素、持久词性或信息入口类型公开服务。概念本体根和普通概念保持语言无关；语素只有在真实构词需求证明词条和解析候选不足后才能另行设计。词性若后继需要，只由 BIZ 根据本次词出现、完整名称候选、目标强类型、句法关系和上下文形成可重算值式判断，不进入基础数据服务。

线程生命周期、线程队列、控制面板投影、事件日志、缓存统计、外设采集、外设原始材料、持久证据和纯值算法不属于基础数据公开服务，不得列入或通过一个万能 DATA 查询口转发。

## 6. 维护规则

1. 新的 BIZ 详细设计若需要基础数据，必须先在本文件新增或复用一项公开能力，再在详细设计中引用编号。
