## 1. 本版修订原因

v0.5 把 `安全维护外部事实规格.后状态/来源事实批次` 冻结为服务调用前必选句柄，但纯被动变化没有这两个身份；服务和纯值算法又不得生成稳定身份。旧外部载荷还只提供参与者组，无法在核心会话回调中创建后特征值、后状态、动态、关系和索引候选，也没有外部事实发布后权威读回。

本版固定裁决：

1. 调用方在 `安全维护请求.外部事实身份规格` 中提供后安全特征值、后状态和状态变化动态三个稳定主键。
2. F-S103 只返回可选 `来源已发布事实批次`：主动分支复制所选已发布结算批次，纯被动/无变化/重放固定为空。
3. `安全维护外部事实规格` 不再要求后状态句柄；它携带三个稳定主键、当前快照前状态、候选值、可选既有来源批次、提交方法和版本。
4. 数据操作唯一拥有 move-only `安全维护外部事实参与包`。包在核心会话回调中用三个稳定主键形成后特征值、后状态、动态、关系和索引候选，向执行器提供稳定参与者视图，并在最后发布后返回权威外部事实读回。
5. 纯被动分支不得临时生成来源事实批次；来源存在固定为自我，来源动作固定为定义中的被动维护提交方法。
6. 无变化或精确重复仍可能发布维护游标、累计有效时间和维护账；普通核心入口拒绝空核心写集，因此该分支必须消费 `CORE-C1/v1` 的 `执行仅参与者事务`，不得伪造结构候选。

## 4. 精确 DTO 与接口替代

协议模块追加：

```cpp
struct 安全维护外部事实身份规格 {
    节点稳定主键 后安全特征值稳定主键;
    节点稳定主键 后状态稳定主键;
    节点稳定主键 状态变化动态稳定主键;
};
```

`安全维护请求` 追加 `std::optional<安全维护外部事实身份规格> 外部事实身份规格`；`安全维护载荷` 追加 `std::optional<节点句柄> 来源已发布事实批次`。

实际值变化时身份规格必须存在、三主键非零且命名域依次精确等于 `节点稳定主键命名域::特征值身份`、`节点稳定主键命名域::状态身份`、`节点稳定主键命名域::动态身份`；无变化或精确重复可以为空。F-S103 不读取或生成主键，只在主动结算分支写所选既有批次。

`安全维护外部事实规格` 固定为：

```text
幂等主键、自我、维护族、适用场景、外部事实身份规格、前状态、
前值、后值、整数变化量、维护方向、发生时间、
optional 来源已发布事实批次、被动维护提交方法、来源版本
```

数据操作模块唯一声明详细设计 v0.5 第 10.1 节冻结的：

- `安全维护外部事实发布读回载荷/结果`
- `安全维护外部事实参与包`
- `安全维护外部事实参与载荷/结果`
- `安全维护外部事实参与提供者`

参与包的三个私有虚函数签名、友元、生命周期和 #359 真实实现边界不得改名、扩参或降级为裸回调。只有 #377 隔离提供者与 #359 真实适配可以实现该包；公开业务结果不得暴露它。

## 5. 事务与读回硬合同

F-S107：

1. 先读已发布事实并调用 F-S103。
2. 无变化/精确重复以空外部包调用 F-S108。
3. 实际变化先复核三主键，再形成外部规格；纯被动批次为空，主动批次等于 F-S103 载荷。
4. 外部形成非成功时零写入；成功包唯一移动给 F-S108。

F-S108：

1. 实际值变化时，安全记录参与者固定在前，外部包参与者视图在后；调用普通核心会话事务。
2. 普通核心执行器回调调用 `外部包.写入核心候选(会话)`；完整后请求提交。
3. 回调完成后参与者按特征值、状态、动态、因果/关系、索引顺序准备和确认。
4. 无变化或精确重复时，只形成安全记录参与者并调用 `执行仅参与者事务`；不得调用普通入口或建立哨兵结构。
5. 最后发布后先读回安全维护记录；实际变化再调用 `外部包.读取发布后事实()`。
6. 三个已发布句柄的稳定主键、前后值/状态、动态、可选来源批次、代次和版本必须逐字段一致。
7. 发布后不一致为 `内部不一致`，不得伪回滚。
