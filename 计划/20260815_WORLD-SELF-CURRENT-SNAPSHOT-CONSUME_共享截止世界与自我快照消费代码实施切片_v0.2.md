## 1. 目标与完成条件

实现 `运行期只读查询组合器::读取共享截止世界与自我快照`：按请求唯一非零事实截止，经同一 `L2结构聚合服务`正式读取现实世界、自我角色、自我存在、当前位置成员和内部世界宿主，全部结果截止相同且逐字段互证后返回完整快照。

完成必须同时满足：

1. 只建立一个 BIZ 组合模块，不修改 DATA provider，不直达 L1、SQL、缓存或日志。
2. 场景与存在全部当前读取统一使用请求中的一个非零事实截止；不建立逐 owner 向量或第二发布见证。
3. 整树、两条直接父子边、自我成员、宿主正反向、自我角色、身份来源和完整存在全部闭合。
4. 只在 `已形成` 时返回快照；其它状态零部分载荷、零 DATA 写。
5. 根工程和生产外专项通过；父级共享截止读取与 G0/G1、SELF-FORM 和真实治理接线保持 `NOT_RUN`。

## 4. 物理实现合同

新模块声明固定为：

```cpp
export module 海中鱼巣.领域.组合.运行期只读查询;
```

模块只 import 场景、存在、结构聚合三个正式模块，唯一导出详细设计第 4 节 DTO 和 `运行期只读查询组合器`。组合器保存 `const L2结构聚合服务&`，不可复制、不可移动；中间结果全部局部值式，不保存上次请求或结果。

入口按详细设计第 5 节固定顺序调用。六项请求头均使用 `请求.事实截止代次`；先复核结构化状态，再复核结果截止，最后访问载荷。任一非成功立即返回，不用后续服务补救前一项。

状态映射固定为：未找到 / 已退出 -> 材料缺失；DATA 明确事实代次漂移 -> 当前性漂移；入口拒绝 / 引用冲突 / 数量预算不足 -> 提供者拒绝；资源失败 -> 资源失败；DATA 内部不一致、坏成功、错截止、复义和其它不应出现状态 -> 内部不一致。禁止仅凭结果截止不同、调用时序或推测存在并发，把 DATA 内部不一致重分类为当前性漂移。

模块私有中文辅助执行稳定排序查找和逐字段互证。完整快照必须先在局部一次构造，最后移动到成功结果；禁止先写 optional 后逐步填充。
