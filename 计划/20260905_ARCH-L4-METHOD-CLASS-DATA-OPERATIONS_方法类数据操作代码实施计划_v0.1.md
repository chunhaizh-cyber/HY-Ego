## 3. 冻结 ABI

存在类新增独立版本1、16状态、五DTO及：

```cpp
方法虚拟存在写集规格结果 形成方法虚拟存在写集规格(
    const 方法虚拟存在写集规格请求&) const;
方法虚拟存在查询结果 查询方法虚拟存在(
    const 方法虚拟存在查询请求&) const;
```

不得复用/泛化任务Vt，不使用普通存在、世界owner或存在类写端口。规格只返回method owner
一节点一关系无权限写集；查询验证M→Vm唯一及Vm目标反向恰一，禁止多方法共享Vm。

方法类版本2、34状态、v0.1全部DTO加Vm投影/初始化DTO，公开八入口：

```cpp

方法类条件结果 添加条件项(const 方法类条件添加请求&);
方法类条件组结果 读取条件项组(const 方法类条件组读取请求&) const;
方法类结果方向结果 添加结果方向项(const 方法类结果方向添加请求&);
```
