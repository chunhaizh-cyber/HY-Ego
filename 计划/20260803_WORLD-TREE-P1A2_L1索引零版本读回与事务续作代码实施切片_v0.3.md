## 4. 精确施工合同

### 4.1 DTO 与准入

不改变 `节点直接发布后读回项` 和 `可重建索引读回` 的现行物理声明或字段。`请求静态完整_` 必须按 v0.3 详细设计 §4 同时验证：索引种类、`索引物理键` variant、`预期版本==0`、读回规格无重复、每个索引键在写集中只有一条创建或移除操作，以及与同键索引写项一一配对。任一失败在持久准备和候选调用次数均为零时返回 `入口拒绝`。

其它对象读回继续要求其真实非零对象版本。不得把节点目标版本填入索引读回 `预期版本`，不得忽略或归一化非零值。

### 4.2 当前索引

`当前索引` 读回只与唯一同键 `节点直接索引创建项` 配对。局部节点目标经本事务计划身份映射解析；既有节点见证原样复核。完成发布和代次推进后、原独占许可释放前，执行器读取当前索引记录，要求键、当前性和节点目标与创建项及已确认候选逐字段一致，形成：

```text
键 = 读回项索引物理键
当前 = true
节点目标 = 解析后的创建目标
关系目标 = nullopt
```

### 4.3 已移除索引

`已移除索引` 读回只与唯一同键 `节点直接索引移除项` 配对。写前当前记录、移除项 `预期目标` 和已确认候选必须一致。完成发布后同键必须未命中，结果以不可变移除项/候选中的节点见证形成：

```text
键 = 读回项索引物理键
当前 = false
节点目标 = 移除项.预期目标
关系目标 = nullopt
```

未命中单独不是成功证明；从未存在、错误目标、无配对或多配对均不得形成已移除读回。结果不声称索引仓保留移除历史。

### 4.4 编码、幂等与发布后失败

零值按现行 U64 网络字节序进入请求意图、确定性写集材料、幂等比较、持久准备和恢复解码。当前/已移除种类、键、当前性、节点目标和空关系目标进入不可变幂等原结果及结果摘要。精确重放返回原发布代次和原索引读回，不查持久端口、不推进代次。

发布后索引命中/未命中或目标不一致时，执行器隔离事务域并返回 `内部不一致`；不得撤销、重写或伪回滚已发布事实。

## 5. 实施顺序与失败收口

1. 从正式新 HEAD 重核当前 P1A2 未提交 WIP、index 和所有权；只续作计划白名单，不夹带其它 WIP。
2. 先闭合索引读回静态准入和同键一一配对；非零版本不得进入持久准备。
3. 在固定普通事务的索引候选段形成创建/移除预期目标，并在发布后原许可读回中形成两类 `可重建索引读回`。
4. 把零值和完整索引结果纳入确定性材料、幂等原结果、持久证据和恢复解码；不得新增平行格式。
5. 继续完成 v0.2 全部未完成施工，更新工程和专属记录，执行完整矩阵。

候选前失败、候选建立/确认失败、逆序撤销、未发布见证、部分发布、代次推进和发布见证继续服从 v0.2/v0.1/4040。只有本版明确新增的索引版本与读回规则替代旧空白。

## 6. 验证
