日期：2026-08-12

计划身份：`CONCEPT-SPACE-STRUCTURE-CRUD-REBUILD-N1`

状态：`待激活`；设计完成，不等于实施完成

## 1. 目标与依赖

新建唯一 `L2概念名称结构服务` 和名称关系 owner，完成概念到词条的首选 / 别名 / 简称关系、当前 / 历史、退出、按概念名称读取、按词条 + 词性读取候选和非权威反向索引重建。依赖 L1 语言结构和 C2 概念维度 / 当前读取真实结果。

## 2. 允许范围

新增 `L2概念名称结构.数据.h`、`服务.L2概念名称结构.ixx`；修改普通应用、根工程 / filters；新增三份 `L2概念名称候选参数验证` 临时文件和两份 CONCEPT-N1 记录，共十路径。禁止修改词条 / 概念端点服务、现有聚合、启动入口和流程图。

## 3. 接口和事务

数据头唯一拥有名称角色、名称事实、写 / 读 / 退出 / 候选 DTO。公开函数固定为：

```text
建立概念名称
退出概念名称
按概念读取全部当前名称
按词条和词性读取当前概念候选
读取概念名称历史
重建概念名称反向索引
```

写前同截止验证概念、词条、语言、词性；词性须等于概念维度对应词性。名称 owner 只拥有关系类型和名称关系，不创建端点。同概念 + 语言首选唯一；同概念 / 词条 / 角色 / 语言当前唯一。候选查询先用索引取候选再回读全部端点和关系；零 / 一 / 多项均合法，不猜选。普通应用在概念服务后形成名称 owner / 服务。

## 4. 验证与声明

覆盖同概念多名、同词条多概念、同语言首选唯一、不同语言首选并存、错维度、退出不删除端点、索引清空重建和多候选不猜选。不得声明语境消歧、名称接受业务或旧语素入口已经清理。
