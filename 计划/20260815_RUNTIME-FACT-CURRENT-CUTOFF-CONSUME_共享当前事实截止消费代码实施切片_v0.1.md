## 1. 目标与完成条件

实现 `运行期事实版本服务::读取当前已发布共享事实截止`：经同一 `L2结构聚合服务`的存在 const getter 调用现有 `L2存在结构服务::读取当前事实代次()`，复核成功形状并绑定运行代次、事实范围版本后返回单一非零共享事实截止。

完成必须同时满足：

1. 只建立一个 BIZ 组合模块，不修改 DATA、L1、装配或线程代码。
2. 请求只含合同版本、运行代次和事实范围版本；DATA 调用无对象参数、无 owner、无幂等和无第二见证。
3. 只在 DATA 已读取、合同匹配、截止非零且变更代次为空时返回成功材料。
4. 所有非成功截止为空；无缓存、无自动重试、零 DATA 写。
5. 根工程与生产外专项通过；父级 G0/G1 和真实治理接线保持 `NOT_RUN`。

## 4. 实现合同

新模块固定声明：

```cpp
export module 海中鱼巣.领域.组合.运行期事实版本;
```

模块唯一导出详细设计第 4 节配置、请求、状态、成功材料、结果和服务类。服务保存 `const L2结构聚合服务&`和不可变值式配置，不缓存存在服务引用或截止。

入口固定顺序：请求准入 -> const getter -> `读取当前事实代次()` -> 合同 / 状态 / 截止 / 变更代次复核 -> 一次构造成功材料。请求拒绝必须零 DATA 调用；DATA 资源失败映射资源失败；其它非成功或坏形状映射内部不一致。

当前 DATA 入口不提供 fake seam。专项允许只为构造正式隔离 DATA 栈使用 L1 运行包、owner 交付和 L2 聚合，但生产模块仍禁止 import / 直达 L1 或 owner。为稳定覆盖坏 DATA 形状而需要抽象 provider 时不得在本计划临场扩展公开 ABI，具名退回设计。专项只动态覆盖真实入口能够产生的成功、请求拒绝、连续读取和并发读取；无法确定性注入的资源失败 / 私有坏形状保持 `NOT_RUN`，只静态复核生产映射，不得伪造 PASS。
