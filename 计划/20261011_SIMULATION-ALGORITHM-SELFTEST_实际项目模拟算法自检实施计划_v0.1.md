## 4. 冻结接口和调用合同

### 4.1 启动面

`启动模式`追加`数值模拟自检 = 3`。`解析并验证启动选项(int, char* const[]) noexcept`原签名不变；精确参数`--self-test-simulation`映射该模式。同参数重复返回`重复模式参数`，与`--headless`或`--runtime-context`任意顺序组合返回`模式组合冲突`，沿既有退出码2；未知参数仍拒绝。

`main(int, char*[])`原签名不变。在解析成功后、调用`运行海中鱼巣`之前判断模式，命中则直接`return 海中鱼巣::运行模拟学习算法自检();`，其它路径完全保留。入口不写测试正文、断言、输出或循环。不得让自检模式流入普通应用的默认分支。

### 4.2 自检面

唯一公开声明位于`业务/自检.模拟学习.h`：

```cpp
namespace 海中鱼巣 {
int 运行模拟学习算法自检() noexcept;
}
```

同名cpp先包含本头，再包含`模拟学习.算法.h`、`../启动.程序入口.h`、`../启动选项.数据.h`及所需标准库。仅该cpp可输出逐项PASS/FAIL与最终汇总。每次调用拥有独立局部细分器、样例、计数和断言材料，函数退出释放；没有全局测试状态、线程、节点、数据库或端口。

返回0严格表示全部必需检查通过且失败数为0；任一检查失败或意外异常返回1。每项运行实际条件检查，不使用发布配置可消除的`assert`作为判定。异常在自检最终边界转为失败输出和非零退出，不逃逸noexcept。输出使用ASCII标签也可，避免把控制台编码失败误判为算法错误。

自检私有驱动反复调用`推进()`并检查返回状态；每次前后callback计数差不得大于1。测试驱动允许固定足够大的步数保护（如100000步），超出只能记录该用例FAIL并结束，不可称算法完成，不得进入算法生产参数。自检用例只采用本计划明确的小范围输入，近I64两极用线性/常数，不穷举整个I64域。

诊断责任：参数解析向上送出既有结构化状态；main返回既有参数退出码或自检退出码；自检私有辅助向上送出布尔检查/异常，由`运行模拟学习算法自检`在自检控制台本地记录一次。无需启动生产日志服务，不改变既有生产诊断。

## 5. 必需运行矩阵

所有成功用例都检查：最终状态已完成；读回样例的输入唯一、输出符合独立期望；callback总数等于成功唯一输入数；新样例增量不重复；材料/进度数量相符；终态再次推进不调用callback且不重复返回增量。

| 用例 | 输入及期望 |
| --- | --- |
| 参数解析 | 无参数仍普通；单自检参数接受；重复自检/与另两模式双向组合拒绝；未知参数拒绝；直接调用解析器，不调用生产装配 |
| 尚未初始化 | 推进和读取保持尚未初始化，零callback |
| 单点与相邻点 | `[3,3]`恒等仅1样例/1区域；`[3,4]`恒等仅2样例/1区域 |
| 三点补足五点 | `[0,8]`的`x`和`2*x+1`分别5样例/1区域，精确取值0、2、4、6、8 |
| 奇数宽度 | `[0,3]`恒等4个不同输入，1区域，无空分割 |
| 非整比例偏差 | `[0,3]`整数`x/2`，全4点且细分，不能用截断比例吞掉偏差 |
| 二次曲线 | `[0,8]`的`x*x`全部9个整数样例、8个相邻单位区域；共享边界不重复求值 |
| 中点掩蔽偏差 | `[0,8]`的`x*(x-4)*(x-8)`首轮三点输出0，但四分位置非零；必须产生细分而非整域一个区域 |
| 多输入完整网格 | `[0,4]×[0,4]`的`x*y`取得25个唯一完整输入，1区域；不按全局仿射错误细分 |
| 多输出 | `[0,8]`输出`{x,x*x}`，第二分量触发细分，9样例/8区域，不平均抵消 |
| 两极安全 | `[MIN+1,MAX-1]`分别恒等/常数7，5唯一样例/1区域，端点输出保留、无有符号溢出；MIN/MAX自身端点拒绝 |
| 暂停续接 | 线性用例推进至至少一次callback后停止，只读进度/材料不得增计；同对象继续完成，唯一输入不重复 |
| 重复初始化 | 已有有效作业后非法请求初始化拒绝并保留旧进度/材料；合法重新初始化清空旧作业、初始化本身不求值 |
| 入口拒绝 | 输入组空、输出维数0、倒置区间、空callback、MIN/MAX端点均输入不合法且零callback |
| 求值非成功 | 分别返回输入不可求值/结果未知/求值失败：样例求值失败并原样返回失败状态；后续推进零重试 |
| 输出拒绝 | 长度不符映射输出维数不符；MIN或MAX输出映射输出包含无穷哨兵；后续推进零重试 |
| 异常 | callback抛普通异常映射求值抛异常，抛bad_alloc映射资源失败；后续零重试，不能伪称实际容器分配注入 |
| callback重入 | callback内两个读取允许；初始化/推进重入返回输入不合法而不污染外层作业，外层最终可完成 |

不得用算法自身私有判等函数计算测试期望，不把材料读取当作再次求值。成功覆盖证明有限样例而非全域数学证明。真实内存分配失败、进程恢复、共享世界隔离、学习线程及条件结果发布不在本叶验证范围，明确NOT_RUN。
