# WEB-CASE1-COLOR-TYPE 先天颜色词用实施计划

版本 v0.1，2026-11-27。施工、构建及发布由当前交互窗口在主工作区串行持有。源码基线 2d602fbeca062c8637a55710cb1d85c25126b748。

## 依据与目标

用户裁决「颜色是先天特征类型」。[7160 §10](../规范/7160_子规范_特征概念信息.md#10-先天特征概念初始化) 保留既有 RGB 根作为当前正式颜色类型，由正式语言名称关系提供「颜色」。[初始种子](../初始化材料/最小结构定义种子.txt) 已为同一根提供「红绿蓝颜色」。现行提供者把既有先天集合中的 RGB颜色与其当前完整定义核同，再校验种子精确来源、交给正式名称所有者写入并独立读回。三个分量是一个颜色值。白色是现有颜色子域，保持其不同 C 身份。

## 允许文件与施工

- [初始化.概念名称.cpp](../海中鱼巣/业务/初始化.概念名称.cpp) 的先天名称准备函数使用仅含「红绿蓝颜色」和「颜色」的精确 RGB 别名列表。保留标准符号绑定边界，按声明的主体和词面匹配各自发布项，为各项保存其准确范围与定义编号。一旦任一项缺正式来源沿原目标未覆盖路径退出。正式身份、分组、重入、写入失败和读回保持现有所有者合同，不改接口或通用匹配。
- [最小结构定义种子.txt](../初始化材料/最小结构定义种子.txt) 追加一条「RGB颜色 又称 颜色」。不改先天类型初始化、白色子域、适用域、词典专项、杯子类、水温或其它组生产文件。
- 专属公开验证记录 20261127_WEB-CASE1-COLOR-TYPE_先天颜色词用验证.md。验证资源为实际工程 Release x64 及同一交互窗口的隔离运行目录。按 AGENTS §7.1 新故障先报告。

## 创建侧核验与验收

源码已核对：概念特征类建立唯一既有 RGB 根；正式名称提供者的准备和发布通过稳定身份、完整定义和精确源项闭合，不依赖名称猜测。名称项与定义依据一一对应，正式发布和独立读回遍历各项。原 RGB 名称关系与新增项同根，继续区分白色子域 C；不同正式颜色类型若出现，不在本片合并。启动前确认当前 main 没有同路径活动所有者，水温计划尚不激活。

实际 Release x64 编译、记录输入及唯一进程。正常入口提交「测试杯甲是一个杯子。它的颜色是白色。」并独立读回其正式解释，核同源 E、颜色 FT 与白色子域身份；另验证 RGB颜色/红绿蓝颜色同根及白色不能充当该 FT。具备该句成文条件时从正式已保存结构生成并独立解析，核原语气、对象、FT、子域与准确来源。保留材料级和业务采用级证据；杯子类未完成、缺正式采用或反向回读则逐项保留，颜色词用通过也不计整组。没有观测，不产生精确 RGB/S。正常网页关闭，同 PID 自然退出码 0 后记录验证与后继最早缺口。
