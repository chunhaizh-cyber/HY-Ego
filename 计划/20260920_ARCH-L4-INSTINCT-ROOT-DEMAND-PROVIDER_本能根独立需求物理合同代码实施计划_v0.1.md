## 1. 目标、范围与完成边界

本计划建立`ARCH-L4`需求 owner 的阶段21专用根材料 provider：按两组固定初始化身份建立或读回安全 / 服务各自的根目标合同 T、独立根需求 D、根列表项 L 和唯一当前成员关系 M，并在同一非零事实截止读回完整根材料。它为后续8121阶段21提供根材料，不实现阶段21本身。

本计划完成条件：公开 provider 能在同一需求 owner 写集中幂等建立或恢复一组根材料，严格读回`T -> 实际F`、`D -> T`、`L -> D`闭包，且两个根互不交叉；完整结果携带非零同一截止与稳定身份；专属验证覆盖首次、精确重复、部分恢复、异义键、退出、当前性漂移、发布未知和内部不一致。

明确排除：特征类`按存在持有特征变更并返回实际F`的实现和调用、首值/状态/动态、8121运行锚点、普通应用启动接线、线程、任务、普通子需求、普通需求 ABI 迁移、旧方向二次特征记录的修补或复用。

## 2. 正式依据与已核对事实

- 8121 §2—§5：根 D 仅有根特征、根目标合同、父空、顺序0及根列表闭包；阶段21只消费实际 F，并以同一`Gfinal`读回。
- 5170 §3、§4、§6、§11：需求 owner 持有目标合同、需求、列表项和成员；双根不得使用普通需求的所属存在/目标宿主聚合键，且由阶段21专用入口发布。
- 6120 §2.1：安全、服务目标分别是`A == I64_MAX`、`V == I64_MAX`；双根目标、树与当前满足独立。
- 6130 §8、§11：两组固定业务幂等身份形成双根；服务根不得附带合同账户或维护语义。

## 3. 唯一 owner、物理模型与公开合同

### 3.1 owner 与物理位置

唯一事实 owner 是现有`需求类数据服务`所属的`ARCH-L4`需求结构 owner。根材料不得借用存在 owner、特征 owner、概念 owner、自我 owner或另建 registry。根专用 DTO、关系类型配置、公开根入口和其私有写集 / 读回辅助全部置于现有`海中鱼巣/领域/数据服务.需求类.h`的`需求类数据服务`中：该类已独占持有需求 owner 写端口，建立第二服务会复制或泄露该端口并破坏唯一 owner。根入口与普通需求入口保持不同强类型签名；禁止两个入口并存或让执行者临场改变物理位置。

根材料固定为需求 owner 所有的三个普通节点和三条需求 owner 关系：

```text
根目标合同 T --根目标实际特征--> 实际 F
独立根需求 D --根目标合同--> T
根列表项 L --当前根成员--> D
```

`D`不存在`所属存在`、`目标宿主`、方向定义、自我字段、自我关系或自我 owner；不存在父关系即父为空，根 DTO 固定返回顺序`0`而不写入顺序节点。`L`的业务幂等身份是根角色，不是普通聚合键；它只保存该根稳定列表身份和唯一当前成员 D，不吸收普通成员的来源、路径、权重、资格、预算或结算。`T`的语义由根角色和根特征类型唯一确定：安全为`A == I64_MAX`，服务为`V == I64_MAX`；实现不得以可变值、文本、浮点、方向二次特征、综合分数或服务账表达该目标。

### 3.2 DTO 与状态

新增强类型`本能根角色 { 安全, 服务 }`、`本能根初始化身份`、`本能根材料请求`、`本能根材料`和`本能根材料结果`。请求只含合同版本、期望当前事实截止、根角色、对应根实际 F、该角色固定业务幂等身份；不含自我、目标宿主、所属存在、首值、状态或动态。

成功结果只允许`已形成`、`已恢复`和`已读取`，并返回角色、T、D、L、成员关系、实际 F、父为空、顺序0与同一非零截止。非成功至少区分入口拒绝、实际F未找到/已退出/类型不匹配、幂等冲突、引用冲突、当前性漂移、材料未闭合、根材料已退出、已可能发布、资源失败和内部不一致；非成功不得返回可消费根材料。

`完整()`是无 I/O 的值式校验：四项身份有效、关系端点和角色一致、D无普通需求物理绑定、父空/顺序0、L当前成员唯一等于D、`T`只关联该实际F、截止非零。它不替代正式读回。

### 3.3 幂等、写集、恢复与读回

每个角色使用不同固定初始化身份；相同角色、相同完整请求只能重放并重新读回，身份相同但实际 F 或合同语义不同必须`幂等冲突`。安全与服务的 D/T/L/M 不得共享节点或关系。仅当该角色全部缺失时，以一个需求 owner 写集原子发布 T、D、L及三关系；任一部分已存在时必须先按原身份完整读回，并且只按同一原请求补齐该角色允许缺失的材料，禁止换键、另建第二根或使用普通需求入口。

提交返回未知时只以原完整请求和原幂等身份重放 / 读回收敛。任何预读、写后读或组合读的事实截止变化均返回`当前性漂移`且零新写。最终读回在同一非零`Gfinal`读取两个角色的 T、D、L、M和实际F；根边界、成员闭包、根间不交叉和实际F与请求匹配全部成立才成功。
