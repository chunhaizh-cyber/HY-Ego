## 1. 目标与完成条件

在实例特征领域新建唯一无对象状态的 `海中鱼巣.领域.服务.L1实例特征当前值集合读取`，实现自由函数 `从快照读取当前实际存在I64实例特征值集合`。函数消费 P24 完整槽结构、P25 完整定义详情、P23 登记定位请求和形成上游结果的同一 P17 快照，对每个槽形成唯一当前属性槽、I64 值、材料形状、来源节点和生命周期见证。

完成必须同时满足：

- 输出主体/槽集合与 P24 一一对应，无扫描、无夹带、无遗漏或部分成功；
- 合法空主体和零槽成功空组，P23调用0；
- 非空时 P23 纯值定位调用精确1次且不重取 P17；
- 同槽同目标属性类型的当前属性槽和值事实分别恰一且互相指向；
- I64 材料、来源、生命周期和 P25 值域完整；
- 不解释其它属性类型，不调用比较算法；
- 生产函数对象状态、锁、缓存、SQL、日志和 provider 调用均为0，模块依赖环为0。

## 3. 目标接口和物理位置

新数据头唯一拥有 P26 读取/排序规则、请求、稳定诊断、当前属性槽见证、I64 当前值见证、来源节点见证、完整项/主体组/集合事实与结果。

新模块 `海中鱼巣.领域.服务.L1实例特征当前值集合读取` 固定 `export import 海中鱼巣.领域.服务.L1特征定义集合读取`、私有 import L1 纯值合同；合法调用方自行 import P17/L1 纯值合同，P26 不重新导出 L1 服务。模块导出：

```cpp
当前实际存在I64实例特征值集合结果
从快照读取当前实际存在I64实例特征值集合(
    const 当前实际存在I64实例特征值集合读取请求& 请求,
    const L1完整快照& 快照);
```

新模块用于避免 P25 已依赖实例特征模块造成的反向模块环；现有实例特征和 P25 模块不得反向 import P26。函数诊断责任为“向上送出”，不本地记录日志。

## 6. 状态与失败收口

- 自身或上游版本错、上游非完整：入口拒绝；
- 合法空主体/零槽：已读取完整空组；
- P24/P25/P17 仅截止不同：事实代次漂移；
- 非空 P23 六类非成功保持同名；
- `未找到` 只用于 P23 登记四节点全部确定未命中；上游成功后槽、值或来源缺失为内部不一致；
- 上游坏成功、范围/排序矛盾、槽/属性/值/材料/来源/生命周期/值域矛盾：内部不一致和稳定诊断；
- 分配失败：资源失败；其它异常：内部不一致。

所有非成功事实为空，只有内部不一致允许诊断。不得重取快照、扫描补造、读取缓存/SQL/历史、返回部分槽或用调用方回显补齐。
