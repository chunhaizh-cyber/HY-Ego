原位扩展唯一 `L1实际存在服务`，消费 P19 完整成员范围、P20 非阻塞登记定位和 P17 一次非阻塞完整快照，对指定根全部当前直接成员形成同一截止、稳定排序、一一对应的实际存在资格集合。

- 输入只携带版本和完整 P19 世界结构事实，无独立成员候选字段；
- P20 返回并释放存在服务锁后才调用 P17，许可竞争立即拒绝；

- 每个成员的节点、资格槽、资格值、类型、来源、材料和生命周期完整互证；
- 任一缺失、重复或矛盾返回空事实和确定诊断，不返回部分集合；
- 合法空成员在登记节点当前且截止一致时成功空组；
- 不解释 L1 场景关系，不读取特征、状态、动态或历史。

唯一实现依据为同名 v0.1 详细设计和函数流程图，以及 1140、4190、4015、4030、4200 §3、§5—§6、P7、P17、P19、P20冻结合同。

- 请求无效：`入口拒绝`；
- P19坏成功、重复成员：`内部不一致`和稳定诊断；

- P20/P17竞争：`许可拒绝`；

- P7/P17/P19/P20实际接口无法机械匹配冻结合同；
