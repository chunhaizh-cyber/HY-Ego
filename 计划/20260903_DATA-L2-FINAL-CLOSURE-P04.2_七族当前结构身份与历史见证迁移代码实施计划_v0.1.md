## 4. 冻结的 ABI 与实现位置

每份数据头删除对应旧 `L2{族}身份来源读取请求 / 结果`及其有效性和成功谓词，并定义详细设计第 2.2 节规定的具名历史 request/result。当前确认不新增 DTO、wrapper、payload 或 overload。

六个既有服务模块分别在其公开服务类中定义下列 exact const 函数，声明和定义均在本模块：

```cpp
L2结构结果头 确认当前{族}结构身份(
    const L2结构请求头& 请求头,
    L2{族}身份 身份) const;

L2{族}身份来源历史见证读取结果 读取{族}身份来源历史见证(
    const L2{族}身份来源历史见证读取请求& 请求) const;
```

`L2特征结构服务`分别拥有定义、实例两组函数。服务内部的旧当前/历史投影 helper 必须改成不暴露旧 request/result 名称的私有实现：当前 helper 只产出或校验结果头，历史 helper 只产出新具名历史结果。既有完整创建、完整读取、场景树和其它既有完整结果可在同一服务内从 owner-aware 投影形成既有完整见证，但不得把它变成新的公开当前身份 DTO。

公共失败顺序和结果形状不由执行者重裁决，严格逐条实现详细设计第 4 节及 4230 第 2.4 节：请求形状、守卫、当前存在、当前退出、历史存在、身份可接受性、来源闭包、历史退出见证。资源不可用映射`资源失败`，其它异常、L1 结果形状/合同、provider或装配矛盾映射`内部不一致`；守卫前截止/H为零，守卫后回显已确认的 G0 或 H，所有非成功空见证、空变更、零写入。
