## 1. 目标与完成条件

新建唯一无对象状态的 `海中鱼巣.领域.服务.L1完整世界快照组合`，实现自由函数 `组合同代次完整世界事实快照`。函数只消费调用方的一份 P17 `L1完整快照`、P19/P21/P24/P25/P26/P27 同轮纯值成功事实和 P19 末次代次结果，形成 4200 §5.2 的完整世界事实快照。

完成必须同时满足：

- 根、场景、父子、成员、存在资格、当前归属、实例槽、定义、当前值、材料、来源、状态和动态完整闭合；
- G0、P17、全部领域截止和 G1 为同一非零事实代次；
- 场景、关系、存在、宿主特征、状态和动态稳定有序；
- 合法正式根的零成员/零特征/零状态/零动态成功，空根或空场景组非成功；
- 任一矛盾零部分快照，内部不一致才携带稳定缺项；
- 生产函数 provider、锁、快照重取、缓存、SQL、历史、审计、重试和写入调用均为0。

本叶不实现 G0—领域读取—G1 的生产协调、许可拒绝上游短路、一次完整漂移重试、存在/场景子快照、统一世界门面、恢复装配、运行期接线或 STEP-5。

## 3. 目标接口与物理位置

在 `L1完整世界快照.数据.h` 定义详细设计冻结的：

- `世界树业务状态` 稳定值1—11；
- 四个版本常量；
- `完整世界快照组合请求`；
- 十一值 `完整世界快照缺项种类` 与稳定诊断；
- 场景、存在、实例特征、宿主特征、完整世界快照和组合结果 DTO。

在 `服务.L1完整世界快照组合.ixx` 导出唯一函数：

```cpp
完整世界快照组合结果 组合同代次完整世界事实快照(
    const 完整世界快照组合请求& 请求,
    const L1完整快照& 快照,
    const 当前世界结构事实& 世界结构,
    const 当前实际存在资格集合事实& 实际存在,
    const 当前实际存在实例特征槽集合事实& 实例槽,
    const 实例槽引用I64特征定义集合事实& 特征定义,
    const 当前实际存在I64实例特征值集合事实& 当前特征值,
    const 当前世界状态动态集合事实& 状态动态,
    const 当前世界事实代次结果& 末次世界事实代次);
```

模块只 import 上游公开纯值合同，不保存引用、不构造 provider、不调用服务对象、不取得锁、不重导出 L1 服务。旧 P1C-Q/QF 不参与实现；未来生产协调器和统一世界门面只能消费本合同。

## 6. 失败、异常与协调边界

- 请求合同、规则或根形状错：入口拒绝，空快照；
- G1许可拒绝：许可拒绝，立即返回；
- 上游非成功：后继协调者短路，本函数调用0；
- 全部成功但截止不一致：版本漂移，空快照，缺项空；
- 上游声称完整但范围、端点、定义、值或排序矛盾：内部不一致，稳定诊断，零部分快照；
- 合法正式根零成员/零特征/零状态/零动态：已读取、同次非零截止、完整=true；
- 分配失败：资源失败；其它异常：内部不一致；
- 函数不等待、不sleep、不retry、不取锁、不读缓存/SQL/历史/审计、不写事实。

4200 的第一次漂移后完整重试由后继协调叶实现。本函数每次只处理一轮不可变材料，不保存上一轮结果，不允许新旧轮次拼接。
