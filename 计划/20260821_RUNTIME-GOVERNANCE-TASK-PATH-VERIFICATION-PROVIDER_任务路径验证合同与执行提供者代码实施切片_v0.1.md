## 1. 当前缺口与停止条件

当前 `L2完整路径材料::验证合同` 只是普通 `稳定编码`，且任务筹办把方法适用范围来源编码写入该字段。仓库没有按该合同读取并执行验证的生产入口，也没有合同算法 / 材料的唯一 owner。因此本计划在设计上列出目标 ABI，但不能向执行侧宣称“可机械施工”。

只有以下提供者事实在正式仓库冻结后，计划才可重新审查并可能转为 `可执行`：

1. `L2路径验证合同身份`、内容版本、算法身份 / 版本、材料组身份 / 版本的强类型及权威读取来源；
2. 唯一执行 owner 和公开取得方式；
3. `已通过` / `未通过` / `不可裁决` 的算法输入、输出和非成功规则；
4. 普通应用同实例装配，不产生第二 provider 或静态全局；
5. 目标文件所有权和工程接线不与异主 WIP 冲突。

## 2. 分层 ABI（执行前不得自行改名或补语义）

DATA-L2 结构类型位于 `海中鱼巣/领域/L2任务结构.数据.h`：

- `L2路径验证合同身份`
- `L2路径验证合同版本`
- `L2路径验证算法身份`
- `L2路径验证算法版本`
- `L2路径验证材料组身份`
- `L2路径验证材料组版本`
- `L2路径验证合同引用`

DATA-L2 公开入口只能继续提供结构 CRUD / 读回：

```cpp
L2任务方法路径读取结果 读取任务方法路径(
    L2任务方法路径读取请求 请求) const noexcept;
```

该入口只能返回 `L2完整路径材料` 及其中的 `L2路径验证合同引用`，不得返回业务“已通过 / 未通过”判断。

DATA 外业务 DTO 位于 `海中鱼巣/领域/运行期只读查询.数据.h`：

- `任务路径验证业务请求`
- `任务路径验证业务状态`
- `任务路径验证业务结果`

唯一业务 provider 复用 `海中鱼巣/领域/组合.运行期只读查询.ixx` 的 `运行期只读查询组合器`，目标入口为：

```cpp
任务路径验证业务结果 验证当前选中路径(
    const 任务路径验证业务请求& 请求) const noexcept;
```

该入口经 DATA-L2 正式读回后执行具名算法；它不取得 DATA owner、不写路径或任务、不创建验证结果节点。

## 4. 目标读取与状态矩阵

每次请求必须在一个共同事实截止下完成：

| 输入 | 来源 | 必须核对 |
| --- | --- | --- |
| 任务当前选中路径 | `L2任务结构服务::读取当前选中路径` | 任务归属、路径身份唯一 |
| 路径材料 | `L2任务结构服务::读取任务方法路径` | 强类型合同、合同版本、路径任务、筹办轮次 |
| 当前实例方法 | `读取实例方法` / 按任务当前实例方法 | 路径引用、执行轮次、方法版本 |
| 正式任务实际结果 | `读取任务实际结果` / 按任务与执行轮次读取 | 任务、实例方法、执行轮次、结果身份、来源版本 |
| 验证合同与材料 | DATA-L2 正式结构读取，再由 BIZ provider 消费 | 合同 / 算法 / 材料身份与版本 |

状态映射：

- 合同与材料完整、共同截止一致、具名算法返回通过 → `已通过` + 证据。
- 具名算法返回未通过 → `未通过`，零证据。
- 合同 / 算法 / 材料缺失或算法无法判断 → `合同未形成` 或 `不可裁决`，零证据。
- 请求非法 → `入口拒绝`；权限不足 → `许可拒绝`；引用不存在 → `未找到`。
- 已发布读取观察到非预期截止 → `事实代次漂移`，不得重试或重分类。
- 资源异常 / 结构矛盾 → `资源失败` / `内部不一致`，零证据。

不得把目标状态比较结果、日志 PASS、方法返回值或线程退出作为上述“已通过”。

## 5. 事务、幂等与生命周期边界

- 本计划为纯读验证；不形成新的持久验证结果节点。
- 相同请求在相同共同截止下必须返回相同值式结果；不保存请求或缓存成功。
- 不成功不产生任何路径、任务、实例方法或实际结果写入。
- 任务生命周期迁移必须是后继计划的独立原子写入口；本计划不调用 `退出任务`，不增加状态字段。
