## 3. DTO、字段和实现顺序

### 3.1 核心数据头与合同

在 `核心/L1事实基座.数据.h` 增加 `L1领域结果字段计划`、`L1领域结果见证计划`、`L1领域结果见证字段`、`L1领域结果见证段`、`L1领域结果见证记录`，并在 `L1领域意图凭证` 增加 `领域结果计划摘要` 字段：无结果计划时全零，E01 必须等于计划摘要。v1 只支持节点，字段 C++ 类型固定为 `节点种类` + `std::optional<值表示种类>`；optional 序列化为 U8 0/1，值存在时紧跟 U8 underlying。将计划放入 `L1写集请求`，将结果段放入 `L1写入结果`、`L1幂等账记录`、`L1审计记录`，将记录组放入 `L1恢复材料`。所有新数组按字段标签/幂等键升序唯一。

E01 计划固定 `0x15000301U/合同1/规则1/变体1`，两个字段固定为：标签 `0x00000001`→本地键1→`节点种类::普通`+`std::nullopt`；标签 `0x00000002`→本地键2→`节点种类::属性类型`+`std::optional{值表示种类::I64}`。计划不带稳定编码。

在 `核心/合同.L1事实基座.ixx` 扩展 `L1幂等首次结果副本` 和 `映射L1幂等探测`，同义返回首次 RW 原值；不得按当前映射重新计算。保持请求意图摘要、执行证据摘要和现有 L1 v2 合同的分账。

### 3.2 唯一编码器

在 `核心/L1事实基座.数据.h` 的现有编码命名空间中增加两个唯一函数：

```text
形成L1领域结果计划摘要(计划)：原始 ASCII "HZY-L1-RP"，随后按固定顺序写大端 U32/U64/U8；字段为标签、U32本地键、U8节点种类 underlying、U8 optional标记，标记1时紧跟 U8 值表示种类 underlying → SHA-256/32字节
形成L1领域结果见证摘要(结果)：原始 ASCII "HZY-L1-RW"，随后按固定顺序写大端 U32/U64/U8；再写发布代次、幂等键和每字段稳定编码 → SHA-256/32字节
```

禁止复用领域字符串拼接、JSON、指针、地址、unordered 容器顺序、普通快照、SQL 或返回对象地址。G6 意图编码只写 RP 摘要；RW 只在映射产生后形成。

### 3.3 E01 与核心事务

1. 在 `服务.L1实际存在.ixx` 形成 E01 RP 计划并把其摘要纳入 G6 意图凭证；构造写集本地键 1/2 和计划，调用一次既有 `0x15000301U`。
2. 在 `服务.L1事实基座.ixx` 的 provider 前阶段验证计划、版本、标签、变体、凭证中的 `领域结果计划摘要` 和 G6 摘要绑定；锁前失败固定返回 `入口拒绝`。
3. 在 `仓库.L1事实基座.ixx` 的唯一候选锁内分配映射，严格解析两个本地键的 `节点种类` 与 optional I64；锁内映射/类型/摘要错误固定返回 `入口拒绝`，候选丢弃且不交换。通过后形成 RW、通用读回、领域结果见证摘要和确定性结果摘要。
4. 仓库 `状态` 新增 `std::unordered_map<std::uint64_t, L1领域结果见证记录> 领域结果见证状态组`。成功候选把同一不可变 `L1领域结果见证记录` 分别写入幂等账、成功审计和该状态组，三者在一次 `std::swap` 中原子可见；交换前失败三者均不进入正式状态。新增精确函数 `L1恢复材料 导出恢复材料() const`，在共享锁内从三份状态副本分别复制并按幂等键/字段标签排序为 `L1恢复材料.领域结果见证记录组`，不从幂等账派生第三副本。
5. 交换发布后执行既有权威读回。RW 或通用读回不一致固定返回 `内部不一致` 并隔离；保留已交换代次和候选中已形成的首次账/成功审计，追加失败见证/隔离审计，不改写原幂等记录。
6. 领域从 `L1写入结果.领域结果见证` 按标签取得两个稳定编码，形成现有 `实际存在结构登记`；删除/禁止独立 `查找映射` 作为结果事实来源。

### 3.4 恢复

在既有 L1 仓库恢复材料导出/建立候选路径中，仓库 `状态` 的结果见证状态组是第三权威副本；导出函数在同一共享锁内分别复制幂等账、成功审计和该状态组，按幂等键和字段标签排序生成恢复结果段。恢复候选逐一与三份输入及通用读回、两个摘要比较。缺字段、错版本、错误 P-E、重复成功见证、恢复结果段与任一状态副本不等均返回 `材料不完整` 或 `内部不一致`，候选不存在且当前状态不变。不得从 `登记_`、当前快照、索引、SQL 或领域返回缓存补造 P-E。

## 4. 失败收口和验证矩阵

| 场景 | 预期 | 调用/事实门禁 |
| --- | --- | --- |
| E01 首次未找到 | RP 合法、P-L1-S 1/1、P-E 0/0；一次 0x15000301；RW 1/1 | 同一候选账/审计/恢复段/返回结果四路等值 |
| E01 同义重试 | 读取首次 RW/读回 | provider/提交 0/0、无新映射 |
| E01 异义/计划变化 | 幂等冲突 | 零业务载荷、只保留冲突审计 |
| 计划缺项/错标签/未知本地键 | 入口拒绝 | 零候选、零事实 |
| 锁内映射缺失/重复/类型错误 | 固定入口拒绝 | 候选不交换、不写正式成功账/审计 |
| 交换前摘要错误 | 固定入口拒绝 | 候选不交换、不写正式成功账/审计 |
| 发布后读回失败 | 隔离 | 失败见证；不二次提交 |
| 恢复三副本/导出段缺字段或错摘要 | 材料不完整 | 候选不存在、当前状态零变化 |
| 持久结果见证未知 | 持久化未知 | 运行期代次权威，普通入口/启动恢复隔离 |
