## 2. 复合 DTO

协议模块必须按详细设计 v0.3 第 10.1 节逐项定义 `安全五组权限值`、`安全四门释放倍率`、`安全五组权限状态值`、`安全四门限制层来源`、`安全因果路径快照`、`安全权限材料缺口`、`安全输入版本快照` 和 `安全任务来源权限`。

下列字段不得再用自然语言或匿名容器：

- 主路径与并列路径使用 `安全因果路径快照`。
- 主动结算的事件 / 复发 / 因素变化组分别使用对应具名快照 vector。
- 收到 / 保留权限、四门倍率、限制层、权限状态、缺口、受影响组和来源版本使用详细设计冻结的 array / vector / DTO。
- 任务全部来源权限使用 `std::vector<安全任务来源权限>`；候选、零权限和缺口任务组使用 `std::vector<安全任务执行候选快照>`。
- 有序任务结果使用 `std::vector<任务权限载荷>`。
- 外部事实参与载荷只含拥有的 `unique_ptr` 参与者组、候选代次和 `安全输入版本快照`；删除无正式类型所有者的候选引用字段。
