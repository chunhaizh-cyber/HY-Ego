# INTERNAL-GOVERNANCE-WORLD 内部治理世界首叶实施计划

日期：2026-10-14

版本：v0.1

代码核对基线：`3059dba1309d41fed68133e702d2edc9d1ae316a`。

计划状态以顶层登记的计划索引为准；本文件不自行取得共享装配／工程写入权。

## 1. 目标及合同

实现 `新_内部治理世界类` 独立根，复用共享概念和各对象 owner；以已有 `标记任务已结算()` 为真实消费者，完成 Vt 状态 S/D、唯一内部动作、治理场景组织、实际因果交付和世界限定查询。

完整合同见 [详细设计](../规范/详细设计/20261014_INTERNAL-GOVERNANCE-WORLD_内部治理世界首叶详细设计_v0.1.md)。用户本轮对治理世界的明确裁决取代该具名范围内旧“Vt 不入任何世界／治理状态不形成 S/D”的限制；不改变 task 状态写权、唯一 self、服务值普通动作或其它世界。

## 2. 开工 S0

1. 读取本计划精确版本、详细设计、当前接口、知识库当前性和用户具名裁决。
2. 确认 task、scene、dynamic、causal、服务值结算、装配及工程文件无其它活动 owner；取得真实项目编译资源。
3. 当前初始化工作已发布不自动代表消息释放；顶层完成共享文件交接后方可开工。无关 dirty 不冻结本叶。
4. 核对场景根仍为构造参数、task 已结算仍唯一生产调用者；有会改变合同的漂移先停受影响范围并回报。

## 3. 允许／禁止范围

允许文件精确采用详细设计第 9 节清单，以及专属 `验证记录/20261014_INTERNAL-GOVERNANCE-WORLD_施工与编译记录_v0.1.md`。新类文件 `海中鱼巣/业务/内部治理.世界.h/.cpp` 登记到现有根工程。

禁止规范／规则／其它计划／知识聚合索引写入；禁止材料内容域、完整服务包、语言初始化、跨 Vt 归纳、其它任务状态批量迁移、跨世界复制及临时测试工程。

## 4. 实施次序

1. 中立语义投影、task Vt 专属概念持有和 scene 治理引用结构；普通入口的 Vt 拒绝放在重复早退前，删除空场景写前纳入治理引用非空检查。
2. 内部世界根与场景、已有内部动作／原子 D 组合；修复 `关联动作结果()` 的 Vt 目标分派。
3. 迁移 task 已结算新建及重放、服务值结算确认重放；普通服务值证据仍留现实世界。
4. 同批补动作证据 provider、因果治理参与者、范围枚举、反查 Vt 键和显式发生交付。
5. 普通应用真实构造、注册、停止顺序及工程登记；现实世界四个已知编码查询入口拒绝治理组织材料，结算工程报告复用终止链；不得以零行为骨架声称接通。
6. 静态核对所有新接口生产调用、跨根拒绝、引用保护、时序和无虚构事实；完成后统一实际项目编译链接。

同 owner／ABI／生产文件上的接口与消费者在本叶一起交付，不拆成字段提供者和空消费者。工程错误在本范围修复；关键语义漂移具名回报。

## 6. 失败、交付与知识变更

动作前业务不具备零动作；工程异常日志、弹窗、终止。动作后保留事实、不回滚状态、不伪补时间、不重做动作。重放只读已有完整治理链；旧或部分内部动作不得靠重放补造前状态。

施工记录必须写新增／变更函数完整签名、直接调用边、唯一 owner、锁及引用寿命变化，以及知识条目待回写清单。完成报告分别说明代码、编译、未运行测试、提交／推送和业务证据边界。

首叶可以没有已形成 Q：不同 Vt 各一次结算不足以满足现有具体 Q 分组。本叶不得因此伪造重复发生，也不声称跨 Vt 因果或全本能方法链已闭合。
