# INSTINCT-STAGE3-HARD-DENIAL-RULE-UNIVERSE 任务现实执行硬否决规则宇宙代码实施计划 v0.2

日期：2026-08-31

计划身份：`INSTINCT-STAGE3-HARD-DENIAL-RULE-UNIVERSE`

## 1. 目标与完成条件

按同名详细设计 v0.1 及其 v0.2 前置 ABI 修订，实现唯一版本化硬否决规则宇宙、Gnow 完整读回和强类型 hard-veto 消费。

完成必须同时满足：

1. 方法 / 任务 owner 数据头发布最小稳定动作冻结 ABI，安全目录不建立第二 DTO；
2. 首次版本 1 和后继连续版本在一个安全 owner 写集中原子发布，旧宇宙 / 规则退出且历史可读；
3. 同语义多来源同义归一、异义拒绝，当前成员索引是唯一完整集合权威；
4. 读取只对现实改变动作互证单一共同作用场景、self 和直接作用主体成员；
5. 覆盖见证逐项证明版本、生命周期、self、场景和动作范围；
6. hard-veto 对零现实改变返回不适用，对完整空 / 非空适用组分别返回未命中 / 命中，非完整集合 fail-closed；
7. 当前 `0..INT64_MAX`、`L=2767011611056432742`、`H=7378697629483820645`、安全根定义版本 1 和主动安全结算规则版本 1 零改。

本计划不实现方法动作 v2 服务、任务冻结 producer、FRESH、最终复核、任务线程、普通应用或真实规则发布者。

## 4. 实施步骤

1. 在方法数据头增加唯一 `L2方法动作作用范围` 枚举；在任务数据头增加三类身份、同型别名和 `任务冻结动作项`；不加入持久键或服务入口。
2. 重建安全规则数据头和服务，使用固定 owner / 登记身份及 `0x0307'2001..200E`；`200F..201F` 保留。
3. 实现规则输入规范化、同语义来源归一、当前宇宙闭包、首次 / 连续版本写集、旧闭包退出、幂等重放和正式读回。
4. 实现 Gnow 全集读取：只对现实改变动作互证共同场景、场景成员、self、直接作用主体和规则适用性。
5. 实现 hard-veto v2 纯消费者；非完整全集不得降级为空集。
6. 建立专项、外部 ABI consumer和持久恢复 consumer，不依赖其它未发布 SELF 模块。
7. 形成施工 / 验证记录与函数级知识变更清单。

## 5. 失败收口

沿用 v0.1 的发布 / 读取 / hard-veto 状态矩阵。额外固定：坏枚举、零顺序、坏动作身份 / 键、零作用主体、坏材料或现实改变缺共同场景为入口拒绝或场景范围不闭合；安全模块不得从方法 v1 或测试常量补齐缺项。
