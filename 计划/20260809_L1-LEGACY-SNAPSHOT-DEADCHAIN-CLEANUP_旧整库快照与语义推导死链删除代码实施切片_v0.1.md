## 3. 白名单与禁止范围

允许修改、删除和新增文件精确采用同名详细设计第 4 节。不得修改启动、运行期上下文、生产配置、其它领域结构服务、规范、流程图、详细设计、计划或计划索引。

工程与 filters 中双轴草案 WIP 必须原样保留且不得进入本计划提交；只暂存本计划五个删除文件对应的工程行。

## 4. 实施步骤

1. 删除零消费者的后继状态规格、状态动态原子发布、方法登记根快照解释五文件及工程登记。
2. 删除 `L1状态` 中相邻前状态选择和后继状态规格形成，删除 `L1动态` 中迁移动能规格 / 读取，删除特征比较中的无消费者业务比较；同步删除专属 DTO、import 和 helper。
3. 删除 L1 服务旧精确读取与完整快照公开面、旧请求和完整快照 DTO，删除仓库快照构造 / 排序；保留中性公开面及内部必要精确读取。
4. 扫描所有目标身份、函数、类型和工程引用归零，确认中性提交、当前 / 历史 / 关系条件 / 一致当前投影仍存在。
5. 完成两配置构建、模块扫描、生产启动和验证记录。

发现计划外真实调用者时只停止对应对象删除并具名返回，不建立兼容壳，不把旧语义改写成新的中性读取函数。
