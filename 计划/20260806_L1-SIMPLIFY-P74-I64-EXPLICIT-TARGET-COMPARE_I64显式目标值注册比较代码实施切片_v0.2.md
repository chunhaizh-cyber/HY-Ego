## 4. 机器合同与失败收口

- P74 公开合同版本、规则版本和所有既有 DTO 字段顺序不变；P17 合同版本由 P17
  自身冻结，P74 只复用，不复制内部实现。
- 正常比较：P17 完整快照调用=1，P17 独立代次调用=0，P74 阻塞快照调用=0。
- 合同/请求非法：入口拒绝，P17调用=0；P17 许可竞争：P74 `许可拒绝`、原因
  无、空载荷；P17 资源失败：资源失败；隔离、损坏、其它坏成功：内部不一致；
  代次不等：版本漂移/输入版本失效。
- 左值固定当前事实、右值固定目标状态，排序为 `compare(左,右)`，差异为 `右-左`；
  不返回满足 bool，不写需求/满足/路径/任务/装配事实。
- 不自建第二快照、第二解释者、缓存、账、稳定编码器、锁外权威路由或 P17 旁路。

任何阻塞等待、隐式重试、第二读取、P17 内部锁/仓库外泄或白名单外修改均须具名
退回，不得以测试夹具或文档替代机器合同。
