## 3. 机械施工步骤

1. 保持 v0.2 的 DTO、五个公开函数、合法 L1 登记结构、八条节点目标关系和配置 I64 组材料互证。
2. `比较特征` 单次读取完整快照，确认右输入稳定编码等于合同 `上界值`，来源、属性类型、创建代次和预计值与同一快照一致。
3. 写前确认左右值均位于 P2 闭区间；不满足时返回入口拒绝/值域不允许，零比较载荷。
4. 实现两个可达成功分支：左值小于上界返回 `-1/当前低于目标`；左值等于上界返回 `0/当前达到目标`。
5. 保留左值大于上界的防御判断，固定返回入口拒绝/值域不允许；不得通过越界写集或伪造快照形成成功 `1/当前高于目标`。
6. 沿用 v0.2 的差异可表示性、结果位、异常、幂等、并发、工程和静态禁用项步骤。

## 4. 事务、失败收口与依赖

比较全程零 L1 写入。注册/读回失败沿用 v0.2 映射；目标身份错配、目标来源/属性/代次错配返回输入版本失效或内部不一致；越界返回值域不允许。若执行需要引入独立目标值提供者、修改 P2/P3/P4 值域或删除防御分支，立即退回设计，不得扩大白名单。

## 5. 验证合同

除 v0.2 的结构、登记、读回、幂等、并发、单次快照和静态门禁外，专项必须通过：

- 合法当前值低于上界：`-1/当前低于目标` 成功；
- 合法当前值等于上界：`0/当前达到目标` 成功；
- 高于上界的构造输入只验证入口拒绝/值域不允许和空比较载荷，不得宣称成功；
- 目标身份不是合同上界、目标来源/属性/代次错配均拒绝；
- P4 合法换代后仍按上述两种可达成功分支验证；
- `左>右` 源码防御分支存在，但不计入成功三态闭合。

验证仍不包含独立目标值注册、生产接线、恢复、STEP-3、P7+ 或集成验收。
