## 1. 目标与完成条件

实现一个真实事件日志支持线程：独立有界 MPSC / 单消费者 FIFO 接收强类型人读摘要，线程入口对每个已移出摘要最多调用一次现行事件日志出口，并以 SUPPORT 最终候选生命周期形成唯一移动租约。

完成必须同时满足：

1. 只新增一个稳定数据头和一个真实模块；旧 `事件日志线程.ixx`、旧运行消息协议 / 队列不恢复、不复用。
2. `启动事件日志线程` 固定组合 SUPPORT 创建、内部进入等待、失败安全回收；成功只返回一份不可复制、只可移动构造的 EVENT 租约。
3. 租约唯一拥有队列、生产写入适配器、入口和 SUPPORT 候选租约，并公开提交、停收截止、位置读取 / 等待、未取出快照和 rvalue 显式停止连接。
4. 日志摘要不承载机器事实；写入 false、队列满和支持降级不改变业务结果，不参与线程继续布尔，不触发重试或回队。
5. stop 后零新取出；已移出项最多完成一次；未移出项在后继接管前可形成有界值式快照。
6. 根工程双配置、生产外专项双配置和静态门禁通过；无法确定性注入的真实资源失败保持 `NOT_RUN`。

## 4. 物理实现合同

### 4.1 数据头

新建 `海中鱼巣/线程/事件日志线程.数据.h`，唯一声明详细设计第 3 节常量、摘要、状态、请求、位置、排队项和快照值类型。传统 include 时自带标准头与 `线程生命周期.数据.h`；模块定义 `EVENT_LOG_THREAD_NO_INCLUDES` 时只展开实体正文。包含移动租约或 SUPPORT 见证的组合结果留在真实模块唯一声明。无独立实现，所以不建同名 `.cpp`。

摘要固定为受控 `std::wstring` 值，并携带必须等于租约运行代次的非零运行代次和非零摘要身份；不得使用 `wstring_view`、裸指针或调用方容器引用跨线程。摘要身份只作本运行代次旁路定位，队列不去重，不得解释为全生命周期幂等、恰好一次、恢复资格或可靠投递；不得增加“已确认机器事实”或业务成功字段。

### 4.2 真实模块

新建 `海中鱼巣/线程/运行.事件日志线程.ixx`：

```cpp
export module 海中鱼巣.线程.运行.事件日志线程;
export import 海中鱼巣.线程.候选.支持线程;
```

模块在全局模块片段 include 所需标准库和 `../核心/日志系统.h`，在 module purview 内唯一导出数据头正文、`事件日志线程租约`、`事件日志线程启动结果` 与 `启动事件日志线程`。不得把 `.ixx` 作为头 include，不建立分区、`.cpp`、`.inl` 或第二事件写入模块。

模块私有唯一拥有：事件状态、生产写入适配器和 `支持线程入口端口` 实现。适配器格式化受控字段后机械调用一次 `记录事件日志(摘要.所属模块, 摘要.入口或操作, 内容)`，只返回已写入 / 未写入；禁止修改日志系统头、解析日志结果或用其它日志类别记录本次失败。

### 4.3 租约与公开成员

按详细设计第 4 节精确实现：

```cpp
事件日志提交结果 提交(事件日志摘要 摘要) noexcept;
事件日志停止接收结果 停止接收并取得截止() noexcept;
事件日志处理位置 读取处理位置() const noexcept;
事件日志完成等待结果 等待完成到截止(
    const 事件日志完成等待请求& 请求) const noexcept;
事件日志未取出快照结果 冻结并读取未取出快照(
    const 事件日志未取出快照请求& 请求) noexcept;
事件日志线程停止连接结果 停止并连接(
    const 事件日志线程停止连接请求& 请求) && noexcept;
```

租约只允许移动构造，移动赋值 / 复制全部删除。成员按“状态 -> 适配器 -> 入口 -> 析构回收请求 -> SUPPORT 租约”声明。正常调用方把租约转为 rvalue 调用 `停止并连接`：先复核原状态已经停收且“完成位置到同一截止”或“同截止未取出快照已成功读取”；若原状态未停收则函数自身锁存停收但记住前置未闭合；随后移动唯一 SUPPORT 租约执行正式回收，返回 EVENT 结构化状态、最终 SUPPORT 见证和最终位置，本对象变空。未停收、或未完成且无成功快照时仍必须 stop / join，但返回 `前置未闭合但已安全连接`；请求无效使用内部已存合法 fallback 安全连接并返回 `请求拒绝但已安全连接`。重复 / 移动源调用返回 `租约已消费`。析构只作保守 fallback，先锁存停收、再安全连接并销毁借用对象，但不冒充正式收口结果；逆序成员析构作最后安全网。

### 4.4 队列、并发和停止

使用一个 mutex、一个 condition_variable 和一个有界 deque；所有生产者在同一短锁线性化接受位置，单消费者只取队首。满时拒绝新项，零驱逐、零优先级、零停止哨兵。锁内不得调用日志、SUPPORT、8110、DATA、文件或回调。

入口在第一次条件等待前注册覆盖全部等待期的 `std::stop_callback`；回调只对同一 condition_variable `notify_all()`，不取锁、不调用任何端口或日志。等待谓词每次在锁内重新检查 stop、取出冻结、队列非空和内部故障，确保空队列上的 SUPPORT `request_stop()` 能确定唤醒入口并完成 join，禁止轮询 sleep。

完成位置表示唯一写入尝试已经返回，不表示写入成功。适配器 false / 抛出均增加饱和失败计数、推进完成位置、零重试、零回队、零业务结果变化。

停收在线性化点锁存最后接受位置；后继等待只接受该截止。冻结快照先永久禁止新取出，再复制未取出队列；复制资源失败保留原队列和冻结状态，同截止可重试。入口看到 stop 或取出冻结后零新取出；已经移到局部的一项最多完成一次再收束。

### 4.5 启动组合

实现唯一根函数：

```cpp
事件日志线程启动结果 启动事件日志线程(
    const 事件日志线程启动请求& 请求,
    线程生命周期发布端口& 生命周期端口) noexcept;
```

公开启动请求只含事件合同版本、运行代次、线程逻辑身份、容量、进入等待毫秒和启动失败回收诊断等待毫秒，不嵌入 SUPPORT DTO。完整请求校验在任何分配和 SUPPORT 调用之前完成；模块内部机械形成固定 `事件日志 / 事件日志` 配对的 SUPPORT 创建、等待和回收请求。随后按“状态 / 适配器 / 入口 -> 创建候选 -> 等待内部进入 -> 复核同次见证未显示入口故障 / 提前完成 -> 成功组装租约；否则移动候选回收”实施。禁止读取 8110 投影、查找既有租约、接受调用方选择 SUPPORT 类别 / 模块、复制 SUPPORT DTO、发布第二套进入 / 完成见证或调用 detach。

函数名、变量名、类内业务成员名和新增项目标识符使用中文；标准库、平台 API 和外部固定名称除外。

- 真实 SUPPORT 物理线程、内部进入见证、唯一 EVENT 移动租约和身份历史重用拒绝；
- 摘要坏 / 错运行代次、零摘要身份 / 时间 / 稳定编码、字段空 / 越界或未知分类拒绝；相同摘要身份的独立重复不触发隐式幂等；
- 多生产者接受位置唯一单调、成功项总量守恒和按位置 FIFO；
- 满时拒绝且零驱逐；若公开边界无法确定性保持队列为满，动态项记 `NOT_RUN` 并只做静态分支核对；
- 写入成功时每项完成一次；日志设施失败无法安全确定性注入时，false 分支动态项记 `NOT_RUN`，不得改生产 seam；
- 停收与提交竞态截止准确、重复停收同截止、截止后提交拒绝；
- 完成等待的无需等待、已到达、超时和虚假唤醒守恒；
- 超时后冻结快照按位置升序、不含正在处理项、冻结后零新取出、同截止重读一致；
- stop 前 / 取出中 / 取出后竞态只允许零新取出和当前一项最多一次；
- 空队列等待时 SUPPORT request_stop 经 stop callback 确定唤醒并完成，零轮询、零悬挂 join；
- 显式 rvalue 停止连接返回 EVENT 状态、最终 SUPPORT 见证和位置；重复 / 移动源返回租约已消费，零第二 join；
- 未停收显式停止，以及已停收但未完成到截止且无同截止成功快照的显式停止，都仍安全 join，并精确返回前置未闭合而非普通成功 / 请求拒绝；
- 单 owner、析构 fallback、SUPPORT 完成见证和最终 join，且 join 先于入口 / 适配器 / 状态销毁；
- 日志输出不参与专项 PASS；专项只以结构化 EVENT / SUPPORT 结果、位置、快照和线程见证判定。
