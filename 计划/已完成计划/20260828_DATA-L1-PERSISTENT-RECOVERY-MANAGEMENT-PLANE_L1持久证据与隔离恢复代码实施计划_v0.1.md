实现普通应用持久 L1 运行包，使完整中性事实状态在受控存储中形成持久证据，并在后续进程构造任何 L2 服务前隔离恢复为唯一内存权威。不得保存业务专用锚点快照，不得让普通读取磁盘回源。

## 4. S0 门禁

1. 核对 `main`、HEAD、origin、ahead/behind 和 index。
2. 六个现有修改文件没有其它活动所有者；任一重叠只停止对应实施。
3. 仓库仍只有五个权威状态交换点。
4. 服务无参数工厂仍创建全新内存状态，尚无持久工厂。
5. 普通应用仍在 owner / L2 服务构造前建立 L1 运行包。
6. 读取代码知识规则和目标核心文件当前用途条目；落后时按当前源码裁决。

## 5. 实施步骤

1. 新增持久配置、状态、见证和成功谓词。
2. 在仓库模块实现独占会话、SHA-256、规范编码 / 解码、双槽和清单原子替换、有界恢复审计。
3. 为完整权威状态实现编码 / 解码；剔除七类非权威索引和进程生命周期维护幂等项。
4. 从恢复权威字段重建七类索引，调用现有整仓不变量检查，再一次交换发布。
5. 在五个现有权威交换点前调用唯一持久准备 helper；失败映射现有中性状态并保持零内存变化。
6. 在服务模块实现持久运行包工厂；无参数纯内存工厂保持隔离测试兼容。
7. 扩展普通应用配置和装配，恢复失败时不构造 owner、L2 服务或业务上下文。
8. 增加专项测试入口和工程登记，不改变现有测试分派语义。
9. 形成施工 / 验证记录，精确列出实际运行和 `NOT_RUN` 项。

## 6. 实施不变量

- 磁盘材料不是普通读取权威。
- 稳定编码、owner、创建 / 退出代次和历史不得重写。
- 持久清单成功必须先于内存交换；失败不得交换。
- 精确重复和只读不产生新快照。
- 恢复不推进事实代次。
- 旧进程端口、锁和地址不持久化。
- 非权威索引不持久化，只确定重建。
- 禁止 raw C++ 布局和 `variant::index()` 编码。
- 不保存本能根或任何业务子图专用快照。
