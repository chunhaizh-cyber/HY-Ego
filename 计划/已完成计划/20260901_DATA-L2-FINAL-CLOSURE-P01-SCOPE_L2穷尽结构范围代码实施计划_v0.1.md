## 1. 目标与完成条件

把用户确认的 DATA-L2 穷尽范围落实到公共 C++ 分类合同，同时保持现有 ARCH-L4 兼容 ABI 数值不变：

```text
当前 DATA-L2 活跃节点 owner：11 个
  场景、存在、特征定义、特征实例、状态、动态、因果、
  语言、词条、概念、不可变材料

ARCH-L4 兼容节点族：
  方法、需求、任务

独立关系 owner：
  概念名称关系（不增加节点族枚举）
```

本计划完成必须同时满足：

1. 不可变材料取得新且不复用的 `L2节点族` 数值 `14`。
2. 公共头能够纯值判定“当前 DATA-L2 活跃节点族”和“ARCH-L4 兼容节点族”。
3. 方法、需求、任务不被当前 DATA-L2 分类接受，但其既有枚举值 `11—13` 和现有 DTO / 服务编译 ABI 保持。
4. 既有 `L2节点族身份来源事实完整` 保持兼容旧三族，并接受不可变材料节点族的纯值形状；本计划不新增材料身份来源服务入口。
5. 规范、代码分类和静态断言一致；既有工程在干净提交候选上通过计划规定的构建。
6. 施工 / 验证记录明确本计划只完成范围分类，不证明 P02、P03 或任一结构族已经 `FROZEN`。

## 3. 冻结代码合同

唯一修改生产文件：

`海中鱼巣/领域/L2结构公共.数据.h`

### 3.1 枚举

保留现有所有枚举数值并追加：

```cpp
enum class L2节点族 : std::uint8_t {
    场景 = 1,
    存在 = 2,
    特征定义 = 3,
    特征实例 = 4,
    状态 = 5,
    动态 = 6,
    因果 = 7,
    语言 = 8,
    词条 = 9,
    概念 = 10,
    方法 = 11,
    需求 = 12,
    任务 = 13,
    不可变材料 = 14
};
```

禁止把 `11—13` 复用给不可变材料，禁止重排 `1—10`，禁止通过合同版本不变掩盖枚举重编号。

### 3.2 分类谓词

在公共头中新增两个 `inline constexpr`、`noexcept`、无 I/O 的纯值函数：

```cpp
inline constexpr bool L2节点族属于当前DATA_L2(L2节点族 节点族) noexcept;
inline constexpr bool L2节点族属于ARCH_L4兼容(L2节点族 节点族) noexcept;
```

第一函数只对 `1—10` 和 `14` 返回 `true`；第二函数只对 `11—13` 返回 `true`。所有未定义数值均返回 `false`。

`L2节点族身份来源事实完整` 的节点族有效性改为：

```text
L2节点族属于当前DATA_L2(来源.节点族)
|| L2节点族属于ARCH_L4兼容(来源.节点族)
```

该组合保持既有兼容形状并加入不可变材料，不把 ARCH-L4 兼容项重新解释为当前 DATA-L2。

### 3.3 静态 ABI 断言

在公共头加入最小 `static_assert`，至少固定：

```text
概念 == 10
方法 == 11
需求 == 12
任务 == 13
不可变材料 == 14
当前 DATA-L2 接受不可变材料且拒绝方法 / 需求 / 任务
ARCH-L4 兼容接受方法 / 需求 / 任务且拒绝不可变材料
```

静态断言是编译期 ABI 门禁，不建立运行期事实、日志或第二服务入口。
