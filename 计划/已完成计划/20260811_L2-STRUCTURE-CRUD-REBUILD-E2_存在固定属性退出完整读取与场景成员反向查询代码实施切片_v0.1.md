## 1. 目标、范围与完成条件

在已发布的 E1 存在节点、S2 场景成员关系、S3 场景固定属性与完整读取、L1 历史属性值组和 L1 当前引用闭包保护之上，完成 `L2存在结构服务` 的固定属性初始发布、固定属性换代、存在整体退出和完整当前 / 历史读取；同时由唯一场景所有者 `L2场景结构服务` 提供“按存在查询当前场景成员引用”的反向值式投影。

本叶只闭合存在结构自身节点与固定属性，以及场景所有者已有成员关系的反向公开读取。存在服务不得 import 或调用场景服务；存在退出不得携带、扫描或代替场景所有者退出成员关系。它不实现特征、状态、动态、因果、业务存在真实性、资格判断或 A1 聚合面。

完成条件固定为：

1. `L2存在结构服务` 新增固定属性初始、固定属性换代、存在退出和完整存在读取四个公开函数；
2. 固定属性初始以一份 L1 写集同时建立新值并切换当前槽；换代以一份 L1 写集同时建立新值、切换当前槽并退出具名旧值；
3. 初始时同类型已有当前值返回 `引用冲突`；换代时属性未设置返回 `属性未设置`，旧值编码不符返回 `引用冲突`，均零变化；
4. 成功与精确重复都从首次变更代次的 L1 历史属性值组和单事实历史读取重建首次载荷，不以调用时当前槽替换首次结果；
5. 存在退出请求只显式携带当前固定属性值编码升序组；L2 从完整当前存在快照逐字段核对“不少、不多、不错项”，不携带或退出场景成员关系；
6. 当前场景成员关系、未来特征 / 状态关系、值来源或独立材料引用仍存在时，由 L1 当前引用闭包返回 `引用冲突=10`，E2 精确映射为 L2 `引用冲突`；调用方须先经对应所有者闭合引用，再用新代次和新幂等身份退出存在；
7. 存在退出成功时，存在节点及请求中全部当前固定属性值在同一 L1 事实代次退出，历史仍可按退出前截止完整读取；
8. 当前完整存在以两次同一期望代次的一致投影返回普通存在节点和全部当前固定属性，不返回混代或部分载荷；
9. 历史完整存在使用前后代次夹取、历史存在节点和 `读取中性历史属性值组` 按半开区间重建，不用节点当前槽快照或当前事实补历史缺项；
10. 现有 `读取存在节点` 保留签名并收敛为完整读取兼容入口：当前截止为 0，历史截止等于请求期望事实代次；任意更早历史截止只由新增完整读取入口承载；
11. 场景服务新增按存在当前成员反向查询；同一期望代次同时核对目标存在节点与目标成员关系组，合法空引用组成功，结果按“顺序、场景编码、关系编码”稳定排序；
12. 反向查询的 DTO 归属存在数据头，查询实现和公开函数唯一归属场景服务；依赖保持 `场景服务 -> 存在公开读取 + L1`，不得形成反向 import；
13. 全部非成功返回空载荷；登记未加载、许可拒绝、代次漂移、目标未找到 / 已退出、幂等冲突、引用冲突、资源失败和内部矛盾不得互相折叠。

两个属性写入口固定使用 S3 已验证的边界：

```text
纯值校验
-> 先构造完整不变 L1 写集
-> 探测当前代次
-> 实际代次 != 请求期望：恰一次直提原写集，让 L1 裁决重复 / 冲突 / 漂移
-> 同代次：一致投影核对普通存在节点与具名属性槽
-> 恰一次提交同一写集
-> 从新编码映射取得新值
-> 以首次变更代次读历史属性值组和单事实历史
-> 形成首次完整载荷或内部不一致
```

初始写集精确为：`节点=[]`、`关系=[]`、`值=[{存在固定属性值本地键,存在,属性类型,材料,来源}]`、`属性槽变更=[{存在,属性类型,本地键}]`、`退出事实=[]`。前置必须取得当前普通存在节点；具名属性未设置才允许提交，已有当前值返回引用冲突。

换代写集与初始唯一差异是 `退出事实=[旧值稳定编码]`。前置必须取得当前普通存在节点和具名当前属性；未设置返回属性未设置，槽值不等于请求旧值返回引用冲突，所属、类型、材料、来源或生命周期矛盾返回内部不一致。

成功 / 精确重复必须验证 L1 合同、幂等键、首次事实代次、发布 / 重试边界和唯一新编码映射。新值从首次截止的历史属性值组重建；换代旧值另以单事实历史读取核对退出代次。任一缺项、复义、错本地键、错所属 / 类型 / 材料 / 来源或混代返回内部不一致，不二次提交。

## 7. 存在退出与引用保护

退出前在请求期望代次调用 `读取完整存在(当前)` 形成权威当前快照，从中提取固定属性值编码严格升序组。实际组与请求组不逐字段相等时返回 L2 `引用冲突`、空载荷且不提交。

闭包一致后形成唯一 L1 写集：节点 / 关系 / 值 / 槽变更全空，`退出事实` 为存在节点编码与全部当前固定属性值编码的全局升序唯一组。场景成员关系和任何其它所有者事实不得加入该写集。

L1 对最终写集执行二次当前引用闭包保护。任一当前场景成员关系、未来特征 / 状态引用、值来源或独立材料引用仍指向目标存在或其待退出值时，返回 `L1中性写入状态::引用冲突`；E2 精确返回 L2 `引用冲突`。调用方必须先经关系 / 值所有者退出这些引用，再用新的期望代次和幂等身份重试，不得复用被引用冲突绑定的原请求身份改语义。

成功 / 精确重复要求空新编码映射和首次发布 / 重试边界正确；随后按首次事实代次读取存在节点与请求中每个属性值的单事实历史，核对全部退出代次相等，形成稳定排序的 `已退出存在`。任一缺项、多项、错类、错所属或生命周期矛盾返回内部不一致，不把已发布事实补偿回滚或伪报引用冲突。

## 8. 完整当前 / 历史存在与兼容读取

### 8.1 当前完整存在

第一次 L1 一致投影只请求目标存在节点，必须为当前普通节点；节点当前属性槽按类型严格升序，类型和值编码均非零且无重复。第二次在同一期望代次重读节点，并按第一次槽组请求全部具名属性值。第二次槽组必须与第一次逐字段相等；每个属性项必须成功并回显目标存在 / 类型，槽值与值事实编码相等，值事实当前且所属、类型、材料、来源和生命周期完整。

两次读取都只能在请求期望代次成功。任一次许可拒绝、漂移或资源失败按同名状态返回空存在；节点未找到 / 已退出按同名状态；缺项、复义、错槽、混代或形状矛盾返回内部不一致。成功后属性按“类型、值”升序形成 `L2存在事实`。

### 8.2 历史完整存在

历史读取固定流程为：

```text
读取当前事实前代次并要求等于请求期望代次
-> 读取目标存在单事实历史
-> 读取中性历史属性值组(存在, 历史截止事实代次)
-> 读取当前事实后代次并要求仍等于请求期望代次
-> 按 [创建代次, 退出代次) 重建截止投影
```

历史属性值组必须回显所属存在、历史截止和请求期望事实代次；每个值真实属于目标存在，同一属性类型在截止至多一个有效值。晚于历史截止的退出代次在旧截止投影中清空；截止等于退出代次时该节点 / 值不再当前可见。存在节点的当前槽只做普通节点结构校验，不能决定历史属性内容或补历史缺项。

任一前后代次变化返回事实代次漂移和空载荷；入口、资源或历史组失败按精确状态收口；目标在截止前未创建返回未找到，截止已退出返回已退出；其它半结构或生命周期矛盾返回内部不一致。

### 8.3 E1 兼容入口

`读取存在节点` 保留原签名，只构造 `L2存在完整读取请求` 并调用 `读取完整存在`：当前类别的历史截止为 0，历史类别的历史截止等于请求期望事实代次。结果头和完整存在逐字段透传，不再调用 E1 空属性私有读取路径。`形成E1存在事实` 只继续服务 `新增存在节点` 的首次创建读回。

场景服务全部存在端点核对从 `L2存在E1事实完整` 改为 `L2存在事实完整(存在, 结果截止)`；有固定属性的当前普通存在必须可作为成员关系端点，属性事实本身不进入成员关系结果。

## 9. 按存在查询当前场景成员引用

查询必须先取得完整场景成员关系类型登记；登记未加载、定位失败或漂移映射为现有精确登记状态，不猜测关系类型编码。然后以同一期望代次执行：

1. 调用存在公开 `读取完整存在(当前)`，要求目标存在完整、当前且截止等于请求期望代次；
2. 调用 L1 一致当前投影，请求至少包含 `节点={存在编码}` 和 `目标关系组={{存在编码, 登记成员关系类型}}`，其它未请求组为空；
3. L1 节点项必须与存在公开读取的身份、普通节点和生命周期一致；不能仅凭空目标关系组判成功；
4. 每条关系必须是当前登记成员关系类型，目标精确等于请求存在，源节点是当前普通场景，顺序可无损映射且非零，关系生命周期在截止完整；
5. 转换为 `L2存在场景成员引用事实`，按“顺序、场景编码、关系编码”严格稳定排序；同关系编码重复、同场景 / 同存在出现多条当前关系或任一端点复义均内部不一致；
6. 目标存在合法且关系组为空时返回 `已读取`、请求期望截止和空引用组。

许可拒绝、漂移、未找到、已退出、登记失败、资源失败或内部矛盾均返回空引用组，不返回部分成员。查询不重试、不 sleep、不访问场景仓库，也不把反向投影保存为第二权威列表。

## 10. 状态映射、幂等与异常边界

`映射存在写入状态` 必须显式覆盖 `L1中性写入状态::引用冲突 -> L2结构状态::引用冲突`。E1 节点新增若意外收到该状态也按引用冲突透传，不得落入未覆盖 switch。历史属性值组、一致当前读取和场景登记状态分别使用已有同名映射边界，不将许可拒绝或漂移降级。

非成功优先级固定为：

```text
纯值非法 -> 入口拒绝
既有幂等键 -> 精确重复 / 幂等冲突
新幂等键旧期望 -> 事实代次漂移
目标未找到 / 已退出 -> 同名状态
属性未设置 -> 属性未设置
旧值或显式属性闭包不符 -> 引用冲突
L1 外部当前引用未闭合 -> 引用冲突
许可拒绝 / 资源异常 -> 许可拒绝 / 资源失败
成功形状、登记、端点、槽、索引或读回矛盾 -> 内部不一致
```

所有写入口恰一次提交。`std::bad_alloc` / `std::length_error` 映射资源失败，其它未处理异常映射内部不一致。非成功不携带属性、存在或引用组，不伪造变更代次；安全取得的实际代次只用于对应漂移 / 冲突结果头。

13. 退出请求漏一个属性值、多带其它事实或顺序错误分别为引用冲突 / 入口拒绝且零提交；成功结果逐字段等于 L1 历史读回；
