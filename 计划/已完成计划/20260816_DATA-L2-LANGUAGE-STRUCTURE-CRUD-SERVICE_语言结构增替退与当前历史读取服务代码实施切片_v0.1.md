# DATA-L2 语言结构增替退与当前历史读取服务代码实施切片

日期：2026-08-16

版本：v0.1

身份：`DATA-L2-LANGUAGE-STRUCTURE-CRUD-SERVICE`

状态：设计就绪；以计划索引登记状态为准

## 1. 目标

依据[详细设计](../规范/详细设计/20260816_DATA-L2-LANGUAGE-STRUCTURE-CRUD-SERVICE_语言结构增替退与当前历史读取服务详细设计_v0.1.md)，建立唯一语言 owner 和 `L2语言结构服务`，实现语言新增、不同新身份替换、退出、按身份当前 / 历史读取及按登记键当前 / 历史读取。

本计划完成只证明语言结构 CRUD 服务叶；不装配普通应用，不实现词条、语言记录、概念名称、默认汉语身份、语素或词性，不完成 `DATA-EXT-10`。

## 2. 前置和激活门禁

- 0050、1100、2200、4240 及不可变材料服务结果已经闭合机器语义和材料提供者。
- `DATA-L2-LANGUAGE-PUBLIC-DTO v0.1` 必须先有正式代码结果、计划退出和目标文件释放，且最终 `L2语言结构.数据.h` ABI 与本设计逐项机械一致。
- 实施前从最新正式 `main` 重做 S0，确认新服务模块、不可变材料模块、根工程文件、唯一代码段、构建资源和 Git / index 租约没有重叠所有者。
- 设计发布时上述 DTO 尚在执行，因此本计划登记为 `待激活`，不得越过门禁施工。

## 4. 必须实现的公开实体

在新模块中实现：

```text
语言所有者建立身份
L2语言所有者交付
尝试形成L2语言所有者交付(...)
L2语言结构服务
```

`L2语言结构服务`完整构造固定接收：

```cpp
const L1事实基座服务&
const 不可变材料服务&
L2语言所有者交付&&
```

公开函数固定为：

```cpp
L2语言新增结果 新增语言(const L2语言新增请求&);
L2语言替换结果 替换语言(const L2语言替换请求&);
L2语言退出结果 退出语言(const L2语言退出请求&);
L2语言读取结果 读取语言(const L2语言读取请求&) const;
L2语言按登记键读取结果 按登记键读取语言(
    const L2语言按登记键读取请求&) const;
```

不得增加裸稳定编码入口、通用跨族 CRUD、字符串入口、默认汉语常量、缓存或索引权威。

## 5. 实施步骤

1. S0 核对计划版本、plan / design blob、DTO 最终 ABI、目标四个生产路径、异主 WIP、代码段、构建和发布资源。
2. 在不可变材料服务增加通用中性同 L1 实例谓词；只比较内部保存的 L1 引用地址，不引用语言类型，不暴露 L1、材料 owner 或事实。
3. 在新模块实现语言 owner 交付验证、固定 `0x0208` 私有登记、登记首次 / 精确重复和构造后正式读回。
4. 实现同截止语言读回核心：按身份复用 owner 一致当前 / 历史事实与关系组读取；按登记键复用精确目标端点当前 / 历史关系组读取；语言节点、族归属、登记键关系、来源关系、材料事实和格式登记必须在一个明确截止完整互证。
5. 为三个写入口先实现首次规范化写集读取：按新建 / 新建加退出 / 仅退出三种形状重建原完整请求；同义返回原截止结果，异义返回幂等冲突，坏首次材料返回内部不一致。
6. 实现新增：同一 owner 一次建立四事实；同键唯一；首次和精确重复分别闭合。
7. 实现替换：一次 owner 写集退出旧四事实并建立不同新身份的四事实，同代正式读回新旧完整结果。
8. 实现退出：一次 owner 写集退出四事实，保持 L1 全局引用保护，不级联删除材料或引用方。
9. 为全部入口建立异常和状态映射，非成功空载荷、零变更；发布未知只允许原请求重放。
10. 在根工程和 filters 中唯一登记新模块，不登记临时检查源码。
11. 形成专属记录，执行验证，只提交允许文件并普通推送；结果发布后由计划索引所有者登记退出。

## 6. 成功条件

- 语言节点、族归属、登记键和来源关系只有一个语言 owner 和一个公开写服务；
- 四项登记、关系方向、固定键和生命周期符合详细设计；
- 材料服务与语言服务的同 L1 实例在构造时机械证明，不能以相同代次数值代替；
- 登记键材料同截止正式读回为严格 UTF-8，来源材料同截止完整可读；
- 新增、替换、退出、按身份读和按登记键读的当前 / 历史形状与 DTO 一致；
- 替换形成不同新语言身份，旧四事实退出和新四事实创建同代；
- 同幂等同请求从首次规范化写集回显原截止结果，即使首次对象后来被替换或退出也不改变；同幂等异义、同键异请求、旧材料不符和当前引用分别分账；
- 非成功不泄漏语言或变更代次；发布后坏读回只能是内部不一致；
- 根工程双配置、专项、工程 XML、唯一登记、UTF-8、中文标识符、diff、strict、白名单和生产零测试痕迹通过；
- 临时检查源码和产物清理完成。

## 8. 失败收口

- DTO 最终 ABI、不可变材料私有形态或 L1 公开接口发生会改变字段、所有权、事务或结果形状的漂移：停止施工并具名退回计划支撑。
- 目标文件 / 语义有另一所有者，或代码段、构建、Git / index 租约冲突：只停止受影响资源，保留现场并协调。
- 普通 C++、工程 XML、固定键、编码或静态检查错误：在白名单内修复并重跑受影响验证。
- 发布结果未知：保留精确提交和 index 事实，只做只读远端核对；禁止 force、rebase、merge、reset、stash 或带入异主 WIP。
