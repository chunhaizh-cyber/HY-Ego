## 1. 目标与完成条件

按同名详细设计，在唯一 `L2概念结构服务` 内完成：

1. 按概念读取当前或指定历史截止的唯一治理生命周期；
2. `活跃 -> 冷却`、`冷却 -> 活跃`、`冷却 -> 退役`、`退役 -> 活跃` 四条合法迁移；
3. 一份概念 owner 写集建立新生命周期值、退出具名旧值并切换当前属性槽；
4. 首次提交 / 精确重复从首次截止读回同一新旧事实；
5. 根保护、非法迁移、漂移、幂等、引用、许可、资源和内部错误分账；
6. 不根据用途、支持、名称、统计或时间做业务裁决。

完成只证明本叶生产代码、公开 ABI 和必要构建检查进入正式 Git；不证明自动治理、定义约束、概念退出、普通应用完整材料装配、DATA-L3 投影、`DATA-EXT-08` 整项或真实消费者闭环。

## 4. 机械施工合同

1. 按详细设计 §3 增加生命周期合同版本、迁移 / 读取请求、写 / 读结果、五项纯值 helper 和成功形状；不改变既有枚举数值或普通概念字段顺序。
2. `L2普通概念事实完整(...)` 复用新的生命周期事实 helper，既有根、普通概念、上下位和支持 DTO / 成功形状保持。
3. 服务增加 `迁移概念治理生命周期(...)` 与 `读取概念治理生命周期(...) const`；只读取 / 写入概念 owner 的治理生命周期属性值。
4. 读取当前属性槽或历史有效值时必须证明恰一完整事实；根、未知概念、已退出概念、零项 / 重复 / 混代分别按设计分账。
5. 使用本地键 `0x020A'5001` 形成新值；一份写集建立新 I64 值、退出具名旧值并切槽，不修改任何其它概念事实。
6. 当前代次等于请求守卫时逐字段核对旧事实和合法迁移；已漂移时原写集交给 L1 裁决精确重复 / 漂移 / 幂等冲突，不用新事实改写请求。
7. 首次和精确重复都从首次结果截止读回新当前值和同代退出旧值；发布未知 / 资源失败保留原请求重放，零内部重试、sleep 或 deadline。
8. 写 / 读全部非成功空载荷、零变更；坏私有事实或坏成功形状为内部不一致。
