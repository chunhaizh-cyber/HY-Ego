## 1. 目标、完成条件与非目标

依据 4020、4240 v0.3 和 `CONCEPT-SPACE-STRUCTURE-CRUD-REBUILD` 总详细设计 v0.3，新建唯一 `不可变材料服务`，完成材料 owner、格式 / SHA-256 / 长度 / 来源节点 / 生命周期登记、隔离候选复读、不可变发布、当前 / 历史读取和引用保护退出。

完成条件：服务构造以固定登记正式建立并读回一个系统签发者、两个材料格式和三个材料属性类型；合法严格 UTF-8 与通用字节材料可经公开入口写入并逐字段正式读回；系统签发来源与普通已发布节点来源均闭合；相同格式、摘要、完整内容和解析来源精确重复，同内容异来源冲突且零新增；坏路径、坏格式、长度 / 摘要不符、坏 UTF-8、来源不存在 / 已退出 / 漂移均零事实变化；被当前值或结构引用时退出冲突；退出后当前不可见、历史完整。物理路径不进入材料身份。

本叶不解释文本、规则、词性或概念语义，不实现语言 / 词条 / 词性、概念、名称、二次特征、因果链、聚合消费者、阶段 18、材料物理回收或跨进程恢复。

写入结果 `成功()` 精确为：状态是 `已提交` / `精确重复`、合同版本正确、事实截止非零、变更事实代次存在、材料存在且为截止时完整活动事实，并且 `*变更事实代次 == 结果头.事实截止代次 == 材料.生命周期.创建事实代次`；精确重复仍从首次截止读回。退出结果 `成功()` 精确为：状态是 `已提交` / `精确重复`、合同版本正确、事实截止非零、变更事实代次存在、退出材料存在且完整、其退出事实代次同时等于变更事实代次和事实截止。登记读取结果 `成功()` 精确为：状态 `已读取`、合同版本正确、事实截止非零、无变更事实代次、登记存在且登记截止等于结果截止，系统签发者、两个格式身份和三个属性类型身份均非零且两两互异；自身读取字段还必须满足当前读取时历史截止为 0，历史读取时历史截止非零且等于结果截止。六项当前性和属性类型表示由读取函数形成登记前正式互证，不增加登记 DTO 字段。材料读取结果虽无 `成功()`，其 `已读取` 完整形状同样校验自身读取类别 / 历史截止与结果截止。其它状态或成功态缺载荷一律 `false`。

结果状态集合固定为：写入 `{已提交, 精确重复, 入口拒绝, 许可拒绝, 未找到, 已退出, 事实代次漂移, 幂等冲突, 资源失败, 内部不一致}`；读取 `{已读取, 入口拒绝, 许可拒绝, 未找到, 已退出, 事实代次漂移, 资源失败, 内部不一致}`；退出 `{已提交, 精确重复, 入口拒绝, 许可拒绝, 未找到, 已退出, 事实代次漂移, 幂等冲突, 引用冲突, 资源失败, 内部不一致}`；登记读取 `{已读取, 入口拒绝, 许可拒绝, 未找到, 事实代次漂移, 资源失败, 内部不一致}`。任一非成功 optional 载荷为空；当前已永久退出和从未存在 / 截止早于创建必须分别返回 `已退出`、`未找到`。

构造顺序固定为 `配置纯值校验 -> 根打开 / 规范化 / 卷身份 -> 固定子目录逐级验证或建立 -> owner 交付同实例 / 身份 / 独占范围校验 -> 六节点登记 -> 发布截止读回 -> 形成服务实例`。配置 / 目录失败必须发生在登记写前。登记只接受 L1 `成功` / `精确重复`；L1 `资源失败` 映射构造 `资源失败`，其它固定内部请求逻辑拒绝映射 `登记失败`，登记读回缺项或混代映射 `内部不一致`。构造失败销毁传入端口租约但不退出既有 owner 或已发布登记；调用方只能经 L1 正式重入重新取得交付后以同一配置重试。

材料 owner 建立身份固定为 `0x4C32'4D41'5445'5201`，私有幂等域固定为 `0x30`。构造登记幂等身份固定为 `0x4C32'4D41'5452'4701`；本地键固定为：`0x3000'1001` 系统签发者普通节点、`0x3000'1002` 严格 UTF-8 格式普通节点、`0x3000'1003` 通用字节格式普通节点、`0x3000'1101` 格式身份 U64 组属性类型、`0x3000'1102` 字节长度 U64 组属性类型、`0x3000'1103` SHA-256 U64 组属性类型。六节点由一份 owner 写集建立并从首次代次正式读回；任一错 owner、错类型、重复或不完整均为内部不一致。

每个材料新建写集固定使用请求局部键 `0x3000'2001` 材料节点、`0x3000'2101` 格式值、`0x3000'2102` 长度值、`0x3000'2103` 摘要值。局部键只在单写集内解析；调用方幂等身份原值直接作为 L1 owner 写入幂等身份，不散列、不截断、不另造第二 L1 写键。

调用方负责建立 owner 范围并在构造输入中移动交付；服务验证端口与传入 L1 同实例、owner 身份和独占范围后私有持有唯一写端口。调用方还必须显式提供已存在的非空绝对普通目录；服务只验证、规范化并持有，不选择默认路径。后继 A1 / 生产装配负责生产根来源和生命周期，本叶不修改普通应用或启动。激活 S0 必须对上述所有固定值机械查重。

物理实现依赖固定使用 Windows 现有工具链的系统文件句柄、卷身份和系统 SHA-256；若 SHA-256 采用 BCrypt / CNG，只能在允许的 `海中鱼巣.vcxproj` 登记 `bcrypt.lib`，不得引入第三方库。逐组件句柄、卷身份、SHA-256 和路径互证的私有 helper 可机械实现，但不得成为第二模块、公开入口或验证 seam。

受控根固定包含 `候选/` 与 `对象/sha256/`；固定子目录存在时必须验证为同卷普通目录且无重解析点，缺失时由服务逐级建立，目录 I/O 失败映射 `目录资源失败`。最终对象路径固定为 `对象/sha256/<摘要前两位小写十六进制>/<64位小写十六进制摘要>.bin`；调用方只能提交 `候选/` 下已有普通文件。根、候选、父级、对象目录、临时文件和最终对象逐组件拒绝符号链接、挂载点或其它重解析点。根内判断必须使用逐级打开句柄取得的最终规范化路径、卷身份和目录身份，禁止字符串前缀或仅词法规范化充当安全证明。候选、最终分片目录和最终对象必须以卷身份证明同根同卷；不同卷、越界、相对路径、路径穿越或重解析越界均为入口拒绝。

服务在最终分片目录建立唯一临时文件，写入并复读完整字节、长度和摘要后关闭写句柄，再执行同卷不可覆盖原子 rename。目标已存在或 rename 竞争出现目标时，必须完整复读：一致则收敛，不一致则内部不一致。已知目录 / 读写 / rename I/O 失败映射资源失败；rename 结果未知时重开最终摘要路径，存在且一致才继续，不存在为资源失败，存在但不一致为内部不一致。rename 前失败尝试删除本次临时文件；清理失败只留下受控根内孤立临时文件，不改变原状态且不得发布 L1。重启由调用方再次显式传入同一规范化根，服务按摘要派生并复读；路径不进入身份或幂等键。

## 5. 来源节点、幂等与写入状态机

### 5.1 来源节点合同

来源联合只有两种合法形状：`系统签发` 解析为当前登记中的系统签发者；`已发布节点` 使用调用方提交的非零节点。两者最终都必须成为正式已发布节点编码。写入前必须：

1. 校验来源非零；
2. 经唯一正式 L1 公开读取取得当前节点事实；
3. 互证查询编码、节点编码、成功状态和非零读取截止；
4. 证明节点在本次写入截止当前存在，创建代次不晚于读取截止且无生效退出；
5. 释放读取，再保存该截止 / 事实代次进入写请求提交条件。

来源不存在、已退出、错形状或读取资源失败均不写材料事实。来源在读后提交前漂移返回事实代次漂移且零材料写入。执行者不得接受显示名、SQL 行、日志、路径、服务对象、线程或调用方自报文本作为来源。

### 5.2 写入状态机

```text
校验请求纯值与路径
-> 正式读取来源节点
-> 复读候选完整字节
-> 校验登记格式、长度、SHA-256
-> 严格 UTF-8 追加校验
-> 在最终摘要分片目录建立同卷临时文件
-> 不可覆盖原子 rename 到摘要定位或逐字节收敛既有对象
-> 材料 owner 单写集发布普通材料节点 + 三值 + 三当前属性槽
-> 从首次事实代次正式读回
-> 逐字段互证后返回
```

三个值分别使用登记中的格式 / 长度 / 摘要属性类型；材料固定为 `[格式身份]`、`[字节长度]`、按确定大端序打包的四个 SHA-256 `uint64`，来源节点三项相同。候选失败、来源失败或提交拒绝不得发布 L1 材料事实。L1 发布前形成但未被引用的文件只是孤立候选，可由后继维护回收；L1 发布后文件缺失返回内部不一致，不撤销事实、不以日志补成功。

幂等键覆盖调用方幂等身份和完整请求语义。相同格式、摘要和完整字节收敛同一当前材料身份；同幂等身份异格式、异长度、异摘要、异来源或异字节为幂等冲突。摘要相同而复读字节不同为内部不一致。

发布结果未知时必须保存原完整请求并原样重放。只有明确零变化的事实代次漂移，才可重新正式读取来源后用同一幂等身份重组完整请求；不得改来源、候选、摘要或格式。

服务实例私有维护非权威请求账和内容索引。请求账键为调用方幂等身份，保存完整原请求、待决状态和首次结果；内容键固定为 `格式身份 + 字节长度 + SHA-256`，值为材料身份。命中必须复读物理完整字节并正式读回 L1，不得把缓存升级为事实。一次调用只在短临界区登记 / 观察待决项，进入文件系统或 L1 前释放服务锁。

同幂等身份异请求返回幂等冲突。同请求或同内容并发只允许一个 leader 写入，其余等待正式结果；不同幂等身份提交相同格式 / 长度 / 摘要 / 完整字节且解析来源相同时，返回 leader 的同一首次身份。同内容但来源不同返回幂等冲突，不建立第二身份；多来源结构不在本叶。当前材料已退出后只有新幂等身份可建立新身份，旧编码不复用。发布结果未知时只允许原幂等身份原请求重放；其它幂等身份命中同内容待决项返回资源失败并标记“原幂等键重放”，不得创建第二节点。索引命中但物理或 L1 读回异义返回内部不一致。

索引只覆盖唯一服务实例生命周期，不形成恢复权威。固定材料登记为 `精确重复`、内容索引无命中且最终对象已存在时，无法区分物理孤儿和已丢索引的当前材料，必须返回内部不一致而不得再建节点；只有新 L1 首次发布固定登记时，既有对象才可作为孤立候选重新准入。跨进程恢复、或保留当前 L1 事实但丢失服务索引后的 provider 重建不在本叶；后继若需支持，必须先提供 owner 范围枚举或等价正式能力，不得扫描路径补造身份。

### 5.3 生产实现唯一性与诊断责任

生产状态机及全部私有辅助只允许存在于 `海中鱼巣/领域/服务.不可变材料.ixx`。不得建立 `.inl`、访问器模板、故障注入、测试宏、脚本状态、计数器、调度让行、友元、私有状态出口、测试配置、替代 provider 或只为验证存在的分支。公开构造和四个 CRUD / 读取函数诊断责任为 `本地记录`；直接私有辅助为 `向上送出`；纯摘要分组和逐字段比较为 `无适用错误分支`。诊断关闭不得改变状态或事实。

## 6. 读取、退出、并发与失败守恒

读取请求头合同版本必须等于 `L2结构合同版本` 且期望事实代次非零。当前读取要求 `读取类别 == 当前`、历史截止为 0，成功结果截止等于请求头期望代次；历史读取要求 `读取类别 == 历史`、历史截止非零且不大于请求头期望代次，成功结果截止等于历史截止。读取只返回该截止时的单一完整 `optional<不可变材料事实>`，绝不返回完整事件序列或 vector 历史。当前截止已永久退出返回 `已退出` 空载荷；历史截止早于创建返回 `未找到` 空载荷；历史截止在创建之后返回截止投影，退出不晚于截止时生命周期保留退出代次。登记读取遵守同一当前 / 历史截止形状；登记永久不退出，历史截止早于建立返回 `未找到`，其它合法截止返回单一登记快照。任何成功负载必须逐字段互证格式、长度、摘要、来源、生命周期和可选定位；非成功为空载荷。

每次当前读取必须先读取材料 owner 节点，并证明恰有格式、长度、摘要三个登记属性槽；从槽中取得三个权威当前值编码后，以同一截止读取三值，逐字段互证所属材料节点、属性类型、相同来源、表示和材料。槽缺失、额外槽、值缺失、编码复用、混代或来源不一均为内部不一致；不得从摘要、路径、分配顺序、进程缓存或请求回显猜值编码。

退出请求只携带材料身份。服务先保存上述退出前完整读回，再提交一份材料 owner 写集：新建节点 / 关系 / 值 / 属性槽变更均为空，`退出事实` 精确包含材料节点和三个槽中取得的值编码。依赖当前 L1 节点先于值分配编码、退出集合按编码升序规范化的事实，材料节点先进入历史，随后三值同代退出并移除当前槽，历史节点保留退出前三槽；S0 若发现该顺序漂移必须退回计划支撑。外部关系、其它当前值的所属 / 类型 / 来源或独立材料引用仍指向材料节点时，由 L1 完整退出集合返回引用冲突且全写集零变化；服务不得把外部 owner 事实加入集合，也不得分步清槽或先退三值。

退出成功后按发布截止读取历史节点与三个历史值，证明节点三槽、三值载荷和来源与退出前一致，四者退出代次相同；当前四事实均不可见。任一缺项或混代返回内部不一致且不回滚已发布退出。稳定身份永久不复用；退出不删除物理文件，物理回收不在本叶。

服务不得跨服务持锁。来源读取完成后释放 L1 读取，再进入材料 owner 写入；提交使用来源期望代次防竞态。公开边界捕获资源异常并映射资源失败，未知异常映射内部不一致；不得把异常、日志或人读文本当状态。

## 7. 验证矩阵

验证分为三层，结论不得互相替代：真实公开服务黑盒、静态源码、根工程 / 文件系统物理。专项只消费公开构造和公开 CRUD / 读取入口，不得包含或复制生产实现。至少覆盖：

| 类别 | 用例与断言 |
| --- | --- |
| 构造登记黑盒 | 六个固定节点同 owner、角色 / 属性表示正确、同一次构造精确重复、正式读回同一非零截止 |
| 合法材料黑盒 | 系统签发严格 UTF-8、普通来源通用字节，写后按首次截止逐字段读回 |
| provider 构造 | 显式绝对根成功；空根、相对根、不存在根、非目录和根重解析拒绝；无默认路径或环境回退 |
| 来源分层 | 黑盒覆盖零来源、真实当前普通来源、公开可达的未找到 / 已退出 / 错形状；全部零材料事实变化；无法稳定制造的读后漂移单列 `NOT_RUN` |
| 候选边界 | 根外路径、路径穿越、符号链接 / 重解析越界、缺失文件、异卷发布拒绝 |
| 内容 | 长度不符、摘要不符、空 UTF-8、BOM、无效序列、`U+FFFD` 拒绝 |
| 幂等与内容收敛 | 同幂等同请求精确重复；同幂等异义冲突；不同幂等同完整内容同来源并发返回同一首次身份；同内容异来源冲突且零新增；同摘要异字节内部不一致；待决只允许原键原请求重放 |
| 当前 / 历史 | 当前完整；历史按具名截止返回单一完整快照；退出后当前返回 `已退出` 空载荷，历史截止投影保留退出生命周期；零 vector 历史 |
| 引用保护 | 被当前值或结构引用时退出冲突且零变化 |
| 退出闭包 | 退出前从三槽取得三值编码；四事实同 owner 同代退出；外部引用冲突零变化；退出后当前四事实不可见、历史节点三槽与三历史值完整 |
| 失败守恒 | 公开输入可达的候选 / 文件失败零 L1 变化；真实 I/O 故障、分配耗尽、rename 未知结果、L1 资源失败或发布后读回失败若无法无注入稳定触发，逐项记 `NOT_RUN`，只保留静态映射证据 |
| 并发分层 | 真实同键并发只形成一个当前身份；无法稳定制造的来源漂移记 `NOT_RUN`；静态证明无跨服务锁 |
| 物理与静态 | 摘要路径、同卷临时文件、不可覆盖原子 rename、结果未知读回裁决、重启同根复读源码成立；生产代码零验证入口 / 分支 / 模板拆分 |
