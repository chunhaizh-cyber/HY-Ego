## 3. 当前事实与裁决

当前 `不可变治理批次`和待完成槽只保存消息编号，完整消息在邮箱冻结结果析构时丢失；`L2治理函数骨架`的同名全局分类函数固定返回空批次。本计划仍须修正 002-01→002-03 交接。

同时，邮箱 `提交`已在入队前完成协议、全局幂等键和同任务顺序复核；重复、同键异义和协议错误不会进入队列。冻结批次私有字段仅邮箱可写且邮箱不冻结空队列。实施固定采用裁决 A：

```text
保留：完整消息交付、时效复核、类型分类、停止优先、入口拒绝、内部错误
删除：分类层重复材料普通分账、幂等冲突普通分账、空批次成功
禁止：新增第二输入来源或修改邮箱协议
```

## 5. 实施步骤

1. 保留执行侧已经完成的完整冻结批次 move 接管、分类 DTO 归位、领域重复骨架删除、自我线程同实例调用和合法测试迁移。
2. 删除分类函数的批内 `已处理消息`、同幂等键查找、同任务最新序号重建；准入上下文只填写当前分类时间。
3. 删除 `空批次`状态；身份合法后观察到空消息组返回 `内部错误`和空载荷。
4. 将 `存在具名拒绝`收窄并改名为 `存在时效拒绝`，只接受分类时过期或发生时间仍在未来；重复、幂等冲突、顺序拒绝、其它静态协议拒绝和内部不一致全部升级为 `内部错误`且不交付部分治理输入。
5. 保持邮箱冻结顺序完成唯一类型映射；停止输入形成 `停止优先`并截断后继。
6. 自我线程按 `已分类 / 存在时效拒绝 / 停止优先 / 入口拒绝 / 内部错误`分流；普通输入仍止于未实现的 002-04。
7. 调整治理端到端测试，只覆盖合法邮箱可达矩阵；不得访问私有队列 / 冻结字段或建立测试专用第二输入源。
8. 形成函数级知识变更清单和 v0.2 施工 / 验证记录。
