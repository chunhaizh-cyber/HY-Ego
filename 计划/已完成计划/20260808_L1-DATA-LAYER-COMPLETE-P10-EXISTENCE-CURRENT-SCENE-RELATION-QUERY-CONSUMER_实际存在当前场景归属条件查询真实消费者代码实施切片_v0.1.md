## 1. 目标与依据

本计划只实现一个真实第二层消费者已经需要的中性查询闭环：第一层按目标节点和关系类型返回当前关系有序组；既有场景结构服务用该组判定初始场景接纳的零 / 一 / 多和精确归属。

第一层不自证。代码发布只形成候选；随后由生产代码外合法第二层消费者经正式会话、有效租约和既有领域服务实际创建、读取、退出、再读取，累计证明一项到零项的条件查询行为。单条路径不证明整个第一层完善。

正式依据：0050、4015 v0.5、4030 v1.3、4200 v1.2、ACCEPTANCE-01 v0.3、CODE-FILE-01，以及：

- `规范/详细设计/20260808_L1-DATA-LAYER-COMPLETE-P10-EXISTENCE-CURRENT-SCENE-RELATION-QUERY-CONSUMER_实际存在当前场景归属条件查询真实消费者详细设计_v0.1.md`
- `流程图/20260808_L1-DATA-LAYER-COMPLETE-P10-EXISTENCE-CURRENT-SCENE-RELATION-QUERY-CONSUMER_读取初始场景接纳唯一关系函数流程图_v0.1.md`

## 4. 实施步骤

### 4.1 中性合同与服务

1. 在 `L1中性CRUD.数据.h` 按详细设计 §4.1 新增 `L1中性目标关系读取请求` 和 `L1中性目标关系读取结果`；不提升合同版本，不修改现有 DTO。
2. 在 `L1事实基座服务` 新增唯一 const `读取中性当前目标关系组`；合同版本或编码无效返回入口拒绝、代次零、空组。
3. 服务入口只调用仓库对应条件查询并保持目标、类型、状态、代次和关系组；资源异常映射资源失败，其它异常映射内部不一致，所有非成功结果关系组为空。

### 4.2 仓库派生索引

4. 在仓库 `状态` 中新增目标 + 关系类型到当前关系编码有序组的业务中性派生索引。索引只存稳定编码，不复制关系事实字段或生命周期。
5. 建立纯值桶插入、桶删除和从权威当前关系进程内派生 helper。插入后严格升序且无重复，删除后空桶清除。
6. 在中性提交候选的新关系循环中同步插入索引；在关系退出分支中以退出前关系的目标和类型同步删除索引。
7. 在 legacy 提交候选的关系新建和关系退出分支做同样维护。不得建立第二索引、第二仓或第二发布。
8. 扩展 `状态完整`：权威当前关系与派生索引必须双向恰一对应，所有桶严格升序、无零编码、无重复、无空桶。
9. 既有状态材料转状态若必须适配新增状态字段，只允许在当前关系已经形成后调用同一纯进程内派生 helper；不得修改恢复 DTO、材料格式、入口、状态或测试，也不得把恢复作为完成门。

### 4.3 仓库条件查询

10. 新增仓库 const 条件查询：请求有效后取得一次既有共享锁，只查请求目标 + 类型桶。
11. 桶不存在返回成功空组和当前事实代次；桶存在则按编码逐项回读 `当前关系`，验证编码、目标、类型、当前性和严格升序。
12. 逐项复制完整中性关系事实；任一桶 / 权威矛盾返回内部不一致和空组。查询不得调用 `状态完整`、全量派生、完整快照、历史、审计、恢复、SQL、旧管理索引或日志。

### 4.4 第二层消费者

13. 保持 `读取初始场景接纳` 的公开请求、结果、锁、构造和调用者不变，只修改模块内部 `读取接纳实现`。
14. 保留场景、成员、关系类型和首末当前代次读取；删除该函数对精确 `读取中性当前关系` 的调用及“精确归属已退出”特殊分支。
15. 恰一次调用 `读取中性当前目标关系组`，请求目标为成员、类型为登记直接成员关系类型。
16. 第一层非成功按现有状态映射；成功空组返回未找到；成功多项返回内部不一致；成功一项时验证请求归属关系编码、初始场景源端、成员目标端、登记类型、角色零、未退出和创建代次。
17. 唯一关系的查询条件字段若与第一层回显矛盾返回内部不一致；只是与调用方请求的业务归属不一致返回未找到。
18. 场景、成员、类型、关系组和结束代次必须与起始代次同一非零截止；漂移返回版本漂移，不拼接部分事实。
19. 成功沿用既有 `初始场景接纳事实` 和已读取状态；不新增第二层 DTO、缓存或日志判定。

### 4.5 记录

20. 写专属施工记录，逐文件记录实际改动、仓库不变量和未覆盖范围。
21. 写专属构建与生产链验证记录；只能记录真实运行结果，不写“第一层自证通过”或“第一层已完善”。

## 5. 状态与不变量矩阵

| 场景 | 第一层结果 | 第二层结果 | 权威变化 |
| --- | --- | --- | --- |
| 无效合同或零编码 | 入口拒绝、空组 | 入口拒绝 | 零 |
| 合法目标 + 类型零命中 | 成功、当前代次、空组 | 未找到 | 零 |
| 恰一项且匹配初始场景接纳 | 成功、有序一项 | 已读取及完整事实 | 零 |
| 恰一项但不是请求归属 | 成功、有序一项 | 未找到 | 零 |
| 多于一项当前直接归属 | 成功、有序多项 | 内部不一致 | 零 |
| 索引编码缺失或条件不符 | 内部不一致、空组 | 内部不一致 | 零 |
| 跨调用事实代次漂移 | 每次单读可成功 | 版本漂移 | 零 |
| 资源异常 | 资源失败、空组 | 资源失败 | 零 |

索引维护失败发生在候选状态内，权威状态不得交换。关系创建和退出发布后，权威当前关系与索引在同一次状态交换后可见。
