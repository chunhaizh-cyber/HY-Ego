## 1. 目标和完成条件

在任务 owner 内实现一类挂到任务虚拟存在的强类型`任务子目标承接记录`，提供建立、绑定已发布子需求、登记回流、退出、按身份当前 / 历史读取以及按任务与筹办轮次有界组读取的公开结构合同。

本计划完成必须同时满足：

1. 记录完整绑定任务、任务虚拟存在、筹办轮次、显式父需求、采用方法 / 版本 / 主轴 / 条件、子目标、来源截止 G 和建立幂等身份；
2. 三状态只能按`待绑定子需求 -> 等待子需求 -> 子需求已回流待父需求重判`前进；
3. 四个写入口均由任务 owner 的一个原子写集发布，旧状态 / 关系同代退出并保留历史；
4. 同键同完整请求精确重复、同键异请求幂等冲突；外层首个 G 读取报告漂移时必须转入首次写入材料收敛，不得提前返回；
5. 显式父需求当前属于来源任务的需求列表项；子需求绑定时父关系和目标精确互证；
6. 回流登记只形成待父需求重判记录，不直接唤醒来源任务，不建立重筹办轮次；
7. 普通应用持有唯一结构服务，专项经 getter 覆盖可运行矩阵；
8. 施工 / 验证记录明确区分动态 PASS、源码静态证明和`NOT_RUN`。

## 7. 实施步骤

### S1：数据头与静态守恒

1. 新建数据头，定义合同版本、身份、状态、材料、记录、请求和结果；该头使用`#pragma once`和`L2_TASK_SUBGOAL_ACCEPTANCE_RECORD_NO_INCLUDES`条件包含守卫；
2. 只在`服务.L2任务结构.ixx`的导出块中、`L2任务结构.数据.h`之后恰好一次包含新数据头；新结构服务只从任务模块取得本记录 DTO 和受限端口，并直接导入需求、方法、状态、特征、动态五个公开服务模块；禁止再次包含新数据头、建立 header unit / 模块分区、让任务模块反向导入新服务或形成第二 DTO 导出面；
3. 为全部纯值请求、事实和结果建立中文命名守卫；
4. `static_assert`穷尽三个状态和现行全部`L2结构状态`映射；
5. 非成功结果清空记录 / 组载荷，预算不足不返回截断组。

### S2：任务 owner 类型登记与投影

1. 按详细设计第 6.4 节为记录节点、任务组关系、任务 / 虚拟存在 / 父需求 / 方法 / 主轴 / 条件 / 目标 / 子需求 / 回流引用及全部属性建立唯一内部类型和本地键；
2. 不复用任务治理状态、路径或实例方法的类型身份；
3. 实现指定截止的完整记录投影，严格验证基数、端点、属性表示、生命周期和状态守恒；
4. 实现任务 + 轮次有界组读取，按记录身份排序，扫描 / 返回预算分别计数。

内部本地键数值只允许从任务 owner 当前未占用区间选择，并通过静态唯一性检查；本地键不是公开机器语义，禁止写入 DTO、日志或测试断言。

### S3：完整写集与旧 G 收敛

1. 建立记录：节点、关系、属性和建立幂等身份一次发布；
2. 绑定子需求：旧状态值退出、新状态值和子需求引用同代发布；
3. 登记回流：等待状态退出、回流状态和完整回流引用 / 属性同代发布；
4. 退出：节点和全部当前关系 / 值同代退出；
5. 每个写入口先按 owner + 幂等身份读取首次写入材料；建立请求直接按请求重建预期写集，绑定 / 回流 / 退出按请求 G 的记录历史投影取得当时前驱稳定编码后重建，逐项比较原完整规范化写集并从首次结果代次历史读回；
6. 外层首个 G 读取报告漂移后停止其余当前前驱读取；旧 G 首次材料未命中才返回漂移，不形成新编码；
7. 发布后读回矛盾返回内部不一致，不补写、不伪回滚。

### S4：跨服务公开验证

1. 建立入口按单函数图执行任务 / 虚拟存在、父需求列表成员、完整列表项、完整父需求和完整方法互证；
2. 绑定入口读取子需求当前父关系和父子完整需求；随后调用`读取需求成员列表(子需求)`，从唯一当前成员关系取得列表项身份，再调用`读取需求列表项完整`，逐字段互证成员关系端点、所属存在和目标三元组；
3. 回流入口必须重新执行与绑定相同的`成员关系 -> 列表项身份 -> 完整列表项`链，再读取实际状态及其完整特征实例、可选动态和可选子任务归属；可选子任务的需求列表项必须等于该链本次取得的当前列表项，状态主体 / 特征及动态后状态必须与记录子目标结构一致；
4. 绑定 / 回流中，当前成员关系成功空、复义、关系端点自相矛盾、关系指向列表项未找到 / 已退出、完整列表项身份回显不等或子需求与其列表项核心契约矛盾，唯一映射`内部不一致`；子需求 / 列表项彼此一致但与记录父需求所属存在或冻结子目标不一致，唯一映射`引用冲突`；
5. 每个入口指定一个首个 G 读取：建立为任务，绑定 / 回流 / 退出为记录；首读报告漂移或截止不等于 G 时把原请求交端口做旧 G 收敛，禁止直接向上返回；
6. 所有跨服务非成功逐项映射，未知成功形状统一内部不一致。
