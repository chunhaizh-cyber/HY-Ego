## 4. 必须成立的不变量

- 集合身份 S 稳定，成员只挂在不可变版本 V；一个当前 S 恰一当前 V。
- 换代一次写集同时新增新版本全量结构并退出旧当前关系，禁止部分成功。
- 每版非空、成员唯一、顺序连续、角色非零且不超 provider 预算。
- 成员是同截止完整当前普通一次特征节点；派生定义、集合节点、裸 L1 节点均拒绝。
- 集合无原始值、无阶次递增、无分类 / 概念 / 算法字段。
- 当前 / 历史 / 反向结果同截止闭合；坏成员或坏关系不被跳过。
- 精确重复零新代次；同键异义冲突；已可能发布只原请求原键重放。
