## 6. 错误映射和恢复

新增完整列表项读取的精确映射：

| 底层状态/形状 | 公开状态 |
| --- | --- |
| 回显非 G0、`事实代次漂移` | `当前性漂移` |
| `未找到`、`已退出`、`属性未设置` | `内部错误`，因为当前成员关系已经引用该当前列表项 |
| `入口拒绝` | `入口拒绝` |
| `许可拒绝` | `许可拒绝` |
| `引用冲突`或完整列表项身份与成员端点不一致 | `引用冲突` |
| `资源失败`、`数量预算不足` | `资源失败` |
| 状态已读取但成功谓词不成立、载荷缺失、未知状态或异常 | `内部错误` |

所有非成功零裁决；不得退回简化列表项继续，不得刷新 G0 或内部重试。
