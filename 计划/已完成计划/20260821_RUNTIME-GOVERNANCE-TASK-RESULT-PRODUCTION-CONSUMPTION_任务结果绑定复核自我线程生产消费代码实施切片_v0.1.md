# 任务结果绑定复核自我线程生产消费代码实施切片 v0.1

计划身份：`RUNTIME-GOVERNANCE-TASK-RESULT-PRODUCTION-CONSUMPTION`

日期：2026-08-21

## 1. 目标与完成条件

按同名详细设计机械实施，把已经正式退出的 002-04 接入真实 `自我线程::运行治理循环()`：

1. 真实任务结果治理消息经自我线程唯一邮箱和批次路由进入 002-03；
2. 自我线程持久处理槽保存原批次、路由项、G0、复核状态和重试材料；
3. 任务结果分支调用 002-04，成功后冻结唯一任务实际结果后继输入；
4. 合法等待和资源失败只重试同一槽，当前性漂移选择结构化终止；
5. 生产专项经过真实队列、批次路由和物理自我线程形成正式证据；
6. 发布源码、施工/验证记录并登记退出。

## 4. 实施顺序

1. 在自我线程数据合同中增加任务结果成员预算、处理槽状态、后继输入、槽快照和专用退出结果；
2. 在自我线程类增加生产消息提交、槽快照等待和显式同槽重试入口；
3. 建立唯一私有当前批次处理槽，把冻结结果移动入槽并恰一次分类；
4. 在其它尚未完成治理骨架之前处理任务结果路由项，调用 002-04 并按详细设计映射全部状态；
5. 成功时冻结唯一后继输入，不调用 002-05，不清槽、不推进完整批次成功游标；
6. 在普通应用自我线程创建前装配现有运行期只读查询组合器，并显式设置预算 64；
7. 扩展治理专项，经真实物理自我线程、真实邮箱、批次路由和处理槽验证成功、重复、合法等待同槽重试和旧 G0 终止；
8. 完成双配置 Rebuild、两配置治理专项、strict、diff、精确范围、记录和函数级知识变更清单。

## 5. 机械门禁

- 生产成功验证不得直接调用 002-04，必须从 `自我线程::提交治理消息`开始并读取正式槽快照。
- 合法等待或资源失败重试时，批次身份、治理消息编号、幂等键、任务和 G0 必须保持不变，复核次数严格增加；禁止再次读取邮箱或再次分类。
- 当前性漂移固定结构化终止，不重取新 G0。
- 只有 002-04`已绑定`且全部字段互证通过才形成后继输入；其它状态后继必须为空。
- 后继输入不是 002-05 请求，不得调用 002-05/06、任务完成、需求满足、结算或学习入口。
- 其它治理输入继续沿既有未完成路径；不得把本叶结果升级为完整 T02。
