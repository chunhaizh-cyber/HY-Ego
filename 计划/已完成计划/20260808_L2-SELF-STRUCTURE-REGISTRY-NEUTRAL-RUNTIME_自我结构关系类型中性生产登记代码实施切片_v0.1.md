## 4. 目标接口与实施合同

### 4.1 DTO

新数据头冻结：合同 / 规则版本 1、十类结构化状态、低 56 位非零幂等身份、登记请求、包含服务身份与关系类型的不可变登记、结果和完整性函数。全部结构值式拥有，不保存仓库、锁、指针、候选或写能力。

### 4.2 领域服务

```cpp
class L1自我结构登记服务 final {
public:
    explicit L1自我结构登记服务(L1事实基座服务& L1) noexcept;
    自我结构登记结果 建立登记(const 自我结构登记请求& 请求);
    自我结构登记结果 读取当前登记() const;
};
```

建立登记固定：

1. 私有幂等域 `0x1B`；
2. 两个普通节点，本地键 1 / 2；
3. 关系、值、属性槽和退出项均为空；
4. 恰一次中性提交；
5. 只接受成功或精确重复；
6. 新编码映射恰两项且互异；
7. 按写入截止一致读取两个节点；
8. 逐字段一致后发布局部定位并返回完整登记。

当前读取必须深复制定位后调用正式一致当前投影；定位或缓存不得直接作为成功事实。

### 4.3 生产接线

固定配置新增 `{1}` 自我结构登记幂等身份并纳入有效性与等值。

运行期上下文唯一拥有服务，提供初始化、当前读取、完整判断及 const / 非 const 访问器。候选 `完整()` 重新读回登记并与此前全部新数据登记互证共同截止。

生产启动在实例特征登记成功后、旧系统角色初始化前恰一次建立登记。非成功停止后继与候选发布；结构化启动结果新增该领域状态，未执行阶段保持入口拒绝。

工程与 filters 只登记两个新源码路径，不建立第二目标或验收模块。

## 5. 失败收口

- 入口无效：零第一层调用、零状态变化；
- 事实代次漂移、许可拒绝、资源失败和幂等冲突：保留结构化状态，不局部补造；
- 写入成功后映射或读回矛盾：返回内部不一致，生产候选不得发布；
- 已有局部登记与新结果不等：内部不一致；
- 构建或运行失败：只在九路径范围内归因和修复，无法收敛则保留现场具名退回。
