日期：2026-08-15

## 1. 目标与完成条件

按同名详细设计，在唯一 `L2特征结构服务` 增加当前值独立退出公开 ABI。一次特征实例 owner 写集只退出具名当前值并同代移除属性槽；实例、自有关系和历史值保持。

完成条件：公开请求 / 结果 / helper / 服务函数存在；首次与精确重复成功形状完整；未设置、错当前引用、漂移和幂等冲突分账；生产双配置可构建，公开入口施工检查通过，临时验证代码已清理。

## 4. 精确施工合同

逐字实现详细设计第 3—5 节冻结的：

- `L2特征当前值退出请求`；
- `L2特征当前值退出结果`；
- `L2特征当前值退出请求有效(...)`；
- `L2特征当前值退出结果::成功()`；
- `L2特征结构服务::退出特征当前值(...)`。

使用现有特征实例 owner、端口、值类型登记、完整实例读取、历史值读取、幂等映射和 L1 退出事实；不得修改既有值新增 / 换代或实例退出语义。

## 5. 实施步骤

1. 在数据头追加 DTO、helper 和成功谓词。
2. 在服务内部追加失败结果形成和一次提交 / 读回所需私有辅助。
3. 在公开服务原位实现值退出函数，保持一次 owner-scoped 写集和原请求幂等。
4. 运行根工程 Debug / Release 构建与生产外公开入口检查。
5. 写施工与施工检查记录；删除临时代码和输出；复核生产零验证痕迹。

## 6. 验证与成功门禁

至少运行：

```powershell
git diff --check
git diff --cached --check
python .\tools\check_specs.py --strict
```

公开入口检查覆盖详细设计第 7 节可合法构造的全部分支；真实资源耗尽、私有损坏和发布未知无法稳定构造时记 `NOT_RUN`，不得增加 seam。

成功门禁：仅两生产文件和两永久记录属于本计划；根工程及专项 Debug / Release 通过；diff、strict、UTF-8 和生产零验证痕迹通过；仓库内外临时资源不存在。

## 7. 停工与声明边界

若当前 L1 退出值不再同代清除引用它的属性槽，或现行特征实例完整读取不能在写入截止证明“实例当前且当前值为空”，属于真实接口漂移并退回计划支撑。普通编译、算法和检查错误由执行者在白名单内修复。

本叶退出不证明状态 / 动态 / 因果条件查询、世界树 / 概念空间聚合、正式消费者适用性或《数据服务最终需求清单》整体完成。
