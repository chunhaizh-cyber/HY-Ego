1. 错合同、零守卫、零来源、零预算分别入口拒绝且零载荷；
2. 当前来源存在但无状态时成功空组；
3. 同来源一个 / 多个状态完整读回并按状态身份严格升序；
4. 不同来源严格隔离；
5. 每个候选的精确值与时间值角色配对、所属状态和来源逐字段互证；
6. 状态预算等于数量成功，少一返回数量预算不足且零载荷；
7. 来源未找到、已退出与陈旧守卫分账；
8. 状态退出后不再命中，既有历史读取仍保持；
9. 读取前后事实代次不推进；
10. 既有按主体 / 特征实例当前状态组读取和单状态当前 / 历史读取保持。
