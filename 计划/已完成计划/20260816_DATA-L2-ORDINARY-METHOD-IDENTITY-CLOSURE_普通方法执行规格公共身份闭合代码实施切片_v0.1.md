## 4. 生产实体与 helper

严格按详细设计字段顺序和显式构造实现：

```text

L2方法结果身份
L2方法动作入口身份

L2方法规格版本
```

实现六个头内 `inline bool ... noexcept` helper：

```text
L2方法治理虚拟存在身份有效
L2方法条件身份有效
L2方法结果身份有效
L2方法动作入口身份有效
L2方法内容版本有效
L2方法规格版本有效
```

四种节点身份包装 `稳定编码` 且彼此、与 `L2方法身份` / `L2存在身份` 不可隐式转换；两种版本包装非零 `uint64_t`，不得包装稳定编码、事实代次、生命周期顺序或任务轮次。不得增加作用对象槽、动作键、参数、禁止项、请求 / 结果或服务入口。
