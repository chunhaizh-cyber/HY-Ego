## 1. 目标与完成条件

按同名详细设计，在唯一 `L2状态结构服务` 中实现 I64 抽象目标状态合同结构类型登记、独立强类型身份、增改退和当前 / 历史完整读取，为 DATA-EXT-12 需求结构提供可引用但不代替业务满足判断的目标合同。

完成条件：目标合同由现有状态 owner 单事务发布；身份不与实例状态混用；特征定义、目标判断比较注册、目标材料、允许关系、首次请求见证、来源和生命周期可同截止读回；替换 / 退出闭包与引用保护成立；根工程双配置构建和静态合同检查通过；专属记录发布。

## 4. 精确施工合同

逐字段实现详细设计第 3—7 节冻结的：

1. `L2目标状态合同身份`、允许关系位、结构类型登记、事实、CRUD 请求 / 结果和纯值 helper；
2. 状态 owner 内独立的四节点结构类型登记，不改变实例状态登记；
3. 新增固定 1 节点 + 2 关系 + 2 值 + 2 槽，且零状态族归属；
4. 写前按同一守卫正式读取完整特征定义和唯一当前目标判断 I64 比较注册；
5. 替换建立新身份并同代退出旧闭包，退出精确闭合两关系两值并服从 L1 当前引用保护；
6. 当前 / 历史完整读取及同截止特征 / 比较注册互证；
7. 全部结构化状态、幂等、漂移、异常映射和中文公开命名。

目标合同只保存目标材料和判断合同，不调用 `比较特征(...)` 形成满足结论。需求等合法消费者以后读取当前事实和目标合同，再调用比较能力并自行解释允许关系。

## 5. 实施步骤

1. 从索引绑定的最新正式 HEAD 重做 S0，核对依赖计划结果、状态 / 特征实际 ABI、目标文件、Git index、唯一代码段和构建资源。
2. 在 `L2状态结构.数据.h` 增加对特征数据合同的单向包含及全部目标合同 DTO / helper；保持公共身份和节点族零变化。
3. 在 `服务.L2状态结构.ixx` 私有区增加目标合同类型登记、固定向量编解码、投影组装、状态映射和幂等域。
4. 实现类型登记建立 / 当前读取、目标合同新增 / 替换 / 退出和当前 / 历史完整读取。
5. 核对目标合同节点无状态族归属、无实例状态主体 / 特征实例关系和无实例状态精确 / 时间值槽。
6. 运行根工程 Debug / Release、静态合同、UTF-8、diff、strict、白名单和生产零验证痕迹检查。
7. 形成施工与施工检查记录，只记录实际证据和 `NOT_RUN` 边界。

## 6. 验证与成功门禁

至少运行：

```powershell
git diff --check
git diff --cached --check
python .\tools\check_specs.py --strict
```

另须根工程 x64 Debug / Release Rebuild。静态检查至少覆盖：

- 目标合同身份与 `L2状态身份` 不可互换，节点族枚举零变化；
- 结构登记固定四节点且实例状态登记零变化；
- 新增、替换、退出的固定写集和完整闭包；
- 目标判断 I64 注册、左右角色、用途和具名关系输出能力；
- 允许关系位 1—7、零 / 未知位拒绝及 I64 极值材料；
- 同键重复 / 异义、零变化漂移和原完整请求重放边界；
- 当前 / 历史读取同截止、已退出历史、半结构 / 混形状拒绝；
- 特征定义和比较注册退出受当前目标合同引用保护；
- 普通应用、聚合、工程、特征文件和生产验证 seam 零差异。

不建立永久专项或独立验收工程。真实资源失败、发布未知、跨 owner 竞争、需求消费和满足裁决由合法消费者实际使用时判断，未运行项诚实保留 `NOT_RUN`。

## 7. 激活、停工与声明边界

本计划登记时保持 `待激活`，至少等待：

1. `DATA-L2-FEATURE-I64-COMPARISON-REGISTRY-AND-COMPARE v0.1` 真实结果发布、索引退出和两个特征文件释放；
2. 当前 EVENT 专项清理完成并明确释放唯一代码段、构建资源和 Git 发布租约；
3. 两个状态生产文件及 index 无重叠所有者；
4. 执行者从最新正式 HEAD 确认现有状态 owner 写端口可形成详细设计的固定写集，特征服务最终 ABI 与预冻结合同机械一致。

若最终比较注册类型 / 读取签名改变、状态 owner 无法承载专属登记结构、L1 不能保护跨 owner 当前引用，或完整读取无法在同一守卫互证特征与比较注册，属于真实设计漂移并具名退回计划支撑。普通编译和局部实现错误由执行者在白名单内修复。

本叶完成只证明 I64 抽象目标状态合同 CRUD，不证明需求 CRUD、任务 CRUD、目标满足、方法成功、DATA-EXT-12 或《数据服务最终需求清单》整体完成。
