日期：2026-08-15
版本：v0.1
计划身份：`DATA-L2-FEATURE-CURRENT-VALUE-READ`

## 1. 目标与完成条件

按同名详细设计，在唯一 `L2特征结构服务` 增加具名当前值读取 ABI，复用现有完整实例当前读取并把“实例存在但当前值为空”明确映射为 `属性未设置`。

完成条件：公开请求 / 结果 / helper / 服务函数存在；成功只返回同截止完整当前值；未设置、实例读取失败和坏成功形状分账；生产双配置构建及静态合同检查通过；专属记录发布且不建立独立专项验收。

## 4. 精确施工合同

逐字实现详细设计第 3—5 节冻结的：

- `L2特征当前值读取请求`；
- `L2特征当前值读取结果`；
- `L2特征当前值读取请求有效(...)`；
- `L2特征当前值读取结果::成功()`；
- `L2特征结构服务::读取特征当前值(...) const`。

入口只委托现有 `读取完整特征实例(...) const`，不得直达 L1、复制完整实例投影、改变现有读写语义或增加第二当前值解释。

## 5. 实施步骤

1. 在数据头追加 DTO、请求 helper 和成功谓词。
2. 在服务私有区域追加统一失败结果形成函数。
3. 在公开服务原位实现当前值只读委托、未设置映射和坏形状拒绝。
4. 运行根工程 Debug / Release 构建和静态合同检查。
5. 写施工与施工检查记录，复核白名单、UTF-8、diff、strict 和生产零验证痕迹。

## 6. 验证与成功门禁

至少运行：

```powershell
git diff --check
git diff --cached --check
python .\tools\check_specs.py --strict
```

另须完成根工程 x64 Debug / Release Rebuild；静态检查必须覆盖 DTO 字段、helper 非零守卫、成功谓词、服务签名、只委托完整实例读取、未设置状态和零生产 seam。

不新建动态专项或业务消费者。构建与静态检查只证明本叶编译和静态合同；真实运行分支留给合法消费者实际使用时判断。

## 7. 停工与声明边界

若现行 `读取完整特征实例(...)` 不再能在一个非零守卫下返回同截止可选当前值，或目标两生产文件被其它活动切片取得所有权，属于真实漂移 / 冲突并停止受影响切片。普通编译和局部实现错误由执行者在白名单内修复。

本叶完成只证明 DATA-EXT-03 的具名当前值读取 ABI，不证明其它 DATA-EXT、普通应用消费或《数据服务最终需求清单》整体完成。
