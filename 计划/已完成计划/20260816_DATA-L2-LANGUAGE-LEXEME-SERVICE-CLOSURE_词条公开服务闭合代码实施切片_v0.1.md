## 1. 目标

## 4. 目标函数

```cpp
L2词条新增结果 新增词条(const L2词条新增请求&);
L2词条退出结果 退出词条(const L2词条退出请求&);
L2词条读取结果 读取词条(const L2词条读取请求&) const;
L2词条按规范化键读取结果 按规范化键读取词条(
    const L2词条按规范化键读取请求&) const;
```

词条规范化键固定为语言身份、规范化合同材料和严格 UTF-8 规范化词面材料。没有词条替换入口；键或来源改义建立新身份。

四个公开函数均为现有唯一 `L2语言结构服务` 的导出成员，向上送出结构化非成功；四类结果 `成功()`、六个纯值守卫和失败结果 helper 为无适用错误分支。owner 交付工厂、登记 / 核心读取、首次重放和双交付验证向上送出，不逐层重复记录。全部模块内部函数名、签名、插入文件和技术身份以详细设计 5.1、6 为唯一冻结依据，不得临场新增导出 ABI。

## 5. 实施步骤

1. 在语言头增加词条完整事实、请求、结果、规范化键和纯值 helper；保持既有语言 ABI 与行为不变。
2. 在语言服务模块增加不可交换的词条 owner 交付和私有登记；扩展服务构造以同时接收语言 / 词条交付并验证同一 L1。
3. 实现词条新增、退出、身份读取和键读取；完整复用材料服务、语言当前 / 历史读回、L1 首次写集、引用保护和共同截止。
4. 建立仓库外材料根和生产外专项，覆盖详细设计矩阵；不得登记生产工程。可在专项及四个公开函数入口设置调试器断点逐项检查参数和返回，但不得修改启动、入口、普通应用或其它生产源码建立验证调用。
5. 运行根工程 x64 Debug / Release fresh Rebuild、strict、XML、UTF-8、diff、白名单、唯一登记和生产零测试痕迹检查。
6. 清理专项实际文件，写入专属记录，只暂存本计划四文件，普通提交并推送。
