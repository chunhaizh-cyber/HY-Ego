## 1. 目标和完成条件

建立独立 L1 通用事实基座：节点、关系和值共用一个全局不可复用稳定编码；关系承载节点图拓扑；普通属性由节点唯一属性槽直接指向值；一次完整写集只在最后原子发布一个事实代次。

公开接口必须同时闭合：

```text
当前节点 / 关系 / 值读取
当前属性读取
历史事实读取
幂等审计读取
完整当前快照读取
恢复候选建立 -> 确认发布 / 撤销拒绝
```

完成条件是四个新 L1 文件进入工程，公开服务可提交、按四类路径读取、形成完整快照、建立并两阶段处理隔离恢复候选，专项矩阵和 Debug/Release 完整自检均通过。此计划不接入运行期上下文，不删除或兼容转发旧基座。

## 4. 目标函数、DTO 和物理位置

### 4.1 数据头

`L1事实基座.数据.h` 唯一声明稳定编码、写集本地键、幂等键、`原始值材料` 四分支、节点 / 关系 / 值 / 属性槽、写集、写入结果、当前读取结果、属性读取结果、历史读取结果、审计记录 / 结果、完整快照 / 结果、恢复材料 / 结果及所有状态枚举。

数据头不持有锁、仓库、候选令牌、服务指针或领域类型；纯比较只验证字段完整性、排序、唯一性和跨 DTO 结构一致性。

### 4.2 仓库

`仓库.L1事实基座.ixx` 唯一拥有不可变当前状态、历史事实表、永久编码占用、幂等账、审计账和隔离恢复候选。仓库内部用一把 `shared_mutex` 保护状态；候选为隔离副本，失败销毁，成功一次替换。

仓库公开给同模块服务的最小操作必须覆盖：当前事实读、当前属性读、历史读、审计读、当前快照复制、普通写集候选 / 确认 / 撤销 / 发布、恢复候选建立 / 确认 / 撤销。不得导出内部表、锁、索引、可写引用或候选令牌。

### 4.3 服务

`服务.L1事实基座.ixx` 唯一拥有 `L1事实基座服务`，公开十一个函数签名固定为：

```cpp
L1写入结果 提交写集(const L1写集请求& 请求);
L1读取结果 读取当前节点(稳定编码 编码) const;
L1读取结果 读取当前关系(稳定编码 编码) const;
L1读取结果 读取当前值(稳定编码 编码) const;
L1属性读取结果 读取当前属性(稳定编码 节点, 稳定编码 属性类型) const;
L1历史读取结果 读取历史事实(稳定编码 编码) const;
L1审计读取结果 读取审计(写集幂等键 幂等键) const;
L1完整快照结果 读取完整快照() const;
L1恢复结果 建立恢复候选(const L1恢复材料&, std::uint64_t 期望事实代次);
L1恢复结果 确认恢复候选();
L1恢复结果 撤销恢复候选() noexcept;
```

当前、历史、审计、快照结果不得互换；所有非成功结果不带部分业务事实。确认恢复候选是唯一恢复发布入口；撤销恢复候选是显式拒绝发布入口。

### 4.4 自检、工程和入口

`自检.L1事实基座.ixx` 只通过服务公开面覆盖 P0 矩阵。`启动.应用程序.ixx` 只 import 自检并以唯一顺序 270 登记 `L1-SIMPLIFY-P0-S01`。工程 / filters 只登记四个新 L1 模块和专项自检。

## 6. 全分支事务与错误合同

| 分支 | 当前事实 | 候选 / 账 | 返回 |
| --- | --- | --- | --- |
| 写前入口拒绝 | 不变 | 不建立 | 入口拒绝 |
| 同键同义 | 不变 | 不重复发布 | 精确重复 + 原结果 |
| 同键异义 | 不变 | 候选销毁并保留审计 | 幂等冲突 |
| 普通候选 / 确认失败 | 不变 | 逆序撤销 | 结构化非成功 |
| 普通最后发布成功 | 一次推进代次 | 记录成功审计 / 幂等账 | 成功 + 编码映射 |
| 当前读取首末漂移 | 不变 | 不返回混代 | 事实代次漂移 |
| 恢复材料不完整 | 不变 | 零候选 | 材料不完整 / 内部不一致 |
| 恢复候选建立成功 | 不变 | 保存隔离候选 | 候选已建立 |
| 恢复确认代次漂移 | 不变 | 丢弃候选 | 事实代次漂移 |
| 恢复确认成功 | 一次替换并推进代次 | 记录恢复发布审计 | 恢复已发布 |
| 恢复撤销 / 拒绝 | 不变 | 丢弃候选 | 候选已撤销 / 无候选 |
| 发布后读回矛盾 | 不静默回滚 | 进入隔离 | 内部不一致 |

持锁期间禁止调用领域、日志、SQL、文件、回调和其它服务；`bad_alloc` / `length_error` 为资源失败，其它异常为内部不一致。

## 7. 验证矩阵

### DTO / 字段来源

1. 稳定编码非零、永久占用、创建 / 退出代次和四种原始材料形状；属性类型表示与值材料分支匹配。
2. 当前事实、当前属性、历史事实、审计记录、完整快照、恢复材料和恢复结果字段逐项存在且 optional / 空载荷规则一致。
3. 恢复材料当前 / 历史 / 审计 / 幂等四账不重复、不缺项，永久占用覆盖全部编码。

### 提供者—消费者

1. 数据头只提供值式 DTO / 谓词；仓库只提供最小结构操作给服务。
2. 服务只消费仓库公开操作；自检只消费服务公开面；无其它模块取得锁、候选或内部表。
3. 当前、历史、审计、快照和恢复结果类型不混用；旧基座 import / include 零命中。

### 事务 / 读回

1. 多值、多关系、属性替换、关系替换和旧事实退出在一个普通写集中原子发布。
2. 同键同义 / 异义、版本漂移、入口拒绝、资源失败、候选撤销和发布后读回均有精确分类。
3. 当前读取首末代次重试一次；历史读取可返回已退出记录；审计读取不返回事实；完整快照不返回历史 / 审计。
4. 恢复缺项、编码重复、槽矛盾、关系断裂、代次无序、幂等 / 审计冲突均零发布；确认漂移丢弃候选；撤销显式拒绝发布。

### 工程 / 完成边界

Debug / Release Rebuild、完整自检、严格规范检查、模块依赖、范围和旧依赖静态检查全部通过；自检总数 `N+1` 且顺序 270 唯一。不得声明运行期迁移、领域闭环、SQL / 材料持久化、生产接线或旧基座删除。
