# INSTANCE-FEATURE-IFR-L2-PROJECTION-READ 代码实施计划 v0.1

状态：可执行。基线：`def54a06`；直接依赖 `8d79cf4f` 的 v2 IF/R 布局。

## 目标

在 `存在类数据服务` 实现 IF/R 的同截止完整只读投影 `读取IFR结构`，供后续目标提交和 L3 分类使用。它只读取存在 owner 已有事实，不创建、退出或改写节点、关系、值、属性槽或当前采用。

## 冻结合同

新增纯值 DTO：节点/关系时态、R项身份及投影、完整 IF/R 投影、读取请求/结果。请求固定 `{版本=1,Gread,E,FT,F成员上限,R项上限,关系上限}`；成功为 `已读取`，要求 `Gread=H=请求Gread`、完整形状、关系和成员预算均未超。未找到、已退出、数量预算不足、事实代次漂移、引用冲突、资源失败、内部不一致均清空投影。

读取顺序固定：同截止核验 E；唯一 `E→IF`；IF 的成员 F 和唯一 `IF→R集合`；R集合的唯一当前 `R集合→版本`；版本的 R项；每项唯一材料属性槽和唯一材料值、R项形成成员。所有节点、关系和值必须属于存在 owner、类型/方向正确且在 H 活动。成员 F、形成成员严格编码升序；R项按编码排序；所有形成成员的并集恰等 IF 成员 F。材料必须是 v2 属性类型的 U64组，且能反序列化为规范化 `特征R区间材料`。

## 范围与验证

允许 `海中鱼巣/领域/数据服务.存在类.h` 与专属施工/验证记录。禁止提交 IF/R 写集、退出、L3、特征出生、规则调用、当前采用改写或 L1 ABI 修改。验证包括静态形状/零写扫描、Debug/Release隔离翻译和专属只读驱动；旧持久数据、跨进程恢复和完整应用启动为 NOT_RUN。
