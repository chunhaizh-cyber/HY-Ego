## 1. 已冻结的 P04.2 合同

1. 七个当前入口固定为 `确认当前{族}结构身份(G0 + 本族身份) -> L2结构结果头`。成功只表示 provider 已在同一 G0 确认本族结构当前，结果不回显身份、结构字段、生命周期或 owner。
2. 七个历史入口固定为按族具名的 `L2{族}身份来源历史见证读取请求 / 结果`和`读取{族}身份来源历史见证`。输入为非零 Gread、本族身份和非零 `H <= Gread`；结果回显 H，成功必须满足 `H == 结果头.事实截止代次`且包含完整 `L2节点族身份来源事实`。
3. 当前已退出在当前确认中先于错族分类返回`已退出`；历史对象在 H 前退出而闭包完整时仍成功回传完整见证。H 早于创建返回`未找到`；错族 / 裸 L1 / 保留元节点返回`入口拒绝`；已接受本族目标的来源闭包损坏返回`内部不一致`；守卫漂移、资源和异常按 4230 第 2.4 节处理。
4. 七个旧`读取{族}身份来源`的请求、结果、公开声明、定义和全部调用必须在同一个消费者迁移切片物理删除，不保留兼容壳或双入口。
