## 1. 目标和完成条件

按详细设计一次性退出旧句柄头和五份未接线安全候选源码，精确删除旧句柄头的两个工程登记单元，并用当前生产消费者归零、XML、隔离根工程构建和发布读回证明删除闭包。

完成必须同时满足：

1. 六份目标源码物理删除；
2. 主工程一行和 filters 一块旧句柄登记精确删除，除此之外工程差异为零；
3. 剩余生产源码没有对目标文件、模块或旧句柄身份的真实消费；
4. 删除前后隔离 Debug/Release x64 根工程 Rebuild均成功；
5. 两份专属记录形成，十项交付精确提交、普通推送并远端回读一致。

本计划可执行只表示删除合同已闭合；不证明代码已删、安全能力已重建或任何运行/业务结果成立。

## 2. S0 与选择门禁

执行者必须从计划索引读回本计划精确版本、plan/design blob和 `可执行` 状态，并记录：

1. `main`、HEAD、`origin/main`、ahead/behind、index及完整 dirty；
2. 六份目标仍受跟踪、无异主修改且 blob 等于详细设计第2.2节；
3. 两工程文件中的旧句柄登记仍各恰一项；
4. 场景所有者已经释放 `海中鱼巣.vcxproj` 和 `海中鱼巣.vcxproj.filters`，两文件相对正式 HEAD 不包含场景或其它异主差异；
5. 第4节组外消费者扫描仍只有允许命中；
6. 目标用途知识与当前源码互证，记录全部退出函数/类型的知识变更清单，但不修改共享知识。

计划发布提交可以位于代码事实起点之后；只要六目标 blob、两工程旧登记和正式依据未漂移即可执行。任一目标文件、模块合同或工程锚点变化时不得套用旧补丁。

所有权/构建资源暂时不可用只形成等待，不修改计划状态。真实组外消费者、目标 blob改变、工程锚点改变或正式依据冲突属于设计漂移，停止受影响范围并具名退回。

## 5. 机械实施步骤

1. 在 WIP 表登记第3节十个文件，取得唯一代码所有权；工程文件必须已有场景所有者的明确交接。
2. 在仓库外唯一目录导出正式 HEAD，执行删除前 Debug/Release x64 Rebuild并保存命令、工具链、输入提交和退出码。
3. 使用最小文件补丁物理删除六份源码。
4. 从 `海中鱼巣.vcxproj` 只删除 `<ClInclude Include="海中鱼巣\核心\句柄.h" />`。
5. 从 `海中鱼巣.vcxproj.filters` 只删除旧句柄头的完整三行 `ClInclude` 块；不修改任何 `ClCompile` 或场景项。
6. 执行路径、模块、旧身份、工程登记和 XML 静态验证；核对生产 diff恰为六删除和两个工程登记单元。
7. 从同一正式 HEAD 导出第二份隔离副本，只应用本包精确生产差异，执行删除后 Debug/Release x64 Rebuild；不得复制带异主 WIP 的工作树。
8. 运行差异和 strict 检查，写两份专属记录。施工记录列出六文件所有退出身份/函数、调用边变化、正式依据、验证状态及“没有替代当前提供者”的边界。
9. 取得唯一 Git 发布租约，确认 index空，只暂存第3节十项交付；执行 cached name/status/diff/check。
10. 精确提交并普通 push；回读本地/远端提交、六路径不存在、两工程登记不存在、index空；释放 WIP并通知交互智能体。

不得使用 `stash`、`reset`、`checkout`、`clean`、全文件覆盖或递归删除。目标六文件应使用逐路径删除补丁；临时验证目录仅在本轮专属根中按规则清理。

## 6. 工程精确差异合同

主工程最终只允许一项删除：

```xml
    <ClInclude Include="海中鱼巣\核心\句柄.h" />
```

filters最终只允许一块删除：

```xml
    <ClInclude Include="海中鱼巣\核心\句柄.h">
      <Filter>头文件</Filter>
    </ClInclude>
```

五份安全 `.ixx` 当前没有工程登记，禁止新增后再删除、伪造 `ClCompile` 删除或调整 filters。若 diff 包含 `合同.场景角色组织.ixx`、场景类、B包模块或任何其它工程项，本计划提交门禁失败。

### 7.2 隔离构建影响对比

验证根：

```text
D:\TEMP\海中鱼巣\SERVICE-LAYER-BOUNDARY-CLEANUP-A\<run-id>\
```

从 S0 正式 HEAD 导出 `before` 和 `after` 两份隔离源码；`after` 只应用本包八个生产路径差异。每份源码对 Debug/Release 使用独立 `IntDir`、`OutDir`，执行：

```powershell
MSBuild.exe .\海中鱼巣.vcxproj /m:1 /t:Rebuild /p:Configuration=Debug /p:Platform=x64 /verbosity:minimal
MSBuild.exe .\海中鱼巣.vcxproj /m:1 /t:Rebuild /p:Configuration=Release /p:Platform=x64 /verbosity:minimal
```

四次均须退出0。若 before失败，先归因正式基线；若 after新增失败且指向目标删除，修复不得超出本计划。隔离构建不消费工作区场景WIP，也不证明程序运行。
