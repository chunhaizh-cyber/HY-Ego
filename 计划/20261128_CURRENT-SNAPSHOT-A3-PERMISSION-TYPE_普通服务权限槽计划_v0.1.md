# CURRENT-SNAPSHOT-A3-PERMISSION-TYPE 普通服务权限类型提供者 v0.1

起点 f7bcaf6c1。依据 5380 §3.4、7160 先天槽、2100、4070 §5、4015 §15。用户已裁决正式服务权限为无符号整数并由正式 owner 管理。本窗口发布，persist_core_design 仅拥有特征概念恢复文件。

普通装配在已取得正式特征概念/特征值所有者且仍处于冷建候选时，使用现有 `建立或取得先天特征类型槽` 的 `服务权限` 槽。依当前正式实现和已有隔离对照，定义严格为 U64 数组、全材料域、完整材料精确、不自动聚合、无单位。使用现有具名概念所有者、特征值和正式概念身份列表。只发布并独立重读槽与类型；不创建实际权限 F/V、服务登记动作，不以网页身份绑定或服务对象写入为前置。既有槽时复用，形状/独立读回错误使装配失败，不绕过。

普通恢复复用特征概念所有者的已核键；沿真实槽记录按 `服务权限` 的具名语义定位并校验定义、直接概念父及现行实例计数字段形态，不能从 U64 空值或其它类型猜得。现有词典来源批次槽验证维持，结果增加 `服务权限类型根`。仅在当前候选内部核对，不调用已恢复宿主写入口。普通日志随已核结果投影槽根。尚不打开登记或网页；旧快照若缺槽明确拒绝，保持原字节。

允许 `装配.普通应用.cpp`、`领域/概念_特征类.cpp`、`领域/概念_特征.恢复.h`、`启动.应用程序.cpp` 和专属验证记录。Release x64，真实普通新库、独立重启、上一普通受控旧库拒绝与不改写；独立物理核对新槽、原类型/根、零现行实例计数。保持正式数据库不动，正常退出按阶段实报。正向服务对象登记另需实例所有者、原窗认知及普通持续持久写入。
