# 世界树应用服务核心代码实施计划

版本：v0.2

设计：[世界树应用服务核心详细设计 v0.2](../规范/详细设计/20260905_ARCH-L3-WORLD-TREE-APPLICATION-CORE_世界树应用服务核心详细设计_v0.1.md)

状态：已退出当前候选；等提供者链闭合后重新形成

基线：`8ce3298dedf4f7911b4023d8b8abf164facb240a`

## 1. 漂移结论

执行期退回问题已确认为设计漂移：v0.1 把场景/存在类已有的单关系 CRUD 包装成世界树 11 个公开入口，与用户要求和类所有权重复。该 ABI、原计划步骤和“只写一条关系即完成世界语义”的完成条件全部失效。任何执行者不得继续 v0.1，不得建立空模块或兼容壳。

## 2. 目标与未满足门禁

本计划的目标已改为实现详细设计 v0.2 冻结的 `ARCH-L3` 现实世界语义编排与完整读取。它只能在具名 DATA-L2 提供者全部发布后重新冻结精确 DTO、失败映射、续跑状态和允许文件。

当前最早缺口是 `DATA-L2-SCENE-MEMBER-ATOMIC-RELOCATION`。后续还需场景创建+接纳原子提供者、存在内部世界专用引用/读回、状态动态正式发布提供者。这些缺口不得由 ARCH-L3 临场直达 L1 或连续调用多次同 owner CRUD 伪装原子。

## 3. 预冻结实施边界

未来激活版只允许建立：

- `海中鱼巣/业务/应用服务.世界树类.ixx`、必要工程登记与专属施工记录；
- 详细设计第 4 节的现实世界级语义组；
- 异 owner 分阶段的`已完成/待继续/结果未知/非成功`强类型结果和原幂等续跑；
- 完整读取的同 G0 整体成功/整体丢弃边界。

不允许世界树公开或私有复制单类 CRUD，不允许调用旧 L2，不允许需求/任务/方法/Vt/Vm 进入世界树投影。“按所属存在读取需求/任务”是独立 ARCH-L4 视图，不属本计划。

## 4. 激活与完成声明

执行智能体当前必须退出本计划并选择索引中的 DATA-L2 提供者叶。每个提供者完成后，计划智能体只沿同一依赖链冻结下一个最早缺口；不得跳到空 ARCH-L3 模块。

本 v0.2 不是可执行计划，也不证明代码、编译、运行、现实根唯一、内部世界、ARCH-L4 业务视图、生产接线、旧逻辑替代或集成验收完成。
