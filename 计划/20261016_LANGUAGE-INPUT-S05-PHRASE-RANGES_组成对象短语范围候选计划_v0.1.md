# LANGUAGE-INPUT-S05-PHRASE-RANGES 组成对象短语范围候选计划

日期：2026-10-16。版本：v0.1。状态由`计划/计划索引.md`唯一维护。代码起点：`e5bf63e2c94c0a117081b07201636b5decbe2cd0`。

## 1. 目标与完成边界

现行 S05 子解释器已经依正式知识枚举“〔部分〕是〔整体〕的一部分”的完整句面布局，却在调用方未同时给出两个对象槽时丢弃这些布局，仅返回`短语定位待提供`。本叶把**布局中的两个对象短语范围候选**作为独立值式结果交付，使后继词条/概念召回、指代和实例绑定有可核对的原文位置。现行`候选组`继续专指已经过调用方槽位核验的组成含义候选；布局不能计作含义已解，更不能当作已绑定 E 或现实组成事实。

本叶只覆盖已经由 S05 正式知识及当前固定词面识别的无标点单句。短语内部可以含多个词，但本叶不解释内部词义、不查询概念或现实 E、不选代词目标、不生成临时专名。完整短语的后续候选与指向仍需独立合同。旧 S05 计划 v0.1 在“缺槽时候选组为空、未覆盖全句”上继续成立；其“没有可读短语布局材料”的结果形态由本计划具名扩展，不把`候选组`改义。

依据：[0050](../规范/0050_项目通用机器逻辑与禁止性规则总纲_20260721.md) §3.2、[2340](../规范/2340_根规范_自然语言知识.md) §2—4、[7200](../规范/7200_子规范_词条概念候选与上下文消歧.md) §3—4、[7230](../规范/7230_子规范_语言材料知识与交互字段.md) §3、[7240](../规范/7240_子规范_自然语言双向转换与组织规则.md) §1—2/§4、[7250](../规范/7250_子规范_最小汉语知识与语言学习.md) §2 S05，以及 [S05 施工证据](../验证记录/20261016_LANGUAGE-INPUT-S05-COMPOSITION_施工与编译记录_v0.1.md)。

## 2. 当前能力与复用裁决

`业务/解释.基础语言.cpp` 的私有`是S05结构`、`枚举S05布局`、严格 UTF-8 标量范围、完整词条匹配及知识枚举已经在同一 owner 内；`解释单句组成陈述`先取得所有合法布局，再检查`部分槽/整体槽`。总入口`解释已支持单句构式`仅依据 S05 `候选组`归并已解/待绑定/多义，`短语定位待提供`归为`分支未完成`。直接扩展这条入口，不新建平行句面解析器、不改知识服务、工程登记、普通应用装配或输出生成。

复用现行 S05 的知识结构、固定词读取、最长词条匹配和布局枚举。`新_场景类::读取本树范围成员完整()`、名称关系和全特征匹配虽可支持后继实例候选，但本叶不调用；布局只说明原文边界，不足以证明对象 E。输出端的`明确对象描述`仍缺可恢复指称。

## 3. 精确公开合同与物理位置

在`海中鱼巣/业务/解释.基础语言.h`的`基础组成候选`旁新增值式 DTO；只在`基础组成输入结果`末尾追加一个字段，保持已有字段顺序和`解释单句组成陈述`签名不变。定义与私有复核逻辑仅改同名 `.cpp`。唯一 owner 为 DATA 外基础语言解释业务。

```cpp
struct 基础组成短语布局候选 final {
    稳定编码 所用知识节点;
    解释原文范围 部分范围, 整体范围;
    解释原文范围 是词范围, 的词范围, 一部分词范围;
};
// 基础组成输入结果的最后一个字段：
std::vector<基础组成短语布局候选> 短语布局候选组;
```

每项来自一条当前完整可读、结构严格匹配且固定词面为`是/的/一部分`的正式知识，五个范围均是原文 Unicode 标量半开区间；部分与整体按知识角色映射，不能对调。不同知识或不同合法布局逐项保留，按`知识节点、部分范围、整体范围、三固定词范围`升序确定输出顺序；相同六元身份的重复项去重，若同一知识的重复身份来自服务结果则按现行重复知识判`内部不一致`。布局组没有独立身份、事务或持久生命周期。

只有状态`短语定位待提供`允许非空`短语布局候选组`；此时`候选组`仍为空、`未覆盖范围组`仍为全句，调用方不能消费布局作为已采用含义。其余所有状态下布局组为空，包括两槽齐全时的正常候选、多规则、缺规则、结构未支持、读取漂移及工程未完成；避免形成两份不同完成层级的公开候选。零有效布局仍为原有`结构未支持`或`缺规则`，不以空布局组伪装成功。两槽均缺或仅缺一个时统一返回完整布局集合；不得用单槽缩小结果或读取其未核验目标 E。

## 4. 函数行为与非成功边界

1. 保持原入口输入、UTF-8、知识与固定词校验及`不支持词面有布局`优先级。只有至少一项受支持布局且没有竞争的未支持词面布局，才进入缺槽分支。枚举不得按第一布局截断。现行`新_语言类::枚举语言知识候选`先取得该语言完整身份组，超出`最大知识条目数`时返回`额度不足`且清空信息组，只有完整定义/端点复核成功才返回`已完成`；本叶**仅在`已完成`后**交付范围候选，任何额度不足或其它非成功均返回空布局组，绝不交付可采用的部分范围。现行额度与状态仍是 S05/语言知识枚举的旧 ABI；本叶不新增、扩大或绕过该限制，不能据此声称其已满足 0050 §3.2 的无预算完整读取。该迁移须另行闭合语言知识提供者和全部消费者合同，不能用极大额度模拟无预算。
2. 缺槽时先把已枚举的内部布局转为上述独立 DTO；在公开返回前复读`获取语言`的完整`新语言信息`，以及全部已用固定词、完整最长匹配片段和完整知识候选组，逐字段与首读相等。复读语言非成功按现行`映射S05语言状态`映射，词/匹配/知识非成功各按现行 S05 映射；内容不同为`读取漂移`，清空布局组，保留全句未覆盖。读回不借助世界根或场景 E，因为它们尚未参与布局计算。没有共同原子快照，前后相容不能证明不存在 ABA。
3. 复读成功后排序、核对各范围非空、界内、连续覆盖句面且对应固定词节点，再填`短语布局候选组`并返回`短语定位待提供`。若内部枚举产生违反自身布局合同的范围，返回`内部不一致`、空布局组；内存分配等工程异常向上送至实际最终诊断责任边界，不吞成`结构未支持`或空列表。
4. 两槽齐全路径保持现行范围精确相等、候选额度、现实根、完整成员及 E 读回/复读、状态裁决和事实零写。为追加结果字段，修订本入口的聚合初始化；总分派对 S05 的候选计数、状态归并、调用次数和其它 S01/S02/S09 分支均不改。`短语布局候选组`不进入总分派语义候选数；当分支结果为`短语定位待提供`时总状态仍是`分支未完成`。
