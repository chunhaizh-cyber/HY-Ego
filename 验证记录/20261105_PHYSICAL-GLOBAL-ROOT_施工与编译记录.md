## 4. 静态复核矩阵（详细设计第8节）

| 项 | 结论 |
| --- | --- |
| 全局根唯一 | 由互斥内“已有效则核验、否则一次原子建立”保证；全局变量 `全局根场景节点` 只在首次成功后赋值 |
| 五类型唯一 | 初始化一次建立5个登记节点；`全局根结构完整已加锁` 核登记边恰5条、每节点键唯一且各被引用一次 |
| 四世界根初始化挂接、模拟按需挂接 | 现实/外设/自然语言/内部治理在各自初始化中挂接；模拟只在首次 `确保根()` 挂接 |
| 重复初始化无变化 | `初始化()` 已有效→无变化；`挂接世界根` 同类型同根→无变化 |
| 同类型第二根 → 结构不一致 | `挂接世界根` 读现有挂接后拒绝 |
| 根挂错类型 → 结构不一致 | 同根已挂其它类型拒绝；未挂根已带类型字段拒绝 |
| 装配读回不符 → 停门 | `成功()` 末项为 false，装配结果不成功 |
| 既有父链过滤不受影响 | 挂接边角色 9102 不等于场景层级角色3、存在组成角色2；`场景层级关系组` 与 `查询父存在关系` 均按角色过滤；世界根新增字段按字段键过滤读取 |
| 锁序 | `全局根互斥` 为叶锁，持锁期间只调用 `全局基础数据集`，不回调世界服务 |
