## 2. 实际实现

新增任务集合约束域，独立于原有“完整特征值材料身份列表”。支持指定任务成员、至少一个真实任务、对应指定正式需求的任务，组合为AND。约束和材料均在比较前规范排序；约束去重，具体任务身份通过只读端口核验。比较返回整数1/0，未装配、坏引用、结构异常不返回语义未满足。

概念owner完成规范化、建立/读取、更新回滚、零引用清理、约束蕴含比较及有限材料逐值比较。任务provider只读L1结构，核对任务类型、集合根登记、唯一需求引用、Vt回指和反向一需求一任务；不取任务锁，不读取任务状态。需求身份校验由需求owner以一次L1完整节点读取提供，不复制私有schema。装配在任务初始化后注入端口；线程析构join后、任务服务析构前解绑。材料服务在世界树中先于概念服务声明、后于概念服务销毁。

任务筹办直接比较实际集合与目标域；集合条件不再因非I64而拒绝。相同对象和特征类型的条件合并完整约束，而非只记录当前缺失项。全部条件源投影不包含本次命中/缺失证据。采用、承接、就绪复核贯通集合DTO；祖先循环按集合语义等价核验；集合结果走值域保证关系，不进入I64线性反求、不虚构方向。预计及禁止结果使用同次执行冻结准确值，并核对FT根和单位。

自我为集合需求建立既有材料相似度算法的参照包含关系；1/0包含标志不冒充10000相似度事实。需求复核返回已满足或未满足但无有向差值；追加未装配工程状态，旧枚举值不重排。

兼容失败关闭：结构化服务要求入口拒绝新约束域；实例区间存储拒绝未支持的新域；旧模拟归档格式明确拒绝新域编解码；场景采集对新域登记“边界未展开”缺口并返回材料不完整，不保存假完整快照。

## 3. 静态复核及实际编译

交叉只读复核实际发现并修复：

1. 集合结果比较须核对值域FT根，不能消费其它FT的同形约束。
2. 指定任务与对应需求任务可以语义等价，祖先循环不得只比较DTO。
3. 合并结果与类型根域相等时复用根，不能强建非严格子域。
4. 新variant使归档模板static_assert；旧场景采集会静默略过引用。v0.2按原目标补最小失败关闭。

既有二次概念准入已经支持非I64材料相似度的参照包含结果域，本轮没有修改该类。
