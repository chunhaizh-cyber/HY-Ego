### 3.2 专项运行

隔离专项程序建立两个不同特征类型的双状态原子动态，再调用 `建立复合动态()`：

```text
compound-dynamic-ok
EXIT=0
```

实际核验：

1. 复合动态读回种类为“复合”。
2. 两个成员由两条基础数据集外部父子关系保存。
3. 四个来源状态按稳定编码去重并按 UTC 纳秒排序。
4. 同一时间组与相邻时间组共产生三条跨特征状态出现时间二次特征。
5. 删除复合动态后，两条成员关系和复合内部派生项退出。
6. 两个成员动态只减少组成引用，仍可完整读回，没有被复合动态删除动作连带删除。

专项程序和为调用状态类私有入口建立的临时只读测试接缝只存在于上述 `D:\TEMP` 隔离目录，没有写入仓库。

## 4. 代码知识变更清单

### 新增函数

1. `新_二次特征类::比较状态出现时间(const 二次特征状态出现时间输入&, const 二次特征状态出现时间输入&) const noexcept`
   - 用途：形成带左右特征类型身份的有方向状态出现时间差。
   - 结果：复用二次特征计算结果，返回准确纳秒差、二次特征类型概念和结果值域概念。
   - 非职责：不读取状态事实，不判断状态属于哪个动态。
2. `新_动态类::建立复合动态(稳定编码, const std::vector<稳定编码>&) noexcept`
   - 用途：把同一主题存在或其子存在的多个单特征动态组织为多特征复合动态。
   - 事实写入：复合动态基础字段、外部成员父子关系、跨特征时间派生项和成员引用计数。
   - 非职责：不复制或改写成员动态，不自动形成聚合动态概念。
3. `新_动态类::减少组成引用(稳定编码) noexcept`
   - 用途：复合成员关系退出时只减少引用，不取得成员删除所有权。

### 修改函数

1. `新_二次特征类::计算(const 新二次特征计算请求&) const noexcept`
   - 新增“状态出现时间间隔”输入、算法、概念身份和饱和时间差分支。
2. `概念_二次特征类::建立或取得二次特征概念(...) noexcept`
   - 通过内部定义校验支持左右特征类型参与身份的状态出现时间概念。
3. `概念_二次特征类::建立或取得默认二次特征概念(...) noexcept`
   - 为状态出现时间间隔生成 I64 全域及纳秒单位输出定义。
4. `新_动态类::初始化() noexcept`
   - 初始化复合时间派生项所需的共享字段和节点类型。
5. `新_动态类::获取动态(稳定编码) const noexcept`
   - 分开读回原子、单特征序列和复合动态；复合成员只从外部关系读取。
6. `新_动态类::删除动态(稳定编码) noexcept`
   - 复合动态先退出外部成员关系和内部派生项，再删除本体；成员只减少组成引用。
7. `新_动态特征抽取类::抽取(const 新动态特征抽取请求&) const noexcept`
   - 复合动态直接投影已经保存的跨特征状态出现时间二次特征；成员自身特征仍独立抽取。
