## 4. 「正式数据」代码核实（非想象）

1. **装配加载路径**（`构造普通应用上下文`）：只读程序旁固定初始化文本  
   `初始化材料/{最小结构定义种子,结构化子概念种子,最小语言知识种子,指代定义种子,表达组织知识种子}.txt`  
   与 `基础数据/词典`；**无**用户世界快照/正式库打开、恢复、迁移入口（与 2026-11-05 PHYSICAL-GLOBAL-ROOT 记录一致：全仓无结构事实快照加载）。
2. **云端本 Linux agent**：无 MSVC；无挂载的用户正式库目录；环境 secrets/磁盘亦无「正式持久库」可执行件。
3. 因此「L3 必须上用户电脑」不准确；更准确是：  
   - **种子装配正式上下文** — CI L2 已跑；  
   - **用户会话级端到端**（真人消息 → 接收需求认知 → 领域核对 / 方法表达出入）— 需 Windows 上启动治理线程与入站消息，且可能外发，**本轮禁止自动启动**。
