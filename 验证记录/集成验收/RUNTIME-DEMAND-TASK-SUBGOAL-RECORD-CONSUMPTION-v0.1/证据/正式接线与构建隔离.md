## 正式构建隔离

- `海中鱼巣/入口.cpp:10`无条件 import `海中鱼巣.端到端测试.自我治理一致事实`；
- `海中鱼巣/入口.cpp:20`无条件公开`--test-治理`启动分支；
- `海中鱼巣.vcxproj:216`无条件以`ClCompile`登记该端到端测试模块；
- Debug 和 Release 使用同一工程项，未发现关闭自检入口的条件属性、宏或独立正式目标。

因此 Release 虽然成功编译链接，但仍携带自检模块和测试启动入口。按 ACCEPTANCE-01 第 1、6 节与集成验收技能门禁：生产程序不自检，自检直接调用、仅自检可达或仅编译进正式目标都不构成正式接线。结论为：

```text
正式接线 = FAIL
自检隔离 = FAIL
正式构建隔离 = FAIL
```

这不是服务算法的结构化业务事实失败；它阻止的是从“自检通过”升级到“服务验收通过”。
