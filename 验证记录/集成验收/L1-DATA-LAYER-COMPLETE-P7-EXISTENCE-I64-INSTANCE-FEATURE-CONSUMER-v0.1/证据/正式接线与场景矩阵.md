# P7 正式接线与场景矩阵

## 正式接线

```text
生产运行期会话::启动
-> 有效运行期上下文租约
-> const 运行期上下文*
-> const L1特征定义服务&（形成受控 I64 定义）
-> const L1实例特征服务&
-> const 建立登记 / const 建立实际存在I64实例特征
-> const 读取当前登记 / const 读取实际存在I64实例特征
```

驱动不导入 L1 模块，不取得仓、锁、事务、候选、可变上下文或私有定位，不使用 `const_cast`，不解析日志。

## 标准八类场景

| 类型 | 状态 | 理由 |
| --- | --- | --- |
| 成功 | PASS | 登记首次和实例首次结构化成功及公开终态成立 |
| 精确重复 | PASS | 登记和实例均精确重复，不形成第二事实 |
| 合法拒绝 | PASS | 越界、同键异义和不同键同组合均具名拒绝且零变化 |
| 外部失败 | NOT_APPLICABLE | 本消费者无 SQL、文件、网络或外设依赖 |
| 并发 | NOT_APPLICABLE | 本计划明确不纳入并发消费者矩阵 |
| 崩溃恢复 | NOT_APPLICABLE | 当前不考虑崩溃、重启、断电和跨进程恢复 |
| 正式读回 | PASS | 各适用边界均经公开入口独立重读 |
| 正式构建 | PASS | 未替换入口的原生产目标 Debug/Release 完整 Rebuild 与正式参数运行通过 |

以上只累计本消费者的真实覆盖，不构成第一层自证或整个 L1 完善。
