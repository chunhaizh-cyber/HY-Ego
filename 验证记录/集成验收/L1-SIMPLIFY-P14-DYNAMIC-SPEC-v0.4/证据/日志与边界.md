# P14 v0.4 日志与边界

## 1. 独立日志观察

候选按现有日志规范把日志写到固定目录 `D:\海中鱼巣\日志`，不随可执行文件当前目录改变。验收分别在 Debug、Release 运行前后统计 P14 观察标识的命中数：

| 配置 | 运行日志增量 | 逻辑错误日志增量 | 退出码 |
| --- | ---: | ---: | ---: |
| Debug | 1 | 0 | 0 |
| Release | 1 | 0 | 0 |

两次新增运行日志正文均为：

```text
观察标识=L1-SIMPLIFY-P14-DYNAMIC-SPEC-S01；结果=通过；验收项数=28；失败项数=0；未分类异常=0；正式接线=不适用；正式读回=不适用
```

日志只证明操作者可观察到组件自检结果，不是机器权威事实，不替代结构化自检报告、L1事实或正式独立读回。

## 2. 单目标与消费边界

- 工程仍只有一个 `海中鱼巣.exe` 目标；没有第二 exe、独立自检目标或第二装配。
- `--self-test-exit` 是同一生产程序的受控自检路由，按 v0.4 正式设计不构成第二目标。
- P14 的当前消费者仍只有 `自检.L1动态.ixx` 和顺序390启动包装；生产运行期没有 P14 调用边。
- 因而正式生产消费者、正式接线和正式独立读回均为 `NOT_APPLICABLE`，不得计入服务集成 PASS。

## 3. 用户边界

用户已明确当前不考虑程序崩溃问题。因此崩溃、重启、断电和跨进程恢复在本验收中均为 `NOT_APPLICABLE`，既不标失败，也不作为完成声明。
