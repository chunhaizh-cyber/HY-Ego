# 结构化结果与覆盖边界

## 判定

1. 生产会话取得结构化启动成功和有效租约。
2. 实际存在登记、初始场景和世界登记各连续读取两次；六次均为已读取且每一对逐字段相等。
3. 三类公开事实的共同截止均为第四代。
4. 实际存在登记合同、规则和首次请求身份符合公开合同；服务身份与资格属性类型非零且互异。
5. 正式生产顺序在登记建立后继续发布初始场景实际存在，因而登记定位截止落后于最终当前截止；本轮成功读回证明登记读取根能够在一次合法代次漂移后完整重做并收敛。
6. 外部消费者没有直接调用第一层，也没有读取私有仓、锁、缓存或日志。

## 本轮实际新增覆盖

| 能力 | 本消费者本轮实际使用 | 本轮不覆盖 |
| --- | --- | --- |
| 一致当前查询 | 指定登记定位截止，一次选择服务身份与资格属性类型两个节点 | 值、属性、关系、关系组、其它消费者 |
| 有界代次收敛 | 后继业务推进代次后，完整丢弃旧轮材料并重做一次 | 无限重试、等待、并发压力 |
| 跨服务公开读回 | 登记、场景和世界各连续两次全等且共同截止 | 私有失败分支和坏事实注入 |

实际存在登记的两节点创建和旧精确读取已经由既有消费者验收覆盖，本轮不重复计为新创建证明。精确重复、合法拒绝、外部失败、并发和崩溃恢复没有为了补齐第一层覆盖而额外构造。

因此，本轮只证明第一层的一次两节点一致当前投影及一次有界完整重做足以支撑实际存在登记消费者；不形成第一层独立通过结论，也不能据此认定第一层整体完善。
