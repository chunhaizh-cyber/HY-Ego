## 实际消费者链

```text
生产运行期会话::启动
-> 运行期上下文::初始化世界登记
-> 运行期上下文::初始化初始场景
-> 初始场景服务::创建初始场景
-> 第一层业务中性写集公开入口
-> 初始场景服务内部经当前代次、节点、属性、值和关系公开入口完成权威读回
-> 生产启动返回结构化世界登记状态、初始场景状态和候选租约
-> 外部消费者从租约取得运行期上下文
-> 运行期上下文::读取初始场景（连续两次）
-> 运行期上下文::读取世界登记（连续两次）
```

验收驱动没有直接调用第一层，没有访问私有仓、锁、候选或内部事务，也没有进入生产工程。正式生产目标仍只包含生产入口。
