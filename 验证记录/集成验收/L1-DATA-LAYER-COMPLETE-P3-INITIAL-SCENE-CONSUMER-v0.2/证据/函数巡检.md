# 函数巡检

候选提交六个生产代码文件中，共识别二十五个新增或直接修改函数。两种配置完整重建证明二十五个函数均进入编译；其中四个失败映射或后续消费者函数按本次消费者合同排除，剩余二十一个函数全部完成编译接入和入口巡检，没有观察到逻辑异常。

## 已进入的二十一个函数

| 所有者 | 函数 | 责任与本轮观察 |
| --- | --- | --- |
| 场景数据合同 | `初始场景创建请求有效`、`初始场景读取请求有效`、`初始场景事实完整`、`初始场景结果::成功` | 纯值判断；无独立错误日志责任；成功链均成立 |
| 场景服务内部 | `映射L1幂等键`、`写入状态`、`映射`、`编码与登记不重复`、`读取实现`、`创建实现` | 内部形成中性请求和逐字段裁决；异常向上结构化送出；成功链均进入 |
| 场景公开服务 | `创建初始场景`、`读取当前初始场景` | 向生产运行期送出结构化结果；创建一次、当前读取多次 |
| 世界登记服务 | `按登记读取权威事实` | 在第二代继续读回第一代登记事实，并返回当前验证截止 |
| 生产配置 | `读取生产运行期固定配置`、`生产运行期配置::operator==`、`生产运行期配置::有效` | 初始场景幂等身份进入固定配置并通过完整性核对 |
| 运行期上下文 | `完整`、`初始化初始场景`、`读取初始场景`、`初始场景完整` | 只转发结构化结果并核对登记与场景共同截止 |
| 生产运行期 | `生产运行期会话::启动` | 世界登记成功后创建初始场景，场景成功后才继续后续生产链 |

## 未进入的四个函数

| 函数 | 未进入原因 | 结论边界 |
| --- | --- | --- |
| 场景服务内部的中性读取失败状态映射 | 成功读回没有触发读取失败 | 只取得编译接入，不声明失败分支通过 |
| 场景服务内部的世界登记失败状态映射 | 世界登记公开读回成功 | 只取得编译接入，不声明失败分支通过 |
| 场景服务内部的初始场景接纳规格形成函数 | 属于后续实际存在消费者，不在本消费者生产链 | 保留既有合同，不用本轮入口巡检替代后续验收 |
| `L1场景结构服务::读取初始场景(请求)` | 本轮生产租约使用无参数当前读入口 | 只取得编译接入；当前读入口已实际进入 |

全部新增或修改函数均按生产合同归类为纯值判断、内部结构化传播或向上送出。合法成功不记逻辑异常；本轮没有为了函数覆盖率建立生产探针、私有入口或额外业务调用。
