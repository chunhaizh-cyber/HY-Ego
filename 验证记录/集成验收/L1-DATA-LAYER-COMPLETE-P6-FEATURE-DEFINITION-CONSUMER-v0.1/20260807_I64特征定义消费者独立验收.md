# P6 I64特征定义消费者独立验收

日期：2026-08-07

结构化结论：`INTEGRATION-ACCEPTANCE-DRIFT`

人读结论：`未正式接线 / 计划要求的写消费者无法经生产租约合法调用非const服务入口`

候选提交：`3faf31fcecdd38e86816d1318f7ae4bb5c10e0da`

## 1. 首个漂移事实

正式设计固定的合法调用方向是：

```text
生产运行期会话::启动
-> 运行期上下文租约
-> 运行期上下文::读取L1特征定义服务
-> 建立登记 / 建立I64特征定义
```

候选实际接口不能形成该调用：

1. `运行期上下文租约::读取() const` 返回 `const 运行期上下文*`。
2. 该指针只能调用 `运行期上下文::读取L1特征定义服务() const`，返回 `const L1特征定义服务&`。
3. `L1特征定义服务::建立登记` 与 `建立I64特征定义` 都是非const成员函数。
4. 生产代码外合法消费者编译探针在首次 `服务.建立登记(请求)` 处稳定失败：C2662，`this` 不能从 `const L1特征定义服务` 转换为可写引用。

验收边界禁止 `const_cast`、新增验收入口、直调L1、私有仓或事务，因此不能绕开该事实继续执行首次、精确重复、冲突和非法值域矩阵。
