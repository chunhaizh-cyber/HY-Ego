# P6 正式接线与场景矩阵

## 正式接线

| 边界 | 候选事实 | 结论 |
| --- | --- | --- |
| 租约读取 | `const 运行期上下文*` | 只有只读上下文 |
| 特征定义服务访问 | const上下文返回 `const L1特征定义服务&` | 只有只读服务 |
| 登记/定义建立 | 非const成员函数 | 合法消费者不可调用 |
| 绕过 | const_cast、验收入口、直调L1均禁止 | 不得补造 |

因此正式接线为FAIL，结论类型为“未正式接线”，不是环境阻断或已经运行后的业务事实失败。

## 八类场景

| 类型 | 状态 | 说明 |
| --- | --- | --- |
| 成功 | NOT_RUN | 首次登记写入口在编译期不可达 |
| 精确重复 | NOT_RUN | 依赖首次登记和首次定义，不能越过正式入口漂移补造 |
| 合法拒绝 | NOT_RUN | 非法区间必须通过同一正式写入口，当前不可达 |
| 外部失败 | NOT_APPLICABLE | 本消费者不使用SQL、文件、网络或外设 |
| 并发 | NOT_APPLICABLE | 计划未要求并发消费者覆盖 |
| 崩溃恢复 | NOT_APPLICABLE | 用户明确当前不考虑崩溃、重启、断电和跨进程恢复 |
| 正式读回 | NOT_RUN | 尚无合法首次定义可形成公开读取定位 |
| 正式构建 | PASS | 原生产目标Debug/Release完整重建和正式参数运行通过 |

不得把原生产程序启动成功、源码中存在实现或静态写集形状替代上述未运行消费者矩阵。
