```json
{"通过":true,"启动状态":1,"世界登记状态":1,"初始场景状态":1,"实际存在登记状态":1,"初始场景实际存在状态":1,"实际读回状态":3,"登记读回状态":3,"场景读回状态":3,"世界读回状态":3,"发布状态":1,"共同截止":4,"存在":12,"资格值":14,"成员关系":13,"资格属性类型":11,"资格来源":10,"直接成员关系类型":4}
```

## 四项权威事实互证

1. 四项公开结果各连续读取两次，状态和公开事实逐字段全等。
2. 初始场景实际存在、实际存在登记、初始场景和世界登记共同当前截止为4。
3. 实际存在的世界根等于初始场景的世界根，并等于世界登记的世界根编码。
4. 实际存在的当前场景等于初始场景事实中的初始场景。
5. 资格值所属节点等于实际存在；属性类型等于实际存在登记的资格属性类型11；来源等于登记服务身份10；I64材料为1；创建事实代次等于截止4。
6. 当前场景归属关系源端为初始场景、目标端为实际存在、关系类型等于世界登记的直接成员关系类型4、角色为0。
7. 世界登记5项、初始场景3项、实际存在登记2项和本次创建3项共13个不同实体编码全部非零唯一；跨事实引用只按相同业务身份全等复用。
8. 世界登记、初始场景、实际存在登记、实际存在事实及运行期上下文创建事实完整性判断均成立。

## 八类场景

| 类型 | 结果 | 合同理由 |
| --- | --- | --- |
| 成功 | PASS | 双配置结构化启动、创建、候选发布和四项权威读回成立 |
| 精确重复 | NOT_APPLICABLE | 生产合同只首次创建一次；计划明确不为补格构造重复写 |
| 合法拒绝 | NOT_APPLICABLE | 固定生产请求合法；计划明确不补造非法请求 |
| 外部失败 | NOT_APPLICABLE | 本消费者只使用进程内中性事实基座，无外部资源 |
| 并发 | NOT_APPLICABLE | 固定生产会话启动合同没有并发调用要求 |
| 崩溃恢复 | NOT_APPLICABLE | 用户明确当前不考虑崩溃、重启、断电和跨进程恢复 |
| 正式读回 | PASS | 四项公开入口各连续读取两次并在共同截止4逐字段互证 |
| 正式构建 | PASS | 自检关闭的原生产目标Debug/Release完整重建和正式参数运行通过 |

本验收只累计P5消费者实际使用的节点、值、属性槽、关系新增/查询及本写集原子性，不扩大为L1自证。
