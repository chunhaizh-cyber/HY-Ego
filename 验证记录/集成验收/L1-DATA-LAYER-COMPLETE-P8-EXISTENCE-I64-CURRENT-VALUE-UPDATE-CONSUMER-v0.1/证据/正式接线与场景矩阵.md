# P8 正式接线与场景矩阵

## 正式接线

外部消费者只 `import 海中鱼巣.启动.生产运行期`。调用链为：

```text
生产运行期会话::启动
-> 启动结果.租约.读取
-> const 运行期上下文
-> 读取L1特征定义服务 / 读取L1实例特征服务
-> 建立P6定义与P7实例前提
-> 换代实际存在I64实例特征当前值
-> 读取实际存在I64实例特征 / 读取世界登记
```

验收驱动不导入或调用 L1、仓、锁、事务令牌、私有 helper、候选句柄或内部快照，不解析生产日志，也不建立双目标或生产验收模式。

## 场景矩阵

| 场景 | 请求与结构化结果 | 公开终态核对 | 结论 |
| --- | --- | --- | --- |
| 首次合法换代 | 旧 I64=3，新 I64=5；返回 `已提交` | 新定位公开读回为值5、编码31；旧定位公开读回 `未找到`；代次8→9 | PASS |
| 精确重复 | 同一幂等身份与同一请求；返回 `幂等读回` | 重复前后新当前逐字段相同，世界截止不变 | PASS |
| 同键异义 | 同一幂等身份，新值改为6；返回 `幂等冲突` | 无部分实例；新当前与世界截止不变 | PASS |
| 新值越界 | 新值18，定义上界17；返回 `入口拒绝` | 无部分实例；新当前与世界截止不变 | PASS |
| 新来源无效 | 新来源编码为0；返回 `入口拒绝` | 无部分实例；新当前与世界截止不变 | PASS |
| 写前代次漂移 | 新幂等身份但沿用换代前代次；返回 `事实代次漂移` | 无部分实例；新当前与世界截止不变 | PASS |
| 崩溃、重启、断电、跨进程恢复 | 当前范围明确不考虑 | 未构造 | NOT_APPLICABLE |
| 并发 | P8 设计和本轮验收未纳入 | 未构造 | NOT_APPLICABLE |
| 外部资源故障 | 本消费者不使用 SQL、文件、网络或外设 | 未构造 | NOT_APPLICABLE |

## 旧值历史边界

第二层公开合同没有旧值历史 DTO。消费者能够独立确认旧定位已不再是当前事实；旧值历史完整、旧值处于已退出状态、当前属性槽指向新值三项由目标服务在返回 `已提交` 或 `幂等读回` 前，经正式 L1 中性读回逐项强制检查。为了独立补格而从外部驱动直调 L1 会越过领域边界，因此明确禁止。

## 结论边界

本矩阵支持 `P8实际存在I64实例特征当前值第二层消费者公开黑盒局部通过`。不支持“第一层自检通过”“整个 L1 完善”“所有消费者已迁移”或任何恢复、并发结论。
