诊断责任裁决依据：

- CODE-FILE-01 v0.3 §4.4 允许在合同备注、详细设计或计划的逐函数合同登记诊断责任，不要求每个公开函数必须有源码诊断注释。
- P8 详细设计把两个公开重载冻结为同一结构化结果合同，明确非const入口只执行一次原样转发；错误矩阵规定资源失败或内部不一致返回对应结构化状态、不补写且不返回部分领域事实。因此两个公开重载均为“向上送出”，不存在无授权默认成功。
- 三个专属 helper 在源码中显式登记“向上送出”；失败经引用参数、`bool` 或 `optional` 送至 const 主实现，再映射为结构化 `实例特征状态`。
- 无生产日志不能证明或否定责任成立；本验收依据结构化结果与公开读回，不解析日志。

未迁移的 `换代I64实例特征当前值`、初始场景实例、其它实例特征入口和其它消费者不属于本验收目标。
