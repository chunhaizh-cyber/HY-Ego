## 实际消费者链

```text
生产运行期会话::启动
-> 运行期上下文初始化世界登记和初始场景
-> 启动结果返回结构化状态与有效租约
-> 外部消费者从租约取得运行期上下文
-> 运行期上下文::读取初始场景（连续两次）
-> 初始场景服务内部恰一次请求一致当前投影
-> 运行期上下文::读取世界登记（连续两次）
-> 比较两份场景、两份登记和共同事实截止
```

消费者驱动没有导入或直接调用第一层模块，没有访问私有仓、锁、候选、事务或恢复材料，也没有进入生产工程。正式生产目标仍只包含生产入口。
