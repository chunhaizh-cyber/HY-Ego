# DATA-L1-FINAL-CLOSURE R2 统一黑盒输出

Debug 与 Release 的仓库外统一 driver 都执行以下两个公开验收入口，并均返回 `0`：

```text
海中鱼巣::运行L1事实基座持久恢复端到端测试()
海中鱼巣::运行DATA_L1有限N分区原子事务端到端测试()
```

两配置输出一致，证明本轮实际覆盖：

- 节点、关系、值三类事实的当前、历史、墓碑、组与一致投影；
- owner、属性槽、事实代次、幂等与拒绝后零写；
- v1、v2、v3 原子事务入口与格式 1、2、3 恢复；
- V01—V08，包括非法 N / 身份 / owner / 端口 / G0 / 引用 / 属性槽、首中末参与者失败、旧账重放和后继 v3 收敛；
- 清单、槽、长度、摘要、未知格式 / 标签、存储占用和非活动槽的 fail-closed。

逐行原始输出见 `08-unified-driver-debug-run.txt` 与 `09-unified-driver-release-run.txt`。受控新运行包恢复计入正式读回，不冒充突然崩溃、强杀或断电恢复。
