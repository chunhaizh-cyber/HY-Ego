## 3. 分账裁决

- `编译接入通过`是候选施工记录已有证据，但本轮结论不是编译接入结论。
- 所有自检动态 PASS 都保留，不改写成 FAIL；同时它们不计普通应用入口巡检。
- V04 的 2 个子项、V07 许可子项、V09、V12、V15 继续是 NOT_RUN。
- 正式接线和正式构建隔离是本轮独立静态事实；它们不覆盖历史自检记录，而是限制允许声明范围。
