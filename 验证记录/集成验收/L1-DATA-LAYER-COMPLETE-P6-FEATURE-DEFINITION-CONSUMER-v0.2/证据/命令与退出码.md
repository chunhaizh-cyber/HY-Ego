验收目录是未跟踪新增目录，普通 `git diff --check -- <目录>` 不会检查其中内容；因此最终逐文件 whitespace 检查使用空文件与每个目标文件执行 `git diff --no-index --check`，把退出码 `0`（无差异）和 `1`（仅有差异）都视为检查正常，只把大于 `1` 视为检查失败：

```powershell
$验收目录 = '验证记录\集成验收\L1-DATA-LAYER-COMPLETE-P6-FEATURE-DEFINITION-CONSUMER-v0.2'
$空文件 = Join-Path $env:TEMP 'hzy-p6-v02-empty.txt'
New-Item -ItemType File -Path $空文件 -Force | Out-Null
Get-ChildItem -LiteralPath $验收目录 -Recurse -File | ForEach-Object {
    git diff --no-index --check -- $空文件 $_.FullName
    if ($LASTEXITCODE -gt 1) { throw "diff check failed: $($_.FullName)" }
}
```
