# P6 v0.2 正式接线与场景矩阵

## 正式接线

```text
生产运行期会话::启动
-> 有效运行期上下文租约
-> const 运行期上下文*
-> const L1特征定义服务&
-> const 建立登记 / const 建立I64特征定义
-> const 读取I64特征定义
```

驱动不 import L1 模块，不取得仓、锁、事务、可变上下文或私有定位，不使用 `const_cast`，不解析日志。

## 八类场景

| 类型 | 状态 | 结构化结果与权威观察 |
| --- | --- | --- |
| 成功 | PASS | 登记与定义均 `已提交`；代次 `4 -> 5 -> 6`；八编码非零唯一 |
| 精确重复 | PASS | 相同定义请求为 `幂等读回`；定义载荷逐字段相同，截止仍为6 |
| 合法拒绝 | PASS | 同键不同合法上界为 `幂等冲突`；非法区间为 `入口拒绝`；两者均无部分定义 |
| 外部失败 | NOT_APPLICABLE | 本消费者不使用 SQL、文件、网络或外设 |
| 并发 | NOT_APPLICABLE | P6 v0.2 计划未要求并发消费者覆盖 |
| 崩溃恢复 | NOT_APPLICABLE | 用户明确当前不考虑崩溃、重启、断电和跨进程恢复 |
| 正式读回 | PASS | 首次、重复、冲突前后和拒绝前后均由公开读取入口返回同一完整事实 |
| 正式构建 | PASS | 原生产目标 Debug/Release 完整 Rebuild；验收驱动不进入生产目标 |

## 零变化核对

- 精确重复后世界登记当前截止保持 `6`；
- 幂等冲突前后正式定义事实、三值编码、下界、上界和来源服务逐字段一致，世界登记当前截止保持 `6`；
- 非法区间拒绝前后同样逐字段一致，世界登记当前截止保持 `6`；
- 非成功结果均不携带部分定义事实或值编码。

上述结果只累计本消费者实际覆盖，不构成第一层自证或整个 L1 完善。
