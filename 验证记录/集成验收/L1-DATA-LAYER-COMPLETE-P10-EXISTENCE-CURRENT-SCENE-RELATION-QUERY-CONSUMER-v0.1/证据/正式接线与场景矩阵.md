# 实际存在当前场景归属条件查询正式接线与场景矩阵

## 正式接线

外部消费者只 `import 海中鱼巣.启动.生产运行期`。它经生产会话和有效租约取得 const 运行期上下文，再取得 const `L1实际存在场景组合服务`。组合读取经第二层场景接纳服务使用本轮新增的目标加关系类型查询；消费者不导入或调用第一层、场景内部服务、仓、索引、锁、事务令牌或私有 helper，不解析日志。

## 单目标边界

唯一主目标是消费者新建的非启动锚定实际存在。启动锚定实际存在不是第二验收目标，只作为生产上下文中已有的错误输入；拒绝前后读回只证明主目标或错误输入未发生未授权变化。

消费者创建和退出都沿正式第二层入口发生。它没有为了观察条件关系组而越过第二层直调第一层，因此本次证据正是“后续数据服务层通过实际读写查删路径证明第一层支撑能力”，不是第一层自证。

## 结论边界

本矩阵支持“一个真实第二层消费者实际使用目标加关系类型查询，创建后为一项，退出后为空”的公开黑盒局部结论。不支持第一层自检、自证或整体完善，也不支持多项业务关系、关系替换、源端查询、分页、性能、并发或恢复结论。
