## 2. 精确候选隔离

验证根：

```text

```

候选通过以下方式展开，不使用工作区未提交内容：

```powershell
git archive --format=zip --output=<验证根>\candidate.zip 862b58f92fc8377546e88a486d8426d1cfa3e50a
Expand-Archive -LiteralPath <验证根>\candidate.zip -DestinationPath <验证根>\source
```

归档展开共 `7972` 个文件、`52045864` 字节。首次尝试用 PowerShell 内联 `candidate^{tree}` 查询 tree 时出现一次命令编码歧义；随后用 `git show -s --format=%T` 纠正并取得 tree `5187316123af8571f202f64b2ac96238c8e3c6c1`。该查询失败没有改变归档内容、构建命令或候选身份。

## 3. Release 全新重建

实际命令：

```powershell
MSBuild.exe <验证根>\source\海中鱼巣.slnx /t:Rebuild /m:1 `
  /p:Configuration=Release /p:Platform=x64 `
  /p:OutDir=<验证根>\Release\out\ `
  /p:IntDir=<验证根>\Release\obj\ /v:minimal
```

结果：退出 `0`；日志末尾包含 `正在生成代码`、`已完成代码的生成`和 exe 输出路径。日志实际列出 `服务.任务子目标回流重判.ixx`与`端到端测试.自我治理一致事实.ixx`，各出现 2 次（编译行和模块跟踪行）。

## 4. 治理专项分账

实际命令：

```powershell
<验证根>\Release\out\海中鱼巣.exe --test-治理
```

结果：退出 `0`，stdout `5338` 字节，stderr `0` 字节。stdout 第 2 行明确输出本服务 V01—V04、V08—V13、V15、V20、V22 动态通过及其 NOT_RUN 边界；第 69 行为 `[治理测试] 全部通过`。

这只形成 `自检通过` 范围的施工证据，不构成普通应用合法消费者、权威终态或正式读回。
