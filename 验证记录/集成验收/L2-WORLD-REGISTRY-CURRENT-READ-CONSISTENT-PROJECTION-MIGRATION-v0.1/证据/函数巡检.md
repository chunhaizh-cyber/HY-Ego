# 函数巡检

本次候选直接影响闭包为世界登记服务中的三个函数：

```text
世界登记服务::映射一致读取失败
世界登记服务::一致读取失败形状完整
世界登记服务::按登记读取权威事实
```

- 三个函数均在候选临时归档的 Debug 与 Release 完整构建中编译、链接通过。
- 正式成功链实际进入 `按登记读取权威事实`；另外两个纯值辅助只服务结构化非成功分支，本轮没有为覆盖补格制造许可竞争或坏结果。
- 目标根只有一个物理一致投影调用点，最大完整尝试次数为二；旧事实代次、节点、属性、值和完整快照读取调用为零。
- 目标根成功时验证五节点、根唯一属性槽、当前值所属、类型、来源及整数一，并只更新返回登记副本的已验证事实代次。
- 世界登记公开数据合同、建立空世界写入、运行期上下文和生产调用者没有因本候选改变。
- 未观察到默认成功、部分登记、私有仓访问、生产自检、第二生产目标或日志判定入口。

两个未实际进入的失败辅助不影响本次成功服务合同，也不得据此声明许可拒绝、资源失败或内部不一致分支已运行覆盖。
