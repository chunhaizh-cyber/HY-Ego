## 2. 实际变更

- `海中鱼巣/领域/新_动态类.h/.cpp`
  - 物理删除“单特征序列/组合”动态种类、`连接原子动态()`公开入口、顺序成员项内部字段及其建立、读回、删除逻辑。
  - `新动态信息`不再公开`原子动态节点组`。
  - `建立复合动态()`只接受双状态原子动态。
  - 复合成员仍由外部父子关系保存；输入成员规范化为集合，不以稳定编码顺序表达时间。
  - 按“成员主题存在＋特征类型”分组；同组原子按前状态时间排序并要求相邻原子共享状态端点，不同组独立并行。
  - `获取动态()`按同一规则重新核验复合结构，并从成员状态汇总全局时间投影。
- `海中鱼巣/业务/新_动态特征抽取类.h/.cpp`
  - 删除对已退出单特征序列的特征拼接分支及专用结果状态。
  - 原子动态仍独立抽取；复合动态仍只投影已保存的跨特征状态出现时间二次特征。

历史验证记录中的“单特征序列”只描述其绑定旧提交时的历史结果，本切片未改写历史证据。

### 3.2 专项运行

专项入口只存在于隔离目录；状态类的测试接缝也只存在于隔离目录，没有写入仓库。

```text
parallel-serial-dynamic-ok
EXIT=0
```

实际覆盖：

1. 建立同一主题、同一特征类型且共享端点的两个原子动态。
2. 建立另一特征类型的一个原子动态。
3. 以无语义顺序的成员输入建立复合动态，读回 3 个外部原子成员、5 个去重状态及非空跨特征时间特征。
4. 同一特征类型的两个原子不共享端点时返回`端点不连续`，未发布复合动态节点。
5. 删除复合动态后，其三个原子成员仍可完整读回。

## 4. 代码知识变更清单

### 退出函数

1. `新动态建立结果 新_动态类::连接原子动态(const std::vector<稳定编码>&) noexcept`
   - 原用途：把同特征、共享端点的有序原子动态另行发布为正式单特征序列动态。
   - 退出原因：场景动态列表已经提供原子动态时间材料，正式连续序列会形成重复结构。
   - 调用边：当前源码中没有生产调用者；本次同步删除动态特征抽取中的对应消费分支。

### 修改函数

1. `bool 新_动态类::初始化() noexcept`
   - 不再建立单特征序列专用的成员项、成员项类型、顺序和目标字段。
2. `新动态建立结果 新_动态类::建立复合动态(稳定编码, const std::vector<稳定编码>&) noexcept`
   - 成员由“原子或单特征序列”收紧为“仅原子动态”。
   - 增加按主题存在与特征类型分通道、同通道按时间排序和共享端点校验。
   - 成员集合继续以外部父子关系持久保存；跨特征状态时间二次特征继续写入复合动态。
3. `std::optional<新动态信息> 新_动态类::获取动态(稳定编码) const noexcept`
   - 删除单特征序列读回；复合读回只接受原子成员并复核串行通道连续性与跨特征数量。
4. `新动态操作状态 新_动态类::删除动态(稳定编码) noexcept`
   - 删除单特征序列内部成员项和引用退出分支；保留原子与复合两类生命周期。
5. `新动态特征抽取结果 新_动态特征抽取类::抽取(const 新动态特征抽取请求&) const noexcept`
   - 删除单特征序列的原子概念特征拼接分支；原子与复合分支不变。

### DTO与公开合同变化

- `新动态种类`只保留`原子=1`和`复合=3`；数值 2 不再具有现行含义。
- `新动态信息`退出`原子动态节点组`。
- `新动态操作状态`退出`原子动态不足`和`不是单特征动态`。
- `新动态特征抽取状态`退出`原子特征尚未生成`。

上述用途卡当前不存在覆盖本组新版函数的现行条目；共享知识库未在本切片中修改，发布后应按结果提交复核。
