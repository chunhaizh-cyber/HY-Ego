## 2. 实际实现

- 由一个 `新_世界树类` 对象按固定构造顺序装配特征值、特征概念、实例特征、二次特征概念、二次特征、存在概念、状态、存在、动态概念、动态、场景、动态特征抽取和动态概念抽象服务。
- `初始化()` 按依赖顺序初始化全部新版结构，并建立或读回唯一根场景。
- 提供子场景、场景内存在、存在/场景特征、迁移和只读投影入口。
- 特征变化入口先读回同类型最近状态并拒绝时间倒退，再调用场景类更新当前值和生成状态；具备合法前状态时建立原子动态、挂入场景并尝试一次动态概念识别/单层抽象。
- 动态挂接失败时尝试删除尚未进入场景的动态；特征、状态或已经登记的动态事实不因后继概念处理失败而被伪回滚。
- 第一个同结构动态没有聚合候选时，以“完成并保留实例概念”返回；概念冲突和后段失败独立回显。

## 4. 代码知识变更清单

以下函数均为新增，模块为 `海中鱼巣::新_世界树类`，公开函数声明位于 `海中鱼巣/业务/新_世界树类.h`，唯一非 inline 定义位于同名 `.cpp`：

- `新_世界树类::新_世界树类() noexcept`：装配新版服务对象；不建立机器事实。
- `新_世界树类::~新_世界树类()`：按成员逆序释放编排对象；不删除全局机器事实。
- `新_世界树类::初始化() noexcept`：初始化新版结构并建立/读回根场景。
- `新_世界树类::已初始化() const noexcept`、`获取世界树根场景()`：读取当前编排对象与根场景状态。
- `获取先天特征概念()`、`建立特征概念(...)`：经特征概念类提供语义入口，不复制概念事实。
- `建立子场景(...)`、`建立场景内存在(...)`、`迁移子场景(...)`、`迁移存在(...)`：转交场景类执行世界树组织操作。
- `给存在添加特征(...)`、`给场景添加特征(...)`：转交场景类建立实例特征和首状态。
- `更新存在特征并形成动态(...)`、`更新场景特征并形成动态(...)`：完成“当前值变化—状态—原子动态—场景登记—动态概念处理”的综合语义链。
- `建立原子动态(...)`、`建立复合动态(...)`：建立动态后统一完成场景挂接和概念处理。
- `查询场景/存在/特征/状态/动态/动态概念`：返回对应唯一 owner 的值式读回。
- `查询直接子场景/直接成员存在/场景状态/场景动态`：返回场景组织投影。
- `查找最近同类型状态(...)`：私有只读辅助，按存在、同一特征类型概念树和强时间选择唯一最近状态。
- `完成动态发布(...)`：私有编排辅助，处理场景挂接、失败回滚和概念处理结果映射。
- `新世界动态发布结果::成功() const noexcept`：只判断四种完整动态发布结果，不改变事实。

新增调用边：`新_世界树类` 单向调用上述新版领域服务和两项新版业务服务；没有任何下层服务反向依赖 `新_世界树类`。
