## 2. 实际变更

- `海中鱼巣/领域/概念_动态类.h/.cpp`
  - 新增复合实例动态概念建立入口。
  - 每个原子成员概念必须提供恰好一项状态变化材料；复合实例概念按调用方已经确定的成员顺序复制这些材料。
  - 跨特征状态出现时间二次特征直接保存为复合概念自身的动态特征。
  - 复合概念不持久引用成员原子实例概念，避免原子动态改用聚合概念后形成悬空引用。
  - 建立过程中任一字段、项节点、组织关系或完整读回失败时，清理本次已建概念材料。
- `海中鱼巣/领域/新_动态类.h/.cpp`
  - `建立复合动态()`在成员、串行通道和跨特征时间材料核验完成后建立专属实例动态概念并写入动态概念字段。
  - 复合动态建立失败时同步清理已建立的实例概念、动态字段、成员关系、派生项和成员引用。
  - `获取动态()`要求原子与复合动态都具有合法概念；实例概念必须反向对应当前动态。
  - `采用聚合动态概念()`允许原子和复合动态把专属实例概念替换为已有合法聚合概念。
  - `删除动态()`对原子和复合动态统一解除概念字段，并在原概念为实例概念时删除该专属概念。

### 3.2 专项运行

专项入口与状态建立测试接缝只存在于隔离目录，没有写入仓库。

```text
Debug:   composite-instance-concept-ok
```

实际覆盖：

1. 由三个跨两种特征类型的原子动态建立复合动态，建立结果和正式读回均返回非空动态概念节点。
2. 专属实例概念准确反向绑定复合动态；状态变化项数量等于原子成员数量；动态特征项数量等于跨特征时间项数量。
3. 每项概念动态特征的顺序、二次特征类型、准确时间差、结果值域和前后来源状态与复合动态材料一致。
4. 两个同结构复合实例概念能够形成聚合概念；复合动态能够采用该聚合概念，原专属实例概念随即删除。
5. 删除采用聚合概念的复合动态不会删除共享聚合概念。
6. 删除仍采用专属实例概念的复合动态会删除该专属概念，同时三个原子成员及其概念仍可完整读回。
7. 同特征串行通道端点不连续时仍返回`端点不连续`，不发布复合动态或复合实例概念。

## 4. 代码知识变更清单

### 新增函数

1. `动态概念建立结果 概念_动态类::建立复合实例动态概念(稳定编码, const std::vector<稳定编码>&, const std::vector<动态概念特征项>&) noexcept`
   - 模块与位置：`概念_动态类`，`海中鱼巣/领域/概念_动态类.h/.cpp`，公开成员函数。
   - 用途：为一个已经建立但尚未正式读回发布的复合动态建立专属实例概念；复制各原子成员概念的一项状态变化材料并保存跨特征时间特征。
   - 非职责：不建立复合动态、不改变成员动态概念、不长期保存成员概念引用、不执行聚合抽象。
   - 参数来源：实际动态节点来自`建立复合动态()`本次新建节点；成员概念按规范化成员动态顺序取得；跨特征时间特征来自同次二次特征计算结果。
   - 结果与错误：成功返回`已建立`和概念节点；来源不足、概念不存在、状态数量不合法、入口拒绝、资源失败与结构不一致分账返回。
   - 事实与生命周期：写入实例概念节点、状态变化项、动态特征项及概念图根组织关系；失败清理本次材料；后续由动态删除或聚合概念替换入口删除。
   - 新增调用边：`新_动态类::建立复合动态()`调用本函数；本函数调用动态概念读回及基础数据集节点、字段、关系能力。
   - 用途卡状态：当前无覆盖本函数的现行用途卡，发布后待知识库维护者新建或复核。

### 修改函数

1. `新动态建立结果 新_动态类::建立复合动态(稳定编码, const std::vector<稳定编码>&) noexcept`
   - 在原有原子成员、串行通道和跨特征时间计算之后增加专属实例概念建立、字段绑定、完整读回及失败清理。
   - 返回结果新增实际复合动态概念节点。
2. `std::optional<新动态信息> 新_动态类::获取动态(稳定编码) const noexcept`
   - 原子和复合动态统一要求合法概念；实例概念必须反向对应当前动态；复合动态读回返回概念节点。
3. `新动态操作状态 新_动态类::采用聚合动态概念(稳定编码, 稳定编码) noexcept`
   - 取消仅限原子动态的限制；复合动态在满足同一实例概念、上位聚合关系及读回条件时使用相同替换生命周期。
4. `新动态操作状态 新_动态类::删除动态(稳定编码) noexcept`
   - 原子和复合动态统一解除概念字段；实例概念随动态删除，共享聚合概念保留。
