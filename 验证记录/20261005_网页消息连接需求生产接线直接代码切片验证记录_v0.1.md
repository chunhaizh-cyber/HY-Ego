## 1. 本片目标与边界

本片只接通以下生产链：

```text
网页新消息
-> 上层接纳后宿主才保存并递增序号
-> 当前网页会话交互者存在
-> 自我“当前交互者”存在引用特征
-> 服务根下本能定义来源的连接子需求
-> 当前事实重新读取并复核为已满足
```

明确不包含：自然语言理解、具体服务目标、任务建立或执行、服务值结算、网页回复、跨进程消息账和多会话切换。

## 2. 实际代码变化

- 网页宿主增加消息接收回调；上层拒绝时返回 HTTP 503，不保存消息且不递增序号。
- 普通需求增加 `本能定义` / `任务子目标` 来源；本能定义不带承接节点并可正式建立，任务子目标仍须通过未接通的强类型任务承接门禁。
- 普通需求支持存在引用准确值按目标存在概念复核。
- 二次特征概念的材料相似度窄扩展为可引用同一特征类型的非 I64 目标概念；“包含于/不包含于”分别使用精确相似度 10000 / 非 10000 的结果域。其它算法保持原限制。
- 普通应用增加网页消息结构化入口：首条消息建立会话标识材料和概念、交互者存在、自我当前交互者特征、比较关系及连接子需求；同序号同正文精确复用，异义拒绝，下一连续序号复用既有事实。
- 普通控制面板启动路径把网页宿主回调接到普通应用入口。
