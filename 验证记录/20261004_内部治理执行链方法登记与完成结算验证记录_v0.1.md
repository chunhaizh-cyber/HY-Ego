## 3. 实际代码变更

### 3.1 世界语义层方法登记入口

新增：

```cpp
新方法建立结果 新_世界树类::登记方法(
    const 新方法登记请求& 请求) noexcept;
```

该入口只在世界树和方法根已经初始化后，把完整请求转发给既有唯一 `新_方法类` owner。它不初始化方法根、不登记 C++ 本能函数、不执行动作、不建立第二方法仓或第二事实入口；异常统一返回资源失败。

### 3.2 影响评估精确匹配修正

修改：

```cpp
新任务影响评估结果 新_任务类::评估方法执行影响(
    稳定编码 任务节点,
    稳定编码 执行实例节点) noexcept;
```

修正两项错误：

1. 预计变化与实际状态不再要求实例概念稳定编码完全相等；仍要求同一存在、同一实例特征，并分别核验预计概念和实际概念属于结果方案冻结的同一特征类型根。
2. 预期值域不再用实例历史聚合概念代替本次实际值；改为用状态中固定准确值查找该类型下最具体概念，再与预期值域比较包含关系。

因此，实例概念因历史值域扩大而变化不会误伤合法状态，概念聚合范围也不会反向限制本次真实实例值。
