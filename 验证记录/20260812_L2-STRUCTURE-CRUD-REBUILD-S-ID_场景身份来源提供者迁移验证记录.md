## 2. 静态与代码复核

- 父子新增、替换、退出分别验证涉及的全部场景端点来源。
- 成员新增、替换、退出不再调用 `读取完整存在`，只消费 E-ID 身份来源。
- 反向成员查询不再调用 `读取完整存在`，并逐个验证源场景 S-ID。
- 当前 / 历史完整读取使用相同请求期望代次和历史截止形成来源闭环；属性只接受四项场景登记类型。
- 退出写集显式包含 `族归属关系稳定编码`，退出结果正式读回 `已退出身份来源`。
- 十个公开写入口均在读取登记或提交前调用 `是保留登记幂等身份`，源码计数 10。
- 历史来源具备前后两次事实代次探测；当前 / 历史均核 owner 读取头、独占范围、锚点 / 类型 owner、普通节点形状、创建代次和覆盖生命周期。
- 父子 / 成员关系投影显式接收场景 owner；属性投影显式接收场景来源 owner，不再以事实自身 owner 形成恒真检查。
- 新增场景成功 / 精确重复同时历史读回节点和族归属关系，核对同 owner、同创建代次和精确方向 / 类型 / 角色。
