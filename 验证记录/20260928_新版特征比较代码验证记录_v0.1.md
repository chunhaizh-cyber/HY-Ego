## 2. 实际实现

1. 保留既有`执行比较规则(...)`及其写入去重调用，不改变原添加特征值路径。
2. 新增单特征概念关系查询，返回同一、左为上位、右为上位、共同上位或无可比关系，同时返回特征类型根和最近共同上位。
3. 新增值域关系比较，返回相等、左包含右、右包含左、相交或分离，不把值域关系强行换算成相似度。
4. 新增准确值比较入口：
   - I64标量返回饱和有向差值；
   - 多维I64先查找左右准确值对应的最具体单特征概念，再返回逐维相对比例、等权汇总的相似度；
   - RGB使用固定`0～255`通道范围计算相似度；
   - 二维轮廓的每个分辨率层均直接由原始二值图按面积覆盖率生成，不再使用逐层`2×2 OR`；灰度覆盖率按8个`uint8`打包进一个`uint64`；
   - 每层先取得原始占用像素的最小包围框，保持长宽比缩放：长边填满目标可用区域，短边居中，奇数余量允许两边相差一个像素；
   - 原图最外圈为空白时，各目标层最外圈保持为0，包围框只映射到目标层内部；原图存在贴边像素时不强制增加边界；
   - 轮廓比较从8×8灰度根层开始，按归一化灰度绝对差计算相似度；任一层低于50%立即返回`0`，否则返回双方最细共同层的相似度；
   - 三维体素不直接比较，分别形成沿Z、Y、X方向的`XY/XZ/YZ`三张正交轮廓投影，各自执行轮廓比较后等权平均；
   - 完全相同材料返回`10000`；没有适用量化算法的其它非I64不同材料返回`-1`。
5. 新增实例特征比较入口，按双当前准确值、准确值与历史聚合值域、双历史聚合值域、仅特征概念的顺序选择材料。实例准入值域不作为实际表现参与比较。
6. 同一特征概念但双方都没有实际材料时，返回相似度`-1`，不返回`10000`。

### 5.1 实现结果

新增三个互不替代的公开入口：

- `新_特征类::比较特征概念值域关系(...) const noexcept`
  - 只返回同一特征类型根内两个概念值域的相等、包含、相交或分离关系。
- `新_特征类::计算特征概念值域重叠度(...) const noexcept`
  - 有限I64区间、稳定编码集合和结构化I64值域使用交并比，返回`0～10000`。
  - 全材料域与有限域之间没有可计算的集合基数时返回`规则不支持`，不伪造分数。
- `新_特征类::计算特征概念材料接近度(...) const noexcept`
  - I64区间使用值域中位代表值；结构化I64逐维取代表值，RGB复用固定`0～255`算法，其它结构化I64复用多维相似度算法。
  - 有限材料节点集合按左右双向最佳匹配平均；轮廓和体素复用既有材料比较算法。
  - 只有精确相等而没有量化算法的材料，不把“不相等”错误解释为相似度`0`，而返回`规则不支持`。

共同准入规则为：两个输入都必须是特征概念节点，必须属于同一特征类型根，并且材料类型、单位和比较规则一致。不处理存在概念、多特征组合概念、归类或共同点提取。

数值安全修订：

- I64闭区间长度和中位代表值先映射到无符号有序编码计算，避免有符号溢出和浮点转回I64越界；
- 结构化值域不再直接连乘左右体积，而按“交集占左/右比例”换算交并比，避免高维体积溢出为无穷；
- 跨兄弟概念的材料接近度使用共同特征类型根和材料类型，不再要求右材料命中左子概念值域。

## 7. 历史值命中、稳定标准值与多区间归组

续作起点：`ad8f522bde99c800b8867cbafcf9e22925d91d05`

用户确认的直接代码口径：

- 每个历史准确值保存命中次数；
- 区间标准值首次形成后保持稳定，只有候选命中次数严格超过当前标准值时才替换，并列不替换；
- 新值连接多个区间时不自动合并，按各区间标准值相似度选择唯一最高者；最高分并列时固定选择稳定编码较小的区间；
- 归组区间扩大时允许修改对应特征概念值域。

### 7.1 实际实现

1. 新增历史值命中记录节点，以`准确值 + I64命中次数`保存每个不同准确值；保留公开`历史不同值`读回，同时新增`历史值命中信息`。
2. 每个实例特征新增独立标准值。首次值成为标准值；候选命中次数严格大于现标准值时替换；相等时保持原标准值。
3. 初始归组阈值固定为`9000`：
   - I64标量采用连续连接归组，新值与区间任一成员达到阈值即可连接；
   - 其它材料采用紧密相似归组，新值与区间标准值达到阈值才连接；
   - 没有材料接近度算法时按不可比较处理，不错误加入既有区间。
4. `0`个区间时不形成概念；首值形成单区间概念但不建立子特征；出现第二个区间时，为两个区间分别建立子概念和子特征。
5. 多区间阶段由父特征持有的归组子特征保存区间成员引用、标准值、当前值和聚合域。新值命中多个区间时先比较标准值相似度，同分按子特征稳定编码升序选择；不调用区间合并。
6. 归组区间扩大时直接修改既有特征概念的值域，不建立替代概念；概念信息是可修改事实，不适用不可变共享对象口径。
7. 由概念生成的实例拥有自己的准入值域副本。概念值域改变不自动改写其它既有实例；本次归组只更新当前接收子特征的实例准入值域。
8. 结构化I64根概念现在允许以准确材料节点集合形成严格下位概念；每个节点的I64数组必须逐维命中上位结构化值域。
9. 子特征成员关系复用父特征的命中记录节点，不重复累计出现次数；共享记录携带所属父特征，只有该父特征及其直接归组子特征可以读回。

## 8. 实例建立时按实际值选择最具体概念

用户确认的建立顺序：

```text
先检查持有节点下是否已有传入概念对应的实例
→ 有则复用
→ 无则定位同一特征类型概念树
→ 提供实际值时查找包含该值的最具体概念
→ 以选定概念为模板建立实例特征
```

实现结果：

- `新_特征类::建立或取得特征(...)`新增可选实际值参数；既有两参数调用保持原行为。
- 未提供实际值时，继续直接采用传入概念作为模板。
- 提供实际值时，通过`比较单特征概念(...)`取得特征类型根，再调用`查找值对应的最具体概念(...)`；只有唯一找到时才建立实例。
- 选定模板后再次检查持有节点下是否已有该模板概念对应的实例，有则复用，避免重复节点。
- 建立实例时复制选定概念的值域和单位；可选实际值只参与概念选择，本函数不写当前值、历史值或命中次数。
- 未找到、匹配冲突、概念结构异常或实例重复冲突均返回空稳定编码，不降级采用上位概念。

仓库外验证增加：

- 建立`I64全域 → 0～100 → 20～30`三级概念链；
- 以类型根和实际值`25`建立实例时，模板准确选择`20～30`概念；
- 实例准入值域复制为`20～30`，当前值仍为空；
- 相同输入重复调用返回同一实例节点；
- 四个相关实现源文件独立编译通过；命中次数、I64归组、RGB归组和概念可变/实例字段独立四组既有验证继续通过。

代码知识变更：

## 9. 实际值权威与正式所属概念反馈

本段直接代码切片起点：`8f644cd7dd651e45cc3a2af6abe8352c1d4260ce`

用户确认的当前口径：

```text
实际值及历史值是唯一事实来源
→ 概念值域只用于分类和归纳，不能作为实例值准入门
→ 实例历史聚合值域由全部实际历史形成
→ 实例正式所属概念随历史域细化、扩大或改挂
→ 概念值域变化后检查兄弟概念的相等和包含关系
```

### 9.1 实际实现

1. 从`新特征信息`和物理字段中删除`实例准入值域`；建立实例不再复制概念值域。
2. 删除`单区间概念字段`旁路。单一区间和多区间都只通过正式`特征概念字段`表达实例所属概念。
3. `建立或取得特征(...)`提供实际值时只核验材料物理类型：
   - 找到唯一最具体概念时采用该概念；
   - 未找到或匹配冲突时采用特征类型根继续建立实例；
   - 本函数仍不写当前值和历史值。
4. `添加特征值(...)`与`比较特征值(...)`不再检查实际值是否落入概念区间，只检查I64直值或特征值节点的材料物理类型。
5. `获取特征(...)`不再要求当前值、历史值和历史聚合值域落入概念值域；仍核验材料类型、历史去重、命中次数、标准值和聚合读回一致性。
6. 每次历史聚合值域发布后同步修正正式所属概念：
   - 当前概念包含历史域时，沿子链复用最具体包含概念；不存在准确概念时建立严格子概念并改挂实例；
   - 历史域扩大并包含当前概念时，必要时先把当前概念改挂到能包含新域的最近祖先，再直接扩大当前概念值域；
   - 已有概念不能覆盖实际历史时，允许扩展特征类型根的同表示值域，再建立准确历史域概念；
   - 概念变化后，等值兄弟优先复用；当前包含兄弟时将兄弟下挂，兄弟包含当前时将当前下挂；相交或分离不自动合并。
   - 即使历史域没有再次变化，也会重新核验当前概念与直接上位：等值时实例改挂上位，越界时当前概念向最近合法祖先重新挂接；没有可包含祖先时先扩展特征类型根。
7. 子特征不再受父实例准入域限制：相等子域可复用父概念，严格子域建立下位概念，父概念不能包含时回到同一特征类型根建立合法概念。
8. I64数组的可选概念抽象查找未命中或冲突时不阻止准确材料相似度兜底；材料类型或结构错误仍明确失败。
9. 特征概念保存`当前引用实例数量`：
   - 新概念从`0`开始；只有实例特征的正式`特征概念字段`直接引用才计数，概念父子关系不计数；
   - 新实例完成字段和持有关系建立后加一，复用已有实例不增加；
   - 实例改挂概念时先给新概念加一，再修改正式概念字段，最后给原概念减一；字段修改失败时减少新概念计数，原概念减少失败时恢复实例字段并减少新概念计数；
   - 每次引用计数减少后立即判断：减少后为`0`且没有子概念节点时删除概念节点及其字段、结构化分量和概念树关系；根链节点与普通下位概念采用同一条件，没有类型例外；
   - 数量禁止为负并防止I64上溢；当前尚无实例特征删除入口，因此删除实例时减计数尚未接线。
