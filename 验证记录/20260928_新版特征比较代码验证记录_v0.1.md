## 2. 实际实现

1. 保留既有`执行比较规则(...)`及其写入去重调用，不改变原添加特征值路径。
2. 新增单特征概念关系查询，返回同一、左为上位、右为上位、共同上位或无可比关系，同时返回特征类型根和最近共同上位。
3. 新增值域关系比较，返回相等、左包含右、右包含左、相交或分离，不把值域关系强行换算成相似度。
4. 新增准确值比较入口：
   - I64标量返回饱和有向差值；
   - 多维I64先查找左右准确值对应的最具体单特征概念，再返回逐维相对比例、等权汇总的相似度；
   - RGB使用固定`0～255`通道范围计算相似度；
   - 二维轮廓使用与特征值保存相同的逐级`2×2`占用汇总算法生成比较层级，单个`uint64`根不同立即返回`0`；根相同后逐层细化，任一层相似度低于50%立即返回`0`，否则返回双方最细共同层的位相同比例；
   - 三维体素不直接比较，分别形成沿Z、Y、X方向的`XY/XZ/YZ`三张正交轮廓投影，各自执行轮廓比较后等权平均；
   - 完全相同材料返回`10000`；没有适用量化算法的其它非I64不同材料返回`-1`。
5. 新增实例特征比较入口，按双当前准确值、准确值与历史聚合值域、双历史聚合值域、仅特征概念的顺序选择材料。实例准入值域不作为实际表现参与比较。
6. 同一特征概念但双方都没有实际材料时，返回相似度`-1`，不返回`10000`。

## 4. 代码知识变更清单

### 新增公开函数

- `概念_特征类::比较值域(...) const noexcept`
  - 用途：比较同一材料类型下两个值域的集合关系。
  - 非职责：不产生相似度、不建立概念、不修改概念树。
- `概念_特征类::比较单特征概念(...) const noexcept`
  - 用途：读取同一根链内两个单特征概念的上下位或共同上位关系。
  - 非职责：不处理多特征类型组合概念。
- `新_特征类::比较特征值(...) const noexcept`
  - 用途：使用给定实例特征的概念、单位和准入域比较两个准确值。
  - 调用边：调用概念读回、最具体概念查找、单特征概念关系和特征值读回。
- `新_特征类::比较特征(...) const noexcept`
  - 用途：完整读回左右实例特征并选择实际比较材料。
  - 调用边：调用特征读回、单特征概念关系、准确值比较或值域比较。

### 保留且未改变语义的函数

- `概念_特征类::执行比较规则(...) const noexcept`
- `新_特征类::添加特征值(...) noexcept`

二者继续承担准确材料等价判断和历史去重；本切片没有把新实例比较结果反向接入写路径。

### 本轮修改的私有实现

- `比较双准确值(...)`
  - 增加RGB、二维轮廓和三维体素三类先天材料的分派；公开签名不变。
- 新增RGB固定范围相似度、轮廓压缩层生成、二值层相似度、体素正交投影及投影比较等匿名命名空间辅助函数。
  - 用途：只支撑`新_特征类`内部比较。
  - 非职责：不修改特征值持久结构，不直接比较三维体素，不提供旋转、平移或缩放不变性。
