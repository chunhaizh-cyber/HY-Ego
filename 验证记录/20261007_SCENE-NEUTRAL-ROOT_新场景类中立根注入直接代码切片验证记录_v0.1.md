# 新场景类中立根注入直接代码切片验证记录 v0.1

## 1. 切片身份

- 用户直接代码目标：修订 `新_场景类`，使场景树根只能由上层以参数传入；场景类保持中立，存在、状态、动态等底层类不得反向引用场景类。
- 起点：`80646450fb1a74ca6d27923f6399b3da6e3477fe`
- 分支：`main`
- 所有者：当前交互智能体。
- 明确不修改：现有流程图、规范、计划、数据目录及根目录构建残留。

## 2. 实际变更

1. 删除全局 `场景树根节点` 声明和定义。
2. `新_场景类`构造时接收由上层持有的根句柄引用，并新增只读`获取根场景()`。
3. `新_世界树类`持有现实世界根句柄并传给场景服务。
4. `新_场景类::是场景节点()`除核验场景结构身份外，还沿唯一父链核验节点属于本服务实例绑定的根；根必须没有父场景。
5. 任务类不再读取全局场景根，改从所持场景服务取得对应根。
6. 删除存在、状态、动态类对`新_场景类`的前向声明和友元；场景编排所需的中立初始化、清理和引用计数入口改为公开底层接口。

## 4. 代码知识变更清单

### 新增或改变的稳定函数

- `新_场景类::新_场景类(稳定编码&, 新_存在类&, 新_状态类&, 新_动态类&) noexcept`
  - 根句柄来源改为上层世界对象；场景服务不拥有全局根。
- `std::optional<稳定编码> 新_场景类::获取根场景() const noexcept`
  - 返回本服务实例当前绑定且结构有效的根。
- `bool 新_场景类::是场景节点(稳定编码) const noexcept`
  - 从仅验证节点类型改为同时验证本根可达性和唯一父链。
- `新_存在类::初始化存在节点(...)`、`新_存在类::清理存在节点内容(...)`
  - 函数行为不变；由场景友元私有入口改为不感知场景的公开底层入口。
- `新_状态类::{增加引用, 撤销增加引用, 减少引用}`
  - 函数行为不变；由场景友元访问改为公开中立引用生命周期入口。
- `新_动态类::{增加引用, 撤销增加引用, 减少引用}`
  - 函数行为不变；由场景友元访问改为公开中立引用生命周期入口。

### 调用边变化

- `新_世界树类 -> 新_场景类`：新增世界根句柄构造注入。
- `新_任务类 -> 新_场景类::获取根场景`：替换对全局根的直接读取。
- `新_存在类／新_状态类／新_动态类 -> 新_场景类`：删除全部反向声明和友元边。
