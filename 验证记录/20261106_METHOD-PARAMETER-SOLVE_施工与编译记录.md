## 3. 切片C：筹办实参求解

`核验任务条件和参数内部` 对有序方法在逐位置循环前整体预解：
1. 实参场景 = 自我（`自我服务结算配置_` 未配置时退回需求目标存在）所属场景，读取其完整子树一次，不上溯。
2. 存在位置候选：范围概念匹配且具有全部必需特征类型；固定采用只保留冻结节点；概念材料不足沿原口径报“参数概念未确认”。正式信息参数位置沿原分支。
3. 配对排序：结果项为目标特征类型且结果域保证满足目标为1等；变化方向与目标方向相同为2等，相反排除；其余3等（含只有条件的配对）。
4. 按序收窄：结果作用对象（特征位置取所属存在位置）收窄为需求目标存在；条件项的存在概念与特征值域排除未命中对象（值未到不排除）。首个使全部存在位置非空的配对为依据；都不满足时按首个配对报缺口。
5. 存在位置取稳定编码最小者；特征位置取所属已绑定对象上范围概念兼容的特征（0个报“参数特征类型未取得”，多个结构缺口；所属未绑定不单独报）。
6. 条件项阶段：已在绑定阶段报过缺口的位置不再追加“参数对象未取得”。
旧逐层上溯扫描删除；诊断宏 `HY_EGO_DEBUG_LOG_PARAM_BINDING` 改为记录候选判定与收窄后候选数。

## 4. 与详细设计的偏差

- 第5节第7项“选择一致性回筹办”与筹办项“绑定依据配对”字段未实施：选择阶段按实际绑定逐配对核验条件，依据配对的条件按构造成立；若选择改选另一配对，该配对条件同样已在这组绑定上核验成立，执行合法，不需回筹办。
- 第5节第2项执行分支必要条件未单独过滤：配对条件按 `配对分支来源有效` 已涵盖分支必要条件，由第4项收窄覆盖。
- 收窄只用条件项的 `特征值域概念节点` 与 `存在概念节点`；`精确数值域` 条件不参与收窄，仍由后续条件核验判定。
