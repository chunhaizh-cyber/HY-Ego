## 2. 施工内容

- **S1 表示与持久**（`概念_特征类.h/.cpp`）：三种集合值域各加 `含概念成员组`、`全部属于概念组`；共用字段 `集合含概念成员字段`、`集合全部属于概念字段`，登记于结构检查、初始化、schema 不重叠列表与零引用清理列表；规范化排序去重，概念成员非空时“至少一个”归零；建立、更新（含存在集合原子更新删旧写新）、主读取器、定义保护读取器读写两组；概念节点进入定义保护闭包。规则状态末尾追加 `成员归属未知=11`；归属结果类型 `特征成员概念归属{属于,不属于,未知}` / `特征成员概念归属结果`；三个成员读取接口各加默认返回“读取接口未装配”的虚函数。
- **比较（v0.2 §5）**：满足判定加概念项（不满足/未知分账，未知→`成员归属未知`）；蕴含三态（`集合三态`、`组合蕴含`）；值域关系约束对约束按三态蕴含与联合可满足性组合（`组合约束关系`、`约束联合可满足`），无法定论返回 `成员归属未知`；有限快照对约束按命中/未命中/未知计数，有未知时仅命中与未命中并存才证明相交；`查找值对应的最具体概念` 中未知不算命中、不报结构错误；建立/更新前 `集合概念项可建立`：概念节点须存在，实例成员被证明不属于概念子集则拒绝。
- **新_特征类**：比较状态末尾追加 `材料不足=13`，`成员归属未知` 映射为它。
- **S2 存在归属**（`新_存在类`）：`判定存在集合成员概念`：上位链可达即属于，否则 `采集存在概念匹配材料` 特征合取，匹配/不符合/材料不足→属于/不属于/未知，采集期间变化→前提已变化。
- **S3/S4 需求、任务、方法归属与嵌套判定**（子智能体）：`概念_存在类` 增加 `正式已解析路径值`（实例＋完整路径定位、五状态、重复为定义故障、保护并入复核）、`正式结构范围判定器`（引用型内容遇信息结构范围交对应 owner，递归防护深度 8）、`正式结构概念属于`；`信息内容.数据.h` 追加任务引用、方法引用；`新_需求类` 无锁直接内容读取与 `判定需求集合成员概念`；`新_任务类` 无锁 `判定任务集合成员概念`（状态与服务值经路径值，引用项嵌套判定，前后快照比对）；`新_方法类` 无锁 `判定方法集合成员概念`。
- **消费者**：`新_任务类` 当前值命中概念把 `成员归属未知` 当材料未到；选择任务结果分支中存在集合目标带概念项时不认作保证满足；`方法问题归档.模拟世界` tie 加两组；`新_模拟世界类` 本地语义快照遇概念项显式拒绝；`模拟学习` 存在集合取样遇概念成员按不支持（不以空集原型代替）。
- **S5 模拟学习**：无结果样例的存在集合条件改为概念成员约束（成员为有序普通存在参数 j 的实参时取其范围概念；非空且无概念项时至少一个存在）；新增 `新_方法类::保存模拟集合约束值域`（本切片仅存在集合）。“集合包含存在”关系照常保留。

## 3. 与设计 v0.2 的偏差

1. §5.2 ⊑ 只按概念相同认定，未接 `存在概念包含` / `正式结构概念属于` 上下位链，也未用实例成员归属证明概念成员：只会多出“未能判定”，不会误判。
2. §5.4 证明不可满足只用“实例成员不属于概念子集”，未用概念相交判据；证明可满足要求概念成员等于概念子集。
3. §3.1 概念合法性：建立时只核节点存在与可证明的不可满足；概念种类由 owner 判定时返回入口拒绝。
4. §3.3 保护：概念节点快照进入定义保护闭包，未取上位链保护。
5. §6 `新_模拟世界类` 本地语义快照：显式拒绝含概念项的集合值域，未序列化（该路径服务服务要求语义快照，非学习路径）。
6. 任务集合其它 `比较任务集合条件` 调用点未适配 `成员归属未知`（本切片不生成含概念项的任务集合值域）。
7. 子智能体偏差：方法下位子概念（221/222 等）一律未知（继承成员组织项，通用判定器不判成员组织）；嵌套判定“接口未装配”在符合状态中映射为未支持，由 owner 依赖标志还原为读取接口未装配；路径项不适用记不适用但不降级整体；任务“采用方法”取最近方法节点，执行组织只核节点存在；需求身份核验为 `判定被认知需求内容保护` 的子集。
