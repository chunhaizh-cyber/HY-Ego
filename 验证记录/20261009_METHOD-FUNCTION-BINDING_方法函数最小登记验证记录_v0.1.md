# METHOD-FUNCTION-BINDING 方法函数最小登记验证记录

来源：用户直接代码切片。起点：`main@c3c7ae2de500020dc238cd1e70a0650a28ae612e`。

## 冻结范围

本切片把方法知识建立与本能函数调用绑定分开：

```text
方法知识建立 = 方法头 + 唯一方法虚拟存在 + 参数规格 + 条件—结果知识
函数登记     = 已存在本能方法节点 -> 稳定登记名 -> C++函数入口
```

函数登记不建立方法身份，不读取或写入参数规格、条件—结果和方法虚拟存在内容，不执行函数，也不建立动作动态。参数场景仍是实际调用函数时的统一只读容器，不属于登记材料。

## 实际变更

- 原`新_方法类::登记方法`改名为`建立方法知识`，请求DTO改为`新方法知识建立请求`，不再接收或验证本能函数登记名。
- 本能方法知识允许暂时没有函数绑定；`获取方法`仍能完整读回方法知识，`调用本能函数`则明确返回`函数未登记`。
- 新增`新_方法类::登记本能函数(稳定编码,const std::string&)`：只接受已有本能方法节点和已进入进程注册表的稳定登记名。
- 首次绑定返回`已修改`；同名重复返回`无变化`；异名重绑返回`函数登记冲突`；组合方法返回`方法类型不符`；未解析登记名返回`函数登记不合法`。
- 单字段发布后立即读回；读回不一致或异常时删除本次新增字段，避免留下半绑定。
