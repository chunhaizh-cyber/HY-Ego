# 动态概念自动识别与分层抽象验证记录 v0.1

日期：2026-10-02

代码切片：用户直接授权的动态概念自动识别与一层抽象实现

起点：`85f44f2e6af06c52b41e39c22c3455bf6922f3db`

分支：`main`

## 1. 本次范围

本切片只实现以下链路：

```text
动态实例概念保存已抽取二次特征
→ 按状态槽位和动态特征槽位判断完整包含
→ 唯一最具体已有概念识别
→ 无包含候选时按是否变化、方向、幅度选择最近同结构概念
→ 形成一层上位动态概念
→ 当前动态采用聚合概念
```

不自动生成速度、加速度、周期等新的高层特征类型；不一次递归生成多层抽象；不修改世界树、自我线程、正式规范或其它活动切片。

## 2. 实际代码结果

1. 动态概念状态项的准确相对时间改为可选：实例保留准确时间，聚合概念在来源时间不一致时表示“不限定准确时长”。
2. 动态概念特征项的准确结果改为可选：实例保留准确结果，聚合概念保存二次特征类型和结果值域。
3. 聚合函数同时聚合状态变化组和动态特征组；实例准确结果形成最小 I64 覆盖闭区间，已有聚合概念继续使用其结果值域。
4. 新增完整包含判断；状态槽位核对特征类型、前后值域和可选时长，动态特征槽位核对位置、二次特征类型和结果值域包含。
5. 新增全部动态概念查询，并由业务编排筛选唯一最具体包含候选。
6. 新增 `新_动态概念抽象类`：先抽取并保存实例动态特征，再识别已有概念；没有包含候选时，只形成一层上位概念。
7. 最近候选排序固定为：是否变化差异、方向差异、幅度距离；稳定编码只在距离完全相同时提供稳定顺序。
8. 修正动态间特征比较：聚合概念没有实例准确结果时明确返回“内部特征尚未生成”，不把结果值域伪装成准确结果。
9. 修正旧实例读回稳定性：后续新建更窄结果域概念时，不再要求实例保存的结果域仍是“当前最具体概念”，只要求准确结果仍被原结果域包含。

## 4. 代码知识变更清单

### 新增

- `海中鱼巣::新_动态概念抽象类::新_动态概念抽象类(...) noexcept`
  - 文件：`海中鱼巣/业务/新_动态概念抽象类.cpp`
  - 用途：绑定动态实例、动态概念、二次特征概念和动态特征抽取服务；不持有第二份事实。
  - 直接调用边：无业务调用者；由后续上层装配或治理流程显式构造。
- `海中鱼巣::新_动态概念抽象类::处理新动态(稳定编码) noexcept`
  - 用途：完成一次动态实例的特征保存、已有概念识别或一层抽象以及概念采用。
  - 非职责：不生成新的高级特征类型，不递归形成无限层级，不等待其它动态完成。
  - 直接调用：`新_动态特征抽取类::抽取`、`概念_动态类::保存动态特征`、`查询全部动态概念`、`判断动态概念包含`、`聚合共同动态概念`、`新_动态类::采用聚合动态概念`。
- `海中鱼巣::概念_动态类::判断动态概念包含(稳定编码, 稳定编码) const noexcept`
  - 用途：按完整状态槽位和动态特征槽位判断上位概念是否包含下位概念。
  - 结果：`已判断 + bool`；结构或资源失败不返回真假。
- `海中鱼巣::概念_动态类::查询全部动态概念() const noexcept`
  - 用途：返回动态概念物理组织中的可完整读回节点，升序去重。
