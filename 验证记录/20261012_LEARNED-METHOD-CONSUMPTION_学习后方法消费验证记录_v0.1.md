## 2. 实际改动

- 任务预计结果、禁止结果与冲突证据支持精确 I64 域；新增字段定义、初始化、写入、回滚账、读回、执行冻结及评估消费。概念域与直接域互斥，拒绝倒置、非有限端点、错误长度、非 I64 类型与单位不一致。
- 九处任务闭包检查保留方法结构及资源检查，不再仅因含合法精确域而拒绝。结果评估对 I64 实值调用统一特征值域比较，不用上位概念代替精确落域。无显式方向时只从完整域相对当前值的位置推导增、减或单点不变，跨值不猜方向。
- 精确条件经概念 owner 建立或取得等价概念，继续通过既有子需求提议交由 self 建立需求；不改抽象方法条件、不让 task 直接建立需求。
- 新增受方法学习影响任务查询及重新筹办入口。只对活动需求、合法根链、相关方法和四个安全筹办态处理；在途执行、终态及未知实例采用保护保留。
- 方法副本保存抽象配对来源。已有实例通过 COW 完整复制后增补，同源方法只增加未导入配对，新来源增加候选；旧收窄条件、旧实例及 X 引用不改不删。采用回调按当前旧根比较并切换，采用不明保留定位和图，禁止自动重复复制。
- 学习结束采用进程内交接编号幂等接收，self 保留通知直到 manager 接纳后再确认学习 worker。manager 完整展开事件，通过具名 self 复核后调用 task 重筹办，只释放可追溯 W1/W2 筹办阻塞；旧筹办工作许可不能再次派发 W3。
- `等待方法实例消费`改为实际未完成交接/复核/准备项的派生状态；学习未形成配对的合法事件按空集合消费，不误报学习失败。
- 服务结算消费者去除三处直接域硬拒，支持实例来源及 typed 等域匹配；原真实结果、动作、来源、状态时间及加一事实验证仍保留。
- 问题归档保留旧七字段布局，仅增加可选问题头尾部来源扩展。既有自检源码仅迁移函数签名与快照断言，没有运行。

## 3. 静态核对与修复

1. 新直接域字段写入前预留回滚账容量，防止字段形成后分配失败漏记。
2. 全部内部及公开执行信息读回统一核验直接域的 I64 类型、实际特征与单位。
3. 普通方法读取拒绝同一实例内重复来源配对，旧无来源标记仍可读；不只依靠 COW 入口判重。
4. manager 固定当前学习事件，避免晚到的小编号抢占已展开批次；旧工作编号失效记录避免复核为满足/等待后恢复旧 W3 许可。

`git diff --check`通过；LF/CRLF 提示不是编译警告。以上是静态核对，不是运行或故障注入证据。

最终独立定点复核确认来源配对重复缺陷已关闭；对先接纳后确认、交接重试、学习占用、self 需求复核、任务重新筹办资格、旧 W2/W3 许可失效及阻塞分类未发现新的确定阻断缺陷。此结论不扩展为并发或停止恢复实证。
