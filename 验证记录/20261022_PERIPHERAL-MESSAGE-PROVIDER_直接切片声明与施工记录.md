## 2. 冻结合同

- 本切片不是本能函数：直接保存外设真实收发事实，改变窗口的接收/发送消息引用集合；不解释人类、连接、求助或需求，不修改自我特征。
- 消息独立类型化身份，来源键为会话、页面、方向、宿主源序号；原文、正式记录时间、外设场景及窗口引用由既有真实入口提供。同键同正文复用原身份，不恢复已移除成员；同键异义工程终止。接收成功/完整socket写出才录入，不把排队/接纳当发送完成。
- 新消息先取得私有无类型空节点；正式消息身份、来源根持有、规范集合材料引用保护、F当前/历史/标准核心通过同次封存CAS发表。空节点不是正式消息，不向普通reader暴露。准备凭据私有构造且move-only，绑定空节点完整前提与必须参与的身份片段，不开放跳过成员校验开关。
- 特征概念增加消息集合身份判等=7，独立消息成员reader，U64数组、无单位、全材料域及有限完整材料聚合；不新增值域variant。不把消息冒充E/D/T。普通读取校验全部正式成员，快照保护参与CAS。
- 原六特征不改义；新窗口增加两个消息集合F，旧窗口按已有正式窗口/场景定位补建空集合，不从最后正文或旧计数伪造历史消息。旧数量/最后正文为兼容后继收尾：消息核心先成立，再按原入口更新；失败工程终止、保留正式消息，重复源交付不重复增加兼容计数。它们不宣称与消息核心同次CAS，不作为新连接依据。
- 当前集合移除不删除消息；来源根及集合材料以正式引用保护消息身份。无TTL或物理清理接口，不改变原始消息内容。观察/连接/语言按需读取，不强制每条消息交给自我。
- 状态、动态沿既有F→E→S/D完成链形成；核心发表后派生失败工程终止，不补造成功、不再次发送。外设reader只读L1快照，不取得外设业务互斥锁，避免F→外设与外设→F反锁。
- 允许：业务/新_外设世界树类.h/.cpp、装配.普通应用.cpp真实收发转交；领域/概念_特征类.h/.cpp、领域/新_特征类.h/.cpp，领域/新_存在类.cpp仅消息规则收尾准入，以及本记录。禁止改L1公开接口、方法7/4/3/6规格、连接、人类/需求、规范/索引、删除集或工程入口。

## 3. 接口及物理位置

外设owner扩展消息方向、来源键、正式消息信息DTO；公开按来源/身份读取、按窗口读取当前消息、移除当前消息引用；更新收发增加宿主来源序号，全部生产消费者同步。实现均在既有同名头源内，不新建工程文件。

概念owner提供消息成员读取接口及装配、消息保护字段、严格集合成员读取与比较。特征owner提供 `新消息待发表凭据` 和 `准备顶层消息集合更新`；凭据构造仅对外设owner可见。复用既有封存、组合提交、F历史聚合、存在特征变化收尾与场景状态/动态挂接，不新建L1分配API或公共预留账。

## 4. 实际施工与验证

施工源码核对发现既有状态→动态概念抽取对精确集合判等按T/D/E枚举选择算法。新消息规则必须同步接入该正常链，否则首次消息动态即被拒绝。允许范围据此补充 `领域/概念_二次特征类.h/.cpp`、`领域/新_二次特征类.cpp`、`业务/新_动态特征抽取类.cpp` 及 `业务/新_动态概念抽象类.cpp` 的消息判等消费者：增加消息集合判等算法=12，输入为同一个消息FT根，结果仍为0/10000，不引入数量方向或新观察事实。该适配不改变本切片目标、事务或权限。

已实现：

1. 外设消息方向、来源键、消息信息DTO；接收/发送更新增加真实来源序号。装配保留宿主上行号/发送提交号，并接纳同源无变化读回，不重复计数。
2. 外设窗口新增接收/发送消息集合F；首次建立空集合并形成初始状态，旧窗口只补空集合，不把旧正文/计数伪装为历史消息。旧六特征及旧连接参数解释保持。
3. 正式消息采用独立节点，保存来源会话、页面、方向、U64源序号、场景/窗口、正文材料、正式记录时间和消息owner；来源根明确持有消息。消息身份、集合材料成员保护、F核心一次CAS发布；来源键查重也以来源根完整快照作为CAS前提。
4. 凭据一次采用、不能复制或从普通编码公开构造；特征准备必须带入该身份封存片段，回执逐项互证且不改变既有调用方附加回执下标。其余正式成员及全部历史材料保持严格校验。
5. 提供按身份/来源读取、读取当前消息以及移除当前引用。移除保留本体及历史；相同来源再次交付不恢复被移除成员。新消息同正文异序号仍分别记录；同键异正文工程终止。
6. F核心完成后通过存在owner更新专属概念、生成状态，挂接外设场景并形成动态/动态概念。消息集合判等消费者补齐为类别0/10000，不生成数量方向或因果猜测。
7. 独立审查发现无业务锁reader跨批重读公共消息根可能把并发追加当结构损坏，已改为一次L1联合读取消息及其端点保护；首条空集合、token例外、历史聚合、移除去重链第二轮静态审查未再发现可定位阻断。该结果仅为源码审查。
