## 2. 实际实现与只读边界

公开入口 `新_语言类::按已登记词条最长匹配` 接收语言 ID、文本及借用的 const 词服务；输出临时值式 DTO，不创建节点。词条引用有值表示命中，为空表示未知。原文区间为零基字节/码点起点及长度；相邻未知码点合并，原文字节不变，词条重复出现保留各次位置。

先严格校验输入、获取语言，再枚举词 ID、逐项读取正式词 DTO，在本次局部码点 trie 中完成从左到右最长匹配。所有非成功结果为空片段组，不把服务错误降级成未知。有效空文本成功返回空组；合法空词库时非空文本保留为一段未知。

规范化与词存储一致：不做 NFC/NFKC、大小写、全半角、空白或标点折叠，不裁剪，不修复编码。拒绝非法/截断/过长 UTF-8、代理码点、超过 U+10FFFF、U+FEFF 和 U+FFFD；NUL 合法，使用字符串长度处理。码点不是字形簇。

本次词库边界为一次枚举得到的 ID 组，不吸收随后登记的新词。现有词服务无词条修改/删除公开入口；未承诺跨服务共同事务快照。每次读取由原服务自身持锁返回副本，匹配函数不持语言锁调用词服务，避免反向锁。分配异常返回资源失败和空组。

新增调用仅操作公开返回 DTO 与本次局部容器，没有读取底层节点/字段/词索引；没有初始化、建立、更新、删除、名称、概念或世界树调用。未新增服务读取接口。词、名称、自然语言世界树头源本轮无差异。
