## 3. 实际变更

1. 新增值式零动作恢复材料，保存本次撤销 X（若已建立）和开始前最近 M/X；只在 task owner 正式读回恢复成立后返回。恢复材料不是新的事实账或动作许可。
2. 空 X 撤销成功及精确重复统一回到待查找方法，保留原最近 M/X；只删除本次空 X 专属结构并清理其问题暂存。已动作、结束、实际状态或评估材料不准走此路径。
3. X 前合法条件/位置变化、X 后未调用时的合法来源重确认/条件变化，以及函数明确“参数不匹配、未进入、未取得、全部输出为空”走通用恢复。方法正式停用独立复核。函数未登记、未装配、调用异常或缺运行对不再被当成正常零动作。
4. 已动作先关联动作及可确认状态；工程异常保留 X 和既有事实并进入统一日志、弹窗、终止链，不撤销或重放。
5. manager 核验完整原请求、恢复 DTO、被撤销 X 真不存在和原最近 M/X；只作废原请求对应的旧筹办/裁决，废弃旧调度快照并唤醒正常筹办。新裁决、新 X、其它原因的等待不被按 T 广泛清除。迟到回执不覆盖新结果；worker 接收确认成功后才释放活动工作。
6. 保留现有 child-demand/self 决议路径，没有新增本能方法、子需求来源或组合分步执行。

独立复核发现并修复三个直接调用链问题：方向核验先将筹办工程错折业务等待；现存但不可读的 T 被当成已消失；当前 X 已有动作/输出与合法当前位置变化混淆。计划owner确认属于已冻结范围内纠错，未改计划合同。最终联合静态复核未发现剩余具名 P1/P2；它不是运行测试。
