## 1. 本次完成范围

在既有 `manager -> W1/W2 -> self筹办裁决 -> manager保存` 链路后增加一次真实执行前判断：

1. self只在W2中恰好一个方法、一个条件结果配对具备时请求执行方向核验；
2. 世界树综合服务fresh重算W2，确认方法、配对和结果定位仍是当前唯一具备项；
3. 把方法结果项的参数角色绑定为实际存在，形成单阶段预计特征变化；
4. fresh读取任务唯一需求、安全根需求和服务根需求；
5. 判断任务目标是需要增加还是需要减少，并要求预计值域保证命中目标或严格变化方向与其一致；
6. 对作用于自我的安全/服务特征预计变化分别核验，反向影响拒绝，含混方向不默认允许；
7. self返回允许、暂缓、拒绝、重新判断、缺少执行依赖或需核查；
8. 只有“允许执行”进入manager，manager才再次fresh重算唯一具备定位并把任务从`待检查条件`推进到`待执行`。

本轮没有建立本能函数注册解析器，没有调用方法函数，没有开始执行实例，也没有生成实际状态或影响评估。

## 2. 数值口径

安全值、服务值继续采用已实现不变量：

```text
0 <= 当前值 <= INT64_MAX
目标值 = INT64_MAX
差距 = INT64_MAX - 当前值
```

该差值处于`[0, INT64_MAX]`，不会溢出。通用I64差值继续在运算前判断上下界并饱和到`INT64_MAX/INT64_MIN`；本轮没有把根差距改成仅比较大小。

## 3. 失败与并发边界

- 多个方法或多个配对同时具备仍返回需核查，不按编码或登记顺序选择。
- 组合方法、仅有状态/动态结果、无可判定值域或严格方向的结果，当前返回缺少执行依赖，不假装可执行。
- 当前条件、任务状态或唯一定位变化时返回重新判断/定位变化，不推进任务。
- 方向核验资源失败时，self保留原反馈消息重试；manager推进资源失败时删除未完成接收记录，使同一裁决可以重试。
- manager在完成“待执行”状态推进以前不公开该裁决，避免读取者观察到“允许”但任务仍未过门的中间态。
- 方法结果定义被当作方法声明的预计变化全集；未声明特征不推定发生变化。后续实际执行出现的计划外变化仍必须由影响评估保留。

## 5. 代码知识变更清单

### 新增函数

1. `新_世界树类::核验任务执行方向(...) const noexcept`
   - 文件：`海中鱼巣/业务/新_世界树类.h/.cpp`
   - 用途：fresh重算唯一具备方法配对，将结果角色绑定成实际对象，核验任务目标以及安全/服务方向，返回预计变化和分类结果。
   - 非职责：不批准任务、不修改任务状态、不调用方法、不生成实际变化。
   - 直接调用者：`新_自我线程类::实现::处理筹办反馈`。
   - 直接被调者：任务、需求、方法、存在、特征概念、二次特征概念及既有W2综合读取。

2. `新_世界树类::确认任务进入待执行(...) noexcept`
   - 文件：`海中鱼巣/业务/新_世界树类.h/.cpp`
   - 用途：manager收到self允许后fresh重算唯一具备定位，未变化时把任务推进到`待执行`。
   - 非职责：不重新替self作方向裁决，不调用方法，不建立执行实例。
