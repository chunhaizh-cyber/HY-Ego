- Debug x64 完整重建成功，`--runtime-context` 退出码 0。
- Release x64 完整重建成功，`--runtime-context` 退出码 0。

因此，本次 L1 删除在正式基线上的两配置生产启动验证通过；共享工作区退出码 1 来自本计划范围外的未发布启动链差异，不能归因于本次删除，也不授权本计划修改该差异。
