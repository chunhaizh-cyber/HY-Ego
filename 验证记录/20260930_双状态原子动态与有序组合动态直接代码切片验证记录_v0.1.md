# 双状态原子动态与有序组合动态直接代码切片验证记录

起点：`8be855ae344b7f3374bdded90dac1ee1f6789cc1`

## 1. 用户口径与范围

本切片只完成动态基础层：

1. 最初动态必须是恰好包含前、后两个状态的原子动态；
2. 原子动态建立后立即形成自己的实例动态概念；
3. 多状态动态由有序原子动态连接形成；
4. 组合动态只保存原子成员引用，完整状态序列由成员端点推导；
5. 相邻原子必须共享端点，且主题、基础特征类型一致、时间严格递增；
6. 组合动态不在本层建立第二套实例动态概念；
7. 代表状态、循环锚点、不同长度时间轴对齐和高级动态概念不属于本切片。

## 2. 实际实现

- `新_动态类::建立原子动态(...)`固定建立双状态原子动态，并继续建立实例动态概念、增加状态引用和执行完整读回。
- 既有`建立动态(...)`保留调用形状，但只接受两个状态；其它数量返回`状态数量不合法`。
- `新_动态类::连接原子动态(...)`建立组合动态，核验成员种类、共享端点、主题、特征类型和时间顺序。
- 组合动态新增有序成员项物理字段，不保存状态项和动态概念字段；`获取动态(...)`按成员推导状态序列。
- 原子和组合统一参与主题、状态查询和引用计数；删除时分别退出状态引用或成员动态引用。
- `概念_动态类::建立实例动态概念(...)`只接受两个状态，防止绕过动态类直接建立多状态实例概念。
- `新_动态特征抽取类::抽取(...)`对原子动态计算唯一状态对的三类特征；对组合动态只组合成员原子概念中已经保存的特征，不重新遍历推导状态计算。

- 组合动态读回：成员为`D01,D12`，推导状态为`S0,S1,S2`，没有第二实例动态概念；
- 组合特征读回：位置0三项、位置1三项，共六项；
- 连接`D01`与端点不匹配的`D02=S0→S2`：返回`端点不连续`。

程序输出：

```text
PASS
```

## 5. 代码知识变更清单

### 新增公开函数

- `新_动态类::建立原子动态(稳定编码, 稳定编码, 稳定编码)`：建立双状态原子动态并立即形成实例动态概念。
- `新_动态类::连接原子动态(const std::vector<稳定编码>&)`：核验并保存有序原子成员，形成组合动态。

### 修改公开函数

- `新_动态类::建立动态(...)`：由任意多状态建立入口收缩为双状态兼容入口。
- `新_动态类::获取动态(...)`：区分原子和组合；组合状态序列由成员推导。
- `新_动态类::按概念查询动态(...)`、`采用聚合动态概念(...)`和`删除动态(...)`：适配只有原子动态持有概念的结构。
- `概念_动态类::建立实例动态概念(...)`：只接受两个状态。
- `新_动态特征抽取类::抽取(...)`：原子计算、组合读取并重排成员既有特征。

### 新增内部函数

- `新_动态类::撤销增加引用(...)`：只用于组合建立尚未发布时恢复原子成员引用计数，不触发零引用删除。
