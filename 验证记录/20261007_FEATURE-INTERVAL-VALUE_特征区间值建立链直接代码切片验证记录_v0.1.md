## 4. 代码知识变更清单

新增公开函数：

- `稳定编码 新_特征类::建立区间值特征(稳定编码, const 特征概念值域&) noexcept`
  - 用途：建立只有显式实例区间值、没有当前准确值和历史材料的实例特征。
  - 非职责：不生成状态，不写历史聚合域，不选择业务持有者。
- `新存在特征添加结果 新_存在类::添加特征区间值(稳定编码, 稳定编码, const 特征概念值域&) noexcept`
  - 用途：把区间值特征挂到存在并同步专属存在概念。
  - 非职责：不要求强时间，不生成状态。
- `新场景特征添加结果 新_场景类::添加场景特征区间值(稳定编码, 稳定编码, const 特征概念值域&) noexcept`
  - 用途：为场景自身添加区间值特征。
- `新场景特征添加结果 新_场景类::添加场景内存在特征区间值(稳定编码, 稳定编码, 稳定编码, const 特征概念值域&) noexcept`
  - 用途：核验直接场景归属后为成员存在添加区间值特征。

直接修改函数：

- `新_特征类::初始化()`：建立实例区间值字段身份。
- `新_特征类::获取特征()`：完整读回可选实例区间值。
- `新_特征类::删除特征()`：同步删除实例区间值字段和私有值域节点。
