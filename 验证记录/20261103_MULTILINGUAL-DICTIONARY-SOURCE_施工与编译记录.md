## 代码知识变更清单

- 新增 `词典查询服务::词典查询服务(std::shared_ptr<const 离线词典数据源>) noexcept`：只持不可变源的共享寿命，不取得 DATA 写权。
- 新增 `词典精确查询结果 词典查询服务::查询词义(const 词典精确查询请求&) const noexcept`：只读代理完整词义材料；空源未配置，非空调用 `离线词典数据源::精确查询`。
- 新增 `词典前缀查询结果 词典查询服务::查询原文词面候选(const 词典前缀查询请求&) const noexcept`：只读代理所有前缀候选；不裁决分词，不写语言事实，非空调用 `离线词典数据源::查询词面前缀`。
- 新增 `词典打开结果 离线词典数据源::打开(const std::filesystem::path&) noexcept`：私有候选完整读取TSV、严格UTF8和13列四转义/必填/义项唯一性检查、排序后一次交付不可变共享源；缺包、数据、I/O、资源错误分账，失败无源且计数0。标准库文件读取与内部解析为直接被调，不写DATA。
- 新增 `词典精确查询结果 离线词典数据源::精确查询(const 词典精确查询请求&) const noexcept`：源语种及字节词面一次索引查找，完整义项值式返回，不折叠、不建词；分配或其它工程失败不交付半成功。
- 新增 `词典前缀查询结果 离线词典数据源::查询词面前缀(const 词典前缀查询请求&) const noexcept`：完整验证原文并形成Unicode标量边界，按指定起点逐边界精确查索引，短到长返回所有候选及半开范围；不裁决英语边界或唯一切分。
- 新增私有构造、实现及UTF8/字段/转义/拆行/边界/错误辅助，均属于同一适配源cpp，无公共通用工具、线程、底座锁、语言owner依赖或可变查询缓存。`ifstream` 的 badbit 异常开启，使分配失败不会被getline状态吞成普通I/O失败。
- 新增生产工具 `检查文本(文本: str, 身份: bool=False)`、`转义(文本: str)`、`计算摘要(路径: Path)`、`提取读音(记录: dict)`、`构建词典(输入: Path, 输出目录: Path, 包标识: str, 来源版本: str)`、`主函数()`；入口只把本地完整真实来源转换为外部材料包，保留发布前失败与已发布后统计输出的事实边界，不构成验证脚本或正式语言写入口。
