# 新版场景递归范围边界判定施工验证记录

日期：2026-09-30

切片：用户直接代码切片——场景完整子树范围读取与边界面选择修正

起点：`d9e7b184f2e9992b7ae3968e0655b0198ad246c8`

结果提交：本记录所在提交

## 1. 实际变更

1. 新增`查询场景范围存在(场景节点)`，递归读取当前场景及全部下级场景的直接成员并集，不把场景节点本身混入普通存在结果。
2. 新增`存在属于场景范围(场景节点, 存在节点)`：
   - 普通存在按其唯一直接所属场景是否位于当前场景子树判断；
   - 场景节点按场景树是否从当前场景向下可达判断。
3. `计算场景边界(...)`不再只比较直接所属场景。边界存在位于当前场景完整子树时选择距内部参考点最远的合法面；否则按外部引用选择最近的合法面。
4. `场景边界面`的结果字段由“直接属于当前场景”修正为“属于当前场景范围”。

## 3. 代码知识变更清单

### 新增公开函数

- `std::vector<稳定编码> 新_场景类::查询场景范围存在(稳定编码) const noexcept`
  - 用途：读取场景完整子树内的普通存在并集。
  - 非职责：不返回场景节点，不改变任何归属。
- `bool 新_场景类::存在属于场景范围(稳定编码, 稳定编码) const noexcept`
  - 用途：按场景树和唯一直接所属场景判断递归范围包含关系。
  - 事实读写：只读。

### 修改公开函数

- `场景边界计算结果 新_场景类::计算场景边界(const 场景边界几何读取接口&, 稳定编码, const 三维毫米坐标&) const noexcept`
