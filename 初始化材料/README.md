## 支持的结构

| 标准表达 | 输出含义 |
| --- | --- |
| `A 是 一种 B` | 概念归类：下位 A、上位 B |
| `A 的 P 是 整数 N` | 主体 A 的特征类型 P 要求准确 I64 值 N |
| `A 的 P 是 概念 C` | 主体 A 的特征类型 P 采用概念条件 C |
| `A 是 B 的 一部分` | 定义中的部分 A、整体 B 组成约束 |
| `A 又称 B` | 为 A 提出别名词面 B |

整数采用标准十进制，支持完整 I64 范围；不接受加号、前导零、负零、小数或尾部残余。换行支持 LF 和 CRLF。非空行不允许首尾空格、连续空格、制表符、其它 Unicode 空白、注释或句末标点；解释器不裁剪或改写原文。

每个定义项保留模板、作用域、角色方向及原文行号、字节范围和 Unicode 标量范围。每次概念或特征类型角色出现有独立的局部符号引用；相同词面也保留各次出现，后继消歧绑定后才能确定正式身份。别名是词面提议，不创建第二概念或自动合并。

## 语料来源

物理类型和结构化分量布局取自 [概念_特征类.h](../海中鱼巣/领域/概念_特征类.h)。坐标、尺寸、RGB、轮廓和体素的已知定义取自 [概念_特征类.cpp](../海中鱼巣/领域/概念_特征类.cpp) 中的 `概念_特征类::初始化`：

- 坐标 X、Y、Z 分量使用毫米单位与完整有符号 I64 域。
- 尺寸 X、Y、Z 跨度分量使用毫米单位与非负 I64 域，包含 0。
- RGB 红、绿、蓝分量使用 0 到 255 的闭区间。
- 三组分量的顺序分别为 0、1、2；坐标、尺寸和颜色仍是不同特征类型。
- 二维轮廓和三维体素分别使用二维、三维二值格及全材料值域。

`I64分量`、`结构化分量`、有符号／非负／RGB 分量分类、各分量的描述名称，以及三个“又称”关系由本次交互整理提供。它们是有来源的定义描述和名称约定，不证明同名正式词条或概念已经登记。

`材料类型`、`角色`、`分量顺序`、`单位`、`闭区间下界`、`闭区间上界`、`值域范围`和`维度数量`在本批均是待绑定的属性词面。维度数量在现有 DTO 中由分量数得出，后继不得另存第二份数量权威。组成语句描述定义结构；归类语句尚未实现约束继承。

本批没有描述 RGB 分量的单位缺省、全部比较／聚合规则或二值格材料处理规则。未写的字段保持未说明，不能解释成无限制或一份已完整发布的概念定义。
