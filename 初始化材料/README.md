## 支持的结构

| 标准表达 | 输出含义 |
| --- | --- |
| `A 是 一种 B` | 概念归类：下位 A、上位 B |
| `A 的 P 是 整数 N` | 主体 A 的特征类型 P 要求准确 I64 值 N |
| `A 的 P 是 概念 C` | 主体 A 的特征类型 P 采用概念条件 C |
| `A 是 B 的 一部分` | 定义中的部分 A、整体 B 组成约束 |
| `A 又称 B` | 为 A 提出别名词面 B |
| `A 的 分量 N 是 整数区间 L U` | 主体 A 的第 N 个有序分量采用 I64 闭区间 [L,U] |

整数采用标准十进制，支持完整 I64 范围；不接受加号、前导零、负零、小数或尾部残余。换行支持 LF 和 CRLF。非空行不允许首尾空格、连续空格、制表符、其它 Unicode 空白、注释或句末标点；解释器不裁剪或改写原文。

每个定义项保留模板、作用域、角色方向及原文行号、字节范围和 Unicode 标量范围。每次概念或特征类型角色出现有独立的局部符号引用；相同词面也保留各次出现，后继消歧绑定后才能确定正式身份。别名是词面提议，不创建第二概念或自动合并。

分量模板的 N、L、U 都使用同一个严格 I64 解析器；它们是准确整数材料，不进入概念符号表。序号非负且不越界、L≤U、全部分量恰一声明及父域严格包含由子概念构造业务核验，纯解释器不替领域裁决。

## 语料来源

物理类型和结构化分量布局取自 [概念_特征类.h](../海中鱼巣/领域/概念_特征类.h)。坐标、尺寸、RGB、轮廓和体素的已知定义取自 [概念_特征类.cpp](../海中鱼巣/领域/概念_特征类.cpp) 中的 `概念_特征类::初始化`：

- 坐标 X、Y、Z 分量使用毫米单位与完整有符号 I64 域。
- 尺寸 X、Y、Z 跨度分量使用毫米单位与非负 I64 域，包含 0。
- RGB 红、绿、蓝分量使用 0 到 255 的闭区间。
- 三组分量的顺序分别为 0、1、2；坐标、尺寸和颜色仍是不同特征类型。
- 二维轮廓和三维体素分别使用二维、三维二值格及全材料值域。

`I64分量`、`结构化分量`、有符号／非负／RGB 分量分类、各分量的描述名称，以及三个“又称”关系由本次交互整理提供。它们是有来源的定义描述和名称约定，不证明同名正式词条或概念已经登记。

`材料类型`、`角色`、`分量顺序`、`单位`、`闭区间下界`、`闭区间上界`、`值域范围`和`维度数量`在本批均是待绑定的属性词面。维度数量在现有 DTO 中由分量数得出，后继不得另存第二份数量权威。组成语句描述定义结构；归类语句尚未实现约束继承。

本批没有描述 RGB 分量的单位缺省、全部比较／聚合规则或二值格材料处理规则。未写的字段保持未说明，不能解释成无限制或一份已完整发布的概念定义。

## 结构化子概念语料

新 132 句由本次交互提供，定义依据为现行先天 RGB 颜色、三维空间坐标和三维空间尺寸的完整公开定义：12 个 RGB 精确三通道域、9 个坐标域、9 个尺寸域。RGB 别名明确数值，未以通用色名假定色彩空间。坐标和尺寸都是独立分量区间的笛卡尔积，不表示球形范围、三个跨度相等或某个现实物体的位置、尺寸。

[结构化子概念业务](../海中鱼巣/业务/初始化.结构化子概念.h)先完整解释全篇，按声明 A 的精确词面组织批内局部符号。父 B 必须是三个显式先天 FT 之一；类别、材料、单位、比较和聚合规则以及分量角色、单位从当前正式父定义继承，继承的名称关系清空。每个分量必须明确给出一条闭区间，至少一处分量严格收窄；缺省、重复、未声明主体或其它模板整批拒绝。分量和别名可先于合法声明出现，别名不会成为声明键。

全批声明、分量、父域、同父完整定义查询和命名语言、来源预检完成后，才按显式直接父建立或复用子概念，逐项公开读回直接父及五项定义。所有身份确认后，经[通用 FT 命名入口](../海中鱼巣/业务/初始化.概念名称.h)发布 30 个标准名称和 12 个别名，共用词条、名称端点及正反向读回。相同父下相同完整定义可复用身份；不同名称不是强建多个身份的理由。没有新类型根、现实存在、特征实例或比较事实，也不增加实例引用。

本批新增范围是 30 个子域声明及 42 对名称目标；与原五个先天 FT、六对名称目标合计，覆盖目标为 35 个 FT 定义、48 对名称目标。实际新增或复用数量须由运行结果判定，不能据声明数认定新增了 30 个节点。后续失败保留此前实际步骤，不承诺整批原子或批量回滚。

## 当前接入与边界

纯解释器只形成调用期语言定义材料。[名称初始化业务](../海中鱼巣/业务/初始化.概念名称.h)组合它和现有公开服务，绑定五个已有先天特征概念的标准词面：三维空间坐标、三维空间尺寸、RGB颜色、二维轮廓、三维体素，并消费`RGB颜色 又称 红绿蓝颜色`形成同一RGB概念的第六组名称关联。它不改变这些概念的定义，也不把单位、角色和材料类型辅助信息登记成概念。

普通应用构造在取得上下文锁前，从实际程序所在目录的`初始化材料`分别完整读取三份固定文本。根工程 Build 后分别复制三个源文件到该路径；启动不依赖工作目录，也没有内置正文回退。初次装配在中文语言和世界服务可用后，先处理原五个 FT 名称，再处理新子概念及名称，随后处理基础语言知识。已装配的重复构造对名称、子概念和语言知识三批只做正式读取复核，不调用这些批次的建立入口、不修补缺失。文件、解释、预检、写入、读回或结果拷贝的工程异常进入独立诊断终止链；已发生事实保留。

原名称结果继续保留逐出现绑定、未绑定符号、未应用定义及另两条未处理别名。六组名称完成不表示原 66 句均已应用。新子概念结果另存完整解释、来源、父域比较、写前匹配、实际建立返回、写后匹配、定义读回、逐出现绑定及名称真实步骤；只读结果不伪造建立或已复用状态。未知类别登记、任意词典初始化、原辅助元信息补全、组成发布及双向表达仍未闭合。类别必须明确，可由结构和已绑定信息约束推导，不能唯一确定时不登记；词性不作为类别权威或必经步骤。

## 基础语言知识语料

第三份文本由本次交互依据 2340、7230—7250 及[完整实施设计](../规范/详细设计/20261014_INIT-LANGUAGE-KNOWLEDGE-SEEDS_功能词与五种基础语言知识初始化详细设计_v0.1.md)提供，由[语言知识初始化业务](../海中鱼巣/业务/初始化.语言知识.h)读取。`知识/目的/操作/角色/参数/项/结束`是元格式；S01 等标签仅定位来源，不决定语义，也不登记成词条。目标、联合参数合同及有序项必须完整声明。

| 表达结构 | 规则保存的含义 |
| --- | --- |
| `A 是 C` | 存在对象归类到存在概念 |
| `A 是 一种 C` | 同类别概念上下位；特征概念实际绑定时须同 FT 类型根 |
| `A 的 P 是 整数 V` | I64 准确值特征描述；实际材料和单位须与 P 相容 |
| `A 的 P 是 概念 V` | 特征概念条件描述；实际 V 须属于 P 的 FT 类型树 |
| `A 是 B 的 一部分` | 部分 A、整体 B 的组成描述 |

固定项按首次出现顺序登记“是、一种、的、整数、概念、一部分”，只取得正式词条，不强制创建同名概念或名称关系。规则角色尚未绑定，初始化不创建现实存在、交互场景、特征事实或代词指向；上述联合约束由操作及角色合同保存，未来解释消费必须实际核验。

业务先对全篇解码、检查参数引用及类型、规范化局部编号。词条正式读回之前只使用私有词面草稿，不能把零编码冒充正式端点。输入上限为 1 MiB、262144 个 Unicode 标量、4096 非空行、128 块，每块最多 128 角色、128 参数及 512 项；超限单独报告工程控制未完成，不给出语义结论。首次依次处理知识结构、词条、完整原文来源及知识，失败保留已经发生的步骤，不承诺跨 owner 整批原子回滚。

语言 owner 按完整规范化目标和有序结构查重；来源不参加定义身份，相同定义可关联多个来源。完整原文以实际字节保存，每块使用 Unicode 标量半开范围，CR 与 LF 分别计数。新建单条知识及全部私有组成、初始来源关联在同一原子节点组发布；复用知识只补缺少的来源关联。词读取在语言锁外，读写均复核完整候选范围和端点快照，漂移不作为正常未找到。

知识仍由当前内存底座承载，没有磁盘持久化或恢复入口。这批代码不让旧六模板解释器自动消费新知识，也没有完成双向解释、任意词典初始化、后天学习或代词定义与绑定。五条规则和六个固定词面是输入规模，实际新增/复用节点数量须以运行结果为准。
