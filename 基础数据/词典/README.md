# 词典数据

本目录保存海中鱼巣语言模块使用的词典相关数据，包括原始词典数据、整理后的词面及义项、文字读音，以及来源、版本、许可证和署名资料。运行期只读索引由提供者打开包时一次建立，不在每次查询时扫描或重建。

首批收录中文、英文词头，释义来自中文维基词典的汉语解释；英文词头、读音表示及释义中的外文原样保留，不生成翻译。筛选条件为非空释义且含汉字，这是弱覆盖筛选，不保证逐句语言鉴别。首版不收录源 examples 字段的例句及其中的引文、音频或图片，例句原文、例句汉译两列为空；未对 gloss 逐句识别引文或作版权审计。后续可增加其他语种。

词典数据是语言材料，不因收录而自动成为系统已理解的概念或已确认的世界事实。数据来源和许可证须随数据保留；程序代码许可证不替代词典数据许可证。

## 文件与重建

- `原始/zhwiktionary-20261101.jsonl.gz`：实际源包；本地保留，不提交 Git。
- `词典.tsv`：UTF-8 无 BOM、格式 `HY-EGO-DICTIONARY/1` 的 13 列处理包；本地保留，不提交 Git。
- `来源清单.json`：版本、HTTP 元数据、SHA256、统计与构建命令。
- [LICENSE.md](LICENSE.md)、[ATTRIBUTION.md](ATTRIBUTION.md)：源许可、署名、修改及贡献者追溯。
- `../../工具/词典/构建词典.py`：标准库生产导入工具，输入必须是本地 JSONL 或 gzip；不联网，不是验证脚本。
- `原始/opencc-1.4.2/`：OpenCC ver.1.4.2 的 `TSPhrases.txt`、`TSCharacters.txt` 与 `LICENSE`（Apache-2.0），繁转简依据；本地保留，不提交 Git。
- `批次/<清单SHA256>/词典.简体.tsv`：按 2026-11-13 用户裁决把 `词典.tsv` 整体转成简体的同格式包，记录键与原始来源定位不变。本地保留，不提交 Git。
- 同批的 `繁简表.tsv`、`词头表.tsv`、`词性表.tsv`：读词典释义用辅助表（7250 §3.4）。繁简表为 OpenCC 繁转简词组（P 行，繁简等长）与单字（C 行，多值取第一个）；词头表收全部中文词头并转简体；词性表按记录行号保存原始词性，包头带原始包 SHA256。只有同批核验和格式解析都成功才启用，不用松散表凑包。
- `当前批次.txt`：唯一发布点，只包含批次清单的 64 位小写 SHA256 加 LF。对应目录中的 `批次清单.tsv` 固定保存格式、包标识、raw 摘要、OpenCC 版本及八个固定文件的长度/摘要/数据行数。
- 同批保存 `来源清单.json`、`LICENSE.md`、`ATTRIBUTION.md`、`OpenCC-LICENSE.txt`，最后一项是 OpenCC 原许可字节。

繁转简与 OpenCC t2s 一致：自左向右先取最长词组，否则逐字，都不命中保留原字；词组繁简等长，原文与简体逐标量对齐。上述文件均由 `../../工具/词典/构建词典辅助表.py` 生成。

在项目根目录运行：

```powershell
python 工具/词典/构建词典.py --input 基础数据/词典/原始/zhwiktionary-20261101.jsonl.gz --output-dir 基础数据/词典 --package-id zhwiktionary-20261101-zh-en-zh-gloss-v1 --source-version "zhwiktionary-dump-20261101;kaikki-extract-20261102;wiktextract-19f9a3006a405fb7bfb40193dca41c7117a009a5"
```

```powershell
python 工具/词典/构建词典辅助表.py --input 基础数据/词典/原始/zhwiktionary-20261101.jsonl.gz --dictionary 基础数据/词典/词典.tsv --opencc 基础数据/词典/原始/opencc-1.4.2 --output-dir 基础数据/词典
```

辅助表构建工具先按受控来源清单核对 raw、原词典和 OpenCC 两表/许可；可用 `--source-manifest` 指定经过维护确认的清单。完整写入独有暂存批次后生成清单、安装不可变目录，最后原子切换 `当前批次.txt`。切换前失败原 current 不变，残留位置在错误中报告；不覆盖既有完整批次、不删除原始材料。批次相同则核对后复用。不是断电恢复保证，也不自动清理旧批次。原始 `构建词典.py` 仍是生成原包的独立工具。

程序打开时只选择一次 current，在解析实际字节流时核摘要与计数并建立不可变内存索引；后续查询不再读文件或重验整包。current 存在但包损坏返回工程错误，不回退旧文件。没有 current 时保留旧平铺包查询：只有简体文件确实不存在才回退原词典；散包不启用释义辅助表，也不能冒充可用的词典学习来源。

运行代码没有词典写接口；维护构建/分发与内部学习分离。摘要保证与发布记录一致，不等于数字签名，也不能证明释义被正确理解。词典知识经语言解释与正式 owner 写回内部词条/概念，不直接成为现实对象的当前事实。
