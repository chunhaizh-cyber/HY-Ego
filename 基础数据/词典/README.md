# 词典数据

本目录保存海中鱼巣语言模块使用的词典相关数据，包括原始词典数据、整理后的词面及义项、文字读音，以及来源、版本、许可证和署名资料。运行期只读索引由提供者打开包时一次建立，不在每次查询时扫描或重建。

首批收录中文、英文词头，释义来自中文维基词典的汉语解释；英文词头、读音表示及释义中的外文原样保留，不生成翻译。筛选条件为非空释义且含汉字，这是弱覆盖筛选，不保证逐句语言鉴别。首版不收录源 examples 字段的例句及其中的引文、音频或图片，例句原文、例句汉译两列为空；未对 gloss 逐句识别引文或作版权审计。后续可增加其他语种。

词典数据是语言材料，不因收录而自动成为系统已理解的概念或已确认的世界事实。数据来源和许可证须随数据保留；程序代码许可证不替代词典数据许可证。

## 文件与重建

- `原始/zhwiktionary-20261101.jsonl.gz`：实际源包；本地保留，不提交 Git。
- `词典.tsv`：UTF-8 无 BOM、格式 `HY-EGO-DICTIONARY/1` 的 13 列处理包；本地保留，不提交 Git。
- `来源清单.json`：版本、HTTP 元数据、SHA256、统计与构建命令。
- [LICENSE.md](LICENSE.md)、[ATTRIBUTION.md](ATTRIBUTION.md)：源许可、署名、修改及贡献者追溯。
- `../../工具/词典/构建词典.py`：标准库生产导入工具，输入必须是本地 JSONL 或 gzip；不联网，不是验证脚本。

在项目根目录运行：

```powershell
python 工具/词典/构建词典.py --input 基础数据/词典/原始/zhwiktionary-20261101.jsonl.gz --output-dir 基础数据/词典 --package-id zhwiktionary-20261101-zh-en-zh-gloss-v1 --source-version "zhwiktionary-dump-20261101;kaikki-extract-20261102;wiktextract-19f9a3006a405fb7bfb40193dca41c7117a009a5"
```

脚本流式处理 JSONL，先在输出目录完整生成临时文件，校验字符并关闭后以 `os.replace` 原子替换 TSV。构建失败保留既有完整包并清理本次临时文件，不递归清理目录。统计以 JSON 输出；发布新输入后须同步维护来源清单，不将旧元数据冒充新包。相同原始字节及构建参数生成相同 TSV；构建时间只在统计中，不进入 TSV。

13 列依次为：记录键、词头语种、词面、义项键、汉语释义、例句原文、例句汉译、读音、来源页 URL、来源版本、许可标识、署名、原始来源定位。记录键包含 raw SHA256 和解压行号；义项键为从 1 开始的原 sense 序号。字段仅转义反斜线、TAB、LF、CR；不含 BOM、NUL、替换字符或其它禁止控制字符。

原始数据及大 TSV 通过本目录 `.gitignore` 忽略。获取仓库代码不会自动取得词典包；请按来源清单下载匹配摘要的原始包再重建。工程可条件复制本地处理包和许可资料到产物目录，但缺包不等于词义未命中，复制成功也不等于普通应用已装配词典服务。
