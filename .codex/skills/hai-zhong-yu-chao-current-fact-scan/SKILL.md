# 海中鱼巣当前事实扫描

## 角色与入口

严格服从仓库根目录 `AGENTS.md`。用 `git rev-parse --show-toplevel` 和当前唯一工作区的 Git 结果解析路径、分支、HEAD、`origin/main`、dirty state 与远端事实，并从 `.codex/rules/` 核对执行通道；不得硬编码仓库路径或主分支名。身份无法确认时停止在只读事实报告，不推测补齐。

本技能只完成 S0 / 当前本地事实扫描：

```text
当前目标
-> 当前工作区与 dirty state
-> 当前规则 / 计划列表 / 计划状态 / 具名依赖
-> 当前真实代码入口、调用点、结构承载
-> 缺口、风险、待确认问题
```

## 专用步骤

1. 解析 Git 顶层，读取 `AGENTS.md`。
2. 按扫描对象限载读取：

```text
计划/计划索引.md
规范/规范目录.md
目标正式规范、有效设计、现行计划、任务文件头部规则
```

3. 读取当前 Git 证据：

```powershell
git status --short --branch --untracked-files=no
git diff --name-only
git rev-parse --show-toplevel
git branch --show-current
git rev-parse HEAD
git rev-parse origin/main
```

4. 用范围受限的 `rg` 和短文件读取定位真实入口、调用者、结构承载、写入方、读取方、拒绝、返回和验证证据。
5. 核对 dirty diff 是否影响所读事实；计划状态只从计划索引读取，计划段开始、漂移、失败和完成事实只从 Git 与结构化消息读取；不得把不同提交或计划版本的事实混合为同一结论。
6. 将结果分为 `事实 / 差异 / 证据 / 风险 / 建议`；不能由当前证据证明的内容标记为待核，不用计划目标替代代码事实。


正式只读复核还必须具名：

```text
目标提交与工作区
复核对象与问题清单
证据入口
报告所属智能体类型与授权接收对象
```

## 停止边界

- 本技能没有写断点或状态文件的例外：不得修改任何文件、构建、运行程序、暂存、提交、推送、修改计划状态、解除依赖、裁决完成或取得活动计划段 / 发布占用。
- 用户要求持久化扫描结果时，本技能仍保持只读；扫描结束后的独立写步骤中，交互智能体可按用户直接指令取得明确切片并落盘，计划智能体或计划支撑智能体可写入自己拥有的设计包，执行智能体可写入当前计划冻结的专属施工 / 验证记录并向配对计划支撑智能体发送消息，流程图与知识图谱维护智能体可转用 `hai-zhong-yu-chao-flowchart-code-correction` 写入其当前代码图谱切片但不得写能力证据目录；能力证据目录维护智能体（兼代码知识库维护）只写其专属能力目录和已取得所有权的 `知识库/函数用途/**`、知识当前性聚合状态。不得在本技能内部混入写操作。
- 不从本地状态推断云端状态，不把日志、控制台或显示文本当机器事实。
- 没有当前调用路径、结构承载和验证证据时，不得宣称 `已实现`、`已接通` 或 `已完成`。
