## 2. 实际施工

1. 新增模块 `海中鱼巣.领域.合同.动态结构`，形成4213 v0.1的值式DTO、状态/阶段枚举、成功谓词、只读provider与12个公开业务入口合同。
2. 原地重建 `动态类数据服务`：
   - 支持I64原子动态和全部成员为同主体的组合动态；`组成存在`固定在写前拒绝。
   - 只读核验九项动态结构交付，不在构造期间初始化或写入结构材料。
   - 创建先读L1首次材料；精确重放恢复首次写集和首次发布结果，不重新执行当前来源准入。
   - 创建前核验E、B、S、FT、准确值、强时间与K比较回执，并按整个调用共享预算预留发布后独立读回所需D、边、材料和新增根深度。
   - 实现当前/历史内容、三类反查、直接/递归来源展开、当前/历史身份；全部读取入口具有Gread前后守卫。
   - 实现普通退出和双键同步清理；首次清理对活动历史事实逐D证明完整自有集合，后继重放对墓碑/原退出集合逐身份和种类互证，换新清理键固定收敛为幂等冲突。
3. 在 `海中鱼巣.vcxproj` 与 `.filters` 中把新合同登记在状态使用绑定合同之后、动态类之前。
4. 施工中经三轮独立只读复核，最终结论为 `PASS`。复核推动关闭写后才发现预算不足、K预算未共享、B/S假成功错误分账、当前身份缺尾守卫、清理换键及恢复集合不完整等问题。
