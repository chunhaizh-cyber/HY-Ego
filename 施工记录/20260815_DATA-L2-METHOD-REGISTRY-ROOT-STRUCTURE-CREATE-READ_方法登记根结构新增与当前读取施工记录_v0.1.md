## 2. 实际实现

1. 新增唯一 `L2方法身份` owner 建立身份、move-only `L2方法所有者交付`、形成函数和不可复制 / 移动的 `L2方法结构服务`；服务只持同一 L1 读取服务、唯一 owner 写端口和一把方法根写锁。
2. 构造期在方法 owner 内原子登记方法族锚点 / 族归属关系类型，以及方法根角色锚点 / 角色关系类型 / 首次请求见证属性类型；登记接受首次或精确重复结果并逐节点历史读回。
3. 公开面只新增 `读取全部当前方法登记根`、`建立方法登记根`、`按角色读取当前方法登记根` 三入口，以及 `L2方法登记根建立请求有效`、`L2方法登记根事实完整` 两个新纯值 helper；读取请求和角色校验保持模块私有。
4. 唯一方法登记根写集在同一 owner 事务中原子包含根方法节点、方法族归属关系、方法根角色关系、`[首次幂等身份, 首次期望事实代次]` U64 见证值及当前属性槽。
5. 全组读取只调用一次 L1 owner-aware 关系类型闭包投影，在一个事实截止内闭合 owner、方法族来源、唯一根角色和首次见证；合法结果为 0—1 根，非零守卫成功截止等于请求守卫，零守卫选择调用许可内最新非零截止。
6. 建立入口在私有锁内区分精确重复、同键异义、同角色异请求、事实代次漂移和结构化失败；首次或 L1 精确重复后，经唯一写端口读取首次规范化写集与首次结果，并以首次截止历史读回四项写入事实。
7. 单根读取复用同一次全组读取；同代根缺失返回 `未找到`。全部非成功结果保持空根载荷和零变更事实代次，不增加 sleep、忙重试、生产 seam 或第二写入口。
