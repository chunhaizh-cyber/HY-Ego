## 2. 实际实现

### 2.1 不可变定义角色合同

`L2普通概念结构合同版本`由 1 提升为 2，新增独立 `L2概念定义合同版本=1`。普通概念建立请求和完整事实增加确定排序的定义角色合同组；每个合同固定校验非零角色、有限非零最大数量和 `最小数量 <= 最大数量`，每个定义项必须命中一个角色且顺序从 1 连续，实际数量必须落在合同上下界内。

定义角色合同进入普通概念签名、首次请求见证、确定写集、首次结果重建、当前 / 历史投影和幂等完整请求互证。定义语义变化仍只能建立新普通概念身份；生产公开面没有增加原地定义增、替、退入口。

### 2.2 固定登记与确定写集

唯一概念 owner 增加四个固定登记：

```text
0x020A'6206  定义角色合同成员关系类型
0x020A'6219  定义角色值属性类型
0x020A'621A  定义最小数量属性类型
0x020A'621B  定义最大数量属性类型
```

合同节点、成员关系、角色值、最小数量值和最大数量值分别使用 `0xB—0xF` 五个本地键分区。节点、关系、值和属性槽变更在提交前按与 L1 相同的稳定键规范化排序，保证多合同、多定义写集的首次提交与幂等重建一致。

### 2.3 定义双向当前 / 历史读取

新增三个值式合同类型组和两个公开入口：

- `按概念读取定义关系组(...)`：先证明普通概念存在，再在同一截止完整返回全部角色合同和定义关系；零定义概念成功返回空关系组；
- `按定义目标读取概念定义关系组(...)`：在概念 owner 范围按扫描 / 数量预算有界枚举，返回命中关系及实际使用的 `(概念, 角色)` 合同；合法零命中为成功空组。

当前读取要求非零 `G0` 且结果截止等于请求守卫；历史读取固定返回 `H` 截止。预算不足返回 `数量预算不足` 和零载荷；底层漂移、许可或资源失败保留原分类；成功坏形状归 `内部不一致`。

### 2.4 退役普通概念不可逆退出

新增 `退出普通概念(...)`。入口在同一概念写锁内完成幂等首次材料复核、退役见证、支持 / 反向定义 / 外部引用保护、完整 DAG 读取和预算检查。移除目标后，对每个直接父子组合只在不存在其它可达路径时建立替代直接边，并与目标自有当前事实和目标相关直接边的退出一起交给唯一 owner 原子提交。

退出写集只包含当前自有事实、当前退役生命周期值和当前关联直接边；已经退出的历史生命周期值不重复退出。首次成功与精确重复从首次截止重建同一退出概念、退出边和替代边；同幂等身份但新请求概念或退役生命周期编码不在首次写集时返回 `幂等冲突`。

退出后当前普通概念和正向定义读取返回 `已退出` 与零载荷；历史读取在退出前后截止分别返回完整活动 / 已退出事实。反向当前读取不再包含目标，历史读取仍按截止返回。

## 3. 施工中发现并修复的纯代码错误

1. 初版退出写集会把已经退出的历史生命周期值再次加入退出集合；改为逐事实种类读取当前项，只处理仍当前的自有事实。
2. 初版普通概念写集没有对全部写集分量执行 L1 同规则规范化，多合同场景会使提交后首次写集与原请求比较不等；现已稳定排序节点、关系、值和属性槽变更。
3. 初版退出首次结果重建对同幂等异概念 / 异退役编码误报 `内部不一致`；现先互证首次写集是否包含新请求身份，固定返回 `幂等冲突`。

这些修正均在计划允许的两个生产文件内完成，没有改变设计公开合同或扩大所有权。
