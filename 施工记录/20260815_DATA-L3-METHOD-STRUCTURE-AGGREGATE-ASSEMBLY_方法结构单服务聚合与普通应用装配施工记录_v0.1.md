## 2. 实际实现

1. 新增唯一真实模块 `海中鱼巣.领域.服务.L2方法结构聚合`，只 import 方法结构服务，只持一份 non-owning `L2方法结构服务&`，禁用默认、复制和移动。
2. 聚合公开 const / non-const `取得L2方法结构服务()`，两者均 `noexcept` 并返回绑定的同一实例；没有 owner、写端口、锁、缓存、DTO 映射或其它服务依赖。
3. 普通应用在概念服务 / 概念聚合之后持有唯一方法服务和方法聚合，成员按“服务后声明聚合”排列，析构时聚合先于其引用的方法服务销毁。
4. 普通应用只新增 const / non-const `取得L2方法结构聚合服务()`；没有直接方法服务 getter、pointer / optional getter、第二聚合或按枚举选服务入口。
5. 普通应用经同一 L1 运行包依次建立方法 owner、形成 move-only 交付、构造方法服务和方法聚合，只在全部成功后把两份唯一所有权移动进入上下文。
6. 装配状态 0—27 逐项保持不变，追加 28 `方法所有者范围建立失败`、29 `方法所有者交付形成失败`、30 `方法服务构造失败`、31 `L2方法结构聚合服务构造失败`；失败候选由 RAII 清理且不返回半上下文。
