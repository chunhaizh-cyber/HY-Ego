## 2. 实际施工

### 2.1 存在 DTO 与服务

新建 `海中鱼巣/领域/L2存在结构.数据.h`：

- 唯一定义存在事实、新增 / 读取请求及写入 / 读取结果；
- 直接消费 S1 已发布的 `L2存在身份`、共同请求 / 结果头、结构状态、属性事实和生命周期，没有复制或别名化共同实体；
- E1 完整存在事实由非零身份、完整生命周期和空固定属性组组成；默认构造不代表成功事实。

新建 `海中鱼巣/领域/服务.L2存在结构.ixx`：

- `新增存在节点` 把合法请求映射为本地键 `0x02020001U` 的恰一个普通节点，关系、值、属性槽变更和退出项均为空；
- L2 幂等身份完整 64 位原样映射为 L1 幂等键，只调用一次 `提交中性写集`，不预探测、不预分配、不重试提交、不建立第二幂等账；
- 首次成功和精确重复核对 L1 发布形状、唯一新编码映射及历史节点读回；同键异义由 L1 正式幂等账返回冲突；
- 当前读取只选择一个存在节点并恰一次调用一致当前投影，其余五组选择与结果保持为空；
- 历史读取按“当前代次前探测—历史事实—当前代次后探测”夹取同一期望代次；
- 所有非成功返回空存在、空变更代次和结构化状态；未建立固定属性、退出、反向引用、缓存、登记、仓库直达或业务资格判断；
- 模块只 import 公共 L2 合同与 L1 正式服务，不 import 或调用场景服务。
