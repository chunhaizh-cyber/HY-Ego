## 2. 实际生产变更

### 2.1 数据合同

在 `海中鱼巣/领域/L2特征结构.数据.h` 原位加入：

- 派生规则身份 / 提交项 / 事实；
- 直接来源提交项 / 事实，显式区分顺序与输入角色；
- 统一特征定义事实、新增、完整当前 / 历史读取、全组当前读取和显式退出 DTO；
- 请求有效性、基础 / 派生互斥、结果成功形状和退出同代完整性纯值 helper。

基础定义固定阶次为 1、无来源、无规则；派生定义要求来源非空、顺序从 1 连续、输入角色非零、`(来源, 输入角色)` 唯一、规则身份 / 版本非零，并由服务核对实际阶次等于来源最大阶次加一。

完整性 helper 对已退出定义要求实际阶次属性、可选规则见证、全部直接来源关系及全部固定属性与定义同代退出。施工检查发现并修正了条件表达式中 `bool` 被提升为有值 `optional` 导致所有退出投影误拒绝的问题，最终改为显式同代退出谓词。

### 2.2 唯一特征结构服务

在现有 `海中鱼巣/领域/服务.L2特征结构.ixx` 和同一 `L2特征结构服务` 内实现：

- 私有实际阶次 I64 属性类型、规则见证 U64 组属性类型和直接来源关系类型的一次固定登记；
- `新增统一特征定义`，以一份特征定义 owner 写集原子建立定义节点、族归属、实际阶次、零或多直接来源及零或一规则见证；
- `读取完整统一特征定义` 的当前 / 历史投影；
- `读取全部当前统一特征定义` 的零守卫原子最新或非零乐观守卫闭包读取；
- `退出统一特征定义` 的显式闭包核对、L1 当前引用保护、同代退出和历史读回；
- 固定属性新增 / 换代和特征实例新增在写前改为证明目标是完整统一定义。

派生创建逐来源使用同一个非零守卫调用正式完整读取，因此保留 `未找到`、`已退出`、漂移和坏结构的状态区分；没有用全组缺失把已退出来源降格为未找到。

历史投影仅对私有实际阶次和规则见证要求 `来源稳定编码 == 定义身份`；公开固定属性保留调用方提交的独立来源，不被错误收窄为定义自引用。
