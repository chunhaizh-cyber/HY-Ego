## 2. 实际实施

1. 在既有数据头增加显式 UTC 半开窗口读取请求、裁决、完整快照、结构化状态、结果和成功谓词。
2. 在既有只读组合 module 增加 `本能主动安全UTC窗口裁决组合器`，固定执行：基础快照首次读回 -> 同 G0 主动来源规则 -> 同 G0 永久变化账 -> 空 / 非空裁决 -> 基础快照二次读回 -> 完整性收束。
3. 规则版本 1 只接受显式空来源方法组。永久账合法空组唯一形成 `未改变A`；任意非空组都返回 `来源未裁定`，空载荷、截止 0。
4. 完整谓词显式互证安全根实例、窗口、规则版本、规则形成代次、账登记代次、声明成员数、规范身份组和共同 G0。
5. 扩展既有专项，增加 A00—A04：坏请求 / 坏窗口、规则未发布、账未登记、合法空组、旧 G、预算不足、非空来源未裁定和下层状态映射。
6. 没有增加 UTC 生产者、单调秒换算、写入口、owner、游标推进或工程登记。
