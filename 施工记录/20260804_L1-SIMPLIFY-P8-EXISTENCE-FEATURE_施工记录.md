## 2. 实际代码变更

1. 在 `L1实例特征.数据.h` 新增 `实际存在I64实例特征建立请求`、`实际存在I64实例特征读取请求` 以及两个对应有效性函数；旧 DTO 字段未修改。
2. `L1实例特征服务` 保留原三参构造，新增绑定 `L1实际存在场景组合服务` 的四参构造；P7 provider 以不可变非拥有指针保存。
3. 新增 `建立实际存在I64实例特征` 与 `读取实际存在I64实例特征`。建立入口先真实读回 P7 实际存在和 P2 I64 定义，再校准 L1 来源节点、完整快照及同代次。
4. 抽取场景入口和实际存在入口共用的实例写集构造、提交及事实读回核心。写集仍使用私有 `0x06` 域，固定为一个普通实例槽节点、两条关系、一个 I64 当前值和一个当前属性槽：
   - `实际存在 -> 实例槽`，宿主槽关系类型，角色 1；
   - `实例槽 -> P2 I64 定义`，定义模板关系类型，角色 2。
5. 以 `特征操作幂等身份.值` 建立值式有序账。同键同义重新提交原写集并独立读回，同键异义返回幂等冲突；发布后读回或载荷异常不补写、不回滚、不删除已建立的账记录。
6. 原位扩展顺序 320 的实例特征专项，从 27 项增加到 45 项；未新增模块、工程登记、启动入口或顶层自检单元。
