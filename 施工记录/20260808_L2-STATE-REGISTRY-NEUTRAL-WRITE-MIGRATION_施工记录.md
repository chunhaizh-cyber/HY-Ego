1. 把唯一 `L1状态登记幂等域 = 0x0CULL` 移入状态数据头，删除服务内重复定义；第二个首态发布根继续使用原 `0x0D` 域。

5. 首次成功和精确重复共同核对中性合同、回显键、非零首次发布代次及七项新编码映射完整唯一，再执行 G0、七节点、G1 精确当前读回。七节点必须形状正确、当前属性为空、未退出、共同创建代次等于 L1 返回的首次发布代次；当前读回截止允许晚于首次发布代次。
6. `读取当前登记` 不再直接返回缓存，只把缓存作为七编码定位并复用同一精确读回 helper；读回重新裁决当前性和一致代次。
