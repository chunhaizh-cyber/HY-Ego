## 3. 施工期纯代码修复

首个合法 legacy 场景曾返回`内部错误`。根因是 provider 把成员读取器在关系时点返回的列表项投影，与当前完整列表项做了整个对象相等比较；列表成员关系变化后，两份投影身份仍相同但成员集合不同，导致合法事实被过强比较拒绝。

修复只收窄这项多余比较：保留“成员关系指向的列表项身份 == 当前完整列表项身份”，并保留“当前完整列表项 == 当前满足裁决快照中的列表项”互证；不再要求关系时点投影与当前完整列表项整个对象相等。该修复没有改变公开合同、G0 身份互证或 legacy 分支语义。
