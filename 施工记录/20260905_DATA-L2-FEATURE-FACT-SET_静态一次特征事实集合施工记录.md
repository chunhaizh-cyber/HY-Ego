- 成员关系用 64 位 `顺序/角色` 编码保存；读取时完整解码、校验连续顺序、成员唯一、生命周期、owner、端点和关系类型。当前 / 历史 / 版本结果逐成员形成完整 `特征类结点` 投影，不跳过坏项。
- 版本追溯沿前版本反向链定位集合身份；已换代或集合已退出后仍以版本生效截止重建不可变成员快照。反向结果按集合稳定编码排序，超调用预算返回空载荷 `数量超限`。
- 三个写入口复用 L1 首次写入材料和规范化写集完成同义重放；异义为 `幂等冲突`。L1 已确认发布后，编码映射或专用历史读回不能闭合时返回 `已可能发布`，不补偿删除。
