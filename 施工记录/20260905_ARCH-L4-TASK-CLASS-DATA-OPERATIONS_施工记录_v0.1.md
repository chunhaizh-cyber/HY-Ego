## 2. 实际变更

- 新建 `海中鱼巣/领域/数据服务.任务类.ixx`，模块只公开导入需求类；定义合同版本 2、
  冻结的 31 个状态、结构类型、记录身份、记录、七类请求/结果 DTO 和成功谓词。
- `任务类数据服务` 持有唯一 task owner move-only 写端口及 L1、需求类、存在类只读引用；
  构造时校验当前独占 owner 和四个非零、互异、当前、同 owner 的无属性普通关系类型。
- 基础新增以固定本地键形成一节点两关系原子写集，互证来源需求确属请求存在，以二元组
  防重，并按首次材料、写入结果和同代读回收口幂等、冲突与发布未知。
- 身份查询读取基础节点和两条不可变关系，随后通过存在类专用入口读取零或一个 Vt，按
  预算读取方法节点组；方法结果去重并按稳定编码升序返回。精确查询读取所属存在和来源
  需求两个目标关系组并求源任务唯一交集。
- 目标方向入口只把任务当前关联的来源需求、请求身份、当前事实特征和结果位交给需求类
  计算，值式回显需求目标宿主、静态目标特征、方向定义和比较结果，零任务写、零目标复制。
- Vt 初始化先读基础任务与首次材料，经存在类取得无权限固定规格，再由任务类自己的端口
  恰一次提交一节点一关系，并经存在类专用查询读回；不借端口、不调用普通存在入口。
- 方法添加只证明输入编码是 G0 当前普通节点，以 task owner 原子发布一条角色 0 的
  `T→方法` 关系；不判断方法资格、版本、条件、效果或可执行性。方法组入口提供有界读回。
- 在工程与 filters 中于需求类之后各唯一登记任务类模块。

## 3. 公开 ABI

新增七个入口：

1. `任务类数据服务::新增任务记录(const 任务类新增请求&)`；
2. `任务类数据服务::查询任务记录(const 任务类身份查询请求&) const`；
3. `任务类数据服务::按所属存在和来源需求精确查询(const 任务类精确查询请求&) const`；
4. `任务类数据服务::读取任务目标方向(const 任务类目标方向读取请求&) const`；
5. `任务类数据服务::初始化任务虚拟存在(const 任务类虚拟存在初始化请求&)`；
6. `任务类数据服务::添加方法节点(const 任务类方法添加请求&)`；
7. `任务类数据服务::读取方法节点组(const 任务类方法组读取请求&) const`。

未增加查询锚点、Vt 首态、R1、状态、轮次、路径、冻结、执行、结果、结算、调度、退出、
恢复或旧 L2 兼容入口。
