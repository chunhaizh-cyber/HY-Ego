# FEATURE-TYPE-R-INTERVAL-RULE-PROVIDER 施工记录 v0.1

计划：`FEATURE-TYPE-R-INTERVAL-RULE-PROVIDER` v0.3。开工 HEAD：`f2764631f70419189f41e623c95a33cd5c782076`。

## 实际变更

- `海中鱼巣/领域/数据服务.特征类.h`：物理删除旧的“当前采用基准 F + 候选 F”归组 ABI；新增 R 材料、已核验成员投影、规则预算、归组/代表/归并请求与结果，以及已发布 I64 FT 的补齐入口。
- `海中鱼巣/领域/数据服务.特征类.cpp`：初始化独立的 R 规则结构扩展；新 I64 FT 在同一写集形成归组、代表及可选归并规则；实现三项只读规则调用和 I64 补齐逻辑。
- R 规则读取按实际取得的 FT→规则关系、规则锚点、锚点定义归属关系和两个规则属性执行预算守卫；并且仅允许本次实际读取的 R 项、成员和材料预算非零。
- 非 I64 或无域形成的归并按合同返回成功零输出；它们不接受未使用的规则或 R 输入预算。
- `归并特征R概念` 改用私有的 `形成I64特征域已持锁` 共享计算：原公开入口会取得同一互斥锁，不能在归并入口已持锁时重入；公开 `形成I64特征域` 仍通过该共享计算保持原有合同。
- 未修改 L1、特征值、存在、概念树、世界树、普通应用或 IF/R 持久化代码。

## S0 与复用裁决

计划在 `计划/计划索引.md` 中为“可执行”；当前 `main`、HEAD 与 `origin/main` 同为上述提交。目标两文件是本切片唯一生产源码写入；其他清理 WIP、概念树 WIP 和世界树构建切片均未改动、未暂存。

现有 `I64比较绑定结构扩展` 已提供“独立结构扩展首次写集、严格读回、初始化映射”的实现样板。因此 R 规则结构采用新的独立幂等写集，不改变既有定义 `d_` 的首次写集，避免旧定义恢复被误判为旧格式。规则锚点是每个 `FT+用途` 独立创建的普通节点，不是全局共享锚点。

## 完成边界

本施工只实现 FT 的 R 规则提供者。它不证明 IF/R 已持久化、FCr 已写入、四 owner 出生接线、非 I64 规则、跨进程恢复、普通应用装配或阶段 21。
