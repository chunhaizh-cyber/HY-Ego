## 2. 实际生产变更

只修改：

1. `海中鱼巣/领域/L2特征结构.数据.h`；
2. `海中鱼巣/领域/服务.L2特征结构.ixx`。

数据头新增：

- `L2特征当前值读取请求`；
- `L2特征当前值读取结果`；
- `L2特征当前值读取请求有效(...)`；
- `L2特征当前值读取结果::成功()`。

服务模块新增：

- 私有失败形成函数 `形成特征当前值读取失败(...)`；
- 公开 const 入口 `读取特征当前值(...)`。

入口只调用现有 `读取完整特征实例(...)`。它验证同一非零截止、零变更、当前读取类别、完整实例、自有关系和未退出生命周期；空当前值映射为 `属性未设置`，完整当前值才返回 `已读取`。没有新增 owner、写端口、L1 直达、缓存、索引、工程登记、普通应用入口或生产验证 seam。

## 3. 施工中纠正

初版委托只检查完整实例读取的状态。代码复核发现这不足以拒绝上游“已读取但截止 / 变更 / 类别 / 载荷不完整”的防御性坏成功形状，因此在计划范围内补充：

- 结果截止必须等于请求守卫；
- 变更事实代次必须为空；
- 读取类别必须为当前、历史截止必须为零；
- 实例和自有关系必须存在；
- 实例身份、生命周期和完整性必须成立。

补正未改变公开 ABI 或机器语义；补正后重新运行双配置 Rebuild。

## 4. 完成边界

本施工只形成 DATA-EXT-03 的具名当前值读取 ABI 和生产实现。它不证明 DATA-EXT-03 整项、其它 DATA-EXT、普通应用实际消费、运行态全部分支、暂停 EVENT 或《数据服务最终需求清单》整体完成。
