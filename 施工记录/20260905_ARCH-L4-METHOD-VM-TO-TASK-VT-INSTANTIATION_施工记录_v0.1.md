## 2. 实际 ABI

### 方法类 v3

- `方法类数据合同版本` 升为 3，原 34 个状态值保持不变，追加 35..42 八个参数规格状态。
- `方法类结构类型` 追加方法 owner 的场景、存在、特征三种 `Vm -> FT` 关系类型。
- 新增 `方法参数类别`、参数规格项、添加请求、组读取请求及单项/组结果 DTO。
- 新增 `添加方法参数规格` 和 `读取方法参数规格组`。添加只允许在唯一 Vm 上按全局
  `1..N` 顺序追加一条带类别关系类型和顺序角色的 FT 引用；组读合并三类关系并按全局
  顺序返回。FT 只由 L1 当前节点事实验证为带值表示的属性类型。

### 存在类参数规格专用合同 v1

- 新增 `任务方法实例参数规格专用合同版本`、25 个专用状态、三值类别、十四关系结构类型、
  方法来源/实例规格/实例投影、实例写集/绑定写集/组查询 DTO。
- 新增 `形成任务方法实例参数规格写集规格`：验证 T/Vt、M/Vm、三类方法参数关系与 FT，
  为 task owner 形成一个实例头 I、Vt 宿主、M/Vm 来源及同长度同顺序同类别的 `I -> FT`
  规格关系。写集不含值、属性槽、退出或实际参数。
- 新增 `形成任务实例参数绑定写集规格`：证明 I 及唯一参数槽后，只形成一条具名类别和
  顺序的 `I -> F` task-owner 关系；同槽不提供重绑。
- 新增 `读取任务方法实例参数规格组`：有界读回实例、来源规格、复制规格及每槽可选绑定，
  拒绝断序、复义、错 owner、错端点、错类别、无规格数据关系和来源漂移。

### 任务类 v3

- `任务类数据合同版本` 升为 3，原 31 个状态值保持不变，追加 32..53 二十二个实例化、
  绑定和可执行参数读回状态。
- `任务类结构类型` 在原四类型后追加 task owner 的实例宿主/来源、三类实例规格、三类实例
  数据关系，再追加 method owner 的 Vm 与三类方法参数关系。
- 构造函数新增 `方法类数据服务` 与 `特征类数据服务` 只读依赖；仍只持有既有 task-owner
  写端口。
- 新增四个公开数据操作入口：`实例化方法虚拟存在到任务虚拟存在`、
  `读取任务方法实例参数规格组`、`绑定任务方法实例参数`、
  `读取任务方法实例可执行参数组`。
- 实例化先证明方法已登记到任务，再读 M/Vm 和完整参数规格，提交 task-owner 写集并在
  Gend 精确读回。绑定前 fresh 查询已有 F 并要求 `F.特征类型 == 槽.FT`。可执行组读回
  要求每槽唯一绑定并逐槽 fresh 查询完整 `特征类结点`；零参数实例合法返回空组，任一缺槽、
  F 退出、类型错或漂移均返回零参数载荷的非成功状态。

## 3. 函数知识变更清单

- 方法类新增可复用用途：方法函数定义期按顺序登记三类参数 FT；按 Vm 读取完整强类型参数表。
- 存在类新增可复用用途：形成方法 Vm 到任务 Vt 内独立实例 I 的规格复制写集；形成逐槽绑定
  写集；读回实例规格及可选绑定。
- 任务类新增可复用用途：组合方法/存在/特征公开查询完成实例化、绑定和完整参数 fresh 读回。
- 未修改共享知识库与函数用途索引；应由已发布代码的知识库维护流程在后续独立回合投影。

## 4. 边界声明

- 本次仅实现数据记录、写集规格、提交与读回函数。
- 场景类零调用；旧 `服务.L2*` 零调用；不存在存在类向方法类/任务类的反向 import。
- 不创建参数规格节点，不复制 C/R、值或缺值特征，不合并 Vm/Vt/I，不回写 Vm，不跟随
  特征换代，不提供重绑。

  不判断方法运行结果，也不宣称 5260 正式实例方法已经形成。
