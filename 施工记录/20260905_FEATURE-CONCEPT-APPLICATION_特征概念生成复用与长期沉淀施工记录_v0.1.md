## 2. 实施结果

新增业务模块 `海中鱼巣.业务.应用服务.特征概念类`，并登记 vcxproj 与 filters。提供匹配、取得或生成、完整写入准备/原材料重放、已发布实例关联、正式名称字段读取、独立观测登记、长期成熟、治理生命周期迁移、引用释放及值域细分候选。

应用只组合真实 provider。世界实例、宿主及成员关系由验证中的合法上游写入；应用源码对存在/特征/特征值三 provider 的调用均为只读。应用未创建自有 L1 owner、私有权威概念表或第二概念入口。

新三类 provider 提供同 L1 实例识别、精确历史事实与按节点唯一历史值读取。每个读取在 Gread 下核验真实头、身份、类型、H 有效性及节点/值同创建同退出，不使用当前属性槽猜历史值。按节点路径预算先于零/多项分类，精确错误值不回退。材料来源允许其它真实 owner；属性类型仍必须属于值 owner，来源节点按 H 真实核验。

既有概念 owner 增加单次配置，复用材料服务及已有普通概念根/写端口。旧 C2 构造依赖顺序保留，root-only 配置缺旧 provider 的旧引用路径显式拒绝。新强类型引用追加持久 tag 11—14；旧 tag 与世界排序键保持各自命名空间，未新增 tag15、规则 owner 或把规则身份编码为数值签名。

概念创建、名称绑定/替换/退出、观测、成熟、实例当前引用释放均为同一概念 owner 的规范化单写集。原键首次材料核对先于当前 G 和当前端点检查。首次结果按发布 H 读回，发布后任何不能完成的结果保留可能发布及已知截止；不能确认首次键是否已发布的资源/内部失败亦不得伪称零写。

观测外部关系按 Grecord 历史重建，再按 Gobs 向世界 provider 核验。释放只退出名称/观测至实例的当前外部边，保留观测记录、概念归属及成熟证据。外部世界 owner 仍须自行处理其它当前引用。成熟规则完整材料及证据顺序固定，时间 0 合法，跨度和间隔必须大于 0，0/10/19 选择 0/19。

形成规则有独立不可变承载记录，与首次概念创建同事务写入，规则历史不依赖概念继续存在。成熟历史承载记录完整重读，不能只比较元数据忽略概念/证据缺项。细分读取宿主/FT 全部专用概念并独立验证本次规则，不按新规则筛掉旧观测；按观测键及来源/时间约束防止跨规则膨胀。

v0.6 创建保存完整原生成请求和结构请求。纯值互证全部形成输入，G 等于原 H 时重做正式当前生成准备，只有完全相同的创建裁决可交 owner；G 大于 H 时保持原 H/原键，仅已绑定完整相同写集可重放，未绑定键漂移。G 等于 H 却重新得到既有匹配，说明传入创建裁决与事实矛盾，返回引用冲突零写并保留原材料，不伪造已读取成功。

## 3. 发现与修复

- fixture 材料存储根及候选文件位置最初不满足真实材料 provider 要求，修正隔离目录与候选路径，未改生产材料服务。
- 独立只读审查指出历史头/状态分类、值表示、创建退出配对、来源和类型 owner、预算等问题，均在新增只读入口修复；旧 CRUD/旧重放主体未改。
- 名称同目标 fresh G 重复复用原关系，原键异完整请求仍冲突；语义零写分支增加尾 G 守卫和完整结果检查。
- 历史成熟规则一致性从仅元数据比较修正为完整成熟记录及证据读回。
- 真实生命周期连续冷却/退役/恢复后，旧键重放暴露既有首次结果 helper 将后来退出误当首次 H 退出。修正为退出代次不大于首次 H 才拒绝，并保留后续正式历史投影；未改变旧 ABI。
- 引用材料 fixture 最初用了 feature owner 的属性类型。快速探针返回引用冲突 11，G23 不变；改用 value owner 自有 I64 类型后已创建 1、G24→25。外部 host 来源保留，生产约束未放宽。
- 创建准备可变最终值域缺口按正式 v0.6 补原生成材料自证；未临场新增历史概念组接口。

- §18 补充真实消费者确认无观测退役特征概念普通退出返回内部不一致 14，G35 不变。原退出路径重建首次写集缺少初始程度/独立规则记录。修复为创建与退出共同调用 `FC追加首次特征内容`，先完整验证首次写集及规则历史，再从退出集合中排除独立规则记录及其自有关系/属性。程度值仍随概念退出。修后 G35→36，原创建 H 重放、退出旧键重放和原形成规则异义拒绝均真实通过。
