## 2. 实际实现

1. 新增单头公开合同 `海中鱼巣/领域/L2普通概念结构.数据.h`，定义普通概念合同版本、治理生命周期闭集、签名、定义、根归属、直接上位、来源证据、完整普通概念、建立 / 读取请求和结果。
2. 定义当前六类世界公开结构可回读的十三类强类型关系引用。因果动作使用独立 `L2概念动作引用` 包裹现行动作稳定编码，不猜成方法身份或动作入口身份。
3. 签名规则、签名值、定义、来源证据和治理生命周期事实均显式携带所属概念；直接上位携带上位 / 下位端点，根归属携带根 / 概念端点。
4. `L2普通概念建立请求有效` 接受两个签名项空组，但固定联合 `(角色, 顺序)` 唯一；直接上位和来源证据非空、严格排序。该 helper 不读取根、材料、世界端点、同根关系或 DAG。
5. `L2普通概念事实完整` 检查身份来源、同概念端点、稳定编码、确定排序、生命周期与治理状态闭集；写结果只接受首次活跃且全部初始事实当前，当前读取允许活跃 / 冷却 / 退役但要求全部当前，历史读取允许返回截止内已经退出的完整事实。
6. 工程和 filters 以 `ClInclude` 各唯一登记新头；没有新增模块、owner、服务函数、普通应用 getter、锁、缓存、日志、生产检查入口或第二 C1。
