## 2. 实际实现

1. 新增唯一真实模块 `海中鱼巣.领域.服务.L2概念结构聚合`，只 import C1，只持一份 non-owning `L2概念结构服务&`，禁用默认、复制和移动。
2. 聚合公开 const / non-const `取得L2概念结构服务()`，两者均 `noexcept` 并返回绑定的同一实例；没有 owner、写端口、锁、缓存、DTO 映射或世界结构转发。
3. 普通应用增加唯一 C1 与唯一概念聚合所有权，成员按“C1 后声明聚合”排列，析构时聚合先于其引用的 C1 销毁。
4. 普通应用只新增 const / non-const `取得L2概念结构聚合服务()`；未新增直接 C1 getter、optional / pointer getter、统一服务查找或按枚举选服务入口。
5. 在既有世界聚合完成后，普通应用经同一 `L1事实基座运行包` 依次建立唯一概念 owner、形成 move-only 交付、构造 C1、构造概念聚合，并只在全部成功后移动进入上下文。
6. 装配状态 0—23 保持不变，追加 24 `概念所有者范围建立失败`、25 `概念所有者交付形成失败`、26 `概念服务构造失败`、27 `L2概念结构聚合服务构造失败`；失败候选由 RAII 清理并返回空上下文。
