# 存在概念两组定义提供者施工记录

计划：`EXISTENCE-CONCEPT-DEFINITION-PROVIDER-REBUILD v0.3`

状态：施工中；本记录不声明计划完成。

## 当前已落地

- 合同头已增加存在概念两组定义的独立 DTO：自身 `FT→FC` 值域组、已知子 `EC` 组、显式完整声明、预算、状态、12 项结构登记交付和读写请求/结果。
- 两组 ABI 与旧 `纯概念定义` variant 分离；调用方不能借由新接口传入 D/O/R、组成角色、关系类型或参与角色。
- 服务头已声明两组定义的结构登记、规范化、有界枚举、精确查询、创建或复用和完整读回入口。

## 尚未完成

- 旧 D/O/R 物理退出、普通应用装配迁移和新 ABI 的 L1 写入/读回实现尚未完成。
- 当前 Debug 编译的首个错误仍是旧 `完整存在概念结构登记请求_v1` 默认比较式；后续旧实现同样存在语法错误。该旧链正是本计划的退出对象，未将其修补为新能力。
- 本记录不是构建、运行、恢复、集成验收或业务闭环证据。
