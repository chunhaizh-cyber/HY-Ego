## 2. 实际施工

1. 新增 `海中鱼巣.适配.适配器.单调时钟`，由单个不可复制实例保存非零运行代次、时间纪元和唯一 `steady_clock` 起点，公开读取只返回非负、可表示的 I64 纳秒值式证据。
2. `完整秒时钟服务`改为只借用单调时钟适配器；DTO 归模块自身所有；完整区间固定为`[上一+1, 当前]`，成功、无新秒和非成功的 optional 形状分账。
3. `运行期事实版本服务`改为只借用同一 `L2结构聚合服务`，经存在服务当前事实代次入口形成完整`已发布共享事实截止`。
4. `自我治理批次路由`改为保存完整秒观察、可选区间和完整共享事实截止材料，并在交付前逐字段复核状态、形状和配置回显。
5. `自我线程`改为借用结构聚合服务，并按`聚合借用 -> 单调适配器 -> 完整秒服务 -> 事实版本服务 -> 批次路由`顺序拥有临时运行期对象；下游只从已复核材料显式取得标量。
6. 启动阶段 20 改为传入普通应用上下文的同一 L2 结构聚合服务。
7. 现有自我治理端到端入口新增合法消费者读回：坏请求零材料、连续单调证据非递减、完整秒 optional 守恒、共享事实截止完整成功及治理批次对最终材料的实际消费。
8. 根工程和 filters 唯一登记新适配器，删除旧 `运行期Provider.数据.h`登记及文件；未保留转发头、别名、fallback 或双构造。

## 4. 完成边界

本施工只闭合当前进程内单调时间、完整秒、共享事实截止、现有生产消费者和合法读回入口的单一 ABI。批次路由最终重试状态机、普通应用最终 ownership、T02 最终停止边界、G0/G1、真实资源失败、跨进程连续性和系统业务闭环均未实施或未证明。
