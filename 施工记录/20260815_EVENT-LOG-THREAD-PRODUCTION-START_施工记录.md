### 2.2 真实模块与唯一租约

`海中鱼巣/线程/运行.事件日志线程.ixx` 建立真实模块 `海中鱼巣.线程.运行.事件日志线程`，只 `export import` SUPPORT 候选模块。模块私有实现：

```text
有界 deque + 单 mutex + condition_variable
-> 多生产者在短锁内线性化接受位置
-> 单消费者 FIFO 取出
-> 锁外机械调用一次记录事件日志
-> false / 异常只累计未成功次数并推进完成位置
```

入口在第一次等待前注册覆盖完整等待期的 `stop_callback`，回调只 `notify_all()`。停止接收锁存唯一截止；冻结快照永久禁止新取出并复制未取出有界值；stop 后零新取出，已移到局部的当前项最多完成一次。

启动函数在分配和 SUPPORT 调用前完整校验公开请求，内部固定形成 `事件日志 / 事件日志` 创建、进入等待和失败回收请求。成功返回一份只可移动构造的 EVENT 租约；租约按状态、适配器、入口、fallback 回收请求、SUPPORT 租约顺序拥有资源，显式 rvalue 停止连接和析构 fallback 都保持 SUPPORT join 先于借用对象销毁。

施工审查还补齐了模块全部新增函数的诊断责任备注，并显式包含 `exception`、`stdexcept`、`system_error`，未改变公开 DTO 或机器语义。
