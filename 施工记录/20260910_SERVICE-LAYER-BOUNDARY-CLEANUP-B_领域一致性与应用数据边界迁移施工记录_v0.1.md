## 2. 实际施工

1. 特征、需求、任务数据服务分别新增专属当前事实代次核验合同常量、四字段结果和`核验当前事实代次(uint64_t) const noexcept`。每个入口对非零期望值只调用一次自身 L1 当前事实代次读取，并区分成功、漂移、资源失败和内部不一致。
2. 新增七个冻结的窄同底座谓词；它们只逐层委托既有领域绑定能力，不返回或泄露 L1、锁、端口或 token。
3. 存在服务构造补齐特征服务同底座检查；任务服务构造补齐需求、存在、方法、特征四个依赖检查，原异常文本保持。
4. 二次特征计算、需求目标方向、任务目标方向三个应用物理删除 L1 成员、L1 首参数构造、直接 L1 读取和应用层`绑定于(L1)`；首尾守卫分别迁至特征、需求、任务领域核验入口。
5. `需求目标方向结果::成功()`删除跨模块`二次计算内部::键/输出键`调用，改为公开来源 variant 到公开节点身份 variant 的唯一节点递归；缺失、重复、无值和超深均收口为失败。
