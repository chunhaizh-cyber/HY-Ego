## 2. 实际修改

### 2.1 公开 DTO

在下列三个既有请求中分别追加 `std::uint64_t 最大数量 = 0`：

```text
L2按主体当前动态读取请求
L2按前状态当前动态读取请求
L2按后状态当前动态读取请求
```

三个纯值有效性 helper 均在既有合同版本、非零事实代次守卫和端点有效条件上增加 `最大数量 != 0`。

### 2.2 服务实现

三个公开入口把各自预算传入同一个私有 `按端点读取动态组(...)`。私有过程保持原 owner-aware 一致当前投影、关系角色检查、动态身份去重、端点互证、完整动态同截止读回和既有并发漂移收敛；新增行为固定为：

```text
收集唯一动态身份
-> 按动态身份稳定编码排序
-> 对象数大于最大数量
-> 返回 数量预算不足 + 安全截止 + 空动态组
```

预算等于匹配对象数仍走原成功路径。没有截断、分页、第二结果类型、第二入口、owner、写端口、缓存或索引变化；`收敛并发条件读取` 保持原样。
