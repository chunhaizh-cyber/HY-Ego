## 2. 实施结果

1. 在既有唯一 `服务合同事实权威服务` 内新增 module-private v2 覆盖登记、五类永久历史根和 `0x0307'3060..306B` 专属键；首次建立以当时当前合同 / 状态、进展 v2、准备 v2 形成不可变覆盖种子，恢复只接受首次规范写集和永久成员关系。
2. 进展 / 准备 v2 后继更新继续退出旧当前成员关系，但永久保留 v1/v2 历史成员；同代事实按业务流而不是全类别强制串成一条链。
3. 新增公开低层工程 ABI `按事实代次边界读取服务维护历史完整快照_v2`：从显式覆盖种子重放到 `Gstart`，返回请求 self 的左边界当前投影和 `(Gstart,G0]` 五类变化。
4. provider 返回成功前，把历史重放所得 G0 当前合同 / 状态、进展、准备与既有正式当前读回逐字段互证；公开 DTO 没有增加第二份 G0 终态投影。
5. `成功()`验证快照自包含形状、成员一一覆盖、规范顺序、self 归属、左边界有效未满足、消费秒不超冻结总秒及状态 / 到期事件合同归属唯一性。
6. 修正既有 v2 当前进展 / 准备读取的 per-self 投影：先完整校验全局 owner 闭包，再只投影请求 self；foreign self 不再被错误当成引用冲突。
7. validation-only 钩子可精确注入 G0 终态错配、按业务流后继缺口、v2 永久种子关系退出及当前 v2 引用关系损坏。引用损坏前必须证明目标属于同 G 当前成员完整闭包，历史事实或任意同 owner 非当前节点不能通过。
8. 专项新增 B00—B10，并补强 W05：持久恢复前后使用相同 self / Gseed / Gstart / G0，要求 v2 边界结果逐字段相等。

  - 用途：只接受 `已读取 + 完整快照 + 正式截止非零`，其它状态必须零载荷。
