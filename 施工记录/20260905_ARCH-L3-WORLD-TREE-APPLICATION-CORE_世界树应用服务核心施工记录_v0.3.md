## 3. 提供者组合与状态收口

- 模块只普通 `import 海中鱼巣.领域.数据服务.场景类`；没有导入旧 `服务.L2*`或 L1，也没有反向导出场景类。
- 读取仅调用 `场景类数据服务::查询场景树`，并核对合同、代次、绑定根、非空组和场景编码唯一性。
- 存在位置遍历整个绑定根闭包，对零位置、多位置和唯一位置分账；场景位置从同截止的`父场景`关系读取，绑定根明确不可移动。
- 两个移动入口共用私有过程，分别固定 provider 成员种类为`存在`和`子场景`；每次公开调用最多调用一次`场景类数据服务::迁移成员关系`。
- provider `已迁移`经发布代次最终读回闭合为`已移动`；无法闭合时只返回`已发布待复核`和已发布代次。provider `精确重复`要求 fresh 预读已唯一位于目标；后继事实覆盖、非本键已在目标、可能发布均保持非成功。
- 没有删除+新增、补偿回滚、自动重试、幂等键替换、缓存或后台线程。
