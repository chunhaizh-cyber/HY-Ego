## 2. 实际修改

### 2.1 公开 DTO

在下列三个既有请求中分别追加 `std::uint64_t 最大数量 = 0`：

```text
L2按条件状态当前因果读取请求
L2按动作当前因果读取请求
L2按结果状态当前因果读取请求
```

三个纯值有效性 helper 均在既有合同版本、非零事实代次守卫和端点有效条件上增加 `最大数量 != 0`。

### 2.2 服务实现

三个公开入口把各自预算传入同一个私有 `按端点读取(...)`。私有过程保持原 owner-aware 一致当前投影、关系角色检查、源因果身份排序去重和完整因果同截止读回；新增的唯一行为是：

```text
源因果身份排序去重
-> 去重对象数大于最大数量
-> 返回 数量预算不足 + 安全截止 + 空因果组
```

预算等于匹配对象数仍走原成功路径。没有截断、分页、第二结果类型、第二入口、owner、写端口、缓存或索引变化。
