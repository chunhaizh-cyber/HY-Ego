## 2. 实际施工

### 2.1 DTO、服务与工程登记

- 新建 `L2特征结构.数据.h`，唯一声明特征定义事实以及新增、固定属性初始 / 换代、退出、完整读取所需十个值式 DTO，并提供请求有效性、事实完整性和成功形状纯值辅助。
- 新建模块 `海中鱼巣.领域.服务.L2特征结构` 与 `L2特征结构服务`，只保存 `L1事实基座服务&`，公开五个入口：`新增特征定义`、`新增特征定义固定属性`、`换代特征定义固定属性`、`读取完整特征定义`、`退出特征定义`。
- 定义节点和固定属性值分别使用本地键 `0x0203'0001U`、`0x0203'0301U`；没有 import 存在服务，没有实现 F2 实例、宿主关系、特征值、状态、动态、因果或聚合装配。
- 主工程和 filters 登记新头与新模块；最终主工程为 27 个生产 `.ixx`、13 个头，四配置 `/utf-8` 共 4 项。

### 2.2 事务、读取与幂等

- 创建以唯一节点写集提交；属性初始以一份写集建值并设槽，属性换代以一份写集建新值、切槽并退出旧值；退出以一份写集退出定义节点及调用方显式给出的全部当前属性值。
- 当前完整读取以同一期望代次的两次 L1 一致投影形成节点和属性事实；历史读取以具名定义节点一致投影检查前代次，读取单事实历史与历史属性值组，再以同一具名投影检查后代次。
- 历史前后代次探测最初机械复用了 L1 旧式代次接口，Release 并发证据表明该接口会把底层许可拒绝压成资源失败。最终改为请求目标定义节点的 L1 一致当前投影，严格核对唯一节点结果项，从而保留许可拒绝、事实代次漂移和资源失败的独立状态。
- 创建、属性和退出的首次成功与精确重复均按首次事实代次重建原结果。为支持后继属性或退出后的原请求重试，单事实历史读回只要求读取代次不早于首次代次，并精确核对创建代次；晚于首次截止的退出和当前槽只在值式副本中清除，不修改权威事实。

### 2.3 专项验证施工

- 新建 Debug / Release x64、v145、C++20、Unicode、`/utf-8` 独立专项项目，编译七个正式模块和一个验证入口，不进入主工程或 filters。
- PowerShell 包装把输出和中间目录定向到系统临时 GUID 目录；验证只 import L1 公开服务与 F1 正式模块，夹具只经 L1 正式写集创建，F1 行为只经五个正式公开函数触发和读回。
- 第 16 项验证最初把历史成功结果误按当前轮代次校验；最终改为当前结果按轮代次、历史结果按具名历史截止校验。失败时的结构化诊断只存在于专项验证文件，没有形成生产诊断入口。
- 修复过程中曾短暂尝试空一致投影；L1 正式合同禁止空查询，该机械版本导致一次 Release 进程访问异常，已撤销且不计正式证据。最终实现始终使用具名目标定义节点，双配置复验未再出现访问异常或残留进程。
