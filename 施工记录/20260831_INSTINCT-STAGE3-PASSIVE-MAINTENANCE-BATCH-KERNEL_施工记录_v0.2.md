新增本记录与同名验证记录。实际实现包括：

1. 增加多完整秒请求、有限事实段、规范审计段、状态、载荷、结果和完整性谓词；所有非成功结果均无载荷。
2. `事实分段键`使用模块内非零 `std::uint64_t` 不透明关联键；不 import DATA，不取得 L1 身份或持久权威语义。
3. 验证事实段严格连续覆盖、唯一键、来源形状和相邻同语义必须合并；规则版本 1 请求必须与当前固定 `L/H` 同义。
4. 使用检查加乘、非负地板和、比例边界二分和每比例固定最多 10,000 步的安全收敛形成批量候选；不存在按待维护完整秒总数执行的循环。
5. 低位门禁材料仅在实际进入 `V>0 && 0<A<L` 时消费；其它分支向单秒参考派生`不适用`。
6. 形成连续规范审计段；事实、需求分支、30 天门禁、服务比例、A 分支和 0/1/L/H 边界变化时切段；输出预算不足返回空载荷。
7. 专项在既有 P00—P07 后新增 B00—B10，覆盖入口、版本、分段、地板和、30 天、活动保护、低位门禁、输出预算、比例边界、A 边界、I64 大跨度和 64 组确定性短区间逐秒 reference。

施工中发现并修正的计划内代码问题：

- 初稿把事实分段键错误纳入“相邻业务字段同义”比较，导致不同键的同语义相邻段不能被拒绝；现已从业务同义比较中排除键。
- 初稿只验证阈值顺序，没有拒绝安全根定义版本 1 下的阈值异义；现以模块私有兼容投影核对当前固定整数，正式权威仍来自请求中的安全根定义读回。
- 初稿把非空区间的零审计预算误映射为`分段不闭合`；现映射为`输出预算不足`。
- reference helper 初稿用`不适用`探测低位分支，会触发单秒载荷完整性拒绝；现先用允许形状探测真实分支，再仅在低位分支代入事实段门禁。
