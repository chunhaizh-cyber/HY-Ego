## 3. 函数级代码知识变更清单

### 3.1 新增或扩展的合同与公开函数

- `存在组成结构只读提供者::{绑定于,读取当前组成父,读取当前组成子组}`：只读存在 owner 的当前组成关系；不写事实、不解释世界树业务。
- `直接归属联合只读提供者::{绑定于,读取当前联合父,读取当前联合子组,读取当前场景角色位置}`：组合存在组成、场景存在成员和场景子场景三类归属；不成为第二写权威。
- `存在类数据服务::{读取当前组成父,读取当前组成子组}`：实现存在侧窄 provider。
- `存在类数据服务::新增子存在关系(const 存在类成员新增请求&, const 直接归属联合只读提供者&)`、`删除子存在关系(...)`：在固定 4096 关系预算内校验联合单父、无环和 C 角色后提交既有 L1 写集。
- `场景直接包含只读提供者::{读取当前场景包含父组,读取当前场景包含子组,读取当前场景角色位置}`：只读场景 owner 的包含及 C 位置事实。
- `直接归属联合只读组合器::{绑定于,读取当前联合父,读取当前联合子组,读取当前场景角色位置}`：持有两侧窄 provider 并核验同一 L1；不直接访问 L1。
- `场景类数据服务::{读取当前场景包含父组,读取当前场景包含子组,读取当前场景角色位置}`：实现场景侧窄读。
- `场景类数据服务::{启用并建立场景树根,启用并接纳直接子场景,启用并纳入既有归属树}`：以单次场景 owner 写入发布角色、四根、树证明和必要父边。
- `场景类数据服务::{新增直接存在成员,退出直接存在成员,迁移直接存在成员,迁移直接子场景}`：维护当前直接包含及同树迁移。
- `场景类数据服务::{读取当前直接存在成员组,读取当前直接存在成员父,读取直接存在成员历史,读取当前直接子场景组,读取当前直接子场景父,读取直接子场景历史}`：按固定种类委托通用只读核心；这些是本轮补齐的 L2 函数缺口。
- `场景类数据服务::读取直接包含历史(...)`：通用历史读保留为内部兼容入口。
- `场景类数据服务::读取当前场景树(const 场景树当前读取请求&, const 直接归属联合只读提供者&)`：递归投影根、场景、直接成员及直接子场景，执行稳定排序和预算核验。
- `世界树应用服务::{验证现实世界根,读取现实世界存在位置,移动现实世界存在,移动现实世界场景,创建场景并纳入现实世界,创建存在并纳入现实世界}`：六个 L3 入口只组合新 L2 服务，返回完整阶段、进度、续跑请求和成功投影。
