## 2. 实际生产变更

### 2.1 数据合同

在 `海中鱼巣/领域/L2特征结构.数据.h` 原位增加：

- `L2特征当前值退出请求`；
- `L2特征当前值退出结果`；
- `L2特征当前值退出请求有效(...)`；
- `L2特征当前值退出结果::成功()`。

请求固定要求有效共同合同、非零期望事实代次、非零幂等身份、非零实例和值编码，且值编码不等于实例编码。成功结果固定包含仍为当前且当前值为空的实例、未变化的两条自有关系引用，以及在写入截止退出的具名历史值；非成功三份载荷均为空且无变更代次。

### 2.2 唯一特征结构服务

在 `海中鱼巣/领域/服务.L2特征结构.ixx` 的同一 `L2特征结构服务` 内增加 `退出特征当前值(...)`：

1. 形成只含具名值编码的实例 owner 退出写集，不建立新值、新编码映射或第二属性槽；
2. 当当前事实代次仍等于请求守卫时，经正式完整实例读取区分 `属性未设置` 与 `引用冲突`；
3. 当前事实代次已经变化时不改写原请求，直接由 L1 对原守卫和原幂等写集裁决漂移、精确重复或冲突；
4. 首次和精确重复均核对合同版本、幂等身份、发布 / 重试边界、事实代次和零新编码映射；
5. 以首次写入事实代次作为历史截止，读回实例仍存在、两条自有关系保持且当前值为空，并读回具名值的完整历史生命周期；
6. 发布后读回仅允许一次内部历史投影重取；持续并发不能形成稳定读回时返回资源失败，要求调用方保留原完整请求重放，不把已发生发布误报为零变化漂移。

生产代码没有修改 L1、工程、filters、普通应用、聚合或其它 DATA 服务，没有新增空值、墓碑值、第二 owner、等待 / sleep、忙重试 ABI、测试 seam、测试 key 或验证输出。
