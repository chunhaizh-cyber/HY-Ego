## 3. 实际施工

### 3.1 裁决 DTO 与只读组合

- 新增任务目标达成请求、状态、裁决快照、结果和生命周期后继准备纯值 DTO；只有`目标已达成`和`目标未达成`可携带裁决。
- 运行期只读查询组合器新增带方法服务的八服务构造重载，保留既有七服务构造；七服务实例调用新裁决入口固定返回入口拒绝。
- 新裁决入口固定按正式结果身份读取、独立读回、完整方法、完整特征实例、目标状态合同和比较注册顺序执行，并逐项互证任务、实例、轮次、路径、方法、目标、状态、动态、场景和主体。
- 正式比较请求的左右材料只来自实际状态和目标合同；低于、达到、高于三种具名关系集中映射为`0x01 / 0x02 / 0x04`，并由编译期断言锁定。
- 正式结果尚无、方法尚无和目标合同尚无映射为合法等待；旧截止映射为当前性漂移；错绑映射为引用冲突；未注册或类型、单位、维度、角色不匹配映射为不可比较；资源、入口和内部错误保持独立分账。

### 3.2 治理装配与自我线程

- 治理骨架新增方法服务借用、八服务装配重载和值式目标裁决转发入口；七服务装配会清空方法服务借用，防止复用旧装配形成伪成功。
- 普通应用从同一应用上下文注入现有方法结构服务，不新建第二方法服务。
- 自我线程在002-04成功后先冻结唯一任务结果后继，再进入目标裁决；公开处理槽新增目标裁决次数和可选裁决。
- 处理槽分别记录绑定复核次数和目标裁决次数。后继已冻结时，同槽重试跳过邮箱、分类和002-04，只再次调用目标裁决。
- 已达成或未达成冻结唯一裁决并返回`任务目标裁决已形成`；不可比较、引用冲突、入口拒绝、当前性和内部错误结构化终止；合法等待和资源失败保槽等待显式重试。
- 自我线程未取得任务写能力，也未调用任务结构写入口。

### 3.3 治理专项

- 主成功路径继续从真实任务结果生产运行包进入工作线程、管理线程、上行桥、自我治理邮箱、批次路由和002-04，再进入目标裁决。
- 成功夹具的任务目标、方法结果、路径预期、目标合同、实际状态和动态证据已调整为同一目标；形成`当前达到目标 + 待验证后完成`。
- 辅助链覆盖`当前低于目标 + 目标未达成待重筹办`、旧截止、任务错绑、结果尚无、七服务入口拒绝和非 I64 实际状态不可比较。
- 不可比较链先形成正式任务结果并通过002-04绑定，再由目标裁决结构化终止；裁决前后事实代次相等，零生命周期准备。
