## 实际实现

1. 增加独立 `L2目标状态合同身份`、四项专属结构类型身份、登记 DTO、目标合同事实、增改退和当前 / 历史读取 DTO 及纯值校验；目标合同身份不转换为 `L2状态身份`，不取得状态族归属。
2. 在现有状态 owner 内建立四节点专属结构类型登记；服务构造时独立建立或精确重复收敛，不改变既有十节点实例状态登记。
3. 新增固定写集为一个合同节点、两条具名外部引用关系、一个 I64 目标值、一个 U64 合同值和两个当前槽；U64 合同值持久保存规则版本、目标判断用途、允许关系位、首次幂等身份和首次期望事实代次。
4. 新增 / 替换写前以同一非零守卫读取完整当前特征定义和唯一当前目标判断比较注册，并核对 I64 标量算法、当前事实 / 目标状态左右角色、右减左方向及具名关系输出能力。
5. 替换以一笔状态 owner 写集退出旧节点、两关系、两值并建立全新五项闭包；退出只提交具名五项旧闭包，服从 L1 当前引用保护。
6. 当前读取使用一笔 owner 一致投影读取合同节点、两关系、两值、两个槽及三个实例状态禁止关系组，再以同守卫正式互证特征定义和比较注册；历史读取使用显式截止重建闭包并做历史互证。
7. 完整请求的首次规范化写集可由状态 owner 正式读回；精确重复原样重放，同键异义以逐字段回读收敛为幂等冲突。
