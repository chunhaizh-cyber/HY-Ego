## 2. 实际施工

### 2.1 公共 L2 合同

新建 `海中鱼巣/领域/L2结构公共.数据.h` 与 `海中鱼巣/领域/合同.L2结构公共.ixx`：

- 定义共同请求头、结果头、有序身份引用、类型化原始材料、属性提交项、属性事实和生命周期；
- 只提供计划冻结的请求头、幂等身份和生命周期纯值完整性辅助；
- 合同模块导出 L1 公共事实合同与公共 L2 数据头，不形成事实写入能力。

### 2.2 场景 DTO 与服务

新建 `海中鱼巣/领域/L2场景结构.数据.h` 与 `海中鱼巣/领域/服务.L2场景结构.ixx`：

- 场景数据头唯一定义父子关系事实、成员关系事实、S1 场景事实、新增 / 读取请求及写入 / 读取结果；
- `新增场景节点` 把合法请求映射为本地键 `0x02010001U` 的恰一个普通节点，关系、值、属性槽变更和退出项均为空；
- L2 幂等身份的完整 64 位原样映射为 L1 幂等键，只调用一次 `提交中性写集`，不预探测、不预分配、不重试提交、不建立第二幂等账；
- 首次成功和精确重复均核对 L1 发布形状、唯一新编码映射及历史节点读回；同键异义按 L1 正式幂等账返回冲突；
- 当前读取只选择一个节点并恰一次调用一致当前投影，其余五组选择与结果保持为空；
- 历史读取按“当前代次前探测—历史事实—当前代次后探测”顺序夹取同一期望代次；
- 所有非成功均返回空场景、空变更代次和结构化状态；未建立关系、属性、退出、缓存、登记、仓库直达或生产装配。

## 3. 施工期修复

首次外部 Debug 构建发现验证入口自身的机械错误：普通 `.cpp` 带有不完整的全局模块片段、缺少标准容器比较所需声明，且零强类型身份赋值未显式构造。只在 `验证工具/L2场景节点参数验证.cpp` 内修正后，Debug 与 Release 外验均构建运行通过；该问题未改变生产合同、L1 ABI、文件范围或机器语义。

宽字符标准输出在命令捕获环境中不可见，无法满足逐断言人读证据要求。验证入口改为 UTF-8 窄输出后重新执行，所有结构化字段和断言均可见；没有把退出码单独作为通过依据。
