## 2. 实际修改

### 2.1 一次中性一致当前读取

`L1实际存在服务::读取资格实现` 不再首读 / 末读事实代次并分散读取三个节点、属性槽和资格值。每轮只在一个物理调用点形成：

```text
节点：实际存在、资格属性类型、登记服务来源
关系：空
值：空
属性值：实际存在 × 资格属性类型
源关系组：空
目标关系组：空
```

无显式资格值时，属性值投影同时携带当前槽和当前值事实，因此不重复请求独立值。有显式资格值时，同一一致请求的值组恰一项且为调用方给出的编码：

```text
无显式值：3节点 / 0关系 / 0值 / 1属性值 / 0源组 / 0目标组
有显式值：3节点 / 0关系 / 1值 / 1属性值 / 0源组 / 0目标组
```

显式值结果与属性投影当前值事实逐字段全等后才形成资格事实。这样保持“显式编码不存在返回未找到；存在但不是当前资格返回内部不一致”，且没有向第一层增加业务字段。
