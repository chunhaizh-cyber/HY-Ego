## 1. 实际范围

本次只修改场景数据头、场景服务模块，新增生产工程外 R1 专项三文件和本记录 / 配对验证记录，并同步删除三套只消费旧 ABI 的九个临时专项文件。未修改 L1、存在 / 特征 / 状态 / 动态 / 因果服务、A1、普通应用、根工程 / filters、规范、详细设计、计划、索引或流程图。

## 2. 实际实现

- 新增具名场景树身份、根 / 非根创建请求结果、树归属、树节点、整树读取和树结构登记 DTO 及纯值完整性函数。
- 场景 owner 构造期登记树锚点、根标记类型和树归属类型；登记只锁定定位复制 / 发布，不跨 L1 提交与读回持锁。
- 根创建以一份 owner-scoped 写集建立场景、场景族归属和根标记；非根创建以一份写集建立场景、场景族归属、树归属和直接父关系。两者成功和精确重复均正式读回首次截止事实。
- `读取场景树归属` 对根标记 / 树归属严格二选一，当前和历史逐项核对 owner、类型、端点、角色和生命周期；退出截止返回 `已退出` 空载荷。
- `读取场景树` 收集具名树根和全部非根，逐节点核场景、来源、归属、父关系、同树、稳定排序、根零父、非根恰一父、连通和无环。
- 删除旧裸 `L2场景节点新增请求`、`新增场景节点`、`新增场景父子关系`、`退出场景父子关系` 及只服务旧 ABI 的私有 helper。
- 父子替换只允许同树非根；场景身份来源、属性、成员、完整读取和反向成员读取均增加正式树归属门禁。
- 既有属性新增 / 换代、父子替换、成员新增 / 替换 / 退出先形成确定写集并执行 S2 代次检查；只有同代成功才执行树归属和业务前置，`直接提交` 路径交由 L1 幂等账判定精确重复，不把漂移、许可、资源或内部错误统一压成入口拒绝。
- 场景退出 DTO 增加当前树归属关系和已退出树归属。根的规范请求固定引用冲突；非根叶必须精确闭合树归属与直接父，单事务退出完整闭包并正式历史读回场景、身份来源、树归属和直接父四项同代载荷。
- 场景根创建、非根创建和场景退出以服务级业务写锁稳定并发提交与写后读回；未增加验证锁、测试计数器或故障钩子。
