## 2. 实际实现

1. 导出唯一 `概念所有者建立身份`、move-only `L2概念所有者交付`、形成函数和不可复制移动的 `L2概念结构服务`。
2. 构造期在唯一概念 owner 内依次原子登记概念族锚点/族归属关系类型，以及本体根角色锚点/角色关系类型/直接上位关系类型/首次见证属性类型；登记支持首次与精确重复并逐节点历史读回。
3. 实现三项公开能力：`建立概念本体根`、`按角色读取当前概念本体根`、`读取全部当前概念本体根`；未增加第四入口、根退出、根替换或普通概念入口。
4. 单根写集原子包含根概念节点、概念族归属关系、根角色关系、首次请求见证 U64 组值和当前属性槽；公开幂等身份逐值进入同一 owner 域，两项内部登记身份由模块私有检查拒绝。
5. 全组读取只调用一次 L1 关系类型闭包投影：同截止读回 owner、角色关系、概念族来源、首次请求见证和根作为目标端的直接上位空组；输出按四角色固定升序并拒绝重复角色、重复根身份或重复首次幂等身份。
6. 建立入口以私有 mutex 串行同 owner 根唯一性检查；同键异义、同角色异请求、陈旧守卫、资源失败和坏形状分别结构化返回。成功或精确重复经唯一写端口读取首次规范化写集/首次结果，再以首次截止执行 owner-aware 历史读回并证明直接上位为空。

现行 L1 `节点种类` 只有 `普通` 与 `属性类型`；关系类型节点按仓库既有唯一表达实现为“被关系的 `关系类型节点` 字段引用的普通节点”。首轮编译对不存在的 `节点种类::关系类型` 报错后已按这一现行 ABI 修正，公开合同、稳定编码、关系方向和事务写集未改变。
