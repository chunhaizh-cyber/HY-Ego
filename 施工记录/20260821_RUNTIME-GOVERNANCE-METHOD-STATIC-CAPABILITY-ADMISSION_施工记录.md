## 3. 实际施工

### 3.1 DATA-L2 方法 v2

- 合同版本提升为 2，增加用途、条件目标类型、三态方向、闭合结果类型、条件结果关系、输入规格、限制条件及其强类型事实。
- 结果类型分支机器序号固定为状态合同 `1`、动态概念 `2`；持久负载、排序和比较只用分支序号与稳定编码，未使用 `variant::index()`、类型名、内存布局或哈希。
- 目标对象类型在相同事实截止确认属于存在根；概念结果类型确认属于动态根；状态合同结果通过状态服务同截止读回。
- 新增、替换、退出保持单一方法 owner 原子写集；精确重复独立历史读回；同键异义、版本 / 顺序 / 引用冲突零写。
- 当前 / 历史 `读取普通方法` 重建完整 v2 事实；历史 v1 事实允许读回旧基础材料，但不会补默认方向、目标对象或结果类型。

### 3.2 投影与用途粗召回

- 新增 `按用途读取方法粗召回组`：当前索引和历史锚点均使用调用方截止，按扫描用途事实数和粗召回方法数双预算收口，预算不足返回空载荷。
- 新增 `读取方法六项静态能力投影组`：每个结果为独立主轴，只绑定四元组相同的唯一用途；条件仅通过正式条件结果关系进入对应主轴。
- 全方法与条件级输入规格 / 限制条件按主轴合并，按正式字段字典序排序并稳定去重；用途结果冲突、条件关系缺失及引用冲突形成值式结构缺口。
- 历史粗召回改为从旧截止仍活动的方法锚点逐方法历史读回，不再用全部当前值索引伪造历史。

### 3.3 DATA 外候选准入

- 新增 `方法静态能力候选准入提供者`，构造函数只持有 `const L2方法结构服务&`。
- `读取匹配候选` 固定执行入口校验、用途粗召回、逐方法投影、六项精确比较、结构缺口合并、候选规范化排序和四态结论。
- 空组只与空组相等；任一 DATA 非成功不返回部分候选；原共同截止原样返回。
- 同方法、同版本、同主轴结果和同签名的重复候选按稳定顺序保留首项；同主轴签名复义返回内部错误。

### 3.4 消费者迁移、工程与删除

- `运行期只读查询组合器::裁决任务目标达成` 只在结果类型为 `L2目标状态合同身份` 且强类型身份相等时计入预期结果命中；动态概念分支不按底层编码误认。
- `L2方法结构服务` 构造增加概念服务只读依赖；普通应用和治理专项都传入既有唯一概念服务。
- 工程和 filters 登记新准入模块，删除旧筹办模块登记；旧筹办两文件已删除且未保留兼容空壳。

### 3.5 专项扩展

- 需求专项新增方法 v2 当前 / 历史 CRUD、精确重复、同键异义、错版本 / 错根 / 顺序 / 引用零写、多用途多结果、条件级与全方法规格、无笛卡尔组合、双预算、替换和退出历史隔离。
- 治理专项经公开提供者覆盖六项完全相同、六项逐项差异、空组严格相等、四态结论、扫描 / 候选预算、当前性漂移、入口拒绝、固定旧截止、替换 / 退出后历史候选和提供者读链零事实写入。
