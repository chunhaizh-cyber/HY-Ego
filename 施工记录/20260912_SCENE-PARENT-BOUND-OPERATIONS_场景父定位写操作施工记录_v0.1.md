# 场景父定位写操作施工记录

身份：SCENE-PARENT-BOUND-OPERATIONS；日期：2026-09-12；起点：`ac85e073`（v0.2计划支撑已发布）。

## 变更

- `场景角色启用请求`升级为版本3，增加父场景和两项有界预算；`启用场景角色`只把完整请求转入既有`启用并接纳直接子场景`，零父直接拒绝。
- 物理删除无父场景启用实现，以及`启用并纳入既有归属树`的公开声明、定义、请求DTO和成功谓词；不再沿普通存在组成链猜测上游场景。
- `场景角色退出请求`升级为版本3并增加父场景。退出先证明当前唯一直接父、非根树归属证明和空依赖，再由一个场景owner写集共同退出父关系、树归属证明、四根及四根绑定共十项。
- 重放按首次写集读取十项历史生命周期；同键异父返回幂等冲突，原键精确重复零写。
- 绑定存在专项新增零父拒绝、父定位退出、精确重放及同键异父覆盖。

未修改L1、存在类、绑定存在协调器、世界树、工程登记和生产装配。

## 函数知识变更清单

| 函数 | 变化 | 调用边与边界 |
| --- | --- | --- |
| `场景类数据服务::启用场景角色(request, joint)` | 旧无父单owner启用改为显式父场景门面 | 只调用`启用并接纳直接子场景`；不猜父、不选根 |
| `场景类数据服务::退出场景角色(request)` | 增加父定位及十事实共同退出 | 读取父组、位置、依赖和首次材料；一次场景owner提交 |
| `场景类数据服务::形成启用写集(g,key,E)` | 请求DTO参数改为三个内部参数 | 只形成场景族边、四根和四绑定，不决定父或根 |
| `启用并纳入既有归属树`及旧成功谓词 | 物理退出 | 模块外生产调用原为0 |

共享知识库未在本切片改写；其场景服务用途卡应在结果发布后按本提交复核。
