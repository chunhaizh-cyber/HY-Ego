## 4. 编译修正

首轮 Debug 编译发现 MSVC 模块边界下现有事实 DTO 的默认比较不可用于快照比较。施工在新索引模块内改用显式字段、optional 与 variant 比较帮助函数；现有公开 DTO 和服务签名均未改变。

结果提交后的计划矩阵复核指出三项白名单内遗漏，追加施工如下：

- 私有不可变视图显式保存固定合同版本与私有数据版本，并把两者纳入候选构造、完整验证、内容等价及查询捕获/末次身份门。
- 候选完整验证增加四类映射键、关系三引用键、值三引用键及节点属性槽键的非零机械校验；Debug 一次性损坏改为注入零关系源映射键。
- 专项改为独立读、重建、清空、匹配失效四线程竞争，机械要求实际观察重建成功、精确重复和索引视图漂移；竞争结束后重建完整视图、权威回读，并以最后清空证明后发生清空不被覆盖。

并发判定保持详细设计冻结顺序：取得发布锁后，当前视图与候选身份及内容完全相等时先返回精确重复；仅在不等价时把已变化的视图序号分类为索引视图漂移。专项保留多轮独立读、重建、清空和匹配失效线程竞争，只断言允许状态集合、单一来源代次、最终完整重建及后发生清空，不要求一次调度必然观察到视图漂移；该分支另以源码静态闭包证明，不增加第二 Debug 入口。
