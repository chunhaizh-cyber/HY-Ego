## 3. 实际施工

### 3.1 DATA-L2 方法 v3

- `L2普通方法结构合同版本`由 2 升至 3。
- 删除`L2方法用途粗召回键/请求/项/结果`以及`按用途读取方法粗召回组`。
- 新增`L2方法特征粗召回请求/项/结果`和`按特征读取方法用途粗召回组`。
- 粗召回只按目标特征命中；对象类型、方向和结果类型留给 BIZ provider 判断。
- 当前 / 历史均由调用方冻结截止读取，结果按方法身份、用途身份严格升序；同一方法只消耗一次候选预算，同方法全部命中用途仍保留。
- 扫描用途事实预算或方法候选预算不足时整项返回`数量预算不足`且不返回截断候选。

### 3.2 旧准入退出与新 provider

- 删除`方法静态能力准入.数据.h`和`服务.方法静态能力候选准入.ixx`，旧六项精确相等准入 DTO / provider / `读取匹配候选`全部退出。
- 新增`任务特征方法查找与条件提议.数据.h`，冻结九种合法逻辑结论、四种任务相对不兼容原因、值式候选 / 缺口 / 未绑定证据 / 条件草案和八预算请求。
- 新增`任务特征方法查找与条件提议提供者`，只持有七服务 const 引用；唯一公开入口为`评估下一筹办方法候选并形成条件提议`。
- provider 互证任务来源需求、旧实际状态、特征实例、治理状态、正式未达成裁决和共同截止 G；目标状态引用或重算矛盾返回`引用冲突`，G 漂移返回`当前性漂移`。
- 零概念不猜默认；存在根直达；普通 / 多概念形成完整祖先闭包；错根、退出概念、成环和引用损坏按结构化状态收口。
- 粗召回后逐方法消费六项静态能力投影；对象、方向、结果种类和目标状态合同不兼容分别形成证据；用途 / 结果角色冲突保留为结构缺口。
- 零适用候选区分`方法结构待补齐`与`当前无适用方法`；多适用候选返回`多候选待选择证据`，不采用且零条件草案。
- 只有唯一采用方法读取完整方法。先完成条件角色筛选并收集已绑定条件；已绑定组非空时在条件循环外唯一一次读取主体当前状态组，全部条件复用；空组零调用。
- 输入规格 / 限制作用对象角色等于主轴结果角色时绑定目标宿主，否则形成具名未绑定证据；条件草案只来源于已采用方法。
- `bad_alloc/length_error`映射`资源失败`，其它异常映射`内部错误`；非`已评估`结果统一零业务载荷。
- 15 个`L2结构状态`显式映射并各有`static_assert`；v0.5 补齐`已提交/精确重复/已读取 -> 内部错误`三项断言。

### 3.3 普通应用、消费者和工程

- 普通应用构造并持有唯一`任务特征方法查找与条件提议提供者`，新增 const getter `取得任务特征方法查找与条件提议提供者()`。
- 新增具名装配失败状态`任务特征方法查找提供者构造失败`。
- 治理专项只经普通应用 getter 消费真实 provider；没有第二套生产服务或测试专用 provider。
- 需求专项迁移到按特征粗召回，保留当前 / 历史、双预算、替换和退出矩阵。
- 根工程和 filters 对旧两个文件与新两个文件做精确替换登记。
