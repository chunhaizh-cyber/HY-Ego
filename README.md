# HY-Ego · 海中鱼巣

海中鱼巣是一个使用 C++ 开发的数字生命研究项目，围绕自我、需求、任务、方法、学习以及与外部世界的交互，探索从信息组织到行动与反馈的系统实现。

项目同时维护生产代码、逻辑规范、详细设计、施工计划和验证记录。当前处于持续研发与验证阶段；代码存在、编译通过和完整服务流程验证通过是不同的证据，具体能力边界请以对应版本的验证记录为准。

## 项目内容

- **信息与世界建模**：组织存在、特征、场景、概念、动态和因果等信息，以及现实世界认知、自然语言和外设相关材料。
- **自我与任务治理**：围绕需求组织任务、筹办执行条件，并连接方法执行、学习和结果反馈。
- **语言与交互**：包含初始化语言材料、基础汉语结构转换、本地网页对话和控制面板相关实现。
- **外设接入**：包含可选的 Intel RealSense D455 接入代码；是否完成具体设备验证，应查阅相应记录。

以上是代码组织与研究方向的概述，不代表通用自然语言理解、自主学习或端到端服务闭环已经全部完成。

## 构建环境

- Windows。
- Visual Studio C++ 开发环境，安装工程指定的 **MSVC v145** 工具集和 **Windows 10 SDK**。
- C++20 与 MSBuild。

可打开根目录的 `海中鱼巣.slnx`，或直接构建 `海中鱼巣.vcxproj`。建议使用 `x64` 配置。默认构建不启用 RealSense，不要求安装该 SDK。

在 Visual Studio Developer PowerShell 中，切换到仓库根目录：

```powershell
msbuild .\海中鱼巣.vcxproj /t:Build /m /p:Configuration=Release /p:Platform=x64
```

需要调试时，将 `Configuration=Release` 改为 `Configuration=Debug`。Debug 配置包含额外检查，启动初始化可能明显慢于 Release；具体耗时取决于源码版本、初始化材料和运行环境。

也可以指定独立的构建输出目录，便于找到可执行文件和隔离不同配置的产物：

```powershell
$buildRoot = Join-Path $env:TEMP 'HY-Ego-build-Release'
msbuild .\海中鱼巣.vcxproj /t:Build /m /p:Configuration=Release /p:Platform=x64 "/p:OutDir=$buildRoot\bin/" "/p:IntDir=$buildRoot\obj/"
```

不同配置应使用不同的构建目录，避免产物混用。

## 运行

使用上面的独立输出目录构建成功后：

```powershell
& "$buildRoot\bin\海中鱼巣.exe"
```

默认模式进入普通控制面板和本地网页对话宿主。程序先完成应用装配及治理线程启动，再进入宿主，因此启动初始化期间可能尚未出现页面。

| 参数 | 用途 |
| --- | --- |
| 无参数 | 默认普通控制面板模式 |
| `--headless` | 无窗口常驻运行 |
| `--runtime-context` | 生产运行期模式，使用普通程序启动链和无窗口宿主 |
| `--web-service-object-login=<登录名>` | 仅默认模式允许，由可信本机启动者显式指定本次网页会话的服务对象登录名 |

模式参数不能重复或混用。`--web-service-object-login` 不是身份认证的替代入口；未指定时，不自动把网页访客绑定为第一权限人。

构建会把四份固定初始化文本复制到可执行文件旁的 `初始化材料/`。分发或移动程序时，应同时保留这个目录，不能只复制 EXE。材料格式见[初始化材料说明](初始化材料/README.md)。

当前日志目录在代码中固定为 `D:\海中鱼巣\日志`，不会随 EXE 输出目录变化。运行前应确认该位置可写；不同工作树运行时也会使用这一共享目录。

## 可选：RealSense D455

准备好 vcpkg 布局的 RealSense SDK 后，可在 `x64` 构建命令中增加：

```powershell
/p:EnableD455RealSense=true /p:VcpkgRoot=C:\path\to\vcpkg
```

也可通过环境变量 `VCPKG_ROOT` 提供根目录。工程从 `installed/x64-windows` 读取 SDK，并按 Debug／Release 配置复制对应的 RealSense 和 LZ4 DLL。此开关仅启用设备相关构建，不表示相机连接、观察处理或交互流程已验证通过。
